# 演習問題【3-B-25】

## 解答

### 1. 準備：エントロピー $S(T, 0)$ とヘルムホルツの自由エネルギー $F(T, 0)$ の導出

まず，磁化 $M=0$ のときの熱容量 $C_{M=0}$ が与えられている．

$$C_{M=0} = T \left( \frac{\partial S(T, 0)}{\partial T} \right) = \frac{b}{T^2}$$

これより，エントロピーの温度依存性を求める．

$$\frac{\partial S(T, 0)}{\partial T} = \frac{b}{T^3}$$

これを $T$ について積分すると，

$$S(T, 0) = \int \frac{b}{T^3} dT = -\frac{b}{2T^2} + B \quad (B \text{ は積分定数})$$

が得られる．

次に，磁化 $M=0$ のときのヘルムホルツの自由エネルギー $F(T, 0)$ を求める．
熱力学の関係式 $dF = -S dT + M dH$ より， $M=0$ のときは

$$\frac{dF(T, 0)}{dT} = -S(T, 0) = \frac{b}{2T^2} - B$$

となる．
これを $T$ について積分すると，

$$F(T, 0) = \int \left( \frac{b}{2T^2} - B \right) dT = -\frac{b}{2T} - BT + A \quad (A \text{ は積分定数})$$

が得られる．

### 2. 磁化 $M$ を含む自由エネルギー $F(T, M)$ の構成

問題文より，キュリーの法則 $\chi_T = C/T$ が成り立つ．
磁化は $M = \chi_T H = (C/T) H$ と書けるので，

$$T = \frac{CH}{M}$$

である．

磁場 $H$ を含む自由エネルギー $F(T, H)$ は，一般に $F(T, H) = F(T, 0) - \int_0^H M dH'$ と書ける．
$M = (C/T) H'$ を代入すると，

$$F(T, H) = F(T, 0) - \int_0^H \frac{C}{T} H' dH' = F(T, 0) - \frac{C}{T} \frac{H^2}{2} = F(T, 0) - \frac{CH^2}{2T}$$

ここで $M = CH/T$ より $H = MT/C$ なので，これを代入して $F(T, M)$ を求める．

$$F(T, M) = F(T, 0) - \frac{C}{2T} \left( \frac{MT}{C} \right)^2 = F(T, 0) + \frac{TM^2}{2C}$$

これに $F(T, 0)$ を代入すると，

$$F(T, M) = A - BT - \frac{b}{2T} + \frac{TM^2}{2C}$$

となる．

### 3. 熱容量 $C_M$ および $C_H$ の計算

#### (i) 磁化一定の熱容量 $C_M$

エントロピー $S(T, M)$ は，

$$S(T, M) = -\left( \frac{\partial F(T, M)}{\partial T} \right)_M = -\left[ -B + \frac{b}{2T^2} + \frac{M^2}{2C} \right] = B - \frac{b}{2T^2} - \frac{M^2}{2C}$$

磁化 $M$ を一定に保ったときの熱容量 $C_M$ は，

$$C_M = T \left( \frac{\partial S(T, M)}{\partial T} \right)_M = T \left( \frac{b}{T^3} \right) = \frac{b}{T^2}$$

となる．
これは $M=0$ のときと一致している．

#### (ii) 磁場一定の熱容量 $C_H$

$S(T, M)$ に $M = CH/T$ を代入して， $H$ を用いたエントロピー $S(T, H)$ を求める．

$$S(T, H) = B - \frac{b}{2T^2} - \frac{(CH/T)^2}{2C} = B - \frac{b}{2T^2} - \frac{CH^2}{2T^2} = B - \frac{b + CH^2}{2T^2}$$

磁場 $H$ を一定に保ったときの熱容量 $C_H$ は，

$$C_H = T \left( \frac{\partial S(T, H)}{\partial T} \right)_H = T \left( \frac{b + CH^2}{T^3} \right) = \frac{b + CH^2}{T^2}$$

となる．

### 4. 断熱磁化率 $\chi_s$ の計算

断熱過程ではエントロピー $S$ が一定 ( $dS = 0$ ) である．

$$dS = \left( \frac{\partial S}{\partial H} \right)_M dH + \left( \frac{\partial S}{\partial M} \right)_H dM = 0$$

これより，断熱磁化率 $\chi_s$ は次のように求められる．

$$\chi_s = \left( \frac{\partial M}{\partial H} \right)_s = -\frac{(\partial S / \partial H)_M}{(\partial S / \partial M)_H}$$

計算を簡略化するため， $S(H, M)$ を求める．
$M = CH/T$ より $1/T = M/(CH)$ を用いると，

$$S(H, M) = B - \frac{b}{2} \left( \frac{M}{CH} \right)^2 - \frac{M^2}{2C}$$

各偏微分を計算する．

$$\left( \frac{\partial S}{\partial H} \right)_M = -\frac{b M^2}{2 C^2} (-2 H^{-3}) = \frac{b M^2}{C^2 H^3}$$

$$\left( \frac{\partial S}{\partial M} \right)_H = -\frac{b}{2 C^2 H^2} (2M) - \frac{2M}{2C} = -\frac{bM}{C^2 H^2} - \frac{M}{C}$$

これらを $\chi_s$ の式に代入すると，

$$\chi_s = -\frac{\frac{b M^2}{C^2 H^3}}{-\left( \frac{bM}{C^2 H^2} + \frac{M}{C} \right)} = \frac{b M^2}{C^2 H^3} \cdot \frac{1}{\frac{bM}{C^2 H^2} + \frac{M}{C}}$$

分母を通分すると，

$$\frac{bM}{C^2 H^2} + \frac{M}{C} = \frac{bM + M C H^2}{C^2 H^2} = \frac{M(b + C H^2)}{C^2 H^2}$$

したがって，

$$\chi_s = \frac{b M^2}{C^2 H^3} \cdot \frac{C^2 H^2}{M(b + C H^2)} = \frac{b M}{H(b + C H^2)}$$

ここで $M = CH/T$ を代入すると，

$$\chi_s = \frac{b (CH/T)}{H (b + C H^2)} = \frac{C}{T} \frac{b}{b + C H^2}$$

となる．

### まとめ

- $C_H = \frac{b + CH^2}{T^2}$
- $C_M = \frac{b}{T^2}$
- $\chi_s = \frac{C}{T} \frac{b}{b + CH^2}$

## 解説

この問題は，磁性体の熱力学的な性質，特に「磁場一定」と「磁化一定」という異なる条件下での熱容量の違い，および断熱過程における磁化率（断熱磁化率）を求めるものである．

1.  **熱容量の定義**:
  熱容量はエントロピーの温度変化を $T$ で割ったもの（ $C = T \frac{\partial S}{\partial T}$ ）である．
2.  **磁化一定 ( $C_M$ ) vs 磁場一定 ( $C_H$ )**:
    *   磁化 $M$ を一定に保つことは，系の内部状態を制限することになる．
    *   磁場 $H$ を一定に保つことは，外部から磁場を制御することを意味する．
    *   常磁性体の場合，磁場を一定に保つと，温度変化に伴って磁化 $M$ も変化するため，磁化一定の場合よりも熱容量が大きくなる（ $C_H > C_M$ ）．
3.  **断熱磁化率 ( $\chi_s$ )**:
    *   断熱過程ではエントロピーが変化しない．
    *   磁場を変化させたときに，温度変化を伴いながらもエントロピーを一定に保つように磁化がどう変化するかを示している．
    *   これは，磁気冷却（磁気熱量効果）などの技術において非常に重要な指標となる．

解答プロセスでは，自由エネルギー $F$ を媒介としてエントロピー $S$ を導出し，そこから各熱力学量を計算している．
