# 演習問題【3-B-25】

## 解答

キュリーの法則に従う常磁性体について，

```math
\chi_T=\frac{C}{T},\qquad M=\chi_T H=\frac{CH}{T}
```

である．
ここで $C$ は正の定数である．
また，磁化 $M=0$ のときの熱容量は

```math
C_{M=0}=\frac{b}{T^2}
```

と与えられている．
以下では，この条件からエントロピーと自由エネルギーを求め，各熱力学量を導出する．

### 1．エントロピーと自由エネルギー

熱容量の定義より，

```math
C_{M=0}=T\left(\frac{\partial S}{\partial T}\right)_{M=0}
=\frac{b}{T^2}
```

である．
したがって，

```math
\left(\frac{\partial S(T,0)}{\partial T}\right)
=\frac{b}{T^3}
```

となる．
これを温度 $T$ について積分すると，

```math
S(T,0)=-\frac{b}{2T^2}+B
```

を得る．
ここで $B$ は積分定数である．

磁化を自然変数とするヘルムホルツ自由エネルギー $F(T,M)$ について，

```math
dF=-S\,dT+H\,dM
```

が成り立つ．
特に $M=0$ では，

```math
\frac{dF(T,0)}{dT}=-S(T,0)
=\frac{b}{2T^2}-B
```

である．
これを積分すると，

```math
F(T,0)=A-BT-\frac{b}{2T}
```

を得る．
ここで $A$ も積分定数である．

### 2．自由エネルギー $F(T,M)$ の導出

キュリーの法則

```math
M=\frac{CH}{T}
```

より，

```math
H=\frac{TM}{C}
```

である．
自由エネルギーの微分関係

```math
dF=-S\,dT+H\,dM
```

から，

```math
\left(\frac{\partial F}{\partial M}\right)_T=H
=\frac{TM}{C}
```

となる．
これを $M$ について積分し，積分定数を $F(T,0)$ と定めると，

```math
F(T,M)=F(T,0)+\int_0^M\frac{TM'}{C}\,dM'
```

である．
よって，

```math
F(T,M)=F(T,0)+\frac{TM^2}{2C}
```

となる．
先ほど求めた $F(T,0)$ を代入すれば，

```math
\boxed{
F(T,M)=A-BT-\frac{b}{2T}+\frac{TM^2}{2C}
}
```

を得る．

### 3．磁化一定の熱容量 $C_M$

エントロピーは自由エネルギーから

```math
S(T,M)=-\left(\frac{\partial F}{\partial T}\right)_M
```

と求められる．
したがって，

```math
S(T,M)=B-\frac{b}{2T^2}-\frac{M^2}{2C}
```

である．

磁化 $M$ を一定に保ったときの熱容量は，

```math
C_M=T\left(\frac{\partial S}{\partial T}\right)_M
```

で定義される．
上式を $T$ で偏微分すると，

```math
\left(\frac{\partial S}{\partial T}\right)_M
=\frac{b}{T^3}
```

であるから，

```math
\boxed{
C_M=\frac{b}{T^2}
}
```

となる．

### 4．磁場一定の熱容量 $C_H$

キュリーの法則 $M=CH/T$ をエントロピーの式に代入すると，

```math
\begin{aligned}
S(T,H)
&=B-\frac{b}{2T^2}
-\frac{1}{2C}\left(\frac{CH}{T}\right)^2\\
&=B-\frac{b+CH^2}{2T^2}
\end{aligned}
```

となる．

磁場 $H$ を一定に保ったときの熱容量は，

```math
C_H=T\left(\frac{\partial S}{\partial T}\right)_H
```

である．
ここでは $b+CH^2$ は温度に依存しないため，

```math
\left(\frac{\partial S}{\partial T}\right)_H
=\frac{b+CH^2}{T^3}
```

となる．
したがって，

```math
\boxed{
C_H=\frac{b+CH^2}{T^2}
}
```

を得る．

### 5．断熱磁化率 $\chi_s(H_0)$

断熱過程ではエントロピーが一定であるため，

```math
dS=0
```

である．
エントロピーを $S(H,M)$ と表すと，

```math
dS=
\left(\frac{\partial S}{\partial H}\right)_M dH
+\left(\frac{\partial S}{\partial M}\right)_H dM=0
```

となる．
したがって，

```math
\chi_s
=\left(\frac{\partial M}{\partial H}\right)_S
=-\frac{(\partial S/\partial H)_M}
{(\partial S/\partial M)_H}
```

である．

先に求めた

```math
S(T,M)=B-\frac{b}{2T^2}-\frac{M^2}{2C}
```

に $1/T=M/(CH)$ を代入すると，

```math
S(H,M)=B-\frac{bM^2}{2C^2H^2}-\frac{M^2}{2C}
```

を得る．
これをそれぞれ $H$ ， $M$ で偏微分する．

まず， $M$ を一定に保つと，

```math
\left(\frac{\partial S}{\partial H}\right)_M
=\frac{bM^2}{C^2H^3}
```

である．
次に， $H$ を一定に保つと，

```math
\left(\frac{\partial S}{\partial M}\right)_H
=-\frac{bM}{C^2H^2}-\frac{M}{C}
```

となる．
よって，

```math
\begin{aligned}
\chi_s
&=-\frac{\dfrac{bM^2}{C^2H^3}}
{-\dfrac{bM}{C^2H^2}-\dfrac{M}{C}}\\
&=\frac{bM}{H(b+CH^2)}
\end{aligned}
```

である．
さらに $M=CH/T$ を代入すると，

```math
\chi_s=\frac{b(CH/T)}{H(b+CH^2)}
```

となる．
したがって，磁場 $H=H_0$ における断熱磁化率は，

```math
\boxed{
\chi_s(H_0)=\frac{C}{T}\frac{b}{b+CH_0^2}
}
```

である．

### 結果

求める熱容量と断熱磁化率は，

```math
\boxed{
C_M=\frac{b}{T^2}
}
```

```math
\boxed{
C_H=\frac{b+CH_0^2}{T^2}
}
```

```math
\boxed{
\chi_s(H_0)=\frac{C}{T}\frac{b}{b+CH_0^2}
}
```

である．
