# 演習問題【3-B-33】

## 解答

### 1. 熱力学関数 $J(T, V, \mu)$ の決定

与えられた単一成分の理想気体の化学ポテンシャル $\mu$ の式は以下の通りである：

$$\mu = \phi(T) + kT \log \left( \frac{p}{p_0(T)} \right) \quad \cdots (1)$$

ここで， $p$ は圧力 ， $k$ はボルツマン定数 ， $T$ は温度 ， $p_0(T)$ は基準圧力である．

この式を圧力 $p$ について解く．

$$\frac{\mu - \phi(T)}{kT} = \log \left( \frac{p}{p_0(T)} \right)$$

$$\frac{p}{p_0(T)} = \exp \left( \frac{\mu - \phi(T)}{kT} \right)$$

$$p = p_0(T) \exp \left( \frac{\mu - \phi(T)}{kT} \right) \quad \cdots (2)$$

理想気体の状態方程式 $pV = NkT$ より，圧力 $p$ は次のように書ける：

$$p = \frac{NkT}{V} \quad \cdots (3)$$

熱力学関数 $J(T, V, \mu)$ は，グランドポテンシャル（大正準ポテンシャル）であり， $\Omega = -pV$ で定義される．
式 (2) を $J = -pV$ に代入すると，

$$J(T, V, \mu) = -p_0(T) V \exp \left( \frac{\mu - \phi(T)}{kT} \right) \quad \cdots (4)$$

となり，求める $J(T, V, \mu)$ の形が得られる．

### 2. 関係式の検証

グランドポテンシャルの微分に関する関係式 (3.5) は以下の通りである：

$$\left( \frac{\partial J}{\partial \mu} \right)_{T,V} = -N, \quad \left( \frac{\partial J}{\partial V} \right)_{T,\mu} = -p, \quad \left( \frac{\partial J}{\partial T} \right)_{V,\mu} = -S$$

これらが式 (4) から導かれることを検証する．

#### (i) $\mu$ による偏微分

式 (4) を $\mu$ で偏微分する．
指数関数の微分 $\frac{d}{dx} e^{ax} = a e^{ax}$ を用いる．

$$\left( \frac{\partial J}{\partial \mu} \right)_{T,V} = -p_0 V \cdot \frac{\partial}{\partial \mu} \left[ \exp \left( \frac{\mu - \phi(T)}{kT} \right) \right]$$

$$= -p_0 V \cdot \frac{1}{kT} \exp \left( \frac{\mu - \phi(T)}{kT} \right)$$

ここで，式 (2) より $p = p_0 \exp \left( \frac{\mu - \phi(T)}{kT} \right)$ であるから，

$$\left( \frac{\partial J}{\partial \mu} \right)_{T,V} = -\frac{pV}{kT}$$

式 (3) より $pV = NkT$ なので，

$$\left( \frac{\partial J}{\partial \mu} \right)_{T,V} = -\frac{NkT}{kT} = -N$$

となり，第1の関係式が検証された．

#### (ii) $V$ による偏微分

式 (4) を $V$ で偏微分する．
$V$ は式の1次式であるため，

$$\left( \frac{\partial J}{\partial V} \right)_{T,\mu} = -p_0 \exp \left( \frac{\mu - \phi(T)}{kT} \right)$$

式 (2) より，これはまさに圧力 $p$ であるから，

$$\left( \frac{\partial J}{\partial V} \right)_{T,\mu} = -p$$

となり，第2の関係式が検証された．

#### (iii) $T$ による偏微分

式 (4) を $T$ で偏微分する．
積の微分公式 $\frac{d}{dx}(fg) = f'g + fg'$ を用いる．

$$\left( \frac{\partial J}{\partial T} \right)_{V,\mu} = -V \left[ \frac{\partial p_0}{\partial T} e^{(\mu-\phi)/kT} + p_0 \frac{\partial}{\partial T} \left( e^{(\mu-\phi)/kT} \right) \right]$$

指数部分の微分を行う：

$$\frac{\partial}{\partial T} \left( \frac{\mu - \phi(T)}{kT} \right) = \frac{1}{k} \frac{\partial}{\partial T} \left( \frac{\mu}{T} - \frac{\phi(T)}{T} \right)$$

$$= \frac{1}{k} \left[ -\frac{\mu}{T^2} - \frac{\phi'(T)T - \phi(T)}{T^2} \right]$$

$$= \frac{1}{k} \left[ -\frac{\mu}{T^2} - \frac{\phi'(T)}{T} + \frac{\phi(T)}{T^2} \right]$$

$$= -\frac{1}{kT} \left[ \frac{\mu - \phi(T)}{T} + \phi'(T) \right]$$

これを用いて，全体の式を整理すると，

```math
\left( \frac{\partial J}{\partial T} \right)_{V,\mu} = -p_0 V e^{(\mu-\phi)/kT} \left\{ \frac{1}{p_0} \frac{\partial p_0}{\partial T} - \frac{1}{kT} \left( \frac{\mu - \phi(T)}{T} + \phi'(T) \right) \right\}
```

```math
= -p V \left\{ \frac{\partial \ln p_0}{\partial T} - \frac{\mu - \phi(T)}{kT^2} - \frac{\phi'(T)}{kT} \right\}
```

```math
= -NkT \left\{ \frac{\partial \ln p_0}{\partial T} - \frac{\mu - \phi(T)}{kT^2} - \frac{\phi'(T)}{kT} \right\}
```

$$= -N \left( kT \frac{\partial \ln p_0}{\partial T} - \frac{\mu - \phi(T)}{T} - \phi'(T) \right) \quad \cdots (5)$$

一方，式 (1) を用いて，圧力を一定に保ったときの化学ポテンシャルの温度変化 $\left( \frac{\partial \mu}{\partial T} \right)_p$ を計算する．

$$\mu = \phi(T) + kT \ln(p/p_0(T))$$

$$\left( \frac{\partial \mu}{\partial T} \right)_p = \phi'(T) + k \ln(p/p_0(T)) + kT \frac{\partial}{\partial T} \ln(p/p_0(T))$$

ここで $\ln(p/p_0(T)) = \ln p - \ln p_0(T)$ であり， $p$ は一定なので $\frac{\partial \ln p}{\partial T} = 0$ である．

$$\left( \frac{\partial \mu}{\partial T} \right)_p = \phi'(T) + k \ln(p/p_0(T)) - kT \frac{\partial \ln p_0}{\partial T}$$

式 (1) より $k \ln(p/p_0(T)) = \frac{\mu - \phi(T)}{T}$ であるから，

$$\left( \frac{\partial \mu}{\partial T} \right)_p = \phi'(T) + \frac{\mu - \phi(T)}{T} - kT \frac{\partial \ln p_0}{\partial T}$$

$$= - \left( kT \frac{\partial \ln p_0}{\partial T} - \phi'(T) - \frac{\mu - \phi(T)}{T} \right)$$

これと式 (5) を比較すると，

$$\left( \frac{\partial J}{\partial T} \right)_{V,\mu} = N \left( \frac{\partial \mu}{\partial T} \right)_p$$

となる．
グランドポテンシャルの定義より $\left( \frac{\partial J}{\partial T} \right)_{V,\mu} = -S$ であるから，

$$\left( \frac{\partial J}{\partial T} \right)_{V,\mu} = N \left( \frac{\partial \mu}{\partial T} \right)_p = -S$$

となり，第3の関係式も検証された．

## 解説

本問題は，グランドポテンシャル（大正準ポテンシャル） $\Omega = -pV$ の熱力学的な性質を，理想気体の化学ポテンシャルの表現を用いて検証するものである．

### 1.  グランドポテンシャルの役割

グランドポテンシャルは，温度 $T$ ，体積 $V$ ，化学ポテンシャル $\mu$ を独立変数とする関数である．
統計力学における大正準アンサンブル（グランドカノニカルアンサンブル）の熱力学的ポテンシャルに相当する．

### 2.  微分関係の意味

グランドポテンシャルの全微分 $dJ = -S dT - p dV - N d\mu$ は，各変数が変化したときにポテンシャルがどのように変化するかを表している．
-   $(\frac{\partial J}{\partial T})_{V,\mu} = -S$ : 温度変化がエントロピーに関連していること．
-   $(\frac{\partial J}{\partial V})_{T,\mu} = -p$ : 体積変化が圧力に関連していること．
-   $(\frac{\partial J}{\partial \mu})_{T,V} = -N$ : 化学ポテンシャルの変化が粒子数に関連していること．

### 3.  計算のポイント

今回の計算では，化学ポテンシャル $\mu$ が圧力 $p$ を含む形で与えられているため， $J$ を $\mu$ の関数として書き直す際，指数関数が現れる．
偏微分の際，どの変数を固定（定数として扱う）するかを正確に把握することが重要である．
特に $T$ による微分では，指数関数の肩にある $\frac{\mu-\phi}{kT}$ の微分に注意が必要である．
