# 演習問題【3-B-33】

## 解答

### 1．熱力学関数 $J(T,V,\mu)$ を求める

単一成分の理想気体の化学ポテンシャルは，

```math
\mu=\phi(T)+kT\log\frac{p}{p_0(T)}
\tag{1}
```

と与えられている．
ここで， $T$ は温度， $p$ は圧力， $V$ は体積， $N$ は粒子数， $k$ はボルツマン定数であり， $\phi(T)$ と $p_0(T)$ は温度だけの関数である．

まず，式 (1) を圧力 $p$ について解くと，

```math
\log\frac{p}{p_0(T)}
=\frac{\mu-\phi(T)}{kT}
```

であるから，

```math
p=p_0(T)\exp\left(\frac{\mu-\phi(T)}{kT}\right)
\tag{2}
```

となる．

理想気体の状態方程式は

```math
pV=NkT
```

である．
また，熱力学関数 $J$ はグランドポテンシャルであり，

```math
J=U-TS-\mu N=-pV
\tag{3}
```

と表される．
ここで， $U$ は内部エネルギー， $S$ はエントロピーである．

式 (2) を式 (3) に代入すると，

```math
\boxed{
J(T,V,\mu)
=-p_0(T)V
\exp\left(\frac{\mu-\phi(T)}{kT}\right)
}
\tag{4}
```

を得る．
これが求める熱力学関数である．

### 2．関係式 (3.5) の検証

グランドポテンシャルの全微分は，

```math
dJ=-S\,dT-p\,dV-N\,d\mu
\tag{5}
```

である．
したがって，検証すべき関係式は，

```math
\left(\frac{\partial J}{\partial T}\right)_{V,\mu}=-S,
\qquad
\left(\frac{\partial J}{\partial V}\right)_{T,\mu}=-p,
\qquad
\left(\frac{\partial J}{\partial\mu}\right)_{T,V}=-N
\tag{6}
```

である．
以下，式 (4) からそれぞれを確かめる．

#### (i) 化学ポテンシャル \(\mu\) による偏微分

式 (4) を $\mu$ で偏微分する．
このとき， $T,V$ は一定であるため， $p_0(T)$ と $\phi(T)$ は定数として扱う．

```math
\begin{aligned}
\left(\frac{\partial J}{\partial\mu}\right)_{T,V}
&=-p_0V
\exp\left(\frac{\mu-\phi}{kT}\right)
\frac{1}{kT}\\
&=-\frac{pV}{kT}.
\end{aligned}
```

ここで，式 (2) を用いた．さらに，理想気体の状態方程式 $pV=NkT$ より，

```math
\boxed{
\left(\frac{\partial J}{\partial\mu}\right)_{T,V}
=-N
}
\tag{7}
```

となる．
第1の関係式が確認された．

#### (ii) 体積 $V$ による偏微分

式 (4) は $V$ に比例するため， $T,\mu$ を一定に保って微分すると，

```math
\begin{aligned}
\left(\frac{\partial J}{\partial V}\right)_{T,\mu}
&=-p_0(T)\exp\left(\frac{\mu-\phi(T)}{kT}\right)\\
&=-p.
\end{aligned}
```

最後の等号では，式 (2) を用いた．したがって，

```math
\boxed{
\left(\frac{\partial J}{\partial V}\right)_{T,\mu}
=-p
}
\tag{8}
```

となり，第2の関係式も確認された．

#### (iii) 温度 $T$ による偏微分

最後に， $V,\mu$ を一定に保って式 (4) を温度 $T$ で偏微分する．
このとき， $\phi(T)$ と $p_0(T)$ は温度に依存するため，それぞれの微分を考慮する必要がある．

計算を簡潔にするため，

```math
q(T)=\frac{\mu-\phi(T)}{kT}
```

とおく．
$\mu$ は一定であるから，

```math
\begin{aligned}
\frac{dq}{dT}
&=\frac{1}{k}\frac{d}{dT}
\left(\frac{\mu-\phi(T)}{T}\right)\\
&=-\frac{\phi'(T)}{kT}
-\frac{\mu-\phi(T)}{kT^2}.
\end{aligned}
\tag{9}
```

ここで， $\phi'(T)=d\phi/dT$ である．

式 (4) を $T$ で微分し，指数関数の微分公式を用いると，

```math
\begin{aligned}
\left(\frac{\partial J}{\partial T}\right)_{V,\mu}
={}&-p_0V e^q
\left[
\frac{1}{p_0}\frac{dp_0}{dT}
+\frac{dq}{dT}
\right]\\
={}&-pV
\left[
\frac{d\log p_0}{dT}
-\frac{\phi'(T)}{kT}
-\frac{\mu-\phi(T)}{kT^2}
\right].
\end{aligned}
```

ここで $pV=NkT$ を用いると，

```math
\boxed{
\left(\frac{\partial J}{\partial T}\right)_{V,\mu}
=-N\left[
kT\frac{d\log p_0}{dT}
-\phi'(T)
-\frac{\mu-\phi(T)}{T}
\right]
}
\tag{10}
```

を得る．

一方，式 (1) を温度 $T$ で微分する．
このとき圧力 $p$ を一定に保つと，

```math
\begin{aligned}
\left(\frac{\partial\mu}{\partial T}\right)_p
&=\phi'(T)
+k\log\frac{p}{p_0(T)}
-kT\frac{d\log p_0}{dT}.
\end{aligned}
```

式 (1) から，

```math
k\log\frac{p}{p_0(T)}
=\frac{\mu-\phi(T)}{T}
```

であるため，

```math
\left(\frac{\partial\mu}{\partial T}\right)_p
=\phi'(T)+\frac{\mu-\phi(T)}{T}
-kT\frac{d\log p_0}{dT}.
\tag{11}
```

式 (10) と式 (11) を比較すると，

```math
\boxed{
\left(\frac{\partial J}{\partial T}\right)_{V,\mu}
=N\left(\frac{\partial\mu}{\partial T}\right)_p
}
\tag{12}
```

となる．

さらに，単一成分の系では，化学ポテンシャルの微分関係

```math
d\mu=-\frac{S}{N}\,dT+\frac{V}{N}\,dp
\tag{13}
```

が成り立つ．
これは， $dU=T\,dS-p\,dV+\mu\,dN$ と $U-TS-\mu N=-pV$ から得られる関係である．
圧力を一定にすると $dp=0$ であるため，

```math
\left(\frac{\partial\mu}{\partial T}\right)_p
=-\frac{S}{N}
\tag{14}
```

となる．
これを式 (12) に代入すれば，

```math
\boxed{
\left(\frac{\partial J}{\partial T}\right)_{V,\mu}
=N\left(\frac{\partial\mu}{\partial T}\right)_p
=-S
}
\tag{15}
```

を得る．
これで第3の関係式も確認された．

### 3．結論

与えられた化学ポテンシャルの式から，グランドポテンシャルは

```math
\boxed{
J(T,V,\mu)
=-p_0(T)V
\exp\left(\frac{\mu-\phi(T)}{kT}\right)
}
```

と求められる．
この関数をそれぞれ $\mu,V,T$ で偏微分することにより，

```math
\boxed{
\left(\frac{\partial J}{\partial\mu}\right)_{T,V}=-N,\qquad
\left(\frac{\partial J}{\partial V}\right)_{T,\mu}=-p,\qquad
\left(\frac{\partial J}{\partial T}\right)_{V,\mu}=-S
}
```

が成立することを確認した．
したがって，関係式 (3.5) が検証されたのである．
