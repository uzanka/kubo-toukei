# 演習問題【3-A-10】

## 解答

準静的断熱膨張と Joule–Thomson 過程における温度変化を，それぞれの過程で一定に保たれる状態量に着目して比較する．

### （1）準静的断熱膨張における温度低下

準静的断熱膨張は，気体にかける外圧をゆっくりと低下させることで実現される．
この過程では，気体は各瞬間に平衡状態にあり，熱の授受がないため，エントロピー $S$ は一定である．
したがって，

```math
dS=0
```

である．

エントロピーの全微分は，温度 $T$ と圧力 $p$ を用いて

```math
dS=\left(\frac{\partial S}{\partial T}\right)_p dT
+\left(\frac{\partial S}{\partial p}\right)_T dp
```

と表される．
ここで，定圧熱容量 $C_p$ の定義と Maxwell の関係式より，

```math
\left(\frac{\partial S}{\partial T}\right)_p
=\frac{C_p}{T},
\qquad
\left(\frac{\partial S}{\partial p}\right)_T
=-\left(\frac{\partial V}{\partial T}\right)_p
```

が成り立つ．
したがって，

```math
dS=\frac{C_p}{T}dT
-\left(\frac{\partial V}{\partial T}\right)_p dp
```

である．

準静的断熱膨張では $dS=0$ であるから，

```math
\frac{C_p}{T}dT
=\left(\frac{\partial V}{\partial T}\right)_p dp
```

となる．
これを $dp$ について解くと，

```math
\left(\frac{\partial T}{\partial p}\right)_S
=\frac{T}{C_p}
\left(\frac{\partial V}{\partial T}\right)_p
```

を得る．

ここで，定圧体膨張係数 $\alpha$ を

```math
\alpha=\frac{1}{V}
\left(\frac{\partial V}{\partial T}\right)_p
```

と定義すると，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=V\alpha
```

であるから，

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_S
=\frac{TV\alpha}{C_p}
}
```

となる．

絶対温度 $T$ ，体積 $V$ ，定圧熱容量 $C_p$ はいずれも正であり，問題の条件より $\alpha>0$ である．
したがって，

```math
\left(\frac{\partial T}{\partial p}\right)_S>0
```

が成り立つ．
すなわち，エントロピー一定のもとでは，圧力が低下すると温度も低下する．
よって，準静的断熱膨張では必ず温度低下が起こるのである．

### （2）Joule–Thomson 過程における温度変化

Joule–Thomson 過程は，多孔質の栓などを通して気体を高圧側から低圧側へ流す断熱絞り過程である．
この過程では，栓の前後で運動エネルギーおよび位置エネルギーの変化を無視でき，軸仕事の授受もないとすると，定常流のエネルギー保存則よりエンタルピー $H$ が一定となる．
したがって，

```math
dH=0
```

である．

エンタルピーの微分は，定義 $H=U+pV$ と熱力学の基本関係式から，

```math
dH=T\,dS+V\,dp
```

と表される．
また，前半で用いたエントロピーの微分式

```math
dS=\frac{C_p}{T}dT
-\left(\frac{\partial V}{\partial T}\right)_p dp
```

を代入すると，

```math
dH=C_p\,dT+
\left[
V-T\left(\frac{\partial V}{\partial T}\right)_p
\right]dp
```

となる．

Joule–Thomson 過程では $dH=0$ であるから，

```math
C_p\,dT
=-\left[
V-T\left(\frac{\partial V}{\partial T}\right)_p
\right]dp
```

である．
したがって，

```math
\left(\frac{\partial T}{\partial p}\right)_H
=\frac{T\left(\frac{\partial V}{\partial T}\right)_p-V}{C_p}
```

を得る．
ここで $(\partial V/\partial T)_p=V\alpha$ を代入すると，

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_H
=\frac{(T\alpha-1)V}{C_p}
}
```

となる．

この式から，Joule–Thomson 過程における温度変化の符号は $T\alpha-1$ に依存することがわかる．
すなわち， $T\alpha>1$ ならば圧力低下によって温度が低下し， $T\alpha<1$ ならば温度が上昇する．
したがって，Joule–Thomson 過程では必ずしも温度低下が起こるとは限らないのである．

### （3）両過程における温度変化の比較

同じ初期状態から，同じ微小な圧力低下 $\Delta p<0$ が起こる場合を考える．
準静的断熱膨張による温度変化を $\Delta T_S$ ，Joule–Thomson 過程による温度変化を $\Delta T_H$ とする．
微小変化に対しては，

```math
\Delta T_S
=\left(\frac{\partial T}{\partial p}\right)_S\Delta p
```

および

```math
\Delta T_H
=\left(\frac{\partial T}{\partial p}\right)_H\Delta p
```

と表される．

したがって，両者の温度変化の差は，

```math
\begin{aligned}
\Delta T_S-\Delta T_H
&=\left[
\left(\frac{\partial T}{\partial p}\right)_S
-\left(\frac{\partial T}{\partial p}\right)_H
\right]\Delta p\\
&=\left[
\frac{TV\alpha}{C_p}
-\frac{(T\alpha-1)V}{C_p}
\right]\Delta p\\
&=\frac{V}{C_p}\Delta p
\end{aligned}
```

となる．

ここで， $V>0$ ， $C_p>0$ ， $\Delta p<0$ であるから，

```math
\boxed{
\Delta T_S-\Delta T_H<0
}
```

が成り立つ．
すなわち，

```math
\Delta T_S<\Delta T_H
```

である．
これを温度低下の大きさで表すと，

```math
\boxed{
-\Delta T_S>-\Delta T_H
}
```

となる．

以上より，同じ初期状態から同じ微小な圧力低下が起こる場合，準静的断熱膨張による温度低下は，Joule–Thomson 過程による温度低下よりも必ず大きい．
なお，Joule–Thomson 過程で温度が上昇する場合にも，上の不等式は成立し，準静的断熱膨張の方が最終温度は低くなるのである．
