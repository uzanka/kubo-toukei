# 演習問題【3-A-10】

## 解答

準静的断熱膨張と Joule–Thomson 過程について，それぞれの温度変化を熱力学的に導出し，比較する．

なお，本問では，「準静的断熱膨張」は内部可逆な準静的断熱膨張を意味するものと解釈する．
したがって，この過程は等エントロピー過程である．

以下では，一定組成の安定な単一相の気体を考える．
温度 $T$ ，圧力 $p$ ，モル体積 $v$ および定圧モル熱容量 $c_p$ は正とする．
また，定圧体膨張係数 $\alpha$ は，考える状態範囲全体で正であるとする．

Joule–Thomson 過程については，定常流，断熱，軸仕事なし，および入口と出口の運動エネルギー・位置エネルギーの変化を無視できる絞り過程を考える．

### （1）準静的断熱膨張における温度変化

内部可逆な断熱過程では，熱の授受がなく，エントロピー生成もないため，エントロピーは一定である．
したがって，

```math
ds=0
```

となる．
ここで， $s$ はモルエントロピーである．

エントロピーの全微分は，

```math
ds=
\left(\frac{\partial s}{\partial T}\right)_p dT
+
\left(\frac{\partial s}{\partial p}\right)_T dp
```

である．

定圧モル熱容量の定義から，

```math
\left(\frac{\partial s}{\partial T}\right)_p
=\frac{c_p}{T}
```

が成り立つ．

また，Gibbs 自由エネルギーのモル量を $g$ とすると，

```math
dg=-s\,dT+v\,dp
```

である．
これから得られる Maxwell の関係式より，

```math
\left(\frac{\partial s}{\partial p}\right)_T
=
-\left(\frac{\partial v}{\partial T}\right)_p
```

となる．

したがって，

```math
ds=
\frac{c_p}{T}dT
-
\left(\frac{\partial v}{\partial T}\right)_p dp
```

である．

準静的断熱膨張では $ds=0$ なので，

```math
\frac{c_p}{T}dT
=
\left(\frac{\partial v}{\partial T}\right)_p dp
```

となる．
これを整理すると，

```math
\left(\frac{\partial T}{\partial p}\right)_s
=
\frac{T}{c_p}
\left(\frac{\partial v}{\partial T}\right)_p
```

を得る．

ここで，定圧体膨張係数を

```math
\alpha=
\frac{1}{v}
\left(\frac{\partial v}{\partial T}\right)_p
```

と定義すると，

```math
\left(\frac{\partial v}{\partial T}\right)_p
=v\alpha
```

であるから，

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_s
=
\frac{Tv\alpha}{c_p}
}
\tag{1}
```

となる．

問題の条件および安定な平衡状態の仮定より，

```math
T>0,\qquad v>0,\qquad c_p>0,\qquad \alpha>0
```

であるため，

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_s>0
}
```

が成り立つ．

したがって，等エントロピー経路に沿って圧力が低下すると，温度も低下する．

実際，初期圧力を $p_0$ ，最終圧力を $p_1$ とし，

```math
p_1<p_0
```

とすると，

```math
T_S(p_1)-T_0
=
\int_{p_0}^{p_1}
\left(\frac{\partial T}{\partial p}\right)_s dp
<0
```

である．
ここで， $T_S(p)$ は等エントロピー経路上の温度であり，積分区間全体で式（1）の被積分関数は正である．

よって，

```math
\boxed{
T_S(p_1)<T_0
}
\tag{2}
```

となる．

したがって，準静的かつ内部可逆な断熱膨張では必ず温度が低下する．

### （2）Joule–Thomson 過程における温度変化

Joule–Thomson 過程は，多孔質の栓などを通して気体を高圧側から低圧側へ流す断熱絞り過程である．

定常流のエネルギー保存則を考える．
この過程では，熱の授受がなく，軸仕事もなく，入口と出口の運動エネルギーおよび位置エネルギーの変化を無視できるため，入口と出口のモルエンタルピーは等しくなる．

したがって，

```math
dh=0
```

である．

一方，モルエンタルピーの定義

```math
h=u+pv
```

と熱力学の基本関係式

```math
du=T\,ds-p\,dv
```

より，

```math
\begin{aligned}
dh
&=du+p\,dv+v\,dp\\
&=T\,ds+v\,dp
\end{aligned}
```

となる．

したがって，

```math
dh=T\,ds+v\,dp
```

である．

ここに，（1）で求めたエントロピーの微分式

```math
ds=
\frac{c_p}{T}dT
-
\left(\frac{\partial v}{\partial T}\right)_p dp
```

を代入すると，

```math
dh=
c_p\,dT+
\left[
v-T\left(\frac{\partial v}{\partial T}\right)_p
\right]dp
```

となる．

Joule–Thomson 過程ではエンタルピーが一定なので，

```math
c_p\,dT
=
\left[
T\left(\frac{\partial v}{\partial T}\right)_p-v
\right]dp
```

である．

したがって，

```math
\left(\frac{\partial T}{\partial p}\right)_h
=
\frac{
T\left(\frac{\partial v}{\partial T}\right)_p-v
}{c_p}
```

となる．

ここで，

```math
\left(\frac{\partial v}{\partial T}\right)_p=v\alpha
```

を代入すると，

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_h
=
\frac{v(T\alpha-1)}{c_p}
}
\tag{3}
```

を得る．

この式から，Joule–Thomson 過程における温度変化の符号は $T\alpha-1$ に依存することがわかる．

```math
T\alpha>1
```

ならば，圧力低下によって温度が低下する．

```math
T\alpha<1
```

ならば，圧力低下によって温度が上昇する．

```math
T\alpha=1
```

ならば，その状態における一次の温度変化はゼロである．

したがって，

```math
\boxed{\alpha>0}
```

という条件だけでは，Joule–Thomson 過程で温度低下が必ず起こるとはいえない．

有限の圧力低下 $p_0\to p_1$ に対するJoule–Thomson過程の温度変化を考える．
等エンタルピー状態線に沿って，

```math
T_H(p_1)-T_0
=
\int_{p_0}^{p_1}
\left(\frac{\partial T}{\partial p}\right)_h dp
```

であるから，

```math
\boxed{
T_H(p_1)-T_0
=
\int_{p_0}^{p_1}
\frac{v(T_H(p),p)
[T_H(p)\alpha(T_H(p),p)-1]}
{c_p(T_H(p),p)}
\,dp
}
\tag{4}
```

となる．

ここで， $T_H(p)$ は等エンタルピー状態線上の温度である．

したがって，Joule–Thomson 過程で正味の温度低下が起こるための必要十分条件は，

```math
\boxed{
\int_{p_0}^{p_1}
\left(\frac{\partial T}{\partial p}\right)_h dp<0
}
\tag{5}
```

である．

なお，経路全体で

```math
T\alpha>1
```

が成立すれば，式（5）は満たされる．
これはJoule–Thomson冷却が起こるための十分条件である．
ただし，経路上で $T\alpha-1$ の符号が変化する場合でも，積分全体が負であれば正味の冷却は起こるため，経路全体で $T\alpha>1$ であることは必要条件ではない．

### （3）両過程における温度変化の比較

同じ初期状態

```math
(T_0,p_0,h_0,s_0)
```

から出発し，同じ最終圧力

```math
p_1<p_0
```

に到達する2つの過程を考える．

準静的断熱膨張の最終温度を $T_S$ ，そのときのモルエンタルピーを $h_S$ とする．
また，Joule–Thomson 過程の最終温度を $T_H$ ，そのときのモルエンタルピーを $h_H$ とする．

まず，準静的断熱膨張では，

```math
ds=0
```

であるから，エンタルピーの微分式

```math
dh=T\,ds+v\,dp
```

より，

```math
dh=v\,dp
```

となる．

これを初期圧力 $p_0$ から最終圧力 $p_1$ まで積分すると，

```math
h_S-h_0
=
\int_{p_0}^{p_1}v_S(p)\,dp
```

となる．
ここで， $v_S(p)$ は等エントロピー経路上のモル体積である．

モル体積は正であり，

```math
p_1<p_0
```

なので，

```math
\int_{p_0}^{p_1}v_S(p)\,dp<0
```

である．
したがって，

```math
\boxed{
h_S<h_0
}
\tag{6}
```

が成立する．

一方，Joule–Thomson 過程ではモルエンタルピーが一定であるため，

```math
\boxed{
h_H=h_0
}
\tag{7}
```

である．

式（6），（7）より，

```math
\boxed{
h_S<h_H
}
\tag{8}
```

となる．

ここで，両過程の最終状態は同じ圧力 $p_1$ にあることに注意する．

定圧モル熱容量の定義から，

```math
c_p=
\left(\frac{\partial h}{\partial T}\right)_p
```

である．
また，両最終状態を結ぶ同一圧力 $p_1$ の単一相領域において $c_p>0$ であるため，この圧力ではモルエンタルピーは温度の増加関数である．

したがって，式（8）のエンタルピーの大小関係から，

```math
\boxed{
T_S<T_H
}
\tag{9}
```

が得られる．

両過程は同じ初期温度 $T_0$ から出発しているため，

```math
\begin{aligned}
(T_0-T_S)-(T_0-T_H)
&=T_H-T_S\\
&>0
\end{aligned}
```

となる．
したがって，

```math
\boxed{
T_0-T_S>T_0-T_H
}
\tag{10}
```

が成立する．

この不等式は，Joule–Thomson 過程で冷却が起こる場合には，2つの正の温度低下量について，

```math
\boxed{
\text{準静的断熱膨張による温度低下量}
>
\text{Joule–Thomson 過程による温度低下量}
}
```

を意味する．

実際にJoule–Thomson過程でも正味の温度低下が起こる場合には，

```math
T_H<T_0
```

である．
式（2），（9）と合わせると，

```math
\boxed{
T_S<T_H<T_0
}
```

となる．
よって，両方の温度低下量は正であり，式（10）の比較がそのまま成立する．

一方，Joule–Thomson 過程で温度上昇が起こる場合には，

```math
T_H>T_0>T_S
```

となり，Joule–Thomson 過程には正の温度低下量は存在しない．
この場合にも式（9）および式（10）の符号付き温度変化の比較は成立するが，2つの正の冷却量の比較とは解釈できない．

### 結論

準静的かつ内部可逆な断熱膨張では，

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_s
=
\frac{Tv\alpha}{c_p}>0
}
```

であり，圧力低下に伴って必ず温度が低下する．

Joule–Thomson 過程では，

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_h
=
\frac{v(T\alpha-1)}{c_p}
}
```

であり，温度変化の符号は $T\alpha-1$ に依存する．
したがって，定圧体膨張係数が正であることだけでは，Joule–Thomson 過程で冷却が起こるとは限らない．

しかし，同じ初期状態と同じ最終圧力について，準静的断熱膨張ではモルエンタルピーが低下するのに対し，Joule–Thomson 過程ではモルエンタルピーが一定である．
正の定圧モル熱容量のもとでは，

```math
\boxed{T_S<T_H}
```

が成立する．

したがって，Joule–Thomson 過程でも正味の温度低下が起こる場合には，

```math
\boxed{
T_0-T_S>T_0-T_H>0
}
```

となり，準静的断熱膨張による温度低下量の方が必ず大きい．

なお，問題文の条件 $\alpha>0$ だけでは，Joule–Thomson 過程での冷却までは保証されない．
そのため，「2つの正の温度低下量の比較」という意味で問題文を厳密に成立させるには，Joule–Thomson 過程でも正味の冷却が起こるという条件が必要である．
