# 演習問題【3-A-7】

## 解答

### 証明

問題文の「体積 $V$ が一定のとき」という条件のままでは，体積とともにエントロピーが増大するかどうかを論じることはできない．
そこで，解答例に従い，**温度 $T$ を一定に保ち，体積 $V$ を変化させたとき** にエントロピーが増大することを示す．

圧力 $p$ が絶対温度 $T$ に比例するという条件から，状態方程式は

```math
p=f(V)T
```

と書ける．
ここで， $f(V)$ は体積 $V$ のみに依存する関数である．

次に，Helmholtz 自由エネルギー $F=U-TS$ の全微分

```math
dF=-S\,dT-p\,dV
```

を考える．
$F$ は状態量であり，その混合偏微分の順序を交換できるため，

```math
\frac{\partial}{\partial V}
\left(\frac{\partial F}{\partial T}\right)_V
=
\frac{\partial}{\partial T}
\left(\frac{\partial F}{\partial V}\right)_T
```

が成り立つ．
ここで，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_V,
\qquad
p=-\left(\frac{\partial F}{\partial V}\right)_T
```

であるから，Maxwell の関係式

```math
\boxed{
\left(\frac{\partial S}{\partial V}\right)_T
=\left(\frac{\partial p}{\partial T}\right)_V
}
```

が得られる．

この関係式に状態方程式 $p=f(V)T$ を代入する．
体積 $V$ を一定に保って温度 $T$ について偏微分すると，

```math
\left(\frac{\partial p}{\partial T}\right)_V=f(V)
```

である．
また，状態方程式から

```math
f(V)=\frac{p}{T}
```

と表される．
したがって，

```math
\left(\frac{\partial S}{\partial V}\right)_T
=f(V)=\frac{p}{T}
```

となる．

通常の気体では，圧力 $p>0$ ，絶対温度 $T>0$ であるから，

```math
\boxed{
\left(\frac{\partial S}{\partial V}\right)_T
=\frac{p}{T}>0
}
```

が成立する．
よって，温度一定のもとでは，体積 $V$ の増加とともにエントロピー $S$ は単調に増大する．
以上で証明が完了した．
