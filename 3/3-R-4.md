# 例題【3-R-4】

## 解答

### 証明

内部エネルギー $U$ を温度 $T$ と体積 $V$ の関数 $U=U(V,T)$ とみなす．
また，状態方程式によって圧力 $p$ が $p=p(V,T)$ と表されるとする．

示すべきことは，

```math
\left(\frac{\partial U}{\partial V}\right)_T=0
\quad\Longrightarrow\quad
\left(\frac{\partial U}{\partial p}\right)_T=0
```

である．

#### 1．連鎖律による変数変換

温度 $T$ を一定に保つと，内部エネルギー $U$ の微小変化は

```math
dU=\left(\frac{\partial U}{\partial V}\right)_T dV
```

と表される．
一方， $U$ を圧力 $p$ と温度 $T$ の関数 $U=U(p,T)$ とみなせば，同じ微小変化は

```math
dU=\left(\frac{\partial U}{\partial p}\right)_T dp
```

とも表される．

したがって，温度一定のもとでは

```math
\left(\frac{\partial U}{\partial p}\right)_T dp
=
\left(\frac{\partial U}{\partial V}\right)_T dV
```

が成り立つ．
ここで， $(\partial p/\partial V)_T\neq0$ と仮定する．
この条件のもとでは，温度一定で圧力と体積を局所的に相互変換でき，

```math
\left(\frac{\partial V}{\partial p}\right)_T
=\frac{1}{(\partial p/\partial V)_T}
```

が成り立つ．
よって，

```math
\boxed{
\left(\frac{\partial U}{\partial p}\right)_T
=
\frac{(\partial U/\partial V)_T}
{(\partial p/\partial V)_T}
}
```

を得る．
これは，解答例に示された連鎖律による変数変換の式である．

#### 2．仮定を適用する

問題の仮定

```math
\left(\frac{\partial U}{\partial V}\right)_T=0
```

を上式に代入すると，

```math
\left(\frac{\partial U}{\partial p}\right)_T
=\frac{0}{(\partial p/\partial V)_T}=0
```

となる．

したがって，

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_T=0
\quad\Longrightarrow\quad
\left(\frac{\partial U}{\partial p}\right)_T=0
}
```

が示された．
ただし，この結論は $(\partial p/\partial V)_T\neq0$ であり，圧力と体積の間で局所的な変数変換が可能である領域について成立する．

### 補足説明

この証明の要点は， **温度を一定に保ったとき，圧力の変化を体積の変化に置き換えて考えること** である．
体積を変えても内部エネルギーが変化しないならば，圧力を変えた場合にも内部エネルギーは変化しない．
このことを数学的に表したものが，連鎖律による上記の関係式である．
