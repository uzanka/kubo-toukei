# 例題【3-R-4】

## 解答

### 1．証明に用いる追加仮定

内部エネルギーと圧力が，温度と体積の関数

```math
U=U(V,T),\qquad p=p(V,T)
```

として表され，対象とする状態の近傍で連続微分可能であるとする．

さらに，この証明では圧力を体積に代わる独立変数として局所的に用いるため，次の条件を仮定する．

```math
\boxed{
\left(\frac{\partial p}{\partial V}\right)_T\neq0
}
\tag{1}
```

この条件のもとでは，写像

```math
(V,T)\longmapsto(p(V,T),T)
```

のヤコビアンがゼロでないため，逆関数定理により，対象とする状態の近傍で体積を

```math
V=V(p,T)
```

と表すことができる．

なお，式（1）は，この証明で圧力と体積の間の微分可能な変数変換を行うための十分条件である．

### 2．連鎖律による証明

体積を圧力と温度の関数として表すと，内部エネルギーは

```math
U=U(V(p,T),T)
```

となる．

ここで，温度 $T$ を一定に保って圧力 $p$ で偏微分し，連鎖律を適用すると，

```math
\left(\frac{\partial U}{\partial p}\right)_T
=
\left(\frac{\partial U}{\partial V}\right)_T
\left(\frac{\partial V}{\partial p}\right)_T
\tag{2}
```

を得る．

一方，

```math
p=p(V(p,T),T)
```

を温度一定で圧力 $p$ に関して偏微分すると，

```math
1=
\left(\frac{\partial p}{\partial V}\right)_T
\left(\frac{\partial V}{\partial p}\right)_T
```

であるから，

```math
\left(\frac{\partial V}{\partial p}\right)_T
=
\frac{1}{
\left(\frac{\partial p}{\partial V}\right)_T
}
\tag{3}
```

となる．

式（3）を式（2）に代入すれば，

```math
\left(\frac{\partial U}{\partial p}\right)_T
=
\frac{
\left(\frac{\partial U}{\partial V}\right)_T
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
\tag{4}
```

を得る．

ここで，問題の仮定

```math
\left(\frac{\partial U}{\partial V}\right)_T=0
```

を式（4）に代入すると，式（1）によって分母はゼロではないため，

```math
\left(\frac{\partial U}{\partial p}\right)_T
=
\frac{0}{
\left(\frac{\partial p}{\partial V}\right)_T
}
=0
```

となる．
したがって，

```math
\boxed{
\left(\frac{\partial U}{\partial p}\right)_T=0
}
```

が示された．

### 3．追加仮定の物理的な意味と適用範囲

通常の機械的に安定な単一相の平衡状態では，等温圧縮率

```math
\kappa_T
=
-\frac{1}{V}
\left(\frac{\partial V}{\partial p}\right)_T
```

が有限かつ正である．
このとき，

```math
\left(\frac{\partial p}{\partial V}\right)_T
=
-\frac{1}{V\kappa_T}<0
```

となるため，式（1）の条件が満たされる．
したがって，通常の機械的に安定な状態では，上記の証明を適用できる．

ただし，臨界点などでは，

```math
\left(\frac{\partial p}{\partial V}\right)_T=0
```

となることがある．
そのような状態では，逆関数定理による局所的な変数変換を保証できず，上記の証明は適用できない．

実際，温度一定で

```math
p=p_0+(V-V_0)^3,\qquad
U=U_0+(V-V_0)^3
```

とすると， $V=V_0$ において，

```math
\left(\frac{\partial U}{\partial V}\right)_T=0
```

である一方，

```math
U=U_0+p-p_0
```

であるから，

```math
\left(\frac{\partial U}{\partial p}\right)_T=1
```

となる．
したがって，式（1）の条件を設けず，問題文の前提だけを一点での条件として解釈した場合には，結論は必ずしも成立しない．

以上より，**圧力と体積の間で局所的な微分可能な変数変換が可能であることを仮定すれば，問題の命題は連鎖律によって証明される．**
