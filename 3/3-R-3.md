# 例題【3-R-3】

## 解答

### 1. 定圧熱容量 $C_p$ の圧力依存性

定圧熱容量 $C_p$ は，圧力を一定に保ったまま温度を $dT$ 上昇させるのに必要な熱量 $dQ$ を用いて次のように定義される：

$$C_p = \left( \frac{\partial Q}{\partial T} \right)_p$$

熱力学の第一法則およびエントロピー $S$ の定義を用いると，定圧過程における微小熱量は $dQ = T dS$ と書けるため，

$$C_p = T \left( \frac{\partial S}{\partial T} \right)_p$$

となる．

ここで，エントロピー $S$ に関する **Maxwell（マクスウェル）の関係式** を用いる．
この関係式は，熱力学ポテンシャル（ヘルムホルツの自由エネルギーやギブスの自由エネルギー）の性質から導かれる，偏微分の順序交換に関する重要な等式である．
定圧過程における関係式は次の通りである：

$$\left( \frac{\partial S}{\partial p} \right)_T = -\left( \frac{\partial V}{\partial T} \right)_p \quad \cdots (\text{A})$$

この式 (A) の両辺を温度 $T$ で偏微分する．
左辺は， $\left( \frac{\partial}{\partial T} \right)_p \left( \frac{\partial S}{\partial p} \right)_T = \left( \frac{\partial^2 S}{\partial T \partial p} \right)_T$ である．
右辺は， $-\left( \frac{\partial}{\partial T} \right)_p \left( \frac{\partial V}{\partial T} \right)_p = -\left( \frac{\partial^2 V}{\partial T^2} \right)_p$ である．

一方， $C_p$ の定義式を圧力 $p$ で偏微分すると，

$$\left( \frac{\partial C_p}{\partial p} \right)_T = \left( \frac{\partial}{\partial p} \right)_T \left[ T \left( \frac{\partial S}{\partial T} \right)_p \right] = T \left( \frac{\partial^2 S}{\partial p \partial T} \right)_T$$

（ $T$ は定数なので積の微分は不要である）
となる．
偏微分の順序交換が成り立つことから， $\frac{\partial^2 S}{\partial p \partial T} = \frac{\partial^2 S}{\partial T \partial p}$ であるため，

$$\left( \frac{\partial C_p}{\partial p} \right)_T = T \left( \frac{\partial^2 S}{\partial T \partial p} \right)_T = -T \left( \frac{\partial^2 V}{\partial T^2} \right)_p \quad \cdots (1)$$

が得られる．

この式 (1) を圧力 $p$ について積分することで， $C_p(T, p)$ を求めることができる．
基準となる圧力を $p_0$ とすると，

$$C_p(T, p) = C_p(T, p_0) + \int_{p_0}^p \left( \frac{\partial C_p}{\partial p'} \right)_T dp' = C_p(T, p_0) - T \int_{p_0}^p \left( \frac{\partial^2 V}{\partial T^2} \right)_{p'} dp' \quad \cdots (2)$$

となる．

### 2. 比熱の展開式の導出

状態方程式が次のような形式で圧力 $p$ について展開されていると仮定する：

$$pV = A(T) + B(T)p + C^*(T)p^2 + \dots \quad \cdots (3)$$

ここで $A, B, C^*$ は温度 $T$ のみの関数である．
この式を体積 $V$ について解くと，

$$V(T, p) = \frac{A(T)}{p} + B(T) + C^*(T)p + \dots$$

となる．
これを $T$ で 2 回偏微分する．
まず 1 回目の微分は，

$$\left( \frac{\partial V}{\partial T} \right)_p = \frac{A'(T)}{p} + B'(T) + C^{*'}(T)p + \dots$$

となり，2 回目の微分は，

$$\left( \frac{\partial^2 V}{\partial T^2} \right)_p = \frac{A''(T)}{p} + B''(T) + C^{*''}(T)p + \dots \quad \cdots (4)$$

となる．

これを式 (2) に代入する．
積分を実行すると，

$\int \frac{1}{p} dp = \log p$

$\int 1 dp = p$

$\int p dp = \frac{1}{2}p^2$

となるため，

$$C_p(T, p) = C_p(T, p_0) - T \left\{ A''(T) \log \frac{p}{p_0} + B''(T)(p - p_0) + \frac{1}{2}C^{*''}(T)(p^2 - p_0^2) + \dots \right\} \quad \cdots (5)$$

という比熱の展開式が得られる．

### 3. 理想気体の場合

理想気体の状態方程式は $pV = nRT$ である．
これを式 (3) の形式に合わせると，

$A(T) = nRT$

$B(T) = 0$

$C^*(T) = 0$

となる．
ここで， $A(T)$ を $T$ で 2 回微分すると，

$A'(T) = nR$

$A''(T) = 0$

となる．
したがって，式 (4) より $(\partial^2 V / \partial T^2)_p = 0$ であり，式 (1) から

$$\left( \frac{\partial C_p}{\partial p} \right)_T = 0$$

が証明された．
これは，理想気体の定圧熱容量が圧力に依存しないことを意味する．

### 4. $C_p$ と $C_v$ の相互関係

定積熱容量 $C_v$ と定圧熱容量 $C_p$ の差は，以下の関係式で与えられる：

$$C_p - C_v = T \left( \frac{\partial p}{\partial T} \right)_V \left( \frac{\partial V}{\partial T} \right)_p \quad \cdots (6)$$

（これは $dQ = dU + pdV$ および $dS$ の定義から導かれる）

また，Maxwell の関係式を用いた計算により，次のような関係も示せる：

$$C_p - C_v = -T \frac{(\partial^2 V / \partial T^2)_p}{(\partial V / \partial T)_p} = -T \frac{(\partial^2 p / \partial T^2)_V}{(\partial p / \partial V)_T} \quad \cdots (7)$$

これらの式から，状態方程式 $p=f(T, V)$ が既知であれば， $(\partial^2 V / \partial T^2)_p$ や $(\partial V / \partial T)_p$ が計算できるため， $C_p$ または $C_v$ の一方の温度依存性がわかれば，もう一方の関数形を決定することが可能である．

## 解説

### 用語の解説

1.  **定圧熱容量 ( $C_p$ ) と 定積熱容量 ( $C_v$ )**
    物体に熱を加えたとき，温度がどれくらい上がるかを表す指標である．
    圧力を一定に保つ（定圧）か，体積を一定に保つ（定積）かによって，エネルギーが仕事として使われるかどうかが変わるため，その値は異なる．
    一般に $C_p > C_v$ である．

2.  **状態方程式 (Equation of State)**
    物質の状態（圧力 $p$ ，体積 $V$ ，温度 $T$ ）の間の関係を表す式である．
    理想気体では $pV = nRT$ となるが，現実の気体ではより複雑な式（ビリアル展開など）が用いられる．

3.  **Maxwell（マクスウェル）の関係式**
    熱力学における「エントロピー」という目に見えない概念と，「圧力」や「体積」といった直接測定できる物理量を結びつける非常に強力なツールである．
    これがあるおかげで，直接測りにくいエントロピーの変化を，測定可能な量（体積や圧力の変化）として扱える．

4.  **ビリアル展開 (Virial Expansion)**
    現実の気体の状態方程式を，圧力 $p$ のべき級数（ $p, p^2, \dots$ ）として表現する方法である．
    圧力が低いときは最初の数項だけで精度良く近似できる．

5.  **ヤコビアン (Jacobian)**
    複数の変数の変換（例えば $(T, V)$ から $(T, p)$ への変換）を行う際に，その変換がどれくらいの「面積（または体積）の拡大率」を持つかを表す行列式の値である．
    熱力学において，変数変換を伴う微分計算を行う際に不可欠な概念である．
