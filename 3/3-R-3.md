# 例題【3-R-3】

## 解答

### 1．熱力学的前提条件

以下では，熱力学的平衡状態にある閉じた単純圧縮系を考える．
物質量 $N$ は一定とし，仕事は $pV$ 仕事のみとする．

また，エントロピーや自由エネルギーは必要な次数まで連続微分可能であり，状態方程式は対象とする単相領域で微分可能であると仮定する．

さらに，状態方程式

```math
p=f(T,V)
```

から局所的に $V=V(T,p)$ と表すためには，

```math
\left(\frac{\partial p}{\partial V}\right)_T\neq 0
```

が必要である．
この条件は以下の偏微分変換にも用いる．

### 2．定圧熱容量 $C_p$ の圧力依存性

#### 2.1 基本関係式

定圧熱容量 $C_p$ はエンタルピー $H=U+pV$ を用いて

```math
C_p=\left(\frac{\partial H}{\partial T}\right)_p
```

と定義される．

物質量一定の単純圧縮系では，エンタルピーの基本関係式は

```math
dH=T\,dS+V\,dp
```

である．

圧力一定では $dp=0$ なので，

```math
dH=T\,dS
```

となる．
したがって，

```math
\boxed{
C_p=T\left(\frac{\partial S}{\partial T}\right)_p
}
\tag{1}
```

を得る．

#### 2.2 Maxwellの関係式を用いた導出

式(1)を圧力 $p$ について温度一定で偏微分すると，

```math
\left(\frac{\partial C_p}{\partial p}\right)_T
=
T\frac{\partial}{\partial p}
\left(\frac{\partial S}{\partial T}\right)_p
\tag{2}
```

となる．

エントロピー $S(T,p)$ が十分滑らかであれば，混合偏微分の順序を交換できるため，

```math
\left(\frac{\partial C_p}{\partial p}\right)_T
=
T\frac{\partial}{\partial T}
\left(\frac{\partial S}{\partial p}\right)_T
\tag{3}
```

である．

ここでGibbs自由エネルギー

```math
G=H-TS
```

を導入する．
その全微分は

```math
dG=-S\,dT+V\,dp
```

である．
よって，

```math
S=-\left(\frac{\partial G}{\partial T}\right)_p,
\qquad
V=\left(\frac{\partial G}{\partial p}\right)_T
```

となる．

Gibbs自由エネルギーの混合偏微分の交換可能性より，

```math
\frac{\partial}{\partial p}
\left(\frac{\partial G}{\partial T}\right)_p
=
\frac{\partial}{\partial T}
\left(\frac{\partial G}{\partial p}\right)_T
```

が成立する．
したがって，

```math
-\left(\frac{\partial S}{\partial p}\right)_T
=
\left(\frac{\partial V}{\partial T}\right)_p
```

を得る．
すなわち，

```math
\boxed{
\left(\frac{\partial S}{\partial p}\right)_T
=
-\left(\frac{\partial V}{\partial T}\right)_p
}
\tag{4}
```

であり，これがMaxwellの関係式である．

式(4)を式(3)に代入すると，

```math
\begin{aligned}
\left(\frac{\partial C_p}{\partial p}\right)_T
&=
-T\frac{\partial}{\partial T}
\left(\frac{\partial V}{\partial T}\right)_p\\
&=
-T\left(\frac{\partial^2V}{\partial T^2}\right)_p.
\end{aligned}
```

したがって，

```math
\boxed{
\left(\frac{\partial C_p}{\partial p}\right)_T
=
-T\left(\frac{\partial^2V}{\partial T^2}\right)_p
}
\tag{5}
```

となる．

この式により，状態方程式から $V(T,p)$ が求まれば，定圧熱容量の圧力依存性を決定するための微分係数が求められる．

#### 2.3 圧力についての積分

式(5)を基準圧力 $p_0$ から圧力 $p$ まで積分する．温度 $T$ は一定に保たれるので，

```math
\int_{p_0}^{p}
\left(\frac{\partial C_p}{\partial p'}\right)_Tdp'
=
-T\int_{p_0}^{p}
\left(\frac{\partial^2V}{\partial T^2}\right)_{p'}dp'
```

となる．

左辺を積分すると，

```math
C_p(T,p)-C_p(T,p_0)
=
-T\int_{p_0}^{p}
\left(\frac{\partial^2V}{\partial T^2}\right)_{p'}dp'
```

である．
したがって，

```math
\boxed{
C_p(T,p)=C_p(T,p_0)
-T\int_{p_0}^{p}
\left(\frac{\partial^2V}{\partial T^2}\right)_{p'}dp'
}
\tag{6}
```

を得る．

ここで $C_p(T,p_0)$ は基準圧力における定圧熱容量である．

したがって，状態方程式は $C_p$ の圧力依存性を決定するが，熱容量の絶対値を決めるには，基準圧力における熱容量の温度依存性も必要である．

### 3．圧力展開された状態方程式による $C_p$ の展開式

#### 3.1 状態方程式の展開

状態方程式が

```math
pV=A(T)+B(T)p+C^*(T)p^2+\cdots
\tag{7}
```

と展開されるとする．

両辺を $p$ で割ると，

```math
V=\frac{A(T)}p+B(T)+C^*(T)p+\cdots
\tag{8}
```

となる．

展開係数 $A(T),B(T),C^*(T),\ldots$ は，温度について少なくとも2回微分可能と仮定する．

温度 $T$ による微分をプライムで表す．
圧力一定で温度について2回微分すると，

```math
\boxed{
\left(\frac{\partial^2V}{\partial T^2}\right)_p
=
\frac{A''(T)}p+B''(T)+C^{*''}(T)p+\cdots
}
\tag{9}
```

となる．

#### 3.2 $C_p$ の圧力展開

式(9)を式(6)に代入すると，

```math
\begin{aligned}
C_p(T,p)=C_p(T,p_0)
-T\int_{p_0}^{p}
\left[
\frac{A''(T)}{p'}
+B''(T)
+C^{*''}(T)p'
+\cdots
\right]dp'.
\end{aligned}
```

温度 $T$ は積分中一定であるため，各展開係数の温度微分は積分の外に出せる．

各項を積分すると，

```math
\int_{p_0}^{p}\frac{dp'}{p'}
=\ln\frac{p}{p_0},
```

```math
\int_{p_0}^{p}dp'=p-p_0,
```

```math
\int_{p_0}^{p}p'\,dp'
=\frac12(p^2-p_0^2)
```

である．

したがって，

```math
\boxed{
\begin{aligned}
C_p(T,p)=C_p(T,p_0)-T\Bigg[
&A''(T)\ln\frac{p}{p_0}\\
&+B''(T)(p-p_0)\\
&+\frac12C^{*''}(T)(p^2-p_0^2)
+\cdots
\Bigg].
\end{aligned}
}
\tag{10}
```

これが圧力展開された状態方程式に対応する定圧熱容量の展開式である．

なお，対数項を含むため，ここでは $p>0,\ p_0>0$ とする．
また，級数の微分・積分は，対象領域で項別操作が正当化できるものとする．

#### 3.3 展開係数の温度依存性を決定する関係式

式(5)と式(9)から，

```math
\left(\frac{\partial C_p}{\partial p}\right)_T
=
-T\left[
\frac{A''(T)}p
+B''(T)
+C^{*''}(T)p+\cdots
\right]
```

を得る．

これを整理すると，

```math
\boxed{
-\frac1T
\left(\frac{\partial C_p}{\partial p}\right)_T
=
\frac{A''(T)}p+B''(T)+C^{*''}(T)p+\cdots
}
\tag{11}
```

である．

この式が，定圧熱容量の圧力依存性と状態方程式の展開係数の温度依存性を結び付ける関係式である．

例えば，左辺を圧力について

```math
-\frac1T
\left(\frac{\partial C_p}{\partial p}\right)_T
=
\frac{q_{-1}(T)}p+q_0(T)+q_1(T)p+\cdots
```

と展開できるならば，圧力の各べきの係数を比較することにより，

```math
\boxed{
A''(T)=q_{-1}(T)
}
```

```math
\boxed{
B''(T)=q_0(T)
}
```

```math
\boxed{
C^{*''}(T)=q_1(T)
}
```

となる．高次の係数についても同様である．

ただし，この係数比較によって得られるのは各展開係数の2階温度微分である．
展開係数そのものの温度依存性を決定するには，さらに温度について2回積分する必要がある．

例えば，

```math
A''(T)=q_{-1}(T)
```

が得られた場合，基準温度 $T_0$ における $A(T_0)$ および $A'(T_0)$ を与えると，

```math
\boxed{
A(T)=A(T_0)+A'(T_0)(T-T_0)
+\int_{T_0}^{T}(T-\tau)q_{-1}(\tau)\,d\tau
}
\tag{12}
```

となる．

同様に，

```math
\boxed{
B(T)=B(T_0)+B'(T_0)(T-T_0)
+\int_{T_0}^{T}(T-\tau)q_0(\tau)\,d\tau
}
\tag{13}
```

および

```math
\boxed{
C^*(T)=C^*(T_0)+C^{*'}(T_0)(T-T_0)
+\int_{T_0}^{T}(T-\tau)q_1(\tau)\,d\tau
}
\tag{14}
```

を得る．

したがって，係数の温度依存性を一意に決めるには，それぞれについて基準温度での係数の値と1階温度微分の値が必要である．
これらの情報は，実験データや基準状態における条件から与える．

また，式(11)から係数を個別に決定するには，圧力依存性が十分な精度で分かっており，展開に用いる圧力関数が対象領域で独立に識別できることが必要である．
有限個の測定値だけから無限個の係数を一意に決定することはできない．

以上により，式(11)が展開係数の温度依存性を決定するための基本式であり，式(12)～(14)が係数そのものを求める式である．

なお，通常の気体の圧力ビリアル展開として低圧極限で理想気体に近づくことを別途仮定する場合には，

```math
\lim_{p\to0}pV=nRT
```

より

```math
A(T)=nRT
```

となり，

```math
A''(T)=0
```

である．
この場合，式(10)の対数項は消失する．
ただし，この低圧極限の条件は式(7)だけから必然的に導かれるものではないため，別途仮定が必要である．

### 4．理想気体の場合

理想気体の状態方程式は

```math
pV=nRT
\tag{15}
```

である．
したがって，

```math
V=\frac{nRT}{p}
```

となる．

圧力一定で温度について2回偏微分すると，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=\frac{nR}{p}
```

および

```math
\left(\frac{\partial^2V}{\partial T^2}\right)_p=0
```

を得る．

これを式(5)に代入すると，

```math
\boxed{
\left(\frac{\partial C_p}{\partial p}\right)_T=0
}
\tag{16}
```

となる．

したがって，理想気体の定圧熱容量は圧力に依存せず，

```math
\boxed{C_p=C_p(T)}
```

と表される．

### 5．定積熱容量 $C_v$ の体積依存性

#### 5.1 基本関係式

定積熱容量は内部エネルギー $U$ を用いて

```math
C_v=\left(\frac{\partial U}{\partial T}\right)_V
```

と定義される．

内部エネルギーの基本関係式

```math
dU=T\,dS-p\,dV
```

において，体積一定では $dV=0$ なので，

```math
\boxed{
C_v=T\left(\frac{\partial S}{\partial T}\right)_V
}
\tag{17}
```

となる．

式(17)を体積 $V$ について温度一定で偏微分すると，

```math
\left(\frac{\partial C_v}{\partial V}\right)_T
=
T\frac{\partial}{\partial V}
\left(\frac{\partial S}{\partial T}\right)_V.
\tag{18}
```

エントロピーが十分滑らかであれば混合偏微分の順序を交換できるため，

```math
\left(\frac{\partial C_v}{\partial V}\right)_T
=
T\frac{\partial}{\partial T}
\left(\frac{\partial S}{\partial V}\right)_T
\tag{19}
```

となる．

#### 5.2 Maxwellの関係式

Helmholtz自由エネルギー

```math
F=U-TS
```

を導入する．
その全微分は

```math
dF=-S\,dT-p\,dV
```

である．

したがって，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_V,
\qquad
p=-\left(\frac{\partial F}{\partial V}\right)_T
```

となる．

混合偏微分の交換可能性より，

```math
-\left(\frac{\partial S}{\partial V}\right)_T
=
-\left(\frac{\partial p}{\partial T}\right)_V
```

である．
よって，

```math
\boxed{
\left(\frac{\partial S}{\partial V}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_V
}
\tag{20}
```

というMaxwellの関係式を得る．

式(20)を式(19)に代入すると，

```math
\boxed{
\left(\frac{\partial C_v}{\partial V}\right)_T
=
T\left(\frac{\partial^2p}{\partial T^2}\right)_V
}
\tag{21}
```

となる．

#### 5.3 体積についての積分

式(21)を基準体積 $V_0$ から体積 $V$ まで積分する．

温度一定で積分すると，

```math
C_v(T,V)-C_v(T,V_0)
=
T\int_{V_0}^{V}
\left(\frac{\partial^2p}{\partial T^2}\right)_{V'}dV'
```

である．
したがって，

```math
\boxed{
C_v(T,V)=C_v(T,V_0)
+T\int_{V_0}^{V}
\left(\frac{\partial^2p}{\partial T^2}\right)_{V'}dV'
}
\tag{22}
```

を得る．

これにより，状態方程式から定積熱容量の体積依存性も求められることが分かる．
ただし，ここでも基準体積における熱容量 $C_v(T,V_0)$ が必要である．

#### 5.4 体積展開された状態方程式による $C_v$ の展開式

定積熱容量側の展開例として，状態方程式が

```math
pV=\widetilde A(T)
+\frac{\widetilde B(T)}V
+\frac{\widetilde C(T)}{V^2}
+\cdots
\tag{23}
```

と表される場合を考える．

ここでは，圧力展開の場合の係数との混同を避けるため，係数にチルダを付けて区別する．

両辺を $V$ で割ると，

```math
p=
\frac{\widetilde A(T)}V
+\frac{\widetilde B(T)}{V^2}
+\frac{\widetilde C(T)}{V^3}
+\cdots
\tag{24}
```

である．

体積一定で温度について2回微分すると，

```math
\left(\frac{\partial^2p}{\partial T^2}\right)_V
=
\frac{\widetilde A''(T)}V
+\frac{\widetilde B''(T)}{V^2}
+\frac{\widetilde C''(T)}{V^3}
+\cdots
\tag{25}
```

となる．

これを式(22)に代入すると，

```math
\begin{aligned}
C_v(T,V)=C_v(T,V_0)+T\int_{V_0}^{V}
\left[
\frac{\widetilde A''(T)}{V'}
+\frac{\widetilde B''(T)}{V'^2}
+\frac{\widetilde C''(T)}{V'^3}
+\cdots
\right]dV'.
\end{aligned}
```

各項を積分する．

```math
\int_{V_0}^{V}\frac{dV'}{V'}
=\ln\frac{V}{V_0},
```

```math
\int_{V_0}^{V}\frac{dV'}{V'^2}
=\frac1{V_0}-\frac1V,
```

```math
\int_{V_0}^{V}\frac{dV'}{V'^3}
=\frac12\left(\frac1{V_0^2}-\frac1{V^2}\right).
```

したがって，

```math
\boxed{
\begin{aligned}
C_v(T,V)=C_v(T,V_0)+T\Bigg[
&\widetilde A''(T)\ln\frac{V}{V_0}\\
&+\widetilde B''(T)
\left(\frac1{V_0}-\frac1V\right)\\
&+\frac12\widetilde C''(T)
\left(\frac1{V_0^2}-\frac1{V^2}\right)
+\cdots
\Bigg].
\end{aligned}
}
\tag{26}
```

これが体積展開された状態方程式に対応する定積熱容量の展開式である．

なお，式(23)は式(7)とは別形式の展開であり，両者の係数を同一視する必要はない．

### 6．定圧熱容量と定積熱容量の関係

#### 6.1 一般関係式の導出

エントロピーを状態変数 $T,V$ の関数

```math
S=S(T,V)
```

として表す．
その全微分は

```math
dS=
\left(\frac{\partial S}{\partial T}\right)_VdT
+
\left(\frac{\partial S}{\partial V}\right)_TdV
\tag{27}
```

である．

圧力一定の変化では，

```math
dV=\left(\frac{\partial V}{\partial T}\right)_p dT
```

となる．
これを式(27)に代入すると，

```math
\left(\frac{\partial S}{\partial T}\right)_p
=
\left(\frac{\partial S}{\partial T}\right)_V
+
\left(\frac{\partial S}{\partial V}\right)_T
\left(\frac{\partial V}{\partial T}\right)_p
\tag{28}
```

を得る．

式(20)のMaxwellの関係式を用いると，

```math
\left(\frac{\partial S}{\partial T}\right)_p
=
\left(\frac{\partial S}{\partial T}\right)_V
+
\left(\frac{\partial p}{\partial T}\right)_V
\left(\frac{\partial V}{\partial T}\right)_p
\tag{29}
```

となる．

式(29)の両辺に $T$ を掛け，式(1)および式(17)を用いると，

```math
\boxed{
C_p-C_v
=
T\left(\frac{\partial p}{\partial T}\right)_V
\left(\frac{\partial V}{\partial T}\right)_p
}
\tag{30}
```

を得る．

#### 6.2 状態方程式を用いた表現

状態方程式

```math
p=p(T,V)
```

の全微分は

```math
dp=
\left(\frac{\partial p}{\partial T}\right)_VdT
+
\left(\frac{\partial p}{\partial V}\right)_TdV
\tag{31}
```

である．

圧力一定では $dp=0$ なので，

```math
0=
\left(\frac{\partial p}{\partial T}\right)_VdT
+
\left(\frac{\partial p}{\partial V}\right)_TdV.
```

したがって，

```math
\boxed{
\left(\frac{\partial V}{\partial T}\right)_p
=
-\frac{
\left(\frac{\partial p}{\partial T}\right)_V
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
}
\tag{32}
```

となる．

式(32)を式(30)に代入すると，

```math
\boxed{
C_p-C_v
=
-T\frac{
\left(\frac{\partial p}{\partial T}\right)_V^2
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
}
\tag{33}
```

を得る．

これが状態方程式から直接計算できる $C_p-C_v$ の一般式である．

#### 6.3 体積の偏微分を用いた表現

さらに，式(31)において温度一定とすると，

```math
dp=
\left(\frac{\partial p}{\partial V}\right)_TdV
```

である．

```math
\left(\frac{\partial p}{\partial V}\right)_T\neq0
```

であれば，逆関数の微分関係から，

```math
\boxed{
\left(\frac{\partial V}{\partial p}\right)_T
=
\frac1{
\left(\frac{\partial p}{\partial V}\right)_T
}
}
\tag{34}
```

となる．

また，式(32)より，

```math
\left(\frac{\partial p}{\partial T}\right)_V
=
-\left(\frac{\partial p}{\partial V}\right)_T
\left(\frac{\partial V}{\partial T}\right)_p
```

である．

これら2つの関係を式(33)に代入すると，

```math
\begin{aligned}
C_p-C_v
&=
-T
\frac{
\left[
-\left(\frac{\partial p}{\partial V}\right)_T
\left(\frac{\partial V}{\partial T}\right)_p
\right]^2
}{
\left(\frac{\partial p}{\partial V}\right)_T
}\\
&=
-T
\left(\frac{\partial p}{\partial V}\right)_T
\left(\frac{\partial V}{\partial T}\right)_p^2\\
&=
-T
\frac{
\left(\frac{\partial V}{\partial T}\right)_p^2
}{
\left(\frac{\partial V}{\partial p}\right)_T
}.
\end{aligned}
```

したがって，

```math
\boxed{
C_p-C_v
=
-T
\frac{
\left(\frac{\partial V}{\partial T}\right)_p^2
}{
\left(\frac{\partial V}{\partial p}\right)_T
}
}
\tag{35}
```

とも表せる．

ここで，式(35)の導出には，式(32)と式(34)の両方を使用している．

なお，式(33)および式(35)は，状態方程式が局所的に逆変換可能である領域で成立する．

#### 6.4 物理的な符号の確認

等温圧縮率を

```math
\kappa_T
=
-\frac1V\left(\frac{\partial V}{\partial p}\right)_T
```

と定義する．

機械的に安定な単相流体では，

```math
\kappa_T>0
```

であるため，

```math
\left(\frac{\partial V}{\partial p}\right)_T<0
```

となる．

また，熱膨張率を

```math
\alpha
=
\frac1V\left(\frac{\partial V}{\partial T}\right)_p
```

と定義すると，式(35)から

```math
\boxed{
C_p-C_v=\frac{TV\alpha^2}{\kappa_T}\geq0
}
\tag{36}
```

を得る．

これは安定な通常の単相系で $C_p\geq C_v$ となるという物理的性質と一致する．

したがって，導出した一般式の符号も物理的に整合している．

### 7．一方の熱容量から他方を求める方法

#### 7.1 $C_p$ から $C_v$ を求める場合

式(33)を $C_v$ について整理すると，

```math
\boxed{
C_v
=
C_p+
T\frac{
\left(\frac{\partial p}{\partial T}\right)_V^2
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
}
\tag{37}
```

となる．

状態方程式 $p=f(T,V)$ が与えられていれば，

```math
\left(\frac{\partial p}{\partial T}\right)_V,
\qquad
\left(\frac{\partial p}{\partial V}\right)_T
```

は計算できる．

したがって，ある基準圧力 $p_0$ における

```math
C_p(T,p_0)
```

の温度依存性が分かっていれば，式(6)から任意の圧力における

```math
C_p(T,p)
```

を求めることができる．

さらに，状態方程式を用いて $p$ と $V$ の対応を取り，式(37)に代入すれば，

```math
C_v(T,V)
```

を求められる．

#### 7.2 $C_v$ から $C_p$ を求める場合

同様に，式(33)を $C_p$ について整理すると，

```math
\boxed{
C_p
=
C_v-
T\frac{
\left(\frac{\partial p}{\partial T}\right)_V^2
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
}
\tag{38}
```

となる．

ある基準体積 $V_0$ における

```math
C_v(T,V_0)
```

の温度依存性が分かっていれば，式(22)から任意の体積における

```math
C_v(T,V)
```

を求めることができる．

さらに式(38)を用いれば，

```math
C_p(T,p)
```

を求めることができる．

ただし，ここでも状態方程式によって $p$ と $V$ の対応を取る必要がある．

したがって，一方の熱容量の基準状態における温度依存性と状態方程式が与えられれば，他方の熱容量の関数形も決定できる．

なお，熱容量のある一点での数値だけでは，温度依存性全体を決定することはできない．
必要なのは，基準圧力または基準体積における熱容量の温度関数である．

### 8．結論

以上より，定圧熱容量については，

```math
\boxed{
\left(\frac{\partial C_p}{\partial p}\right)_T
=
-T\left(\frac{\partial^2V}{\partial T^2}\right)_p
}
```

が成立し，定積熱容量については，

```math
\boxed{
\left(\frac{\partial C_v}{\partial V}\right)_T
=
T\left(\frac{\partial^2p}{\partial T^2}\right)_V
}
```

が成立する．

したがって，状態方程式が分かれば，それぞれの熱容量の圧力依存性および体積依存性を決定できる．
ただし，熱容量そのものを求めるには，基準圧力または基準体積における熱容量の温度依存性が必要である．

また，状態方程式が

```math
pV=A(T)+B(T)p+C^*(T)p^2+\cdots
```

と展開される場合には，

```math
\boxed{
-\frac1T
\left(\frac{\partial C_p}{\partial p}\right)_T
=
\frac{A''(T)}p+B''(T)+C^{*''}(T)p+\cdots
}
```

が成立する．

この関係から，熱容量の圧力依存性と展開係数の2階温度微分との関係が求められる．
さらに，基準温度における係数とその1階温度微分を与えれば，温度について2回積分することにより，各展開係数の温度依存性を決定できる．

理想気体では

```math
pV=nRT
```

であるため，

```math
\left(\frac{\partial^2V}{\partial T^2}\right)_p=0
```

となり，

```math
\boxed{
\left(\frac{\partial C_p}{\partial p}\right)_T=0
}
```

が成立する．

さらに，定圧熱容量と定積熱容量の間には，

```math
\boxed{
C_p-C_v
=
-T\frac{
\left(\frac{\partial p}{\partial T}\right)_V^2
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
}
```

という一般関係がある．
したがって，状態方程式と一方の熱容量の基準状態における温度依存性が分かれば，他方の熱容量も求められる．

以上により，問題文で要求された定圧熱容量および定積熱容量の依存性，圧力展開による熱容量の展開式，理想気体における圧力非依存性，ならびに一方の熱容量から他方を決定できることが示された．
