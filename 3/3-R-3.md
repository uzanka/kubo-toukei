# 例題【3-R-3】

## 解答

### 1．定圧熱容量 $C_p$ の圧力依存性

定圧熱容量 $C_p$ は，エンタルピー $H=U+pV$ を用いて

```math
C_p=\left(\frac{\partial H}{\partial T}\right)_p
=T\left(\frac{\partial S}{\partial T}\right)_p
\tag{1}
```

と表される．
ここで， $S$ はエントロピーである．
第2の等号は，エンタルピーの微分関係 $dH=T\,dS+V\,dp$ において，圧力一定，すなわち $dp=0$ とすることで得られる．

式（1）を圧力 $p$ で偏微分する．
温度 $T$ を一定に保つと，

```math
\left(\frac{\partial C_p}{\partial p}\right)_T
=T\frac{\partial}{\partial p}
\left(\frac{\partial S}{\partial T}\right)_p
\tag{2}
```

となる．
エントロピーが十分滑らかな状態関数であれば，混合偏微分の順序を交換できるので，

```math
\left(\frac{\partial C_p}{\partial p}\right)_T
=T\frac{\partial}{\partial T}
\left(\frac{\partial S}{\partial p}\right)_T
\tag{3}
```

である．

ここで，Gibbs 自由エネルギー

```math
G=H-TS
```

を導入する．
その全微分は

```math
dG=-S\,dT+V\,dp
\tag{4}
```

である．
したがって，

```math
S=-\left(\frac{\partial G}{\partial T}\right)_p,
\qquad
V=\left(\frac{\partial G}{\partial p}\right)_T
\tag{5}
```

となる．
$G$ の混合偏微分の順序を交換すると，

```math
-\left(\frac{\partial S}{\partial p}\right)_T
=\left(\frac{\partial V}{\partial T}\right)_p
```

を得る．
よって Maxwell の関係式

```math
\boxed{
\left(\frac{\partial S}{\partial p}\right)_T
=-\left(\frac{\partial V}{\partial T}\right)_p
}
\tag{6}
```

が成立する．

式（6）を式（3）に代入すると，

```math
\boxed{
\left(\frac{\partial C_p}{\partial p}\right)_T
=-T\left(\frac{\partial^2V}{\partial T^2}\right)_p
}
\tag{7}
```

となる．
これにより， $C_p$ の圧力依存性は状態方程式 $p=f(T,V)$ から求められることが分かる．

式（7）を基準圧力 $p_0$ から圧力 $p$ まで積分すれば，

```math
\boxed{
C_p(T,p)=C_p(T,p_0)
-T\int_{p_0}^{p}
\left(\frac{\partial^2V}{\partial T^2}\right)_{p'}dp'
}
\tag{8}
```

を得る．
ここで積分変数を $p'$ と書いたのは，積分中に変化する圧力と，積分の上限 $p$ を区別するためである．
右辺の積分は状態方程式から計算でき，基準圧力 $p_0$ における熱容量 $C_p(T,p_0)$ が分かれば，任意の圧力での $C_p$ が求められる．

### 2．状態方程式の圧力展開による $C_p$ の展開式

状態方程式が

```math
pV=A(T)+B(T)p+C^*(T)p^2+\cdots
\tag{9}
```

と展開されているとする．
両辺を $p$ で割ると，

```math
V=\frac{A(T)}p+B(T)+C^*(T)p+\cdots
\tag{10}
```

である．
ここで，プライムは温度 $T$ による微分を表す．
圧力 $p$ を一定に保って温度で2回偏微分すると，

```math
\left(\frac{\partial^2V}{\partial T^2}\right)_p
=\frac{A''(T)}p+B''(T)+C^{*''}(T)p+\cdots
\tag{11}
```

となる．
これを式（8）に代入し，各項を積分する．

```math
\begin{aligned}
C_p(T,p)=C_p(T,p_0)-T\Bigg[
&A''(T)\log\frac{p}{p_0}\\
&+B''(T)(p-p_0)\\
&+\frac12 C^{*''}(T)(p^2-p_0^2)
+\cdots
\Bigg]
\end{aligned}
\tag{12}
```

これが求める $C_p$ の展開式である．
一般に，展開係数 $A(T),B(T),C^*(T),\ldots$ の温度に関する2階微分が，熱容量の圧力依存性を決定する．
ただし，基準圧力 $p_0$ での熱容量 $C_p(T,p_0)$ は別途与える必要がある．

#### 理想気体の場合

理想気体の状態方程式は

```math
pV=nRT
\tag{13}
```

である．
したがって，

```math
V=\frac{nRT}{p}
```

であり，圧力一定のもとでは

```math
\left(\frac{\partial^2V}{\partial T^2}\right)_p=0
\tag{14}
```

となる．
よって，式（7）から

```math
\boxed{
\left(\frac{\partial C_p}{\partial p}\right)_T=0
}
\tag{15}
```

が得られる．
すなわち，理想気体の定圧熱容量は圧力に依存せず，温度だけの関数である．

### 3．定積熱容量 $C_v$ の体積依存性

定積熱容量 $C_v$ は

```math
C_v=\left(\frac{\partial U}{\partial T}\right)_V
=T\left(\frac{\partial S}{\partial T}\right)_V
\tag{16}
```

と表される．
ここでは粒子数を一定とする．
式（16）を体積 $V$ で偏微分すると，

```math
\left(\frac{\partial C_v}{\partial V}\right)_T
=T\frac{\partial}{\partial V}
\left(\frac{\partial S}{\partial T}\right)_V
\tag{17}
```

である．
混合偏微分の順序を交換すれば，

```math
\left(\frac{\partial C_v}{\partial V}\right)_T
=T\frac{\partial}{\partial T}
\left(\frac{\partial S}{\partial V}\right)_T
\tag{18}
```

となる．

Helmholtz 自由エネルギー $F=U-TS$ を用いると，

```math
dF=-S\,dT-p\,dV
\tag{19}
```

である．
したがって，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_V,
\qquad
p=-\left(\frac{\partial F}{\partial V}\right)_T
```

であり，混合偏微分の順序交換から，

```math
\boxed{
\left(\frac{\partial S}{\partial V}\right)_T
=\left(\frac{\partial p}{\partial T}\right)_V
}
\tag{20}
```

という Maxwell の関係式を得る．
これを式（18）に代入すると，

```math
\boxed{
\left(\frac{\partial C_v}{\partial V}\right)_T
=T\left(\frac{\partial^2p}{\partial T^2}\right)_V
}
\tag{21}
```

となる．
したがって，基準体積 $V_0$ から体積 $V$ まで積分すると，

```math
\boxed{
C_v(T,V)=C_v(T,V_0)
+T\int_{V_0}^{V}
\left(\frac{\partial^2p}{\partial T^2}\right)_{V'}dV'
}
\tag{22}
```

が得られる．
これにより，状態方程式から $C_v$ の体積依存性も求められる．

#### ビリアル展開の場合

状態方程式が

```math
pV=A(T)+\frac{B(T)}V+\frac{C(T)}{V^2}+\cdots
\tag{23}
```

と展開されるとする．
両辺を $V$ で割ると，

```math
p=\frac{A(T)}V+\frac{B(T)}{V^2}
+\frac{C(T)}{V^3}+\cdots
\tag{24}
```

である．
体積 $V$ を一定に保って温度で2回偏微分すると，

```math
\left(\frac{\partial^2p}{\partial T^2}\right)_V
=\frac{A''(T)}V+\frac{B''(T)}{V^2}
+\frac{C''(T)}{V^3}+\cdots
\tag{25}
```

となる．
式（22）に代入し，各項を積分すれば，

```math
\begin{aligned}
C_v(T,V)=C_v(T,V_0)+T\Bigg[
&A''(T)\log\frac{V}{V_0}\\
&+B''(T)\left(\frac1{V_0}-\frac1V\right)\\
&+\frac12 C''(T)\left(\frac1{V_0^2}-\frac1{V^2}\right)
+\cdots
\Bigg]
\end{aligned}
\tag{26}
```

を得る．
これがビリアル展開に対応する $C_v$ の展開式である．

### 4．定圧熱容量と定積熱容量の関係

状態方程式が分かっているとき， $C_p$ と $C_v$ の一方から他方を求めるには，両者の差を表す式を導けばよい．

エントロピーを $S=S(T,V)$ と考えると，

```math
dS=
\left(\frac{\partial S}{\partial T}\right)_VdT
+\left(\frac{\partial S}{\partial V}\right)_TdV
\tag{27}
```

である．
圧力一定の変化について $dV=(\partial V/\partial T)_p\,dT$ を代入し， $dT$ の係数を比較すると，

```math
\left(\frac{\partial S}{\partial T}\right)_p
=
\left(\frac{\partial S}{\partial T}\right)_V
+\left(\frac{\partial S}{\partial V}\right)_T
\left(\frac{\partial V}{\partial T}\right)_p
\tag{28}
```

を得る．
式（20）の Maxwell の関係式を用いれば，

```math
\left(\frac{\partial S}{\partial T}\right)_p
=
\left(\frac{\partial S}{\partial T}\right)_V
+\left(\frac{\partial p}{\partial T}\right)_V
\left(\frac{\partial V}{\partial T}\right)_p
\tag{29}
```

となる．
式（29）の両辺に $T$ を掛け，熱容量の定義を用いると，

```math
\boxed{
C_p-C_v
=T\left(\frac{\partial p}{\partial T}\right)_V
\left(\frac{\partial V}{\partial T}\right)_p
}
\tag{30}
```

が得られる．

さらに，状態方程式 $p=p(T,V)$ の全微分は

```math
dp=\left(\frac{\partial p}{\partial T}\right)_VdT
+\left(\frac{\partial p}{\partial V}\right)_TdV
\tag{31}
```

である．
圧力一定のとき $dp=0$ なので，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=-\frac{\left(\frac{\partial p}{\partial T}\right)_V}
{\left(\frac{\partial p}{\partial V}\right)_T}
\tag{32}
```

となる．
これを式（30）に代入すると，

```math
\boxed{
C_p-C_v
=-T\frac{
\left(\frac{\partial p}{\partial T}\right)_V^2
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
}
\tag{33}
```

を得る．

また，逆関数の微分関係

```math
\left(\frac{\partial V}{\partial p}\right)_T
=\frac1{\left(\frac{\partial p}{\partial V}\right)_T}
\tag{34}
```

を用いると，式（33）は

```math
\boxed{
C_p-C_v
=-T\frac{
\left(\frac{\partial V}{\partial T}\right)_p^2
}{
\left(\frac{\partial V}{\partial p}\right)_T
}
}
\tag{35}
```

とも書ける．
式（33），（35）の偏微分係数はすべて状態方程式から計算できる．
これが $C_p-C_v$ を求める一般式である．

### 5．一方の熱容量から他方を求める方法

状態方程式が与えられていれば，式（33）から

```math
\boxed{
C_v=C_p+
T\frac{
\left(\frac{\partial p}{\partial T}\right)_V^2
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
}
\tag{36}
```

と表せる．
したがって，定圧熱容量 $C_p$ が温度と圧力の関数として分かっていれば，状態方程式から偏微分係数を計算することで，定積熱容量 $C_v$ を求められる．
このとき，状態方程式を用いて圧力 $p$ と体積 $V$ の対応を取る必要がある．

逆に，

```math
\boxed{
C_p=C_v-
T\frac{
\left(\frac{\partial p}{\partial T}\right)_V^2
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
}
\tag{37}
```

であるから， $C_v$ が分かっていれば $C_p$ も求められる．

また，式（8）と式（22）から分かるように，基準圧力 $p_0$ での $C_p(T,p_0)$ ，または基準体積 $V_0$ での $C_v(T,V_0)$ の温度依存性が与えられれば，状態方程式を用いて各熱容量の圧力依存性または体積依存性を求められる．
その後，式（36）または式（37）を用いることで，他方の熱容量の関数形も決定できる．

以上より，定圧熱容量の圧力依存性および定積熱容量の体積依存性は状態方程式によって決まり，さらに状態方程式と一方の熱容量の関数形が分かれば，他方の熱容量も求められることが示された．
