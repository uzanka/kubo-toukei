# 演習問題【3-A-1】

## 解答

Helmholtz自由エネルギーの性質の検証する．

### 1．定義と符号規約

体系のHelmholtz自由エネルギーを

```math
F=U-TS
\tag{1}
```

と定義する．
ここで， $U$ は内部エネルギー， $S$ はエントロピー， $T$ は絶対温度である．

体系と熱源からなる合成系について，

```math
U^*=U+U^{(e)},\qquad
S^*=S+S^{(e)}
\tag{2}
```

とする．
体系と熱源の相互作用エネルギーは無視する．

体系が受け取る熱を正とし，その総量を $Q$ とする．
また，体系が外界から受け取る仕事を正とする．

### 2．（i）の検証

#### 2.1 熱源のエネルギーおよびエントロピー変化

原問題の条件を満たす熱源として，体系との間で熱のみを交換し，外界とはエネルギーを交換しない熱源を考える．
これは原問題が指定する条件を満たす，より限定された場合である．

熱源の温度が体系と等しい一定温度 $T$ である場合，熱力学第一法則から，

```math
\Delta U^{(e)}=-Q
\tag{3}
```

となる．

また，熱源のエントロピー変化は，

```math
\Delta S^{(e)}=-\frac QT
\tag{4}
```

である．

#### 2.2 合成系の変化

式（2），（3）から，

```math
\boxed{\Delta U^*=\Delta U-Q}
\tag{5}
```

を得る．

同様に，式（2），（4）から，

```math
\boxed{\Delta S^*=\Delta S-\frac QT}
\tag{6}
```

となる．

合成系は外界と熱および物質を交換しないため，熱力学第二法則より，

```math
\boxed{\Delta S^*=\Delta S_{\mathrm{gen}}^*\geq0}
\tag{7}
```

である．

ここで， $\Delta S_{\mathrm{gen}}^*$ は合成系全体におけるエントロピー生成である．

#### 2.3 自由エネルギーとの関係

初期状態と終状態の温度がともに一定の $T$ である場合，

```math
\Delta F=\Delta U-T\Delta S
\tag{8}
```

となる．

式（6）から，

```math
Q=T(\Delta S-\Delta S^*)
\tag{9}
```

である．
これを式（5）に代入すると，

```math
\begin{aligned}
\Delta U^*
&=\Delta U-Q\\
&=\Delta U-T(\Delta S-\Delta S^*)\\
&=\Delta U-T\Delta S+T\Delta S^*\\
&=\Delta F+T\Delta S^*
\end{aligned}
```

となる．
式（7）を用いれば，

```math
\boxed{
\Delta U^*
=
\Delta F+T\Delta S_{\mathrm{gen}}^*
}
\tag{10}
```

を得る．

したがって，

```math
\boxed{\Delta U^*\geq\Delta F}
\tag{11}
```

が成立する．

等号が成立する条件は，

```math
\boxed{\Delta S_{\mathrm{gen}}^*=0}
\tag{12}
```

である．
すなわち，合成系全体のエントロピー生成がゼロとなる場合である．

一方，合成系内に不可逆現象が存在する場合には，

```math
\Delta S_{\mathrm{gen}}^*>0
```

であるため，

```math
\boxed{\Delta U^*>\Delta F}
\tag{13}
```

となる．

したがって，原問題（i）の等式は，一般の不可逆過程に対しては成立せず，合成系全体のエントロピー生成がゼロの場合に限って成立する．

#### 2.4 原問題（i）に対する具体的な反例

原問題の条件を満たす不可逆等温膨張を考える．

温度 $T$ の熱浴に接触した $n$ mol の理想気体を，体積 $V_1$ から $V_2$ へ膨張させる．
ただし，

```math
V_2>V_1
```

とし，外圧を終状態の圧力

```math
p^{(e)}=\frac{nRT}{V_2}
```

に一定に保つ．
体系は熱浴との熱交換によって温度 $T$ に保たれるものとする．

理想気体の内部エネルギーは温度だけで決まるから，

```math
\Delta U=0
\tag{14}
```

である．

体系が外界にする仕事は，

```math
W_{\mathrm{by}}
=p^{(e)}(V_2-V_1)
=nRT\left(1-\frac{V_1}{V_2}\right)
```

である．
したがって，体系が受け取る仕事は，

```math
A_{\mathrm{on}}
=-nRT\left(1-\frac{V_1}{V_2}\right)
\tag{15}
```

となる．

第一法則より，

```math
\Delta U=Q+A_{\mathrm{on}}=0
```

であるから，

```math
Q=nRT\left(1-\frac{V_1}{V_2}\right)
\tag{16}
```

を得る．

熱源の内部エネルギー変化は，

```math
\Delta U^{(e)}
=-nRT\left(1-\frac{V_1}{V_2}\right)
```

である．

したがって，

```math
\boxed{
\Delta U^*
=-nRT\left(1-\frac{V_1}{V_2}\right)
}
\tag{17}
```

となる．

一方，理想気体のエントロピー変化は，

```math
\Delta S=nR\ln\frac{V_2}{V_1}
```

であり，Helmholtz自由エネルギーの変化は，

```math
\boxed{
\Delta F=-nRT\ln\frac{V_2}{V_1}
}
\tag{18}
```

となる．

したがって，

```math
\begin{aligned}
\Delta U^*-\Delta F
&=nRT\left[
\ln\frac{V_2}{V_1}
-1+\frac{V_1}{V_2}
\right]\\
&>0
\end{aligned}
```

である．
最後の不等式は， $x=V_2/V_1>1$ とおけば，

```math
\ln x-1+\frac1x>0
```

が成立することから従う．
実際，

```math
\frac{d}{dx}\left(\ln x-1+\frac1x\right)
=\frac{x-1}{x^2}>0
```

であり， $x=1$ で関数値はゼロである．

よって，

```math
\boxed{\Delta U^*\neq\Delta F}
```

となる．

この反例は，体系と熱源の温度が等しく，熱源が体系だけに熱を供給し，熱源が外界から仕事を受けない場合であっても，原問題（i）の等式が一般には成立しないことを示している．

### 3．（ii）の検証

体系が温度 $T$ を一定に保ちながら変化する場合を考える．
原問題（ii）には熱源の条件が明示されていないため，まず温度 $T$ の熱浴と熱交換する場合を考える．
これは等温過程に対する標準的な熱力学モデルである．

#### 3.1 熱力学第一法則

体系が受け取る仕事を $A_{\mathrm{on}}$ とすると，

```math
\Delta U=Q+A_{\mathrm{on}}
\tag{19}
```

である．

また，熱浴の内部エネルギー変化は，

```math
\Delta U^{(e)}=-Q
\tag{20}
```

である．

したがって，

```math
\boxed{\Delta U^*=A_{\mathrm{on}}}
\tag{21}
```

となる．

#### 3.2 仕事と自由エネルギー変化

（i）と同じエントロピー収支から，

```math
\Delta U^*
=
\Delta F+T\Delta S_{\mathrm{gen}}^*
```

である．
式（21）を代入すると，

```math
\boxed{
A_{\mathrm{on}}
=
\Delta F+T\Delta S_{\mathrm{gen}}^*
}
\tag{22}
```

となる．

第二法則より，

```math
\boxed{A_{\mathrm{on}}\geq\Delta F}
\tag{23}
```

が成立する．

等号が成立するための条件は，

```math
\boxed{\Delta S_{\mathrm{gen}}^*=0}
\tag{24}
```

である．

したがって，一般の等温過程で体系が外界から受け取る仕事が自由エネルギーの増加量に等しいとは限らない．

#### 3.3 （ii）に対する反例

2.4節で考えた理想気体の不可逆等温膨張を用いる．

```math
A_{\mathrm{on}}
=-nRT\left(1-\frac{V_1}{V_2}\right)
```

である一方，

```math
\Delta F=-nRT\ln\frac{V_2}{V_1}
```

である．

したがって，

```math
\boxed{
A_{\mathrm{on}}-\Delta F
=
nRT\left[
\ln\frac{V_2}{V_1}
-1+\frac{V_1}{V_2}
\right]>0
}
\tag{25}
```

となり，

```math
\boxed{A_{\mathrm{on}}\neq\Delta F}
```

である．

この反例は，温度一定という条件だけでは（ii）の等式が成立しないことを示している．

### 4．原問題の条件から導ける正しい結論

以上の結果を整理すると，温度一定の単一熱浴と接触する体系について，合成系が外界と熱および物質を交換しない場合には，

```math
\boxed{
\Delta U^*
=
\Delta F+T\Delta S_{\mathrm{gen}}^*
}
```

が成立する．

また，合成系と外界とのエネルギー交換が体系に加えられる全仕事だけである場合には，

```math
\boxed{
A_{\mathrm{on}}
=
\Delta F+T\Delta S_{\mathrm{gen}}^*
}
```

が成立する．

したがって，一般の不可逆過程について正しく成立する関係は，

```math
\boxed{
\Delta U^*\geq\Delta F,\qquad
A_{\mathrm{on}}\geq\Delta F
}
```

である．

等号が成立するのは，合成系全体のエントロピー生成がゼロとなる場合である．

なお，（i）で温度が過程中に変化する場合には，瞬間温度を $T(t)$ とすると，

```math
dU^*=dF+S\,dT+T\,dS_{\mathrm{gen}}^*
```

となる．
したがって，温度変化を許す場合には，等温の場合の関係式をそのまま適用することもできない．

### 5．最終結論

原問題（i），（ii）の等式は，記載された条件だけでは一般には証明できない．
その理由は，温度が等しいことや一定であることだけでは，合成系全体の不可逆性を排除できないためである．

原問題の条件のもとで一般的に導けるのは，自由エネルギー変化と合成系の内部エネルギー変化，および体系が受け取る仕事との間にある，エントロピー生成を含む関係式である．

可逆過程ではエントロピー生成がゼロとなり，初めて，

```math
\boxed{\Delta U^*=\Delta F}
```

および，

```math
\boxed{A_{\mathrm{on}}=\Delta F}
```

が成立する．
