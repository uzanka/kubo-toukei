# 演習問題【3-A-1】

## 解答

### （i）の証明

体系と，体系に熱を供給する熱源からなる合成系を考える．
体系の内部エネルギーおよびエントロピーをそれぞれ $U,S$ ，熱源の内部エネルギーおよびエントロピーをそれぞれ $U^{(e)},S^{(e)}$ とする．
また，体系の温度を $T$ ，熱源の温度を $T^{(e)}$ とする．
問題の条件より，両者の温度は常に等しく，熱源の温度 $T^{(e)}$ は一定である．

解答例と同様に，準静的な無限小過程を考える．
準静的過程とは，系が各瞬間に熱平衡状態に限りなく近い状態を通りながら変化する過程である．

#### 1．熱源の内部エネルギーとエントロピーの変化

熱源から体系に微小な熱量 $d'Q$ が供給されるとする．
ここで， $d'Q$ は熱の移動量を表し，状態量の完全微分 $dQ$ とは区別するためにプライムを付けている．

熱源は外界から仕事を受けず，体系以外に熱を供給しないため，熱源から流出する熱量だけ内部エネルギーが減少する．
したがって，熱力学第一法則より，

```math
dU^{(e)}=-d'Q
\tag{1}
```

である．

また，熱源は一定温度 $T^{(e)}$ で準静的に変化するので，可逆過程の関係 $dS^{(e)}=d'Q^{(e)}/T^{(e)}$ を適用できる．
ここで， $d'Q^{(e)}=-d'Q$ は熱源が受け取る熱量である．
よって，

```math
dS^{(e)}=-\frac{d'Q}{T^{(e)}}
\tag{2}
```

となる．

式（1），（2）から $d'Q$ を消去すると，

```math
dU^{(e)}=T^{(e)}dS^{(e)}
\tag{3}
```

が得られる．

#### 2．合成系のエントロピー変化

体系と熱源からなる合成系の内部エネルギー $U^*$ およびエントロピー $S^*$ は，それぞれ

```math
U^*=U+U^{(e)},\qquad
S^*=S+S^{(e)}
\tag{4}
```

と表される．

合成系は外界から熱を受け取らず，体系と熱源の間でのみ熱が移動する．
さらに，熱の移動が可逆的に行われるとする．
このとき，合成系全体のエントロピーは変化しない．したがって，

```math
dS^*=dS+dS^{(e)}=0
\tag{5}
```

である．
よって，

```math
dS^{(e)}=-dS
\tag{6}
```

を得る．

なお，断熱された合成系について，熱力学第二法則が一般に保証するのは $dS^*\geq 0$ である．
式（5）の等号は，単に準静的であることだけから導かれるのではなく，可逆的な熱の移動を前提としている．

#### 3．合成系の内部エネルギー変化

式（4）より，合成系の内部エネルギー変化は

```math
dU^*=dU+dU^{(e)}
\tag{7}
```

である．
ここに式（3）を代入すると，

```math
dU^*=dU+T^{(e)}dS^{(e)}
\tag{8}
```

となる．
さらに，式（6）を用いれば，

```math
dU^*=dU-T^{(e)}dS
\tag{9}
```

を得る．

問題の条件より $T=T^{(e)}$ であるから，

```math
dU^*=dU-TdS
\tag{10}
```

となる．

#### 4．Helmholtzの自由エネルギーとの関係

Helmholtzの自由エネルギー $F$ は，

```math
F=U-TS
\tag{11}
```

と定義される．
これを微分すると，積の微分法則により，

```math
dF=dU-TdS-SdT
\tag{12}
```

である．

本問題では熱源の温度 $T^{(e)}$ が一定であり，体系の温度は常に $T=T^{(e)}$ に保たれる．
したがって，体系の温度も一定であり， $dT=0$ となる．
よって，式（12）は

```math
dF=dU-TdS
\tag{13}
```

となる．

式（10）と式（13）を比較すると，

```math
\boxed{
dU^*=dF
}
\tag{14}
```

が得られる．
すなわち，合成系の内部エネルギーの変化は，体系のHelmholtzの自由エネルギーの変化に等しいのである．

ここで，式（14）は微小変化について成立する関係である．
これを積分すれば，考えている過程に沿って合成系の内部エネルギー変化と自由エネルギー変化が等しいことが分かる．
しかし，この関係だけから，合成系の内部エネルギーそのものが自由エネルギーに定数を加えたものとして，すべての可能な状態について一意に表されるとは限らない．
熱源の状態変化が体系の状態だけで一意に定まるとは限らないためである．

以上により，（i）が証明された．

### （ii）の証明

体系が一定温度 $T$ を保ちながら変化する場合を考える．
体系と熱源からなる合成系について，熱力学第一法則を適用する．

問題の条件より，熱源は外界から仕事を受けず，体系以外に熱を供給しない．
したがって，合成系全体は外界から熱を受け取らず，外界から体系に加えられる仕事 $d'A$ のみを受け取る．
ここで， $d'A$ は外界から体系に加えられる微小仕事を表す．

よって，合成系の内部エネルギー変化は

```math
dU^*=d'A
\tag{15}
```

となる．

一方，（i）で証明した関係より，

```math
dU^*=dF
\tag{16}
```

である．
式（15），（16）を比較すると，

```math
\boxed{
dF=d'A
}
\tag{17}
```

を得る．

したがって，体系が一定温度を保ちながら変化するとき，体系が外界から受け取る仕事は，体系のHelmholtzの自由エネルギーの増し高に等しい．
これにより，（ii）が証明された．
