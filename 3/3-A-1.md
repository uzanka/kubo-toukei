# 演習問題【3-A-1】

## 解答

### はじめに

体系のHelmholtz自由エネルギーを

```math
F=U-TS
```

と定義する．
ここで， $U$ は内部エネルギー， $S$ はエントロピー， $T$ は体系の温度である．

以下では，体系に熱を供給する熱源を温度 $T$ の理想熱浴として扱い，体系と熱源の温度は常に等しく一定であるとする．
また，体系と熱源からなる合成系は外界と熱を交換せず，熱浴は外界から仕事を受けないものとする．

ただし，合成系全体が可逆的に変化することは，問題文の条件だけからは一般に保証されない．
そこで，まず不可逆過程も含めて成立する関係を導き，次に可逆過程の場合を考える．

### （i）の証明

#### 1．熱源の内部エネルギーとエントロピーの変化

体系の内部エネルギーおよびエントロピーを $U,S$ ，熱源の内部エネルギーおよびエントロピーを $U^{(e)},S^{(e)}$ とする．

熱源から体系に供給される微小な熱量を $\delta Q$ とし，体系が受け取る熱を正とする．

熱源は外界から仕事を受けず，体系以外に熱を供給しないため，熱力学第一法則より，

```math
dU^{(e)}=-\delta Q
\tag{1}
```

となる．

熱源は温度 $T$ の理想熱浴であるから，そのエントロピー変化は，

```math
dS^{(e)}=-\frac{\delta Q}{T}
\tag{2}
```

と表される．
したがって，

```math
dU^{(e)}=T\,dS^{(e)}
\tag{3}
```

を得る．

#### 2．合成系のエントロピー変化

体系と熱源からなる合成系の内部エネルギーおよびエントロピーを，それぞれ

```math
U^*=U+U^{(e)},\qquad
S^*=S+S^{(e)}
\tag{4}
```

と定義する．

式（4）を微分すると，

```math
dS^*=dS+dS^{(e)}
```

である．
式（2）を用いれば，

```math
dS^*=dS-\frac{\delta Q}{T}
\tag{5}
```

となる．

合成系は外界と熱を交換しないので，熱力学第二法則より，

```math
dS^*\geq 0
\tag{6}
```

である．

ここで， $dS^*$ は合成系における微小なエントロピー生成を表す．
合成系全体が可逆的に変化する場合には，

```math
dS^*=0
\tag{7}
```

となる．
一方，不可逆過程では一般に $dS^*>0$ である．

#### 3．合成系の内部エネルギー変化

式（4）を微分すると，

```math
dU^*=dU+dU^{(e)}
\tag{8}
```

となる．
式（1）を代入すれば，

```math
dU^*=dU-\delta Q
\tag{9}
```

を得る．

一方，温度 $T$ は一定であるから，Helmholtz自由エネルギー

```math
F=U-TS
\tag{10}
```

の全微分は，

```math
dF=dU-T\,dS
\tag{11}
```

となる．

式（5）より，

```math
\delta Q=T(dS-dS^*)
\tag{12}
```

である．
これを式（9）に代入すると，

```math
\begin{aligned}
dU^*
&=dU-T(dS-dS^*)\\
&=dU-T\,dS+T\,dS^*\\
&=dF+T\,dS^*
\end{aligned}
```

となる．
したがって，

```math
\boxed{dU^*=dF+T\,dS^*}
\tag{13}
```

を得る．

温度 $T$ は一定なので，これを過程全体にわたって積分すると，

```math
\boxed{\Delta U^*=\Delta F+T\Delta S^*}
\tag{14}
```

となる．

熱力学第二法則より $\Delta S^*\geq0$ であるから，

```math
\boxed{\Delta U^*\geq\Delta F}
\tag{15}
```

が成立する．

等号

```math
\boxed{\Delta U^*=\Delta F}
\tag{16}
```

が成立するのは，合成系全体のエントロピー生成がゼロとなる可逆過程の場合である．

以上より，合成系の内部エネルギー変化と体系のHelmholtz自由エネルギー変化は，一般には式（14）の関係を満たし，合成系が可逆的に変化する場合に限って等しくなる．

したがって，問題文の（i）の等式を証明するには，合成系全体の可逆性という条件が必要である．

### （ii）の証明

体系が一定温度 $T$ を保ちながら変化する場合を考える．
外界から体系に加えられる仕事を正とし，その微小量を $\delta A_{\mathrm{on}}$ とする．

#### 1．合成系に対する熱力学第一法則

体系と熱源からなる合成系は外界と熱を交換せず，熱源は外界から仕事を受けないものとする．
また，合成系と外界とのエネルギー交換は体系に加えられる仕事だけであるとする．

このとき，熱力学第一法則より，

```math
dU^*=\delta A_{\mathrm{on}}
\tag{17}
```

となる．

#### 2．仕事と自由エネルギー変化の関係

（i）で得られた式（13）より，

```math
dU^*=dF+T\,dS^*
```

である．
式（17）を代入すると，

```math
\delta A_{\mathrm{on}}=dF+T\,dS^*
\tag{18}
```

を得る．

温度 $T$ は一定なので，過程全体にわたって積分すれば，

```math
\boxed{A_{\mathrm{on}}=\Delta F+T\Delta S^*}
\tag{19}
```

となる．

ここで， $A_{\mathrm{on}}$ は外界から体系に加えられた正味の仕事であり， $\Delta F=F_2-F_1$ はHelmholtz自由エネルギーの変化量である．

熱力学第二法則より $\Delta S^*\geq0$ であるから，

```math
\boxed{A_{\mathrm{on}}\geq\Delta F}
\tag{20}
```

が成立する．

等号

```math
\boxed{A_{\mathrm{on}}=\Delta F}
\tag{21}
```

が成立するのは，合成系全体のエントロピー生成がゼロとなる可逆過程の場合である．

したがって，体系が一定温度を保ちながら可逆的に変化するとき，体系が外界から受け取る正味の仕事は，体系のHelmholtz自由エネルギーの増加量に等しい．

一方，一般の不可逆等温過程では，外界から加えられる仕事は自由エネルギーの増加量以上となる．

### 結論

Helmholtz自由エネルギー $F=U-TS$ に対して，温度 $T$ が一定である場合，体系と熱源からなる合成系の内部エネルギー変化は，

```math
\boxed{\Delta U^*=\Delta F+T\Delta S^*}
```

の関係を満たす．

また，合成系が外界と熱を交換せず，外界とのエネルギー交換が体系に加えられる仕事だけである場合，

```math
\boxed{A_{\mathrm{on}}=\Delta F+T\Delta S^*}
```

となる．

第二法則より $\Delta S^*\geq0$ であるから，一般には，

```math
\boxed{\Delta U^*\geq\Delta F,\qquad
A_{\mathrm{on}}\geq\Delta F}
```

が成立する．合成系全体が可逆的に変化する場合には $\Delta S^*=0$ となるため，これらの不等式は等式に変わる．

したがって，問題文の（i），（ii）の等式を成立させるためには，合成系全体が可逆的に変化するという条件が必要である．
元の問題文がその条件を明示していない場合，等式を無条件に主張することはできず，問題文に可逆性の条件を補う必要がある．
