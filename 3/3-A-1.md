# 演習問題【3-A-1】

## 解答

### (i) の証明

まず，体系（system）と，温度 $T^{(e)}$ を一定に保つ熱源（reservoir）を考える．
この熱源と体系を合わせたものを「合成系（composite system）」と呼ぶ．

体系の内部エネルギーを $U$ ，エントロピーを $S$ とする．
熱源の内部エネルギーを $U^{(e)}$ ，エントロピーを $S^{(e)}$ とする．

#### 1. 熱源に関する熱力学第一・第二法則

体系が一様な温度 $T$ を持つことは，系が熱平衡状態にあることを意味する．
したがって過程は準静的とみなせ，各状態は平衡状態として扱える．
この准静過程のもとでは，熱力学の定理をそのまま適用できる．

熱源から体系へ微小な熱量 $d'Q$ が供給される過程を考える．
熱源から体系へ $d'Q$ の熱が流出するため，熱源の内部エネルギーの変化 $dU^{(e)}$ とエントロピーの変化 $dS^{(e)}$ は次のように書ける．

$$dU^{(e)} = -d'Q \quad \dots (1)$$
$$dS^{(e)} = -\frac{d'Q}{T^{(e)}} \quad \dots (2)$$

ここで， $T^{(e)}$ は熱源の温度であり，問題の条件より一定である．
熱源は外界から仕事を受けないため，エントロピー変化は（2）で一意に定まる．
なお，式(2)を変形することで $d'Q = -T^{(e)} dS^{(e)}$ が得られる．

#### 2. 合成系の状態量

合成系の内部エネルギー $U^*$ とエントロピー $S^*$ は，両者の和として定義される．

$$U^* = U + U^{(e)}$$
$$S^* = S + S^{(e)}$$

#### 3. 合成系のエントロピー変化

合成系は外界から断熱されている（熱源は外界と接していない）．
**ここで重要なのは，過程が準静的であるため，両者の間の熱移動は可逆であり，合成系の全エントロピー変化は 0 となることである．**

$$dS^* = dS + dS^{(e)} = 0$$

これより，

$$dS^{(e)} = -dS \quad \dots (3)$$

が得られる．

> **注記** : 
  熱力学第二法則は本来 $dS^* \geq 0$ を与えるが，本問題では体系が一様な温度を持つため準静過程のみを考えればよい（系と熱源の間の変化が可逆）．
  したがって等号が成り立つ．

#### 4. 合成系の内部エネルギー変化の導出

合成系の内部エネルギーの変化 $dU^*$ は，

$$dU^* = dU + dU^{(e)}$$

式(1)より $dU^{(e)} = -d'Q$ であり，式(2)を変形して $d'Q = -T^{(e)} dS^{(e)}$ である．
これらを代入すると，

$$dU^{(e)} = T^{(e)} dS^{(e)}$$

したがって，

$$dU^* = dU + T^{(e)} dS^{(e)}$$

式(3)より $dS^{(e)} = -dS$ なので，

$$dU^* = dU - T^{(e)} dS \quad \dots (4)$$

#### 5. ヘルムホルツの自由エネルギーとの関係

問題の条件により，体系の温度 $T$ と熱源の温度 $T^{(e)}$ は等しい（ $T = T^{(e)}$ ）．
この関係を(4)に代入すると，

$$dU^* = dU - T\, dS \quad \dots (5)$$

ヘルムホルツの自由エネルギーは $F = U - TS$ と定義される．
その微小変化は，

$$dF = d(U - TS) = dU - T\, dS - S\, dT$$

(i) の問題文には体系の温度が一定であることは仮定されていないが，以下の議論により $dU^* = dF$ が導かれる．

$dU - T\, dS$ は， $T^{(e)}$ を固定パラメータとして見たときの関数 $U - T^{(e)} S$ の増し高 $d(U - T^{(e)} S)$ に等しい．
体系の温度 $T$ は常に $T^{(e)}$ に等しく保たれるとしているから，

$$d(U - T^{(e)} S) = d(U - TS) = dF$$

と書いてもさしつかえない．
したがって，

$$dU^* = dF \quad \dots (6)$$

が証明された．
つまり， **合成系の内部エネルギー変化は，体系の自由エネルギーの変化に等しい．**

> **補足（微分形と関数形の区別）** : 
  $dU^* = dF$ は微分形としての等価性を意味する．
  一般には $d'Q$ が過程（経路）に依存するため，関数形としては $F = U^* + C$ （ $C$ は定数） とは限らない．
  しかし，準静過程に限れば平衡状態間の対応が一義的となるため，加算定数を含めて $F = U^*$ と書いてもさしつかえない．

> **補足(ii)** :
  問題(ii)では「体系がその温度を一定に保ちながら」と明記されており，この場合は $dT = 0$ が仮定できる．
  その場合 $dF = dU - T\, dS$ がなりたち，(i) の結果と完全に一致する．

### (ii) の証明

体系がその温度を一定に保ちながら変化する場合を考える．

#### 1. 合成系への仕事の取り込み

合成系に対して熱力学第一法則を適用する．
合成系には外界から熱の供給はない（断熱）が，外界から体系に加えられる仕事 $d'A$ が与えられる．
したがって，合成系の内部エネルギー変化は仕事のみに等しい．

$$dU^* = d'A \quad \dots (7)$$

#### 2. 自由エネルギーの変化との関係

(ii) の条件「体系がその温度を一定に保ちながら」より， $dT = 0$ が成り立つ．
したがって，

$$dF = d(U - TS) = dU - T\, dS \quad (dT = 0)$$

(i) で得られた関係 $dU^* = dU - T\, dS$ と合わせると，

$$dU^* = dF$$

これを(7)に代入すると，

$$dF = d'A$$

が得られる．
これは， **体系が温度を一定に保ちながら変化するとき，体系が外界から受けとる仕事は自由エネルギーの増し高に等しい**ことを示している．

## 解説

### 1. ヘルムホルツの自由エネルギーとは？

自由エネルギー $F = U - TS$ は，ある温度 $T$ において系から「取り出すことができるエネルギー」を表す指標である．
内部エネルギー $U$ は系が持つ全エネルギーだが，その中には温度を維持するためにエントロピーを維持しなければならないエネルギー $TS$ が含まれている．
実際に仕事として取り出せるのは，その差である $F$ になる．

### 2. なぜ「合成系」を考えるのか？

熱力学の議論では，対象とする「体系」だけでなく周囲の環境（熱源など）とのやり取りを正確に記述する必要がある．
「熱源と体系を合わせたもの（合成系）」を一つの物体として捉えることで，「外界（熱源の外側）とのやり取り」を「熱の出入りなし，仕事のみ」というシンプルな形に整理できる．

### 3. 証明のポイント

- **(i) のポイント** :
  - 熱源のエントロピー変化と体系のエントロピー変化が逆向きになること（ $dS^{(e)} = -dS$ ）を利用して，合成系のエネルギー変化を体系の変数だけで書き直した．
  - **重要な点** : (i) では温度一定の仮定はないが，準静過程の仮定のもとで関数 $U - T^{(e)} S$ を導入し， $T = T^{(e)}$ の条件を用いて $dF$ と接続した．
  この中間ステップが本質的である．

- **(ii) のポイント** :
  - 第一法則において「熱の出入りがない」という条件を合成系の視点から「外部からの仕事のみを受ける」と言い換えた．
  - **(ii) では温度一定が明記されている** ため， $dT = 0$ が仮定でき，自由エネルギーの微小変化 $dF = dU - T\, dS$ が確定する．
