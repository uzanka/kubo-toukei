# 演習問題【3-A-13】

## 解答

### 1．理想混合気体の Helmholtz 自由エネルギー

それぞれ $n_1\ \mathrm{mol}$ ， $n_2\ \mathrm{mol}$ の2成分からなる理想混合気体を考える．
混合気体の温度を $T$ ，全体積を $V$ ，全圧力を $p$ とする．

まず，混合前の各成分の Helmholtz 自由エネルギーを考える．
成分 $i$ の Helmholtz 自由エネルギーは，理想気体の場合，

```math
F_i(T,V_i,n_i)
=n_i\Phi_i(T)-n_iRT\log\frac{V_i}{n_i}
\tag{1}
```

と表される．
ここで， $V_i$ は混合前に成分 $i$ が占めていた体積， $\Phi_i(T)$ は成分 $i$ のみに依存する温度の関数である．

混合前の各成分が占めていた体積は，物質量に比例して

```math
V_1=V\frac{n_1}{n_1+n_2},
\qquad
V_2=V\frac{n_2}{n_1+n_2}
\tag{2}
```

と表される．

理想混合気体の Helmholtz 自由エネルギーは，混合前の各成分の自由エネルギーと，混合によるエントロピー増加 $\Delta S$ を用いて，

```math
F(T,V,n_1,n_2)
=F_1(T,V_1,n_1)+F_2(T,V_2,n_2)-T\Delta S
\tag{3}
```

と書ける．
理想混合気体の混合エントロピーは，

```math
\Delta S=-R\left[
n_1\log\frac{n_1}{n_1+n_2}
+n_2\log\frac{n_2}{n_1+n_2}
\right]
\tag{4}
```

である．

### 2．混合エントロピーの項を整理する

式 (1)，(2) より，成分1については，

```math
\begin{aligned}
F_1(T,V_1,n_1)
&=n_1\Phi_1(T)
-n_1RT\log\frac{V_1}{n_1}\\
&=n_1\Phi_1(T)
-n_1RT\log\frac{V}{n_1+n_2}\\
&=n_1\Phi_1(T)
-n_1RT\log\frac{V}{n_1}\\
&\quad
-n_1RT\log\frac{n_1}{n_1+n_2}
\end{aligned}
\tag{5}
```

となる．
最後の変形では，

```math
\frac{V}{n_1+n_2}
=\frac{V}{n_1}\frac{n_1}{n_1+n_2}
```

を用いた．
同様に，成分2については，

```math
\begin{aligned}
F_2(T,V_2,n_2)
&=n_2\Phi_2(T)
-n_2RT\log\frac{V}{n_2}\\
&\quad
-n_2RT\log\frac{n_2}{n_1+n_2}
\end{aligned}
\tag{6}
```

となる．

一方，式 (4) より，

```math
\begin{aligned}
-T\Delta S
=RT\bigg[
&n_1\log\frac{n_1}{n_1+n_2}\\
&+n_2\log\frac{n_2}{n_1+n_2}
\bigg]
\end{aligned}
\tag{7}
```

である．

式 (5)，(6)，(7) を式 (3) に代入すると，混合前の体積の比に由来する対数項が相殺される．
したがって，

```math
\begin{aligned}
F(T,V,n_1,n_2)
={}&n_1\Phi_1(T)-n_1RT\log\frac{V}{n_1}\\
&+n_2\Phi_2(T)-n_2RT\log\frac{V}{n_2}
\end{aligned}
\tag{8}
```

を得る．
ここで，混合後の全体積 $V$ を用いた各成分の自由エネルギーを

```math
F_i(T,V,n_i)
=n_i\Phi_i(T)-n_iRT\log\frac{V}{n_i}
```

と定義すれば，

```math
\boxed{
F(T,V,n_1,n_2)
=F_1(T,V,n_1)+F_2(T,V,n_2)
}
\tag{9}
```

となる．
これが，理想混合気体の Helmholtz 自由エネルギーである．

### 3．Helmholtz 自由エネルギーから Gibbs 自由エネルギーを求める

Gibbs 自由エネルギーは，

```math
G=F+pV
\tag{10}
```

で定義される．
ここで，理想気体の状態方程式より，

```math
pV=(n_1+n_2)RT
\tag{11}
```

が成り立つ．

式 (9) を式 (10) に代入すると，

```math
G=F_1(T,V,n_1)+F_2(T,V,n_2)+pV
\tag{12}
```

となる．

次に，Gibbs 自由エネルギーを各成分の化学ポテンシャルで表す．
化学ポテンシャル $\mu_i$ は，温度と圧力を一定に保ち，他の成分の物質量も一定にしたときの Gibbs 自由エネルギーの物質量 $n_i$ に関する偏微分である．
すなわち，

```math
\mu_i=
\left(\frac{\partial G}{\partial n_i}\right)_{T,p,n_{j\ne i}}
\tag{13}
```

である．
Gibbs 自由エネルギーは示量性を持つため，Euler の関係から，

```math
G=n_1\mu_1+n_2\mu_2
\tag{14}
```

が成り立つ．
また， $G=F+pV$ と理想気体の状態方程式を用いると，式 (14) は

```math
G=n_1\left(\frac{\partial F}{\partial n_1}\right)_{T,V,n_2}
+n_2\left(\frac{\partial F}{\partial n_2}\right)_{T,V,n_1}
\tag{15}
```

とも書ける．
ここでは， $F$ を体積 $V$ 一定で偏微分している．

式 (8) を $n_1$ について偏微分すると，

```math
\begin{aligned}
\left(\frac{\partial F}{\partial n_1}\right)_{T,V,n_2}
&=\Phi_1(T)-RT\log\frac{V}{n_1}+RT\\
&=\Phi_1(T)+RT+RT\log\frac{n_1}{V}
\end{aligned}
\tag{16}
```

を得る．
最後の $RT$ は， $-n_1\log(V/n_1)$ を $n_1$ で微分したときに生じる項である．
同様に，

```math
\left(\frac{\partial F}{\partial n_2}\right)_{T,V,n_1}
=\Phi_2(T)+RT+RT\log\frac{n_2}{V}
\tag{17}
```

となる．

ここで，各成分の分圧 $p_i$ を

```math
p_1=\frac{n_1RT}{V},
\qquad
p_2=\frac{n_2RT}{V}
\tag{18}
```

と定義する．
すると，

```math
\frac{n_i}{V}=\frac{p_i}{RT}
```

であるから，式 (16)，(17) はそれぞれ，

```math
\left(\frac{\partial F}{\partial n_i}\right)_{T,V,n_{j\ne i}}
=\Phi_i(T)+RT+RT\log\frac{p_i}{RT}
\tag{19}
```

とまとめられる．

一方，純粋な理想気体 $i$ の Gibbs 自由エネルギーを $n_i$ で割った1 mol 当たりの値は，その気体の圧力を $p_i$ とすると，

```math
\bar G_i(T,p_i)
=\Phi_i(T)+RT+RT\log\frac{p_i}{RT}
\tag{20}
```

である．
したがって，式 (19) より，混合気体中の成分 $i$ の化学ポテンシャルは，

```math
\boxed{\mu_i=\bar G_i(T,p_i)}
\tag{21}
```

となる．
すなわち，混合気体中の各成分の化学ポテンシャルは，その成分が分圧 $p_i$ で存在する純粋な理想気体の1 mol 当たりの Gibbs 自由エネルギーに等しい．

式 (14) に式 (21) を代入すれば，求める Gibbs 自由エネルギーの公式は，

```math
\boxed{
G(T,p,n_1,n_2)
=n_1\bar G_1(T,p_1)+n_2\bar G_2(T,p_2)
}
\tag{22}
```

となる．
ここで， $p_1,p_2$ は各成分の分圧であり，理想気体の状態方程式から，

```math
p_1=p\frac{n_1}{n_1+n_2},
\qquad
p_2=p\frac{n_2}{n_1+n_2}
\tag{23}
```

と表される．
また，全圧 $p$ はドルトンの分圧の法則により，

```math
p=p_1+p_2
=\frac{(n_1+n_2)RT}{V}
\tag{24}
```

である．

### 4．標準圧力を用いた表現

標準圧力を $p_0$ とする．
理想気体の1 mol 当たりの Gibbs 自由エネルギーは，圧力に関して，

```math
\bar G_i(T,p_i)
=\bar G_i(T,p_0)+RT\log\frac{p_i}{p_0}
\tag{25}
```

と表される．
これを式 (22) に代入すると，

```math
\begin{aligned}
G={}&n_1\left[
\bar G_1(T,p_0)+RT\log\frac{p_1}{p_0}
\right]\\
&+n_2\left[
\bar G_2(T,p_0)+RT\log\frac{p_2}{p_0}
\right]
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\begin{aligned}
G={}&n_1\bar G_1(T,p_0)+n_2\bar G_2(T,p_0)\\
&+RT\left[
n_1\log\frac{p_1}{p_0}
+n_2\log\frac{p_2}{p_0}
\right]
\end{aligned}
}
\tag{26}
```

を得る．
これが，標準圧力を用いて表した Gibbs 自由エネルギーの公式である．

### 5．結論

2成分からなる理想混合気体の Gibbs 自由エネルギーは，

```math
\boxed{
G=n_1\bar G_1(T,p_1)+n_2\bar G_2(T,p_2)
}
```

で与えられる．
ここで， $p_i$ は成分 $i$ の分圧， $\bar G_i(T,p_i)$ は分圧 $p_i$ における純粋な理想気体 $i$ の1 mol 当たりの Gibbs 自由エネルギーである．

この結果は，理想混合気体では各成分の化学ポテンシャルがその分圧だけで決まることを示している．
また，標準圧力 $p_0$ を用いれば，式 (26) のように Gibbs 自由エネルギーを基準圧力での値と分圧による補正項に分けて表すことができる．
