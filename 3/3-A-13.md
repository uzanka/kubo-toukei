# 演習問題【3-A-13】

## 解答

本問題では，2成分からなる理想混合気体の Gibbs 自由エネルギーを導出する．

### 1. Helmholtz 自由エネルギー $F$ の構成

まず，混合前のそれぞれの成分（気体 1 および 気体 2）の Helmholtz 自由エネルギーを考える．
理想気体の Helmholtz 自由エネルギー $F_i$ は，温度 $T$ ，体積 $V_i$ ，物質量 $n_i$ を用いて次のように表される．

$$F_i(T, V_i, n_i) = n_i \Phi_i(T) - n_i R T \log\left(\frac{V_i}{n_i}\right) \quad \cdots \text{(A)}$$

ここで， $\Phi_i(T)$ は成分 $i$ の特性関数である．

次に，混合気体の全体積を $V$ ，各成分の物質量を $n_1, n_2$ とすると，混合前の各成分が占めていた体積 $V_1, V_2$ は，混合後の体積 $V$ を物質量の比で分配したものとみなせる（ドルトンの分圧の法則に基づく）．

$$V_1 = V \frac{n_1}{n_1 + n_2}, \quad V_2 = V \frac{n_2}{n_1 + n_2} \quad \cdots \text{(B)}$$

理想混合気体の Helmholtz 自由エネルギー $F$ は，各成分の自由エネルギーの和に，混合によって生じるエントロピー変化に伴う項を加えたものとして次のように書ける．

$$F(T, V, n_1, n_2) = F_1(T, V_1, n_1) + F_2(T, V_2, n_2) - T \Delta S \quad \cdots \text{(C)}$$

ここで， $\Delta S$ は混合によるエントロピーの増加であり，理想混合の場合，次のように与えられる．

```math
\Delta S = -R \left\{ n_1 \log\left(\frac{n_1}{n_1 + n_2}\right) + n_2 \log\left(\frac{n_2}{n_1 + n_2}\right) \right\} \quad \cdots \text{(D)}
```

式 (A) と (B) を式 (C) に代入して整理する．
まず，第1項について：

$$F_1(T, V_1, n_1) = n_1 \Phi_1(T) - n_1 R T \log\left(\frac{V_1}{n_1}\right) = n_1 \Phi_1(T) - n_1 R T \log\left(\frac{V}{n_1 + n_2}\right)$$

$$= n_1 \Phi_1(T) - n_1 R T \left[ \log\left(\frac{V}{n_1}\right) + \log\left(\frac{n_1}{n_1 + n_2}\right) \right]$$

$$= n_1 \Phi_1(T) - n_1 R T \log\left(\frac{V}{n_1}\right) - n_1 R T \log\left(\frac{n_1}{n_1 + n_2}\right)$$

同様に，第2項は：

$$F_2(T, V_2, n_2) = n_2 \Phi_2(T) - n_2 R T \log\left(\frac{V}{n_2}\right) - n_2 R T \log\left(\frac{n_2}{n_1 + n_2}\right)$$

これらを式 (C) に代入すると：

$$F = \left[ n_1 \Phi_1(T) - n_1 R T \log\left(\frac{V}{n_1}\right) - n_1 R T \log\left(\frac{n_1}{n_1 + n_2}\right) \right] + \left[ n_2 \Phi_2(T) - n_2 R T \log\left(\frac{V}{n_2}\right) - n_2 R T \log\left(\frac{n_2}{n_1 + n_2}\right) \right] - T \Delta S$$

ここで， $-T \Delta S$ の項は：

```math
-T \Delta S = R T \left\{ n_1 \log\left(\frac{n_1}{n_1 + n_2}\right) + n_2 \log\left(\frac{n_2}{n_1 + n_2}\right) \right\}
```

これを代入すると，F₁, F₂ の展開項から現れた $-n_i RT \log(n_i/(n_1+n_2))$ と， $-T\Delta S$ からの $+n_i RT \log(n_i/(n_1+n_2))$ が打ち消し合い，次のようになる．

$$F(T, V, n_1, n_2) = n_1 \Phi_1(T) - n_1 R T \log\left(\frac{V}{n_1}\right) + n_2 \Phi_2(T) - n_2 R T \log\left(\frac{V}{n_2}\right)$$

$$F(T, V, n_1, n_2) = F_1(T, V, n_1) + F_2(T, V, n_2) \quad \cdots \text{(E)}$$

### 2. Gibbs 自由エネルギー $G$ の導出

Gibbs 自由エネルギー $G$ は，Helmholtz 自由エネルギー $F$ と圧力 $p$ ，体積 $V$ を用いて $G = F + pV$ と定義される．

理想混合気体の全圧 $p$ は，理想気体の状態方程式より：

$$p = \frac{(n_1 + n_2) R T}{V} \quad \cdots \text{(F)}$$

これを用いて $G$ を展開する．

$$G = F_1(T, V, n_1) + F_2(T, V, n_2) + pV$$
$$= \left[ n_1 \Phi_1(T) - n_1 R T \log\left(\frac{V}{n_1}\right) \right] + \left[ n_2 \Phi_2(T) - n_2 R T \log\left(\frac{V}{n_2}\right) \right] + pV$$

ここで，分圧 $p_i$ は $p_i = \frac{n_i R T}{V}$ である．
これを用いると， $\log\left(\frac{V}{n_i}\right) = \log\left(\frac{n_i R T}{p_i}\right)^{-1} = \dots$ ではなく，直接 $\frac{V}{n_i} = \frac{R T}{p_i}$ であることに注目する．

$$G = n_1 \Phi_1(T) - n_1 R T \log\left(\frac{R T}{p_1}\right) + n_2 \Phi_2(T) - n_2 R T \log\left(\frac{R T}{p_2}\right) + pV$$
$$= n_1 \left[ \Phi_1(T) + R T \log\left(\frac{p_1}{R T}\right) \right] + n_2 \left[ \Phi_2(T) + R T \log\left(\frac{p_2}{R T}\right) \right] + pV \quad \cdots \text{(G)}$$

ここで， $pV = (n_1 + n_2)RT$ であり，後で定義する $\bar{G}_i$ に $+RT$ の項が含まれるため，この $pV$ は打ち消される．

ここで，純粋な成分 $i$ の Gibbs 自由エネルギー $\bar{G}_i(T, p_i)$ は， $n_i=1$ のときの $G$ に等しい．

$$\bar{G}_i(T, p_i) = \Phi_i(T) + RT + RT \log\left(\frac{p_i}{R T}\right)$$

これを用いると，式 (G) は次のように書ける．

$$G(T, p, n_1, n_2) = n_1 \bar{G}_1(T, p_1) + n_2 \bar{G}_2(T, p_2) \quad \cdots \text{(H)}$$

これが求める公式である．

### 3. 標準圧力を用いた表現

標準圧力 $p_0$ を導入すると，化学ポテンシャル $\bar{G}_i$ は次のように書ける．

$$\bar{G}_i(T, p_i) = \bar{G}_i(T, p_0) + R T \log\left(\frac{p_i}{p_0}\right)$$

これを式 (H) に代入すると，

$$G = n_1 \left[ \bar{G}_1(T, p_0) + R T \log\left(\frac{p_1}{p_0}\right) \right] + n_2 \left[ \bar{G}_2(T, p_0) + R T \log\left(\frac{p_2}{p_0}\right) \right]$$

$$G = n_1 \bar{G}_1(T, p_0) + n_2 \bar{G}_2(T, p_0) + R T \left( n_1 \log\frac{p_1}{p_0} + n_2 \log\frac{p_2}{p_0} \right)$$

となる．

## 解説

### 1.  理想混合気体とは

各成分が互いに影響を及ぼし合わず，かつ混合前後で体積が単純に加成的（あるいは分圧の法則が成り立つ）である状態を指す．

### 2.  エントロピー混合

異なる種類の粒子が混ざり合うことで，系の乱雑さ（エントロピー）が増大する現象．
この増加分 $\Delta S$ が，混合系の自由エネルギーを変化させる重要な要因となる．

### 3.  化学ポテンシャル $\mu_i$

物質 $i$ を 1 mol 加えたときの Gibbs 自由エネルギーの変化量

```math
\left(\frac{\partial G}{\partial n_i}\right)_{T, p, n_{j \neq i}}
```

．
混合系においては，各成分の分圧によって決まる $\bar{G}_i(T, p_i)$ がその成分の化学ポテンシャルとなる．

### 4.  ドルトンの分圧の法則

混合気体の全圧 $p$ は，各成分が単独で存在するときの圧力（分圧）の和に等しい．
