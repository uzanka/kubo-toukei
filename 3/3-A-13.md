# 演習問題【3-A-13】

## 解答

### 1．純粋な理想気体の Helmholtz 自由エネルギー

異なる2種類の化学種からなる理想気体混合物を考える．
各成分は相互作用を持たず，それぞれ独立した理想気体として振る舞うものとする．

成分 $i$ の物質量を $n_i$ ，体積を $V_i$ ，温度を $T4 とする．

Helmholtz 自由エネルギー $F_i$ について，

```math
dF_i=-S_i\,dT-p_i\,dV_i+\mu_i\,dn_i
```

が成立する．
したがって，

```math
\left(\frac{\partial F_i}{\partial V_i}\right)_{T,n_i}
=-p_i
```

である．

理想気体の状態方程式

```math
p_iV_i=n_iRT
```

を代入すると，

```math
\left(\frac{\partial F_i}{\partial V_i}\right)_{T,n_i}
=-\frac{n_iRT}{V_i}
```

となる．

これを $V_i$ について積分し，さらに Helmholtz 自由エネルギーの示量性を考慮すると，

```math
F_i(T,V_i,n_i)
=
n_i\Phi_i(T)
-n_iRT\log\frac{V_i}{n_iv^\circ}
\tag{1}
```

を得る．

ここで，

- $\Phi_i(T)$ は成分 $i$ に固有の温度関数であり，単位は $\mathrm{J/mol}$ である．
- $v^\circ$ は任意の正の基準モル体積である．

この基準モル体積を導入することで，

```math
\frac{V_i}{n_iv^\circ}
```

は無次元となり，対数の数学的な定義に問題がなくなる．

### 2．理想混合気体の Helmholtz 自由エネルギー

全物質量を

```math
N=n_1+n_2
```

とし，モル分率を

```math
x_1=\frac{n_1}{N},
\qquad
x_2=\frac{n_2}{N}
```

と定義する．

混合前に各成分が占める体積を，

```math
V_1=x_1V,\qquad V_2=x_2V
\tag{2}
```

とする．

このとき，

```math
V_1+V_2=V
```

である．
また，混合前の各成分の圧力は，

```math
p_1^{\mathrm{initial}}
=\frac{n_1RT}{V_1}
=\frac{NRT}{V}
```

```math
p_2^{\mathrm{initial}}
=\frac{n_2RT}{V_2}
=\frac{NRT}{V}
```

となり，等しい．

ここで，仕切りを取り除き，2成分を混合させる過程を考える．

理想気体では内部エネルギーは温度だけに依存する．
したがって，混合前後で温度と各成分の物質量が変化しなければ，

```math
\boxed{\Delta U_{\mathrm{mix}}=0}
```

となる．

一方，混合によって各成分は初期体積 $V_i$ から全体積 $V$ まで自由に広がる．

理想気体のエントロピー変化は，

```math
\Delta S_i=n_iR\log\frac{V}{V_i}
```

なので，全混合エントロピーは，

```math
\begin{aligned}
\Delta S_{\mathrm{mix}}
&=n_1R\log\frac{V}{V_1}
+n_2R\log\frac{V}{V_2}\\
&=-R\left(
n_1\log x_1+n_2\log x_2
\right).
\end{aligned}
```

したがって，

```math
\boxed{
\Delta S_{\mathrm{mix}}
=-R\sum_{i=1}^{2}n_i\log x_i
}
\tag{3}
```

となる．

Helmholtz 自由エネルギーの定義

```math
F=U-TS
```

より，混合による自由エネルギーの変化は，

```math
\Delta F_{\mathrm{mix}}
=
\Delta U_{\mathrm{mix}}
-T\Delta S_{\mathrm{mix}}
```

である．

ここで，

```math
\Delta U_{\mathrm{mix}}=0
```

なので，

```math
\Delta F_{\mathrm{mix}}
=-T\Delta S_{\mathrm{mix}}
```

となる．

したがって，混合後の Helmholtz 自由エネルギーは，

```math
F(T,V,n_1,n_2)
=
F_1(T,V_1,n_1)
+
F_2(T,V_2,n_2)
-T\Delta S_{\mathrm{mix}}
\tag{4}
```

と表される．

### 3．混合 Helmholtz 自由エネルギーの整理

式 (1)，（2）より，成分1について，

```math
\begin{aligned}
F_1(T,V_1,n_1)
={}&n_1\Phi_1(T)
-n_1RT\log\frac{x_1V}{n_1v^\circ}\\
={}&n_1\Phi_1(T)
-n_1RT\log\frac{V}{n_1v^\circ}\\
&-n_1RT\log x_1.
\end{aligned}
```

同様に，成分2について，

```math
\begin{aligned}
F_2(T,V_2,n_2)
={}&n_2\Phi_2(T)
-n_2RT\log\frac{V}{n_2v^\circ}\\
&-n_2RT\log x_2.
\end{aligned}
```

一方，式 (3) より，

```math
-T\Delta S_{\mathrm{mix}}
=
RT\left(n_1\log x_1+n_2\log x_2\right)
```

である．

したがって，式 (4) に代入すると，モル分率に由来する対数項が相殺される．

その結果，

```math
\boxed{
\begin{aligned}
F(T,V,n_1,n_2)
={}&n_1\Phi_1(T)
-n_1RT\log\frac{V}{n_1v^\circ}\\
&+n_2\Phi_2(T)
-n_2RT\log\frac{V}{n_2v^\circ}
\end{aligned}
}
\tag{5}
```

を得る．

一般に，

```math
\boxed{
F(T,V,n_1,n_2)
=
\sum_{i=1}^{2}
n_i\left[
\Phi_i(T)
-RT\log\frac{V}{n_iv^\circ}
\right]
}
\tag{6}
```

と表される．

これが理想混合気体の Helmholtz 自由エネルギーである．

### 4．Helmholtz 自由エネルギーから Gibbs 自由エネルギーへの変換

Gibbs 自由エネルギーは，

```math
G=F+pV
\tag{7}
```

と定義される．

理想混合気体の状態方程式は，

```math
pV=(n_1+n_2)RT=NRT
\tag{8}
```

である．

したがって，式 (6)，（8）を式 (7) に代入すると，

```math
\begin{aligned}
G
={}&\sum_{i=1}^{2}
n_i\left[
\Phi_i(T)-RT\log\frac{V}{n_iv^\circ}
\right]\\
&+NRT
\end{aligned}
```

となる．

ここで，

```math
NRT=\sum_{i=1}^{2}n_iRT
```

であることから，

```math
\boxed{
G=
\sum_{i=1}^{2}
n_i\left[
\Phi_i(T)+RT
-RT\log\frac{V}{n_iv^\circ}
\right]
}
\tag{9}
```

を得る．

次に，各成分の分圧を，

```math
\boxed{
p_i=\frac{n_iRT}{V}
}
\tag{10}
```

と定義する．

式 (10) より，

```math
\frac{V}{n_iv^\circ}
=
\frac{RT}{p_iv^\circ}
```

なので，

```math
-\log\frac{V}{n_iv^\circ}
=
\log\frac{p_iv^\circ}{RT}
```

となる．

したがって，式 (9) は，

```math
\boxed{
G=
\sum_{i=1}^{2}
n_i\left[
\Phi_i(T)+RT
+RT\log\frac{p_iv^\circ}{RT}
\right]
}
\tag{11}
```

と書ける．

### 5．化学ポテンシャルと純粋な理想気体の Gibbs 自由エネルギー

混合気体中の成分 $i$ の化学ポテンシャルは，

```math
\mu_i=
\left(\frac{\partial G}{\partial n_i}\right)_{T,p,n_{j\ne i}}
```

で定義される．

Helmholtz 自由エネルギーを用いると，

```math
\boxed{
\mu_i=
\left(\frac{\partial F}{\partial n_i}\right)_{T,V,n_{j\ne i}}
}
\tag{12}
```

とも表される．

この関係を確認する．

平衡体積を $V^*(T,p,n_1,n_2)$ とすると，

```math
G(T,p,n_1,n_2)
=
F(T,V^*,n_1,n_2)+pV^*
```

であり，

```math
\left(\frac{\partial F}{\partial V}\right)_{T,n_1,n_2}
=-p
```

が成立する．

したがって，温度と圧力を一定にして物質量を変化させると，

```math
\begin{aligned}
\left(\frac{\partial G}{\partial n_i}\right)_{T,p}
={}&
\left(\frac{\partial F}{\partial n_i}\right)_{T,V}\\
&+
\left[
\left(\frac{\partial F}{\partial V}\right)_{T,n_i}
+p
\right]
\left(\frac{\partial V^*}{\partial n_i}\right)_{T,p}
\end{aligned}
```

となる．

角括弧内は，

```math
-p+p=0
```

であるから，

```math
\left(\frac{\partial G}{\partial n_i}\right)_{T,p}
=
\left(\frac{\partial F}{\partial n_i}\right)_{T,V}
```

が得られる．

これにより，式 (12) が正当化される．

次に，式 (6) を $n_i$ について偏微分する．

```math
F_i
=
n_i\Phi_i(T)
-n_iRT\log\frac{V}{n_iv^\circ}
```

なので，

```math
\begin{aligned}
\left(\frac{\partial F}{\partial n_i}\right)_{T,V,n_j}
={}&\Phi_i(T)
-RT\log\frac{V}{n_iv^\circ}
+RT\\
={}&\Phi_i(T)+RT
+RT\log\frac{n_iv^\circ}{V}.
\end{aligned}
```

ここで，

```math
\frac{n_iv^\circ}{V}
=\frac{p_iv^\circ}{RT}
```

を用いると，

```math
\boxed{
\mu_i
=
\Phi_i(T)+RT
+RT\log\frac{p_iv^\circ}{RT}
}
\tag{13}
```

を得る．

一方，純粋な理想気体 $i$ のモル Helmholtz 自由エネルギーは，

```math
\bar F_i(T,v_i)
=
\Phi_i(T)-RT\log\frac{v_i}{v^\circ}
```

である．

したがって，そのモル Gibbs 自由エネルギーは，

```math
\bar G_i=\bar F_i+p_iv_i
```

であり，理想気体の状態方程式

```math
p_iv_i=RT,\qquad v_i=\frac{RT}{p_i}
```

を代入すると，

```math
\begin{aligned}
\bar G_i(T,p_i)
&=\Phi_i(T)
-RT\log\frac{RT}{p_iv^\circ}
+RT\\
&=\Phi_i(T)+RT
+RT\log\frac{p_iv^\circ}{RT}.
\end{aligned}
```

したがって，

```math
\boxed{
\mu_i=\bar G_i(T,p_i)
}
\tag{14}
```

となる．

すなわち，理想混合気体中の各成分の化学ポテンシャルは，その成分が分圧で存在する純粋な理想気体のモル Gibbs 自由エネルギーに等しい．

### 6．Euler の関係式による Gibbs 自由エネルギーの導出

式 (6) の Helmholtz 自由エネルギーは，

```math
F(T,\lambda V,\lambda n_1,\lambda n_2)
=
\lambda F(T,V,n_1,n_2)
```

を満たす．

すなわち，温度を一定にして体積と各成分の物質量を同じ倍率で変化させると，Helmholtz 自由エネルギーも同じ倍率で変化する．

したがって，Euler の定理から，

```math
F
=
V\left(\frac{\partial F}{\partial V}\right)_{T,n_1,n_2}
+n_1\left(\frac{\partial F}{\partial n_1}\right)_{T,V,n_2}
+n_2\left(\frac{\partial F}{\partial n_2}\right)_{T,V,n_1}
```

が成立する．

ここで，

```math
\left(\frac{\partial F}{\partial V}\right)_{T,n_1,n_2}
=-p
```

および，

```math
\left(\frac{\partial F}{\partial n_i}\right)_{T,V,n_j}
=\mu_i
```

なので，

```math
F=-pV+n_1\mu_1+n_2\mu_2
```

となる．

両辺に $pV$ を加えると，

```math
\boxed{
G=n_1\mu_1+n_2\mu_2
}
\tag{15}
```

を得る．

式 (14) を代入すると，

```math
\boxed{
G(T,p,n_1,n_2)
=
n_1\bar G_1(T,p_1)
+n_2\bar G_2(T,p_2)
}
\tag{16}
```

となる．

これが求める理想混合気体の Gibbs 自由エネルギーの公式である．

### 7．標準圧力を用いた表現

標準圧力を $p^\circ$ とする．

純粋な理想気体のモル Gibbs 自由エネルギーについて，

```math
\left(\frac{\partial\bar G_i}{\partial p_i}\right)_T
=\bar V_i
```

であり，理想気体の状態方程式から，

```math
\bar V_i=\frac{RT}{p_i}
```

となる．

したがって，

```math
d\bar G_i=RT\frac{dp_i}{p_i}
```

である．

これを標準圧力 $p^\circ$ から分圧 $p_i$ まで積分すると，

```math
\boxed{
\bar G_i(T,p_i)
=
\bar G_i(T,p^\circ)
+RT\log\frac{p_i}{p^\circ}
}
\tag{17}
```

を得る．

これを式 (16) に代入すると，

```math
\begin{aligned}
G
={}&n_1\left[
\bar G_1(T,p^\circ)
+RT\log\frac{p_1}{p^\circ}
\right]\\
&+n_2\left[
\bar G_2(T,p^\circ)
+RT\log\frac{p_2}{p^\circ}
\right].
\end{aligned}
```

したがって，

```math
\boxed{
\begin{aligned}
G={}&n_1\bar G_1(T,p^\circ)
+n_2\bar G_2(T,p^\circ)\\
&+RT\left[
n_1\log\frac{p_1}{p^\circ}
+n_2\log\frac{p_2}{p^\circ}
\right]
\end{aligned}
}
\tag{18}
```

となる．

ここで，ドルトンの分圧の法則より，

```math
p=p_1+p_2
```

であり，

```math
p_i=x_ip,\qquad
x_i=\frac{n_i}{n_1+n_2}
```

なので，

```math
\boxed{
\begin{aligned}
G={}&n_1\bar G_1(T,p^\circ)
+n_2\bar G_2(T,p^\circ)\\
&+RT\left[
n_1\log\frac{x_1p}{p^\circ}
+n_2\log\frac{x_2p}{p^\circ}
\right].
\end{aligned}
}
\tag{19}
```

これが標準圧力を用いた Gibbs 自由エネルギーの公式である．

### 8．独立した検算

#### 8.1 圧力微分の検算

式 (19) を全圧 $p$ で偏微分すると，

```math
\begin{aligned}
\left(\frac{\partial G}{\partial p}\right)_{T,n_1,n_2}
&=\frac{RT}{p}(n_1+n_2)\\
&=\frac{NRT}{p}.
\end{aligned}
```

理想気体の状態方程式より，

```math
V=\frac{NRT}{p}
```

なので，

```math
\boxed{
\left(\frac{\partial G}{\partial p}\right)_{T,n_1,n_2}
=V
}
```

となる．

Gibbs 自由エネルギーの基本関係式と一致する．

#### 8.2 化学ポテンシャルの検算

式 (19) を $n_i$ で偏微分すると，

```math
\boxed{
\mu_i=
\bar G_i(T,p^\circ)
+RT\log\frac{x_ip}{p^\circ}
}
```

となる．

これは式 (14)，（17）から得られる，

```math
\mu_i=\bar G_i(T,p_i)
```

と一致する．

したがって，化学ポテンシャルの導出にも矛盾はない．

#### 8.3 混合 Gibbs 自由エネルギーの符号

混合前は，各成分が同じ温度・全圧力 $p$ で純粋に存在していたとする．

混合後は，

```math
p_i=x_ip
```

となるので，

```math
\begin{aligned}
\Delta G_{\mathrm{mix}}
&=G_{\mathrm{mix}}-G_{\mathrm{before}}\\
&=RT\sum_{i=1}^{2}
n_i\log\frac{p_i}{p}\\
&=RT\sum_{i=1}^{2}n_i\log x_i.
\end{aligned}
```

異なる2成分がともに存在する場合，

```math
0<x_i<1
```

なので，

```math
\boxed{\Delta G_{\mathrm{mix}}<0}
```

となる．

これは理想気体の混合が自発的に進むという物理的性質と整合する．

#### 8.4 成分がゼロになる極限

一方の成分の物質量がゼロに近づく場合，

```math
x_i\to0^+
```

となる．

このとき，

```math
\lim_{x\to0^+}x\log x=0
```

なので，混合自由エネルギーの各成分の寄与は適切な極限を持つ．

化学ポテンシャルそのものは，

```math
\mu_i\sim RT\log x_i\to-\infty
```

となるが，その成分の自由エネルギーへの寄与 $n_i\mu_i$ はゼロに収束する．

これは理想気体混合物の正しい極限挙動である．

### 9．最終結果

- 分圧による Gibbs 自由エネルギー

```math
\boxed{
G=n_1\bar G_1(T,p_1)
+n_2\bar G_2(T,p_2)
}
```


- 標準圧力を用いた Gibbs 自由エネルギー

```math
\boxed{
\begin{aligned}
G={}&n_1\bar G_1(T,p^\circ)
+n_2\bar G_2(T,p^\circ)\\
&+RT\left[
n_1\log\frac{p_1}{p^\circ}
+n_2\log\frac{p_2}{p^\circ}
\right]
\end{aligned}
}
```


- 分圧とモル分率の関係

```math
\boxed{
p_i=x_ip,\qquad
x_i=\frac{n_i}{n_1+n_2}
}
```


- 混合 Gibbs 自由エネルギー

```math
\boxed{
\Delta G_{\mathrm{mix}}
=RT\sum_{i=1}^{2}n_i\log x_i<0
}
```
