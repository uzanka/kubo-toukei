# 演習問題【3-A-14】

## 解答

### 1．ヘルムホルツ自由エネルギーと熱力学的関係式

ゴム糸の状態が絶対温度 $T$ と長さ $l$ によって定まるものとし，ヘルムホルツ自由エネルギーを $F(T,l)$ とする．
ゴム糸を微小な長さ $dl$ だけ伸ばすために外部が系にする仕事を $d'W=X\,dl$ と定義すると，熱力学の基本関係式は

```math
dU=T\,dS+X\,dl
```

である．
ここで， $U$ は内部エネルギー， $S$ はエントロピー， $X$ はゴム糸の張力である．

ヘルムホルツ自由エネルギーは

```math
F=U-TS
```

と定義される．
これを微分すると，

```math
dF=dU-T\,dS-S\,dT
```

となる．
ここに $dU=T\,dS+X\,dl$ を代入すると，

```math
dF=-S\,dT+X\,dl
```

を得る．
一方， $F$ を $T,l$ の関数とみなせば，

```math
dF=
\left(\frac{\partial F}{\partial T}\right)_l dT
+\left(\frac{\partial F}{\partial l}\right)_T dl
```

である．
この2つの式を比較することにより，

```math
\boxed{
S=-\left(\frac{\partial F}{\partial T}\right)_l
}
\tag{1}
```

および

```math
\boxed{
X=\left(\frac{\partial F}{\partial l}\right)_T
}
\tag{2}
```

が得られる．
これらは，エントロピーと張力をヘルムホルツ自由エネルギーの偏微分で表す関係式である．

また， $F=U-TS$ より $U=F+TS$ である．
式 (1) を用いると，

```math
\boxed{
U=F-T\left(\frac{\partial F}{\partial T}\right)_l
}
\tag{3}
```

となる．

### 2．内部エネルギーが長さに依存しないことの証明

問題の条件より，長さ $l$ を一定に保って張力を測定すると，

```math
X=AT,\qquad A>0
\tag{4}
```

が成り立つ．
ここで， $A$ は長さ $l$ によって決まる定数である．
したがって，長さを固定した温度微分は

```math
\left(\frac{\partial X}{\partial T}\right)_l=A
\tag{5}
```

となる．

次に，式 (3) を長さ $l$ について偏微分する．
温度 $T$ を一定に保つと，

```math
\left(\frac{\partial U}{\partial l}\right)_T
=
\left(\frac{\partial F}{\partial l}\right)_T
-T\frac{\partial}{\partial l}
\left(\frac{\partial F}{\partial T}\right)_l
\tag{6}
```

である．
ここで， $F$ が十分滑らかであり，混合偏微分の順序を交換できると仮定すると，

```math
\frac{\partial}{\partial l}
\left(\frac{\partial F}{\partial T}\right)_l
=
\frac{\partial}{\partial T}
\left(\frac{\partial F}{\partial l}\right)_T
=
\left(\frac{\partial X}{\partial T}\right)_l
```

となる．
また，式 (2) より $\left(\partial F/\partial l\right)_T=X$ であるから，式 (6) は

```math
\boxed{
\left(\frac{\partial U}{\partial l}\right)_T
=X-T\left(\frac{\partial X}{\partial T}\right)_l
}
\tag{7}
```

と書ける．
これに式 (4)，(5) を代入すると，

```math
\begin{aligned}
\left(\frac{\partial U}{\partial l}\right)_T
&=AT-TA\\
&=0
\end{aligned}
```

を得る．
すなわち，

```math
\boxed{
\left(\frac{\partial U}{\partial l}\right)_T=0
}
\tag{8}
```

である．
これは，温度を一定にしたとき，長さを変化させても内部エネルギーが変化しないことを意味する．
系の状態変数が $T,l$ であるため，内部エネルギーは長さに依存せず，

```math
\boxed{
U=U(T)
}
```

と表される．
したがって，内部エネルギーは温度だけの関数であることが示された．

### 3．エントロピーが長さとともに減少することの証明

次に，エントロピー $S$ の長さ依存性を調べる．
式 (1) を長さ $l$ について，温度 $T$ を一定に保って偏微分すると，

```math
\left(\frac{\partial S}{\partial l}\right)_T
=-\frac{\partial}{\partial l}
\left(\frac{\partial F}{\partial T}\right)_l
\tag{9}
```

となる．
ここで，先ほどと同様に混合偏微分の順序を交換し，式 (2) を用いると，

```math
\begin{aligned}
\left(\frac{\partial S}{\partial l}\right)_T
&=-\frac{\partial}{\partial T}
\left(\frac{\partial F}{\partial l}\right)_T\\
&=-\left(\frac{\partial X}{\partial T}\right)_l
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
\left(\frac{\partial S}{\partial l}\right)_T
=-\left(\frac{\partial X}{\partial T}\right)_l
}
\tag{10}
```

である．
式 (5) より $\left(\partial X/\partial T\right)_l=A$ であるから，

```math
\boxed{
\left(\frac{\partial S}{\partial l}\right)_T=-A<0
}
\tag{11}
```

となる．

この偏微分が負であることは，温度を一定に保ってゴム糸の長さを増加させると，エントロピーが減少することを意味する．
よって，

```math
\boxed{
\text{エントロピー }S\text{ は，長さ }l\text{ の増大とともに減少する}
}
```

ことが示された．

### 4．物理的な解釈と理想気体との類似

本問の結果は，理想気体の内部エネルギーが体積ではなく温度だけに依存するという性質と類似している．
理想気体では，

```math
\left(\frac{\partial U}{\partial V}\right)_T=0
```

が成り立つ．
本問のゴム糸でも同様に，

```math
\left(\frac{\partial U}{\partial l}\right)_T=0
```

となる．
すなわち，いずれも温度を一定に保ったとき，それぞれの力学的な変数を変化させても内部エネルギーは変化しない．

一方，エントロピーの変化の向きは異なる．
理想気体では，温度一定のもとで体積が増加するとエントロピーは増加するが，本問のゴム糸では長さが増加するとエントロピーは減少する．
ゴムを伸ばすと高分子鎖の取り得る配置が制限され，分子鎖の配向に関する乱雑さが減少するという微視的な描像は，この結果と整合的である．
ただし，この分子レベルの説明は熱力学的な導出そのものとは区別されるべき解釈である．

以上より，張力が $X=AT$ ， $A>0$ に従うゴム糸について，内部エネルギーは温度だけの関数であり，エントロピーは長さの増大とともに減少することが証明された．
