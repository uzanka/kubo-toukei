# 演習問題【3-A-3】

## 解答

# 1．断熱温度係数 $\chi_s$ の導出

断熱準静的過程では，エントロピー $S$ が一定に保たれる．
このとき，温度 $T$ の圧力 $p$ に対する変化率を断熱温度係数といい，

```math
\chi_s=\left(\frac{\partial T}{\partial p}\right)_S
```

と定義する．
この $\chi_s$ を定圧体膨張係数 $\alpha$ と定圧熱容量 $C_p$ を用いて表すことが目標である．

## 1.1．ヤコビアンによる偏微分の変換

ヤコビアンを用いると，断熱温度係数は

```math
\chi_s
=\left(\frac{\partial T}{\partial p}\right)_S
=\frac{\partial(T,S)}{\partial(p,S)}
\tag{1}
```

と表される．
ここで，ヤコビアンの連鎖律を用いて，分子と分母に同じ変数 $(T,p)$ に関するヤコビアンを導入すると，

```math
\frac{\partial(T,S)}{\partial(p,S)}
=
\frac{
\displaystyle\frac{\partial(T,S)}{\partial(T,p)}
}{
\displaystyle\frac{\partial(p,S)}{\partial(T,p)}
}
\tag{2}
```

となる．

それぞれのヤコビアンを計算すると，

```math
\frac{\partial(T,S)}{\partial(T,p)}
=
\begin{vmatrix}
1&0\\
\left(\frac{\partial S}{\partial T}\right)_p&
\left(\frac{\partial S}{\partial p}\right)_T
\end{vmatrix}
=
\left(\frac{\partial S}{\partial p}\right)_T
\tag{3}
```

である．
また，

```math
\frac{\partial(p,S)}{\partial(T,p)}
=
\begin{vmatrix}
0&1\\
\left(\frac{\partial S}{\partial T}\right)_p&
\left(\frac{\partial S}{\partial p}\right)_T
\end{vmatrix}
=
-\left(\frac{\partial S}{\partial T}\right)_p
\tag{4}
```

である．

式（3），（4）を式（1），（2）に代入すると，

```math
\chi_s
=-\frac{
\left(\frac{\partial S}{\partial p}\right)_T
}{
\left(\frac{\partial S}{\partial T}\right)_p
}
\tag{5}
```

を得る．

## 1.2．Maxwellの関係式の適用

式（5）に現れる $\left(\frac{\partial S}{\partial p}\right)_T$ を求めるため，Maxwellの関係式を用いる．

Gibbsの自由エネルギー $G=H-TS$ の微分は，

```math
dG=-S\,dT+V\,dp
\tag{6}
```

である．
したがって， $G$ を温度 $T$ と圧力 $p$ の関数とみなすと，

```math
S=-\left(\frac{\partial G}{\partial T}\right)_p,
\qquad
V=\left(\frac{\partial G}{\partial p}\right)_T
\tag{7}
```

となる．
混合二階偏微分の順序を交換できることから，

```math
\boxed{
\left(\frac{\partial S}{\partial p}\right)_T
=-\left(\frac{\partial V}{\partial T}\right)_p
}
\tag{8}
```

が得られる．
これが本問で用いるMaxwellの関係式である．

一方，定圧熱容量 $C_p$ は，

```math
C_p=T\left(\frac{\partial S}{\partial T}\right)_p
\tag{9}
```

と定義されるため，

```math
\left(\frac{\partial S}{\partial T}\right)_p
=\frac{C_p}{T}
\tag{10}
```

である．

式（8），（10）を式（5）に代入すると，

```math
\begin{aligned}
\chi_s
&=-\frac{
-\left(\frac{\partial V}{\partial T}\right)_p
}{
C_p/T
}\\
&=\frac{T}{C_p}
\left(\frac{\partial V}{\partial T}\right)_p
\end{aligned}
\tag{11}
```

となる．

ここで，定圧体膨張係数 $\alpha$ は，

```math
\alpha=\frac{1}{V}
\left(\frac{\partial V}{\partial T}\right)_p
\tag{12}
```

と定義される．
よって，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=V\alpha
\tag{13}
```

である．
式（13）を式（11）に代入すれば，

```math
\boxed{\chi_s=\frac{TV\alpha}{C_p}}
\tag{14}
```

を得る．
これが求める断熱温度係数である．

# 2．圧力一定のもとで準静的に膨張するときのエントロピーの増し高

次に，圧力 $p$ を一定に保ちながら，体系を準静的に膨張させる場合を考える．
このときのエントロピー変化を，先ほど求めた断熱温度係数 $\chi_s$ を用いて表す．

圧力 $p$ と体積 $V$ を独立変数としてエントロピーを $S=S(p,V)$ とみなすと，全微分は

```math
dS=
\left(\frac{\partial S}{\partial p}\right)_Vdp
+\left(\frac{\partial S}{\partial V}\right)_pdV
\tag{15}
```

である．
圧力一定の条件では $dp=0$ であるから，

```math
dS=\left(\frac{\partial S}{\partial V}\right)_pdV
\tag{16}
```

となる．
したがって， $\left(\frac{\partial S}{\partial V}\right)_p$ を求めればよい．

## 2.1．エントロピーの体積微分

エントロピーを $S=S(T,p)$ とみなし，圧力 $p$ を一定に保って連鎖律を適用すると，

```math
\left(\frac{\partial S}{\partial V}\right)_p
=
\left(\frac{\partial S}{\partial T}\right)_p
\left(\frac{\partial T}{\partial V}\right)_p
\tag{17}
```

である．

式（9）より，

```math
\left(\frac{\partial S}{\partial T}\right)_p
=\frac{C_p}{T}
\tag{18}
```

である．
また，式（12），（13）より，

```math
\left(\frac{\partial T}{\partial V}\right)_p
=\frac{1}{
\left(\frac{\partial V}{\partial T}\right)_p
}
=\frac{1}{V\alpha}
\tag{19}
```

となる．

式（18），（19）を式（17）に代入すると，

```math
\left(\frac{\partial S}{\partial V}\right)_p
=\frac{C_p}{T}\frac{1}{V\alpha}
=\frac{C_p}{TV\alpha}
\tag{20}
```

を得る．

一方，式（14）より，

```math
\chi_s=\frac{TV\alpha}{C_p}
```

であるから，

```math
\boxed{
\left(\frac{\partial S}{\partial V}\right)_p
=\frac{1}{\chi_s}
}
\tag{21}
```

となる．

## 2.2．エントロピーの増し高

式（21）を式（16）に代入すると，

```math
\boxed{
dS=\frac{1}{\chi_s}\,dV
}
\tag{22}
```

が得られる．
したがって，圧力一定のもとで体積が微小量 $dV$ だけ増加したとき，エントロピーの微小な増し高は $dV/\chi_s$ である．

体積が有限の量だけ $V_1$ から $V_2$ まで変化する場合には，式（22）を積分して，

```math
\boxed{
S_2-S_1
=\int_{V_1}^{V_2}
\frac{1}{\chi_s(p,V)}\,dV
}
\tag{23}
```

となる．
ここでは圧力 $p$ を一定に保つ．
一般に $\chi_s$ は温度や体積に依存するため，有限変化に対して単純に $\Delta S=\Delta V/\chi_s$ と書けるとは限らない．
ただし，変化の範囲で $\chi_s$ が一定とみなせる場合には，

```math
\Delta S=\frac{V_2-V_1}{\chi_s}
\tag{24}
```

と表すことができる．

以上により，断熱温度係数と，圧力一定のもとでのエントロピーの増し高が求められた．
