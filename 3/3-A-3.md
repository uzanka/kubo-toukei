# 演習問題【3-A-3】

## 解答

### 1．断熱温度係数 $\chi_s$ の導出

#### 1.1．前提と適用条件

組成および物質量が一定の単純圧縮系を考える．
系は単一相の平衡状態にあり，状態量 $T,p,V,S$ は必要な次数まで微分可能であるとする．
また，温度は $T>0$ ，体積は $V>0$ ，定圧熱容量は有限かつ正の値 $C_p>0$ をとるものとする．
ここでは，エントロピー $S$ ，体積 $V$ ，熱容量 $C_p$ はすべて全量で統一する．

断熱準静的過程が等エントロピー過程となるのは，内部可逆である場合である．
したがって，断熱温度係数を導出する際には，内部可逆な断熱準静的過程を考える．

断熱温度係数は，等エントロピー条件の下での温度の圧力に対する変化率として，

```math
\chi_s=\left(\frac{\partial T}{\partial p}\right)_S
```

と定義される．
この $\chi_s$ を，定圧体膨張係数 $\alpha$ と定圧熱容量 $C_p$ を用いて表す．

#### 1.2．ヤコビアンによる偏微分の変換

ヤコビアンを用いると，

```math
\chi_s
=\left(\frac{\partial T}{\partial p}\right)_S
=\frac{\partial(T,S)}{\partial(p,S)}
\tag{1}
```

と表される．

ヤコビアンの連鎖律より，

```math
\frac{\partial(T,S)}{\partial(p,S)}
=
\frac{
\displaystyle\frac{\partial(T,S)}{\partial(T,p)}
}{
\displaystyle\frac{\partial(p,S)}{\partial(T,p)}
}
\tag{2}
```

となる．

分子のヤコビアンは，

```math
\begin{aligned}
\frac{\partial(T,S)}{\partial(T,p)}
&=
\begin{vmatrix}
1&0\\
\left(\dfrac{\partial S}{\partial T}\right)_p&
\left(\dfrac{\partial S}{\partial p}\right)_T
\end{vmatrix}\\
&=
\left(\frac{\partial S}{\partial p}\right)_T
\end{aligned}
\tag{3}
```

である．

また，分母のヤコビアンは，

```math
\begin{aligned}
\frac{\partial(p,S)}{\partial(T,p)}
&=
\begin{vmatrix}
0&1\\
\left(\dfrac{\partial S}{\partial T}\right)_p&
\left(\dfrac{\partial S}{\partial p}\right)_T
\end{vmatrix}\\
&=
-\left(\frac{\partial S}{\partial T}\right)_p
\end{aligned}
\tag{4}
```

である．

式（3），（4）を式（1），（2）に代入すると，

```math
\chi_s
=-\frac{
\left(\dfrac{\partial S}{\partial p}\right)_T
}{
\left(\dfrac{\partial S}{\partial T}\right)_p
}
\tag{5}
```

を得る．
ここで，分母がゼロでないことは，

```math
\left(\frac{\partial S}{\partial T}\right)_p
=\frac{C_p}{T}>0
```

によって保証される．

#### 1.3．Maxwellの関係式の適用

Gibbsの自由エネルギーを

```math
G=H-TS
```

と定義する．
組成および物質量一定の単純圧縮系では，

```math
dG=-S\,dT+V\,dp
\tag{6}
```

である．
したがって，

```math
S=-\left(\frac{\partial G}{\partial T}\right)_p,
\qquad
V=\left(\frac{\partial G}{\partial p}\right)_T
\tag{7}
```

となる．

Gibbs自由エネルギーの混合二階偏微分の順序を交換できることから，

```math
\boxed{
\left(\frac{\partial S}{\partial p}\right)_T
=-\left(\frac{\partial V}{\partial T}\right)_p
}
\tag{8}
```

が得られる．
これが本問で用いるMaxwellの関係式である．

一方，定圧熱容量 $C_p$ は，

```math
C_p=T\left(\frac{\partial S}{\partial T}\right)_p
\tag{9}
```

と定義されるため，

```math
\left(\frac{\partial S}{\partial T}\right)_p
=\frac{C_p}{T}
\tag{10}
```

である．

式（8），（10）を式（5）に代入すると，

```math
\begin{aligned}
\chi_s
&=-\frac{
-\left(\dfrac{\partial V}{\partial T}\right)_p
}{
C_p/T
}\\
&=\frac{T}{C_p}
\left(\frac{\partial V}{\partial T}\right)_p
\end{aligned}
\tag{11}
```

となる．

ここで，定圧体膨張係数 $\alpha$ は，

```math
\alpha=\frac{1}{V}
\left(\frac{\partial V}{\partial T}\right)_p
\tag{12}
```

と定義される．
したがって，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=V\alpha
\tag{13}
```

である．

式（13）を式（11）に代入すれば，

```math
\boxed{
\chi_s=\frac{TV\alpha}{C_p}
}
\tag{14}
```

を得る．
これが求める断熱温度係数である．

### 2．圧力一定のもとで準静的に膨張するときのエントロピー変化

次に，圧力 $p$ を一定に保ちながら，体系を準静的に膨張させる場合を考える．
この過程は断熱過程とは限らない．
各状態が平衡状態として記述できるものとし，エントロピー変化を状態量の変化として求める．

#### 2.1．定圧過程におけるエントロピー変化

定圧条件 $dp=0$ の下では，エントロピーの全微分は，

```math
dS=
\left(\frac{\partial S}{\partial T}\right)_p dT
\tag{15}
```

となる．
式（9）より，

```math
\boxed{
dS=\frac{C_p}{T}\,dT
}
\qquad(dp=0)
\tag{16}
```

を得る．

一方，体積の全微分も，定圧条件では，

```math
dV=
\left(\frac{\partial V}{\partial T}\right)_p dT
\tag{17}
```

である．
定圧体膨張係数の定義から，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=V\alpha
```

なので，

```math
dV=V\alpha\,dT
\tag{18}
```

となる．

ここで， $\alpha\ne0$ である状態を考えると，式（18）より，

```math
dT=\frac{1}{V\alpha}\,dV
\tag{19}
```

である．
式（19）を式（16）に代入すると，

```math
\begin{aligned}
dS
&=\frac{C_p}{T}\frac{1}{V\alpha}\,dV\\
&=\frac{C_p}{TV\alpha}\,dV
\end{aligned}
\tag{20}
```

となる．

一方，式（14）より，

```math
\chi_s=\frac{TV\alpha}{C_p}
```

であるから，

```math
\boxed{
dS=\frac{1}{\chi_s}\,dV
}
\qquad(\alpha\ne0)
\tag{21}
```

を得る．
したがって，定圧過程におけるエントロピーの微小変化は，断熱温度係数を用いて表すことができる．

なお， $\alpha\ne0$ であれば，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=V\alpha\ne0
```

であるため，逆関数定理により，定圧経路上で温度 $T$ を体積 $V$ の微分可能な関数として局所的に表すことができる．
したがって，この条件の下では，

```math
\left(\frac{\partial S}{\partial V}\right)_p
=\frac{1}{\chi_s}
```

という偏微分表示も正当化される．

#### 2.2．エントロピーの有限変化

圧力 $p$ を一定に保ち，体積が $V_1$ から $V_2$ まで変化する場合を考える．
経路全体で $\alpha\ne0$ が成り立つとき，式（21）を積分して，

```math
\boxed{
S_2-S_1
=
\int_{V_1}^{V_2}
\frac{1}{\chi_s(p,V)}\,dV
}
\tag{22}
```

を得る．
ここでは積分中，圧力 $p$ は一定である．

一般に $\chi_s$ は状態に依存するため，有限変化に対して単純に

```math
\Delta S=\frac{V_2-V_1}{\chi_s}
```

とは書けない．
ただし，変化の範囲で $\chi_s$ が一定である場合には，

```math
\boxed{
\Delta S=\frac{V_2-V_1}{\chi_s}
}
\tag{23}
```

となる．
$\chi_s$ がほぼ一定とみなせる場合には，この式を近似式として用いることができる．

#### 2.3．$\alpha=0$ となる場合

$\alpha=0$ となる状態では，式（14）より，

```math
\chi_s=0
```

であるため，式（21）のように $1/\chi_s$ を用いる表現は適用できない．

この場合， $\alpha=0$ であることから，

```math
\left(\frac{\partial V}{\partial T}\right)_p=0
```

となる．
このとき逆関数定理の条件は満たされず，微分可能な逆関数 $T=T(p,V)$ の存在や，有限な値を持つ

```math
\left(\frac{\partial T}{\partial V}\right)_p
```

は一般には保証されない．
ただし，逆関数そのものが存在しないとは限らない．
例えば，微分係数がゼロとなる点でも，元の関数が単調であれば逆関数自体は存在し得る．

したがって， $\alpha=0$ の状態を含む定圧経路では，体積 $V$ をパラメータとする式（21），（22）を一般式として使用することはできない．
その場合には，式（16）に戻り，

```math
\boxed{
S_2-S_1
=
\int_{T_1}^{T_2}
\frac{C_p(p,T)}{T}\,dT
}
\tag{24}
```

を用いる．
この式は，定圧経路上で $C_p$ が定義され，積分が存在する限り，途中で $\alpha=0$ となる場合にも適用できる．

### 3．エントロピー変化の符号

式（14）より，

```math
\chi_s=\frac{TV\alpha}{C_p}
```

である．
通常の安定な平衡状態では $T>0$ ， $V>0$ ， $C_p>0$ であるため， $\chi_s$ の符号は $\alpha$ の符号と一致する．

したがって， $\alpha>0$ の物質では，

```math
dV>0
\quad\Longrightarrow\quad
dS>0
```

となり，定圧膨張に伴ってエントロピーは増加する．

一方，負の熱膨張係数を持つ物質では $\alpha<0$ となり，定圧膨張に伴うエントロピー変化が負になる場合もある．
よって，定圧膨張に伴うエントロピー変化の符号は，熱膨張係数の符号を考慮して判断する必要がある．

以上により，断熱温度係数と，定圧準静的膨張に伴うエントロピー変化が求められた．
