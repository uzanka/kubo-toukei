# 演習問題【3-A-19】

## 解答

熱力学的安定性条件 (3.32b) を用いて，

```math
\left(\frac{\partial \mu}{\partial N}\right)_{T,p}\geq 0
```

を導く．

式 (3.32b) は

```math
\delta T\,\delta S-\delta p\,\delta V
+\sum_i\delta X_i\,\delta x_i
+\sum_j\delta\mu_j\,\delta N_j
\geq 0
```

である．
ここで， $T$ ， $p$ ， $N$ を独立変数とする．
温度 $T$ と圧力 $p$ を一定に保つ変化を考えると，

```math
\delta T=\delta p=0
```

である．
さらに，一成分系を考え，粒子数 $N$ の変化のみに着目すれば，式 (3.32b) は

```math
\delta\mu\,\delta N\geq 0
```

となる．

温度 $T$ と圧力 $p$ を一定に保ったとき，化学ポテンシャル $\mu$ は粒子数 $N$ の関数として変化する．
微小変化に対して，

```math
\delta\mu
=
\left(\frac{\partial\mu}{\partial N}\right)_{T,p}
\delta N
```

と表せる．
これを上式に代入すると，

```math
\left(\frac{\partial\mu}{\partial N}\right)_{T,p}
(\delta N)^2\geq 0
```

を得る．

ここで， $\delta N\neq 0$ とすれば $(\delta N)^2>0$ であるから，

```math
\boxed{
\left(\frac{\partial\mu}{\partial N}\right)_{T,p}
\geq 0
}
```

が導かれる．

ただし，この安定性条件から導かれるのは非負性であり，厳密な正値

```math
\left(\frac{\partial\mu}{\partial N}\right)_{T,p}>0
```

までは保証されない．
等号が成立する可能性を排除するには，追加の条件が必要である．
したがって，提示された解答例に従う限り，問題文の $>0$ は $\geq 0$ とするのが適切である．
