# 演習問題【3-A-4】

## 解答

与えられた状態方程式から，各熱力学量を導出するプロセスを以下に記す．

### 0. 準備：体積 $V$ の展開式

まず，与えられた状態方程式 $pV = A(T) + B(T)p + C(T)p^2 + \dots$ を $V$ について整理する．
両辺を圧力 $p$ で割ることで，体積 $V$ の展開式が得られる．

$$V(T, p) = \frac{A(T)}{p} + B(T) + C(T)p + \dots$$

### 1. Gibbs 自由エネルギー $G$ の導出

熱力学の基本関係式より，Gibbs 自由エネルギー $G$ の圧力 $p$ に関する偏微分は，系の体積 $V$ に等しい．

$$\left(\frac{\partial G}{\partial p}\right)_T = V$$

これに，先ほど求めた $V$ の展開式を代入する．

$$\left(\frac{\partial G}{\partial p}\right)_T = \frac{A(T)}{p} + B(T) + C(T)p + \dots$$

この式の両辺を，温度 $T$ を一定に保ったまま，圧力 $p$ について積分する．

$$G(T, p) = \int \left( \frac{A(T)}{p} + B(T) + C(T)p + \dots \right) dp$$

各項を積分すると，次のようになる．

$$G(T, p) = A(T) \ln p + B(T)p + \frac{1}{2}C(T)p^2 + \dots + \text{constant}(T)$$

ここで，積分定数（ $\text{constant}(T)$ ）を，基準となる圧力 $p_0$ における Gibbs 自由エネルギー $G(T, p_0)$ を用いて整理する．

対数の性質 $\ln p = \ln \frac{p}{p_0} + \ln p_0$ および，各項の差の形 $B(T)p = B(T)(p - p_0) + B(T)p_0$ を用いて，式を書き換えると：

$$G(T, p) = A(T) \left( \ln \frac{p}{p_0} + \ln p_0 \right) + B(T)(p - p_0) + B(T)p_0 + \frac{1}{2}C(T)(p^2 - p_0^2) + \frac{1}{2}C(T)p_0^2 + \dots + \text{constant}(T)$$

これらの中で $p_0$ に依存し，かつ温度 $T$ のみの関数である項（ $\ln p_0$ を含む項や $p_0$ の多項式部分）をすべてまとめて $G(T, p_0)$ と定義することで，以下の公式が得られる．

$$G(T, p) = G(T, p_0) + A(T) \ln \frac{p}{p_0} + B(T)(p - p_0) + \frac{1}{2}C(T)(p^2 - p_0^2) + \dots \quad \cdots (1)$$

### 2. エントロピー $S$ の導出

エントロピー $S$ は，Gibbs 自由エネルギー $G$ を温度 $T$ で偏微分することで得られる．

$$S = -\left(\frac{\partial G}{\partial T}\right)_p$$

これに，先ほど導出した式(1)を代入する．

$$S(T, p) = -\frac{\partial}{\partial T} \left[ G(T, p_0) + A(T) \ln \frac{p}{p_0} + B(T)(p - p_0) + \frac{1}{2}C(T)(p^2 - p_0^2) + \dots \right]_p$$

温度 $T$ に関する偏微分を各項に対して行う．
この際，圧力 $p$ や $p_0$ は定数として扱うため， $\ln \frac{p}{p_0}$ や $(p - p_0)$ などの項は微分時に消えない．
*   第1項： $-\frac{\partial}{\partial T} G(T, p_0) = S(T, p_0)$ と定義される（基準圧力でのエントロピー）．
*   第2項： $-\frac{\partial}{\partial T} \left( A(T) \ln \frac{p}{p_0} \right) = -\frac{dA}{dT} \ln \frac{p}{p_0}$
*   第3項： $-\frac{\partial}{\partial T} \left( B(T)(p - p_0) \right) = -\frac{dB}{dT}(p - p_0)$
*   第4項： $-\frac{\partial}{\partial T} \left( \frac{1}{2}C(T)(p^2 - p_0^2) \right) = -\frac{1}{2}\frac{dC}{dT}(p^2 - p_0^2)$

ここで，係数の温度微分を $A'(T) = \frac{dA}{dT}, B'(T) = \frac{dB}{dT}, C'(T) = \frac{dC}{dT}$ と置くと，次の公式が得られる．

$$S(T, p) = S(T, p_0) - A'(T) \ln \frac{p}{p_0} - B'(T)(p - p_0) - \frac{1}{2}C'(T)(p^2 - p_0^2) - \dots \quad \cdots (2)$$

### 3. エンタルピー $H$ の導出

エンタルピーの定義式 $H = G + TS$ に，これまでに得られた式(1)と式(2)を代入して，項を整理していく．

$$H(T, p) = \underbrace{\left[ G(T, p_0) + A \ln \frac{p}{p_0} + B(p - p_0) + \dots \right]}_{G(T, p)} + T \underbrace{\left[ S(T, p_0) - A' \ln \frac{p}{p_0} - B'(p - p_0) - \dots \right]}_{S(T, p)}$$

$T$ を括弧内に分配すると，

$$H(T, p) = G(T, p_0) + A \ln \frac{p}{p_0} + B(p - p_0) + \dots + TS(T, p_0) - TA' \ln \frac{p}{p_0} - TB'(p - p_0) - \dots$$

これらを $\ln \frac{p}{p_0}$ や $(p - p_0)$ などの共通の項ごとにまとめ直す．

- 定数項（ $p, p_0$ に依存しない項）：
$$G(T, p_0) + TS(T, p_0)$$
これは，基準圧力 $p_0$ におけるエンタルピーの定義そのものである．
したがって $H(T, p_0)$ と書ける．
- $\ln \frac{p}{p_0}$ の項：
$$A \ln \frac{p}{p_0} - TA' \ln \frac{p}{p_0} = (A - TA') \ln \frac{p}{p_0}$$
- $(p - p_0)$ の項：
$$B(p - p_0) - TB'(p - p_0) = (B - TB')(p - p_0)$$
- $(p^2 - p_0^2)$ の項：
$$\frac{1}{2}C(p^2 - p_0^2) - \frac{1}{2}TC'(p^2 - p_0^2) = \frac{1}{2}(C - TC')(p^2 - p_0^2)$$

これらをすべて足し合わせることで，最終的な公式が得られる．

$$H(T, p) = H(T, p_0) + (A - TA') \ln \frac{p}{p_0} + (B - TB')(p - p_0) + \frac{1}{2}(C - TC')(p^2 - p_0^2) + \dots \quad \cdots (3)$$

### まとめ：得られた計算公式

実験から得られた展開係数 $A(T), B(T), C(T), \dots$ およびその温度微分 $A'(T), B'(T), C'(T), \dots$ を用いると，各熱力学量は以下の通り計算できる．

1.  Gibbs 自由エネルギー $G$
$$G(T, p) = G(T, p_0) + A \ln \frac{p}{p_0} + B(p - p_0) + \frac{1}{2}C(p^2 - p_0^2) + \dots$$
2.  エントロピー $S$
$$S(T, p) = S(T, p_0) - A' \ln \frac{p}{p_0} - B'(p - p_0) - \frac{1}{2}C'(p^2 - p_0^2) - \dots$$
3.  エンタルピー $H$
$$H(T, p) = H(T, p_0) + (A - TA') \ln \frac{p}{p_0} + (B - TB')(p - p_0) + \frac{1}{2}(C - TC')(p^2 - p_0^2) + \dots$$

※ $G(T, p_0), S(T, p_0), H(T, p_0)$ の値を決定するには，別途熱容量に関する知識が必要となる．
