# 演習問題【3-A-4】

## 解答

### 状態方程式の展開係数から熱力学量を求める公式

状態方程式

```math
pV=A(T)+B(T)p+C(T)p^2+\cdots
```

が実験によって与えられているとする．
ここで， $A(T),B(T),C(T),\ldots$ は温度 $T$ の関数である．
この展開係数を用いて，Gibbs 自由エネルギー $G$ ，エントロピー $S$ ，エンタルピー $H$ を求める公式を導出する．

#### 1．Gibbs 自由エネルギー $G$ の導出

まず，状態方程式を圧力 $p$ で割ると，体積 $V$ は

```math
V(T,p)=\frac{A(T)}{p}+B(T)+C(T)p+\cdots
```

と表される．

Gibbs 自由エネルギーの微分関係

```math
dG=-S\,dT+V\,dp
```

より，温度 $T$ を一定に保ったとき，

```math
\left(\frac{\partial G}{\partial p}\right)_T=V
```

が成り立つ．
したがって，

```math
\left(\frac{\partial G}{\partial p}\right)_T
=\frac{A(T)}{p}+B(T)+C(T)p+\cdots
```

である．

ここで，基準圧力を $p_0>0$ とし，温度 $T$ を一定に保って，圧力 $p_0$ から $p$ まで積分する．
すると，

```math
G(T,p)-G(T,p_0)
=\int_{p_0}^{p}V(T,\tilde p)\,d\tilde p
```

となる．
ここで， $\tilde p$ は積分変数である．
体積の展開式を代入して各項を積分すると，

```math
\begin{aligned}
G(T,p)-G(T,p_0)
={}&A(T)\int_{p_0}^{p}\frac{d\tilde p}{\tilde p}\\
&+B(T)\int_{p_0}^{p}d\tilde p\\
&+C(T)\int_{p_0}^{p}\tilde p\,d\tilde p+\cdots\\
={}&A(T)\ln\frac{p}{p_0}
+B(T)(p-p_0)\\
&+\frac{1}{2}C(T)(p^2-p_0^2)+\cdots .
\end{aligned}
```

よって，Gibbs 自由エネルギーは

```math
\boxed{
\begin{aligned}
G(T,p)={}&G(T,p_0)
+A(T)\ln\frac{p}{p_0}\\
&+B(T)(p-p_0)\\
&+\frac{1}{2}C(T)(p^2-p_0^2)+\cdots
\end{aligned}
}
\tag{1}
```

と求められる．

#### 2．エントロピー $S$ の導出

Gibbs 自由エネルギーとエントロピーの関係は，

```math
S=-\left(\frac{\partial G}{\partial T}\right)_p
```

である．
式 (1) を温度 $T$ について，圧力 $p$ と基準圧力 $p_0$ を一定に保って偏微分する．
このとき， $p$ と $p_0$ は温度に依存しないため， $\ln(p/p_0)$ ， $p-p_0$ ， $p^2-p_0^2$ は微分に対して定数として扱う．

係数の温度微分を

```math
A'(T)=\frac{dA}{dT},\qquad
B'(T)=\frac{dB}{dT},\qquad
C'(T)=\frac{dC}{dT}
```

と定義すると，

```math
\begin{aligned}
S(T,p)={}&-\left(\frac{\partial G(T,p_0)}
{\partial T}\right)\\
&-A'(T)\ln\frac{p}{p_0}\\
&-B'(T)(p-p_0)\\
&-\frac{1}{2}C'(T)(p^2-p_0^2)-\cdots .
\end{aligned}
```

基準圧力 $p_0$ においても，

```math
S(T,p_0)=-\left(\frac{\partial G(T,p_0)}
{\partial T}\right)_{p_0}
```

であるから，エントロピーは

```math
\boxed{
\begin{aligned}
S(T,p)={}&S(T,p_0)
-A'(T)\ln\frac{p}{p_0}\\
&-B'(T)(p-p_0)\\
&-\frac{1}{2}C'(T)(p^2-p_0^2)-\cdots
\end{aligned}
}
\tag{2}
```

と求められる．

#### 3．エンタルピー $H$ の導出

Gibbs 自由エネルギーの定義

```math
G=H-TS
```

を変形すると，

```math
H=G+TS
```

を得る．
ここに式 (1) と式 (2) を代入する．

まず，基準圧力 $p_0$ における項は

```math
G(T,p_0)+TS(T,p_0)=H(T,p_0)
```

とまとめられる．
また， $\ln(p/p_0)$ の係数は

```math
A(T)-TA'(T)
```

であり， $p-p_0$ の係数は

```math
B(T)-TB'(T)
```

である．
同様に， $p^2-p_0^2$ の係数は

```math
\frac{1}{2}\bigl[C(T)-TC'(T)\bigr]
```

となる．
したがって，

```math
\boxed{
\begin{aligned}
H(T,p)={}&H(T,p_0)\\
&+\bigl[A(T)-TA'(T)\bigr]\ln\frac{p}{p_0}\\
&+\bigl[B(T)-TB'(T)\bigr](p-p_0)\\
&+\frac{1}{2}\bigl[C(T)-TC'(T)\bigr]
(p^2-p_0^2)+\cdots
\end{aligned}
}
\tag{3}
```

が得られる．

#### 4．結論と基準値について

以上より，実験で決定した状態方程式の展開係数 $A(T),B(T),C(T),\ldots$ と，それらの温度微分を用いることで，Gibbs 自由エネルギー，エントロピー，エンタルピーを圧力の関数として表す公式が得られる．

```math
\begin{aligned}
G(T,p)-G(T,p_0)
={}&A(T)\ln\frac{p}{p_0}\\
&+B(T)(p-p_0)\\
&+\frac12 C(T)(p^2-p_0^2)+\cdots ,
\end{aligned}
```

```math
\begin{aligned}
S(T,p)-S(T,p_0)
={}&-A'(T)\ln\frac{p}{p_0}\\
&-B'(T)(p-p_0)\\
&-\frac12 C'(T)(p^2-p_0^2)-\cdots ,
\end{aligned}
```

```math
\begin{aligned}
H(T,p)-H(T,p_0)
={}&[A(T)-TA'(T)]\ln\frac{p}{p_0}\\
&+[B(T)-TB'(T)](p-p_0)\\
&+\frac12[C(T)-TC'(T)](p^2-p_0^2)+\cdots .
\end{aligned}
```

ただし，これらの式は基準圧力 $p_0$ における熱力学量を基準としている．
状態方程式の展開係数だけからは，基準値 $G(T,p_0)$ ， $S(T,p_0)$ ， $H(T,p_0)$ の絶対値は一般に定まらない．
これらを決定するには，基準状態での熱力学量や熱容量など，追加の熱力学的情報が必要である．
また，以上の式は，状態方程式の展開が有効な圧力範囲で適用される．
