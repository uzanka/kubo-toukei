# 演習問題【3-A-5】

## 解答

### Helmholtz 自由エネルギーと Gibbs 自由エネルギーを用いた恒等式の証明

#### 1．第1式の証明

示すべき式は

```math
\left(\frac{\partial U}{\partial V}\right)_T+p
=T\left(\frac{\partial p}{\partial T}\right)_V
```

である．

まず，Helmholtz 自由エネルギー $F$ の定義

```math
F=U-TS
```

より，

```math
U=F+TS
```

である．
また，Helmholtz 自由エネルギーの微分関係

```math
dF=-S\,dT-p\,dV
```

から，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_V
```

が得られる．
これを $U=F+TS$ に代入すると，

```math
U=F-T\left(\frac{\partial F}{\partial T}\right)_V
```

となる．

この式を，温度 $T$ を一定に保って体積 $V$ について偏微分する．
$T$ は一定であるため，

```math
\left(\frac{\partial U}{\partial V}\right)_T
=
\left(\frac{\partial F}{\partial V}\right)_T
-T\frac{\partial}{\partial V}
\left(\frac{\partial F}{\partial T}\right)_V
```

である．

ここで， $F$ が十分滑らかな関数であれば，混合偏微分の順序を交換できるため，

```math
\frac{\partial}{\partial V}
\left(\frac{\partial F}{\partial T}\right)_V
=
\frac{\partial}{\partial T}
\left(\frac{\partial F}{\partial V}\right)_T
```

が成り立つ．
さらに，微分関係 $dF=-S\,dT-p\,dV$ より，

```math
\left(\frac{\partial F}{\partial V}\right)_T=-p
```

であるから，

```math
\begin{aligned}
\frac{\partial}{\partial V}
\left(\frac{\partial F}{\partial T}\right)_V
&=\frac{\partial}{\partial T}
\left(\frac{\partial F}{\partial V}\right)_T\\
&=\left(\frac{\partial(-p)}{\partial T}\right)_V\\
&=-\left(\frac{\partial p}{\partial T}\right)_V
\end{aligned}
```

となる．
また，同じ微分関係から，

```math
\left(\frac{\partial F}{\partial V}\right)_T=-p
```

である．
以上を代入すると，

```math
\begin{aligned}
\left(\frac{\partial U}{\partial V}\right)_T
&=-p-T\left[-\left(\frac{\partial p}{\partial T}\right)_V\right]\\
&=-p+T\left(\frac{\partial p}{\partial T}\right)_V
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_T+p
=T\left(\frac{\partial p}{\partial T}\right)_V
}
```

が証明された．

#### 2．第2式の証明

示すべき式は

```math
\left(\frac{\partial H}{\partial p}\right)_T-V
=-T\left(\frac{\partial V}{\partial T}\right)_p
```

である．

まず，Gibbs 自由エネルギー $G$ の定義

```math
G=H-TS
```

より，

```math
H=G+TS
```

である．
また，Gibbs 自由エネルギーの微分関係

```math
dG=-S\,dT+V\,dp
```

から，

```math
S=-\left(\frac{\partial G}{\partial T}\right)_p
```

が得られる．
これを $H=G+TS$ に代入すると，

```math
H=G-T\left(\frac{\partial G}{\partial T}\right)_p
```

となる．

この式を，温度 $T$ を一定に保って圧力 $p$ について偏微分する．
すると，

```math
\left(\frac{\partial H}{\partial p}\right)_T
=
\left(\frac{\partial G}{\partial p}\right)_T
-T\frac{\partial}{\partial p}
\left(\frac{\partial G}{\partial T}\right)_p
```

である．

ここでも， $G$ が十分滑らかであれば，混合偏微分の順序を交換できるため，

```math
\frac{\partial}{\partial p}
\left(\frac{\partial G}{\partial T}\right)_p
=
\frac{\partial}{\partial T}
\left(\frac{\partial G}{\partial p}\right)_T
```

が成り立つ．
さらに，微分関係 $dG=-S\,dT+V\,dp$ より，

```math
\left(\frac{\partial G}{\partial p}\right)_T=V
```

であるから，

```math
\begin{aligned}
\frac{\partial}{\partial p}
\left(\frac{\partial G}{\partial T}\right)_p
&=\frac{\partial}{\partial T}
\left(\frac{\partial G}{\partial p}\right)_T\\
&=\left(\frac{\partial V}{\partial T}\right)_p
\end{aligned}
```

となる．
これらを代入すると，

```math
\begin{aligned}
\left(\frac{\partial H}{\partial p}\right)_T
&=V-T\left(\frac{\partial V}{\partial T}\right)_p
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
\left(\frac{\partial H}{\partial p}\right)_T-V
=-T\left(\frac{\partial V}{\partial T}\right)_p
}
```

が証明された．

#### 3．まとめ

2つの式は，それぞれ Helmholtz 自由エネルギーと Gibbs 自由エネルギーの定義，エントロピーとの関係，および自由エネルギーの微分関係から導かれる．
証明の要点は，次の関係を利用することである．

```math
\begin{gathered}
F=U-TS,\qquad
\left(\frac{\partial F}{\partial V}\right)_T=-p,\\
G=H-TS,\qquad
\left(\frac{\partial G}{\partial p}\right)_T=V.
\end{gathered}
```

これらの関係と混合偏微分の順序交換を用いることで，内部エネルギー $U$ の体積微分と圧力の温度微分，およびエンタルピー $H$ の圧力微分と体積の温度微分を結び付けることができる．
