# 演習問題【3-B-26】

## 解答

熱力学第3法則によれば，温度 $T$ が絶対零度に近づくとき，エントロピー $S$ は磁場 $H$ に依存しない極限値に近づく．
したがって，エントロピーの磁場依存性は消失し，

```math
\lim_{T\to0}\left(\frac{\partial S}{\partial H}\right)_T=0
```

となる．

ここで，磁化 $M$ を用いて表したヘルムホルツ自由エネルギー $F(T,M)$ の全微分は，

```math
dF=-S\,dT+H\,dM
```

である．
この関係から得られるマクスウェルの関係式は，

```math
\left(\frac{\partial S}{\partial M}\right)_T
=-\left(\frac{\partial H}{\partial T}\right)_M
```

である．
磁場 $H$ を自然変数とする自由エネルギーを用いれば，さらに

```math
\boxed{
\left(\frac{\partial S}{\partial H}\right)_T
=\left(\frac{\partial M}{\partial T}\right)_H
}
```

が得られる．
よって，

```math
\lim_{T\to0}\left(\frac{\partial M}{\partial T}\right)_H=0
```

である．

次に，等温磁化率 $\chi_T$ は

```math
M=\chi_T H
```

で定義される．
磁場 $H$ を一定に保って温度で偏微分すると，

```math
\left(\frac{\partial M}{\partial T}\right)_H
=H\left(\frac{\partial\chi_T}{\partial T}\right)_H
```

となる．
したがって，

```math
\lim_{T\to0}
H\left(\frac{\partial\chi_T}{\partial T}\right)_H=0
```

である．
ここで， $H$ を一定の非零値に保てば，

```math
\boxed{
\lim_{T\to0}\left(\frac{\partial\chi_T}{\partial T}\right)_H=0
}
```

を得る．
これで示された．

なお，この結論は，熱力学第3法則が適用でき，エントロピーの低温極限が磁場に依存しないことを前提とするものである．
この結果から，キュリーの法則 $\chi_T=C/T$ のように低温で磁化率の温度微分が発散する式は，絶対零度近傍までそのまま適用できないことが分かる．
