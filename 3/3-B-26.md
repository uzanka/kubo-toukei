# 演習問題【3-B-26】

## 解答

等温磁化率を、ゼロ磁場における線形応答係数として，

```math
\boxed{
\chi_T(T)=
\left.
\left(\frac{\partial M}{\partial H}\right)_T
\right|_{H=0}
}
\tag{1}
```

と定義する．

熱力学第3法則のネルンストの熱定理によれば，絶対零度に近づくとき，エントロピー $S$ は磁場 $H$ に依存しない極限値をもつ．
すなわち，

```math
\lim_{T\to0}S(T,H)=S_0
\tag{2}
```

であり， $S_0$ は磁場に依存しない定数である．

ただし，式 (2) だけでは，エントロピーの磁場に関する二階偏微分がゼロに収束することは保証されない．
そこで，以下の低温展開に関する正則性条件を仮定する．

ある $T_*>0$ ， $p>0$ ，磁場範囲 $H_0>0$ ，および二階連続微分可能な関数 $s(H)$ が存在して，

```math
S(T,H)
=
S_0+
\left(\frac{T}{T_*}\right)^p s(H)
+r(T,H)
\tag{3}
```

と表され，剰余項 $r(T,H)$ が，

```math
\boxed{
\left\|r(T,\cdot)\right\|_{C^2([-H_0,H_0])}
=
o\left(\left(\frac{T}{T_*}\right)^p\right)
}
\tag{4}
```

を満たすものとする．
ここで， $C^2$ ノルムは関数および磁場に関する一階・二階偏微分の一様な大きさを表す．

式 (3) を磁場 $H$ で二階偏微分すると，

```math
\frac{\partial^2S}{\partial H^2}
=
\left(\frac{T}{T_*}\right)^p
\frac{d^2s}{dH^2}
+
\frac{\partial^2r}{\partial H^2}
```

となる．
$p>0$ であり，式 (4) が成立するから，

```math
\boxed{
\lim_{T\to0}
\sup_{|H|\leq H_0}
\left|
\frac{\partial^2S}{\partial H^2}
\right|=0
}
\tag{5}
```

を得る．

次に，磁場 $H$ を独立変数とする熱力学ポテンシャル $G(T,H)$ を考える．
磁気仕事の共役変数を $H,M$ とする規約では，その全微分は，

```math
dG=-S\,dT-M\,dH
```

である．
したがって，

```math
S=-\left(\frac{\partial G}{\partial T}\right)_H,
\qquad
M=-\left(\frac{\partial G}{\partial H}\right)_T
```

となる．

熱力学ポテンシャルの必要な混合偏微分が交換可能であることから，マクスウェルの関係式

```math
\boxed{
\left(\frac{\partial S}{\partial H}\right)_T
=
\left(\frac{\partial M}{\partial T}\right)_H
}
\tag{6}
```

を得る．

式 (1) より，等温磁化率は，

```math
\chi_T(T)
=
\left.
\frac{\partial M}{\partial H}
\right|_{H=0}
```

である．
これを温度 $T$ で微分し，混合偏微分の交換可能性を用いると，

```math
\frac{d\chi_T}{dT}
=
\left.
\frac{\partial}{\partial H}
\left(\frac{\partial M}{\partial T}\right)_H
\right|_{H=0}
```

となる．

ここに式 (6) を適用すれば，

```math
\boxed{
\frac{d\chi_T}{dT}
=
\left.
\frac{\partial^2S}{\partial H^2}
\right|_{H=0}
}
\tag{7}
```

を得る．

一方，式 (5) より，

```math
\lim_{T\to0}
\left.
\frac{\partial^2S}{\partial H^2}
\right|_{H=0}=0
```

である．
したがって，式 (7) から，

```math
\boxed{
\lim_{T\to0}
\frac{d\chi_T}{dT}=0
}
```

となる．

以上より，ネルンストの熱定理に加え，エントロピーが磁場に関して適切な低温展開をもち，その二階偏微分も低温でゼロに収束する常磁性体では，等温磁化率の温度微分は絶対零度に近づくとゼロに収束する．

**（注）** キュリーの法則

```math
\chi=\frac{C}{T}
```

では，

```math
\frac{d\chi}{dT}=-\frac{C}{T^2}
```

となる．
また，キュリー・ワイスの法則

```math
\chi=\frac{C}{T+\theta}
```

では，

```math
\frac{d\chi}{dT}
=-\frac{C}{(T+\theta)^2}
```

となる．
通常の $C>0,\theta>0$ の場合，いずれも温度微分は $T\to0$ でゼロに収束しない．
したがって，これらの法則を絶対零度近傍までそのまま適用することはできず，低温ではこれらの法則からの逸脱が生じる．
