# 演習問題【3-A-6】

## 解答

示すべき関係式は

```math
\left(\frac{\partial H}{\partial p}\right)_T-V
=-T\left(\frac{\partial V}{\partial T}\right)_p
=-C_p\left(\frac{\partial T}{\partial p}\right)_S
```

である．
以下では，前問で得られた関係式と，Maxwell の関係式，ヤコビアンの性質を用いて証明する．

### 1．第1の等号の証明

前問で，Gibbs 自由エネルギー $G$ を用いることにより，

```math
\boxed{
\left(\frac{\partial H}{\partial p}\right)_T-V
=-T\left(\frac{\partial V}{\partial T}\right)_p
}
```

が得られている．
したがって，第1の等号は前問の結果から直ちに成立する．

### 2．第2の等号の証明

第2の等号

```math
-T\left(\frac{\partial V}{\partial T}\right)_p
=-C_p\left(\frac{\partial T}{\partial p}\right)_S
```

を証明する．

まず，Gibbs 自由エネルギーの微分関係

```math
dG=-S\,dT+V\,dp
```

より，

```math
S=-\left(\frac{\partial G}{\partial T}\right)_p,
\qquad
V=\left(\frac{\partial G}{\partial p}\right)_T
```

である．
$G$ が十分滑らかであれば，混合偏微分の順序を交換できるため，

```math
\begin{aligned}
\left(\frac{\partial S}{\partial p}\right)_T
&=-\frac{\partial}{\partial p}
\left(\frac{\partial G}{\partial T}\right)_p\\
&=-\frac{\partial}{\partial T}
\left(\frac{\partial G}{\partial p}\right)_T\\
&=-\left(\frac{\partial V}{\partial T}\right)_p
\end{aligned}
```

が成り立つ．
これが Maxwell の関係式

```math
\boxed{
\left(\frac{\partial V}{\partial T}\right)_p
=-\left(\frac{\partial S}{\partial p}\right)_T
}
\tag{1}
```

である．

次に，ヤコビアンの性質を用いて，

```math
\left(\frac{\partial S}{\partial p}\right)_T
=\frac{\partial(S,T)}{\partial(p,T)}
```

と表す．
ヤコビアンの連鎖律より，

```math
\frac{\partial(S,T)}{\partial(p,T)}
=
\frac{\partial(S,T)}{\partial(S,p)}
\frac{\partial(S,p)}{\partial(p,T)}
```

である．
それぞれのヤコビアンを計算すると，

```math
\frac{\partial(S,T)}{\partial(S,p)}
=\left(\frac{\partial T}{\partial p}\right)_S
```

および

```math
\frac{\partial(S,p)}{\partial(p,T)}
=-\left(\frac{\partial S}{\partial T}\right)_p
```

となる．
したがって，

```math
\boxed{
\left(\frac{\partial S}{\partial p}\right)_T
=-\left(\frac{\partial T}{\partial p}\right)_S
\left(\frac{\partial S}{\partial T}\right)_p
}
\tag{2}
```

を得る．

ここで，定圧熱容量 $C_p$ は，圧力一定の条件におけるエントロピーの温度微分を用いて，

```math
C_p=T\left(\frac{\partial S}{\partial T}\right)_p
```

と表される．
よって，

```math
\left(\frac{\partial S}{\partial T}\right)_p
=\frac{C_p}{T}
```

である．
これを式 (2) に代入すると，

```math
\left(\frac{\partial S}{\partial p}\right)_T
=-\frac{C_p}{T}
\left(\frac{\partial T}{\partial p}\right)_S
```

となる．
さらに，Maxwell の関係式 (1) を用いれば，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=\frac{C_p}{T}
\left(\frac{\partial T}{\partial p}\right)_S
```

が得られる．
両辺に $-T$ を掛けると，

```math
\boxed{
-T\left(\frac{\partial V}{\partial T}\right)_p
=-C_p\left(\frac{\partial T}{\partial p}\right)_S
}
```

となり，第2の等号も証明された．

### 3．結論

以上より，

```math
\boxed{
\left(\frac{\partial H}{\partial p}\right)_T-V
=-T\left(\frac{\partial V}{\partial T}\right)_p
=-C_p\left(\frac{\partial T}{\partial p}\right)_S
}
```

が成立する．
