# 演習問題【3-A-20】

## 解答

体積変化を考えず，単位体積の常磁性体を考える．
自由エネルギー $F$ を温度 $T$ と磁化 $M$ の関数 $F(T,M)$ とする．
このとき，熱力学の関係式として

```math
dF=-S\,dT+H\,dM
```

が成り立つ．
ここで， $S$ はエントロピー，\(H\) は磁場である．したがって，

```math
\left(\frac{\partial F}{\partial T}\right)_M=-S
\tag{1}
```

および

```math
\left(\frac{\partial F}{\partial M}\right)_T=H
\tag{2}
```

を得る．

また，自由エネルギー $F=U-TS$ から，内部エネルギー $U$ は

```math
U=F+TS
```

と表される．
式 (1) を代入すると，

```math
U=F-T\left(\frac{\partial F}{\partial T}\right)_M
\tag{3}
```

となる．
これは，解答例の

```math
U=-T^2\frac{\partial}{\partial T}\left(\frac{F}{T}\right)_M
```

と同じ関係式である．

### 1．自由エネルギー $F(T,M)$ の導出

等温磁化率 $\chi_T$ の定義より，磁化 $M$ と磁場 $H$ の間には

```math
M=\chi_T H
```

の関係がある．
したがって，

```math
H=\frac{M}{\chi_T}=\chi_T^{-1}M
\tag{4}
```

である．

式 (2) に式 (4) を代入すると，

```math
\left(\frac{\partial F}{\partial M}\right)_T
=\chi_T^{-1}M
```

となる．
ここで，温度 $T$ を一定に保って $M$ について積分する．
等温磁化率 $\chi_T$ は温度の関数であるため，この積分では定数として扱える．
よって，

```math
F(T,M)=\int \chi_T^{-1}M\,dM
=\frac{1}{2}\chi_T^{-1}M^2+C(T)
```

となる．
積分定数 $C(T)$ は温度のみの関数である．
$M=0$ とすると $F(T,0)=C(T)$ であるから，

```math
\boxed{
F(T,M)=F(T,0)+\frac12\chi_T^{-1}M^2
}
\tag{5}
```

を得る．

### 2．エントロピー $S(T,M)$ の導出

式 (1) より，エントロピーは自由エネルギーを温度で偏微分することで求められる．

```math
S(T,M)=-\left(\frac{\partial F}{\partial T}\right)_M
```

式 (5) を代入すると，

```math
S(T,M)
=-\left(\frac{\partial F(T,0)}{\partial T}\right)
-\frac{1}{2}M^2\frac{d}{dT}\chi_T^{-1}
```

となる．
この温度微分では磁化 $M$ を一定に保つ．
また，

```math
S(T,0)=-\frac{\partial F(T,0)}{\partial T}
```

であるため，

```math
\boxed{
S(T,M)=S(T,0)
-\frac{1}{2}\left(\frac{d}{dT}\chi_T^{-1}\right)M^2
}
\tag{6}
```

を得る．

### 3．内部エネルギー $U(T,M)$ の導出

式 (3) を用いると，

```math
U(T,M)
=F(T,M)-T\left(\frac{\partial F}{\partial T}\right)_M
```

である．
式 (5) を代入して温度微分を計算すると，

```math
\begin{aligned}
U(T,M)
={}&F(T,0)+\frac12\chi_T^{-1}M^2\\
&-T\frac{\partial F(T,0)}{\partial T}
-\frac{1}{2}TM^2\frac{d}{dT}\chi_T^{-1}
\end{aligned}
```

となる．
ここで，

```math
U(T,0)=F(T,0)
-T\frac{\partial F(T,0)}{\partial T}
```

であることを用いて整理すれば，

```math
\boxed{
U(T,M)=U(T,0)
+\frac{1}{2}\left\{
\chi_T^{-1}
-T\frac{d}{dT}\chi_T^{-1}
\right\}M^2
}
\tag{7}
```

を得る．

### 結論

等温磁化率 $\chi_T$ をもつ常磁性体の自由エネルギー，エントロピー，内部エネルギーは，それぞれ

```math
\boxed{
F(T,M)=F(T,0)+\frac12\chi_T^{-1}M^2
}
```

```math
\boxed{
S(T,M)=S(T,0)
-\frac12\left(\frac{d}{dT}\chi_T^{-1}\right)M^2
}
```

```math
\boxed{
U(T,M)=U(T,0)
+\frac{1}{2}\left\{
\chi_T^{-1}
-T\frac{d}{dT}\chi_T^{-1}
\right\}M^2
}
```

である．
これらの式から，磁化による自由エネルギー，エントロピー，内部エネルギーの変化は，磁化 $M$ の二乗と，等温磁化率の温度依存性によって決まることが分かる．
