# 演習問題【3-A-8】

## 解答

問題で与えられた変数は以下の通りである：
- $U$ : 内部エネルギー
- $H$ : エンタルピー
- $S$ : エントロピー
- $p$ : 圧力
- $V$ : 体積
- $T$ : 温度

熱力学の基本式（熱力学第一法則の微分形式）を用いることで，これらの不等式を導出できる．

### (i) $\left(\frac{\partial S}{\partial p}\right)_H < 0$ の証明

エンタルピー $H$ の定義は $H = U + pV$ である．
この微分形式（微小変化の関係式）を考える．
$H = U + pV$ を微分すると，

$$dH = dU + d(pV) = dU + p dV + V dp$$

ここで，熱力学第一法則の微分形式 $dU = T dS - p dV$ を代入すると，

$$dH = (T dS - p dV) + p dV + V dp$$

$$dH = T dS + V dp$$

となる．

この式において，エンタルピーが一定（ $dH = 0$ ）である条件，すなわち等エンタルピー変化を考えると，

$$0 = T dS + V dp$$

$$T dS = -V dp$$

両辺を $T dp$ で割ると（ $T > 0$ であるとする），

$$\left(\frac{\partial S}{\partial p}\right)_H = -\frac{V}{T}$$

が得られる．
温度 $T$ は絶対温度であり常に正 ( $T > 0$ )，体積 $V$ も常に正 ( $V > 0$ ) であるから，

$$\left(\frac{\partial S}{\partial p}\right)_H = -\frac{V}{T} < 0$$

が成立する．

### (ii) $\left(\frac{\partial S}{\partial V}\right)_U > 0$ の証明

熱力学第一法則の微分形式 $dU = T dS - p dV$ を用いる．
内部エネルギーが一定（ $dU = 0$ ）である条件，すなわち等内部エネルギー変化を考えると，

$$0 = T dS - p dV$$

$$T dS = p dV$$

両辺を $T dV$ で割ると（ $T > 0$ であるとする），

$$\left(\frac{\partial S}{\partial V}\right)_U = \frac{p}{T}$$

が得られる．
圧力 $p$ は常に正 ( $p > 0$ )，温度 $T$ も常に正 ( $T > 0$ ) であるから，

$$\left(\frac{\partial S}{\partial V}\right)_U = \frac{p}{T} > 0$$

が成立する．

## 解説

この問題は，熱力学における「状態量」の変化の関係を理解するための基本的な問題である．

### 1. 基本的な用語の整理

まず，登場する変数が何を意味しているかを確認する．
- **内部エネルギー ( $U$ )**: 系（物質）が内部に持っているエネルギーの総量．
- **エンタルピー ( $H$ )**: 内部エネルギーに，その物質がその場所を占めるために必要なエネルギー ( $pV$ ) を加えたもの．
- **エントロピー ( $S$ )**: 系の「乱雑さ」を表す尺度．
値が大きいほど，状態の不確かさや乱雑さが増していることを示す．
- **圧力 ( $p$ ) と 体積 ( $V$ )**: 物質が外部に及ぼす力と，占有している空間の広さ．
- **温度 ( $T$ )**: 物質の熱的な状態を示す指標（絶対温度は常に正の値をとる）．

### 2. 熱力学の基本式（微分形式）の意味

この問題を解く鍵は，エネルギーの変化（ $dU$ や $dH$ ）と，エントロピーの変化（ $dS$ ），圧力・体積の変化（ $dp, dV$ ）がどのように結びついているかを示す式を知ることである．

- **$dU = T dS - p dV$**: これは「内部エネルギーの変化は，熱として加えられたエネルギー ( $T dS$ ) から，外部へ仕事として取り出されたエネルギー ( $p dV$ ) を引いたものである」ことを示している．
- **$dH = T dS + V dp$**: これはエンタルピーの変化を表す式で，エントロピーの変化と圧力の変化がどのように関係しているかを示している．

### 3. 「偏微分」の意味

問題文にある $\left(\frac{\partial S}{\partial p}\right)_H$ という記法は，**「エンタルピー $H$ を一定に保ったまま，圧力 $p$ を変化させたとき，エントロピー $S$ がどのように変化するか」**を意味している．

### 4. 物理的なイメージ

数式だけでなく，物理的に何が起きているかを考えてみよう．

- **(i) 圧力を上げるとエントロピーは下がる**
  エンタルピーを一定に保ちながら圧力を上げると（圧縮すると），物質が占める体積は小さくなる．
  物質が狭い場所に閉じ込められると，粒子の動きや配置の自由度が減るため，乱雑さ（エントロピー）は減少する．
  これが $\left(\frac{\partial S}{\partial p}\right)_H < 0$ という負の値の意味である．

- **(ii) 体積を大きくするとエントロピーは上がる**
  内部エネルギーを一定に保ちながら体積を大きくすると（膨張させると），物質が動ける空間が広がる．
  空間が広がれば，粒子の配置の仕方がより多様になり，乱雑さ（エントロピー）は増加する．
  これが $\left(\frac{\partial S}{\partial V}\right)_U > 0$ という正の値の意味である．
