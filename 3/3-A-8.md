# 演習問題【3-A-8】

## 解答

内部エネルギーを $U$ ，エンタルピーを $H$ ，エントロピーを $S$ ，圧力を $p$ ，体積を $V$ ，絶対温度を $T$ とする．
以下では，物質の組成を変えず，通常の正の絶対温度，正の圧力，正の体積をもつ系を考える．

熱力学の基本式

```math
dU=T\,dS-p\,dV
\tag{1}
```

を用いて，それぞれの不等式を証明する．

### (i) $\displaystyle \left(\frac{\partial S}{\partial p}\right)_H<0$ の証明

エンタルピーの定義は

```math
H=U+pV
\tag{2}
```

である．
両辺を微分すると，

```math
dH=dU+p\,dV+V\,dp
\tag{3}
```

となる．
式 (1) の $dU=T\,dS-p\,dV$ を式 (3) に代入すれば，

```math
\begin{aligned}
dH
&=T\,dS-p\,dV+p\,dV+V\,dp\\
&=T\,dS+V\,dp
\end{aligned}
\tag{4}
```

を得る．

ここで，エンタルピー $H$ を一定に保つ変化を考えると， $dH=0$ である．
したがって，式 (4) より

```math
T\,dS+V\,dp=0
```

となり，

```math
T\,dS=-V\,dp
```

を得る．
両辺を $T\,dp$ で割ると，

```math
\left(\frac{\partial S}{\partial p}\right)_H
=-\frac{V}{T}
\tag{5}
```

となる．
ここで，左辺はエンタルピー $H$ を一定に保ったときの，圧力 $p$ に対するエントロピー $S$ の偏微分を表す．

$V>0$ ， $T>0$ であるから，

```math
-\frac{V}{T}<0
```

である．
よって，

```math
\boxed{
\left(\frac{\partial S}{\partial p}\right)_H<0
}
```

が証明された．

### (ii) $\displaystyle \left(\frac{\partial S}{\partial V}\right)_U>0$ の証明

熱力学の基本式 (1) より，

```math
dU=T\,dS-p\,dV
\tag{6}
```

である．
ここで，内部エネルギー $U$ を一定に保つ変化を考えると， $dU=0$ である．
したがって，式 (6) より

```math
T\,dS-p\,dV=0
```

となり，

```math
T\,dS=p\,dV
```

を得る．
両辺を $T\,dV$ で割ると，

```math
\left(\frac{\partial S}{\partial V}\right)_U
=\frac{p}{T}
\tag{7}
```

となる．
左辺は，内部エネルギー $U$ を一定に保ったときの，体積 $V$ に対するエントロピー $S$ の偏微分を表す．

$p>0$ ， $T>0$ であるから，

```math
\frac{p}{T}>0
```

である．
よって，

```math
\boxed{
\left(\frac{\partial S}{\partial V}\right)_U>0
}
```

が証明された．

### 補足

特に，状態方程式が

```math
p=f(V)T
```

の形で表される系では，内部エネルギー $U$ は体積 $V$ に依存しない．
この場合， $U$ を一定に保つことは，温度 $T$ を一定に保つことと対応するため，

```math
\left(\frac{\partial S}{\partial V}\right)_U
=
\left(\frac{\partial S}{\partial V}\right)_T
```

となる．
したがって，このような系では，(ii) の結果は前問で扱った特殊な場合を含んでいる．
