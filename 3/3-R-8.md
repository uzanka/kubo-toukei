# 例題【3-R-8】

## 解答

まず，系の状態を記述するために，自由エネルギー $F$ が温度 $T$ とばねの伸び $x$ の関数 $F(T, x)$ であると考える．

### 1. 自由エネルギー $F(T, x)$ の導出

熱力学の基本関係式より，自由エネルギー $F$ の微分は次のように書ける：

$$dF = -S dT + X dx \quad \cdots (1)$$

ここで， $S$ はエントロピー， $X$ はばねの張力である．

式 (1) において，温度 $T$ を一定に保った状態（等温過程）での $F$ の $x$ による変化を考えるため，両辺を $x$ で偏微分すると：

$$\left(\frac{\partial F}{\partial x}\right)_T = X \quad \cdots (2)$$

となる．
問題文より，張力 $X$ は伸び $x$ に比例し，その比例定数（ばね定数）は $k$ であるため， $X = kx$ である．
したがって，

$$\left(\frac{\partial F}{\partial x}\right)_T = kx \quad \cdots (3)$$

が得られる．

この式 (3) を $x$ について積分する．
ここで， $k$ は温度 $T$ の関数であるが， $x$ に関する積分においては $T$ は定数として扱う．

$$\int \left(\frac{\partial F}{\partial x}\right)_T dx = \int kx dx$$

$$F(T, x) = \frac{1}{2}kx^2 + C(T)$$

ここで， $C(T)$ は積分定数であり，温度 $T$ にのみ依存する関数である．
この定数は，ばねの伸びが $x=0$ のときの自由エネルギー $F(T, 0)$ に相当する．
したがって，自由エネルギー $F$ は次のように求められる：

$$F(T, x) = F(T, 0) + \frac{1}{2}kx^2 \quad \cdots (4)$$

### 2. エントロピー $S(T, x)$ の導出

熱力学の定義より，エントロピー $S$ は自由エネルギー $F$ を温度 $T$ で偏微分したものにマイナスをつけたものである：

$$S = -\left(\frac{\partial F}{\partial T}\right)_x \quad \cdots (5)$$

式 (4) を用いて，これを計算する．

$$S(T, x) = -\frac{\partial}{\partial T} \left[ F(T, 0) + \frac{1}{2}k(T)x^2 \right]$$

$$S(T, x) = -\frac{dF(T, 0)}{dT} - \frac{1}{2} \frac{dk}{dT} x^2$$

ここで， $k' = \frac{dk}{dT}$ と定義し，また $S(T, 0) = -\frac{dF(T, 0)}{dT}$ であることを用いると，エントロピー $S$ は次のように求められる：

$$S(T, x) = S(T, 0) - \frac{1}{2}k'x^2 \quad \cdots (6)$$

### 3. 内部エネルギー $U(T, x)$ の導出

自由エネルギー $F$ ，内部エネルギー $U$ ，温度 $T$ ，エントロピー $S$ の間には， $F = U - TS$ ，すなわち $U = F + TS$ という関係がある．
これに，先ほど求めた式 (4) と式 (6) を代入する．

$$U(T, x) = \left[ F(T, 0) + \frac{1}{2}kx^2 \right] + T \left[ S(T, 0) - \frac{1}{2}k'x^2 \right]$$

式を整理する．

$$U(T, x) = F(T, 0) + TS(T, 0) + \frac{1}{2}kx^2 - \frac{1}{2}Tk'x^2$$

$$U(T, x) = \{ F(T, 0) + TS(T, 0) \} + \frac{1}{2}(k - Tk')x^2$$

ここで， $U(T, 0) = F(T, 0) + TS(T, 0)$ であるため，最終的に内部エネルギー $U$ は次のように求められる：

$$U(T, x) = U(T, 0) + \frac{1}{2}(k - Tk')x^2 \quad \cdots (7)$$

以上より，求める結果は以下の通りである：
- $F(T, x) = F(T, 0) + \frac{1}{2}kx^2$
- $S(T, x) = S(T, 0) - \frac{1}{2}k'x^2 \quad \left(k' = \frac{dk}{dT}\right)$
- $U(T, x) = U(T, 0) + \frac{1}{2}(k - Tk')x^2$

## 解説

この問題のポイントは，ばね定数 $k$ が温度 $T$ に依存している点である．

### 1. 自由エネルギーの定義

物理学において，系の状態が温度 $T$ と別の変数 $x$ （今回はばねの伸び）で決まるとき，その状態を記述する関数として自由エネルギー $F$ を用いる．
等温過程において，外部からばねに加わる力（張力 $X$ ）は，自由エネルギーの $x$ による変化率（偏微分）として表される．

### 2. 温度依存性の扱い

通常の力学ではばね定数 $k$ は定数として扱われるが，熱力学では $k$ が温度によって変化することを考慮する必要がある．
そのため， $k$ を $k(T)$ とみなし，その温度変化率を $k' = \frac{dk}{dT}$ として計算に組み込んでいる．

### 3. エネルギーの変換

自由エネルギー $F$ は「等温過程における仕事ができる能力」を表し，内部エネルギー $U$ は「系が持つ全エネルギー」を表す．
エントロピー $S$ を介してこれらは結びついている．
今回の結果において，内部エネルギーの項に $(k - Tk')$ という形が現れたのは，温度変化に伴ってばね定数が変わることによるエネルギーの寄与が反映されているためである．
