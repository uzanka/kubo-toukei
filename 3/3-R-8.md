# 例題【3-R-8】

## 解答

ばね定数 $k$ が温度 $T$ に依存するばねを考える．
ばねの伸びを $x$ ，ばねの張力を $X$ とすると，問題の条件より，

```math
X=k(T)x
```

が成立する．
また，ばねの熱膨張は考えないものとする．
このとき，自由エネルギー $F$ ，エントロピー $S$ ，内部エネルギー $U$ を求める．

### 1．自由エネルギー $F$ を求める

ばねの状態が温度 $T$ と伸び $x$ によって定まるとき，ヘルムホルツ自由エネルギーを $F(T,x)$ と表す．
熱力学の基本関係式は，

```math
dF=-S\,dT+X\,dx
\tag{1}
```

である．
ここで， $S$ はエントロピー， $X$ はばねの張力である．
準静的過程では，ばねを引く外力とばねの張力がつり合うため，外力がばねにする仕事は $X\,dx$ と表される．

式 (1) より，温度 $T$ を一定に保ったとき，

```math
\left(\frac{\partial F}{\partial x}\right)_T=X
```

となる．
ここで， $X=k(T)x$ を代入すると，

```math
\left(\frac{\partial F}{\partial x}\right)_T=k(T)x
\tag{2}
```

を得る．

温度 $T$ を一定に保って $x$ について積分すると， $k(T)$ は積分中に定数として扱えるため，

```math
F(T,x)=\frac12 k(T)x^2+C(T)
```

となる．
ここで， $C(T)$ は温度のみの関数である．
伸びが $x=0$ のときには，

```math
C(T)=F(T,0)
```

であるから，自由エネルギーは

```math
\boxed{
F(T,x)=F(T,0)+\frac12 k(T)x^2
}
\tag{3}
```

と求められる．

### 2．エントロピー $S$ を求める

自由エネルギーの全微分式 (1) より，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_x
```

である．
式 (3) を温度 $T$ について偏微分する．
このとき，伸び $x$ を一定に保ち，ばね定数 $k(T)$ の温度依存性を考慮すると，

```math
\begin{aligned}
S(T,x)
&=-\frac{\partial}{\partial T}
\left[F(T,0)+\frac12 k(T)x^2\right]\\
&=-\frac{dF(T,0)}{dT}
-\frac12\frac{dk}{dT}x^2
\end{aligned}
```

となる．
ここで，

```math
S(T,0)=-\frac{dF(T,0)}{dT},
\qquad
k'=\frac{dk}{dT}
```

と定義すれば，

```math
\boxed{
S(T,x)=S(T,0)-\frac12 k'x^2
}
\tag{4}
```

を得る．

### 3．内部エネルギー $U$ を求める

ヘルムホルツ自由エネルギーの定義

```math
F=U-TS
```

より，

```math
U=F+TS
```

である．
式 (3)，(4) を代入すると，

```math
\begin{aligned}
U(T,x)
={}&F(T,0)+\frac12 kx^2\\
&+T\left[S(T,0)-\frac12 k'x^2\right]\\
={}&F(T,0)+TS(T,0)
+\frac12(k-Tk')x^2
\end{aligned}
```

となる．
ここで，伸びが $x=0$ のときにも $U=F+TS$ が成立するため，

```math
U(T,0)=F(T,0)+TS(T,0)
```

である．
したがって，内部エネルギーは

```math
\boxed{
U(T,x)=U(T,0)+\frac12(k-Tk')x^2
}
\tag{5}
```

と求められる．

以上より，求める自由エネルギー，エントロピー，内部エネルギーは，

```math
\boxed{
F(T,x)=F(T,0)+\frac12 k(T)x^2
}
```

```math
\boxed{
S(T,x)=S(T,0)-\frac12\frac{dk}{dT}x^2
}
```

```math
\boxed{
U(T,x)=U(T,0)+\frac12
\left(k-T\frac{dk}{dT}\right)x^2
}
```

である．
ここで， $F(T,0)$ ， $S(T,0)$ ， $U(T,0)$ は，伸びがゼロの基準状態における各熱力学量であり，温度 $T$ の関数である．


## 解説

この問題の重要点は，ばね定数が温度に依存するため，自由エネルギーと内部エネルギーの伸びに関する項が一般には一致しないことである．
- 自由エネルギーの伸びに関する項は $\frac12 kx^2$ である．
- エントロピーの伸びに関する項は $-\frac12 k'x^2$ である．
- 内部エネルギーの伸びに関する項は $\frac12(k-Tk')x^2$ である．

もし $k$ が温度に依存しない場合には $k'=0$ となり，エントロピーは伸び $x$ に依存しなくなる．
このとき，自由エネルギーと内部エネルギーの伸びに関する項はいずれも $\frac{1}{2} kx^2$ となる．

なお，力学で用いるばねのポテンシャルエネルギー $\frac{1}{2} kx^2$ は，通常，ばね定数を温度に依存しない定数として扱う場合の表現である．
本問題では，ばね定数の温度依存性を考慮するため，等温過程での仕事と関係する自由エネルギーと，熱力学的な内部エネルギーを区別する必要がある．
