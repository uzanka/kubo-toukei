# 演習問題【3-B-23】

## 解答

### 1．熱容量の大小関係

前問で導いた公式より，

```math
C_{V,N}=C_{V,\mu}
-T\frac{\left(\dfrac{\partial N}{\partial T}\right)_{V,\mu}^{2}}
{\left(\dfrac{\partial N}{\partial\mu}\right)_{T,V}}
```

である．
通常の熱力学的に安定な系では，粒子数の化学ポテンシャルに対する応答は正であり，

```math
\left(\frac{\partial N}{\partial\mu}\right)_{T,V}>0
```

が成り立つ．
また，絶対温度は $T>0$ であり，偏微分の二乗は非負である．
したがって，

```math
\boxed{
C_{V,N}\le C_{V,\mu}
}
\tag{1}
```

となる．

### 2．ルシャトリエ・ブラウンの原理による解釈

この大小関係を解釈するため，物質粒子を通すことができ，かつ熱も通すことができる壁で囲まれた系を考える．
外部から系に熱 $Q>0$ を与えたときの温度上昇を比較する．
体積は一定とする．

まず，粒子数 $N$ が一定の場合を考える．
この場合，系と外部との間で物質の移動は起こらない．熱容量の定義から，温度上昇は

```math
(\Delta T)_N=\frac{Q}{C_{V,N}}
\tag{2}
```

である．

次に，化学ポテンシャル $\mu$ が一定の場合を考える．
この場合，系は粒子源と物質をやり取りできるため，熱を与えたときに粒子の流入または流出が起こり得る．
この物質移動は，温度上昇という外部からの作用を緩和する方向に働く．

ルシャトリエ・ブラウンの原理によれば，外部から加えられた作用に対して，系に生じる二次的な変化は，その作用を打ち消す方向に起こる．
したがって，物質移動を許した場合の温度上昇は，粒子移動を禁止した場合よりも小さくなる．
すなわち，

```math
(\Delta T)_\mu\le(\Delta T)_N
\tag{3}
```

である．

熱容量の定義より，

```math
(\Delta T)_\mu=\frac{Q}{C_{V,\mu}}
```

であるから，式 (2)，(3) より，

```math
\frac{Q}{C_{V,\mu}}
\le
\frac{Q}{C_{V,N}}
```

となる．
$Q>0$ であり，熱容量が正であることから，

```math
\boxed{
C_{V,N}\le C_{V,\mu}
}
```

を得る．
これは式 (1) と一致する．

したがって， **粒子数を固定した系よりも，化学ポテンシャルを固定して粒子の出入りを許した系の方が，同じ熱量を与えたときの温度上昇が小さく，熱容量が大きいか，少なくとも等しい** ．
これが，ルシャトリエ・ブラウンの原理による解釈である．

### 3．定圧熱容量との違い

なお，1成分系では，定圧熱容量について $C_{p,N}$ と $C_{p,\mu}$ を同様に比較することはできない．
Gibbs–Duhem の関係により，温度 $T$ ，圧力 $p$ ，化学ポテンシャル $\mu$ の間には

```math
S\,dT-V\,dp+N\,d\mu=0
```

という関係があり，これら3つの変数は独立ではないためである．
