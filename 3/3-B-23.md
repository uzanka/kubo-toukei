# 演習問題【3-B-23】

## 解答

体積 $V$ が一定の条件のもとで，粒子数 $N$ が一定である場合の熱容量 $C_{V,N}$ と，化学ポテンシャル $\mu$ が一定である場合の熱容量 $C_{V,\mu}$ を比較すると，以下の関係が成り立つ．

$$C_{V,N} \le C_{V,\mu}$$

この関係をルシャトリエ・ブラウンの原理（Le Chatelier-Braun principle）を用いて解釈する．

ルシャトリエ・ブラウンの原理とは，「系に外部から変化（摂動）が加えられたとき，その変化を打ち消す（緩和させる）方向に変化が起こる」という原理である．

いま，系に外部から熱 $Q$ を与えるという変化を加えたとする．
この「作用」により，系の温度 $T$ が上昇しようとする（ $\Delta T > 0$ ）．

1. **粒子数 $N$ が一定の場合（ $(\Delta T)_N$ ）**
   系は物質粒子を外部とやり取りできないため，与えられた熱 $Q$ はすべて系の内部エネルギーを上昇させ，温度の上昇 $(\Delta T)_N$ に直接寄与する．
   このとき，温度上昇は次のように書ける．
```math
(\Delta T)_N = \frac{Q}{C_{V,N}}
```

2. **化学ポテンシャル $\mu$ が一定の場合（ $(\Delta T)_\mu$ ）**
   系は物質粒子を外部（粒子源）とやり取りできる透熱壁で包まれていると考える．
   熱 $Q$ が与えられて温度が上がろうとすると，ルシャトリエ・ブラウンの原理に従い，その温度上昇を打ち消す方向に変化が起こる．
   温度が上がると，系の化学ポテンシャル $\mu$ も変化しようとするが， $\mu$ は一定に保たれる必要があるため，粒子が系から流れ出したり，逆に流れ込んだりする（物質の流れ $J_M$ ）ことで， $\mu$ の変化を補償する．
   この物質の流れに伴うエネルギーの変化（エントロピーの変化や化学ポテンシャルによる仕事など）が，温度上昇を抑える方向に働く．
   つまり，物質の流れ $J_M$ は「温度を低める向き」に起こるため，温度上昇は粒子数一定の場合よりも小さくなる．
```math
(\Delta T)_\mu < (\Delta T)_N
```

この温度上昇の関係式を熱容量の定義式を用いて書き換えると，

$$\frac{Q}{C_{V,\mu}} < \frac{Q}{C_{V,N}}$$

となり，分母を整理すると

$$C_{V,N} < C_{V,\mu}$$

が得られる．
粒子移動が温度変化を緩和する「バッファ」として機能するため， $\mu$ 一定条件の方が熱容量は大きくなるのである．

## 解説

### 1. 熱容量の物理的意味

熱容量とは，「系の温度を 1 単位上げるために必要な熱量」のことである．
熱容量が大きいほど，同じ量の熱を与えても温度が上がりにくい．

$$C = \frac{Q}{\Delta T}$$

### 2. 拘束条件の違い

- $C_{V,N}$ (粒子数一定):
  系が完全に閉じた状態（あるいは物質移動が禁止された状態）での熱容量．
  熱を与えると，そのエネルギーは純粋に温度（内部エネルギー）を上げるためだけに消費される．
- $C_{V,\mu}$ (化学ポテンシャル一定):
  系が粒子源とつながり，物質を自由にやり取りできる状態での熱容量．
  熱を与えると，温度上昇を抑えるために粒子が移動し，その移動プロセスがエネルギーを吸収したり，温度上昇を打ち消したりする．

### 3. ルシャトリエ・ブラウンの原理の適用

ルシャトリエ・ブラウンの原理は，化学平衡や熱力学的平衡の議論で非常に強力である．
「温度を上げようとする外部からの働き」に対し，系が「温度を下げようとする反応」を起こす．
具体的には， $\mu$ を一定に保つために粒子が移動することで，熱の流入によるエネルギー増加分の一部を「粒子の移動に伴うエネルギーの変化」として吸収し，結果として温度上昇を抑制する．

この「変化を打ち消す働き」があるため， $\mu$ 一定の条件では温度変化に対する抵抗力（熱容量）が，粒子数一定の条件よりも強くなるのである．

これは定圧条件における $C_V \le C_p$ の関係（圧力を上げようとする変化を，体積膨張が打ち消すことで温度上昇を抑える）と論理的に非常によく似た構造を持っている．
