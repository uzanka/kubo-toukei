# 演習問題【3-B-23】

## 解答

### 1．熱容量の大小関係

前問で導いた関係式より，

```math
C_{V,N}
=
C_{V,\mu}
-
T\frac{
\left(\dfrac{\partial N}{\partial T}\right)_{V,\mu}^{2}
}{
\left(\dfrac{\partial N}{\partial\mu}\right)_{T,V}
}
```

が成立する．

ここで，熱容量はそれぞれ

```math
C_{V,N}
=
T\left(\frac{\partial S}{\partial T}\right)_{V,N}
```

```math
C_{V,\mu}
=
T\left(\frac{\partial S}{\partial T}\right)_{V,\mu}
```

と定義する．

通常の正則な熱力学的安定単一相では，粒子数の化学ポテンシャルに対する応答は正であり，

```math
\left(\frac{\partial N}{\partial\mu}\right)_{T,V}>0
```

が成立する．

また，絶対温度は $T>0$ であり，偏微分の二乗は非負である．
したがって，

```math
C_{V,\mu}-C_{V,N}\geq0
```

となるので，

```math
\boxed{
C_{V,N}\leq C_{V,\mu}
}
\tag{1}
```

を得る．

これは，定積熱容量について，粒子数を一定にした場合よりも化学ポテンシャルを一定にした場合の方が，熱容量が大きいか，少なくとも等しいことを示している．

### 2．ルシャトリエ・ブラウンの原理による解釈

この大小関係を解釈するため，物質粒子を通すことができ，かつ熱も通すことができる透熱壁で囲まれた系を考える．

系の体積は一定とし，外部から系に正の微小熱量 $\delta Q>0$ を与えたときの温度上昇を比較する．

まず，粒子数 $N$ が一定の場合を考える．

この場合，系と外部との間で物質の移動は起こらない．
熱容量の定義より，

```math
\delta Q=C_{V,N}\,dT_N
```

であるから，

```math
\boxed{
dT_N=\frac{\delta Q}{C_{V,N}}
}
\tag{2}
```

となる．

次に，化学ポテンシャル $\mu$ が一定の場合を考える．

この場合，系は外部の粒子源と物質をやり取りできるため，熱を与えると，それに伴って粒子の流入または流出が起こり得る．

この粒子移動は，温度上昇という外部からの作用を緩和する方向に働く．

ルシャトリエ・ブラウンの原理によれば，外部から加えられた作用に対して，系に生じる二次的な変化は，その作用を打ち消す方向に起こる．

したがって，粒子移動を禁止した場合の温度上昇 $dT_N$ は，粒子移動を許した場合，すなわち化学ポテンシャル一定の場合の温度上昇 $dT_\mu$ よりも大きいか，少なくとも等しい．

すなわち，

```math
\boxed{
dT_N\geq dT_\mu
}
\tag{3}
```

である．

一方，化学ポテンシャル一定の場合には，

```math
\delta Q=C_{V,\mu}\,dT_\mu
```

であるから，

```math
dT_\mu=\frac{\delta Q}{C_{V,\mu}}
```

となる．

式(2)，(3)より，

```math
\frac{\delta Q}{C_{V,\mu}}
\leq
\frac{\delta Q}{C_{V,N}}
```

を得る．

ここで， $\delta Q>0$ であり，両熱容量が正であることから，

```math
\boxed{
C_{V,N}\leq C_{V,\mu}
}
```

となる．

これは式(1)と一致する．

したがって，粒子数を固定した系よりも，化学ポテンシャルを固定して粒子の出入りを許した系の方が，同じ微小熱量を与えたときの温度上昇が小さいか，少なくとも等しい．

これがルシャトリエ・ブラウンの原理による解釈である．

なお，粒子の流入・流出の方向は物質の性質によって異なるが，粒子移動によって温度上昇が緩和されるという結論は変わらない．

また，粒子数が変化する場合，体積一定の熱力学第一法則は，

```math
dU=T\,dS+\mu\,dN
```

である．
したがって，開放系では内部エネルギーの変化と熱の授受を区別する必要がある．
ここで用いた熱容量は，いずれも $T(\partial S/\partial T)$ によって定義したものである．

### 3．定圧熱容量との違い

なお，1成分の均質系では，定圧熱容量について $C_{p,N}$ の代わりに $C_{p,\mu}$ を考えることはできない．

Gibbs–Duhemの関係により，

```math
S\,dT-V\,dp+N\,d\mu=0
```

が成立する．

ここで，圧力 $p$ と化学ポテンシャル $\mu$ を一定にすると，

```math
dp=0,\qquad d\mu=0
```

であるから，

```math
S\,dT=0
```

となる．

通常の熱力学的状態では $S>0$ であるため，

```math
dT=0
```

である．

したがって，温度 $T$ ，圧力 $p$ ，化学ポテンシャル $\mu$ の3つの変数は独立ではなく，圧力と化学ポテンシャルを同時に一定に保ったまま温度を変化させることはできない．

よって，1成分の均質系では， $C_{p,\mu}$ を独立な熱容量として定義することはできない．

結論

```math
\boxed{
C_{V,N}\leq C_{V,\mu}
}
```

粒子移動を許すことによって，外部から加えられた熱に対する温度上昇が緩和される．
この結果は，ルシャトリエ・ブラウンの原理と整合している．

なお，等号が成立するのは，

```math
\left(\frac{\partial N}{\partial T}\right)_{V,\mu}=0
```

の場合であり，粒子移動による熱的応答への寄与がない場合に相当する．
