# 演習問題【3-A-15】

## 解答

ゴム糸の長さを $l$ ，温度を $T$ ，エントロピーを $S$ ，張力を $f$ とする．
前問より，張力は

```math
f=AT \qquad (A>0)
```

で与えられる．
ここで， $A$ は長さ $l$ に依存してもよいが，温度 $T$ には依存しないものとする．
また，長さを一定に保ったときの熱容量を

```math
C_l=T\left(\frac{\partial S}{\partial T}\right)_l
```

と定義する．
以下では，熱容量 $C_l>0$ の安定な状態を考える．

### 1．断熱的に引き伸ばすと温度が上昇すること

まず，断熱可逆過程を考える．
断熱可逆過程ではエントロピーが一定であるため，

```math
dS=0
```

が成り立つ．
エントロピー $S$ は温度 $T$ と長さ $l$ の関数であるから，全微分は

```math
dS=
\left(\frac{\partial S}{\partial T}\right)_l dT
+
\left(\frac{\partial S}{\partial l}\right)_T dl
```

と表される．
ここで，熱容量の定義より，

```math
\left(\frac{\partial S}{\partial T}\right)_l
=\frac{C_l}{T}
```

である．
これを代入すると，

```math
dS=\frac{C_l}{T}dT
+\left(\frac{\partial S}{\partial l}\right)_T dl
```

となる．
断熱可逆過程では $dS=0$ であるから，

```math
\frac{C_l}{T}dT
=-\left(\frac{\partial S}{\partial l}\right)_T dl
```

を得る．
したがって，

```math
\left(\frac{\partial T}{\partial l}\right)_S
=-\frac{T}{C_l}
\left(\frac{\partial S}{\partial l}\right)_T
\tag{1}
```

である．

次に，マクスウェルの関係式を用いて，式 (1) の右辺に含まれるエントロピーの偏微分を求める．

ヘルムホルツ自由エネルギーを

```math
F=U-TS
```

と定義する．
ゴム糸に対して，内部エネルギー $U$ の微小変化は

```math
dU=T\,dS+f\,dl
```

と表される．
ここで $f\,dl$ は，ゴム糸を長さ $dl$ だけ伸ばすために外部から加える微小仕事である．
したがって，

```math
\begin{aligned}
dF
&=dU-T\,dS-S\,dT\\
&=-S\,dT+f\,dl
\end{aligned}
```

となる．
一方， $F$ を温度 $T$ と長さ $l$ の関数とみなすと，

```math
dF=
\left(\frac{\partial F}{\partial T}\right)_l dT
+
\left(\frac{\partial F}{\partial l}\right)_T dl
```

である．
両式を比較することにより，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_l,
\qquad
f=\left(\frac{\partial F}{\partial l}\right)_T
```

を得る．
自由エネルギーの混合二階偏微分が等しいことから，

```math
\left(\frac{\partial S}{\partial l}\right)_T
=-\left(\frac{\partial f}{\partial T}\right)_l
```

が成り立つ．
これがマクスウェルの関係式である．

前問の関係式 $f=AT$ より，長さ $l$ を一定に保ったとき，

```math
\left(\frac{\partial f}{\partial T}\right)_l=A
```

である．
したがって，

```math
\left(\frac{\partial S}{\partial l}\right)_T=-A
```

となる．
これを式 (1) に代入すると，

```math
\boxed{
\left(\frac{\partial T}{\partial l}\right)_S
=\frac{TA}{C_l}>0
}
```

を得る．
ここで， $T>0$ ， $A>0$ ， $C_l>0$ を用いた．
よって，断熱可逆的にゴム糸を引き伸ばすと，温度は上昇することが示された．

### 2．一定張力で温度を高めると長さが縮むこと

次に，張力 $f$ を一定に保ちながら温度 $T$ を変化させる過程を考える．
張力は $f=f(T,l)$ であるから，全微分は

```math
df=
\left(\frac{\partial f}{\partial T}\right)_l dT
+
\left(\frac{\partial f}{\partial l}\right)_T dl
```

と表される．
張力一定の条件 $df=0$ を用いると，

```math
\left(\frac{\partial f}{\partial l}\right)_T dl
=-\left(\frac{\partial f}{\partial T}\right)_l dT
```

となる．
したがって，

```math
\left(\frac{\partial l}{\partial T}\right)_f
=-\frac{(\partial f/\partial T)_l}
{(\partial f/\partial l)_T}
\tag{2}
```

を得る．

前問の関係式 $f=AT$ より，

```math
\left(\frac{\partial f}{\partial T}\right)_l=A>0
```

である．
また，熱力学的に安定な状態では，長さを一定温度のもとで増加させると張力が増加するため，

```math
\left(\frac{\partial f}{\partial l}\right)_T>0
```

が成り立つ．
この条件は，ゴム糸が安定な状態で正の伸長剛性を持つことに対応する．

以上を式 (2) に代入すると，

```math
\boxed{
\left(\frac{\partial l}{\partial T}\right)_f
=-\frac{A}{(\partial f/\partial l)_T}<0
}
```

となる．
したがって，張力を一定に保って温度を高めると，ゴム糸の長さは減少することが示された．

以上より，ゴム糸について，断熱可逆的な伸長では温度が上昇し，張力一定のもとで温度を上昇させると長さが縮むことが示された．
