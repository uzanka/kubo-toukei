# 例題【3-R-1】

## 解答

### （i）エンタルピーと合成系の内部エネルギー

エンタルピー $H$ は，系の内部エネルギー $U$ ，圧力 $p$ ，体積 $V$ を用いて

```math
H=U+pV
```

と定義される．
この式の $pV$ が，外圧を与える仕事源のエネルギーに対応することを示す．

断面積 $\sigma$ のシリンダーに気体を入れ，その上に質量のないピストンを置く．
さらに，ピストンの上に質量 $M$ のおもりを載せる．
重力加速度を $g$ とすると，おもりが気体に加える外圧 $p^{(e)}$ は

```math
p^{(e)}=\frac{Mg}{\sigma}
\tag{1}
```

である．
ピストンの高さを $z$ とすれば，気体の体積は

```math
V=\sigma z
\tag{2}
```

である．

気体とおもりが力学的につり合っているとき，気体の圧力 $p$ は外圧 $p^{(e)}$ と一致する．
すなわち，

```math
p=p^{(e)}=\frac{Mg}{\sigma}
\tag{3}
```

である．

ここで，気体だけでなく，外圧を与えるおもりと地球も含めた合成系を考える．
地球の位置を固定し，おもりの位置エネルギーの基準を適切に選ぶと，おもりの位置エネルギー $U_e$ は

```math
U_e=Mgz
\tag{4}
```

と書ける．
式（1）～（3）を用いると，

```math
\begin{aligned}
U_e
&=Mgz\\
&=\frac{Mg}{\sigma}\sigma z\\
&=pV
\end{aligned}
\tag{5}
```

となる．
したがって，合成系のエネルギー $U^*$ は，気体の内部エネルギー $U$ とおもりの位置エネルギーの和として，

```math
U^*=U+U_e=U+pV
\tag{6}
```

と表される．
ここで，おもりの位置エネルギーは，厳密にはおもりと地球との相互作用に由来するエネルギーである．

エンタルピーの定義 $H=U+pV$ と式（6）を比較すると，

```math
\boxed{
U^*=H
}
```

が得られる．
ただし，位置エネルギーの基準の選び方に応じた任意定数は除いている．

なお，この議論では，気体の圧力と外圧がつり合っていることが重要である．
外圧を変える場合，おもりの質量 $M$ と高さ $z$ の両方が変化し得る．
そのため，おもりの位置エネルギーの変化は，単にピストンが上下することによる変化だけではない．
式（5）を微分すると，

```math
dU_e=d(pV)=p\,dV+V\,dp
\tag{7}
```

となる．
第1項 $p\,dV$ はピストンの移動に伴うエネルギー変化に対応し，第2項 $V\,dp$ は外圧を変えるためにおもりを追加したり取り除いたりすることに伴うエネルギー変化に対応する．
両方を含めることで，おもりの位置エネルギーの変化が $d(pV)$ と一致するのである．

以上より，系に圧力を加える仕事源も含めて考えると，その合成系のエネルギーはエンタルピーに等しいことが示された．

### （ii）一定の外圧のもとでの熱吸収量とエンタルピー変化

始状態を1，終状態を2とし，系が吸収する熱量を $Q$ とする．
ここでは，系が外部にする仕事を正とする符号規約を採用する．
また，系が外界と行う仕事は体積仕事だけであると仮定する．

熱力学第一法則は，

```math
U_2-U_1=Q-W_{\mathrm{by}}
\tag{8}
```

である．
ここで $W_{\mathrm{by}}$ は，系が外部に対して行う仕事である．

外圧 $p^{(e)}$ が一定であるとき，体積が $dV$ だけ変化する際に系が外部にする仕事は

```math
dW_{\mathrm{by}}=p^{(e)}\,dV
```

である．
したがって，始状態から終状態まで積分すると，

```math
\begin{aligned}
W_{\mathrm{by}}
&=\int_{V_1}^{V_2}p^{(e)}\,dV\\
&=p^{(e)}(V_2-V_1)
\end{aligned}
\tag{9}
```

となる．
この式は，変化の途中で系の圧力 $p$ が外圧 $p^{(e)}$ と一致しない場合にも成立する．
必要なのは，外圧が一定であり，体積仕事以外の仕事がないことである．

式（9）を式（8）に代入すると，

```math
U_2-U_1
=Q-p^{(e)}(V_2-V_1)
```

を得る．
これを $Q$ について解けば，

```math
Q=(U_2-U_1)+p^{(e)}(V_2-V_1)
\tag{10}
```

となる．

ここで，始状態と終状態はともに熱平衡状態にある．
また，両端の状態では系の圧力と外圧がつり合っているので，

```math
p_1=p_2=p^{(e)}
```

である．
したがって，式（10）は

```math
\begin{aligned}
Q
&=(U_2+p_2V_2)-(U_1+p_1V_1)\\
&=H_2-H_1
\end{aligned}
```

と書ける．
ゆえに，

```math
\boxed{
Q=\Delta H=H_2-H_1
}
```

が得られる．
すなわち，一定の外圧のもとで，始状態と終状態が熱平衡状態にあり，体積仕事以外の仕事がない場合には，系が吸収する熱量はエンタルピーの増加量に等しい．

この結果は，変化が可逆であるか不可逆であるかに依存しない．
なぜなら，熱量 $Q$ と仕事 $W_{\mathrm{by}}$ は一般に変化の経路に依存するものの，式（9）の仕事は一定の外圧のもとで体積の変化だけによって定まり，式（10）の右辺は始状態と終状態の状態量だけで表されるからである．
したがって，上記の条件が満たされれば，可逆変化にも不可逆変化にも同じ関係が成立する．

以上より，一定の外圧のもとでの熱吸収量がエンタルピーの増加量に等しいことが証明された．
この性質は，エンタルピーが定圧過程における熱の出入りを扱う際に有用である理由の一つである．
