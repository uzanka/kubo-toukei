# 演習問題【3-B-29】

## 解答

### 1．磁性体の場合

#### 1.1　磁化を指定した自由エネルギー $F(T,M)$

体積 $V$ の常磁性体が一様な磁化 $M$ をもつとき，全磁気モーメントは $MV$ である．
等温磁化率を $\chi_T$ とすると，線形応答の範囲では

```math
M=\chi_T H
```

が成立する．
ここで，磁化率 $\chi_T$ は一般に温度 $T$ に依存する．

磁化 $M$ を指定したとき，磁性体自身の自由エネルギーは，磁化がゼロの場合の自由エネルギー $F(T,0)$ を基準として，

```math
F(T,M)=F(T,0)+\frac{VM^2}{2\chi_T}
\tag{1}
```

と表される．
すなわち，磁化をゼロから $M$ まで変化させると，自由エネルギーは $VM^2/(2\chi_T)$ だけ増加する．

#### 1.2　外部磁場を指定した自由エネルギー $F^*(T,H)$

磁気モーメント $MV$ と外部磁場 $H$ との相互作用エネルギーは，

```math
W=-HMV
\tag{2}
```

である．
この相互作用を含めた自由エネルギーを

```math
F^*(T,H)=F(T,M)-HMV
\tag{3}
```

と定義する．
この式は，磁化 $M$ を指定する形式から，外部磁場 $H$ を指定する形式への変換に対応する．

平衡状態では $M=\chi_T H$ であるため，式 (1) と式 (3) より，

```math
\begin{aligned}
F^*(T,H)
&=F(T,0)+\frac{V(\chi_T H)^2}{2\chi_T}
-H(\chi_T H)V\\
&=F(T,0)+\frac{V}{2}\chi_T H^2
-V\chi_T H^2\\
&=F(T,0)-\frac{V}{2}\chi_T H^2
\end{aligned}
\tag{4}
```

を得る．

したがって，両者の違いは次のとおりである．

- $F(T,M)$ は，磁化 $M$ を指定した磁性体自身の自由エネルギーである．
- $F^*(T,H)$ は，外部磁場 $H$ を指定する形式であり，磁性体と外場との相互作用項 $-HMV$ を含む自由エネルギーである．

#### 1.3　エントロピー $S$ の導出

自由エネルギー $F$ のエントロピーは，温度 $T$ に関する偏微分によって

```math
S=-\left(\frac{\partial F}{\partial T}\right)_{\text{指定した変数}}
```

と求められる．
ここで，偏微分の際には，添字に示した変数を一定に保つ．
また，

```math
S(T,0)=-\frac{\partial F(T,0)}{\partial T},
\qquad
\chi_T'=\frac{\partial\chi_T}{\partial T}
```

とする．

まず，磁化 $M$ を一定に保つ場合，式 (1) から

```math
S=-\left(\frac{\partial F}{\partial T}\right)_M
=S(T,0)-\frac{VM^2}{2}
\frac{\partial}{\partial T}\left(\frac{1}{\chi_T}\right)
```

である．
ここで，

```math
\frac{\partial}{\partial T}\left(\frac{1}{\chi_T}\right)
=-\frac{\chi_T'}{\chi_T^2}
```

を用いると，

```math
S=S(T,0)+\frac{VM^2}{2\chi_T^2}\chi_T'
```

となる．
平衡状態の関係 $M=\chi_T H$ を用いれば，

```math
\boxed{
S=S(T,0)+\frac{V}{2}\chi_T'H^2
}
\tag{5}
```

を得る．

次に，外部磁場 $H$ を一定に保つ場合，式 (4) から

```math
\begin{aligned}
S
&=-\left(\frac{\partial F^*}{\partial T}\right)_H\\
&=-\frac{\partial F(T,0)}{\partial T}
+\frac{V}{2}H^2\frac{\partial\chi_T}{\partial T}\\
&=S(T,0)+\frac{V}{2}\chi_T'H^2
\end{aligned}
```

となる．
したがって，どちらの自由エネルギーから計算しても，同じエントロピーが得られる．

### 2．誘電体の場合

#### 2.1　分極を指定した自由エネルギー $F(T,P)$

誘電率 $\epsilon$ の誘電体が電場 $E$ 中にあるとき，電気分極 $P$ は，ここで用いる単位系では

```math
P=\frac{\epsilon-1}{4\pi}E
\tag{6}
```

で与えられる．
これは，磁性体における $M=\chi_T H$ に対応する関係である．

分極 $P$ を指定したときの誘電体自身の自由エネルギーは，

```math
F(T,P)=F(T,0)+\frac{2\pi VP^2}{\epsilon-1}
\tag{7}
```

と表される．

#### 2.2　外部電場を指定した自由エネルギー $F^*(T,E)$

分極 $P$ と外部電場 $E$ との相互作用エネルギーは，

```math
W=-EPV
\tag{8}
```

である．
したがって，外場との相互作用を含めた自由エネルギーは，

```math
F^*(T,E)=F(T,P)-EPV
\tag{9}
```

と定義される．

平衡状態では，式 (6) より $P=(\epsilon-1)E/(4\pi)$ である．
これを式 (7)，(9) に代入すると，

```math
\begin{aligned}
F^*(T,E)
&=F(T,0)+\frac{2\pi V}{\epsilon-1}
\left(\frac{\epsilon-1}{4\pi}E\right)^2\\
&\qquad
-EV\left(\frac{\epsilon-1}{4\pi}E\right)\\
&=F(T,0)+\frac{V(\epsilon-1)}{8\pi}E^2
-\frac{V(\epsilon-1)}{4\pi}E^2\\
&=F(T,0)-\frac{V}{8\pi}(\epsilon-1)E^2
\end{aligned}
\tag{10}
```

を得る．
これは問題文の式 (2) である．

したがって，誘電体の場合も，磁性体と同様に，

- $F(T,P)$ は，分極 $P$ を指定した誘電体自身の自由エネルギーである．
- $F^*(T,E)$ は，外部電場 $E$ を指定する形式であり，誘電体と外場との相互作用項 $-EPV$ を含む自由エネルギーである．

という違いがある．

#### 2.3　エントロピー $S$ の導出

誘電体についても，

```math
S(T,0)=-\frac{\partial F(T,0)}{\partial T},
\qquad
\epsilon'=\frac{\partial\epsilon}{\partial T}
```

とする．

まず，分極 $P$ を一定に保つ場合，式 (7) から

```math
S=-\left(\frac{\partial F}{\partial T}\right)_P
=S(T,0)-2\pi VP^2
\frac{\partial}{\partial T}
\left(\frac{1}{\epsilon-1}\right)
```

である．
ここで，

```math
\frac{\partial}{\partial T}
\left(\frac{1}{\epsilon-1}\right)
=-\frac{\epsilon'}{(\epsilon-1)^2}
```

を用いると，

```math
S=S(T,0)+\frac{2\pi VP^2}{(\epsilon-1)^2}\epsilon'
```

となる．
さらに，式 (6) から

```math
P^2=\frac{(\epsilon-1)^2}{16\pi^2}E^2
```

であるため，

```math
\boxed{
S=S(T,0)+\frac{V}{8\pi}\epsilon'E^2
}
\tag{11}
```

を得る．

次に，外部電場 $E$ を一定に保つ場合，式 (10) から

```math
\begin{aligned}
S
&=-\left(\frac{\partial F^*}{\partial T}\right)_E\\
&=-\frac{\partial F(T,0)}{\partial T}
+\frac{V}{8\pi}E^2\frac{\partial\epsilon}{\partial T}\\
&=S(T,0)+\frac{V}{8\pi}\epsilon'E^2
\end{aligned}
```

となる．
したがって，誘電体の場合も，二通りの計算で同じエントロピーが得られる．

### 3．結論

磁性体と誘電体の自由エネルギーは，それぞれ

```math
\begin{aligned}
F(T,M)&=F(T,0)+\frac{VM^2}{2\chi_T},\\
F^*(T,H)&=F(T,0)-\frac{V}{2}\chi_T H^2,\\
F(T,P)&=F(T,0)+\frac{2\pi VP^2}{\epsilon-1},\\
F^*(T,E)&=F(T,0)-\frac{V}{8\pi}(\epsilon-1)E^2
\end{aligned}
```

である．
前者は磁化または分極を指定した自由エネルギーであり，後者は外場との相互作用項を含み，外場を指定する形式に変換した自由エネルギーである．

エントロピーは，磁性体では

```math
\boxed{
S=S(T,0)+\frac{V}{2}\chi_T'H^2
}
```

誘電体では

```math
\boxed{
S=S(T,0)+\frac{V}{8\pi}\epsilon'E^2
}
```

である．
それぞれ，磁化と電場を指定した自由エネルギーのどちらから計算しても同じ結果となる．
