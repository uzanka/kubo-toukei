# 例題【3-R-9】

## 解答

### 1．熱容量とエントロピーの関係

状態量 $x$ を一定に保つ過程を考える．
この過程における熱容量 $C_x$ は，

```math
C_x=T\left(\frac{\partial S}{\partial T}\right)_x
```

で定義される．
したがって，

```math
\left(\frac{\partial S}{\partial T}\right)_x
=\frac{C_x}{T}
\tag{1}
```

である．

以下では，対象とする系が熱力学的に安定であり，

```math
C_x(T)\geq0
```

であるとする．
また，熱容量は低温で有限な極限をもつものとする．
これは，通常の平衡熱力学における低温での正則性に関する仮定である．

### 2．熱力学第3法則の適用

熱力学第3法則より，温度を絶対零度に近づけると，エントロピーは有限な値 $S_0$ に近づく．
すなわち，

```math
\lim_{T\to0^+}S(T,x)=S_0
\tag{2}
```

である．

式（1）を温度について積分すると，

```math
S(T,x)-S(\varepsilon,x)
=
\int_\varepsilon^T
\frac{C_x(T')}{T'}\,dT'
```

となる．
ここで $\varepsilon\to0^+$ とし，式（2）を用いると，

```math
S(T,x)-S_0
=
\int_0^T
\frac{C_x(T')}{T'}\,dT'
\tag{3}
```

を得る．
この積分は広義積分であり，式（2）より有限値に収束する．

### 3．熱容量の極限

熱容量の低温極限を

```math
\lim_{T\to0^+}C_x(T)=c
```

とおく．
熱容量は非負であり，その有限な極限も非負であるから，

```math
c\geq0
```

である．

ここで，仮に $c>0$ とすると，極限の定義から，十分低い温度では

```math
C_x(T)>\frac{c}{2}
```

が成立する．
したがって，式（3）の積分について，

```math
\begin{aligned}
\int_0^T\frac{C_x(T')}{T'}\,dT'
&\geq
\int_0^T\frac{c}{2T'}\,dT'\\
&=\lim_{\varepsilon\to0^+}
\frac{c}{2}\ln\frac{T}{\varepsilon}\\
&=+\infty
\end{aligned}
```

となる．

これは，式（3）の積分が有限値に収束するという第3法則の帰結に矛盾する．

よって，

```math
c>0
```

は成立しない．
一方， $c\geq0$ であるから，

```math
\boxed{
\lim_{T\to0^+}C_x(T)=0
}
```

となる．

### 4．結論

熱力学第3法則によるエントロピーの有限値への収束と，熱容量の非負性から，熱容量が正の値に収束することは排除される．
熱容量の低温極限が有限値として存在するという正則性条件のもとで，

```math
\boxed{
\lim_{T\to0^+}C_x(T)=0
}
```

が示された．

これは絶対零度で熱容量を測定するという意味ではなく，温度を絶対零度に近づけると，熱容量もゼロに近づくという極限の主張である．
