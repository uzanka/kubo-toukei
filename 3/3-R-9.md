# 例題【3-R-9】

## 解答

ある状態量 $x$ を一定に保つ過程を考える．
この過程における熱容量 $C_x$ は，エントロピー $S$ を用いて

```math
C_x=T\left(\frac{\partial S}{\partial T}\right)_x
```

と表される．
ここで， $T$ は絶対温度であり，偏微分は $x$ を一定に保ったときの温度変化に対する微分である．
したがって，

```math
\left(\frac{\partial S}{\partial T}\right)_x
=\frac{C_x}{T}
```

が成り立つ．

熱力学第3法則によれば，絶対温度 $T$ がゼロに近づくとき，エントロピー $S$ は有限の値 $S_0$ に近づく．
すなわち，

```math
\lim_{T\to0}S(T)=S_0
```

である．
ここで， $S_0$ は有限な定数である．

上の熱容量とエントロピーの関係を温度について積分すると，

```math
S(T)-S_0
=\int_0^T\frac{C_x(T')}{T'}\,dT'
```

となる．
左辺は $T\to0$ でゼロに近づくため，右辺の積分は有限でなければならない．

ここで，熱容量の極限 $\lim_{T\to0}C_x(T)$ が存在すると仮定する．
熱力学的に安定な系では熱容量は非負であるため，その極限も非負である．
仮に，

```math
\lim_{T\to0}C_x(T)=c>0
```

であるとすると，十分低い温度では $C_x(T)$ は正の定数 $c$ に近い値をとる．
したがって，積分の低温部分は

```math
\int_0^T\frac{C_x(T')}{T'}\,dT'
```

において， $\int_0^T c/T'\,dT'$ と同様に対数発散することになる．
実際，

```math
\int_\varepsilon^T\frac{c}{T'}\,dT'
=c\ln\frac{T}{\varepsilon}
```

であり， $\varepsilon\to0$ とするとこの値は無限大に発散する．
これは，エントロピーが絶対零度で有限の値に近づくという第3法則に矛盾する．

よって，熱容量の極限が存在するという仮定のもとでは，その極限は正の値をとれない．
一方，熱容量は非負であるため，

```math
\boxed{
\lim_{T\to0}C_x(T)=0
}
```

が得られる．

したがって，熱力学第3法則のもとで，熱容量の絶対零度における極限が存在するならば，その極限はゼロである．
