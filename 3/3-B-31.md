# 演習問題【3-B-31】

## 解答

### 1．エントロピーの変化から熱量を求める

温度 $T$ に依存する誘電率 $\epsilon(T)$ をもつ誘電体を平行板蓄電器に入れ，電位差を $0$ から $\Phi$ まで等温準静的に増加させる．
等温準静的過程とは，温度を一定に保ちながら，系が各段階で平衡状態にあるようにゆっくり変化させる過程である．

この過程で誘電体が吸収する微小熱量を $d'Q$ とすると，可逆過程における熱力学の関係式より，

```math
d'Q=T\,dS
\tag{1}
```

である．
ここで $S$ は誘電体のエントロピーである．
温度 $T$ は一定なので，誘電体が吸収する全熱量 $Q_{\mathrm{abs}}$ は，

```math
Q_{\mathrm{abs}}=\int d'Q
=T\Delta S
=T\{S(T,E)-S(T,0)\}
\tag{2}
```

と表される．

前問で得られた，電場 $E$ によるエントロピーの変化は，

```math
S(T,E)-S(T,0)
=\frac{V}{8\pi}\frac{d\epsilon(T)}{dT}E^2
\tag{3}
```

である．
ここで $V$ は誘電体の体積である．

平行板蓄電器の極板間隔を $a$ とすると，電位差が $\Phi$ のときの電場は，

```math
E=\frac{\Phi}{a}
\tag{4}
```

である．
式 (3)，(4) を式 (2) に代入すると，

```math
\begin{aligned}
Q_{\mathrm{abs}}
&=T\frac{V}{8\pi}\frac{d\epsilon(T)}{dT}
\left(\frac{\Phi}{a}\right)^2\\
&=\frac{VT}{8\pi a^2}
\frac{d\epsilon(T)}{dT}\Phi^2
\end{aligned}
\tag{5}
```

を得る．

問題で求める熱量を，誘電体が外部へ放出する熱量 $Q_{\mathrm{rel}}$ と定義すると，吸収熱量とは符号が反対である．
したがって，

```math
Q_{\mathrm{rel}}=-Q_{\mathrm{abs}}
```

より，

```math
\boxed{
Q_{\mathrm{rel}}
=-\frac{VT}{8\pi a^2}
\frac{d\epsilon(T)}{dT}\Phi^2
}
\tag{6}
```

となる．
これが，電位差を $0$ から $\Phi$ まで増加させるときに誘電体が放出する熱量である．

### 2．蓄電器の容量を用いた表現

次に，式 (6) を蓄電器の容量 $C$ を用いて書き直す．
誘電率を $\epsilon(T)$ ，極板面積を $A$ ，極板間隔を $a$ とすると，平行板蓄電器の容量は，

```math
C=\frac{\epsilon(T)A}{4\pi a}
\tag{7}
```

である．
また，誘電体の体積は $V=aA$ であるから，

```math
\begin{aligned}
\frac{V}{8\pi a^2}
&=\frac{aA}{8\pi a^2}\\
&=\frac{A}{8\pi a}\\
&=\frac{C}{2\epsilon(T)}
\end{aligned}
\tag{8}
```

が成立する．
これを式 (6) に代入すると，

```math
Q_{\mathrm{rel}}
=-\frac{1}{2}C\Phi^2
\frac{T}{\epsilon(T)}
\frac{d\epsilon(T)}{dT}
\tag{9}
```

となる．

ここで，対数微分の関係

```math
\begin{aligned}
\frac{d\log\epsilon^{-1}(T)}{d\log T}
&=\frac{T}{\epsilon^{-1}(T)}
\frac{d\epsilon^{-1}(T)}{dT}\\
&=-\frac{T}{\epsilon(T)}
\frac{d\epsilon(T)}{dT}
\end{aligned}
\tag{10}
```

を用いる．
式 (9)，(10) より，求める熱量は，

```math
\boxed{
Q_{\mathrm{rel}}
=\frac{1}{2}C\Phi^2
\frac{d\log\epsilon^{-1}(T)}{d\log T}
}
\tag{11}
```

と表される．
ここで $C$ は，温度 $T$ における蓄電器の容量である．

### 3．結果の物理的意味

```math
\frac{1}{2} C\Phi^2
```

は，電位差が $\Phi$ のときに蓄電器に蓄えられる静電エネルギーである．
式 (11) は，誘電体が放出する熱量が，この静電エネルギーに誘電率の温度依存性を表す無次元量を掛けたものになることを示している．

熱の出入りの向きは，誘電率の温度微分 $d\epsilon/dT$ によって決まる．

- $d\epsilon/dT<0$ の場合， $Q_{\mathrm{rel}}>0$ となり，誘電体は熱を放出する．
- $d\epsilon/dT>0$ の場合， $Q_{\mathrm{rel}}<0$ となり，誘電体は熱を放出するのではなく，熱を吸収する．
- $d\epsilon/dT=0$ の場合，この過程に伴う熱の出入りはゼロである．

以上より，電位差を $0$ から $\Phi$ まで等温準静的に増加させるとき，誘電体が放出する熱量は，

```math
\boxed{
Q_{\mathrm{rel}}
=\frac{1}{2} C\Phi^2
\frac{d\log\epsilon^{-1}(T)}{d\log T}
}
```

である．
