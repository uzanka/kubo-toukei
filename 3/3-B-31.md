# 演習問題【3-B-31】

## 解答

## 1．熱力学的関係式

温度 $T$ に依存する誘電率 $\epsilon(T)$ をもつ誘電体を，平行板蓄電器の極板間に完全に満たすように挿入する．
極板面積を $A$ ，極板間隔を $a$ ，誘電体の体積を $V=aA$ とする．

本問では，蓄電器内部の誘電体を熱力学的な系とし，極板および外部回路の熱的寄与は無視する．
また，端効果を無視できる一様電場を仮定し，誘電体は線形かつ損失のない理想誘電体であるとする．
漏れ電流や誘電ヒステリシスなどの不可逆な散逸がなく，電位差の変化は可逆準静的に行われるものとする．

このとき，誘電体の温度を一定に保ちながら電位差を $0$ から $\Phi$ まで増加させる過程は，可逆等温過程である．
したがって，誘電体が吸収する微小熱量を $d'Q_{\mathrm{abs}}$ とすると，

```math
d'Q_{\mathrm{abs}}=T\,dS
\tag{1}
```

が成立する．

温度 $T$ は一定であるから，誘電体が吸収する全熱量は，

```math
\begin{aligned}
Q_{\mathrm{abs}}
&=\int d'Q_{\mathrm{abs}}\\
&=T\int dS\\
&=T\{S(T,E)-S(T,0)\}
\end{aligned}
\tag{2}
```

となる．

前問で得られたエントロピー変化の式は，

```math
S(T,E)-S(T,0)
=\frac{V}{8\pi}
\frac{d\epsilon(T)}{dT}E^2
\tag{3}
```

である．
ここで， $V$ は誘電体の体積， $E$ は電場の大きさである．

平行板蓄電器の端効果を無視すれば，極板間の電場は一様であり，

```math
E=\frac{\Phi}{a}
\tag{4}
```

と表される．

式 (3)，式 (4) を式 (2) に代入すると，

```math
\begin{aligned}
Q_{\mathrm{abs}}
&=T\frac{V}{8\pi}
\frac{d\epsilon(T)}{dT}
\left(\frac{\Phi}{a}\right)^2\\
&=\frac{VT}{8\pi a^2}
\frac{d\epsilon(T)}{dT}\Phi^2
\end{aligned}
\tag{5}
```

を得る．

ここで，誘電体が外部へ放出する熱量を $Q_{\mathrm{rel}}$ と定義する．
吸収熱量を正とする式 (2) の符号規約に対して，放出熱量はその反対符号であるから，

```math
Q_{\mathrm{rel}}=-Q_{\mathrm{abs}}
```

である．
したがって，

```math
\boxed{
Q_{\mathrm{rel}}
=-\frac{VT}{8\pi a^2}
\frac{d\epsilon(T)}{dT}\Phi^2
}
\tag{6}
```

となる．

## 2．蓄電器の容量を用いた表現

ガウス単位系において，誘電体が極板間を完全に満たす平行板蓄電器の容量は，

```math
C=\frac{\epsilon(T)A}{4\pi a}
\tag{7}
```

である．
また，誘電体の体積は $V=aA$ であるから，

```math
\begin{aligned}
\frac{V}{8\pi a^2}
&=\frac{aA}{8\pi a^2}\\
&=\frac{A}{8\pi a}\\
&=\frac{C}{2\epsilon(T)}
\end{aligned}
\tag{8}
```

が成立する．

式 (8) を式 (6) に代入すると，

```math
Q_{\mathrm{rel}}
=-\frac12 C\Phi^2
\frac{T}{\epsilon(T)}
\frac{d\epsilon(T)}{dT}
\tag{9}
```

を得る．

ここで， $\epsilon(T)>0$ ， $T>0$ とし，誘電率が温度について微分可能であるとする．
対数微分の関係から，

```math
\begin{aligned}
\frac{d\log\epsilon^{-1}(T)}{d\log T}
&=T\frac{d}{dT}\log\epsilon^{-1}(T)\\
&=-T\frac{d}{dT}\log\epsilon(T)\\
&=-\frac{T}{\epsilon(T)}
\frac{d\epsilon(T)}{dT}
\end{aligned}
\tag{10}
```

となる．

式 (10) を式 (9) に代入すれば，

```math
\boxed{
Q_{\mathrm{rel}}
=\frac12 C\Phi^2
\frac{d\log\epsilon^{-1}(T)}{d\log T}
}
\tag{11}
```

を得る．
ここで， $C$ は温度 $T$ における蓄電器の容量である．

## 3．結果の物理的意味

式 (11) の

```math
\frac12 C\Phi^2
```

は，最終状態において蓄電器に蓄えられる静電エネルギーである．
したがって，誘電体が外部へ放出する熱量は，この静電エネルギーに誘電率の温度依存性を表す無次元量を掛けたものとして表される．

また，

```math
\frac{d\log\epsilon^{-1}(T)}{d\log T}
=-\frac{T}{\epsilon(T)}
\frac{d\epsilon(T)}{dT}
```

であるから，熱量の符号は誘電率の温度微分によって決まる．

- $d\epsilon/dT<0$ の場合， $Q_{\mathrm{rel}}>0$ となり，誘電体は熱を放出する．
- $d\epsilon/dT>0$ の場合， $Q_{\mathrm{rel}}<0$ となり，誘電体は熱を吸収する．
- $d\epsilon/dT=0$ の場合， $Q_{\mathrm{rel}}=0$ となり，この過程に伴う正味の熱の出入りはない．

以上より，理想的な可逆準静的過程において，電位差を $0$ から $\Phi$ まで等温で増加させるとき，誘電体が外部へ放出する符号付き熱量は，

```math
\boxed{
Q_{\mathrm{rel}}
=\frac12 C\Phi^2
\frac{d\log\epsilon^{-1}(T)}{d\log T}
}
```

である．

なお，この式は可逆過程に対する結果であり，誘電損失などの不可逆な散逸が存在する場合には，エントロピー変化だけから実際の熱量を求めることはできない．
