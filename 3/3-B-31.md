# 演習問題【3-B-31】

## 解答

問題文では，等温準静的な過程における蓄電器内部の熱量を求めている．

まず，誘電体が吸収する微小熱量 $d'Q$ とエントロピー $S$ の関係は，熱力学の基本式より次のように与えられる．

$$d'Q = T dS$$

この過程において，電位差を $0$ から $\Phi$ まで変化させたときに誘電体が吸収する全熱量を $Q_{\mathrm{diel}}$ とすると，

$$Q_{\mathrm{diel}} = \int_{0}^{\Phi} T \frac{dS}{d\varphi} d\varphi$$

と書ける（ $\varphi$ は積分のダミー変数）．
等温過程では温度 $T$ が一定であるから，エントロピー変化 $\Delta S$ を用いて

$$Q_{\mathrm{diel}} = T \Delta S = T [S(T, E) - S(T, 0)]$$

と表せる．
ここで問題 [29] の結果より，電場 $E$ に依存するエントロピーは

$$S(T, E) - S(T, 0) = V \frac{d\epsilon(T)}{dT} \frac{E^2}{8\pi} \quad (1)$$

で与えられる．
この式は，電場が存在することでエントロピーがどれだけ変化するかを示している．
平行平板蓄電器において電位差 $\Phi$ のとき電場は $E = \Phi/a$ （ $a$ は極板間隔）となる．

問題文で求められている「蓄電器の中に発生する熱量」は，誘電体が放出する熱量に等しい．
誘電体が吸収する熱量を $Q_{\mathrm{diel}}$ とすると，放出する熱量（＝発生する熱量）は $-Q_{\mathrm{diel}}$ である．
式(1)を用いて計算すると，

$$Q_{\mathrm{diel}} = T \left( V \frac{d\epsilon(T)}{dT} \frac{E^2}{8\pi} \right) = VT \frac{d\epsilon(T)}{dT} \frac{\Phi^2}{8\pi a^2}$$

ゆえに，蓄電器の中に発生する熱量 $-Q_{\mathrm{diel}}$ は

$$-Q_{\mathrm{diel}} = -VT \frac{d\epsilon(T)}{dT} \frac{\Phi^2}{8\pi a^2} \quad (2)$$

となる．
これが解答例の式(2)に相当する．

次に，平行平板蓄電器の容量 $C$ を用いて式を整理する．
容量 $C$ は

$$C = \frac{\epsilon A}{4\pi a}$$

（ $A$ は極板面積）であり，体積 $V = aA$ であることに注意すると，

$$\frac{V}{8\pi a^2} = \frac{aA}{8\pi a^2} = \frac{A}{8\pi a} = \frac{1}{2} \cdot \frac{\epsilon A}{4\pi a} \cdot \frac{1}{\epsilon} = \frac{1}{2} \cdot \frac{C}{\epsilon}$$

が成り立つ．
これを式(2)に代入すると，

$$-Q_{\mathrm{diel}} = -V T \frac{d\epsilon(T)}{dT} \frac{\Phi^2}{8\pi a^2} = -T \frac{d\epsilon(T)}{dT} \Phi^2 \cdot \frac{C}{2\epsilon} = -\frac{1}{2} C \Phi^2 \cdot T \frac{1}{\epsilon} \frac{d\epsilon(T)}{dT}$$

ここで，対数微分の定義より

$$\frac{d \log \epsilon^{-1}(T)}{d \log T} = \frac{T}{\epsilon^{-1}} \cdot \frac{d(\epsilon^{-1})}{dT} = -T \frac{1}{\epsilon} \frac{d\epsilon(T)}{dT}$$

したがって，

$$-Q_{\mathrm{diel}} = \frac{1}{2} C \Phi^2 \frac{d \log \epsilon^{-1}(T)}{d \log T} \quad (3)$$

と求められる．
これが解答例の式(3)である．

## 解説

この問題は，電場によって誘電体の性質（誘電率 $\epsilon$ ）が変化することに伴うエントロピーの変化と，それに伴う熱の出入りを扱う統計力学・熱力学の問題である．

### 1. 等温準静的過程とは

「等温」とは，過程の間に温度 $T$ が変化しないことを意味する．
「準静的」とは，過程が極めてゆっくりと進むため，常に平衡状態を保っていることを意味する．
これにより，エントロピーと熱の関係式 $dQ = T dS$ を直接適用することができる．

### 2. エントロピーと電場の関係

通常，物質のエントロピーは温度 $T$ と体積 $V$ の関数 $S(T,V)$ であるが，電場のような外部場が存在する場合，その場に依存して変化する．
問題[29]で与えられた式(1)は，電場によって誘電体の分子の配向などが整い，エントロピーが変化することを記述している．

### 3. なぜ熱が発生するのか

電位差を大きくして電場を強めると，誘電体内部の双極子が電場の方向に揃おうとする．
この「揃う」プロセスは秩序を形成することであり，エントロピーを減少させる（ $dS < 0$ ）．
エントロピーが減少するとき，熱力学の法則により，その分だけ熱が外部へ放出される（ $dQ = T dS < 0$ ）．
この放出された熱が，蓄電器の系において「発生した熱」となる．

### 4. 結果の解釈

最終的な答えに含まれる $\frac{d \log \epsilon^{-1}(T)}{d \log T}$ という項は，温度の変化に対して誘電率がどのように変化するかという「温度依存性」を表している．

通常の誘電体では，温度が上昇すると分子の熱運動が激しくなり双極子の配向が乱されるため，誘電率は温度とともに減少する（ $d\epsilon/dT < 0$ ）．
このとき $\frac{d \log \epsilon^{-1}(T)}{d \log T} > 0$ となり，発生熱量 $-Q_{\mathrm{diel}}$ は正となる．
すなわち，通常の誘電体では電位差を上げる過程で熱が外部へ放出される．

もし $d\epsilon/dT > 0$ となる特殊な材料であれば，逆に熱が吸収されることになる．
