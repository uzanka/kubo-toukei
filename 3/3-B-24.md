# 演習問題【3-B-24】

## 解答

### 1．断熱磁化率と等温磁化率の関係

等温磁化率 $\chi_T$ ，断熱磁化率 $\chi_S$ ，および熱容量 $C_M,C_H$ は，それぞれ

```math
\chi_T=\left(\frac{\partial M}{\partial H}\right)_T,
\qquad
\chi_S=\left(\frac{\partial M}{\partial H}\right)_S,
```

```math
C_M=T\left(\frac{\partial S}{\partial T}\right)_M,
\qquad
C_H=T\left(\frac{\partial S}{\partial T}\right)_H
```

と定義される．
ここで， $M$ は磁化， $H$ は磁場， $S$ はエントロピー， $T$ は絶対温度である．

偏微分はヤコビアンを用いて，

```math
\left(\frac{\partial M}{\partial H}\right)_S
=
\frac{\partial(M,S)}{\partial(H,S)}
```

と表せる．
さらに，ヤコビアンの連鎖律を用いると，

```math
\begin{aligned}
\chi_S
&=
\frac{\partial(M,S)}{\partial(H,S)}
\\
&=
\frac{\partial(M,S)}{\partial(M,T)}
\frac{\partial(M,T)}{\partial(H,T)}
\frac{\partial(H,T)}{\partial(H,S)}.
\end{aligned}
```

各ヤコビアンを計算する．
まず，

```math
\frac{\partial(M,S)}{\partial(M,T)}
=
\left(\frac{\partial S}{\partial T}\right)_M
=\frac{C_M}{T}
```

である．
次に，

```math
\frac{\partial(M,T)}{\partial(H,T)}
=
\left(\frac{\partial M}{\partial H}\right)_T
=\chi_T
```

である．
最後に，逆数の関係から，

```math
\begin{aligned}
\frac{\partial(H,T)}{\partial(H,S)}
&=
\frac{1}{\dfrac{\partial(H,S)}{\partial(H,T)}}
\\
&=
\frac{1}{\left(\dfrac{\partial S}{\partial T}\right)_H}
=\frac{T}{C_H}
\end{aligned}
```

となる．
これらを代入すると，

```math
\chi_S
=
\frac{C_M}{T}\,\chi_T\,\frac{T}{C_H}
```

を得る．
したがって，

```math
\boxed{
\chi_S=\chi_T\frac{C_M}{C_H}
}
```

が示された．

### 2．$C_M-C_H$ を計算する公式

次に，磁化 $M$ が温度 $T$ と磁場 $H$ の関数として与えられているとき， $C_M-C_H$ を求める公式を導く．

熱容量の定義より，

```math
C_M=T\left(\frac{\partial S}{\partial T}\right)_M
```

である．
ヤコビアンを用いると，

```math
\begin{aligned}
C_M
&=T\frac{\partial(S,M)}{\partial(T,M)}
\\
&=T
\frac{\dfrac{\partial(S,M)}{\partial(T,H)}}
{\dfrac{\partial(T,M)}{\partial(T,H)}}.
\end{aligned}
```

分母は

```math
\frac{\partial(T,M)}{\partial(T,H)}
=
\left(\frac{\partial M}{\partial H}\right)_T
```

であり，分子は

```math
\begin{aligned}
\frac{\partial(S,M)}{\partial(T,H)}
&=
\begin{vmatrix}
\left(\dfrac{\partial S}{\partial T}\right)_H
&
\left(\dfrac{\partial S}{\partial H}\right)_T
\\
\left(\dfrac{\partial M}{\partial T}\right)_H
&
\left(\dfrac{\partial M}{\partial H}\right)_T
\end{vmatrix}
\\
&=
\left(\frac{\partial S}{\partial T}\right)_H
\left(\frac{\partial M}{\partial H}\right)_T
-
\left(\frac{\partial S}{\partial H}\right)_T
\left(\frac{\partial M}{\partial T}\right)_H
\end{aligned}
```

である．
よって，

```math
\begin{aligned}
C_M
={}&T\left(\frac{\partial S}{\partial T}\right)_H\\
&-
T\frac{
\left(\dfrac{\partial S}{\partial H}\right)_T
\left(\dfrac{\partial M}{\partial T}\right)_H
}{
\left(\dfrac{\partial M}{\partial H}\right)_T
}.
\end{aligned}
\tag{1}
```

ここで，Maxwell の関係式

```math
\boxed{
\left(\frac{\partial S}{\partial H}\right)_T
=
\left(\frac{\partial M}{\partial T}\right)_H
}
\tag{2}
```

を用いる．
この関係式は，磁性体の Helmholtz 自由エネルギー $F(T,M)$ が

```math
dF=-S\,dT+H\,dM
```

を満たすことから導かれる．
磁場 $H$ を自然変数とする熱力学ポテンシャル $F^*=F-HM$ を定義すると，

```math
dF^*=-S\,dT-M\,dH
```

となる．
したがって，

```math
S=-\left(\frac{\partial F^*}{\partial T}\right)_H,
\qquad
M=-\left(\frac{\partial F^*}{\partial H}\right)_T
```

である．
混合二階偏微分の順序を交換すれば，式 (2) が得られる．

式 (2) を式 (1) に代入し，

```math
T\left(\frac{\partial S}{\partial T}\right)_H=C_H
```

を用いると，

```math
C_M
=
C_H-
T\frac{
\left(\dfrac{\partial M}{\partial T}\right)_H^2
}{
\left(\dfrac{\partial M}{\partial H}\right)_T
}
```

となる．
よって，求める公式は

```math
\boxed{
C_M-C_H
=
-T\frac{
\left(\dfrac{\partial M}{\partial T}\right)_H^2
}{
\left(\dfrac{\partial M}{\partial H}\right)_T
}
}
```

である．

この式により，磁化 $M(T,H)$ が既知であれば，その偏微分から $C_M-C_H$ を計算できる．
ただし，導出では $\left(\partial M/\partial H\right)_T\neq0$ を仮定している．
通常の安定な常磁性体では $\left(\partial M/\partial H\right)_T>0$ であるため，

```math
C_M\le C_H
```

となる．
等号が成立するのは， $\left(\partial M/\partial T\right)_H=0$ の場合である．
