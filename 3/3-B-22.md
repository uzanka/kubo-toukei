# 演習問題【3-B-22】

## 解答

定積熱容量は，体積 $V$ と粒子数 $N$ を一定に保ったときの温度変化に対するエントロピー $S$ の変化率を用いて，

```math
C_{V,N}=T\left(\frac{\partial S}{\partial T}\right)_{V,N}
```

と定義される．
本問題では，この偏微分を，独立変数を $T,V,N$ から $T,V,\mu$ に変更して表すことを考える．

### 1．ヤコビアンによる変数変換

ヤコビアンの商の公式を用いると，

```math
\left(\frac{\partial S}{\partial T}\right)_{V,N}
=
\frac{\partial(S,N,V)/\partial(T,\mu,V)}
{\partial(T,N,V)/\partial(T,\mu,V)}
```

である．
ここで，分子と分母のヤコビアンを計算すると，

```math
\frac{\partial(S,N,V)}{\partial(T,\mu,V)}
=
\begin{vmatrix}
\left(\dfrac{\partial S}{\partial T}\right)_{V,\mu}
&
\left(\dfrac{\partial S}{\partial\mu}\right)_{T,V}
\\[6pt]
\left(\dfrac{\partial N}{\partial T}\right)_{V,\mu}
&
\left(\dfrac{\partial N}{\partial\mu}\right)_{T,V}
\end{vmatrix}
```

および

```math
\frac{\partial(T,N,V)}{\partial(T,\mu,V)}
=
\left(\frac{\partial N}{\partial\mu}\right)_{T,V}
```

となる．
したがって，

```math
\begin{aligned}
\left(\frac{\partial S}{\partial T}\right)_{V,N}
={}&
\left(\frac{\partial S}{\partial T}\right)_{V,\mu}
\\
&-
\frac{
\left(\dfrac{\partial N}{\partial T}\right)_{V,\mu}
}{
\left(\dfrac{\partial N}{\partial\mu}\right)_{T,V}
}
\left(\frac{\partial S}{\partial\mu}\right)_{T,V}
\end{aligned}
\tag{1}
```

を得る．

### 2．Maxwell 型の関係式

式 (1) の第2項に含まれる $\left(\partial S/\partial\mu\right)_{T,V}$ を変形するため，大ポテンシャル $\Omega(T,V,\mu)$ を導入する．
その微分は，

```math
d\Omega=-S\,dT-p\,dV-N\,d\mu
```

である．
よって，

```math
S=-\left(\frac{\partial\Omega}{\partial T}\right)_{V,\mu},
\qquad
N=-\left(\frac{\partial\Omega}{\partial\mu}\right)_{T,V}
```

が成り立つ．
これらをそれぞれ $\mu$ と $T$ で偏微分すると，

```math
\left(\frac{\partial S}{\partial\mu}\right)_{T,V}
=
-\frac{\partial^2\Omega}{\partial\mu\,\partial T}
```

および

```math
\left(\frac{\partial N}{\partial T}\right)_{V,\mu}
=
-\frac{\partial^2\Omega}{\partial T\,\partial\mu}
```

となる．
大ポテンシャルの混合二階偏微分が連続であれば，偏微分の順序を交換できるため，

```math
\boxed{
\left(\frac{\partial S}{\partial\mu}\right)_{T,V}
=
\left(\frac{\partial N}{\partial T}\right)_{V,\mu}
}
\tag{2}
```

を得る．
これは Maxwell 型の関係式である．

### 3．定積熱容量の公式

式 (2) を式 (1) に代入すると，

```math
\begin{aligned}
\left(\frac{\partial S}{\partial T}\right)_{V,N}
&=
\left(\frac{\partial S}{\partial T}\right)_{V,\mu}
-
\frac{
\left(\dfrac{\partial N}{\partial T}\right)_{V,\mu}^{2}
}{
\left(\dfrac{\partial N}{\partial\mu}\right)_{T,V}
}.
\end{aligned}
```

ここで，体積と化学ポテンシャルを固定した熱容量を

```math
C_{V,\mu}
=
T\left(\frac{\partial S}{\partial T}\right)_{V,\mu}
```

と定義する．
上式の両辺に $T$ を掛けると，求める公式は

```math
\boxed{
C_{V,N}
=
C_{V,\mu}
-
T\frac{
\left(\dfrac{\partial N}{\partial T}\right)_{V,\mu}^{2}
}{
\left(\dfrac{\partial N}{\partial\mu}\right)_{T,V}
}
}
```

となる．

ただし，この導出では， $\left(\partial N/\partial\mu\right)_{T,V}\neq0$ であり，必要な偏微分が存在することを仮定している．
