# 演習問題【3-A-18】

## 解答

針金の張力を $X$ ，長さを $x$ とする．
針金が熱力学的に安定な平衡状態にあることを利用し，

```math
\left(\frac{\partial X}{\partial x}\right)_{S,p}>0,
\qquad
\left(\frac{\partial X}{\partial x}\right)_{T,p}>0
```

を示す．
ここで， $S$ はエントロピー， $T$ は温度， $p$ は外圧である．

### 1．エントロピーと外圧を一定にした場合

熱力学的に安定な平衡状態では，内部エネルギーの二次変分は非負である．
問題で参照されている式 (3.32b) より，エントロピーと外圧を一定に保つ場合，すなわち

```math
\delta S=0,\qquad \delta p=0
```

の場合には，

```math
2\delta_2 U=\delta X\,\delta x\geq0
```

となる．

ここで，エントロピー $S$ と外圧 $p$ を一定に保って長さ $x$ を微小量 $\delta x$ だけ変化させると，張力の変化は

```math
\delta X=
\left(\frac{\partial X}{\partial x}\right)_{S,p}\delta x
```

と表される．
これを二次変分の式に代入すると，

```math
2\delta_2 U
=
\left(\frac{\partial X}{\partial x}\right)_{S,p}
(\delta x)^2\geq0
```

を得る．
$(\delta x)^2>0$ であるから，

```math
\left(\frac{\partial X}{\partial x}\right)_{S,p}\geq0
```

である．
さらに，長さ方向に狭義に安定な平衡状態では，長さの変化に対する二次変分は正である．
したがって，

```math
\boxed{
\left(\frac{\partial X}{\partial x}\right)_{S,p}>0
}
\tag{1}
```

となる．

### 2．温度と外圧を一定にした場合

次に，温度と外圧を一定に保つ場合を考える．
このとき，

```math
\delta T=0,\qquad \delta p=0
```

である．
式 (3.32b) にこの条件を適用すると，

```math
2\delta_2 U=\delta X\,\delta x\geq0
```

となる．

温度 $T$ と外圧 $p$ を一定に保ったとき，張力の微小変化は

```math
\delta X=
\left(\frac{\partial X}{\partial x}\right)_{T,p}\delta x
```

である．
よって，

```math
2\delta_2 U
=
\left(\frac{\partial X}{\partial x}\right)_{T,p}
(\delta x)^2\geq0
```

となる．
したがって，

```math
\left(\frac{\partial X}{\partial x}\right)_{T,p}\geq0
```

を得る．
ここでも，長さ方向に狭義に安定な平衡状態を考えれば，二次変分は正であるため，

```math
\boxed{
\left(\frac{\partial X}{\partial x}\right)_{T,p}>0
}
\tag{2}
```

となる．

以上より，求める二つの不等式が示された．

### 3．別解：二つの偏微分の関係を用いる方法

二つの偏微分が同符号であることを利用してもよい．
以下では，外圧 $p$ を一定に保つ．

```math
C_X\equiv
\left(\frac{\partial S}{\partial T}\right)_{X,p},
\qquad
C_x\equiv
\left(\frac{\partial S}{\partial T}\right)_{x,p}
```

と定義する．
これらは通常の熱容量を温度 $T$ で割った量であり，安定な系では正である．

ヤコビアンの連鎖律を用いると，

```math
\begin{aligned}
\left(\frac{\partial X}{\partial x}\right)_{S,p}
&=\frac{\partial(X,S)}{\partial(x,S)}\\[4pt]
&=\frac{\partial(X,S)}{\partial(X,T)}
\frac{\partial(X,T)}{\partial(x,T)}
\frac{\partial(x,T)}{\partial(x,S)}\\[4pt]
&=\frac{C_X}{C_x}
\left(\frac{\partial X}{\partial x}\right)_{T,p}
\end{aligned}
```

となる．
ここで， $C_X>0$ および $C_x>0$ より，

```math
\frac{C_X}{C_x}>0
```

である．
したがって，

```math
\left(\frac{\partial X}{\partial x}\right)_{S,p}
\quad\text{と}\quad
\left(\frac{\partial X}{\partial x}\right)_{T,p}
```

は同符号である．
よって，一方が正であれば他方も正となる．

ただし，この別解だけでは両者が正であることを単独で確定できないため，少なくとも一方の正値性を安定性条件から示す必要がある．
