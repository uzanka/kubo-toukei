# 演習問題【3-A-18】

## 解答

針金の張力を $X$ ，長さを $x$ とする．

熱力学的安定性の条件として、式3.32bより，

```math
\delta T\delta S-\delta p\delta V
+\delta X\delta x\geq0
\tag{1}
```

が成立する．
ただし，針金以外の一般化座標および粒子数は固定する．

ここで，式(1)の半正定値性だけでは，求める厳密な正の不等号は導けない．
そこで，以下では対象とする平衡状態が非退化な厳密安定平衡であること，すなわち，内部エネルギー $U(S,V,x)$ の $(S,V,x)$ に関するヘッセ行列

```math
H=
\begin{pmatrix}
U_{SS}&U_{SV}&U_{Sx}\\
U_{SV}&U_{VV}&U_{Vx}\\
U_{Sx}&U_{Vx}&U_{xx}
\end{pmatrix}
```

が正定値であることを仮定する．

ここで，添字は各変数による偏微分を表す．
また， $U$ は二階連続微分可能とする．

この仮定により，任意の非零変分に対して，

```math
Q=
\begin{pmatrix}
\delta S&\delta V&\delta x
\end{pmatrix}
H
\begin{pmatrix}
\delta S\\
\delta V\\
\delta x
\end{pmatrix}
>0
\tag{2}
```

が成立する．

なお，熱力学の基本関係

```math
dU=T\,dS-p\,dV+X\,dx
```

から，

```math
T=U_S,\qquad p=-U_V,\qquad X=U_x
```

である．
したがって，式(2)の二次形式は式3.32bの左辺に一致する．

以下では，圧力一定の条件を保つための体積変化を許容する．

### 1．エントロピーと圧力を一定にした場合

まず，エントロピー $S$ と圧力 $p$ を一定に保つ．

このとき，

```math
\delta S=0,\qquad \delta p=0
```

である．

圧力は

```math
p=-U_V
```

であるから，その微小変化は

```math
\delta p=-U_{VV}\delta V-U_{Vx}\delta x
```

となる．

ヘッセ行列の正定値性より，

```math
U_{VV}>0
```

であるため， $\delta p=0$ を満たす体積変化は

```math
\delta V=-\frac{U_{Vx}}{U_{VV}}\delta x
```

と定められる．

したがって， $S,p$ を一定に保ちながら，任意の微小な $\delta x\neq0$ を与えることができる．

このとき，式(2)より，

```math
Q>0
```

である．

一方，

```math
\delta S=0,\qquad \delta p=0
```

であるから，

```math
Q=\delta T\delta S-\delta p\delta V
+\delta X\delta x
=\delta X\delta x
```

となる．

したがって，

```math
\delta X\delta x>0
\tag{3}
```

を得る．

一定の $S,p$ のもとでは，

```math
\delta X=
\left(\frac{\partial X}{\partial x}\right)_{S,p}
\delta x
```

であるから，式(3)に代入すると，

```math
\left(\frac{\partial X}{\partial x}\right)_{S,p}
(\delta x)^2>0
```

となる．

ここで， $\delta x\neq0$ より，

```math
(\delta x)^2>0
```

であるため，

```math
\boxed{
\left(\frac{\partial X}{\partial x}\right)_{S,p}>0
}
\tag{4}
```

を得る．

### 2．温度と圧力を一定にした場合

次に，温度 $T$ と圧力 $p$ を一定に保つ．

このとき，

```math
\delta T=0,\qquad \delta p=0
```

である．

温度と圧力の微小変化は，

```math
\delta T
=U_{SS}\delta S+U_{SV}\delta V+U_{Sx}\delta x
```

```math
\delta p
=-U_{SV}\delta S-U_{VV}\delta V-U_{Vx}\delta x
```

で与えられる．

ここで， $S,V$ に関する係数行列の行列式は，

```math
\begin{vmatrix}
U_{SS}&U_{SV}\\
-U_{SV}&-U_{VV}
\end{vmatrix}
=
-\left(U_{SS}U_{VV}-U_{SV}^{\,2}\right)
```

である．

ヘッセ行列の正定値性より，

```math
U_{SS}U_{VV}-U_{SV}^{\,2}>0
```

であるから，この行列式はゼロではない．

したがって，陰関数定理により， $T,p$ を一定に保ちながら， $S,V$ を $x$ の関数として局所的に定めることができる．

すなわち，任意の微小な $\delta x\neq0$ に対して，

```math
\delta T=0,\qquad \delta p=0
```

を満たす変分が存在する．

このとき，式(2)より，

```math
Q>0
```

である．

一方，

```math
\delta T=0,\qquad \delta p=0
```

なので，

```math
Q=\delta X\delta x>0
\tag{5}
```

となる．

一定の $T,p$ のもとでは，

```math
\delta X=
\left(\frac{\partial X}{\partial x}\right)_{T,p}
\delta x
```

であるから，式(5)に代入すると，

```math
\left(\frac{\partial X}{\partial x}\right)_{T,p}
(\delta x)^2>0
```

を得る．

$\delta x\neq0$ より，

```math
(\delta x)^2>0
```

であるから，

```math
\boxed{
\left(\frac{\partial X}{\partial x}\right)_{T,p}>0
}
\tag{6}
```

となる．

### 3．結論

以上より，内部エネルギー $U(S,V,x)$ のヘッセ行列が対象とする平衡状態で正定値であるとき，

```math
\boxed{
\left(\frac{\partial X}{\partial x}\right)_{S,p}>0,
\qquad
\left(\frac{\partial X}{\partial x}\right)_{T,p}>0
}
```

が成立する．

したがって，エントロピーと圧力を一定にした場合，および温度と圧力を一定にした場合のいずれにおいても，平衡状態の近傍では，針金の長さの微小な増加に対して張力は増加する．

なお，式3.32bに明記された半正定値条件 $Q\geq0$ だけでは，二つの偏微分について非負性までしか保証されない．
厳密な正の不等号を得るため，本解答ではヘッセ行列の正定値性という非退化な安定性の条件を明示的に採用した．
