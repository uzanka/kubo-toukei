# 演習問題【3-A-18】

## 解答

針金の張力を $X$ , 長さを $x$ とする．
与えられた条件のもとで， $`(\partial X / \partial x)_{S,p} > 0`$ および $`(\partial X / \partial x)_{T,p} > 0`$ であることを示す．

### 1. $(\partial X / \partial x)_{S,p} > 0$ の証明

熱力学において，系の安定性は内部エネルギー $U$ の二次の変分 $\delta_2 U$ によって決定される．
エントロピー $S$ と圧力 $p$ が一定（ $\delta S = 0, \delta p = 0$ ）の条件下での，内部エネルギーの二次の変分は，次のように書くことができる．

まず，張力 $X$ はエントロピー $S$ と長さ $x$ が一定のときの内部エネルギーの $x$ に関する微分として定義される．

$$X = \left( \frac{\partial U}{\partial x} \right)_{S,p}$$

このとき，長さ $x$ をわずかに $\delta x$ だけ変化させたときの張力の変化 $\delta X$ は，次のように表せる．

$$\delta X = \left( \frac{\partial X}{\partial x} \right)_{S,p} \delta x$$

内部エネルギーの二次の変分 $\delta_2 U$ は，微小な変化 $\delta x$ に対して次のように近似できる．

$$2\delta_2 U = \delta X \delta x = \left( \frac{\partial X}{\partial x} \right)_{S,p} (\delta x)^2$$

熱力学の安定性理論によれば，狭義に安定な平衡系では $\delta_2 U > 0$ が要請される（等号が成立するのは臨界点のみ）．
実在の材料は通常の安定な平衡状態にあるため，

$$\left( \frac{\partial X}{\partial x} \right)_{S,p} > 0$$

### 2. $(\partial X / \partial x)_{T,p} > 0$ の証明

温度 $T$ と圧力 $p$ が一定（ $\delta T = 0, \delta p = 0$ ）の条件下では，
変数が $(T, p)$ で固定された系の安定性を論じる際，適切な熱力学ポテンシャルは内部エネルギー $U$ ではなくヘルムホルツの自由エネルギー $F = U - TS$ である．

$dF = d(U - TS) = -SdT + Xdx$ より，

$$\left( \frac{\partial F}{\partial x} \right)_{T,p} = X$$

であり，長さ $x$ を $\delta x$ だけ変化させたときの自由エネルギーの変化は，

$$\delta_2 F = \frac{1}{2} \left( \frac{\partial X}{\partial x} \right)_{T,p} (\delta x)^2$$

となる．
熱力学における安定性条件として，平衡状態において $\delta_2 F \geq 0$ でなければならない（狭義に安定な系では $> 0$ ）．
したがって，

$$\left( \frac{\partial X}{\partial x} \right)_{T,p} \geq 0$$

実在の材料では臨界的な状態ではなく安定な平衡状態にあるため，狭義の安定性条件が要請され，

$$\left( \frac{\partial X}{\partial x} \right)_{T,p} > 0$$

が得られる．

### 3. ヤコビアンを用いた別解

微分の変数を $S$ （エントロピー）から $T$ （温度）へと変換するために，ヤコビアン（Jacobian）を用いた関係式を利用することもできる．

$$\left( \frac{\partial X}{\partial x} \right)_S = \frac{\partial(X, S)}{\partial(x, S)}$$

連鎖律（chain rule）をヤコビアンに適用すると，次のように変数を $(X, T)$ および $(x, T)$ を経由して展開できる．

$$\frac{\partial(X, S)}{\partial(x, S)} = \frac{\partial(X, S)}{\partial(X, T)} \cdot \frac{\partial(X, T)}{\partial(x, T)} \cdot \frac{\partial(x, T)}{\partial(x, S)}$$

ここで，各項を整理する．
1. $\frac{\partial(X, S)}{\partial(X, T)} = \left( \frac{\partial S}{\partial T} \right)_X = C_X$
2. $\frac{\partial(X, T)}{\partial(x, T)} = \left( \frac{\partial X}{\partial x} \right)_T$
3. $\frac{\partial(x, T)}{\partial(x, S)} = \left( \frac{\partial T}{\partial S} \right)_x = \frac{1}{(\partial S / \partial T)_x} = \frac{1}{C_x}$

（ここで $C_X \equiv (\partial S/\partial T)_X$, $C_x \equiv (\partial S/\partial T)_x$ と定義する．
実測の定圧熱容量はそれぞれ $T C_X$, $T C_x$ に等しい．）

これらをまとめると，

$$\left( \frac{\partial X}{\partial x} \right)_S = \frac{C_X}{C_x} \left( \frac{\partial X}{\partial x} \right)_T$$

となる．

熱容量は安定な系において常に正である（系に熱を加えると温度が上昇する）ことから， $C_X > 0, C_x > 0$ が成り立つ．
したがって， $(\partial X / \partial x)_S$ と $(\partial X / \partial x)_T$ は同じ符号を持つことになり，一方が正であれば他方も正となる．

## 解説

この問題は，統計力学や熱力学における「系の安定性」が，物理量（ここでは張力 $X$ と長さ $x$ ）の微分の符号にどのように現れるかを問うている．

### 1. 安定性と二階微分

ある物理量（エネルギー $U$ など）が最小値をとるとき，その点では一次微分が $0$ になり，二次微分が正（ $\ge 0$ ）になる．
もし二次微分が負であれば，その点はエネルギーの「山」の頂上を意味し，わずかな変化ですぐにエネルギーが下がってしまうため，安定な状態とは言えない．
針金の張力 $X$ は，エネルギーを長さ $x$ で微分したものなので，張力の $x$ による微分は，エネルギーの二階微分に対応している．

### 2. 物理的意味

$(\partial X / \partial x) > 0$ ということは，「針金を伸ばそうとすると，それに応じて張力が増す」という性質を表している．
もしこれが負（ $(\partial X / \partial x) < 0$ ）だと，「伸ばせば伸ばすほど張力が弱まる」ことになり，一度伸び始めると止まらなくなるため，物理的に極めて不安定な状態である．

### 3. ヤコビアンによる変数の変換

「エントロピー一定」という条件から「温度一定」という条件へ計算の枠組みを移す際，単なる代入ではなく，変数のセット $(x, S)$ から $(x, T)$ への変換が必要である．
ヤコビアンを用いることで，異なる物理的制約下での微分係数の関係を厳密に計算することができる．
