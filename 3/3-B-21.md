# 演習問題【3-B-21】

## 解答

以下では，温度 $T>0$ ，体積 $V$ ，粒子数 $N$ を用いて，内部エネルギー $U$ と化学ポテンシャル $\mu$ の関係を導く．
また，

```math
\xi=\frac{\mu}{T}
```

とおく．
各偏微分では，添字に記した変数を一定に保つものとする．

### (i) の証明

独立変数を $T,V,N$ とするヘルムホルツ自由エネルギー

```math
F=U-TS
```

を考える．
ここで， $S$ はエントロピーである．
自由エネルギーの全微分は

```math
dF=-S\,dT-p\,dV+\mu\,dN
```

である．
したがって，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_{V,N},
\qquad
\mu=\left(\frac{\partial F}{\partial N}\right)_{T,V}
```

が成り立つ．

$F=U-TS$ を $U$ について解き，エントロピーの関係式を代入すると，

```math
U=F+TS
=F-T\left(\frac{\partial F}{\partial T}\right)_{V,N}
```

を得る．
両辺を $T,V$ 一定のもとで $N$ について偏微分すると，

```math
\left(\frac{\partial U}{\partial N}\right)_{T,V}
=
\left(\frac{\partial F}{\partial N}\right)_{T,V}
-T\frac{\partial}{\partial N}
\left(\frac{\partial F}{\partial T}\right)_{V,N}
```

となる．
自由エネルギーの混合二階偏微分の順序を交換できると仮定すれば，

```math
\left(\frac{\partial U}{\partial N}\right)_{T,V}
=
\mu-T\frac{\partial}{\partial T}
\left(\frac{\partial F}{\partial N}\right)_{T,V}
```

である．
化学ポテンシャルの定義

```math
\mu=\left(\frac{\partial F}{\partial N}\right)_{T,V}
```

を用いると，

```math
\left(\frac{\partial U}{\partial N}\right)_{T,V}
=\mu-T\left(\frac{\partial\mu}{\partial T}\right)_{V,N}
```

となる．
よって，

```math
\boxed{
\left(\frac{\partial U}{\partial N}\right)_{T,V}-\mu
=-T\left(\frac{\partial\mu}{\partial T}\right)_{V,N}
}
```

が証明された．

### (ii) の証明

```math
\xi=\frac{\mu}{T}
```

とおく．
求めるのは，体積 $V$ と $\xi$ を一定に保ったときの $N$ の温度微分

```math
\left(\frac{\partial N}{\partial T}\right)_{V,\xi}
```

である．
この条件では $\mu/T$ が一定であるため，温度を変化させると，化学ポテンシャル $\mu$ も温度に応じて変化する．

まず， $N$ を $T,\mu,V$ の関数とみなす．
その全微分は

```math
dN=
\left(\frac{\partial N}{\partial T}\right)_{V,\mu}dT
+\left(\frac{\partial N}{\partial\mu}\right)_{T,V}d\mu
```

である．
一方， $\xi=\mu/T$ を一定に保つと，

```math
d\left(\frac{\mu}{T}\right)=0
```

であるから，

```math
\frac{1}{T}d\mu-\frac{\mu}{T^2}dT=0
```

となる．
したがって，

```math
\left(\frac{\partial\mu}{\partial T}\right)_{V,\xi}
=\frac{\mu}{T}
```

である．
これを \(dN\) の式に代入すれば，

```math
\left(\frac{\partial N}{\partial T}\right)_{V,\xi}
=
\left(\frac{\partial N}{\partial T}\right)_{V,\mu}
+\frac{\mu}{T}
\left(\frac{\partial N}{\partial\mu}\right)_{T,V}
\tag{1}
```

を得る．

次に， $N$ を $T,V,\mu$ の関数とみなしたときの偏微分

```math
\left(\frac{\partial N}{\partial T}\right)_{V,\mu}
```

を求める．
$N$ を一定に保つ条件では， $\mu$ は温度 $T$ に応じて変化する．
したがって，

```math
d\mu=
\left(\frac{\partial\mu}{\partial T}\right)_{V,N}dT
+\left(\frac{\partial\mu}{\partial N}\right)_{T,V}dN
```

において $dN=0$ とすると，

```math
\left(\frac{\partial\mu}{\partial T}\right)_{V,N}
```

が一定粒子数での化学ポテンシャルの温度微分となる．
逆に， $T,V$ 一定のもとでは $dN=(\partial N/\partial\mu)_{T,V}d\mu$ であるため，

```math
\left(\frac{\partial N}{\partial T}\right)_{V,\mu}
=-\left(\frac{\partial N}{\partial\mu}\right)_{T,V}
\left(\frac{\partial\mu}{\partial T}\right)_{V,N}
\tag{2}
```

を得る．

式 (2) を式 (1) に代入すると，

```math
\begin{aligned}
\left(\frac{\partial N}{\partial T}\right)_{V,\xi}
&=\left(\frac{\partial N}{\partial\mu}\right)_{T,V}
\left\{
\frac{\mu}{T}
-\left(\frac{\partial\mu}{\partial T}\right)_{V,N}
\right\}.
\end{aligned}
```

ここで，(i) で証明した関係式を変形すると，

```math
\frac{\mu}{T}
-\left(\frac{\partial\mu}{\partial T}\right)_{V,N}
=\frac{1}{T}
\left(\frac{\partial U}{\partial N}\right)_{T,V}
```

である．
したがって，

```math
\boxed{
\left(\frac{\partial N}{\partial T}\right)_{V,\mu/T}
=
\left(\frac{\partial N}{\partial\mu}\right)_{T,V}
\frac{\left(\frac{\partial U}{\partial N}\right)_{T,V}}{T}
}
```

となり，(ii) が証明された．

### (iii) の証明

まず， $U$ を $T,V,N$ の関数とみなす．
その全微分は

```math
dU=
\left(\frac{\partial U}{\partial T}\right)_{V,N}dT
+\left(\frac{\partial U}{\partial N}\right)_{T,V}dN
```

である．
体積 $V$ と $\xi=\mu/T$ を一定に保って温度を変化させると，

```math
\left(\frac{\partial U}{\partial T}\right)_{V,\xi}
=
\left(\frac{\partial U}{\partial T}\right)_{V,N}
+\left(\frac{\partial U}{\partial N}\right)_{T,V}
\left(\frac{\partial N}{\partial T}\right)_{V,\xi}
```

を得る．
したがって，

```math
\begin{aligned}
&\left(\frac{\partial U}{\partial T}\right)_{V,\xi}
-\left(\frac{\partial U}{\partial T}\right)_{V,N}\\
&\qquad=
\left(\frac{\partial U}{\partial N}\right)_{T,V}
\left(\frac{\partial N}{\partial T}\right)_{V,\xi}.
\end{aligned}
\tag{3}
```

式 (3) に (ii) の結果を代入すると，

```math
\begin{aligned}
&\left(\frac{\partial U}{\partial T}\right)_{V,\xi}
-\left(\frac{\partial U}{\partial T}\right)_{V,N}\\
&\quad=
\left(\frac{\partial U}{\partial N}\right)_{T,V}
\left(\frac{\partial N}{\partial\mu}\right)_{T,V}
\frac{\left(\frac{\partial U}{\partial N}\right)_{T,V}}{T}\\
&\quad=
\left(\frac{\partial N}{\partial\mu}\right)_{T,V}
\frac{\left(\frac{\partial U}{\partial N}\right)_{T,V}^{2}}{T}.
\end{aligned}
```

よって，求める等式

```math
\boxed{
\begin{aligned}
&\left(\frac{\partial U}{\partial T}\right)_{V,\mu/T}
-\left(\frac{\partial U}{\partial T}\right)_{V,N}\\
&\qquad=
\left(\frac{\partial N}{\partial\mu}\right)_{T,V}
\frac{\left(\frac{\partial U}{\partial N}\right)_{T,V}^{2}}{T}
\end{aligned}
}
```

が得られる．

最後に，不等式を示す．
熱力学的に安定な系では，固定された $T,V$ のもとでヘルムホルツ自由エネルギー $F$ は粒子数 $N$ に関して凸である．
すなわち，

```math
\left(\frac{\partial^2 F}{\partial N^2}\right)_{T,V}
=
\left(\frac{\partial\mu}{\partial N}\right)_{T,V}
\geq 0
```

である．
したがって，逆関数が局所的に存在する通常の安定な領域では，

```math
\left(\frac{\partial N}{\partial\mu}\right)_{T,V}
=\frac{1}{\left(\frac{\partial\mu}{\partial N}\right)_{T,V}}
\geq 0
```

となる．
また，温度は $T>0$ であり，実数の二乗は非負であるため，

```math
\frac{\left(\frac{\partial U}{\partial N}\right)_{T,V}^{2}}{T}
\geq 0
```

である．
以上から，

```math
\boxed{
\left(\frac{\partial U}{\partial T}\right)_{V,\mu/T}
-\left(\frac{\partial U}{\partial T}\right)_{V,N}
\geq 0
}
```

が証明された．
ただし，この不等式の導出では， $(\partial N/\partial\mu)_{T,V}$ が定義され，非負であることを仮定している．
