# 演習問題【3-B-32】

## 解答

平行板の間隔を $a$ , 幅を $b$ , 長さを $l$ とする．
平行板の間に誘電体を深さ $x$ だけ挿入する．
このとき，平行板に電位差 $\Phi$ を与えると，誘電体は極板の間に吸い込まれる．
この現象を自由エネルギーの観点から説明する．

### 1. 電場と系定数の設定

まず，平行板の間の電場 $E$ を考える．
電位差が $\Phi$ で間隔が $a$ であるため，電場 $E$ は次のように表される．

$$E = \frac{\Phi}{a}$$

問題の設定より， $\Phi$ と $a$ は一定であるため，電場 $E$ も一定である．

また，誘電体が挿入されている部分の体積を $V_1$, 挿入されていない部分（空気などの部分）の体積を $V_0$ とする．
誘電体の幅は $b$, 長さは $l$, 挿入されている深さが $x$ であるから，

$$V_1 = abx$$

$$V_0 = ab(l - x)$$

となる．

### 2. 全体の自由エネルギー $F_{\text{total}}$ の構成

系の全体の自由エネルギー $F_{\text{total}}$ は，以下の2つの要素の和として考えることができる．

1.  **電場がない状態における誘電体自体の自由エネルギー $F(T, 0)$**:
    これは挿入深さ $x$ に依存しない定数として扱う．

2.  **電場によって生じる自由エネルギーの変化**:
    電位差 $\Phi$ が一定に保たれた条件下では，系の変化によって得られる仕事を含むヘルムホルツ自由エネルギーを用いる．
    誘電体の誘電率を $\epsilon$ とすると，誘電体が挿入されることによる自由エネルギー変化は，分極した誘電体が電場と相互作用することで生じる項として次のように書ける．
    $$\Delta F = -\frac{V_1}{8\pi} (\epsilon - 1) E^2$$
    （※ここで係数 $8\pi$ は，ガウス単位系における電磁気学の定義に基づいている．）

さらに，電気回路から供給される電荷による仕事の影響も含めると，一定電位差条件下での自由エネルギー変化は以下のようになる（Gibbs型の自由エネルギーを採用）．

$$F_{\text{total}} = F(T, 0) - \frac{V_1}{8\pi} (\epsilon - 1) E^2 + \frac{V_0 + V_1}{8\pi} E^2$$

ここで， $V_0 + V_1 = abl$ であり， $V_1 = abx$ を代入すると，

$$F_{\text{total}} = F(T, 0) - \frac{abx}{8\pi} (\epsilon - 1) E^2 + \frac{abl}{8\pi} E^2$$

第3項 $\frac{abl}{8\pi} E^2$ は $x$ に依存しない定数であるから，自由エネルギーの $x$ 依存的な部分（変動部分）は第2項のみであり，

$$F_{\text{total}}(x) = F(T, 0) - \frac{abx}{8\pi} (\epsilon - 1) E^2 + \text{(定数)}$$

と書ける．

### 3. 力の導出

系が受ける力 $X$ は，自由エネルギー $F_{\text{total}}$ を挿入深さ $x$ で微分し，その符号を反転させたものである．

$$X = -\frac{\partial F_{\text{total}}}{\partial x}$$

$F_{\text{total}}$ の変動部分を $x$ について微分すると：

$$\frac{\partial F_{\text{total}}}{\partial x} = -\frac{ab(\epsilon - 1) E^2}{8\pi}$$

したがって，

$$X = - \left( -\frac{ab(\epsilon - 1) E^2}{8\pi} \right) = \frac{ab(\epsilon - 1) E^2}{8\pi}$$

$E = \Phi/a$ を代入すると，

$$X = \frac{ab(\epsilon - 1) \Phi^2}{8\pi a^2} = \frac{b(\epsilon - 1) \Phi^2}{8\pi a}$$

### 4. 結論

$\epsilon > 1$ より，力 $X = \frac{b(\epsilon - 1) \Phi^2}{8\pi a}$ は正の値である．
$x$ を増やす方向（誘電体をより深く挿入する方向）に力が働くことを示している．
これは，誘電体を挿入することで系の自由エネルギーが減少し，より安定な状態へ向かおうとする結果である．
よって，誘電体は極板の間に吸い込まれる．

## 解説

この問題の鍵は，**「系は自由エネルギーを最小化しようとする」**という熱力学の基本的な性質を理解することにある．

1.  **なぜエネルギーが減るのか？**
    誘電体に電場をかけると，誘電体内部の電荷がわずかに偏る「分極」が起こる．
    この分極した状態は，外部電場との相互作用によってエネルギー的に有利（低いエネルギー状態）になる．

2.  **なぜ「吸い込まれる」のか？**
    誘電体が極板の間に入ると，電場が存在する領域が「空気」から「誘電体」に置き換わる．
    誘電体は分極によって電場を利用してエネルギーを下げることができるため，系全体としては，誘電体を極板の間により多く入れる（ $x$ を大きくする）ほど，全体の自由エネルギー $F_{\text{total}}$ が減少する．

3.  **数学的な意味**
    数学的には， $\frac{\partial F}{\partial x} < 0$ であることは，エネルギーが $x$ の増加とともに減少することを意味する．
    物理学において，力はエネルギーの勾配の負として定義されるため， $X = -\frac{\partial F}{\partial x}$ となり，正の力が $x$ の増加方向に働く．
    これが「吸い込まれる」現象の正体である．
