# 演習問題【3-B-32】

## 解答

平行板の間隔を $a$ ，幅を $b$ ，長さを $l$ とし，誘電体が極板間に入り込んでいる深さを $x$ とする．
誘電体の比誘電率を $\epsilon$ とし，端効果を無視する．
極板間の電位差 $\Phi$ は電源によって一定に保たれているものとする．
以下では，解答例と同じガウス単位系を用いる．

### 1．電位差一定の条件での自由エネルギー

極板間の電場は一様であり，

```math
E=\frac{\Phi}{a}
```

である．
$a$ と $\Phi$ は一定であるため，誘電体の挿入深さ $x$ を変えても $E$ は一定である．

誘電体が入り込んでいる部分の体積は $V_1=abx$ ，誘電体が入っていない部分の体積は $V_0=ab(l-x)$ である．

電位差を一定に保つ条件では，電源とのエネルギーのやり取りを考慮した自由エネルギーを使う必要がある．
電場がないときの自由エネルギーを $F(T,0)$ とすると，挿入深さに依存する電気的な自由エネルギーの変化は

```math
F_{\mathrm{total}}(x)
=F(T,0)-\frac{V_1}{8\pi}(\epsilon-1)E^2
+\text{（\(x\) に依存しない項）}
```

と表せる．
ここで， $\epsilon-1$ は誘電体を真空と置き換えたときの誘電的な寄与を表す．

したがって， $V_1=abx$ を代入すると，

```math
F_{\mathrm{total}}(x)
=F(T,0)-\frac{abx}{8\pi}(\epsilon-1)E^2
+\text{（定数）}
```

となる．

### 2．誘電体に働く力

誘電体が入り込む方向を $x$ の正方向とする．
自由エネルギー $F_{\mathrm{total}}$ に対応する力 $X$ は，

```math
X=-\frac{\partial F_{\mathrm{total}}}{\partial x}
```

で与えられる．
$E$ と $\epsilon$ は一定であるから，

```math
\frac{\partial F_{\mathrm{total}}}{\partial x}
=-\frac{ab}{8\pi}(\epsilon-1)E^2
```

であり，

```math
X=\frac{ab}{8\pi}(\epsilon-1)E^2
```

となる．
さらに， $E=\Phi/a$ を代入すると，

```math
\boxed{
X=\frac{b(\epsilon-1)\Phi^2}{8\pi a}
}
```

を得る．

### 3．結論

通常の誘電体では $\epsilon>1$ であるため， $X>0$ となる．
すなわち，誘電体には挿入深さ $x$ が増加する方向に力が働く．
よって，誘電体は極板の間に吸い込まれるのである．

この結果は，コンデンサの静電容量が誘電体の挿入によって増加することからも理解できる．
電位差を一定に保ったとき，電源とのエネルギーのやり取りを含めた自由エネルギーは，静電容量が増加する方向に減少するためである．


## 解説

解答例との相違について
上の修正解答では，物理的に整合する力の式を採用した．
一方，提示された解答例の式

```math
F_{\mathrm{total}}
=F(T,0)-\frac{V_1}{8\pi}(\epsilon-1)E^2
+\frac{V_0}{8\pi}E^2
```

をそのまま微分すると，

```math
X=\frac{ab\epsilon E^2}{8\pi}
```

となる．
しかし，これは電位差一定の平行板コンデンサについて，静電容量の変化から得られる力

```math
X=\frac{1}{2}\Phi^2\frac{dC}{dx}
=\frac{b(\epsilon-1)\Phi^2}{8\pi a}
```

と一致しない．
ここで $C(x)=\frac{b}{4\pi a}[l+(\epsilon-1)x]$ である．
したがって，解答例の自由エネルギーの式には，電場エネルギーと電源との仕事の扱いに不整合がある．
解答例と同じ「自由エネルギーを微分して力を求める」という方法は適切だが，その方法に用いる自由エネルギーの式は修正する必要がある．
