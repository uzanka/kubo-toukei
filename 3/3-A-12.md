# 演習問題【3-A-12】

## 解答

### 1．定圧熱容量からエントロピーを求める

問題文より， $n\ \mathrm{mol}$ の理想気体の定圧熱容量は，

```math
C_p(T)=nC_p^0+nC_{\mathrm{vib}}(T)
```

である．
ここで， $C_p^0$ および $C_{\mathrm{vib}}(T)$ はモル比熱である．

定圧熱容量の定義から，

```math
C_p=T\left(\frac{\partial S}{\partial T}\right)_{p,n}
```

であるため，

```math
\left(\frac{\partial S}{\partial T}\right)_{p,n}
=
\frac{n[C_p^0+C_{\mathrm{vib}}(T)]}{T}
\tag{1}
```

となる．

一方，Gibbs 自由エネルギーの微分式

```math
dG=-S\,dT+V\,dp+\mu\,dn
```

から得られる Maxwell の関係式は，

```math
\left(\frac{\partial S}{\partial p}\right)_{T,n}
=
-\left(\frac{\partial V}{\partial T}\right)_{p,n}
```

である．

理想気体の状態方程式

```math
pV=nRT
```

より，

```math
V=\frac{nRT}{p}
```

なので，

```math
\left(\frac{\partial V}{\partial T}\right)_{p,n}
=\frac{nR}{p}
```

となる．

したがって，

```math
\boxed{
dS=
\frac{n[C_p^0+C_{\mathrm{vib}}(T)]}{T}\,dT
-\frac{nR}{p}\,dp
}
\tag{2}
```

を得る．

ここで，任意の正の基準温度 $T_r$ と基準圧力 $p_r$ を導入する．
また，基準状態におけるエントロピーを

```math
S_r=S(T_r,p_r,n)
```

と定義する．

式 (2) を基準状態 $(T_r,p_r)$ から状態 $(T,p)$ まで積分すると，

```math
\begin{aligned}
S(T,p,n)-S_r
={}&nC_p^0\int_{T_r}^{T}\frac{dT'}{T'}\\
&+n\int_{T_r}^{T}
\frac{C_{\mathrm{vib}}(T')}{T'}\,dT'\\
&-nR\int_{p_r}^{p}\frac{dp'}{p'}
\end{aligned}
```

となる．

各積分を実行すると，

```math
\boxed{
\begin{aligned}
S(T,p,n)
=S_r+n\bigg[
&C_p^0\log\frac{T}{T_r}\\
&+\int_{T_r}^{T}
\frac{C_{\mathrm{vib}}(T')}{T'}\,dT'\\
&-R\log\frac{p}{p_r}
\bigg]
\end{aligned}
}
\tag{3}
```

を得る．

ここで，すべての対数の引数は無次元である．
また，積分下限 $T_r$ は正であるため， $T=0$ 付近での積分の収束性を仮定する必要はない．

### 2．エントロピーから Gibbs 自由エネルギーを求める

Gibbs 自由エネルギーの基本関係式は，

```math
dG=-S\,dT+V\,dp
```

である．

物質量 $n$ を一定にして，この式を基準状態から積分する．
まず，圧力を $p_r$ に固定して温度を $T_r$ から $T$ に変化させ，次に温度を $T$ に固定して圧力を $p_r$ から $p$ に変化させる．

基準状態の Gibbs 自由エネルギーを

```math
G_r=G(T_r,p_r,n)
```

とすると，

```math
\begin{aligned}
G(T,p,n)-G_r
={}&-\int_{T_r}^{T}S(T',p_r,n)\,dT'\\
&+\int_{p_r}^{p}V(T,p',n)\,dp'
\end{aligned}
\tag{4}
```

となる．

まず，式 (3) において $p=p_r$ とすると，

```math
\begin{aligned}
S(T',p_r,n)
=S_r+n\bigg[
&C_p^0\log\frac{T'}{T_r}\\
&+\int_{T_r}^{T'}
\frac{C_{\mathrm{vib}}(T'')}{T''}\,dT''
\bigg]
\end{aligned}
```

である．

これを式 (4) の第1項に代入すると，

```math
\begin{aligned}
-\int_{T_r}^{T}S(T',p_r,n)\,dT'
={}&-S_r(T-T_r)\\
&-nC_p^0\int_{T_r}^{T}
\log\frac{T'}{T_r}\,dT'\\
&-n\int_{T_r}^{T}dT'
\int_{T_r}^{T'}
\frac{C_{\mathrm{vib}}(T'')}{T''}\,dT''
\end{aligned}
```

となる．

ここで，

```math
\int_{T_r}^{T}\log\frac{T'}{T_r}\,dT'
=
T\log\frac{T}{T_r}-T+T_r
```

であるから，

```math
\begin{aligned}
-\int_{T_r}^{T}S(T',p_r,n)\,dT'
={}&-S_r(T-T_r)\\
&-nC_p^0
\left[
T\log\frac{T}{T_r}-T+T_r
\right]\\
&-n\int_{T_r}^{T}dT'
\int_{T_r}^{T'}
\frac{C_{\mathrm{vib}}(T'')}{T''}\,dT''
\end{aligned}
\tag{5}
```

を得る．

次に，理想気体の状態方程式から，

```math
V(T,p',n)=\frac{nRT}{p'}
```

なので，

```math
\begin{aligned}
\int_{p_r}^{p}V(T,p',n)\,dp'
&=nRT\int_{p_r}^{p}\frac{dp'}{p'}\\
&=nRT\log\frac{p}{p_r}
\end{aligned}
\tag{6}
```

となる．

式 (5)，（6）を式 (4) に代入すると，

```math
\boxed{
\begin{aligned}
G(T,p,n)=G_r
&-S_r(T-T_r)\\
&-nC_p^0
\left[
T\log\frac{T}{T_r}-T+T_r
\right]\\
&-n\int_{T_r}^{T}dT'
\int_{T_r}^{T'}
\frac{C_{\mathrm{vib}}(T'')}{T''}\,dT''\\
&+nRT\log\frac{p}{p_r}
\end{aligned}
}
\tag{7}
```

を得る．

これが Gibbs 自由エネルギーの一般式である．

### 3．基準状態の定数と示量性

純粋な理想気体を考え，温度と圧力を一定にしたとき，Gibbs 自由エネルギーとエントロピーは示量性を持つ．

したがって，

```math
G_r=ng_r
```

```math
S_r=ns_r
```

と表せる．
ここで， $g_r$ と $s_r$ は基準状態におけるモル Gibbs 自由エネルギーとモルエントロピーである．

これを式 (3)，（7）に代入すると，

```math
\boxed{
\begin{aligned}
S(T,p,n)=n\bigg[
&s_r+C_p^0\log\frac{T}{T_r}\\
&+\int_{T_r}^{T}
\frac{C_{\mathrm{vib}}(T')}{T'}\,dT'\\
&-R\log\frac{p}{p_r}
\bigg]
\end{aligned}
}
\tag{8}
```

および，

```math
\boxed{
\begin{aligned}
G(T,p,n)=n\bigg[
&g_r-s_r(T-T_r)\\
&-C_p^0
\left(
T\log\frac{T}{T_r}-T+T_r
\right)\\
&-\int_{T_r}^{T}dT'
\int_{T_r}^{T'}
\frac{C_{\mathrm{vib}}(T'')}{T''}\,dT''\\
&+RT\log\frac{p}{p_r}
\bigg]
\end{aligned}
}
\tag{9}
```

となる．

ここで， $g_r$ と $s_r$ は基準状態の熱力学量であり，熱容量だけからは決定できない．
したがって，絶対的な Gibbs 自由エネルギーとエントロピーの値を決定するには，基準状態の情報が必要である．

### 4．導出した式の独立検証

導出した式が与えられた熱容量および理想気体の状態方程式と整合することを確認する．

#### （a）Gibbs 自由エネルギーの温度微分

式 (9) を温度で偏微分する．

```math
\begin{aligned}
\left(\frac{\partial G}{\partial T}\right)_{p,n}
=n\bigg[
&-s_r-C_p^0\log\frac{T}{T_r}\\
&-\int_{T_r}^{T}
\frac{C_{\mathrm{vib}}(T')}{T'}\,dT'\\
&+R\log\frac{p}{p_r}
\bigg]
\end{aligned}
```

したがって，

```math
-\left(\frac{\partial G}{\partial T}\right)_{p,n}
=S
```

となり，式 (8) と一致する．

#### （b）Gibbs 自由エネルギーの圧力微分

式 (9) を圧力で偏微分すると，

```math
\left(\frac{\partial G}{\partial p}\right)_{T,n}
=\frac{nRT}{p}
```

である．

理想気体の状態方程式より，

```math
\frac{nRT}{p}=V
```

なので，

```math
\boxed{
\left(\frac{\partial G}{\partial p}\right)_{T,n}=V
}
```

が成立する．

#### （c）定圧熱容量

式 (8) を温度で偏微分すると，

```math
\left(\frac{\partial S}{\partial T}\right)_{p,n}
=
\frac{n}{T}
\left[
C_p^0+C_{\mathrm{vib}}(T)
\right]
```

である．
よって，

```math
\begin{aligned}
T\left(\frac{\partial S}{\partial T}\right)_{p,n}
&=nC_p^0+nC_{\mathrm{vib}}(T)\\
&=C_p(T)
\end{aligned}
```

となり，問題文で与えられた定圧熱容量を正しく再現する．

以上の3つの検証により，導出した Gibbs 自由エネルギーとエントロピーの式は，基本熱力学関係式および状態方程式と整合している．

### 5．低温極限に関する注意

問題文では，

```math
\lim_{T\to0}C_{\mathrm{vib}}(T)=0
```

が与えられている．

しかし，この条件だけでは，

```math
\int_0^T\frac{C_{\mathrm{vib}}(T')}{T'}\,dT'
```

の収束は保証されない．

今回の修正版では，積分下限を任意の正の基準温度 $T_r$ としたため，ゼロ温度での積分収束性を仮定する必要がなくなった．

したがって，元の問題文の条件のままで，正の温度範囲におけるエントロピーと Gibbs 自由エネルギーを導出できる．

なお，第三法則を用いて絶対零度でのエントロピーを決定したい場合には，別途，積分の収束性と低温での熱容量の振る舞いについて追加情報が必要である．

### 6．最終結果

- エントロピー

```math
\boxed{
\begin{aligned}
S(T,p,n)=n\bigg[
&s_r+C_p^0\log\frac{T}{T_r}\\
&+\int_{T_r}^{T}
\frac{C_{\mathrm{vib}}(T')}{T'}\,dT'\\
&-R\log\frac{p}{p_r}
\bigg]
\end{aligned}
}
```


- Gibbs 自由エネルギー

```math
\boxed{
\begin{aligned}
G(T,p,n)=n\bigg[
&g_r-s_r(T-T_r)\\
&-C_p^0
\left(
T\log\frac{T}{T_r}-T+T_r
\right)\\
&-\int_{T_r}^{T}dT'
\int_{T_r}^{T'}
\frac{C_{\mathrm{vib}}(T'')}{T''}\,dT''\\
&+RT\log\frac{p}{p_r}
\bigg]
\end{aligned}
}
```
