# 演習問題【3-A-12】

## 解答

### 1. エントロピー $S$ の定義と定式化

熱容量 $C_p$ とエントロピー $S$ の間には，定圧条件下において以下の関係がある．

$$\left( \frac{\partial S}{\partial T} \right)_p = \frac{C_p}{T}$$

これより，エントロピー $S(T, p, n)$ は $T$ について積分することで得られる．
ここで，圧力 $p$ と物質量 $n$ に依存する項を考慮するため，付加関数 $g_1(p, n)$ を導入して次のように書くことができる．

$$S(T, p, n) = \int^T \frac{C_p(T')}{T'} dT' + g_1(p, n) \quad \dots (1)$$

問題文より，定圧熱容量 $C_p$ は次のように与えられている．

$$C_p(T) = n C_p^0 + n C_{\text{vib}}(T)$$

これを式(1)に代入すると，

$$S(T, p, n) = \int^T \frac{n C_p^0 + n C_{\text{vib}}(T')}{T'} dT' + g_1(p, n)$$

$$S(T, p, n) = n C_p^0 \log T + n \int_0^T \frac{C_{\text{vib}}(T')}{T'} dT' + g_1(p, n) \quad \dots (1')$$

（ここで， $\lim_{T \to 0} C_{\text{vib}}(T) = 0$ であるため，積分範囲の下限を $0$ とすることができる．）

### 2. Gibbs 自由エネルギー $G$ の導出

Gibbs 自由エネルギー $G$ は，熱力学の基本関係式 $(\partial G / \partial T)_p = -S$ を用いて求めることができる．

$$\left( \frac{\partial G}{\partial T} \right)_p = - \left( n C_p^0 \log T + n \int_0^T \frac{C_{\text{vib}}(T')}{T'} dT' + g_1(p, n) \right)$$

この両辺を $T$ について積分する．

$$G(p, T, n) = \int \left( -n C_p^0 \log T - n \int_0^T \frac{C_{\text{vib}}(T')}{T'} dT' - g_1(p, n) \right) dT$$

各項を個別に積分する．
- 第1項： $\int (-n C_p^0 \log T) dT = -n C_p^0 (T \log T - T)$
- 第2項： $\int (-n \int_0^T \frac{C_{\text{vib}}(T')}{T'} dT') dT = -n \int_0^T dT' \int_0^{T'} \frac{C_{\text{vib}}(T'')}{T''} dT''$
- 第3項： $\int (-g_1(p, n)) dT = -T g_1(p, n) + g_2(p, n)$ （ここで $g_2(p, n)$ は $T$ に依存しない積分定数）

したがって，

$$G(p, T, n) = -n C_p^0 (T \log T - T) - n \int_0^T dT' \int_0^{T'} \frac{C_{\text{vib}}(T'')}{T''} dT'' - T g_1(p, n) + g_2(p, n) \quad \dots (2)$$

が得られる．

### 3. 圧力 $p$ に関する関係式と付加関数の決定

次に， $(\partial G / \partial p)_T = V$ という関係を用いる．
理想気体の状態方程式 $V = nRT/p$ を代入すると，

$$\left( \frac{\partial G}{\partial p} \right)_T = -T \frac{\partial g_1}{\partial p} + \frac{\partial g_2}{\partial p} = \frac{nRT}{p}$$

この式がすべての $T$ について成り立つためには，次のように項を分ける必要がある．

$$-T \frac{\partial g_1}{\partial p} + \frac{\partial g_2}{\partial p} = T \left( \frac{nR}{p} \right) + 0$$

これより，

$$\frac{\partial g_1}{\partial p} = -\frac{nR}{p}, \quad \frac{\partial g_2}{\partial p} = 0$$

が得られる．
これらを $p$ について積分すると，

$$g_1(p, n) = -nR \log p + \phi_1(n)$$

$$g_2(p, n) = \phi_2(n)$$

となる（ここで $\phi_1(n), \phi_2(n)$ は $p$ に依存しない関数である）．
$g_1 , g_2$ は付加関数であるため，これらは物質量 $n$ に比例する．

$$\phi_1(n) = n\alpha, \quad \phi_2(n) = nU_0 \quad (\alpha, U_0 \text{ は定数})$$

よって，

$$g_1(p, n) = -nR \log p + n\alpha, \quad g_2(p, n) = nU_0 \quad \dots (3)$$

### 4. 公式の完成

$G$ が示量性（物質量 $n$ に比例する性質）を持つためには， $G/n$ が $n$ に依存してはならない．
式(2)に式(3)を代入して整理すると，

$$G = -n C_p^0 (T \log T - T) - n \int_0^T dT' \int_0^{T'} \frac{C_{\text{vib}}(T'')}{T''} dT'' - T (-nR \log p + n\alpha) + nU_0$$

$$G = n \left[ -C_p^0 T \log T + C_p^0 T - \int_0^T dT' \int_0^{T'} \frac{C_{\text{vib}}(T'')}{T''} dT'' + RT \log p - \alpha T + U_0 \right]$$

$$G = n \left[ U_0 - C_p^0 T \log T + RT \log p - (\alpha - C_p^0) T - \int_0^T dT' \int_0^{T'} \frac{C_{\text{vib}}(T'')}{T''} dT'' \right]$$

ここで，定数部分をまとめて $\alpha - C_p^0 = iR$ とおくと（ $i$ は化学定数），

$$G(p, T, n) = n \left[ U_0 - C_p^0 T \log T + RT \log p - iRT - \int_0^T dT' \int_0^{T'} \frac{C_{\text{vib}}(T'')}{T''} dT'' \right] \quad \dots (5)$$

が得られる．

最後に，エントロピー $S$ を求める．
式(1')に $g_1(p, n) = -nR \log p + n\alpha$ を代入し， $\alpha = C_p^0 + iR$ を用いると，

$$S(T, p, n) = n C_p^0 \log T + n \int_0^T \frac{C_{\text{vib}}(T')}{T'} dT' - nR \log p + n(C_p^0 + iR)$$

$$S(T, p, n) = n \left[ C_p^0 \log T - R \log p + \int_0^T \frac{C_{\text{vib}}(T')}{T'} dT' + C_p^0 + iR \right] \quad \dots (6)$$

が得られる．

## 解説

### 1. 示量性と付加関数

熱力学における「示量性」とは，物質量 $n$ が 2 倍になれば，系の体積 $V$ やエントロピー $S$ ，Gibbs 自由エネルギー $G$ などの物理量も 2 倍になるという性質である．
これに対し，温度 $T$ や圧力 $p$ は物質量によらない「示強性」を持つ量である．
今回の導出では，積分定数として導入した $g_1(p, n)$ や $g_2(p, n)$ が $n$ にどのように依存するかを，この示量性の条件（ $G/n$ が $n$ に依存しない）から決定している．

### 2. 化学定数 $i$ の意味

積分定数として現れた $i$ は，系の基準状態（標準状態）をどのように定めるかによって決まる値である．
エントロピーや Gibbs 自由エネルギーには，絶対的な値の基準を定めるための「オフセット」が必要であり，この $i$ がその役割を果たしている．

### 3. 式の構成要素

導出された式に含まれる各項の物理的な意味は以下の通りである：
- $C_p^0$ に関する項： 分子の並進運動と回転に由来するエネルギーとエントロピーへの寄与．
- $C_{\text{vib}}$ に関する項： 分子の内部振動に由来する寄与．
- $RT \log p$ や $-R \log p$ の項： 理想気体の膨張・圧縮に伴う圧力依存性．
- $U_0$ や $iR$ の項： 基準状態における内部エネルギーやエントロピーに関連する定数．
