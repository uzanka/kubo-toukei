# 演習問題【3-A-12】

## 解答

### 1．定圧熱容量からエントロピーを求める

問題文より， $n\ \mathrm{mol}$ の理想気体の定圧熱容量は

```math
C_p(T)=nC_p^0+nC_{\mathrm{vib}}(T)
```

である．
ここで， $C_p^0$ は分子の並進運動と回転運動に由来する定圧モル比熱， $C_{\mathrm{vib}}(T)$ は分子の内部振動に由来するモル比熱である．

定圧条件下では，エントロピー $S$ と定圧熱容量 $C_p$ の間に

```math
\left(\frac{\partial S}{\partial T}\right)_p
=\frac{C_p}{T}
```

という関係が成り立つ．
これは，定圧条件下で温度を微小量 $dT$ だけ変化させたとき，エントロピーの変化が $dS=C_p\,dT/T$ で与えられることを意味する．

この式を温度 $T$ について積分すると，

```math
S(T,p,n)=\int^T\frac{C_p(T')}{T'}\,dT'
+g_1(p,n)
\tag{1}
```

となる．
ここで， $T'$ は積分変数であり， $g_1(p,n)$ は温度に依存しない積分関数である．
積分定数が圧力 $p$ と物質量 $n$ に依存することは，温度について偏微分したときにその項が消えることから分かる．

対数の引数を無次元にするため，基準温度を $T_0$ とすると，

```math
\begin{aligned}
S(T,p,n)
={}&nC_p^0\log\frac{T}{T_0}\\
&+n\int_0^T
\frac{C_{\mathrm{vib}}(T')}{T'}\,dT'
+g_1(p,n)
\end{aligned}
\tag{2}
```

と書ける．
ただし，温度に依存しない定数は $g_1(p,n)$ に含めた．
また，振動による積分を下限 $0$ から定義するため， $C_{\mathrm{vib}}(T')/T'$ の積分が $T'=0$ 付近で収束することを仮定する．

### 2．エントロピーから Gibbs 自由エネルギーを求める

Gibbs 自由エネルギー $G$ は，温度 $T$ ，圧力 $p$ ，物質量 $n$ を用いて $G=G(T,p,n)$ と表される．
その熱力学的関係式の一つは

```math
\left(\frac{\partial G}{\partial T}\right)_{p,n}=-S
\tag{3}
```

である．
この関係式に式 (2) を代入すると，

```math
\begin{aligned}
\left(\frac{\partial G}{\partial T}\right)_{p,n}
={}&-nC_p^0\log\frac{T}{T_0}\\
&-n\int_0^T
\frac{C_{\mathrm{vib}}(T')}{T'}\,dT'
-g_1(p,n)
\end{aligned}
```

を得る．
両辺を温度 $T$ について積分すると，

```math
\begin{aligned}
G(T,p,n)
={}&-nC_p^0
\left[T\log\frac{T}{T_0}-T\right]\\
&-n\int_0^T dT'\int_0^{T'}
\frac{C_{\mathrm{vib}}(T'')}{T''}\,dT''\\
&-Tg_1(p,n)+g_2(p,n)
\end{aligned}
\tag{4}
```

となる．
ここで， $T''$ も積分変数であり， $g_2(p,n)$ は温度に依存しない積分関数である．

式 (4) の第1項は， $C_p^0$ が温度に依存しないことから得られる．
第2項は，振動によるエントロピーの温度積分である．
第3項は $g_1(p,n)$ が温度に依存しないことから生じる．

### 3．理想気体の状態方程式を用いて積分関数を決定する

次に，Gibbs 自由エネルギーの圧力微分に関する関係式

```math
\left(\frac{\partial G}{\partial p}\right)_{T,n}=V
\tag{5}
```

を用いる．
理想気体の状態方程式

```math
pV=nRT
```

より，

```math
V=\frac{nRT}{p}
```

である．
一方，式 (4) を圧力 $p$ で偏微分すると，

```math
-T\frac{\partial g_1}{\partial p}
+\frac{\partial g_2}{\partial p}
=\frac{nRT}{p}
\tag{6}
```

となる．
この等式は任意の温度 $T$ について成り立つ．
左辺の $T$ に比例する項と温度に依存しない項を比較すると，

```math
\frac{\partial g_1}{\partial p}=-\frac{nR}{p},
\qquad
\frac{\partial g_2}{\partial p}=0
```

を得る．
したがって，基準圧力を $p_0$ として圧力について積分すると，

```math
g_1(p,n)=-nR\log\frac{p}{p_0}+\phi_1(n)
\tag{7}
```

```math
g_2(p,n)=\phi_2(n)
\tag{8}
```

となる．
ここで， $\phi_1(n)$ と $\phi_2(n)$ は圧力に依存しない関数である．

さらに，Gibbs 自由エネルギー $G$ は示量性を持つ．
すなわち，温度と圧力を一定に保ったまま物質量を $n$ 倍の割合で変化させると， $G$ も同じ割合で変化する．
したがって， $G/n$ は物質量 $n$ に依存しない．
式 (4)，(7)，(8) にこの条件を適用すると， $\phi_1(n)$ と $\phi_2(n)$ はそれぞれ $n$ に比例しなければならない．
よって，

```math
\phi_1(n)=n\alpha,\qquad
\phi_2(n)=nU_0
\tag{9}
```

と書ける．
ここで， $\alpha$ と $U_0$ は物質量に依存しない定数である．

以上より，

```math
g_1(p,n)=-nR\log\frac{p}{p_0}+n\alpha
```

```math
g_2(p,n)=nU_0
```

が得られる．

### 4．Gibbs 自由エネルギーの公式

式 (7)～(9) を式 (4) に代入すると，

```math
\begin{aligned}
G(T,p,n)
=n\bigg[&
-C_p^0T\log\frac{T}{T_0}
+C_p^0T\\
&+RT\log\frac{p}{p_0}
-\alpha T+U_0\\
&-\int_0^T dT'\int_0^{T'}
\frac{C_{\mathrm{vib}}(T'')}{T''}\,dT''
\bigg]
\end{aligned}
\tag{10}
```

となる．
ここで，定数 $i$ を

```math
iR=\alpha-C_p^0
\tag{11}
```

によって定義する．
式 (10) は，

```math
\boxed{
\begin{aligned}
G(T,p,n)=n\bigg[&
U_0-C_p^0T\log\frac{T}{T_0}
+RT\log\frac{p}{p_0}\\
&-iRT
-\int_0^T dT'\int_0^{T'}
\frac{C_{\mathrm{vib}}(T'')}{T''}\,dT''
\bigg]
\end{aligned}
}
\tag{12}
```

と整理できる．
これが Gibbs 自由エネルギーの公式である．

なお，解答例では $\log T$ ， $\log p$ と表記しているが，これは基準温度・基準圧力を省略した略記である．
また，基準温度や基準圧力の選び方は，定数 $i$ や $U_0$ の表し方に反映される．

### 5．エントロピーの公式

エントロピーは，式 (2) に

```math
g_1(p,n)=-nR\log\frac{p}{p_0}+n\alpha
```

を代入することによって求められる．
さらに，式 (11) より

```math
\alpha=C_p^0+iR
```

であるから，

```math
\begin{aligned}
S(T,p,n)
=n\bigg[&
C_p^0\log\frac{T}{T_0}
-R\log\frac{p}{p_0}\\
&+\int_0^T\frac{C_{\mathrm{vib}}(T')}{T'}\,dT'
+C_p^0+iR
\bigg]
\end{aligned}
```

となる．
したがって，エントロピーの公式は

```math
\boxed{
\begin{aligned}
S(T,p,n)=n\bigg[&
C_p^0\log\frac{T}{T_0}
-R\log\frac{p}{p_0}\\
&+\int_0^T\frac{C_{\mathrm{vib}}(T')}{T'}\,dT'
+C_p^0+iR
\bigg]
\end{aligned}
}
\tag{13}
```

である．

この式は，式 (3) の関係式を用いて，式 (12) の Gibbs 自由エネルギーを温度で偏微分することによっても得られる．

### 6．1 mol 当たりの Gibbs 自由エネルギーと圧力依存性

1 mol 当たりの Gibbs 自由エネルギーを

```math
\bar G(T,p)=\frac{G(T,p,n)}{n}
```

と定義する．
式 (12) で，温度 $T$ を一定に保って圧力 $p$ と基準圧力 $p_0$ に対応する値を比較すると，圧力に依存する項だけが異なる．
したがって，

```math
\boxed{
\bar G(T,p)=\bar G(T,p_0)
+RT\log\frac{p}{p_0}
}
\tag{14}
```

を得る．
これは解答例の式 (7) である．

### 7．結果の確認

導出した式には，次の特徴がある．

- Gibbs 自由エネルギー $G$ とエントロピー $S$ は，いずれも物質量 $n$ に比例している．これは両者が示量性を持つことと一致する．
- 圧力依存性は，Gibbs 自由エネルギーでは $RT\log(p/p_0)$ ，エントロピーでは $-R\log(p/p_0)$ として現れる．
- 振動による寄与は，エントロピーでは $C_{\mathrm{vib}}(T)/T$ の積分として，Gibbs 自由エネルギーではその温度積分として現れる．
- $i$ と $U_0$ は積分によって生じる定数であり，熱容量の温度依存性だけでは決定できない．これらを数値的に定めるには，基準状態などの追加情報が必要である．

以上より，問題で与えられた定圧熱容量と理想気体の状態方程式から，Gibbs 自由エネルギーおよびエントロピーの公式が導かれた．
