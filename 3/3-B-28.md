# 演習問題【3-B-28】

## 解答

### 1．自由エネルギー $F^*(T,X)$ の物理的意味

ばね定数 $k$ のばねに皿をつるし，その上に質量 $m$ のおもりを載せる．
皿の質量を $m'$ ，重力加速度を $g$ ，ばねの伸びを $x$ ，ばねに作用する外部張力を $X$ とする．
伸び $x$ の正方向を下向きとする．

おもりと皿が静止しているとき，力のつり合いより，

```math
X=(m+m')g
```

となる．
ばねが $x$ だけ伸びると，おもりと皿はともに $x$ だけ下降する．
したがって，伸びがゼロの状態を重力ポテンシャルエネルギーの基準とすれば，

```math
\begin{aligned}
W
&=(m+m')g(z_0-x)-(m+m')gz_0\\
&=-(m+m')gx
\end{aligned}
```

である．
よって，

```math
\boxed{W=-Xx}
```

となる．

ここで， $X$ は外部から加える荷重を表す制御変数である．
上記の吊り下げ荷重は，特定の一定値 $X$ を実現する一例である．
荷重を変化させる場合には，外部荷重を準静的に調節する装置を用い，異なる荷重設定における平衡状態を比較する．
したがって，以下の $dX$ は，固定された一つのおもりの重量が変化することではなく，外部荷重の設定値を変化させることを表す．

温度 $T$ ，伸び $x$ におけるばねのヘルムホルツ自由エネルギーを $F(T,x)$ とする．
このとき，外部荷重 $X$ を一定に保った系の自由エネルギーに相当するポテンシャルは，

```math
\Phi(T,X;x)=F(T,x)-Xx
```

で与えられる．

平衡状態では，このポテンシャルが伸び $x$ に関して最小となる．
したがって，

```math
\left(\frac{\partial\Phi}{\partial x}\right)_{T,X}
=
\left(\frac{\partial F}{\partial x}\right)_T-X=0
```

より，

```math
\boxed{
X=\left(\frac{\partial F}{\partial x}\right)_T
}
```

を得る．
ここで，ばね自身の張力を

```math
X_{\mathrm{s}}=
\left(\frac{\partial F}{\partial x}\right)_T
```

と表せば，平衡状態においてのみ $X_{\mathrm{s}}=X$ となる．
また，安定な平衡には，

```math
\left(\frac{\partial^2F}{\partial x^2}\right)_T>0
```

が必要である．

平衡伸びを $x=x(T,X)$ とすると，ルジャンドル変換によって得られる自由エネルギーは，

```math
\boxed{
F^*(T,X)=F(T,x(T,X))-Xx(T,X)
}
```

となる．
すなわち， $F(T,x)$ が伸び $x$ を独立変数とする自由エネルギーであるのに対し， $F^*(T,X)$ は外部張力 $X$ を独立変数とする自由エネルギーである．

さらに，固定した温度 $T$ と外部張力 $X$ の下では，平衡状態が $\Phi(T,X;x)$ を最小にするため， $F^*(T,X)$ は外部荷重制御下の平衡自由エネルギーを表す．

### 2．自由エネルギー $F^*$ の具体的な形

ばねがフックの法則に従い，ばね定数 $k$ が温度に依存しない場合，弾性エネルギーは，

```math
E_{\mathrm{el}}=\frac12kx^2
```

である．
したがって，ばねの自由エネルギーは，

```math
F(T,x)=F(T,0)+\frac12kx^2
```

と表される．

これを，

```math
F^*(T,X)=F(T,x)-Xx
```

に代入すると，

```math
F^*
=
F(T,0)+\frac12kx^2-Xx
```

となる．
平衡条件

```math
X=kx
```

より，

```math
x=\frac{X}{k}
```

であるから，

```math
\begin{aligned}
F^*(T,X)
&=F(T,0)+\frac{X^2}{2k}
-\frac{X^2}{k}\\
&=F(T,0)-\frac{X^2}{2k}
\end{aligned}
```

となる．
よって，

```math
\boxed{
F^*(T,X)=F(T,0)-\frac{X^2}{2k}
}
```

を得る．

この結果は，ポテンシャル

```math
\Phi(T,X;x)
=
F(T,0)+\frac{k}{2}
\left(x-\frac{X}{k}\right)^2
-\frac{X^2}{2k}
```

を用いても確認できる．
$k>0$ であるから，その最小値は $x=X/k$ において得られ，上記の $F^*(T,X)$ と一致する．

### 3．微分 $dF^*(T,X)$ の物理的意味

まず，ばね自身の自由エネルギー $F(T,x)$ の全微分は，

```math
dF=-S\,dT+X_{\mathrm{s}}\,dx
```

である．
ここで，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_x,
\qquad
X_{\mathrm{s}}=
\left(\frac{\partial F}{\partial x}\right)_T
```

である．

一方，

```math
F^*(T,X)=F(T,x(T,X))-Xx(T,X)
```

を全微分すると，

```math
dF^*=dF-X\,dx-x\,dX
```

となる．
ここで，平衡状態の族に沿って変化を考えると，

```math
X_{\mathrm{s}}=X
```

であるから，

```math
\begin{aligned}
dF^*
&=-S\,dT+X_{\mathrm{s}}\,dx-X\,dx-x\,dX\\
&=-S\,dT-x\,dX
\end{aligned}
```

となる．
したがって，

```math
\boxed{
dF^*=-S\,dT-x\,dX
}
```

を得る．

この式は， $F^*$ が温度 $T$ と外部張力 $X$ を自然変数とする自由エネルギーであることを示している．
特に，

```math
\boxed{
\left(\frac{\partial F^*}{\partial T}\right)_X=-S
}
```

および，

```math
\boxed{
\left(\frac{\partial F^*}{\partial X}\right)_T=-x
}
```

が成立する．

すなわち，温度を一定にして外部張力を準静的に変化させたとき， $F^*$ の変化は，

```math
\boxed{dF^*=-x\,dX}
```

で表される．
一方，外部張力を一定にして温度を変化させたときは，

```math
\boxed{dF^*=-S\,dT}
```

となる．

ここで， $-x\,dX$ の力学的意味を考える．
ばねの弾性エネルギーは，

```math
E_{\mathrm{el}}=\frac12kx^2
```

であるから，

```math
dE_{\mathrm{el}}=kx\,dx=X_{\mathrm{s}}\,dx
```

となる．
また，外部荷重のポテンシャルエネルギーは，それぞれの荷重設定に対して，

```math
W_X=-Xx
```

であるから，

```math
dW_X=-X\,dx-x\,dX
```

となる．
これらを加えると，

```math
\begin{aligned}
dE_{\mathrm{el}}+dW_X
&=X_{\mathrm{s}}\,dx-X\,dx-x\,dX\\
&=(X_{\mathrm{s}}-X)\,dx-x\,dX
\end{aligned}
```

を得る．
平衡状態では $X_{\mathrm{s}}=X$ であるから，

```math
\boxed{
dE_{\mathrm{el}}+dW_X=-x\,dX
}
```

となる．

したがって， $-x\,dX$ は，平衡状態を保ちながら外部張力の設定値を変化させたときの，ばねの弾性エネルギーと外部荷重のポテンシャルエネルギーの和の変化を表している．
ばねの伸びに伴う弾性エネルギーの変化と，荷重による位置エネルギーの変化のうち $X\,dx$ に相当する部分が相殺され，荷重の設定値の変化に対応する $-x\,dX$ が残るのである．

さらに，この関係は，平衡状態において，

```math
E_{\mathrm{el}}+W_X
=
\frac12kx^2-Xx
=
-\frac{X^2}{2k}
```

となることからも確認できる．
これを $X$ で微分すると，

```math
d(E_{\mathrm{el}}+W_X)
=
-\frac{X}{k}\,dX
=
-x\,dX
```

となる．

また，ばねの内部エネルギーを $U$ とすると，

```math
F+TS=U
```

であるから，

```math
\begin{aligned}
F^*+TS
&=F-Xx+TS\\
&=U-Xx\\
&=U+W_X
\end{aligned}
```

となる．
よって，

```math
\boxed{
F^*+TS=U+W_X
}
```

であり，これは，ばねの内部エネルギーと外部荷重のポテンシャルエネルギーの和に対応する．

以上より， $F^*(T,X)$ は外部張力を制御変数とする熱力学ポテンシャルであり，

```math
\boxed{
dF^*=-S\,dT-x\,dX
}
```

は，温度変化による熱力学的寄与と，外部張力の設定値の変化による力学的寄与を表す式である．
