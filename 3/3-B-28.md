# 演習問題【3-B-28】

## 解答

### 1．自由エネルギー $F^*(T,X)$ の物理的意味

ばね定数 $k$ のばねに皿をつるし，質量 $M$ のおもりを皿に載せる．
ばねの伸びを $x$ ，ばねの張力を $X$ とすると，力のつり合いより

```math
X=Mg
```

であり，フックの法則より

```math
X=kx
```

である．
ここで， $g$ は重力加速度である．

磁場や張力などの外力がないときの皿の高さを $z_0$ とする．
ばねが $x$ だけ伸びると，おもりの高さは $z_0-x$ となる．
皿の質量を $M'$ とすれば，おもりと皿の重力ポテンシャルエネルギー $W$ は

```math
W=Mg(z_0-x)+M'gz_0
```

である．
これを整理し， $X=Mg$ を用いると，

```math
W=-Xx+(M+M')gz_0
```

となる．
最後の項は定数であるから，

```math
W=-Xx+\text{const.}
```

と書ける．

温度 $T$ ，伸び $x$ におけるばねの自由エネルギーを $F(T,x)$ とする．
ばねとおもりを合わせた全系の自由エネルギーは，ばねの自由エネルギーとおもりの重力ポテンシャルエネルギーの和である．
定数項を除けば，

```math
\boxed{
F^*(T,X)=F(T,x)-Xx
}
```

となる．
したがって， $F^*$ は，伸び $x$ をもつばねだけではなく，ばねとおもりを合わせた全系の自由エネルギーを表す量である．
おもりは純力学的な系であるため，その自由エネルギーは重力ポテンシャルエネルギーに等しい．

### 2．自由エネルギー $F^*$ の具体的な形

ばね定数を $k$ とすると，ばねの自由エネルギーは

```math
F(T,x)=F(T,0)+\frac{1}{2}kx^2
```

と表される．
これを $F^*=F-Xx$ に代入すると，

```math
F^*=F(T,0)+\frac{1}{2}kx^2-Xx
```

である．
ここで $X=kx$ ，すなわち $x=X/k$ を用いれば，

```math
\begin{aligned}
F^*(T,X)
&=F(T,0)+\frac{X^2}{2k}-\frac{X^2}{k}\\
&=F(T,0)-\frac{X^2}{2k}
\end{aligned}
```

となる．
よって，

```math
\boxed{
F^*(T,X)=F(T,0)-\frac{X^2}{2k}
}
```

である．

### 3．微分 $dF^*(T,X)$ の意味

$F^*=F(T,x)-Xx$ を微分すると，

```math
dF^*=dF-X\,dx-x\,dX
```

となる．
ばねの自由エネルギーの微分は

```math
dF=-S\,dT+X\,dx
```

である．
これを代入すると，

```math
\begin{aligned}
dF^*
&=-S\,dT+X\,dx-X\,dx-x\,dX\\
&=-S\,dT-x\,dX
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
dF^*=-S\,dT-x\,dX
}
```

である．
この式は， $F^*$ が温度 $T$ と張力 $X$ を独立変数としてもつ自由エネルギーであることを示している．
特に，

```math
\left(\frac{\partial F^*}{\partial T}\right)_X=-S,
\qquad
\left(\frac{\partial F^*}{\partial X}\right)_T=-x
```

である．

さらに， $-x\,dX$ の物理的意味を考える．
ばねの弾性エネルギーを

```math
E_{\mathrm{el}}=\frac{1}{2}kx^2
```

とすると， $X=kx より，

```math
dE_{\mathrm{el}}=kx\,dx=X\,dx
```

である．
一方，おもりの重力ポテンシャルエネルギーは，定数項を除けば $W=-Xx$ であるから，

```math
dW=-X\,dx-x\,dX
```

となる．
この2式を加えると，

```math
\begin{aligned}
dE_{\mathrm{el}}+dW
&=X\,dx-X\,dx-x\,dX\\
&=-x\,dX
\end{aligned}
```

を得る．
すなわち，

```math
\boxed{
-x\,dX=dE_{\mathrm{el}}+dW
}
```

である．

これは， $-x\,dX$ が，ばねの弾性エネルギーの変化とおもりの重力ポテンシャルエネルギーの変化の和を表すことを意味する．
張力を変化させると，ばねの弾性エネルギーとおもりの位置エネルギーはそれぞれ変化するが，その合計の変化が $-x\,dX$ で表されるのである．

また， $F^*+TS$ は，ばねの内部エネルギーとおもりの重力ポテンシャルエネルギーの和に対応する．
実際，

```math
F^*+TS=(F+TS)-Xx=U-Xx
```

であり， $F+TS=U$ はばねの内部エネルギーである．
ここに $W=-Xx+\text{const.}$ を用いると，

```math
\boxed{
F^*+TS=U+W+\text{const.}
}
```

となる．
これにより， $F^*$ が全系の自由エネルギーを表すことも確認できる．


## 解説

この問題の重要点は， $F(T,x)$ が伸び $x$ を独立変数とする自由エネルギーであるのに対し， $F^*(T,X)$ は張力 $X$ を独立変数とする自由エネルギーであることである．
両者は $F^*=F-Xx$ という変換で結ばれ，その結果として微分に現れる力学的な項が $X\,dx$ から $-x\,dX$ へと変わる．
