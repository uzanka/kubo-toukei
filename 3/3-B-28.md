# 演習問題【3-B-28】

## 解答

本問題では，ばねと重り（おもり）を組み合わせた系において，新しい自由エネルギー $F^*$ を導入し，その物理的な意味を考察する．

### 1. 設定の整理

まず，系の構成要素を整理する．
- **ばね**:
  ばね定数 $k$ のばね．
  伸びを $x$ とすると，ばねの張力は $X = kx$ である．
- **おもり**:
  質量 $M$ のおもり．
  ばねの端にかかっている．
- **皿とおもり**:
  ばねの端に吊るされた皿（質量 $M'$ を含む）とおもり．

系全体のポテンシャルエネルギー $W$ を考える．
皿の初期の高さ（ $X=0$ のとき）を $z_0$ とする．
おもり $M$ がばねの伸び $x$ によって位置 $z_0 - x$ にあるとき，おもりの位置エネルギーは $Mg(z_0 - x)$ である．
また，皿（質量 $M'$ ）は常に高さ $z_0$ にあるとすると，その位置エネルギーは $M'gz_0$ である．

したがって，おもり全体のポテンシャルエネルギー $W$ は，

$$W = Mg(z_0 - x) + M'gz_0$$

$$W = Mgz_0 - Mgx + M'gz_0$$

$$W = -Mgx + (M + M')gz_0$$

ここで，おもりの張力 $X = Mg$ なので，

$$W = -Xx + \text{const.}$$

と書ける．

### 2. 全系の自由エネルギー $F^*$ の導入

ばね自体の自由エネルギーを $F(T, x)$ とする．
系全体の自由エネルギー $F^*$ を，ばねの自由エネルギーと，おもりによるポテンシャルエネルギーの和として定義する．

$$F^* = F(T, x) + W + \text{const.}$$

ここで， $W = -Xx + \text{const.}$ なので，

$$F^*(T, X) = F(T, x) - Xx + \text{const.}$$

となる．
これが問題文で与えられた定義である．

この $F^*$ は，ばね（熱的な自由度を持つ）とおもり（純力学的な系）を合わせた「全系」の自由エネルギーを表している．

### 3. $F^*$ の具体的な形

ばね定数を $k$ とすると，ばねの自由エネルギーは $F(T, x) = F(T, 0) + \frac{1}{2}kx^2$ と書ける．
これに $F^* = F - Xx$ を適用する（定数は無視する）．

$$F^* = F(T, 0) + \frac{1}{2}kx^2 - Xx$$

ここで $x = X/k$ を代入すると，

$$F^* = F(T, 0) + \frac{1}{2}k\left(\frac{X}{k}\right)^2 - X\left(\frac{X}{k}\right)$$

$$F^* = F(T, 0) + \frac{X^2}{2k} - \frac{X^2}{k}$$

$$F^* = F(T, 0) - \frac{X^2}{2k}$$

となる．

### 4. $dF^*$ の物理的意味

次に， $F^*$ の微小変化 $dF^*$ を計算し，その物理的な意味を考える．
変数 $T$ と $X$ を用いて微分する．

$$dF^* = dF(T, 0) + d\left(\frac{1}{2}kx^2 - Xx\right)$$

ここで， $F^*(T,X)$ は $T$ と $X$ を独立変数とする関数なので，全面微分を丁寧に計算する．

$$dF^* = \left(\frac{\partial F}{\partial T}\right)_x dT + \left(\frac{\partial F}{\partial x}\right)_T dx - (X\,dx + x\,dX)$$

ここで， $\left(\frac{\partial F}{\partial x}\right)_T = \frac{\partial}{\partial x} \left(F(T, 0) + \frac{1}{2}kx^2\right) = kx = X$ である．
よって，

$$dF^* = dF(T, 0) + X\,dx - X\,dx - x\,dX$$

$$dF^* = dF(T, 0) - x\,dX$$

となる．

ここで， $-x\,dX$ という項に注目する．
前述の $W = -Xx$ （定数項を除く）の関係を使うと，

$$dW = d(-Xx) = -X\,dx - x\,dX$$

また，ばねの弾性エネルギー（自由エネルギーの $x$ 依存部分）は $E_{el} = \frac{1}{2}kx^2$ である．
その微分は $dE_{el} = kx\,dx = X\,dx$ である．
これらを組み合わせると，

$$-x\,dX = (X\,dx) + (-X\,dx - x\,dX) = dE_{el} + dW$$

となる．

したがって， $dF^*$ は以下のようになる．

$$dF^* = dF(T, 0) + d\left(\frac{1}{2}kx^2\right) + dW$$

これは，
1. ばねの内部エネルギー（温度 $T$ に依存する部分 $F(T, 0)$ ）の変化
2. ばねの弾性エネルギーの増加
3. おもりの位置エネルギーの変化
の合計であることを示している．

特に， $-x\,dX$ の部分は，「ばねに蓄えられる弾性エネルギーの増加」と「おもりが持つ位置エネルギーの減少」の合計を表している．

## 解説

### なぜこのような定義をするのか？

通常のばねの自由エネルギー $F(T, x)$ は，ばねの「伸び $x$」を独立変数として扱う．
しかし，実際の物理的な実験や観測では，ばねにかかる「力（張力） $X$ 」を制御したり，測定したりすることが多い．
そこで， $X$ を独立変数とする新しい自由エネルギー $F^*(T, X)$ を定義することで，系の状態を $T$ と $X$ で記述できるようになる．

### 変数変換のポイント

$x$ から $X$ への変換は， $X = kx$ という拘束条件に基づいている．
熱力学的なポテンシャルにおいて，変数を $x$ から $X$ に変換する場合，ルジャンドル変換（Legendre transformation）に似た操作が行われている．
$F^*(X) = F(x) - Xx$ という形は，まさにルジャンドル変換の形式そのものである．

### $dF^*$ の項の解釈

$dF^* = dF(T, 0) - x\,dX$ という結果は非常にシンプルである．
通常，熱力学では $dF = -SdT - PdV$ のように書かれるが，ここでは $X$ を用いているため，

$$dF^* = -SdT - x\,dX$$

のように解釈できる．
ここでの $x$ は，圧力 $P$ に相当する役割（張力 $X$ に対する共役変数）を果たしている．
$-x\,dX$ は，外力が系に対して行う仕事と，その仕事がどのようにエネルギーとして分配されるか（ばねの弾性エネルギーか，おもりの位置エネルギーか）を非常に明快に示している．
