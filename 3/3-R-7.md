# 演習問題【3-R-7】

## 解答

理想気体の定積熱容量が

```math
C_V=Nf(T)
```

と与えられている．
ここで， $N$ は分子数， $f(T)$ は温度 $T$ の関数である．
この関係と理想気体の状態方程式

```math
pV=NkT
```

を用いて，ヘルムホルツ自由エネルギー $F$ ，内部エネルギー $U$ ，エントロピー $S$ ，化学ポテンシャル $\mu$ を求める．
ただし， $k$ はボルツマン定数である．

### 1．エントロピー $S$ を求める

定積熱容量の定義より，

```math
C_V=T\left(\frac{\partial S}{\partial T}\right)_{V,N}
```

である．
したがって，

```math
\left(\frac{\partial S}{\partial T}\right)_{V,N}
=\frac{C_V}{T}
=\frac{Nf(T)}{T}
```

となる．
これを温度 $T$ について積分すると，

```math
\boxed{
S=N\int^T\frac{f(T')}{T'}\,dT'
+g_1(V,N)
}
\tag{1}
```

を得る．
ここで， $g_1(V,N)$ は温度に依存しない積分関数である．

### 2．ヘルムホルツ自由エネルギー $F$ を求める

ヘルムホルツ自由エネルギーは

```math
F=U-TS
```

で定義され，その温度微分は

```math
\left(\frac{\partial F}{\partial T}\right)_{V,N}=-S
```

を満たす．
したがって，式 (1) を代入して温度について積分すると，

```math
\begin{aligned}
F={}&-N\int^T dT'
\int^{T'}\frac{f(T'')}{T''}\,dT''\\
&-Tg_1(V,N)+g_2(V,N)
\end{aligned}
\tag{2}
```

となる．
ここで， $g_2(V,N)$ も温度に依存しない積分関数である．

ここで，部分積分の公式

```math
\int u\,dv=uv-\int v\,du
```

を用いる．

```math
u=\int^{T'}\frac{f(T'')}{T''}\,dT'',
\qquad dv=dT'
```

とおけば，

```math
du=\frac{f(T')}{T'}\,dT',
\qquad v=T'
```

であるから，

```math
\boxed{
\int^T dT'\int^{T'}\frac{f(T'')}{T''}\,dT''
=
T\int^T\frac{f(T')}{T'}\,dT'
-\int^T f(T')\,dT'
}
\tag{3}
```

となる．
この等式では，不定積分の積分定数を整合するように選び，定数項を付加関数に吸収している．

### 3．内部エネルギー $U$ を求める

関係式

```math
U=F+TS
```

に式 (1)，(2)，(3) を代入すると，

```math
\begin{aligned}
U
&=N\int^T f(T')\,dT'+g_2(V,N)
\end{aligned}
```

となる．
したがって，

```math
\boxed{
U=N\int^T f(T')\,dT'+g_2(V,N)
}
\tag{4}
```

を得る．

### 4．付加関数 $g_1,g_2$ を決定する

ヘルムホルツ自由エネルギーと圧力の関係は，

```math
\left(\frac{\partial F}{\partial V}\right)_{T,N}=-p
```

である．
理想気体の状態方程式 $p=NkT/V$ を用いると，

```math
\left(\frac{\partial F}{\partial V}\right)_{T,N}
=-\frac{NkT}{V}
```

となる．

式 (2) を体積 $V$ について偏微分すると，

```math
-T\frac{\partial g_1}{\partial V}
+\frac{\partial g_2}{\partial V}
=-\frac{NkT}{V}
```

を得る．
$g_1,g_2$ は温度に依存しないため，この等式が任意の温度 $T$ で成立するには，温度に比例する項と温度に依存しない項がそれぞれ一致しなければならない．
よって，

```math
\frac{\partial g_1}{\partial V}=\frac{Nk}{V},
\qquad
\frac{\partial g_2}{\partial V}=0
```

である．
これらを体積について積分すると，

```math
\boxed{
g_1(V,N)=Nk\log V+k\phi_1(N)
}
```

および

```math
\boxed{
g_2(V,N)=\phi_2(N)
}
\tag{5}
```

を得る．
ここで， $\phi_1(N),\phi_2(N)$ は粒子数 $N$ のみの関数である．

### 5．化学ポテンシャル $\mu$ を求め，付加関数を決定する

化学ポテンシャルは，温度と体積を一定に保ったときの自由エネルギーの粒子数微分であり，

```math
\mu=\left(\frac{\partial F}{\partial N}\right)_{T,V}
```

と定義される．
式 (2)，(5) を用いると，

```math
\begin{aligned}
\mu={}&-\int^T dT'\int^{T'}
\frac{f(T'')}{T''}\,dT''\\
&-kT\log V
-kT\frac{d\phi_1}{dN}
+\frac{d\phi_2}{dN}
\end{aligned}
\tag{6}
```

となる．

化学ポテンシャルは示強性を持つ量である．
すなわち，温度 $T$ を固定すると，粒子数 $N$ と体積 $V$ には個別には依存せず，その比 $V/N$ を通じて依存する．
したがって，式 (6) における $\log V$ と $N$ に依存する項をまとめると，

```math
\log V+\frac{d\phi_1}{dN}
=\log\frac{V}{N}+\alpha
```

でなければならない．
ここで， $\alpha$ は定数である．
よって，

```math
\frac{d\phi_1}{dN}=-\log N+\alpha
```

となる．
これを粒子数 $N$ について積分すると，

```math
\boxed{
\phi_1(N)=-N\log N+N+N\alpha
}
```

を得る．

また，化学ポテンシャルが $N$ に依存しないためには，

```math
\frac{d\phi_2}{dN}=\phi_0
```

でなければならない．
ここで， $\phi_0$ は定数である．
したがって，

```math
\boxed{
\phi_2(N)=N\phi_0
}
\tag{7}
```

となる．
以上により，付加関数 $g_1,g_2$ が決定された．

### 6．最終結果

式 (1)，(2)，(4)，(6) に式 (5)，(7) の結果を代入する．
まず，ヘルムホルツ自由エネルギーは

```math
\boxed{
\begin{aligned}
F={}&-N\int^T dT'\int^{T'}
\frac{f(T'')}{T''}\,dT''\\
&-NkT\log\frac{V}{N}
-NkT+N\phi_0-NkT\alpha
\end{aligned}
}
\tag{8}
```

となる．

内部エネルギーは，

```math
\boxed{
U=N\int^T f(T')\,dT'+N\phi_0
}
\tag{9}
```

である．
また，エントロピーは，

```math
\boxed{
S=N\int^T\frac{f(T')}{T'}\,dT'
+Nk\log\frac{V}{N}+Nk+Nk\alpha
}
\tag{10}
```

となる．

さらに，化学ポテンシャルは，

```math
\boxed{
\begin{aligned}
\mu={}&-\int^T dT'\int^{T'}
\frac{f(T'')}{T''}\,dT''\\
&-kT\log\frac{V}{N}
+\phi_0-kT\alpha
\end{aligned}
}
\tag{11}
```

である．
理想気体の状態方程式から

```math
\frac{V}{N}=\frac{kT}{p}
```

であるため，式 (11) は圧力を用いて

```math
\boxed{
\begin{aligned}
\mu={}&-\int^T dT'\int^{T'}
\frac{f(T'')}{T''}\,dT''\\
&+kT\log\frac{p}{kT}
+\phi_0-kT\alpha
\end{aligned}
}
\tag{12}
```

とも表せる．

なお，ギブズ自由エネルギー $G$ は

```math
\boxed{G=N\mu}
\tag{13}
```

である．

以上により，与えられた定積熱容量 $C_V=Nf(T)$ と理想気体の状態方程式を用いて， $F,U,S,\mu$ の一般形が求められた．
積分の基準や定数の選び方によって式の見かけは変わるが，それらは熱力学的な基準の選択に対応するものである．


## 解説

### 積分定数の意味

熱容量 $C_V$ は，内部エネルギーの温度微分を決める量である．
したがって，熱容量だけから内部エネルギーの絶対値を一意に決めることはできず，エネルギーの基準に相当する定数が残る．
同様に，エントロピーにも基準の選択に対応する定数が残る．
修正版の $\phi_0$ や $\alpha$ は，こうした自由度を表すものである．

### 化学ポテンシャルの示強性

化学ポテンシャルが示強性であるという条件は，単に粒子数 $N$ に依存しないという意味ではない．
体積 $V$ と粒子数 $N$ を同じ倍率で増加させても，温度 $T$ と密度 $N/V$ を一定に保てば， $\mu$ は変化しないという意味である．
この性質によって，式 (6) に現れる $N$ 依存性が制限され，付加関数の形が決まる．

### 最終結果の確認

式 (8) の自由エネルギーは $N$ に比例する形で表されており，内部エネルギー $U$ ，エントロピー $S$ ，ギブズ自由エネルギー $G$ も示量性を満たす．
一方，化学ポテンシャル $\mu$ は温度と粒子数密度によって決まる示強性の量である．
これらの性質は，導出した式が理想気体の熱力学と整合していることを確認するうえで重要である．
