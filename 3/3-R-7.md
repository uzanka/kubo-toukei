# 演習問題【3-R-7】

## 解答

ある理想気体の定積熱容量 $C_v = Nf(T)$ が与えられているとき，自由エネルギー $F$ ，内部エネルギー $U$ ，エントロピー $S$ ，および化学ポテンシャル $\mu$ の形を求める．

### 1. エントロピー $S$ の決定

定積熱容量 $C_v$ とエントロピー $S$ の間には，以下の関係がある：

$$C_v = T \left( \frac{\partial S}{\partial T} \right)_V$$

これより，

$$\left( \frac{\partial S}{\partial T} \right)_V = \frac{C_v}{T} = \frac{Nf(T)}{T}$$

この式を $T$ について積分すると，

$$S(T, V, N) = \int^T \frac{C_v(T')}{T'} dT' + g_1(V, N) = N \int^T \frac{f(T')}{T'} dT' + g_1(V, N) \quad \cdots (1)$$

ここで， $g_1(V, N)$ は $T$ に依存しない積分定数（ $V$ と $N$ の関数）である．

### 2. ヘルムホルツ自由エネルギー $F$ の決定

ヘルムホルツ自由エネルギー $F$ とエントロピー $S$ の間には， $(\partial F/\partial T)_V = -S$ という関係がある．
これを $T$ について積分すると，

$$F(T, V, N) = -\int^T S(T', V, N) dT' + g_2(V, N)$$

式(1)を代入すると，

$$F = -\int^T \left[ N \int^{T'} \frac{f(T'')}{T''} dT'' + g_1(V, N) \right] dT' + g_2(V, N)$$

$$F = -N \int^T dT' \int^{T'} \frac{f(T'')}{T''} dT'' - T g_1(V, N) + g_2(V, N) \quad \cdots (2)$$

ここで， $g_2(V, N)$ は $T$ に依存しない積分定数である．

ここで，積分項について部分積分を行う．
$u = \int^{T'} \frac{f(T'')}{T''} dT''$ ， $dv = dT'$ とおくと ， $du = \frac{f(T')}{T'} dT'$ ， $v = T'$ であるから，

$$\int^T dT' \int^{T'} \frac{f(T'')}{T''} dT'' = \left[ T' \int^{T'} \frac{f(T'')}{T''} dT'' \right]^T - \int^T T' \frac{f(T')}{T'} dT'$$

$$= T \int^T \frac{f(T')}{T'} dT' - \int^T f(T') dT' \quad \cdots (3)$$

これを用いると，式(2)は以下のように書ける：

$$F = -N \left( T \int^T \frac{f(T')}{T'} dT' - \int^T f(T') dT' \right) - T g_1(V, N) + g_2(V, N)$$

### 3. 内部エネルギー $U$ の決定

内部エネルギー $U$ は $U = F + TS$ で与えられる．
式(1)と式(2)を代入すると，

$$U = \left[ -NT \int^T \frac{f(T')}{T'} dT' + N \int^T f(T') dT' - T g_1(V, N) + g_2(V, N) \right] + T \left[ N \int^T \frac{f(T')}{T'} dT' + g_1(V, N) \right]$$

$$U = N \int^T f(T') dT' + g_2(V, N) \quad \cdots (4)$$

### 4. 付加関数 $g_1, g_2$ の決定

理想気体の状態方程式 $p = NkT/V$ を用い， $(\partial F/\partial V)_T = -p$ という関係から $g_1, g_2$ を求める．
式(2)を $V$ で微分すると，

$$\left( \frac{\partial F}{\partial V} \right)_T = -T \frac{\partial g_1}{\partial V} + \frac{\partial g_2}{\partial V} = -\frac{NkT}{V}$$

これより，

$$\frac{\partial g_1}{\partial V} = \frac{Nk}{V}, \quad \frac{\partial g_2}{\partial V} = 0$$

これを積分すると，

$$g_1(V, N) = Nk \log V + k\phi_1(N), \quad g_2(V, N) = \phi_2(N) \quad \cdots (5)$$

ここで， $\phi_1(N), \phi_2(N)$ は $N$ のみの関数である．

### 5. 化学ポテンシャル $\mu$ の決定と $g_1, g_2$ の具体的な形

化学ポテンシャルは $\mu = (\partial F/\partial N)_{T, V}$ である．
式(2)を $N$ で微分すると，

$$\mu = -\int^T dT' \int^{T'} \frac{f(T'')}{T''} dT'' - T \frac{\partial g_1}{\partial N} + \frac{\partial g_2}{\partial N}$$

式(5)を代入して， $\frac{\partial g_1}{\partial N} = k \log V + k\frac{d\phi_1}{dN}$ ， $\frac{\partial g_2}{\partial N} = \frac{d\phi_2}{dN}$ とすると，

$$\mu = -\int^T dT' \int^{T'} \frac{f(T'')}{T''} dT'' - kT \log V - kT \frac{d\phi_1}{dN} + \frac{d\phi_2}{dN} \quad \cdots (6)$$

$\mu$ は示量性（intensive property）を持つ，すなわち $V/N$ だけの関数でなければならない．
式(6)を整理すると，

$$\mu = -\int^T dT' \int^{T'} \frac{f(T'')}{T''} dT'' - kT \left( \log V + \frac{d\phi_1}{dN} \right) + \frac{d\phi_2}{dN}$$

$\log V + \frac{d\phi_1}{dN} = \log(V/N) + \text{constant}$ となるためには，

$$\frac{d\phi_1}{dN} = -\log N + \alpha \quad (\alpha \text{ は定数})$$

が必要である．
これより，

$$\phi_1(N) = -N \log N + N + N\alpha$$

が得られる．
また， $\mu$ が $N$ に依存しないためには， $\frac{d\phi_2}{dN}$ が定数である必要がある．

$$\frac{d\phi_2}{dN} = \phi_0 \quad (\phi_0 \text{ は定数})$$

これより，

$$\phi_2(N) = N\phi_0$$

が得られる．

### 6. 最終的な結果

これらをすべて元の式に代入して整理すると，以下のようになる．

$$F = -\int^T dT' \int^{T'} \frac{C_V(T'')}{T''} dT'' - NkT \log \frac{V}{N} - NkT + N\phi_0 - NkT\alpha \quad \cdots (9)$$

$$U = \int^T C_V(T') dT' + N\phi_0 \quad \cdots (10)$$

$$S = \int^T \frac{C_V(T')}{T'} dT' + Nk \log \frac{V}{N} + Nk + Nk\alpha \quad \cdots (11)$$

$$\mu = -\int^T dT' \int^{T'} \frac{f(T'')}{T''} dT'' - kT \log \frac{V}{N} + \phi_0 - kT\alpha$$

$$= -\int^T dT' \int^{T'} \frac{f(T'')}{T''} dT'' + kT \log \frac{p}{kT} + \phi_0 - kT\alpha \quad \cdots (12)$$

$$G \equiv N\mu \quad \cdots (13)$$

## 解説

この問題では，与えられた熱容量の情報から，熱力学の基本的な変数（ $F, U, S, \mu$ ）をすべて導出することが求められました．

### 用いた熱力学の基本関係式

1.  **定積熱容量とエントロピーの関係**:
  $C_v = T \left(\frac{\partial S}{\partial T}\right)_V$ ．
  これは温度変化に伴うエントロピーの変化が熱容量によって決まることを示している．
2.  **ヘルムホルツ自由エネルギーの定義**:
  $F = U - TS$ ．
  また，温度変化による $F$ の変化はエントロピーを用いて $(\partial F/\partial T)_V = -S$ と表せる．
3.  **内部エネルギーと自由エネルギーの関係**:
  $U = F + TS$ ．
4.  **圧力と自由エネルギーの関係**:
  圧力は，体積変化に伴う自由エネルギーの減少として $p = -\left(\frac{\partial F}{\partial V}\right)_T$ と表せる．
5.  **化学ポテンシャル**:
  粒子数 $N$ の変化に伴う自由エネルギーの変化として $\mu = \left(\frac{\partial F}{\partial N}\right)_{T,V}$ と定義される．

### 解法のポイント

*   **積分定数 $g_1, g_2$ の扱い**:
    微分方程式を積分する際，定数は変数（ $T$ ）以外の変数（ $V, N$ ）の関数として現れる．
    これらを適切に設定し，物理的な拘束条件（理想気体の状態方程式や， $\mu$ が示量性を持つこと）を用いることで，具体的な形を決定していく．
*   **示量性と示強性**: 
    *   **示量性（Extensive property）**:
        系の大きさに比例する量（ $S, U, F, G$ など）．
    *   **示強性（Intensive property）**:
        系の大きさに依存しない量（ $T, p, \mu$ など）．
        化学ポテンシャル $\mu$ が $V/N$ だけの関数であるという条件は， $\mu$ が示強性を持つという物理的事実を数学的に表現したものである．
        これを利用することで，不定形だった $g_1, g_2$ の関数形を特定することができた．
*   **部分積分の活用**:
    複雑な二重積分を簡略化するために，数学的なテクニックである部分積分が非常に有効である．

このプロセスにより，熱容量という一つの熱力学的パラメータから，系の状態を記述する主要なすべての関数を系統的に導き出すことができた．
