# 演習問題【3-A-11】

## 解答

### (i) 断熱圧縮率と等温圧縮率の比

断熱圧縮率 $\kappa_S$ と等温圧縮率 $\kappa_T$ は，それぞれ

```math
\kappa_S=-\frac{1}{V}
\left(\frac{\partial V}{\partial p}\right)_S,
\qquad
\kappa_T=-\frac{1}{V}
\left(\frac{\partial V}{\partial p}\right)_T
```

と定義される．
ここで， $V$ は体積， $p$ は圧力， $S$ はエントロピーである．
添字 $S$ はエントロピー一定，添字 $T$ は温度一定の条件を表す．

これらの定義から，

```math
\frac{\kappa_S}{\kappa_T}
=
\frac{(\partial V/\partial p)_S}
{(\partial V/\partial p)_T}
```

である．

ここで，ヤコビアン

```math
\frac{\partial(x,y)}{\partial(u,v)}
=
\begin{vmatrix}
\displaystyle\frac{\partial x}{\partial u}
&
\displaystyle\frac{\partial x}{\partial v}\\[6pt]
\displaystyle\frac{\partial y}{\partial u}
&
\displaystyle\frac{\partial y}{\partial v}
\end{vmatrix}
```

を用いる．
ヤコビアンの性質より，

```math
\left(\frac{\partial V}{\partial p}\right)_S
=\frac{\partial(V,S)}{\partial(p,S)},
\qquad
\left(\frac{\partial V}{\partial p}\right)_T
=\frac{\partial(V,T)}{\partial(p,T)}
```

である．
したがって，

```math
\frac{\kappa_S}{\kappa_T}
=
\frac{\partial(V,S)/\partial(p,S)}
{\partial(V,T)/\partial(p,T)}
```

となる．

ヤコビアンの連鎖律

```math
\frac{\partial(x,y)}{\partial(u,v)}
=
\frac{\partial(x,y)}{\partial(a,b)}
\frac{\partial(a,b)}{\partial(u,v)}
```

を用いると，

```math
\frac{\partial(V,S)}{\partial(p,S)}
=
\frac{\partial(V,S)}{\partial(V,T)}
\frac{\partial(V,T)}{\partial(p,S)}
```

および

```math
\frac{\partial(V,T)}{\partial(p,T)}
=
\frac{\partial(V,T)}{\partial(p,S)}
\frac{\partial(p,S)}{\partial(p,T)}
```

が成り立つ．
これらを比の式に代入し，共通因子を約分すると，

```math
\frac{\kappa_S}{\kappa_T}
=
\frac{\partial(V,S)/\partial(V,T)}
{\partial(p,S)/\partial(p,T)}
```

となる．
ここで，

```math
\frac{\partial(V,S)}{\partial(V,T)}
=\left(\frac{\partial S}{\partial T}\right)_V,
\qquad
\frac{\partial(p,S)}{\partial(p,T)}
=\left(\frac{\partial S}{\partial T}\right)_p
```

であるから，

```math
\frac{\kappa_S}{\kappa_T}
=
\frac{(\partial S/\partial T)_V}
{(\partial S/\partial T)_p}
```

を得る．

定積比熱 $C_V$ と定圧比熱 $C_p$ は，それぞれ

```math
C_V=T\left(\frac{\partial S}{\partial T}\right)_V,
\qquad
C_p=T\left(\frac{\partial S}{\partial T}\right)_p
```

と表される．
よって，求める関係式は

```math
\boxed{
\frac{\kappa_S}{\kappa_T}=\frac{C_V}{C_p}
}
```

である．

### (ii) 式 (3.37b) の証明と圧縮率の大小関係

#### 1．一般的な不等式の証明

式 (3.37b)

```math
\left(\frac{\partial Y_i}{\partial y_i}\right)_{Y_k}
<
\left(\frac{\partial Y_i}{\partial y_i}\right)_{y_k}
\tag{3.37b}
```

を証明する．
ここで， $Y_i,Y_k$ は $y_i,y_k$ の関数であるとする．
以下では，偏微分が存在し，必要なヤコビアンが正則であると仮定する．

まず，ヤコビアンを用いると，

```math
\left(\frac{\partial Y_i}{\partial y_i}\right)_{Y_k}
=
\frac{\partial(Y_i,Y_k)}{\partial(y_i,Y_k)}
```

である．
さらに，ヤコビアンの連鎖律より，

```math
\frac{\partial(Y_i,Y_k)}{\partial(y_i,Y_k)}
=
\frac{
\partial(Y_i,Y_k)/\partial(y_i,y_k)
}{
\partial(y_i,Y_k)/\partial(y_i,y_k)
}
```

となる．
それぞれのヤコビアンを展開すると，

```math
\begin{aligned}
\left(\frac{\partial Y_i}{\partial y_i}\right)_{Y_k}
={}&
\left(\frac{\partial Y_i}{\partial y_i}\right)_{y_k}\\
&-
\frac{
\left(\frac{\partial Y_i}{\partial y_k}\right)_{y_i}
\left(\frac{\partial Y_k}{\partial y_i}\right)_{y_k}
}{
\left(\frac{\partial Y_k}{\partial y_k}\right)_{y_i}
}.
\end{aligned}
\tag{1}
```

次に，熱力学的な状態量の関係から，交差偏微分の対称性を導く．

熱力学ポテンシャル $U$ の全微分が

```math
dU=y_i\,dY_i+y_k\,dY_k+\cdots
```

と表されるとする．
ここで，

```math
\Phi=U-y_iY_i-y_kY_k
```

と定義すると，

```math
d\Phi=-Y_i\,dy_i-Y_k\,dy_k+\cdots
```

となる．
したがって，

```math
\left(\frac{\partial\Phi}{\partial y_i}\right)_{y_k}
=-Y_i,
\qquad
\left(\frac{\partial\Phi}{\partial y_k}\right)_{y_i}
=-Y_k
```

である．
混合二階偏微分の交換可能性から，

```math
\frac{\partial^2\Phi}{\partial y_k\partial y_i}
=
\frac{\partial^2\Phi}{\partial y_i\partial y_k}
```

が成り立つので，

```math
\boxed{
\left(\frac{\partial Y_i}{\partial y_k}\right)_{y_i}
=
\left(\frac{\partial Y_k}{\partial y_i}\right)_{y_k}
}
\tag{2}
```

を得る．

式 (2) を式 (1) に代入すると，

```math
\begin{aligned}
\left(\frac{\partial Y_i}{\partial y_i}\right)_{Y_k}
={}&
\left(\frac{\partial Y_i}{\partial y_i}\right)_{y_k}\\
&-
\frac{
\left[
\left(\frac{\partial Y_i}{\partial y_k}\right)_{y_i}
\right]^2
}{
\left(\frac{\partial Y_k}{\partial y_k}\right)_{y_i}
}.
\end{aligned}
\tag{3}
```

ここで，熱力学的に安定な系において

```math
\left(\frac{\partial Y_k}{\partial y_k}\right)_{y_i}>0
```

が成り立つとする．
分子は実数の二乗であるから，式 (3) の第2項は非負である．
よって，

```math
\boxed{
\left(\frac{\partial Y_i}{\partial y_i}\right)_{Y_k}
\leq
\left(\frac{\partial Y_i}{\partial y_i}\right)_{y_k}
}
```

が得られる．

特に，

```math
\left(\frac{\partial Y_i}{\partial y_k}\right)_{y_i}
\neq 0
```

であれば第2項は正であるため，厳密な不等式 (3.37b) が成立する．
交差偏微分がゼロの場合には等号が成立することに注意する必要がある．

#### 2．断熱圧縮率と等温圧縮率への適用

式 (3) において，

```math
Y_i=V,\qquad y_i=-p,\qquad
Y_k=S,\qquad y_k=T
```

と置く．
このとき，

```math
dU=(-p)\,dV+T\,dS
```

であるから，先ほどの熱力学ポテンシャルに関する関係が適用できる．

式 (3) は，

```math
\left(\frac{\partial V}{\partial(-p)}\right)_S
=
\left(\frac{\partial V}{\partial(-p)}\right)_T
-
\frac{
\left[(\partial V/\partial T)_p\right]^2
}{
(\partial S/\partial T)_p
}
```

となる．
ここで，

```math
\left(\frac{\partial V}{\partial(-p)}\right)_S
=-\left(\frac{\partial V}{\partial p}\right)_S
=V\kappa_S
```

および

```math
\left(\frac{\partial V}{\partial(-p)}\right)_T
=V\kappa_T
```

である．
また，

```math
\left(\frac{\partial S}{\partial T}\right)_p
=\frac{C_p}{T}
```

であるから，

```math
V\kappa_S
=
V\kappa_T
-\frac{T}{C_p}
\left(\frac{\partial V}{\partial T}\right)_p^2
```

となる．
両辺を $V$ で割ると，

```math
\boxed{
\kappa_S
=
\kappa_T
-\frac{T}{VC_p}
\left(\frac{\partial V}{\partial T}\right)_p^2
}
\tag{4}
```

を得る．

絶対温度 $T>0$ ，体積 $V>0$ ，定圧熱容量 $C_p>0$ であるため，式 (4) の減算項は非負である．
したがって，

```math
\boxed{
\kappa_S\leq\kappa_T
}
```

が成り立つ．
さらに，

```math
\left(\frac{\partial V}{\partial T}\right)_p\neq0
```

であれば減算項は正となり，

```math
\boxed{
\kappa_S<\kappa_T
}
```

が得られる．

したがって，断熱圧縮率は等温圧縮率以下であり，定圧での体積の温度依存性がゼロでない通常の気体では，断熱圧縮率の方が厳密に小さいのである．

### (iii) Le Chatelier–Braun の原理による物理的解釈

Le Chatelier–Braun の原理とは，平衡状態にある系に外部から変化を加えると，系はその変化の影響を弱める方向に応答するという原理である．

この原理を，ピストンで囲まれた気体の圧縮に適用する．
初期状態から体積を $\Delta V<0$ だけ減少させる場合を考える．
断熱圧縮率と等温圧縮率の定義より，微小変化に対して，

```math
\Delta p
=-\frac{\Delta V}{V\kappa}
```

と表される．

同じ体積変化 $\Delta V<0$ に対し，断熱圧縮の場合は

```math
(\Delta p)_S
=-\frac{\Delta V}{V\kappa_S}
```

であり，等温圧縮の場合は

```math
(\Delta p)_T
=-\frac{\Delta V}{V\kappa_T}
```

である．
ここで， $\kappa_S<\kappa_T$ であるから，

```math
\frac{1}{\kappa_S}>\frac{1}{\kappa_T}
```

となる．
また， $-\Delta V>0$ であるため，

```math
\boxed{
(\Delta p)_S>(\Delta p)_T
}
```

が得られる．
すなわち，同じ体積だけ圧縮したとき，断熱圧縮の方が圧力上昇は大きいのである．

この違いは，熱の移動が許されるかどうかによって説明できる．
断熱圧縮では，外部から気体に加えられた仕事によって内部エネルギーが増加し，通常は温度が上昇する．
その結果，圧縮による体積減少に加えて温度上昇も圧力を増加させる方向に働く．

一方，熱の移動が可能な等温圧縮では，圧縮による温度上昇を抑えるため，気体から外部へ熱が移動する．
この熱移動は温度上昇に伴う圧力増加を緩和するため，等温圧縮における圧力上昇は断熱圧縮の場合より小さくなる．

したがって，外部から加えた圧縮という変化に対して，その影響を弱める向きに熱移動が生じる．
これが Le Chatelier–Braun の原理の具体例である．
