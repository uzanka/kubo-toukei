# 演習問題【3-A-16】

## 解答

### 1. 容量性とオイラーの定理の利用

ヘルムホルツ自由エネルギー $F(T, V, N_1, N_2, \dots)$ は容量性（extensive property）の量である．
容量性の量とは，系のサイズ（体積 $V$ や粒子数 $N_j$ ）を $\alpha$ 倍に拡大したとき，その値も $\alpha$ 倍になる量のことである．
したがって，次のような関係式が成り立つ：

$$F(T, \alpha V, \alpha N_1, \alpha N_2, \dots) = \alpha F(T, V, N_1, N_2, \dots)$$

数学的には， $F$ は変数 $V, N_1, N_2, \dots$ に関して 1 次の同次関数（homogeneous function of degree 1）であるといえる．
このとき，「オイラーの定理（Euler's theorem）」を用いると，次のように記述できる：

$$F = V \left( \frac{\partial F}{\partial V} \right)_{T, \{N_j\}} + \sum_j N_j \left( \frac{\partial F}{\partial N_j} \right)_{T, V, \{N_{k \neq j}\}}$$

### 2. 熱力学的な変数の特定

ヘルムホルツ自由エネルギーの基本式（熱力学的基本関係式）は以下のように与えられる：

$$dF = -S dT - p dV + \sum_j \mu_j dN_j$$

ここで， $p$ は圧力， $S$ はエントロピー， $\mu_j$ は $j$ 種目の化学ポテンシャルである．
この式から，各偏微分係数は以下の熱力学量に対応していることがわかる：
- $\left( \frac{\partial F}{\partial V} \right)_{T, \{N_j\}} = -p$
- $\left( \frac{\partial F}{\partial N_j} \right)_{T, V, \{N_{k \neq j}\}} = \mu_j$

これらを先ほどのオイラーの定理の結果に代入すると，次の関係が得られる：

$$F = -pV + \sum_j N_j \mu_j$$

### 3. Gibbs-Duhem の関係の導出

次に，この関係式の両辺の全微分をとる．

左辺の微分は，基本式そのものである：

$$dF = -S dT - p dV + \sum_j \mu_j dN_j$$

右辺の微分は，積の微分公式を用いて次のように計算できる：

$$d\left( -pV + \sum_j N_j \mu_j \right) = -p dV - V dp + \sum_j ( \mu_j dN_j + N_j d\mu_j )$$

$$= -p dV - V dp + \sum_j \mu_j dN_j + \sum_j N_j d\mu_j$$

左辺と右辺を等置する：

$$-S dT - p dV + \sum_j \mu_j dN_j = -p dV - V dp + \sum_j \mu_j dN_j + \sum_j N_j d\mu_j$$

両辺から共通する項（ $-p dV$ および $\sum_j \mu_j dN_j$ ）を消去すると：

$$-S dT = -V dp + \sum_j N_j d\mu_j$$

整理すると，求める Gibbs-Duhem の関係式が得られる：

$$S dT - V dp + \sum_j N_j d\mu_j = 0$$

## 解説

この問題のポイントは，**「容量性（extensive property）」と「オイラーの定理」の関係**を理解することにある．

### 1.  容量性の数学的表現

熱力学において，温度 $T$ や圧力 $p$ は「強度変数（intensive property）」と呼ばれ，系のサイズに依存しない．
一方で，体積 $V$ や粒子数 $N$ ，自由エネルギー $F$ は「容量変数（extensive property）」と呼ばれ，系のサイズに比例する．
数学的には，これらをスケーリングしても形が変わらない性質を「同次性」と呼び，これを利用して複雑な関数をその偏微分（強度変数）の組み合わせで書き換えることができる．

### 2.  オイラーの定理の意味

オイラーの定理は，同次関数において「関数そのものの値」を「各変数の偏微分を用いた和」として表現できることを保証している．
熱力学では，これにより $F$ という複雑なエネルギー関数を，目に見える物理量である $p, V, \mu, N$ の単純な積の和として記述できる．

### 3.  Gibbs-Duhem 関係式の物理的意味

Gibbs-Duhem の関係式は，強度変数（ $T, p, \mu$ ）が互いに独立ではなく，一定の制約（この式で表される）の下で変化することを示している．
例えば，温度と圧力を勝手に自由に決めることはできず，それらは系の状態（エントロピーや組成）と密接に結びついていることを意味している．
