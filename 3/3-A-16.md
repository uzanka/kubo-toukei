# 演習問題【3-A-16】

## 解答

ヘルムホルツ自由エネルギー $F$ の容量性を利用してオイラーの定理を適用し，その結果を熱力学の基本式と比較することで，Gibbs-Duhem の関係式

```math
S\,dT-V\,dP+\sum_j N_j\,d\mu_j=0
```

を導く．

### 1．容量性とオイラーの定理

温度 $T$ ，体積 $V$ ，各種粒子数 $N_1,N_2,\ldots$ の関数として，ヘルムホルツ自由エネルギーを

```math
F=F(T,V,N_1,N_2,\ldots)
```

とする．
ヘルムホルツ自由エネルギーは容量性の量であり，系の温度 $T$ を一定に保ったまま体積と各種粒子数を同じ倍率 $\alpha$ で拡大すると，その値も $\alpha$ 倍になる．
したがって，

```math
F(T,\alpha V,\alpha N_1,\alpha N_2,\ldots)
=\alpha F(T,V,N_1,N_2,\ldots)
\tag{1}
```

が成り立つ．

式 (1) の両辺を $\alpha$ で微分する．
左辺には合成関数の微分を適用し，右辺を微分すると，

```math
\begin{aligned}
&V\left(\frac{\partial F}{\partial V}\right)_{T,N}
+\sum_j N_j
\left(\frac{\partial F}{\partial N_j}\right)_{T,V,N_{k\ne j}}\\
&\qquad=F(T,V,N_1,N_2,\ldots)
\end{aligned}
```

を得る．
ここで， $\alpha=1$ とした．
よって，

```math
F=
V\left(\frac{\partial F}{\partial V}\right)_{T,N}
+\sum_j N_j
\left(\frac{\partial F}{\partial N_j}\right)_{T,V,N_{k\ne j}}
\tag{2}
```

となる．
これは，容量性を持つ一次同次関数に対するオイラーの定理である．

### 2．熱力学の基本式を用いる

ヘルムホルツ自由エネルギーの定義は

```math
F=U-TS
```

である．
その全微分は

```math
dF=-S\,dT-P\,dV+\sum_j\mu_j\,dN_j
\tag{3}
```

と表される．
ここで， $S$ はエントロピー， $P$ は圧力， $\mu_j$ は $j$ 種粒子の化学ポテンシャルである．

式 (3) と $F=F(T,V,N_1,N_2,\ldots)$ の全微分を比較すると，

```math
\left(\frac{\partial F}{\partial V}\right)_{T,N}=-P
```

および

```math
\left(\frac{\partial F}{\partial N_j}\right)_{T,V,N_{k\ne j}}
=\mu_j
```

が得られる．
これらを式 (2) に代入すると，

```math
\boxed{
F=-PV+\sum_jN_j\mu_j
}
\tag{4}
```

となる．

### 3．Gibbs-Duhem の関係式を導く

式 (4) の両辺を全微分する．
左辺については式 (3) より，

```math
dF=-S\,dT-P\,dV+\sum_j\mu_j\,dN_j
\tag{5}
```

である．
一方，式 (4) の右辺を積の微分公式に従って微分すると，

```math
\begin{aligned}
dF
&=d\left(-PV+\sum_jN_j\mu_j\right)\\
&=-P\,dV-V\,dP
+\sum_j\left(\mu_j\,dN_j+N_j\,d\mu_j\right)\\
&=-P\,dV-V\,dP
+\sum_j\mu_j\,dN_j+\sum_jN_j\,d\mu_j
\end{aligned}
\tag{6}
```

となる．

式 (5) と式 (6) は同じ $dF$ を表すため，両者を等置すると，

```math
\begin{aligned}
-S\,dT-P\,dV+\sum_j\mu_j\,dN_j
={}&-P\,dV-V\,dP\\
&+\sum_j\mu_j\,dN_j+\sum_jN_j\,d\mu_j
\end{aligned}
```

を得る．
両辺に共通する項 $-P\,dV$ と $\sum_j\mu_j\,dN_j$ を消去すると，

```math
-S\,dT=-V\,dP+\sum_jN_j\,d\mu_j
```

となる．
両辺を移項して整理すれば，

```math
\boxed{
S\,dT-V\,dP+\sum_jN_j\,d\mu_j=0
}
```

を得る．
これが求める Gibbs-Duhem の関係式である．

## 解説

この導出の要点は，ヘルムホルツ自由エネルギーの容量性から式 (4) を得て，その全微分を熱力学の基本式と比較することである．

Gibbs-Duhem の関係式は，エントロピー $S$ ，体積 $V$ ，粒子数 $N_j$ に対応する強度変数である温度 $T$ ，圧力 $P$ ，化学ポテンシャル $\mu_j$ の微小変化の間に成り立つ制約を表している．
したがって，これらの強度変数をすべて独立に変化させることはできない．
