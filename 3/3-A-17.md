# 演習問題【3-A-17】

## 解答

熱力学第3法則とマクスウェルの関係式を用いて，熱膨張係数

```math
\alpha=\frac{1}{V}\left(\frac{\partial V}{\partial T}\right)_p
```

および圧力係数

```math
\left(\frac{\partial p}{\partial T}\right)_V
```

が $\to0$ でゼロに近づくことを示す．
ここでは，体積 $V$ が有限かつ正である一様な物質を考える．

### 1．マクスウェルの関係式

まず，ギブズ自由エネルギー $G=U-TS+pV$ の全微分は

```math
dG=-S\,dT+V\,dp
```

である．
したがって，

```math
S=-\left(\frac{\partial G}{\partial T}\right)_p,
\qquad
V=\left(\frac{\partial G}{\partial p}\right)_T
```

となる．
自由エネルギーの混合二階偏微分が等しいことから，

```math
\boxed{
\left(\frac{\partial V}{\partial T}\right)_p
=-\left(\frac{\partial S}{\partial p}\right)_T
}
\tag{1}
```

を得る．

次に，ヘルムホルツ自由エネルギー $F=U-TS$ の全微分は

```math
dF=-S\,dT-p\,dV
```

である．
よって，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_V,
\qquad
p=-\left(\frac{\partial F}{\partial V}\right)_T
```

であるから，同様に混合二階偏微分の等式を用いると，

```math
\boxed{
\left(\frac{\partial p}{\partial T}\right)_V
=\left(\frac{\partial S}{\partial V}\right)_T
}
\tag{2}
```

が得られる．
これらが本問で用いるマクスウェルの関係式である．

### 2．熱力学第3法則を用いた証明

熱力学第3法則によれば，一様な物質のエントロピー $S$ は，密度が有限である限り，温度 $T\to0$ で圧力や密度に依存しない一定値に近づく．
したがって，低温極限において，エントロピーの圧力および体積に関する偏微分は

```math
\lim_{T\to0}
\left(\frac{\partial S}{\partial p}\right)_T=0
```

および

```math
\lim_{T\to0}
\left(\frac{\partial S}{\partial V}\right)_T=0
```

となる．
ここでは，エントロピーとその偏微分が低温極限で十分滑らかに振る舞うことを前提としている．

まず，式 (1) により，

```math
\begin{aligned}
\lim_{T\to0}
\left(\frac{\partial V}{\partial T}\right)_p
&=-\lim_{T\to0}
\left(\frac{\partial S}{\partial p}\right)_T\\
&=0
\end{aligned}
```

を得る．
体積 $V$ は低温極限で有限かつ正であるため，

```math
\begin{aligned}
\lim_{T\to0}\alpha
&=\lim_{T\to0}
\frac{1}{V}\left(\frac{\partial V}{\partial T}\right)_p\\
&=0
\end{aligned}
```

となる．
よって，熱膨張係数は $T\to0$ でゼロに近づく．

次に，式 (2) により，

```math
\begin{aligned}
\lim_{T\to0}
\left(\frac{\partial p}{\partial T}\right)_V
&=\lim_{T\to0}
\left(\frac{\partial S}{\partial V}\right)_T\\
&=0
\end{aligned}
```

となる．
したがって，圧力係数も $T\to0$ でゼロに近づく．

以上より，

```math
\boxed{
\lim_{T\to0}
\frac{1}{V}\left(\frac{\partial V}{\partial T}\right)_p=0,
\qquad
\lim_{T\to0}
\left(\frac{\partial p}{\partial T}\right)_V=0
}
```

が示された．

### 3．別証：定圧熱容量を用いる方法

熱膨張係数に関する結論は，定圧熱容量 $C_p$ を用いても導くことができる．
エントロピーの低温極限の値を基準値として差し引き，その値をゼロとする場合，

```math
S(T,p)=\int_0^T\frac{C_p(T',p)}{T'}\,dT'
```

と表される．
両辺を圧力 $p$ で偏微分すると，

```math
\left(\frac{\partial S}{\partial p}\right)_T
=\int_0^T\frac{1}{T'}
\left(\frac{\partial C_p}{\partial p}\right)_{T'}dT'
```

となる．
ここで，マクスウェルの関係式 (1) より，

```math
-\left(\frac{\partial V}{\partial T}\right)_p
=\int_0^T\frac{1}{T'}
\left(\frac{\partial C_p}{\partial p}\right)_{T'}dT'
\tag{3}
```

である．
さらに，熱力学の関係式

```math
\left(\frac{\partial C_p}{\partial p}\right)_T
=-T\left(\frac{\partial^2 V}{\partial T^2}\right)_p
```

を式 (3) に代入すると，

```math
-\left(\frac{\partial V}{\partial T}\right)_p
=-\int_0^T
\left(\frac{\partial^2 V}{\partial T'^2}\right)_p dT'
```

を得る．
積分を実行すれば，

```math
-\left(\frac{\partial V}{\partial T}\right)_p
=-\left(\frac{\partial V}{\partial T}\right)_p
+\lim_{T\to0}\left(\frac{\partial V}{\partial T}\right)_p
```

となる．
したがって，

```math
\boxed{
\lim_{T\to0}\left(\frac{\partial V}{\partial T}\right)_p=0
}
```

が得られる．
よって，体積が有限かつ正であれば，熱膨張係数もゼロに近づく．
圧力係数についても，同様に定積熱容量を用いることで導出できる．

なお，この別証では，積分と偏微分の交換が可能であること，および必要な低温極限が存在することを仮定している．
