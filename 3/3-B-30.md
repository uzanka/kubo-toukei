# 演習問題【3-B-30】

## 解答

この問題では，温度によって性質（誘電率）が変わる物質を中に入れた蓄電器（コンデンサー）において，スイッチの状態（電圧が一定か，電荷が一定か）によって物質の「熱容量」がどのように変化するかを考える．

### 1. 基礎知識の整理

計算を始める前に，重要な概念を整理しておく．

* **誘電率 ( $\epsilon(T)$ )**:
  物質が電場に対してどの程度反応するかを示す値である．
  ここでは温度 $T$ によって値が変わる性質を考える．
* **電場 ( $E$ ) と電気変位 ( $D$ )**: 
    * $E$ は空間に存在する電場の強さである．
    * $D$ は，物質内の電荷の分布を含めた「電場的な効果」を表す量で， $D = \epsilon E$ という関係がある．
* **エントロピー ( $S$ ) と熱容量 ( $C$ )**:
    * エントロピー $S$ は系の乱雑さを表す量である．
    * 熱容量 $C$ は，温度を $1$ 度上げるのに必要な熱量であり，エントロピーの変化率を用いて $C = T \left( \frac{\partial S}{\partial T} \right)$ と定義される．
    * ここで，括弧内の $\left( \frac{\partial S}{\partial T} \right)$ は，「他の条件（電場 $E$ や電気変位 $D$ ）を一定に保ったまま」温度で微分することを意味する．

問題文から与えられたエントロピーの式は以下の通りである：

$$S(T, E) = S(T, 0) + \frac{V}{8\pi} \frac{d\epsilon}{dT} E^2 \quad \cdots (1)$$

ここで $V$ は誘電体の体積， $\frac{d\epsilon}{dT}$ は誘電率の温度変化率を表す．
$S(T, 0)$ は電場がないときのエントロピーである．

### 2. ケース(i)：スイッチを閉じている場合（電位 $\Phi$ が一定）

スイッチを閉じているときは，電池につながっているため，蓄電器の極板間の電位差（電圧） $\Phi$ が常に一定に保たれる．

平行平板蓄電器において，電位差 $\Phi$ と電場 $E$ ，極板間距離 $a$ の間には $E = \Phi/a$ という関係がある．
$\Phi$ と $a$ が一定なので，電場 $E_0 = \Phi/a$ も一定となる．

このとき，熱容量 $C_E$ は「電場 $E$ を一定に保ったまま」温度で微分して求める：

$$C_E = T \left( \frac{\partial S}{\partial T} \right)_E$$

式(1)を $T$ で微分する．
$E$ は一定なので，右辺の $E^2$ は定数として扱う．

$$\frac{\partial S}{\partial T} = \frac{d S(T, 0)}{d T} + \frac{V}{8\pi} \frac{d^2\epsilon}{dT^2} E_0^2$$

これに $T$ を掛けると，解答例の式(2)が得られる：

$$C_E = T \frac{d S(T, 0)}{d T} + \frac{V}{8\pi} T \frac{d^2\epsilon}{dT^2} E_0^2 = C_0(T) + \frac{V}{8\pi} T \frac{d^2\epsilon}{dT^2} E_0^2 \quad \cdots (2)$$

ここで $C_0(T) = T \frac{d S(T, 0)}{d T}$ は，電場がないとき（ $E=0$ ）の熱容量である．

### 3. ケース(ii)：スイッチを開いている場合（電気変位 $D$ が一定）

スイッチを一度閉じて電荷を蓄えた後，スイッチを開くと，極板に溜まった電荷は逃げることができなくなる．
これにより，物質内の電気変位 $D$ が一定に保たれる．

$D$ を一定に保ちながら温度を変える場合，誘電率 $\epsilon(T)$ が変わると，電場 $E$ も連動して変化する．
関係式 $D = \epsilon E$ より， $E = D/\epsilon$ である．

このときの熱容量 $C_D$ は，「電気変位 $D$ を一定に保ったまま」温度で微分して求める：

$$C_D = T \left( \frac{\partial S}{\partial T} \right)_D$$

式(1)を，条件 $D = \text{const.}$ のもとで $T$ で微分する．

$$S(T, D) = S(T, 0) + \frac{V}{8\pi} \frac{d\epsilon}{dT} E^2$$

ここで， $E^2 = (D/\epsilon)^2$ である．
積の微分法を用いると：

$$\frac{\partial S}{\partial T} = \frac{d S(T, 0)}{d T} + \frac{V}{8\pi} \frac{\partial}{\partial T} \left( \frac{d\epsilon}{dT} E^2 \right)$$

$$\frac{\partial S}{\partial T} = \frac{d S(T, 0)}{d T} + \frac{V}{8\pi} \left[ \frac{d^2\epsilon}{dT^2} E^2 + \frac{d\epsilon}{dT} \left( \frac{\partial E^2}{\partial T} \right)_D \right]$$

これに $T$ を掛けると，解答例の式(3)が得られる：

$$C_D = C_0(T) + \frac{V}{8\pi} T \frac{d^2\epsilon}{dT^2} E^2 + \frac{V}{8\pi} T \frac{d\epsilon}{dT} \left( \frac{\partial E^2}{\partial T} \right)_D \quad \cdots (3)$$

次に， $\left( \frac{\partial E^2}{\partial T} \right)_D$ を計算する．
$E^2 = D^2 \epsilon^{-2}$ なので，これを $T$ で微分すると（ $D$ は定数）：

$$\left( \frac{\partial E^2}{\partial T} \right)_D = D^2 \left( -2 \epsilon^{-3} \frac{d\epsilon}{dT} \right) = -\frac{2 D^2}{\epsilon^3} \frac{d\epsilon}{dT}$$

ここで $D = \epsilon E$ を代入すると：

$$\left( \frac{\partial E^2}{\partial T} \right)_D = -\frac{2 (\epsilon E)^2}{\epsilon^3} \frac{d\epsilon}{dT} = -\frac{2 E^2}{\epsilon} \frac{d\epsilon}{dT}$$

最後に，この結果を式(3)に代入して整理する．
式(3)の第3項は：

$$\frac{V}{8\pi} T \frac{d\epsilon}{dT} \left( -\frac{2 E^2}{\epsilon} \frac{d\epsilon}{dT} \right) = -\frac{V T}{4\pi} \frac{E^2}{\epsilon} \left( \frac{d\epsilon}{dT} \right)^2$$

これを用いて $C_D$ を書くと：

$$C_D = C_0(T) + \frac{V}{8\pi} T \frac{d^2\epsilon}{dT^2} E^2 - \frac{V T}{4\pi} \frac{E^2}{\epsilon} \left( \frac{d\epsilon}{dT} \right)^2$$

式(2)の $C_E = C_0(T) + \frac{V}{8\pi} T \frac{d^2\epsilon}{dT^2} E^2$ を利用すると：

$$C_D = C_E - \frac{V T}{4\pi} \frac{E^2}{\epsilon} \left( \frac{d\epsilon}{dT} \right)^2$$

$E^2 = D^2/\epsilon^2$ を代入して，最終的な式(4)が得られる：

$$C_D = C_E - \frac{VT}{4\pi} \frac{D^2}{\epsilon^3} \left( \frac{d\epsilon}{dT} \right)^2 \quad \cdots (4)$$

### 4. まとめ

* **スイッチを閉じているとき（電位一定）**: $C_E = C_0(T) + \frac{V}{8\pi} T \frac{d^2\epsilon}{dT^2} E_0^2$
* **スイッチを開いているとき（電荷一定）**: $C_D = C_E - \frac{VT}{4\pi} \frac{D^2}{\epsilon^3} \left( \frac{d\epsilon}{dT} \right)^2$

スイッチを開いた場合（ $D$ 一定），誘電率の変化に伴って電場が調整される効果により，熱容量はスイッチを閉じている場合よりも小さくなることがわかる．

## 解説

この問題のポイントは，「何が一定に保たれているか」によって，微分の対象が変わる点にある．

### 1.  熱力学的な制約の理解

*   電圧一定（スイッチ閉） $\rightarrow$ 電場 $E$ が一定 $\rightarrow$ 系の自由度は電場に依存しない．
*   電荷一定（スイッチ開） $\rightarrow$ 電気変位 $D$ が一定 $\rightarrow$ 温度が変わると $\epsilon$ が変わるため，電場 $E = D/\epsilon$ も変化してしまう．
この「電場の変化」がエントロピーの変化に寄与するため，熱容量に補正項が現れる．

### 2.  微分のテクニック

*   多変数関数 $S(T, E)$ を微分する際，変数を $E$ に固定するか $D$ に固定するかで，連鎖律（チェインルール）の使い方を使い分ける必要がある．
特に $\left( \frac{\partial E^2}{\partial T} \right)_D$ の計算は，物理的な制約を数学的に処理する上で非常に重要である．

### 3.  物理的な意味

*   式(4)のマイナス記号は，電荷が一定という制約が，温度変化に伴うエントロピーの増加を抑制する方向に働くことを示唆している．
