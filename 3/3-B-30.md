# 演習問題【3-B-30】

## 解答

### 1．基礎となるエントロピーの式

温度 $T$ に依存する誘電率 $\epsilon(T)$ をもつ誘電体を考える．
誘電体の体積 $V$ は一定である．
前問で得られた，電場 $E$ を指定した場合のエントロピーは，

```math
S(T,E)=S(T,0)+\frac{V}{8\pi}
\frac{d\epsilon}{dT}E^2
\tag{1}
```

である．
ここで $S(T,0)$ は，電場がゼロのときのエントロピーである．
また，電場 $E$ と電気変位 $D$ の間には，

```math
D=\epsilon E
\tag{2}
```

という関係がある．
以下では，式 (1) を用いて，スイッチの状態ごとに熱容量を求める．

熱容量は，温度を微小に変化させたときのエントロピーの変化率から，

```math
C=T\left(\frac{\partial S}{\partial T}\right)
```

と表される．
ただし，偏微分では，実験条件に応じて一定に保つ変数を指定する必要がある．

### 2．スイッチを閉じている場合

スイッチを閉じると，蓄電器は一定の起電力をもつ電池につながれる．
したがって，極板間の電位差 $\Phi$ は一定である．
極板間の距離を $a$ とすると，極板間の電場は

```math
E_0=\frac{\Phi}{a}
```

である．
電位差と極板間距離が一定なので，電場 $E_0$ も一定となる．

この条件での熱容量を $C_E$ とすると，

```math
C_E=T\left(\frac{\partial S}{\partial T}\right)_E
\tag{3}
```

である．
式 (1) を，電場 $E$ を一定に保って温度 $T$ で微分すると，

```math
\left(\frac{\partial S}{\partial T}\right)_E
=
\frac{dS(T,0)}{dT}
+\frac{V}{8\pi}\frac{d^2\epsilon}{dT^2}E_0^2
```

を得る．
ここで，

```math
C_0(T)=T\frac{dS(T,0)}{dT}
```

と定義する．
これは，電場がゼロのときの熱容量である．
両辺に $T$ を掛けると，

```math
\boxed{
C_E=C_0(T)+\frac{V}{8\pi}T
\frac{d^2\epsilon}{dT^2}E_0^2
}
\tag{4}
```

となる．
これが，スイッチを閉じて電場が一定に保たれる場合の熱容量である．

### 3．スイッチを開いている場合

#### 3.1　電気変位が一定になる理由

スイッチを一度閉じて蓄電器を充電した後，スイッチを開く場合を考える．
極板に蓄えられた電荷が外部へ漏れないならば，極板の電荷は一定に保たれる．
極板の面積も一定であるため，極板上の自由電荷の面密度も一定である．
したがって，この条件では電気変位 $D$ が一定となる．

一方，誘電率 $\epsilon(T)$ は温度に依存する．
そのため，式 (2) の関係

```math
E=\frac{D}{\epsilon}
\tag{5}
```

より，電気変位 $D$ が一定でも，温度が変化すれば電場 $E$ は変化する．
この点が，スイッチを閉じた場合との違いである．

#### 3.2　電気変位一定の熱容量

電気変位 $D$ を一定に保った場合の熱容量を $C_D$ とすると，

```math
C_D=T\left(\frac{\partial S}{\partial T}\right)_D
\tag{6}
```

である．
式 (1) を電気変位一定の条件で温度微分すると，

```math
\begin{aligned}
\left(\frac{\partial S}{\partial T}\right)_D
&=\frac{dS(T,0)}{dT}\\
&\quad+\frac{V}{8\pi}
\left[
\frac{d^2\epsilon}{dT^2}E^2
+\frac{d\epsilon}{dT}
\left(\frac{\partial E^2}{\partial T}\right)_D
\right].
\end{aligned}
\tag{7}
```

ここでは $E$ も温度に依存するため，積の微分を用いている．

次に，式 (5) より，

```math
E^2=\frac{D^2}{\epsilon^2}
```

である．
$D$ は一定なので，これを温度で微分すると，

```math
\begin{aligned}
\left(\frac{\partial E^2}{\partial T}\right)_D
&=\frac{\partial}{\partial T}
\left(\frac{D^2}{\epsilon^2}\right)\\
&=-\frac{2D^2}{\epsilon^3}\frac{d\epsilon}{dT}\\
&=-\frac{2E^2}{\epsilon}\frac{d\epsilon}{dT}.
\end{aligned}
\tag{8}
```

式 (8) を式 (7) に代入し，両辺に $T$ を掛けると，

```math
\begin{aligned}
C_D
&=C_0(T)+\frac{V}{8\pi}T
\frac{d^2\epsilon}{dT^2}E^2\\
&\quad-\frac{VT}{4\pi}
\frac{E^2}{\epsilon}
\left(\frac{d\epsilon}{dT}\right)^2.
\end{aligned}
\tag{9}
```

式 (4) の $C_E$ を用いれば，

```math
C_D=C_E-\frac{VT}{4\pi}
\frac{E^2}{\epsilon}
\left(\frac{d\epsilon}{dT}\right)^2
```

となる．
さらに， $E=D/\epsilon$ より $E^2=D^2/\epsilon^2$ であるから，

```math
\boxed{
C_D=C_E-\frac{VT}{4\pi}
\frac{D^2}{\epsilon^3}
\left(\frac{d\epsilon}{dT}\right)^2
}
\tag{10}
```

を得る．
これが，スイッチを開き，極板の電荷が保存される場合の熱容量である．

なお，最初から一度もスイッチを閉じておらず，蓄電器が充電されていない場合は $D=E=0$ である．
この場合，式 (1) より $S=S(T,0)$ となり，熱容量は $C_0(T)$ である．

### 4．結論と物理的意味

スイッチを閉じて電池につないでいる場合，電場 $E_0$ が一定であり，熱容量は

```math
\boxed{
C_E=C_0(T)+\frac{V}{8\pi}T
\frac{d^2\epsilon}{dT^2}E_0^2
}
```

である．

一方，充電後にスイッチを開き，極板の電荷が保存される場合，電気変位 $D$ が一定となり，熱容量は

```math
\boxed{
C_D=C_E-\frac{VT}{4\pi}
\frac{D^2}{\epsilon^3}
\left(\frac{d\epsilon}{dT}\right)^2
}
```

である．

誘電率 $\epsilon$ が正である通常の誘電体では，式 (10) の補正項はゼロ以下である．
したがって，同じ温度，同じ電場・電気変位の対応する状態において，

```math
C_D\leq C_E
```

が成立する．
特に，誘電率が温度に依存しない場合， $d\epsilon/dT=0$ となり，両者の熱容量は一致する．
