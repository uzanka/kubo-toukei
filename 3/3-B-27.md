# 演習問題【3-B-27】

## 解答

断熱消磁法によって絶対零度に到達できないことを，熱力学第3法則と断熱過程におけるエントロピーの変化から示す．

まず，ネルンストの熱定理によれば，温度 $T$ が絶対零度に近づくとき，エントロピー $S(T,H)$ は磁場 $H$ に依存しない極限値 $S_0$ に近づく．
エントロピーの基準を $S_0=0$ とする．

断熱消磁では磁場が $H_i$ から $0$ まで変化するため，この磁場範囲で低温極限が一様に成立するものとする．
すなわち，

```math
\boxed{
\lim_{T\to0}
\sup_{0\leq H\leq H_i}
|S(T,H)|=0
}
\tag{1}
```

を仮定する．

ここで，初期状態を温度 $T_i>0$ ，磁場 $H_i>0$ とする．
通常の熱力学的に安定な常磁性体では，定磁場熱容量

```math
C_H=T\left(\frac{\partial S}{\partial T}\right)_H
```

は非負であり，有限温度の範囲で正となる．
したがって，

```math
S_i=S(T_i,H_i)
=\int_0^{T_i}\frac{C_H(T,H_i)}{T}\,dT>0
\tag{2}
```

である．

### 1．可逆断熱消磁の場合

断熱過程では外部との熱の授受がない．
さらに，過程が可逆であれば，

```math
dS=\frac{\delta Q_{\mathrm{rev}}}{T}=0
```

となる．
したがって，過程全体でエントロピーは一定に保たれ，

```math
\boxed{
S(T,H)=S_i>0
}
\tag{3}
```

が成立する．

ここで，断熱消磁によって絶対零度に到達できると仮定する．
このとき，最終磁場を $H_f$ とすると，

```math
0\leq H_f\leq H_i
```

であり，最終状態は $T_f=0$ である．

しかし，式 (1) より，

```math
\lim_{T\to0}S(T,H)=0
```

である一方，式 (3) より，エントロピーは過程中ずっと $S_i>0$ である．
したがって，

```math
S_i=0
```

となるが，これは式 (2) に矛盾する．

よって，可逆断熱消磁によって絶対零度に到達することはできない．

### 2．不可逆断熱消磁の場合

不可逆な断熱過程では，熱力学第2法則によりエントロピーは減少しない．
したがって，

```math
\boxed{
S_f-S_i=S_{\mathrm{gen}}\geq0
}
```

となる．
ここで $S_{\mathrm{gen}}$ は過程中に生成されるエントロピーである．

式 (2) より $S_i>0$ であるから，

```math
S_f\geq S_i>0
```

となる．
一方，絶対零度では式 (1) より、

```math
S_f=0
```

でなければならない．
これは矛盾する．

したがって，不可逆断熱消磁によっても絶対零度に到達することはできない．

### 3．結論

可逆断熱過程ではエントロピーが一定に保たれ，不可逆断熱過程ではエントロピーが増加する．
いずれの場合も，有限の初期温度から出発した常磁性体の正のエントロピーを，断熱消磁によって絶対零度に対応する共通の極限値まで減少させることはできない．

よって，

```math
\boxed{
T_f>0
}
```

であり，**断熱消磁法によって有限の初期温度から絶対零度に到達することは不可能である．**
