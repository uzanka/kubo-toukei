# 演習問題【3-B-27】

## 解答

断熱消磁法によって $0\,\mathrm K$ に到達できないことを，熱力学第3法則と断熱過程におけるエントロピー一定の条件から示す．

### 1．熱力学第3法則と低温でのエントロピー

熱力学第3法則によれば，温度 $T$ が絶対零度に近づくとき，エントロピー $S(T,H)$ は磁場 $H$ に依存しない極限値に近づく．
エントロピーの基準を $S(0,H)=0$ とすれば，

```math
\lim_{T\to0}S(T,H)=0
```

である．
すなわち，異なる磁場に対するエントロピー曲線は， $T\to0$ で同じ極限値に近づく．

このことを，磁場が十分に小さい場合について，問題［20］の結果を用いて確認する．
磁化を $M=\chi_T H$ とすると，エントロピーは近似的に

```math
S(T,H)=S(T,0)
+\frac{1}{2}\frac{d\chi_T}{dT}H^2
```

と表される．

前問で示したように，常磁性体では

```math
\lim_{T\to0}\frac{\partial\chi_T}{\partial T}=0
```

である．
したがって，有限の磁場 $H$ に対して，

```math
\lim_{T\to0}\bigl[S(T,H)-S(T,0)\bigr]=0
```

となる．
よって，低温では磁場が異なっていてもエントロピーの差は消失する．

### 2．断熱消磁ではエントロピーが一定である

断熱消磁では，磁性体を熱浴から切り離して磁場を減少させる．
この過程が可逆であれば，エントロピーは一定に保たれる．
初期温度を $T_i>0$ ，初期磁場を $H_i$ とすると，

```math
S(T,H)=S(T_i,H_i)=S_i
```

が過程全体で成り立つ．
ここで，初期状態のエントロピーを $S_i>0$ とする．

磁場を $H\to0$ としていくと，最終的には

```math
S(T_f,0)=S_i
```

を満たす温度 $T_f$ に至る．
一方，熱力学第3法則より，

```math
\lim_{T\to0}S(T,0)=0
```

である．
したがって， $S_i>0$ である限り， $T_f=0$ では $S(T_f,0)=S_i$ を満たせない．
よって，

```math
\boxed{
T_f>0
}
```

である．

### 3．結論

断熱消磁ではエントロピーを一定に保ったまま磁場を減少させるが，熱力学第3法則により，絶対零度ではエントロピーは磁場によらない共通の極限値に近づく．有限の初期温度から出発した系のエントロピーが正である限り，磁場をゼロにしても温度は正の値にとどまる．

したがって， **断熱消磁法によって有限の初期温度から $0\,\mathrm K$ に到達することは不可能である** ．
