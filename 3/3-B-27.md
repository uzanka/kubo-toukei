# 演習問題【3-B-27】

## 解答

**1. 断熱消磁法の原理**

断熱消磁法は，磁性体の温度を極低温まで下げるための手法である．
このプロセスは大きく分けて以下の2つのステップで行われる．

- **等温磁化 (Isothermal magnetization)**:
  磁性体を熱浴（一定温度 $T_i$ の環境）に接触させた状態で，外部磁場 $H$ を $H_i$ から $H_f$ へ変化させる．
  磁場をかけるとスピンの向きが揃い，乱雑さ（エントロピー $S$ ）が減少するため，その分熱が放出される．
  この熱を熱浴に逃がすことで，温度を一定に保つ．
- **断熱消磁 (Adiabatic demagnetization)**:
  磁性体を熱浴から切り離し，断熱状態（外部との熱のやり取りがない状態）にする．
  この状態で外部磁場を減少させる．
  断熱かつ可逆的な変化であれば，エントロピーは一定 ( $S = \text{const.}$ ) に保たれる．
  磁場を下げるとスピンの乱雑さが増そうとするため，そのエネルギー源として温度 $T$ が低下する．

**2. エントロピーと熱力学第三法則**

熱力学第三法則によれば，絶対零度 ( $T = 0\text{K}$ ) に近づくとき，物質のエントロピー $S$ は磁場の有無にかかわらず一定の値（通常は 0）に近づく．
すなわち，

$$\lim_{T \rightarrow 0} S(T, H) = 0 \quad (\text{任意の } H \text{ に対して})$$

が成り立つ．

**3. エントロピーの展開と振る舞い**

常磁性体において，磁場 $H$ が十分に小さい場合，エントロピー $S(T, H)$ は次のように近似できる（問題[20]の結果より）：

$$S(T, H) \approx S(T, 0) + \frac{1}{2} \left( \frac{d\chi_T}{dT} \right) H^2$$

ここで， $\chi_T$ は等温磁化率である．

$T \rightarrow 0$ において，熱力学第三法則により $S(T, 0) \rightarrow 0$ となる．
また，多くの常磁性体において $d\chi_T/dT \rightarrow 0$ となるため，磁場 $H \neq 0$ の場合のエントロピー曲線も， $T \rightarrow 0$ では $H=0$ の曲線 ( $S(T, 0)$ ) に重なっていく．

**4. 結論：なぜ $0\text{K}$ に到達できないのか**

断熱消磁のプロセスでは，エントロピー $S$ が一定のまま変化する．
初期状態の温度が $T_i > 0$ であり，磁場が $H_i > 0$ であるとき，系が持つエントロピー $S_i = S(T_i, H_i)$ は正の値 ( $S_i > 0$ ) を持つ．

消磁によって磁場を $H \rightarrow 0$ としていったとき，エントロピー一定の条件 $S(T, H) = S_i$ を満たしながら温度 $T$ が変化する．
しかし，上述の通り $T \rightarrow 0$ では $S(T, H) \rightarrow 0$ となるため，正のエントロピー $S_i > 0$ を持ち続ける限り，温度 $T$ が $0\text{K}$ に達することはない．
エントロピー曲線が $H=0$ の曲線に収束していくため，一定のエントロピー $S_i$ を保つ曲線は，有限の温度 $T > 0$ において $H=0$ の曲線と交差する．

したがって，断熱消磁によって絶対零度 $0\text{K}$ に到達することは不可能である．

## 解説

この問題の核心は，「絶対零度ではエントロピーが 0 になる」という熱力学第三法則と，「断熱過程ではエントロピーが変化しない」という性質の組み合わせにある．

図をイメージすると分かりやすくなる．
縦軸をエントロピー $S$ ，横軸を温度 $T$ としたグラフを考える．
- $H=0$ のときの曲線は，原点 $(0, 0)$ を通るように $T=0$ に向かって下がっていく．
- $H \neq 0$ のときの曲線は，それよりも高い位置にあるが， $T$ が小さくなるにつれて $H=0$ の曲線に吸い寄せられるように近づいていく．

「断熱消磁」とは，グラフ上で「水平な線（一定のエントロピー $S = \text{const.}$ ）」を辿って，左方向（低温側）へ移動することに相当する．
もし，初期状態のエントロピーが少しでも正（ $S > 0$ ）であれば，水平な線を左へ辿っていっても，いつかは $H=0$ の曲線（つまり磁場がゼロの状態）とぶつかる．
そのぶつかった点の温度は $0\text{K}$ よりも高い位置になる．
$0\text{K}$ に到達するためには，グラフの原点 $(0, 0)$ を通る水平な線を辿らなければならないが，これは「最初からエントロピーが 0 である（＝すでに絶対零度である）」という状態を意味してしまい，冷却のプロセスとしては成立しない．

このように，熱力学的な制約によって，有限の手順で絶対零度に到達することはできないことが示されている．
