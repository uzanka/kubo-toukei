# 演習問題【3-A-9】

## 解答

断熱自由膨張では内部エネルギー $U$ が一定であり，Joule–Thomson 過程ではエンタルピー $H$ が一定である．
前問で得られた関係式

```math
\left(\frac{\partial S}{\partial V}\right)_U>0,
\qquad
\left(\frac{\partial S}{\partial p}\right)_H<0
```

を用いて，それぞれの過程におけるエントロピーの変化を調べる．

### （1）断熱自由膨張

断熱自由膨張では，気体は真空に向かって膨張するため，外部に仕事をせず，断熱条件から熱の授受もない．
したがって，熱力学第一法則より

```math
dU=dQ-dW=0
```

となり，内部エネルギー $U$ は一定である．

エントロピー $S$ の全微分は

```math
dS=
\left(\frac{\partial S}{\partial U}\right)_VdU
+\left(\frac{\partial S}{\partial V}\right)_UdV
```

である．
ここで $dU=0$ より，

```math
dS=\left(\frac{\partial S}{\partial V}\right)_UdV
```

となる．
前問の結果から

```math
\left(\frac{\partial S}{\partial V}\right)_U>0
```

であり，問題の設定では $dV>0$ であるから，

```math
dS>0
```

が得られる．
すなわち，断熱自由膨張ではエントロピーが増大するため，この過程は不可逆である．

### （2）Joule–Thomson 過程

Joule–Thomson 過程では，気体は多孔質の栓などを通過して高圧側から低圧側へ流れる．
装置が断熱され，定常流であり，運動エネルギーおよび位置エネルギーの変化を無視でき，軸仕事の授受もないとする．
このとき，定常流のエネルギー保存則より，栓の前後でエンタルピー $H$ は一定である．
したがって，

```math
dH=0
```

となる．

エントロピー $S$ の全微分は

```math
dS=
\left(\frac{\partial S}{\partial H}\right)_p dH
+\left(\frac{\partial S}{\partial p}\right)_Hdp
```

である．
ここで $dH=0$ より，

```math
dS=\left(\frac{\partial S}{\partial p}\right)_Hdp
```

となる．
前問の結果から

```math
\left(\frac{\partial S}{\partial p}\right)_H<0
```

であり，問題の設定では $dp<0$ であるから，

```math
dS>0
```

が得られる．
すなわち，Joule–Thomson 過程でもエントロピーが増大するため，この過程は不可逆である．

以上より，いずれの過程も断熱条件のもとでエントロピーが増大するため，熱力学第二法則によって不可逆過程であると結論される．
