# 演習問題【3-A-9】

## 解答

本問題では，2つの異なる断熱過程における不可逆性を，エントロピーの変化に着目して示す．
熱力学第二法則によれば，断熱過程においてエントロピーが増大する場合，その過程は不可逆である．

### 1. 断熱自由膨張の過程

**過程の定義と性質:**

断熱自由膨張とは，断熱された容器内において，ガスが外部（真空）に向かって膨張する過程である．
この過程では以下の性質を持つ．
- **断熱過程:** 容器が断熱されているため，外部との熱のやり取りはない（ $dQ = 0$ ）．
- **自由膨張:** 膨張先が真空であるため，ガスが外部に対して仕事を行うことはない（ $dW = 0$ ）．

**内部エネルギーの変化:**

熱力学第一法則 $dU = dQ - dW$ に，上記の性質を代入すると，

$$dU = 0 - 0 = 0$$

となり，内部エネルギー $U$ は変化しない（ $U = \text{const.}$ ）．

**エントロピーの変化:**

エントロピー $S$ の全微分は，内部エネルギー $U$ と体積 $V$ を用いて以下のように書ける．

$$dS = \left( \frac{\partial S}{\partial U} \right)_V dU + \left( \frac{\partial S}{\partial V} \right)_U dV$$

ここで $dU = 0$ であるため，

$$dS = \left( \frac{\partial S}{\partial V} \right)_U dV$$

となる．
熱力学の基本関係式 $dU = TdS - pdV$ より $dS = \frac{1}{T}dU + \frac{p}{T}dV$ であるから，

$$\left( \frac{\partial S}{\partial V} \right)_U = \frac{p}{T}$$

が得られる．
圧力 $p$ と絶対温度 $T$ は常に正であるため， $\left( \frac{\partial S}{\partial V} \right)_U > 0$ である．
問題の設定より $dV > 0$ であるから，

$$dS = \text{(正の定数)} \times dV > 0$$

となり，エントロピーは増大する．
したがって，この過程は不可逆である．

### 2. ジュール＝トムソン過程

**過程の定義と性質:**

ジュール＝トムソン過程とは，多孔質の栓などを通して，ガスが高圧から低圧へと断熱的に膨張する過程である．
定常流（流れが安定した状態）を仮定すると，以下の性質を持つ．
- **断熱過程:** 外部との熱のやり取りはない（ $dQ = 0$ ）．
- **定常流:** 流れのエネルギーバランスから，エンタルピー $H$ が一定に保たれる（ $dH = 0$ ）．

**エントロピーの変化:**

エントロピー $S$ の全微分は，エンタルピー $H$ と圧力 $p$ を用いて以下のように書ける．

$$dS = \left( \frac{\partial S}{\partial H} \right)_p dH + \left( \frac{\partial S}{\partial p} \right)_H dp$$

ここで $dH = 0$ であるため，

$$dS = \left( \frac{\partial S}{\partial p} \right)_H dp$$

となる．
熱力学の基本関係式 $dH = TdS + Vdp$ より $dS = \frac{1}{T}dH - \frac{V}{T}dp$ であるから，

$$\left( \frac{\partial S}{\partial p} \right)_H = -\frac{V}{T}$$

が得られる．
体積 $V$ と絶対温度 $T$ は常に正であるため， $\left( \frac{\partial S}{\partial p} \right)_H < 0$ である．
問題の設定より $dp < 0$ （減圧）であるから，

$$dS = \text{(負の定数)} \times dp = \text{(負)} \times \text{(負)} > 0$$

となり，エントロピーは増大する．
したがって，この過程も不可逆である．

## 解説

### なぜエントロピーが増えると不可逆なのか？

熱力学第二法則にはいくつかの表現があるが，最も直感的なものの一つが「孤立系（あるいは断熱系）におけるエントロピーは，不可逆変化が起こると必ず増大する」というものである．

- **可逆過程:** 系の状態が変化しても，その過程を完全に逆方向に辿って，系と外部の両方を元の状態に正確に戻せる理想的な過程．
このとき，エントロピーの変化は $dS = 0$ である．
- **不可逆過程:** 一度起こると，外部に何らかの影響を与えずに元の状態に戻すことができない現実的な過程．
このとき，断熱条件下ではエントロピーが増大（ $dS > 0$ ）する．

### 今回のケースのまとめ

1. **自由膨張:** ガスが真空に広がる際，エネルギーの散らばり（乱雑さ）が大きくなるため，エントロピーが増大する．
これは一度広がったガスが，何の外部操作もなく自発的に元の狭い容器に戻ることはない（＝不可逆である）ことと対応している．
2. **ジュール＝トムソン過程:** 狭い隙間を通り抜ける際，ガス分子が衝突したり，圧力勾配によってランダムな運動が強まったりすることで，エントロピーが増大する．

どちらの過程も，外部からエネルギー（仕事や熱）を与えずに「自然に」起こる変化であり，その過程で系の「乱雑さ（エントロピー）」が増しているため，元の状態に戻すには外部からエネルギーを投入しなければならず，不可逆といえる．
