# 例題【3-R-5】

## 解答

### 1．熱力学的安定条件

一様な閉じた体系が熱力学的に安定であるとする．
平衡状態の近傍における微小変化について，安定条件を

```math
\delta T\,\delta S-\delta p\,\delta V\ge 0
\tag{1}
```

と表す．
ここで， $T$ は温度， $S$ はエントロピー， $p$ は圧力， $V$ は体積である．

以下では，この条件とマクスウェルの関係式を用いて，定積熱容量および定圧熱容量の非負性，温度一定での体積の圧力依存性，さらに両熱容量の大小関係を導く．

### 2．定積熱容量の非負性と圧力の体積依存性

まず，温度 $T$ と体積 $V$ を独立変数に選ぶ．
エントロピー $S$ と圧力 $p$ は，それぞれ $S(T,V)$ ， $p(T,V)$ と表せる．
それらの微小変化は

```math
\delta S=
\left(\frac{\partial S}{\partial T}\right)_V
\delta T+
\left(\frac{\partial S}{\partial V}\right)_T
\delta V
\tag{2}
```

および

```math
\delta p=
\left(\frac{\partial p}{\partial T}\right)_V
\delta T+
\left(\frac{\partial p}{\partial V}\right)_T
\delta V
\tag{3}
```

である．
これらを安定条件 (1) に代入すると，

```math
\begin{aligned}
&\left(\frac{\partial S}{\partial T}\right)_V
\delta T^2\\
&+\left[
\left(\frac{\partial S}{\partial V}\right)_T
-\left(\frac{\partial p}{\partial T}\right)_V
\right]\delta T\delta V\\
&-\left(\frac{\partial p}{\partial V}\right)_T
\delta V^2\ge 0
\end{aligned}
\tag{4}
```

を得る．

ここで，ヘルムホルツ自由エネルギー $F=U-TS$ の微分は

```math
dF=-S\,dT-p\,dV
```

である．
$F$ の二階混合偏微分が等しいことから，マクスウェルの関係式

```math
\left(\frac{\partial S}{\partial V}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_V
\tag{5}
```

が成立する．
したがって，式 (4) の交差項は消え，

```math
\left(\frac{\partial S}{\partial T}\right)_V
\delta T^2
-\left(\frac{\partial p}{\partial V}\right)_T
\delta V^2\ge 0
\tag{6}
```

となる．

定積熱容量 $C_V$ は

```math
C_V
=T\left(\frac{\partial S}{\partial T}\right)_V
\tag{7}
```

と定義されるので，式 (6) は

```math
\frac{C_V}{T}\delta T^2
-\left(\frac{\partial p}{\partial V}\right)_T
\delta V^2\ge 0
\tag{8}
```

と書ける．

この不等式は，任意の微小変化 $\delta T,\delta V$ に対して成立しなければならない．
まず $\delta V=0$ とすると，

```math
\frac{C_V}{T}\delta T^2\ge 0
```

である．
絶対温度 $T>0$ であり， $\delta T$ は任意であるから，

```math
\boxed{
C_V\ge 0
}
\tag{9}
```

を得る．

次に $\delta T=0$ とすると，

```math
-\left(\frac{\partial p}{\partial V}\right)_T
\delta V^2\ge 0
```

となる．
したがって，

```math
\boxed{
\left(\frac{\partial p}{\partial V}\right)_T\le 0
}
\tag{10}
```

である．
つまり，温度一定では，体積を増加させたときに圧力が増加することはなく，圧力は体積に対して非増加である．

### 3．定圧熱容量の非負性と等温圧縮に対する体積の応答

次に，温度 $T$ と圧力 $p$ を独立変数に選ぶ．
エントロピー $S(T,p)$ と体積 $V(T,p)$ の微小変化は

```math
\delta S=
\left(\frac{\partial S}{\partial T}\right)_p
\delta T+
\left(\frac{\partial S}{\partial p}\right)_T
\delta p
\tag{11}
```

および

```math
\delta V=
\left(\frac{\partial V}{\partial T}\right)_p
\delta T+
\left(\frac{\partial V}{\partial p}\right)_T
\delta p
\tag{12}
```

である．
これらを式 (1) に代入すると，

```math
\begin{aligned}
&\left(\frac{\partial S}{\partial T}\right)_p
\delta T^2\\
&+\left[
\left(\frac{\partial S}{\partial p}\right)_T
-\left(\frac{\partial V}{\partial T}\right)_p
\right]\delta T\delta p\\
&-\left(\frac{\partial V}{\partial p}\right)_T
\delta p^2\ge 0
\end{aligned}
\tag{13}
```

を得る．

ここで，ギブズ自由エネルギー $G=U-TS+pV$ の微分は

```math
dG=-S\,dT+V\,dp
```

である．
これから得られるマクスウェルの関係式は

```math
\left(\frac{\partial S}{\partial p}\right)_T
=-\left(\frac{\partial V}{\partial T}\right)_p
\tag{14}
```

である．
式 (14) を式 (13) に代入すると，

```math
\left(\frac{\partial S}{\partial T}\right)_p
\delta T^2
-2\left(\frac{\partial V}{\partial T}\right)_p
\delta T\delta p
-\left(\frac{\partial V}{\partial p}\right)_T
\delta p^2\ge 0
\tag{15}
```

となる．

**ここで注意すべき点は，交差項が消えるわけではない** ということである．
交差項を含む二次形式全体が非負であることから，各変数を独立にゼロにすることで，二つの二次項の係数がそれぞれ非負であると分かる．
実際， $\delta p=0$ とすれば，

```math
\left(\frac{\partial S}{\partial T}\right)_p
\delta T^2\ge 0
```

である．
定圧熱容量の定義

```math
C_p=T\left(\frac{\partial S}{\partial T}\right)_p
\tag{16}
```

と $T>0$ より，

```math
\boxed{
C_p\ge 0
}
\tag{17}
```

を得る．

また， $\delta T=0$ とすれば，

```math
-\left(\frac{\partial V}{\partial p}\right)_T
\delta p^2\ge 0
```

であるから，

```math
\boxed{
\left(\frac{\partial V}{\partial p}\right)_T\le 0
}
\tag{18}
```

となる．
したがって，温度一定で圧力を増加させると，体積は局所的に増加しない．
圧縮率が正である通常の安定な物質では，体積は厳密に減少する．

### 4．定圧熱容量と定積熱容量の大小関係

最後に，

```math
C_p\ge C_V
```

を示す．
定義より，

```math
C_p=T\left(\frac{\partial S}{\partial T}\right)_p,
\qquad
C_V=T\left(\frac{\partial S}{\partial T}\right)_V
```

である．
したがって， $T>0$ より，

```math
C_p\ge C_V
\quad\Longleftrightarrow\quad
\left(\frac{\partial S}{\partial T}\right)_p
\ge
\left(\frac{\partial S}{\partial T}\right)_V
\tag{19}
```

を示せばよい．

ここで，ヤコビアンを用いて偏微分を変換する．
状態方程式 $p=p(T,V)$ によって局所的に変数変換できる，すなわち $(\partial p/\partial V)_T\ne0$ であるとする．
このとき，

```math
\begin{aligned}
\left(\frac{\partial S}{\partial T}\right)_p
&=
\frac{\partial(S,p)}{\partial(T,p)}\\
&=
\frac{\partial(S,p)}{\partial(T,V)}
\frac{\partial(T,V)}{\partial(T,p)}
\end{aligned}
\tag{20}
```

である．
ヤコビアンを展開すると，

```math
\frac{\partial(S,p)}{\partial(T,V)}
=
\left(\frac{\partial S}{\partial T}\right)_V
\left(\frac{\partial p}{\partial V}\right)_T
-
\left(\frac{\partial S}{\partial V}\right)_T
\left(\frac{\partial p}{\partial T}\right)_V
\tag{21}
```

となる．
また，

```math
\frac{\partial(T,V)}{\partial(T,p)}
=
\frac{1}{(\partial p/\partial V)_T}
\tag{22}
```

である．
式 (20)～(22) より，

```math
\begin{aligned}
\left(\frac{\partial S}{\partial T}\right)_p
&=
\left(\frac{\partial S}{\partial T}\right)_V\\
&\quad-
\left(\frac{\partial S}{\partial V}\right)_T
\frac{(\partial p/\partial T)_V}
{(\partial p/\partial V)_T}
\end{aligned}
\tag{23}
```

を得る．
ここで，式 (5) のマクスウェルの関係式

```math
\left(\frac{\partial S}{\partial V}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_V
```

を用いると，

```math
\begin{aligned}
\left(\frac{\partial S}{\partial T}\right)_p
&=
\left(\frac{\partial S}{\partial T}\right)_V
-\frac{\left[(\partial p/\partial T)_V\right]^2}
{(\partial p/\partial V)_T}
\end{aligned}
\tag{24}
```

となる．
式 (10) より $(\partial p/\partial V)_T\le0$ であり，さらに式 (20) の変数変換が可能であるため，ここでは $(\partial p/\partial V)_T<0$ である．
したがって，

```math
-\frac{\left[(\partial p/\partial T)_V\right]^2}
{(\partial p/\partial V)_T}\ge0
\tag{25}
```

である．
よって式 (24) から，

```math
\left(\frac{\partial S}{\partial T}\right)_p
\ge
\left(\frac{\partial S}{\partial T}\right)_V
```

が得られる．
両辺に正の温度 $T$ を掛けると，

```math
\boxed{
C_p\ge C_V
}
\tag{26}
```

となる．

### 5．結論

熱力学的安定条件とマクスウェルの関係式から，次の関係が導かれた．

```math
\boxed{
C_V\ge0,\qquad C_p\ge0
}
```

```math
\boxed{
\left(\frac{\partial V}{\partial p}\right)_T\le0
}
```

さらに，通常の安定な状態で状態変数の変換が可能であるとき，

```math
\boxed{
C_p\ge C_V
}
```

が成立する．
すなわち，一様な閉じた体系では，定積熱容量および定圧熱容量は負にならず，温度一定では圧力の増加に伴って体積は増加せず，定圧熱容量は定積熱容量以上である．
