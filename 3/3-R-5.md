# 例題【3-R-5】

## 解答

### 1．熱力学的安定条件と追加仮定

以下では，系を物質量および組成が一定の単純圧縮系とし，単一相の平衡状態を考える．また，温度 $T>0$ ，体積 $V>0$ とする．

内部エネルギーを

```math
U=U(S,V)
```

と表す．
基本関係式は

```math
dU=T\,dS-p\,dV
```

であるから，

```math
T=\left(\frac{\partial U}{\partial S}\right)_V,
\qquad
p=-\left(\frac{\partial U}{\partial V}\right)_S
```

となる．

熱力学的安定性を，内部エネルギーの局所的な厳密凸性として表す．
すなわち，内部エネルギーのヘッセ行列について，

```math
\boxed{
\begin{pmatrix}
U_{SS}&U_{SV}\\
U_{VS}&U_{VV}
\end{pmatrix}
\text{ は正定値}
}
\tag{1}
```

を仮定する．
ここで， $U$ は必要な二階偏微分が連続な関数とし， $U_{SV}=U_{VS}$ とする．

この仮定は，通常の安定な単一相の状態から臨界点などの限界的な状態を除いた，厳密に安定な平衡状態を対象とするものである．

式（1）から，

```math
U_{SS}>0
```

であるため，逆関数定理により，局所的にエントロピーを

```math
S=S(T,V)
```

と表すことができる．
したがって，以下では $T,V$ を独立変数として用いる．

また，有限の圧力変化について体積の減少を主張する場合には，その圧力変化に対応する状態が同一の滑らかな単一相の領域内にあり，式（1）がその領域全体で成立するものとする．

### 2．定積熱容量の非負性と等温圧力微分の符号

まず，内部エネルギーのヘッセ行列の正定値性から，

```math
\delta T\,\delta S-\delta p\,\delta V>0
\tag{2}
```

が，ゼロでない任意の微小変化に対して成立する．

実際，

```math
\delta T
=
\left(\frac{\partial T}{\partial S}\right)_V\delta S
+
\left(\frac{\partial T}{\partial V}\right)_S\delta V
```

および

```math
\delta p
=
\left(\frac{\partial p}{\partial S}\right)_V\delta S
+
\left(\frac{\partial p}{\partial V}\right)_S\delta V
```

であるから，

```math
\begin{aligned}
\delta T\,\delta S-\delta p\,\delta V
={}&U_{SS}(\delta S)^2\\
&+2U_{SV}\delta S\delta V
+U_{VV}(\delta V)^2
\end{aligned}
```

となる．
これは式（1）の正定値性によって正である．

一方，エントロピーと圧力を $T,V$ の関数として表すと，

```math
S=S(T,V),\qquad p=p(T,V)
```

であるから，

```math
\delta S=
\left(\frac{\partial S}{\partial T}\right)_V\delta T
+
\left(\frac{\partial S}{\partial V}\right)_T\delta V
\tag{3}
```

および

```math
\delta p=
\left(\frac{\partial p}{\partial T}\right)_V\delta T
+
\left(\frac{\partial p}{\partial V}\right)_T\delta V
\tag{4}
```

となる．

これらを式（2）に代入すると，

```math
\begin{aligned}
&
\left(\frac{\partial S}{\partial T}\right)_V\delta T^2\\
&+\left[
\left(\frac{\partial S}{\partial V}\right)_T
-\left(\frac{\partial p}{\partial T}\right)_V
\right]\delta T\delta V\\
&-\left(\frac{\partial p}{\partial V}\right)_T\delta V^2
>0
\end{aligned}
\tag{5}
```

を得る．

ここで，ヘルムホルツ自由エネルギー

```math
F=U-TS
```

の微分は，

```math
dF=-S\,dT-p\,dV
```

である．
二階混合偏微分の交換可能性から，マクスウェルの関係式

```math
\boxed{
\left(\frac{\partial S}{\partial V}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_V
}
\tag{6}
```

が得られる．

これを式（5）に代入すると，交差項が消え，

```math
\left(\frac{\partial S}{\partial T}\right)_V\delta T^2
-
\left(\frac{\partial p}{\partial V}\right)_T\delta V^2
>0
\tag{7}
```

となる．

定積熱容量の定義は，

```math
C_V=T\left(\frac{\partial S}{\partial T}\right)_V
```

であるから，

```math
\frac{C_V}{T}\delta T^2
-
\left(\frac{\partial p}{\partial V}\right)_T\delta V^2
>0
\tag{8}
```

となる．

まず， $\delta V=0$ ， $\delta T\neq0$ とすると，

```math
\frac{C_V}{T}\delta T^2>0
```

である．
$T>0$ より，

```math
\boxed{C_V>0}
\tag{9}
```

を得る．

次に， $\delta T=0$ ， $\delta V\neq0$ とすると，

```math
-\left(\frac{\partial p}{\partial V}\right)_T
\delta V^2>0
```

であるから，

```math
\boxed{
\left(\frac{\partial p}{\partial V}\right)_T<0
}
\tag{10}
```

となる．

したがって，厳密に安定な状態では，温度一定で圧力は体積に対して厳密に減少する．

### 3．温度一定で圧力を増加させたときの体積変化

式（10）より，

```math
\left(\frac{\partial p}{\partial V}\right)_T<0
```

である．
したがって，逆関数定理によって，局所的に体積を

```math
V=V(T,p)
```

と表すことができる．
逆関数の微分公式から，

```math
\left(\frac{\partial V}{\partial p}\right)_T
=
\frac{1}{
\left(\frac{\partial p}{\partial V}\right)_T
}
```

であるため，

```math
\boxed{
\left(\frac{\partial V}{\partial p}\right)_T<0
}
\tag{11}
```

を得る．

すなわち，温度一定で圧力を増加させると，体積は局所的に厳密に減少する．

さらに，この関係が対象とする圧力区間全体で成立するならば， $p_2>p_1$ に対して，

```math
\begin{aligned}
V(T,p_2)-V(T,p_1)
&=
\int_{p_1}^{p_2}
\left(\frac{\partial V}{\partial p}\right)_T dp\\
&<0
\end{aligned}
```

となる．
したがって，

```math
\boxed{
p_2>p_1
\quad\Longrightarrow\quad
V(T,p_2)<V(T,p_1)
}
\tag{12}
```

である．

よって，温度を一定にして圧力を増加させると，体積は必ず減少する．

### 4．定圧熱容量の非負性

式（10）によって，

```math
\left(\frac{\partial p}{\partial V}\right)_T<0
```

であるから，すでに示したとおり， $(T,p)$ を局所的な独立変数として用いることができる．

したがって，

```math
S=S(T,p),\qquad V=V(T,p)
```

と表せる．
それぞれの微小変化は，

```math
\delta S=
\left(\frac{\partial S}{\partial T}\right)_p\delta T
+
\left(\frac{\partial S}{\partial p}\right)_T\delta p
\tag{13}
```

および

```math
\delta V=
\left(\frac{\partial V}{\partial T}\right)_p\delta T
+
\left(\frac{\partial V}{\partial p}\right)_T\delta p
\tag{14}
```

である．

これらを安定条件（2）に代入すると，

```math
\begin{aligned}
&
\left(\frac{\partial S}{\partial T}\right)_p\delta T^2\\
&+\left[
\left(\frac{\partial S}{\partial p}\right)_T
-\left(\frac{\partial V}{\partial T}\right)_p
\right]\delta T\delta p\\
&-\left(\frac{\partial V}{\partial p}\right)_T\delta p^2
>0
\end{aligned}
\tag{15}
```

となる．

ここで，ギブズ自由エネルギー

```math
G=U-TS+pV
```

の微分は，

```math
dG=-S\,dT+V\,dp
```

である．
これから得られるマクスウェルの関係式は，

```math
\boxed{
\left(\frac{\partial S}{\partial p}\right)_T
=
-\left(\frac{\partial V}{\partial T}\right)_p
}
\tag{16}
```

である．

式（16）を式（15）に代入すると，

```math
\begin{aligned}
&
\left(\frac{\partial S}{\partial T}\right)_p\delta T^2\\
&-2\left(\frac{\partial V}{\partial T}\right)_p
\delta T\delta p\\
&-\left(\frac{\partial V}{\partial p}\right)_T\delta p^2
>0
\end{aligned}
\tag{17}
```

を得る．

この二次形式は，ゼロでない任意の $(\delta T,\delta p)$ に対して正である．
ここで， $\delta p=0$ ， $\delta T\neq0$ とすると，

```math
\left(\frac{\partial S}{\partial T}\right)_p
\delta T^2>0
```

となる．
定圧熱容量の定義

```math
C_p=T\left(\frac{\partial S}{\partial T}\right)_p
```

と $T>0$ より，

```math
\boxed{C_p>0}
\tag{18}
```

を得る．

したがって，定積熱容量および定圧熱容量は，ともに負にならない．

### 5．定圧熱容量と定積熱容量の大小関係

定義より，

```math
C_p=T\left(\frac{\partial S}{\partial T}\right)_p,
\qquad
C_V=T\left(\frac{\partial S}{\partial T}\right)_V
```

である．
$T>0$ なので，

```math
C_p\geq C_V
```

を示すには，

```math
\left(\frac{\partial S}{\partial T}\right)_p
\geq
\left(\frac{\partial S}{\partial T}\right)_V
\tag{19}
```

を示せばよい．

ここで，式（10）により，

```math
\left(\frac{\partial p}{\partial V}\right)_T<0
```

であるから，ヤコビアンを用いた変数変換が可能である．

ヤコビアンの連鎖則より，

```math
\begin{aligned}
\left(\frac{\partial S}{\partial T}\right)_p
&=
\frac{\partial(S,p)}{\partial(T,p)}\\
&=
\frac{\partial(S,p)}{\partial(T,V)}
\frac{\partial(T,V)}{\partial(T,p)}
\end{aligned}
\tag{20}
```

となる．

それぞれのヤコビアンを展開すると，

```math
\frac{\partial(S,p)}{\partial(T,V)}
=
\left(\frac{\partial S}{\partial T}\right)_V
\left(\frac{\partial p}{\partial V}\right)_T
-
\left(\frac{\partial S}{\partial V}\right)_T
\left(\frac{\partial p}{\partial T}\right)_V
\tag{21}
```

および，

```math
\frac{\partial(T,V)}{\partial(T,p)}
=
\frac{1}{
\left(\frac{\partial p}{\partial V}\right)_T
}
\tag{22}
```

である．

式（20）～（22）から，

```math
\begin{aligned}
\left(\frac{\partial S}{\partial T}\right)_p
&=
\left(\frac{\partial S}{\partial T}\right)_V\\
&\quad-
\left(\frac{\partial S}{\partial V}\right)_T
\frac{
\left(\frac{\partial p}{\partial T}\right)_V
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
\end{aligned}
\tag{23}
```

を得る．

ここで，式（6）のマクスウェルの関係式，

```math
\left(\frac{\partial S}{\partial V}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_V
```

を代入すると，

```math
\begin{aligned}
\left(\frac{\partial S}{\partial T}\right)_p
&=
\left(\frac{\partial S}{\partial T}\right)_V\\
&\quad-
\frac{
\left[
\left(\frac{\partial p}{\partial T}\right)_V
\right]^2
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
\end{aligned}
\tag{24}
```

となる．

式（10）より，

```math
\left(\frac{\partial p}{\partial V}\right)_T<0
```

であるから，

```math
-\frac{
\left[
\left(\frac{\partial p}{\partial T}\right)_V
\right]^2
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
\geq0
\tag{25}
```

である．

したがって，式（24）から，

```math
\left(\frac{\partial S}{\partial T}\right)_p
\geq
\left(\frac{\partial S}{\partial T}\right)_V
```

を得る．
両辺に $T>0$ を掛けると，

```math
\boxed{
C_p\geq C_V
}
\tag{26}
```

となる．

なお，式（24）から，両熱容量の差は，

```math
\boxed{
C_p-C_V
=
-T\frac{
\left[
\left(\frac{\partial p}{\partial T}\right)_V
\right]^2
}{
\left(\frac{\partial p}{\partial V}\right)_T
}
\geq0
}
\tag{27}
```

とも表せる．
等号が成立するのは，

```math
\left(\frac{\partial p}{\partial T}\right)_V=0
```

の場合である．

### 6．結論

厳密に安定な単純圧縮系の平衡状態において，内部エネルギーのヘッセ行列が正定値であることから，

```math
\boxed{
C_V>0,\qquad C_p>0
}
```

が導かれる．

また，

```math
\boxed{
\left(\frac{\partial p}{\partial V}\right)_T<0
}
```

であるため，温度一定で圧力を増加させると体積は厳密に減少する．
さらに，

```math
\boxed{
C_p\geq C_V
}
```

が成立する．

したがって，定積熱容量および定圧熱容量は負にならず，温度一定で圧力を増加させると体積は減少し，定圧熱容量は定積熱容量より小さくならない．
