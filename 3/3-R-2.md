# 例題【3-R-2】

## 解答

示すべき関係式は

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_{T,N}+p
=T\left(\frac{\partial p}{\partial T}\right)_{V,N}
=-C_V\left(\frac{\partial T}{\partial V}\right)_{S,N}
}
```

である．
この式を二つの等式に分けて証明する．
ここで， $N$ は粒子数であり，添字は偏微分の際に一定に保つ物理量を表す．

### 1．第1の等式の証明

まず，内部エネルギー $U$ の基本関係式から出発する．
単純な圧縮性系では，

```math
dU=T\,dS-p\,dV+\mu\,dN
\tag{1}
```

が成り立つ．
ここで， $T$ は絶対温度， $S$ はエントロピー， $p$ は圧力， $\mu$ は化学ポテンシャルである．

粒子数 $N$ を一定に保つと $dN=0$ であるから，式（1）は

```math
dU=T\,dS-p\,dV
\tag{2}
```

となる．
温度 $T$ と粒子数 $N$ を一定に保って体積 $V$ を変化させると，式（2）から

```math
\left(\frac{\partial U}{\partial V}\right)_{T,N}
=T\left(\frac{\partial S}{\partial V}\right)_{T,N}-p
\tag{3}
```

を得る．
したがって，

```math
\left(\frac{\partial U}{\partial V}\right)_{T,N}+p
=T\left(\frac{\partial S}{\partial V}\right)_{T,N}
\tag{4}
```

である．

次に，Maxwell の関係式を用いる．
その根拠を確認するため，Helmholtz 自由エネルギー $F$ を

```math
F=U-TS
\tag{5}
```

と定義する．
その全微分は，式（1）を用いると

```math
\begin{aligned}
dF
&=dU-T\,dS-S\,dT\\
&=-S\,dT-p\,dV+\mu\,dN
\end{aligned}
\tag{6}
```

となる．
よって， $T,V,N$ を独立変数とみなせば，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_{V,N},
\qquad
p=-\left(\frac{\partial F}{\partial V}\right)_{T,N}
\tag{7}
```

である．

$F$ の二階混合偏微分が連続であれば，微分の順序を交換できる．
したがって，

```math
\begin{aligned}
\left(\frac{\partial S}{\partial V}\right)_{T,N}
&=-\frac{\partial}{\partial V}
\left(\frac{\partial F}{\partial T}\right)_{V,N}\\
&=-\frac{\partial^2 F}{\partial V\,\partial T}\\
&=-\frac{\partial}{\partial T}
\left(\frac{\partial F}{\partial V}\right)_{T,N}\\
&=\left(\frac{\partial p}{\partial T}\right)_{V,N}
\end{aligned}
\tag{8}
```

を得る．
これが，この問題で用いる Maxwell の関係式である．

式（8）を式（4）に代入すると，

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_{T,N}+p
=T\left(\frac{\partial p}{\partial T}\right)_{V,N}
}
\tag{9}
```

となり，第1の等式が証明された．

### 2．第2の等式の証明

次に，

```math
T\left(\frac{\partial p}{\partial T}\right)_{V,N}
=-C_V\left(\frac{\partial T}{\partial V}\right)_{S,N}
\tag{10}
```

を証明する．
第1の証明で得た Maxwell の関係式より，

```math
\left(\frac{\partial p}{\partial T}\right)_{V,N}
=\left(\frac{\partial S}{\partial V}\right)_{T,N}
\tag{11}
```

である．
したがって，式（10）を示すには，

```math
T\left(\frac{\partial S}{\partial V}\right)_{T,N}
=-C_V\left(\frac{\partial T}{\partial V}\right)_{S,N}
\tag{12}
```

を証明すればよい．

エントロピー $S$ を $T,V,N$ の関数とみなすと，その全微分は

```math
dS=
\left(\frac{\partial S}{\partial T}\right)_{V,N}dT
+
\left(\frac{\partial S}{\partial V}\right)_{T,N}dV
\tag{13}
```

である．
ここで，粒子数 $N$ を一定に保ちながらエントロピー $S$ も一定に保つ変化を考える．
このとき $dS=0$ なので，

```math
0=
\left(\frac{\partial S}{\partial T}\right)_{V,N}dT
+
\left(\frac{\partial S}{\partial V}\right)_{T,N}dV
\tag{14}
```

となる．
式（14）を $dV$ で割り，整理すると，

```math
\left(\frac{\partial T}{\partial V}\right)_{S,N}
=-\frac{
\left(\frac{\partial S}{\partial V}\right)_{T,N}
}{
\left(\frac{\partial S}{\partial T}\right)_{V,N}
}
\tag{15}
```

を得る．

一方，定積熱容量 $C_V$ は，粒子数一定のもとで

```math
C_V=\left(\frac{\partial U}{\partial T}\right)_{V,N}
\tag{16}
```

と定義される．
体積一定かつ粒子数一定では，式（2）より $dU=T\,dS$ であるから，

```math
C_V=T\left(\frac{\partial S}{\partial T}\right)_{V,N}
\tag{17}
```

が成り立つ．
したがって，

```math
\left(\frac{\partial S}{\partial T}\right)_{V,N}
=\frac{C_V}{T}
\tag{18}
```

である．

式（18）を式（15）に代入すると，

```math
\begin{aligned}
\left(\frac{\partial T}{\partial V}\right)_{S,N}
&=-\frac{
\left(\frac{\partial S}{\partial V}\right)_{T,N}
}{C_V/T}\\
&=-\frac{T}{C_V}
\left(\frac{\partial S}{\partial V}\right)_{T,N}
\end{aligned}
\tag{19}
```

となる．
両辺に $-C_V$ を掛ければ，

```math
-C_V\left(\frac{\partial T}{\partial V}\right)_{S,N}
=T\left(\frac{\partial S}{\partial V}\right)_{T,N}
\tag{20}
```

を得る．
さらに，式（11）の Maxwell の関係式を代入すると，

```math
\boxed{
T\left(\frac{\partial p}{\partial T}\right)_{V,N}
=-C_V\left(\frac{\partial T}{\partial V}\right)_{S,N}
}
\tag{21}
```

となり，第2の等式も証明された．

### 結論

式（9）と式（21）を合わせると，

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_{T,N}+p
=T\left(\frac{\partial p}{\partial T}\right)_{V,N}
=-C_V\left(\frac{\partial T}{\partial V}\right)_{S,N}
}
```

が得られる．
以上で証明は完了である．

この導出では，第1の等式に内部エネルギーの基本関係式と Maxwell の関係式を用い，第2の等式に同じ Maxwell の関係式，定積熱容量の定義，および一定エントロピー条件を用いた．
したがって，解答例と同じ熱力学的な方法で証明されている．
