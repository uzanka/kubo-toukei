# 例題【2-R-5】

## 解答

### 1．初期状態と混合後の状態

気体1，気体2は，それぞれ $n_1$ mol， $n_2$ mol の理想気体であり，初めは圧力 $p$ ，温度 $T$ のもとで，体積 $V_1$ ， $V_2$ の容器に別々に入っている．
理想気体の状態方程式 $pV=nRT$ より，

```math
V_1=\frac{n_1RT}{p},\qquad
V_2=\frac{n_2RT}{p}
```

である．

隔壁を取り除いて気体を混合すると，圧力と温度は変化しないという条件から，混合後の全体積 $V$ は

```math
\begin{aligned}
V&=V_1+V_2\\
&=\frac{(n_1+n_2)RT}{p}
\end{aligned}
```

となる．

### 2．可逆的な分離過程を考える

気体の混合は不可逆過程であるが，エントロピー $S$ は状態量であり，その変化は初期状態と終状態のみによって決まる．
したがって，実際の混合過程を直接計算する代わりに，混合後の状態から初めの分離状態へ戻す可逆過程を考えればよい．
混合過程と分離過程は始状態と終状態が逆であるため，

```math
\Delta S_{\mathrm{混合}}
=-\Delta S_{\mathrm{分離}}
```

が成り立つ．

そこで，解答例と同様に，気体1だけを通す半透壁と，気体2だけを通す半透壁を用いて，混合気体を分離することを考える．

混合気体中で気体1，気体2が及ぼす分圧をそれぞれ $p_1$ ， $p_2$ とすると，ダルトンの分圧の法則より，

```math
p=p_1+p_2
```

である．
また，問題文の条件から，分圧はモル比に比例するため，

```math
p_1=p\frac{n_1}{n_1+n_2},\qquad
p_2=p\frac{n_2}{n_1+n_2}
```

となる．

気体1だけを通す半透壁で囲まれた箱を考えると，その壁には気体1の分圧 $p_1$ が内側から作用する．
一方，気体1を通さない外側の気体2も，壁に反対向きの圧力 $p_2$ を及ぼす．
したがって，箱の壁に作用する圧力の差は，気体1の分圧を差し引いた分だけとなる．
この関係を利用すれば，半透壁で囲まれた箱を引き抜く際に，気体の圧力による正味の仕事を生じさせずに分離できる．
気体2についても同様である．

この分離操作では，系を断熱し，仕事の出入りもないように行う．
熱力学第一法則より内部エネルギーは変化せず，理想気体の内部エネルギーは温度のみに依存するため，温度も変化しない．
また，この分離操作は仕事を伴わないので，エントロピー変化はゼロである．

したがって，エントロピー変化を求めるうえで必要なのは，分離した気体1，気体2を，それぞれ体積 $V$ から元の体積 $V_1$ ， $V_2$ まで等温可逆的に圧縮する過程である．

### 3．等温可逆圧縮によるエントロピー変化

理想気体の内部エネルギーは温度のみに依存するため，温度 $T$ が一定の等温過程では，

```math
dU=0
```

である．
ここで，系が外部にする仕事を正とする熱力学第一法則

```math
dU=d'Q-p\,dV
```

を用いると，

```math
d'Q=p\,dV
```

となる．
ここで， $d'Q$ は気体が吸収する微小な熱量である．

エントロピーの定義より，可逆過程では

```math
dS=\frac{d'Q_{\mathrm{rev}}}{T}
```

であるため，

```math
dS=\frac{p\,dV}{T}
```

を得る．
さらに，理想気体の状態方程式 $pV=nRT$ より $p=nRT/V$ を代入すると，

```math
dS=nR\frac{dV}{V}
```

となる．

この式を体積 $V$ から $V_i$ まで積分すると，

```math
\begin{aligned}
\Delta S_i
&=\int_V^{V_i}n_iR\frac{dV}{V}\\
&=n_iR\log\frac{V_i}{V}
\end{aligned}
```

が得られる．
したがって，気体1，気体2のエントロピー変化はそれぞれ，

```math
\Delta S_1=n_1R\log\frac{V_1}{V}
```

```math
\Delta S_2=n_2R\log\frac{V_2}{V}
```

である．
ここでは圧縮であるため $V_i<V$ であり，それぞれのエントロピー変化は負となる．

分離過程全体のエントロピー変化は，これらの和であるから，

```math
\begin{aligned}
\Delta S_{\mathrm{分離}}
&=\Delta S_1+\Delta S_2\\
&=n_1R\log\frac{V_1}{V}
+n_2R\log\frac{V_2}{V}
\end{aligned}
```

となる．

### 4．混合によるエントロピー増加

混合過程のエントロピー変化は，分離過程のエントロピー変化の符号を反転させたものである．
したがって，

```math
\begin{aligned}
\Delta S_{\mathrm{混合}}
&=-\Delta S_{\mathrm{分離}}\\
&=-R\left(
n_1\log\frac{V_1}{V}
+n_2\log\frac{V_2}{V}
\right)
\end{aligned}
```

となる．

ここで，初期状態と混合後の状態の体積を表す式から，

```math
\frac{V_1}{V}
=\frac{n_1RT/p}{(n_1+n_2)RT/p}
=\frac{n_1}{n_1+n_2}
```

および

```math
\frac{V_2}{V}
=\frac{n_2RT/p}{(n_1+n_2)RT/p}
=\frac{n_2}{n_1+n_2}
```

である．
これらを代入すると，

```math
\boxed{
\Delta S
=-R\left(
n_1\log\frac{n_1}{n_1+n_2}
+n_2\log\frac{n_2}{n_1+n_2}
\right)
}
```

となる．
これは示すべき式 (1) である．

なお， $n_1/(n_1+n_2)$ ， $n_2/(n_1+n_2)$ はいずれも $0$ と $1$ の間にあるため，それらの対数は負である．
よって，上式のエントロピー増加は正となる．以上で証明された．
