# 例題【2-R-5】

## 解答

異なる2種類の理想気体を考える．
混合前には，気体1が物質量 $n_1$ ，体積 $V_1$ ，気体2が物質量 $n_2$ ，体積 $V_2$ を占め，両者は隔壁によって分離されているものとする．
両気体の初期圧力は $p$ ，初期温度は $T$ である．

隔壁を取り除いて混合させる．容器は剛体であり，外壁は移動しないものとする．
したがって，混合後の全体積は，

```math
V=V_1+V_2
```

である．
また，問題文の条件より，混合前後で温度と全圧は変化しない．

以下では， $\ln$ を自然対数とする．

### 1．混合前後の状態と分圧

混合前の各気体について，理想気体の状態方程式より，

```math
pV_1=n_1RT,\qquad
pV_2=n_2RT
```

である．
したがって，

```math
V_1=\frac{n_1RT}{p},\qquad
V_2=\frac{n_2RT}{p}
```

となる．
よって，混合後の全体積は，

```math
V=V_1+V_2
=\frac{(n_1+n_2)RT}{p}
```

である．

混合後，各成分は容器全体に分布する．
気体1，2の分圧をそれぞれ $p_1,p_2$ とする．
理想気体混合物では，各成分は他成分との相互作用を無視できる独立な理想気体として扱われ，それぞれの分圧について状態方程式が成立する．
これは Gibbs–Dalton の法則に対応する．

したがって，

```math
p_1V=n_1RT,\qquad
p_2V=n_2RT
```

である．
これらに混合後の全体積を代入すると，

```math
p_1=\frac{n_1}{n_1+n_2}p,\qquad
p_2=\frac{n_2}{n_1+n_2}p
```

を得る．
よって，

```math
p_1+p_2=p
```

となり，全圧が混合前後で変化しないという条件と整合する．

### 2．各成分のエントロピー変化

理想気体の物質量 $n_i$ に対するエントロピーの微分形は，

```math
dS_i
=n_i\frac{C_{V,i}(T)}{T}\,dT
+n_iR\frac{dV}{V}
```

である．
ここで， $C_{V,i}(T)$ は気体 $i$ の定積モル熱容量であり，温度依存性を許している．

この式を初期状態から最終状態まで積分すると，

```math
\Delta S_i
=n_i\int_{T_i}^{T_f}
\frac{C_{V,i}(T)}{T}\,dT
+n_iR\ln\frac{V_f}{V_i}
```

となる．

今回，混合前後で温度は変化しないので，

```math
T_i=T_f=T
```

である．
したがって，

```math
\int_T^T\frac{C_{V,i}(T)}{T}\,dT=0
```

となる．

また，混合前には気体 $i$ は体積 $V_i$ を占め，混合後には容器全体の体積 $V$ に分布するため，

```math
V_f=V
```

である．
よって，各成分のエントロピー変化は，

```math
\Delta S_i=n_iR\ln\frac{V}{V_i}
```

となる．

さらに，混合前後の各成分について状態方程式を用いると，

```math
pV_i=n_iRT,\qquad
p_iV=n_iRT
```

である．
したがって，

```math
\frac{V}{V_i}=\frac{p}{p_i}
```

となる．
これをエントロピー変化の式に代入すれば，

```math
\boxed{
\Delta S_i=n_iR\ln\frac{p}{p_i}
}
```

を得る．

### 3．混合物全体のエントロピー変化

理想気体混合物では，各成分間の相互作用を無視でき，各成分のエントロピーを加算できる．したがって，全エントロピー変化は，

```math
\Delta S=\Delta S_1+\Delta S_2
```

である．
よって，

```math
\Delta S
=n_1R\ln\frac{p}{p_1}
+n_2R\ln\frac{p}{p_2}
```

となる．

ここで，分圧の関係，

```math
p_1=\frac{n_1}{n_1+n_2}p,\qquad
p_2=\frac{n_2}{n_1+n_2}p
```

を代入すると，

```math
\begin{aligned}
\Delta S
&=n_1R\ln\frac{n_1+n_2}{n_1}
+n_2R\ln\frac{n_1+n_2}{n_2}\\[4pt]
&=-R\left(
n_1\ln\frac{n_1}{n_1+n_2}
+n_2\ln\frac{n_2}{n_1+n_2}
\right).
\end{aligned}
```

したがって，求めるエントロピー増加は，

```math
\boxed{
\Delta S
=-R\left(
n_1\ln\frac{n_1}{n_1+n_2}
+n_2\ln\frac{n_2}{n_1+n_2}
\right)
}
```

である．

### 補足

この導出では，実際の混合過程を可逆過程と仮定していない．
エントロピーは状態量であるため，混合前後の状態からエントロピー変化を求めている．

また，異なる種類の理想気体を混合する場合には，各成分を区別できるため，それぞれの成分のエントロピーを加算する．
一方，同一種類の気体を混合する場合には，この式で表される混合エントロピー増加は生じない．
