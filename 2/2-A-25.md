# 演習問題【2-A-25】

## 解答

### 1. 自由膨張における温度変化の導出

Gay-Lussac（ゲイ＝リュサック）の実験における「自由膨張」とは，断熱された容器内の気体が，隣接する空間が真空である状態へと膨張する過程を指す．

この過程において，以下の2つの条件が重要である．
1.  **断熱過程であること** ：
  外部との熱のやり取りがないため，熱力学第一法則より，内部エネルギーの変化 $\Delta U$ は，外部からなされた仕事 $W$ と吸収した熱 $Q$ を用いて $\Delta U = Q + W$ と書ける．
  断熱なので $Q = 0$ であり，真空への膨張なので外部へする仕事（および外部からされる仕事）は $W = 0$ である．
  したがって，内部エネルギーは変化せず，一定に保たれる（ $U = \text{const.}$ ）．
2.  **不可逆過程であること** ：
  真空への自由膨張は，平衡状態に戻る際に自然なプロセスとして進むため，不可逆な過程である．

内部エネルギー $U$ は温度 $T$ と体積 $V$ の関数 $U(T, V)$ であるから，その全微分は次のように書ける．

$$dU = \left(\frac{\partial U}{\partial T}\right)_V dT + \left(\frac{\partial U}{\partial V}\right)_T dV$$

等内部エネルギー過程（ $dU = 0$ ）において，体積の変化 $dV$ に対する温度の変化 $dT$ を求めるため，上式を整理すると：

$$0 = \left(\frac{\partial U}{\partial T}\right)_V dT + \left(\frac{\partial U}{\partial V}\right)_T dV$$

$$\left(\frac{\partial T}{\partial V}\right)_U = -\frac{\left(\frac{\partial U}{\partial V}\right)_T}{\left(\frac{\partial U}{\partial T}\right)_V} \quad \cdots (\text{A})$$

ここで，定積比熱 $C_V$ は次のように定義される．

$$C_V = \left(\frac{\partial U}{\partial T}\right)_V$$

次に，分子の $\left(\frac{\partial U}{\partial V}\right)_T$ を求めるために，熱力学の基本関係式 $dU = TdS - pdV$ を用いる．

$$\left(\frac{\partial U}{\partial V}\right)_T = T \left(\frac{\partial S}{\partial V}\right)_T - p$$

ここで，マクスウェルの関係式 $\left(\frac{\partial S}{\partial V}\right)_T = \left(\frac{\partial p}{\partial T}\right)_V$ を用いると，

$$\left(\frac{\partial U}{\partial V}\right)_T = T \left(\frac{\partial p}{\partial T}\right)_V - p$$

これらを式 (A) に代入すると，求める公式が得られる．

```math
\left(\frac{\partial T}{\partial V}\right)_U = -\frac{T\left(\frac{\partial p}{\partial T}\right)_V - p}{C_V} = \frac{1}{C_V} \left\{ p - T \left(\frac{\partial p}{\partial T}\right)_V \right\}
```

以上により，自由膨張における温度変化の公式が導かれた．

## 解説

### 自由膨張と内部エネルギー

通常の膨張（例えばピストンを押す膨張）では，気体は外部に対して仕事をするため，そのエネルギー源として内部エネルギーを消費し，温度が下がる．
しかし， **自由膨張** の場合は，膨張先が真空であるため，気体が押し出すべき対象が存在しない．
そのため，気体は仕事をせず，エネルギーを消費することもないため，理想気体であれば温度は変化しない．

### 実在気体の場合

理想気体では $p = \frac{RT}{V}$ なので， $\left(\frac{\partial p}{\partial T}\right)_V = \frac{R}{V}$ となる．
これを公式に代入すると：

```math
\left(\frac{\partial T}{\partial V}\right)_U = \frac{1}{C_V} \left\{ \frac{RT}{V} - T \left(\frac{R}{V}\right) \right\} = 0
```

となり，理想気体では温度変化がゼロであることがわかる．

しかし，実在気体の場合，分子間力（引力や斥力）が存在するため， $\left(\frac{\partial p}{\partial T}\right)_V$ は $\frac{R}{V}$ とは一致しない．
そのため，分子間力の性質によって，自由膨張に伴って温度が上がったり下がったりすることがある．
- **引力が支配的な場合**：
  膨張によって分子が離れる際に引力に抗う必要があり，エネルギーを消費して温度が下がる．
- **斥力が支配的な場合**：
  膨張によって分子間の反発が弱まり，エネルギーが放出されるような効果が生じて温度が上がることがある．
