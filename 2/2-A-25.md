# 演習問題【2-A-25】

## 解答

### 1．自由膨張では内部エネルギーが一定となる

Gay–Lussac の実験では，断熱された容器内の気体を真空中へ自由膨張させ，温度変化を測定する．
自由膨張とは，気体が真空へ広がる過程であり，気体が外部に対して膨張仕事をしないことが特徴である．

熱力学第一法則を

```math
\Delta U=Q+W_{\mathrm{on}}
```

と表す．
ここで， $U$ は内部エネルギー， $Q$ は気体が受け取る熱量， $W_{\mathrm{on}}$ は外部が気体に対して行う仕事である．

この実験では，容器が断熱されているため，

```math
Q=0
```

である．
また，膨張先は真空であるため，気体は外部を押して仕事をする必要がなく，

```math
W_{\mathrm{on}}=0
```

である．
したがって，

```math
\Delta U=0
```

となり，内部エネルギーは初期状態と最終状態で等しい．
すなわち，

```math
\boxed{
U=\text{一定}
}
```

である．

ただし，自由膨張は不可逆過程であり，その途中では気体が一様な平衡状態にあるとは限らない．
以下では，内部エネルギーが等しい近接した平衡状態の間で，温度と体積の関係を求める．

### 2．内部エネルギー一定の条件から温度変化を求める

内部エネルギー $U$ は，温度 $T$ と体積 $V$ の関数 $U(T,V)$ である．
したがって，全微分は

```math
dU=
\left(\frac{\partial U}{\partial T}\right)_V dT
+
\left(\frac{\partial U}{\partial V}\right)_T dV
```

と書ける．

自由膨張では内部エネルギーが一定であるため， $dU=0$ である．
よって，

```math
0=
\left(\frac{\partial U}{\partial T}\right)_V dT
+
\left(\frac{\partial U}{\partial V}\right)_T dV
```

となる．
これを $dT$ について整理すると，

```math
\left(\frac{\partial T}{\partial V}\right)_U
=
-\frac{
\left(\frac{\partial U}{\partial V}\right)_T
}{
\left(\frac{\partial U}{\partial T}\right)_V
}
\tag{1}
```

を得る．

ここで，定積熱容量 $C_V$ を

```math
C_V=
\left(\frac{\partial U}{\partial T}\right)_V
```

と定義する．
これは，体積を一定に保ったまま温度を変化させたとき，内部エネルギーがどの程度変化するかを表す量である．
以下では， $U$ ， $V$ ， $C_V$ は同じ一定量の気体についての量とする．

式 (1) は，

```math
\left(\frac{\partial T}{\partial V}\right)_U
=
-\frac{1}{C_V}
\left(\frac{\partial U}{\partial V}\right)_T
\tag{2}
```

となる．
したがって，次に $(\partial U/\partial V)_T$ を求めればよい．

### 3．マクスウェルの関係式を用いる

単純な圧縮性物質の内部エネルギーについて，熱力学の基本関係式

```math
dU=T\,dS-p\,dV
```

が成り立つ．
ここで， $S$ はエントロピー， $p$ は圧力である．
温度 $T$ を一定に保ったとき，

```math
\left(\frac{\partial U}{\partial V}\right)_T
=
T\left(\frac{\partial S}{\partial V}\right)_T-p
\tag{3}
```

となる．

さらに，マクスウェルの関係式

```math
\left(\frac{\partial S}{\partial V}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_V
\tag{4}
```

を利用する．
この関係式は，ヘルムホルツ自由エネルギー $F=U-TS$ の全微分

```math
dF=-S\,dT-p\,dV
```

における混合二階偏微分の順序を入れ替えられることから導かれる．

式 (4) を式 (3) に代入すると，

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_T
=
T\left(\frac{\partial p}{\partial T}\right)_V-p
}
\tag{5}
```

を得る．

これを式 (2) に代入すれば，

```math
\begin{aligned}
\left(\frac{\partial T}{\partial V}\right)_U
&=-\frac{1}{C_V}
\left[
T\left(\frac{\partial p}{\partial T}\right)_V-p
\right]\\
&=\frac{1}{C_V}
\left[
p-T\left(\frac{\partial p}{\partial T}\right)_V
\right]
\end{aligned}
```

となる．
したがって，求める公式は

```math
\boxed{
\left(\frac{\partial T}{\partial V}\right)_U
=
\frac{1}{C_V}
\left[
p-T\left(\frac{\partial p}{\partial T}\right)_V
\right]
}
```

である．

体積が $V$ から $V+dV$ に微小変化するときの温度変化は，この式に $dV$ を掛けて，

```math
\boxed{
dT=
\frac{1}{C_V}
\left[
p-T\left(\frac{\partial p}{\partial T}\right)_V
\right]dV
}
```

と表される．
ここで，右辺の $p$ ， $T$ ， $C_V$ ，および偏微分は，変化の前の平衡状態で評価する量である．
これが求める公式である．

### 4．理想気体と実在気体の違い

理想気体では，物質量を $n$ ，気体定数を $R$ とすると，状態方程式は

```math
pV=nRT
```

である．
これを温度 $T$ について偏微分すると，

```math
\left(\frac{\partial p}{\partial T}\right)_V
=\frac{nR}{V}
```

となる．
一方，状態方程式から $p=nRT/V$ であるため，

```math
p-T\left(\frac{\partial p}{\partial T}\right)_V
=
\frac{nRT}{V}-T\frac{nR}{V}=0
```

である．
したがって，

```math
\boxed{
dT=0
}
```

となる．
すなわち，理想気体では自由膨張しても温度は変化しない．
これは，理想気体の内部エネルギーが温度だけで決まり，体積に依存しないことと一致する．

一方，実在気体では分子間相互作用などのために，状態方程式が理想気体の式からずれる．
その結果，

```math
p-T\left(\frac{\partial p}{\partial T}\right)_V
```

がゼロとは限らず，自由膨張に伴って温度が変化することがある．
定積熱容量 $C_V>0$ かつ $dV>0$ の場合，この量が正なら温度は上昇し，負なら温度は低下する．
したがって，温度変化の向きは，気体の状態方程式を用いて判断できるのである．
