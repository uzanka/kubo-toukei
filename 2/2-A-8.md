# 演習問題【2-A-8】

## 解答

### 1. 過程の物理的性質の解析

まず，この過程（真空への断熱膨張，あるいは自由膨張）における熱力学的な変化を整理する．

- **断熱過程であるため** : 外部との熱のやり取りはない．
  したがって，系が吸収または放出する熱量は $Q = 0$ である．
- **真空への膨張であるため** : 膨張する先に抵抗（圧力）がない．
  したがって，系が外部に対して行う仕事は $W = 0$ である．

熱力学第一法則 $\Delta U = Q - W$（あるいは $dU = d'Q - d'W$ ）に，これらを代入すると，

$$dU = 0 - 0 = 0$$

となる．
つまり，この過程において系の内部エネルギーは変化しない．

理想気体において，内部エネルギー $U$ は温度 $T$ のみの関数である（ $dU = nC_v dT$ ）．
内部エネルギーが変化しないということは，温度も変化しないことを意味する．

$$dU = nC_v^0 dT = 0 \implies dT = 0 \implies T = \text{constant}$$

したがって，この膨張過程の前後で温度は $T_1 = T_2 = T$ と一定である．

### 2. エントロピー変化の計算

理想気体のエントロピー $S$ は，温度 $T$ ，体積 $V$ ，物質量 $n$ を用いて次のように表される（前問の結果より）．

$$S(T, V, n) = n \left( C_v^0 \log T + R \log \frac{V}{n} + S_0 \right)$$

この式を用いて，体積 $V_1$ から $V_2$ への変化に伴うエントロピー変化 $\Delta S$ を計算する．

$$\Delta S = S(T, V_2, n) - S(T, V_1, n)$$

$$\Delta S = n \left( C_v^0 \log T + R \log \frac{V_2}{n} + S_0 \right) - n \left( C_v^0 \log T + R \log \frac{V_1}{n} + S_0 \right)$$

共通する項（ $n C_v^0 \log T$ および $n S_0$ ）を差し引くと，

$$\Delta S = nR \log \frac{V_2}{n} - nR \log \frac{V_1}{n}$$

となる．
対数の性質 $\log A - \log B = \log(A/B)$ を用いると，

$$\Delta S = nR \log \left( \frac{V_2/n}{V_1/n} \right) = nR \log \left( \frac{V_2}{V_1} \right)$$

が得られる．

### 3. 不可逆性の証明

問題の条件より，膨張しているため $V_2 > V_1$ である．
したがって， $\frac{V_2}{V_1} > 1$ であり，自然対数 $\log(V_2/V_1)$ は正の値をとる．
物質量 $n$ および気体定数 $R$ も正であるため，

$$\Delta S = nR \log \left( \frac{V_2}{V_1} \right) > 0$$

となる．

熱力学第二法則によれば，断熱系において，エントロピーが増大する過程は **不可逆過程** である．
本過程は断熱的であり，かつエントロピーが増大しているため，この過程は不可逆過程であることが示された．

## 解説

### 1. 真空への断熱膨張（自由膨張）

通常，気体が膨張するときは外部に対して仕事をするが，相手が「真空」である場合，押し返す圧力がないため，気体は外部に対して仕事をすることができない（ $W=0$ ）．
また，断熱であるため熱の出入りもない（ $Q=0$ ）．
このため，エネルギーの出入りがないまま体積だけが増えるという，特殊な現象が起こる．

### 2. エントロピーが増大する理由

エントロピーは「状態の数（微視的な乱雑さ）」と深く関わっている．
体積が $V_1$ から $V_2$ へと大きくなると，気体分子が動き回れる空間が広がる．
これは，分子が取り得る配置のパターン（微視的な状態の数）が劇的に増えることを意味する．
「狭い部屋にいた分子が，広い部屋に広がった」状態は，自然界において非常に起こりやすい（確率が高い）状態であり，その逆（広い部屋の分子が勝手に狭い部屋に集まる）は，確率的にほぼ起こり得ない．
この「確率的な一方向性」が，エントロピーの増大と不可逆性の正体である．

### 3. 準静的過程との違い

もし，この膨張が「ゆっくりとした（準静的な）断熱膨張」であれば，気体は外部へ仕事をし，温度が下がる．
その場合，体積が増えることによるエントロピーの増加と，温度が下がることでエントロピーが減少する効果が釣り合い，全体のエントロピー変化はゼロ（可逆）になる．
しかし，今回の「真空への膨張」は一瞬で，かつ仕事も行われないため，温度が変わらずに体積だけが増えることになり，結果としてエントロピーが正の方向に増大してしまう．
