# 演習問題【2-A-8】

## 解答

理想気体が体積 $V_1$ の状態から真空中に断熱膨張し，体積 $V_2$ の状態になる過程を考える．
ここで，物質量を $n$ ，気体定数を $R$ ，定積モル熱容量を $C_v^0$ とする．
また， $V_2>V_1$ である．

### 1．熱力学第1法則から温度の変化を求める

まず，真空への断熱膨張における熱量と仕事を考える．

断熱過程では系と外部との間に熱の授受がないため，系が受け取る熱量 $Q$ は

```math
Q=0
```

である．
また，膨張先は真空であり，気体を押し返す外圧が存在しない．
したがって，気体が外部にする仕事 $W$ も

```math
W=0
```

となる．

熱力学第1法則は，内部エネルギーの変化を $\Delta U$ とすると，

```math
\Delta U=Q-W
```

と表される．
ここに $Q=0$ ， $W=0$ を代入すると，

```math
\Delta U=0-0=0
```

を得る．
すなわち，内部エネルギーは膨張の前後で変化しない．

理想気体の内部エネルギーは温度だけの関数であり，定積モル熱容量 $C_v^0$ が一定ならば，

```math
\Delta U=nC_v^0(T_2-T_1)
```

と表される．
ここで， $T_1$ と $T_2$ は，それぞれ膨張前と膨張後の平衡状態の絶対温度である．

$\Delta U=0$ であるから，

```math
nC_v^0(T_2-T_1)=0
```

となる．
$n>0$ ， $C_v^0>0$ であるため，

```math
\boxed{
T_2=T_1
}
```

を得る．
したがって，膨張前後の温度は等しい．
ただし，これは初期状態と最終状態の温度が等しいという意味であり，不可逆な膨張過程の途中でも温度が一定であることを意味するものではない．

### 2．エントロピー変化を計算する

前問で求めた，定積モル熱容量が一定の理想気体のエントロピーは，積分定数を含めて，

```math
S(T,V,n)
=n\left(C_v^0\ln T
+R\ln\frac{V}{n}+S_0\right)
```

と表される．
ここで $S_0$ は定数である．
対数の引数を厳密に無次元化するための基準値は，エントロピーの差を取ると相殺されるため，以下では省略する．

エントロピーは状態量であるから，実際の過程が不可逆であっても，初期状態と最終状態のエントロピーの差は，

```math
\Delta S=S(T_2,V_2,n)-S(T_1,V_1,n)
```

によって求められる．
上式にエントロピーの表式を代入すると，

```math
\begin{aligned}
\Delta S
={}&n\left(C_v^0\ln T_2
+R\ln\frac{V_2}{n}+S_0\right)\\
&-n\left(C_v^0\ln T_1
+R\ln\frac{V_1}{n}+S_0\right)
\end{aligned}
```

となる．
ここで， $T_2=T_1$ であるから，温度に関する項と積分定数は相殺される．
よって，

```math
\begin{aligned}
\Delta S
&=nR\left(\ln\frac{V_2}{n}
-\ln\frac{V_1}{n}\right)\\[4pt]
&=nR\ln\left(\frac{V_2/n}{V_1/n}\right)
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
\Delta S=nR\ln\frac{V_2}{V_1}
}
```

となる．
これが真空への断熱膨張におけるエントロピー変化である．

### 3．熱力学第2法則から不可逆性を示す

問題の条件より，気体は膨張しているため，

```math
V_2>V_1
```

である．
したがって，

```math
\frac{V_2}{V_1}>1
```

となる．
自然対数は，その引数が1より大きいとき正の値を取るので，

```math
\ln\frac{V_2}{V_1}>0
```

である．
また，物質量 $n$ と気体定数 $R$ はともに正であるため，

```math
\boxed{
\Delta S=nR\ln\frac{V_2}{V_1}>0
}
```

となる．

熱力学第2法則によれば，断熱された系のエントロピーは減少せず，可逆断熱過程では一定に保たれる．
これに対し，本問ではエントロピーが正に増加している．
したがって，この過程は可逆ではなく，

```math
\boxed{
\text{真空への断熱膨張は不可逆過程である}
}
```

と結論される．


## 解説

実際の膨張過程では $Q=0$ であるが，エントロピー変化はゼロではない．
エントロピーが状態量であるため，初期状態と最終状態を結ぶ仮想的な可逆等温過程を考えても，同じエントロピー変化を計算できる．
その場合に使う熱量は実際の断熱膨張での熱量とは異なるので，この点を混同しないことが重要である．
