# 演習問題【2-A-28】

## 解答

### 1. 仕事を最大にする条件

熱力学第二法則に基づくと，ある系から熱を奪い，外部に対して仕事を取り出すプロセスにおいて，得られる仕事が最大になるのは，そのプロセスがすべて **可逆過程** である場合である．

本問題では，温度 $T_1$ の物体から熱を奪い，温度 $T_0$ の熱浴に熱を捨てながら，その差分を仕事として取り出すことになる．
このとき，物体から奪う微小な熱量を $d'Q$ とすると，熱力学的なサイクル（カルノーサイクル）を介して，温度 $T$ の物体から $d'Q$ の熱を奪い，温度 $T_0$ の熱源に $d'Q_0$ の熱を与えることで，その差 $d'W = d'Q - d'Q_0$ を仕事として取り出すことができる．

カルノーサイクルの効率 $\eta$ を用いると，

$$\eta = \frac{d'W}{d'Q} = 1 - \frac{T_0}{T}$$

となる．
したがって，取り出せる微小な仕事は

$$d'W = \left( 1 - \frac{T_0}{T} \right) d'Q$$

と表される．
この過程を，物体の温度 $T$ が $T_1$ から $T_0$ まで連続的に変化するように（可逆的に）行うことで，仕事は最大となる．

### 2. 最大仕事の計算

物体の温度が $T$ から $T + dT$ へ変化するとき，物体が失う熱量は $d'Q = -C dT$ である（ $dT < 0$ なので，失う熱量は正となる）．
これを用いて，取り出せる微小な仕事 $d'W$ は次のように書ける．

$$d'W = \left( 1 - \frac{T_0}{T} \right) (-C dT)$$

得られる仕事の総量 $W$ は，物体の温度が $T_1$ から $T_0$ まで変化する間の $d'W$ を積分することで得られる．

$$W = \int_{T_1}^{T_0} \left( 1 - \frac{T_0}{T} \right) (-C) dT$$

積分範囲を整理するため，負の符号を積分範囲の入れ替えに使うと，

$$W = \int_{T_0}^{T_1} \left( 1 - \frac{T_0}{T} \right) C dT$$

となる．
この積分を実行する．

$$W = C \int_{T_0}^{T_1} \left( 1 - \frac{T_0}{T} \right) dT$$

$$W = C \left[ T - T_0 \log T \right]_{T_0}^{T_1}$$

```math
W = C \left\{ (T_1 - T_0 \log T_1) - (T_0 - T_0 \log T_0) \right\}
```

```math
W = C \left\{ (T_1 - T_0) - T_0 (\log T_1 - \log T_0) \right\}
```

対数の性質 $\log A - \log B = \log(A/B)$ を用いると，

```math
W = C \left\{ (T_1 - T_0) - T_0 \log \frac{T_1}{T_0} \right\}
```

が得られる．

以上より，仕事は **可逆過程** において最大となり，その最大値は

```math
C \left\{ (T_1 - T_0) - T_0 \log \frac{T_1}{T_0} \right\}
```

である．

## 解説

### なぜ可逆過程で仕事が最大なのか？

熱力学第二法則によれば，熱を仕事に変換する際，すべての熱を完全に仕事に変えることはできず，必ず一部の熱を低温の熱源へ捨てる必要がある．
このとき，捨てなければならない熱の最小量が，プロセスが「可逆的」であるときに決まる．
不可逆な過程（例えば，高温の物体と低温の物体を直接接触させるなど）では，熱が「無秩序な」形で移動してしまい，仕事として取り出せるエネルギーが減少してしまう．
したがって，最大限に仕事を取り出すには，温度差を極めて小さく保ちながら，一歩ずつ（可逆的に）熱を移動させる必要がある．

### 計算のポイント：微小熱量 $d'Q$ の扱い

この問題で注意が必要なのは，物体が失う熱量 $d'Q$ の定義である．
物体の温度が下がる（ $dT < 0$ ）とき，物体から放出される熱量は正の値でなければならないため， $d'Q = -C dT$ となる．
これを積分計算に正しく代入することが，符号のミスを防ぐ鍵となる．

### 物理的なイメージ

このプロセスは，いわば「温度差を利用したエネルギー回収」である．
高温の物体が持つ熱エネルギーを，直接捨てるのではなく，カルノーサイクルのような熱機関を介して，温度 $T_0$ の熱源との間でやり取りすることで，熱エネルギーの一部を「整然とした」機械的な仕事へと変換しているのである．
