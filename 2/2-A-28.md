# 演習問題【2-A-28】

## 解答

### 1．仕事が最大となる条件

初期温度 $T_1$ の物体を，温度 $T_0$ に保たれた熱浴と熱的に相互作用させ，最終的に物体の温度を $T_0$ まで下げる過程を考える．
ここで $T_1>T_0$ であり，熱容量 $C$ は一定とする．
温度はすべて絶対温度である．

物体が冷却されるとき，物体から取り出した熱の一部を仕事に変換できる．
外部に得られる仕事を最大にするためには，熱力学第二法則に従って，熱を仕事に変換する効率を最大にしなければならない．

そのために，物体の温度が $T$ であるとき，物体を高温熱源，温度 $T_0$ の熱浴を低温熱源とするカルノーサイクルを働かせる．
熱を取り出すたびに物体の温度は少しずつ低下するため，物体の温度に合わせてカルノーサイクルを順次働かせる．
この操作を可逆的に行えば，熱力学第二法則による仕事の上限を各段階で達成できるため，総仕事が最大となる．

### 2．微小な熱量から得られる仕事

物体の温度が $T$ から $T+dT$ に変化するとき，物体が失う熱量を $d'Q$ とする．
温度が低下する場合は $dT<0$ であるため，

```math
d'Q=-C\,dT>0
```

となる．

温度 $T$ の熱源から熱量 $d'Q$ を受け取り，温度 $T_0$ の熱浴に熱を捨てるカルノーサイクルの効率は，

```math
\eta=1-\frac{T_0}{T}
```

である．
効率は，受け取った熱量のうち仕事に変換できる割合であるから，微小な仕事 $d'W$ は

```math
d'W=\eta\,d'Q
```

と表される．
したがって，

```math
d'W=\left(1-\frac{T_0}{T}\right)(-C\,dT)
```

となる．

### 3．最大仕事の計算

物体の温度が $T_1$ から $T_0$ まで低下するとき，得られる最大仕事 $W_{\max}$ は，各段階で得られる微小仕事を積分したものである．
よって，

```math
W_{\max}
=-C\int_{T_1}^{T_0}
\left(1-\frac{T_0}{T}\right)dT
```

となる．
積分の上下限を入れ替えると，

```math
W_{\max}
=C\int_{T_0}^{T_1}
\left(1-\frac{T_0}{T}\right)dT
```

である．
これを積分すれば，

```math
\begin{aligned}
W_{\max}
&=C\left[
(T_1-T_0)-T_0\int_{T_0}^{T_1}\frac{1}{T}\,dT
\right]\\
&=C\left[
(T_1-T_0)-T_0\ln\frac{T_1}{T_0}
\right]
\end{aligned}
```

となる．
したがって，求める最大仕事は

```math
\boxed{
W_{\max}
=C\left[
(T_1-T_0)-T_0\ln\frac{T_1}{T_0}
\right]
}
```

である．

### 4．結果の物理的意味

この結果は，物体を温度 $T_1$ から $T_0$ まで冷却する際，温度 $T$ と $T_0$ の間で微小なカルノーサイクルを順次働かせる可逆過程で，外部に得られる仕事が最大となることを示している．

一方，物体を温度 $T_0$ の熱浴に直接接触させて冷却すると，熱を仕事に変換する装置がないため，外部に取り出せる仕事はゼロである．
不可逆過程では，この可逆過程と同じ初期状態・最終状態の間で得られる仕事は最大値を超えない．

また， $T_1>T_0$ ならば， $\ln(T_1/T_0)$ を含む上式で表される最大仕事は正である．
$T_1=T_0$ の極限では温度差がなくなり，取り出せる最大仕事もゼロとなる．
