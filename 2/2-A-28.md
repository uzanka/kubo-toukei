# 演習問題【2-A-28】

## 解答

### 1．最大仕事の上限を熱力学第二法則から求める

初期温度 $T_1$ の物体を，温度 $T_0$ に保たれた熱浴と熱的に相互作用させ，最終的に物体の温度を $T_0$ まで下げる過程を考える．
ここで， $T_1>T_0>0$ であり，熱容量 $C$ は一定とする．
また，温度はすべて絶対温度とする．

物体は，各瞬間に熱平衡状態にあり，その温度は一様であるとする．
物体から取り出された熱は仕事を取り出す装置に供給され，その装置は最終的に初期状態に戻るものとする．
また，物体の冷却に伴うエネルギーの放出は熱によって生じるものとし，他の熱源や外部からの仕事の供給は考えない．

まず，物体から取り出される全熱量を $Q_1$ ，熱浴に放出される全熱量を $Q_0$ ，外部に取り出される仕事を $W$ とする．
いずれも正の値をとるように定義する．

熱容量が一定であるため，物体から取り出される微小熱量は

```math
d'Q_1=-C\,dT
```

である．
したがって，温度が $T_1$ から $T_0$ まで低下するとき，

```math
\begin{aligned}
Q_1
&=-C\int_{T_1}^{T_0}dT\\
&=C(T_1-T_0)
\end{aligned}
```

となる．

仕事を取り出す装置は最終的に初期状態に戻るので，エネルギー保存則より，

```math
Q_1=W+Q_0
```

である．
したがって，

```math
W=C(T_1-T_0)-Q_0
\tag{1}
```

となる．

次に，熱力学第二法則を適用する．

物体のエントロピー変化は，熱容量が一定であることから，

```math
\begin{aligned}
\Delta S_{\mathrm{body}}
&=\int_{T_1}^{T_0}\frac{C}{T}\,dT\\
&=C\ln\frac{T_0}{T_1}
\end{aligned}
\tag{2}
```

である．

一方，温度 $T_0$ の熱浴は熱量 $Q_0$ を受け取るため，そのエントロピー変化は，

```math
\Delta S_{\mathrm{bath}}=\frac{Q_0}{T_0}
\tag{3}
```

となる．

仕事を取り出す装置はサイクルを完了して初期状態に戻るので，そのエントロピー変化はゼロである．
したがって，物体，熱浴および装置を合わせた全体系について，熱力学第二法則より，

```math
\Delta S_{\mathrm{total}}
=
\Delta S_{\mathrm{body}}
+
\Delta S_{\mathrm{bath}}
\geq 0
```

が成立する．

式 (2)，(3) を代入すると，

```math
C\ln\frac{T_0}{T_1}
+\frac{Q_0}{T_0}
\geq 0
```

となる．
これを整理すれば，

```math
\boxed{
Q_0\geq CT_0\ln\frac{T_1}{T_0}
}
\tag{4}
```

を得る．

式 (1) と式 (4) より，

```math
\begin{aligned}
W
&=C(T_1-T_0)-Q_0\\
&\leq C(T_1-T_0)
-CT_0\ln\frac{T_1}{T_0}
\end{aligned}
```

である．
したがって，外部に取り出せる仕事には，

```math
\boxed{
W\leq
C\left[
(T_1-T_0)-T_0\ln\frac{T_1}{T_0}
\right]
}
\tag{5}
```

という上限が存在する．

この上限は，熱力学第二法則から導かれたものであり，取り出し方や熱機関の具体的な構成によらず，すべての許される過程に対して成立する．

### 2．最大仕事が得られる条件

式 (4) の等号が成立する条件は，

```math
\Delta S_{\mathrm{total}}=0
```

である．
これは，全過程においてエントロピー生成がゼロとなる可逆過程に対応する．

したがって，外部に取り出せる仕事が最大となるのは，全過程を可逆的に行う場合である．

この条件を実現する方法として，物体の温度に合わせて微小なカルノーサイクルを順次働かせる方法を考える．

物体の温度が $T$ であるとき，物体を高温熱源，温度 $T_0$ の熱浴を低温熱源とするカルノーサイクルを動作させる．
このとき，カルノーサイクルの効率は，

```math
\eta=1-\frac{T_0}{T}
```

である．

物体から取り出される熱量を微小量 $d'Q_1$ とすると，熱から仕事に変換される微小仕事は，

```math
d'W=\eta\,d'Q_1
```

となる．

物体の温度が $T$ から $T+dT$ に変化するとき，温度変化は $dT<0$ であり，物体から取り出される熱量は，

```math
d'Q_1=-C\,dT>0
```

である．
したがって，

```math
\begin{aligned}
d'W
&=\left(1-\frac{T_0}{T}\right)(-C\,dT)
\end{aligned}
\tag{6}
```

となる．

ただし，物体は有限の熱容量を持つため，熱を取り出すとその温度は変化する．
したがって，有限量の熱を一度に取り出す場合には，高温熱源の温度を一定とみなすことはできない．

そこで，取り出す熱量を無限小とし，物体の温度変化も無限小となる極限を考える．
この極限では，各段階において物体の温度を一定とみなしてカルノーサイクルを動作させることができる．
さらに，物体と熱機関の間の温度差を無限小に保ち，十分にゆっくりと操作することで，可逆的な熱交換が実現できる．

したがって，この微小カルノーサイクルを物体の温度が $T_1$ から $T_0$ まで下がる間，連続的に繰り返すことによって，全過程を可逆的に行うことができる．

よって，式 (5) の上限はこの可逆過程によって達成される．

### 3．最大仕事の計算

式 (6) より，物体の温度が $T_1$ から $T_0$ まで低下するとき，得られる仕事は，

```math
W_{\max}
=-C\int_{T_1}^{T_0}
\left(1-\frac{T_0}{T}\right)dT
```

である．

積分の上下限を入れ替えると，

```math
W_{\max}
=C\int_{T_0}^{T_1}
\left(1-\frac{T_0}{T}\right)dT
```

となる．
これを積分すれば，

```math
\begin{aligned}
W_{\max}
&=C\left[
(T_1-T_0)
-T_0\int_{T_0}^{T_1}\frac{1}{T}\,dT
\right]\\
&=C\left[
(T_1-T_0)
-T_0\left(\ln T_1-\ln T_0\right)
\right]\\
&=C\left[
(T_1-T_0)-T_0\ln\frac{T_1}{T_0}
\right]
\end{aligned}
```

となる．

したがって，求める最大仕事は，

```math
\boxed{
W_{\max}
=C\left[
(T_1-T_0)-T_0\ln\frac{T_1}{T_0}
\right]
}
```

である．

これは式 (5) で得られたすべての過程に対する上限と一致している．
したがって，この値が実際に達成可能な最大仕事であることが示された．

### 4．結果の物理的意味

以上より，外部に取り出せる仕事が最大となるのは，物体から熱を取り出す過程を全体として可逆的に行う場合である．
具体的には，物体の温度に合わせて微小なカルノーサイクルを順次働かせ，温度 $T$ の物体から熱を取り出し，温度 $T_0$ の熱浴に放熱する過程である．

また，この結果から，不可逆過程における仕事の損失とエントロピー生成との関係も求められる．
全体系のエントロピー生成を $S_{\mathrm{gen}}$ とすると，

```math
S_{\mathrm{gen}}
=
C\ln\frac{T_0}{T_1}
+\frac{Q_0}{T_0}
```

である．
したがって，

```math
Q_0=CT_0\ln\frac{T_1}{T_0}
+T_0S_{\mathrm{gen}}
```

となる．
これを式 (1) に代入すれば，

```math
\boxed{
W=W_{\max}-T_0S_{\mathrm{gen}}
}
```

を得る．

熱力学第二法則より，

```math
S_{\mathrm{gen}}\geq0
```

であるから，

```math
W\leq W_{\max}
```

が成立する．
また，エントロピー生成がゼロとなる可逆過程でのみ，最大仕事が得られる．不可逆過程ではエントロピー生成が正となり，その分だけ取り出せる仕事が減少する．

さらに， $T_1>T_0$ ならば，

```math
\frac{T_1}{T_0}>1
```

である．
ここで， $x=T_1/T_0$ と置くと，

```math
x-1-\ln x>0
\qquad (x>1)
```

が成立するため，

```math
W_{\max}>0
```

である．
一方， $T_1=T_0$ の極限では，

```math
W_{\max}=0
```

となる．
これは，温度差がなくなれば，熱を仕事に変換するための熱力学的な能力も失われることを意味する．

以上より，求める最大仕事は，

```math
\boxed{
W_{\max}
=C\left[
(T_1-T_0)-T_0\ln\frac{T_1}{T_0}
\right]
}
```

であり，全過程を可逆的に行う場合に最大となる．
