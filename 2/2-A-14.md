# 演習問題【2-A-14】

## 解答

### (i) 断熱圧縮率と等温圧縮率の比

#### 1．圧縮率の定義と断熱条件

断熱圧縮率 $\kappa_S$ と等温圧縮率 $\kappa_T$ は，それぞれ

```math
\kappa_S\equiv-\frac{1}{V}
\left(\frac{\partial V}{\partial p}\right)_S,
\qquad
\kappa_T\equiv-\frac{1}{V}
\left(\frac{\partial V}{\partial p}\right)_T
\tag{1}
```

と定義される．
ここで， $S$ はエントロピー， $T$ は絶対温度である．
断熱圧縮率ではエントロピーを一定に保ち，等温圧縮率では温度を一定に保つ．

エントロピーを圧力 $p$ と体積 $V$ の関数 $S(p,V)$ とみなすと，全微分は

```math
dS=
\left(\frac{\partial S}{\partial p}\right)_Vdp
+
\left(\frac{\partial S}{\partial V}\right)_p dV
\tag{2}
```

である．
断熱過程では $dS=0$ であるから，

```math
0=
\left(\frac{\partial S}{\partial p}\right)_Vdp
+
\left(\frac{\partial S}{\partial V}\right)_p dV
```

となる．
これを $dV/dp$ について整理すると，

```math
\left(\frac{\partial V}{\partial p}\right)_S
=
-\frac{
\left(\dfrac{\partial S}{\partial p}\right)_V
}{
\left(\dfrac{\partial S}{\partial V}\right)_p
}
```

を得る．
したがって，式 (1) より，

```math
\boxed{
\kappa_S=
\frac{1}{V}
\frac{
\left(\dfrac{\partial S}{\partial p}\right)_V
}{
\left(\dfrac{\partial S}{\partial V}\right)_p
}
}
\tag{3}
```

となる．

#### 2．エントロピーの偏微分を比熱で表す

定積比熱 $C_V$ と定圧比熱 $C_p$ は，

```math
C_V=T\left(\frac{\partial S}{\partial T}\right)_V,
\qquad
C_p=T\left(\frac{\partial S}{\partial T}\right)_p
\tag{4}
```

と表される．
ここでは，両者を同じ系についての熱容量として扱う．

まず，エントロピーを $T,V$ の関数とみなすと，連鎖律より，

```math
\left(\frac{\partial S}{\partial p}\right)_V
=
\left(\frac{\partial S}{\partial T}\right)_V
\left(\frac{\partial T}{\partial p}\right)_V
```

である．
式 (4) を用いると，

```math
\boxed{
\left(\frac{\partial S}{\partial p}\right)_V
=
\frac{C_V}{T}
\left(\frac{\partial T}{\partial p}\right)_V
}
\tag{5}
```

となる．

同様に，エントロピーを $T,p$ の関数とみなすと，

```math
\left(\frac{\partial S}{\partial V}\right)_p
=
\left(\frac{\partial S}{\partial T}\right)_p
\left(\frac{\partial T}{\partial V}\right)_p
```

であるから，

```math
\boxed{
\left(\frac{\partial S}{\partial V}\right)_p
=
\frac{C_p}{T}
\left(\frac{\partial T}{\partial V}\right)_p
}
\tag{6}
```

を得る．

式 (5)，(6) を式 (3) に代入すると，

```math
\kappa_S=
\frac{C_V}{VC_p}
\frac{
\left(\dfrac{\partial T}{\partial p}\right)_V
}{
\left(\dfrac{\partial T}{\partial V}\right)_p
}
\tag{7}
```

となる．

#### 3．三乗積の公式を用いて整理する

状態変数 $T,p,V$ の間には，三乗積の公式

```math
\left(\frac{\partial T}{\partial p}\right)_V
\left(\frac{\partial p}{\partial V}\right)_T
\left(\frac{\partial V}{\partial T}\right)_p
=-1
\tag{8}
```

が成立する．
また，

```math
\frac{1}{
\left(\dfrac{\partial T}{\partial V}\right)_p
}
=
\left(\frac{\partial V}{\partial T}\right)_p
```

であるから，式 (8) より，

```math
\begin{aligned}
\frac{
\left(\dfrac{\partial T}{\partial p}\right)_V
}{
\left(\dfrac{\partial T}{\partial V}\right)_p
}
&=
-\frac{1}{
\left(\dfrac{\partial p}{\partial V}\right)_T
}\\
&=
-\left(\frac{\partial V}{\partial p}\right)_T
\end{aligned}
\tag{9}
```

を得る．

これを式 (7) に代入すると，

```math
\begin{aligned}
\kappa_S
&=-\frac{C_V}{VC_p}
\left(\frac{\partial V}{\partial p}\right)_T\\
&=\frac{C_V}{C_p}\kappa_T
\end{aligned}
```

となる．
ゆえに，

```math
\boxed{
\frac{\kappa_S}{\kappa_T}=\frac{C_V}{C_p}
}
```

が示された．

### (ii) 断熱磁化率と等温磁化率の比

#### 1．磁化率の定義と断熱条件

断熱磁化率 $\chi_S$ と等温磁化率 $\chi_T$ は，

```math
\chi_S\equiv
\left(\frac{\partial M}{\partial H}\right)_S,
\qquad
\chi_T\equiv
\left(\frac{\partial M}{\partial H}\right)_T
\tag{10}
```

と定義される．
ここで， $M$ は磁化， $H$ は磁場である．
また，磁化一定の比熱 $C_M$ と磁場一定の比熱 $C_H$ は，

```math
C_M=T\left(\frac{\partial S}{\partial T}\right)_M,
\qquad
C_H=T\left(\frac{\partial S}{\partial T}\right)_H
\tag{11}
```

で定義される．

(i) と同様に，エントロピーを磁場 $H$ と磁化 $M$ の関数 $S(H,M)$ とみなすと，

```math
dS=
\left(\frac{\partial S}{\partial H}\right)_M dH
+
\left(\frac{\partial S}{\partial M}\right)_H dM
\tag{12}
```

である．

断熱過程では $dS=0$ であるため，

```math
0=
\left(\frac{\partial S}{\partial H}\right)_M dH
+
\left(\frac{\partial S}{\partial M}\right)_H dM
```

となる．
これを $dM/dH$ について整理すると，

```math
\boxed{
\chi_S
=
-\frac{
\left(\dfrac{\partial S}{\partial H}\right)_M
}{
\left(\dfrac{\partial S}{\partial M}\right)_H
}
}
\tag{13}
```

を得る．

#### 2．エントロピーの偏微分を比熱で表す

エントロピーを $T,M$ の関数とみなすと，連鎖律より，

```math
\left(\frac{\partial S}{\partial H}\right)_M
=
\left(\frac{\partial S}{\partial T}\right)_M
\left(\frac{\partial T}{\partial H}\right)_M
```

である．
式 (11) を用いれば，

```math
\boxed{
\left(\frac{\partial S}{\partial H}\right)_M
=
\frac{C_M}{T}
\left(\frac{\partial T}{\partial H}\right)_M
}
\tag{14}
```

となる．

同様に，エントロピーを $T,H$ の関数とみなすと，

```math
\left(\frac{\partial S}{\partial M}\right)_H
=
\left(\frac{\partial S}{\partial T}\right)_H
\left(\frac{\partial T}{\partial M}\right)_H
```

であるから，

```math
\boxed{
\left(\frac{\partial S}{\partial M}\right)_H
=
\frac{C_H}{T}
\left(\frac{\partial T}{\partial M}\right)_H
}
\tag{15}
```

を得る．

式 (14)，(15) を式 (13) に代入すると，

```math
\chi_S
=
-\frac{C_M}{C_H}
\frac{
\left(\dfrac{\partial T}{\partial H}\right)_M
}{
\left(\dfrac{\partial T}{\partial M}\right)_H
}
\tag{16}
```

となる．

#### 3．三乗積の公式を用いて整理する

状態変数 $T,H,M$ の間には，三乗積の公式

```math
\left(\frac{\partial T}{\partial H}\right)_M
\left(\frac{\partial H}{\partial M}\right)_T
\left(\frac{\partial M}{\partial T}\right)_H
=-1
\tag{17}
```

が成立する．
また，

```math
\frac{1}{
\left(\dfrac{\partial T}{\partial M}\right)_H
}
=
\left(\frac{\partial M}{\partial T}\right)_H
```

であるため，式 (17) より，

```math
\begin{aligned}
\frac{
\left(\dfrac{\partial T}{\partial H}\right)_M
}{
\left(\dfrac{\partial T}{\partial M}\right)_H
}
&=
-\frac{1}{
\left(\dfrac{\partial H}{\partial M}\right)_T
}\\
&=
-\left(\frac{\partial M}{\partial H}\right)_T\\
&=-\chi_T
\end{aligned}
\tag{18}
```

を得る．

式 (18) を式 (16) に代入すると，

```math
\begin{aligned}
\chi_S
&=-\frac{C_M}{C_H}(-\chi_T)\\
&=\frac{C_M}{C_H}\chi_T
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\frac{\chi_S}{\chi_T}=\frac{C_M}{C_H}
}
```

が示された．

### 結論

以上より，エントロピーの全微分と連鎖律を用いることで，次の2つの関係が得られた．

```math
\boxed{
\frac{\kappa_S}{\kappa_T}=\frac{C_V}{C_p}
}
```

```math
\boxed{
\frac{\chi_S}{\chi_T}=\frac{C_M}{C_H}
}
```

いずれも，断熱条件ではエントロピーが一定であることを利用し，適切な状態変数で表したエントロピーの偏微分を比熱によって書き換えることで導かれる結果である．
