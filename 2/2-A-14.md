# 演習問題【2-A-14】

## 解答

### (i) 断熱圧縮率と等温圧縮率の比

まず，圧縮率の定義を確認する．
断熱圧縮率 $\kappa_s$ および等温圧縮率 $\kappa_T$ は次のように定義される:

$$\kappa_s \equiv -\frac{1}{V} \left( \frac{\partial V}{\partial p} \right)_S, \quad \kappa_T \equiv -\frac{1}{V} \left( \frac{\partial V}{\partial p} \right)_T$$

これら の比 $\kappa_s/\kappa_T$ を求めるために，エントロピー $S$ を圧力 $p$ と体積 $V$ の関数 $S(p,V)$ として扱い，その全微分を考える:

$$dS = \left( \frac{\partial S}{\partial p} \right)_V dp + \left( \frac{\partial S}{\partial V} \right)_p dV$$

#### ステップ1: $dS = 0$ から $(\partial V/\partial p)_S$ を求める

断熱過程 ( $dS = 0$ ) では， $p$ と $V$ の変化は

$$0 = \left( \frac{\partial S}{\partial p} \right)_V dp + \left( \frac{\partial S}{\partial V} \right)_p dV$$

を満たす．
したがって，

$$\left( \frac{\partial V}{\partial p} \right)_S = -\frac{(\partial S/\partial p)_V}{(\partial S/\partial V)_p}$$

ゆえに，

$$\kappa_s = -\frac{1}{V}\left( \frac{\partial V}{\partial p} \right)_S = \frac{1}{V} \cdot \frac{(\partial S/\partial p)_V}{(\partial S/\partial V)_p} \quad \cdots (1)$$

#### ステップ2: 偏微分を熱容量で表す

エントロピー $S$ を温度 $T$ と圧力 $p$ の関数 $S(T,p)$ とみなすと，定圧比熱の定義 $(\partial S/\partial T)_p = C_p/T$ より，

$$dS = \frac{C_p}{T}\,dT + \left( \frac{\partial S}{\partial p} \right)_T dp$$

ヘルムホルツ自由エネルギー $F = U - TS$ ( $dF = -S\,dT - p\,dV$ ) からのマクスウェルの関係式

$$\left( \frac{\partial S}{\partial p} \right)_T = -\left( \frac{\partial V}{\partial T} \right)_p \quad \cdots (2)$$

を用いると，

$$dS = \frac{C_p}{T}\,dT - \left( \frac{\partial V}{\partial T} \right)_p dp \quad \cdots (3)$$

一方，エントロピー $S$ を温度 $T$ と体積 $V$ の関数 $S(T,V)$ とみなすと，定積比熱の定義 $(\partial S/\partial T)_V = C_V/T$ より，

$$dS = \frac{C_V}{T}\,dT + \left( \frac{\partial S}{\partial V} \right)_T dV$$

同じくマクスウェルの関係式 ( $(∂S/∂V)_T = (∂p/∂T)_V$ ) を用いると，

$$dS = \frac{C_V}{T}\,dT + \left( \frac{\partial p}{\partial T} \right)_V dV \quad \cdots (4)$$

#### ステップ3: $(\partial S/\partial p)_V$ と $(\partial S/\partial V)_p$ を計算する

式 (4) において $T$ と $V$ を独立変数とみなし， $S(p,V)$ における偏微分を連鎖法則で表すと：

$$\left( \frac{\partial S}{\partial p} \right)_V = \left( \frac{\partial S}{\partial T} \right)_V \left( \frac{\partial T}{\partial p} \right)_V = \frac{C_V}{T}\left( \frac{\partial T}{\partial p} \right)_V \quad \cdots (5)$$

同様に，式 (3) において $T$ と $p$ を独立変数とみなし：

$$\left( \frac{\partial S}{\partial V} \right)_p = \left( \frac{\partial S}{\partial T} \right)_p \left( \frac{\partial T}{\partial V} \right)_p = \frac{C_p}{T}\left( \frac{\partial T}{\partial V} \right)_p \quad \cdots (6)$$

#### ステップ4: 三乗積の公式を用いて整理する

式 (1) に (5), (6) を代入すると，

$$\kappa_s = \frac{C_V}{V\,C_p}\,\frac{(\partial T/\partial p)_V}{(\partial T/\partial V)_p}$$

ここで，状態量 $p, V, T$ の間の三乗積の公式 (triple product rule)

$$\left( \frac{\partial p}{\partial T} \right)_V \left( \frac{\partial T}{\partial V} \right)_p \left( \frac{\partial V}{\partial p} \right)_T = -1$$

より，

$$\left( \frac{\partial p}{\partial T} \right)_V = -\left( \frac{\partial p}{\partial V} \right)_T \left( \frac{\partial V}{\partial T} \right)_p \quad \cdots (7)$$

式 (7) および $(\partial T/\partial p)_V = 1/(\partial p/\partial T)_V$, $(\partial T/\partial V)_p = 1/(\partial V/\partial T)_p$ を用いると，

$$\kappa_s = \frac{C_V}{VC_p} \cdot \frac{(\partial V/\partial T)_p}{(\partial p/\partial T)_V} = \frac{C_V}{VC_p} \cdot \frac{(\partial V/\partial T)_p}{-(\partial p/\partial V)_T (\partial V/\partial T)_p} = -\frac{C_V}{VC_p}\,\frac{1}{(\partial p/\partial V)_T}$$

等温圧縮率の定義 $\kappa_T = -(1/V)(\partial V/\partial p)_T$ より， $(\partial p/\partial V)_T = -1/(V\kappa_T)$ である．
したがって，

$$\kappa_s = \frac{C_V}{VC_p} \cdot (V\kappa_T) = \frac{C_V}{C_p}\,\kappa_T$$

ゆえに，

$$\boxed{\frac{\kappa_s}{\kappa_T} = \frac{C_V}{C_p}}$$

が示された．

### (ii) 断熱磁化率と等温磁化率の比

磁性系における熱力学を扱う．
磁気仕事を $\mu_0 H\,dM$ とすると，内部エネルギー $U$ の基本方程式は，

$$dU = T\,dS + \mu_0 H\,dM$$

ここで，便宜上 $\mu_0 = 1$ と書く（結果には影響しない）．
したがって，

$$dU = T\,dS + H\,dM$$

磁化一定の比熱 $C_M$ と磁場一定の比熱 $C_H$ はそれぞれ

$$C_M \equiv T\left(\frac{\partial S}{\partial T}\right)_M, \quad C_H \equiv T\left(\frac{\partial S}{\partial T}\right)_H$$

で定義される．
また，断熱磁化率 $\chi_s$ と等温磁化率 $\chi_T$ は

$$\chi_s \equiv \left( \frac{\partial M}{\partial H} \right)_S, \quad \chi_T \equiv \left( \frac{\partial M}{\partial H} \right)_T$$

で定義される．

#### ステップ1: マクスウェルの関係式

ヘルムホルツ自由エネルギー $F(T,M) = U - TS$ に対して，

$$dF = -S\,dT + H\,dM$$

よりマクスウェルの関係式：

$$\left(\frac{\partial S}{\partial M}\right)_T = -\left(\frac{\partial H}{\partial T}\right)_M \quad \cdots (8)$$

ギブス自由エネルギー $G(T,H) = U - TS - HM$ に対して，

$$dG = -S\,dT - M\,dH$$

よりマクスウェルの関係式：

$$\left(\frac{\partial S}{\partial H}\right)_T = \left(\frac{\partial M}{\partial T}\right)_H \quad \cdots (9)$$

#### ステップ2: $(\partial M/\partial H)_S$ を求める

エントロピーを $H$ と $M$ の関数 $S(H,M)$ として，その全微分は，

$$dS = \left(\frac{\partial S}{\partial H}\right)_M dH + \left(\frac{\partial S}{\partial M}\right)_H dM$$

断熱過程 ( $dS = 0$ ) では，

$$\left(\frac{\partial M}{\partial H}\right)_S = -\frac{(\partial S/\partial H)_M}{(\partial S/\partial M)_H} \quad \cdots (10)$$

#### ステップ3: $(\partial S/\partial H)_M$ と $(\partial S/\partial M)_H$ を計算する

$(\partial S/\partial H)_M$ について，エントロピー $S$ を温度 $T$ と磁場 $H$ の関数 $S(T,H)$ として，連鎖法則を適用する（ $M$ を固定して $H$ を変化させると $T$ も変化する）：

$$\left(\frac{\partial S}{\partial H}\right)_M = \left(\frac{\partial S}{\partial H}\right)_T + \left(\frac{\partial S}{\partial T}\right)_H \left(\frac{\partial T}{\partial H}\right)_M$$

式 (9) より $(\partial S/\partial H)_T = (\partial M/\partial T)_H$ ，また $(\partial S/\partial T)_H = C_H/T$ である．
さらに， $M$ を固定して $T$ と $H$ が逆関数関係にあることから， $(\partial T/\partial H)_M = 1/(\partial H/\partial T)_M$ である．
したがって，

$$\left(\frac{\partial S}{\partial H}\right)_M = \left(\frac{\partial M}{\partial T}\right)_H + \frac{C_H}{T} \cdot \frac{1}{(\partial H/\partial T)_M} \quad \cdots (11)$$

同様に， $(\partial S/\partial M)_H$ について，エントロピー $S$ を温度 $T$ と磁化 $M$ の関数 $S(T,M)$ として連鎖法則を適用する（ $H$ を固定して $M$ を変化させると $T$ も変化する）：

$$\left(\frac{\partial S}{\partial M}\right)_H = \left(\frac{\partial S}{\partial M}\right)_T + \left(\frac{\partial S}{\partial T}\right)_M \left(\frac{\partial T}{\partial M}\right)_H$$

式 (8) より $(\partial S/\partial M)_T = -(\partial H/\partial T)_M$ ，また $(\partial S/\partial T)_M = C_M/T$ である．三乗積の公式より，

$$\left(\frac{\partial T}{\partial M}\right)_H = -\frac{1}{(\partial M/\partial H)_T \cdot (\partial H/\partial T)_M}$$

したがって，

$$\left(\frac{\partial S}{\partial M}\right)_H = -\left(\frac{\partial H}{\partial T}\right)_M - \frac{C_M}{T} \cdot \frac{1}{(\partial M/\partial H)_T \cdot (\partial H/\partial T)_M} \quad \cdots (12)$$

#### ステップ4: 比熱の差 $C_H - C_M$ を求める

式 (10) に (11), (12) を直接代入しても複雑になるため，別の経路で整理する．

まず，エントロピー $S$ を $T, M$ の関数として， $(\partial S/\partial T)_H$ を連鎖法則で表す：

$$\left(\frac{\partial S}{\partial T}\right)_H = \left(\frac{\partial S}{\partial T}\right)_M + \left(\frac{\partial S}{\partial M}\right)_T \left(\frac{\partial M}{\partial T}\right)_H$$

したがって，

$$\frac{C_H}{T} = \frac{C_M}{T} + \left(\frac{\partial S}{\partial M}\right)_T \left(\frac{\partial M}{\partial T}\right)_H$$

式 (8) より $(\partial S/\partial M)_T = -(\partial H/\partial T)_M$ であるから，

$$C_H - C_M = -T\left(\frac{\partial H}{\partial T}\right)_M \left(\frac{\partial M}{\partial T}\right)_H \quad \cdots (13)$$

三乗積の公式より $(\partial H/\partial T)_M = -(\partial M/\partial T)_H / (\partial M/\partial H)_T$ である．これを代入すると，

$$C_H - C_M = T\frac{\left( \frac{\partial M}{\partial T} \right)_H^2}{\left( \frac{\partial M}{\partial H} \right)_T} \quad \cdots (14)$$

#### ステップ5: 磁化率の比を計算する

もう一つの経路で $(\chi_s/\chi_T)$ を求める．
$M$ を $T, H$ の関数として，連鎖法則を適用：

$$dM = \left(\frac{\partial M}{\partial T}\right)_H dT + \left(\frac{\partial M}{\partial H}\right)_T dH$$

断熱過程 ( $dT = (\partial T/\partial H)_S dH$ ) において，

$$\left(\frac{\partial M}{\partial H}\right)_S = \left(\frac{\partial M}{\partial T}\right)_H \left(\frac{\partial T}{\partial H}\right)_S + \left(\frac{\partial M}{\partial H}\right)_T \quad \cdots (15)$$

エントロピー $S(T,H)$ において $dS = 0$ とすると，

$$\left(\frac{\partial T}{\partial H}\right)_S = -\frac{(\partial S/\partial H)_T}{(\partial S/\partial T)_H} = -\frac{T(\partial M/\partial T)_H}{C_H}$$

（ここで式 (9) を用いた）．
これを式 (15) に代入：

$$\left(\frac{\partial M}{\partial H}\right)_S = \left(\frac{\partial M}{\partial H}\right)_T - \frac{T}{C_H} \left( \frac{\partial M}{\partial T} \right)_H^2$$

したがって，

$$\frac{\chi_s}{\chi_T} = \frac{(\partial M/\partial H)_S}{(\partial M/\partial H)_T} = 1 - \frac{T(\partial M/\partial T)_H^2}{C_H (\partial M/\partial H)_T}$$

式 (14) より $T(\partial M/\partial T)_H^2 / (\partial M/\partial H)_T = C_H - C_M$ であるから，

$$\frac{\chi_s}{\chi_T} = 1 - \frac{C_H - C_M}{C_H} = \frac{C_M}{C_H}$$

ゆえに，

$$\boxed{\frac{\chi_s}{\chi_T} = \frac{C_M}{C_H}}$$

が示された．

## 解説

### 圧縮率の比 $\kappa_s/\kappa_T = C_V/C_p$ の物理的意味

断熱圧縮率は等温圧縮率よりも小さい ( $\kappa_s < \kappa_T$ )．
これは，圧縮したときに温度が上昇するが，断熱のために熱量が逃げられないため，さらに硬くなる（体積変化が小さくなる）からである．
比熱の比 $C_V/C_p$ は通常 1 より小さい (理想気体では $C_p - C_V = nR$ ) ．

### 磁気系の対応

磁性体においても，変数 $(p, V)$ を $(H, M)$ に置き換えることで，圧縮率の場合と全く同じ熱力学構造が成立する．
これは「状態方程式の形」に依存しない普遍的な熱力学の結果である．

### 三乗積の公式の重要性

この問題の鍵は，三乗積の公式

$$\left(\frac{\partial X}{\partial Y}\right)_Z \left(\frac{\partial Y}{\partial Z}\right)_X \left(\frac{\partial Z}{\partial X}\right)_Y = -1$$

を正しく適用することにある．
これを間違えると，次元の合わない式や誤った関係式に繋がってしまう．

### 比熱の差と応答関数の関係

本問題で得られた二つの結果は，以下の普遍的な構造を持つ：

**断熱過程における応答関数は等温過程のそれよりも小さい．**
これは，断熱条件が系の自由度を効果的に減らす（温度変化が追加の復元力を生む）ことに起因する．
式 (14) はその差 $C_H - C_M$ が磁化の温度依存性 $(\partial M/\partial T)_H$ で決まることを示している．
同様に式 (i) においては $C_p - C_V = T V \alpha^2 / \kappa_T$ （ $\alpha$ は熱膨張係数）の関係が成立する．
