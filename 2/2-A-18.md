# 演習問題【2-A-18】

## 解答

理想気体1 molを，温度 $T=20^\circ\mathrm{C}=293\,\mathrm{K}$ に保ちながら，圧力 $p_1=1\,\mathrm{atm}$ から $p_2=100\,\mathrm{atm}$ まで等温圧縮する．
エントロピー，Helmholtz 自由エネルギー，Gibbs 自由エネルギーの変化量を順に求める．

ここで，気体定数は

```math
R=1.987\ \mathrm{cal/(mol\cdot K)}
```

とする．

### 1．エントロピーの変化 $\Delta S$

理想気体1 molについて，エントロピーの微小変化は，

```math
dS=\frac{C_p(T)}{T}\,dT-R\frac{dp}{p}
\tag{1}
```

と表される．
ここで， $C_p(T)$ は定圧モル比熱であり，温度に依存してもよい．

今回の圧縮過程では温度が一定であるため，

```math
dT=0
```

である．
したがって，式 (1) は，

```math
dS=-R\frac{dp}{p}
```

となる．
これを初期圧力 $p_1$ から最終圧力 $p_2$ まで積分すると，

```math
\begin{aligned}
\Delta S
&=S_2-S_1\\
&=-R\int_{p_1}^{p_2}\frac{dp}{p}\\
&=-R\ln\frac{p_2}{p_1}
\end{aligned}
```

を得る．
ここで， $p_2/p_1=100$ であるから，

```math
\Delta S=-R\ln100
```

となる．
数値を代入すると，

```math
\begin{aligned}
\Delta S
&=-1.987\times\ln100\\
&=-1.987\times4.60517\\
&\simeq-9.15\ \mathrm{cal/K}
\end{aligned}
```

である．

したがって，

```math
\boxed{
\Delta S\simeq-9.2\ \mathrm{cal/K}
}
```

となる．
圧縮によって気体のエントロピーは減少するのである．

### 2．Helmholtz 自由エネルギーの変化 $\Delta F$

Helmholtz 自由エネルギー $F$ は，

```math
F=U-TS
```

と定義される．
したがって，初期状態から最終状態への変化は，

```math
\Delta F=\Delta U-\Delta(TS)
```

である．
今回の過程では温度 $T$ が一定であるため，

```math
\Delta F=\Delta U-T\Delta S
\tag{2}
```

となる．

理想気体の内部エネルギー $U$ は温度のみの関数である．
初期状態と最終状態の温度は等しいため，

```math
\Delta U=0
```

である．
これを式 (2) に代入すると，

```math
\Delta F=-T\Delta S
```

を得る．
先ほど求めた $\Delta S=-R\ln100$ を代入すれば，

```math
\Delta F=RT\ln100
```

である．
したがって，

```math
\begin{aligned}
\Delta F
&=293\times1.987\times4.60517\\
&\simeq2681\ \mathrm{cal}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\Delta F\simeq2.68\ \mathrm{kcal}
}
```

である．
ここでは1 molの気体全体の自由エネルギー変化を表している．

### 3．Gibbs 自由エネルギーの変化 $\Delta G$

Gibbs 自由エネルギー $G$ は，

```math
G=U-TS+pV=F+pV
```

と定義される．
したがって，

```math
\Delta G=\Delta F+\Delta(pV)
\tag{3}
```

である．

理想気体1 molの状態方程式は，

```math
pV=RT
```

である．
今回の圧縮過程では温度が一定であるため， $RT$ は一定であり，

```math
\Delta(pV)=0
```

となる．
これを式 (3) に代入すると，

```math
\Delta G=\Delta F
```

を得る．
したがって，

```math
\boxed{
\Delta G\simeq2.68\ \mathrm{kcal}
}
```

である．

### 結論

理想気体1 molを $293\,\mathrm{K}$ に保ちながら，圧力を $1\,\mathrm{atm}$ から $100\,\mathrm{atm}$ まで等温圧縮したときの変化量は，

```math
\boxed{
\Delta S\simeq-9.2\ \mathrm{cal/K}
}
```

```math
\boxed{
\Delta F\simeq2.68\ \mathrm{kcal}
}
```

```math
\boxed{
\Delta G\simeq2.68\ \mathrm{kcal}
}
```

である．
エントロピーは減少し，Helmholtz 自由エネルギーと Gibbs 自由エネルギーはともに増加する．


## 解説

解答例と同じく，今回の計算に定積比熱や定圧比熱を一定とする仮定は不要である．
理想気体では内部エネルギーとエンタルピーが温度のみの関数であり，等温過程ではそれらの変化がゼロになることが本質である．
