# 演習問題【2-A-20】

## 解答

求めるエントロピーの変化 $\Delta S = S_v - S_i$ を計算するために，状態 $i$ (0℃, 1atm の氷) から 状態 $v$ (100℃, 1atm の水蒸気) への変化を，以下の3つの段階に分けて考える．

1.  **氷の融解 (0℃, 1atm)** : 氷から水への相転移
2.  **水の昇温 (0℃ $\to$ 100℃, 1atm)** : 水の温度上昇
3.  **水の蒸発 (100℃, 1atm)** : 水から水蒸気への相転移

エントロピーの変化 $\Delta S$ は，準静的な過程において，吸収した熱量 $Q$ をその時の絶対温度 $T$ で割ったものの積分として次のように表される．

$$\Delta S = \int \frac{dQ}{T}$$

### 1. 氷の融解によるエントロピー変化 ( $\Delta S_1$ )

0℃ ( $T_0 = 273$ K) における氷の融解熱 $\Delta H_{melt} = 1436.3$ cal/mol は，等温過程における熱量 $Q = \Delta H_{melt}$ である．
このときの温度は一定なので，

$$\Delta S_1 = \frac{\Delta H_{melt}}{T_0} = \frac{1436.3}{273} \approx 5.261 \text{ cal/(mol}\cdot\text{deg)}$$

### 2. 水の昇温によるエントロピー変化 ( $\Delta S_2$ )

0℃ ( $T_0 = 273$ K) から 100℃ ( $T_{100} = 373$ K) までの水の温度上昇を考える．
このときの熱容量を $C_p = 18.046$ cal/(deg $\cdot$ mol) とすると，微小な温度変化 $dT$ に対して加えられる熱量は $dQ = C_p dT$ である．

$$\Delta S_2 = \int_{T_0}^{T_{100}} \frac{C_p dT}{T} = C_p \ln\left(\frac{T_{100}}{T_0}\right)$$

数値を代入すると，

$$\Delta S_2 = 18.046 \times \ln\left(\frac{373}{273}\right) \approx 18.046 \times 0.3121 \approx 5.632 \text{ cal/(mol}\cdot\text{deg)}$$

### 3. 水の蒸発によるエントロピー変化 ( $\Delta S_3$ )

100℃ ( $T_{100} = 373$ K) における水の蒸発熱 $\Delta H_{evap} = 9717.1$ cal/mol は，等温過程における熱量 $Q = \Delta H_{evap}$ である．

$$\Delta S_3 = \frac{\Delta H_{evap}}{T_{100}} = \frac{9717.1}{373} \approx 26.051 \text{ cal/(mol}\cdot\text{deg)}$$

### 合計のエントロピー変化 ( $\Delta S$ )

全体の変化は，これら3つのステップの和となる．

$$\Delta S = \Delta S_1 + \Delta S_2 + \Delta S_3$$

$$\Delta S \approx 5.261 + 5.632 + 26.051 = 36.944 \text{ cal/(mol}\cdot\text{deg)}$$

小数点第1位まで求めると，

$$\Delta S \approx 36.9 \text{ cal/(mol}\cdot\text{deg)}$$

## 解説

### 1. エントロピーとは何か？

エントロピー ( $S$ ) は，系の「乱雑さ」や「エネルギーの分散具合」を表す物理量である．
熱力学において，ある状態から別の状態へ変化する際，その過程でやり取りされる熱量 $Q$ と，その時の絶対温度 $T$ の比 $\frac{Q}{T}$ を積み重ねたものとして定義される．

### 2. なぜ「道筋」を分けて考えるのか？

エントロピーは「状態量」といわれる性質を持っており，最終的な状態（ここでは0℃の氷と100℃の水蒸気）が決まっていれば，どのような経路を通っても変化量は同じになる．
しかし，計算を簡単にするために，物理現象として自然な「融解 $\to$ 昇温 $\to$ 蒸発」というステップに分割して計算するのが一般的である．

### 3. 各ステップの計算のポイント

* **相転移（融解・蒸発）** :
  温度が変わらずに状態だけが変わる過程（等温過程）では，温度 $T$ が一定であるため，積分 $\int \frac{dQ}{T}$ は単に $\frac{Q}{T}$ となる．
  ここで $Q$ は相転移に伴う熱量（潜熱）である．

* **温度変化（昇温）** :
  温度が変化する場合，分母の $T$ が常に変わっていくため，積分が必要である．
  熱容量 $C_p$ が一定であると仮定すると， $\int \frac{C_p dT}{T} = C_p \ln(T_{final}/T_{initial})$ という形になる．
  ここで $\ln$ は自然対数である．

### 4. 単位について

この問題では単位として "cal/(deg mol)" が使われている．
これは "cal/(K $\cdot$ mol)" と同じ意味である（温度差 $1 \text{ deg} = 1 \text{ K}$ であるため）．
