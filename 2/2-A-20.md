# 演習問題【2-A-20】

## 解答

求めるエントロピー差は，

```math
\Delta S=S_v-S_i
```

である．
ここで， $S_i$ は $0^\circ\mathrm{C}$ ，1 atm の氷1 molのエントロピー， $S_v$ は $100^\circ\mathrm{C}$ ，1 atm の水蒸気1 molのエントロピーである．

エントロピーは状態量であるため，初期状態から最終状態までの変化を，計算しやすい準静的かつ可逆な経路に分けて求めてよい．
そこで，次の3段階を考える．

1. $0^\circ\mathrm{C}$ で氷を融解して水にする．
2. 水を $0^\circ\mathrm{C}$ から $100^\circ\mathrm{C}$ まで加熱する．
3. $100^\circ\mathrm{C}$ で水を蒸発させて水蒸気にする．

各段階のエントロピー変化を求め，最後に合計する．

### 1．氷の融解によるエントロピー変化

氷の融解熱は，

```math
\Delta H_{\mathrm{melt}}=1436.3\ \mathrm{cal/mol}
```

であり，融解温度は $0^\circ\mathrm{C}$ である．
絶対温度に直すと，

```math
T_0=273.15\ \mathrm{K}
```

となる．

融解を可逆的に行うと，温度が一定であるため，エントロピー変化は吸収熱量を温度で割ったものとなる．
圧力一定の相転移では，吸収熱量は融解エンタルピーに等しいから，

```math
\begin{aligned}
\Delta S_1
&=\frac{\Delta H_{\mathrm{melt}}}{T_0}\\
&=\frac{1436.3}{273.15}\\
&\simeq5.258\ \mathrm{cal/(mol\cdot K)}
\end{aligned}
```

を得る．

### 2．水の昇温によるエントロピー変化

次に，水を $0^\circ\mathrm{C}$ から $100^\circ\mathrm{C}$ まで，圧力1 atmで加熱する．温度は，

```math
T_0=273.15\ \mathrm{K},
\qquad
T_{100}=373.15\ \mathrm{K}
```

の間で変化する．

問題文で与えられた水の平均定圧モル熱容量を，

```math
C_p=18.046\ \mathrm{cal/(mol\cdot K)}
```

とする．
これを温度範囲内で一定と近似する．
微小な温度上昇 $dT$ に対して吸収する熱量は，

```math
\delta Q_{\mathrm{rev}}=C_p\,dT
```

である．
したがって，エントロピー変化は，

```math
\begin{aligned}
\Delta S_2
&=\int_{T_0}^{T_{100}}\frac{\delta Q_{\mathrm{rev}}}{T}\\
&=\int_{T_0}^{T_{100}}\frac{C_p}{T}\,dT\\
&=C_p\ln\frac{T_{100}}{T_0}
\end{aligned}
```

となる．
数値を代入すると，

```math
\begin{aligned}
\Delta S_2
&=18.046\ln\frac{373.15}{273.15}\\
&\simeq18.046\times0.31196\\
&\simeq5.630\ \mathrm{cal/(mol\cdot K)}
\end{aligned}
```

を得る．

### 3．水の蒸発によるエントロピー変化

水の蒸発熱は，

```math
\Delta H_{\mathrm{vap}}=9717.1\ \mathrm{cal/mol}
```

であり，蒸発温度は $100^\circ\mathrm{C}$ ，すなわち，

```math
T_{100}=373.15\ \mathrm{K}
```

である．
この相転移も一定温度で起こるため，蒸発によるエントロピー変化は，

```math
\begin{aligned}
\Delta S_3
&=\frac{\Delta H_{\mathrm{vap}}}{T_{100}}\\
&=\frac{9717.1}{373.15}\\
&\simeq26.041\ \mathrm{cal/(mol\cdot K)}
\end{aligned}
```

となる．

### 4．全エントロピー変化

エントロピーは状態量であるため，初期状態から最終状態への全変化は，3段階のエントロピー変化の和である．
したがって，

```math
\Delta S=\Delta S_1+\Delta S_2+\Delta S_3
```

となる．
各値を代入すると，

```math
\begin{aligned}
\Delta S
&\simeq5.258+5.630+26.041\\
&\simeq36.929\ \mathrm{cal/(mol\cdot K)}
\end{aligned}
```

を得る．
よって，求めるエントロピー差は，

```math
\boxed{
S_v-S_i\simeq36.9\ \mathrm{cal/(mol\cdot K)}
}
```

である．
有効数字や温度の近似を考慮すれば，約 $37\ \mathrm{cal/(mol\cdot K)}$ と表せる．
