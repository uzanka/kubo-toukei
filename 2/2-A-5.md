# 演習問題【2-A-5】

## 解答

### 準備：理想気体の基本関係式

以下では，気体が外部にする仕事を正，気体が外部から吸収する熱量を正とする．
また，断熱過程は可逆断熱過程，すなわち等エントロピー過程であると仮定する．

気体の内部エネルギーの変化を $\Delta U$ ，吸収熱量を $Q$ ，気体が外部にする仕事を $W$ とすると，熱力学第1法則は

```math
\Delta U=Q-W
```

である．

循環過程では，気体は元の状態に戻るため，

```math
\Delta U=0
```

となる．
したがって，サイクル全体について，

```math
W=Q_{\mathrm{in}}-Q_{\mathrm{out}}
```

が成り立つ．
ここで， $Q_{\mathrm{in}}$ は気体が吸収する熱量の総量， $Q_{\mathrm{out}}$ は気体が放出する熱量の総量であり，いずれも正の量とする．

熱機関の効率は，吸収した熱量のうち仕事に変換された割合であるから，

```math
\eta=\frac{W}{Q_{\mathrm{in}}}
=1-\frac{Q_{\mathrm{out}}}{Q_{\mathrm{in}}}
\tag{1}
```

である．

理想気体の内部エネルギー変化は，

```math
\Delta U=C_v\Delta T
```

と表される．
したがって，断熱過程では $Q=0$ なので，

```math
W=-\Delta U
=C_v(T_{\mathrm{始}}-T_{\mathrm{終}})
\tag{2}
```

となる．

等積過程では体積が変化しないため，仕事はゼロであり，

```math
Q=C_v\Delta T
```

である．
一方，等圧過程では，

```math
Q=C_p\Delta T,\qquad W=p\Delta V
```

が成り立つ．

理想気体の状態方程式とマイヤーの関係式

```math
pV=nRT,\qquad C_p-C_v=nR
```

より，

```math
pV=(C_p-C_v)T
=(\gamma-1)C_vT
\tag{3}
```

を得る．

さらに，可逆断熱過程では，

```math
TV^{\gamma-1}=\text{const.}
\tag{4}
```

が成り立つ．
これと理想気体の状態方程式から，

```math
Tp^{(1-\gamma)/\gamma}=\text{const.}
\tag{5}
```

も得られる．

以下では，各サイクルの順方向を

```math
a\to b\to c\to d\to a
```

とする．


### (i) Otto サイクル

#### 1．各過程と熱量

Otto サイクルは，2つの可逆断熱過程と2つの等積過程からなる．

- $a\to b$ ： 断熱圧縮．体積は $V_1$ から $V_2$ に減少する．
- $b\to c$ ： 等積加熱．体積 $V_2$ を一定に保つ．
- $c\to d$ ： 断熱膨張．体積は $V_2$ から $V_1$ に増加する．
- $d\to a$ ： 等積冷却．体積 $V_1$ を一定に保つ．

ここで $V_2<V_1$ とする．
各状態の温度を $T_a,T_b,T_c,T_d$ と表す．

熱を吸収するのは等積過程 $b\to c$ のみなので，

```math
Q_{\mathrm{in}}=C_v(T_c-T_b)
\tag{6}
```

である．

熱を放出するのは等積過程 $d\to a$ のみなので，

```math
Q_{\mathrm{out}}=C_v(T_d-T_a)
\tag{7}
```

である．

式 (1)，(6)，(7) より，

```math
\begin{aligned}
\eta
&=1-\frac{Q_{\mathrm{out}}}{Q_{\mathrm{in}}}\\
&=1-\frac{C_v(T_d-T_a)}{C_v(T_c-T_b)}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\eta=1-\frac{T_d-T_a}{T_c-T_b}
}
\tag{8}
```

を得る．

#### 2．断熱関係を用いた温度差の変形

断熱圧縮 $a\to b$ に式 (4) を適用すると，

```math
T_aV_1^{\gamma-1}
=T_bV_2^{\gamma-1}
```

となる．
よって，

```math
\frac{T_a}{T_b}
=\left(\frac{V_2}{V_1}\right)^{\gamma-1}
\tag{9}
```

である．

同様に，断熱膨張 $c\to d$ について，

```math
T_cV_2^{\gamma-1}
=T_dV_1^{\gamma-1}
```

であるから，

```math
\frac{T_d}{T_c}
=\left(\frac{V_2}{V_1}\right)^{\gamma-1}
\tag{10}
```

を得る．

ここで，

```math
r=\left(\frac{V_2}{V_1}\right)^{\gamma-1}
```

と置けば，

```math
T_a=rT_b,\qquad T_d=rT_c
```

となる．
したがって，

```math
T_d-T_a=r(T_c-T_b)
```

であり，

```math
\frac{T_d-T_a}{T_c-T_b}
=r
=\left(\frac{V_2}{V_1}\right)^{\gamma-1}
```

が成立する．

これを式 (8) に代入すると，

```math
\boxed{
\eta=1-\left(\frac{V_2}{V_1}\right)^{\gamma-1}
}
```

となる．
これが Otto サイクルの効率である．


### (ii) Joule サイクル

#### 1．各過程と熱量

Joule サイクルは，2つの可逆断熱過程と2つの等圧過程からなる．

- $a\to b$ ： 断熱圧縮．圧力は $p_1$ から $p_2$ に上昇する．
- $b\to c$ ： 等圧加熱．圧力 $p_2$ を一定に保ちながら膨張する．
- $c\to d$ ： 断熱膨張．圧力は $p_2$ から $p_1$ に低下する．
- $d\to a$ ： 等圧冷却．圧力 $p_1$ を一定に保ちながら圧縮する．

各状態の温度を $T_a,T_b,T_c,T_d$ とする．

等圧加熱 $b\to c$ で熱を吸収するため，

```math
Q_{\mathrm{in}}=C_p(T_c-T_b)
\tag{11}
```

である．

等圧冷却 $d\to a$ で熱を放出するため，

```math
Q_{\mathrm{out}}=C_p(T_d-T_a)
\tag{12}
```

である．

式 (1)，(11)，(12) より，

```math
\begin{aligned}
\eta
&=1-\frac{Q_{\mathrm{out}}}{Q_{\mathrm{in}}}\\
&=1-\frac{C_p(T_d-T_a)}{C_p(T_c-T_b)}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\eta=1-\frac{T_d-T_a}{T_c-T_b}
}
\tag{13}
```

を得る．

#### 2．断熱関係を用いた温度差の変形

断熱圧縮 $a\to b$ に式 (5) を適用すると，

```math
T_ap_1^{(1-\gamma)/\gamma}
=T_bp_2^{(1-\gamma)/\gamma}
```

である．

整理すると，

```math
\frac{T_a}{T_b}
=\left(\frac{p_1}{p_2}\right)^{(\gamma-1)/\gamma}
\tag{14}
```

となる．

同様に，断熱膨張 $c\to d$ について，

```math
T_cp_2^{(1-\gamma)/\gamma}
=T_dp_1^{(1-\gamma)/\gamma}
```

であるから，

```math
\frac{T_d}{T_c}
=\left(\frac{p_1}{p_2}\right)^{(\gamma-1)/\gamma}
\tag{15}
```

を得る．

ここで，

```math
r=\left(\frac{p_1}{p_2}\right)^{(\gamma-1)/\gamma}
```

と置けば，

```math
T_a=rT_b,\qquad T_d=rT_c
```

となる．
したがって，

```math
T_d-T_a=r(T_c-T_b)
```

であり，

```math
\frac{T_d-T_a}{T_c-T_b}
=\left(\frac{p_1}{p_2}\right)^{(\gamma-1)/\gamma}
```

が成立する．

これを式 (13) に代入すると，

```math
\boxed{
\eta=1-\left(\frac{p_1}{p_2}\right)^{(\gamma-1)/\gamma}
}
```

となる．
これが Joule サイクルの効率である．


### (iii) Diesel サイクル

#### 1．各過程と熱量

Diesel サイクルは，2つの可逆断熱過程，1つの等圧過程，1つの等積過程からなる．

- $a\to b$ ： 断熱圧縮．体積は $V_1$ から $V_3$ に減少する．
- $b\to c$ ： 等圧加熱．圧力 $p_2$ を一定に保ちながら，体積は $V_3$ から $V_2$ に増加する．
- $c\to d$ ： 断熱膨張．体積は $V_2$ から $V_1$ に増加する．
- $d\to a$ ： 等積冷却．体積 $V_1$ を一定に保つ．

体積の関係は，

```math
V_3<V_2<V_1
```

である．
各状態の温度を $T_a,T_b,T_c,T_d$ とする．

熱を吸収するのは等圧過程 $b\to c$ のみなので，

```math
Q_{\mathrm{in}}=C_p(T_c-T_b)
=\gamma C_v(T_c-T_b)
\tag{16}
```

である．

熱を放出するのは等積過程 $d\to a$ のみなので，

```math
Q_{\mathrm{out}}=C_v(T_d-T_a)
\tag{17}
```

である．

式 (1)，(16)，(17) より，

```math
\begin{aligned}
\eta
&=1-\frac{Q_{\mathrm{out}}}{Q_{\mathrm{in}}}\\
&=1-\frac{C_v(T_d-T_a)}
{\gamma C_v(T_c-T_b)}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\eta=1-\frac{1}{\gamma}
\frac{T_d-T_a}{T_c-T_b}
}
\tag{18}
```

を得る．

#### 2．温度差の比を体積比で表す

等圧加熱過程 $b\to c$ では，理想気体の状態方程式から，

```math
\frac{T_c}{T_b}=\frac{V_2}{V_3}
```

が成立する．
よって，

```math
T_b=T_c\frac{V_3}{V_2}
\tag{19}
```

である．

断熱圧縮 $a\to b$ に式 (4) を適用すると，

```math
T_aV_1^{\gamma-1}
=T_bV_3^{\gamma-1}
```

であるため，

```math
T_a=T_b\left(\frac{V_3}{V_1}\right)^{\gamma-1}
\tag{20}
```

となる．

また，断熱膨張 $c\to d$ について，

```math
T_cV_2^{\gamma-1}
=T_dV_1^{\gamma-1}
```

であるから，

```math
T_d=T_c\left(\frac{V_2}{V_1}\right)^{\gamma-1}
\tag{21}
```

を得る．

式 (19)～(21) を用いて温度差の比を変形すると，

```math
\begin{aligned}
\frac{T_d-T_a}{T_c-T_b}
&=
\frac{
\left(\dfrac{V_2}{V_1}\right)^{\gamma-1}
-\dfrac{V_3}{V_2}
\left(\dfrac{V_3}{V_1}\right)^{\gamma-1}
}{
1-\dfrac{V_3}{V_2}
}.
\end{aligned}
```

分子と分母に $V_2$ を掛けると，

```math
\begin{aligned}
\frac{T_d-T_a}{T_c-T_b}
&=
\frac{
V_2\left(\dfrac{V_2}{V_1}\right)^{\gamma-1}
-
V_3\left(\dfrac{V_3}{V_1}\right)^{\gamma-1}
}{
V_2-V_3
}\\
&=
\frac{
\dfrac{V_2^\gamma}{V_1^{\gamma-1}}
-\dfrac{V_3^\gamma}{V_1^{\gamma-1}}
}{
V_2-V_3
}\\
&=
\frac{V_2^\gamma-V_3^\gamma}
{V_1^{\gamma-1}(V_2-V_3)}.
\end{aligned}
```

分子と分母を $V_1^\gamma$ で規格化すれば，

```math
\boxed{
\frac{T_d-T_a}{T_c-T_b}
=
\frac{
\left(\dfrac{V_2}{V_1}\right)^\gamma
-
\left(\dfrac{V_3}{V_1}\right)^\gamma
}{
\left(\dfrac{V_2}{V_1}\right)
-
\left(\dfrac{V_3}{V_1}\right)
}
}
\tag{22}
```

を得る．

式 (22) を式 (18) に代入すると，

```math
\boxed{
\eta
=1-\frac{1}{\gamma}
\frac{
\left(\dfrac{V_2}{V_1}\right)^\gamma
-
\left(\dfrac{V_3}{V_1}\right)^\gamma
}{
\left(\dfrac{V_2}{V_1}\right)
-
\left(\dfrac{V_3}{V_1}\right)
}
}
```

となる．
これが Diesel サイクルの効率である．


### 結論

可逆断熱過程を含む理想気体の標準的な熱機関サイクルについて，熱力学第1法則と各過程の状態関係を用いると，効率は次のように求められる．

**(i) Otto サイクル**

```math
\boxed{
\eta=1-\left(\frac{V_2}{V_1}\right)^{\gamma-1}
}
```

**(ii) Joule サイクル**

```math
\boxed{
\eta=1-\left(\frac{p_1}{p_2}\right)^{(\gamma-1)/\gamma}
}
```

**(iii) Diesel サイクル**

```math
\boxed{
\eta
=1-\frac{1}{\gamma}
\frac{
\left(\dfrac{V_2}{V_1}\right)^\gamma
-
\left(\dfrac{V_3}{V_1}\right)^\gamma
}{
\left(\dfrac{V_2}{V_1}\right)
-
\left(\dfrac{V_3}{V_1}\right)
}
}
```

いずれの導出も，吸収熱量と放出熱量から効率を表し，断熱関係式を用いて温度差の比を体積比または圧力比で表すという共通の手順に基づいている．

**注意：** 上記の効率公式は，順方向の熱機関サイクル $a\to b\to c\to d\to a$ に対するものである．
問題文の図の説明にある逆向きの矢印 $a\to d\to c\to b\to a$ を維持する場合，サイクルは逆運転となるため，同じ式をそのまま熱機関効率として用いることはできない．
