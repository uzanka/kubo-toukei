# 演習問題【2-A-5】

## 解答

### 準備：理想気体の基本関係式

以下では， $C_v$ と $C_p$ は一定量の理想気体全体の定積熱容量と定圧熱容量であり，

```math
\gamma=\frac{C_p}{C_v}
```

とする．
また，気体が外部にする仕事を正，気体が外部から吸収する熱量を正とする．

熱力学第1法則は，気体の内部エネルギーの変化を $\Delta U$ ，吸収熱量を $Q$ ，気体が外部にする仕事を $W$ とすると，

```math
\Delta U=Q-W
```

と表される．
気体が循環過程を行うと，元の状態に戻るため，内部エネルギーの変化はゼロである．
したがって，

```math
W=Q_{\mathrm{in}}-Q_{\mathrm{out}}
```

となる．
ここで， $Q_{\mathrm{in}}$ は気体が吸収する熱量の総量， $Q_{\mathrm{out}}$ は気体が外部へ放出する熱量の総量であり，どちらも正の量として定義する．
熱機関の効率は，吸収熱量のうち仕事に変換される割合であるから，

```math
\eta=\frac{W}{Q_{\mathrm{in}}}
=1-\frac{Q_{\mathrm{out}}}{Q_{\mathrm{in}}}
```

である．

さらに，理想気体では，内部エネルギーの変化は

```math
\Delta U=C_v\Delta T
```

である．
断熱過程では熱の授受がないため $Q=0$ であり，気体が外部にする仕事は

```math
W=-\Delta U=C_v(T_{\mathrm{始}}-T_{\mathrm{終}})
```

となる．
等積過程では体積が変化しないため仕事はゼロであり，吸収熱量は $C_v\Delta T$ である．
等圧過程で吸収する熱量は $C_p\Delta T$ ，気体が外部にする仕事は $p\Delta V$ である．
また，理想気体の状態方程式と Mayer の関係 $C_p-C_v=nR$ より，

```math
pV=nRT=(C_p-C_v)T
=(\gamma-1)C_vT
\tag{1}
```

が成立する．

断熱過程では，さらに次の関係式が成立する．

```math
TV^{\gamma-1}=\text{const.}
\tag{2}
```

また，理想気体の状態方程式と組み合わせると，

```math
Tp^{(1-\gamma)/\gamma}=\text{const.}
\tag{3}
```

も得られる．
これらを用いて各サイクルの効率を導出する．

なお，以下では解答例に従い，各サイクルの経路を $a\to b\to c\to d\to a$ とする．
問題文の「図の説明」に記載された矢印は，この経路と一致するように訂正する必要がある．

### (i) Otto サイクル

#### 1．各過程の整理

Otto サイクルは，2つの断熱過程と2つの等積過程からなる．
各過程は次のとおりである．

- $a\to b$ ： 断熱圧縮過程．体積は $V_1$ から $V_2$ に減少する．
- $b\to c$ ： 等積加熱過程．体積 $V_2$ を一定に保ち，気体が熱を吸収する．
- $c\to d$ ： 断熱膨張過程．体積は $V_2$ から $V_1$ に増加する．
- $d\to a$ ： 等積冷却過程．体積 $V_1$ を一定に保ち，気体が熱を放出する．

ここで， $V_2<V_1$ である．各状態の温度をそれぞれ $T_a,T_b,T_c,T_d$ とする．

#### 2．仕事と吸収熱量

等積過程 $b\to c$ と $d\to a$ では体積が変化しないため，気体が外部にする仕事はゼロである．

断熱圧縮過程 $a\to b$ で気体が外部にする仕事は，

```math
W_{a\to b}=C_v(T_a-T_b)
```

である．
圧縮により温度が上昇するため，この仕事は負となる．
一方，断熱膨張過程 $c\to d$ で気体が外部にする仕事は，

```math
W_{c\to d}=C_v(T_c-T_d)
```

である．
したがって，サイクル全体の正味の仕事は，

```math
\begin{aligned}
W
&=C_v(T_a-T_b)+C_v(T_c-T_d)\\
&=C_v\{(T_c-T_b)-(T_d-T_a)\}
\end{aligned}
\tag{4}
```

となる．

気体が外部から熱を吸収するのは等積加熱過程 $b\to c$ のみである．
したがって，

```math
Q_{\mathrm{in}}=C_v(T_c-T_b)
\tag{5}
```

である．
式 (4)，(5) より，効率は

```math
\begin{aligned}
\eta
&=\frac{W}{Q_{\mathrm{in}}}\\
&=1-\frac{T_d-T_a}{T_c-T_b}
\end{aligned}
\tag{6}
```

と表される．

#### 3．温度差の比を体積比で表す

断熱過程 $a\to b$ に式 (2) を適用すると，

```math
T_aV_1^{\gamma-1}
=T_bV_2^{\gamma-1}
```

であるから，

```math
\frac{T_a}{T_b}
=\left(\frac{V_2}{V_1}\right)^{\gamma-1}
\tag{7}
```

となる．
同様に，断熱過程 $c\to d$ について，

```math
T_cV_2^{\gamma-1}
=T_dV_1^{\gamma-1}
```

であるから，

```math
\frac{T_d}{T_c}
=\left(\frac{V_2}{V_1}\right)^{\gamma-1}
\tag{8}
```

となる．

式 (7)，(8) の右辺を

```math
r=\left(\frac{V_2}{V_1}\right)^{\gamma-1}
```

とおくと，

```math
T_a=rT_b,\qquad T_d=rT_c
```

である．
したがって，

```math
T_d-T_a=r(T_c-T_b)
```

となり，

```math
\frac{T_d-T_a}{T_c-T_b}
=r
=\left(\frac{V_2}{V_1}\right)^{\gamma-1}
```

を得る．
これを式 (6) に代入すると，

```math
\boxed{
\eta
=1-\left(\frac{V_2}{V_1}\right)^{\gamma-1}
}
```

となる．
これが Otto サイクルの効率である．

### (ii) Joule サイクル

#### 1．各過程の整理

Joule サイクルは，2つの断熱過程と2つの等圧過程からなる．
各過程は次のとおりである．

- $a\to b$ ： 断熱圧縮過程．圧力は $p_1$ から $p_2$ に上昇する．
- $b\to c$ ： 等圧加熱過程．圧力 $p_2$ を一定に保ち，気体が膨張しながら熱を吸収する．
- $c\to d$ ： 断熱膨張過程．圧力は $p_2$ から $p_1$ に低下する．
- $d\to a$ ： 等圧冷却過程．圧力 $p_1$ を一定に保ち，気体が圧縮されながら熱を放出する．

各状態の温度を $T_a,T_b,T_c,T_d$ とする．

#### 2．仕事と吸収熱量

断熱過程 $a\to b$ と $c\to d$ で気体が外部にする仕事は，

```math
W_{a\to b}=C_v(T_a-T_b)
```

および

```math
W_{c\to d}=C_v(T_c-T_d)
```

である．

等圧過程 $b\to c$ の仕事は，式 (1) より，

```math
\begin{aligned}
W_{b\to c}
&=p_2(V_c-V_b)\\
&=(\gamma-1)C_v(T_c-T_b)
\end{aligned}
```

である．
一方，等圧過程 $d\to a$ の仕事は，

```math
\begin{aligned}
W_{d\to a}
&=p_1(V_a-V_d)\\
&=(\gamma-1)C_v(T_a-T_d)
\end{aligned}
```

である．

したがって，正味の仕事は，

```math
\begin{aligned}
W={}&C_v\{(T_a-T_b)+(T_c-T_d)\}\\
&+(\gamma-1)C_v\{(T_c-T_b)+(T_a-T_d)\}
\end{aligned}
```

となる．
ここで，

```math
(T_a-T_b)+(T_c-T_d)
=(T_c-T_b)+(T_a-T_d)
```

であるから，

```math
\begin{aligned}
W
&=\gamma C_v\{(T_c-T_b)+(T_a-T_d)\}\\
&=C_p\{(T_c-T_b)-(T_d-T_a)\}
\end{aligned}
\tag{9}
```

を得る．

気体が熱を吸収するのは等圧過程 $b\to c$ のみであり，

```math
Q_{\mathrm{in}}=C_p(T_c-T_b)
\tag{10}
```

である．
よって，式 (9)，(10) から，

```math
\eta
=1-\frac{T_d-T_a}{T_c-T_b}
\tag{11}
```

となる．

#### 3．温度差の比を圧力比で表す

式 (3) を断熱過程 $a\to b$ に適用すると，

```math
T_ap_1^{(1-\gamma)/\gamma}
=T_bp_2^{(1-\gamma)/\gamma}
```

である．
これを整理すると，

```math
\frac{T_a}{T_b}
=\left(\frac{p_1}{p_2}\right)^{(\gamma-1)/\gamma}
\tag{12}
```

となる．
同様に，断熱過程 $c\to d$ について，

```math
T_cp_2^{(1-\gamma)/\gamma}
=T_dp_1^{(1-\gamma)/\gamma}
```

であるから，

```math
\frac{T_d}{T_c}
=\left(\frac{p_1}{p_2}\right)^{(\gamma-1)/\gamma}
\tag{13}
```

となる．

式 (12)，(13) の右辺を

```math
r=\left(\frac{p_1}{p_2}\right)^{(\gamma-1)/\gamma}
```

とおくと，

```math
T_a=rT_b,\qquad T_d=rT_c
```

である．
したがって，

```math
T_d-T_a=r(T_c-T_b)
```

となり，

```math
\frac{T_d-T_a}{T_c-T_b}
=\left(\frac{p_1}{p_2}\right)^{(\gamma-1)/\gamma}
```

を得る．
これを式 (11) に代入すれば，

```math
\boxed{
\eta
=1-\left(\frac{p_1}{p_2}\right)^{(\gamma-1)/\gamma}
}
```

となる．
これが Joule サイクルの効率である．

### (iii) Diesel サイクル

#### 1．各過程の整理

Diesel サイクルは，2つの断熱過程，1つの等圧過程，1つの等積過程からなる．
各過程は次のとおりである．

- $a\to b$ ： 断熱圧縮過程．体積は $V_1$ から $V_3$ に減少する．
- $b\to c$ ： 等圧加熱過程．圧力 $p_2$ を一定に保ち，体積は $V_3$ から $V_2$ に増加する．気体は熱を吸収する．
- $c\to d$ ： 断熱膨張過程．体積は $V_2$ から $V_1$ に増加する．
- $d\to a$ ： 等積冷却過程．体積 $V_1$ を一定に保ち，気体が熱を放出する．

体積の関係は，

```math
V_3<V_2<V_1
```

である．
各状態の温度を $T_a,T_b,T_c,T_d$ とする．

#### 2．仕事と吸収熱量

断熱過程 $a\to b$ と $c\to d$ で気体が外部にする仕事は，

```math
W_{a\to b}=C_v(T_a-T_b)
```

および

```math
W_{c\to d}=C_v(T_c-T_d)
```

である．

等圧加熱過程 $b\to c$ の仕事は，

```math
\begin{aligned}
W_{b\to c}
&=p_2(V_2-V_3)\\
&=(\gamma-1)C_v(T_c-T_b)
\end{aligned}
```

である．
等積過程 $d\to a$ では体積が変化しないため，仕事はゼロである．

したがって，サイクル全体の正味の仕事は，

```math
\begin{aligned}
W={}&C_v\{(T_a-T_b)+(T_c-T_d)\}\\
&+(\gamma-1)C_v(T_c-T_b)
\end{aligned}
```

となる．
整理すると，

```math
\boxed{
W=C_v\{\gamma(T_c-T_b)-(T_d-T_a)\}
}
\tag{14}
```

を得る．

気体が外部から熱を吸収するのは等圧加熱過程 $b\to c$ のみであるため，

```math
\begin{aligned}
Q_{\mathrm{in}}
&=C_p(T_c-T_b)\\
&=\gamma C_v(T_c-T_b)
\end{aligned}
\tag{15}
```

である．
式 (14)，(15) より，効率は，

```math
\eta
=1-\frac{1}{\gamma}
\frac{T_d-T_a}{T_c-T_b}
\tag{16}
```

となる．

#### 3．温度差の比を体積比で表す

まず，等圧過程 $b\to c$ では，理想気体の状態方程式より，

```math
\frac{T_c}{T_b}=\frac{V_2}{V_3}
```

が成立する．
したがって，

```math
T_b=T_c\frac{V_3}{V_2}
\tag{17}
```

である．

次に，断熱過程 $a\to b$ に式 (2) を適用すると，

```math
T_aV_1^{\gamma-1}
=T_bV_3^{\gamma-1}
```

であるから，

```math
T_a=T_b\left(\frac{V_3}{V_1}\right)^{\gamma-1}
\tag{18}
```

となる．
さらに，断熱過程 $c\to d$ について，

```math
T_cV_2^{\gamma-1}
=T_dV_1^{\gamma-1}
```

であるから，

```math
T_d=T_c\left(\frac{V_2}{V_1}\right)^{\gamma-1}
\tag{19}
```

となる．

式 (17)～(19) を用いて，式 (16) に含まれる温度差の比を変形する．
まず，式 (17)～(19) より，

```math
\begin{aligned}
\frac{T_d-T_a}{T_c-T_b}
&=
\frac{
\left(\dfrac{V_2}{V_1}\right)^{\gamma-1}
-\dfrac{V_3}{V_2}
\left(\dfrac{V_3}{V_1}\right)^{\gamma-1}
}{
1-\dfrac{V_3}{V_2}
}
\end{aligned}
```

を得る．
ここで，分子と分母に $V_2$ を掛けると，

```math
\begin{aligned}
\frac{T_d-T_a}{T_c-T_b}
&=
\frac{
V_2\left(\dfrac{V_2}{V_1}\right)^{\gamma-1}
-
V_3\left(\dfrac{V_3}{V_1}\right)^{\gamma-1}
}{
V_2-V_3
}\\
&=
\frac{
\dfrac{V_2^\gamma}{V_1^{\gamma-1}}
-
\dfrac{V_3^\gamma}{V_1^{\gamma-1}}
}{
V_2-V_3
}\\
&=
\frac{V_2^\gamma-V_3^\gamma}
{V_1^{\gamma-1}(V_2-V_3)}
\end{aligned}
```

となる．

ここで，分子と分母を $V_1^\gamma$ で規格化すると，

```math
\boxed{
\frac{T_d-T_a}{T_c-T_b}
=
\frac{
\left(\dfrac{V_2}{V_1}\right)^\gamma
-
\left(\dfrac{V_3}{V_1}\right)^\gamma
}{
\left(\dfrac{V_2}{V_1}\right)
-
\left(\dfrac{V_3}{V_1}\right)
}
}
\tag{20}
```

を得る．

式 (20) を式 (16) に代入すると，

```math
\boxed{
\eta
=1-\frac{1}{\gamma}
\frac{
\left(\dfrac{V_2}{V_1}\right)^\gamma
-
\left(\dfrac{V_3}{V_1}\right)^\gamma
}{
\left(\dfrac{V_2}{V_1}\right)
-
\left(\dfrac{V_3}{V_1}\right)
}
}
```

となる．
これが Diesel サイクルの効率である．

### 結論

以上より，理想気体が行う3種類の準静的循環過程の効率は，それぞれ次のように求められた．

**(i) Otto サイクル**

```math
\boxed{
\eta=1-\left(\frac{V_2}{V_1}\right)^{\gamma-1}
}
```

**(ii) Joule サイクル**

```math
\boxed{
\eta=1-\left(\frac{p_1}{p_2}\right)^{(\gamma-1)/\gamma}
}
```

**(iii) Diesel サイクル**

```math
\boxed{
\eta
=1-\frac{1}{\gamma}
\frac{
\left(\dfrac{V_2}{V_1}\right)^\gamma
-
\left(\dfrac{V_3}{V_1}\right)^\gamma
}{
\left(\dfrac{V_2}{V_1}\right)
-
\left(\dfrac{V_3}{V_1}\right)
}
}
```

いずれの場合も，効率の導出は，まず熱力学第1法則と各過程の性質から正味の仕事および吸収熱量を求め，次に断熱過程の関係式を用いて温度差の比を体積比または圧力比に変換するという，同一の考え方に基づいている．
