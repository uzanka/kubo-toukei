# 演習問題【2-A-5】

## 解答

ここでは，理想気体の状態方程式 $pV = nRT$ および，断熱過程における関係式 $TV^{\gamma-1} = \text{const.}$ （または $pV^\gamma = \text{const.}$ ）を用いて，それぞれのサイクルの効率 $\eta = W/Q$ を導出する．
ここで， $W$ はサイクルが外部に対して行う正味の仕事， $Q$ はサイクルが外部から吸収する熱量である．

### (i) Otto サイクル

**1. 過程の整理**

図(a)の Otto サイクルは，以下の 4 つの過程からなる．
- $a \to b$ : 断熱圧縮過程（体積 $V_1 \to V_2$ で減少）．
- $b \to c$ : 等容加熱過程（体積 $V_2$ で一定）．
  外部から熱を吸収する．
- $c \to d$ : 断熱膨張過程（体積 $V_2 \to V_1$ で増加）．
- $d \to a$ : 等容冷却過程（体積 $V_1$ で一定）．
  外部へ熱を放出する．

Otto サイクルは「断熱×2＋等容×2」で構成される．
ここで，圧縮後の体積 $V_2$ は圧縮前の体積 $V_1$ より小さい （ $V_2 < V_1$ ）．

**2. 仕事 $W$ と熱量 $Q$ の計算**

正味の仕事 $W$ は各過程での仕事の総和である．
- $b \to c, d \to a$ は等容過程なので，仕事は $0$ である．
- $a \to b$ は断熱圧縮なので，気体が外になす仕事は内部エネルギーの減少に等しい：
  $$W_{a \to b} = C_v(T_a - T_b)$$
- $c \to d$ は断熱膨張なので，同様に：
  $$W_{c \to d} = C_v(T_c - T_d)$$

これらを合計すると，

$$W = C_v(T_a - T_b + T_c - T_d) = C_v\{(T_c - T_b) - (T_d - T_a)\}$$

となる．

一方，気体が熱を受け取るのは $b \to c$ の等容過程のみである：
$$Q = Q_{b \to c} = C_v(T_c - T_b)$$

ゆえに効率 $\eta$ は，

$$\eta = \frac{W}{Q} = 1 - \frac{T_d - T_a}{T_c - T_b}$$

**3. 温度比の変換**

断熱過程の条件 $TV^{\gamma-1} = \text{const.}$ を用いる．
- 過程 $a \to b$ （断熱圧縮）より， $T_a V_1^{\gamma-1} = T_b V_2^{\gamma-1}$ ，つまり $\displaystyle \frac{T_b}{T_a} = \left(\frac{V_1}{V_2}\right)^{\gamma-1}$
- 過程 $c \to d$ （断熱膨張）より， $T_c V_2^{\gamma-1} = T_d V_1^{\gamma-1}$ ，つまり $\displaystyle \frac{T_c}{T_d} = \left(\frac{V_1}{V_2}\right)^{\gamma-1}$

両式から，
$$\frac{T_b}{T_a} = \frac{T_c}{T_d} = \left(\frac{V_1}{V_2}\right)^{\gamma-1}$$

つまり，
$$\frac{T_d}{T_c} = \frac{T_a}{T_b} = \left(\frac{V_2}{V_1}\right)^{\gamma-1}$$

等比の性質（ $\displaystyle \frac{x}{y} = \frac{z}{w} \implies \frac{x - z}{y - w} = \frac{x}{y}$ ）より，
$$\frac{T_d - T_a}{T_c - T_b} = \frac{T_d}{T_c} = \left(\frac{V_2}{V_1}\right)^{\gamma-1}$$

よって，Otto サイクルの効率は，

$$\eta = 1 - \left(\frac{V_2}{V_1}\right)^{\gamma-1}$$

で与えられる．

### (ii) Joule サイクル

**1. 過程の整理**

Joule サイクル（ブレイプトンサイクル）は，以下の 4 つの過程からなる．
- $a \to b$ : 断熱圧縮過程（圧力 $p_1 \to p_2$ で増加）．
- $b \to c$ : 等圧膨張過程（圧力 $p_2$ で一定）．
  外部から熱を吸収する．
- $c \to d$ : 断熱膨張過程（圧力 $p_2 \to p_1$ で減少）．
- $d \to a$ : 等圧圧縮過程（圧力 $p_1$ で一定）．
  外部へ熱を放出する．

Joule サイクルは「断熱×2＋等圧×2」で構成され，等容過程は含まれない．

**2. 仕事 $W$ と熱量 $Q$ の計算**

正味の仕事 $W$ は各過程での仕事の総和である．
- $a \to b, c \to d$ は断熱過程なので，気体が外になす仕事は：
  $$W_{a \to b} = C_v(T_a - T_b), \quad W_{c \to d} = C_v(T_c - T_d)$$
- $b \to c$ は等圧過程なので，
  $$W_{b \to c} = p_2(V_c - V_b) = (\gamma - 1)C_v(T_c - T_b)$$
- $d \to a$ は等圧過程なので，
  $$W_{d \to a} = p_1(V_a - V_d) = (\gamma - 1)C_v(T_a - T_d)$$

これらを合計すると，

$$\begin{aligned} W &= C_v(T_a - T_b + T_c - T_d) + (\gamma - 1)C_v(T_c - T_b + T_a - T_d) \\ &= C_v\left[\gamma(T_a - T_b + T_c - T_d)\right] \\ &= C_p\{(T_c - T_b) - (T_d - T_a)\} \end{aligned}$$

一方，気体が熱を受け取るのは $b \to c$ の等圧過程のみである：
$$Q = Q_{b \to c} = C_p(T_c - T_b)$$

ゆえに効率 $\eta$ は，

$$\eta = \frac{W}{Q} = 1 - \frac{T_d - T_a}{T_c - T_b}$$

**3. 温度比の変換**

断熱過程の条件 $Tp^{(1-\gamma)/\gamma} = \text{const.}$ を用いる．
- 過程 $a \to b$ より， $T_a p_1^{(1-\gamma)/\gamma} = T_b p_2^{(1-\gamma)/\gamma}$ ，つまり $\displaystyle \frac{T_b}{T_a} = \left(\frac{p_2}{p_1}\right)^{\frac{\gamma-1}{\gamma}}$
- 過程 $c \to d$ より， $T_c p_2^{(1-\gamma)/\gamma} = T_d p_1^{(1-\gamma)/\gamma}$ ，つまり $\displaystyle \frac{T_c}{T_d} = \left(\frac{p_2}{p_1}\right)^{\frac{\gamma-1}{\gamma}}$

両式から，
$$\frac{T_b}{T_a} = \frac{T_c}{T_d} = \left(\frac{p_2}{p_1}\right)^{\frac{\gamma-1}{\gamma}}$$

つまり，
$$\frac{T_d}{T_c} = \frac{T_a}{T_b} = \left(\frac{p_1}{p_2}\right)^{\frac{\gamma-1}{\gamma}}$$

等比の性質より，
$$\frac{T_d - T_a}{T_c - T_b} = \frac{T_d}{T_c} = \left(\frac{p_1}{p_2}\right)^{\frac{\gamma-1}{\gamma}}$$

したがって，Joule サイクルの効率は，

$$\eta = 1 - \left(\frac{p_1}{p_2}\right)^{\frac{\gamma-1}{\gamma}}$$

で与えられる．

### (iii) Diesel サイクル

**1. 過程の整理**

図(c)の Diesel サイクルは，以下の 4 つの過程からなる．
- $a \to b$ : 断熱圧縮過程（体積 $V_1 \to V_3$ で減少）．
- $b \to c$ : 等圧加熱過程（圧力 $p_2$ で一定，体積 $V_3 \to V_2$ ）．
  外部から熱を吸収する．
- $c \to d$ : 断熱膨張過程（体積 $V_2 \to V_1$ で増加）．
- $d \to a$ : 等容冷却過程（体積 $V_1$ で一定）．
  外部へ熱を放出する．

**2. 仕事 $W$ と熱量 $Q$ の計算**

正味の仕事 $W$ は各過程での仕事の総和である．
- $a \to b, c \to d$ は断熱過程なので，
  $$W_{a \to b} = C_v(T_a - T_b), \quad W_{c \to d} = C_v(T_c - T_d)$$
- $b \to c$ は等圧過程なので，
  $$W_{b \to c} = p_2(V_c - V_b) = (\gamma - 1)C_v(T_c - T_b)$$
- $d \to a$ は等容過程なので，仕事は $0$ である．

これらを合計すると，

$$\begin{aligned} W &= C_v(T_a - T_b + T_c - T_d) + (\gamma - 1)C_v(T_c - T_b) \\ &= C_v\left[\gamma(T_c - T_b) - (T_d - T_a)\right] \end{aligned}$$

一方，気体が熱を受け取るのは $b \to c$ の等圧過程のみである：
$$Q = Q_{b \to c} = C_p(T_c - T_b) = \gamma C_v(T_c - T_b)$$

ゆえに効率 $\eta$ は，

$$\eta = \frac{W}{Q} = 1 - \frac{T_d - T_a}{\gamma(T_c - T_b)}$$

**3. 温度比を体積比へ変換**

過程の条件式を用いて温度比を体積比で表す．
- 過程 $b \to c$ （等圧）より， $\displaystyle \frac{T_c}{T_b} = \frac{V_2}{V_3}$ ，つまり $\displaystyle T_b = T_c\,\frac{V_3}{V_2}$
- 過程 $a \to b$ （断熱）より， $T_a V_1^{\gamma-1} = T_b V_3^{\gamma-1}$ ，つまり $\displaystyle T_a = T_b\left(\frac{V_3}{V_1}\right)^{\gamma-1}$
- 過程 $c \to d$ （断熱）より， $T_c V_2^{\gamma-1} = T_d V_1^{\gamma-1}$ ，つまり $\displaystyle T_d = T_c\left(\frac{V_2}{V_1}\right)^{\gamma-1}$

これらを用いて $\displaystyle \frac{T_d - T_a}{T_c - T_b}$ を変形する．
$T_b = T_c(V_3/V_2)$ ， $T_a = T_c\cdot\dfrac{V_3}{V_2}\left(\dfrac{V_3}{V_1}\right)^{\gamma-1}$ ， $T_d = T_c(V_2/V_1)^{\gamma-1}$ を代入し，分母分子を $T_c$ でくると，

$$\begin{aligned} \frac{T_d - T_a}{T_c - T_b} &= \frac{(V_2/V_1)^{\gamma-1} - (V_3/V_2)(V_3/V_1)^{\gamma-1}}{1 - V_3/V_2} \\ &= \frac{V_2(V_2/V_1)^{\gamma-1} - V_3(V_3/V_1)^{\gamma-1}}{V_2 - V_3} \end{aligned}$$

（第 2 行目：分母分子に $V_2$ を掛けた．）

各項を整理する．
$V_2(V_2/V_1)^{\gamma-1} = V_2^\gamma / V_1^{\gamma-1}$ ，
$V_3(V_3/V_1)^{\gamma-1} = V_3^\gamma / V_1^{\gamma-1}$ ．

よって，

$$\begin{aligned} \frac{T_d - T_a}{T_c - T_b} &= \frac{(V_2^\gamma - V_3^\gamma)/V_1^{\gamma-1}}{V_2 - V_3} \\ &= \frac{V_2^\gamma - V_3^\gamma}{V_1^{\gamma-1}(V_2 - V_3)} \end{aligned}$$

分子・分母を $V_1^\gamma$ で割る：

$$\begin{aligned} \frac{T_d - T_a}{T_c - T_b} &= \frac{(V_2/V_1)^\gamma - (V_3/V_1)^\gamma}{(V_2 - V_3)/V_1} \\ &= \frac{(V_2/V_1)^\gamma - (V_3/V_1)^\gamma}{(V_2/V_1) - (V_3/V_1)} \end{aligned}$$

したがって，Diesel サイクルの効率は，

$$\eta = 1 - \frac{1}{\gamma}\frac{(V_2/V_1)^\gamma - (V_3/V_1)^\gamma}{(V_2/V_1) - (V_3/V_1)}$$

で与えられる．

## 解説

### 1. サイクルと効率

熱機関の効率は，どれだけ「無駄なく」熱を仕事に変えられたかを示す指標である．
サイクルによって，同じ理想気体を使っても，その効率は大きく異なる．

- **Otto サイクル** : ガソリンエンジンのモデル．
  圧縮・膨張の比率が重要．
- **Joule サイクル** : 圧力一定の加熱過程を含む．
- **Diesel サイクル** : ディーゼルエンジンのモデル．
  圧縮比が高く，等圧加熱を行う．

### 2. 断熱過程と等温過程の基本式

計算の鍵となるのは，理想気体の断熱変化における以下の関係式である．
- $T V^{\gamma-1} = \text{constant}$
- $p V^\gamma = \text{constant}$
- $T p^{(1-\gamma)/\gamma} = \text{constant}$

これらを使いこなすことで，温度や圧力の比を，体積の比へと変換することができる．

### 3. 熱容量 $C_p$ と $C_v$

- $C_v$ (定積熱容量): 体積一定で加熱したときの熱容量．
- $C_p$ (定圧熱容量): 圧力一定で加熱したときの熱容量．

これらには $\gamma = C_p/C_v$ という関係があり，気体の種類（単原子分子か二原子分子かなど）によって値が決まる．
