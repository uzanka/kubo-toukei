# 演習問題【2-B-39】

## 解答

### 1．Curie–Weiss の法則とマクスウェルの関係式

以下では，単位体積あたりの常磁性体を考える．
内部エネルギーを $U$ ，エントロピーを $S$ ，磁化を $M$ ，磁場を $H$ ，絶対温度を $T$ とする．
磁気仕事の符号規約として，熱力学の基本関係式を

```math
dU=T\,dS+H\,dM
\tag{1}
```

とする．

Curie–Weiss の法則は，

```math
\chi=\frac{C}{T-\theta}
```

である．
ここで $C$ と $\theta$ は温度によらない定数である．
磁化率の定義 $M=\chi H$ を用いると，

```math
M=\frac{CH}{T-\theta}
```

となる．
これを磁場 $H$ について解けば，

```math
\boxed{
H=\frac{M(T-\theta)}{C}
}
\tag{2}
```

を得る．

次に，マクスウェルの関係式を導く．
ヘルムホルツ自由エネルギーを

```math
F=U-TS
```

と定義すると，式 (1) より，

```math
dF=dU-T\,dS-S\,dT
=-S\,dT+H\,dM
```

となる．
したがって，

```math
\left(\frac{\partial F}{\partial T}\right)_M=-S,
\qquad
\left(\frac{\partial F}{\partial M}\right)_T=H
```

である．
$F$ は状態量であるため，混合二階偏微分の順序を入れ替えられる．
よって，

```math
-\left(\frac{\partial S}{\partial M}\right)_T
=\left(\frac{\partial H}{\partial T}\right)_M
```

すなわち，

```math
\boxed{
\left(\frac{\partial S}{\partial M}\right)_T
=-\left(\frac{\partial H}{\partial T}\right)_M
}
\tag{3}
```

が得られる．

式 (2) を，磁化 $M$ を一定に保って温度 $T$ で偏微分すると，

```math
\left(\frac{\partial H}{\partial T}\right)_M
=\frac{M}{C}
```

である．
これを式 (3) に代入すると，

```math
\boxed{
\left(\frac{\partial S}{\partial M}\right)_T
=-\frac{M}{C}
}
\tag{4}
```

を得る．

### 2．熱容量 $C_M$ が温度のみの関数であることの証明

磁化 $M$ を一定に保つときの熱容量 $C_M$ は，

```math
C_M=\left(\frac{\partial U}{\partial T}\right)_M
```

と定義される．
式 (1) において $dM=0$ とすると $dU=T\,dS$ となるため，

```math
\boxed{
C_M=T\left(\frac{\partial S}{\partial T}\right)_M
}
\tag{5}
```

である．

式 (5) の両辺を，温度 $T$ を一定に保って磁化 $M$ で偏微分すると，

```math
\left(\frac{\partial C_M}{\partial M}\right)_T
=T\frac{\partial^2 S}{\partial M\,\partial T}
```

となる．
ここで，式 (4) を温度 $T$ で偏微分すれば，

```math
\frac{\partial^2 S}{\partial T\,\partial M}
=-\frac{\partial}{\partial T}
\left(\frac{\partial H}{\partial T}\right)_M
=-\left(\frac{\partial^2 H}{\partial T^2}\right)_M
```

である．
式 (2) より $H=M(T-\theta)/C$ は，磁化 $M$ 一定のもとで温度 $T$ の一次関数であるため，

```math
\left(\frac{\partial^2 H}{\partial T^2}\right)_M=0
```

となる．
したがって，

```math
\boxed{
\left(\frac{\partial C_M}{\partial M}\right)_T=0
}
```

である．
つまり， $C_M$ は磁化 $M$ に依存せず，温度 $T$ のみの関数である．

### 3．内部エネルギー $U$ の導出

式 (1) より，温度を一定に保ったとき，

```math
\left(\frac{\partial U}{\partial M}\right)_T
=T\left(\frac{\partial S}{\partial M}\right)_T+H
\tag{6}
```

である．
式 (2) と式 (4) を式 (6) に代入すると，

```math
\begin{aligned}
\left(\frac{\partial U}{\partial M}\right)_T
&=-\frac{TM}{C}+\frac{M(T-\theta)}{C}\\
&=-\frac{\theta M}{C}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\left(\frac{\partial U}{\partial M}\right)_T
=-\frac{\theta M}{C}
}
\tag{7}
```

を得る．

一方，定義より，

```math
\left(\frac{\partial U}{\partial T}\right)_M=C_M(T)
```

である．
したがって，内部エネルギーの全微分は，

```math
dU=C_M(T)\,dT-\frac{\theta M}{C}\,dM
\tag{8}
```

と表される．

式 (8) を積分すると，

```math
U=\int^T C_M(T')\,dT'
-\frac{\theta}{C}\int M\,dM+U_0
```

となる．
ここで $U_0$ は積分定数である．
磁化について積分すれば，

```math
\boxed{
U=\int^T C_M(T')\,dT'
-\frac{1}{2}\frac{\theta}{C}M^2+U_0
}
```

を得る．
これは問題文で示された内部エネルギーの表式である．

### 4．エントロピー $S$ の導出

式 (1) をエントロピーの微分について整理すると，

```math
dS=\frac{1}{T}(dU-H\,dM)
\tag{9}
```

である．
式 (2) と式 (8) を式 (9) に代入すると，

```math
dS
=\frac{1}{T}
\left[
C_M(T)\,dT
-\frac{\theta M}{C}\,dM
-\frac{M(T-\theta)}{C}\,dM
\right]
```

となる．
磁化 $M$ を含む項を整理すると，

```math
-\frac{\theta M}{C}\,dM
-\frac{M(T-\theta)}{C}\,dM
=-\frac{MT}{C}\,dM
```

である．
よって，

```math
\boxed{
dS=\frac{C_M(T)}{T}\,dT-\frac{M}{C}\,dM
}
\tag{10}
```

を得る．

これを温度 $T$ と磁化 $M$ について積分すると，

```math
S=\int^T\frac{C_M(T')}{T'}\,dT'
-\frac{1}{C}\int M\,dM+S_0
```

となる．
ここで $S_0$ は積分定数である．
したがって，

```math
\boxed{
S=\int^T\frac{C_M(T')}{T'}\,dT'
-\frac{M^2}{2C}+S_0
}
```

を得る．
これは問題文で示されたエントロピーの表式である．
