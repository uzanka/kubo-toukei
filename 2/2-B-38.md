# 演習問題【2-B-38】

## 解答

### 1．膨張の潜熱とマクスウェルの関係式

ある物質の体積を $V$ ，エントロピーを $S$ ，圧力を $p$ ，絶対温度を $T$ とする．
経験温度を $\theta$ とし，体膨張係数を

```math
\alpha=\frac{1}{V}\left(\frac{\partial V}{\partial\theta}\right)_p
```

と定義する．

まず，温度 $T$ を一定に保ち，圧力 $p$ を微小量 $dp$ だけ変化させる可逆過程を考える．
このとき，物質が吸収する微小熱量を $d'Q$ とすると，

```math
d'Q=T\,dS
```

が成り立つ．
問題で定義された膨張の潜熱 $L_p$ は，圧力変化あたりの吸収熱量であるから，

```math
L_p\equiv\left(\frac{d'Q}{dp}\right)_T
=T\left(\frac{\partial S}{\partial p}\right)_T
\tag{1}
```

となる．

次に，ギブズ自由エネルギー $G=U+pV-TS$ の全微分は，

```math
dG=-S\,dT+V\,dp
```

である．
$G$ は状態量であるため，混合二階偏微分の順序を入れ替えることができる．
これより，マクスウェルの関係式

```math
\left(\frac{\partial S}{\partial p}\right)_T
=-\left(\frac{\partial V}{\partial T}\right)_p
\tag{2}
```

が得られる．
式 (2) を式 (1) に代入すると，

```math
\boxed{
L_p=-T\left(\frac{\partial V}{\partial T}\right)_p
}
\tag{3}
```

となる．
これは，圧力変化に伴う吸収熱と，温度変化に伴う体積変化を結び付ける関係式である．

### 2．経験温度 $\theta$ を用いた微分方程式

体積 $V$ を，圧力一定のもとで経験温度 $\theta$ の関数として測定する．
絶対温度 $T$ も $\theta$ の関数であると考えると，連鎖律より，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=
\left(\frac{\partial V}{\partial\theta}\right)_p
\frac{d\theta}{dT}
\tag{4}
```

が成り立つ．

体膨張係数の定義から，

```math
\left(\frac{\partial V}{\partial\theta}\right)_p
=V\alpha
\tag{5}
```

である．
式 (4)，(5) を式 (3) に代入すると，

```math
L_p=-TV\alpha\frac{d\theta}{dT}
\tag{6}
```

を得る．
これを $dT/d\theta$ について整理すれば，

```math
\frac{dT}{d\theta}
=-\frac{TV\alpha}{L_p}
```

となる．
両辺を $T$ で割ると，

```math
\frac{1}{T}\frac{dT}{d\theta}
=-\frac{V\alpha}{L_p}
```

である．
ここで，

```math
\frac{d\ln T}{d\theta}
=\frac{1}{T}\frac{dT}{d\theta}
```

であるため，求める微分方程式は，

```math
\boxed{
\frac{d\ln T}{d\theta}
=-\frac{V(\theta)\alpha(\theta)}{L_p(\theta)}
}
\tag{7}
```

となる．
右辺は，測定によって求められる体積，体膨張係数，膨張の潜熱で表されている．

### 3．積分による絶対温度の較正

基準となる経験温度を $\theta_0$ ，そのときの絶対温度を $T_0$ とする．
式 (7) を $\theta_0$ から $\theta$ まで積分すると，

```math
\int_{T_0}^{T}\frac{dT'}{T'}
=-\int_{\theta_0}^{\theta}
\frac{V(\theta')\alpha(\theta')}{L_p(\theta')}
\,d\theta'
```

となる．
左辺を積分すれば，

```math
\boxed{
\ln\frac{T}{T_0}
=-\int_{\theta_0}^{\theta}
\frac{V(\theta')\alpha(\theta')}{L_p(\theta')}
\,d\theta'
}
\tag{8}
```

を得る．
ここで，積分中の $V(\theta')$ ， $\alpha(\theta')$ ， $L_p(\theta')$ は，いずれも同じ一定圧力のもとで測定した値である．

式 (8) を $T$ について解くと，

```math
\boxed{
T=T_0\exp\left[
-\int_{\theta_0}^{\theta}
\frac{V(\theta')\alpha(\theta')}{L_p(\theta')}
\,d\theta'
\right]
}
\tag{9}
```

となる．

したがって，基準状態の絶対温度 $T_0$ が分かっていれば，体積 $V$ ，体膨張係数 $\alpha$ ，膨張の潜熱 $L_p$ の測定値を用いて積分することで，任意の経験温度 $\theta$ に対応する絶対温度 $T$ を求めることができる．
これが，本方法による絶対温度の較正原理である．


## 解説

この方法では，まず基準温度 $T_0$ を一つ定め，そこから式 (9) を用いて他の温度を較正する．
したがって，経験温度と絶対温度の対応関係を実験的に構築するためには，基準点の設定と，体積・膨張係数・膨張の潜熱の測定が必要である．
