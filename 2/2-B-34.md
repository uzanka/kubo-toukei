# 演習問題【2-B-34】

## 解答

### 1．定積モル比熱 $C_V$ が温度 $T$ のみの関数であることの証明

1 mol の van der Waals 気体を考える．
内部エネルギーを $U$ ，モル体積を $V$ ，圧力を $p$ ，絶対温度を $T$ とする．
定積モル比熱 $C_V$ は，

```math
C_V=\left(\frac{\partial U}{\partial T}\right)_V
```

と定義される．

まず，熱力学の基本関係式

```math
dU=T\,dS-p\,dV
\tag{1}
```

を用いる．
ここで $S$ は 1 mol あたりのエントロピーである．
温度 $T$ を一定に保ったとき，式 (1) より，

```math
\left(\frac{\partial U}{\partial V}\right)_T
=T\left(\frac{\partial S}{\partial V}\right)_T-p
\tag{2}
```

となる．

次に，マクスウェルの関係式

```math
\left(\frac{\partial S}{\partial V}\right)_T
=\left(\frac{\partial p}{\partial T}\right)_V
\tag{3}
```

を用いる．
この関係式は，ヘルムホルツ自由エネルギー $F=U-TS$ の全微分

```math
dF=-S\,dT-p\,dV
```

から導かれる．
実際に， $F$ の混合二階偏微分の順序を入れ替えられることから，式 (3) が得られる．

式 (3) を式 (2) に代入すると，

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_T
=T\left(\frac{\partial p}{\partial T}\right)_V-p
}
\tag{4}
```

となる．

ここで，定積モル比熱の定義と偏微分の順序交換を用いると，

```math
\begin{aligned}
\left(\frac{\partial C_V}{\partial V}\right)_T
&=\frac{\partial}{\partial V}
\left(\frac{\partial U}{\partial T}\right)_V\\
&=\frac{\partial}{\partial T}
\left(\frac{\partial U}{\partial V}\right)_T
\end{aligned}
\tag{5}
```

である．
式 (4) を式 (5) に代入すれば，

```math
\begin{aligned}
\left(\frac{\partial C_V}{\partial V}\right)_T
&=\frac{\partial}{\partial T}
\left[
T\left(\frac{\partial p}{\partial T}\right)_V-p
\right]\\
&=\left(\frac{\partial p}{\partial T}\right)_V
+T\left(\frac{\partial^2p}{\partial T^2}\right)_V
-\left(\frac{\partial p}{\partial T}\right)_V\\
&=T\left(\frac{\partial^2p}{\partial T^2}\right)_V
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
\left(\frac{\partial C_V}{\partial V}\right)_T
=T\left(\frac{\partial^2p}{\partial T^2}\right)_V
}
\tag{6}
```

である．

van der Waals の状態方程式は，

```math
p=\frac{RT}{V-b}-\frac{a}{V^2}
\tag{7}
```

で与えられる．
ここで $R$ は気体定数， $a,b$ は物質に固有の定数である．
式 (7) を温度 $T$ について偏微分すると，

```math
\left(\frac{\partial p}{\partial T}\right)_V
=\frac{R}{V-b}
```

となる．
右辺は温度 $T$ に依存しないため，

```math
\left(\frac{\partial^2p}{\partial T^2}\right)_V=0
```

である．
これを式 (6) に代入すると，

```math
\left(\frac{\partial C_V}{\partial V}\right)_T=0
```

を得る．
したがって，定積モル比熱はモル体積 $V$ に依存せず，

```math
\boxed{
C_V=C_V(T)
}
```

と表される．
これで定積モル比熱が温度のみの関数であることが示された．

### 2．内部エネルギー $U$ の表式

式 (4) と van der Waals の状態方程式 (7) から，

```math
\begin{aligned}
\left(\frac{\partial U}{\partial V}\right)_T
&=T\frac{R}{V-b}
-\left(\frac{RT}{V-b}-\frac{a}{V^2}\right)\\
&=\frac{a}{V^2}
\end{aligned}
\tag{8}
```

となる．
一方，定積モル比熱の定義から，

```math
\left(\frac{\partial U}{\partial T}\right)_V=C_V(T)
```

である．
よって，内部エネルギーの全微分は，

```math
dU=C_V(T)\,dT+\frac{a}{V^2}\,dV
\tag{9}
```

と書ける．

式 (9) を温度 $T$ とモル体積 $V$ について積分すると，

```math
U=\int C_V(T)\,dT+\int\frac{a}{V^2}\,dV+U_0
```

となる．
ここで $U_0$ は積分定数である．
各積分を計算すると，

```math
\int\frac{a}{V^2}\,dV=-\frac{a}{V}
```

であるため，

```math
\boxed{
U(T,V)=\int C_V(T)\,dT-\frac{a}{V}+U_0
}
```

を得る．

この式は，内部エネルギーが温度に依存する項と，分子間引力に対応する $-a/V$ の項からなることを示している．

### 3．エントロピー $S$ の表式

熱力学の基本関係式 (1) をエントロピー $S$ について整理すると，

```math
dS=\frac{1}{T}\,dU+\frac{p}{T}\,dV
\tag{10}
```

となる．

式 (9) の $dU$ と van der Waals の状態方程式 (7) を式 (10) に代入すると，

```math
\begin{aligned}
dS
&=\frac{1}{T}
\left(C_V(T)\,dT+\frac{a}{V^2}\,dV\right)\\
&\quad+\frac{1}{T}
\left(\frac{RT}{V-b}-\frac{a}{V^2}\right)dV
\end{aligned}
```

である．
これを整理すると，

```math
dS
=\frac{C_V(T)}{T}\,dT
+\frac{a}{TV^2}\,dV
+\frac{R}{V-b}\,dV
-\frac{a}{TV^2}\,dV
```

となる．
体積に関する二つの項が相殺されるため，

```math
\boxed{
dS=\frac{C_V(T)}{T}\,dT+\frac{R}{V-b}\,dV
}
\tag{11}
```

を得る．

式 (11) を温度 $T$ とモル体積 $V$ について積分すれば，

```math
S=\int\frac{C_V(T)}{T}\,dT
+R\int\frac{1}{V-b}\,dV+S_0
```

である．
ここで $S_0$ は積分定数である．
対数の引数を無次元にするため，基準モル体積 $V_*>0$ を導入すると，

```math
\int\frac{1}{V-b}\,dV
=\ln\frac{V-b}{V_*}+\text{定数}
```

である．
この定数を $S_0$ に含めることにより，

```math
\boxed{
S(T,V)=
\int\frac{C_V(T)}{T}\,dT
+R\ln\frac{V-b}{V_*}+S_0
}
```

を得る．
この表式は $V>b$ の範囲で成立する．
なお，基準体積 $V_*$ の選び方は加法定数に吸収できるため，通常は $R\ln(V-b)$ と略記される．
