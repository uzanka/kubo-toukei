# 演習問題【2-A-11】

## 解答

問題の条件は，

```math
pV=f(\theta)
\tag{1}
```

および

```math
\left(\frac{\partial U}{\partial V}\right)_\theta=0
\tag{2}
```

である．
ここで， $p$ は圧力， $V$ は体積， $U4 は内部エネルギー， $\theta$ は任意の温度目盛である．

本問の目的は， $f(\theta)$ が熱力学的絶対温度 $T$ に比例すること，すなわち，

```math
f(\theta)=AT
```

と表されることを示すことである．
ただし， $A$ は正の定数である．

### 1．熱力学的恒等式を導く

まず，熱力学の基本関係式

```math
dU=T\,dS-p\,dV
\tag{3}
```

を用いる．
ここで， $S$ は系のエントロピーである．

式 (3) を温度 $T$ を一定に保った変化について考えると，

```math
\left(\frac{\partial U}{\partial V}\right)_T
=
T\left(\frac{\partial S}{\partial V}\right)_T-p
\tag{4}
```

となる．

次に，Maxwell の関係式

```math
\left(\frac{\partial S}{\partial V}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_V
\tag{5}
```

を用いる．
この関係式は，ヘルムホルツ自由エネルギー $\Phi=U-TS$ の微分形

```math
d\Phi=-S\,dT-p\,dV
```

から得られる．
すなわち， $\Phi$ の混合二階偏微分の順序を交換することで，式 (5) が導かれる．

式 (5) を式 (4) に代入すると，

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_T
=
T\left(\frac{\partial p}{\partial T}\right)_V-p
}
\tag{6}
```

を得る．
これが，本問で用いる熱力学的恒等式である．

### 2．条件 (b) を用いて圧力と絶対温度の関係を求める

条件 (b) より，

```math
\left(\frac{\partial U}{\partial V}\right)_\theta=0
```

である．
$\theta$ は温度目盛であるため， $\theta$ を固定することは絶対温度 $T$ を固定することに対応する．
したがって，

```math
\left(\frac{\partial U}{\partial V}\right)_T=0
```

となる．

これを式 (6) に代入すると，

```math
0=T\left(\frac{\partial p}{\partial T}\right)_V-p
```

すなわち，

```math
\boxed{
T\left(\frac{\partial p}{\partial T}\right)_V=p
}
\tag{7}
```

を得る．

### 3．条件 (a) を用いて微分方程式を解く

条件 (a) より，

```math
pV=f(\theta)
```

である．
ここで，絶対温度 $T$ と温度目盛 $\theta$ の対応関係を $\theta=\theta(T)$ と表し，

```math
g(T):=f\bigl(\theta(T)\bigr)
```

と定義する．
すると，条件 (a) は，

```math
pV=g(T)
```

と書き直せる．
したがって，

```math
p=\frac{g(T)}{V}
\tag{8}
```

である．

式 (8) を，体積 $V$ を一定に保って温度 $T$ で偏微分すると，

```math
\left(\frac{\partial p}{\partial T}\right)_V
=\frac{1}{V}\frac{dg}{dT}
\tag{9}
```

となる．

式 (8)，(9) を式 (7) に代入すれば，

```math
T\frac{1}{V}\frac{dg}{dT}
=\frac{g(T)}{V}
```

を得る．
両辺に $V$ を掛けると，

```math
T\frac{dg}{dT}=g(T)
\tag{10}
```

となる．

この微分方程式を解くために，次のように変形する．

```math
\begin{aligned}
\frac{d}{dT}\left(\frac{g(T)}{T}\right)
&=\frac{T\frac{dg}{dT}-g(T)}{T^2}\\
&=0
\end{aligned}
```

ここで，最後の等号には式 (10) を用いた．
したがって， $g(T)/T$ は温度によらない定数である．
この定数を $A$ とすると，

```math
\frac{g(T)}{T}=A
```

であり，

```math
g(T)=AT
\tag{11}
```

を得る．

一方， $g(T)=f(\theta(T))$ と定義したため，式 (11) は，

```math
\boxed{
f(\theta)=AT
}
```

を意味する．
また， $pV>0$ かつ $T>0$ であるから， $A=pV/T>0$ である．

### 4．結論

条件 (a)，(b) と熱力学的恒等式から，

```math
\boxed{
f(\theta)=AT\qquad (A>0)
}
```

が導かれた．
すなわち， $f(\theta)$ は熱力学的絶対温度 $T$ に正の定数を掛けたものである．

したがって， $f(\theta)$ は絶対温度に比例する尺度であり，比例定数による単位の違いを除けば，絶対温度そのものとしての意味を持つことが示された．

## 解説

この証明から分かるのは， $f(\theta)$ が絶対温度に比例することである．
比例定数 $A$ は，温度目盛の単位や気体の量によって定まるため，問題の条件だけからその数値までは決定できないのである．
