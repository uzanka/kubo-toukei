# 演習問題【2-B-40】

## 解答

### 1. 体積磁歪と圧磁気係数の関係の導出

熱力学第一法則および第二法則より，系の内部エネルギー $U$ ，エントロピー $S$ ，圧力 $p$ ，体積 $V$ ，磁場 $H$ ，および磁気モーメント $I$ の間には以下の関係が成り立つ．

$$dU = T dS - p dV + H dI \quad \cdots (1)$$

ここで，温度 $T$ を一定（等温過程）と考える．
内部エネルギー $U$ は $T, p, H$ の関数として表されるため，式(1)より以下の偏微分が導かれる．

$$\left(\frac{\partial U}{\partial p}\right)_H = T\left(\frac{\partial S}{\partial p}\right)_H - p\left(\frac{\partial V}{\partial p}\right)_H + H\left(\frac{\partial I}{\partial p}\right)_H \quad \cdots (2)$$

$$\left(\frac{\partial U}{\partial H}\right)_p = T\left(\frac{\partial S}{\partial H}\right)_p - p\left(\frac{\partial V}{\partial H}\right)_p + H\left(\frac{\partial I}{\partial H}\right)_p \quad \cdots (3)$$

ここで，偏微分の順序によらない性質（混合偏微分の等価性），すなわち

$$\frac{\partial^2 U}{\partial p \partial H} = \frac{\partial^2 U}{\partial H \partial p}$$

を用いる．
式(2)を $H$ で偏微分したものと，式(3)を $p$ で偏微分したものを比較する．
$T$ が一定であることに注意すると，

$$\frac{\partial}{\partial H} \left[ T\left(\frac{\partial S}{\partial p}\right)_H - p\left(\frac{\partial V}{\partial p}\right)_H + H\left(\frac{\partial I}{\partial p}\right)_H \right] = \frac{\partial}{\partial p} \left[ T\left(\frac{\partial S}{\partial H}\right)_p - p\left(\frac{\partial V}{\partial H}\right)_p + H\left(\frac{\partial I}{\partial H}\right)_p \right]$$

左辺と右辺を展開すると，

$$T\frac{\partial^2 S}{\partial H \partial p} - p\frac{\partial^2 V}{\partial H \partial p} + \frac{\partial I}{\partial p} + H\frac{\partial^2 I}{\partial H \partial p} = T\frac{\partial^2 S}{\partial p \partial H} - \left(\frac{\partial V}{\partial H}\right)_p - p\frac{\partial^2 V}{\partial p \partial H} + H\frac{\partial^2 I}{\partial p \partial H}$$

ここで，混合偏微分の等価性により $T\frac{\partial^2 S}{\partial H \partial p} = T\frac{\partial^2 S}{\partial p \partial H}$ および $p\frac{\partial^2 V}{\partial H \partial p} = p\frac{\partial^2 V}{\partial p \partial H}$ ，さらに $H\frac{\partial^2 I}{\partial H \partial p} = H\frac{\partial^2 I}{\partial p \partial H}$ であるため，これらは互いに打ち消し合う．
したがって，以下の関係が得られる．

$$\frac{\partial I}{\partial p} = -\left(\frac{\partial V}{\partial H}\right)_p$$

これに等温の条件 $T = \text{const.}$ を明示すれば，

$$\left(\frac{\partial V}{\partial H}\right)_{p,T} = -\left(\frac{\partial I}{\partial p}\right)_{H,T} \quad \cdots (4)$$

となり，題意の第一部が示された．

### 2. 体積変化 $\Delta V/V$ の導出

次に，磁気モーメント $I$ と等温磁化率 $\chi$ の関係式 $I = \chi HV$ を用いて，式(4)の右辺を書き換える．

$$\left(\frac{\partial V}{\partial H}\right)_{p,T} = -\left(\frac{\partial (\chi HV)}{\partial p}\right)_{H,T}$$

右辺の $p$ による微分において， $H$ は定数であるため，積の微分法則を適用すると，

$$\left(\frac{\partial V}{\partial H}\right)_{p,T} = -\left[ V H \left(\frac{\partial \chi}{\partial p}\right)_T + \chi H \left(\frac{\partial V}{\partial p}\right)_{H,T} \right]$$

両辺を $V$ で割り，さらに $\beta = -\frac{1}{V}\left(\frac{\partial V}{\partial p}\right)_{H,T}$ を用いて整理すると，

$$\frac{1}{V} \left(\frac{\partial V}{\partial H}\right)_{p,T} = -H \left[ \left(\frac{\partial \chi}{\partial p}\right)_T - \chi \beta \right] = H \left[ \beta \chi - \left(\frac{\partial \chi}{\partial p}\right)_T \right] \quad \cdots (5)$$

が得られる．
磁場を $0$ から $H$ まで等温的に変化させ，そのときの体積変化を $\Delta V$ とすると，式(5)の両辺を $H$ について $0$ から $H$ まで積分する．
このとき， $\chi$ および $\left(\frac{\partial \chi}{\partial p}\right)_T$ の磁場 $H$ に対する依存性は無視できるものとする．

```math
\int_V^{V+\Delta V} \frac{dV'}{V'} = \int_0^H H' \left\{ \beta \chi - \left(\frac{\partial \chi}{\partial p}\right)_T \right\} dH'
```

左辺は $\ln\left(\frac{V+\Delta V}{V}\right)$ となり，右辺を積分すると，

```math
\ln\left(1 + \frac{\Delta V}{V}\right) = \frac{1}{2} H^2 \left\{ \beta \chi - \left(\frac{\partial \chi}{\partial p}\right)_T \right\} \quad \cdots (6)
```

ここで， $\Delta V \ll V$ であるため， $\ln(1+x) \approx x$ （ $x \ll 1$ のとき）という近似を用いる．

```math
\frac{\Delta V}{V} = \frac{1}{2} H^2 \left\{ \beta \chi - \left(\frac{\partial \chi}{\partial p}\right)_T \right\}
```

となり，題意の第二部が示された．

## 解説

### 物理的意味

この問題は，磁場によって物質の体積が変化する現象（磁歪）と，圧力によって磁気モーメントが変化する現象（圧磁気効果）が，熱力学的な状態量を通じて密接に関連していることを示している．

- 体積磁歪 $(\partial V / \partial H)_{p,T}$:
  磁場をかけたときに，圧力を一定に保ったまま体積がどれくらい変わるかを表す．
- 圧磁気係数 $(\partial I / \partial p)_{H,T}$:
  圧力をかけたときに，磁場を一定に保ったまま磁気モーメントがどれくらい変わるかを表す．

### 重要な概念

1. 混合偏微分の等価性 :
  $\frac{\partial^2 U}{\partial p \partial H} = \frac{\partial^2 U}{\partial H \partial p}$ という性質は，状態量 $U$ が滑らかな関数である場合に常に成り立つ．
  これを利用することで，複雑な偏微分の関係式を単純化できる．
2. 等温圧縮率 $\beta$ :
  圧力をかけたときに体積がどれくらい縮みやすいかを示す指標である．
  $\beta = -\frac{1}{V} (\frac{\partial V}{\partial p})_T$ と定義される．
3. 等温磁化率 $\chi$ :
  磁場をかけたときに磁化がどれくらい生じるかを示す指標である．
  本問では $I = \chi HV$ という関係を用いた．
4. 近似 $\ln(1+x) \approx x$ :
  微小な変化 $\Delta V/V$ を扱う際，対数関数のテイラー展開の第1項を用いることで，複雑な積分結果を簡潔な式に落とし込むことができる．
