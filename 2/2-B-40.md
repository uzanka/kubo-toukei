# 演習問題【2-B-40】

## 解答

### 1．体積磁歪と圧磁気係数の関係

磁性体の内部エネルギーを $U$ ，エントロピーを $S$ ，体積を $V$ ，圧力を $p$ ，磁場を $H$ ，試料全体の磁気モーメントを $I$ ，絶対温度を $T$ とする．
磁気仕事の符号規約として，熱力学の基本関係式は

```math
dU=T\,dS-p\,dV+H\,dI
\tag{1}
```

である．

以下では温度 $T$ を一定に保つ．
内部エネルギー $U$ を $T,p,H$ の関数と考えると，式 (1) より，

```math
\left(\frac{\partial U}{\partial p}\right)_{T,H}
=
T\left(\frac{\partial S}{\partial p}\right)_{T,H}
-p\left(\frac{\partial V}{\partial p}\right)_{T,H}
+H\left(\frac{\partial I}{\partial p}\right)_{T,H}
\tag{2}
```

および

```math
\left(\frac{\partial U}{\partial H}\right)_{T,p}
=
T\left(\frac{\partial S}{\partial H}\right)_{T,p}
-p\left(\frac{\partial V}{\partial H}\right)_{T,p}
+H\left(\frac{\partial I}{\partial H}\right)_{T,p}
\tag{3}
```

が得られる．

ここで，状態量 $U$ の混合二階偏微分は，微分の順序によらず等しい．
したがって，

```math
\frac{\partial}{\partial H}
\left(\frac{\partial U}{\partial p}\right)_{T,H}
=
\frac{\partial}{\partial p}
\left(\frac{\partial U}{\partial H}\right)_{T,p}
\tag{4}
```

が成り立つ．
式 (2) の両辺を $H$ で偏微分すると，

```math
\begin{aligned}
\frac{\partial}{\partial H}
\left(\frac{\partial U}{\partial p}\right)_{T,H}
={}&T\frac{\partial^2 S}{\partial H\,\partial p}
-p\frac{\partial^2 V}{\partial H\,\partial p}\\
&+\left(\frac{\partial I}{\partial p}\right)_{T,H}
+H\frac{\partial^2 I}{\partial H\,\partial p}
\end{aligned}
\tag{5}
```

となる．
一方，式 (3) の両辺を $p$ で偏微分すると，

```math
\begin{aligned}
\frac{\partial}{\partial p}
\left(\frac{\partial U}{\partial H}\right)_{T,p}
={}&T\frac{\partial^2 S}{\partial p\,\partial H}
-\left(\frac{\partial V}{\partial H}\right)_{T,p}\\
&-p\frac{\partial^2 V}{\partial p\,\partial H}
+H\frac{\partial^2 I}{\partial p\,\partial H}
\end{aligned}
\tag{6}
```

を得る．

式 (4) の左右を式 (5)，(6) で置き換える．
$S,V,I$ の混合二階偏微分の順序を交換できるため，両辺に共通する項は相殺される．
その結果，

```math
\left(\frac{\partial I}{\partial p}\right)_{T,H}
=-\left(\frac{\partial V}{\partial H}\right)_{T,p}
```

となる．
よって，

```math
\boxed{
\left(\frac{\partial V}{\partial H}\right)_{p,T}
=-\left(\frac{\partial I}{\partial p}\right)_{H,T}
}
\tag{7}
```

を得る．
これが体積磁歪と圧磁気係数の間に成り立つ関係である．

### 2．体積変化と等温圧縮率・磁化率の関係

等温磁化率 $\chi$ は，

```math
\chi=\frac{I}{HV}
```

と定義される．
したがって，

```math
I=\chi HV
\tag{8}
```

である．
式 (7) に式 (8) を代入すると，

```math
\left(\frac{\partial V}{\partial H}\right)_{p,T}
=-\left(\frac{\partial(\chi HV)}{\partial p}\right)_{H,T}
\tag{9}
```

となる．

圧力 $p$ を変化させる際には磁場 $H$ と温度 $T$ は一定であるため，積の微分法則より，

```math
\left(\frac{\partial V}{\partial H}\right)_{p,T}
=-H\left[
V\left(\frac{\partial\chi}{\partial p}\right)_{H,T}
+\chi\left(\frac{\partial V}{\partial p}\right)_{H,T}
\right]
\tag{10}
```

を得る．

ここで，等温圧縮率 $\beta$ は

```math
\beta=-\frac{1}{V}
\left(\frac{\partial V}{\partial p}\right)_{H,T}
```

と定義されるので，

```math
\left(\frac{\partial V}{\partial p}\right)_{H,T}
=-\beta V
\tag{11}
```

である．
式 (11) を式 (10) に代入し，両辺を $V$ で割ると，

```math
\frac{1}{V}
\left(\frac{\partial V}{\partial H}\right)_{p,T}
=
H\left[
\beta\chi-\left(\frac{\partial\chi}{\partial p}\right)_{H,T}
\right]
\tag{12}
```

となる．

弱磁場の線形応答領域では，磁化率 $\chi$ は磁場 $H$ によらない量として扱える．
この近似では，

```math
\left(\frac{\partial\chi}{\partial p}\right)_{H,T}
=\left(\frac{\partial\chi}{\partial p}\right)_T
```

と書ける．
また，体積変化が小さい範囲では，等温圧縮率 $\beta$ も磁場によらないものとして扱う．
したがって，式 (12) は

```math
\boxed{
\frac{1}{V}
\left(\frac{\partial V}{\partial H}\right)_{p,T}
=
H\left[
\beta\chi-\left(\frac{\partial\chi}{\partial p}\right)_T
\right]
}
\tag{13}
```

となる．
ここで，右辺の $\beta,\chi,(\partial\chi/\partial p)_T$ は，指定された圧力と温度における弱磁場での値である．

### 3．磁場をゼロから $H$ まで増加させた場合の体積変化

磁場がゼロのときの体積を $V_0$ とし，磁場を $0$ から $H$ まで等温的に増加させた後の体積を $V_0+\Delta V$ とする．
式 (13) を，磁場 $H'$ について $0$ から $H$ まで積分する．
弱磁場近似のもとでは，式 (13) の角括弧内は磁場によらない定数として扱えるため，

```math
\int_{V_0}^{V_0+\Delta V}\frac{dV'}{V'}
=
\int_0^H
H'\left[
\beta\chi-\left(\frac{\partial\chi}{\partial p}\right)_T
\right]dH'
```

となる．
左辺を積分すると，

```math
\ln\frac{V_0+\Delta V}{V_0}
```

であり，右辺を積分すると，

```math
\frac{H^2}{2}
\left[
\beta\chi-\left(\frac{\partial\chi}{\partial p}\right)_T
\right]
```

である．
したがって，

```math
\ln\left(1+\frac{\Delta V}{V_0}\right)
=
\frac{H^2}{2}
\left[
\beta\chi-\left(\frac{\partial\chi}{\partial p}\right)_T
\right]
\tag{14}
```

を得る．

問題の条件 $|\Delta V|\ll V_0$ より，対数関数の近似

```math
\ln(1+x)\simeq x
\qquad (|x|\ll1)
```

を用いることができる．
式 (14) の左辺は，

```math
\ln\left(1+\frac{\Delta V}{V_0}\right)
\simeq\frac{\Delta V}{V_0}
```

となるため，

```math
\boxed{
\frac{\Delta V}{V_0}
=
\frac{H^2}{2}
\left[
\beta\chi-\left(\frac{\partial\chi}{\partial p}\right)_T
\right]
}
\tag{15}
```

を得る．
磁場による体積変化が小さいため，基準体積 $V_0$ を $V$ と表せば，問題文の式

```math
\boxed{
\frac{\Delta V}{V}
=
\frac{H^2}{2}
\left\{
\beta\chi-\left(\frac{\partial\chi}{\partial p}\right)_T
\right\}
}
```

が得られる．


## 解説

第二の式は，弱磁場近似において体積変化の $H^2$ 次までを求めた結果である．
一般に磁化率や圧縮率が磁場に強く依存する場合には，式 (13) の右辺を磁場に依存する関数として積分する必要があり，問題文の簡潔な形はそのままでは成立しない．
