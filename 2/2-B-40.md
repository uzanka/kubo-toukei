# 演習問題【2-B-40】

## 解答

### 0．前提と問題文の解釈

次の3点を前提とする．

**(a) 対象物質**:
自発磁化・残留磁化・ヒステリシスのない単一の可逆平衡相(常磁性体・反磁性体など)を扱う．

**(b) 過程**:
温度 $T$ と圧力 $p$ を一定に保ち，磁場を $0$ から $H$ まで準静的に増す．
体積磁歪 $(\partial V/\partial H)_{p,T}$ は定圧での偏微分なので，定圧・等温の過程が自然な解釈である．

**(c) 条件 $|\Delta V|\ll V$ の解釈**:
この条件は，積分中の $V,\ \beta,\ \chi$ をゼロ磁場の値で近似できる弱磁場・線形応答の条件と解釈する．
第2の関係式は $H$ の最低次( $H^2$ )の結果である．
問題文の $\beta,\chi$ は，ゼロ磁場での値 $\beta_0,\chi_0$ を指すと読む．

この解釈が必要な理由は第4節で述べる．
$|\Delta V|\ll V$ だけでは $\beta,\chi$ の磁場依存性を無視できるとは限らないためである．

### 1．体積磁歪と圧磁気係数の関係

#### 1.1 基本関係式

内部エネルギー $U$ ，エントロピー $S$ ，体積 $V$ ，圧力 $p$ ，磁場 $H$ ，試料全体の磁気モーメント $I$ ，温度 $T$ に対し，

```math
dU=T\,dS-p\,dV+H\,dI
\tag{1}
```

とする．
$H$ と $I$ が共役変数となる単位系を採用する．
SI で磁気仕事を $\mu_0H\,dI$ とする場合は第4節で述べる．

#### 1.2 Legendre変換

```math
G=U-TS+pV-HI
```

を定義すると，

```math
dG=-S\,dT+V\,dp-I\,dH
\tag{2}
```

である．
よって $G=G(T,p,H)$ について，

```math
\left(\frac{\partial G}{\partial p}\right)_{T,H}=V,\qquad
\left(\frac{\partial G}{\partial H}\right)_{T,p}=-I
\tag{3}
```

$G$ が混合二階偏微分の交換を許す程度に滑らかであると仮定すると，

```math
\frac{\partial}{\partial H}\left(\frac{\partial G}{\partial p}\right)_{T,H}
=
\frac{\partial}{\partial p}\left(\frac{\partial G}{\partial H}\right)_{T,p}
```

より，

```math
\boxed{
\left(\frac{\partial V}{\partial H}\right)_{p,T}
=
-\left(\frac{\partial I}{\partial p}\right)_{H,T}
}
\tag{4}
```

が得られる．

### 2．磁場依存性を残した一般式

$H\neq0$ では $\chi=I/(HV)$ より $I=\chi HV$ である( $H=0$ での値は $\chi_0=\lim_{H\to0}I/(HV)$ と定義する)．
これを (4) に代入し， $H,T$ 一定のもとで $p$ について積の微分を行うと，

```math
\left(\frac{\partial V}{\partial H}\right)_{p,T}
=-H\left[V\left(\frac{\partial\chi}{\partial p}\right)_{H,T}
+\chi\left(\frac{\partial V}{\partial p}\right)_{H,T}\right]
\tag{5}
```

$\beta=-\dfrac1V\left(\dfrac{\partial V}{\partial p}\right)_{H,T}$ より $\left(\dfrac{\partial V}{\partial p}\right)_{H,T}=-\beta V$ なので，

```math
\boxed{
\frac1V\left(\frac{\partial V}{\partial H}\right)_{p,T}
=H\left[\beta\chi-\left(\frac{\partial\chi}{\partial p}\right)_{H,T}\right]
}
\tag{6}
```

ここで一般には $\chi=\chi(p,T,H)$ ， $\beta=\beta(p,T,H)$ である．

#### 積分

$p,T$ 一定で $H$ を $0$ から $H$ まで増す．
$V_0=V(p,T,0)$ ， $V=V_0+\Delta V$ とし，

```math
F(H')=\beta(p,T,H')\chi(p,T,H')-\left(\frac{\partial\chi}{\partial p}\right)_{H',T}
```

とおくと，(6) より $dV/V=H'F(H')\,dH'$ である．
これを積分して，

```math
\ln\frac{V_0+\Delta V}{V_0}=\int_0^H H'F(H')\,dH'
\tag{7}
```

### 3．弱磁場近似

#### 3.1 仮定

前提 (a) のもと，次を仮定する．

1. ゼロ磁場近傍で $\chi,\beta$ は有限で， $p$ と $H$ について十分滑らかである．
2. 磁場反転 $H\to-H$ に対して平衡状態の対称性が保たれる．したがって $I(-H)=-I(H)$ ， $V(-H)=V(H)$ である．

#### 3.2 展開

$I$ は $H$ の奇関数， $V$ は偶関数なので， $\chi=I/(HV)$ と $\beta=-\dfrac1V\left(\dfrac{\partial V}{\partial p}\right)_{H,T}$ は $H$ の偶関数である．
よって，

```math
\chi=\chi_0(p,T)+O(H^2),\qquad
\beta=\beta_0(p,T)+O(H^2)
\tag{8}
```

$p$ への十分な滑らかさを仮定すれば，

```math
\left(\frac{\partial\chi}{\partial p}\right)_{H,T}
=\left(\frac{\partial\chi_0}{\partial p}\right)_T+O(H^2)
\tag{9}
```

したがって，

```math
F(H')=\beta_0\chi_0-\left(\frac{\partial\chi_0}{\partial p}\right)_T+O(H'^2)
```

となり，(7) は，

```math
\ln\left(1+\frac{\Delta V}{V_0}\right)
=\frac{H^2}{2}\left[\beta_0\chi_0-\left(\frac{\partial\chi_0}{\partial p}\right)_T\right]+O(H^4)
\tag{10}
```

#### 3.3 体積変化が小さい場合

$x=\Delta V/V_0$ とおくと，(10) より $x=O(H^2)$ で， $|x|\ll1$ である．
$\ln(1+x)=x+O(x^2)=x+O(H^4)$ なので，

```math
\frac{\Delta V}{V_0}=\frac{H^2}{2}\left[\beta_0\chi_0-\left(\frac{\partial\chi_0}{\partial p}\right)_T\right]+O(H^4)
```

また $\dfrac{\Delta V}{V}=\dfrac{x}{1+x}=x+O(x^2)=\dfrac{\Delta V}{V_0}+O(H^4)$ より，

```math
\boxed{
\frac{\Delta V}{V}
=\frac{H^2}{2}\left[\beta_0\chi_0-\left(\frac{\partial\chi_0}{\partial p}\right)_T\right]+O(H^4)
}
\tag{11}
```

$\beta_0,\chi_0$ は与えられた $p,T$ でのゼロ磁場の値である．
前提 (c) に従って $\beta_0,\chi_0$ を問題文の $\beta,\chi$ と書き， $O(H^4)$ を省略した最低次の近似式として表すと，

```math
\boxed{
\frac{\Delta V}{V}\simeq\frac{H^2}{2}\left\{\beta\chi-\left(\frac{\partial\chi}{\partial p}\right)_T\right\}
}
\tag{12}
```

となり，問題の式が示された．
ここでの $\simeq$ は，誤差が $O(H^4)$ の弱磁場近似であることを表す．

### 4．適用条件と補足

**$|\Delta V|\ll V$ だけでは不十分な理由**:
$\beta,\chi$ の磁場依存性を許すと，この条件だけでは (12) の形は一般には成立しない．
たとえば $\beta=\beta_0$ 一定， $\chi=\chi_0(1+aH^2)$ ， $\chi$ の圧力依存性なしの場合，(7) から $\ln(V/V_0)=\beta_0\chi_0(H^2/2+aH^4/4)$ となる．
$H$ における $\chi(H)$ を (12) に代入した $\beta_0\chi_0(H^2/2+aH^4/2)$ とは $O(H^4)$ の項が異なる．
したがって (12) は $O(H^4)$ を除いた最低次の結果であり，これが前提 (c) の理由である．

**過程の条件**:
磁場を変える間は $T$ だけでなく $p$ も一定に保つ必要がある．
ここでは定圧・等温の準静的な平衡過程を扱った．

**SI単位系**:
磁気仕事を $\mu_0H\,dI$ とする場合， $dG=-S\,dT+V\,dp-\mu_0I\,dH$ となる．
(4) は $\left(\dfrac{\partial V}{\partial H}\right)_{p,T}=-\mu_0\left(\dfrac{\partial I}{\partial p}\right)_{H,T}$ に，(12) は $\dfrac{\Delta V}{V}\simeq\dfrac{\mu_0H^2}{2}\left\{\beta\chi-\left(\dfrac{\partial\chi}{\partial p}\right)_T\right\}$ になる．
ただし $\chi=I/(HV)$ の定義は変えない．
問題文の式は， $\mu_0$ を $H$ の定義に吸収した規約に対応する．
