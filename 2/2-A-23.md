# 演習問題【2-A-23】

## 解答

求める係数は，準静的かつ可逆な断熱過程における温度変化を表す量である．
可逆断熱過程ではエントロピー $S$ が一定に保たれるため， $dS=0$ が成り立つ．
以下では，エントロピー一定の条件を用いて導出する．

エントロピー $S$ を温度 $T$ と体積 $V$ の関数 $S(T,V)$ と考えると，全微分は

```math
dS=
\left(\frac{\partial S}{\partial T}\right)_V dT
+\left(\frac{\partial S}{\partial V}\right)_T dV
```

と書ける．
断熱過程では $dS=0$ であるから，

```math
0=
\left(\frac{\partial S}{\partial T}\right)_V dT
+\left(\frac{\partial S}{\partial V}\right)_T dV
```

となる．
この式を $dT/dV$ について整理すると，

```math
\left(\frac{\partial T}{\partial V}\right)_S
=-\frac{
\left(\frac{\partial S}{\partial V}\right)_T
}{
\left(\frac{\partial S}{\partial T}\right)_V
}
\tag{1}
```

を得る．
ここで，添字 $S$ はエントロピーを一定に保った偏微分を表す．

次に，式 (1) の分子と分母を，求めやすい熱力学量に置き換える．

まず，定積熱容量 $C_V$ は，体積一定のもとで温度を変化させるのに必要な熱量と温度変化の関係を表す量であり，

```math
C_V=T\left(\frac{\partial S}{\partial T}\right)_V
```

と表される．
したがって，

```math
\left(\frac{\partial S}{\partial T}\right)_V
=\frac{C_V}{T}
\tag{2}
```

である．

また，マクスウェルの関係式の一つとして，

```math
\left(\frac{\partial S}{\partial V}\right)_T
=\left(\frac{\partial p}{\partial T}\right)_V
\tag{3}
```

が成り立つ．
この関係式は，ヘルムホルツ自由エネルギー $F=U-TS$ の全微分

```math
dF=-S\,dT-p\,dV
```

から導かれる．
実際に，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_V,
\qquad
p=-\left(\frac{\partial F}{\partial V}\right)_T
```

であり， $F$ の混合二階偏微分の順序を入れ替えられることから，式 (3) が得られる．

式 (2) と式 (3) を式 (1) に代入すると，

```math
\left(\frac{\partial T}{\partial V}\right)_S
=-\frac{
\left(\frac{\partial p}{\partial T}\right)_V
}{
C_V/T
}
```

となる．
よって，

```math
\left(\frac{\partial T}{\partial V}\right)_S
=-\frac{T}{C_V}
\left(\frac{\partial p}{\partial T}\right)_V
```

である．
両辺に $V$ を掛ければ，求める係数は

```math
\boxed{
V\left(\frac{\partial T}{\partial V}\right)_S
=-\frac{VT}{C_V}
\left(\frac{\partial p}{\partial T}\right)_V
}
```

となる．
これが求める関係式である．

### 温度変化の物理的意味

通常の気体で $C_V>0$ かつ $\left(\partial p/\partial T\right)_V>0$ である場合，上式の右辺は負となる．
したがって，

```math
\left(\frac{\partial T}{\partial V}\right)_S<0
```

であり，エントロピー一定のもとで体積を増加させると温度は低下する．

例えば，物質量 $n$ の理想気体では，状態方程式 $pV=nRT$ より，

```math
\left(\frac{\partial p}{\partial T}\right)_V
=\frac{nR}{V}
```

である．
これを一般式に代入すると，

```math
V\left(\frac{\partial T}{\partial V}\right)_S
=-\frac{nRT}{C_V}
```

を得る．
理想気体では $C_V>0$ であるため，断熱膨張によって温度が低下することが分かる．

なお，状態方程式から求められるのは $\left(\partial p/\partial T\right)_V$ であり， $C_V$ は別途与えられるか，ほかの熱力学的情報から求められる必要がある．
