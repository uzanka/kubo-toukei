# 演習問題【2-A-12】

## 解答

輻射場のエネルギー密度 $u$ ，圧力 $p$ ，絶対温度 $T$ の間には，

```math
p=\frac13u,\qquad u=\sigma T^4
```

が成立する．
ここで， $\sigma$ は正の定数である．
体積 $V$ の輻射場の全エネルギーを $U$ ，全エントロピーを $S$ とすると，

```math
U=uV=\sigma T^4V,\qquad p=\frac13\sigma T^4
\tag{1}
```

である．

### 1．輻射場のエントロピー密度

熱力学第1法則とエントロピーの定義より，可逆準静的過程に対して，

```math
dS=\frac{dU+p\,dV}{T}
\tag{2}
```

が成立する．
式 (1) を式 (2) に代入すると，

```math
dS=\frac{d(\sigma T^4V)+\frac13\sigma T^4\,dV}{T}
```

となる．
ここで，

```math
d(\sigma T^4V)
=4\sigma T^3V\,dT+\sigma T^4\,dV
```

であるから，

```math
\begin{aligned}
dS
&=\frac{
4\sigma T^3V\,dT+\sigma T^4\,dV
+\frac13\sigma T^4\,dV
}{T}\\
&=4\sigma T^2V\,dT
+\frac43\sigma T^3\,dV
\end{aligned}
```

を得る．右辺は，

```math
dS=d\left(\frac43\sigma T^3V\right)
```

と書ける．
したがって，全エントロピーは，

```math
S=\frac43\sigma T^3V+\text{定数}
```

である．
エントロピーは示量性の状態量であり，体積に比例するため，基準を適切に選んで積分定数をゼロとすると，

```math
S=\frac43\sigma T^3V
\tag{3}
```

となる．

エントロピー密度 $s$ は単位体積当たりのエントロピー，すなわち $s=S/V$ である．
したがって，式 (3) より，

```math
\boxed{
s=\frac43\sigma T^3
}
```

を得る．
これが輻射場のエントロピー密度である．

### 2．$p$-$V$ 平面における等温線と断熱線

#### 等温線

等温過程では温度 $T$ が一定である．
式 (1) より，

```math
p=\frac{1}{3}\sigma T^4=\text{一定}
```

となる．
したがって， $p$-$V$ 平面における等温線は，圧力が一定の水平線である．
温度の異なる等温線は，それぞれ異なる圧力に位置する．

#### 断熱線

カルノーサイクルの断熱過程は可逆断熱過程であるため，エントロピーは一定である．
式 (3) より，

```math
S=\frac{4}{3}\sigma T^3V=\text{一定}
```

であるから，

```math
T^3V=\text{一定}
\tag{4}
```

を得る．

一方，式 (1) から，

```math
T=\left(\frac{3p}{\sigma}\right)^{1/4}
```

である．
これを式 (4) に代入すると，

```math
\left(\frac{3p}{\sigma}\right)^{3/4}V
=\text{一定}
```

となる．
定数をまとめれば，

```math
p^{3/4}V=\text{一定}
```

である．
両辺を $4/3$ 乗すると，

```math
\boxed{
pV^{4/3}=\text{一定}
}
```

を得る．
よって，断熱線は，

```math
p\propto V^{-4/3}
```

という右下がりの曲線である．

### 3．カルノーサイクルの考察

高温側の温度を $T_1$ ，低温側の温度を $T_2$ とし，

```math
T_1>T_2
```

とする．
カルノーサイクルを $A\to B\to C\to D\to A$ の順に考える．

各過程は次のとおりである．

- $A\to B$ ： 温度 $T_1$ での等温膨張．輻射場は熱量 $Q_1>0$ を吸収する．
- $B\to C$ ： 可逆断熱膨張．エントロピーは一定である．
- $C\to D$ ： 温度 $T_2$ での等温圧縮．輻射場は熱量 $Q_2>0$ を外部へ放出する．
- $D\to A$ ： 可逆断熱圧縮．エントロピーは一定である．

このサイクルの $p$-$V$ 図では，等温線 $AB$ は高い圧力にある水平線，等温線 $CD$ は低い圧力にある水平線であり，これらを2本の断熱線 $BC$ ， $DA$ が結ぶ．

#### 3.1 吸収熱量と放出熱量

まず，等温過程 $A\to B$ では $T=T_1$ が一定である．
したがって，

```math
dU=d(\sigma T_1^4V)=\sigma T_1^4\,dV
```

である．
式 (2) より，この過程で吸収する熱量は，

```math
\begin{aligned}
Q_1
&=\int_A^B(dU+p\,dV)\\
&=\int_{V_A}^{V_B}
\left(\sigma T_1^4+\frac{1}{3}\sigma T_1^4\right)dV\\
&=\boxed{\frac{4}{3}\sigma T_1^4(V_B-V_A)}
\end{aligned}
\tag{5}
```

となる．
ここで， $V_B>V_A$ であるから $Q_1>0$ である．

同様に，等温過程 $C\to D$ では $T=T_2$ が一定である．
この過程では $V_D<V_C$ であり，輻射場は熱を放出する．
放出熱量の正の大きさを $Q_2$ とすると，

```math
\begin{aligned}
Q_2
&=-\int_C^D(dU+p\,dV)\\
&=-\int_{V_C}^{V_D}\frac{4}{3}\sigma T_2^4\,dV\\
&=\boxed{\frac{4}{3}\sigma T_2^4(V_C-V_D)}
\end{aligned}
\tag{6}
```

となる．

#### 3.2 断熱過程の関係を利用する

断熱過程では $T^3V=\text{一定}$ であるから，過程 $B\to C$ について，

```math
T_1^3V_B=T_2^3V_C
```

となる．
したがって，

```math
\frac{V_B}{V_C}
=\left(\frac{T_2}{T_1}\right)^3
\tag{7}
```

である．

同様に，過程 $D\to A$ について，

```math
T_2^3V_D=T_1^3V_A
```

であるから，

```math
\frac{V_A}{V_D}
=\left(\frac{T_2}{T_1}\right)^3
\tag{8}
```

となる．
式 (7)，(8) より，

```math
\frac{V_B}{V_C}=\frac{V_A}{V_D}
```

である．
この比を $r$ とすると， $V_B=rV_C$ ， $V_A=rV_D$ であるから，

```math
V_B-V_A=r(V_C-V_D)
```

が成立する．
したがって，

```math
\boxed{
\frac{V_B-V_A}{V_C-V_D}
=\left(\frac{T_2}{T_1}\right)^3
}
\tag{9}
```

を得る．

#### 3.3 カルノーサイクルの熱量比と効率

式 (5)，(6)，(9) を用いると，

```math
\begin{aligned}
\frac{Q_1}{Q_2}
&=\frac{T_1^4}{T_2^4}
\frac{V_B-V_A}{V_C-V_D}\\[4pt]
&=\frac{T_1^4}{T_2^4}
\left(\frac{T_2}{T_1}\right)^3\\[4pt]
&=\frac{T_1}{T_2}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\frac{Q_1}{T_1}=\frac{Q_2}{T_2}
}
```

が得られる．
これは，カルノーサイクルにおける熱量と温度の関係である．

サイクル全体では内部エネルギーの変化がゼロであるため，熱力学第1法則より，輻射場が外部にする正味の仕事 $W$ は，

```math
W=Q_1-Q_2
```

である．
したがって，熱機関の効率 $\eta$ は，

```math
\begin{aligned}
\eta
&=\frac{W}{Q_1}\\
&=1-\frac{Q_2}{Q_1}\\
&=\boxed{1-\frac{T_2}{T_1}}
\end{aligned}
```

となる．
また，仕事は，

```math
\boxed{
W=\frac{4}{3}\sigma T_1^3(T_1-T_2)(V_B-V_A)
}
```

とも表される．

以上より，輻射場のエントロピー密度は $s=\frac{4}{3}\sigma T^3$ であり，等温線は $p$-$V$ 平面で水平線，断熱線は $pV^{4/3}=\text{一定}$ の曲線となる．
さらに，これらから構成される可逆カルノーサイクルの効率は，

```math
\boxed{
\eta=1-\frac{T_2}{T_1}
}
```

であり，高温側と低温側の絶対温度だけで決まるのである．
