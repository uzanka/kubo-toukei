# 演習問題【2-B-35】

## 解答

### 1. 内部エネルギー $U$ の導出

熱力学第一法則および内部エネルギーの全微分について考える．
内部エネルギー $U(T, V)$ の全微分は次のように書ける：

$$dU = \left(\frac{\partial U}{\partial T}\right)_V dT + \left(\frac{\partial U}{\partial V}\right)_T dV$$

ここで，定積分子熱の定義より $\left(\frac{\partial U}{\partial T}\right)_V = C_V$ である．
また，熱力学の基本関係式（マクスウェルの関係式）を用いると，

$$\left(\frac{\partial U}{\partial V}\right)_T = T \left(\frac{\partial p}{\partial T}\right)_V - p$$

が成り立つ．

van der Waals の状態方程式 $p = \frac{RT}{V-b} - \frac{a}{V^2}$ を用いて， $\left(\frac{\partial p}{\partial T}\right)_V$ を計算する：

$$\left(\frac{\partial p}{\partial T}\right)_V = \frac{R}{V-b}$$

これを代入すると，

$$\left(\frac{\partial U}{\partial V}\right)_T = T \left(\frac{R}{V-b}\right) - \left(\frac{RT}{V-b} - \frac{a}{V^2}\right) = \frac{a}{V^2}$$

この式を $V$ について積分することで $U$ の $V$ 依存性を求める．
$T$ は定数として扱う：

$$U(T, V) = \int \frac{a}{V^2} dV + f(T) = -\frac{a}{V} + f(T)$$

ここで $f(T)$ は温度のみに依存する関数である．

再び $\left(\frac{\partial U}{\partial T}\right)_V = C_V$ を用いると，

$$\frac{df(T)}{dT} = C_V$$

$C_V$ は定数であるから，これを積分して $f(T) = C_V T + \text{const.}$ を得る．

したがって，求める内部エネルギーは，

$$U = C_V T - \frac{a}{V} + \text{const.}$$

となる．

### 2. 断熱準静的変化の証明

断熱準静的変化ではエントロピーが一定（ $dS = 0$ ）である．
エントロピーの微分 $dS$ は次のように表される：

$$dS = \frac{1}{T} dU + \frac{p}{T} dV = 0$$

$$dU = -p dV \quad \dots (\text{A})$$

一方で，内部エネルギーの全微分は，

$$dU = C_V dT + \left(\frac{\partial U}{\partial V}\right)_T dV = C_V dT + \frac{a}{V^2} dV \quad \dots (\text{B})$$

である．

式(A)と式(B)を等置すると，

$$C_V dT + \frac{a}{V^2} dV = -p dV$$

$$C_V dT = -\left(p + \frac{a}{V^2}\right) dV$$

van der Waals の状態方程式 $\left(p + \frac{a}{V^2}\right) = \frac{RT}{V-b}$ を代入する：

$$C_V dT = -\frac{RT}{V-b} dV$$

$$\frac{C_V}{R} \frac{dT}{T} = -\frac{dV}{V-b}$$

ここで， $\gamma = \frac{C_V + R}{C_V} = 1 + \frac{R}{C_V}$ より， $\frac{R}{C_V} = \gamma - 1$ である．
したがって，

$$\frac{1}{\gamma - 1} \frac{dT}{T} = -\frac{dV}{V-b}$$

$$\frac{dT}{T} + (\gamma - 1) \frac{dV}{V-b} = 0$$

この変数分離形の微分方程式を積分すると，

$$\ln T + (\gamma - 1) \ln(V - b) = \text{const.}$$

$$\ln [T (V - b)^{\gamma - 1}] = \text{const.}$$

$$T (V - b)^{\gamma - 1} = \text{const.}$$

が得られる．
これが一つ目の証明である．

次に，これを用いて二つ目の式を導く．
状態方程式より $T = \frac{1}{R} \left(p + \frac{a}{V^2}\right)(V - b)$ であるから，これを代入すると，

$$\frac{1}{R} \left(p + \frac{a}{V^2}\right)(V - b) \cdot (V - b)^{\gamma - 1} = \text{const.}$$

$$\left(p + \frac{a}{V^2}\right)(V - b)^\gamma = \text{const.}$$

が成り立つ．
これで二つ目の証明も完了した．

### 3. 真空中の断熱膨張における温度変化

真空への断熱膨張（ジュール膨張）では，外部に対して仕事をせず ( $W=0$ )，外部との熱のやり取りもない ( $Q=0$ )．
熱力学第一法則 $\Delta U = Q - W$ より， $\Delta U = 0$ ，すなわち内部エネルギーは変化しない ( $U = \text{const.}$ )．

状態1から状態2への変化において，

$$U_2 - U_1 = 0$$

$$C_V T_2 - \frac{a}{V_2} + \text{const.} - \left(C_V T_1 - \frac{a}{V_1} + \text{const.}\right) = 0$$

$$C_V (T_2 - T_1) - a \left(\frac{1}{V_2} - \frac{1}{V_1}\right) = 0$$

$$C_V (T_2 - T_1) = a \left(\frac{1}{V_2} - \frac{1}{V_1}\right)$$

$$T_2 - T_1 = \frac{a}{C_V} \left(\frac{1}{V_2} - \frac{1}{V_1}\right)$$

よって，温度変化は $\frac{a}{C_V} \left(\frac{1}{V_2} - \frac{1}{V_1}\right)$ である．

## 解説

### van der Waals 気体とは

理想気体は分子自身の体積や分子間力を無視しているが，実在する気体ではそれらを考慮する必要がある．
van der Waals の式は，分子が占める有効な体積（ $V-b$ ）と，分子間力による圧力の減少（ $p + a/V^2$ ）を考慮した，実在気体の性質をよく表すモデルである．

### 内部エネルギーの $V$ 依存性

理想気体の場合，内部エネルギーは温度のみの関数 ( $U=C_V T$ ) であるが，van der Waals 気体のように分子間力がある場合，分子が近づいたり離れたりすることでエネルギーが変化する．
この問題では，そのエネルギー変化が $-\frac{a}{V}$ という形で現れることを示している．

### 断熱準静的変化 vs 真空への断熱膨張

- **断熱準静的変化**：
  非常にゆっくりと膨張し，常に平衡状態を保ちながら断熱される過程である．
  このとき，気体は膨張に伴って外部へ仕事をするため，エネルギーを消費し，温度が下がる．
- **真空への断熱膨張（ジュール膨張）**：
  真空に向かって急激に膨張する過程である．
  外部に押し返す対象がないため，気体は仕事をしない．
  その結果，内部エネルギーは一定に保たれる．
  ただし，van der Waals 気体の場合，分子が離れることで分子間力のポテンシャルエネルギーが増大するため，運動エネルギー（温度）が減少する．
