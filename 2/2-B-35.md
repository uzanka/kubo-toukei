# 演習問題【2-B-35】

## 解答

### 1．内部エネルギー $U$ の導出

1 mol の van der Waals 気体を考える．
圧力を $p$ ，モル体積を $V$ ，絶対温度を $T$ ，内部エネルギーを $U$ ，定積モル比熱を $C_V$ とする．
問題の状態方程式は，

```math
\left(p+\frac{a}{V^2}\right)(V-b)=RT
```

である．
これを圧力 $p$ について解くと，

```math
p=\frac{RT}{V-b}-\frac{a}{V^2}
\tag{1}
```

となる．
ここで， $a,b$ は van der Waals 定数， $R$ は気体定数である．
また， $C_V$ は温度によらない定数とする．

内部エネルギーの全微分は，

```math
dU=
\left(\frac{\partial U}{\partial T}\right)_V dT
+\left(\frac{\partial U}{\partial V}\right)_T dV
```

と表される．
定積モル比熱の定義より，

```math
\left(\frac{\partial U}{\partial T}\right)_V=C_V
```

であるため，

```math
dU=C_V\,dT+
\left(\frac{\partial U}{\partial V}\right)_T dV
\tag{2}
```

となる．

次に，内部エネルギーの体積微分を求める．
熱力学の基本関係式

```math
dU=T\,dS-p\,dV
```

から，温度一定のもとで，

```math
\left(\frac{\partial U}{\partial V}\right)_T
=T\left(\frac{\partial S}{\partial V}\right)_T-p
```

を得る．
ここで，マクスウェルの関係式

```math
\left(\frac{\partial S}{\partial V}\right)_T
=\left(\frac{\partial p}{\partial T}\right)_V
```

を用いると，

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_T
=T\left(\frac{\partial p}{\partial T}\right)_V-p
}
\tag{3}
```

となる．

式 (1) を温度 $T$ について偏微分すると，

```math
\left(\frac{\partial p}{\partial T}\right)_V
=\frac{R}{V-b}
```

である．
これを式 (3) に代入すれば，

```math
\begin{aligned}
\left(\frac{\partial U}{\partial V}\right)_T
&=\frac{RT}{V-b}
-\left(\frac{RT}{V-b}-\frac{a}{V^2}\right)\\
&=\frac{a}{V^2}
\end{aligned}
```

を得る．
したがって，式 (2) は，

```math
dU=C_V\,dT+\frac{a}{V^2}\,dV
\tag{4}
```

となる．

式 (4) を積分すると，

```math
U=\int C_V\,dT+\int\frac{a}{V^2}\,dV+U_0
```

である．
$C_V$ は定数なので，

```math
\int C_V\,dT=C_VT
```

であり，

```math
\int\frac{a}{V^2}\,dV=-\frac{a}{V}
```

となる．
ここで $U_0$ は積分定数である．
よって，内部エネルギーは，

```math
\boxed{
U=C_VT-\frac{a}{V}+U_0
}
```

と表される．
これで第一の結論が得られた．

### 2．断熱準静的変化における関係式の導出

断熱準静的変化については，解答例と同様に，可逆な断熱変化を考える．
この場合，熱の出入りがなくエントロピー $S$ は一定であるため，

```math
dS=0
```

が成り立つ．

熱力学の基本関係式

```math
dU=T\,dS-p\,dV
```

をエントロピーについて整理すると，

```math
dS=\frac{1}{T}\,dU+\frac{p}{T}\,dV
\tag{5}
```

である．
式 (4) を式 (5) に代入すると，

```math
dS=\frac{C_V}{T}\,dT
+\frac{a}{TV^2}\,dV+\frac{p}{T}\,dV
```

となる．
状態方程式 (1) より，

```math
\frac{p}{T}=\frac{R}{V-b}-\frac{a}{TV^2}
```

であるため，式 (5) は，

```math
dS=\frac{C_V}{T}\,dT+\frac{R}{V-b}\,dV
\tag{6}
```

と簡単になる．

可逆断熱変化では $dS=0$ であるから，

```math
\frac{C_V}{T}\,dT+\frac{R}{V-b}\,dV=0
```

を得る．
両辺を $C_V$ で割ると，

```math
\frac{dT}{T}+\frac{R}{C_V}\frac{dV}{V-b}=0
```

となる．
ここで，

```math
\gamma=\frac{C_V+R}{C_V}
=1+\frac{R}{C_V}
```

と定義されているので，

```math
\frac{R}{C_V}=\gamma-1
```

である．
したがって，

```math
\frac{dT}{T}
+(\gamma-1)\frac{dV}{V-b}=0
\tag{7}
```

となる．

式 (7) を積分すれば，

```math
\ln T+(\gamma-1)\ln(V-b)=\text{const.}
```

である．
対数の性質を用いてまとめると，

```math
\ln\left[T(V-b)^{\gamma-1}\right]=\text{const.}
```

となるので，

```math
\boxed{
T(V-b)^{\gamma-1}=\text{const.}
}
\tag{8}
```

を得る．
これが求める第一の断熱関係式である．

さらに，状態方程式から，

```math
T=\frac{1}{R}\left(p+\frac{a}{V^2}\right)(V-b)
```

である．
これを式 (8) に代入すると，

```math
\frac{1}{R}
\left(p+\frac{a}{V^2}\right)(V-b)^\gamma
=\text{const.}
```

となる．
$R$ は定数であるため，これを右辺の定数に含めれば，

```math
\boxed{
\left(p+\frac{a}{V^2}\right)(V-b)^\gamma
=\text{const.}
}
\tag{9}
```

を得る．
これが求める第二の断熱関係式である．

### 3．真空中への断熱膨張による温度変化

最後に，気体を真空中へ断熱膨張させる場合を考える．
これは不可逆過程であり，前節で導いた可逆断熱変化の関係式は適用できない．

真空への膨張では，気体は外部に対して膨張仕事をしない．
また，容器が断熱されているため，外部との熱のやり取りもない．
したがって，

```math
Q=0,\qquad W=0
```

である．
熱力学第一法則

```math
\Delta U=Q-W
```

より，

```math
\Delta U=0
```

となる．
よって，初期状態を $(T_1,V_1)$ ，終状態を $(T_2,V_2)$ とすると，

```math
U_2=U_1
```

である．
内部エネルギーの式を代入すれば，

```math
C_VT_2-\frac{a}{V_2}+U_0
=C_VT_1-\frac{a}{V_1}+U_0
```

となる．
両辺で積分定数 $U_0$ を消去して整理すると，

```math
C_V(T_2-T_1)
=a\left(\frac{1}{V_2}-\frac{1}{V_1}\right)
```

を得る．
したがって，真空への断熱膨張による温度変化は，

```math
\boxed{
T_2-T_1
=\frac{a}{C_V}
\left(\frac{1}{V_2}-\frac{1}{V_1}\right)
}
```

である．

膨張では $V_2>V_1$ であるから，

```math
\frac{1}{V_2}-\frac{1}{V_1}<0
```

となる．
通常 $a>0$ ， $C_V>0$ であるため，

```math
T_2-T_1<0
```

である．
したがって，van der Waals 気体は真空中への断熱膨張によって温度が低下する．
これは，体積が増えることで分子間引力に由来する内部エネルギーの項 $-a/V$ が増加し，内部エネルギー全体を一定に保つために温度が低下することに対応する．
