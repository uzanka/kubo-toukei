# 演習問題【2-B-37】

## 解答

### 1．エンタルピーに関する熱力学的恒等式

圧力 $p$ ，体積 $V$ ，絶対温度 $T$ の実在気体を考える．
内部エネルギーを $U$ ，エントロピーを $S$ ，エンタルピーを

```math
H=U+pV
```

と定義する．
熱力学の基本関係式

```math
dU=T\,dS-p\,dV
```

から，エンタルピーの全微分は

```math
\begin{aligned}
dH
&=dU+p\,dV+V\,dp\\
&=T\,dS+V\,dp
\end{aligned}
```

となる．
したがって，温度を一定に保ったとき，

```math
\left(\frac{\partial H}{\partial p}\right)_T
=T\left(\frac{\partial S}{\partial p}\right)_T+V
\tag{1}
```

である．

ここで，ギブズ自由エネルギー $G=H-TS$ の全微分は

```math
dG=-S\,dT+V\,dp
```

と表される．
$G$ は状態量であるため，混合二階偏微分の順序を交換できる．
このことから，マクスウェルの関係式

```math
\left(\frac{\partial S}{\partial p}\right)_T
=-\left(\frac{\partial V}{\partial T}\right)_p
\tag{2}
```

が得られる．
式 (2) を式 (1) に代入すると，

```math
\boxed{
\left(\frac{\partial H}{\partial p}\right)_T
=V-T\left(\frac{\partial V}{\partial T}\right)_p
}
\tag{3}
```

となる．
以下では，この恒等式を用いて，圧力が小さいときの展開係数 $A(T)$ の性質を求める．

### 2．展開式を用いて $A(T)\propto T$ を導く

問題文より，圧力が十分に小さい範囲で，

```math
pV=A(T)+B(T)p+C(T)p^2+\cdots
\tag{4}
```

および

```math
U=\alpha(T)+\beta(T)p+\gamma(T)p^2+\cdots
\tag{5}
```

と展開できる．
ここで，各係数は温度 $T$ のみの関数である．

まず，式 (4)，(5) と $H=U+pV$ から，

```math
H=(\alpha+A)+(\beta+B)p
+(\gamma+C)p^2+\cdots
\tag{6}
```

を得る．
これを温度一定のもとで圧力 $p$ について偏微分すると，

```math
\left(\frac{\partial H}{\partial p}\right)_T
=(\beta+B)+2(\gamma+C)p+\cdots
\tag{7}
```

となる．

次に，式 (4) を $p$ で割ると，

```math
V=\frac{A(T)}{p}+B(T)+C(T)p+\cdots
\tag{8}
```

である．
ここで，プライム記号を温度による微分として，

```math
A'=\frac{dA}{dT},\qquad
B'=\frac{dB}{dT},\qquad
C'=\frac{dC}{dT}
```

と定義する．
式 (8) を温度一定ではなく圧力一定のもとで温度微分すると，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=\frac{A'}{p}+B'+C'p+\cdots
\tag{9}
```

を得る．

式 (8)，(9) を熱力学的恒等式 (3) に代入すると，

```math
\begin{aligned}
\left(\frac{\partial H}{\partial p}\right)_T
={}&\left(\frac{A}{p}+B+Cp+\cdots\right)\\
&-T\left(\frac{A'}{p}+B'+C'p+\cdots\right)
\end{aligned}
```

である．
したがって，

```math
\left(\frac{\partial H}{\partial p}\right)_T
=\frac{A-TA'}{p}
+(B-TB')+(C-TC')p+\cdots
\tag{10}
```

となる．

式 (7) と式 (10) は，同じエンタルピーの圧力微分を表している．
式 (7) は，圧力 $p\to0$ で有限の値 $\beta+B$ に近づく．
よって，式 (10) の $1/p$ の項が発散しないためには，

```math
A-TA'=0
\tag{11}
```

でなければならない．
より直接的には，式 (7) と式 (10) を等置して両辺に $p$ を掛け， $p\to0$ の極限を取れば，式 (11) が得られる．

式 (11) を整理すると，

```math
\frac{dA}{dT}=\frac{A}{T}
```

である．
したがって，

```math
\frac{d}{dT}\left(\frac{A}{T}\right)=0
```

となるため， $A/T$ は温度によらない定数である．
よって，

```math
\boxed{
A(T)=kT
}
\tag{12}
```

を得る．
ここで $k$ は温度によらない定数である．

### 3．実在気体を用いて絶対温度を測定する

式 (4) より，圧力をゼロに近づけると，

```math
\boxed{
A(T)=\lim_{p\to0}pV
}
\tag{13}
```

である．
式 (12) と式 (13) から，低圧極限における積 $pV$ は絶対温度 $T$ に比例することが分かる．

同じ気体温度計を用い，基準温度を $T_0$ ，その温度における係数を $A(T_0)=A_0$ とする．
式 (12) より，

```math
A(T)=kT,\qquad A_0=kT_0
```

であるため，両式の比を取ると比例定数 $k$ が消去され，

```math
\frac{A(T)}{A_0}=\frac{T}{T_0}
```

となる．
したがって，

```math
\boxed{
T=T_0\frac{A(T)}{A_0}
}
\tag{14}
```

を得る．
例えば，基準温度として氷点の $T_0=273.15\,\mathrm K$ を用いれば，

```math
\boxed{
T=273.15\,\mathrm K
\frac{A(T)}{A_{\mathrm{ice}}}
}
```

と表される．
ここで $A_{\mathrm{ice}}$ は，氷点における低圧極限の $pV$ の値である．

実際には，有限の圧力では式 (4) の $Bp$ ， $Cp^2$ などの項が寄与するため，複数の十分低い圧力で $pV$ を測定し， $p\to0$ に外挿して $A(T)$ を求める．
同じ操作を基準温度でも行えば，式 (14) により絶対温度を測定できる．

以上より，実在気体であっても，低圧極限で $pV$ が絶対温度に比例するという性質を利用することで，絶対温度を測定できることが示された．
