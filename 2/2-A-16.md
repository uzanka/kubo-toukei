# 演習問題【2-A-16】

## 解答

### (i) の証明

定積比熱 $c_v$ の定義は，体積一定 ( $v = \text{const.}$ ) のとき，単位質量あたりの加えられた熱量 $d'q$ を温度変化 $dT$ で割ったものである．

$$c_v = \left(\frac{d'q}{dT}\right)_v \quad \cdots (1)$$

熱力学第二法則より，平衡状態間の準静的変化において，熱量 $d'q$ は温度 $T$ とエントロピー変化 $ds$ を用いて

$$d'q = T ds \quad \cdots (2)$$

と表される．
式 (2) を式 (1) に代入すると，

$$c_v = \left(\frac{T ds}{dT}\right)_v = T \left(\frac{\partial s}{\partial T}\right)_v$$

これより，

$$\left(\frac{\partial s}{\partial T}\right)_v = \frac{c_v}{T}$$

が得られる．

定圧比熱 $c_p$ についても，圧力一定 ( $p = \text{const.}$ ) の条件において同様の議論により，

$$\left(\frac{\partial s}{\partial T}\right)_p = \frac{c_p}{T}$$

が得られる．

### (ii) の証明

熱力学基本式

$$du = T ds - p dv \quad \cdots (3)$$

を用いる．
内部エネルギー $u$ を温度 $T$ と体積 $v$ の関数 $u(T, v)$ と考え，まず $v$ を一定にして $T$ で偏微分すると，

$$\left(\frac{\partial u}{\partial T}\right)_v = T \left(\frac{\partial s}{\partial T}\right)_v \quad \cdots (4)$$

が得られる．
次に，式 (4) の両辺を $v$ で偏微分する．
左辺は

$$\frac{\partial}{\partial v} \left( \frac{\partial u}{\partial T} \right)_v = \frac{\partial^2 u}{\partial v \partial T}$$

右辺において， $T$ は $v$ に依存しないのでそのまま外に出せ，

$$\frac{\partial}{\partial v} \left[ T \left(\frac{\partial s}{\partial T}\right)_v \right] = T \frac{\partial^2 s}{\partial v \partial T}$$

偏微分の順序は交換可能であるから，

$$\frac{\partial^2 u}{\partial T \partial v} = T \frac{\partial^2 s}{\partial T \partial v}$$

が示された．

エンタルピー $h = u + pv$ については，式 (3) から

$$dh = du + p\,dv + v\,dp = T ds + v dp$$

特に定圧条件では，

$$\left(\frac{\partial h}{\partial T}\right)_p = T \left(\frac{\partial s}{\partial T}\right)_p$$

この両辺を $p$ で偏微分すると，上と同様に，

$$\frac{\partial^2 h}{\partial p \partial T} = T \frac{\partial^2 s}{\partial p \partial T}$$

となり，題意は示された．

### (iii) の証明

第1式 $\left(\frac{\partial s}{\partial v}\right)_T = \left(\frac{\partial p}{\partial T}\right)_v$ は，問題 [15] の解答により証明済みである．

第2式 $\left(\frac{\partial s}{\partial p}\right)_T = -\left(\frac{\partial v}{\partial T}\right)_p$ を証明する．
内部エネルギー $u$ を $T, p$ を独立変数として表し， Schwarz の定理（状態量の混合偏導関数の交換可能性）を用いる．

まず，式 (3) に $s(T,p)$ と $v(T,p)$ の全微分を代入すると，

$$du = \left[ T \left(\frac{\partial s}{\partial p}\right)_T - p \left(\frac{\partial v}{\partial p}\right)_T \right] dp + \left[ T \left(\frac{\partial s}{\partial T}\right)_p - p \left(\frac{\partial v}{\partial T}\right)_p \right] dT$$

これと $du = (\partial u/\partial p)_T\,dp + (\partial u/\partial T)_p\,dT$ とを比較すると，

$$\left(\frac{\partial u}{\partial p}\right)_T = T \left(\frac{\partial s}{\partial p}\right)_T - p \left(\frac{\partial v}{\partial p}\right)_T \quad \cdots (5)$$

$$\left(\frac{\partial u}{\partial T}\right)_p = T \left(\frac{\partial s}{\partial T}\right)_p - p \left(\frac{\partial v}{\partial T}\right)_p \quad \cdots (6)$$

が得られる．
$u$ は状態量であるから，Schwarz の定理により

$$\frac{\partial}{\partial T} \left( \frac{\partial u}{\partial p} \right)_T = \frac{\partial}{\partial p} \left( \frac{\partial u}{\partial T} \right)_p$$

式 (5) の両辺を $T$ で偏微分すると，

$$\text{左辺} = \left(\frac{\partial s}{\partial p}\right)_T + T \frac{\partial^2 s}{\partial T \partial p} - p \frac{\partial^2 v}{\partial T \partial p}$$

式 (6) の両辺を $p$ で偏微分すると，

$$\text{右辺} = T \frac{\partial^2 s}{\partial p \partial T} - \left(\frac{\partial v}{\partial T}\right)_p - p \frac{\partial^2 v}{\partial p \partial T}$$

偏微分の順序交換 $\frac{\partial^2 s}{\partial T \partial p} = \frac{\partial^2 s}{\partial p \partial T}$ および $\frac{\partial^2 v}{\partial T \partial p} = \frac{\partial^2 v}{\partial p \partial T}$ を用いると，両辺の第 2 項および第 3 項が打ち消し合い，

$$\left(\frac{\partial s}{\partial p}\right)_T = -\left(\frac{\partial v}{\partial T}\right)_p$$

が得られる．
題意は示された．

## 解説

### 1. 比熱とエントロピー

定積比熱 $c_v$ と定圧比熱 $c_p$ は，それぞれ体積一定，圧力一定のもとでの熱量を温度変化で割った量として定義される．
熱力学第二法則 $d'q = T\,ds$ を用いると，これらはエントロピーの温度微分として表せる．
これは，比熱が実質的に「エントロピーの温度依存性」を測る量であることを示している．

### 2. 状態量の完全微分

内部エネルギー $u$ やエンタルピー $h$ は状態量であり，その微小変化は完全微分である．
これにより偏微分の順序は交換可能であり (Schwarz の定理)，この性質を用いてマクスウェルの関係式をはじめとする熱力学の重要な関係式が導かれる．

### 3. マクスウェルの関係式

エントロピー $s$ は直接測定できないが，マクスウェルの関係式により，圧力 $p$ や温度 $T$ ，体積 $v$ という実驗的に_accessible な物理量のみで表せる．
特に $\left(\partial s/\partial p\right)_T = -\left(\partial v/\partial T\right)_p$ は，「一定温度で圧力を変化させたときのエントロピー変化が，熱膨張係数で与えられる」ことを意味し，熱力学の実測物理量との結びつきをよく示している．
