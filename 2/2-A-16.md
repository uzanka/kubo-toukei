# 演習問題【2-A-16】

## 解答

### (i) 比熱とエントロピーの偏微分の関係

定積比熱 $c_v$ と定圧比熱 $c_p$ は，それぞれ体積一定および圧力一定の条件で，単位質量当たりの温度変化に対する吸収熱量の割合として定義される．
すなわち，

```math
c_v=\left(\frac{\delta q_{\mathrm{rev}}}{dT}\right)_v,
\qquad
c_p=\left(\frac{\delta q_{\mathrm{rev}}}{dT}\right)_p
```

である．
ここで， $\delta q_{\mathrm{rev}}$ は単位質量当たりの可逆過程で系が吸収する微小熱量である．

エントロピーの定義より，可逆過程では，

```math
\delta q_{\mathrm{rev}}=T\,ds
```

が成立する．
したがって，定積過程では，

```math
c_v
=T\left(\frac{ds}{dT}\right)_v
=T\left(\frac{\partial s}{\partial T}\right)_v
```

である．
よって，

```math
\boxed{
\left(\frac{\partial s}{\partial T}\right)_v
=\frac{c_v}{T}
}
```

を得る．

同様に，定圧過程では，

```math
c_p
=T\left(\frac{ds}{dT}\right)_p
=T\left(\frac{\partial s}{\partial T}\right)_p
```

であるから，

```math
\boxed{
\left(\frac{\partial s}{\partial T}\right)_p
=\frac{c_p}{T}
}
```

となる．
以上より，(i) の2つの関係式が証明された．

### (ii) 内部エネルギーとエンタルピーの混合偏微分の関係

#### 1．内部エネルギーについて

熱力学の基本関係式は，

```math
du=T\,ds-p\,dv
\tag{1}
```

である．
ここで， $u$ は単位質量当たりの内部エネルギー， $v$ は比容である．

内部エネルギー $u$ とエントロピー $s$ を温度 $T$ と比容 $v$ の関数とみなす．
比容一定の条件 $dv=0$ では，式 (1) より，

```math
\left(\frac{\partial u}{\partial T}\right)_v
=T\left(\frac{\partial s}{\partial T}\right)_v
\tag{2}
```

となる．

次に，式 (2) の両辺を温度 $T$ 一定のもとで比容 $v$ について偏微分する．
左辺は，

```math
\left(\frac{\partial}{\partial v}\right)_T
\left(\frac{\partial u}{\partial T}\right)_v
```

となり，右辺は $T$ が一定であるため，

```math
T\left(\frac{\partial}{\partial v}\right)_T
\left(\frac{\partial s}{\partial T}\right)_v
```

となる．
したがって，

```math
\frac{\partial^2u}{\partial v\,\partial T}
=
T\frac{\partial^2s}{\partial v\,\partial T}
```

を得る．
内部エネルギー $u$ とエントロピー $s$ が十分滑らかであれば，混合偏微分の順序を交換できる．
よって，

```math
\boxed{
\frac{\partial^2u}{\partial T\,\partial v}
=
T\frac{\partial^2s}{\partial T\,\partial v}
}
```

が証明された．

#### 2．エンタルピーについて

単位質量当たりのエンタルピーは，

```math
h=u+pv
```

と定義される．
これを微分すると，

```math
dh=du+p\,dv+v\,dp
```

となる．
式 (1) の $du=T\,ds-p\,dv$ を代入すれば，

```math
\begin{aligned}
dh
&=T\,ds-p\,dv+p\,dv+v\,dp\\
&=T\,ds+v\,dp
\end{aligned}
\tag{3}
```

を得る．

圧力一定の条件 $dp=0$ では，式 (3) より，

```math
\left(\frac{\partial h}{\partial T}\right)_p
=T\left(\frac{\partial s}{\partial T}\right)_p
\tag{4}
```

となる．

次に，式 (4) の両辺を温度 $T$ 一定のもとで圧力 $p$ について偏微分する．
$T$ は一定であるから，

```math
\frac{\partial^2h}{\partial p\,\partial T}
=
T\frac{\partial^2s}{\partial p\,\partial T}
```

となる．
混合偏微分の順序を交換すると，

```math
\boxed{
\frac{\partial^2h}{\partial T\,\partial p}
=
T\frac{\partial^2s}{\partial T\,\partial p}
}
```

を得る．
よって，(ii) の2つの関係式が証明された．

### (iii) マクスウェルの関係式

#### 1．第1式の証明

示すべき関係式は，

```math
\left(\frac{\partial s}{\partial v}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_v
```

である．
これは，熱力学の基本関係式 (1) と，内部エネルギー $u$ が状態量であることから導ける．

エントロピー $s$ を $T,v$ の関数とみなすと，

```math
ds=
\left(\frac{\partial s}{\partial T}\right)_v dT
+
\left(\frac{\partial s}{\partial v}\right)_T dv
```

である．
これを式 (1) に代入すれば，

```math
\begin{aligned}
du
={}&T\left(\frac{\partial s}{\partial T}\right)_v dT\\
&+\left[
T\left(\frac{\partial s}{\partial v}\right)_T-p
\right]dv
\end{aligned}
\tag{5}
```

となる．

一方，内部エネルギー $u(T,v)$ の全微分は，

```math
du=
\left(\frac{\partial u}{\partial T}\right)_v dT
+
\left(\frac{\partial u}{\partial v}\right)_T dv
```

である．
$u$ は状態量であるため，その混合偏微分の順序は交換可能である．
したがって，式 (5) の $dT$ および $dv$ の係数について完全微分の条件を適用すると，

```math
\left(\frac{\partial}{\partial v}\right)_T
\left[
T\left(\frac{\partial s}{\partial T}\right)_v
\right]
=
\left(\frac{\partial}{\partial T}\right)_v
\left[
T\left(\frac{\partial s}{\partial v}\right)_T-p
\right]
```

となる．
これを展開すると，

```math
T\frac{\partial^2s}{\partial v\,\partial T}
=
\left(\frac{\partial s}{\partial v}\right)_T
+
T\frac{\partial^2s}{\partial T\,\partial v}
-
\left(\frac{\partial p}{\partial T}\right)_v
```

である．
ここで，エントロピー $s$ の混合偏微分の順序を交換すると，混合偏微分の項が相殺される．よって，

```math
\boxed{
\left(\frac{\partial s}{\partial v}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_v
}
```

を得る．

#### 2．第2式の証明

示すべき関係式は，

```math
\left(\frac{\partial s}{\partial p}\right)_T
=
-\left(\frac{\partial v}{\partial T}\right)_p
```

である．
この式も，内部エネルギー $u$ の完全微分性を用いて導く．

エントロピー $s$ と比容 $v$ を $T,p$ の関数とみなすと，

```math
ds=
\left(\frac{\partial s}{\partial T}\right)_p dT
+
\left(\frac{\partial s}{\partial p}\right)_T dp
```

および，

```math
dv=
\left(\frac{\partial v}{\partial T}\right)_p dT
+
\left(\frac{\partial v}{\partial p}\right)_T dp
```

である．
これらを熱力学の基本関係式

```math
du=T\,ds-p\,dv
```

に代入すると，

```math
\begin{aligned}
du
={}&
\left[
T\left(\frac{\partial s}{\partial T}\right)_p
-p\left(\frac{\partial v}{\partial T}\right)_p
\right]dT\\
&+
\left[
T\left(\frac{\partial s}{\partial p}\right)_T
-p\left(\frac{\partial v}{\partial p}\right)_T
\right]dp
\end{aligned}
\tag{6}
```

を得る．
したがって，係数を比較すると，

```math
\left(\frac{\partial u}{\partial p}\right)_T
=
T\left(\frac{\partial s}{\partial p}\right)_T
-p\left(\frac{\partial v}{\partial p}\right)_T
\tag{7}
```

および，

```math
\left(\frac{\partial u}{\partial T}\right)_p
=
T\left(\frac{\partial s}{\partial T}\right)_p
-p\left(\frac{\partial v}{\partial T}\right)_p
\tag{8}
```

となる．

内部エネルギー $u(T,p)$ は状態量であるから，その混合偏微分の順序を交換できる．
すなわち，

```math
\left(\frac{\partial}{\partial T}\right)_p
\left(\frac{\partial u}{\partial p}\right)_T
=
\left(\frac{\partial}{\partial p}\right)_T
\left(\frac{\partial u}{\partial T}\right)_p
\tag{9}
```

が成立する．

式 (7) の両辺を温度 $T$ について圧力一定のもとで偏微分すると，

```math
\begin{aligned}
\left(\frac{\partial}{\partial T}\right)_p
\left(\frac{\partial u}{\partial p}\right)_T
={}&
\left(\frac{\partial s}{\partial p}\right)_T
+
T\frac{\partial^2s}{\partial T\,\partial p}\\
&-p\frac{\partial^2v}{\partial T\,\partial p}
\end{aligned}
\tag{10}
```

となる．
一方，式 (8) の両辺を圧力 $p$ について温度一定のもとで偏微分すると，

```math
\begin{aligned}
\left(\frac{\partial}{\partial p}\right)_T
\left(\frac{\partial u}{\partial T}\right)_p
={}&
T\frac{\partial^2s}{\partial p\,\partial T}
-\left(\frac{\partial v}{\partial T}\right)_p\\
&-p\frac{\partial^2v}{\partial p\,\partial T}
\end{aligned}
\tag{11}
```

となる．

式 (9) により式 (10) と式 (11) の左辺は等しい．
さらに， $s$ と $v$ は状態量であり，混合偏微分の順序を交換できるため，

```math
\frac{\partial^2s}{\partial T\,\partial p}
=
\frac{\partial^2s}{\partial p\,\partial T},
\qquad
\frac{\partial^2v}{\partial T\,\partial p}
=
\frac{\partial^2v}{\partial p\,\partial T}
```

が成立する．
したがって，両辺に現れる混合偏微分の項が相殺され，

```math
\left(\frac{\partial s}{\partial p}\right)_T
=
-\left(\frac{\partial v}{\partial T}\right)_p
```

を得る．
ゆえに，

```math
\boxed{
\left(\frac{\partial s}{\partial p}\right)_T
=
-\left(\frac{\partial v}{\partial T}\right)_p
}
```

が証明された．

以上より，(iii) の2つのマクスウェルの関係式が得られた．


## 解説

これらの関係式は，熱力学の基本関係式と状態量の完全微分性に由来するものである．
特に，(iii) の第2式は，定温での比エントロピーの圧力依存性が，定圧での比容の温度依存性の負値に等しいことを意味する．
比容の温度依存性は熱膨張と直接結び付いており，測定可能な量からエントロピーの変化を評価できる点が，マクスウェルの関係式の重要な意義である．
