# 演習問題【2-A-16】

## 解答

### (i) の証明

定積比熱 $c_v$ の定義は，体積一定 ( $v = \text{const.}$ ) のとき，単位質量あたりの加えられた熱量 $d'q$ を温度変化 $dT$ で割ったものである．

$$c_v = \left(\frac{d'q}{dT}\right)_v \quad \dots (1)$$

熱力学第二法則より，可逆変化における微小熱量 $d'q$ は温度 $T$ とエントロピー変化 $ds$ を用いて次のように表される．

$$d'q = T ds \quad \dots (2)$$

式 (2) を式 (1) に代入すると，

$$c_v = \left(\frac{T ds}{dT}\right)_v = T \left(\frac{\partial s}{\partial T}\right)_v$$

これより，

$$\left(\frac{\partial s}{\partial T}\right)_v = \frac{c_v}{T}$$

が得られる．
定圧比熱 $c_p$ についても，圧力一定 ( $p = \text{const.}$ ) の条件において同様の議論を行うことで，

$$\left(\frac{\partial s}{\partial T}\right)_p = \frac{c_p}{T}$$

が得られる．

### (ii) の証明

熱力学第一法則（および第二法則）より，単位質量あたりの内部エネルギーの微小変化 $du$ は次のように書ける．

$$du = T ds - p dv \quad \dots (3)$$

ここで，エントロピー $s$ を $T$ と $v$ の関数 $s(T, v)$ と考えると，その全微分は

$$ds = \left(\frac{\partial s}{\partial T}\right)_v dT + \left(\frac{\partial s}{\partial v}\right)_T dv$$

である．
これを式 (3) に代入すると，

$$du = T \left[ \left(\frac{\partial s}{\partial T}\right)_v dT + \left(\frac{\partial s}{\partial v}\right)_T dv \right] - p dv$$

$$du = T \left(\frac{\partial s}{\partial T}\right)_v dT + \left\{ T \left(\frac{\partial s}{\partial v}\right)_T - p \right\} dv \quad \dots (4)$$

式 (4) において，温度一定の条件での内部エネルギーの体積による微分は，

$$\left(\frac{\partial u}{\partial v}\right)_T = T \left(\frac{\partial s}{\partial v}\right)_T$$

である．
この式の両辺をさらに $T$ で偏微分すると，

$$\frac{\partial}{\partial T} \left( \frac{\partial u}{\partial v} \right)_T = \frac{\partial}{\partial T} \left[ T \left(\frac{\partial s}{\partial v}\right)_T \right]$$

$$\frac{\partial^2 u}{\partial T \partial v} = \left(\frac{\partial s}{\partial v}\right)_T + T \frac{\partial^2 s}{\partial T \partial v} \quad \dots (5)$$

（※ ここで，問題文の式 $\frac{\partial^2 u}{\partial T \partial v} = T \frac{\partial^2 s}{\partial T \partial v}$ と比較すると，左辺の定義や前提に違いがある可能性がある．
解答例では $du/dT = T ds/dT$ を用いて直接 $d^2u/dv dT$ を計算している．
以下，解答例の論理に従う．）

解答例の論理に従うと：
式 (3) より， $\left(\frac{\partial u}{\partial T}\right)_v = T \left(\frac{\partial s}{\partial T}\right)_v$ である．
この式の両辺を $v$ で偏微分すると，

$$\frac{\partial}{\partial v} \left( \frac{\partial u}{\partial T} \right)_v = \frac{\partial}{\partial v} \left[ T \left(\frac{\partial s}{\partial T}\right)_v \right]$$

左辺は $\frac{\partial^2 u}{\partial v \partial T}$ であり，右辺において $T$ は $v$ に依存しないため，

$$\frac{\partial^2 u}{\partial v \partial T} = T \frac{\partial^2 s}{\partial v \partial T}$$

となる．
偏微分の順序交換が可能であることから，題意は示された．

また，エンタルピー $h$ については， $dh = T ds + v dp$ である．
同様に， $\left(\frac{\partial h}{\partial T}\right)_p = T \left(\frac{\partial s}{\partial T}\right)_p$ であるから，この両辺を $p$ で偏微分すると，

$$\frac{\partial}{\partial p} \left( \frac{\partial h}{\partial T} \right)_p = \frac{\partial}{\partial p} \left[ T \left(\frac{\partial s}{\partial T}\right)_p \right]$$

$$\frac{\partial^2 h}{\partial p \partial T} = T \frac{\partial^2 s}{\partial p \partial T}$$

となり，こちらも題意は示された．

### (iii) の証明

第1式 $\left(\frac{\partial s}{\partial v}\right)_T = \left(\frac{\partial p}{\partial T}\right)_v$ は，問題 [15] の解答により証明済みである．

次に，第2式 $\left(\frac{\partial s}{\partial p}\right)_T = -\left(\frac{\partial v}{\partial T}\right)_p$ を証明する．
式 (3) $du = T ds - p dv$ を，変数 $T$ と $p$ を用いて書き換える．

$du = \left(\frac{\partial u}{\partial T}\right)_p dT + \left(\frac{\partial u}{\partial p}\right)_T dp$

これに対し，式 (3) を $T$ と $p$ で展開すると，

$$du = T ds - p dv = T \left[ \left(\frac{\partial s}{\partial T}\right)_p dT + \left(\frac{\partial s}{\partial p}\right)_T dp \right] - p \left[ \left(\frac{\partial v}{\partial T}\right)_p dT + \left(\frac{\partial v}{\partial p}\right)_T dp \right]$$

$$du = \left\{ T \left(\frac{\partial s}{\partial T}\right)_p - p \left(\frac{\partial v}{\partial T}\right)_p \right\} dT + \left\{ T \left(\frac{\partial s}{\partial p}\right)_T - p \left(\frac{\partial v}{\partial p}\right)_T \right\} dp \quad \dots (6)$$

ここで，

$$M = T \left(\frac{\partial s}{\partial T}\right)_p - p \left(\frac{\partial v}{\partial T}\right)_p, \quad N = T \left(\frac{\partial s}{\partial p}\right)_T - p \left(\frac{\partial v}{\partial p}\right)_T$$

とおくと， $du$ は完全微分であるから， $\left(\frac{\partial M}{\partial p}\right)_T = \left(\frac{\partial N}{\partial T}\right)_p$ が成り立つ．

$$\frac{\partial}{\partial p} \left[ T \left(\frac{\partial s}{\partial T}\right)_p - p \left(\frac{\partial v}{\partial T}\right)_p \right]_T = \frac{\partial}{\partial T} \left[ T \left(\frac{\partial s}{\partial p}\right)_T - p \left(\frac{\partial v}{\partial p}\right)_T \right]_p$$

左辺を計算すると：

$$\text{LHS} = T \frac{\partial^2 s}{\partial p \partial T} - \left(\frac{\partial v}{\partial T}\right)_p - p \frac{\partial^2 v}{\partial p \partial T}$$

右辺を計算すると：

$$\text{RHS} = \left(\frac{\partial s}{\partial p}\right)_T + T \frac{\partial^2 s}{\partial T \partial p} - p \frac{\partial^2 v}{\partial T \partial p}$$

偏微分の順序交換 $\frac{\partial^2 s}{\partial p \partial T} = \frac{\partial^2 s}{\partial T \partial p}$ および $\frac{\partial^2 v}{\partial p \partial T} = \frac{\partial^2 v}{\partial T \partial p}$ を用いると，両辺の第1項と第3項が打ち消し合い，

$$0 = -\left(\frac{\partial v}{\partial T}\right)_p$$

となるはずだが，これは誤りである．
解答例の論理を確認する．

解答例によれば，

$$(\partial u / \partial p)_T = T (\partial s / \partial p)_T - p (\partial v / \partial p)_T$$

$$(\partial u / \partial T)_p = T (\partial s / \partial T)_p - p (\partial v / \partial T)_p$$

これらに対して，

$\frac{\partial}{\partial T} (\partial u / \partial p)_T = \frac{\partial}{\partial p} (\partial u / \partial T)_p$

を適用する．

左辺：

$$\frac{\partial}{\partial T} \left[ T \left(\frac{\partial s}{\partial p}\right)_T - p \left(\frac{\partial v}{\partial p}\right)_T \right] = \left(\frac{\partial s}{\partial p}\right)_T + T \frac{\partial^2 s}{\partial T \partial p} - p \frac{\partial^2 v}{\partial T \partial p}$$

右辺：

$$\frac{\partial}{\partial p} \left[ T \left(\frac{\partial s}{\partial T}\right)_p - p \left(\frac{\partial v}{\partial T}\right)_p \right] = T \frac{\partial^2 s}{\partial p \partial T} - \left(\frac{\partial v}{\partial T}\right)_p - p \frac{\partial^2 v}{\partial p \partial T}$$

これらを等置すると，

$$\left(\frac{\partial s}{\partial p}\right)_T + T \frac{\partial^2 s}{\partial T \partial p} - p \frac{\partial^2 v}{\partial T \partial p} = T \frac{\partial^2 s}{\partial p \partial T} - \left(\frac{\partial v}{\partial T}\right)_p - p \frac{\partial^2 v}{\partial p \partial T}$$

第1項と第3項が相殺され，

$$\left(\frac{\partial s}{\partial p}\right)_T = -\left(\frac{\partial v}{\partial T}\right)_p$$

が得られる．
題意は示された．

## 解説

### 1. 比熱の定義

比熱とは，物質の温度を $1\,\text{K}$ 上げるために必要な熱量のことである．
- **定積比熱 $c_v$ ** : 体積を一定に保ったまま加熱する場合の比熱．
- **定圧比熱 $c_p$ ** : 圧力を一定に保ったまま加熱する場合の比熱．

これらは，熱力学第二法則 $d'q = T ds$ を用いて，エントロピーの変化率として記述できる．

### 2. 偏微分の順序交換

数学的に，関数が十分に滑らかであれば，偏微分の順序を入れ替えても結果は変わらない．

$$\frac{\partial^2 f}{\partial x \partial y} = \frac{\partial^2 f}{\partial y \partial x}$$

熱力学において，内部エネルギー $u$ やエントロピー $s$ が「状態量」であるということは，これらの関数が完全微分であり，この順序交換が成り立つことを意味する．
これがマクスウェルの関係式を導出する際の強力な武器となる．

### 3. マクスウェルの関係式

(iii) で示した関係式は，マクスウェルの関係式と呼ばれる．
直接測定が困難なエントロピー $s$ の変化を，圧力 $p$ や温度 $T$ ，体積 $V$ といった実験的に測定しやすい変数を用いて表現することを可能にする．
特に $\left(\frac{\partial s}{\partial p}\right)_T = -\left(\frac{\partial v}{\partial T}\right)_p$ は，圧力を変えたときのエントロピーの変化が，温度を変えたときの体積の変化（熱膨張に関連）と深く結びついていることを示している．
