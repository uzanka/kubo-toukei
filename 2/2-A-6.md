# 演習問題【2-A-6】

## 解答

等温線 $t,t'$ に対応する絶対温度を，それぞれ $T_t,T_{t'}$ とする．
また， $AB$ で吸収する熱量を $Q_{AB}>0$ ， $CD$ で放出する熱量の大きさを $Q_{CD}>0$ とする．

本問の循環過程は可逆な準静的循環過程であるから，Clausius の関係式

```math
\oint \frac{\delta Q}{T}=0
```

が成立する．
ここで， $\delta Q$ は系に流入する微小熱量を正とする符号付きの熱量であり， $T$ は熱の授受が行われる際の絶対温度である．

循環過程 $A\to B\to C\to D\to A$ のうち，熱の授受があるのは等温過程 $AB$ と $CD$ のみである．
断熱過程 $BC$ および $DA$ では熱の授受がないため，Clausius の積分への寄与はゼロである．

まず，等温過程 $AB$ では温度が一定値 $T_t$ であるから，

```math
\int_{AB}\frac{\delta Q}{T}
=\frac{1}{T_t}\int_{AB}\delta Q
=\frac{Q_{AB}}{T_t}
```

となる．

一方，等温過程 $CD$ では温度が一定値 $T_{t'}$ であり，系は熱を放出する．
放出熱量の大きさを $Q_{CD}>0$ と定義したため，系に流入する熱量は $-Q_{CD}$ である．したがって，

```math
\int_{CD}\frac{\delta Q}{T}
=-\frac{Q_{CD}}{T_{t'}}
```

となる．

以上を Clausius の関係式に代入すると，

```math
\frac{Q_{AB}}{T_t}
-\frac{Q_{CD}}{T_{t'}}=0
```

を得る．
よって，

```math
\frac{Q_{AB}}{T_t}
=\frac{Q_{CD}}{T_{t'}}
```

であり，これを整理すると，

```math
\boxed{
\frac{Q_{AB}}{Q_{CD}}
=\frac{T_t}{T_{t'}}
}
```

となる．

右辺は等温線 $t,t'$ に対応する絶対温度の比だけで決まり，断熱線 $a,a'$ の具体的な選び方を含まない．

したがって，循環過程 $ABCD$ において， $AB$ で吸収する熱量と $CD$ で放出する熱量の比は，等温線 $t,t'$ のみによって定まり，断熱線の選び方には依存しないことが示された．

## 解説

ここでの結論は，可逆な準静的循環過程という条件に基づくものである．
もし $Q_{CD}$ を放出熱量の正の大きさではなく，系に流入する熱量の符号付きの値として定義した場合には， $Q_{CD}<0$ となり，式は $Q_{AB}/Q_{CD}=-T_t/T_{t'}$ となる．
この符号の違いに注意することが重要である．
