# 演習問題【2-A-6】

## 解答

### 1．証明の準備

本問では，断熱線および等温線に沿う過程を可逆準静的過程とする．
準静的であることだけでは可逆性は保証されないため，この仮定は必要である．

また，等温線 $t$ は等温線 $t'$ より高温であるとする．
各等温線上の過程は，それぞれ対応する単一の熱源 $H,L$ との間で熱の授受を行うものとする．
異なる作動物質を比較する場合も，同じ熱源 $H,L$ と熱平衡になる等温状態を比較する．
これは熱力学第零法則による温度レベルの同定であり，絶対温度の数値や温度比をあらかじめ仮定するものではない．

等温過程での熱交換以外に熱の授受はなく，断熱過程では熱交換がないものとする．

異なる断熱線の組から構成される二つの可逆循環過程を考える．

- 循環過程 $\mathcal C_1$ ： 断熱線 $a_1,a_1'$ と等温線 $t,t'$ から構成する．
- 循環過程 $\mathcal C_2$ ： 断熱線 $a_2,a_2'$ と等温線 $t,t'$ から構成する．

各循環過程の向きは，等温線 $t$ 上で熱源 $H$ から熱を吸収し，等温線 $t'$ 上で熱源 $L$ へ熱を放出する向きに選ぶ．

循環過程 $\mathcal C_i$ について，熱源 $H$ から吸収する熱量を $Q_{h,i}>0$ ，熱源 $L$ へ放出する熱量の大きさを $Q_{c,i}>0$ とする．
これらは熱量の正の大きさであり，熱交換の向きは上記の循環方向によって定める．

### 2．Thomson の原理による比較

各循環過程は可逆であり，逆向きにも実行できる．
また，作動物質の量を調整することによって，熱交換量を任意の正の比率に調整できるものとする．
これは熱量が作動物質の量に比例する通常の巨視的熱力学を前提とする．

ここで，

```math
r_1=\frac{Q_{h,1}}{Q_{c,1}},
\qquad
r_2=\frac{Q_{h,2}}{Q_{c,2}}
```

とおく．

二つの熱量比が異なると仮定する．
添字を入れ替えることにより，一般性を失うことなく，

```math
r_1>r_2
```

と仮定できる．
すなわち，

```math
\frac{Q_{h,1}}{Q_{c,1}}
>
\frac{Q_{h,2}}{Q_{c,2}}
\tag{1}
```

である．

このとき，次の複合循環装置を構成する．

- 循環過程 $\mathcal C_1$ を通常の向きに一度実行する．
- 循環過程 $\mathcal C_2$ を逆向きに実行する．その作動規模は，熱源 $H$ との熱交換量が $\mathcal C_1$ の吸熱量と一致するように調整する．

具体的には，

```math
\lambda=\frac{Q_{h,1}}{Q_{h,2}}>0
```

倍の規模で $\mathcal C_2$ を逆向きに実行する．

このとき，熱源 $(H$ との熱交換については， $\mathcal C_1$ が $Q_{h,1}$ を吸収する一方，逆向きの $\mathcal C_2$ が $\lambda Q_{h,2}$ を放出する．
したがって，

```math
Q_{h,1}-\lambda Q_{h,2}=0
```

となり，熱源 $H$ との正味の熱交換はゼロになる．

一方，熱源 $L$ との熱交換については， $\mathcal C_1$ が $Q_{c,1}$ を放出し，逆向きの $\mathcal C_2$ が $\lambda Q_{c,2}$ を吸収する．

したがって，複合装置が熱源 $L$ から正味に吸収する熱量は，

```math
Q_L=\lambda Q_{c,2}-Q_{c,1}
```

である．
ここに $\lambda=Q_{h,1}/Q_{h,2}$ を代入すると，

```math
Q_L
=
Q_{h,1}
\left(
\frac{Q_{c,2}}{Q_{h,2}}
-
\frac{Q_{c,1}}{Q_{h,1}}
\right)
```

となる．

式(1)の両辺の逆数を取ると，

```math
\frac{Q_{c,1}}{Q_{h,1}}
<
\frac{Q_{c,2}}{Q_{h,2}}
```

である．
したがって，

```math
\boxed{Q_L>0}
\tag{2}
```

となる．

すなわち，複合装置は熱源 $L$ から正の熱量を吸収し，熱源 $H$ とは正味の熱交換を行わない．

次に，複合装置が外部にする正味の仕事を考える．

各循環過程は一巡後に元の状態に戻るため，熱力学第一法則より，

```math
W_1=Q_{h,1}-Q_{c,1}
```

および，

```math
W_2=Q_{h,2}-Q_{c,2}
```

である．
ここで，仕事は系が外部にする仕事を正とする．

逆向きの $\mathcal C_2$ がする仕事は $-\lambda W_2$ であるから，複合装置の正味の仕事は，

```math
W_{\mathrm{net}}
=
W_1-\lambda W_2
```

となる．
各循環過程の仕事の式を代入すると，

```math
\begin{aligned}
W_{\mathrm{net}}
&=
(Q_{h,1}-Q_{c,1})
-\lambda(Q_{h,2}-Q_{c,2})\\
&=
Q_{h,1}-Q_{c,1}
-Q_{h,1}
+\lambda Q_{c,2}\\
&=
\lambda Q_{c,2}-Q_{c,1}\\
&=Q_L
\end{aligned}
```

である．
式(2)より，

```math
\boxed{W_{\mathrm{net}}=Q_L>0}
\tag{3}
```

となる．

したがって，複合装置は一巡後にすべての作動物質を初期状態に戻し，熱源 $H$ とは正味の熱交換をせず，熱源 $L$ から吸収した熱をすべて仕事に変換することになる．

これは，単一の熱源から熱を取り出し，その熱を完全に仕事に変換する循環装置は存在しないという Thomson の原理に反する．

したがって，

```math
r_1>r_2
```

という仮定は成立しない．
同様に，添字を入れ替えれば，

```math
r_2>r_1
```

という仮定も成立しない．

よって，

```math
\boxed{r_1=r_2}
```

でなければならない．
すなわち，

```math
\boxed{
\frac{Q_{h,1}}{Q_{c,1}}
=
\frac{Q_{h,2}}{Q_{c,2}}
}
\tag{4}
```

を得る．

### 3．断熱線の選び方に依存しないこと

ここで， $\mathcal C_1,\mathcal C_2$ は，同じ二つの等温線 $t,t'$ を用い，断熱線の組だけを変えて構成した任意の可逆循環過程である．

式(4)より，両者の熱量比は等しい．

したがって，熱量比は断熱線 $a,a'$ の具体的な選び方には依存せず，二つの等温線 $t,t'$ の組のみによって定まる．

さらに，この比較は異なる作動物質を用いた二つの可逆循環過程についても同様に成立する．
したがって，同じ二つの熱的状態に対応する熱源の間で動作する限り，この熱量比は作動物質の種類にも依存しない．

以上より，

```math
\boxed{
\frac{Q_{AB}}{Q_{CD}}
\text{ は等温線 }t,t'\text{ のみによって定まり，断熱線の選び方によらない}
}
```

ことが示された．

### 4．熱力学的温度比との関係

以上の証明では，絶対温度の数値や温度比を前提として使用していない．

二つの等温線 $t,t'$ に対する普遍的な熱量比を

```math
R(t,t')=\frac{Q_{AB}}{Q_{CD}}
```

と定義する．
ここで，最初の温度レベルが高い場合には吸熱量と放熱量の比を取り，順序を逆にした場合にはその逆数を定義する．

さらに，三つの温度レベル $t_1>t_2>t_3$ を考える．
$t_1,t_2$ の間で動作する可逆循環過程と， $t_2,t_3$ の間で動作する可逆循環過程を組み合わせ，温度レベル $t_2$ での熱交換量が相殺されるように装置の規模を調整する．

この複合装置は $t_1,t_3$ の間で動作する可逆循環過程となる．したがって，

```math
\boxed{
R(t_1,t_2)R(t_2,t_3)=R(t_1,t_3)
}
```

が成立する．

この乗法関係を用いれば，任意の基準温度 $t_0$ と正の規格化定数 $T_0$ を選び，

```math
T(t)=T_0R(t,t_0)
```

と定義できる．
このとき，

```math
R(t,t')=\frac{R(t,t_0)}{R(t',t_0)}
```

であるから，

```math
\boxed{
R(t,t')=\frac{T_t}{T_{t'}}
}
```

と表される．

したがって，

```math
\boxed{
\frac{Q_{AB}}{Q_{CD}}
=
\frac{T_t}{T_{t'}}
}
```

となる．

この温度比の関係は，最初から仮定したものではなく，Thomson の原理に基づいて示した熱量比の普遍性から導かれるものである．
