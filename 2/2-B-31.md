# 演習問題【2-B-31】

## 解答

### 1．仮定と初期状態

Thomson の原理とは，単一の熱源から熱を受け取り，ほかに何の変化も残さずに，その熱をすべて仕事に変換する循環過程は存在しないという原理である．

異種の理想気体の拡散混合が可逆であると仮定し，Thomson の原理に矛盾する循環過程を構成する．

気体1が $n_1$ mol，気体2が $n_2$ mol あり，両者が混合した状態を状態 I とする．
混合気体の温度，圧力，全体積をそれぞれ $T,p,V$ とする．

状態 I について，理想気体の状態方程式より，

```math
pV=(n_1+n_2)RT
```

が成立する．

ここで，状態 II を次のように設定する．

全体積 $V$ の剛体・断熱容器の内部を固定された仕切りで二つに分け，一方に純粋な気体1を $n_1$ mol，他方に純粋な気体2を $n_2$ mol 入れる．
両気体の温度を $T$ ，圧力を $p$ とする．
各気体の体積をそれぞれ $V_1,V_2$ とする．

理想気体の状態方程式より，

```math
pV_1=n_1RT,\qquad pV_2=n_2RT
```

である．
したがって，

```math
V_1=\frac{n_1RT}{p},\qquad
V_2=\frac{n_2RT}{p}
```

となる．
これらを状態 I の状態方程式に代入すると，

```math
\boxed{
V_1=\frac{n_1}{n_1+n_2}V,\qquad
V_2=\frac{n_2}{n_1+n_2}V
}
```

を得る．
また，

```math
V_1+V_2=V
```

である．

### 2．状態 II から状態 I：断熱容器内での拡散混合

状態 II において，内部の仕切りを取り除き，二種類の気体を拡散混合させる．

容器は剛体かつ断熱されているため，

```math
Q_{\mathrm{II}\to\mathrm{I}}=0,\qquad
W_{\mathrm{II}\to\mathrm{I}}=0
```

である．

したがって，熱力学第一法則より，

```math
\Delta U_{\mathrm{II}\to\mathrm{I}}=0
```

となる．

理想気体の内部エネルギーは温度だけの関数であり，混合気体の内部エネルギーは各成分の内部エネルギーの和である．
よって，初期状態と最終状態の内部エネルギーが等しいことから，混合後の平衡温度は $T$ である．

また，全体積 $V$ は一定なので，混合後の圧力は，

```math
p=\frac{(n_1+n_2)RT}{V}
```

となる．

したがって，混合後の状態は状態 I と一致する．

ここで，問題の仮定に従い，この拡散混合過程が可逆であるとする．
可逆過程では逆過程によって系と周囲をともに元の状態に戻せるので，状態 I から状態 II への逆過程も，周囲に正味の変化を残さずに実行できるはずである．

もとの混合過程では熱量も仕事もゼロであったから，その逆過程についても，

```math
\boxed{
Q_{\mathrm{I}\to\mathrm{II}}=0,\qquad
W_{\mathrm{I}\to\mathrm{II}}=0
}
\tag{1}
```

でなければならない．

ここで，熱・仕事がゼロとなる根拠は可逆性だけではなく，逆向きにたどる元の過程が剛体・断熱容器内で行われ，熱・仕事の授受を伴わないことにある．

### 3．状態 II から状態 III：各気体の可逆等温膨張

次に，状態 II で分離されている気体1と気体2を，それぞれ別の摩擦のないピストン付き容器に入れ，温度 $T$ の同一の熱源と接触させる．

各気体を温度 $T$ に保ちながら，準静的かつ可逆的に等温膨張させる．
外圧は，膨張中の気体の圧力より無限小だけ低く調整するものとする．

気体1は体積 $V_1$ から $V$ まで膨張し，気体2は体積 $V_2$ から $V$ まで膨張する．
膨張後の状態を状態 III とする．

#### 3.1 気体1の膨張

理想気体の状態方程式より，膨張途中の体積を $V'$ とすると，

```math
p_1(V')=\frac{n_1RT}{V'}
```

である．

したがって，気体1が外部にする仕事は，

```math
\begin{aligned}
W_1
&=\int_{V_1}^{V}p_1(V')\,dV'\\
&=n_1RT\int_{V_1}^{V}\frac{dV'}{V'}\\
&=n_1RT\ln\frac{V}{V_1}.
\end{aligned}
```

理想気体の内部エネルギーは温度だけの関数であるため，等温膨張では，

```math
\Delta U_1=0
```

である．

熱力学第一法則より，

```math
\Delta U_1=Q_1-W_1
```

なので，

```math
\boxed{
Q_1=W_1=n_1RT\ln\frac{V}{V_1}
}
\tag{2}
```

となる．

#### 3.2 気体2の膨張

同様に，気体2について，

```math
p_2(V')=\frac{n_2RT}{V'}
```

であるから，

```math
\begin{aligned}
W_2
&=\int_{V_2}^{V}p_2(V')\,dV'\\
&=n_2RT\int_{V_2}^{V}\frac{dV'}{V'}\\
&=n_2RT\ln\frac{V}{V_2}.
\end{aligned}
```

また，等温膨張なので，

```math
\Delta U_2=0
```

であり，第一法則より，

```math
\boxed{
Q_2=W_2=n_2RT\ln\frac{V}{V_2}
}
\tag{3}
```

となる．

#### 3.3 膨張過程全体の熱量と仕事

気体1と気体2は，同一の温度 $T$ の熱源から熱を吸収する．
したがって，吸収する熱量の合計 $Q$ と外部にする仕事の合計 $W$ は，

```math
Q=Q_1+Q_2
```

```math
W=W_1+W_2
```

である．
式 (2)，(3) より，

```math
Q=W
```

となる．

ここに，

```math
V_1=\frac{n_1}{n_1+n_2}V,\qquad
V_2=\frac{n_2}{n_1+n_2}V
```

を代入すると，

```math
\boxed{
\begin{aligned}
W=Q=RT\bigg[
&n_1\ln\frac{n_1+n_2}{n_1}\\
&+n_2\ln\frac{n_1+n_2}{n_2}
\bigg]
\end{aligned}
}
\tag{4}
```

を得る．

ここで，

```math
n_1>0,\qquad n_2>0
```

であるから，

```math
\frac{V}{V_1}=\frac{n_1+n_2}{n_1}>1
```

```math
\frac{V}{V_2}=\frac{n_1+n_2}{n_2}>1
```

となる．
よって，対数の値はいずれも正であり，

```math
\boxed{W=Q>0}
\tag{5}
```

である．

膨張後の状態 III では，各気体はそれぞれ温度 $T$ ，体積 $V$ の純粋気体として分離されている．
それぞれの圧力は，

```math
p_1^*=\frac{n_1RT}{V},\qquad
p_2^*=\frac{n_2RT}{V}
```

である．
また，

```math
p_1^*+p_2^*
=\frac{(n_1+n_2)RT}{V}
=p
```

が成立する．

### 4．状態 III から状態 I：半透壁を用いた可逆的な再混合

状態 III では，純粋な気体1と気体2が，それぞれ温度 $T$ ，体積 $V$ ，圧力 $p_1^*$ ， $p_2^*$ の状態で別々の容器に入っている．

ここで，次の理想的な半透壁装置を用いる．

気体1だけを透過させる半透壁と，気体2だけを透過させる半透壁を用意し，それぞれの気体を別々の供給室から共通の受け入れ室へ移動させる．
半透壁とピストンは摩擦のない理想装置とし，移動は準静的・可逆的に行う．

#### 4.1 半透壁における圧力の条件

可逆的な物質移動では，半透壁を通過できる各成分について，膜の両側で化学ポテンシャルが等しくなる必要がある．

理想気体では，同じ温度における化学ポテンシャルはその成分の分圧によって決まるため，供給室の圧力と受け入れ室における対応成分の分圧が等しくなる．

したがって，受け入れ室における気体1の分圧は $p_1^*$ ，気体2の分圧は $p_2^*$ である．
Dalton の分圧の法則より，受け入れ室の全圧は，

```math
\boxed{
p_{\mathrm{mix}}=p_1^*+p_2^*=p
}
\tag{6}
```

となる．

#### 4.2 装置全体の仕事の計算

受け入れ室の体積を $v$ とする．

受け入れ室に移動した気体 $i$ の物質量は，状態方程式より，

```math
n_i^{(\mathrm{r})}
=\frac{p_i^*v}{RT}
=\frac{n_i}{V}v
```

である．
ここで，添字 $\mathrm{r}$ は受け入れ室を表す．

したがって，供給室に残っている気体の物質量は，

```math
n_i^{(\mathrm{s})}
=n_i\left(1-\frac{v}{V}\right)
```

となる．

供給室の圧力は $p_i^*$ ，温度は $T$ に保たれるので，その体積 $V_{si}$ は，

```math
\begin{aligned}
V_{si}
&=\frac{n_i^{(\mathrm{s})}RT}{p_i^*}\\
&=\frac{n_i(1-v/V)RT}{n_iRT/V}\\
&=V-v
\end{aligned}
```

である．
したがって，

```math
\boxed{
dV_{s1}=dV_{s2}=-dv
}
\tag{7}
```

となる．

ここで，仕事は気体が外部にする向きを正とする．

受け入れ室の体積が $dv$ だけ増加する際，供給室1，供給室2，受け入れ室で気体が外部にする微小仕事の合計は，

```math
\begin{aligned}
\delta W_{\mathrm{merge}}
&=p_1^*dV_{s1}
+p_2^*dV_{s2}
+(p_1^*+p_2^*)dv\\
&=-p_1^*dv-p_2^*dv
+(p_1^*+p_2^*)dv\\
&=0.
\end{aligned}
```

したがって，

```math
\boxed{
W_{\mathrm{III}\to\mathrm{I}}=0
}
\tag{8}
```

である．

この式では，供給室内の気体が圧縮されることによる負の仕事と，受け入れ室内の混合気体が膨張することによる正の仕事をすべて考慮している．
両者は正確に相殺される．

なお，理想的な可逆操作では，膜を通過する各成分の圧力差を無限小にする．
上の圧力の等式はその可逆極限を表している．
受け入れ室の初期体積がゼロとなる端点は，微小な初期体積から始めてその体積をゼロに近づける極限として扱う．

#### 4.3 再混合過程の熱量

気体1と気体2は，いずれも温度 $T$ を保っている．
理想気体の内部エネルギーは温度だけの関数であり，各成分の物質量も全過程で一定である．
したがって，

```math
\Delta U_{\mathrm{III}\to\mathrm{I}}=0
```

である．

第一法則より，

```math
\Delta U_{\mathrm{III}\to\mathrm{I}}
=
Q_{\mathrm{III}\to\mathrm{I}}
-
W_{\mathrm{III}\to\mathrm{I}}
```

であるから，式 (8) を代入すると，

```math
0=Q_{\mathrm{III}\to\mathrm{I}}-0
```

となる．
よって，

```math
\boxed{
Q_{\mathrm{III}\to\mathrm{I}}=0
}
\tag{9}
```

である．

受け入れ室の最終体積は $V$ であり，その中には気体1が $n_1$ mol，気体2が $n_2$ mol 含まれている．
温度は $T$ ，全圧は式 (6) より $p$ である．

したがって，最終状態は状態 I と一致する．

以上より，状態 III から状態 I への再混合では，熱および仕事の正味の授受はともにゼロである．

### 5．Thomson の原理との矛盾

以上の三つの過程を組み合わせると，

```math
\mathrm{I}\longrightarrow
\mathrm{II}\longrightarrow
\mathrm{III}\longrightarrow
\mathrm{I}
```

という一周期のサイクルが完成する．

各過程における熱量と仕事をまとめると，次のようになる．

| 過程 | 吸収熱量 | 外部にする仕事 |
|---|---:|---:|
| I → II：可逆分離 | $0$ | $0$ |
| II → III：等温膨張 | $Q>0$ | $W=Q>0$ |
| III → I：半透壁による再混合 | $0$ | $0$ |
| 合計 | $Q>0$ | $W=Q>0$ |

したがって，サイクル全体では，

```math
\boxed{
Q_{\mathrm{cyc}}=W_{\mathrm{cyc}}>0
}
```

となる．

このサイクルでは，系は初期状態 I に完全に戻る．

また，熱を授受する相手は，状態 II から状態 III への等温膨張で接触させた温度 $T$ の単一熱源だけである．

状態 I から状態 II への分離は，もとの断熱・剛体容器内の混合過程の逆過程であり，仮定された可逆性のもとで周囲に正味の変化を残さない．
状態 III から状態 I への再混合も，理想的な半透壁装置によって正味の熱・仕事の授受を伴わずに実行される．

したがって，この循環過程が外界に残す正味の効果は，

- 単一熱源から正の熱量 $Q$ を取り出すこと．
- それと等しい仕事 $W=Q$ を外部に供給すること．

だけである．

これは，単一熱源から吸収した熱をすべて仕事に変換し，他に何の変化も残さない循環過程であり，Thomson の原理に反する．

よって，最初の仮定，すなわち異種の理想気体の拡散混合が可逆であるという仮定は誤りである．

したがって，

```math
\boxed{
\text{異種の理想気体の拡散混合は不可逆過程である}
}
```

ことが示された．

### 6．補足：本証明で用いた条件

**(1) 状態 II の混合過程について**

状態 II から状態 I への混合は，剛体・断熱容器内で仕切りを取り除く自由拡散として設定した．
そのため，

```math
Q_{\mathrm{II}\to\mathrm{I}}
=
W_{\mathrm{II}\to\mathrm{I}}
=0
```

である．
逆過程の熱量・仕事がゼロとなるのは，この過程が可逆であるという仮定による．
可逆性だけから一般に熱量・仕事がゼロになると主張しているわけではない．

**(2) 等温膨張について**

仕事の対数式は，摩擦のないピストンを使用した準静的・可逆的な等温膨張に対して導いた．
不可逆な等温膨張に同じ式を無条件に適用しているわけではない．

**(3) 半透壁装置について**

気体1だけを透過させる膜と，気体2だけを透過させる膜を備えた理想装置を用いた．
供給室での圧力仕事と受け入れ室での膨張仕事をすべて合算することで，正味の仕事がゼロになることを示した．
単に圧力が釣り合うという説明だけで仕事ゼロを仮定しているわけではない．

**(4) 理想気体の仮定について**

本証明では，理想気体の内部エネルギーが温度だけの関数であること，および混合気体の全圧が各成分の分圧の和であることを使用した．

また，気体1と気体2は異なる化学種であり，それぞれを選択的に透過させる理想的な半透壁が利用できるものとした．
