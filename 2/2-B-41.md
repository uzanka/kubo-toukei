# 演習問題【2-B-41】

## 解答

### 1．回路を一周する準静的過程を考える

異なる金属 A，B を接合点 1，2 で接続し，接合点 1 の温度を $T_1$ ，接合点 2 の温度を $T_2$ とする．
ただし，

```math
T_1>T_2
```

であり，両接合点の温度は一定に保つ．
回路には起電力 $E$ の電池が接続され，実際には電流が流れない状態にある．

この状態で，回路の電流を十分小さく保ちながら，正電荷 1 単位を回路に沿って一周させる仮想的な準静的過程を考える．
ここでは，接点 1 で電流が A から B へ流れる向きに回路を一周させるものとする．
正電荷は慣用電流と同じ方向に移動するため，接点 1 では A から B へ，接点 2 では B から A へ移動する．

電流を十分小さくすることで，ジュール熱を無視できるようにする．
また，起電力 $E$ の符号は，この電荷を電池に逆らって一周させるために外部から与える仕事が $+E$ となるように定める．
電荷量を 1 単位としたため，この仕事の大きさは $E$ である．

一周後には回路の状態が元に戻るため，内部エネルギーの変化はゼロである．
これを利用して，熱力学第一法則と第二法則から関係式を導く．

### 2．熱力学第一法則を適用する

$\Pi_{AB}(T)$ は，接点で単位電流が A から B へ流れるとき，単位時間あたりに放出される熱量である．
ここで，1 単位の電荷を移動させる時間は，電流を 1 単位に規格化すれば 1 秒に相当する．

接点 1 では，電流が A から B へ流れるため，物質は

```math
\Pi_{AB}(T_1)
```

の熱を放出する．
したがって，物質が吸収する熱量は $-\Pi_{AB}(T_1)$ である．

一方，接点 2 では電流が B から A へ流れるため，Peltier 熱の符号が逆になる．
したがって，物質は

```math
\Pi_{AB}(T_2)
```

の熱を吸収する．

よって，回路を一周する過程で物質が吸収する熱量の総和 $Q$ は，

```math
Q=-\Pi_{AB}(T_1)+\Pi_{AB}(T_2)
\tag{1}
```

である．

熱力学第一法則を，吸収熱を $Q$ ，外部から系になされる仕事を $W_{\mathrm{on}}$ として，

```math
\Delta U=Q+W_{\mathrm{on}}
```

と表す．
この過程は一周して元の状態に戻るため， $\Delta U=0$ である．
また，電池に逆らって電荷を移動させる仕事は $W_{\mathrm{on}}=E$ であるから，

```math
0=-\Pi_{AB}(T_1)+\Pi_{AB}(T_2)+E
```

となる．
したがって，

```math
\boxed{
E=\Pi_{AB}(T_1)-\Pi_{AB}(T_2)
}
\tag{2}
```

を得る．

### 3．Clausius の等式を適用する

この準静的過程を可逆過程として扱い，金属内部の温度勾配に由来する Thomson 効果をいったん無視する．
可逆サイクルでは Clausius の等式

```math
\oint\frac{d'Q}{T}=0
```

が成り立つ．

接点 1 で吸収する熱量は $-\Pi_{AB}(T_1)$ ，接点 2 で吸収する熱量は $+\Pi_{AB}(T_2)$ であり，それぞれの温度は $T_1,T_2$ である．
したがって，

```math
-\frac{\Pi_{AB}(T_1)}{T_1}
+\frac{\Pi_{AB}(T_2)}{T_2}=0
```

となる．
これを整理すれば，

```math
\boxed{
\frac{\Pi_{AB}(T_1)}{T_1}
=\frac{\Pi_{AB}(T_2)}{T_2}
}
\tag{3}
```

を得る．

### 4．熱起電力の温度微分を求める

式 (2) より，

```math
E=\Pi_{AB}(T_1)-\Pi_{AB}(T_2)
```

である．
ここで， $T_2$ を一定に保って $T_1$ で微分すると，

```math
\frac{dE}{dT_1}
=\frac{d\Pi_{AB}(T_1)}{dT_1}
\tag{4}
```

となる．

次に，式 (3) の右辺は $T_2$ が一定であるため定数である．
したがって，

```math
\frac{d}{dT_1}
\left(\frac{\Pi_{AB}(T_1)}{T_1}\right)=0
```

である．
商の微分を計算すると，

```math
\frac{1}{T_1}
\frac{d\Pi_{AB}(T_1)}{dT_1}
-\frac{\Pi_{AB}(T_1)}{T_1^2}=0
```

となる．
両辺に $T_1$ を掛ければ，

```math
\frac{d\Pi_{AB}(T_1)}{dT_1}
=\frac{\Pi_{AB}(T_1)}{T_1}
\tag{5}
```

を得る．
式 (4)，(5) より，

```math
\boxed{
\frac{dE}{dT_1}
=\frac{\Pi_{AB}(T_1)}{T_1}
}
```

が導かれる．
これが求める関係式である．

### 5．Thomson 効果を考慮した場合

以上の導出では，金属 A，B の内部に温度勾配があることで生じる Thomson 熱を無視した．
より一般には，金属内部での Thomson 熱を加えなければならないが，その寄与を含めても同じ関係式が得られる．

そこで，選んだ回路方向における A，B 両金属の Thomson 熱の差を表す符号付き係数を $\Theta(T)$ と定義する．
この係数は，温度 $T$ から $T+dT$ の区間で，回路内に生じる正味の Thomson 熱の寄与が $\Theta(T)dT$ となるように定める．

この寄与を含めると，エネルギー収支は

```math
E=\Pi_{AB}(T_1)-\Pi_{AB}(T_2)
+\int_{T_2}^{T_1}\Theta(T)\,dT
\tag{6}
```

と書ける．
同様に，Clausius の等式は，

```math
\frac{\Pi_{AB}(T_1)}{T_1}
-\frac{\Pi_{AB}(T_2)}{T_2}
+\int_{T_2}^{T_1}\frac{\Theta(T)}{T}\,dT=0
\tag{7}
```

となる．

式 (6) を $T_1$ で微分すると，

```math
\frac{dE}{dT_1}
=\frac{d\Pi_{AB}(T_1)}{dT_1}+\Theta(T_1)
\tag{8}
```

である．
また，式 (7) を $T_14 で微分すると，

```math
\frac{1}{T_1}\frac{d\Pi_{AB}(T_1)}{dT_1}
-\frac{\Pi_{AB}(T_1)}{T_1^2}
+\frac{\Theta(T_1)}{T_1}=0
```

となる．
両辺に $T_1$ を掛ければ，

```math
\frac{d\Pi_{AB}(T_1)}{dT_1}+\Theta(T_1)
=\frac{\Pi_{AB}(T_1)}{T_1}
\tag{9}
```

を得る．
式 (8)，(9) より，

```math
\boxed{
\frac{dE}{dT_1}
=\frac{\Pi_{AB}(T_1)}{T_1}
}
```

が再び導かれる．
したがって，Thomson 効果を考慮しても，求める熱起電力と Peltier 熱の関係は変わらないのである．
