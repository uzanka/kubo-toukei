# 演習問題【2-B-41】

## 解答

### 0．前提，記号，符号の規約

**(a) 単位電荷あたりの量**

$\Pi_{AB}$ は「単位電流が1秒間流れたときの放出熱量」と定義されている．
単位電流を1秒間流せば，通過する電荷はちょうど1単位である．
したがって $\Pi_{AB}(T)$ は，接点を電荷1単位が A から B へ通過するときに放出される熱量である．
同様に，起電力 $E$ も電荷1単位あたりの仕事を表す．
以下では電荷1単位が回路を一周する過程で量を評価する．

**(b) 一周の向き**

正電荷が接点1で A から B へ，接点2で B から A へ流れる向きを「正の向き」とする．

**(c) E の符号**

電池が正の向きに単位電荷を押し進めるとき，電池が単位電荷あたりにする仕事を $E$ と定める．
電流ゼロの条件下では，この $E$ は熱起電力と大きさが等しく向きが逆である．
この規約が，問題の関係式の符号に対応する．

**(d) 熱の符号**

Peltier 熱は電流に比例し，電流を逆向きにすると符号が反転する．
よって接点1では熱量 $\Pi_{AB}(T_1)$ が放出される．
接点2では電流が B から A へ向かうので，熱量 \(\Pi_{AB}(T_2)\) が吸収される．

**(e) Thomson 熱**

金属 A，B の内部には温度勾配があり，電流が流れると Thomson 熱が出入りする．
回路を正の向きに一周するとき，温度 $T$ から $T+dT$ の区間にある両金属の部分から，熱浴へ放出される Thomson 熱の合計を $\Theta(T)dT$ と定義する．
$\Theta(T)$ は正負どちらの値もとりうる．
これは正の向きの一周に対して定義した量なので，電流の向きを反転したときの符号は問題にならない．
$\Theta(T)=0$ の場合も，以下の導出に含まれる．

**(f) 準静的過程と Kelvin の仮定**

- 電池の起電力を調整して電流を無限に小さくし，電荷を準静的に一周させる．
- 電荷 $dq$ を運ぶとき，Peltier 熱と Thomson 熱は $dq$ に比例する．ジュール熱は（電流）× $dq$ に比例し，電流 $\to 0$ で無視できる．
- 熱伝導による熱の流れは電荷輸送に依存しない定常的な背景である．これは電荷輸送に伴う熱の収支から切り離して扱う（Kelvin の仮定）．

以上の準備のもとで，Peltier 効果と Thomson 効果だけを可逆過程として扱う．
$dq$ で割れば電荷1単位あたりの量が得られる．

**(g) 微分の意味**

$E$ は $T_1,T_2$ の関数である．
問題の $dE/dT$ は， $T_2$ を固定して $T_1$ を $T$ と書いた偏微分 $\partial E/\partial T_1$ を意味する．
$\Pi_{AB}(T)$ と $\Theta(T)$ は連続で， $\Pi_{AB}(T)$ は微分可能とする．

### 1．熱力学第一法則（エネルギー保存）

電荷1単位が正の向きに一周する間に，回路が熱浴から吸収する熱量の総和 $Q$ は，

```math
Q=-\Pi_{AB}(T_1)+\Pi_{AB}(T_2)
-\int_{T_2}^{T_1}\Theta(T)\,dT
\tag{1}
```

である．
ただし第3項は， $\Theta$ が放出熱であることから負符号となる．

この過程でジュール熱は無視できる．
電池が回路になす仕事は単位電荷あたり $E$ である．
一周後には，電池を除く回路の導体は定常状態に戻っているので，その内部エネルギーの変化は $\Delta U=0$ である．
第一法則

```math
\Delta U=Q+W_{\mathrm{on}}
```

で $W_{\mathrm{on}}=E$ とおくと，

```math
0=-\Pi_{AB}(T_1)+\Pi_{AB}(T_2)
-\int_{T_2}^{T_1}\Theta(T)\,dT+E
```

となる．
したがって，

```math
\boxed{
E=\Pi_{AB}(T_1)-\Pi_{AB}(T_2)
+\int_{T_2}^{T_1}\Theta(T)\,dT
}
\tag{2}
```

### 2．熱力学第二法則（Clausius の等式）

(f) により一周の過程は可逆である．導体の状態は元に戻るので，導体のエントロピー変化は 0 であり，熱浴のエントロピー変化の総和も 0 になる．

接点1では温度 $T_1$ の熱浴へ $\Pi_{AB}(T_1)$ を放出し，接点2では温度 $T_2$ の熱浴から $\Pi_{AB}(T_2)$ を吸収する．
温度 $T$ の区間では，温度 $T$ の熱浴へ $\Theta(T)dT$ を放出する．
よって Clausius の等式

```math
\oint\frac{d'Q}{T}=0
```

は，

```math
-\frac{\Pi_{AB}(T_1)}{T_1}
+\frac{\Pi_{AB}(T_2)}{T_2}
-\int_{T_2}^{T_1}\frac{\Theta(T)}{T}\,dT=0
```

となる．
符号を整えて，

```math
\boxed{
\frac{\Pi_{AB}(T_1)}{T_1}
-\frac{\Pi_{AB}(T_2)}{T_2}
+\int_{T_2}^{T_1}\frac{\Theta(T)}{T}\,dT=0
}
\tag{3}
```

### 3． $T_1$ についての微分

$T_2$ を固定して，式 (2) を $T_1$ で微分する．
$\Pi_{AB}(T_2)$ は定数であり，積分の上端での微分には微積分学の基本定理を使う．

```math
\boxed{
\frac{\partial E}{\partial T_1}
=
\frac{d\Pi_{AB}(T_1)}{dT_1}
+\Theta(T_1)
}
\tag{4}
```

式 (3) も $T_1$ で微分する．

```math
\frac{1}{T_1}\frac{d\Pi_{AB}(T_1)}{dT_1}
-\frac{\Pi_{AB}(T_1)}{T_1^2}
+\frac{\Theta(T_1)}{T_1}=0
```

両辺に $T_1$ を掛けて整理すると，

```math
\frac{d\Pi_{AB}(T_1)}{dT_1}
+\Theta(T_1)
=
\frac{\Pi_{AB}(T_1)}{T_1}
\tag{5}
```

となる．
式 (4) の右辺は式 (5) の左辺と同じなので，

```math
\boxed{
\frac{\partial E}{\partial T_1}
=
\frac{\Pi_{AB}(T_1)}{T_1}
}
```

が得られる．
$T_1$ を $T$ と書けば，求める関係式

```math
\boxed{
\frac{dE}{dT}
=
\frac{\Pi_{AB}(T)}{T}
}
```

が示された．

### 4．補足

- Thomson 熱の寄与は，式 (4) と (5) で同じ $\Theta(T_1)$ として現れ，両者の比較で打ち消される．したがって結論は Thomson 係数の値によらない．
- 式 (2) と (3) は，Thomson 係数がゼロの場合も含む一般の関係である． $\Theta=0$ の場合は式 (3) から $\Pi_{AB}(T)/T$ が定数となるが，これは $\Theta=0$ という特殊な場合の帰結にすぎない．一般には $\Pi_{AB}(T)/T$ は定数ではない．
- 結論は，電池の符号の規約 (c) に依存する． $E$ の符号を逆にとれば，右辺の符号も逆になる．
