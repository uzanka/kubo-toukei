# 演習問題【2-C-43】

## 解答

考える実在の気体の状態方程式を，圧力 $p$ と温度 $T$ の級数展開を用いて次のように表す．

$$pV = f(p, T) = A(T) + B(T)p + C(T)p^2 + \dots$$

ここで， $A(T), B(T), C(T), \dots$ は温度 $T$ に依存する係数である．

定圧モル比熱 $C_p$ の圧力依存性に関する関係式

$$\left(\frac{\partial C_p}{\partial p}\right)_T = -T \left(\frac{\partial^2 V}{\partial T^2}\right)_p$$

を用いる．
ここで $V = f(p, T)/p$ であるから，右辺の $\left(\frac{\partial^2 V}{\partial T^2}\right)_p$ は次のように書き換えられる．

$$\left(\frac{\partial^2 V}{\partial T^2}\right)_p = \frac{\partial^2}{\partial T^2} \left( \frac{f(p, T)}{p} \right) = \frac{1}{p} \left(\frac{\partial^2 f}{\partial T^2}\right)_p$$

したがって，

$$\left(\frac{\partial C_p}{\partial p}\right)_T = -\frac{T}{p} \left(\frac{\partial^2 f}{\partial T^2}\right)_p$$

を得る．
これを圧力 $0$ から $p$ まで積分することで， $C_p(p, T)$ と $p=0$ における値 $C_p^{(0)}(T)$ の差を求める．

$$C_p - C_p^{(0)} = \int_0^p \left(\frac{\partial C_p}{\partial p}\right)_T dp = -\int_0^p \frac{T}{p} \left(\frac{\partial^2 f}{\partial T^2}\right)_p dp$$

次に， $f(p, T)$ の展開式 $f(p, T) = A(T) + B(T)p + C(T)p^2 + \dots$ を用いて， $\left(\frac{\partial^2 f}{\partial T^2}\right)_p$ を求める．

$$\left(\frac{\partial^2 f}{\partial T^2}\right)_p = A''(T) + B''(T)p + C''(T)p^2 + \dots$$

ここで， $A(T) \propto T$ であることから， $A''(T) = 0$ であることに注意する．
よって，

$$\left(\frac{\partial^2 f}{\partial T^2}\right)_p = B''(T)p + C''(T)p^2 + \dots$$

これを積分の式に代入すると，

$$C_p - C_p^{(0)} = -\int_0^p \frac{T}{p} \left( B''(T)p + C''(T)p^2 + \dots \right) dp$$

$$C_p - C_p^{(0)} = -T \int_0^p \left( B''(T) + C''(T)p + \dots \right) dp$$

$$C_p - C_p^{(0)} = -T \left[ B''(T)p + \frac{1}{2} C''(T)p^2 + \dots \right]$$

$$C_p - C_p^{(0)} = -TB''(T)p - \frac{1}{2} TC''(T)p^2 - \dots$$

これを $C_p^{(0)}$ について整理すると，次の式を得る．

$$C_p^{(0)} = C_p + TB''(T)p + \frac{1}{2} TC''(T)p^2 + \dots \quad \cdots (1)$$

ゆえに，与えられた温度において有限な圧力 $p$ に対する定圧モル比熱の測定値が得られているならば，式 (1) に基づいて $p \to 0$ へと **外挿 (extrapolation)** することで，理想気体状態における定圧モル比熱 $C_p^{(0)}$ を推定することができる．

## 解説

### 1. 定圧モル比熱と理想気体

熱力学において，**定圧モル比熱 $C_p$** とは，圧力を一定に保ったまま物質 1 モルあたりの温度を 1 K 上昇させるのに必要な熱量のことである．
**理想気体**とは，分子間の相互作用を無視できるモデルであり，数学的には圧力が $p = 0$ の極限として記述される．
実在の気体は分子間の引力や反発力を持つため，理想気体とは異なる挙動を示すが，圧力が非常に低い領域では理想気体に近づく．
したがって，実在気体の性質を理解するためには，測定された $C_p$ から「もし圧力がゼロだったら（理想気体だったら）どうなるか」を求めることが重要になる．

### 2. 状態方程式の展開

実在気体の状態方程式 $pV = f(p, T)$ は，圧力 $p$ に関するべき級数として展開できる．

$$pV = A(T) + B(T)p + C(T)p^2 + \dots$$

ここで， $A, B, C$ などの係数は温度 $T$ の関数である．
特に，圧力が $0$ に近づくとき， $pV \to A(T)$ となるため， $A(T)$ は理想気体における $pV$ の値（理想気体の状態方程式 $pV = RT$ に対応）を表している．
理想気体では $pV = RT$ なので， $A(T) = RT$ であり， $A$ は $T$ の 1 次式となる．
そのため，2 階微分 $A''(T)$ は $0$ になる．

### 3. 外挿（Extrapolation）とは

**外挿**とは，既知のデータが存在する範囲（ここでは有限の圧力 $p$ の範囲）の外側にある値（ここでは $p = 0$ ）を，データの傾向に基づいて推定することである．
本問では，実測された $C_p(p)$ の値を圧力の関数としてプロットし，その曲線の傾向（式 (1) のような多項式）をたどって $p = 0$ の点まで延長することで，直接測定することが困難な理想気体状態の値を求めている．
