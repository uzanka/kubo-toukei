# 演習問題【2-C-43】

## 解答

### 0．前提，記号および適用条件

実在気体1 molを考え，モル体積を $V_m$ ，圧力を $p$ ，絶対温度を $T$ ，定圧モル比熱を $C_p$ ，モルエントロピーを $S_m$ ，モルGibbs自由エネルギーを $G_m$ とする．

以下では，次の条件を仮定する．

1．気体は単一の平衡相にあり，温度と圧力について熱力学的状態関数が十分滑らかである．

2．物質量および化学組成は一定とする．化学反応や相転移による組成変化は考えない．

3．温度 $T$ を一定にして圧力を十分小さくすると，気体は理想気体極限に近づく．

4．低圧領域で状態方程式を圧力について展開でき，その展開係数は温度について少なくとも二階微分可能である．また，必要な範囲で級数の微分および積分を項別に行えるものとする．

ここで，理想気体極限 $p\to0$ は，有限体積で圧力が厳密にゼロの状態を意味するのではなく，温度一定で圧力をゼロに近づける極限を意味する．

このとき，

```math
C_p^{(0)}(T)
=
\lim_{p\to0}C_p(p,T)
```

を理想気体状態における定圧モル比熱と定義する．

### 1．定圧モル比熱の圧力依存性を表す関係式

定圧モル比熱の定義は，

```math
\boxed{
C_p=T\left(\frac{\partial S_m}{\partial T}\right)_p
}
\tag{1}
```

である．

これを温度一定のもとで圧力 $p$ について偏微分すると，

```math
\left(\frac{\partial C_p}{\partial p}\right)_T
=
T\frac{\partial}{\partial p}
\left(\frac{\partial S_m}{\partial T}\right)_p
```

となる．

ここで，モルGibbs自由エネルギーの全微分は，

```math
dG_m=-S_m\,dT+V_m\,dp
```

である．

したがって，混合二階偏微分の交換可能性からMaxwellの関係式，

```math
\boxed{
\left(\frac{\partial S_m}{\partial p}\right)_T
=
-\left(\frac{\partial V_m}{\partial T}\right)_p
}
\tag{2}
```

が得られる．

式 (2) を用いると，

```math
\begin{aligned}
\left(\frac{\partial C_p}{\partial p}\right)_T
&=
T\frac{\partial}{\partial T}
\left(\frac{\partial S_m}{\partial p}\right)_T\\
&=
-T\frac{\partial}{\partial T}
\left(\frac{\partial V_m}{\partial T}\right)_p
\end{aligned}
```

となる．

よって，

```math
\boxed{
\left(\frac{\partial C_p}{\partial p}\right)_T
=
-T\left(\frac{\partial^2 V_m}{\partial T^2}\right)_p
}
\tag{3}
```

を得る．

これが，定圧モル比熱の圧力依存性を表す基本関係式である．

### 2．低圧状態方程式の展開と理想気体極限

#### 2.1 低圧状態方程式の展開

低圧領域において，実在気体の状態方程式が圧力について展開可能であると仮定する．

このとき，

```math
pV_m
=
A(T)+B(T)p+C(T)p^2+D(T)p^3+\cdots
\tag{4}
```

と表せる．

ここで， $A(T),B(T),C(T),D(T)$ は温度のみの関数であり，右辺は低圧における圧力展開を表す．

なお， $C(T)$ は状態方程式の展開係数であり，定圧モル比熱 $C_p$ とは異なる量である．

式 (4) を $p$ で割ると，

```math
V_m
=
\frac{A(T)}p
+B(T)
+C(T)p
+D(T)p^2+\cdots
\tag{5}
```

となる．

#### 2.2 理想気体極限から $A(T)$ を決定する

ここで，1 molの気体について，低圧極限では理想気体の状態方程式が成立する．

したがって，

```math
\lim_{p\to0}pV_m=RT
\tag{6}
```

である．

一方，式 (4) より，

```math
\lim_{p\to0}pV_m=A(T)
```

となる．

両式を比較すると，

```math
\boxed{
A(T)=RT
}
\tag{7}
```

を得る．

ここで， $R$ はモル気体定数であり，温度に依存しない定数である．

したがって，

```math
A'(T)=R
```

```math
A''(T)=0
```

である．
すなわち，

```math
\boxed{
\frac{d^2A(T)}{dT^2}=0
}
\tag{8}
```

となる．

この結論は，理想気体極限を直接用いて得られたものであり，内部エネルギーの低圧展開や，エンタルピーの圧力微分の有限性を別途仮定する必要はない．

### 3．体積の温度二階偏微分を求める

式 (5) に式 (7) を代入すると，

```math
V_m
=
\frac{RT}{p}
+B(T)+C(T)p+D(T)p^2+\cdots
\tag{9}
```

となる．

ここで，圧力 $p$ を一定に保って温度 $T$ について偏微分すると，

```math
\left(\frac{\partial V_m}{\partial T}\right)_p
=
\frac{R}{p}
+B'(T)+C'(T)p+D'(T)p^2+\cdots
```

である．

さらに，もう一度温度について偏微分すると，

```math
\left(\frac{\partial^2 V_m}{\partial T^2}\right)_p
=
B''(T)+C''(T)p+D''(T)p^2+\cdots
```

を得る．

ここで，

```math
\frac{\partial^2}{\partial T^2}
\left(\frac{RT}{p}\right)=0
```

であるため，理想気体に対応する項は消える．

したがって，

```math
\boxed{
\left(\frac{\partial^2 V_m}{\partial T^2}\right)_p
=
B''(T)+C''(T)p+D''(T)p^2+\cdots
}
\tag{10}
```

となる．

ここで， $B''(T)$ ， $C''(T)$ ， $D''(T)$ は，各展開係数の温度に関する二階微分を表す．

### 4．定圧モル比熱の圧力依存性を積分する

式 (3) に式 (10) を代入すると，

```math
\begin{aligned}
\left(\frac{\partial C_p}{\partial p}\right)_T
=
-T\left[
B''(T)+C''(T)p+D''(T)p^2+\cdots
\right]
\end{aligned}
\tag{11}
```

を得る．

次に，温度 $T$ を一定に保ち，圧力を理想気体極限 $p=0$ から有限圧力 $p$ まで積分する．

積分変数を $q$ とすると，

```math
C_p(p,T)-C_p^{(0)}(T)
=
\int_0^p
\left(\frac{\partial C_p}{\partial q}\right)_T dq
```

である．

式 (11) を代入すると，

```math
\begin{aligned}
C_p(p,T)-C_p^{(0)}(T)
=
-T\int_0^p
\left[
B''(T)+C''(T)q+D''(T)q^2+\cdots
\right]dq
\end{aligned}
```

となる．

各係数は温度 $T$ のみの関数であり，この積分では定数として扱える．

したがって，

```math
\begin{aligned}
C_p(p,T)-C_p^{(0)}(T)
=
-T\left[
B''(T)p
+\frac12C''(T)p^2
+\frac13D''(T)p^3
+\cdots
\right]
\end{aligned}
```

を得る．

これを整理すると，

```math
\boxed{
C_p^{(0)}(T)
=
C_p(p,T)
+TB''(T)p
+\frac12TC''(T)p^2
+\frac13TD''(T)p^3
+\cdots
}
\tag{12}
```

となる．

これが，有限圧力で測定した実在気体の定圧モル比熱から，理想気体極限の定圧モル比熱を求める補正式である．

### 5．実測値から理想気体状態の比熱を推定する方法

式 (12) より，有限圧力 $p$ で測定した定圧モル比熱 $C_p(p,T)$ から，理想気体状態の値 $C_p^{(0)}(T)$ を求めることができる．

特に，圧力が十分小さい場合には，高次の項を無視して，

```math
\boxed{
C_p^{(0)}(T)
=
C_p(p,T)+TB''(T)p+O(p^2)
}
\tag{13}
```

と近似できる．

したがって，実際の推定方法は次のとおりである．

1．温度 $T$ を一定に保ち，複数の低圧 $p$ における実在気体の定圧モル比熱 $C_p(p,T)$ を測定する．

2．状態方程式の低圧展開を用いて，係数 $B(T),C(T),D(T),\ldots$ を求める．
これらの係数は，PVT測定または適切な状態方程式から決定できる．

3．係数 $B(T)$ などの温度依存性を調べ，必要な二階微分 $B''(T),C''(T),\ldots$ を求める．

4．式 (12) に従って有限圧力での測定値を補正する．
あるいは，複数の低圧における測定値を圧力について外挿し， $p=0$ における切片を求める．

5．得られた切片を理想気体状態の定圧モル比熱 $C_p^{(0)}(T)$ とする．

なお，実測値を圧力について直接外挿する場合には，

```math
C_p(p,T)
=
C_p^{(0)}(T)-TB''(T)p+O(p^2)
```

という低圧展開を利用できる．
したがって，低圧での $C_p$ と $p$ の関係を一次式で近似したとき，その圧力ゼロでの切片が求める理想気体の定圧モル比熱となる．

### 6．適用条件と注意事項

本解答の補正式は，低圧領域での状態方程式の展開を前提とする．

特に，次の条件が必要である．

- 気体が単一の平衡相を保っていること．
- 温度と圧力について状態関数が十分滑らかであること．
- 物質量と化学組成が一定であること．
- 低圧展開の係数が温度について二階微分可能であること．
- 状態方程式の展開を温度微分および圧力積分に対して必要な範囲で項別に扱えること．
- $p\to0$ で理想気体極限が成立すること．

また，状態方程式の係数 $B(T),C(T),D(T),\ldots$ は温度によって変化するため，これらの二階微分は一般にゼロではない．
したがって，実在気体の定圧モル比熱は圧力に依存する．

一方，理想気体極限では，

```math
pV_m=RT
```

となり，体積の温度二階偏微分に寄与する圧力依存項が消えるため，定圧モル比熱は圧力ゼロの極限値に近づく．

実際の推定では，低圧展開の高次項が無視できる圧力範囲を選び，測定値を圧力ゼロへ外挿することが重要である．

### 7．結論

実在気体の定圧モル比熱と圧力の関係は，

```math
\boxed{
\left(\frac{\partial C_p}{\partial p}\right)_T
=
-T\left(\frac{\partial^2V_m}{\partial T^2}\right)_p
}
```

で与えられる．

さらに，低圧での状態方程式を，

```math
pV_m
=
RT+B(T)p+C(T)p^2+D(T)p^3+\cdots
```

と展開すれば，

```math
\boxed{
C_p^{(0)}(T)
=
C_p(p,T)
+TB''(T)p
+\frac12TC''(T)p^2
+\frac13TD''(T)p^3
+\cdots
}
```

となる．

したがって，**実際の気体の定圧モル比熱を複数の低圧で測定し，低圧展開による補正を行うか，測定値を圧力ゼロへ外挿することで，理想気体状態の定圧モル比熱を推定できる．**

これが求める方法である．
