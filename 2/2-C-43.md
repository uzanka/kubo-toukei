# 演習問題【2-C-43】

## 解答

### 1．定圧モル比熱の圧力依存性を表す関係式

実在気体の 1 mol を考え，モル体積を $V$ ，圧力を $p$ ，絶対温度を $T$ ，定圧モル比熱を $C_p$ とする．
まず，定圧モル比熱の定義は，

```math
C_p=T\left(\frac{\partial S}{\partial T}\right)_p
\tag{1}
```

である．
ここで $S$ はモルエントロピーである．

式 (1) を温度一定のもとで圧力 $p$ について偏微分すると，

```math
\left(\frac{\partial C_p}{\partial p}\right)_T
=
T\frac{\partial}{\partial p}
\left(\frac{\partial S}{\partial T}\right)_p
```

となる．
混合二階偏微分の順序を交換できるため，

```math
\left(\frac{\partial C_p}{\partial p}\right)_T
=
T\frac{\partial}{\partial T}
\left(\frac{\partial S}{\partial p}\right)_T
\tag{2}
```

である．

ここで，ギブズ自由エネルギーの全微分から得られるマクスウェルの関係式，

```math
\left(\frac{\partial S}{\partial p}\right)_T
=
-\left(\frac{\partial V}{\partial T}\right)_p
\tag{3}
```

を用いる．
式 (3) を式 (2) に代入すれば，

```math
\boxed{
\left(\frac{\partial C_p}{\partial p}\right)_T
=-T\left(\frac{\partial^2V}{\partial T^2}\right)_p
}
\tag{4}
```

を得る．
これが，実在気体の定圧モル比熱の圧力依存性を表す関係式である．

### 2．状態方程式の展開と $A(T)$ の性質

問題文より，圧力が小さいときの状態方程式は，

```math
pV=f(p,T)=A(T)+B(T)p+C(T)p^2+\cdots
\tag{5}
```

と展開できる．
ここで $A(T)$ ， $B(T)$ ， $C(T)$ は温度のみの関数である．
なお，ここでの $C(T)$ は状態方程式の展開係数であり，定圧モル比熱 $C_p$ とは異なる量である．

式 (5) から，

```math
V=\frac{A(T)}{p}+B(T)+C(T)p+\cdots
\tag{6}
```

となる．

この後の計算には，

```math
A''(T)=\frac{d^2A}{dT^2}=0
\tag{7}
```

が必要である．
この性質は，熱力学的整合性から導かれる．

エンタルピーを $H=U+pV$ とすると，熱力学的恒等式

```math
\left(\frac{\partial H}{\partial p}\right)_T
=V-T\left(\frac{\partial V}{\partial T}\right)_p
\tag{8}
```

が成り立つ．
問題文の内部エネルギーの展開式

```math
U=\alpha(T)+\beta(T)p+\gamma(T)p^2+\cdots
```

を用いれば，エンタルピー $H$ も圧力のべき級数として表せる．
したがって，左辺の $(\partial H/\partial p)_T$ は $p\to0$ で有限である．

一方，式 (6) より，式 (8) の右辺には，

```math
\frac{A(T)-T A'(T)}{p}
```

という項が現れる．
ここで $A'(T)=dA/dT$ である．
左辺が有限であるためには，この発散項の係数がゼロでなければならない．
よって，

```math
A(T)-TA'(T)=0
```

となる．
これを整理すると，

```math
\frac{d}{dT}\left(\frac{A(T)}{T}\right)=0
```

であるから，

```math
A(T)=kT
```

となる．
ここで $k$ は温度に依存しない定数である．
したがって，

```math
\boxed{
A''(T)=0
}
```

が示された．
1 mol の気体では，低圧極限が理想気体状態に対応するため $A(T)=RT$ である．

### 3．$p=0$ における定圧モル比熱を求める

式 (6) を温度 $T$ について偏微分する．
圧力 $p$ を一定に保つと，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=\frac{A'(T)}{p}+B'(T)+C'(T)p+\cdots
```

である．
もう一度温度について偏微分すると，

```math
\left(\frac{\partial^2V}{\partial T^2}\right)_p
=\frac{A''(T)}{p}+B''(T)+C''(T)p+\cdots
```

となる．
ここで $B''(T)=d^2B/dT^2$ ， $C''(T)=d^2C/dT^2$ である．

前節で $A''(T)=0$ を示したため，

```math
\left(\frac{\partial^2V}{\partial T^2}\right)_p
=B''(T)+C''(T)p+\cdots
\tag{9}
```

となる．
式 (9) を式 (4) に代入すると，

```math
\left(\frac{\partial C_p}{\partial p}\right)_T
=-T\left[B''(T)+C''(T)p+\cdots\right]
\tag{10}
```

を得る．

温度 $T$ を一定に保ったまま，圧力を $0$ から $p$ まで積分する．
$p=0$ の極限における定圧モル比熱を

```math
C_p^{(0)}(T)=\lim_{p\to0}C_p(p,T)
```

と定義すると，

```math
C_p(p,T)-C_p^{(0)}(T)
=\int_0^p
\left(\frac{\partial C_p}{\partial q}\right)_T dq
\tag{11}
```

である．
ここで $q$ は積分変数である．
式 (10) を代入すれば，

```math
C_p-C_p^{(0)}
=-T\int_0^p
\left[B''(T)+C''(T)q+\cdots\right]dq
```

となる．
積分を実行すると，

```math
C_p-C_p^{(0)}
=-T\left[
B''(T)p+\frac{1}{2}C''(T)p^2+\cdots
\right]
```

を得る．
したがって，

```math
\boxed{
C_p^{(0)}
=C_p+T B''(T)p
+\frac{1}{2}T C''(T)p^2+\cdots
}
\tag{12}
```

である．

### 4．実測値から理想気体状態の比熱を推定する方法

式 (12) によれば，温度 $T$ において有限圧力 $p$ で測定した定圧モル比熱 $C_p$ から，状態方程式の係数 $B(T)$ ， $C(T)$ などの温度に関する二階微分を用いて補正を行うことで， $p=0$ の極限における値 $C_p^{(0)}(T)$ を推定できる．

実際には，複数の低圧で測定した $C_p$ の値と状態方程式の係数を利用し，式 (12) に従って圧力ゼロへ外挿する．
これにより，実在気体の測定値から理想気体状態における定圧モル比熱を求めることができる．
