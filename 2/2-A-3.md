# 演習問題【2-A-3】

## 解答

2本の断熱線が交わると仮定し，Thomson の原理に矛盾することを示す．

### 1．循環過程の構成

$p$-$V$ 図において，2本の準静的断熱線 $a$ ， $b$ が点 $C$ で交わっていると仮定する．

ここで，断熱線 $a$ ， $b$ の両方と交わる等温線を1本選び，その交点をそれぞれ $A$ ， $B$ とする．
このような等温線を選べるのは，通常の熱力学系では断熱線の傾きが等温線の傾きより急であるためである．
なお，この等温線は点 $C$ を通る必要はない．

このとき，等温線 $AB$ と断熱線 $BC$ ， $CA$ をつなぐことで，

```math
A\longrightarrow B\longrightarrow C\longrightarrow A
```

という閉じた循環過程を構成できる．
各過程は準静的な等温過程または断熱過程であるから，この循環過程は可逆過程である．

### 2．循環過程における熱量と仕事

まず，等温過程 $A\to B$ を考える．
この過程は，系が外部から熱を吸収する向きにとる．
この過程で系が吸収する熱量を $Q$ とする．

次に，断熱過程 $B\to C$ と $C\to A$ を考える．
両過程はいずれも断熱過程であるため，系と外部との間で熱の授受は起こらない．
したがって，これらの過程における熱量はともにゼロである．

よって，循環過程全体で系が外部から受け取る正味の熱量は，

```math
Q_{\mathrm{total}}=Q+0+0=Q
```

となる．

一方，系が外部にする正味の仕事を $W$ とする．
準静的過程では，微小仕事は $p\,dV$ で表されるため，循環過程全体の仕事は

```math
W=\oint p\,dV
```

である．
$p$-$V$ 図では，この積分は循環過程が囲む面積に対応する．
循環の向きを系が外部に仕事をする向きにとれば，

```math
W>0
```

となる．

### 3．熱力学第1法則による関係

熱力学第1法則によれば，系が外部から吸収する熱量を $Q_{\mathrm{total}}$ ，系が外部にする仕事を $W$ ，内部エネルギーの変化を $\Delta U$ とすると，

```math
\Delta U=Q_{\mathrm{total}}-W
```

が成立する．

この過程は循環過程であり，系は元の状態に戻る．
内部エネルギーは状態量であるから，

```math
\Delta U=0
```

である．
したがって，

```math
0=Q_{\mathrm{total}}-W
```

より，

```math
Q_{\mathrm{total}}=W
```

を得る．
さらに， $Q_{\mathrm{total}}=Q$ であるから，

```math
Q=W>0
```

となる．

すなわち，この循環過程では，系が単一の熱源から正の熱量 $Q$ を吸収し，その熱をすべて仕事 $W=Q$ に変換していることになる．
また，系は循環過程の終了時に元の状態に戻るため，系自体に変化は残らない．
熱の授受が起こるのは等温過程 $A\to B$ だけであり，熱源はその等温過程の温度にある単一の熱源である．

しかし，Thomson の原理によれば，単一の熱源から熱を取り出し，それをすべて仕事に変換し，それ以外に何の変化も残さない循環過程は実現できない．

したがって，ここで構成した循環過程は Thomson の原理に矛盾する．

### 4．結論

以上の矛盾は，2本の断熱線が点 $C$ で交わると仮定したことから生じたものである．
ゆえに，最初の仮定は誤りである．

したがって，

```math
\boxed{
\text{2本の準静的断熱線は交わることがない}
}
```

ことが示された．
