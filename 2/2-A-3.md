# 演習問題【2-A-3】

## 解答

二つの異なる準静的断熱線が交わると仮定し，Thomson の原理に矛盾することを示す．

### 1．前提と仮定

以下の条件を満たす単純圧縮系を考える．

1. 考える平衡状態領域は単一相であり，状態は温度 $T$ と体積 $V$ によって局所的に指定される．
2. 状態方程式 $p=p(T,V)$ は交点の近傍で $C^1$ 級であり，交点 $C=(T_C,V_C)$ において
   ```math
   \left(\frac{\partial p}{\partial T}\right)_V\bigg|_C\ne0
   ```
   を満たす．
3. 考える二つの準静的断熱線は，交点の近傍で正則な曲線であり，温度 $T$ を局所的なパラメータとして
   ```math
   V=V_1(T),\qquad V=V_2(T)
   ```
   と表せる．
   また，これらは交点のどの近傍においても同一の曲線ではない．
4. 断熱過程では熱の授受がなく，等温過程はその温度と等しい温度の単一熱源と準静的に熱交換させて実行できるものとする．

これらは本証明で用いる正則性および非退化性の仮定である．
特に，2は $p$-$V$ 平面への局所的な写像を保証するための条件であり，3は断熱線と等温線から局所的な閉サイクルを構成するための条件である．

### 2．交点近傍での閉サイクルの構成

二つの断熱線が交点 $C$ を通るので，

```math
V_1(T_C)=V_2(T_C)=V_C
```

である．
ここで，

```math
f(T)=V_1(T)-V_2(T)
```

と定義する．
仮定3より， $f$ は連続であり， $f(T_C)=0$ である一方， $T_C$ の任意の近傍に $f(T)\ne0$ となる点が存在する．

そこで， $T_C$ に十分近い $T_1$ を選び，

```math
f(T_1)\ne0
```

とする．
開集合

```math
\{T\mid f(T)\ne0\}
```

のうち， $T_1$ を含む連結成分を考える．
この連結成分は区間であり， $T_C$ はその外にあるため， $T_C$ 側の端点を $T_0$ とおくことができる．
連続性から

```math
f(T_0)=0
```

であり，連結成分の内部では

```math
f(T)\ne0
\qquad (T_0<T\le T_1)
```

である．

したがって，

```math
V_1(T_0)=V_2(T_0)=V_0
```

である一方，

```math
V_1(T)\ne V_2(T)
\qquad (T_0<T\le T_1)
```

が成り立つ．

ここで，

```math
C_0=(T_0,V_0),
```

```math
A=(T_1,V_1(T_1)),\qquad
B=(T_1,V_2(T_1))
```

とおく．

二つの断熱線上の区間 $C_0\to A$ ， $B\to C_0$ と，等温線 $T=T_1$ 上の区間 $A\to B$ をつなぐ．

二つの断熱線は $T_0<T\le T_1$ で交わらず，それぞれ $V=V_i(T)$ という一価関数で表されるため，等温線 $T=T_1$ は各断熱線とそれぞれ端点で一度だけ交わる．
また，等温線上の区間 $A\to B$ は $T=T_1$ に限られるため，断熱線の内部とは交わらない．

よって，この三つの経路からなる曲線は， $T$-$V$ 平面において自己交差のない単純閉曲線となる．

### 3．$p$-$V$ 平面での仕事

写像

```math
F:(T,V)\longmapsto(p(T,V),V)
```

を考える．
その Jacobian は

```math
\frac{\partial(p,V)}{\partial(T,V)}
=
\begin{vmatrix}
\left(\dfrac{\partial p}{\partial T}\right)_V&
\left(\dfrac{\partial p}{\partial V}\right)_T\\
0&1
\end{vmatrix}
=
\left(\frac{\partial p}{\partial T}\right)_V
```

である．
仮定2より，交点 $C$ ではこの Jacobian はゼロでない．
したがって，逆関数定理により， $C$ の十分小さい近傍で $F$ は局所的な $C^1$ 級微分同相写像となる．

前節の閉曲線は $C$ の十分小さい近傍に取ることができるので，その像も $p$-$V$ 平面で自己交差のない単純閉曲線となり，正の面積を囲む．

一サイクルで系が外部にする仕事は

```math
W=\oint_\Gamma p\,dV
```

である．
Green の定理から，閉曲線の向きを適切に選べば，

```math
W=\operatorname{Area}(D)>0
```

となる．
ここで $D$ は $p$-$V$ 平面で閉曲線が囲む領域である．
したがって，

```math
\boxed{W>0}
```

である．

### 4．Thomson の原理との矛盾

構成したサイクルでは，二つの過程は断熱過程であるため熱の授受はない．
熱の授受が行われるのは，温度 $T_1$ の等温過程 $A\to B$ のみである．
この過程は，温度 $T_1$ の単一熱源と準静的に熱交換させて行う．

一サイクル後には系は初期状態に戻るため，

```math
\Delta U=0
```

である．
第一法則

```math
\Delta U=Q-W
```

より，

```math
0=Q-W
```

したがって，

```math
\boxed{Q=W>0}
```

を得る．

これは，単一の熱源から熱を受け取り，その熱をすべて仕事に変換するサイクルが存在することを意味する．

しかし，Thomson の原理によれば，このようなサイクルは存在しない．
これは Thomson の原理に矛盾する．

したがって，仮定1〜4を満たす状態領域では，二つの異なる準静的断熱線が交わることはない．

```math
\boxed{\text{二つの異なる準静的断熱線は交わらない．}}
```
