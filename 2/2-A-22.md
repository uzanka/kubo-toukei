# 演習問題【2-A-22】

## 解答

### 1. エントロピー変化の導出

固体の温度 $T$ を一定に保ったまま，圧力を $p_A$ から $p_B$ まで変化させる（圧縮する）ときの，エントロピーの変化量 $\Delta S$ を求める．

エントロピー $S$ は圧力 $p$ と温度 $T$ の関数 $S(T, p)$ であるため，その全微分は次のように書ける．

$$dS = \left(\frac{\partial S}{\partial T}\right)_p dT + \left(\frac{\partial S}{\partial p}\right)_T dp$$

今回は温度 $T$ が一定（ $dT = 0$ ）であるため，式は以下のように簡略化される．

$$dS = \left(\frac{\partial S}{\partial p}\right)_T dp$$

エントロピーの変化量 $\Delta S$ は，圧力の変化 $p_A \to p_B$ にわたってこの式を積分することで得られる．

$$\Delta S = \int_{p_A}^{p_B} \left(\frac{\partial S}{\partial p}\right)_T dp$$

ここで，マクスウェルの関係式を用いて， $(\partial S/\partial p)_T$ を体積 $V$ の偏微分に変換する．
マクスウェルの関係式によれば，

$$\left(\frac{\partial S}{\partial p}\right)_T = -\left(\frac{\partial V}{\partial T}\right)_p$$

が成り立つ．
これを用いると，求める積分は次のように書き換えられる．

$$\Delta S = \int_{p_A}^{p_B} -\left(\frac{\partial V}{\partial T}\right)_p dp = -\int_{p_A}^{p_B} \left(\frac{\partial V}{\partial T}\right)_p dp$$

問題文より，与えられた実験結果は $\left(\frac{\partial V}{\partial T}\right)_p = a + bp + cp^2$ である．
これを代入して積分を実行する．

$$\Delta S = -\int_{p_A}^{p_B} (a + bp + cp^2) dp$$

$$\Delta S = -\left[ ap + \frac{1}{2}bp^2 + \frac{1}{3}cp^3 \right]_{p_A}^{p_B}$$

$$\Delta S = -\left\{ a(p_B - p_A) + \frac{1}{2}b(p_B^2 - p_A^2) + \frac{1}{3}c(p_B^3 - p_A^3) \right\}$$

以上により，エントロピーの増加量は次のように求まった．

$$\Delta S = - \left\{ a(p_B - p_A) + \frac{1}{2}b(p_B^2 - p_A^2) + \frac{c}{3}(p_B^3 - p_A^3) \right\}$$

## 解説

### マクスウェルの関係式の役割

この問題では，エントロピーの変化を直接計算することは困難であるが，マクスウェルの関係式を用いることで，測定可能な量である「温度による体積の変化率（熱膨張係数に関連する量）」を使ってエントロピーの変化を記述できるようになる．

### 圧縮とエントロピーの関係

問題文では「圧縮するとき」とある．
一般に，圧力を高める（ $p_B > p_A$ ）ことは系を押しつぶすことに相当する．
もし，この固体が通常の物質（熱膨張係数が正，つまり $\left(\frac{\partial V}{\partial T}\right)_p > 0$ ）であれば， $a, b, c$ は正の値をとる傾向がある．
その場合， $\Delta S$ の値は負になる．

「エントロピーが増すか？」という問いに対して，計算結果が負であれば，エントロピーは「減少する」ことになる．
物理的には，圧力を加えて体積を小さくすることで，粒子の配置の自由度が制限されるため，エントロピーが減少するという直感と一致する．
