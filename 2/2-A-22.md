# 演習問題【2-A-22】

## 解答

温度 $T$ を一定に保ち，圧力を $p_A$ から $p_B$ まで増加させるときのエントロピー変化 $\Delta S$ を求める．
ここでは，圧縮により $p_B>p_A$ となる場合を考える．

エントロピー $S$ は，平衡状態を表す状態量である．
温度 $T$ と圧力 $p$ を独立変数とすると，その全微分は

```math
dS=\left(\frac{\partial S}{\partial T}\right)_p dT
+\left(\frac{\partial S}{\partial p}\right)_T dp
```

と書ける．
今回は温度一定の変化であるため， $dT=0$ であり，

```math
dS=\left(\frac{\partial S}{\partial p}\right)_T dp
```

となる．
したがって，圧力が $p_A$ から $p_B$ まで変化するときのエントロピー変化は，

```math
\Delta S=S_B-S_A
=\int_{p_A}^{p_B}
\left(\frac{\partial S}{\partial p}\right)_T dp
```

で与えられる．

ここで，マクスウェルの関係式

```math
\left(\frac{\partial S}{\partial p}\right)_T
=-\left(\frac{\partial V}{\partial T}\right)_p
```

を用いる．
この関係式は，ギブズ自由エネルギー $G$ の全微分

```math
dG=-S\,dT+V\,dp
```

において，混合二階偏微分の順序を入れ替えられることから導かれる．
この式をエントロピー変化の積分に代入すると，

```math
\Delta S
=-\int_{p_A}^{p_B}
\left(\frac{\partial V}{\partial T}\right)_p dp
```

となる．

問題文では，温度 $T$ において，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=a+bp+cp^2
```

と与えられている．
これを代入すると，

```math
\Delta S=-\int_{p_A}^{p_B}(a+bp+cp^2)\,dp
```

である．
各項を圧力 $p$ について積分すれば，

```math
\Delta S
=-\left[ap+\frac{b}{2}p^2+\frac{c}{3}p^3\right]_{p_A}^{p_B}
```

を得る．
よって，エントロピー変化は

```math
\boxed{
\Delta S
=-\left\{
a(p_B-p_A)
+\frac{b}{2}(p_B^2-p_A^2)
+\frac{c}{3}(p_B^3-p_A^3)
\right\}
}
```

である．

### エントロピー変化の符号

上式は，圧縮に伴うエントロピーの変化を符号付きで表している．
圧力範囲全体で

```math
\left(\frac{\partial V}{\partial T}\right)_p>0
```

であれば， $p_B>p_A$ より積分の値は正となるため，

```math
\Delta S<0
```

である．
すなわち，この場合，等温圧縮によってエントロピーは減少する．
一方，この偏微分の符号が与えられていなければ，エントロピーが増加するか減少するかは，最終式によって判断する必要がある．
