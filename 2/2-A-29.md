# 演習問題【2-A-29】

## 解答

### 1．問題の考え方

室温 $25^\circ\mathrm C$ の室を，温度一定の熱浴と考える．
この室温は絶対温度で

```math
T_H=25+273=298\,\mathrm K
```

である．
また，氷ができる温度は

```math
T_0=273\,\mathrm K
```

である．

水 $1\,\mathrm{ton}$ から氷を作るためには，まず水を $298\,\mathrm K$ から $273\,\mathrm K$ まで冷却し，続いて $273\,\mathrm K$ で凝固させなければならない．

冷凍機は，外部から仕事を受け取ることで，低温側から熱を取り出して高温側へ移動させる装置である．
ここでは，各段階で可逆なカルノー冷凍機を用いる場合を考える．
このとき必要な仕事は最小となる．

したがって，必要な最小仕事 $W$ は，水の冷却に必要な仕事 $W_1$ と，凝固に必要な仕事 $W_2$ の和である．

```math
W=W_1+W_2
```

### 2．水を $25^\circ\mathrm C$ から $0^\circ\mathrm C$ まで冷却する仕事 $W_1$

まず，水の熱容量 $C$ を求める．
水の質量は

```math
m=1\,\mathrm{ton}=10^6\,\mathrm g
```

であり，水の比熱を $1\,\mathrm{cal/(g\cdot K)}$ と近似する．
したがって，水全体の熱容量は

```math
C=mc_p=10^6\,\mathrm{cal/K}
```

である．
ジュールに換算すると， $1\,\mathrm{cal}=4.186\,\mathrm J$ より，

```math
C=4.186\times10^6\,\mathrm{J/K}
```

となる．

水の温度が $T$ から $T+dT$ に変化するとき，水から取り出す微小熱量 $d'Q$ は

```math
d'Q=-C\,dT
```

である．
冷却中は $dT<0$ なので， $d'Q>0$ である．

温度 $T$ の水から熱量 $d'Q$ を取り出し，室温 $T_H$ の熱浴へ捨てる可逆冷凍機を考える．可逆な熱の移動では，

```math
\frac{dQ_H}{T_H}=\frac{d'Q}{T}
```

が成り立つ．
ここで $dQ_H$ は高温側へ捨てる熱量である．
冷凍機に与える仕事を $d'W$ とすると，エネルギー保存則から

```math
d'W=dQ_H-d'Q
```

であるため，

```math
d'W=d'Q\left(\frac{T_H}{T}-1\right)
```

となる．
$d'Q=-C\,dT$ ， $T_H=298\,\mathrm K$ を代入し，初期温度 $298\,\mathrm K$ から最終温度 $273\,\mathrm K$ まで積分すると，

```math
W_1=-C\int_{298}^{273}
\left(\frac{298}{T}-1\right)dT
```

を得る．
積分の上下限を入れ替えれば，

```math
W_1=C\int_{273}^{298}
\left(\frac{298}{T}-1\right)dT
```

である．
よって，

```math
\begin{aligned}
W_1
&=C\left[298\ln T-T\right]_{273}^{298}\\
&=C\left[
298\ln\frac{298}{273}-(298-273)
\right]
\end{aligned}
```

となる．
数値を代入すると，

```math
\begin{aligned}
W_1
&=4.186\times10^6
\left[
298\ln\frac{298}{273}-25
\right]\\
&\simeq4.65\times10^6\,\mathrm J
\end{aligned}
```

である．

### 3．水を $0^\circ\mathrm C$ で凍らせる仕事 $W_2$

次に， $0^\circ\mathrm C$ の水を同じ温度の氷に変える過程を考える．
水が凍る際には，融解熱に相当する潜熱 $L$ を外部へ放出する必要がある．

水 $1\,\mathrm{ton}=10^6\,\mathrm g$ の物質量 $n$ は，水のモル質量を $18\,\mathrm{g/mol}$ とすると，

```math
n=\frac{10^6}{18}
\simeq5.556\times10^4\,\mathrm{mol}
```

である．
融解熱が $1436.3\,\mathrm{cal/mol}$ であるから，凝固の際に放出される熱量の大きさは

```math
\begin{aligned}
L
&=n\times1436.3\\
&\simeq7.979\times10^7\,\mathrm{cal}
\end{aligned}
```

となる．
ジュールに換算すると，

```math
L\simeq7.979\times10^7\times4.186
\simeq3.34\times10^8\,\mathrm J
```

である．

この熱を，低温側 $T_0=273\,\mathrm K$ から高温側 $T_H=298\,\mathrm K$ へ移動させる可逆冷凍機に必要な仕事は，

```math
W_2=L\left(\frac{T_H}{T_0}-1\right)
```

である．
したがって，

```math
\begin{aligned}
W_2
&=L\frac{T_H-T_0}{T_0}\\
&=3.34\times10^8
\frac{298-273}{273}\\
&\simeq3.06\times10^7\,\mathrm J
\end{aligned}
```

を得る．

### 4．最小電気料金の計算

冷却と凝固に必要な最小仕事の合計は，

```math
\begin{aligned}
W&=W_1+W_2\\
&\simeq4.65\times10^6
+3.06\times10^7\\
&\simeq3.52\times10^7\,\mathrm J
\end{aligned}
```

である．

電力量の単位に換算する．

```math
1\,\mathrm{kWh}=3.6\times10^6\,\mathrm J
```

より，

```math
\begin{aligned}
E
&=\frac{3.52\times10^7}{3.6\times10^6}\\
&\simeq9.79\,\mathrm{kWh}
\end{aligned}
```

となる．
電気料金は $1\,\mathrm{kWh}$ 当たり $12$ 円なので，

```math
\begin{aligned}
\text{料金}
&=9.79\times12\\
&\simeq117.5\,\mathrm{円}
\end{aligned}
```

である．
したがって，理想的な可逆冷凍機を想定した場合の最低電気料金は，

```math
\boxed{
\text{約 }1.2\times10^2\,\mathrm{円}
\quad（約118\,\mathrm{円})
}
```

である．

### 5．補足

この金額は，熱力学第二法則に従う理想的な可逆過程で得られる最小仕事を電気エネルギーに換算した値である．
実際の冷凍機には摩擦，熱漏れ，圧縮機の損失などが存在するため，実際の電気料金はこの最小値より高くなる．
