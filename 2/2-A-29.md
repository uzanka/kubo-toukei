# 演習問題【2-A-29】

## 解答

### 1．問題の設定と物理モデル

室温 $25^\circ\mathrm{C}$ の室を，温度一定の熱浴と考える．
また，水は初め室温と熱平衡にあり，初期温度は $25^\circ\mathrm{C}$ であるとする．
室温と氷の凝固温度を絶対温度で表すと，

```math
T_H=25+273=298\,\mathrm K
```

```math
T_0=273\,\mathrm K
```

である．
ここで， $T_H$ は高温側の熱浴の温度， $T_0$ は水の凝固温度である．

水 $1\,\mathrm{ton}$ から氷を作るためには，まず水を $298\,\mathrm K$ から $273\,\mathrm K$ まで冷却し，続いて $273\,\mathrm K$ で凝固させる必要がある．

以下では，水の比熱を一定とし，凝固は $0^\circ\mathrm C$ の平衡状態で起こるものとする．
また，熱の授受は水・氷と室温の熱浴との間に限り，他の熱源との熱交換は考えない．
冷凍機には外部から電気仕事を供給するものとし，それ以外の外部仕事の授受は考えない．
さらに，冷凍機はサイクルを行い，最終的に初期状態に戻るものとする．

冷凍機に外部から供給する電気仕事を $W$ ，水・氷から取り出す熱量を $Q_c$ ，室温の熱浴へ放出する熱量を $Q_H$ とする．
いずれも正の値で定義する．
ここでは，電気エネルギーは損失なく仕事に変換される理想的な場合を考える．

このとき，冷凍機のエネルギー保存則より，

```math
\boxed{Q_H=Q_c+W}
\tag{1}
```

が成立する．

### 2．水の熱容量と凝固潜熱

まず，水の質量は，

```math
m=1\,\mathrm{ton}=10^6\,\mathrm g
```

である．
水の比熱は問題文に指定されていないため，

```math
c_p=1\,\mathrm{cal/(g\cdot K)}
```

と近似する．
すると，水全体の熱容量 $C$ は，

```math
\begin{aligned}
C&=mc_p\\
&=10^6\times1\\
&=10^6\,\mathrm{cal/K}
\end{aligned}
```

となる．

$1\,\mathrm{cal}=4.186\,\mathrm J$ を用いてジュールに換算すると，

```math
\boxed{
C=4.186\times10^6\,\mathrm{J/K}
}
\tag{2}
```

である．

次に，水の物質量 $n$ は，水のモル質量を $18\,\mathrm{g/mol}$ とすると，

```math
\begin{aligned}
n&=\frac{10^6}{18}\\
&\simeq5.556\times10^4\,\mathrm{mol}
\end{aligned}
```

となる．

氷の融解熱は $1436.3\,\mathrm{cal/mol}$ であるため，凝固時に放出される熱量の大きさ $L$ は，

```math
\begin{aligned}
L&=n\times1436.3\\
&=\frac{10^6}{18}\times1436.3\\
&\simeq7.9794\times10^7\,\mathrm{cal}
\end{aligned}
```

である．

ジュールに換算すると，

```math
\boxed{
L\simeq3.3402\times10^8\,\mathrm J
}
\tag{3}
```

となる．

したがって，水の冷却と凝固によって取り出す全熱量は，

```math
\begin{aligned}
Q_c&=C(T_H-T_0)+L
\end{aligned}
```

である．
すなわち，

```math
\boxed{
Q_c=C(T_H-T_0)+L
}
\tag{4}
```

となる．

### 3．熱力学第二法則から最小仕事の下限を求める

次に，冷凍機の具体的な構成によらず，熱力学第二法則から必要な仕事の下限を求める．

まず，水を $T_H$ から $T_0$ まで冷却するときのエントロピー変化は，

```math
\begin{aligned}
\Delta S_1
&=\int_{T_H}^{T_0}\frac{C}{T}\,dT\\
&=C\ln\frac{T_0}{T_H}
\end{aligned}
```

である．

また，水が $T_0$ で凝固するときのエントロピー変化は，凝固に伴って熱量 $L$ を放出するため，

```math
\Delta S_2=-\frac{L}{T_0}
```

である．

したがって，水と氷を合わせた物体のエントロピー変化は，

```math
\boxed{
\Delta S_{\mathrm{body}}
=
C\ln\frac{T_0}{T_H}
-\frac{L}{T_0}
}
\tag{5}
```

となる．

ここで，冷凍機は最終的に初期状態に戻るため，そのエントロピー変化はゼロである．
また，室温の熱浴は温度 $T_H$ のまま熱量 $Q_H$ を受け取るため，そのエントロピー変化は，

```math
\Delta S_{\mathrm{bath}}=\frac{Q_H}{T_H}
```

である．

電気仕事の供給はエネルギーの移動であり，理想的な仕事の授受にはエントロピーの移動は伴わない．
したがって，物体，冷凍機および熱浴を含む全体系について，熱力学第二法則より，

```math
\Delta S_{\mathrm{total}}
=
\Delta S_{\mathrm{body}}
+\Delta S_{\mathrm{bath}}
\geq0
```

が成立する．

式 (1)，(5) を代入すると，

```math
C\ln\frac{T_0}{T_H}
-\frac{L}{T_0}
+\frac{Q_c+W}{T_H}
\geq0
```

となる．
さらに，式 (4) を代入すれば，

```math
C\ln\frac{T_0}{T_H}
-\frac{L}{T_0}
+
\frac{C(T_H-T_0)+L+W}{T_H}
\geq0
```

を得る．

これを $W$ について整理すると，

```math
\begin{aligned}
W\geq{}&
C\left[
T_H\ln\frac{T_H}{T_0}
-(T_H-T_0)
\right]\\
&+L\left(
\frac{T_H}{T_0}-1
\right)
\end{aligned}
```

となる．

したがって，必要な仕事には，

```math
\boxed{
W\geq
C\left[
T_H\ln\frac{T_H}{T_0}
-(T_H-T_0)
\right]
+
L\left(
\frac{T_H}{T_0}-1
\right)
}
\tag{6}
```

という下限が存在する．

この下限は，熱力学第二法則から導かれたものであり，冷凍機の具体的な構成によらず，設定した物理モデルの範囲内で，すべての許される冷凍過程に対して成立する．

### 4．可逆冷凍機による最小仕事の実現

式 (6) で得られた下限が，実際に可逆冷凍機によって実現できることを確認する．

可逆過程では，全体系のエントロピー生成がゼロとなり，

```math
\Delta S_{\mathrm{total}}=0
```

が成立する．

この条件を実現するため，水の温度に合わせて微小なカルノー冷凍機を順次動作させる．
熱交換は無限小の温度差で準静的に行うものとし，可逆過程の極限を考える．

#### 4.1 水を $T_H$ から $T_0$ まで冷却する仕事 $W_1$

水の温度が $T$ から $T+dT$ に変化するとき，水から取り出す微小熱量 $d'Q$ は，

```math
d'Q=-C\,dT
```

である．
冷却中は $dT<0$ であるため，

```math
d'Q>0
```

となる．

温度 $T$ の水から熱量 $d'Q$ を取り出し，温度 $T_H$ の熱浴へ熱を放出する可逆冷凍機を考える．
可逆な熱交換では，

```math
\frac{dQ_H}{T_H}
=
\frac{d'Q}{T}
```

が成立する．
したがって，

```math
dQ_H=\frac{T_H}{T}d'Q
```

である．

エネルギー保存則より，

```math
d'W=dQ_H-d'Q
```

なので，

```math
d'W=
d'Q\left(\frac{T_H}{T}-1\right)
```

となる．

ここに，

```math
d'Q=-C\,dT
```

を代入すると，

```math
d'W=
-C\left(\frac{T_H}{T}-1\right)dT
```

である．

水の温度が $T_H$ から $T_0$ まで低下する間に必要な仕事を積分すれば，

```math
W_1
=
-C\int_{T_H}^{T_0}
\left(\frac{T_H}{T}-1\right)dT
```

となる．
積分の上下限を入れ替えると，

```math
W_1
=
C\int_{T_0}^{T_H}
\left(\frac{T_H}{T}-1\right)dT
```

である．

したがって，

```math
\begin{aligned}
W_1
&=C\left[
T_H\ln\frac{T_H}{T_0}
-(T_H-T_0)
\right]
\end{aligned}
```

を得る．

数値を代入すると，

```math
\begin{aligned}
W_1
&=4.186\times10^6
\left[
298\ln\frac{298}{273}-25
\right]\\
&\simeq4.652\times10^6\,\mathrm J
\end{aligned}
```

である．

よって，

```math
\boxed{
W_1\simeq4.652\times10^6\,\mathrm J
}
\tag{7}
```

となる．

#### 4.2 水を $T_0$ で凍らせる仕事 $W_2$

次に，温度 $T_0=273\,\mathrm K$ の水を，同じ温度の氷に変える過程を考える．

このとき，低温側から取り出す熱量は凝固潜熱 $L$ である．

可逆冷凍機について，

```math
\frac{Q_H}{T_H}=\frac{L}{T_0}
```

が成立するので，

```math
Q_H=L\frac{T_H}{T_0}
```

となる．

エネルギー保存則より，

```math
W_2=Q_H-L
```

であるから，

```math
\boxed{
W_2=L\left(\frac{T_H}{T_0}-1\right)
}
```

を得る．

数値を代入すると，

```math
\begin{aligned}
W_2
&=3.3402\times10^8
\left(\frac{298}{273}-1\right)\\
&\simeq3.059\times10^7\,\mathrm J
\end{aligned}
```

となる．

したがって，

```math
\boxed{
W_2\simeq3.059\times10^7\,\mathrm J
}
\tag{8}
```

である．

#### 4.3 最小仕事の確定

冷却過程と凝固過程に必要な仕事を合計すると，

```math
W_{\min}=W_1+W_2
```

である．

式 (7)，(8) より，

```math
\begin{aligned}
W_{\min}
={}&C\left[
T_H\ln\frac{T_H}{T_0}
-(T_H-T_0)
\right]\\
&+L\left(
\frac{T_H}{T_0}-1
\right)
\end{aligned}
```

となる．

これは式 (6) で得られた，すべての冷凍過程に対する仕事の下限と一致する．

したがって，この下限は可逆冷凍機によって実現可能であり，求める最小仕事であることが示された．

なお，実際に有限時間で運転する場合には，熱交換に有限の温度差が必要となるため，不可逆性が生じる．
したがって，ここで求めた値は，可逆過程の極限における理論上の最小仕事である．

### 5．最小電気料金の計算

以上より，冷却と凝固に必要な最小仕事の合計は，

```math
\begin{aligned}
W_{\min}
&=W_1+W_2\\
&=4.652\times10^6
+3.059\times10^7\\
&\simeq3.524\times10^7\,\mathrm J
\end{aligned}
```

である．

電力量の単位に換算する．

```math
1\,\mathrm{kWh}=3.6\times10^6\,\mathrm J
```

より，

```math
\begin{aligned}
E
&=\frac{3.524\times10^7}{3.6\times10^6}\\
&\simeq9.79\,\mathrm{kWh}
\end{aligned}
```

となる．

電気料金は1キロワット時当たり12円なので，

```math
\begin{aligned}
\text{料金}
&=9.79\times12\\
&\simeq117.5\,\mathrm{円}
\end{aligned}
```

である．

したがって，求める理論上の最低電気料金は，

```math
\boxed{
\text{最低電気料金}\simeq118\,\mathrm{円}
}
```

となる．

### 6．結果の物理的意味

今回の計算では，水の冷却に必要な仕事と，凝固潜熱を取り出すために必要な仕事を別々に求めた．

その合計は，

```math
W_{\min}\simeq3.524\times10^7\,\mathrm J
```

であり，電力量では約 $9.79\,\mathrm{kWh}$ に相当する．

また，熱力学第二法則から求めた仕事の下限と，可逆カルノー冷凍機によって得られる仕事が一致したことから，可逆過程が最小仕事を与えることが確認された．

不可逆過程では全体系にエントロピーが生成されるため，必要仕事は増加する．
全体系のエントロピー生成を $S_{\mathrm{gen}}$ とすると，

```math
S_{\mathrm{gen}}
=
\Delta S_{\mathrm{body}}
+\frac{Q_H}{T_H}
```

である．
したがって，

```math
\boxed{
W=W_{\min}+T_HS_{\mathrm{gen}}
}
```

と表される．

熱力学第二法則より，

```math
S_{\mathrm{gen}}\geq0
```

であるため，

```math
W\geq W_{\min}
```

となる．
したがって，エントロピー生成がゼロとなる可逆過程でのみ，理論上の最小仕事が得られる．

以上より，1 tonの水から氷を作るための理論上の最低電気料金は，

```math
\boxed{
\text{約118円}
}
```

である．

実際の冷凍機では，圧縮機の損失，摩擦，熱漏れ，電動機の効率などによって不可逆性が生じるため，実際の電気料金はこの理論上の最低値より高くなる．
