# 演習問題【2-B-36】

## 解答

### 1．Joule–Thomson 係数の一般式

Joule–Thomson 係数は，エンタルピー $H$ 一定のもとでの温度の圧力微分として，

```math
\mu_{\mathrm{JT}}
=\left(\frac{\partial T}{\partial p}\right)_H
```

と定義される．

エンタルピーの微分は，

```math
dH=T\,dS+V\,dp
```

である．
また，エントロピーの全微分を $T,p$ で表すと，

```math
dS=\frac{C_{p,\mathrm{tot}}}{T}\,dT
-\left(\frac{\partial V}{\partial T}\right)_p dp
```

となる．
したがって，

```math
dH=C_{p,\mathrm{tot}}\,dT+
\left[
V-T\left(\frac{\partial V}{\partial T}\right)_p
\right]dp.
```

エンタルピー一定，すなわち $dH=0$ とすれば，

```math
\boxed{
\mu_{\mathrm{JT}}
=
\frac{T\left(\dfrac{\partial V}{\partial T}\right)_p-V}
{C_{p,\mathrm{tot}}}
}
\tag{1}
```

を得る．

ここで， $C_{p,\mathrm{tot}}$ は全体の定圧熱容量である．
物質量を $n$ mol，モル定圧熱容量を $C_p$ とすれば，

```math
C_{p,\mathrm{tot}}=nC_p
```

である．
以下では，モル体積

```math
v=\frac Vn
```

を用いて計算する．
このとき，

```math
\boxed{
\mu_{\mathrm{JT}}
=
\frac{T\left(\dfrac{\partial v}{\partial T}\right)_p-v}
{C_p}
}
\tag{2}
```

となる．

### 2．希薄 van der Waals 気体の状態方程式の展開

$n$ mol の van der Waals 気体の状態方程式は，

```math
\left(p+\frac{an^2}{V^2}\right)(V-nb)=nRT
```

である．
モル体積 $v=V/n$ を用いると，

```math
p=\frac{RT}{v-b}-\frac{a}{v^2}
\tag{3}
```

となる．

希薄気体の条件を明確にするため，

```math
q=\frac1v=\frac nV,\qquad
x=bq=\frac{nb}{V},\qquad
y=\frac{a q}{RT}=\frac{na}{VRT}
```

と定義する．
問題の条件は，

```math
|x|\ll1,\qquad |y|\ll1
```

である．

式 (3) は，

```math
p=\frac{RTq}{1-bq}-aq^2
```

と書ける．
幾何級数を二次の微小項まで展開すると，

```math
\frac1{1-bq}
=1+bq+b^2q^2+O(q^3)
```

であるから，

```math
\begin{aligned}
p
&=RTq(1+bq+b^2q^2+\cdots)-aq^2\\
&=RTq+(RTb-a)q^2+RTb^2q^3+O(q^4).
\end{aligned}
```

したがって，

```math
\boxed{
p=RTq\left(1+x+x^2-y\right)+O(q^4)
}
\tag{4}
```

となる．
ここでは，理想気体項 $RTq$ に対して二次の相対補正まで保持している．

特に， $x^2=(nb/V)^2$ に対応する項 $RTb^2q^3$ まで保持している．

### 3．Joule–Thomson 係数の分子の展開

式 (2) の分子

```math
T\left(\frac{\partial v}{\partial T}\right)_p-v
```

を求める．

式 (3) を $T$ および $v$ で偏微分すると，

```math
\left(\frac{\partial p}{\partial T}\right)_v
=\frac{R}{v-b}
```

および

```math
\left(\frac{\partial p}{\partial v}\right)_T
=-\frac{RT}{(v-b)^2}+\frac{2a}{v^3}
```

である．

圧力一定の条件から，

```math
\left(\frac{\partial v}{\partial T}\right)_p
=
-\frac{(\partial p/\partial T)_v}
{(\partial p/\partial v)_T}
```

なので，

```math
\left(\frac{\partial v}{\partial T}\right)_p
=
\frac{R/(v-b)}
{RT/(v-b)^2-2a/v^3}.
```

ここで，

```math
q=\frac1v,\qquad A=\frac{a}{RT}
```

と置く．
分子を整理すると，

```math
\begin{aligned}
T\left(\frac{\partial v}{\partial T}\right)_p-v
&=
\frac{TR/(v-b)-v[RT/(v-b)^2-2a/v^3]}
{RT/(v-b)^2-2a/v^3}\\
&=
\frac{2a-RTb/(1-bq)^2}
{RT/(1-bq)^2-2aq}.
\end{aligned}
```

したがって，

```math
\boxed{
T\left(\frac{\partial v}{\partial T}\right)_p-v
=
\frac{2A-b(1-bq)^{-2}}
{(1-bq)^{-2}-2Aq}
}
\tag{5}
```

である．

ここで，

```math
(1-bq)^{-2}
=1+2bq+3b^2q^2+O(q^3)
```

を用いる．
式 (5) の分子・分母をそれぞれ一次の $q$ まで展開すれば，

```math
2A-b(1-bq)^{-2}
=
(2A-b)-2b^2q+O(q^2)
```

および

```math
(1-bq)^{-2}-2Aq
=
1+(2b-2A)q+O(q^2)
```

となる．

```math
\frac{1}{1+\alpha q}
=1-\alpha q+O(q^2)
```

を用いて分母を逆数展開すると，

```math
\begin{aligned}
T\left(\frac{\partial v}{\partial T}\right)_p-v
&=
\left[(2A-b)-2b^2q+O(q^2)\right]\\
&\quad\times
\left[1-(2b-2A)q+O(q^2)\right]\\
&=
(2A-b)\\
&\quad-
\left[
2b^2+(2A-b)(2b-2A)
\right]q
+O(q^2).
\end{aligned}
```

よって，

```math
\boxed{
T\left(\frac{\partial v}{\partial T}\right)_p-v
=
\left(\frac{2a}{RT}-b\right)
-
\left[
2b^2+
\left(\frac{2a}{RT}-b\right)
\left(2b-\frac{2a}{RT}\right)
\right]\frac nV
+O\left(\frac{n^2}{V^2}\right)
}
\tag{6}
```

を得る．

ここでは，希薄気体の最低次の項に加えて，二次の微小量に対応する密度一次の補正を保持している．

### 4．定圧モル熱容量 $C_p$ の展開

Joule–Thomson 係数を二次の微小項まで一貫して求めるためには，式 (2) の分母である $C_p$ の密度依存性も考慮する必要がある．

熱力学的関係式

```math
C_p-C_V
=
-T\frac{
\left[(\partial p/\partial T)_v\right]^2
}{
(\partial p/\partial v)_T
}
```

を用いる．
ここで $C_V$ はモル定積熱容量である．

先ほど求めた偏微分を代入すると，

```math
C_p-C_V
=
\frac{TR^2/(v-b)^2}
{RT/(v-b)^2-2a/v^3}.
```

これを整理して，

```math
C_p-C_V
=
\frac{R}
{1-\dfrac{2a(v-b)^2}{RTv^3}}
```

を得る．
$q=1/v$ ， $A=a/(RT)$ を用いれば，

```math
\boxed{
C_p-C_V
=
\frac{R}{1-2Aq(1-bq)^2}
}
\tag{7}
```

となる．

希薄気体では $q$ が小さいので，

```math
(1-bq)^2=1-2bq+O(q^2)
```

より，

```math
2Aq(1-bq)^2=2Aq+O(q^2).
```

したがって，

```math
\begin{aligned}
C_p-C_V
&=R[1+2Aq+O(q^2)]\\
&=R+\frac{2a}{T}q+O(q^2).
\end{aligned}
```

ここで，

```math
C_{p0}=C_V+R
```

と定義すれば，

```math
\boxed{
C_p=C_{p0}+\frac{2a}{T}\frac nV
+O\left(\frac{n^2}{V^2}\right)
}
\tag{8}
```

である．

よって，

```math
\begin{aligned}
\frac1{C_p}
&=
\frac1{C_{p0}}
\left[
1+\frac{2a}{TC_{p0}}\frac nV
+O\left(\frac{n^2}{V^2}\right)
\right]^{-1}\\
&=
\frac1{C_{p0}}
\left[
1-\frac{2a}{TC_{p0}}\frac nV
+O\left(\frac{n^2}{V^2}\right)
\right].
\end{aligned}
```

したがって，

```math
\boxed{
\frac1{C_p}
=
\frac1{C_{p0}}
\left[
1-\frac{2a}{TC_{p0}}\frac nV
+O\left(\frac{n^2}{V^2}\right)
\right]
}
\tag{9}
```

となる．

### 5．二次の微小項までの Joule–Thomson 係数

式 (6)，(9) を式 (2) に代入する．

```math
\begin{aligned}
\mu_{\mathrm{JT}}
&=
\frac1{C_{p0}}
\left[
1-\frac{2a}{TC_{p0}}\frac nV
+O\left(\frac{n^2}{V^2}\right)
\right]\\
&\quad\times
\left\{
\left(\frac{2a}{RT}-b\right)\right.\\
&\qquad\left.
-
\left[
2b^2+
\left(\frac{2a}{RT}-b\right)
\left(2b-\frac{2a}{RT}\right)
\right]\frac nV
+O\left(\frac{n^2}{V^2}\right)
\right\}.
\end{aligned}
```

二次の微小項まで保持し，二次の補正同士の積を三次以上として省略すると，

```math
\boxed{
\begin{aligned}
\mu_{\mathrm{JT}}
&=
\frac1{C_{p0}}
\left\{
\left(\frac{2a}{RT}-b\right)\right.\\
&\quad-
\left[
2b^2
+\left(\frac{2a}{RT}-b\right)
\left(2b-\frac{2a}{RT}\right)\right.\\
&\qquad\left.\left.
+\frac{2a}{TC_{p0}}
\left(\frac{2a}{RT}-b\right)
\right]\frac nV
\right\}\\
&\quad+O\left(\frac{n^2}{V^2}\right).
\end{aligned}
}
\tag{10}
```

ここで，

```math
C_{p0}=C_V+R
```

である．

式 (10) が， $nb/V$ および $na/(VRT)$ に関する二次の微小項まで考慮した Joule–Thomson 係数である．

なお，最低次の希薄気体近似だけを残せば，

```math
\boxed{
\mu_{\mathrm{JT}}
\simeq
\frac1{C_{p0}}
\left(\frac{2a}{RT}-b\right)
}
\tag{11}
```

となる．
これは二次の密度補正を無視した場合の式であり，式 (10) の最低次の項に相当する．

### 6．逆転温度と臨界温度

Joule–Thomson 効果が消失する逆転温度 $T_i$ は，

```math
\mu_{\mathrm{JT}}=0
```

となる温度である．

まず，ゼロ圧力極限，すなわち $n/V\to0$ では，式 (10) の密度補正が消える．
したがって，

```math
\frac{2a}{RT_i^{(0)}}-b=0
```

である．
ここで $T_i^{(0)}$ はゼロ圧力極限の逆転温度を表す．

よって，

```math
\boxed{
T_i^{(0)}=\frac{2a}{Rb}
}
\tag{12}
```

となる．

van der Waals 気体の臨界温度

```math
T_c=\frac{8a}{27Rb}
```

を用いれば，

```math
\frac{T_i^{(0)}}{T_c}
=
\frac{2a/(Rb)}{8a/(27Rb)}
=
\frac{27}{4}.
```

したがって，

```math
\boxed{
T_i^{(0)}=\frac{27}{4}T_c
}
\tag{13}
```

を得る．

#### 有限圧力での逆転温度の補正

式 (10) の有限密度補正も考慮する．

```math
q=\frac nV,\qquad
K=\frac{2a}{RT}-b
```

と置くと，逆転条件は，

```math
K-q\left[
2b^2+K\left(2b-\frac{2a}{RT}\right)
+\frac{2a}{TC_{p0}}K
\right]
+O(q^2)=0
```

である．

ゼロ密度での逆転温度では $K=0$ となるため，有限密度での補正を求める際には，括弧内の $K$ を含む項は二次以上となる．
したがって，

```math
K-2b^2q+O(q^2)=0
```

である．
よって，

```math
\frac{2a}{RT_i}-b
=
2b^2q+O(q^2).
```

これを $T_i$ について解くと，

```math
\begin{aligned}
T_i
&=
\frac{2a}{Rb(1+2bq)}
+O(q^2)\\
&=
\frac{2a}{Rb}
\left(1-2bq\right)
+O(q^2).
\end{aligned}
```

したがって，

```math
\boxed{
T_i
=
T_i^{(0)}
\left(1-2b\frac nV\right)
+O\left(\frac{n^2}{V^2}\right)
}
\tag{14}
```

となる．

逆転状態では最低次の近似から，

```math
p\simeq R T_i^{(0)}q
```

であるため，

```math
q=\frac{p}{RT_i^{(0)}}+O(p^2)
```

と書ける．
これを式 (14) に代入すると，

```math
\boxed{
T_i(p)
=
\frac{2a}{Rb}-\frac{2bp}{R}+O(p^2)
}
\tag{15}
```

を得る．

臨界温度で表せば，

```math
\boxed{
T_i(p)
=
\frac{27}{4}T_c-\frac{2bp}{R}+O(p^2)
}
\tag{16}
```

となる．

したがって，問題で通常求める希薄気体・ゼロ圧力極限の逆転温度は，

```math
\boxed{T_i^{(0)}=\frac{27}{4}T_c}
```

である．
有限圧力では，二次の微小量まで考慮すると逆転温度に圧力依存性が現れる．

### 7．Joule–Thomson 効果の符号と物理的解釈

式 (11) の最低次の近似では，

```math
\mu_{\mathrm{JT}}
=
\frac1{C_{p0}}
\left(\frac{2a}{RT}-b\right).
```

通常，

```math
a>0,\qquad b>0,\qquad C_{p0}>0
```

であるから，

```math
T<T_i^{(0)}
```

では

```math
\mu_{\mathrm{JT}}>0
```

となる．
このとき圧力低下 $dp<0$ に対して，

```math
dT=\mu_{\mathrm{JT}}\,dp<0
```

であるため，温度は低下する．

一方，

```math
T>T_i^{(0)}
```

では

```math
\mu_{\mathrm{JT}}<0
```

となり，圧力低下に伴って温度は上昇する．

したがって，逆転温度を境に Joule–Thomson 効果の符号が反転する．

また， $a=0$ とすると，

```math
\mu_{\mathrm{JT}}\simeq-\frac{b}{C_{p0}}
```

となる．
これは排除体積だけを持つ van der Waals 型気体では，圧力低下に伴って温度が上昇することを示している．
反対に， $b=0$ ならば，

```math
\mu_{\mathrm{JT}}\simeq\frac{2a}{RTC_{p0}}>0
```

となり，引力による冷却効果が現れる．
これらの極限も物理的に整合している．

### 8．結論

希薄 van der Waals 気体の Joule–Thomson 係数を， $nb/V$ および $na/(VRT)$ に関する二次の微小項まで考慮すると，

```math
\boxed{
\begin{aligned}
\mu_{\mathrm{JT}}
&=
\frac1{C_{p0}}
\left\{
\left(\frac{2a}{RT}-b\right)\right.\\
&\quad-
\left[
2b^2
+\left(\frac{2a}{RT}-b\right)
\left(2b-\frac{2a}{RT}\right)\right.\\
&\qquad\left.\left.
+\frac{2a}{TC_{p0}}
\left(\frac{2a}{RT}-b\right)
\right]\frac nV
\right\}\\
&\quad+O\left(\frac{n^2}{V^2}\right),
\end{aligned}
}
```

ただし，

```math
C_{p0}=C_V+R
```

である．

ゼロ圧力極限における逆転温度は，

```math
\boxed{
T_i^{(0)}=\frac{2a}{Rb}=\frac{27}{4}T_c
}
```

である．
有限圧力での一次補正まで含めると，

```math
\boxed{
T_i(p)=\frac{27}{4}T_c-\frac{2bp}{R}+O(p^2)
}
```

となる．

以上より，最低次の希薄気体近似では逆転温度は臨界温度の $27/4$ 倍であり，二次の微小量まで考慮すると有限圧力による補正が現れる．
