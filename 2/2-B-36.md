# 演習問題【2-B-36】

## 解答

### 1．Joule–Thomson 係数の一般式

Joule–Thomson 係数は，エンタルピー $H$ を一定に保ったときの温度 $T$ の圧力 $p$ に対する変化率であり，

```math
\mu_{\mathrm{JT}}
=\left(\frac{\partial T}{\partial p}\right)_H
```

と定義される．
熱力学の関係式から，この係数は

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_H
=\frac{T\left(\frac{\partial V}{\partial T}\right)_p-V}
{C_{p,\mathrm{tot}}}
}
\tag{1}
```

と表される．
ここで， $V$ は全体積， $C_{p,\mathrm{tot}}$ は全体の定圧熱容量である．

以下では，物質量 $n$ mol の気体を考え，まず全体積 $V$ を用いて計算する．
最終的には，モル定圧熱容量 $C_p=C_{p,\mathrm{tot}}/n$ を用いた式に直す．

### 2．希薄 van der Waals 気体の状態方程式

物質量 $n$ mol の van der Waals 気体の状態方程式は，

```math
\left(p+\frac{an^2}{V^2}\right)(V-nb)=nRT
```

である．
これを圧力 $p$ について解くと，

```math
p=\frac{nRT}{V-nb}-\frac{an^2}{V^2}
\tag{2}
```

となる．

問題では， $\frac{nb}{V}$ および $\frac{na}{VRT}$ が小さい希薄気体を考え，これらの量について二次の項まで考慮する．
まず，

```math
\frac{1}{V-nb}
=\frac{1}{V}\frac{1}{1-\frac{nb}{V}}
```

である．
微小量 $x$ に対して

```math
\frac{1}{1-x}\simeq1+x
```

という近似を用いると，

```math
\frac{nRT}{V-nb}
\simeq\frac{nRT}{V}
+\frac{n^2RTb}{V^2}
```

となる．
これを式 (2) に代入すると，

```math
\boxed{
p\simeq\frac{nRT}{V}
+\frac{n^2(RTb-a)}{V^2}
}
\tag{3}
```

を得る．
ここでは $1/V^2$ の次数まで残し，それより高次の項を無視している．
特に，引力を表す $-an^2/V^2$ はこの次数に含まれるため，無視してはならない．

### 3．等圧での体積の温度微分を求める

式 (3) を，圧力 $p$ を一定に保って温度 $T$ で偏微分する．
左辺の $p$ は一定であるため，

```math
0=\frac{\partial}{\partial T}
\left[
\frac{nRT}{V}
+\frac{n^2(RTb-a)}{V^2}
\right]_p
```

である．
右辺を微分すると，

```math
0=\frac{nR}{V}
-\frac{nRT}{V^2}\left(\frac{\partial V}{\partial T}\right)_p
+\frac{n^2Rb}{V^2}
-\frac{2n^2(RTb-a)}{V^3}
\left(\frac{\partial V}{\partial T}\right)_p
```

となる．
$\left(\frac{\partial V}{\partial T}\right)_p$ を含む項を左辺に移項すると，

```math
\begin{aligned}
&\left(\frac{\partial V}{\partial T}\right)_p
\left[
\frac{nRT}{V^2}
+\frac{2n^2(RTb-a)}{V^3}
\right]\\
&\qquad=\frac{nR}{V}+\frac{n^2Rb}{V^2}
\end{aligned}
```

である．
これを整理すれば，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=\frac{V}{T}
\frac{1+\frac{nb}{V}}
{1+\frac{2n}{V}\left(b-\frac{a}{RT}\right)}
\tag{4}
```

を得る．

ここで， $\frac{nb}{V}$ および $\frac{na}{VRT}$ が小さいことを用いる．
微小量 $x$ に対して $(1+x)^{-1}\simeq1-x$ であるから，

```math
\begin{aligned}
\left(\frac{\partial V}{\partial T}\right)_p
&\simeq\frac{V}{T}
\left(1+\frac{nb}{V}\right)
\left[
1-\frac{2n}{V}\left(b-\frac{a}{RT}\right)
\right]\\
&\simeq\frac{V}{T}
\left[
1+\frac{nb}{V}
-\frac{2n}{V}\left(b-\frac{a}{RT}\right)
\right]
\end{aligned}
```

となる．
積の二次の微小項を無視して整理すると，

```math
\boxed{
\left(\frac{\partial V}{\partial T}\right)_p
\simeq\frac{V}{T}
\left[
1+\frac{n}{V}
\left(\frac{2a}{RT}-b\right)
\right]
}
\tag{5}
```

である．

### 4．Joule–Thomson 係数を求める

式 (5) を Joule–Thomson 係数の一般式 (1) に代入する．

```math
\begin{aligned}
T\left(\frac{\partial V}{\partial T}\right)_p-V
&\simeq
V\left[
1+\frac{n}{V}
\left(\frac{2a}{RT}-b\right)
\right]-V\\
&=n\left(\frac{2a}{RT}-b\right)
\end{aligned}
```

となる．
したがって，

```math
\left(\frac{\partial T}{\partial p}\right)_H
\simeq\frac{n}{C_{p,\mathrm{tot}}}
\left(\frac{2a}{RT}-b\right)
```

を得る．
全体の定圧熱容量とモル定圧熱容量の関係

```math
C_{p,\mathrm{tot}}=nC_p
```

を用いれば，求める Joule–Thomson 係数は

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_H
\simeq\frac{1}{C_p}
\left(\frac{2a}{RT}-b\right)
}
\tag{6}
```

である．
ここで $C_p$ はモル定圧熱容量である．

### 5．逆転温度 $T_i$ と臨界温度 $T_c$

Joule–Thomson 効果が消失する温度を逆転温度 $T_i$ と呼ぶ．
すなわち，

```math
\left(\frac{\partial T}{\partial p}\right)_H=0
```

となる温度である．
式 (6) より，定圧モル熱容量が有限であるとすると，

```math
\frac{2a}{RT_i}-b=0
```

となる．
したがって，

```math
\boxed{
T_i=\frac{2a}{Rb}
}
\tag{7}
```

を得る．

一方，van der Waals 気体の臨界温度は，

```math
T_c=\frac{8a}{27Rb}
```

で与えられる．
したがって，両者の比は，

```math
\frac{T_i}{T_c}
=\frac{2a/(Rb)}{8a/(27Rb)}
=\frac{27}{4}
```

である．
よって，

```math
\boxed{
T_i=\frac{27}{4}T_c
}
\tag{8}
```

となる．

### 6．結果の意味

式 (6) において $C_p>0$ ならば， $T<T_i$ では Joule–Thomson 係数は正となり，圧力低下に伴って温度が低下する．
一方， $T>T_i$ では係数が負となり，圧力低下に伴って温度が上昇する．
これが Joule–Thomson 効果の逆転である．

なお，得られた $T_i$ は，希薄気体近似で $1/V^2$ の項まで残した状態方程式に基づく逆転温度である．
有限圧力での実在気体の逆転温度は，より高次の補正を考慮すると圧力にも依存し得る．
