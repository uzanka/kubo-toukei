# 演習問題【2-C-46】

## 解答

### 定圧気体温度計による絶対温度の較正

#### 1．温度と密度を結ぶ基本式

前問で得られた Joule–Thomson 係数 $\mu$ の関係式は，

```math
\mu c_p=T\left(\frac{\partial v}{\partial T}\right)_p-v
\tag{1}
```

である．
ここで， $T$ は絶対温度， $v$ は単位質量当たりの体積， $c_p$ は定圧比熱である．
密度を $\rho$ とすれば $v=1/\rho$ である．

式 (1) を整理すると，

```math
T\left(\frac{\partial v}{\partial T}\right)_p
=v+\mu c_p
```

となる．
したがって，

```math
\frac{dT}{T}=\frac{dv}{v+\mu c_p}
```

である．
ここで，分母の $v$ をくくり出すと，

```math
\frac{dT}{T}
=\frac{dv}{v}\frac{1}{1+\mu c_p/v}
```

となる．
$v=1/\rho$ より，

```math
\frac{\mu c_p}{v}=\rho\mu c_p
```

であるため，単位が整合するように換算すれば，

```math
\boxed{
\frac{dT}{T}
=-\frac{d\rho}{\rho}\frac{1}{1+q(\theta)}
}
\tag{2}
```

を得る．
ここで，

```math
q(\theta)=\rho(\theta)\mu(\theta)c_p K
\tag{3}
```

と定義した．
$K$ は，問題で与えられた単位を用いて計算するための換算係数であり，

```math
K=\frac{4.19\times10^7}{0.98\times10^6}
\simeq42.755
```

である．
これは， $1\,\mathrm{cal}=4.19\times10^7\,\mathrm{erg}$ ， $1\,\mathrm{kgf/cm^2}\simeq0.98\times10^6\,\mathrm{dyn/cm^2}$ に基づく換算である．
以下では，表に与えられた $\mu$ と $c_p=0.240\,\mathrm{cal/(g\,deg)}$ をこの係数で換算する．

#### 2．密度の式を用いた積分

問題で与えられた密度の近似式は，

```math
\rho=\frac{0.0012932}{1+0.003669\theta}
\frac{p}{760}
```

である．
ここで，圧力 $p$ の単位は $\mathrm{mmHg}$ ，温度 $\theta$ の単位は ${}^\circ\mathrm{C}$ である．
また，

```math
a=0.003669
```

とおく．
$1\,\mathrm{kgf/cm^2}\simeq0.98\times10^6\,\mathrm{dyn/cm^2}$ であり， $1\,\mathrm{mmHg}\simeq1333.22\,\mathrm{dyn/cm^2}$ であるから，この圧力は約 $735\,\mathrm{mmHg}$ に相当する．
したがって，密度計算では $p\simeq735\,\mathrm{mmHg}$ とする．

圧力は一定なので，

```math
\log\rho
=\text{定数}-\log(1+a\theta)
```

である．
よって，

```math
\frac{d\log\rho}{d\theta}
=-\frac{a}{1+a\theta}
```

となる．
これを式 (2) に代入すると，

```math
\frac{dT}{T}
=\frac{a}{(1+a\theta)(1+q(\theta))}\,d\theta
```

を得る．
両辺を $\theta=0$ から $\theta=100$ まで積分する．

```math
\int_{T_0}^{T_{100}}\frac{dT}{T}
=\int_0^{100}
\frac{a}{(1+a\theta)(1+q(\theta))}\,d\theta
```

ここで， $T_0$ は $0^\circ\mathrm{C}$ に対応する絶対温度， $T_{100}$ は $100^\circ\mathrm{C}$ に対応する絶対温度である．
摂氏温度の温度差と絶対温度の温度差は等しいので，

```math
T_{100}=T_0+100
```

である．
したがって，

```math
\boxed{
\log\left(1+\frac{100}{T_0}\right)
=\int_0^{100}
\frac{a}{(1+a\theta)(1+q(\theta))}\,d\theta
}
\tag{4}
```

となる．

#### 3．解答例に従った近似展開

式 (3) の $q(\theta)$ は，数値的に $10^{-3}$ 程度の小さい量である．
したがって，

```math
\frac{1}{1+q}\simeq1-q
```

という近似が成り立つ．
ここで，

```math
f(\theta)=\frac{1}{1+q(\theta)}-1
\tag{5}
```

と定義すると，

```math
\frac{1}{1+q(\theta)}=1+f(\theta)
```

である．
式 (4) は，

```math
\begin{aligned}
\log\left(1+\frac{100}{T_0}\right)
&=\int_0^{100}\frac{a}{1+a\theta}\,d\theta\\
&\quad+a\int_0^{100}
\frac{f(\theta)}{1+a\theta}\,d\theta
\end{aligned}
```

となる．
第1項を積分すれば，

```math
\boxed{
\log\left(1+\frac{100}{T_0}\right)
=\log(1+100a)
+a\int_0^{100}g(\theta)\,d\theta
}
\tag{6}
```

を得る．
ただし，

```math
g(\theta)=\frac{f(\theta)}{1+a\theta}
\tag{7}
```

である．

次に， $T_0$ が $1/a$ に近いことに着目して，

```math
T_0=\frac1a+x
\tag{8}
```

とおく．
式 (6) に代入して整理すると，

```math
\log\left[
\frac{1+\dfrac{ax}{1+100a}}{1+ax}
\right]
=a\int_0^{100}g(\theta)\,d\theta
```

となる．
$ax$ は小さいため，対数を一次まで展開する．
すなわち， $\log(1+y)\simeq y$ を用いると，

```math
ax\left(\frac{1}{1+100a}-1\right)
=a\int_0^{100}g(\theta)\,d\theta
```

である．
両辺を $a$ で割れば，

```math
\boxed{
x\left(\frac{1}{1+100a}-1\right)
=\int_0^{100}g(\theta)\,d\theta
}
\tag{9}
```

を得る．

#### 4．測定値を用いた数値計算

まず，密度の近似式に $p\simeq735\,\mathrm{mmHg}$ を代入する．
次に，式 (3)，(5)，(7) に従って各温度で $q$ ， $f$ ， $g$ を計算する．
その結果を以下に示す．

| $\theta$ （ ${}^\circ\mathrm{C}$ ） | $\rho$ （ $\mathrm{g/cm^3}$ ） | $q=\rho\mu c_pK$ | $f$ | $g$ |
|---:|---:|---:|---:|---:|
| 0 | 0.001251 | 0.003298 | −0.003288 | −0.003288 |
| 25 | 0.001146 | 0.002586 | −0.002580 | −0.002363 |
| 50 | 0.001057 | 0.001985 | −0.001981 | −0.001674 |
| 75 | 0.000981 | 0.001540 | −0.001538 | −0.001206 |
| 100 | 0.000915 | 0.001211 | −0.001210 | −0.000885 |

ここで， $f=(1+q)^{-1}-1$ である．
$q\ll1$ なので， $f\simeq-q$ としてもほぼ同じ値になる．

次に，刻み幅 $h=25$ の Simpson 公式を使って積分を近似する．
積分区間は4等分されているので，

```math
\begin{aligned}
I&=\int_0^{100}g(\theta)\,d\theta\\
&\simeq\frac{25}{3}\big[
g(0)+4g(25)+2g(50)\\
&\qquad\qquad+4g(75)+g(100)\big]
\end{aligned}
```

となる．
表の値を代入すると，

```math
I\simeq-0.1816
```

を得る．
なお，解答例に記載された積分値 $-0.00183$ は小数点の位置の誤りと考えられ，表の値を積分すれば約 $-0.18$ となる．

式 (9) より，

```math
x\left(\frac{1}{1+100a}-1\right)=I
```

である．
$a=0.003669$ を代入すれば，

```math
\frac{1}{1+100a}-1
=\frac{1}{1.3669}-1
\simeq-0.26842
```

となる．
したがって，

```math
x=\frac{-0.1816}{-0.26842}
\simeq0.677
```

である．

式 (8) に戻ると，

```math
T_0=\frac{1}{0.003669}+0.677
```

であり，

```math
\frac{1}{0.003669}\simeq272.554
```

だから，

```math
T_0\simeq272.554+0.677
=273.231\,\mathrm{K}
```

となる．

#### 5．結論

以上より， $0^\circ\mathrm{C}$ に対応する絶対温度は，

```math
\boxed{
T_0\simeq273.2\,\mathrm{K}
}
```

である．
これは解答例と同じ近似法による結果であり，単位換算と数値積分を整合させて計算した値である．
