# 演習問題【2-A-17】

## 解答

### (i) 比熱の差と熱膨張係数・等温圧縮率の関係

証明すべき式は，

```math
c_p-c_v
=T\left(\frac{\partial v}{\partial T}\right)_p
\left(\frac{\partial p}{\partial T}\right)_v
=\frac{\alpha^2vT}{\beta}
```

である．
ここで， $c_p$ は定圧比熱， $c_v$ は定積比熱であり，

```math
\alpha=\frac{1}{v}\left(\frac{\partial v}{\partial T}\right)_p,
\qquad
\beta=-\frac{1}{v}\left(\frac{\partial v}{\partial p}\right)_T
```

と定義される．
$\alpha$ は熱膨張係数， $\beta$ は等温圧縮率である．

#### 1．比熱をエントロピーで表す

単位質量当たりのエントロピーを $s$ とすると，比熱は，

```math
c_p=T\left(\frac{\partial s}{\partial T}\right)_p,
\qquad
c_v=T\left(\frac{\partial s}{\partial T}\right)_v
\tag{1}
```

と表される．
したがって，両者の差は，

```math
c_p-c_v
=T\left\{
\left(\frac{\partial s}{\partial T}\right)_p
-\left(\frac{\partial s}{\partial T}\right)_v
\right\}
\tag{2}
```

である．

#### 2．連鎖律と Maxwell の関係式を用いる

エントロピー $s$ を温度 $T$ と比容 $v$ の関数 $s(T,v)$ と考える．
圧力 $p$ を一定に保って温度を変える場合，比容 $v$ も温度に応じて変化する．
したがって，連鎖律より，

```math
\left(\frac{\partial s}{\partial T}\right)_p
=
\left(\frac{\partial s}{\partial T}\right)_v
+
\left(\frac{\partial s}{\partial v}\right)_T
\left(\frac{\partial v}{\partial T}\right)_p
\tag{3}
```

が成立する．

式 (3) を式 (2) に代入すると，

```math
c_p-c_v
=T\left(\frac{\partial s}{\partial v}\right)_T
\left(\frac{\partial v}{\partial T}\right)_p
\tag{4}
```

となる．

ここで，Maxwell の関係式

```math
\left(\frac{\partial s}{\partial v}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_v
\tag{5}
```

を用いると，

```math
\boxed{
c_p-c_v
=T\left(\frac{\partial v}{\partial T}\right)_p
\left(\frac{\partial p}{\partial T}\right)_v
}
\tag{6}
```

を得る．

#### 3．熱膨張係数と等温圧縮率で表す

次に，式 (6) の $(\partial p/\partial T)_v$ を $\alpha$ と $\beta$ で表す．

比容 $v$ を温度 $T$ と圧力 $p$ の関数 $v(T,p)$ と考えると，その全微分は，

```math
dv=
\left(\frac{\partial v}{\partial T}\right)_p dT
+
\left(\frac{\partial v}{\partial p}\right)_T dp
\tag{7}
```

である．
体積一定，すなわち $dv=0$ の条件では，

```math
0=
\left(\frac{\partial v}{\partial T}\right)_p dT
+
\left(\frac{\partial v}{\partial p}\right)_T dp
```

となる．
これを $dp/dT$ について整理すると，

```math
\left(\frac{\partial p}{\partial T}\right)_v
=
-\frac{
\left(\dfrac{\partial v}{\partial T}\right)_p
}{
\left(\dfrac{\partial v}{\partial p}\right)_T
}
\tag{8}
```

を得る．

一方， $\alpha$ と $\beta$ の定義より，

```math
\left(\frac{\partial v}{\partial T}\right)_p=\alpha v,
\qquad
\left(\frac{\partial v}{\partial p}\right)_T=-\beta v
\tag{9}
```

である．
式 (9) を式 (8) に代入すると，

```math
\begin{aligned}
\left(\frac{\partial p}{\partial T}\right)_v
&=-\frac{\alpha v}{-\beta v}\\
&=\frac{\alpha}{\beta}
\end{aligned}
\tag{10}
```

となる．

さらに，式 (9)，(10) を式 (6) に代入すると，

```math
\begin{aligned}
c_p-c_v
&=T(\alpha v)\frac{\alpha}{\beta}\\
&=\frac{\alpha^2vT}{\beta}
\end{aligned}
```

を得る．
ゆえに，

```math
\boxed{
c_p-c_v
=T\left(\frac{\partial v}{\partial T}\right)_p
\left(\frac{\partial p}{\partial T}\right)_v
=\frac{\alpha^2vT}{\beta}
}
```

が証明された．

### (ii) 比熱の圧力・比容依存性

#### 1．$\displaystyle \left(\frac{\partial c_p}{\partial p}\right)_T$ の証明

式 (1) より，

```math
c_p=T\left(\frac{\partial s}{\partial T}\right)_p
```

である．
温度 $T$ を一定に保って圧力 $p$ で偏微分すると，

```math
\left(\frac{\partial c_p}{\partial p}\right)_T
=
T\frac{\partial^2s}{\partial p\,\partial T}
\tag{11}
```

となる．

エントロピー $s$ が十分滑らかな状態関数であれば，混合偏微分の順序を交換できる．
したがって，

```math
\frac{\partial^2s}{\partial p\,\partial T}
=
\left(\frac{\partial}{\partial T}\right)_p
\left(\frac{\partial s}{\partial p}\right)_T
\tag{12}
```

である．

ここで，Maxwell の関係式

```math
\left(\frac{\partial s}{\partial p}\right)_T
=
-\left(\frac{\partial v}{\partial T}\right)_p
\tag{13}
```

を用いると，式 (12) は，

```math
\begin{aligned}
\frac{\partial^2s}{\partial p\,\partial T}
&=
-\left(\frac{\partial}{\partial T}\right)_p
\left(\frac{\partial v}{\partial T}\right)_p\\
&=
-\left(\frac{\partial^2v}{\partial T^2}\right)_p
\end{aligned}
```

となる．
これを式 (11) に代入すれば，

```math
\boxed{
\left(\frac{\partial c_p}{\partial p}\right)_T
=
-T\left(\frac{\partial^2v}{\partial T^2}\right)_p
}
```

を得る．

#### 2．$\displaystyle \left(\frac{\partial c_v}{\partial v}\right)_T$ の証明

同様に，式 (1) より，

```math
c_v=T\left(\frac{\partial s}{\partial T}\right)_v
```

である．
温度 $T$ を一定に保って比容 $v$ で偏微分すると，

```math
\left(\frac{\partial c_v}{\partial v}\right)_T
=
T\frac{\partial^2s}{\partial v\,\partial T}
\tag{14}
```

となる．

混合偏微分の順序を交換すると，

```math
\frac{\partial^2s}{\partial v\,\partial T}
=
\left(\frac{\partial}{\partial T}\right)_v
\left(\frac{\partial s}{\partial v}\right)_T
\tag{15}
```

である．

Maxwell の関係式

```math
\left(\frac{\partial s}{\partial v}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_v
\tag{16}
```

を用いると，

```math
\begin{aligned}
\frac{\partial^2s}{\partial v\,\partial T}
&=
\left(\frac{\partial}{\partial T}\right)_v
\left(\frac{\partial p}{\partial T}\right)_v\\
&=
\left(\frac{\partial^2p}{\partial T^2}\right)_v
\end{aligned}
```

となる．
これを式 (14) に代入すれば，

```math
\boxed{
\left(\frac{\partial c_v}{\partial v}\right)_T
=
T\left(\frac{\partial^2p}{\partial T^2}\right)_v
}
```

を得る．

以上より，(ii) の2つの関係式も証明された．
