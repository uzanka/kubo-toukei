# 演習問題【2-A-17】

## 解答

### (i) の証明

まず，定圧熱容量 $c_p$ と定積熱容量 $c_v$ は，エントロピー $s$ を用いて次のように表される．

$$c_p = T \left( \frac{\partial s}{\partial T} \right)_p, \quad c_v = T \left( \frac{\partial s}{\partial T} \right)_v$$

したがって，その差は以下のようになる．

$$c_p - c_v = T \left\{ \left( \frac{\partial s}{\partial T} \right)_p - \left( \frac{\partial s}{\partial T} \right)_v \right\} \quad \cdots (1)$$

ここで，エントロピー $s$ を温度 $T$ と体積 $v$ の関数 $s(T, v)$ と考える．
圧力を一定に保ったまま温度を変化させる $(\partial s / \partial T)_p$ について，連鎖律（チェインルール）を用いると，

$$\left( \frac{\partial s}{\partial T} \right)_p = \left( \frac{\partial s}{\partial T} \right)_v + \left( \frac{\partial s}{\partial v} \right)_T \left( \frac{\partial v}{\partial T} \right)_p \quad \cdots (2)$$

と書ける．
これを式 (1) に代入すると，

$$c_p - c_v = T \left( \frac{\partial s}{\partial v} \right)_T \left( \frac{\partial v}{\partial T} \right)_p$$

が得られる．
ここで，マクスウェルの関係式 $\left( \frac{\partial s}{\partial v} \right)_T = \left( \frac{\partial p}{\partial T} \right)_v$ を用いると，

$$c_p - c_v = T \left( \frac{\partial v}{\partial T} \right)_p \left( \frac{\partial p}{\partial T} \right)_v \quad \cdots (3)$$

となる．
これが前半部分の証明である．

次に，後半の $\frac{\alpha^2 v T}{\beta}$ を導く．
偏微分の循環則（あるいは，状態量 $p, v, T$ の間にある関係式）より，以下の関係が成り立つ．

$$\left( \frac{\partial p}{\partial T} \right)_v \left( \frac{\partial T}{\partial v} \right)_p \left( \frac{\partial v}{\partial p} \right)_T = -1$$

これを変形すると，

$$\left( \frac{\partial p}{\partial T} \right)_v = - \frac{1}{\left( \frac{\partial T}{\partial v} \right)_p \left( \frac{\partial v}{\partial p} \right)_T} = - \frac{\left( \frac{\partial v}{\partial T} \right)_p}{\left( \frac{\partial v}{\partial p} \right)_T} \quad \cdots (4)$$

となる．
問題文で与えられた $\alpha, \beta$ の定義式を整理すると，

$$\left( \frac{\partial v}{\partial T} \right)_p = \alpha v, \quad \left( \frac{\partial v}{\partial p} \right)_T = -\beta v$$

である．
これらを式 (4) に代入すると，

$$\left( \frac{\partial p}{\partial T} \right)_v = - \frac{\alpha v}{-\beta v} = \frac{\alpha}{\beta}$$

が得られる．
これを式 (3) に代入すると，

$$c_p - c_v = T (\alpha v) \left( \frac{\alpha}{\beta} \right) = \frac{\alpha^2 v T}{\beta}$$

となり，題意は示された．

### (ii) の証明

#### $\left( \frac{\partial c_p}{\partial p} \right)_T$ について

$c_p = T \left( \frac{\partial s}{\partial T} \right)_p$ であるから，これを温度 $T$ 一定の条件で圧力 $p$ で微分すると，

$$\left( \frac{\partial c_p}{\partial p} \right)_T = \frac{\partial}{\partial p} \left[ T \left( \frac{\partial s}{\partial T} \right)_p \right]_T = T \frac{\partial^2 s}{\partial p \partial T}$$

となる．
ここで，偏微分の順序を入れ替えると，

$$\frac{\partial^2 s}{\partial p \partial T} = \frac{\partial}{\partial T} \left( \frac{\partial s}{\partial p} \right)_T$$

である．
マクスウェルの関係式 $\left( \frac{\partial s}{\partial p} \right)_T = - \left( \frac{\partial v}{\partial T} \right)_p$ を用いると，

$$\frac{\partial^2 s}{\partial p \partial T} = \frac{\partial}{\partial T} \left[ - \left( \frac{\partial v}{\partial T} \right)_p \right] = - \left( \frac{\partial^2 v}{\partial T^2} \right)_p$$

となる．
したがって，

$$\left( \frac{\partial c_p}{\partial p} \right)_T = - T \left( \frac{\partial^2 v}{\partial T^2} \right)_p$$

が得られる．

#### $\left( \frac{\partial c_v}{\partial v} \right)_T$ について

同様に， $c_v = T \left( \frac{\partial s}{\partial T} \right)_v$ であるから，

$$\left( \frac{\partial c_v}{\partial v} \right)_T = \frac{\partial}{\partial v} \left[ T \left( \frac{\partial s}{\partial T} \right)_v \right]_T = T \frac{\partial^2 s}{\partial v \partial T}$$

となる．
偏微分の順序を入れ替えると，

$$\frac{\partial^2 s}{\partial v \partial T} = \frac{\partial}{\partial T} \left( \frac{\partial s}{\partial v} \right)_T$$

である．
マクスウェルの関係式 $\left( \frac{\partial s}{\partial v} \right)_T = \left( \frac{\partial p}{\partial T} \right)_v$ を用いると，

$$\frac{\partial^2 s}{\partial v \partial T} = \frac{\partial}{\partial T} \left[ \left( \frac{\partial p}{\partial T} \right)_v \right] = \left( \frac{\partial^2 p}{\partial T^2} \right)_v$$

となる．
したがって，

$$\left( \frac{\partial c_v}{\partial v} \right)_T = T \left( \frac{\partial^2 p}{\partial T^2} \right)_v$$

が得られる．

## 解説

### 1. 熱容量 $c_p, c_v$ とエントロピーの関係

熱力学において，熱容量は物質に与えた熱量 $dQ$ と温度変化 $dT$ の比として定義される．
エントロピー $s$ の定義式 $ds = \frac{dQ}{T}$ を用いると，
- 定積熱容量 $c_v$ : 体積が一定（ $dv=0$ ）のとき， $dQ = T ds$ なので， $c_v = \left( \frac{dQ}{dT} \right)_v = T \left( \frac{\partial s}{\partial T} \right)_v$ ．
- 定圧熱容量 $c_p$ : 圧力が一定（ $dp=0$ ）のとき， $c_p = \left( \frac{dQ}{dT} \right)_p = T \left( \frac{\partial s}{\partial T} \right)_p$ ．

### 2. マクスウェルの関係式

マクスウェルの関係式は，熱力学ポテンシャル（内部エネルギー，エンタルピー，ヘルムホルツ自由エネルギー，ギブス自由エネルギー）が状態量であり，その全微分が完全微分であることを利用して導かれる，偏微分の関係式である．
例えば，ギブス自由エネルギー $g(T, p)$ の全微分 $dg = -s dT - v dp$ から，

$$\left( \frac{\partial s}{\partial p} \right)_T = \left( \frac{\partial v}{\partial T} \right)_p$$

（符号の定義によるが，本問の文脈では $\left( \frac{\partial s}{\partial p} \right)_T = - \left( \frac{\partial v}{\partial T} \right)_p$ としている．
これはエントロピーの定義や使用するポテンシャルの符号の取り方による．
本解答では問題の導出に合わせる形で記述している．）

### 3. 偏微分の循環則

複数の変数 $x, y, z$ があるとき，ある変数での微分を別の変数での微分に変換するルールがある．
例えば $p, v, T$ の関係では，

$$\left( \frac{\partial p}{\partial T} \right)_v \left( \frac{\partial T}{\partial v} \right)_p \left( \frac{\partial v}{\partial p} \right)_T = -1$$

これは，状態量 $p(v, T)$ が一価関数であることを保証する数学的性質から導かれる．
これを用いることで，複雑な偏微分の項を，与えられた $\alpha, \beta$ の形に落とし込むことができる．
