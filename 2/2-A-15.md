# 演習問題【2-A-15】

## 解答

### (i) の証明

熱力学第一法則より，内部エネルギー $U$ の微小変化 $dU$ は次のように表される．

$$dU = T dS - p dV \quad \dots (1)$$

ここで， $T$ は温度， $S$ はエントロピー， $p$ は圧力， $V$ は体積である．

エントロピー $S$ が状態量であり， $T$ と $V$ の関数 $S(T, V)$ であると考えると，その微小変化 $dS$ は全微分として以下のように書ける．

$$dS = \left(\frac{\partial S}{\partial T}\right)_V dT + \left(\frac{\partial S}{\partial V}\right)_T dV$$

これを式 (1) に代入すると，

$$dU = T \left[ \left(\frac{\partial S}{\partial T}\right)_V dT + \left(\frac{\partial S}{\partial V}\right)_T dV \right] - p dV$$

$$dU = T \left(\frac{\partial S}{\partial T}\right)_V dT + \left\{ T \left(\frac{\partial S}{\partial V}\right)_T - p \right\} dV \quad \dots (2)$$

$U$ は状態量であるため， $dU$ は完全微分である．
したがって， $dU = M dT + N dV$ とおいたとき，完全微分の条件 $\left(\frac{\partial M}{\partial V}\right)_T = \left(\frac{\partial N}{\partial T}\right)_V$ が成り立つ．
式 (2) において， $M = T \left(\frac{\partial S}{\partial T}\right)_V$ ， $N = T \left(\frac{\partial S}{\partial V}\right)_T - p$ とすると，

$$\frac{\partial}{\partial V} \left[ T \left(\frac{\partial S}{\partial T}\right)_V \right]_T = \frac{\partial}{\partial T} \left[ T \left(\frac{\partial S}{\partial V}\right)_T - p \right]_V$$

左辺に積の微分公式を適用すると，

$$T \frac{\partial^2 S}{\partial V \partial T} = \left(\frac{\partial S}{\partial V}\right)_T + T \frac{\partial^2 S}{\partial T \partial V} - \left(\frac{\partial p}{\partial T}\right)_V$$

偏微分の順序交換 $\frac{\partial^2 S}{\partial V \partial T} = \frac{\partial^2 S}{\partial T \partial V}$ が成り立つため，両辺の第1項と第3項が打ち消し合い，

$$0 = \left(\frac{\partial S}{\partial V}\right)_T - \left(\frac{\partial p}{\partial T}\right)_V$$

すなわち，マクスウェルの関係式の一つである

$$\left(\frac{\partial S}{\partial V}\right)_T = \left(\frac{\partial p}{\partial T}\right)_V \quad \dots (3)$$

が得られる．

式 (2) より，温度 $T$ 一定の条件での内部エネルギーの体積による微分は，

$$\left(\frac{\partial U}{\partial V}\right)_T = T \left(\frac{\partial S}{\partial V}\right)_T - p$$

これに式 (3) を代入すると，

$$\left(\frac{\partial U}{\partial V}\right)_T = T \left(\frac{\partial p}{\partial T}\right)_V - p$$

となり，題意は示された．

### (ii) の証明

エンタルピー $H$ の定義 $H = U + pV$ より，その微小変化 $dH$ は

$$dH = dU + d(pV) = dU + p dV + V dp$$

ここに $dU = T dS - p dV$ を代入すると，

$$dH = (T dS - p dV) + p dV + V dp = T dS + V dp \quad \dots (4)$$

が得られる．
これを $dS$ について解くと，

$$T dS = dH - V dp \implies dS = \frac{1}{T} dH - \frac{V}{T} dp \quad \dots (5)$$

となる．
$S$ は状態量なので， $S$ を $T$ と $p$ の関数 $S(T, p)$ と考えると，その微小変化 $dS$ は

$$dS = \left(\frac{\partial S}{\partial T}\right)_p dT + \left(\frac{\partial S}{\partial p}\right)_T dp$$

である．
これを式 (5) の右辺に展開して，

$$dS = \frac{1}{T} \left[ \left(\frac{\partial H}{\partial T}\right)_p dT + \left(\frac{\partial H}{\partial p}\right)_T dp \right] - \frac{V}{T} dp$$

$$dS = \frac{1}{T} \left(\frac{\partial H}{\partial T}\right)_p dT + \left[ \frac{1}{T} \left(\frac{\partial H}{\partial p}\right)_T - \frac{V}{T} \right] dp \quad \dots (6)$$

$dS$ は完全微分であるため，混合偏微分の順序交換 $\frac{\partial^2 S}{\partial p \partial T} = \frac{\partial^2 S}{\partial T \partial p}$ が成り立つ．
式 (6) より，

$$\frac{\partial}{\partial p} \left[ \frac{1}{T} \left(\frac{\partial H}{\partial T}\right)_p \right]_T = \frac{\partial}{\partial T} \left[ \frac{1}{T} \left(\frac{\partial H}{\partial p}\right)_T - \frac{V}{T} \right]_p$$

左辺は， $\frac{1}{T}$ は $p$ によらないため，

$$\text{LHS} = \frac{1}{T} \left(\frac{\partial^2 H}{\partial p \partial T}\right)_p$$

右辺は，積の微分法を用いると，

$$\text{RHS} = -\frac{1}{T^2} \left(\frac{\partial H}{\partial p}\right)_T + \frac{1}{T} \left(\frac{\partial^2 H}{\partial T \partial p}\right)_T - \frac{\partial}{\partial T} \left(\frac{V}{T}\right)_p$$

これらを等置し， $\frac{\partial^2 H}{\partial p \partial T} = \frac{\partial^2 H}{\partial T \partial p}$ を用いて整理すると，

$$\frac{1}{T} \left(\frac{\partial^2 H}{\partial p \partial T}\right)_p = -\frac{1}{T^2} \left(\frac{\partial H}{\partial p}\right)_T + \frac{1}{T} \left(\frac{\partial^2 H}{\partial T \partial p}\right)_p - \frac{\partial}{\partial T} \left(\frac{V}{T}\right)_p$$

両辺の第1項と第3項が相殺されて，

$$0 = -\frac{1}{T^2} \left(\frac{\partial H}{\partial p}\right)_T - \frac{\partial}{\partial T} \left(\frac{V}{T}\right)_p$$

$$\frac{1}{T^2} \left(\frac{\partial H}{\partial p}\right)_T = -\frac{\partial}{\partial T} \left(\frac{V}{T}\right)_p$$

$$\left(\frac{\partial H}{\partial p}\right)_T = -T^2 \left(\frac{\partial}{\partial T} \left(\frac{V}{T}\right)\right)_p$$

ここで，右辺の括弧内を微分すると，

$$\frac{\partial}{\partial T} \left(\frac{V}{T}\right)_p = \frac{1}{T} \left(\frac{\partial V}{\partial T}\right)_p - \frac{V}{T^2}$$

よって，

$$\left(\frac{\partial H}{\partial p}\right)_T = -T^2 \left[ \frac{1}{T} \left(\frac{\partial V}{\partial T}\right)_p - \frac{V}{T^2} \right] = -T \left(\frac{\partial V}{\partial T}\right)_p + V$$

となり，題意は示された．

## 解説

### 1. 基本的な熱力学量

この問題では，以下の熱力学的な状態量が登場する．
- 内部エネルギー $U$ : 系が保持しているエネルギーの総量．
- エンタルピー $H$ : $H = U + pV$ で定義され，定圧過程などで扱われる量．
- エントロピー $S$ : 系の乱雑さや状態の数に関連する量．
- 圧力 $p$ ，体積 $V$ ，温度 $T$ : 系を記述する基本的な変数．

### 2. 完全微分と状態量

「状態量」とは，その値が系の現在の状態（ $P, V, T$ など）だけで決まり，どのような経路を通ってきたかに依存しない量のことを言う．
状態量 $f(x, y)$ の微小変化 $df$ は，次のように書ける．

$$df = \left(\frac{\partial f}{\partial x}\right)_y dx + \left(\frac{\partial f}{\partial y}\right)_x dy$$

これを **完全微分** と呼ぶ．
完全微分の重要な性質として，微分の順序を入れ替えても結果が同じになること，すなわち

$$\frac{\partial^2 f}{\partial y \partial x} = \frac{\partial^2 f}{\partial x \partial y}$$

が挙げられる．
これを利用して，熱力学変数の間の複雑な関係式（マクスウェルの関係式）を導き出すことができる．

### 3. マクスウェルの関係式

熱力学の基本式（ $dU = T dS - p dV$ など）において，各変数が状態量であることを利用し，上記のような「混合偏微分の順序交換」を適用することで得られる関係式を **マクスウェルの関係式** と呼ぶ．
例えば，(i) の証明過程で導出した

$$\left(\frac{\partial S}{\partial V}\right)_T = \left(\frac{\partial p}{\partial T}\right)_V$$

は，直接測定が難しいエントロピーの変化を，測定可能な圧力や温度の変化として捉えることを可能にする．
