# 演習問題【2-A-15】

## 解答

### (i) $\displaystyle \left(\frac{\partial U}{\partial V}\right)_T=T\left(\frac{\partial p}{\partial T}\right)_V-p$ の証明

#### 1．内部エネルギーの全微分を求める

熱力学の基本関係式は，

```math
dU=T\,dS-p\,dV
\tag{1}
```

である．
ここで， $U$ は内部エネルギー， $S$ はエントロピー， $T$ は絶対温度， $p$ は圧力， $V$ は体積である．

エントロピー $S$ を温度 $T$ と体積 $V$ の関数とみなすと，その全微分は，

```math
dS=
\left(\frac{\partial S}{\partial T}\right)_VdT
+
\left(\frac{\partial S}{\partial V}\right)_TdV
```

である．
これを式 (1) に代入すると，

```math
\begin{aligned}
dU
={}&T\left(\frac{\partial S}{\partial T}\right)_VdT\\
&+\left\{
T\left(\frac{\partial S}{\partial V}\right)_T-p
\right\}dV
\end{aligned}
\tag{2}
```

となる．

#### 2．完全微分の条件を用いる

内部エネルギー $U$ は状態量であるため，式 (2) は完全微分である．
一般に，状態量 $U(T,V)$ の全微分が

```math
dU=M(T,V)\,dT+N(T,V)\,dV
```

と表されるとき，混合偏微分の順序交換から，

```math
\left(\frac{\partial M}{\partial V}\right)_T
=
\left(\frac{\partial N}{\partial T}\right)_V
\tag{3}
```

が成立する．

式 (2) と比較すると，

```math
M=T\left(\frac{\partial S}{\partial T}\right)_V
```

および

```math
N=T\left(\frac{\partial S}{\partial V}\right)_T-p
```

である．
これらを式 (3) に代入すると，

```math
\begin{aligned}
&\left(\frac{\partial}{\partial V}\right)_T
\left[
T\left(\frac{\partial S}{\partial T}\right)_V
\right]\\
&\qquad=
\left(\frac{\partial}{\partial T}\right)_V
\left[
T\left(\frac{\partial S}{\partial V}\right)_T-p
\right]
\end{aligned}
```

を得る．

左辺では $T$ は一定であるから，

```math
T\frac{\partial^2S}{\partial V\,\partial T}
```

となる．
一方，右辺を積の微分法則で展開すると，

```math
\left(\frac{\partial S}{\partial V}\right)_T
+
T\frac{\partial^2S}{\partial T\,\partial V}
-
\left(\frac{\partial p}{\partial T}\right)_V
```

となる．
したがって，

```math
\begin{aligned}
T\frac{\partial^2S}{\partial V\,\partial T}
={}&
\left(\frac{\partial S}{\partial V}\right)_T\\
&+T\frac{\partial^2S}{\partial T\,\partial V}
-\left(\frac{\partial p}{\partial T}\right)_V
\end{aligned}
```

である．

エントロピー $S$ の混合二階偏微分の順序を交換できるため，

```math
\frac{\partial^2S}{\partial V\,\partial T}
=
\frac{\partial^2S}{\partial T\,\partial V}
```

が成立する．
よって，両辺に現れる混合二階偏微分の項が相殺され，

```math
\boxed{
\left(\frac{\partial S}{\partial V}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_V
}
\tag{4}
```

を得る．
これは Maxwell の関係式の一つである．

#### 3．目的の式を導く

式 (2) で $T$ を一定とすると， $dT=0$ であるから，

```math
dU=
\left\{
T\left(\frac{\partial S}{\partial V}\right)_T-p
\right\}dV
```

となる．
したがって，

```math
\left(\frac{\partial U}{\partial V}\right)_T
=
T\left(\frac{\partial S}{\partial V}\right)_T-p
```

である．
ここに式 (4) を代入すれば，

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_T
=
T\left(\frac{\partial p}{\partial T}\right)_V-p
}
```

を得る．
よって，(i) が証明された．

### (ii) $\displaystyle \left(\frac{\partial H}{\partial p}\right)_T=-T\left(\frac{\partial V}{\partial T}\right)_p+V$ の証明

#### 1．エンタルピーの全微分を求める

エンタルピー $H$ は，

```math
H=U+pV
```

と定義される．
両辺を微分すると，

```math
dH=dU+p\,dV+V\,dp
```

となる．
ここに熱力学の基本関係式

```math
dU=T\,dS-p\,dV
```

を代入すると，

```math
\begin{aligned}
dH
&=T\,dS-p\,dV+p\,dV+V\,dp\\
&=T\,dS+V\,dp
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
dS=\frac{1}{T}dH-\frac{V}{T}dp
}
\tag{5}
```

である．

#### 2．エントロピーの全微分を表す

エンタルピー $H$ を温度 $T$ と圧力 $p$ の関数 $H(T,p)$ とみなすと，

```math
dH=
\left(\frac{\partial H}{\partial T}\right)_p dT
+
\left(\frac{\partial H}{\partial p}\right)_T dp
```

である．
これを式 (5) に代入すると，

```math
\begin{aligned}
dS
={}&
\frac{1}{T}
\left(\frac{\partial H}{\partial T}\right)_p dT\\
&+
\left[
\frac{1}{T}\left(\frac{\partial H}{\partial p}\right)_T
-\frac{V}{T}
\right]dp
\end{aligned}
\tag{6}
```

となる．

一方，エントロピー $S$ は状態量であるため， $S(T,p)$ の全微分も完全微分である．
一般に，

```math
dS=A(T,p)\,dT+B(T,p)\,dp
```

が完全微分であるとき，

```math
\left(\frac{\partial A}{\partial p}\right)_T
=
\left(\frac{\partial B}{\partial T}\right)_p
\tag{7}
```

が成立する．

式 (6) の係数を式 (7) に代入すると，

```math
\begin{aligned}
&\left(\frac{\partial}{\partial p}\right)_T
\left[
\frac{1}{T}
\left(\frac{\partial H}{\partial T}\right)_p
\right]\\
&\quad=
\left(\frac{\partial}{\partial T}\right)_p
\left[
\frac{1}{T}\left(\frac{\partial H}{\partial p}\right)_T
-\frac{V}{T}
\right]
\end{aligned}
\tag{8}
```

を得る．

#### 3．混合偏微分の順序交換を用いる

式 (8) の左辺では，温度 $T$ は一定であるから，

```math
\frac{1}{T}
\frac{\partial^2H}{\partial p\,\partial T}
```

となる．
右辺を積の微分法則で展開すると，

```math
\begin{aligned}
&\frac{1}{T}
\frac{\partial^2H}{\partial T\,\partial p}
-\frac{1}{T^2}\left(\frac{\partial H}{\partial p}\right)_T\\
&\qquad
-\frac{1}{T}\left(\frac{\partial V}{\partial T}\right)_p
+\frac{V}{T^2}
\end{aligned}
```

となる．
したがって，

```math
\begin{aligned}
\frac{1}{T}
\frac{\partial^2H}{\partial p\,\partial T}
={}&
\frac{1}{T}
\frac{\partial^2H}{\partial T\,\partial p}\\
&-\frac{1}{T^2}\left(\frac{\partial H}{\partial p}\right)_T\\
&-\frac{1}{T}\left(\frac{\partial V}{\partial T}\right)_p
+\frac{V}{T^2}
\end{aligned}
```

である．

エンタルピー $H$ の混合二階偏微分の順序を交換できるため，

```math
\frac{\partial^2H}{\partial p\,\partial T}
=
\frac{\partial^2H}{\partial T\,\partial p}
```

が成立する．
よって，左右両辺の混合二階偏微分の項が相殺され，

```math
0=
-\frac{1}{T^2}\left(\frac{\partial H}{\partial p}\right)_T
-\frac{1}{T}\left(\frac{\partial V}{\partial T}\right)_p
+\frac{V}{T^2}
```

を得る．
両辺に $T^2$ を掛けて整理すると，

```math
\left(\frac{\partial H}{\partial p}\right)_T
+T\left(\frac{\partial V}{\partial T}\right)_p
-V=0
```

となる．
したがって，

```math
\boxed{
\left(\frac{\partial H}{\partial p}\right)_T
=
-T\left(\frac{\partial V}{\partial T}\right)_p+V
}
```

を得る．
よって，(ii) も証明された．


## 解説

両方の証明に共通する要点は，熱力学の基本関係式を全微分の形に直し，内部エネルギー $U$ ，エンタルピー $H$ ，エントロピー $S$ が状態量であることを利用して，混合二階偏微分の順序交換を適用することである．
この操作によって，エントロピーの偏微分を圧力や体積の偏微分に結び付けることができ，目的の恒等式が導かれる．
