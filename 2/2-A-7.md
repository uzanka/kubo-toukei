# 演習問題【2-A-7】

## 解答

理想気体のエントロピー $S$ を，熱力学第1法則とエントロピーの定義を用いて求める．

定積モル熱容量は温度に依存せず，

```math
C_v=C_v^0
```

で一定であるとする．
以下では，組成一定の理想気体を考え， $C_v^0$ は1 mol 当たりの定積熱容量とする．

### 1．エントロピーの微分式を求める

まず，1 mol の理想気体を考える．

平衡状態間の可逆過程に対して，エントロピーの微小変化は，

```math
dS=\frac{\delta Q_{\mathrm{rev}}}{T}
```

で与えられる．
ここで， $\delta Q_{\mathrm{rev}}$ は気体が可逆過程で受け取る微小熱量， $T$ は絶対温度である．

一方，気体が外部にする微小仕事は $p\,dV$ であるから，熱力学第1法則より，

```math
dU=\delta Q_{\mathrm{rev}}-p\,dV
```

となる．
したがって，

```math
\delta Q_{\mathrm{rev}}=dU+p\,dV
```

であり，これをエントロピーの式に代入すると，

```math
dS=\frac{dU+p\,dV}{T}
\tag{1}
```

を得る．

### 2．理想気体の関係式を代入する

理想気体では，内部エネルギーは温度のみの関数である（Joule の法則）．

したがって，1 mol の理想気体について，定積モル熱容量が一定であることから，

```math
dU=C_v^0\,dT
```

と表される．

また，1 mol の理想気体の状態方程式は，

```math
pV=RT
```

であるから，

```math
p=\frac{RT}{V}
```

となる．

これらを式(1)に代入すると，

```math
\begin{aligned}
dS
&=\frac{C_v^0\,dT+p\,dV}{T}\\
&=\frac{C_v^0}{T}\,dT
+\frac{R}{V}\,dV
\end{aligned}
\tag{2}
```

を得る．

### 3．積分して1 mol のエントロピーを求める

式(2)を基準状態 $(T_0,v_0)$ から状態 $(T,V)$ まで積分する．

ここで， $T_0$ は基準温度， $v_0$ は基準モル体積とする．
1 mol の場合，体積 $V$ はモル体積に等しい．

また， $s_0$ を基準状態 $(T_0,v_0)$ におけるモルエントロピーとする．

すると，

```math
\begin{aligned}
s-s_0
&=\int_{T_0}^{T}\frac{C_v^0}{T}\,dT
+\int_{v_0}^{V}\frac{R}{V}\,dV\\[6pt]
&=C_v^0\ln\frac{T}{T_0}
+R\ln\frac{V}{v_0}
\end{aligned}
```

となる．

したがって，1 mol の理想気体のモルエントロピーは，

```math
\boxed{
s(T,V)=s_0+
C_v^0\ln\frac{T}{T_0}
+R\ln\frac{V}{v_0}
}
\tag{3}
```

で与えられる．

ここで，対数の引数はいずれも無次元である．
また， $s_0$ は基準状態におけるモルエントロピーであり，与えられた熱容量と状態方程式だけからは決定されない積分定数である．

### 4．一般の $n$ mol の場合

次に，一般の $n$ mol の理想気体を考える．
ここでは，物質量 $n$ は一定である．

内部エネルギーの変化は物質量に比例するため，

```math
dU=nC_v^0\,dT
```

である．

また，状態方程式は，

```math
pV=nRT
```

であるから，

```math
p=\frac{nRT}{V}
```

となる．

これらを式(1)に代入すると，

```math
\begin{aligned}
dS
&=\frac{nC_v^0\,dT+p\,dV}{T}\\
&=nC_v^0\frac{dT}{T}
+nR\frac{dV}{V}
\end{aligned}
\tag{4}
```

を得る．

ここで，式(4)を物質量 $n$ 一定として積分する．

基準体積を

```math
V_*=n_*v_0
```

とする．
ここで， $n_*$ は基準物質量（例えば $1\ \mathrm{mol}$ ）である．

すると，

```math
\boxed{
S(T,V,n)
=
nC_v^0\ln\frac{T}{T_0}
+nR\ln\frac{V}{V_*}
+f(n)
}
\tag{5}
```

となる．

ここで， $f(n)$ は物質量 $n$ のみに依存する積分定数である．
式(4)だけでは，この関数の形は決定できない．

そこで，エントロピーが示量性をもつ状態量であることを用いる．

示量性とは，温度を一定に保ったまま，系の体積と物質量を同じ倍率 $\lambda>0$ で拡大すると，エントロピーも同じ倍率で変化することを意味する．
理想気体では内部エネルギーも同じ倍率で変化するため，

```math
\boxed{
S(T,\lambda V,\lambda n)
=
\lambda S(T,V,n)
}
\tag{6}
```

が成立する．

式(5)に式(6)を適用すると，

```math
\begin{aligned}
&\lambda nC_v^0\ln\frac{T}{T_0}
+\lambda nR\ln\frac{\lambda V}{V_*}
+f(\lambda n)\\
&\qquad=
\lambda nC_v^0\ln\frac{T}{T_0}
+\lambda nR\ln\frac{V}{V_*}
+\lambda f(n)
\end{aligned}
```

となる．

ここで，

```math
\ln\frac{\lambda V}{V_*}
=
\ln\frac{V}{V_*}+\ln\lambda
```

を用いて整理すると，

```math
\lambda nR\ln\lambda+f(\lambda n)
=
\lambda f(n)
```

したがって，

```math
\boxed{
f(\lambda n)
=
\lambda f(n)-\lambda nR\ln\lambda
}
\tag{7}
```

を得る．

この関数方程式を満たす $f(n)$ を求める．

```math
\lambda=\frac{n}{n_*}
```

とし，式(7)において基準物質量を $n_*$ とすれば，

```math
f(n)
=
\frac{n}{n_*}f(n_*)
-nR\ln\frac{n}{n_*}
```

となる．

ここで，

```math
s_0=\frac{f(n_*)}{n_*}
```

と定義すると，

```math
\boxed{
f(n)
=
ns_0-nR\ln\frac{n}{n_*}
}
\tag{8}
```

を得る．

式(8)を式(5)に代入すると，

```math
\begin{aligned}
S(T,V,n)
={}&nC_v^0\ln\frac{T}{T_0}
+nR\ln\frac{V}{n_*v_0}\\
&+ns_0-nR\ln\frac{n}{n_*}
\end{aligned}
```

となる．

対数の性質を用いて整理すれば，

```math
\ln\frac{V}{n_*v_0}
-\ln\frac{n}{n_*}
=
\ln\frac{V}{nv_0}
```

であるから，

```math
\boxed{
S(T,V,n)
=
n\left[
s_0+
C_v^0\ln\frac{T}{T_0}
+
R\ln\frac{V}{nv_0}
\right]
}
\tag{9}
```

を得る．

ここで，

```math
v=\frac{V}{n}
```

はモル体積である．
したがって，式(9)は，

```math
\boxed{
S(T,V,n)
=
n\left[
s_0+
C_v^0\ln\frac{T}{T_0}
+
R\ln\frac{v}{v_0}
\right]
}
```

とも表される．

これは1 mol の結果である式(3)を，モル体積 $v=V/n$ を一定に保つ示量的な拡張として得たものである．

### 5．最終結果

以上より，一般の $n$ mol の理想気体のエントロピーは，

```math
\boxed{
S(T,V,n)
=
n\left[
s_0+
C_v^0\ln\frac{T}{T_0}
+
R\ln\frac{V}{nv_0}
\right]
}
```

である．

ここで， $T_0$ は基準温度， $v_0$ は基準モル体積， $s_0$ は基準状態におけるモルエントロピーである．

なお，この式は物質量一定の状態変化に対して式(4)を満たし，また，

```math
S(T,\lambda V,\lambda n)
=
\lambda S(T,V,n)
```

を満たすため，熱力学的な示量性とも整合している．
