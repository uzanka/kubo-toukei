# 演習問題【2-A-7】

## 解答

理想気体のエントロピー $S$ を求めるために，熱力学の基本関係式から出発する．

### 1. エントロピー変化の定義

熱力学の第一法則およびエントロピーの定義より，系の微小なエントロピー変化 $dS$ は次のように表される．

$$dS = \frac{d'Q}{T}$$

ここで， $d'Q$ は系に流入する微小熱量， $T$ はその時の絶対温度である．
熱力学第一法則 $dU = d'Q - dW$（あるいは $d'Q = dU + p dV$ ）を用いると，エントロピー変化は次のように書き換えられる．

$$dS = \frac{dU + p dV}{T}$$

### 2. 理想気体の性質の代入

理想気体の性質を用いて，式中の $dU$ と $p dV$ を温度 $T$ と体積 $V$ の関数に変換する．

- **内部エネルギーの変化 ( $dU$ )** :
  定積熱容量 $C_v$ を用いると， $dU = C_v dT$ と書ける．
  本問題では $C_v = C_v^0$ （定数）であるから，

$$dU = C_v^0 dT$$

- **圧力 ( $p$ )** :
  理想気体の状態方程式 $pV = nRT$ より， $p = \frac{nRT}{V}$ である．

これらを $dS$ の式に代入すると，

$$dS = \frac{C_v^0 dT + \frac{nRT}{V} dV}{T}$$

$$dS = \frac{C_v^0}{T} dT + \frac{nR}{V} dV$$

### 3. 積分によるエントロピーの導出

エントロピー $S$ を求めるために，上記の式を積分する．
ここでは，まず $n = 1$（1 mol）の場合を考える．

$$S = \int \left( \frac{C_v^0}{T} dT + \frac{R}{V} dV \right)$$

$$S = C_v^0 \int \frac{1}{T} dT + R \int \frac{1}{V} dV$$

$$S = C_v^0 \log T + R \log V + S_0$$

ここで， $S_0$ は積分定数であり，温度 $T$ や体積 $V$ に依存しない定数である．

### 4. 一般的な $n$ mol の場合

エントロピーが「容量性（extensive property）」の量であること，つまり物質量 $n$ に比例することを考慮する．
$n$ mol の系におけるエントロピー $S(T, V, n)$ は， $1$ mol のときのエントロピーの $n$ 倍となる．

状態方程式を用いて $1$ mol の式の $V$ を $V/n$ に置き換える（または $R \to nR$ と置き換える）ことで，一般式を得る．

$$S(T, V, n) = n \left( C_v^0 \log T + R \log \frac{V}{n} + S_0 \right)$$

これが求める理想気体のエントロピーである．

## 解説

### 1. エントロピーとは

エントロピーは，系の「乱雑さ」や「無秩序さ」の度合いを表す物理量である．
熱力学においては，エネルギーの質（利用可能性）を示す指標としても重要である．
エントロピーは状態量であり，系の現在の状態（温度，圧力，体積など）のみによって決まる．

### 2. 理想気体の熱容量

本問題では定積熱容量 $C_v$ が温度によらないとされている．
実際の気体では，温度が上がると熱容量も変化することがあるが，多くの基本的な熱力学の議論では計算を簡略化するために定数として扱う．

### 3. 容量性の量（Extensive property）

物理量には，物質の量に依存する「容量性（Extensive）」なものと，依存しない「強度性（Intensive）」なものがある．
- **容量性** : 質量，体積，内部エネルギー，エントロピーなど（ $n$ 倍すると $n$ 倍になる）．
- **強度性** : 温度，圧力，密度など（ $n$ 倍しても変わらない）．

エントロピーは容量性であるため，物質量 $n$ を考慮した際，式全体に $n$ がかかる形になることに注意が必要である．
