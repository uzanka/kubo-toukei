# 演習問題【2-A-7】

## 解答

理想気体のエントロピー $S$ を，熱力学第1法則とエントロピーの定義を用いて求める．
定積モル熱容量は温度に依存せず，

```math
C_v=C_v^0
```

で一定であるとする．

### 1．エントロピーの微分式を求める

まず，1 mol の理想気体を考える．
気体が準静的かつ可逆な変化をするとき，エントロピーの微小変化 $dS$ は，

```math
dS=\frac{\delta Q_{\mathrm{rev}}}{T}
```

で与えられる．
ここで， $\delta Q_{\mathrm{rev}}$ は気体が可逆過程で受け取る微小熱量， $T$ は絶対温度である．

一方，気体が外部にする微小仕事は $p\,dV$ であるから，熱力学第1法則より，

```math
dU=\delta Q_{\mathrm{rev}}-p\,dV
```

となる．
したがって，

```math
\delta Q_{\mathrm{rev}}=dU+p\,dV
```

であり，これをエントロピーの式に代入すると，

```math
dS=\frac{dU+p\,dV}{T}
\tag{1}
```

を得る．

### 2．理想気体の関係式を代入する

定積モル熱容量 $C_v^0$ が一定であるため，1 mol の理想気体の内部エネルギー変化は，

```math
dU=C_v^0\,dT
```

と表される．
また，1 mol の理想気体の状態方程式は，

```math
pV=RT
```

であるから，

```math
p=\frac{RT}{V}
```

となる．

これらを式 (1) に代入すると，

```math
\begin{aligned}
dS
&=\frac{C_v^0\,dT+p\,dV}{T}\\
&=\frac{C_v^0}{T}\,dT
+\frac{R}{V}\,dV
\end{aligned}
\tag{2}
```

を得る．

### 3．積分して1 mol のエントロピーを求める

式 (2) の右辺を積分する．
対数の引数を無次元にするため，基準温度を $T_0$ ，基準モル体積を $v_0$ とする．
1 mol の場合，体積 $V$ はモル体積に等しいので，

```math
\begin{aligned}
S-S_0
&=\int_{T_0}^{T}\frac{C_v^0}{T}\,dT
+\int_{v_0}^{V}\frac{R}{V}\,dV\\[6pt]
&=C_v^0\ln\frac{T}{T_0}
+R\ln\frac{V}{v_0}
\end{aligned}
```

となる．
ここで $S_0$ は基準状態におけるエントロピーである．
したがって，1 mol の理想気体のエントロピーは，

```math
\boxed{
S=C_v^0\ln\frac{T}{T_0}
+R\ln\frac{V}{v_0}+S_0
}
\tag{3}
```

で与えられる．
基準値を省略し，積分定数にまとめれば，

```math
S=C_v^0\ln T+R\ln V+S_0
```

という解答例の形式になる．

### 4．一般の $n$ mol の場合

次に， $n$ mol の理想気体を考える．
内部エネルギーの変化は物質量に比例するため，

```math
dU=nC_v^0\,dT
```

である．
また，状態方程式は，

```math
pV=nRT
```

であるから，

```math
p=\frac{nRT}{V}
```

となる．
これらを式 (1) に代入すると，

```math
dS=nC_v^0\frac{dT}{T}
+nR\frac{dV}{V}
\tag{4}
```

を得る．

ここで，エントロピーは容量性の状態量であるため，物質量に比例する．
1 mol 当たりの体積，すなわちモル体積を

```math
v=\frac{V}{n}
```

とおけば，エントロピーは温度 $T$ とモル体積 $v$ の関数として表される．
1 mol の結果を用いると，

```math
S=n\left[
C_v^0\ln\frac{T}{T_0}
+R\ln\frac{V/n}{v_0}
+S_0
\right]
```

となる．
したがって，一般の $n$ mol の理想気体のエントロピーは，

```math
\boxed{
S(T,V,n)=
n\left[
C_v^0\ln\frac{T}{T_0}
+R\ln\frac{V}{nv_0}
+S_0
\right]
}
\tag{5}
```

で与えられる．

基準値を省略して積分定数にまとめれば，

```math
\boxed{
S(T,V,n)=
n\left(
C_v^0\ln T
+R\ln\frac{V}{n}
+S_0
\right)
}
```

となり，解答例の式が得られる．
