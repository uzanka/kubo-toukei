# 演習問題【2-A-27】

## 解答

### 1. 内部エネルギー $U$ が $M$ によらないことの証明

単位体積あたりの熱力学的な基本関係式（第一法則）は，磁場 $H$ と磁化 $M$ を用いると次のように書ける．

$$dU = T dS + H dM$$

これを $dS$ について解くと，

$$dS = \frac{1}{T} dU - \frac{H}{T} dM \quad \dots (1)$$

となる．

ここで， $S$ が状態量であるための条件（積分可能条件，またはマクスウェルの関係式に相当する条件）は，混合偏微分が等しいことである．

$$\left(\frac{\partial S}{\partial T}\right)_M \left(\frac{\partial S}{\partial M}\right)_T \quad \text{ではなく} \quad \frac{\partial^2 S}{\partial M \partial T} = \frac{\partial^2 S}{\partial T \partial M}$$

式(1)より，各偏微分は以下のようになる．

$$\left(\frac{\partial S}{\partial T}\right)_M = \frac{1}{T} \left(\frac{\partial U}{\partial T}\right)_M$$

$$\left(\frac{\partial S}{\partial M}\right)_T = \frac{1}{T} \left(\frac{\partial U}{\partial M}\right)_T - \frac{H}{T}$$

これらを積分可能条件に代入すると，

$$\frac{\partial}{\partial M} \left[ \frac{1}{T} \left(\frac{\partial U}{\partial T}\right)_M \right] = \frac{\partial}{\partial T} \left[ \frac{1}{T} \left(\frac{\partial U}{\partial M}\right)_T - \frac{H}{T} \right]$$

となる．
この関係式を整理すると，問題 [15] の結果と同様に，以下の関係式が得られることが知られている．

$$\left(\frac{\partial U}{\partial M}\right)_T = -T^2 \left(\frac{\partial}{\partial T} \left(\frac{H}{T}\right)\right)_M \quad \dots (2)$$

問題の条件より， $M = f(H/T)$ である．
これは， $M$ が変数 $H/T$ のみの関数であることを意味する．
したがって，磁化 $M$ を一定に保つ（ $M = \text{const.}$ ）ということは， $H/T$ も一定の値をとることを意味する．
つまり，定磁化条件下では $H/T$ は温度 $T$ の変化によらず一定であるため，

$$\left(\frac{\partial}{\partial T} \left(\frac{H}{T}\right)\right)_M = 0$$

となる．
これを式(2)に代入すると，

$$\left(\frac{\partial U}{\partial M}\right)_T = -T^2 \cdot 0 = 0$$

が得られる．
これは，内部エネルギー $U$ が磁化 $M$ に依存しない（ $T$ のみの関数である）ことを示している．

### 2. エントロピー $S$ の関数形の決定

$\left(\frac{\partial U}{\partial M}\right)_T = 0$ より，内部エネルギーは $U = U(T)$ と書ける．
したがって， $dU = \frac{dU(T)}{dT} dT$ である．
これを式(1)に代入する．

$$dS = \frac{1}{T} dU(T) - \frac{H}{T} dM$$

ここで， $M = f(x)$ （ただし $x = H/T$ ）とおく．
$x = H/T$ より $H = Tx$ である．
また， $dM = f'(x) dx$ と書ける．
これらを式に代入すると，

$$dS = \frac{1}{T} dU(T) - \frac{Tx}{T} f'(x) dx = \frac{1}{T} dU(T) - x f'(x) dx$$

となる．
この両辺を積分すると，

$$S = \int \frac{1}{T} \frac{dU(T)}{dT} dT - \int x f'(x) dx + C$$

$$S = g(T) - \int x f'(x) dx + C$$

ここで， $g(T)$ は $T$ のみの積分定数を含む関数である．
右辺の第2項について，部分積分を用いると，

$$\int x f'(x) dx = x f(x) - \int f(x) dx$$

となる．
これを代入すると，

$$S = g(T) - \left( x f(x) - \int f(x) dx \right) + C$$

$$S = g(T) - x f(x) + \int f(x) dx + C'$$

（ここで $C'$ は新しい積分定数）

最後に $x = H/T$ を元に戻すと，

$$S\left(T, \frac{H}{T}\right) = g(T) - \frac{H}{T} f\left(\frac{H}{T}\right) + \int_0^{H/T} f(x) dx + C'$$

が得られる．

## 解説

### 磁化の依存性について

問題文にある $M = f(H/T)$ という条件は，常磁性体の磁気的な性質が「磁場 $H$ と温度 $T$ の比」のみで決まることを示している．
これは，例えばキュリーの法則（ $M \propto H/T$ ）などがこの特殊なケースに該当する．

### なぜ $(\partial U / \partial M)_T = 0$ なのか？

熱力学において，内部エネルギー $U$ の変化は温度 $T$ と磁化 $M$ の変化によって決まる．
通常，磁場を変化させると磁化が変化し，それによってエネルギーが変化する．
しかし，この問題のように $M$ が $H/T$ だけの関数である場合，磁場 $H$ を変えても $H/T$ が変わらないように温度 $T$ を調整すれば，磁化 $M$ は変化しない．
数学的には，「 $M$ を一定に保つ」という操作が「 $H/T$ を一定に保つ」という操作と等価になるため，磁場によるエネルギー変化の寄与が相殺され，結果として内部エネルギーは $M$ に依存しなくなる．

### エントロピーの導出のポイント

エントロピー $S$ を求める過程では，まず $U$ が $M$ に依存しないことを利用して $dS$ を整理し，その後に変数変換（ $x = H/T$ ）を行っている．
積分計算において，部分積分 $\int u v' = uv - \int u' v$ を用いることで，複雑な $x f'(x)$ の項を，既知の関数 $f(x)$ の積分を含む形に整理することができた．
最終的な結果において， $g(T)$ は温度のみに依存する項であり，それ以外の項は $H/T$ の関数として記述されている．
