# 演習問題【2-A-27】

## 解答

### 1．内部エネルギー $U$ が磁化 $M$ に依存しないことの証明

単位体積あたりの常磁性体を考える．磁気仕事の符号規約として，熱力学第一法則を

```math
dU=d'Q+H\,dM
```

と表す．
ここで， $U$ は内部エネルギー， $Q$ は物質が吸収する熱量， $H$ は磁場， $M$ は磁化である．
可逆過程では $d'Q=T\,dS$ であるから，

```math
dU=T\,dS+H\,dM
```

となる．
これをエントロピー $S$ について整理すると，

```math
dS=\frac{1}{T}dU-\frac{H}{T}dM
\tag{1}
```

を得る．

内部エネルギーを温度 $T$ と磁化 $M$ の関数 $U(T,M)$ と考えると，式 (1) から，

```math
\left(\frac{\partial S}{\partial T}\right)_M
=\frac{1}{T}\left(\frac{\partial U}{\partial T}\right)_M
\tag{2}
```

および

```math
\left(\frac{\partial S}{\partial M}\right)_T
=\frac{1}{T}\left(\frac{\partial U}{\partial M}\right)_T
-\frac{H}{T}
\tag{3}
```

が得られる．

エントロピー $S$ は状態量であるため，その混合二階偏微分の順序を入れ替えることができる．
したがって，

```math
\frac{\partial}{\partial M}
\left(\frac{\partial S}{\partial T}\right)_M
=
\frac{\partial}{\partial T}
\left(\frac{\partial S}{\partial M}\right)_T
\tag{4}
```

が成り立つ．
式 (2)，(3) を式 (4) に代入すると，

```math
\frac{\partial}{\partial M}
\left[
\frac{1}{T}\left(\frac{\partial U}{\partial T}\right)_M
\right]
=
\frac{\partial}{\partial T}
\left[
\frac{1}{T}\left(\frac{\partial U}{\partial M}\right)_T
-\frac{H}{T}
\right]
```

となる．
両辺を展開すると，

```math
\frac{1}{T}\frac{\partial^2 U}{\partial M\,\partial T}
=
\frac{1}{T}\frac{\partial^2 U}{\partial T\,\partial M}
-\frac{1}{T^2}\left(\frac{\partial U}{\partial M}\right)_T
-\left(\frac{\partial}{\partial T}\frac{H}{T}\right)_M
```

である．
内部エネルギーの混合二階偏微分が等しいことを用いて整理すると，

```math
\frac{1}{T^2}\left(\frac{\partial U}{\partial M}\right)_T
+
\left(\frac{\partial}{\partial T}\frac{H}{T}\right)_M
=0
```

となる．
よって，

```math
\boxed{
\left(\frac{\partial U}{\partial M}\right)_T
=-T^2\left(\frac{\partial}{\partial T}\frac{H}{T}\right)_M
}
\tag{5}
```

を得る．

ここで，問題の条件より，

```math
M=f\left(\frac{H}{T}\right)
\tag{6}
```

である．
つまり，磁化 $M$ は $H/T$ のみで決まる．
$f$ が考えている範囲で局所的に逆関数をもつ場合，磁化 $M$ を一定に保てば $H/T$ も一定に保たれる．
したがって，

```math
\left(\frac{\partial}{\partial T}\frac{H}{T}\right)_M=0
```

である．
これを式 (5) に代入すると，

```math
\left(\frac{\partial U}{\partial M}\right)_T
=-T^2\cdot0=0
```

となる．
したがって，内部エネルギーは磁化 $M$ に依存せず，

```math
\boxed{U=U(T)}
```

と表される．これで第一の問いが示された．

### 2．エントロピー $S$ の関数形の導出

次に，式 (1) を用いてエントロピーを求める．
内部エネルギーが $U=U(T)$ であるため，

```math
dU=\frac{dU(T)}{dT}\,dT
```

である．
したがって，式 (1) は

```math
dS=\frac{1}{T}dU(T)-\frac{H}{T}dM
\tag{7}
```

と書ける．

ここで，

```math
x=\frac{H}{T}
```

と置く．
問題の条件 $M=f(H/T)$ より，

```math
M=f(x),\qquad dM=f'(x)\,dx
```

であり，$H/T=x$ であるから，式 (7) は

```math
dS=\frac{1}{T}dU(T)-x f'(x)\,dx
\tag{8}
```

となる．

式 (8) の右辺をそれぞれ積分すると，

```math
S=\int\frac{1}{T}dU(T)-\int x f'(x)\,dx+S_0
\tag{9}
```

を得る．
ここで $S_0$ は積分定数である．
温度のみに依存する項を

```math
g(T)=\int^T\frac{1}{\tau}\frac{dU(\tau)}{d\tau}\,d\tau
```

と定義すれば，式 (9) は

```math
S=g(T)-\int x f'(x)\,dx+S_0
\tag{10}
```

となる．

残る積分には部分積分を用いる．
積の微分公式

```math
\frac{d}{dx}[x f(x)]=f(x)+x f'(x)
```

より，

```math
\int x f'(x)\,dx
=x f(x)-\int f(x)\,dx
```

である．
これを式 (10) に代入すると，

```math
S=g(T)-x f(x)+\int f(x)\,dx+S_0
```

となる．
積分の下限を $0$ とする形で積分定数を整理すれば，

```math
S=g(T)-x f(x)+\int_0^x f(y)\,dy+S_0
\tag{11}
```

と表せる．

最後に $x=H/T$ を戻すと，求めるエントロピーの関数形は

```math
\boxed{
S(T,H)=g(T)
-\frac{H}{T}f\left(\frac{H}{T}\right)
+\int_0^{H/T}f(y)\,dy+S_0
}
```

である．
ここで，

```math
g(T)=\int^T\frac{1}{\tau}
\frac{dU(\tau)}{d\tau}\,d\tau
```

は温度のみに依存する関数であり， $S_0$ は積分定数である．

### 3．結果の意味

磁化が $H/T$ のみの関数であるとき，積分可能条件から内部エネルギーは磁化に依存しないことが分かった．
さらに，エントロピーは温度のみに依存する項 $g(T)$ と，変数 $H/T$ の関数によって表される項の和として定まる．

なお，問題では $U(T)$ の具体的な関数形までは与えられていないため，温度に依存する項 $g(T)$ をこれ以上具体的に定めることはできない．
