# 演習問題【2-A-1】

## 解答

## Clausius の原理を用いた Clausius の不等式の証明

考える体系が外界の熱源 $R_i$ から受け取る熱量を $Q_i$ とする。
熱源から体系に熱が流入するとき $Q_i>0$ 、体系から熱源へ熱が流出するとき $Q_i<0$ と約束する。

各熱源の温度を $T_i^{(e)}$ とする。
本証明では、熱源の添字を並べ替え、 $T_1^{(e)}$ を最低温度、 $T_n^{(e)}$ を最高温度とする。まず、少なくとも2つの熱源の温度が異なり、

```math
T_n^{(e)}>T_1^{(e)}
```

である場合を考える。

### 1. 補助 Carnot サイクルを導入する

外界は、温度がそれぞれ $T_1^{(e)},T_2^{(e)},\dots,T_n^{(e)}$ である $n$ 個の熱源 $R_1,R_2,\dots,R_n$ からなると考える。

ここで、 $n-1$ 個の可逆な Carnot サイクル $C_1,C_2,\dots,C_{n-1}$ を導入し、各サイクルが隣り合う2つの熱源の間で働くようにする。

- $C_1$ は $R_1$ と $R_2$ の間で働き、両熱源から受け取る符号付き熱量をそれぞれ $Q_1'$ 、 $Q_2''$ とする。
- $C_2$ は $R_2$ と $R_3$ の間で働き、熱量をそれぞれ $Q_2'$ 、 $Q_3''$ とする。
- 同様に、 $C_{n-1}$ は $R_{n-1}$ と $R_n$ の間で働き、熱量をそれぞれ $Q_{n-1}'$、 $Q_n''$ とする。

ここで、 $Q_i'$ と $Q_i''$ も、各補助サイクルが対応する熱源から受け取る符号付き熱量を表す。

考える体系の元の循環過程を $C$ とする。
$C$ とすべての補助 Carnot サイクルが1回ずつ完了したとき、各熱源が失った正味の熱量は

```math
\begin{array}
{ll} R_1:&Q_1+Q_1',\\
R_2:&Q_2+Q_2'+Q_2'',\\
&\vdots\\
R\_{n-1}:&Q_{n-1}+Q_{n-1}'+Q_{n-1}'',\\
R_n:&Q_n+Q_n''
\end{array}
```

となる。

### 2. 中間の熱源の熱量変化をゼロにする

補助 Carnot サイクルを適切に調節して、中間の熱源 $R_2,\dots,R_{n-1}$ の正味の熱量変化がゼロになるようにする。すなわち、

```math
\boxed{
Q_i+Q_i'+Q_i''=0 \quad (i=2,\dots,n-1)
}
\tag{2}
```

を満たすようにする。

さらに、両端の熱源についても正味の熱量変化の和がゼロになるように、次の条件を追加して課す。

```math
\boxed{
Q_1+Q_1'+Q_n+Q_n''=0
}
\tag{2'}
```

この式 (2)' は式 (2) から導かれるものではない。
補助 Carnot サイクルを決めるために、式 (2) と併せて満たすべき条件である。

### 3. Carnot サイクルの性質を用いる

各補助サイクル $C_i$ は可逆な Carnot サイクルなので、熱力学温度と熱量の間に

```math
\frac{Q_i'}{T_i^{(e)}}+ \frac{Q_{i+1}''}{T_{i+1}^{(e)}}=0 \quad (i=1,\dots,n-1)
\tag{3}
```

が成立する。

これは、可逆な Carnot サイクルでは、熱の授受が起こる各熱源について、熱量をその熱源の絶対温度で割った値の和がゼロになることを表す。
熱量には符号を付けているので、熱を放出する側の熱量は負となる。

ここで、調節する未知数は

```math
Q_1',\dots,Q\_{n-1}',\qquad Q_2'',\dots,Q_n''
```

の合計 $2(n-1)$ 個である。

これらに対して、式 (2) が $n-2$ 個、式 (2)' が1個、式 (3) が $n-1$ 個あり、合計は

```math
(n-2)+1+(n-1)=2(n-1)
```

個となる。

さらに、この連立方程式が実際に解けることを確認する。
簡単のため、ここでは $T_i=T_i^{(e)}$ と書き、 $x_i=Q_i'$ とおく。

式 (3) から

```math
Q_{i+1}''=-\frac{T_{i+1}}{T_i}x_i
```

を得る。
これを式 (2) に代入すると、

```math
x_i=\frac{T_i}{T_{i-1}}x_{i-1}-Q_i \quad (i=2,\dots,n-1)
```

となる。
これを順に用いれば、

```math
x_{n-1} =\frac{T_{n-1}}{T_1}x_1 -\sum_{i=2}^{n-1}\frac{T_{n-1}}{T_i}Q_i
```

を得る。

一方、式 (2)' に $Q_n''=-\frac{T_n}{T_{n-1}}x_{n-1}$ を代入すると、

```math
\boxed{
\left(\frac{T_n}{T_1}-1\right)x_1 =Q_1+Q_n+\sum_{i=2}^{n-1} \frac{T_n}{T_i}Q_i }
```

となる。
ここで $T_n>T_1>0$ なので、左辺の $x_1$ の係数はゼロではない。
したがって $x_1$ が定まり、順次 $x_2,\dots,x_{n-1}$ と $Q_2'',\dots,Q_n''$ も定まる。

よって、この条件を満たすように補助 Carnot サイクルを調節できる。

### 4. 各熱源の熱量を温度で割った関係式を得る

式 (3) をすべて加えると、

```math
\frac{Q_1'}{T_1^{(e)}} +\sum_{i=2}^{n-1} \frac{Q_i'+Q_i''}{T_i^{(e)}} +\frac{Q_n''}{T_n^{(e)}}=0
```

となる。

式 (2) より、中間の各熱源について

```math
Q_i'+Q_i''=-Q_i \quad (i=2,\dots,n-1)
```

だから、これを代入すれば、

```math
\frac{Q_1'}{T_1^{(e)}} -\sum_{i=2}^{n-1}\frac{Q_i}{T_i^{(e)}} +\frac{Q_n''}{T_n^{(e)}}=0
```

を得る。
したがって、

```math
\boxed{
\frac{Q_1'}{T_1^{(e)}}+ \frac{Q_n''}{T_n^{(e)}} =\sum_{i=2}^{n-1}\frac{Q_i}{T_i^{(e)}}
}
\tag{4}
```

が成立する。

### 5. Clausius の原理を適用する

ここで、補助 Carnot サイクルも含めた複合サイクル全体を考える。

すべてのサイクルは完了しているため、考える体系と補助サイクルの内部状態は元に戻る。
さらに、式 (2) によって中間の熱源の正味の熱量変化はゼロであり、式 (2)' によって両端の熱源の熱量変化の和もゼロである。

したがって、複合サイクル全体について第1法則を適用すると、外界から受け取る正味の仕事 $A$ は

```math
A=-\left[ (Q_1+Q_1')+(Q_n+Q_n'') \right]=0
```

となる。

ここで、

```math
H_1=Q_1+Q_1',\qquad H_n=Q_n+Q_n''
```

とおく。
$H_1,H_n$ はそれぞれ $R_1,R_n$ が失った正味の熱量である。
式 (2)' から、

```math
H_1+H_n=0
```

すなわち、

```math
H_n=-H_1
```

である。

この複合サイクルにより外界に生じる変化は、両端の熱源 $R_1,R_n$ の間の熱の移動だけである。
また、正味の仕事のやり取りもない。

ところが、 $T_n^{(e)}>T_1^{(e)}$ である。
Clausius の原理によれば、ほかに何の変化も起こさずに低温の熱源 $R_1$ から高温の熱源 $R_n$ へ熱を移すことはできない。

したがって、

```math
\boxed{
H_n\geq 0,\qquad H_1\leq 0
}
\tag{5}
```

でなければならない。

$H_n=-H_1$ であり、 $T_n^{(e)}>T_1^{(e)}>0$ なので、

```math
\frac{H_n}{T_n^{(e)}} \leq \frac{H_n}{T_1^{(e)}} =-\frac{H_1}{T_1^{(e)}}
```

が成立する。
すなわち、

```math
\frac{Q_n+Q_n''}{T_n^{(e)}} \leq -\frac{Q_1+Q_1'}{T_1^{(e)}}
```

である。
これを展開して整理すると、

```math
\boxed{
\frac{Q_1'}{T_1^{(e)}}+ \frac{Q_n''}{T_n^{(e)}} \leq -\left( \frac{Q_1}{T_1^{(e)}}+ \frac{Q_n}{T_n^{(e)}} \right)
}
\tag{6}
```

を得る。

### 6. Clausius の不等式を導く

式 (4) を式 (6) に代入すると、

```math
\sum_{i=2}^{n-1}\frac{Q_i}{T_i^{(e)}} \leq -\left( \frac{Q_1}{T_1^{(e)}}+ \frac{Q_n}{T_n^{(e)}} \right)
```

となる。
両辺を整理すれば、

```math
\frac{Q_1}{T_1^{(e)}}+ \sum_{i=2}^{n-1}\frac{Q_i}{T_i^{(e)}}+ \frac{Q_n}{T_n^{(e)}}\leq 0
```

を得る。
したがって、

```math
\boxed{
\displaystyle \sum_{i=1}^{n}\frac{Q_i}{T_i^{(e)}}\leq 0
}
\tag{2.9}
```

が証明された。

可逆な循環過程では、逆向きの過程も実現できるため、正方向と逆方向の両方に上の不等式を適用すると等号が得られる。
不可逆な循環過程では、第二法則の厳密な形により不等号は厳密となる。
したがって、等号は過程が可逆である場合に限って成立する。

なお、すべての熱源が同じ温度 $T$ にある場合には、 $\sum_i Q_i/T=(\sum_i Q_i)/T$ となる。
この場合、単一の熱源から受け取った熱を他に何の変化もなくすべて仕事に変えることはできない、という Kelvin–Planck の原理（Clausius の原理と等価）から、同じ不等式が得られる。
