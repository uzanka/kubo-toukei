# 演習問題【2-A-1】

## 解答

### Clausius の原理を用いた Clausius の不等式の証明

考える体系が外界の熱源 $R_i4 から受け取る熱量を $Q_i$ とする．
熱源から体系に熱が流入するとき $Q_i>0$ ，体系から熱源へ熱が流出するとき $Q_i<0$ と約束する．
各熱源の絶対温度を $T_i^{(e)}$ とする．

考える体系は，一連の熱源と熱を授受して一つの循環過程を行うものとする．
したがって，循環過程の終了後，体系は初期状態に戻る．

#### 1．補助熱源と補助 Carnot サイクルを導入する

まず，元の熱源 $R_1,\ldots,R_n$ とは別に，温度 $T_04 の補助熱源 $R_0$ を導入する．
その温度は，

```math
T_0>\max_{1\leq i\leq n}T_i^{(e)}
```

となるように選ぶ．

このように選べば， $R_0$ はすべての元の熱源より高温であり，どの元の熱源とも異なる温度をもつ．

次に，それぞれの元の熱源 $R_i$ と補助熱源 $R_0$ の間で働く， $n$ 個の可逆な Carnot サイクル $C_i$ を導入する．

各 Carnot サイクル $C_i$ が熱源 $R_i$ から受け取る符号付き熱量を $Q_i'$ ，熱源 $R_0$ から受け取る符号付き熱量を $Q_{0i}'$ とする．

熱量の符号は，熱源から Carnot サイクルに熱が流入するとき正，Carnot サイクルから熱源へ熱が流出するとき負とする．

各 Carnot サイクルは可逆であるから，Carnot の定理より，

```math
\boxed{
\frac{Q_i'}{T_i^{(e)}}+
\frac{Q_{0i}'}{T_0}=0
}
\tag{1}
```

が成立する．

各補助 Carnot サイクルの運転方向と規模を調節し，

```math
\boxed{
Q_i'=-Q_i
}
\tag{2}
```

となるようにする．

可逆な Carnot サイクルは運転方向を逆転させることができ，熱量の規模も任意に調節できるため，この設定は可能である．

式 (1)，式 (2) より，

```math
-\frac{Q_i}{T_i^{(e)}}+
\frac{Q_{0i}'}{T_0}=0
```

となるので，

```math
\boxed{
Q_{0i}'=
T_0\frac{Q_i}{T_i^{(e)}}
}
\tag{3}
```

を得る．

#### 2．複合サイクルの熱量と仕事の関係

元の体系の循環過程と，すべての補助 Carnot サイクル $C_i$ を合わせた複合サイクルを考える．

各元の熱源 $R_i$ が複合サイクルに与える正味の熱量は，

```math
Q_i+Q_i'
```

である．
式 (2) より，

```math
\boxed{
Q_i+Q_i'=0
\quad (i=1,\ldots,n)
}
\tag{4}
```

となる．

したがって，すべての元の熱源は個別に元の状態へ戻る．

一方，補助熱源 $R_0$ が複合サイクルに与える正味の熱量を $H_0$ とすると，

```math
H_0=\sum_{i=1}^{n}Q_{0i}'
```

である．
式 (3) を代入すれば，

```math
\boxed{
H_0=
T_0\sum_{i=1}^{n}
\frac{Q_i}{T_i^{(e)}}
}
\tag{5}
```

を得る．

複合サイクルを構成するすべての体系は循環過程を完了するため，内部エネルギーの正味の変化はゼロである．

第1法則より，複合サイクルが外界にする正味の仕事を $W_0$ とすると，

```math
\Delta U=H_0-W_0=0
```

であるから，

```math
\boxed{
W_0=H_0
}
\tag{6}
```

となる．

したがって，この複合サイクルは，補助熱源 $R_0$ との間で熱量 $H_0$ を授受し，正味の仕事 $H_0$ を外界に供給する．

#### 3．Clausius の原理を適用する

ここで，式 (5) の $H_0$ が正であると仮定する．
すなわち，

```math
H_0>0
```

とする．

式 (6) より，複合サイクルは外界に仕事 $H_0$ を供給する．

この仕事を利用して，さらに別の補助熱源 $R_*$ を導入し，温度を

```math
T_*>T_0
```

とする．

そして，温度 $T_0$ の熱源 $R_0$ から熱を吸収し，温度 $T_*$ の熱源 $R_*$ に熱を放出する可逆 Carnot 冷凍機 $P$ を導入する．

この冷凍機を，先ほどの複合サイクルが供給する仕事 $H_0$ によって駆動する．

冷凍機 $P$ が低温熱源 $R_0$ から受け取る熱量を $Q_c>0$ ，高温熱源 $R_*$ へ放出する熱量の大きさを $Q_h>0$ とする．

冷凍機は一つの循環過程を完了するので，第1法則より，

```math
Q_h=Q_c+H_0
\tag{7}
```

が成立する．

また，可逆 Carnot サイクルの性質から，

```math
\boxed{
\frac{Q_c}{T_0}
=
\frac{Q_h}{T_*}
}
\tag{8}
```

が成立する．

式 (7) を式 (8) に代入すると，

```math
\frac{Q_c}{T_0}
=
\frac{Q_c+H_0}{T_*}
```

となる．
これを整理すれば，

```math
Q_c(T_*-T_0)=T_0H_0
```

を得る．
したがって，

```math
\boxed{
Q_c=
\frac{T_0H_0}{T_*-T_0}>0
}
\tag{9}
```

となる．

さらに，式 (7) より，

```math
\boxed{
Q_h=
\frac{T_*H_0}{T_*-T_0}>0
}
\tag{10}
```

である．

ここで，複合サイクルと冷凍機 $P$ を合わせた全体を考える．

複合サイクルは熱源 $R_0$ から熱量 $H_0$ を受け取り，仕事 $H_0$ を外界に供給する．
冷凍機 $P$ は，その仕事 $H_0$ を受け取り，熱源 $R_0$ から熱量 $Q_c$ を吸収して，熱源 $R_*$ に熱量 $Q_h$ を放出する．

したがって，両者の仕事の授受は相殺され，外界との正味の仕事の授受はゼロとなる．

また，式 (4) より，元の熱源 $R_1,\ldots,R_n$ はすべて個別に元の状態へ戻る．

補助熱源 $R_0$ は，複合サイクルから熱量 $H_0$ ，冷凍機から熱量 $Q_c$ を受け取られるため，合計で

```math
H_0+Q_c
```

の熱を失う．

一方，補助熱源 $R_*$ は冷凍機から熱量 $Q_h$ を受け取る．

式 (7) より，

```math
H_0+Q_c=Q_h
```

である．

したがって，この全体の過程によって外界に生じる変化は，温度 $T_0$ の熱源 $R_0$ から温度 $T_*$ の熱源 $R_*$ へ熱量 $Q_h$ を移すことだけである．

ところが，

```math
T_*>T_0
```

であるから，この過程は，ほかに何の変化も残さずに低温熱源から高温熱源へ熱を移すことに相当する．

これは Clausius の原理に反する．

したがって，最初に仮定した

```math
H_0>0
```

は成立し得ない．
ゆえに，

```math
\boxed{
H_0\leq0
}
\tag{11}
```

でなければならない．

#### 4．Clausius の不等式を導く

式 (5) より，

```math
H_0=
T_0\sum_{i=1}^{n}
\frac{Q_i}{T_i^{(e)}}
```

である．
式 (11) より，

```math
T_0\sum_{i=1}^{n}
\frac{Q_i}{T_i^{(e)}}\leq0
```

となる．

ここで，絶対温度について

```math
T_0>0
```

であるから，両辺を $T_0$ で割っても不等号の向きは変わらない．
したがって，

```math
\boxed{
\displaystyle
\sum_{i=1}^{n}
\frac{Q_i}{T_i^{(e)}}\leq0
}
\tag{2.9}
```

を得る．

以上により，Clausius の原理を用いて Clausius の不等式が証明された．

なお，本証明では元の熱源を一つも合成していないため，複数の熱源が同じ温度である場合も，すべての熱源を個別に元の状態へ戻すことができる．
したがって，熱源の温度が互いに異なるという条件は必要ない．
