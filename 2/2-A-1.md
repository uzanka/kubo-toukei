# 演習問題【2-A-1】

## 解答

外界の各部分は適当に分割することにより，温度がそれぞれ $T_1^{(e)}, T_2^{(e)}, \dots, T_n^{(e)}$ である熱源 $R_1, R_2, \dots, R_n$ の集りと考えることができる．
いま， $C_1, C_2, \dots, C_{n-1}$ で表される $n-1$ 個の Carnot サイクルを考え，それらが次の働きをなすものとする：

- $C_1$ は熱源 $R_1$ と $R_2$ との間にはたらき， $R_1$ から受けとる熱量は $Q_1'$ ， $R_2$ から受けとる熱量は $Q_2''$ である．
- $C_2$ は熱源 $R_2$ と $R_3$ との間にはたらき， $R_2$ から受けとる熱量は $Q_2'$ ， $R_3$ から受けとる熱量は $Q_3''$ である．
- $\dots$
- $C_{n-1}$ は熱源 $R_{n-1}$ と $R_n$ との間にはたらき， $R_{n-1}$ から受けとる熱量は $Q_{n-1}'$ ， $R_n$ から受けとる熱量は $Q_n''$ である．

考える体系の行う循環過程を $C$ と表す．
$C, C_1, C_2, \dots, C_{n-1}$ の全サイクルが完了したとき，熱源 (外界) の失なった熱量はそれぞれ，

- $R_1 : Q_1 + Q_1'$
- $R_2 : Q_2 + Q_2' + Q_2''$
- $\dots$
- $R_{n-1} : Q_{n-1} + Q_{n-1}' + Q_{n-1}''$
- $R_n : Q_n + Q_n''$

である．
ゆえに第 1 法則により考える体系が外界から受けとった仕事の全体 $A$ は

$$ A = -\{(Q_1 + Q_1') + (Q_2 + Q_2' + Q_2'') + \dots + (Q_n + Q_n'')\} \quad \cdots (1) $$

となる．
ここで，Carnot サイクル $C_1, C_2, \dots, C_{n-1}$ を適当に調節して， $2(n-1)$ 個の量 $Q_1', \dots, Q_{n-1}'; Q_2'', \dots, Q_n''$ を次の式が満足されるようにとることにする．

$$
\begin{cases}
Q_2 + Q_2' + Q_2'' = 0 \\
Q_3 + Q_3' + Q_3'' = 0 \\
\dots \\
Q_{n-1} + Q_{n-1}' + Q_{n-1}'' = 0
\end{cases} \quad \cdots (2)
$$

このとき，式 (1) の総和の中から $C_1, \dots, C_{n-1}$ の各サイクルの熱量変化（式 (2) の各行）を差し引くと，残るのは $R_1$ と $R_n$ に関する項のみとなる．

$$ A = -\{(Q_1 + Q_1') + (Q_n + Q_n'')\} \quad \cdots (2)' $$

したがって， $Q_1 + Q_1' + Q_n + Q_n'' = 0$ が成り立つ．

これらの式は Carnot サイクルにおいて常に成り立つ関係式

$$
\begin{cases}
\frac{Q_1'}{T_1^{(e)}} + \frac{Q_2''}{T_2^{(e)}} = 0 \\
\dots \\
\frac{Q_{n-1}'}{T_{n-1}^{(e)}} + \frac{Q_n''}{T_n^{(e)}} = 0
\end{cases} \quad \cdots (3)
$$

とあわせて $2(n-1)$ 個の独立な方程式となる．
$Q_1, \dots, Q_n$ は与えられた定数であるから，これら $2(n-1)$ 個の未知数 $Q_1', \dots, Q_n''$ を調整して (2) と (3) を同時に満たすことは一般に可能である．

(2) の各式にそれぞれ $-1/T_2^{(e)}, \dots, -1/T_{n-1}^{(e)}$ を掛け，これらすべてと (3) の式をすべて加算すると，次のような関係が得られる．

$$ \frac{Q_1'}{T_1^{(e)}} + \frac{Q_n''}{T_n^{(e)}} = \sum_{i=2}^{n-1} \frac{Q_i}{T_i^{(e)}} \quad \cdots (4) $$

ここで，Clausius の原理を適用する．
いま， $T_n^{(e)} > T_1^{(e)}$ であると仮定すると，Clausius の原理は

$$ Q_n + Q_n'' \ge 0, \quad Q_1 + Q_1' \le 0 \quad \cdots (5) $$

であることを要求する．
式 (2)' より $Q_n + Q_n'' = -(Q_1 + Q_1')$ であるから，これを用いると，

$$ \frac{Q_n + Q_n''}{T_n^{(e)}} \le -\frac{Q_1 + Q_1'}{T_1^{(e)}} \quad \cdots (6) $$

となる．
左辺を展開すると，

$$ \frac{Q_n}{T_n^{(e)}} + \frac{Q_n''}{T_n^{(e)}} \le -\frac{Q_1}{T_1^{(e)}} - \frac{Q_1'}{T_1^{(e)}} $$

$$ \frac{Q_1'}{T_1^{(e)}} + \frac{Q_n''}{T_n^{(e)}} \le -\left( \frac{Q_1}{T_1^{(e)}} + \frac{Q_n}{T_n^{(e)}} \right) \quad \cdots (6)' $$

(6)' と (4) を合わせると，

$$ \sum_{i=2}^{n-1} \frac{Q_i}{T_i^{(e)}} \le -\left( \frac{Q_1}{T_1^{(e)}} + \frac{Q_n}{T_n^{(e)}} \right) $$

$$ \sum_{i=2}^{n-1} \frac{Q_i}{T_i^{(e)}} + \frac{Q_1}{T_1^{(e)}} + \frac{Q_n}{T_n^{(e)}} \le 0 $$

$$ \sum_{i=1}^{n} \frac{Q_i}{T_i^{(e)}} \le 0 \quad \cdots (7) $$

が証明される．
この不等号は (5) 式の不等号に由来するものであり，等号は過程が可逆であるときに限る．

## 解説

### 1. Clausius の原理とは

Clausius の原理とは，「温度の異なる熱源間で熱をやり取りする循環過程において，外界（熱源）が失った熱量の合計を温度で重み付けして足し合わせると，その値は $0$ 以下になる」という原理である．
数式では $\sum \frac{Q_i}{T_i} \le 0$ と表される．
これは熱力学第二法則の定式化の一つである．

### 2. 証明の戦略：中間熱源の導入

この証明では， $n$ 個の熱源がある複雑な系を，複数の Carnot サイクル（ $C_1, C_2, \dots$ ）を組み合わせた系として捉え直している．
Carnot サイクルは「可逆な熱機関」であり，その性質として $\frac{Q_{in}}{T_{high}} + \frac{Q_{out}}{T_{low}} = 0$ という関係を満たす．
これを利用して，熱源 $R_2$ から $R_{n-1}$ までの熱量変化を「中継」させることで，最終的に端っこの $R_1$ と $R_n$ だけの関係に集約させている．

### 3. 数学的なポイント

- **自由度の活用** :
  $2(n-1)$ 個の未知数（各 Carnot サイクルが受け取る熱量）を用意し，それらを $2(n-1)$ 個の方程式（熱量保存則と可逆性の条件）に当てはめることで，任意の設定に対して「中継」が可能な Carnot サイクルが存在することを示している．
- **不等式の合成** :
  全ての熱源の寄与を足し合わせる際，中間の熱源については Carnot サイクルの性質によって項が相殺（または整理）され，最終的にすべての熱源の項を含む不等式が導かれる．
