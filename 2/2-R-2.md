# 例題【2-R-2】

## 解答

### 状態方程式 $p=f(V)T$ における内部エネルギーの体積依存性

#### 1．熱力学第一法則からエントロピーの全微分を求める

内部エネルギーを $U$ ，エントロピーを $S$ ，圧力を $p$ ，体積を $V$ ，絶対温度を $T$ とする．
物質量が一定の単純圧縮系を考える．熱力学第一法則は，

```math
dU=\delta Q-p\,dV
```

と表される．
ここで， $\delta Q$ は系に加えられる微小な熱量である．
可逆な準静的過程では $\delta Q=T\,dS$ であるため，

```math
dU=T\,dS-p\,dV
```

となる．
これをエントロピー $S$ について解けば，

```math
\boxed{
dS=\frac{1}{T}\,dU+\frac{p}{T}\,dV
}
\tag{1}
```

を得る．
この関係式は，平衡状態の状態量の間に成り立つ関係式である．

#### 2．エントロピーの完全微分条件を適用する

内部エネルギーを温度と体積の関数 $U=U(T,V)$ として表すと，その全微分は，

```math
dU=
\left(\frac{\partial U}{\partial T}\right)_V dT
+
\left(\frac{\partial U}{\partial V}\right)_T dV
```

である．
これを式 (1) に代入すると，

```math
\begin{aligned}
dS={}&
\frac{1}{T}
\left(\frac{\partial U}{\partial T}\right)_V dT\\
&+\left[
\frac{1}{T}\left(\frac{\partial U}{\partial V}\right)_T
+\frac{p}{T}
\right]dV
\end{aligned}
\tag{2}
```

となる．

ここで，エントロピー $S$ は状態量である．
すなわち，その値は状態によって定まり，変化の経路には依存しない．
したがって， $S=S(T,V)$ の全微分 $dS$ は完全微分である．

式 (2) を

```math
dS=M(T,V)\,dT+N(T,V)\,dV
```

と書くと，

```math
M(T,V)=\frac{1}{T}
\left(\frac{\partial U}{\partial T}\right)_V
```

および

```math
N(T,V)=
\frac{1}{T}\left(\frac{\partial U}{\partial V}\right)_T
+\frac{p}{T}
```

である．
完全微分であるための条件は，

```math
\boxed{
\left(\frac{\partial M}{\partial V}\right)_T
=
\left(\frac{\partial N}{\partial T}\right)_V
}
\tag{3}
```

となる．

まず，式 (3) の左辺を計算する．温度 $T$ を一定に保つと，

```math
\left(\frac{\partial M}{\partial V}\right)_T
=
\frac{1}{T}
\frac{\partial^2 U}{\partial V\,\partial T}
\tag{4}
```

である．

次に，右辺を計算する．式 (2) の $N$ を温度 $T$ で微分すると，

```math
\begin{aligned}
\left(\frac{\partial N}{\partial T}\right)_V
={}&
\frac{\partial}{\partial T}
\left[
\frac{1}{T}
\left(\frac{\partial U}{\partial V}\right)_T
\right]_V\\
&+\left(\frac{\partial}{\partial T}\frac{p}{T}\right)_V
\end{aligned}
```

となる．
第1項には積の微分法則を適用する．
その結果，

```math
\begin{aligned}
\left(\frac{\partial N}{\partial T}\right)_V
={}&-\frac{1}{T^2}
\left(\frac{\partial U}{\partial V}\right)_T\\
&+\frac{1}{T}
\frac{\partial^2 U}{\partial T\,\partial V}
+\left(\frac{\partial}{\partial T}\frac{p}{T}\right)_V
\end{aligned}
\tag{5}
```

を得る．

ここで，内部エネルギー $U(T,V)$ の二階偏導関数が連続であると仮定すると，混合偏導関数の順序を交換できる．
すなわち，

```math
\frac{\partial^2 U}{\partial V\,\partial T}
=
\frac{\partial^2 U}{\partial T\,\partial V}
```

である．
式 (4)，(5) を式 (3) に代入すると，両辺に現れる混合偏導関数の項が打ち消し合い，

```math
0=
-\frac{1}{T^2}
\left(\frac{\partial U}{\partial V}\right)_T
+\left(\frac{\partial}{\partial T}\frac{p}{T}\right)_V
```

となる．
これを整理すれば，

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_T
=
T^2\left(\frac{\partial}{\partial T}\frac{p}{T}\right)_V
}
\tag{6}
```

を得る．
これは，単純圧縮系に対して成り立つ熱力学恒等式である．

さらに，右辺を展開すると，

```math
\left(\frac{\partial}{\partial T}\frac{p}{T}\right)_V
=
\frac{1}{T}\left(\frac{\partial p}{\partial T}\right)_V
-\frac{p}{T^2}
```

であるため，式 (6) は次のようにも書ける．

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_T
=
T\left(\frac{\partial p}{\partial T}\right)_V-p
}
\tag{7}
```

#### 3．与えられた状態方程式を代入する

問題では，状態方程式が

```math
p=f(V)T
```

で与えられている．
ここで， $f(V)$ は体積 $V$ のみの関数であり，温度 $T$ には依存しない．
したがって，

```math
\frac{p}{T}=f(V)
```

である．
体積 $V$ を一定に保ったとき，右辺は温度 $T$ に依存しないので，

```math
\left(\frac{\partial}{\partial T}\frac{p}{T}\right)_V
=
\left(\frac{\partial f(V)}{\partial T}\right)_V
=0
```

となる．
これを式 (6) に代入すると，

```math
\left(\frac{\partial U}{\partial V}\right)_T
=T^2\times0=0
```

を得る．
すなわち，

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_T=0
}
```

である．

#### 4．結論

```math
\left(\frac{\partial U}{\partial V}\right)_T=0
```

という結果は，温度 $T$ を一定に保って体積 $V$ を変化させても，内部エネルギー $U$ は変化しないことを意味する．
したがって，考える状態領域では内部エネルギーは体積に依存せず，

```math
\boxed{
U=U(T)
}
```

と表される．

以上により，状態方程式が $p=f(V)T$ の形である物質では，内部エネルギーが体積 $V$ に無関係であることが示された．
