# 演習問題【2-A-19】

## 解答

25℃の水1 molを，温度一定のもとで圧力 $p_1=1$ atm から $p_2=1000$ atm まで準静的かつ可逆的に圧縮する．
このとき，外部から系になされる仕事を $A$ ，系が吸収する熱量を $Q$ ，内部エネルギーの変化を $\Delta U$ とする．
外部からなされる仕事と系に流入する熱量を正とする．

温度は解答例に従って $T=298$ K と近似する．
また，単位換算には，

```math
1\ \mathrm{atm\,cm^3}=0.101325\ \mathrm{J}
```

を用いる．

### 1．圧縮に必要な仕事 $A$

水の体積 $V$ は圧力 $p$ の関数として，

```math
V=a+bp+cp^2
```

と与えられている．
係数は，

```math
\begin{aligned}
a&=18.066,\\
b&=-0.000715,\\
c&=0.000000046
\end{aligned}
```

である．

体積を圧力で微分すると，

```math
dV=(b+2cp)\,dp
```

となる．
外部から系になされる仕事は，

```math
A=-\int_{V_1}^{V_2}p\,dV
```

であるため，圧力を積分変数に変換すると，

```math
A=-\int_{1}^{1000}p(b+2cp)\,dp
```

となる．
これを積分すれば，

```math
A=-\left[
\frac{b}{2}p^2+\frac{2c}{3}p^3
\right]_{1}^{1000}
```

を得る．
係数を代入すると，

```math
\begin{aligned}
A
&=-\left[
\frac{-0.000715}{2}(1000^2-1)
+\frac{2(0.000000046)}{3}(1000^3-1)
\right]\\
&\simeq326.833\ \mathrm{atm\,cm^3/mol}
\end{aligned}
```

である．
これをジュールに換算すると，

```math
\begin{aligned}
A
&=326.833\times0.101325\\
&\simeq33.12\ \mathrm{J/mol}
\end{aligned}
```

となる．
したがって，圧縮に必要な仕事は，

```math
\boxed{
A\simeq33.1\ \mathrm{J/mol}
}
```

である．

### 2．圧縮過程での熱量 $Q$

次に，内部エネルギーの変化を求めるために，系が吸収する熱量 $Q$ を計算する．
準静的かつ可逆な等温過程では，

```math
\delta Q_{\mathrm{rev}}=T\,dS
```

であるため，

```math
Q=T\Delta S
```

と表される．

ここで，Maxwell の関係式

```math
\left(\frac{\partial S}{\partial p}\right)_T
=-\left(\frac{\partial V}{\partial T}\right)_p
```

を用いる．
温度一定のもとで圧力を $1$ atm から $1000$ atm まで変化させると，

```math
\begin{aligned}
\Delta S
&=\int_{1}^{1000}
\left(\frac{\partial S}{\partial p}\right)_Tdp\\
&=-\int_{1}^{1000}
\left(\frac{\partial V}{\partial T}\right)_pdp
\end{aligned}
```

となる．
与えられた関係式

```math
\left(\frac{\partial V}{\partial T}\right)_p
=0.0045+0.0000014p
```

を代入すると，

```math
\Delta S
=-\int_{1}^{1000}(0.0045+0.0000014p)\,dp
```

である．
積分を実行すると，

```math
\begin{aligned}
\Delta S
&=-\left[
0.0045p+0.0000007p^2
\right]_{1}^{1000}\\
&=-(4.5+0.7-0.0045007)\\
&\simeq-5.1954993
\end{aligned}
```

となる．
この値は，圧力を atm で表したときの数値であり，温度微分の与えられた単位を考慮すると，エントロピー変化の単位は $\mathrm{atm\,cm^3/(mol\,K)}$ に相当する．

したがって，熱量は，

```math
Q=T\Delta S
\simeq-298\times5.1954993
```

より，

```math
Q\simeq-1548.26\ \mathrm{atm\,cm^3/mol}
```

である．
ジュールに換算すると，

```math
\begin{aligned}
Q
&=-1548.26\times0.101325\\
&\simeq-156.88\ \mathrm{J/mol}
\end{aligned}
```

を得る．
よって，

```math
\boxed{
Q\simeq-156.9\ \mathrm{J/mol}
}
```

である．
負号は，圧縮時に水が外部へ熱を放出することを意味する．

### 3．内部エネルギーの変化 $\Delta U$

熱力学第1法則より，

```math
\Delta U=A+Q
```

である．
先ほど求めた仕事と熱量を代入すると，

```math
\begin{aligned}
\Delta U
&=33.116-156.877\\
&\simeq-123.761\ \mathrm{J/mol}
\end{aligned}
```

となる．
したがって，内部エネルギーの変化は，

```math
\boxed{
\Delta U\simeq-123.8\ \mathrm{J/mol}
}
```

である．

以上より，水1 molを25℃で1 atmから1000 atmまで圧縮するのに必要な仕事は約 $33.1$ J/molであり，内部エネルギーは約 $123.8$ J/mol減少する．

なお，25℃をより厳密に $298.15$ K として計算しても，丸め後の結論はほぼ同じである．
また，解答例のように積分範囲の下限を $0$ atm と近似すると， $Q\simeq-157.0$ J/mol， $\Delta U\simeq-123.9$ J/molとなるが，初期圧力を $1$ atm とした厳密な積分では，上記の値が得られる．
