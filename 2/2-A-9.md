# 演習問題【2-A-9】

## 解答

1 mol の理想気体を考え，定圧モル熱容量を $C_p$ ，定積モル熱容量を $C_v$ とする．
また，両者の比を

```math
\gamma=\frac{C_p}{C_v}
```

と定義する．
以下では，まず $C_p,C_v$ が温度によらず一定である場合を考える．

エントロピーの微小変化は，可逆過程に対して，

```math
dS=\frac{\delta Q_{\mathrm{rev}}}{T}
```

と表される．
ここで， $\delta Q_{\mathrm{rev}}$ は系が吸収する微小熱量， $T$ は絶対温度である．熱力学第1法則より，

```math
dU=\delta Q_{\mathrm{rev}}-p\,dV
```

であるから，

```math
\delta Q_{\mathrm{rev}}=dU+p\,dV
\tag{1}
```

となる．

### 1．第1の場合：圧力一定の過程

まず，圧力を一定に保ちながら温度を $T_1$ から $T_2$ に上げる過程を考える．
定圧過程では，

```math
dp=0
```

である．

理想気体の内部エネルギーは温度だけの関数であるため，

```math
dU=C_v\,dT
\tag{2}
```

となる．
また，1 mol の理想気体の状態方程式は，

```math
pV=RT
```

である．
これを微分すると，

```math
p\,dV+V\,dp=R\,dT
```

となる．
定圧過程では $dp=0$ であるから，

```math
p\,dV=R\,dT
\tag{3}
```

を得る．

式 (1)，(2)，(3) を用いると，定圧過程で気体が吸収する微小熱量は，

```math
\begin{aligned}
\delta Q_{\mathrm{rev}}
&=dU+p\,dV\\
&=C_v\,dT+R\,dT\\
&=(C_v+R)\,dT
\end{aligned}
```

となる．
ここで，1 mol の理想気体に対する Mayer の関係式

```math
C_p=C_v+R
```

を用いれば，

```math
\delta Q_{\mathrm{rev}}=C_p\,dT
```

となる．
したがって，定圧過程におけるエントロピーの微小変化は，

```math
dS_p=\frac{C_p}{T}\,dT
```

である．
これを温度 $T_1$ から $T_2$ まで積分すると，

```math
\begin{aligned}
\Delta S_p
&=\int_{T_1}^{T_2}\frac{C_p}{T}\,dT\\
&=C_p\int_{T_1}^{T_2}\frac{1}{T}\,dT\\
&=C_p\ln\frac{T_2}{T_1}
\end{aligned}
```

を得る．
よって，第1の場合のエントロピー増分は，

```math
\boxed{
\Delta S_p=C_p\ln\frac{T_2}{T_1}
}
\tag{4}
```

である．

### 2．第2の場合：体積一定の過程

次に，体積を一定に保ちながら温度を $T_1$ から $T_2$ に上げる過程を考える．
定積過程では，

```math
dV=0
```

である．
したがって，気体が外部にする微小仕事は $p\,dV=0$ となり，熱力学第1法則より，

```math
\delta Q_{\mathrm{rev}}=dU
```

である．
式 (2) より $dU=C_v\,dT$ であるから，

```math
\delta Q_{\mathrm{rev}}=C_v\,dT
```

となる．
よって，定積過程におけるエントロピーの微小変化は，

```math
dS_v=\frac{C_v}{T}\,dT
```

である．
これを $T_1$ から $T_2$ まで積分すると，

```math
\begin{aligned}
\Delta S_v
&=\int_{T_1}^{T_2}\frac{C_v}{T}\,dT\\
&=C_v\int_{T_1}^{T_2}\frac{1}{T}\,dT\\
&=C_v\ln\frac{T_2}{T_1}
\end{aligned}
```

を得る．
したがって，第2の場合のエントロピー増分は，

```math
\boxed{
\Delta S_v=C_v\ln\frac{T_2}{T_1}
}
\tag{5}
```

である．

### 3．エントロピー増分の比

式 (4)，(5) より，定圧過程と定積過程におけるエントロピー増分の比は，

```math
\begin{aligned}
\frac{\Delta S_p}{\Delta S_v}
&=\frac{C_p\ln(T_2/T_1)}
{C_v\ln(T_2/T_1)}\\
&=\frac{C_p}{C_v}
\end{aligned}
```

となる．
ここで，

```math
\gamma=\frac{C_p}{C_v}
```

であるから，

```math
\boxed{
\frac{\Delta S_p}{\Delta S_v}=\gamma
}
```

を得る．

したがって，

```math
\boxed{
\Delta S_p=\gamma\,\Delta S_v
}
```

であり，温度を $T_1$ から $T_2$ に上げるとき，定圧過程におけるエントロピーの増し高は，定積過程におけるエントロピーの増し高の $\gamma$ 倍であることが示された．


## 解説

この結論は， $C_p,C_v$ が温度範囲内で一定である場合に成立する．
より一般に両者が温度に依存しても， $C_p(T)/C_v(T)=\gamma$ が一定であれば，

```math
\Delta S_p=\int_{T_1}^{T_2}\frac{C_p(T)}{T}\,dT
=\gamma\int_{T_1}^{T_2}\frac{C_v(T)}{T}\,dT
=\gamma\,\Delta S_v
```

となり，同じ結論が得られる．
