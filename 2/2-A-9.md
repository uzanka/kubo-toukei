# 演習問題【2-A-9】

## 解答

理想気体のエントロピーの変化 $dS$ は，熱力学第一法則 $dU = d'Q - p dV$ を用いて次のように書き表せる．

$$dS = \frac{d'Q}{T} = \frac{dU + p dV}{T}$$

ここで，理想気体の内部エネルギーの変化は $dU = C_v dT$ であり，また，定圧比熱 $C_p$ と定積比熱 $C_v$ の間には $C_p = C_v + R$ （ $n=1$ のとき）の関係がある．

### 1. 第 1 の場合：圧力一定の過程 ( $p = \text{const.}$ )

圧力一定の過程では， $dp = 0$ である．
このとき，熱力学第一法則において $d'Q = C_p dT$ となる．
（※理由： $dU + p dV = C_v dT + p dV$ であり， $pV = RT$ より $p dV = R dT + T dp$ ．
$dp=0$ のとき $p dV = R dT$ なので， $dU + p dV = C_v dT + R dT = (C_v + R) dT = C_p dT$ となる．）

したがって，エントロピーの変化 $dS_1$ は，

$$dS_1 = \frac{C_p dT}{T}$$

これを温度 $T_1$ から $T_2$ まで積分すると，

$$\Delta S_1 = \int_{T_1}^{T_2} \frac{C_p}{T} dT = C_p \log \left( \frac{T_2}{T_1} \right)$$

が得られる．

### 2. 第 2 の場合：体積一定の過程 ( $V = \text{const.}$ )

体積一定の過程では， $dV = 0$ である．
このとき，仕事 $dW = p dV = 0$ であるから，熱力学第一法則より $d'Q = dU = C_v dT$ となる．

したがって，エントロピーの変化 $dS_2$ は，

$$dS_2 = \frac{C_v dT}{T}$$

これを温度 $T_1$ から $T_2$ まで積分すると，

$$\Delta S_2 = \int_{T_1}^{T_2} \frac{C_v}{T} dT = C_v \log \left( \frac{T_2}{T_1} \right)$$

が得られる．

### 3. 比の計算

第 1 の場合と第 2 の場合の比をとると，

$$\frac{\Delta S_1}{\Delta S_2} = \frac{C_p \log (T_2/T_1)}{C_v \log (T_2/T_1)} = \frac{C_p}{C_v}$$

問題の定義より $\gamma = C_p/C_v$ であるから，

$$\frac{\Delta S_1}{\Delta S_2} = \gamma$$

となり，第 1 の場合のエントロピーの増し高は第 2 の場合の $\gamma$ 倍であることが示された．

## 解説

### 1. 定圧過程と定積過程の違い

同じ温度上昇 $\Delta T$ を与える場合でも，過程によって必要な熱量やエントロピーの変化が異なる．
- **定積過程** では，体積が変わらないため，与えた熱はすべて内部エネルギー（温度）の増加に使わる．
- **定圧過程** では，温度が上がるのと同時に体積も膨張するため，与えた熱の一部は外部への仕事として使わる．
  そのため，同じ温度上昇を得るためには，定積過程よりも多くの熱を供給する必要がある．

### 2. エントロピーと比熱の関係

エントロピーは「乱雑さ」の尺度である．
定圧過程では，温度が上がるだけでなく体積も拡大して分子が動ける空間が増えるため，定積過程に比べてエントロピーの増加量が大きくなる．
その比が，比熱の比 $\gamma$ に一致するという結果は，熱力学的なエネルギーの分配がエントロピーの変化に直接反映されていることを示している．

### 3. $\gamma$ の物理的意味

$\gamma = C_p/C_v$ は，気体の「膨張しやすさ」や「エネルギーの蓄え方」に関連する定数である．
この値が大きいほど，定圧過程において体積変化による仕事への寄与が大きくなることを意味する．
