# 演習問題【2-A-10】

## 解答

実験結果より，圧力 $p$ と比容 $v$ の積は温度 $T$ のみの関数であり，内部エネルギー $u$ も温度 $T$ のみの関数である．
すなわち，

```math
pv=f(T),\qquad u=u(T)
```

と表される．
ここで，比容 $v$ は単位質量当たりの体積，比内部エネルギー $u$ は単位質量当たりの内部エネルギーである．
以下では，絶対温度 $T$ を用いる．

この2つの条件と熱力学の基本関係式から，状態方程式の形を導く．

### 1．熱力学の基本関係式を用いる

単位質量当たりのエントロピーを $s$ とすると，熱力学の基本関係式は，

```math
T\,ds=du+p\,dv
\tag{1}
```

である．

ここで，温度 $T$ を一定に保った変化を考える．
このとき， $u$ と $s$ の微小変化はそれぞれ，

```math
du=\left(\frac{\partial u}{\partial v}\right)_Tdv
```

および

```math
ds=\left(\frac{\partial s}{\partial v}\right)_Tdv
```

と表される．
これらを式 (1) に代入すると，

```math
T\left(\frac{\partial s}{\partial v}\right)_Tdv
=
\left(\frac{\partial u}{\partial v}\right)_Tdv
+p\,dv
```

となる．
両辺の $dv$ の係数を比較すれば，

```math
T\left(\frac{\partial s}{\partial v}\right)_T
=
\left(\frac{\partial u}{\partial v}\right)_T+p
\tag{2}
```

を得る．

問題の条件より，内部エネルギー $u$ は温度 $T$ のみの関数である．
したがって，温度を一定にしたとき，体積を変化させても内部エネルギーは変化しない．
すなわち，

```math
\left(\frac{\partial u}{\partial v}\right)_T=0
```

である．
これを式 (2) に代入すると，

```math
T\left(\frac{\partial s}{\partial v}\right)_T=p
\tag{3}
```

となる．

### 2．Maxwell の関係式を用いる

式 (3) に含まれるエントロピーの偏微分を，圧力の偏微分に置き換える．
そのために，Maxwell の関係式を導く．

単位質量当たりのヘルムホルツ自由エネルギー $a$ を，

```math
a=u-Ts
```

と定義する．
これを微分すると，

```math
da=du-T\,ds-s\,dT
```

である．
式 (1) より $du-T\,ds=-p\,dv$ であるから，

```math
da=-s\,dT-p\,dv
\tag{4}
```

となる．

一方， $a$ は状態量であり，温度 $T$ と比容 $v$ の関数であるため，その全微分は，

```math
da=
\left(\frac{\partial a}{\partial T}\right)_v dT
+
\left(\frac{\partial a}{\partial v}\right)_T dv
```

と書ける．
式 (4) と比較すると，

```math
\left(\frac{\partial a}{\partial T}\right)_v=-s,
\qquad
\left(\frac{\partial a}{\partial v}\right)_T=-p
```

である．
ここで， $a$ の混合二階偏微分の順序を交換できることを用いると，

```math
\frac{\partial}{\partial v}
\left(\frac{\partial a}{\partial T}\right)_v
=
\frac{\partial}{\partial T}
\left(\frac{\partial a}{\partial v}\right)_T
```

となる．
したがって，

```math
-\left(\frac{\partial s}{\partial v}\right)_T
=
-\left(\frac{\partial p}{\partial T}\right)_v
```

より，Maxwell の関係式

```math
\boxed{
\left(\frac{\partial s}{\partial v}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_v
}
\tag{5}
```

を得る．

式 (5) を式 (3) に代入すると，

```math
T\left(\frac{\partial p}{\partial T}\right)_v=p
```

すなわち，

```math
\boxed{
T\left(\frac{\partial p}{\partial T}\right)_v=p
}
\tag{6}
```

となる．

### 3．状態方程式の形を求める

問題の条件 $pv=f(T)$ より，圧力 $p$ は，

```math
p=\frac{f(T)}{v}
```

と表される．
これを温度 $T$ について，比容 $v$ を一定に保って偏微分すると，

```math
\left(\frac{\partial p}{\partial T}\right)_v
=
\frac{1}{v}\frac{df}{dT}
```

を得る．

これを式 (6) に代入すると，

```math
T\frac{1}{v}\frac{df}{dT}
=
\frac{f(T)}{v}
```

である．
両辺に $v$ を掛けて整理すれば，

```math
T\frac{df}{dT}=f(T)
\tag{7}
```

となる．

ここで，式 (7) を変形すると，

```math
\frac{d}{dT}\left(\frac{f(T)}{T}\right)
=
\frac{T\frac{df}{dT}-f(T)}{T^2}
=0
```

である．
したがって， $f(T)/T$ は温度によらない定数である．
この定数を $A$ とおけば，

```math
\frac{f(T)}{T}=A
```

より，

```math
f(T)=AT
```

を得る．

もとの条件 $pv=f(T)$ に代入すると，

```math
\boxed{
pv=AT
}
```

となる．
これが求める状態方程式の形である．

### 4．結論

与えられた実験結果と熱力学の基本関係式から，この気体の状態方程式は，

```math
\boxed{
pv=AT\qquad (A=\text{定数})
}
```

という形でなければならないことが示された．

これは理想気体の状態方程式と同じ形である．
ただし，比容 $v$ を用いているため，定数 $A$ は単位質量当たりの気体定数に相当する．
その具体的な値は，与えられた条件だけでは決まらない．

## 解説

この気体について熱力学から導ける状態方程式の形は $pv=AT$ である．
すなわち，圧力と比容の積が絶対温度に比例することまでは示せるが，比例定数 $A$ の具体的な値までは決定できない．
