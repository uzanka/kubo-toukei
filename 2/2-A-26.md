# 演習問題【2-A-26】

## 解答

### 1．等温磁化における磁化熱

Curie の法則より，磁化率 $\chi$ と磁化 $M$ の間には

```math
\chi=\frac{M}{H}=\frac{C}{T}
```

の関係がある．
したがって，

```math
M=\frac{CH}{T}
\tag{1}
```

である．
ここで， $C>0$ は Curie 定数である．
以下では，解答例と同じく単位体積あたりの量を考え，磁気仕事の符号規約を

```math
dU=d'Q+H\,dM
\tag{2}
```

とする．
ここで， $d'Q$ は物質が外部から吸収する微小熱量， $H\,dM$ は外部が物質に対して行う微小磁気仕事である．

内部エネルギーは

```math
U=aT^4
```

で与えられる．
等温磁化では $T=T_1$ 一定であるため，内部エネルギーは変化せず，

```math
dU=0
```

となる．
よって，式 (2) から

```math
d'Q=-H\,dM
\tag{3}
```

を得る．

式 (1) において温度を $T_1$ に保つと，

```math
M=\frac{CH}{T_1},
\qquad
dM=\frac{C}{T_1}\,dH
```

である．
これを式 (3) に代入すれば，

```math
d'Q=-\frac{C}{T_1}H\,dH
```

となる．
磁場を $H=0$ から $H=H_1$ まで変化させるとき，物質が吸収する全熱量 $Q$ は

```math
\begin{aligned}
Q
&=\int_0^{H_1}d'Q\\
&=-\frac{C}{T_1}\int_0^{H_1}H\,dH\\
&=-\frac{C}{T_1}
\left[\frac{H^2}{2}\right]_0^{H_1}\\
&=-\frac{CH_1^2}{2T_1}
\end{aligned}
```

である．
したがって，

```math
\boxed{
Q=-\frac{CH_1^2}{2T_1}
}
```

となる．
負号は物質が熱を吸収するのではなく，外部へ放出することを意味する．
よって，磁化によって外部に放出される熱量の大きさ，すなわち磁化熱は

```math
\boxed{
-Q=\frac{CH_1^2}{2T_1}
}
```

である．

### 2．エントロピーの導出

次に，断熱消磁後の温度を求めるため，温度 $T$ と磁場 $H$ を用いてエントロピー $S$ を表す．

式 (2) と，準静的な可逆過程に対する関係式

```math
d'Q=T\,dS
```

から，

```math
dU=T\,dS+H\,dM
```

を得る．
これを $dS$ について整理すると，

```math
dS=\frac{1}{T}dU-\frac{H}{T}dM
\tag{4}
```

である．

内部エネルギー $U=aT^4$ の全微分は

```math
dU=4aT^3\,dT
```

である．
また，式 (1) より，

```math
M=\frac{CH}{T}
```

であるから，

```math
dM=C\,d\left(\frac{H}{T}\right)
```

となる．
このように $H/T$ をひとまとまりの変数として扱うと，式 (4) の積分が簡単になる．
これらを式 (4) に代入すると，

```math
dS=4aT^2\,dT
-C\frac{H}{T}\,d\left(\frac{H}{T}\right)
\tag{5}
```

を得る．

式 (5) の右辺をそれぞれ積分すれば，

```math
\int 4aT^2\,dT=\frac{4}{3}aT^3
```

および

```math
-\int C\frac{H}{T}\,d\left(\frac{H}{T}\right)
=-\frac{C}{2}\left(\frac{H}{T}\right)^2
```

となる．
したがって，エントロピーは

```math
\boxed{
S(T,H)=\frac{4}{3}aT^3
-\frac{C}{2}\left(\frac{H}{T}\right)^2
+S_0
}
\tag{6}
```

と表される．
ここで $S_0$ は積分定数である．

### 3．断熱消磁後の温度

磁場を $H_1$ から $0$ に戻す断熱過程を考える．
ここでは準静的かつ可逆な断熱消磁を想定するため，エントロピーは一定である．
初期状態を $(T_1,H_1)$ ，終状態を $(T_2,0)$ とすると，

```math
S(T_1,H_1)=S(T_2,0)
```

である．
式 (6) を代入すると，

```math
\frac{4}{3}aT_1^3
-\frac{C}{2}\left(\frac{H_1}{T_1}\right)^2
=
\frac{4}{3}aT_2^3
```

となる．
これを $T_2$ について整理すれば，

```math
\frac{4}{3}aT_2^3
=
\frac{4}{3}aT_1^3
-\frac{C}{2}\left(\frac{H_1}{T_1}\right)^2
```

したがって，

```math
\boxed{
T_2^3=T_1^3-\frac{3C}{8a}
\left(\frac{H_1}{T_1}\right)^2
}
\tag{7}
```

である．
このモデルが有効で，式 (7) の右辺が正である範囲では，

```math
0<T_2<T_1
```

となる．
すなわち，磁場をゼロに戻すと温度が低下する．
これが断熱消磁による冷却である．

### 4．磁場が小さい場合の近似

$H_1$ が十分小さく，温度変化が $T_1$ に比べて小さい場合を考える．
式 (7) を用いると，

```math
T_2
=T_1\left[
1-\frac{3CH_1^2}{8aT_1^5}
\right]^{1/3}
```

となる．

ここで，

```math
\varepsilon=\frac{3CH_1^2}{8aT_1^5}
```

と置く．
$\varepsilon\ll1$ ならば，二項展開

```math
(1-\varepsilon)^{1/3}
\simeq 1-\frac{\varepsilon}{3}
```

を用いることができる．
したがって，

```math
\begin{aligned}
T_2
&\simeq T_1\left(
1-\frac{CH_1^2}{8aT_1^5}
\right)\\
&=T_1-\frac{CH_1^2}{8aT_1^4}
\end{aligned}
```

となる．
よって，温度変化 $\Delta T=T_2-T_1$ は

```math
\boxed{
\Delta T\simeq-\frac{CH_1^2}{8aT_1^4}
}
```

である．
負号は，断熱消磁によって温度が低下することを表している．

### 5．モデルの適用範囲と熱力学第三法則

式 (7) によれば， $H_1$ を十分大きくすると右辺がゼロ以下になることがある．
この場合，式 (7) から正の温度をもつ終状態を求めることはできない．
これは実際に温度が負になることを意味するのではなく，ここで用いたモデルがその条件では適用できないことを示している．

実際，式 (6) の磁場に依存する項は， $T$ がゼロに近づくと，固定された非ゼロの磁場に対して発散する．
したがって，このエントロピーの表式は，熱力学第三法則と整合する絶対零度近傍の振る舞いを記述していない．
Curie の法則 $M=CH/T$ も，極低温まで無制限に適用できるわけではない．

そのため，式 (7) と近似式は，モデルが有効な温度・磁場の範囲でのみ用いる必要がある．
実際の断熱消磁では，絶対零度を有限の操作で到達することはできず，極低温では磁化率や熱容量などの温度依存性をより正確に取り扱う必要がある．
