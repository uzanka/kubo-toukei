# 演習問題【2-A-2】

## 解答

熱量 $Q$ は系に流入する熱量を正とし，仕事 $A$ は外部が系にする仕事を正とする．
この符号規約では，熱力学第1法則は

```math
\Delta U=Q+A
```

と表される．
ここで， $\Delta U$ は系の内部エネルギーの変化である．

本問題では，系が等温可逆変化を行って元の状態に戻る循環過程を考える．
系は初めの状態に戻るため，内部エネルギーは状態量であることから，

```math
\Delta U=0
```

が成立する．
以下，このことを用いて，熱量と仕事がともにゼロであることを導く．

### (i) Clausius の不等式を用いた導出

Clausius の不等式は，任意の循環過程について

```math
\oint \frac{d'Q}{T}\leq 0
```

と表される．
ここで， $d'Q$ は系に流入する微小熱量， $T$ はそのときの系の温度である．
また，積分記号 $\oint$ は，系が循環過程を一周する間に積分することを表す．

本問題の過程は可逆循環過程であるから，Clausius の不等式において等号が成立し，

```math
\oint \frac{d'Q}{T}=0
```

となる．

さらに，この過程は等温過程であるため，温度 $T$ は一定である．
したがって， $T$ を積分の外に出すことができ，

```math
\frac{1}{T}\oint d'Q=0
```

を得る．温度 $T$ はゼロではないから，

```math
\oint d'Q=0
```

である．
循環過程全体における正味の熱量を

```math
Q=\oint d'Q
```

と定義すれば，

```math
\boxed{
Q=0
}
```

となる．
すなわち，外部から系に流入する熱量と，系から外部へ流出する熱量の総和は相殺され，正味の熱量はゼロである．

次に，熱力学第1法則

```math
\Delta U=Q+A
```

を用いる．
系は元の状態に戻るため， $\Delta U=0$ であり，すでに $Q=0$ が得られているから，

```math
0=0+A
```

となる．
よって，

```math
\boxed{
A=0
}
```

である．

以上より，Clausius の不等式を用いると，等温可逆循環過程では，外部から入った正味の熱量も，外部が系にした正味の仕事もゼロであることが導かれる．

### (ii) Thomson の原理からの直接的な導出

Thomson の原理とは， **単一の熱源から熱を取り出し，それをすべて仕事に変え，それ以外に何の変化も残さない循環過程は実現できない** という原理である．

本問題の過程は等温可逆過程であるため，熱の授受が起こる際の系と熱源の温度は一致する．
したがって，熱の正味の出入りは，温度 $T$ の単一の熱源との熱交換として考えることができる．

そこで，この過程で外部から系に流入する正味の熱量 $Q$ がゼロでないと仮定する．
まず $Q>0$ の場合を考え，次に $Q<0$ の場合を考える．

#### 1．$Q>0$ の場合

まず，

```math
Q>0
```

と仮定する．
これは，系が熱源から正味の熱を受け取ることを意味する．

系は元の状態に戻るので，内部エネルギーの変化はゼロである．
したがって，熱力学第1法則から，

```math
\Delta U=Q+A=0
```

であり，

```math
A=-Q<0
```

となる．

ここで， $A$ は外部が系にする仕事である．
$A<0$ ということは，系が外部に仕事をしていることを意味する．
系が外部にする仕事を $W=-A$ と書けば，

```math
W=-A=Q>0
```

である．

したがって，この循環過程では，系は熱源から熱量 $Q$ を受け取り，それをすべて仕事 $W=Q$ に変換している．
しかも，系自身は元の状態に戻っているため，系に状態変化は残らない．

つまり，この過程の結果は，単一の熱源から熱を取り出し，その熱をすべて仕事に変えることだけである．
これは Thomson の原理に矛盾する．

ゆえに，

```math
\boxed{
Q>0\text{ は許されない}
}
```

のである．

#### 2．$Q<0$ の場合

次に，

```math
Q<0
```

と仮定する．
この場合，系は正味の熱を外部へ放出している．

ここで，与えられた過程の逆過程を考える．
可逆過程であるため，逆過程も実現可能であり，等温可逆循環過程である．
また，逆過程でも系は元の状態に戻る．

逆過程で系に流入する正味の熱量を $Q_{\mathrm{rev}}$ ，外部が系にする正味の仕事を $A_{\mathrm{rev}}$ とする．
過程を逆向きにすると熱量と仕事の符号が反転するため，

```math
Q_{\mathrm{rev}}=-Q>0
```

および

```math
A_{\mathrm{rev}}=-A
```

となる．
元の過程では $A=-Q$ であったから，

```math
A_{\mathrm{rev}}=-A=Q<0
```

である．
したがって，逆過程で系が外部にする仕事 $W_{\mathrm{rev}}=-A_{\mathrm{rev}}$ は，

```math
W_{\mathrm{rev}}=-A_{\mathrm{rev}}=-Q>0
```

となる．
ここで，

```math
W_{\mathrm{rev}}=-Q=Q_{\mathrm{rev}}
```

であることに注意する．

よって，逆過程では，系が熱源から熱量 $Q_{\mathrm{rev}}>0$ を受け取り，それをすべて仕事 $W_{\mathrm{rev}}=Q_{\mathrm{rev}}$ に変換している．
また，系は一周して元の状態に戻るため，系に状態変化は残らない．

これは，単一の熱源から受け取った熱をすべて仕事に変える循環過程であり，Thomson の原理に矛盾する．

したがって，

```math
\boxed{
Q<0\text{ も許されない}
}
```

のである．

#### 3．結論

$Q>0$ は Thomson の原理に矛盾し， $Q<0$ も逆過程を考えることによって Thomson の原理に矛盾する．
したがって，熱量の総和はゼロでなければならず，

```math
\boxed{
Q=0
}
```

となる．

さらに，系は元の状態に戻るので $\Delta U=0$ である．
熱力学第1法則

```math
\Delta U=Q+A
```

に $Q=0$ および $\Delta U=0$ を代入すると，

```math
0=0+A
```

となるから，

```math
\boxed{
A=0
}
```

を得る．

以上より，等温可逆循環過程においては，外部から入った正味の熱量も，外部が系にした正味の仕事もゼロである．
