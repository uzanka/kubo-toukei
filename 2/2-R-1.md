# 例題【2-R-1】

## 解答

# トムソンの原理とクラウジウスの原理の相互導出

## 1．2つの原理の定義

まず，証明に用いる2つの原理を確認する．

**トムソンの原理** （Kelvin–Planck の表現）とは，単一の熱源から熱を取り出し，それをすべて仕事に変換して，他には何の変化も残さない循環過程は不可能である，という原理である．
つまり，熱を受け取るだけの熱源を相手にして，熱を完全に仕事へ変換する熱機関は存在しない．

**クラウジウスの原理** とは，他に何の変化も残さず，低温熱源から高温熱源へ熱を移す循環過程は不可能である，という原理である．
低温から高温へ熱を移すこと自体が絶対に不可能なのではなく，そのための仕事など，別の変化を一切伴わない過程が不可能なのである．

以下では，低温熱源を $R_1$ ，その絶対温度を $T_1$ ，高温熱源を $R_2$ ，その絶対温度を $T_2$ とする．
ここで，

```math
T_2>T_1>0
```

である．
また，熱量は，熱源から出る量と熱源に入る量を区別して記述する．

## 2．トムソンの原理からクラウジウスの原理を導く

トムソンの原理が成り立つならば，クラウジウスの原理も成り立つことを示す．
そのため，クラウジウスの原理が成り立たないと仮定し，その結果としてトムソンの原理に反する装置を構成できることを示す．
これは対偶による証明である．

### 2.1 クラウジウスの原理を否定する

クラウジウスの原理が成り立たないと仮定する．
すると，他に何の変化も残さず，低温熱源 $R_1$ から高温熱源 $R_2$ へ正の熱量 $Q_1$ を移せる装置が存在することになる．
この装置を $A$ とする．

装置 $A$ による熱源の変化は，次のとおりである．

- 低温熱源 $R_1$ ： 熱量 $Q_1$ を失う．
- 高温熱源 $R_2$ ： 熱量 $Q_1$ を受け取る．
- 外部仕事 ： 仕事の授受はない．

### 2.2 カルノー熱機関を組み合わせる

次に，熱源 $R_2$ を高温側，熱源 $R_1$ を低温側として，この2つの熱源の間でカルノー熱機関 $C$ を作動させる．
カルノー熱機関とは，2つの熱源の間で可逆的に動作する理想的な熱機関である．

熱機関が低温熱源 $R_1$ に放出する熱量を，装置 $A$ が $R_1$ から取り出した熱量 $Q_1$ と一致させる．
熱機関の規模を適切に選べば，これは可能である．
熱機関が高温熱源 $R_2$ から受け取る熱量を $Q_1+Q_2$ とおくと，エネルギー保存則より，熱機関が外部にする仕事は

```math
W=(Q_1+Q_2)-Q_1=Q_2
```

となる．
ここで $Q_2>0$ である．
実際，カルノー熱機関では，

```math
\frac{Q_1}{Q_1+Q_2}=\frac{T_1}{T_2}
```

となるように熱量が定まり， $T_2>T_1$ なので $Q_2>0$ である．

### 2.3 2つの装置による正味の変化

装置 $A$ とカルノー熱機関 $C$ を合わせて考える．

| 対象 | 装置 $A$ | 熱機関 $C$ | 正味の変化 |
|---|---|---|---|
| 低温熱源 $R_1$ | 熱量 $Q_1$ を失う | 熱量 $Q_1$ を受け取る | 変化なし |
| 高温熱源 $R_2$ | 熱量 $Q_1$ を受け取る | 熱量 $Q_1+Q_2$ を失う | 熱量 $Q_2$ を失う |
| 外部仕事 | なし | 仕事 $Q_2$ を出力する | 仕事 $Q_2$ が出力される |

したがって，全体として残る変化は，高温熱源 $R_2$ から熱量 $Q_2$ を取り出して，その全量を仕事に変換することだけである．
低温熱源 $R_1$ にも，他の装置にも正味の変化は残らない．

これは，単一の熱源から熱を取り出し，それをすべて仕事に変換することはできない，というトムソンの原理に反する．

よって，

```math
\boxed{
\text{クラウジウスの原理が偽}
\ \Longrightarrow
\text{トムソンの原理が偽}
}
```

が示された．
これは対偶であるから，

```math
\boxed{
\text{トムソンの原理}
\ \Longrightarrow
\text{クラウジウスの原理}
}
```

が成り立つ．

## 3．クラウジウスの原理からトムソンの原理を導く

今度は逆に，クラウジウスの原理が成り立つならば，トムソンの原理も成り立つことを示す．
そのため，トムソンの原理が成り立たないと仮定し，クラウジウスの原理に反する装置を構成する．
これも対偶による証明である．

### 3.1 トムソンの原理を否定する

トムソンの原理が成り立たないと仮定する．
すると，単一の熱源 $R_2$ から熱量 $Q_2>0$ を取り出し，それを全量仕事に変換する装置 $B$ が存在することになる．
装置 $B$ は循環過程であり，熱源 $R_2$ と仕事以外には何の変化も残さないものとする．

装置 $B$ による変化は次のとおりである．

- 高温熱源 $R_2$ ： 熱量 $Q_2$ を失う．
- 外部：仕事 $Q_2$ が出力される．

### 3.2 出力された仕事でカルノー冷凍機を動かす

次に，低温熱源 $R_1$ から熱を取り出して高温熱源 $R_2$ へ移すカルノー冷凍機を考える．
冷凍機とは，外部から仕事を受け取り，低温熱源から高温熱源へ熱を移す装置である．

装置 $B$ が出力する仕事 $Q_2$ をすべて使って，冷凍機を作動させる．
冷凍機の規模を適切に選べば，消費する仕事をちょうど $Q_2$ とできる．
冷凍機が低温熱源 $R_1$ から取り出す熱量を $Q_1$ とすると，エネルギー保存則より，高温熱源 $R_2$ へ放出する熱量は

```math
Q_1+Q_2
```

となる．

カルノー冷凍機では，

```math
\frac{Q_1+Q_2}{Q_1}=\frac{T_2}{T_1}
```

となるように熱量が定まり， $T_2>T_1$ なので，正の熱量 $Q_1$ を移すことができる．

### 3.3 2つの装置による正味の変化

装置 $B$ とカルノー冷凍機を組み合わせた結果を考える．

| 対象 | 装置 $B$ | 冷凍機 | 正味の変化 |
|---|---|---|---|
| 低温熱源 $R_1$ | 変化なし | 熱量 $Q_1$ を失う | 熱量 $Q_1$ を失う |
| 高温熱源 $R_2$ | 熱量 $Q_2$ を失う | 熱量 $Q_1+Q_2$ を受け取る | 熱量 $Q_1$ を受け取る |
| 外部仕事 | 仕事 $Q_2$ を出力する | 仕事 $Q_2$ を消費する | 仕事の授受なし |

この組み合わせでは，装置 $B$ の出力した仕事が冷凍機の運転に使われるため，外部との正味の仕事の授受はない．
また，高温熱源 $R_2$ が失う熱量 $Q_2$ は，冷凍機が受け取る熱量の一部 $Q_2$ と打ち消し合う．

したがって，全体として残る変化は，低温熱源 $R_1$ から熱量 $Q_1$ を取り出し，高温熱源 $R_2$ へ移すことだけである．
外部から仕事を供給する必要はなく，他の変化も残らない．

これは，他に何の変化も残さずに低温熱源から高温熱源へ熱を移すことはできない，というクラウジウスの原理に反する．

よって，

```math
\boxed{
\text{トムソンの原理が偽}
\ \Longrightarrow
\text{クラウジウスの原理が偽}
}
```

が示された．
対偶をとると，

```math
\boxed{
\text{クラウジウスの原理}
\ \Longrightarrow
\text{トムソンの原理}
}
```

が成り立つ．

## 4．結論

第2節ではトムソンの原理からクラウジウスの原理が導かれ，第3節ではクラウジウスの原理からトムソンの原理が導かれた．
したがって，2つの原理は互いに導き出すことができ，論理的に同値である．
すなわち，

```math
\boxed{
\text{トムソンの原理}
\ \Longleftrightarrow
\text{クラウジウスの原理}
}
```

である．
