# 演習問題【2-A-4】

## 解答

熱機関が熱を受け取る過程を (1)，熱を外部へ捨てる過程を (2) とする．
また，熱機関が外部から受け取る熱量の総量を $Q_1$ ，外部へ捨てる熱量の総量を $Q_2$ とする．
いずれも正の量として定義する．
最高温度および最低温度は，それぞれ $T_{\max}$ ， $T_{\min}$ である．

### 1．Clausius の不等式の適用

熱機関は循環過程を行い，元の状態に戻る．
したがって，Clausius の不等式より，

```math
\oint \frac{d'Q}{T^{(e)}}\leq 0
```

が成立する．
ここで， $d'Q$ は系に流入する微小熱量を正とする量， $T^{(e)}$ は熱の授受が行われる外部の熱源の温度である．

吸熱過程 (1) では熱量が系に流入し，放熱過程 (2) では熱量が系から流出する．
放熱量 $d'Q_2$ は正の量として定義するため，Clausius の不等式は，

```math
\int_{(1)}\frac{d'Q_1}{T^{(e)}}
-
\int_{(2)}\frac{d'Q_2}{T^{(e)}}
\leq 0
```

と表される．
これを整理すると，

```math
\int_{(1)}\frac{d'Q_1}{T^{(e)}}
\leq
\int_{(2)}\frac{d'Q_2}{T^{(e)}}
\tag{1}
```

を得る．

### 2．熱源の温度による評価

まず，吸熱過程 (1) において，熱源の温度 $T^{(e)}$ は最高温度 $T_{\max}$ を超えない．すなわち，

```math
T^{(e)}\leq T_{\max}
```

である．
絶対温度は正であるから，

```math
\frac{1}{T^{(e)}}\geq \frac{1}{T_{\max}}
```

となる．
吸熱過程では $d'Q_1>0$ であるため，両辺に $d'Q_1$ を掛けて積分すれば，

```math
\int_{(1)}\frac{d'Q_1}{T^{(e)}}
\geq
\frac{1}{T_{\max}}\int_{(1)}d'Q_1
```

を得る．
ここで，

```math
Q_1=\int_{(1)}d'Q_1
```

であるから，

```math
\int_{(1)}\frac{d'Q_1}{T^{(e)}}
\geq \frac{Q_1}{T_{\max}}
\tag{2}
```

となる．

次に，放熱過程 (2) において，熱源の温度 $T^{(e)}$ は最低温度 $T_{\min}$ を下回らない．
すなわち，

```math
T^{(e)}\geq T_{\min}
```

であるから，

```math
\frac{1}{T^{(e)}}\leq \frac{1}{T_{\min}}
```

となる．
放熱量 $d'Q_2$ も正の量として定義しているため，両辺に $d'Q_2$ を掛けて積分すると，

```math
\int_{(2)}\frac{d'Q_2}{T^{(e)}}
\leq
\frac{1}{T_{\min}}\int_{(2)}d'Q_2
```

を得る．
ここで，

```math
Q_2=\int_{(2)}d'Q_2
```

であるから，

```math
\int_{(2)}\frac{d'Q_2}{T^{(e)}}
\leq \frac{Q_2}{T_{\min}}
\tag{3}
```

となる．

式 (1)，(2)，(3) を合わせると，

```math
\frac{Q_1}{T_{\max}}
\leq
\int_{(1)}\frac{d'Q_1}{T^{(e)}}
\leq
\int_{(2)}\frac{d'Q_2}{T^{(e)}}
\leq
\frac{Q_2}{T_{\min}}
```

である．
したがって，

```math
\frac{Q_1}{T_{\max}}\leq\frac{Q_2}{T_{\min}}
```

となる．
$Q_1>0$ ， $T_{\max}>0$ ， $T_{\min}>0$ であることを用いて整理すると，

```math
\boxed{
\frac{Q_2}{Q_1}\geq
\frac{T_{\min}}{T_{\max}}
}
\tag{4}
```

を得る．

### 3．熱機関の効率の導出

熱機関が外部にする仕事を $W$ とする．
熱力学第1法則によれば，内部エネルギーの変化は，系が受け取る熱量から系が外部にする仕事を引いた量であるから，

```math
\Delta U=Q_1-Q_2-W
```

と表される．
熱機関は循環過程を行って元の状態に戻るため，内部エネルギーは変化せず，

```math
\Delta U=0
```

である．
したがって，

```math
W=Q_1-Q_2
```

となる．

熱機関の効率 $\eta$ は，受け取った熱量に対する外部への仕事の割合として定義されるため，

```math
\eta=\frac{W}{Q_1}
=\frac{Q_1-Q_2}{Q_1}
=1-\frac{Q_2}{Q_1}
```

である．

式 (4) より，

```math
\frac{Q_2}{Q_1}\geq
\frac{T_{\min}}{T_{\max}}
```

であるから，

```math
\eta
=1-\frac{Q_2}{Q_1}
\leq
1-\frac{T_{\min}}{T_{\max}}
```

となる．
よって，

```math
\boxed{
\eta\leq 1-\frac{T_{\min}}{T_{\max}}
}
```

が示された．

### 4．等号が成立する条件

等号が成立するためには，Clausius の不等式で等号が成立することに加えて，吸熱がすべて最高温度 $T_{\max}$ で行われ，放熱がすべて最低温度 $T_{\min}$ で行われることが必要である．
通常，これは温度 $T_{\max}$ と $T_{\min}$ の2つの熱源の間で動作する可逆熱機関，すなわちカルノー機関の場合に実現される．

この場合，

```math
\eta=1-\frac{T_{\min}}{T_{\max}}
```

となる．
これに対し，不可逆な熱機関や，最高温度・最低温度以外の温度でも熱の授受を行う熱機関では，効率はこの上限より小さくなる．

したがって，一般に熱機関の効率は

```math
\boxed{
\eta\leq 1-\frac{T_{\min}}{T_{\max}}
}
```

であり，等号が成立する特別な場合を除けば，

```math
\boxed{
\eta<1-\frac{T_{\min}}{T_{\max}}
}
```

である．


## 解説

問題文の「より小さい」を厳密な不等号として維持するならば，可逆カルノー機関を除外する条件が必要である．
その条件が明記されていない場合，数学的・物理的に正しい一般的な結論は $\eta\leq 1-T_{\min}/T_{\max}$ である．
