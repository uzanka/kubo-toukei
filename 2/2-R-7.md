# 例題【2-R-7】

## 解答

### 1．前提と仕事の定義

系と外界との間に物質の出入りがない閉じた系を考える．
系の内部エネルギー，エントロピー，体積をそれぞれ $U,S,V$ ，系の温度と圧力をそれぞれ $T,p$ とする．
また，外界の温度を $T^{(e)}$ ，外界の圧力を $p^{(e)}$ とする．

系に対してなされる仕事を正とする．
仕事を，体積変化に伴う圧力仕事と，それ以外の仕事に分ける．
膨張仕事以外の仕事を $W_{\mathrm{other}}$ ，系に対してなされる全仕事を $W_{\mathrm{total}}$ とする．

体積が $V_1$ から $V_2$ に変化するとき，外界の圧力による仕事は，

```math
-\int_{V_1}^{V_2}p^{(e)}\,dV
```

である．
したがって，

```math
W_{\mathrm{total}}
=
W_{\mathrm{other}}
-\int_{V_1}^{V_2}p^{(e)}\,dV
\tag{1}
```

となる．
微小変化については，

```math
\delta W_{\mathrm{total}}
=
\delta W_{\mathrm{other}}-p^{(e)}dV
```

と表される．

本問では，問題文の目標式に対応させて，最小仕事 $W_{\min}$ を**膨張仕事以外の仕事 $W_{\mathrm{other}}$ の最小値**と解釈する．
したがって，

```math
W_{\min}=W_{\mathrm{other,min}}
```

である．
この定義は重要である．
膨張仕事を含む全仕事の最小値は，一般に $W_{\mathrm{other,min}}$ とは異なる．

以下では，同じ初期状態と最終状態を結ぶ過程について，同じ外界条件のもとで仕事を比較する．
また，系は単一の一定温度の熱浴と熱を授受し，準静的な可逆過程が可能であるものとする．

なお，仕事は一般に経路に依存する量であるため，微小仕事を厳密には $\delta W$ と表す．
以下では，有限変化の仕事を $W$ ，問題文の微小仕事を $\delta W$ として区別する．

### 2．熱力学第一法則と第二法則による最小仕事の証明

系が外界から吸収する熱量を $Q$ とする．
熱力学第一法則より，

```math
\Delta U
=
Q+W_{\mathrm{other}}
-\int_{V_1}^{V_2}p^{(e)}\,dV
```

である．
これを $W_{\mathrm{other}}$ について解くと，

```math
W_{\mathrm{other}}
=
\Delta U-Q
+\int_{V_1}^{V_2}p^{(e)}\,dV
\tag{2}
```

となる．

次に，系が温度 $T^{(e)}$ 一定の単一の熱浴と熱を授受するものとする．
熱浴のエントロピー変化は，

```math
\Delta S_{\mathrm{bath}}
=
-\frac{Q}{T^{(e)}}
```

である．
系と熱浴を合わせた全体のエントロピー生成を $S_{\mathrm{gen}}$ とすると，熱力学第二法則より，

```math
S_{\mathrm{gen}}
=
\Delta S+\Delta S_{\mathrm{bath}}
\geq0
```

である．
したがって，

```math
\Delta S-\frac{Q}{T^{(e)}}\geq0
```

となり，

```math
Q\leq T^{(e)}\Delta S
\tag{3}
```

を得る．

式 (3) を式 (2) に代入すると，

```math
\boxed{
W_{\mathrm{other}}
\geq
\Delta U-T^{(e)}\Delta S
+\int_{V_1}^{V_2}p^{(e)}\,dV
}
\tag{4}
```

となる．

式 (4) の等号は，

```math
S_{\mathrm{gen}}=0
```

すなわち，全過程が可逆である場合に成立する．
ただし，実際の可逆過程は，熱的・力学的な駆動力を無限小とする準静的極限として扱う．
また，仕事伝達装置などに散逸がない理想的な条件を考える．

したがって，指定された外界条件のもとで可逆過程が実現可能であれば，式 (4) の右辺が膨張仕事以外の仕事の下限となり，可逆過程でその下限が実現する．

以下では，等温変化に対応する熱浴の温度を $T$ とする．
すなわち，

```math
T^{(e)}=T
```

である．
これは，系の温度と熱浴の温度を無限小の差で保つ可逆極限に対応する．

### 3．(i) 等温等積変化

Helmholtz 自由エネルギー $F$ は，

```math
F=U-TS
```

と定義される．
その全微分は，

```math
dF=dU-TdS-SdT
```

である．
等温変化では，

```math
dT=0
```

なので，

```math
dF=dU-TdS
\tag{5}
```

となる．

等積変化では，

```math
dV=0
```

であるから，有限変化についても，

```math
V_2=V_1
```

となる．
したがって，

```math
\int_{V_1}^{V_2}p^{(e)}\,dV=0
```

である．

この条件を式 (4) に適用し， $T^{(e)}=T$ とすると，

```math
W_{\mathrm{other}}
\geq
\Delta U-T\Delta S
```

となる．
等温変化では，

```math
\Delta F=\Delta U-T\Delta S
```

なので，

```math
W_{\mathrm{other}}\geq\Delta F
```

である．
等号は可逆過程で成立するから，

```math
\boxed{
W_{\mathrm{other,min}}=\Delta F
}
```

を得る．

また，等積変化では圧力仕事がゼロであるため，

```math
W_{\mathrm{total}}=W_{\mathrm{other}}
```

となる．
したがって，この場合には全仕事の最小値も $\Delta F$ に等しい．

これを微小変化について表すと，

```math
\boxed{
\delta W_{\min}=dF
}
```

となる．
問題文の表記に従えば，

```math
\boxed{
dW_{\min}=dF
}
```

である．

### 4．(ii) 等温等圧変化

Gibbs 自由エネルギー $G$ は，

```math
G=U-TS+pV
```

と定義される．
その全微分は，

```math
dG=dU-TdS-SdT+p\,dV+V\,dp
```

である．
等温等圧変化では，

```math
dT=0,\qquad dp=0
```

なので，

```math
dG=dU-TdS+p\,dV
\tag{6}
```

となる．

系の圧力を一定値 $p_0$ に保つ等圧変化を考える．
このとき，

```math
p=p_0
```

である．
また，外界の圧力も基準値 $p_0$ に設定する．

ただし，可逆的な体積変化を実現するためには，系と外界の間に体積変化を駆動する圧力差が必要である．
したがって，有限の体積変化を考える際に，系の圧力と外界の圧力を厳密に等しくしたまま変化が進むと考えるのは適切ではない．

例えば，膨張の場合には，

```math
p^{(e)}=p_0-\varepsilon
```

圧縮の場合には，

```math
p^{(e)}=p_0+\varepsilon
```

とし，最後に，

```math
\varepsilon\to0^+
```

の極限を取る．
この極限で系と外界の圧力差は無限小となり，可逆過程に対応する．
したがって，

```math
p^{(e)}\to p_0
```

であり，

```math
\begin{aligned}
\lim_{\varepsilon\to0^+}
\int_{V_1}^{V_2}p^{(e)}\,dV
&=
\int_{V_1}^{V_2}p_0\,dV\\
&=
p_0(V_2-V_1)\\
&=
p_0\Delta V
\end{aligned}
\tag{7}
```

となる．

式 (4) に $T^{(e)}=T$ とこの可逆極限を適用すると，

```math
W_{\mathrm{other}}
\geq
\Delta U-T\Delta S+p_0\Delta V
\tag{8}
```

を得る．

一方，系の初期状態と最終状態の圧力はいずれも $p_0$ である．
Gibbs 自由エネルギーの定義より，

```math
G=U-TS+pV
```

なので，

```math
\begin{aligned}
\Delta G
&=
U_2-U_1-T(S_2-S_1)
+p_0V_2-p_0V_1\\
&=
\Delta U-T\Delta S+p_0\Delta V
\end{aligned}
```

である．
これを式 (8) に代入すると，

```math
W_{\mathrm{other}}\geq\Delta G
```

となる．
等号は可逆過程の極限で成立するため，

```math
\boxed{
W_{\mathrm{other,min}}=\Delta G
}
```

を得る．

微小変化については，式 (6) より，

```math
\boxed{
\delta W_{\min}=dG
}
```

となる．
問題文の表記に従えば，

```math
\boxed{
dW_{\min}=dG
}
```

である．

### 5．膨張仕事を含めた全仕事との関係

ここまで求めた $\Delta F$ および $\Delta G$ は，膨張仕事以外の仕事の最小値に関するものである．
全仕事との関係を確認する．

式 (1) より，

```math
W_{\mathrm{total}}
=
W_{\mathrm{other}}
-\int_{V_1}^{V_2}p^{(e)}\,dV
```

である．
可逆過程では式 (4) の等号が成立するので，

```math
\begin{aligned}
W_{\mathrm{total,min}}
&=
\Delta U-T\Delta S
+\int_{V_1}^{V_2}p^{(e)}\,dV
-\int_{V_1}^{V_2}p^{(e)}\,dV\\
&=
\Delta U-T\Delta S
\end{aligned}
```

となる．
等温変化では，

```math
\Delta F=\Delta U-T\Delta S
```

であるから，

```math
\boxed{
W_{\mathrm{total,min}}=\Delta F
}
```

となる．

したがって，等温等圧変化においても，

```math
W_{\mathrm{other,min}}=\Delta G
```

である一方，

```math
W_{\mathrm{total,min}}=\Delta F
```

である．
この二つは異なる仕事の最小値であり，混同してはならない．

以上より，問題文の $dW_{\min}$ を膨張仕事以外の仕事の最小値と解釈すれば，

```math
\boxed{
\begin{aligned}
\text{(i) 等温等積変化：}\quad
&dW_{\min}=dF,\\[4pt]
\text{(ii) 等温等圧変化：}\quad
&dW_{\min}=dG
\end{aligned}
}
```

が示された．
