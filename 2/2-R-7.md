# 例題【2-R-7】

## 解答

系と外界との間に物質の出入りがない場合を考える．
系の内部エネルギー，エントロピー，体積をそれぞれ $U$ ， $S$ ， $V$ とし，系の温度と圧力をそれぞれ $T$ ， $p$ ，外界の圧力を $p^{(e)}$ とする．

ここでは，系に対してなされる仕事を正とする．
また，最小仕事は，可逆過程によって系をある状態から別の状態へ変化させるときに必要となる最小の仕事である．

熱力学第一法則より，

```math
dU=d'Q+dW
```

である．
ここで， $d'Q$ は系が吸収する微小な熱量， $dW$ は系に対してなされる微小な仕事である．

系の体積が $dV$ だけ変化するとき，系が外界にする膨張仕事は $p^{(e)}dV$ である．
したがって，系に対してなされる膨張仕事は $-p^{(e)}dV$ となる．
この膨張仕事以外の仕事を $dW_{\mathrm{other}}$ とすると，

```math
dW=dW_{\mathrm{other}}-p^{(e)}dV
```

である．
よって，熱力学第一法則は

```math
dU=d'Q+dW_{\mathrm{other}}-p^{(e)}dV
```

と書ける．
これを $dW_{\mathrm{other}}$ について解くと，

```math
dW_{\mathrm{other}}=dU-d'Q+p^{(e)}dV
```

を得る．

可逆過程では，熱の出入りとエントロピー変化の間に

```math
d'Q_{\mathrm{rev}}=T^{(e)}dS
```

が成り立つ．
また，最小仕事を考える場合には，系の温度と外界の温度が等しく， $T=T^{(e)}$ である．
したがって，

```math
\boxed{
dW_{\min}=dU-TdS+p^{(e)}dV
}
\tag{1}
```

となる．
ここで $dW_{\min}$ は，膨張仕事を除いた仕事の最小値を表す．

### (i) 等温等積変化

Helmholtz自由エネルギー $F$ は，

```math
F=U-TS
```

と定義される．
その全微分は，

```math
dF=dU-TdS-SdT
```

である．
等温変化では $dT=0$ であるから，

```math
dF=dU-TdS
\tag{2}
```

となる．

等積変化では体積が一定であるため，

```math
dV=0
```

である．
これらの条件を式 (1) に代入すると，

```math
dW_{\min}=dU-TdS
```

となる．
式 (2) より，

```math
\boxed{
dW_{\min}=dF
}
```

を得る．
したがって，外界との間に物質の出入りがない等温等積変化では，最小仕事はHelmholtz自由エネルギーの増し高に等しい．

### (ii) 等温等圧変化

Gibbs自由エネルギー $G$ は，

```math
G=F+pV=U-TS+pV
```

と定義される．
その全微分は，

```math
dG=dU-TdS-SdT+p\,dV+V\,dp
```

である．
等温変化では $dT=0$ ，等圧変化では $dp=0$ であるから，

```math
dG=dU-TdS+p\,dV
\tag{3}
```

となる．

また，系の圧力 $p$ と外界の圧力 $p^{(e)}$ が等しく保たれているため，

```math
p=p^{(e)}
```

である．
これを式 (1) に代入すると，

```math
dW_{\min}=dU-TdS+p\,dV
```

となる．
式 (3) より，

```math
\boxed{
dW_{\min}=dG
}
```

を得る．
したがって，外界との間に物質の出入りがない等温等圧変化では，最小仕事はGibbs自由エネルギーの増し高に等しい．

以上より，(i)，(ii) のいずれも示された．


## 解説

### 最小仕事と自由エネルギーの物理的意味

この問題で重要なのは，最小仕事の一般式

```math
dW_{\min}=dU-TdS+p^{(e)}dV
```

において，体積変化に関する項が，それぞれの拘束条件によって異なる扱いになることである．
- 等温等積変化では $dT=0$ ， $dV=0$ であるため，体積変化に伴う仕事がなく，Helmholtz自由エネルギーの変化 $dF$ が最小仕事に等しくなる．
- 等温等圧変化では $(dT=0$ ， $dp=0$ ， $p=p^{(e)}$ であるため，体積変化に伴う仕事を含めた量がGibbs自由エネルギーの変化 $dG$ に一致する．
