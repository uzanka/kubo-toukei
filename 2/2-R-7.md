# 演習問題【2-R-7】

## 解答

### 準備：熱力学の基本式と自由エネルギーの定義

この問題を解くために，まず熱力学における基本的な関係式を確認する．

1.  **熱力学第一法則**:
    系（私たちが注目している対象）の内部エネルギーの変化 $dU$ は，系に与えられた熱 $dQ$ と，系に対してなされた仕事 $dW$ の和で表される．
    $$dU = dQ + dW$$

2.  **可逆過程における熱とエントロピー**:
    温度 $T$ の系において，可逆的な熱のやり取りはエントロピーの変化 $dS$ を用いて以下のように書ける．
    $$dQ = T dS$$
    ここで，等温変化（温度が変わらない変化）を考える場合，系の温度 $T$ は常に一定であり，外界の温度 $T^{(e)}$ と等しくなる（ $T = T^{(e)}$ ）．

3.  **仕事の構成**:
    系に対してなされる仕事 $dW$ は，内部エネルギーの変化 $dU$ と熱 $dQ$ を用いて，次のように書き換えられる．
    $$dW = dU - dQ = dU - T dS$$
    さらに，系が体積 $V$ を変化させる際に，外界の圧力 $p^{(e)}$ に対してなされる仕事（膨張仕事）の項 $p^{(e)} dV$ を含めると，全仕事 $dW$ は以下のようになる．
    $$dW = dU - T dS + p^{(e)} dV \quad \dots (\text{A})$$

4.  **自由エネルギーの定義**:
    熱力学において，特定の条件下での「使いやすさ」や「変化の方向」を表す指標として，以下の二つの自由エネルギーが定義されている．
    *   ヘルムホルツ自由エネルギー $F$ :
        $F = U - TS$
        その微分形は， $dF = dU - T dS - S dT$ である．
        等温変化 ( $dT=0$ ) では， $dF = dU - T dS$ となる．
    *   ギブス自由エネルギー $G$ :
        $G = F + pV = U - TS + pV$
        その微分形は， $dG = dU - T dS - S dT + p dV + V dp$ である．
        等温変化 ( $dT=0$ ) かつ，圧力が一定 ( $dp=0$ ) の場合， $dG = dU - T dS + p dV$ となる．

### (i) 等温等積変化における最小仕事

**条件**:
*   等温変化 ( $T$ が一定)
*   等積変化 (体積 $V$ が一定 $\Rightarrow dV = 0$ )

式 (A) にこれらの条件を適用する．

$$dW = dU - T dS + p^{(e)} (0) = dU - T dS$$

ここで，等温変化におけるヘルムホルツ自由エネルギーの増し高 $dF$ の定義は，

$$dF = dU - T dS$$

であるため，

$$dW = dF$$

となる．

したがって，等温等積変化において外界から系になされる最小仕事 $dW_{\min}$ は，ヘルムホルツ自由エネルギーの増し高 $dF$ に等しくなる．

### (ii) 等温等圧変化における最小仕事

**条件**:
*   等温変化 ( $T$ が一定)
*   等圧変化 (圧力が一定 $\Rightarrow p = p^{(e)}$ かつ $dp = 0$ )

式 (A) にこれらの条件を適用する．

$$dW = dU - T dS + p^{(e)} dV$$

ここで，系が等圧で変化しているため，外界の圧力 $p^{(e)}$ は系の圧力 $p$ と等しく ( $p^{(e)} = p$ )，かつ一定である．
このとき，ギブス自由エネルギー $G$ の定義に基づく微分形は，

$$dG = dU - T dS + p dV$$

となる．

したがって，

$$dW = dG$$

となる．

以上のことから，等温等圧変化において外界から系になされる最小仕事 $dW_{\min}$ は，ギブス自由エネルギーの増し高 $dG$ に等しくなる．

## 解説

この問題は，熱力学の第一法則と，特定の条件下で系が持つ「エネルギーの質」を表す自由エネルギーの関係を問うものである．

**なぜ「最小仕事」なのか？**

現実のプロセス（摩擦や急激な変化を伴うもの）では，系を変化させるためにより多くのエネルギー（仕事）が必要になる．
しかし，理想的にゆっくりと，かつ摩擦などの無駄がない「可逆過程」で行った場合，必要な仕事は理論上の最小値となる．
この最小値が，系の状態量の変化（エントロピーや内部エネルギーの変化）によって決まることを示している．

**自由エネルギーの使い分け**

*   **ヘルムホルツ自由エネルギー ( $F$ )**:
  「体積が固定された容器」の中での変化を考えるときに非常に便利である．
  体積が変わらないので，膨張仕事などの余計な項を考えなくて済む．
*   **ギブス自由エネルギー ( $G$ )**:
  「大気圧の下」など，圧力が一定の環境下での化学反応や相転移を考えるときに非常に便利である．
  私たちが日常生活で目にする多くの現象は，この等圧条件下のものである．

このように，物理的な拘束条件（体積が一定か，圧力が一定か）に応じて，適切なエネルギーの指標を用いることで，系の変化をシンプルに記述できるのが自由エネルギーの大きな利点である．
