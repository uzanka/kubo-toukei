# 演習問題【2-B-33】

## 解答

### 前提

体系の単位質量あたりの内部エネルギーを $u$ ，エントロピーを $s$ ，比体積を $v$ ，圧力を $p$ ，絶対温度を $T$ とする．
問題の仮定は，内部エネルギー $u$ が比体積 $v$ に依存しないということである．
すなわち，

```math
u=u(T)
```

である．
単純な圧縮性物質に対する熱力学の基本関係式は，

```math
du=T\,ds-p\,dv
\tag{1}
```

である．
この式を利用して，各項目を順番に証明する．

### (i) 定積比熱 $c_v$ は温度 $T$ のみの関数である

内部エネルギー $u$ は温度のみの関数であるため，全微分は

```math
du=\frac{du(T)}{dT}\,dT
```

と書ける．
ここで，

```math
g(T)=\frac{du(T)}{dT}
```

と置けば，

```math
du=g(T)\,dT
\tag{2}
```

である．
$g(T)$ は温度 $T$ のみの関数である．

定積比熱 $c_v$ は，単位質量あたりの内部エネルギーの温度に対する変化率として，

```math
c_v=\left(\frac{\partial u}{\partial T}\right)_v
```

と定義される．
式 (2) より，

```math
c_v=g(T)
```

となる．
したがって，

```math
\boxed{
c_v=c_v(T)
}
```

であり，定積比熱は温度 $T$ のみの関数である．
これで (i) が示された．

### (ii) 比体積 $v$ は $p/T$ のみの関数である

式 (1) と式 (2) より，

```math
g(T)\,dT=T\,ds-p\,dv
```

である．
これを $dv$ について整理すると，

```math
dv=\frac{T}{p}\,ds-\frac{g(T)}{p}\,dT
\tag{3}
```

となる．

まず， $T,p$ を独立変数として，式 (3) の両辺をそれぞれ偏微分する．
圧力一定では，

```math
\left(\frac{\partial v}{\partial T}\right)_p
=\frac{T}{p}\left(\frac{\partial s}{\partial T}\right)_p
-\frac{g(T)}{p}
\tag{4}
```

である．
また，温度一定では，

```math
\left(\frac{\partial v}{\partial p}\right)_T
=\frac{T}{p}\left(\frac{\partial s}{\partial p}\right)_T
\tag{5}
```

となる．

ここで，マクスウェルの関係式

```math
\left(\frac{\partial s}{\partial p}\right)_T
=-\left(\frac{\partial v}{\partial T}\right)_p
\tag{6}
```

を用いる．
この関係式は，比ギブズ自由エネルギー $g_{\mathrm{G}}=u+pv-Ts$ の全微分

```math
dg_{\mathrm{G}}=-s\,dT+v\,dp
```

から導かれる．
状態量 $g_{\mathrm{G}}$ の混合二階偏微分が等しいことにより，式 (6) が得られるのである．

式 (6) を式 (5) に代入すると，

```math
\left(\frac{\partial v}{\partial p}\right)_T
=-\frac{T}{p}\left(\frac{\partial v}{\partial T}\right)_p
\tag{7}
```

となる．

比体積 $v$ の全微分は，

```math
dv=
\left(\frac{\partial v}{\partial T}\right)_p dT
+\left(\frac{\partial v}{\partial p}\right)_T dp
```

である．
式 (7) を代入すると，

```math
dv=
\left(\frac{\partial v}{\partial T}\right)_p
\left(dT-\frac{T}{p}\,dp\right)
\tag{8}
```

となる．

ここで，

```math
x=\frac{p}{T}
```

と定義する．
$p=xT$ であるから，全微分は

```math
dp=T\,dx+x\,dT
\tag{9}
```

となる．
これを式 (8) に代入すると，

```math
\begin{aligned}
dv
&=\left(\frac{\partial v}{\partial T}\right)_p
\left\{dT-\frac{T}{p}(T\,dx+x\,dT)\right\}\\
&=\left(\frac{\partial v}{\partial T}\right)_p
\left\{dT-\frac{T^2}{p}\,dx
-\frac{xT}{p}\,dT\right\}
\end{aligned}
```

を得る．
$x=p/T$ より $xT/p=1$ であるため， $dT$ の項は相殺され，

```math
dv=-\frac{T^2}{p}
\left(\frac{\partial v}{\partial T}\right)_p dx
\tag{10}
```

となる．

式 (10) では， $dv$ が $dx$ のみを含み，独立な $dT$ の項が存在しない．
したがって， $x=p/T$ を一定に保った変化では $dv=0$ となる．
つまり，比体積 $v$ は $T$ に独立に依存するのではなく， $x=p/T$ のみで決まる．
よって，

```math
\boxed{
v=v\left(\frac{p}{T}\right)
}
```

である．
これで (ii) が示された．

### (iii) 定圧比熱 $c_p$ と定積比熱 $c_v$ の差も $p/T$ のみの関数である

定圧比熱と定積比熱は，エントロピーを用いてそれぞれ，

```math
c_p=T\left(\frac{\partial s}{\partial T}\right)_p,
\qquad
c_v=T\left(\frac{\partial s}{\partial T}\right)_v
\tag{11}
```

と表される．
したがって，

```math
c_p-c_v
=T\left[
\left(\frac{\partial s}{\partial T}\right)_p
-\left(\frac{\partial s}{\partial T}\right)_v
\right]
\tag{12}
```

である．

エントロピー $s$ を $T,v$ の関数と考え，連鎖律を適用すると，

```math
\left(\frac{\partial s}{\partial T}\right)_p
=
\left(\frac{\partial s}{\partial T}\right)_v
+\left(\frac{\partial s}{\partial v}\right)_T
\left(\frac{\partial v}{\partial T}\right)_p
\tag{13}
```

となる．

さらに，ヘルムホルツ自由エネルギー $f_{\mathrm{H}}=u-Ts$ の全微分

```math
df_{\mathrm{H}}=-s\,dT-p\,dv
```

から導かれるマクスウェルの関係式，

```math
\left(\frac{\partial s}{\partial v}\right)_T
=\left(\frac{\partial p}{\partial T}\right)_v
\tag{14}
```

を用いる．
式 (13)，(14) を式 (12) に代入すると，

```math
c_p-c_v
=T\left(\frac{\partial p}{\partial T}\right)_v
\left(\frac{\partial v}{\partial T}\right)_p
\tag{15}
```

が得られる．

ここで，(ii) より $v=v(p/T)$ である．
比体積 $v$ を一定に保つと， $p/T$ も一定となる．
したがって，

```math
\frac{p}{T}=\text{一定}
```

より，

```math
\left(\frac{\partial p}{\partial T}\right)_v=\frac{p}{T}
\tag{16}
```

である．
式 (16) を式 (15) に代入すると，

```math
\boxed{
c_p-c_v
=p\left(\frac{\partial v}{\partial T}\right)_p
}
\tag{17}
```

となる．

さらに，(ii) で定義した $x=p/T$ を用いると， $v=v(x)$ であるから，連鎖律より，

```math
\left(\frac{\partial v}{\partial T}\right)_p
=\frac{dv}{dx}\left(\frac{\partial x}{\partial T}\right)_p
```

である．
圧力一定では，

```math
\left(\frac{\partial x}{\partial T}\right)_p
=-\frac{p}{T^2}
```

となるので，

```math
\left(\frac{\partial v}{\partial T}\right)_p
=-\frac{p}{T^2}\frac{dv}{dx}
```

を得る．
これを式 (17) に代入すれば，

```math
\begin{aligned}
c_p-c_v
&=-\frac{p^2}{T^2}\frac{dv}{dx}\\
&=-x^2\frac{dv}{dx}
\end{aligned}
```

となる．
$v$ は $x$ のみの関数であるため， $dv/dx$ も $x$ のみの関数である．
したがって，

```math
\boxed{
c_p-c_v
=-\left(\frac{p}{T}\right)^2
\frac{dv}{d(p/T)}
}
```

となり， $c_p-c_v$ も $p/T$ のみの関数である．
これで (iii) が示された．


## 解説

3つの結論は，いずれも内部エネルギーが体積に依存しないという仮定から出発している．
特に (ii) で得た $v=v(p/T)$ が，(iii) の比熱差を $p/T4 のみの関数として表すための重要な結果である．
