# 演習問題【2-B-33】

## 解答

物質の質量を $m$ ，比体積を $v=V/m$ ，比内部エネルギーを $u$ ，比エントロピーを $s$ とする．
問題の仮定より，比内部エネルギーは体積に依存しないため，

```math
u=u(T)
```

と表される．

以下では，証明に必要な追加仮定として，考察する状態領域を

```math
D=I_T\times I_v
```

とする．
ここで， $I_T\subset(0,\infty)$ および $I_v\subset(0,\infty)$ はそれぞれ連結な開区間である．
また，状態量および状態方程式は，以下の偏微分と全微分が存在するだけの滑らかさを持つものとする．
さらに，機械的安定性の条件として，

```math
\boxed{
\left(\frac{\partial p}{\partial v}\right)_T<0
}
\tag{A}
```

を仮定する．

### (i) 定積比熱 $c_v$ は温度 $T$ のみの関数であること

定積比熱の定義より，

```math
c_v=\left(\frac{\partial u}{\partial T}\right)_v.
```

問題の仮定 $u=u(T)$ を用いると，

```math
c_v=\frac{du(T)}{dT}.
```

したがって，

```math
\boxed{c_v=c_v(T)}
```

となる．

### (ii) 体積 $V$ は $p/T$ のみの関数であること

単純圧縮性物質の基本関係式

```math
du=T\,ds-p\,dv
```

より，

```math
ds=\frac{du}{T}+\frac{p}{T}\,dv.
```

ここで，(i) より $du=c_v(T)\,dT$ であるから，

```math
ds=\frac{c_v(T)}{T}\,dT+\frac{p}{T}\,dv.
\tag{1}
```

エントロピー $s$ は状態量であるため，その全微分は完全微分である．
したがって，式 (1) の交差偏微分は等しく，

```math
\frac{\partial}{\partial v}
\left(\frac{c_v(T)}{T}\right)_T
=
\frac{\partial}{\partial T}
\left(\frac{p}{T}\right)_v.
```

左辺はゼロであるから，

```math
\left(\frac{\partial}{\partial T}\frac{p}{T}\right)_v=0.
\tag{2}
```

ここで，状態領域は

```math
D=I_T\times I_v
```

であり， $I_T$ は連結な区間である．
したがって，任意の固定した $v\in I_v$ に対して，式 (2) より $p/T$ は $T\in I_T$ に依存しない．
よって，領域 $D$ 全体において，

```math
\frac{p}{T}=f(v)
\tag{3}
```

と表すことができる．

式 (3) を $v$ で微分すると，

```math
f'(v)=\frac{1}{T}
\left(\frac{\partial p}{\partial v}\right)_T.
```

追加仮定 (A) と $T>0$ より，

```math
f'(v)<0.
```

したがって， $f(v)$ は連結区間 $I_v$ 上で狭義単調減少する．
ゆえに，その値域 $f(I_v)$ 上に逆関数 $F$ が存在する．
すなわち，

```math
v=F(f(v)).
```

式 (3) を代入すれば，

```math
\boxed{
v=F\left(\frac{p}{T}\right)
}
```

となる．

質量 $m$ は一定であり， $V=mv$ であるから，

```math
V=mF\left(\frac{p}{T}\right).
```

したがって，

```math
\boxed{
V=\widetilde F\left(\frac{p}{T}\right)
}
```

となり，体積 $V$ は $p/T$ のみの関数である．

### (iii) 定圧比熱 $c_p$ と定積比熱 $c_v$ の差は $p/T$ のみの関数であること

比エンタルピーを

```math
H=u+pv
```

と定義する．
その全微分は，

```math
dH=du+p\,dv+v\,dp
```

である．

定圧比熱の定義より，

```math
c_p=\left(\frac{\partial H}{\partial T}\right)_p.
```

したがって，

```math
c_p
=
\left(\frac{\partial u}{\partial T}\right)_p
+p\left(\frac{\partial v}{\partial T}\right)_p
+v\left(\frac{\partial p}{\partial T}\right)_p.
```

内部エネルギーは $u=u(T)$ であるから，

```math
\left(\frac{\partial u}{\partial T}\right)_p=c_v.
```

また，定圧条件では

```math
\left(\frac{\partial p}{\partial T}\right)_p=0
```

である．
よって，

```math
c_p-c_v
=p\left(\frac{\partial v}{\partial T}\right)_p.
\tag{4}
```

(ii) で得た

```math
v=F\left(\frac{p}{T}\right)
```

を式 (4) に代入する．
圧力 $p$ を一定として温度 $T$ で微分すると，

```math
\left(\frac{\partial v}{\partial T}\right)_p
=
F'\left(\frac{p}{T}\right)
\left(-\frac{p}{T^2}\right).
```

したがって，

```math
c_p-c_v
=
-\frac{p^2}{T^2}
F'\left(\frac{p}{T}\right).
```

ゆえに，

```math
\boxed{
c_p-c_v
=
-\left(\frac{p}{T}\right)^2
F'\left(\frac{p}{T}\right)
}
```

となる．
右辺は $p/T$ のみの関数であるから，

```math
\boxed{c_p-c_v\text{ は }p/T\text{ のみの関数である．}}
```

以上より，追加仮定 (A) および状態領域 $D=I_T\times I_v$ の下で，(i)，(ii)，(iii) のすべてが証明された．
