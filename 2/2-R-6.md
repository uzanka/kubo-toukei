# 例題【2-R-6】

## 解答

### 1．エントロピーの全微分

磁性体の体積は一定とし，単位体積当たりの内部エネルギー，エントロピー，磁化をそれぞれ $u$ ， $s$ ， $M$ とする．
エントロピー $s$ は温度 $T$ と磁場 $H$ の関数であるため，その全微分は

```math
ds=
\left(\frac{\partial s}{\partial T}\right)_H dT
+
\left(\frac{\partial s}{\partial H}\right)_T dH
```

である．
両辺に $T$ を掛けると，

```math
Tds=
T\left(\frac{\partial s}{\partial T}\right)_H dT
+
T\left(\frac{\partial s}{\partial H}\right)_T dH
\tag{1}
```

となる．

ここで，磁場 $H$ 一定の条件下における単位体積当たりの熱容量 $C_H$ は，

```math
C_H=T\left(\frac{\partial s}{\partial T}\right)_H
```

と定義される．
したがって，式 (1) は

```math
Tds=C_HdT+
T\left(\frac{\partial s}{\partial H}\right)_T dH
\tag{2}
```

と書ける．

### 2．マクスウェルの関係式の導出

式 (2) を利用するため，エントロピーの磁場に関する偏微分を磁化の温度に関する偏微分で表す関係式を導く．

磁性体の単位体積当たりの内部エネルギー $u$ の微小変化は，熱力学第一法則により

```math
du=Tds+HdM
\tag{3}
```

と表される．
ここで，磁場 $H$ と磁化 $M$ は，この式で採用する磁気的な仕事の符号規約に従うものとする．

エントロピー $s$ と磁化 $M$ を温度 $T$ と磁場 $H$ の関数とみなすと，式 (3) より，

```math
\left(\frac{\partial u}{\partial T}\right)_H
=
T\left(\frac{\partial s}{\partial T}\right)_H
+
H\left(\frac{\partial M}{\partial T}\right)_H
\tag{4}
```

および

```math
\left(\frac{\partial u}{\partial H}\right)_T
=
T\left(\frac{\partial s}{\partial H}\right)_T
+
H\left(\frac{\partial M}{\partial H}\right)_T
\tag{5}
```

が得られる．

ここで，式 (4) を $H$ で偏微分する．
このとき $T$ は一定であるから，

```math
\begin{aligned}
\frac{\partial}{\partial H}
\left(\frac{\partial u}{\partial T}\right)_H
={}&
T\frac{\partial^2s}{\partial H\partial T}
+\left(\frac{\partial M}{\partial T}\right)_H\\
&+H\frac{\partial^2M}{\partial H\partial T}
\end{aligned}
\tag{6}
```

となる．

一方，式 (5) を $T$ で偏微分する．
このとき $H$ は一定であるから，

```math
\begin{aligned}
\frac{\partial}{\partial T}
\left(\frac{\partial u}{\partial H}\right)_T
={}&
\left(\frac{\partial s}{\partial H}\right)_T
+T\frac{\partial^2s}{\partial T\partial H}\\
&+H\frac{\partial^2M}{\partial T\partial H}
\end{aligned}
\tag{7}
```

となる．

内部エネルギー $u$ が必要な回数だけ連続微分可能であれば，混合偏微分は交換可能である．したがって，

```math
\frac{\partial}{\partial H}
\left(\frac{\partial u}{\partial T}\right)_H
=
\frac{\partial}{\partial T}
\left(\frac{\partial u}{\partial H}\right)_T
```

が成り立つ．
また，エントロピーと磁化についても混合偏微分が交換可能であるため，式 (6)，(7) の両辺に現れる二階偏微分の項は相殺される．
その結果，

```math
\boxed{
\left(\frac{\partial s}{\partial H}\right)_T
=
\left(\frac{\partial M}{\partial T}\right)_H
}
\tag{8}
```

を得る．
これが本問で用いるマクスウェルの関係式である．

### 3．断熱変化への適用

本問では，断熱的な準静的変化を考える．断熱過程では熱の出入りがなく，可逆過程ではエントロピー変化が

```math
ds=\frac{d'Q_{\mathrm{rev}}}{T}
```

で与えられるため，

```math
ds=0
```

となる．

したがって，式 (2) より，

```math
0=C_HdT+
T\left(\frac{\partial s}{\partial H}\right)_T dH
```

である．
ここに式 (8) のマクスウェルの関係式を代入すると，

```math
0=C_HdT+
T\left(\frac{\partial M}{\partial T}\right)_H dH
```

となる．
これを $dT$ について解けば，

```math
dT=-\frac{T}{C_H}
\left(\frac{\partial M}{\partial T}\right)_H dH
\tag{9}
```

を得る．

### 4．Curieの法則の適用

問題文より，磁化 $M$ はCurieの法則

```math
M=\frac{CH}{T}
```

に従う．
ここで， $C$ は定数である．
式 (9) に必要な偏微分は，磁場 $H$ を一定に保って温度 $T$ で微分することにより，

```math
\left(\frac{\partial M}{\partial T}\right)_H
=
\left(\frac{\partial}{\partial T}\frac{CH}{T}\right)_H
=-\frac{CH}{T^2}
```

となる．
これを式 (9) に代入すると，

```math
\begin{aligned}
dT
&=-\frac{T}{C_H}
\left(-\frac{CH}{T^2}\right)dH\\
&=\frac{CH}{C_HT}dH
\end{aligned}
```

となる．
よって，

```math
\boxed{
dT=\frac{CH}{C_HT}\,dH
}
```

が得られ，題意が示された．


## 解説

### 断熱変化で温度が変化する理由

本問の式は，磁場を変化させると，熱の出入りがない場合でも磁性体の温度が変化し得ることを示している．
これは磁気熱量効果に関係する現象である．
Curieの法則から，

```math
\left(\frac{\partial M}{\partial T}\right)_H
=-\frac{CH}{T^2}
```

であるため， $C>0$ ， $H>0$ ， $C_H>0$ の条件では，

```math
dT=\frac{CH}{C_HT}\,dH
```

となる．
したがって，磁場を増加させると温度が上昇し，磁場を減少させると温度が低下するという結果が得られる．
