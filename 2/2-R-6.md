# 例題【2-R-6】

## 解答

### 1．前提とエントロピーの全微分

磁性体の体積は一定とし，単位体積当たりの内部エネルギー，エントロピー，磁化をそれぞれ $u,s,M$ とする．
また，磁場 $H$ と磁化 $M$ は，問題文の式に対応する熱力学的な磁気仕事の規約に従うものとし，単位体積当たりの磁気的仕事を $H\,dM$ と表す．
体積変化による仕事など，磁気的仕事以外の仕事は考えない．

以下では，磁性体が平衡状態にあり，エントロピー $s$ と磁化 $M$ が温度 $T$ および磁場 $H$ の関数として十分滑らかに表されるものとする．

エントロピーの全微分は，

```math
ds=
\left(\frac{\partial s}{\partial T}\right)_H dT
+
\left(\frac{\partial s}{\partial H}\right)_T dH
```

である．
両辺に $T$ を掛けると，

```math
Tds=
T\left(\frac{\partial s}{\partial T}\right)_H dT
+
T\left(\frac{\partial s}{\partial H}\right)_T dH
\tag{1}
```

となる．

磁場一定のときの単位体積当たりの熱容量 $C_H$ は，

```math
C_H=T\left(\frac{\partial s}{\partial T}\right)_H
```

と定義される．
したがって，式 (1) は，

```math
Tds=C_HdT+
T\left(\frac{\partial s}{\partial H}\right)_T dH
\tag{2}
```

と書ける．

### 2．マクスウェルの関係式の導出

単位体積当たりの内部エネルギーの微小変化は，採用した磁気的仕事の規約のもとで，

```math
du=Tds+H\,dM
\tag{3}
```

と表される．

ここで， $s,M$ を $T,H$ の関数とみなす．
式 (3) に全微分を代入し， $dT,dH$ の係数を比較すると，

```math
\left(\frac{\partial u}{\partial T}\right)_H
=
T\left(\frac{\partial s}{\partial T}\right)_H
+
H\left(\frac{\partial M}{\partial T}\right)_H
\tag{4}
```

および，

```math
\left(\frac{\partial u}{\partial H}\right)_T
=
T\left(\frac{\partial s}{\partial H}\right)_T
+
H\left(\frac{\partial M}{\partial H}\right)_T
\tag{5}
```

を得る．

次に，式 (4) の両辺を $H$ で偏微分する．
このとき $T$ は一定であるから，

```math
\begin{aligned}
\frac{\partial}{\partial H}
\left(\frac{\partial u}{\partial T}\right)_H
={}&
T\frac{\partial^2s}{\partial H\partial T}
+\left(\frac{\partial M}{\partial T}\right)_H\\
&+H\frac{\partial^2M}{\partial H\partial T}
\end{aligned}
\tag{6}
```

となる．

一方，式 (5) の両辺を $T$ で偏微分する．
このとき $H$ は一定であるから，

```math
\begin{aligned}
\frac{\partial}{\partial T}
\left(\frac{\partial u}{\partial H}\right)_T
={}&
\left(\frac{\partial s}{\partial H}\right)_T
+T\frac{\partial^2s}{\partial T\partial H}\\
&+H\frac{\partial^2M}{\partial T\partial H}
\end{aligned}
\tag{7}
```

となる．

内部エネルギー $u$ が十分滑らかであれば，混合偏微分の交換可能性から，

```math
\frac{\partial}{\partial H}
\left(\frac{\partial u}{\partial T}\right)_H
=
\frac{\partial}{\partial T}
\left(\frac{\partial u}{\partial H}\right)_T
```

が成立する．
また，エントロピー $s$ と磁化 $M$ についても混合偏微分が交換可能であるとする．

したがって，式 (6) と式 (7) の左辺は等しく，右辺に現れる二階偏微分の項は相殺される．
残る項を比較すると，

```math
\left(\frac{\partial M}{\partial T}\right)_H
=
\left(\frac{\partial s}{\partial H}\right)_T
```

を得る．
よって，

```math
\boxed{
\left(\frac{\partial s}{\partial H}\right)_T
=
\left(\frac{\partial M}{\partial T}\right)_H
}
\tag{8}
```

となる．
これが，本問で採用した磁気的仕事の規約に対応するマクスウェルの関係式である．

### 3．断熱可逆変化への適用

ここでは，断熱可逆過程を考える．
断熱過程では系と外界との間に熱の出入りがなく，

```math
\delta Q=0
```

である．
また，可逆過程ではエントロピー生成がないため，エントロピー変化は，

```math
ds=\frac{\delta Q_{\mathrm{rev}}}{T}=0
```

となる．
したがって，

```math
ds=0
\tag{9}
```

である．

式 (2) に式 (9) を代入すると，

```math
0=C_HdT+
T\left(\frac{\partial s}{\partial H}\right)_T dH
```

となる．
ここに，式 (8) のマクスウェルの関係式を代入すれば，

```math
0=C_HdT+
T\left(\frac{\partial M}{\partial T}\right)_H dH
```

を得る．
これを $dT$ について解くと，

```math
\boxed{
dT=-\frac{T}{C_H}
\left(\frac{\partial M}{\partial T}\right)_H dH
}
\tag{10}
```

となる．

### 4．Curie の法則の適用

問題文より，磁化 $M$ は Curie の法則，

```math
M=\frac{CH}{T}
```

に従う．
ここで $C$ は定数である．

式 (10) に必要な偏微分を求める．
磁場 $H$ を一定に保って温度 $T$ で偏微分すると，

```math
\begin{aligned}
\left(\frac{\partial M}{\partial T}\right)_H
&=
\left(\frac{\partial}{\partial T}\frac{CH}{T}\right)_H\\
&=-\frac{CH}{T^2}
\end{aligned}
```

となる．
これを式 (10) に代入すると，

```math
\begin{aligned}
dT
&=-\frac{T}{C_H}
\left(-\frac{CH}{T^2}\right)dH\\
&=\frac{CH}{C_HT}\,dH
\end{aligned}
```

を得る．

したがって，

```math
\boxed{
dT=\frac{CH}{C_HT}\,dH
}
```

となり，題意が示された．

## 解説

### 1．断熱変化で温度が変化する理由

得られた式は，磁場を変化させると，熱の出入りがない場合でも磁性体の温度が変化し得ることを示している．
これは磁気熱量効果に関係する現象である．

Curie の法則から，

```math
\left(\frac{\partial M}{\partial T}\right)_H
=-\frac{CH}{T^2}
```

であるため， $C>0$ ， $H>0$ ， $C_H>0$ の条件では，

```math
dT=\frac{CH}{C_HT}\,dH
```

となる．
したがって，磁場を増加させると温度は上昇し，磁場を減少させると温度は低下する．
この結論は，断熱可逆過程における微小変化についてのものである．

### 2．適用条件と注意

本導出では，次の条件を仮定している．

- 磁性体の体積は一定である．
- 磁気的仕事以外の仕事は考えない．
- 磁性体は平衡状態にあり，状態量を $T,H$ の関数として表せる．
- 内部エネルギー，エントロピー，磁化は，必要な回数だけ連続微分可能である．
- 変化は断熱可逆過程である．
- $C_H\neq 0$ であり，式を $dT$ について解ける．

特に，断熱過程であっても不可逆過程ではエントロピーが生成され得るため，一般に $ds=0$ とはならない．
また，準静的過程であることだけでは可逆性は保証されない．
そのため，本問の導出では断熱可逆過程を明示している．

さらに，磁気的仕事の表現は単位系や磁場・磁化の定義に依存する．
本解答では，問題文の目標式に対応する $H\,dM$ の規約を採用した．
SI 単位系で通常の $H,M$ を用い，磁気的仕事を $\mu_0H\,dM$ と表す規約を採用する場合には，マクスウェルの関係式は，

```math
\left(\frac{\partial s}{\partial H}\right)_T
=
\mu_0\left(\frac{\partial M}{\partial T}\right)_H
```

となり，最終式にも $\mu_0$ が現れる．
したがって，問題文の式を用いる際には，磁気的仕事の単位系・定義を一貫させる必要がある．
