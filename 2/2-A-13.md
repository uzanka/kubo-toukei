# 演習問題【2-A-13】

## 解答

単位体積の常磁性体を考え，磁化を $M$ ，磁場を $H$ ，内部エネルギー密度を $U$ ，エントロピー密度を $S$ ，絶対温度を $T$ とする．

磁化率とその逆数は，

```math
\chi=\frac{M}{H},\qquad
\theta=\frac{1}{\chi}
```

で定義される．
したがって，

```math
H=M\theta
\tag{1}
```

である．

ただし，有限の磁場において一般に $M/H$ が磁化 $M$ に依存しないとは限らない．
そこで，本証明では，常磁性体の弱磁場における線形応答領域を考え，磁化率 $\chi$ は温度 $T$ のみの関数であると仮定する．
すなわち，

```math
M=\chi(T)H
```

とし，

```math
\theta=\frac{1}{\chi(T)}=\theta(T)
```

とする．

また，「内部エネルギーが磁化に依存しない」という条件は，温度 $T$ を独立変数として，

```math
\boxed{
\left(\frac{\partial U}{\partial M}\right)_T=0
}
\tag{2}
```

であると解釈する．

以下では，磁気的な仕事を $H\,dM$ とする単位系・符号規約を採用する．
SI 単位系で磁気仕事に $\mu_0$ が入る場合も，同じ導出によって結論が得られる．

### 1．Maxwell の関係式を導く

磁気的な仕事を考慮した熱力学の基本関係式は，

```math
dU=T\,dS+H\,dM
\tag{3}
```

である．
したがって，ヘルムホルツ自由エネルギー密度

```math
F=U-TS
```

の微分は，

```math
dF=dU-T\,dS-S\,dT
```

である．
式 (3) を代入すると，

```math
\boxed{
dF=-S\,dT+H\,dM
}
\tag{4}
```

を得る．

よって，ヘルムホルツ自由エネルギーの偏微分から，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_M,
\qquad
H=\left(\frac{\partial F}{\partial M}\right)_T
\tag{5}
```

となる．

ここで， $F$ が十分滑らかであり，混合二階偏微分の順序を交換できるとする．
すると，

```math
\frac{\partial}{\partial M}
\left(\frac{\partial F}{\partial T}\right)
=
\frac{\partial}{\partial T}
\left(\frac{\partial F}{\partial M}\right)
```

が成立する．
式 (5) を用いれば，

```math
-\left(\frac{\partial S}{\partial M}\right)_T
=
\left(\frac{\partial H}{\partial T}\right)_M
```

となる．
したがって，Maxwell の関係式として，

```math
\boxed{
\left(\frac{\partial S}{\partial M}\right)_T
=
-\left(\frac{\partial H}{\partial T}\right)_M
}
\tag{6}
```

を得る．

### 2．内部エネルギーの条件を用いる

内部エネルギー $U$ を温度 $T$ と磁化 $M$ の関数 $U(T,M)$ として表すと，

```math
dU=
\left(\frac{\partial U}{\partial T}\right)_M dT
+
\left(\frac{\partial U}{\partial M}\right)_T dM
```

である．

式 (3) と比較すれば，

```math
\left(\frac{\partial U}{\partial M}\right)_T
=
T\left(\frac{\partial S}{\partial M}\right)_T+H
\tag{7}
```

となる．

式 (6) を式 (7) に代入すると，

```math
\left(\frac{\partial U}{\partial M}\right)_T
=
H-T\left(\frac{\partial H}{\partial T}\right)_M
\tag{8}
```

を得る．

問題の条件 (2) より，式 (8) の左辺はゼロである．
したがって，

```math
0=H-T\left(\frac{\partial H}{\partial T}\right)_M
```

すなわち，

```math
\boxed{
T\left(\frac{\partial H}{\partial T}\right)_M=H
}
\tag{9}
```

が成立する．

### 3．磁化率の逆数と絶対温度の関係を導く

式 (1) より，

```math
H=M\theta(T)
```

である．

これを温度 $T$ について，磁化 $M$ を一定に保って偏微分すると，

```math
\left(\frac{\partial H}{\partial T}\right)_M
=
M\frac{d\theta}{dT}
\tag{10}
```

となる．

式 (1)，式 (10) を式 (9) に代入すると，

```math
TM\frac{d\theta}{dT}=M\theta
```

を得る．

磁化 $M\neq0$ の領域では，両辺を $M$ で割ることができるため，

```math
\boxed{
T\frac{d\theta}{dT}=\theta
}
\tag{11}
```

となる．

これを変形すると，

```math
\begin{aligned}
\frac{d}{dT}\left(\frac{\theta}{T}\right)
&=\frac{T\dfrac{d\theta}{dT}-\theta}{T^2}\\
&=0
\end{aligned}
```

となる．
最後の等号には式 (11) を用いた．

したがって，温度 $T>0$ の連結された状態領域において，

```math
\frac{\theta}{T}=k
```

という一定の比例定数 $k$ が存在する．
よって，

```math
\boxed{\theta=kT}
\tag{12}
```

を得る．

常磁性体の磁化率が正である領域では，

```math
\chi>0,\qquad \theta=\frac{1}{\chi}>0
```

であり，絶対温度も $T>0$ である．
したがって，

```math
k=\frac{\theta}{T}>0
```

となる．

### 4．結論

以上より，次の条件のもとで，

1. 内部エネルギーが温度一定のもとで磁化に依存しないこと，すなわち $\left(\partial U/\partial M\right)_T=0$ であること．
2. 磁化率が弱磁場の線形応答領域において温度のみの関数であり， $\theta=1/\chi=\theta(T)$ と表せること．
3. 熱力学的状態関数が十分滑らかで，Maxwell の関係式が適用できること．

磁化率の逆数 $\theta$ は熱力学的絶対温度 $T$ に比例し，

```math
\boxed{
\theta=kT\qquad(k>0)
}
```

が成立する．

したがって，

```math
\boxed{
\chi=\frac{1}{kT}
}
```

となり，磁化率は絶対温度に反比例する．

なお，比例定数 $k$ の数値は，物質の磁気的性質や採用する単位系に依存するため，本問の条件だけからは決定できない．

### 補足：追加仮定の必要性

元の問題文にある「内部エネルギーが磁化に依存しない」という条件だけでは，磁化率の逆数 $\theta$ が磁化 $M$ に依存しないことは一般には導けない．

もし $\theta=\theta(T,M)$ を許すなら，式 (9) から得られるのは，

```math
T\left(\frac{\partial\theta}{\partial T}\right)_M=\theta
```

であり，その一般解は，

```math
\theta(T,M)=T\,a(M)
```

となる．
ここで $a(M)$ は磁化に依存する任意の関数である．
したがって， $\theta/T$ が磁化にも依存しない一定値になるとは限らない．

ゆえに，問題の結論を得るためには，磁化率が磁化に依存せず温度のみの関数であるという仮定，あるいはそれと同等の線形応答条件が必要である．
