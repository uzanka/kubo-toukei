# 演習問題【2-A-13】

## 解答

単位体積の常磁性体を考える．磁化を $M$ ，磁場を $H$ ，内部エネルギーを $U$ ，系が吸収する微小熱量を $d'Q$ とする．
また，磁化率とその逆数を

```math
\chi=\frac{M}{H},\qquad
\theta=\frac{1}{\chi}
```

と定義する．
したがって，

```math
H=M\theta
\tag{1}
```

である．
問題の条件は，内部エネルギー $U$ が磁化 $M$ に依存しないということである．
また，磁化率 $\chi$ ，したがって $\theta$ も磁化 $M$ には依存せず，温度 $T$ のみの関数であるとする．

### 1．熱力学第1法則からエントロピーに関する関係式を導く

常磁性体に対する熱力学第1法則は，

```math
d'Q=dU-d'A
```

と表される．
ここで， $d'A$ は磁気的な仕事であり，

```math
d'A=H\,dM
```

である．
したがって，

```math
d'Q=dU-H\,dM
\tag{2}
```

を得る．

式 (1) の $H=M\theta$ を式 (2) に代入すると，

```math
d'Q=dU-M\theta\,dM
```

となる．
両辺を $\theta$ で割れば，

```math
\frac{d'Q}{\theta}
=\frac{dU}{\theta}-M\,dM
\tag{3}
```

を得る．

ここで，内部エネルギー $U$ と $\theta$ は温度 $T$ のみの関数であるから，

```math
U=U(T),\qquad \theta=\theta(T)
```

と書ける．
したがって，

```math
dU=\frac{dU}{dT}\,dT
```

であり，式 (3) は，

```math
\frac{d'Q}{\theta}
=
\frac{1}{\theta(T)}
\frac{dU}{dT}\,dT-M\,dM
\tag{4}
```

と表される．

右辺の第1項は温度 $T$ のみの関数と $dT$ の積であり，第2項は磁化 $M$ のみの関数と $dM$ の積である．
したがって，右辺は次の状態関数の全微分として表すことができる．

```math
\mathcal S(T,M)
=
\int^T\frac{1}{\theta(\tau)}
\frac{dU}{d\tau}\,d\tau
-\frac{M^2}{2}
```

実際に微分すると，

```math
d\mathcal S
=
\frac{1}{\theta(T)}
\frac{dU}{dT}\,dT-M\,dM
```

となる．
よって，式 (4) より，

```math
\boxed{
d\mathcal S=\frac{d'Q}{\theta}
}
\tag{5}
```

が成立する．
すなわち， $d'Q/\theta$ は完全微分であり， $\mathcal S$ は状態関数である．

この段階では， $\theta$ が絶対温度であるとはまだ結論できない．
次に，カルノーサイクルを用いて両者の関係を明らかにする．

### 2．カルノーサイクルによって絶対温度との関係を導く

この常磁性体を用いて，可逆なカルノーサイクルを構成する．
高温熱源の絶対温度を $T_1$ ，低温熱源の絶対温度を $T_2$ とし，

```math
T_1>T_2
```

とする．
それぞれの温度に対応する磁化率の逆数を，

```math
\theta_1=\theta(T_1),\qquad
\theta_2=\theta(T_2)
```

とする．
$\theta$ は温度のみの関数であるため，各等温過程では一定である．

このサイクルで，高温熱源から系が吸収する熱量を $Q_1>0$ ，低温熱源へ系が放出する熱量の大きさを $Q_2>0$ とする．

状態関数 $\mathcal S$ は，系が一周して元の状態に戻ると変化しないため，

```math
\oint d\mathcal S=0
```

である．
式 (5) を用いると，

```math
\oint\frac{d'Q}{\theta}=0
\tag{6}
```

となる．

サイクルのうち，熱の授受が行われるのは2つの等温過程である．
高温側では熱量 $Q_1$ を吸収し，低温側では熱量 $Q_2$ を放出するため，式 (6) は，

```math
\frac{Q_1}{\theta_1}
-\frac{Q_2}{\theta_2}=0
```

と書ける．
したがって，

```math
\boxed{
\frac{Q_1}{Q_2}
=\frac{\theta_1}{\theta_2}
}
\tag{7}
```

を得る．

一方，カルノーの定理によれば，可逆カルノーサイクルにおける吸収熱量と放出熱量の比は，熱源の絶対温度の比に等しい．
すなわち，

```math
\boxed{
\frac{Q_1}{Q_2}
=\frac{T_1}{T_2}
}
\tag{8}
```

である．

式 (7)，(8) を比較すると，

```math
\frac{\theta_1}{\theta_2}
=\frac{T_1}{T_2}
```

となる．
ここで $T_1,T_2$ は任意の2つの絶対温度であるから，

```math
\frac{\theta_1}{T_1}
=\frac{\theta_2}{T_2}
```

が任意の温度について成立する．
したがって， $\theta/T$ は温度によらない定数である．
この定数を $k$ とおけば，

```math
\boxed{
\theta=kT
}
```

となる．
磁化率の逆数 $\theta$ は正の温度尺度であるため， $k>0$ である．

### 3．結論

以上より，常磁性体の内部エネルギーが磁化 $M$ に依存せず，磁化率の逆数 $\theta=1/\chi$ が磁化に依存しないという条件のもとでは，

```math
\boxed{
\theta=kT\qquad (k>0)
}
```

が成立する．
すなわち，磁化率の逆数として定義される温度 $\theta$ は，熱力学的絶対温度 $T$ に比例することが示された．


## 解説

この結果は，磁化率が絶対温度に反比例すること，すなわち $\chi\propto 1/T$ を意味する．
ただし，比例定数 $k$ の数値は，磁化率の定義や単位系に依存するため，問題の条件だけからは決定できないのである．
