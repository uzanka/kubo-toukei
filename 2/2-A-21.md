# 演習問題【2-A-21】

## 解答

物質の質量を $M$ g，固体および液体の単位質量当たりの比熱をそれぞれ $c_s,c_l$ ，単位質量当たりの融解潜熱を $Q_0$ とする．
融解温度を $T_0$ ，過冷却液体および固体の温度を $T_1$ とし，

```math
T_1<T_0
```

とする．
ここで，温度はすべて絶対温度で表す．

求めるのは，同じ温度 $T_1$ にある過冷却液体と固体のエントロピーの差，

```math
\Delta S=S_{\mathrm{液体}}(T_1)-S_{\mathrm{固体}}(T_1)
```

である．

エントロピーは状態量であるため，その変化は経路に依存しない．
そこで，温度 $T_1$ の固体から温度 $T_1$ の過冷却液体へ直接変化させる代わりに，次の3段階からなる仮想的な可逆過程を考える．

```math
\begin{aligned}
&\text{温度 }T_1\text{ の固体}\\
&\quad\longrightarrow
\text{温度 }T_0\text{ の固体}\\
&\quad\longrightarrow
\text{温度 }T_0\text{ の液体}\\
&\quad\longrightarrow
\text{温度 }T_1\text{ の液体}
\end{aligned}
```

エントロピー変化は，各段階の変化量を足し合わせることで求められる．

### 1．過程①：固体を温度 $T_1$ から $T_0$ まで加熱する

固体の比熱 $c_s$ は温度によらず一定であると仮定する．
微小な温度上昇 $dT$ に対して吸収する熱量は，

```math
\delta Q_{\mathrm{rev}}=Mc_s\,dT
```

である．
したがって，この加熱によるエントロピー変化を $\Delta S_1$ とすると，

```math
\begin{aligned}
\Delta S_1
&=\int_{T_1}^{T_0}\frac{\delta Q_{\mathrm{rev}}}{T}\\
&=Mc_s\int_{T_1}^{T_0}\frac{dT}{T}\\
&=Mc_s\ln\frac{T_0}{T_1}
\end{aligned}
```

を得る．
よって，

```math
\boxed{
\Delta S_1=Mc_s\ln\frac{T_0}{T_1}
}
\tag{1}
```

である．
$T_0>T_1$ であるため，この段階ではエントロピーが増加する．

### 2．過程②：温度 $T_0$ で固体を融解する

次に，温度 $T_0$ を一定に保ったまま，固体を液体へと融解させる．
単位質量当たりの融解潜熱が $Q_0$ であるため，質量 $M$ の物質が吸収する熱量は，

```math
Q_{\mathrm{melt}}=MQ_0
```

である．

融解は一定温度 $T_0$ で起こるため，エントロピー変化 $\Delta S_2$ は吸収熱量を温度で割った量となる．
したがって，

```math
\Delta S_2=\frac{MQ_0}{T_0}
```

を得る．
すなわち，

```math
\boxed{
\Delta S_2=\frac{MQ_0}{T_0}
}
\tag{2}
```

である．
融解では熱を吸収するため，この段階のエントロピー変化は正である．

### 3．過程③：液体を温度 $T_0$ から $T_1$ まで冷却する

最後に，液体を温度 $T_0$ から $T_1$ まで冷却する．
液体の比熱 $c_l$ も温度によらず一定であるため，この過程での微小熱量は，

```math
\delta Q_{\mathrm{rev}}=Mc_l\,dT
```

と表される．
冷却過程では $dT<0$ であるため，系が吸収する熱量は負となる．

この過程のエントロピー変化 $\Delta S_3$ は，

```math
\begin{aligned}
\Delta S_3
&=\int_{T_0}^{T_1}\frac{\delta Q_{\mathrm{rev}}}{T}\\
&=Mc_l\int_{T_0}^{T_1}\frac{dT}{T}\\
&=Mc_l\ln\frac{T_1}{T_0}\\
&=-Mc_l\ln\frac{T_0}{T_1}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\Delta S_3=-Mc_l\ln\frac{T_0}{T_1}
}
\tag{3}
```

である．
冷却では熱を放出するため，エントロピー変化は負である．

### 4．全エントロピー変化を求める

エントロピーは状態量であるため，初期状態から最終状態までのエントロピー変化は，3段階の変化量の和である．
したがって，

```math
\Delta S=\Delta S_1+\Delta S_2+\Delta S_3
```

である．
式 (1)，(2)，(3) を代入すると，

```math
\begin{aligned}
\Delta S
&=Mc_s\ln\frac{T_0}{T_1}
+\frac{MQ_0}{T_0}
-Mc_l\ln\frac{T_0}{T_1}\\
&=\frac{MQ_0}{T_0}
-M(c_l-c_s)\ln\frac{T_0}{T_1}
\end{aligned}
```

となる．
よって，求めるエントロピー差は，

```math
\boxed{
S_{\mathrm{液体}}(T_1)-S_{\mathrm{固体}}(T_1)
=
M\left[
\frac{Q_0}{T_0}
-(c_l-c_s)\ln\frac{T_0}{T_1}
\right]
}
```

である．

この式の右辺が正であれば，同温度の過冷却液体は固体よりもエントロピーが大きい．
一方，右辺が負であれば，その温度では過冷却液体のエントロピーの方が小さい．
具体的な大小関係を判断するには， $Q_0,c_s,c_l,T_0,T_1$ の値が必要である．


## 解説

解答例と同じ経路分割によって，過冷却液体と同温度の固体とのエントロピー差は，

```math
\boxed{
\Delta S=M\left[
\frac{Q_0}{T_0}
-(c_l-c_s)\ln\frac{T_0}{T_1}
\right]
}
```

と求められる．
この式は，融解に伴うエントロピー増加と，比熱の違いによる温度依存の補正を表している．
