# 演習問題【2-A-24】

## 解答

### 1. エンタルピー一定の実験であることを示す

Joule-Thomson の実験では，断熱壁をもつ管の中に綿栓をつめ，高圧側（圧力 $p_1$ ，温度 $T_1$ ）から低圧側（圧力 $p_2$ ，温度 $T_2$ ）へ気体を定常的に流し出す．

第 $n$ モルの気体が綿栓を通過するとする．
低圧側のピストンが気体に単位時間あたり行う仕事は

$$W_{\text{in}} = p_1 V_1 = p_1 \cdot n \bar{V}(p_1, T_1)$$

高圧側のピストンが気体から受ける仕事は

$$W_{\text{out}} = p_2 V_2 = p_2 \cdot n \bar{V}(p_2, T_2)$$

ここで $\bar{V}(p, T)$ はモル体積である．
管は断熱壁で囲まれているので，系と外界との熱のやり取りはない（ $Q = 0$ ）．
熱力学第一法則より，気体の内部エネルギーの変化 $\Delta U$ はなされた正味の仕事に等しい：

$$\Delta U = U_2 - U_1 = W_{\text{in}} - W_{\text{out}} = p_1 V_1 - p_2 V_2$$

これを整理すると，

$$U_2 + p_2 V_2 = U_1 + p_1 V_2$$

すなわち，

$$H_2 = H_1$$

ここで $H = U + pV$ はエンタルピーである．
したがって，Joule-Thomson の実験は**エンタルピー一定（等エンタルピー）過程**を実験的に実現していることが示された．
$\quad \blacksquare$

---

### 2. Joule-Thomson 係数の公式の導出

エンタルピー $H$ は温度 $T$ と圧力 $p$ の関数 $H(T, p)$ であるから，その全微分は次のように書ける．

$$dH = \left(\frac{\partial H}{\partial T}\right)_p dT + \left(\frac{\partial H}{\partial p}\right)_T dp$$

等エンタルピー過程（ $dH = 0$ ）において，圧力の変化 $dp$ に対する温度の変化 $dT$ を求める：

$$0 = \left(\frac{\partial H}{\partial T}\right)_p dT + \left(\frac{\partial H}{\partial p}\right)_T dp$$

三つ積の公式（連鎖律）より，

$$\left(\frac{\partial T}{\partial p}\right)_H = -\frac{\left(\frac{\partial H}{\partial p}\right)_T}{\left(\frac{\partial H}{\partial T}\right)_p} \quad \cdots (\text{A})$$

ここで，定圧熱容量 $C_p$ は次のように定義される．

$$C_p = \left(\frac{\partial H}{\partial T}\right)_p$$

また，熱力学の基本関係式 $dH = TdS + Vdp$ を用いて， $(\frac{\partial H}{\partial p})_T$ を求める．

$$\left(\frac{\partial H}{\partial p}\right)_T = T \left(\frac{\partial S}{\partial p}\right)_T + V$$

ここで，マクスウェルの関係式 $\left(\frac{\partial S}{\partial p}\right)_T = -\left(\frac{\partial V}{\partial T}\right)_p$ （Gibson 自由エネルギー $dG = -SdT + Vdp$ の交叉微分の等価性から導かれる）を用いると，

$$\left(\frac{\partial H}{\partial p}\right)_T = -T \left(\frac{\partial V}{\partial T}\right)_p + V$$

これらを式 (A) に代入すると，求める Joule-Thomson 係数の公式が得られる．

$$\left(\frac{\partial T}{\partial p}\right)_H = -\frac{-T\left(\frac{\partial V}{\partial T}\right)_p + V}{C_p} = \frac{T\left(\frac{\partial V}{\partial T}\right)_p - V}{C_p} \quad \cdots (1)$$

### 3. 状態方程式を用いた係数の簡略化

与えられた近似的な状態方程式 $pV = RT + B(T)p$ を用いて，係数を $B$ で表す．
この式を $V$ について解くと，

$$V = \frac{RT}{p} + B(T)$$

この $V$ を用いて， $(\frac{\partial V}{\partial T})_p$ を計算する．
圧力 $p$ を一定として温度 $T$ で偏微分すると， $B$ は $p$ に依存しないので，

$$\left(\frac{\partial V}{\partial T}\right)_p = \frac{R}{p} + \frac{dB}{dT} \quad \cdots (2)$$

これを式 (1) の分子に代入する．

$$T\left(\frac{\partial V}{\partial T}\right)_p - V = T\left(\frac{R}{p} + \frac{dB}{dT}\right) - \left(\frac{RT}{p} + B\right)$$

$$= \frac{RT}{p} + T\frac{dB}{dT} - \frac{RT}{p} - B = T\frac{dB}{dT} - B$$

よって，Joule-Thomson 係数は

$$\left(\frac{\partial T}{\partial p}\right)_H = \frac{T\frac{dB}{dT} - B}{C_p} \quad \cdots (3)$$

---

### 4. 理想気体の極限

理想気体の場合，分子間の相互作用がないので $B(T) = 0$ である．
このとき式 (3) より

$$\left(\frac{\partial T}{\partial p}\right)_H = 0$$

すなわち，理想気体は Joule-Thomson 膨張において温度変化しない．
これは理想気体の性質と一致する． $\blacksquare$

## 解説

### Joule-Thomson 係数とは

Joule-Thomson 係数 $\mu_{\text{JT}} = (\partial T/\partial p)_H$ は，断熱膨張によって気体の温度がどのように変化するかを表す指標である．
- $\mu_{\text{JT}} > 0$ の場合：圧力が下がる（ $\Delta p < 0$ ）と温度も下がる（ $\Delta T < 0$ ），すなわち**冷却効果**が生じる．
- $\mu_{\text{JT}} < 0$ の場合：圧力が下がる（ $\Delta p < 0$ ）と温度が上がる（ $\Delta T > 0$ ），すなわち**加熱効果**が生じる．

### 逆転温度 (Inversion Temperature)

式 (3) において， $\mu_{\text{JT}} = 0$ となる条件は

$$T \frac{dB}{dT} - B = 0 \quad \Longleftrightarrow \quad \frac{dB}{dT} = \frac{B}{T}$$

である．
これは， $B(T)$ と $T$ のグラフにおいて，**原点から引いた直線の傾きが $B/T$ に等しくなる点**，すなわち原点から $B(T)$ 曲線に引いた**接線**との交点に対応する（図1）．

この $\mu_{\text{JT}} = 0$ となる温度 $T_i$ を**逆転温度**と呼ぶ．
- $T < T_i$ では $\mu_{\text{JT}} > 0$ となり，膨張によって冷却される．
- $T > T_i$ では $\mu_{\text{JT}} < 0$ となり，膨張によって加熱される．

実在気体（例えば $\text{CO}_2$ など）を冷却用途で使用する場合，使用する温度範囲が逆転温度よりも低い領域にあることを確認する必要がある．

### 状態方程式の表記について

問題文の状態方程式 $pV = RT + B(T)p$ は，第2ビリアル係数 $B(T)$ を用いて気体の理想気体からのずれを表している．
$B(T)$ は温度の関数であり，次元は[体積・モル$^{-1}$]を持つ．
解答例で時折見られる $pV = RT(1 + Bp)$ という表記は，本質的には同じ形だが，この場合の $B$ は元の $B/(RT)$ に対応し，次元が[圧力$^{-1}$]に変わるため注意が必要である．
