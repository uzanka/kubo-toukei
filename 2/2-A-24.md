# 演習問題【2-A-24】

## 解答

### 1．Joule–Thomson 実験がエンタルピー一定であることの証明

Joule–Thomson 実験では，断熱管の中にある綿栓を通して，気体を高圧側の状態 1 から低圧側の状態 2 へ定常的に流す．
高圧側の圧力と温度を $p_1,T_1$ ，低圧側の圧力と温度を $p_2,T_2$ とする．
ここで $p_1>p_2$ である．

管は断熱されているため，外界との熱のやり取りはない．
また，軸仕事がなく，流入側と流出側の運動エネルギーおよび位置エネルギーの差を無視できるとする．

流体が管に流入するとき，高圧側の気体は流体を押し込むために，単位物質量あたり $p_1V_1$ の流動仕事をする．
一方，流体が低圧側へ流出するときには，単位物質量あたり $p_2V_2$ の流動仕事を外部に対して行う．
ここで $V_1,V_2$ はモル体積である．

熱力学第一法則より，内部エネルギー $U$ の変化は，流入側で受け取る仕事から流出側で行う仕事を差し引いたものとなる．
したがって，

```math
U_2-U_1=p_1V_1-p_2V_2
```

である．これを整理すると，

```math
U_2+p_2V_2=U_1+p_1V_1
```

となる．
エンタルピーを

```math
H=U+pV
```

と定義すれば，

```math
\boxed{
H_2=H_1
}
```

を得る．
したがって，Joule–Thomson 実験は，流体のエンタルピーが流入側と流出側で等しい実験，すなわち **等エンタルピー過程** である．

### 2．Joule–Thomson 係数の導出

Joule–Thomson 係数は，エンタルピーを一定に保ったときの温度の圧力に対する変化率

```math
\mu_{\mathrm{JT}}
\equiv
\left(\frac{\partial T}{\partial p}\right)_H
```

で定義される．
以下では，この係数を定圧熱容量 $C_p$ と体積の偏微分で表す．

エンタルピー $H$ を温度 $T$ と圧力 $p$ の関数と考えると，全微分は

```math
dH=
\left(\frac{\partial H}{\partial T}\right)_p dT
+
\left(\frac{\partial H}{\partial p}\right)_T dp
```

と書ける．
エンタルピー一定の条件 $dH=0$ を代入すると，

```math
0=
\left(\frac{\partial H}{\partial T}\right)_p dT
+
\left(\frac{\partial H}{\partial p}\right)_T dp
```

である．
これを $dT/dp$ について整理すれば，

```math
\left(\frac{\partial T}{\partial p}\right)_H
=
-\frac{
\left(\frac{\partial H}{\partial p}\right)_T
}{
\left(\frac{\partial H}{\partial T}\right)_p
}
\tag{1}
```

を得る．

定圧熱容量 $C_p$ は，圧力一定のもとでのエンタルピーの温度変化率として，

```math
C_p=\left(\frac{\partial H}{\partial T}\right)_p
\tag{2}
```

と定義される．
したがって，式 (1) の分母は $C_p$ である．

次に，分子の $\left(\partial H/\partial p\right)_T$ を求める．
単純な圧縮性物質について，エンタルピーの微分は

```math
dH=T\,dS+V\,dp
```

と表される．
これを温度一定の条件で微分すると，

```math
\left(\frac{\partial H}{\partial p}\right)_T
=
T\left(\frac{\partial S}{\partial p}\right)_T+V
\tag{3}
```

となる．

ここで，ギブズ自由エネルギー $G=H-TS$ の全微分

```math
dG=-S\,dT+V\,dp
```

から導かれるマクスウェルの関係式

```math
\left(\frac{\partial S}{\partial p}\right)_T
=
-\left(\frac{\partial V}{\partial T}\right)_p
\tag{4}
```

を用いる．
式 (4) を式 (3) に代入すれば，

```math
\left(\frac{\partial H}{\partial p}\right)_T
=
-T\left(\frac{\partial V}{\partial T}\right)_p+V
\tag{5}
```

を得る．

式 (2) と式 (5) を式 (1) に代入すると，

```math
\left(\frac{\partial T}{\partial p}\right)_H
=
-\frac{-T\left(\frac{\partial V}{\partial T}\right)_p+V}{C_p}
```

となる．
よって，求める Joule–Thomson 係数は

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_H
=
\frac{
T\left(\frac{\partial V}{\partial T}\right)_p-V
}{C_p}
}
\tag{6}
```

である．

### 3．状態方程式を用いた Joule–Thomson 係数の表現

問題文の状態方程式は

```math
pV=RT+B(T)p
```

である．
ここで $V$ はモル体積， $R$ は気体定数， $B(T)$ は温度の関数である．
この式を $V$ について解くと，

```math
V=\frac{RT}{p}+B(T)
\tag{7}
```

となる．

式 (7) を，圧力 $p$ を一定に保って温度 $T$ について偏微分すると，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=
\frac{R}{p}+\frac{dB}{dT}
\tag{8}
```

である．
これを式 (6) の分子に代入すれば，

```math
\begin{aligned}
T\left(\frac{\partial V}{\partial T}\right)_p-V
&=
T\left(\frac{R}{p}+\frac{dB}{dT}\right)
-\left(\frac{RT}{p}+B\right)\\
&=\frac{RT}{p}+T\frac{dB}{dT}
-\frac{RT}{p}-B\\
&=T\frac{dB}{dT}-B
\end{aligned}
```

となる．
したがって，求める Joule–Thomson 係数は

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_H
=
\frac{T\frac{dB}{dT}-B}{C_p}
}
\tag{9}
```

である．

### 4．係数の符号と逆転温度

通常 $C_p>0$ であるため，式 (9) から Joule–Thomson 係数の符号は $T\,dB/dT-B$ の符号によって決まる．
圧力が高圧側から低圧側へ下がるときは $dp<0$ であり，微小な変化について

```math
dT=\mu_{\mathrm{JT}}\,dp
```

が成り立つ．
したがって， $\mu_{\mathrm{JT}}>0$ なら温度は低下し， $\mu_{\mathrm{JT}}<0$ なら温度は上昇する．

Joule–Thomson 係数がゼロになる温度を逆転温度 $T_i$ と呼ぶ．
式 (9) より，その条件は

```math
T_i\left.\frac{dB}{dT}\right|_{T_i}=B(T_i)
```

すなわち，

```math
\left.\frac{dB}{dT}\right|_{T_i}
=\frac{B(T_i)}{T_i}
```

である．
これは， $B(T)$ のグラフ上の点 $(T_i,B(T_i))$ における接線の傾きが，原点とその点を結ぶ直線の傾きに等しいことを意味する．
したがって，逆転温度では，原点を通る直線が $B(T)$ の曲線に接する．

なお，この近似状態方程式では，逆転温度の条件に圧力が明示的に現れないため，逆転温度はこの近似の範囲では圧力に依存しない．
また，逆転温度の上下で係数の符号がどちら向きに変わるかは， $B(T)$ の具体的な形によって決まる．

理想気体では $B(T)=0$ であるため，式 (9) は

```math
\left(\frac{\partial T}{\partial p}\right)_H=0
```

となる．
したがって，理想気体は Joule–Thomson 実験において温度変化を示さない．
