# 演習問題【2-B-30】

## 解答

### 1. Thomsonの原理とCarathéodoryの原理の定言

まず両原理を明確に定言する．

**Thomsonの原理**（Kelvin-Planckの定言）：
> 単一熱源から熱を受け取り，それをすべて仕事に変換する循環過程（第二種永動機械）は存在しない．

すなわち，温度 T の熱源から熱量 Q を受け取って仕事 W を得る循環過程においては，Q = W （すべての熱が仕事に変わる）となることはあり得ない．
必ず一部の熱を低温の熱源へと捨てなければならない．

**Carathéodoryの原理**（断熱到達不能性）：
> 平衡状態の任意の近傍には，断熱過程（dQ = 0）では到達できない状態が存在する．

これらを結びつける橋渡しとして，Carnotサイクルと積分因子の概念を用いる．

---

### 2. Thomsonの原理 ⇔ Carnotの定理

**Carnotの定理**：
> いかなる熱機関も，高温熱源 TH から熱量 QH を受け取り，低温熱源 TL に熱量 QL を捨てて仕事 W = QH − QL を行う循環過程である．
このとき効率 η = W/QH は用いられる物質に依らず η ≤ TL/TH であり，可逆機関のみが等号を満たす．

Carnotの定理の **Thomsonの原理からの導出** を証明する．

可逆熱機関 Erev が効率 ηrev = QL/QH = TL/TH よりも大きいと仮定する（背理法）．
Erev の低温側から高温側に熱量を流す熱機械 M （外界からの仕事 W を使って熱を逆流させる）を組み合わせる．
M が消費する仕事が Erev が生み出す仕事より小さければ，正味の外界との仕事のやり取りはゼロとしながら，高温熱源から低温熱源へ正味の熱が流れる．
これを逆に回せば，低温熱源のみから熱を受け取ってすべて仕事に変換する第二種永動機械が作れてしまう．
これはThomsonの原理に矛盾する．
したがって ηrev ≰ TL/TH であり，同様の議論によりηrev ≥ TL/TH も導かれることから，

$$\eta_{\text{rev}} = \frac{T_L}{T_H}$$

が得られる．
これがCarnotの定理である．

---

### 3. Carnotの定理 → δQ の積分因子の存在

2つの独立変数 (V, T) で記される系を考える．
可逆Carnotサイクルを構成する正の無限小の帯（thin ribbon）を検討する．
これは隣接する2つの断熱過程（dQ = 0 を満たす曲線）と，隣接する2つの等温過程（T と T + dT ）からなる平行四辺形である（図1）．

この微小Carnotサイクルで吸収される正味の熱量 δQ_cycle は：
$$\delta Q_{\text{cycle}} = C \, dV \, dT$$
と書ける（C は係数）．
一方，可逆機関としての効率から：

$$\delta W = \delta Q_{\text{cycle}} = (T + dT - T) \cdot (\text{断熱の間隔}) = dT \cdot (\text{定数}) $$

Carnotの定理 η = TL/TH を微小サイクルに適用すると，正味の吸収熱量 δQ_cycle がゼロにならないこと，しかし **δQ/T が完全微分形になる** ことが導かれる．

より抽象的に述べる．
2変数 (x, y) のPfaff形式：

$$\delta Q = A(x,y)\,dx + B(x,y)\,dy$$

を考える．
Carnotの定理は，すべての断熱曲線（δQ = 0）が一点で交わらない（断熱が互いに交差しない＝Thomsonの原理の帰結）ことを意味する．
数学的に，これはいかなる2つの断熱曲線も交わり得ず，空間を「層」として満たすことから，**δQ にゼロでない関数 λ(x, y) （積分因子）が存在して**：

$$\lambda(x,y)\,\delta Q = dS$$

が完全微分となる．
この λ は 1/T （逆温度）に比例し，dS はエントロピー S という状態量の微小変化である．

---

### 4. エントロピーの構成とCarathéodoryの原理

積分因子 λ = 1/T が存在することで，エントロピー：
$$dS = \frac{\delta Q_{\text{rev}}}{T}$$
が状態量として定義される．
すなわち，ある状態 (x₀, y₀) から他の状態 (x₁, y₁) へ至る過程で，δQ/T の積分の値は経路に依らない．

ここでCarathéodoryの原理を証明する．
(x₀, y₀) の十分小さな近傍を考え，その中を通過する断熱曲線 δQ = 0 （すなわち dS = 0 ）を引き，それを等エントロピー線と考える．
この等エントロピー線は (x₀, y₀) を通る **1本の曲線** しか引けない（S = const が1変数方程式で曲面を規定）．

近傍内の任意の点 (x, y) について，もしそれが S(x, y) = S(x₀, y₀) を満たさなければ，その点は断熱過程では到達できない（断熱過程では S が保存されるから）．
すなわち：

$$S(x,y) \neq S(x_0,y_0) \quad \text{の点} \quad (x,y) \text{は断熱不可達．}$$

(x₀, y₀) の近傍は2次元であり，S = const が1本の曲線（1次元）を規定するだけなので，近傍内の almost all の点は断熱不可達である．
したがって：

> **Carathéodoryの原理**：平衡状態の任意の近傍には，断熱過程では到達できない状態が存在する．

が示された．

### 5. 磁気系への適用（解答例との整合性）

磁性体 (H, M) にこの枠組みを適用すると，δQ = TdS は：

$$dS = \frac{1}{T}(dU - H\,dM)$$

と表される．
Scalings則 M = f(H/T) の下では (∂U/∂M)T = 0 が導かれ，エントロピーは：

$$S(T,H) = g(T) - \frac{H}{T}f\!\left(\frac{H}{T}\right) + \int_0^{H/T}\! f(x)\,dx + \text{const.}$$

Curie則 f(x) = Cx のとき：

$$S(T,H) = g(T) - \frac{C}{2}\!\left(\frac{H}{T}\right)^{\!2} + \text{const.}$$

これは解答例の計算結果と一致する．
ただし，これらは Carathéodoryの原理が導かれた **後の応用計算** であり，原理的導出そのものではない．
原理的導出は Sections 1–4 で示した通り．

## 解説

### Thomson → Carnot → 積分因子 → エントロピー → Carathéodory の論理連鎖

1. **Thomsonの原理**（単一熱源からの完全熱変換の不可能性）
   ↓ （背理法：反例を仮定すると第二種永動機械が作れる）
2. **Carnotの定理**（可逆機関の効率が物質に依らず TH/TL だけ）
   ↓ （微小Carnotサイクルの分析）
3. **積分因子 λ = 1/T の存在**（δQλ が完全微分 dS ）
   ↓ （Sの状態量定義）
4. **エントロピー S の状態量としての定義**
   ↓ （断熱過程では S が保存）
5. **Carathéodoryの原理**（S = const の曲面以外へは到達できない）

### 解答例について

本問題の解答例もまた「磁性体の熱力学と断熱消磁冷却の計算」を展開している．
これは Carathéodoryの原理が与えられた **後の応用** であって，Thomson→Carathéodory の導出そのものではない．
解答例に含まれる (∂U/∂M)T = 0 の導出，エントロピーの積分形，Curie則への代入はすべて正しい計算ではあるが，問題の要求（原理的導出）には答えていない．

提出解答も同様であり，原理的導出を本題に加える必要がある．
