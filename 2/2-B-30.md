# 演習問題【2-B-30】

## 解答

### 1．原理の述べ方と基本的な前提

**Thomson の原理（Kelvin–Planck の原理）**

単一の熱源から正の熱量を取り出し，それをすべて仕事に変換し，他に何の変化も残さずに一周期の運転を終える装置は存在しない．

**Carathéodory の原理**

任意の平衡状態の任意の近傍に，その状態から準静的断熱過程によっては到達できない平衡状態が存在する．

本証明では，準静的断熱過程の経路が近傍内にとどまることは要求しない．

以下，単純な閉じた熱力学系を考える．
平衡状態は，経験温度 $\theta$ と，系と外界との間の仕事の授受を記述するすべての一般化変数 $x_1,\ldots,x_n$ によって指定されるものとする．

状態空間 $\Omega$ は $(n+1)$ 次元の開集合であり，内部エネルギー $U$ は $\Omega$ 上の連続微分可能な状態関数とする．

準静的過程において，系が外部にする仕事を

```math
\delta W_{\mathrm{by}}
=\sum_{i=1}^{n}A_i\,dx_i
```

と定義する．
ここで $A_i$ は状態の連続関数である．

熱は系が吸収する向きを正，仕事は系が外部にする向きを正とする．

この符号規約における熱力学第一法則は，

```math
dU=\delta Q-\delta W_{\mathrm{by}}
```

である．
したがって，

```math
\begin{aligned}
\delta Q
&=dU+\sum_{i=1}^{n}A_i\,dx_i\\
&=q_0\,d\theta+\sum_{i=1}^{n}q_i\,dx_i
\end{aligned}
\tag{1}
```

となる．

ここで，

```math
q_0=
\left(\frac{\partial U}{\partial\theta}\right)_x
```

および

```math
q_i=
\left(\frac{\partial U}{\partial x_i}\right)_\theta+A_i
```

である．
各係数は連続関数とする．

式 (1) は，系が平衡状態を経ながら進む準静的過程に対する熱量の微分形式である．
一方，熱力学第一法則の積分形

```math
\boxed{\Delta U=Q-W_{\mathrm{by}}}
```

は，非準静的過程を含む一般の過程に対しても成立する．

本証明では，以下の熱力学的条件を採用する．

**(i) 準静的断熱過程の可逆性**

Carathéodory の原理における到達可能性を判定する準静的断熱過程は可逆であり，その逆過程も実現できるものとする．

**(ii) 正の熱容量**

固定された力学的変数のもとでの熱容量は正であるとする．
すなわち，

```math
\boxed{
q_0=
\left(\frac{\partial U}{\partial\theta}\right)_x>0
}
```

が考察する状態空間で成立するものとする．

**(iii) 通常の熱的接触と加熱操作の実現可能性**

経験温度 $\theta$ は高温ほど大きくなるように定める．
系より高温の熱源と熱的に接触させると，熱源から系へ熱が移動するものとする．

また，熱源は十分大きく，その温度は一定に保たれるものとする．

固定された力学的変数のもとで，系の内部を平衡状態に保ちながら熱源と接触させ，任意の目標温度まで加熱できるものとする．
目標温度に達した時点で熱源との接触を切ることができるものとする．

この加熱過程では，すべての一般化仕事変数を固定し，電気的仕事，軸仕事，攪拌仕事など，その他の仕事の授受も行わないものとする．

以上は，本証明で使用する熱的接触と操作の実現可能性を明示した前提である．

なお，準静的過程であることは，可逆過程であることを意味しない．
有限の温度差をもつ熱源との熱交換は，系が内部平衡を保ちながら進む場合でも不可逆になり得る．

### 2．背理法の仮定

Carathéodory の原理が成立しないと仮定する．

すると，ある平衡状態

```math
P_0=(\theta_0,x^0)\in\Omega
```

と，その開近傍 $D$ が存在し， $D$ 内のすべての平衡状態が $P_0$ から準静的断熱過程によって到達可能である．

断熱経路は $D$ の外側を通ってもよい．

$D$ は $P_0$ の開近傍であるから，十分小さい正の数 $\varepsilon$ を選ぶことにより，

```math
P_1=(\theta_0+\varepsilon,x^0)\in D
```

とできる．

さらに，線分

```math
L=
\left\{
(\theta,x^0)
\mid
\theta_0\leq\theta\leq\theta_0+\varepsilon
\right\}
```

全体が $D$ に含まれるように選ぶことができる．

このとき， $P_0$ と $P_1$ はすべての力学的変数が同じであり，温度だけが異なる平衡状態である．

背理法の仮定より，準静的断熱過程

```math
\alpha:P_0\longrightarrow P_1
```

が存在する．

前提 (i) より，逆過程

```math
\alpha^{-1}:P_1\longrightarrow P_0
```

も準静的断熱過程として実現できる．

したがって，

```math
\boxed{Q_{\alpha^{-1}}=0}
\tag{2}
```

である．

### 3．Thomson の原理に反するサイクルの構成

次の二つの過程を組み合わせて，閉じたサイクルを構成する．

#### 3.1 過程 $\beta$ ：単一熱源による加熱

温度

```math
\theta_R>\theta_0+\varepsilon
```

の熱源を1つ用意する．

この熱源と系を熱的に接触させ，すべての一般化仕事変数を

```math
x_i=x_i^0
```

に固定したまま，系を $P_0$ から $P_1$ まで加熱する．

前提 (iii) より，加熱中は熱源から系へ熱が移動する．
また，熱源の温度は一定に保たれる．

加熱は系の内部が平衡状態を保つようにゆっくり行う．
一方，熱源と系の温度には有限の差があるため，この加熱過程は一般には不可逆である．

目標状態 $P_1$ に達した時点で熱源との接触を切る．

この過程では，すべての一般化仕事変数が一定であり，その他の仕事の授受もないため，

```math
\boxed{W_\beta=0}
\tag{3}
```

である．

過程 $\beta$ は準静的な平衡状態間の過程として実施されるので，式 (1) を適用できる．

この過程では，

```math
dx_i=0
```

であるから，

```math
\delta Q=q_0\,d\theta
```

となる．

したがって，系が吸収する熱量は，

```math
\begin{aligned}
Q_\beta
&=\int_\beta\delta Q\\
&=\int_{\theta_0}^{\theta_0+\varepsilon}
q_0(\theta,x^0)\,d\theta.
\end{aligned}
```

前提 (ii) より，

```math
q_0(\theta,x^0)>0
```

であり，また $\varepsilon>0$ であるから，

```math
\boxed{
Q_\beta=
\int_{\theta_0}^{\theta_0+\varepsilon}
q_0(\theta,x^0)\,d\theta>0
}
\tag{4}
```

を得る．

同じ結果は，第一法則からも確認できる．

過程 $\beta$ の内部エネルギー変化は，

```math
\Delta U_\beta=U(P_1)-U(P_0)
```

であり，式 (3) より，

```math
Q_\beta=\Delta U_\beta
```

である．

$U$ は状態関数なので，

```math
\begin{aligned}
U(P_1)-U(P_0)
&=U(\theta_0+\varepsilon,x^0)
-U(\theta_0,x^0)\\
&=\int_{\theta_0}^{\theta_0+\varepsilon}
\left(\frac{\partial U}{\partial\theta}\right)_x d\theta\\
&=\int_{\theta_0}^{\theta_0+\varepsilon}
q_0(\theta,x^0)\,d\theta.
\end{aligned}
```

したがって，式 (4) と一致する．

ここでの積分は，平衡状態に沿った熱量の積分であり，内部エネルギー差については状態関数としても同じ値が得られる．

#### 3.2 過程 $\alpha^{-1}$ ：断熱復帰

次に，加熱によって得られた状態 $P_1$ から，準静的断熱過程 $\alpha$ の逆過程を実行する．

すなわち，

```math
P_1\xrightarrow{\alpha^{-1}}P_0
```

とする．

この過程は断熱過程であるため，

```math
\boxed{
Q_{\alpha^{-1}}=0
}
```

である．

また，この過程では熱源との熱の授受はない．

#### 3.3 サイクル全体のエネルギー収支

以上の二つの過程を組み合わせると，

```math
P_0\xrightarrow{\beta}P_1
\xrightarrow{\alpha^{-1}}P_0
```

という一周期のサイクルが完成する．

系は初期状態に戻るので，

```math
\Delta U_{\mathrm{cyc}}=0
```

である．

サイクル全体で系が吸収する熱量は，

```math
\begin{aligned}
Q_{\mathrm{cyc}}
&=Q_\beta+Q_{\alpha^{-1}}\\
&=Q_\beta\\
&>0.
\end{aligned}
```

第一法則の積分形より，

```math
\Delta U_{\mathrm{cyc}}
=Q_{\mathrm{cyc}}-W_{\mathrm{cyc}}
```

であるから，

```math
0=Q_{\mathrm{cyc}}-W_{\mathrm{cyc}}
```

となる．

したがって，

```math
\boxed{
W_{\mathrm{cyc}}
=Q_{\mathrm{cyc}}
=Q_\beta>0
}
\tag{5}
```

を得る．

つまり，このサイクルでは，単一の熱源から吸収した熱量がすべて仕事に変換される．

サイクル終了後，系は初期状態に戻る．
また，熱源以外の熱的環境との熱の授受はない．
外部の仕事受け取り装置も，仕事を受け取る以外の変化を残さない理想的なものとする．

したがって，このサイクルが外界に残す正味の効果は，

- 単一熱源から熱量 $Q_\beta>0$ を取り出すこと．
- それと等しい仕事 $W_{\mathrm{cyc}}=Q_\beta$ を外部に供給すること．

だけである．

これは Thomson の原理に反する．

よって，Carathéodory の原理が成立しないという仮定は誤りである．

### 4．結論

背理法により，Carathéodory の原理の否定は，Thomson の原理および第1節で明示した熱力学的前提と矛盾することが示された．

したがって，任意の平衡状態 $P_0$ の任意の近傍には， $P_0$ から準静的断熱過程によって到達できない平衡状態が少なくとも1つ存在する．

ゆえに，

```math
\boxed{
\text{Thomson の原理}
\Longrightarrow
\text{Carathéodory の原理}
}
```

が示された．

### 5．補足：証明の適用範囲

**(1) 断熱経路が近傍の外を通ることについて**

断熱過程 $\alpha$ およびその逆過程 $\alpha^{-1}$ が近傍 $D$ の外側を通っても問題ない．

必要なのは， $P_0$ と $P_1$ が準静的断熱過程で結ばれ，その逆過程も実現できるという事実だけである．

**(2) 準静的過程と可逆過程の区別について**

準静的過程であることから，一般に可逆性が導かれるわけではない．

本証明で逆過程を使用するのは，準静的断熱過程 $\alpha$ について前提 (i) によって可逆性を仮定したためである．

一方，加熱過程 $\beta$ は準静的であっても不可逆でよい．
有限の温度差をもつ熱源と系との間で熱が移動するため，可逆過程とは限らない．

**(3) 加熱過程の仕事について**

加熱過程 $\beta$ では，すべての一般化仕事変数を固定し，それ以外の仕事の授受も行わない．

したがって，

```math
W_\beta=0
```

が成立する．

単に体積だけを一定にしたという条件では，電気的仕事や軸仕事などが残る可能性があるため，本証明ではすべての仕事モードを排除している．

**(4) 正の熱容量の役割について**

本証明では，

```math
q_0>0
```

を利用して，

```math
U(P_1)-U(P_0)>0
```

すなわち，

```math
Q_\beta>0
```

を保証している．

これは本証明で採用した非退化条件である．

なお，

```math
q_0=0
```

であることだけから，

```math
\delta Q\equiv0
```

とは結論できない．
正の熱容量がすべての熱力学系に対して論理的に必須であると主張しているわけではない．

**(5) Thomson の原理との論理的関係について**

本証明の数学的・物理的な論理構造は，

```math
\boxed{
\begin{gathered}
\text{Thomson の原理}\\
+\ \text{第一法則}\\
+\ \text{正の熱容量}\\
+\ \text{断熱過程の逆行可能性}\\
+\ \text{通常の熱的接触と加熱操作の実現可能性}\\
\Downarrow\\
\text{Carathéodory の原理}
\end{gathered}
}
```

である．

熱的接触や断熱過程の逆行可能性を何も仮定しない，文字どおりの Thomson の原理単独からの形式的な論理帰結として主張しているわけではない．
これらを通常の熱力学系の基本的な設定として採用した範囲で，Thomson の原理から Carathéodory の原理を導いている．
