# 演習問題【2-B-30】

## 解答

### 1．Thomson の原理と Carathéodory の原理

まず，証明する二つの原理を述べる．

**Thomson の原理** とは，単一の熱源から熱を受け取り，その熱をすべて仕事に変換して，ほかに何の変化も残さずに一周期の運転を終える熱機関は存在しないという原理である．
これは熱力学第二法則の表現の一つである．

一方， **Carathéodory の原理** とは，任意の平衡状態の任意の近傍には，その状態から断熱過程によって到達できない平衡状態が存在するという原理である．

この Carathéodory の原理を Thomson の原理から導くため，背理法を用いる．
すなわち，まず Carathéodory の原理が成立しないと仮定し，Thomson の原理に矛盾することを示す．

### 2．Carathéodory の原理が成立しないと仮定する

Carathéodory の原理が成立しないと仮定する．
すると，ある平衡状態 2 とその近傍が存在し，その近傍にあるすべての平衡状態へ，状態 2 から断熱過程で到達できることになる．

この近傍内に，状態 2 と同じ温度 $T$ をもち，状態 2 へ向かう等温過程で系が正の熱量 $Q$ を吸収するような平衡状態 1 を選ぶ．
例えば，気体の可逆等温膨張を考えればよい．
ここで $Q>0$ は，系が外部の熱源から吸収する熱量を表す．

状態 1 と状態 2 の間には，次の二つの過程を考えることができる．

- **過程 A：状態 1 から状態 2 への等温過程** ．温度 $T$ の単一熱源から熱量 $Q>0$ を吸収する過程である．
- **過程 B：状態 2 から状態 1 への断熱過程** ．上の仮定によって存在する過程であり，熱の出入りはない．

この二つの過程を順番に行えば，系は状態 1 から出発して状態 1 に戻るため，一つのサイクルが成立する．

### 3．このサイクルで得られる仕事を求める

仕事の符号は， **系が外部に対して行う仕事を正** とする．
熱力学第一法則は，

```math
\Delta U=Q-W
```

と書ける．
ここで $\Delta U$ は内部エネルギーの変化， $Q$ は系が吸収した熱量， $W$ は系が外部に対して行った仕事である．

まず，過程 A について考える．
状態 1 から状態 2 への内部エネルギーの変化は $U_2-U_1$ であるから，

```math
U_2-U_1=Q-W_{12}
```

となる．
ここで $W_{12}$ は，過程 A で系が行う仕事である．
したがって，

```math
W_{12}=Q-(U_2-U_1)
\tag{1}
```

を得る．

次に，過程 B について考える．
この過程は断熱過程であるため，系が吸収する熱量はゼロである．
よって，

```math
U_1-U_2=0-W_{21}
```

となる．
ここで $W_{21}$ は，過程 B で系が行う仕事である．
これを整理すると，

```math
W_{21}=U_2-U_1
\tag{2}
```

である．

サイクル全体で系が外部に対して行う仕事 $W_{\mathrm{cyc}}$ は，二つの過程で行う仕事の和である．
式 (1)，(2) より，

```math
\begin{aligned}
W_{\mathrm{cyc}}
&=W_{12}+W_{21}\\
&=Q-(U_2-U_1)+(U_2-U_1)\\
&=Q
\end{aligned}
```

となる．
したがって，

```math
\boxed{
W_{\mathrm{cyc}}=Q>0
}
```

を得る．

この結果は，サイクル全体で系が温度 $T$ の単一熱源から熱量 $Q$ を吸収し，その熱量のすべてを仕事に変換することを意味する．
系は一周期の後に初期状態に戻り，断熱過程では熱のやり取りがないため，熱源以外に変化を残さずに正の仕事を取り出したことになる．

しかし，これは Thomson の原理に反する．

### 4．結論

Thomson の原理に矛盾する結果が得られた原因は，Carathéodory の原理が成立しないと仮定したことである．
したがって，その仮定は誤りである．

よって，任意の平衡状態の任意の近傍には，その状態から断熱過程によって到達できない平衡状態が存在する．
すなわち，

```math
\boxed{
\text{Thomson の原理}
\Longrightarrow
\text{Carathéodory の原理}
}
```

が示されたのである．


## 補足

この証明の要点は，Carathéodory の原理が成立しないと仮定したときに，等温過程と断熱過程を組み合わせて閉じたサイクルを作り，単一熱源から吸収した熱をすべて仕事に変換できてしまうことにある．
これが Thomson の原理との矛盾である．
