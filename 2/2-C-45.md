# 演習問題【2-C-45】

## 解答

# 定圧気体温度計の経験温度を絶対温度に較正する基本公式

## 1．準備と物理量の定義

定圧気体温度計では，一定圧力のもとで気体の体積を測定し，その体積に比例する量を経験温度 $\theta$ として定める．
本問では，経験温度 $\theta$ を絶対温度 $T$ に較正するため，気体の密度，比熱，Joule–Thomson 係数を測定する．

単位質量当たりの体積である比体積を $v$ とすると，密度 $\rho$ との関係は

```math
v=\frac{1}{\rho}
```

である．
また，単位質量当たりのエンタルピーを $h$ ，定圧比熱を $c_p$ とする．
Joule–Thomson 係数は，エンタルピー一定の条件で圧力が変化したときの温度変化率であり，

```math
\mu=\left(\frac{\partial T}{\partial p}\right)_h
```

と定義される．
ここで $p$ は圧力である．

経験温度 $\theta$ を基準にして測定した定圧比熱と Joule–Thomson 係数を，それぞれ $c_p'$ ， $\mu'$ と表す．
目標は，測定値 $\rho(\theta)$ ， $c_p'(\theta)$ ， $\mu'(\theta)$ から $T$ と $\theta$ の関係を求めることである．

## 2．Joule–Thomson 係数の基本公式

まず，較正に必要な熱力学的関係式を導く．
単位質量当たりのエンタルピーの微分は，

```math
dh=T\,ds+v\,dp
```

である．
ここで $s$ は単位質量当たりのエントロピーである．
定圧比熱の定義から，

```math
c_p=T\left(\frac{\partial s}{\partial T}\right)_p
```

となる．
また，Maxwell の関係式より，

```math
\left(\frac{\partial s}{\partial p}\right)_T
=-\left(\frac{\partial v}{\partial T}\right)_p
```

である．
したがって，エントロピーの全微分は

```math
ds=\frac{c_p}{T}\,dT
-\left(\frac{\partial v}{\partial T}\right)_p dp
```

と表せる．
これをエンタルピーの微分に代入すると，

```math
dh=c_p\,dT+
\left[v-T\left(\frac{\partial v}{\partial T}\right)_p\right]dp
```

を得る．

Joule–Thomson 過程ではエンタルピーが一定であるから $dh=0$ である．
よって，

```math
c_p\,dT=
\left[T\left(\frac{\partial v}{\partial T}\right)_p-v\right]dp
```

となる．
両辺を $dp$ で割ると，

```math
\boxed{
\mu c_p
=T\left(\frac{\partial v}{\partial T}\right)_p-v
}
\tag{1}
```

を得る．
これが較正の出発点となる基本公式である．

## 3．経験温度で測定した量との関係

### 3.1 定圧比熱

定圧比熱は，エンタルピーの温度による変化率である．
経験温度を用いた測定では，

```math
c_p'=\left(\frac{\partial h}{\partial\theta}\right)_p
```

と表される．
エンタルピー $h$ を絶対温度 $T$ の関数として考え，連鎖律を適用すると，

```math
c_p'
=\left(\frac{\partial h}{\partial T}\right)_p
\frac{dT}{d\theta}
```

である．
ここで $(\partial h/\partial T)_p=c_p$ なので，

```math
\boxed{
c_p'=c_p\frac{dT}{d\theta}
}
\tag{2a}
```

となる．

### 3.2 Joule–Thomson 係数

経験温度で表した Joule–Thomson 係数は，

```math
\mu'=\left(\frac{\partial\theta}{\partial p}\right)_h
```

と定義される．
経験温度 $\theta$ が絶対温度 $T$ の関数として表されるとすると，エンタルピー一定の条件で連鎖律を適用できる．
したがって，

```math
\mu'
=\frac{d\theta}{dT}
\left(\frac{\partial T}{\partial p}\right)_h
```

であり，

```math
\boxed{
\mu'=\mu\frac{d\theta}{dT}
}
\tag{2b}
```

を得る．

式 (2a)，(2b) を掛け合わせると，

```math
\mu'c_p'
=\left(\mu\frac{d\theta}{dT}\right)
\left(c_p\frac{dT}{d\theta}\right)
=\mu c_p
```

となる．
よって，

```math
\boxed{
\mu'c_p'=\mu c_p
}
\tag{3}
```

である．
すなわち，経験温度で測定した比熱と Joule–Thomson 係数の積は，絶対温度で定義した両者の積に等しい．

## 4．較正に用いる微分方程式の導出

一定圧力における気体温度計の経験温度は，比体積に比例する．
比例定数を $K$ とすると，

```math
\theta=Kv
```

である．
したがって，圧力を一定に保てば，

```math
\boxed{
\left(\frac{\partial v}{\partial\theta}\right)_p
=\frac{v}{\theta}
}
\tag{4}
```

となる．

式 (1) の左辺に式 (3) を適用すると，

```math
\mu'c_p'
=T\left(\frac{\partial v}{\partial T}\right)_p-v
```

である．
ここで，連鎖律により，

```math
\left(\frac{\partial v}{\partial T}\right)_p
=\left(\frac{\partial v}{\partial\theta}\right)_p
\frac{d\theta}{dT}
```

となる．
式 (4) を代入すると，

```math
\left(\frac{\partial v}{\partial T}\right)_p
=\frac{v}{\theta}\frac{d\theta}{dT}
```

である．
したがって，

```math
\mu'c_p'
=T\frac{v}{\theta}\frac{d\theta}{dT}-v
```

となる．
両辺を $v$ で割り， $\rho=1/v$ を用いて整理すると，

```math
\mu'c_p'\rho
=\frac{T}{\theta}\frac{d\theta}{dT}-1
```

である．
ゆえに，

```math
\frac{T}{\theta}\frac{d\theta}{dT}
=1+\mu'c_p'\rho
```

となる．
対数微分の関係

```math
\frac{d\log\theta}{d\log T}
=\frac{T}{\theta}\frac{d\theta}{dT}
```

を用いれば，

```math
\boxed{
\frac{d\log\theta}{d\log T}
=1+\mu'c_p'\rho
\equiv f(\theta)
}
\tag{5}
```

を得る．
ここで，

```math
\boxed{
f(\theta)=1+\mu'(\theta)c_p'(\theta)\rho(\theta)
}
\tag{6}
```

と定義した．
右辺はすべて経験温度 $\theta$ の関数として測定される量から計算できる．
したがって， $f(\theta)$ は既知の関数である．

## 5．絶対温度への較正公式

式 (5) を逆にして，

```math
\frac{d\log T}{d\log\theta}
=\frac{1}{f(\theta)}
```

と書く．
ここで $d\log\theta=d\theta/\theta$ であるから，

```math
d\log T=\frac{d\theta}{\theta f(\theta)}
```

となる．
既知の基準点 $(\theta_0,T_0)$ から，較正したい点 $(\theta_1,T_1)$ まで積分すると，

```math
\int_{T_0}^{T_1}\frac{dT}{T}
=\int_{\theta_0}^{\theta_1}
\frac{d\theta}{\theta f(\theta)}
```

を得る．
左辺を積分して整理すれば，

```math
\boxed{
\log\frac{T_1}{T_0}
=\int_{\theta_0}^{\theta_1}
\frac{d\theta}{\theta f(\theta)}
}
\tag{7}
```

となる．
式 (6) を用いて書き直すと，最終的な較正公式は，

```math
\boxed{
T_1=T_0\exp\left[
\int_{\theta_0}^{\theta_1}
\frac{d\theta}{
\theta\left\{1+\mu'(\theta)c_p'(\theta)\rho(\theta)\right\}}
\right]
}
\tag{8}
```

である．

## 6．較正の実行方法

実際の較正は，次の手順で行う．

1. 既知の絶対温度 $T_0$ に対応する基準経験温度 $\theta_0$ を定める．
2. 各経験温度 $\theta$ について，測定した密度 $\rho(\theta)$ ，定圧比熱 $c_p'(\theta)$，Joule–Thomson 係数 $\mu'(\theta)$ を用いて，
   ```math
   f(\theta)=1+\mu'(\theta)c_p'(\theta)\rho(\theta)
   ```
   を計算する．
3. 式 (7) の積分を数値的に評価し，式 (8) から，任意の経験温度 $\theta_1$ に対応する絶対温度 $T_1$ を求める．

以上により，測定データと1つの既知の基準温度があれば，経験温度 $\theta$ を絶対温度 $T$ に較正するための基本公式が得られる．ただし，この導出では $\theta>0$ ， $f(\theta)\neq0$ の範囲を考え，経験温度が絶対温度の関数として表されることを仮定している．
