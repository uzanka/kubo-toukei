# 演習問題【2-B-42】

## 解答

### 0．前提，記号および符号規約

外界との間に物質の出入りがない閉じた系を考える．
内部エネルギーを $U$ ，エントロピーを $S$ ，温度を $T$ ，体積を $V$ ，圧力を $p$ ，エンタルピーを $H$ ，Helmholtz自由エネルギーを $F$ ，Gibbs自由エネルギーを $G$ とする．

それぞれの熱力学ポテンシャルを，

```math
H=U+pV
```

```math
F=U-TS
```

```math
G=H-TS
```

と定義する．

以下では，系が外界から吸収する熱量を正，外界が系にする仕事を正とする．
また，最小仕事は，指定された状態変化を実現するために外界から系に与える仕事の最小値とし，仕事の符号を保持して扱う．

系の変化を表す内部状態変数を $\xi$ とする．
例えば，化学反応の進行度や内部構造の変化を表す変数がこれに該当する．
複数の内部状態変数がある場合も，同様の議論を各変数について加えればよい．

内部状態変数 $\xi$ は，系の状態を指定する独立変数として扱えるものとする．
温度微分では，初期状態の内部状態変数 $\xi_A$ と終状態の内部状態変数 $\xi_B$ を固定する．
微小変化の場合には，

```math
\xi_B=\xi_A+d\xi
```

とし，温度微分では初期値 $\xi_A$ と変化量 $d\xi$ を固定する．

また，以下では，各熱力学ポテンシャルが必要な偏微分および混合二階偏微分を許す程度に滑らかであるとする．

#### 0.1 仕事の定義

**(i) 等温等積変化**

体積仕事がゼロであるため，最小仕事は系が受ける全仕事の最小値を意味する．

**(ii) 等温等圧変化**

最小仕事は，圧力に対抗する体積仕事を除いた有用仕事の最小値を意味する．
体積仕事を含む全仕事の最小値とは区別する．

この区別は重要である．
等圧過程では，体積仕事を含む全仕事の最小値は $\Delta F$ であるのに対し，体積仕事を除いた有用仕事の最小値は $\Delta G$ となる．

#### 0.2 最小仕事の過程と熱量測定の過程

以下では，二つの過程を区別する．

**過程1：最小仕事を求める過程**

同じ初期状態から終状態への変化を，温度一定の可逆過程によって実現する．
この過程で外界から系に与える最小仕事を求める．

**過程2：熱量測定の過程**

過程1とは別に，同じ初期状態から同じ終状態への変化を考える．
この過程では，体積仕事以外の外部仕事を伴わないものとする．

両過程は異なっていてよい．
ただし，初期状態および終状態はそれぞれ同一である．
したがって，両過程における状態量の変化は共通する．

最小仕事の過程は可逆過程である一方，熱量測定の過程は必ずしも可逆である必要はない．
この二つの過程を状態関数によって結び付ける．

### 1．内部状態変数を含む熱力学基本関係式

内部状態変数 $\xi$ を含む閉じた系の基本関係式を，

```math
\boxed{
dU=T\,dS-p\,dV+\mathcal A\,d\xi
}
\tag{1}
```

とする．

ここで， $\mathcal A$ は $\xi$ に共役な一般化熱力学力であり，

```math
\mathcal A=
\left(\frac{\partial U}{\partial\xi}\right)_{S,V}
```

で定義される．

例えば，化学反応の場合には，反応進行度を $\xi$ として，各成分の物質量変化を

```math
dN_i=\nu_i\,d\xi
```

と表すと，化学的な寄与は

```math
\sum_i\mu_i\,dN_i
=
\left(\sum_i\nu_i\mu_i\right)d\xi
```

となる．
この項を $\mathcal A\,d\xi$ と表せる．
ここで， $\mu_i$ は各成分の化学ポテンシャル， $\nu_i$ は化学量論係数である．

このような内部状態の変化があっても，系の外部との物質の出入りがなければ閉じた系である．

なお， $\mathcal A\,d\xi$ は内部状態の変化を記述する熱力学的な状態空間の項であり，それだけで外界との境界仕事を意味するものではない．
外部から与えられる仕事は，第一法則と最小仕事の条件によって別途評価する．

#### 1.1 Helmholtz自由エネルギー

Helmholtz自由エネルギーは，

```math
F=U-TS
```

である．
全微分を取ると，

```math
dF=dU-T\,dS-S\,dT
```

となる．
式 (1) を代入すれば，

```math
\begin{aligned}
dF
&=T\,dS-p\,dV+\mathcal A\,d\xi\\
&\quad-T\,dS-S\,dT\\
&=-S\,dT-p\,dV+\mathcal A\,d\xi
\end{aligned}
```

である．
したがって，

```math
\boxed{
dF=-S\,dT-p\,dV+\mathcal A\,d\xi
}
\tag{2}
```

を得る．

よって，

```math
\boxed{
\left(\frac{\partial F}{\partial T}\right)_{V,\xi}
=-S
}
\tag{3}
```

が成立する．

#### 1.2 Gibbs自由エネルギー

エンタルピーは，

```math
H=U+pV
```

であるから，

```math
\begin{aligned}
dH
&=dU+p\,dV+V\,dp\\
&=T\,dS+V\,dp+\mathcal A\,d\xi
\end{aligned}
```

となる．

Gibbs自由エネルギーは，

```math
G=H-TS
```

なので，

```math
\begin{aligned}
dG
&=dH-T\,dS-S\,dT\\
&=-S\,dT+V\,dp+\mathcal A\,d\xi
\end{aligned}
```

である．
したがって，

```math
\boxed{
dG=-S\,dT+V\,dp+\mathcal A\,d\xi
}
\tag{4}
```

を得る．

よって，

```math
\boxed{
\left(\frac{\partial G}{\partial T}\right)_{p,\xi}
=-S
}
\tag{5}
```

が成立する．

### 2．最小仕事の関係式

#### 2.1 等温等積変化

温度 $T$ の単一の熱浴と接した閉じた系を考える．
系が吸収する熱量を $\delta'Q$ ，外界が系にする全仕事を $\delta W_{\mathrm{on}}$ とする．

熱力学第一法則は，

```math
dU=\delta'Q+\delta W_{\mathrm{on}}
\tag{6}
```

である．

熱力学第二法則より，熱浴の温度が $T$ であるとき，

```math
dS-\frac{\delta'Q}{T}\geq0
```

したがって，

```math
\delta'Q\leq T\,dS
\tag{7}
```

となる．

等積条件では体積仕事がないので，式 (6)，(7) より，

```math
\begin{aligned}
\delta W_{\mathrm{on}}
&=dU-\delta'Q\\
&\geq dU-T\,dS
\end{aligned}
```

を得る．

ここで，等温・等積条件では，

```math
dT=0,\qquad dV=0
```

であるから，式 (2) より，

```math
dF=dU-T\,dS
```

となる．
したがって，

```math
\delta W_{\mathrm{on}}\geq dF
```

であり，可逆過程で等号が成立する．

よって，等温等積変化における最小仕事は，

```math
\boxed{
\delta W_{\min,V}
=dF\big|_{T,V}
=
\left(\frac{\partial F}{\partial\xi}\right)_{T,V}d\xi
}
\tag{8}
```

である．

#### 2.2 等温等圧変化

次に，温度 $T$ ，圧力 $p$ を一定に保つ場合を考える．

外界が系にする仕事を，体積仕事と有用仕事に分ける．

体積仕事は，

```math
\delta W_{\mathrm{pV,on}}=-p\,dV
```

である．
したがって，熱力学第一法則は，

```math
dU=\delta'Q+\delta W_{\mathrm{useful,on}}-p\,dV
\tag{9}
```

となる．

エンタルピーの定義から，

```math
dH=dU+p\,dV+V\,dp
```

である．
圧力一定，すなわち $dp=0$ の条件では，

```math
dH=\delta'Q+\delta W_{\mathrm{useful,on}}
```

となる．
よって，

```math
\delta W_{\mathrm{useful,on}}=dH-\delta'Q
```

である．

熱力学第二法則より，

```math
\delta'Q\leq T\,dS
```

なので，

```math
\begin{aligned}
\delta W_{\mathrm{useful,on}}
&\geq dH-T\,dS
\end{aligned}
```

となる．

一方，等温・等圧条件では，

```math
dT=0,\qquad dp=0
```

であるから，式 (4) より，

```math
dG=dH-T\,dS
```

である．
したがって，

```math
\delta W_{\mathrm{useful,on}}\geq dG
```

となり，可逆過程で等号が成立する．

よって，等温等圧変化において体積仕事を除いた有用仕事の最小値は，

```math
\boxed{
\delta W_{\min,p}^{\mathrm{useful}}
=dG\big|_{T,p}
=
\left(\frac{\partial G}{\partial\xi}\right)_{T,p}d\xi
}
\tag{10}
```

である．

なお，式 (8)，(10) の最小仕事は，指定した変化方向に対する符号付きの仕事である．
自由エネルギーが減少する場合には，外界への仕事の取り出しを表す負の値となり得る．

### 3．熱量測定の過程

ここでは，前節の最小仕事を求める可逆過程とは別に，同じ状態変化 $d\xi$ を実現する熱量測定の過程を考える．

この過程では体積仕事以外の外部仕事を伴わないものとする．

#### 3.1 等温等積変化

等積条件では，

```math
dV=0
```

であり，体積仕事もゼロである．
また，有用仕事を伴わないため，熱力学第一法則から，

```math
dU=\delta'Q_V
```

となる．
したがって，

```math
\boxed{
\delta'Q_V
=
\left(\frac{\partial U}{\partial\xi}\right)_{T,V}d\xi
}
\tag{11}
```

である．

#### 3.2 等温等圧変化

等圧条件では $dp=0$ であり，体積仕事以外の仕事を伴わない．
第一法則より，

```math
dU=\delta'Q_p-p\,dV
```

である．

エンタルピーの全微分

```math
dH=dU+p\,dV+V\,dp
```

に $dp=0$ を代入すると，

```math
dH=\delta'Q_p
```

となる．
よって，

```math
\boxed{
\delta'Q_p
=
\left(\frac{\partial H}{\partial\xi}\right)_{T,p}d\xi
}
\tag{12}
```

を得る．

ここで，式 (11)，(12) の $\delta'Q_V,\delta'Q_p$ は，実際の熱量測定過程で系が吸収する熱量である．
一方，式 (8)，(10) の最小仕事は別の可逆過程で得られる．
両者は同じ初期状態，同じ終状態の変化を表すため，状態関数の微小変化を介して比較できる．

### 4．（i）等温等積変化の場合

式 (8) より，

```math
\delta W_{\min,V}
=
\left(\frac{\partial F}{\partial\xi}\right)_{T,V}d\xi
```

である．
以下，添字を簡略化して，

```math
F_\xi=
\left(\frac{\partial F}{\partial\xi}\right)_{T,V},
\qquad
S_\xi=
\left(\frac{\partial S}{\partial\xi}\right)_{T,V}
```

と表す．

また，温度微分では $V,\xi,d\xi$ を固定する．

式 (3) より，

```math
\left(\frac{\partial F}{\partial T}\right)_{V,\xi}
=-S
```

である．

ここで， $F$ が混合二階偏微分の交換を許す程度に滑らかであると仮定すると，

```math
\begin{aligned}
\frac{\partial}{\partial T}
\left(
\frac{\partial F}{\partial\xi}
\right)_{T,V}
&=
\frac{\partial}{\partial\xi}
\left(
\frac{\partial F}{\partial T}
\right)_{V,\xi}\\
&=-\left(\frac{\partial S}{\partial\xi}\right)_{T,V}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
F_{T\xi}=-S_\xi
}
\tag{13}
```

を得る．

一方，

```math
U=F+TS
```

であるから，温度と体積を一定にして $\xi$ で偏微分すると，

```math
\begin{aligned}
\left(\frac{\partial U}{\partial\xi}\right)_{T,V}
&=
\left(\frac{\partial F}{\partial\xi}\right)_{T,V}
+
T\left(\frac{\partial S}{\partial\xi}\right)_{T,V}\\
&=F_\xi+TS_\xi
\end{aligned}
```

となる．
よって，

```math
\boxed{
U_\xi=F_\xi+TS_\xi
}
\tag{14}
```

である．

ここで，式 (8)，(13) を用いると，

```math
\begin{aligned}
-\left(
\frac{\partial}{\partial T}
\left[
\frac{\delta W_{\min,V}}{T}
\right]
\right)_{V,\xi,d\xi}
&=
-\left(
\frac{\partial}{\partial T}
\left[
\frac{F_\xi d\xi}{T}
\right]
\right)_{V,\xi,d\xi}\\
&=
-\frac{F_{T\xi}d\xi}{T}
+\frac{F_\xi d\xi}{T^2}\\
&=
\frac{S_\xi d\xi}{T}
+\frac{F_\xi d\xi}{T^2}\\
&=
\frac{F_\xi+TS_\xi}{T^2}d\xi\\
&=
\frac{U_\xi d\xi}{T^2}
\end{aligned}
```

となる．

式 (11) より，

```math
U_\xi d\xi=\delta'Q_V
```

であるため，

```math
\boxed{
\frac{\delta'Q_V}{T^2}
=
-\left(
\frac{\partial}{\partial T}
\left[
\frac{\delta W_{\min,V}}{T}
\right]
\right)_{V,\xi,d\xi}
}
\tag{15}
```

を得る．

これが等温等積変化における求める関係式である．

### 5．（ii）等温等圧変化の場合

式 (10) より，

```math
\delta W_{\min,p}^{\mathrm{useful}}
=
\left(\frac{\partial G}{\partial\xi}\right)_{T,p}d\xi
```

である．
以下，

```math
G_\xi=
\left(\frac{\partial G}{\partial\xi}\right)_{T,p},
\qquad
S_\xi=
\left(\frac{\partial S}{\partial\xi}\right)_{T,p}
```

と表す．

温度微分では $p,\xi,d\xi$ を固定する．

式 (5) より，

```math
\left(\frac{\partial G}{\partial T}\right)_{p,\xi}
=-S
```

である．

混合二階偏微分が交換可能であることから，

```math
\begin{aligned}
\frac{\partial}{\partial T}
\left(
\frac{\partial G}{\partial\xi}
\right)_{T,p}
&=
\frac{\partial}{\partial\xi}
\left(
\frac{\partial G}{\partial T}
\right)_{p,\xi}\\
&=-\left(\frac{\partial S}{\partial\xi}\right)_{T,p}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
G_{T\xi}=-S_\xi
}
\tag{16}
```

である．

また，

```math
H=G+TS
```

より，

```math
\begin{aligned}
\left(\frac{\partial H}{\partial\xi}\right)_{T,p}
&=
\left(\frac{\partial G}{\partial\xi}\right)_{T,p}
+
T\left(\frac{\partial S}{\partial\xi}\right)_{T,p}\\
&=G_\xi+TS_\xi
\end{aligned}
```

となる．
よって，

```math
\boxed{
H_\xi=G_\xi+TS_\xi
}
\tag{17}
```

を得る．

式 (10)，(16) を用いると，

```math
\begin{aligned}
-\left(
\frac{\partial}{\partial T}
\left[
\frac{\delta W_{\min,p}^{\mathrm{useful}}}{T}
\right]
\right)_{p,\xi,d\xi}
&=
-\left(
\frac{\partial}{\partial T}
\left[
\frac{G_\xi d\xi}{T}
\right]
\right)_{p,\xi,d\xi}\\
&=
-\frac{G_{T\xi}d\xi}{T}
+\frac{G_\xi d\xi}{T^2}\\
&=
\frac{S_\xi d\xi}{T}
+\frac{G_\xi d\xi}{T^2}\\
&=
\frac{G_\xi+TS_\xi}{T^2}d\xi\\
&=
\frac{H_\xi d\xi}{T^2}
\end{aligned}
```

となる．

式 (12) より，

```math
H_\xi d\xi=\delta'Q_p
```

であるから，

```math
\boxed{
\frac{\delta'Q_p}{T^2}
=
-\left(
\frac{\partial}{\partial T}
\left[
\frac{\delta W_{\min,p}^{\mathrm{useful}}}{T}
\right]
\right)_{p,\xi,d\xi}
}
\tag{18}
```

を得る．

これが等温等圧変化における求める関係式である．

### 6．等圧過程で有用仕事を用いる必要性

問題文の等圧変化の式では，最小仕事として体積仕事を除いた有用仕事を用いる必要がある．

仮に，体積仕事を含む全仕事の最小値 $\Delta F$ を用いると，一般には問題文の等圧の式は成立しない．

実際，圧力一定の経路では体積 $V$ も温度に依存するため，

```math
\left(\frac{\partial F}{\partial T}\right)_{p,\xi}
=
-S-p\left(\frac{\partial V}{\partial T}\right)_{p,\xi}
```

となる．

したがって，初期状態と終状態の圧力および各内部変数を固定すると，

```math
-\left(
\frac{\partial}{\partial T}
\frac{\Delta F}{T}
\right)_p
=
\frac{\Delta U}{T^2}
+
\frac{p}{T}
\Delta\left[
\left(\frac{\partial V}{\partial T}\right)_{p,\xi}
\right]
```

となる．

これは一般に，

```math
\frac{\Delta H}{T^2}
=
\frac{\Delta U+p\Delta V}{T^2}
```

とは一致しない．

したがって，等圧変化で求める熱量 $Q_p=\Delta H$ と対応させるためには，体積仕事を除いた有用仕事の最小値 $\Delta G$ を用いなければならない．

このため，本解答では等圧過程の $\delta W_{\min}$ を有用仕事の最小値として定義した．

### 7．結論

以上より，内部状態変数を $\xi$ として，必要な偏微分の交換可能性を仮定すれば，次の関係式が得られる．

**(i) 等温等積変化**

```math
\boxed{
\frac{\delta'Q_V}{T^2}
=
-\left(
\frac{\partial}{\partial T}
\left[
\frac{\delta W_{\min,V}}{T}
\right]
\right)_{V,\xi,d\xi}
}
```

ここで， $\delta W_{\min,V}$ は等温等積変化で系が受ける全仕事の最小値である．

**(ii) 等温等圧変化**

```math
\boxed{
\frac{\delta'Q_p}{T^2}
=
-\left(
\frac{\partial}{\partial T}
\left[
\frac{\delta W_{\min,p}^{\mathrm{useful}}}{T}
\right]
\right)_{p,\xi,d\xi}
}
```

ここで， $\delta W_{\min,p}^{\mathrm{useful}}$ は等温等圧変化で体積仕事を除いた有用仕事の最小値である．

したがって，問題文の $\delta W_{\min}$ を，(i) では全仕事の最小値，(ii) では体積仕事を除いた有用仕事の最小値と解釈すれば，

```math
\boxed{
\frac{\delta'Q}{T^2}
=
-\left(
\frac{\partial}{\partial T}
\left[
\frac{\delta W_{\min}}{T}
\right]
\right)_V
}
```

および，

```math
\boxed{
\frac{\delta'Q}{T^2}
=
-\left(
\frac{\partial}{\partial T}
\left[
\frac{\delta W_{\min}}{T}
\right]
\right)_p
}
```

が得られる．

これらが求める Gibbs–Helmholtz の関係式（Kelvin の式）である．
