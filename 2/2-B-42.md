# 演習問題【2-B-42】

## 解答

### 準備：自由エネルギーと最小仕事の関係

物質の出入りがない閉じた系を考える．
内部エネルギーを $U$ ，エントロピーを $S$ ，温度を $T$ ，体積を $V$ ，圧力を $p$ とする．
また，エンタルピー $H$ ，Helmholtz 自由エネルギー $F$ ，Gibbs 自由エネルギー $G$ をそれぞれ

```math
H=U+pV,\qquad F=U-TS,\qquad G=H-TS
```

と定義する．

対象とする変化について，初期状態と終状態の自由エネルギーの差を $\Delta F$ ， $\Delta G$ と表す．
温度を一定に保った可逆過程では，等積変化に対応する最小仕事は $\Delta F$ ，等圧変化に対応する最小仕事は $\Delta G$ である．
すなわち，

```math
\Delta W_{\min}=\Delta F
\qquad (T,V=\text{一定})
\tag{1}
```

```math
\Delta W_{\min}=\Delta G
\qquad (T,p=\text{一定})
\tag{2}
```

である．
以下では，同じ変化についてこれらの自由エネルギー差を温度の関数として扱う．

### (i) 等温等積変化の場合

まず，温度 $T$ ，体積 $V$ を一定に保った変化を考える．
式 (1) より，

```math
\frac{\Delta W_{\min}}{T}=\frac{\Delta F}{T}
```

である．
これを温度 $T$ について微分すると，商の微分公式から，

```math
\left(\frac{\partial}{\partial T}
\frac{\Delta W_{\min}}{T}\right)_V
=
\frac{1}{T}\left(\frac{\partial\Delta F}{\partial T}\right)_V
-\frac{\Delta F}{T^2}
\tag{3}
```

となる．

Helmholtz 自由エネルギーの定義 $F=U-TS$ より，

```math
\left(\frac{\partial F}{\partial T}\right)_V=-S
```

である．
したがって，初期状態と終状態の差についても，

```math
\left(\frac{\partial\Delta F}{\partial T}\right)_V
=-\Delta S
\tag{4}
```

が成り立つ．
式 (4) を式 (3) に代入すると，

```math
\left(\frac{\partial}{\partial T}
\frac{\Delta W_{\min}}{T}\right)_V
=-\frac{\Delta S}{T}-\frac{\Delta F}{T^2}
```

となる．
ここで，

```math
\Delta F=\Delta U-T\Delta S
```

であるから，

```math
-\frac{\Delta S}{T}-\frac{\Delta F}{T^2}
=-\frac{\Delta U}{T^2}
```

となる．
よって，

```math
\boxed{
\left(\frac{\partial}{\partial T}
\frac{\Delta W_{\min}}{T}\right)_V
=-\frac{\Delta U}{T^2}
}
\tag{5}
```

を得る．

等積条件では体積仕事 $p\,dV$ がゼロである．
さらに，熱量測定の過程で体積仕事以外の仕事を伴わないとすれば，熱力学第一法則より，

```math
\Delta U=\Delta Q_V
```

である．
ここで $\Delta Q_V$ は，等積変化において系が吸収する熱量を表す．
これを式 (5) に代入すれば，

```math
\left(\frac{\partial}{\partial T}
\frac{\Delta W_{\min}}{T}\right)_V
=-\frac{\Delta Q_V}{T^2}
```

となる．
したがって，

```math
\boxed{
\frac{\Delta Q_V}{T^2}
=-\left(\frac{\partial}{\partial T}
\frac{\Delta W_{\min}}{T}\right)_V
}
```

を得る．
対象とする変化を微小変化で表せば，これは問題文の

```math
\boxed{
\frac{\delta'Q}{T^2}
=-\left(\frac{\partial}{\partial T}
\left[\frac{\delta W_{\min}}{T}\right]\right)_V
}
```

に一致する．
これで (i) が示された．

### (ii) 等温等圧変化の場合

次に，温度 $T$ ，圧力 $p$ を一定に保った変化を考える．
式 (2) より，

```math
\frac{\Delta W_{\min}}{T}=\frac{\Delta G}{T}
```

である．
これを温度 $T$ について微分すると，

```math
\left(\frac{\partial}{\partial T}
\frac{\Delta W_{\min}}{T}\right)_p
=
\frac{1}{T}\left(\frac{\partial\Delta G}{\partial T}\right)_p
-\frac{\Delta G}{T^2}
\tag{6}
```

となる．

Gibbs 自由エネルギー $G=H-TS$ より，

```math
\left(\frac{\partial G}{\partial T}\right)_p=-S
```

であるため，

```math
\left(\frac{\partial\Delta G}{\partial T}\right)_p
=-\Delta S
\tag{7}
```

となる．
式 (7) を式 (6) に代入すると，

```math
\left(\frac{\partial}{\partial T}
\frac{\Delta W_{\min}}{T}\right)_p
=-\frac{\Delta S}{T}-\frac{\Delta G}{T^2}
```

である．
ここで，

```math
\Delta G=\Delta H-T\Delta S
```

であるから，

```math
-\frac{\Delta S}{T}-\frac{\Delta G}{T^2}
=-\frac{\Delta H}{T^2}
```

となる．
したがって，

```math
\boxed{
\left(\frac{\partial}{\partial T}
\frac{\Delta W_{\min}}{T}\right)_p
=-\frac{\Delta H}{T^2}
}
\tag{8}
```

を得る．

等圧条件で体積仕事以外の仕事を伴わない場合，熱力学第一法則より，

```math
\Delta Q_p=\Delta H
```

が成り立つ．
ここで $\Delta Q_p$ は，等圧変化において系が吸収する熱量である．
したがって，式 (8) より，

```math
\left(\frac{\partial}{\partial T}
\frac{\Delta W_{\min}}{T}\right)_p
=-\frac{\Delta Q_p}{T^2}
```

を得る．
よって，

```math
\boxed{
\frac{\Delta Q_p}{T^2}
=-\left(\frac{\partial}{\partial T}
\frac{\Delta W_{\min}}{T}\right)_p
}
```

となる．
対象とする変化を微小変化で表せば，問題文の

```math
\boxed{
\frac{\delta'Q}{T^2}
=-\left(\frac{\partial}{\partial T}
\left[\frac{\delta W_{\min}}{T}\right]\right)_p
}
```

が得られ，(ii) も示された．


## 解説

この二つの関係式は，Gibbs–Helmholtz の関係式の表現である．
要点は，等積過程では Helmholtz 自由エネルギー $F$ と内部エネルギー $U$ を，等圧過程では Gibbs 自由エネルギー $G$ とエンタルピー $H$ を対応させることにある．
自由エネルギーの温度依存性を熱量に結び付けることで，熱量の測定から最小仕事を評価できるのである．
