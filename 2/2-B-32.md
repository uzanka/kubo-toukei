# 演習問題【2-B-32】

## 解答

### 1．体系全体が受け取る熱量を求める

断熱性の滑りピストンによって隔てられた，1 mol ずつの2種類の理想気体を考える．
気体1の温度，体積，圧力を $T',V',p'$ ，気体2のそれらを $T'',V'',p''$ とする．
滑りピストンは準静的に動き，常に力学的平衡が保たれるものとする．
したがって，

```math
p'=p''=p
```

が成り立つ．

体系全体が受け取る微小熱量を $d'Q$ ，各気体が受け取る微小熱量を $d'Q'$ ， $d'Q''$ とすると，

```math
d'Q=d'Q'+d'Q''
\tag{1}
```

である．

ここでは，熱力学第一法則を

```math
dU=d'Q-p\,dV
```

と表す．
すなわち，系が外部にする仕事を正とする．
1 mol の理想気体について，内部エネルギーの微小変化は $dU=C_V\,dT$ であるから，各気体について

```math
d'Q'=C_V'\,dT'+p\,dV'
\tag{2}
```

および

```math
d'Q''=C_V''\,dT''+p\,dV''
\tag{3}
```

となる．
ここで $C_V'$ と $C_V''$ は，それぞれの気体のモル定積熱容量である．

### 2．状態方程式を用いて \(d'Q\) を整理する

気体1について，理想気体の状態方程式は

```math
pV'=\mathcal R T'
```

である．
ここで $\mathcal R$ は気体定数である．
両辺を微分すると，

```math
p\,dV'+V'\,dp=\mathcal R\,dT'
```

となる．
したがって，

```math
p\,dV'=\mathcal R\,dT'-V'\,dp
```

である．
さらに $V'=\mathcal R T'/p$ を代入すれば，

```math
p\,dV'=\mathcal R\,dT'
-\frac{\mathcal R T'}{p}\,dp
\tag{4}
```

を得る．
式 (4) を式 (2) に代入すると，

```math
d'Q'=(C_V'+\mathcal R)\,dT'
-\frac{\mathcal R T'}{p}\,dp
\tag{5}
```

となる．

同様に，気体2についても状態方程式 $pV''=\mathcal R T''$ より，

```math
p\,dV''=\mathcal R\,dT''
-\frac{\mathcal R T''}{p}\,dp
```

であるため，

```math
d'Q''=(C_V''+\mathcal R)\,dT''
-\frac{\mathcal R T''}{p}\,dp
\tag{6}
```

を得る．

式 (5)，(6) を式 (1) に代入すると，体系全体の熱量は

```math
\boxed{
\begin{aligned}
d'Q={}&(C_V'+\mathcal R)\,dT'\\
&+(C_V''+\mathcal R)\,dT''
-\frac{\mathcal R(T'+T'')}{p}\,dp
\end{aligned}
}
\tag{7}
```

となる．

したがって， $d'Q$ は3変数 $T',T'',p$ の微分形式である．
これを

```math
d'Q=X_1\,dT'+X_2\,dT''+X_3\,dp
\tag{8}
```

と表すと，各係数は

```math
X_1=C_V'+\mathcal R,
\qquad
X_2=C_V''+\mathcal R,
\qquad
X_3=-\frac{\mathcal R(T'+T'')}{p}
\tag{9}
```

である．

### 3．積分因子が存在するための必要条件

$d'Q$ に非零の積分因子 $\lambda(T',T'',p)$ が存在すると仮定する．
これは，ある状態関数 $\phi(T',T'',p)$ を用いて，

```math
\lambda\,d'Q=d\phi
\tag{10}
```

と書けることを意味する．
すなわち，積分因子を掛けた微分形式が完全微分になるという仮定である．

完全微分の外微分はゼロであるため，

```math
d(\lambda\,d'Q)=d^2\phi=0
```

となる．
この式と $d'Q$ の外積をとると，積分因子が非零であることから，

```math
d'Q\wedge d(d'Q)=0
\tag{11}
```

という必要条件が得られる．
これは3変数の微分形式に対する積分可能条件であり，係数 $X_1,X_2,X_3$ を用いて展開すると，

```math
\begin{aligned}
0={}&X_1\left(
\frac{\partial X_3}{\partial T''}
-\frac{\partial X_2}{\partial p}
\right)\\
&+X_2\left(
\frac{\partial X_1}{\partial p}
-\frac{\partial X_3}{\partial T'}
\right)\\
&+X_3\left(
\frac{\partial X_2}{\partial T'}
-\frac{\partial X_1}{\partial T''}
\right)
\end{aligned}
\tag{12}
```

となる．

重要なのは，式 (12) は積分因子が存在するための必要条件だという点である．
したがって，左辺がゼロでなければ，積分因子は存在しない．

### 4．必要条件を検証する

式 (9) から，各偏微分は

```math
\frac{\partial X_3}{\partial T''}
=-\frac{\mathcal R}{p},
\qquad
\frac{\partial X_2}{\partial p}=0
```

および

```math
\frac{\partial X_1}{\partial p}=0,
\qquad
\frac{\partial X_3}{\partial T'}
=-\frac{\mathcal R}{p}
```

である．
また， $X_1$ は $T''$ に依存せず， $X_2$ は $T'$ に依存しないため，

```math
\frac{\partial X_2}{\partial T'}=0,
\qquad
\frac{\partial X_1}{\partial T''}=0
```

となる．

これらを式 (12) の左辺に代入すると，

```math
\begin{aligned}
&-(C_V'+\mathcal R)\frac{\mathcal R}{p}
+(C_V''+\mathcal R)\frac{\mathcal R}{p}\\
&\qquad=\frac{\mathcal R}{p}(C_V''-C_V')
\end{aligned}
```

を得る．
したがって，必要条件の左辺は

```math
\boxed{
\frac{\mathcal R}{p}(C_V''-C_V')
}
\tag{13}
```

である．

問題の条件 $C_V'\ne C_V''$ と， $\mathcal R>0$ ， $p>0$ より，式 (13) はゼロではない．
よって，積分因子が存在するための必要条件は満たされない．

### 5．結論

以上より，考えている3変数の状態空間において，体系全体の熱量 $d'Q$ に非零の積分因子を掛けて完全微分にすることはできない．
したがって，問題文の定義に従い，この熱的に不均質な体系は

```math
\boxed{
\text{非ホロノームである}
}
```

と結論される．
