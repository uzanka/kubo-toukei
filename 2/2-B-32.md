# 演習問題【2-B-32】

## 解答

### 1．体系の設定と基本的な前提

二つの異なる理想気体が，質量を無視でき，摩擦のない断熱性の滑りピストンによって隔てられている体系を考える．
気体1，気体2はそれぞれ1 molとし，それぞれの温度，体積，圧力を

```math
(T',V',p'),\qquad (T'',V'',p'')
```

とする．

内側の滑りピストンは準静的に動き，常に力学的平衡が成立するものとする．
したがって，

```math
\boxed{p'=p''=p}
```

である．

ここで，外側の境界について，次の条件を明示する．

- 外側の境界は可動であり，全体積 $V'+V''$ は一定ではない．
- 外側の荷重を調節できるため，共通圧力 $p$ は独立に変化できる．
- 二つの気体の温度は，それぞれ独立に調節できる．

したがって，体系の平衡状態は，

```math
\boxed{(T',T'',p)}
```

という独立な3変数で指定される．

状態空間は，

```math
\Omega=
\{(T',T'',p)\mid T'>0,\ T''>0,\ p>0\}
```

であり，3次元の開集合である．

また，気体1と気体2のモル定積熱容量 $C_V'$ ， $C_V''$ は，それぞれ温度によらない正の定数であり，

```math
\boxed{C_V'\neq C_V''}
```

とする．

### 2．体系全体が受け取る微小熱量を求める

体系全体が受け取る微小熱量を $d'Q$ ，各気体が受け取る微小熱量を $d'Q'$ ， $d'Q''$ とする．
断熱性の内側ピストンを通じた熱の授受はないため，

```math
\boxed{d'Q=d'Q'+d'Q''}
\tag{1}
```

である．

系が外部にする仕事を正とする熱力学第一法則は，

```math
dU=d'Q-p\,dV
```

である．

1 molの理想気体について，

```math
dU=C_V\,dT
```

であるから，各気体について，

```math
d'Q'=C_V'\,dT'+p\,dV'
\tag{2}
```

```math
d'Q''=C_V''\,dT''+p\,dV''
\tag{3}
```

となる．

ここで， $p\,dV'$ ， $p\,dV''$ は各気体の境界仕事を表す．
内部ピストンに対する仕事は，二つの気体について合計すると相殺され，体系全体の外部仕事は $p\,d(V'+V'')$ となる．

### 3．状態方程式を用いて熱量を整理する

気体1について，理想気体の状態方程式は，

```math
pV'=\mathcal R T'
```

である．
ここで $\mathcal R$ はモル気体定数である．

両辺を微分すると，

```math
p\,dV'+V'\,dp=\mathcal R\,dT'
```

となる．
したがって，

```math
p\,dV'=\mathcal R\,dT'-V'\,dp
```

である．
さらに，

```math
V'=\frac{\mathcal R T'}p
```

を代入すると，

```math
\boxed{
p\,dV'
=\mathcal R\,dT'
-\frac{\mathcal R T'}p\,dp
}
\tag{4}
```

を得る．

式 (4) を式 (2) に代入すると，

```math
d'Q'
=(C_V'+\mathcal R)dT'
-\frac{\mathcal R T'}p\,dp
\tag{5}
```

となる．

同様に，気体2について，

```math
pV''=\mathcal R T''
```

より，

```math
p\,dV''
=\mathcal R\,dT''
-\frac{\mathcal R T''}p\,dp
```

である．
したがって，

```math
d'Q''
=(C_V''+\mathcal R)dT''
-\frac{\mathcal R T''}p\,dp
\tag{6}
```

を得る．

式 (5)，(6) を式 (1) に代入すると，体系全体の熱量は，

```math
\boxed{
\begin{aligned}
d'Q={}&(C_V'+\mathcal R)dT'\\
&+(C_V''+\mathcal R)dT''\\
&-\frac{\mathcal R(T'+T'')}{p}\,dp
\end{aligned}
}
\tag{7}
```

となる．

これを，

```math
d'Q=X_1\,dT'+X_2\,dT''+X_3\,dp
\tag{8}
```

と表すと，係数は，

```math
X_1=C_V'+\mathcal R
```

```math
X_2=C_V''+\mathcal R
```

```math
X_3=-\frac{\mathcal R(T'+T'')}{p}
\tag{9}
```

である．

### 4．積分因子が存在するための必要条件

$d'Q$ に非零の積分因子 $\lambda(T',T'',p)$ が存在すると仮定する．

このとき，ある状態関数 $\phi(T',T'',p)$ を用いて，

```math
\boxed{\lambda\,d'Q=d\phi}
\tag{10}
```

と表すことができる．

ここで， $\lambda$ は微分可能な非零関数とする．

式 (10) の両辺の外微分を取ると，

```math
d(\lambda\,d'Q)=d^2\phi=0
```

となる．

一方，

```math
d(\lambda\,d'Q)
=d\lambda\wedge d'Q+\lambda\,d(d'Q)
```

である．
これと $d'Q$ の外積を取ると，

```math
d'Q\wedge d(\lambda\,d'Q)
=
\lambda\,d'Q\wedge d(d'Q)=0
```

となる．

$\lambda\neq0$ なので，

```math
\boxed{
d'Q\wedge d(d'Q)=0
}
\tag{11}
```

が得られる．

これは，3変数の微分形式 $d'Q$ に積分因子が存在するための必要条件である．

### 5．必要条件を検証する

式 (9) より，

```math
\frac{\partial X_3}{\partial T''}
=-\frac{\mathcal R}{p},
\qquad
\frac{\partial X_2}{\partial p}=0
```

である．

また，

```math
\frac{\partial X_1}{\partial p}=0,
\qquad
\frac{\partial X_3}{\partial T'}
=-\frac{\mathcal R}{p}
```

である．

さらに，

```math
\frac{\partial X_2}{\partial T'}=0,
\qquad
\frac{\partial X_1}{\partial T''}=0
```

である．

したがって，式 (11) の左辺を係数で展開すると，

```math
\begin{aligned}
0={}&X_1\left(
\frac{\partial X_3}{\partial T''}
-\frac{\partial X_2}{\partial p}
\right)\\
&+X_2\left(
\frac{\partial X_1}{\partial p}
-\frac{\partial X_3}{\partial T'}
\right)\\
&+X_3\left(
\frac{\partial X_2}{\partial T'}
-\frac{\partial X_1}{\partial T''}
\right)
\end{aligned}
\tag{12}
```

が必要となる．

式 (9) の係数と上記の偏微分を代入すると，

```math
\begin{aligned}
&-(C_V'+\mathcal R)\frac{\mathcal R}{p}\\
&\quad +(C_V''+\mathcal R)\frac{\mathcal R}{p}
+0
\end{aligned}
```

となる．
整理すれば，

```math
\boxed{
d'Q\wedge d(d'Q)
=
\frac{\mathcal R}{p}
(C_V''-C_V')
\,dT'\wedge dT''\wedge dp
}
\tag{13}
```

を得る．

問題の条件より，

```math
C_V'\neq C_V''
```

であり，また，

```math
\mathcal R>0,\qquad p>0
```

である．
したがって，

```math
\boxed{
d'Q\wedge d(d'Q)\neq0
}
```

が状態空間 $\Omega$ のすべての点で成立する．

しかし，これは積分因子が存在するための必要条件，

```math
d'Q\wedge d(d'Q)=0
```

に矛盾する．

よって， $\Omega$ のいかなる局所領域においても， $d'Q$ に非零の積分因子を掛けて完全微分にすることはできない．

### 6．結論

以上より，二つの理想気体の定積熱容量が異なり，外側の境界が可動で，温度 $T'$ ， $T''$ および共通圧力 $p$ が独立な状態変数となる場合，体系全体の熱量の微分形式 $d'Q$ は積分因子をもたない．

したがって，この体系は非ホロノームである．

```math
\boxed{
\text{熱的に不均質な体系は非ホロノームである}
}
```

### 7．境界条件に関する補足

本証明では，外側の境界が可動であり，共通圧力 $p$ を独立に変化させられることを前提としている．

この条件がない場合，結論は一般には成立しない．

例えば，外側の容器が剛体で全体積が一定なら，

```math
dV'+dV''=0
```

である．
このとき，式 (2)，(3) の和から，

```math
\begin{aligned}
d'Q
&=C_V'dT'+C_V''dT''
+p(dV'+dV'')\\
&=C_V'dT'+C_V''dT''
\end{aligned}
```

となる．
定積熱容量が定数であれば，

```math
\boxed{
d'Q=d(C_V'T'+C_V''T'')
}
```

であるから，積分因子 $\lambda=1$ が存在する．

また，共通圧力 $p$ が一定の場合にも，

```math
d'Q=(C_V'+\mathcal R)dT'
+(C_V''+\mathcal R)dT''
```

となり，これは完全微分である．

したがって，外側の境界が可動であるだけでなく，共通圧力も独立に変化できることが，本証明の重要な条件である．
