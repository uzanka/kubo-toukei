# 演習問題【2-B-32】

## 解答

### 1. 体系の熱量の定式化

この体系は，断熱性の滑りピストンによって隔てられた2つの部分（部分' と 部分''）から構成されている．
それぞれの部分が受け取る熱量を $d'Q'$ および $d'Q''$ とすると，体系全体の熱量 $d'Q$ はその和として表される．

$$d'Q = d'Q' + d'Q''$$

熱力学第一法則より，各部分の熱量は内部エネルギーの変化 $dU$ と仕事 $dW$ を用いて $dU = d'Q + d'W$ ，すなわち $d'Q = dU + d'W$ と書ける．
理想気体の内部エネルギーの変化は $dU = C_V dT$ で表されるため，各部分の熱量は以下のようになる．

$$d'Q' = C_V' dT' + p' dV'$$

$$d'Q'' = C_V'' dT'' + p'' dV''$$

ここで，滑りピストンは圧力が釣り合っている状態を保つため，両側の圧力は常に等しい．
すなわち $p' = p'' = p$ である．

理想気体の状態方程式 $pV = RT$ を用いると，体積の変化 $dV$ は温度 $T$ と圧力 $p$ を用いて次のように書ける．
状態方程式の両辺の対数をとり，全微分をとると，

$$\ln p + \ln V = \ln R + \ln T$$

$$\frac{dp}{p} + \frac{dV}{V} = \frac{dT}{T}$$

$$\frac{dV}{V} = \frac{dT}{T} - \frac{dp}{p}$$

$$dV = \frac{V}{T} dT - \frac{V}{p} dp$$

$V = \frac{RT}{p}$ を代入すると，

$$dV = \frac{R}{p} dT - \frac{RT}{p^2} dp = \frac{R}{p} dT - \frac{R}{p} \frac{T}{p} dp$$

あるいは， $pdV = R dT - \frac{RT}{p} dp$ と書ける．

これを用いて，各部分の熱量を $dT', dT'', dp$ の形式で書き直す．

$$d'Q' = C_V' dT' + p \left( \frac{R}{p} dT' - \frac{RT'}{p^2} dp \right) = (C_V' + R) dT' - \frac{RT'}{p} dp$$

$$d'Q'' = C_V'' dT'' + p \left( \frac{R}{p} dT'' - \frac{RT''}{p^2} dp \right) = (C_V'' + R) dT'' - \frac{RT''}{p} dp$$

したがって，体系全体の熱量 $d'Q$ は以下のようになる．

$$d'Q = (C_V' + R) dT' + (C_V'' + R) dT'' - \frac{R(T' + T'')}{p} dp \quad \cdots (1)$$

### 2. 積分因子の存在条件の検討

式(1)は， $T', T'', p$ という3つの変数を持つ微分形式である．
一般に，3変数 $x_1, x_2, x_3$ の微分形式 $X_1 dx_1 + X_2 dx_2 + X_3 dx_3$ が積分因子 $\lambda(x_1, x_2, x_3)$ をもつための必要条件は，次のように与えられる．

$$X_1 \left(\frac{\partial X_3}{\partial x_2} - \frac{\partial X_2}{\partial x_3}\right) + X_2 \left(\frac{\partial X_1}{\partial x_3} - \frac{\partial X_3}{\partial x_1}\right) + X_3 \left(\frac{\partial X_2}{\partial x_1} - \frac{\partial X_1}{\partial x_2}\right) = 0 \quad \cdots (2)$$

式(1)において，変数を $x_1 = T', x_2 = T'', x_3 = p$ とおくと，各成分は以下のようになる．
- $X_1 = C_V' + R$
- $X_2 = C_V'' + R$
- $X_3 = -\frac{R}{p}(T' + T'')$

これらの偏微分を計算する．
- $\frac{\partial X_3}{\partial x_2} = \frac{\partial}{\partial T''} \left[ -\frac{R}{p}(T' + T'') \right] = -\frac{R}{p}$
- $\frac{\partial X_2}{\partial x_3} = \frac{\partial}{\partial p} (C_V'' + R) = 0$
- $\frac{\partial X_1}{\partial x_3} = \frac{\partial}{\partial p} (C_V' + R) = 0$
- $\frac{\partial X_3}{\partial x_1} = \frac{\partial}{\partial T'} \left[ -\frac{R}{p}(T' + T'') \right] = -\frac{R}{p}$
- $\frac{\partial X_2}{\partial x_1} = \frac{\partial}{\partial T'} (C_V'' + R) = 0$
- $\frac{\partial X_1}{\partial x_2} = \frac{\partial}{\partial T''} (C_V' + R) = 0$

これらを式(2)の左辺に代入すると，

$$ (C_V' + R) \left( -\frac{R}{p} - 0 \right) + (C_V'' + R) \left( 0 - \left(-\frac{R}{p}\right) \right) + \left( -\frac{R(T' + T'')}{p} \right) (0 - 0) $$

$$ = -(C_V' + R)\frac{R}{p} + (C_V'' + R)\frac{R}{p} $$

$$ = \frac{R}{p} (C_V'' - C_V') $$

問題の条件より $C_V' \neq C_V''$ であるため，この値は 0 にはならない．

### 3. 結論

式(2)の条件が満たされないため，微分形式 $d'Q$ は積分因子をもたない．
したがって，この体系は非ホロノームである．

## 解説

### 積分因子とは何か？

熱力学において，熱量 $dQ$ は状態量（温度や圧力など）の関数として直接表すことができず，経路に依存する量である．
しかし，もしある関数 $\lambda$（積分因子）を掛けて $\lambda dQ$ としたとき，これが状態量の微分 $d\phi$ として書けるならば， $\lambda dQ$ は「状態量」として扱えるようになる．
エントロピー $S$ について言えば， $\frac{dQ}{T} = dS$ と書ける．
ここで $\frac{1}{T}$ が積分因子にあたる．
積分因子が存在するということは，その系が熱力学的に「一様」であり，エントロピーという状態量を定義できることを意味する．

### なぜこの問題は「非ホロノーム」なのか？

この問題のポイントは，ピストンで隔てられた2つの領域の温度が異なる（ $T' \neq T''$ ）という点にある．
通常，熱力学の基本法則（エントロピーの増大など）は，系全体が熱的に一様であることを前提としている．
しかし，このように温度分布が不均一な系では，系全体の熱量 $d'Q$ に対して，温度のみに依存するような単純な積分因子（例えば $1/T$ ）を見つけることができない．

数学的には，3つの変数（ $T', T'', p$ ）が絡み合う複雑な微分形式になってしまい，その「回転（curl）」のような成分がゼロにならないため，状態量へと変換できない．
このように，積分因子を持たない（＝状態量を定義できない）系を，非ホロノームな系と呼ぶ．
