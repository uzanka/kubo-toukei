# 例題【2-R-3】

## 解答

### 内部エネルギー密度と温度の関係

#### 1．全内部エネルギーを表す

問題では，気体の単位体積当たりの内部エネルギー $u$ が温度 $T$ のみの関数であり，状態方程式が

```math
p=\frac13u(T)
\tag{1}
```

で与えられている．
ここで， $p$ は圧力， $T$ は絶対温度である．

体積 $V$ の系が空間的に一様であるとすると，全内部エネルギー $U$ は単位体積当たりの内部エネルギーと体積の積で表される．
したがって，

```math
\boxed{
U=Vu(T)
}
\tag{2}
```

となる．

#### 2．熱力学第一法則を用いる

単純圧縮系に対する熱力学第一法則を，エントロピー $S$ を用いて表すと，

```math
dU=T\,dS-p\,dV
```

である．
これを $dS$ について解けば，

```math
dS=\frac1T\,dU+\frac pT\,dV
\tag{3}
```

を得る．

一方，式 (2) を微分すると，積の微分法則から

```math
dU=u(T)\,dV+V\frac{du(T)}{dT}\,dT
```

となる．
これを式 (3) に代入すると，

```math
dS=
\frac VT\frac{du(T)}{dT}\,dT
+\frac{u(T)+p}{T}\,dV
```

である．
ここで，状態方程式 $p=u(T)/3$ を用いると，

```math
\boxed{
dS=
\frac VT\frac{du(T)}{dT}\,dT
+\frac{4u(T)}{3T}\,dV
}
\tag{4}
```

となる．

#### 3．エントロピーの完全微分条件を適用する

エントロピー $S$ は状態量であるため，その微小変化 $dS$ は完全微分である．
すなわち，エントロピーを $T,V$ の関数 $S(T,V)$ とみなしたとき，混合偏微分の順序を交換できる．

一般に，

```math
dS=M(T,V)\,dT+N(T,V)\,dV
```

と表されるとき，完全微分であるためには，

```math
\left(\frac{\partial M}{\partial V}\right)_T
=
\left(\frac{\partial N}{\partial T}\right)_V
\tag{5}
```

が成立する．

式 (4) と比較して，

```math
M(T,V)=\frac VT\frac{du(T)}{dT}
```

および

```math
N(T,V)=\frac{4u(T)}{3T}
```

とおく．
まず， $M$ を体積 $V$ で偏微分すると，

```math
\left(\frac{\partial M}{\partial V}\right)_T
=\frac{1}{T}\frac{du(T)}{dT}
\tag{6}
```

となる．
次に， $N$ を温度 $T$ で偏微分する．
商の微分法則により，

```math
\begin{aligned}
\left(\frac{\partial N}{\partial T}\right)_V
&=\frac{4}{3}\frac{d}{dT}\left(\frac{u(T)}T\right)\\
&=\frac{4}{3}\left[
\frac1T\frac{du(T)}{dT}
-\frac{u(T)}{T^2}
\right]
\end{aligned}
\tag{7}
```

である．

式 (6)，(7) を完全微分条件 (5) に代入すると，

```math
\frac{1}{T}\frac{du(T)}{dT}
=
\frac{4}{3}\left[
\frac{1}{T}\frac{du(T)}{dT}
-\frac{u(T)}{T^2}
\right]
```

となる．
両辺に $3T^2$ を掛けて整理すると，

```math
3T\frac{du(T)}{dT}
=
4T\frac{du(T)}{dT}-4u(T)
```

である．
したがって，

```math
\boxed{
T\frac{du(T)}{dT}-4u(T)=0
}
\tag{8}
```

という微分方程式を得る．

#### 4．微分方程式を解く

式 (8) を変形すると，

```math
\frac{du(T)}{dT}=\frac{4u(T)}T
```

である．
$u(T)>0$ ， $T>0$ の範囲では，変数を分離して，

```math
\frac{du(T)}{u(T)}=4\frac{dT}{T}
```

と書ける．
両辺を積分すると，

```math
\ln u(T)=4\ln T+C
```

となる．
ここで $C$ は積分定数である．
対数の性質を用いて整理すれば，

```math
u(T)=e^C T^4
```

である．
比例定数を $A=e^C$ とおくと，

```math
\boxed{
u(T)=AT^4
}
\tag{9}
```

を得る．
$u(T)=0$ という解も $A=0$ とすることでこの形に含まれる．

#### 5．結論

与えられた状態方程式 $p=u(T)/3$ と，エントロピーが状態量であるという条件から，

```math
\boxed{
u(T)\propto T^4
}
```

であることが示された．
すなわち，内部エネルギー密度は絶対温度の4乗に比例する．
比例定数 $A$ の値は，与えられた条件だけでは決定されない．
この $T^4$ 依存性は，熱平衡状態にある光子気体のエネルギー密度が従う Stefan–Boltzmann 則と整合する結果である．
