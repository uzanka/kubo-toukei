# 例題【2-R-4】

## 解答

### カルノーサイクルを用いた熱力学恒等式の証明

証明すべき式は，

```math
\boxed{
\left(\frac{\partial p}{\partial T}\right)_V
=\frac{1}{T}
\left\{
\left(\frac{\partial U}{\partial V}\right)_T+p
\right\}
}
```

である．
ここで， $p$ は圧力， $V$ は体積， $T$ は絶対温度， $U$ は内部エネルギーである．
この式を，温度差が微小な2つの熱源を用いたカルノーサイクルによって導く．

#### 1．カルノーサイクルの設定

絶対温度 $T_1$ の高温熱源と，絶対温度

```math
T_2=T_1-dT
```

の低温熱源を用意する．
ここで $dT>0$ は微小な温度差である．
この2つの熱源の間で気体に可逆なカルノーサイクルを行わせ，4つの状態 $1,2,3,4$ を次のように定める．

- $1\to2$ ： 温度 $T_1$ での等温膨張．気体は高温熱源から熱量 $Q_1>0$ を吸収する．
- $2\to3$ ： 断熱膨張．気体の温度が $T_1$ から $T_2$ に下がる．
- $3\to4$ ： 温度 $T_2$ での等温圧縮．気体は低温熱源へ熱を放出する．この過程の熱量を符号付きで $Q_2<0$ と表す．
- $4\to1$ ： 断熱圧縮．気体の温度が $T_2$ から $T_1$ に戻る．

各状態の体積を $V_1,V_2,V_3,V_4$ とする．
$dT$ が微小であるため，断熱過程に伴う体積変化も微小であり，

```math
V_3-V_2=O(dT),\qquad
V_4-V_1=O(dT)
```

となる．
ここで $O(dT)$ は， $dT$ と同じ程度の小ささをもつ量を意味する．
したがって，1次の近似では $V_3\simeq V_2$ ， $V_4\simeq V_1$ とみなせる．

#### 2．等温過程における吸収熱量

熱力学第一法則は，気体が外部から受け取る熱量を $\delta Q$ ，気体が外部にする仕事を $p\,dV$ とすると，

```math
dU=\delta Q-p\,dV
```

と表される．
したがって，

```math
\delta Q=dU+p\,dV
```

である．

過程 $1\to2$ は温度 $T_1$ での等温過程なので，内部エネルギーの微小変化は，

```math
dU=\left(\frac{\partial U}{\partial V}\right)_{T_1}dV
```

と書ける．
よって，

```math
\delta Q=
\left\{
\left(\frac{\partial U}{\partial V}\right)_{T_1}+p
\right\}dV
```

となる．
これを状態1から状態2まで積分すると，

```math
\boxed{
Q_1=
\int_{V_1}^{V_2}
\left\{
\left(\frac{\partial U}{\partial V}\right)_{T_1}
+p(V,T_1)
\right\}dV
}
\tag{1}
```

を得る．
ここで $p(V,T)$ は，体積 $V$ ，温度 $T$ における圧力を表す．

#### 3．サイクル全体の仕事と微小温度差による近似

カルノーサイクルを一周すると，気体は元の状態に戻るため，内部エネルギーの変化はゼロである．
したがって，熱力学第一法則から，

```math
Q_1+Q_2=W
```

となる．
ここで， $W$ は気体が外部にする正味の仕事である．
圧力を体積に関して積分すると，

```math
W=\oint p\,dV
```

である．
よって，

```math
Q_1+Q_2
=
\int_1^2p\,dV
+\int_2^3p\,dV
+\int_3^4p\,dV
+\int_4^1p\,dV
\tag{2}
```

となる．
各積分は，それぞれの過程に沿った圧力の体積積分を表す．

##### 微小温度差での仕事の近似

温度 $T_1$ の等温過程 $1\to2$ と，温度 $T_2$ の等温過程 $3\to4$ を比較する．
同じ体積 $V$ での圧力差は，テイラー展開の一次近似によって，

```math
p(V,T_1)-p(V,T_2)
\simeq
\left(\frac{\partial p}{\partial T}\right)_VdT
```

となる．
この圧力差は $O(dT)$ である．

一方，断熱過程の体積変化は $O(dT)$ であり，断熱過程の仕事の積分そのものも一般に $O(dT)$ である．
したがって，断熱過程の積分だけを個別に無視することは，1次の精度では正当化できない．
しかし，等温過程の体積範囲を $V_1$ から $V_2$ にそろえる際に生じる積分区間の補正と，断熱過程の仕事を合わせると，それらの差は $O(dT^2)$ となる．
これは，短い体積区間が $O(dT)$ であり，その区間で比較される断熱経路と等温経路の圧力差も $O(dT)$ だからである．

したがって，1次の精度では，サイクル全体の仕事は2つの等温曲線の間の面積に等しく，

```math
\begin{aligned}
W
&\simeq
\int_{V_1}^{V_2}
\{p(V,T_1)-p(V,T_2)\}\,dV\\
&\simeq
dT\int_{V_1}^{V_2}
\left(\frac{\partial p}{\partial T}\right)_VdV
\end{aligned}
```

となる．
よって，

```math
\boxed{
Q_1+Q_2
=
dT\int_{V_1}^{V_2}
\left(\frac{\partial p}{\partial T}\right)_VdV
+O(dT^2)
}
\tag{3}
```

である．
以後は， $dT$ の一次の項までを考える．

#### 4．カルノーサイクルの熱量関係を用いる

可逆なカルノーサイクルでは，吸収熱量と放出熱量の間に，

```math
\frac{Q_1}{T_1}+\frac{Q_2}{T_2}=0
\tag{4}
```

が成立する．
これは，可逆サイクルについて $\oint \delta Q/T=0$ であることによる．
$Q_2$ は放出熱量を負の符号で表しているため，この形になる．

式 (4) から，

```math
Q_2=-\frac{T_2}{T_1}Q_1
```

である．
したがって，

```math
Q_1+Q_2
=Q_1\left(1-\frac{T_2}{T_1}\right)
=\frac{dT}{T_1}Q_1
```

となる．
ここで $T_1=T_2+dT$ なので， $dT$ の一次の精度では $T_1$ を $T_2$ に置き換えることができる．
よって，

```math
\boxed{
Q_1+Q_2
\simeq\frac{dT}{T_2}Q_1
}
\tag{5}
```

を得る．

式 (1) を式 (5) に代入すると，

```math
\begin{aligned}
Q_1+Q_2
\simeq{}&\frac{dT}{T_2}
\int_{V_1}^{V_2}
\left\{
\left(\frac{\partial U}{\partial V}\right)_{T_1}
+p(V,T_1)
\right\}dV
\end{aligned}
\tag{6}
```

となる．

#### 5．2つの結果を比較して目的の式を導く

式 (3) と式 (6) は，いずれも $Q_1+Q_2$ を表している．
したがって， $dT$ の一次の項を等置すると，

```math
\begin{aligned}
dT\int_{V_1}^{V_2}
\left(\frac{\partial p}{\partial T}\right)_VdV
\simeq{}&
\frac{dT}{T_2}
\int_{V_1}^{V_2}
\left\{
\left(\frac{\partial U}{\partial V}\right)_{T_1}
+p(V,T_1)
\right\}dV
\end{aligned}
```

を得る．
両辺を $dT$ で割り， $dT\to0$ の極限を考える．
このとき $T_1,T_2\to T$ となるため，

```math
\boxed{
\int_{V_1}^{V_2}
\left(\frac{\partial p}{\partial T}\right)_VdV
=
\frac1T\int_{V_1}^{V_2}
\left\{
\left(\frac{\partial U}{\partial V}\right)_T+p
\right\}dV
}
\tag{7}
```

となる．

ここで，状態1の体積 $V_1$ を固定し，状態2の体積 $V_2$ を同じ温度 $T$ の等温線上で任意に選ぶことができる．
したがって，式 (7) は任意の体積区間 $V_1$ から $V_2$ について成立する．

連続な関数について，任意の区間で2つの関数の積分が等しければ，被積分関数も等しくなければならない．
よって，

```math
\left(\frac{\partial p}{\partial T}\right)_V
=
\frac1T
\left\{
\left(\frac{\partial U}{\partial V}\right)_T+p
\right\}
```

が導かれる．

以上より，求める熱力学恒等式，

```math
\boxed{
\displaystyle
\left(\frac{\partial p}{\partial T}\right)_V
=
\frac{1}{T}
\left\{
\left(\frac{\partial U}{\partial V}\right)_T+p
\right\}
}
```

が，2つの近接した温度の熱源を用いたカルノーサイクルによって証明された．
