# 演習問題【7-A-11】

## 解答

重水素分子と水素分子の交換反応

```math
\mathrm{D_2+H_2\rightleftharpoons 2HD}
```

の平衡定数を，分子の並進，回転，核スピン，振動の分配関数を用いて求める．
分子の回転運動は古典的近似が成り立つほど高温であると仮定する．

### 1．平衡定数と分配関数の関係

各分子種の分子数を $N_{\mathrm{H_2}},N_{\mathrm{D_2}},N_{\mathrm{HD}}$ とし，それぞれの単一分子分配関数を $f(\mathrm{H_2}),f(\mathrm{D_2}),f(\mathrm{HD})$ とする．
理想気体の混合系における全分配関数は，

```math
Z=
\frac{f(\mathrm{H_2})^{N_{\mathrm{H_2}}}}{N_{\mathrm{H_2}}!}
\frac{f(\mathrm{D_2})^{N_{\mathrm{D_2}}}}{N_{\mathrm{D_2}}!}
\frac{f(\mathrm{HD})^{N_{\mathrm{HD}}}}{N_{\mathrm{HD}}!}
\tag{1}
```

と表される．

平衡では，原子数の保存条件のもとで分配関数が最大となる分子数の組合せが選ばれる．
反応が右に1回進むと， $\mathrm{H_2}$ と $\mathrm{D_2}$ がそれぞれ1分子減少し， $\mathrm{HD}$ が2分子増加する．
この変化に対して $\log Z$ が停留する条件を用いると，

```math
\frac{N_{\mathrm{HD}}^2}
{N_{\mathrm{H_2}}N_{\mathrm{D_2}}}
=
\frac{f(\mathrm{HD})^2}
{f(\mathrm{H_2})f(\mathrm{D_2})}
\tag{2}
```

が得られる．
したがって，平衡定数は単一分子分配関数の比で表せる．
この反応では反応前後の分子数が同じであるため，理想気体では数密度で定義した平衡定数と分圧で定義した平衡定数の比の形は同じになる．

単一分子分配関数を並進運動と内部自由度に分けると，

```math
f(i)=f_{\mathrm{trans}}(i)\,j(i)
```

である．
ここで， $f_{\mathrm{trans}}$ は並進分配関数， $j$ は回転，核スピン，振動などの内部自由度の分配関数である．
よって，

```math
K=
\left[
\frac{m_{\mathrm{HD}}^2}
{m_{\mathrm{H_2}}m_{\mathrm{D_2}}}
\right]^{3/2}
\frac{j(\mathrm{HD})^2}
{j(\mathrm{H_2})j(\mathrm{D_2})}
\tag{3}
```

となる．
ここでは，並進分配関数 $f_{\mathrm{trans}}/V=(2\pi mk_{\mathrm B}T/h^2)^{3/2}$ を用いた．
体積 $V$ と温度に依存する共通因子は比を取ることで相殺される．
以下，各因子を求める．

### 2．並進運動の寄与

水素原子と重水素原子の質量をそれぞれ $m_{\mathrm H},m_{\mathrm D}$ とする．
分子の質量は，

```math
m_{\mathrm{H_2}}=2m_{\mathrm H},
\qquad
m_{\mathrm{D_2}}=2m_{\mathrm D},
\qquad
m_{\mathrm{HD}}=m_{\mathrm H}+m_{\mathrm D}
```

である．
これらを式 (3) の並進分配関数の比に代入すると，

```math
\begin{aligned}
\left[
\frac{m_{\mathrm{HD}}^2}
{m_{\mathrm{H_2}}m_{\mathrm{D_2}}}
\right]^{3/2}
&=
\left[
\frac{(m_{\mathrm H}+m_{\mathrm D})^2}
{4m_{\mathrm H}m_{\mathrm D}}
\right]^{3/2}\\
&=
\frac{(m_{\mathrm H}+m_{\mathrm D})^3}
{8(m_{\mathrm H}m_{\mathrm D})^{3/2}}
\end{aligned}
\tag{4}
```

となる．

### 3．回転運動と核スピンの寄与

回転の特性温度を $\Theta_{r,i}$ とする．
回転が古典的に扱える高温では，異核二原子分子の回転分配関数は $T/\Theta_r$ ，同核二原子分子では対称数が2であるため $T/(2\Theta_r)$ で近似される．
ただし， $\mathrm{H_2}$ と $\mathrm{D_2}$ では核スピンの統計的重率も考慮する必要がある．

水素原子核のスピンは $1/2$ であるため， $\mathrm{H_2}$ ではオルソ状態の核スピン重率が3，パラ状態の核スピン重率が1である．
高温では偶数回転量子数と奇数回転量子数の分配関数がそれぞれ $T/(2\Theta_{r,\mathrm{H_2}})$ に近づくので，

```math
j(\mathrm{H_2})
\simeq (3+1)\frac{T}{2\Theta_{r,\mathrm{H_2}}}
=\frac{2T}{\Theta_{r,\mathrm{H_2}}}
\tag{5}
```

となる．

重水素原子核のスピンは1であるため， $\mathrm{D_2}$ ではオルソ状態の重率が6，パラ状態の重率が3である．
したがって，

```math
j(\mathrm{D_2})
\simeq (6+3)\frac{T}{2\Theta_{r,\mathrm{D_2}}}
=\frac{9T}{2\Theta_{r,\mathrm{D_2}}}
\tag{6}
```

となる．

一方， $\mathrm{HD}$ は異核二原子分子であり，同核分子の交換対称性による偶奇の制約を受けない．
水素核の2状態と重水素核の3状態の組合せから，核スピン重率は $2\times3=6$ である．
よって，

```math
j(\mathrm{HD})
\simeq 6\frac{T}{\Theta_{r,\mathrm{HD}}}
\tag{7}
```

である．

式 (5)～(7) より，

```math
\begin{aligned}
\frac{j(\mathrm{HD})^2}
{j(\mathrm{H_2})j(\mathrm{D_2})}
&=
\frac{(6T/\Theta_{r,\mathrm{HD}})^2}
{(2T/\Theta_{r,\mathrm{H_2}})
(9T/(2\Theta_{r,\mathrm{D_2}}))}\\
&=4\frac{\Theta_{r,\mathrm{H_2}}\Theta_{r,\mathrm{D_2}}}
{\Theta_{r,\mathrm{HD}}^2}
\end{aligned}
\tag{8}
```

を得る．
回転温度は慣性モーメント $I$ に反比例し， $I=\mu r^2$ である．
ここで， $\mu$ は換算質量， $r$ は核間距離である．
核間距離が同じと仮定すれば，

```math
\frac{\Theta_{r,\mathrm{H_2}}\Theta_{r,\mathrm{D_2}}}
{\Theta_{r,\mathrm{HD}}^2}
=
\frac{I_{\mathrm{HD}}^2}
{I_{\mathrm{H_2}}I_{\mathrm{D_2}}}
```

となる．
したがって，

```math
\begin{aligned}
\frac{j(\mathrm{HD})^2}
{j(\mathrm{H_2})j(\mathrm{D_2})}
&=
4\frac{I_{\mathrm{HD}}^2}
{I_{\mathrm{H_2}}I_{\mathrm{D_2}}}\\
&=
16\frac{m_{\mathrm H}m_{\mathrm D}}
{(m_{\mathrm H}+m_{\mathrm D})^2}
\end{aligned}
\tag{9}
```

である．
式 (4)，(9) の積を取ると，質量と回転・核スピンによる因子は，

```math
\begin{aligned}
&\frac{(m_{\mathrm H}+m_{\mathrm D})^3}
{8(m_{\mathrm H}m_{\mathrm D})^{3/2}}
\cdot
16\frac{m_{\mathrm H}m_{\mathrm D}}
{(m_{\mathrm H}+m_{\mathrm D})^2}\\
&\qquad =
2\frac{m_{\mathrm H}+m_{\mathrm D}}
{\sqrt{m_{\mathrm H}m_{\mathrm D}}}
\end{aligned}
\tag{10}
```

となる．

### 4．振動運動と零点エネルギーの寄与

各分子の振動特性温度を

```math
\Theta_i=\frac{h\nu_i}{k_{\mathrm B}}
```

とする．
ここで， $\nu_i$ は分子 $i$ の振動数である．
振動の零点エネルギー $h\nu_i/2$ を含む調和振動子の分配関数は，

```math
q_{\mathrm{vib}}(i)
=
\frac{e^{-\Theta_i/(2T)}}
{1-e^{-\Theta_i/T}}
\tag{11}
```

である．
この分配関数を用いると，振動による比は，

```math
\begin{aligned}
\frac{q_{\mathrm{vib}}(\mathrm{HD})^2}
{q_{\mathrm{vib}}(\mathrm{H_2})q_{\mathrm{vib}}(\mathrm{D_2})}
={}&
\frac{
(1-e^{-\Theta_{\mathrm{H_2}}/T})
(1-e^{-\Theta_{\mathrm{D_2}}/T})
}{
(1-e^{-\Theta_{\mathrm{HD}}/T})^2
}\\
&\times
\exp\left[
-\frac{2\Theta_{\mathrm{HD}}
-\Theta_{\mathrm{H_2}}
-\Theta_{\mathrm{D_2}}}{2T}
\right]
\end{aligned}
\tag{12}
```

となる．
指数関数は零点エネルギーによる補正を表している．
電子状態の結合エネルギーは同位体置換で同じと近似するが，振動数が同じではないため，零点エネルギーの差は残るのである．

式 (10)，(12) をまとめると，平衡定数は，

```math
\boxed{
\begin{aligned}
K(T)={}&
2\frac{m_{\mathrm H}+m_{\mathrm D}}
{\sqrt{m_{\mathrm H}m_{\mathrm D}}}
\frac{
(1-e^{-\Theta_{\mathrm{H_2}}/T})
(1-e^{-\Theta_{\mathrm{D_2}}/T})
}{
(1-e^{-\Theta_{\mathrm{HD}}/T})^2
}\\
&\times
\exp\left[
-\frac{2\Theta_{\mathrm{HD}}
-\Theta_{\mathrm{H_2}}
-\Theta_{\mathrm{D_2}}}{2T}
\right]
\end{aligned}
}
\tag{13}
```

を得る．

### 5．高温極限と振動が凍結した領域

各分子の振動数は，換算質量 $\mu$ が同じ力定数のもとで変わるとき，

```math
\nu\propto\frac{1}{\sqrt{\mu}}
```

に従う．
水素核の質量を $m_{\mathrm H}=m$ ，重水素核の質量を $m_{\mathrm D}=2m$ と近似すると，

```math
\mu_{\mathrm{H_2}}=\frac m2,\qquad
\mu_{\mathrm{HD}}=\frac{2m}{3},\qquad
\mu_{\mathrm{D_2}}=m
```

である．
したがって，振動特性温度も同じ比に従い，

```math
\boxed{
\Theta_{\mathrm{HD}}:\Theta_{\mathrm{H_2}}:\Theta_{\mathrm{D_2}}
=1:1.155:0.817
}
\tag{14}
```

となる．

#### 高温極限

すべての振動特性温度より高温，すなわち $T\gg\Theta_i$ では，

```math
1-e^{-\Theta_i/T}\simeq\frac{\Theta_i}{T}
```

であり，指数因子も1に近づく．
よって，式 (13) は，

```math
K_\infty=
2\frac{m_{\mathrm H}+m_{\mathrm D}}
{\sqrt{m_{\mathrm H}m_{\mathrm D}}}
\frac{\Theta_{\mathrm{H_2}}\Theta_{\mathrm{D_2}}}
{\Theta_{\mathrm{HD}}^2}
\tag{15}
```

となる．
式 (14) と $m_{\mathrm D}=2m_{\mathrm H}$ を代入すると，

```math
\begin{aligned}
K_\infty
&=3\sqrt2\left(1.155\times0.817\right)\\
&=3\sqrt2\left(\frac{2\sqrt2}{3}\right)\\
&=\boxed{4}
\end{aligned}
```

を得る．

#### 振動がほぼ基底状態にある領域

一方，すべての振動特性温度より低温，すなわち $T\ll\Theta_i$ では，

```math
1-e^{-\Theta_i/T}\simeq1
```

である．
式 (13) は，

```math
K(T)\simeq
3\sqrt2\exp\left[
-\frac{2\Theta_{\mathrm{HD}}
-\Theta_{\mathrm{H_2}}
-\Theta_{\mathrm{D_2}}}{2T}
\right]
\tag{16}
```

と簡略化できる．
ここで式 (14) を使うと，

```math
\begin{aligned}
\frac{2\Theta_{\mathrm{HD}}
-\Theta_{\mathrm{H_2}}
-\Theta_{\mathrm{D_2}}}{2}
&\simeq
\frac{2-1.155-0.817}{2}
\Theta_{\mathrm{HD}}\\
&\simeq0.0144\Theta_{\mathrm{HD}}
\end{aligned}
```

となる．
解答例で用いられている $\Theta_{\mathrm{HD}}\simeq4324\ \mathrm K$ を代入すれば，

```math
0.0144\Theta_{\mathrm{HD}}\simeq62.3\ \mathrm K
```

である．
また $3\sqrt2\simeq4.24$ なので，

```math
\boxed{
K(T)\simeq4.24\,e^{-62.3/T}
}
\tag{17}
```

を得る．
この近似は振動励起が抑制される $T\ll\Theta_i$ の領域を表しているが，回転については古典近似が成り立つ温度範囲で用いる必要がある．

### 結論

回転運動が古典的に扱える高温領域では，統計力学的に求めた $\mathrm{D_2+H_2\rightleftharpoons2HD}$ の平衡定数は式 (13) で与えられる．
さらに，振動も十分に熱励起される極限では $K_\infty=4$ となり，振動がほぼ基底状態に留まる領域では，解答例の条件のもとで，

```math
\boxed{
K(T)\simeq4.24\,e^{-62.3/T}
}
```

となる．
これらの温度依存性は，並進・回転・核スピンの統計的重率だけでなく，同位体置換による振動数の違いと零点エネルギーの差によっても平衡が変化することを示している．
