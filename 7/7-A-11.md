# 演習問題【7-A-11】

## 解答

本問題では，反応 $\text{D}_2 + \text{H}_2 \rightleftharpoons 2\text{HD}$ の平衡定数を統計力学的な手法を用いて求める．

### 1. 統計力学的な定式化

系全体の分配関数 $Z$ を考える．
反応に関与する分子は $\text{H}_2, \text{D}_2, \text{HD}$ の3種類であり，それぞれの分子数を $N(\text{H}_2), N(\text{D}_2), N(\text{HD})$ とすると，理想気体の統計力学によれば，全分配関数 $Z$ は次のように書ける：

$$Z(N(\text{H}_2), N(\text{D}_2), N(\text{HD})) = \frac{f(\text{H}_2)^{N(\text{H}_2)}}{N(\text{H}_2)!} \frac{f(\text{D}_2)^{N(\text{D}_2)}}{N(\text{D}_2)!} \frac{f(\text{HD})^{N(\text{HD})}}{N(\text{HD})!}$$

ここで $f(\text{i})$ は分子 $\text{i}$ の単一分子分配関数である．

平衡状態においては，系の自由エネルギーが最小となる，あるいは分配関数 $Z$ が最大となる状態が選ばれる．
ここで，反応に関与する原子の総数は保存されるという制約条件がある：

$$2N(\text{H}_2) + N(\text{HD}) = \text{const.}$$

$$2N(\text{D}_2) + N(\text{HD}) = \text{const.}$$

これらの制約条件の下で $Z$ を最大化することで，平衡における各分子数 $N(\text{i})$ の比を求めることができる．
具体的には，ラグランジュの未定乗数法を用いるか，あるいは $\ln Z$ を最大化することで，平衡定数 $K_p$ （または圧力を一定としたときの $K_c$ ）が次のように導かれる：

$$K_p = K_c = \frac{N(\text{HD})^2}{N(\text{H}_2)N(\text{D}_2)} = \frac{f(\text{HD})^2}{f(\text{H}_2)f(\text{D}_2)}$$

### 2. 分配関数の分解と各成分の寄与

単一分子分配関数 $f$ は，各自由度の寄与の積として分解できる：

$$f = f_{\text{trans}} f_{\text{rot}} f_{\text{vib}} f_{\text{elec}}$$

ここで， $f_{\text{trans}}$ は並進運動， $f_{\text{rot}}$ は回転運動， $f_{\text{vib}}$ は振動運動， $f_{\text{elec}}$ は電子状態（および核スピン）の分配関数である．

#### (a) 並進運動の寄与

並進分配関数は，分子の質量 $m$ に対して $f_{\text{trans}} \propto m^{3/2}$ の関係がある：

$$f_{\text{trans}} = \left( \frac{2\pi mkT}{h^2} \right)^{3/2} V$$

これを用いると，平衡定数への質量による寄与は以下のようになる：

$$\frac{f(\text{HD})^2}{f(\text{H}_2)f(\text{D}_2)} \propto \frac{(m_{\text{HD}}^{3/2})^2}{m_{\text{H}_2}^{3/2} m_{\text{D}_2}^{3/2}} = \left( \frac{m_{\text{HD}}^2}{m_{\text{H}_2} m_{\text{D}_2}} \right)^{3/2}$$

#### (b) 回転運動と核スピンの寄与

回転分配関数 $f_{\text{rot}}$ は，慣性モーメント $I$ に対して $f_{\text{rot}} \propto I$ の関係がある．
また，核スピンの統計的な重み $j$ も考慮する必要がある．
核間距離がすべての分子で同一であると仮定すると，慣性モーメントは換算質量 $\mu$ に比例する（ $I = \mu r^2$ ）．
したがって，回転および核スピンの寄与の比は次のように書ける：

$$\frac{j_{\text{nuc-rot}}(\text{HD})^2}{j_{\text{nuc-rot}}(\text{H}_2)j_{\text{nuc-rot}}(\text{D}_2)} = \frac{4I(\text{HD})^2}{I(\text{H}_2)I(\text{D}_2)} = 4 \frac{\{m_{\text{H}}m_{\text{D}}/(m_{\text{H}} + m_{\text{D}})\}^2}{(m_{\text{H}}/2)(m_{\text{D}}/2)} = 16 \frac{m_{\text{H}}m_{\text{D}}}{(m_{\text{H}} + m_{\text{D}})^2}$$

#### (c) 振動運動の寄与

振動分配関数は，振動数 $\nu$ と零点エネルギー $h\nu/2$ を考慮して次のように表される：

$$f_{\text{vib}} = \frac{e^{-h\nu/2kT}}{1 - e^{-h\nu/kT}}$$

これらをすべて組み合わせると，平衡定数 $K$ は以下の式となる：

$$K = 4 \frac{m_{\text{H}} + m_{\text{D}}}{2(m_{\text{H}}m_{\text{D}})^{1/2}} \frac{(1 - e^{-h\nu_{\text{H}_2}/kT})(1 - e^{-h\nu_{\text{D}_2}/kT})}{(1 - e^{-h\nu_{\text{HD}}/kT})^2} e^{-(h/2)(2\nu_{\text{HD}} - \nu_{\text{H}_2} - \nu_{\text{D}_2})/kT}$$

### 3. 温度依存性と極限

#### 高温極限 ($\Theta_{\text{HD}} \ll T$)

高温では，振動項において $1 - e^{-h\nu/kT} \approx h\nu/kT$ と近似できる．
このとき，式は次のように簡略化される：

$$K_{\infty} = 4 \frac{m_{\text{H}} + m_{\text{D}}}{2(m_{\text{H}}m_{\text{D}})^{1/2}} \frac{\nu_{\text{H}_2}\nu_{\text{D}_2}}{\nu_{\text{HD}}^2}$$

振動数は換算質量の平方根に反比例すること（ $\nu \propto \mu^{-1/2}$ ）を用いると，

```math
\nu_{\text{HD}} : \nu_{\text{H}_2} : \nu_{\text{D}_2} = \mu_{\text{HD}}^{-1/2} : \mu_{\text{H}_2}^{-1/2} : \mu_{\text{D}_2}^{-1/2}
```

となる．

```math
m_{\text{D}} = 2m_{\text{H}}
```

とすると，

```math
\nu_{\text{HD}} : \nu_{\text{H}_2} : \nu_{\text{D}_2} = 1 : 1.155 : 0.817
```

となり，

```math
K_{\infty} = 4
```

が得られる．

#### 低温極限 ($\Theta_{\text{HD}} \gg T$)

低温では，振動項は指数関数的な減衰が支配的となる．
式 (3) に示される通り，温度 $T$ に依存した指数関数的な挙動を示す．

### 4. 数値計算の結果

$m_{\text{D}} = 2m_{\text{H}}$ のとき，具体的な数値を用いて計算すると，

$$K = 3\sqrt{2} \exp [-0.0144\Theta_{\text{HD}}/T] = 4.24 \exp (-62.3/T)$$

が得られる．

## 解説

本問題は，微視的な分子の性質（質量，回転，振動）が，どのように巨視的な平衡定数へと結びつくかを示す典型的な例である．

### 1.  質量と平衡

並進運動の寄与により，より重い分子が生成される反応では平衡が右に寄りやすい．

### 2.  振動エネルギーの影響

振動の零点エネルギーは，反応前後で変化する場合，平衡定数に対して指数関数的な影響を及ぼす．
今回の反応では，結合エネルギーの変化がないと仮定しているため，振動数の比が重要となる．

### 3.  統計力学の威力

複雑な反応の平衡状態を，個々の分子の分配関数という単純な要素に分解して扱うことができる点が，統計力学の強力な点である．
