# 例題【7-R-1】

## 解答

### 1．回転分配関数の高温近似

異核二原子分子の回転分配関数は，問題文の式 (7.8) より

```math
r(T)=\sum_{l=0}^{\infty}(2l+1)
\exp\left[-l(l+1)\frac{\Theta_r}{T}\right]
```

である．
ここで，

```math
\Theta_r=\frac{\hbar^2}{2Ik}
```

である．
以下では，

```math
x=\frac{\Theta_r}{T}
```

とおくと，

```math
r(T)=\sum_{l=0}^{\infty}(2l+1)e^{-xl(l+1)}
```

となる．
高温では $x\ll1$ であるため，Euler–Maclaurin の総和公式を用いて $x$ の漸近展開を求める．

#### Euler–Maclaurin の総和公式

関数 $f(t)$ に対して，

```math
\begin{aligned}
\sum_{l=0}^{\infty}f(l)
={}&\int_0^\infty f(t)\,dt+\frac{f(0)}2\\
&-\frac{B_2}{2!}f'(0)
-\frac{B_4}{4!}f'''(0)\\
&-\frac{B_6}{6!}f^{(5)}(0)-\cdots
\end{aligned}
```

が成り立つ．
ここで $B_{2k}$ は Bernoulli 数であり，

```math
B_2=\frac16,\qquad
B_4=-\frac1{30},\qquad
B_6=\frac1{42}
```

である．
したがって，

```math
\begin{aligned}
\sum_{l=0}^{\infty}f(l)
={}&\int_0^\infty f(t)\,dt+\frac{f(0)}2\\
&-\frac1{12}f'(0)
+\frac1{720}f'''(0)\\
&-\frac1{30240}f^{(5)}(0)+\cdots
\end{aligned}
```

となる．

今回は，

```math
f(t)=(2t+1)e^{-xt(t+1)}
```

とする．

#### 積分項と端点補正項

まず，積分項を計算する．

```math
I=\int_0^\infty(2t+1)e^{-xt(t+1)}dt
```

とおき，

```math
u=t(t+1)
```

と変数変換すると，

```math
du=(2t+1)dt
```

であるから，

```math
\begin{aligned}
I
&=\int_0^\infty e^{-xu}du\\
&=\left[-\frac1x e^{-xu}\right]_0^\infty\\
&=\frac1x.
\end{aligned}
```

したがって，

```math
\boxed{
\int_0^\infty f(t)\,dt=\frac1x
}
```

となる．

また，

```math
f(0)=1
```

であるから，

```math
\boxed{\frac{f(0)}2=\frac12}
```

である．

#### 高階微分の計算

```math
g(t)=e^{-xt(t+1)}
```

とおくと，

```math
f(t)=(2t+1)g(t)
```

である．
Leibniz の公式より，

```math
f^{(n)}(t)
=(2t+1)g^{(n)}(t)+2n g^{(n-1)}(t)
```

となる．
特に，

```math
\begin{aligned}
f'(t)&=(2t+1)g'(t)+2g(t),\\
f'''(t)&=(2t+1)g'''(t)+6g''(t),\\
f^{(5)}(t)&=(2t+1)g^{(5)}(t)+10g^{(4)}(t)
\end{aligned}
```

である．

ここで，

```math
g(t)=e^{-xt}e^{-xt^2}
```

を $t=0$ のまわりで展開すると，

```math
\begin{aligned}
g(t)
={}&1-xt
+\left(\frac{x^2}{2}-x\right)t^2\\
&+\left(x^2-\frac{x^3}{6}\right)t^3\\
&+\left(\frac{x^2}{2}-\frac{x^3}{2}
+\frac{x^4}{24}\right)t^4\\
&+\left(-\frac{x^3}{2}+\frac{x^4}{6}
-\frac{x^5}{120}\right)t^5
+O(t^6).
\end{aligned}
```

したがって，

```math
\begin{aligned}
g'(0)&=-x,\\
g''(0)&=x^2-2x,\\
g'''(0)&=6x^2-x^3,\\
g^{(4)}(0)&=12x^2-12x^3+x^4,\\
g^{(5)}(0)&=-60x^3+20x^4-x^5.
\end{aligned}
```

これらを $f(t)$ の導関数に代入すると，

```math
\begin{aligned}
f'(0)
&=g'(0)+2g(0)\\
&=2-x,
\end{aligned}
```

```math
\begin{aligned}
f'''(0)
&=g'''(0)+6g''(0)\\
&=(6x^2-x^3)+6(x^2-2x)\\
&=-12x+12x^2-x^3,
\end{aligned}
```

```math
\begin{aligned}
f^{(5)}(0)
&=g^{(5)}(0)+10g^{(4)}(0)\\
&=(-60x^3+20x^4-x^5)\\
&\quad+10(12x^2-12x^3+x^4)\\
&=120x^2-180x^3+30x^4-x^5.
\end{aligned}
```

よって，

```math
\boxed{
\begin{aligned}
f'(0)&=2-x,\\
f'''(0)&=-12x+12x^2-x^3,\\
f^{(5)}(0)&=120x^2-180x^3+30x^4-x^5.
\end{aligned}
}
```

#### Euler–Maclaurin 展開への代入

以上の結果を Euler–Maclaurin の総和公式に代入すると，

```math
\begin{aligned}
r(T)
={}&\frac1x+\frac12-\frac1{12}(2-x)\\
&+\frac1{720}(-12x+12x^2-x^3)\\
&-\frac1{30240}
(120x^2-180x^3+30x^4-x^5)
+\cdots
\end{aligned}
```

を得る．

定数項は，

```math
\frac12-\frac{2}{12}
=\frac12-\frac16
=\frac13
```

である．

次に， $x$ の係数は，

```math
\frac1{12}-\frac{12}{720}
=\frac1{12}-\frac1{60}
=\frac1{15}
```

となる．

また， $x^2$ の係数は，

```math
\frac{12}{720}-\frac{120}{30240}
=\frac1{60}-\frac1{252}
=\frac4{315}
```

である．

したがって，

```math
\boxed{
r(T)=\frac1x+\frac13+\frac{x}{15}
+\frac{4x^2}{315}+O(x^3)
}
```

となる．

ここで $x=\Theta_r/T$ を代入すると，

```math
\boxed{
r(T)=
\frac{T}{\Theta_r}
+\frac13
+\frac1{15}\frac{\Theta_r}{T}
+\frac4{315}\left(\frac{\Theta_r}{T}\right)^2
+O\left(\left(\frac{\Theta_r}{T}\right)^3\right)
}
```

を得る．
これが求める高温展開式である．

特に，最初の補正項まで残せば，

```math
\boxed{
r(T)\simeq
\frac{T}{\Theta_r}
+\frac13
+\frac1{15}\frac{\Theta_r}{T}
}
```

となる．

これは，古典的な回転分配関数 $T/\Theta_r$ に量子力学的な補正が加わることを示している．

### 2．HCl 分子への適用

与えられた値は，

```math
\Theta_r=15.02\ \mathrm K,\qquad
T=300.4\ \mathrm K
```

である．
したがって，

```math
x=\frac{\Theta_r}{T}
=\frac{15.02}{300.4}
=0.0500
```

となる．
また，

```math
\frac{T}{\Theta_r}=20
```

である．

$x^2$ の項まで含む高温展開式に代入すると，

```math
\begin{aligned}
r(T)
&\simeq
20+\frac13+\frac{0.05}{15}
+\frac4{315}(0.05)^2\\
&=20+0.3333333333\\
&\quad+0.0033333333+0.0000317460\\
&=20.3366984.
\end{aligned}
```

したがって，

```math
\boxed{
r(300.4\ \mathrm K)\simeq20.3366984
}
```

となる．

なお， $x$ の一次の補正まで用いた場合は，

```math
r(T)\simeq20+\frac13+\frac{0.05}{15}
=20.3366667
```

である．

### 3．古典的な値との比較

古典的な回転分配関数は，

```math
r_{\mathrm{cl}}=\frac{T}{\Theta_r}
```

であるから，

```math
\boxed{r_{\mathrm{cl}}=20.0000}
```

となる．

$x^2$ の項まで含む高温展開による値との差は，

```math
\begin{aligned}
\Delta r
&=20.3366984-20.0000\\
&=0.3366984.
\end{aligned}
```

したがって，古典値に対する相対補正は，

```math
\begin{aligned}
\frac{\Delta r}{r_{\mathrm{cl}}}\times100
&=\frac{0.3366984}{20}\times100\\
&\simeq1.68349\%.
\end{aligned}
```

よって，量子力学的な補正は約 $1.68\%$ である．

さらに，元の無限和

```math
r(T)=\sum_{l=0}^{\infty}(2l+1)e^{-0.05l(l+1)}
```

を直接数値計算すると，

```math
r_{\mathrm{direct}}\simeq20.3366988
```

となる．
これは $x^2$ の項まで含む高温展開による値とよく一致している．

| 計算方法 | 回転分配関数 $r$ |
|---|---:|
| 古典的近似 $T/\Theta_r$ | 20.0000000 |
| 高温展開（ $x$ の一次まで） | 20.3366667 |
| 高温展開（ $x^2$ の項まで） | 20.3366984 |
| 元の無限和の直接数値計算 | 20.3366988 |

### 4．結論

Euler–Maclaurin の総和公式を用いると，異核二原子分子の高温回転分配関数は，

```math
\boxed{
r(T)=
\frac{T}{\Theta_r}
+\frac13
+\frac1{15}\frac{\Theta_r}{T}
+\frac4{315}\left(\frac{\Theta_r}{T}\right)^2
+\cdots
}
```

と展開できる．

HCl 分子について， $T=300.4\ \mathrm K$ ， $\Theta_r=15.02\ \mathrm K$ とすると，

```math
\boxed{r(T)\simeq20.3366984}
```

となる．

これは古典的な値 $20.0000$ より約 $1.68\%$ 大きい．
したがって，この温度では古典近似は比較的よく成り立つが，量子力学的な補正も有限の大きさを持つ．
