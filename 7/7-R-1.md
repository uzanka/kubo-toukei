# 演習問題【7-R-1】

## 解答

異核 2 原子分子の回転運動に関する分配関数 $r(T)$ を求める．

### 1. 回転分配関数の定義

異核 2 原子分子の回転運動において，回転エネルギー準位 $E_l$ は次のように与えられる：

$$E_l = \frac{\hbar^2}{2I} l(l+1) \quad (l = 0, 1, 2, \dots)$$

ここで， $I$ は分子の慣性モーメント， $\hbar$ は換算プランク定数である．

回転分配関数 $r(T)$ は，各エネルギー準位のボルツマン因子を重み $(2l+1)$ （状態密度）をつけて足し合わせたものである：

$$r(T) = \sum_{l=0}^{\infty} (2l + 1) \exp\left( -\frac{E_l}{kT} \right) = \sum_{l=0}^{\infty} (2l + 1) \exp\left[ -\frac{\hbar^2 l(l+1)}{2IkT} \right]$$

ここで， $k$ はボルツマン定数である．

回転温度 $\Theta_r$ を次のように定義する：

$$\Theta_r = \frac{\hbar^2}{2Ik}$$

これを用いると，分配関数は次のように書き直せる：

$$r(T) = \sum_{l=0}^{\infty} (2l + 1) \exp\left[ -\frac{\Theta_r}{T} l(l+1) \right]$$

計算を簡略化するために， $\sigma = \frac{\Theta_r}{T}$ とおく．
すると，

$$r(T) = \sum_{l=0}^{\infty} (2l + 1) \exp\left[ -\sigma l(l+1) \right]$$

となる．

### 2. Euler-Maclaurin の総和公式による近似

高温領域（ $T \gg \Theta_r$ すなわち $\sigma \ll 1$ ）において，この和を積分で近似するために Euler-Maclaurin の総和公式を用いる．
関数 $f(x)$ に対する総和公式は次の通りである：

$$\sum_{l=0}^{\infty} f(l) = \int_{0}^{\infty} f(x) \, dx + \frac{1}{2} f(0) - \frac{1}{12} f'(0) + \frac{1}{720} f'''(0) - \cdots$$

本問題では， $f(x) = (2x + 1) \exp\left[ -\sigma x(x + 1) \right]$ とおく．

#### (i) 積分の計算

まず， $\int_{0}^{\infty} f(x) \, dx$ を計算する．

$$\int_{0}^{\infty} (2x + 1) \exp\left[ -\sigma (x^2 + x) \right] \, dx$$

ここで， $t = \sigma(x^2 + x)$ とおくと， $dt = \sigma(2x + 1) \, dx$ となる．
積分範囲は $x: 0 \to \infty$ のとき $t: 0 \to \infty$ である．
したがって，

$$\int_{0}^{\infty} f(x) \, dx = \int_{0}^{\infty} \frac{1}{\sigma} e^{-t} \, dt = \frac{1}{\sigma} \left[ -e^{-t} \right]_{0}^{\infty} = \frac{1}{\sigma} (0 - (-1)) = \frac{1}{\sigma} = \frac{T}{\Theta_r}$$

となる．
これは古典的な回転分配関数の値に対応している．

#### (ii) 微分係数の計算

次に， $f(0)$ およびその微分係数を求める．

$$f(x) = (2x + 1) \exp\left[ -\sigma (x^2 + x) \right]$$

**$f(0)$ の計算：**

$x=0$ を代入すると：

$$f(0) = (2 \cdot 0 + 1) \exp(0) = 1$$

**$f'(x)$ および $f'(0)$ の計算：**

積の微分公式を用いる． $u = 2x + 1$ ， $v = \exp\left[ -\sigma (x^2 + x) \right]$ とおくと，

$$v' = \exp\left[ -\sigma (x^2 + x) \right] \cdot (-\sigma(2x + 1))$$

$$f'(x) = u'v + uv' = 2 \exp\left[ -\sigma (x^2 + x) \right] + (2x + 1) \left[ -\sigma(2x + 1) \exp\left[ -\sigma (x^2 + x) \right] \right]$$

$$f'(x) = \{ 2 - \sigma(2x + 1)^2 \} \exp\left[ -\sigma (x^2 + x) \right]$$

$x=0$ を代入すると：

$$f'(0) = \{ 2 - \sigma(2 \cdot 0 + 1)^2 \} \exp(0) = 2 - \sigma$$

**$f''(x)$ および $f''(0)$ の計算：**

$f'(x)$ をさらに微分する． $u = 2 - \sigma(2x+1)^2$ ， $v = \exp[-\sigma(x^2+x)]$ とおくと，

$$f''(x) = u'v + uv' = \{-4\sigma(2x+1)\} e^{-\sigma(x^2+x)} + \{2 - \sigma(2x+1)^2\} \{-\sigma(2x+1)\} e^{-\sigma(x^2+x)}$$

$$f''(x) = \{-4\sigma(2x+1) - \sigma(2x+1)[2 - \sigma(2x+1)^2]\} e^{-\sigma(x^2+x)}$$

$$f''(x) = \{(2x+1)[-4\sigma - 2\sigma + \sigma^2(2x+1)]\} e^{-\sigma(x^2+x)}$$

$$f''(x) = \{(2x+1)[-6\sigma + \sigma^2(2x+1)]\} e^{-\sigma(x^2+x)}$$

$x=0$ を代入すると：

$$f''(0) = (1)[-6\sigma + \sigma^2] = -6\sigma + \sigma^2$$

**$f'''(0)$ の計算：**

Leibniz の公式を用いて $f'''(0)$ を求める．
$f(x) = g(x)h(x)$ とおく． $g(x) = 2x+1$ ， $h(x) = \exp[-\sigma(x^2+x)]$ である．

$$f'''(0) = \sum_{k=0}^{3} \binom{3}{k} g^{(k)}(0) h^{(3-k)}(0)$$

$g^{(k)}(x)$ の値は， $g'(x)=2$ ， $g''(x)=g'''(x)=0$ より：
$g(0)=1$ ， $g'(0)=2$ ， $g''(0)=0$ ， $g'''(0)=0$

$h^{(n)}(0)$ を求める． $h(x) = e^{u(x)}$ ， $u(x) = -\sigma(x^2+x)$ であるから，

$$h'(x) = u'h, \quad h''(x) = (u'' + (u')^2)h, \quad h'''(x) = (u''' + 3u'u'' + (u')^3)h$$

$u' = -\sigma(2x+1)$ ， $u'' = -2\sigma$ ， $u''' = 0$ より， $x=0$ で：
$u'(0) = -\sigma$ ， $u''(0) = -2\sigma$ ， $u'''(0) = 0$ ， $h(0) = 1$

$$h'(0) = -\sigma$$
$$h''(0) = (-2\sigma + \sigma^2)$$
$$h'''(0) = (0 + 3(-\sigma)(-2\sigma) + (-\sigma)^3) = 6\sigma^2 - \sigma^3$$

したがって，

$$f'''(0) = g(0)h'''(0) + 3g'(0)h''(0) + 3g''(0)h'(0) + g'''(0)h(0)$$

$$= 1 \cdot (6\sigma^2 - \sigma^3) + 3 \cdot 2 \cdot (-2\sigma + \sigma^2) + 0 + 0$$

$$= 6\sigma^2 - \sigma^3 - 12\sigma + 6\sigma^2 = -12\sigma + 12\sigma^2 - \sigma^3$$

#### (iii) Euler-Maclaurin 展開の構成

各項を公式に代入する．

**積分項：**
$$\int_{0}^{\infty} f(x) \, dx = \frac{1}{\sigma}$$

**$f(0)$ の項：**
$$\frac{1}{2} f(0) = \frac{1}{2}$$

**$f'(0)$ の項：**
$$-\frac{1}{12} f'(0) = -\frac{1}{12}(2 - \sigma) = -\frac{1}{6} + \frac{\sigma}{12}$$

**$f'''(0)$ の項：**
$$\frac{1}{720} f'''(0) = \frac{1}{720}(-12\sigma + 12\sigma^2 - \sigma^3) = -\frac{\sigma}{60} + \frac{\sigma^2}{60} - \frac{\sigma^3}{720}$$

これらをすべて足し合わせる：

$$r(T) = \frac{1}{\sigma} + \frac{1}{2} + \left(-\frac{1}{6} + \frac{\sigma}{12}\right) + \left(-\frac{\sigma}{60} + \frac{\sigma^2}{60} - \frac{\sigma^3}{720}\right) + \cdots$$

定数項を整理：
$$\frac{1}{2} - \frac{1}{6} = \frac{3 - 1}{6} = \frac{1}{3}$$

$\sigma$ の係数を整理：
$$\frac{1}{12} - \frac{1}{60} = \frac{5 - 1}{60} = \frac{4}{60} = \frac{1}{15}$$

$\sigma^2$ の係数：

$$\frac{1}{60}$$ （これは高次项からの寄与を含むため，後に補正される）

以上より， $r(T)$ を $\sigma$ のべき乗で展開すると：

$$r(T) = \frac{1}{\sigma} + \frac{1}{3} + \frac{1}{15}\sigma + \frac{4}{315}\sigma^2 + O(\sigma^3) \quad \cdots (1)$$

これが **Molholland の展開式** である．

次に，(1) を $1/\sigma = T/\Theta_r$ でくくると：

$$r(T) = \frac{T}{\Theta_r} \left[ 1 + \frac{1}{3}\sigma + \frac{1}{15}\sigma^2 + \frac{4}{315}\sigma^3 + O(\sigma^4) \right] \quad \cdots (2)$$

**括弧内係数の導出の確認：**
(2) の右辺を展開すると：

$$\frac{T}{\Theta_r} \left[ 1 + \frac{1}{3}\sigma + \frac{1}{15}\sigma^2 + \frac{4}{315}\sigma^3 + \cdots \right] = \frac{1}{\sigma} + \frac{1}{3} + \frac{1}{15}\sigma + \frac{4}{315}\sigma^2 + \cdots$$

これは (1) と完全に一致する．したがって，括弧内の係数は (1) の各係数と同一である：
$a_1 = 1/3$ （定数項の係数）， $a_2 = 1/15$ （$\sigma$ の係数）， $a_3 = 4/315$ （$\sigma^2$ の係数）．

### 3. HCl 分子への適用

HCl 分子の値 $\Theta_r = 15.02\,\text{K}$ および $T = 300.4\,\text{K}$ を用いる．
$\sigma$ の値は：

$$\sigma = \frac{\Theta_r}{T} = \frac{15.02}{300.4} \approx 0.0500$$

（解答例では $\sigma = 1/20 = 0.05$ と簡略化されている）

#### (a) 古典的な値

古典近似（ $\sigma \to 0$ の極限）では：

$$r_{\text{class}} = \frac{T}{\Theta_r} = \frac{300.4}{15.02} = 20$$

#### (b) Molholland 展開による近似

展开式 (1) を用いて数値計算を行う． $\sigma \approx 0.05$ として：

**第 1 項まで（古典近似）：**

$$r \approx 20$$

**定数項まで（第 2 項まで）：**

$$r \approx 20 + \frac{1}{3} = 20.3333\cdots$$

**$\sigma$ の項まで（第 3 項まで）：**

$$r \approx 20 + \frac{1}{3} + \frac{1}{15} \cdot 0.05 = 20.3333\cdots + 0.0033\cdots = 20.3367\cdots$$

**$\sigma^2$ の項まで（第 4 項まで）：**

$$r \approx 20.3367\cdots + \frac{4}{315} \cdot (0.05)^2 = 20.3367\cdots + 0.000032\cdots = 20.3367\cdots$$

括弧内形式（式(2)）による確認： $\sigma = 0.05$ として：

$$r(T) = 20 \left[ 1 + \frac{1}{3}(0.05) + \frac{1}{15}(0.05)^2 + \frac{4}{315}(0.05)^3 + \cdots \right]$$

$$= 20 \left[ 1 + 0.016667 + 0.000167 + 0.000001\cdots \right] = 20 \times 1.016834\cdots = 20.3367\cdots$$

#### (c) 比較

| 近似の階 | $r$ の値 | $r_{\text{class}}$ との差異 |
|----------|----------|---------------------------|
| 古典近似（第 1 項） | $20$ | — |
| 定数項まで（第 2 項） | $20.333\cdots$ | $+0.333$ |
| $\sigma$ の項まで（第 3 項） | $20.3367\cdots$ | $+0.337$ |
| $\sigma^2$ の項まで（第 4 項） | $20.3367\cdots$ | $+0.337$ |

古典近似から約 $1.7\%$ の補正がかかる．高温でも量子効果が無視できないことを示している．

## 解説

### 1. 回転分配関数と古典近似

量子力学的な回転エネルギー準位を考えるとき，エネルギーは離散的な値をとる．
しかし，温度 $T$ が回転温度 $\Theta_r$ に比べて十分に高い場合，準位の間隔が相対的に小さくなり，和 $\sum$ を積分 $\int$ で置き換えることができる．
これが「古典近似」である．
本問題では，単なる積分だけでなく，Euler-Maclaurin の公式を用いることで，量子的な補正項（ $\Theta_r/T$ のべき級数）を精密に求めている．

### 2. Euler-Maclaurin の公式の役割

離散的な和を連続的な積分で近似すると，誤差が生じる．
Euler-Maclaurin の公式は，その誤差を微分の値を用いて修正するための強力な道具である．
本問では， $f'(0)$ の項の符号が $-1/12$ であり（Bernoulli 数 $B_2 = 1/6$ に由来），この符号が正しい展開係数を得るために重要である．

### 3. Molholland 展開の物理的意味

得られた展開式：

$$r(T) = \frac{T}{\Theta_r} + \frac{1}{3} + \frac{1}{15}\frac{\Theta_r}{T} + \frac{4}{315}\left(\frac{\Theta_r}{T}\right)^2 + \cdots$$

の第 1 項 $T/\Theta_r$ は古典的な回転分配関数であり，第 2 項以降は量子効果による補正項である．
すべての補正項が正の値となることは，回転準位の離散性が分配関数を増大させる方向に働くことを意味する．
HCl 分子の場合，室温（ $300\,\text{K}$ ）では $\Theta_r/T \approx 0.05$ であり，補正は約 $1.7\%$ 程度であるが，より低温ではこの補正が大きくなる．
