# 演習問題【7-C-22】

## 解答

クラスター積分 $b_l$ の定義に基づき， $b_3$ を計算する．

クラスター積分 $b_l$ は， $l$ 個の分子の間に可能なすべての結合 ( $f_{ij}$ ) の組み合わせについての積分の和として定義される．
$l=3$ の場合，3 個の分子 1, 2, 3 の間の結合の組み合わせ（グラフ）は，以下の 2 種類に分類される．

1. **結合が 2 本のタイプ (A)**:
   3 つの分子が一本の道のように結ばれている状態．
   結び方の組み合わせは， $(1-2, 1-3)$ , $(2-1, 2-3)$ , $(3-1, 3-2)$ の 3 通りである．
   それぞれの結合項は $f_{12}f_{13}$ , $f_{21}f_{23}$ , $f_{31}f_{32}$ と表される．

2. **結合が 3 本のタイプ (B)**:
   3 つの分子が互いにすべて結ばれている（三角形の）状態．
   結び方は $f_{12}f_{23}f_{31}$ の 1 通りである．

したがって， $b_3$ は次のように書き表される．

$$b_3 = \frac{1}{3!V} \iiint (f_{12}f_{13} + f_{21}f_{23} + f_{31}f_{32} + f_{12}f_{23}f_{31}) \, d\mathbf{r}_1 \, d\mathbf{r}_2 \, d\mathbf{r}_3$$

ここで，各項の積分を計算する．

まず，タイプ (A) の項のひとつである $f_{12}f_{13}$ の積分を考える．

$$I_A = \frac{1}{V} \iiint f_{12}f_{13} \, d\mathbf{r}_1 \, d\mathbf{r}_2 \, d\mathbf{r}_3$$

$f_{ij}$ は粒子 $i$ と $j$ の相対距離のみに依存するため， $\mathbf{r}_2$ と $\mathbf{r}_3$ についての積分を先に実行する．

$$I_A = \frac{1}{V} \int d\mathbf{r}_1 \left( \int f_{12} \, d\mathbf{r}_2 \right) \left( \int f_{13} \, d\mathbf{r}_3 \right)$$

既約クラスター積分 $\beta_1$ の定義 $`\beta_1 = \frac{1}{V} \iint f_{12} \, d\mathbf{r}_1 \, d\mathbf{r}_2`$ より， $`\int f_{12} \, d\mathbf{r}_2`$ は $\mathbf{r}_1$ に依存しない一定の値 $C$ を与える．
このとき， $\beta_1 = \frac{1}{V} \int C \, d\mathbf{r}_1 = C$ となる．

したがって，

$$I_A = \frac{1}{V} \int C^2 \, d\mathbf{r}_1 = \frac{1}{V} \cdot V \cdot C^2 = C^2 = \beta_1^2$$

となる．
タイプ (A) の 3 つの項はすべて同様に $\beta_1^2$ となる．

次に，タイプ (B) の項 $f_{12}f_{23}f_{31}$ の積分を考える．

$$I_B = \frac{1}{V} \iiint f_{12}f_{23}f_{31} \, d\mathbf{r}_1 \, d\mathbf{r}_2 \, d\mathbf{r}_3$$

問題文で与えられた既約クラスター積分 $\beta_2$ の定義 $\beta_2 = \frac{1}{2V} \iiint f_{12}f_{23}f_{31} \, d\mathbf{r}_1 \, d\mathbf{r}_2 \, d\mathbf{r}_3$ を用いると，

$$I_B = 2\beta_2$$

となる．

これらを $b_3$ の式に代入すると，

$$b_3 = \frac{1}{6} (3 \cdot \beta_1^2 + 2\beta_2) = \frac{1}{2}\beta_1^2 + \frac{1}{3}\beta_2$$

となり，題意は示された．

## 解説

この問題は，クラスター積分がどのように既約クラスター積分 $\beta_k$ によって構成されているかを問うものである．

クラスター積分 $b_l$ は， $l$ 個の粒子間の相互作用（結合）のあらゆる組み合わせを考慮するが，その中には「ある結合を切ると系が二つに分かれる」ような，計算を分解可能なもの（還元可能）が含まれている．
還元可能なグラフの積分は，それぞれの部分（サブクラスター）の積分の積として計算できるため，これらを個別に計算した $\beta_k$ を用いることで， $b_l$ を簡潔な和の形で記述できる．

今回の $l=3$ のケースでは，
- 2本の結合を持つグラフは，2つの $\beta_1$ （1粒子間の相互作用）の積として分解できる．
- 3本の結合を持つグラフは，1つの $\beta_2$ （3粒子が互いに関連し合う既約な状態）として扱われる．

このように，複雑な多体系の統計的性質を，より単純な「既約な」要素の組み合わせとして理解できることが，クラスター展開の重要な側面である．
