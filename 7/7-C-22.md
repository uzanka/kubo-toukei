# 演習問題【7-C-22】

## 解答

3個の分子 $1,2,3$ を含むクラスター積分 $b_3$ を求め，既約クラスター積分 $\beta_1,\beta_2$ を用いて

```math
\boxed{
b_3=\frac12\beta_1^2+\frac13\beta_2
}
```

と表されることを示す．

### 1．3粒子の結合図形による分類

分子 $i,j$ の間の相互作用を表す Mayer 関数を

```math
f_{ij}=e^{-u_{ij}/kT}-1
```

とする．
ここで， $u_{ij}$ は分子 $i,j$ 間のポテンシャルエネルギー， $k$ は Boltzmann 定数， $T$ は絶対温度である．
分子間ポテンシャルが距離のみに依存する場合， $f_{ij}=f_{ji}$ である．

クラスター積分 $b_3$ は，3個の分子すべてがつながった結合図形に対応する積分の和である．
3個の分子が互いに連結する結合の仕方は，次の2種類に分類できる．

**（A）結合が2本の経路型**

3個の分子のうち1個を中心として，残りの2個がそれぞれ結ばれる型である．
中心となる分子の選び方に応じて，次の3通りがある．

```math
f_{12}f_{13},\qquad
f_{21}f_{23},\qquad
f_{31}f_{32}
```

**（B）結合が3本の三角形型**

3個の分子が互いにすべて結ばれる型であり，対応する項は

```math
f_{12}f_{23}f_{31}
```

の1通りである．

したがって，クラスター積分の定義より，

```math
\begin{aligned}
b_3=\frac{1}{3!V}\iiint
\bigl(
&f_{12}f_{13}
+f_{21}f_{23}
+f_{31}f_{32}\\
&+f_{12}f_{23}f_{31}
\bigr)
\,d\mathbf r_1\,d\mathbf r_2\,d\mathbf r_3
\end{aligned}
\tag{1}
```

と書ける．
ここで， $V$ は系の体積であり， $\mathbf r_i$ は分子 $i$ の位置ベクトルである．

### 2．経路型の結合に対応する積分

まず，結合が2本の経路型のうち， $f_{12}f_{13}$ に対応する積分を考える．

```math
I_A=\frac1V\iiint
f_{12}f_{13}\,
d\mathbf r_1\,d\mathbf r_2\,d\mathbf r_3
```

とおく．
$f_{12}$ は分子1と2の相対位置にのみ依存し， $f_{13}$ は分子1と3の相対位置にのみ依存する．
そのため， $\mathbf r_1$ を固定すると， $\mathbf r_2$ と $\mathbf r_3$ に関する積分を独立に実行できる．
よって，

```math
\begin{aligned}
I_A
=\frac1V\int d\mathbf r_1
\left(\int f_{12}\,d\mathbf r_2\right)
\left(\int f_{13}\,d\mathbf r_3\right)
\end{aligned}
\tag{2}
```

となる．

ここで，問題文で与えられた既約クラスター積分

```math
\beta_1=\frac1V\iint
f_{12}\,d\mathbf r_1\,d\mathbf r_2
\tag{3}
```

を用いる．
分子間ポテンシャルは相対位置のみに依存するため，一様な系で境界の影響を無視すると，

```math
\int f_{12}\,d\mathbf r_2
```

は $\mathbf r_1$ に依存しない一定値となる．
これを $C$ とおけば，式 (3) より

```math
\beta_1=\frac1V\int C\,d\mathbf r_1=C
```

である．
同様に，

```math
\int f_{13}\,d\mathbf r_3=\beta_1
```

である．
したがって，式 (2) は

```math
\begin{aligned}
I_A
&=\frac1V\int \beta_1^2\,d\mathbf r_1\\
&=\frac1V V\beta_1^2\\
&=\beta_1^2
\end{aligned}
```

となる．

ほかの2つの経路型の項も，分子の同等性により同じ積分値を与える．
よって，3つの経路型の寄与の合計は

```math
\boxed{
3\beta_1^2
}
\tag{4}
```

である．

### 3．三角形型の結合に対応する積分

次に，結合が3本ある三角形型の積分を

```math
I_B=\frac1V\iiint
f_{12}f_{23}f_{31}\,
d\mathbf r_1\,d\mathbf r_2\,d\mathbf r_3
```

とおく．
問題文で与えられた既約クラスター積分の定義

```math
\boxed{
\beta_2=\frac1{2V}\iiint
f_{12}f_{23}f_{31}\,
d\mathbf r_1\,d\mathbf r_2\,d\mathbf r_3
}
\tag{5}
```

と比較すると，

```math
\boxed{
I_B=2\beta_2
}
\tag{6}
```

である．

### 4．$b_3$ の導出

式 (1) において，3つの経路型の積分の合計は $3\beta_1^2$ ，三角形型の積分は $2\beta_2$ である．
これらを代入すると，

```math
\begin{aligned}
b_3
&=\frac1{3!}\left(3\beta_1^2+2\beta_2\right)\\
&=\frac16\left(3\beta_1^2+2\beta_2\right)
\end{aligned}
```

となる．
よって，

```math
\boxed{
b_3=\frac12\beta_1^2+\frac13\beta_2
}
```

が得られ，題意が示された．

### 補足

この結果は，クラスター積分 $b_3$ が，既約クラスター積分 $\beta_1,\beta_2$ の組合せによって表されることを示している．
経路型の図形では，分子2と3に関する積分が独立に分離できるため，積分値が $\beta_1^2$ となる．
一方，三角形型では3つの分子が互いに結ばれているため，同じように分解することはできず，その寄与は既約クラスター積分 $\beta_2$ で表される．
