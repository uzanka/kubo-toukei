# 演習問題【7-A-8】

## 解答

アンモニア分子 $\mathrm{NH_3}$ は非直線分子であり，理想気体とみなせる．
したがって，定積モル比熱 $\bar C_V$ は，並進運動，回転運動，振動運動の各寄与の和として求められる．
本問では，並進運動と回転運動には古典近似を用い，振動運動には量子力学的な調和振動子の式を用いる．

### 1．並進運動と回転運動の寄与

#### 1.1　並進運動

分子の重心の並進運動は， $x,y,z$ の3方向の自由度をもつ．
各方向の運動エネルギーは運動量の二次形式であるため，エネルギー等分配則により，1自由度あたりの平均エネルギーは $k_{\mathrm B}T/2$ である．
したがって，1分子あたりの並進エネルギーは

```math
U_{\mathrm{trans}}=\frac32 k_{\mathrm B}T
```

であり，1 mol あたりでは

```math
\bar C_{V,\mathrm{trans}}=\frac32R
\tag{1}
```

となる．
ここで， $R$ は気体定数である．

#### 1.2　回転運動

$\mathrm{NH_3}$ は非直線分子であるため，回転運動には3つの独立な自由度がある．
回転準位が十分に密である高温領域では，回転運動を古典的に扱うことができ，各回転自由度の平均エネルギーは $k_{\mathrm B}T/2$ となる．
このとき，1 mol あたりの回転エネルギーは

```math
U_{\mathrm{rot}}=\frac32RT
```

であり，回転運動による定積モル比熱は

```math
\bar C_{V,\mathrm{rot}}=\frac32R
\tag{2}
```

である．

この古典近似が妥当であることを，回転温度から確認する．
主慣性モーメント $A,B,C$ に対応する回転温度は，それぞれ

```math
\Theta_A=\frac{h^2}{8\pi^2 A k_{\mathrm B}},
\qquad
\Theta_B=\frac{h^2}{8\pi^2 B k_{\mathrm B}},
\qquad
\Theta_C=\frac{h^2}{8\pi^2 C k_{\mathrm B}}
```

である．
問題の慣性モーメントを代入すると，

```math
\Theta_A\simeq9.1\,\mathrm K,
\qquad
\Theta_B=\Theta_C\simeq14.3\,\mathrm K
```

となる．
これらは $T=300\,\mathrm K$ より十分に小さいため，回転運動には古典近似を用いてよい．

よって，並進運動と回転運動の合計は

```math
\boxed{
\bar C_{V,\mathrm{trans+rot}}
=\frac32R+\frac32R=3R
}
\tag{3}
```

である．

### 2．振動運動の寄与

振動運動では，振動エネルギー準位の間隔が熱エネルギー $k_{\mathrm B}T$ と同程度以上になる場合があるため，量子力学的な取り扱いが必要である．

#### 2.1　振動比熱の公式

基準振動数が波数 $\tilde\nu_i$ で表される振動モード $i$ のエネルギー準位は，

```math
E_n=\left(n+\frac12\right)hc\tilde\nu_i,
\qquad n=0,1,2,\ldots
```

である．
ここで， $h$ は Planck 定数， $c$ は光速度である．

調和振動子の平均エネルギーは，

```math
\langle E_i\rangle
=\frac12hc\tilde\nu_i
+\frac{hc\tilde\nu_i}
{e^{hc\tilde\nu_i/(k_{\mathrm B}T)}-1}
```

となる．
第一項は零点エネルギーであり，温度に依存しないため，比熱には寄与しない．
よって，1 mol あたりの振動内部エネルギーは，振動モードの縮重度を $g_i$ として，

```math
U_{\mathrm{vib},i}
=g_iR\frac{hc\tilde\nu_i/k_{\mathrm B}}
{e^{hc\tilde\nu_i/(k_{\mathrm B}T)}-1}
```

と表せる．
ここで無次元量

```math
\theta_i=\frac{hc\tilde\nu_i}{k_{\mathrm B}T}
\tag{4}
```

を導入すると，

```math
U_{\mathrm{vib},i}
=g_iR\frac{hc\tilde\nu_i/k_{\mathrm B}}
{e^{\theta_i}-1}
```

である．
これを温度 $T$ で微分すると，振動比熱の寄与は

```math
\boxed{
\bar C_{V,\mathrm{vib},i}
=Rg_i\frac{\theta_i^2e^{\theta_i}}
{(e^{\theta_i}-1)^2}
}
\tag{5}
```

となる．
したがって，すべての振動モードを足し合わせれば，

```math
\boxed{
\bar C_{V,\mathrm{vib}}
=R\sum_i g_i
\frac{\theta_i^2e^{\theta_i}}
{(e^{\theta_i}-1)^2}
}
\tag{6}
```

である．

波数 $\tilde\nu_i$ の単位が $\mathrm{cm}^{-1}$ であることに注意すると，

```math
\frac{hc}{k_{\mathrm B}}
\simeq1.4387\,\mathrm{cm\,K}
```

を用いて，

```math
\theta_i=1.4387\frac{\tilde\nu_i}{T}
\tag{7}
```

と計算できる．

#### 2.2　各振動モードの計算

温度を $T=300\,\mathrm K$ とすると，問題で与えられた各振動モードについて，

```math
\begin{aligned}
\theta_1&=1.4387\frac{3337}{300}
\simeq16.00,\\
\theta_2&=1.4387\frac{950}{300}
\simeq4.56,\\
\theta_3&=1.4387\frac{3444}{300}
\simeq16.52,\\
\theta_4&=1.4387\frac{1627}{300}
\simeq7.80
\end{aligned}
```

となる．
縮重度は，

```math
g_1=g_2=1,\qquad g_3=g_4=2
```

である．

まず， $\theta_1$ と $\theta_3$ は大きい．
$\theta_i\gg1$ のとき，

```math
\frac{e^{\theta_i}}{(e^{\theta_i}-1)^2}
\simeq e^{-\theta_i}
```

であるから，

```math
\begin{aligned}
g_1\frac{\theta_1^2e^{\theta_1}}
{(e^{\theta_1}-1)^2}
&\simeq(16.00)^2e^{-16.00}
\simeq2.9\times10^{-5},\\
g_3\frac{\theta_3^2e^{\theta_3}}
{(e^{\theta_3}-1)^2}
&\simeq2(16.52)^2e^{-16.52}
\simeq3.7\times10^{-5}
\end{aligned}
```

となり，いずれも非常に小さい．

一方， $\theta_2$ の寄与は，

```math
\begin{aligned}
g_2\frac{\theta_2^2e^{\theta_2}}
{(e^{\theta_2}-1)^2}
&\simeq(4.56)^2
\frac{e^{4.56}}{(e^{4.56}-1)^2}\\
&\simeq0.222
\end{aligned}
```

である．

同様に，2重縮重した $\theta_4$ の寄与は，

```math
\begin{aligned}
g_4\frac{\theta_4^2e^{\theta_4}}
{(e^{\theta_4}-1)^2}
&\simeq2(7.80)^2
\frac{e^{7.80}}{(e^{7.80}-1)^2}\\
&\simeq0.0498
\end{aligned}
```

である．
以上を合計すると，

```math
\begin{aligned}
\sum_i g_i\frac{\theta_i^2e^{\theta_i}}
{(e^{\theta_i}-1)^2}
&\simeq0.000029+0.222+0.000037+0.0498\\
&\simeq0.272
\end{aligned}
```

となる．
したがって，振動運動による定積モル比熱は，

```math
\boxed{
\bar C_{V,\mathrm{vib}}\simeq0.272R
}
\tag{8}
```

である．

### 3．全モル比熱

全定積モル比熱は，並進運動，回転運動，振動運動の各寄与の和である．
式 (3)，(8) より，

```math
\begin{aligned}
\bar C_V
&=\bar C_{V,\mathrm{trans+rot}}
+\bar C_{V,\mathrm{vib}}\\
&\simeq3R+0.272R\\
&\simeq3.272R
\end{aligned}
```

を得る．
よって，

```math
\boxed{
\bar C_V\simeq3.27R
\simeq27.2\,\mathrm{J\,mol^{-1}K^{-1}}
}
```

である．
これが $300\,\mathrm K$ における $\mathrm{NH_3}$ 気体の定積モル比熱である．
