# 演習問題【7-A-3】

## 解答

2原子分子の回転運動について，古典統計力学を用いて回転分配関数 $r(T)$ を求め，さらにエントロピー $S_{\mathrm{rot}}$ および定積比熱 $C_{V,\mathrm{rot}}$ を導出する．
回転運動のエネルギーは問題文より，

```math
\epsilon_{\mathrm{rot}}
=\frac{p_\theta^2}{2I}
+\frac{p_\varphi^2}{2I\sin^2\theta}
```

で与えられる．
ここで， $I$ は分子の慣性モーメント， $\theta,\varphi$ は回転方向を表す角度， $p_\theta,p_\varphi$ はそれぞれに共役な正準運動量である．

### 1．回転分配関数の定義

古典統計力学では，分配関数は位相空間全体にわたって Boltzmann 因子 $e^{-\epsilon_{\mathrm{rot}}/(kT)}$ を積分することで求められる．
位相空間とは，座標とそれに共役な運動量を組み合わせた空間である．
一般化座標が2つあるため，積分の規格化因子は $1/h^2$ となる．
ここで， $h=2\pi\hbar$ は Planck 定数， $k$ は Boltzmann 定数， $T$ は絶対温度である．

したがって，回転運動の分配関数は

```math
\begin{aligned}
r(T)=\frac{1}{h^2}
&\int_0^\pi d\theta
\int_0^{2\pi}d\varphi
\int_{-\infty}^{\infty}dp_\theta
\int_{-\infty}^{\infty}dp_\varphi\\
&\times
\exp\left[
-\frac{1}{kT}\left(
\frac{p_\theta^2}{2I}
+\frac{p_\varphi^2}{2I\sin^2\theta}
\right)
\right]
\end{aligned}
\tag{1}
```

である．
この積分を角度と運動量について順に実行する．

### 2．分配関数の計算

#### 2.1　角度 $\varphi$ の積分

被積分関数は $\varphi$ に依存しないため，

```math
\int_0^{2\pi}d\varphi=2\pi
\tag{2}
```

である．

#### 2.2　運動量 $p_\theta,p_\varphi$ の積分

運動量に関する積分には，Gaussian 積分の公式

```math
\int_{-\infty}^{\infty}e^{-ax^2}\,dx
=\sqrt{\frac{\pi}{a}}
\qquad(a>0)
\tag{3}
```

を用いる．

まず， $p_\theta$ に関する積分は，

```math
\begin{aligned}
\int_{-\infty}^{\infty}
e^{-p_\theta^2/(2IkT)}\,dp_\theta
&=\sqrt{\frac{\pi}{1/(2IkT)}}\\
&=\sqrt{2\pi IkT}
\end{aligned}
\tag{4}
```

となる．

次に， $p_\varphi$ に関する積分を考える．
この運動量の二次項には $1/\sin^2\theta$ が含まれているので，積分結果は $\theta$ に依存する．
式 (3) を用いると，

```math
\begin{aligned}
&\int_{-\infty}^{\infty}
e^{-p_\varphi^2/(2IkT\sin^2\theta)}\,dp_\varphi\\
&\qquad=\sqrt{\frac{\pi}{1/(2IkT\sin^2\theta)}}\\
&\qquad=\sqrt{2\pi IkT}\sin\theta
\end{aligned}
\tag{5}
```

を得る．
ここでは積分範囲が $0\leq\theta\leq\pi$ であるため， $\sin\theta\geq0$ を用いた．

式 (2)，(4)，(5) をまとめると，運動量の積分と $\varphi$ の積分を実行した結果は，

```math
(2\pi)\sqrt{2\pi IkT}
\sqrt{2\pi IkT}\sin\theta
=4\pi^2IkT\sin\theta
```

となる．

#### 2.3　角度 $\theta$ の積分

これを式 (1) に代入すると，

```math
\begin{aligned}
r(T)
&=\frac{1}{h^2}
\int_0^\pi4\pi^2IkT\sin\theta\,d\theta\\
&=\frac{4\pi^2IkT}{h^2}
\left[-\cos\theta\right]_0^\pi\\
&=\frac{4\pi^2IkT}{h^2}\times2\\
&=\frac{8\pi^2IkT}{h^2}
\end{aligned}
```

である．
ここで $h=2\pi\hbar$ より，

```math
h^2=4\pi^2\hbar^2
```

であるから，

```math
\boxed{
r(T)=\frac{2IkT}{\hbar^2}
}
\tag{6}
```

を得る．
これが求める古典的な回転分配関数である．

### 3．エントロピーの計算

回転運動に対応する Helmholtz 自由エネルギーは，分配関数を用いて

```math
F_{\mathrm{rot}}=-kT\log r(T)
```

と表される．
式 (6) を代入すると，

```math
F_{\mathrm{rot}}
=-kT\log\left(\frac{2IkT}{\hbar^2}\right)
\tag{7}
```

となる．

エントロピーは，Helmholtz 自由エネルギーの温度微分から

```math
S_{\mathrm{rot}}
=-\left(\frac{\partial F_{\mathrm{rot}}}{\partial T}\right)_V
```

で与えられる．
慣性モーメント $I$ が温度に依存しないとすると，

```math
\begin{aligned}
S_{\mathrm{rot}}
&=\frac{\partial}{\partial T}
\left[
kT\log\left(\frac{2IkT}{\hbar^2}\right)
\right]\\
&=k\log\left(\frac{2IkT}{\hbar^2}\right)
+kT\frac{\partial}{\partial T}
\log\left(\frac{2IkT}{\hbar^2}\right)
\end{aligned}
```

である．
対数の中では $I,k,\hbar$ は定数であるため，

```math
\frac{\partial}{\partial T}
\log\left(\frac{2IkT}{\hbar^2}\right)
=\frac1T
```

となる．
したがって，

```math
\boxed{
S_{\mathrm{rot}}
=k\left[
1+\log\left(\frac{2IkT}{\hbar^2}\right)
\right]
}
\tag{8}
```

を得る．
これは分子1個あたりの回転運動によるエントロピーである．

### 4．定積比熱の計算

定積比熱は，エントロピーを温度で微分することで，

```math
C_{V,\mathrm{rot}}
=T\left(\frac{\partial S_{\mathrm{rot}}}{\partial T}\right)_V
```

と表される．
式 (8) を代入すると，

```math
\begin{aligned}
C_{V,\mathrm{rot}}
&=T\frac{\partial}{\partial T}
\left[
k+k\log\left(\frac{2IkT}{\hbar^2}\right)
\right]\\
&=T\frac{k}{T}\\
&=k
\end{aligned}
```

となる．
よって，

```math
\boxed{
C_{V,\mathrm{rot}}=k
}
\tag{9}
```

である．

これは古典的なエネルギー等分配則とも整合する．
運動エネルギーには $p_\theta$ と $p_\varphi$ という2つの二次形式が含まれており，それぞれの平均エネルギーは $kT/2$ である．
したがって，平均回転エネルギーは $kT$ となり，温度に関する微分から比熱 $k$ が得られる．

### 5．古典近似の適用範囲

回転温度を

```math
\Theta_r=\frac{\hbar^2}{2Ik}
```

と定義すると，式 (6) は

```math
r(T)=\frac{T}{\Theta_r}
```

と書ける．
古典近似は，回転エネルギー準位の量子化の影響が小さい高温領域，すなわち

```math
T\gg\Theta_r
```

で有効である．
逆に， $T$ が $\Theta_r4 より十分に小さい場合，古典式は量子的な回転状態を正しく記述できない．

以上より，回転分配関数，エントロピー，比熱はそれぞれ

```math
\boxed{
\begin{aligned}
r(T)&=\frac{2IkT}{\hbar^2},\\[4pt]
S_{\mathrm{rot}}
&=k\left[1+\log\left(\frac{2IkT}{\hbar^2}\right)\right],\\
C_{V,\mathrm{rot}}&=k
\end{aligned}
}
```

である．
これらは分子1個についての古典近似の結果である．
