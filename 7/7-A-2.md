# 演習問題【7-A-2】

## 解答

ヘリウム原子が温度 $T=6000\ \mathrm{K}$ の熱平衡状態にあるとする．
基底状態 ${}^1\mathrm{S}_0$ と第一励起状態 ${}^3\mathrm{S}_1$ のエネルギー差および縮重度を用いて，第一励起状態にある原子の割合を求める．

### 1．Boltzmann 分布による励起状態の存在確率

温度 $T$ で熱平衡にある原子について，エネルギーが $\epsilon_l$ の状態 $l$ にある確率は，Boltzmann 分布によって

```math
P(l)=\frac{g_l e^{-\epsilon_l/(k_{\mathrm B}T)}}{Z}
\tag{1}
```

と表される．
ここで， $g_l$ はその状態の縮重度， $k_{\mathrm B}$ は Boltzmann 定数， $Z$ は内部自由度の分配関数である．
分配関数は，考慮するすべての状態の Boltzmann 因子を縮重度で重み付けして足し合わせたものであり，

```math
Z=\sum_l g_l e^{-\epsilon_l/(k_{\mathrm B}T)}
```

である．
分配関数で割ることにより，各状態の存在確率の合計が $1$ となる．

本問題では，基底状態 ${}^1\mathrm{S}_0$ のエネルギーを基準として $\epsilon_0=0$ とする．
その縮重度は $g_0=1$ である．
第一励起状態 ${}^3\mathrm{S}_1$ のエネルギーを $\Delta E$ ，縮重度を $g_1=3$ とする．
他の電子状態の寄与を無視すると，分配関数は

```math
\begin{aligned}
Z
&\simeq g_0 e^{-\epsilon_0/(k_{\mathrm B}T)}
+g_1 e^{-\Delta E/(k_{\mathrm B}T)}\\
&=1+3e^{-\Delta E/(k_{\mathrm B}T)}
\end{aligned}
\tag{2}
```

となる．
したがって，第一励起状態 ${}^3\mathrm{S}_1$ にある原子の割合は，

```math
\boxed{
P({}^3\mathrm{S}_1)
\simeq
\frac{3e^{-\Delta E/(k_{\mathrm B}T)}}
{1+3e^{-\Delta E/(k_{\mathrm B}T)}}
}
\tag{3}
```

である．

### 2．エネルギー差と Boltzmann 因子の計算

問題で与えられたエネルギー差は $159843\ \mathrm{cm}^{-1}$ である．
これは分光学で用いる波数 $\tilde{\nu}$ で表した値であり，エネルギー差は

```math
\Delta E=hc\tilde{\nu}
```

によって求められる．
ここで， $h$ は Planck 定数， $c$ は光速度である．

したがって，Boltzmann 因子の指数は

```math
\frac{\Delta E}{k_{\mathrm B}T}
=\frac{hc\tilde{\nu}}{k_{\mathrm B}T}
=\frac{hc}{k_{\mathrm B}}\frac{\tilde{\nu}}{T}
```

となる．
定数

```math
\frac{hc}{k_{\mathrm B}}
\simeq 1.43878\ \mathrm{cm\,K}
```

を用いると，

```math
\begin{aligned}
\frac{\Delta E}{k_{\mathrm B}T}
&=\frac{
(1.43878\ \mathrm{cm\,K})
(159843\ \mathrm{cm}^{-1})
}{6000\ \mathrm{K}}\\
&\simeq \frac{229978\ \mathrm{K}}{6000\ \mathrm{K}}\\
&\simeq 38.33
\end{aligned}
```

を得る．
よって，

```math
e^{-\Delta E/(k_{\mathrm B}T)}
=e^{-38.33}
\simeq 2.26\times10^{-17}
\tag{4}
```

である．

この値は極めて小さいため，

```math
3e^{-\Delta E/(k_{\mathrm B}T)}
\simeq 6.77\times10^{-17}\ll1
```

となる．
したがって，式 (3) の分母は $1+3e^{-\Delta E/(k_{\mathrm B}T)}\simeq1$ と近似できる．
以上より，

```math
\begin{aligned}
P({}^3\mathrm{S}_1)
&\simeq 3e^{-\Delta E/(k_{\mathrm B}T)}\\
&\simeq 3(2.26\times10^{-17})\\
&\simeq 6.8\times10^{-17}
\end{aligned}
```

となる．

### 結論

$6000\ \mathrm{K}$ において，第一励起状態 ${}^3\mathrm{S}_1$ にあるヘリウム原子の割合は，二つの電子状態のみを考慮する近似のもとで，

```math
\boxed{
P({}^3\mathrm{S}_1)\simeq 6.8\times10^{-17}
}
```

である．
これは $10^{17}$ 個程度の原子があっても，単純な熱平衡の見積もりでは励起状態の原子がほとんど存在しないほど小さい割合である．
