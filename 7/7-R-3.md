# 例題【7-R-3】

## 解答

**解離反応**

```math
\mathrm{AB}\rightleftharpoons\mathrm A+\mathrm B
```

が熱平衡にあるとき，分子1個あたりの分配関数を用いて，質量作用の法則

```math
\frac{n_{\mathrm{AB}}}{n_{\mathrm A}n_{\mathrm B}}=K(T)
```

を導く．
さらに，平衡定数 $K(T)$ を分子の質量，内部自由度の分配関数，および基底状態のエネルギー差で表す．
ここでは，分子間相互作用を無視できる理想気体を考え，温度 $T$ と容積 $V$ を一定とする．

### 1．分配関数と平衡条件

容器中の $\mathrm A$ ， $\mathrm B$ ， $\mathrm{AB}$ の分子数を，それぞれ $N_{\mathrm A}$ ， $N_{\mathrm B}$ ， $N_{\mathrm{AB}}$ とする．
各分子種の基底状態のエネルギーを $\epsilon_\alpha^0$ とし，基底状態のエネルギーを除いた1分子分配関数を $f_\alpha$ とする．
ここで， $\alpha=\mathrm A,\mathrm B,\mathrm{AB}$ である．

基底状態のエネルギーも含めた1分子分配関数 $q_\alpha$ は，

```math
q_\alpha=f_\alpha
\exp\left(-\frac{\epsilon_\alpha^0}{kT}\right)
\tag{1}
```

と書ける．
ここで， $k$ は Boltzmann 定数である．

各分子種について分子が互いに区別できないことを考慮すると，分子数の組合せに対する統計的重み $\mathcal W$ は，

```math
\mathcal W=
\frac{q_{\mathrm A}^{N_{\mathrm A}}
q_{\mathrm B}^{N_{\mathrm B}}
q_{\mathrm{AB}}^{N_{\mathrm{AB}}}}
{N_{\mathrm A}!\,N_{\mathrm B}!\,N_{\mathrm{AB}}!}
\tag{2}
```

である．
これは，その分子数の組合せが実現する確率に比例する量である．
したがって，熱平衡では，原子数保存の条件を満たしながら $\mathcal W$ が最大となる分子数の組合せを求めればよい．

この反応では，A原子とB原子の総数がそれぞれ保存される．
すなわち，

```math
N_{\mathrm A}+N_{\mathrm{AB}}
=N_{\mathrm A}^{\mathrm{tot}}=\mathrm{const.}
\tag{3}
```

```math
N_{\mathrm B}+N_{\mathrm{AB}}
=N_{\mathrm B}^{\mathrm{tot}}=\mathrm{const.}
\tag{4}
```

である．
ここで， $N_{\mathrm A}^{\mathrm{tot}}$ と $N_{\mathrm B}^{\mathrm{tot}}$ は，それぞれA原子とB原子の総数である．

分子数が十分に大きい場合，Stirling の公式

```math
\ln N!\simeq N\ln N-N
```

を用いて，式 (2) の対数を

```math
\ln\mathcal W\simeq
\sum_{\alpha=\mathrm A,\mathrm B,\mathrm{AB}}
\left[
N_\alpha\ln\left(\frac{q_\alpha}{N_\alpha}\right)
+N_\alpha
\right]
\tag{5}
```

と近似できる．
これを変分すると，

```math
\delta\ln\mathcal W
=\sum_{\alpha=\mathrm A,\mathrm B,\mathrm{AB}}
\ln\left(\frac{q_\alpha}{N_\alpha}\right)
\delta N_\alpha
\tag{6}
```

となる．

式 (3)，(4) を変分すると，

```math
\delta N_{\mathrm A}=-\delta N_{\mathrm{AB}},
\qquad
\delta N_{\mathrm B}=-\delta N_{\mathrm{AB}}
\tag{7}
```

である．
すなわち，解離反応が進んで $\mathrm{AB}$ が1分子減少すると， $\mathrm A$ と $\mathrm B$ がそれぞれ1分子増加する．

式 (7) を式 (6) に代入すると，

```math
\begin{aligned}
\delta\ln\mathcal W
=\biggl[
&\ln\left(\frac{q_{\mathrm{AB}}}{N_{\mathrm{AB}}}\right)
-\ln\left(\frac{q_{\mathrm A}}{N_{\mathrm A}}\right)\\
&-\ln\left(\frac{q_{\mathrm B}}{N_{\mathrm B}}\right)
\biggr]\delta N_{\mathrm{AB}}
\end{aligned}
\tag{8}
```

を得る．
平衡状態では，保存条件を満たす任意の微小変化に対して $\delta\ln\mathcal W=0$ でなければならない．
したがって，式 (8) の角括弧内はゼロである．
これを整理すると，

```math
\ln\left(\frac{q_{\mathrm{AB}}}{N_{\mathrm{AB}}}\right)
=
\ln\left(\frac{q_{\mathrm A}}{N_{\mathrm A}}\right)
+
\ln\left(\frac{q_{\mathrm B}}{N_{\mathrm B}}\right)
```

となる．
両辺の指数を取ることで，

```math
\boxed{
\frac{N_{\mathrm{AB}}}{N_{\mathrm A}N_{\mathrm B}}
=\frac{q_{\mathrm{AB}}}{q_{\mathrm A}q_{\mathrm B}}
}
\tag{9}
```

が得られる．
これが分配関数で表した熱平衡条件である．

### 2．分子数を濃度に変換する

各分子の濃度，すなわち単位体積あたりの分子数を

```math
n_\alpha=\frac{N_\alpha}{V}
\tag{10}
```

と定義する．
すると，

```math
\begin{aligned}
\frac{n_{\mathrm{AB}}}{n_{\mathrm A}n_{\mathrm B}}
&=\frac{N_{\mathrm{AB}}/V}
{(N_{\mathrm A}/V)(N_{\mathrm B}/V)}\\
&=V\frac{N_{\mathrm{AB}}}
{N_{\mathrm A}N_{\mathrm B}}
\end{aligned}
```

である．
式 (9) を代入すれば，

```math
\boxed{
\frac{n_{\mathrm{AB}}}{n_{\mathrm A}n_{\mathrm B}}
=V\frac{q_{\mathrm{AB}}}{q_{\mathrm A}q_{\mathrm B}}
}
\tag{11}
```

を得る．

ここで，式 (1) により，

```math
\begin{aligned}
\frac{q_{\mathrm{AB}}}{q_{\mathrm A}q_{\mathrm B}}
&=
\frac{f_{\mathrm{AB}}}{f_{\mathrm A}f_{\mathrm B}}
\exp\left[
-\frac{\epsilon_{\mathrm{AB}}^0}{kT}
+\frac{\epsilon_{\mathrm A}^0}{kT}
+\frac{\epsilon_{\mathrm B}^0}{kT}
\right]
\end{aligned}
```

となる．
問題文で定義された

```math
w_0=\epsilon_{\mathrm A}^0+\epsilon_{\mathrm B}^0
-\epsilon_{\mathrm{AB}}^0
\tag{12}
```

を使うと，

```math
\frac{q_{\mathrm{AB}}}{q_{\mathrm A}q_{\mathrm B}}
=\frac{f_{\mathrm{AB}}}{f_{\mathrm A}f_{\mathrm B}}
e^{w_0/(kT)}
```

である．
したがって，式 (11) より，

```math
\boxed{
\frac{n_{\mathrm{AB}}}{n_{\mathrm A}n_{\mathrm B}}
=K(T)
=V\frac{f_{\mathrm{AB}}}{f_{\mathrm A}f_{\mathrm B}}
e^{w_0/(kT)}
}
\tag{13}
```

を得る．
これで，質量作用の法則が分配関数から導かれた．

### 3．分配関数を質量と内部自由度で表す

最後に，式 (13) に含まれる各分配関数を具体的に表す．
分子 $\alpha$ の質量を $m_\alpha$ ，内部自由度の分配関数を $j_\alpha^0$ とする．
理想気体における1分子の並進分配関数は，

```math
f_{\mathrm{trans},\alpha}
=V\left(\frac{2\pi m_\alpha kT}{h^2}\right)^{3/2}
```

である．
並進運動と内部自由度の分配関数は積に分解できるため，基底状態のエネルギーを除いた1分子分配関数は，

```math
\boxed{
f_\alpha
=V\left(\frac{2\pi m_\alpha kT}{h^2}\right)^{3/2}
j_\alpha^0
}
\tag{14}
```

となる．

式 (14) を式 (13) に代入すると，

```math
\begin{aligned}
K(T)
={}&V
\frac{
V\left(\dfrac{2\pi m_{\mathrm{AB}}kT}{h^2}\right)^{3/2}
j_{\mathrm{AB}}^0
}{
\left[
V\left(\dfrac{2\pi m_{\mathrm A}kT}{h^2}\right)^{3/2}
j_{\mathrm A}^0
\right]
\left[
V\left(\dfrac{2\pi m_{\mathrm B}kT}{h^2}\right)^{3/2}
j_{\mathrm B}^0
\right]
}
e^{w_0/(kT)}
\end{aligned}
```

である．
外側の $V$ と，それぞれの分配関数に含まれる体積因子を整理すると，体積は相殺される．
したがって，

```math
\begin{aligned}
K(T)
={}&
\frac{
\left(\dfrac{2\pi m_{\mathrm{AB}}kT}{h^2}\right)^{3/2}
}{
\left(\dfrac{2\pi m_{\mathrm A}kT}{h^2}\right)^{3/2}
\left(\dfrac{2\pi m_{\mathrm B}kT}{h^2}\right)^{3/2}
}\\
&\times
\frac{j_{\mathrm{AB}}^0}{j_{\mathrm A}^0j_{\mathrm B}^0}
e^{w_0/(kT)}
\end{aligned}
\tag{15}
```

となる．
解離反応では，

```math
m_{\mathrm{AB}}=m_{\mathrm A}+m_{\mathrm B}
\tag{16}
```

である．
並進分配関数の比を整理すると，

```math
\begin{aligned}
&\frac{
\left(\dfrac{2\pi m_{\mathrm{AB}}kT}{h^2}\right)^{3/2}
}{
\left(\dfrac{2\pi m_{\mathrm A}kT}{h^2}\right)^{3/2}
\left(\dfrac{2\pi m_{\mathrm B}kT}{h^2}\right)^{3/2}
}\\
&\quad=
\left[
\frac{m_{\mathrm{AB}}h^2}
{2\pi m_{\mathrm A}m_{\mathrm B}kT}
\right]^{3/2}\\
&\quad=
\left[
\frac{(m_{\mathrm A}+m_{\mathrm B})h^2}
{2\pi m_{\mathrm A}m_{\mathrm B}kT}
\right]^{3/2}
\end{aligned}
\tag{17}
```

となる．
式 (17) を式 (15) に代入すれば，

```math
\boxed{
K(T)=
\left[
\frac{(m_{\mathrm A}+m_{\mathrm B})h^2}
{2\pi m_{\mathrm A}m_{\mathrm B}kT}
\right]^{3/2}
\frac{j_{\mathrm{AB}}^0}{j_{\mathrm A}^0j_{\mathrm B}^0}
e^{w_0/(kT)}
}
\tag{18}
```

を得る．

### 結論

以上より，熱平衡状態では，

```math
\boxed{
\frac{n_{\mathrm{AB}}}{n_{\mathrm A}n_{\mathrm B}}
=K(T)
=V\frac{f_{\mathrm{AB}}}{f_{\mathrm A}f_{\mathrm B}}
e^{w_0/(kT)}
}
```

および，

```math
\boxed{
K(T)=
\left[
\frac{(m_{\mathrm A}+m_{\mathrm B})h^2}
{2\pi m_{\mathrm A}m_{\mathrm B}kT}
\right]^{3/2}
\frac{j_{\mathrm{AB}}^0}{j_{\mathrm A}^0j_{\mathrm B}^0}
e^{w_0/(kT)}
}
```

が成立する．
これにより，分配関数を用いて質量作用の法則が導かれ，問題文の式が示された．

なお，濃度 $n_\alpha$ は単位体積あたりの分子数であるため， $n_{\mathrm{AB}}/(n_{\mathrm A}n_{\mathrm B})$ の次元は体積である．
式 (18) の質量因子も体積の次元をもつので，次元の上でも整合している．
