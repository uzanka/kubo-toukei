# 例題【7-R-3】

## 解答

解離反応

```math
\mathrm{AB}\rightleftharpoons \mathrm A+\mathrm B
```

が熱平衡にあるとき，分子1個当たりの分配関数を用いて，質量作用の法則

```math
\frac{n_{\mathrm{AB}}}{n_{\mathrm A}n_{\mathrm B}}
=K(T)
```

を導く．
さらに， $K(T)$ を各分子の質量，内部自由度の分配関数，および基底状態のエネルギー差を用いて表す．

以下では，分子間相互作用を無視できる希薄な理想気体を考え，温度 $T$ と容積 $V$ は一定とする．
また， $k$ は Boltzmann 定数， $h$ はプランク定数である．

### 1．分子数と分配関数

容器中の $\mathrm A$ ， $\mathrm B$ ， $\mathrm{AB}$ の分子数を，それぞれ $N_{\mathrm A}$ ， $N_{\mathrm B}$ ， $N_{\mathrm{AB}}$ とする．

各分子の基底状態のエネルギーを $\epsilon_{\alpha}^{0}$ とし，そのエネルギーを除いた1分子分配関数を $f_\alpha$ とする．
ここで $\alpha=\mathrm A,\mathrm B,\mathrm{AB}$ である．
したがって，基底状態のエネルギーも含めた1分子分配関数 $q_\alpha$ は，

```math
q_\alpha=f_\alpha
\exp\left(-\frac{\epsilon_\alpha^0}{kT}\right)
\tag{1}
```

と書ける．

分子が互いに区別できないことを考慮すると，分子数の組合せ $(N_{\mathrm A},N_{\mathrm B},N_{\mathrm{AB}})$ に対応する統計的重み $\mathcal W$ は，

```math
\mathcal W=
\frac{q_{\mathrm A}^{N_{\mathrm A}}
q_{\mathrm B}^{N_{\mathrm B}}
q_{\mathrm{AB}}^{N_{\mathrm{AB}}}}
{N_{\mathrm A}!\,N_{\mathrm B}!\,N_{\mathrm{AB}}!}
\tag{2}
```

と表される．
ここでは，この重みが，原子総数を固定したときの各分子数の組合せの相対的な出現確率を与える．
したがって，熱平衡では，この統計的重みが最大となる分子数の組合せを求めればよい．

### 2．熱平衡条件の導出

反応

```math
\mathrm{AB}\rightleftharpoons\mathrm A+\mathrm B
```

では，A原子とB原子の総数はそれぞれ保存される．
よって，

```math
N_{\mathrm A}+N_{\mathrm{AB}}
=N_{\mathrm A}^{\mathrm{tot}}=\mathrm{const.}
\tag{3}
```

```math
N_{\mathrm B}+N_{\mathrm{AB}}
=N_{\mathrm B}^{\mathrm{tot}}=\mathrm{const.}
\tag{4}
```

となる．
ここで， $N_{\mathrm A}^{\mathrm{tot}}$ と $N_{\mathrm B}^{\mathrm{tot}}$ は，それぞれA原子とB原子の総数である．

熱平衡では，これらの拘束条件を保ちながら $\mathcal W$ が最大になる．
そこで， $\ln\mathcal W$ を考える．
式（2）より，

```math
\begin{aligned}
\ln\mathcal W
={}&N_{\mathrm A}\ln q_{\mathrm A}
+N_{\mathrm B}\ln q_{\mathrm B}
+N_{\mathrm{AB}}\ln q_{\mathrm{AB}}\\
&-\ln N_{\mathrm A}!
-\ln N_{\mathrm B}!
-\ln N_{\mathrm{AB}}!
\end{aligned}
\tag{5}
```

である．
分子数が十分大きいとき，Stirling の近似

```math
\ln N!\simeq N\ln N-N
```

を用いることができる．
これにより，

```math
\ln\mathcal W\simeq
\sum_{\alpha=\mathrm A,\mathrm B,\mathrm{AB}}
\left\{
N_\alpha\ln\frac{q_\alpha}{N_\alpha}
+N_\alpha
\right\}
\tag{6}
```

となる．

式（3），（4）の拘束条件を微小変化させると，

```math
\delta N_{\mathrm A}+\delta N_{\mathrm{AB}}=0,
\qquad
\delta N_{\mathrm B}+\delta N_{\mathrm{AB}}=0
```

である．
したがって，

```math
\delta N_{\mathrm A}
=-\delta N_{\mathrm{AB}},
\qquad
\delta N_{\mathrm B}
=-\delta N_{\mathrm{AB}}
\tag{7}
```

を得る．

式（6）を変分すると，

```math
\delta\ln\mathcal W
=\sum_{\alpha}
\ln\frac{q_\alpha}{N_\alpha}\,\delta N_\alpha
```

となる．
式（7）を代入すると，

```math
\begin{aligned}
\delta\ln\mathcal W
=\biggl\{
&\ln\frac{q_{\mathrm{AB}}}{N_{\mathrm{AB}}}
-\ln\frac{q_{\mathrm A}}{N_{\mathrm A}}\\
&-\ln\frac{q_{\mathrm B}}{N_{\mathrm B}}
\biggr\}\delta N_{\mathrm{AB}}
\end{aligned}
\tag{8}
```

を得る．
平衡状態では，許された微小変化に対して $\delta\ln\mathcal W=0$ でなければならない．
したがって，式（8）の波括弧内がゼロとなり，

```math
\ln\frac{q_{\mathrm{AB}}}{N_{\mathrm{AB}}}
=\ln\frac{q_{\mathrm A}}{N_{\mathrm A}}
+\ln\frac{q_{\mathrm B}}{N_{\mathrm B}}
```

となる．
指数関数を取って整理すると，

```math
\frac{q_{\mathrm{AB}}}{N_{\mathrm{AB}}}
=\frac{q_{\mathrm A}q_{\mathrm B}}
{N_{\mathrm A}N_{\mathrm B}}
```

すなわち，

```math
\boxed{
\frac{N_{\mathrm{AB}}}{N_{\mathrm A}N_{\mathrm B}}
=\frac{q_{\mathrm{AB}}}{q_{\mathrm A}q_{\mathrm B}}
}
\tag{9}
```

が得られる．
これが分配関数を用いて表した熱平衡条件である．

### 3．分子数を濃度に変換する

各分子の濃度は，単位体積当たりの分子数として，

```math
n_\alpha=\frac{N_\alpha}{V}
\tag{10}
```

と定義される．
したがって，

```math
\begin{aligned}
\frac{n_{\mathrm{AB}}}{n_{\mathrm A}n_{\mathrm B}}
&=\frac{N_{\mathrm{AB}}/V}
{(N_{\mathrm A}/V)(N_{\mathrm B}/V)}\\
&=V\frac{N_{\mathrm{AB}}}
{N_{\mathrm A}N_{\mathrm B}}
\end{aligned}
```

となる．
式（9）を代入すると，

```math
\frac{n_{\mathrm{AB}}}{n_{\mathrm A}n_{\mathrm B}}
=V\frac{q_{\mathrm{AB}}}{q_{\mathrm A}q_{\mathrm B}}
\tag{11}
```

を得る．

ここで，式（1）を使うと，

```math
\begin{aligned}
\frac{q_{\mathrm{AB}}}{q_{\mathrm A}q_{\mathrm B}}
&=\frac{f_{\mathrm{AB}}}{f_{\mathrm A}f_{\mathrm B}}
\exp\left(
\frac{\epsilon_{\mathrm A}^{0}
+\epsilon_{\mathrm B}^{0}
-\epsilon_{\mathrm{AB}}^{0}}{kT}
\right)
\end{aligned}
```

となる．
問題文で定義された

```math
w_0=\epsilon_{\mathrm A}^{0}
+\epsilon_{\mathrm B}^{0}
-\epsilon_{\mathrm{AB}}^{0}
\tag{12}
```

を用いれば，

```math
\frac{q_{\mathrm{AB}}}{q_{\mathrm A}q_{\mathrm B}}
=\frac{f_{\mathrm{AB}}}{f_{\mathrm A}f_{\mathrm B}}
e^{w_0/kT}
```

である．
これを式（11）に代入すると，

```math
\boxed{
\frac{n_{\mathrm{AB}}}{n_{\mathrm A}n_{\mathrm B}}
=V\frac{f_{\mathrm{AB}}}{f_{\mathrm A}f_{\mathrm B}}
e^{w_0/kT}
}
\tag{13}
```

を得る．
ここで，右辺は温度だけで決まるため，これを平衡定数 $K(T)$ と定義する．

### 4．分配関数の具体的な形

最後に， $K(T)$ を各分子の質量と内部自由度の分配関数で表す．

分子 $\alpha$ の質量を $m_\alpha$ ，内部自由度の分配関数を $j_\alpha^0$ とする．
理想気体の1分子の並進運動の分配関数は，

```math
f_{\mathrm{trans},\alpha}
=V\left(\frac{2\pi m_\alpha kT}{h^2}\right)^{3/2}
```

である．
並進運動と内部自由度は独立に扱えるため，基底状態のエネルギーを除いた1分子分配関数は，

```math
\boxed{
f_\alpha
=V\left(\frac{2\pi m_\alpha kT}{h^2}\right)^{3/2}
j_\alpha^0
}
\tag{14}
```

となる．

式（14）を式（13）に代入すると，

```math
\begin{aligned}
K(T)
={}&V
\frac{
V\left(\dfrac{2\pi m_{\mathrm{AB}}kT}{h^2}\right)^{3/2}
j_{\mathrm{AB}}^0
}{
\left[
V\left(\dfrac{2\pi m_{\mathrm A}kT}{h^2}\right)^{3/2}
j_{\mathrm A}^0
\right]
\left[
V\left(\dfrac{2\pi m_{\mathrm B}kT}{h^2}\right)^{3/2}
j_{\mathrm B}^0
\right]
}
e^{w_0/kT}
\end{aligned}
```

となる．
分子と分母に含まれる容積 $V$ は相殺されるので，

```math
\begin{aligned}
K(T)
={}&
\frac{
\left(\dfrac{2\pi m_{\mathrm{AB}}kT}{h^2}\right)^{3/2}
}{
\left(\dfrac{2\pi m_{\mathrm A}kT}{h^2}\right)^{3/2}
\left(\dfrac{2\pi m_{\mathrm B}kT}{h^2}\right)^{3/2}
}
\frac{j_{\mathrm{AB}}^0}{j_{\mathrm A}^0j_{\mathrm B}^0}
e^{w_0/kT}
\end{aligned}
\tag{15}
```

を得る．

解離反応では，質量の関係

```math
m_{\mathrm{AB}}=m_{\mathrm A}+m_{\mathrm B}
\tag{16}
```

が成り立つ．
また，並進運動の分配関数の比を整理すると，

```math
\begin{aligned}
&\frac{
\left(\dfrac{2\pi m_{\mathrm{AB}}kT}{h^2}\right)^{3/2}
}{
\left(\dfrac{2\pi m_{\mathrm A}kT}{h^2}\right)^{3/2}
\left(\dfrac{2\pi m_{\mathrm B}kT}{h^2}\right)^{3/2}
}\\
&\qquad=
\left[
\frac{m_{\mathrm{AB}}h^2}
{2\pi m_{\mathrm A}m_{\mathrm B}kT}
\right]^{3/2}\\
&\qquad=
\left[
\frac{(m_{\mathrm A}+m_{\mathrm B})h^2}
{2\pi m_{\mathrm A}m_{\mathrm B}kT}
\right]^{3/2}
\end{aligned}
\tag{17}
```

となる．
式（17）を式（15）に代入すれば，

```math
\boxed{
K(T)=
\left[
\frac{(m_{\mathrm A}+m_{\mathrm B})h^2}
{2\pi m_{\mathrm A}m_{\mathrm B}kT}
\right]^{3/2}
\frac{j_{\mathrm{AB}}^0}{j_{\mathrm A}^0j_{\mathrm B}^0}
e^{w_0/kT}
}
\tag{18}
```

が得られる．

### 結論

以上より，熱平衡状態では，

```math
\boxed{
\frac{n_{\mathrm{AB}}}{n_{\mathrm A}n_{\mathrm B}}
=K(T)
=\frac{Vf_{\mathrm{AB}}}{f_{\mathrm A}f_{\mathrm B}}
e^{w_0/kT}
}
```

かつ，

```math
\boxed{
K(T)=
\left[
\frac{(m_{\mathrm A}+m_{\mathrm B})h^2}
{2\pi m_{\mathrm A}m_{\mathrm B}kT}
\right]^{3/2}
\frac{j_{\mathrm{AB}}^0}{j_{\mathrm A}^0j_{\mathrm B}^0}
e^{w_0/kT}
}
```

が成立する．
これにより，分配関数から質量作用の法則が導かれ，問題文の式が示された．

なお， $K(T)$ の単位は体積である．
実際，濃度 $n_\alpha$ は単位体積当たりの分子数なので， $n_{\mathrm{AB}}/(n_{\mathrm A}n_{\mathrm B})$ の単位も体積となり，式の次元は整合している．
