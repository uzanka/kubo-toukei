# 演習問題【7-A-5】

## 解答

異核 2 原子分子の回転分配関数 $r(T)$ の高温展開の式を以下のように用いる．

```math
r(T) \approx \frac{1}{\sigma} \left\{ 1 + \frac{\sigma}{3} + \frac{\sigma^2}{15} + \frac{4\sigma^3}{315} + O(\sigma^4) \right\} \quad \left( \sigma = \frac{\Theta_r}{T} \right)
```

ここで， $\Theta_r$ は回転温度である．

まず，回転自由エネルギー $F_{\text{rot}}$ を求める．

```math
\frac{F_{\text{rot}}}{N} = -kT \log r(T) = -kT \log \left[ \frac{1}{\sigma} \left\{ 1 + \frac{\sigma}{3} + \frac{\sigma^2}{15} + \frac{4\sigma^3}{315} + O(\sigma^4) \right\} \right]
```

```math
= kT \log \sigma - kT \log \left\{ 1 + \frac{\sigma}{3} + \frac{\sigma^2}{15} + \frac{4\sigma^3}{315} + O(\sigma^4) \right\}
```

$\log(1+x) \approx x - \frac{x^2}{2} + \dots$ の展開を用いると，

```math
\log \left\{ 1 + \frac{\sigma}{3} + \frac{\sigma^2}{15} + \dots \right\} \approx \left( \frac{\sigma}{3} + \frac{\sigma^2}{15} \right) - \frac{1}{2} \left( \frac{\sigma}{3} \right)^2 + \dots = \frac{\sigma}{3} + \left( \frac{1}{15} - \frac{1}{18} \right) \sigma^2 + \dots = \frac{\sigma}{3} + \frac{1}{90} \sigma^2 + \dots
```

これを用いると，自由エネルギーの式は次のように書ける．

```math
\frac{F_{\text{rot}}}{N} = kT \log \sigma - kT \left( \frac{\sigma}{3} + \frac{\sigma^2}{90} + \dots \right) = kT \log \sigma - \frac{k\Theta_r}{3} \left\{ 1 + \frac{\sigma}{30} + \dots \right\} \quad \cdots (1)
```

次に，内部エネルギー $U_{\text{rot}}$ を求める．

$$ \frac{U_{\text{rot}}}{N} = -T^2 \frac{\partial}{\partial T} \left( \frac{F_{\text{rot}}}{NT} \right) $$

ここで， $\frac{F_{\text{rot}}}{NT} = k \log \sigma - \frac{k\Theta_r}{3T} (1 + \frac{\sigma}{30} + \dots)$ である．
$\sigma = \Theta_r/T$ より， $\frac{\partial \sigma}{\partial T} = -\frac{\Theta_r}{T^2} = -\frac{\sigma}{T}$ である．
したがって，

$$ \frac{\partial}{\partial T} (k \log \sigma) = \frac{k}{\sigma} \left( -\frac{\sigma}{T} \right) = -\frac{k}{T} $$

$$ \frac{\partial}{\partial T} \left( \frac{k\Theta_r}{3T} \right) = -\frac{k\Theta_r}{3T^2} $$

$$ \frac{\partial}{\partial T} \left( \frac{k\Theta_r}{3T} \cdot \frac{\sigma}{30} \right) = \frac{\partial}{\partial T} \left( \frac{k\Theta_r^2}{90T^2} \right) = -\frac{2k\Theta_r^2}{90T^3} $$

これらをまとめると，

$$ \frac{\partial}{\partial T} \left( \frac{F_{\text{rot}}}{NT} \right) = -\frac{k}{T} + \frac{k\Theta_r}{3T^2} + \frac{2k\Theta_r^2}{90T^3} + \dots $$

よって，

$$ \frac{U_{\text{rot}}}{N} = -T^2 \left( -\frac{k}{T} + \frac{k\Theta_r}{3T^2} + \frac{k\Theta_r^2}{45T^3} + \dots \right) = kT - \frac{k\Theta_r}{3} - \frac{k\Theta_r^2}{45T} + \dots $$

これを整理して，

```math
\frac{U_{\text{rot}}}{N} = kT - \frac{k\Theta_r}{3} \left\{ 1 + \frac{1}{15} \frac{\Theta_r}{T} + \dots \right\} \quad \cdots (2)
```

最後に，回転比熱 $C_{\text{rot}}$ を求める．

```math
\frac{C_{\text{rot}}}{N} = \frac{\partial}{\partial T} \left( \frac{U_{\text{rot}}}{N} \right) = k + \frac{k\Theta_r^2}{45T^2} + \dots = k \left\{ 1 + \frac{1}{45} \left( \frac{\Theta_r}{T} \right)^2 + \dots \right\} \quad \cdots (3)
```

式(3)より，高温限界 ( $T \to \infty$ ) において，比熱は $C_{\text{rot}}/N \to k$ となる．
このとき，式(3)の第2項 $\frac{1}{45}(\Theta_r/T)^2$ は正であるため，比熱は $k$ に対して上方から近づく．
一方，低温限界 ( $T \to 0$ ) では，回転運動が凍結されるため，比熱は $C_{\text{rot}} \to 0$ となる．
$T=0$ から出発して， $T \to \infty$ で $k$ に上方から近づく連続関数であるから，その曲線は少なくとも一つの極大をもたなければならない．

## 解説

この問題の核心は，高温展開の結果から比熱の「振る舞い」を読み取ることにある．

### 1. 高温での振る舞い

古典統計力学によれば，回転自由度は $2$ （ $\theta$ と $\phi$ 方向の運動）であり，エネルギー等配分の法則から，回転の内部エネルギーは $kT$ となり，比熱は $k$ となる．
しかし，実際には回転エネルギー準位は離散的であるため，高温であっても量子力学的な補正項が現れる．
展開式(3)における $\frac{1}{45}(\Theta_r/T)^2$ という項は，この補正を表しており，比熱が古典的な値 $k$ よりもわずかに高い値から減少していくことを示している．

### 2. 低温での振る舞い

温度が回転温度 $\Theta_r$ よりも十分に低くなると，エネルギー準位の飛び越しが困難になり，回転運動が「凍結」される．
このとき，回転によるエネルギーの吸収がほとんどできなくなるため，比熱は $0$ に近づく．

### 3. 極大の存在

比熱の曲線は， $T=0$ で $0$ から始まり， $T \to \infty$ で $k$ に収束する．
ところが，高温側からの収束の仕方が「上方から（ $k$ より大きい値から）」であるため，途中で必ず $k$ よりも高い値をとる領域が存在することになる．
したがって，曲線は必ず山のような形，すなわち極大値をもたなければならないのである．
