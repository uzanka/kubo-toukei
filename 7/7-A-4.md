# 演習問題【7-A-4】

## 解答

主慣性モーメント $A,B,C$ をもつ回転体について，問題文のハミルトニアンから古典的な回転分配関数 $r(T)$ を求める．
Euler の角を $\theta,\phi,\psi$ ，それぞれに共役な正準運動量を $p_\theta,p_\phi,p_\psi$ とする．

### 1．回転分配関数とハミルトニアンの平方完成

古典統計力学では，分配関数は位相空間全体で Boltzmann 因子 $e^{-\mathcal H/(kT)}$ を積分することで与えられる．
回転の一般化座標は3つであるため，

```math
\begin{aligned}
r(T)=\frac{1}{h^3}
&\int_0^\pi d\theta
\int_0^{2\pi}d\phi
\int_0^{2\pi}d\psi\\
&\times\int_{-\infty}^{\infty}dp_\theta
\int_{-\infty}^{\infty}dp_\phi
\int_{-\infty}^{\infty}dp_\psi
\,e^{-\mathcal H/(kT)}
\end{aligned}
\tag{1}
```

である．
ここで， $h=2\pi\hbar$ は Planck 定数， $k$ は Boltzmann 定数， $T$ は絶対温度である．

問題文のハミルトニアンは，

```math
\begin{aligned}
\mathcal H={}&
\frac{1}{2A\sin^2\theta}
\left\{(p_\phi-\cos\theta\,p_\psi)\cos\psi
-\sin\theta\sin\psi\,p_\theta\right\}^2\\
&+\frac{1}{2B\sin^2\theta}
\left\{(p_\phi-\cos\theta\,p_\psi)\sin\psi
+\sin\theta\cos\psi\,p_\theta\right\}^2\\
&+\frac{p_\psi^2}{2C}
\end{aligned}
\tag{2}
```

である．
ここで，

```math
q=p_\phi-\cos\theta\,p_\psi,
\qquad
D=\frac{\sin^2\psi}{A}+\frac{\cos^2\psi}{B}
\tag{3}
```

とおく．
式 (2) を展開して $p_\theta$ に関する項をまとめると，

```math
\begin{aligned}
\mathcal H={}&
\frac{D}{2}p_\theta^2
+\frac{1}{\sin\theta}
\left(\frac1B-\frac1A\right)
\sin\psi\cos\psi\,q\,p_\theta\\
&+\frac{1}{2\sin^2\theta}
\left(\frac{\cos^2\psi}{A}
+\frac{\sin^2\psi}{B}\right)q^2
+\frac{p_\psi^2}{2C}
\end{aligned}
\tag{4}
```

となる．

運動量についての積分を実行しやすくするため， $p_\theta$ に関して平方完成する．
すると，

```math
\begin{aligned}
\mathcal H={}&
\frac{D}{2}
\left\{
p_\theta+
\frac{(1/B-1/A)\sin\psi\cos\psi}
{\sin\theta\,D}\,q
\right\}^2\\
&+\frac{q^2}{2AB\sin^2\theta\,D}
+\frac{p_\psi^2}{2C}
\end{aligned}
\tag{5}
```

を得る．
この変形では， $q^2$ の係数を整理するために，

```math
\begin{aligned}
&\frac{\cos^2\psi}{A}+\frac{\sin^2\psi}{B}
-\frac{(1/B-1/A)^2\sin^2\psi\cos^2\psi}{D}\\
&\qquad=\frac{1}{AB\,D}
\end{aligned}
```

という恒等式を用いた．

式 (5) では，第一項が $p_\theta$ の平方，第二項が $q=p_\phi-\cos\theta\,p_\psi$ の平方，第三項が $p_\psi$ の平方になっている．
この形を利用し，運動量について順に積分する．

### 2．運動量についての積分

以下では，Gaussian 積分の公式

```math
\int_{-\infty}^{\infty}e^{-ax^2/2}\,dx
=\sqrt{\frac{2\pi}{a}}
\qquad(a>0)
\tag{6}
```

を用いる．
また，積分変数を定数だけ平行移動しても，積分範囲が全実数であれば積分値は変化しない．

#### 2.1　$p_\theta$ についての積分

式 (5) の第一項に着目する．

```math
\begin{aligned}
&\int_{-\infty}^{\infty}
\exp\left[
-\frac{D}{2kT}
\left\{
p_\theta+
\frac{(1/B-1/A)\sin\psi\cos\psi}
{\sin\theta\,D}\,q
\right\}^2
\right]dp_\theta\\
&\qquad=\sqrt{\frac{2\pi kT}{D}}
\end{aligned}
```

である．
したがって， $p_\theta$ の積分から得られる因子は，

```math
\boxed{
(2\pi kT)^{1/2}
\left(\frac{\sin^2\psi}{A}+\frac{\cos^2\psi}{B}\right)^{-1/2}
}
\tag{7}
```

となる．
この積分を実行しても，残りの因子

```math
\exp\left[
-\frac{q^2}{2ABkT\sin^2\theta\,D}
-\frac{p_\psi^2}{2CkT}
\right]
```

は残る．

#### 2.2　$p_\phi$ についての積分

次に，

```math
q=p_\phi-\cos\theta\,p_\psi
```

とおいたことを利用する．
$p_\psi$ を固定すれば， $q$ は $p_\phi$ を定数だけ平行移動した変数であり， $dq=dp_\phi$ である．
したがって，

```math
\begin{aligned}
&\int_{-\infty}^{\infty}
\exp\left[
-\frac{(p_\phi-\cos\theta\,p_\psi)^2}
{2ABkT\sin^2\theta\,D}
\right]dp_\phi\\
&\qquad=
\sqrt{2\pi kT\,AB}\,\sin\theta\,\sqrt D
\end{aligned}
```

となる．
ここでは $0\leq\theta\leq\pi$ より $\sin\theta\geq0$ であることを用いた．

これと式 (7) の因子を掛け合わせると，

```math
\begin{aligned}
&\sqrt{\frac{2\pi kT}{D}}\,
\sqrt{2\pi kT\,AB}\,\sin\theta\,\sqrt D\\
&\qquad=(2\pi kT)\sqrt{AB}\,\sin\theta
\end{aligned}
\tag{8}
```

となる．
ここで $D^{-1/2}$ と $D^{1/2}$ が相殺するため，結果は $\psi$ に依存しない．

#### 2.3　$p_\psi$ についての積分

最後に残る運動量依存性は，

```math
\exp\left(-\frac{p_\psi^2}{2CkT}\right)
```

である．
したがって，

```math
\begin{aligned}
\int_{-\infty}^{\infty}
e^{-p_\psi^2/(2CkT)}\,dp_\psi
=\sqrt{2\pi CkT}
\end{aligned}
\tag{9}
```

となる．
式 (8)，(9) を合わせると，すべての運動量積分の結果は，

```math
\boxed{
(2\pi kT)^{3/2}\sqrt{ABC}\,\sin\theta
}
\tag{10}
```

である．

### 3．Euler の角についての積分

式 (10) を分配関数 (1) に代入すると，

```math
\begin{aligned}
r(T)=\frac{(2\pi kT)^{3/2}\sqrt{ABC}}{h^3}
\int_0^\pi\sin\theta\,d\theta
\int_0^{2\pi}d\phi
\int_0^{2\pi}d\psi
\end{aligned}
```

となる．
各角度の積分を実行すると，

```math
\int_0^\pi\sin\theta\,d\theta
=\left[-\cos\theta\right]_0^\pi=2
```

および

```math
\int_0^{2\pi}d\phi=2\pi,
\qquad
\int_0^{2\pi}d\psi=2\pi
```

である．
したがって，角度積分全体は

```math
2(2\pi)(2\pi)=8\pi^2
```

となる．
ゆえに，求める古典的回転分配関数は，

```math
\boxed{
r(T)=\frac{8\pi^2}{h^3}
(2\pi kT)^{3/2}\sqrt{ABC}
}
\tag{11}
```

である．

これを主慣性モーメントごとの因子に分けると，

```math
\boxed{
\begin{aligned}
r(T)
={}&\pi^{1/2}
\left(\frac{8\pi^2AkT}{h^2}\right)^{1/2}\\
&\times
\left(\frac{8\pi^2BkT}{h^2}\right)^{1/2}
\left(\frac{8\pi^2CkT}{h^2}\right)^{1/2}
\end{aligned}
}
\tag{12}
```

となり，解答例の式 (6) と一致する．
以上で，多原子分子の回転分配関数の古典的近似が導出された．
