# 演習問題【7-C-20】

## 解答

系の Helmholtz 自由エネルギーを $F(N, T, V)$ とすると， $N \gg 1$ のとき化学ポテンシャル $\mu$ は次のように書ける．

$$\mu = \left( \frac{\partial F}{\partial N} \right)_{T,V} \cong F(N+1, T, V) - F(N, T, V)$$

これより，

$$-kT \log \frac{Z(N+1, T, V)}{Z(N, T, V)} \approx F(N+1, T, V) - F(N, T, V)$$

となる．
ここで，分配関数 $Q(N, T, V)$ との関係を用いると，

$$e^{-\mu/kT} = \left( \frac{2\pi mkT}{h^2} \right)^{3/2} \frac{Q(N+1, T, V)}{Q(N, T, V)} \quad \cdots (1)$$

が得られる．

次に， $Q(N+1, T, V)$ を具体的に計算する．
$N+1$ 個の粒子のうち，粒子 $0$ を新たに加えたものと考える．
全エネルギー $U(0, 1, \dots, N)$ は，粒子 $0$ と他の粒子 $i$ との間の相互作用エネルギーの和，および粒子 $1$ から $N$ までの間のエネルギーの和として，

$$U(0, 1, \dots, N) = \sum_{i=1}^{N} u_{0i} + U(1, 2, \dots, N)$$

と書ける．
これを用いると，ボルツマン因子は次のように展開できる．

$$e^{-U(0, 1, \dots, N)/kT} = e^{-U(1, 2, \dots, N)/kT} \prod_{i=1}^{N} e^{-u_{0i}/kT} = e^{-U(1, 2, \dots, N)/kT} \prod_{i=1}^{N} (1 + f_{0i}) \quad \cdots (2)$$

ここで， $f_{0i} = e^{-u_{0i}/kT} - 1$ である．

$Q(N+1, T, V)$ の定義より，

$$Q(N+1, T, V) = \frac{1}{(N+1)!} \int \dots \int e^{-U(0, 1, \dots, N)/kT} dx_0 dy_0 dz_0 dx_1 \dots dz_N$$

(2) 式を代入すると，

$$Q(N+1, T, V) = \frac{1}{(N+1)!} \int \dots \int e^{-U(1, \dots, N)/kT} \prod_{i=1}^{N} (1 + f_{0i}) dx_0 \dots dz_N$$

積分を粒子 $0$ についての積分と，それ以外についてに分けると，

$$Q(N+1, T, V) = \frac{1}{N+1} \iiint dx_0 dy_0 dz_0 \left[ \frac{1}{N!} \int \dots \int e^{-U(1, \dots, N)/kT} \prod_{i=1}^{N} (1 + f_{0i}) dx_1 \dots dz_N \right]$$

粒子 $0$ の積分 $\iiint dx_0 dy_0 dz_0$ は体積 $V$ に等しいので，

$$Q(N+1, T, V) = \frac{V}{N+1} \frac{1}{N!} \int \dots \int e^{-U(1, \dots, N)/kT} \prod_{i=1}^{N} (1 + f_{0i}) dx_1 \dots dz_N \quad \cdots (3)$$

となる．

次に，積 $\prod_{i=1}^{N} (1 + f_{0i})$ を展開する．
この展開式には， $n$ 個の $f_{0i}$ の項が含まれる．
その項の数は， $N$ 個の中から $n$ 個を選ぶ組み合わせの数 $N!/\{(N-n)! n!\}$ に等しい．
粒子の同等性により，これらの項に対応する積分の値はすべて等しくなる．
したがって，(3) 式の積分は，

$$\int \dots \int e^{-U(1, \dots, N)/kT} \prod_{i=1}^{N} (1 + f_{0i}) dx_1 \dots dz_N = \sum_{n=0}^{N} \frac{N!}{(N-n)! n!} \int \dots \int e^{-U(1, \dots, N)/kT} \left( \prod_{i=1}^{n} f_{0i} \right) dx_1 \dots dz_N \quad \cdots (4)$$

と書ける．

ここで，特定の $n$ 個の粒子が指定された座標範囲にある確率 $P_n(x_1, \dots, z_n)$ を考える．

$$P_n(x_1, \dots, z_n) = \frac{1}{Q(N, T, V) N!} \int \dots \int e^{-U(1, \dots, N)/kT} dx_{n+1} \dots dz_N \quad \cdots (5)$$

である．
また，粒子の番号を区別しないときの確率 $v^{-n} F_n(x_1, \dots, z_n)$ は，

$$\frac{1}{v^n} F_n(x_1, \dots, z_n) = \frac{N!}{(N-n)!} P_n(x_1, \dots, z_n) \quad \cdots (6)$$

で与えられる．

(4) 式の積分内の項について，

$$\int \dots \int e^{-U(1, \dots, N)/kT} \left( \prod_{i=1}^{n} f_{0i} \right) dx_1 \dots dz_n = \int \dots \int \left( \prod_{i=1}^{n} f_{0i} \right) \left( \int \dots \int e^{-U(1, \dots, N)/kT} dx_{n+1} \dots dz_N \right) dx_1 \dots dz_n$$

(5) 式を用いると，内側の積分は $Q(N, T, V) N! P_n(x_1, \dots, z_n)$ である．
よって，

$$\int \dots \int e^{-U(1, \dots, N)/kT} \left( \prod_{i=1}^{n} f_{0i} \right) dx_1 \dots dz_n = Q(N, T, V) N! \int \dots \int P_n(x_1, \dots, z_n) \prod_{i=1}^{n} f_{0i} dx_1 \dots dz_n$$

となる．
これを (4) 式に代入すると，

$$Q(N+1, T, V) = \frac{V}{N+1} \sum_{n=0}^{N} \frac{1}{(N-n)! n!} Q(N, T, V) N! \int \dots \int P_n(x_1, \dots, z_n) \prod_{i=1}^{n} f_{0i} dx_1 \dots dz_n$$

$$\quad = \frac{V}{N+1} Q(N, T, V) \sum_{n=0}^{N} \frac{N!}{(N-n)! n!} \int \dots \int P_n(x_1, \dots, z_n) \prod_{i=1}^{n} f_{0i} dx_1 \dots dz_n$$

(6) 式より $\frac{N!}{(N-n)! n!} P_n(x_1, \dots, z_n) = \frac{1}{n! v^n} F_n(x_1, \dots, z_n)$ であるから，

$$Q(N+1, T, V) = \frac{V}{N+1} Q(N, T, V) \left[ 1 + \sum_{n=1}^{N} \frac{1}{n! v^n} \int \dots \int F_n(x_1, \dots, z_n) \prod_{i=1}^{n} f_{0i} dx_1 \dots dz_n \right]$$

（ $n=0$ の項は 1 である．）

最後に，(1) 式にこれを代入する．
$V/(N+1) \cong V/N = v$ であるから，

$$e^{-\mu/kT} = \left( \frac{2\pi mkT}{h^2} \right)^{3/2} \frac{1}{Q(N, T, V)} \cdot \frac{V}{N+1} Q(N, T, V) \left[ 1 + \sum_{n=1}^{N} \frac{1}{n! v^n} \int \dots \int F_n(x_1, \dots, z_n) \prod_{i=1}^{n} f_{0i} dx_1 \dots dz_n \right]$$

$$e^{-\mu/kT} = \left( \frac{2\pi mkT}{h^2} \right)^{3/2} v \left[ 1 + \sum_{n=1}^{N} \frac{1}{n! v^n} \int \dots \int F_n(x_1, \dots, z_n) \prod_{i=1}^{n} f_{0i} dx_1 \dots dz_n \right]$$

となり，題意は示された．

## 解説

この問題は，粒子間の相互作用を考慮したときの分配関数の変化，およびそれが化学ポテンシャルにどのように影響するかを導出するものである．

1.  **化学ポテンシャルの定義**:
  化学ポテンシャル $\mu$ は，粒子を 1 つ加えたときの自由エネルギーの変化として定義される．
  $N \gg 1$ では，微分の代わりに差分を用いることができる．
2.  **分配関数の関係**:
  分配関数 $Q$ と $\mu$ の間には，熱力学的関係式から $e^{-\mu/kT}$ が $Q(N+1)/Q(N)$ の比に関連していることがわかる．
3.  **相互作用の導入**:
  新たに加えた粒子 $0$ と，既存の $N$ 個の粒子の間の相互作用エネルギーを $u_{0i}$ とすると，系の全エネルギーは，粒子 $0$ の寄与と，それ以外の粒子間のエネルギーの和として分離できる．
  ボルツマン因子 $e^{-U/kT}$ は，この和の指数関数として，粒子 $0$ に関する項 $\prod e^{-u_{0i}/kT}$ と，既存の系の項 $e^{-U(1,\dots,N)/kT}$ の積として書ける．
4.  **展開と組み合わせ**:
  $\prod (1 + f_{0i})$ の展開は，粒子 $0$ が他の粒子と「相互作用する」粒子の数 $n$ についての和をとることに相当する．
  粒子の同等性により，どの粒子と相互作用するかに関わらず，積分値は同じになるため，組み合わせの数 $N!/\{(N-n)!n!\}$ を用いて和の形にまとめられる．
5.  **確率密度の利用**:
  特定の $n$ 個の粒子が指定された座標範囲にある確率 $P_n$ と，粒子を区別しないときの確率密度 $F_n$ の関係を用いることで，積分を $F_n$ を用いた形に書き換えることができる．

これらを組み合わせることで，相互作用がある場合の化学ポテンシャルの式が導出される．
