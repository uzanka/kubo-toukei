# 演習問題【7-C-20】

## 解答

$N\gg1$ 個の同等な古典粒子からなる系を考え，粒子間には二体相互作用のみが働くとする．
分子間ポテンシャルから定義される Mayer 関数 $f_{0i}$ を用いて，化学ポテンシャル $\mu$ に対する関係式を導く．

### 1．化学ポテンシャルと分配関数

まず，分子1個の並進運動の分配関数に現れる因子を

```math
q_{\mathrm{tr}}=
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
```

とおく．
ここで， $m$ は粒子の質量， $k$ は Boltzmann 定数， $T$ は絶対温度， $h$ は Planck 定数である．

粒子間のポテンシャルエネルギーを $U(1,\ldots,N)$ とし，配置積分を

```math
Q(N,T,V)=
\frac1{N!}
\int_V\cdots\int_V
e^{-U(1,\ldots,N)/kT}
\,d\mathbf r_1\cdots d\mathbf r_N
```

と定義する．
ここで， $\mathbf r_i=(x_i,y_i,z_i)$ は粒子 $i$ の位置ベクトルである．

運動量積分は各粒子について独立に行えるため，系全体の正準分配関数は

```math
Z(N,T,V)=q_{\mathrm{tr}}^N Q(N,T,V)
```

となる．

Helmholtz 自由エネルギーは

```math
F(N,T,V)=-kT\ln Z(N,T,V)
```

であり，化学ポテンシャルは

```math
\mu=\left(\frac{\partial F}{\partial N}\right)_{T,V}
```

と定義される．
$N\gg1$ では，粒子を1個増やしたときの自由エネルギーの変化を用いて

```math
\mu\simeq F(N+1,T,V)-F(N,T,V)
```

と近似できる．
したがって，

```math
\begin{aligned}
e^{-\mu/kT}
&\simeq \frac{Z(N+1,T,V)}{Z(N,T,V)}\\
&=q_{\mathrm{tr}}
\frac{Q(N+1,T,V)}{Q(N,T,V)}.
\end{aligned}
```

よって，

```math
\boxed{
e^{-\mu/kT}
=
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\frac{Q(N+1,T,V)}{Q(N,T,V)}
}
\tag{1}
```

を得る．
ここでは，大きな $N$ に対して有限差分を微分で近似することによる誤差を無視した．

### 2．$N+1$ 粒子系の配置積分

$N+1$ 粒子系に，新たに加えた粒子を $0$ ，元からある粒子を $1,\ldots,N$ として番号を付ける．
二体相互作用のみを仮定すると，全ポテンシャルエネルギーは

```math
U(0,1,\ldots,N)
=
U(1,\ldots,N)+\sum_{i=1}^{N}u_{0i}
```

と書ける．
ここで $u_{0i}$ は粒子 $0$ と粒子 $i$ の間のポテンシャルエネルギーである．

問題文の Mayer 関数

```math
f_{0i}=e^{-u_{0i}/kT}-1
```

を用いると，

```math
e^{-u_{0i}/kT}=1+f_{0i}
```

であるから，

```math
\boxed{
e^{-U(0,1,\ldots,N)/kT}
=
e^{-U(1,\ldots,N)/kT}
\prod_{i=1}^{N}(1+f_{0i})
}
\tag{2}
```

となる．

配置積分の定義に式 (2) を代入すれば，

```math
\begin{aligned}
Q(N+1,T,V)
={}&\frac1{(N+1)!}
\int_V d\mathbf r_0
\int_V\cdots\int_V
e^{-U(1,\ldots,N)/kT}\\
&\qquad\qquad\times
\prod_{i=1}^{N}(1+f_{0i})
\,d\mathbf r_1\cdots d\mathbf r_N
\end{aligned}
```

を得る．

ここで，系が一様で，容器の境界による影響を無視できるとする．
粒子間ポテンシャルは相対位置のみに依存するため，粒子 $0$ の位置を平行移動しても，残りの座標について積分した値は変わらない．
したがって， $\mathbf r_0$ に関する積分は体積 $V$ を与える．
よって，

```math
\begin{aligned}
Q(N+1,T,V)
={}&\frac{V}{N+1}\frac1{N!}
\int_V\cdots\int_V
e^{-U(1,\ldots,N)/kT}\\
&\qquad\qquad\times
\prod_{i=1}^{N}(1+f_{0i})
\,d\mathbf r_1\cdots d\mathbf r_N
\end{aligned}
\tag{3}
```

となる．
この式では，粒子 $0$ の位置を任意の固定点に選んでいる．

### 3．Mayer 関数の積の展開

式 (3) の積

```math
\prod_{i=1}^{N}(1+f_{0i})
```

を展開する．
この積には， $f_{0i}$ を $n$ 個選んだ項が含まれる．
$N$ 個の粒子から $n$ 個を選ぶ方法は

```math
\binom Nn=\frac{N!}{n!(N-n)!}
```

通りである．
また，粒子はすべて同等であるため，どの $n$ 個を選んでも，座標について全積分した値は同じである．
したがって，

```math
\begin{aligned}
Q(N+1,T,V)
={}&\frac{V}{N+1}
\sum_{n=0}^{N}\frac1{n!(N-n)!}\\
&\times
\int_V\cdots\int_V
e^{-U(1,\ldots,N)/kT}
\left(\prod_{i=1}^{n}f_{0i}\right)
\,d\mathbf r_1\cdots d\mathbf r_N
\end{aligned}
\tag{4}
```

となる．
ここで， $n=0$ の場合は空積を $1$ と定める．

### 4．$n$ 粒子の確率密度を用いた書き換え

次に，特定の番号を付けた粒子 $1,\ldots,n$ がそれぞれ指定された座標付近に存在する同時確率密度を $P_n$ とする．
残りの粒子の座標を積分して消去すれば，

```math
\boxed{
P_n(\mathbf r_1,\ldots,\mathbf r_n)
=
\frac1{N!Q(N,T,V)}
\int_V\cdots\int_V
e^{-U(1,\ldots,N)/kT}
\,d\mathbf r_{n+1}\cdots d\mathbf r_N
}
\tag{5}
```

となる．
$P_n\,d\mathbf r_1\cdots d\mathbf r_n$ は，番号を指定した $n$ 個の粒子が指定された微小領域内に存在する確率である．

式 (5) から，

```math
\begin{aligned}
&\int_V\cdots\int_V
e^{-U(1,\ldots,N)/kT}
\left(\prod_{i=1}^{n}f_{0i}\right)
\,d\mathbf r_1\cdots d\mathbf r_N\\
&\quad=
N!Q(N,T,V)
\int_V\cdots\int_V
P_n(\mathbf r_1,\ldots,\mathbf r_n)
\left(\prod_{i=1}^{n}f_{0i}\right)
\,d\mathbf r_1\cdots d\mathbf r_n
\end{aligned}
\tag{6}
```

を得る．
重要なのは，式 (6) の左辺では全 $N$ 粒子の座標を積分し，右辺では残りの $N-n$ 粒子の座標を式 (5) の中で積分済みであることである．

問題文では，粒子の番号を指定しないとき，そのうち $n$ 個がそれぞれ指定された座標付近に存在する確率を

```math
\frac1{v^n}F_n(\mathbf r_1,\ldots,\mathbf r_n)
\,d\mathbf r_1\cdots d\mathbf r_n
```

と定義している．
ここで $v=V/N$ である．

番号を指定した $n$ 個の粒子を選ぶ方法は $N(N-1)\cdots(N-n+1)$ 通りであるから，

```math
\frac1{v^n}F_n
=
\frac{N!}{(N-n)!}P_n
\tag{7}
```

となる．
式 (7) より，

```math
\frac{N!}{n!(N-n)!}P_n
=
\frac1{n!v^n}F_n
\tag{8}
```

である．

### 5．最終式の導出

式 (6) と式 (8) を式 (4) に代入すると，

```math
\begin{aligned}
Q(N+1,T,V)
={}&\frac{V}{N+1}Q(N,T,V)\\
&\times
\left[
1+\sum_{n=1}^{N}
\frac1{n!v^n}
\int_V\cdots\int_V
F_n(\mathbf r_1,\ldots,\mathbf r_n)
\prod_{i=1}^{n}f_{0i}
\,d\mathbf r_1\cdots d\mathbf r_n
\right]
\end{aligned}
\tag{9}
```

となる．
角括弧内の $1$ は $n=0$ の項に由来する．

式 (9) を式 (1) に代入すると，

```math
\begin{aligned}
e^{-\mu/kT}
={}&
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\frac{V}{N+1}\\
&\times
\left[
1+\sum_{n=1}^{N}
\frac1{n!v^n}
\int_V\cdots\int_V
F_n(\mathbf r_1,\ldots,\mathbf r_n)
\prod_{i=1}^{n}f_{0i}
\,d\mathbf r_1\cdots d\mathbf r_n
\right]
\end{aligned}
```

を得る．

最後に， $N\gg1$ であるため，

```math
\frac{V}{N+1}\simeq\frac VN=v
```

と近似できる．
また，各 $\mathbf r_i$ の成分を $x_i,y_i,z_i$ と書き直すと，求める式

```math
\boxed{
\begin{aligned}
e^{-\mu/kT}
={}&
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}v\\
&\times
\left[
1+\sum_{n=1}^{N}
\frac1{n!v^n}
\int\cdots\int
F_n(x_1,y_1,z_1,\ldots,x_n,y_n,z_n)
\prod_{i=1}^{n}f_{0i}\,
dx_1\,dy_1\,dz_1\cdots dx_n\,dy_n\,dz_n
\right]
\end{aligned}
}
```

が得られる．
これで題意が示された．
