# 演習問題【7-B-18】

## 解答

問題で与えられた分子間ポテンシャルに対して，第２ビリアル係数 $B(T)$ および Joule - Thomson 係数 $\left(\frac{\partial T}{\partial p}\right)_H$ を求める．

第２ビリアル係数 $B(T)$ は，次のように定義される．

$$B(T) = \frac{1}{2} \int_0^\infty \{1 - e^{-u(r)/kT}\} 4\pi r^2 dr \quad \cdots (1)$$

### (a) $u(r) = a/r^n$ ( $n > 0$ ) の場合

まず，第２ビリアル係数 $B(T)$ を求める．
$u(r) = a/r^n$ を式(1)に代入すると，

$$B(T) = \frac{1}{2} \int_0^\infty \{1 - e^{-a/(r^n kT)}\} 4\pi r^2 dr = 2\pi \int_0^\infty \{1 - e^{-a/(r^n kT)}\} r^2 dr$$

この積分を直接行うのは困難なため，部分積分を用いる．
$U = 1 - e^{-a/(r^n kT)}$, $dV = r^2 dr \implies V = \frac{1}{3}r^3$ とおくと，

$$\int U dV = \left[ \frac{1}{3}r^3 (1 - e^{-a/(r^n kT)}) \right]_0^\infty - \int_0^\infty \frac{1}{3}r^3 \frac{d}{dr}(1 - e^{-a/(r^n kT)}) dr$$

境界項について考える．
$r \to \infty$ では， $e^{-a/(r^n kT)} \approx 1 - \frac{a}{r^n kT}$ であるから，

$$r^3 (1 - e^{-a/(r^n kT)}) \approx r^3 \left(\frac{a}{r^n kT}\right) = \frac{a}{kT} r^{3-n}$$

$n > 3$ であれば， $r \to \infty$ でこの項は $0$ に収束する．
$r \to 0$ では， $e^{-a/(r^n kT)} \to 0$ であるから，

$$r^3 (1 - e^{-a/(r^n kT)}) \approx r^3 \to 0$$

したがって，境界項は $0$ である．
次に，右辺の積分を実行する．

$$\frac{d}{dr}(1 - e^{-a/(r^n kT)}) = -e^{-a/(r^n kT)} \cdot \frac{d}{dr}\left(-\frac{a}{r^n kT}\right) = e^{-a/(r^n kT)} \cdot \left(-\frac{an}{r^{n+1} kT}\right)$$

よって，

$$B(T) = 2\pi \left[ 0 - \int_0^\infty \frac{1}{3}r^3 e^{-a/(r^n kT)} \left(-\frac{an}{r^{n+1} kT}\right) dr \right] = \frac{2\pi na}{3kT} \int_0^\infty e^{-a/(r^n kT)} \frac{1}{r^{n-2}} dr$$

ここで， $x = \frac{a}{r^n kT}$ と変数変換を行う．
これより， $r^n = \frac{a}{x kT}$ すなわち $r = \left(\frac{a}{kT}\right)^{1/n} x^{-1/n}$ である．
微分の関係は， $\frac{dr}{dx} = \left(\frac{a}{kT}\right)^{1/n} \left(-\frac{1}{n}\right) x^{-1/n-1}$ となる．
積分範囲は， $r: 0 \to \infty$ のとき $x: \infty \to 0$ である．

$$\int_0^\infty e^{-a/(r^n kT)} \frac{1}{r^{n-2}} dr = \int_\infty^0 e^{-x} \left[ \left(\frac{a}{kT}\right)^{1/n} x^{-1/n} \right]^{-(n-2)} \left(\frac{a}{kT}\right)^{1/n} \left(-\frac{1}{n}\right) x^{-1/n-1} dx$$

$$= \frac{1}{n} \left(\frac{a}{kT}\right)^{1/n - (n-2)/n} \int_0^\infty e^{-x} x^{(n-2)/n - 1/n - 1} dx$$

$$= \frac{1}{n} \left(\frac{a}{kT}\right)^{(3-n)/n} \int_0^\infty e^{-x} x^{(n-3)/n - 1} dx$$

ここでガンマ関数 $\Gamma(z) = \int_0^\infty e^{-x} x^{z-1} dx$ を用いると，

$$= \frac{1}{n} \left(\frac{a}{kT}\right)^{(3-n)/n} \Gamma\left(\frac{n-3}{n}\right)$$

これを $B(T)$ の式に代入して，

$$B(T) = \frac{2\pi na}{3kT} \cdot \frac{1}{n} \left(\frac{a}{kT}\right)^{(3-n)/n} \Gamma\left(\frac{n-3}{n}\right) = \frac{2\pi}{3} \left(\frac{a}{kT}\right) \left(\frac{a}{kT}\right)^{(3-n)/n} \Gamma\left(\frac{n-3}{n}\right)$$

$$B(T) = \frac{2\pi}{3} \Gamma\left(\frac{n-3}{n}\right) \left(\frac{a}{kT}\right)^{3/n} \quad \cdots (2\text{a})$$

次に，Joule - Thomson 係数 $\mu_{JT} = \left(\frac{\partial T}{\partial p}\right)_H$ を求める．
関係式 $\left(\frac{\partial T}{\partial p}\right)_H = \frac{1}{C_p} \left(T \frac{dB}{dT} - B\right)$ を用いる．
(2a) より， $B(T) = C_a T^{-3/n}$ （ただし $C_a = \frac{2\pi}{3} \Gamma\left(\frac{n-3}{n}\right) (a/k)^{3/n}$ ）と書けるので，

$$\frac{dB}{dT} = -\frac{3}{n} C_a T^{-3/n-1}$$

$$T \frac{dB}{dT} = -\frac{3}{n} C_a T^{-3/n} = -\frac{3}{n} B(T)$$

これより，

$$\mu_{JT} = \frac{1}{C_p} \left(-\frac{3}{n} B - B\right) = -\frac{1}{C_p} \left(\frac{3}{n} + 1\right) B(T)$$

$B(T)$ を代入して，

$$\mu_{JT} = -\frac{2\pi}{3 C_p} \Gamma\left(\frac{n-3}{n}\right) \left(\frac{3}{n} + 1\right) \left(\frac{a}{kT}\right)^{3/n} \quad \cdots (4\text{a})$$

### (b) $u(r)$ が次のように与えられる場合

$u(r) = \infty \ (r < a), \ u(r) = -u_0 \ (a < r < b), \ u(r) = 0 \ (r > b)$

第２ビリアル係数 $B(T)$ を求める．
式(1) の積分範囲を分割する．

$$B(T) = \frac{1}{2} \left[ \int_0^a (1 - e^{-\infty}) 4\pi r^2 dr + \int_a^b (1 - e^{-(-u_0)/kT}) 4\pi r^2 dr + \int_b^\infty (1 - e^{0}) 4\pi r^2 dr \right]$$

ここで， $e^{-\infty} = 0$ ， $e^{0} = 1$ であるから，

$$B(T) = \frac{1}{2} \left[ \int_0^a 4\pi r^2 dr + \int_a^b (1 - e^{u_0/kT}) 4\pi r^2 dr + 0 \right]$$

$$= \frac{1}{2} \left[ \frac{4}{3}\pi a^3 + (1 - e^{u_0/kT}) \frac{4}{3}\pi (b^3 - a^3) \right]$$

$$= \frac{2\pi}{3} \left[ a^3 + (1 - e^{u_0/kT})(b^3 - a^3) \right]$$

$$= \frac{2\pi}{3} \left[ a^3 + b^3 - a^3 - e^{u_0/kT}(b^3 - a^3) \right]$$

```math
= \frac{2\pi}{3} \left\{ b^3 - e^{u_0/kT}(b^3 - a^3) \right\} \quad (2\text{b})
```

次に，Joule - Thomson 係数 $\mu_{JT}$ を求める．
$B(T) = \frac{2\pi}{3} b^3 - \frac{2\pi}{3} (b^3 - a^3) e^{u_0/kT}$ であるから，

$$\frac{dB}{dT} = -\frac{2\pi}{3} (b^3 - a^3) \frac{d}{dT}(e^{u_0/kT}) = -\frac{2\pi}{3} (b^3 - a^3) e^{u_0/kT} \left(-\frac{u_0}{kT^2}\right) = \frac{2\pi}{3} (b^3 - a^3) e^{u_0/kT} \frac{u_0}{kT^2}$$

これより， $T \frac{dB}{dT}$ は，

$$T \frac{dB}{dT} = \frac{2\pi}{3} (b^3 - a^3) e^{u_0/kT} \frac{u_0}{kT}$$

したがって，

$$\mu_{JT} = \frac{1}{C_p} \left[ \frac{2\pi}{3} (b^3 - a^3) e^{u_0/kT} \frac{u_0}{kT} - \left( \frac{2\pi}{3} b^3 - \frac{2\pi}{3} (b^3 - a^3) e^{u_0/kT} \right) \right]$$

$$= \frac{2\pi}{3 C_p} \left[ (b^3 - a^3) e^{u_0/kT} \left( \frac{u_0}{kT} + 1 \right) - b^3 \right]$$

```math
= \frac{2\pi}{3 C_p} \left\{ -b^3 + \left(1 + \frac{u_0}{kT}\right)(b^3 - a^3)e^{u_0/kT} \right\} \quad \cdots (4\text{b})
```

### 考察

(a) の場合， $\mu_{JT} < 0$ である．
これは，圧力が減少する膨張過程において温度が上昇することを意味する．
これは斥力的なポテンシャルの典型的な振る舞いである．

(b) の場合について考える．
$u_0 = 0$ （引力がない斥力的な場合）とすると，

$$\mu_{JT} = \frac{2\pi}{3 C_p} \{ -b^3 + (1)(b^3 - a^3)e^0 \} = \frac{2\pi}{3 C_p} \{ -b^3 + b^3 - a^3 \} = -\frac{2\pi a^3}{3 C_p} < 0$$

となり，(a) と同様に膨張で温度が上昇する．
一方で， $u_0 > 0$ として引力が働く範囲がある場合，温度 $T$ が十分に低いとき，指数関数 $e^{u_0/kT}$ が非常に大きな値を持つようになる．
このとき，(4b) の式の第２項 $\left(1 + \frac{u_0}{kT}\right)(b^3 - a^3)e^{u_0/kT}$ が第１項 $-b^3$ よりも支配的となり， $\mu_{JT} > 0$ となる．
$\mu_{JT} > 0$ は，膨張に伴って温度が低下することを意味する．
したがって，引力による効果が支配的な低温領域では，Joule - Thomson 膨張によって温度が下がるのである．

## 解説

### 第２ビリアル係数とは

実在気体の状態方程式を，理想気体の状態方程式からのずれとして展開したものがビリアル展開である．

$$ \frac{PV}{kT} = 1 + B(T)\frac{P}{kT} + C(T)\left(\frac{P}{kT}\right)^2 + \dots $$

ここで， $B(T)$ は第２ビリアル係数と呼ばれ，粒子間の２体相互作用の寄与を反映している．
斥力的な相互作用が強いと $B(T) > 0$ となり，引力的な相互作用が強いと $B(T) < 0$ となる．

### Joule - Thomson 効果

Joule - Thomson 効果とは，断熱的に（エンタルピー $H$ が一定の条件下で）圧力が減少する際（膨張時）に，気体の温度が変化する現象である．
この温度変化の符号を決めるのが Joule - Thomson 係数 $\mu_{JT} = \left(\frac{\partial T}{\partial p}\right)_H$ である．
- $\mu_{JT} < 0$ ： 膨張によって温度が上がる（加熱）．
- $\mu_{JT} > 0$ ： 膨張によって温度が下がる（冷却）．

本問題において，(a) のような純粋な斥力ポテンシャルの場合は常に加熱されるが，(b) のように引力が働くポテンシャルの場合は，温度領域によって加熱（高温域）と冷却（低温域）が切り替わることが示された．
この温度の境界は，一般に逆転温度と呼ばれ，実在気体の性質を理解する上で極めて重要である．
