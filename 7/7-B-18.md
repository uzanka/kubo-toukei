# 演習問題【7-B-18】

## 解答

分子間ポテンシャル $u(r)$ に対して，第2ビリアル係数 $B(T)$ を求め，さらに Joule–Thomson 係数

```math
\mu_{JT}=\left(\frac{\partial T}{\partial p}\right)_H
```

を計算する．
ここで， $H$ はエンタルピー， $p$ は圧力， $T$ は絶対温度である．

第2ビリアル係数は，分子1個当たりの体積 $v=V/N$ を用いた低密度展開

```math
p=\frac{kT}{v}
\left[
1+\frac{B(T)}{v}
+O\left(\frac1{v^2}\right)
\right]
```

に現れる係数であり，分子間相互作用が理想気体の状態方程式からのずれに及ぼす影響を表す．
その積分表示は

```math
\boxed{
B(T)=\frac12\int_0^\infty
\left[1-e^{-u(r)/kT}\right]4\pi r^2\,dr
}
\tag{1}
```

である．
ここで， $k$ は Boltzmann 定数， $u(r)$ は分子間ポテンシャルである．

以下では，この $B(T)$ を分子1個当たりの体積として定義し， $C_p$ は分子1個当たりの定圧熱容量として表す．

低圧では，ビリアル展開を用いて状態方程式を体積について解くと，

```math
v=\frac{kT}{p}+B(T)+O(p)
```

となる．
熱力学関係式

```math
\mu_{JT}
=\frac1{C_p}
\left[
T\left(\frac{\partial v}{\partial T}\right)_p-v
\right]
```

に代入すると，低圧の先頭次数では

```math
\boxed{
\mu_{JT}
=\frac1{C_p}
\left(T\frac{dB}{dT}-B\right)
}
\tag{2}
```

を得る．
以下，この式を用いて計算する．

### (a) $u(r)=a/r^n$ の場合

#### 1．第2ビリアル係数

まず， $a>0$ とする．
この場合，ポテンシャルは斥力的である．
式 (1) に代入すると，

```math
\begin{aligned}
B(T)
&=\frac12\int_0^\infty
\left[1-e^{-a/(r^nkT)}\right]4\pi r^2\,dr\\
&=2\pi\int_0^\infty
\left[1-e^{-a/(r^nkT)}\right]r^2\,dr
\end{aligned}
\tag{3}
```

となる．
この積分を評価するため，部分積分を用いる．

```math
f(r)=1-e^{-a/(r^nkT)}
```

とおくと，

```math
\frac{df}{dr}
=-\frac{an}{kT}r^{-n-1}e^{-a/(r^nkT)}
```

である．
部分積分により，

```math
\int_0^\infty r^2f(r)\,dr
=
\left[\frac{r^3f(r)}3\right]_0^\infty
-\frac13\int_0^\infty r^3f'(r)\,dr
```

となる．
境界項は $n>3$ のときゼロとなる．
実際， $r\to0$ では $f(r)\to1$ なので $r^3f(r)\to04 であり， $r\to\infty$ では

```math
f(r)\sim\frac{a}{kT}r^{-n}
```

であるから $r^3f(r)\sim (a/kT)r^{3-n}\to0$ である．
したがって，

```math
\begin{aligned}
B(T)
&=-\frac{2\pi}{3}
\int_0^\infty r^3f'(r)\,dr\\
&=\frac{2\pi na}{3kT}
\int_0^\infty
e^{-a/(r^nkT)}r^{2-n}\,dr
\end{aligned}
\tag{4}
```

となる．

ここで，

```math
x=\frac{a}{r^nkT}
```

と置く．
このとき，

```math
r=\left(\frac{a}{kT}\right)^{1/n}x^{-1/n}
```

であり，

```math
dr=-\frac1n
\left(\frac{a}{kT}\right)^{1/n}
x^{-1/n-1}\,dx
```

である．
積分範囲は $r:0\to\infty$ に対して $x:\infty\to0$ となるため，

```math
\begin{aligned}
&\int_0^\infty
e^{-a/(r^nkT)}r^{2-n}\,dr\\
&\quad=
\frac1n
\left(\frac{a}{kT}\right)^{(3-n)/n}
\int_0^\infty e^{-x}x^{(n-3)/n-1}\,dx
\end{aligned}
```

を得る．
ガンマ関数の定義

```math
\Gamma(s)=\int_0^\infty e^{-x}x^{s-1}\,dx
\qquad (s>0)
```

を用いると，

```math
\int_0^\infty
e^{-a/(r^nkT)}r^{2-n}\,dr
=
\frac1n
\left(\frac{a}{kT}\right)^{(3-n)/n}
\Gamma\left(\frac{n-3}{n}\right)
```

となる．
式 (4) に代入すれば，

```math
\boxed{
B(T)=
\frac{2\pi}{3}
\Gamma\left(\frac{n-3}{n}\right)
\left(\frac{a}{kT}\right)^{3/n}
}
\tag{5}
```

を得る．
この式が有限な第2ビリアル係数を与える条件は $a>0,\ n>3$ である．
問題文の $n>0$ だけでは不十分であり， $0<n\leq3$ では式 (1) の積分が長距離側で発散する．

#### 2．Joule–Thomson 係数

式 (5) より，

```math
B(T)\propto T^{-3/n}
```

である．
したがって，

```math
\frac{dB}{dT}=-\frac3n\frac{B}{T}
```

となり，

```math
T\frac{dB}{dT}-B
=-\left(\frac3n+1\right)B
```

を得る．
これを式 (2) に代入すると，

```math
\boxed{
\mu_{JT}
=
-\frac{2\pi}{3C_p}
\Gamma\left(\frac{n-3}{n}\right)
\left(\frac3n+1\right)
\left(\frac{a}{kT}\right)^{3/n}
}
\tag{6}
```

となる．
$n>3$ ではガンマ関数は正であり， $a>0$ と $C_p>0$ であるため，

```math
\boxed{
\mu_{JT}<0
}
```

である．
したがって，この純粋な斥力ポテンシャルでは，圧力を下げる Joule–Thomson 膨張によって気体の温度は上昇する．

### (b) 硬い斥力核と引力領域をもつポテンシャル

ポテンシャルが

```math
u(r)=
\begin{cases}
\infty,&r<a,\\
-u_0,&a<r<b,\\
0,&r>b
\end{cases}
\qquad (u_0>0)
```

で与えられる場合を考える．
$r<a$ は分子が近づけない領域であり， $a<r<b$ は一定の引力が働く領域である．

#### 1．第2ビリアル係数

式 (1) の積分を，ポテンシャルが一定となる3つの領域に分割する．

```math
\begin{aligned}
B(T)=\frac12\bigg[
&\int_0^a 4\pi r^2\,dr\\
&+\int_a^b
\left(1-e^{u_0/kT}\right)4\pi r^2\,dr\\
&+\int_b^\infty 0\cdot4\pi r^2\,dr
\bigg].
\end{aligned}
```

ここでは， $r<a$ で $e^{-u/kT}=0$ ， $a<r<b$ で $e^{-u/kT}=e^{u_0/kT}$ ， $r>b$ で $1-e^{-u/kT}=0$ を用いた．
積分を実行すると，

```math
\begin{aligned}
B(T)
&=\frac{2\pi}{3}
\left[
a^3+(1-e^{u_0/kT})(b^3-a^3)
\right]\\
&=\frac{2\pi}{3}
\left[
b^3-e^{u_0/kT}(b^3-a^3)
\right].
\end{aligned}
```

したがって，

```math
\boxed{
B(T)=\frac{2\pi}{3}
\left[
b^3-e^{u_0/kT}(b^3-a^3)
\right]
}
\tag{7}
```

を得る．

この式の第1項は硬い斥力核による正の寄与であり，第2項は引力による負の寄与である．
温度が高いと $e^{u_0/kT}\to1$ となり，

```math
B(T)\longrightarrow\frac{2\pi a^3}{3}
```

である．
これは引力の影響が相対的に弱くなり，硬い斥力核が支配的になることを表している．
一方，低温では $e^{u_0/kT}$ が大きくなり， $B(T)$ は負になる．

#### 2．Joule–Thomson 係数

式 (7) を温度で微分する．

```math
\frac{d}{dT}e^{u_0/kT}
=
-\frac{u_0}{kT^2}e^{u_0/kT}
```

であるから，

```math
\frac{dB}{dT}
=
\frac{2\pi}{3}(b^3-a^3)
e^{u_0/kT}\frac{u_0}{kT^2}
```

となる．
よって，

```math
T\frac{dB}{dT}
=
\frac{2\pi}{3}(b^3-a^3)
e^{u_0/kT}\frac{u_0}{kT}
```

である．
これを式 (2) に代入すると，

```math
\boxed{
\mu_{JT}
=
\frac{2\pi}{3C_p}
\left[
-b^3+
\left(1+\frac{u_0}{kT}\right)
(b^3-a^3)e^{u_0/kT}
\right]
}
\tag{8}
```

を得る．

#### 3．温度による符号の変化

まず $u_0=0$ とすると，引力領域がなくなり，硬い斥力核だけが残る．
このとき，

```math
B(T)=\frac{2\pi a^3}{3}
```

であり，式 (8) より，

```math
\boxed{
\mu_{JT}=-\frac{2\pi a^3}{3C_p}<0
}
```

となる．
したがって，膨張時には温度が上昇する．

次に $u_0>0$ とする．
ここで，

```math
x=\frac{u_0}{kT},
\qquad x>0
```

とおくと，式 (8) の符号を決めるのは

```math
-b^3+(1+x)(b^3-a^3)e^x
```

である．
$x\to0$ ，すなわち高温極限では，この式は

```math
-b^3+(b^3-a^3)=-a^3<0
```

に近づくため，

```math
\mu_{JT}<0
```

となる．
したがって，高温では膨張時に温度が上昇する．

一方， $T\to0$ では $x\to\infty$ となり，正の項 $(1+x)(b^3-a^3)e^x$ が支配的になる．
このため，

```math
\mu_{JT}>0
```

となり，膨張時に温度が低下する．

両者の間には逆転温度 $T_I$ が存在する．
この温度では $\mu_{JT}=0$ であるから，

```math
(1+x_I)e^{x_I}
=\frac{b^3}{b^3-a^3},
\qquad
x_I=\frac{u_0}{kT_I}
```

を満たす．
左辺は $x_I>0$ で単調増加し， $x_I=0$ では1である．
右辺は $0<a<b$ に対して1より大きい．
したがって，正の解 $x_I$ がただ1つ存在し，

```math
\boxed{
T_I=\frac{u_0}{kx_I}
}
```

で定まる．

### 結論

(a) の純粋な斥力ポテンシャル $u(r)=a/r^n$ では， $a>0,\ n>3$ のとき第2ビリアル係数は正であり，Joule–Thomson 係数は負となる．
したがって，Joule–Thomson 膨張では温度が上昇する．

(b) の硬い斥力核と引力領域をもつポテンシャルでは，高温では斥力の寄与が支配的で $\mu_{JT}<0$ となるが，低温では引力の寄与が支配的になり $\mu_{JT}>0$ となる．
その間に逆転温度が存在し，それより高温では膨張時に加熱し，低温では膨張時に冷却する．

以上は，いずれも低密度で第2ビリアル係数までを残した近似の範囲での結論である．
