# 演習問題【7-B-15】

## 解答

2原子分子の振動エネルギーは，非調和性を考慮すると

```math
\epsilon_n
=
\left(n+\frac12\right)h\nu
-x_e\left(n+\frac12\right)^2h\nu,
\qquad n=0,1,2,\ldots
```

で与えられる．
ここで， $h$ は Planck 定数， $\nu$ は振動数， $x_e$ は非調和性を表す無次元定数である．
この非調和性が振動比熱に与える影響を， $x_e$ の1次まで求める．

### 1．振動分配関数

温度 $T$ における振動分配関数 $v(T)$ は，各振動準位の Boltzmann 因子を足し合わせたものである．
したがって，

```math
v(T)=\sum_{n=0}^{\infty}
\exp\left(-\frac{\epsilon_n}{kT}\right)
```

と書ける．
ここで， $k$ は Boltzmann 定数である．

計算を簡単にするため，

```math
u=\frac{h\nu}{kT}
```

と定義する．
すると，

```math
-\frac{\epsilon_n}{kT}
=
-\left(n+\frac12\right)u
+x_e\left(n+\frac12\right)^2u
```

となる．
さらに，

```math
\left(n+\frac12\right)^2=n(n+1)+\frac14
```

であるから，

```math
\begin{aligned}
v(T)
&=
\sum_{n=0}^{\infty}
\exp\left[
-\left(n+\frac12\right)u
+x_e\left(n+\frac12\right)^2u
\right]\\
&=
\exp\left(-\frac u2+\frac{x_eu}{4}\right)
\sum_{n=0}^{\infty}
\exp\left[-nu+x_en(n+1)u\right].
\end{aligned}
\tag{1}
```

これが振動分配関数の表式である．

### 2．分配関数の1次展開

$x_e$ の1次までを求めるため，

```math
e^{x_en(n+1)u}
\simeq 1+x_en(n+1)u
```

と近似する．
ここで，

```math
\bar v(T)=
\sum_{n=0}^{\infty}
e^{-nu}e^{x_en(n+1)u}
```

とおくと，

```math
\bar v(T)
\simeq
\sum_{n=0}^{\infty}e^{-nu}
+x_eu\sum_{n=0}^{\infty}n(n+1)e^{-nu}
\tag{2}
```

となる．

まず，等比級数の和から，

```math
\sum_{n=0}^{\infty}e^{-nu}
=\frac1{1-e^{-u}}
```

である．
次に， $n$ を含む和を求める．

```math
\frac{d}{du}e^{-nu}=-ne^{-nu},
\qquad
\frac{d^2}{du^2}e^{-nu}=n^2e^{-nu}
```

であるため，

```math
\begin{aligned}
\sum_{n=0}^{\infty}n(n+1)e^{-nu}
&=
\left(\frac{d^2}{du^2}-\frac d{du}\right)
\sum_{n=0}^{\infty}e^{-nu}\\
&=
\left(\frac{d^2}{du^2}-\frac d{du}\right)
\frac1{1-e^{-u}}.
\end{aligned}
```

ここで，

```math
\frac d{du}\frac1{1-e^{-u}}
=-\frac{e^{-u}}{(1-e^{-u})^2}
```

および

```math
\frac{d^2}{du^2}\frac1{1-e^{-u}}
=
\frac{e^{-u}+e^{-2u}}{(1-e^{-u})^3}
```

を用いると，

```math
\begin{aligned}
\sum_{n=0}^{\infty}n(n+1)e^{-nu}
&=
\frac{e^{-u}+e^{-2u}}{(1-e^{-u})^3}
+\frac{e^{-u}}{(1-e^{-u})^2}\\
&=\frac{2e^{-u}}{(1-e^{-u})^3}.
\end{aligned}
```

したがって，式 (2) は

```math
\begin{aligned}
\bar v(T)
&\simeq
\frac1{1-e^{-u}}
+\frac{2x_eu e^{-u}}{(1-e^{-u})^3}\\
&=
\frac1{1-e^{-u}}
\left[
1+\frac{2x_eu e^{-u}}{(1-e^{-u})^2}
\right]
\end{aligned}
\tag{3}
```

となる．

両辺の対数を取り， $x_e$ の1次まで展開する．
$\ln(1+y)\simeq y$ を用いれば，

```math
\boxed{
\ln\bar v(T)
\simeq
-\ln(1-e^{-u})
+\frac{2x_eu e^{-u}}{(1-e^{-u})^2}
}
\tag{4}
```

を得る．

### 3．振動比熱の計算

振動によるモル比熱は，分配関数を用いて

```math
C_{\mathrm{vib}}
=
R\frac{\partial}{\partial T}
\left(
T^2\frac{\partial}{\partial T}\ln v
\right)
```

と表される．
ここで， $R$ は気体定数である．

$u=h\nu/(kT)$ であるから，

```math
\frac{du}{dT}=-\frac uT
```

となる．
連鎖律を用いると，

```math
\begin{aligned}
T^2\frac{\partial}{\partial T}\ln v
&=T^2\frac{d\ln v}{du}\frac{du}{dT}\\
&=-Tu\frac{d\ln v}{du}\\
&=-\frac{h\nu}{k}\frac{d\ln v}{du}.
\end{aligned}
```

これをさらに $T$ で微分すれば，

```math
\boxed{
C_{\mathrm{vib}}
=Ru^2\frac{d^2}{du^2}\ln v
}
\tag{5}
```

が得られる．

式 (1) より，

```math
\ln v
=
-\frac u2+\frac{x_eu}{4}+\ln\bar v(T)
```

である．
最初の2項は $u$ の1次式であるため， $u$ に関する2階微分では消える．
よって，

```math
C_{\mathrm{vib}}
=
Ru^2\frac{d^2}{du^2}\ln\bar v(T)
```

と書ける．

式 (4) を代入すると，

```math
\begin{aligned}
C_{\mathrm{vib}}
\simeq{}&
Ru^2\frac{d^2}{du^2}
\left[-\ln(1-e^{-u})\right]\\
&+
2x_eRu^2\frac{d^2}{du^2}
\left[\frac{ue^{-u}}{(1-e^{-u})^2}\right].
\end{aligned}
\tag{6}
```

ここで，

```math
g(u)=\frac{e^{-u}}{(1-e^{-u})^2}
```

とおく．
このとき，式 (6) の非調和補正項に含まれる関数は $ug(u)$ であり，

```math
\frac{d^2}{du^2}[ug(u)]
=2g'(u)+ug''(u)
```

となる．
微分すると，

```math
\frac{g'(u)}{g(u)}
=-\frac{1+e^{-u}}{1-e^{-u}}
```

および

```math
\frac{g''(u)}{g(u)}
=
\frac{1+4e^{-u}+e^{-2u}}{(1-e^{-u})^2}
```

が得られる．
したがって，

```math
\begin{aligned}
2g'(u)+ug''(u)
=g(u)\left[
-\frac{2(1+e^{-u})}{1-e^{-u}}
+\frac{u(1+4e^{-u}+e^{-2u})}{(1-e^{-u})^2}
\right].
\end{aligned}
\tag{7}
```

また，調和振動子の項については，

```math
\frac{d^2}{du^2}
\left[-\ln(1-e^{-u})\right]
=
\frac{e^u}{(e^u-1)^2}
```

である．
これらを式 (6) に代入すると，

```math
\boxed{
\begin{aligned}
C_{\mathrm{vib}}
\simeq{}&
R\frac{u^2e^u}{(e^u-1)^2}\\
&\times
\left[
1+\frac{2x_e}{(1-e^{-u})^2}
\left\{
-2(1-e^{-2u})
+u(1+4e^{-u}+e^{-2u})
\right\}
\right]
\end{aligned}
}
\tag{8}
```

となる．
この式の角括弧内の $x_e$ を含む項が，非調和性による1次の補正である．

### 4．高温極限

高温では $u=h\nu/(kT)\to0$ となる．
調和振動子の比熱に現れる因子は，

```math
u^2\frac{e^u}{(e^u-1)^2}
=
1-\frac{u^2}{12}+\frac{u^4}{240}
+O(u^6)
```

と展開できる．

一方，非調和性による補正は式 (6)，(7) から求められる．

```math
g(u)=\frac1{u^2}-\frac1{12}
+\frac{u^2}{240}+O(u^4)
```

であるため，

```math
2g'(u)+ug''(u)
=
\frac2{u^3}+\frac{u}{40}+O(u^3)
```

となる．
したがって，非調和補正は

```math
\begin{aligned}
2x_eu^2[2g'(u)+ug''(u)]
&=
\frac{4x_e}{u}+\frac{x_eu^3}{20}
+O(x_eu^5)\\
&=
4x_e\left(\frac1u+\frac{u^3}{80}\right)
+O(x_eu^5)
\end{aligned}
```

である．
以上より，高温極限の比熱は

```math
\boxed{
C_{\mathrm{vib}}
\simeq
R\left[
1-\frac{u^2}{12}+\frac{u^4}{240}
+4x_e\left(\frac1u+\frac{u^3}{80}\right)
\right]
}
\tag{9}
```

となる．
これは解答例の高温展開と一致する．

特に，非調和性による先頭の補正は

```math
\boxed{
\Delta C_{\mathrm{vib}}
\simeq4x_eR\frac1u
=4x_eR\frac{kT}{h\nu}
}
```

である．
すなわち，1次摂動の範囲では，非調和性による補正は温度とともに増大する．

### 5．結論と適用範囲

求める比熱は式 (8) で与えられ，その高温展開は式 (9) である．
高温での非調和補正の主要項は $4x_eRkT/(h\nu)$ となる．

ただし，この結果は $x_e$ の1次までの摂動結果である．
エネルギー式を無限に高い振動準位までそのまま適用すると，正の $x_e$ に対して準位エネルギーが高い $n$ で際限なく低下し，厳密な分配関数は収束しなくなる．
実際の分子では束縛された振動準位の数は有限であり，この式は主として低励起準位の近似として用いられる．

また，非調和補正の主要項は $x_e/u$ に比例するため，高温で $u$ が非常に小さくなると，1次補正が調和振動子の比熱に比べて大きくなり，摂動近似の妥当性が失われる．
したがって，式 (9) は非調和性が小さく，補正が十分小さい温度範囲で解釈すべき式である．
