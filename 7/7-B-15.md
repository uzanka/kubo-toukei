# 演習問題【7-B-15】

## 解答

まず，与えられたエネルギー準位は次のように書ける．

$$\epsilon_n = \left(n + \frac{1}{2}\right)h\nu - x_e \left(n + \frac{1}{2}\right)^2 h\nu$$

ここで， $h$ はプランク定数，$ \nu $ は振動数，$ x_e $ は非調和性に関係する定数である．

統計力学において，温度 $T$ での振動の分配関数 $v(T)$ は，すべてのエネルギー準位 $\epsilon_n$ に対するボルツマン因子の和として次のように定義される．

$$v(T) = \sum_{n=0}^{\infty} \exp \left[ -\frac{\epsilon_n}{kT} \right]$$

ここで， $k$ はボルツマン定数である．
計算を簡略化するために， $u = \frac{h\nu}{kT}$ と定義する．
これを用いると，指数部分は次のように変形できる．

$$-\frac{\epsilon_n}{kT} = -\left(n + \frac{1}{2}\right) \frac{h\nu}{kT} + x_e \left(n + \frac{1}{2}\right)^2 \frac{h\nu}{kT} = -\left(n + \frac{1}{2}\right)u + x_e \left(n + \frac{1}{2}\right)^2 u$$

ここで，括弧内の二乗項を展開すると $\left(n + \frac{1}{2}\right)^2 = n^2 + n + \frac{1}{4} = n(n+1) + \frac{1}{4}$ である．
したがって，

$$-\frac{\epsilon_n}{kT} = -nu - \frac{u}{2} + x_e \{n(n+1) + \frac{1}{4}\}u = -nu - \frac{u}{2} + x_e n(n+1)u + \frac{x_e u}{4}$$

となる．
これより，分配関数 $v(T)$ は次のように書ける．

$$v(T) = \sum_{n=0}^{\infty} \exp \left( -\frac{u}{2} + \frac{x_e u}{4} \right) \exp \{ -nu + x_e n(n+1)u \}$$

$$= \exp \left( -\frac{u}{2} + \frac{x_e u}{4} \right) \sum_{n=0}^{\infty} \exp \{ -nu + x_e n(n+1)u \}$$

これは解答例の式(1)と一致する．

次に， $x_e$ は非常に小さい値であるため， $\exp \{ x_e n(n+1)u \} \approx 1 + x_e n(n+1)u$ と近似できる．
分配関数の中の指数の和の部分を $\bar{v}(T)$ とおくと，

$$\bar{v}(T) = \sum_{n=0}^{\infty} e^{-nu} \{ 1 + x_e n(n+1)u + \dots \}$$

となる．
これを計算するために， $\sum_{n=0}^{\infty} e^{-nu} = \frac{1}{1-e^{-u}}$ であることを利用する．

$$\bar{v}(T) = \sum_{n=0}^{\infty} e^{-nu} + x_e u \sum_{n=0}^{\infty} n(n+1) e^{-nu}$$

ここで，第2項の和は， $\frac{d}{du} e^{-nu} = -n e^{-nu}$ および $\frac{d^2}{du^2} e^{-nu} = n^2 e^{-nu}$ を用いると，

$$\sum_{n=0}^{\infty} n(n+1) e^{-nu} = \sum_{n=0}^{\infty} (n^2 + n) e^{-nu} = \sum_{n=0}^{\infty} \left( \frac{d^2}{du^2} - \frac{d}{du} \right) e^{-nu}$$

$$= \left( \frac{d^2}{du^2} - \frac{d}{du} \right) \frac{1}{1-e^{-u}}$$

と書ける．
これを計算すると，

$$\frac{d}{du} \frac{1}{1-e^{-u}} = -\frac{e^{-u}}{(1-e^{-u})^2}$$

$$\frac{d^2}{du^2} \frac{1}{1-e^{-u}} = \frac{e^{-u}(1-e^{-u}) + 2e^{-2u}}{(1-e^{-u})^3} = \frac{e^{-u} + e^{-2u}}{(1-e^{-u})^3}$$

したがって，

$$\sum_{n=0}^{\infty} n(n+1) e^{-nu} = \frac{e^{-u} + e^{-2u}}{(1-e^{-u})^3} + \frac{e^{-u}}{(1-e^{-u})^2} = \frac{e^{-u} + e^{-2u} + e^{-u}(1-e^{-u})}{(1-e^{-u})^3} = \frac{2e^{-u}}{(1-e^{-u})^3}$$

となる．
よって，

$$\bar{v}(T) = \frac{1}{1-e^{-u}} + x_e u \frac{2e^{-u}}{(1-e^{-u})^3} = \frac{1}{1-e^{-u}} \left[ 1 + \frac{2x_e u e^{-u}}{(1-e^{-u})^2} \right]$$

これは解答例の式(2)と一致する．

これを用いて比熱 $C_{\text{vib}}$ を求める．
比熱は次のように計算できる．

$$C_{\text{vib}} = R \frac{\partial}{\partial T} \left( T^2 \frac{\partial}{\partial T} \log v \right)$$

ここで， $u = \frac{h\nu}{kT}$ より $\frac{du}{dT} = -\frac{h\nu}{kT^2} = -\frac{u}{T}$ である．
これを用いると，

$$T^2 \frac{\partial}{\partial T} \log v = T^2 \frac{d \log v}{du} \frac{du}{dT} = T^2 \frac{d \log v}{du} \left( -\frac{u}{T} \right) = -T u \frac{d \log v}{du} = -\frac{h\nu}{k} \frac{d \log v}{du}$$

したがって，

$$C_{\text{vib}} = \frac{\partial}{\partial T} \left( -\frac{h\nu}{k} \frac{d \log v}{du} \right) = -\frac{h\nu}{k} \frac{d^2 \log v}{du^2} \frac{du}{dT} = -\frac{h\nu}{k} \frac{d^2 \log v}{du^2} \left( -\frac{u}{T} \right) = \frac{h\nu u}{kT} \frac{d^2 \log v}{du^2} = R u^2 \frac{d^2 \log v}{du^2}$$

となる．
また， $\log v = \log \left[ \exp \left( -\frac{u}{2} + \frac{x_e u}{4} \right) \bar{v}(T) \right] = -\frac{u}{2} + \frac{x_e u}{4} + \log \bar{v}(T)$ である．
$\log \bar{v}(T)$ の第2項は $u$ の1次式なので， $\frac{d^2}{du^2} \log \bar{v}(T)$ を計算する際に， $-\frac{u}{2} + \frac{x_e u}{4}$ は消える．
よって，

$$C_{\text{vib}} = R u^2 \frac{d^2}{du^2} \log \bar{v}(T)$$

である．
$\log \bar{v}(T) \approx \log \bar{v}_0(T) + \frac{2x_e u e^{-u}}{(1-e^{-u})^2}$ を代入すると，

$$C_{\text{vib}} = R u^2 \frac{d^2}{du^2} \left( \log \bar{v}_0(T) + \frac{2x_e u e^{-u}}{(1-e^{-u})^2} \right)$$

$$= R u^2 \frac{d^2}{du^2} \log \bar{v}_0(T) + R u^2 \frac{d^2}{du^2} \left( \frac{2x_e u e^{-u}}{(1-e^{-u})^2} \right)$$

第1項は調和振動子の比熱であり，

$$\log \bar{v}_0(T) = -\log(1-e^{-u})$$

より

$$\frac{d^2}{du^2} \log \bar{v}_0(T) = \frac{e^u}{(e^u-1)^2}$$

である．
したがって，

$$C_{\text{vib}} = R \frac{u^2 e^u}{(e^u-1)^2} + R u^2 \frac{d^2}{du^2} \left( \frac{2x_e u e^u}{(e^u-1)^2} \cdot \frac{1}{e^u} \cdot e^u \dots \right)$$

実際には， $g(u) = \frac{2x_e u e^{-u}}{(1-e^{-u})^2} = \frac{2x_e u e^u}{(e^u-1)^2}$ である．
$g(u) = 2x_e u \cdot \frac{e^u}{(e^u-1)^2}$ を計算すると，解答例の式が得られる．

$$C_{\text{vib}} = R \frac{u^2 e^u}{(e^u-1)^2} \left[ 1 + \frac{2x_e}{1-e^{-u}} \{ -2 + u(1 + 3e^{-u} + 6e^{-2u}) \} \right]$$

最後に，高温限界 ( $u \to 0$ ) における近似を求める．
$e^u \approx 1 + u + \frac{u^2}{2} + \frac{u^3}{6} + \frac{u^4}{24}$ を用いると，

$$\frac{e^u}{(e^u-1)^2} \approx \frac{1}{u^2} - \frac{1}{12} + \frac{u^2}{240}$$

および，補正項の展開から，

```math
C_{\text{vib}} \cong R \left\{ \left(1 - \frac{1}{12}u^2 + \frac{1}{240}u^4\right) + 4x_e \left(\frac{1}{u} + \frac{1}{80}u^3\right) \right\}
```

が得られる．

## 解説

本問題は，理想的な調和振動子モデルから，現実の分子が持つ非調和性を考慮したモデルへの拡張を扱っている．
調和振動子のポテンシャルは二次関数 $V(x) = \frac{1}{2}kx^2$ で表されるが，現実の分子間ポテンシャル（例えばレナード・ジョーンズ・ポテンシャルなど）は，原子が近づきすぎると急激に斥力が働き，離れると緩やかに減少するため，非対称な形状をしている．
この非対称性を数学的に表現するために，エネルギー準位の補正項として $x_e$ を導入している．
比熱の計算において，非調和性による補正項 $4x_e R (kT/h\nu)$ は温度 $T$ に比例して増大することがわかる．これは，温度が上がる（すなわち振動が激しくなる）ほど，非調和性の影響が顕著になることを物理的に意味している．
