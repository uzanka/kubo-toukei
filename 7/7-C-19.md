# 演習問題【7-C-19】

## 解答

水素分子 $\mathrm{H_2}$ が金属表面に吸着し，2個の水素原子に解離する反応

```math
\mathrm{H_2(gas)}\rightleftharpoons
2\mathrm{H(ads)}
```

を考える．
ここで， $\mathrm{gas}$ は気相， $\mathrm{ads}$ は吸着相を表す．
解離吸着によって放出されるエネルギーを $w$ とする．
$w$ は零点振動エネルギーを含まないエネルギーである．
求めるのは，吸着原子の数 $N$ と吸着サイト総数 $N_0$ の比が，気相の水素圧力 $p$ にどう依存するかである．

### 1．吸着相の分配関数と化学ポテンシャル

#### 1.1　吸着相の分配関数

金属表面には $N_0$ 個の吸着サイトがあり，そのうち $N$ 個に水素原子が吸着しているとする．
各サイトには最大1個の水素原子が吸着できると仮定する．

$N_0$ 個のサイトから $N$ 個を選ぶ方法の数は

```math
\frac{N_0!}{N!(N_0-N)!}
```

である．
また，吸着した水素原子1個の分配関数を $q_{\mathrm H}$ とすると，吸着相の全分配関数は

```math
Z_{\mathrm{ads}}
=
\frac{N_0!}{N!(N_0-N)!}(q_{\mathrm H})^N
\tag{1}
```

となる．

吸着した水素原子には，核スピンの縮重度2がある．
さらに，吸着面に垂直な方向の振動数を $\nu_\perp$ ，面に平行な2方向の振動数を $\nu_\parallel$ とする．
調和振動子の分配関数は，振動数 $\nu$ に対して

```math
q_{\mathrm{vib}}(\nu)
=
\frac{1}{2\sinh\left(\frac{h\nu}{2kT}\right)}
```

である．
この式は零点振動エネルギーも含む形である．
ここで， $h$ は Planck 定数， $k$ は Boltzmann 定数， $T$ は絶対温度である．

吸着原子1個の分配関数は，核スピン，3方向の振動，解離吸着エネルギーの寄与を掛け合わせて

```math
\boxed{
q_{\mathrm H}
=
2
\left(2\sinh\frac{h\nu_\perp}{2kT}\right)^{-1}
\left(2\sinh\frac{h\nu_\parallel}{2kT}\right)^{-2}
e^{w/(2kT)}
}
\tag{2}
```

となる．

ここでは，解離吸着エネルギー $w$ を2個の吸着水素原子に均等に割り当てているため，原子1個あたりの因子は $e^{w/(2kT)}$ である．

#### 1.2　吸着水素原子の化学ポテンシャル

Helmholtz 自由エネルギーは $F=-kT\ln Z$ で与えられるため，式 (1) から

```math
F_{\mathrm{ads}}(N)
=-kT\ln\left[
\frac{N_0!}{N!(N_0-N)!}(q_{\mathrm H})^N
\right]
```

を得る．

吸着水素原子の化学ポテンシャルは，温度とサイト総数を一定にして $N$ で微分した量である．
大きな $N$ に対して Stirling の近似

```math
\ln N!\simeq N\ln N-N
```

を用いると，

```math
\boxed{
\mu_{\mathrm H}(\mathrm{ads})
=
-kT\ln q_{\mathrm H}
+kT\ln\frac{N}{N_0-N}
}
\tag{3}
```

となる．
この式の第1項は，吸着水素原子1個の内部状態と吸着エネルギーによる寄与であり，第2項は吸着サイトが埋まる割合による寄与である．

### 2．水素ガスの化学ポテンシャル

水素ガスを理想気体として扱う．
分子1個の質量を $m$ ，慣性モーメントを $I$ ，分子振動の振動数を $\nu$ とする．
気相の水素分子の分配関数には，並進，回転，核スピン，振動の4つの寄与がある．

理想気体の化学ポテンシャルは，分子1個あたりの分配関数を用いて表せる．
並進分配関数の圧力依存性を状態方程式で置き換えると，次の形になる．

```math
\mu_{\mathrm{H_2}}(\mathrm{gas})
=-kT\ln\left[\frac{C(T)}{p}\right]
\tag{4}
```

ここで，

```math
\begin{aligned}
C(T)={}&
\frac{(2\pi mkT)^{3/2}}{h^3}\,kT\\
&\times
\left[
2^2\frac{8\pi^2IkT}{2h^2}
\left(2\sinh\frac{h\nu}{2kT}\right)^{-1}
\right]
\end{aligned}
\tag{5}
```

と定義した．

式 (5) の各因子の意味は次のとおりである．

- $\frac{(2\pi mkT)^{3/2}}{h^3}\frac{kT}{p}$ は，並進運動の寄与である．
- $2^2$ は，水素分子を構成する2つの水素原子核の核スピン縮重度を掛け合わせたものである．
- $\frac{8\pi^2IkT}{2h^2}$ は，対称数2を考慮した高温近似の回転分配関数である．
- $\left(2\sinh\frac{h\nu}{2kT}\right)^{-1}$ は，水素分子の振動分配関数である．

ここで $C(T)$ は温度に依存するが，圧力には依存しない．
したがって，式 (4) により，気相の化学ポテンシャルの圧力依存性は $\ln p$ で与えられることが分かる．

### 3．気相と吸着相の平衡条件

平衡状態では，水素分子1個が気相から吸着し，2個の水素原子となる反応に対して化学ポテンシャルの釣り合いが成り立つ．
したがって，

```math
\boxed{
2\mu_{\mathrm H}(\mathrm{ads})
=\mu_{\mathrm{H_2}}(\mathrm{gas})
}
\tag{6}
```

である．
式 (3) と式 (4) を代入すると，

```math
2\left[
-\ln q_{\mathrm H}
+\ln\frac{N}{N_0-N}
\right]
=
-\ln\frac{C(T)}p
```

となる．
整理して，

```math
2\ln\frac{N}{N_0-N}
=
2\ln q_{\mathrm H}-\ln C(T)+\ln p
```

を得る．
両辺を2で割ると，

```math
\ln\frac{N}{N_0-N}
=
\ln q_{\mathrm H}
-\frac12\ln C(T)
+\frac12\ln p
```

である．
指数関数を取れば，

```math
\boxed{
\frac{N}{N_0-N}
=
\frac{q_{\mathrm H}}{\sqrt{C(T)}}\,p^{1/2}
}
\tag{7}
```

となる．
したがって，係数

```math
A(T)=\frac{q_{\mathrm H}}{\sqrt{C(T)}}
```

を定義すると，

```math
\boxed{
\frac{N}{N_0-N}=A(T)p^{1/2}
}
\tag{8}
```

である．
これが，吸着量と水素圧力の関係を表す式である．

### 4．係数 $A(T)$ の具体形

式 (2) と式 (5) を式 (7) に代入する．
平方根を計算すると，

```math
\begin{aligned}
\sqrt{C(T)}
={}&
\frac{
2(2\pi)^{7/4}m^{3/4}(kT)^{7/4}I^{1/2}
}{h^{5/2}}\\
&\times
\left(2\sinh\frac{h\nu}{2kT}\right)^{-1/2}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\begin{aligned}
A(T)
={}&
\frac{h^{5/2}}
{(2\pi)^{7/4}m^{3/4}(kT)^{7/4}I^{1/2}}\\
&\times
\frac{
\left(2\sinh\frac{h\nu}{2kT}\right)^{1/2}
e^{w/(2kT)}
}{
\left(2\sinh\frac{h\nu_\perp}{2kT}\right)
\left(2\sinh\frac{h\nu_\parallel}{2kT}\right)^2
}
\end{aligned}
}
\tag{9}
```

を得る．
この係数は温度，分子の振動数，慣性モーメント，解離吸着エネルギーに依存する．
温度を固定すれば， $A(T)$ は圧力によらない定数である．

### 5．被覆率で表した吸着等温式

被覆率を

```math
\theta=\frac{N}{N_0}
```

と定義する．
式 (8) から，

```math
\frac{\theta}{1-\theta}=A(T)\sqrt p
```

である．
これを $\theta$ について解けば，

```math
\theta=A(T)\sqrt p\,(1-\theta)
```

すなわち，

```math
\theta[1+A(T)\sqrt p]=A(T)\sqrt p
```

となる．
したがって，最終的に

```math
\boxed{
\frac{N}{N_0}
=
\theta
=
\frac{A(T)\sqrt p}{1+A(T)\sqrt p}
}
\tag{10}
```

を得る．
これが求める吸着量と水素圧力の関係である．
水素分子が解離して2個の水素原子として吸着するため，圧力 $p$ ではなく，その平方根 $\sqrt p$ が被覆率を決める量として現れる．

### 6．振動数が十分に高い場合の近似

振動励起がほとんど起こらず，

```math
h\nu\gg kT,\qquad
h\nu_\perp\gg kT,\qquad
h\nu_\parallel\gg kT
```

が成り立つとする．
このとき，

```math
2\sinh\frac{h\nu}{2kT}
\simeq e^{h\nu/(2kT)}
```

である．
同様の近似を吸着水素原子の振動モードにも適用すると，式 (9) は

```math
\boxed{
\begin{aligned}
A(T)\simeq{}&
\frac{h^{5/2}}
{(2\pi)^{7/4}m^{3/4}(kT)^{7/4}I^{1/2}}\\
&\times
\exp\left[
\frac{
h\nu/4-h\nu_\perp/2-h\nu_\parallel+w/2
}{kT}
\right]
\end{aligned}
}
\tag{11}
```

となる．
ここで得られた式は，振動励起を無視し，零点振動エネルギーの効果だけを残した近似である．
これは振動のエネルギー間隔が熱エネルギーより十分大きい場合の近似であり，一般の高温近似とは区別すべきである．

### 結論

水素分子が金属表面上で解離吸着する場合，平衡条件から

```math
\boxed{
\frac{N}{N_0}
=
\frac{A(T)\sqrt p}{1+A(T)\sqrt p}
}
```

が得られる．
この関係は，低圧では被覆率が $\sqrt p$ に比例し，高圧では吸着サイトが埋まるため $N/N_0\to1$ となることを示す．
係数 $A(T)$ は，式 (9) のように振動，回転，核スピン，解離吸着エネルギーの寄与で決まる．
