# 演習問題【7-A-12】

## 解答

反応

```math
\mathrm{HCl+DBr\rightleftharpoons DCl+HBr}
```

の平衡定数が，十分高温では $1$ となることを統計力学的に示す．
ここでは，反応に関与する分子を理想気体とし，分子の回転と振動が古典的な高温近似で扱えるものとする．
同位体置換によって分子の核間距離と結合力は変化しないと仮定する．

### 1．平衡定数と分配関数の関係

理想気体の平衡定数は，

```math
K_p=\frac{p_{\mathrm{DCl}}p_{\mathrm{HBr}}}
{p_{\mathrm{HCl}}p_{\mathrm{DBr}}}
```

である．
反応の前後で分子数はそれぞれ2分子で等しいため，理想気体では圧力を数密度に置き換えても $k_{\mathrm B}T$ の因子が相殺される．
したがって，この問題の平衡定数は

```math
K_p=K_c=
\frac{n_{\mathrm{DCl}}n_{\mathrm{HBr}}}
{n_{\mathrm{HCl}}n_{\mathrm{DBr}}}
```

と書ける．
ここで， $n_i$ は分子種 $i$ の数密度である．

統計力学では，化学平衡の条件から，平衡定数は各分子の単一分子分配関数 $f(i)$ を用いて

```math
\boxed{
K_p=
\frac{f(\mathrm{DCl})f(\mathrm{HBr})}
{f(\mathrm{HCl})f(\mathrm{DBr})}
}
\tag{1}
```

と表される．
単一分子分配関数は，並進，回転，振動などの独立な自由度の分配関数の積である．
電子状態や核スピンによる因子も含められるが，今回の反応では各元素が反応の前後で1回ずつ現れるため，それらの因子は同じ条件のもとで相殺される．

### 2．並進分配関数の寄与

質量 $m$ の分子の並進分配関数は，

```math
f_{\mathrm{trans}}(m)
=V\left(\frac{2\pi m k_{\mathrm B}T}{h^2}\right)^{3/2}
```

である．
ここで， $V$ は体積， $h$ は Planck 定数である．
式 (1) では体積および温度に共通する因子が相殺されるため，並進運動による寄与は

```math
\begin{aligned}
K_{\mathrm{trans}}
&=\left[
\frac{m(\mathrm{DCl})m(\mathrm{HBr})}
{m(\mathrm{HCl})m(\mathrm{DBr})}
\right]^{3/2}
\end{aligned}
\tag{2}
```

となる．
原子の質量を $m_{\mathrm H},m_{\mathrm D},m_{\mathrm{Cl}},m_{\mathrm{Br}}$ とすると，分子の質量は各原子の質量の和であるため，

```math
\boxed{
K_{\mathrm{trans}}
=
\left[
\frac{(m_{\mathrm D}+m_{\mathrm{Cl}})
(m_{\mathrm H}+m_{\mathrm{Br}})}
{(m_{\mathrm H}+m_{\mathrm{Cl}})
(m_{\mathrm D}+m_{\mathrm{Br}})}
\right]^{3/2}
}
\tag{3}
```

を得る．

### 3．回転分配関数の寄与

今回の分子はすべて異核二原子分子であるため，回転分配関数の高温近似は

```math
f_{\mathrm{rot}}(i)
\simeq\frac{8\pi^2 I_i k_{\mathrm B}T}{h^2}
```

である．
ここで， $I_i$ は分子 $i$ の慣性モーメントである．
温度に共通する因子が相殺されるので，回転分配関数の比は

```math
\begin{aligned}
K_{\mathrm{rot}}
&=\frac{I(\mathrm{DCl})I(\mathrm{HBr})}
{I(\mathrm{HCl})I(\mathrm{DBr})}
\end{aligned}
\tag{4}
```

となる．

二原子分子の慣性モーメントは

```math
I=\mu r^2
```

である．
ここで， $\mu$ は換算質量， $r$ は核間距離である．
同位体置換によって核間距離が変わらないと仮定すると，慣性モーメントは換算質量に比例する．
したがって，

```math
\boxed{
K_{\mathrm{rot}}
=\frac{\mu_{\mathrm{DCl}}\mu_{\mathrm{HBr}}}
{\mu_{\mathrm{HCl}}\mu_{\mathrm{DBr}}}
}
\tag{5}
```

となる．

### 4．振動分配関数の寄与

振動数を $\nu_i$ とする調和振動子の分配関数は，振動の零点エネルギーを除く表記では

```math
f_{\mathrm{vib}}(i)
=\frac{1}{1-e^{-h\nu_i/(k_{\mathrm B}T)}}
```

である．
十分高温で $h\nu_i\ll k_{\mathrm B}T$ ならば，

```math
1-e^{-h\nu_i/(k_{\mathrm B}T)}
\simeq\frac{h\nu_i}{k_{\mathrm B}T}
```

であるため，

```math
f_{\mathrm{vib}}(i)\simeq\frac{k_{\mathrm B}T}{h\nu_i}
```

となる．
したがって，振動分配関数による寄与は

```math
\boxed{
K_{\mathrm{vib}}
=\frac{\nu_{\mathrm{HCl}}\nu_{\mathrm{DBr}}}
{\nu_{\mathrm{DCl}}\nu_{\mathrm{HBr}}}
}
\tag{6}
```

である．
零点エネルギーを分配関数に含める表記でも，完全な高温極限では同じ結果が得られる．

分子の結合力が同じであると仮定すると，振動数 $\nu$ は換算質量 $\mu$ を用いて

```math
\nu\propto\frac{1}{\sqrt{\mu}}
```

と表される．
したがって，

```math
\begin{aligned}
K_{\mathrm{vib}}
&=
\frac{\mu_{\mathrm{DCl}}^{1/2}
\mu_{\mathrm{HBr}}^{1/2}}
{\mu_{\mathrm{HCl}}^{1/2}
\mu_{\mathrm{DBr}}^{1/2}}\\
&=
\left[
\frac{\mu_{\mathrm{DCl}}\mu_{\mathrm{HBr}}}
{\mu_{\mathrm{HCl}}\mu_{\mathrm{DBr}}}
\right]^{1/2}
\end{aligned}
\tag{7}
```

となる．

### 5．各自由度の寄与を組み合わせる

式 (1) より，平衡定数は並進，回転，振動の寄与を掛け合わせたものである．
式 (3)，(5)，(7) を組み合わせると，

```math
\begin{aligned}
K_p
={}&
\left[
\frac{(m_{\mathrm D}+m_{\mathrm{Cl}})
(m_{\mathrm H}+m_{\mathrm{Br}})}
{(m_{\mathrm H}+m_{\mathrm{Cl}})
(m_{\mathrm D}+m_{\mathrm{Br}})}
\right]^{3/2}\\
&\times
\left[
\frac{\mu_{\mathrm{DCl}}\mu_{\mathrm{HBr}}}
{\mu_{\mathrm{HCl}}\mu_{\mathrm{DBr}}}
\right]^{3/2}
\end{aligned}
\tag{8}
```

を得る．

ここで，二原子分子 $\mathrm{XY}$ の換算質量は

```math
\mu_{\mathrm{XY}}=\frac{m_{\mathrm X}m_{\mathrm Y}}
{m_{\mathrm X}+m_{\mathrm Y}}
```

である．
したがって，

```math
\begin{aligned}
&\frac{\mu_{\mathrm{DCl}}\mu_{\mathrm{HBr}}}
{\mu_{\mathrm{HCl}}\mu_{\mathrm{DBr}}}\\
&\quad=
\frac{
\frac{m_{\mathrm D}m_{\mathrm{Cl}}}{m_{\mathrm D}+m_{\mathrm{Cl}}}
\frac{m_{\mathrm H}m_{\mathrm{Br}}}{m_{\mathrm H}+m_{\mathrm{Br}}}
}{
\frac{m_{\mathrm H}m_{\mathrm{Cl}}}{m_{\mathrm H}+m_{\mathrm{Cl}}}
\frac{m_{\mathrm D}m_{\mathrm{Br}}}{m_{\mathrm D}+m_{\mathrm{Br}}}
}\\
&\quad=
\frac{(m_{\mathrm H}+m_{\mathrm{Cl}})
(m_{\mathrm D}+m_{\mathrm{Br}})}
{(m_{\mathrm D}+m_{\mathrm{Cl}})
(m_{\mathrm H}+m_{\mathrm{Br}})}
\end{aligned}
\tag{9}
```

となる．
これは式 (3) の角括弧内の質量比の逆数である．
ゆえに，式 (8) の二つの因子は相殺し，

```math
\begin{aligned}
K_p
&=
\left[
\frac{(m_{\mathrm D}+m_{\mathrm{Cl}})
(m_{\mathrm H}+m_{\mathrm{Br}})}
{(m_{\mathrm H}+m_{\mathrm{Cl}})
(m_{\mathrm D}+m_{\mathrm{Br}})}
\right]^{3/2}\\
&\quad\times
\left[
\frac{(m_{\mathrm H}+m_{\mathrm{Cl}})
(m_{\mathrm D}+m_{\mathrm{Br}})}
{(m_{\mathrm D}+m_{\mathrm{Cl}})
(m_{\mathrm H}+m_{\mathrm{Br}})}
\right]^{3/2}\\
&=1
\end{aligned}
```

を得る．

### 結論

同位体置換によって核間距離と結合力が変わらず，回転と振動が高温近似で扱えるとすると，並進，回転，振動の各分配関数に由来する質量依存性が互いに相殺する．
したがって，

```math
\boxed{
\lim_{T\to\infty}K_p=1
}
```

である．
つまり，十分高温では，この同位体交換反応の平衡定数は $1$ に近づく．
