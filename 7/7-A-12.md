# 演習問題【7-A-12】

## 解答

平衡定数を分子の分配関数を用いて表すことから出発する．
化学反応 $\text{HCl} + \text{DBr} \rightleftharpoons \text{DCl} + \text{HBr}$ における平衡定数 $K_p$（または $K_c$ ）は，各成分の数密度 $N$ または分配関数 $f$ を用いて次のように書ける．

$$K_p = K_c = \frac{N(\text{DCl}) N(\text{HBr})}{N(\text{HCl}) N(\text{DBr})} = \frac{f(\text{DCl}) f(\text{HBr})}{f(\text{HCl}) f(\text{DBr})}$$

ここで，各分子の分配関数 $f$ は，並進，回転，および振動の各自由度に関する分配関数の積として近似できる．

$$f \approx f_{\text{trans}} f_{\text{rot}} f_{\text{vib}}$$

高温極限（ $kT$ が回転や振動のエネルギー準位に対して十分に大きい場合）における各分配関数の温度依存性と質量依存性を考える．

1. **並進分配関数 ( $f_{\text{trans}}$ ):**
   並進分配関数は，分子の質量 $m$ に対して $f_{\text{trans}} \propto m^{3/2}$ の依存性を持つ．
   したがって，平衡定数に含まれる並進部分の比は次のようになる．
```math
\text{Ratio}_{\text{trans}} = \frac{f_{\text{trans}}(\text{DCl}) f_{\text{trans}}(\text{HBr})}{f_{\text{trans}}(\text{HCl}) f_{\text{trans}}(\text{DBr})} = \left[ \frac{m(\text{DCl}) m(\text{HBr})}{m(\text{HCl}) m(\text{DBr})} \right]^{3/2}
```

2. **回転分配関数 ( $f_{\text{rot}}$ ):**
   高温において，回転分配関数は慣性モーメント $I$ に比例する ( $f_{\text{rot}} \propto I$ )．
   同位元素置換によって分子の核間距離 $r$ および結合力（力の定数）が変化しないと仮定すると，慣性モーメント $I = \mu r^2$ は換算質量 $\mu$ にのみ比例する．
   したがって，回転部分の比は次のようになる．
```math
\text{Ratio}_{\text{rot}} = \frac{f_{\text{rot}}(\text{DCl}) f_{\text{rot}}(\text{HBr})}{f_{\text{rot}}(\text{HCl}) f_{\text{rot}}(\text{DBr})} = \frac{I(\text{DCl}) I(\text{HBr})}{I(\text{HCl}) I(\text{DBr})} = \frac{\mu(\text{DCl}) \mu(\text{HBr})}{\mu(\text{HCl}) \mu(\text{DBr})}
```

3. **振動分配関数 ( $f_{\text{vib}}$ ):**
   振動エネルギー準位が $h\nu \ll kT$ を満たす高温極限では，振動分配関数は振動数 $\nu$ に対して $f_{\text{vib}} \propto \frac{kT}{h\nu} \propto \nu^{-1}$ の依存性を持つ．
   振動数は換算質量 $\mu$ に対して $\nu \propto \mu^{-1/2}$ であるため， $f_{\text{vib}} \propto \mu^{1/2}$ となる．
   したがって，振動部分の比は次のようになる．
```math
\text{Ratio}_{\text{vib}} = \frac{f_{\text{vib}}(\text{DCl}) f_{\text{vib}}(\text{HBr})}{f_{\text{vib}}(\text{HCl}) f_{\text{vib}(\text{DBr})} } = \frac{\nu(\text{HCl}) \nu(\text{DBr})}{\nu(\text{DCl}) \nu(\text{HBr})} = \frac{\mu(\text{DCl})^{1/2} \mu(\text{HBr})^{1/2}}{\mu(\text{HCl})^{1/2} \mu(\text{DBr})^{1/2}} = \left[ \frac{\mu(\text{DCl}) \mu(\text{HBr})}{\mu(\text{HCl}) \mu(\text{DBr})} \right]^{1/2}
```

これらをすべて掛け合わせると，平衡定数は次のようになる．

$$K = \text{Ratio}_{\text{trans}} \cdot \text{Ratio}_{\text{rot}} \cdot \text{Ratio}_{\text{vib}}$$

$$K = \left[ \frac{m(\text{DCl}) m(\text{HBr})}{m(\text{HCl}) m(\text{DBr})} \right]^{3/2} \cdot \frac{\mu(\text{DCl}) \mu(\text{HBr})}{\mu(\text{HCl}) \mu(\text{DBr})} \cdot \left[ \frac{\mu(\text{DCl}) \mu(\text{HBr})}{\mu(\text{HCl}) \mu(\text{DBr})} \right]^{1/2}$$

$$K = \left[ \frac{m(\text{DCl}) m(\text{HBr})}{m(\text{HCl}) m(\text{DBr})} \right]^{3/2} \left[ \frac{\mu(\text{DCl}) \mu(\text{HBr})}{\mu(\text{HCl}) \mu(\text{DBr})} \right]^{3/2}$$

ここで，換算質量 $\mu$ と分子の全質量 $m$ の関係 $\mu = \frac{m_1 m_2}{m_1 + m_2}$ を用いると，

$$\frac{m(\text{DCl}) m(\text{HBr})}{m(\text{HCl}) m(\text{DBr})} = \frac{(m_{\text{D}} + m_{\text{Cl}})(m_{\text{H}} + m_{\text{Br}})}{(m_{\text{H}} + m_{\text{Cl}})(m_{\text{D}} + m_{\text{Br}})}$$

であり，

$$\frac{\mu(\text{DCl}) \mu(\text{HBr})}{\mu(\text{HCl}) \mu(\text{DBr})} = \frac{\frac{m_{\text{D}} m_{\text{Cl}}}{m_{\text{D}} + m_{\text{Cl}}} \cdot \frac{m_{\text{H}} m_{\text{Br}}}{m_{\text{H}} + m_{\text{Br}}}}{\frac{m_{\text{H}} m_{\text{Cl}}}{m_{\text{H}} + m_{\text{Cl}}} \cdot \frac{m_{\text{D}} m_{\text{Br}}}{m_{\text{D}} + m_{\text{Br}}}} = \frac{m_{\text{D}} m_{\text{Cl}} m_{\text{H}} m_{\text{Br}}}{m_{\text{H}} m_{\text{Cl}} m_{\text{D}} m_{\text{Br}}} \cdot \frac{(m_{\text{H}} + m_{\text{Cl}})(m_{\text{D}} + m_{\text{Br}})}{(m_{\text{D}} + m_{\text{Cl}})(m_{\text{H}} + m_{\text{Br}})} = \frac{(m_{\text{H}} + m_{\text{Cl}})(m_{\text{D}} + m_{\text{Br}})}{(m_{\text{D}} + m_{\text{Cl}})(m_{\text{H}} + m_{\text{Br}})}$$

となる．
したがって，

$$K = \left[ \frac{(m_{\text{D}} + m_{\text{Cl}})(m_{\text{H}} + m_{\text{Br}})}{(m_{\text{H}} + m_{\text{Cl}})(m_{\text{D}} + m_{\text{Br}})} \right]^{3/2} \cdot \left[ \frac{(m_{\text{H}} + m_{\text{Cl}})(m_{\text{D}} + m_{\text{Br}})}{(m_{\text{D}} + m_{\text{Cl}})(m_{\text{H}} + m_{\text{Br}})} \right]^{3/2} = 1$$

となる．
これにより，十分高温において平衡定数が $1$ となることが示された．

## 解説

本問題の核心は，同位元素置換（isotopic substitution）が物理的な性質（分子のポテンシャルエネルギー曲面）にほとんど影響を与えないという仮定に基づき，分配関数の質量依存性を正確に扱う点にある．

### 1.  同位元素置換の物理的意義

原子の核の種類が変わっても（例えば $\text{H}$ が $\text{D}$ に変わっても），電子配置は変わらないため，分子間の相互作用（結合力）や平衡核間距離 $r$ はほぼ一定とみなせる．
これにより，慣性モーメント $I$ や振動数 $\nu$ の変化は，質量（および換算質量 $\mu$ ）の変化のみに由来すると整理できる．

### 2.  分配関数の分解

統計力学において，分子の全分配関数は各自由度の独立性を仮定して積の形で書ける．
高温では，回転や振動のエネルギー間隔が熱エネルギー $kT$ に比べて無視できるほど小さくなるため，連続的な分布として近似できる．
- **並進:** 全質量 $m$ のみの関数．
- **回転:** 慣性モーメント $I \propto \mu$ の関数．
- **振動:** 振動数 $\nu \propto \mu^{-1/2}$ に依存し，高温では $\nu^{-1}$ に比例する．

### 3.  計算のポイント:

平衡定数は「生成物の分配関数の積」と「反応物の分配関数の積」の比である．
各自由度ごとに比を計算し，それらを最後に統合する．
特に，並進部分の質量比と，回転・振動部分から導かれる換算質量の比が互いに逆数関係（ $X$ と $1/X$ ）にあることを利用すると，最終的な結果が $1$ になることが簡潔に示せる．
