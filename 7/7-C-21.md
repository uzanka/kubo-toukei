# 演習問題【7-C-21】

## 解答

実在気体の熱力学的ポテンシャルおよび熱容量について，理想気体からのずれの最低次の補正項を求める．

### 1. 設定と準備

まず，与えられた式 (7.31) および (7.30) を確認する．

$$\log Z_N = V \sum_{l=1}^{\infty} b_l \zeta^l - N \log \zeta + N \log \left\{ \left( \frac{2\pi mkT}{h^2} \right)^{3/2} j \right\} \quad \cdots (1)$$

$$\sum_{l=1}^{\infty} l b_l \zeta^l = \frac{N}{V} \equiv v^{-1} \quad \cdots (2)$$

ここで， $v = V/N$ は 1 粒子あたりの体積であり，比計量（specific volume）と呼ばれる．
また， $b_l$ は virial 係数， $j$ はある温度依存性を持つ関数である．
式 (2) において， $b_1 = 1$ であることを用いると，

$$\zeta + 2b_2 \zeta^2 + 3b_3 \zeta^3 + \dots = v^{-1} \quad \cdots (3)$$

と書ける．

理想気体の場合，実在気体としての補正がないため $b_l = 0 \ (l \ge 2)$ である．
このとき，式 (3) は $\zeta = v^{-1}$ となり， $\zeta$ は比計量の逆数に一致する．
実在気体の場合， $\zeta$ は $v$ の関数として近似的に求められる．
式 (3) を $\zeta$ について解くために， $\zeta \approx v^{-1}$ という第 1 近似を右辺に代入する．

$$\zeta \approx v^{-1} - 2b_2 (v^{-1})^2 = v^{-1} - 2b_2 v^{-2} \quad \cdots (4)$$

これが $\zeta$ の $v^{-1}$ の次数の補正を含む近似式である．

### 2. Helmholtz 自由エネルギー $F$ の導出

Helmholtz 自由エネルギーは $F = -kT \log Z_N$ で定義される．
式 (1) に式 (4) を代入する．
まず， $\log Z_N$ の各項を計算する．

第 1 項：

$$V \sum_{l=1}^{\infty} b_l \zeta^l = Nv ( \zeta + b_2 \zeta^2 + \dots ) \approx Nv ( (v^{-1} - 2b_2 v^{-2}) + b_2 (v^{-1})^2 ) = Nv ( v^{-1} - b_2 v^{-2} ) = N(1 - b_2 v^{-1})$$

第 2 項：

$$-N \log \zeta \approx -N \log (v^{-1} - 2b_2 v^{-2}) = -N \log \{ v^{-1} (1 - 2b_2 v^{-1}) \} = -N [ -\log v + \log(1 - 2b_2 v^{-1}) ] \approx N \log v + 2N b_2 v^{-1}$$

これらを合わせると，

$$\log Z_N \approx N(1 - b_2 v^{-1}) + N \log v + 2N b_2 v^{-1} + N \log \left\{ \left( \frac{2\pi mkT}{h^2} \right)^{3/2} j \right\}$$

$$\log Z_N \approx N \log v + N \log \left\{ \left( \frac{2\pi mkT}{h^2} \right)^{3/2} j \right\} + N(1 + b_2 v^{-1})$$

したがって，

$$F = -NkT \left[ \log \left\{ \left( \frac{2\pi mkT}{h^2} \right)^{3/2} jv \right\} + (1 + b_2 v^{-1}) \right] \quad \cdots (5)$$

が得られる．
これは理想気体の項（対数項）に，実在気体による補正項 $(1 + b_2 v^{-1})$ が加わった形である．

### 3. 各種熱力学量の導出

#### 圧力 $p$

圧力は $p = -\left( \frac{\partial F}{\partial V} \right)_T$ で与えられる．
$V = Nv$ より $\frac{\partial}{\partial V} = \frac{1}{N} \frac{\partial}{\partial v}$ であるから，

$$p = -\frac{1}{N} \frac{\partial F}{\partial v} = \frac{kT}{N} \frac{\partial}{\partial v} \{ N \log(jv) + N(1 + b_2 v^{-1}) \}$$

$$p = kT \left[ \frac{1}{v} - b_2 v^{-2} + \dots \right] = \frac{kT}{v} (1 - b_2 v^{-1}) \quad \cdots (6)$$

#### Gibbs 自由エネルギー $G$

$G = F + pV$ である．
$pV = ( \frac{kT}{v} (1 - b_2 v^{-1}) ) (Nv) = NkT (1 - b_2 v^{-1})$ であるから，

$$G = -NkT \left[ \log \left\{ \left( \frac{2\pi mkT}{h^2} \right)^{3/2} jv \right\} + (1 + b_2 v^{-1}) \right] + NkT (1 - b_2 v^{-1})$$

$$G = -NkT \left[ \log \left\{ \left( \frac{2\pi mkT}{h^2} \right)^{3/2} jv \right\} + 2b_2 v^{-1} \right] \quad \cdots (7)$$

#### エントロピー $S$

$S = -\left( \frac{\partial F}{\partial T} \right)_v$ である．
$F$ の式を展開すると，

$$F = -NkT \log \left\{ \left( \frac{2\pi mkT}{h^2} \right)^{3/2} jv \right\} - NkT(1 + b_2 v^{-1})$$

これを $T$ で微分する．

$$S = Nk \left[ \log \left\{ \left( \frac{2\pi mkT}{h^2} \right)^{3/2} jv \right\} + \frac{3}{2} + T \frac{\partial}{\partial T} (\log j) \right] + Nk \left[ 1 + \frac{\partial}{\partial T} (Tb_2) v^{-1} \right]$$

整理すると，

$$S = Nk \left[ \log \left\{ \left( \frac{2\pi mkT}{h^2} \right)^{3/2} jv \right\} + \frac{3}{2} + T \frac{\partial \log j}{\partial T} + 1 + \frac{\partial (Tb_2)}{\partial T} v^{-1} \right] \quad \cdots (8)$$

#### 内部エネルギー $U$

$U = F + TS$ である．

$$U = -NkT \log \{ \dots \} - NkT(1 + b_2 v^{-1}) + T \cdot Nk [ \log \{ \dots \} + \frac{3}{2} + T \frac{\partial \log j}{\partial T} + 1 + \frac{\partial (Tb_2)}{\partial T} v^{-1} ]$$

対数項が打ち消し合い，

$$U = NkT \left[ \frac{3}{2} - T \frac{\partial \log j}{\partial T} + T \frac{\partial b_2}{\partial T} v^{-1} \right] \quad \cdots (9)$$

（第 1 項の $-NkT(1 + b_2 v^{-1})$ と第 2 項の $NkT(1 + \frac{\partial (Tb_2)}{\partial T} v^{-1})$ の和が $NkT [ -b_2 + \frac{\partial (Tb_2)}{\partial T} ] v^{-1} = NkT [ -b_2 + b_2 + T \frac{\partial b_2}{\partial T} ] v^{-1} = NkT (T \frac{\partial b_2}{\partial T} v^{-1})$ となる．）

#### エンタルピー $H$

$H = G + TS$ である．
$G$ と $S$ の式を用いると，

$$H = -NkT \left[ \log \{ \dots \} + 2b_2 v^{-1} \right] + NkT \left[ \log \{ \dots \} + \frac{5}{2} + T \frac{\partial \log j}{\partial T} + \frac{\partial (Tb_2)}{\partial T} v^{-1} \right]$$

$$H = NkT \left[ \frac{5}{2} - T \frac{\partial \log j}{\partial T} - 2b_2 v^{-1} + \frac{\partial (Tb_2)}{\partial T} v^{-1} \right]$$

$$H = NkT \left[ \frac{5}{2} - T \frac{\partial \log j}{\partial T} - (b_2 - T \frac{\partial b_2}{\partial T}) v^{-1} \right] \quad \cdots (10)$$

#### 定積比熱 $C_v$ と定圧比熱 $C_p$

理想気体の内部自由度（回転・振動など）による比熱寄与を $C_i$ とする（ $C_i = Nk \cdot \frac{\partial}{\partial T} \left[ T^2 \frac{\partial \log j}{\partial T} \right]$ ）．
このとき， $U = U_{ideal} + \Delta U$ と書けて，

$$C_v = \left( \frac{\partial U}{\partial T} \right)_v = \frac{3}{2} Nk + C_i + \frac{\partial}{\partial T} \left( T^2 \frac{\partial b_2}{\partial T} \right) \cdot v^{-1} + \dots \quad \cdots (11)$$

同様に $C_p = \left( \frac{\partial H}{\partial T} \right)_p$ を計算すると，

$$C_p = \frac{5}{2} Nk + C_i + \frac{\partial}{\partial T} \left\{ T^3 \frac{\partial}{\partial T} \left( \frac{b_2}{T} \right) \right\} v^{-1} + \dots \quad \cdots (12)$$

が得られる．

## 解説

本問題は，実在気体の状態方程式における virial 展開を用いて，熱力学的な諸量を理想気体からの補正として求めるものである．

重要なポイントは以下の通りである．

1.  **Virial 展開と $\zeta$ の関係**:
  実在気体の粒子間の相互作用を $b_l$ という係数で表す．
  $\zeta$ は $v$ の関数であるが，これを $v$ のべき級数として近似的に求めることが計算の第一歩となる．
2.  **自由エネルギーの補正**:
  Helmholtz 自由エネルギー $F$ には，理想気体としての寄与（対数項）と，粒子間の相互作用に由来する補正項 $(1 + b_2 v^{-1})$ が現れる．
3.  **熱力学関係式の活用**:
  一度 $F$ を求めれば，微分操作を通じて圧力 $p$ ，エントロピー $S$ ，内部エネルギー $U$ などの他の全ての量にアクセスできる．
4.  **比熱の補正**:
  比熱はエネルギーの温度微分であるため，温度に依存する virial 係数 $b_2(T)$ の微分項が重要な役割を果たす．

このように，実在気体の補正は比計量 $v$ の逆数 $v^{-1}$ に比例する形で現れることがわかる．
