# 演習問題【7-C-21】

## 解答

実在気体の Helmholtz 自由エネルギー $F$ ，Gibbs 自由エネルギー $G$ ，エントロピー $S$ ，内部エネルギー $U$ ，エンタルピー $H$ ，定積熱容量 $C_V$ ，定圧熱容量 $C_p$ について，理想気体からのずれの最低次の補正項を求める．

以下では，粒子数を $N$ ，体積を $V$ ，温度を $T$ とし，1粒子当たりの体積を

```math
v=\frac VN
```

と定義する．
また，最低次の補正である $1/v$ の項までを残し，それより高次の項は省略する．

### 1．大分配関数から Helmholtz 自由エネルギーを求める

問題文の式 (7.31)，(7.30) より，

```math
\ln Z_N
=
V\sum_{l=1}^{\infty}b_l\zeta^l
-N\ln\zeta
+N\ln\left[
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}j(T)
\right]
\tag{1}
```

および

```math
\sum_{l=1}^{\infty}l b_l\zeta^l
=\frac NV=\frac1v
\tag{2}
```

が成り立つ．
ここで， $\zeta$ は fugacity に対応する無次元の変数， $b_l$ は大分配関数の展開係数， $j(T)$ は分子の内部自由度に関する分配関数である．

$b_1=1$ を用いると，式 (2) は

```math
\zeta+2b_2\zeta^2+3b_3\zeta^3+\cdots=\frac1v
```

となる．
最低次の補正まで求めるため， $\zeta\simeq1/v$ として高次項を無視すると，

```math
\boxed{
\zeta=\frac1v-\frac{2b_2}{v^2}
+O(v^{-3})
}
\tag{3}
```

を得る．

次に，Helmholtz 自由エネルギーは

```math
F=-kT\ln Z_N
```

で定義される．
式 (1) に式 (3) を代入する．
まず，

```math
\begin{aligned}
V\sum_{l=1}^{\infty}b_l\zeta^l
&=Nv(\zeta+b_2\zeta^2+\cdots)\\
&=N\left(1-\frac{b_2}{v}\right)
+O(v^{-2})
\end{aligned}
```math

である．
また，

```math
\begin{aligned}
-N\ln\zeta
&=-N\ln\left[
\frac1v\left(1-\frac{2b_2}{v}\right)
\right]\\
&=N\ln v+\frac{2Nb_2}{v}
+O(v^{-2})
\end{aligned}
```

となる．
これらを式 (1) に代入して整理すると，

```math
\ln Z_N
=
N\left[
\ln\left\{
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
j(T)v
\right\}
+1+\frac{b_2}{v}
\right]
+O(v^{-2})
```

を得る．
したがって，

```math
\boxed{
F=-NkT\left[
\ln\left\{
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
j(T)v
\right\}
+1+\frac{b_2(T)}{v}
\right]+O(v^{-2})
}
\tag{4}
```

である．
ここで， $b_2$ が温度に依存することを明示するため， $b_2=b_2(T)$ と書いた．

以降の計算を簡潔にするため，

```math
L(T,v)=
\ln\left[
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
j(T)v
\right]
```

とおく．
式 (4) は

```math
F=-NkT\left[L+1+\frac{b_2}{v}\right]
```

と表せる．

### 2．圧力 $p$

圧力は Helmholtz 自由エネルギーから

```math
p=-\left(\frac{\partial F}{\partial V}\right)_{T,N}
```

で求められる．
$V=Nv$ であるから，

```math
\left(\frac{\partial}{\partial V}\right)_{T,N}
=\frac1N\left(\frac{\partial}{\partial v}\right)_{T,N}
```

である．
式 (4) より，

```math
\begin{aligned}
p
&=-\frac1N\frac{\partial F}{\partial v}\\
&=kT\left(\frac1v-\frac{b_2}{v^2}\right)
+O(v^{-3}).
\end{aligned}
```

したがって，

```math
\boxed{
p=\frac{kT}{v}
\left(1-\frac{b_2}{v}\right)
+O(v^{-3})
}
\tag{5}
```

である．
第1項は理想気体の状態方程式であり，第2項が分子間相互作用による最低次の補正である．

### 3．Gibbs 自由エネルギー $G$

Gibbs 自由エネルギーは

```math
G=F+pV
```

で定義される．
式 (5) から，

```math
pV=NkT\left(1-\frac{b_2}{v}\right)
+O(v^{-2})
```

である．
これを式 (4) に代入すると，

```math
\begin{aligned}
G
&=-NkT\left[L+1+\frac{b_2}{v}\right]
+NkT\left(1-\frac{b_2}{v}\right)
+O(v^{-2})\\
&=-NkT\left[L+\frac{2b_2}{v}\right]
+O(v^{-2}).
\end{aligned}
```

よって，

```math
\boxed{
G=-NkT\left[
\ln\left\{
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
j(T)v
\right\}
+\frac{2b_2}{v}
\right]
+O(v^{-2})
}
\tag{6}
```

となる．

### 4．エントロピー $S$

エントロピーは

```math
S=-\left(\frac{\partial F}{\partial T}\right)_{V,N}
```

である．
ここでは $V,N$ が一定なので， $v=V/N$ も一定である．

対数項 $L$ の温度微分は

```math
T\frac{\partial L}{\partial T}
=\frac32+T\frac{d\ln j}{dT}
```

である．
さらに，

```math
\frac{d}{dT}(Tb_2)
=b_2+T\frac{db_2}{dT}
```

を用いると，式 (4) より

```math
\begin{aligned}
S
=Nk\bigg[
&L+\frac32+T\frac{d\ln j}{dT}\\
&+1+\frac1v\frac{d(Tb_2)}{dT}
\bigg]+O(v^{-2})
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\begin{aligned}
S=Nk\bigg[
&\ln\left\{
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
j(T)v
\right\}
+\frac52+T\frac{d\ln j}{dT}\\
&+\frac1v\left(b_2+T\frac{db_2}{dT}\right)
\bigg]+O(v^{-2})
\end{aligned}
}
\tag{7}
```

を得る．

### 5．内部エネルギー $U$

内部エネルギーは

```math
U=F+TS
```

で与えられる．
式 (4)，(7) を代入すると，対数項と定数項が相殺され，

```math
\boxed{
U=NkT\left[
\frac32+T\frac{d\ln j}{dT}
+\frac{T}{v}\frac{db_2}{dT}
\right]+O(v^{-2})
}
\tag{8}
```

となる．

特に，内部自由度に由来する項は

```math
+T\frac{d\ln j}{dT}
```

であり，符号は正である．
これは $j(T)$ が内部状態の分配関数として定義されていることによる．
したがって，解答例および提示された解答にある $-T\,d\ln j/dT$ は符号の誤りである．

### 6．エンタルピー $H$

エンタルピーは

```math
H=U+pV
```

である．
式 (5)，(8) を用いると，

```math
\begin{aligned}
H
&=NkT\left[
\frac32+T\frac{d\ln j}{dT}
+\frac{T}{v}\frac{db_2}{dT}
\right]\\
&\quad+NkT\left(1-\frac{b_2}{v}\right)
+O(v^{-2})
\end{aligned}
```

となる．
よって，

```math
\boxed{
H=NkT\left[
\frac52+T\frac{d\ln j}{dT}
+\frac1v\left(
T\frac{db_2}{dT}-b_2
\right)
\right]+O(v^{-2})
}
\tag{9}
```

を得る．
ここでも，内部自由度の寄与は正の符号である．

### 7．定積熱容量 $C_V$

定積熱容量は

```math
C_V=\left(\frac{\partial U}{\partial T}\right)_{V,N}
```

で定義される．
式 (8) を温度で微分する．
$v$ は一定であるため，

```math
C_V=
\frac32Nk+
Nk\frac{d}{dT}
\left(T^2\frac{d\ln j}{dT}\right)
+\frac{Nk}{v}\frac{d}{dT}
\left(T^2\frac{db_2}{dT}\right)
+O(v^{-2})
```

となる．
ここで，内部自由度に由来する熱容量を

```math
C_i=
Nk\frac{d}{dT}
\left(T^2\frac{d\ln j}{dT}\right)
```

と定義すれば，

```math
\boxed{
C_V=
\frac32Nk+C_i
+\frac{Nk}{v}\frac{d}{dT}
\left(T^2\frac{db_2}{dT}\right)
+O(v^{-2})
}
\tag{10}
```

である．

### 8．定圧熱容量 $C_p$

定圧熱容量は

```math
C_p=\left(\frac{\partial H}{\partial T}\right)_{p,N}
```

で定義される．
ここでは圧力 $p$ が一定なので，温度の変化に伴って $v$ も変化する点に注意しなければならない．
この変化を無視して式 (9) を単純に温度微分すると，正しい $C_p$ は得られない．

式 (9) の補正項は

```math
H_{\mathrm{ex}}
=NkT\left(T\frac{db_2}{dT}-b_2\right)\frac1v
```

である．
最低次の補正を求めるとき，状態方程式 (5) より，密度の最低次近似は

```math
\frac1v=\frac{p}{kT}+O(p^2)
```

である．
これを $H_{\mathrm{ex}}$ に代入すると，

```math
H_{\mathrm{ex}}
=Np\left(T\frac{db_2}{dT}-b_2\right)+O(p^2)
```

となる．
圧力を一定にして温度微分すると，

```math
\begin{aligned}
\left(\frac{\partial H_{\mathrm{ex}}}{\partial T}\right)_p
&=Np\frac{d}{dT}
\left(T\frac{db_2}{dT}-b_2\right)+O(p^2)\\
&=NpT\frac{d^2b_2}{dT^2}+O(p^2).
\end{aligned}
```

さらに，最低次では $p\simeq kT/v$ であるから，

```math
NpT\frac{d^2b_2}{dT^2}
\simeq
\frac{NkT^2}{v}\frac{d^2b_2}{dT^2}.
```

したがって，

```math
\boxed{
C_p=
\frac52Nk+C_i
+\frac{NkT^2}{v}\frac{d^2b_2}{dT^2}
+O(v^{-2})
}
\tag{11}
```

を得る．

この式は，解答例に記載された定圧熱容量の補正項とは一致しない．
定圧条件での体積変化を考慮すると，最低次の補正は $NkT^2b_2''/v$ となる．
また，系全体の熱容量を表しているため，補正項には $Nk$ が必要である．

### 9．理想気体からの補正のまとめ

以上の結果を，理想気体の値と補正項に分けてまとめる．

| 熱力学量 | 理想気体からの補正を含む式 |
|---|---|
| Helmholtz 自由エネルギー $F$ | $\displaystyle -NkT\left[L+1+\frac{b_2}{v}\right]$ |
| Gibbs 自由エネルギー $G$ | $\displaystyle -NkT\left[L+\frac{2b_2}{v}\right]$ |
| エントロピー $S$ | $\displaystyle Nk\left[L+\frac52+T\frac{d\ln j}{dT}+\frac{b_2+Tb_2'}{v}\right]$ |
| 内部エネルギー $U$ | $\displaystyle NkT\left[\frac32+T\frac{d\ln j}{dT}+\frac{Tb_2'}{v}\right]$ |
| エンタルピー $H$ | $\displaystyle NkT\left[\frac52+T\frac{d\ln j}{dT}+\frac{Tb_2'-b_2}{v}\right]$ |
| 定積熱容量 $C_V$ | $\displaystyle \frac32Nk+C_i+\frac{Nk}{v}\frac{d}{dT}(T^2b_2')$ |
| 定圧熱容量 $C_p$ | $\displaystyle \frac52Nk+C_i+\frac{NkT^2}{v}b_2''$ |

ここで，

```math
L=\ln\left[
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
j(T)v
\right],
\qquad
b_2'=\frac{db_2}{dT},
\qquad
b_2''=\frac{d^2b_2}{dT^2}
```

であり，表ではいずれも $O(v^{-2})$ 以上の項を省略している．

この結果から，最低次の実在気体補正は，Helmholtz 自由エネルギーと Gibbs 自由エネルギーでは $b_2/v$ に比例し，内部エネルギーとエンタルピーでは $b_2(T)$ の温度微分に依存することが分かる．
また，比熱の補正には，それぞれ $b_2(T)$ の温度微分が現れる．
