# 演習問題【7-A-10】

## 解答

窒素分子の解離反応

```math
\mathrm{N_2}\rightleftharpoons 2\mathrm N
```

について，温度 $T=5000\ \mathrm K$ における平衡定数

```math
K_p=\frac{p_{\mathrm N}^2}{p_{\mathrm{N_2}}}
```

を求める．
ここで， $p_{\mathrm N}$ と $p_{\mathrm{N_2}}$ はそれぞれ窒素原子と窒素分子の分圧である．
解離エネルギー $D_0=169.3\ \mathrm{kcal/mol}$ は，振動の零点エネルギーの補正を含む値である．

### 1．平衡定数と分配関数の関係

理想気体の状態方程式より，

```math
p_i=n_i k_{\mathrm B}T
```

である．
ここで， $n_i$ は粒子 $i$ の数密度， $k_{\mathrm B}$ は Boltzmann 定数である．
したがって，

```math
\begin{aligned}
K_p
&=\frac{(n_{\mathrm N}k_{\mathrm B}T)^2}
{n_{\mathrm{N_2}}k_{\mathrm B}T}\\
&=k_{\mathrm B}T\frac{n_{\mathrm N}^2}{n_{\mathrm{N_2}}}
\end{aligned}
\tag{1}
```

となる．

統計力学では，化学平衡条件と各化学種の分配関数を用いることで，数密度の比を求めることができる．
各分子・原子の分配関数を並進運動と内部自由度に分けると，式 (1) は

```math
\begin{aligned}
K_p={}&k_{\mathrm B}T
\frac{(q_{\mathrm{trans,N}}/V)^2}
{q_{\mathrm{trans,N_2}}/V}\\
&\times
\frac{e(\mathrm N)^2}
{e(\mathrm{N_2})q_{\mathrm{rot}}(\mathrm{N_2})
q_{\mathrm{vib}}(\mathrm{N_2})}
e^{-D_0/(RT)}
\end{aligned}
\tag{2}
```

と表される．
ここで， $q_{\mathrm{trans}}$ は並進分配関数， $q_{\mathrm{rot}}$ は回転分配関数， $q_{\mathrm{vib}}$ は振動分配関数， $e$ は電子分配関数である．
$D_0$ はモルあたりのエネルギーであるため，解離の Boltzmann 因子は $e^{-D_0/(RT)}$ となる．
分子1個あたりのエネルギーを用いる場合は，同じ因子を $e^{-D_0/(N_{\mathrm A}k_{\mathrm B}T)}$ と表すことができる．

### 2．各分配関数の計算

#### 2.1　並進分配関数

質量 $m_i$ の粒子の並進分配関数は，

```math
\frac{q_{\mathrm{trans},i}}{V}
=\left(\frac{2\pi m_i k_{\mathrm B}T}{h^2}\right)^{3/2}
```

である．
ここで， $h$ は Planck 定数である．
窒素原子の質量を $m_{\mathrm N}$ ，窒素分子の質量を $2m_{\mathrm N}$ とすると，

```math
\begin{aligned}
&\frac{(q_{\mathrm{trans,N}}/V)^2}
{q_{\mathrm{trans,N_2}}/V}\\
&\quad=
\frac{(2\pi m_{\mathrm N}k_{\mathrm B}T/h^2)^3}
{(4\pi m_{\mathrm N}k_{\mathrm B}T/h^2)^{3/2}}\\
&\quad=
\left(\frac{\pi m_{\mathrm N}k_{\mathrm B}T}{h^2}\right)^{3/2}
\end{aligned}
\tag{3}
```

を得る．

#### 2.2　回転分配関数

窒素分子は同核二原子分子であるため，対称数は $\sigma=2$ である．
回転特性温度は $\Theta_r=2.84\ \mathrm K$ であり， $T=5000\ \mathrm K$ はこれより十分に高いため，回転運動には古典近似を用いることができる．
したがって，

```math
q_{\mathrm{rot}}(\mathrm{N_2})
\simeq\frac{T}{2\Theta_r}
```

となる．
よって，平衡定数に含まれる回転分配関数の逆数は，

```math
\frac{1}{q_{\mathrm{rot}}(\mathrm{N_2})}
\simeq\frac{2\Theta_r}{T}
\tag{4}
```

である．

#### 2.3　振動分配関数

窒素分子の振動特性温度は $\Theta_v=3.35\times10^3\ \mathrm K$ である．
解離エネルギー $D_0$ は零点エネルギーの補正を含むため，振動分配関数には零点エネルギーを除いた形を用いる．
したがって，

```math
q_{\mathrm{vib}}(\mathrm{N_2})
=\frac{1}{1-e^{-\Theta_v/T}}
```

であり，

```math
\frac{1}{q_{\mathrm{vib}}(\mathrm{N_2})}
=1-e^{-\Theta_v/T}
\tag{5}
```

となる．

#### 2.4　電子分配関数

問題文より，窒素分子の基底電子状態は縮重していないため，

```math
e(\mathrm{N_2})=1
```

である．
一方，窒素原子は電子スピンによって4重に縮重しているため，

```math
e(\mathrm N)=4
```

である．
したがって，

```math
\frac{e(\mathrm N)^2}{e(\mathrm{N_2})}
=\frac{4^2}{1}=16
\tag{6}
```

を得る．
生成物は窒素原子2個であるため，電子縮重度も $4^2$ となる点に注意する．

### 3．平衡定数の式

式 (3)～(6) を式 (2) に代入すると，

```math
\begin{aligned}
K_p(T)={}&k_{\mathrm B}T
\left(\frac{\pi m_{\mathrm N}k_{\mathrm B}T}{h^2}\right)^{3/2}
\frac{2\Theta_r}{T}\\
&\times(1-e^{-\Theta_v/T})
\times16\,e^{-D_0/(RT)}
\end{aligned}
\tag{7}
```

となる．
ここで，

```math
k_{\mathrm B}T\frac{2\Theta_r}{T}
=2k_{\mathrm B}\Theta_r
```

であるから，式 (7) は

```math
\boxed{
\begin{aligned}
K_p(T)={}&
\left(\frac{\pi m_{\mathrm N}k_{\mathrm B}T}{h^2}\right)^{3/2}
(2k_{\mathrm B}\Theta_r)\\
&\times16(1-e^{-\Theta_v/T})
e^{-D_0/(RT)}
\end{aligned}
}
\tag{8}
```

と整理できる．
特に，式 (8) には独立した $k_{\mathrm B}T$ の因子は残らない．

### 4．数値計算

与えられた定数と条件は，

```math
\begin{aligned}
T&=5000\ \mathrm K,\\
D_0&=169.3\ \mathrm{kcal/mol},\\
\Theta_r&=2.84\ \mathrm K,\\
\Theta_v&=3350\ \mathrm K
\end{aligned}
```

である．
c.g.s. 単位系で，

```math
\begin{aligned}
k_{\mathrm B}&=1.3806\times10^{-16}\ \mathrm{erg/K},\\
h&=6.626\times10^{-27}\ \mathrm{erg\,s},\\
m_{\mathrm N}&=14.01\times1.6605\times10^{-24}\\
&\simeq2.326\times10^{-23}\ \mathrm g,\\
R&=1.987\times10^{-3}\ \mathrm{kcal/(mol\,K)}
\end{aligned}
```

を用いる．

まず，解離エネルギーの項は，

```math
\frac{D_0}{RT}
=\frac{169.3}{(1.987\times10^{-3})(5000)}
\simeq17.04
```

である．
また，

```math
\frac{\Theta_v}{T}=\frac{3350}{5000}=0.670
```

より，

```math
\ln(1-e^{-\Theta_v/T})
=\ln(1-e^{-0.670})
\simeq-0.717
```

となる．

式 (8) の各因子について自然対数を取ると，c.g.s. 単位での数値は，

```math
\begin{aligned}
\frac32\ln\left(
\frac{\pi m_{\mathrm N}k_{\mathrm B}T}{h^2}
\right)&\simeq62.38,\\
\ln(2k_{\mathrm B}\Theta_r)&\simeq-34.78,\\
\ln16&\simeq2.773,\\
\ln(1-e^{-\Theta_v/T})&\simeq-0.717,\\
-\frac{D_0}{RT}&\simeq-17.04
\end{aligned}
```

となる．
対数は，ここでは各物理量を c.g.s. 単位で数値表示した値について計算している．
したがって，

```math
\begin{aligned}
\ln K_p(\mathrm{c.g.s.})
&\simeq62.38-34.78+2.773-0.717-17.04\\
&\simeq12.61
\end{aligned}
\tag{9}
```

を得る．
この値は， $K_p$ を $\mathrm{dyn/cm^2}$ で表した数値の自然対数である．

圧力単位を atm に変換するため，

```math
1\ \mathrm{atm}=1.01325\times10^6\ \mathrm{dyn/cm^2}
```

を用いる．
したがって，

```math
\begin{aligned}
\ln K_p(\mathrm{atm})
&=\ln K_p(\mathrm{c.g.s.})
-\ln(1.01325\times10^6)\\
&\simeq12.61-13.83\\
&\simeq-1.22
\end{aligned}
```

となる．
最後に，自然対数から常用対数に変換すると，

```math
\begin{aligned}
\log_{10}K_p(\mathrm{atm})
&=\frac{\ln K_p(\mathrm{atm})}{\ln10}\\
&\simeq\frac{-1.22}{2.303}\\
&\simeq-0.53
\end{aligned}
```

を得る．

### 結論

5000 K における窒素分子の解離反応の平衡定数は，

```math
\boxed{
\log_{10}K_p(\mathrm{atm})\simeq-0.53
}
```

である．
したがって，

```math
\boxed{
K_p\simeq0.30\ \mathrm{atm}
}
```

となる．
これは解答例の $\log_{10}K_p(\mathrm{atm})\simeq-0.52$ と，丸め方による小さな差の範囲で一致する．
