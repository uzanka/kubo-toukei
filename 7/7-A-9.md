# 演習問題【7-A-9】

## 解答

酸素分子 $\mathrm{O_2}$ の電子状態が Helmholtz 自由エネルギーに与える補正項を求める．
基底電子準位と第一励起電子準位の寄与を電子分配関数に取り入れ，基底準位のみを考えた場合との自由エネルギーの差を計算する．
温度は $T=5000\ \mathrm K$ である．

### 1．電子分配関数の導出

温度 $T$ における電子分配関数は，各電子準位の縮重度と Boltzmann 因子の積をすべての準位について足し合わせることで与えられる．
すなわち，

```math
e(T)=\sum_i g_i e^{-\Delta E_i/(k_{\mathrm B}T)}
```

である．
ここで， $g_i$ は電子準位 $i$ の縮重度， $\Delta E_i$ は基底準位を基準としたエネルギー差， $k_{\mathrm B}$ は Boltzmann 定数である．

問題文より，酸素分子の基底準位は ${}^3\Sigma_g^-$ であり，縮重度は $g_0=3$ である．
第一励起準位は ${}^1\Delta_g$ であり，縮重度は $g_1=2$ ，基底準位とのエネルギー差は波数で $7824\ \mathrm{cm}^{-1}$ と与えられている．

第二励起準位以上の寄与を無視すると，電子分配関数は基底準位と第一励起準位の二つの寄与の和として近似できる．
基底準位のエネルギーをゼロとすると，

```math
\boxed{
e(T)=3+2e^{-\Delta E/(k_{\mathrm B}T)}
}
\tag{1}
```

となる．

### 2．Boltzmann 因子の計算

問題で与えられたエネルギー差は波数 $\tilde\nu=7824\ \mathrm{cm}^{-1}$ で表されている．
波数からエネルギーへの換算には，

```math
\Delta E=hc\tilde\nu
```

を用いる．
したがって，

```math
\frac{\Delta E}{k_{\mathrm B}T}
=\frac{hc}{k_{\mathrm B}}\frac{\tilde\nu}{T}
```

である．
ここで，

```math
\frac{hc}{k_{\mathrm B}}
\simeq1.4388\ \mathrm{cm\,K}
```

を用いると，

```math
\begin{aligned}
\frac{\Delta E}{k_{\mathrm B}T}
&=\frac{(1.4388\ \mathrm{cm\,K})(7824\ \mathrm{cm}^{-1})}
{5000\ \mathrm K}\\
&\simeq2.251
\end{aligned}
```

となる．
よって，第一励起準位の Boltzmann 因子は，

```math
e^{-\Delta E/(k_{\mathrm B}T)}
=e^{-2.251}
\simeq0.105
\tag{2}
```

である．
式 (1) に代入すると，

```math
\begin{aligned}
e(T)
&\simeq3+2(0.105)\\
&\simeq3.21
\end{aligned}
\tag{3}
```

を得る．

### 3．Helmholtz 自由エネルギーへの補正項

電子分配関数によるモル Helmholtz 自由エネルギーの寄与は，

```math
\bar F_e=-RT\ln e(T)
```

である．
ここで， $R$ は気体定数であり， $\ln$ は自然対数である．
式 (3) と，

```math
R=1.987\ \mathrm{cal\,mol^{-1}K^{-1}}
```

を用いると，

```math
\begin{aligned}
\bar F_e
&\simeq-(1.987)(5000)\ln(3.21)
\ \mathrm{cal/mol}\\
&\simeq-11584\ \mathrm{cal/mol}\\
&\simeq-11.58\ \mathrm{kcal/mol}
\end{aligned}
\tag{4}
```

となる．
これは電子分配関数全体による自由エネルギーへの寄与である．

しかし，問題で求める「第一励起準位による補正項」とは，基底準位だけを考えた場合の自由エネルギーからの変化量である．
基底準位のみを考えた場合の電子分配関数は $e_0(T)=3$ なので，その自由エネルギーへの寄与は

```math
\bar F_{e,0}=-RT\ln3
```

となる．
したがって，求める補正項は，

```math
\begin{aligned}
\Delta\bar F_e
&=\bar F_e-\bar F_{e,0}\\
&=-RT\ln e(T)+RT\ln3\\
&=-RT\ln\left(\frac{e(T)}{3}\right)
\end{aligned}
```

である．
式 (3) より $e(T)/3\simeq3.21/3\simeq1.07$ であるため，

```math
\begin{aligned}
\Delta\bar F_e
&\simeq-(1.987\times10^{-3})(5000)\ln(1.07)
\ \mathrm{kcal/mol}\\
&\simeq-9.935(0.0677)\ \mathrm{kcal/mol}\\
&\simeq-0.67\ \mathrm{kcal/mol}
\end{aligned}
```

を得る．

### 結論

第二励起準位以上の寄与を無視した近似のもとで，酸素分子の第一励起電子準位による Helmholtz 自由エネルギーへの補正項は，

```math
\boxed{
\Delta\bar F_e\simeq-0.67\ \mathrm{kcal/mol}
\approx-0.7\ \mathrm{kcal/mol}
}
```

である．
補正項が負であるのは，第一励起準位を考慮すると利用可能な電子状態が増え，電子分配関数が大きくなるためである．
自由エネルギーは分配関数の対数に負号を付けた量であるため，分配関数が増えると自由エネルギーは低下する．
