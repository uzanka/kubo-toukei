# 演習問題【7-B-14】

## 解答

二つの主慣性モーメントが等しい分子を対称なコマと呼ぶ．
与えられたエネルギー準位から回転分配関数を求め，高温極限で和を積分に置き換えることにより，古典的な回転分配関数を導出する．

### 1．回転分配関数の定義

問題文で与えられた回転エネルギー準位は

```math
\varepsilon_{l,\lambda,m}
=
\frac{\hbar^2}{8\pi^2}
\left\{
\frac{l(l+1)}{A}
+\lambda^2\left(\frac1C-\frac1A\right)
\right\}
```

である．
ここで， $A,A,C$ は主慣性モーメント， $l$ は回転角運動量の量子数， $\lambda$ は対称軸方向の角運動量に関する量子数， $m$ は空間固定軸方向の角運動量に関する量子数である．
それぞれの量子数の範囲は

```math
l=0,1,2,\ldots,\qquad
\lambda=-l,\ldots,l,\qquad
m=-l,\ldots,l
```

である．

回転分配関数とは，すべての回転エネルギー準位について Boltzmann 因子 $e^{-\varepsilon/kT}$ を足し合わせた量である．
ここで， $k$ は Boltzmann 定数， $T$ は絶対温度である．
エネルギー準位は $m$ に依存せず，各 $l,\lambda$ に対して $m$ の値が $2l+1$ 個存在する．
したがって，回転分配関数は

```math
r(T)=
\sum_{l=0}^{\infty}
\sum_{\lambda=-l}^{l}
(2l+1)e^{-\varepsilon_{l,\lambda,m}/kT}
```

と表される．
エネルギー準位を代入すると，

```math
\begin{aligned}
r(T)
={}&
\sum_{l=0}^{\infty}\sum_{\lambda=-l}^{l}
(2l+1)\\
&\quad\times
\exp\left[
-\frac{\hbar^2}{8\pi^2 kT}
\left\{
\frac{l(l+1)}{A}
+\lambda^2\left(\frac1C-\frac1A\right)
\right\}
\right].
\end{aligned}
```

ここで，計算を簡単にするため，無次元量

```math
\boxed{
\sigma=\frac{\hbar^2}{8\pi^2AkT},
\qquad
\tau=\frac{\hbar^2}{8\pi^2kT}
\left(\frac1C-\frac1A\right)
}
\tag{1}
```

を導入する．
すると，

```math
\boxed{
r(T)=
\sum_{l=0}^{\infty}
\sum_{\lambda=-l}^{l}
(2l+1)e^{-l(l+1)\sigma-\lambda^2\tau}
}
\tag{2}
```

となる．
これが回転分配関数の一般的な級数表示である．
一般には，この級数を簡単な初等関数だけで表すことはできない．
そこで，高温極限を考える．

### 2．高温極限での和の積分近似

温度が十分に高いとき， $\sigma$ と $\tau$ はともに小さくなる．
このとき，多数の量子状態が分配関数に寄与するため，量子数 $l$ と $\lambda$ に関する和を積分で近似できる．
式 (2) は

```math
r(T)\simeq
\int_0^\infty
(2l+1)e^{-l(l+1)\sigma}
\left(\int_{-l}^{l}e^{-\lambda^2\tau}\,d\lambda\right)dl
\tag{3}
```

となる．

内側の積分を

```math
I(l)=\int_{-l}^{l}e^{-\lambda^2\tau}\,d\lambda
```

と定義する．
被積分関数は $\lambda$ の偶関数であるため，

```math
I(l)=2\int_0^l e^{-\lambda^2\tau}\,d\lambda
```

である．
積分の上限と下限を微分することにより，

```math
\frac{dI(l)}{dl}=2e^{-l^2\tau}
\tag{4}
```

を得る．

一方，

```math
\frac{d}{dl}e^{-l(l+1)\sigma}
=-\sigma(2l+1)e^{-l(l+1)\sigma}
```

であるから，

```math
(2l+1)e^{-l(l+1)\sigma}
=-\frac1{\sigma}\frac{d}{dl}e^{-l(l+1)\sigma}
```

と書ける．
これを式 (3) に代入すると，

```math
r(T)\simeq
-\frac1{\sigma}
\int_0^\infty
I(l)\frac{d}{dl}e^{-l(l+1)\sigma}\,dl
```

となる．
ここで部分積分を行うと，

```math
\begin{aligned}
r(T)\simeq{}&
-\frac1{\sigma}
\left[
I(l)e^{-l(l+1)\sigma}
\right]_0^\infty\\
&+\frac1{\sigma}
\int_0^\infty e^{-l(l+1)\sigma}\frac{dI(l)}{dl}\,dl.
\end{aligned}
```

境界項はゼロになる．
$l=0$ では $I(0)=0$ である．
また $l\to\infty$ では，指数関数 $e^{-l(l+1)\sigma}$ の減衰が積分 $I(l)$ の増大を上回る．
特に， $\tau$ が負の場合でも，後に示すように $\sigma+\tau>0$ であるため，積全体はゼロに収束する．

式 (4) を用いれば，

```math
\begin{aligned}
r(T)
&\simeq
\frac2{\sigma}
\int_0^\infty
e^{-l(l+1)\sigma-l^2\tau}\,dl.
\end{aligned}
```

したがって，

```math
\boxed{
r(T)\simeq
\frac2{\sigma}
\int_0^\infty
e^{-l(l+1)\sigma-l^2\tau}\,dl
}
\tag{5}
```

となる．

### 3．高温極限での指数関数の近似

式 (5) の指数部分を整理すると，

```math
\begin{aligned}
l(l+1)\sigma+l^2\tau
&=l^2(\sigma+\tau)+l\sigma.
\end{aligned}
```

高温極限では $\sigma,\tau\to0$ であるが，このことだけから $l\sigma$ を無視できるとは限らない．
そこで，

```math
x=l\sqrt{\sigma}
```

とおく．
式 (1) より，

```math
\frac{\tau}{\sigma}=\frac AC-1
```

であり， $A,C$ は一定なので， $\tau/\sigma$ は温度に依存しない．
したがって，

```math
l^2(\sigma+\tau)+l\sigma
=
x^2\left(1+\frac{\tau}{\sigma}\right)
+x\sqrt{\sigma}
```

と書ける．
高温極限では，積分に主に寄与する範囲で $x$ は有限の値をとるため， $x\sqrt{\sigma}\to0$ である．
よって，先頭の近似として

```math
l(l+1)\sigma+l^2\tau
\simeq l^2(\sigma+\tau)
```

とできる．
この近似を式 (5) に代入すると，

```math
r(T)\simeq
\frac2{\sigma}
\int_0^\infty e^{-l^2(\sigma+\tau)}\,dl
\tag{6}
```

となる．

ここで，

```math
\sigma+\tau
=
\frac{\hbar^2}{8\pi^2AkT}
+
\frac{\hbar^2}{8\pi^2kT}
\left(\frac1C-\frac1A\right)
=
\frac{\hbar^2}{8\pi^2CkT}
\tag{7}
```

である．
慣性モーメント $C$ は正なので， $\sigma+\tau>0$ であり，式 (6) のガウス積分は収束する．
この関係は，先に部分積分で境界項が消えることを示す際にも用いられる．

### 4．ガウス積分による古典的極限

正の定数 $a$ に対するガウス積分の公式

```math
\int_0^\infty e^{-ax^2}\,dx
=\frac12\sqrt{\frac{\pi}{a}}
```

を用いる．
式 (6) で $a=\sigma+\tau$ とすれば，

```math
\begin{aligned}
r(T)
&\simeq
\frac2{\sigma}\cdot
\frac12\sqrt{\frac{\pi}{\sigma+\tau}}\\
&=\frac{\sqrt{\pi}}{\sigma\sqrt{\sigma+\tau}}.
\end{aligned}
```

したがって，高温極限の回転分配関数は

```math
\boxed{
r(T)\simeq\frac{\sqrt{\pi}}{\sigma\sqrt{\sigma+\tau}}
}
\tag{8}
```

と表される．

式 (1) と式 (7) より，

```math
\frac1{\sigma}=\frac{8\pi^2AkT}{\hbar^2},
\qquad
\frac1{\sqrt{\sigma+\tau}}
=
\left(\frac{8\pi^2CkT}{\hbar^2}\right)^{1/2}
```

である．
これらを式 (8) に代入すると，

```math
\boxed{
r(T)\simeq
\sqrt{\pi}\,
\frac{8\pi^2AkT}{\hbar^2}
\left(\frac{8\pi^2CkT}{\hbar^2}\right)^{1/2}
}
\tag{9}
```

を得る．
これが，問題文に与えられたエネルギー準位の式を用いて導かれる，高温度における回転分配関数の古典的極限である．

### 5．結論と記号上の注意

回転分配関数の一般式は

```math
\boxed{
r(T)=
\sum_{l=0}^{\infty}
\sum_{\lambda=-l}^{l}
(2l+1)e^{-l(l+1)\sigma-\lambda^2\tau}
}
```

であり，高温極限では，量子数の和を積分で近似することにより，

```math
\boxed{
r(T)\simeq
\sqrt{\pi}\,
\frac{8\pi^2AkT}{\hbar^2}
\left(\frac{8\pi^2CkT}{\hbar^2}\right)^{1/2}
}
```

となる．
この導出は解答例と同じであり，和の積分近似，部分積分，ガウス積分を順に用いるものである．

ただし，記号には注意が必要である．
通常， $\hbar$ は換算 Planck 定数 $h/(2\pi)$ を意味し，剛体回転のエネルギーは $\hbar^2l(l+1)/(2I)$ ，または Planck 定数 $h$ を用いて $h^2l(l+1)/(8\pi^2I)$ と表される．
したがって，問題文の $\hbar^2/(8\pi^2)$ が標準的な記号規約どおりの意味で使われている場合，元のエネルギー準位の係数には確認が必要である．
解答例の意図が Planck 定数 $h$ を用いる表記であれば，式 (1) と式 (9) の $\hbar$ を $h$ に置き換えたものが，通常の古典的回転分配関数の式となる．
