# 演習問題【7-B-14】

## 解答

### 1．問題文のエネルギー準位と回転分配関数の定義

二つの主慣性モーメントが等しい分子を対称なコマと呼ぶ．
主慣性モーメントを $A,A,C$ とする．

まず，問題文のエネルギー準位について，Planck定数と換算Planck定数の記号を正しく区別する必要がある．
通常の量子力学では，

```math
\hbar=\frac{h}{2\pi}
```

であるため，対称なコマの回転エネルギー準位は，

```math
\boxed{
\varepsilon_{l,\lambda,m}
=
\frac{h^2}{8\pi^2}
\left\{
\frac{l(l+1)}{A}
+\lambda^2\left(\frac1C-\frac1A\right)
\right\}
}
\tag{1}
```

と表される．
同じ式を換算Planck定数 $\hbar$ で表すと，

```math
\boxed{
\varepsilon_{l,\lambda,m}
=
\frac{\hbar^2}{2}
\left\{
\frac{l(l+1)}{A}
+\lambda^2\left(\frac1C-\frac1A\right)
\right\}
}
\tag{2}
```

となる．
以下では，式 (1) を用いる．

量子数の範囲は，

```math
l=0,1,2,\ldots
```

```math
\lambda=-l,\ldots,l,
\qquad
m=-l,\ldots,l
```

である．

エネルギー準位は $m$ に依存しないため，各 $l,\lambda$ に対して $m$ による縮重度は $2l+1$ である．
したがって，回転分配関数は，

```math
r(T)
=
\sum_{l=0}^{\infty}
\sum_{\lambda=-l}^{l}
(2l+1)e^{-\varepsilon_{l,\lambda,m}/kT}
\tag{3}
```

と表される．
ここで， $k$ はBoltzmann定数， $T$ は絶対温度である．

### 2．無次元量の導入

計算を簡単にするため，次の無次元量を導入する．

```math
\boxed{
\sigma=\frac{h^2}{8\pi^2AkT},
\qquad
\tau=\frac{h^2}{8\pi^2kT}
\left(\frac1C-\frac1A\right)
}
\tag{4}
```

これらを式 (1) に代入すると，

```math
\boxed{
r(T)=
\sum_{l=0}^{\infty}
\sum_{\lambda=-l}^{l}
(2l+1)e^{-\sigma l(l+1)-\tau\lambda^2}
}
\tag{5}
```

を得る．
これが回転分配関数の一般的な級数表示である．

一般には，この級数を簡単な初等関数だけで表すことはできないため，高温極限を考える．

### 3．高温極限での和の積分近似

温度が十分に高いとき，

```math
\sigma\to0,\qquad \tau\to0
```

となる．
このとき，多数の量子状態が分配関数に寄与するため，量子数 $l$ と $\lambda$ に関する和を積分で近似できる．

したがって，式 (5) は，

```math
r(T)\simeq
\int_0^\infty
(2l+1)e^{-\sigma l(l+1)}
\left(
\int_{-l}^{l}e^{-\tau\lambda^2}\,d\lambda
\right)dl
\tag{6}
```

となる．

ここで，内側の積分を

```math
I(l)=\int_{-l}^{l}e^{-\tau\lambda^2}\,d\lambda
```

と定義する．
被積分関数は $\lambda$ の偶関数なので，

```math
I(l)=2\int_0^l e^{-\tau\lambda^2}\,d\lambda
```

である．
積分の上限を微分すると，

```math
\boxed{
\frac{dI(l)}{dl}=2e^{-\tau l^2}
}
\tag{7}
```

を得る．

一方，

```math
\frac{d}{dl}e^{-\sigma l(l+1)}
=
-\sigma(2l+1)e^{-\sigma l(l+1)}
```

であるから，

```math
(2l+1)e^{-\sigma l(l+1)}
=
-\frac1{\sigma}
\frac{d}{dl}e^{-\sigma l(l+1)}
```

と書ける．
これを式 (6) に代入すると，

```math
r(T)\simeq
-\frac1{\sigma}
\int_0^\infty
I(l)\frac{d}{dl}e^{-\sigma l(l+1)}\,dl
```

となる．

ここで部分積分を行うと，

```math
\begin{aligned}
r(T)\simeq{}&
-\frac1{\sigma}
\left[
I(l)e^{-\sigma l(l+1)}
\right]_0^\infty\\
&+\frac1{\sigma}
\int_0^\infty
e^{-\sigma l(l+1)}
\frac{dI(l)}{dl}\,dl .
\end{aligned}
```

境界項はゼロとなる．
実際， $l=0$ では $I(0)=0$ である．
また， $l\to\infty$ では指数関数が減衰するため，積全体はゼロに収束する．

このことは，

```math
\sigma+\tau
=
\frac{h^2}{8\pi^2CkT}>0
\tag{8}
```

からも確認できる．
$A,C$ は正の慣性モーメントであるため， $\sigma+\tau$ は常に正である．
したがって， $\tau$ が負の場合でも積分は収束する．

式 (7) を代入すれば，

```math
\begin{aligned}
r(T)
&\simeq
\frac2{\sigma}
\int_0^\infty
e^{-\sigma l(l+1)-\tau l^2}\,dl .
\end{aligned}
```

よって，

```math
\boxed{
r(T)\simeq
\frac2{\sigma}
\int_0^\infty
e^{-\sigma l(l+1)-\tau l^2}\,dl
}
\tag{9}
```

となる．

### 4．高温極限での指数関数の近似

式 (9) の指数部分を整理すると，

```math
\begin{aligned}
\sigma l(l+1)+\tau l^2
&=(\sigma+\tau)l^2+\sigma l
\end{aligned}
```

となる．

ここで，

```math
x=l\sqrt{\sigma+\tau}
```

とおくと，

```math
\begin{aligned}
\sigma l(l+1)+\tau l^2
&=x^2+
\frac{\sigma}{\sqrt{\sigma+\tau}}x
\end{aligned}
```

と書ける．

式 (4) と式 (8) より，

```math
\begin{aligned}
\frac{\sigma}{\sqrt{\sigma+\tau}}
&=
\frac{\displaystyle\frac{h^2}{8\pi^2AkT}}
{\displaystyle\sqrt{\frac{h^2}{8\pi^2CkT}}}\\[2mm]
&=
\boxed{
\sqrt{\frac{h^2C}{8\pi^2A^2kT}}
}.
\end{aligned}
\tag{10}
```

したがって，高温極限では，

```math
\frac{\sigma}{\sqrt{\sigma+\tau}}\to0
\qquad(T\to\infty)
```

となる．

式 (9) の積分に変数変換を適用すると，

```math
\begin{aligned}
r(T)
&\simeq
\frac{2}{\sigma\sqrt{\sigma+\tau}}
\int_0^\infty
\exp\left[
-x^2-
\frac{\sigma}{\sqrt{\sigma+\tau}}x
\right]dx.
\end{aligned}
\tag{11}
```

ここで，

```math
a=\frac{\sigma}{\sqrt{\sigma+\tau}}
```

とおけば， $a\to0$ である．
したがって，積分の極限は，

```math
\begin{aligned}
\lim_{a\to0}
\int_0^\infty e^{-x^2-ax}\,dx
&=
\int_0^\infty e^{-x^2}\,dx\\
&=\frac{\sqrt{\pi}}2
\end{aligned}
```

となる．

この極限は， $a\geq0$ に対して

```math
0\leq e^{-x^2-ax}\leq e^{-x^2}
```

であり，右辺が積分可能であることから，積分と極限の交換によって正当化できる．

よって，式 (11) は高温極限で，

```math
\boxed{
r(T)\simeq
\frac2{\sigma\sqrt{\sigma+\tau}}
\cdot\frac{\sqrt{\pi}}2
}
```

となる．
すなわち，

```math
\boxed{
r(T)\simeq
\frac{\sqrt{\pi}}{\sigma\sqrt{\sigma+\tau}}
}
\tag{12}
```

を得る．

### 5．ガウス積分による古典的極限

式 (4) と式 (8) より，

```math
\frac1{\sigma}
=
\frac{8\pi^2AkT}{h^2}
```

および，

```math
\frac1{\sqrt{\sigma+\tau}}
=
\left(
\frac{8\pi^2CkT}{h^2}
\right)^{1/2}
```

である．

これらを式 (12) に代入すると，

```math
\boxed{
r(T)\simeq
\sqrt{\pi}\,
\frac{8\pi^2AkT}{h^2}
\left(
\frac{8\pi^2CkT}{h^2}
\right)^{1/2}
}
\tag{13}
```

を得る．

これが，通常の量子力学のエネルギー準位に基づく対称なコマの高温度における古典的回転分配関数である．

### 6．古典力学による独立した確認

得られた結果が古典的な回転分配関数と一致することを確認する．

主慣性モーメントが $A,A,C$ である剛体の回転Hamiltonianは，

```math
H_{\mathrm{rot}}
=
\frac{L_1^2+L_2^2}{2A}
+
\frac{L_3^2}{2C}
```

である．
ここで， $L_1,L_2,L_3$ は分子固定座標系での角運動量成分である．

剛体の配向を表すEuler角の積分範囲に対して，

```math
\int d\Omega=8\pi^2
```

である．
したがって，対称数を1とした古典的回転分配関数は，

```math
r_{\mathrm{cl}}
=
\frac1{h^3}
\int d\Omega
\int dL_1dL_2dL_3\,
e^{-H_{\mathrm{rot}}/(kT)}
```

と表される．

角運動量に関するGaussian積分を実行すると，

```math
\begin{aligned}
r_{\mathrm{cl}}
&=
\frac{8\pi^2}{h^3}
\left(
\int_{-\infty}^{\infty}
e^{-L_1^2/(2AkT)}\,dL_1
\right)\\
&\quad\times
\left(
\int_{-\infty}^{\infty}
e^{-L_2^2/(2AkT)}\,dL_2
\right)
\left(
\int_{-\infty}^{\infty}
e^{-L_3^2/(2CkT)}\,dL_3
\right)\\
&=
\frac{8\pi^2}{h^3}
(2\pi AkT)\sqrt{2\pi CkT}.
\end{aligned}
```

これを整理すると，

```math
\begin{aligned}
r_{\mathrm{cl}}
&=
\sqrt{\pi}
\left(
\frac{8\pi^2AkT}{h^2}
\right)
\left(
\frac{8\pi^2CkT}{h^2}
\right)^{1/2}.
\end{aligned}
```

これは式 (13) と一致する．

したがって，量子力学から求めた高温極限は，古典力学から求めた回転分配関数とも整合している．

### 7．結論

対称なコマの回転分配関数は，

```math
\boxed{
r(T)=
\sum_{l=0}^{\infty}
\sum_{\lambda=-l}^{l}
(2l+1)
\exp\left[
-\frac{h^2}{8\pi^2kT}
\left\{
\frac{l(l+1)}{A}
+\lambda^2\left(\frac1C-\frac1A\right)
\right\}
\right]
}
```

である．

高温極限では，量子数の和を積分で近似し，部分積分とGaussian積分を用いることで，

```math
\boxed{
r(T)\simeq
\sqrt{\pi}\,
\frac{8\pi^2AkT}{h^2}
\left(
\frac{8\pi^2CkT}{h^2}
\right)^{1/2}
}
```

を得る．

これは，対称数を1とした対称なコマの古典的回転分配関数であり，慣性モーメントが $A,A,C$ である剛体の位相空間積分から得られる結果と一致する．

なお，実際の分子に対称数 $\sigma_{\mathrm{sym}}$ がある場合には，同等な配向の重複を除くため，通常は上の分配関数を $\sigma_{\mathrm{sym}}$ で割る．
ただし，ここでは問題文で指定された量子状態をそのまま数え，対称数を1としている．
