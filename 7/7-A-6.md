# 演習問題【7-A-6】

## 解答

本問では，温度が十分に高いときの $\mathrm{H}_2$ ガスと $\mathrm{D}_2$ ガスについて，オルソ分子とパラ分子の存在比を求める．
鍵となるのは，核スピンの状態数の違いと，原子核の交換に対して分子の全波動関数が満たすべき対称性である．
さらに，高温では偶数の回転量子数をもつ状態と奇数の回転量子数をもつ状態の分配関数がほぼ等しくなることを利用する．

### 1．回転分配関数の偶数・奇数成分

二原子分子の回転状態は，回転量子数 $J=0,1,2,\ldots$ によって指定される．
回転エネルギーは

```math
E_J=k_{\mathrm B}\Theta_rJ(J+1)
```

であり，それぞれの $J$ に対する磁気的縮重度は $2J+1$ である．
ここで， $k_{\mathrm B}$ は Boltzmann 定数， $\Theta_r$ は回転温度である．
したがって，回転分配関数の偶数 $J$ と奇数 $J$ の部分をそれぞれ

```math
r_{\mathrm{even}}(T)
=\sum_{\substack{J=0\\J\ \mathrm{even}}}^{\infty}
(2J+1)e^{-\Theta_rJ(J+1)/T}
```

および

```math
r_{\mathrm{odd}}(T)
=\sum_{\substack{J=0\\J\ \mathrm{odd}}}^{\infty}
(2J+1)e^{-\Theta_rJ(J+1)/T}
```

と定義する．
核スピンの自由度を含まない回転分配関数は，この二つの和の和である．

高温 $T\gg\Theta_r$ では，多数の回転準位が熱的に占有される．
この領域では，隣り合う $J$ に対する重み $(2J+1)e^{-\Theta_rJ(J+1)/T}$ は緩やかに変化するため，偶数 $J$ の項と奇数 $J$ の項の和は主要項で等しくなる．
したがって，

```math
\boxed{
r_{\mathrm{even}}(T)\simeq
r_{\mathrm{odd}}(T)\simeq\frac12r_c(T)
}
\tag{1}
```

である．
ここで $r_c(T)$ は回転分配関数の高温近似であり，異核二原子分子については $r_c(T)\simeq T/\Theta_r$ である．
本問では，式 (1) によって偶数 $J$ と奇数 $J$ の回転分配関数の寄与が等しいことを利用する．

### 2．$\mathrm{H}_2$ 分子のオルソ・パラ比

水素原子核の核スピンは $s=1/2$ であり，フェルミ粒子である．
したがって，二つの水素原子核を交換するとき，分子の全波動関数は符号が反転しなければならない．
電子状態と振動状態が基底状態にある場合，それらの交換対称性は対称であるため，全波動関数の対称性は回転状態と核スピン状態の対称性によって決まる．

回転波動関数は，二つの原子核を交換すると分子軸の向きが反転するため，

```math
\psi_{\mathrm{rot}}\longrightarrow
(-1)^J\psi_{\mathrm{rot}}
```

と変化する．
したがって，偶数 $J$ の回転状態は対称，奇数 $J$ の回転状態は反対称である．

二つのスピン $1/2$ の合成スピン状態は，対称な三重項状態 $S=1$ と反対称な一重項状態 $S=0$ に分かれる．
それぞれの状態数は，

```math
g_{\mathrm{sym}}=2S+1=3,
\qquad
g_{\mathrm{asym}}=1
```

である．
全波動関数が反対称でなければならないため，回転状態と核スピン状態の対称性は互いに反対である．
よって，

- **オルソ $\mathrm{H}_2$** ： 奇数 $J$ ，核スピンの重率 $3$ ．
- **パラ $\mathrm{H}_2$** ： 偶数 $J$ ，核スピンの重率 $1$ ．

となる．
ここで，オルソは問題文の定義どおり，核スピンの重率が大きい方である．

したがって，オルソ分子とパラ分子の数の比は，それぞれの核スピンの重率と回転分配関数の積の比として，

```math
\begin{aligned}
n(\text{オルソ}-\mathrm{H}_2):
n(\text{パラ}-\mathrm{H}_2)
&=3r_{\mathrm{odd}}:r_{\mathrm{even}}\\
&\simeq3:1
\end{aligned}
```

となる．
よって，

```math
\boxed{
n(\text{オルソ}-\mathrm{H}_2):
n(\text{パラ}-\mathrm{H}_2)=3:1
}
\tag{2}
```

である．

### 3．$\mathrm{D}_2$ 分子のオルソ・パラ比

重水素原子核の核スピンは $s=1$ であり，ボソンである．
したがって，二つの重水素原子核を交換するとき，分子の全波動関数は対称でなければならない．

二つのスピン $1$ の合成スピンは，全スピン $S=0,1,2$ の状態に分かれる．
その状態数はそれぞれ $2S+1$ である．
二つのスピン $1$ の合成状態では， $S=0,2$ が対称， $S=1$ が反対称である．
したがって，対称な核スピン状態の重率は

```math
g_{\mathrm{sym}}=(2\times2+1)+(2\times0+1)
=5+1=6
```

であり，反対称な核スピン状態の重率は

```math
g_{\mathrm{asym}}=2\times1+1=3
```

である．

$\mathrm{D}_2$ では全波動関数が対称でなければならないため，回転状態と核スピン状態の対称性は同じである．
したがって，

- **オルソ $\mathrm{D}_2$** ： 偶数 $J$ ，核スピンの重率 $6$ ．
- **パラ $\mathrm{D}_2$** ： 奇数 $J$ ，核スピンの重率 $3$ ．

となる．
高温では式 (1) より偶数 $J$ と奇数 $J$ の回転分配関数がほぼ等しいため，

```math
\begin{aligned}
n(\text{オルソ}-\mathrm{D}_2):
n(\text{パラ}-\mathrm{D}_2)
&=6r_{\mathrm{even}}:3r_{\mathrm{odd}}\\
&\simeq6:3\\
&=2:1
\end{aligned}
```

である．
よって，

```math
\boxed{
n(\text{オルソ}-\mathrm{D}_2):
n(\text{パラ}-\mathrm{D}_2)=2:1
}
\tag{3}
```

となる．

### 結論

高温では，偶数 $J$ と奇数 $J$ の回転分配関数の寄与が等しくなるため，オルソ分子とパラ分子の存在比は，核スピンの重率の比で決まる．
したがって，

```math
\boxed{
\begin{aligned}
\mathrm{H}_2&:\quad
n(\text{オルソ}):n(\text{パラ})=3:1,\\
\mathrm{D}_2&:\quad
n(\text{オルソ}):n(\text{パラ})=2:1
\end{aligned}
}
```

である．
