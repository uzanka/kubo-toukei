# 演習問題【7-A-6】

## 解答

水素分子 ( $\text{H}_2$ ) および 重水素分子 ($\text{D}_2$) のような 2 原子分子において，核スピンの状態と回転状態の対称性は，全波動関数の対称性の要請によって結びついている．
この性質を利用して，高温におけるオルソ状態とパラ状態の存在比を求める．

### 1. $\text{H}_2$ 分子の組成と対称性

水素の原子核 ( $\text{H}$ ) はスピン $s = 1/2$ を持つフェルミ粒子である．
2 つの $`\text{H}`$ 原子核からなる $`\text{H}_2`$ 分子の全波動関数 $`\Psi`$ は，回転状態，電子状態，振動状態，および核スピン状態の積として表される．
電子状態および振動状態が基底状態（対称）であると仮定すると，全波動関数の対称性は回転状態 $`\psi_{\text{rot}}`$ と核スピン状態 $`\psi_{\text{nuc-spin}}`$ の対称性の積によって決まる．

フェルミ粒子であるため，全波動関数 $\Psi$ は核の入れ替えに対して反対称（antisymmetric）でなければならない．
ここで，回転状態 $\psi_{\text{rot}}$ の対称性は回転量子数 $J$ に対して $(-1)^J$ で与えられる．
したがって，核スピン状態 $\psi_{\text{nuc-spin}}$ は以下の対称性を持つ必要がある：

- $J$ が偶数（対称）のとき，核スピン状態は反対称でなければならない．
- $J$ が奇数（反対称）のとき，核スピン状態は対称でなければならない．

核スピン $s = 1/2$ の 2 つの粒子の合成スピン状態は， $S = 1$ （三重項，対称）および $S = 0$ （一重項，反対称）である．
- 対称な核スピン状態（三重項）： 重率 $g_{\text{sym}} = 3$
- 反対称な核スピン状態（一重項）： 重率 $g_{\text{asym}} = 1$

問題文の定義により，重率の大きい方をオルソ，小さい方をパラと呼ぶため：

- オルソ $`\text{H}_2`$ ： $`J`$ が奇数の状態， $`g_{\text{ortho}} = 3`$
- パラ $`\text{H}_2`$ ： $`J`$ が偶数の状態， $`g_{\text{para}} = 1`$

高温 ( $T \gg \Theta_r$ ) においては，回転状態の和は積分で近似でき， $J$ が偶数の状態の数と奇数の状態の数はほぼ等しくなる．
したがって，オルソ $\text{H}_2$ とパラ $\text{H}_2$ の数の比は，核スピンの重率の比に等しくなる：

$$n(\text{オルソ}-\text{H}_2) : n(\text{パラ}-\text{H}_2) = 3 : 1$$

### 2. $\text{D}_2$ 分子の組成と対称性

重水素の原子核 ( $\text{D}$ ) はスピン $s = 1$ を持つボソンである．
ボソンの場合，全波動関数 $\Psi$ は核の入れ替えに対して対称（symmetric）でなければならない．

核スピン $s = 1$ の 2 つの粒子の合成スピン状態は， $S = 2, 1, 0$ である．

これらの対称性は以下の通りである：

- 対称な核スピン状態 ( $S=2$ および $S=0$ )： 重率 $g_{\text{sym}} = (2 \times 2 + 1) + (0 \times 0 + 1) = 5 + 1 = 6$
- 反対称な核スピン状態 ( $S=1$ )： 重率 $g_{\text{asym}} = (2 \times 1 + 1) = 3$

（一般式：スピン $s$ の 2 粒子について，対称な状態の重率は $(s+1)(2s+1)$ ，反対称な状態の重率は $s(2s+1)$ である．
$s=1$ を代入すると， $2 \times 3 = 6$ および $1 \times 3 = 3$ となる．）

全波動関数が対称であるためには：
- $J$ が偶数（対称）のとき，核スピン状態は対称でなければならない．
- $J$ が奇数（反対称）のとき，核スピン状態は反対称でなければならない．

問題の定義に基づくと：
- オルソ $`\text{D}_2`$ ： $`J`$ が偶数の状態， $`g_{\text{ortho}} = 6`$
- パラ $`\text{D}_2`$ ： $`J`$ が奇数の状態， $`g_{\text{para}} = 3`$

高温における回転状態の分布が $J$ の偶奇で等しいことから，存在比は：

$$n(\text{オルソ}-\text{D}_2) : n(\text{パラ}-\text{D}_2) = 6 : 3 = 2 : 1$$

### 結論

- $\text{H}_2$ ガスにおけるオルソ $\text{H}_2$ とパラ $\text{H}_2$ の数の比は $3 : 1$ である．
- $\text{D}_2$ ガスにおけるオルソ $\text{D}_2$ とパラ $\text{D}_2$ の数の比は $2 : 1$ である．

## 解説

本問題の核心は，量子力学的な対称性の要請（パウリの排他原理およびボソンの対称性）が，マクロな統計量（オルソ・パラの比率）にどのように反映されるかを理解することにある．

### 1. 対称性のルール

- フェルミ粒子（ $\text{H}$ ）は，全波動関数が「入れ替えたときに符号が反転」しなければならない．
- ボソン（ $\text{D}$ ）は，「入れ替えても符号が変わらない」しなければならない．

### 2. 回転状態との連動

- 二原子分子の回転状態は，回転量子数 $J$ によって「対称」か「反対称」かが決まる．
- 全体の対称性を保つために，回転状態が対称なら核スピンも対称（または反対称）でなければならない，という「パズル」のような制約が生じる．

### 3. 統計的重率

- 核スピンの組み合わせによって，対称な状態の数（重率）と反対称な状態の数は異なる．
- 高温では回転状態の偶奇が等確率で現れるため，最終的な存在比は，この核スピンの「対称・反対称の重率の比」そのものになる．
