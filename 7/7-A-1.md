# 演習問題【7-A-1】

## 解答

アルゴンを理想気体とみなし，その並進運動に関する分配関数，Helmholtz自由エネルギー，内部エネルギー，エントロピーおよび分子1個当たりの化学ポテンシャルを， $300\,\mathrm K$ ， $1\,\mathrm{atm}$ ， $1\,\mathrm{cm^3}$ の条件で計算する．
アルゴンの原子量は $39.94$ とする．

### 1．与えられた条件と定数

与えられた条件は，

```math
T=300\,\mathrm K,\qquad
p=1\,\mathrm{atm},\qquad
V=1\,\mathrm{cm^3}
```

である．
圧力をCGS単位系に直すと，

```math
p=1.01325\times10^6\,\mathrm{erg/cm^3}
```

となる．

以下では，Boltzmann定数とPlanck定数に

```math
\begin{aligned}
k&=1.380649\times10^{-16}\,
\mathrm{erg/K},\\
h&=6.62607015\times10^{-27}\,
\mathrm{erg\,s}
\end{aligned}
```

を用いる．
また，原子量1に相当する質量として，解答例に記載された

```math
m^*=1.65963\times10^{-24}\,\mathrm g
```

を用いる．

アルゴン原子1個の質量 $m$ は，

```math
\begin{aligned}
m&=39.94m^*\\
&=39.94\times1.65963\times10^{-24}\\
&=6.62856\times10^{-23}\,\mathrm g
\end{aligned}
```

である．

したがって，

```math
\boxed{m=6.62856\times10^{-23}\,\mathrm g}
```

となる．

また，熱エネルギーは，

```math
\boxed{kT=4.141947\times10^{-14}\,\mathrm{erg}}
```

である．

### 2．気体に含まれる原子数 $N$

理想気体の状態方程式は，

```math
pV=NkT
```

である．
これを原子数 $N$ について解くと，

```math
N=\frac{pV}{kT}
```

となる．
数値を代入すれば，

```math
\begin{aligned}
N&=\frac{
(1.01325\times10^6)\times1
}{
4.141947\times10^{-14}
}\\
&=2.44631\times10^{19}
\end{aligned}
```

を得る．
したがって，

```math
\boxed{N\simeq2.4463\times10^{19}}
```

である．

### 3．並進分配関数

#### 3.1　熱的ド・ブロイ波長

統計力学では，並進運動の量子状態の密度を表すために，熱的ド・ブロイ波長

```math
\Lambda=\frac{h}{\sqrt{2\pi mkT}}
```

を導入する．
これは，温度 $T$ における粒子の並進運動を特徴づける長さである．

上で求めた $m$ と $kT$ を代入すると，

```math
\begin{aligned}
\Lambda
&=\frac{6.62607015\times10^{-27}}
{\sqrt{2\pi(6.62856\times10^{-23})
(4.141947\times10^{-14})}}\\
&\simeq1.59534\times10^{-9}\,\mathrm{cm}
\end{aligned}
```

となる．

#### 3.2　1粒子分配関数

体積 $V$ の中を自由に運動する原子1個の並進分配関数を $q_1$ とすると，

```math
q_1=\frac{V}{\Lambda^3}
```

である．
したがって，

```math
\begin{aligned}
q_1
&=\frac{1}{(1.59534\times10^{-9})^3}\\
&\simeq2.46285\times10^{26}
\end{aligned}
```

を得る．
よって，

```math
\boxed{q_1\simeq2.463\times10^{26}}
```

である．

#### 3.3　全 $N$ 粒子系の分配関数

ここで，1粒子分配関数 $q_1$ と，全粒子を含む系の分配関数 $Q_N$ を区別する必要がある．

アルゴン原子は互いに区別できない粒子であるため，全系の分配関数には $N!$ で割るGibbs補正が必要となる．
したがって，

```math
\boxed{Q_N=\frac{q_1^N}{N!}}
```

である．

原子数 $N$ が非常に大きいため，Stirlingの近似

```math
\ln N!\simeq N\ln N-N
```

を用いると，

```math
\begin{aligned}
\ln Q_N
&=N\ln q_1-\ln N!\\
&\simeq N\ln q_1-N\ln N+N\\
&=N\left[1-\ln\left(\frac{N}{q_1}\right)\right]
\end{aligned}
```

となる．

そこで，

```math
\boxed{\chi=\ln\left(\frac{N}{q_1}\right)}
```

と定義する．
$N=pV/(kT)$ ， $q_1=V/\Lambda^3$ より，

```math
\chi
=\ln\left(\frac{p\Lambda^3}{kT}\right)
```

すなわち，

```math
\boxed{
\chi=
\ln\left\{
\frac{p}{kT}
\left(\frac{h^2}{2\pi mkT}\right)^{3/2}
\right\}
}
```

となる．
数値を代入すると，

```math
\begin{aligned}
\chi
&=\ln\left(
\frac{2.44631\times10^{19}}
{2.46285\times10^{26}}
\right)\\
&\simeq-16.12483
\end{aligned}
```

を得る．
したがって，

```math
\boxed{\chi\simeq-16.1248}
```

である．

これを全系の分配関数に対する式に代入すると，

```math
\ln Q_N=N(1-\chi)
```

より，

```math
\begin{aligned}
\ln Q_N
&=(2.44631\times10^{19})(17.12483)\\
&\simeq4.18927\times10^{20}
\end{aligned}
```

となる．
よって，全系の並進分配関数は，

```math
\boxed{
Q_N\simeq
\exp(4.18927\times10^{20})
}
```

である．
このように巨大な指数になるため，数値計算では $Q_N$ 自体よりも $\ln Q_N$ を用いる方が適切である．

### 4．Helmholtz自由エネルギー $F_{\mathrm{trans}}$

Helmholtz自由エネルギーは，全系の分配関数を用いて，

```math
F_{\mathrm{trans}}=-kT\ln Q_N
```

と表される．
前節の式を代入すると，

```math
\begin{aligned}
F_{\mathrm{trans}}
&=-kTN(1-\chi)\\
&=NkT(\chi-1)
\end{aligned}
```

を得る．
すなわち，1原子当たりでは，

```math
\boxed{
\frac{F_{\mathrm{trans}}}{N}=kT(\chi-1)
}
```

である．

数値を代入すると，

```math
\begin{aligned}
\frac{F_{\mathrm{trans}}}{N}
&=(4.141947\times10^{-14})
(-16.12483-1)\\
&\simeq-7.09301\times10^{-13}\,\mathrm{erg}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\frac{F_{\mathrm{trans}}}{N}
\simeq-7.093\times10^{-13}\,\mathrm{erg}
}
```

である．

全系の自由エネルギーは，

```math
\begin{aligned}
F_{\mathrm{trans}}
&=N\frac{F_{\mathrm{trans}}}{N}\\
&\simeq(2.44631\times10^{19})
(-7.09301\times10^{-13})\\
&\simeq-1.73517\times10^7\,\mathrm{erg}
\end{aligned}
```

となる．
よって，

```math
\boxed{
F_{\mathrm{trans}}
\simeq-1.7352\times10^7\,\mathrm{erg}
}
```

である．

### 5．内部エネルギー $U_{\mathrm{trans}}$

アルゴンは単原子理想気体である．
並進運動には $x,y,z$ 方向の3つの自由度がある．
古典統計力学のエネルギー等分配則によれば，各自由度は平均エネルギー $kT/2$ を持つ．

したがって，1原子当たりの平均並進運動エネルギーは，

```math
\boxed{
\frac{U_{\mathrm{trans}}}{N}
=\frac32kT
}
```

となる．
数値を代入すると，

```math
\begin{aligned}
\frac{U_{\mathrm{trans}}}{N}
&=\frac32(4.141947\times10^{-14})\\
&=6.21292\times10^{-14}\,\mathrm{erg}
\end{aligned}
```

を得る．

全系の内部エネルギーは，

```math
\begin{aligned}
U_{\mathrm{trans}}
&=N\frac{U_{\mathrm{trans}}}{N}\\
&=\frac32NkT\\
&=\frac32pV
\end{aligned}
```

である．
ここで $pV=NkT$ を用いた．
したがって，

```math
\begin{aligned}
U_{\mathrm{trans}}
&=\frac32(1.01325\times10^6)(1)\\
&=1.519875\times10^6\,\mathrm{erg}
\end{aligned}
```

となる．
よって，

```math
\boxed{
U_{\mathrm{trans}}\simeq1.5199\times10^6\,\mathrm{erg}
}
```

である．

【解答者注釈】
解答例に記載されている $1.5598\times10^6\,\mathrm{erg}$ は，1原子当たりの内部エネルギーと原子数を掛け合わせた値と一致しないため，誤りである．

### 6．エントロピー $S_{\mathrm{trans}}$

エントロピーは，Helmholtz自由エネルギーと内部エネルギーの関係

```math
F=U-TS
```

から求められる．
これを $S$ について解くと，

```math
S=\frac{U-F}{T}
```

となる．
したがって，1原子当たりでは，

```math
\frac{S_{\mathrm{trans}}}{N}
=\frac{1}{T}
\left(
\frac{U_{\mathrm{trans}}}{N}
-\frac{F_{\mathrm{trans}}}{N}
\right)
```

である．
これに，

```math
\frac{U_{\mathrm{trans}}}{N}=\frac32kT,
\qquad
\frac{F_{\mathrm{trans}}}{N}=kT(\chi-1)
```

を代入すると，

```math
\begin{aligned}
\frac{S_{\mathrm{trans}}}{N}
&=\frac{1}{T}
\left[\frac32kT-kT(\chi-1)\right]\\
&=k\left(\frac52-\chi\right)
\end{aligned}
```

を得る．
すなわち，

```math
\boxed{
\frac{S_{\mathrm{trans}}}{N}
=k\left(\frac52-\chi\right)
}
```

である．

数値を代入すると，

```math
\begin{aligned}
\frac{S_{\mathrm{trans}}}{N}
&=(1.380649\times10^{-16})
(2.5+16.12483)\\
&\simeq2.57144\times10^{-15}\,\mathrm{erg/K}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\frac{S_{\mathrm{trans}}}{N}
\simeq2.571\times10^{-15}\,\mathrm{erg/K}
}
```

である．

全系のエントロピーは，

```math
\begin{aligned}
S_{\mathrm{trans}}
&=N\frac{S_{\mathrm{trans}}}{N}\\
&=(2.44631\times10^{19})
(2.57144\times10^{-15})\\
&\simeq6.29054\times10^4\,\mathrm{erg/K}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
S_{\mathrm{trans}}
\simeq6.291\times10^4\,\mathrm{erg/K}
}
```

である．

【解答者注釈】
この値は，熱力学関係式 $S=(U-F)/T$ によっても確認できる．
解答例に記載されている $S_{\mathrm{trans}}/N=1.8808\times10^{-15}\,\mathrm{erg/K}$ は，正しい式 $k(5/2-\chi)$ と一致しないため，誤りである．

### 7．分子1個当たりの化学ポテンシャル $\mu_{\mathrm{trans}}$

化学ポテンシャルは，温度と体積を一定にして粒子を1個追加したときの自由エネルギーの変化を表す．
すなわち，

```math
\mu_{\mathrm{trans}}
=\left(\frac{\partial F_{\mathrm{trans}}}{\partial N}\right)_{T,V}
```

である．
理想気体の自由エネルギー

```math
F_{\mathrm{trans}}=NkT(\chi-1)
```

を用いると，

```math
\boxed{
\mu_{\mathrm{trans}}=kT\chi
}
```

を得る．
これは理想気体において，1粒子当たりの Gibbs 自由エネルギー $G/N$ に等しい．

数値を代入すると，

```math
\begin{aligned}
\mu_{\mathrm{trans}}
&=(4.141947\times10^{-14})(-16.12483)\\
&\simeq-6.67882\times10^{-13}\,\mathrm{erg}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\mu_{\mathrm{trans}}
\simeq-6.679\times10^{-13}\,\mathrm{erg}
}
```

である．

## 8．Gibbs補正についての注意

全系の分配関数を求める際に，

```math
Q_N=\frac{q_1^N}{N!}
```

とすることが重要である．
これは，アルゴン原子が互いに区別できない粒子であることを反映している．

もしGibbs補正を忘れて $Q_N=q_1^N$ とすると，

```math
F_{\mathrm{wrong}}=-NkT\ln q_1
```

となってしまう．
この場合，

```math
\ln q_1\simeq60.7685
```

より，

```math
\frac{F_{\mathrm{wrong}}}{N}
\simeq-2.517\times10^{-12}\,\mathrm{erg}
```

となり，正しい自由エネルギーとは大きく異なる．
したがって，Gibbs補正は不可欠である．

## 9．最終結果と補足

以上から， $300\,\mathrm K$ ， $1\,\mathrm{atm}$ ， $1\,\mathrm{cm^3}$ のアルゴン理想気体について，並進運動に関する各物理量は次のとおりである．

| 物理量 | 値 |
|---|---|
| 原子数 $N$ | $2.4463\times10^{19}$ |
| 熱的ド・ブロイ波長 $\Lambda$ | $1.5953\times10^{-9}\,\mathrm{cm}$ |
| 1粒子分配関数 $q_1$ | $2.4628\times10^{26}$ |
| 全系分配関数 $Q_N$ | $\exp(4.18927\times10^{20})$ |
| Helmholtz自由エネルギー $F_{\mathrm{trans}}$ | $-1.7352\times10^7\,\mathrm{erg}$ |
| 1原子当たりの自由エネルギー $F_{\mathrm{trans}}/N$ | $-7.093\times10^{-13}\,\mathrm{erg}$ |
| 内部エネルギー $U_{\mathrm{trans}}$ | $1.5199\times10^6\,\mathrm{erg}$ |
| 1原子当たりの内部エネルギー $U_{\mathrm{trans}}/N$ | $6.213\times10^{-14}\,\mathrm{erg}$ |
| エントロピー $S_{\mathrm{trans}}$ | $6.291\times10^4\,\mathrm{erg/K}$ |
| 1原子当たりのエントロピー $S_{\mathrm{trans}}/N$ | $2.571\times10^{-15}\,\mathrm{erg/K}$ |
| 化学ポテンシャル $\mu_{\mathrm{trans}}$ | $-6.679\times10^{-13}\,\mathrm{erg}$ |

解答例との比較では，化学ポテンシャル，1原子当たりの自由エネルギー，1原子当たりの内部エネルギーは，使用する物理定数や丸め方の違いを考慮すれば概ね一致する．
一方，解答例の全内部エネルギー $1.5598\times10^6\,\mathrm{erg}$ とエントロピー $1.8808\times10^{-15}\,\mathrm{erg/K}$ （1原子当たり）は誤りであり，それぞれ約 $1.5199\times10^6\,\mathrm{erg}$ ，約 $2.571\times10^{-15}\,\mathrm{erg/K}$ に修正される．

以上が，分配関数から一貫して導出した修正後の解答である．
