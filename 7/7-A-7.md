# 演習問題【7-A-7】

## 解答

水素分子 $\mathrm{H}_2$ には，核スピンの状態によってパラ水素とオルソ水素が存在する．
両者の間の変換は低温では遅いため，それぞれを独立した系として扱うことができる．
本問では，回転分配関数の低温展開を用いて各異性体の比熱を計算し，パラ水素の比熱の方が大きいことを示す．

### 1．回転分配関数と比熱の関係

剛体回転子の回転エネルギー準位は，

```math
E_J=k_{\mathrm B}\Theta_r J(J+1),
\qquad J=0,1,2,\ldots
```

である．
ここで， $k_{\mathrm B}$ は Boltzmann 定数， $\Theta_r=\hbar^2/(2Ik_{\mathrm B})$ は回転温度， $I$ は分子の慣性モーメントである．
以下では， $\Theta_r$ を単に $\theta$ と書く．

水素分子では核スピンと回転状態の対称性の制約により，パラ水素には偶数 $J$ の準位，オルソ水素には奇数 $J$ の準位だけが許される．
したがって，各異性体の回転分配関数は，

```math
r_{\mathrm{even}}
=\sum_{J=0,2,4,\ldots}(2J+1)e^{-\theta J(J+1)/T}
```

および

```math
r_{\mathrm{odd}}
=\sum_{J=1,3,5,\ldots}(2J+1)e^{-\theta J(J+1)/T}
```

である．
核スピンの重率を含めると，パラ水素の分配関数は $r_{\mathrm{even}}$ ，オルソ水素の分配関数は $3r_{\mathrm{odd}}$ となる．
ただし，分配関数に掛かる温度非依存の定数因子は，内部エネルギーや比熱を求める際には消えるため，以下ではそれぞれ $r_{\mathrm{even}}$ ， $r_{\mathrm{odd}}$ を用いる．

1 mol あたりの内部エネルギー $U$ は，分配関数 $r$ から

```math
U=-R\frac{\partial\log r}{\partial(1/T)}
\tag{1}
```

で与えられる．
ここで， $R$ は気体定数である．
したがって，定積比熱は，

```math
C=\frac{dU}{dT}
=R\frac{d}{dT}
\left[-\frac{\partial\log r}{\partial(1/T)}\right]
\tag{2}
```

となる．

以下では，低温 $T\ll\theta$ を考え，指数関数のうち最も寄与の大きい項を残して比熱を求める．

### 2．パラ水素の比熱

パラ水素では偶数 $J$ の準位だけが許される．
回転分配関数の低温展開は，

```math
r_{\mathrm{even}}
=1+5e^{-6\theta/T}
+9e^{-20\theta/T}+\cdots
\tag{3}
```

である．
低温では $e^{-6\theta/T}\ll1$ であり，最初の励起準位 $J=2$ の寄与が主要となる．
したがって，

```math
\begin{aligned}
\log r_{\mathrm{even}}
&\simeq\log\left(1+5e^{-6\theta/T}\right)\\
&\simeq5e^{-6\theta/T}
\end{aligned}
\tag{4}
```

となる．
ここでは $\log(1+x)\simeq x$ （ $|x|\ll1$ ）を用いた．

式 (1) に代入すると，

```math
\begin{aligned}
U_{\mathrm{para}}
&\simeq -R\frac{\partial}{\partial(1/T)}
\left(5e^{-6\theta/T}\right)\\
&=30R\theta e^{-6\theta/T}
\end{aligned}
\tag{5}
```

を得る．
これを温度 $T$ で微分すれば，比熱は，

```math
\begin{aligned}
C_{\mathrm{para}}
&=\frac{dU_{\mathrm{para}}}{dT}\\
&\simeq30R\theta
\frac{6\theta}{T^2}e^{-6\theta/T}
\end{aligned}
```

となる．
よって，

```math
\boxed{
C_{\mathrm{para}}
\simeq180R\left(\frac{\theta}{T}\right)^2
e^{-6\theta/T}
}
\tag{6}
```

である．

### 3．オルソ水素の比熱

オルソ水素では奇数 $J$ の準位だけが許される．
回転分配関数は，

```math
r_{\mathrm{odd}}
=3e^{-2\theta/T}
+7e^{-12\theta/T}
+11e^{-30\theta/T}+\cdots
\tag{7}
```

である．
低温では最低準位 $J=1$ の寄与が支配的となるため，第一項をくくり出すと，

```math
r_{\mathrm{odd}}
=3e^{-2\theta/T}
\left(1+\frac73e^{-10\theta/T}+\cdots\right)
\tag{8}
```

となる．
したがって，

```math
\begin{aligned}
\log r_{\mathrm{odd}}
&=\log3-\frac{2\theta}{T}
+\log\left(1+\frac73e^{-10\theta/T}+\cdots\right)\\
&\simeq\log3-\frac{2\theta}{T}
+\frac73e^{-10\theta/T}
\end{aligned}
\tag{9}
```

である．

式 (1) に代入すると，

```math
\begin{aligned}
U_{\mathrm{ortho}}
&\simeq -R\frac{\partial}{\partial(1/T)}
\left[
\log3-2\theta\frac1T
+\frac73e^{-10\theta/T}
\right]\\
&=2R\theta+\frac{70}{3}R\theta e^{-10\theta/T}
\end{aligned}
\tag{10}
```

となる．
第一項 $2R\theta$ は温度に依存しないため，比熱には寄与しない．
よって，

```math
\begin{aligned}
C_{\mathrm{ortho}}
&=\frac{dU_{\mathrm{ortho}}}{dT}\\
&\simeq\frac{70}{3}R\theta
\frac{10\theta}{T^2}e^{-10\theta/T}
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
C_{\mathrm{ortho}}
\simeq\frac{700}{3}R
\left(\frac{\theta}{T}\right)^2e^{-10\theta/T}
}
\tag{11}
```

である．

### 4．両者の比熱の比較

式 (6)，(11) から比熱の比を計算すると，

```math
\begin{aligned}
\frac{C_{\mathrm{para}}}{C_{\mathrm{ortho}}}
&\simeq
\frac{180R(\theta/T)^2e^{-6\theta/T}}
{(700/3)R(\theta/T)^2e^{-10\theta/T}}\\
&=\frac{27}{35}e^{4\theta/T}
\end{aligned}
\tag{12}
```

となる．
低温 $T\to0$ では $\theta/T\to\infty$ であるから，

```math
\lim_{T\to0}
\frac{C_{\mathrm{para}}}{C_{\mathrm{ortho}}}
=\infty
```

である．
したがって，低温では，

```math
\boxed{
C_{\mathrm{para}}>C_{\mathrm{ortho}}
}
```

が成り立つ．

### 結論

パラ水素では最低回転準位 $J=0$ から最初の励起準位 $J=2$ までのエネルギー差が $6k_{\mathrm B}\theta$ である．
一方，オルソ水素では最低準位 $J=1$ から次の許容準位 $J=3$ までのエネルギー差が $10k_{\mathrm B}\theta$ である．
このため，低温ではパラ水素の比熱は $e^{-6\theta/T}$ に比例する一方，オルソ水素の比熱はより強く抑制される $e^{-10\theta/T}$ に比例する．
したがって，十分低温ではパラ水素の比熱の方が大きくなるのである．
