# 演習問題【7-A-7】

## 解答

水素分子には，核スピンの組み合わせによって，オルソ水素とパラ水素という2つの状態が存在する．
低温において，これらの状態間の変換は非常に遅いため，それぞれを独立した系として扱うことができる．

回転特性温度 $\theta = \frac{\hbar^2}{2Ik_B}$ （ $I$ は慣性モーメント）を導入し，剛体回転子のエネルギー準位を $E_J = J(J+1)k_B\theta$ と表す．
ここで $R$ は気体定数， $T$ は絶対温度である．

まず，統計力学における分配関数 $r$ と内部エネルギー $U$ ，および定積比熱 $C$ の関係を整理する．
1モルあたりの内部エネルギー $U$ は，分配関数 $r$ を用いて次のように表される：

$$U = -R \frac{\partial \log r}{\partial (1/T)}$$

定積比熱 $C$ は，内部エネルギーを温度で微分することで得られる：

```math
C = \frac{dU}{dT} = R \frac{\partial}{\partial T} \left\{ -\frac{\partial \log r}{\partial (1/T)} \right\}
```

以下に，パラ水素とオルソ水素それぞれの低温における比熱を計算する．

### 1. パラ水素の比熱

解答例より，パラ水素の分配関数 $r_{\text{even}}$ の低温における展開は以下の通りである：

$$r_{\text{even}} = 1 + 5e^{-6\theta/T} + 9e^{-20\theta/T} + \dots$$

低温（ $T \to 0$ ）では，第2項以降の指数関数項 $\epsilon = 5e^{-6\theta/T}$ は $\epsilon \ll 1$ を満たす．
したがって， $\log(1+\epsilon) \simeq \epsilon$ （ $\epsilon \ll 1$ ）を用いて，

$$\log r_{\text{even}} \simeq \log(1 + 5e^{-6\theta/T}) \simeq 5e^{-6\theta/T}$$

これを用いて，内部エネルギーの項を計算する：

$$-\frac{\partial \log r_{\text{even}}}{\partial (1/T)} \simeq -\frac{\partial}{\partial (1/T)} \left( 5e^{-6\theta(1/T)} \right) = -5(-6\theta)e^{-6\theta/T} = 30\theta e^{-6\theta/T}$$

次に，これを温度 $T$ で微分して比熱を求める．
微分演算 $\frac{\partial}{\partial T}$ は， $\beta = 1/T$ とおくと $\frac{\partial}{\partial T} = -\frac{1}{T^2} \frac{\partial}{\partial \beta}$ と書けるので，

$$C_{\text{para}} = R \left( -\frac{1}{T^2} \right) \frac{\partial}{\partial (1/T)} \left( 30\theta e^{-6\theta/T} \right) = R \left( -\frac{1}{T^2} \right) (30\theta)(-6\theta)e^{-6\theta/T} = 180R \left(\frac{\theta}{T}\right)^2 e^{-6\theta/T}$$

したがって，パラ水素の低温における比熱は次のように求められる：

$$C_{\text{para}} \simeq 180R \left(\frac{\theta}{T}\right)^2 e^{-6\theta/T}$$

### 2. オルソ水素の比熱

オルソ水素の分配関数 $r_{\text{odd}}$ の低温における展開は以下の通りである：

$$r_{\text{odd}} = 3e^{-2\theta/T} + 7e^{-12\theta/T} + 11e^{-30\theta/T} + \dots$$

これを第1項でくくりだすと，

$$r_{\text{odd}} = 3e^{-2\theta/T} \left( 1 + \frac{7}{3}e^{-10\theta/T} + \dots \right)$$

となる．
対数をとると，

$$\log r_{\text{odd}} = \log 3 - \frac{2\theta}{T} + \log \left( 1 + \frac{7}{3}e^{-10\theta/T} + \dots \right) \simeq \log 3 - \frac{2\theta}{T} + \frac{7}{3}e^{-10\theta/T}$$

となる．
これを用いて内部エネルギーの項を計算する：

$$-\frac{\partial \log r_{\text{odd}}}{\partial (1/T)} \simeq -\frac{\partial}{\partial (1/T)} \left( \log 3 - 2\theta(1/T) + \frac{7}{3}e^{-10\theta(1/T)} \right) = 2\theta - \frac{7}{3}(-10\theta)e^{-10\theta/T} = 2\theta + \frac{70}{3}\theta e^{-10\theta/T}$$

これを温度 $T$ で微分して比熱を求める：
定数項 $2\theta$ は温度によらないため， $\frac{\partial}{\partial(1/T)} (2\theta) = 0$ であり比熱への寄与はない．
指数小項のみが寄与し，

$$C_{\text{ortho}} = R \left( -\frac{1}{T^2} \right) \frac{\partial}{\partial (1/T)} \left( \frac{70}{3}\theta e^{-10\theta/T} \right) = R \left( -\frac{1}{T^2} \right) \left( \frac{70}{3}\theta (-10\theta) e^{-10\theta/T} \right) = \frac{700}{3}R \left(\frac{\theta}{T}\right)^2 e^{-10\theta/T}$$

したがって，オルソ水素の低温における比熱は次のように求められる：

$$C_{\text{ortho}} \simeq \frac{700}{3}R \left(\frac{\theta}{T}\right)^2 e^{-10\theta/T}$$

### 3. 比較

得られた2つの比熱の式を比較する．
両者の比を計算すると，

$$\frac{C_{\text{para}}}{C_{\text{ortho}}} = \frac{180R(\theta/T)^2 e^{-6\theta/T}}{\frac{700}{3}R(\theta/T)^2 e^{-10\theta/T}} = \frac{540}{700}e^{4\theta/T} = \frac{27}{35}e^{4\theta/T}$$

低温（ $T \to 0$ ，すなわち $\theta/T \to \infty$ ）では， $e^{4\theta/T} \to \infty$ であるから， $\frac{C_{\text{para}}}{C_{\text{ortho}}} \to \infty$ ．
ゆえに，低温において $C_{\text{para}} > C_{\text{ortho}}$ が成り立つことが示された．

## 解説

この問題の核心は，水素分子の核スピン状態（オルソとパラ）が回転エネルギー準位の統計的重み（分配関数）にどのように影響するかを理解することにある．

パラ水素は核スピンが **反対称** な状態（一重項，核スピン全量子数 $I=0$ ）であり，回転波動関数は対称でなければならない．
その結果，回転準位 $J$ は **偶数**（ $J=0, 2, \dots$ ）のみが許容される．
一方，オルソ水素は核スピンが **対称** な状態（三重項， $I=1$ ）であり，回転波動関数は反対称でなければならない．
その結果，回転準位 $J$ は **奇数**（ $J=1, 3, \dots$ ）のみが許容される．
（これらはPauli原理，すなわちフェルミオンからなる全系の全波動関数が反対称でなければならないことから要請される性質である．）

低温では，最も低いエネルギー準位が支配的となる．

- パラ水素の場合，基底状態は $J=0$ であり，そのエネルギーは非常に低い．
  温度を上げると，次に低い $J=2$ の準位が励起され始める．
  この「準位の励起」が比熱のピークとして現れる．
- オルソ水素の場合，基底状態は $J=1$ であり，パラ水素の基底状態よりもエネルギーが高い．
  低温では $J=1$ 準位に留まり，次の $J=3$ 準位への励起は $J=1 \to J=2$ よりもはるかに高いエネルギーを必要とするため，比熱への寄与は極めて小さくなる．

このように，パラ水素はより低いエネルギーでの「準位の遷移」を経験するため，低温における比熱がオルソ水素よりも大きくなるのである．
