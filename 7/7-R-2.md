# 例題【7-R-2】

## 解答

炭酸ガス $\mathrm{CO_2}$ を理想気体として扱い， $0^\circ\mathrm C$ ， $1\,\mathrm{atm}$ におけるモル Helmholtz 自由エネルギー $\bar F$ ，モルエントロピー $\bar S$ ，定積モル比熱 $\bar C_V$ を求める．

分子の運動を並進運動，回転運動，内部振動に分け，それぞれの分配関数から各熱力学関数への寄与を計算する．
電子基底状態は縮重していないため，電子状態からの寄与はないものとする．

計算には次の定数を用いる．

```math
\begin{aligned}
T&=273.15\ \mathrm K, \\
p&=1.01325\times10^6\ \mathrm{erg/cm^3}, \\
k&=1.380649\times10^{-16}\ \mathrm{erg/K}, \\
h&=6.62607015\times10^{-27}\ \mathrm{erg\,s}, \\
R&=1.987204\ \mathrm{cal/(mol \,K)}.
\end{aligned}
```

分子の質量は，原子質量単位 $1.65963\times10^{-24}\,\mathrm g$ を用いて，

```math
\begin{aligned}
m &=44.010\times1.65963\times10^{-24} \\
&=7.3040\times10^{-23}\ \mathrm g
\end{aligned}
```

となる．また，

```math
RT=542.805\ \mathrm{cal/mol}
```

である．以下，対数はすべて自然対数を表す．

## 1．並進運動による寄与

### 1.1　並進分配関数

分子が空間内を自由に運動する並進運動の分配関数を考える．
分子1個の並進分配関数は，体積 $V$ の中で

```math
q_{\mathrm{trans},1} =\left(\frac{2\pi mkT}{h^2}\right)^{3/2}V
```

と表される．

気体分子が $N$ 個あるとき，分子を区別できないことを考慮して，理想気体の全分配関数には $N!$ で割る因子が入る．
Stirling の近似

```math
\ln N!\simeq N\ln N-N
```

を用いると，並進運動によるモル Helmholtz 自由エネルギーは

```math
\bar F_{\mathrm{trans}} =-RT\left[ \ln\left\{ \left(\frac{2\pi mkT}{h^2}\right)^{3/2} \frac VN \right\}+1 \right]
```

となる．
ここで， $V/N$ は分子1個当たりの体積である．

理想気体の状態方程式

```math
pV=NkT
```

から

```math
\frac VN=\frac{kT}{p}
```

であるため，並進分配関数を

```math
\boxed{
q_{\mathrm{trans}} =\left(\frac{2\pi mkT}{h^2}\right)^{3/2} \frac{kT}{p}
}
```

と定めることができる．
したがって，

```math
\begin{aligned}
\ln q_{\mathrm{trans}} &=\ln\left[ \left(\frac{2\pi mkT}{h^2}\right)^{3/2} \frac{kT}{p} \right] \\
&\simeq16.036
\end{aligned}
```

を得る．

【解答者注釈】
解答例に記載されている $4.673$ は正しくなく，正しい値は約 $16.036$ である．

### 1.2　Helmholtz 自由エネルギー

上の分配関数を用いると，

```math
\bar F_{\mathrm{trans}} =-RT(\ln q_{\mathrm{trans}}+1)
```

である．
したがって，

```math
\begin{aligned}
\bar F_{\mathrm{trans}} &=-542.805(16.036+1) \\
&\simeq-9247.2\ \mathrm{cal/mol}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\bar F_{\mathrm{trans}} \simeq-9.247\times10^3\ \mathrm{cal/mol}
}
\quad \cdots (1)
```

である．

なお，解答例では式に $+1$ を記載している一方で，最終的な数値計算ではこの $+1$ を落としている．
したがって，解答例には対数値の誤りに加えて，この数値計算上の誤りもある．

### 1.3　エントロピー

並進運動によるモルエントロピーは，

```math
\bar S_{\mathrm{trans}} =R\left(\ln q_{\mathrm{trans}}+\frac{5}{2}\right)
```

で与えられる．
したがって，

```math
\begin{aligned}
\bar S_{\mathrm{trans}} &=1.987204(16.036+2.500) \\
&\simeq36.835\ \mathrm{cal/(mol\,K)}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\bar S_{\mathrm{trans}} \simeq36.835\ \mathrm{cal/(mol\,K)}
}
\quad \cdots (2)
```

である．

### 1.4　定積モル比熱

並進運動には空間の $x,y,z$ 方向の3自由度がある．
古典統計力学の等分配則により，各二次形式の自由度はモル内部エネルギーに $RT/2$ ずつ寄与する．
そのため，

```math
\boxed{
\bar C_{\mathrm{trans}} =\frac32R =2.981\ \mathrm{cal/(mol\,K)}
}
\quad \cdots (3)
```

となる．

## 2．回転運動による寄与

### 2.1　回転分配関数

$\mathrm{CO_2}$ は直線状分子であり，回転運動に寄与する独立な回転自由度は2つである．
慣性モーメントを $I$ とすると，回転特性温度は

```math
\Theta_r=\frac{h^2}{8\pi^2Ik}
```

で与えられる．
与えられた慣性モーメント

```math
I=71.67\times10^{-40}\ \mathrm{g\,cm^2}
```

を代入すると，

```math
\boxed{
\Theta_r\simeq0.56196\ \mathrm K
}
```

となる．

$T=273.15\,\mathrm K$ は回転特性温度より十分に大きいため，古典近似を用いてよい．
また，2つの酸素原子が同一であるため，対称数は $\gamma=2$ である．
したがって，

```math
q_{\mathrm{rot}}=\frac{T}{\gamma\Theta_r} =\frac{T}{2\Theta_r}
```

となり，

```math
\begin{aligned}
\ln q_{\mathrm{rot}} &=\ln\left(\frac{273.15}{2\times0.56196}\right) \\
&\simeq5.4932
\end{aligned}
```

を得る．

### 2.2　Helmholtz 自由エネルギー

回転運動によるモル自由エネルギーは，

```math
\bar F_{\mathrm{rot}}=-RT\ln q_{\mathrm{rot}}
```

である．
したがって，

```math
\begin{aligned}
\bar F_{\mathrm{rot}} &=-542.805\times5.4932 \\
&\simeq-2981.7\ \mathrm{cal/mol}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\bar F_{\mathrm{rot}} \simeq-2.982\times10^3\ \mathrm{cal/mol}
}
\quad \cdots (4)
```

である．

### 2.3　エントロピー

回転運動によるエントロピーは，

```math
\bar S_{\mathrm{rot}} =R(\ln q_{\mathrm{rot}}+1)
```

である．
したがって，

```math
\begin{aligned}
\bar S_{\mathrm{rot}} &=1.987204(5.4932+1) \\
&\simeq12.903\ \mathrm{cal/(mol\,K)}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\bar S_{\mathrm{rot}} \simeq12.903\ \mathrm{cal/(mol\,K)}
}
\quad \cdots (5)
```

である．

### 2.4　定積モル比熱

直線状分子の回転自由度は2つであり，古典的な等分配則から，

```math
\boxed{
\bar C_{\mathrm{rot}} =R =1.9872\ \mathrm{cal/(mol\,K)}
}
\quad \cdots (6)
```

となる．

## 3．内部振動による寄与

### 3.1　振動特性温度

問題文で与えられた振動の波数は，

```math
\bar\nu_1=\bar\nu_2=667.3\ \mathrm{cm}^{-1},
```

```math
\bar\nu_3=1383.3\ \mathrm{cm}^{-1}, \qquad \bar\nu_4=2439.3\ \mathrm{cm}^{-1}
```

である．
炭酸ガス分子の振動モードは4つとして数え， $\bar\nu_1$ と $\bar\nu_2$ の2つのモードをそれぞれ含める．

調和振動子の振動特性温度は，

```math
\Theta_i=\frac{hc\bar\nu_i}{k}
```

で与えられる．
波数を $\mathrm{cm}^{-1}$ で表せば，

```math
\frac{hc}{k} =1.4387769\ \mathrm{K\,cm}
```

を用いることができる．
したがって，

```math
\begin{aligned}
\Theta_1=\Theta_2&\simeq960.096\ \mathrm K, \\
\Theta_3&\simeq1990.260\ \mathrm K, \\
\Theta_4&\simeq3509.608\ \mathrm K.
\end{aligned}
```

各モードについて，

```math
x_i=\frac{\Theta_i}{T}
```

とおくと，

```math
\boxed{
(x_1,x_2,x_3,x_4) \simeq(3.5149,3.5149,7.2863,12.8486)
}
\quad \cdots (7)
```

となる．

### 3.2　振動分配関数と Helmholtz 自由エネルギー

量子力学的な調和振動子のエネルギー準位は，

```math
E_n=\left(n+\frac{1}{2}\right)h c\bar\nu \qquad(n=0,1,2,\ldots)
```

である．
このため，各振動モードには零点振動エネルギー $hc\bar\nu/2$ が存在する．

振動分配関数は，各モードの分配関数を掛け合わせて，

```math
q_{\mathrm{vib}} =\prod_{i=1}^{4} \frac{\exp(-\Theta_i/2T)} {1-\exp(-\Theta_i/T)}
```

となる．
したがって，

```math
\ln q_{\mathrm{vib}} =\sum_{i=1}^{4} \left[ -\frac{\Theta_i}{2T} -\ln\left(1-e^{-\Theta_i/T}\right) \right]
```

である．
式(7)の値を用いて計算すると，

```math
\boxed{
\ln q_{\mathrm{vib}}\simeq-13.5213
}
```

となる．

よって，振動によるモル Helmholtz 自由エネルギーは，

```math
\bar F_{\mathrm{vib}}=-RT\ln q_{\mathrm{vib}}
```

から，

```math
\begin{aligned}
\bar F_{\mathrm{vib}} &=-542.805\times(-13.5213) \\
&\simeq7339.4\ \mathrm{cal/mol}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\bar F_{\mathrm{vib}} \simeq7.339\times10^3\ \mathrm{cal/mol}
}
\quad \cdots (8)
```

である．

振動自由エネルギーが正になるのは，ここでは振動の零点エネルギーを含めているためである．
これは計算上の矛盾ではない．
自由エネルギーの絶対値はエネルギーの基準に依存するため，以下では電子基底状態のエネルギーをゼロとし，振動については零点エネルギーを含めるという基準を採用する．

### 3.3　エントロピー

調和振動子のモルエントロピーは，

```math
\bar S_{\mathrm{vib}} =R\sum_{i=1}^{4} \left[ -\ln(1-e^{-x_i}) +\frac{x_i}{e^{x_i}-1} \right]
```

と表される．

各項を式(7)から計算すると，

```math
\sum_{i=1}^{4} \left[ -\ln(1-e^{-x_i}) +\frac{x_i}{e^{x_i}-1} \right] \simeq0.28167
```

である．
したがって，

```math
\begin{aligned}
\bar S_{\mathrm{vib}} &=1.987204\times0.28167 \\
&\simeq0.55974\ \mathrm{cal/(mol\,K)}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\bar S_{\mathrm{vib}} \simeq0.5597\ \mathrm{cal/(mol\,K)}
}
\quad \cdots (9)
```

である．

### 3.4　定積モル比熱

調和振動子の定積モル比熱は，

```math
\bar C_{\mathrm{vib}} =R\sum_{i=1}^{4} \frac{x_i^2e^{x_i}}{(e^{x_i}-1)^2}
```

で与えられる．
式(7)の各 $x_i$ を代入すると，

```math
\sum_{i=1}^{4} \frac{x_i^2e^{x_i}}{(e^{x_i}-1)^2} \simeq0.81773
```

を得る．
したがって，

```math
\begin{aligned}
\bar C_{\mathrm{vib}} &=1.987204\times0.81773 \\
&\simeq1.6250\ \mathrm{cal/(mol\,K)}
\end{aligned}
```

である．
よって，

```math
\boxed{
\bar C_{\mathrm{vib}} \simeq1.6250\ \mathrm{cal/(mol\,K)}
}
\quad \cdots (10)
```

となる．

## 4．電子状態の寄与

基底電子状態は $^{1}\Sigma_g^+$ であり，縮重していない．
また，基底電子状態のエネルギーをゼロに選ぶので，電子分配関数は

```math
q_{\mathrm{elec}}=1
```

である．
よって，

```math
\ln q_{\mathrm{elec}}=0
```

となるため，電子状態からの自由エネルギー，エントロピー，比熱への寄与はいずれもゼロである．

## 5．全熱力学関数

並進運動，回転運動，振動運動は独立に扱えるので，全分配関数は各分配関数の積である．
したがって，各運動に対応するモル自由エネルギー，エントロピー，比熱を足し合わせれば，全熱力学関数が得られる．

### 5.1　全 Helmholtz 自由エネルギー

式(1)，式(4)，式(8)より，

```math
\begin{aligned}
\bar F &=\bar F_{\mathrm{trans}} +\bar F_{\mathrm{rot}} +\bar F_{\mathrm{vib}} \\
&\simeq-9247.2-2981.7+7339.4 \\
&\simeq-4889.5\ \mathrm{cal/mol}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar F\simeq-4.890\times10^3\ \mathrm{cal/mol}
}
```

である．

### 5.2　全エントロピー

式(2)，式(5)，式(9)より，

```math
\begin{aligned}
\bar S &=\bar S_{\mathrm{trans}} +\bar S_{\mathrm{rot}} +\bar S_{\mathrm{vib}} \\
&\simeq36.8348+12.9033+0.55974 \\
&\simeq50.2979\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar S\simeq50.298\ \mathrm{cal/(mol\,K)}
}
```

である．

### 5.3　全定積モル比熱

式(3)，式(6)，式(10)より，

```math
\begin{aligned}
\bar C_V &=\bar C_{\mathrm{trans}} +\bar C_{\mathrm{rot}} +\bar C_{\mathrm{vib}} \\
&\simeq2.9808+1.9872+1.6250 \\
&\simeq6.5930\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar C_V\simeq6.593\ \mathrm{cal/(mol\,K)}
}
```

である．

## 6．最終結果と補足

以上より，求める熱力学関数は，

```math
\boxed{
\begin{aligned}
\bar F&\simeq-4.890\times10^3\ \mathrm{cal/mol}, \\
\bar S&\simeq50.298\ \mathrm{cal/(mol\,K)}, \\
\bar C_V&\simeq6.593\ \mathrm{cal/(mol\,K)}.
\end{aligned}
}
```

SI 単位に換算すると，

```math
\boxed{
\begin{aligned}
\bar F&\simeq-20.458\ \mathrm{kJ/mol}, \\
\bar S&\simeq210.45\ \mathrm{J/(mol\,K)}, \\
\bar C_V&\simeq27.585\ \mathrm{J/(mol\,K)}.
\end{aligned}
}
```

なお，解答例の振動計算では，特性温度を温度で割った値に丸めの不整合があるため，振動自由エネルギーとして約 $7337\ \mathrm{cal/mol}$ が記載されている．
その丸めた値を使用すると全自由エネルギーは約 $-4893\ \mathrm{cal/mol}$ になるが，問題文の波数から特性温度を一貫して計算すると約 $7339\ \mathrm{cal/mol}$ となり，全自由エネルギーは約 $-4890\ \mathrm{cal/mol}$ となる．
どちらも有効数字3桁では $-4.89\times10^3\ \mathrm{cal/mol}$ で一致する．

また，実測値との比較では温度に注意する必要がある．
NIST Chemistry WebBook に掲載されている標準モルエントロピー $213.785\ \mathrm{J/(mol\,K)}$ は $298.15\,\mathrm K$ ， $1\,\mathrm{bar}$ の値であり， $273.15\,\mathrm K$ の値ではない．

本解答の $273.15\,\mathrm K$ ， $1\,\mathrm{atm}$ における値 $210.45\ \mathrm{J/(mol\,K)}$ は，温度の違いを踏まえれば妥当な値である．
