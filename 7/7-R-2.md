# 例題【7-R-2】

## 解答

CO₂を理想気体とみなし，0 ℃，1 atm におけるモル Helmholtz 自由エネルギー $\bar F$ ，モルエントロピー $\bar S$ ，定積モル比熱 $\bar C_V$ を求める．

分子の運動を並進運動，回転運動，内部振動に分け，各運動の分配関数から熱力学関数を計算する．
電子状態については，問題文の条件に従い，基底状態のみを考える．

## 1．計算条件と定数

温度と圧力は，

```math
T=273.15\ \mathrm K,
\qquad
p=1.01325\times10^6\ \mathrm{erg/cm^3}
```

である．

計算には次の定数を用いる．

```math
\begin{aligned}
k&=1.380649\times10^{-16}\ \mathrm{erg/K},\\
h&=6.62607015\times10^{-27}\ \mathrm{erg\,s},\\
R&=1.987204\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

統一原子質量単位として，

```math
1\ \mathrm u=1.66053906892\times10^{-24}\ \mathrm g
```

を用いる．
問題文で与えられた分子量は44.010であるから，CO₂分子の質量は，

```math
\begin{aligned}
m
&=44.010\times1.66053906892\times10^{-24}\\
&=7.30803244\times10^{-23}\ \mathrm g
\end{aligned}
```

となる．

また，

```math
RT=1.987204\times273.15
=542.80477\ \mathrm{cal/mol}
```

である．
以下の対数はすべて自然対数とする．

## 2．並進運動による寄与

### 2.1　並進分配関数

質量 $m$ の分子1個が体積 $V$ の中を自由に運動するとき，並進分配関数は

```math
q_{\mathrm{trans},1}
=
V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
```

である．

分子が $N$ 個ある理想気体の全分配関数は，分子が区別できないことを考慮して，

```math
Q_{\mathrm{trans}}
=
\frac{q_{\mathrm{trans},1}^{\,N}}{N!}
```

となる．

Helmholtz自由エネルギー

```math
F=-kT\ln Q_{\mathrm{trans}}
```

に Stirling の近似

```math
\ln N!\simeq N\ln N-N
```

を用いると，モル並進自由エネルギーは，

```math
\bar F_{\mathrm{trans}}
=
-RT\left[
\ln\left\{
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\frac VN
\right\}+1
\right]
```

となる．

理想気体の状態方程式

```math
pV=NkT
```

より，

```math
\frac VN=\frac{kT}{p}
```

である．
そこで，

```math
q_{\mathrm{trans}}
=
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\frac{kT}{p}
```

と定義する．
これは無次元量である．

与えられた数値を代入すると，

```math
q_{\mathrm{trans}}
\simeq9.2192803\times10^6
```

となる．
したがって，

```math
\boxed{
\ln q_{\mathrm{trans}}=16.0368075
}
```

を得る．

### 2.2　Helmholtz自由エネルギー

上の結果から，

```math
\bar F_{\mathrm{trans}}
=-RT(\ln q_{\mathrm{trans}}+1)
```

である．
したがって，

```math
\begin{aligned}
\bar F_{\mathrm{trans}}
&=-542.80477(16.0368075+1)\\
&\simeq-9247.66\ \mathrm{cal/mol}.
\end{aligned}
```

よって，

```math
\boxed{
\bar F_{\mathrm{trans}}
\simeq-9.24766\times10^3\ \mathrm{cal/mol}
}
\tag{1}
```

である．

### 2.3　エントロピー

並進運動によるモルエントロピーは，

```math
\bar S_{\mathrm{trans}}
=R\left(\ln q_{\mathrm{trans}}+\frac52\right)
```

である．
したがって，

```math
\begin{aligned}
\bar S_{\mathrm{trans}}
&=1.987204(16.0368075+2.5)\\
&\simeq36.83642\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

よって，

```math
\boxed{
\bar S_{\mathrm{trans}}
\simeq36.83642\ \mathrm{cal/(mol\,K)}
}
\tag{2}
```

である．

### 2.4　定積モル比熱

並進運動には $x,y,z$ 方向の3つの自由度がある．
古典統計力学の等分配則によれば，各自由度はモル内部エネルギーに $RT/2$ ずつ寄与する．

したがって，

```math
\boxed{
\bar C_{\mathrm{trans}}
=\frac32R
=2.980806\ \mathrm{cal/(mol\,K)}
}
\tag{3}
```

となる．

## 3．回転運動による寄与

### 3.1　回転分配関数

CO₂は直線状分子であるため，独立な回転自由度は2つである．
回転特性温度は，

```math
\Theta_r=\frac{h^2}{8\pi^2Ik}
```

で与えられる．

問題文の慣性能率

```math
I=71.67\times10^{-40}\ \mathrm{g\,cm^2}
```

を代入すると，

```math
\boxed{
\Theta_r\simeq0.561955\ \mathrm K
}
```

となる．

ここで，

```math
\frac{\Theta_r}{T}
\simeq0.0020578\ll1
```

であるため，回転分配関数には古典近似を用いることができる．

また，CO₂は両端に同一の酸素原子を持つため，回転対称数は

```math
\sigma=2
```

である．
したがって，回転分配関数は，

```math
q_{\mathrm{rot}}
=\frac{T}{2\Theta_r}
```

となる．

数値を代入すると，

```math
\begin{aligned}
\ln q_{\mathrm{rot}}
&=\ln\left(\frac{273.15}{2\times0.561955}\right)\\
&\simeq5.493207.
\end{aligned}
```

### 3.2　Helmholtz自由エネルギー

回転分配関数によるモル自由エネルギーは，

```math
\bar F_{\mathrm{rot}}
=-RT\ln q_{\mathrm{rot}}
```

である．
よって，

```math
\begin{aligned}
\bar F_{\mathrm{rot}}
&=-542.80477\times5.493207\\
&\simeq-2981.74\ \mathrm{cal/mol}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar F_{\mathrm{rot}}
\simeq-2.98174\times10^3\ \mathrm{cal/mol}
}
\tag{4}
```

である．

### 3.3　エントロピー

回転分配関数は温度に比例するので，

```math
\bar S_{\mathrm{rot}}
=R(\ln q_{\mathrm{rot}}+1)
```

となる．
したがって，

```math
\begin{aligned}
\bar S_{\mathrm{rot}}
&=1.987204(5.493207+1)\\
&\simeq12.90333\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

よって，

```math
\boxed{
\bar S_{\mathrm{rot}}
\simeq12.90333\ \mathrm{cal/(mol\,K)}
}
\tag{5}
```

である．

### 3.4　定積モル比熱

直線状分子の回転自由度は2つである．
古典的な等分配則から，

```math
\boxed{
\bar C_{\mathrm{rot}}
=R=1.987204\ \mathrm{cal/(mol\,K)}
}
\tag{6}
```

となる．

## 4．内部振動による寄与

### 4.1　振動特性温度

問題文で与えられた基準振動の波数は，

```math
\begin{aligned}
\bar\nu_1=\bar\nu_2&=667.3\ \mathrm{cm^{-1}},\\
\bar\nu_3&=1383.3\ \mathrm{cm^{-1}},\\
\bar\nu_4&=2439.3\ \mathrm{cm^{-1}}
\end{aligned}
```

である．

直線状三原子分子の振動自由度は

```math
3\times3-5=4
```

であり， $\bar\nu_1,\bar\nu_2$ は二重縮退した曲げ振動に対応する．
したがって，4つの振動モードとして数える．

波数 $\bar\nu_i$ の調和振動子に対する振動特性温度は，

```math
\Theta_i=\frac{hc\bar\nu_i}{k}
```

である．
波数を $\mathrm{cm^{-1}}$ で表すとき，

```math
\frac{hc}{k}=1.4387769\ \mathrm{K\,cm}
```

を使うことができる．
よって，

```math
\begin{aligned}
\Theta_1=\Theta_2&\simeq960.0958\ \mathrm K,\\
\Theta_3&\simeq1990.2601\ \mathrm K,\\
\Theta_4&\simeq3509.6085\ \mathrm K.
\end{aligned}
```

各モードについて，

```math
x_i=\frac{\Theta_i}{T}
```

とおけば，

```math
\boxed{
(x_1,x_2,x_3,x_4)
\simeq
(3.514903,\ 3.514903,\ 7.286327,\ 12.848649)
}
\tag{7}
```

となる．

### 4.2　振動分配関数とHelmholtz自由エネルギー

調和振動子のエネルギー準位は，

```math
E_n=\left(n+\frac12\right)hc\bar\nu_i,
\qquad n=0,1,2,\ldots
```

である．
したがって，1つの振動モードの分配関数は，

```math
\begin{aligned}
q_i
&=\sum_{n=0}^{\infty}
e^{-(n+1/2)\Theta_i/T}\\
&=\frac{e^{-\Theta_i/(2T)}}{1-e^{-\Theta_i/T}}
\end{aligned}
```

となる．

振動モードは独立であるため，全振動分配関数は各モードの分配関数の積である．
よって，

```math
q_{\mathrm{vib}}
=
\prod_{i=1}^{4}
\frac{e^{-\Theta_i/(2T)}}{1-e^{-\Theta_i/T}}
```

であり，

```math
\ln q_{\mathrm{vib}}
=
\sum_{i=1}^{4}
\left[
-\frac{\Theta_i}{2T}
-\ln(1-e^{-\Theta_i/T})
\right]
```

を得る．

式 (7) の値を代入すると，

```math
\boxed{
\ln q_{\mathrm{vib}}
\simeq-13.5212989
}
```

となる．

したがって，振動によるモル自由エネルギーは，

```math
\begin{aligned}
\bar F_{\mathrm{vib}}
&=-RT\ln q_{\mathrm{vib}}\\
&=-542.80477\times(-13.5212989)\\
&\simeq7339.43\ \mathrm{cal/mol}.
\end{aligned}
```

よって，

```math
\boxed{
\bar F_{\mathrm{vib}}
\simeq7.33943\times10^3\ \mathrm{cal/mol}
}
\tag{8}
```

である．

ここで，振動分配関数には

```math
e^{-\Theta_i/(2T)}
```

が含まれているため，零点振動エネルギー $hc\bar\nu_i/2$ も自由エネルギーに含まれている．
このエネルギー基準では，振動自由エネルギーは正の値になり得る．
これは物理的な矛盾ではない．

### 4.3　エントロピー

各振動モードの寄与を足し合わせると，モルエントロピーは，

```math
\bar S_{\mathrm{vib}}
=
R\sum_{i=1}^{4}
\left[
-\ln(1-e^{-x_i})
+\frac{x_i}{e^{x_i}-1}
\right]
```

である．

式 (7) の値を代入すると，

```math
\sum_{i=1}^{4}
\left[
-\ln(1-e^{-x_i})
+\frac{x_i}{e^{x_i}-1}
\right]
\simeq0.281674
```

となる．
したがって，

```math
\begin{aligned}
\bar S_{\mathrm{vib}}
&=1.987204\times0.281674\\
&\simeq0.559743\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

よって，

```math
\boxed{
\bar S_{\mathrm{vib}}
\simeq0.559743\ \mathrm{cal/(mol\,K)}
}
\tag{9}
```

である．

### 4.4　定積モル比熱

調和振動子の定積モル比熱は，

```math
\bar C_{\mathrm{vib}}
=
R\sum_{i=1}^{4}
\frac{x_i^2e^{x_i}}{(e^{x_i}-1)^2}
```

である．
式 (7) の値から，

```math
\sum_{i=1}^{4}
\frac{x_i^2e^{x_i}}{(e^{x_i}-1)^2}
\simeq0.817727
```

となる．
したがって，

```math
\begin{aligned}
\bar C_{\mathrm{vib}}
&=1.987204\times0.817727\\
&\simeq1.624991\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

よって，

```math
\boxed{
\bar C_{\mathrm{vib}}
\simeq1.624991\ \mathrm{cal/(mol\,K)}
}
\tag{10}
```

である．

## 5．電子状態の寄与

問題文によると，基底電子状態は

```math
{}^1\Sigma_g^+
```

であり，縮重していない．
電子基底状態のエネルギーをゼロとし，励起電子状態の熱的占有を無視すると，電子分配関数は，

```math
q_{\mathrm{elec}}=1
```

である．

したがって，

```math
\ln q_{\mathrm{elec}}=0
```

となり，電子状態による自由エネルギー，エントロピー，比熱への寄与はいずれもゼロである．

## 6．全熱力学関数

各運動の分配関数が独立な積で表されるため，分配関数の対数は各寄与の和となる．
したがって，Helmholtz自由エネルギー，エントロピー，比熱も各寄与の和として求められる．

### 6.1　Helmholtz自由エネルギー

式 (1)，式 (4)，式 (8) より，

```math
\begin{aligned}
\bar F
&=\bar F_{\mathrm{trans}}
+\bar F_{\mathrm{rot}}
+\bar F_{\mathrm{vib}}\\
&=-9247.66044-2981.73908+7339.42559\\
&=-4889.97393\ \mathrm{cal/mol}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar F\simeq-4.88997\times10^3\ \mathrm{cal/mol}
}
```

である．

### 6.2　エントロピー

式 (2)，式 (5)，式 (9) より，

```math
\begin{aligned}
\bar S
&=\bar S_{\mathrm{trans}}
+\bar S_{\mathrm{rot}}
+\bar S_{\mathrm{vib}}\\
&=36.836418+12.903327+0.559743\\
&=50.299488\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar S\simeq50.29949\ \mathrm{cal/(mol\,K)}
}
```

である．

### 6.3　定積モル比熱

式 (3)，式 (6)，式 (10) より，

```math
\begin{aligned}
\bar C_V
&=\bar C_{\mathrm{trans}}
+\bar C_{\mathrm{rot}}
+\bar C_{\mathrm{vib}}\\
&=2.980806+1.987204+1.624991\\
&=6.593001\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar C_V\simeq6.59300\ \mathrm{cal/(mol\,K)}
}
```

である．

## 7．最終結果

以上より，電子基底状態をエネルギーの基準とし，振動の零点エネルギーを含めた場合，0 ℃，1 atm におけるCO₂のモル熱力学関数は，

```math
\boxed{
\begin{aligned}
\bar F&\simeq-4.88997\times10^3\ \mathrm{cal/mol},\\
\bar S&\simeq50.29949\ \mathrm{cal/(mol\,K)},\\
\bar C_V&\simeq6.59300\ \mathrm{cal/(mol\,K)}
\end{aligned}
}
```

である．

SI単位では， $1\ \mathrm{cal}=4.184\ \mathrm J$ を用いて，

```math
\boxed{
\begin{aligned}
\bar F&\simeq-20.45965\ \mathrm{kJ/mol},\\
\bar S&\simeq210.45306\ \mathrm{J/(mol\,K)},\\
\bar C_V&\simeq27.58512\ \mathrm{J/(mol\,K)}
\end{aligned}
}
```

となる．

なお，Helmholtz自由エネルギーの絶対値はエネルギー基準に依存する．
本解答では，電子基底状態をゼロとし，振動の零点振動エネルギーを含める基準を採用した．
