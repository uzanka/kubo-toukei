# 例題【7-R-2】

## 解答

炭酸ガス $\mathrm{CO_2}$ を理想気体とみなし， $0^\circ\mathrm C$ ， $1\,\mathrm{atm}$ におけるモル Helmholtz 自由エネルギー $\bar F$ ，モルエントロピー $\bar S$ ，定積モル比熱 $\bar C_V$ を求める問題である．

分子の運動を並進運動，回転運動，内部振動に分け，各運動の分配関数から対応する熱力学関数を計算する．
これらの寄与を加え合わせることで，全体の熱力学関数が得られる．

### 1．計算条件と定数

温度と圧力は

```math
T=273.15\ \mathrm K,
\qquad
p=1.01325\times10^6\ \mathrm{erg/cm^3}
```

である．
計算には次の定数を用いる．

```math
\begin{aligned}
k&=1.380649\times10^{-16}\ \mathrm{erg/K},\\
h&=6.62607015\times10^{-27}\ \mathrm{erg\,s},\\
R&=1.987204\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

分子の質量は，原子質量単位 $1.65963\times10^{-24}\ \mathrm g$ を用いて

```math
\begin{aligned}
m
&=44.010\times1.65963\times10^{-24}\\
&=7.30403\times10^{-23}\ \mathrm g
\end{aligned}
```

となる．
また，

```math
RT=542.805\ \mathrm{cal/mol}
```

である．
以下の対数はすべて自然対数である．

### 2．並進運動による寄与

#### 2.1　並進分配関数

質量 $m$ の分子1個が体積 $V$ の中を自由に運動するとき，並進分配関数は

```math
q_{\mathrm{trans},1}
=
V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
```

である．
ここで，添字 $1$ は1分子についての分配関数であることを表す．

分子が $N$ 個ある理想気体の全分配関数は，分子が区別できないことを考慮して

```math
Q_{\mathrm{trans}}
=
\frac{q_{\mathrm{trans},1}^{\,N}}{N!}
```

となる．
Helmholtz 自由エネルギー $F=-kT\ln Q_{\mathrm{trans}}$ に Stirling の近似

```math
\ln N!\simeq N\ln N-N
```

を用いると，モル並進自由エネルギーは

```math
\bar F_{\mathrm{trans}}
=
-RT\left[
\ln\left\{
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\frac VN
\right\}+1
\right]
```

と書ける．

理想気体の状態方程式 $pV=NkT$ より，

```math
\frac VN=\frac{kT}{p}
```

である．
したがって，計算に使う無次元量を

```math
q_{\mathrm{trans}}
=
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\frac{kT}{p}
```

と定めると，

```math
\begin{aligned}
\ln q_{\mathrm{trans}}
&=
\ln\left[
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\frac{kT}{p}
\right]\\
&=16.035986\ldots\\
&\simeq16.036
\end{aligned}
```

を得る．
解答例にある $4.673$ は誤りである．

#### 2.2　Helmholtz 自由エネルギー

上の結果より，

```math
\bar F_{\mathrm{trans}}
=-RT(\ln q_{\mathrm{trans}}+1)
```

であるから，

```math
\begin{aligned}
\bar F_{\mathrm{trans}}
&=-542.805(16.035986+1)\\
&\simeq-9247.2\ \mathrm{cal/mol}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar F_{\mathrm{trans}}
\simeq-9.247\times10^3\ \mathrm{cal/mol}
}
\tag{1}
```

である．

#### 2.3　エントロピー

並進運動によるモルエントロピーは

```math
\bar S_{\mathrm{trans}}
=R\left(\ln q_{\mathrm{trans}}+\frac52\right)
```

である．
よって，

```math
\begin{aligned}
\bar S_{\mathrm{trans}}
&=1.987204(16.035986+2.5)\\
&\simeq36.8348\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar S_{\mathrm{trans}}
\simeq36.835\ \mathrm{cal/(mol\,K)}
}
\tag{2}
```

である．

#### 2.4　定積モル比熱

並進運動には $x,y,z$ 方向の3つの自由度がある．
古典統計力学の等分配則によれば，各自由度はモル内部エネルギーに $RT/2$ ずつ寄与する．
そのため，

```math
\boxed{
\bar C_{\mathrm{trans}}
=\frac32R
\simeq2.981\ \mathrm{cal/(mol\,K)}
}
\tag{3}
```

となる．

### 3．回転運動による寄与

#### 3.1　回転分配関数

$\mathrm{CO_2}$ は直線状分子であるため，独立な回転自由度は2つである．
回転特性温度は

```math
\Theta_r=\frac{h^2}{8\pi^2Ik}
```

で与えられる．
慣性モーメント

```math
I=71.67\times10^{-40}\ \mathrm{g\,cm^2}
```

を代入すると，

```math
\boxed{
\Theta_r\simeq0.561955\ \mathrm K
}
```

となる．

$T=273.15\ \mathrm K$ は $\Theta_r$ より十分に大きいため，回転分配関数には古典近似を用いることができる．
また，2つの酸素原子は同一であり，分子の対称数は $\gamma=2$ である．
したがって，

```math
q_{\mathrm{rot}}=\frac{T}{\gamma\Theta_r}
=\frac{T}{2\Theta_r}
```

である．
これより，

```math
\begin{aligned}
\ln q_{\mathrm{rot}}
&=\ln\left(\frac{273.15}{2\times0.561955}\right)\\
&\simeq5.493207
\end{aligned}
```

を得る．

#### 3.2　Helmholtz 自由エネルギー

回転分配関数によるモル自由エネルギーは

```math
\bar F_{\mathrm{rot}}=-RT\ln q_{\mathrm{rot}}
```

である．
よって，

```math
\begin{aligned}
\bar F_{\mathrm{rot}}
&=-542.805\times5.493207\\
&\simeq-2981.7\ \mathrm{cal/mol}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar F_{\mathrm{rot}}
\simeq-2.982\times10^3\ \mathrm{cal/mol}
}
\tag{4}
```

である．

#### 3.3　エントロピー

回転運動によるモルエントロピーは

```math
\bar S_{\mathrm{rot}}
=R(\ln q_{\mathrm{rot}}+1)
```

である．
したがって，

```math
\begin{aligned}
\bar S_{\mathrm{rot}}
&=1.987204(5.493207+1)\\
&\simeq12.9033\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

よって，

```math
\boxed{
\bar S_{\mathrm{rot}}
\simeq12.903\ \mathrm{cal/(mol\,K)}
}
\tag{5}
```

となる．

#### 3.4　定積モル比熱

直線状分子の回転自由度は2つであり，古典的な等分配則から回転運動の定積モル比熱は

```math
\boxed{
\bar C_{\mathrm{rot}}=R
\simeq1.987\ \mathrm{cal/(mol\,K)}
}
\tag{6}
```

となる．

### 4．内部振動による寄与

#### 4.1　振動特性温度

問題文で与えられた基準振動の波数は

```math
\begin{aligned}
\bar\nu_1=\bar\nu_2&=667.3\ \mathrm{cm}^{-1},\\
\bar\nu_3&=1383.3\ \mathrm{cm}^{-1},\\
\bar\nu_4&=2439.3\ \mathrm{cm}^{-1}
\end{aligned}
```

である．
直線状の三原子分子では振動自由度は4つであり，ここでは $\bar\nu_1$ と $\bar\nu_2$ を別々の振動モードとして数える．

波数 $\bar\nu_i$ の調和振動子に対する振動特性温度は

```math
\Theta_i=\frac{hc\bar\nu_i}{k}
```

で与えられる．
波数を $\mathrm{cm}^{-1}$ で表すとき，

```math
\frac{hc}{k}=1.4387769\ \mathrm{K\,cm}
```

を使える．
したがって，

```math
\begin{aligned}
\Theta_1=\Theta_2&\simeq960.096\ \mathrm K,\\
\Theta_3&\simeq1990.260\ \mathrm K,\\
\Theta_4&\simeq3509.608\ \mathrm K.
\end{aligned}
```

各モードについて $x_i=\Theta_i/T$ とおけば，

```math
\boxed{
(x_1,x_2,x_3,x_4)
\simeq(3.5149,\,3.5149,\,7.2863,\,12.8486)
}
\tag{7}
```

となる．

#### 4.2　振動分配関数と Helmholtz 自由エネルギー

調和振動子のエネルギー準位は

```math
E_n=\left(n+\frac12\right)hc\bar\nu_i,
\qquad n=0,1,2,\ldots
```

である．
したがって，1つの振動モードの分配関数は

```math
q_i
=\sum_{n=0}^{\infty}
e^{-(n+1/2)\Theta_i/T}
=
\frac{e^{-\Theta_i/(2T)}}{1-e^{-\Theta_i/T}}
```

となる．
振動モードは独立に扱えるため，全振動分配関数は各モードの分配関数の積である．
よって，

```math
q_{\mathrm{vib}}
=\prod_{i=1}^{4}
\frac{e^{-\Theta_i/(2T)}}{1-e^{-\Theta_i/T}}
```

となり，

```math
\ln q_{\mathrm{vib}}
=
\sum_{i=1}^{4}
\left[
-\frac{\Theta_i}{2T}
-\ln(1-e^{-\Theta_i/T})
\right]
```

を得る．
式 (7) の値を代入すると，

```math
\boxed{
\ln q_{\mathrm{vib}}\simeq-13.521299
}
```

である．

したがって，振動によるモル自由エネルギーは

```math
\begin{aligned}
\bar F_{\mathrm{vib}}
&=-RT\ln q_{\mathrm{vib}}\\
&=-542.805\times(-13.521299)\\
&\simeq7339.4\ \mathrm{cal/mol}.
\end{aligned}
```

よって，

```math
\boxed{
\bar F_{\mathrm{vib}}
\simeq7.339\times10^3\ \mathrm{cal/mol}
}
\tag{8}
```

である．

ここで，分配関数に $e^{-\Theta_i/(2T)}$ が含まれているため，振動の零点振動エネルギー $hc\bar\nu_i/2$ も自由エネルギーに含まれている．
このエネルギーの基準を採用すると，振動自由エネルギーは正の値になり得る．
自由エネルギーの絶対値はエネルギーの基準に依存するため，これは矛盾ではない．

#### 4.3　エントロピー

各振動モードの寄与を足し合わせると，モルエントロピーは

```math
\bar S_{\mathrm{vib}}
=
R\sum_{i=1}^{4}
\left[
-\ln(1-e^{-x_i})
+\frac{x_i}{e^{x_i}-1}
\right]
```

である．
式 (7) の値を代入すると，

```math
\sum_{i=1}^{4}
\left[
-\ln(1-e^{-x_i})
+\frac{x_i}{e^{x_i}-1}
\right]
\simeq0.281674
```

となる．
したがって，

```math
\begin{aligned}
\bar S_{\mathrm{vib}}
&=1.987204\times0.281674\\
&\simeq0.55974\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

よって，

```math
\boxed{
\bar S_{\mathrm{vib}}
\simeq0.5597\ \mathrm{cal/(mol\,K)}
}
\tag{9}
```

である．

#### 4.4　定積モル比熱

調和振動子の定積モル比熱は

```math
\bar C_{\mathrm{vib}}
=
R\sum_{i=1}^{4}
\frac{x_i^2e^{x_i}}{(e^{x_i}-1)^2}
```

である．
式 (7) の値から，

```math
\sum_{i=1}^{4}
\frac{x_i^2e^{x_i}}{(e^{x_i}-1)^2}
\simeq0.817727
```

となる．
したがって，

```math
\begin{aligned}
\bar C_{\mathrm{vib}}
&=1.987204\times0.817727\\
&\simeq1.62499\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

よって，

```math
\boxed{
\bar C_{\mathrm{vib}}
\simeq1.6250\ \mathrm{cal/(mol\,K)}
}
\tag{10}
```

である．

### 5．電子状態の寄与

問題文によると，基底電子状態は $^{1}\Sigma_g^+$ であり，縮重していない．
電子基底状態のエネルギーをゼロと定めると，電子分配関数は

```math
q_{\mathrm{elec}}=1
```

である．
したがって， $\ln q_{\mathrm{elec}}=0$ となり，電子状態による自由エネルギー，エントロピー，比熱への寄与はいずれもゼロである．

### 6．全熱力学関数

各運動の分配関数が独立な積で表されるため，対応するモル熱力学関数は各寄与の和として求められる．

#### 6.1　Helmholtz 自由エネルギー

式 (1)，式 (4)，式 (8) より，

```math
\begin{aligned}
\bar F
&=\bar F_{\mathrm{trans}}
+\bar F_{\mathrm{rot}}
+\bar F_{\mathrm{vib}}\\
&\simeq-9247.2-2981.7+7339.4\\
&\simeq-4889.5\ \mathrm{cal/mol}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar F\simeq-4.890\times10^3\ \mathrm{cal/mol}
}
```

である．

#### 6.2　エントロピー

式 (2)，式 (5)，式 (9) より，

```math
\begin{aligned}
\bar S
&=\bar S_{\mathrm{trans}}
+\bar S_{\mathrm{rot}}
+\bar S_{\mathrm{vib}}\\
&\simeq36.8348+12.9033+0.55974\\
&\simeq50.2979\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar S\simeq50.298\ \mathrm{cal/(mol\,K)}
}
```

である．

#### 6.3　定積モル比熱

式 (3)，式 (6)，式 (10) より，

```math
\begin{aligned}
\bar C_V
&=\bar C_{\mathrm{trans}}
+\bar C_{\mathrm{rot}}
+\bar C_{\mathrm{vib}}\\
&\simeq2.9808+1.9872+1.6250\\
&\simeq6.5930\ \mathrm{cal/(mol\,K)}.
\end{aligned}
```

したがって，

```math
\boxed{
\bar C_V\simeq6.593\ \mathrm{cal/(mol\,K)}
}
```

である．

### 7．最終結果

以上より， $0^\circ\mathrm C$ ， $1\,\mathrm{atm}$ における求める熱力学関数は，使用した振動エネルギーの基準のもとで，

```math
\boxed{
\begin{aligned}
\bar F&\simeq-4.890\times10^3\ \mathrm{cal/mol},\\
\bar S&\simeq50.298\ \mathrm{cal/(mol\,K)},\\
\bar C_V&\simeq6.593\ \mathrm{cal/(mol\,K)}
\end{aligned}
}
```

である．
SI 単位では，

```math
\boxed{
\begin{aligned}
\bar F&\simeq-20.458\ \mathrm{kJ/mol},\\
\bar S&\simeq210.45\ \mathrm{J/(mol\,K)},\\
\bar C_V&\simeq27.585\ \mathrm{J/(mol\,K)}
\end{aligned}
}
```

となる．

なお，解答例の振動自由エネルギー約 $7337\ \mathrm{cal/mol}$ と本解答の約 $7339\ \mathrm{cal/mol}$ の差は，振動特性温度とその比を丸めたことによる差である．
一方，解答例の並進自由エネルギーと並進エントロピーの値には対数値の誤りがあるため，そちらは丸め誤差では説明できない．
