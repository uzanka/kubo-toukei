# 演習問題【7-B-16】

## 解答

### (i) 分子内振動の自由度

分子 $\text{CH}_4$ は $5$ 個の原子（炭素 $1$ 個，水素 $4$ 個）から構成されている．
各原子の自由度は $3$ 方向（ $x, y, z$ ）の運動を考慮するため，全自由度は $3 \times 5 = 15$ となる．

この全自由度は，以下の $3$ つの運動の和として表される：
1. **並進運動**： 分子全体の重心の移動に相当し，常に $3$ 自由度である．
2. **回転運動**： 分子の回転に相当し，非線形分子であるメタンの場合は $3$ 自由度である．
3. **振動運動**： 原子間の相対的な運動に相当する．

したがって，振動の自由度 $f_{\text{vib}}$ は次のように計算される：

$$f_{\text{vib}} = (\text{全自由度}) - (\text{並進自由度}) - (\text{回転自由度}) = 15 - 3 - 3 = 9$$

よって，分子内振動の自由度は $9$ である．

### (ii) 回転および核スピンの分配関数

高温近似においては，分子の回転運動と核スピンの運動は相互に影響しないものとして独立に扱うことができる．
メタン $`\text{CH}_4`$ において，水素原子（ $`\text{H}`$ ）の核スピン量子数を $`s_{\text{H}} = 1/2`$ ，炭素原子（ $^{12}\text{C}$ ）の核スピン量子数を $s_{\text{C}} = 0$ とすると，各核スピンの縮重度は $(2s+1)$ で与えられる．
水素原子は $4$ 個あるため，核スピンに関する分配関数は $(2s_{\text{H}} + 1)^4$ となる．
炭素原子については $(2s_{\text{C}} + 1)^1$ である．

また，回転運動の分配関数 $z_{\text{rot}}$ は，高温近似において慣性モーメント $A, B, C$ を用いて次のように表される：

$$z_{\text{rot}} = \frac{\sqrt{\pi}}{\sigma} \left( \frac{8\pi^2 AkT}{h^2} \right)^{1/2} \left( \frac{8\pi^2 BkT}{h^2} \right)^{1/2} \left( \frac{8\pi^2 CkT}{h^2} \right)^{1/2}$$

ここで， $\sigma$ は分子の対称数（対称数 $\gamma$ とも表記される）である．
メタンは $3$ 回対称軸を $4$ 本持つため， $\gamma = 3 \times 4 = 12$ である．

核スピンと回転を合わせた分配関数 $z_{\text{nuc-rot}}$ は，これらを掛け合わせることで得られる：

$$z_{\text{nuc-rot}} = \frac{1}{\gamma} (2s_{\text{C}} + 1)(2s_{\text{H}} + 1)^4 \sqrt{\pi} \left( \frac{8\pi^2 AkT}{h^2} \right)^{1/2} \left( \frac{8\pi^2 BkT}{h^2} \right)^{1/2} \left( \frac{8\pi^2 CkT}{h^2} \right)^{1/2}$$

（注：解答例の式 $(1)$ と形式が異なる場合があるが，定数項のまとめ方によるものである．）

### (iii) 化学定数の導出

メタン気体の全分配関数 $Z_{\text{N}}$ は，並進，回転，核スピン，および振動（調和振動子近似）の寄与の積として次のように書ける：

$$Z_{\text{N}}(T, V) = \frac{1}{N!} (z_{\text{trans}} z_{\text{rot}} z_{\text{nuc}} z_{\text{vib}})^N$$

ここで， $z_{\text{trans}} = V \left( \frac{2\pi mkT}{h^2} \right)^{3/2}$ である．
振動部分は各振動モード $i$ について $\frac{1}{1 - e^{-h\nu_i/kT}}$ の寄与を持つ．

ヘルムホルツ自由エネルギー $F$ は $F = -kT \ln Z_{\text{N}}$ で与えられる．
スターリングの近似 $\ln N! \approx N \ln N - N$ を用いると：

$$F = -kT \left[ N \ln V + \frac{3N}{2} \ln \left( \frac{2\pi mkT}{h^2} \right) + N \ln z_{\text{rot}} + N \ln z_{\text{nuc}} + N \ln z_{\text{vib}} - (N \ln N - N) \right]$$

$$F = -NkT \left[ \ln \left( \frac{V}{N} \right) + \frac{5}{2} + \frac{3}{2} \ln \left( \frac{2\pi mkT}{h^2} \right) + \ln z_{\text{rot}} + \ln z_{\text{nuc}} + \ln z_{\text{vib}} \right]$$

次に，ギブス自由エネルギー $G = F + pV$ を考える．
理想気体の状態方程式 $pV = NkT$ より，$pV = NkT$ を代入する．
$1 \text{mol}$ あたり（ $N = N_{\text{A}}$ ）の $G$ を求めるために，まず $N$ を $1 \text{mol}$ の場合として扱う．

$$G = -NkT \ln \left( \frac{V}{N} \right) - \frac{5}{2} NkT - \frac{3}{2} NkT \ln \left( \frac{2\pi mkT}{h^2} \right) - NkT \ln z_{\text{rot}} - NkT \ln z_{\text{nuc}} - NkT \ln z_{\text{vib}} + NkT$$

理想気体の関係式 $\frac{V}{N} = \frac{RT}{p}$ を用いて整理すると，

$$G = RT \ln \left( \frac{p}{RT} \right) + \dots (\text{他の項})$$

最終的に，温度 $T$ と圧力 $p$ に依存する項を整理すると，解答例(3)のように：

$$G(T, p) = \bar{U}_0 + RT \log p - 4RT \log T + RT \sum_{i} \log (1 - e^{-h\nu_i/kT}) - RT i_0$$

が得られる．
ここで， $i_0$ は温度や圧力に依存しない定数であり，これを化学定数と呼ぶ．
$i_0$ の具体的な形は，分配関数の各成分を代入し，定数項を抽出することで得られる：

```math
i_0 = \log \left\{ \frac{(2\pi m)^{3/2} k^{5/2} 8\pi^2 (ABC)^{3/2} (2s_{\text{C}} + 1)(2s_{\text{H}} + 1)^4}{\gamma^3 h^3} g_0 \right\}
```

### (iv) 置換による熱力学関数の相違

$\text{H}$ を $\text{D}$ で置換した系列 $\text{CH}_4, \text{CH}_3\text{D}, \text{CH}_2\text{D}_2, \text{CHD}_3, \text{CD}_4$ において，ギブス自由エネルギー $\Delta G$ の変化をもたらす因子は以下の通りである．

1. **振動数の変化**：
  原子の質量が変化するため，振動数 $\nu_i$ が変化する．
  これは $G$ の第 $4$ 項（振動の寄与）に影響する．
2. **分子全体の質量の変化**：
  並進運動の寄与（ $m$ に依存）が変化する．
3. **慣性モーメントの変化**：
  原子の配置と質量分布が変わるため，慣性モーメント $A, B, C$ が変化する．
  これは化学定数 $i_0$ の中の $(ABC)^{3/2}$ の項に影響する．
4. **核スピンの寄与の変化**：
  $\text{H}$ と $\text{D}$ では核スピン量子数が異なる場合がある（ $\text{H}$ は $1/2$ ， $\text{D}$ は $1$ など）ため，核スピンの縮重度 $\prod (2s_{\text{n}} + 1)$ が変化する．
5. **対称数の変化**：
  置換によって分子の対称性が低下するため，対称数 $\gamma$ が変化する．

これらの因子が複合的に作用することで，各分子の熱力学的な安定性（ $\Delta G$ ）が決定される．

## 解説

本問題は，統計力学的な分配関数から，マクロな熱力学量であるギブス自由エネルギーを導出するプロセスを理解するためのものである．

特に重要な点は， **「微視的な状態の数（分配関数）」がどのように「巨視的なエネルギー（自由エネルギー）」へと結びつくか** という点である．
分配関数 $Z$ が大きければ大きいほど，利用可能な微視的状態が多いことを意味し，自由エネルギー $F = -kT \ln Z$ は低くなる（安定化する）．

置換による変化については，単に「重くなるから安定になる」という直感だけでなく，対称性の低下（ $\gamma$ の減少）や，核スピンの寄与（縮重度の増大）といった，量子力学的な性質が熱力学量にどのように反映されるかを整理することが肝要である．
