# 演習問題【7-B-16】

## 解答

メタン $\mathrm{CH_4}$ について，分子内振動の自由度，回転と核スピンの分配関数，化学定数，および水素を重水素で置換した場合の熱力学関数の変化を順に考える．

### (i) 分子内振動の自由度

メタンは炭素原子1個と水素原子4個からなるため，原子数は $5$ である．
各原子は空間の3方向に運動できるので，分子全体の自由度は

```math
3\times5=15
```

である．

分子全体の並進運動には3自由度があり，非線形分子であるメタンの回転運動には3自由度がある．
したがって，分子内振動の自由度は

```math
f_{\mathrm{vib}}=3N_{\mathrm{atom}}-3-3
```

であり，

```math
\boxed{
f_{\mathrm{vib}}=15-6=9
}
```

となる．

メタンの9個の振動自由度は，4種類の基本振動に分けて表すことができる．
それぞれの縮重度は $1,2,3,3$ であり，合計は $1+2+3+3=9$ である．

### (ii) 回転および核スピンの分配関数

#### 1．核スピンの分配関数

核スピン量子数を $s$ とする原子核は，核スピンの磁気量子数に対応して $2s+1$ 個の状態を持つ．
高温近似では，核スピンの状態と回転運動を分離して扱えるため，核スピンの分配関数は各原子核の縮重度の積である．

炭素を ${}^{12}\mathrm C$ とすると，核スピン量子数は $s_{\mathrm C}=0$ である．
水素原子核は $s_{\mathrm H}=1/2$ である．
したがって，

```math
\begin{aligned}
z_{\mathrm{nuc}}
&=(2s_{\mathrm C}+1)(2s_{\mathrm H}+1)^4\\
&=1\times2^4\\
&=16
\end{aligned}
```

となる．

#### 2．回転分配関数

高温近似では，回転量子状態の和を連続的な積分で近似できる．
非線形剛体分子の回転分配関数は，主慣性モーメントを $A,B,C$ ，回転対称数を $\gamma$ とすると，

```math
\boxed{
z_{\mathrm{rot}}
=
\frac{\sqrt{\pi}}{\gamma}
\left(\frac{8\pi^2AkT}{h^2}\right)^{1/2}
\left(\frac{8\pi^2BkT}{h^2}\right)^{1/2}
\left(\frac{8\pi^2CkT}{h^2}\right)^{1/2}
}
\tag{1}
```

である．
ここで， $h$ は Planck 定数， $k$ は Boltzmann 定数， $T$ は絶対温度である．

メタンは正四面体構造を持ち，分子を回転させて同一の配置に重ねられる回転操作は12通りある．
したがって，回転対称数は

```math
\gamma=12
```

である．
また，メタンは球形コマとして近似できるため，3つの主慣性モーメントは等しく，

```math
A=B=C
```

とみなせる．

核スピンと回転を合わせた分配関数は，核スピンの分配関数と回転分配関数の積である．
電子基底状態の縮重度を $g_0$ とすると，

```math
z_{\mathrm{nuc-rot}}=g_0z_{\mathrm{nuc}}z_{\mathrm{rot}}
```

である．
メタンの電子基底状態は縮重していないので $g_0=1$ であり，

```math
\boxed{
z_{\mathrm{nuc-rot}}
=
\frac{16\sqrt{\pi}}{12}
\left(\frac{8\pi^2AkT}{h^2}\right)^{3/2}
}
\tag{2}
```

を得る．

### (iii) 化学定数

#### 1．分子の分配関数

まず，分子1個の並進分配関数は，体積 $V$ ，分子質量 $m$ に対して

```math
z_{\mathrm{trans}}
=
V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
```

である．

次に，振動分配関数を考える．
調和振動子の準位を基底状態からの励起エネルギーで表すと，各モードの分配関数は

```math
z_{\mathrm{vib},j}
=
\frac1{1-e^{-h\nu_j/kT}}
```

である．
零点振動エネルギーは基底状態エネルギー $\bar U_04 に含めることとすると，全振動分配関数は

```math
z_{\mathrm{vib}}
=
\prod_{j=1}^{9}
\frac1{1-e^{-h\nu_j/kT}}
\tag{3}
```

となる．

メタンには4種類の基本振動があるため，これを基本振動数 $\nu_1,\nu_2,\nu_3,\nu_4$ と縮重度で表せば，

```math
\boxed{
z_{\mathrm{vib}}
=
\frac1{1-e^{-h\nu_1/kT}}
\frac1{(1-e^{-h\nu_2/kT})^2}
\frac1{(1-e^{-h\nu_3/kT})^3}
\frac1{(1-e^{-h\nu_4/kT})^3}
}
\tag{4}
```

である．

したがって，分子1個の並進，回転，核スピン，振動の分配関数を掛け合わせれば，分子全体の分配関数が得られる．
$N$ 個の同一分子からなる理想気体の分配関数は

```math
\boxed{
Z_N=
\frac{e^{-N\epsilon_0/kT}}{N!}
\left[
V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
z_{\mathrm{nuc-rot}}z_{\mathrm{vib}}
\right]^N
}
\tag{5}
```

となる．
ここで， $\epsilon_0$ は分子1個当たりの基底状態エネルギーであり， $\bar U_0=N_{\mathrm A}\epsilon_0$ はそのモル値である．

#### 2．Gibbs 自由エネルギー

Helmholtz 自由エネルギーは

```math
F=-kT\ln Z_N
```

である．
式 (5) を代入し，Stirling の近似

```math
\ln N!\simeq N\ln N-N
```

を用いると，

```math
\begin{aligned}
F={}&N\epsilon_0\\
&-NkT\left[
\ln\frac VN+1
+\frac32\ln\left(\frac{2\pi mkT}{h^2}\right)
+\ln z_{\mathrm{nuc-rot}}
+\ln z_{\mathrm{vib}}
\right]
\end{aligned}
\tag{6}
```

を得る．

Gibbs 自由エネルギーは $G=F+pV$ である．
理想気体の状態方程式 $pV=NkT$ を用いると，式 (6) の $+1$ に対応する項は $pV$ の項と相殺される．
したがって，

```math
\begin{aligned}
\bar G
={}&\bar U_0\\
&-RT\ln\left[
\frac{kT}{p}
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
z_{\mathrm{nuc-rot}}z_{\mathrm{vib}}
\right]
\end{aligned}
\tag{7}
```

となる．
ここで， $\bar G$ はモル Gibbs 自由エネルギーである．

式 (1)，式 (3)，式 (7) を用いて温度依存項をまとめる．
並進分配関数は $T^{3/2}$ ，回転分配関数も $T^{3/2}$ に比例し，状態方程式に由来する因子 $kT/p$ は $T/p$ に比例するため，Gibbs 自由エネルギーの対数には $\ln p-4\ln T$ が現れる．
よって，

```math
\boxed{
\bar G(T,p)
=
\bar U_0
+RT\ln p
-4RT\ln T
+RT\sum_{j=1}^{9}\ln(1-e^{-h\nu_j/kT})
-RTi_0
}
\tag{8}
```

という形に整理できる．
ここで，対数の単位依存性を含む定数 $i_0$ は，式 (1) と式 (7) から

```math
\boxed{
i_0
=
\ln\left[
k\left(\frac{2\pi mk}{h^2}\right)^{3/2}
\frac{\sqrt{\pi}}{\gamma}
\left(\frac{8\pi^2k}{h^2}\right)^{3/2}
(ABC)^{1/2}
g_0(2s_{\mathrm C}+1)(2s_{\mathrm H}+1)^4
\right]
}
\tag{9}
```

となる．
メタンでは $g_0=1$ ， $s_{\mathrm C}=0$ ， $s_{\mathrm H}=1/2$ ， $\gamma=12$ である．

厳密には， $\ln p$ や $\ln T$ は単位付きの量の対数として直接扱うのではなく，基準圧力 $p_*$ と基準温度 $T_*$ を用いて $\ln(p/p_*)$ ， $\ln(T/T_*)$ のように無次元比で表すべきである．
式 (8) は，圧力と温度の単位を固定し，それらの単位依存性を $i_0$ に吸収した表記である．

### (iv) 水素を重水素に置換した場合に考慮すべき因子

系列

```math
\mathrm{CH_4},\quad
\mathrm{CH_3D},\quad
\mathrm{CH_2D_2},\quad
\mathrm{CHD_3},\quad
\mathrm{CD_4}
```

の熱力学関数の相違を考えるには，以下の因子を考慮する必要がある．

**1．分子全体の質量 $m$**

並進分配関数は $m^{3/2}$ に比例するため，水素を重水素に置換すると並進運動の寄与が変化する．
Gibbs 自由エネルギーの質量依存部分は $-\frac32RT\ln m$ である．

**2．主慣性モーメント $A,B,C$**

回転分配関数は $(ABC)^{1/2}$ に比例するため，質量分布の変化によって回転の寄与が変わる．
置換体の分子は一般に球形コマではなくなるため，正確な計算では重心を基準として慣性テンソルを求め，その主値を計算しなければならない．

粗い近似として，重心を炭素原子の位置とみなし，3つの主慣性モーメントをほぼ等しいと仮定すると，代表的な慣性モーメントの比は

```math
A(\mathrm{CH_4}):A(\mathrm{CH_3D}):A(\mathrm{CH_2D_2}):A(\mathrm{CHD_3}):A(\mathrm{CD_4})
\approx 4:5:6:7:8
```

と見積もれる．
ただし，これは質量分布の変化を概算したものであり，置換体の正確な主慣性モーメントの比ではない．

**3．核スピンの縮重度**

水素原子核と重水素原子核では核スピン量子数が異なる．
水素の核スピン量子数は $1/2$ ，重水素の核スピン量子数は $1$ であるため，核スピン縮重度はそれぞれ $2$ ， $3$ である．
各分子の核スピン縮重度の積は，

```math
\begin{array}{c|ccccc}
\text{分子}
&\mathrm{CH_4}&\mathrm{CH_3D}&\mathrm{CH_2D_2}&\mathrm{CHD_3}&\mathrm{CD_4}\\
\hline
g_{\mathrm{nuc}}
&16&24&36&54&81
\end{array}
```

となる．
この因子が大きいほど，核スピン状態の数が増え，分配関数が大きくなる．

**4．回転対称数 $\gamma$**

同位体置換により分子の対称性が変わるため，回転対称数も変化する．
各分子の対称数は

```math
\begin{array}{c|ccccc}
\text{分子}
&\mathrm{CH_4}&\mathrm{CH_3D}&\mathrm{CH_2D_2}&\mathrm{CHD_3}&\mathrm{CD_4}\\
\hline
\gamma&12&3&2&3&12
\end{array}
```

である．
回転分配関数には $1/\gamma$ が掛かるため，対称数の変化は化学定数に影響する．

**5．振動数 $\nu_j$ と基底状態エネルギー $\bar U_0$**

同位体置換によって原子の質量が変わり，各振動モードの振動数も変化する．
メタンの縮重した振動モードは，置換によって対称性が低下すると分裂する場合があるため，置換後の振動数を用いて振動分配関数を計算する必要がある．
また，零点振動エネルギーも振動数に依存するので，基底状態エネルギー $\bar U_0$ の変化も考慮する必要がある．

以上をまとめると，同位体置換によるモル Gibbs 自由エネルギーの変化は，基準となる $\mathrm{CH_4}$ と置換体 $X$ について，

```math
\begin{aligned}
\frac{\Delta \bar G_X}{RT}
={}&
\frac{\Delta\bar U_{0,X}}{RT}
-\frac32\ln\frac{m_X}{m_{\mathrm{CH_4}}}\\
&-\frac12\ln\frac{A_XB_XC_X}{A_{\mathrm{CH_4}}B_{\mathrm{CH_4}}C_{\mathrm{CH_4}}}\\
&+\ln\frac{\gamma_X}{\gamma_{\mathrm{CH_4}}}
-\ln\frac{g_{\mathrm{nuc},X}}{g_{\mathrm{nuc},\mathrm{CH_4}}}\\
&+\sum_{j=1}^{9}
\ln\frac{1-e^{-h\nu_{X,j}/kT}}
{1-e^{-h\nu_{\mathrm{CH_4},j}/kT}}
\end{aligned}
\tag{10}
```

と表される．
この式によって，質量，慣性モーメント，対称数，核スピン縮重度，振動数，基底状態エネルギーがどのように熱力学関数に影響するかを整理できる．

なお，質量，核スピン縮重度，対称数のみを考え，慣性モーメントと振動数の変化を無視した部分的な近似を採用すると，解答例に記載された $\Delta G/RT$ の数値が得られる．
ただし，それらは式 (10) に含まれるすべての寄与を考慮した自由エネルギー差ではない．
