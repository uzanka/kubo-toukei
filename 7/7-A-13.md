# 演習問題【7-A-13】

## 解答

### 1．仮定と証明の方針

分子間相互作用を考慮した実在気体の圧力の式を，ビリアル定理を用いて導出する．

以下では，次の条件を仮定する．

- 分子は同種の古典粒子であり，熱平衡状態にある．
- 分子間相互作用は，距離だけに依存する二体ポテンシャル $u(r)$ の和で表される．
- 外部ポテンシャルは存在せず，系は巨視的な一様・等方流体である．
- ポテンシャルの基準は $u(\infty)=0$ とする．
- ポテンシャルは安定で，十分に短距離的であり，以下の積分と低密度展開が収束するものとする．

分子数密度を

```math
\rho=\frac NV=\frac1v
```

と定義する．

まず，ビリアル定理を二粒子分布関数で表し，次に希薄気体の極限で二粒子分布関数を近似する．
最後に部分積分を用いて，問題文の圧力の式を導く．

### 2．ビリアル定理による圧力の表示

分子 $i$ と分子 $j$ の距離を

```math
r_{ij}=|\mathbf r_i-\mathbf r_j|
```

とする．
二体ポテンシャル $u(r)$ を用いると，全ポテンシャルエネルギーは

```math
U=\sum_{i<j}u(r_{ij})
\tag{1}
```

である．

ビリアル定理より，

```math
pV
=
NkT-\frac13
\left\langle
\sum_{i=1}^{N}
\mathbf r_i\cdot\nabla_i U
\right\rangle
\tag{2}
```

が成立する．
ここで， $k$ はBoltzmann定数， $\langle\cdots\rangle$ は熱平衡状態での統計平均を表す．

二体ポテンシャルについて，

```math
\nabla_i u(r_{ij})
=
\frac{du}{dr_{ij}}
\frac{\mathbf r_i-\mathbf r_j}{r_{ij}}
```

であり，

```math
\nabla_j u(r_{ij})
=
-\frac{du}{dr_{ij}}
\frac{\mathbf r_i-\mathbf r_j}{r_{ij}}
```

となる．
したがって，粒子ペア $i,j$ に関する項をまとめると，

```math
\begin{aligned}
&\mathbf r_i\cdot\nabla_i u(r_{ij})
+\mathbf r_j\cdot\nabla_j u(r_{ij})\\
&=
(\mathbf r_i-\mathbf r_j)\cdot
\frac{du}{dr_{ij}}
\frac{\mathbf r_i-\mathbf r_j}{r_{ij}}\\
&=
r_{ij}\frac{du}{dr_{ij}}
\end{aligned}
```

を得る．
よって，

```math
\sum_i\mathbf r_i\cdot\nabla_i U
=
\sum_{i<j}r_{ij}\frac{du(r_{ij})}{dr_{ij}}
```

となる．
これを式 (2) に代入すれば，

```math
\boxed{
pV
=
NkT-\frac13
\left\langle
\sum_{i<j}r_{ij}u'(r_{ij})
\right\rangle
}
\tag{3}
```

を得る．
ここで $u'(r)=du(r)/dr$ とした．

### 3．二粒子分布関数による表現

希薄気体の熱力学極限を正しく扱うため，二粒子分布関数 $g(r)$ を導入する．

一様・等方な流体では，距離 $r$ だけに依存する動径分布関数 $g(r)$ を用いて，任意の二粒子間関数 $A(r)$ に対し，

```math
\left\langle
\sum_{i<j}A(r_{ij})
\right\rangle
=
\frac{N\rho}{2}
\int_{\mathbb R^3}A(r)g(r)\,d\mathbf r
\tag{4}
```

と表せる．

ここで， $g(r)$ は二つの粒子が距離 $r$ だけ離れて存在する確率密度を，粒子間相関のない場合と比較した関数である．
十分遠方では粒子間の相関がなくなるため，

```math
\lim_{r\to\infty}g(r)=1
```

となる．

式 (4) で

```math
A(r)=ru'(r)
```

とすれば，

```math
\left\langle
\sum_{i<j}r_{ij}u'(r_{ij})
\right\rangle
=
\frac{N\rho}{2}
\int_{\mathbb R^3}ru'(r)g(r)\,d\mathbf r
```

である．
したがって，式 (3) は

```math
pV
=
NkT-\frac{N\rho}{6}
\int_{\mathbb R^3}ru'(r)g(r)\,d\mathbf r
```

となる．
両辺を $V$ で割り， $\rho=N/V$ を用いると，

```math
\boxed{
p
=
\rho kT-\frac{\rho^2}{6}
\int_{\mathbb R^3}ru'(r)g(r)\,d\mathbf r
}
\tag{5}
```

を得る．
これは，熱力学極限におけるビリアル定理の二粒子分布関数による表現である．

### 4．希薄気体近似

ここで，粒子数密度 $\rho$ が十分小さい希薄気体を考える．

低密度極限では，指定した二粒子間の相互作用が支配的となり，他の粒子による相関の寄与は密度に関する高次の補正となる．
このため，

```math
\boxed{
g(r)=e^{-\beta u(r)}+O(\rho)
}
\tag{6}
```

と近似できる．
ただし，

```math
\beta=\frac1{kT}
```

である．

この関係は，低密度極限で他の粒子の影響が消え，指定した二粒子の配置確率が，二粒子間のBoltzmann因子 $e^{-\beta u(r)}$ に従うことを表している．

式 (6) を式 (5) に代入すると，

```math
\begin{aligned}
p
&=
\rho kT
-\frac{\rho^2}{6}
\int_{\mathbb R^3}
ru'(r)e^{-\beta u(r)}\,d\mathbf r
+O(\rho^3).
\end{aligned}
\tag{7}
```

ここで， $O(\rho^3)$ は圧力の密度展開における三次以上の寄与を表す．
この展開は，ポテンシャルが安定で短距離的であり，低密度展開が成立する条件の下で用いる．

ポテンシャルは距離 $r$ だけの関数であるため，球座標を用いると，

```math
d\mathbf r=4\pi r^2\,dr
```

である．
よって，

```math
\boxed{
p
=
\rho kT
-\frac{2\pi\rho^2}{3}
\int_0^\infty
r^3u'(r)e^{-\beta u(r)}\,dr
+O(\rho^3)
}
\tag{8}
```

となる．

### 5．部分積分による変形

式 (8) の積分を変形するため，

```math
f(r)=1-e^{-\beta u(r)}
\tag{9}
```

とおく．
これを $r$ で微分すると，

```math
\begin{aligned}
\frac{df}{dr}
&=
-\frac{d}{dr}e^{-\beta u(r)}\\
&=
\beta u'(r)e^{-\beta u(r)}
\end{aligned}
```

である．
したがって，

```math
u'(r)e^{-\beta u(r)}
=
kT\frac{df}{dr}
\tag{10}
```

となる．

式 (8) の積分は，

```math
\begin{aligned}
\int_0^\infty
r^3u'(r)e^{-\beta u(r)}\,dr
&=
kT\int_0^\infty r^3\frac{df}{dr}\,dr
\end{aligned}
```

と書ける．

ここで部分積分を行うと，

```math
\begin{aligned}
\int_0^\infty r^3\frac{df}{dr}\,dr
&=
\left[r^3f(r)\right]_0^\infty
-3\int_0^\infty r^2f(r)\,dr.
\end{aligned}
\tag{11}
```

ポテンシャルが適切な短距離型のものであり，

```math
\lim_{r\to0}r^3f(r)=0,
\qquad
\lim_{r\to\infty}r^3f(r)=0
\tag{12}
```

が成立すると仮定する．
このとき境界項は消えるので，

```math
\int_0^\infty r^3\frac{df}{dr}\,dr
=
-3\int_0^\infty r^2f(r)\,dr
```

となる．
式 (9) と式 (10) を用いれば，

```math
\boxed{
\begin{aligned}
&\int_0^\infty
r^3u'(r)e^{-\beta u(r)}\,dr\\
&\qquad=
-3kT\int_0^\infty
r^2\left\{1-e^{-\beta u(r)}\right\}\,dr
\end{aligned}
}
\tag{13}
```

を得る．

式 (13) を式 (8) に代入すると，

```math
\begin{aligned}
p
&=
\rho kT
-\frac{2\pi\rho^2}{3}
\left[
-3kT
\int_0^\infty
r^2\left\{1-e^{-\beta u(r)}\right\}\,dr
\right]
+O(\rho^3)\\
&=
\rho kT
+
2\pi\rho^2 kT
\int_0^\infty
r^2\left\{1-e^{-\beta u(r)}\right\}\,dr
+O(\rho^3).
\end{aligned}
```

したがって，

```math
\boxed{
p
=
\rho kT
\left[
1+
2\pi\rho
\int_0^\infty
r^2\left\{1-e^{-u(r)/(kT)}\right\}\,dr
+O(\rho^2)
\right]
}
\tag{14}
```

となる．

### 6．比体積 $v$ による表現

分子数密度と比体積の関係は，

```math
\rho=\frac NV=\frac1v
```

である．
これを式 (14) に代入すると，

```math
p
=
\frac{kT}{v}
\left[
1+
\frac{2\pi}{v}
\int_0^\infty
r^2\left\{1-e^{-u(r)/(kT)}\right\}\,dr
+O(v^{-2})
\right]
```

を得る．
ここで， $O(v^{-2})$ の係数は，温度とポテンシャルに依存する体積の次元を持つ量である．

さらに，

```math
2\pi\int_0^\infty r^2(\cdots)\,dr
=
\frac12\int_0^\infty4\pi r^2(\cdots)\,dr
```

であるから，

```math
\boxed{
p
=
\frac{kT}{v}
\left[
1+
\frac1{2v}
\int_0^\infty
\left\{1-e^{-u(r)/(kT)}\right\}
4\pi r^2\,dr
+O(v^{-2})
\right]
}
\tag{15}
```

となる．

$O(v^{-2})$ は $o(1/v)$ よりも強い次数の評価であるため，問題文の記法に合わせれば，

```math
\boxed{
p
=
\frac{kT}{v}
\left[
1+
\frac1{2v}
\int_0^\infty
\left\{1-e^{-u(r)/(kT)}\right\}
4\pi r^2\,dr
+o\left(\frac1v\right)
\right]
}
```

となる．
これが求める式である．

### 7．第2ビリアル係数と物理的意味

第2ビリアル係数 $B_2(T)$ を，

```math
\boxed{
B_2(T)
=
\frac12
\int_{\mathbb R^3}
\left\{1-e^{-u(r)/(kT)}\right\}\,d\mathbf r
}
```

と定義する．
球対称性から，

```math
B_2(T)
=
2\pi
\int_0^\infty
r^2\left\{1-e^{-u(r)/(kT)}\right\}\,dr
```

である．
したがって，圧力の式は，

```math
\boxed{
p=\frac{kT}{v}
\left[
1+\frac{B_2(T)}v+O(v^{-2})
\right]
}
```

と表せる．

先頭項 $kT/v$ は理想気体の圧力であり，第2項は分子間相互作用による補正である．

ポテンシャルが正の領域では，

```math
u(r)>0
\quad\Longrightarrow\quad
1-e^{-u(r)/(kT)}>0
```

となり，第2ビリアル係数に正の寄与を与える．
一方，ポテンシャルが負の領域では，

```math
u(r)<0
\quad\Longrightarrow\quad
1-e^{-u(r)/(kT)}<0
```

となり，負の寄与を与える．

一般的な分子間ポテンシャルでは，斥力的な短距離領域と引力的な中・長距離領域が共存するため，圧力補正の符号は積分全体によって決まる．

また，

```math
u(r)=0
```

ならば，

```math
B_2(T)=0
```

となり，

```math
p=\frac{kT}{v}
```

という理想気体の状態方程式に戻る．
このことからも，導出した式が物理的に整合していることが確認できる．

### 8．適用条件に関する注意

今回の導出では，低密度展開と部分積分を用いた．
そのため，ポテンシャルには適切な収束条件が必要である．
例えば，

```math
\int_0^\infty
r^2\left|1-e^{-u(r)/(kT)}\right|\,dr
<\infty
```

が成立するような，十分に短距離的なポテンシャルを想定する．
また，部分積分の境界項が消えることも必要である．

Coulombポテンシャルのような長距離相互作用では，この積分が一般に収束しないため，今回の導出をそのまま適用することはできない．

さらに，希薄気体近似は全粒子の配置積分を単純に $V^N$ と近似することを意味しない．
巨視的な系では全粒子の相互作用の総寄与を無視できないため，二粒子分布関数を導入して，

```math
g(r)=e^{-u(r)/(kT)}+O(\rho)
```

という低密度極限を用いる必要がある．
この扱いによって，熱力学極限と整合した導出が得られる．

以上より，ビリアル定理を用いて，問題文の実在気体の圧力の式が導かれた．
