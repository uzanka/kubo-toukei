# 演習問題【7-A-13】

## 解答

分子間相互作用を考慮した実在気体の圧力の式を，ビリアル定理を用いて導出する．
解答例と同様に，まずビリアル定理によって圧力を分子間ポテンシャルの平均で表し，次に希薄気体近似と部分積分を用いて，求める式を導く．

### 1．ビリアル定理による圧力の表示

分子 $i$ と分子 $j$ の距離を $r_{ij}=|\mathbf r_i-\mathbf r_j|$ とする．
分子間相互作用が距離のみに依存する二体ポテンシャル $u(r)$ で表されるとき，系の全ポテンシャルエネルギーは

```math
U=\sum_{\langle ij\rangle}u(r_{ij})
```

と書ける．
ここで， $\sum_{\langle ij\rangle}$ は，分子のすべての組を重複なく足し合わせることを表す．
また，ポテンシャルの基準は $u(\infty)=0$ とする．

ビリアル定理より，圧力 $p$ ，体積 $V$ ，分子数 $N$ ，温度 $T$ の間には

```math
pV
=NkT-\frac13
\left\langle
\sum_{i=1}^{N}
\mathbf r_i\cdot\nabla_i U
\right\rangle
```

という関係が成り立つ．
ここで， $k$ は Boltzmann 定数， $\langle\cdots\rangle$ は熱平衡状態における統計平均である．

二体ポテンシャルについて，

```math
\nabla_i u(r_{ij})
=
\frac{du}{dr_{ij}}
\frac{\mathbf r_i-\mathbf r_j}{r_{ij}}
```

である．
分子 $i,j$ の組に由来する項を， $i$ 側と $j$ 側からまとめると，

```math
\begin{aligned}
&\mathbf r_i\cdot\nabla_i u(r_{ij})
+\mathbf r_j\cdot\nabla_j u(r_{ij})\\
&\quad=
(\mathbf r_i-\mathbf r_j)\cdot
\frac{du}{dr_{ij}}
\frac{\mathbf r_i-\mathbf r_j}{r_{ij}}\\
&\quad=r_{ij}\frac{du}{dr_{ij}}
\end{aligned}
```

となる．
したがって，

```math
\sum_i\mathbf r_i\cdot\nabla_i U
=
\sum_{\langle ij\rangle}
r_{ij}\frac{du}{dr_{ij}}
```

であり，ビリアル定理は

```math
pV
=
NkT-\frac13
\sum_{\langle ij\rangle}
\left\langle
r_{ij}\frac{du}{dr_{ij}}
\right\rangle
```

と書ける．

分子ペアの数は $N(N-1)/2$ 組である．
また，分子が同じ種類であり，すべてのペアが同じポテンシャルに従うため，どのペアについても統計平均は等しい．
そこで，代表的なペアの距離を $r$ と書けば，

```math
\boxed{
pV
=
NkT-\frac{N(N-1)}6
\left\langle r\frac{du}{dr}\right\rangle
}
\tag{1}
```

を得る．

### 2．分子間ポテンシャルの平均

代表的な分子ペア $1,2$ について，配置の統計平均を考える．
温度 $T$ において，各分子配置の重みは Boltzmann 因子 $e^{-U/kT}$ に比例するため，

```math
\begin{aligned}
\left\langle r\frac{du}{dr}\right\rangle
&=
\frac{
\displaystyle
\int\cdots\int
r_{12}\frac{du}{dr_{12}}
e^{-U/kT}\,
d\mathbf r_1\cdots d\mathbf r_N
}{
\displaystyle
\int\cdots\int
e^{-U/kT}\,
d\mathbf r_1\cdots d\mathbf r_N
}.
\end{aligned}
\tag{2}
```

ここで， $U$ は全ポテンシャルエネルギーであり，分母はすべての分子配置について Boltzmann 因子を積分したものである．
分子の運動量に関する積分は分子間距離に依存しないため，この平均では位置座標に関する積分だけを考えればよい．

### 3．希薄気体近似

分子の数密度 $N/V=1/v$ が小さい希薄気体を考える．
このとき，特定の分子ペアが相互作用することによる寄与を最低次まで残し，他の分子間相互作用による高次の補正を無視する．

具体的には，式 (2) の分母では相互作用を無視して $e^{-U/kT}\simeq1$ と近似する．
すると，

```math
\int\cdots\int
e^{-U/kT}\,d\mathbf r_1\cdots d\mathbf r_N
\simeq V^N
```

となる．

一方，分子の位置に関する分子の積分では，選んだペア $1,2$ の相互作用 $u(r_{12})$ を残し，その他の相互作用を無視する．
この近似により，

```math
\begin{aligned}
\left\langle r\frac{du}{dr}\right\rangle
&\simeq
\frac1{V^N}
\int\cdots\int
r_{12}\frac{du}{dr_{12}}
e^{-u(r_{12})/kT}\,
d\mathbf r_1\cdots d\mathbf r_N.
\end{aligned}
```

積分の被積分関数は，選んだ2分子の座標以外には依存しない．
したがって，残りの $N-2$ 個の分子の座標を積分すると $V^{N-2}$ が得られ，

```math
\begin{aligned}
\left\langle r\frac{du}{dr}\right\rangle
&\simeq
\frac1{V^2}
\int d\mathbf r_1\int d\mathbf r_2\,
r_{12}\frac{du}{dr_{12}}
e^{-u(r_{12})/kT}.
\end{aligned}
```

ここで，相対座標

```math
\mathbf r=\mathbf r_2-\mathbf r_1,
\qquad r=|\mathbf r|
```

を導入する．
容器が十分大きく，境界の影響を無視できるとき，積分は

```math
\int d\mathbf r_1\int d\mathbf r_2\,g(\mathbf r_2-\mathbf r_1)
\simeq
V\int d\mathbf r\,g(\mathbf r)
```

と変形できる．
これを用いると，

```math
\boxed{
\left\langle r\frac{du}{dr}\right\rangle
\simeq
\frac1V\int d\mathbf r\,
r\frac{du}{dr}e^{-u(r)/kT}
}
\tag{3}
```

となる．

ポテンシャルは距離 $r$ のみの関数なので，この積分は球座標で表せる．
球対称性から $d\mathbf r=4\pi r^2\,dr$ であるため，

```math
\left\langle r\frac{du}{dr}\right\rangle
\simeq
\frac{4\pi}{V}
\int_0^\infty
r^3\frac{du}{dr}e^{-u(r)/kT}\,dr
\tag{4}
```

を得る．

### 4．部分積分による変形

式 (4) の積分を変形するため，

```math
f(r)=1-e^{-u(r)/kT}
```

とおく．
これを $r$ で微分すると，

```math
\begin{aligned}
\frac{df}{dr}
&=-\frac{d}{dr}e^{-u(r)/kT}\\
&=\frac1{kT}\frac{du}{dr}e^{-u(r)/kT}
\end{aligned}
```

である．
したがって，

```math
\frac{du}{dr}e^{-u(r)/kT}
=kT\frac{df}{dr}
```

となり，式 (4) は

```math
\left\langle r\frac{du}{dr}\right\rangle
\simeq
\frac{4\pi kT}{V}
\int_0^\infty r^3\frac{df}{dr}\,dr
```

と書ける．

ここで部分積分を行うと，

```math
\int_0^\infty r^3\frac{df}{dr}\,dr
=
\left[r^3f(r)\right]_0^\infty
-3\int_0^\infty r^2f(r)\,dr
```

となる．
通常の物理的に適切なポテンシャルで，境界項が消える，すなわち

```math
\lim_{r\to0}r^3f(r)=0,
\qquad
\lim_{r\to\infty}r^3f(r)=0
```

と仮定する．
この条件のもとでは，

```math
\int_0^\infty r^3\frac{df}{dr}\,dr
=
-3\int_0^\infty r^2f(r)\,dr
```

となる．
よって，

```math
\boxed{
\left\langle r\frac{du}{dr}\right\rangle
\simeq
-\frac{12\pi kT}{V}
\int_0^\infty
r^2\left\{1-e^{-u(r)/kT}\right\}\,dr
}
\tag{5}
```

を得る．

### 5．圧力の式の導出

式 (5) を式 (1) に代入すると，

```math
\begin{aligned}
pV
&\simeq NkT
-\frac{N(N-1)}6
\left[
-\frac{12\pi kT}{V}
\int_0^\infty
r^2\left\{1-e^{-u(r)/kT}\right\}\,dr
\right]\\
&=NkT+
\frac{2\pi N(N-1)kT}{V}
\int_0^\infty
r^2\left\{1-e^{-u(r)/kT}\right\}\,dr.
\end{aligned}
```

両辺を $V$ で割り， $v=V/N$ を用いると，

```math
p
=
\frac{kT}{v}
\left[
1+
\frac{2\pi(N-1)}{V}
\int_0^\infty
r^2\left\{1-e^{-u(r)/kT}\right\}\,dr
\right]
```

となる．
巨視的な系では $N\gg1$ であるから， $N-1\simeq N$ と近似できる．
さらに $N/V=1/v$ を用いれば，

```math
p
=
\frac{kT}{v}
\left[
1+
\frac{2\pi}{v}
\int_0^\infty
r^2\left\{1-e^{-u(r)/kT}\right\}\,dr
+o\left(\frac1v\right)
\right]
```

を得る．
ここで， $o(1/v)$ は，密度 $1/v$ に関して表示した補正項のうち， $1/v$ より高次の項を表す．

最後に，

```math
\frac{2\pi}{v}\int_0^\infty r^2(\cdots)\,dr
=
\frac1{2v}\int_0^\infty 4\pi r^2(\cdots)\,dr
```

であることを用いると，求める圧力の式

```math
\boxed{
p=\frac{kT}{v}
\left[
1+\frac1{2v}
\int_0^\infty
\left\{1-e^{-u(r)/kT}\right\}
4\pi r^2\,dr
+o\left(\frac1v\right)
\right]
}
```

が得られる．

### 6．結果の物理的意味

先頭項 $kT/v$ は理想気体の圧力である．
その後に続く積分項は，分子間相互作用によって理想気体の状態方程式からずれる効果を表している．

ポテンシャルが正の領域では $1-e^{-u(r)/kT}$ は正となり，斥力的な相互作用は一般に圧力を高める方向に働く．
一方，ポテンシャルが負の領域ではこの量は負となり，引力的な相互作用は一般に圧力を低下させる方向に働く．
ただし，実際の補正の符号は積分全体の値によって決まり，引力と斥力の両方がある場合には両者の寄与を合わせて判断する必要がある．
