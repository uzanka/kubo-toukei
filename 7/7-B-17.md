# 演習問題【7-B-17】

## 解答

分子間ポテンシャルが同位体によらず，分子の内部運動についても古典的近似が成り立つ高温領域を考える．
このとき，気体反応の平衡において，同位体の質量差に起因する分別が起こらないことを示す．

## 1. 同位体置換とポテンシャルエネルギー

同位体は核電荷 $Z$ が等しく，核質量 $m$ が異なる原子核である．

Born–Oppenheimer 近似では，核の位置を固定して電子状態を求める．
このとき電子ハミルトニアンは，核の位置と核電荷には依存するが，核質量には依存しない．

したがって，同じ核電荷をもつ核を同位体に置き換えても，同じ核配置に対する電子エネルギー，すなわちポテンシャルエネルギー面は変化しない．

この性質は分子間相互作用だけでなく，分子内の結合ポテンシャルにも適用される．
以下では，この通常の Born–Oppenheimer 近似のもとで，全ポテンシャルエネルギー $U(R)$ は核質量に依存しないものとする．

ここで重要なのは，異なる化学種のポテンシャルまで同一であると仮定する必要はないことである．
同位体の質量を置き換えたときに，対応する配置でのポテンシャルが変化しないことが必要なのである．

## 2. 全系の古典分配関数

同位体の種類を $s$ ，その核質量を $m_s$ ，全系に存在する原子核数を $N_s$ とする．
また，全原子核数を

```math
M=\sum_s N_s
```

とする．

全原子核の座標と運動量をそれぞれ $R,P$ とすると，ハミルトニアンは

```math
H(R,P)
=
\sum_{a=1}^{M}\frac{p_a^2}{2m_{s(a)}}
+U(R)
```

と表せる．

ここで $s(a)$ は原子核 $a$ の同位体の種類を表す．

同じ同位体の原子核は互いに同種粒子であるため，古典的な正準分配関数は

```math
Q_{\mathrm{cl}}
=
\frac{1}{\prod_s N_s!h^{3M}}
\int dR\,dP\,
e^{-\beta H(R,P)},
\qquad
\beta=\frac{1}{kT}
```

で与えられる．

運動エネルギーとポテンシャルエネルギーが分離しているので，運動量積分と配置積分を分けることができる．

1個の原子核について，

```math
\int d^3p_a\,
e^{-\beta p_a^2/(2m_{s(a)})}
=
(2\pi m_{s(a)}kT)^{3/2}
```

であるから，

```math
\begin{aligned}
Q_{\mathrm{cl}}
&=
\frac{1}{\prod_s N_s!h^{3M}}
\left[
\prod_s(2\pi m_skT)^{3N_s/2}
\right]
\int dR\,e^{-\beta U(R)}
\\
&=
\frac{Z_{\mathrm{conf}}}{\prod_s N_s!}
\prod_s
\left(
\frac{2\pi m_skT}{h^2}
\right)^{3N_s/2},
\end{aligned}
```

ただし，

```math
Z_{\mathrm{conf}}
=
\int dR\,e^{-\beta U(R)}
```

である．

この配置積分は質量に依存しない．
したがって，質量依存性は

```math
\boxed{
Q_{\mathrm{mass}}
=
\prod_s
\left(
\frac{2\pi m_skT}{h^2}
\right)^{3N_s/2}
}
```

という因子に完全に分離される．

ここでは全配置空間で積分しているため，反応物・生成物を定義する配置領域が同位体交換で変わらない，という独立の仮定は必要ない．

## 3. 化学反応における質量因子の相殺

一般の化学反応を

```math
\sum_X\alpha_X X
\rightleftharpoons
\sum_X\beta_X X
```

とする．

分子種 $X$ に含まれる同位体 $s$ の原子核数を $n_{Xs}$ とする．

通常の化学反応では，核反応を伴わないので，同位体 $s$ の原子核数は保存される．
したがって，

```math
\sum_X\alpha_Xn_{Xs}
=
\sum_X\beta_Xn_{Xs}
```

が成り立つ．

ここで，反応による各分子種の化学量論係数の変化を

```math
\nu_X=\beta_X-\alpha_X
```

と定義すると，

```math
\sum_X\nu_Xn_{Xs}=0
```

である．

分子種 $X$ の古典的分配関数に含まれる運動量積分由来の質量因子は

```math
q_{X,\mathrm{mass}}
=
\prod_s
\left(
\frac{2\pi m_skT}{h^2}
\right)^{3n_{Xs}/2}
```

となる．
分子の並進・回転・振動を別々に扱った場合も，内部運動を含めた古典的な位相空間積分を行えば，この同じ質量因子が得られる．

したがって，反応の平衡定数に含まれる質量依存因子は

```math
\begin{aligned}
K_{\mathrm{mass}}
&=
\prod_X
q_{X,\mathrm{mass}}^{\nu_X}
\\
&=
\prod_s
\left(
\frac{2\pi m_skT}{h^2}
\right)^{
\frac32\sum_X\nu_Xn_{Xs}
}.
\end{aligned}
```

ところが，原子核数保存則から

```math
\sum_X\nu_Xn_{Xs}=0
```

であるため，

```math
\boxed{K_{\mathrm{mass}}=1}
```

となる．

つまり，反応の平衡定数に質量差に由来する因子は残らない．

配置積分や分子の統計的重みは平衡定数に寄与し得るが，同位体の質量差による分別因子は生じない．

## 4. 自由エネルギーによる確認

同じ結論を自由エネルギーから確認する．

分配関数の質量依存部分による自由エネルギーは

```math
F_{\mathrm{mass}}
=
-\frac32 kT
\sum_sN_s
\ln\left(
\frac{2\pi m_skT}{h^2}
\right)
```

である．

反応進行度を $\xi$ とすると，同位体ごとの全原子核数は保存されるので，

```math
\frac{dN_s}{d\xi}=0
```

である．

したがって，

```math
\begin{aligned}
\frac{dF_{\mathrm{mass}}}{d\xi}
&=
-\frac32 kT
\sum_s
\frac{dN_s}{d\xi}
\ln\left(
\frac{2\pi m_skT}{h^2}
\right)
\\
&=0.
\end{aligned}
```

よって，反応の進行に伴って質量依存部分の自由エネルギーは変化しない．

これは，質量差が反応の平衡を同位体の一方に有利にすることがないことを示している．

## 5. 統計的因子について

以上は，質量差に由来する同位体分別についての結論である．
核スピン統計や分子の交換対称性に由来する統計的因子まで，一般に消失するという意味ではない．

例えば，

```math
\mathrm{H_2+D_2\rightleftharpoons 2HD}
```

では，回転対称数などによる統計的因子が平衡定数に残り得る．

実際，回転対称数を

```math
\sigma_{\mathrm{H_2}}=2,\qquad
\sigma_{\mathrm{D_2}}=2,\qquad
\sigma_{\mathrm{HD}}=1
```

とすると，

```math
\frac{\sigma_{\mathrm{H_2}}\sigma_{\mathrm{D_2}}}
{\sigma_{\mathrm{HD}}^2}
=4
```

という因子が現れる．

この因子は同位体の質量差に由来するものではなく，分子の組み合わせ方に関する統計的な因子である．

例えば，H原子の割合を $x$ ，D原子の割合を $1-x$ として，原子がランダムに二個ずつ組み合わさるなら，

```math
\begin{aligned}
[\mathrm{H_2}]&\propto x^2,\\
[\mathrm{HD}]&\propto 2x(1-x),\\
[\mathrm{D_2}]&\propto (1-x)^2.
\end{aligned}
```

したがって，

```math
\frac{[\mathrm{HD}]^2}
{[\mathrm{H_2}][\mathrm{D_2}]}
=4
```

となる．
これは統計的な組み合わせ数による結果であり，質量差によってHやDが選択的に濃縮される現象ではない．

核スピン統計を厳密に取り入れる場合には，核スピン状態と回転状態の交換対称性を一貫して数え上げる必要がある．
回転対称数と核スピン統計を独立な因子として無条件に重ねてはならない．

## 6. 結論

同位体の質量だけが異なり，同位体置換によってポテンシャルエネルギーが変化しない場合，古典的な分配関数では質量依存性が運動量積分から得られる因子に分離される．

その因子は，各同位体の全原子核数だけに依存する．
通常の化学反応では各同位体の原子核数が保存されるため，反応の平衡定数において質量因子は相殺される．

したがって，

```math
\boxed{
\text{古典極限では，質量差に基づく平衡同位体分別は起こらない．}
}
```

ゆえに，同位体の質量差を利用する平衡気体反応による分離は不可能である．

この結論は，古典的な並進・内部運動を扱い，同位体間でポテンシャルエネルギーが同じであるという通常の近似の範囲で成立する．
核スピン統計などの統計的組成因子や，反応速度の違いを利用する非平衡分離まで否定するものではない．
