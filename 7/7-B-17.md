# 演習問題【7-B-17】

## 解答

分子間ポテンシャルが同位体によって変わらず，さらに分子の内部運動にも古典的近似が適用できる高温領域では，化学反応による同位体分離が起こらないことを示す．

この問題の要点は，古典近似のもとでは，分子の分配関数に現れる質量依存性が，各原子核の質量の積に分離できることである．
化学反応では同位体ごとの原子核数が保存されるため，この質量依存性は反応の前後で相殺される．

### 1．古典近似における分子の分配関数

原子核を $n$ 個含む分子を考える．
原子核 $i$ の質量を $m_i$ ，運動量を $\mathbf p_i$ ，位置を $\mathbf r_i$ とする．
分子の運動エネルギーは

```math
\epsilon_{\mathrm p}
=\sum_{i=1}^{n}\frac{\mathbf p_i^2}{2m_i}
```

である．
また，分子内の相対的な位置関係を表す座標を $\mathbf q$ ，そのポテンシャルエネルギーを $U(\mathbf q)$ とする．

高温で古典近似が成り立つとき，分子1個の分配関数 $f$ は位相空間にわたる積分として

```math
f=
\frac{g_{\mathrm{nuc}}}{h^{3n}}
\int
e^{-(\epsilon_{\mathrm p}+U(\mathbf q))/kT}
\prod_{i=1}^{n}d^3\mathbf p_i
\prod_{i=1}^{n}d^3\mathbf r_i
```

と書ける．
ここで， $g_{\mathrm{nuc}}$ は核スピンの縮重度， $h$ は Planck 定数， $k$ は Boltzmann 定数， $T$ は絶対温度である．

位置座標の積分では，分子全体の並進に相当する座標を先に積分すると体積 $V$ が得られ，残りは分子内の相対座標に関する積分となる．
そこで，

```math
\Phi(T)=
\int e^{-U(\mathbf q)/kT}\prod_jd q_j
```

と定義すれば，

```math
f=
\frac{g_{\mathrm{nuc}}V\Phi(T)}{h^{3n}}
\prod_{i=1}^{n}
\int_{-\infty}^{\infty}
e^{-\mathbf p_i^2/(2m_i kT)}
\,d^3\mathbf p_i
```

となる．

各原子核の運動量積分はガウス積分である．
1次元の公式

```math
\int_{-\infty}^{\infty}e^{-ax^2}\,dx
=\sqrt{\frac{\pi}{a}}
```

を3方向に適用すると，

```math
\int_{-\infty}^{\infty}
e^{-\mathbf p_i^2/(2m_i kT)}
\,d^3\mathbf p_i
=(2\pi m_i kT)^{3/2}
```

を得る．
したがって，分配関数は

```math
\boxed{
f=
g_{\mathrm{nuc}}V\Phi(T)
\prod_{i=1}^{n}
\left(\frac{2\pi m_i kT}{h^2}\right)^{3/2}
}
\tag{1}
```

となる．

### 2．質量因子が相殺されること

式 (1) から，分配関数に含まれる質量依存性は，各原子核についての

```math
\left(\frac{2\pi m_i kT}{h^2}\right)^{3/2}
```

という因子の積に分離できることが分かる．
一方， $\Phi(T)$ は分子内の相対座標に関するポテンシャルの積分であり，ポテンシャルが同位体置換によって変わらないという仮定のもとでは，同位体の質量には依存しない．

ここで，気体反応

```math
\alpha_A A+\alpha_B B+\cdots
\rightleftharpoons
\beta_L L+\beta_M M+\cdots
```

を考える．
$\alpha_X$ と $\beta_X$ は反応物と生成物の化学量論係数である．

各同位体を $s$ で区別し，分子 $X$ に含まれる同位体 $s$ の原子核数を $n_{Xs}$ ，その質量を $m_s$ とする．
通常の化学反応では，同位体の種類ごとに原子核数が保存されるため，

```math
\boxed{
\sum_{\text{生成物 }X}\beta_X n_{Xs}
=
\sum_{\text{反応物 }X}\alpha_X n_{Xs}
}
\tag{2}
```

が，すべての同位体 $s$ について成り立つ．

式 (1) の質量依存因子を生成物側と反応物側で比べると，

```math
\frac{
\displaystyle
\prod_{\text{生成物 }X}
\prod_s
\left(\frac{2\pi m_s kT}{h^2}\right)^{3\beta_X n_{Xs}/2}
}{
\displaystyle
\prod_{\text{反応物 }X}
\prod_s
\left(\frac{2\pi m_s kT}{h^2}\right)^{3\alpha_X n_{Xs}/2}
}
```

となる．
これを同位体 $s$ ごとにまとめれば，

```math
\prod_s
\left(\frac{2\pi m_s kT}{h^2}\right)^{
\frac32
\left(
\sum_{\text{生成物 }X}\beta_X n_{Xs}
-
\sum_{\text{反応物 }X}\alpha_X n_{Xs}
\right)
}
```

である．
式 (2) により，各指数はゼロとなる．
したがって，

```math
\boxed{
\text{生成物と反応物の質量依存因子の比}=1
}
\tag{3}
```

である．
すなわち，反応の平衡には同位体の質量に依存する補正が現れない．

### 3．核スピン因子も相殺されること

原子核の核スピン量子数を $s_s$ とすると，その縮重度は $2s_s+1$ である．
高温近似で核スピンの状態を各原子核について独立に数えると，分子 $X$ の核スピン縮重度は

```math
g_{\mathrm{nuc},X}
=\prod_s(2s_s+1)^{n_{Xs}}
```

と表される．

したがって，反応の前後での核スピン縮重度の比は

```math
\prod_s(2s_s+1)^{
\sum_{\text{生成物 }X}\beta_X n_{Xs}
-
\sum_{\text{反応物 }X}\alpha_X n_{Xs}
}
=1
```

である．
ここでも，同位体ごとの原子核数が保存されることを用いた．
よって，このモデルの範囲では核スピン縮重度も，反応の前後で相殺される．

### 4．化学平衡定数に対する結論

分子1個の分配関数を $f_X$ とし，

```math
\widetilde f_X=\frac{f_X}{V}
```

と定義する．
これは分子の分配関数から並進に由来する体積因子を取り除いた量である．

理想気体混合物の平衡条件は，化学ポテンシャルを用いると

```math
\sum_X \nu_X\mu_X=0
```

と書ける．
ここで， $\nu_X$ は生成物について正，反応物について負の化学量論係数である．
理想気体の化学ポテンシャルを分配関数で表すと，この条件は

```math
\prod_X c_X^{\nu_X}
=
\prod_X\widetilde f_X^{\nu_X}
```

となる．
ここで $c_X=N_X/V$ は分子 $X$ の数密度である．
したがって，数密度で定義する平衡定数は，標準状態の取り方を除けば， $\widetilde f_X$ の積で表される．
この書き方では，各分子に共通する体積 $V$ が反応前後で必ず相殺されるため，生成物と反応物の分子数が異なる反応にも適用できる．

式 (1) から， $\widetilde f_X$ は核スピン因子，内部座標の積分，および原子核の質量に関する積に分解される．
式 (3) により質量因子は相殺され，前節の結果により核スピン因子も相殺される．
さらに，ポテンシャルが同位体置換によって変わらないという仮定のもとでは，内部座標の積分も同位体の質量に依存しない．

ゆえに，古典近似が分子の内部運動にも適用できる高温領域では，化学平衡定数は同位体の質量や同位体の配置によって変化しない．
したがって， **この平衡定数の差を利用した化学平衡による同位体分離は不可能である．**

なお，この結論は，ポテンシャルの同位体依存性や量子効果を無視した平衡論上の結論である．
低温では振動の量子準位や零点振動エネルギーが質量に依存し，平衡定数に同位体効果が現れ得るため，化学反応を利用した同位体分離が可能となる場合がある．
