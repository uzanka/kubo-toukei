# 演習問題【8-B-19】

## 解答

金属内の電子は，有効質量 $m^*$ をもつ理想フェルミ気体を形成しているものとする．
電子が光子を吸収して金属外に脱出する過程を考え，フェルミ・ディラック分布を用いて電子の流束を求める．
その後，積分変数を適切に変換することで，光電流が温度 $T$ の2乗と関数 $\phi(\delta)$ の積で表されることを示す．
さらに， $\delta$ の符号に応じて $\phi(\delta)$ を級数展開する．

### 1．電子の脱出条件と電子の流束

金属内の電子の運動エネルギーは，

```math
\varepsilon=\frac{p_x^2+p_y^2+p_z^2}{2m^*}
```

である．
ここで， $p_x,p_y$ は金属表面に平行な運動量成分， $p_z$ は表面に垂直な運動量成分である．

光子の吸収時には，表面に平行な運動量成分は変化しない．
したがって，電子が金属外へ脱出するためのエネルギー条件は，表面に垂直な運動エネルギーを用いて，

```math
h\nu+\frac{p_z^2}{2m^*}>\chi+\mu
```

と表される．
ここで， $\nu$ は入射光の振動数， $\chi$ は仕事関数， $\mu$ は金属内電子の化学ポテンシャルである．

限界振動数を $\nu_0$ とすると，その定義は

```math
\boxed{h\nu_0=\chi}
```

である．
脱出に必要な垂直運動量の下限を $p_0$ とすれば，

```math
\boxed{
p_0=\sqrt{2m^*(\chi+\mu-h\nu)}
}
\tag{1}
```

となる．
以下では，限界振動数付近で $p_0$ が実数となる範囲を考える．

温度 $T$ ，ボルツマン定数 $k$ に対して，電子の占有確率はフェルミ・ディラック分布

```math
f(\varepsilon)=
\frac{1}{\exp[(\varepsilon-\mu)/(kT)]+1}
```

で与えられる．
単位面積当たり，単位時間当たりに表面へ到達し，脱出条件を満たす電子の流束を $S$ とする．
電子のスピンの2状態を考慮すると，

```math
\begin{aligned}
S={}&\frac{2}{h^3}
\int_{p_0}^{\infty}\frac{p_z}{m^*}\,dp_z\\
&\quad\times
\iint_{-\infty}^{\infty}
\frac{dp_x\,dp_y}
{\exp\left[
\frac{p_x^2+p_y^2+p_z^2}{2m^*kT}
-\frac{\mu}{kT}
\right]+1}
\end{aligned}
\tag{2}
```

となる．
ここで， $2/h^3$ はスピンの重率を含めた運動量空間の状態数密度であり， $p_z/m^*$ は電子の表面に垂直な速度である．

### 2．電子の流束を積分する

まず，表面に平行な運動量 $p_x,p_y$ について積分する．
極座標

```math
p_x=p_\perp\cos\theta,\qquad
p_y=p_\perp\sin\theta
```

を導入すると，

```math
dp_x\,dp_y=p_\perp\,dp_\perp\,d\theta
```

である．
角度について積分すれば，

```math
\iint dp_x\,dp_y
=2\pi\int_0^\infty p_\perp\,dp_\perp
```

となる．

ここで，

```math
u=\frac{p_\perp^2}{2m^*kT}
```

と置く．
すると，

```math
p_\perp\,dp_\perp=m^*kT\,du
```

である．
これを式(2)に代入すると，

```math
\begin{aligned}
S={}&\frac{4\pi m^*kT}{h^3}
\int_{p_0}^{\infty}\frac{p_z}{m^*}\,dp_z\\
&\quad\times
\int_0^\infty
\frac{du}
{\exp\left[
u+\frac{p_z^2/(2m^*)-\mu}{kT}
\right]+1}
\end{aligned}
\tag{3}
```

となる．

次に，内側の積分を計算する．

```math
\int\frac{du}{e^{u+a}+1}
=-\log(1+e^{-(u+a)})
```

であるため，

```math
\begin{aligned}
&\int_0^\infty
\frac{du}{e^{u+a}+1}\\
&\quad=
\left[-\log(1+e^{-(u+a)})\right]_0^\infty\\
&\quad=\log(1+e^{-a})
\end{aligned}
```

を得る．
これを式(3)に適用すると，

```math
\begin{aligned}
S={}&\frac{4\pi m^*kT}{h^3}
\int_{p_0}^{\infty}\frac{p_z}{m^*}\,dp_z\\
&\quad\times
\log\left[
1+\exp\left(
\frac{\mu-p_z^2/(2m^*)}{kT}
\right)
\right]
\end{aligned}
\tag{4}
```

となる．

ここで，積分変数を

```math
y=\frac{p_z^2/(2m^*)-\mu-\chi+h\nu}{kT}
```

と変換する．このとき，

```math
dy=\frac{p_z}{m^*kT}\,dp_z
```

であり，

```math
\frac{p_z}{m^*}\,dp_z=kT\,dy
```

となる．
また，式(1)の $p_z=p_0$ において $y=0$ である．
さらに，

```math
\frac{\mu-p_z^2/(2m^*)}{kT}
=\frac{h\nu-\chi}{kT}-y
```

である．
したがって， $h\nu_0=\chi$ と置けば，

```math
\frac{\mu-p_z^2/(2m^*)}{kT}
=\frac{h(\nu-\nu_0)}{kT}-y
```

となる．
ここで，

```math
\delta=\frac{h(\nu-\nu_0)}{kT}
```

と定義すると，式(4)は

```math
\begin{aligned}
S
&=\frac{4\pi m^*kT}{h^3}
\int_0^\infty kT\log(1+e^{\delta-y})\,dy\\
&=\frac{4\pi m^*k^2}{h^3}T^2
\int_0^\infty\log(1+e^{\delta-y})\,dy
\end{aligned}
```

となる．
よって，

```math
\boxed{
S=AT^2\phi(\delta)
}
\tag{5}
```

と表せる．
ここで，

```math
\boxed{
\phi(\delta)=\int_0^\infty
\log(1+e^{\delta-y})\,dy
}
\tag{6}
```

であり， $A$ は温度と振動数に依存しない定数である．
例えば，脱出確率を $\alpha$ ，電子の電荷の大きさを $e$ とすれば，単位面積当たりの電流密度の大きさは $\alpha eS$ に比例する．
全光電流に含まれる面積や材料固有の定数も含めれば，問題の定数 $A$ にまとめられる．

### 3．$\delta\leq0$ の場合の級数展開

まず， $\delta\leq0$ の場合を考える．
$y\geq0$ であるため，

```math
0\leq e^{\delta-y}\leq1
```

である．
対数関数の級数展開

```math
\log(1+x)
=\sum_{l=1}^{\infty}
\frac{(-1)^{l-1}}{l}x^l
```

を用いると，

```math
\log(1+e^{\delta-y})
=\sum_{l=1}^{\infty}
\frac{(-1)^{l-1}}{l}e^{l\delta}e^{-ly}
```

となる．
これを式(6)に代入して項別に積分すれば，

```math
\begin{aligned}
\phi(\delta)
&=\sum_{l=1}^{\infty}
\frac{(-1)^{l-1}}{l}e^{l\delta}
\int_0^\infty e^{-ly}\,dy
\end{aligned}
```

を得る．
ここで，

```math
\int_0^\infty e^{-ly}\,dy
=\left[-\frac{e^{-ly}}{l}\right]_0^\infty
=\frac1l
```

であるから，

```math
\phi(\delta)
=\sum_{l=1}^{\infty}
\frac{(-1)^{l-1}}{l^2}e^{l\delta}
```

となる．
したがって，

```math
\boxed{
\phi(\delta)
=e^\delta-\frac{e^{2\delta}}{2^2}
+\frac{e^{3\delta}}{3^2}-\cdots
\qquad(\delta\leq0)
}
\tag{7}
```

が得られる．
$\delta=0$ では級数は交代級数として収束し，この式の連続極限も成立する．

### 4．$\delta\geq0$ の場合の級数展開

次に， $\delta\geq0$ の場合を考える．
式(6)の積分を二つの区間に分割すると，

```math
\phi(\delta)
=\int_0^\delta\log(1+e^{\delta-y})\,dy
+\int_\delta^\infty\log(1+e^{\delta-y})\,dy
\tag{8}
```

となる．

第1項では $x=\delta-y$ ，第2項では $x=y-\delta$ と変数変換する．
これにより，

```math
\phi(\delta)
=\int_0^\delta\log(1+e^x)\,dx
+\int_0^\infty\log(1+e^{-x})\,dx
\tag{9}
```

を得る．

ここで，

```math
\log(1+e^x)=x+\log(1+e^{-x})
```

であるから，

```math
\begin{aligned}
\int_0^\delta\log(1+e^x)\,dx
&=\int_0^\delta x\,dx
+\int_0^\delta\log(1+e^{-x})\,dx\\
&=\frac{\delta^2}{2}
+\int_0^\delta\log(1+e^{-x})\,dx
\end{aligned}
```

となる．
これを式(9)に代入すると，

```math
\begin{aligned}
\phi(\delta)
={}&\frac{\delta^2}{2}
+\int_0^\delta\log(1+e^{-x})\,dx\\
&+\int_0^\infty\log(1+e^{-x})\,dx
\end{aligned}
\tag{10}
```

である．

ここで，関数 $\phi$ の定義から，

```math
\phi(0)=\int_0^\infty\log(1+e^{-x})\,dx
\tag{11}
```

である．
また，

```math
\begin{aligned}
\int_0^\delta\log(1+e^{-x})\,dx
&=\int_0^\infty\log(1+e^{-x})\,dx\\
&\quad-\int_\delta^\infty\log(1+e^{-x})\,dx
\end{aligned}
```

となる．
最後の積分で $x=y+\delta$ と変数変換すれば，

```math
\begin{aligned}
\int_\delta^\infty\log(1+e^{-x})\,dx
&=\int_0^\infty\log(1+e^{-(y+\delta)})\,dy\\
&=\phi(-\delta)
\end{aligned}
\tag{12}
```

を得る．
したがって，

```math
\int_0^\delta\log(1+e^{-x})\,dx
=\phi(0)-\phi(-\delta)
```

である．
これを式(10)に代入すると，

```math
\boxed{
\phi(\delta)=\frac{\delta^2}{2}
+2\phi(0)-\phi(-\delta)
}
\tag{13}
```

が得られる．

ここで，式(7)を $\delta=0$ に適用すると，

```math
\phi(0)=\sum_{l=1}^{\infty}
\frac{(-1)^{l-1}}{l^2}
```

である．
この級数は，リーマンゼータ関数

```math
\zeta(2)=\sum_{l=1}^\infty\frac1{l^2}
=\frac{\pi^2}{6}
```

を用いて評価できる．
偶数項と奇数項を分けると，

```math
\begin{aligned}
\phi(0)
&=\sum_{l=1}^{\infty}\frac1{l^2}
-2\sum_{l=1}^{\infty}\frac1{(2l)^2}\\
&=\zeta(2)-\frac12\zeta(2)\\
&=\frac{\pi^2}{12}
\end{aligned}
\tag{14}
```

となる．
よって，

```math
2\phi(0)=\frac{\pi^2}{6}
```

である．
式(13)は，

```math
\phi(\delta)=\frac{\pi^2}{6}
+\frac{\delta^2}{2}-\phi(-\delta)
\tag{15}
```

と書ける．

ここで， $-\delta\leq0$ であるため，式(7)を用いると，

```math
\phi(-\delta)
=e^{-\delta}
-\frac{e^{-2\delta}}{2^2}
+\frac{e^{-3\delta}}{3^2}-\cdots
```

となる．
したがって，

```math
\boxed{
\begin{aligned}
\phi(\delta)
={}&\frac{\pi^2}{6}+\frac{\delta^2}{2}\\
&-\left(
e^{-\delta}-\frac{e^{-2\delta}}{2^2}
+\frac{e^{-3\delta}}{3^2}-\cdots
\right),
\qquad \delta\geq0
\end{aligned}
}
\tag{16}
```

を得る．

### 結論

電子の脱出条件とフェルミ・ディラック分布から電子の流束を計算すると，光電流は

```math
\boxed{
I\propto AT^2\phi\left(
\frac{h(\nu-\nu_0)}{kT}
\right)
}
```

と表される．
ここで，

```math
\boxed{
\phi(\delta)=\int_0^\infty
\log(1+e^{\delta-y})\,dy
}
```

である．
さらに， $\delta$ の符号に応じて，

```math
\boxed{
\phi(\delta)=
\begin{cases}
\displaystyle
e^\delta-\frac{e^{2\delta}}{2^2}
+\frac{e^{3\delta}}{3^2}-\cdots,
&\delta\leq0,\\[10pt]
\displaystyle
\frac{\pi^2}{6}+\frac{\delta^2}{2}
-\left(
e^{-\delta}-\frac{e^{-2\delta}}{2^2}
+\frac{e^{-3\delta}}{3^2}-\cdots
\right),
&\delta\geq0
\end{cases}
}
```

が得られる．
これにより，問題で指定された光電流の式と， $\phi(\delta)$ の両方の展開式が導かれた．
