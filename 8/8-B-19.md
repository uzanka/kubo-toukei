# 演習問題【8-B-19】

## 解答

金属内の電子は，有効質量 $m^*$ を持つ理想的なフェルミ気体としてモデル化できる．

### 1. 電子の脱出条件と電子の流れの定式化

金属内の電子が光子（エネルギー $h\nu$ ）を吸収して金属の表面から外部へ飛び出すためには，吸収後のエネルギーが金属の仕事関数 $\chi$ およびフェルミエネルギー $\mu$ の和を上回る必要がある．
電子の運動量を $\mathbf{p} = (p_x, p_y, p_z)$ とすると，エネルギー保存則より，脱出条件は次のように書ける：

$$h\nu + \frac{p^2}{2m^*} > \chi + \mu$$

ここで， $p^2 = p_x^2 + p_y^2 + p_z^2$ である．
電子が表面（ $z=0$ ）から外部（ $z>0$ ）へ飛び出すためには，表面に垂直な成分 $p_z$ が正である必要がある．
この条件を満たす電子の運動量領域を積分することで，単位時間あたりに表面に到達する電子の流れ $S$ を求めることができる．

フェルミ・ディラック分布に従う電子の密度を考慮すると，流れ $S$ は次のように与えられる：

```math
S = \frac{2}{h^3} \int_{p_0}^{\infty} \frac{p_z}{m^*} dp_z \iint_{-\infty}^{\infty} dp_x dp_y \frac{1}{\exp\left( \frac{p_x^2 + p_y^2 + p_z^2}{2m^* kT} - \frac{\mu}{kT} \right) + 1} \quad \cdots (1)
```

ここで， $p_0$ は脱出に必要な最小の $p_z$ である．
式(1)の条件 $h\nu + \frac{p_0^2}{2m^*} = \chi + \mu$ より，

$$p_0 = \sqrt{2m^*(\chi + \mu - h\nu)}$$

である．

### 2. 積分計算による $S$ の導出

まず， $p_x, p_y$ に関する 2 次元積分を実行する．
極座標 $p_x^2 + p_y^2 = p_\perp^2$ を導入すると，

$$\iint_{-\infty}^{\infty} dp_x dp_y = \int_{0}^{2\pi} d\theta \int_{0}^{\infty} p_\perp dp_\perp = 2\pi \int_{0}^{\infty} p_\perp dp_\perp$$

となる．
ここで， $u = \frac{p_\perp^2}{2m^* kT}$ と置換すると， $du = \frac{p_\perp}{m^* kT} dp_\perp$ より， $p_\perp dp_\perp = m^* kT \, du$ となる．

これを用いると，

```math
S = \frac{2}{h^3} \int_{p_0}^{\infty} \frac{p_z}{m^*} dp_z \cdot 2\pi m^* kT \int_{0}^{\infty} \frac{du}{\exp\left( u + \frac{p_z^2}{2m^* kT} - \frac{\mu}{kT} \right) + 1}
```

```math
S = \frac{4\pi m^* kT}{h^3} \int_{p_0}^{\infty} \frac{p_z}{m^*} dp_z \int_{0}^{\infty} \frac{du}{e^{u + A} + 1} \quad \left( A = \frac{p_z^2}{2m^* kT} - \frac{\mu}{kT} \right)
```

ここで， $\int \frac{1}{e^{u+A}+1} du = -\log(1 + e^{-(u+A)})$ であることを利用すると，

$$\int_{0}^{\infty} \frac{du}{e^{u+A}+1} = \left[ -\log(1 + e^{-(u+A)}) \right]_{0}^{\infty} = 0 - (-\log(1 + e^{-A})) = \log(1 + e^{-A})$$

となる．
よって，

```math
S = \frac{4\pi m^* kT}{h^3} \int_{p_0}^{\infty} \frac{p_z}{m^*} dp_z \log\left( 1 + \exp\left( \frac{\mu}{kT} - \frac{p_z^2}{2m^* kT} \right) \right) \quad \cdots (2)
```

次に，積分変数を $y$ に変換する．
$y = \frac{p_z^2}{2m^* kT} - \frac{\mu + \chi - h\nu}{kT} = \frac{p_z^2}{2m^* kT} - \frac{\mu + \chi}{kT} + \frac{h\nu}{kT}$ と置く．
ここで $\nu_0$ を $h\nu_0 = \chi + \mu$ を満たす限界振動数とすると，

$$y = \frac{p_z^2}{2m^* kT} - \frac{h\nu_0}{kT} + \frac{h\nu}{kT} = \frac{p_z^2}{2m^* kT} - \frac{h(\nu_0 - \nu)}{kT}$$

となる．
これより， $dy = \frac{p_z}{m^* kT} dp_z$ となり， $p_z=p_0$ のとき $y=0$ である．

したがって，

$$S = \frac{4\pi m^* kT}{h^3} \int_{0}^{\infty} (kT \, dy) \log\left( 1 + \exp\left( \frac{h\nu - h\nu_0}{kT} - y \right) \right)$$

$$S = \frac{4\pi m^* (kT)^2}{h^3} \int_{0}^{\infty} \log(1 + e^{\delta - y}) \, dy$$

ここで $\delta = \frac{h(\nu - \nu_0)}{kT}$ と定義すると， $S = AT^2 \phi(\delta)$ となり，

$$\phi(\delta) = \int_{0}^{\infty} \log(1 + e^{\delta - y}) \, dy \quad \cdots (3)$$

を得る．

### 3. $\phi(\delta)$ の展開式の導出

#### (i) $\delta \le 0$ の場合

$\delta \le 0$ のとき， $y \ge 0$ より $\delta - y \le 0$ であるから， $e^{\delta - y} \le 1$ である．
$\log(1+x)$ のテイラー展開 $\log(1+x) = \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n} x^{n}$ を用いると，

$$\begin{aligned} \phi(\delta) &= \int_{0}^{\infty} \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n} (e^{\delta - y})^n \, dy \\ &= \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n} e^{n\delta} \int_{0}^{\infty} e^{-ny} \, dy \\ &= \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n} e^{n\delta} \left[ \frac{e^{-ny}}{-n} \right]_{0}^{\infty} \\ &= \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n^2} e^{n\delta} \quad \cdots (4) \end{aligned}$$

#### (ii) $\delta \ge 0$ の場合

積分範囲を $[0, \delta]$ と $[\delta, \infty)$ に分割する．

$$\begin{aligned} \phi(\delta) &= \int_{0}^{\delta} \log(1 + e^{\delta - y}) \, dy + \int_{\delta}^{\infty} \log(1 + e^{\delta - y}) \, dy \end{aligned}$$

第 1 項について， $x = \delta - y$ と置換すると， $dx = -dy$ ， $y=0 \to x=\delta$ ， $y=\delta \to x=0$ ．

$$\int_{0}^{\delta} \log(1 + e^{\delta - y}) \, dy = \int_{0}^{\delta} \log(1 + e^x) \, dx$$

第 2 項について， $x = y - \delta$ と置換すると， $dx = dy$ ， $y=\delta \to x=0$ ， $y=\infty \to x=\infty$ ．

$$\int_{\delta}^{\infty} \log(1 + e^{\delta - y}) \, dy = \int_{0}^{\infty} \log(1 + e^{-x}) \, dx$$

よって，

$$\phi(\delta) = \int_{0}^{\delta} \log(1 + e^x) \, dx + \int_{0}^{\infty} \log(1 + e^{-x}) \, dx \quad \cdots (5)$$

ここで， $\log(1+e^x) = \log(e^x(e^{-x}+1)) = x + \log(1 + e^{-x})$ であるから，

$$\int_{0}^{\delta} \log(1 + e^x) \, dx = \int_{0}^{\delta} x \, dx + \int_{0}^{\delta} \log(1 + e^{-x}) \, dx = \frac{\delta^2}{2} + \int_{0}^{\delta} \log(1 + e^{-x}) \, dx$$

これを式(5)に代入すると，

$$\phi(\delta) = \frac{\delta^2}{2} + \int_{0}^{\delta} \log(1 + e^{-x}) \, dx + \int_{0}^{\infty} \log(1 + e^{-x}) \, dx$$

$$\phi(\delta) = \frac{\delta^2}{2} + \int_{0}^{\infty} \log(1 + e^{-x}) \, dx + \left( \int_{0}^{\delta} \log(1 + e^{-x}) \, dx - \int_{0}^{\infty} \log(1 + e^{-x}) \, dx \right)$$

$$\phi(\delta) = \frac{\delta^2}{2} + \phi(0) - \int_{\delta}^{\infty} \log(1 + e^{-x}) \, dx$$

ここで， $\int_{\delta}^{\infty} \log(1 + e^{-x}) \, dx = \int_{0}^{\infty} \log(1 + e^{-(x+\delta)}) \, dx$ となるが，より直接的に $\int_{0}^{\infty} \log(1 + e^{-x}) \, dx = \phi(0)$ であることを用いると，
$\int_{0}^{\delta} \log(1 + e^{-x}) \, dx = \phi(0) - \int_{\delta}^{\infty} \log(1 + e^{-x}) \, dx$ である．
また， $\phi(-\delta)$ は $\delta \le 0$ の場合の式(4)より，

$$\phi(-\delta) = \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n^2} e^{-n\delta}$$

一方で， $\int_{0}^{\infty} \log(1 + e^{-x}) \, dx$ の項別積分は，

$$\int_{0}^{\infty} \log(1 + e^{-x}) \, dx = \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n^2} = \frac{\pi^2}{6} = \phi(0) \quad \cdots (6)$$

である．
（これは $\zeta(2) = \pi^2/6$ を用いることで得られる．）

$\delta \ge 0$ のとき， $\int_{\delta}^{\infty} \log(1 + e^{-x}) \, dx = \int_{0}^{\infty} \log(1 + e^{-(x+\delta)}) \, dx$ は少し複雑なので，
$\int_{0}^{\delta} \log(1+e^{-x}) dx = \int_{0}^{\infty} \log(1+e^{-x}) dx - \int_{\delta}^{\infty} \log(1+e^{-x}) dx = \phi(0) - \int_{\delta}^{\infty} \log(1+e^{-x}) dx$ ．

ここで $\int_{\delta}^{\infty} \log(1+e^{-x}) dx$ を計算すると，

$$\int_{\delta}^{\infty} \log(1+e^{-x}) dx = \int_{0}^{\infty} \log(1+e^{-(x+\delta)}) dx$$

$\log(1+e^{-(x+\delta)}) = \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n} e^{-n(x+\delta)} = \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n} e^{-n\delta} e^{-nx}$ ．
これを積分すると，

$$\int_{0}^{\infty} \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n} e^{-n\delta} e^{-nx} dx = \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n^2} e^{-n\delta} = \phi(-\delta)$$

したがって， $\delta \ge 0$ のとき，

$$\begin{aligned} \phi(\delta) &= \frac{\delta^2}{2} + \phi(0) + (\phi(0) - \phi(-\delta)) \\ &= \frac{\delta^2}{2} + 2\phi(0) - \phi(-\delta) \\ &= \frac{\delta^2}{2} + \frac{\pi^2}{6} - \phi(-\delta) \quad \cdots (7) \end{aligned}$$

を得る．

以上により，題意の展開式が示された．

## 解説

この問題は，金属の光電効果を統計力学的な観点から解析するものである．

### 1. 物理的背景

金属中の電子はフェルミ統計に従い，フェルミエネルギー $\mu$ までのエネルギー状態を占有している．
光子を吸収した電子が外部へ脱出するためには，そのエネルギーが仕事関数 $\chi$ を超える必要がある．

### 2. 統計力学の適用

電子の流れ $S$ は，フェルミ・ディラック分布を用いた多次元の積分として定式化される．
この積分を計算することで，光電流 $I$ が温度 $T$ の 2 乗に比例し，ある関数 $\phi(\delta)$ に依存することが導かれる．

### 3. 数学的テクニック

関数 $\phi(\delta)$ の展開には， $\log(1+x)$ のテイラー展開と，項別積分が用いられている．
$\delta$ の符号によって展開の形が変わる点は，関数の振る舞いが低エネルギー領域（ $\delta \le 0$ ）と高エネルギー領域（ $\delta \ge 0$ ）で異なることを反映している．

### 4. Fowlerプロット

本問で導出された理論式は，実験結果と非常によく一致することが知られている．
$\log(I/AT^2)$ を $\delta$ に対してプロットしたものは Fowler プロットと呼ばれ，この直線の傾きや切片から，金属の仕事関数 $\chi$ を精度よく決定することができる．
