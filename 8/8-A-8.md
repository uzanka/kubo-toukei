# 演習問題【8-A-8】

## 解答

### 1．物理モデルと使用する公式

LiおよびNaの価電子を，3次元の非相互作用量子自由電子Fermi気体（Sommerfeld模型）として扱う．
価電子の電子比熱およびスピン常磁性磁化率を求める．

本解答では，電子比熱を単位質量当たりの比熱，スピン常磁性磁化率を単位質量当たりの磁化率として計算する．

以下の記号を用いる．

- $z$ ： 原子1個当たりの価電子数
- $N_A$ ： Avogadro定数
- $M$ ： モル質量 $\mathrm{(g/mol)}$
- $\rho$ ： 質量密度 $\mathrm{(g/cm^3)}$
- $N_m$ ： 単位質量当たりの価電子数 $\mathrm{(g^{-1})}$
- $n_e$ ： 単位体積当たりの電子数 $\mathrm{(cm^{-3})}$
- $E_F$ ： 絶対零度におけるFermiエネルギー
- $D(E_F)$ ： Fermiエネルギーにおける全状態密度
- $k_B$ ： Boltzmann定数
- $\mu_B$ ： Bohr磁子

LiおよびNaは1価の金属であるため，

```math
z=1
```

とする．

また，以下の仮定を置く．

1. 価電子は3次元の非相互作用自由電子として扱う．
2. 電子の分散関係は非相対論的な自由電子の分散関係に従う．
3. スピン縮退度は2とする．
4. バンド構造による有効質量の補正，電子間相互作用，および軌道反磁性は無視する．
5. 温度はFermi温度に比べて十分に低い．
6. 磁化率は弱磁場における線形応答として求める．

電子比熱と磁化率の低温近似の適用条件は，

```math
\boxed{k_BT\ll E_F}
```

である．
ここで， $T$ は絶対温度， $E_F$ はFermiエネルギーである．

また，磁場によるZeemanエネルギーはFermiエネルギーに比べて十分小さいものとし，

```math
\boxed{\mu_B|H|\ll E_F}
```

とする．
磁化率は特に，外部磁場をゼロに近づけた線形応答の極限で定義する．

以下ではGaussian cgs単位系を使用する．

#### 1.1 単位質量当たりおよび単位体積当たりの電子数

1 molの金属に含まれる価電子数は，

```math
zN_A
```

であり，その質量は $M$ である．

したがって，単位質量当たりの電子数は，

```math
\boxed{
N_m=\frac{zN_A}{M}
}
\tag{1}
```

である．

また，質量密度を $\rho$ とすると，単位体積当たりの電子数は，

```math
\begin{aligned}
n_e
&=\rho N_m\\
&=\frac{\rho zN_A}{M}
\end{aligned}
```

である．
よって，

```math
\boxed{
n_e=\frac{\rho zN_A}{M}
}
\tag{2}
```

となる．

ここでは，問題文の密度の数値を $\mathrm{g/cm^3}$ と解釈する．
また，計算には近似モル質量として，

```math
M_{\mathrm{Li}}\simeq7.00\ \mathrm{g/mol}
```

```math
M_{\mathrm{Na}}\simeq23.0\ \mathrm{g/mol}
```

を用いる．

#### 1.2 Fermiエネルギー

3次元自由電子気体を一辺 $L$ の立方体に入れ，周期境界条件を課す．
このとき，波数空間における許される状態は，単位体積当たり

```math
\frac{V}{(2\pi)^3}
```

個存在する．
ここで $V=L^3$ である．

巨視的な系では，波数空間の状態を連続的に数えることができる．

電子の波数ベクトルを $\boldsymbol q$ ，Fermi波数を $q_F$ とする．
スピン縮退度は2なので，絶対零度における電子数は，

```math
N_e
=
2\frac{V}{(2\pi)^3}
\frac{4\pi}{3}q_F^3
```

で与えられる．
したがって，

```math
N_e=\frac{Vq_F^3}{3\pi^2}
```

となる．

ここで，

```math
n_e=\frac{N_e}{V}
```

を用いれば，

```math
n_e=\frac{q_F^3}{3\pi^2}
```

である．
よって，

```math
\boxed{
q_F=(3\pi^2n_e)^{1/3}
}
```

となる．

非相対論的な自由電子のエネルギーは，

```math
E(\boldsymbol q)
=\frac{\hbar^2q^2}{2m_e}
```

であるため，Fermiエネルギーは，

```math
E_F=\frac{\hbar^2q_F^2}{2m_e}
```

となる．
ここで，

```math
\hbar=\frac{h}{2\pi}
```

を用いると，

```math
\begin{aligned}
E_F
&=\frac{h^2}{8\pi^2m_e}
(3\pi^2n_e)^{2/3}\\
&=\frac{h^2}{2m_e}
\left(\frac{3n_e}{8\pi}\right)^{2/3}
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
E_F=
\frac{h^2}{2m_e}
\left(\frac{3n_e}{8\pi}\right)^{2/3}
}
\tag{3}
```

である．

ここで， $h$ はPlanck定数， $m_e$ は電子質量である．

#### 1.3 電子比熱の公式

3次元自由電子気体のFermiエネルギーにおける全状態密度は，

```math
D(E_F)=\frac{3N_e}{2E_F}
```

である．
ここで，全状態密度はスピン縮退度2を含んでいる．

強く縮退したFermi気体にSommerfeld展開を適用すると，電子系の全定積熱容量は，

```math
C_V=\frac{\pi^2}{3}k_B^2T D(E_F)
```

となる．

したがって，

```math
\begin{aligned}
C_V
&=\frac{\pi^2}{3}k_B^2T
\frac{3N_e}{2E_F}\\
&=\frac{\pi^2N_ek_B^2T}{2E_F}
\end{aligned}
```

を得る．

試料全体の質量を $\mathcal M$ とすると，単位質量当たりの電子比熱は，

```math
c_v=\frac{C_V}{\mathcal M}
```

である．
また，

```math
\frac{N_e}{\mathcal M}=N_m
```

なので，

```math
\boxed{
c_v=N_m\frac{\pi^2k_B^2T}{2E_F}
}
\tag{4}
```

となる．

この式は，

```math
k_BT\ll E_F
```

の低温近似で成立する．

#### 1.4 スピン常磁性磁化率の公式

以下では，磁化率についてGaussian cgs単位系を使用する．

スピン縮退度2を含むFermiエネルギーにおける状態密度を単位体積当たりで表すと，

```math
D_V(E_F)=\frac{D(E_F)}{V}
=\frac{3n_e}{2E_F}
```

となる．

外部磁場 $H$ を加えると，電子のスピンによるZeemanエネルギーが生じ，スピンの向きによってエネルギー準位が分裂する．

弱磁場の線形応答領域では，Fermi準位近傍のスピン占有数の差は，

```math
n_\uparrow-n_\downarrow
=\mu_BH D_V(E_F)
```

と表される．
ここで， $D_V(E_F)$ は両スピンの状態を含む全状態密度である．

スピン磁化は，

```math
M_V=\mu_B(n_\uparrow-n_\downarrow)
```

なので，

```math
M_V=\mu_B^2H D_V(E_F)
```

となる．

Gaussian cgs単位系では，体積磁化率は

```math
\chi_{P,V}=\frac{M_V}{H}
```

で定義される．
したがって，

```math
\chi_{P,V}=\mu_B^2D_V(E_F)
```

を得る．
これに，

```math
D_V(E_F)=\frac{3n_e}{2E_F}
```

を代入すると，

```math
\chi_{P,V}
=\frac{3n_e\mu_B^2}{2E_F}
```

となる．

これは単位体積当たりのスピン常磁性磁化率である．
単位質量当たりの磁化率を求めるには，質量密度 $\rho$ で割ればよい．

```math
\begin{aligned}
\chi_s
&=\frac{\chi_{P,V}}{\rho}\\
&=\frac{3n_e\mu_B^2}{2\rho E_F}\\
&=\frac{3N_m\mu_B^2}{2E_F}
\end{aligned}
```

したがって，

```math
\boxed{
\chi_s=\frac{3N_m\mu_B^2}{2E_F}
}
\tag{5}
```

となる．

この式は低温におけるPauliスピン常磁性の先頭項であり，この近似では温度に依存しない．

なお，SI単位系で体積磁化率を表す場合には真空の透磁率が現れるが，ここではGaussian cgs単位系を使用するため導入しない．

### 2．電子比熱の公式を整理する

式 (4) に式 (3) を代入すると，

```math
\begin{aligned}
c_v
&=N_m
\frac{\pi^2k_B^2T}
{2\cdot\frac{h^2}{2m_e}
\left(\frac{3n_e}{8\pi}\right)^{2/3}}\\
&=N_m\frac{\pi^2k_B^2m_eT}{h^2}
\left(\frac{8\pi}{3n_e}\right)^{2/3}
\end{aligned}
```

となる．

ここで，

```math
(8\pi)^{2/3}=4\pi^{2/3}
```

を用いると，

```math
c_v=
\frac{4\pi^{8/3}}{3^{2/3}}
\frac{k_B^2m_e}{h^2}
\frac{N_m}{n_e^{2/3}}T
```

を得る．

さらに，式 (2) より，

```math
n_e=\rho N_m
```

であるから，

```math
\begin{aligned}
\frac{N_m}{n_e^{2/3}}
&=\frac{N_m}{(\rho N_m)^{2/3}}\\
&=N_m^{1/3}\rho^{-2/3}
\end{aligned}
```

となる．

また，式 (1) より，

```math
N_m^{1/3}
=\left(\frac{zN_A}{M}\right)^{1/3}
```

である．

これらを代入すれば，

```math
\boxed{
c_v=
\frac{4}{3^{2/3}}\pi^{8/3}
\frac{k_B^2m_eN_A^{1/3}}{h^2}
\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}T
}
\tag{6}
```

を得る．

CODATA 2022の物理定数をGaussian cgs単位系で代入し，エネルギーの単位をcalに換算すると，

```math
\boxed{
c_v\simeq
3.24973\times10^{-5}
\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}T
\quad
\mathrm{cal\,g^{-1}K^{-1}}
}
\tag{7}
```

となる．

ここでは， $T$ をK， $\rho$ を $\mathrm{g/cm^3}$ ， $M$ を $\mathrm{g/mol}$ で表す．

したがって，強く縮退した自由電子Fermi気体の電子比熱は，

```math
\boxed{c_v\propto T}
```

となる．

### 3．スピン常磁性磁化率の公式を整理する

式 (5) に式 (3) を代入すると，

```math
\begin{aligned}
\chi_s
&=\frac{3N_m\mu_B^2}
{2\cdot\frac{h^2}{2m_e}
\left(\frac{3n_e}{8\pi}\right)^{2/3}}\\
&=\frac{3N_m\mu_B^2m_e}{h^2}
\left(\frac{8\pi}{3n_e}\right)^{2/3}
\end{aligned}
```

となる．

ここで，

```math
(8\pi)^{2/3}=4\pi^{2/3}
```

を用いると，

```math
\chi_s=
4\cdot3^{1/3}\pi^{2/3}
\frac{\mu_B^2m_e}{h^2}
\frac{N_m}{n_e^{2/3}}
```

を得る．

電子比熱の場合と同様に，

```math
\frac{N_m}{n_e^{2/3}}
=N_m^{1/3}\rho^{-2/3}
```

および，

```math
N_m^{1/3}
=\left(\frac{zN_A}{M}\right)^{1/3}
```

を代入すると，

```math
\boxed{
\chi_s=
4\cdot3^{1/3}\pi^{2/3}
\frac{\mu_B^2m_eN_A^{1/3}}{h^2}
\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}
}
\tag{8}
```

となる．

定数をGaussian cgs単位系で代入すると，

```math
\boxed{
\chi_s\simeq
1.86479\times10^{-6}
\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}
\quad
\mathrm{cm^3/g}
}
\tag{9}
```

を得る．

ここで， $\mathrm{cm^3/g}$ はGaussian cgs単位系における単位質量当たりの磁化率であり，

```math
\mathrm{cm^3/g}
\equiv
\mathrm{emu/(Oe\cdot g)}
```

と表すこともできる．

以上より，電子比熱とスピン常磁性磁化率は，いずれも

```math
\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}
```

に比例する．
ただし，電子比熱は温度 $T$ に比例し，スピン常磁性磁化率は低温近似の先頭項では温度に依存しない．

### 4．Liの計算

Liの価電子は1原子当たり1個であるから，

```math
z=1
```

とする．

与えられた密度と，計算に用いる近似モル質量は，

```math
\rho=0.534\ \mathrm{g/cm^3}
```

```math
M=7.00\ \mathrm{g/mol}
```

である．

#### 4.1 電子密度とFermiエネルギー

単位質量当たりの電子数は，

```math
\begin{aligned}
N_m
&=\frac{N_A}{7.00}\\
&=\frac{6.02214076\times10^{23}}{7.00}\\
&=8.60306\times10^{22}\ \mathrm{g^{-1}}
\end{aligned}
```

となる．

したがって，電子密度は，

```math
\begin{aligned}
n_e
&=\rho N_m\\
&=0.534\times8.60306\times10^{22}\\
&=4.59403\times10^{22}\ \mathrm{cm^{-3}}
\end{aligned}
```

である．

式 (3) より，

```math
E_F=
\frac{h^2}{2m_e}
\left(\frac{3n_e}{8\pi}\right)^{2/3}
```

であるから，

```math
E_F\simeq4.67735\ \mathrm{eV}
```

を得る．

したがって，有効数字を3桁に丸めると，

```math
\boxed{
E_F(\mathrm{Li})=4.68\ \mathrm{eV}
}
```

となる．

Fermi温度は，

```math
T_F=\frac{E_F}{k_B}
```

で定義されるので，

```math
\boxed{
T_F(\mathrm{Li})=5.43\times10^4\ \mathrm K
}
```

となる．

#### 4.2 電子比熱

式 (7) にLiの値を代入すると，

```math
\begin{aligned}
F_{\mathrm{Li}}
&=\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}\\
&=\frac{1}{0.534^{2/3}\times7.00^{1/3}}\\
&=0.794218
\end{aligned}
```

となる．

したがって，

```math
\begin{aligned}
c_v
&=3.24973\times10^{-5}
\times0.794218\,T\\
&=2.5809966\times10^{-5}T
\quad\mathrm{cal\,g^{-1}K^{-1}}
\end{aligned}
```

を得る．

よって，

```math
\boxed{
c_v(\mathrm{Li})
=2.58\times10^{-5}T
\quad
\mathrm{cal\,g^{-1}K^{-1}}
}
```

である．

#### 4.3 スピン常磁性磁化率

式 (9) にLiの値を代入すると，

```math
\begin{aligned}
\chi_s
&=1.86479\times10^{-6}\times0.794218\\
&=1.4810481\times10^{-6}
\end{aligned}
```

となる．

したがって，

```math
\boxed{
\chi_s(\mathrm{Li})
=1.48\times10^{-6}
\quad
\mathrm{cm^3/g}
}
```

である．

### 5．Naの計算

Naの価電子も1原子当たり1個であるから，

```math
z=1
```

とする．

与えられた密度と，計算に用いる近似モル質量は，

```math
\rho=0.97\ \mathrm{g/cm^3}
```

```math
M=23.0\ \mathrm{g/mol}
```

である．

#### 5.1 電子密度とFermiエネルギー

単位質量当たりの電子数は，

```math
\begin{aligned}
N_m
&=\frac{N_A}{23.0}\\
&=\frac{6.02214076\times10^{23}}{23.0}\\
&=2.61832\times10^{22}\ \mathrm{g^{-1}}
\end{aligned}
```

となる．

したがって，電子密度は，

```math
\begin{aligned}
n_e
&=\rho N_m\\
&=0.97\times2.61832\times10^{22}\\
&=2.53977\times10^{22}\ \mathrm{cm^{-3}}
\end{aligned}
```

である．

式 (3) より，

```math
E_F\simeq3.15065\ \mathrm{eV}
```

を得る．

問題文の密度の有効数字に合わせると，

```math
\boxed{
E_F(\mathrm{Na})=3.2\ \mathrm{eV}
}
```

となる．

したがって，Fermi温度は，

```math
\boxed{
T_F(\mathrm{Na})=3.7\times10^4\ \mathrm K
}
```

である．

#### 5.2 電子比熱

式 (7) にNaの値を代入すると，

```math
\begin{aligned}
F_{\mathrm{Na}}
&=\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}\\
&=\frac{1}{0.97^{2/3}\times23.0^{1/3}}\\
&=0.358847
\end{aligned}
```

となる．

したがって，

```math
\begin{aligned}
c_v
&=3.24973\times10^{-5}
\times0.358847\,T\\
&=1.1661574\times10^{-5}T
\quad\mathrm{cal\,g^{-1}K^{-1}}
\end{aligned}
```

を得る．

問題文の密度の有効数字に合わせると，

```math
\boxed{
c_v(\mathrm{Na})
=1.2\times10^{-5}T
\quad
\mathrm{cal\,g^{-1}K^{-1}}
}
```

である．

#### 5.3 スピン常磁性磁化率

式 (9) にNaの値を代入すると，

```math
\begin{aligned}
\chi_s
&=1.86479\times10^{-6}\times0.358847\\
&=6.6917379\times10^{-7}
\end{aligned}
```

となる．

したがって，

```math
\boxed{
\chi_s(\mathrm{Na})
=6.7\times10^{-7}
\quad
\mathrm{cm^3/g}
}
```

である．

### 6．数値計算に用いた物理定数

数値計算にはCODATA 2022の推奨値を用いる．
Gaussian cgs単位系に換算すると，

```math
\begin{aligned}
k_B&=1.380649\times10^{-16}
\ \mathrm{erg/K},\\
m_e&=9.1093837139\times10^{-28}
\ \mathrm{g},\\
h&=6.62607015\times10^{-27}
\ \mathrm{erg\,s},\\
\mu_B&=9.2740100657\times10^{-21}
\ \mathrm{erg/G},\\
N_A&=6.02214076\times10^{23}
\ \mathrm{mol^{-1}}
\end{aligned}
```

である．

また，熱化学カロリーについて，

```math
1\ \mathrm{cal}=4.184\ \mathrm J
=4.184\times10^7\ \mathrm{erg}
```

を用いた．

さらに，

```math
1\ \mathrm{eV}
=1.602176634\times10^{-12}\ \mathrm{erg}
```

を用いてFermiエネルギーをeVに換算した．

### 7．計算結果の比較

各金属の計算結果をまとめると，次のとおりである．

| 物理量 | Li | Na |
|---|---:|---:|
| 価電子数 $z$ | 1 | 1 |
| 質量密度 $\rho$ | 0.534 | 0.97 |
| モル質量 $M$ | 7.00 | 23.0 |
| 電子密度 $n_e$ | $4.59\times10^{22}$ | $2.5\times10^{22}$ |
| Fermiエネルギー $E_F$ | 4.68 eV | 3.2 eV |
| Fermi温度 $T_F$ | $5.43\times10^4$ K | $3.7\times10^4$ K |

密度は $\mathrm{g/cm^3}$ ，モル質量は $\mathrm{g/mol}$ ，電子密度は $\mathrm{cm^{-3}}$ である．

電子比熱とスピン常磁性磁化率の最終結果は，

| 金属 | 電子比熱 $c_v$ | 質量スピン常磁性磁化率 $\chi_s$ |
|---|---|---|
| Li | $2.58\times10^{-5}T\ \mathrm{cal\,g^{-1}K^{-1}}$ | $1.48\times10^{-6}\ \mathrm{cm^3/g}$ |
| Na | $1.2\times10^{-5}T\ \mathrm{cal\,g^{-1}K^{-1}}$ | $6.7\times10^{-7}\ \mathrm{cm^3/g}$ |

である．

### 8．物理的な妥当性の検討

#### 8.1 強縮退近似の確認

強く縮退している条件は，

```math
T\ll T_F
```

である．

今回得られたFermi温度は，

```math
T_F(\mathrm{Li})\simeq5.43\times10^4\ \mathrm K
```

```math
T_F(\mathrm{Na})\simeq3.66\times10^4\ \mathrm K
```

である．

例えば，室温を $T=300\ \mathrm K$ とすると，

```math
\frac{T}{T_F}
\simeq
\begin{cases}
5.53\times10^{-3} & \mathrm{Li},\\
8.21\times10^{-3} & \mathrm{Na}
\end{cases}
```

となる．

いずれも十分に小さいため，室温程度では強縮退近似が妥当である．

したがって，電子比熱の温度に対する一次の比例関係と，Pauliスピン常磁性磁化率の温度に依存しない先頭項は，この模型の範囲で正当化される．

#### 8.2 電子比熱の物理的意味

強く縮退したFermi気体では，低温においてFermiエネルギー近傍の限られた電子だけが熱励起に寄与する．

したがって，電子比熱は，

```math
c_v\propto T
```

となる．

これはFermi–Dirac統計とPauliの排他原理に由来する，量子縮退系に特有の性質である．

#### 8.3 スピン常磁性磁化率の物理的意味

Pauliスピン常磁性は，Fermi準位近傍にある電子のスピンの占有数が，外部磁場によってわずかに偏ることに由来する．

このため，低温極限ではFermi準位の状態密度によって磁化率が決まり，

```math
\chi_s\simeq\mathrm{const.}
```

となる．

有限温度では，Fermi分布の熱的な広がりによる高次補正が存在するが，今回の低温近似では無視している．

#### 8.4 自由電子模型の限界

今回計算した磁化率は，Pauliスピン常磁性成分のみである．

実在金属の全磁化率には，Landau軌道反磁性，内殻電子の反磁性，バンド構造や電子間相互作用による補正などが存在する．

したがって，今回の結果は実在金属の全磁化率そのものではなく，自由電子Fermi気体模型によるスピン常磁性成分の理論値である．

また，電子比熱は電子系のみの寄与であり，格子振動による比熱は含まない．

### 9．結論

LiおよびNaの価電子を非相互作用の量子自由電子Fermi気体とみなすと，単位質量当たりの電子比熱は，

```math
c_v=N_m\frac{\pi^2k_B^2T}{2E_F}
```

であり，単位質量当たりのPauliスピン常磁性磁化率は，

```math
\chi_s=\frac{3N_m\mu_B^2}{2E_F}
```

で与えられる．

密度とモル質量を用いてFermiエネルギーを計算し，物理定数を代入すると，

**Liについて**

```math
\boxed{
c_v(\mathrm{Li})
=2.58\times10^{-5}T
\quad
\mathrm{cal\,g^{-1}K^{-1}}
}
```

```math
\boxed{
\chi_s(\mathrm{Li})
=1.48\times10^{-6}
\quad
\mathrm{cm^3/g}
}
```

**Naについて**

```math
\boxed{
c_v(\mathrm{Na})
=1.2\times10^{-5}T
\quad
\mathrm{cal\,g^{-1}K^{-1}}
}
```

```math
\boxed{
\chi_s(\mathrm{Na})
=6.7\times10^{-7}
\quad
\mathrm{cm^3/g}
}
```

を得る．

したがって，自由電子Fermi気体模型では，Liの単位質量当たりの電子比熱およびスピン常磁性磁化率は，いずれもNaより大きい．

以上より，強く縮退した自由電子Fermi気体の理論に基づき，LiおよびNaの電子比熱と単位質量当たりのスピン常磁性磁化率が求められた．
