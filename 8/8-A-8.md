# 演習問題【8-A-8】

## 解答

### 1．使用する公式と物理量の定義

LiおよびNaの価電子を自由電子Fermi気体とみなし，電子比熱 $c_v$ とスピン常磁性磁化率 $\chi_s$ を求める．
ここで求めるのは，いずれも **単位質量あたりの値** である．

以下の記号を用いる．

- $z$ ： 原子1個あたりの価電子数
- $N_A$ ： Avogadro定数
- $M$ ： モル質量（ $\mathrm{g/mol}$ ）
- $\rho$ ： 質量密度（ $\mathrm{g/cm^3}$ ）
- $N_m$ ： 単位質量あたりの電子数（ $\mathrm{g^{-1}}$ ）
- $n_e$ ： 単位体積あたりの電子数（ $\mathrm{cm^{-3}}$ ）

1 molの金属に含まれる価電子数は $zN_A$ であり，その質量は $M$ である．
したがって，単位質量あたりの電子数は

```math
N_m=\frac{zN_A}{M}
\tag{1}
```

である．
単位体積あたりの電子数は，質量密度を用いて

```math
n_e=\rho N_m=\frac{\rho zN_A}{M}
\tag{2}
```

と表される．

強く縮退した理想Fermi気体に対する電子比熱とスピン常磁性磁化率の公式は，

```math
c_v=N_m\frac{\pi^2 k^2 T}{2\mu_0}
\tag{3}
```

```math
\chi_s=\frac{3N_m\mu_B^2}{2\mu_0}
\tag{4}
```

である．
ここで， $k$ はBoltzmann定数， $\mu_B$ はBohr磁子， $\mu_0$ は絶対零度におけるFermiエネルギーである．

3次元自由電子気体では，Fermiエネルギーは単位体積あたりの電子数によって

```math
\mu_0=\frac{h^2}{2m}
\left(\frac{3n_e}{8\pi}\right)^{2/3}
\tag{5}
```

と表される．
ここで， $h$ はPlanck定数， $m$ は電子質量である．
式 (3)，(4) に式 (5) を代入して，密度などの与えられた量で表す．

### 2．電子比熱の公式を整理する

式 (3) に式 (5) を代入すると，

```math
\begin{aligned}
c_v
&=N_m\frac{\pi^2k^2T}
{2\cdot\frac{h^2}{2m}
\left(\frac{3n_e}{8\pi}\right)^{2/3}}\\
&=N_m\frac{\pi^2k^2mT}{h^2}
\left(\frac{8\pi}{3n_e}\right)^{2/3}
\end{aligned}
```

となる．
ここで，

```math
(8\pi)^{2/3}=4\pi^{2/3}
```

を使うと，

```math
c_v=
\frac{4\pi^{8/3}}{3^{2/3}}
\frac{k^2m}{h^2}
\frac{N_m}{n_e^{2/3}}T
```

を得る．
さらに $n_e=\rho N_m$ であるから，

```math
\frac{N_m}{n_e^{2/3}}
=\frac{N_m}{(\rho N_m)^{2/3}}
=N_m^{1/3}\rho^{-2/3}
```

となる．
これと式 (1) より，

```math
N_m^{1/3}
=\left(\frac{zN_A}{M}\right)^{1/3}
```

である．
よって，

```math
\boxed{
c_v=
\frac{4}{3^{2/3}}\pi^{8/3}
\frac{k^2mN_A^{1/3}}{h^2}
\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}T
}
\tag{6}
```

となる．
定数をcgs単位系で代入し，エネルギーの単位をcalに換算すると，

```math
\boxed{
c_v\simeq
0.3248\times10^{-4}
\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}
T
\quad
\mathrm{cal\,g^{-1}K^{-1}}
}
\tag{7}
```

を得る．
ここでは $T$ をK， $\rho$ を $\mathrm{g/cm^3}$ ， $M$ を $\mathrm{g/mol}$ で表している．

### 3．スピン常磁性磁化率の公式を整理する

式 (4) に式 (5) を代入すると，

```math
\begin{aligned}
\chi_s
&=\frac{3N_m\mu_B^2}
{2\cdot\frac{h^2}{2m}
\left(\frac{3n_e}{8\pi}\right)^{2/3}}\\
&=\frac{3N_m\mu_B^2m}{h^2}
\left(\frac{8\pi}{3n_e}\right)^{2/3}
\end{aligned}
```

となる．
ここで $(8\pi)^{2/3}=4\pi^{2/3}$ を用いると，

```math
\chi_s=
4\cdot3^{1/3}\pi^{2/3}
\frac{\mu_B^2m}{h^2}
\frac{N_m}{n_e^{2/3}}
```

を得る．
電子比熱の場合と同じく，

```math
\frac{N_m}{n_e^{2/3}}
=N_m^{1/3}\rho^{-2/3}
=\frac{z^{1/3}N_A^{1/3}}{M^{1/3}}\rho^{-2/3}
```

であるから，

```math
\boxed{
\chi_s=
4\cdot3^{1/3}\pi^{2/3}
\frac{\mu_B^2mN_A^{1/3}}{h^2}
\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}
}
\tag{8}
```

となる．
定数をcgs単位系で代入すると，

```math
\boxed{
\chi_s\simeq
1.8646\times10^{-6}
\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}
\quad
\mathrm{c.g.s.\ e.m.u./g}
}
\tag{9}
```

を得る．

式 (7)，(9) から，どちらの物理量も

```math
\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}
```

に比例することがわかる．
また，この近似では電子比熱は温度 $T$ に比例し，スピン常磁性磁化率は温度に依存しない．

### 4．Liの計算

Liの価電子は1原子あたり1個とするので，

```math
z=1,\qquad \rho=0.534,\qquad M=7
```

である．
まず，式 (7)，(9) に必要な因子を計算すると，

```math
\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}
=\frac{1}{0.534^{2/3}\,7^{1/3}}
\simeq0.794
```

となる．
これを式 (7) に代入すると，

```math
\begin{aligned}
c_v
&\simeq0.3248\times10^{-4}\times0.794\,T\\
&=0.2579\times10^{-4}T
\quad\mathrm{cal\,g^{-1}K^{-1}}
\end{aligned}
```

を得る．
同様に，式 (9) より，

```math
\begin{aligned}
\chi_s
&\simeq1.8646\times10^{-6}\times0.794\\
&=1.4808\times10^{-6}
\quad\mathrm{c.g.s.\ e.m.u./g}
\end{aligned}
```

となる．
したがって，Liの結果は，

```math
\boxed{
c_v=0.2579\times10^{-4}T
\quad\mathrm{cal\,g^{-1}K^{-1}}
}
```

```math
\boxed{
\chi_s=1.4808\times10^{-6}
\quad\mathrm{c.g.s.\ e.m.u./g}
}
```

である．

### 5．Naの計算

Naについては，

```math
z=1,\qquad \rho=0.97,\qquad M=23
```

である．
したがって，

```math
\frac{z^{1/3}}{\rho^{2/3}M^{1/3}}
=\frac{1}{0.97^{2/3}\,23^{1/3}}
\simeq0.359
```

となる．
これを式 (7) に代入すると，

```math
\begin{aligned}
c_v
&\simeq0.3248\times10^{-4}\times0.359\,T\\
&=0.1166\times10^{-4}T
\quad\mathrm{cal\,g^{-1}K^{-1}}
\end{aligned}
```

を得る．
同様に，式 (9) より，

```math
\begin{aligned}
\chi_s
&\simeq1.8646\times10^{-6}\times0.359\\
&=0.6691\times10^{-6}
\quad\mathrm{c.g.s.\ e.m.u./g}
\end{aligned}
```

となる．
したがって，Naの結果は，

```math
\boxed{
c_v=0.1166\times10^{-4}T
\quad\mathrm{cal\,g^{-1}K^{-1}}
}
```

```math
\boxed{
\chi_s=0.6691\times10^{-6}
\quad\mathrm{c.g.s.\ e.m.u./g}
}
```

である．

### 6．結果の比較と物理的意味

計算結果をまとめると，次のとおりである．

| 金属 | 電子比熱 $c_v$ | スピン常磁性磁化率 $\chi_s$ |
|---|---|---|
| Li | $0.2579\times10^{-4}T\ \mathrm{cal\,g^{-1}K^{-1}}$ | $1.4808\times10^{-6}\ \mathrm{c.g.s.\ e.m.u./g}$ |
| Na | $0.1166\times10^{-4}T\ \mathrm{cal\,g^{-1}K^{-1}}$ | $0.6691\times10^{-6}\ \mathrm{c.g.s.\ e.m.u./g}$ |

電子比熱が温度に比例する理由は，強く縮退したFermi気体では，Fermi準位近傍の限られた電子だけが熱エネルギーを受け取って励起されるためである．
一方，スピン常磁性磁化率は，この近似ではFermi準位付近の状態密度で決まり，低温の先頭項では温度に依存しない．

また，LiとNaでは，密度とモル質量が異なるため，単位質量あたりの電子数や電子密度が異なる．
その結果，Fermiエネルギーも異なり，電子比熱と磁化率にも差が生じる．
今回の自由電子近似では，Liの単位質量あたりの電子比熱およびスピン常磁性磁化率は，いずれもNaより大きい．

以上より，理想Fermi気体の公式を用いて単位質量あたりの電子比熱とスピン常磁性磁化率を表し，密度とモル質量を代入することで，LiおよびNaの値が得られるのである．
