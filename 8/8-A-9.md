# 演習問題【8-A-9】

## 解答

### 1．理想Fermi気体の状態方程式 $pV=\frac23U$ の導出

3次元の自由電子Fermi気体を考える．
電子の運動エネルギーは $\varepsilon=p^2/(2m)$ であるため，状態密度 $D(\varepsilon)$ はエネルギーの平方根に比例する．
スピンの2重縮退を含む状態密度を

```math
D(\varepsilon)=C\varepsilon^{1/2}
```

と表す．
ここで $C$ は電子数と体積で決まる定数である．

Fermi分布関数は

```math
f(\varepsilon)=
\frac{1}{e^{\beta(\varepsilon-\mu)}+1},
\qquad
\beta=\frac{1}{kT}
```

である．
系の内部エネルギー $U$ は，各エネルギー状態のエネルギーに占有確率を掛けて積分することにより，

```math
U=\int_0^\infty \varepsilon D(\varepsilon)
f(\varepsilon)\,d\varepsilon
\tag{1}
```

と表される．

一方，大分配関数 $\mathcal Z$ を用いると，圧力は

```math
pV=kT\ln\mathcal Z
=kT\int_0^\infty D(\varepsilon)
\ln\left[1+e^{\beta(\mu-\varepsilon)}\right]
\,d\varepsilon
\tag{2}
```

と書ける．
ここで，状態密度はスピンの自由度を含むものとする．

式 (2) に部分積分を適用する．

```math
u=\ln\left[1+e^{\beta(\mu-\varepsilon)}\right],
\qquad
dv=C\varepsilon^{1/2}\,d\varepsilon
```

とおくと，

```math
du=-\beta f(\varepsilon)\,d\varepsilon,
\qquad
v=\frac23C\varepsilon^{3/2}
```

である．
したがって，

```math
\begin{aligned}
pV
&=kT\left[
\frac23C\varepsilon^{3/2}
\ln\left(1+e^{\beta(\mu-\varepsilon)}\right)
\right]_0^\infty\\
&\quad+\frac23kT\beta C
\int_0^\infty\varepsilon^{3/2}
f(\varepsilon)\,d\varepsilon
\end{aligned}
```

となる．
境界項は， $\varepsilon=0$ では $\varepsilon^{3/2}=0$ ， $\varepsilon\to\infty$ では対数の項が指数関数的にゼロに近づくため，消失する．
さらに $kT\beta=1$ および $D(\varepsilon)=C\varepsilon^{1/2}$ を用いると，

```math
\begin{aligned}
pV
&=\frac23C\int_0^\infty
\varepsilon^{3/2}f(\varepsilon)\,d\varepsilon\\
&=\frac23\int_0^\infty
\varepsilon D(\varepsilon)f(\varepsilon)\,d\varepsilon\\
&=\frac23U
\end{aligned}
```

となる．
よって，

```math
\boxed{pV=\frac23U}
\tag{3}
```

が示された．
これは，非相対論的な自由粒子からなる理想Fermi気体の状態方程式であり，縮退の強弱や温度によらず成り立つ関係である．

### 2．強縮退極限における圧力の導出

強く縮退している場合とは，

```math
kT\ll\mu_0
```

が成り立つ場合である．
ここで $\mu_0$ は，温度 $T=0$ における化学ポテンシャル，すなわちFermiエネルギーである．

電子数を $N$ ，体積を $V$ とし，電子1個あたりの体積を

```math
v=\frac VN
```

と定義する．
以下では粒子数 $N$ を一定に保って温度と体積を変化させる．

#### 2.1．化学ポテンシャルの低温展開

自由電子系の状態密度を

```math
D(\varepsilon)=C\varepsilon^{1/2}
```

とすると，電子数は

```math
N=\int_0^\infty D(\varepsilon)
f(\varepsilon)\,d\varepsilon
```

である．
強縮退極限では，Sommerfeld展開

```math
\int_0^\infty F(\varepsilon)f(\varepsilon)\,d\varepsilon
=
\int_0^\mu F(\varepsilon)\,d\varepsilon
+\frac{\pi^2}{6}(kT)^2F'(\mu)
+O(T^4)
\tag{4}
```

を利用できる．
式 (4) に $F(\varepsilon)=D(\varepsilon)$ を代入すると，

```math
N=\frac23C\mu^{3/2}
+\frac{\pi^2}{12}C(kT)^2\mu^{-1/2}
+O(T^4)
\tag{5}
```

となる．

絶対零度では $N=\frac23C\mu_0^{3/2}$ である．
低温では $\mu-\mu_0=O(T^2)$ なので，式 (5) を $\mu_0$ のまわりで展開すると，

```math
C\mu_0^{1/2}(\mu-\mu_0)
+\frac{\pi^2}{12}C(kT)^2\mu_0^{-1/2}
=O(T^4)
```

となる．
これを整理すると，

```math
\boxed{
\mu(T)=\mu_0
\left[
1-\frac{\pi^2}{12}
\left(\frac{kT}{\mu_0}\right)^2
\right]+O(T^4)
}
\tag{6}
```

を得る．

#### 2.2．内部エネルギーと圧力

内部エネルギーは式 (1) より，

```math
U=C\int_0^\infty
\varepsilon^{3/2}f(\varepsilon)\,d\varepsilon
```

である．
Sommerfeld展開を $F(\varepsilon)=C\varepsilon^{3/2}$ に適用すると，

```math
U=\frac25C\mu^{5/2}
+\frac{\pi^2}{4}C(kT)^2\mu^{1/2}
+O(T^4)
\tag{7}
```

となる．
式 (6) の化学ポテンシャルを代入し， $T^2$ まで整理すると，

```math
U=\frac25C\mu_0^{5/2}
\left[
1+\frac{5\pi^2}{12}
\left(\frac{kT}{\mu_0}\right)^2
\right]+O(T^4)
\tag{8}
```

を得る．
ここで，

```math
N=\frac23C\mu_0^{3/2}
```

を用いると，

```math
\boxed{
U=\frac35N\mu_0
\left[
1+\frac{5\pi^2}{12}
\left(\frac{kT}{\mu_0}\right)^2
\right]+O(T^4)
}
\tag{9}
```

となる．

状態方程式 $pV=\frac23U$ に式 (9) を代入し， $v=V/N$ を用いると，

```math
p=\frac25\frac{\mu_0}{v}
\left[
1+\frac{5\pi^2}{12}
\left(\frac{kT}{\mu_0}\right)^2
\right]+O(T^4)
```

である．
これを展開した形で書けば，

```math
\boxed{
p=
\frac25\frac{\mu_0}{v}
+\frac{\pi^2}{6}\frac{(kT)^2}{\mu_0v}
+O(T^4)
}
\tag{10}
```

となる．

### 3．強縮退極限における圧縮率

圧縮率 $\kappa$ は，圧力を変えたとき体積がどれだけ変化するかを表す量であり，

```math
\kappa=-\frac1V\left(\frac{\partial V}{\partial p}\right)_T
```

と定義される．
電子数 $N$ が一定で $v=V/N$ であるから，

```math
\boxed{
\kappa=-\frac1v
\left(\frac{\partial p}{\partial v}\right)_T^{-1}
}
\tag{11}
```

と書ける．

また，Fermiエネルギーは電子密度 $N/V=1/v$ の $2/3$ 乗に比例するため，

```math
\mu_0\propto v^{-2/3}
\tag{12}
```

である．
式 (10) の第1項と第2項をそれぞれ

```math
p_0=\frac25\frac{\mu_0}{v},
\qquad
p_2=\frac{\pi^2}{6}\frac{(kT)^2}{\mu_0v}
```

とおく．
式 (12) より，

```math
p_0\propto v^{-5/3},
\qquad
p_2\propto v^{-1/3}
```

となる．
したがって，

```math
\left(\frac{\partial p}{\partial v}\right)_T
=-\frac53\frac{p_0}{v}
-\frac13\frac{p_2}{v}+O(T^4)
```

である．
これを整理すると，

```math
\left(\frac{\partial p}{\partial v}\right)_T
=-\frac53\frac{p_0}{v}
\left(1+\frac15\frac{p_2}{p_0}\right)+O(T^4)
```

を得る．
式 (11) に代入すると，

```math
\kappa=
\frac{3}{5p_0}
\left(1+\frac15\frac{p_2}{p_0}\right)^{-1}
+O(T^4)
```

となる．
低温では $p_2/p_0\ll1$ であり，

```math
(1+x)^{-1}\simeq1-x
```

と近似できる．
また，

```math
\frac{3}{5p_0}=\frac32\frac{v}{\mu_0}
```

および

```math
\frac{p_2}{p_0}
=\frac{5\pi^2}{12}
\left(\frac{kT}{\mu_0}\right)^2
```

であるから，最終的に

```math
\boxed{
\kappa=
\frac32\frac{v}{\mu_0}
\left[
1-\frac{\pi^2}{12}
\left(\frac{kT}{\mu_0}\right)^2
+O(T^4)
\right]
}
\tag{13}
```

を得る．
特に絶対零度では，

```math
\boxed{
\kappa_0=\frac32\frac{v}{\mu_0}
}
\tag{14}
```

である．

### 4．Na結晶の圧縮率の計算

Naは1原子あたり1個の価電子を持つとする．
原子量は $23$ ，密度は $0.97\,\mathrm{g/cm^3}$ であるから，1 molあたりの体積（モル体積）は

```math
V_A=\frac{23\,\mathrm{g}}{0.97\,\mathrm{g/cm^3}}
\simeq23.71\,\mathrm{cm^3/mol}
\tag{15}
```

である．
Avogadro定数を $N_A=6.022\times10^{23}\,\mathrm{mol^{-1}}$ とすると，電子1個あたりの体積は

```math
v=\frac{V_A}{N_A}
```

となる．

Fermiエネルギーは，

```math
\mu_0=\frac{h^2}{2m}
\left(\frac{3N_A}{8\pi V_A}\right)^{2/3}
\tag{16}
```

で与えられる．
cgs単位系でPlanck定数と電子質量を代入すると，

```math
\mu_0\simeq5.05\times10^{-12}\,\mathrm{erg}
\simeq3.15\,\mathrm{eV}
```

を得る．

式 (14) に $v=V_A/N_A$ を代入すると，

```math
\kappa_0=\frac32\frac{V_A}{N_A\mu_0}
```

である．
数値を代入すれば，

```math
\begin{aligned}
\kappa_0
&=\frac32
\frac{23.71\,\mathrm{cm^3/mol}}
{(6.022\times10^{23}\,\mathrm{mol^{-1}})
(5.05\times10^{-12}\,\mathrm{erg})}\\
&\simeq1.17\times10^{-11}\,\mathrm{cm^2/dyn}
\end{aligned}
```

となる．
ここでは $1\,\mathrm{erg}=1\,\mathrm{dyn\cdot cm}$ を用いた．
したがって，

```math
\boxed{
\kappa_0\simeq11.7\times10^{-12}
\,\mathrm{cm^2/dyn}
}
\tag{17}
```

を得る．
これは絶対零度での圧縮率である．
強縮退した低温では，式 (13) による $T^2$ の補正を加えることができる．

以上より，理想Fermi気体では $pV=\frac23U$ が成り立ち，強縮退極限での圧縮率は式 (13) で表される．
Naの自由電子模型では，絶対零度での圧縮率は約 $1.17\times10^{-11}\,\mathrm{cm^2/dyn}$ である．
