# 演習問題【8-C-26】

## 解答

各粒子が並進運動のエネルギー $\epsilon_{\mathbf p}=p^2/(2m)$ に加えて，内部自由度のエネルギー $0$ または $\epsilon_1$ をもつ理想 Bose 気体を考える．
内部準位はそれぞれ一つずつ存在すると仮定する．
このとき，内部励起準位が Bose–Einstein 凝縮温度に与える影響を求める．

### 1．粒子数の式

温度を $T$ ，ボルツマン定数を $k$ ，化学ポテンシャルを $\mu$ とし，

```math
\beta=\frac{1}{kT}
```

と定義する．
Bose–Einstein 統計によれば，エネルギー $\epsilon$ の状態の平均占有数は，

```math
\overline n(\epsilon)=
\frac{1}{e^{\beta(\epsilon-\mu)}-1}
```

である．

各粒子の全エネルギーは，並進運動と内部自由度のエネルギーの和であるから，

```math
\epsilon_{\mathbf p,j}
=\frac{p^2}{2m}+\epsilon_j,
\qquad
\epsilon_0=0,\quad \epsilon_1>0
```

となる．
したがって，全粒子数 $N$ は，

```math
N=\sum_{j=0}^{1}\sum_{\mathbf p}
\frac{1}{
e^{\beta(p^2/(2m)+\epsilon_j-\mu)}-1
}
\tag{1}
```

と表される．

系の体積 $V$ が十分に大きい場合，運動量状態の和を積分に置き換えることができる．
内部準位の縮重度をそれぞれ $1$ とすると，

```math
\sum_{\mathbf p}
\longrightarrow
\frac{V}{h^3}\int d^3p
=\frac{4\pi V}{h^3}\int_0^\infty p^2\,dp
```

である．
ここで $h$ はプランク定数である．

各内部準位について，変数変換

```math
x=\frac{p^2}{2mkT}
```

を行うと，

```math
p^2\,dp
=\frac12(2mkT)^{3/2}x^{1/2}\,dx
```

となる．
さらに，Bose–Einstein 分布を

```math
\frac{1}{e^{x+a}-1}
=\sum_{l=1}^{\infty}e^{-l(x+a)}
```

と展開すれば，ガンマ積分

```math
\int_0^\infty x^{1/2}e^{-lx}\,dx
=\frac{\Gamma(3/2)}{l^{3/2}}
=\frac{\sqrt{\pi}}{2l^{3/2}}
```

を用いて，次の式が得られる．

```math
\begin{aligned}
N'={}&V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}\\
&\times\left[
\mathcal F_{3/2}(-\beta\mu)
+\mathcal F_{3/2}(\beta(\epsilon_1-\mu))
\right]
\end{aligned}
\tag{2}
```

ここで $N'$ は凝縮していない粒子の総数であり，

```math
\boxed{
\mathcal F_{3/2}(x)
=\sum_{l=1}^{\infty}\frac{e^{-lx}}{l^{3/2}}
}
\tag{3}
```

と定義した．
この級数は $x\geq0$ で収束する．
また， $\mathcal F_{3/2}(0)$ はリーマンゼータ関数の値であり，

```math
\boxed{
\mathcal F_{3/2}(0)
=\zeta\left(\frac32\right)
\simeq2.612
}
\tag{4}
```

である．

### 2．凝縮温度の条件

Bose–Einstein 凝縮は，化学ポテンシャル $\mu$ が最低エネルギー状態のエネルギーに達したときに始まる．
本問題では最低内部準位のエネルギーを $0$ ，運動エネルギーの最低値も $0$ としているため，凝縮温度 $T_c$ では，

```math
\mu=0
```

である．
凝縮が始まる直前には，励起状態にある粒子数 $N'$ が全粒子数 $N$ に等しいため，

```math
N=N'(T_c,\mu=0)
```

となる．
式(2)に $\mu=0$ を代入し，粒子数密度を $n=N/V$ とすると，

```math
\boxed{
n=
\left(\frac{2\pi mkT_c}{h^2}\right)^{3/2}
\left[
\zeta\left(\frac32\right)
+\mathcal F_{3/2}\left(\frac{\epsilon_1}{kT_c}\right)
\right]
}
\tag{5}
```

を得る．
これが，内部励起準位を考慮した凝縮温度を決定する基本式である．

通常の内部励起準位をもたない理想 Bose 気体の凝縮温度を $T_c^0$ とすると，

```math
n=\zeta\left(\frac32\right)
\left(\frac{2\pi mkT_c^0}{h^2}\right)^{3/2}
\tag{6}
```

である．
式(5)，(6)を比較すれば，

```math
\boxed{
\left(\frac{T_c^0}{T_c}\right)^{3/2}
=
1+
\frac{\mathcal F_{3/2}(\epsilon_1/(kT_c))}
{\zeta(3/2)}
}
\tag{7}
```

となる．
したがって，凝縮温度は次の陰関係を満たす．

```math
\boxed{
T_c=T_c^0
\left[
1+
\frac{\mathcal F_{3/2}(\epsilon_1/(kT_c))}
{\zeta(3/2)}
\right]^{-2/3}
}
\tag{8}
```

ここで， $T_c$ は右辺の指数関数の引数にも含まれるため，一般には数値的に求める必要がある．

通常の凝縮温度 $T_c^0$ は，

```math
\boxed{
T_c^0=
\frac{h^2}{2\pi mk}
\left[
\frac{n}{\zeta(3/2)}
\right]^{2/3}
}
\tag{9}
```

である．

### 3．内部励起エネルギーが十分に大きい場合

次に，内部励起準位のエネルギーが熱エネルギーより十分に大きい場合，

```math
\epsilon_1\gg kT_c
```

を考える．
このとき，級数 $\mathcal F_{3/2}$ は第1項が支配的となり，

```math
\mathcal F_{3/2}\left(\frac{\epsilon_1}{kT_c}\right)
\simeq e^{-\epsilon_1/(kT_c)}
```

と近似できる．
したがって，式(8)は，

```math
T_c\simeq T_c^0
\left[
1+\frac{1}{\zeta(3/2)}
e^{-\epsilon_1/(kT_c)}
\right]^{-2/3}
\tag{10}
```

となる．
さらに，

```math
(1+x)^{-2/3}\simeq1-\frac23x
\qquad(|x|\ll1)
```

を用いると，

```math
T_c\simeq T_c^0
\left[
1-\frac{2}{3\zeta(3/2)}
e^{-\epsilon_1/(kT_c)}
\right]
\tag{11}
```

である．

指数関数の中にある $T_c$ を $T_c^0$ で置き換えても，この一次近似の精度では同じ結果となる．
したがって，

```math
T_c\simeq T_c^0
\left[
1-\frac{2}{3\zeta(3/2)}
e^{-\epsilon_1/(kT_c^0)}
\right]
```

を得る．
ここで $\zeta(3/2)\simeq2.612$ なので，

```math
\boxed{
T_c\simeq T_c^0
\left[
1-0.255e^{-\epsilon_1/(kT_c^0)}
\right]
}
\tag{12}
```

となる．
これは $\epsilon_1\gg kT_c^0$ の場合の近似式である．

### 4．結果の物理的意味

内部励起準位があると，その準位を占有する粒子も励起状態の粒子数に加わる．
そのため，凝縮温度では，内部励起準位が存在しない場合よりも多くの粒子を非凝縮状態に収容できる．
同じ全粒子密度に達するには温度を下げる必要があり，有限の $\epsilon_1$ では $T_c<T_c^0$ となる．

特に， $\epsilon_1\to\infty$ では内部励起準位の占有が抑えられ，

```math
\mathcal F_{3/2}\left(\frac{\epsilon_1}{kT_c}\right)\to0
```

となるため，

```math
T_c\to T_c^0
```

である．
一方， $\epsilon_1\to0$ では二つの内部準位が縮退し，式(5)の括弧内は $2\zeta(3/2)$ となる．
したがって，

```math
\boxed{
T_c\to\frac{T_c^0}{2^{2/3}}
\qquad(\epsilon_1\to0)
}
```

である．
これは，内部準位が二重に縮退すると，励起状態に収容できる粒子数が増加し，凝縮温度が低下することを示している．

### 結論

内部準位が $0$ と $\epsilon_1$ の二つである理想 Bose 気体の凝縮温度は，

```math
\boxed{
\left(\frac{T_c^0}{T_c}\right)^{3/2}
=
1+
\frac{\mathcal F_{3/2}(\epsilon_1/(kT_c))}
{\zeta(3/2)}
}
```

によって決定される．
ここで，

```math
\mathcal F_{3/2}(x)
=\sum_{l=1}^{\infty}\frac{e^{-lx}}{l^{3/2}},
\qquad
T_c^0=
\frac{h^2}{2\pi mk}
\left[\frac{N/V}{\zeta(3/2)}\right]^{2/3}
```

である．
一般の $\epsilon_1$ ではこの式を数値的に解く．
また， $\epsilon_1\gg kT_c^0$ では，

```math
\boxed{
T_c\simeq T_c^0
\left[
1-0.255e^{-\epsilon_1/(kT_c^0)}
\right]
}
```

となり，内部励起準位による凝縮温度の低下が指数関数的に小さくなる．
