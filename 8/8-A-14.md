# 演習問題【8-A-14】

## 解答

光子気体の Helmholtz 自由エネルギー $F$ ，エントロピー $S$ ，内部エネルギー $U$ ，および輻射圧 $p$ を求める．
光子のエネルギーが

```math
E(\boldsymbol q)=\hbar cq
```

で与えられることを利用し，大分配関数から順に導出する．
ここで， $q=|\boldsymbol q|$ ， $\hbar$ は換算プランク定数， $c$ は光速， $V$ は気体の体積， $T$ は絶対温度， $k$ はボルツマン定数である．

### 1．光子の化学ポテンシャルと大分配関数

熱平衡にある光子気体では，光子は生成・消滅することができ，光子数は保存量ではない．
したがって，光子の化学ポテンシャルは

```math
\mu=0
```

である．

グランドポテンシャル $\Omega$ と Helmholtz 自由エネルギー $F$ の関係は

```math
\Omega=F-\mu N
```

である．
ここで， $N$ は光子の平均粒子数である．
また，グランドポテンシャルは大分配関数 $\Xi$ を用いて

```math
\Omega=-kT\log\Xi
```

と表される．
一方，一様な系では $\Omega=-pV$ であるから，

```math
pV=kT\log\Xi
\tag{1}
```

となる．
さらに， $\mu=0$ であることから，

```math
\boxed{F=-pV}
\tag{2}
```

が得られる．
したがって，まず式(1)から $pV$ を計算すれば，Helmholtz 自由エネルギーも求められる．

光子はボース粒子であるため，各モードには光子が $0,1,2,\ldots$ 個存在できる．
エネルギーが $\epsilon_i$ である一つのモードについて，大分配関数は

```math
\Xi_i=\sum_{n=0}^{\infty}
e^{-n\epsilon_i/(kT)}
```

である．
これは等比級数であるから，

```math
\Xi_i=\frac{1}{1-e^{-\epsilon_i/(kT)}}
```

となる．
各モードは独立に占有されるので，全モードの大分配関数は各モードの大分配関数の積である．
したがって，

```math
\Xi=\prod_i\frac{1}{1-e^{-\epsilon_i/(kT)}}
```

となり，両辺の対数を取ると，

```math
\log\Xi
=-\sum_i\log\left(1-e^{-\epsilon_i/(kT)}\right)
\tag{3}
```

が得られる．

### 2．大分配関数から輻射圧を求める

光子のエネルギーは問題の条件から

```math
\epsilon_i=\hbar cq
```

である．
式(3)を式(1)に代入すると，

```math
pV=-kT\sum_i
\log\left(1-e^{-\hbar cq/(kT)}\right)
\tag{4}
```

となる．

次に，波数ベクトルの離散的な状態の和を，波数空間の積分に置き換える．
体積 $V$ の系では，波数空間の単位体積当たりの状態数は $V/(2\pi)^3$ である．
また，光子には二つの独立な偏光状態が存在するため，状態数には重率 $2$ を掛ける必要がある．
よって，

```math
\sum_i\longrightarrow
2\frac{V}{(2\pi)^3}\int d^3q
```

と置き換えられる．

被積分関数は $q=|\boldsymbol q|$ のみに依存するので，球座標を用いると

```math
d^3q=4\pi q^2\,dq
```

である．
したがって，式(4)は

```math
\begin{aligned}
pV
&=-kT\frac{2V}{(2\pi)^3}
\int_0^\infty
4\pi q^2
\log\left(1-e^{-\hbar cq/(kT)}\right)dq\\[4pt]
&=-\frac{VkT}{\pi^2}
\int_0^\infty
q^2\log\left(1-e^{-\hbar cq/(kT)}\right)dq
\end{aligned}
\tag{5}
```

となる．

ここで，無次元変数

```math
x=\frac{\hbar cq}{kT}
```

を導入する．
すると，

```math
q=\frac{kT}{\hbar c}x,\qquad
dq=\frac{kT}{\hbar c}dx
```

であるため，

```math
q^2dq=\left(\frac{kT}{\hbar c}\right)^3x^2dx
```

となる．
これを式(5)に代入すると，

```math
pV=-\frac{V(kT)^4}{\pi^2(\hbar c)^3}
\int_0^\infty x^2\log(1-e^{-x})\,dx
\tag{6}
```

を得る．

### 3．積分の計算

式(6)に現れる積分を

```math
I=\int_0^\infty x^2\log(1-e^{-x})\,dx
```

とおく．
部分積分を行うため，

```math
u=\log(1-e^{-x}),\qquad
dv=x^2dx
```

とおけば，

```math
du=\frac{1}{e^x-1}\,dx,\qquad
v=\frac{x^3}{3}
```

である．
したがって，

```math
I=
\left[\frac{x^3}{3}\log(1-e^{-x})\right]_0^\infty
-\frac13\int_0^\infty\frac{x^3}{e^x-1}\,dx
\tag{7}
```

となる．

境界項はゼロである．
実際， $x\to\infty$ では $\log(1-e^{-x})\to0$ である．
また， $x\to0^+$ では $1-e^{-x}\sim x$ なので， $\log(1-e^{-x})\sim\log x$ となるが， $x^3\log x\to0$ である．
したがって，

```math
I=-\frac13\int_0^\infty\frac{x^3}{e^x-1}\,dx
\tag{8}
```

である．

ここで，積分の値を求めるために，

```math
\frac{1}{e^x-1}
=\frac{e^{-x}}{1-e^{-x}}
=\sum_{n=1}^{\infty}e^{-nx}
```

という等比級数の展開を用いる．
よって，

```math
\begin{aligned}
\int_0^\infty\frac{x^3}{e^x-1}\,dx
&=\sum_{n=1}^{\infty}
\int_0^\infty x^3e^{-nx}\,dx
\end{aligned}
```

となる．
変数変換 $y=nx$ を行うと，

```math
\int_0^\infty x^3e^{-nx}\,dx
=\frac{1}{n^4}\int_0^\infty y^3e^{-y}\,dy
```

である．
ガンマ積分

```math
\int_0^\infty y^3e^{-y}\,dy=3!=6
```

を用いれば，

```math
\int_0^\infty\frac{x^3}{e^x-1}\,dx
=6\sum_{n=1}^{\infty}\frac{1}{n^4}
```

となる．
ここで，リーマンゼータ関数の値

```math
\sum_{n=1}^{\infty}\frac{1}{n^4}
=\frac{\pi^4}{90}
```

を用いると，

```math
\boxed{
\int_0^\infty\frac{x^3}{e^x-1}\,dx
=\frac{\pi^4}{15}
}
\tag{9}
```

が得られる．

式(8)，(9)より，

```math
I=-\frac{\pi^4}{45}
```

である．
これを式(6)に代入すると，

```math
pV
=\frac{V(kT)^4}{\pi^2(\hbar c)^3}
\frac{\pi^4}{45}
```

したがって，

```math
\boxed{
pV=\frac{\pi^2(kT)^4}{45(\hbar c)^3}V
}
\tag{10}
```

となる．

Stefan-Boltzmann 定数を

```math
\sigma=\frac{\pi^2k^4}{60\hbar^3c^2}
```

と定義すれば，式(10)は

```math
\boxed{pV=\frac{4\sigma}{3c}VT^4}
\tag{11}
```

と表せる．
よって，輻射圧は

```math
\boxed{p=\frac{4\sigma}{3c}T^4}
\tag{12}
```

である．

また，式(2)から Helmholtz 自由エネルギーは

```math
\boxed{
F=-\frac{4\sigma}{3c}VT^4
}
\tag{13}
```

となる．

### 4．エントロピーの計算

Helmholtz 自由エネルギーとエントロピーの関係は，

```math
S=-\left(\frac{\partial F}{\partial T}\right)_V
```

である．
これは，体積を一定に保ったまま温度を変化させたときの自由エネルギーの温度依存性からエントロピーが求められることを意味する．

式(13)を温度 $T$ について微分すると，

```math
\begin{aligned}
S
&=-\frac{\partial}{\partial T}
\left(-\frac{4\sigma}{3c}VT^4\right)\\[4pt]
&=\frac{16\sigma}{3c}VT^3
\end{aligned}
```

となる．
したがって，

```math
\boxed{
S=\frac{16\sigma}{3c}VT^3
}
\tag{14}
```

である．

### 5．内部エネルギーの計算

Helmholtz 自由エネルギーの定義

```math
F=U-TS
```

を変形すると，

```math
U=F+TS
```

が得られる．
式(13)，(14)を代入すれば，

```math
\begin{aligned}
U
&=-\frac{4\sigma}{3c}VT^4
+T\frac{16\sigma}{3c}VT^3\\[4pt]
&=\frac{12\sigma}{3c}VT^4\\[4pt]
&=\frac{4\sigma}{c}VT^4
\end{aligned}
```

となる．
よって，

```math
\boxed{
U=\frac{4\sigma}{c}VT^4
}
\tag{15}
```

である．

さらに，式(11)と比較すると，

```math
\boxed{U=3pV}
\tag{16}
```

という関係が得られる．
すなわち，光子気体の内部エネルギーは輻射圧と体積の積の3倍である．

### 結論

光子のエネルギースペクトル $E(\boldsymbol q)=\hbar cq$ と，光子の化学ポテンシャルが $\mu=0$ であることを利用すると，光子気体の熱力学量は次のように求められる．

```math
\boxed{
F=-\frac{4\sigma}{3c}VT^4
}
```

```math
\boxed{
S=\frac{16\sigma}{3c}VT^3
}
```

```math
\boxed{
U=\frac{4\sigma}{c}VT^4
}
```

```math
\boxed{
p=\frac{4\sigma}{3c}T^4
}
```

ただし，

```math
\boxed{
\sigma=\frac{\pi^2k^4}{60\hbar^3c^2}
}
```

は Stefan-Boltzmann 定数である．
これらの結果は，光子気体の内部エネルギーが $T^4$ に比例すること，および $U=3pV$ が成り立つことを示している．
