# 演習問題【8-A-14】

## 解答

光子気体において，光子の数は一定ではなく，エネルギーが与えられると自由に変に生成・消滅することができる．
そのため，光子の化学ポテンシャル $\mu$ は $0$ である．
したがって，ヘルムホルツ自由エネルギー $F$ は，粒子数 $N$ を用いた $F = N\mu - pV$ の式において $\mu = 0$ となり， $F = -pV$ と書ける．
ここで $p$ は輻射圧， $V$ は気体の体積である．

まず，大分配関数 $\Xi$ を用いて， $pV$ を求める．
統計力学の定式化によれば，グランドカノニカル分布における熱力学ポテンシャル（この場合は $pV$ ）は次のように与えられる：

$$pV = kT \log \Xi$$

光子一粒子あたりの状態を考慮すると，大分配関数は次のような形になる：

$$\log \Xi = -\sum_{i} \log \{1 - e^{-\epsilon_i / kT}\}$$

ここで $\epsilon_i$ は状態 $i$ のエネルギーである．
光子のエネルギーは波数ベクトル $\boldsymbol{q}$ を用いて $\epsilon(\boldsymbol{q}) = \hbar c q$ （ただし $q = |\boldsymbol{q}|$ ）と表される．

状態の和 $\sum_i$ を，波数空間における積分 $\int d^3q$ に置き換える．
波数空間の体積要素は $d^3q = 4\pi q^2 dq$ であり，光子には二つの偏り（偏光）があるため，重みとして $2$ を加味する必要がある．
また，状態密度の正規化定数として $\frac{V}{(2\pi)^3}$ を用いると，

$$pV = -kT \frac{2V}{(2\pi)^3} \int_0^\infty \log \{1 - e^{-\hbar cq / kT}\} 4\pi q^2 dq$$

となる．
これを整理すると，

$$pV = -\frac{V}{\pi^2} kT \int_0^\infty q^2 \log \{1 - e^{-\hbar cq / kT}\} dq$$

である．
ここで，変数変換 $x = \frac{\hbar cq}{kT}$ を行う．
これより， $q = \frac{kT}{\hbar c} x$ であり， $dq = \frac{kT}{\hbar c} dx$ となる．
これを代入すると，

$$pV = -\frac{V (kT)^4}{\pi^2 (\hbar c)^3} \int_0^\infty x^2 \log (1 - e^{-x}) dx$$

となる．
積分部分に対して部分積分法を適用する．
$u = \log(1 - e^{-x})$ ， $dv = x^2 dx$ とおくと， $du = \frac{e^{-x}}{1 - e^{-x}} dx = \frac{1}{e^x - 1} dx$ ， $v = \frac{x^3}{3}$ である．

$$\int_0^\infty x^2 \log (1 - e^{-x}) dx = \left[ \frac{x^3}{3} \log (1 - e^{-x}) \right]_0^\infty - \int_0^\infty \frac{x^3}{3} \frac{1}{e^x - 1} dx$$

第一項は $x \to \infty$ で $\log(1) = 0$ ， $x \to 0$ でも $\log(x)$ のオーダーで $x^3$ が支配するため $0$ に収束する．
したがって，

$$\int_0^\infty x^2 \log (1 - e^{-x}) dx = -\frac{1}{3} \int_0^\infty \frac{x^3}{e^x - 1} dx$$

となる．
この積分はよく知られた値で， $\int_0^\infty \frac{x^3}{e^x - 1} dx = \frac{\pi^4}{15}$ である．
よって，

$$pV = -\frac{V (kT)^4}{\pi^2 (\hbar c)^3} \left( -\frac{1}{3} \cdot \frac{\pi^4}{15} \right) = \frac{\pi^2 (kT)^4 V}{45 (\hbar c)^3}$$

を得る．
ここで，ステファン・ボルツマン定数 $\sigma = \frac{\pi^2 k^4}{60 \hbar^3 c^2}$ を用いると，

$$\frac{\pi^2 k^4 T^4 V}{45 \hbar^3 c^3} = \frac{60 \sigma c^2 T^4 V}{45 \hbar^3 c^3} = \frac{4\sigma}{3c} VT^4$$

となる．
Since $F = -pV$ ， $F = -\frac{4\sigma}{3c} VT^4$ である．

次に，エントロピー $S$ を求める．
熱力学の基本関係式より，

$$S = -\left( \frac{\partial F}{\partial T} \right)_V = -\left( -\frac{4\sigma}{3c} V \cdot 4T^3 \right) = \frac{16\sigma}{3c} VT^3$$

である．

最後に，内部エネルギー $U$ を求める．
熱力学の第一法則に関連する関係式 $U = F + TS$ を用いると，

$$U = -\frac{4\sigma}{3c} VT^4 + \frac{16\sigma}{3c} VT^4 = \frac{12\sigma}{3c} VT^4 = \frac{4\sigma}{c} VT^4$$

となる．
また，これは $pV$ を用いて次のように書ける：

$$U = 3 \left( \frac{4\sigma}{3c} VT^4 \right) = 3pV$$

以上より，求める値は以下の通りである：
- Helmholtz 自由エネルギー： $F = -\frac{4\sigma}{3c} VT^4$
- エントロピー： $S = \frac{16\sigma}{3c} VT^3$
- 内部エネルギー： $U = \frac{4\sigma}{c} VT^4$
- 輻射圧： $p = \frac{4\sigma}{3c} T^4$

## 解説

この問題は，光子という「粒子数が一定ではない粒子」の統計力学的な振る舞いを扱うものである．
重要なポイントは以下の3点である：

### 1. 化学ポテンシャル $\mu = 0$

光子はエネルギーさえ与えればいくらでも生成できるため，粒子数を固定する必要がない．
このため，グランドカノニカル分布を用いるのが自然であり， $\mu = 0$ となる．

### 2. 状態和から積分への変換

微視的な状態の和を，連続的な波数空間の積分として扱う．
このとき，光子の偏光（二つの独立な振幅の方向）を考慮して，積分に $2$ をかけることを忘れてはならない．

### 3. ステファン・ボルツマンの法則

最終的に得られた輻射圧 $p \propto T^4$ や内部エネルギー $U \propto T^4$ は，古典的な熱放射の理論と整合している．

### まとめ

以上のように，統計力学の基本的な手法を用いることで，光子気体の熱力学的な諸量を導出することができる．
