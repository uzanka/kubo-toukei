# 演習問題【8-B-22】

## 解答

理想 Bose 気体の内部エネルギーを求め，その結果を用いて状態方程式，エントロピー，Helmholtz 自由エネルギーを導く．
解答例と同様に，エネルギー準位の和を積分に置き換え，Bose–Einstein 分布を級数展開する方法を用いる．

以下では，粒子の内部自由度による縮重度を別途掛けない場合を考える．

### 1．状態密度と内部エネルギーの積分表示

粒子の質量を $m$ ，系の体積を $V$ ，温度を $T$ ，化学ポテンシャルを $\mu$ とする．
また，ボルツマン定数を $k$ ，プランク定数を $h$ とし，

```math
\beta=\frac{1}{kT}
```

と定義する．

非相対論的な自由粒子のエネルギーは，

```math
\epsilon=\frac{p^2}{2m}
```

である．
ここで $p$ は運動量の大きさである．

運動量空間において，体積 $d^3p$ に含まれる量子状態の数は $Vd^3p/h^3$ である．
運動量の大きさだけに着目し，球座標を用いると，

```math
d^3p=4\pi p^2\,dp
```

となる．
一方，

```math
p=\sqrt{2m\epsilon},
\qquad
dp=\frac{m}{p}\,d\epsilon
```

であるから，

```math
p^2dp=m\sqrt{2m\epsilon}\,d\epsilon
```

となる．
したがって，エネルギーが $\epsilon$ から $\epsilon+d\epsilon$ の範囲にある状態数は，

```math
g(\epsilon)\,d\epsilon
=\frac{4\pi Vm\sqrt{2m\epsilon}}{h^3}\,d\epsilon
```

である．
これを整理すると，状態密度は，

```math
\boxed{
g(\epsilon)=
2\pi V\left(\frac{2m}{h^2}\right)^{3/2}
\epsilon^{1/2}
}
\tag{1}
```

となる．
ここで，状態密度に内部自由度の縮重度を別途掛けていないことに注意する．

Bose–Einstein 統計によれば，エネルギー $\epsilon$ の状態における平均占有数は，

```math
\overline n(\epsilon)
=\frac{1}{e^{\beta(\epsilon-\mu)}-1}
```

である．
したがって，内部エネルギー $E$ は，各状態のエネルギーと平均占有数の積をすべての状態について足し合わせたものとなる．
連続的なエネルギー表示では，

```math
E=\int_0^\infty
\epsilon\,g(\epsilon)\,\overline n(\epsilon)\,d\epsilon
```

である．
式(1)を代入すると，

```math
\boxed{
E=
2\pi V\left(\frac{2m}{h^2}\right)^{3/2}
\int_0^\infty
\frac{\epsilon^{3/2}}
{e^{\beta(\epsilon-\mu)}-1}\,d\epsilon
}
\tag{2}
```

を得る．

### 2．縮退が弱い場合の内部エネルギー

縮退が弱い場合には，化学ポテンシャルは $\mu<0$ である．
ここで，

```math
z=e^{\beta\mu}
=e^{\mu/(kT)}
```

とおく．
$z$ はフガシティと呼ばれる無次元量であり， $\mu<0$ ならば $0<z<1$ となる．
縮退が弱い場合には，さらに $z\ll1$ である．

このとき，Bose–Einstein 分布は等比級数を用いて，

```math
\begin{aligned}
\frac{1}{e^{\beta(\epsilon-\mu)}-1}
&=\frac{ze^{-\beta\epsilon}}
{1-ze^{-\beta\epsilon}}\\
&=\sum_{l=1}^{\infty}
z^l e^{-l\beta\epsilon}\\
&=\sum_{l=1}^{\infty}
e^{l\beta(\mu-\epsilon)}
\end{aligned}
\tag{3}
```

と展開できる．
この級数は $0<z<1$ で収束し，縮退が弱い場合には低次の項が特に重要となる．

式(3)を式(2)に代入すれば，

```math
\begin{aligned}
E={}&2\pi V\left(\frac{2m}{h^2}\right)^{3/2}\\
&\times
\sum_{l=1}^{\infty}
e^{l\beta\mu}
\int_0^\infty
\epsilon^{3/2}e^{-l\beta\epsilon}\,d\epsilon
\end{aligned}
\tag{4}
```

となる．

次に，積分を計算するため，

```math
x=l\beta\epsilon
```

と変数変換する．
すると，

```math
\epsilon=\frac{x}{l\beta},
\qquad
d\epsilon=\frac{dx}{l\beta}
```

であるから，

```math
\begin{aligned}
\int_0^\infty
\epsilon^{3/2}e^{-l\beta\epsilon}\,d\epsilon
&=\frac{1}{(l\beta)^{5/2}}
\int_0^\infty x^{3/2}e^{-x}\,dx
\end{aligned}
\tag{5}
```

となる．

ここで，ガンマ関数の定義

```math
\Gamma(s)=\int_0^\infty x^{s-1}e^{-x}\,dx
```

を用いる．
特に，

```math
\Gamma\left(\frac52\right)
=\frac32\Gamma\left(\frac32\right)
=\frac{3\sqrt{\pi}}4
```

であるため，

```math
\int_0^\infty x^{3/2}e^{-x}\,dx
=\frac{3\sqrt{\pi}}4
```

となる．
これを式(4)，(5)に代入すると，

```math
E=
2\pi V\left(\frac{2m}{h^2}\right)^{3/2}
(kT)^{5/2}\frac{3\sqrt{\pi}}4
\sum_{l=1}^{\infty}
\frac{e^{l\mu/(kT)}}{l^{5/2}}
```

を得る．
係数を整理すれば，

```math
\boxed{
E=
\frac32 kTV
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\sum_{l=1}^{\infty}
\frac{e^{l\mu/(kT)}}{l^{5/2}}
}
\tag{6}
```

となる．
これで問題文の式が示された．

以下では，この結果を用いて状態方程式，エントロピー，Helmholtz 自由エネルギーを求める．

### 3．粒子数の展開式

ほかの熱力学量を求めるため，粒子数 $N$ も同様に計算する．
粒子数は各状態の平均占有数の総和であるため，

```math
N=\int_0^\infty
g(\epsilon)\,\overline n(\epsilon)\,d\epsilon
```

となる．
式(1)，(3)を用いると，

```math
\begin{aligned}
N={}&2\pi V\left(\frac{2m}{h^2}\right)^{3/2}\\
&\times
\sum_{l=1}^{\infty}e^{l\beta\mu}
\int_0^\infty\epsilon^{1/2}
e^{-l\beta\epsilon}\,d\epsilon
\end{aligned}
```

を得る．
先ほどと同様に積分すると，

```math
\int_0^\infty\epsilon^{1/2}
e^{-l\beta\epsilon}\,d\epsilon
=\frac{\Gamma(3/2)}{(l\beta)^{3/2}},
\qquad
\Gamma\left(\frac32\right)=\frac{\sqrt{\pi}}2
```

である．
したがって，

```math
\boxed{
N=V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\sum_{l=1}^{\infty}
\frac{e^{l\mu/(kT)}}{l^{3/2}}
}
\tag{7}
```

となる．

計算を簡潔にするため，

```math
Q(T)=V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
```

と定義する．
さらに， $z=e^{\mu/(kT)}$ を用いると，式(6)，(7)は，

```math
\boxed{
E=\frac32 kTQ(T)
\sum_{l=1}^{\infty}\frac{z^l}{l^{5/2}}
}
\tag{8}
```

および

```math
\boxed{
N=Q(T)\sum_{l=1}^{\infty}\frac{z^l}{l^{3/2}}
}
\tag{9}
```

と書ける．

### 4．状態方程式

非相対論的な自由粒子からなる理想気体では，圧力 $p$ と内部エネルギー $E$ の間に，

```math
pV=\frac23E
\tag{10}
```

という関係が成り立つ．
これは，運動量 $\boldsymbol p$ と速度 $\boldsymbol v$ の関係が $\boldsymbol v=\boldsymbol p/m$ であることから，圧力が運動エネルギーの体積密度の $2/3$ 倍になるためである．
この関係は Bose–Einstein 分布に従う理想気体にも成立する．

式(6)を式(10)に代入すると，

```math
\begin{aligned}
pV
&=\frac23
\left[
\frac32 kTV
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\sum_{l=1}^{\infty}
\frac{e^{l\mu/(kT)}}{l^{5/2}}
\right]
\end{aligned}
```

であるから，

```math
\boxed{
pV=kTV\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\sum_{l=1}^{\infty}
\frac{e^{l\mu/(kT)}}{l^{5/2}}
}
\tag{11}
```

を得る．
これが求める状態方程式の展開形である．

また，式(7)と式(11)を比較すると，粒子数 $N$ を用いた状態方程式は，

```math
\boxed{
\frac{pV}{NkT}
=
\frac{\displaystyle\sum_{l=1}^{\infty}
z^l/l^{5/2}}
{\displaystyle\sum_{l=1}^{\infty}
z^l/l^{3/2}}
}
\tag{12}
```

となる．

縮退が弱く $z\ll1$ の場合には，最初の2項までを残すと，

```math
N\simeq Q(T)
\left(z+\frac{z^2}{2^{3/2}}\right)
```

および

```math
pV\simeq kTQ(T)
\left(z+\frac{z^2}{2^{5/2}}\right)
```

となる．
したがって，

```math
\boxed{
pV\simeq NkT\left(1-\frac{z}{2^{5/2}}+\cdots\right)
}
\tag{13}
```

である．
最も低次の近似では $pV\simeq NkT$ となり，古典的な理想気体の状態方程式に一致する．
次の項は Bose 統計による量子補正を表す．

### 5．Helmholtz 自由エネルギー

Helmholtz 自由エネルギーを $F$ とする．
大分配関数 $\Xi$ とグランドポテンシャル $\Omega$ の関係は，

```math
\Omega=-kT\ln\Xi
```

であり，一様な系では $\Omega=-pV$ である．
また，

```math
\Omega=F-\mu N
```

であるから，

```math
F=\mu N-pV
\tag{14}
```

を得る．

式(7)，(11)を式(14)に代入すると，

```math
\begin{aligned}
F={}&\mu V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\sum_{l=1}^{\infty}
\frac{z^l}{l^{3/2}}\\
&-kTV\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\sum_{l=1}^{\infty}
\frac{z^l}{l^{5/2}}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
F=kTV\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\left[
\frac{\mu}{kT}
\sum_{l=1}^{\infty}\frac{z^l}{l^{3/2}}
-\sum_{l=1}^{\infty}\frac{z^l}{l^{5/2}}
\right]
}
\tag{15}
```

が得られる．
ここで， $\mu/(kT)=\ln z$ であるから，この式はフガシティ $z$ だけを用いて表すこともできる．

### 6．エントロピー

内部エネルギー，Helmholtz 自由エネルギー，エントロピー $S$ の関係は，

```math
F=E-TS
```

である．
したがって，

```math
S=\frac{E-F}{T}
```

となる．
式(14)を用いると，

```math
S=\frac{E-\mu N+pV}{T}
```

である．
さらに，式(10)の $pV=2E/3$ を代入すれば，

```math
\boxed{
S=\frac{1}{T}\left(\frac53E-\mu N\right)
}
\tag{16}
```

となる．

式(6)，(7)を代入して整理すると，

```math
\boxed{
\begin{aligned}
S={}&kV\left(\frac{2\pi mkT}{h^2}\right)^{3/2}\\
&\times\left[
\frac52\sum_{l=1}^{\infty}
\frac{z^l}{l^{5/2}}
-\frac{\mu}{kT}
\sum_{l=1}^{\infty}\frac{z^l}{l^{3/2}}
\right]
\end{aligned}
}
\tag{17}
```

を得る．
これがエントロピーの展開式である．

### 結論

縮退が弱い理想 Bose 気体について，内部エネルギー，状態方程式，Helmholtz 自由エネルギー，エントロピーは次のように求められる．
ここで $z=e^{\mu/(kT)}$ である．

```math
\boxed{
E=\frac32 kTV\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\sum_{l=1}^{\infty}\frac{z^l}{l^{5/2}}
}
```

```math
\boxed{
pV=kTV\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\sum_{l=1}^{\infty}\frac{z^l}{l^{5/2}}
}
```

```math
\boxed{
F=\mu N-pV
}
```

```math
\boxed{
S=\frac{1}{T}\left(\frac53E-\mu N\right)
}
```

ここで， $F$ と $S$ の級数表示は式(15)，(17)で与えられる．
また，粒子数は式(7)により，

```math
N=V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\sum_{l=1}^{\infty}\frac{z^l}{l^{3/2}}
```

である．
縮退が弱いときには $z\ll1$ であり，級数の第1項が古典的な理想気体の結果を与え，第2項以降が Bose 統計による量子補正を与える．
