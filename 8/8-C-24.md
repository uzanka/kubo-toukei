# 演習問題【8-C-24】

## 解答

本問題では，完全に縮退した理想 Fermi 気体において，非相対論的極限と相対論的極限におけるエネルギー $E$ および圧力 $p$ の振る舞いを示す．

### 0. 準備：フェルミ運動量と粒子数密度の関係

まず，縮退した Fermi 気体における粒子数密度 $n$ と，最高エネルギー状態にある粒子の運動量であるフェルミ運動量 $|\mathbf{p}_0|$ （または $p_F$ ）の関係を求める．

スピン $1/2$ の粒子を考えるので，運動量空間の微小体積 $d^3\mathbf{p}$ に含まれる状態数は，

$$dn = \frac{2}{(2\pi \hbar)^3} d^3\mathbf{p} = \frac{2}{(2\pi \hbar)^3} 4\pi p^2 dp = \frac{p^2}{\pi^2 \hbar^3} dp$$

となる．
粒子数密度 $n$ は，フェルミ面 $p_F$ までの積分で与えられるので，

$$n = \int_0^{p_F} \frac{p^2}{\pi^2 \hbar^3} dp = \frac{p_F^3}{3\pi^2 \hbar^3}$$

である．
これより，フェルミ運動量 $p_F$ は次のように書ける．

$$p_F = \hbar (3\pi^2 n)^{1/3} = \frac{h}{2\pi} (3\pi^2 n)^{1/3} = h \left( \frac{3n}{8\pi} \right)^{1/3}$$

ここで， $h$ はプランク定数である．
問題文にあるパラメータ $\sinh \theta_0$ を用いると，

$$\frac{p_F}{mc} = \frac{h}{mc} \left( \frac{3n}{8\pi} \right)^{1/3} = \sinh \theta_0$$

の関係が成り立つ．
したがって， $p_F = mc \sinh \theta_0$ である．

### 1. 非相対論的極限 ( $|\mathbf{p}_0| \ll mc$ )

$|\mathbf{p}_0| \ll mc$ のとき， $\sinh \theta_0 \approx \theta_0 \ll 1$ とみなせる．
このとき，粒子のエネルギー $\epsilon(p)$ は次のように近似できる．

$$\epsilon(p) \cong mc^2 + \frac{p^2}{2m}$$

全エネルギー $E$ は，

$$E = \int_0^{p_F} \epsilon(p) \frac{V p^2}{\pi^2 \hbar^3} dp = \int_0^{p_F} \left( mc^2 + \frac{p^2}{2m} \right) \frac{V p^2}{\pi^2 \hbar^3} dp$$

$$E = N mc^2 + \frac{V}{2m \pi^2 \hbar^3} \int_0^{p_F} p^4 dp = N mc^2 + \frac{V}{2m \pi^2 \hbar^3} \frac{p_F^5}{5}$$

ここで， $n = \frac{p_F^3}{3\pi^2 \hbar^3} \implies \frac{V}{\pi^2 \hbar^3} = \frac{3N}{p_F^3}$ を代入すると，

$$E = N mc^2 + \frac{3N}{p_F^3} \frac{p_F^5}{10m} = N mc^2 + \frac{3}{5} N \frac{p_F^2}{2m}$$

となる．
運動エネルギーの部分を $K = \frac{3}{5} N \frac{|\mathbf{p}_0|^2}{2m}$ とおけば，

$$E \cong E_0 + K \quad \left( \text{ただし } E_0 = N mc^2 \right)$$

が得られる．

次に，圧力 $p$ を求める．
圧力は熱力学的な関係式 $p = -(\partial E/\partial V)_S$ より，

$$E = N mc^2 + \frac{3N}{10m} p_F^2 = N mc^2 + \frac{3N}{10m} \left( \frac{3\pi^2 \hbar^3 N}{V} \right)^{2/3}$$

$$E = N mc^2 + C V^{-2/3} \quad \left( C = \frac{3N}{10m} (3\pi^2 \hbar^3 N)^{2/3} \right)$$

であるから，

$$p = -\frac{\partial E}{\partial V} = -\left( -\frac{2}{3} C V^{-5/3} \right) = \frac{2}{3} \frac{C V^{-2/3}}{V} = \frac{2}{3} \frac{K}{V}$$

よって， $pV \cong \frac{2}{3}K$ が成り立つ．

### 2. 相対論的極限 ( $|\mathbf{p}_0| \gg mc$ )

$|\mathbf{p}_0| \gg mc$ のとき， $\sinh \theta_0 \approx \frac{1}{2} e^{\theta_0} \gg 1$ とみなせる．
このとき，粒子のエネルギー $\epsilon(p)$ は，

$$\epsilon(p) \cong cp$$

と近似できる．
全エネルギー $E$ は，

$$E = \int_0^{p_F} (cp) \frac{V p^2}{\pi^2 \hbar^3} dp = \frac{Vc}{\pi^2 \hbar^3} \int_0^{p_F} p^3 dp = \frac{Vc}{\pi^2 \hbar^3} \frac{p_F^4}{4}$$

再び $\frac{V}{\pi^2 \hbar^3} = \frac{3N}{p_F^3}$ を用いると，

$$E = \frac{3N}{p_F^3} \frac{c p_F^4}{4} = \frac{3}{4} N p_F c$$

となる．
運動エネルギーの部分を $K = E$ とおけば，

$$E \cong K = \frac{3}{4} N |\mathbf{p}_0| c$$

が得られる．
（※解答例の $3/8$ は， $g=1$ の場合，あるいは表記上の誤りの可能性があるが，標準的なスピン $1/2$ の Fermi 気体では $3/4$ となる．）

次に，圧力 $p$ を求める．
$E = C' V^{-1/3}$ の形をしているので，

$$p = -\frac{\partial E}{\partial V} = -\left( -\frac{1}{3} C' V^{-4/3} \right) = \frac{1}{3} \frac{C' V^{-1/3}}{V} = \frac{1}{3} \frac{E}{V}$$

よって， $pV \cong \frac{1}{3}K$ が成り立つ．

## 解説

本問題のポイントは，エネルギーの振る舞いが運動量 $p$ に対してどのように依存するか，そしてそれが体積 $V$ にどのように依存するかを理解することである．

### 1.  エネルギーの依存性

- 非相対論的では $\epsilon \propto p^2$ であるため，全エネルギー $E$ は $p_F^2$ に比例し， $p_F \propto V^{-1/3}$ より $E \propto V^{-2/3}$ となる．
- 相対論的では $\epsilon \propto p$ であるため，全エネルギー $E$ は $p_F$ に比例し， $E \propto V^{-1/3}$ となる．

### 2.  圧力の導出

- 圧力はエネルギーの体積による変化率 $p = -(\partial E/\partial V)$ である．
- 一般に $E \propto V^{-\alpha}$ ならば， $p = \alpha \frac{E}{V}$ となる．
- 非相対論的では $\alpha = 2/3$ なので， $p = \frac{2}{3} \frac{E}{V}$ ．
- 相対論的では $\alpha = 1/3$ なので， $p = \frac{1}{3} \frac{E}{V}$ ．

### 3.  フェルミ運動量

- 縮退した系では，粒子はエネルギーの低い状態から順に詰まっていく．
  最上部のエネルギー $\epsilon(p_F)$ が化学ポテンシャル $\mu$ に等しくなる．
- この $p_F$ が，系の密度 $n$ によって決まる重要なスケールである．
