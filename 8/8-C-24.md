# 演習問題【8-C-24】

## 解答

完全に縮退した理想 Fermi 気体では，絶対零度において，粒子は運動量の小さい状態から順に占有する．
このため，運動量空間では，運動量の大きさがフェルミ運動量 $p_F=|\mathbf p_0|$ 以下の状態がすべて占有され，それより大きな状態は空いている．

この性質を用いて，非相対論的極限と相対論的極限における内部エネルギーおよび圧力を求める．
なお，計算の結果，問題文の相対論的極限の係数 $3/8$ は $3/4$ に修正する必要がある．

### 1．フェルミ運動量と粒子数密度の関係

スピン $1/2$ の粒子には，スピンの向きが2通りある．
体積 $V$ の中で，運動量空間の微小体積 $d^3\mathbf p$ に含まれる状態数は，

```math
d\Gamma=\frac{2V}{h^3}\,d^3\mathbf p
```

である．
運動量の大きさを $p=|\mathbf p|$ として球座標を用いると，

```math
d^3\mathbf p=4\pi p^2\,dp
```

となるため，

```math
d\Gamma=\frac{8\pi V}{h^3}p^2\,dp
```

である．

絶対零度では， $p_F$ 以下のすべての状態が占有される．
したがって，粒子数 $N$ は，

```math
\begin{aligned}
N
&=\frac{8\pi V}{h^3}\int_0^{p_F}p^2\,dp\\
&=\frac{8\pi V}{3h^3}p_F^3
\end{aligned}
```

となる．
粒子数密度を $n=N/V$ とすれば，

```math
n=\frac{8\pi}{3h^3}p_F^3
```

である．
よって，

```math
\boxed{
p_F=h\left(\frac{3n}{8\pi}\right)^{1/3}
}
\tag{1}
```

が得られる．

ここで，無次元量

```math
q=\frac{p_F}{mc}
=\frac{h}{mc}\left(\frac{3n}{8\pi}\right)^{1/3}
\tag{2}
```

を導入する．
$q\ll1$ はフェルミ運動量が $mc$ より十分小さい非相対論的極限を表し， $q\gg1$ はフェルミ運動量が $mc$ より十分大きい相対論的極限を表す．

### 2．非相対論的極限： $p_F\ll mc$

電子の相対論的エネルギーは，

```math
\varepsilon(p)=\sqrt{p^2c^2+m^2c^4}
```

である．
$p\ll mc$ では平方根を展開すると，

```math
\begin{aligned}
\varepsilon(p)
&=mc^2\sqrt{1+\frac{p^2}{m^2c^2}}\\
&\simeq mc^2+\frac{p^2}{2m}
\end{aligned}
\tag{3}
```

となる．
すなわち，粒子のエネルギーは静止エネルギーと非相対論的な運動エネルギーの和で近似できる．

絶対零度では $p_F$ 以下の状態がすべて占有されるから，全エネルギーは，

```math
E=\frac{8\pi V}{h^3}\int_0^{p_F}
\varepsilon(p)p^2\,dp
```

である．
式(3)を代入すると，

```math
\begin{aligned}
E
&\simeq\frac{8\pi V}{h^3}
\int_0^{p_F}
\left(mc^2+\frac{p^2}{2m}\right)p^2\,dp\\
&=\frac{8\pi V}{h^3}
\left(
mc^2\frac{p_F^3}{3}
+\frac{p_F^5}{10m}
\right)
\end{aligned}
```

となる．
粒子数の関係

```math
N=\frac{8\pi V}{3h^3}p_F^3
```

を用いれば，

```math
E\simeq Nmc^2+\frac{8\pi V}{10mh^3}p_F^5
```

である．
第2項を $N$ で表すと，

```math
\frac{8\pi V}{10mh^3}p_F^5
=\frac{3}{10}N\frac{p_F^2}{m}
=\frac35N\frac{p_F^2}{2m}
```

となる．
したがって，

```math
\boxed{
E\simeq E_0+K
=N\left(mc^2+\frac35\frac{p_F^2}{2m}\right)
}
\tag{4}
```

を得る．
ここで $E_0=Nmc^2$ は全粒子の静止エネルギー， $K$ は全運動エネルギーである．

#### 圧力の導出

圧力は，粒子数とエントロピーを一定に保って体積を変化させたときのエネルギーの変化率である．
絶対零度ではエントロピーはゼロであるため，

```math
p=-\left(\frac{\partial E}{\partial V}\right)_N
```

と書ける．

粒子数 $N$ を一定にすると，式(1)から，

```math
p_F\propto V^{-1/3}
```

である．
したがって，式(4)の運動エネルギーは，

```math
K=\frac35N\frac{p_F^2}{2m}
\propto V^{-2/3}
```

となる．
すなわち $K=CV^{-2/3}$ と表せる定数 $C$ を用いれば，

```math
\begin{aligned}
p
&=-\frac{\partial}{\partial V}
\left(Nmc^2+CV^{-2/3}\right)\\
&=\frac23CV^{-5/3}\\
&=\frac{2K}{3V}
\end{aligned}
```

である．
したがって，

```math
\boxed{pV\simeq\frac23K}
\tag{5}
```

が得られる．
これで非相対論的極限の式が示された．

### 3．相対論的極限： $p_F\gg mc$

次に，フェルミ運動量が静止質量に対応する運動量 $mc$ より十分大きい場合を考える．
このとき，

```math
\varepsilon(p)
=cp\sqrt{1+\frac{m^2c^2}{p^2}}
\simeq cp
\tag{6}
```

となる．
静止エネルギーの寄与は運動エネルギーに比べて無視できるため，全エネルギーは運動エネルギーにほぼ等しい．

したがって，

```math
\begin{aligned}
E
&\simeq\frac{8\pi V}{h^3}
\int_0^{p_F}cp^3\,dp\\
&=\frac{8\pi Vc}{h^3}\frac{p_F^4}{4}\\
&=\frac{2\pi Vc}{h^3}p_F^4
\end{aligned}
```

となる．
ここでも，

```math
N=\frac{8\pi V}{3h^3}p_F^3
```

を用いると，

```math
\frac{2\pi Vc}{h^3}p_F^4
=\frac34Np_Fc
```

である．
よって，

```math
\boxed{
E\simeq K=\frac34Np_Fc
}
\tag{7}
```

を得る．

**したがって，問題文に記載された係数 $3/8$ ではなく， $3/4$ が正しい係数である．**

#### 圧力の導出

粒子数 $N$ を一定に保つと，式(1)より $p_F\propto V^{-1/3}$ である．
式(7)から，

```math
E\simeq K=\frac34Np_Fc\propto V^{-1/3}
```

となる．
したがって， $K=C'V^{-1/3}$ とおけば，

```math
\begin{aligned}
p
&=-\frac{\partial E}{\partial V}\\
&=\frac13C'V^{-4/3}\\
&=\frac{E}{3V}
\end{aligned}
```

である．
ゆえに，

```math
\boxed{pV\simeq\frac13K}
\tag{8}
```

が得られる．
これで相対論的極限における圧力の式が示された．

### 結論

絶対零度の Fermi 気体では，フェルミ運動量と粒子数密度の関係は，

```math
p_F=h\left(\frac{3n}{8\pi}\right)^{1/3}
```

である．
このフェルミ運動量が $mc$ より十分小さい場合，非相対論的近似から，

```math
\boxed{
E\simeq N\left(mc^2+\frac35\frac{p_F^2}{2m}\right),
\qquad
pV\simeq\frac23K
}
```

を得る．
一方， $p_F\gg mc$ の相対論的極限では，

```math
\boxed{
E\simeq K=\frac34Np_Fc,
\qquad
pV\simeq\frac13K
}
```

となる．
したがって，問題文の相対論的極限のエネルギー式にある係数 $3/8$ は $3/4$ に訂正する必要がある．


## 補足

本解答では，解答例と同様に，完全縮退した Fermi 気体の粒子数密度からフェルミ運動量を求め，二つの極限でエネルギーを近似してから圧力を導出している．

特に，相対論的極限の係数については，粒子数とエネルギーの運動量積分の両方から確認した．

その結果，問題文の $3/8$ では圧力の関係とも整合しないため，正しい係数は $3/4$ である．
