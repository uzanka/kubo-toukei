# 演習問題【8-R-1】

## 解答

## 1. 方針と仮定

スピン $1/2$ の粒子からなる，3 次元の非相互作用・非相対論的な理想 Fermi 気体を考える．
粒子数 $N$ ，体積 $V$ ，数密度 $n=N/V$ ，温度 $T$ とし，強い縮退条件

```math
k_{\mathrm B}T\ll \varepsilon_F
```

を仮定する．
ここで $\varepsilon_F$ は絶対零度における Fermi エネルギーである．

求めるのは，化学ポテンシャル（Fermi ポテンシャル） $\mu(T)$ と内部エネルギー $U(T)$ の，温度の $T^4$ の項までの展開である．

計算には Sommerfeld 展開を用いる．
なお，以下では粒子数 $N$ と体積 $V$ を一定に保つ．

## 2. 状態密度と Sommerfeld 展開

スピンの縮退度 $g_s=2$ を含む 3 次元自由粒子の状態密度は

```math
D(\varepsilon)=C\varepsilon^{1/2}, \qquad 
C=\frac{V}{2\pi^2} \left(\frac{2m}{\hbar^2}\right)^{3/2}
```

である．
Fermi–Dirac 分布関数を

```math
f(\varepsilon)= \frac{1}{\exp[(\varepsilon-\mu)/(k_{\mathrm B}T)]+1}
```

とすると，粒子数と内部エネルギーは

```math
N=\int_0^\infty D(\varepsilon)f(\varepsilon) d\varepsilon,
```

```math
U=\int_0^\infty \varepsilon D(\varepsilon) f(\varepsilon) d\varepsilon
```

で与えらる．

強い縮退条件では，Sommerfeld 展開

```math
\begin{aligned}
\int_0^\infty \phi(\varepsilon)f(\varepsilon)\\,d\varepsilon ={}&\int_0^\mu\phi(\varepsilon) d\varepsilon \\
&+\frac{\pi^2}{6}(k_{\mathrm B}T)^2\phi'(\mu) \\
&+\frac{7\pi^4}{360}(k_{\mathrm B}T)^4 \phi'''(\mu)+\cdots
\end{aligned}
```

を利用できる．

絶対零度の Fermi エネルギーを

```math
\varepsilon_F= \frac{\hbar^2}{2m}(3\pi^2n)^{2/3}, \qquad 
n=\frac NV
```

と定義する．
これは $T=0$ での化学ポテンシャルに等しく，粒子数は

```math
N=C\frac{2}{3}\varepsilon_F^{3/2}
```

を満たす．

## 3. Fermi ポテンシャル $\mu(T)$ の導出

粒子数の積分に Sommerfeld 展開を適用すると，

```math
\begin{aligned}
N=C\bigg[ &\frac23\mu^{3/2} +\frac{\pi^2}{12}(k_{\mathrm B}T)^2\mu^{-1/2} \\
&+\frac{7\pi^4}{960}(k_{\mathrm B}T)^4\mu^{-5/2} +\cdots\bigg].
\end{aligned}
```

粒子数 $N$ は温度によらず一定なので，これを $T=0$ の粒子数の式と等置する．
Fermi 温度

```math
T_F=\frac{\varepsilon_F}{k_{\mathrm B}}
```

および無次元量

```math
t=\frac{T}{T_F}=\frac{k_{\mathrm B}T}{\varepsilon_F}
```

を導入し， $\mu/\varepsilon_F=1+at^2+bt^4+\cdots$ とおく．
粒子数の式に代入して $t^2$ と $t^4$ の係数を比較すると，

```math
a=-\frac{\pi^2}{12}, \qquad b=-\frac{\pi^4}{80}
```

を得る．
したがって，Fermi ポテンシャルは

```math
\boxed{
\mu(T)=\varepsilon_F\left[ 1-\frac{\pi^2}{12} \left(\frac{T}{T_F}\right)^2 -\frac{\pi^4}{80} \left(\frac{T}{T_F}\right)^4 +O\left(\frac{T}{T_F}\right)^6 \right]
}
```

である．

## 4. 内部エネルギー $U(T)$ の導出

内部エネルギーの積分に Sommerfeld 展開を適用すると，

```math
\begin{aligned}
U=C\bigg[ &\frac25\mu^{5/2} +\frac{\pi^2}{4}(k_{\mathrm B}T)^2\mu^{1/2} \\
&-\frac{7\pi^4}{960}(k_{\mathrm B}T)^4 \mu^{-3/2}+\cdots \bigg].
\end{aligned}
```

ここで $N=\frac23C\varepsilon_F^{3/2}$ を用いると，

```math
\begin{aligned}
\frac{U}{N\varepsilon_F} ={}&\frac35\left(\frac{\mu}{\varepsilon_F}\right)^{5/2} \\
&+\frac{3\pi^2}{8}t^2 \left(\frac{\mu}{\varepsilon_F}\right)^{1/2} \\
&-\frac{7\pi^4}{640}t^4 \left(\frac{\mu}{\varepsilon_F}\right)^{-3/2} +\cdots.
\end{aligned}
```

先ほど求めた $\mu(T)$ の展開を代入し， $t^4$ までの項を整理すると，

```math
\frac{U}{N\varepsilon_F} =\frac35+\frac{\pi^2}{4}t^2 -\frac{3\pi^4}{80}t^4+O(t^6).
```

したがって，内部エネルギーは

```math
\boxed{
U(T)=\frac35N\varepsilon_F \left[ 1+\frac{5\pi^2}{12} \left(\frac{T}{T_F}\right)^2 -\frac{\pi^4}{16} \left(\frac{T}{T_F}\right)^4 +O\left(\frac{T}{T_F}\right)^6 \right]
}
```

となる．

## 5. 最終結果とレビュー

求める結果をまとめると，次のとおりである．

```math
\boxed{
\mu(T)=\varepsilon_F \left[ 1-\frac{\pi^2}{12}\left(\frac{T}{T_F}\right)^2 -\frac{\pi^4}{80}\left(\frac{T}{T_F}\right)^4 \right]
}
```

```math
\boxed{
U(T)=\frac35N\varepsilon_F \left[ 1+\frac{5\pi^2}{12}\left(\frac{T}{T_F}\right)^2 -\frac{\pi^4}{16}\left(\frac{T}{T_F}\right)^4 \right]
}
```

いずれも，表示した式では $O((T/T_F)^6)$ 以上の項を省略している．

解答の整合性を確認した．

- スピン $1/2$ に対応するスピン縮退度 $2$ を状態密度に含めている．
- 粒子数 $N$ と体積 $V$ を一定に保つ条件で化学ポテンシャルを展開している．
- 内部エネルギーにも同じ化学ポテンシャルの展開を代入し， $T^2$ 項と $T^4$ 項を整理している．
- $T\to0$ の極限では $\mu\to\varepsilon_F$ ， $U\to\frac35N\varepsilon_F$ となり，絶対零度の理想 Fermi 気体の結果と一致する．

以上より，強い縮退条件 $T/T_F\ll1$ における，Fermi ポテンシャルと内部エネルギーの $T^4$ 項までの展開は上記のとおりである．
