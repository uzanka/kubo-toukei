# 例題【8-R-1】

## 解答

### 強く縮退した理想 Fermi 気体の Fermi ポテンシャルと内部エネルギー

#### 1．問題の設定

体積 $V$ の中に，質量 $m$ ，スピン $1/2$ の粒子が $N$ 個存在する三次元の理想 Fermi 気体を考える．
粒子間の相互作用は無視し，粒子数 $N$ と体積 $V$ は一定に保つ．
粒子数密度を

```math
n=\frac{N}{V}
```

とする．

本問題では，強縮退条件

```math
k_{\mathrm B}T\ll\varepsilon_F
```

のもとで，Fermi ポテンシャル，すなわち化学ポテンシャル $\mu(T)$ と内部エネルギー $U(T)$ を温度の $T^4$ の項まで求める．
ここで， $\varepsilon_F$ は絶対零度における Fermi エネルギー， $k_{\mathrm B}$ は Boltzmann 定数である．

計算には Sommerfeld 展開を用いる．
これは，低温の Fermi 気体におけるエネルギー積分を，化学ポテンシャルまでの積分と温度による補正項に分ける方法である．

#### 2．状態密度と絶対零度の Fermi エネルギー

##### 2.1 状態密度

運動量の大きさが $p$ 以下の一粒子状態の数は，スピンの二つの向きを考慮すると，

```math
\mathcal N(p)
=2\frac{V}{h^3}\frac{4\pi p^3}{3}
```

である．
ここで $h$ は Planck 定数である．
自由粒子のエネルギーは

```math
\varepsilon=\frac{p^2}{2m}
```

であるため，エネルギーが $\varepsilon$ 以下の状態数は

```math
\mathcal N(\varepsilon)
=\frac{8\pi V}{3h^3}(2m\varepsilon)^{3/2}
```

となる．
これを $\varepsilon$ で微分すると，状態密度は

```math
D(\varepsilon)
=\frac{d\mathcal N}{d\varepsilon}
=\frac{4\pi V}{h^3}(2m)^{3/2}\varepsilon^{1/2}
```

である．
したがって，

```math
\boxed{
D(\varepsilon)=C\varepsilon^{1/2}
}
```

と書ける．
ただし，

```math
C=\frac{4\pi V}{h^3}(2m)^{3/2}
=\frac{V}{2\pi^2}
\left(\frac{2m}{\hbar^2}\right)^{3/2}
```

であり， $\hbar=h/(2\pi)$ である．
状態密度にはスピン縮退度 $2$ がすでに含まれている．

##### 2.2 絶対零度の Fermi エネルギー

絶対零度 $T=0$ では，エネルギーが $\varepsilon_F$ 以下の状態はすべて占有され，それより上の状態は空である．
したがって，

```math
N=\int_0^{\varepsilon_F}D(\varepsilon)\,d\varepsilon
```

であり，状態密度を代入すると，

```math
\begin{aligned}
N
&=C\int_0^{\varepsilon_F}\varepsilon^{1/2}\,d\varepsilon\\
&=\frac23C\varepsilon_F^{3/2}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\varepsilon_F
=\frac{\hbar^2}{2m}(3\pi^2n)^{2/3}
}
\tag{1}
```

を得る．
絶対零度では化学ポテンシャルは $\mu(0)=\varepsilon_F$ である．

Fermi 温度を

```math
T_F=\frac{\varepsilon_F}{k_{\mathrm B}}
```

と定義し，無次元温度を

```math
t=\frac{T}{T_F}
=\frac{k_{\mathrm B}T}{\varepsilon_F}
```

とおく．
強縮退条件は $t\ll1$ と表せる．

#### 3．Sommerfeld 展開

Fermi-Dirac 分布関数は

```math
f(\varepsilon)
=\frac{1}{e^{(\varepsilon-\mu)/(k_{\mathrm B}T)}+1}
```

である．
強縮退の場合，十分滑らかな関数 $\phi(\varepsilon)$ に対して，Sommerfeld 展開は

```math
\begin{aligned}
\int_0^\infty \phi(\varepsilon)f(\varepsilon)\,d\varepsilon
={}&\int_0^\mu\phi(\varepsilon)\,d\varepsilon\\
&+\frac{\pi^2}{6}(k_{\mathrm B}T)^2\phi'(\mu)\\
&+\frac{7\pi^4}{360}(k_{\mathrm B}T)^4\phi'''(\mu)
+\cdots
\end{aligned}
\tag{2}
```

で与えられる．
ここで $\phi'$ と $\phi'''$ は，それぞれ $\varepsilon$ による一階微分と三階微分である．

この式を粒子数と内部エネルギーの積分に適用する．

#### 4．Fermi ポテンシャル $\mu(T)$ の導出

粒子数は

```math
N=\int_0^\infty D(\varepsilon)f(\varepsilon)\,d\varepsilon
=C\int_0^\infty \varepsilon^{1/2}f(\varepsilon)\,d\varepsilon
```

である．
式 (2) に $\phi(\varepsilon)=\varepsilon^{1/2}$ を代入する．
このとき，

```math
\phi'(\varepsilon)=\frac12\varepsilon^{-1/2},
\qquad
\phi'''(\varepsilon)=\frac38\varepsilon^{-5/2}
```

であるから，

```math
\boxed{
N=C\left[
\frac23\mu^{3/2}
+\frac{\pi^2}{12}(k_{\mathrm B}T)^2\mu^{-1/2}
+\frac{7\pi^4}{960}(k_{\mathrm B}T)^4\mu^{-5/2}
+\cdots
\right]
}
\tag{3}
```

となる．

粒子数 $N$ は一定であり，絶対零度では $N=\frac23C\varepsilon_F^{3/2}$ である．
これを式 (3) と等置すると，

```math
1=
\left(\frac{\mu}{\varepsilon_F}\right)^{3/2}
+\frac{\pi^2}{8}t^2
\left(\frac{\mu}{\varepsilon_F}\right)^{-1/2}
+\frac{7\pi^4}{640}t^4
\left(\frac{\mu}{\varepsilon_F}\right)^{-5/2}
+\cdots
\tag{4}
```

を得る．

ここで，

```math
\frac{\mu}{\varepsilon_F}
=1+at^2+bt^4+O(t^6)
\tag{5}
```

とおく．
二項展開を用いると，

```math
\left(\frac{\mu}{\varepsilon_F}\right)^{3/2}
=
1+\frac32at^2
+\left(\frac32b+\frac38a^2\right)t^4
+O(t^6)
```

および，

```math
\left(\frac{\mu}{\varepsilon_F}\right)^{-1/2}
=1-\frac12at^2+O(t^4)
```

である．
また， $t^4$ の項では，

```math
\left(\frac{\mu}{\varepsilon_F}\right)^{-5/2}
=1+O(t^2)
```

と近似できる．
これらを式 (4) に代入し，同じ次数の係数を比較する．

まず， $t^2$ の係数は

```math
\frac32a+\frac{\pi^2}{8}=0
```

であるから，

```math
\boxed{a=-\frac{\pi^2}{12}}
```

となる．
続いて， $t^4$ の係数は

```math
\frac32b+\frac38a^2
-\frac{\pi^2}{16}a+\frac{7\pi^4}{640}=0
```

である．
先ほどの $a=-\pi^2/12$ を代入すると，

```math
\frac32b+\frac{3\pi^4}{160}=0
```

となり，

```math
\boxed{b=-\frac{\pi^4}{80}}
```

を得る．
したがって，Fermi ポテンシャルは

```math
\boxed{
\mu(T)=\varepsilon_F
\left[
1-\frac{\pi^2}{12}
\left(\frac{T}{T_F}\right)^2
-\frac{\pi^4}{80}
\left(\frac{T}{T_F}\right)^4
+O\!\left(\left(\frac{T}{T_F}\right)^6\right)
\right]
}
\tag{6}
```

である．

#### 5．内部エネルギー $U(T)$ の導出

内部エネルギーは，各状態のエネルギーにその状態の平均占有数を掛けて，全状態について和を取ったものである．
したがって，

```math
U=\int_0^\infty \varepsilon D(\varepsilon)
f(\varepsilon)\,d\varepsilon
=C\int_0^\infty \varepsilon^{3/2}
f(\varepsilon)\,d\varepsilon
```

となる．
式 (2) に $\phi(\varepsilon)=\varepsilon^{3/2}$ を代入する．
このとき，

```math
\phi'(\varepsilon)=\frac32\varepsilon^{1/2},
\qquad
\phi'''(\varepsilon)=-\frac38\varepsilon^{-3/2}
```

であるから，

```math
\boxed{
U=C\left[
\frac25\mu^{5/2}
+\frac{\pi^2}{4}(k_{\mathrm B}T)^2\mu^{1/2}
-\frac{7\pi^4}{960}(k_{\mathrm B}T)^4\mu^{-3/2}
+\cdots
\right]
}
\tag{7}
```

を得る．

式 (7) を $N\varepsilon_F$ で割り， $N=\frac23C\varepsilon_F^{3/2}$ と $t=k_{\mathrm B}T/\varepsilon_F$ を用いると，

```math
\begin{aligned}
\frac{U}{N\varepsilon_F}
={}&\frac35
\left(\frac{\mu}{\varepsilon_F}\right)^{5/2}\\
&+\frac{3\pi^2}{8}t^2
\left(\frac{\mu}{\varepsilon_F}\right)^{1/2}\\
&-\frac{7\pi^4}{640}t^4
\left(\frac{\mu}{\varepsilon_F}\right)^{-3/2}
+O(t^6)
\end{aligned}
\tag{8}
```

となる．

式 (6) で求めた化学ポテンシャルの展開を代入する．
$y=\mu/\varepsilon_F=1+at^2+bt^4+O(t^6)$ と書けば，

```math
y^{5/2}
=1+\frac52at^2
+\left(\frac52b+\frac{15}{8}a^2\right)t^4
+O(t^6)
```

および，

```math
y^{1/2}=1+\frac12at^2+O(t^4)
```

である．
また，式 (8) の第 3 項では， $t^4$ までを求めればよいため， $y^{-3/2}=1+O(t^2)$ としてよい．

これらを式 (8) に代入し， $a=-\pi^2/12$ ， $b=-\pi^4/80$ を用いると， $t^2$ の係数は

```math
\frac32a+\frac{3\pi^2}{8}
=\frac{\pi^2}{4}
```

となる．
$t^4$ の係数は

```math
\begin{aligned}
&\frac35\left(\frac52b+\frac{15}{8}a^2\right)
+\frac{3\pi^2}{16}a-\frac{7\pi^4}{640}\\
&\qquad=-\frac{3\pi^4}{80}
\end{aligned}
```

である．
したがって，

```math
\boxed{
\frac{U}{N\varepsilon_F}
=\frac35+\frac{\pi^2}{4}
\left(\frac{T}{T_F}\right)^2
-\frac{3\pi^4}{80}
\left(\frac{T}{T_F}\right)^4
+O\!\left(\left(\frac{T}{T_F}\right)^6\right)
}
\tag{9}
```

を得る．
これを絶対零度の内部エネルギー $\frac35N\varepsilon_F$ を用いて整理すれば，

```math
\boxed{
U(T)=\frac35N\varepsilon_F
\left[
1+\frac{5\pi^2}{12}
\left(\frac{T}{T_F}\right)^2
-\frac{\pi^4}{16}
\left(\frac{T}{T_F}\right)^4
+O\!\left(\left(\frac{T}{T_F}\right)^6\right)
\right]
}
\tag{10}
```

となる．

#### 6．最終結果

強縮退条件 $T/T_F\ll1$ における Fermi ポテンシャルと内部エネルギーは，それぞれ

```math
\boxed{
\mu(T)=\varepsilon_F
\left[
1-\frac{\pi^2}{12}
\left(\frac{T}{T_F}\right)^2
-\frac{\pi^4}{80}
\left(\frac{T}{T_F}\right)^4
+O\!\left(\left(\frac{T}{T_F}\right)^6\right)
\right]
}
```

および，

```math
\boxed{
U(T)=\frac35N\varepsilon_F
\left[
1+\frac{5\pi^2}{12}
\left(\frac{T}{T_F}\right)^2
-\frac{\pi^4}{16}
\left(\frac{T}{T_F}\right)^4
+O\!\left(\left(\frac{T}{T_F}\right)^6\right)
\right]
}
```

である．

温度が上昇すると，固定粒子数の条件のもとで化学ポテンシャルは絶対零度の Fermi エネルギーより低下する．
一方，内部エネルギーは絶対零度の値 $\frac35N\varepsilon_F$ から増加する．
これらの結果は，絶対零度の極限 $T\to0$ で $\mu\to\varepsilon_F$ ， $U\to\frac35N\varepsilon_F$ となることとも整合している．
