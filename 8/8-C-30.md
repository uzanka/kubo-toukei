# 演習問題【8-C-30】

## 解答

### 理想 Fermi 気体の磁化率に現れる振動項

#### 1．問題の設定と計算方針

磁場 $H$ 中の自由電子は，軌道運動が Landau 準位に量子化される．
電子系が Fermi-Dirac 統計に従い，

```math
k_BT\lesssim\mu_{\mathrm B}H\ll\mu
```

という条件にあるとき，磁化率には磁場に対する振動項が現れる．
これが de Haas–van Alphen 効果である．
ここで， $k_B$ は Boltzmann 定数， $T$ は絶対温度， $\mu_{\mathrm B}$ は Bohr 磁子， $\mu$ は化学ポテンシャルである．

計算は次の順序で進める．

まず，問題 [17] の Landau 準位から 1 電子分配関数 $Z(\beta)$ を求める．
次に，Laplace 逆変換を用いて自由エネルギーに関係する関数 $\Omega_1(\epsilon)$ を表し，複素積分の極の留数から振動項を取り出す．
最後に，Fermi 分布の微分を積分して温度による減衰を求め，磁場で微分することで磁化率の振動項を導く．

以下では計算を簡潔にするため，

```math
X=\mu_{\mathrm B}H,\qquad
C=\frac{(2\pi m)^{3/2}}{h^3}
```

とおく．
ここで $m$ は電子の質量， $h$ は Planck 定数である．

#### 2．1 電子分配関数と Laplace 逆変換

##### 2.1 1 電子分配関数

スピン縮退を含めないとき，磁場中の 1 電子状態のエネルギーは

```math
\epsilon_{l,p_z}
=2X\left(l+\frac12\right)+\frac{p_z^2}{2m},
\qquad l=0,1,2,\ldots
```

である．
問題 [17] の状態数を用いると，1 電子分配関数は

```math
Z(\beta)
=\frac{4\pi VmX}{h^3}
\sum_{l=0}^{\infty}
\int_{-\infty}^{\infty}
e^{-\beta\epsilon_{l,p_z}}\,dp_z
```

となる．
ここで

```math
\sum_{l=0}^{\infty}
e^{-2\beta X(l+1/2)}
=\frac{1}{2\sinh(\beta X)}
```

および

```math
\int_{-\infty}^{\infty}
e^{-\beta p_z^2/(2m)}\,dp_z
=\sqrt{\frac{2\pi m}{\beta}}
```

を用いる．
これらを代入すれば，

```math
\boxed{
Z(\beta)
=VC\beta^{-3/2}
\frac{\beta X}{\sinh(\beta X)}
}
\tag{1}
```

を得る．
磁場がない極限 $X\to0$ では， $\sinh(\beta X)\simeq\beta X$ であるから，

```math
Z(\beta)\longrightarrow VC\beta^{-3/2}
```

となる．
これは自由粒子の分配関数であり，式 (1) の整合性を確認できる．

##### 2.2 自由エネルギーに関係する関数

ヒントの Laplace 逆変換は

```math
D(\epsilon)
=\frac{1}{2\pi i}
\int_{c-i\infty}^{c+i\infty}
e^{\beta\epsilon}Z(\beta)\,d\beta
```

である．
ここで $D(\epsilon)$ は 1 電子状態密度であり， $c>0$ は Bromwich 積分路の実部である．

自由エネルギーの積分を扱いやすくするため，次の関数を定義する：

```math
\Omega_1(\epsilon)
=\frac{1}{2\pi i}
\int_{c-i\infty}^{c+i\infty}
\frac{e^{\beta\epsilon}}{\beta^2}
Z(\beta)\,d\beta .
```

式 (1) を代入すると，

```math
\boxed{
\Omega_1(\epsilon)
=VCX\frac{1}{2\pi i}
\int_{c-i\infty}^{c+i\infty}
\frac{e^{\beta\epsilon}}
{\beta^{5/2}\sinh(\beta X)}\,d\beta
}
\tag{2}
```

を得る．

Fermi 分布関数を

```math
f(\epsilon)
=\frac{1}{e^{(\epsilon-\mu)/(k_BT)}+1}
```

とすると，大正準ポテンシャル $\Omega=F-N\mu$ は

```math
\boxed{
F-N\mu
=\int_0^\infty
\Omega_1(\epsilon)
\frac{\partial f}{\partial\epsilon}\,d\epsilon
}
\tag{3}
```

と表せる．
この式は，Fermi 分布の微分によって，状態密度のエネルギー依存性を自由エネルギーへ結び付けるものである．

#### 3．留数計算による振動項

##### 3.1 極の寄与

式 (2) の被積分関数は， $\beta=0$ に分岐点を持つ．
負の実軸上に分岐切断を取り，積分路を左へ移すと，切断の周りの積分と極の周りの積分に分けることができる．
切断の寄与は磁場について滑らかな部分を与えるため，振動項を求める際には極の寄与に注目する．

```math
\beta_l=\frac{il\pi}{X},
\qquad l=\pm1,\pm2,\ldots
```

は $\sinh(\beta X)=0$ を満たす極である．
各極の周りで

```math
\beta X=il\pi+z
```

とおく．
$z=0$ 近傍では

```math
\sinh(il\pi+z)\simeq(-1)^l z
```

であるため，留数を求めることができる．
正負の $l$ の寄与を対にして整理すると，

```math
\boxed{
\Omega_1^{\mathrm{osc}}(\epsilon)
=-2VC
\sum_{l=1}^{\infty}
\frac{X^{5/2}}{(\pi l)^{5/2}}
(-1)^l
\cos\left(
\frac{l\pi\epsilon}{X}-\frac{\pi}{4}
\right)
}
\tag{4}
```

となる．
ここで $\Omega_1^{\mathrm{osc}}$ は， $\Omega_1$ のうち磁場に対して振動する部分である．

#### 4．有限温度による振動の減衰

##### 4.1 Fermi 分布の微分

式 (3) に式 (4) を代入する．
各調和成分について

```math
I_l
=2\int_0^\infty
\cos\left(
\frac{l\pi\epsilon}{X}-\frac{\pi}{4}
\right)
\frac{\partial f}{\partial\epsilon}\,d\epsilon
```

と定義する．
この定義では係数 2 を含めていることに注意する．

Fermi 分布の微分は

```math
\frac{\partial f}{\partial\epsilon}
=-\frac{1}{4k_BT}
\frac{1}{\cosh^2[(\epsilon-\mu)/(2k_BT)]}
```

である．
また， $k_BT\ll\mu$ なので，積分の主な寄与は $\epsilon=\mu$ の近傍にある．
そこで積分下限を $0$ から $-\infty$ に拡張しても，最低次の近似では誤差は小さい．

```math
z=\frac{\epsilon-\mu}{2k_BT}
```

と変数変換すると，

```math
\begin{aligned}
I_l\simeq
-\operatorname{Re}\biggl[
&e^{i(l\pi\mu/X-\pi/4)}\\
&\times
\int_{-\infty}^{\infty}
\frac{e^{2\pi i l k_BT z/X}}{\cosh^2z}\,dz
\biggr].
\end{aligned}
\tag{5}
```

##### 4.2 複素積分

積分

```math
J(a)=\int_{-\infty}^{\infty}
\frac{e^{iaz}}{\cosh^2z}\,dz
```

を考える．
$a>0$ とし，上半平面で積分路を閉じると，被積分関数は

```math
z_n=i\left(n+\frac12\right)\pi,
\qquad n=0,1,2,\ldots
```

に二位の極を持つ．
これらの留数を求めて和を取ると，

```math
\boxed{
J(a)=\frac{\pi a}{\sinh(\pi a/2)}
}
```

を得る．
ここでは積分値が正となる点に注意する．
式 (5) に

```math
a=\frac{2\pi l k_BT}{X}
```

を代入すると，

```math
\boxed{
I_l
=-\frac{2\pi^2 l k_BT/X}
{\sinh(\pi^2 l k_BT/X)}
\cos\left(
\frac{l\pi\mu}{X}-\frac{\pi}{4}
\right)
}
\tag{6}
```

となる．

##### 4.3 自由エネルギーの振動項

式 (3)，(4)，(6) を組み合わせる．
$I_l$ の定義には係数 2 が含まれているため，式 (4) の係数と整合させると，

```math
\boxed{
\begin{aligned}
\Omega_{\mathrm{osc}}
&=F_{\mathrm{osc}}-N\mu\\
&=
VC\frac{2k_BT}{\sqrt{\pi}}X^{3/2}
\sum_{l=1}^{\infty}
\frac{(-1)^l}{l^{3/2}}
\frac{
\cos(l\pi\mu/X-\pi/4)
}{
\sinh(\pi^2l k_BT/X)
}
\end{aligned}
}
\tag{7}
```

を得る．
これが自由エネルギーに関係する振動項である．

式 (7) の分母にある

```math
\sinh\left(\frac{\pi^2l k_BT}{X}\right)
```

は，温度による振動の減衰を表す．
引数が大きい場合には $\sinh x\simeq e^x/2$ となり，振動は指数関数的に小さくなる．
したがって，基本振動を観測できるためには，おおよそ

```math
\frac{\pi^2 k_BT}{X}\lesssim1
```

が必要である．
単に $k_BT\lesssim X$ であれば十分というわけではない．

#### 5．磁化率の振動項

##### 5.1 固定粒子数での微分

磁化率は

```math
\chi=-\frac{1}{VH}
\left(\frac{\partial F}{\partial H}\right)_{T,V,N}
```

で定義される．
化学ポテンシャル $\mu$ は一般に磁場に依存するが，大正準ポテンシャル $\Omega=F-N\mu$ を用いると，

```math
F=\Omega+\mu N
```

であり，粒子数 $N$ を固定した微分では

```math
\left(\frac{dF}{dH}\right)_{T,V,N}
=
\left(\frac{\partial\Omega}{\partial H}\right)_{T,V,\mu}
```

となる．
これは

```math
\left(\frac{\partial\Omega}{\partial\mu}\right)_{T,V,H}=-N
```

によって $\mu$ の変化に由来する項が相殺されるためである．
よって，式 (7) の磁場微分では， $\mu$ を一定としてよい．

##### 5.2 主要項の計算

式 (7) に現れる位相を

```math
\theta_l=\frac{l\pi\mu}{X}-\frac{\pi}{4}
```

とおく．
ここで $X=\mu_{\mathrm B}H$ であるから，

```math
\frac{\partial\theta_l}{\partial H}
=-\frac{l\pi\mu\mu_{\mathrm B}}{X^2}
```

となり，

```math
\frac{\partial}{\partial H}\cos\theta_l
=\frac{l\pi\mu\mu_{\mathrm B}}{X^2}
\sin\theta_l
```

を得る．

強く縮退した系では $X\ll\mu$ であるため，位相の微分による寄与は，前置因子 $X^{3/2}$ や温度減衰因子の微分による寄与よりも主要である．
これらの高次の補正を無視すると，

```math
\boxed{
\begin{aligned}
\chi_{\mathrm{osc}}
\simeq{}&
-C\frac{2\sqrt{\pi}k_BT\,\mu\mu_{\mathrm B}^2}
{X^{3/2}}\\
&\times
\sum_{l=1}^{\infty}
\frac{(-1)^l}{l^{1/2}}
\frac{\sin(l\pi\mu/X-\pi/4)}
{\sinh(\pi^2l k_BT/X)}
\end{aligned}
}
\tag{8}
```

となる．
これが磁化率の振動項である．
この式は， $\mu\gg X$ の条件の下で，位相の微分による主要項を残した近似式である．

##### 5.3 電子数密度による表示

スピン縮退を含めない場合，強縮退極限の電子数密度は

```math
n\simeq\frac{4\pi}{3h^3}(2m\mu)^{3/2}
```

である．
これと

```math
C=\frac{(2\pi m)^{3/2}}{h^3}
```

の関係

```math
n=\frac{4}{3\sqrt{\pi}}C\mu^{3/2}
```

を用いると，式 (8) は

```math
\boxed{
\begin{aligned}
\chi_{\mathrm{osc}}
\simeq{}&
-\frac{3\pi n\mu_{\mathrm B}^2}{2k_BT}
\left(\frac{k_BT}{X}\right)^2
\left(\frac{X}{\mu}\right)^{1/2}\\
&\times
\sum_{l=1}^{\infty}
\frac{(-1)^l}{l^{1/2}}
\frac{\sin(l\pi\mu/X-\pi/4)}
{\sinh(\pi^2l k_BT/X)}
\end{aligned}
}
\tag{9}
```

と表せる．

特に，第一調和成分 $l=1$ だけを残すと，

```math
\boxed{
\begin{aligned}
\chi_{\mathrm{osc}}^{(1)}
\simeq{}&
+\frac{3\pi n\mu_{\mathrm B}^2}{2k_BT}
\left(\frac{k_BT}{X}\right)^2
\left(\frac{X}{\mu}\right)^{1/2}\\
&\times
\frac{\sin(\pi\mu/X-\pi/4)}
{\sinh(\pi^2 k_BT/X)}
\end{aligned}
}
\tag{10}
```

となる．
ここでは，式 (7) の自由エネルギー振動項と磁化率の定義から一貫して符号を決めている．
このため，提示された解答例の式 (9)，(10) と同じ位相を使った場合には，符号が反対となる．
解答例では自由エネルギーの式から磁化率への微分で符号の不整合があると考えられる．

なお，実在の電子のスピン縮退度 2 を状態数に含める場合には，スピンの Zeeman エネルギーを別に考慮しない軌道磁化率についても，式 (8)～(10) の値は 2 倍となる．

#### 6．振動周期と観測条件

位相は

```math
\theta_l=\frac{l\pi\mu}{\mu_{\mathrm B}H}-\frac{\pi}{4}
```

であるから，振動は $1/H$ に対して周期的である．
基本振動 $l=1$ の位相が $2\pi$ 変化する磁場逆数の周期は

```math
\boxed{
\Delta\left(\frac1H\right)=\frac{2\mu_{\mathrm B}}{\mu}
}
```

となる．
また，第一調和成分の振幅は，温度減衰を除けば $H^{-3/2}$ に比例する．
したがって， $\chi_{\mathrm{osc}}H^{3/2}\sinh(\pi^2k_BT/X)$ を考えると，第一調和成分は $1/H$ の周期関数となる．

以上より，de Haas–van Alphen 効果は，Landau 準位の離散化に由来する振動項と，Fermi 分布の有限温度幅による減衰によって説明される．
振動を観測するには，化学ポテンシャルが Landau 準位間隔より十分大きいだけでなく，熱による減衰も十分小さい必要がある．
