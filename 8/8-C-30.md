# 演習問題【8-C-30】

## 解答

## 1. 方針

磁場中の自由電子の磁化率は，磁場がかなり強くなる ( $kT \lesssim \mu_B H \ll \mu$ ) とき，磁場 $H$ の関数として振動する項を含む（de Haas–van Alphen 効果）．
この振動項を，問題のヒントに従い，Boltzmann 統計での 1 電子問題の分配関数 $Z(\beta)$ から Laplace 逆変換によって求める。

本問題ではスピン自由度を含むが，単位系の表記については解答例に倣い $\mu_B H$ を Landau 準位の間隔として用いる．
化学ポテンシャルを $\mu$ と表すのは解答例に合わせる（物理学での化学ポテンシャルと同じ記号であるが，文脈で区別できる）．

## 2. 分配関数と状態密度

### 2.1 問題 [17] の結果

問題 [17] で求めた磁場中の自由電子の 1 粒子分配関数を $Z(\beta)$ とする．
Landau 準位の和を取ると，

```math
Z(\beta)
= V \frac{(2\pi m)^{3/2}}{h^3} (\mu_B H)^{1/2}
\int_0^\infty \frac{e^{-\beta\varepsilon}}{\sqrt{\varepsilon}} \cdot \frac{\beta \mu_B H}{\sinh(\beta \mu_B H)} d\varepsilon
```

の形の結果が得られる．
Poisson 和公式を用いて滑らかな部分と振動部分に分離すると，振動部分は $\beta = i l\pi / (\mu_B H)$ ( $l = \pm 1, \pm 2, \cdots$ ) に極を持つ．

### 2.2 Laplace 逆変換

ヒントの式 (6.6) より，状態密度 $D(\varepsilon)$ は

```math
D(\varepsilon) = \frac{1}{2\pi i} \int_{c-i\infty}^{c+i\infty} e^{\beta\varepsilon} Z(\beta) d\beta
```

で与えられる．
自由エネルギーに関連する量 $\Omega_1(\varepsilon)$ を

```math
\Omega_1(\varepsilon) = \frac{1}{2\pi i} \int_{c-i\infty}^{c+i\infty} \frac{e^{\beta\varepsilon}}{\beta^2} Z(\beta) d\beta \qquad \cdots (1)
```

と定義する（2 回部分積分を行った形）．
問題 [17] の結果を代入すると，

```math
\Omega_1(\varepsilon) = V \frac{(2\pi m)^{3/2} \mu_B H}{h^3} \cdot \frac{1}{2\pi i} \int_{c-i\infty}^{c+i\infty} \frac{e^{\beta\varepsilon}}{\beta^{5/2} \sinh(\beta \mu_B H)} d\beta
\qquad \cdots (2)
```

## 3. 留数計算による振動項の導出

### 3.1 極と積分経路

被積分関数は $\beta = 0$ に分岐点を持つ．
負の実軸上に切断を入れ， $\beta$ 平面上で積分路を左へずらす．
このとき $\beta_l = i l\pi / (\mu_B H)$ ( $l = \pm 1, \pm 2, \cdots$ ) の極の周りの積分が振動項を与える（切断周りの積分はなめらかな関数を与え，振動項には寄与しない）．

$l > 0$ について $\beta \mu_B H = i l\pi + z$ とおくと，

```math
\Omega_1^{\text{osc}}(\varepsilon) 
= V \frac{(2\pi m)^{3/2} (\mu_B H)^{5/2}}{h^3} \sum_{l=\pm 1, \pm 2, \cdots} \frac{(-1)^l}{(i l\pi)^{5/2}} e^{i l\pi\varepsilon / (\mu_B H)}
```

ここで $z = 0$ における $\sinh z \cong z$ との近似を用い，留数を取った．
複素位相を整理すると，

```math
\Omega_1^{\text{osc}}(\varepsilon) 
= -V \frac{(2\pi m)^{3/2}}{h^3} (\mu_B H)^{5/2} \sum_{l=1}^{\infty} \frac{2(-1)^l}{(\pi l)^{5/2}} \cos\!\left( \frac{l\pi\varepsilon}{\mu_B H} - \frac{\pi}{4} \right)
\qquad \cdots (3)
```

### 3.2 物理的条件の役割

条件 $kT \lesssim \mu_B H$ は， $\partial f/\partial\varepsilon$ のピーク幅 ( $\sim kT$ ) と振動項の波長 ( $\sim \mu_B H/l$ ) を比較した際に，振動が相殺されなくなる領域を指定する．
条件 $\mu_B H \ll \mu$ はフェルミエネルギーが Landau 準位間隔より十分大きいため，多くの準位が占有され連続近似が有効であることを保証する．

## 4. 大正準ポテンシャルの振動項

### 4.1 積分の準備

Helmholtz 自由エネルギー $F$ と化学ポテンシャル $\mu$ の関係から（問題 [17] の結果より），

```math
F - N\mu = \int_0^\infty \Omega_1(\varepsilon) \frac{\partial f}{\partial\varepsilon} d\varepsilon
```

$f(\varepsilon)$ はフェルミ分布関数。$\Omega_1^{\text{osc}}$ を代入し， $l$ ごとの積分を

```math
I_l = \int_0^\infty \cos\!\left( \frac{l\pi\varepsilon}{\mu_B H} - \frac{\pi}{4} \right) \frac{\partial f}{\partial\varepsilon} d\varepsilon
```

と置く．
$\varepsilon = \mu + x$ と変数変換すると，

```math
I_l = \operatorname{Re} \left[ e^{i l\pi\mu/(\mu_B H) - i\pi/4} \int_{-\mu}^\infty \frac{e^{i l\pi x/(\mu_B H)}}{\left\{ e^{x/(2kT)} + e^{-x/(2kT)} \right\}^2} dx \right]
```

$kT \ll \mu$ だから，積分下限を $-\infty$ で近似してよい．
$z = x/(2kT)$ とおくと，

```math
I_l = -\operatorname{Re} \left[ e^{i l\pi\mu/(\mu_B H) - i\pi/4} \int_{-\infty}^\infty \frac{e^{2\pi i l kT z / (\mu_B H)}}{\cosh^2 z} dz \right]
\qquad \cdots (4)
```

### 4.2 複素積分

$z = i(n+1/2)\pi$ ( $n = 0, 1, 2, \cdots$ ) は 2 位の極．
上半円を加えて閉じると，

```math
\int_{-\infty}^\infty \frac{e^{2\pi i l kT z / (\mu_B H)}}{\cosh^2 z} dz = 2\pi i \sum_{n=0}^\infty \operatorname{Res}_{z_n}
```

$z_n = i(n+1/2)\pi + y$ とおいて $y=0$ で留数を計算すると，

```math
\operatorname{Res}_{z_n} = -\frac{2\pi^2 l kT}{\mu_B H} e^{-\pi^2 l kT (2n+1)/(\mu_B H)}
```

$n$ について和を取ると等比級数となり，

```math
\int_{-\infty}^\infty \frac{e^{2\pi i l kT z / (\mu_B H)}}{\cosh^2 z} dz
= -\frac{2\pi^2 l kT / (\mu_B H)}{\sinh\!\bigl( \pi^2 l kT / (\mu_B H) \bigr)}
\qquad \cdots (5)
```

これより，

```math
I_l = -\frac{2\pi^2 l kT / (\mu_B H)}{\sinh\!\bigl( \pi^2 l kT / (\mu_B H) \bigr)} \cos\!\left( \frac{l\pi\mu}{\mu_B H} - \frac{\pi}{4} \right)
\qquad \cdots (6)
```

### 4.3 $F_{\text{osc}}$ の導出

式 (3), (6) を積分に代入して， $\varepsilon = \mu$ で振動項を評価（ $kT \sim \mu_B H$ では $\partial f/\partial\varepsilon$ のピーク近傍で評価）．

```math
F_{\text{osc}} - N\mu 
= -V \frac{(2\pi m)^{3/2}}{h^3} (\mu_B H)^{5/2} \sum_{l=1}^\infty \frac{2(-1)^l}{(\pi l)^{5/2}} \cdot I_l
```

```math
\boxed{
F_{\text{osc}} - N\mu = V \frac{(2\pi m)^{3/2}}{h^3} \frac{2kT}{\sqrt{\pi}} (\mu_B H)^{3/2} \sum_{l=1}^\infty \frac{(-1)^l}{l^{3/2}} \frac{\cos\!\bigl( l\pi\mu/(\mu_B H) - \pi/4 \bigr)}{\sinh\!\bigl( \pi^2 l kT / (\mu_B H) \bigr)}
}
\qquad \cdots (7)
```

## 5. 磁化率の振動項

### 5.1 微分計算

磁化率の振動項は、

```math
\chi_{\text{osc}} = -\frac{1}{VH} \left( \frac{\partial F_{\text{osc}}}{\partial H} \right)_{T,V,N}
```

式 (7) を $H$ で微分する．
$\mu$ の $H$ 依存性は振動項に寄与しない（なめらかな部分のみ）として無視できる．
主要な寄与は以下の 2 つの項から来る：

**第1項**： 前置因子 $(\mu_B H)^{3/2}$ の微分
```math
\frac{\partial}{\partial H} (\mu_B H)^{3/2} 
= \frac{3}{2} (\mu_B H)^{1/2} \mu_B^2 \cdot \frac{1}{H}
```

**第2項**： $\cos\!\bigl( l\pi\mu/(\mu_B H) - \pi/4 \bigr)$ の微分
```math
\frac{\partial}{\partial H} \cos\!\left( \frac{l\pi\mu}{\mu_B H} - \frac{\pi}{4} \right) 
= \frac{l\pi\mu}{H (\mu_B H)} \sin\!\left( \frac{l\pi\mu}{\mu_B H} - \frac{\pi}{4} \right)
```

### 5.2 主要項の抽出

$kT \lesssim \mu_B H$ の条件では， $\sinh(x) \approx 1$ ( $x = \pi^2 l kT / (\mu_B H) \gtrsim \pi^2 l$ ) としてよい．
第1項は $(\mu_B H)^{1/2}$ の効きをするのに対し，第2項は $(\mu_B H)^{1/2} \cdot (\mu_B H)^{-1} \cdot \mu = (\mu_B H)^{-1/2}\mu$ の効きをし， $\mu \gg \mu_B H$ の条件で第2項が支配的となる．

したがって，第2項のみを残すと，

```math
\chi_{\text{osc}} 
\cong -\frac{1}{VH} 
\cdot V \frac{(2\pi m)^{3/2}}{h^3} \frac{2kT}{\sqrt{\pi}} (\mu_B H)^{3/2} 
\sum_{l=1}^\infty \frac{(-1)^l}{l^{3/2}} \frac{1}{\sinh(\pi^2 l kT / (\mu_B H))} 
\cdot \left[ -\frac{l\pi\mu}{H (\mu_B H)} \sin\!\left( \frac{l\pi\mu}{\mu_B H} - \frac{\pi}{4} \right) \right]
```

ここで $H$ の幂を整理すると， $(1/H) \cdot (\mu_B H)^{3/2} \cdot (\mu_B H)^{-1} \cdot (1/H) = (\mu_B H)^{1/2} / H^2$ となる．
$\sin(x-\pi/4) = \frac{1}{\sqrt{2}}[\sin x - \cos x]$ の位相因子を $\sin(l\pi\mu/(\mu_B H)+\pi/4)$ に書き換えると（ $-\sin\theta = \sin(\theta-\pi/2)$ を使用），

```math
\boxed{
\chi_{\text{osc}} 
\cong \mu_B^2 \frac{(2\pi m)^{3/2}}{h^3} \frac{2\sqrt{\pi}\,kT}{(\mu_B H)^2} \left( \frac{\mu_B H}{\mu} \right)^{\!\!1/2} 
\sum_{l=1}^\infty \frac{(-1)^l}{l^{1/2}} \frac{\sin\!\bigl( l\pi\mu/(\mu_B H) - \pi/4 \bigr)}{\sinh\!\bigl( \pi^2 l kT / (\mu_B H) \bigr)}
}
\qquad \cdots (8)
```

ただし， $(\mu_B H/\mu)$ および $(kT/\mu)$ がさらに掛かった項は無視した．

### 5.3 電子数密度での表現

電子数密度 $n \cong 4\pi(2m\mu)^{3/2} / (3h^3)$ （スピンを考えていないことに注意）を使うと， $l=1$ の項だけを残して

```math
\boxed{
\chi_{\text{osc}} 
\cong -\frac{n\mu_B^2}{kT} \frac{3\pi}{2} \left( \frac{kT}{\mu_B H} \right)^{\!\!2} \left( \frac{\mu_B H}{\mu} \right)^{\!\!1/2} \frac{\sin\!\bigl( \pi\mu/(\mu_B H) - \pi/4 \bigr)}{\sinh\!\bigl( \pi^2 kT / (\mu_B H) \bigr)}
}
\qquad \cdots (9)
```

### 5.4 振動周期と観測条件

式 (8), (9) より， $\chi_{\text{osc}} / \bigl[ H^{3/2} \sinh\{\pi^2 kT/(\mu_B H)\} \bigr]$ が $1/H$ の周期関数であり，その周期は $2\mu_B/\mu$ であることがわかる．

このような振動を観測するためには $kT \lesssim \mu_B H$ が必要であり，これは式 (9) の分母の $\sinh\{\pi^2 kT/(\mu_B H)\}$ があまり大きくならない条件でもある．
$\mu_B H = \pi^2 kT$ となる磁場は $H = 1.469\times 10^5 \times T \text{Oe}$ ( $T$ は K) で，極低温でないと観測が困難であることを示す．

また $\chi_{\text{osc}} \propto (\mu_B H/\mu)^{1/2}$ があるため，なめらかな部分に比べて小さい．
測定には非常な精度を要する．
