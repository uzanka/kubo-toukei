# 演習問題【8-C-30】

## 解答

## 1. 方針

磁場中の自由電子について，1 電子分配関数 $Z(\beta)$ から状態密度 $D(\varepsilon)$ を逆 Laplace 変換で求める．
低温かつ強磁場の条件

```math
k_BT\lesssim \mu_B H\ll \mu
```

では，フェルミ面近傍の Landau 準位の占有が磁場とともに周期的に変化し，磁化に振動項（de Haas–van Alphen 振動）が現れる．

以下では，電子のスピンによる Zeeman 分裂を含め，磁場 $H$ は $B\simeq\mu_0H$ （SI 単位系）とする．
教科書が Gaussian 単位系を用いている場合は，対応する磁場因子を読み替える必要がある．

## 2. Landau 準位と状態密度

磁場方向を $z$ 軸に取ると，軌道運動のエネルギーは

```math
\varepsilon_{n,k_z,s}
=\frac{\hbar^2 k_z^2}{2m}
+\hbar\omega_c\left(n+\frac12\right)
+s\,\mu_B B,
\qquad
\omega_c=\frac{eB}{m},
```

である．
ここで $n=0,1,\ldots$ ， $s=\pm1$ はスピンの符号である（符号の取り方はスピン項の定義に依存する）．

面積 $A$ あたりの各 Landau 準位の軌道縮退度は $eB/(2\pi\hbar)$ ．
$k_z$ の状態を連続化し，ヒントの逆 Laplace 変換を用いると，状態密度は滑らかな平均項に加えて，Landau 準位の離散性に由来する振動項を持つ．
Poisson 和公式で準位和を変換すると，三次元自由電子気体の振動状態密度は，フェルミエネルギー近傍で概略

```math
D_{\mathrm{osc}}(\varepsilon,B)
\propto B^{1/2}
\sum_{p=1}^{\infty}\frac{1}{p^{1/2}}
\cos\!\left(
\frac{\pi p\,\varepsilon^2}{\hbar eB/m}
-\frac{\pi}{4}
\right)
```

という高調波和になる．
位相の定数や前置係数は，状態密度を体積あたりで定義するか，スピン縮退を別に数えるかなどの規約に依存する．
重要なのは，位相が $1/B$ に比例することである．

## 3. 磁化の振動項

磁化は大正準ポテンシャル $\Omega$ から

```math
M_{\mathrm{osc}}=-\left(\frac{\partial\Omega_{\mathrm{osc}}}{\partial B}\right)_{\mu,T}
```

として得られる．
低温極限では，三次元自由電子系の主要な振動項は Lifshitz–Kosevich 型の高調波和で表される：

```math
\boxed{
M_{\mathrm{osc}}
\propto B^{1/2}
\sum_{p=1}^{\infty}
\frac{R_T(p)R_D(p)}{p^{3/2}}
\sin\!\left(
2\pi p\,\frac{F}{B}-\frac{\pi}{4}+\phi_s
\right)
}
```

ここで

```math
F=\frac{\hbar}{2\pi e}A_F,\qquad
A_F=\pi k_F^2,\qquad
k_F=\frac{\sqrt{2m\mu}}{\hbar}
```

は de Haas–van Alphen 振動の基本周波数（ $1/B$ に関する周波数）である．
$A_F$ はフェルミ面の磁場に垂直な極値断面積， $\phi_s$ はスピン分裂に伴う位相である．
自由電子球では

```math
F=\frac{\mu m}{e\hbar}.
```

有限温度による減衰因子は

```math
R_T(p)=\frac{X_p}{\sinh X_p},\qquad
X_p=\frac{2\pi^2 p\,k_BT}{\hbar\omega_c},
```

であり，散乱による準位の幅を Lorentz 型で近似すると Dingle 因子は

```math
R_D(p)=\exp\!\left(-\frac{2\pi^2p\,k_BT_D}{\hbar\omega_c}\right).
```

$T_D$ は Dingle 温度で，理想的な無散乱系では $R_D=1$ ．
問題の理想化された条件では，まず $T\to0$ ， $R_D=1$ とすればよい．

## 4. 結論

求める振動項の本質は

```math
\boxed{
M_{\mathrm{osc}}\sim
B^{1/2}\sum_{p=1}^{\infty}p^{-3/2}
\sin\!\left(2\pi p\,\frac{F}{B}-\frac{\pi}{4}+\phi_s\right)
}
```

である．
したがって磁化率の振動も $1/B$ に対して周期的であり，基本周波数はフェルミ面の極値断面積で決まる．
磁化率を $\chi=\partial M/\partial H$ と定義する場合は，上式をさらに $H$ で微分するため，振動位相と磁場依存の前置因子が変わる．

**注意：** 問題文にある「前問」および「問題 [17]」の具体的な式が提示されていないため，ここでは一般的な三次元自由電子系の Lifshitz–Kosevich 形を示した．
教科書独自の規約（SI/Gaussian 単位系，スピンの数え方， $D(\varepsilon)$ の定義）により，厳密な数値係数や位相表記は変わり得る．
