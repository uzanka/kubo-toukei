# 演習問題【8-C-23】

## 解答

相対論的なエネルギーをもつスピン $1/2$ の Fermi 粒子について，粒子数 $N$ ，内部エネルギー $E$ ，圧力 $p$ の積分表示を導き，さらに絶対零度での値を求める．

以下では，粒子のエネルギーに静止エネルギー $mc^2$ を含める．
また，スピンの二つの状態を考慮し，スピン縮重度を $2$ とする．

### 1．運動量空間における状態数

体積 $V$ の中で，運動量が微小体積 $d^3p$ に入る量子状態の数は，スピンの重率 $2$ を考慮すると，

```math
d\Gamma=\frac{2V}{h^3}\,d^3p
```

である．
ここで $h$ はプランク定数である．
運動量の大きさを $p=|\boldsymbol p|$ とすると，球座標では

```math
d^3p=4\pi p^2\,dp
```

となるため，

```math
d\Gamma=\frac{8\pi V}{h^3}p^2\,dp
\tag{1}
```

を得る．

問題の指示に従い，

```math
p=mc\sinh\theta
```

と変数変換する．
両辺を微分すれば，

```math
dp=mc\cosh\theta\,d\theta
```

である．
したがって，

```math
p^2\,dp
=m^3c^3\sinh^2\theta\cosh\theta\,d\theta
```

となる．
式(1)は，

```math
\boxed{
d\Gamma=
\frac{8\pi Vm^3c^3}{h^3}
\sinh^2\theta\cosh\theta\,d\theta
}
\tag{2}
```

と書ける．

### 2．粒子数 $N$ の導出

相対論的な粒子のエネルギーは，

```math
\varepsilon=c\sqrt{p^2+m^2c^2}
```

で与えられる．
$p=mc\sinh\theta$ を代入すると，

```math
\begin{aligned}
\varepsilon
&=c\sqrt{m^2c^2\sinh^2\theta+m^2c^2}\\
&=mc^2\sqrt{\sinh^2\theta+1}\\
&=mc^2\cosh\theta
\end{aligned}
```

となる．
最後の等式では，双曲線関数の恒等式

```math
\cosh^2\theta-\sinh^2\theta=1
```

を用いた．

温度 $T$ ，化学ポテンシャル $\mu$ における Fermi 粒子の平均占有数は，

```math
f(\varepsilon)=
\frac{1}{e^{\beta(\varepsilon-\mu)}+1},
\qquad
\beta=\frac{1}{kT}
```

である．
ここで $k$ はボルツマン定数である．
粒子数 $N$ は各状態の平均占有数をすべての状態について足し合わせた量であるから，

```math
N=\int f(\varepsilon)\,d\Gamma
```

となる．
式(2)と $\varepsilon=mc^2\cosh\theta$ を代入すると，

```math
\boxed{
N=
8\pi\frac{m^3c^3}{h^3}V
\int_0^\infty
\frac{\sinh^2\theta\cosh\theta}
{e^{-\beta\mu+\beta mc^2\cosh\theta}+1}
\,d\theta
}
\tag{3}
```

が得られる．
これが求める粒子数の式である．

### 3．内部エネルギー $E$ の導出

内部エネルギーは，粒子数の場合と同様に，各状態のエネルギーと平均占有数の積をすべての状態について足し合わせたものである．
したがって，

```math
E=\int\varepsilon f(\varepsilon)\,d\Gamma
```

である．
ここで $\varepsilon=mc^2\cosh\theta$ を用い，式(2)を代入すると，

```math
\begin{aligned}
E={}&
\frac{8\pi m^3c^3}{h^3}V
\int_0^\infty
mc^2\cosh\theta\,
\sinh^2\theta\cosh\theta\\
&\qquad\times
\frac{d\theta}
{e^{-\beta\mu+\beta mc^2\cosh\theta}+1}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
E=
8\pi\frac{m^4c^5}{h^3}V
\int_0^\infty
\frac{\sinh^2\theta\cosh^2\theta}
{e^{-\beta\mu+\beta mc^2\cosh\theta}+1}
\,d\theta
}
\tag{4}
```

を得る．
このエネルギーには静止エネルギーも含まれていることに注意する．

### 4．圧力 $p$ の導出

圧力を求めるために，大分配関数 $\Xi$ を用いる．
Fermi 粒子系のグランドポテンシャル $\Omega$ は，

```math
\Omega=-kT\ln\Xi
```

である．
一様な系では $\Omega=-pV$ なので，

```math
\boxed{pV=kT\ln\Xi}
\tag{5}
```

となる．

Fermi 粒子の各状態は，粒子が入っていない状態と粒子が1個入っている状態のいずれかであるため，その状態に対応する大分配関数は

```math
1+e^{-\beta(\varepsilon-\mu)}
```

である．
したがって，全状態について積を取れば，

```math
\Xi=\prod_i
\left[1+e^{-\beta(\varepsilon_i-\mu)}\right]
```

となり，対数を取ると，

```math
\ln\Xi=
\sum_i\ln\left[1+e^{-\beta(\varepsilon_i-\mu)}\right]
```

を得る．
運動量空間の状態数を用いて和を積分に置き換えれば，

```math
\begin{aligned}
p
={}&
\frac{8\pi m^3c^3}{h^3}kT
\int_0^\infty
\sinh^2\theta\cosh\theta\\
&\qquad\times
\ln\left[
1+e^{-\beta(mc^2\cosh\theta-\mu)}
\right]d\theta
\end{aligned}
\tag{6}
```

となる．

ここで，部分積分を行う．

```math
u=\ln\left[
1+e^{-\beta(mc^2\cosh\theta-\mu)}
\right],
\qquad
dv=\sinh^2\theta\cosh\theta\,d\theta
```

と置くと，

```math
v=\frac13\sinh^3\theta
```

である．
また， $u$ の微分は，

```math
du=
-\frac{\beta mc^2\sinh\theta}
{e^{\beta(mc^2\cosh\theta-\mu)}+1}\,d\theta
```

となる．
部分積分の境界項は，

```math
\left[
\frac13\sinh^3\theta
\ln\left(1+e^{-\beta(mc^2\cosh\theta-\mu)}\right)
\right]_0^\infty=0
```

である．
$\theta=0$ では $\sinh\theta=0$ であり， $\theta\to\infty$ では対数項が指数関数的に減少するためである．

したがって，

```math
\begin{aligned}
&\int_0^\infty
\sinh^2\theta\cosh\theta
\ln\left(1+e^{-\beta(mc^2\cosh\theta-\mu)}\right)
\,d\theta\\
&\qquad=
\frac{\beta mc^2}{3}
\int_0^\infty
\frac{\sinh^4\theta}
{e^{\beta(mc^2\cosh\theta-\mu)}+1}
\,d\theta
\end{aligned}
```

となる．
これを式(6)に代入し， $\beta kT=1$ を用いて整理すると，

```math
\boxed{
p=
\frac{8\pi}{3}\frac{m^4c^5}{h^3}
\int_0^\infty
\frac{\sinh^4\theta}
{e^{-\beta\mu+\beta mc^2\cosh\theta}+1}
\,d\theta
}
\tag{7}
```

が得られる．
これが求める圧力の式である．

### 5．絶対零度 $T=0$ での粒子数，内部エネルギー，圧力

絶対零度では $\beta\to\infty$ となり，Fermi 分布は階段関数になる．
すなわち，

```math
f(\varepsilon)=
\begin{cases}
1,&\varepsilon<\mu_0,\\
0,&\varepsilon>\mu_0
\end{cases}
```

である．
ここで $\mu_0$ は絶対零度における化学ポテンシャルであり，静止エネルギーを含む．

最大占有運動量を Fermi 運動量 $p_F$ とし，

```math
p_F=mc\sinh\theta_0,
\qquad
\mu_0=mc^2\cosh\theta_0
\tag{8}
```

と定義する．
エネルギーは $\theta$ とともに単調に増加するため，占有状態は $0\leq\theta\leq\theta_0$ に限られる．
したがって，式(3)，(4)，(7)の積分範囲を $0$ から $\theta_0$ までに置き換えればよい．

#### （1）粒子数

式(3)より，

```math
\frac NV=
8\pi\frac{m^3c^3}{h^3}
\int_0^{\theta_0}
\sinh^2\theta\cosh\theta\,d\theta
```

となる．

```math
\int\sinh^2\theta\cosh\theta\,d\theta
=\frac13\sinh^3\theta
```

であるから，

```math
\frac NV=
\frac{8\pi}{3}\frac{m^3c^3}{h^3}
\sinh^3\theta_0
```

を得る．
$p_F=mc\sinh\theta_0$ を用いると，

```math
\boxed{
\frac NV=\frac{8\pi}{3h^3}p_F^3
}
\tag{9}
```

となる．
したがって，粒子数密度 $n=N/V$ が与えられれば，

```math
\boxed{
p_F=h\left(\frac{3n}{8\pi}\right)^{1/3}
}
\tag{10}
```

によって Fermi 運動量が定まり，式(8)から $\mu_0$ も決まる．

#### （2）内部エネルギー

式(4)より，

```math
\frac EV=
8\pi\frac{m^4c^5}{h^3}
\int_0^{\theta_0}
\sinh^2\theta\cosh^2\theta\,d\theta
```

となる．
双曲線関数の恒等式から，

```math
\sinh^2\theta\cosh^2\theta
=\frac18(\cosh4\theta-1)
```

である．
よって，

```math
\begin{aligned}
\int_0^{\theta_0}
\sinh^2\theta\cosh^2\theta\,d\theta
&=\frac18
\left[\frac14\sinh4\theta-\theta\right]_0^{\theta_0}\\
&=\frac1{32}(\sinh4\theta_0-4\theta_0)
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\frac EV=
\frac{\pi}{4}\frac{m^4c^5}{h^3}
\left(\sinh4\theta_0-4\theta_0\right)
}
\tag{11}
```

を得る．
これは静止エネルギーを含む全エネルギー密度である．

#### （3）圧力

式(7)より，

```math
p=
\frac{8\pi}{3}\frac{m^4c^5}{h^3}
\int_0^{\theta_0}\sinh^4\theta\,d\theta
```

となる．
恒等式

```math
\sinh^4\theta
=\frac18(\cosh4\theta-4\cosh2\theta+3)
```

を用いると，

```math
\begin{aligned}
\int_0^{\theta_0}\sinh^4\theta\,d\theta
&=\frac18
\left[
\frac14\sinh4\theta
-2\sinh2\theta+3\theta
\right]_0^{\theta_0}\\
&=\frac18
\left(
\frac14\sinh4\theta_0
-2\sinh2\theta_0+3\theta_0
\right)
\end{aligned}
```

である．
したがって，

```math
\boxed{
p=
\frac{\pi}{3}\frac{m^4c^5}{h^3}
\left(
\frac14\sinh4\theta_0
-2\sinh2\theta_0+3\theta_0
\right)
}
\tag{12}
```

が得られる．

### 結論

相対論的な Fermi 粒子について，運動量の大きさを $p=mc\sinh\theta$ と変数変換することで，粒子数，内部エネルギー，圧力はそれぞれ式(3)，(4)，(7)の積分表示となる．

絶対零度では Fermi 分布が階段関数となるため，積分範囲は $0\leq\theta\leq\theta_0$ に限られ，粒子数密度，内部エネルギー密度，圧力は，

```math
\boxed{
\frac NV=\frac{8\pi}{3h^3}p_F^3
}
```

```math
\boxed{
\frac EV=
\frac{\pi m^4c^5}{4h^3}
\left(\sinh4\theta_0-4\theta_0\right)
}
```

```math
\boxed{
p=
\frac{\pi m^4c^5}{3h^3}
\left(
\frac14\sinh4\theta_0-2\sinh2\theta_0+3\theta_0
\right)
}
```

となる．
ここで，

```math
p_F=mc\sinh\theta_0,
\qquad
\mu_0=mc^2\cosh\theta_0
```

である．
粒子数密度が決まれば Fermi 運動量 $p_F$ ，したがって $\theta_0$ と絶対零度の化学ポテンシャル $\mu_0$ が決定される．
