# 例題【8-R-4】

## 解答

### 1．ドナー準位の自由エネルギー

単位体積中に $N_D$ 個のドナー原子が存在し，そのうち $n_D$ 個が電子を1個ずつ持っているものとする．
一つのドナー準位には電子が最大1個しか入らないため，各ドナーは，電子を持たない状態，またはスピンが異なる2通りの状態のいずれかをとる．

したがって，電子を持つドナーの配置とスピン状態の組み合わせの総数 $W$ は，

```math
W=\frac{N_D!}{n_D!(N_D-n_D)!}\,2^{n_D}
\tag{1}
```

である．
ここで，二項係数は $N_D$ 個のドナーから電子を持つ $n_D$ 個を選ぶ方法の数であり， $2^{n_D}$ は各電子のスピン状態の選び方の数である．

伝導帯の下端をエネルギーの原点とする．
ドナー準位は伝導帯の下端より $E_D$ だけ低いため，ドナー準位に電子が1個入ると，エネルギーは $-E_D$ となる．
よって，ドナーに属する電子のエネルギーの総和は $-n_DE_D$ である．

自由エネルギー $F$ は，内部エネルギーから温度とエントロピーの積を差し引いたものである．
エントロピーを $S=k\log W$ とすれば，

```math
F=-n_DE_D-kT\log W
\tag{2}
```

となる．
式 (1) を代入すると，

```math
F=-n_DE_D
-kT\log\left\{
\frac{N_D!}{n_D!(N_D-n_D)!}\,2^{n_D}
\right\}
\tag{3}
```

を得る．

ここで，Stirling の公式

```math
\log M!\approx M\log M-M
```

を用いる．
これを式 (3) に適用して整理すると，

```math
\begin{aligned}
F\approx{}&-n_DE_D\\
&-kT\left\{
n_D\log2
-n_D\log\frac{n_D}{N_D}
-(N_D-n_D)\log\frac{N_D-n_D}{N_D}
\right\}
\end{aligned}
\tag{4}
```

となる．
Stirling の公式は， $N_D$ ， $n_D$ ， $N_D-n_D$ が十分大きい場合に有効な近似である．

### 2．ドナー準位の電子の化学ポテンシャル

化学ポテンシャルは，温度と体積を一定に保ったとき，粒子数を変化させた際の自由エネルギーの変化率である．
したがって，ドナー準位にある電子の化学ポテンシャルは

```math
\mu=\frac{\partial F}{\partial n_D}
\tag{5}
```

で与えられる．

式 (4) を $n_D$ で微分すると，

```math
\begin{aligned}
\mu
&=-E_D-kT\left\{
\log2-\log\frac{n_D}{N_D-n_D}
\right\}\\
&=-E_D-kT\log\frac{2(N_D-n_D)}{n_D}
\end{aligned}
\tag{6}
```

となる．
これを整理すれば，

```math
\log\frac{n_D}{2(N_D-n_D)}
=\frac{\mu+E_D}{kT}
```

であるから，

```math
\boxed{
\frac{n_D}{N_D-n_D}
=2e^{(\mu+E_D)/(kT)}
}
\tag{7}
```

を得る．
すなわち，

```math
\boxed{
e^{\mu/(kT)}
=\frac{n_D}{2(N_D-n_D)}e^{-E_D/(kT)}
}
\tag{8}
```

である．
係数 $2$ は，ドナー準位に電子が存在するときに許される2通りのスピン状態に由来する．

### 3．伝導帯の電子密度

次に，伝導帯に存在する電子の密度 $n$ を求める．
伝導帯の下端をエネルギーの原点とすると，伝導電子のエネルギーは

```math
\varepsilon=\frac{\mathbf{q}^2}{2m^*}
\tag{9}
```

である．
ここで， $\mathbf{q}$ は電子の運動量， $m^*$ は伝導電子の実効質量である．

伝導電子は縮退していないため，Fermi-Dirac 分布をボルツマン分布で近似できる．
したがって，電子の占有確率は

```math
f(\varepsilon)\approx e^{-(\varepsilon-\mu)/(kT)}
\tag{10}
```

となる．

運動量空間における状態数を数えると，一単位体積当たりの伝導電子密度は，スピンの自由度2を考慮して，

```math
n=\frac{2}{h^3}\int
e^{-(\mathbf{q}^2/(2m^*)-\mu)/(kT)}
\,d^3q
\tag{11}
```

で与えられる．
ここで $h$ は Planck 定数であり，運動量空間の体積 $h^3$ ごとに1つの状態が対応するものとしている．

指数関数を分離すると，

```math
n=\frac{2}{h^3}e^{\mu/(kT)}
\int e^{-\mathbf{q}^2/(2m^*kT)}\,d^3q
\tag{12}
```

となる．
三次元のガウス積分

```math
\int e^{-\mathbf{q}^2/(2m^*kT)}\,d^3q
=(2\pi m^*kT)^{3/2}
\tag{13}
```

を用いれば，

```math
n=2\left(\frac{2\pi m^*kT}{h^2}\right)^{3/2}
e^{\mu/(kT)}
\tag{14}
```

を得る．

ここで，有効状態密度 $N_c$ を

```math
\boxed{
N_c=2\left(\frac{2\pi m^*kT}{h^2}\right)^{3/2}
=2\left(\frac{m^*kT}{2\pi\hbar^2}\right)^{3/2}
}
\tag{15}
```

と定義する．
ただし， $\hbar=h/(2\pi)$ は換算 Planck 定数である．

式 (14) は，

```math
\boxed{n=N_ce^{\mu/(kT)}}
\tag{16}
```

と書ける．

### 4．題意の関係式の導出

式 (8) より，

```math
e^{\mu/(kT)}
=\frac{n_D}{2(N_D-n_D)}e^{-E_D/(kT)}
```

である．
これを式 (16) に代入すると，

```math
n=N_c\frac{n_D}{2(N_D-n_D)}
e^{-E_D/(kT)}
\tag{17}
```

となる．
両辺に $(N_D-n_D)/n_D$ を掛けて整理すれば，

```math
\boxed{
\frac{n(N_D-n_D)}{n_D}
=\frac12 N_c e^{-E_D/(kT)}
}
\tag{18}
```

が得られる．
これで題意が示された．

### 5．物理的意味

式 (18) は，ドナー原子の電離と伝導電子の生成が熱平衡にあることを表す関係式である．

ドナーが電子を1個持っている状態を $D^0$ ，電子を失った状態を $D^+$ ，伝導帯の電子を $e^-$ とすると，次の解離平衡を考えることができる．

```math
D^0\rightleftharpoons D^+ + e^-
\tag{19}
```

それぞれの密度は，

```math
[D^0]=n_D,\qquad
[D^+]=N_D-n_D,\qquad
[e^-]=n
\tag{20}
```

である．
よって，式 (18) は，

```math
\boxed{
\frac{[D^+][e^-]}{[D^0]}
=\frac12N_ce^{-E_D/(kT)}
}
\tag{21}
```

となる．
これは，ドナーの電離に関する質量作用の法則に対応する．
右辺は温度 $T$ とドナー準位の深さ $E_D$ によって決まる．

特に，温度が低いと $e^{-E_D/(kT)}$ は小さくなり，ドナーから伝導帯へ電子が熱励起されにくくなる．
一方，温度が上がるとこの因子は増加し，ドナーが電離して伝導電子を供給しやすくなる．
このように，式 (18) は，ドナー準位に束縛された電子と伝導帯の自由電子との間の熱平衡を記述する式である．

### 注意：問題文の $N_c$ の定義について

問題文では，

```math
N_c=2\left(\frac{2\pi m^*kT}{\hbar^2}\right)^{3/2}
```

と記載されているが，これは通常の有効状態密度の定義と一致しない．
運動量空間の状態数から正しく導かれる定義は，式 (15) の

```math
N_c=2\left(\frac{m^*kT}{2\pi\hbar^2}\right)^{3/2}
```

である．
したがって，問題文の $\hbar$ を用いた定義は誤植と考えられる．

もし問題文に記載された定義を文字どおり採用するなら，その $N_c$ を用いた関係式は

```math
\frac{n(N_D-n_D)}{n_D}
=\frac{N_c}{2(2\pi)^3}e^{-E_D/(kT)}
```

となる．
題意の式 (18) を得るには， $N_c$ を式 (15) の標準的な定義に修正する必要がある．
