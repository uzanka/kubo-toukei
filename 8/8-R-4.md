# 演習問題【8-R-4】

## 解答

本問題では，ドナー準位にある電子の数 $n_D$ と，伝導帯にある電子の数 $n$ の関係式を導出する．

### 1．ドナー準位における電子の数 $n_D$

まず，単位体積あたり $N_D$ 個のドナー原子が存在すると考える．
各ドナー原子は，以下の３つの状態のいずれかをとることができる．

1. 電子を含まない状態（ドナーがイオン化して $D^+$ となった状態）
2. スピンが $+$ の電子を１個含んでいる状態
3. スピンが $-$ の電子を１個含んでいる状態

問題文の条件より，一つのドナー準位には同時に２個の電子は入りえない（パウリの排他原理に基づく制限）．

ここで，ドナー準位にある電子の総数を $n_D$ とすると，電子を含まないドナーの数は $N_D - n_D$ である．
電子を含んでいるドナーは $n_D$ 個あるが，それぞれの電子は $+$ または $-$ の２つのスピン状態のいずれかをとることができる．
したがって，電子の状態の組み合わせの数は $2^{n_D}$ 通りとなる．

ドナーの配置に関する微視的状態の総数 $W$ は，次のように書ける．

$$W = \frac{N_D!}{n_D! (N_D - n_D)!} \cdot 2^{n_D}$$

ここで， $\frac{N_D!}{n_D! (N_D - n_D)!}$ は $N_D$ 個の場所から $n_D$ 個の電子を入れる場所を選ぶ組み合わせの数であり，それにスピンの自由度 $2^{n_D}$ を乗じている．

系の自由エネルギー $F$ は，エントロピー $S = k T \log W$ を用いて次のように表される（ここで $E_D$ はドナー準位のエネルギー，伝導帯の下端を基準として $-E_D$ としているため，電子が１個入るごとにエネルギーが $-E_D$ ずつ変化すると考える）．

$$F = -n_D E_D - k T \log W$$

```math
F = -n_D E_D - k T \log \left\{ \frac{N_D!}{n_D! (N_D - n_D)!} \cdot 2^{n_D} \right\}
```

Stirling の公式 $\log N! \approx N \log N - N$ を用いてこれを近似すると，

$$\log W \approx (N_D \log N_D - N_D) - (n_D \log n_D - n_D) - ((N_D - n_D) \log (N_D - n_D) - (N_D - n_D)) + n_D \log 2$$

$$\log W \approx N_D \log N_D - n_D \log n_D - (N_D - n_D) \log (N_D - n_D) + n_D \log 2$$

これを整理すると，

$$\log W \approx n_D \log 2 - n_D \log \frac{n_D}{N_D} - (N_D - n_D) \log \frac{N_D - n_D}{N_D}$$

となる．
したがって，自由エネルギー $F$ は，

```math
F = -n_D E_D - k T \left\{ n_D \log 2 - n_D \log \frac{n_D}{N_D} - (N_D - n_D) \log \frac{N_D - n_D}{N_D} \right\}
```

である．

ドナー準位にある電子の化学ポテンシャル $\mu$ は， $F$ を $n_D$ で微分することで得られる．

```math
\mu = \frac{\partial F}{\partial n_D} = -E_D - k T \left\{ \log 2 - \left( \log \frac{n_D}{N_D} + n_D \cdot \frac{1}{n_D} \right) - \left( - \log \frac{N_D - n_D}{N_D} + (N_D - n_D) \cdot \frac{-1}{N_D - n_D} \right) \right\}
```

（計算を簡略化するため， $\frac{\partial}{\partial n_D} [n_D \log n_D] = \log n_D + 1$ を用いる）

```math
\mu = -E_D - k T \left\{ \log 2 - (\log n_D + 1) + (\log (N_D - n_D) + 1) - \log N_D \right\}
```

```math
\mu = -E_D - k T \left\{ \log 2 - \log \frac{n_D}{N_D} + \log \frac{N_D - n_D}{N_D} \right\}
```

```math
\mu = -E_D - k T \left\{ \log 2 - \log \frac{n_D}{N_D - n_D} \right\}
```

これを整理すると，

$$\frac{\mu + E_D}{k T} = -\log 2 + \log \frac{n_D}{N_D - n_D} = \log \frac{n_D}{2(N_D - n_D)}$$

よって，

$$\frac{n_D}{N_D - n_D} = 2 e^{(\mu + E_D)/k T} \quad \cdots (A)$$

が得られる．

### 2．伝導帯における電子の数 $n$

次に，伝導帯に存在する電子の数 $n$ を考える．
伝導帯電子は縮退していないため，フェルミ・ディラック分布はボルツマン分布で近似できる．
単位体積あたりの電子密度 $n$ は，状態密度 $g(\epsilon)$ を用いて次のように書ける．

$$n = \int_0^\infty g(\epsilon) f(\epsilon) d\epsilon$$

ここで， $g(\epsilon) = \frac{2}{h^3} (2\pi m^*)^{3/2} \epsilon^{1/2}$ であり， $f(\epsilon) = e^{-(\epsilon - \mu)/kT}$ である．

$$n = \frac{2}{h^3} (2\pi m^*)^{3/2} \int_0^\infty \epsilon^{1/2} e^{-(\epsilon - \mu)/kT} d\epsilon$$

$$n = \frac{2}{h^3} (2\pi m^*)^{3/2} e^{\mu/kT} \int_0^\infty \epsilon^{1/2} e^{-\epsilon/kT} d\epsilon$$

ガウス積分（またはガンマ関数 $\Gamma(3/2) = \frac{\sqrt{\pi}}{2}$ ）を用いると，

$$\int_0^\infty \epsilon^{1/2} e^{-\epsilon/kT} d\epsilon = (kT)^{3/2} \frac{\sqrt{\pi}}{2}$$

となる．
これを代入すると，

$$n = \frac{2}{h^3} (2\pi m^*)^{3/2} e^{\mu/kT} (kT)^{3/2} \frac{\sqrt{\pi}}{2} = 2 \left( \frac{2\pi m^* kT}{h^2} \right)^{3/2} e^{\mu/kT}$$

問題文の定義 $N_c = 2(2\pi m^* kT/\hbar^2)^{3/2}$ （※ここで $\hbar = h/2\pi$ であることに注意）を用いると，

$$n = N_c e^{\mu/kT} \quad \cdots (B)$$

となる．

### 3．関係式の導出

式 (A) と 式 (B) から，共通の項である $e^{\mu/kT}$ を消去する．
式 (A) より， $e^{\mu/kT} = \frac{1}{2} \frac{n_D}{N_D - n_D} e^{-E_D/kT}$ である．
これを式 (B) に代入すると，

$$n = N_c \cdot \frac{1}{2} \frac{n_D}{N_D - n_D} e^{-E_D/kT}$$

両辺に $\frac{N_D - n_D}{n_D}$ を掛けると，

$$\frac{n(N_D - n_D)}{n_D} = \frac{1}{2} N_c e^{-E_D/kT}$$

となり，題意の関係式が示された．

### 4．意味の解釈

この関係式は，半導体中のドナー原子の電離状態と伝導帯の電子密度の間の平衡を表している．
具体的には，以下の解離平衡反応を考えている．

$$\text{D} \rightleftharpoons \text{D}^+ + \text{e}$$

ここで， $\text{D}$ は電子を持つドナー原子， $\text{D}^+$ は電子を失ったドナーイオン， $\text{e}$ は伝導帯の自由電子である．
この平衡定数を $K(T)$ とすると，質量作用の法則より，

$$K(T) = \frac{[\text{D}^+][\text{e}]}{[\text{D}]} = \frac{(N_D - n_D)n}{n_D}$$

が得られる．
題意の式を書き直すと，

$$\frac{n(N_D - n_D)}{n_D} = K(T)$$

となり，導出した式はまさにこの質量作用の法則に対応している．
つまり，温度 $T$ やドナーのエネルギー準位 $E_D$ によって決まる一定の比率で，ドナーからの電子の放出と吸収が平衡状態にあることを示している．

## 解説

本問題は，統計力学的な手法（自由エネルギーの最小化，あるいは分配関数）を用いて，半導体のキャリア密度の基礎となる関係式を導出させるものである．

### ポイント 1：ドナーの統計的性質

ドナー原子は，スピンの自由度（ $+$ または $-$ ）を持っていることが重要である．
そのため，電子が $n_D$ 個入っている状態の数は， $n_D$ 個の場所を選ぶ組み合わせに加えて，それぞれの電子の $2$ 通りのスピン状態を考慮して $2^{n_D}$ 倍される．
これが式 (1) の $2^{n_D}$ の由来である．

### ポイント 2：化学ポテンシャルの役割

化学ポテンシャル $\mu$ は，「粒子を１個追加したときに系に加わるエネルギーの変化」を意味する．
ドナー準位における $\mu$ を求めることは，ドナーに電子がどの程度詰まっているか（占有率）を決定することに等しい．

### ポイント 3：伝導帯の電子密度

伝導帯の電子密度 $n$ の計算では，状態密度 $g(\epsilon)$ とフェルミ分布 $f(\epsilon)$ の積を全エネルギー範囲で積分している．
「縮退していない」という条件は，フェルミ準位が伝導帯の下端から十分に離れており，ボルツマン分布（指数関数的な分布）で近似できることを意味している．

### ポイント 4：物理的意味（質量作用の法則）

最終的に得られた式は，化学平衡における「質量作用の法則」そのものである．
半導体物理学においては，ドナーの電離度 $\alpha = n_D/N_D$ を議論する際に非常に重要な式であり，温度が上がると $e^{-E_D/kT}$ の項が大きくなるため，より多くのドナーが電離して伝導帯に電子を供給することが理解できる．
