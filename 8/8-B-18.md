# 演習問題【8-B-18】

## 解答

実効質量 $m^*$ をもつ電子が数密度 $n=N/V$ で存在する系を考える．
磁場 $H$ を加えたとき，電子の軌道運動とスピンの両方を考慮し，非縮退の Boltzmann 統計を用いて磁化率を求める．

電子の磁化には，軌道運動による寄与とスピンによる寄与がある．
まず単一電子の分配関数を求め，次に磁場に対する自由エネルギーの変化から磁化を計算する．
最後に，弱磁場極限をとることにより，磁化率を導く．

### 1．単一電子のエネルギー準位

磁場中では，電子の軌道運動はランダウ準位に量子化される．
電子のエネルギーは，

```math
\varepsilon(l,p_z)
=
\frac{p_z^2}{2m^*}
+2\mu_B^*H\left(l+\frac12\right)
\pm\mu_BH
\tag{1}
```

で与えられる．
ここで，

```math
\mu_B=\frac{e\hbar}{2mc},
\qquad
\mu_B^*=\frac{e\hbar}{2m^*c}
```

であり， $\mu_B$ は通常のボーア磁子， $\mu_B^*$ は軌道運動に関する実効ボーア磁子である．
$l=0,1,2,\ldots$ はランダウ量子数， $p_z$ は磁場方向の運動量である．
式(1)の最後の項はスピンの二つの向きに対応するエネルギーである．

ここでは $xy$ 面内の軌道運動はランダウ準位の項にすでに含まれているため，連続的な運動エネルギーとして残るのは磁場方向の $p_z^2/(2m^*)$ である．

### 2．単一電子の分配関数

温度を $T$ ，ボルツマン定数を $k$ とし，

```math
\beta=\frac{1}{kT}
```

とおく．
分配関数は，各エネルギー状態に対する Boltzmann 因子 $e^{-\beta\varepsilon}$ をすべての状態について足し合わせたものである．

単一電子の分配関数は，軌道運動とスピンの自由度を独立に足し合わせることで求められる．
軌道運動の分配関数は，ランダウ準位の縮重度を含めると，

```math
Z_{1,\mathrm{orb}}
=
V\left(\frac{2\pi m^*kT}{h^2}\right)^{3/2}
\frac{x^*}{\sinh x^*}
```

となる．
ここで，

```math
x^*=\beta\mu_B^*H
```

である．
この式に現れる $x^*/\sinh x^*$ は，ランダウ準位の和と準位ごとの縮重度から生じる．
磁場がゼロに近づくと $x^*/\sinh x^*\to1$ となり，磁場がない場合の通常の並進分配関数に戻る．

一方，スピンの二つの状態はエネルギー $\pm\mu_BH$ をもつので，その分配関数は，

```math
\begin{aligned}
Z_{1,\mathrm{spin}}
&=e^{-\beta\mu_BH}+e^{\beta\mu_BH}\\
&=2\cosh x
\end{aligned}
```

である．
ここで，

```math
x=\beta\mu_BH
```

と定義した．

軌道運動とスピンの分配関数を掛け合わせると，

```math
Z_1(H)=
V\left(\frac{2\pi m^*kT}{h^2}\right)^{3/2}
\frac{x^*}{\sinh x^*}\,2\cosh x
\tag{2}
```

を得る．

磁場がゼロの場合には $x=x^*=0$ であり， $x^*/\sinh x^*\to1$ ， $2\cosh x\to2$ となる．
したがって，

```math
Z_1(0)=
2V\left(\frac{2\pi m^*kT}{h^2}\right)^{3/2}
```

である．
よって，磁場がある場合とない場合の分配関数の比は，

```math
\boxed{
\frac{Z_1(H)}{Z_1(0)}
=
\frac{x^*}{\sinh x^*}\cosh x
}
\tag{3}
```

となる．
ここでは，磁場ゼロでも存在するスピンの重率 $2$ は比を取ることで相殺される．

非縮退の Boltzmann 統計に従う $N$ 個の独立な電子系の全分配関数は，

```math
Z(H)=\frac{Z_1(H)^N}{N!}
```

である．
これを磁場ゼロの場合と比較すると，

```math
\boxed{
Z(H)=Z(0)
\left[
\frac{x^*}{\sinh x^*}\cosh x
\right]^N
}
\tag{4}
```

が得られる．

### 3．磁化の導出

Helmholtz 自由エネルギー $F$ と分配関数の関係は，

```math
F=-kT\log Z
```

である．
磁気モーメントの総量 $M$ は，自由エネルギーの磁場微分の負号として定義されるので，

```math
M=-\left(\frac{\partial F}{\partial H}\right)_{T,V,N}
=
kT\left(\frac{\partial\log Z}{\partial H}\right)_{T,V,N}
\tag{5}
```

となる．

式(4)の対数を取ると，

```math
\log Z
=
\log Z(0)
+N\left[
\log x^*-\log(\sinh x^*)+\log(\cosh x)
\right]
```

である．
ここでは $T,V,N$ を一定として磁場 $H$ で微分する．

まず，軌道運動の寄与について，

```math
\frac{\partial x^*}{\partial H}=\beta\mu_B^*
```

であるから，

```math
\begin{aligned}
kT\frac{\partial}{\partial H}
\log\left(\frac{x^*}{\sinh x^*}\right)
&=
kT\beta\mu_B^*
\left(\frac1{x^*}-\coth x^*\right)\\
&=
-\mu_B^*
\left(\coth x^*-\frac1{x^*}\right)
\end{aligned}
```

となる．
ここで，ランジュバン関数

```math
L(y)=\coth y-\frac1y
```

を用いると，軌道運動による磁化の寄与は

```math
M_{\mathrm{orb}}=-N\mu_B^*L(x^*)
```

である．

次に，スピンの寄与を計算する．

```math
\frac{\partial x}{\partial H}=\beta\mu_B
```

であるから，

```math
\begin{aligned}
kT\frac{\partial}{\partial H}\log(\cosh x)
&=kT\beta\mu_B\tanh x\\
&=\mu_B\tanh x
\end{aligned}
```

となる．
したがって，スピンによる磁化は，

```math
M_{\mathrm{spin}}=N\mu_B\tanh x
```

である．

軌道運動とスピンの寄与を合わせると，

```math
\boxed{
M=N\mu_B\tanh(\beta\mu_BH)
-N\mu_B^*L(\beta\mu_B^*H)
}
\tag{6}
```

が得られる．

### 4．弱磁場極限から磁化率を求める

磁化率は，磁場がゼロに近いときの磁化の応答を表す量である．
ここでは $M$ は系全体の磁気モーメント， $n=N/V$ は電子の数密度である．
したがって，体積磁化率は，

```math
\chi=
\frac1V\left(\frac{\partial M}{\partial H}\right)_{H=0}
```

と定義される．
弱磁場では磁化が $H$ に比例するため，これは $\chi=\lim_{H\to0}M/(VH)$ と等価である．

磁場が十分に弱いとき，

```math
x=\beta\mu_BH\ll1,
\qquad
x^*=\beta\mu_B^*H\ll1
```

となる．
このとき，双曲線正接関数およびランジュバン関数は，

```math
\tanh x=x+O(x^3)
```

```math
L(x)=\frac{x}{3}+O(x^3)
```

と展開できる．
これらを式(6)に代入すると，

```math
\begin{aligned}
M
&\simeq N\mu_B(\beta\mu_BH)
-N\mu_B^*\left(\frac{\beta\mu_B^*H}{3}\right)\\
&=N\beta H
\left(\mu_B^2-\frac13\mu_B^{*2}\right)
\end{aligned}
```

となる．
よって，

```math
\begin{aligned}
\chi
&=\frac1V
\left(\frac{\partial M}{\partial H}\right)_{H=0}\\[4pt]
&=\frac{N}{VkT}
\left(\mu_B^2-\frac13\mu_B^{*2}\right)
\end{aligned}
```

である．
$n=N/V$ を代入すると，

```math
\boxed{
\chi=
\frac{n}{kT}
\left(\mu_B^2-\frac13\mu_B^{*2}\right)
}
```

となる．
これが示すべき式である．

### 解説

得られた磁化率は，

```math
\chi=
\underbrace{\frac{n\mu_B^2}{kT}}_{\text{スピンの寄与}}
-
\underbrace{\frac{n\mu_B^{*2}}{3kT}}_{\text{軌道運動の寄与}}
```

と分けて理解できる．

第一項はスピンによる正の寄与である．
磁場を加えると，磁場に沿った向きのスピン状態がより多く占有され，磁場と同じ向きの磁化が生じる．

第二項は軌道運動による負の寄与である．
磁場中では電子の軌道運動がランダウ準位に量子化され，その結果，磁場と反対向きの磁化が生じる．
したがって，軌道運動は反磁性的に働く．

このように，非縮退の電子系では，スピンの常磁性的な応答と軌道運動の反磁性的な応答が加算され，最終的に

```math
\boxed{
\chi=
\frac{n}{kT}
\left(\mu_B^2-\frac13\mu_B^{*2}\right)
}
```

が得られる．
