# 演習問題【8-A-12】

## 解答

### 1．電気的中性の条件から伝導電子密度を求める

伝導帯の底をエネルギーの基準 $0$ とし，ドナー準位を $-E_D$ とする．
ここで， $E_D>0$ はドナー準位から伝導帯の底までのエネルギー差であり， $\mu$ はこの基準で測った化学ポテンシャル，すなわちFermi準位である．

ドナーの総密度を $N_D$ ，伝導帯にある電子の密度を $n$ ，電子を束縛したままの中性ドナーの密度を $n_D$ とすると，電気的中性の条件は

```math
\boxed{n=N_D-n_D}
\tag{1}
```

である．
ドナーが電子を伝導帯に放出すると，ドナーは正に帯電する．
したがって，伝導帯の電子密度は，電子を放出して電離したドナーの密度に等しい．

ドナー準位は $-E_D$ にあり，そこに電子が束縛されている状態にはスピンによる2重の状態がある．
Fermi統計に従うと，中性ドナーの密度は

```math
n_D=
\frac{N_D}
{1+\frac12\exp[-(\mu+E_D)/(kT)]}
\tag{2}
```

となる．
ここで， $\mu+E_D$ はドナー準位と化学ポテンシャルの差に対応する量である．

また，伝導帯中の電子が非縮退近似に従うとき，伝導電子密度とFermi準位の関係は

```math
\boxed{
n=N_c e^{\mu/(kT)}
}
\tag{3}
```

である．
ここで，

```math
N_c=2\left(\frac{2\pi m^*kT}{h^2}\right)^{3/2}
\tag{4}
```

は伝導帯の有効状態密度， $m^*$ は電子の有効質量， $h$ はPlanck定数である．
この近似は，Fermi準位が伝導帯の底より数 $kT$ 以上低い場合に成立する．

式 (2) の指数関数を式 (3) を用いて書き換えると，

```math
e^{-(\mu+E_D)/(kT)}
=\frac{N_c}{n}e^{-E_D/(kT)}
```

であるから，

```math
n_D=
\frac{N_D}
{1+\dfrac{N_c}{2n}e^{-E_D/(kT)}}
\tag{5}
```

となる．
これを式 (1) に代入すると，

```math
n=N_D-
\frac{N_D}
{1+\dfrac{N_c}{2n}e^{-E_D/(kT)}}
```

を得る．
右辺を整理すれば，

```math
n=
\frac{N_D}
{1+\dfrac{2n}{N_c}e^{E_D/(kT)}}
```

となる．
したがって，

```math
n+\frac{2n^2}{N_c}e^{E_D/(kT)}=N_D
```

であり，これを整理すると，

```math
\boxed{
\frac{n^2}{N_D-n}
=\frac12N_c e^{-E_D/(kT)}
}
\tag{6}
```

が得られる．

これは $n$ に関する二次方程式である．
式 (6) を整理すると，

```math
n^2+\frac12N_c e^{-E_D/(kT)}n
-\frac12N_DN_c e^{-E_D/(kT)}=0
```

となる．
二次方程式の解のうち，電子密度として正となる解を選ぶと，

```math
\boxed{
n=\frac{N_c}{4}e^{-E_D/(kT)}
\left[
-1+\sqrt{1+\frac{8N_D}{N_c}e^{E_D/(kT)}}
\right]
}
\tag{7}
```

を得る．
これが，温度とドナー密度から伝導電子密度を求める一般式である．

式 (3) より，Fermi準位は

```math
\mu=kT\ln\frac{n}{N_c}
```

である．
式 (7) を代入すると，

```math
\boxed{
\mu=-E_D+kT\ln\left[
\frac14
\left(
-1+\sqrt{1+\frac{8N_D}{N_c}e^{E_D/(kT)}}
\right)
\right]
}
\tag{8}
```

となる．

### 2．十分に温度が低い場合

温度が十分に低いとき， $e^{E_D/(kT)}$ は大きくなる．
したがって，

```math
\frac{8N_D}{N_c}e^{E_D/(kT)}\gg1
\tag{9}
```

が成り立つ．
この条件の下では，式 (7) の平方根において，根号内の $1$ を無視できる．
さらに平方根の値が十分大きいため，括弧内の $-1$ も無視できる．

すると，

```math
\begin{aligned}
n
&\simeq\frac{N_c}{4}e^{-E_D/(kT)}
\sqrt{\frac{8N_D}{N_c}e^{E_D/(kT)}}\\
&=\sqrt{\frac{N_DN_c}{2}}\,
e^{-E_D/(2kT)}
\end{aligned}
```

を得る．
よって，

```math
\boxed{
n\simeq
\sqrt{\frac{N_DN_c}{2}}\,e^{-E_D/(2kT)}
\ll N_D
}
\tag{10}
```

である．
電子密度がドナー密度より十分小さいため，ドナーの大部分は電子を束縛した中性状態にある．
伝導帯に熱励起される電子は少数であり，これが不純物の電離が十分でない低温領域である．

次に，式 (8) からFermi準位を求める．
低温近似を代入すると，

```math
\begin{aligned}
\mu
&\simeq -E_D
+kT\ln\left[
\frac14\sqrt{\frac{8N_D}{N_c}}
e^{E_D/(2kT)}
\right]\\
&=-\frac{E_D}{2}
+\frac{kT}{2}\ln\frac{N_D}{2N_c}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\mu\simeq
-\frac{E_D}{2}
+\frac{kT}{2}\ln\frac{N_D}{2N_c}
}
\tag{11}
```

である．
低温では補正項が小さくなるため，Fermi準位はおよそ $-E_D/2$ ，すなわちドナー準位 $-E_D$ と伝導帯の底 $0$ の中間付近に位置する．

### 3．十分に温度が高い場合

温度が上がると，伝導帯の有効状態密度 $N_c\propto T^{3/2}$ が増大する．
このとき，

```math
\frac{8N_D}{N_c}e^{E_D/(kT)}\ll1
\tag{12}
```

が成立する場合を考える．
式 (7) において，

```math
\sqrt{1+x}=1+\frac{x}{2}-\frac{x^2}{8}+\cdots
\qquad (|x|\ll1)
```

を用いる．
ここで $x=(8N_D/N_c)e^{E_D/(kT)}$ である．
展開すると，

```math
\begin{aligned}
n
&=\frac{N_c}{4}e^{-E_D/(kT)}
\left(\frac{x}{2}-\frac{x^2}{8}+\cdots\right)\\
&=N_D-\frac{2N_D^2}{N_c}e^{E_D/(kT)}+\cdots
\end{aligned}
```

である．
したがって，

```math
\boxed{
n=N_D\left[
1-\frac{2N_D}{N_c}e^{E_D/(kT)}+\cdots
\right]
\simeq N_D
}
\tag{13}
```

となる．
このとき，式 (8) より，

```math
\boxed{
\mu=kT\left[
\ln\frac{N_D}{N_c}
-\frac{2N_D}{N_c}e^{E_D/(kT)}
+\cdots
\right]
}
\tag{14}
```

を得る．

高温極限では $n\simeq N_D$ であるため，式 (1) から

```math
n_D=N_D-n
\simeq\frac{2N_D^2}{N_c}e^{E_D/(kT)}
\ll N_D
```

となる．
つまり，中性ドナーの密度は小さく，ドナーはほぼ完全に電離して電子を伝導帯へ放出している．

このことは，Fermi準位の位置とも整合する．
条件 (12) は，

```math
\frac{N_D}{N_c}e^{E_D/(kT)}\ll\frac18
```

を意味する．
式 (14) の主項 $\mu\simeq kT\ln(N_D/N_c)$ は，この条件の下でドナー準位 $-E_D$ より低い値となる．
したがってドナー準位の占有確率は小さく，ドナーが電子をほとんど失っていることと矛盾しない．

ここでいう高温極限は，ドナーからの熱励起を考えるモデル内での極限である．
さらに高温となり，価電子帯から伝導帯への固有励起が無視できなくなった場合には，その寄与も別途考慮する必要がある．

### 4．電気伝導度と温度依存性

問題で与えられた電気伝導度は，

```math
\boxed{
\sigma=\frac{e^2n}{m^*}\tau
}
\tag{15}
```

である．
ここで $e$ は電気素量， $\tau$ は緩和時間である．
以下では， $\tau$ は温度によらずほぼ一定とする．

#### 4.1．低温の場合

式 (10) を式 (15) に代入すると，

```math
\sigma\simeq\frac{e^2\tau}{m^*}
\sqrt{\frac{N_DN_c}{2}}
e^{-E_D/(2kT)}
```

となる．
式 (4) より，

```math
\frac{N_c}{2}
=\left(\frac{2\pi m^*kT}{h^2}\right)^{3/2}
```

なので，

```math
\boxed{
\sigma\simeq
\frac{e^2\tau}{m^*}
N_D^{1/2}
\left(\frac{2\pi m^*k}{h^2}\right)^{3/4}
T^{3/4}e^{-E_D/(2kT)}
}
\tag{16}
```

である．
したがって，低温では電気伝導度が活性化型の指数関数で強く抑制される．

自然対数をとると，

```math
\ln\sigma=
\mathrm{const}
+\frac34\ln T-\frac{E_D}{2kT}
\tag{17}
```

となる．
横軸を $1/T$ とした場合，

```math
\boxed{
\frac{d\ln\sigma}{d(1/T)}
=-\frac34T-\frac{E_D}{2k}
}
\tag{18}
```

である．
低温の活性化項が支配的な領域では， $\frac34\ln T$ の変化は指数関数項より緩やかである．
したがって， $\ln\sigma$ と $1/T$ のグラフはほぼ直線となり，その傾斜は

```math
\boxed{
\frac{d\ln\sigma}{d(1/T)}
\simeq-\frac{E_D}{2k}
}
\tag{19}
```

と近似できる．
よって，この直線の傾斜からドナーのイオン化エネルギー $E_D$ を求められる．
具体的には，

```math
\boxed{
E_D\simeq-2k
\left(\frac{d\ln\sigma}{d(1/T)}\right)
}
```

である．
常用対数 $\log_{10}\sigma$ を用いる場合，傾斜は $-E_D/(2k\ln10)$ となる．

#### 4.2．高温の場合

式 (13) より $n\simeq N_D$ であるから，式 (15) は

```math
\boxed{
\sigma\simeq\frac{e^2N_D}{m^*}\tau
}
\tag{20}
```

となる．
緩和時間 $\tau$ がほぼ一定であれば，この領域では電気伝導度もほぼ一定である．

#### 4.3．$\ln\sigma$ と $1/T$ の曲線の形

以上より， $\ln\sigma$ を $1/T$ に対してプロットすると，次のような定性的な形になる．

- **高温側（小さい $1/T4 ）** ： ドナーはほぼ完全に電離し， $n\simeq N_D$ となる． $\tau$ を一定とすれば， $\sigma$ はほぼ一定であり，曲線は水平に近い．
- **低温側（大きい $1/T$ ）** ： ドナーから伝導帯への熱励起が抑制され， $\sigma\propto T^{3/4}e^{-E_D/(2kT)}$ となる．曲線はほぼ直線となり，傾斜はおよそ $-E_D/(2k)$ である．

したがって，低温側の直線部分の傾斜を測定すれば，ドナーのイオン化エネルギーを実験的に決定できるのである．
