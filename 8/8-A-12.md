# 演習問題【8-A-12】

## 解答

### 1. 電気的中性の条件と伝導電子密度の導出

半導体中の電気的中性の条件は，ドナーによる正電荷と，伝導帯中の電子による負電荷の総和が釣り合うことである．
ドナーの密度を $N_D$ ，伝導帯中の電子密度を $n$ ，ドナーが電子を失った状態（イオン化したドナー）の密度を $n_D$ とすると，次のように書ける．

$$n = N_D - n_D \quad \cdots (A)$$

ここで， $n_D$ はドナー準位の占有確率を用いて次のように表される．
統計力学的な配分関数の関係から，ドナーの密度 $N_D$ に対するイオン化したドナーの割合は，

$$n_D = \frac{N_D}{1 + \frac{1}{2} \exp\left( \frac{\mu - E_D}{kT} \right)} \quad \cdots (B)$$

と与えられる．
ただし， $\mu$ は Fermi 準位， $E_D$ はドナー準位のエネルギー， $k$ はボルツマン定数， $T$ は絶対温度である．
また，伝導帯中の電子密度 $n$ と Fermi 準位 $\mu$ の関係は，

$$n = N_c \exp\left( \frac{\mu}{kT} \right) \quad \cdots (C)$$

これは非縮退近似（$E_c - \mu \gg kT$，すなわちFermi準位が伝導帯の底から十分離れた場合）のもとで成立する．
低温・不純物伝導領域ではこの条件が満たされるが，高温では $n \to N_D$ として $\mu$ が伝導帯に近づくため，適用には注意が必要である．
ここで $N_c$ は有効状態密度であり， $N_c = 2 \left( \frac{2\pi m^* kT}{h^2} \right)^{3/2}$ である．

式 (B) を書き換えると，

$$n_D = \frac{N_D}{1 + \frac{1}{2} \frac{n}{N_c} \exp\left( \frac{E_D}{kT} \right)} = \frac{N_D \cdot 2 N_c}{2 N_c + n \exp\left( \frac{E_D}{kT} \right)}$$

となる．
これを式 (A) に代入すると，

$$n = N_D - \frac{2 N_D N_c}{2 N_c + n \exp\left( \frac{E_D}{kT} \right)}$$

$$n = \frac{2 N_D N_c + n N_D \exp\left( \frac{E_D}{kT} \right) - 2 N_D N_c}{2 N_c + n \exp\left( \frac{E_D}{kT} \right)} = \frac{n N_D \exp\left( \frac{E_D}{kT} \right)}{2 N_c + n \exp\left( \frac{E_D}{kT} \right)}$$

これより，

$$n \left( 2 N_c + n \exp\left( \frac{E_D}{kT} \right) \right) = n N_D \exp\left( \frac{E_D}{kT} \right)$$

両辺を $n$ で割り（$n \neq 0$ と仮定），

$$2 N_c + n \exp\left( \frac{E_D}{kT} \right) = N_D \exp\left( \frac{E_D}{kT} \right)$$

$$n \exp\left( \frac{E_D}{kT} \right) = N_D \exp\left( \frac{E_D}{kT} \right) - 2 N_c$$

$$n = N_D - 2N_c \exp\left( -\frac{E_D}{kT} \right)$$

これは n を暗黙的に表した式である。近似は行われていない。厳密には二次方程式を解く必要がある．

$$\frac{n^2}{N_D - n} = \frac{1}{2} N_c \exp\left( -\frac{E_D}{kT} \right) \quad \cdots (1)$$

これを $n$ についての2次方程式として解くと，

$$n^2 + n \cdot \frac{1}{2} N_c \exp\left( -\frac{E_D}{kT} \right) - N_D \cdot \frac{1}{2} N_c \exp\left( -\frac{E_D}{kT} \right) = 0$$

解の公式より，

$$n = \frac{-\frac{1}{2} N_c e^{-E_D/kT} + \sqrt{\frac{1}{4} N_c^2 e^{-2E_D/kT} + 2 N_D N_c e^{-E_D/kT}}}{2}$$

分子の中身から $\frac{1}{4} N_c^2 e^{-2E_D/kT}$ をくくり出すと，

$$n = \frac{\sqrt{\frac{1}{4} N_c^2 e^{-2E_D/kT}}}{2} \left( -1 + \sqrt{1 + \frac{8N_D}{N_c} e^{E_D/kT}} \right)$$

$$= \frac{N_c}{4} e^{-E_D/kT} \left( -1 + \sqrt{1 + \frac{8N_D}{N_c} e^{E_D/kT}} \right) \quad \cdots (2)$$

次に，Fermi 準位 $\mu$ を求める．式 (C) より， $\log(n/N_c) = \mu/kT$ であるから，

$$\mu = kT \log \frac{n}{N_c}$$

式 (2) を代入すると，

$$\mu = kT \log \left[ \frac{1}{4} e^{-E_D/kT} \left( -1 + \sqrt{1 + \frac{8N_D}{N_c} e^{E_D/kT}} \right) \right]$$

$$= -E_D + kT \log \left[ \frac{1}{4} \left( -1 + \sqrt{1 + \frac{8N_D}{N_c} e^{E_D/kT}} \right) \right] \quad \cdots (3)$$

### 2. 低温および高温の極限

#### (i) 十分に温度が低い場合（低温極限）

低温では， $e^{E_D/kT}$ が非常に大きくなる．
したがって，

$$e^{E_D/kT} \gg \frac{N_c}{8N_D} \quad \cdots (4)$$

が成り立つ．
このとき，式 (2) の根号の中では $1$ が支配的であり，さらに $\{ \}$ の中の $-1$ も無視できる．

$$n \approx \frac{N_c}{4} e^{-E_D/kT} \left( \sqrt{\frac{8N_D}{N_c} e^{E_D/kT}} \right) = \frac{N_c}{4} e^{-E_D/kT} \cdot \sqrt{\frac{8N_D}{N_c}} e^{E_D/2kT}$$

$$n = \left( \frac{N_D N_c}{2} \right)^{1/2} e^{-E_D/2kT} \ll N_D \quad \cdots (5)$$

また，Fermi 準位 $\mu$ については，

$$\mu \approx -E_D + kT \log \left[ \frac{1}{4} \sqrt{\frac{8N_D}{N_c}} e^{E_D/2kT} \right] = -E_D + kT \left( \frac{E_D}{2kT} + \log \sqrt{\frac{N_D}{2N_c}} \right)$$

$$\mu = -\frac{E_D}{2} + \frac{kT}{2} \log \frac{N_D}{2N_c} \quad \cdots (6)$$

となる．
低温では $\mu \approx -E_D/2$ であり，これはドナー準位と伝導帯の底の中間付近に位置することを意味する．
このとき，ドナーは電子をほとんど失っておらず，ごく一部が電離している状態である．

#### (ii) 十分に温度が高い場合（高温極限）

高温では， $N_c$ が増大し， $e^{E_D/kT}$ が $1$ に近づく．

$$\frac{8N_D}{N_c} e^{E_D/kT} \ll 1 \quad \cdots (7)$$

が成り立つ．
このとき，式 (2) を $e^{E_D/kT}$ のべき級数展開を用いて近似する．
$\sqrt{1+x} \approx 1 + \frac{1}{2}x - \frac{1}{8}x^2$ を用いると，

$$n = \frac{N_c}{4} e^{-E_D/kT} \left( -1 + 1 + \frac{1}{2} \frac{8N_D}{N_c} e^{E_D/kT} - \dots \right) = N_D - \dots$$

より正確には，

$$n = N_D \left( 1 - \frac{2N_D}{N_c} e^{E_D/kT} + \dots \right) \quad \cdots (8)$$

となる．
同様に $\mu$ については，

$$\mu = kT \left( \log \frac{N_D}{N_c} - \frac{2N_D}{N_c} e^{E_D/kT} + \dots \right) \quad \cdots (9)$$

となる．
高温では $\mu$ はドナー準位よりも低くなり，イオン化ドナーの割合 $n_i = N_D - n = N_D \cdot (2N_D/N_c) e^{E_D/kT} \ll N_D$ であるから，**ドナーはほとんどその電子を失っていない**．すなわち，一見電子密度 $n$ が $N_D$ に等しいように見えるが，これは有効状態密度 $N_c \propto T^{3/2}$ の増大により Fermi 準位 $\mu$ が下方へシフトし，結果としてドナーの電離率が低下するためである（不純物電離の逆転現象）．電子密度 $n$ はドナー密度 $N_D$ に等しく近づく．

### 3. 電気伝導度 $\sigma$ の振る舞い

電気伝導度 $\sigma$ は次のように与えられる．

$$\sigma = \frac{e^2 n}{m^*} \tau \quad \cdots (10)$$

これに求めた $n$ を代入する．

- **低温の場合**：
式 (5) を用いると，
$$\sigma = \frac{e^2 \tau}{m^*} \left( \frac{N_D N_c}{2} \right)^{1/2} e^{-E_D/2kT}$$
ここで $N_c = 2(2\pi m^* kT/h^2)^{3/2}$ を代入すると，$N_c^{1/2} \propto T^{3/4}$ であるから，

$$\sigma = \frac{e^2 \tau}{m^*} \left( \frac{2\pi m^* kT}{h^2} \right)^{3/4} N_D^{1/2} e^{-E_D/2kT} \quad \cdots (11)$$

となる．これより $\sigma \propto T^{3/4} e^{-E_D/2kT}$ であることがわかる．

- **高温の場合**：
式 (8) より $n \approx N_D$ であるから，
$$\sigma \approx \frac{e^2 \tau}{m^*} N_D \quad \cdots (12)$$
となる．

ここで， $\log \sigma$ を $1/T$ に対してプロットすることを考える．
低温においては， $\log \sigma \approx \text{const} + \frac{3}{4} \log T - \frac{E_D}{2kT}$ である．
$\log T = -\log(1/T)$ であり，$T^{3/4}$ の変化は $e^{-E_D/2kT}$ の変化に比べて極めて緩やかである．
したがって， $\log \sigma$ の $1/T$ に対する傾きは，指数の項によって支配される．

$$\frac{\partial \log \sigma}{\partial (1/T)} \approx -\frac{E_D}{2} \quad \cdots (13)$$

この傾斜を測定することで，ドナーのイオン化エネルギー $E_D$ を決定することができる．

## 解説

本問題は，半導体中の不純物（ドナー）が温度によってどのように電離し，それが電気伝導性にどのような影響を与えるかを扱うものである．

### 1.  電気的中性の条件

半導体は全体として電気的に中性である必要がある．
「ドナーが与えた正電荷」と「伝導帯を走る電子の負電荷」が釣り合うことを数式化したものが式 (1) である．

### 2.  温度による挙動の変化

- **低温** では，熱エネルギー $kT$ がドナーの結合エネルギー $E_D$ に比べて小さいため，電子はドナーに捕らえられたままである．
わずかに電離した電子のみが伝導に寄与するため，電子密度 $n$ は指数関数的に小さな値をとる．
- **高温** では，熱エネルギーによってドナーがほぼ完全に電離するため， $n \approx N_D$ となり，温度への依存性が弱くなる．

### 3.  電気伝導度の測定意義

$\log \sigma$ と $1/T$ の関係（アレニウスプロットに似た形式）を調べることで，その傾きからエネルギー障壁（ここでは $E_D/2$ ）を直接見積もることができる．
これは材料特性を評価するための非常に強力な手法である．
