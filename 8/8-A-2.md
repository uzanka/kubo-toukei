# 演習問題【8-A-2】

## 解答
### Fermi 分布の折線近似による比熱の導出

有限温度における Fermi 分布を折線で近似し，電子系の比熱が低温で温度 $T$ に比例することを示す．

#### 1．Fermi 分布の折線近似

電子の状態密度を一定値 $D$ とし，温度 $T$ における Fermi 分布を

```math
f(\epsilon)=\frac{1}{e^{\beta(\epsilon-\mu)}+1}
```

とする．
ここで， $\beta=1/(kT)$ ， $\mu$ は化学ポテンシャル， $k$ は Boltzmann 定数である．

低温では，Fermi 分布は $\epsilon=\mu$ の近傍で急激に変化する．
この変化する領域を直線で近似し，それより低いエネルギーでは $f(\epsilon)=1$ ，高いエネルギーでは $f(\epsilon)=0$ とする．

まず， $\epsilon=\mu$ における Fermi 分布の傾きを求める．微分すると，

```math
f'(\epsilon)=
-\frac{\beta e^{\beta(\epsilon-\mu)}}
{\left(e^{\beta(\epsilon-\mu)}+1\right)^2}
```

である．
したがって，$\epsilon=\mu$ では

```math
f'(\mu)=-\frac{\beta}{4}
=-\frac{1}{4kT}
```

となる．

折線の遷移領域の幅を $2akT$ とおく．
この領域では，分布関数は $1$ から $0$ まで直線的に減少するため，折線の傾きは

```math
-\frac{1}{2akT}
```

である．
この傾きを Fermi 分布の $\epsilon=\mu$ における傾きに一致させると，

```math
-\frac{1}{2akT}=-\frac{1}{4kT}
```

となる．
よって，

```math
2akT=4kT,\qquad a=2
\tag{1}
```

である．

#### 2．重心を用いたエネルギー変化の計算

絶対零度では，電子は $\epsilon=\mu_0$ 以下の状態を占有している．
有限温度では，Fermi 分布の変化によって，Fermi 準位付近の電子が高いエネルギー状態へ励起される．
一方，低いエネルギー状態には電子の空席が生じる．

電子の総数は保存されるため，励起によって失われる電子数と，高いエネルギー状態に現れる電子数は等しい．
したがって，エネルギー変化は，電子が移動する前後の分布の重心の横座標の差から求められる．

解答例の図において，四辺形 $\mathrm{AA'B'B}$ と三角形 $\mathrm{ABC}$ は，それぞれ零温度と有限温度における遷移領域を表す．
状態密度 $D$ が一定であるため，これらの図形の面積は電子数に対応する．

四辺形 $\mathrm{AA'B'B}$ の面積は

```math
N_{\mathrm{trans}}=D\cdot akT
\tag{2}
```

である．
また，三角形 $\mathrm{ABC}$ の底辺の長さは $2akT$ ，高さは $D$ であるから，その面積も

```math
\frac12\cdot 2akT\cdot D
=DakT
=N_{\mathrm{trans}}
```

となる．
すなわち，両図形の面積は等しく，電子数が保存されていることが分かる．

次に，それぞれの図形の重心の横座標を求める．
点 $\mathrm{O}$ をエネルギーの基準とし，点 $\mathrm{B}$ の横座標を $\mathrm{OB}$ と表す．
四辺形 $\mathrm{AA'B'B}$ の重心 $\mathrm{G}$ の横座標は，

```math
x_{\mathrm{G}}
=\mathrm{OB}+\frac12\mathrm{BB}'
=\mathrm{OB}+\frac12 akT
\tag{3}
```

である．
一方，三角形 $\mathrm{ABC}$ の重心 $\mathrm{G}'$ の横座標は，

```math
x_{\mathrm{G}'}
=\mathrm{OB}+\frac13\mathrm{BC}
=\mathrm{OB}+\frac23 akT
\tag{4}
```

である．
ここで， $\mathrm{BC}=2akT$ を用いた．

有限温度でのエネルギー増加 $\Delta E$ は，電子数 $N_{\mathrm{trans}}$ に重心の移動距離を掛けたものである．
したがって，

```math
\begin{aligned}
\Delta E
&=N_{\mathrm{trans}}
(x_{\mathrm{G}'}-x_{\mathrm{G}})\\
&=DakT\left[
\left(\mathrm{OB}+\frac23 akT\right)
-\left(\mathrm{OB}+\frac12 akT\right)
\right]\\
&=DakT\cdot\frac16 akT\\
&=\frac{a^2}{6}D(kT)^2
\end{aligned}
\tag{5}
```

となる．
式 (1) より $a=2$ であるから，

```math
\boxed{
\Delta E=\frac23Dk^2T^2
}
\tag{6}
```

を得る．

#### 3．比熱の導出

比熱 $C$ は，電子系のエネルギーを温度で微分したものである．
低温では，式 (6) より，

```math
\begin{aligned}
C
&=\frac{d\Delta E}{dT}\\
&=\frac{d}{dT}
\left(\frac23Dk^2T^2\right)\\
&=\frac43Dk^2T
\end{aligned}
```

となる．
したがって，

```math
\boxed{
C=\frac43Dk^2T\propto T
}
```

である．

以上より，Fermi 分布を折線で近似する初等的な方法によって，電子系の比熱が低温において温度 $T$ に比例することが示された．
なお，ここで得られた係数 $4/3$ は折線近似によるものであり，厳密な計算では係数は $\pi^2/3$ となる．
