# 例題【8-R-5】

## 解答

### 1．前提条件と粒子数の分解

三次元空間を運動する，粒子間相互作用のない自由 Bose 気体を考える．
粒子の質量を $m$ ，体積を $V$ ，粒子数を $N$ ，絶対温度を $T$ ，Boltzmann 定数を $k$ とする．

内部自由度による追加の縮退はないものとし，空間には周期境界条件を課す．

以下では，熱力学的極限

```math
N,V\longrightarrow\infty,
\qquad
\rho_V=\frac NV\longrightarrow\rho>0
```

を考える．

まず，大正準集団を用いて平均占有数を求める．
この場合， $N$ は平均粒子数を表し，化学ポテンシャル $\mu_V$ は

```math
\langle\hat N\rangle=N
```

となるように定める．
また， $N_0$ および $N'$ は，それぞれ基底状態と励起状態の平均占有粒子数を表す．

基底状態のエネルギーをエネルギー原点に選び，

```math
\varepsilon_0=0
```

とする．

さらに，

```math
\beta=\frac1{kT}
```

とおく．

Bose-Einstein 分布によれば，1粒子準位 $\varepsilon_i$ の平均占有数は，

```math
\boxed{
\bar n_i=
\frac1{e^{\beta(\varepsilon_i-\mu_V)}-1}
}
\tag{1}
```

である．

したがって，平均粒子数は，

```math
N=N_0+N'
\tag{2}
```

と分解できる．

基底状態の平均占有数は，

```math
\boxed{
N_0=\frac1{e^{-\beta\mu_V}-1}
}
\tag{3}
```

であり，励起状態の平均占有数は，

```math
\boxed{
N'=
\sum_{i\neq0}
\frac1{e^{\beta(\varepsilon_i-\mu_V)}-1}
}
\tag{4}
```

である．

大正準分配関数の収束条件から，

```math
\mu_V\leq\varepsilon_0=0
```

でなければならない．

ただし，基底状態の平均占有数を有限に保つためには，

```math
\boxed{\mu_V<0}
\tag{5}
```

である必要がある．

したがって，有限体積では化学ポテンシャルは負であり，凝縮相での $\mu=0$ は熱力学的極限での値として扱う．

### 2．励起状態の粒子数密度

#### 2.1 状態密度

三次元自由粒子のエネルギーと運動量の関係は，

```math
\varepsilon=\frac{p^2}{2m}
```

である．

周期境界条件のもとで，十分大きな体積を考えると，1粒子状態密度は，

```math
\boxed{
D(\varepsilon)=
\frac{V}{4\pi^2}
\left(\frac{2m}{\hbar^2}\right)^{3/2}
\varepsilon^{1/2}
}
\tag{6}
```

となる．
ここで $\hbar=h/(2\pi)$ は換算 Planck 定数である．

#### 2.2 連続状態近似

体積が十分大きい場合，励起状態の離散的な準位の和を状態密度による積分で近似できる．

したがって，

```math
N'\simeq
\int_0^\infty
\frac{D(\varepsilon)}
{e^{\beta(\varepsilon-\mu_V)}-1}
\,d\varepsilon
```

となる．

式 (6) を代入すると，

```math
N'\simeq
\frac{V}{4\pi^2}
\left(\frac{2m}{\hbar^2}\right)^{3/2}
\int_0^\infty
\frac{\varepsilon^{1/2}}
{e^{\beta(\varepsilon-\mu_V)}-1}
\,d\varepsilon
\tag{7}
```

である．

ここで，

```math
x=\beta\varepsilon,
\qquad
\alpha_V=-\beta\mu_V
\tag{8}
```

とおく．有限体積では $\mu_V<0$ であるため，

```math
\alpha_V>0
```

である．

また，

```math
\varepsilon=kTx,
\qquad
d\varepsilon=kT\,dx
```

より，

```math
\varepsilon^{1/2}d\varepsilon
=(kT)^{3/2}x^{1/2}dx
```

となる．

これを式 (7) に代入すると，

```math
N'\simeq
V\left(\frac{mkT}{2\pi\hbar^2}\right)^{3/2}
\frac2{\sqrt\pi}
\int_0^\infty
\frac{x^{1/2}}{e^{x+\alpha_V}-1}\,dx
```

となる．

ここで，

```math
F_{3/2}(\alpha)
=
\frac2{\sqrt\pi}
\int_0^\infty
\frac{x^{1/2}}{e^{x+\alpha}-1}\,dx
\tag{9}
```

と定義する．

指数関数の展開

```math
\frac1{e^{x+\alpha}-1}
=
\sum_{\ell=1}^{\infty}
e^{-\ell(x+\alpha)}
```

を用いる．
各項は非負であるため，積分と無限和の交換は Tonelli の定理によって正当化される．

したがって，

```math
\begin{aligned}
F_{3/2}(\alpha)
&=
\frac2{\sqrt\pi}
\sum_{\ell=1}^{\infty}
e^{-\ell\alpha}
\int_0^\infty x^{1/2}e^{-\ell x}\,dx\\
&=
\frac2{\sqrt\pi}
\sum_{\ell=1}^{\infty}
e^{-\ell\alpha}
\frac{\Gamma(3/2)}{\ell^{3/2}}
\end{aligned}
```

となる．

ここで，

```math
\Gamma\left(\frac32\right)=\frac{\sqrt\pi}{2}
```

であるから，

```math
\boxed{
F_{3/2}(\alpha)
=
\sum_{\ell=1}^{\infty}
\frac{e^{-\ell\alpha}}{\ell^{3/2}}
}
\tag{10}
```

を得る．

ここで，

```math
C_T=
\left(\frac{mkT}{2\pi\hbar^2}\right)^{3/2}
```

とおく．

固定した $\alpha\geq0$ に対する熱力学的極限では，

```math
\boxed{
\lim_{V\to\infty}\frac{N'}V
=
C_TF_{3/2}(\alpha)
}
\tag{11}
```

となる．

#### 2.3 関数 $F_{3/2}(\alpha)$ の性質

式 (10) より， $F_{3/2}(\alpha)$ は $\alpha\geq0$ で正かつ連続であり，狭義単調減少する．

また，

```math
F_{3/2}(0)
=
\sum_{\ell=1}^{\infty}\frac1{\ell^{3/2}}
=
\zeta\left(\frac32\right)
```

であり，

```math
\lim_{\alpha\to\infty}F_{3/2}(\alpha)=0
```

である．

したがって，

```math
\boxed{
0<F_{3/2}(\alpha)
\leq\zeta\left(\frac32\right)
}
\tag{12}
```

が成立する．

よって，励起状態に収容できる粒子数密度の最大値は，

```math
\boxed{
\rho_c(T)=
C_T\zeta\left(\frac32\right)
}
\tag{13}
```

である．

ここで，

```math
\rho_c(T)\propto T^{3/2}
```

となる．

### 3．有限体積の離散和と極限操作の正当化

体積を一辺 $L$ の立方体とし，

```math
V=L^3
```

とする．
周期境界条件のもとでは，運動量は，

```math
\boldsymbol p=
\frac{2\pi\hbar}{L}\boldsymbol n,
\qquad
\boldsymbol n\in\mathbb Z^3
```

である．

励起状態の粒子数密度を，

```math
S_L(a)
=
\frac1{L^3}
\sum_{\boldsymbol n\neq0}
\frac1{
\exp\left[
\frac{\beta}{2m}
\left(\frac{2\pi\hbar}{L}\right)^2
|\boldsymbol n|^2+a
\right]-1
}
\tag{14}
```

と定義する．

このとき，

```math
\frac{N'}V=S_L(\alpha_V)
```

である．

固定した $a>0$ では，被積分関数は運動量の原点で連続であり，高運動量では指数関数的に減衰する．
したがって，Riemann 和の収束から，

```math
\boxed{
\lim_{L\to\infty}S_L(a)
=
C_TF_{3/2}(a)
}
\qquad(a>0)
\tag{15}
```

となる．

次に， $a=0$ の場合を考える．

低運動量では，

```math
\frac1{e^{\beta p^2/(2m)}-1}
\sim
\frac{2m}{\beta p^2}
```

である．

三次元運動量空間における原点付近の積分は，

```math
\int_0^\eta p^2\frac1{p^2}\,dp
=
\eta
```

に比例するため，有限である．

また，離散和について，

```math
\sum_{0<|\boldsymbol n|\leq R}
\frac1{|\boldsymbol n|^2}=O(R)
```

が成立する．
したがって，

```math
\begin{aligned}
&\frac1{L^3}
\sum_{0<|\boldsymbol p|<\eta}
\frac1{e^{\beta p^2/(2m)}-1}\\
&\qquad\leq
\frac{C}{L}
\sum_{0<|\boldsymbol n|<c\eta L}
\frac1{|\boldsymbol n|^2}\\
&\qquad=
O(\eta)+O(L^{-1})
\end{aligned}
```

となる．

一方， $|\boldsymbol p|\geq\eta$ では被積分関数は連続であり，高運動量側では指数関数的に減衰するため，通常の Riemann 和の収束が成立する．

したがって，まず $L\to\infty$ とし，その後 $\eta\to0^+$ とすれば，

```math
\boxed{
\lim_{L\to\infty}S_L(0)
=
C_T\zeta\left(\frac32\right)
}
\tag{16}
```

を得る．

以上より，固定した $a\geq0$ に対して，

```math
\boxed{
\lim_{L\to\infty}S_L(a)
=
C_TF_{3/2}(a)
}
\tag{17}
```

が成立する．

また， $S_L(a)$ は $a\geq0$ で狭義単調減少する．

### 4．臨界温度 $T_c$ の導出

励起状態に収容できる粒子数密度の最大値が，全粒子数密度 $\rho$ に一致する温度を臨界温度 $T_c$ と定義する．

したがって，

```math
\rho=C_{T_c}\zeta\left(\frac32\right)
```

である．
よって，

```math
\boxed{
T_c=
\frac{2\pi\hbar^2}{mk}
\left[
\frac{\rho}{\zeta(3/2)}
\right]^{2/3}
}
\tag{18}
```

を得る．

### 5．有限体積における粒子数保存則

大正準集団における有限体積の粒子数密度を，

```math
\rho_V=\frac NV
```

とする．

式 (3)，(14) より，

```math
\boxed{
\rho_V=
\frac1{V(e^{\alpha_V}-1)}
+
S_L(\alpha_V)
}
\tag{19}
```

となる．

この右辺は $\alpha_V>0$ で連続かつ狭義単調減少する．

また， $\alpha_V\to0^+$ では基底状態の占有数密度が発散し， $\alpha_V\to\infty$ では両項がゼロに収束する．

したがって，任意の $\rho_V>0$ に対して，式 (19) を満たす $\alpha_V>0$ は一意に存在する．

以下では，

```math
\rho_V\longrightarrow\rho>0
```

を用いる．

### 6．高温相 $T>T_c$

式 (18) より，

```math
\rho=
C_T\zeta\left(\frac32\right)
\left(\frac{T_c}{T}\right)^{3/2}
```

である．
したがって，

```math
\boxed{
\rho<C_T\zeta\left(\frac32\right)
}
\tag{20}
```

となる．

#### 6.1 $\alpha_V$ の正値性

仮に， $\alpha_V$ がゼロに収束する部分列を持つとする．

任意の $\delta>0$ に対して，十分大きな $V$ では，

```math
0<\alpha_V\leq\delta
```

となる．

$S_L(a)$ は単調減少するため，

```math
S_L(\alpha_V)\geq S_L(\delta)
```

である．

粒子数保存則より，

```math
\rho_V\geq S_L(\delta)
```

となる．

ここで $V\to\infty$ とすれば，

```math
\rho\geq C_TF_{3/2}(\delta)
```

を得る．

さらに $\delta\to0^+$ とすると，

```math
\rho\geq C_T\zeta\left(\frac32\right)
```

となる．
これは式 (20) に矛盾する．

したがって，

```math
\boxed{
\liminf_{V\to\infty}\alpha_V>0
}
\tag{21}
```

である．

#### 6.2 $\alpha_V$ の有界性

仮に， $\alpha_V\to\infty$ となる部分列が存在するとする．

任意の $A>0$ に対して，十分大きな $V$ では，

```math
\alpha_V\geq A
```

となる．

したがって，

```math
\rho_V
\leq
\frac1{V(e^A-1)}+S_L(A)
```

である．

$V\to\infty$ とすると，

```math
\rho\leq C_TF_{3/2}(A)
```

となる．
さらに $A\to\infty$ とすると，

```math
\rho\leq0
```

となり， $\rho>0$ に矛盾する．

よって，

```math
\boxed{
\limsup_{V\to\infty}\alpha_V<\infty
}
\tag{22}
```

である．

#### 6.3 $\alpha_V$ の収束性

任意の収束部分列を取り，

```math
\alpha_{V_j}\longrightarrow a>0
```

とする．

任意の $0<\epsilon<a$ に対し，十分大きな $j$ では，

```math
a-\epsilon
\leq\alpha_{V_j}
\leq a+\epsilon
```

である．
単調減少性から，

```math
S_{L_j}(a+\epsilon)
\leq
S_{L_j}(\alpha_{V_j})
\leq
S_{L_j}(a-\epsilon)
```

となる．

固定パラメータに対する式 (17) より，

```math
C_TF_{3/2}(a+\epsilon)
\leq
\liminf_{j\to\infty}S_{L_j}(\alpha_{V_j})
```

および，

```math
\limsup_{j\to\infty}S_{L_j}(\alpha_{V_j})
\leq
C_TF_{3/2}(a-\epsilon)
```

を得る．

さらに $\epsilon\to0^+$ とすると，連続性から，

```math
\boxed{
\lim_{j\to\infty}S_{L_j}(\alpha_{V_j})
=
C_TF_{3/2}(a)
}
```

となる．

また，式 (21) より，

```math
\frac1{V_j(e^{\alpha_{V_j}}-1)}
\longrightarrow0
```

である．

したがって，式 (19) から，

```math
\boxed{
\rho=C_TF_{3/2}(a)
}
\tag{23}
```

を得る．

$F_{3/2}$ は狭義単調減少するため，式 (23) を満たす $a>0$ は一意である．

有界性と部分列の一意性から，数列全体について，

```math
\boxed{
\alpha_V\longrightarrow\alpha(T)>0
}
\tag{24}
```

となる．

#### 6.4 基底状態の粒子数

式 (3)，(24) より，

```math
N_0=
\frac1{e^{\alpha_V}-1}
\longrightarrow
\frac1{e^{\alpha(T)}-1}
```

である．
したがって，

```math
\boxed{N_0=O(1)}
```

である．
一方，$N=\rho_VV$ かつ $\rho_V\to\rho>0$ なので，

```math
\boxed{
\lim_{N,V\to\infty}\frac{N_0}{N}=0
}
```

となる．
よって，

```math
\boxed{N_0=o(N)}
```

である．

### 7．低温相 $0<T<T_c$

式 (18) より，

```math
\boxed{
\rho>C_T\zeta\left(\frac32\right)
}
\tag{25}
```

である．

#### 7.1 $\alpha_V\to0^+$ の証明

仮に， $\alpha_V$ がゼロに収束しない部分列を持つとする．

ある $\delta>0$ と部分列について，

```math
\alpha_V\geq\delta
```

となる．

したがって，

```math
\frac1{V(e^{\alpha_V}-1)}
\leq
\frac1{V(e^\delta-1)}
\longrightarrow0
```

であり，

```math
S_L(\alpha_V)\leq S_L(\delta)
```

となる．

粒子数保存則から，

```math
\rho_V
\leq
\frac1{V(e^\delta-1)}
+
S_L(\delta)
```

である．

極限を取ると，

```math
\rho\leq C_TF_{3/2}(\delta)
<
C_T\zeta\left(\frac32\right)
```

となる．
これは式 (25) に矛盾する．

したがって，

```math
\boxed{
\alpha_V\longrightarrow0^+
}
\tag{26}
```

である．

#### 7.2 励起状態の粒子数密度

式 (26) より，任意の $\delta>0$ に対して，十分大きな $V$ では，

```math
0<\alpha_V\leq\delta
```

となる．

したがって，

```math
S_L(\delta)
\leq
S_L(\alpha_V)
\leq
S_L(0)
```

である．

固定した $\delta$ に対して極限を取り，さらに $\delta\to0^+$ とすれば，

```math
\boxed{
\lim_{V\to\infty}S_L(\alpha_V)
=
C_T\zeta\left(\frac32\right)
}
\tag{27}
```

となる．

すなわち，

```math
\boxed{
\lim_{V\to\infty}\frac{N'}V
=
C_T\zeta\left(\frac32\right)
}
\tag{28}
```

である．

#### 7.3 凝縮粒子数

粒子数保存則より，

```math
\frac{N_0}{N}
=
1-\frac{N'}N
```

である．
また，

```math
\rho=C_{T_c}\zeta\left(\frac32\right)
```

なので，

```math
\begin{aligned}
\lim_{V\to\infty}\frac{N_0}{N}
&=
1-\frac{C_T\zeta(3/2)}
{C_{T_c}\zeta(3/2)}\\
&=
1-\left(\frac{T}{T_c}\right)^{3/2}.
\end{aligned}
```

したがって，

```math
\boxed{
\lim_{N,V\to\infty}\frac{N_0}{N}
=
1-\left(\frac{T}{T_c}\right)^{3/2}
}
\qquad(0<T<T_c)
\tag{29}
```

である．

右辺は正の定数であるから，

```math
\boxed{N_0=\Theta(N)}
```

が成立する．

### 8．臨界点 $T=T_c$

臨界点では，

```math
\rho=C_T\zeta\left(\frac32\right)
\tag{30}
```

である．

仮に， $\alpha_V$ がゼロに収束しない部分列を持つとする．

ある $\delta>0$ について，

```math
\alpha_V\geq\delta
```

となる部分列が存在する．

この場合，

```math
\frac1{V(e^{\alpha_V}-1)}
\longrightarrow0
```

かつ，

```math
S_L(\alpha_V)\leq S_L(\delta)
```

である．

粒子数保存則から，

```math
\rho\leq C_TF_{3/2}(\delta)
<
C_T\zeta\left(\frac32\right)
```

となる．
これは式 (30) に矛盾する．

したがって，

```math
\boxed{
\alpha_V\longrightarrow0^+
}
\tag{31}
```

である．

低温相と同じ挟み撃ちによって，

```math
\lim_{V\to\infty}\frac{N'}V
=
C_T\zeta\left(\frac32\right)
=\rho
```

となる．
よって，

```math
\boxed{
\lim_{N,V\to\infty}\frac{N_0}{N}=0
}
\tag{32}
```

である．

臨界点では化学ポテンシャルはゼロに近づくが，凝縮粒子数の割合はゼロである．

### 9．大正準集団での化学ポテンシャル

式 (26)，(31) より，

```math
\alpha_V\longrightarrow0^+
\qquad(0<T\leq T_c)
```

である．

したがって，

```math
\mu_V=-kT\alpha_V
```

から，

```math
\boxed{
\lim_{V\to\infty}\mu_V=0
\qquad(0<T\leq T_c)
}
\tag{33}
```

となる．

有限体積では $\mu_V<0$ であり，厳密にゼロとなるわけではない．

また，式 (3) より，

```math
\mu_V=
-kT\log\left(1+\frac1{N_0}\right)
```

である．

$N_0\gg1$ の場合，

```math
\begin{aligned}
\mu_V
&=
-kT\left[
\frac1{N_0}
-\frac1{2N_0^2}
+O(N_0^{-3})
\right]\\
&=
-\frac{kT}{N_0}
+\frac{kT}{2N_0^2}
+O\left(\frac{kT}{N_0^3}\right).
\end{aligned}
```

したがって，

```math
\boxed{
\mu_V=
-\frac{kT}{N_0}
+
O\left(\frac{kT}{N_0^2}\right)
}
```

である．

低温相では $N_0=\Theta(N)$ であるから，

```math
\mu_V\longrightarrow0^-
```

となる．

なお，化学ポテンシャルの数値はエネルギー原点に依存する．
最低エネルギーを $\varepsilon_0=0$ とした今回の設定では $\mu=0$ であるが，一般には，

```math
\boxed{\mu=\varepsilon_0}
```

となる．

### 10．正準集団での凝縮粒子数の確認

ここまでは大正準集団による平均占有数を用いた．
次に，粒子数 $N$ を厳密に固定した正準集団でも，同じ凝縮粒子数の割合が得られることを示す．

#### 10.1 正準分配関数

励起状態に $M$ 個の粒子が存在するとき，基底状態の占有数は $N-M$ である．

励起状態の $M$ 粒子に対する正準分配関数を $Z_{\mathrm{ex},L}(M)$ とする．

基底状態のエネルギーはゼロで，縮退度が1であるから，

```math
\boxed{
Z_{N,L}
=
\sum_{M=0}^{N}Z_{\mathrm{ex},L}(M)
}
\tag{34}
```

である．

一方，励起状態だけの大正準分配関数は，

```math
\Xi_{\mathrm{ex},L}(z)
=
\prod_{\boldsymbol p\neq0}
\frac1{1-ze^{-\beta\varepsilon_{\boldsymbol p}}}
```

であり，

```math
\Xi_{\mathrm{ex},L}(z)
=
\sum_{M=0}^{\infty}
Z_{\mathrm{ex},L}(M)z^M
\tag{35}
```

となる．

ここで，

```math
P_{L,z}(M)
=
\frac{Z_{\mathrm{ex},L}(M)z^M}
{\Xi_{\mathrm{ex},L}(z)}
```

と定義する．

正準集団の励起粒子数分布は，

```math
P_{N,L}(M)
=
\frac{Z_{\mathrm{ex},L}(M)}
{\displaystyle\sum_{j=0}^{N}Z_{\mathrm{ex},L}(j)}
```

なので，

```math
\boxed{
P_{N,L}(M)
=
\frac{
P_{L,z}(M)z^{-M}
}{
\displaystyle\sum_{j=0}^{N}P_{L,z}(j)z^{-j}
}
}
\tag{36}
```

が成立する．

#### 10.2 固定した $0<z<1$ における励起粒子数

固定した $0<z<1$ では，各励起準位の占有数は独立な幾何分布に従う．

励起粒子数の平均密度は，

```math
\lim_{V\to\infty}
\frac{\mathbb E_z[M]}V
=
\rho_z
```

である．
ここで，

```math
\rho_z=C_T\operatorname{Li}_{3/2}(z)
```

と定義する．

また，分散は，

```math
\operatorname{Var}_z(M)
=
\sum_{\boldsymbol p\neq0}
\frac{ze^{-\beta\varepsilon_{\boldsymbol p}}}
{\left(1-ze^{-\beta\varepsilon_{\boldsymbol p}}\right)^2}
```

である．
$z<1$ では原点での特異性がなく，高運動量では指数関数的に減衰するため，

```math
\operatorname{Var}_z(M)=O(V)
```

となる．

したがって，Chebyshev の不等式により，

```math
\boxed{
\frac MV\longrightarrow\rho_z
}
\tag{37}
```

が確率収束する．

#### 10.3 低温相 $T<T_c$

補助的なフガシティとして $z=1$ を選ぶ．
有限体積では基底状態を除いているため， $\Xi_{\mathrm{ex},L}(1)$ は有限である．

励起粒子数の平均密度は，

```math
\lim_{V\to\infty}
\frac{\mathbb E_1[M]}V
=
\rho_c(T)
```

である．
ただし，

```math
\rho_c(T)=C_T\zeta\left(\frac32\right)
```

とする．

励起粒子数の分散は，

```math
\operatorname{Var}_1(M)
=
\sum_{\boldsymbol p\neq0}
\bar n_{\boldsymbol p}
(1+\bar n_{\boldsymbol p})
```

である．

低運動量では，

```math
\bar n_{\boldsymbol p}
(1+\bar n_{\boldsymbol p})
=O(p^{-4})
```

となる．

運動量を離散化すると，低運動量部分は，

```math
O(L^4)
\sum_{\boldsymbol n\neq0}
\frac1{|\boldsymbol n|^4}
```

で抑えられる．
三次元では，

```math
\sum_{\boldsymbol n\neq0}
\frac1{|\boldsymbol n|^4}<\infty
```

であり，高運動量部分の寄与は $O(L^3)$ である．

よって，

```math
\boxed{
\operatorname{Var}_1(M)=O(L^4)
}
```

となる．

$V=L^3$ であるため，

```math
\frac{\operatorname{Var}_1(M)}{V^2}
=
O(L^{-2})\longrightarrow0
```

である．

Chebyshev の不等式から，

```math
\boxed{
\frac MV\longrightarrow\rho_c(T)
}
```

が確率収束する．

低温相では，

```math
\rho>\rho_c(T)
```

であるため，

```math
P_{L,1}(M\leq N)\longrightarrow1
```

となる．

式 (36) で $z=1$ とすれば，正準集団の励起粒子数分布は， $P_{L,1}(M)$ を $M\leq N$ に制限して正規化したものである．
制限事象の確率が1に収束するため，正準集団でも，

```math
\frac MV\longrightarrow\rho_c(T)
```

が確率収束する．

したがって，

```math
\frac{N_0}{V}
=
\frac NV-\frac MV
\longrightarrow
\rho-\rho_c(T)
```

である．

よって，

```math
\boxed{
\lim_{N,V\to\infty}
\frac{\langle N_0\rangle}{N}
=
1-\left(\frac{T}{T_c}\right)^{3/2}
}
\qquad(T<T_c)
\tag{38}
```

となる．

ここで $0\leq N_0/N\leq1$ であるため，有界性と確率収束から期待値の極限も成立する．

#### 10.4 高温相および臨界点 $T\geq T_c$

この場合，

```math
\rho\leq\rho_c(T)
```

である．

任意の十分小さい $\eta>0$ に対して，

```math
0<\eta<\rho
```

とし，

```math
\rho-\frac{\eta}{2}<\rho_z<\rho
```

となる $0<z<1$ を選ぶ．
これは，

```math
\rho_z=C_T\operatorname{Li}_{3/2}(z)
```

が連続かつ狭義単調増加し，

```math
\lim_{z\to1^-}\rho_z=\rho_c(T)\geq\rho
```

となるため可能である．

さらに，

```math
0<\delta<
\min\left\{
\frac{\rho_z}{2},
\frac{\eta}{4},
\frac{\rho-\rho_z}{2}
\right\}
```

とする．

集合

```math
B_V=
\left\{
M:
(\rho_z-\delta)V
\leq M
\leq
(\rho_z+\delta)V
\right\}
```

を考える．
式 (37) より，

```math
P_{L,z}(B_V)\longrightarrow1
```

である．

また，

```math
\rho_z+\delta<\rho
```

なので，十分大きな $V$ では $B_V$ は $M\leq N$ に含まれる．

基底状態に粒子が $\eta V$ 以上存在する事象は，

```math
M\leq N-\eta V
```

に対応する．

以下では，有限体積の密度を

```math
\rho_V=\frac NV
```

とし，極限密度 $\rho$ と区別する．

式 (36) の分母を $B_V$ 上で評価すると，

```math
\sum_{j=0}^{N}P_{L,z}(j)z^{-j}
\geq
P_{L,z}(B_V)
z^{-(\rho_z-\delta)V}
```

となる．

一方，分子については，

```math
\sum_{M\leq N-\eta V}
P_{L,z}(M)z^{-M}
\leq
z^{-(\rho_V-\eta)V}
```

である．

したがって，

```math
\begin{aligned}
P_{N,L}(M\leq N-\eta V)
&\leq
\frac{
z^{-(\rho_V-\eta)V}
}{
P_{L,z}(B_V)
z^{-(\rho_z-\delta)V}
}\\
&=
\frac{
z^{(\rho_z-\delta-\rho_V+\eta)V}
}{
P_{L,z}(B_V)
}.
\end{aligned}
```

ここで，

```math
\rho_z>\rho-\frac{\eta}{2},
\qquad
\delta<\frac{\eta}{4},
\qquad
\rho_V\longrightarrow\rho
```

より，十分大きな $V$ では，

```math
\rho_z-\delta-\rho_V+\eta
>
\frac{\eta}{8}>0
```

となる．

$0<z<1$ であるから，

```math
z^{(\rho_z-\delta-\rho_V+\eta)V}
\longrightarrow0
```

である．
また，

```math
P_{L,z}(B_V)\longrightarrow1
```

なので，

```math
P_{N,L}(M\leq N-\eta V)
\longrightarrow0
```

が成立する．

したがって，

```math
\boxed{
\frac{N_0}{V}\longrightarrow0
}
```

が確率収束する．

さらに $0\leq N_0/N\leq1$ であるから，

```math
\boxed{
\lim_{N,V\to\infty}
\frac{\langle N_0\rangle}{N}=0
}
\qquad(T\geq T_c)
\tag{39}
```

となる．

以上より，正準集団でも，

```math
T>T_c\Longrightarrow N_0=o(N)
```

および，

```math
T<T_c\Longrightarrow N_0=\Theta(N)
```

が成立する．

### 11．正準集団の自由エネルギーと化学ポテンシャル

正準集団における熱力学的化学ポテンシャルは，Helmholtz 自由エネルギー密度 $f(T,\rho)$ によって，

```math
\mu=
\left(\frac{\partial f}{\partial\rho}\right)_T
```

と定義される．

#### 11.1 励起状態の大正準分配関数

励起状態の大正準分配関数は，

```math
\Xi_{\mathrm{ex},L}(z)
=
\prod_{\boldsymbol p\neq0}
\frac1{1-ze^{-\beta\varepsilon_{\boldsymbol p}}}
```

である．
したがって，

```math
\log\Xi_{\mathrm{ex},L}(z)
=
\sum_{\boldsymbol p\neq0}
\sum_{\ell=1}^{\infty}
\frac{z^\ell e^{-\ell\beta\varepsilon_{\boldsymbol p}}}{\ell}
```

となる．

三次元 Gaussian 積分より，

```math
\int
\frac{d^3p}{(2\pi\hbar)^3}
e^{-\ell\beta p^2/(2m)}
=
C_T\ell^{-3/2}
```

である．

したがって，

```math
\boxed{
\lim_{V\to\infty}
\frac1V\log\Xi_{\mathrm{ex},L}(z)
=
C_T\operatorname{Li}_{5/2}(z)
}
\qquad(0<z\leq1)
\tag{40}
```

となる．
ここで，

```math
\operatorname{Li}_{5/2}(z)
=
\sum_{\ell=1}^{\infty}
\frac{z^\ell}{\ell^{5/2}}
```

と定義した．

特に，

```math
\boxed{
\lim_{V\to\infty}
\frac1V\log\Xi_{\mathrm{ex},L}(1)
=
C_T\zeta\left(\frac52\right)
}
\tag{41}
```

である．

この極限を正当化するため，Gaussian 格子和について，ある定数 $C>0$ に対し，

```math
\frac1{L^3}
\sum_{\boldsymbol n\neq0}
e^{-c\ell|\boldsymbol n|^2/L^2}
\leq C\ell^{-3/2}
```

という一様評価を用いる．

これは Gaussian の格子和の評価から得られる．
したがって，対数分配関数の級数は，

```math
C\sum_{\ell=1}^{\infty}\ell^{-5/2}
```

によって支配される．
右辺は収束するため，支配収束定理によって級数と熱力学的極限の交換が正当化される．

#### 11.2 正準分配関数の熱力学的極限

正準分配関数は，

```math
Z_{N,L}
=
\sum_{M=0}^{N}Z_{\mathrm{ex},L}(M)
```

である．
また，

```math
P_{L,z}(M)
=
\frac{Z_{\mathrm{ex},L}(M)z^M}
{\Xi_{\mathrm{ex},L}(z)}
```

より，

```math
Z_{N,L}
=
\Xi_{\mathrm{ex},L}(z)
\sum_{M=0}^{N}P_{L,z}(M)z^{-M}
```

と書ける．

**（i）正常相 $\rho<\rho_c(T)$**

連続性と単調性から，

```math
\rho=C_T\operatorname{Li}_{3/2}(z_*)
```

を満たす一意な $z_*\in(0,1)$ が存在する．

$M\leq N$ では，

```math
z_*^{-M}\leq z_*^{-N}
```

なので，

```math
Z_{N,L}
\leq
\Xi_{\mathrm{ex},L}(z_*)z_*^{-N}
```

である．
したがって，

```math
\limsup_{V\to\infty}
\frac1V\log Z_{N,L}
\leq
C_T\operatorname{Li}_{5/2}(z_*)
-\rho\log z_*
```

となる．
ここでは $N/V=\rho_V\to\rho$ を用いた．

次に， $0<z<z_*$ を選び，

```math
\rho_z=C_T\operatorname{Li}_{3/2}(z)<\rho
```

とする．

```math
\delta_z=
\frac12\min\{\rho_z,\rho-\rho_z\}
```

とおけば， $\delta_z>0$ であり，

```math
B_V=
\left\{
M:
(\rho_z-\delta_z)V
\leq M
\leq
(\rho_z+\delta_z)V
\right\}
```

の確率は式 (37) より1に収束する．

また，

```math
\rho_z+\delta_z<\rho
```

なので，十分大きな $V$ では $B_V$ は $M\leq N$ に含まれる．

したがって，

```math
Z_{N,L}
\geq
\Xi_{\mathrm{ex},L}(z)
P_{L,z}(B_V)
z^{-(\rho_z-\delta_z)V}
```

である．

極限を取ると，

```math
\liminf_{V\to\infty}
\frac1V\log Z_{N,L}
\geq
C_T\operatorname{Li}_{5/2}(z)
-(\rho_z-\delta_z)\log z
```

となる．

ここで $z\to z_*^-$ とすれば，

```math
\rho_z\to\rho,
\qquad
\delta_z\to0
```

となる．
したがって，

```math
\boxed{
\lim_{V\to\infty}
\frac1V\log Z_{N,L}
=
C_T\operatorname{Li}_{5/2}(z_*)
-\rho\log z_*
}
\tag{42}
```

を得る．

**（ii）凝縮相 $\rho\geq\rho_c(T)$**

まず，

```math
Z_{N,L}\leq\Xi_{\mathrm{ex},L}(1)
```

であるため，

```math
\limsup_{V\to\infty}
\frac1V\log Z_{N,L}
\leq
C_T\zeta\left(\frac52\right)
```

となる．

一方，任意の $0<z<1$ に対して，

```math
\rho_z=C_T\operatorname{Li}_{3/2}(z)
<
\rho_c(T)\leq\rho
```

である．

```math
\delta_z=
\frac12\min\{\rho_z,\rho-\rho_z\}
```

とすれば，正常相と同じ下側評価から，

```math
\liminf_{V\to\infty}
\frac1V\log Z_{N,L}
\geq
C_T\operatorname{Li}_{5/2}(z)
-(\rho_z-\delta_z)\log z
```

となる．

ここで $z\to1^-$ とすると，

```math
\operatorname{Li}_{5/2}(z)
\longrightarrow
\zeta\left(\frac52\right)
```

であり， $\rho_z$ と $\delta_z$ は有界なので，

```math
(\rho_z-\delta_z)\log z\longrightarrow0
```

となる．

したがって，

```math
\boxed{
\lim_{V\to\infty}
\frac1V\log Z_{N,L}
=
C_T\zeta\left(\frac52\right)
}
\qquad(\rho\geq\rho_c(T))
\tag{43}
```

である．

#### 11.3 自由エネルギー密度

Helmholtz 自由エネルギー密度は，

```math
f(T,\rho)
=
-kT\lim_{V\to\infty}
\frac1V\log Z_{N,L}
```

である．

式 (42)，(43) より，

```math
\boxed{
f(T,\rho)=
\begin{cases}
kT\rho\log z_*
-kTC_T\operatorname{Li}_{5/2}(z_*),
& \rho<\rho_c(T),\\[6pt]
-kTC_T\zeta\left(\dfrac52\right),
& \rho\geq\rho_c(T).
\end{cases}
}
\tag{44}
```

ここで，正常相では，

```math
\rho=C_T\operatorname{Li}_{3/2}(z_*)
```

である．

ポリログ関数の微分公式，

```math
\frac{d}{dz}\operatorname{Li}_s(z)
=
\frac1z\operatorname{Li}_{s-1}(z)
```

より，

```math
\frac{d\rho}{dz_*}
=
\frac{C_T}{z_*}\operatorname{Li}_{1/2}(z_*)
```

である．

式 (44) の正常相の部分を微分すると，

```math
\begin{aligned}
\frac{df}{dz_*}
&=
kT\log z_*\frac{d\rho}{dz_*}
+\frac{kT\rho}{z_*}
-\frac{kTC_T}{z_*}\operatorname{Li}_{3/2}(z_*)\\
&=
kT\log z_*\frac{d\rho}{dz_*}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\mu=
\left(\frac{\partial f}{\partial\rho}\right)_T
=
kT\log z_*
}
\qquad(\rho<\rho_c(T))
\tag{45}
```

である．

一方，凝縮相では，

```math
f(T,\rho)
=
-kTC_T\zeta\left(\frac52\right)
```

であり，粒子数密度に依存しない．
よって，

```math
\boxed{
\mu=
\left(\frac{\partial f}{\partial\rho}\right)_T
=0
}
\qquad(\rho>\rho_c(T))
\tag{46}
```

となる．

#### 11.4 臨界密度での微分可能性

臨界密度では，

```math
\rho\to\rho_c(T)^-
```

に対して，

```math
z_*\to1^-
```

となる．
したがって，

```math
\lim_{\rho\to\rho_c(T)^-}
kT\log z_*=0
```

である．

さらに，式 (44) の正常相の自由エネルギーは，

```math
\lim_{\rho\to\rho_c(T)^-}f(T,\rho)
=
-kTC_T\zeta\left(\frac52\right)
```

となり，凝縮相側の値と一致する．

ここで $h<0$ に対して平均値の定理を用いると，ある $\xi_h\in(\rho_c(T)+h,\rho_c(T))$ が存在し，

```math
\frac{
f(T,\rho_c(T)+h)-f(T,\rho_c(T))
}{h}
=
\left.
\frac{\partial f}{\partial\rho}
\right|_{\rho=\xi_h}
```

となる．

$h\to0^-$ とすると，

```math
\xi_h\to\rho_c(T)^-
```

であるから，

```math
\frac{\partial f}{\partial\rho}
\longrightarrow0
```

となる．

一方，凝縮相側では自由エネルギーが一定なので，右側の差分商もゼロである．

したがって，

```math
\boxed{
\left.
\frac{\partial f}{\partial\rho}
\right|_{\rho=\rho_c(T)}
=0
}
```

となる．

以上から，正準集団の熱力学的極限では，

```math
\boxed{
\mu=0
\qquad(\rho\geq\rho_c(T))
}
\tag{47}
```

が成立する．

固定粒子数密度 $\rho$ の系では，これは $T\leq T_c$ に対応する．

### 12．絶対零度 $T=0$

ここまでの積分および統計的な極限では，

```math
\beta=\frac1{kT}
```

を用いているため， $T>0$ を仮定している．

したがって， $T=0$ は独立に扱う．

三次元自由理想 Bose 気体では，基底状態のエネルギーがゼロであり，それ以外の状態のエネルギーは正である．

したがって，絶対零度では全粒子が基底状態に存在する．

```math
\boxed{N_0=N}
```

また，基底状態の全エネルギーは，

```math
E_0(N)=0
```

であるから，零温度の化学ポテンシャルは粒子数を1個増やしたときの基底エネルギーの増加，

```math
\mu_0=E_0(N+1)-E_0(N)
```

で与えられる．
よって，

```math
\boxed{\mu_0=0}
```

である．

### 13．結論

以上より，三次元自由理想 Bose 気体では，臨界温度

```math
\boxed{
T_c=
\frac{2\pi\hbar^2}{mk}
\left[
\frac{\rho}{\zeta(3/2)}
\right]^{2/3}
}
```

を境として，次の性質が成立する．

**$T>T_c$ の場合**

```math
\boxed{
\lim_{N,V\to\infty}\frac{N_0}{N}=0
}
```

したがって，

```math
\boxed{N_0=o(N)}
```

であり，化学ポテンシャルは負の値をとる．

**$T=T_c$ の場合**

```math
\boxed{
\lim_{N,V\to\infty}\frac{N_0}{N}=0
}
```

であるが，

```math
\boxed{\mu\to0^-}
```

となる．

**$0<T<T_c$ の場合**

```math
\boxed{
\lim_{N,V\to\infty}\frac{N_0}{N}
=
1-\left(\frac{T}{T_c}\right)^{3/2}>0
}
```

である．
したがって，

```math
\boxed{N_0=\Theta(N)}
```

となり，

```math
\boxed{\mu\to0^-}
```

である．

**$T=0$ の場合**

```math
\boxed{N_0=N,\qquad\mu=0}
```

である．

以上より，三次元自由理想 Bose 気体では，臨界温度以下において化学ポテンシャルが最低エネルギーに一致し，基底状態に巨視的な数の粒子が集中する．
