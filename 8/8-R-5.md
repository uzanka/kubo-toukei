# 例題【8-R-5】

## 解答

### 1．粒子数を基底状態と励起状態に分ける

体積 $V$ ，粒子数 $N$ の理想 Bose 気体を考える．
1粒子準位のエネルギーを $\varepsilon_i$ ，化学ポテンシャルを $\mu$ ，ボルツマン定数を $k$ ，絶対温度を $T$ とし，

```math
\beta=\frac{1}{kT}
```

とおく．
Bose-Einstein 分布によれば，エネルギー $\varepsilon_i$ の1粒子準位に存在する粒子の平均数は

```math
\frac{1}{e^{\beta(\varepsilon_i-\mu)}-1}
```

である．
したがって，粒子の総数は

```math
N=\sum_i\frac{1}{e^{\beta(\varepsilon_i-\mu)}-1}
\tag{1}
```

と表される．

ここで，エネルギーの原点を最低エネルギー状態 $\boldsymbol{p}=0$ に選び，そのエネルギーを $\varepsilon_0=0$ とする．
最低エネルギー状態にある粒子数を $N_0$ ，それ以外の状態にある粒子数を $N'$ とすれば，

```math
N=N_0+N'
\tag{2}
```

である．
最低エネルギー状態の縮退度を $g_0=1$ とすると，

```math
N_0=\frac{1}{e^{-\beta\mu}-1}
\tag{3}
```

となる．
一方，励起状態の粒子数は

```math
N'=\sum_{i\ne0}\frac{1}{e^{\beta(\varepsilon_i-\mu)}-1}
\tag{4}
```

である．

Bose-Einstein 分布の分母が正であるためには，化学ポテンシャルは最低エネルギー以下でなければならない．
したがって，

```math
\mu\leq0
\tag{5}
```

である．

### 2．励起状態に存在できる粒子数の上限

系の体積が十分大きい場合，励起状態の和は状態密度 $D(\varepsilon)$ を用いた積分で近似できる．
三次元の自由 Bose 気体について，状態密度は

```math
D(\varepsilon)=
\frac{V}{4\pi^2}
\left(\frac{2m}{\hbar^2}\right)^{3/2}
\varepsilon^{1/2}
\tag{6}
```

である．
ここで， $m$ は粒子の質量， $\hbar=h/(2\pi)$ は換算 Planck 定数である．

式 (4) は，連続状態に対する積分を用いて，

```math
N'\approx\int_0^\infty
\frac{D(\varepsilon)}
{e^{\beta(\varepsilon-\mu)}-1}
\,d\varepsilon
\tag{7}
```

と表される．
式 (6) を代入すると，

```math
\begin{aligned}
N'={}&\frac{V}{4\pi^2}
\left(\frac{2m}{\hbar^2}\right)^{3/2}\\
&\times\int_0^\infty
\frac{\varepsilon^{1/2}}
{e^{\beta(\varepsilon-\mu)}-1}
\,d\varepsilon
\end{aligned}
\tag{8}
```

となる．

ここで，積分変数を

```math
x=\beta\varepsilon=\frac{\varepsilon}{kT},
\qquad
\alpha=-\beta\mu=-\frac{\mu}{kT}
\tag{9}
```

と変換する．
式 (5) より $\alpha\geq0$ である．
この変数変換を行うと，

```math
\begin{aligned}
N'={}&V\left(\frac{mkT}{2\pi\hbar^2}\right)^{3/2}\\
&\times\frac{2}{\sqrt{\pi}}
\int_0^\infty
\frac{x^{1/2}}{e^{x+\alpha}-1}\,dx
\end{aligned}
\tag{10}
```

を得る．

ここで，次の関数を定義する．

```math
F_{3/2}(\alpha)
=\frac{2}{\sqrt{\pi}}
\int_0^\infty
\frac{x^{1/2}}{e^{x+\alpha}-1}\,dx
\tag{11}
```

この関数は，指数関数を級数展開することで，

```math
F_{3/2}(\alpha)
=\sum_{\ell=1}^{\infty}
\frac{e^{-\ell\alpha}}{\ell^{3/2}}
\tag{12}
```

とも表される．
これを用いれば，式 (10) は

```math
\boxed{
N'=V\left(\frac{mkT}{2\pi\hbar^2}\right)^{3/2}
F_{3/2}(\alpha)
}
\tag{13}
```

となる．

式 (12) から， $\alpha$ が大きくなるにつれて各項が減少することが分かる．
したがって， $F_{3/2}(\alpha)$ は $\alpha\geq0$ で単調減少し，その最大値は $\alpha=0$ ，すなわち $\mu=0$ のときに得られる．

```math
\begin{aligned}
F_{3/2}(\alpha)
&\leq F_{3/2}(0)\\
&=\sum_{\ell=1}^{\infty}\frac{1}{\ell^{3/2}}\\
&=\zeta\left(\frac32\right)\\
&\approx2.612
\end{aligned}
\tag{14}
```

ここで， $\zeta(s)$ は Riemann のゼータ関数である．

式 (13)，(14) より，励起状態に存在できる粒子数には

```math
\boxed{
N'\leq
V\left(\frac{mkT}{2\pi\hbar^2}\right)^{3/2}
\zeta\left(\frac32\right)
}
\tag{15}
```

という上限がある．
この上限を $N_{\max}(T)$ とすると，

```math
N_{\max}(T)=
V\left(\frac{mkT}{2\pi\hbar^2}\right)^{3/2}
\zeta\left(\frac32\right)
\tag{16}
```

である．
特に， $N_{\max}(T)\propto T^{3/2}$ であるから，温度が低下すると励起状態に存在できる粒子数の上限も減少する．

### 3．臨界温度 $T_c$ の導出

臨界温度 $T_c$ を，励起状態に存在できる粒子数の最大値が全粒子数 $N$ に等しくなる温度として定義する．
したがって，

```math
N=V\left(\frac{mkT_c}{2\pi\hbar^2}\right)^{3/2}
\zeta\left(\frac32\right)
\tag{17}
```

である．
これを粒子数密度 $\rho=N/V$ を用いて書き直すと，

```math
\rho=
\zeta\left(\frac32\right)
\left(\frac{mkT_c}{2\pi\hbar^2}\right)^{3/2}
\tag{18}
```

となる．
よって，臨界温度は

```math
\boxed{
T_c=\frac{2\pi\hbar^2}{mk}
\left[
\frac{\rho}{\zeta(3/2)}
\right]^{2/3}
}
\tag{19}
```

で与えられる．

#### $T>T_c$ の場合

式 (16)，(17) より，

```math
N_{\max}(T)=N\left(\frac{T}{T_c}\right)^{3/2}
\tag{20}
```

である．
$T>T_c$ では $N_{\max}(T)>N$ であるため，全粒子を励起状態に収容することが可能である．
したがって，熱力学的極限では基底状態への巨視的な粒子の集中は起こらず，化学ポテンシャルは

```math
\mu<0
\tag{21}
```

となる．

このとき， $\alpha=-\beta\mu>0$ であり，基底状態の占有数は

```math
N_0=\frac{1}{e^\alpha-1}
\tag{22}
```

となる．
一定の温度 $T>T_c$ では，粒子数密度を一定に保ちながら体積を大きくしても $\alpha$ は有限の正の値に保たれる．
そのため， $N_0=O(1)$ である．
一方，全粒子数は $N=\rho V=O(V)$ である．
したがって，

```math
\boxed{N_0=o(N)}
\tag{23}
```

となる．
ここで， $O(N)$ は $N$ に比例する程度の大きさを， $o(N)$ は $N$ に比べて無視できる大きさを表し，いずれも熱力学的極限 $N,V\to\infty$ を考えている．

#### $T<T_c$ の場合

$T<T_c$ では，

```math
N_{\max}(T)<N
\tag{24}
```

となる．
この温度では，励起状態だけでは全粒子を収容できない．
したがって，励起状態に収容できない粒子が最低エネルギー状態へ集まり，基底状態の占有数が巨視的な大きさになる．

このとき，熱力学的極限では励起状態の粒子数がその最大値に達し， $\mu\to0^-$ となる．
励起状態の粒子数は，式 (13)，(14) より，

```math
N'=V\left(\frac{mkT}{2\pi\hbar^2}\right)^{3/2}
\zeta\left(\frac32\right)
\tag{25}
```

である．
式 (17) と式 (25) を比較すると，

```math
\boxed{
N'=N\left(\frac{T}{T_c}\right)^{3/2}
}
\tag{26}
```

を得る．

式 (2) より $N_0=N-N'$ であるため，

```math
\boxed{
N_0=N\left[
1-\left(\frac{T}{T_c}\right)^{3/2}
\right]
}
\tag{27}
```

となる．
一定の $T<T_c$ では，角括弧内は正の定数である．
したがって，

```math
\boxed{N_0=O(N)}
\tag{28}
```

である．
つまり，臨界温度以下では，基底状態に存在する粒子数が全粒子数と同じ次数の大きさになる．
これが Bose-Einstein 凝縮である．

### 4．化学ポテンシャルが $\mu=0$ となること

Bose-Einstein 分布では，化学ポテンシャルは最低エネルギー $\varepsilon_0=0$ 以下であり， $\mu\leq0$ である．
また，励起状態に収容できる粒子数は， $\mu\to0^-$ のときに最大となる．

$T<T_c$ では，式 (24) のとおり，全粒子を励起状態だけに収容することはできない．
そのため，励起状態の粒子数は最大値に達し，化学ポテンシャルは熱力学的極限で

```math
\boxed{\mu=0\qquad(T<T_c)}
\tag{29}
```

となる．

ただし，この等式は熱力学的極限での表現である．
有限体積の系では，式 (3) に $\mu=0$ を直接代入すると $N_0$ が発散するため，有限系では $\mu$ はわずかに負である．
凝縮相で $N_0$ が巨視的な大きさになると，

```math
\mu=-kT\log\left(1+\frac{1}{N_0}\right)
\approx-\frac{kT}{N_0}
\tag{30}
```

となり， $N_0=O(N)$ とともに $\mu\to0^-$ となるのである．

以上より，理想 Bose 気体では，臨界温度 $T_c$ より高温で $N_0=o(N)$ である一方，低温では $N_0=O(N)$ となり，熱力学的極限において化学ポテンシャルは $\mu=0$ に固定されることが示された．
これが Bose-Einstein 凝縮である．
