# 演習問題【8-R-6】

## 解答

### 1．光子気体の化学ポテンシャルがゼロである理由

化学ポテンシャル $\mu$ は，温度 $T$ と体積 $V$ を一定に保ったとき，粒子数 $N$ を1個変化させることに伴う自由エネルギーの変化を表す量である．
すなわち，

```math
\mu=\left(\frac{\partial F}{\partial N}\right)_{T,V}
```

である．

一般の Bose 気体では，粒子数が一定であるという制約条件のもとで分布を求めるため，化学ポテンシャル $\mu$ が現れる．
しかし，光子気体では，光子は物質によって放射・吸収されるため，光子の総数 $N$ は保存されない．
熱平衡状態における光子数は，温度 $T$ と体積 $V$ によって定まるのである．

したがって，光子気体では粒子数保存の制約条件を課す必要がなく，Bose 分布を導く際に，粒子数に対応する Lagrange の未定乗数は現れない．
これは，化学ポテンシャルを $\mu=0$ とすることに相当する．

また，自由エネルギーの観点からも，光子数が自由に変化できる熱平衡状態では，固定された温度と体積のもとで自由エネルギーが光子数について極小となる．
よって，

```math
\left(\frac{\partial F}{\partial N}\right)_{T,V}=0
```

であり，化学ポテンシャルの定義から，

```math
\boxed{\mu=0}
```

が得られる．

### 2．分配関数を用いた別解

光子気体において化学ポテンシャルがゼロとなることを，電磁場の分配関数からも示す．

容器内の電磁場は，固有振動数 $\nu_i$ をもつ独立な振動モードの重ね合わせとして表される．
各モードは量子調和振動子とみなすことができ，モード $i$ に含まれる光子数を $n_i=0,1,2,\ldots$ とすると，零点エネルギーを除いた電磁場のエネルギーは

```math
E=\sum_i n_i h\nu_i
\tag{1}
```

となる．
ここで， $h$ は Planck 定数である．
各振動モードのエネルギーは，光子1個当たり $h\nu_i$ である．

光子数は一定ではないため，分配関数では，それぞれのモードについて可能なすべての光子数を足し合わせる．
したがって，分配関数 $Z$ は

```math
\begin{aligned}
Z(T,V)
&=\sum_{n_0=0}^{\infty}
\sum_{n_1=0}^{\infty}\cdots
e^{-\beta\sum_i n_i h\nu_i}\\
&=\prod_i\sum_{n_i=0}^{\infty}
e^{-\beta n_i h\nu_i}
\end{aligned}
\tag{2}
```

と表される．
ここで， $\beta=1/(kT)$ である．

各モードについて，等比級数の公式

```math
\sum_{n=0}^{\infty}x^n=\frac{1}{1-x}
\qquad (|x|<1)
```

を用いると，

```math
\sum_{n_i=0}^{\infty}e^{-\beta n_i h\nu_i}
=\frac{1}{1-e^{-\beta h\nu_i}}
```

となる．
したがって，式 (2) は

```math
\boxed{
Z(T,V)=\prod_i
\frac{1}{1-e^{-\beta h\nu_i}}
}
\tag{3}
```

となる．

次に，モード $j$ に含まれる光子の平均数 $\overline{n}_j$ を求める．
その定義から，

```math
\overline{n}_j
=
\frac{\displaystyle\sum_{n_j=0}^{\infty}
n_j e^{-\beta n_j h\nu_j}}
{\displaystyle\sum_{n_j=0}^{\infty}
e^{-\beta n_j h\nu_j}}
\tag{4}
```

である．
ここで $q=e^{-\beta h\nu_j}$ とおくと，

```math
\sum_{n_j=0}^{\infty}q^{n_j}
=\frac{1}{1-q}
```

および，

```math
\sum_{n_j=0}^{\infty}n_jq^{n_j}
=\frac{q}{(1-q)^2}
```

が成り立つ．
したがって，式 (4) より，

```math
\begin{aligned}
\overline{n}_j
&=\frac{q/(1-q)^2}{1/(1-q)}\\
&=\frac{q}{1-q}\\
&=\frac{1}{e^{\beta h\nu_j}-1}
\end{aligned}
\tag{5}
```

を得る．

一方，化学ポテンシャル $\mu$ をもつ一般の Bose 気体に対する Bose-Einstein 分布は，

```math
\overline{n}_j
=\frac{1}{e^{\beta(h\nu_j-\mu)}-1}
\tag{6}
```

である．
式 (5) と式 (6) を比較すると，指数部が一致するため，

```math
h\nu_j-\mu=h\nu_j
```

となる．
よって，

```math
\boxed{\mu=0}
```

が得られる．

以上より，光子気体では光子数が保存されず，光子の生成・消滅が熱平衡で許されるため，化学ポテンシャルはゼロであることが示された．
