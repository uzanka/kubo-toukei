# 演習問題【8-A-7】

## 解答

### 1．非縮退極限におけるスピン磁化率

非縮退極限では，電子はMaxwell–Boltzmann統計で近似できる．
この場合，電子のスピン磁気モーメントは，磁場に平行な $+\mu_{\mathrm B}$ と逆平行な $-\mu_{\mathrm B}$ の2つの状態をとる．
ここで， $\mu_{\mathrm B}$ はBohr磁子， $H$ は磁場の大きさである．

磁場中では，磁気モーメントが平行な状態のエネルギーは $-\mu_{\mathrm B}H$ ，逆平行な状態のエネルギーは $+\mu_{\mathrm B}H$ となる．
Boltzmann分布に従うと，磁場に平行な方向への偏りが生じる．
その結果，単位体積あたりの磁気モーメント，すなわち磁化 $M$ は，

```math
M=n\mu_{\mathrm B}
\tanh\left(\frac{\mu_{\mathrm B}H}{kT}\right)
```

で表される．
ここで， $n$ は単位体積あたりの全電子数， $k$ はBoltzmann定数， $T$ は絶対温度である．

弱磁場条件 $\mu_{\mathrm B}H\ll kT$ では， $\tanh x\simeq x$ を使うことができるため，

```math
M\simeq n\mu_{\mathrm B}
\frac{\mu_{\mathrm B}H}{kT}
=\frac{n\mu_{\mathrm B}^{2}}{kT}H
```

となる．
磁化率を $\chi=M/H$ と定義すれば，

```math
\boxed{
\chi_{\infty}=\frac{n\mu_{\mathrm B}^{2}}{kT}
}
\tag{1}
```

を得る．
これはCurie則に対応する結果であり，非縮退極限では磁化率は温度 $T$ に反比例する．
温度が高くなるほど熱運動の影響が大きくなり，磁場によるスピンの偏りが小さくなるためである．

### 2．強縮退極限におけるスピン磁化率

一方，強く縮退している電子系では，電子はFermi–Dirac統計に従い，低いエネルギー状態から順に占有する．
絶対零度では，Fermiエネルギー $E_{\mathrm F}=\mu_0$ 以下の状態が満たされている．
ここで，Fermi温度を

```math
T_0=\frac{\mu_0}{k}
```

と定義する．
強縮退条件は $T\ll T_0$ である．

電子のスピンには2つの向きがあり，磁場を加えるとそれぞれのエネルギーが $\mp\mu_{\mathrm B}H$ だけ変化する．
しかし，低エネルギー状態はすでに電子で満たされているため，電子が熱的に状態を変えられる範囲は限られる．
磁場に応答して占有数の差を生み出すのは，主としてFermi準位の近傍にある電子である．

自由電子系の強縮退極限におけるスピン磁化率は，Fermi準位における状態密度を用いて

```math
\chi_0=2\mu_{\mathrm B}^{2}D(\mu_0)
```

と表される．
ここで $D(\varepsilon)$ はスピンの自由度を除いた，単位体積あたりの状態密度である．
3次元自由電子系では，

```math
D(\varepsilon)=C\sqrt{\varepsilon}
```

となる（ $C$ は電子密度などで決まる定数）．
絶対零度では，スピンの2重縮退を含めた電子数密度は

```math
n=2\int_0^{\mu_0}D(\varepsilon)\,d\varepsilon
=\frac43C\mu_0^{3/2}
```

である．
一方，

```math
D(\mu_0)=C\sqrt{\mu_0}
```

なので，

```math
D(\mu_0)=\frac{3n}{4\mu_0}
```

を得る．
これを磁化率の式に代入すると，

```math
\begin{aligned}
\chi_0
&=2\mu_{\mathrm B}^{2}\frac{3n}{4\mu_0}\\
&=\frac32\frac{n\mu_{\mathrm B}^{2}}{\mu_0}\\
&=\frac32\frac{n\mu_{\mathrm B}^{2}}{kT_0}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\chi_0=\frac32\frac{n\mu_{\mathrm B}^{2}}{kT_0}
}
\tag{2}
```

である．
これはPauliスピン常磁性磁化率である．
その先頭項は低温では温度に依存しない．
なお，有限温度による補正は，3次元自由電子系では低温で $T^2$ の次数から現れる．

### 3．2つの磁化率の比とその意味

式 (1) と式 (2) の比をとると，

```math
\begin{aligned}
\frac{\chi_0}{\chi_{\infty}}
&=
\frac{\dfrac32\dfrac{n\mu_{\mathrm B}^{2}}{kT_0}}
{\dfrac{n\mu_{\mathrm B}^{2}}{kT}}\\[4pt]
&=\boxed{\frac32\frac{T}{T_0}}
\end{aligned}
\tag{3}
```

となる．

この比は，強縮退極限での磁化率が，非縮退系に対する古典的な式で見積もった磁化率に比べてどの程度小さいかを示している．
ここで重要なのは，式 (3) が，強縮退極限と非縮退極限のそれぞれの公式を同じ温度 $T$ で比較した比である点である．
両方の近似が同時に成立するという意味ではない．
特に，強縮退極限で実際の磁化率が温度に比例するという意味でもない．

この比の物理的意味を理解するため，まず非縮退系の磁化率の式を考える．

```math
\chi_{\infty}=\frac{n\mu_{\mathrm B}^{2}}{kT}
```

は，全電子数 $n$ の電子が古典的に磁場へ応答できると考えた場合の結果である．
これに対して，強縮退した電子系では，Fermi準位より十分低い状態はほぼ完全に占有されている．
Pauliの排他律により，これらの電子が近くの状態へ移ることは容易ではない．

Fermi分布関数が1から0へ変化するエネルギー幅はおよそ $kT$ である．
一方，電子が占有するエネルギー領域の尺度はFermiエネルギー $\mu_0=kT_0$ である．
このため，熱的に状態を変え得る電子の割合は，概ね

```math
\frac{kT}{\mu_0}=\frac{T}{T_0}
```

の程度となる．
強縮退極限では $T/T_0\ll1$ なので，熱的に状態を変えられる電子は全電子のごく一部に限られる．
これが，Pauliスピン磁化率が古典的な非縮退系の値に比べて小さくなる理由である．

式 (3) に現れる $3/2$ は，自由電子系の磁化率を使って比較したときの係数である．
したがって， $3T/(2T_0)$ を「磁化率の比較から定義した有効的な電子割合」とみなすことはできるが，これを実際に数え上げた電子の割合と厳密に同一視すべきではない．
実際に磁化へ寄与する電子の範囲は，Fermi準位付近の状態密度や磁場による占有数の変化によって決まる．

以上より，強縮退した自由電子系では，電子のうちFermi準位近傍の限られた状態だけが磁場に応答するため，磁化率はPauli磁化率として低温でほぼ一定となる．
一方，非縮退極限では全電子が古典的に磁場に応答し，磁化率はCurie則に従って $1/T$ に比例する．
この違いが，両者の磁化率の比に表れているのである．
