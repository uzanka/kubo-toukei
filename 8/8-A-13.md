# 演習問題【8-A-13】

## 解答

価電子帯の上端をエネルギーの原点 $E_{\mathrm v}=0$ とし，アクセプタ準位のエネルギーを $E_A>0$ とする．
電子の化学ポテンシャルを $\mu$ ，ボルツマン定数を $k_{\mathrm B}$ とする．

以下では，アクセプタは互いに独立であり，空のアクセプタ状態 $A^0$ の縮退度は $1$ ，電子が1個占有した状態 $A^-$ のスピン縮退度は $2$ とする．
また，伝導帯の電子やドナーなど，ほかの電荷担体は無視できるものとする．
価電子帯は，単一の等方的な放物線バンドで近似し，その正孔の状態密度有効質量を $m_h^*$ とする．

### 1．アクセプタの占有確率

アクセプタに電子が存在しない状態の重みは $1$ であり，エネルギー $E_A$ の状態に電子が1個存在する場合の重みは，スピン縮退度を含めて

```math
2\exp\left[-\frac{E_A-\mu}{k_{\mathrm B}T}\right]
```

である．
したがって，アクセプタ1個の大分配関数は

```math
\Xi_A
=1+2\exp\left[-\frac{E_A-\mu}{k_{\mathrm B}T}\right]
```

となる．

アクセプタの総濃度を $N_A$ とし，電子が1個占有したイオン化アクセプタ $A^-$ の濃度を $N_A^-$ ，空のアクセプタ $A^0$ の濃度を $N_A^0$ とすると，

```math
N_A^-=
N_A
\frac{2\exp\left[-(E_A-\mu)/(k_{\mathrm B}T)\right]}
{1+2\exp\left[-(E_A-\mu)/(k_{\mathrm B}T)\right]}
```

および

```math
N_A^0=
N_A
\frac{1}
{1+2\exp\left[-(E_A-\mu)/(k_{\mathrm B}T)\right]}
```

である．
当然，

```math
N_A=N_A^-+N_A^0
```

が成り立つ．
両者の比をとると，

```math
\frac{N_A^-}{N_A^0}
=
2\exp\left[-\frac{E_A-\mu}{k_{\mathrm B}T}\right]
\tag{1}
```

を得る．

### 2．価電子帯の正孔濃度

価電子帯上端から下向きに測ったエネルギーを $\epsilon\geq 0$ とする．
このエネルギーにある価電子帯電子のエネルギーは $-\epsilon$ であるから，その電子の占有確率は

```math
f_e(\epsilon)
=
\frac{1}
{\exp\left[(-\epsilon-\mu)/(k_{\mathrm B}T)\right]+1}
```

である．
したがって，正孔の占有確率は

```math
f_h(\epsilon)=1-f_e(\epsilon)
=
\frac{1}
{\exp\left[(\epsilon+\mu)/(k_{\mathrm B}T)\right]+1}
```

となる．
ここで，正孔の化学ポテンシャルを

```math
\mu_h=-\mu
```

と定義すれば，

```math
f_h(\epsilon)
=
\frac{1}
{\exp\left[(\epsilon-\mu_h)/(k_{\mathrm B}T)\right]+1}
\tag{2}
```

と書ける．

正孔の状態密度を，単位体積・単位エネルギー・スピン1状態当たりの $D_1(\epsilon)$ とする．
単一の等方的な放物線バンドでは，正孔の分散関係は

```math
\epsilon=\frac{\hbar^2k^2}{2m_h^*}
```

であるから，状態密度は

```math
D_1(\epsilon)
=
\frac{1}{4\pi^2}
\left(\frac{2m_h^*}{\hbar^2}\right)^{3/2}
\sqrt{\epsilon}
\tag{3}
```

となる．
ここで， $\hbar=h/(2\pi)$ ， $h$ はプランク定数である．

スピン縮退度は $2$ なので，正孔濃度 $p$ は

```math
p
=
2\int_0^\infty D_1(\epsilon)f_h(\epsilon)\,d\epsilon
\tag{4}
```

で与えられる．

正孔が非縮退であるとき，すなわち

```math
\exp\left(\frac{\mu_h}{k_{\mathrm B}T}\right)\ll 1
```

のときには，ボルツマン近似

```math
f_h(\epsilon)
\simeq
\exp\left[-\frac{\epsilon-\mu_h}{k_{\mathrm B}T}\right]
```

を用いることができる．
これを式 (4) に代入すると，

```math
p
\simeq
2\exp\left(\frac{\mu_h}{k_{\mathrm B}T}\right)
\int_0^\infty
D_1(\epsilon)
\exp\left(-\frac{\epsilon}{k_{\mathrm B}T}\right)
\,d\epsilon
```

となる．
式 (3) と

```math
\int_0^\infty
\epsilon^{1/2}e^{-\epsilon/(k_{\mathrm B}T)}\,d\epsilon
=
\frac{\sqrt{\pi}}{2}(k_{\mathrm B}T)^{3/2}
```

を用いると，

```math
p=N_v\exp\left(\frac{\mu_h}{k_{\mathrm B}T}\right)
```

を得る．
ここで，

```math
N_v
=
2\left(\frac{2\pi m_h^*k_{\mathrm B}T}{h^2}\right)^{3/2}
\tag{5}
```

は価電子帯の有効状態密度である．
したがって，

```math
p=N_v\exp\left(-\frac{\mu}{k_{\mathrm B}T}\right)
```

であり，

```math
\exp\left(\frac{\mu}{k_{\mathrm B}T}\right)
=
\frac{N_v}{p}
\tag{6}
```

となる．
非縮退条件は，この近似の範囲では $p/N_v\ll 1$ と表せる．

### 3．正孔濃度とアクセプタ濃度の関係

式 (1) に式 (6) を代入すると，

```math
\frac{N_A^-}{N_A^0}
=
2\exp\left(-\frac{E_A}{k_{\mathrm B}T}\right)
\exp\left(\frac{\mu}{k_{\mathrm B}T}\right)
=
\frac{2N_v}{p}
\exp\left(-\frac{E_A}{k_{\mathrm B}T}\right)
```

となる．
よって，

```math
\frac{pN_A^-}{N_A^0}
=
2N_v\exp\left(-\frac{E_A}{k_{\mathrm B}T}\right)
\tag{7}
```

を得る．

ここで，伝導帯電子，ドナーおよびその他の荷電欠陥を無視すると，電荷中性条件は

```math
p=N_A^-
\tag{8}
```

である．
また，

```math
N_A^0=N_A-N_A^-=N_A-p
```

なので，式 (7) は

```math
\boxed{
\frac{p^2}{N_A-p}
=
2N_v\exp\left(-\frac{E_A}{k_{\mathrm B}T}\right)
}
\tag{9}
```

となる．
これが，正孔濃度の温度依存性を決める方程式である．

### 4．正孔濃度の温度依存性

式 (9) の右辺を

```math
B(T)=2N_v\exp\left(-\frac{E_A}{k_{\mathrm B}T}\right)
```

とおくと，

```math
p^2=B(T)(N_A-p)
```

である．
これを $p$ について解き，正の解を選ぶと，

```math
\boxed{
p(T)=
\frac{\sqrt{B(T)^2+4N_AB(T)}-B(T)}{2}
}
\tag{10}
```

を得る．
ただし，

```math
B(T)
=
4\left(\frac{2\pi m_h^*k_{\mathrm B}T}{h^2}\right)^{3/2}
\exp\left(-\frac{E_A}{k_{\mathrm B}T}\right)
```

である．
式 (10) が，この近似の範囲での正孔濃度の温度依存性を与える．

さらに， $E_A>0$ かつ $N_v\propto T^{3/2}$ であるから，

```math
\frac{d\ln B}{dT}
=
\frac{3}{2T}
+
\frac{E_A}{k_{\mathrm B}T^2}
>0
```

となり， $B(T)$ は温度とともに増加する．
また，

```math
F(p)=\frac{p^2}{N_A-p}
```

とおくと， $0<p<N_A$ において

```math
F'(p)
=
\frac{p(2N_A-p)}{(N_A-p)^2}>0
```

である．
したがって，式 (9) から，正孔濃度 $p$ は温度 $T$ とともに単調に増加する．

特に，次の二つの温度領域が得られる．

**低温領域（凍結領域）**

```math
B(T)\ll N_A
```

のときには，式 (9) の解は $p\ll N_A$ となるので，

```math
\frac{p^2}{N_A-p}\simeq\frac{p^2}{N_A}
```

と近似できる．
したがって，

```math
p\simeq\sqrt{N_AB(T)}
=
\sqrt{2N_AN_v}
\exp\left(-\frac{E_A}{2k_{\mathrm B}T}\right)
```

である．
式 (5) を代入すると，

```math
\boxed{
p\simeq
2\sqrt{N_A}
\left(\frac{2\pi m_h^*k_{\mathrm B}T}{h^2}\right)^{3/4}
\exp\left(-\frac{E_A}{2k_{\mathrm B}T}\right)
}
\tag{11}
```

となる．
すなわち，

```math
p\propto T^{3/4}
\exp\left(-\frac{E_A}{2k_{\mathrm B}T}\right)
```

であり，温度の低下とともに正孔濃度は指数関数的に減少する．

**高温側の外因性領域（アクセプタのほぼ完全イオン化）**

```math
B(T)\gg N_A
```

のときには，式 (9) より $p$ は $N_A$ に近づく．
したがって，

```math
\boxed{p\simeq N_A}
\tag{12}
```

となる．
この領域では，ほぼすべてのアクセプタがイオン化しており，正孔濃度はアクセプタ濃度によって決まる．

ただし，式 (12) が成り立つのは，正孔が非縮退であり，かつ伝導帯電子が無視できる温度範囲に限られる．
さらに温度を上げて真性キャリアが無視できなくなると，電荷中性条件は一般に

```math
p=n+N_A^-
```

となるため， $p\simeq N_A$ という近似は成立しなくなる．

以上より，伝導帯電子を無視できる範囲では，低温で正孔濃度は

```math
p\propto T^{3/4}
\exp\left(-\frac{E_A}{2k_{\mathrm B}T}\right)
```

に従って小さく，温度の上昇とともに増加し，アクセプタがほぼ完全にイオン化した高温側の外因性領域では

```math
p\simeq N_A
```

に近づく．
