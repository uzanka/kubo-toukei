# 演習問題【8-A-13】

## 解答

本問題では，単位体積あたり $N_A$ 個のアクセプターを含む半導体において，充満帯（価電子帯）に生じる空孔の密度 $p$ が温度 $T$ とともにどのように変化するかを求める．
アクセプターは電子を一つしか収容できないという制限があることに注意して，順を追って計算を進める．

### 1. アクセプターの占有状態

まず，アクセプター準位の状態について考える．
エネルギーの原点は充満帯の頂上（価電子帯の最上部）に設定する．
アクセプターのエネルギー準位は $E_A$ である．

アクセプターが電子を一つしか収容できないという条件の下では，アクセプターの占有状態は，「電子が $0$ 個の状態（空孔が存在する状態）」と「電子が $1$ 個の状態（空孔が存在しない状態）」の $2$ 通りしかない．

ここでは，スピン自由度を正しく考慮するため，大正準集団（グラウン・カノニカルアンサンブル）を用いて統計的に扱う．
許容される微視的状態は以下の $3$ つ：

- 状態 $0$ （電子が $0$ 個，空孔あり）: 統計的重量 = $1$
- 状態 $\uparrow$ （電子 $1$ 個，スピン上向き）: 統計的重量 = $e^{-(E_A - \mu)/kT}$
- 状態 $\downarrow$ （電子 $1$ 個，スピン下向き）: 統計的重量 = $e^{-(E_A - \mu)/kT}$

大配分関数 $\Xi$ は，

$$\Xi = 1 + 2e^{-(E_A - \mu)/kT}$$

したがって，平均電子数はスピンを考慮した正しい统计的な重みを用いて以下のように与えられる：

$$n_A = N_A \frac{2e^{-(E_A - \mu)/kT}}{1 + 2e^{-(E_A - \mu)/kT}} = \frac{2N_A}{e^{(E_A - \mu)/kT} + 2} \quad \cdots (1)$$

ここで $\mu$ はフェルミ準位（化学ポテンシャル）である．
式(1)の分母に現れる $2$ は，電子が存在する状態のスピンによる重率（ $g = 2$ ）に由来する．

アクセプターが空孔（電子がいない状態）である数 $p_A$ は，全体のアクセプター数 $N_A$ から電子が入っている数 $n_A$ を引いたものである：

$$p_A = N_A - n_A = N_A \frac{1}{1 + 2e^{-(E_A - \mu)/kT}} = \frac{N_A e^{(E_A - \mu)/kT}}{e^{(E_A - \mu)/kT} + 2} \quad \cdots (4)$$

### 2. 充満帯の空孔密度

次に，充満帯（価電子帯）における空孔の密度 $p$ について考える．
充満帯にある電子の密度 $n$ は，状態密度 $D(\epsilon)$ とFermi-Dirac分布を用いて次のように表される：

$$n = \int_{0}^{\infty} \frac{2D(\epsilon)}{e^{-(\epsilon + \mu)/kT} + 1} d\epsilon \quad \cdots (2)$$

ここで $\epsilon$ は充満帯の頂上からのエネルギーである．
空孔の密度 $p$ は，電子が占有していない状態の密度として，

```math
p = \int_{0}^{\infty} 2 \left\{ 1 - \frac{1}{e^{-(\epsilon + \mu)/kT} + 1} \right\} D(\epsilon) d\epsilon
```

括弧内を整理すると：

$$1 - \frac{1}{e^{-(\epsilon + \mu)/kT} + 1} = \frac{e^{-(\epsilon + \mu)/kT}}{e^{-(\epsilon + \mu)/kT} + 1} = \frac{1}{e^{(\epsilon + \mu)/kT} + 1}$$

したがって，

$$p = \int_{0}^{\infty} \frac{2D(\epsilon)}{e^{(\epsilon + \mu)/kT} + 1} d\epsilon$$

ここで $\mu = -\mu'$ とおくと，

$$p = \int_{0}^{\infty} \frac{2D(\epsilon)}{e^{(\epsilon - \mu')/kT} + 1} \quad \cdots (3)$$

これは，エネルギー $\epsilon$ ，Fermiポテンシャル $\mu'$ をもつ空孔に対するFermi統計の形式となっている．

空孔が縮退していない（非縮退近似： $e^{(\epsilon - \mu')/kT} \gg 1$ ）と仮定すると，分母の $+1$ を無視できて，

$$p = 2 \left( \frac{2\pi m_n kT}{h^2} \right)^{3/2} e^{\mu'/kT} \equiv N_c e^{\mu'/kT} \quad \cdots (5)$$

ここで $N_c$ は充満帯の有効状態密度である．

### 3. 電荷中性の条件と温度依存性

半導体が電気的に中性であるためには，充満帯の空孔の数 $p$ とイオン化されたアクセプター（電子を収容した負電荷を持つアクセプター）の密度が等しくなければならない：

$$p = N_A - p_A \quad \cdots (6')$$

式(4)を変形すると，

$$\frac{N_A - p_A}{p_A} = \frac{2e^{-(E_A - \mu)/kT}}{1} = 2e^{-E_A/kT} e^{\mu/kT}$$

式(5)から $e^{\mu/kT} = e^{-\mu'/kT} = N_c/p$ より，

$$\frac{N_A - p_A}{p_A} = 2 \frac{N_c}{p} e^{-E_A/kT}$$

これを整理すると，以下の質量作用の法則が得られる：

$$\frac{p(N_A - p_A)}{p_A} = 2N_c e^{-E_A/kT} \quad \cdots (6)$$

これは， $A \to A^- + h$ （ $h=$ 空孔）という反応の質量作用の法則を表す．
ここで現れる prefactor $2$ は，アクセプター準位のスピン重率 $g = 2$ に由来する．

温度による挙動を考察する．

#### (i) 低温（第1の不純物完全イオン化前領域）

低温では，アクセプターは完全にイオン化されていないが， $p \ll N_A$ の領域を考える．
この極限では，大半のアクセプターがイオン化されているので $p_A \approx N_A$ と近似できる．
電荷中性条件(6')から $p = N_A - p_A$ を式(6)に代入すると，

$$\frac{p^2}{p_A} = 2N_c e^{-E_A/kT}$$

$p_A \approx N_A$ とおくと，

$$p \approx \sqrt{2N_c N_A}\, e^{-E_A/2kT} = 2N_A^{1/2} \left( \frac{2\pi m_n kT}{h^2} \right)^{3/4} e^{-E_A/2kT}$$

空孔密度 $p$ は，指数関数的に増大するほか， prefactor に $T^{3/4}$ の温度依存性を持つ．

#### (ii) 高温（飽和・完全国子化領域）

温度がさらに上がると，アクセプターのイオン化が完全に進み，すべてのアクセプターが空孔を放出する飽和領域に入る．
この極限では $e^{(E_A - \mu)/kT} \ll 1$ となり，式(4)から $p_A \to 0$ （すべてのアクセプターがイオン化）となる．
電荷中性条件より，

$$p = N_A - p_A \to N_A$$

すなわち充満帯の空孔密度はアクセプター密度に飽和する：

$$p \sim N_A$$

注意： これは飽和（完全国子化）領域での結果であり，さらに高温で内生キャリア（正孔-電子対の熱励起）が支配的になるときは $p \sim n_i \gg N_A$ となる．

## 解説

### スピン重率因子についての注記

アクセプター準位における統計的な重率は以下の由来を持つ：

- 空の状態（電子なし）: 重率 $g_0 = 1$
- 電子が $1$ 個ある状態: スピン自由度により重率 $g_e = 2$ （スピン上向き・下向き）

この重率の比 $g_0/g_e = 1/2$ が，式(1)の prefactor および分母の係数に現れる．
大正準集団による正しい導出では，許容状態が「空（重率 $1$ ）」と「電子あり（重率 $2$）」の $2$ つであり，平均電子数は

$$n_A = N_A \frac{g_e e^{-(E_A - \mu)/kT}}{g_0 + g_e e^{-(E_A - \mu)/kT}} = N_A \frac{2e^{-(E_A - \mu)/kT}}{1 + 2e^{-(E_A - \mu)/kT}}$$

となる．これが式(1)の正しい形である．

もし，一つのアクセプターがスピンの方向に依らずそれぞれ独立に電子を収容できる（スピン重率が効かない）場合は， $g_0 = g_e = 1$ となり，従来のFermi分布と同じ形になる．
しかし実際の半導体では，アクセプター準位はスピン自由度を持つため，重率 $2$ が統計因子として働く．
