# 演習問題【8-A-13】

## 解答

本問題では，単位体積当たり $N_A$ 個のアクセプターを含む半導体について，充満帯に生じる空孔の密度 $p$ が温度 $T$ とともにどのように変化するかを求める．

アクセプターは電子を1個しか収容できないため，電子のスピンによる重率を考慮する必要がある．
まずアクセプターに収容された電子の密度を求め，次に充満帯の空孔密度を計算する．
最後に，両者を結び付ける電荷中性条件から，空孔密度の温度依存性を導く．

### 1．アクセプターに収容された電子の密度

エネルギーの原点を充満帯の頂上に取り，アクセプターのエネルギー準位を $E_A$ とする．
また，化学ポテンシャルを $\mu$ ，ボルツマン定数を $k$ とする．

アクセプターは電子を1個しか収容できないので，許される状態は，電子を収容していない状態と，電子を1個収容している状態である．

電子を収容していない状態の統計的重率は $1$ である．
一方，電子を1個収容している状態では，電子のスピンの向きが2通りあるため，統計的重率は $2$ である．
したがって，アクセプター1個についての大分配関数は

```math
\Xi_A=1+2e^{-(E_A-\mu)/kT}
```

となる．

電子を収容した状態の統計的重率を考慮すると，アクセプターが電子を収容している確率は

```math
\frac{2e^{-(E_A-\mu)/kT}}
{1+2e^{-(E_A-\mu)/kT}}
```

である．
よって，アクセプターに収容された電子の密度 $n_A$ は

```math
\begin{aligned}
n_A
&=N_A\frac{2e^{-(E_A-\mu)/kT}}
{1+2e^{-(E_A-\mu)/kT}}\\[4pt]
&=\frac{2N_A}{e^{(E_A-\mu)/kT}+2}
\end{aligned}
\tag{1}
```

となる．

電子を収容していないアクセプターの密度を $p_A$ とすると，全アクセプターの密度は $N_A$ であるから，

```math
p_A=N_A-n_A
```

である．
式(1)を代入すれば，

```math
\begin{aligned}
p_A
&=N_A\left(
1-\frac{2}{e^{(E_A-\mu)/kT}+2}
\right)\\[4pt]
&=\frac{N_Ae^{(E_A-\mu)/kT}}
{e^{(E_A-\mu)/kT}+2}\\[4pt]
&=\frac{N_A}
{1+2e^{-(E_A-\mu)/kT}}
\end{aligned}
\tag{2}
```

が得られる．

### 2．充満帯に生じる空孔の密度

次に，充満帯に生じる空孔の密度 $p$ を求める．
充満帯の頂上から下向きに測ったエネルギーの大きさを $\epsilon$ とし，エネルギー $-\epsilon$ における状態密度を $D(\epsilon)$ とする．
ここで， $D(\epsilon)$ はスピンによる重率を含まない状態密度である．

エネルギー $-\epsilon$ における電子の占有確率は，フェルミ・ディラック分布により，

```math
f_e(\epsilon)
=\frac{1}{e^{-(\epsilon+\mu)/kT}+1}
```

と表される．
したがって，その状態に空孔が存在する確率は $1-f_e(\epsilon)$ である．
スピンによる重率 $2$ を考慮すると，空孔密度は

```math
p=\int_0^\infty
2\left[1-\frac{1}{e^{-(\epsilon+\mu)/kT}+1}\right]
D(\epsilon)\,d\epsilon
```

となる．
括弧内を整理すると，

```math
1-\frac{1}{e^{-(\epsilon+\mu)/kT}+1}
=\frac{1}{e^{(\epsilon+\mu)/kT}+1}
```

であるから，

```math
p=\int_0^\infty
\frac{2D(\epsilon)}
{e^{(\epsilon+\mu)/kT}+1}\,d\epsilon
\tag{3}
```

を得る．

ここで，空孔に対する化学ポテンシャルを

```math
\mu'=-\mu
```

と定義する．
すると式(3)は，

```math
p=\int_0^\infty
\frac{2D(\epsilon)}
{e^{(\epsilon-\mu')/kT}+1}\,d\epsilon
```

となる．
これは，エネルギー $-\epsilon$ における空孔を，化学ポテンシャル $\mu'$ をもつ粒子として扱ったフェルミ・ディラック分布の形である．

問題では，空孔の分布は縮退していないと仮定されている．
したがって，空孔の占有確率が十分小さく，

```math
e^{(\epsilon-\mu')/kT}\gg 1
```

と近似できるので，分母の $+1$ を無視できる．
この近似のもとで積分を実行すると，

```math
p=2\left(\frac{2\pi m_n kT}{h^2}\right)^{3/2}
e^{\mu'/kT}
```

となる．
ここで，解答例の記号に従って，

```math
N_c=2\left(\frac{2\pi m_n kT}{h^2}\right)^{3/2}
```

とおけば，

```math
\boxed{p=N_c e^{\mu'/kT}}
\tag{4}
```

を得る．
したがって， $N_c$ は温度に対して

```math
N_c\propto T^{3/2}
```

と変化する．

### 3．質量作用の法則を導く

式(2)から，

```math
\frac{N_A-p_A}{p_A}
=2e^{-(E_A-\mu)/kT}
```

が得られる．
指数関数を分離すると，

```math
\frac{N_A-p_A}{p_A}
=2e^{-E_A/kT}e^{\mu/kT}
\tag{5}
```

である．

一方，式(4)および $\mu=-\mu'$ より，

```math
e^{\mu/kT}
=e^{-\mu'/kT}
=\frac{N_c}{p}
```

である．
これを式(5)に代入すると，

```math
\frac{N_A-p_A}{p_A}
=\frac{2N_c}{p}e^{-E_A/kT}
```

となる．
両辺に $p$ を掛ければ，

```math
\boxed{
\frac{p(N_A-p_A)}{p_A}
=2N_c e^{-E_A/kT}
}
\tag{6}
```

を得る．

これは，アクセプターが電子を受け取って負に帯電したアクセプターとなり，充満帯に空孔が生じる過程

```math
A\longrightarrow A^-+h
```

に対する質量作用の法則である．
ここで， $h$ は空孔を表す．
式(6)の係数 $2$ は，電子を収容したアクセプター状態のスピンによる重率に由来する．

### 4．電荷中性条件と空孔密度

アクセプターのみを考え，伝導帯の電子を無視できる領域では，電荷中性条件は，充満帯の空孔密度と電子を収容したアクセプターの密度が等しいことである．
したがって，

```math
p=n_A=N_A-p_A
\tag{7}
```

となる．

式(7)より，

```math
p_A=N_A-p
```

である．
これを式(6)に代入すると，

```math
\frac{p^2}{N_A-p}
=2N_c e^{-E_A/kT}
\tag{8}
```

が得られる．
この式が，空孔密度 $p$ と温度 $T$ の関係を表す基本式である．

以下では，低温と高温の二つの極限を考える．

#### （1）低温の場合

低温では，アクセプターが電子を受け取る過程が十分に進まず，充満帯に生じる空孔の密度はアクセプター密度よりも小さい．
すなわち，

```math
p\ll N_A
```

である．
このとき式(7)より，

```math
p_A=N_A-p\approx N_A
```

と近似できる．
これは，大半のアクセプターがまだ電子を収容していないことを意味する．

式(6)に $N_A-p_A=p$ を代入すると，

```math
\frac{p^2}{p_A}=2N_c e^{-E_A/kT}
```

である．
ここで $p_A\approx N_A$ と近似すれば，

```math
\frac{p^2}{N_A}\approx
2N_c e^{-E_A/kT}
```

となる．
したがって，

```math
p\approx\sqrt{2N_cN_A}\,
e^{-E_A/(2kT)}
```

を得る．
さらに， $N_c=2(2\pi m_n kT/h^2)^{3/2}$ を代入すると，

```math
\boxed{
p\approx
2N_A^{1/2}
\left(\frac{2\pi m_n kT}{h^2}\right)^{3/4}
e^{-E_A/(2kT)}
}
\tag{9}
```

となる．

よって，低温領域では，空孔密度は $T^{3/4}$ に比例する因子をもち，さらに $e^{-E_A/(2kT)}$ という指数関数の因子によって強く抑制される．
温度が上昇すると，この指数関数の因子が大きくなるため，空孔密度は増加する．

#### （2）高温の場合

温度が上昇し，アクセプターのイオン化が十分に進むと，ほとんどすべてのアクセプターが電子を収容した状態となる．
このとき，

```math
n_A\approx N_A,\qquad p_A\approx 0
```

である．
電荷中性条件 $p=n_A=N_A-p_A$ から，

```math
\boxed{
p\approx N_A
}
\tag{10}
```

となる．

すなわち，アクセプターがほぼ完全にイオン化した領域では，空孔密度はアクセプターの密度に近づき，ほぼ $N_A$ に飽和する．

### 結論

充満帯に生じる空孔の密度 $p$ は，温度の上昇とともに増加する．
低温では，

```math
\boxed{
p\approx
2N_A^{1/2}
\left(\frac{2\pi m_n kT}{h^2}\right)^{3/4}
e^{-E_A/(2kT)}
}
```

であり，温度に対して指数関数的に増加する．
一方，アクセプターがほぼ完全にイオン化した領域では，

```math
\boxed{
p\approx N_A
}
```

となる．
ただし，後者はアクセプターが支配的な領域での結果であり，さらに高温となって真性キャリアが支配的になる場合には，別途その影響を考慮する必要がある．
