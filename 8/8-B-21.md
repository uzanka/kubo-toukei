# 演習問題【8-B-21】

## 解答

電子間のクーロン反発により，一つのドナー準位には電子を2個同時に収容できない．
一方，電子が1個入っている場合，そのスピンには二つの向きがある．
この条件を考慮して大分配関数を求め，磁化率を導く．

以下では， $N_D$ を単位体積当たりのドナー数， $n_D$ を単位体積当たりのドナー準位にある電子数とする．

### 1．一つのドナーが取り得る状態と大分配関数

一つのドナーが取り得る状態は，電子が入っていない状態と，スピンの異なる電子が1個入っている二つの状態である．
電子が2個入った状態はクーロン反発により禁止されるため，考慮しない．

電子が入っていない状態のエネルギーを $0$ とする．
磁場 $H$ 中では，ドナー準位にある電子のエネルギーは，

```math
\epsilon_+=-E_D+\mu_BH
```

および

```math
\epsilon_-=-E_D-\mu_BH
```

である．
ここで， $E_D$ はドナー準位の束縛エネルギー， $\mu_B$ はボーア磁子である．
また，電子の化学ポテンシャルを $\mu$ ，温度を $T$ ，ボルツマン定数を $k$ とし，

```math
\lambda=e^{\mu/(kT)}
```

と定義する．
$\lambda$ は電子の絶対活動度である．

大分配関数では，電子が $r$ 個存在する状態に対して，Boltzmann 因子 $e^{-\epsilon/(kT)}$ に電子数に応じた絶対活動度 $\lambda^r$ を掛ける．

したがって，電子が入っていない状態の重みは $1$ ，スピンが $+$ の電子が1個入った状態の重みは $e^{-(\epsilon_+-\mu)/(kT)}$ ，スピンが $-$ の電子が1個入った状態の重みは $e^{-(\epsilon_--\mu)/(kT)}$ である．
これらを足し合わせると，一つのドナーに対する大分配関数 $\xi$ は，

```math
\begin{aligned}
\xi
&=1+e^{-(\epsilon_+-\mu)/(kT)}
+e^{-(\epsilon_--\mu)/(kT)}\\
&=1+\lambda e^{E_D/(kT)}
\left(
e^{-\mu_BH/(kT)}+e^{\mu_BH/(kT)}
\right)
\end{aligned}
```

となる．
ここで，

```math
\cosh x=\frac{e^x+e^{-x}}{2}
```

を用いれば，

```math
\boxed{
\xi=1+2\lambda e^{E_D/(kT)}
\cosh\left(\frac{\mu_BH}{kT}\right)
}
\tag{1}
```

を得る．

単位体積中に $N_D$ 個のドナーが存在し，各ドナーが独立に振る舞うと仮定すると，単位体積に対応する大分配関数は $\Xi=\xi^{N_D}$ と書ける．
したがって，

```math
\boxed{
\Xi=
\left[
1+2\lambda e^{E_D/(kT)}
\cosh\left(\frac{\mu_BH}{kT}\right)
\right]^{N_D}
}
\tag{2}
```

である．
より厳密には，体積 $V$ の系全体を扱う場合，ドナーの総数 $\mathcal N_D=N_DV$ を用いて $\Xi=\xi^{\mathcal N_D}$ とする．

### 2．大分配関数から磁化を求める

磁化は，大分配関数の対数を磁場 $H$ で微分することで求められる．
単位体積当たりの磁気モーメントを $M$ とすると，

```math
M=kT\frac{\partial\ln\Xi}{\partial H}
```

である．
式(2)より，

```math
\ln\Xi=N_D\ln\xi
```

なので，

```math
M=N_DkT\frac{1}{\xi}
\frac{\partial\xi}{\partial H}
```

となる．

式(1)を $H$ で微分すると，

```math
\frac{\partial\xi}{\partial H}
=
2\lambda e^{E_D/(kT)}
\frac{\mu_B}{kT}
\sinh\left(\frac{\mu_BH}{kT}\right)
```

を得る．
ここで，

```math
\sinh x=\frac{e^x-e^{-x}}{2}
```

である．
これを代入して整理すると，

```math
\boxed{
M=N_D\mu_B
\frac{
2\lambda e^{E_D/(kT)}
\sinh\left(\frac{\mu_BH}{kT}\right)
}{
1+2\lambda e^{E_D/(kT)}
\cosh\left(\frac{\mu_BH}{kT}\right)
}
}
\tag{3}
```

となる．

### 3．弱磁場極限から磁化率を求める

磁化率は，弱磁場における磁化の磁場に対する応答である．
すなわち，

```math
\chi=\lim_{H\to0}\frac{M}{H}
```

である．
磁場が十分に弱い場合，

```math
\frac{\mu_BH}{kT}\ll1
```

なので，

```math
\sinh x\simeq x,\qquad \cosh x\simeq1
```

と近似できる．
式(3)に代入すると，

```math
M\simeq
N_D\mu_B
\frac{
2\lambda e^{E_D/(kT)}
\frac{\mu_BH}{kT}
}{
1+2\lambda e^{E_D/(kT)}
}
```

となる．
したがって，

```math
\boxed{
\chi=
\frac{N_D\mu_B^2}{kT}
\frac{
2\lambda e^{E_D/(kT)}
}{
1+2\lambda e^{E_D/(kT)}
}
}
\tag{4}
```

を得る．
分子と分母を $2\lambda e^{E_D/(kT)}$ で割ると，

```math
\boxed{
\chi=
\frac{N_D\mu_B^2}{kT}
\frac{1}{
1+\frac12e^{-(E_D+\mu)/(kT)}
}
}
\tag{5}
```

となる．

### 4．ドナー準位にある電子数との関係

最後に，ドナー準位に電子が存在する確率を求める．
磁場がゼロのとき，一つのドナーが電子を1個収容している確率は，二つのスピン状態の重みの和を大分配関数で割ったものである．
したがって，

```math
P_{\mathrm{occ}}
=
\frac{2\lambda e^{E_D/(kT)}}
{1+2\lambda e^{E_D/(kT)}}
\tag{6}
```

である．

単位体積当たりのドナー数が $N_D$ なので，ドナー準位にある電子の数密度 $n_D$ は，

```math
n_D=N_DP_{\mathrm{occ}}
=
N_D
\frac{2\lambda e^{E_D/(kT)}}
{1+2\lambda e^{E_D/(kT)}}
\tag{7}
```

となる．
これを式(4)に代入すると，

```math
\boxed{
\chi=\frac{n_D\mu_B^2}{kT}
}
\tag{8}
```

が得られる．

### 結論

一つのドナーには電子を1個しか収容できないが，電子が存在するときにはスピンの二つの向きが許される．
この三つの状態を用いて大分配関数を構成し，磁場で微分することで，弱磁場におけるスピン磁化率は，

```math
\boxed{
\chi=\frac{n_D\mu_B^2}{kT}
}
```

と求められる．
ここで $n_D$ はドナー準位に存在する電子の数密度である．
したがって，磁化率はドナー準位に束縛された電子の数密度に比例し，温度に反比例する．
これは，ドナー準位にある電子が互いに独立なスピン磁気モーメントとして磁場に応答するという Langevin–Debye 型の結果である．
