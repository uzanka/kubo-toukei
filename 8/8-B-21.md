# 演習問題【8-B-21】

## 解答

まず，単一のドナーがとり得る状態とそのエネルギーを整理する．
問題文によれば，ドナー準位には電子が $0$ 個，またはスピンが $+$ または $-$ の電子が $1$ 個入ることができる．
電子間の Coulomb 反発力により，一つのドナーに $2$ 個の電子が入ることはできないためである．

ここで，電子の化学ポテンシャルを $\mu$ ，温度を $T$ ，ボルツマン定数を $k$ とする．
また，ドナー準位のエネルギーを $E_D$ ，磁場 $H$ 中での電子のスピン磁気モーメントを $\mu_B$ とする．
スピンが $+$ の電子のエネルギー $\epsilon_+$ ，スピンが $-$ の電子のエネルギー $\epsilon_-$ は，次のように書ける．

$$\epsilon_+ = -E_D + \mu_B H$$

$$\epsilon_- = -E_D - \mu_B H$$

統計力学における粒子の分配関数を考える．
電子の絶対活動度を $\lambda = e^{\mu/kT}$ とすると，単一のドナーについての分配関数 $\xi$ は，電子が入っていない状態（エネルギー $0$ ，重み $1$ ）と，電子が入っている状態の和として次のように求められる．

$$\xi = 1 + e^{-(\epsilon_+ - \mu)/kT} + e^{-(\epsilon_- - \mu)/kT}$$

$$\xi = 1 + e^{(\mu + E_D - \mu_B H)/kT} + e^{(\mu + E_D + \mu_B H)/kT}$$

ここで $\lambda = e^{\mu/kT}$ を用いると，

$$\xi = 1 + \lambda e^{E_D/kT} \left( e^{-\mu_B H/kT} + e^{\mu_B H/kT} \right)$$

双曲線関数 $\cosh x = \frac{e^x + e^{-x}}{2}$ を用いると，

$$\xi = 1 + 2\lambda e^{E_D/kT} \cosh \left( \frac{\mu_B H}{kT} \right)$$

ドナーの総数を $N_D$ とすると，系全体の大きな分配関数 $\Xi$ は，各ドナーが独立であると仮定して次のように与えられる．

$$\Xi = \xi^{N_D} = \left[ 1 + 2\lambda e^{E_D/kT} \cosh \left( \frac{\mu_B H}{kT} \right) \right]^{N_D}$$

磁化 $M$ は，大きな分配関数を用いて次のように計算できる．

$$M = kT \frac{\partial \ln \Xi}{\partial H} = N_D kT \frac{\partial \ln \xi}{\partial H} = N_D kT \frac{1}{\xi} \frac{\partial \xi}{\partial H}$$

$\xi$ の $H$ による微分を計算すると，

$$\frac{\partial \xi}{\partial H} = 2\lambda e^{E_D/kT} \cdot \frac{\mu_B}{kT} \sinh \left( \frac{\mu_B H}{kT} \right)$$

したがって，

$$M = N_D kT \frac{2\lambda e^{E_D/kT} \frac{\mu_B}{kT} \sinh \left( \frac{\mu_B H}{kT} \right)}{1 + 2\lambda e^{E_D/kT} \cosh \left( \frac{\mu_B H}{kT} \right)} = N_D \mu_B \frac{2\lambda e^{E_D/kT} \sinh \left( \frac{\mu_B H}{kT} \right)}{1 + 2\lambda e^{E_D/kT} \cosh \left( \frac{\mu_B H}{kT} \right)}$$

スピン磁化率 $\chi$ は $\chi = \frac{M}{H}$ で定義される．
磁場 $H$ が微小であるとき， $\sinh x \approx x$ ， $\cosh x \approx 1$ という近似を用いることができる．
これらを代入すると，

$$M \approx N_D \mu_B \frac{2\lambda e^{E_D/kT} \left( \frac{\mu_B H}{kT} \right)}{1 + 2\lambda e^{E_D/kT}} = \frac{2 N_D \lambda e^{E_D/kT} \mu_B^2 H}{kT (1 + 2\lambda e^{E_D/kT})}$$

よって，磁化率は，

$$\chi = \frac{M}{H} = \frac{2 N_D \lambda e^{E_D/kT} \mu_B^2}{kT (1 + 2\lambda e^{E_D/kT})}$$

分母と分子を $2\lambda e^{E_D/kT}$ で割ると，

$$\chi = \frac{N_D \mu_B^2}{kT} \frac{1}{\frac{1}{2\lambda e^{E_D/kT}} + 1} = \frac{N_D \mu_B^2}{kT} \frac{1}{\frac{1}{2} e^{-(E_D+\mu)/kT} + 1}$$

ここで， $n_D$ を単位体積あたりの電子数とすると，磁場が小さいときの電子の占有数 $\langle n \rangle$ は，

$$\langle n \rangle = \frac{e^{(\mu + E_D - \mu_B H)/kT} + e^{(\mu + E_D + \mu_B H)/kT}}{\xi} \approx \frac{2\lambda e^{E_D/kT}}{1 + 2\lambda e^{E_D/kT}}$$

である．
したがって， $n_D = N_D \langle n \rangle$ とおけば，

$$\chi = \frac{n_D \mu_B^2}{kT}$$

が得られる．

## 解説

本問題は，統計力学的な分配関数を用いて，磁場中のスピン系の磁化率を求める典型的な問題である．
重要なポイントは以下の通りである．

### 1.  状態の数と重み

ドナーがとり得る状態は「電子なし，スピン $+$ の電子， $+$ スピンの電子」の $3$ 状態である．
それぞれの状態に対して，エネルギーに基づくボルツマン因子と，化学ポテンシャル $\mu$ を考慮した絶対活動度 $\lambda = e^{\mu/kT}$ を乗じる必要がある．

### 2.  分配関数の構成

個々のドナーについての分配関数 $\xi$ を求め，それらを $N_D$ 乗することで系全体の $\Xi$ を得る．

### 3.  磁化と磁化率の定義

磁化 $M$ は自由エネルギーあるいは分配関数の対数微分として得られる．
磁化率 $\chi$ を求める際は，磁場 $H \to 0$ の極限を考えるため， $\sinh$ と $\cosh$ の近似を用いることが標準的な手法である．

### 4.  物理的解釈

得られた結果 $\chi = \frac{n_D \mu_B^2}{kT}$ は，ドナー準位にある $n_D$ 個の電子が，独立に磁場の影響を受けて向きをそろえる Langevin-Debye の式に一致する．
これは，各電子が互いに干渉せず，独立な磁気モーメントとして振る舞うことを示している．
