# 演習問題【8-B-16】

## 解答

自由電子気体の比熱およびスピン磁化率を求め，それらが高温で古典的な極限値に近づくことを示す．
解答例と同様に，フェルミ分布関数を級数展開し，内部エネルギーと磁化を計算する方法を用いる．

### 1．内部エネルギー，粒子数，磁化の基本式

フェルミ分布関数を

```math
f(\epsilon)=\frac{1}{e^{\beta(\epsilon-\mu)}+1}
```

とする．
ここで， $\beta=1/(kT)$ ， $k$ はボルツマン定数， $T$ は絶対温度， $\mu$ は化学ポテンシャルである．
また， $\mu_0$ は絶対零度におけるフェルミエネルギー， $\mu_B$ はボーア磁子， $H$ は磁場である．

自由電子気体の内部エネルギー $E$ ，粒子数 $N$ ，スピン磁気モーメント $M$ は，状態密度を用いて次のように表される．

```math
E=\frac{3N}{2\mu_0^{3/2}}
\int_0^\infty \epsilon^{3/2}f(\epsilon)\,d\epsilon
\tag{1}
```

```math
N=\frac{3N}{2\mu_0^{3/2}}
\int_0^\infty \epsilon^{1/2}f(\epsilon)\,d\epsilon
\tag{2}
```

```math
\begin{aligned}
M={}&\frac{3N\mu_B}{4\mu_0^{3/2}}
\int_0^\infty \epsilon^{1/2}\\
&\quad\times
\left[f(\epsilon-\mu_BH)
-f(\epsilon+\mu_BH)\right]d\epsilon
\end{aligned}
\tag{3}
```

式(2)は，化学ポテンシャルを決めるためにも用いる．
磁場がゼロのとき，スピンの二つの向きは同じ占有確率をもち，磁場を加えると両者の占有確率に差が生じる．
その差がスピン磁化 $M$ を生み出す．

### 2．高温におけるフェルミ分布関数の展開

縮退温度を $T_0=\mu_0/k$ とする．
高温の非縮退領域 $T\gg T_0$ では，化学ポテンシャルは負となり，フガシティ

```math
z=e^{\beta\mu}
```

は $0<z\ll1$ を満たす．
このとき，フェルミ分布関数は

```math
\begin{aligned}
f(\epsilon)
&=\frac{1}{e^{\beta(\epsilon-\mu)}+1}\\
&=\frac{ze^{-\beta\epsilon}}
{1+ze^{-\beta\epsilon}}
\end{aligned}
```

と書ける．

ここで，等比級数

```math
\frac{1}{1+y}=1-y+y^2-y^3+\cdots
\qquad (|y|<1)
```

を用いると，

```math
\boxed{
f(\epsilon)=
\sum_{l=1}^{\infty}
(-1)^{l-1}z^l e^{-l\beta\epsilon}
}
\tag{4}
```

を得る．
第1項は古典的なボルツマン分布に対応し，第2項以降はフェルミ統計による量子補正を表す．

式(4)を式(1)〜(3)に代入するため，次の積分公式を用いる．

```math
\int_0^\infty
\epsilon^{s-1}e^{-l\beta\epsilon}\,d\epsilon
=\frac{\Gamma(s)}{(l\beta)^s}
```

ここで $\Gamma(s)$ はガンマ関数であり，

```math
\Gamma\left(\frac32\right)=\frac{\sqrt{\pi}}2,
\qquad
\Gamma\left(\frac52\right)=\frac{3\sqrt{\pi}}4
```

である．
したがって，内部エネルギーと粒子数は

```math
\boxed{
E=\frac{3N}{2\mu_0^{3/2}}
(kT)^{5/2}\frac{3\sqrt{\pi}}4
\sum_{l=1}^{\infty}
(-1)^{l-1}\frac{z^l}{l^{5/2}}
}
\tag{5}
```

```math
\boxed{
N=\frac{3N}{2\mu_0^{3/2}}
(kT)^{3/2}\frac{\sqrt{\pi}}2
\sum_{l=1}^{\infty}
(-1)^{l-1}\frac{z^l}{l^{3/2}}
}
\tag{6}
```

となる．

磁化については， $x=\beta\mu_BH$ とおくと，

```math
\boxed{
M=\frac{3N\mu_B}{4\mu_0^{3/2}}
(kT)^{3/2}\frac{\sqrt{\pi}}2
\sum_{l=1}^{\infty}
(-1)^{l-1}
\frac{z^l}{l^{3/2}}\,2\sinh(lx)
}
\tag{7}
```

を得る．
ここで， $\sinh x=(e^x-e^{-x})/2$ である．

### 3．フガシティと粒子密度の関係

フェルミエネルギーは，粒子数密度 $n=N/V$ を用いて

```math
\mu_0=
\frac{h^2}{2m}
\left(\frac{3N}{8\pi V}\right)^{2/3}
```

と表される．
ここで， $h$ はプランク定数， $m$ は電子の質量である．
この関係を利用すると，式(6)の係数は

```math
\frac{3N}{2\mu_0^{3/2}}
(kT)^{3/2}\frac{\sqrt{\pi}}2
=2V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
```

となる．
そこで，

```math
n_c=2\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
```

を熱的な有効状態密度と定義する．
$n_c$ は単位体積当たりの量であり， $n_cV$ は粒子数の次元をもつ．
さらに，

```math
\eta=\frac{N}{n_cV}
\tag{8}
```

とおく．
$N$ と $V$ を一定に保つと $n_c\propto T^{3/2}$ であるため，

```math
\eta\propto T^{-3/2}
```

となる．
実際，先ほどの $\mu_0$ の式から，

```math
\eta=\frac{4}{3\sqrt{\pi}}
\left(\frac{T_0}{T}\right)^{3/2}
```

である．
したがって，高温では $\eta\ll1$ となる．

式(6)において $l=1,2$ の項を残すと，

```math
N\simeq n_cV
\left(z-\frac{z^2}{2^{3/2}}\right)
```

である．
式(8)を用いれば，

```math
\eta=z-\frac{z^2}{2^{3/2}}
```

となる．
これを $z$ について逐次的に解く．
まず $z=\eta+\cdots$ と近似し，右辺に代入すると，

```math
\boxed{
z=\eta+2^{-3/2}\eta^2+O(\eta^3)
}
\tag{9}
```

を得る．
この関係を内部エネルギーと磁化の式に代入すれば，古典的な値からの補正を求めることができる．

### 4．比熱の計算

式(5)と式(6)の係数の比をとると，

```math
E=\frac32 kT\,n_cV
\sum_{l=1}^{\infty}
(-1)^{l-1}\frac{z^l}{l^{5/2}}
```

となる．
ここで $l=1,2$ の項を残し，

```math
E\simeq\frac32 kT\,n_cV
\left(z-\frac{z^2}{2^{5/2}}\right)
```

とする．
式(9)を代入すれば，

```math
\begin{aligned}
z-\frac{z^2}{2^{5/2}}
&=\eta+2^{-3/2}\eta^2
-2^{-5/2}\eta^2+O(\eta^3)\\
&=\eta+2^{-5/2}\eta^2+O(\eta^3)
\end{aligned}
```

である．
したがって， $N=n_cV\eta$ を用いると，

```math
\boxed{
E=\frac32 NkT
\left(1+2^{-5/2}\eta+O(\eta^2)\right)
}
\tag{10}
```

となる．

比熱は，粒子数と体積を一定に保ったときの内部エネルギーの温度微分である．
すなわち，

```math
C_V=\left(\frac{\partial E}{\partial T}\right)_{N,V}
```

である．
ここで， $\eta\propto T^{-3/2}$ なので，

```math
\left(\frac{\partial\eta}{\partial T}\right)_{N,V}
=-\frac{3}{2}\frac{\eta}{T}
```

である．
これを式(10)に代入して微分すると，

```math
\begin{aligned}
C_V
&=\frac32 Nk
\left[
1+2^{-5/2}\eta
-\frac32\,2^{-5/2}\eta
+O(\eta^2)
\right]\\[4pt]
&=\frac32 Nk
\left[
1-\frac12\,2^{-5/2}\eta
+O(\eta^2)
\right]
\end{aligned}
```

となる．
したがって，

```math
\boxed{
C_V=\frac32 Nk
\left(1-2^{-7/2}\eta+O(\eta^2)\right)
}
\tag{11}
```

を得る．

高温極限では $\eta\to0$ であるから，

```math
\boxed{
C_V\longrightarrow\frac32 Nk
}
```

となる．
これは，三次元の古典的な単原子理想気体の定積比熱に一致する．
また，最初の量子補正は負であるため，比熱はこの近似の範囲では古典値より小さい．

### 5．スピン磁化率の計算

式(7)の係数を $n_cV\mu_B$ と書き換えると，

```math
M=n_cV\mu_B
\sum_{l=1}^{\infty}
(-1)^{l-1}\frac{z^l}{l^{3/2}}
\sinh(lx)
```

となる．
ここで， $l=1,2$ の項を残すと，

```math
M\simeq n_cV\mu_B
\left[
z\sinh x-\frac{z^2}{2^{3/2}}\sinh(2x)
\right]
```

である．
式(9)を代入し， $N=n_cV\eta$ を使えば，

```math
\boxed{
M=N\mu_B
\left[
\sinh x+
2^{-3/2}\eta
\{\sinh x-\sinh(2x)\}
+O(\eta^2)
\right]
}
\tag{12}
```

となる．

スピン磁化率は，磁場 $H=0$ における磁化の磁場微分で定義する．
ここでは $M$ は系全体の磁気モーメントであるから，

```math
\chi=\frac1V
\left(\frac{\partial M}{\partial H}\right)_{H=0}
```

とする．

磁場が十分に弱いとき，

```math
x=\frac{\mu_BH}{kT}\ll1
```

であるため，

```math
\sinh x\simeq x,\qquad
\sinh(2x)\simeq2x
```

と近似できる．
式(12)に代入すると，

```math
\begin{aligned}
M
&\simeq N\mu_Bx
\left[
1+2^{-3/2}\eta(1-2)
\right]\\[4pt]
&=N\mu_Bx
\left(1-2^{-3/2}\eta\right)
\end{aligned}
```

となる．
さらに $x=\mu_BH/(kT)$ より，

```math
M\simeq
\frac{N\mu_B^2H}{kT}
\left(1-2^{-3/2}\eta\right)
```

である．
したがって，スピン磁化率は

```math
\boxed{
\chi=\frac{N\mu_B^2}{VkT}
\left(1-2^{-3/2}\eta+O(\eta^2)\right)
}
\tag{13}
```

となる．

高温極限では $\eta\to0$ となるので，

```math
\boxed{
\chi\longrightarrow\frac{N\mu_B^2}{VkT}
}
```

である．
これは，磁場中の二つのスピン状態がボルツマン分布に従う古典的な Curie 則に一致する．
また，最初の量子補正は負であり，フェルミ統計による排他原理が磁化率を古典値より小さくすることが分かる．

### 結論

高温の非縮退領域における自由電子気体の定積比熱およびスピン磁化率は，

```math
\boxed{
C_V=\frac32 Nk
\left(1-2^{-7/2}\eta+O(\eta^2)\right)
}
```

```math
\boxed{
\chi=\frac{N\mu_B^2}{VkT}
\left(1-2^{-3/2}\eta+O(\eta^2)\right)
}
```

である．
ここで，

```math
\eta=\frac{4}{3\sqrt{\pi}}
\left(\frac{T_0}{T}\right)^{3/2}
```

であり， $T_0=\mu_0/k$ は縮退温度である．
したがって，温度が上昇すると量子統計による補正は $T^{-3/2}$ に比例して小さくなり，比熱は $\frac32Nk$ ，スピン磁化率は $\frac{N\mu_B^2}{VkT}$ という古典的な極限値に近づく．
