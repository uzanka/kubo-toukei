# 演習問題【8-B-16】

## 解答

自由電子気体の内部エネルギー $E$ ，スピン磁気モーメント $M$ ，および粒子数 $N$ は，フェルミ分布関数 $f(\epsilon) = \frac{1}{e^{\beta(\epsilon-\mu)} + 1}$ と状態密度を用いて，次のように書き表される．

$$E = N \frac{3}{2} \mu_0^{-3/2} \int_0^\infty \epsilon^{3/2} f(\epsilon) \, d\epsilon \quad \cdots (1)$$

$$M = N \mu_B \frac{3}{4} \mu_0^{-3/2} \int_0^\infty \epsilon^{1/2} [f(\epsilon - \mu_B H) - f(\epsilon + \mu_B H)] \, d\epsilon \quad \cdots (2)$$

$$N = N \frac{3}{2} \mu_0^{-3/2} \int_0^\infty \epsilon^{1/2} f(\epsilon) \, d\epsilon \quad \cdots (3)$$

ここで， $\beta = 1/kT$ ， $\mu$ は化学ポテンシャル， $\mu_0$ は $T=0$ におけるフェルミエネルギーである．

高温限界（縮退温度 $T_0 = \mu_0/k$ に対して $T \gg T_0$ ）では，化学ポテンシャルは $\mu < 0$ となる．
このとき，フェルミ分布関数は次のように展開できる．

$$f(\epsilon) = \frac{e^{\beta\mu}}{e^{\beta(\epsilon-\mu)} + 1} = e^{\beta\mu} \sum_{l=1}^\infty (-1)^{l-1} e^{-l\beta\epsilon} \quad \cdots (4)$$

この展開式を $(1)$ ， $(2)$ ， $(3)$ に代入して積分を実行すると，以下の級数展開が得られる．

$$E = N \frac{3}{2} \frac{1}{\mu_0} (kT)^{5/2} \frac{3\sqrt{\pi}}{4} \sum_{l=1}^\infty (-1)^{l-1} \frac{e^{l\beta\mu}}{l^{5/2}} \quad \cdots (1)'$$

$$M = N \mu_B \frac{3}{4} \frac{1}{\mu_0^{3/2}} (kT)^{3/2} \frac{\sqrt{\pi}}{2} \sum_{l=1}^\infty (-1)^{l-1} \frac{e^{l\beta\mu}}{l^{3/2}} \cdot 2\sinh(l\beta\mu_B H) \quad \cdots (2)'$$

$$N = N \frac{3}{2} \frac{1}{\mu_0^{3/2}} (kT)^{3/2} \frac{\sqrt{\pi}}{2} \sum_{l=1}^\infty (-1)^{l-1} \frac{e^{l\beta\mu}}{l^{3/2}} \quad \cdots (3)'$$

ここで， $l=1$ の項のみをとると，これらは古典的な極限値（非縮退な理想気体の性質）を与える．

次に，古典的な値への補正を調べるため， $l=2$ の項までを考慮する．
式 $(3)'$ において $l=1, 2$ の項をとると，

$$N = N_c \left( e^{\beta\mu} - \frac{1}{2^{3/2}} e^{2\beta\mu} \right) \quad \cdots (5)$$

ここで， $N_c = \frac{2V}{h^3} (2\pi m k T)^{3/2}$ とおくと， $\eta = N/N_c$ を用いて次のように書ける．

$$e^{\beta\mu} - 2^{-3/2} e^{2\beta\mu} = \eta \quad \cdots (6)$$

高温では $\eta \ll 1$ であるため，これを $\eta$ について逐次的に解くと，

$$e^{\beta\mu} = \eta + 2^{-3/2} \eta^2 + \dots \quad \cdots (7)$$

を得る．
これを $(1)'$ および $(2)'$ に代入し， $\eta$ の次数の項まで整理すると，

$$E = \frac{3}{2} NkT \left( 1 + 3 \cdot 2^{-5/2} \eta + \dots \right)$$

$$M = N \mu_B \sinh(\beta \mu_B H) \left( 1 + 2^{-3/2} \eta + \dots \right)$$

が得られる．
具体的に，比熱 $C_v = \frac{\partial E}{\partial T}$ およびスピン磁化率 $\chi = \left( \frac{\partial M}{\partial H} \right)_{H \to 0}$ を計算すると，

$$C_v = \frac{3}{2} Nk (1 - 3 \cdot 2^{-7/2} \eta + \dots) \quad \cdots (10)$$

$$\chi = \frac{N \mu_B^2}{VkT} (1 - 2^{-3/2} \eta + \dots) \quad \cdots (11)$$

となる．
これらの補正項は $\eta \propto (T_0/T)^{3/2}$ に比例するため，温度 $T$ が増大するにつれて $0$ に近づき，古典的な値へと収束することが確認できる．

## 解説

本問題は，量子力学的な統計力学（フェルミ統計）から古典力学的な統計力学（ボルツマン統計）への移行を扱うものである．

### 1. フェルミ分布と高温限界

フェルミ粒子はパウリの排他原理に従うが，温度が非常に高くなると，エネルギー状態が非常に広がり，粒子が各状態に占有する確率が極めて低くなる．
このとき，フェルミ分布関数はボルツマン分布 $f(\epsilon) \propto e^{-\beta\epsilon}$ に近似できるようになる．

### 2. 級数展開の意味

展開式の第1項 ( $l=1$ ) は，粒子が独立に振る舞う古典的な理想気体の性質を表している．
第2項以降 ( $l \ge 2$ ) は，粒子間の量子力学的な相互作用（排他原理による補正）を表しており，温度が下がる（ $\eta$ が大きくなる）ほど，これらの補正の影響が顕著になる．

### 3. $\eta$ の物理的意味

$\eta = N/N_c$ は，系の粒子密度 $N/V$ と，量子的な広がり（熱的ド・ブロイ波長に関連する量）の比を表している．
$\eta \ll 1$ は，粒子が互いに「干渉」しないほど十分に離れている高温状態を意味する．

### 4. 比熱と磁化率の収束

古典的な理想気体では，単原子分子の比熱は $C_v = \frac{3}{2}Nk$ である．
内部エネルギー $E$ は量子補正により正の補正を受けるが，比熱 $C_v$ の補正項が負になるのは，$\eta \propto T^{-3/2}$ が温度に依存することに起因する．
具体的には，化学ポテンシャル $\mu(T)$ の温度依存性を通じて，量子統計の効果によってエネルギーの温度勾配が古典値よりも緩やかになるためである．
