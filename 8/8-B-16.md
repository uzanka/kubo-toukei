# 演習問題【8-B-16】

## 解答

三次元自由電子気体を考える．
電子の質量を $m$ ，粒子数を $N$ ，体積を $V$ ，ボルツマン定数を $k_{\mathrm B}$ ，プランク定数を $h$ とする．
電子のスピン磁気モーメントの大きさを $\mu_B$ とし，外部磁束密度を $B$ とする．
磁場による電子のエネルギーの分裂は $\mp\mu_B B$ であるとする．

絶対零度におけるフェルミエネルギーを $E_F$ ，縮退温度を

```math
T_0=\frac{E_F}{k_{\mathrm B}}
```

と定義する．

まず，縮退温度と同程度の温度でも適用できるフェルミ積分による一般式を導く．
その後，十分高温の非縮退極限 $T\gg T_0$ で展開し，古典極限への近づき方を調べる．

### 1．状態密度と基本式

磁場がないとき，スピン縮退度2を含む三次元自由電子気体の状態密度は

```math
D(\epsilon)
=
\frac{3N}{2E_F^{3/2}}\sqrt{\epsilon}
```

である．
したがって，フェルミ分布関数

```math
f(\epsilon)
=
\frac{1}{\exp[\beta(\epsilon-\mu)]+1},
\qquad
\beta=\frac{1}{k_{\mathrm B}T}
```

を用いると，粒子数と内部エネルギーは

```math
N=
\frac{3N}{2E_F^{3/2}}
\int_0^\infty
\epsilon^{1/2}f(\epsilon)\,d\epsilon
\tag{1}
```

および

```math
U=
\frac{3N}{2E_F^{3/2}}
\int_0^\infty
\epsilon^{3/2}f(\epsilon)\,d\epsilon
\tag{2}
```

で与えられる．

ここで， $\mu$ は温度および磁場に依存する化学ポテンシャルである．
磁場がゼロのとき，式 (1) は粒子数 $N$ を一定に保つように $\mu(T)$ を決定する．

### 2．フェルミ積分による一般式

熱的有効状態密度を

```math
n_Q(T)
=
2\left(\frac{2\pi m k_{\mathrm B}T}{h^2}\right)^{3/2}
```

と定義し，フガシティを

```math
z=e^{\beta\mu}
```

とする．
また，フェルミ積分を

```math
F_\nu(z)
=
\frac{1}{\Gamma(\nu)}
\int_0^\infty
\frac{x^{\nu-1}}{z^{-1}e^x+1}\,dx
\tag{3}
```

と定義する．

この定義では，

```math
F_\nu(z)
=
\sum_{l=1}^{\infty}
(-1)^{l-1}\frac{z^l}{l^\nu}
```

が $0<z<1$ で成立し，積分表示は正の $z$ に対して定義できる．

式 (1)，(2) の積分を変数変換 $x=\beta\epsilon$ によって評価すると，

```math
N=Vn_QF_{3/2}(z)
\tag{4}
```

および

```math
U=\frac32 Vk_{\mathrm B}Tn_QF_{5/2}(z)
\tag{5}
```

を得る．
したがって，

```math
\frac{U}{N}
=
\frac32 k_{\mathrm B}T
\frac{F_{5/2}(z)}{F_{3/2}(z)}
\tag{6}
```

である．

式 (4) は，粒子数 $N$ と体積 $V$ を一定に保つ条件から，任意の温度における $z(T)$ を決める方程式である．
したがって，式 (6) は縮退温度と同程度の温度にも適用できる一般式である．

### 3．定積比熱の一般式

定積比熱は

```math
C_V=\left(\frac{\partial U}{\partial T}\right)_{N,V}
```

で定義される．

フェルミ積分には

```math
z\frac{dF_\nu(z)}{dz}=F_{\nu-1}(z)
\tag{7}
```

という関係がある．
式 (4) で $N,V$ を一定とすると，

```math
0=
\frac32F_{3/2}(z)\,d\ln T
+
F_{1/2}(z)\,d\ln z
```

であるから，

```math
\left(\frac{d\ln z}{d\ln T}\right)_{N,V}
=
-\frac32\frac{F_{3/2}(z)}{F_{1/2}(z)}
\tag{8}
```

となる．

式 (5) を温度で微分する．
$n_Q\propto T^{3/2}$ および式 (7)，(8) を用いると，

```math
\begin{aligned}
C_V
&=
\frac32 Vk_{\mathrm B}n_Q
\left[
\frac52F_{5/2}
+
F_{3/2}\frac{d\ln z}{d\ln T}
\right]\\
&=
\frac32 Vk_{\mathrm B}n_Q
\left[
\frac52F_{5/2}
-\frac32\frac{F_{3/2}^2}{F_{1/2}}
\right]
\end{aligned}
```

を得る．
ここで式 (4) を用いれば，

```math
\boxed{
\frac{C_V}{Nk_{\mathrm B}}
=
\frac{15}{4}\frac{F_{5/2}(z)}{F_{3/2}(z)}
-
\frac94\frac{F_{3/2}(z)}{F_{1/2}(z)}
}
\tag{9}
```

となる．

この式は，粒子数一定の条件を含む定積比熱の一般式であり，縮退温度付近でも使用できる．
その温度での $z$ は式 (4) から決定する．

### 4．スピン磁化率の一般式

磁束密度 $B$ によって，スピンの二つの状態のエネルギーは

```math
\epsilon_\pm=\epsilon\mp\mu_B B
```

となる．
それぞれのスピン状態のフガシティは

```math
z_\pm=ze^{\pm x},
\qquad
x=\frac{\mu_B B}{k_{\mathrm B}T}
```

である．

スピン縮退度を含めた粒子数は

```math
N=
\frac{Vn_Q}{2}
\left[
F_{3/2}(ze^x)+F_{3/2}(ze^{-x})
\right]
\tag{10}
```

となる．
また，磁化 $M$ は二つのスピン状態の粒子数差にボーア磁子を掛けたものであるから，

```math
M=
\frac{Vn_Q\mu_B}{2}
\left[
F_{3/2}(ze^x)-F_{3/2}(ze^{-x})
\right]
\tag{11}
```

である．

磁場がゼロのとき，

```math
N=Vn_QF_{3/2}(z)
```

であり， $M=0$ となる．

磁場反転 $B\to-B$ に対して粒子数は偶関数であるため，粒子数一定条件のもとで化学ポテンシャルは

```math
\mu(B)=\mu(0)+O(B^2)
```

となる．
したがって，磁化率を求める一次の磁場微分では，化学ポテンシャルの磁場依存性は寄与しない．

式 (11) を $B$ で微分し， $B=0$ とすると，

```math
\left.
\frac{\partial M}{\partial B}
\right|_{B=0}
=
\frac{Vn_Q\mu_B^2}{k_{\mathrm B}T}
F_{1/2}(z)
```

である．
ここで，磁束密度 $B$ に関する体積磁化率を

```math
\chi_B=
\frac1V
\left(\frac{\partial M}{\partial B}\right)_{B=0}
```

と定義すれば，

```math
\chi_B=
\frac{n_Q\mu_B^2}{k_{\mathrm B}T}F_{1/2}(z)
```

となる．
式 (4) を使うと，

```math
\boxed{
\chi_B=
\frac{N\mu_B^2}{Vk_{\mathrm B}T}
\frac{F_{1/2}(z)}{F_{3/2}(z)}
}
\tag{12}
```

を得る．

これが任意の縮退度に対するスピン磁化率の一般式である．
ここでは軌道磁化を含めず，スピン磁化のみを扱っている．

### 5．高温・非縮退極限での展開

十分高温の非縮退領域

```math
T\gg T_0
```

では，

```math
z\ll1
```

となる．
このとき，フェルミ分布関数は

```math
f(\epsilon)
=
\frac{ze^{-\beta\epsilon}}{1+ze^{-\beta\epsilon}}
=
\sum_{l=1}^{\infty}
(-1)^{l-1}z^le^{-l\beta\epsilon}
\tag{13}
```

と展開できる．

したがって，

```math
F_\nu(z)
=
z-\frac{z^2}{2^\nu}+O(z^3)
\tag{14}
```

である．

また，

```math
\eta=\frac{N}{Vn_Q}
```

と定義する．
$n_Q\propto T^{3/2}$ であるから，

```math
\eta=
\frac{4}{3\sqrt{\pi}}
\left(\frac{T_0}{T}\right)^{3/2}
\tag{15}
```

となる．
したがって， $T\gg T_0$ では $\eta\ll1$ である．

式 (4) と式 (14) から，

```math
\eta
=
z-\frac{z^2}{2^{3/2}}+O(z^3)
```

を得る．
これを $z$ について逐次的に解くと，

```math
\boxed{
z=\eta+2^{-3/2}\eta^2+O(\eta^3)
}
\tag{16}
```

となる．

### 6．高温領域における比熱

式 (5)，(14) より，

```math
U=
\frac32 Vk_{\mathrm B}Tn_Q
\left[
z-\frac{z^2}{2^{5/2}}+O(z^3)
\right]
```

である．
式 (16) を代入すると，

```math
z-\frac{z^2}{2^{5/2}}
=
\eta+2^{-5/2}\eta^2+O(\eta^3)
```

となる．
したがって，

```math
U=
\frac32 Nk_{\mathrm B}T
\left[
1+2^{-5/2}\eta+O(\eta^2)
\right]
\tag{17}
```

を得る．

ここで， $N,V$ 一定では

```math
\left(\frac{\partial\eta}{\partial T}\right)_{N,V}
=
-\frac{3\eta}{2T}
```

である．
よって式 (17) を温度で微分すると，

```math
\boxed{
C_V=
\frac32 Nk_{\mathrm B}
\left[
1-2^{-7/2}\eta+O(\eta^2)
\right]
}
\tag{18}
```

となる．

したがって，高温極限では

```math
\boxed{
C_V\longrightarrow\frac32 Nk_{\mathrm B}
}
```

であり，三次元古典理想気体の定積比熱に一致する．
最初のフェルミ統計補正は負である．

### 7．高温領域におけるスピン磁化率

式 (12)，(14) より，

```math
\frac{F_{1/2}(z)}{F_{3/2}(z)}
=
\frac{z-z^2/2^{1/2}+O(z^3)}
{z-z^2/2^{3/2}+O(z^3)}
```

である．
分子と分母を $z$ で割って展開すると，

```math
\frac{F_{1/2}(z)}{F_{3/2}(z)}
=
1-2^{-3/2}z+O(z^2)
```

となる．
式 (16) より $z=\eta+O(\eta^2)$ であるため，

```math
\frac{F_{1/2}(z)}{F_{3/2}(z)}
=
1-2^{-3/2}\eta+O(\eta^2)
```

を得る．

したがって，式 (12) から，

```math
\boxed{
\chi_B=
\frac{N\mu_B^2}{Vk_{\mathrm B}T}
\left[
1-2^{-3/2}\eta+O(\eta^2)
\right]
}
\tag{19}
```

となる．

高温極限では，

```math
\boxed{
\chi_B\longrightarrow
\frac{N\mu_B^2}{Vk_{\mathrm B}T}
}
```

である．
これは二つのスピン状態がボルツマン分布に従う場合の Curie 則である．
最初のフェルミ統計補正は負であり，排他原理によってスピン磁化率が古典値より小さくなる．

なお，ここでは磁束密度 $B$ に関する磁化率を定義した．
SI 単位系で磁場 $H$ に関する磁化率を用いる場合，弱い磁化の範囲で $B\simeq\mu_0H$ であるため，

```math
\chi_H=\mu_0\chi_B
```

となる．

### 8．結論

縮退温度と同程度の温度を含む一般的な領域では，定積比熱およびスピン磁化率は，フェルミ積分を用いて

```math
\boxed{
\frac{C_V}{Nk_{\mathrm B}}
=
\frac{15}{4}\frac{F_{5/2}(z)}{F_{3/2}(z)}
-
\frac94\frac{F_{3/2}(z)}{F_{1/2}(z)}
}
```

および

```math
\boxed{
\chi_B=
\frac{N\mu_B^2}{Vk_{\mathrm B}T}
\frac{F_{1/2}(z)}{F_{3/2}(z)}
}
```

と表される．
ここで $z$ は

```math
N=Vn_QF_{3/2}(z)
```

によって決定される．
これらの一般式は，非縮退近似を必要とせず，縮退温度付近にも適用できる．

さらに，十分高温の非縮退領域 $T\gg T_0$ では，

```math
\eta=
\frac{4}{3\sqrt{\pi}}
\left(\frac{T_0}{T}\right)^{3/2}
\ll1
```

を用いて展開できる．
その結果，

```math
\boxed{
C_V=
\frac32 Nk_{\mathrm B}
\left[
1-2^{-7/2}\eta+O(\eta^2)
\right]
}
```

および

```math
\boxed{
\chi_B=
\frac{N\mu_B^2}{Vk_{\mathrm B}T}
\left[
1-2^{-3/2}\eta+O(\eta^2)
\right]
}
```

を得る．

したがって，温度が十分高くなるとフェルミ統計による補正は $T^{-3/2}$ に比例して小さくなり，比熱は古典値 $3Nk_{\mathrm B}/2$ に，スピン磁化率は Curie 則 $N\mu_B^2/(Vk_{\mathrm B}T)$ に近づく．
