# 演習問題【8-B-17】

## 解答

与えられたエネルギー準位は，

$$E(l, p_z) = \frac{e\hbar}{mc} H \left( l + \frac{1}{2} \right) + \frac{p_z^2}{2m} \quad (l = 0, 1, 2, \dots)$$

である．
ここで $\mu_{\text{B}} = \frac{e\hbar}{2mc}$ を用いると，エネルギーは次のように書ける．

$$E(l, p_z) = 2\mu_{\text{B}} H \left( l + \frac{1}{2} \right) + \frac{p_z^2}{2m}$$

まず，量子数 $l$ に対する縮重度 $g_l$ を求める．
ヒントに従い，磁場がない場合のエネルギ－ $E_0 = \frac{p_x^2 + p_y^2 + p_z^2}{2m}$ と比較する．
$xy$ 面内の運動エネルギー $E_{\perp} = \frac{p_x^2 + p_y^2}{2m}$ が， $2\mu_{\text{B}}Hl < E_{\perp} < 2\mu_{\text{B}}H(l+1)$ の範囲にある状態が，磁場中ではエネルギー $2\mu_{\text{B}}H(l+1/2)$ の準位に束ねられる．

磁場がない場合の位相空間における状態密度は， $\frac{L^2}{h^2} dp_x dp_y$ である．
この範囲の縮重度 $g_l$ は，この密度を $E_{\perp}$ の範囲で積分することで得られる．

$$g_l = \frac{L^2}{h^2} \iint_{2\mu_{\text{B}}Hl < \frac{p_x^2+p_y^2}{2m} < 2\mu_{\text{B}}H(l+1)} dp_x dp_y$$

極座標 $p_x = p \cos\theta, p_y = p \sin\theta$ を用いると， $dp_x dp_y = p \, dp \, d\theta$ であり，

$$g_l = \frac{L^2}{h^2} \int_0^{2\pi} d\theta \int_{\sqrt{4m\mu_{\text{B}}Hl}}^{\sqrt{4m\mu_{\text{B}}H(l+1)}} p \, dp = \frac{2\pi L^2}{h^2} \left[ \frac{1}{2}p^2 \right]_{\sqrt{4m\mu_{\text{B}}Hl}}^{\sqrt{4m\mu_{\text{B}}H(l+1)}}$$

$$g_l = \frac{\pi L^2}{h^2} \left( 4m\mu_{\text{B}}H(l+1) - 4m\mu_{\text{B}}Hl \right) = \frac{4\pi m \mu_{\text{B}} H L^2}{h^2}$$

ここで， $\mu_{\text{B}} = \frac{e\hbar}{2mc} = \frac{e(h/2\pi)}{2mc} = \frac{e h}{4\pi mc}$ より， $4\pi m \mu_{\text{B}} = \frac{eh}{c}$ である．
したがって，

$$g_l = \frac{L^2}{h^2} \frac{eH}{c} h = \frac{L^2 eH}{hc}$$

となり，縮重度 $g_l$ は $l$ に依存せず一定の値をとる．

次に，単一電子の分配関数 $Z_1$ を求める．

$$Z_1 = \sum_{l=0}^{\infty} \sum_{p_z} g_l \exp(-\beta E(l, p_z)) = \frac{L^2 eH}{hc} \sum_{l=0}^{\infty} e^{-\beta 2\mu_{\text{B}}H(l+1/2)} \int_{-\infty}^{\infty} \frac{L}{h} dp_z e^{-\beta \frac{p_z^2}{2m}}$$

ここで， $p_z$ に関する積分はガウス積分 $\int_{-\infty}^{\infty} e^{-ax^2} dx = \sqrt{\pi/a}$ を用いて，

$$\int_{-\infty}^{\infty} e^{-\frac{\beta}{2m} p_z^2} dp_z = \sqrt{\frac{2\pi m}{\beta}} = \sqrt{2\pi mkT}$$

である．
また， $l$ に関する和は等比級数である．

$$\sum_{l=0}^{\infty} e^{-\beta 2\mu_{\text{B}}H(l+1/2)} = e^{-\beta \mu_{\text{B}}H} \sum_{l=0}^{\infty} (e^{-2\beta \mu_{\text{B}}H})^l = \frac{e^{-\beta \mu_{\text{B}}H}}{1 - e^{-2\beta \mu_{\text{B}}H}} = \frac{1}{e^{\beta \mu_{\text{B}}H} - e^{-\beta \mu_{\text{B}}H}} = \frac{1}{2\sinh(\beta \mu_{\text{B}}H)}$$

これらをまとめると，

$$Z_1 = \frac{L^2 eH}{hc} \cdot \frac{L}{h} \cdot \sqrt{2\pi mkT} \cdot \frac{1}{2\sinh(\beta \mu_{\text{B}}H)}$$

ここで， $V = L^3$ であり， $\frac{eH}{c} = \frac{4\pi m \mu_{\text{B}} H}{h}$ を用いて整理すると，

$$Z_1 = V \left( \frac{2\pi mkT}{h^2} \right)^{3/2} \frac{\mu_{\text{B}}H/kT}{\sinh(\mu_{\text{B}}H/kT)}$$

$N$ 個の独立な電子からなる系の全分配関数は $Z = Z_1^N / N!$ である．
磁気モーメント $M$ は，

$$M = kT \frac{\partial \log Z}{\partial H} = kT \frac{\partial}{\partial H} (N \log Z_1 - \log N!) = NkT \frac{\partial \log Z_1}{\partial H}$$

ここで， $\log Z_1$ の $H$ 依存性は $\log \left( \frac{\mu_{\text{B}}H/kT}{\sinh(\mu_{\text{B}}H/kT)} \right)$ の部分に含まれる．
したがって，

$$M = NkT \frac{\partial}{\partial H} \left[ \log(\mu_{\text{B}}H/kT) - \log(\sinh(\mu_{\text{B}}H/kT)) \right]$$

$$\frac{\partial}{\partial H} \log(\mu_{\text{B}}H/kT) = \frac{1}{\mu_{\text{B}}H/kT} \cdot \frac{\mu_{\text{B}}}{kT} = \frac{1}{H}$$

$$\frac{\partial}{\partial H} \log(\sinh(\mu_{\text{B}}H/kT)) = \frac{1}{\sinh(\mu_{\text{B}}H/kT)} \cdot \cosh(\mu_{\text{B}}H/kT) \cdot \frac{\mu_{\text{B}}}{kT} = \frac{\mu_{\text{B}}}{kT} \coth(\mu_{\text{B}}H/kT)$$

これらを代入すると，

$$M = NkT \left[ \frac{1}{H} - \frac{\mu_{\text{B}}}{kT} \coth\left(\frac{\mu_{\text{B}}H}{kT}\right) \right] = N \left[ \frac{kT}{H} - \mu_{\text{B}} \coth\left(\frac{\mu_{\text{B}}H}{kT}\right) \right]$$

$$M = -N\mu_{\text{B}} \left[ \coth\left(\frac{\mu_{\text{B}}H}{kT}\right) - \frac{1}{\mu_{\text{B}}H/kT} \right]$$

ここで， $L(x) = \coth x - \frac{1}{x}$ と定義されているので，

$$M = -N\mu_{\text{B}} L\left(\frac{\mu_{\text{B}}H}{kT}\right)$$

が得られる．

## 解説

本問題は，磁場中の電子の運動が量子力学的にどのようにエネルギー準位（ランダウ準位）として現れるか，そしてそれが統計力学的にどのような磁気的性質（常磁性）を示すかを導出させるものである．

### 1. ランダウ準位の形成

磁場中では，電子はローレンツ力を受けて円運動を行う．
古典的には任意の半径の円運動が可能であるが，量子力学的には，この運動は調和振動子のエネルギー準位に似た離散的なエネルギー $\hbar \omega_0 (l + 1/2)$ をとる．
これをランダウ準位と呼ぶ．

### 2. 縮重度の物理的意味

磁場がない場合，位相空間において連続的に存在していた運動量状態が，磁場によって特定のエネルギー準位に「束ねられる」．
この「束ねられた」状態の数（縮重度）は，電子が円運動の「中心」として取り得る位置の広さに対応しており，磁場の強さ $H$ に比例する．

### 3. ブリュアン関数（Langevin関数）

最終的に導出された $L(x) = \coth x - 1/x$ は，常磁性体の磁化を記述する際に現れる関数である．
高温極限 ( $x \to 0$ ) では $L(x) \approx x/3$ となり， $M \propto H/T$ というキュリーの法則（磁化が温度に反比例する）を再現する．
