# 演習問題【8-B-17】

## 解答

磁場中の電子のエネルギー準位は，

```math
E(l,p_z)=2\mu_{\mathrm B}H\left(l+\frac12\right)
+\frac{p_z^2}{2m},
\qquad l=0,1,2,\ldots
```

で与えられる．
ここで，

```math
\mu_{\mathrm B}=\frac{e\hbar}{2mc}
```

はボーア磁子であり， $p_z$ は $z$ 方向の運動量である．
また， $m$ は電子の質量， $H$ は磁場の強さである．
電子のスピンは無視し，電子系は高温の非縮退領域にあって Boltzmann 統計に従うものとする．

求める磁気モーメント $M$ は，単一電子の分配関数から計算できる．
そのため，まず各エネルギー準位の縮重度を求め，次に分配関数を計算する．

### 1．ランダウ準位の縮重度

一辺 $L$ の立方体中に電子が存在するとし，体積を

```math
V=L^3
```

とする．
磁場がないとき，運動量空間の微小領域 $dp_x\,dp_y$ に含まれる状態数は，

```math
\frac{L^2}{h^2}\,dp_x\,dp_y
```

である．
これは， $x$ 方向および $y$ 方向の各運動量について，単位運動量幅当たりの状態数がそれぞれ $L/h$ であることによる．

ヒントに従い，磁場がない場合の $xy$ 面内の運動エネルギーを

```math
E_\perp=\frac{p_x^2+p_y^2}{2m}
```

とする．
磁場が加わると，

```math
2\mu_{\mathrm B}Hl
<E_\perp<
2\mu_{\mathrm B}H(l+1)
```

の範囲にあった状態が，量子化されたエネルギー

```math
2\mu_{\mathrm B}H\left(l+\frac12\right)
```

のランダウ準位に束ねられる．
したがって，この運動量領域に含まれる状態数を積分すれば，準位 $l$ の縮重度 $g_l$ が得られる．

```math
g_l=
\frac{L^2}{h^2}
\iint_{\displaystyle
2\mu_{\mathrm B}Hl<
(p_x^2+p_y^2)/(2m)<
2\mu_{\mathrm B}H(l+1)}
dp_x\,dp_y
```

ここで，

```math
p_x=p\cos\theta,\qquad
p_y=p\sin\theta
```

と変数変換すると，

```math
dp_x\,dp_y=p\,dp\,d\theta
```

である．
また，エネルギーの条件から，積分範囲は

```math
\sqrt{4m\mu_{\mathrm B}Hl}
<p<
\sqrt{4m\mu_{\mathrm B}H(l+1)}
```

となる．
よって，

```math
\begin{aligned}
g_l
&=\frac{L^2}{h^2}
\int_0^{2\pi}d\theta
\int_{\sqrt{4m\mu_{\mathrm B}Hl}}^{
\sqrt{4m\mu_{\mathrm B}H(l+1)}}p\,dp\\[4pt]
&=\frac{2\pi L^2}{h^2}
\left[\frac{p^2}{2}\right]_
{\sqrt{4m\mu_{\mathrm B}Hl}}^{
\sqrt{4m\mu_{\mathrm B}H(l+1)}}\\[4pt]
&=\frac{4\pi m\mu_{\mathrm B}HL^2}{h^2}
\end{aligned}
```

である．
ボーア磁子の定義と $\hbar=h/(2\pi)$ より，

```math
\mu_{\mathrm B}=\frac{eh}{4\pi mc}
```

であるから，

```math
4\pi m\mu_{\mathrm B}=\frac{eh}{c}
```

となる．
したがって，

```math
\boxed{g_l=\frac{L^2eH}{hc}}
\tag{1}
```

を得る．
縮重度は量子数 $l$ に依存せず，磁場の強さに比例する．
ここでは，電子のスピンを無視しているため，スピン由来の重率 $2$ は含めていない．

### 2．単一電子の分配関数

温度を $T$ ，ボルツマン定数を $k$ とし，

```math
\beta=\frac{1}{kT}
```

とおく．
Boltzmann 統計に従う単一電子の分配関数は，すべてのエネルギー状態について Boltzmann 因子 $e^{-\beta E}$ を足し合わせたものである．
したがって，

```math
Z_1=\sum_{l=0}^{\infty}\sum_{p_z}
g_l\,e^{-\beta E(l,p_z)}
```

である．

$z$ 方向の運動量状態については，運動量の間隔が $h/L$ であるため，

```math
\sum_{p_z}\longrightarrow
\frac{L}{h}\int_{-\infty}^{\infty}dp_z
```

と置き換えられる．
式(1)を代入すると，

```math
\begin{aligned}
Z_1
={}&\frac{L^2eH}{hc}\frac{L}{h}
\sum_{l=0}^{\infty}
e^{-2\beta\mu_{\mathrm B}H(l+1/2)}\\
&\qquad\times
\int_{-\infty}^{\infty}
e^{-\beta p_z^2/(2m)}\,dp_z
\end{aligned}
\tag{2}
```

となる．

まず， $p_z$ に関する積分を求める．
ガウス積分の公式

```math
\int_{-\infty}^{\infty}e^{-ax^2}\,dx
=\sqrt{\frac{\pi}{a}}
\qquad(a>0)
```

を用いると，

```math
\begin{aligned}
\int_{-\infty}^{\infty}
e^{-\beta p_z^2/(2m)}\,dp_z
&=\sqrt{\frac{2\pi m}{\beta}}\\[4pt]
&=\sqrt{2\pi mkT}
\end{aligned}
\tag{3}
```

である．

次に，ランダウ量子数 $l$ に関する和を計算する．

```math
x=\frac{\mu_{\mathrm B}H}{kT}
=\beta\mu_{\mathrm B}H
```

とおくと，

```math
\begin{aligned}
\sum_{l=0}^{\infty}
e^{-\beta 2\mu_{\mathrm B}H(l+1/2)}
&=e^{-x}\sum_{l=0}^{\infty}(e^{-2x})^l\\[4pt]
&=\frac{e^{-x}}{1-e^{-2x}}\\[4pt]
&=\frac{1}{e^x-e^{-x}}\\[4pt]
&=\frac{1}{2\sinh x}
\end{aligned}
\tag{4}
```

となる．
ここでは等比級数

```math
\sum_{l=0}^{\infty}r^l=\frac{1}{1-r}
\qquad(|r|<1)
```

を用いた．

式(3)，(4)を式(2)に代入すると，

```math
Z_1=
\frac{L^2eH}{hc}
\frac{L}{h}
\frac{\sqrt{2\pi mkT}}{2\sinh x}
```

である．
ここで $V=L^3$ および

```math
\frac{eH}{c}=\frac{4\pi m\mu_{\mathrm B}H}{h}
```

を用いて整理すると，

```math
Z_1=
V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\frac{x}{\sinh x}
```

となる．
したがって，単一電子の分配関数は，

```math
\boxed{
Z_1=
V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\frac{\mu_{\mathrm B}H/(kT)}
{\sinh\!\left(\mu_{\mathrm B}H/(kT)\right)}
}
\tag{5}
```

である．

なお， $H\to0$ では $x\to0$ となり，

```math
\frac{x}{\sinh x}\longrightarrow1
```

である．
したがって，式(5)は磁場がない場合の古典的な単一粒子分配関数

```math
Z_1=V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
```

に一致する．

### 3．磁気モーメントの導出

$N$ 個の独立な電子からなる古典的な系の全分配関数は，

```math
Z=\frac{Z_1^N}{N!}
\tag{6}
```

で与えられる．
ここで $N!$ は，同一粒子の数え上げによる重複を除くための因子である．

Helmholtz 自由エネルギーを

```math
F=-kT\log Z
```

とする．
磁場 $H$ に関する磁気モーメントは，自由エネルギーの負の磁場微分で定義される．
したがって，

```math
M=-\left(\frac{\partial F}{\partial H}\right)_{T,V,N}
=kT\left(\frac{\partial\log Z}{\partial H}\right)_{T,V,N}
```

である．
式(6)より，

```math
\log Z=N\log Z_1-\log N!
```

となる．
$N$ は一定であり， $N!$ は磁場に依存しないので，

```math
\boxed{
M=NkT\frac{\partial\log Z_1}{\partial H}
}
\tag{7}
```

を得る．

式(5)において，磁場 $H$ に依存する部分は $x/\sinh x$ だけである．
よって，

```math
\log Z_1
=\text{定数}+\log x-\log(\sinh x)
```

と書ける．
ここで，

```math
x=\frac{\mu_{\mathrm B}H}{kT}
```

であるから，

```math
\frac{\partial x}{\partial H}
=\frac{\mu_{\mathrm B}}{kT}
```

である．
したがって，

```math
\begin{aligned}
\frac{\partial\log Z_1}{\partial H}
&=\frac{\partial x}{\partial H}
\left(\frac1x-\frac{\cosh x}{\sinh x}\right)\\[4pt]
&=\frac{\mu_{\mathrm B}}{kT}
\left(\frac1x-\coth x\right)
\end{aligned}
```

となる．
これを式(7)に代入すると，

```math
M=N\mu_{\mathrm B}
\left(\frac1x-\coth x\right)
```

である．
ここで，

```math
L(x)=\coth x-\frac1x
```

と定義すれば，

```math
M=-N\mu_{\mathrm B}L(x)
```

となる．
最後に $x=\mu_{\mathrm B}H/(kT)$ を戻すと，

```math
\boxed{
M=-N\mu_{\mathrm B}
L\left(\frac{\mu_{\mathrm B}H}{kT}\right),
\qquad
L(x)=\coth x-\frac1x
}
\tag{8}
```

が得られる．
これが示すべき関係式である．

### 4．高温極限における物理的意味

高温では，磁場を一定に保つと

```math
x=\frac{\mu_{\mathrm B}H}{kT}\ll1
```

となる．
このとき，双曲線余接関数は

```math
\coth x=\frac1x+\frac{x}{3}
-\frac{x^3}{45}+O(x^5)
```

と展開できる．
したがって，

```math
L(x)=\frac{x}{3}-\frac{x^3}{45}+O(x^5)
```

となり，式(8)から，

```math
M=-N\mu_{\mathrm B}
\left(\frac{x}{3}-\frac{x^3}{45}+\cdots\right)
```

を得る．
一次の近似では，

```math
\boxed{
M\simeq-\frac{N\mu_{\mathrm B}^2H}{3kT}
}
\tag{9}
```

である．

式(9)は，磁気モーメントが磁場と反対向きであり，温度に反比例して小さくなることを示す．
この応答は，電子の軌道運動に由来する **反磁性** である．
スピンを考慮した常磁性とは区別しなければならない．

また，

```math
\lim_{T\to\infty}M=0
```

であるため，十分に高温になると軌道磁気モーメントはゼロに近づく．
これは，古典的な平衡系では軌道運動による平衡磁化が消失するという結果とも整合する．

### 結論

ランダウ準位の縮重度を求め，単一電子の分配関数を計算すると，

```math
Z_1=
V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\frac{x}{\sinh x},
\qquad
x=\frac{\mu_{\mathrm B}H}{kT}
```

となる．
これを磁場について微分することで，

```math
\boxed{
M=-N\mu_{\mathrm B}
L\left(\frac{\mu_{\mathrm B}H}{kT}\right),
\qquad
L(x)=\coth x-\frac1x
}
```

が得られる．
また，高温では

```math
\boxed{
M\simeq-\frac{N\mu_{\mathrm B}^2H}{3kT}
}
```

となり，磁気モーメントは磁場と反対向きで，温度の上昇とともにゼロに近づく．
これはスピンを無視した電子系の軌道反磁性を表す結果である．
