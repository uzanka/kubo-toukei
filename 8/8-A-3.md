# 演習問題【8-A-3】

## 解答

まず，Fermi分布関数 $f(\varepsilon)$ およびその微分について整理する．
Fermi分布関数は次のように与えられる：

$$f(\varepsilon) = \frac{1}{e^{\beta(\varepsilon-\mu)} + 1} \quad \left( \beta = \frac{1}{kT} \right)$$

これについて， $\mu$ および $T$ に関する微分を計算する．

$$\frac{\partial f}{\partial \mu} = -\frac{1}{(e^{\beta(\varepsilon-\mu)} + 1)^2} \cdot e^{\beta(\varepsilon-\mu)} \cdot (-\beta) = \beta \frac{e^{\beta(\varepsilon-\mu)}}{(e^{\beta(\varepsilon-\mu)} + 1)^2}$$

一方で， $\varepsilon$ に関する微分（ $f'(\varepsilon)$ ）は次のようになる：

$$f'(\varepsilon) = \frac{\partial f}{\partial \varepsilon} = -\frac{1}{(e^{\beta(\varepsilon-\mu)} + 1)^2} \cdot e^{\beta(\varepsilon-\mu)} \cdot \beta = -\beta \frac{e^{\beta(\varepsilon-\mu)}}{(e^{\beta(\varepsilon-\mu)} + 1)^2}$$

したがって， $\frac{\partial f}{\partial \mu} = -f'(\varepsilon)$ が得られる．
次に， $T$ に関する微分を考える．
$\beta = (kT)^{-1}$ より $\frac{\partial \beta}{\partial T} = -\frac{1}{kT^2}$ であるから，

$$\frac{\partial f}{\partial T} = \frac{\partial f}{\partial \beta} \frac{\partial \beta}{\partial T} = \left( -\frac{\varepsilon-\mu}{(e^{\beta(\varepsilon-\mu)} + 1)^2} e^{\beta(\varepsilon-\mu)} \right) \left( -\frac{1}{kT^2} \right) = \frac{\varepsilon-\mu}{kT^2} \frac{e^{\beta(\varepsilon-\mu)}}{(e^{\beta(\varepsilon-\mu)} + 1)^2}$$

ここで， $f'(\varepsilon) = -\frac{1}{kT} \frac{e^{\beta(\varepsilon-\mu)}}{(e^{\beta(\varepsilon-\mu)} + 1)^2}$ であることを用いると，

$$\frac{\partial f}{\partial T} = -\frac{\varepsilon-\mu}{T} f'(\varepsilon)$$

と書ける．

次に，Sommerfeld展開を利用する．
強く縮退している系（ $kT \ll \mu$ ）において，関数 $H(\varepsilon)$ に対して成り立つ展開は以下の通りである：

$$\int_{0}^{\infty} H(\varepsilon) f(\varepsilon) \, d\varepsilon \approx \int_{0}^{\mu} H(\varepsilon) \, d\varepsilon + \frac{\pi^2}{6} (kT)^2 H'(\mu) + O(T^4)$$

これを用いて，各公式を導出する．

**(2) の導出**

$$\left( \frac{\partial I}{\partial \mu} \right)_{T} = \int_{0}^{\infty} g(\varepsilon) \frac{\partial f}{\partial \mu} \, d\varepsilon = \int_{0}^{\infty} g(\varepsilon) (-f'(\varepsilon)) \, d\varepsilon = -\int_{0}^{\infty} g(\varepsilon) f'(\varepsilon) \, d\varepsilon$$

ここで， $\int_{0}^{\infty} g(\varepsilon) f'(\varepsilon) \, d\varepsilon$ は， $\int_{0}^{\infty} g(\varepsilon) f(\varepsilon) \, d\varepsilon$ を $\mu$ で微分したものに等しい：

$$\frac{\partial}{\partial \mu} \int_{0}^{\infty} g(\varepsilon) f(\varepsilon) \, d\varepsilon = \int_{0}^{\infty} g(\varepsilon) \frac{\partial f}{\partial \mu} \, d\varepsilon = \int_{0}^{\infty} g(\varepsilon) (-f'(\varepsilon)) \, d\varepsilon$$

Sommerfeld展開を $\int_{0}^{\infty} g(\varepsilon) f(\varepsilon) \, d\varepsilon \approx \int_{0}^{\mu} g(\varepsilon) \, d\varepsilon + \frac{\pi^2}{6} (kT)^2 g'(\mu)$ に適用し， $\mu$ で微分すると，

$$\frac{\partial I}{\partial \mu} \approx \frac{\partial}{\partial \mu} \left( \int_{0}^{\mu} g(\varepsilon) \, d\varepsilon \right) + \frac{\pi^2}{6} (kT)^2 \frac{\partial}{\partial \mu} g'(\mu) = g(\mu) + O(T^2)$$

よって，式(2)が得られる．

**(1) の導出**

$$\left( \frac{\partial I}{\partial T} \right)_{\mu} = \int_{0}^{\infty} g(\varepsilon) \frac{\partial f}{\partial T} \, d\varepsilon = -\frac{1}{T} \int_{0}^{\infty} (\varepsilon-\mu) g(\varepsilon) f'(\varepsilon) \, d\varepsilon$$

$H(\varepsilon) = (\varepsilon-\mu)g(\varepsilon)$ とおくと， $\int_{0}^{\infty} H(\varepsilon) f'(\varepsilon) \, d\varepsilon = -\int_{0}^{\infty} H'(\varepsilon) f(\varepsilon) \, d\varepsilon$ である（部分積分による，境界項は $0$ とみなす）．
Sommerfeld展開を $\int_{0}^{\infty} H'(\varepsilon) f(\varepsilon) \, d\varepsilon$ に適用すると，

$$\int_{0}^{\infty} H'(\varepsilon) f(\varepsilon) \, d\varepsilon \approx \int_{0}^{\mu} H'(\varepsilon) \, d\varepsilon + \frac{\pi^2}{6} (kT)^2 H''(\mu) = H(\mu) - H(0) + \frac{\pi^2}{6} (kT)^2 H''(\mu)$$

ここで $H(\mu) = (\mu-\mu)g(\mu) = 0$ であり，強く縮退している極限では $H(0)$ は微小な項として無視できるため，

$$\int_{0}^{\infty} H(\varepsilon) f'(\varepsilon) \, d\varepsilon \approx - \frac{\pi^2}{6} (kT)^2 H''(\mu)$$

となる．
これを元の式に代入すると，

$$\left( \frac{\partial I}{\partial T} \right)_{\mu} \approx -\frac{1}{T} \left( - \frac{\pi^2}{6} k^2 T^2 H''(\mu) \right) = \frac{\pi^2}{6} k^2 T H''(\mu)$$

$H''(\varepsilon) = \frac{d^2}{d\varepsilon^2} [(\varepsilon-\mu)g(\varepsilon)] = 2g'(\varepsilon) + (\varepsilon-\mu)g''(\varepsilon)$ であるから， $H''(\mu) = 2g'(\mu)$ となる．
したがって，

$$\left( \frac{\partial I}{\partial T} \right)_{\mu} = \frac{\pi^2}{6} k^2 T (2g'(\mu)) + O(T^3) = \frac{\pi^2}{3} k^2 T g'(\mu) + O(T^3)$$

よって，式(1)が得られる．

**(3) の導出**

粒子数 $N$ が一定（ $dN=0$ ）である条件より，

$$dN = \left( \frac{\partial N}{\partial \mu} \right)_{T} d\mu + \left( \frac{\partial N}{\partial T} \right)_{\mu} dT = 0 \implies \left( \frac{\partial \mu}{\partial T} \right)_{N} = -\frac{(\partial N / \partial T)_{\mu}}{(\partial N / \partial \mu)_{T}}$$

$I=N$ とおくと $g=D$ であるから，(1) と (2) の結果を $g=D$ として用いると，

$$\left( \frac{\partial N}{\partial \mu} \right)_{T} = D(\mu) + O(T^2), \quad \left( \frac{\partial N}{\partial T} \right)_{\mu} = \frac{\pi^2}{3} k^2 T D'(\mu) + O(T^3)$$

これらを代入して，

$$\left( \frac{\partial \mu}{\partial T} \right)_{N} = -\frac{\frac{\pi^2}{3} k^2 T D'(\mu)}{D(\mu)} + O(T^3) = -\frac{\pi^2}{3} k^2 T \frac{D'(\mu)}{D(\mu)} + O(T^3)$$

よって，式(3)が得られる．

**(4) の導出**

全微分 $\left( \frac{\partial I}{\partial T} \right)_{N}$ は，

$$\left( \frac{\partial I}{\partial T} \right)_{N} = \left( \frac{\partial I}{\partial \mu} \right)_{T} \left( \frac{\partial \mu}{\partial T} \right)_{N} + \left( \frac{\partial I}{\partial T} \right)_{\mu}$$

と書ける．
これに(1)，(2)，(3)の結果を代入すると，

$$\left( \frac{\partial I}{\partial T} \right)_{N} = [g(\mu)] \left[ -\frac{\pi^2}{3} k^2 T \frac{D'(\mu)}{D(\mu)} \right] + \left[ \frac{\pi^2}{3} k^2 T g'(\mu) \right] + O(T^3)$$

$$= \frac{\pi^2}{3} k^2 T \left[ g'(\mu) - g(\mu) \frac{D'(\mu)}{D(\mu)} \right] + O(T^3)$$

ここで， $g(\varepsilon) = \psi(\varepsilon) D(\varepsilon)$ より，$g'(\varepsilon) = \psi'(\varepsilon) D(\varepsilon) + \psi(\varepsilon) D'(\varepsilon)$ である．
これを代入すると，

$$g'(\mu) - g(\mu) \frac{D'(\mu)}{D(\mu)} = \psi'(\mu) D(\mu) + \psi(\mu) D'(\mu) - (\psi(\mu) D(\mu)) \frac{D'(\mu)}{D(\mu)} = \psi'(\mu) D(\mu)$$

したがって，

$$\left( \frac{\partial I}{\partial T} \right)_{N} = \frac{\pi^2}{3} k^2 T \psi'(\mu) D(\mu) + O(T^3)$$

**$\mu$ から $\mu_0$ への置換の正当化:**
式(3)より，$(\partial \mu/\partial T)_N = -(\pi^2/3) k^2 T (D'(\mu)/D(\mu)) + O(T^3)$ であるから，
$$\frac{d\mu}{dT} = O(T) \implies \mu(T) = \mu_0 + O(T^2)$$
したがって，$g(\mu) = g(\mu_0) + O(T^2)$ であり，上式で $\psi'(\mu)$ や $D(\mu)$ に現れる $\mu$ を $\mu_0$ に置き換えると，その差は元の式の $T$ の係数に掛かることで $O(T^3)$ の寄与となる．すでに $O(T^3)$ の項を無視しているため，$\mu$ を $\mu_0$ に置き換えてよい．

よって，式(4)が得られる．

## 解説

この問題は，Fermi 統計に従う電子系の熱力学的性質，特に Sommerfeld 展開を用いた微分の計算に関するものである．

主なポイントは以下の通りである：

### 1. Sommerfeld展開の適用

電子系のようなフェルミ粒子系では，エネルギーが化学ポテンシャル $\mu$ 付近に集中するため，積分の評価に Sommerfeld 展開が極めて有効である．

### 2. 微分の連鎖律

粒子数 $N$ が一定の条件下での微分 $\left( \frac{\partial}{\partial T} \right)_N$ は，化学ポテンシャル $\mu$ が温度 $T$ に依存することを考慮し， $\mu$ を介した連鎖律を用いる必要がある．

### 3. 物理的意味

導出された結果は，電子系の内部エネルギーや圧力などの物理量 $I$ が，温度の一次の項としてどのように変化するかを示している．
特に $\left( \frac{\partial I}{\partial T} \right)_N$ の式は，比熱などの熱力学的量に関連する重要な関係式である．
