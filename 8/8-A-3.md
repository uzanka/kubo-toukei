# 演習問題【8-A-3】

## 解答

### 1．Fermi分布関数の微分

与えられた物理量は，

```math
I=\int_0^\infty g(\varepsilon)f(\varepsilon)\,d\varepsilon
=\int_0^\infty \psi(\varepsilon)D(\varepsilon)f(\varepsilon)\,d\varepsilon
```

である．
ここで，Fermi分布関数 $f(\varepsilon)$ は

```math
f(\varepsilon)=\frac{1}{e^{\beta(\varepsilon-\mu)}+1},
\qquad
\beta=\frac{1}{kT}
```

で与えられる．
以下では， $\varepsilon$ に関する微分を $f'(\varepsilon)$ と表す．

まず， $\varepsilon$ について微分すると，

```math
f'(\varepsilon)
=-\beta\frac{e^{\beta(\varepsilon-\mu)}}
{\left[e^{\beta(\varepsilon-\mu)}+1\right]^2}
```

となる．
一方，化学ポテンシャル $\mu$ について微分すると，

```math
\begin{aligned}
\left(\frac{\partial f}{\partial\mu}\right)_T
&=\beta\frac{e^{\beta(\varepsilon-\mu)}}
{\left[e^{\beta(\varepsilon-\mu)}+1\right]^2}\\
&=-f'(\varepsilon)
\end{aligned}
```

を得る．

次に，温度 $T$ について微分する．

```math
\frac{\partial\beta}{\partial T}=-\frac{1}{kT^2}
```

であることから，

```math
\begin{aligned}
\left(\frac{\partial f}{\partial T}\right)_\mu
&=\frac{\partial f}{\partial\beta}
\frac{\partial\beta}{\partial T}\\
&=\frac{\varepsilon-\mu}{kT^2}
\frac{e^{\beta(\varepsilon-\mu)}}
{\left[e^{\beta(\varepsilon-\mu)}+1\right]^2}\\
&=-\frac{\varepsilon-\mu}{T}f'(\varepsilon)
\end{aligned}
```

となる．
したがって，必要な関係式は

```math
\boxed{
\left(\frac{\partial f}{\partial\mu}\right)_T=-f'(\varepsilon),
\qquad
\left(\frac{\partial f}{\partial T}\right)_\mu
=-\frac{\varepsilon-\mu}{T}f'(\varepsilon)
}
```

である．

### 2．Sommerfeld展開を用いた公式

強く縮退したFermi系では， $kT\ll\mu$ であり，Fermi分布関数は化学ポテンシャル $\mu$ の近傍で急激に変化する．
このような低温極限では，Sommerfeld展開を利用して積分を近似できる．

滑らかな関数 $H(\varepsilon)$ に対して，

```math
\int_0^\infty H(\varepsilon)f(\varepsilon)\,d\varepsilon
=
\int_0^\mu H(\varepsilon)\,d\varepsilon
+\frac{\pi^2}{6}(kT)^2H'(\mu)
+O(T^4)
```

が成り立つ．
ここで， $\mu$ は積分の下端から十分離れているものとする．

この式を，積分中の関数 $H$ を固定して $\mu$ で微分すると，

```math
-\int_0^\infty H(\varepsilon)f'(\varepsilon)\,d\varepsilon
=
H(\mu)+\frac{\pi^2}{6}(kT)^2H''(\mu)+O(T^4)
```

を得る．
この関係は，以下の2つの公式を導くために用いる．

### 3．公式 $\left(\partial I/\partial T\right)_\mu$ の導出

まず， $\mu$ を一定に保ったまま $I$ を温度 $T$ で偏微分する．

```math
\begin{aligned}
\left(\frac{\partial I}{\partial T}\right)_\mu
&=\int_0^\infty g(\varepsilon)
\left(\frac{\partial f}{\partial T}\right)_\mu
\,d\varepsilon\\
&=-\frac{1}{T}\int_0^\infty
(\varepsilon-\mu)g(\varepsilon)f'(\varepsilon)\,d\varepsilon
\end{aligned}
```

となる．
ここで，

```math
H(\varepsilon)=(\varepsilon-\mu)g(\varepsilon)
```

とおくと，

```math
\left(\frac{\partial I}{\partial T}\right)_\mu
=-\frac{1}{T}\int_0^\infty H(\varepsilon)f'(\varepsilon)\,d\varepsilon
```

である．
前節の公式を適用すれば，

```math
\left(\frac{\partial I}{\partial T}\right)_\mu
=\frac{1}{T}
\left[
H(\mu)+\frac{\pi^2}{6}(kT)^2H''(\mu)+O(T^4)
\right]
```

となる．

定義より，

```math
H(\mu)=(\mu-\mu)g(\mu)=0
```

である．
また， $H(\varepsilon)$ を $\varepsilon$ で2回微分すると，

```math
H''(\varepsilon)
=2g'(\varepsilon)+(\varepsilon-\mu)g''(\varepsilon)
```

であるため，

```math
H''(\mu)=2g'(\mu)
```

を得る．
したがって，

```math
\begin{aligned}
\left(\frac{\partial I}{\partial T}\right)_\mu
&=\frac{\pi^2}{6}k^2T\cdot2g'(\mu)+O(T^3)\\
&=\frac{\pi^2}{3}k^2Tg'(\mu)+O(T^3)
\end{aligned}
```

となる．
ゆえに，

```math
\boxed{
\left(\frac{\partial I}{\partial T}\right)_\mu
=\frac{\pi^2}{3}k^2Tg'(\mu)+O(T^3)
}
\tag{1}
```

である．

### 4．公式 $\left(\partial I/\partial\mu\right)_T$ の導出

今度は，温度 $T$ を一定に保って $I$ を $\mu$ で偏微分する．

```math
\begin{aligned}
\left(\frac{\partial I}{\partial\mu}\right)_T
&=\int_0^\infty
g(\varepsilon)\left(\frac{\partial f}{\partial\mu}\right)_T
\,d\varepsilon\\
&=-\int_0^\infty g(\varepsilon)f'(\varepsilon)\,d\varepsilon
\end{aligned}
```

である．
前節のSommerfeld展開において $H(\varepsilon)=g(\varepsilon)$ とおくと，

```math
-\int_0^\infty g(\varepsilon)f'(\varepsilon)\,d\varepsilon
=
g(\mu)+\frac{\pi^2}{6}(kT)^2g''(\mu)+O(T^4)
```

となる．
したがって，

```math
\boxed{
\left(\frac{\partial I}{\partial\mu}\right)_T
=g(\mu)+O(T^2)
}
\tag{2}
```

を得る．

### 5．粒子数一定の条件から $\left(\partial\mu/\partial T\right)_N4 を求める

電子系の粒子数 $N$ は，状態密度 $D(\varepsilon)$ を用いて

```math
N=\int_0^\infty D(\varepsilon)f(\varepsilon)\,d\varepsilon
```

と表される．
したがって， $I=N$ とおけば $g(\varepsilon)=D(\varepsilon)$ である．
式 (1)，(2) より，

```math
\left(\frac{\partial N}{\partial T}\right)_\mu
=\frac{\pi^2}{3}k^2TD'(\mu)+O(T^3)
```

および

```math
\left(\frac{\partial N}{\partial\mu}\right)_T
=D(\mu)+O(T^2)
```

となる．

粒子数 $N$ を一定に保つとき，その全微分はゼロであるから，

```math
dN=
\left(\frac{\partial N}{\partial\mu}\right)_T d\mu
+\left(\frac{\partial N}{\partial T}\right)_\mu dT=0
```

である．
これを $dT$ について整理すると，

```math
\left(\frac{\partial\mu}{\partial T}\right)_N
=-\frac{
\left(\frac{\partial N}{\partial T}\right)_\mu
}{
\left(\frac{\partial N}{\partial\mu}\right)_T
}
```

となる．
先ほど求めた低温展開を代入し， $D(\mu)\neq0$ とすると，

```math
\begin{aligned}
\left(\frac{\partial\mu}{\partial T}\right)_N
&=-\frac{
\frac{\pi^2}{3}k^2TD'(\mu)+O(T^3)
}{
D(\mu)+O(T^2)
}\\
&=-\frac{\pi^2}{3}k^2T
\frac{D'(\mu)}{D(\mu)}+O(T^3)
\end{aligned}
```

を得る．
よって，

```math
\boxed{
\left(\frac{\partial\mu}{\partial T}\right)_N
=-\frac{\pi^2}{3}k^2T
\frac{D'(\mu)}{D(\mu)}+O(T^3)
}
\tag{3}
```

である．

この式から，粒子数を一定に保ったとき，

```math
\frac{d\mu}{dT}=O(T)
```

であることがわかる．
これを絶対零度から温度 $T$ まで積分すると，

```math
\mu(T)-\mu_0=O(T^2)
```

すなわち，

```math
\mu(T)=\mu_0+O(T^2)
```

となる．
ここで， $\mu_0$ は絶対零度 $T=0$ における化学ポテンシャルである．

したがって，先頭項に含まれる $g(\mu)$ ， $g'(\mu)$ ， $D(\mu)$ ， $D'(\mu)$ などの $\mu$ を $\mu_0$ に置き換えても，その差は $O(T^2)$ である．
これらの項にはさらに $T$ が掛かっているため，式全体への影響は $O(T^3)$ となる．
よって，指定された精度では $\mu$ を $\mu_0$ に置き換えてよい．
以上から，式 (1)，(2) は問題文の形で，

```math
\boxed{
\left(\frac{\partial I}{\partial T}\right)_\mu
=\frac{\pi^2}{3}k^2Tg'(\mu_0)+O(T^3)
}
```

```math
\boxed{
\left(\frac{\partial I}{\partial\mu}\right)_T
=g(\mu_0)+O(T^2)
}
```

と表される．

### 6．公式 $\left(\partial I/\partial T\right)_N$ の導出

粒子数 $N$ を一定に保って温度を変化させる場合，化学ポテンシャル $\mu$ も変化する．
このため，連鎖律より，

```math
\left(\frac{\partial I}{\partial T}\right)_N
=
\left(\frac{\partial I}{\partial T}\right)_\mu
+
\left(\frac{\partial I}{\partial\mu}\right)_T
\left(\frac{\partial\mu}{\partial T}\right)_N
```

である．
式 (1)，(2)，(3) を代入すると，

```math
\begin{aligned}
\left(\frac{\partial I}{\partial T}\right)_N
={}&\frac{\pi^2}{3}k^2Tg'(\mu)\\
&-g(\mu)\frac{\pi^2}{3}k^2T
\frac{D'(\mu)}{D(\mu)}+O(T^3)
\end{aligned}
```

となる．
整理すると，

```math
\left(\frac{\partial I}{\partial T}\right)_N
=
\frac{\pi^2}{3}k^2T
\left[
g'(\mu)-g(\mu)\frac{D'(\mu)}{D(\mu)}
\right]+O(T^3)
```

である．

ここで，

```math
g(\varepsilon)=\psi(\varepsilon)D(\varepsilon)
```

であるから，積の微分より，

```math
g'(\varepsilon)
=\psi'(\varepsilon)D(\varepsilon)
+\psi(\varepsilon)D'(\varepsilon)
```

となる．
また，

```math
g(\varepsilon)\frac{D'(\varepsilon)}{D(\varepsilon)}
=\psi(\varepsilon)D'(\varepsilon)
```

である．
したがって，

```math
\begin{aligned}
g'(\mu)-g(\mu)\frac{D'(\mu)}{D(\mu)}
={}&\psi'(\mu)D(\mu)+\psi(\mu)D'(\mu)\\
&-\psi(\mu)D'(\mu)\\
={}&\psi'(\mu)D(\mu)
\end{aligned}
```

となる．
これを代入し， $\mu=\mu_0+O(T^2)$ を用いて先頭項の $\mu$ を $\mu_0$ に置き換えると，

```math
\boxed{
\left(\frac{\partial I}{\partial T}\right)_N
=\frac{\pi^2}{3}k^2T\psi'(\mu_0)D(\mu_0)+O(T^3)
}
```

を得る．

以上により，求める3つの公式がすべて示された．
