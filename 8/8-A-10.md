# 演習問題【8-A-10】

## 解答

### 1．電子が金属表面から放出される条件

金属中の自由電子が熱エネルギーを得て真空中へ飛び出す現象を，熱電子放出という．
外部電位をエネルギーの基準 $0$ とし，金属内部の電子の位置エネルギーを $-w$ とする．
電子の運動エネルギーを

```math
\varepsilon_k=\frac{p_x^2+p_y^2+p_z^2}{2m}
```

とすれば，金属内部での全エネルギーは

```math
E=\varepsilon_k-w
```

である．
ここで， $m$ は電子の質量， $p_x,p_y,p_z$ は運動量の各成分である．

絶対零度におけるFermi準位は真空準位より $\phi$ だけ低いので，全エネルギーを基準にした化学ポテンシャルは

```math
\mu_{\mathrm{vac},0}=-\phi
```

である．
一方，運動エネルギー $\varepsilon_k$ を用いてFermi分布を記述するときの化学ポテンシャルを $\mu_{k,0}$ とすると，

```math
\mu_{k,0}-w=-\phi
```

であるから，

```math
\boxed{
\mu_{k,0}=w-\phi
}
\tag{1}
```

となる．
ここでは，真空準位を基準とする化学ポテンシャルと，運動エネルギーを基準とする化学ポテンシャルを区別している．
金属のFermi温度が十分高い通常の低温条件では，有限温度での化学ポテンシャル $\mu_k(T)$ は $\mu_{k,0}$ で近似できる．

金属表面を $z$ 方向に向いた平面とする．
表面に垂直な運動エネルギーは

```math
\varepsilon_z=\frac{p_z^2}{2m}
```

である．
表面に平行な運動量は，平らな表面のモデルでは保存される．
そのため，電子が表面のポテンシャル障壁を越えるには，表面に垂直な運動エネルギーが障壁の高さ $w$ を超えなければならない．
また，電子が金属から外へ向かうためには $p_z>0$ である必要がある．
したがって，放出条件は

```math
\boxed{
\frac{p_z^2}{2m}>w
}
\qquad\Longleftrightarrow\qquad
\boxed{
p_z>\sqrt{2mw}
}
\tag{2}
```

である．
全運動エネルギーだけを見て判定するのではなく，表面に垂直な成分を用いることが重要である．

### 2．単位面積・単位時間あたりに放出される電子数

求める電子流束を $\mathcal N$ とする．
運動量空間では，単位体積あたりの量子状態数はスピンの2重縮退を含めて $2\,d^3p/h^3$ である．
ここで， $h$ はPlanck定数である．

状態 $(p_x,p_y,p_z)$ を占有する確率は，Fermi分布関数

```math
f(\varepsilon_k)=
\frac{1}{\exp[(\varepsilon_k-\mu_k)/(kT)]+1}
```

である．
$k$ はBoltzmann定数， $T$ は絶対温度， $\mu_k=\mu_k(T)$ は運動エネルギーを基準とする化学ポテンシャルである．

電子の $z$ 方向速度は $v_z=p_z/m$ であるから，条件 (2) を満たす電子の流束は，

```math
\begin{aligned}
\mathcal N
={}&\frac{2}{h^3}
\int_{\sqrt{2mw}}^\infty
\frac{p_z}{m}\,dp_z\\
&\times
\int_{-\infty}^{\infty}dp_x
\int_{-\infty}^{\infty}dp_y\,
\frac{1}{
\exp\left[
\frac{p_x^2+p_y^2+p_z^2}{2mkT}
-\frac{\mu_k}{kT}
\right]+1
}
\end{aligned}
\tag{3}
```

と表される．
この積分では，放出条件を満たす電子だけを数え，それぞれの電子が表面に到達する速さ $p_z/m$ を掛けている．

### 3．表面に平行な運動量成分の積分

表面に平行な運動量について，

```math
p_\perp^2=p_x^2+p_y^2
```

とおく．
運動量平面で極座標に変換すると，

```math
dp_x\,dp_y=p_\perp\,dp_\perp\,d\theta
```

であり，角度 $\theta$ の積分は $2\pi$ となる．
したがって，式 (3) は

```math
\begin{aligned}
\mathcal N
=\frac{4\pi}{h^3}
\int_{\sqrt{2mw}}^\infty
\frac{p_z}{m}\,dp_z
\int_0^\infty
\frac{p_\perp\,dp_\perp}{
\exp\left[
\frac{p_z^2+p_\perp^2}{2mkT}
-\frac{\mu_k}{kT}
\right]+1}
\end{aligned}
\tag{4}
```

となる．

ここで，表面に垂直な運動エネルギーと，表面に平行な運動エネルギーをそれぞれ

```math
\varepsilon_z=\frac{p_z^2}{2m},
\qquad
\varepsilon_\perp=\frac{p_\perp^2}{2m}
```

と定義する．
すると，

```math
p_\perp\,dp_\perp=m\,d\varepsilon_\perp
```

である．
よって，式 (4) の内側の積分は

```math
m\int_0^\infty
\frac{d\varepsilon_\perp}{
\exp\left[
\frac{\varepsilon_z+\varepsilon_\perp-\mu_k}{kT}
\right]+1}
```

となる．
この積分を評価するため，

```math
x=\frac{\varepsilon_z+\varepsilon_\perp-\mu_k}{kT}
```

とおく．
このとき， $d\varepsilon_\perp=kT\,dx$ であり，積分の下端は $x=(\varepsilon_z-\mu_k)/(kT)$ ，上端は $+\infty$ である．
また，

```math
\int\frac{dx}{e^x+1}
=-\ln(1+e^{-x})
```

であるため，

```math
\begin{aligned}
&m\int_0^\infty
\frac{d\varepsilon_\perp}{
\exp\left[
\frac{\varepsilon_z+\varepsilon_\perp-\mu_k}{kT}
\right]+1}\\
&\qquad=mkT
\ln\left[
1+\exp\left(\frac{\mu_k-\varepsilon_z}{kT}\right)
\right]
\end{aligned}
\tag{5}
```

を得る．

式 (5) を式 (4) に代入すると，

```math
\mathcal N=
\frac{4\pi kT}{h^3}
\int_{\sqrt{2mw}}^\infty
p_z\,dp_z\,
\ln\left[
1+\exp\left(\frac{\mu_k-p_z^2/(2m)}{kT}\right)
\right]
```

となる．
ここで，

```math
\varepsilon_z=\frac{p_z^2}{2m},
\qquad
d\varepsilon_z=\frac{p_z}{m}\,dp_z
```

を用いて積分変数を変更する．
積分範囲は $p_z=\sqrt{2mw}$ で $\varepsilon_z=w$ ，上端では $\varepsilon_z\to\infty$ である．
したがって，

```math
\boxed{
\mathcal N=
\frac{4\pi m kT}{h^3}
\int_w^\infty
d\varepsilon_z\,
\ln\left[
1+\exp\left(\frac{\mu_k-\varepsilon_z}{kT}\right)
\right]
}
\tag{6}
```

が得られる．

### 4．仕事関数が大きい場合の近似

問題の条件は

```math
\phi\gg kT
```

である．
放出条件を満たす範囲では $\varepsilon_z\geq w$ であり，式 (1) を用いると，

```math
\mu_k-\varepsilon_z
\leq\mu_{k,0}-w=-\phi
```

と近似できる．
したがって，

```math
0\leq
\exp\left(\frac{\mu_k-\varepsilon_z}{kT}\right)
\lesssim e^{-\phi/(kT)}\ll1
```

である．
このため， $\ln(1+x)\simeq x$ という近似が使える．
式 (6) は，

```math
\begin{aligned}
\mathcal N
&\simeq
\frac{4\pi m kT}{h^3}
\int_w^\infty
\exp\left(\frac{\mu_{k,0}-\varepsilon_z}{kT}\right)
d\varepsilon_z\\
&=
\frac{4\pi m kT}{h^3}
e^{\mu_{k,0}/(kT)}
\int_w^\infty
e^{-\varepsilon_z/(kT)}\,d\varepsilon_z
\end{aligned}
```

となる．
最後の積分は，

```math
\int_w^\infty e^{-\varepsilon_z/(kT)}\,d\varepsilon_z
=kT\,e^{-w/(kT)}
```

であるから，

```math
\begin{aligned}
\mathcal N
&\simeq\frac{4\pi m(kT)^2}{h^3}
\exp\left(\frac{\mu_{k,0}-w}{kT}\right)\\
&=\frac{4\pi m(kT)^2}{h^3}
\exp\left(-\frac{\phi}{kT}\right)
\end{aligned}
```

を得る．
すなわち，単位面積・単位時間あたりの電子放出数は，

```math
\boxed{
\mathcal N=
\frac{4\pi m k^2}{h^3}
T^2 e^{-\phi/(kT)}
}
\tag{7}
```

である．

### 5．Richardsonの式

陽極に適切な電位差を与え，放出された電子をすべて回収する場合，電流密度の大きさ $J$ は，電子1個の電荷の大きさ $e$ と電子流束 $\mathcal N$ の積である．
したがって，

```math
J=e\mathcal N
```

である．
式 (7) を代入すると，

```math
J=\frac{4\pi m e k^2}{h^3}
T^2 e^{-\phi/(kT)}
```

となる．
よって，

```math
\boxed{
J=AT^2e^{-\phi/(kT)}
}
```

ただし，

```math
\boxed{
A=\frac{4\pi m e k^2}{h^3}
}
```

である．
これがRichardsonの式であり， $A$ はRichardson定数である．

この式は，金属表面から電子を放出させるために必要なエネルギー障壁が仕事関数 $\phi$ で決まり， $\phi\gg kT$ では放出できる電子の数がBoltzmann因子 $e^{-\phi/(kT)}$ によって強く抑制されることを表している．
一方，運動量成分の積分から $T^2$ の因子が生じるため，熱電子流は温度の2乗と仕事関数の指数関数で決まるのである．
