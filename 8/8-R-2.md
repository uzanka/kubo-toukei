# 例題【8-R-2】

## 解答

### 1．粒子数と Sommerfeld 展開

状態密度を $D(\varepsilon)$ ，化学ポテンシャルを $\mu$ ，ボルツマン定数を $k$ ，絶対温度を $T$ とする．
Fermi-Dirac 分布関数は

```math
f(\varepsilon)=\frac{1}{e^{(\varepsilon-\mu)/kT}+1}
```

である．
このとき，粒子数 $N$ と内部エネルギー $E$ は，それぞれ

```math
N=\int_0^\infty D(\varepsilon)f(\varepsilon)\,d\varepsilon
\tag{1}
```

```math
E=\int_0^\infty \varepsilon D(\varepsilon)f(\varepsilon)\,d\varepsilon
\tag{2}
```

と表される．

絶対零度 $T=0$ では，エネルギーが $\mu_0$ より小さい状態は占有され，それより大きい状態は占有されない．
ここで， $\mu_0$ は絶対零度における化学ポテンシャルである．
したがって，粒子数は

```math
N=\int_0^{\mu_0}D(\varepsilon)\,d\varepsilon
\tag{3}
```

となる．

十分低温では，次の Sommerfeld 展開を適用できる．

```math
\begin{aligned}
\int_0^\infty g(\varepsilon)f(\varepsilon)\,d\varepsilon
={}&\int_0^\mu g(\varepsilon)\,d\varepsilon\\
&+\frac{\pi^2}{6}(kT)^2g'(\mu)+O(T^4)
\end{aligned}
\tag{4}
```

ここで， $g(\varepsilon)$ はエネルギーの滑らかな関数であり， $g'(\varepsilon)$ はエネルギーによる微分を表す．
$O(T^4)$ は，温度の4次以上の項を表す．
以下では，低温で支配的な項を残して計算する．

式 (1) に式 (4) を適用し， $g(\varepsilon)=D(\varepsilon)$ とおくと，

```math
N=\int_0^\mu D(\varepsilon)\,d\varepsilon
+\frac{\pi^2}{6}(kT)^2D'(\mu)+O(T^4)
\tag{5}
```

を得る．
式 (3) と式 (5) は同じ粒子数 $N$ を表すため，両式を等置して整理すると，

```math
\begin{aligned}
0={}&\int_{\mu_0}^{\mu}D(\varepsilon)\,d\varepsilon\\
&+\frac{\pi^2}{6}(kT)^2D'(\mu)+O(T^4)
\end{aligned}
\tag{6}
```

となる．

十分低温では $\mu-\mu_0$ は小さいため，積分を一次近似し，微分項の評価点を $\mu_0$ に置き換えることができる．
すなわち，

```math
\int_{\mu_0}^{\mu}D(\varepsilon)\,d\varepsilon
\approx(\mu-\mu_0)D(\mu_0)
```

および

```math
D'(\mu)\approx D'(\mu_0)
```

である．
これらを式 (6) に代入すると，

```math
(\mu-\mu_0)D(\mu_0)
+\frac{\pi^2}{6}(kT)^2D'(\mu_0)\approx0
```

となる．
これを $\mu$ について解けば，

```math
\boxed{
\mu\approx\mu_0
-\frac{\pi^2}{6}(kT)^2
\frac{D'(\mu_0)}{D(\mu_0)}
}
\tag{7}
```

が得られる．
これは，粒子数を一定に保つために，有限温度では化学ポテンシャルが絶対零度の値 $\mu_0$ からずれることを表している．

### 2．内部エネルギーの導出

次に，式 (2) に Sommerfeld 展開を適用する．
$g(\varepsilon)=\varepsilon D(\varepsilon)$ とすると，

```math
\begin{aligned}
E={}&\int_0^\mu\varepsilon D(\varepsilon)\,d\varepsilon\\
&+\frac{\pi^2}{6}(kT)^2
\left[
\frac{d}{d\varepsilon}
\bigl(\varepsilon D(\varepsilon)\bigr)
\right]_{\varepsilon=\mu}
+O(T^4)
\end{aligned}
\tag{8}
```

となる．
積の微分法則より，

```math
\frac{d}{d\varepsilon}
\bigl(\varepsilon D(\varepsilon)\bigr)
=D(\varepsilon)+\varepsilon D'(\varepsilon)
\tag{9}
```

である．

まず，式 (8) の第1項を考える．
積分を $\mu_0$ までの部分とその差分に分けると，

```math
\begin{aligned}
\int_0^\mu\varepsilon D(\varepsilon)\,d\varepsilon
={}&\int_0^{\mu_0}\varepsilon D(\varepsilon)\,d\varepsilon\\
&+\int_{\mu_0}^{\mu}\varepsilon D(\varepsilon)\,d\varepsilon
\end{aligned}
\tag{10}
```

となる．
$\mu-\mu_0$ が小さいことから，第2項は一次近似によって

```math
\int_{\mu_0}^{\mu}\varepsilon D(\varepsilon)\,d\varepsilon
\approx(\mu-\mu_0)\mu_0D(\mu_0)
\tag{11}
```

と表される．

式 (7) より，

```math
\mu-\mu_0
\approx-\frac{\pi^2}{6}(kT)^2
\frac{D'(\mu_0)}{D(\mu_0)}
\tag{12}
```

である．
これを式 (11) に代入すると，

```math
\begin{aligned}
\int_{\mu_0}^{\mu}\varepsilon D(\varepsilon)\,d\varepsilon
\approx
-\frac{\pi^2}{6}(kT)^2\mu_0D'(\mu_0)
\end{aligned}
\tag{13}
```

となる．
したがって，式 (10) は

```math
\begin{aligned}
\int_0^\mu\varepsilon D(\varepsilon)\,d\varepsilon
\approx{}&
\int_0^{\mu_0}\varepsilon D(\varepsilon)\,d\varepsilon\\
&-\frac{\pi^2}{6}(kT)^2\mu_0D'(\mu_0)
\end{aligned}
\tag{14}
```

と書ける．

一方，式 (8) の第2項では，すでに $(kT)^2$ が掛かっているため，最低次の近似では $\mu$ を $\mu_0$ に置き換えてよい．
式 (9) より，

```math
\begin{aligned}
&\left[
\frac{d}{d\varepsilon}
\bigl(\varepsilon D(\varepsilon)\bigr)
\right]_{\varepsilon=\mu}\\
&\qquad\approx D(\mu_0)+\mu_0D'(\mu_0)
\end{aligned}
\tag{15}
```

である．

式 (14) と式 (15) を式 (8) に代入すると，

```math
\begin{aligned}
E\approx{}&
\int_0^{\mu_0}\varepsilon D(\varepsilon)\,d\varepsilon\\
&-\frac{\pi^2}{6}(kT)^2\mu_0D'(\mu_0)\\
&+\frac{\pi^2}{6}(kT)^2
\left[D(\mu_0)+\mu_0D'(\mu_0)\right]
\end{aligned}
\tag{16}
```

となる．
ここで， $\mu_0D'(\mu_0)$ を含む項は互いに相殺される．
よって，

```math
\boxed{
E\approx
\int_0^{\mu_0}\varepsilon D(\varepsilon)\,d\varepsilon
+\frac{\pi^2}{6}(kT)^2D(\mu_0)
}
\tag{17}
```

を得る．

式 (17) の第1項は絶対零度における内部エネルギーであり，体積 $V$ と粒子数 $N$ を一定に保てば温度に依存しない．
したがって，低温における内部エネルギーの温度依存性は，第2項によって決まるのである．

### 3．比熱 $C_V$ の導出

定積比熱は，体積と粒子数を一定に保って内部エネルギーを温度で微分したものである．
したがって，

```math
C_V=\left(\frac{\partial E}{\partial T}\right)_{V,N}
\tag{18}
```

である．
式 (17) を温度 $T$ で微分すると，

```math
\begin{aligned}
C_V
&\approx\frac{\partial}{\partial T}
\left[
\int_0^{\mu_0}\varepsilon D(\varepsilon)\,d\varepsilon
+\frac{\pi^2}{6}(kT)^2D(\mu_0)
\right]\\
&=\frac{\pi^2}{6}k^2D(\mu_0)\frac{d}{dT}T^2\\
&=\frac{\pi^2}{6}k^2D(\mu_0)\cdot2T\\
&=\frac{\pi^2}{3}k^2TD(\mu_0)
\end{aligned}
```

となる．
よって，十分低温では，

```math
\boxed{
C_V\approx\frac{\pi^2}{3}k^2TD(\mu_0)
}
```

が得られる．
これで題意が示された．

なお，問題文の $C_v$ は定積比熱を表す記号であり，上では粒子数一定の条件を明示するため $C_V$ と表記した．
