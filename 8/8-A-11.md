# 演習問題【8-A-11】

## 解答

### 1．電子系の自由エネルギー

$N$ 個の原子を含む金属体のあるエネルギー帯には，スピンの自由度を含めて $2N$ 個の一電子状態があるとする．
このエネルギー帯が完全に満たされるとき，電子数は $2N$ 個である．

いま，実際には $2N-N'$ 個の電子がこのエネルギー帯を占有しているとする．
電子が1つの一電子状態を占有していない場合を空孔と呼ぶため，空孔の数は $N'$ 個である．

電子のエネルギー準位を $\varepsilon_i$ ，化学ポテンシャルを $\mu$ ，絶対温度を $T$ とする．
また，

```math
\beta=\frac{1}{kT}
```

と定義する．
Fermi分布に従う電子系のHelmholtz自由エネルギー $F$ は，

```math
F=(2N-N')\mu
-kT\sum_i\log\left[1+e^{\beta(\mu-\varepsilon_i)}\right]
\tag{1}
```

と表される．
ここで，和 $\sum_i$ は，スピンの自由度を含む $2N$ 個の一電子状態すべてについて取るものとする．

### 2．自由エネルギーを空孔の形に変形する

式 (1) を変形するため，対数の中身を次のように書き換える．

```math
\begin{aligned}
1+e^{\beta(\mu-\varepsilon_i)}
&=e^{\beta(\mu-\varepsilon_i)}
\left[1+e^{\beta(\varepsilon_i-\mu)}\right]
\end{aligned}
```

したがって，

```math
\log\left[1+e^{\beta(\mu-\varepsilon_i)}\right]
=\beta(\mu-\varepsilon_i)
+\log\left[1+e^{\beta(\varepsilon_i-\mu)}\right]
\tag{2}
```

である．
これを式 (1) に代入すると，

```math
\begin{aligned}
F={}&(2N-N')\mu
-kT\sum_i\left\{
\beta(\mu-\varepsilon_i)
+\log\left[1+e^{\beta(\varepsilon_i-\mu)}\right]
\right\}\\
={}&(2N-N')\mu-\sum_i(\mu-\varepsilon_i)\\
&-kT\sum_i\log\left[1+e^{\beta(\varepsilon_i-\mu)}\right]
\end{aligned}
```

となる．
ここで状態の総数が $2N$ 個であるため，

```math
\sum_i(\mu-\varepsilon_i)
=2N\mu-\sum_i\varepsilon_i
```

である．
これを用いると，

```math
\begin{aligned}
F={}&(2N-N')\mu-2N\mu+\sum_i\varepsilon_i\\
&-kT\sum_i\log\left[1+e^{\beta(\varepsilon_i-\mu)}\right]
\end{aligned}
```

となり，整理して，

```math
\boxed{
F=\sum_i\varepsilon_i-N'\mu
-kT\sum_i\log\left[1+e^{\beta(\varepsilon_i-\mu)}\right]
}
\tag{3}
```

を得る．

### 3．空孔の数とFermi分布

次に，空孔の数 $N'$ が，エネルギー準位 $-\varepsilon_i$ ，化学ポテンシャル $-\mu$ をもつ電子気体の粒子数と一致することを示す．

電子が状態 $i$ を占有する確率は，

```math
f_i=\frac{1}{e^{\beta(\varepsilon_i-\mu)}+1}
```

である．
その状態が空いている確率，すなわち空孔が存在する確率は，

```math
\begin{aligned}
1-f_i
&=1-\frac{1}{e^{\beta(\varepsilon_i-\mu)}+1}\\
&=\frac{e^{\beta(\varepsilon_i-\mu)}}
{e^{\beta(\varepsilon_i-\mu)}+1}\\
&=\frac{1}{e^{\beta(\mu-\varepsilon_i)}+1}
\end{aligned}
```

となる．
したがって，空孔の総数は，

```math
N'=\sum_i(1-f_i)
=\sum_i\frac{1}{e^{\beta(\mu-\varepsilon_i)}+1}
\tag{4}
```

である．

ここで，空孔のエネルギー準位を

```math
\varepsilon_i^{(h)}=-\varepsilon_i
```

化学ポテンシャルを

```math
\mu_h=-\mu
```

と定義する．
すると，

```math
\varepsilon_i^{(h)}-\mu_h
=-\varepsilon_i+\mu
=\mu-\varepsilon_i
```

であるから，式 (4) は，

```math
\boxed{
N'=\sum_i
\frac{1}{e^{\beta(\varepsilon_i^{(h)}-\mu_h)}+1}
}
\tag{5}
```

となる．
これは，エネルギー準位 $-\varepsilon_i$ ，化学ポテンシャル $-\mu$ をもつFermi気体の粒子数を表す式そのものである．

### 4．熱的性質が一致すること

空孔を粒子とみなしたFermi気体の自由エネルギーを $F_h$ とする．
粒子数が $N'$ ，化学ポテンシャルが $\mu_h=-\mu$ ，エネルギー準位が $\varepsilon_i^{(h)}=-\varepsilon_i$ であるため，

```math
\begin{aligned}
F_h
&=\mu_hN'
-kT\sum_i
\log\left[1+e^{\beta(\mu_h-\varepsilon_i^{(h)})}\right]\\
&=-N'\mu
-kT\sum_i
\log\left[1+e^{\beta(\varepsilon_i-\mu)}\right]
\end{aligned}
\tag{6}
```

となる．
式 (3) と比較すると，

```math
\boxed{
F=\sum_i\varepsilon_i+F_h
}
\tag{7}
```

である．
ここで $\sum_i\varepsilon_i$ は，完全に満たされたバンドに対応するエネルギーの総和であり，エネルギー準位が固定されていれば温度 $T$ に依存しない定数である．

したがって，電子系と空孔系の自由エネルギーは，温度に依存しない定数を除けば一致する．
その結果，エントロピー

```math
S=-\left(\frac{\partial F}{\partial T}\right)_{N,V}
```

や定積熱容量

```math
C_V=T\left(\frac{\partial S}{\partial T}\right)_{N,V}
```

などの熱的性質は，空孔を電子数 $N'$ ，エネルギー準位 $-\varepsilon_i$ ，化学ポテンシャル $-\mu$ をもつFermi気体とみなして求めた結果に一致する．

以上より，電子が $2N-N'$ 個で占められたエネルギー帯の熱的性質は， $N'$ 個の空孔からなるFermi気体の熱的性質と同じであることが示された．
