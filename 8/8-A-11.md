# 演習問題【8-A-11】

## 解答

問題の状況を整理する．
あるエネルギー帯に $2N$ 個の状態があり，そこに $2N - N'$ 個の電子が占められているとする．
このとき，占められていない状態の数（空孔の数）は $N'$ 個である．

まず，この電子系が持つ Helmholtz 自由エネルギー $F$ を考える．
グランドカノニカルアンサンブルにおける分配関数 $Z_{gc}$ を用いると，グランドポテンシャル $\Omega$ は次のように書ける：

$$\Omega = -kT \sum_{i} \log(1 + e^{\beta(\mu - \varepsilon_i)})$$

ここで， $\mu$ は電子の化学ポテンシャル， $\varepsilon_i$ は各状態のエネルギー準位である．
Helmholtz 自由エネルギー $F$ との関係式 $F = \Omega + \mu N_{el}$ （ただし $N_{el}$ は電子数）を用いると，電子系の自由エネルギーは次のように与えられる：

$$F = \mu(2N - N') - kT \sum_{i} \log(1 + e^{\beta(\mu - \varepsilon_i)}) \quad \cdots (1)$$

これが解答例の式(1)である．

次に，この式を変形して「空孔（ホール）」の観点から記述する．
まず，対数項の中身を次のように変形する：

$$\log(1 + e^{\beta(\mu - \varepsilon_i)}) = \log\left( e^{\beta(\mu - \varepsilon_i)} (e^{-\beta(\mu - \varepsilon_i)} + 1) \right) = \beta(\mu - \varepsilon_i) + \log(1 + e^{\beta(\varepsilon_i - \mu)})$$

これを式(1)に代入すると：

$$F = \mu(2N - N') - kT \sum_{i} \left[ \beta(\mu - \varepsilon_i) + \log(1 + e^{\beta(\varepsilon_i - \mu)}) \right]$$

$$= 2N\mu - N'\mu - \sum_{i} (\mu - \varepsilon_i) - kT \sum_{i} \log(1 + e^{\beta(\varepsilon_i - \mu)})$$

ここで， $\sum_{i} (\mu - \varepsilon_i) = 2N\mu - \sum_{i} \varepsilon_i$ であるから，

$$F = 2N\mu - N'\mu - 2N\mu + \sum_{i} \varepsilon_i - kT \sum_{i} \log(1 + e^{\beta(\varepsilon_i - \mu)})$$

$$F = \sum_{i} \varepsilon_i - N'\mu - kT \sum_{i} \log(1 + e^{\beta(\varepsilon_i - \mu)}) \quad \cdots (3')$$

ここで， $\log(1 + e^{\beta(\varepsilon_i - \mu)}) = \log(1 + e^{\beta(-\mu - (-\varepsilon_i))})$ であるから，

$$F = \sum_{i} \varepsilon_i - N'\mu - kT \sum_{i} \log[1 + e^{\beta(-\mu - (-\varepsilon_i))}] \quad \cdots (3)$$

が得られる．

次に，空孔の数 $N'$ を求める．電子の数 $N_{el} = 2N - N'$ は，次のように書ける：

$$2N - N' = kT \frac{\partial}{\partial \mu} \sum_{i} \log(1 + e^{\beta(\mu - \varepsilon_i)}) = \sum_{i} \frac{e^{\beta(\mu - \varepsilon_i)}}{1 + e^{\beta(\mu - \varepsilon_i)}} = \sum_{i} \frac{1}{1 + e^{\beta(\varepsilon_i - \mu)}} \quad \cdots (4')$$

ここで， $1 - \frac{1}{1 + e^{\beta(\varepsilon_i - \mu)}} = \frac{e^{\beta(\varepsilon_i - \mu)}}{1 + e^{\beta(\varepsilon_i - \mu)}} = \frac{1}{1 + e^{\beta(\mu - \varepsilon_i)}}$ であることを利用すると，

$$2N - N' = \sum_{i} \left( 1 - \frac{1}{1 + e^{\beta(\mu - \varepsilon_i)}} \right) = 2N - \sum_{i} \frac{1}{1 + e^{\beta(\mu - \varepsilon_i)}}$$

したがって，

$$N' = \sum_{i} \frac{1}{1 + e^{\beta(\mu - \varepsilon_i)}} = \sum_{i} \frac{1}{1 + e^{\beta(-\varepsilon_i - (-\mu))}} \quad \cdots (5)$$

が得られる．

式(3)において，第1項の $\sum_{i} \varepsilon_i$ はエネルギーの原点の取り方に依存する定数であり，熱力学的な性質（温度 $T$ や化学ポテンシャル $\mu$ による微分）には寄与しない．
よって，自由エネルギーの温度や化学ポテンシャルに関する依存性は，

$$F \approx -N'\mu - kT \sum_{i} \log[1 + e^{\beta(-\mu - (-\varepsilon_i))}]$$

によって決まる．
これは，粒子数 $N'$ ，エネルギー準位 $-\varepsilon_i$ ，化学ポテンシャル $-\mu$ を持つ電子気体の自由エネルギーの形と全く同一である．
したがって，問題の二つの系の熱的性質は一致する．

## 解説

この問題は，金属や半導体のバンド構造における「電子」と「空孔（ホール）」の対称性を扱っている．

通常，エネルギー準位 $\varepsilon_i$ に電子が入っている状態を考えるが，バンドが満たされている状態から「電子が抜けた穴」を一つの粒子として扱うことができる．
この穴が「空孔」である．
空孔のエネルギーは，電子のエネルギー $\varepsilon_i$ に対して符号を反転させた $-\varepsilon_i$ となり，化学ポテンシャルも $-\mu$ となる．
この問題では，電子の系と空孔の系が数学的に全く同じ自由エネルギーの形を持つことを示している．
これは，物理学において「粒子」と「空孔」を入れ替えて考えることが，計算を単純化したり現象を直感的に理解したりする上で非常に強力な手法であることを示している．
