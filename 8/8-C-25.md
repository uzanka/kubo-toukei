# 演習問題【8-C-25】

## 解答

強く縮退した相対論的な理想 Fermi 気体について，有限温度の化学ポテンシャル $\mu$ および定積熱容量 $C_V4 を求める．
解答例と同様に，粒子数とエネルギーを Fermi 分布の積分で表し，Sommerfeld 展開を用いて低温補正を計算する．

### 1．粒子数とエネルギーの積分表示

相対論的極限では，粒子のエネルギー $\varepsilon$ と運動量の大きさ $p=|\boldsymbol p|$ の関係は，

```math
\varepsilon=cp
```

である．
スピン $1/2$ の粒子にはスピンの状態が2通りあるため，体積 $V$ の運動量空間の微小体積 $d^3p$ に含まれる状態数は，

```math
d\Gamma=\frac{2V}{h^3}d^3p
```

となる．
運動量空間で球座標を用いると，

```math
d^3p=4\pi p^2\,dp
```

である．
また， $\varepsilon=cp$ より，

```math
p=\frac{\varepsilon}{c},
\qquad
dp=\frac{d\varepsilon}{c}
```

となるので，

```math
d\Gamma=\frac{8\pi V}{h^3c^3}
\varepsilon^2\,d\varepsilon
\tag{1}
```

を得る．

温度 $T$ ，化学ポテンシャル $\mu$ における Fermi 分布関数は，

```math
f(\varepsilon)=
\frac{1}{e^{\beta(\varepsilon-\mu)}+1},
\qquad
\beta=\frac{1}{kT}
```

である．
ここで $k$ はボルツマン定数である．
粒子数 $N$ は各状態の平均占有数を合計した量であるから，

```math
N=\int_0^\infty f(\varepsilon)\,d\Gamma
```

となる．
式(1)を代入すれば，

```math
\boxed{
\frac NV=
\frac{8\pi}{h^3c^3}
\int_0^\infty
\frac{\varepsilon^2}
{e^{\beta(\varepsilon-\mu)}+1}
\,d\varepsilon
}
\tag{2}
```

が得られる．

同様に，内部エネルギー $E$ は各状態のエネルギーと平均占有数の積を合計したものである．
したがって，

```math
E=\int_0^\infty
\varepsilon f(\varepsilon)\,d\Gamma
```

より，

```math
\boxed{
\frac EV=
\frac{8\pi}{h^3c^3}
\int_0^\infty
\frac{\varepsilon^3}
{e^{\beta(\varepsilon-\mu)}+1}
\,d\varepsilon
}
\tag{3}
```

を得る．

### 2．Sommerfeld 展開による粒子数とエネルギーの計算

強く縮退した Fermi 気体では，

```math
kT\ll\mu
```

が成り立つ．
このとき，Fermi 分布関数は化学ポテンシャル $\mu$ の近傍で急激に変化するため，積分を Sommerfeld 展開によって近似できる．
一般に，十分滑らかな関数 $g(\varepsilon)$ に対して，

```math
\begin{aligned}
\int_0^\infty g(\varepsilon)
f(\varepsilon)\,d\varepsilon
={}&\int_0^\mu g(\varepsilon)\,d\varepsilon\\
&+\frac{\pi^2}{6}(kT)^2g'(\mu)\\
&+\frac{7\pi^4}{360}(kT)^4g'''(\mu)+\cdots
\end{aligned}
\tag{4}
```

が成立する．
ここで $g'$ ， $g'''$ はそれぞれ一次微分，三次微分である．

#### （1）粒子数密度

式(2)で $g(\varepsilon)=\varepsilon^2$ とする．
このとき，

```math
g'(\mu)=2\mu,\qquad g'''(\mu)=0
```

である．
したがって，式(4)より，

```math
\begin{aligned}
\frac NV
&=\frac{8\pi}{h^3c^3}
\left[
\int_0^\mu\varepsilon^2\,d\varepsilon
+\frac{\pi^2}{6}(kT)^2\,2\mu
\right]+\cdots\\
&=\frac{8\pi}{h^3c^3}
\left[
\frac{\mu^3}{3}
+\frac{\pi^2}{3}\mu(kT)^2
\right]+\cdots
\end{aligned}
```

となる．
これを整理すると，

```math
\boxed{
\frac NV=
\frac{8\pi\mu^3}{3h^3c^3}
\left[
1+\left(\frac{\pi kT}{\mu}\right)^2
\right]+\cdots
}
\tag{5}
```

を得る．

#### （2）エネルギー密度

式(3)で $g(\varepsilon)=\varepsilon^3$ とする．
この場合，

```math
g'(\mu)=3\mu^2,\qquad g'''(\mu)=6
```

であるから，

```math
\begin{aligned}
\frac EV
={}&\frac{8\pi}{h^3c^3}
\left[
\int_0^\mu\varepsilon^3\,d\varepsilon
+\frac{\pi^2}{6}(kT)^2\,3\mu^2\right.\\
&\left.\qquad
+\frac{7\pi^4}{360}(kT)^4\,6
\right]+\cdots\\
={}&\frac{8\pi}{h^3c^3}
\left[
\frac{\mu^4}{4}
+\frac{\pi^2}{2}\mu^2(kT)^2
+\frac{7\pi^4}{60}(kT)^4
\right]+\cdots
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\frac EV=
\frac{2\pi\mu^4}{h^3c^3}
\left[
1+2\left(\frac{\pi kT}{\mu}\right)^2
+\frac{7}{15}\left(\frac{\pi kT}{\mu}\right)^4
\right]+\cdots
}
\tag{6}
```

を得る．

式(5)，(6)は，強く縮退した場合の粒子数密度とエネルギー密度の低温展開である．

### 3．化学ポテンシャル $\mu$ の導出

絶対零度 $T=0$ における化学ポテンシャルを $\mu_0$ とする．
式(5)に $T=0$ を代入すると，

```math
n=\frac NV=\frac{8\pi\mu_0^3}{3h^3c^3}
```

となる．
よって，

```math
\boxed{
\mu_0=hc\left(\frac{3n}{8\pi}\right)^{1/3}
}
\tag{7}
```

である．

次に，有限温度の化学ポテンシャルを

```math
\mu=\mu_0(1+\delta),
\qquad |\delta|\ll1
```

とおく．
ここで $\delta$ は温度上昇による化学ポテンシャルの相対的な変化を表す量である．

式(5)にこの表式を代入すると，

```math
n\simeq
\frac{8\pi\mu_0^3}{3h^3c^3}
\left[
1+3\delta+
\left(\frac{\pi kT}{\mu_0}\right)^2
\right]
```

となる．
粒子数 $N$ と体積 $V$ は一定であるため，粒子数密度 $n$ は温度によらず一定である．
したがって，式(7)との比較から，

```math
1+3\delta+
\left(\frac{\pi kT}{\mu_0}\right)^2
=1
```

を得る．
これを $\delta$ について解くと，

```math
\delta=-\frac13
\left(\frac{\pi kT}{\mu_0}\right)^2
```

である．
したがって，化学ポテンシャルは，

```math
\boxed{
\mu=\mu_0\left[
1-\frac13\left(\frac{\pi kT}{\mu_0}\right)^2
+\cdots
\right]
}
\tag{8}
```

となる．
すなわち，強く縮退した相対論的 Fermi 気体の化学ポテンシャルは，温度の上昇に伴って絶対零度の値 $\mu_0$ から $T^2$ に比例して低下する．

### 4．内部エネルギーを $\mu_0$ で表す

式(6)に式(8)を代入する．簡単のため，

```math
a=\left(\frac{\pi kT}{\mu_0}\right)^2
```

とおく．
このとき，

```math
\frac{\mu^4}{\mu_0^4}
\simeq\left(1-\frac a3\right)^4
\simeq1-\frac43a
```

である．
また， $T^2$ の項まで考えれば，

```math
1+2\left(\frac{\pi kT}{\mu}\right)^2
\simeq1+2a
```

となる．
これらの積を計算すると，

```math
\left(1-\frac43a\right)(1+2a)
\simeq1+\frac23a
```

を得る．
したがって，

```math
\boxed{
\frac EV=
\frac{2\pi\mu_0^4}{h^3c^3}
\left[
1+\frac23\left(\frac{\pi kT}{\mu_0}\right)^2
+\cdots
\right]
}
\tag{9}
```

となる．

式(7)から，

```math
n=\frac{8\pi\mu_0^3}{3h^3c^3}
```

であるため，式(9)を粒子数密度で割ると，

```math
\begin{aligned}
\frac EN
&=\frac{E/V}{N/V}\\
&=\frac34\mu_0
\left[
1+\frac23\left(\frac{\pi kT}{\mu_0}\right)^2
+\cdots
\right]
\end{aligned}
```

となる．
したがって，

```math
\boxed{
E=N\frac34\mu_0
\left[
1+\frac23\left(\frac{\pi kT}{\mu_0}\right)^2
+\cdots
\right]
}
\tag{10}
```

を得る．

### 5．定積熱容量 $C_V$

定積熱容量は，粒子数 $N$ と体積 $V$ を一定に保ったときの内部エネルギーの温度微分である．
すなわち，

```math
C_V=\left(\frac{\partial E}{\partial T}\right)_{N,V}
```

である．
式(10)を展開すると，

```math
E=N\left[
\frac34\mu_0
+\frac12\frac{\pi^2k^2T^2}{\mu_0}
+\cdots
\right]
```

となる．
ここで， $\mu_0$ は $N,V$ が一定ならば温度に依存しない定数である．
したがって，

```math
\begin{aligned}
C_V
&=N\frac{\partial}{\partial T}
\left[
\frac34\mu_0
+\frac12\frac{\pi^2k^2T^2}{\mu_0}
+\cdots
\right]\\
&=N\frac{\pi^2k^2T}{\mu_0}+\cdots
\end{aligned}
```

となる．
よって，

```math
\boxed{
C_V=N\frac{\pi^2k^2T}{\mu_0}+\cdots
}
\tag{11}
```

が得られる．
熱容量の主要項は温度 $T$ に比例する．

最後に，式(7)の

```math
\mu_0=hc\left(\frac{3n}{8\pi}\right)^{1/3}
```

を代入すると，

```math
\begin{aligned}
C_V
&=N\frac{\pi^2k^2T}
{hc(3n/8\pi)^{1/3}}+\cdots\\
&=N\frac{2\pi^{7/3}k^2T}
{3^{1/3}hcn^{1/3}}+\cdots
\end{aligned}
```

である．
したがって，

```math
\boxed{
C_V=
N\frac{2\pi^{7/3}k^2T}
{3^{1/3}hcn^{1/3}}+\cdots
}
\tag{12}
```

となる．

### 結論

強く縮退した相対論的な理想 Fermi 気体の化学ポテンシャルおよび定積熱容量は，

```math
\boxed{
\mu=\mu_0\left[
1-\frac13\left(\frac{\pi kT}{\mu_0}\right)^2
+\cdots
\right]
}
```

```math
\boxed{
\mu_0=hc\left(\frac{3n}{8\pi}\right)^{1/3}
}
```

および

```math
\boxed{
C_V=N\frac{\pi^2k^2T}{\mu_0}+\cdots
=N\frac{2\pi^{7/3}k^2T}
{3^{1/3}hcn^{1/3}}+\cdots
}
```

である．
したがって，温度が上昇すると化学ポテンシャルは絶対零度の値から $T^2$ に比例して低下し，熱容量は低温で $T$ に比例する．
これは，強く縮退した Fermi 気体では，主として Fermi 面近傍の粒子だけが熱的な励起に寄与するためである．
