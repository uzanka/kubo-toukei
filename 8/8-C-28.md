# 演習問題【8-C-28】

## 解答

### 理想 Fermi 気体の密度行列の $q$ 表示

#### 1．問題の設定

スピンを考慮しない，質量 $m$ の相互作用のない同種 Fermi 粒子 $N$ 個からなる系を考える．
各粒子の位置を $\mathbf q_i$ ，全粒子の位置を

```math
\mathbf Q=(\mathbf q_1,\ldots,\mathbf q_N)
```

と表す．
また， $\mathbf Q'=(\mathbf q'_1,\ldots,\mathbf q'_N)$ とする．

自由粒子の 1 粒子ハミルトニアンと系全体のハミルトニアンは

```math
h=\frac{\mathbf p^2}{2m},
\qquad
H=\sum_{i=1}^{N}h_i
```

である．
逆温度を

```math
\beta=\frac{1}{k_{\mathrm B}T}
```

と定義する．
ここで $k_{\mathrm B}$ は Boltzmann 定数， $T$ は絶対温度である．

まず，規格化前の密度演算子 $e^{-\beta H}$ の行列要素を求める．
その後，正準分配関数 $Z_N$ を用いて規格化する．

#### 2．Fermi 粒子の反対称性と密度行列

自由粒子の 1 粒子状態を，波数ベクトル $\mathbf k$ で指定する．
体積 $V$ の箱の中で，規格化された平面波状態は

```math
\varphi_{\mathbf k}(\mathbf q)
=\frac{1}{\sqrt V}e^{i\mathbf k\cdot\mathbf q}
```

と書ける．
そのエネルギーは

```math
\epsilon_{\mathbf k}=\frac{\hbar^2 k^2}{2m}
```

である．

Fermi 粒子の全波動関数は，粒子の交換に対して反対称でなければならない．
この条件を満たす $N$ 粒子の波動関数は，Slater 行列式，すなわち

```math
\Psi_{\mathbf k_1,\ldots,\mathbf k_N}(\mathbf Q)
=
\frac{1}{\sqrt{N!}}
\det\!\left[
\varphi_{\mathbf k_j}(\mathbf q_i)
\right]_{i,j=1}^{N}
```

で表される．
これを置換の和で書けば，

```math
\Psi_{\mathbf k_1,\ldots,\mathbf k_N}(\mathbf Q)
=
\frac{1}{\sqrt{N!V^N}}
\sum_P(-1)^P
\exp\!\left(
i\sum_{j=1}^{N}
\mathbf k_j\cdot\mathbf q_{P(j)}
\right)
```

となる．
ここで $P$ は $N$ 個の粒子番号の置換を表し， $(-1)^P$ は偶置換なら $+1$ ，奇置換なら $-1$ である．

粒子数が一定の正準集団では，規格化前の密度行列はエネルギー固有状態の和として

```math
\rho_N^{(0)}(\mathbf Q,\mathbf Q')
=
\sum_{\{\mathbf k_1,\ldots,\mathbf k_N\}}
e^{-\beta\sum_{j=1}^{N}\epsilon_{\mathbf k_j}}
\Psi_{\mathbf k_1,\ldots,\mathbf k_N}(\mathbf Q)
\Psi_{\mathbf k_1,\ldots,\mathbf k_N}^{*}(\mathbf Q')
```

と書ける．
ここで和は，異なる 1 粒子状態を占める状態の組について取る．

この式に反対称化された波動関数を代入し，波数ベクトルの和をまとめると，1 粒子の熱核

```math
K_\beta(\mathbf q,\mathbf q')
=
\sum_{\mathbf k}
e^{-\beta\epsilon_{\mathbf k}}
\varphi_{\mathbf k}(\mathbf q)
\varphi_{\mathbf k}^{*}(\mathbf q')
```

を用いて，

```math
\boxed{
\rho_N^{(0)}(\mathbf Q,\mathbf Q')
=
\frac{1}{N!}
\sum_P(-1)^P
\prod_{i=1}^{N}
K_\beta(\mathbf q_i,\mathbf q'_{P(i)})
}
\tag{1}
```

と表せる．
ここで，重複しない状態の組についての和を，すべての順序付き波数の組についての和に置き換える際に $1/N!$ が現れる．
各波数について独立に和を取ることで，式 (1) が得られる．

行列式の展開公式

```math
\det A=\sum_P(-1)^P\prod_{i=1}^{N}A_{i,P(i)}
```

を使えば，式 (1) は

```math
\boxed{
\rho_N^{(0)}(\mathbf Q,\mathbf Q')
=
\frac{1}{N!}
\det\!\left[
K_\beta(\mathbf q_i,\mathbf q'_j)
\right]_{i,j=1}^{N}
}
\tag{2}
```

となる．
これが密度行列の $q$ 表示を求めるうえでの基本式である．

#### 3．自由粒子の 1 粒子熱核

平面波状態を用いると，熱核は

```math
K_\beta(\mathbf q,\mathbf q')
=
\frac{1}{V}
\sum_{\mathbf k}
\exp\!\left(
-\frac{\beta\hbar^2 k^2}{2m}
+i\mathbf k\cdot(\mathbf q-\mathbf q')
\right)
```

である．
系の大きさが熱的ド・ブロイ波長に比べて十分大きい場合，波数の和を積分で近似できる．
すなわち，

```math
\frac{1}{V}\sum_{\mathbf k}
\longrightarrow
\int\frac{d^3k}{(2\pi)^3}
```

と置く．
したがって，

```math
K_\beta(\mathbf q,\mathbf q')
=
\int\frac{d^3k}{(2\pi)^3}
\exp\!\left(
-\frac{\beta\hbar^2 k^2}{2m}
+i\mathbf k\cdot(\mathbf q-\mathbf q')
\right)
```

となる．

ここで，熱的ド・ブロイ波長を

```math
\lambda_T
=
\frac{h}{\sqrt{2\pi m k_{\mathrm B}T}}
=
\sqrt{\frac{2\pi\hbar^2\beta}{m}}
```

と定義する．
ガウス積分の公式

```math
\int\frac{d^3k}{(2\pi)^3}
e^{-a k^2+i\mathbf k\cdot\mathbf r}
=
\frac{1}{(4\pi a)^{3/2}}
e^{-|\mathbf r|^2/(4a)}
\qquad(a>0)
```

を用いると，

```math
K_\beta(\mathbf q,\mathbf q')
=
\left(\frac{m}{2\pi\beta\hbar^2}\right)^{3/2}
\exp\!\left(
-\frac{m|\mathbf q-\mathbf q'|^2}
{2\beta\hbar^2}
\right)
```

を得る．
熱的ド・ブロイ波長を用いて書き直せば，

```math
\boxed{
K_\beta(\mathbf q,\mathbf q')
=
\frac{1}{\lambda_T^3}
\exp\!\left(
-\frac{\pi|\mathbf q-\mathbf q'|^2}{\lambda_T^2}
\right)
}
\tag{3}
```

となる．

#### 4．密度行列の $q$ 表示

式 (3) を式 (2) に代入する．
行列式の各要素に共通する係数 $\lambda_T^{-3}$ を各行から取り出すと，

```math
\rho_N^{(0)}(\mathbf Q,\mathbf Q')
=
\frac{1}{N!\lambda_T^{3N}}
\det\!\left[
\exp\!\left(
-\frac{\pi|\mathbf q_i-\mathbf q'_j|^2}{\lambda_T^2}
\right)
\right]_{i,j=1}^{N}
```

となる．
したがって，規格化前の密度行列は

```math
\boxed{
\langle\mathbf Q|e^{-\beta H}|\mathbf Q'\rangle_{\mathrm F}
=
\frac{1}{N!\lambda_T^{3N}}
\det\!\left[
\exp\!\left(
-\frac{\pi|\mathbf q_i-\mathbf q'_j|^2}{\lambda_T^2}
\right)
\right]_{i,j=1}^{N}
}
\tag{4}
```

である．
添字 $\mathrm F$ は Fermi 粒子の反対称な状態空間での行列要素を表す．

規格化済み密度演算子を

```math
\hat\rho_N=\frac{e^{-\beta H}}{Z_N},
\qquad
Z_N=\operatorname{Tr}_{\mathrm F}(e^{-\beta H})
```

と定義すると，求める密度行列は

```math
\boxed{
\langle\mathbf Q|\hat\rho_N|\mathbf Q'\rangle
=
\frac{1}{N!Z_N\lambda_T^{3N}}
\det\!\left[
\exp\!\left(
-\frac{\pi|\mathbf q_i-\mathbf q'_j|^2}{\lambda_T^2}
\right)
\right]_{i,j=1}^{N}
}
\tag{5}
```

である．
ここで $Z_N$ は正準分配関数であり，トレースが 1 になるように密度行列を規格化するために必要である．

#### 5．正準分配関数 $Z_N$ のサイクル分解

式 (5) を具体的に定めるため，正準分配関数 $Z_N$ を求める．
式 (1) の対角成分を全粒子の位置について積分すると，

```math
Z_N
=
\frac{1}{N!}
\sum_P(-1)^P
\int_V d^3q_1\cdots d^3q_N
\prod_{i=1}^{N}K_\beta(\mathbf q_i,\mathbf q_{P(i)})
\tag{6}
```

となる．

置換 $P$ は，互いに独立な巡回置換（サイクル）の積に分解できる．
長さ $l$ のサイクルに属する粒子の座標積分を

```math
J_l
=
\int_V d^3q_1\cdots d^3q_l\,
K_\beta(\mathbf q_1,\mathbf q_2)
K_\beta(\mathbf q_2,\mathbf q_3)
\cdots
K_\beta(\mathbf q_l,\mathbf q_1)
```

と定義する．

熱核は，位置について積分するごとに熱核の時間引数が加算されるという性質を持つ．
したがって，上の積分は

```math
J_l
=
\operatorname{Tr}_1(e^{-l\beta h})
```

に等しい．
ここで $\operatorname{Tr}_1$ は 1 粒子状態についてのトレースである．
温度 $T/l$ に対応する熱的ド・ブロイ波長は $\sqrt l\,\lambda_T$ であるから，大きな体積での近似のもとでは

```math
\boxed{
J_l=\frac{V}{l^{3/2}\lambda_T^3}
}
\tag{7}
```

を得る．

次に，長さ $l$ のサイクルが $N_l$ 個ある置換を考える．
サイクルの個数は

```math
\sum_{l=1}^{N}lN_l=N
\tag{8}
```

を満たす．
長さ $l$ のサイクルは $l-1$ 個の互換の積で表されるため，その置換符号は $(-1)^{l-1}$ である．
よって，置換全体の符号は

```math
(-1)^P=\prod_{l=1}^{N}(-1)^{(l-1)N_l}
```

となる．

また，サイクルの個数が $\{N_l\}$ と定まったとき，そのサイクル型を持つ置換の個数は

```math
\frac{N!}{\displaystyle\prod_{l=1}^{N}l^{N_l}N_l!}
```

である．
式 (6) の係数 $1/N!$ と合わせると，長さ $l$ の各サイクルについて，積分 $J_l$ に加えて組合せ係数由来の $1/l$ が現れる．
したがって，

```math
Z_N
=
\sum_{\substack{N_1,\ldots,N_N\geq0\\
\sum_{l=1}^{N}lN_l=N}}
\prod_{l=1}^{N}
\frac{1}{N_l!}
\left[
\frac{(-1)^{l-1}}{l}J_l
\right]^{N_l}
```

である．
式 (7) を代入して，

```math
\boxed{
Z_N
=
\sum_{\substack{N_1,\ldots,N_N\geq0\\
\sum_{l=1}^{N}lN_l=N}}
\prod_{l=1}^{N}
\frac{1}{N_l!}
\left[
\frac{(-1)^{l-1}V}
{l^{5/2}\lambda_T^3}
\right]^{N_l}
}
\tag{9}
```

を得る．
これが大きな体積での近似における正準分配関数である．

ここで重要なのは，式 (7) のサイクル積分そのものには $l^{-3/2}$ が現れるが，式 (9) の正準分配関数では，置換の個数を数える際の $1/l$ が加わるため $l^{-5/2}$ となる点である．
また，Fermi 粒子の符号は $(-1)^{l-1}$ であり，すべてのサイクルに一律の負号が付くわけではない．

#### 6．結果の確認と結論

式 (9) を粒子数 $N$ について和を取って大分配関数 $\Xi$ にすると，

```math
\begin{aligned}
\Xi
&=\sum_{N=0}^{\infty}z^N Z_N\\
&=
\exp\!\left[
\frac{V}{\lambda_T^3}
\sum_{l=1}^{\infty}
\frac{(-1)^{l-1}z^l}{l^{5/2}}
\right],
\end{aligned}
```

ただし $z=e^{\beta\mu}$ は fugacity である．
これは，Fermi 気体の大分配関数を展開して得られる式と一致し，サイクル分解の係数と符号の整合性を確認できる．

以上より，スピンを考慮しない理想 Fermi 気体の規格化済み密度行列の $q$ 表示は，

```math
\boxed{
\langle\mathbf Q|\hat\rho_N|\mathbf Q'\rangle
=
\frac{1}{N!Z_N\lambda_T^{3N}}
\det\!\left[
\exp\!\left(
-\frac{\pi|\mathbf q_i-\mathbf q'_j|^2}{\lambda_T^2}
\right)
\right]_{i,j=1}^{N}
}
```

である．
ここで $Z_N$ は式 (9) で与えられる．
この結果における行列式と置換符号は，Fermi 粒子の反対称性を表している．
なお，熱核をガウス積分で評価した式と，サイクル積分を $J_l=V/(l^{3/2}\lambda_T^3)$ とする式は，系の大きさが熱的ド・ブロイ波長に比べて十分大きいという近似のもとで成立するものである．
