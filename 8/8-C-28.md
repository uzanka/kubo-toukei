# 演習問題【8-C-28】

## 解答

## 1. 1 粒子の熱核

スピンを無視した，相互作用のない同種フェルミ粒子 $N$ 個の系を考える．
全ハミルトニアンは

```math
H=\sum_{i=1}^{N}h_i
```

であり，自由粒子の場合は $h=\mathbf p^2/(2m)$ である．
逆温度を $\beta=1/(k_{\mathrm B}T)$ とし，非規格化密度演算子を $\rho=e^{-\beta H}$ とする．

1 粒子の熱核を

```math
K_\beta(\mathbf q,\mathbf q')
=\langle\mathbf q|e^{-\beta h}|\mathbf q'\rangle
```

と定義する．
1 粒子ハミルトニアンの固有状態 $\varphi_\alpha$ ，固有エネルギー $\epsilon_\alpha$ を用いれば，

```math
K_\beta(\mathbf q,\mathbf q')
=\sum_\alpha e^{-\beta\epsilon_\alpha}
\varphi_\alpha(\mathbf q)\varphi_\alpha^*(\mathbf q')
```

である．

## 2. Fermi 粒子の反対称性

多粒子の位置を
$\mathbf Q=(\mathbf q_1,\ldots,\mathbf q_N)$ ，
$\mathbf Q'=(\mathbf q'_1,\ldots,\mathbf q'_N)$
と書く．
Fermi 粒子の波動関数は粒子交換に対して反対称であり，反対称化された状態は Slater 行列式で表される．

その結果，密度行列の位置表示は 1 粒子熱核を要素とする行列式で与えられる：

```math
\boxed{
\langle\mathbf Q|e^{-\beta H}|\mathbf Q'\rangle
=\frac{1}{N!}\det\left[
K_\beta(\mathbf q_i,\mathbf q'_j)
\right]_{i,j=1}^{N}
}
```

行列式を置換の和として書くと，

```math
\langle\mathbf Q|e^{-\beta H}|\mathbf Q'\rangle
=\frac{1}{N!}\sum_P(-1)^P
\prod_{i=1}^{N}K_\beta(\mathbf q_i,\mathbf q'_{P(i)})
```

となる．
この公式の根拠は以下のとおりである．
非相互作用系では $e^{-\beta H}=\prod_i e^{-\beta h_i}$ であり，
各粒子の波動関数が Slater 行列式で表されることから，密度行列も反対称化され，
1 粒子熱核を要素とする行列式に帰着する．
ここで $P$ は全ての粒子置換， $(-1)^P$ は置換の符号である．
この符号が Fermi 粒子の反対称性を表す．

## 3. 一様な自由 Fermi 気体

自由粒子では $h=\mathbf p^2/(2m)$ である．
無限体積極限では，1 粒子熱核は

```math
\begin{aligned}
K_\beta(\mathbf q,\mathbf q')
&=\int\frac{d^3k}{(2\pi)^3}
\exp\left[-\beta\frac{\hbar^2k^2}{2m}
+i\mathbf k\cdot(\mathbf q-\mathbf q')\right]\\
&=\left(\frac{m}{2\pi\beta\hbar^2}\right)^{3/2}
\exp\left[-\frac{m|\mathbf q-\mathbf q'|^2}{2\beta\hbar^2}\right].
\end{aligned}
```

これを行列式の式に代入すると，

```math
\boxed{
\begin{aligned}
&\langle\mathbf Q|e^{-\beta H}|\mathbf Q'\rangle\\
&=\frac{1}{N!}
\det\left[
\left(\frac{m}{2\pi\beta\hbar^2}\right)^{3/2}
\exp\left(-\frac{m|\mathbf q_i-\mathbf q'_j|^2}
{2\beta\hbar^2}\right)
\right]_{i,j=1}^{N}.
\end{aligned}
}
```

各要素に共通する係数を行列式の外に出せば，

```math
\boxed{
\begin{aligned}
&\langle\mathbf Q|e^{-\beta H}|\mathbf Q'\rangle\\
&=\frac{1}{N!}
\left(\frac{m}{2\pi\beta\hbar^2}\right)^{3N/2}
\det\left[
\exp\left(-\frac{m|\mathbf q_i-\mathbf q'_j|^2}
{2\beta\hbar^2}\right)
\right]_{i,j=1}^{N}.
\end{aligned}
}
```

熱的 de Broglie 波長

```math
\lambda_T=\sqrt{\frac{2\pi\hbar^2\beta}{m}}
=\frac{h}{\sqrt{2\pi m k_{\mathrm B}T}}
```

を導入すると，

```math
\boxed{
\langle\mathbf Q|e^{-\beta H}|\mathbf Q'\rangle
=\frac{1}{N!\lambda_T^{3N}}
\det\left[
\exp\left(-\frac{\pi|\mathbf q_i-\mathbf q'_j|^2}{\lambda_T^2}\right)
\right]_{i,j=1}^{N}
}
```

とも表せる．

## 4. 規格化と最終解答

問題文の $\rho=e^{-\beta H}$ は一般にはトレースが 1 ではない．
規格化された密度演算子は

```math
\hat{\rho}=\frac{e^{-\beta H}}{Z_N}, \qquad
Z_N=\operatorname{Tr}_{\mathrm{F}} \left( e^{-\beta H} \right)
```

と定義され， $\operatorname{Tr} \left( \hat{\rho} \right) = 1$ を満たす．
したがって，

```math
\boxed{
\langle\mathbf Q|\hat\rho|\mathbf Q'\rangle
=\frac{1}{Z_N}\,
\langle\mathbf Q|e^{-\beta H}|\mathbf Q'\rangle
}
```

となる．$Z_N$ は反対称な $N$ 粒子状態にわたる正準分配関数である．
密度行列を $e^{-\beta H}$ そのものと定義する文献も存在するが，本解答では物理的に標準的な規格化済み $\hat\rho$ を最終解答とする．

## 4.1 正準分配関数 $Z_N$ の評価（サイクル分解）

規格化因子 $Z_N=\operatorname{Tr}_{\mathrm{F}} \left(e^{-\beta H} \right)$ を，置換のサイクル分解によって明示的に求める．

密度行列の対角成分 $\langle\mathbf Q|e^{-\beta H}|\mathbf Q\rangle$ を各粒子座標について積分すればトレースが得られる：

```math
Z_N = \frac{1}{N!}\sum_Q (-1)^Q
\int_V d\mathbf q_1\cdots d\mathbf q_N\,
\prod_{i=1}^N K_\beta(\mathbf q_i,\mathbf q'_{Q(i)})\Big|_{\mathbf q'=\mathbf q}
```

各粒子座標について積分する．置換 $Q$ を巡回置換（サイクル）に分解する．
長さ $l$ の要素から成る各サイクルは，$l$ 粒子の Gauss 積分（たたみ込み）として評価され，その寄与は

```math
J_l = \frac{V}{\lambda_T^3\, l^{3/2}} \qquad (V \gg \lambda_T^3)
```

である．
符号因子も重要で，Fermi 粒子の反対称性から来る：長さ $l$ の巡回置換は $l-1$ 個の互いに素な置換の積で書けるから，

```math
(-1)^Q = \prod_{l=1}^N (-1)^{(l-1)N_l}
```

ここで $N_l$ は長さ $l$ のサイクルの数であり， $\sum_l l N_l=N$ を満たす．

同じサイクル型 $\{N_l\}$ を与える置換 $Q$ の組合せの数は， $N$ 個の要素を大きさ $l$ のグループに分割する方法の数に等しい：

```math
\frac{N!}{\prod_{l=1}^N l^{N_l}\, N_l!}
```

これを合わせると，$Z_N$ は $\sum_l l N_l = N$ のもとで

```math
Z_N = \sum_{\{N_l\}}^{\sum_l l N_l=N}
\prod_{l=1}^N \frac{1}{N_l!}
\left(-\frac{V}{l^{3/2}\lambda_T^3}\right)^{N_l}
```

と書かれる．
この結果は，解答例の式(7)〜(12)と同じサイクル分解による．
指数に現れる $l^{3/2}$ は，Gauss 積分が $l$ 回たたみ込まれたことに由来する（解答例の式(13)では $l^{5/2}$ と誤植されている）．

この結果は Bose 気体にも応用可能で，その場合は Fermi 粒子の場合と異なり符号因子がなく，

```math
Z_N^{\mathrm{Bose}} = \sum_{\{N_l\}}^{\sum_l l N_l=N}
\prod_{l=1}^N \frac{1}{N_l!}
\left(\frac{V}{l^{3/2}\lambda_T^3}\right)^{N_l}
```

となる．
読者はこれを式(6)で $(-1)^Q$ を入れないことから自ら確かめられたい．

## 結論

スピンを無視した理想 Fermi 気体の密度行列は，1 粒子熱核を要素とする行列式

```math
\boxed{
\langle\mathbf Q|\hat\rho|\mathbf Q'\rangle
=\frac{1}{Z_N}\,
\frac{1}{N!}\det\left[
K_\beta(\mathbf q_i,\mathbf q'_j)
\right]_{i,j=1}^{N}
}
```

で表される．
ここで正準分配関数 $Z_N$ はサイクル分解により

```math
Z_N = \sum_{\{N_l\}}^{\sum_l l N_l=N}
\prod_{l=1}^N \frac{1}{N_l!}
\left(-\frac{V}{l^{3/2}\lambda_T^3}\right)^{N_l}
```

と明示的に評価される．
自由粒子の場合，1 粒子熱核はガウス関数となるため，上記の具体式が得られる．
行列式の置換項に付く符号 $(-1)^P$ が，Fermi 粒子の反対称性を反映している．
