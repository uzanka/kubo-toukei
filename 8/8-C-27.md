# 演習問題【8-C-27】

## 解答

### 縮退が弱い理想量子気体のビリアル展開

#### 1．基本的な考え方

考えるのは，三次元空間を運動する非相対論的な理想量子気体である．
粒子数を $N$ ，体積を $V$ ，温度を $T$ ，圧力を $P$ ，化学ポテンシャルを $\mu$ とする．
また， $g$ は運動量状態一つ当たりの内部自由度の重率であり，例えばスピンの縮退度を表す．

**縮退が弱い場合** とは，粒子密度が低い，または温度が高く，量子統計による補正が小さい場合である．
この条件は fugacity（フガシティ）

```math
z=e^{\beta\mu},\qquad
\beta=\frac{1}{k_BT}
```

を用いると，

```math
z\ll1
```

と表される．
ここで $k_B$ は Boltzmann 定数である．
Bose 気体では $\mu\leq0$ であり，弱縮退の場合には $\mu/(k_BT)\ll-1$ となる．
Fermi 気体でも弱縮退の場合には同じく $z\ll1$ である．

この条件のもとで $z$ のべき級数を用いれば，古典理想気体の状態方程式に対する量子統計的な補正を求めることができる．
これが本問題で求めるビリアル展開である．

#### 2．大分配関数の展開

大分配関数は

```math
\Xi=\prod_l
\left(1\mp e^{\beta(\mu-\epsilon_l)}\right)^{\mp1}
```

で与えられる．
ここで $\epsilon_l$ は一粒子状態 $l$ のエネルギーであり，複号の上が Bose 気体，下が Fermi 気体を表す．

以下では符号を簡潔に扱うため，

```math
s=
\begin{cases}
+1 & \text{Bose 気体},\\
-1 & \text{Fermi 気体}
\end{cases}
```

と定義する．

大正準統計力学では，圧力と平均粒子数はそれぞれ

```math
PV=k_BT\ln\Xi,
\qquad
N=k_BT\frac{\partial\ln\Xi}{\partial\mu}
```

で与えられる．

$\ln(1-y)=-\sum_{\ell=1}^{\infty}y^\ell/\ell$ および $\ln(1+y)=\sum_{\ell=1}^{\infty}(-1)^{\ell-1}y^\ell/\ell$ を用い， $z\ll1$ として展開すると，

```math
\ln\Xi
=
\sum_{\ell=1}^{\infty}
\frac{s^{\ell-1}z^\ell}{\ell}
C_\ell
```

を得る．
ただし，

```math
C_\ell=\sum_l e^{-\ell\beta\epsilon_l}
```

とおいた．
したがって，

```math
PV=k_BT
\sum_{\ell=1}^{\infty}
\frac{s^{\ell-1}z^\ell}{\ell}C_\ell
\tag{1}
```

である．

一方，粒子数については $z=e^{\beta\mu}$ より

```math
N=z\frac{\partial\ln\Xi}{\partial z}
```

であるから，

```math
N=\sum_{\ell=1}^{\infty}
s^{\ell-1}z^\ell C_\ell
\tag{2}
```

となる．

#### 3．$C_\ell$ の計算

一粒子エネルギーが $\epsilon=p^2/(2m)$ で与えられる三次元自由粒子を考える．
熱的ド・ブロイ波長を

```math
\lambda_T=\frac{h}{\sqrt{2\pi mk_BT}}
=\sqrt{\frac{2\pi\hbar^2}{mk_BT}}
```

と定義する．
ここで $h$ は Planck 定数， $\hbar=h/(2\pi)$ ， $m$ は粒子の質量である．

熱力学極限では，一粒子状態の和を状態密度を用いた積分で近似できる．
内部自由度の重率 $g$ を含めた三次元自由粒子の状態密度は

```math
D(\epsilon)=
\frac{gV}{4\pi^2}
\left(\frac{2m}{\hbar^2}\right)^{3/2}
\epsilon^{1/2}
```

である．
よって，

```math
C_\ell=
\int_0^\infty D(\epsilon)e^{-\ell\beta\epsilon}\,d\epsilon
```

となる．
ここで

```math
\int_0^\infty
\epsilon^{1/2}e^{-a\epsilon}\,d\epsilon
=\frac{\sqrt{\pi}}{2a^{3/2}}
\qquad(a>0)
```

を用いると，

```math
C_\ell=
\frac{gV}{\lambda_T^3}
\frac{1}{\ell^{3/2}}
\tag{3}
```

を得る．

式 (3) を式 (1)，(2) に代入すれば，

```math
PV=
\frac{gVk_BT}{\lambda_T^3}
\sum_{\ell=1}^{\infty}
\frac{s^{\ell-1}z^\ell}{\ell^{5/2}}
\tag{4}
```

および

```math
N=
\frac{gV}{\lambda_T^3}
\sum_{\ell=1}^{\infty}
\frac{s^{\ell-1}z^\ell}{\ell^{3/2}}
\tag{5}
```

が得られる．

#### 4．fugacity を粒子密度のべき級数として求める

粒子数密度を

```math
\rho=\frac{N}{V}
```

とし，無次元の縮退パラメータ

```math
x=\frac{\rho\lambda_T^3}{g}
=\frac{N\lambda_T^3}{gV}
```

を導入する．
弱縮退条件は $x\ll1$ である．
式 (5) は

```math
x=z+\frac{s}{2^{3/2}}z^2
+\frac{1}{3^{3/2}}z^3+O(z^4)
\tag{6}
```

となる．
ここで $O(z^4)$ は四次以上の項を表す．

$z$ を $x$ のべき級数

```math
z=a_1x+a_2x^2+a_3x^3+O(x^4)
```

とおき，式 (6) に代入して係数を比較する．

一次の項を比較すると，

```math
a_1=1
```

である．
二次の項を比較すると，

```math
a_2+\frac{s}{2^{3/2}}a_1^2=0
```

となるので，

```math
a_2=-\frac{s}{2^{3/2}}
```

を得る．
さらに三次の項を比較すると，

```math
a_3+\frac{s}{2^{3/2}}\,2a_1a_2
+\frac{a_1^3}{3^{3/2}}=0
```

である．
$a_1=1$ および $a_2=-s/2^{3/2}$ を代入すれば，

```math
a_3-\frac14+\frac{1}{3^{3/2}}=0
```

となる．
したがって，

```math
a_3=\frac14-\frac{1}{3^{3/2}}
```

である．
以上から，

```math
\boxed{
z=x-\frac{s}{2^{3/2}}x^2
+\left(\frac14-\frac{1}{3^{3/2}}\right)x^3
+O(x^4)
}
\tag{7}
```

を得る．

#### 5．圧力のビリアル展開

式 (4) を書き直すと，

```math
PV=\frac{gVk_BT}{\lambda_T^3}
\left(
z+\frac{s}{2^{5/2}}z^2
+\frac{1}{3^{5/2}}z^3+O(z^4)
\right)
\tag{8}
```

である．
式 (7) を式 (8) に代入し， $x$ のべきで整理する．
このとき $N=gVx/\lambda_T^3$ を用いると，

```math
\boxed{
PV=Nk_BT
\left[
1-\frac{s}{2^{5/2}}x
+\left(\frac18-\frac{2}{3^{5/2}}\right)x^2
+O(x^3)
\right]
}
```

を得る．
したがって，粒子数密度 $\rho=N/V$ を用いたビリアル展開は，

```math
\boxed{
P=\rho k_BT
\left[
1-\frac{s}{2^{5/2}}
\frac{\rho\lambda_T^3}{g}
+\left(\frac18-\frac{2}{3^{5/2}}\right)
\left(\frac{\rho\lambda_T^3}{g}\right)^2
+O\!\left(
\left(\frac{\rho\lambda_T^3}{g}\right)^3
\right)
\right]
}
\tag{9}
```

である．

Bose 気体では $s=+1$ ，Fermi 気体では $s=-1$ であるため，それぞれ

```math
\boxed{
P_{\mathrm B}=\rho k_BT
\left[
1-\frac{1}{2^{5/2}}\frac{\rho\lambda_T^3}{g}
+\left(\frac18-\frac{2}{3^{5/2}}\right)
\left(\frac{\rho\lambda_T^3}{g}\right)^2
+\cdots
\right]
}
```

および

```math
\boxed{
P_{\mathrm F}=\rho k_BT
\left[
1+\frac{1}{2^{5/2}}\frac{\rho\lambda_T^3}{g}
+\left(\frac18-\frac{2}{3^{5/2}}\right)
\left(\frac{\rho\lambda_T^3}{g}\right)^2
+\cdots
\right]
}
```

となる．
これが求めるビリアル展開の初めの項である．

#### 6．結果の物理的意味

最初の項 $P=\rho k_BT$ は古典理想気体の状態方程式である．
その次の項は量子統計による最初の補正であり，Bose 気体では負，Fermi 気体では正となる．
したがって，同じ温度と粒子数密度では，Bose 気体の圧力は古典理想気体より低く，Fermi 気体の圧力は高くなる．
これは粒子の統計性に由来する効果であり，実際の粒子間相互作用による引力や斥力を仮定したものではない．

なお，この展開は $x=\rho\lambda_T^3/g\ll1$ の場合に有効である．
密度が高い場合や温度が低い場合には高次の項が無視できなくなり，この低次のビリアル展開だけでは圧力を十分な精度で表せないことがある．
