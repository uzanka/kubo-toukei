# 演習問題【8-A-15】

## 解答

二次元の面積 $A=L_xL_y$ の領域に閉じ込められた，質量 $m$ の理想 Bose 気体を考える．
Bose–Einstein 凝縮が起こらないことを示すには，任意の有限な粒子密度に対して，励起状態だけで粒子を収容できることを示せばよい．

### 1．Bose–Einstein 分布と粒子数

二次元の自由粒子のエネルギー準位は，

```math
\epsilon_{\boldsymbol{k}}
=\frac{\hbar^2(k_x^2+k_y^2)}{2m}
=\frac{\hbar^2 k^2}{2m}
```

で与えられる．
ここで， $k=|\boldsymbol{k}|$ であり， $\hbar$ は換算プランク定数である．
基底状態は $k=0$ ，すなわち $\epsilon=0$ の状態である．

温度を $T$ ，ボルツマン定数を $k_{\mathrm B}$ ，化学ポテンシャルを $\mu$ とする．
Bose–Einstein 統計によれば，エネルギー $\epsilon_{\boldsymbol{k}}$ の状態の平均占有数は

```math
\overline{n}_{\boldsymbol{k}}
=\frac{1}{e^{(\epsilon_{\boldsymbol{k}}-\mu)/(k_{\mathrm B}T)}-1}
```

である．
基底状態のエネルギーを $0$ としているため，有限温度では化学ポテンシャルは $\mu\leq0$ を満たす．

基底状態以外の状態に存在する粒子の総数を $N_{\mathrm{ex}}$ とすると，

```math
N_{\mathrm{ex}}
=\sum_{\boldsymbol{k}\neq0}
\frac{1}{e^{(\epsilon_{\boldsymbol{k}}-\mu)/(k_{\mathrm B}T)}-1}
\tag{1}
```

となる．
ここでは，基底状態の占有数を分離し，励起状態に収容できる粒子数を調べる．

### 2．波数空間の和を積分に置き換える

系の面積 $A=L_xL_y$ が十分に大きい熱力学極限では，波数空間の状態は密になる．
このとき，状態の和は積分によって近似できる．
二次元の波数空間では，単位面積当たりの状態数に対応する係数は $A/(2\pi)^2$ である．
したがって，式(1)は

```math
N_{\mathrm{ex}}
\simeq
\frac{A}{(2\pi)^2}
\int
\frac{dk_x\,dk_y}
{e^{(\hbar^2k^2/(2m)-\mu)/(k_{\mathrm B}T)}-1}
\tag{2}
```

と表される．

被積分関数は $k=|\boldsymbol{k}|$ のみに依存するため，波数空間で極座標を用いると，角度方向の積分は $2\pi$ となる．
よって，

```math
N_{\mathrm{ex}}
\simeq
\frac{A}{2\pi}
\int_0^\infty
\frac{k\,dk}
{e^{(\hbar^2k^2/(2m)-\mu)/(k_{\mathrm B}T)}-1}
\tag{3}
```

を得る．

ここで，粒子のエネルギーを

```math
\epsilon=\frac{\hbar^2k^2}{2m}
```

と変数変換する．
微分すると，

```math
d\epsilon=\frac{\hbar^2k}{m}\,dk
```

であるから，

```math
k\,dk=\frac{m}{\hbar^2}\,d\epsilon
```

となる．
式(3)に代入すれば，

```math
N_{\mathrm{ex}}
\simeq
\frac{Am}{2\pi\hbar^2}
\int_0^\infty
\frac{d\epsilon}
{e^{(\epsilon-\mu)/(k_{\mathrm B}T)}-1}
\tag{4}
```

が得られる．
このように，二次元ではエネルギーに対する状態密度が一定となることが分かる．

### 3．級数展開による粒子数の計算

化学ポテンシャルが $\mu<0$ であるとき，

```math
e^{(\epsilon-\mu)/(k_{\mathrm B}T)}>1
```

である．
したがって，等比級数の公式

```math
\frac{1}{e^x-1}
=\sum_{l=1}^{\infty}e^{-lx}
\qquad (x>0)
```

を利用できる．
式(4)の被積分関数を展開すると，

```math
\begin{aligned}
N_{\mathrm{ex}}
&\simeq
\frac{Am}{2\pi\hbar^2}
\int_0^\infty
\sum_{l=1}^{\infty}
e^{-l(\epsilon-\mu)/(k_{\mathrm B}T)}
\,d\epsilon\\[4pt]
&=
\frac{Am}{2\pi\hbar^2}
\sum_{l=1}^{\infty}
e^{l\mu/(k_{\mathrm B}T)}
\int_0^\infty
e^{-l\epsilon/(k_{\mathrm B}T)}
\,d\epsilon
\end{aligned}
```

となる．
各項の積分は，

```math
\begin{aligned}
\int_0^\infty
e^{-l\epsilon/(k_{\mathrm B}T)}\,d\epsilon
&=
\left[
-\frac{k_{\mathrm B}T}{l}
e^{-l\epsilon/(k_{\mathrm B}T)}
\right]_0^\infty\\[4pt]
&=\frac{k_{\mathrm B}T}{l}
\end{aligned}
```

である．
よって，

```math
\boxed{
N_{\mathrm{ex}}
\simeq
\frac{Amk_{\mathrm B}T}{2\pi\hbar^2}
\sum_{l=1}^{\infty}
\frac{1}{l}e^{l\mu/(k_{\mathrm B}T)}
}
\tag{5}
```

を得る．

ここで，

```math
z=e^{\mu/(k_{\mathrm B}T)}
```

とおく．
$z$ はフガシティと呼ばれる量であり， $\mu<0$ であれば $0<z<1$ である．
また，級数の公式

```math
\sum_{l=1}^{\infty}\frac{z^l}{l}
=-\ln(1-z)
\qquad (0<z<1)
```

を用いると，式(5)は

```math
\boxed{
N_{\mathrm{ex}}
\simeq
-\frac{Amk_{\mathrm B}T}{2\pi\hbar^2}
\ln\left(1-e^{\mu/(k_{\mathrm B}T)}\right)
}
\tag{6}
```

となる．

### 4．二次元では励起状態の収容可能な粒子数に上限がない

式(6)の右辺が化学ポテンシャル $\mu$ によってどのように変化するかを考える．

まず， $\mu\to-\infty$ とすると，

```math
e^{\mu/(k_{\mathrm B}T)}\to0
```

であるため，

```math
N_{\mathrm{ex}}\to0
```

となる．
一方， $\mu\to0^-$ とすると，

```math
e^{\mu/(k_{\mathrm B}T)}\to1
```

であるから，

```math
\ln\left(1-e^{\mu/(k_{\mathrm B}T)}\right)
\to-\infty
```

となる．
したがって，

```math
\boxed{
\lim_{\mu\to0^-}N_{\mathrm{ex}}=\infty
}
\tag{7}
```

である．

つまり，化学ポテンシャルを $0$ に近づけると，励起状態に収容できる粒子数は際限なく増加する．
三次元の理想 Bose 気体では，有限温度において励起状態の粒子数に有限の最大値があるのに対し，二次元ではその最大値が存在しない．

このことを粒子密度からも確認する．
粒子密度を

```math
n=\frac{N}{A}
```

とする．
熱力学極限では，巨視的な数の粒子が基底状態に集まらない場合，粒子密度は励起状態の粒子密度で与えられる．
式(6)から，

```math
n
=-\frac{mk_{\mathrm B}T}{2\pi\hbar^2}
\ln\left(1-e^{\mu/(k_{\mathrm B}T)}\right)
```

となる．
これを $\mu$ について解くと，

```math
e^{\mu/(k_{\mathrm B}T)}
=1-\exp\left(-\frac{2\pi\hbar^2n}{mk_{\mathrm B}T}\right)
```

であるから，

```math
\boxed{
\mu
=k_{\mathrm B}T
\ln\left[
1-\exp\left(-\frac{2\pi\hbar^2n}{mk_{\mathrm B}T}\right)
\right]
}
\tag{8}
```

を得る．

$n$ と $T$ が任意の正の有限値であれば，角括弧内の値は $0$ と $1$ の間にある．
したがって，

```math
\boxed{
\mu<0
}
```

であり，任意の有限な粒子密度に対して，化学ポテンシャルは $0$ より小さい値に定まる．
ゆえに，どのような有限密度であっても，励起状態に粒子を収容することが可能である．

### 5．基底状態に巨視的な数の粒子は凝縮しない

最後に，基底状態の平均占有数 $N_0$ を考える．
基底状態のエネルギーは $\epsilon_0=0$ であるため，Bose–Einstein 分布から，

```math
N_0=\frac{1}{e^{-\mu/(k_{\mathrm B}T)}-1}
```

となる．
式(8)によれば，有限の $n$ と $T$ に対して $\mu<0$ であるため， $N_0$ は有限の値となる．

一方，面積 $A$ を大きくし，粒子密度 $n=N/A$ を一定に保つ熱力学極限では，総粒子数 $N=nA$ は $A$ に比例して増加する．
これに対して，基底状態の占有数 $N_0$ は， $n$ と $T$ を一定に保つ限り，面積に比例して増加しない．
したがって，

```math
\boxed{
\lim_{A\to\infty}\frac{N_0}{N}=0
}
```

である．
すなわち，基底状態を占める粒子の割合は，熱力学極限でゼロとなる．

### 結論

二次元の理想 Bose 気体では，化学ポテンシャルを $0$ に近づけると，励起状態の粒子数が無限大に発散する．
そのため，有限温度において任意の有限な粒子密度を励起状態だけで収容することができ，基底状態に巨視的な数の粒子が凝縮する必要がない．

したがって， **二次元の一様な理想 Bose 気体は，有限温度の熱力学極限において Bose–Einstein 凝縮を起こさない** ．
