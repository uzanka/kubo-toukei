# 演習問題【8-B-20】

## 解答

本問題では，ドナー密度 $N_D=10^{15}\ \mathrm{cm}^{-3}$ ，アクセプター密度 $N_A=10^{14}\ \mathrm{cm}^{-3}$ の Ge 半導体について，フェルミ準位 $\mu$ が温度 $T$ によってどのように変化するかを考える．

温度依存性を理解するには，低温でのドナー準位の占有状態，ドナーから伝導帯への電子の熱励起，さらに高温での真性キャリアの生成を順に考える必要がある．

### 1．エネルギー準位と絶対零度でのフェルミ準位

エネルギーの原点はバンドギャップの中央に設定されている．
図より，伝導帯の底と価電子帯の頂上はそれぞれ，

```math
E_C\simeq+0.36\ \mathrm{eV},
\qquad
E_V\simeq-0.36\ \mathrm{eV}
```

である．
したがって，バンドギャップは約 $0.72\ \mathrm{eV}$ である．

ドナー準位と伝導帯下端との差は $E_D=0.04\ \mathrm{eV}$ であるから，ドナー準位そのもののエネルギーを $E_d$ とすると，

```math
E_d=E_C-E_D
=0.36-0.04
=0.32\ \mathrm{eV}
```

となる．

絶対零度では，電子はできるだけエネルギーの低い状態を占有する．
アクセプターはドナーから電子を受け取るため， $N_A$ 個のアクセプターが電子で満たされると，その分だけドナーが電子を失って正に帯電する．
ドナーの方が多いため，残りの $N_D-N_A$ 個の電子はドナー準位に保持される．

したがって，ドナー準位は部分的に占有され，フェルミ準位はそのエネルギーに一致する．
よって，

```math
\boxed{\mu(0)\simeq E_d=0.32\ \mathrm{eV}}
\tag{1}
```

となる．

### 2．伝導帯の電子密度とドナーの占有率

温度が上昇すると，ドナー準位の電子が熱エネルギーを得て伝導帯へ移るようになる．
その程度を計算するため，まず伝導帯の電子密度を求める．

電子が縮退していないとき，フェルミ・ディラック分布は Boltzmann 分布で近似できる．
したがって，伝導帯の電子密度 \(n\) は，

```math
n=N_C(T)\exp\left(\frac{\mu-E_C}{kT}\right)
\tag{2}
```

となる．
ここで， $k$ はボルツマン定数であり， $N_C(T)$ は伝導帯の実効状態密度である．
スピンの重率を含めると，

```math
N_C(T)=2\left(\frac{2\pi m_c^*kT}{h^2}\right)^{3/2}
```

である．
ここで $h$ はプランク定数， $m_c^*=0.4m$ は伝導帯の実効質量である．
この問題の単純なバンド近似では，

```math
\boxed{
N_C(T)\simeq
1.22\times10^{15}T^{3/2}\ \mathrm{cm}^{-3}
}
\tag{3}
```

となる．
ここで $T$ は絶対温度を表す．

次に，ドナーの占有率を考える．
ドナーに電子が収容されている状態にはスピンの重率 $2$ があるため，中性ドナーの密度 $N_D^0$ は，

```math
N_D^0=
\frac{2N_D e^{(\mu-E_d)/(kT)}}
{1+2e^{(\mu-E_d)/(kT)}}
\tag{4}
```

と表される．
一方，電子を失って正に帯電したドナーの密度は，

```math
N_D^+=N_D-N_D^0
```

である．

低温から外因性領域では，価電子帯からの熱励起はまだ小さく，空孔密度 $p$ は $p\simeq0$ と近似できる．
また，アクセプターはほぼすべて電子を受け取って負に帯電しているので， $N_A^-\simeq N_A$ とする．
このとき電荷中性条件

```math
n+N_A^-=p+N_D^+
```

は，

```math
\boxed{n+N_D^0\simeq N_D-N_A}
\tag{5}
```

となる．
式(5)は，伝導帯に励起された電子と，中性ドナーに残っている電子の総数が，ドナーとアクセプターの密度差に等しいことを意味する．

### 3．低温領域におけるフェルミ準位

低温では，伝導帯へ励起される電子の密度 $n$ はまだ小さく，

```math
n\ll N_D-N_A
```

である．
この場合，式(5)より，

```math
N_D^0\simeq N_D-N_A
\tag{6}
```

となる．
式(4)を式(6)に代入すると，

```math
\frac{2N_D e^{(\mu-E_d)/(kT)}}
{1+2e^{(\mu-E_d)/(kT)}}
\simeq N_D-N_A
```

である．
両辺を整理すれば，

```math
2N_A e^{(\mu-E_d)/(kT)}
\simeq N_D-N_A
```

となる．
したがって，

```math
\boxed{
\mu\simeq E_d+
kT\ln\left(\frac{N_D-N_A}{2N_A}\right)
}
\tag{7}
```

を得る．

与えられた濃度を代入すると，

```math
\frac{N_D-N_A}{2N_A}=4.5
```

であるから，

```math
\mu\simeq0.32\ \mathrm{eV}+kT\ln4.5
```

となる．
ここで $\ln4.5>0$ であるため，温度が上昇すると，フェルミ準位はドナー準位からいったん上昇する．
ただし，これは $n\ll N_D-N_A$ が成立する低温での近似であり，伝導帯の電子密度が無視できなくなると，この式は成立しなくなる．

### 4．中間温度領域における極大と下降

温度が上がると，ドナー準位から伝導帯への電子の熱励起が増加する．
式(5)において，伝導帯の電子密度 $n$ が無視できなくなると，中性ドナーの密度 $N_D^0$ は減少し始める．

この領域でのフェルミ準位を求めるため，

```math
x=\exp\left(\frac{\mu-E_C}{kT}\right),
\qquad
\Delta_D=E_C-E_d=0.04\ \mathrm{eV}
```

とおく．
すると，

```math
n=N_Cx
```

であり，式(4)は，

```math
N_D^0=
\frac{2N_Dx}
{e^{-\Delta_D/(kT)}+2x}
```

と書き換えられる．
これを式(5)に代入すると，

```math
\boxed{
N_Cx+
\frac{2N_Dx}
{e^{-\Delta_D/(kT)}+2x}
=N_D-N_A
}
\tag{8}
```

となる．
この式を $x$ について解けば，

```math
\boxed{
\mu=E_C+kT\ln x
}
\tag{9}
```

からフェルミ準位を求められる．

低温では式(7)に従って $\mu$ は上昇するが，温度が高くなるにつれて $N_C$ が $T^{3/2}$ に比例して増加し，伝導帯の電子密度も増える．
その結果，フェルミ準位は極大値をとった後に下降する．
与えられたパラメータを用いた単純なモデルでは，極大は数十 K 程度，およそ $40\ \mathrm{K}$ 付近で現れ，さらに温度が上がるとドナーのイオン化が進む．
このイオン化への移行が顕著になる温度は，概算で数十 K から $80\ \mathrm{K}$ 程度である．

ドナーがほぼ完全にイオン化した後で，空孔がまだ少ない温度領域では，

```math
N_D^0\simeq0,
\qquad
n\simeq N_D-N_A=9\times10^{14}\ \mathrm{cm}^{-3}
```

と近似できる．
式(2)より，

```math
\boxed{
\mu\simeq E_C+
kT\ln\left(\frac{N_D-N_A}{N_C(T)}\right)
}
\tag{10}
```

となる．
ここで $N_C(T)\propto T^{3/2}$ であり， $N_C$ はドーピング濃度よりずっと大きいため，温度が上昇すると $\mu$ は低下する．
これが図における極大以降の下降部分に対応する．

### 5．高温領域と真性半導体への移行

さらに温度が上がると，価電子帯の電子が伝導帯へ熱励起されるようになり，伝導帯の電子と価電子帯の空孔が対となって生成される．
このとき，伝導帯の電子密度 $n$ と空孔密度 $p$ はともに増加する．

ドナーとアクセプターの濃度差は，

```math
N_D-N_A=9\times10^{14}\ \mathrm{cm}^{-3}
```

である．
真性キャリア密度 $n_i$ がこの値に匹敵すると，ドナーから供給される電子だけではなく，価電子帯からの熱励起が重要になる．

図から読み取れるバンドギャップは約 $E_g=0.72\ \mathrm{eV}$ であり，バンドギャップ中央は $E_C\simeq0.36\ \mathrm{eV}$ である．
真性準位が中央にあると近似すると，

```math
n_i\simeq N_C(T)\exp\left(-\frac{E_g}{2kT}\right)
```

となる．
式(3)を用いると，

```math
n_i\simeq
1.22\times10^{15}T^{3/2}
\exp\left(-\frac{0.36}{kT}\right)
\ \mathrm{cm}^{-3}
\tag{11}
```

である．
$n_i$ が $9\times10^{14}\ \mathrm{cm}^{-3}$ 程度になる温度は，この単純な近似では約 $450\ \mathrm{K}$ である．
したがって，数百 K の温度領域で真性キャリアが支配的になり，フェルミ準位はバンドギャップ中央に近づく．

なお，厳密には真性準位は伝導帯と価電子帯の状態密度にも依存する．
価電子帯の状態密度を $N_V$ とすれば，

```math
\mu_i=\frac{E_C+E_V}{2}
+\frac{kT}{2}\ln\left(\frac{N_V}{N_C}\right)
```

である．
価電子帯の実効質量が指定されていないため，中央からのずれを定量的に評価することはできない．
図では簡単化して $\mu\to0$ としている．

### 結論

フェルミ準位の温度依存性は，次のように説明できる．

- **絶対零度付近** ： アクセプターがドナーから電子を受け取り，残った電子はドナー準位を占有するため， $\mu\simeq E_d=0.32\ \mathrm{eV}$ である．
- **低温の凍結領域** ： ドナーから伝導帯への励起は少ない．補償されたドナーの占有率から， $\mu\simeq E_d+kT\ln4.5$ となり，温度上昇に伴ってフェルミ準位は初めに上昇する．
- **中間温度領域** ： 伝導帯への熱励起が増加し，フェルミ準位は数十 K 付近で極大をとった後，下降する．ドナーがほぼ完全にイオン化すると， $n\simeq N_D-N_A$ となる．
- **高温領域** ： 真性キャリアの影響が強まり，約 $450\ \mathrm{K}$ 付近から真性半導体の性質が支配的になる．図の近似では，フェルミ準位はバンドギャップ中央の $\mu=0$ に近づく．

したがって，図に示されたフェルミ準位の挙動は，低温でのドナー占有率，中間温度でのドナーのイオン化，高温での真性キャリアの生成という三つの機構によって理解できる．
