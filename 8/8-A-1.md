# 演習問題【8-A-1】

## 解答

### (i) $0\,\mathrm{K}$ における Fermi ポテンシャル $\mu_0$

絶対零度 $T=0$ では，電子はエネルギーの低い状態から順に占有する．
したがって，エネルギー $\epsilon=0$ から $\epsilon=\mu_0$ までの状態が占有され，それより高いエネルギーの状態は空である．

状態密度 $D$ は単位エネルギー当たりの状態数であるため，エネルギー区間 $d\epsilon$ に含まれる状態数は $D\,d\epsilon$ である．
よって，電子の総数 $N$ は

```math
N=\int_0^{\mu_0}D\,d\epsilon=D\mu_0
```

と表される．
したがって，零温度における Fermi ポテンシャルは

```math
\boxed{
\mu_0=\frac{N}{D}
}
\tag{1}
```

である．

### (ii) 強く縮退している場合と縮退していない場合の条件

温度 $T$ において，エネルギー $\epsilon$ の状態が電子によって占有される確率は，Fermi–Dirac 分布関数

```math
f(\epsilon)=\frac{1}{e^{\beta(\epsilon-\mu)}+1}
```

で与えられる．
ここで， $\beta=1/(kT)$ であり， $k$ は Boltzmann 定数， $\mu$ は温度 $T$ における Fermi ポテンシャルである．

状態密度が一定値 $D$ であることから，電子の総数は

```math
N=D\int_0^\infty
\frac{d\epsilon}{e^{\beta(\epsilon-\mu)}+1}
\tag{2}
```

となる．
この式を用いて，縮退の条件を導く．

**1．縮退していない場合**

縮退していない場合には，各状態の占有確率が十分に小さく，Fermi–Dirac 分布を Boltzmann 分布で近似できる．
すなわち，分母において $1$ を無視できるため，

```math
e^{\beta(\epsilon-\mu)}\gg1
```

が必要である．
特に，積分範囲の下端 $\epsilon=0$ において，

```math
e^{-\beta\mu}\gg1
\tag{3}
```

が成り立たなければならない．

この近似を式 (2) に適用すると，

```math
\begin{aligned}
N
&\simeq D\int_0^\infty
e^{-\beta(\epsilon-\mu)}\,d\epsilon\\
&=De^{\beta\mu}\int_0^\infty
e^{-\beta\epsilon}\,d\epsilon\\
&=\frac{D}{\beta}e^{\beta\mu}\\
&=DkT e^{\beta\mu}
\end{aligned}
```

となる．
したがって，

```math
e^{\beta\mu}\simeq\frac{N}{DkT}
```

である．
これが式 (3) と矛盾しないためには，

```math
\frac{N}{DkT}\ll1
```

でなければならない．
よって，縮退していない場合の条件は

```math
\boxed{
N\ll DkT
}
\tag{4}
```

である．

ここで， $DkT$ はエネルギー幅 $kT$ に含まれる状態数の目安である．
したがって，この条件は，熱エネルギー $kT$ の幅に含まれる状態数が電子の総数 $N$ よりも十分に多いことを意味する．
この場合，電子は各状態に低い確率で分布するため，非縮退近似が成立する．

**2．強く縮退している場合**

一方，強く縮退している場合には，Fermi ポテンシャルが熱エネルギーより十分に大きく，

```math
\boxed{
\beta\mu\gg1
}
\qquad\text{すなわち}\qquad
\mu\gg kT
\tag{5}
```

が成り立つ．
この場合，Fermi–Dirac 分布は $\epsilon=\mu$ の近傍を除き，ほぼ階段関数の形をとる．
すなわち， $\epsilon<\mu$ では状態の占有確率はほぼ $1$ ， $\epsilon>\mu$ ではほぼ $0$ である．

式 (2) の積分を $\epsilon=\mu$ で分割すると，

```math
\begin{aligned}
N=D\biggl\{&
\int_0^\mu d\epsilon\\
&-\int_0^\mu
\frac{d\epsilon}{e^{\beta(\mu-\epsilon)}+1}\\
&+\int_\mu^\infty
\frac{d\epsilon}{e^{\beta(\epsilon-\mu)}+1}
\biggr\}
\end{aligned}
\tag{6}
```

となる．
第1項は，零温度で占有される状態数に対応する．
第2項は，温度上昇によって $\epsilon<\mu$ の領域から失われる電子数に対応し，第3項は $\epsilon>\mu$ の領域に現れる電子数に対応する．

第2項では $x=\beta(\mu-\epsilon)$ ，第3項では $x=\beta(\epsilon-\mu)$ と変数変換すると，

```math
\begin{aligned}
N=D\biggl\{&
\mu-kT\int_0^{\beta\mu}
\frac{dx}{e^x+1}\\
&+kT\int_0^\infty
\frac{dx}{e^x+1}
\biggr\}
\end{aligned}
```

を得る．
ここで， $\beta\mu\gg1$ であるため，第2項の積分上限を $\infty$ に拡張できる．
すると，第2項と第3項は互いに相殺され，

```math
N\simeq D\mu
```

となる．
したがって，

```math
\mu\simeq\frac{N}{D}=\mu_0
```

である．
これを条件 (5) に代入すると，

```math
\frac{N}{DkT}\gg1
```

を得る．
よって，強く縮退している場合の条件は

```math
\boxed{
N\gg DkT
}
\tag{7}
```

である．

以上より，縮退の条件は次のようにまとめられる．

```math
\boxed{
\begin{array}{ll}
N\ll DkT & \text{縮退していない場合}\\[4pt]
N\gg DkT & \text{強く縮退している場合}
\end{array}}
```

なお， $N\sim DkT$ では，いずれの近似も一般には十分な精度をもたない．

### (iii) 強く縮退している場合に比熱が $T$ に比例することの証明

強く縮退している場合の電子系の全エネルギー $E$ は，Fermi–Dirac 分布を用いて

```math
E=D\int_0^\infty
\frac{\epsilon\,d\epsilon}
{e^{\beta(\epsilon-\mu)}+1}
\tag{8}
```

と表される．

式 (6) と同様に積分を $\epsilon=\mu$ で分割すると，

```math
\begin{aligned}
E=D\biggl\{&
\int_0^\mu\epsilon\,d\epsilon\\
&-\int_0^\mu
\frac{\epsilon\,d\epsilon}
{e^{\beta(\mu-\epsilon)}+1}\\
&+\int_\mu^\infty
\frac{\epsilon\,d\epsilon}
{e^{\beta(\epsilon-\mu)}+1}
\biggr\}
\end{aligned}
\tag{9}
```

となる．
第1項を積分すると，

```math
\int_0^\mu\epsilon\,d\epsilon
=\frac{\mu^2}{2}
```

である．

次に，第2項では $x=\beta(\mu-\epsilon)$ ，第3項では $x=\beta(\epsilon-\mu)$ と変数変換する．
このとき，

```math
\epsilon=\mu-kTx,\qquad
d\epsilon=-kT\,dx
```

および

```math
\epsilon=\mu+kTx,\qquad
d\epsilon=kT\,dx
```

となる．
これらを式 (9) に代入すると，

```math
\begin{aligned}
E=D\biggl\{&
\frac{\mu^2}{2}
-kT\int_0^{\beta\mu}
\frac{\mu-kTx}{e^x+1}\,dx\\
&+kT\int_0^\infty
\frac{\mu+kTx}{e^x+1}\,dx
\biggr\}
\end{aligned}
\tag{10}
```

を得る．

強く縮退している場合には $\beta\mu\gg1$ であるため，第2項の積分上限を $\infty$ に拡張できる．
すると， $\mu$ に比例する項は第2項と第3項で相殺される．
一方， $x$ に比例する項は同符号で加算される．
したがって，

```math
E\simeq D\left\{
\frac{\mu^2}{2}
+2(kT)^2\int_0^\infty
\frac{x\,dx}{e^x+1}
\right\}
\tag{11}
```

となる．

ここで，積分公式

```math
\int_0^\infty\frac{x}{e^x+1}\,dx
=\frac{\pi^2}{12}
```

を用いると，

```math
\begin{aligned}
E
&\simeq D\left\{
\frac{\mu^2}{2}
+\frac{\pi^2}{6}(kT)^2
\right\}\\
&=\frac{D\mu^2}{2}
+\frac{\pi^2}{6}Dk^2T^2
\end{aligned}
\tag{12}
```

を得る．

ここで，電子の総数 $N$ は一定である．
状態密度が一定の場合，電子数の式 (2) は厳密には

```math
N=DkT\ln(1+e^{\beta\mu})
```

と積分できるため，

```math
\mu=kT\ln\left(e^{N/(DkT)}-1\right)
```

である．
したがって， $N/(DkT)\gg1$ では，

```math
\begin{aligned}
\mu
&=\frac{N}{D}
+kT\ln\left(1-e^{-N/(DkT)}\right)\\
&\simeq\frac{N}{D}=\mu_0
\end{aligned}
```

となる．
このとき， $\mu$ の温度依存性は指数関数的に小さいため，式 (12) の第1項は強く縮退した極限で温度に依存しない項として扱える．

定積比熱 $C_V$ は，粒子数一定の条件下で全エネルギーを温度で微分したものである．
したがって，

```math
\begin{aligned}
C_V
&=\left(\frac{\partial E}{\partial T}\right)_N\\
&\simeq\frac{d}{dT}
\left(\frac{\pi^2}{6}Dk^2T^2\right)\\
&=\frac{\pi^2}{3}Dk^2T
\end{aligned}
```

となる．
ゆえに，

```math
\boxed{
C_V\simeq\frac{\pi^2}{3}Dk^2T\propto T
}
```

である．
以上より，強く縮退した電子系の低温における比熱は，温度 $T$ に比例することが示された．
