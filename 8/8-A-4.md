# 演習問題【8-A-4】

## 解答

### 1．磁場中の電子のエネルギー

磁場 $\boldsymbol H$ 中にある電子は，スピン磁気モーメントの向きによってエネルギーが異なる．
問題文の規約に従うと，電子のエネルギーは

```math
\varepsilon=\frac{p^2}{2m}\pm\mu_{\mathrm B}H
\tag{1}
```

である．
ここで， $p=|\boldsymbol p|$ は電子の運動量の大きさ， $m$ は電子の質量， $\mu_{\mathrm B}$ はBohr磁子である．

以下では，スピン磁気モーメントが磁場と逆平行な状態を $+$ スピン，平行な状態を $-$ スピンとする．
したがって，それぞれのエネルギーは

```math
\varepsilon_+=\frac{p^2}{2m}+\mu_{\mathrm B}H,
\qquad
\varepsilon_-=\frac{p^2}{2m}-\mu_{\mathrm B}H
```

となる．

### 2．各スピン状態に属する電子数

絶対零度 $T=0$ では，電子はエネルギーの低い状態から順に占有し，Fermiエネルギー $\mu_0$ までの状態が満たされる．
弱い磁場を加えた場合にも，それぞれのスピン状態について，全エネルギーが $\mu_0$ 以下の状態が占有されると考える．

$ + $ スピンでは，

```math
\frac{p_+^2}{2m}+\mu_{\mathrm B}H\leq\mu_0
```

であるから，最大運動量 $p_+$ は

```math
p_+=\sqrt{2m(\mu_0-\mu_{\mathrm B}H)}
```

となる．
同様に， $-$ スピンでは，

```math
\frac{p_-^2}{2m}-\mu_{\mathrm B}H\leq\mu_0
```

より，

```math
p_-=\sqrt{2m(\mu_0+\mu_{\mathrm B}H)}
```

となる．

次に，各スピン状態に属する電子数を数える．
体積 $V$ の自由電子系では，運動量空間において体積 $h^3/V$ あたりに1つの量子状態が存在する．
ここで $h$ はPlanck定数である．
したがって，スピンの向きを1つに固定した場合，運動量の大きさが $p$ 以下の状態数は，半径 $p$ の球の体積から

```math
\begin{aligned}
N(p)
&=\frac{V}{h^3}\frac{4\pi p^3}{3}\\
&=\frac{4\pi V}{3h^3}p^3
\end{aligned}
```

となる．
ここでは，スピンの向きを1つに固定しているため，スピンの2重縮退による因子2は含まれない．

これを $p_+$ ， $p_-$ に適用すると，

```math
N_+=\frac{4\pi V}{3h^3}
\left[2m(\mu_0-\mu_{\mathrm B}H)\right]^{3/2}
\tag{2}
```

および

```math
N_-=\frac{4\pi V}{3h^3}
\left[2m(\mu_0+\mu_{\mathrm B}H)\right]^{3/2}
\tag{3}
```

を得る．

### 3．全磁気モーメントを求める

$ + $ スピンの磁気モーメントは $-\mu_{\mathrm B}$ ， $-$ スピンの磁気モーメントは $+\mu_{\mathrm B}$ である．
したがって，系全体の磁気モーメント $M$ は

```math
\begin{aligned}
M
&=-\mu_{\mathrm B}N_++\mu_{\mathrm B}N_-\\
&=\mu_{\mathrm B}(N_--N_+)
\end{aligned}
```

である．
式 (2)，(3) を代入すると，

```math
\begin{aligned}
M={}&\frac{4\pi V\mu_{\mathrm B}}{3h^3}\\
&\times\left\{
[2m(\mu_0+\mu_{\mathrm B}H)]^{3/2}
-[2m(\mu_0-\mu_{\mathrm B}H)]^{3/2}
\right\}
\end{aligned}
\tag{4}
```

となる．
磁場がないときは $N_+=N_-$ であり，系全体の磁気モーメントはゼロである．
磁場を加えると，エネルギーが低くなるスピン状態の電子数が増え，2つの状態の電子数に差が生じるため，磁気モーメントが発生する．

### 4．弱磁場近似による展開

磁場が十分弱く，

```math
\mu_{\mathrm B}H\ll\mu_0
```

であるとする．
このとき，

```math
x=\mu_{\mathrm B}H
```

とおけば，Taylor展開より

```math
(\mu_0+x)^{3/2}
=\mu_0^{3/2}+\frac32\mu_0^{1/2}x+O(x^2)
```

および

```math
(\mu_0-x)^{3/2}
=\mu_0^{3/2}-\frac32\mu_0^{1/2}x+O(x^2)
```

である．
両式の差をとると，偶数次の項は相殺され，

```math
(\mu_0+x)^{3/2}-(\mu_0-x)^{3/2}
=3\mu_0^{1/2}x+O(x^3)
```

となる．
したがって，

```math
\begin{aligned}
&[2m(\mu_0+\mu_{\mathrm B}H)]^{3/2}\\
&\quad-[2m(\mu_0-\mu_{\mathrm B}H)]^{3/2}\\
&=3(2m)^{3/2}\mu_0^{1/2}\mu_{\mathrm B}H
+O(H^3)
\end{aligned}
```

である．
これを式 (4) に代入すると，

```math
M=
\frac{4\pi V}{3h^3}
\,3\mu_{\mathrm B}^2H(2m)^{3/2}\mu_0^{1/2}
+O(H^3)
```

を得る．
ここで，

```math
(2m)^{3/2}\mu_0^{1/2}
=\frac{(2m\mu_0)^{3/2}}{\mu_0}
```

を用いると，

```math
M=
3H\mu_{\mathrm B}^2
\frac{4\pi V}{3h^3}
\frac{(2m\mu_0)^{3/2}}{\mu_0}
+O(H^3)
\tag{5}
```

となる．

### 5．電子数を用いて整理する

磁場がないとき，2つのスピン状態の電子数は等しく，全電子数 $N$ は

```math
N=2\frac{4\pi V}{3h^3}(2m\mu_0)^{3/2}
\tag{6}
```

である．
したがって，

```math
\frac{4\pi V}{3h^3}(2m\mu_0)^{3/2}
=\frac N2
```

である．
これを式 (5) に代入すれば，

```math
\boxed{
M=\frac32\frac{N\mu_{\mathrm B}^2}{\mu_0}H+O(H^3)
}
\tag{7}
```

を得る．

ここでは，磁場がないときのFermiエネルギー $\mu_0$ を用いて電子数を表した．
電子数 $N$ を一定に保つ場合，磁場による化学ポテンシャルの変化は $H^2$ の次数から始まる．
したがって，磁場に比例する一次の項を求める本計算では，その変化を考慮する必要はない．

### 6．スピン常磁性磁化率

磁化率 $\chi_s$ は，単位体積あたりの磁気モーメントが磁場に応答する大きさを表す量である．
磁化を $\mathcal M=M/V$ とすると，

```math
\mathcal M=\chi_s H
```

である．
式 (7) を用い，電子数密度 $n=N/V$ を導入すると，

```math
\frac MV
=\frac32\frac{N}{V}
\frac{\mu_{\mathrm B}^2}{\mu_0}H
=\frac32\frac{n\mu_{\mathrm B}^2}{\mu_0}H
```

となる．
したがって，スピン常磁性磁化率は

```math
\boxed{
\chi_s=\frac32\frac{n\mu_{\mathrm B}^2}{\mu_0}
}
```

である．

また，Fermi温度を $T_0$ と書けば，

```math
\mu_0=kT_0
```

であるから，

```math
\boxed{
\chi_s=\frac32\frac{n\mu_{\mathrm B}^2}{kT_0}
}
```

となる．
以上が，絶対零度で完全に縮退した自由電子系のスピン常磁性磁化率である．
