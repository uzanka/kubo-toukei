# 演習問題【8-A-4】

## 解答

磁場 $\boldsymbol{H}$ の中に置かれた電子のスピン磁気モーメントに着目する．
電子のスピンは磁場に対して平行，あるいは逆平行のいずれかの向きを向く．
電子のスピン磁気モーメントの大きさを $\mu_{\text{B}}$ とすると，磁場 $\boldsymbol{H}$ 中における各スピン状態のエネルギー $\varepsilon$ は，運動エネルギー $\frac{\boldsymbol{p}^2}{2m}$ を用いて以下のように記述できる．

$$\varepsilon = \frac{\boldsymbol{p}^2}{2m} \pm \mu_{\text{B}} H \quad \cdots (1)$$

ここで， $\pm$ の符号はスピンの向きに対応している．
解答例の定義に従い，スピンが磁場に対して逆平行な状態を $+$ スピン，平行な状態を $-$ スピンとすると，それぞれのエネルギーは以下のようになる．

- $+$ スピン（磁気モーメントが $\boldsymbol{H}$ と逆向き）：
  $\varepsilon_+ = \frac{\boldsymbol{p}^2}{2m} + \mu_{\text{B}} H$
- $-$ スピン（磁気モーメントが $\boldsymbol{H}$ と同じ向き）：
  $\varepsilon_- = \frac{\boldsymbol{p}^2}{2m} - \mu_{\text{B}} H$

絶対零度 ( $0\text{ K}$ ) において，電子系はフェルミエネルギー $\mu_0$ までのエネルギー状態をすべて占有する．
したがって，各スピンを持つ電子の運動エネルギーの最大値は，磁場中では以下のように制限される．

- $+$ スピンの電子：
```math
\frac{\boldsymbol{p}_+^2}{2m} + \mu_{\mathrm{B}} H \leq \mu_0 \implies \frac{\boldsymbol{p}_+^2}{2m} \leq \mu_0 - \mu_{\mathrm{B}} H
```
- $-$ スピンの電子：
```math
\frac{\boldsymbol{p}_-^2}{2m} - \mu_{\mathrm{B}} H \leq \mu_0 \implies \frac{\boldsymbol{p}_-^2}{2m} \leq \mu_0 + \mu_{\mathrm{B}} H
```

体積 $V$ 内の運動量空間における状態密度を考慮すると，運動量 $p$ 以下の状態数 $N(p)$ は次のように与えられる．

$$N(p) = \frac{V}{(2\pi\hbar)^3} \int_0^p 4\pi p'^2 dp' = \frac{4\pi V}{3h^3} p^3$$

これを用いると，各スピンを持つ電子の数 $N_+$ および $N_-$ は以下の通りとなる．

$$N_+ = \frac{4\pi V}{3h^3} p_+^3 \quad \left( \frac{1}{2m} p_+^2 = \mu_0 - \mu_{\text{B}} H \right) \quad \cdots (2)$$

$$N_- = \frac{4\pi V}{3h^3} p_-^3 \quad \left( \frac{1}{2m} p_-^2 = \mu_0 + \mu_{\text{B}} H \right) \quad \cdots (3)$$

全磁気モーメント $M$ は，各スピンによる磁気モーメントの総和である．
$+$ スピンの電子は $-\mu_{\text{B}}$ ， $-$ スピンの電子は $+\mu_{\text{B}}$ の磁気モーメントを持つため，

$$M = N_+ (-\mu_{\text{B}}) + N_- (+\mu_{\text{B}}) = -\mu_{\text{B}} (N_+ - N_-)$$

式 (2)，(3) を代入すると，

$$M = -\mu_{\text{B}} \frac{4\pi V}{3h^3} (p_+^3 - p_-^3) = \mu_{\text{B}} \frac{4\pi V}{3h^3} (p_-^3 - p_+^3)$$

ここで， $p_+ = \sqrt{2m(\mu_0 - \mu_{\text{B}} H)}$ ， $p_- = \sqrt{2m(\mu_0 + \mu_{\text{B}} H)}$ であるから，

$$M = \mu_{\text{B}} \frac{4\pi V}{3h^3} \left[ \{2m(\mu_0 + \mu_{\text{B}} H)\}^{3/2} - \{2m(\mu_0 - \mu_{\text{B}} H)\}^{3/2} \right]$$

磁場が弱い条件 ( $\mu_0 \gg \mu_{\text{B}} H$ ) において，この式を $\mu_{\text{B}} H$ について展開する．
$f(x) = (A + x)^{3/2} - (A - x)^{3/2}$ とおくと， $x \ll A$ のとき $f(x) \approx 3 A^{1/2} x$ と展開できる．
ここでは $A = 2m\mu_0$ ， $x = 2m\mu_{\text{B}} H$ であるから，

$$M \approx \mu_{\text{B}} \frac{4\pi V}{3h^3} \cdot 3 (2m\mu_0)^{1/2} (2m\mu_{\text{B}} H) = 3H\mu_{\text{B}}^2 \frac{4\pi V}{3h^3} \frac{(2m\mu_0)^{3/2}}{\mu_0}$$

全電子数 $N$ は， $H=0$ のときの電子数に相当し，

$$N = N_+ + N_- \Big|_{H=0} = 2 \cdot \frac{4\pi V}{3h^3} (2m\mu_0)^{3/2}$$

であるから， $\frac{4\pi V}{3h^3} (2m\mu_0)^{3/2} = \frac{N}{2}$ を用いると，

$$M = 3H\mu_{\text{B}}^2 \frac{N}{2\mu_0} = \frac{3}{2} \frac{N\mu_{\text{B}}^2}{\mu_0} H \quad \cdots (4)$$

スピン常磁性磁化率 $\chi$ は， $M = \chi V H$ （または磁化 $m = M/V = \chi H$ ）より，

$$\chi = \frac{3}{2} \frac{n\mu_{\text{B}}^2}{\mu_0}$$

ここで $n = N/V$ は電子数密度である．
また， $\mu_0 = k T_0$ （ $T_0$ はフェルミ温度）と書けば，

$$\chi = \frac{3}{2} \frac{n\mu_{\text{B}}^2}{k T_0}$$

が得られる．

## 解説

本問題は，金属中の電子による「パウリ常磁性」を求めるものである．
通常の常磁性（キュリー則に従うもの）とは異なり，フェルミ統計に従う電子系では，磁場によってエネルギーが変化するのはフェルミ面付近の電子のみである．

### 1. エネルギーの分裂

磁場中ではスピンの向きによってエネルギー準位が上下に分裂する．
磁場に平行なスピンはエネルギーが下がり，逆平行なスピンはエネルギーが上がる．

### 2. 占有数の変化

$0\text{ K}$ ではフェルミ面 $\mu_0$ までの状態が埋まるが，磁場によってエネルギーが変化するため，エネルギーが下がったスピンの電子数は増え，上がったスピンの電子数は減る．

### 3. 磁化の発生

この占有数の差が磁気モーメントの差となり，結果として磁化が生じる．

### 4. パウリ常磁性の特徴

磁化の大きさは磁場 $H$ に比例するが，その係数（磁化率）は温度にほとんど依存せず，電子数密度 $n$ とフェルミエネルギー $\mu_0$ に依存する．
これは，フェルミ面付近の限られた数の電子のみが磁場に対して応答するためである．
