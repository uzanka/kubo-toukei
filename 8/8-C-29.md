# 演習問題【8-C-29】

## 解答

### 理想 Fermi 気体の軌道磁化率

#### 1．磁場中の自由エネルギー

一様な磁場 $H$ 中の自由電子を考える．
電子の軌道運動は Landau 準位に量子化される．
スピンに由来する Zeeman エネルギーは考慮せず，解答例と同様に，まずスピン縮退を数えない状態数を用いる．

問題 [17] の結果より，Helmholtz 自由エネルギーは

```math
\begin{aligned}
F={}&N\mu
-\frac{4\pi Vm\mu_{\mathrm B}H}{h^3}k_BT
\sum_{l=0}^{\infty}
\int_{-\infty}^{\infty}dp_z\\
&\quad\times
\ln\left[
1+\exp\left(
\frac{\mu-2\mu_{\mathrm B}H(l+\frac12)-p_z^2/(2m)}
{k_BT}
\right)
\right]
\end{aligned}
\tag{1}
```

と書ける．
ここで， $N$ は粒子数， $V$ は体積， $m$ は電子の質量， $p_z$ は磁場方向の運動量， $\mu_{\mathrm B}$ は Bohr 磁子， $h$ は Planck 定数， $\mu$ は化学ポテンシャルである．
また， $k_B$ は Boltzmann 定数， $T$ は絶対温度である．

問題の条件は

```math
k_BT\ll\mu,\qquad
\mu_{\mathrm B}H\ll k_BT
```

である．
前者は電子系が強く縮退していること，後者は磁場が十分弱いことを表す．

#### 2．Euler の総和公式による磁場の二次の補正

式 (1) の和を積分に変換するため，

```math
f(x)=
\int_{-\infty}^{\infty}dp_z\,
\ln\left[
1+\exp\left(
\frac{\mu-2\mu_{\mathrm B}Hx-p_z^2/(2m)}
{k_BT}
\right)
\right]
```

とおく．
問題文の Euler の総和公式を用いると，

```math
\sum_{l=0}^{\infty}f\left(l+\frac12\right)
\simeq
\int_0^\infty f(x)\,dx
+\frac{1}{24}f'(0)
\tag{2}
```

となる．
ここでは $f'(\infty)=0$ を用いた．

$f(x)$ を微分すると，

```math
\begin{aligned}
f'(x)
={}&-\frac{2\mu_{\mathrm B}H}{k_BT}
\int_{-\infty}^{\infty}dp_z\\
&\times
\frac{1}{
\exp\left[
\{p_z^2/(2m)+2\mu_{\mathrm B}Hx-\mu\}/(k_BT)
\right]+1
}.
\end{aligned}
```

したがって，

```math
f'(0)
=
-\frac{2\mu_{\mathrm B}H}{k_BT}
\int_{-\infty}^{\infty}
\frac{dp_z}{
e^{[p_z^2/(2m)-\mu]/(k_BT)}+1
}
\tag{3}
```

である．
式 (2)，(3) を式 (1) に代入すると，

```math
\begin{aligned}
F\simeq{}&N\mu
-\frac{4\pi Vm\mu_{\mathrm B}H}{h^3}k_BT
\int_0^\infty dx
\int_{-\infty}^{\infty}dp_z\\
&\times
\ln\left[
1+\exp\left(
\frac{\mu-2\mu_{\mathrm B}Hx-p_z^2/(2m)}
{k_BT}
\right)
\right]\\
&+\frac{\pi mV}{3h^3}(\mu_{\mathrm B}H)^2
\int_{-\infty}^{\infty}
\frac{dp_z}{e^{[p_z^2/(2m)-\mu]/(k_BT)}+1}.
\end{aligned}
\tag{4}
```

ここで重要なのは，第 3 項が $H^2$ に比例することである．
これは，離散的な Landau 準位を連続積分で近似した際に生じる最低次の量子補正である．

#### 3．積分変数をエネルギーに変換する

式 (4) の第 1 の積分では，

```math
\epsilon=2\mu_{\mathrm B}Hx+\frac{p_z^2}{2m}
```

とおく．
固定した $p_z$ に対して $x$ を積分し，次に $p_z$ を積分すると，

```math
\begin{aligned}
&\int_0^\infty dx
\int_{-\infty}^{\infty}dp_z\,
\ln\left[
1+\exp\left(
\frac{\mu-2\mu_{\mathrm B}Hx-p_z^2/(2m)}
{k_BT}
\right)
\right]\\
&\qquad=
\frac{\sqrt{2m}}{\mu_{\mathrm B}H}
\int_0^\infty
\sqrt{\epsilon}\,
\ln\left(1+e^{(\mu-\epsilon)/(k_BT)}\right)d\epsilon .
\end{aligned}
```

また，第 2 の積分では

```math
\epsilon=\frac{p_z^2}{2m}
```

とおくと，

```math
\int_{-\infty}^{\infty}
\frac{dp_z}{e^{[p_z^2/(2m)-\mu]/(k_BT)}+1}
=
\sqrt{2m}\int_0^\infty
\frac{\epsilon^{-1/2}\,d\epsilon}
{e^{(\epsilon-\mu)/(k_BT)}+1}
```

となる．
以上を式 (4) に代入すれば，

```math
\begin{aligned}
F\simeq{}&N\mu
-\frac{2\pi(2m)^{3/2}Vk_BT}{h^3}
\int_0^\infty
\sqrt{\epsilon}\,
\ln\left(1+e^{(\mu-\epsilon)/(k_BT)}\right)d\epsilon\\
&+\frac{\pi(2m)^{3/2}V}{6h^3}
(\mu_{\mathrm B}H)^2
\int_0^\infty
\frac{\epsilon^{-1/2}\,d\epsilon}
{e^{(\epsilon-\mu)/(k_BT)}+1}.
\end{aligned}
\tag{5}
```

第 1 項と第 2 項を合わせた部分には，磁場 $H$ が陽に現れない．
第 3 項が，軌道運動の量子化に由来する磁場の二次の補正である．

#### 4．磁化率の計算

磁化 $M$ と磁化率 $\chi$ は，この問題の規約では

```math
M=-\frac{1}{V}
\left(\frac{\partial F}{\partial H}\right)_{T,V,N},
\qquad
\chi=\frac{M}{H}
```

で定義される．
したがって，

```math
\chi=-\frac{1}{VH}
\left(\frac{\partial F}{\partial H}\right)_{T,V,N}
\tag{6}
```

である．

ここで，粒子数 $N$ を固定すると，化学ポテンシャル $\mu$ は一般に磁場 $H$ に依存する．
この依存性を正しく扱うには，大正準ポテンシャル

```math
\Omega(\mu,H)=-k_BT\ln\Xi
```

を用いるとよい．
Helmholtz 自由エネルギーは Legendre 変換により

```math
F(N,H)=\Omega(\mu,H)+\mu N
```

と書け，化学ポテンシャルは粒子数の条件

```math
N=-\left(\frac{\partial\Omega}{\partial\mu}\right)_{T,V,H}
```

を満たすように定まる．
よって， $N$ を固定して全微分すると，

```math
\begin{aligned}
\left(\frac{dF}{dH}\right)_{T,V,N}
&=
\left(\frac{\partial\Omega}{\partial H}\right)_{T,V,\mu}
+\left[
\left(\frac{\partial\Omega}{\partial\mu}\right)_{T,V,H}
+N
\right]
\left(\frac{d\mu}{dH}\right)_{T,V,N}\\
&=
\left(\frac{\partial\Omega}{\partial H}\right)_{T,V,\mu}.
\end{aligned}
\tag{7}
```

したがって，固定粒子数で磁化率を求める際には，化学ポテンシャルの変化から生じる項は相殺される．
式 (5) では，最低次の磁場依存性は $H^2$ の項にあるため，この項だけを微分すればよい．

#### 5．強縮退極限での評価

強く縮退した Fermi 気体では， $k_BT\ll\mu$ であるため，Fermi-Dirac 分布は近似的に階段関数となる：

```math
\frac{1}{e^{(\epsilon-\mu)/(k_BT)}+1}
\simeq
\begin{cases}
1,&0\leq\epsilon<\mu,\\
0,&\epsilon>\mu.
\end{cases}
```

したがって，式 (5) の第 3 項に含まれる積分は，最低次の近似で

```math
\begin{aligned}
\int_0^\infty
\frac{\epsilon^{-1/2}\,d\epsilon}
{e^{(\epsilon-\mu)/(k_BT)}+1}
&\simeq\int_0^\mu\epsilon^{-1/2}\,d\epsilon\\
&=2\sqrt{\mu}
\end{aligned}
\tag{8}
```

となる．
この近似は $k_BT/\mu\ll1$ における最低次の結果であり，有限温度による相対補正は通常 $O((k_BT/\mu)^2)$ の次数で現れる．

式 (8) を式 (5) に代入し，磁場の二次の項を $F_2$ と書けば，

```math
F_2\simeq
\frac{\pi(2m)^{3/2}V}{3h^3}
\mu_{\mathrm B}^2H^2\sqrt{\mu}
```

を得る．
これを式 (6) に代入すると，

```math
\begin{aligned}
\chi_{\mathrm{orb}}^{(1)}
&\simeq-\frac{1}{VH}\frac{\partial F_2}{\partial H}\\
&=-\frac{2\pi(2m)^{3/2}}{3h^3}
\mu_{\mathrm B}^2\sqrt{\mu}.
\end{aligned}
```

ここで上付きの $(1)$ は，スピン縮退を数えない状態数に対する結果であることを示す．
強縮退極限では，化学ポテンシャルを磁場がない $T=0$ での値 $\mu_0$ で近似できる．
したがって，

```math
\boxed{
\chi_{\mathrm{orb}}^{(1)}
\simeq
-\frac{2\pi(2m)^{3/2}}{3h^3}
\mu_{\mathrm B}^2\sqrt{\mu_0}
}
\tag{9}
```

である．

実在の電子には二つのスピン状態があるが，ここではスピンの磁気モーメントによる寄与は考えていない．
軌道運動の状態数にスピン縮退度 2 を含める場合には，式 (9) も 2 倍となる：

```math
\boxed{
\chi_{\mathrm L}
\simeq
-\frac{4\pi(2m)^{3/2}}{3h^3}
\mu_{\mathrm B}^2\sqrt{\mu_0}
}
\tag{10}
```

これは実在の電子系についての Landau 軌道反磁性の結果である．

#### 6．物理的な意味

式 (9) の磁化率は負である．
磁化が外部磁場を打ち消す向きに生じることを意味し，これを軌道反磁性という．
負号は，Landau 準位への量子化によって電子系の自由エネルギーが磁場の二次の項だけ増加することに由来する．

さらに，スピン縮退度 2 を含めた軌道磁化率は，Pauli 常磁性の磁化率

```math
\chi_{\mathrm P}
=
\frac{4\pi(2m)^{3/2}}{h^3}
\mu_{\mathrm B}^2\sqrt{\mu_0}
```

と比較すると，

```math
\boxed{
\chi_{\mathrm L}=-\frac13\chi_{\mathrm P}
}
```

となる．
したがって，強く縮退した自由電子系では，軌道運動による Landau 反磁性は，スピンによる Pauli 常磁性の大きさの $1/3$ であり，符号は反対である．
