# 演習問題【8-A-6】

## 解答

### 1．古典的な等分配則から期待される原子熱

金属の原子熱，すなわち1 molあたりの定積熱容量 $C_V$ を考える．
古典力学のエネルギー等分配則によれば，エネルギーに二次形式で現れる自由度1つあたりの平均エネルギーは $kT/2$ である．
ここで， $k$ はBoltzmann定数， $T$ は絶対温度である．

まず，結晶格子の振動を考える．各原子は3次元空間で振動し，1つの振動方向には運動エネルギーとポテンシャルエネルギーの2つの二次形式の項がある．
したがって，1つの振動方向の平均エネルギーは

```math
\frac12 kT+\frac12 kT=kT
```

となる．
1 molには $N_A$ 個の原子があるため，格子振動の内部エネルギーは

```math
U_{\mathrm{lat}}=3N_AkT=3RT
```

である．
ここで $R=N_Ak$ は気体定数である．
よって，格子振動による定積モル比熱は

```math
C_{V,\mathrm{lat}}=\frac{dU_{\mathrm{lat}}}{dT}=3R
```

となる．
これがDulong–Petitの法則である．

次に，Naのように1原子あたり1個の自由電子があるとする．
自由電子を古典的な理想気体とみなすと，電子は3つの並進自由度を持つため，1個あたりの平均運動エネルギーは $3kT/2$ である．
1 molの電子の内部エネルギーは

```math
U_{\mathrm e}=\frac32N_AkT=\frac32RT
```

となり，電子による定積モル比熱は

```math
C_{V,\mathrm e}=\frac32R
```

となる．

したがって，電子と格子の寄与を合計すると，

```math
\boxed{
C_V=C_{V,\mathrm{lat}}+C_{V,\mathrm e}
=3R+\frac32R=4.5R
}
```

となるはずである．
しかし，実際の普通の金属の原子熱は，通常の温度範囲では主としてDulong–Petitの法則に従い，電子の寄与は小さい．
これは，金属中の電子を古典的な理想気体として扱うことができないためである．

### 2．電子の比熱が小さい理由

金属中の伝導電子はFermi粒子であり，Pauliの排他律に従う．
絶対零度では，電子はエネルギーの低い量子状態から順に占有し，Fermiエネルギー $\mu_0$ までの状態が満たされる．
温度が有限の場合，電子の占有確率はFermi分布関数

```math
f(\varepsilon)=
\frac{1}{e^{(\varepsilon-\mu)/(kT)}+1}
```

で表される．
ここで $\mu$ は化学ポテンシャルであり，低温では $\mu\simeq\mu_0$ である．

電子が熱エネルギーを受け取ってより高いエネルギー状態へ移るためには，移動先に空いた状態が必要である．
しかし，Fermi準位より十分低いエネルギーの状態はすでに電子で満たされているため，Pauliの排他律によって電子は容易に移動できない．
同様に，Fermi準位より十分高い状態はほとんど空であるが，そこへ移動するためには熱エネルギーを受け取る電子が必要である．

そのため，温度上昇によって占有状態が実質的に変化できる電子は，主としてFermi準位の近くにいる電子に限られる．
Fermi分布関数が1から0へ変化するエネルギー幅はおよそ $kT$ である．
したがって，熱的に影響を受ける電子の数は，Fermi準位付近の幅 $kT$ に含まれる状態数に比例する．
一方，全電子数はFermiエネルギー $\mu_0$ までの状態数に対応するため，熱的に影響を受ける電子の割合は概ね

```math
\frac{kT}{\mu_0}=\frac{T}{T_0}
```

の程度である．
ここで，

```math
T_0=\frac{\mu_0}{k}
```

はFermi温度である．

したがって，電子比熱は古典的な値 $3R/2$ より大幅に小さくなり，概ね $T/T_0$ に比例する．
この議論はオーダー評価であり，正確な係数までは与えない．
自由電子Fermi気体の低温比熱をSommerfeld展開で計算すると，

```math
\boxed{
C_{V,\mathrm e}\simeq
\frac{\pi^2}{2}R\frac{T}{T_0}
}
```

となる．
つまり，電子比熱が小さい根本的な理由は，電子の熱運動が弱いからではなく， **Fermi準位から十分離れた電子は，Pauliの排他律と状態の占有によって熱的に励起されにくいから** である．

### 3．NaのFermiエネルギーとFermi温度

電子の熱的な寄与が小さいことを定量的に確かめるため，NaのFermiエネルギー $\mu_0$ を求める．
Naは1原子あたり1個の伝導電子を持つものとする．

3次元の自由電子系では，スピンの2重縮退を含む状態密度は

```math
D(\varepsilon)=
\frac{V}{2\pi^2}
\left(\frac{2m}{\hbar^2}\right)^{3/2}
\sqrt{\varepsilon}
```

で与えられる．
ここで $V$ は試料体積， $m$ は電子質量， $\hbar=h/(2\pi)$ である．
絶対零度ではFermiエネルギーまでの全状態が占有されるので，

```math
N=\int_0^{\mu_0}D(\varepsilon)\,d\varepsilon
```

となる．
積分を実行すると，

```math
N=\frac{V}{3\pi^2}
\left(\frac{2m\mu_0}{\hbar^2}\right)^{3/2}
```

を得る．
これを $\mu_0$ について解けば，

```math
\boxed{
\mu_0=\frac{\hbar^2}{2m}
\left(\frac{3\pi^2N}{V}\right)^{2/3}
}
```

となる．
ここで電子数密度を $n_{\mathrm e}=N/V$ と書けば，

```math
\mu_0=\frac{\hbar^2}{2m}(3\pi^2 n_{\mathrm e})^{2/3}
```

である．

問題で与えられたNaの体積は $24\,\mathrm{cm^3/mol}$ であり，1 molあたりの体積，すなわちモル体積 $V_m$ である．
したがって，1 molのNaを考えると，

```math
N=N_A,\qquad V=V_m=24\,\mathrm{cm^3}
```

であり，電子数密度は

```math
n_{\mathrm e}=\frac{N_A}{V_m}
=\frac{6.022\times10^{23}}{24}
\simeq2.51\times10^{22}\,\mathrm{cm^{-3}}
```

となる．
この値を用いると，

```math
\begin{aligned}
\mu_0
&=\frac{\hbar^2}{2m}
\left(\frac{3\pi^2N_A}{V_m}\right)^{2/3}\\
&\simeq5.0\times10^{-12}\,\mathrm{erg}
\end{aligned}
```

を得る．
$1\,\mathrm{eV}\simeq1.602\times10^{-12}\,\mathrm{erg}$ であるから，

```math
\boxed{
\mu_0\simeq3.1\,\mathrm{eV}
}
```

となる．

さらに，Fermi温度は

```math
T_0=\frac{\mu_0}{k}
```

で定義される．
Boltzmann定数 $k\simeq1.381\times10^{-16}\,\mathrm{erg/K}$ を用いると，

```math
\boxed{
T_0\simeq3.6\times10^4\,\mathrm K
}
```

を得る．

常温 $T\simeq300\,\mathrm K$ では，

```math
\frac{T}{T_0}\simeq
\frac{300}{3.6\times10^4}
\simeq8.3\times10^{-3}\ll1
```

である．
このように，常温はNaのFermi温度と比べて非常に低く，電子系は強く縮退している．
そのため，熱的に状態を変えられる電子の割合は小さい．

自由電子Fermi気体の低温比熱の式からは，

```math
\begin{aligned}
C_{V,\mathrm e}
&\simeq\frac{\pi^2}{2}R\frac{T}{T_0}\\
&\simeq0.041R\\
&\simeq0.34\,\mathrm{J\,mol^{-1}K^{-1}}
\end{aligned}
```

となる．
一方，格子振動によるDulong–Petitの値は

```math
C_{V,\mathrm{lat}}\simeq3R
\simeq24.9\,\mathrm{J\,mol^{-1}K^{-1}}
```

である．
したがって，電子比熱は格子比熱の約1.4％にすぎず，通常の温度範囲では金属の原子熱に対する寄与は小さいのである．

以上より，古典的な等分配則では自由電子が $3R/2$ の比熱を与えると予想されるものの，実際の金属中の電子はFermi統計に従う強縮退系であり，Fermi準位の近傍にいる限られた電子しか熱的に励起されない．
Naでは $T/T_0\ll1$ であるため，電子比熱は小さく，格子振動による $3R$ の寄与が支配的となるのである．
