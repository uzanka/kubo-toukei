# 演習問題【8-A-5】

## 解答

### 1．スピン常磁性磁化率の積分表示

磁場 $H$ 中では，スピン磁気モーメントの向きによって電子のエネルギーが $\mp\mu_{\mathrm B}H$ だけ変化する．
ここで， $D(\varepsilon)$ はスピンの自由度を除いた単位体積あたりの状態密度である．
また，Fermi分布関数を

```math
f(\varepsilon)=
\frac{1}{e^{\beta(\varepsilon-\mu)}+1},
\qquad
\beta=\frac{1}{kT}
```

とする．
磁場の向きに平行な磁気モーメントをもつ電子の数密度を $n_+$ ，逆平行な磁気モーメントをもつ電子の数密度を $n_-$ とすると，

```math
n_+=\int_0^\infty D(\varepsilon)
f(\varepsilon-\mu_{\mathrm B}H)\,d\varepsilon
```

および

```math
n_-=\int_0^\infty D(\varepsilon)
f(\varepsilon+\mu_{\mathrm B}H)\,d\varepsilon
```

である．
したがって，単位体積あたりの磁気モーメント，すなわち磁化 $M$ は，

```math
M=\mu_{\mathrm B}(n_+-n_-)
```

で与えられる．

磁場が十分弱く， $\mu_{\mathrm B}H\ll kT$ であるとして，Fermi分布関数を磁場について一次までTaylor展開すると，

```math
f(\varepsilon\mp\mu_{\mathrm B}H)
\simeq f(\varepsilon)
\mp\mu_{\mathrm B}Hf'(\varepsilon)
```

となる．
ここで， $f'(\varepsilon)=df/d\varepsilon$ である．
よって，

```math
\begin{aligned}
M
&\simeq\mu_{\mathrm B}\int_0^\infty D(\varepsilon)
\left[-2\mu_{\mathrm B}Hf'(\varepsilon)\right]d\varepsilon\\
&=-2\mu_{\mathrm B}^{2}H
\int_0^\infty D(\varepsilon)f'(\varepsilon)\,d\varepsilon
\end{aligned}
```

である．
磁化率を $\chi=M/H$ と定義すると，

```math
\boxed{
\chi=-2\mu_{\mathrm B}^{2}
\int_0^\infty D(\varepsilon)f'(\varepsilon)\,d\varepsilon
}
\tag{1}
```

を得る．
これは，境界条件を特別に仮定しない形の磁化率の基本式である．

ここで，部分積分を行うと，

```math
\begin{aligned}
-\int_0^\infty D(\varepsilon)f'(\varepsilon)\,d\varepsilon
&=-\left[D(\varepsilon)f(\varepsilon)\right]_0^\infty\\
&\quad+\int_0^\infty D'(\varepsilon)f(\varepsilon)\,d\varepsilon\\
&=D(0)f(0)+\int_0^\infty D'(\varepsilon)f(\varepsilon)\,d\varepsilon
\end{aligned}
```

となる．
ここでは $f(\varepsilon)\to0$ as $\varepsilon\to\infty$ を用いた．
したがって，一般には，

```math
\boxed{
\chi=2\mu_{\mathrm B}^{2}
\left[
D(0)f(0)+
\int_0^\infty D'(\varepsilon)f(\varepsilon)\,d\varepsilon
\right]
}
\tag{2}
```

である．
特に $D(0)=0$ であれば，問題文の式

```math
\boxed{
\chi=2\mu_{\mathrm B}^{2}
\int_0^\infty D'(\varepsilon)f(\varepsilon)\,d\varepsilon
}
\tag{3}
```

が得られる．
以下では，問題文の積分表示に従い，状態密度の下端の境界項が消える場合を考える．
自由電子系の $D(\varepsilon)=C\sqrt{\varepsilon}$ は，この条件を満たす．

### 2．絶対零度 $T=0$ の場合

絶対零度では，Fermi分布関数はFermiエネルギー $\mu_0$ を境界とする階段関数である．
すなわち，

```math
f(\varepsilon)=
\begin{cases}
1,&0\leq\varepsilon<\mu_0,\\
0,&\varepsilon>\mu_0.
\end{cases}
```

式 (3) に代入すると，

```math
\begin{aligned}
\chi_0
&=2\mu_{\mathrm B}^{2}
\int_0^{\mu_0}D'(\varepsilon)\,d\varepsilon\\
&=2\mu_{\mathrm B}^{2}
\left[D(\mu_0)-D(0)\right]
\end{aligned}
```

である．
したがって $D(0)=0$ の場合，

```math
\boxed{
\chi_0=2\mu_{\mathrm B}^{2}D(\mu_0)
}
\tag{4}
```

となる．

なお，式 (1) を用いれば，この結果は下端で $D(0)=0$ と仮定しなくても得られる．
絶対零度では $-f'(\varepsilon)$ が $\varepsilon=\mu_0$ に集中するため，

```math
-\int_0^\infty D(\varepsilon)f'(\varepsilon)\,d\varepsilon
=D(\mu_0)
```

となり，やはり式 (4) が得られる．
したがって， **一般の状態密度に対する物理的な絶対零度の磁化率は $2\mu_{\mathrm B}^{2}D(\mu_0)$** である．

### 3．強く縮退している場合

強く縮退している場合は $kT\ll\mu_0$ である．
このとき，Sommerfeld展開が利用できる．
滑らかな関数 $F(\varepsilon)$ に対して，

```math
\int_0^\infty F(\varepsilon)f(\varepsilon)\,d\varepsilon
=
\int_0^\mu F(\varepsilon)\,d\varepsilon
+\frac{\pi^2}{6}(kT)^2F'(\mu)+O(T^4)
\tag{5}
```

が成り立つ．
ここで，有限温度における化学ポテンシャルを $\mu$ ，絶対零度における値を $\mu_0$ と区別する．

#### 3.1．固定粒子数の条件から化学ポテンシャルを求める

全電子数密度 $n$ は，スピンの2重縮退を考慮して，

```math
n=2\int_0^\infty D(\varepsilon)f(\varepsilon)\,d\varepsilon
```

と表される．
粒子数密度が温度によらず一定であるとすると，絶対零度では

```math
\frac n2=\int_0^{\mu_0}D(\varepsilon)\,d\varepsilon
\tag{6}
```

である．
一方，有限温度では式 (5) より，

```math
\frac n2=
\int_0^\mu D(\varepsilon)\,d\varepsilon
+\frac{\pi^2}{6}(kT)^2D'(\mu)+O(T^4)
```

となる．

低温では $\mu-\mu_0=O(T^2)$ であるため，

```math
\int_0^\mu D(\varepsilon)\,d\varepsilon
=
\int_0^{\mu_0}D(\varepsilon)\,d\varepsilon
+(\mu-\mu_0)D(\mu_0)+O(T^4)
```

と展開できる．
これを式 (6) と比較すると，

```math
(\mu-\mu_0)D(\mu_0)
+\frac{\pi^2}{6}(kT)^2D'(\mu_0)=O(T^4)
```

である．
したがって，

```math
\boxed{
\mu(T)=\mu_0-\frac{\pi^2}{6}(kT)^2
\frac{D'(\mu_0)}{D(\mu_0)}+O(T^4)
}
\tag{7}
```

を得る．

#### 3.2．磁化率の低温展開

式 (1) に対応する低温展開は，

```math
-\int_0^\infty D(\varepsilon)f'(\varepsilon)\,d\varepsilon
=
D(\mu)+\frac{\pi^2}{6}(kT)^2D''(\mu)+O(T^4)
```

である．
よって，

```math
\chi=2\mu_{\mathrm B}^{2}
\left[
D(\mu)+\frac{\pi^2}{6}(kT)^2D''(\mu)
\right]+O(T^4)
\tag{8}
```

となる．
ただし，ここでは低温においてバンド下端の影響が高次の項に含まれるものとしている．

式 (7) を用いて $D(\mu)$ を $\mu_0$ のまわりで展開すると，

```math
\begin{aligned}
D(\mu)
&=D(\mu_0)+D'(\mu_0)(\mu-\mu_0)+O(T^4)\\
&=D(\mu_0)
-\frac{\pi^2}{6}(kT)^2
\frac{[D'(\mu_0)]^2}{D(\mu_0)}
+O(T^4)
\end{aligned}
```

である．
また， $D''(\mu)=D''(\mu_0)+O(T^2)$ であるから，式 (8) は

```math
\begin{aligned}
\chi
=2\mu_{\mathrm B}^{2}\Bigg[
D(\mu_0)
+\frac{\pi^2}{6}(kT)^2
\left\{
D''(\mu_0)
-\frac{[D'(\mu_0)]^2}{D(\mu_0)}
\right\}
\Bigg]+O(T^4)
\end{aligned}
```

となる．
ここで，

```math
\frac{d^2\log D}{d\varepsilon^2}
=
\frac{D''}{D}-\frac{(D')^2}{D^2}
```

を用いれば，

```math
\boxed{
\chi=
2\mu_{\mathrm B}^{2}D(\mu_0)
\left[
1+\frac{\pi^2}{6}(kT)^2
\left.
\frac{d^2\log D(\varepsilon)}{d\varepsilon^2}
\right|_{\varepsilon=\mu_0}
+O(T^4)
\right]
}
\tag{9}
```

を得る．
これが，強く縮退している場合の一般的な低温展開である．

### 4．縮退していない場合

縮退していない場合には，Fermi分布関数をMaxwell–Boltzmann分布で近似できる．
すなわち，

```math
f(\varepsilon)\simeq e^{-\beta(\varepsilon-\mu)}
```

である．
このとき，

```math
f'(\varepsilon)=-\beta f(\varepsilon)
```

が成り立つ．
式 (1) に代入すると，

```math
\begin{aligned}
\chi
&=-2\mu_{\mathrm B}^{2}
\int_0^\infty D(\varepsilon)f'(\varepsilon)\,d\varepsilon\\
&=2\mu_{\mathrm B}^{2}\beta
\int_0^\infty D(\varepsilon)f(\varepsilon)\,d\varepsilon
\end{aligned}
```

となる．
電子数密度は $n=2\int_0^\infty Df\,d\varepsilon$ であるから，

```math
\chi=2\mu_{\mathrm B}^{2}\beta\frac n2
=\frac{n\mu_{\mathrm B}^{2}}{kT}
```

を得る．
したがって，

```math
\boxed{
\chi=\frac{n\mu_{\mathrm B}^{2}}{kT}
}
\tag{10}
```

である．
これはCurie則に対応する結果であり，磁化率は温度に反比例する．

### 5．自由電子系への適用

自由電子系では，スピンの自由度を除いた状態密度は，

```math
D(\varepsilon)=C\sqrt{\varepsilon}
```

と表される．
ここで $C$ は定数である．

#### 5.1．絶対零度

絶対零度における電子数密度は，

```math
\begin{aligned}
\frac n2
&=\int_0^{\mu_0}C\sqrt{\varepsilon}\,d\varepsilon\\
&=\frac23C\mu_0^{3/2}
\end{aligned}
```

である．
よって，

```math
C=\frac{3n}{4\mu_0^{3/2}},
\qquad
D(\mu_0)=C\sqrt{\mu_0}
=\frac{3n}{4\mu_0}
```

となる．
式 (4) より，

```math
\boxed{
\chi_0=\frac32\frac{n\mu_{\mathrm B}^{2}}{\mu_0}
}
\tag{11}
```

を得る．

#### 5.2．強く縮退している場合

自由電子系では，

```math
\log D(\varepsilon)=\log C+\frac12\log\varepsilon
```

であるから，

```math
\frac{d\log D}{d\varepsilon}=\frac{1}{2\varepsilon},
\qquad
\frac{d^2\log D}{d\varepsilon^2}
=-\frac{1}{2\varepsilon^2}
```

となる．
これを式 (9) に代入すると，

```math
\begin{aligned}
\chi
&=2\mu_{\mathrm B}^{2}D(\mu_0)
\left[
1-\frac{\pi^2}{12}\frac{(kT)^2}{\mu_0^2}
+O(T^4)
\right]\\
&=\frac32\frac{n\mu_{\mathrm B}^{2}}{\mu_0}
\left[
1-\frac{\pi^2}{12}\frac{(kT)^2}{\mu_0^2}
+O(T^4)
\right]
\end{aligned}
```

である．
Fermi温度を $T_0=\mu_0/k$ と定義すると，

```math
\boxed{
\chi=
\frac32\frac{n\mu_{\mathrm B}^{2}}{kT_0}
\left[
1-\frac{\pi^2}{12}\left(\frac{T}{T_0}\right)^2
+O\!\left(\frac{T^4}{T_0^4}\right)
\right]
}
\tag{12}
```

となる．

この $T^2$ 補正には，Sommerfeld展開に現れる $D''(\mu_0)$ の項と，化学ポテンシャル $\mu(T)$ の温度変化による項の両方が寄与している．
実際，自由電子系では $D''(\varepsilon)=-C/(4\varepsilon^{3/2})$ であり，ゼロではない．

#### 5.3．縮退していない場合

縮退していない場合の式 (10) は，状態密度の具体的な形に依存しないため，自由電子系にもそのまま適用できる．
すなわち，

```math
\boxed{
\chi=\frac{n\mu_{\mathrm B}^{2}}{kT}
}
\tag{13}
```

である．
この場合には，磁化率はCurie則に従って温度の上昇とともに減少する．

以上より，自由電子系のスピン常磁性磁化率は，絶対零度では式 (11)，強く縮退している低温では式 (12)，縮退していない場合には式 (13) で与えられる．
