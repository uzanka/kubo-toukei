# 演習問題【8-R-3】

## 解答

### 1．伝導電子密度と正孔密度の関係

伝導帯のエネルギー準位を $\varepsilon_i$ ，充満帯のエネルギー準位を $\varepsilon_j$ ，電子の化学ポテンシャル（フェルミ・ポテンシャル）を $\mu$ とする．
また， $\beta=1/(kT)$ とおく．

Fermi-Dirac 分布関数によれば，エネルギー準位 $\varepsilon$ が電子によって占有される確率は

```math
f(\varepsilon)=\frac{1}{e^{\beta(\varepsilon-\mu)}+1}
```

である．
したがって，伝導帯と充満帯に存在する電子の総数 $N$ は

```math
N=\sum_i\frac{1}{e^{\beta(\varepsilon_i-\mu)}+1}
+\sum_j\frac{1}{e^{\beta(\varepsilon_j-\mu)}+1}
\tag{1}
```

と表される．

ここで，真性半導体では，絶対零度において充満帯の状態はすべて電子で占有されている．
充満帯の状態数は $N$ であるため，

```math
\sum_j1=N
\tag{2}
```

が成り立つ．
式 (1)，(2) より，

```math
\sum_i\frac{1}{e^{\beta(\varepsilon_i-\mu)}+1}
=
\sum_j\left(
1-\frac{1}{e^{\beta(\varepsilon_j-\mu)}+1}
\right)
\tag{3}
```

となる．

式 (3) の左辺は伝導帯に存在する電子の総数であり，右辺は充満帯に存在する空席，すなわち正孔の総数である．
両辺を単位体積当たりの数に換算すれば，伝導電子密度 $n$ と正孔密度 $p$ について

```math
\boxed{n=p}
\tag{4}
```

が得られる．
これは，真性半導体では電子が価電子帯から伝導帯へ励起されるたびに，伝導電子と正孔が一つずつ生成されることに対応する．

### 2．ボルツマン近似によるキャリア密度の計算

エネルギーの原点を充満帯の上端にとる．
問題の仮定により，伝導帯と充満帯のエネルギー準位は，それぞれ

```math
\varepsilon_i=E_c+\frac{\mathbf{q}^2}{2m_e},
\qquad
\varepsilon_j=-\frac{\mathbf{q}^2}{2m_h}
\tag{5}
```

と表される．
ここで， $\mathbf{q}$ は運動量， $m_e$ は伝導電子の実効質量， $m_h$ は正孔の実効質量である．
また， $E_c$ はエネルギーギャップである．

運動量空間では，一つのスピン状態当たりの状態密度は $d^3q/h^3$ であり，電子のスピンの自由度は2である．
したがって，伝導電子密度は

```math
n=\frac{2}{h^3}\int
\frac{d^3q}{
e^{\beta(E_c-\mu+\mathbf{q}^2/2m_e)}+1}
\tag{6}
```

となる．

一方，正孔は充満帯の電子が占有していない状態であるため，その存在確率は $1-f(\varepsilon_j)$ である．
よって，

```math
\begin{aligned}
p&=\frac{2}{h^3}\int
\left(1-\frac{1}{e^{\beta(\varepsilon_j-\mu)}+1}\right)
d^3q\\
&=\frac{2}{h^3}\int
\frac{d^3q}{e^{\beta(\mu-\varepsilon_j)}+1}
\end{aligned}
```

となる．
式 (5) を代入すれば，

```math
p=\frac{2}{h^3}\int
\frac{d^3q}{
e^{\beta(\mu+\mathbf{q}^2/2m_h)}+1}
\tag{7}
```

を得る．
ここで，式 (6)，(7) の積分は運動量空間全体にわたって行う．

次に， $E_c\gg kT$ であり，化学ポテンシャルがエネルギーギャップの中央付近にあるとする．
このとき，

```math
E_c-\mu\gg kT,\qquad \mu\gg kT
\tag{8}
```

が成り立つ．
したがって，積分に寄与する状態では指数関数の値が十分大きくなり，Fermi-Dirac 分布の分母にある $+1$ を無視できる．
すなわち，ボルツマン近似

```math
\frac{1}{e^x+1}\approx e^{-x}
\qquad (x\gg1)
\tag{9}
```

を適用できる．

式 (6) に式 (9) を適用すると，

```math
n\approx\frac{2}{h^3}
e^{-(E_c-\mu)/kT}
\int e^{-\mathbf{q}^2/(2m_e kT)}\,d^3q
\tag{10}
```

となる．
ここで，三次元のガウス積分

```math
\int e^{-\mathbf{q}^2/(2mkT)}\,d^3q
=(2\pi mkT)^{3/2}
\tag{11}
```

を用いる．
式 (10)，(11) より，

```math
\boxed{
n\approx
2\left(\frac{2\pi m_e kT}{h^2}\right)^{3/2}
e^{-(E_c-\mu)/kT}
}
\tag{12}
```

が得られる．

同様に，式 (7) にボルツマン近似を適用すると，

```math
p\approx\frac{2}{h^3}e^{-\mu/kT}
\int e^{-\mathbf{q}^2/(2m_h kT)}\,d^3q
```

となる．
ガウス積分を実行すれば，

```math
\boxed{
p\approx
2\left(\frac{2\pi m_h kT}{h^2}\right)^{3/2}
e^{-\mu/kT}
}
\tag{13}
```

を得る．

### 3．フェルミ・ポテンシャル $\mu$ の導出

式 (4) の $n=p$ に式 (12)，(13) を代入すると，

```math
\left(\frac{m_e}{m_h}\right)^{3/2}
e^{-(E_c-\mu)/kT}
=e^{-\mu/kT}
\tag{14}
```

となる．
ここで，両辺に $e^{\mu/kT}$ を掛けて整理すると，

```math
\left(\frac{m_e}{m_h}\right)^{3/2}
e^{-E_c/kT}e^{2\mu/kT}=1
```

したがって，

```math
e^{2\mu/kT}
=\left(\frac{m_h}{m_e}\right)^{3/2}
e^{E_c/kT}
\tag{15}
```

である．
両辺の自然対数をとれば，

```math
\frac{2\mu}{kT}
=\frac{3}{2}\log\frac{m_h}{m_e}
+\frac{E_c}{kT}
```

となる．
これを $\mu$ について解くと，

```math
\boxed{
\mu=\frac{1}{2}E_c
+\frac{3}{4}kT\log\frac{m_h}{m_e}
}
\tag{16}
```

が得られる．
これで，フェルミ・ポテンシャルについての題意が示された．

### 4．伝導電子密度と正孔密度の導出

式 (16) を式 (12) に代入する．
まず，

```math
E_c-\mu
=\frac{1}{2}E_c
-\frac{3}{4}kT\log\frac{m_h}{m_e}
```

であるため，

```math
e^{-(E_c-\mu)/kT}
=
\left(\frac{m_h}{m_e}\right)^{3/4}
e^{-E_c/(2kT)}
\tag{17}
```

となる．
これを式 (12) に代入すれば，

```math
\begin{aligned}
n
&\approx
2\left(\frac{2\pi m_e kT}{h^2}\right)^{3/2}
\left(\frac{m_h}{m_e}\right)^{3/4}
e^{-E_c/(2kT)}\\
&=
2\left[
\frac{2\pi(m_e m_h)^{1/2}kT}{h^2}
\right]^{3/2}
e^{-E_c/(2kT)}
\end{aligned}
```

を得る．
式 (4) より $n=p$ であるため，

```math
\boxed{
n=p=
2\left[
\frac{2\pi(m_e m_h)^{1/2}kT}{h^2}
\right]^{3/2}
e^{-E_c/(2kT)}
}
\tag{18}
```

が得られる．
これでキャリア密度についての題意も示された．

### 5．数値計算

与えられた条件は，

```math
E_c=0.7\,\mathrm{eV},\qquad
T=300\,\mathrm{K},\qquad
m_e=m_h=m
```

である．
数値計算では，解答例の係数に従い， $m$ を自由電子質量 $m_0$ とする．

ボルツマン定数を

```math
k=8.617\times10^{-5}\,\mathrm{eV/K}
```

とすると，

```math
\frac{E_c}{k}
=\frac{0.7}{8.617\times10^{-5}}
\approx8123\,\mathrm{K}
\tag{19}
```

である．
したがって，

```math
\frac{E_c}{2kT}
=\frac{8123}{2\times300}
\approx13.54
\tag{20}
```

となる．
ゆえに，

```math
e^{-E_c/(2kT)}
\approx e^{-13.54}
\approx1.31\times10^{-6}
\tag{21}
```

である．

また， $m_e=m_h=m_0$ としたとき，式 (18) の前因子は

```math
\begin{aligned}
2\left(\frac{2\pi m_0 kT}{h^2}\right)^{3/2}
&\approx4.83\times10^{15}T^{3/2}
\,\mathrm{cm}^{-3}\\
&\approx4.83\times10^{15}(300)^{3/2}
\,\mathrm{cm}^{-3}\\
&\approx2.51\times10^{19}\,\mathrm{cm}^{-3}
\end{aligned}
\tag{22}
```

となる．
したがって，式 (18)，(21)，(22) より，

```math
\begin{aligned}
n=p
&\approx2.51\times10^{19}
\times1.31\times10^{-6}\,\mathrm{cm}^{-3}\\
&\approx3.3\times10^{13}\,\mathrm{cm}^{-3}
\end{aligned}
```

を得る．
よって，求める伝導電子密度および正孔密度は，

```math
\boxed{
n=p\approx3.3\times10^{13}\,\mathrm{cm}^{-3}
}
```

である．

なお， $m$ が自由電子質量ではなく，別の共通質量を意味する場合には，数値結果に $(m/m_0)^{3/2}$ を掛ける必要がある．
