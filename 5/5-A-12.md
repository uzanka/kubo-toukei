# 演習問題【5-A-12】

## 解答

### 1．ミクロカノニカル分布から圧力の関係式を導く

#### 1.1 系全体のエネルギーと微視状態数

断面積 $A$ のピストンをもつ断熱容器に気体が閉じ込められ，ピストンの上に重さ $w$ のおもりが載っているとする．
ピストンの位置を $x$ とすると，気体の体積は

```math
V=Ax
```

である．
また，位置エネルギーの基準を適切に選ぶと，おもりの位置エネルギーは $wx$ と表される．

気体のエネルギーを $E$ ，系全体のエネルギーを $E_{\mathrm{tot}}$ とする．
気体，ピストン，おもりを含めた全体は孤立系であるため，全エネルギーは一定である．
したがって，

```math
E_{\mathrm{tot}}=E+wx
```

より，気体のエネルギーは

```math
E=E_{\mathrm{tot}}-wx
```

となる．

気体のエネルギーが $E$ ，体積が $V$ のときの微視状態数を $\Omega(E,V)$ とする．
このとき，おもりの位置が $x$ である場合の系の微視状態数は，エネルギー幅を一定とすれば，

```math
\Omega_{\mathrm{tot}}(x)
\propto\Omega(E_{\mathrm{tot}}-wx,Ax)
```

に比例する．

ミクロカノニカル分布では，孤立系の許された微視状態は等しい確率で実現する．
したがって，平衡状態では，実現する微視状態数が最大となるおもりの位置が最も確からしい位置である．
よって，平衡位置 $x^*$ は

```math
\left.
\frac{d}{dx}
\ln\Omega(E_{\mathrm{tot}}-wx,Ax)
\right|_{x=x^*}=0
```

を満たす．
対数を用いるのは，正の関数 $\Omega$ と $\ln\Omega$ が同じ位置で極大となるからである．

#### 1.2 極大条件から圧力を導く

合成関数の微分法を用いると，

```math
-w\frac{\partial\ln\Omega}{\partial E}
+A\frac{\partial\ln\Omega}{\partial V}=0
```

となる．
両辺にボルツマン定数 $k$ を掛け，ボルツマンのエントロピーの式

```math
S(E,V)=k\ln\Omega(E,V)
```

を用いると，

```math
-w\left(\frac{\partial S}{\partial E}\right)_V
+A\left(\frac{\partial S}{\partial V}\right)_E=0
```

を得る．
ここで，添字 $E$ または $V$ は，それぞれエネルギーまたは体積を一定に保って偏微分することを表す．
整理すれば，

```math
\frac{w}{A}
=
\frac{
\left(\dfrac{\partial S}{\partial V}\right)_E
}{
\left(\dfrac{\partial S}{\partial E}\right)_V
}
\tag{1}
```

となる．

平衡状態では，ピストンに加わる外圧と気体の圧力が釣り合っている．
ピストンに作用する重力は $w$ ，ピストンの断面積は $A$ であるため，外圧は $w/A$ である．
したがって，気体の圧力を $p$ とすると，

```math
p=\frac{w}{A}
```

である．
よって式 (1) は，

```math
\boxed{
p=
\frac{
\left(\dfrac{\partial S}{\partial V}\right)_E
}{
\left(\dfrac{\partial S}{\partial E}\right)_V
}
}
\tag{2}
```

と書ける．
これは，ミクロカノニカル分布における微視状態数の極大条件から得られた関係式である．

#### 1.3 エントロピー一定の条件を用いる

次に，エントロピー $S(E,V)$ が一定となる変化を考える．
その全微分は，

```math
dS=
\left(\frac{\partial S}{\partial E}\right)_VdE
+
\left(\frac{\partial S}{\partial V}\right)_EdV
```

である．
エントロピー一定の過程では $dS=0$ であるから，

```math
\left(\frac{\partial S}{\partial E}\right)_VdE
+
\left(\frac{\partial S}{\partial V}\right)_EdV=0
```

となる．
これを $dV$ についての変化率として整理すると，

```math
\left(\frac{\partial E}{\partial V}\right)_S
=
-\frac{
\left(\dfrac{\partial S}{\partial V}\right)_E
}{
\left(\dfrac{\partial S}{\partial E}\right)_V
}
```

を得る．
式 (2) を代入すれば，

```math
\left(\frac{\partial E}{\partial V}\right)_S=-p
```

となる．
したがって，求める関係式は

```math
\boxed{
p=-\left(\frac{\partial E}{\partial V}\right)_S
}
```

である．

この式は，エントロピーを一定に保ちながら気体の体積を微小量だけ増加させるとき，気体のエネルギーは圧力に比例して減少することを表している．

### 2．単原子分子理想気体への適用

#### 2.1 理想気体のエントロピー

次に，得られた関係式を，粒子数 $N$ ，体積 $V$ ，内部エネルギー $E$ の単原子分子理想気体に適用する．
理想気体では，分子間相互作用を無視でき，内部エネルギーは分子の並進運動の運動エネルギーからなる．

古典的な位相空間において，エネルギー $E$ 以下の状態数は

```math
\Omega_0(E,V,N)
=
\frac{V^N}{N!h^{3N}}
\frac{(2\pi mE)^{3N/2}}
{\Gamma\left(\frac{3N}{2}+1\right)}
```

と表される．
ここで $m$ は分子の質量， $h$ はプランク定数， $\Gamma$ はガンマ関数である．
この式は，位置の積分から $V^N$ ，運動量の積分から $3N$ 次元の球の体積に比例する $E^{3N/2}$ が現れることに基づく．

エントロピーを $S=k\ln\Omega_0$ と定義し， $E$ と $V$ に依存しない項をまとめれば，

```math
S(E,V,N)
=
Nk\ln V+\frac{3}{2}Nk\ln E+C(N,m,h,k)
```

と書ける．
ここで $C$ は $E$ と $V$ に依存しない項である．
対数の各項は，元の無次元の状態数の対数を展開して得られるものであり，単独の対数の引数には適切な基準量が含まれる．

#### 2.2 エントロピー一定の条件から求める

粒子数 $N$ を一定とし，エントロピーを微分すると，

```math
dS=\frac{Nk}{V}\,dV+\frac{3Nk}{2E}\,dE
```

となる．
エントロピー一定の過程では $dS=0$ であるから，

```math
\frac{Nk}{V}\,dV+\frac{3Nk}{2E}\,dE=0
```

を得る．
両辺を $Nk$ で割ると，

```math
\frac{dV}{V}+\frac{3}{2}\frac{dE}{E}=0
```

である．
これを整理すれば，

```math
\frac{dE}{E}=-\frac{2}{3}\frac{dV}{V}
```

となる．
したがって，

```math
\boxed{
\left(\frac{\partial E}{\partial V}\right)_S
=-\frac{2}{3}\frac EV
}
```

を得る．

#### 2.3 状態方程式

第1節で導いた関係式

```math
p=-\left(\frac{\partial E}{\partial V}\right)_S
```

に，上の結果を代入すると，

```math
p=-\left(-\frac{2}{3}\frac EV\right)
```

となる．
よって，

```math
\boxed{
p=\frac{2}{3}\frac EV
}
```

が得られる．
これを変形すると，

```math
\boxed{
pV=\frac{2}{3}E
}
```

である．

さらに，単原子分子理想気体の内部エネルギーと温度の関係

```math
E=\frac{3}{2}NkT
```

を代入すると，

```math
pV=\frac{2}{3}\left(\frac{3}{2}NkT\right)=NkT
```

となる．
したがって，

```math
\boxed{
pV=NkT
}
```

が得られ，通常の理想気体の状態方程式と一致する．

なお，エネルギー殻内の状態密度からエントロピーを定義する場合と，エネルギー以下の累積状態数から定義する場合とでは，有限の $N$ に対して微小な補正が生じる．
ここで得た標準的な状態方程式は，そのような有限粒子数補正を無視できる巨視的な熱力学極限での結果である．
