# 演習問題【5-A-10】
## 解答

### 1．振り子のエネルギー

質量 $m$ のおもりを長さ $l$ の糸で吊るし，鉛直下向きの位置からの振れ角を $\theta$ とする．
振れが小さいとき，

```math
\sin\theta\simeq\theta,\qquad
\cos\theta\simeq1-\frac{\theta^2}{2}
```

と近似できる．

位置エネルギーの基準を支点の高さにとると，振り子の全エネルギー $E_t$ は

```math
E_t=\frac{1}{2}ml^2\dot{\theta}^{\,2}-mgl\cos\theta
```

である．
ここで $\dot{\theta}$ は角速度である．
小振幅近似を用いると，

```math
E_t\simeq
\frac{1}{2}ml^2\dot{\theta}^{\,2}
+\frac{1}{2}mgl\theta^2-mgl
\tag{1}
```

となる．

以下では，最下点に静止しているときのエネルギー $-mgl$ を差し引いた量を，振り子の振動エネルギー $E$ と定義する．
すなわち，

```math
E\equiv E_t+mgl
```

であり，式 (1) より，

```math
\boxed{
E=\frac{1}{2}ml^2\dot{\theta}^{\,2}
+\frac{1}{2}mgl\theta^2
}
\tag{2}
```

となる．
この $E$ は，振り子の振動によるエネルギーである．

小振幅の振り子は角振動数 $\omega=\sqrt{g/l}$ の単振動とみなせる．
単振動では，1周期にわたる運動エネルギーと振動に伴うポテンシャルエネルギーの時間平均が等しい．
時間平均を $\overline{\phantom{x}}$ で表すと，

```math
\overline{\frac{1}{2}ml^2\dot{\theta}^{\,2}}
=
\overline{\frac{1}{2}mgl\theta^2}
```

である．
したがって，

```math
l\,\overline{\dot{\theta}^{\,2}}
=g\,\overline{\theta^2}
```

となる．
式 (2) のエネルギーは，糸の長さが一定のとき保存されるので，これを時間平均して上の関係を用いると，

```math
\begin{aligned}
E
&=\frac{1}{2}ml^2\overline{\dot{\theta}^{\,2}}
+\frac{1}{2}mgl\overline{\theta^2}\\
&=mgl\overline{\theta^2}
\end{aligned}
```

を得る．
よって，

```math
\boxed{E=mgl\overline{\theta^2}}
\tag{3}
```

である．

### 2．糸の張力と外部からされる仕事

次に，糸の張力 $T$ を求める．
おもりの糸に沿う向きの運動方程式を考えると，中心向きの加速度は $l\dot{\theta}^{\,2}$ であるから，

```math
T-mg\cos\theta=ml\dot{\theta}^{\,2}
```

となる．
したがって，

```math
T=ml\dot{\theta}^{\,2}+mg\cos\theta
```

である．
小振幅近似 $\cos\theta\simeq1-\theta^2/2$ を用いれば，

```math
T\simeq
ml\dot{\theta}^{\,2}+mg-\frac{1}{2}mg\theta^2
```

となる．
両辺を1周期にわたって時間平均すると，

```math
\overline T
=ml\overline{\dot{\theta}^{\,2}}
+mg-\frac{1}{2}mg\overline{\theta^2}
```

を得る．
ここで，

```math
l\overline{\dot{\theta}^{\,2}}
=g\overline{\theta^2}
```

を代入すれば，

```math
\begin{aligned}
\overline T
&=mg\overline{\theta^2}
+mg-\frac{1}{2}mg\overline{\theta^2}\\
&=mg+\frac{1}{2}mg\overline{\theta^2}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\overline T=mg+\frac{1}{2}mg\overline{\theta^2}
}
\tag{4}
```

である．

ここで，糸をゆっくり引き上げ，糸の長さが微小量 $\delta l$ だけ変化したとする．
糸を短くする場合には $\delta l<0$ である．
外部から振り子の系にされる仕事は，張力の時間平均を用いて

```math
\boxed{
\delta E_t=-\overline T\,\delta l
}
\tag{5}
```

と表される．
糸を短くすると $-\overline T\,\delta l>0$ となり，系の全エネルギー $E_t$ は増加する．
この仕事の式は，振り子の振動周期に比べて糸の長さの変化が十分に遅いことを前提とする．

ただし，求めたい振動エネルギーは $E=E_t+mgl$ であるため，その微小変化は

```math
\delta E=\delta E_t+mg\,\delta l
\tag{6}
```

となる．
式 (5)，(6) と式 (4) を組み合わせると，

```math
\begin{aligned}
\delta E
&=-\overline T\,\delta l+mg\,\delta l\\
&=-(\overline T-mg)\delta l\\
&=-\frac{1}{2}mg\overline{\theta^2}\,\delta l
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
\delta E=-\frac{1}{2}mg\overline{\theta^2}\,\delta l
}
\tag{7}
```

である．
この式から，糸の長さを短くすると振動エネルギーが増加することが分かる．

### 3．エネルギーと振動数の変化

式 (3) より，

```math
\overline{\theta^2}=\frac{E}{mgl}
```

である．
これを式 (7) に代入すると，

```math
\begin{aligned}
\delta E
&=-\frac{1}{2}mg\frac{E}{mgl}\,\delta l\\
&=-\frac{E}{2l}\,\delta l
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\frac{\delta E}{E}
=-\frac{1}{2}\frac{\delta l}{l}
}
\tag{8}
```

を得る．

次に，振り子の振動数を求める．
小振幅の振り子の角振動数 $\omega$ と通常の振動数 $\nu$ は，

```math
\omega=\sqrt{\frac gl},
\qquad
\nu=\frac{\omega}{2\pi}
=\frac{1}{2\pi}\sqrt{\frac gl}
```

である．
したがって，

```math
\nu\propto l^{-1/2}
```

となる．
対数をとって微分すれば，

```math
\frac{\delta\nu}{\nu}
=-\frac{1}{2}\frac{\delta l}{l}
\tag{9}
```

を得る．

式 (8)，(9) を比較すると，

```math
\boxed{
\frac{\delta E}{E}
=\frac{\delta\nu}{\nu}
}
```

である．
すなわち，糸の長さをゆっくり変化させると，振動エネルギーと振動数は同じ相対割合で変化する．

この関係を積分すると，

```math
d\ln E=d\ln\nu
```

であるから，

```math
\ln E-\ln\nu=\text{一定}
```

となる．
よって，

```math
\boxed{
\frac{E}{\nu}=\text{一定}
}
```

を得る．
これが本問における断熱不変量である．

特に，糸の長さを $l_i$ から $l_f$ にゆっくり変化させた場合には，

```math
\boxed{
\frac{E_f}{E_i}
=\frac{\nu_f}{\nu_i}
=\sqrt{\frac{l_i}{l_f}}
}
```

となる．
したがって，糸を短くすると振動数と振動エネルギーはともに増加し，糸を長くすると両者はともに減少する．
