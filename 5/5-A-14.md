# 演習問題【5-A-14】

## 解答

### (i) 古典的状態数の導出

#### 1．ハミルトニアンと位相空間積分

振動数 $\nu$ の独立な振動子 $N$ 個からなる系を考える．
解答例と同じ形式を用いるため，質量を座標と運動量の正準変数に吸収した変数を用いる．
このとき，全系のハミルトニアンは

```math
\mathcal H
=\sum_{i=1}^{N}
\left\{
\frac12p_i^2+
\frac12(2\pi\nu)^2q_i^2
\right\}
\tag{1}
```

と表される．

通常の質量 $m$ を用いたハミルトニアン

```math
\mathcal H
=\sum_{i=1}^{N}
\left\{
\frac{p_i^2}{2m}
+\frac12m(2\pi\nu)^2q_i^2
\right\}
```

から出発する場合も， $P_i=p_i/\sqrt m$ ， $Q_i=\sqrt m\,q_i$ と変数変換すれば式 (1) の形になる．
この変換は位相空間の体積を変えないため，状態数の計算結果は同じである．

古典的状態数 $\Omega_0(E)$ は，全エネルギーが $E$ 以下となる位相空間領域の体積を，1振動子当たりの状態領域の基本単位 $h$ で割ったものである．
したがって，

```math
\boxed{
\Omega_0(E)
=\frac1{h^N}
\int_{\mathcal H\leq E}
\prod_{i=1}^{N}dq_i\,dp_i
}
\tag{2}
```

と表される．
ここで $h$ はプランク定数である．
各振動子は座標と運動量からなる1組の正準変数をもつため，位相空間の基本単位は $h$ であり，全系では $h^N$ となる．

#### 2．変数変換による積分領域の簡略化

式 (1) の積分を計算するため，次の変数変換を行う．

```math
x_i=\frac{p_i}{\sqrt2},
\qquad
x_{N+i}=\frac{2\pi\nu q_i}{\sqrt2}
\quad (i=1,\ldots,N)
```

これにより，

```math
p_i=\sqrt2x_i,
\qquad
q_i=\frac{\sqrt2}{2\pi\nu}x_{N+i}
```

となる．
したがって，微分は

```math
dp_i=\sqrt2\,dx_i,
\qquad
dq_i=\frac{\sqrt2}{2\pi\nu}\,dx_{N+i}
```

と変換される．
よって，各振動子について，

```math
dq_i\,dp_i
=\frac{2}{2\pi\nu}\,dx_i\,dx_{N+i}
=\frac1{\pi\nu}\,dx_i\,dx_{N+i}
```

である．
これを $N$ 個の振動子について掛け合わせると，

```math
\boxed{
\prod_{i=1}^{N}dq_i\,dp_i
=\frac1{(\pi\nu)^N}
\prod_{j=1}^{2N}dx_j
}
\tag{3}
```

となる．

また，式 (1) のハミルトニアンはこの変数変換によって，

```math
\mathcal H=\sum_{j=1}^{2N}x_j^2
```

となる．
よって，全エネルギーが $E$ 以下という条件は，

```math
\sum_{j=1}^{2N}x_j^2\leq E
```

である．
これは，半径 $\sqrt E$ の $2N$ 次元超球の内部を表す条件である．

#### 3．超球の体積から状態数を求める

半径 $R$ の $d$ 次元超球の体積は，

```math
V_d(R)=
\frac{\pi^{d/2}}{\Gamma(d/2+1)}R^d
```

で与えられる．
ここで $\Gamma$ はガンマ関数である．
今回，次元は $d=2N$ ，半径は $R=\sqrt E$ なので，

```math
\begin{aligned}
V_{2N}(\sqrt E)
&=\frac{\pi^N}{\Gamma(N+1)}
(\sqrt E)^{2N}\\
&=\frac{\pi^N}{N!}E^N
\end{aligned}
```

となる．
ここでは $\Gamma(N+1)=N!$ を用いた．

式 (2)，(3) にこの超球の体積を代入すると，

```math
\begin{aligned}
\Omega_0(E)
&=\frac1{h^N(\pi\nu)^N}
\frac{\pi^N}{N!}E^N\\
&=\frac1{N!}\left(\frac{E}{h\nu}\right)^N
\end{aligned}
```

を得る．
したがって，求める古典的状態数は

```math
\boxed{
\Omega_0(E)=
\frac1{N!}\left(\frac{E}{h\nu}\right)^N
}
\tag{4}
```

である．
ここで $N!$ は超球の体積公式から生じたものであり，振動子を区別できないことによる追加の因子ではない．

### (ii) ミクロカノニカル集団からエネルギーと温度の関係を導く

#### 1．エントロピーを求める

ミクロカノニカル集団では，全エネルギーが指定された孤立系の状態を考え，エントロピーを状態数の対数によって

```math
S=k\ln\Omega_0(E)
```

と定義する．
ここで $k$ はボルツマン定数である．
式 (4) を代入すると，

```math
\begin{aligned}
S
&=k\ln\left[
\frac1{N!}
\left(\frac{E}{h\nu}\right)^N
\right]\\
&=Nk\ln\left(\frac{E}{h\nu}\right)
-k\ln N!
\end{aligned}
\tag{5}
```

となる．

$N\gg1$ の場合，Stirling の公式

```math
\ln N!\simeq N\ln N-N
```

を用いると，

```math
\begin{aligned}
S
&\simeq Nk\ln\left(\frac{E}{h\nu}\right)
-Nk\ln N+Nk\\
&=Nk\left[
\ln\left(\frac{E}{Nh\nu}\right)+1
\right]
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
S\simeq Nk\left[
\ln\left(\frac{E}{Nh\nu}\right)+1
\right]
}
\tag{6}
```

である．

#### 2．エントロピーから温度を求める

ミクロカノニカル集団における温度 $T$ は，エントロピーのエネルギーに対する偏微分によって定義される．
振動子の個数 $N$ と振動数 $\nu$ を一定に保つと，

```math
\frac1T=
\left(\frac{\partial S}{\partial E}\right)_{N,\nu}
```

である．
式 (6) をエネルギー $E$ で偏微分すると，

```math
\begin{aligned}
\frac1T
&\simeq Nk\frac{\partial}{\partial E}
\ln\left(\frac{E}{Nh\nu}\right)\\
&=\frac{Nk}{E}
\end{aligned}
```

を得る．
よって，

```math
\frac1T=\frac{Nk}{E}
```

となり，これを整理すれば，

```math
\boxed{
E=NkT
}
```

である．

この結果は，古典的な調和振動子1個当たりの平均エネルギーが $kT$ であることを意味する．
各振動子には運動エネルギーとポテンシャルエネルギーの2つの二次形式の項があり，それぞれが平均で $kT/2$ のエネルギーを担うため，1振動子当たりの全平均エネルギーは $kT$ となる．
したがって， $N$ 個の振動子の全エネルギーは

```math
\boxed{
E=NkT
}
```

となり，求める関係が導かれた．
