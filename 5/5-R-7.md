# 例題【5-R-7】

## 解答

### 1．合成系の分配関数

体系 A，B，C， $\ldots$ が，それぞれほとんど独立であり，体系間の相互作用が十分に弱い場合を考える．
このとき，合成系 A + B + C + $\cdots$ のエネルギーは，各部分系のエネルギーの和で近似できる．
また，すべての部分系は同じ温度 $T$ の熱浴と接しているものとする．

まず，体系 A の量子状態を $l$ ，その状態のエネルギーを $E_{\mathrm{A},l}$ とする．
体系 A の分配関数は，すべての量子状態についてボルツマン因子を足し合わせたものであり，

```math
Z_{\mathrm{A}}=\sum_l e^{-\beta E_{\mathrm{A},l}}
\tag{1}
```

と表される．
ここで，

```math
\beta=\frac{1}{kT}
\tag{2}
```

であり， $k$ はボルツマン定数である．
同様に，体系 B の量子状態を $m$ ，そのエネルギーを $E_{\mathrm{B},m}$ とすると，

```math
Z_{\mathrm{B}}=\sum_m e^{-\beta E_{\mathrm{B},m}}
\tag{3}
```

となる．
体系 C 以降についても同様である．

次に，合成系の量子状態を考える．
部分系間の相互作用が十分に弱いため，合成系の量子状態は，各部分系の量子状態の組によって指定される．
例えば，体系 A が状態 $l$ ，体系 B が状態 $m$ ，体系 C が状態 $n$ にあるとき，合成系の状態は $(l,m,n)$ と表される．
この状態のエネルギーは，各部分系のエネルギーの和で近似できるため，

```math
E_{\mathrm{A+B+C},lmn}
\simeq E_{\mathrm{A},l}
+E_{\mathrm{B},m}
+E_{\mathrm{C},n}
\tag{4}
```

である．

分配関数は，合成系がとりうるすべての量子状態についてボルツマン因子を足し合わせることで求められる．
したがって，体系 A，B，C， $\ldots$ からなる合成系の分配関数は，

```math
\begin{aligned}
Z_{\mathrm{A+B+\cdots}}
&=\sum_{l,m,n,\ldots}
e^{-\beta(E_{\mathrm{A},l}+E_{\mathrm{B},m}
+E_{\mathrm{C},n}+\cdots)}\\
&=\sum_{l,m,n,\ldots}
e^{-\beta E_{\mathrm{A},l}}
e^{-\beta E_{\mathrm{B},m}}
e^{-\beta E_{\mathrm{C},n}}\cdots
\end{aligned}
\tag{5}
```

となる．
ここでは，指数関数の性質

```math
e^{-(a+b)}=e^{-a}e^{-b}
```

を用いた．

さらに，各部分系の量子状態は独立に選ぶことができるため，それぞれの量子状態についての和を分離できる．
よって，式 (5) は，

```math
\begin{aligned}
Z_{\mathrm{A+B+\cdots}}
&=\left(\sum_l e^{-\beta E_{\mathrm{A},l}}\right)
\left(\sum_m e^{-\beta E_{\mathrm{B},m}}\right)\\
&\qquad\times
\left(\sum_n e^{-\beta E_{\mathrm{C},n}}\right)\cdots
\end{aligned}
\tag{6}
```

と変形できる．
式 (1)，(3) および体系 C 以降の分配関数の定義を用いれば，

```math
\boxed{
Z_{\mathrm{A+B+\cdots}}
=Z_{\mathrm{A}}Z_{\mathrm{B}}Z_{\mathrm{C}}\cdots
}
\tag{7}
```

が得られる．
すなわち，弱く接触したほとんど独立な体系からなる合成系の分配関数は，各部分系の分配関数の積で与えられる．

### 2．合成系の自由エネルギー

次に，自由エネルギーの加法性を示す．
温度 $T$ におけるヘルムホルツ自由エネルギー $F$ と分配関数 $Z$ の間には，

```math
F=-kT\log Z
\tag{8}
```

という関係がある．
したがって，合成系の自由エネルギーは，

```math
F_{\mathrm{A+B+\cdots}}
=-kT\log Z_{\mathrm{A+B+\cdots}}
\tag{9}
```

である．
式 (7) を式 (9) に代入すると，

```math
\begin{aligned}
F_{\mathrm{A+B+\cdots}}
&=-kT\log\left(
Z_{\mathrm{A}}Z_{\mathrm{B}}Z_{\mathrm{C}}\cdots
\right)\\
&=-kT\left(
\log Z_{\mathrm{A}}+\log Z_{\mathrm{B}}
+\log Z_{\mathrm{C}}+\cdots
\right)\\
&=-kT\log Z_{\mathrm{A}}
-kT\log Z_{\mathrm{B}}
-kT\log Z_{\mathrm{C}}-\cdots
\end{aligned}
\tag{10}
```

となる．
ここでは，対数の性質

```math
\log(ab)=\log a+\log b
```

を用いた．
各部分系の自由エネルギーは，

```math
F_{\mathrm{A}}=-kT\log Z_{\mathrm{A}},
\qquad
F_{\mathrm{B}}=-kT\log Z_{\mathrm{B}}
```

などと定義される．
よって，式 (10) から，

```math
\boxed{
F_{\mathrm{A+B+\cdots}}
=F_{\mathrm{A}}+F_{\mathrm{B}}+F_{\mathrm{C}}+\cdots
}
\tag{11}
```

を得る．
したがって，合成系の自由エネルギーは各部分系の自由エネルギーの和で与えられる．

### 結論

部分系間の相互作用を無視でき，すべての体系が同じ温度 $T$ にあるとき，合成系のエネルギーは各部分系のエネルギーの和として表される．
その結果，分配関数は各部分系の分配関数の積となり，

```math
\boxed{
Z_{\mathrm{A+B+\cdots}}
=Z_{\mathrm{A}}Z_{\mathrm{B}}Z_{\mathrm{C}}\cdots
}
```

が成立する．
さらに，自由エネルギーの定義 $F=-kT\log Z$ と対数の性質から，

```math
\boxed{
F_{\mathrm{A+B+\cdots}}
=F_{\mathrm{A}}+F_{\mathrm{B}}+F_{\mathrm{C}}+\cdots
}
```

が導かれる．
以上により，求める二つの関係式が示された．
