# 演習問題【5-B-32】

## 解答

理想気体において， $p = \frac{2}{3} \frac{E_{\text{kin}}}{V}$ が成り立つことを，以下の2つの方法で示す．

### 方法(i)：状態密度を用いた積分による導出

まず，系の圧力を状態密度 $\Omega(\epsilon)$ を用いて表す式から出発する．
与えられた式 (5.94c) によれば，圧力 $p$ と体積 $V$ の積は次のように書ける：

$$pV = \pm \frac{1}{\beta} \sum \log \{ 1 \pm e^{-\beta(\epsilon-\mu)} \}$$

ここで $\beta = 1/(k_B T)$ は逆温度であり， $\mu$ は化学ポテンシャルである．
連続的なエネルギー分布を考えるために，これを状態密度 $\Omega(\epsilon)$ を用いた積分の形に書き換えると，以下のようになる：

$$pV = \pm \frac{1}{\beta} \int_{0}^{\infty} \log \{ 1 \pm e^{\beta(\mu-\epsilon)} \} \Omega(\epsilon) \, d\epsilon$$

ここで， $\log \{ 1 \pm e^{\beta(\mu-\epsilon)} \} = \log \{ 1 \pm \frac{1}{e^{\beta(\epsilon-\mu)}} \}$ である．
なお，本文中の記号 $\Omega(\epsilon)$ は状態密度（微分形）， $\Omega_0(\epsilon) = \int_{0}^{\epsilon} \Omega(\epsilon') \, d\epsilon'$ は累積状態数（積分形）を意味する （本文の定義 $\Omega(\epsilon) = \Omega'_0(\epsilon)$ に従う）．

この積分を実行するために，部分積分を用いる．
$u = \log \{ 1 \pm e^{\beta(\mu-\epsilon)} \}$ , $dv = \Omega(\epsilon)d\epsilon = d\Omega_0(\epsilon)$ とおくと， $\frac{du}{d\epsilon} = \frac{-\beta}{e^{\beta(\epsilon-\mu)} \pm 1}$ となる．
したがって，

$$pV = \pm \frac{1}{\beta} \left[ \log \{ 1 \pm e^{\beta(\mu-\epsilon)} \} \Omega_0(\epsilon) \right]_{0}^{\infty} + \int_{0}^{\infty} \frac{1}{e^{\beta(\epsilon-\mu)} \pm 1} \Omega_0(\epsilon) \, d\epsilon \quad \cdots (1)$$

ここで， $\epsilon \to \infty$ において $\log \{ 1 \pm e^{\beta(\mu-\epsilon)} \} \to 0$ であり，また $\epsilon \to 0$ において累積状態数 $\Omega_0(0) = 0$ であると仮定すると，第1項（境界項）は消滅する．

次に，3次元空間における理想気体の状態密度について考える．
エネルギー $\epsilon = p^2/(2m)$ の粒子系では，状態密度 $\Omega(\epsilon)$ は $\epsilon^{1/2}$ に比例する．
一方，状態の累積数 $\Omega_0(\epsilon)$ は $\Omega_0(\epsilon) \propto \epsilon^{3/2}$ と書ける．
これより，以下の関係が得られる：

$$\epsilon \frac{d\Omega_0}{d\epsilon} = \frac{3}{2} \Omega_0 \implies \Omega_0(\epsilon) = \frac{2}{3} \epsilon \frac{d\Omega_0}{d\epsilon}$$

この関係を式 (1) の積分項に代入する．

$$pV = \int_{0}^{\infty} \frac{1}{e^{\beta(\epsilon-\mu)} \pm 1} \left( \frac{2}{3} \epsilon \frac{d\Omega_0}{d\epsilon} \right) \, d\epsilon = \frac{2}{3} \int_{0}^{\infty} \frac{\epsilon}{e^{\beta(\epsilon-\mu)} \pm 1} \frac{d\Omega_0}{d\epsilon} \, d\epsilon$$

ここで， $\frac{d\Omega_0}{d\epsilon} = \Omega(\epsilon)$ であるから，

$$pV = \frac{2}{3} \int_{0}^{\infty} \frac{\epsilon}{e^{\beta(\epsilon-\mu)} \pm 1} \Omega(\epsilon) \, d\epsilon$$

全運動エネルギー $E_{\text{kin}}$ は $\int_{0}^{\infty} \frac{\epsilon\,\Omega(\epsilon)}{e^{\beta(\epsilon-\mu)} \pm 1} \, d\epsilon$ で与えられるため，

$$pV = \frac{2}{3} E_{\text{kin}}$$

となり，題意は示された．
ここで導出にはフェルミ・ディラック分布とボース・アインシュタイン分布の両方を含む一般的な分布関数を用いたが， $\pm$ の符号を取り出して $e^{-\beta(\epsilon-\mu)}$ に展開すれば古典理想気体（マクスウェル・ボルツマン分布）にも同様に導ける．ゆえにこの関係は統計性のいかんにかかわらず成り立つ．

### 方法(ii)：熱力学的な関係式を用いた導出

熱力学の基本関係式 $dE = TdS - pdV$ から，エントロピー $S$ を一定に保ったまま体積 $V$ を変化させたときのエネルギー $E$ の変化率は，

$$\left( \frac{\partial E}{\partial V} \right)_S = -p \implies p = -\left( \frac{\partial E}{\partial V} \right)_S$$

と得られる．

3次元空間において，粒子が閉じ込められている箱の辺の長さ $l$ と体積 $V$ の関係は $V \propto l^3$ である．
量子力学的な「箱の中の粒子」のモデルによれば，粒子のエネルギー準位 $\epsilon$ は辺の長さの2乗に反比例する：

$$\epsilon_n = \frac{\hbar^2 \pi^2}{2mL^2}(n_1^2 + n_2^2 + n_3^2) \propto \frac{1}{l^2} \propto V^{-2/3}$$

したがって，全運動エネルギー $E_{\text{kin}}$ も体積 $V$ に対して次のような依存性をもつ：

$$E_{\text{kin}} \propto V^{-2/3}$$

準静的な断熱膨張において，粒子の量子数 $(n_1, n_2, n_3)$ を固定すれば占有数が変わらずエントロピーは保存される．この条件下で $E_{\text{kin}}$ を微分すると，

$$\frac{dE_{\text{kin}}}{E_{\text{kin}}} = -\frac{2}{3} \frac{dV}{V}$$

偏微分形式で書けば，

$$\left( \frac{\partial E_{\text{kin}}}{\partial V} \right)_S = -\frac{2}{3} \frac{E_{\text{kin}}}{V}$$

これを圧力の式に代入すると，

$$p = -\left( -\frac{2}{3} \frac{E_{\text{kin}}}{V} \right) = \frac{2}{3} \frac{E_{\text{kin}}}{V}$$

となり，題意は示された．

## 解説

この問題は，理想気体の微視的な統計力学的な性質（状態密度やエネルギー分布）と，巨視的な熱力学的な性質（圧力やエネルギーの変化）が，どのように結びついているかを問うものである．

方法(i)では，エネルギー分布に基づく積分計算によって， $pV$ と $E_{\text{kin}}$ の間に定数倍の明確な関係があることを示した．
ここでの鍵は，3次元空間における状態密度がエネルギーの平方根 $\sqrt{\epsilon}$ に比例するという性質である．
この性質が，積分結果として $p = \frac{2}{3} \frac{E}{V}$ という係数 $\frac{2}{3}$ を導き出す原因となっている．

方法(ii)では，より直感的な「箱の中の粒子」のモデルを用いた．
量子力学的な境界条件によって，体積が変化すると粒子のエネルギー準位が変化することを利用している．
エントロピーを一定に保つ（すなわち量子数を変えない）という条件の下で，体積の変化がエネルギーに与える影響を計算することで，統計力学の詳細な計算を回避して結果を得ることができる．

### 補足：符号の扱いについて（方法(ii)）

方法(ii)では，熱力学の基本関係式 $dE = TdS - pdV$ から導かれる $p = -(\partial E/\partial V)_S$ を用いる．
この負号は，体積が増加する ($dV > 0$) と系のエネルギーが減少する ($dE < 0$) という物理的な事実を反映している．
したがって，$(\partial E_{\text{kin}}/\partial V)_S = -(2/3)(E_{\text{kin}}/V)$ を代入するときの負号が自動的に説明される：

$$p = -\left( -\frac{2}{3} \frac{E_{\text{kin}}}{V} \right) = \frac{2}{3} \frac{E_{\text{kin}}}{V}$$

### 補足：次元依存性について

本解答では3次元を仮定した ($\Omega_0(\epsilon) \propto \epsilon^{3/2}$, $\epsilon \propto V^{-2/3}$)．
$d$ 次元の場合には， $\Omega_0(\epsilon) \propto \epsilon^{d/2}$, $\epsilon \propto V^{-2/d}$ となり，一般化すると：

$$p = \frac{2}{d} \frac{E_{\text{kin}}}{V}$$

と得られる．3次元 ($d=3$) では $\frac{2}{3}$ となる．
