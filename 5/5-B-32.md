# 演習問題【5-B-32】

## 解答

理想気体において，粒子の統計性によらず，

```math
\boxed{p=\frac{2}{3}\frac{E_{\mathrm{kin}}}{V}}
```

が成り立つことを，状態密度を用いる方法と熱力学的な方法の2通りで示す．

### 方法 (i)：状態密度を用いた導出

#### 1．圧力を状態密度の積分で表す

温度 $T$ の熱平衡状態を考え，逆温度を

```math
\beta=\frac{1}{k_{\mathrm B}T}
```

とする．
ここで， $k_{\mathrm B}$ は Boltzmann 定数， $\mu$ は化学ポテンシャルである．

与えられた式 (5.94c) より，圧力 $p$ と体積 $V$ の積は，

```math
pV=\frac{s}{\beta}
\sum_r \log\left[
1+s e^{-\beta(\varepsilon_r-\mu)}
\right]
\tag{1}
```

と表される．
ここで， $\varepsilon_r$ は1粒子量子状態 $r$ のエネルギーであり， $s$ は統計性を指定する符号である．
フェルミ・ディラック統計では $s=+1$ ，ボース・アインシュタイン統計では $s=-1$ とする．

1粒子状態のエネルギーが連続的に分布するとみなし，状態密度を $\Omega(\varepsilon)$ とする．
また，エネルギーが $\varepsilon$ 以下の量子状態の累積数を

```math
\Omega_0(\varepsilon)
=\int_0^\varepsilon\Omega(\varepsilon')\,d\varepsilon'
```

と定義する．
したがって，

```math
\frac{d\Omega_0}{d\varepsilon}
=\Omega(\varepsilon)
```

である．
量子状態の和を積分に置き換えると，式 (1) は

```math
pV=\frac{s}{\beta}
\int_0^\infty
\log\left[
1+s e^{\beta(\mu-\varepsilon)}
\right]\Omega(\varepsilon)\,d\varepsilon
\tag{2}
```

となる．

#### 2．部分積分を行う

式 (2) に部分積分を適用する．

```math
f(\varepsilon)
=\log\left[1+s e^{\beta(\mu-\varepsilon)}\right]
```

とおくと，微分は

```math
\frac{df}{d\varepsilon}
=-\frac{s\beta}{e^{\beta(\varepsilon-\mu)}+s}
\tag{3}
```

である．
この符号は，ボース・アインシュタイン統計とフェルミ・ディラック統計で異なるため， $s$ を明示しておくことが重要である．

また， $\Omega(\varepsilon)d\varepsilon=d\Omega_0(\varepsilon)$ であるから，式 (2) を部分積分すると，

```math
\begin{aligned}
pV
={}&\frac{s}{\beta}
\left[
f(\varepsilon)\Omega_0(\varepsilon)
\right]_0^\infty\\
&-\frac{s}{\beta}
\int_0^\infty
\Omega_0(\varepsilon)
\frac{df}{d\varepsilon}\,d\varepsilon .
\end{aligned}
```

式 (3) を代入すれば，

```math
\begin{aligned}
pV
={}&\frac{s}{\beta}
\left[
f(\varepsilon)\Omega_0(\varepsilon)
\right]_0^\infty\\
&+\int_0^\infty
\frac{\Omega_0(\varepsilon)}
{e^{\beta(\varepsilon-\mu)}+s}\,d\varepsilon .
\end{aligned}
\tag{4}
```

ここで，境界項がゼロになることを確認する．
エネルギーが大きい領域では $f(\varepsilon)$ は指数関数的にゼロに近づく一方， $\Omega_0(\varepsilon)$ はエネルギーのべき乗に比例する．
したがって，上限での積はゼロに近づく．
また，下限では $\Omega_0(0)=0$ であるため，境界項は消える．
ゆえに，

```math
\boxed{
pV=
\int_0^\infty
\frac{\Omega_0(\varepsilon)}
{e^{\beta(\varepsilon-\mu)}+s}\,d\varepsilon
}
\tag{5}
```

となる．

#### 3．3次元の状態密度を用いる

自由粒子の運動エネルギーは，

```math
\varepsilon=\frac{\boldsymbol p^2}{2m}
```

で与えられる．
ここで $\boldsymbol p$ は粒子の運動量， $m$ は粒子の質量である．
3次元では，運動量の大きさが $p$ 以下の状態数は，半径 $p$ の球の体積に比例するため， $\varepsilon$ 以下の状態数は

```math
\Omega_0(\varepsilon)\propto p^3
\propto\varepsilon^{3/2}
```

となる．
したがって，

```math
\varepsilon\frac{d\Omega_0}{d\varepsilon}
=\frac32\Omega_0(\varepsilon)
```

であり，これを変形すると，

```math
\boxed{
\Omega_0(\varepsilon)
=\frac23\varepsilon\Omega(\varepsilon)
}
\tag{6}
```

を得る．

式 (6) を式 (5) に代入すると，

```math
\begin{aligned}
pV
&=\frac23\int_0^\infty
\frac{\varepsilon\Omega(\varepsilon)}
{e^{\beta(\varepsilon-\mu)}+s}\,d\varepsilon .
\end{aligned}
\tag{7}
```

一方，エネルギー $\varepsilon$ の1粒子量子状態の平均占有数は，

```math
\overline n(\varepsilon)
=\frac{1}{e^{\beta(\varepsilon-\mu)}+s}
```

である．
したがって，全運動エネルギーは，各状態のエネルギーに平均占有数と状態密度を掛けて積分することで，

```math
E_{\mathrm{kin}}
=\int_0^\infty
\varepsilon\,\overline n(\varepsilon)
\Omega(\varepsilon)\,d\varepsilon
```

と表せる．
式 (7) は，

```math
pV=\frac23E_{\mathrm{kin}}
```

となるので，求める関係式

```math
\boxed{
p=\frac23\frac{E_{\mathrm{kin}}}{V}
}
```

が示された．

ここで，統計性は平均占有数 $\overline n(\varepsilon)$ にのみ現れ，積分を圧力と運動エネルギーの関係に結びつける部分は同じである．
古典的な Maxwell–Boltzmann 統計では，平均占有数が希薄極限で $e^{-\beta(\varepsilon-\mu)}$ となるため，同じ関係式が得られる．

### 方法 (ii)：熱力学的関係式を用いた導出

#### 1．圧力と体積変化に伴うエネルギーの関係

粒子数 $N$ が一定の系に対して，熱力学の基本関係式は，

```math
dE=T\,dS-p\,dV
```

である．
エントロピー $S$ を一定に保って体積 $V$ を変化させると $dS=0$ であるから，

```math
dE=-p\,dV
```

となる．
したがって，

```math
\boxed{
p=-\left(\frac{\partial E}{\partial V}\right)_{S,N}
}
\tag{8}
```

である．
理想気体では相互作用によるポテンシャルエネルギーを持たないため，内部エネルギー $E$ は全運動エネルギー $E_{\mathrm{kin}}$ に等しい．
よって，

```math
p=-\left(
\frac{\partial E_{\mathrm{kin}}}{\partial V}
\right)_{S,N}
\tag{9}
```

となる．

#### 2．量子エネルギー準位の体積依存性

1辺の長さが $\ell$ の立方体の箱に粒子を閉じ込める．
この箱の体積は

```math
V=\ell^3
```

である．
箱の中の自由粒子の量子エネルギー準位は，

```math
\varepsilon_{n_1n_2n_3}
=\frac{\hbar^2\pi^2}{2m\ell^2}
(n_1^2+n_2^2+n_3^2)
```

と表される．
ここで， $\hbar$ は換算 Planck 定数， $n_1,n_2,n_3$ は量子数である．
量子数を固定すると，エネルギー準位は

```math
\varepsilon_{n_1n_2n_3}
\propto\frac{1}{\ell^2}
\propto V^{-2/3}
\tag{10}
```

となる．

準静的な断熱変化において，各量子状態の占有状況が保たれるとする．
このとき，状態を占める粒子数は変わらず，各粒子のエネルギーだけが式 (10) に従って変化する．
したがって，全運動エネルギーも，

```math
E_{\mathrm{kin}}\propto V^{-2/3}
```

という体積依存性を持つ．

#### 3．体積で微分する

上の比例関係を微分すると，

```math
\frac{dE_{\mathrm{kin}}}{E_{\mathrm{kin}}}
=-\frac23\frac{dV}{V}
```

となる．
すなわち，エントロピーと粒子数を一定に保ったとき，

```math
\left(
\frac{\partial E_{\mathrm{kin}}}{\partial V}
\right)_{S,N}
=-\frac23\frac{E_{\mathrm{kin}}}{V}
\tag{11}
```

である．
これを式 (9) に代入すれば，

```math
\begin{aligned}
p
&=-\left(
-\frac23\frac{E_{\mathrm{kin}}}{V}
\right)\\
&=\frac23\frac{E_{\mathrm{kin}}}{V}.
\end{aligned}
```

したがって，

```math
\boxed{
p=\frac23\frac{E_{\mathrm{kin}}}{V}
}
```

が得られ，題意が示された．

以上の2つの方法で，3次元の理想気体では，圧力と全運動エネルギーの関係が粒子の統計性によらず成り立つことが示された．
