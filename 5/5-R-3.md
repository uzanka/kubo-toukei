# 演習問題【5-R-3】

## 解答

### (i) 熱力学的重率 $W_M$ の導出

振動数 $\nu$ をもつ1個の振動子のエネルギー準位は，

```math
\epsilon_n=\left(n+\frac12\right)h\nu,
\qquad n=0,1,2,\ldots
\tag{1}
```

で与えられる．
ここで， $h$ はプランク定数であり， $n$ は振動子の量子数である．

$N$ 個の振動子の量子数を $n_1,n_2,\ldots,n_N$ とすると，系全体のエネルギー $E$ は各振動子のエネルギーの和であるから，

```math
\begin{aligned}
E&=\sum_{i=1}^{N}\left(n_i+\frac12\right)h\nu\\
&=\frac{N}{2}h\nu+h\nu\sum_{i=1}^{N}n_i
\end{aligned}
\tag{2}
```

となる．
問題文では，全エネルギーが

```math
E=\frac{N}{2}h\nu+Mh\nu
\tag{3}
```

と与えられている．
式 (2) と式 (3) を比較すると，

```math
\boxed{
\sum_{i=1}^{N}n_i=M
}
\tag{4}
```

が得られる．

したがって，熱力学的重率 $W_M$ を求めることは，非負整数 $n_1,n_2,\ldots,n_N$ のうち，和が $M$ となる組合せの数を求めることに等しい．
各振動子は番号によって区別されるため，どの振動子に何個のエネルギー量子が割り当てられるかが異なれば，別の状態として数える．

この個数は，いわゆる「星と棒」の方法で求められる．
$M$ 個の星 $\ast$ をエネルギー量子に対応させ， $N$ 個の振動子を区別するために， $N-1$ 本の仕切りを配置する．
例えば，星が仕切りの左側から順に3個，0個，2個ある場合，3個の振動子の量子数は $(3,0,2)$ である．
仕切りが連続している場合や，列の端に仕切りがある場合も許すため，量子数が0の振動子も数えられる．

このように， $M$ 個の星と $N-1$ 本の仕切りを一列に並べれば，式 (4) を満たす量子数の組合せが一意に定まる．
星と仕切りを合わせると，並べるものの総数は $M+N-1$ 個である．
そのうち星を置く $M$ 個の位置を選べば，残りの位置はすべて仕切りとなる．
したがって，求める組合せの数は二項係数で表され，

```math
\begin{aligned}
W_M
&=\binom{M+N-1}{M}\\
&=\frac{(M+N-1)!}{M!(N-1)!}
\end{aligned}
```

となる．
よって，熱力学的重率は

```math
\boxed{
W_M=\frac{(M+N-1)!}{M!(N-1)!}
}
\tag{5}
```

である．

### (ii) 温度 $T$ とエネルギー $E$ の関係

#### 1．エントロピーを求める

ボルツマンの原理によると，エントロピー $S$ は熱力学的重率 $W_M$ を用いて，

```math
S=k\log W_M
\tag{6}
```

と表される．
ここで， $k$ はボルツマン定数である．
式 (5) を代入すると，

```math
S=k\left\{
\log(M+N-1)!-\log M!-\log(N-1)!
\right\}
\tag{7}
```

となる．

ここで， $N$ と $M$ が十分に大きいと仮定し，Stirling の近似

```math
\log x!\simeq x\log x-x
\tag{8}
```

を用いる．
さらに， $N$ と $M$ が十分に大きいときには， $M+N-1$ を $M+N$ ， $N-1$ を $N$ で近似できる．
これらを式 (7) に適用すると，

```math
\begin{aligned}
\frac{S}{k}\simeq{}&
(M+N)\log(M+N)-(M+N)\\
&-(M\log M-M)-(N\log N-N)
\end{aligned}
```

となる．
ここで，定数項 $-(M+N)+M+N$ は相殺するため，

```math
\boxed{
S\simeq k\left\{
(M+N)\log(M+N)-M\log M-N\log N
\right\}
}
\tag{9}
```

を得る．

以下では， $N$ を一定に保ち，この近似で得られたエントロピーを連続変数 $E$ の関数として扱う．
このようにすることで，エントロピーの微分から温度を求められる．

#### 2．温度をエネルギーの関数として求める

熱力学では，温度 $T$ はエントロピーのエネルギー微分によって定義される．
体積に相当する外部条件は本問で固定されているので，

```math
\frac{1}{T}
=\left(\frac{\partial S}{\partial E}\right)_N
\tag{10}
```

である．
式 (3) より，

```math
M=\frac{E}{h\nu}-\frac{N}{2}
```

であるから，

```math
\left(\frac{\partial M}{\partial E}\right)_N
=\frac{1}{h\nu}
\tag{11}
```

となる．
したがって，連鎖律を用いると，

```math
\frac{1}{T}
=\frac{\partial S}{\partial M}
\frac{\partial M}{\partial E}
\tag{12}
```

である．

まず，式 (9) を $M$ で偏微分する．
$N$ は一定であるため，

```math
\begin{aligned}
\frac{\partial S}{\partial M}
&=k\left\{
\log(M+N)+1-\log M-1
\right\}\\
&=k\log\frac{M+N}{M}
\end{aligned}
\tag{13}
```

となる．
式 (11) と式 (13) を式 (12) に代入すると，

```math
\boxed{
\frac{1}{T}
=\frac{k}{h\nu}\log\frac{M+N}{M}
}
\tag{14}
```

を得る．

次に，式 (3) を用いて $M$ を消去する．

```math
M=\frac{E}{h\nu}-\frac{N}{2},
\qquad
M+N=\frac{E}{h\nu}+\frac{N}{2}
```

であるから，

```math
\begin{aligned}
\frac{M+N}{M}
&=\frac{\dfrac{E}{h\nu}+\dfrac{N}{2}}
{\dfrac{E}{h\nu}-\dfrac{N}{2}}\\
&=\frac{E+\dfrac{N}{2}h\nu}
{E-\dfrac{N}{2}h\nu}
\end{aligned}
\tag{15}
```

となる．
したがって，温度とエネルギーの関係は，

```math
\boxed{
\frac{1}{T}
=\frac{k}{h\nu}
\log\left(
\frac{E+\dfrac{N}{2}h\nu}
{E-\dfrac{N}{2}h\nu}
\right)
}
\tag{16}
```

である．
同じ式を $T$ について解けば，

```math
\boxed{
T=\frac{h\nu}{
k\log\left(
\dfrac{E+\dfrac{N}{2}h\nu}
{E-\dfrac{N}{2}h\nu}
\right)}
}
\tag{17}
```

となる．
この式は $E>Nh\nu/2$ ，すなわち $M>0$ の場合に適用される．

#### 3．エネルギーを温度の関数として求める

式 (16) の両辺に $h\nu/k$ を掛けて指数を取ると，

```math
e^{h\nu/(kT)}
=\frac{E+\dfrac{N}{2}h\nu}
{E-\dfrac{N}{2}h\nu}
\tag{18}
```

となる．
ここで，

```math
A=e^{h\nu/(kT)}
```

とおくと，式 (18) は

```math
A\left(E-\frac{N}{2}h\nu\right)
=E+\frac{N}{2}h\nu
```

と書ける．
これを展開して $E$ について整理すると，

```math
\begin{aligned}
AE-\frac{AN}{2}h\nu
&=E+\frac{N}{2}h\nu\\
E(A-1)&=\frac{N}{2}h\nu(A+1)
\end{aligned}
```

となるため，

```math
E=\frac{N}{2}h\nu\frac{A+1}{A-1}
\tag{19}
```

を得る．
ここに $A=e^{h\nu/(kT)}$ を戻すと，

```math
E=\frac{N}{2}h\nu
\frac{e^{h\nu/(kT)}+1}
{e^{h\nu/(kT)}-1}
```

となる．
さらに，分子を

```math
e^{h\nu/(kT)}+1
=\left(e^{h\nu/(kT)}-1\right)+2
```

と変形すれば，

```math
\boxed{
E=N\left(
\frac12 h\nu+
\frac{h\nu}{e^{h\nu/(kT)}-1}
\right)
}
\tag{20}
```

が得られる．
これが求めるエネルギー $E$ と温度 $T$ の関係式である．

なお， $M=0$ の基底状態では，全振動子が最低エネルギー準位にあり， $E=Nh\nu/2$ である．
式 (20) では $T\to0^+$ の極限を取ると第二項が0に近づき，この基底状態のエネルギーに一致する．

### 補足説明

式 (20) は，振動子のエネルギーが最低準位のエネルギー $h\nu/2$ だけでなく，温度に依存する励起エネルギーも含むことを示している．

特に，高温領域 $kT\gg h\nu$ では，

```math
e^{h\nu/(kT)}
\simeq 1+\frac{h\nu}{kT}
```

と近似できるため，

```math
\frac{h\nu}{e^{h\nu/(kT)}-1}
\simeq kT
```

となる．
したがって，

```math
E\simeq N\left(\frac12h\nu+kT\right)
```

であり， $kT\gg h\nu$ ではゼロ点エネルギーの寄与が相対的に小さいので，

```math
E\simeq NkT
```

となる．
これは，高温極限での調和振動子の古典的な結果と一致する．
