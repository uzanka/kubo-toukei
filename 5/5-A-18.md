# 演習問題【5-A-18】

## 解答

### 1．単原子分子理想気体の場合

#### 1.1 最頻エネルギー $E^*$

単原子分子 $N$ 個からなる理想気体を考える．
状態密度，すなわちエネルギー $E$ 付近にある状態数の密度を $\rho(E)$ とする．
例題 [2] の結果より，

```math
\rho(E)\propto E^{\frac32N-1}
```

である．
温度 $T$ のカノニカル分布では，エネルギー $E$ の状態に対するボルツマン因子は $e^{-E/(kT)}$ である．
したがって，系の全エネルギーが $E$ 付近にある確率密度 $P(E)$ は，

```math
P(E)\propto E^{\frac{3}{2}N-1}e^{-E/(kT)}
```

と表される．

最頻エネルギー $E^*$ は，この確率密度を最大にするエネルギーである．
対数を取っても極大点は変わらないため，

```math
\begin{aligned}
\ln P(E)
&=\text{定数}
+\left(\frac{3}{2}N-1\right)\ln E
-\frac{E}{kT}
\end{aligned}
```

を $E$ で微分する．
極大条件は，

```math
\frac{d}{dE}\ln P(E)
=\frac{\frac{3}{2}N-1}{E}-\frac1{kT}=0
```

である．
これを解くと，

```math
\boxed{
E^*=\left(\frac32N-1\right)kT
}
\tag{1}
```

となる．
ここでは状態密度をそのまま用いた厳密な最頻値を求めた．

#### 1.2 カノニカル分布による平均エネルギー $\bar E$

平均エネルギーは，確率密度を用いて，

```math
\bar E=
\frac{\displaystyle\int_0^\infty E P(E)\,dE}
{\displaystyle\int_0^\infty P(E)\,dE}
```

と定義される．
$P(E)\propto E^{3N/2-1}e^{-E/(kT)}$ を代入すると，

```math
\bar E=
\frac{\displaystyle\int_0^\infty
E^{\frac32N}e^{-E/(kT)}\,dE}
{\displaystyle\int_0^\infty
E^{\frac32N-1}e^{-E/(kT)}\,dE}
```

となる．

ここで，ガンマ関数の定義

```math
\Gamma(s)=\int_0^\infty x^{s-1}e^{-x}\,dx
```

を用いる．
変数変換 $x=E/(kT)$ を行うと，

```math
\int_0^\infty E^{s-1}e^{-E/(kT)}\,dE
=(kT)^s\Gamma(s)
```

である．
したがって，

```math
\begin{aligned}
\bar E
&=kT
\frac{\Gamma\left(\frac32N+1\right)}
{\Gamma\left(\frac32N\right)}
\end{aligned}
```

となる．
ガンマ関数の関係式

```math
\Gamma(s+1)=s\Gamma(s)
```

を用いれば，

```math
\boxed{
\bar E=\frac32NkT
}
\tag{2}
```

を得る．

#### 1.3 最頻値と平均値の比較

式 (1)，(2) より，

```math
\bar E-E^*=kT
```

である．
したがって，有限の $N$ では両者は厳密には一致しない．
しかし， $N\gg1$ のとき，平均エネルギーに対する相対的な差は

```math
\frac{\bar E-E^*}{\bar E}
=\frac{2}{3N}
```

となり， $N$ が大きくなるほどゼロに近づく．
よって，巨視的な系では，

```math
\boxed{
E^*\simeq\bar E=\frac32NkT
}
```

となる．
これは，エネルギーの確率分布が大きな $N$ で鋭いピークをもち，最頻値と平均値が相対的に近づくことを示している．

### 2．量子振動子 $N$ 個からなる系の場合

#### 2.1 最頻励起数 $M^*$

振動数 $\nu$ の独立な量子振動子 $N$ 個からなる系を考える．
各振動子のエネルギー準位は

```math
\varepsilon_n=\left(n+\frac12\right)h\nu,
\qquad n=0,1,2,\ldots
```

である．
系全体のエネルギーは，励起量子数の総和を $M$ とすると，

```math
E=\frac N2h\nu+Mh\nu
```

と表される．

$N$ 個の振動子に $M$ 個の励起量子を分配する方法の数，すなわち熱力学的重率は，

```math
W_M=\frac{(M+N-1)!}{M!(N-1)!}
```

である．
カノニカル分布に従うと，励起数 $M$ に対する確率 $P(M)$ は，

```math
P(M)\propto W_Me^{-Mh\nu/(kT)}
```

となる．
ここでは，零点エネルギー $Nh\nu/2$ による因子は $M$ に依存しないため，比例定数に含めている．

最頻励起数 $M^*$ は $P(M)$ を最大にする値である．
解答例と同様に Stirling の公式を用いるため，まず重率の対数を近似する．
$M,N\gg1$ とすると，

```math
\begin{aligned}
\ln W_M
&\simeq
(M+N)\ln(M+N)\\
&\quad-M\ln M-N\ln N
\end{aligned}
```

となる．
したがって，

```math
\begin{aligned}
\ln P(M)
&=\text{定数}
-\frac{Mh\nu}{kT}+\ln W_M
\end{aligned}
```

を $M$ で微分すると，

```math
-\frac{h\nu}{kT}
+\ln\frac{M+N}{M}=0
```

を得る．
これを整理すれば，

```math
\frac{M+N}{M}=e^{h\nu/(kT)}
```

であるから，

```math
\boxed{
M^*\simeq
\frac{N}{e^{h\nu/(kT)}-1}
}
\tag{3}
```

となる．
したがって，全エネルギーの最頻値は，

```math
\begin{aligned}
E^*
&\simeq\frac N2h\nu+M^*h\nu\\
&=\frac N2h\nu+
\frac{Nh\nu}{e^{h\nu/(kT)}-1}
\end{aligned}
```

である．
よって，

```math
\boxed{
E^*\simeq
N\left[
\frac12h\nu+
\frac{h\nu}{e^{h\nu/(kT)}-1}
\right]
}
\tag{4}
```

を得る．

#### 2.2 カノニカル分布による平均エネルギー $\bar E$

1個の振動子の分配関数は，

```math
z=\sum_{n=0}^{\infty}
e^{-(n+\frac12)h\nu/(kT)}
=\frac{e^{-h\nu/(2kT)}}
{1-e^{-h\nu/(kT)}}
```

である．
独立な $N$ 個の振動子からなる系の分配関数は，

```math
Z=z^N
```

となる．

カノニカル分布における平均エネルギーは，

```math
\bar E=-\frac{\partial\ln Z}{\partial\beta},
\qquad \beta=\frac1{kT}
```

で与えられる．
分配関数の対数を取ると，

```math
\ln Z
=-N\frac{\beta h\nu}{2}
-N\ln(1-e^{-\beta h\nu})
```

である．
したがって，

```math
\begin{aligned}
\bar E
&=-\frac{\partial\ln Z}{\partial\beta}\\
&=\frac N2h\nu+
\frac{Nh\nu}{e^{\beta h\nu}-1}
\end{aligned}
```

となる．
温度 $T$ を用いれば，

```math
\boxed{
\bar E=
N\left[
\frac12h\nu+
\frac{h\nu}{e^{h\nu/(kT)}-1}
\right]
}
\tag{5}
```

を得る．

#### 2.3 最頻値と平均値の比較

式 (4)，(5) を比較すると，

```math
\boxed{
E^*\simeq\bar E
}
```

となる．
すなわち，Stirling の近似を用いて最頻励起数を連続変数として求めると，最頻エネルギーはカノニカル分布の平均エネルギーに一致する．

ただし，実際の励起数 $M$ は非負整数であるため，厳密な最頻値は離散分布の最大点である．
厳密には，

```math
\frac{P(M+1)}{P(M)}
=e^{-h\nu/(kT)}\frac{M+N}{M+1}
```

を用いて隣り合う確率を比較できる．
この比から求められる離散的な最頻励起数は，平均励起数

```math
\bar M=\frac{N}{e^{h\nu/(kT)}-1}
```

と有限の $N$ では必ずしも一致しない．
しかし，最頻励起数と平均励起数はいずれも $N$ に比例して増加するため， $N\gg1$ では相対的な差が小さくなる．

### 3．結論

単原子分子理想気体では，

```math
E^*=\left(\frac32N-1\right)kT,
\qquad
\bar E=\frac32NkT
```

であり， $N\gg1$ では $E^*\simeq\bar E$ となる．

また，量子振動子 $N$ 個からなる系では，Stirling の近似を用いた最頻エネルギーは，

```math
E^*\simeq
N\left[
\frac12h\nu+
\frac{h\nu}{e^{h\nu/(kT)}-1}
\right]
```

である．
これはカノニカル分布から求めた平均エネルギー $\bar E$ と一致する．

したがって，両方の系で， $N$ が十分に大きいとき，最も確からしい全エネルギーとカノニカル分布による平均エネルギーは相対的に一致する．
