# 演習問題【5-A-16】

## 解答

### 1．カノニカル分布から分子の数密度を求める

一様な重力場にある，温度 $T$ の理想気体を考える．
高さ $z=0$ を重力ポテンシャルエネルギーの基準とすると，高さ $z$ にある質量 $m$ の分子のポテンシャルエネルギーは

```math
u(z)=mgz
```

である．
分子の運動量を $\mathbf p$ とすると，1分子のハミルトニアンは

```math
H(\mathbf p,z)=\frac{\mathbf p^2}{2m}+mgz
```

となる．
ここで， $\mathbf p^2=p_x^2+p_y^2+p_z^2$ である．

温度 $T$ が一定の熱平衡状態では，系はカノニカル分布に従う．
カノニカル分布では，エネルギー $H$ をもつ微視状態の確率密度は，ボルツマン因子

```math
e^{-\beta H},
\qquad
\beta=\frac1{kT}
```

に比例する．
したがって，位置と運動量を合わせた1分子の確率密度は，

```math
f(\mathbf r,\mathbf p)
=\frac1{Z_1}
\exp\left[
-\beta\left(\frac{\mathbf p^2}{2m}+mgz\right)
\right]
```

と表される．
ここで， $Z_1$ は確率密度を規格化するための1分子の分配関数であり， $\mathbf r$ は位置ベクトルである．

数密度 $n(z)$ は，単位体積当たりの分子数である．
したがって，1分子の確率密度を運動量空間全体にわたって積分し，分子数 $N$ を掛ければ，

```math
n(z)=N\int f(\mathbf r,\mathbf p)\,d^3p
```

となる．
この式にカノニカル分布を代入すると，

```math
n(z)=\frac{N}{Z_1}
e^{-\beta mgz}
\int_{\mathbb R^3}
e^{-\beta\mathbf p^2/(2m)}\,d^3p
```

を得る．
ここで，運動量に関する積分

```math
\int_{\mathbb R^3}
e^{-\beta\mathbf p^2/(2m)}\,d^3p
```

は高さ $z$ に依存しない．
そのため，比例定数をまとめれば，

```math
n(z)=C e^{-\beta mgz}
```

と書ける．
ここで $C$ は高さによらない定数である．
高さ $z=0$ では $n(0)=C$ であるから，

```math
n(z)=n(0)e^{-\beta mgz}
```

となる．
よって， $\beta=1/(kT)$) を代入すれば，

```math
\boxed{
n(z)=n(0)\exp\left(-\frac{mgz}{kT}\right)
}
\tag{1}
```

を得る．
すなわち，数密度は高さが増すにつれて指数関数的に減少する．
これは，高い位置ほど重力ポテンシャルエネルギーが大きくなり，その位置に分子が存在する確率が小さくなるためである．

### 2．数密度から圧力を求める

局所的に熱平衡にある理想気体では，圧力 $p(z)$ ，数密度 $n(z)$ ，温度 $T$ の間に理想気体の状態方程式

```math
p(z)=n(z)kT
```

が成立する．
本問では温度 $T$ は高さによらず一定である．
したがって，式 (1) を代入すると，

```math
\begin{aligned}
p(z)
&=n(z)kT\\
&=n(0)kT
\exp\left(-\frac{mgz}{kT}\right)
\end{aligned}
```

となる．
高さ $z=0$ における圧力は

```math
p(0)=n(0)kT
```

であるから，最終的に，

```math
\boxed{
p(z)=p(0)\exp\left(-\frac{mgz}{kT}\right)
}
```

を得る．

以上より，一様な重力場にある等温の理想気体では，圧力は高さとともに指数関数的に減少することが示された．
