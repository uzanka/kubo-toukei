# 演習問題【5-B-27】

## 解答

本問題では，Frenkel 型の欠陥が生じる不完全結晶の熱平衡状態における欠陥数 $n$ を求める．

### 1. 系の状態数とエネルギー

まず，欠陥の状態を記述する．
$N$ 個の格子点から $n$ 個の原子を取り除き，それを $N'$ 個の格子間隙のいずれかに配置すると考える．
このとき，格子の空孔（vacancy）の数は $n$ 個であり，格子間隙に存在する原子（interstitial atom）の数も $n$ 個となる．

格子点から $n$ 個の原子を選ぶ方法は $\binom{N}{n}$ 通りである．
また，取り出した $n$ 個の原子を $N'$ 個の格子間隙のいずれかに配置する方法は $\binom{N'}{n}$ 通りである．
したがって，この系の状態数 $W(n)$ は次のように与えられる：

$$W(n) = \binom{N}{n} \binom{N'}{n} = \frac{N!}{n!(N-n)!} \frac{N'!}{n!(N'-n)!}$$

次に，系のエネルギー $E(n)$ を考える．
1個の原子を格子点から格子間隙に移すのに必要なエネルギーが $w$ であるため， $n$ 個の原子を移したときの全エネルギーは次のように書ける：

$$E(n) = nw$$

### 2. 自由エネルギーの極小化と熱平衡状態

統計力学において，温度 $T$ の熱平衡状態では，系の分配関数 $Z$ が最大となる（あるいはヘルムホルツ自由エネルギー $F$ が最小となる）状態が最も確率的に現れる．
分配関数の Frenkel 欠陥に関する項は次のように表される：

$$Z = \sum_n W(n) e^{-E(n)/kT}$$

$w \gg kT$ という条件のもとでは， $W(n)$ の増大と指数関数 $e^{-E(n)/kT}$ の減少が急激に起こるため，和の主要な寄与は $W(n) e^{-E(n)/kT}$ が極大となる $n$ の値に集中する．
この極大値を与える $n$ が熱平衡状態における欠陥数である．

計算を簡略化するため， $f(n) = \ln \{W(n) e^{-E(n)/kT}\}$ とおき，この関数を $n$ について極大化する．

### 3. 式の導出

Stirling の公式 $\ln X! \approx X \ln X - X$ を用いて， $f(n)$ を展開する．

$$\ln W(n) = \ln N! + \ln N'! - 2\ln n! - \ln(N-n)! - \ln(N'-n)!$$

$$\approx (N \ln N - N) + (N' \ln N' - N') - 2(n \ln n - n) - ((N-n) \ln (N-n) - (N-n)) - ((N'-n) \ln (N'-n) - (N'-n))$$

定数項を整理すると：

$$-N - N' + 2n + N - n + N' - n = 0$$

となるため，

$$\ln W(n) \approx N \ln N + N' \ln N' - 2n \ln n - (N-n) \ln (N-n) - (N'-n) \ln (N'-n)$$

これにエネルギー項の対数を加えると：

$$f(n) = \ln W(n) - \frac{E(n)}{kT} = N \ln N + N' \ln N' - 2n \ln n - (N-n) \ln (N-n) - (N'-n) \ln (N'-n) - \frac{w}{kT}n$$

$n$ について微分して， $0$ と置くことで極大条件を求める：

$$\frac{df}{dn} = -2(\ln n + 1) - (-1)(\ln(N-n) + 1) - (-1)(\ln(N'-n) + 1) - \frac{w}{kT} = 0$$

$$-2 \ln n - 2 + \ln(N-n) + 1 + \ln(N'-n) + 1 - \frac{w}{kT} = 0$$

$$-2 \ln n + \ln(N-n) + \ln(N'-n) - \frac{w}{kT} = 0$$

これを整理すると：

$$\ln \left\{ \frac{(N-n)(N'-n)}{n^2} \right\} = \frac{w}{kT}$$

$$\frac{(N-n)(N'-n)}{n^2} = e^{w/kT}$$

逆数を取ると：

$$\frac{n^2}{(N-n)(N'-n)} = e^{-w/kT}$$

となり，第一の式が示された．

### 4. 近似式の導出

問題の条件 $1 \ll n \ll N$ および $n \ll N'$ より， $N-n \approx N$ および $N'-n \approx N'$ と近似できる．
これを用いると，

$$\frac{n^2}{NN'} \approx e^{-w/kT}$$

$$n^2 \approx NN' e^{-w/kT}$$

$$n \approx \sqrt{NN'} e^{-w/2kT}$$

となり，第二の式も示された．

## 解説

本問題は，固体内における点欠陥（Frenkel 欠陥）の熱力学的な生成過程を扱うものである．

1.  **エントロピーと状態数**：
  欠陥 $n$ が増えると，原子が「どこに空孔があるか」および「どこに間隙原子があるか」という組み合わせの数（状態数 $W$ ）が増大する．
  これは系のエントロピー $S = k \ln W$ の増大を意味する．
2.  **エネルギーと自由エネルギー**：
  一方で，欠陥を作るにはエネルギー $w$ が必要であり，系の内部エネルギー $E$ は増大する．
  熱力学的な安定性は，エネルギー $E$ とエントロピー $S$ のバランス（自由エネルギー $F = E - TS$ の最小化）によって決まる．
3.  **熱平衡**：
  高温になると $TS$ 項の影響が強まり，エントロピーを稼ぐために多くの欠陥が生成されやすくなる．
  一方，低温では $E$ 項が支配的となり，欠陥は少なくなるとき，これらが絶妙なバランスを保つ状態が本問題で求めた $n$ である．
