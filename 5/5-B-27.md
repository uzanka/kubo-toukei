# 演習問題【5-B-27】

## 解答

### Frenkel 型欠陥の熱平衡における欠陥数の導出

#### 1．欠陥の状態数とエネルギー

$N$ 個の原子が規則正しく並んだ完全結晶を考える．
このうち $n$ 個の原子を格子点から格子間隙に移すと， $n$ 個の空孔と $n$ 個の格子間原子が生じる．
このような欠陥を Frenkel 型欠陥という．

格子点の総数は $N$ ，原子が入り得る格子間隙の総数は $N'$ である．
また，原子を一個移動させて欠陥を一組作るために必要なエネルギーを $w$ とする．

まず，欠陥数が $n$ であるときの状態数 $W(n)$ を求める．

$N$ 個の格子点から空孔となる $n$ 個の格子点を選ぶ方法は，

```math
\binom{N}{n}=\frac{N!}{n!(N-n)!}
```

通りである．

一方， $N'$ 個の格子間隙から格子間原子が入る $n$ 個の位置を選ぶ方法は，

```math
\binom{N'}{n}=\frac{N'!}{n!(N'-n)!}
```

通りである．

空孔の位置の選び方と格子間原子の位置の選び方は，それぞれ独立に指定できる．
したがって，欠陥数が $n$ であるときの状態数は，これらの積で与えられる．
すなわち，

```math
\boxed{
W(n)=\frac{N!}{n!(N-n)!}
\frac{N'!}{n!(N'-n)!}
}
\tag{1}
```

である．

次に，欠陥を一組作るごとにエネルギーが $w$ だけ増加するため，欠陥数が $n$ である状態のエネルギーは，完全結晶のエネルギーを基準として，

```math
\boxed{
E(n)=nw
}
\tag{2}
```

となる．
ここでは， $n\ll N$ ， $n\ll N'$ であるため，欠陥同士の相互作用によるエネルギーの補正は無視している．

#### 2．分配関数と熱平衡条件

温度 $T$ の熱平衡状態を考える．
Boltzmann の原理によれば，エネルギーが $E(n)$ である状態の統計的な重みは，

```math
e^{-E(n)/(kT)}
```

に比例する．
ここで， $k$ は Boltzmann 定数である．

欠陥数が $n$ である状態は $W(n)$ 通りあるため，欠陥数が $n$ である状態群全体の重みは，

```math
P_n\propto W(n)e^{-E(n)/(kT)}
```

となる．
ここで $P_n$ は，欠陥数が $n$ である状態群が現れる確率に比例する量である．

したがって，Frenkel 型欠陥に関する分配関数は，

```math
\boxed{
Z=\sum_n W(n)e^{-E(n)/(kT)}
}
\tag{3}
```

と表される．
この和は，許されるすべての欠陥数について取るものである．

問題では $w\gg kT$ を仮定している．
このとき，欠陥を作るエネルギーの負担が大きいため，欠陥数が増えると Boltzmann 因子 $e^{-nw/(kT)}$ は急速に小さくなる．
一方，欠陥数が増えると，欠陥を配置する方法の数 $W(n)$ は増加する．

この二つの効果が競合するため，積

```math
W(n)e^{-nw/(kT)}
```

は，ある欠陥数の近くで極大になる．
系の大きさが十分に大きく，この重みが鋭いピークを持つ場合，そのピークを与える欠陥数が熱平衡における最も確からしい欠陥数となる．

そこで，

```math
f(n)=\log\left\{W(n)e^{-nw/(kT)}\right\}
```

とおく．
対数関数は単調増加関数であるため， $W(n)e^{-nw/(kT)}$ を最大にすることと， $f(n)$ を最大にすることは同値である．

#### 3．Stirling の公式による極大条件の導出

式 (1) より，

```math
\begin{aligned}
\log W(n)
={}&\log N!+\log N'!-2\log n!\\
&-\log(N-n)!-\log(N'-n)!
\end{aligned}
```

である．

ここで，問題の条件 $1\ll n\ll N$ と $N'$ が $N$ と同程度であることから， $n$ ， $N-n$ ， $N'-n$ はいずれも十分に大きい．
したがって，Stirling の公式

```math
\log m!\simeq m\log m-m
```

を適用できる．

これを各階乗に適用すると，

```math
\begin{aligned}
\log W(n)\simeq{}&
N\log N-N+N'\log N'-N'\\
&-2(n\log n-n)\\
&-\{(N-n)\log(N-n)-(N-n)\}\\
&-\{(N'-n)\log(N'-n)-(N'-n)\}
\end{aligned}
```

となる．

ここで， $n$ に比例する項と定数項を整理すると，それらは相殺される．
よって，

```math
\begin{aligned}
\log W(n)\simeq{}&
N\log N+N'\log N'\\
&-2n\log n\\
&-(N-n)\log(N-n)\\
&-(N'-n)\log(N'-n)
\end{aligned}
```

を得る．

式 (2) を用いると，

```math
f(n)=\log W(n)-\frac{nw}{kT}
```

であるから，

```math
\begin{aligned}
f(n)\simeq{}&
N\log N+N'\log N'-2n\log n\\
&-(N-n)\log(N-n)\\
&-(N'-n)\log(N'-n)-\frac{nw}{kT}
\end{aligned}
\tag{4}
```

となる．

熱平衡では $f(n)$ が極大となるため， $n$ を連続変数として近似し，その微分をゼロとおく．
式 (4) を $n$ で微分すると，

```math
\begin{aligned}
\frac{df}{dn}
={}&-2(\log n+1)\\
&+\{\log(N-n)+1\}\\
&+\{\log(N'-n)+1\}
-\frac{w}{kT}
\end{aligned}
```

となる．
ここで， $(N-n)\log(N-n)$ および $(N'-n)\log(N'-n)$ を微分する際には，それぞれの内部の微分が $-1$ であることに注意する．

整理すると，

```math
\frac{df}{dn}
=-2\log n+\log(N-n)+\log(N'-n)
-\frac{w}{kT}
```

である．
極大条件 $df/dn=0$ より，

```math
2\log n
=\log(N-n)+\log(N'-n)-\frac{w}{kT}
```

となる．
対数の性質を用いると，

```math
\log n^2
=\log\{(N-n)(N'-n)\}-\frac{w}{kT}
```

であるから，

```math
\log\frac{n^2}{(N-n)(N'-n)}
=-\frac{w}{kT}
```

を得る．
両辺の指数を取ると，

```math
\boxed{
\frac{n^2}{(N-n)(N'-n)}
=e^{-w/(kT)}
}
\tag{5}
```

となる．
これが求める第一の式である．

なお，この停留点が極大であることは，式 (4) の二階微分からも確認できる．

```math
\frac{d^2f}{dn^2}
=-\frac2n-\frac1{N-n}-\frac1{N'-n}<0
```

であるため，許される範囲 $0<n<\min(N,N')$ では $f(n)$ は狭義の凹関数であり，停留点は極大点である．

#### 4．欠陥数の近似式

問題の条件より，

```math
n\ll N,\qquad n\ll N'
```

である．
したがって，

```math
N-n\simeq N,\qquad N'-n\simeq N'
```

と近似できる．
これを式 (5) に代入すると，

```math
\frac{n^2}{NN'}\simeq e^{-w/(kT)}
```

となる．
両辺に $NN'$ を掛ければ，

```math
n^2\simeq NN'e^{-w/(kT)}
```

である．
$n$ は正であるから，正の平方根を取って，

```math
\boxed{
n\simeq\sqrt{NN'}\,e^{-w/(2kT)}
}
```

を得る．
これが求める第二の式である．

また， $N'$ は $N$ と同程度であり， $w\gg kT$ であるため，この近似式は $n\ll N,N'$ という仮定とも整合する．

以上より，Frenkel 型欠陥の熱平衡における欠陥数は，欠陥を生成するエネルギーと欠陥配置の組合せ数の競合によって決まり，指定された二つの関係式が導かれる．
