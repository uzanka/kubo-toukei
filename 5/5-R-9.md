# 例題【5-R-9】

## 解答

### 1．粒子数の分配確率

温度 $T$ の熱浴に接している二つの系 $\mathrm{I}$ ， $\mathrm{II}$ があり，両者の間では粒子の交換が可能であるとする．
二つの系の合計粒子数を $N$ とし，各系の粒子数をそれぞれ $N_{\mathrm I}$ ， $N_{\mathrm{II}}$ とすると，粒子数保存則より

```math
N_{\mathrm I}+N_{\mathrm{II}}=N
```

が成り立つ．

系 $\mathrm I$ の粒子数が $N_{\mathrm I}$ ，温度が $T$ のときの分配関数を $Z_{\mathrm I}(N_{\mathrm I},T)$ とし，系 $\mathrm{II}$ についても同様に $Z_{\mathrm{II}}(N_{\mathrm{II}},T)$ とする．
二つの系が互いに独立であり，粒子数の分配 $(N_{\mathrm I},N_{\mathrm{II}})$ が定まっているとき，合成系の分配関数は各系の分配関数の積

```math
Z_{\mathrm I}(N_{\mathrm I},T)
Z_{\mathrm{II}}(N_{\mathrm{II}},T)
```

で与えられる．

したがって，全粒子数 $N$ を固定した合成系の分配関数は，可能なすべての粒子数分配について和をとることにより，

```math
\begin{aligned}
Z_{\mathrm{I+II}}(N,T)
&=\sum_{N_{\mathrm I}=0}^{N}
Z_{\mathrm I}(N_{\mathrm I},T)
Z_{\mathrm{II}}(N-N_{\mathrm I},T)
\end{aligned}
\tag{1}
```

となる．
ここでは $N_{\mathrm{II}}=N-N_{\mathrm I}$ を用いた．

カノニカル分布において，各微視的状態の確率はその状態のボルツマン因子に比例する．
そのため，粒子数分配 $(N_{\mathrm I},N_{\mathrm{II}})$ が実現する確率は，その分配に対応する分配関数の積に比例する．
式 (1) を規格化因子として用いると，

```math
\boxed{
f(N_{\mathrm I},N_{\mathrm{II}})
=
\frac{
Z_{\mathrm I}(N_{\mathrm I},T)
Z_{\mathrm{II}}(N_{\mathrm{II}},T)
}{
Z_{\mathrm{I+II}}(N,T)
}
}
\tag{2}
```

を得る．
ただし， $N_{\mathrm I}+N_{\mathrm{II}}=N$ である．
式 (2) の分母は，許されるすべての粒子数分配について確率の和が $1$ となるようにするための規格化因子である．

### 2．最も確からしい粒子数分配の条件

最も確からしい分配 $(N_{\mathrm I}^{*},N_{\mathrm{II}}^{*})$ は，式 (2) の確率を最大にする分配である．
全粒子数 $N$ と温度 $T$ は一定であるため，分母 $Z_{\mathrm{I+II}}(N,T)$ は粒子数分配によらない．
したがって，最大化すべきものは分子であり，

```math
\boxed{
Z_{\mathrm I}(N_{\mathrm I}^{*},T)
Z_{\mathrm{II}}(N_{\mathrm{II}}^{*},T)
=\text{最大}
}
\tag{3}
```

が最も確からしい分配の条件となる．

ここで，各系のヘルムホルツ自由エネルギーを

```math
F_{\mathrm I}(N_{\mathrm I},T)
=-kT\ln Z_{\mathrm I}(N_{\mathrm I},T)
```

```math
F_{\mathrm{II}}(N_{\mathrm{II}},T)
=-kT\ln Z_{\mathrm{II}}(N_{\mathrm{II}},T)
```

と定義する．
ただし， $k$ はボルツマン定数である．
対数関数は単調増加関数であるため，式 (3) の積を最大化することは，その対数を最大化することと等価である．
また， $T>0$ であるから，これは自由エネルギーの和を最小化することに等しい．
よって，

```math
\boxed{
F_{\mathrm I}(N_{\mathrm I}^{*},T)
+
F_{\mathrm{II}}(N_{\mathrm{II}}^{*},T)
=\text{最小}
}
\tag{4}
```

となる．

### 3．化学ポテンシャルによる表現

粒子数が十分に大きく，粒子数を連続変数として扱えるとする．
全粒子数 $N$ は一定なので， $N_{\mathrm{II}}=N-N_{\mathrm I}$ である．
したがって，自由エネルギーの和を $N_{\mathrm I}$ の関数とみなすと，その微分は

```math
\begin{aligned}
&\frac{d}{dN_{\mathrm I}}
\left[
F_{\mathrm I}(N_{\mathrm I},T)
+F_{\mathrm{II}}(N-N_{\mathrm I},T)
\right]\\
&\qquad =
\frac{\partial F_{\mathrm I}}{\partial N_{\mathrm I}}
-\frac{\partial F_{\mathrm{II}}}{\partial N_{\mathrm{II}}}
\end{aligned}
\tag{5}
```

である．
ここでは， $dN_{\mathrm{II}}/dN_{\mathrm I}=-1$ を用いた．
内部の極小点では，式 (5) の右辺が \(0\) となるため，

```math
\frac{\partial F_{\mathrm I}}{\partial N_{\mathrm I}}
=
\frac{\partial F_{\mathrm{II}}}{\partial N_{\mathrm{II}}}
\tag{6}
```

を得る．

温度と体積など，各系の他の状態変数を固定したとき，化学ポテンシャル $\mu$ はヘルムホルツ自由エネルギーの粒子数に関する偏微分として定義される．
すなわち，

```math
\mu=\left(\frac{\partial F}{\partial N}\right)_{T,V}
```

である．
これを式 (6) に適用すると，最も確からしい粒子数分配において，

```math
\boxed{
\mu_{\mathrm I}(N_{\mathrm I}^{*},T)
=
\mu_{\mathrm{II}}(N_{\mathrm{II}}^{*},T)
}
\tag{7}
```

が成り立つ．

したがって， **二つの系の間で粒子交換が可能なとき，最も確からしい粒子数分配の平衡条件は，両系の化学ポテンシャルが等しいことである．**

なお，粒子数は厳密には整数であるため，最も確からしい分配は，許される整数の粒子数分配の中で確率を最大にするものとして定義される．
式 (7) は，粒子数が十分に大きく，連続変数による近似が可能な場合に得られる平衡条件であり，その停留点が実際に自由エネルギーの最小値を与えることも必要である．
