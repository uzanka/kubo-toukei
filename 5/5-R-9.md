# 演習問題【5-R-9】

## 解答

温度 $T$ の熱浴に接している二つの系 $\mathrm{I}$ および $\mathrm{II}$ があり，これら二つの系との間で粒子の交換が可能であるとする．
系の全粒子数を $N$ とし，系 $\mathrm{I}$ に属する粒子数を $N_{\mathrm{I}}$ ，系 $\mathrm{II}$ に属する粒子数を $N_{\mathrm{II}}$ とする．
このとき， $N_{\mathrm{I}} + N_{\mathrm{II}} = N$ が成り立つ．

まず，粒子数の分配 $(N_{\mathrm{I}}, N_{\mathrm{II}})$ が起こる確率を求める．
系 $\mathrm{I}$ のエネルギーを $E_{\mathrm{I}}$ ，系 $\mathrm{II}$ のエネルギーを $E_{\mathrm{II}}$ とすると，これら二つの系が熱浴と接しているため，それぞれの系はカノニカル分布に従う．
合成系 $\mathrm{I+II}$ の微視的状態の確率は，ボルツマン因子 $e^{-\beta(E_{\mathrm{I}}+E_{\mathrm{II}})}$ （ただし $\beta = 1/kT$ ）と，それぞれの系が取り得る微視的状態の数 $\Omega_{\mathrm{I}}(E_{\mathrm{I}}, N_{\mathrm{I}})$ および $\Omega_{\mathrm{II}}(E_{\mathrm{II}}, N_{\mathrm{II}})$ の積に比例する．

したがって，合成系 $\mathrm{I+II}$ において，系 $\mathrm{I}$ がエネルギー $E_{\mathrm{I}}$ を持ち，系 $\mathrm{II}$ がエネルギー $E_{\mathrm{II}}$ を持つ微小エネルギー幅 $dE_{\mathrm{I}}, dE_{\mathrm{II}}$ 内の状態が実現される確率密度 $f(E_{\mathrm{I}}, N_{\mathrm{I}}, E_{\mathrm{II}}, N_{\mathrm{II}}, T) \, dE_{\mathrm{I}} \, dE_{\mathrm{II}}$ は次のように書ける：

$$f(E_{\mathrm{I}}, N_{\mathrm{I}}, E_{\mathrm{II}}, N_{\mathrm{II}}, T) \, dE_{\mathrm{I}} \, dE_{\mathrm{II}} = \frac{1}{Z_{\mathrm{I+II}}(N, T)} e^{-\beta(E_{\mathrm{I}}+E_{\mathrm{II}})} \Omega_{\mathrm{I}}(E_{\mathrm{I}}, N_{\mathrm{I}}) \, dE_{\mathrm{I}} \Omega_{\mathrm{II}}(E_{\mathrm{II}}, N_{\mathrm{II}}) \, dE_{\mathrm{II}} \quad \cdots (1)$$

ここで， $Z_{\mathrm{I+II}}(N, T)$ は合成系全体の分配関数である．
粒子数の分配 $(N_{\mathrm{I}}, N_{\mathrm{II}})$ に注目するためには，式(1)をすべての可能なエネルギー $E_{\mathrm{I}}, E_{\mathrm{II}}$ について積分する必要がある．

分配関数の定義 $Z(N, T) = \int e^{-\beta E} \Omega(E, N) \, dE$ を用いると，

$$\int e^{-\beta E_{\mathrm{I}}} \Omega_{\mathrm{I}}(E_{\mathrm{I}}, N_{\mathrm{I}}) \, dE_{\mathrm{I}} = Z_{\mathrm{I}}(N_{\mathrm{I}}, T)$$
$$\int e^{-\beta E_{\mathrm{II}}} \Omega_{\mathrm{II}}(E_{\mathrm{II}}, N_{\mathrm{II}}) \, dE_{\mathrm{II}} = Z_{\mathrm{II}}(N_{\mathrm{II}}, T)$$

となる．
これらを式(1)に代入してエネルギーについて積分すると，粒子数の分配 $(N_{\mathrm{I}}, N_{\mathrm{II}})$ が起こる確率は次のように求められる：

$$f(N_{\mathrm{I}}, N_{\mathrm{II}}) = \frac{Z_{\mathrm{I}}(N_{\mathrm{I}}, T) Z_{\mathrm{II}}(N_{\mathrm{II}}, T)}{Z_{\mathrm{I+II}}(N, T)} \quad (N_{\mathrm{I}} + N_{\mathrm{II}} = N) \quad \cdots (2)$$

ここで， $Z_{\mathrm{I+II}}(N, T)$ は粒子数 $N$ のすべての分配について和をとったものである：

$$Z_{\mathrm{I+II}}(N, T) = \sum_{N_{\mathrm{I}}=0}^{N} Z_{\mathrm{I}}(N_{\mathrm{I}}, T) Z_{\mathrm{II}}(N - N_{\mathrm{I}}, T) \quad \cdots (3)$$

最も確からしい分配 $`(N_{\mathrm{I}}^*, N_{\mathrm{II}}^*)`$ とは，この確率 $`f(N_{\mathrm{I}}, N_{\mathrm{II}})`$ を最大にする粒子数の組み合わせのことである．
すなわち，以下の条件を満たす $N_{\mathrm{I}}$ を求めることと同義である：

```math
Z_{\mathrm{I}}(N_{\mathrm{I}}^*, T) Z_{\mathrm{II}}(N - N_{\mathrm{I}}^*, T) = \text{max.} \quad \cdots (4)
```

次に，これをヘルムホルツの自由エネルギー $F$ を用いて書き換える．
$F = -kT \ln Z$ （または $\ln Z = -\beta F$ ）の関係を用いると，式(4)は次のように書き換えられる：

```math
\ln \left[ Z_{\mathrm{I}}(N_{\mathrm{I}}^*, T) Z_{\mathrm{II}}(N - N_{\mathrm{I}}^*, T) \right] = \ln Z_{\mathrm{I}}(N_{\mathrm{I}}^*, T) + \ln Z_{\mathrm{II}}(N - N_{\mathrm{I}}^*, T) = \text{max.}
```

```math
-\beta F_{\mathrm{I}}(N_{\mathrm{I}}^*, T) - \beta F_{\mathrm{II}}(N - N_{\mathrm{I}}^*, T) = \text{max.}
```

```math
F_{\mathrm{I}}(N_{\mathrm{I}}^*, T) + F_{\mathrm{II}}(N - N_{\mathrm{I}}^*, T) = \text{min.} \quad \cdots (5)
```

したがって，最も確からしい分配は，合成系の自由エネルギー $F_{\mathrm{I}} + F_{\mathrm{II}}$ が最小となる条件として与えられる．
この最小値の条件は，自由エネルギーを粒子数 $N_{\mathrm{I}}$ で微分したものが $0$ になることである：

$$\frac{d}{dN_{\mathrm{I}}} \left[ F_{\mathrm{I}}(N_{\mathrm{I}}, T) + F_{\mathrm{II}}(N - N_{\mathrm{I}}, T) \right] = 0$$

$$\frac{\partial F_{\mathrm{I}}(N_{\mathrm{I}}, T)}{\partial N_{\mathrm{I}}} + \frac{\partial F_{\mathrm{II}}(N - N_{\mathrm{I}}, T)}{\partial N_{\mathrm{II}}} \cdot \frac{dN_{\mathrm{II}}}{dN_{\mathrm{I}}} = 0$$

ここで， $N_{\mathrm{II}} = N - N_{\mathrm{I}}$ より $\frac{dN_{\mathrm{II}}}{dN_{\mathrm{I}}} = -1$ であるから，

$$\frac{\partial F_{\mathrm{I}}(N_{\mathrm{I}}, T)}{\partial N_{\mathrm{I}}} - \frac{\partial F_{\mathrm{II}}(N_{\mathrm{II}}, T)}{\partial N_{\mathrm{II}}} = 0 \implies \frac{\partial F_{\mathrm{I}}}{\partial N_{\mathrm{I}}} = \frac{\partial F_{\mathrm{II}}}{\partial N_{\mathrm{II}}} \quad \cdots (6)$$

化学ポテンシャル $\mu = \frac{\partial F}{\partial N}$ を用いると，求める条件は次のように簡潔に述べられる：

```math
\mu_{\mathrm{I}}(N_{\mathrm{I}}^*, T) = \mu_{\mathrm{II}}(N_{\mathrm{II}}^*, T)
```

以上より，最も確からしい分配を求める条件は，二つの系の化学ポテンシャルが等しくなることである．

## 解説

本問題は，粒子交換が可能な二つの系が熱浴と平衡状態にあるときの，最も確率の高い粒子数の配分（分配）を求めるものである．

統計力学において，ある状態が実現する確率はその状態の微視的状態の数（エントロピーに関連する量）と，熱浴とのエネルギー交換に伴うボルツマン因子に依存する．
本問では粒子数も変化するため，分配関数 $Z(N, T)$ を用いて確率を記述する．

粒子数の分配 $(N_{\mathrm{I}}, N_{\mathrm{II}})$ の確率は，各系が独立にカノニカル分布に従うと仮定したとき，それぞれの系の分配関数の積 $Z_{\mathrm{I}} Z_{\mathrm{II}}$ に比例する．
したがって，この積を最大化することが，最も起こりやすい分配を見つけることにつながる．

自由エネルギー $F = -kT \ln Z$ は，分配関数 $Z$ の対数をとり，温度 $T$ の係数をかけたものである．
$Z$ を最大化することは， $\ln Z$ を最大化することであり，それは $-F/kT$ を最大化すること，すなわち $F$ を最小化することに等しい．

最終的に得られた条件 $\mu_{\mathrm{I}} = \mu_{\mathrm{II}}$ は，熱平衡において温度が等しい（熱的平衡）のと同様に，粒子交換が可能な系においては化学ポテンシャルが等しくなる（化学的平衡）必要があることを示している．
