# 例題【5-R-6】

## 解答

### 1．熱・粒子源との接触と確率の基本式

粒子源および熱源と接触している系を考える．
この系は熱・粒子源とエネルギーおよび粒子を交換できるため，系自身のエネルギー $E$ と粒子数 $N_A$ は一定ではなく，変動しうる．
ここで， $A$ は粒子の種類を表す添字である．
各粒子種の化学ポテンシャルを $\mu_A$ とする．

考える系と熱・粒子源を合わせた全体は孤立しているとする．
熱・粒子源の全エネルギーを $E_t$ ，粒子種 $A$ の粒子数を $N_{A,t}$ とおく．
考える系がエネルギー $E$ ，粒子数 $N_A$ をもつとき，熱・粒子源はエネルギー $E_t-E$ ，粒子数 $N_{A,t}-N_A$ をもつ．

合成系全体のエネルギーと粒子数は一定であるため，考える系が特定の微視状態をとる確率は，その状態が実現したときに熱・粒子源がとることのできる微視状態の数に比例する．
熱・粒子源の状態数を

```math
\Omega_t\left(E_t,\{N_{A,t}\}\right)
```

と表せば，考える系がある微視状態にある確率 $P_r$ は，

```math
P_r\propto
\Omega_t\left(E_t-E,\{N_{A,t}-N_A\}\right)
\tag{1}
```

となる．

ボルツマンの関係式

```math
S_t=k\log\Omega_t
```

を用いると，式 (1) は

```math
P_r\propto
\exp\left[
\frac{1}{k}
S_t\left(E_t-E,\{N_{A,t}-N_A\}\right)
\right]
\tag{2}
```

と書ける．
ここで， $S_t$ は熱・粒子源のエントロピー， $k$ はボルツマン定数である．

### 2．熱・粒子源のエントロピーのテイラー展開

熱・粒子源は考える系に比べて十分に大きいものとする．
すなわち，

```math
E\ll E_t,\qquad N_A\ll N_{A,t}
```

が成り立つと仮定する．
このとき，熱・粒子源のエントロピーを，もとの状態 $\left(E_t,\{N_{A,t}\}\right)$ のまわりでテイラー展開できる．
1次の項まで残すと，

```math
\begin{aligned}
&S_t\left(E_t-E,\{N_{A,t}-N_A\}\right)\\
&\quad\simeq S_t\left(E_t,\{N_{A,t}\}\right)
-E\left(\frac{\partial S_t}{\partial E_t}\right)_{\{N_{A,t}\}}\\
&\qquad
-\sum_A N_A
\left(\frac{\partial S_t}{\partial N_{A,t}}\right)_{E_t,\{N_{B,t}:B\ne A\}}
\end{aligned}
\tag{3}
```

となる．
ここで，粒子数に関する偏微分では，エネルギーと他の粒子種の粒子数を一定に保つ．

熱力学の基本関係式は，

```math
dS_t=\frac{1}{T}dE_t+\frac{P}{T}dV_t
-\sum_A\frac{\mu_A}{T}dN_{A,t}
\tag{4}
```

である．
熱・粒子源の体積を一定に保つと，

```math
\left(\frac{\partial S_t}{\partial E_t}\right)_{V_t,\{N_{A,t}\}}
=\frac{1}{T}
\tag{5}
```

および

```math
\left(\frac{\partial S_t}{\partial N_{A,t}}\right)_{E_t,V_t,\{N_{B,t}:B\ne A\}}
=-\frac{\mu_A}{T}
\tag{6}
```

が得られる．
ここで， $T$ と $\mu_A$ は熱・粒子源の温度と化学ポテンシャルである．

式 (5)，(6) を式 (3) に代入すると，

```math
\begin{aligned}
&S_t\left(E_t-E,\{N_{A,t}-N_A\}\right)\\
&\quad\simeq S_t\left(E_t,\{N_{A,t}\}\right)
-\frac{E}{T}+\sum_A\frac{\mu_A N_A}{T}
\end{aligned}
\tag{7}
```

となる．
したがって，式 (2) より，

```math
\begin{aligned}
P_r
&\propto
\exp\left[
\frac{S_t(E_t,\{N_{A,t}\})}{k}
+\frac{1}{kT}\left(\sum_A\mu_A N_A-E\right)
\right]\\
&\propto
\exp\left[
-\beta\left(E-\sum_A\mu_A N_A\right)
\right]
\end{aligned}
\tag{8}
```

を得る．
ここで，

```math
\beta=\frac{1}{kT}
\tag{9}
```

と定義した．
式 (8) の第1行に含まれる $S_t(E_t,\{N_{A,t}\})$ は，考える系の状態によらない定数であるため，比例定数に吸収した．
また，熱・粒子源が十分に大きいことから，テイラー展開の2次以上の項を無視している．

以上より，考える系がエネルギー $E$ ，各粒子数 $N_A$ をもつ微視状態の確率は，

```math
\boxed{
P_r\propto
\exp\left[
-\beta\left(E-\sum_A\mu_A N_A\right)
\right]
}
\tag{10}
```

で与えられる．
これが以下の古典的および量子的な確率分布の共通の基本形である．

### 3．古典的な場合：式 (5.73a) の導出

古典力学では，系の微視状態は粒子の位置と運動量を指定することで表される．
粒子数が $\{N_A\}$ であるとき，系のハミルトニアンを $H_N(\Gamma)$ とする．
ここで， $\Gamma$ はその粒子数に対応する位相空間の座標全体を表し， $d\Gamma$ は位相空間の微小体積要素である．
この微小体積に対応するエネルギーは $H_N(\Gamma)$ である．

式 (10) において $E=H_N(\Gamma)$ とすれば，

```math
P_r\propto
\exp\left[
-\beta\left(H_N(\Gamma)-\sum_A\mu_A N_A\right)
\right]
\tag{11}
```

となる．
これは，位相空間の各微小領域がもつ確率の重みを与える．

古典的な位相空間積分では，同種粒子の入れ替えによる重複計数を避けるため，粒子種 $A$ ごとに $N_A!$ で割る．
また，位相空間の体積を無次元化するために，プランク定数 $h$ を用いて $h^{3N_A}$ で割る．したがって，確率要素は，

```math
P_r(\{N_A\},d\Gamma)
=\frac{1}{\Theta}
\frac{1}{\displaystyle\prod_A N_A!\,h^{3N_A}}
\exp\left[
-\beta\left(H_N(\Gamma)-\sum_A\mu_A N_A\right)
\right]d\Gamma
\tag{12}
```

となる．
ここで， $\prod_A$ はすべての粒子種についての積を表す．

確率の総和と積分が1になるように，規格化定数 $\Theta$ は

```math
\boxed{
\Theta=
\sum_{\{N_A\}}
\frac{1}{\displaystyle\prod_A N_A!\,h^{3N_A}}
\int d\Gamma\,
\exp\left[
-\beta\left(H_N(\Gamma)-\sum_A\mu_A N_A\right)
\right]
}
\tag{13}
```

と定められる．
和はすべての許される粒子数の組合せについて取り，積分は各組合せに対応する位相空間全体について行う．
この $\Theta$ はグランドカノニカル分配関数である．

式 (12) より，

```math
\boxed{
P_r(\{N_A\},d\Gamma)
=
\frac{1}{\displaystyle\prod_A N_A!\,h^{3N_A}}
\exp\left[
-\beta\left(H_N-\sum_A\mu_A N_A\right)
\right]
\frac{d\Gamma}{\Theta}
}
\tag{5.73a}
```

を得る．
これが古典的な確率分布である．

### 4．量子的な場合：式 (5.73b) の導出

量子力学では，系の微視状態は離散的な量子状態によって指定される．
粒子数の組合せ $\{N_A\}$ に対応する微視状態を $l$ ，その状態のエネルギー固有値を $E_{\{N_A\},l}$ とする．

式 (10) において，エネルギー $E$ をその状態のエネルギー固有値 $E_{\{N_A\},l}$ に置き換えると，

```math
P_r(\{N_A\},l)
\propto
\exp\left[
-\beta\left(E_{\{N_A\},l}-\sum_A\mu_A N_A\right)
\right]
\tag{14}
```

となる．
量子系では，許されるすべての微視状態についてこの確率を足し合わせる．
したがって，規格化定数は，

```math
\boxed{
\Theta=
\sum_{\{N_A\}}\sum_l
\exp\left[
-\beta\left(E_{\{N_A\},l}-\sum_A\mu_A N_A\right)
\right]
}
\tag{15}
```

である．
内側の和は，指定された粒子数の組合せに対して許されるすべての量子状態 $l$ について取る．
この規格化定数を用いれば，

```math
\boxed{
P_r(\{N_A\},l)
=
\frac{
\exp\left[
-\beta\left(E_{\{N_A\},l}-\sum_A\mu_A N_A\right)
\right]
}{\Theta}
}
\tag{5.73b}
```

を得る．
これが量子的な確率分布である．

量子系では，粒子の状態が離散的な微視状態として数えられるため，式 (5.73b) には位相空間の微小体積 $d\Gamma$ や，古典的な積分に用いる $N_A!\,h^{3N_A}$ の因子は現れない．
粒子の区別不能性などは，量子状態を数え上げる際に適切に扱われている．

### 結論

熱・粒子源のエントロピーを1次までテイラー展開し，

```math
\left(\frac{\partial S}{\partial E}\right)_{V,\{N_A\}}=\frac{1}{T},
\qquad
\left(\frac{\partial S}{\partial N_A}\right)_{E,V,\{N_{B}:B\ne A\}}
=-\frac{\mu_A}{T}
```

を用いると，系の微視状態に対する確率の重みは，

```math
P_r\propto
\exp\left[
-\beta\left(E-\sum_A\mu_A N_A\right)
\right]
```

となる．
この重みを古典系では位相空間積分で，量子系では離散的な量子状態の和で規格化することで，それぞれ式 (5.73a) と式 (5.73b) が導かれる．
