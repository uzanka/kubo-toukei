# 演習問題【5-A-24】

## 解答

### 1．制約条件とラグランジュ関数

系がエネルギー $E_s$ の状態 $s$ にある確率を $p_s$ とする．
エントロピーは

```math
S=-k\sum_s p_s\ln p_s
```

で定義される．
ここで $k$ はボルツマン定数である．

確率 $p_s$ は，次の2つの制約条件を満たさなければならない．

```math
\sum_s p_s=1
\tag{1}
```

```math
\sum_s E_sp_s=E
\tag{2}
```

式 (1) は確率の総和が1であることを，式 (2) は平均エネルギーが指定された値 $E$ であることを表している．

これらの制約条件のもとでエントロピー $S$ を最大化するため，ラグランジュの未定乗数法を用いる．
未定乗数を $\lambda$ ， $\kappa$ とし，ラグランジュ関数を

```math
L
=-k\sum_s p_s\ln p_s
+\lambda\left(\sum_s p_s-1\right)
-\kappa\left(\sum_s E_sp_s-E\right)
\tag{3}
```

と定義する．
ここでは，エネルギーの制約項にマイナス符号を付けている．
この符号の選び方によって，後で導入する逆温度を正の量として定義できる．

### 2．エントロピーを最大にする確率分布

各確率 $p_s$ を独立な変数として，ラグランジュ関数を $p_s$ で偏微分する．
極値条件は

```math
\frac{\partial L}{\partial p_s}=0
```

である．
式 (3) を微分すると，

```math
-k(\ln p_s+1)+\lambda-\kappa E_s=0
```

となる．
これを $\ln p_s$ について整理すれば，

```math
\ln p_s=\frac{\lambda}{k}-1-\frac{\kappa}{k}E_s
```

を得る．
両辺の指数を取ると，

```math
p_s=e^{\lambda/k-1}
e^{-\kappa E_s/k}
\tag{4}
```

となる．

ここで，

```math
\beta=\frac{\kappa}{k}
```

とおくと，式 (4) は

```math
p_s=e^{\lambda/k-1}e^{-\beta E_s}
\tag{5}
```

と書ける．

この停留点がエントロピーの極大を与えることも確認する．
エントロピーの二階微分は，

```math
\frac{\partial^2 S}{\partial p_s^2}
=-\frac{k}{p_s}<0
\qquad(p_s>0)
```

である．
したがって，エントロピーは確率 $p_s$ の関数として厳密に凹である．
制約条件 (1)，(2) は確率について線形であるため，停留点が存在すれば，それは制約条件を満たす確率分布の中でエントロピーを最大にする点である．

### 3．規格化条件から分配関数を求める

式 (5) に確率の規格化条件 $\sum_s p_s=1$ を適用すると，

```math
1=e^{\lambda/k-1}\sum_s e^{-\beta E_s}
```

となる．
ここで，分配関数 $Z(\beta)$ を

```math
\boxed{
Z(\beta)=\sum_s e^{-\beta E_s}
}
\tag{6}
```

と定義する．
すると，

```math
e^{\lambda/k-1}=\frac1{Z(\beta)}
```

である．
これを式 (5) に代入すれば，

```math
\boxed{
p_s=\frac{e^{-\beta E_s}}{Z(\beta)}
}
\tag{7}
```

を得る．
これがカノニカル分布である．

### 4．逆温度と平均エネルギーの関係

通常の系では，エネルギーが上限を持たない場合，分配関数 $Z(\beta)$ が収束するためには $\beta>0$ が必要である．
そこで，

```math
\beta=\frac1{kT}
```

と同定すると，式 (7) は

```math
\boxed{
p_s=\frac{e^{-E_s/(kT)}}{Z}
}
```

となる．
ここで，

```math
\boxed{
Z=\sum_s e^{-E_s/(kT)}
}
```

は温度 $T$ におけるカノニカル分配関数である．

最後に，未定乗数 $\beta$ は平均エネルギーの制約条件によって決まる．
実際，式 (6) を用いると，

```math
\begin{aligned}
\sum_s E_sp_s
&=\frac{\sum_s E_se^{-\beta E_s}}{Z}\\
&=-\frac{\partial\ln Z}{\partial\beta}
\end{aligned}
```

となる．
したがって，指定された平均エネルギー $E$ に対して，

```math
\boxed{
E=-\frac{\partial\ln Z}{\partial\beta}
}
```

を満たす $\beta$ を選べばよい．

以上より，確率の規格化条件と平均エネルギーの制約条件のもとでエントロピーを最大にする確率分布は，

```math
\boxed{
p_s=\frac{e^{-E_s/(kT)}}{Z}
}
```

であり，カノニカル分布であることが示された．
