# 演習問題【5-A-5】

## 解答

**(i) 位相空間における軌道**

この質点は $0 \le x \le l$ の範囲に閉じ込められており，壁 $x=0$ および $x=l$ で弾性衝突（跳ね返り）を行う．
弾性衝突では運動量の大きさ $|p|$ が変化しないため，質点の運動量は正の向きに運動しているときは $p$ ，負の向きに運動しているときは $-p$ となる．
したがって，位相空間 $(x, p)$ における軌道は，以下の2本の直線になる．
- $p = p_0$ （定数）かつ $0 \le x \le l$
- $p = -p_0$ （定数）かつ $0 \le x \le l$
（ここで $p_0$ は運動量の大きさである）

**(ii) 位相空間の体積 ( $\Gamma_0(E)$ )**

エネルギー $E$ は，質点の運動量 $p$ を用いて次のように表される．

$$E = \frac{p^2}{2m}$$

これより，運動量の大きさ $p$ はエネルギー $E$ に対して $p = \sqrt{2mE}$ となり，単調増加する．
エネルギー $E$ 以下の位相空間の体積 $\Gamma_0(E)$ は，位相空間における積分によって求められる．

$$\Gamma_0(E) = \int_{0}^{l} dx \int_{-p}^{p} dp = \int_{0}^{l} dx \cdot [p - (-p)] = \int_{0}^{l} 2p \, dx = 2pl$$

ここで $p = \sqrt{2mE}$ を代入すると，

$$\Gamma_0(E) = 2l\sqrt{2mE}$$

となる．

**(iii) 断熱不変性**

壁 $x=l$ が速度 $u$ で動いている場合を考える．
壁との弾性衝突において，壁の速度を $u$ ，衝突前の質点の速度を $v = p/m$ ，衝突後の質点の速度を $v' = p'/m$ とすると，衝突の前後でエネルギーと運動量が保存される（あるいは，壁から見た速度の反転）ことから，以下の関係が成り立つ．

$$\frac{p}{m} - u = -\left(\frac{p'}{m} - u\right) \quad \text{（壁から見た速度の反転）}$$

整理すると，

$$\frac{p}{m} - u = -\frac{p'}{m} + u \implies \frac{p'}{m} = \frac{p}{m} - 2u \implies p' = p - 2mu$$

となる．
つまり，1回の衝突によって運動量の大きさは $p$ から $p - 2mu$ へと減少する．

次に，壁の位置が $\delta l$ だけ移動するのにかかる時間 $\delta t$ を考える．

$$\delta t = \frac{\delta l}{u}$$

この時間内に質点が壁と衝突する回数 $N$ を求める．
質点が $x=0$ と $x=l$ の間を往復する周期は $T = \frac{2l}{p/m} = \frac{2ml}{p}$ である．
よって，衝突頻度（1単位時間あたりの衝突回数）は $f = \frac{1}{T} = \frac{p}{2ml}$ である（片側の壁のみをカウントする場合）．
$\delta t$ の間に起こる衝突回数 $N$ は，

$$N = \delta t \cdot f = \frac{\delta l}{u} \cdot \frac{p}{2ml} = \frac{p \delta l}{2mul}$$

となる．
この衝突の結果，運動量の大きさは合計で $\delta p$ だけ変化する．

$$\delta p = N \cdot (p - p') = \frac{p \delta l}{2mul} \cdot (2mu) = \frac{p \delta l}{l}$$

（※解答例では $\delta p = -p \delta l/l$ とされているが，これは $p$ が減少することを考慮した符号である．
大きさの変化として考える．）

ここで，位相空間の体積に関係する量 $pl$ の変化を調べる．

$$\delta(pl) = p \delta l + l \delta p = p \delta l + l \left(-\frac{p \delta l}{l}\right) = p \delta l - p \delta l = 0$$

したがって， $\delta(pl) = 0$ であり，(ii) で求めた $\Gamma_0(E) = 2l p$ が不変であることが示された．

$$\delta \Gamma_0(E) = 2 \delta(pl) = 0$$

これが断熱不変性である．

**(iv) 量子力学的な状態数 ( $\Omega_0(E)$ )**

シュレーディンガー方程式は次のように与えられる．

$$-\frac{\hbar^2}{2m} \frac{d^2}{dx^2} \psi(x) = E \psi(x)$$

この方程式の一般解は，

$$\psi(x) = A \sin\left(\frac{\sqrt{2mE}}{\hbar}x\right) + B \cos\left(\frac{\sqrt{2mE}}{\hbar}x\right)$$

である．
境界条件 $\psi(0) = 0$ より $B = 0$ ．
また， $\psi(l) = 0$ より，

$$\sin\left(\frac{\sqrt{2mE}}{\hbar}l\right) = 0 \implies \frac{\sqrt{2mE}}{\hbar}l = n\pi \quad (n = 1, 2, 3, \dots)$$

したがって，固有エネルギー $E_n$ は，

$$E_n = \frac{\hbar^2 \pi^2 n^2}{2ml^2} = \frac{(h/2\pi)^2 \pi^2 n^2}{2ml^2} = \frac{h^2}{8ml^2}n^2$$

となる．
エネルギー $E$ 以下の量子状態の数 $\Omega_0(E)$ は，

$$\Omega_0(E) = \sum_{E_n \le E} 1$$

$E_n \le E$ を $n$ について解くと，

$$n^2 \le \frac{8ml^2 E}{h^2} \implies n \le \sqrt{\frac{8ml^2 E}{h^2}}$$

よって，

$$\Omega_0(E) = \left[ \sqrt{\frac{8ml^2 E}{h^2}} \right]$$

となる（ $[\cdot]$ はガウス記号，すなわち最大整数を表す）．

ここで，(ii) の結果 $\Gamma_0(E) = 2l\sqrt{2mE}$ を用いて比較する．
$\hbar = h / (2\pi)$ を用いると，

$$\sqrt{\frac{8ml^2 E}{h^2}} = \sqrt{\frac{8ml^2 E}{(2\pi\hbar)^2}} = \sqrt{\frac{2ml^2 E}{\pi^2 \hbar^2}} = \frac{l}{\pi\hbar} \sqrt{2mE}$$

一方，

$$\frac{\Gamma_0(E)}{h} = \frac{2l\sqrt{2mE}}{h} = \frac{2l\sqrt{2mE}}{2\pi\hbar} = \frac{l}{\pi\hbar} \sqrt{2mE}$$

となる．
したがって，エネルギー $E$ が十分に大きいとき，

$$\Omega_0(E) \approx \frac{\Gamma_0(E)}{h}$$

となり，古典的な位相空間の体積をプランク定数 $h$ で割った値と量子力学的な状態数が一致することがわかる．

## 解説

この問題は，古典統計力学における「位相空間の体積」という概念と，量子力学における「状態数」という概念が，プランク定数 $h$ を介してどのように結びついているかを示している．

### 1.  古典的な視点

粒子の状態は位置 $x$ と運動量 $p$ の組として記述され，その可能な範囲が「位相空間」である．
エネルギーが一定の条件下でのこの範囲の広さが $\Gamma(E)$ である．

### 2.  量子力学的な視点

状態は離散的なエネルギー準位 $E_n$ としてカウントされる．

### 3.  対応原理

古典力学と量子力学が一致する極限（エネルギーが十分に高い，あるいは系のサイズが大きい場合）において，量子的な状態数は，古典的な位相空間の体積をプランク定数 $h$ で割ったものに近似される．
これは，プランク定数 $h$ が位相空間における「1つの状態が占める最小の体積」のような役割を果たしていることを示唆している．

### 4.  断熱不変性

壁をゆっくり動かす（断熱的に変化させる）とき，系のエネルギーは変化するが，位相空間の体積 $\Gamma(E)$ は変化しない．
これは，準古典的な状態数が変化しないこととも深く関連している．
