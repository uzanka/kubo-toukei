# 例題【5-R-1】

## 解答

### 1．1個の分子が壁に与える力積

一辺の長さが $L$ の立方体容器に，質量 $m$ の気体分子が $N$ 個入っているとする．
容器の体積を $V=L^3$ ，壁の面積を $A=L^2$ とする．
座標軸 $x,y,z$ は容器の辺に平行に取る．
また，分子と壁との衝突は完全弾性的であり，分子間の相互作用は無視できると仮定する．

まず，1個の分子に着目する．
分子の速度を

```math
\boldsymbol v=(v_x,v_y,v_z)
```

とすると，その $x$ 方向の運動量は $mv_x$ である．
$x$ 軸に垂直な壁に分子が衝突すると，完全弾性反射によって速度の $x$ 成分の符号だけが反転する．
したがって，衝突前後の分子の $x$ 方向の運動量変化の大きさは，

```math
|\Delta p_x|=|(-mv_x)-(mv_x)|=2m|v_x|
```

である．
作用反作用の法則より，分子が壁に与える力積の大きさも $2m|v_x|$ となる．

### 2．1個の分子の衝突頻度と圧力への寄与

次に，この分子が同じ壁に衝突する頻度を求める．
分子が同じ壁に再び衝突するまでには，容器の長さ $L$ を往復する必要がある．
その間に分子が進む $x$ 方向の距離は $2L$ であるから，衝突間の時間は

```math
\Delta t=\frac{2L}{|v_x|}
```

となる．
したがって，単位時間当たりに同じ壁に衝突する回数は，

```math
f=\frac{1}{\Delta t}=\frac{|v_x|}{2L}
```

である．

1回の衝突で壁に与える力積は $2m|v_x|$ であるため，単位時間当たりに壁へ与える力積の大きさ，すなわちこの分子が壁に及ぼす平均の力は，

```math
\begin{aligned}
F_i
&=(2m|v_x|)\frac{|v_x|}{2L}\\
&=\frac{mv_x^2}{L}
\end{aligned}
```

となる．
圧力は壁に垂直な力を壁の面積で割った量であるから，この分子の圧力への寄与は，

```math
p_i=\frac{F_i}{A}
=\frac{mv_x^2}{L^3}
=\frac{mv_x^2}{V}
```

である．
ここで $V=L^3$ を用いた．

### 3．全分子の寄与を合計する

気体全体の圧力は，すべての分子が壁に与える力の寄与を足し合わせ，壁の面積で割ることによって求められる．
各分子の $x$ 方向速度を $v_{x,1},v_{x,2},\ldots,v_{x,N}$ とすると，

```math
p=\sum_{i=1}^{N}p_i
=\frac{m}{V}\sum_{i=1}^{N}v_{x,i}^2
```

となる．
ここで，圧力の式はすでに壁の面積で割った各分子の寄与を合計している．

分子1個当たりの平均を表す記号を用いて，

```math
\overline{v_x^2}
=\frac1N\sum_{i=1}^{N}v_{x,i}^2
```

と定義する．
また，単位体積当たりの平均分子数は

```math
n=\frac NV
```

である．
これらを用いると，圧力は

```math
\boxed{p=nm\overline{v_x^2}}
\tag{1}
```

と書ける．

### 4．速度の等方性を用いる

気体が平衡状態にあり，特定の方向が優先されないと仮定する．
このような速度分布を等方的という．
等方性により，3つの座標方向の二乗速度の平均は等しく，

```math
\overline{v_x^2}
=\overline{v_y^2}
=\overline{v_z^2}
```

が成り立つ．

一方，分子の速さの二乗は

```math
v^2=v_x^2+v_y^2+v_z^2
```

である．
両辺の平均を取ると，

```math
\overline{v^2}
=\overline{v_x^2}
+\overline{v_y^2}
+\overline{v_z^2}
=3\overline{v_x^2}
```

となる．
したがって，

```math
\boxed{\overline{v_x^2}=\frac13\overline{v^2}}
\tag{2}
```

である．
式 (2) を式 (1) に代入すると，

```math
p=\frac13 nm\overline{v^2}
\tag{3}
```

を得る．

### 5．平均運動エネルギーで表す

分子1個当たりの並進運動エネルギーは，

```math
\epsilon=\frac12 mv^2
```

である．
分子1個当たりの平均運動エネルギーを $\bar{\epsilon}$ とすれば，

```math
\bar{\epsilon}
=\frac12m\overline{v^2}
```

であるから，

```math
m\overline{v^2}=2\bar{\epsilon}
```

となる．
これを式 (3) に代入すると，

```math
p=\frac13 n(2\bar{\epsilon})
```

を得る．
よって，

```math
\boxed{
p=\frac23 n\bar{\epsilon}
}
```

が導かれる．
これが Bernoulli の公式である．

結論として，気体の圧力は，単位体積当たりの平均分子数 $n$ と分子1個当たりの平均運動エネルギー $\bar{\epsilon}$ の積の $2/3$ 倍である．
この結果は，分子と壁との完全弾性衝突，分子間相互作用の無視，および気体の速度分布の等方性を仮定して得られるものである．
