# 演習問題【5-R-1】

## 解答

### 1. 壁に衝突する分子の力積

一辺の長さが $L$ ，面積が $A$ の容器を考え，気体分子の質量を $m$ ，速度を $\mathbf v=(v_x,v_y,v_z)$ とする．

$x$ 軸に垂直な壁に，速度の $x$ 成分が $v_x$ の分子が弾性衝突するとき，衝突前後の運動量の変化は

```math
\Delta p_x=mv_x-(-mv_x)=2mv_x
```

である．
これは分子が壁に与える力積の大きさでもある．

### 2. 単位時間あたりの衝突数

分子が単位時間に壁へ到達するためには，壁から距離 $v_x\Delta t$ 以内にいる必要がある（ $v_x>0$ の分子を考える）．

したがって，速度が $\mathbf v$ の分子の数密度を $n_{\mathbf v}$ とすると，時間 $\Delta t$ に壁へ衝突する分子数は

```math
n_{\mathbf v}A v_x\Delta t
```

である．
この分子群が壁に与える力積の合計は

```math
\Delta I_x =(2mv_x)n_{\mathbf v}A v_x\Delta t =2mn_{\mathbf v}A v_x^2\Delta t.
```

よって，この分子群が壁に及ぼす力は

```math
F_x=\frac{\Delta I_x}{\Delta t} =2mn_{\mathbf v}A v_x^2.
```

### 3. 全分子の寄与を合計する

すべての分子について和を取ると，壁に働く圧力 $p=F_x/A$ は

```math
p=\frac{F_x}{A} =\frac{m}{V}\sum_{i=1}^{N}v_{x,i}^2
```

となる．
ここで，容器の体積を $V$ ，分子数を $N$ とした．

単位体積あたりの平均分子数 $n=N/V$ と，速度成分の平均

```math
\overline{v_x^2} =\frac1N\sum_{i=1}^{N}v_{x,i}^2
```

を使えば，

```math
p=nm\overline{v_x^2}.
```

気体が方向によらず同じ性質を持つ（等方的である）とすると，

```math
\overline{v_x^2} =\overline{v_y^2} =\overline{v_z^2}.
```

したがって，

```math
\overline{v^2} =\overline{v_x^2+v_y^2+v_z^2} =3\overline{v_x^2},
```

すなわち

```math
\overline{v_x^2}=\frac13\overline{v^2}.
```

これを圧力の式に代入すると，

```math
p=\frac13 nm\overline{v^2}.
```

### 4. 平均運動エネルギーで表す

分子1個当たりの平均並進運動エネルギーは

```math
\bar{\epsilon}=\frac12m\overline{v^2}
```

である．
したがって，

```math
m\overline{v^2}=2\bar{\epsilon}.
```

これを圧力の式に代入すれば，

```math
p=\frac13 n(2\bar{\epsilon}).
```

よって，

```math
\boxed{p=\frac23 n\bar{\epsilon}}
```

が得られる．
これが Bernoulli の公式 である．

結論： 気体の圧力は，単位体積当たりの分子数と，分子1個当たりの平均運動エネルギーの積の $2/3$ 倍に等しい．
導出では，壁との弾性衝突，運動の等方性，および十分な数の分子についての時間平均を仮定した．
