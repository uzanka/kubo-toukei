# 演習問題【5-R-1】

## 解答

気体が器壁におよぼす圧力 $p$ を，気体分子の運動量と衝突の観点から導出する．

まず，容器を辺の長さ $l$ の立方体とし，その体積を $V = l^3$ とする．
また，直交座標系 $(x, y, z)$ を容器の辺に平行にとる．
容器内には $N$ 個の気体分子が存在し，それぞれの分子の質量を $m$ ，運動量を $`\boldsymbol{p}_i = (p_{ix}, p_{iy}, p_{iz})`$ とすると，分子 $i$ の運動エネルギー $\epsilon_i$ は次のように書ける．

$$\epsilon_i = \frac{|\boldsymbol{p}_i|^2}{2m} = \frac{p_{ix}^2 + p_{iy}^2 + p_{iz}^2}{2m}$$

気体分子全体の平均運動エネルギー $\bar{\epsilon}$ は，全分子の運動エネルギーの平均であるから，

$$N\bar{\epsilon} = \sum_{i=1}^N \epsilon_i = \sum_{i=1}^N \frac{p_{ix}^2 + p_{iy}^2 + p_{iz}^2}{2m}$$

となる．

次に，ある一つの分子が $x$ 軸に垂直な壁に衝突する場合を考える．
壁は完全になめらかであり，衝突は完全弾性衝突であると仮定する．
このとき，壁との衝突によって運動量の $x$ 成分 $p_x$ は $p_x \to -p_x$ と変化するが，その大きさ $|p_x|$ は不変である．
この衝突によって壁に与えられる力積は， $p_x$ の変化量であることから，

$$\Delta P_x = (-p_x) - p_x = -2p_x$$

である．
壁の法線方向（外向き）を正とすれば，壁が受ける力積は $2|p_x|$ となる．

この分子が単位時間あたりに $x$ 軸に垂直な壁に衝突する回数を求める．
分子が $x$ 軸方向に移動する速度は $v_x = p_x / m$ である．
一回の衝突の間に分子が壁に近づく距離は， $x$ 軸方向の壁の間隔 $l$ に対して，壁のどちら側にいるかによって変わるが，平均的には $2l$ ごとに一回衝突するとみなせる（一回の衝突後，反対側の壁に当たるまで $2l$ 移動する）．
したがって，単位時間あたりの衝突回数は $\frac{|v_x|}{2l} = \frac{|p_x|}{2ml}$ である．

単位時間あたりの力積の和（平均的な力 $F_x$ ）は，

$$F_x = (2|p_x|) \times \frac{|p_x|}{2ml} = \frac{p_x^2}{ml}$$

となる．
この力 $F_x$ は，器壁の面積 $l^2$ に作用しているため，その壁における圧力への寄与 $p_x$ は，

$$p_x = \frac{F_x}{l^2} = \frac{p_x^2}{ml^3} = \frac{p_x^2}{mV}$$

である．

器壁全体での圧力を求めるには，各分子の寄与をすべて足し合わせる．
$ x $ 軸に垂直なある一つの壁に対する単位時間あたりの力 $ F_x $ は，全分子による力積の総和として得られる．

$$F_x = \sum_{i=1}^N \frac{p_{ix}^2}{ml}$$

圧力 $p$ は，この力 $F_x$ を壁の面積 $l^2$ で割ったものであるから，

$$p = \frac{F_x}{l^2} = \sum_{i=1}^N \frac{p_{ix}^2}{ml^3} = \frac{1}{mV} \sum_{i=1}^N p_{ix}^2$$

同様に， $y$ 成分， $z$ 成分についても，

$$p = \frac{1}{mV} \sum_{i=1}^N p_{iy}^2, \quad p = \frac{1}{mV} \sum_{i=1}^N p_{iz}^2$$

となる．
これら 3 つの圧力は等しく，その平均をとると，

$$p = \frac{1}{3} \left( \frac{1}{mV} \sum_{i=1}^N p_{ix}^2 + \frac{1}{mV} \sum_{i=1}^N p_{iy}^2 + \frac{1}{mV} \sum_{i=1}^N p_{iz}^2 \right)$$

$$p = \frac{1}{3mV} \sum_{i=1}^N (p_{ix}^2 + p_{iy}^2 + p_{iz}^2)$$

ここで，運動エネルギー $\epsilon_i = \frac{p_{ix}^2 + p_{iy}^2 + p_{iz}^2}{2m}$ を用いると， $p_{ix}^2 + p_{iy}^2 + p_{iz}^2 = 2m\epsilon_i$ であるから，

$$p = \frac{1}{3mV} \sum_{i=1}^N 2m\epsilon_i = \frac{2}{3V} \sum_{i=1}^N \epsilon_i$$

全分子の運動エネルギーの平均を $\bar{\epsilon} = \frac{1}{N} \sum_{i=1}^N \epsilon_i$ とすると， $\sum_{i=1}^N \epsilon_i = N\bar{\epsilon}$ である．
したがって，

$$p = \frac{2}{3V} N\bar{\epsilon} = \frac{2}{3} \frac{N}{V} \bar{\epsilon}$$

ここで， $n = N/V$ は単位体積中の平均分子数であるから，

$$p = \frac{2}{3} n\bar{\epsilon}$$

が導かれる．

## 解説

この問題は，気体分子運動論の最も基本的な結果の一つである Bernoulli の公式（あるいは理想気体の状態方程式に関連する関係式）を，微視的な分子の衝突モデルから導出するものである．

導出のポイントは以下の通りである．

1. **衝突による力積の理解**：
   分子が壁に衝突して跳ね返るとき，その運動量の変化（力積）が壁に圧力を与えることを理解する必要がある．
   完全弾性衝突では，速度の大きさは変わらず向きだけが反転するため，力積は速度の $2$ 倍になる．

2. **統計的な平均化**：
   個々の分子はバラバラな速度で動いているが，圧力という物理量はマクロな量であるため，多数の分子による衝突の「時間的平均」および「空間的な平均」を考える．

3. **次元の整合性**：
   力の成分 $F_x$ を求め，それを壁の面積 $l^2$ で割ることで圧力 $p$ を導くプロセスにおいて，体積 $V = l^3$ と面積 $l^2$ の関係が正しく扱われているかが重要である．

4. **運動エネルギーとの結びつき**：
   最終的に，力学的な運動量 $p_i$ の二乗の和を，熱力学的な量である運動エネルギー $\epsilon_i$ の形に書き換えることで，マクロな状態量としての圧力との関係が示される．

このプロセスを理解することで，ミクロな粒子の運動がどのようにしてマクロな圧力という現象として現れるのか，その橋渡しを学ぶことができる．
