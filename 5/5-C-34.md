# 演習問題【5-C-34】

## 解答

統計力学において，系の状態は位相空間（運動量 $p$ と座標 $q$ の空間）における点として表される．
ハミルトニアン $\mathcal{H}(p, q, x)$ は，その点における系のエネルギーを表し， $x$ は系の外部パラメータ（例えば体積など）である．
あるエネルギー $E$ とパラメータ $x$ に対して，ハミルトニアンの値が $E$ 以下となる位相空間の領域の体積を $\Omega_0(E, x)$ と定義する．

準静的断熱過程とは，外部パラメータ $x$ が非常にゆっくりと変化する過程のことである．
このとき，系は常に平衡状態にあるとみなすことができ，エネルギー $E$ もパラメータ $x$ の変化に伴って変化する．
この過程において， $\Omega_0(E, x)$ が不変であることを示す．

まず，パラメータ $x$ が $x + dx$ に変化したときの $\Omega_0(E, x)$ の全微分 $d\Omega_0$ を考える．
エネルギー $E$ の変化 $dE$ とパラメータ $x$ の変化 $dx$ を考慮すると，次のように書ける：

$$d\Omega_0 = \Omega_0(E + dE, x + dx) - \Omega_0(E, x) = \left( \frac{\partial\Omega_0}{\partial E} \right)_x dE + \left( \frac{\partial\Omega_0}{\partial x} \right)_E dx \quad \cdots (1)$$

ここで，第1項はエネルギー $E$ の変化による体積の変化を，第2項はパラメータ $x$ の変化による体積の変化を表している．

次に，この過程におけるエネルギーの変化 $dE$ を求める．
ハミルトニアンの全微分は，

$$d\mathcal{H} = \frac{\partial\mathcal{H}}{\partial p} dp + \frac{\partial\mathcal{H}}{\partial q} dq + \frac{\partial\mathcal{H}}{\partial x} dx$$

である．
ハミルトンの運動方程式 $\dot{p} = -\frac{\partial\mathcal{H}}{\partial q}$ および $\dot{q} = \frac{\partial\mathcal{H}}{\partial p}$ を用いると，エネルギーの時間変化 $\frac{d\mathcal{H}}{dt}$ は，

$$\frac{d\mathcal{H}}{dt} = \frac{\partial\mathcal{H}}{\partial p} \dot{p} + \frac{\partial\mathcal{H}}{\partial q} \dot{q} + \frac{\partial\mathcal{H}}{\partial x} \dot{x} = \left( \frac{\partial\mathcal{H}}{\partial p} \left(-\frac{\partial\mathcal{H}}{\partial q}\right) + \frac{\partial\mathcal{H}}{\partial q} \left(\frac{\partial\mathcal{H}}{\partial p}\right) \right) + \frac{\partial\mathcal{H}}{\partial x} \dot{x} = \frac{\partial\mathcal{H}}{\partial x} \dot{x}$$

となる．
ここで $X = \frac{\partial\mathcal{H}}{\partial x}$ とおくと， $\frac{d\mathcal{H}}{dt} = X \dot{x}$ である．
準静的な過程では， $x$ が時間 $\tau$ にわたって一様に変化すると考えてよいので， $dE$ は次のように計算できる：

$$dE = \int_0^\tau \frac{d\mathcal{H}}{dt} dt = \int_0^\tau X \dot{x} dt = \dot{x} \int_0^\tau X dt = \langle X \rangle_{\text{時間平均}} dx \quad \cdots (2)$$

エルゴード定理により，この時間平均は位相平均 $\langle X \rangle_{\text{位相平均}}$ に等しい：

$$\langle X \rangle_{\text{時間平均}} = \langle X \rangle_{\text{位相平均}} = \frac{\int_{\mathcal{H}=E} \frac{X}{|\text{grad } \mathcal{H}|} d\sigma}{\int_{\mathcal{H}=E} \frac{d\sigma}{|\text{grad } \mathcal{H}|}} \quad \cdots (3)$$

これより， $dE = \frac{\int_{\mathcal{H}=E} \frac{X}{|\text{grad } \mathcal{H}|} d\sigma}{\int_{\mathcal{H}=E} \frac{d\sigma}{|\text{grad } \mathcal{H}|}} dx$ を得る．

次に， $\Omega_0$ の変化を幾何学的に考える．
表面 $S_1 : \mathcal{H}(p, q, x) = E$ の一点 A に立てた法線を $\boldsymbol{n}$ とする．
エネルギーが $E$ から $E + dE$ へ変化したとき，エネルギー面は $S_1$ から $S_2 : \mathcal{H}(p, q, x) = E + dE$ へ移動する．
このとき，点 A における法線方向に沿った移動距離を $\overline{AB}$ とすると， $\overline{AB} \text{ grad } \mathcal{H} = dE$ と書ける．
同様に，パラメータ $x$ が $x + dx$ へ変化したとき，エネルギー面は $S_1$ から $S_3 : \mathcal{H}(p, q, x + dx) = E$ へ移動する．
このとき，法線方向に沿った移動距離を $\overline{AC}$ とすると， $\overline{AC} \text{ grad } \mathcal{H} = -X dx$ と書ける．
これより， $S_1$ と $S_2$ の間に挟まれた体積 $(\partial\Omega_0/\partial E) dE$ と， $S_1$ と $S_3$ の間に挟まれた体積 $(\partial\Omega_0/\partial x) dx$ は，それぞれ次のように表される：

$$\frac{\partial\Omega_0}{\partial E} dE = dE \int_{\mathcal{H}=E} \frac{d\sigma}{|\text{grad } \mathcal{H}|}, \quad \frac{\partial\Omega_0}{\partial x} dx = - dx \int_{\mathcal{H}=E} \frac{X}{|\text{grad } \mathcal{H}|} d\sigma \quad \cdots (4)$$

これらを式(1)に代入すると，

$$d\Omega_0 = \left( \int_{\mathcal{H}=E} \frac{d\sigma}{|\text{grad } \mathcal{H}|} \right) dE - \left( \int_{\mathcal{H}=E} \frac{X}{|\text{grad } \mathcal{H}|} d\sigma \right) dx$$

ここで，式(3)より得られる $dE$ を代入すると，

$$d\Omega_0 = \left( \int_{\mathcal{H}=E} \frac{d\sigma}{|\text{grad } \mathcal{H}|} \right) \left( \frac{\int_{\mathcal{H}=E} \frac{X}{|\text{grad } \mathcal{H}|} d\sigma}{\int_{\mathcal{H}=E} \frac{d\sigma}{|\text{grad } \mathcal{H}|}} \right) dx - \left( \int_{\mathcal{H}=E} \frac{X}{|\text{grad } \mathcal{H}|} d\sigma \right) dx = 0$$

となる．
したがって， $d\Omega_0 = 0$ であるから， $\Omega_0(E, x)$ は不変である．

## 解説

この問題は，統計力学における「断熱不変量」の概念を扱っている．
準静的な断熱過程では，系が外部から仕事をされることによりエネルギーが変化するが，エントロピー（あるいは位相空間の体積 $\Omega_0$ ）は変化しないという性質がある．

ポイントは以下の3点である：
1. **エネルギーの変化とパラメータの変化の関係** ：
  ハミルトンの運動方程式により，エネルギーの変化はハミルトニアンのパラメータ $x$ による微分 $X = \partial \mathcal{H}/\partial x$ に依存する．
2. **エルゴード仮説** ：
  系の時間的な平均挙動が，位相空間全体の空間的な平均挙動と一致するという仮定を用いることで，複雑な時間積分を位相空間上の積分へと変換している．
3. **幾何学的な解釈** ：
  $\Omega_0$ の変化を，エネルギー面（ハミルトニアンが一定の面）の微小な移動として捉えることで，微分（偏微分）を面積分として具体的に記述している．

このように，エネルギーの変化による体積の増減と，パラメータの変化による体積の増減が互いに打ち消し合うことで， $\Omega_0$ が一定に保たれることが示される．
