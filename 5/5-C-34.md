# 演習問題【5-C-34】

## 解答

### 1．証明の方針

ハミルトニアン $\mathcal H(p,q,x)$ は，位相空間の点 $(p,q)$ と外部パラメータ $x$ に対して，系のエネルギーを与える関数である．
本問では，エネルギーが $E$ 以下となる位相空間の領域の体積を

```math
\Omega_0(E,x)
```

とする．
示すべきことは，外部パラメータ $x$ が十分にゆっくり変化する準静的断熱過程において，

```math
d\Omega_0(E,x)=0
```

となることである．

証明の要点は， $\Omega_0$ の変化をエネルギー $E$ の変化による寄与とパラメータ $x$ の変化による寄与に分け，両者がちょうど打ち消し合うことを示す点にある．

### 2．位相空間の体積の変化

パラメータが $x$ から $x+dx$ に変化し，それに伴ってエネルギーが $E$ から $E+dE$ に変化したとする．
このとき， $\Omega_0(E,x)$ の全微分は

```math
\begin{aligned}
d\Omega_0
&=\Omega_0(E+dE,x+dx)-\Omega_0(E,x)\\
&=\left(\frac{\partial\Omega_0}{\partial E}\right)_x dE
+\left(\frac{\partial\Omega_0}{\partial x}\right)_E dx
\end{aligned}
\tag{1}
```

である．
第1項はエネルギーの変化による体積の変化，第2項はパラメータの変化による体積の変化を表している．
以下では，それぞれの偏微分をエネルギー面上の積分で表す．

### 3．エネルギー変化 $dE$ の導出

外部パラメータ $x$ が時間 $0$ から $\tau$ まで一定の速さで変化するとする．
ハミルトニアンの時間微分は

```math
\frac{d\mathcal H}{dt}
=\frac{\partial\mathcal H}{\partial p}\dot p
+\frac{\partial\mathcal H}{\partial q}\dot q
+\frac{\partial\mathcal H}{\partial x}\dot x
```

である．
ここで，ハミルトンの運動方程式

```math
\dot q=\frac{\partial\mathcal H}{\partial p},
\qquad
\dot p=-\frac{\partial\mathcal H}{\partial q}
```

を用いると，

```math
\frac{\partial\mathcal H}{\partial p}\dot p
+\frac{\partial\mathcal H}{\partial q}\dot q
=0
```

となる．
したがって，

```math
\frac{d\mathcal H}{dt}
=\frac{\partial\mathcal H}{\partial x}\dot x
=X\dot x
```

である．
ここで，問題文の定義 $X=\partial\mathcal H/\partial x$ を用いた．

この式を時間 $0$ から $\tau$ まで積分すると，

```math
dE=\int_0^\tau X\dot x\,dt
```

を得る．
$\dot x$ は一定であり， $dx=\dot x\tau$ であるから，

```math
\begin{aligned}
dE
&=\dot x\int_0^\tau X\,dt\\
&=\frac{1}{\tau}\int_0^\tau X\,dt\,dx\\
&=\langle X\rangle_{\mathrm{時間平均}}\,dx
\end{aligned}
\tag{2}
```

となる．

ここで，問題文で認めてよいとされているエルゴード定理を用いる．
この定理によれば，エネルギー面 $\mathcal H(p,q,x)=E$ 上での時間平均は，適切な位相平均に等しい．
すなわち，

```math
\langle X\rangle_{\mathrm{時間平均}}
=\langle X\rangle_{\mathrm{位相平均}}
=\frac{
\displaystyle\int_{\mathcal H=E}
\frac{X(p,q,x)}{|\operatorname{grad}\mathcal H|}\,d\sigma
}{
\displaystyle\int_{\mathcal H=E}
\frac{1}{|\operatorname{grad}\mathcal H|}\,d\sigma
}
\tag{3}
```

である．
ここで， $d\sigma$ はエネルギー面上の面積要素， $|\operatorname{grad}\mathcal H|$ は位相空間におけるハミルトニアンの勾配の大きさである．
位相平均では，各面積要素が $1/|\operatorname{grad}\mathcal H|$ に比例する重みを持つため，この因子が積分に現れる．

したがって，式 (2)，(3) より，

```math
dE=
\frac{
\displaystyle\int_{\mathcal H=E}
\frac{X}{|\operatorname{grad}\mathcal H|}\,d\sigma
}{
\displaystyle\int_{\mathcal H=E}
\frac{1}{|\operatorname{grad}\mathcal H|}\,d\sigma
}\,dx
\tag{4}
```

を得る．
ここでは， $x$ の変化が十分に遅く，微小な変化 $dx$ の間ではエネルギー面上の平均をその時点の $E,x$ で評価できるとした．

### 4．位相空間の体積の偏微分

エネルギー面の微小な移動を考えることで，式 (1) に現れる偏微分を求める．

まず， $S_1$ を

```math
S_1:\quad \mathcal H(p,q,x)=E
```

で定義されるエネルギー面とする．
この面を法線方向に微小距離だけ移動させたときに掃かれる体積は，面積要素 $d\sigma$ と法線方向の移動距離との積を，面全体について積分することで求められる．

#### 4.1．エネルギー $E$ に関する偏微分

パラメータ $x$ を固定し，エネルギーを $E$ から $E+dE$ に変化させる．
エネルギー面は

```math
S_2:\quad \mathcal H(p,q,x)=E+dE
```

へ移動する．
法線方向の移動距離を $ds$ とすると，ハミルトニアンの一次近似より，

```math
|\operatorname{grad}\mathcal H|\,ds=dE
```

である．
したがって，エネルギー面が掃く体積は

```math
\begin{aligned}
\left(\frac{\partial\Omega_0}{\partial E}\right)_x dE
&=\int_{\mathcal H=E}ds\,d\sigma\\
&=dE\int_{\mathcal H=E}
\frac{d\sigma}{|\operatorname{grad}\mathcal H|}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\left(\frac{\partial\Omega_0}{\partial E}\right)_x
=\int_{\mathcal H=E}
\frac{d\sigma}{|\operatorname{grad}\mathcal H|}
}
\tag{5}
```

を得る．

#### 4.2．パラメータ $x$ に関する偏微分

次に，エネルギー $E$ を固定して，パラメータを $x$ から $x+dx$ に変化させる．
このとき，

```math
\mathcal H(p,q,x+dx)
\simeq \mathcal H(p,q,x)+X\,dx
```

であるから，新しいエネルギー面は

```math
S_3:\quad \mathcal H(p,q,x)+X\,dx=E
```

と表される．
元の面 $S_1$ から法線方向に距離 $ds$ だけ移動した点では，ハミルトニアンの変化は一次近似で

```math
|\operatorname{grad}\mathcal H|\,ds+X\,dx=0
```

となる．
したがって，符号付きの移動距離は $-X\,dx/|\operatorname{grad}\mathcal H|$ である．
この負号は， $X\,dx$ が正のとき，同じエネルギー $E$ を保つためにエネルギー面が反対向きへ移動することを表す．

よって，パラメータの変化による位相空間の体積変化は

```math
\begin{aligned}
\left(\frac{\partial\Omega_0}{\partial x}\right)_E dx
&=-dx\int_{\mathcal H=E}
\frac{X}{|\operatorname{grad}\mathcal H|}\,d\sigma
\end{aligned}
```

である．
したがって，

```math
\boxed{
\left(\frac{\partial\Omega_0}{\partial x}\right)_E
=-\int_{\mathcal H=E}
\frac{X}{|\operatorname{grad}\mathcal H|}\,d\sigma
}
\tag{6}
```

を得る．

### 5．$\Omega_0(E,x)$ が不変であることの証明

式 (5)，(6) を式 (1) に代入すると，

```math
\begin{aligned}
d\Omega_0
&=\left(\int_{\mathcal H=E}
\frac{d\sigma}{|\operatorname{grad}\mathcal H|}\right)dE\\
&\quad-\left(\int_{\mathcal H=E}
\frac{X}{|\operatorname{grad}\mathcal H|}\,d\sigma\right)dx
\end{aligned}
\tag{7}
```

となる．
ここに，式 (4) のエネルギー変化

```math
dE=
\frac{
\displaystyle\int_{\mathcal H=E}
\frac{X}{|\operatorname{grad}\mathcal H|}\,d\sigma
}{
\displaystyle\int_{\mathcal H=E}
\frac{d\sigma}{|\operatorname{grad}\mathcal H|}
}\,dx
```

を代入する．
すると，

```math
\begin{aligned}
d\Omega_0
&=\left(\int_{\mathcal H=E}
\frac{d\sigma}{|\operatorname{grad}\mathcal H|}\right)
\frac{
\displaystyle\int_{\mathcal H=E}
\frac{X}{|\operatorname{grad}\mathcal H|}\,d\sigma
}{
\displaystyle\int_{\mathcal H=E}
\frac{d\sigma}{|\operatorname{grad}\mathcal H|}
}\,dx\\
&\quad-\left(\int_{\mathcal H=E}
\frac{X}{|\operatorname{grad}\mathcal H|}\,d\sigma\right)dx\\
&=0
\end{aligned}
```

となる．
したがって，

```math
\boxed{
d\Omega_0(E,x)=0
}
```

である．
すなわち，エルゴード定理が成り立ち，外部パラメータ $x$ が十分にゆっくり変化する準静的断熱過程では，位相空間の体積 $\Omega_0(E,x)$ は不変である．

### 補足

本証明では，エネルギー変化による位相空間の体積の増加と，パラメータ変化による体積の減少（または増加）が，エルゴード定理によって結び付けられている．
そのため，両者がちょうど相殺され， $\Omega_0(E,x)$ が保存されるのである．
