# 演習問題【5-R-12】

## 解答

### 1．大分配関数の導出

理想量子気体を考え，1粒子量子状態 $\tau$ のエネルギーを $\epsilon_\tau$ ，その状態にある粒子数を $n_\tau$ とする．
理想気体では粒子間相互作用を無視できるため，全系のエネルギー $E$ と全粒子数 $N$ は

```math
E=\sum_\tau \epsilon_\tau n_\tau,
\qquad
N=\sum_\tau n_\tau
\tag{1}
```

と表される．

温度 $T$ ，化学ポテンシャル $\mu$ のグランドカノニカル集団では，粒子数 $N$ は変動する．
大分配関数 $\Xi$ は，全ての許される量子状態について，重み $e^{-\beta(E-\mu N)}$ を足し合わせたものである．
ここで，

```math
\beta=\frac{1}{kT}
```

であり， $k$ はボルツマン定数である．
したがって，

```math
\begin{aligned}
\Xi
&=\sum_{\{n_\tau\}}e^{-\beta(E-\mu N)}\\
&=\sum_{\{n_\tau\}}
e^{\beta\sum_\tau(\mu-\epsilon_\tau)n_\tau}\\
&=\prod_\tau\sum_{n_\tau}
e^{\beta(\mu-\epsilon_\tau)n_\tau}
\end{aligned}
\tag{2}
```

となる．
最後の等式では，粒子数についての和を全ての許される値にわたって取ることで，各量子状態 $\tau$ の占有数について独立に和を取れることを用いた．

ここで，

```math
q_\tau=e^{\beta(\mu-\epsilon_\tau)}
\tag{3}
```

と置く．
ボース粒子とフェルミ粒子では，同じ量子状態に許される占有数が異なる．

**Bose–Einstein 統計の場合：**

ボース粒子は同じ量子状態に複数個存在できるため， $n_\tau=0,1,2,\ldots$ である．
よって，各状態の和は等比級数となり，

```math
\begin{aligned}
\sum_{n_\tau=0}^{\infty}q_\tau^{n_\tau}
&=1+q_\tau+q_\tau^2+\cdots\\
&=\frac{1}{1-q_\tau}
\end{aligned}
\tag{4}
```

となる．
この級数が収束するには $q_\tau<1$ ，すなわち $\mu<\epsilon_\tau$ が必要である．
したがって通常のボース分布では，化学ポテンシャルは最低エネルギー準位より小さくなければならない．

**Fermi–Dirac 統計の場合：**

フェルミ粒子はパウリの排他原理により，同一の量子状態に高々1個しか存在できない．
したがって $n_\tau=0,1$ であり，

```math
\sum_{n_\tau=0}^{1}q_\tau^{n_\tau}
=1+q_\tau
\tag{5}
```

となる．

以上を複号でまとめると，各量子状態の大分配関数 $\Xi_\tau$ は

```math
\boxed{
\Xi_\tau=(1\mp q_\tau)^{\mp1}
}
\tag{6}
```

である．
ここでは複号の上側が Bose–Einstein 統計，下側が Fermi–Dirac 統計を表す．
すなわち，上側では $(1-q_\tau)^{-1}$ ，下側では $1+q_\tau$ となる．
したがって，全系の大分配関数は

```math
\boxed{
\Xi=\prod_\tau
\left[1\mp e^{\beta(\mu-\epsilon_\tau)}\right]^{\mp1}
}
\tag{7}
```

となる．

### 2．分布関数の導出

量子状態 $\tau$ の平均占有数を $\bar n_\tau$ とする．
各状態の大分配関数 $\Xi_\tau$ を用いると，平均占有数は

```math
\bar n_\tau
=\frac{1}{\beta}
\frac{\partial\ln\Xi_\tau}{\partial\mu}
\tag{8}
```

から求められる．
この式は， $\ln\Xi_\tau$ を化学ポテンシャルで微分することで，その状態の粒子数の平均を取り出せることを意味する．

式 (6) より，

```math
\ln\Xi_\tau
=\mp\ln(1\mp q_\tau)
```

である．
また， $q_\tau=e^{\beta(\mu-\epsilon_\tau)}$ より，

```math
\frac{\partial q_\tau}{\partial\mu}
=\beta q_\tau
```

であるから，

```math
\begin{aligned}
\bar n_\tau
&=\frac{1}{\beta}
\frac{\partial}{\partial\mu}
\left[-\,(\text{複号に応じた係数})\,
\ln(1\mp q_\tau)\right]\\
&=\frac{q_\tau}{1\mp q_\tau}.
\end{aligned}
```

すなわち，

```math
\bar n_\tau
=\frac{e^{\beta(\mu-\epsilon_\tau)}}
{1\mp e^{\beta(\mu-\epsilon_\tau)}}.
```

分子と分母に $e^{\beta(\epsilon_\tau-\mu)}$ を掛けると，

```math
\boxed{
\bar n_\tau
=\frac{1}{e^{\beta(\epsilon_\tau-\mu)}\mp1}
}
\tag{9}
```

を得る．
これが求める分布関数である．
エネルギー $\epsilon$ の関数として書けば，

```math
\boxed{
f(\epsilon)=\frac{1}{e^{\beta(\epsilon-\mu)}\mp1}
}
```

となる．
上側の符号を選ぶとボース粒子の Bose–Einstein 分布，下側の符号を選ぶとフェルミ粒子の Fermi–Dirac 分布になる．

### 3．大ポテンシャル

大分配関数から，大ポテンシャル $\mathcal J$ を

```math
\mathcal J=-kT\ln\Xi
\tag{10}
```

と定義する．
式 (7) の対数を取ると，

```math
\ln\Xi
=\mp\sum_\tau
\ln\left[1\mp e^{\beta(\mu-\epsilon_\tau)}\right]
```

であるから，

```math
\boxed{
\mathcal J
=\pm kT\sum_\tau
\ln\left[1\mp e^{\beta(\mu-\epsilon_\tau)}\right]
}
\tag{11}
```

となる．
ここでも上側の符号が Bose–Einstein 統計，下側の符号が Fermi–Dirac 統計を表す．

熱力学的極限では，大ポテンシャルは $\mathcal J=F-\mu N$ と書ける．
また，一様な系では $\mathcal J=-pV$ である．
したがって，

```math
\mathcal J=F-\mu N=-pV
```

という関係が成り立つ．

### 4．エントロピーの導出

エントロピー $S$ は，大ポテンシャルを温度で偏微分することにより，

```math
S=-\left(\frac{\partial\mathcal J}{\partial T}\right)_{\mu,V}
\tag{12}
```

として求められる．
ここでは，化学ポテンシャル $\mu$ と体積 $V$ を一定に保つ．

式 (11) を温度で微分する．

```math
\begin{aligned}
S={}&\mp k\sum_\tau
\ln\left[1\mp e^{\beta(\mu-\epsilon_\tau)}\right]\\
&-\frac{1}{T}\sum_\tau
\bar n_\tau(\mu-\epsilon_\tau).
\end{aligned}
\tag{13}
```

ここでは $\partial\beta/\partial T=-1/(kT^2)$ と，式 (9) の平均占有数を用いた．

全粒子数の平均 $N$ と内部エネルギーの平均 $E$ はそれぞれ

```math
N=\sum_\tau\bar n_\tau,
\qquad
E=\sum_\tau\epsilon_\tau\bar n_\tau
\tag{14}
```

である．
また，式 (11) より第1項は $-\mathcal J/T$ である．
したがって式 (13) は

```math
\boxed{
S=\frac{E-\mu N-\mathcal J}{T}
}
\tag{15}
```

と書ける．
これは大ポテンシャルの熱力学関係とも一致する．

さらに，式 (9) から次の関係が得られる．

```math
1\pm\bar n_\tau
=\frac{1}{1\mp e^{\beta(\mu-\epsilon_\tau)}}
\tag{16}
```

および

```math
\frac{\bar n_\tau}{1\pm\bar n_\tau}
=e^{\beta(\mu-\epsilon_\tau)}.
\tag{17}
```

式 (17) の対数を取ると，

```math
\ln\frac{\bar n_\tau}{1\pm\bar n_\tau}
=\beta(\mu-\epsilon_\tau)
\tag{18}
```

となる．
よって，

```math
\frac{\epsilon_\tau-\mu}{T}
=-k\ln\frac{\bar n_\tau}{1\pm\bar n_\tau}
```

である．
また，式 (16) から，

```math
\ln\left[1\mp e^{\beta(\mu-\epsilon_\tau)}\right]
=-\ln(1\pm\bar n_\tau)
```

となる．
これらの関係を式 (13) に代入すると，

```math
\begin{aligned}
S
&=k\sum_\tau
\left[
\pm\ln(1\pm\bar n_\tau)
-\bar n_\tau
\ln\frac{\bar n_\tau}{1\pm\bar n_\tau}
\right]\\
&=k\sum_\tau
\left[
-\bar n_\tau\ln\bar n_\tau
\pm(1\pm\bar n_\tau)\ln(1\pm\bar n_\tau)
\right].
\end{aligned}
```

したがって，求めるエントロピーの式は

```math
\boxed{
S=k\sum_\tau
\left[
-\bar n_\tau\ln\bar n_\tau
\pm(1\pm\bar n_\tau)\ln(1\pm\bar n_\tau)
\right]
}
\tag{19}
```

である．
上側の符号がボース粒子，下側の符号がフェルミ粒子に対応する．

統計ごとに書けば，Bose–Einstein 統計では

```math
S_{\mathrm{BE}}
=k\sum_\tau
\left[
(1+\bar n_\tau)\ln(1+\bar n_\tau)
-\bar n_\tau\ln\bar n_\tau
\right]
```

であり，Fermi–Dirac 統計では

```math
S_{\mathrm{FD}}
=-k\sum_\tau
\left[
\bar n_\tau\ln\bar n_\tau
+(1-\bar n_\tau)\ln(1-\bar n_\tau)
\right]
```

となる．
ここで $\bar n_\tau=0$ などの極限では $0\ln0=0$ と解釈する．

### 5．ヘルムホルツ自由エネルギー

ヘルムホルツ自由エネルギー $F$ は，大ポテンシャルとの関係

```math
\mathcal J=F-\mu N
```

を用いて，

```math
F=\mathcal J+\mu N
\tag{20}
```

と求められる．
ここで $N=\sum_\tau\bar n_\tau$ は平均粒子数である．
式 (11) を式 (20) に代入すると，

```math
\boxed{
F=N\mu
\pm kT\sum_\tau
\ln\left[1\mp e^{\beta(\mu-\epsilon_\tau)}\right]
}
\tag{21}
```

を得る．
粒子数は式 (14) と式 (9) から，

```math
\boxed{
N=\sum_\tau
\frac{1}{e^{\beta(\epsilon_\tau-\mu)}\mp1}
}
\tag{22}
```

で与えられる．
式 (21)，式 (22) を組み合わせることで， $F$ を温度 $T$ ，体積 $V$ ，粒子数 $N$ の関数として表せる．
体積 $V$ は1粒子エネルギー準位 $\epsilon_\tau$ を通じて入る．

以上より，グランドカノニカル集団では，大分配関数を各1粒子状態の寄与に分解することで，Bose–Einstein 分布と Fermi–Dirac 分布を統一的に導出できる．
さらに，大ポテンシャルを用いることで，エントロピーの式とヘルムホルツ自由エネルギーの公式も得られる．
