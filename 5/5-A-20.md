# 演習問題【5-A-20】

## 解答

### 1．部分系と $T-\mu$ 分布

体積 $V$ の容器に単原子理想気体の分子 $N$ 個が入っているとする．
このうち，体積 $v$ の小部分に注目し，その中にある分子数を $n$ とする．

小部分 $v$ は，残りの領域 $V-v$ と分子およびエネルギーをやり取りできる．
残りの領域が十分に大きい場合，それを粒子浴および熱浴として扱うことができる．
したがって，小部分 $v$ は温度 $T$ と化学ポテンシャル $\mu$ が一定の $T-\mu$ 分布，すなわち大正準分布によって記述される．

絶対活動度を

```math
\lambda=e^{\beta\mu},
\qquad
\beta=\frac{1}{kT}
```

と定義する．
ここで $k$ はボルツマン定数である．
粒子数が $n$ のときのカノニカル分配関数を $Z_n$ ，部分系の大分配関数を $\Xi$ とすれば，部分系の粒子数が $n$ である確率 $P_n$ は，

```math
\boxed{
P_n=\frac{\lambda^n Z_n}{\Xi}
}
\tag{1}
```

で与えられる．
以下では，この式を用いて $P_n$ を求める．

### 2．部分系のカノニカル分配関数 $Z_n$

単原子古典理想気体では，粒子間の相互作用を無視できるため，粒子数 $n$ のカノニカル分配関数は，1粒子分配関数の $n$ 乗を $n!$ で割ったものとなる．
すなわち，

```math
Z_n=\frac{f^n}{n!}
\tag{2}
```

である．
ここで $f$ は，体積 $v$ にある1粒子の分配関数である．
位置と運動量を用いて，

```math
f=\frac{1}{h^3}
\int e^{-\beta\mathbf p^2/(2m)}
\,d^3r\,d^3p
```

と表される．
ここで $h$ はプランク定数， $m$ は分子の質量である．

位置についての積分は体積 $v$ を与えるため，

```math
f=\frac{v}{h^3}
\iiint_{-\infty}^{\infty}
e^{-\beta(p_x^2+p_y^2+p_z^2)/(2m)}
\,dp_x\,dp_y\,dp_z
```

となる．
指数関数が3成分それぞれに分離できることから，

```math
f=\frac{v}{h^3}
\left(
\int_{-\infty}^{\infty}
e^{-\beta p_x^2/(2m)}\,dp_x
\right)^3
```

である．
ガウス積分の公式

```math
\int_{-\infty}^{\infty}e^{-ax^2}\,dx
=\sqrt{\frac{\pi}{a}}
```

を用いると，

```math
\int_{-\infty}^{\infty}
e^{-\beta p_x^2/(2m)}\,dp_x
=\sqrt{\frac{2\pi m}{\beta}}
=\sqrt{2\pi mkT}
```

を得る．
したがって，

```math
\boxed{
f=v\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
}
\tag{3}
```

となる．
これを式 (2) に代入すれば，粒子数 $n$ の分配関数が定まる．

### 3．大分配関数 $\Xi$ の計算

大分配関数は，可能なすべての粒子数について，粒子数 $n$ の分配関数に絶対活動度の $n$ 乗を掛けて足し合わせたものである．
したがって，

```math
\Xi=\sum_{n=0}^{\infty}\lambda^n Z_n
```

である．
式 (2) を代入すると，

```math
\begin{aligned}
\Xi
&=\sum_{n=0}^{\infty}
\frac{\lambda^n f^n}{n!}\\
&=\sum_{n=0}^{\infty}
\frac{(\lambda f)^n}{n!}
\end{aligned}
```

となる．
指数関数の級数展開

```math
e^x=\sum_{n=0}^{\infty}\frac{x^n}{n!}
```

を用いれば，

```math
\boxed{\Xi=e^{\lambda f}}
\tag{4}
```

を得る．

### 4．粒子数の確率分布 $P_n$

式 (1) に，式 (2)，(4) の結果を代入すると，

```math
\begin{aligned}
P_n
&=\frac{\lambda^n(f^n/n!)}{e^{\lambda f}}\\
&=\frac{(\lambda f)^n}{n!}e^{-\lambda f}
\end{aligned}
```

となる．
よって，

```math
\boxed{
P_n=e^{-\lambda f}\frac{(\lambda f)^n}{n!}
}
\tag{5}
```

である．

### 5．平均粒子数による表現

小部分 $v$ に含まれる分子数の平均値を $\bar n$ とする．
定義より，

```math
\bar n=\sum_{n=0}^{\infty}nP_n
```

である．
式 (5) を代入すると，

```math
\begin{aligned}
\bar n
&=e^{-\lambda f}
\sum_{n=1}^{\infty}
n\frac{(\lambda f)^n}{n!}\\
&=\lambda f\,e^{-\lambda f}
\sum_{n=1}^{\infty}
\frac{(\lambda f)^{n-1}}{(n-1)!}
\end{aligned}
```

となる．
ここで $j=n-1$ と置き換えると，

```math
\begin{aligned}
\bar n
&=\lambda f\,e^{-\lambda f}
\sum_{j=0}^{\infty}\frac{(\lambda f)^j}{j!}\\
&=\lambda f\,e^{-\lambda f}e^{\lambda f}\\
&=\lambda f
\end{aligned}
```

を得る．
したがって，

```math
\boxed{\bar n=\lambda f}
\tag{6}
```

である．

この関係を式 (5) に代入すると，

```math
\boxed{
P_n=e^{-\bar n}\frac{\bar n^n}{n!},
\qquad n=0,1,2,\ldots
}
```

となる．
これは平均値 $\bar n$ をもつ Poisson 分布である．

さらに，巨視的な理想気体では，全体の数密度は $N/V$ であるため，小部分に含まれる平均粒子数は

```math
\boxed{
\bar n\simeq\frac NVv
}
```

となる．
この結果は，小部分が全体に比べて十分小さく，残りの領域を粒子浴として扱える場合に対応する．

以上より， $T-\mu$ 分布を用いると，体積 $v$ の部分系に含まれる粒子数の確率分布は，

```math
\boxed{
P_n=e^{-\bar n}\frac{\bar n^n}{n!}
}
```

という Poisson 分布になることが示された．
