# 演習問題【5-B-25】

## 解答

### 1．考える系と基本的な仮定

質量 $m$ の分子 $N$ 個からなる気体を考える．
気体は希薄であり，分子間相互作用によるポテンシャルエネルギーや圧力へのビリアル補正は無視できるものとする．
ただし，分子間衝突そのものは無視しない．分子間衝突は，気体の運動量分布を等方化し，熱平衡を維持する役割を果たす．

このモデルは，分子間相互作用による熱力学的な補正は小さいが，巨視的な時間尺度では十分な回数の衝突が起こる希薄気体を想定している．

また，局所熱平衡を成立させるため，

```math
\ell_{\mathrm{mfp}}\ll L
```

および，

```math
\tau_{\mathrm{coll}}\ll\tau_{\mathrm{process}}
```

を仮定する．
ここで， $\ell_{\mathrm{mfp}}$ は平均自由行程， $L$ は気体の代表的な巨視的長さ， $\tau_{\mathrm{coll}}$ は衝突による緩和時間， $\tau_{\mathrm{process}}$ は過程の時間尺度である．

さらに，内部自由度を考慮する場合には，並進運動と内部自由度とのエネルギー交換も十分速く，熱平衡が保たれるものとする．

ピストンは摩擦なく移動し，気体は外部と熱交換しない．
また，粘性散逸などの不可逆性を無視できる可逆準静的断熱過程を考える．
したがって，気体の圧力 $p$ と外圧 $p_{\mathrm{ext}}$ は各瞬間で一致する．

まず，移動壁との分子衝突によって気体のエネルギー変化を求める．
その後，分子間衝突による再平衡を考慮して，内部エネルギーの変化を導く．

### 2．移動壁との衝突による分子のエネルギー変化

面積 $A$ のピストンが $+x$ 方向に速度 $U>0$ で移動しているとする．
ピストンの速度は，分子の熱運動の速さに比べて十分小さいものとする．

気体とピストンの境界では，分子が壁を通過できないため，気体の法線方向の平均流速はピストンの速度 $U$ と一致する．
そこで，実験室系における分子の速度を，

```math
v_x=U+c_x
```

と表す．
ここで $c_x$ は，局所気体静止系における分子の速度成分である．
ピストンに向かう分子については，

```math
c_x>0
```

となる．

壁とともに動く座標系では，衝突前の分子の速度は $c_x$ である．
壁との弾性衝突によって，衝突後の相対速度は $-c_x$ となる．
したがって，実験室系に戻すと，

```math
v_x'=U-c_x
```

である．
衝突前後の運動量をそれぞれ $P_x,P_x'$ とすると，

```math
P_x=m(U+c_x)
```

および，

```math
P_x'=m(U-c_x)
```

であるから，

```math
\boxed{
P_x'=2mU-P_x
}
\tag{1}
```

となる．
これは，静止壁 $U=0$ の場合に $P_x'=-P_x$ となることからも確認できる．

次に，分子の並進運動エネルギーの変化を求める．

```math
\begin{aligned}
\Delta\varepsilon
&=\frac{m}{2}(v_x'^2-v_x^2)\\
&=\frac{m}{2}
\left\{(U-c_x)^2-(U+c_x)^2\right\}\\
&=-2mUc_x.
\end{aligned}
```

局所気体静止系の運動量を

```math
q_x=mc_x
```

とおけば，

```math
\boxed{
\Delta\varepsilon=-2Uq_x
}
\tag{2}
```

となる．

膨張時には $U>0$ かつ $q_x>0$ なので，壁に衝突した分子は並進運動エネルギーを失う．
このエネルギーがピストンに仕事として渡される．

### 3．衝突分子数と気体のエネルギー変化

局所気体静止系における分子の運動量を，

```math
\mathbf q=m\mathbf c
```

とする．
運動量分布関数を $\phi(\mathbf q)$ とし，

```math
\int_{\mathbb R^3}\phi(\mathbf q)\,d^3q=1
```

と規格化する．
局所熱平衡では運動量分布は等方的であるから，

```math
\phi(\mathbf q)=\phi(|\mathbf q|)
```

とみなせる．

数密度を $n=N/V$ とすると，運動量が $d^3q$ の範囲にある分子の単位体積当たりの数は，

```math
n\phi(\mathbf q)d^3q
```

である．

時間 $dt$ の間に壁に衝突する分子について，壁に対する相対速度は $q_x/m$ である．
したがって， $q_x>0$ の分子の衝突数は，

```math
dN_{\mathrm{coll}}
=
A\frac{q_x}{m}dt\,
n\phi(\mathbf q)d^3q
\tag{3}
```

となる．

式 (2) より，分子一個当たりのエネルギー変化は，

```math
\Delta\varepsilon=-2Uq_x
```

である．
よって，時間 $dt$ に壁との衝突によって生じる気体の実験室系でのエネルギー変化は，

```math
\begin{aligned}
dE_{\mathrm{lab}}
&=
\int_{q_x>0}
\Delta\varepsilon\,dN_{\mathrm{coll}}\\
&=
-2UA\,dt
\int_{q_x>0}
n\phi(\mathbf q)
\frac{q_x^2}{m}\,d^3q.
\end{aligned}
\tag{4}
```

分子間衝突による局所熱平衡のため， $\phi(\mathbf q)$ は $q_x$ の符号について対称である．
したがって，

```math
\int_{q_x>0}
n\phi(\mathbf q)\frac{q_x^2}{m}\,d^3q
=
\frac12n
\left\langle\frac{q_x^2}{m}\right\rangle
```

となる．
ここで山括弧は分子の局所静止系における平均を表す．
よって，

```math
dE_{\mathrm{lab}}
=
-UA\,dt\,n
\left\langle\frac{q_x^2}{m}\right\rangle
\tag{5}
```

を得る．

一方，分子が壁に及ぼす圧力は運動量流束から求められる．
壁に向かう分子は衝突によって法線方向の相対運動量 $q_x$ を $-q_x$ に変えるため，壁が受け取る運動量は $2q_x$ である．
したがって，

```math
\begin{aligned}
p_{\mathrm{kin}}
&=
2n\int_{q_x>0}
\phi(\mathbf q)\frac{q_x^2}{m}\,d^3q\\
&=
n\left\langle\frac{q_x^2}{m}\right\rangle.
\end{aligned}
\tag{6}
```

ここで $p_{\mathrm{kin}}$ は運動論的に求めた圧力である．
局所熱平衡のもとでは圧力は等方的であり，可逆準静的過程ではピストンの力学的平衡から，

```math
p_{\mathrm{kin}}=p=p_{\mathrm{ext}}
```

となる．

式 (5)，(6) より，

```math
dE_{\mathrm{lab}}
=-pUA\,dt
```

である．
ピストンの移動による体積変化は，

```math
dV=UA\,dt
```

なので，

```math
\boxed{
dE_{\mathrm{lab}}=-p\,dV
}
\tag{7}
```

を得る．

この式は，壁との衝突による気体全体のエネルギー移動を表す．
ただし， $E_{\mathrm{lab}}$ は実験室系で測った全エネルギーであり，気体の内部エネルギーと巨視的な流れの運動エネルギーを含む．

ここで，分子間衝突は気体内部で全エネルギーを保存しながら，並進運動，巨視的流れ，内部自由度の間でエネルギーを再分配する．
可逆準静的極限では，巨視的な流れの運動エネルギーは無視でき，過程の各段階で気体は平衡状態に戻る．
したがって，平衡状態間の内部エネルギーを $E$ とすれば，

```math
\boxed{
dE=-p\,dV
}
\tag{8}
```

が成立する．

すなわち，壁との衝突で外部へ渡された仕事が，気体全体の内部エネルギーの減少に対応する．
分子間衝突はこのエネルギーを各自由度に再分配する役割を果たす．

### 4．運動論による圧力と内部エネルギーの関係

まず，圧力の式 (6) に等方性を用いる．

```math
\left\langle\frac{q_x^2}{m}\right\rangle
=
\frac13
\left\langle\frac{q^2}{m}\right\rangle
```

であるから，

```math
p
=
\frac{n}{3m}\langle q^2\rangle.
```

分子一個当たりの平均並進運動エネルギーを，

```math
\bar\varepsilon_{\mathrm{tr}}
=
\left\langle\frac{q^2}{2m}\right\rangle
```

と定義すると，

```math
p=\frac23n\bar\varepsilon_{\mathrm{tr}}
```

となる．
したがって，

```math
\boxed{
pV=\frac23E_{\mathrm{tr}}
}
\tag{9}
```

を得る．
ここで，

```math
E_{\mathrm{tr}}=N\bar\varepsilon_{\mathrm{tr}}
```

は全並進運動エネルギーである．

### 5．単原子分子理想気体の場合

単原子分子では内部自由度を無視できるため，

```math
E=E_{\mathrm{tr}}
```

である．
したがって，式 (9) より，

```math
pV=\frac23E.
```

これを微分すると，

```math
p\,dV+V\,dp=\frac23dE.
```

式 (8) の断熱条件，

```math
dE=-p\,dV
```

を代入すると，

```math
p\,dV+V\,dp
=
-\frac23p\,dV.
```

よって，

```math
\frac{dp}{p}
+\frac53\frac{dV}{V}=0
```

となる．
これを積分すれば，

```math
\ln p+\frac53\ln V=\text{一定}
```

なので，

```math
\boxed{
pV^{5/3}=\text{一定}
}
\tag{10}
```

を得る．
したがって，単原子分子理想気体では，

```math
\gamma=\frac53
```

である．

### 6．内部自由度を持つ分子の場合

回転や振動などの内部自由度を持つ分子を考える．
分子間衝突によって，並進運動エネルギーと内部エネルギーが十分速く再分配され，過程中に熱平衡が保たれるものとする．

ここでは，対象とする温度範囲で古典的等分配則が成立し，熱的に活性な二次形式の数 $f$ が過程中一定であると仮定する．
振動自由度などが量子的に凍結されている場合には，その自由度は $f$ に含めない．

分子一個当たりの独立な二次形式の数を $f$ とすると，各二次形式の平均エネルギーは $kT/2$ であるから，気体全体の内部エネルギーは，

```math
\boxed{
E=\frac f2NkT
}
\tag{11}
```

となる．

また，式 (6) と等分配則から，並進運動の各方向について，

```math
\left\langle\frac{q_x^2}{2m}\right\rangle
=
\frac12kT
```

である．
よって，

```math
p=n\left\langle\frac{q_x^2}{m}\right\rangle
=nkT
```

となるため，

```math
\boxed{
pV=NkT
}
\tag{12}
```

を得る．

式 (11)，(12) より，

```math
\boxed{
E=\frac f2pV
}
\tag{13}
```

となる．

ここで $E$ は並進運動だけでなく，回転や振動などの内部自由度を含む気体全体の内部エネルギーである．

式 (8) の断熱条件，

```math
dE=-p\,dV
```

を式 (13) に適用する．
$f$ は一定なので，

```math
dE=\frac f2(p\,dV+V\,dp)
```

である．
したがって，

```math
\frac f2(p\,dV+V\,dp)=-p\,dV.
```

両辺を $pV$ で割って整理すると，

```math
\boxed{
\frac{dp}{p}
+\left(1+\frac2f\right)\frac{dV}{V}=0
}
\tag{14}
```

を得る．

これを積分すると，

```math
\ln p+\left(1+\frac2f\right)\ln V
=\text{一定}
```

となるため，

```math
\boxed{
pV^{1+2/f}=\text{一定}
}
\tag{15}
```

が成立する．

### 7．比熱比との関係

モル定積比熱を $C_v$ ，モル定圧比熱を $C_p$ とする．
古典的等分配則から，

```math
C_v=\frac f2R
```

であり，理想気体の Mayer の関係，

```math
C_p-C_v=R
```

を用いると，

```math
C_p=\frac{f+2}{2}R
```

となる．
したがって，

```math
\begin{aligned}
\gamma
&=\frac{C_p}{C_v}\\
&=\frac{(f+2)R/2}{fR/2}\\
&=1+\frac2f.
\end{aligned}
```

よって，式 (15) は，

```math
\boxed{
pV^\gamma=\text{一定},
\qquad
\gamma=\frac{C_p}{C_v}
}
\tag{16}
```

と書ける．

単原子分子では $f=3$ なので $\gamma=5/3$ となる．
内部自由度が活性化している分子では，その自由度を含めた $f$ に応じて $\gamma$ が決まる．

ただし，過程中に熱的に活性な自由度が変化して $C_v$ が温度依存する場合には， $\gamma$ は一定ではなく，単純なべき乗則は一般には成立しない．
その場合は，

```math
\nu C_v(T)dT=-p\,dV
```

と，

```math
pV=\nu RT
```

から，

```math
\boxed{
\int_{T_1}^{T_2}\frac{C_v(T)}{T}\,dT
+
R\ln\frac{V_2}{V_1}=0
}
\tag{17}
```

を得る．
ここで $\nu$ は物質量であり， $C_v(T)$ はモル定積比熱である．

### 結論

移動するピストンとの弾性衝突によって，気体は外部へ仕事をする．
その仕事によるエネルギーの減少は，

```math
dE=-p\,dV
```

で与えられる．

一方，分子間衝突は，気体の運動量分布を等方化し，並進運動と内部自由度の間でエネルギーを再分配する．
そのため，気体は準静的過程の各段階で平衡状態に戻ることができる．

このエネルギー収支を，気体分子運動論から得られる圧力と並進運動エネルギーの関係，および等分配則による全内部エネルギーの関係に適用すると，

```math
\boxed{
pV^\gamma=\text{一定},
\qquad
\gamma=\frac{C_p}{C_v}
}
```

が導かれる．

この微分関係は膨張と圧縮の双方に適用できる．
初期状態を $(p_1,V_1)$ とすれば，積分定数は $p_1V_1^\gamma$ であり，

```math
\boxed{
pV^\gamma=p_1V_1^\gamma
}
```

となる．
したがって，理想気体の可逆準静的断熱過程に対する Poisson の式が，気体分子運動論から導かれた．
