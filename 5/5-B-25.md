# 演習問題【5-B-25】

## 解答

### 理想気体の断熱準静過程に対する Poisson の式の導出

理想気体の断熱準静過程に対して，気体分子運動論に基づき，Poisson の式

```math
pV^\gamma=\text{一定}
```

を導く．
ここで， $p$ は圧力， $V$ は体積， $\gamma=C_p/C_v$ は比熱比である．

#### 1．移動するピストンとの衝突による分子のエネルギー変化

面積 $A$ のピストンが気体の膨張方向に速度 $u$ で移動しているとする．
ピストンは十分ゆっくり動くものとし，分子の熱運動の速さに比べて $u$ は十分小さいとする．

ピストンの壁に垂直な方向を $x$ 方向とし，分子の質量を $m$ ，衝突前の運動量の $x$ 成分を $p_x$ とする．
移動する壁との弾性衝突を考えると，衝突後の運動量成分は，近似的に

```math
p_x'=p_x-2mu
```

となる．

したがって，衝突による分子の並進運動エネルギーの変化は

```math
\begin{aligned}
\delta\varepsilon(p_x)
&=\frac{(p_x-2mu)^2}{2m}
-\frac{p_x^2}{2m}\\
&=-2up_x+2mu^2
\end{aligned}
```

である．
準静的過程では $u$ が十分小さいため， $u^2$ の項を無視できる．
よって，

```math
\boxed{
\delta\varepsilon(p_x)\simeq-2up_x
}
```

となる．

すなわち，膨張するピストンに衝突した分子は，並進運動エネルギーを失うのである．

#### 2．気体全体の並進運動エネルギーの変化

気体の全分子数を $N$ ，数密度を $n=N/V$ とする．
また，分子の運動量を $\mathbf p=(p_x,p_y,p_z)$ ，規格化された運動量分布関数を $f(\mathbf p)$ とし，

```math
\int_{\mathbb R^3}f(\mathbf p)\,d^3p=1
```

とする．
したがって，単位体積中で運動量が $d^3p$ の範囲にある分子数は $nf(\mathbf p)d^3p$ である．

時間 $\delta t$ の間に壁に衝突する分子を考える．
速度の $x$ 成分が $p_x/m>0$ である分子は，壁から距離 $(p_x/m)\delta t$ 以内にあれば衝突する．
したがって，運動量が $d^3p$ の範囲にある衝突分子数は

```math
A\frac{p_x}{m}\delta t\,
nf(\mathbf p)d^3p
```

である．
ここで，壁に向かう分子だけを数えるため， $p_x>0$ とする．

よって，気体全体の並進運動エネルギー $E_{\mathrm{kin}}$ の変化は

```math
\begin{aligned}
\delta E_{\mathrm{kin}}
={}&A\delta t
\int_0^\infty dp_x
\int_{-\infty}^\infty dp_y
\int_{-\infty}^\infty dp_z\\
&\quad\times nf(\mathbf p)\frac{p_x}{m}
(-2up_x)\\
={}&-2uA\delta t
\int_0^\infty dp_x
\int_{-\infty}^\infty dp_y
\int_{-\infty}^\infty dp_z\,
nf(\mathbf p)\frac{p_x^2}{m}
\end{aligned}
```

となる．

ここで，気体が平衡状態にあり，分子の運動量分布が等方的であることを用いる．
等方性とは，分子の運動の方向に特別な方向がなく， $x,y,z$ 各方向の運動エネルギーの平均が等しいということである．
したがって，

```math
\int_{\mathbb R^3}nf(\mathbf p)
\frac{p_x^2}{m}\,d^3p
=\frac13\int_{\mathbb R^3}nf(\mathbf p)
\frac{p^2}{m}\,d^3p
```

が成り立つ．

また，分布が $p_x$ の符号について対称であるため， $p_x>0$ の半空間における積分は，全空間における積分の半分である．
分子一個の平均並進運動エネルギーを $\bar\varepsilon$ とすると，

```math
\bar\varepsilon
=\int_{\mathbb R^3}f(\mathbf p)
\frac{p^2}{2m}\,d^3p
```

であるから，

```math
\begin{aligned}
&\int_0^\infty dp_x
\int_{-\infty}^\infty dp_y
\int_{-\infty}^\infty dp_z\,
nf(\mathbf p)\frac{p_x^2}{m}\\
&\qquad=\frac12\cdot\frac13
\int_{\mathbb R^3}nf(\mathbf p)
\frac{p^2}{m}\,d^3p\\
&\qquad=\frac13n\bar\varepsilon
=\frac{E_{\mathrm{kin}}}{3V}
\end{aligned}
```

となる．
最後の等号では，

```math
E_{\mathrm{kin}}=N\bar\varepsilon
=nV\bar\varepsilon
```

を用いた．

以上より，

```math
\delta E_{\mathrm{kin}}
=-\frac23\frac{uA\delta t}{V}E_{\mathrm{kin}}
```

を得る．
ピストンの移動による体積変化は

```math
\delta V=uA\delta t
```

であるから，

```math
\boxed{
\frac{\delta E_{\mathrm{kin}}}{E_{\mathrm{kin}}}
=-\frac23\frac{\delta V}{V}
}
\tag{1}
```

となる．
これが，移動する壁との衝突から得られる重要な関係式である．

#### 3．圧力と並進運動エネルギーの関係

気体分子が壁に及ぼす圧力は，分子が壁に与える運動量の単位時間・単位面積当たりの総量から求められる．
分子の運動が等方的であることから，

```math
p=n\left\langle\frac{p_x^2}{m}\right\rangle
=\frac13n\left\langle\frac{p^2}{m}\right\rangle
```

となる．
ここで，山括弧は分子についての平均を表す．

一方，

```math
\bar\varepsilon
=\left\langle\frac{p^2}{2m}\right\rangle
```

であるため，

```math
p=\frac23n\bar\varepsilon
```

である．
したがって，

```math
\boxed{pV=\frac23E_{\mathrm{kin}}}
\tag{2}
```

を得る．

式 (2) の両辺の相対的な微小変化をとると，

```math
\boxed{
\frac{\delta p}{p}+\frac{\delta V}{V}
=\frac{\delta E_{\mathrm{kin}}}{E_{\mathrm{kin}}}
}
\tag{3}
```

となる．

#### 4．単原子分子気体の場合

単原子分子気体では，内部エネルギーは並進運動エネルギーのみからなる．
したがって，気体の全エネルギーは

```math
E=E_{\mathrm{kin}}
```

である．

式 (1) を式 (3) に代入すると，

```math
\frac{\delta p}{p}+\frac{\delta V}{V}
=-\frac23\frac{\delta V}{V}
```

であるから，

```math
\frac{\delta p}{p}
+\frac53\frac{\delta V}{V}=0
```

となる．
これを積分すると，

```math
\ln p+\frac53\ln V=\text{一定}
```

であり，対数の性質を用いて，

```math
\boxed{pV^{5/3}=\text{一定}}
```

を得る．

したがって，単原子分子気体では $\gamma=5/3$ である．

#### 5．内部自由度を考慮した場合

多原子分子などでは，分子の並進運動に加えて回転や振動などの内部自由度がエネルギーを担う．
この場合，式 (1) で直接求められるのは並進運動エネルギーの変化であり，気体の全エネルギーの変化と同一視してはならない．

ここで重要なのが， **分子間衝突によるエネルギーの再分配** である．
壁との衝突によって変化するのは，直接には壁に垂直な方向の並進運動エネルギーである．
しかし，分子間衝突を通じてエネルギーが並進・回転・振動などの自由度の間で再分配されると，気体は各自由度が熱平衡にある状態を保つ．
この過程が十分に速く，古典的な等分配則が成立することを仮定する．

分子一個当たりのエネルギーを古典的な自由度の数 $f$ で表すと，各自由度は平均して $\frac12 kT$ のエネルギーを持つため，

```math
E_{\mathrm{kin}}=\frac32NkT
```

であり，全エネルギーは

```math
E=\frac f2NkT
```

となる．
ここで， $k$ は Boltzmann 定数， $T$ は絶対温度である．
したがって，

```math
E=\frac f3E_{\mathrm{kin}}
\tag{4}
```

である．

分子間衝突によって平衡状態が保たれるとき，式 (4) は準静的過程の各平衡状態で成り立つ．
ただし，壁との衝突直後の一時的な変化ではなく，分子間衝突による再平衡後の状態を考える必要がある．

このとき，気体の状態方程式は

```math
pV=NkT
```

であり，全エネルギーは

```math
E=\frac f2pV
\tag{5}
```

と書ける．

断熱過程では外部との熱の授受がない．
気体が体積 $\delta V$ だけ膨張するとき，気体が外部にする仕事は $p\delta V$ である．
したがって，熱力学第1法則より，

```math
\delta E=-p\delta V
\tag{6}
```

となる．

式 (5) の微小変化をとると，

```math
\delta E=\frac f2(p\delta V+V\delta p)
```

である．
これを式 (6) に代入すると，

```math
\frac f2(p\delta V+V\delta p)
=-p\delta V
```

となる．
両辺を $f pV/2$ で割ると，

```math
\frac{\delta p}{p}+\frac{\delta V}{V}
=-\frac2f\frac{\delta V}{V}
```

を得る．
よって，

```math
\boxed{
\frac{\delta p}{p}
+\left(1+\frac2f\right)\frac{\delta V}{V}=0
}
\tag{7}
```

である．

ここで，

```math
\gamma=1+\frac2f
```

とおくと，式 (7) は

```math
\frac{\delta p}{p}
+\gamma\frac{\delta V}{V}=0
```

となる．
これを積分すれば，

```math
\ln p+\gamma\ln V=\text{一定}
```

であるから，

```math
\boxed{
pV^\gamma=\text{一定}
}
```

を得る．
これが，内部自由度を考慮した理想気体の Poisson の式である．

#### 6．比熱比との関係

古典的な等分配則が成立するとき，定積モル比熱 $C_v$ は

```math
C_v=\frac f2R
```

である．
理想気体では Mayer の関係

```math
C_p-C_v=R
```

が成り立つため，

```math
C_p=\frac{f+2}{2}R
```

となる．
したがって，

```math
\frac{C_p}{C_v}
=\frac{(f+2)R/2}{fR/2}
=1+\frac2f
=\gamma
```

である．
ゆえに，

```math
\boxed{
\gamma=\frac{C_p}{C_v}
}
```

となり，熱力学で得られる比熱比と一致する．

以上より，単原子分子気体では $\gamma=5/3$ となり，内部自由度を含む理想気体では，等分配則が成立する範囲で $\gamma=1+2/f=C_p/C_v$ となる．
これによって，理想気体の断熱準静過程に対する Poisson の式

```math
\boxed{
pV^\gamma=\text{一定}
}
```

が得られる．
