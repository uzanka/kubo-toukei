# 演習問題【5-B-29】

## 解答

本問題は，吸着面における気体分子の被覆比 $\theta$ を，グランドカノニカル分布を用いて導出するものである．

### 1. グランドカノニカル分配関数の構成

吸着面には $N$ 個の独立な吸着点があり，それぞれの吸着点は以下の 2 つの状態を取りうる．
- 分子が吸着していない状態：エネルギー $E_0 = 0$ ，粒子数 $n = 0$
- 分子が 1 個吸着している状態：エネルギー $E_1 = -\varepsilon_0$ ，粒子数 $n = 1$

ここで $\varepsilon_0$ は吸着によるエネルギーの減少分である．

各吸着点におけるグランドカノニカル分配関数 $\xi$ は，温度 $T$ （逆温度 $\beta = 1/kT$ ）および化学ポテンシャル $\mu$ を用いて次のように書ける．

$$\xi = \sum_{n=0}^{1} e^{-\beta(E_n - \mu n)} = e^{-\beta(0 - \mu \cdot 0)} + e^{-\beta(-\varepsilon_0 - \mu \cdot 1)} = 1 + e^{\beta(\varepsilon_0 + \mu)}$$

吸着面全体は $N$ 個の独立な吸着点の集合であるから，系全体のグランドカノニカル分配関数 $\Xi$ は，各吸着点の分配関数の積として次のように与えられる．

$$\Xi = \xi^N = [1 + e^{\beta(\varepsilon_0 + \mu)}]^N$$

（別解として，吸着されている分子の総数を $N_1$ とすると， $\Xi$ は $N_1$ に関する和として次のように表せる．
$N_1$ 個の同等な分子を $N$ 個の吸着点に配置する仕方の数は組合せの数 $`{}_N C_{N_1}`$ であるから，）

$$\Xi = \sum_{N_1=0}^{N} \frac{N!}{N_1!(N - N_1)!} e^{\beta N_1 \varepsilon_0} e^{\beta N_1 \mu} = \sum_{N_1=0}^{N} \frac{N!}{N_1!(N - N_1)!} [e^{\beta(\varepsilon_0 + \mu)}]^{N_1}$$

二項定理を用いると，これは $\Xi = [1 + e^{\beta(\varepsilon_0 + \mu)}]^N$ と一致する．

### 2. 被覆比 $\theta$ の導出

吸着されている分子の平均数 $\overline{N_1}$ は，グランドカノニカル分配関数を用いて次のように計算できる．

$$\overline{N_1} = \frac{1}{\beta} \frac{\partial}{\partial \mu} \log \Xi$$

$\log \Xi = N \log [1 + e^{\beta(\varepsilon_0 + \mu)}]$ であるから，

$$\frac{\partial}{\partial \mu} \log \Xi = N \cdot \frac{1}{1 + e^{\beta(\varepsilon_0 + \mu)}} \cdot e^{\beta(\varepsilon_0 + \mu)} \cdot \beta = \frac{N \beta e^{\beta(\varepsilon_0 + \mu)}}{1 + e^{\beta(\varepsilon_0 + \mu)}}$$

したがって，

$$\overline{N_1} = \frac{N e^{\beta(\varepsilon_0 + \mu)}}{1 + e^{\beta(\varepsilon_0 + \mu)}} = \frac{N}{e^{-\beta(\varepsilon_0 + \mu)} + 1}$$
被覆比 $\theta$ は，吸着点の総数 $N$ に対する吸着分子の平均数の比であるから，

$$\theta = \frac{\overline{N_1}}{N} = \frac{1}{e^{-\beta(\varepsilon_0 + \mu)} + 1}$$

を得る．

### 3. 圧力 $p$ との関係

次に，吸着面と接触している理想気体の化学ポテンシャル $\mu$ と圧力 $p$ の関係を用いる．
単原子分子の理想気体において，例題 [8] の結果より，次式が成り立つ．

$$e^{\mu/kT} = \frac{p}{kT} \left( \frac{h^2}{2\pi m kT} \right)^{3/2} \quad \cdots (\text{A})$$

これを用いると， $e^{-\beta(\varepsilon_0 + \mu)}$ は次のように変形できる．

$$e^{-\beta(\varepsilon_0 + \mu)} = e^{-\varepsilon_0/kT} \cdot e^{-\mu/kT} = e^{-\varepsilon_0/kT} \left[ \frac{p}{kT} \left( \frac{h^2}{2\pi m kT} \right)^{3/2} \right]^{-1} = e^{-\varepsilon_0/kT} \frac{kT}{p} \left( \frac{2\pi m kT}{h^2} \right)^{3/2}$$

これを $\theta$ の式に代入すると，

$$\theta = \frac{1}{e^{-\varepsilon_0/kT} \frac{kT}{p} \left( \frac{2\pi m kT}{h^2} \right)^{3/2} + 1} = \frac{p}{p + kT \left( \frac{2\pi m kT}{h^2} \right)^{3/2} e^{-\varepsilon_0/kT}}$$

ここで， $p_0(T) = kT \left( \frac{2\pi m kT}{h^2} \right)^{3/2} e^{-\varepsilon_0/kT}$ と定義すれば，

$$\theta = \frac{p}{p + p_0(T)}$$

が得られる．

## 解説

本問題で導出された $\theta = \frac{p}{p + p_0(T)}$ という関係式は，**Langmuir（ラングミュア）の等温吸着式**として知られている．

この式は，以下の物理的な仮定に基づいている．
1.  **単分子層吸着**：各吸着点は最大で 1 個の分子しか吸着できず，吸着層が厚くなることはない．
2.  **吸着点の等価性**：すべての吸着点はエネルギー的に等価であり，吸着した分子同士の相互作用は無視できる．
3.  **動的平衡**：気体分子の吸着速度と脱離速度が等しくなっている．

式中の $p_0(T)$ は，被覆比 $\theta$ が非常に小さい極限（すなわち $p \ll p_0$ のとき， $\theta \approx p/p_0$ ）における，圧力に対する吸着量の比例定数に対応している．
これは，吸着がほとんど起こっていない状態での吸着のしやすさを表しており，温度 $T$ の関数として記述される．
