# 演習問題【5-B-29】

## 解答

### 1．吸着分子数が $N_1$ 個の状態の分配関数

吸着面には $N$ 個の吸着点があり，各吸着点には最大で1個の分子が吸着できる．
吸着分子の総数を $N_1$ とすると，

```math
0\leq N_1\leq N
```

である．

吸着点に分子が吸着していないときのエネルギーを $0$ ，吸着しているときのエネルギーを $-\varepsilon_0$ とする．
したがって， $N_1$ 個の分子が吸着している状態のエネルギーは

```math
E(N_1)=-N_1\varepsilon_0
```

である．

次に，この状態の配置数を求める．
$N$ 個の吸着点のうち，分子が吸着する $N_1$ 個の位置を選べば，残りの吸着点には分子が吸着しない．
よって，配置数 $W(N_1)$ は組合せの公式より

```math
W(N_1)=\binom{N}{N_1}
=\frac{N!}{N_1!(N-N_1)!}
```

である．

逆温度を

```math
\beta=\frac{1}{kT}
```

と定義する．
温度 $T$ において，吸着分子数が $N_1$ 個である場合の分配関数 $Z_{N_1}$ は，各状態の Boltzmann 因子を配置数だけ足し合わせることで，

```math
\begin{aligned}
Z_{N_1}
&=W(N_1)e^{-\beta E(N_1)}\\
&=\frac{N!}{N_1!(N-N_1)!}
e^{\beta N_1\varepsilon_0}
\end{aligned}
\tag{1}
```

と求められる．
ここで， $E(N_1)=-N_1\varepsilon_0$ であるため，指数の符号が正になることに注意する．

### 2．グランドカノニカル分配関数

吸着面は，温度 $T$ ，化学ポテンシャル $\mu$ の気体と接触している．
そのため，吸着面に存在する分子数 $N_1$ は一定ではなく，気体との間で増減する．
このように粒子数が変化する系には，グランドカノニカル分布を用いる．

グランドカノニカル分配関数 $\Xi$ は，それぞれの粒子数に対応する分配関数 $Z_{N_1}$ に $e^{\beta\mu N_1}$ を掛け，可能な粒子数について足し合わせたものである．
すなわち，

```math
\Xi=\sum_{N_1=0}^{N}Z_{N_1}e^{\beta\mu N_1}
```

である．
式 (1) を代入すると，

```math
\begin{aligned}
\Xi
&=\sum_{N_1=0}^{N}
\frac{N!}{N_1!(N-N_1)!}
e^{\beta N_1\varepsilon_0}
e^{\beta\mu N_1}\\
&=\sum_{N_1=0}^{N}
\frac{N!}{N_1!(N-N_1)!}
\left[e^{\beta(\varepsilon_0+\mu)}\right]^{N_1}
\end{aligned}
```

となる．
ここで，二項定理

```math
(1+x)^N
=\sum_{r=0}^{N}\frac{N!}{r!(N-r)!}x^r
```

を用い， $x=e^{\beta(\varepsilon_0+\mu)}$ と置けば，

```math
\boxed{
\Xi=\left[1+e^{\beta(\varepsilon_0+\mu)}\right]^N
}
\tag{2}
```

を得る．

### 3．平均吸着分子数と被覆比

吸着分子数が $N_1$ 個である確率 $P(N_1)$ は，その状態のグランドカノニカル重みを分配関数で規格化することにより，

```math
P(N_1)=\frac{Z_{N_1}e^{\beta\mu N_1}}{\Xi}
```

と表される．
したがって，吸着分子の平均数 $\overline{N_1}$ は，

```math
\overline{N_1}
=\sum_{N_1=0}^{N}N_1P(N_1)
```

である．
これに確率の式を代入すると，

```math
\overline{N_1}
=\frac{1}{\Xi}
\sum_{N_1=0}^{N}N_1Z_{N_1}e^{\beta\mu N_1}
```

となる．
一方，グランドカノニカル分配関数を $\mu$ で微分すると，

```math
\frac{\partial\Xi}{\partial\mu}
=\beta\sum_{N_1=0}^{N}
N_1Z_{N_1}e^{\beta\mu N_1}
```

である．
よって，

```math
\boxed{
\overline{N_1}
=\frac{1}{\beta}\frac{\partial\ln\Xi}{\partial\mu}
}
\tag{3}
```

が得られる．

式 (2) より，

```math
\ln\Xi
=N\ln\left[1+e^{\beta(\varepsilon_0+\mu)}\right]
```

であるから，これを $\mu$ で微分すると，

```math
\frac{\partial\ln\Xi}{\partial\mu}
=\frac{N\beta e^{\beta(\varepsilon_0+\mu)}}
{1+e^{\beta(\varepsilon_0+\mu)}}
```

となる．
式 (3) に代入すれば，

```math
\overline{N_1}
=\frac{Ne^{\beta(\varepsilon_0+\mu)}}
{1+e^{\beta(\varepsilon_0+\mu)}}
```

を得る．

被覆比 $\theta$ は，吸着点の総数に対する平均吸着分子数の比であるため，

```math
\theta=\frac{\overline{N_1}}{N}
```

と定義される．
したがって，

```math
\theta
=\frac{e^{\beta(\varepsilon_0+\mu)}}
{1+e^{\beta(\varepsilon_0+\mu)}}
```

であり，分子と分母を $e^{\beta(\varepsilon_0+\mu)}$ で割ると，

```math
\boxed{
\theta=\frac{1}{e^{-\beta(\varepsilon_0+\mu)}+1}
}
\tag{4}
```

となる．
これが化学ポテンシャル $\mu$ を用いた被覆比の式である．

### 4．圧力 $p$ と被覆比の関係

次に，気体の化学ポテンシャル $\mu$ を圧力 $p$ で表す．
単原子分子の理想気体を古典的な Boltzmann 統計で扱うとき，例題 [8] の結果より，

```math
e^{\mu/(kT)}
=\frac{p}{kT}
\left(\frac{h^2}{2\pi m kT}\right)^{3/2}
\tag{5}
```

が成り立つ．
ここで， $h$ は Planck 定数， $m$ は気体分子1個の質量である．

式 (5) の両辺の逆数を取ると，

```math
e^{-\mu/(kT)}
=\frac{kT}{p}
\left(\frac{2\pi m kT}{h^2}\right)^{3/2}
```

となる．
また， $\beta=1/(kT)$ であるため，

```math
\begin{aligned}
e^{-\beta(\varepsilon_0+\mu)}
&=e^{-\varepsilon_0/(kT)}e^{-\mu/(kT)}\\
&=\frac{kT}{p}
\left(\frac{2\pi m kT}{h^2}\right)^{3/2}
e^{-\varepsilon_0/(kT)}
\end{aligned}
```

である．
これを式 (4) に代入すると，

```math
\theta=
\frac{1}{
1+\dfrac{kT}{p}
\left(\dfrac{2\pi m kT}{h^2}\right)^{3/2}
e^{-\varepsilon_0/(kT)}
}
```

となる．
分子と分母に $p$ を掛ければ，

```math
\theta=
\frac{p}{
p+kT\left(\dfrac{2\pi m kT}{h^2}\right)^{3/2}
e^{-\varepsilon_0/(kT)}
}
```

を得る．
ここで，温度 $T$ に依存する特性圧力 $p_0(T)$ を

```math
\boxed{
p_0(T)=kT
\left(\frac{2\pi m kT}{h^2}\right)^{3/2}
e^{-\varepsilon_0/(kT)}
}
\tag{6}
```

と定義すると，最終的に

```math
\boxed{
\theta=\frac{p}{p+p_0(T)}
}
```

となる．
これが Langmuir（ラングミュア）の等温吸着式である．

### 5．結果の物理的意味

この式は，吸着点がすべて等価であり，各吸着点には最大1個の分子しか吸着できず，吸着分子間の相互作用を無視できるというモデルに基づいている．

圧力が十分に低く， $p\ll p_0(T)$ のときには，

```math
\theta\simeq\frac{p}{p_0(T)}
```

となり，被覆比は圧力にほぼ比例する．
一方，圧力が十分に高く， $p\gg p_0(T)$ のときには，

```math
\theta\simeq1
```

となる．
これは，ほとんどの吸着点が分子で占められることを意味する．
したがって，導出した式は，低圧での吸着量の増加と，高圧での吸着点の飽和を表すものである．
