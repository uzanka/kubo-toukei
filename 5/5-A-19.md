# 演習問題【5-A-19】

## 解答

### 1．グランドカノニカル分配関数の定義

温度 $T$ ，体積 $V$ の容器に入った単原子古典理想気体を考える．
粒子数 $N$ は一定ではなく，外部との粒子の出入りによって変化できるものとする．
このような系を記述するのがグランドカノニカル集団である．

粒子数が $N$ のときのカノニカル分配関数を $Z_N$ ，化学ポテンシャルを $\mu$ とすると，グランドカノニカル分配関数 $\Xi$ は

```math
\Xi=\sum_{N=0}^{\infty}e^{\beta\mu N}Z_N
```

と定義される．
ここで，

```math
\beta=\frac{1}{kT}
```

であり， $k$ はボルツマン定数である．

絶対活動度 $\lambda$ を

```math
\boxed{
\lambda=e^{\beta\mu}=e^{\mu/(kT)}
}
```

と定義すると，グランドカノニカル分配関数は

```math
\boxed{
\Xi=\sum_{N=0}^{\infty}\lambda^N Z_N
}
\tag{1}
```

と書ける．
したがって，問題は $Z_N$ を求め，それを式 (1) に代入することで解決できる．

### 2．単一粒子の分配関数 $f$

#### 2.1 カノニカル分配関数の計算

粒子間の相互作用を無視できる理想気体では，粒子数 $N$ の系のハミルトニアン $H_N$ は，各粒子の運動エネルギーの和である．
すなわち，

```math
H_N=\sum_{i=1}^{N}\frac{\mathbf p_i^2}{2m}
```

である．
ここで $m$ は粒子の質量， $\mathbf p_i$ は第 $i$ 粒子の運動量ベクトルである．

粒子が古典的に振る舞い，同一粒子を区別しないとき，カノニカル分配関数は

```math
Z_N=\frac{1}{N!h^{3N}}
\int e^{-\beta H_N}\,d\Gamma
```

と表される．
ここで $h$ はプランク定数， $d\Gamma$ は全粒子の位相空間における微小体積要素である．
因子 $N!$ は，同一粒子の入れ替えを重複して数えないためのものである．

粒子間の相互作用がないため，指数関数は各粒子の運動量に関する因子の積に分解できる．
その結果，

```math
Z_N=\frac{1}{N!}
\left[
\frac{1}{h^3}
\int e^{-\beta\mathbf p^2/(2m)}
\,d^3r\,d^3p
\right]^N
```

となる．
ここで，体積 $V$ の中にある1個の粒子の分配関数を

```math
\boxed{
f=\frac{1}{h^3}
\int e^{-\beta\mathbf p^2/(2m)}
\,d^3r\,d^3p
}
\tag{2}
```

と定義する．
これは位置と運動量についての積分であり，粒子の内部構造を考えないため，内部状態に関する追加の因子は含まれない．

#### 2.2 運動量積分の評価

エネルギーは位置に依存しないため，位置について積分すると体積 $V$ が得られる．
よって，

```math
f=\frac{V}{h^3}
\iiint_{-\infty}^{\infty}
e^{-\beta(p_x^2+p_y^2+p_z^2)/(2m)}
\,dp_x\,dp_y\,dp_z
```

である．
指数関数が3成分それぞれの運動量に分離できるため，

```math
f=\frac{V}{h^3}
\left(
\int_{-\infty}^{\infty}
e^{-\beta p_x^2/(2m)}\,dp_x
\right)^3
```

となる．
ガウス積分の公式

```math
\int_{-\infty}^{\infty}e^{-ax^2}\,dx
=\sqrt{\frac{\pi}{a}}
\qquad(a>0)
```

を用いると，

```math
\int_{-\infty}^{\infty}
e^{-\beta p_x^2/(2m)}\,dp_x
=\sqrt{\frac{2\pi m}{\beta}}
=\sqrt{2\pi mkT}
```

である．
したがって，

```math
\begin{aligned}
f
&=\frac{V}{h^3}(2\pi mkT)^{3/2}\\
&=V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\end{aligned}
```

を得る．
よって，単一粒子の分配関数は

```math
\boxed{
f=V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
}
\tag{3}
```

である．

この $f$ は，体積 $V$ ，温度 $T$ ，質量 $m$ に依存する無次元量である．

### 3．グランドカノニカル分配関数の導出

式 (2) の定義から，粒子数 $N$ のカノニカル分配関数は

```math
\boxed{
Z_N=\frac{f^N}{N!}
}
\tag{4}
```

となる．
これをグランドカノニカル分配関数の式 (1) に代入すると，

```math
\begin{aligned}
\Xi
&=\sum_{N=0}^{\infty}\lambda^N Z_N\\
&=\sum_{N=0}^{\infty}\frac{\lambda^N f^N}{N!}\\
&=\sum_{N=0}^{\infty}\frac{(\lambda f)^N}{N!}
\end{aligned}
```

を得る．
指数関数の級数展開

```math
e^x=\sum_{N=0}^{\infty}\frac{x^N}{N!}
```

を用いれば，

```math
\boxed{
\Xi=e^{\lambda f}
}
\tag{5}
```

となる．
これにより，グランドカノニカル分配関数が求める形で表されることが示された．

### 4．$f$ と $\lambda$ の物理的な意味

#### 4.1 $f$ の意味

$f$ は体積 $V$ の中にある1個の粒子の古典的分配関数であり，

```math
f=V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
```

である．
ここで熱的ド・ブロイ波長

```math
\Lambda=\frac{h}{\sqrt{2\pi mkT}}
```

を導入すると，

```math
\boxed{
f=\frac{V}{\Lambda^3}
}
```

と書ける．
したがって， $f$ は容器の体積と，温度・質量によって決まる長さの尺度 $\Lambda$ によって定まる量である．

#### 4.2 $\lambda$ の意味と平均粒子数

$\lambda$ は絶対活動度と呼ばれ，化学ポテンシャル $\mu$ と

```math
\boxed{
\lambda=e^{\mu/(kT)}
}
```

の関係にある．
式 (5) から，

```math
\ln\Xi=\lambda f
```

である．
グランドカノニカル集団における平均粒子数 $\bar N$ は，

```math
\bar N
=\lambda\frac{\partial\ln\Xi}{\partial\lambda}
```

で与えられる．
したがって，

```math
\begin{aligned}
\bar N
&=\lambda\frac{\partial}{\partial\lambda}(\lambda f)\\
&=\lambda f
\end{aligned}
```

となる．
よって，

```math
\boxed{
\bar N=\lambda f
}
\tag{6}
```

である．
これを $\lambda$ について解けば，

```math
\lambda=\frac{\bar N}{f}
```

となる．
式 (3) を代入すると，

```math
\boxed{
\lambda
=\frac{\bar N}{V}
\left(\frac{h^2}{2\pi mkT}\right)^{3/2}
}
\tag{7}
```

を得る．

ここで平均粒子数密度を $\bar n=\bar N/V$ とおけば，

```math
\boxed{
\lambda=\bar n\Lambda^3
}
```

と表せる．
すなわち，絶対活動度は平均粒子数密度と熱的ド・ブロイ波長の3乗の積であり，化学ポテンシャルを表す量でもある．
実際，

```math
\boxed{
\mu=kT\ln\lambda
=kT\ln(\bar n\Lambda^3)
}
```

となる．

以上より，単原子古典理想気体のグランドカノニカル分配関数は

```math
\boxed{
\Xi=e^{\lambda f}
}
```

であり， $f$ は体積 $V$ にある1個の粒子の分配関数， $\lambda$ は化学ポテンシャルによって定まる絶対活動度であることが示された．
