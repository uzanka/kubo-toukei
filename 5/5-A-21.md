# 演習問題【5-A-21】

## 解答

$T-p$ 分布における分配関数 $Y$ は，次のような積分形式で定義される．

$$Y(T, p, N) = \int_0^\infty Z_N(V, T) e^{-\beta p V} dV$$

ここで， $Z_N(V, T)$ は定積 $V$ ， $N$ 個の粒子，温度 $T$ におけるカノニカル分配関数であり， $\beta = 1/kT$ である．

この積分を評価するために，被積分関数 $f(V) = Z_N(V, T) e^{-\beta p V}$ の最大値付近での振る舞いに注目する．
被積分関数の対数 $\log f(V)$ を $V$ について考えると，

$$\log f(V) = \log Z_N(V, T) - \beta p V$$

となる．
この関数が最大値をとる $V$ を $V^*$ とすると，最大値の条件は $`\frac{\partial \log f(V)}{\partial V} \big|_{V=V^*} = 0`$ であるから，

```math
\frac{\partial \log Z_N(V, T)}{\partial V} - \beta p = 0 \implies \frac{\partial \log Z_N(V, T)}{\partial V} \bigg|_{V=V^*} = \frac{p}{kT}
```

となる．

ここで， $V^*$ の近傍で $\log f(V)$ を 2 次までテイラー展開すると，

```math
\log f(V) \approx \log f(V^*) + \frac{1}{2} \frac{\partial^2 \log f(V)}{\partial V^2} \bigg|_{V=V^*} (V - V^*)^2
```

となる．
したがって，被積分関数は

```math
f(V) \approx f(V^*) \exp\left[ \frac{1}{2} \frac{\partial^2 \log Z_N(V, T)}{\partial V^2} \bigg|_{V=V^*} (V - V^*)^2 \right]
```

と書ける（ $\beta p$ の項は $V^*$ で微分すると消えるため，2 次の係数は $\log Z_N$ の 2 次微分のみが残る）．

これを用いて積分を実行すると，

```math
Y \approx f(V^*) \int_0^\infty \exp\left[ \frac{1}{2} \frac{\partial^2 \log Z_N(V, T)}{\partial V^2} \bigg|_{V=V^*} (V - V^*)^2 \right] dV
```

となる．
この積分はガウス積分であり，結果として $\sqrt{2\pi / |\text{係数}|}$ のような因子が現れる．
しかし，ここで $\log Y$ を計算すると，

$$\log Y \approx \log f(V^*) + \log (\text{積分因子})$$

となる．
積分因子（ガウス積分の結果）に含まれるのは $V^*$ や $N$ のべき乗の形であるが，熱力学的極限（ $N \to \infty$ ）においては， $\log f(V^*)$ のオーダー（ $N$ に比例）に比べて，積分因子の対数は無視できるほど小さくなる（ $\log N$ のオーダー程度である）．

したがって，

```math
\log Y \approx \log f(V^*) = \log Z_N(V^*, T) - \beta p V^*
```

と近似できる．
これに $-kT$ を乗じると，

```math
-kT \log Y \approx -kT \log Z_N(V^*, T) + pV^*
```

となる．
ここで， $F_N(T, V) = -kT \log Z_N(V, T)$ はヘルムホルツの自由エネルギーであるから，

```math
-kT \log Y \approx F_N(T, V^*) + pV^*
```

と書ける．

次に，最大値の条件 $\frac{\partial \log Z_N(V^*, T)}{\partial V^*} = \frac{p}{kT}$ を用いると，

```math
\frac{\partial F_N(T, V^*)}{\partial V^*} = -kT \frac{\partial \log Z_N(V^*, T)}{\partial V^*} = -kT \left( \frac{p}{kT} \right) = -p
```

となる．

これは，ヘルムホルツの自由エネルギー $F_N(T, V)$ を変数 $V$ から圧力 $p$ へ Legendre 変換して，ギブスの自由エネルギー $G(T, p, N)$ を構成する手続きそのものである．
すなわち，

```math
G(T, p, N) = F_N(T, V^*) + pV^*
```

である．

以上より， $G(T, p, N) = -kT \log Y(T, p, N)$ が成り立つことが示された．

## 解説

本問題は，カノニカル分布（温度 $T$ と体積 $V$ が一定）から $T-p$ 分布（温度 $T$ と圧力 $p$ が一定）への統計力学的な遷移を，分配関数の積分として記述するものである．

1. **分配関数の役割**: $Z_N$ は系の微視的な状態の和であり， $Y$ は圧力という外部パラメータが加わったときの状態の和を表す．
2. **ラプラス近似 (Laplace's Method)**: 被積分関数が特定の点 $V^*$ で急峻なピークを持つとき，積分値はそのピーク値とピークの広がりによって近似できる．
熱力学的極限では，このピークが非常に鋭くなるため，ピーク値の対数が全体の対数を支配する．
3. **Legendre 変換**: 熱力学において，基本式 $dF = -SdT - pdV$ から $dG = -SdT + Vdp$ を導く際，変数を $V$ から $p$ に変換するために $G = F + pV$ という関係を用いる．
本問題の導出プロセスは，統計力学的な分配関数の積分が，この熱力学的な変換を自然に実現していることを示している．
