# 演習問題【5-A-21】

## 解答

### 1．等温等圧アンサンブルの分配関数

温度 $T$ ，圧力 $p$ ，粒子数 $N$ の等温等圧アンサンブルを考える．
以下では，

```math
T>0,\qquad p>0,\qquad \beta=\frac{1}{kT}
```

とする．
分配関数，期待値およびエントロピーが有限となることを仮定する．

体積 $V$ における微視状態を $\Gamma$ ，そのエネルギーを $E_N(\Gamma;V)$ とする．
カノニカル分配関数を，

```math
Z_N(V,T)
=
\int d\Gamma_V\,
e^{-\beta E_N(\Gamma;V)}
```

と定義する．
ここで $d\Gamma_V$ は無次元化された微視状態の測度である．

また，体積の積分測度を無次元化するため，粒子数，温度，圧力に依存しない正の基準体積 $V_0$ を導入する．
等温等圧アンサンブルの分配関数を，

```math
\boxed{
Y(T,p,N)
=
\frac{1}{V_0}
\int_0^\infty
Z_N(V,T)e^{-\beta pV}\,dV
}
\tag{1}
```

と定義する．
この定義では $Y$ は無次元である．

式 (1) にカノニカル分配関数を代入すると，

```math
Y
=
\int_0^\infty\frac{dV}{V_0}
\int d\Gamma_V\,
e^{-\beta\{E_N(\Gamma;V)+pV\}}
\tag{2}
```

となる．

以後，次の測度を用いる．

```math
d\mu
=
\frac{dV}{V_0}\,d\Gamma_V
```

したがって，

```math
Y
=
\int e^{-\beta(E_N+pV)}\,d\mu
\tag{3}
```

と簡潔に書ける．

### 2．等温等圧アンサンブルの確率分布

体積 $V$ と微視状態 $\Gamma$ を合わせた確率密度を，

```math
\boxed{
\rho_{\mathrm{eq}}(V,\Gamma)
=
\frac{1}{Y}
e^{-\beta\{E_N(\Gamma;V)+pV\}}
}
\tag{4}
```

と定義する．
この確率密度は測度 $d\mu$ に関する密度である．

式 (3) より，

```math
\int \rho_{\mathrm{eq}}\,d\mu
=
\frac{1}{Y}
\int e^{-\beta(E_N+pV)}\,d\mu
=1
```

となるので，確率分布は正しく規格化されている．

任意の物理量 $A$ の期待値を，

```math
\langle A\rangle
=
\int \rho_{\mathrm{eq}}A\,d\mu
\tag{5}
```

と定義する．
特に，

```math
\langle E_N\rangle
=
\int \rho_{\mathrm{eq}}E_N\,d\mu
```

および，

```math
\langle V\rangle
=
\int \rho_{\mathrm{eq}}V\,d\mu
```

である．

### 3．Gibbs エントロピーと NPT 自由エネルギー

等温等圧アンサンブル全体の Gibbs エントロピーを，

```math
\boxed{
S_{\mathrm{NPT}}
=
-k\int
\rho_{\mathrm{eq}}\ln\rho_{\mathrm{eq}}\,d\mu
}
\tag{6}
```

と定義する．
これは体積の揺らぎを含むアンサンブル全体のエントロピーであり，固定体積のカノニカルアンサンブルのエントロピーとは区別される．

式 (4) の対数を取ると，

```math
\ln\rho_{\mathrm{eq}}
=
-\beta(E_N+pV)-\ln Y
\tag{7}
```

である．
これを式 (6) に代入すると，

```math
\begin{aligned}
S_{\mathrm{NPT}}
={}&
k\beta\int
\rho_{\mathrm{eq}}(E_N+pV)\,d\mu\\
&+
k\ln Y\int\rho_{\mathrm{eq}}\,d\mu .
\end{aligned}
```

確率分布の規格化条件と期待値の定義を使えば，

```math
S_{\mathrm{NPT}}
=
k\beta
\left(
\langle E_N\rangle+p\langle V\rangle
\right)
+k\ln Y
```

となる．
ここで $kT\beta=1$ を用いると，

```math
\boxed{
TS_{\mathrm{NPT}}
=
\langle E_N\rangle
+p\langle V\rangle
+kT\ln Y
}
\tag{8}
```

を得る．

等温等圧アンサンブルの Gibbs 自由エネルギーを，

```math
G_{\mathrm{NPT}}
=
\langle E_N\rangle
+p\langle V\rangle
-TS_{\mathrm{NPT}}
\tag{9}
```

と定義する．

式 (8) を式 (9) に代入すると，

```math
\begin{aligned}
G_{\mathrm{NPT}}
&=
\langle E_N\rangle
+p\langle V\rangle\\
&\quad-
\left[
\langle E_N\rangle
+p\langle V\rangle
+kT\ln Y
\right]\\
&=-kT\ln Y .
\end{aligned}
```

したがって，

```math
\boxed{
G_{\mathrm{NPT}}(T,p,N)
=
-kT\ln Y(T,p,N)
}
\tag{10}
```

が得られる．
これは有限粒子数でも成立する厳密な関係である．

#### 自由エネルギーが平衡分布で最小となることの確認

この結果が単に自由エネルギーの定義を書き換えただけではないことを確認するため，任意の規格化された確率密度 $\rho$ に対して，

```math
S[\rho]
=
-k\int\rho\ln\rho\,d\mu
```

および，

```math
\mathcal G[\rho]
=
\int\rho(E_N+pV)\,d\mu-TS[\rho]
```

を定義する．

Gibbs の不等式より，

```math
D(\rho\Vert\rho_{\mathrm{eq}})
=
\int\rho
\ln\frac{\rho}{\rho_{\mathrm{eq}}}\,d\mu
\geq0
```

である．
式 (4) を代入すると，

```math
\begin{aligned}
kT D(\rho\Vert\rho_{\mathrm{eq}})
&=
kT\int\rho\ln\rho\,d\mu\\
&\quad+
\int\rho(E_N+pV)\,d\mu
+kT\ln Y\\
&=
\mathcal G[\rho]+kT\ln Y .
\end{aligned}
```

したがって，

```math
\mathcal G[\rho]\geq-kT\ln Y
```

となり，等号は $\rho=\rho_{\mathrm{eq}}$ のとき成立する．
ゆえに，

```math
\boxed{
G_{\mathrm{NPT}}
=
\min_{\rho}\mathcal G[\rho]
=
-kT\ln Y
}
\tag{11}
```

である．

したがって，式 (10) は等温等圧アンサンブルの平衡自由エネルギーを表す．

### 4．通常の熱力学的 Gibbs 自由エネルギーとの関係

通常の熱力学的 Gibbs 自由エネルギーを，有限粒子数で Helmholtz 自由エネルギーの Legendre 変換として，

```math
G_{\mathrm{Leg}}(T,p,N)
=
\min_{V>0}
\{F_N(T,V)+pV\}
\tag{12}
```

と定義する場合には，式 (10) との区別が必要である．
ここで，

```math
F_N(T,V)=-kT\ln Z_N(V,T)
```

である．

式 (1) は，

```math
Y
=
\frac{1}{V_0}
\int_0^\infty
\exp\left[
-\beta\{F_N(T,V)+pV\}
\right]dV
\tag{13}
```

と書ける．
有限粒子数では，式 (13) は体積について積分した量であるため，一般に，

```math
G_{\mathrm{NPT}}\neq G_{\mathrm{Leg}}
```

である．

ただし，適切な条件のもとで熱力学的極限を取ると，両者の粒子数に比例する主要項は一致する．
以下でその条件を明示する．

#### 4.1 体積の無次元変数への変換

```math
q=\frac{V}{NV_0}
```

とおく．
ここで $q$ は無次元であり，

```math
V=NV_0q,\qquad
\frac{dV}{V_0}=N\,dq
```

である．
また，

```math
f_N(q)
=
\frac{1}{N}F_N(T,NV_0q)
```

および，

```math
h_N(q)=f_N(q)+pV_0q
```

と定義する．

すると式 (13) は，

```math
\boxed{
Y
=
N\int_0^\infty
e^{-\beta Nh_N(q)}\,dq
}
\tag{14}
```

となる．

一方，式 (12) は，

```math
\boxed{
\frac{G_{\mathrm{Leg}}(T,p,N)}{N}
=
m_N,\qquad
m_N=\min_{q>0}h_N(q)
}
\tag{15}
```

と書ける．
ただし，最小値が存在することを仮定する．

#### 4.2 最小値の収束条件

以下の条件を仮定する．

1．各 $h_N$ は連続であり，ある連続関数 $h$ に局所一様収束する．
すなわち，任意のコンパクト集合 $K\subset(0,\infty)$ に対して，

```math
\sup_{q\in K}|h_N(q)-h(q)|
\longrightarrow0
```

が成立する．

2． $h_N$ は equi-coercive である．
すなわち，任意の実数 $C$ に対し，十分大きな $N$ について，

```math
\{q>0:h_N(q)\leq C\}
```

が共通のコンパクト集合に含まれる．
これにより，最小化点が $q\to0$ や $q\to\infty$ へ逃げることを防ぐ．

3．各 $h_N$ と $h$ は大域的最小値を持ち，その値は有限である．

これらの条件のもとで，

```math
m_N=\min_{q>0}h_N(q)
```

は，

```math
m=\min_{q>0}h(q)
```

に収束する．
すなわち，

```math
\boxed{
\lim_{N\to\infty}m_N=m
}
\tag{16}
```

である．
これは局所一様収束と equi-coercivity による最小値の収束である．

#### 4.3 積分に対する Laplace 原理

さらに，積分の裾が指数スケールで十分小さいことを仮定する．
具体的には， $h$ および十分大きな $N$ に対する $h_N$ の大域的最小化点を含むコンパクト集合 $K\subset(0,\infty)$ が存在し，ある $\eta>0$ に対して，

```math
\boxed{
\limsup_{N\to\infty}
\frac{1}{N}
\ln
\int_{K^c}
e^{-\beta Nh_N(q)}\,dq
\leq
-\beta(m+\eta)
}
\tag{17}
```

が成立すると仮定する．
ここで $K^c=(0,\infty)\setminus K$ であり， $m=\min h$ である．
この条件は，最小値近傍以外の積分寄与が指数関数的に抑制されることを表す．

$K$ 上では $h_N$ が $h$ に一様収束するため，Laplace 原理から，

```math
\lim_{N\to\infty}
-\frac{1}{\beta N}
\ln\int_K e^{-\beta Nh_N(q)}\,dq
=m
```

となる．
さらに，式 (17) によって $K$ の外側の寄与は主要項を変えない．
したがって，

```math
\boxed{
\lim_{N\to\infty}
-\frac{1}{\beta N}
\ln
\int_0^\infty
e^{-\beta Nh_N(q)}\,dq
=m
}
\tag{18}
```

が成立する．

式 (14) から，

```math
-\frac{kT}{N}\ln Y
=
-\frac{kT}{N}\ln N
-\frac{kT}{N}
\ln\int_0^\infty e^{-\beta Nh_N(q)}\,dq
```

である．

ここで，

```math
\lim_{N\to\infty}\frac{\ln N}{N}=0
```

および $1/\beta=kT$ を用いると，

```math
\boxed{
\lim_{N\to\infty}
-\frac{kT}{N}\ln Y
=
m
=
\min_{q>0}h(q)
}
\tag{19}
```

を得る．

一方，式 (15)，(16) より，

```math
\boxed{
\lim_{N\to\infty}
\frac{G_{\mathrm{Leg}}(T,p,N)}{N}
=
m
}
\tag{20}
```

である．

式 (19)，(20) を比較すると，

```math
\boxed{
\lim_{N\to\infty}
\frac{-kT\ln Y-G_{\mathrm{Leg}}(T,p,N)}{N}
=0
}
\tag{21}
```

となる．

したがって，通常の熱力学的 Gibbs 自由エネルギーを Legendre 変換で定義した場合にも，適切な熱力学的極限のもとで，等温等圧アンサンブルの自由エネルギーと粒子数に比例する主要項が一致する．

なお， $F_N(T,V)+pV$ が微分可能で，平衡体積 $V_{\mathrm{eq}}$ が内部の局所最小点であれば，

```math
\left.
\frac{\partial F_N}{\partial V}
\right|_{V_{\mathrm{eq}}}
=-p
```

が停留条件となる．
さらに局所安定性には，

```math
\left.
\frac{\partial^2F_N}{\partial V^2}
\right|_{V_{\mathrm{eq}}}\geq0
```

が必要であり，非退化な極小点では不等号は厳密な正となる．
ただし，通常の平衡を決める条件は局所停留ではなく，大域的最小値である．

### 結論

等温等圧アンサンブル全体の確率分布に対する Gibbs エントロピーを用いて定義した自由エネルギーについて，

```math
\boxed{
G_{\mathrm{NPT}}(T,p,N)
=
-kT\ln Y(T,p,N)
}
```

が有限粒子数でも厳密に成立する．

一方，通常の熱力学的 Gibbs 自由エネルギーを Helmholtz 自由エネルギーの Legendre 変換として定義する場合には，有限粒子数では一般に両者は一致しない．
ただし，本文で明示した局所一様収束，equi-coercivity および積分の裾の制御条件のもとで，熱力学的極限では粒子数に比例する主要項が一致する．

なお，基準体積 $V_0$ は測度の規格化の一部である．
異なる基準体積を用いれば， $Y$ と Gibbs エントロピーの基準が対応して変化する．
したがって，分配関数とエントロピーには同じ測度の規約を用いる必要がある．
固定された $V_0$ による加法定数は，熱力学的極限での粒子数に比例する主要項には影響しない．
