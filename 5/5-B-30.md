# 演習問題【5-B-30】

## 解答

### 1．各スピンの状態と確率

磁場 $H$ 中にある $N$ 個の独立なスピンを考える．
各スピンの磁気モーメントは，磁場に平行な $+\mu$ または反平行な $-\mu$ のいずれかの値をとる．

磁場中における磁気モーメント $\mu_i$ のエネルギーは $-\mu_i H$ であるため，平行状態と反平行状態のエネルギーは，それぞれ

```math
E_+=-\mu H,\qquad E_- =+\mu H
```

となる．

温度 $T$ の熱平衡状態において，各状態の実現確率は Boltzmann 因子に比例する．
逆温度を

```math
\beta=\frac{1}{kT}
```

とすると，単一スピンの分配関数 $Z_1$ は，可能な2つの状態の Boltzmann 因子の和であるから，

```math
\begin{aligned}
Z_1
&=e^{-\beta E_+}+e^{-\beta E_-}\\
&=e^{\beta\mu H}+e^{-\beta\mu H}\\
&=2\cosh(\beta\mu H)
\end{aligned}
```

となる．
したがって，スピンが磁場に平行な状態をとる確率 $p_+$ と，反平行な状態をとる確率 $p_-$ は，

```math
\boxed{
p_+=\frac{e^{\beta\mu H}}{Z_1},\qquad
p_-=\frac{e^{-\beta\mu H}}{Z_1}
}
\tag{1}
```

である．
これらの確率は $p_++p_-=1$ を満たす．

### 2．全磁気モーメントの平均値

各スピンに $i=1,\ldots,N$ の番号を付け，その磁気モーメントを $\mu_i$ とする．
全磁気モーメント $M$ は，各スピンの磁気モーメントの和であるから，

```math
M=\sum_{i=1}^{N}\mu_i
```

と表される．
期待値の線形性より，

```math
\overline M=\sum_{i=1}^{N}\overline{\mu_i}
```

である．
すべてのスピンは同じ確率分布に従うため，

```math
\overline M=N\overline{\mu_1}
```

となる．
ここで，単一スピンの平均磁気モーメントは，式 (1) より，

```math
\begin{aligned}
\overline{\mu_1}
&=(+\mu)p_+ +(-\mu)p_-\\
&=\mu(p_+-p_-)\\
&=\mu\frac{e^{\beta\mu H}-e^{-\beta\mu H}}
{e^{\beta\mu H}+e^{-\beta\mu H}}\\
&=\mu\tanh(\beta\mu H)
\end{aligned}
```

である．
したがって，全磁気モーメントの平均値は，

```math
\boxed{
\overline M=N\mu\tanh(\beta\mu H)
}
\tag{2}
```

となる．

### 3．全磁気モーメントのゆらぎ

求めるゆらぎは，

```math
\overline{(M-\overline M)^2}
```

である．
これは，全磁気モーメントがその平均値からどの程度ばらつくかを表す量であり，分散に相当する．

まず， $M=\sum_{i=1}^{N}\mu_i$ および $\overline M=\sum_{i=1}^{N}\overline{\mu_i}$ より，

```math
M-\overline M
=\sum_{i=1}^{N}(\mu_i-\overline{\mu_i})
```

である．
この式を二乗して期待値を取ると，

```math
\begin{aligned}
\overline{(M-\overline M)^2}
&=\overline{
\left[\sum_{i=1}^{N}
(\mu_i-\overline{\mu_i})\right]^2}\\
&=\sum_{i=1}^{N}
\overline{(\mu_i-\overline{\mu_i})^2}\\
&\quad+
2\sum_{i<j}
\overline{
(\mu_i-\overline{\mu_i})
(\mu_j-\overline{\mu_j})
}.
\end{aligned}
\tag{3}
```

ここで重要なのは，各スピンが互いに独立であるという条件である．
$i\ne j$ のとき，独立性より，

```math
\begin{aligned}
&\overline{
(\mu_i-\overline{\mu_i})
(\mu_j-\overline{\mu_j})
}\\
&=\overline{\mu_i-\overline{\mu_i}}\,
\overline{\mu_j-\overline{\mu_j}}\\
&=0
\end{aligned}
```

となる．
最後の等号は，それぞれの偏差の期待値がゼロであることによる．
したがって，式 (3) の交差項はすべて消え，

```math
\overline{(M-\overline M)^2}
=\sum_{i=1}^{N}
\overline{(\mu_i-\overline{\mu_i})^2}
```

を得る．
すべてのスピンは同じ分散を持つので，

```math
\overline{(M-\overline M)^2}
=N\left[
\overline{\mu_1^2}
-(\overline{\mu_1})^2
\right]
\tag{4}
```

となる．

各スピンの磁気モーメントは $+\mu$ または $-\mu$ であるため，どちらの状態でも二乗は $\mu^2$ である．
よって，

```math
\overline{\mu_1^2}
=\mu^2p_++\mu^2p_-
=\mu^2(p_++p_-)
=\mu^2
```

である．
また，式 (2) で求めた単一スピンの平均値は，

```math
\overline{\mu_1}
=\mu\tanh(\beta\mu H)
```

である．
これらを式 (4) に代入すると，

```math
\begin{aligned}
\overline{(M-\overline M)^2}
&=N\left[
\mu^2-\mu^2\tanh^2(\beta\mu H)
\right]\\
&=N\mu^2\left[
1-\tanh^2(\beta\mu H)
\right].
\end{aligned}
```

双曲線関数の恒等式

```math
1-\tanh^2 x=\frac{1}{\cosh^2 x}
```

を用いれば，求めるゆらぎは，

```math
\boxed{
\overline{(M-\overline M)^2}
=\frac{N\mu^2}{\cosh^2(\beta\mu H)}
}
```

となる．
以上で求める式が導出された．
