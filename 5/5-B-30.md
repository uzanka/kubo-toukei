# 演習問題【5-B-30】

## 解答

本問題では，磁場 $H$ 中にある $N$ 個の独立なスピン系の全磁気モーメント $M$ のゆらぎ $\overline{(M - \overline{M})^2}$ を求める．

### 1．スピンの状態と確率の決定

まず，個々のスピンの性質を考える．
各スピンは磁場 $H$ に対して平行な方向（磁気モーメント $+\mu$ ）か，反平行な方向（磁気モーメント $-\mu$ ）のいずれかの状態をとる．
統計力学におけるカノニカル分布に従うとき，ある状態が実現される確率は，その状態のエネルギーを $E$ とすると，ボルツマン因子を用いて次のように表される：

$$P(E) = \frac{e^{-\beta E}}{Z_1}$$

ここで， $\beta = 1/(kT)$ は逆温度であり， $Z_1$ は単一粒子分配関数である．

磁場 $H$ 中におけるスピンのエネルギーは，磁気モーメントが $+\mu$ のとき $E_+ = -\mu H$ ，磁気モーメントが $-\mu$ のとき $E_- = +\mu H$ となる．
したがって，各状態をとる確率 $p_+$ および $p_-$ は以下のようになる：

$$p_+ = \frac{e^{\beta \mu H}}{Z_1}, \quad p_- = \frac{e^{-\beta \mu H}}{Z_1}$$

単一粒子分配関数 $Z_1$ は，すべての可能な状態のボルツマン因子の和であるから，

$$Z_1 = e^{\beta \mu H} + e^{-\beta \mu H} = 2 \cosh(\beta \mu H)$$

となる．

### 2．全磁気モーメントの期待値の計算

系全体の磁気モーメント $M$ は，各スピンの磁気モーメント $\mu_i$ ( $i=1, \dots, N$ ) の総和として次のように書ける：

$$M = \sum_{i=1}^N \mu_i$$

スピンは互いに独立であるため，期待値 $\overline{M}$ は各スピンの期待値の和となる：

$$\overline{M} = \sum_{i=1}^N \overline{\mu_i} = N \overline{\mu_1}$$

ここで，単一スピンの期待値 $\overline{\mu_1}$ は，

$$\overline{\mu_1} = (+\mu) p_+ + (-\mu) p_- = \mu (p_+ - p_-)$$

である．
ここで， $p_+ - p_-$ を計算すると，

$$p_+ - p_- = \frac{e^{\beta \mu H} - e^{-\beta \mu H}}{2 \cosh(\beta \mu H)} = \frac{2 \sinh(\beta \mu H)}{2 \cosh(\beta \mu H)} = \tanh(\beta \mu H)$$

となるので， $\overline{M} = N \mu \tanh(\beta \mu H)$ が得られる．

### 3．ゆらぎ（分散）の計算

次に，ゆらぎ $\overline{(M - \overline{M})^2}$ を求める．
これは統計学における分散に相当する．
各スピン $\mu_i$ は互いに独立であるため，和の分散は分散の和に等しいという性質を用いると，

$$\overline{(M - \overline{M})^2} = \sum_{i=1}^N \overline{(\mu_i - \overline{\mu_i})^2} = N \overline{(\mu_1 - \overline{\mu_1})^2}$$

となる．
単一スピンの分散 $\overline{(\mu_1 - \overline{\mu_1})^2}$ は，次のように計算できる：

$$\overline{(\mu_1 - \overline{\mu_1})^2} = \overline{\mu_1^2} - (\overline{\mu_1})^2$$

スピンの磁気モーメント $\mu_1$ は $\pm \mu$ のいずれかをとるため，その二乗 $\mu_1^2$ は常に $\mu^2$ となる．
したがって， $\overline{\mu_1^2} = \mu^2$ である．
これを用いると，

$$\overline{(\mu_1 - \overline{\mu_1})^2} = \mu^2 - (\mu \tanh(\beta \mu H))^2 = \mu^2 (1 - \tanh^2(\beta \mu H))$$

双曲線関数の公式 $1 - \tanh^2(x) = \frac{1}{\cosh^2(x)}$ を適用すると，

$$\overline{(\mu_1 - \overline{\mu_1})^2} = \frac{\mu^2}{\cosh^2(\beta \mu H)}$$

となる．
したがって，系全体のゆらぎは，

$$\overline{(M - \overline{M})^2} = \frac{N \mu^2}{\cosh^2(\beta \mu H)}$$

として求められる．

## 解説

本問題の解法における重要な概念を以下に整理する．

1. **ボルツマン因子と分配関数**：
   統計力学において，あるエネルギー状態 $E$ をとる確率は，その状態の「重み」である $e^{-\beta E}$ に比例する．
   この重みをすべて足し合わせたものが分配関数 $Z$ であり，各状態の確率を正規化（合計が $1$ になるように調整）するために用いられる．

2. **独立な変数の和の分散**：
   今回のように，各スピンが互いに影響を与え合わない（独立である）場合，全体の状態のばらつき（ゆらぎ）は，個々のスピンのばらつきを単純に足し合わせることで計算できる．
   これは，例えば「1回のコイン投げの誤差」と「もう1回の誤差」を合わせたときの全体の誤差が，それぞれの誤差の合計になることと同じ原理である．

3. **ゆらぎと分散**：
   物理学において「ゆらぎ」とは，観測される値がその平均値からどれくらい離れているか（ばらついているか）を指す．
   数学的には期待値の二乗と二乗の期待値の差，すなわち分散として定義される．

4. **双曲線関数の性質**：
   計算過程で現れる $\tanh$ や $\cosh$ は，スピンの向きの対称性を扱う際によく現れる．
   特に $1 - \tanh^2(x) = \text{sech}^2(x)$ という関係式は，統計力学の計算において頻繁に使用される重要な公式である．
