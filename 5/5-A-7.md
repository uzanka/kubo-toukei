# 演習問題【5-A-7】

## 解答

### 1．ハミルトニアンと等エネルギー面

質量 $m$ ，座標 $q$ ，運動量 $p$ ，振動数 $\nu$ の1次元調和振動子を考える．
そのハミルトニアン，すなわち全エネルギーを表す関数は

```math
\mathcal{H}(q,p)
=\frac{p^2}{2m}
+\frac{1}{2}m(2\pi\nu)^2q^2
```

である．
右辺の第1項は運動エネルギー，第2項はポテンシャルエネルギーである．

等エネルギー面とは，全エネルギーが一定値 $E$ となる位相空間上の点の集合である．
したがって，等エネルギー面は

```math
\frac{p^2}{2m}
+\frac{1}{2}m(2\pi\nu)^2q^2=E
```

を満たす点の集合として与えられる．
ここで $E>0$ とする．
両辺を $E$ で割ると，

```math
\frac{p^2}{2mE}
+\frac{m(2\pi\nu)^2}{2E}q^2=1
```

となる．
これを楕円の標準形

```math
\frac{q^2}{a^2}+\frac{p^2}{b^2}=1
```

と比較すると， $q$ 軸方向と $p$ 軸方向の半軸の長さはそれぞれ

```math
a=\sqrt{\frac{2E}{m(2\pi\nu)^2}},
\qquad
b=\sqrt{2mE}
```

である．

したがって，位相空間 $(q,p)$ における等エネルギー面は **楕円曲線** である．

### 2．エネルギー $E$ 以下の位相空間体積 $\Gamma_0(E)$

エネルギーが $E$ 以下である状態は，

```math
\mathcal{H}(q,p)\leq E
```

を満たす点である．
この領域は，上で求めた楕円曲線の内部とその境界である．
1次元系の位相空間は $(q,p)$ 平面であるため，ここでいう位相空間体積は面積を意味する．

よって，位相空間体積 $\Gamma_0(E)$ は，半軸の長さ $a,b$ をもつ楕円の面積から

```math
\begin{aligned}
\Gamma_0(E)
&=\pi ab\\
&=\pi
\sqrt{\frac{2E}{m(2\pi\nu)^2}}
\sqrt{2mE}\\
&=\pi\sqrt{\frac{4E^2}{(2\pi\nu)^2}}\\
&=\frac{E}{\nu}
\end{aligned}
```

となる．
ここでは $E>0$ ， $\nu>0$ を用いた．
したがって，

```math
\boxed{
\Gamma_0(E)=\frac{E}{\nu}
}
```

である．
この結果には質量 $m$ が含まれない．
これは，楕円の $q$ 軸方向と $p$ 軸方向の半軸が，質量に対してそれぞれ逆向きの依存性をもつためである．

### 3．エネルギー $E$ 以下の量子状態数 $\Omega_0(E)$

量子力学における1次元調和振動子のエネルギー固有値は，

```math
E_n=\left(n+\frac{1}{2}\right)h\nu,
\qquad n=0,1,2,\ldots
```

である．
ここで $h$ はプランク定数であり，量子数 $n$ は非負整数である．
この式から，最低エネルギーは $h\nu/2$ であり，隣り合うエネルギー準位の間隔は $h\nu$ であることが分かる．

エネルギー $E$ 以下の量子状態数 $\Omega_0(E)$ は， $E_n\leq E$ を満たす量子状態の個数である．
したがって，

```math
\Omega_0(E)=\sum_{E_n\leq E}1
```

と表される．
エネルギー固有値を代入すると，

```math
\left(n+\frac{1}{2}\right)h\nu\leq E
```

であるから，

```math
n\leq\frac{E}{h\nu}-\frac12
```

を得る．
許される $n$ は非負整数であるため，この条件を満たす整数の個数を数えればよい．
$E\geq0$ に対して，その個数は

```math
\boxed{
\Omega_0(E)
=\left\lfloor\frac{E}{h\nu}+\frac12\right\rfloor
}
```

となる．
ここで $\lfloor x\rfloor$ は $x$ 以下の最大の整数を表す床関数である．

例えば， $E<h\nu/2$ では最低エネルギー準位にも達しないため，状態数はゼロとなる．
一方， $E=h\nu/2$ では最低エネルギー準位が数えられ，状態数は1となる．
したがって，上の式は最低エネルギー付近も含めて状態数を正しく与える．

### 4．古典的な位相空間体積と量子状態数の比較

第2節で求めた位相空間体積をプランク定数 $h$ で割ると，

```math
\frac{\Gamma_0(E)}{h}
=\frac{E}{h\nu}
```

となる．
一方，第3節で求めた量子状態数は，

```math
\Omega_0(E)
=\left\lfloor\frac{E}{h\nu}+\frac12\right\rfloor
```

である．
床関数を取ることによる差は有限の範囲に収まるため，

```math
\Omega_0(E)=\frac{E}{h\nu}+O(1)
```

と表せる．
ここで $O(1)$ は， $E$ を大きくしても差が有界であることを意味する．

したがって， $E/(h\nu)\gg1$ では，この差は $E/(h\nu)$ に比べて相対的に小さくなる．
すなわち，

```math
\Omega_0(E)\sim\frac{E}{h\nu}
```

である．
これと $\Gamma_0(E)/h=E/(h\nu)$ を合わせると，

```math
\boxed{
\frac{\Gamma_0(E)}{h}\sim\Omega_0(E)
\qquad (E/h\nu\to\infty)
}
```

が得られる．
ここで $\sim$ は，左辺と右辺の比が1に近づくことを意味する．

以上より，調和振動子では，エネルギー以下の古典的な位相空間体積をプランク定数で割った値が，高エネルギー極限において量子状態数に漸近的に一致することが示された．
