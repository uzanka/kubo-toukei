# 演習問題【5-B-33】

## 解答

逆温度を

```math
\beta=\frac{1}{kT}
```

と定義する．
ここで， $k$ は Boltzmann 定数， $T$ は絶対温度， $\mu$ は化学ポテンシャルである．
以下では，大分配関数を用いて，(i) から (iii) の順に示す．

### (i) 粒子数のゆらぎと平均粒子数の関係

粒子数が $N$ の系のカノニカル分配関数を $Z_N$ とする．
グランドカノニカル分布における大分配関数 $\Xi$ は，

```math
\Xi=\sum_{N=0}^{\infty}e^{\beta\mu N}Z_N
\tag{1}
```

である．
粒子数が $N$ である確率は，

```math
P(N)=\frac{e^{\beta\mu N}Z_N}{\Xi}
```

で与えられる．
したがって，平均粒子数 $\bar N$ は，

```math
\bar N
=\sum_{N=0}^{\infty}NP(N)
=\frac{\sum_{N=0}^{\infty}Ne^{\beta\mu N}Z_N}{\Xi}
\tag{2}
```

となる．

まず，大分配関数を化学ポテンシャル $\mu$ で微分する．
$Z_N$ は粒子数 $N$ ，温度 $T$ ，体積 $V$ を固定したカノニカル分配関数であり， $\mu$ には依存しない．
したがって，

```math
\begin{aligned}
\frac{\partial\Xi}{\partial\mu}
&=\sum_{N=0}^{\infty}
\beta N e^{\beta\mu N}Z_N\\
&=\beta\Xi\bar N
\end{aligned}
```

である．
よって，

```math
\boxed{
\bar N=\frac{1}{\beta}
\frac{\partial\ln\Xi}{\partial\mu}
}
\tag{3}
```

を得る．

次に，式 (3) をもう一度 $\mu$ で微分する．
商の微分公式を用いると，

```math
\begin{aligned}
\frac{\partial\bar N}{\partial\mu}
&=\frac{\partial}{\partial\mu}
\left(
\frac{\sum_N Ne^{\beta\mu N}Z_N}{\Xi}
\right)\\
&=\beta\frac{\sum_N N^2e^{\beta\mu N}Z_N}{\Xi}\\
&\quad-\beta
\left(
\frac{\sum_N Ne^{\beta\mu N}Z_N}{\Xi}
\right)^2.
\end{aligned}
```

ここで，粒子数の二乗の期待値は，

```math
\overline{N^2}
=\frac{\sum_N N^2e^{\beta\mu N}Z_N}{\Xi}
```

であるから，

```math
\frac{\partial\bar N}{\partial\mu}
=\beta\left(\overline{N^2}-\bar N^2\right)
```

となる．
分散の定義

```math
\overline{(N-\bar N)^2}
=\overline{N^2}-\bar N^2
```

を用いれば，

```math
\frac{\partial\bar N}{\partial\mu}
=\beta\overline{(N-\bar N)^2}
```

を得る．
最後に， $\beta^{-1}=kT$ を代入すると，

```math
\boxed{
\overline{(N-\bar N)^2}
=kT\frac{\partial\bar N}{\partial\mu}
}
```

となる．
これで (i) が証明された．

### (ii) 古典統計の場合

古典理想気体では，粒子数 $N$ のカノニカル分配関数は，

```math
Z_N=\frac{z_1^N}{N!}
```

と表される．
ここで， $z_1$ は1粒子の分配関数であり，温度と体積には依存するが，化学ポテンシャル $\mu$ には依存しない．

式 (1) に代入すると，大分配関数は，

```math
\begin{aligned}
\Xi
&=\sum_{N=0}^{\infty}
\frac{(e^{\beta\mu}z_1)^N}{N!}\\
&=\exp(e^{\beta\mu}z_1)
\end{aligned}
```

となる．
ここで，指数関数の展開

```math
e^x=\sum_{N=0}^{\infty}\frac{x^N}{N!}
```

を用いた．
式 (3) より，

```math
\begin{aligned}
\bar N
&=\frac{1}{\beta}
\frac{\partial\ln\Xi}{\partial\mu}\\
&=\frac{1}{\beta}
\frac{\partial}{\partial\mu}
(e^{\beta\mu}z_1)\\
&=e^{\beta\mu}z_1
\end{aligned}
```

である．
したがって，

```math
\frac{\partial\bar N}{\partial\mu}
=\beta e^{\beta\mu}z_1
=\beta\bar N
```

を得る．
これを (i) の結果に代入すると，

```math
\beta\overline{(N-\bar N)^2}
=\beta\bar N
```

となるので，

```math
\boxed{
\overline{(N-\bar N)^2}=\bar N
}
```

が得られる．
つまり，古典理想気体では粒子数の分散は平均粒子数に等しい．

### (iii) 量子統計の場合

量子統計では，全粒子数 $N$ ではなく，特定の1粒子量子状態 $\tau$ を占める粒子数 $n_\tau$ に注目する．
その量子状態のエネルギーを $\varepsilon_\tau$ とする．

1つの量子状態の占有数に関する大分配関数を

```math
\xi_\tau
=\sum_{n_\tau}e^{\beta(\mu-\varepsilon_\tau)n_\tau}
\tag{4}
```

と定義する．
この状態の占有数 $n_\tau$ が実現する確率は，

```math
P_\tau(n_\tau)
=\frac{e^{\beta(\mu-\varepsilon_\tau)n_\tau}}
{\xi_\tau}
\tag{5}
```

である．

平均占有数は，

```math
\bar n_\tau
=\frac{\sum_{n_\tau}n_\tau
e^{\beta(\mu-\varepsilon_\tau)n_\tau}}
{\xi_\tau}
```

である．
式 (4) を $\mu$ で微分すると，

```math
\frac{\partial\xi_\tau}{\partial\mu}
=\beta\sum_{n_\tau}n_\tau
e^{\beta(\mu-\varepsilon_\tau)n_\tau}
```

となる．
よって，

```math
\boxed{
\bar n_\tau
=\frac{1}{\beta}
\frac{\partial\ln\xi_\tau}{\partial\mu}
}
\tag{6}
```

を得る．
これは，(i) で得た平均粒子数の式と同じ形である．

式 (6) を再び $\mu$ で微分すれば，

```math
\frac{\partial\bar n_\tau}{\partial\mu}
=\beta\left(
\overline{n_\tau^2}-\bar n_\tau^2
\right)
```

となる．
ここで，

```math
\overline{(n_\tau-\bar n_\tau)^2}
=\overline{n_\tau^2}-\bar n_\tau^2
```

であるから，

```math
\boxed{
\overline{(n_\tau-\bar n_\tau)^2}
=\frac{1}{\beta}
\frac{\partial\bar n_\tau}{\partial\mu}
}
\tag{7}
```

を得る．
以下では，各統計の平均占有数を微分して，この関係式に代入する．

#### (a) ボース・アインシュタイン統計

B.E. 統計では，1つの量子状態に複数の粒子が入ることが許されるため，

```math
n_\tau=0,1,2,\ldots
```

である．
したがって，式 (4) は等比級数となり，

```math
\begin{aligned}
\xi_\tau
&=\sum_{n_\tau=0}^{\infty}
\left[e^{\beta(\mu-\varepsilon_\tau)}\right]^{n_\tau}\\
&=\frac{1}{1-e^{\beta(\mu-\varepsilon_\tau)}}
\end{aligned}
```

となる．
この級数が収束する条件は $\mu<\varepsilon_\tau$ である．

式 (6) より，平均占有数は，

```math
\boxed{
\bar n_\tau
=\frac{1}{e^{\beta(\varepsilon_\tau-\mu)}-1}
}
\tag{8}
```

である．
ここで， $x=e^{\beta(\varepsilon_\tau-\mu)}$ と置けば，

```math
\bar n_\tau=\frac{1}{x-1}
```

となる．
$x$ は $\mu$ に関して

```math
\frac{\partial x}{\partial\mu}=-\beta x
```

を満たすため，

```math
\begin{aligned}
\frac{\partial\bar n_\tau}{\partial\mu}
&=-\frac{1}{(x-1)^2}\frac{\partial x}{\partial\mu}\\
&=\beta\frac{x}{(x-1)^2}
\end{aligned}
```

となる．
一方，

```math
\begin{aligned}
\bar n_\tau(1+\bar n_\tau)
&=\frac{1}{x-1}
\left(1+\frac{1}{x-1}\right)\\
&=\frac{x}{(x-1)^2}
\end{aligned}
```

であるから，

```math
\frac{\partial\bar n_\tau}{\partial\mu}
=\beta\bar n_\tau(1+\bar n_\tau)
```

を得る．
これを式 (7) に代入すると，

```math
\boxed{
\overline{(n_\tau-\bar n_\tau)^2}
=\bar n_\tau(1+\bar n_\tau)
}
\qquad \text{(B.E.)}
```

となる．

#### (b) フェルミ・ディラック統計

F.D. 統計では，パウリの排他原理により，1つの量子状態に入る粒子は高々1個である．
したがって，

```math
n_\tau=0,1
```

であり，式 (4) は，

```math
\begin{aligned}
\xi_\tau
&=1+e^{\beta(\mu-\varepsilon_\tau)}
\end{aligned}
```

となる．
式 (6) より，平均占有数は，

```math
\boxed{
\bar n_\tau
=\frac{1}{e^{\beta(\varepsilon_\tau-\mu)}+1}
}
\tag{9}
```

である．
ここで，再び $x=e^{\beta(\varepsilon_\tau-\mu)}$ と置けば，

```math
\bar n_\tau=\frac{1}{x+1}
```

であり，

```math
\begin{aligned}
\frac{\partial\bar n_\tau}{\partial\mu}
&=-\frac{1}{(x+1)^2}\frac{\partial x}{\partial\mu}\\
&=\beta\frac{x}{(x+1)^2}
\end{aligned}
```

となる．
一方，

```math
\begin{aligned}
\bar n_\tau(1-\bar n_\tau)
&=\frac{1}{x+1}
\left(1-\frac{1}{x+1}\right)\\
&=\frac{x}{(x+1)^2}
\end{aligned}
```

であるから，

```math
\frac{\partial\bar n_\tau}{\partial\mu}
=\beta\bar n_\tau(1-\bar n_\tau)
```

を得る．
これを式 (7) に代入すると，

```math
\boxed{
\overline{(n_\tau-\bar n_\tau)^2}
=\bar n_\tau(1-\bar n_\tau)
}
\qquad \text{(F.D.)}
```

となる．

以上より，ボース・アインシュタイン統計とフェルミ・ディラック統計をまとめると，

```math
\boxed{
\overline{(n_\tau-\bar n_\tau)^2}
=\bar n_\tau(1\pm\bar n_\tau)
}
```

を得る．
ここで，複号の上側 $+$ は B.E. 統計，下側 $-$ は F.D. 統計を表す．
以上で (iii) が証明された．
