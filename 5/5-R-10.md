# 例題【5-R-10】

## 解答

磁場 $H$ の中にあり，温度 $T$ に保たれた $N$ 個の独立なスピン $1/2$ 粒子からなる系を考える．
各粒子のエネルギー準位は $-\mu H$ および $+\mu H$ である．
この系をカノニカル分布で扱い，分配関数から熱力学的諸量を求める．

### 1．分配関数

まず，1個の粒子の分配関数 $Z_1$ を求める．
カノニカル分布では，エネルギー $E_i$ の状態のボルツマン因子は $e^{-\beta E_i}$ である．
ここで，

```math
\beta=\frac{1}{kT}
```

であり， $k$ はボルツマン定数である．
したがって，2つのエネルギー準位を足し合わせると，

```math
\begin{aligned}
Z_1
&=e^{-\beta(-\mu H)}+e^{-\beta(\mu H)}\\
&=e^{\beta\mu H}+e^{-\beta\mu H}.
\end{aligned}
```

双曲線余弦関数 $\cosh x=(e^x+e^{-x})/2$ を用いれば，

```math
Z_1=2\cosh(\beta\mu H)
=2\cosh\left(\frac{\mu H}{kT}\right)
```

となる．

各粒子は互いに独立であり，粒子間の相互作用を考えないため，全系の分配関数 $Z_N$ は1粒子の分配関数の $N$ 乗である．
よって，

```math
\boxed{
Z_N=\left[2\cosh\left(\frac{\mu H}{kT}\right)\right]^N
}
\tag{1}
```

を得る．

### 2．ヘルムホルツ自由エネルギー

カノニカル分布におけるヘルムホルツ自由エネルギー $F$ は，分配関数を用いて

```math
F=-kT\ln Z_N
```

と表される．
式 (1) を代入し， $\ln(a^N)=N\ln a$ を用いると，

```math
\boxed{
F=-NkT\ln\left[
2\cosh\left(\frac{\mu H}{kT}\right)
\right]
}
\tag{2}
```

となる．
以下では，この自由エネルギーから各物理量を求める．

### 3．エントロピー

温度 $T$ ，磁場 $H$ のもとでのエントロピー $S$ は，自由エネルギーから

```math
S=-\left(\frac{\partial F}{\partial T}\right)_H
```

によって求められる．
計算を簡潔にするため，

```math
x=\frac{\mu H}{kT}
```

と置く．
磁場 $H$ を一定にすると，

```math
\frac{\partial x}{\partial T}=-\frac{x}{T}
```

である．
式 (2) は

```math
F=-NkT\ln(2\cosh x)
```

と書けるので，積の微分と連鎖律を用いると，

```math
\begin{aligned}
\left(\frac{\partial F}{\partial T}\right)_H
&=-Nk\ln(2\cosh x)
-NkT\tanh x\,\frac{\partial x}{\partial T}\\
&=-Nk\ln(2\cosh x)+Nkx\tanh x.
\end{aligned}
```

したがって，エントロピーは

```math
S=Nk\left[\ln(2\cosh x)-x\tanh x\right]
```

となる．
$x=\mu H/(kT)$ を代入すると，

```math
\boxed{
S=Nk\left[
\ln\left\{2\cosh\left(\frac{\mu H}{kT}\right)\right\}
-\frac{\mu H}{kT}
\tanh\left(\frac{\mu H}{kT}\right)
\right]
}
\tag{3}
```

を得る．

### 4．内部エネルギー

ヘルムホルツ自由エネルギーと内部エネルギー $U$ の関係は，

```math
F=U-TS
```

である．
したがって，

```math
U=F+TS
```

となる．
式 (2)，式 (3) を代入すると，

```math
\begin{aligned}
U={}&-NkT\ln(2\cosh x)\\
&+NkT\left[\ln(2\cosh x)-x\tanh x\right].
\end{aligned}
```

対数を含む項が相殺されるため，

```math
U=-NkT\,x\tanh x
```

となる．
ここで $x=\mu H/(kT)$ であるから，

```math
\boxed{
U=-N\mu H\tanh\left(\frac{\mu H}{kT}\right)
}
\tag{4}
```

を得る．

### 5．全体としての磁気モーメント

系全体の磁気モーメント $M$ は，温度を一定に保ったときの自由エネルギーの磁場に関する微分から，

```math
M=-\left(\frac{\partial F}{\partial H}\right)_T
```

と求められる．
式 (2) を $H$ で微分すると，

```math
\begin{aligned}
M
&=NkT\tanh\left(\frac{\mu H}{kT}\right)
\frac{\mu}{kT}\\
&=N\mu\tanh\left(\frac{\mu H}{kT}\right).
\end{aligned}
```

したがって，

```math
\boxed{
M=N\mu\tanh\left(\frac{\mu H}{kT}\right)
}
\tag{5}
```

である．
各粒子の磁気モーメントが磁場方向に $\mu$ または $-\mu$ であることから，この式は粒子1個あたりの平均磁気モーメントに粒子数 $N$ を掛けた結果とも解釈できる．

式 (4) と式 (5) を比較すると，

```math
\boxed{
U=-MH
}
```

が成り立つことも分かる．

### 6．比熱

磁場 $H$ を一定に保ったときの比熱を $C_H$ とする．
これは内部エネルギーの温度に関する偏微分であり，

```math
C_H=\left(\frac{\partial U}{\partial T}\right)_H
```

である．
式 (4) を用いると，

```math
U=-N\mu H\tanh x,
\qquad
x=\frac{\mu H}{kT}
```

である．
双曲線正接関数の微分公式

```math
\frac{d}{dx}\tanh x=\frac{1}{\cosh^2 x}
```

および $\partial x/\partial T=-x/T$ から，

```math
\begin{aligned}
C_H
&=-N\mu H\frac{1}{\cosh^2 x}
\left(-\frac{x}{T}\right)\\
&=\frac{N\mu H}{T}\frac{x}{\cosh^2 x}.
\end{aligned}
```

ここで $\mu H/T=kx$ であるため，

```math
C_H=Nk\frac{x^2}{\cosh^2 x}
```

となる．
よって，

```math
\boxed{
C_H=Nk
\left(\frac{\mu H}{kT}\right)^2
\frac{1}{\cosh^2\left(\frac{\mu H}{kT}\right)}
}
\tag{6}
```

を得る．

### 結果のまとめ

求める熱力学的諸量は，次のとおりである．

```math
\boxed{
U=-N\mu H\tanh\left(\frac{\mu H}{kT}\right)
}
```

```math
\boxed{
S=Nk\left[
\ln\left\{2\cosh\left(\frac{\mu H}{kT}\right)\right\}
-\frac{\mu H}{kT}\tanh\left(\frac{\mu H}{kT}\right)
\right]
}
```

```math
\boxed{
C_H=Nk\left(\frac{\mu H}{kT}\right)^2
\frac{1}{\cosh^2\left(\frac{\mu H}{kT}\right)}
}
```

```math
\boxed{
M=N\mu\tanh\left(\frac{\mu H}{kT}\right)
}
```

以上より，1粒子の分配関数から全系の分配関数を求め，自由エネルギーを介して，内部エネルギー，エントロピー，比熱，全体の磁気モーメントを順に導出できる．
