# 例題【5-R-4】

## 解答

### 1．熱力学的重率 $W_M$ の導出

$N$ 個の独立な粒子からなる系を考える．
各粒子は，エネルギー $-\varepsilon_0$ または $+\varepsilon_0$ のいずれかの状態をとる．
ここで， $\varepsilon_0>0$ である．

エネルギー $-\varepsilon_0$ の状態にある粒子数を $N_-$ ，エネルギー $+\varepsilon_0$ の状態にある粒子数を $N_+$ とすると，粒子数と全エネルギーについて，

```math
N=N_-+N_+
\tag{1}
```

```math
E=-N_-\varepsilon_0+N_+\varepsilon_0
\tag{2}
```

が成り立つ．
問題文の $E=M\varepsilon_0$ を式 (2) に代入すると，

```math
M=N_+-N_-
\tag{3}
```

となる．
式 (1)，(3) を連立して解くと，

```math
\boxed{
N_-=\frac{N-M}{2},
\qquad
N_+=\frac{N+M}{2}
}
\tag{4}
```

が得られる．

全エネルギーが $E=M\varepsilon_0$ となる微視状態の数，すなわち熱力学的重率 $W_M$ は， $N$ 個の粒子のうち，どの $N_-$ 個がエネルギー $-\varepsilon_0$ の状態にあるかを選ぶ組合せの数に等しい．
残りの $N_+$ 個は自動的にエネルギー $+\varepsilon_0$ の状態にある．
よって，

```math
W_M=\frac{N!}{N_-!\,N_+!}
```

である．
式 (4) を代入すると，

```math
\boxed{
W_M=
\frac{N!}{
\left(\dfrac{N-M}{2}\right)!
\left(\dfrac{N+M}{2}\right)!
}
}
\tag{5}
```

となる．
これが求める熱力学的重率である．
ただし， $N_-$ と $N_+$ は非負整数でなければならないため，許される $M$ は $-N,-N+2,\ldots,N-2,N$ である．

### 2．エントロピーと温度の関係

#### 2.1 エントロピーを求める

ボルツマンの原理によると，エントロピー $S$ は熱力学的重率 $W_M$ を用いて，

```math
S=k\log W_M
\tag{6}
```

と表される．
ここで， $k$ はボルツマン定数である．
式 (5) より，

```math
\begin{aligned}
S=k\bigg\{&
\log N!
-\log\left(\frac{N-M}{2}\right)!\\
&-\log\left(\frac{N+M}{2}\right)!
\bigg\}
\end{aligned}
\tag{7}
```

となる．

ここで， $N$ が十分に大きく，熱力学的極限を考えられるとする．
Stirling の近似

```math
\log n!\simeq n\log n-n
\tag{8}
```

を用いると，式 (7) は，

```math
\begin{aligned}
\frac{S}{k}\simeq{}&
N\log N-N\\
&-\frac{N-M}{2}
\log\left(\frac{N-M}{2}\right)
+\frac{N-M}{2}\\
&-\frac{N+M}{2}
\log\left(\frac{N+M}{2}\right)
+\frac{N+M}{2}
\end{aligned}
```

となる．
ここで， $-(N)+(N-M)/2+(N+M)/2=0$ であるため，定数項は相殺する．
したがって，

```math
\boxed{
\begin{aligned}
S(E)\simeq k\bigg\{&
N\log N
-\frac{N-M}{2}\log\frac{N-M}{2}\\
&-\frac{N+M}{2}\log\frac{N+M}{2}
\bigg\}
\end{aligned}
}
\tag{9}
```

を得る．
ここで $M=E/\varepsilon_0$ である．

#### 2.2 温度をエネルギーの関数として求める

ミクロカノニカル集団では，全エネルギーを一定に保った系のエントロピーから，温度を

```math
\frac{1}{T}=\left(\frac{\partial S}{\partial E}\right)_N
\tag{10}
```

によって定義する．
$E=M\varepsilon_0$ であるから，

```math
\frac{\partial M}{\partial E}=\frac{1}{\varepsilon_0}
```

であり，連鎖律から，

```math
\frac{1}{T}
=\frac{1}{\varepsilon_0}
\left(\frac{\partial S}{\partial M}\right)_N
\tag{11}
```

となる．

式 (9) を $M$ で偏微分する．
$N$ は一定である．
対数の微分を用いると，

```math
\begin{aligned}
\frac{1}{k}\frac{\partial S}{\partial M}
={}&\frac12
\left[
\log\left(\frac{N-M}{2}\right)+1
\right]\\
&-\frac12
\left[
\log\left(\frac{N+M}{2}\right)+1
\right]\\
={}&\frac12\log\frac{N-M}{N+M}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\frac{1}{T}
=\frac{k}{2\varepsilon_0}
\log\frac{N-M}{N+M}
}
\tag{12}
```

を得る．

本問では $E<0$ ，すなわち $M<0$ の範囲に限定する．
このとき $N-M>N+M$ であるため，式 (12) の右辺は正となり，温度 $T$ も正である．
一方， $M>0$ では右辺が負となるため，温度は負となる．
負の温度もエネルギーに上限をもつ系では統計力学的に定義可能であるが，以下では問題文の指定どおり $E<0$ の範囲を扱う．

#### 2.3 エネルギーと温度の関係を求める

式 (12) を変形すると，

```math
\log\frac{N-M}{N+M}
=\frac{2\varepsilon_0}{kT}
```

である．
両辺の指数を取れば，

```math
\frac{N-M}{N+M}
=e^{2\varepsilon_0/(kT)}
\tag{13}
```

を得る．
式 (4) より，

```math
\frac{N_-}{N_+}
=\frac{N-M}{N+M}
```

であるから，

```math
\frac{N_-}{N_+}
=e^{2\varepsilon_0/(kT)}
\tag{14}
```

となる．

式 (14) と $N=N_-+N_+$ を用いて各状態にある粒子数の割合を求める．
$x=\varepsilon_0/(kT)$ とおくと，

```math
\begin{aligned}
\frac{N_-}{N}
&=\frac{e^{2x}}{1+e^{2x}}
=\frac{e^x}{e^x+e^{-x}},\\[4pt]
\frac{N_+}{N}
&=\frac{1}{1+e^{2x}}
=\frac{e^{-x}}{e^x+e^{-x}}
\end{aligned}
\tag{15}
```

となる．

全エネルギーは $E=(N_+-N_-)\varepsilon_0$ であるため，式 (15) を代入すると，

```math
\begin{aligned}
E
&=N\varepsilon_0
\left(
\frac{e^{-x}-e^x}{e^x+e^{-x}}
\right)\\
&=-N\varepsilon_0
\frac{e^x-e^{-x}}{e^x+e^{-x}}\\
&=-N\varepsilon_0\tanh x
\end{aligned}
```

となる．
ここで，

```math
\tanh x=\frac{e^x-e^{-x}}{e^x+e^{-x}}
```

を用いた．
$x=\varepsilon_0/(kT)$ を戻すと，求めるエネルギーと温度の関係は，

```math
\boxed{
E=-N\varepsilon_0
\tanh\left(\frac{\varepsilon_0}{kT}\right)
}
\tag{16}
```

である．

### 3．比熱と温度の関係

比熱 $C$ は，粒子数 $N$ を一定に保ったときのエネルギーの温度による変化率であり，

```math
C=\left(\frac{\partial E}{\partial T}\right)_N
\tag{17}
```

と定義される．
式 (16) を $T$ で微分する．

```math
x=\frac{\varepsilon_0}{kT}
```

とおけば，

```math
\frac{dx}{dT}
=-\frac{\varepsilon_0}{kT^2}
```

であり，また，

```math
\frac{d}{dx}\tanh x
=\frac{1}{\cosh^2 x}
```

である．
したがって，

```math
\begin{aligned}
C
&=-N\varepsilon_0
\frac{1}{\cosh^2 x}\frac{dx}{dT}\\
&=N\frac{\varepsilon_0^2}{kT^2}
\frac{1}{\cosh^2 x}
\end{aligned}
```

となる．
$x=\varepsilon_0/(kT)$ を代入すると，

```math
\boxed{
C=Nk\left(\frac{\varepsilon_0}{kT}\right)^2
\frac{1}{\cosh^2\left(\dfrac{\varepsilon_0}{kT}\right)}
}
\tag{18}
```

が得られる．

エネルギー準位間の差を $\Delta E=2\varepsilon_0$ とおけば，式 (18) は次のようにも表される．

```math
\boxed{
C=Nk
\frac{\left(\dfrac{\Delta E}{kT}\right)^2
e^{\Delta E/(kT)}}
{\left(1+e^{\Delta E/(kT)}\right)^2}
}
\tag{19}
```

これは Schottky 型比熱と呼ばれる．

温度が非常に低いときは，粒子の大部分がエネルギー $-\varepsilon_0$ の状態にあるため，温度を上げてもエネルギーの変化は小さい．
一方，温度が非常に高いときは，二つの状態に粒子がほぼ等しい割合で分布し，エネルギーは0に近づくため，比熱は再び小さくなる．
その結果，比熱は中間の温度領域で極大値をとる．このような比熱のピークが Schottky 異常である．

以上より，重率 $W_M$ は式 (5)，エネルギーと温度の関係は式 (16)，比熱と温度の関係は式 (18) で与えられる．
