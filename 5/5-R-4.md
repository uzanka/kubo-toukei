# 演習問題【5-R-4】

## 解答

$N$ 個の独立な粒子から成る系を考える．
各粒子がとりうるエネルギー状態は， $-\varepsilon_0$ と $\varepsilon_0$ の $2$ 状態のみであるとする．

系の全エネルギーを $E$ とし， $-\varepsilon_0$ の状態にある粒子の数を $N_-$ ， $\varepsilon_0$ の状態にある粒子の数を $N_+$ とすると，全エネルギー $E$ は次のように書ける．

$$E = -N_- \varepsilon_0 + N_+ \varepsilon_0 = (N_+ - N_-) \varepsilon_0 \quad \cdots (1)$$

また，粒子の総数は $N = N_+ + N_-$ である．

ここで，問題文に従い， $E = M\varepsilon_0$ とおく．
式 (1) より， $M = N_+ - N_-$ である．
$N = N_+ + N_-$ と $M = N_+ - N_-$ の連立方程式を解くと，粒子数 $N_+$ および $N_-$ は次のように求まる．

$$N_+ = \frac{N + M}{2}, \quad N_- = \frac{N - M}{2} \quad \cdots (2)$$

次に，全エネルギー $E$ を持つ系の微視的状態の数（重率） $W_M$ を求める．
これは， $N$ 個の粒子の中から $-\varepsilon_0$ の状態にある $N_-$ 個の粒子を選ぶ組み合わせの数に等しい．

$$W_M = \frac{N!}{N_-! N_+!} = \frac{N!}{\left( \frac{N-M}{2} \right)! \left( \frac{N+M}{2} \right)!} \quad \cdots (3)$$

統計力学におけるエントロピー $S$ は，ボルツマンの原理 $S = k \log W_M$ により定義される．
粒子数 $N$ が十分に大きいとき，スターリングの公式 $\log n! \approx n \log n - n$ を用いると，エントロピー $S$ は次のように近似できる．

$$\begin{aligned} S &= k \log W_M \\ &\approx k \left[ N \log N - N - \left( N_- \log N_- - N_- \right) - \left( N_+ \log N_+ - N_+ \right) \right] \\ &= k \left[ N \log N - N_- \log N_- - N_+ \log N_+ \right] \\ &= k \left[ N \log N - \frac{N-M}{2} \log \left( \frac{N-M}{2} \right) - \frac{N+M}{2} \log \left( \frac{N+M}{2} \right) \right] \quad \cdots (4) \end{aligned}$$

統計熱力学において，温度 $T$ はエントロピーのエネルギーによる変化率として定義される．

$$\frac{1}{T} = \frac{\partial S}{\partial E}$$

ここで， $E = M\varepsilon_0$ であるから， $\frac{\partial S}{\partial E} = \frac{1}{\varepsilon_0} \frac{\partial S}{\partial M}$ である．
式 (4) を $M$ で微分すると，

$$\begin{aligned} \frac{1}{T} &= \frac{1}{\varepsilon_0} \frac{\partial S}{\partial M} \\ &= \frac{k}{\varepsilon_0} \frac{\partial}{\partial M} \left[ N \log N - \frac{N-M}{2} \log \left( \frac{N-M}{2} \right) - \frac{N+M}{2} \log \left( \frac{N+M}{2} \right) \right] \\ &= \frac{k}{\varepsilon_0} \left[ -\left( -\frac{1}{2} \log \left( \frac{N-M}{2} \right) - \frac{N-M}{2} \cdot \frac{2}{N-M} \cdot \left( -\frac{1}{2} \right) \right) - \left( \frac{1}{2} \log \left( \frac{N+M}{2} \right) + \frac{N+M}{2} \cdot \frac{2}{N+M} \cdot \frac{1}{2} \right) \right] \\ &= \frac{k}{\varepsilon_0} \left[ \frac{1}{2} \log \left( \frac{N-M}{2} \right) + \frac{1}{2} - \frac{1}{2} \log \left( \frac{N+M}{2} \right) - \frac{1}{2} \right] \\ &= \frac{k}{2\varepsilon_0} \log \left( \frac{N-M}{N+M} \right) \quad \cdots (5) \end{aligned}$$

となる．

ここで， $M > 0$ ( $E > 0$ ) のとき $\frac{N-M}{N+M} < 1$ となり， $\log$ の値が負になるため， $T < 0$ となる．
これは通常の熱力学の範囲では扱わないため，本問題では $E < 0$ ( $M < 0$ ) の範囲に限定して議論を進める．

式 (5) を $M$ について解く．

$$\log \left( \frac{N-M}{N+M} \right) = \frac{2\varepsilon_0}{kT}$$

$$\frac{N-M}{N+M} = e^{2\varepsilon_0 / kT}$$

これより，

$$\frac{N_-}{N_+} = e^{2\varepsilon_0 / kT} \quad \cdots (6)$$

が得られる．
また， $\frac{N_-}{N_+} = \frac{N-M}{N+M}$ を利用して， $N_-$ と $N_+$ を $N$ で表すと，

$$\begin{aligned} \frac{N_-}{N} &= \frac{N_-}{N_- + N_+} = \frac{e^{2\varepsilon_0 / kT}}{1 + e^{2\varepsilon_0 / kT}} = \frac{1}{1 + e^{-2\varepsilon_0 / kT}} \quad (\text{不適切な書き直し，以下を用いる}) \\ \frac{N_-}{N_+} &= e^{2\varepsilon_0 / kT} \implies N_- = N_+ e^{2\varepsilon_0 / kT} \\ N = N_+ (1 + e^{2\varepsilon_0 / kT}) \implies N_+ = \frac{N}{1 + e^{2\varepsilon_0 / kT}}, \quad N_- = \frac{N e^{2\varepsilon_0 / kT}}{1 + e^{2\varepsilon_0 / kT}} \end{aligned}$$

これらを整理すると，

$$\frac{N_-}{N} = \frac{e^{\varepsilon_0 / kT}}{e^{\varepsilon_0 / kT} + e^{-\varepsilon_0 / kT}}, \quad \frac{N_+}{N} = \frac{e^{-\varepsilon_0 / kT}}{e^{\varepsilon_0 / kT} + e^{-\varepsilon_0 / kT}} \quad \cdots (7)$$

となる．
これはカノニカル分布に従う各粒子の存在確率と一致する．

全エネルギー $E$ を温度 $T$ で表すと，

$$\begin{aligned} E &= (N_+ - N_-) \varepsilon_0 = N \left( \frac{1 - e^{2\varepsilon_0 / kT}}{1 + e^{2\varepsilon_0 / kT}} \right) \varepsilon_0 \\ &= -N \varepsilon_0 \frac{e^{2\varepsilon_0 / kT} - 1}{e^{2\varepsilon_0 / kT} + 1} \\ &= -N \varepsilon_0 \tanh \left( \frac{\varepsilon_0}{kT} \right) \quad \cdots (8) \end{aligned}$$

となる．

最後に，比熱 $C$ を求める．

$$\begin{aligned} C &= \frac{dE}{dT} = -N \varepsilon_0 \frac{d}{dT} \left[ \tanh \left( \frac{\varepsilon_0}{kT} \right) \right] \\ &= -N \varepsilon_0 \cdot \text{sech}^2 \left( \frac{\varepsilon_0}{kT} \right) \cdot \left( -\frac{\varepsilon_0}{kT^2} \right) \\ &= N \frac{\varepsilon_0^2}{kT^2} \text{sech}^2 \left( \frac{\varepsilon_0}{kT} \right) \\ &= Nk \left( \frac{\varepsilon_0}{kT} \right)^2 \frac{1}{\cosh^2 \left( \frac{\varepsilon_0}{kT} \right)} \quad \cdots (9) \end{aligned}$$

となる．

以上より，エネルギーと温度の関係は $E = -N \varepsilon_0 \tanh(\varepsilon_0 / kT)$ であり，比熱と温度の関係は $C = Nk (\varepsilon_0 / kT)^2 / \cosh^2(\varepsilon_0 / kT)$ である．

## 解説

本問題では，ミクロカノニカル集団（エネルギーが一定の系）の考え方から出発し，エントロピーを通じて温度とエネルギーの関係を導出している．

1.  **微視的状態の数とエントロピー**:
    粒子が $2$ つのエネルギー状態のみをとる場合，全体のエネルギーを決定するのは，どの粒子がどちらの状態にあるかという組み合わせである．
    この組み合わせの数が重率 $W$ であり，その対数にボルツマン定数 $k$ を乗じたものがエントロピー $S$ である．

2.  **温度の定義**:
    熱力学における温度は，「系にエネルギーを与えたときに，エントロピーがどれだけ増えるか」という尺度である．
    数式では $\frac{1}{T} = \frac{\partial S}{\partial E}$ と定義される．
    これにより，エネルギーの変化とエントロピーの変化の関係から温度が定まる．

3.  **Schottky 型比熱**:
    導出された比熱 $C$ の式は，温度 $T$ が非常に高いとき（ $\varepsilon_0 / kT \to 0$ ）には $C \to 0$ となり，温度が非常に低いとき（ $\varepsilon_0 / kT \to \infty$ ）にも $C \to 0$ となる．
    しかし，ある特定の温度付近で比熱が極大値をとる．
    この現象は「Schottky 異常」と呼ばれ，エネルギー準位が離散的な系（今回のように $2$ 状態のみの系など）に特有の性質である．

4.  **$E < 0$ の物理的意味**:
    $E < 0$ という条件は，系の大半の粒子が低い方のエネルギー状態（ $-\varepsilon_0$ ）に存在していることを意味している．
    この状態では，温度を上げると（粒子が励起状態へ移動しやすくなると），エントロピーが単調に増加するため，通常の（正の温度を持つ）熱力学的記述が可能となる．
