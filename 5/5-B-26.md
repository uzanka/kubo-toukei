# 演習問題【5-B-26】

## 解答

### 振動子 $N$ 個から成る系の状態数と正常性

振動数 $\nu$ の調和振動子 $N$ 個から成る系について，零点振動のエネルギーを差し引いたエネルギーを $E$ とする．
状態数 $\Omega_0(E)$ を求め，その漸近的な性質を調べることによって，この系が§5.6の意味において正常であることを示す．

#### 1．状態数 $\Omega_0(E)$ の導出

各振動子のエネルギーは，量子数 $n_i=0,1,2,\ldots$ を用いて


```math
\varepsilon_i=\left(n_i+\frac12\right)h\nu
```

と表される．
したがって，系全体のエネルギーは

```math
E_{\mathrm{total}}
=h\nu\sum_{i=1}^{N}n_i+\frac12Nh\nu
```

である．

ここで，零点振動のエネルギー $\frac12Nh\nu$ を差し引き，残りのエネルギーを $E$ と定義する．
すると，

```math
E=h\nu\sum_{i=1}^{N}n_i
```

となる．

```math
M=\frac{E}{h\nu}
```

とおけば， $M$ は非負整数であり，状態を指定する量子数は

```math
n_1+n_2+\cdots+n_N=M
```

を満たす．

したがって，エネルギーがちょうど $Mh\nu$ である状態の数 $W_M$ は，この方程式を満たす非負整数解の個数に等しい．

この個数は， $M$ 個の同一なエネルギー量子を $N$ 個の区別可能な振動子に分配する方法の数である．
重複組合せの公式より，

```math
W_M=\binom{M+N-1}{M}
=\frac{(M+N-1)!}{M!(N-1)!}
```

となる．

一方，問題で求める $\Omega_0(E)$ は，エネルギーが $E$ 以下である状態の総数である．
したがって，

```math
\Omega_0(E)=\sum_{m=0}^{M}W_m
=\sum_{m=0}^{M}\binom{m+N-1}{m}
```

である．

ここで，二項係数の和に関する恒等式

```math
\sum_{m=0}^{M}\binom{m+N-1}{m}
=\binom{M+N}{M}
```

を用いると，

```math
\Omega_0(E)
=\frac{(M+N)!}{M!N!}
```

を得る．
よって，

```math
\boxed{
\Omega_0(E)=
\frac{\left(\dfrac{E}{h\nu}+N\right)!}
{\left(\dfrac{E}{h\nu}\right)!N!}
}
```

である．
ここで， $E/h\nu=M$ は非負整数である．

#### 2．Stirling の公式による漸近形

次に，振動子の数 $N$ が十分に大きい場合を考える．
階乗の近似公式である Stirling の公式

```math
\log n!\simeq n\log n-n
```

を用いると，

```math
\begin{aligned}
\log\Omega_0(E)
&=\log(M+N)!-\log M!-\log N!\\
&\simeq (M+N)\log(M+N)-(M+N)\\
&\quad-M\log M+M-N\log N+N
\end{aligned}
```

となる．
定数項は相殺されるため，

```math
\log\Omega_0(E)
\simeq (M+N)\log(M+N)-M\log M-N\log N
```

を得る．

ここで，エネルギーを振動子一個当たりで表す無次元変数

```math
x=\frac{E}{Nh\nu}=\frac{M}{N}
```

を導入する．
すなわち， $M=Nx$ である．
これを代入すると，

```math
\begin{aligned}
\log\Omega_0(E)
&\simeq N(1+x)\log\{N(1+x)\}\\
&\quad-Nx\log(Nx)-N\log N\\
&=N\{(1+x)\log(1+x)-x\log x\}
\end{aligned}
```

となる．

したがって，

```math
\boxed{
\log\Omega_0(E)\simeq N\phi(x)
}
```

と書ける．
ここで，

```math
\boxed{
\phi(x)=(1+x)\log(1+x)-x\log x
}
```

である．

よって，系の正常性を調べるには，この関数 $\phi(x)$ の性質を調べればよい．

#### 3．関数 $\phi(x)$ の性質

##### （1）一階導関数

$x>0$ において微分すると，

```math
\begin{aligned}
\phi'(x)
&=\log(1+x)+1-\log x-1\\
&=\log\frac{1+x}{x}
\end{aligned}
```

となる．

$x>0$ では

```math
\frac{1+x}{x}=1+\frac1x>1
```

であるから，

```math
\boxed{
\phi'(x)>0
}
```

である．
したがって， $\phi(x)$ は $x>0$ で狭義単調増加する．

また，

```math
\lim_{x\to0^+}\phi'(x)
=\lim_{x\to0^+}\log\left(1+\frac1x\right)
=+\infty
```

である．

##### （2）二階導関数

さらに微分すると，

```math
\begin{aligned}
\phi''(x)
&=\frac{1}{1+x}-\frac1x\\
&=-\frac{1}{x(1+x)}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\phi''(x)<0
}
```

である．
ゆえに， $\phi(x)$ は $x>0$ で狭義の凹関数である．

##### （3）$x\to0^+$ における極限

関数の定義から，

```math
\phi(x)=(1+x)\log(1+x)-x\log x
```

である．

$x\to0^+$ のとき，

```math
(1+x)\log(1+x)\to0
```

である．
また，基本極限

```math
\lim_{x\to0^+}x\log x=0
```

より，

```math
\lim_{x\to0^+}x\log x=0
```

である．
したがって，

```math
\boxed{
\lim_{x\to0^+}\phi(x)=0
}
```

となる．

##### （4）$x\to+\infty$ における極限

関数 $\phi(x)$ を変形すると，

```math
\begin{aligned}
\phi(x)
&=(1+x)\log(1+x)-x\log x\\
&=\log(1+x)+x\log\left(1+\frac1x\right)
\end{aligned}
```

となる．

ここで，

```math
\lim_{x\to+\infty}
x\log\left(1+\frac1x\right)=1
```

である．
これは， $t=1/x$ とおき，

```math
\lim_{t\to0^+}\frac{\log(1+t)}{t}=1
```

を用いれば分かる．
一方，

```math
\lim_{x\to+\infty}\log(1+x)=+\infty
```

である．
したがって，

```math
\boxed{
\lim_{x\to+\infty}\phi(x)=+\infty
}
```

となる．

#### 4．正常性の確認

以上の結果をまとめると， $x>0$ において，

```math
\phi'(x)>0,\qquad \phi''(x)<0
```

であり，さらに，

```math
\lim_{x\to0^+}\phi(x)=0,\qquad
\lim_{x\to+\infty}\phi(x)=+\infty
```

である．

特に， $\phi(x)$ は $x>0$ で連続かつ単調増加し， $x\to0^+$ で $0$ に近づく．
したがって，

```math
\boxed{
\phi(x)>0\qquad(x>0)
}
```

である．

ゆえに，Stirling の公式による漸近形

```math
\log\Omega_0(E)\simeq N\phi(x)
```

において， $\phi(x)$ は正であり，その一階導関数と二階導関数も§5.6で要求される性質を満たす．
したがって， **振動子 $N$ 個から成る系は，§5.6の意味において正常である** ．
