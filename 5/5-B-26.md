# 演習問題【5-B-26】

## 解答

$N$ 個の独立な調和振動子から成る系の全エネルギー $E_{\text{total}}$ は，各振動子の量子数 $n_i$ ( $i=1, 2, \dots, N$ ) を用いて次のように表される．

$$E_{\text{total}} = \sum_{i=1}^{N} \left( n_i + \frac{1}{2} \right) h\nu = \sum_{i=1}^{N} n_i h\nu + \frac{1}{2} N h\nu$$

ここで， $h$ はプランク定数， $\nu$ は振動数である．
問題の指示に従い，零点振動のエネルギー $\frac{1}{2} N h\nu$ を取り去ったエネルギー $E$ を考える．
このとき， $E$ は次のように書ける．

$$E = E_{\text{total}} - \frac{1}{2} N h\nu = \sum_{i=1}^{N} n_i h\nu$$

両辺を $h\nu$ で割ると， $\sum_{i=1}^{N} n_i = \frac{E}{h\nu}$ となる．
ここで， $M = \frac{E}{h\nu}$ と置くと， $M$ はエネルギー量子 $h\nu$ の総数である．
すなわち，問題は「$N$ 個の非負整数 $n_i$ の和が $M$ となる組み合わせの数」を求めることに帰着する．

これは， $M$ 個の同一な粒子（エネルギー量子）を， $N$ 個の区別可能な箱（振動子）に分配する問題であり，重複組合せの考え方を用いて次のように計算できる．

$$\Omega_0(E) = \frac{(M + N - 1)!}{M! (N - 1)!}$$

これが， $E$ のエネルギーを持つ系の状態数 $\Omega_0(E)$ である．

次に， $N$ が十分に大きいときの漸近的な性質を調べるために， $\log \Omega_0(E)$ を Stirling の公式 $\log n! \approx n \log n - n$ を用いて近似する．

$$\begin{aligned} \log \Omega_0(E) &= \log \frac{(M + N - 1)!}{M! (N - 1)!} \\ &\approx (M + N - 1) \log (M + N - 1) - (M + N - 1) - [M \log M - M] - [(N - 1) \log (N - 1) - (N - 1)] \\ &\approx (M + N) \log (M + N) - M \log M - N \log N \end{aligned}$$

（ここで， $N, M \gg 1$ であるから， $N-1 \approx N$ と近似した．）

さらに，変数 $x = \frac{E}{N h\nu} = \frac{M}{N}$ を用いて整理する．
$M = Nx$ であるから，

$$\begin{aligned} \log \Omega_0(E) &\approx (Nx + N) \log (Nx + N) - Nx \log (Nx) - N \log N \\ &= N(x + 1) \log \{ N(x + 1) \} - Nx \log (Nx) - N \log N \\ &= N(x + 1) [\log N + \log (x + 1)] - Nx [\log N + \log x] - N \log N \\ &= N(x + 1) \log N + N(x + 1) \log (x + 1) - Nx \log N - Nx \log x - N \log N \\ &= N \log N + N(x + 1) \log (x + 1) - Nx \log N - Nx \log x - N \log N \\ &= N \{ (x + 1) \log (x + 1) - x \log x \} \end{aligned}$$

したがって， $\log \Omega_0(E) \approx N \phi(x)$ と書ける．
ここで，

$$\phi(x) = (1 + x) \log (1 + x) - x \log x$$

である．

この関数 $\phi(x)$ の性質を調べる．
$x > 0$ において，

$$\phi'(x) = \log(1 + x) + (1 + x) \frac{1}{1 + x} - (\log x + x \frac{1}{x}) = \log(1 + x) + 1 - \log x - 1 = \log \frac{1 + x}{x}$$

$x > 0$ のとき $\frac{1+x}{x} > 1$ であるから， $\phi'(x) > 0$ となり， $\phi(x)$ は単調増加関数である．
また，

$$\phi''(x) = \frac{d}{dx} \log \left( \frac{1 + x}{x} \right) = \frac{1}{1 + x} - \frac{1}{x} = \frac{x - (1 + x)}{x(1 + x)} = -\frac{1}{x(1 + x)} < 0$$

であるから， $\phi(x)$ は上に凸な関数である．

次に，極限を考える．

$$\lim_{x \to 0+} \phi(x) = \lim_{x \to 0+} \{ (1+x) \log (1+x) - x \log x \}$$

第1項は $1 \cdot \log 1 = 0$ に収束し，第2項 $\lim_{x \to 0+} x \log x = 0$ であることから， $\lim_{x \to 0+} \phi(x) = 0$ である．
また，

$$\begin{aligned} \lim_{x \to \infty} \phi(x) &= \lim_{x \to \infty} \{ (1+x) \log (1+x) - x \log x \} \\ &= \lim_{x \to \infty} \{ \log (1+x) + x \log (1+x) - x \log x \} \\ &= \lim_{x \to \infty} \{ \log (1+x) + x \log \left( \frac{1+x}{x} \right) \} \\ &= \lim_{x \to \infty} \{ \log (1+x) + x \log (1 + \frac{1}{x}) \} \end{aligned}$$

ここで， $x \to \infty$ のとき $x \log (1 + \frac{1}{x}) \to 1$ であるが， $\log (1+x) \to \infty$ であるため，

$$\lim_{x \to \infty} \phi(x) = +\infty$$

となる．

以上の結果から， $x > 0$ において $\phi(x)$ は $0$ から始まり，単調に増加して $+\infty$ へ発散する連続関数である．
したがって，常に $\phi(x) > 0$ となり，§5.6 における正常性の条件が満たされていることが示された．

## 解説

本問題では，熱力学的な極限（ $N \to \infty$ ）における状態数の振る舞いを扱った．

1. **状態数 $\Omega_0(E)$ の導出について**
   振動子のエネルギーは量子化されており，エネルギーを $E$ にするために必要なエネルギー量子（ $h\nu$ ）の個数を $M = E/h\nu$ とする．
   $N$ 個の振動子に対して $M$ 個の量子を配分する問題は，数学的には「 $N$ 個の変数 $n_1, \dots, n_N$ の非負整数解の数」を求めることに相当する．
   これは，重複組合せの公式 $\binom{M+N-1}{M}$ で与えられる．

2. **Stirling の公式と漸近展開**
   $N$ や $M$ が非常に大きい場合，階乗の計算は困難になる．
   そこで Stirling の公式を用いて対数 $\log \Omega$ を近似的に計算する．
   これにより，マクロな変数であるエネルギー密度 $x = E/(N h\nu)$ に依存する関数 $\phi(x)$ を取り出すことができる．

3. **「正常であること」の意味**
   統計力学において，系の性質がマクロな変数（エネルギー密度など）にのみ依存し，熱力学的極限で安定した値を持つことを「正常」と呼ぶことがある．
   具体的には， $\phi(x)$ が正の値を取り，適切な関数的性質（凸性や極限挙動）を持つことが重要である．

以上のように，本解答では物理的な設定から数学的な関数の性質の解析まで，一貫したプロセスで証明を行った．
