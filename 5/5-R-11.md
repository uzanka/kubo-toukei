# 演習問題【5-R-11】

## 解答

大分配関数 $\Xi(T, \mu, V)$ は，温度 $T$ ，化学ポテンシャル $\mu$ ，体積 $V$ で規定される，粒子数が一定ではない系（粒子数不定系）の統計力学的な状態を記述する関数である．

まず，大分配関数の定義は次のように書ける．

$$\Xi(T, \mu, V) = \sum_{N=0}^{\infty} \sum_{l} \exp[-\beta(E_{N,l} - N\mu)]$$

ここで，$\beta = 1/(kT)$ は逆温度であり，$E_{N,l}$ は粒子数が $N$ であるときの第 $l$ 番目のエネルギー状態を表す．

次に，系の圧力 $p$ と大分配関数の関係を考える．
熱力学において，大ポテンシャル $\Omega$ は次のように定義される．

$$\Omega = -kT \log \Xi$$

また，熱力学第一法則および大ポテンシャルの微分形式から，$\Omega$ は次のように表される．

$$d\Omega = -S dT - p dV - N d\mu$$

この式から，体積 $V$ に関する偏微分として圧力 $p$ を求めることができる．

$$p = -\left( \frac{\partial \Omega}{\partial V} \right)_{T, \mu}$$

$\Omega = -kT \log \Xi$ を代入すると，

$$p = -\frac{\partial}{\partial V} (-kT \log \Xi) = kT \frac{\partial \log \Xi}{\partial V} \quad \cdots (1)$$

が得られる．
これが，圧力 $p$ と大分配関数の対数 $\log \Xi$ の微分との関係である．

ここで，体積 $V$ が十分に大きい熱力学的極限において，$\log \Xi$ が体積 $V$ に比例するという性質（示唆される性質）を利用する．
体積 $V$ の空間を，$n$ 個の等しい部分空間（それぞれの体積は $V/n$ ）に分割することを考える．
各部分空間が互いに独立であると見なせる場合（相互作用が無視できるほど弱い場合），全体の分配関数 $\Xi$ は各部分の分配関数の積として表される．

$$\Xi(T, \mu, V) = [\Xi(T, \mu, V/n)]^n$$

この式の両辺の自然対数をとると，

$$\log \Xi(T, \mu, V) = n \log \Xi(T, \mu, V/n)$$

となる．
ここで，$V' = V/n$ とおくと，$n = V/V'$ であるから，

$$\log \Xi(T, \mu, V) = \frac{V}{V'} \log \Xi(T, \mu, V')$$

$$\frac{\log \Xi(T, \mu, V)}{V} = \frac{\log \Xi(T, \mu, V')}{V'}$$

この関係は，$\frac{\log \Xi}{V}$ が体積 $V$ によらず一定であることを示している．
したがって，$\log \Xi$ は $V$ の一次関数であり，次のように書ける．

$$\log \Xi(T, \mu, V) = C V \quad (C \text{ は } T, \mu \text{ のみの関数})$$

このとき，体積 $V$ に関する偏微分は次のようになる．

$$\frac{\partial \log \Xi}{\partial V} = C = \frac{\log \Xi}{V} \quad \cdots (2)$$

最後に，式 (1) に 式 (2) を代入すると，

$$p = kT \left( \frac{\log \Xi}{V} \right)$$

両辺に $V$ をかけることで，目的の関係式が得られる．

$$pV = kT \log \Xi$$

（証明終）

## 解説

本問題では，統計力学における「大分配アンサンブル（グランドカノニカル・アンサンブル）」の性質を用いて，マクロな熱力学量である圧力 $p$ と，ミクロな状態の集まりである大分配関数 $\Xi$ の関係を導出した．

重要なポイントは以下の3点である．

1. **大ポテンシャル $\Omega$ との関係**
   統計力学において，粒子数が変動し，エネルギーも交換される系では，大ポテンシャル $\Omega = -kT \log \Xi$ が最も自然な熱力学的ポテンシャルとなる．
   熱力学の基本関係式から，圧力は $\Omega$ の体積による変化率として定義される．

2. **示量性と示能性**
   大分配関数の対数 $\log \Xi$ は，体積 $V$ に対して「示量性（extensivity）」を持つ．
   つまり，系を2倍の体積にすれば $\log \Xi$ も2倍になるという性質である．
   この性質から，$\frac{\partial \log \Xi}{\partial V} = \frac{\log \Xi}{V}$ という非常に簡潔な関係が導かれる．

3. **熱力学的極限**
   「部分空間が独立である」という仮定は，系が十分に大きく，部分間の相互作用が全体の性質に影響を与えない「熱力学的極限」において正当化される．
   これにより，複雑な多体系の統計量を，小さな部分の統計量の組み合わせとして扱うことが可能になる．
