# 演習問題【5-R-11】

## 解答

大分配関数 $\Xi(T,\mu,V)$ に対して，

```math
\boxed{
pV=kT\ln\Xi
}
```

が成り立つことを証明する．
ここで， $T$ は温度， $\mu$ は化学ポテンシャル， $V$ は体積， $p$ は圧力， $k$ はボルツマン定数である．
$\ln$ は自然対数を表す．

証明では，まず大分配関数の体積微分と圧力の関係を導き，次に $\ln\Xi$ が体積に比例することを示す．
以下では，粒子は1種類であり，系は十分に大きく，一様な巨視的系として扱えるものとする．

### 1．圧力と大分配関数の体積微分の関係

粒子数が $N$ の系における，
温度 $T$ ，体積 $V$ での分配関数を

```math
Z_N(T,V)=\sum_l e^{-\beta E_{N,l}(V)}
```

と定義する．
ここで， $\beta=1/(kT)$ ， $E_{N,l}(V)$ は粒子数 $N$ の第 $l$ 番目の微視的状態のエネルギーである．
このとき，大分配関数は

```math
\Xi(T,\mu,V)
=\sum_{N=0}^{\infty}e^{\beta\mu N}Z_N(T,V)
```

と表される．
したがって，

```math
\Xi(T,\mu,V)
=\sum_{N=0}^{\infty}\sum_l
e^{-\beta(E_{N,l}(V)-\mu N)}
\tag{1}
```

である．

式 (1) を体積 $V$ について偏微分する．
温度 $T$ と化学ポテンシャル $\mu$ を一定に保つと， $\beta$ と $\mu N$ は体積に依存しないため，

```math
\begin{aligned}
kT\frac{\partial\ln\Xi}{\partial V}
&=\frac{kT}{\Xi}\frac{\partial\Xi}{\partial V}\\
&=\frac{1}{\Xi}
\sum_{N=0}^{\infty}\sum_l
\left(-\frac{\partial E_{N,l}}{\partial V}\right)
e^{-\beta(E_{N,l}-\mu N)}
\end{aligned}
\tag{2}
```

を得る．
ここでは $kT\beta=1$ を用いた．

次に，粒子数が $N$ の系の圧力を $p_N$ とする．
カノニカル分布では，

```math
p_N
=kT\frac{\partial\ln Z_N}{\partial V}
```

であり，分配関数の定義を用いれば，

```math
p_N
=\frac{1}{Z_N}
\sum_l
\left(-\frac{\partial E_{N,l}}{\partial V}\right)
e^{-\beta E_{N,l}}
\tag{3}
```

となる．
つまり， $p_N$ は粒子数 $N$ を固定した系の圧力であり，微視的状態に由来する圧力をカノニカル分布で平均した量である．

一方，大分配系で粒子数が $N$ となる確率は，

```math
P_r(N)=\frac{e^{\beta\mu N}Z_N}{\Xi}
\tag{4}
```

である．
式 (3)，式 (4) を式 (2) に用いると，

```math
\begin{aligned}
kT\frac{\partial\ln\Xi}{\partial V}
&=\sum_{N=0}^{\infty}
\frac{e^{\beta\mu N}Z_N}{\Xi}\,p_N\\
&=\sum_{N=0}^{\infty}P_r(N)p_N.
\end{aligned}
```

右辺は，粒子数が変動する系で観測される圧力である．
これを $p$ と書けば，

```math
\boxed{
p=kT\left(\frac{\partial\ln\Xi}{\partial V}\right)_{T,\mu}
}
\tag{5}
```

を得る．

### 2．大分配関数の対数が体積に比例すること

次に，体積が十分に大きいとき， $\ln\Xi$ が $V$ に比例することを示す．

体積 $V$ の空間を，体積がそれぞれ $V/n$ である $n$ 個の等しい部分空間に分割することを考える．
仕切りは熱と粒子を通すものとし，仕切りや部分空間間の相互作用，境界による影響を無視できるとする．
このとき，各部分空間は温度 $T$ ，化学ポテンシャル $\mu$ のもとで独立な系とみなせる．

粒子数が各部分空間にそれぞれ $N_1,N_2,\ldots,N_n$ 個あるとき，合成系の分配関数は各部分空間の分配関数の積である．
全粒子数について和をとると，各部分空間の粒子数 $N_i$ について独立に和をとることができるため，大分配関数は

```math
\begin{aligned}
\Xi(T,\mu,V)
&=\sum_{N_1,\ldots,N_n}
\prod_{i=1}^{n}
\left[e^{\beta\mu N_i}Z_{N_i}(T,V/n)\right]\\
&=\prod_{i=1}^{n}
\left[
\sum_{N_i=0}^{\infty}
e^{\beta\mu N_i}Z_{N_i}(T,V/n)
\right]\\
&=\left[\Xi(T,\mu,V/n)\right]^n
\end{aligned}
\tag{6}
```

となる．

式 (6) の自然対数をとると，

```math
\ln\Xi(T,\mu,V)
=n\ln\Xi(T,\mu,V/n)
\tag{7}
```

を得る．
したがって，

```math
\frac{\ln\Xi(T,\mu,V)}{V}
=
\frac{\ln\Xi(T,\mu,V/n)}{V/n}
\tag{8}
```

である．
これは，体積で割った $\ln\Xi$ が，体積の分割によって変化しないことを意味する．
十分に大きな体積について境界効果を無視でき，体積を連続的に変化させて考えられる熱力学的極限では，

```math
\ln\Xi(T,\mu,V)=C(T,\mu)V
\tag{9}
```

と書ける．
ここで $C(T,\mu)$ は，温度と化学ポテンシャルには依存するが，体積には依存しない関数である．

式 (9) を体積 $V$ で偏微分すると，

```math
\frac{\partial\ln\Xi}{\partial V}=C(T,\mu)
=\frac{\ln\Xi}{V}
```

となる．
よって，

```math
\boxed{
\left(\frac{\partial\ln\Xi}{\partial V}\right)_{T,\mu}
=\frac{\ln\Xi}{V}
}
\tag{10}
```

が成り立つ．

### 3．求める関係式

式 (5) と式 (10) を組み合わせると，

```math
p=kT\frac{\ln\Xi}{V}
```

となる．
両辺に $V$ を掛ければ，

```math
\boxed{
pV=kT\ln\Xi
}
```

が得られる．
以上で証明は完了である．

なお，体積に対する比例関係は，部分系間の相互作用や境界効果が巨視的な性質に与える影響を無視できる熱力学的極限で成立する．
