# 演習問題【5-A-2】

## 解答

### 1．Lorentz の方法による圧力の定式化

理想気体中に，面積 $\delta\sigma$ の仮想的な面積素片を考え，その法線方向を $x$ 軸とする．
この面積素片を通して，時間 $\delta t$ の間に裏側から表側へ輸送される運動量の法線成分を $\delta P_n$ とすると，面積素片の両側が互いに及ぼし合う圧力 $p$ は，

```math
p=\frac{\delta P_n}{\delta\sigma\,\delta t}
\tag{1}
```

と表される．
すなわち，圧力は単位時間，単位面積当たりに輸送される法線方向の運動量である．

以下では，分子の質量を $m$ ，速度を $\boldsymbol{v}=(v_x,v_y,v_z)$ とする．
また，速度が $\boldsymbol{v}$ の分子の単位体積当たりの数を $n(\boldsymbol{v})$ と表す．

### 2．面積素片を通過する分子による運動量輸送

時間 $\delta t$ の間に面積素片を通過する分子は，面積素片を底面とし，分子の移動距離を高さとする斜めの筒の中に存在する分子である．
この筒の体積は，速度の法線成分 $v_x$ を用いて

```math
\delta V=\delta\sigma |v_x|\delta t
```

と表される．
したがって，速度が $\boldsymbol{v}$ の分子のうち，時間 $\delta t$ の間に面積素片を通過する分子の数は，

```math
n(\boldsymbol{v})\delta\sigma |v_x|\delta t
```

である．

ここで，運動量輸送には，裏側から表側へ通過する分子だけでなく，表側から裏側へ通過する分子も寄与する．
両方の場合について，表側へ輸送される運動量を計算する．

**（i）裏側から表側へ通過する分子（ $v_x>0$ ）**

この場合，分子は正の法線方向速度 $v_x$ をもち，その法線方向の運動量 $mv_x$ を表側へ運ぶ．
したがって，この分子群による運動量輸送の寄与は，

```math
\delta_1P_n
=\sum_{v_x>0}
n(\boldsymbol{v})\delta\sigma v_x\delta t
\,mv_x
```

すなわち，

\[
\delta_1P_n
=\sum_{v_x>0}
n(\boldsymbol{v})mv_x^2
\delta\sigma\delta t
\tag{2}
\]

となる．

**（ii）表側から裏側へ通過する分子（ $v_x<0$ ）**

この場合，分子の法線方向速度は負であり，その運動量 $mv_x$ も負である．
分子が表側から裏側へ通過すると，表側はその分子に運動量 $mv_x$ を与えるため，表側が受け取る運動量の変化は $-mv_x$ となる．

また，この分子群が通過する数は，

```math
n(\boldsymbol{v})\delta\sigma |v_x|\delta t
=-n(\boldsymbol{v})\delta\sigma v_x\delta t
```

である．
したがって，この分子群による運動量輸送の寄与は，

```math
\begin{aligned}
\delta_2P_n
&=\sum_{v_x<0}
\bigl(-n(\boldsymbol{v})v_x\delta\sigma\delta t\bigr)
(-mv_x)\\
&=\sum_{v_x<0}
n(\boldsymbol{v})mv_x^2
\delta\sigma\delta t
\end{aligned}
\tag{3}
```

となる．

式 (2)，(3) を加えると，すべての速度の分子による運動量輸送は，

```math
\delta P_n
=\sum_{\text{すべての速度}}
n(\boldsymbol{v})mv_x^2
\delta\sigma\delta t
```

となる．
これを式 (1) に代入すれば，

```math
p=\sum_{\text{すべての速度}}
n(\boldsymbol{v})mv_x^2
\tag{4}
```

が得られる．
ここでは，速度の種類を離散的に表した和を用いた．
速度分布を連続的に扱う場合には，この和を速度空間での積分に置き換える．

### 3．圧力と平均運動エネルギーの関係

気体の単位体積当たりの分子数を $n$ ，分子の速度成分 $v_x$ の二乗の平均を $\overline{v_x^2}$ とする．
式 (4) より，

```math
p=nm\overline{v_x^2}
\tag{5}
```

となる．

気体の速度分布は等方的であるとする．
すなわち，特定の方向が優先されないため，

```math
\overline{v_x^2}
=\overline{v_y^2}
=\overline{v_z^2}
```

が成り立つ．
一方，速度の大きさの二乗は

```math
v^2=v_x^2+v_y^2+v_z^2
```

であるから，平均を取ると，

```math
\overline{v^2}
=3\overline{v_x^2}
```

となる．
したがって，

```math
\overline{v_x^2}
=\frac{1}{3}\overline{v^2}
```

であり，式 (5) は

```math
p=\frac{1}{3}nm\overline{v^2}
\tag{6}
```

と書ける．

分子の平均運動エネルギーを

```math
\bar E=\frac{1}{2}m\overline{v^2}
```

と定義すれば，式 (6) は

```math
\boxed{p=\frac{2}{3}n\bar E}
\tag{7}
```

となる．
これが気体分子運動論における Bernoulli の公式である．

### 4．Maxwell 分布を用いた圧力の計算

次に，分子の速度分布が温度 $T$ の Maxwell 分布に従うものとして，式 (5) の圧力を具体的に計算する．

速度の三成分に対する Maxwell 分布関数は，

```math
\begin{aligned}
f(v_x,v_y,v_z)
={}&\left(\frac{m}{2\pi kT}\right)^{3/2}\\
&\times
\exp\left[
-\frac{m}{2kT}
(v_x^2+v_y^2+v_z^2)
\right]
\end{aligned}
\tag{8}
```

である．
ここで， $k$ は Boltzmann 定数であり， $f$ は

```math
\iiint_{-\infty}^{\infty}
f(v_x,v_y,v_z)\,dv_x\,dv_y\,dv_z=1
```

を満たす規格化された速度分布関数である．
したがって，速度成分の二乗の平均は，この分布関数を用いて積分することで求められる．

式 (5) より，圧力は

```math
p=nm\iiint_{-\infty}^{\infty}
v_x^2f(v_x,v_y,v_z)\,
dv_x\,dv_y\,dv_z
\tag{9}
```

と表される．

式 (8) を式 (9) に代入すると，指数関数の中の各速度成分の項を分離できるため，

```math
\begin{aligned}
p={}&nm\left(\frac{m}{2\pi kT}\right)^{3/2}\\
&\times
\left(\int_{-\infty}^{\infty}
v_x^2e^{-\frac{m}{2kT}v_x^2}\,dv_x\right)\\
&\times
\left(\int_{-\infty}^{\infty}
e^{-\frac{m}{2kT}v_y^2}\,dv_y\right)\\
&\times
\left(\int_{-\infty}^{\infty}
e^{-\frac{m}{2kT}v_z^2}\,dv_z\right)
\end{aligned}
\tag{10}
```

となる．

ここで，次のガウス積分の公式を用いる．

```math
\sqrt{\frac{a}{2\pi}}
\int_{-\infty}^{\infty}
e^{-\frac a2x^2}\,dx=1
\tag{11}
```

```math
\sqrt{\frac{a}{2\pi}}
\int_{-\infty}^{\infty}
x^2e^{-\frac a2x^2}\,dx
=\frac{1}{a}
\tag{12}
```

これらの公式は， $a>0$ のときに成り立つ．
式 (10) において，

```math
a=\frac{m}{kT}
```

とおくと，各積分は，

```math
\int_{-\infty}^{\infty}
e^{-\frac a2v_y^2}\,dv_y
=\sqrt{\frac{2\pi}{a}}
```

```math
\int_{-\infty}^{\infty}
e^{-\frac a2v_z^2}\,dv_z
=\sqrt{\frac{2\pi}{a}}
```

および，

```math
\int_{-\infty}^{\infty}
v_x^2e^{-\frac a2v_x^2}\,dv_x
=\frac{1}{a}\sqrt{\frac{2\pi}{a}}
```

となる．
したがって，式 (10) は，

```math
\begin{aligned}
p
&=nm\left(\frac{a}{2\pi}\right)^{3/2}
\frac{1}{a}\left(\frac{2\pi}{a}\right)^{3/2}\\
&=\frac{nm}{a}
\end{aligned}
```

と計算できる．
ここに $a=m/(kT)$ を代入すれば，

```math
\boxed{
p=nkT
}
\tag{13}
```

が得られる．

以上より，Lorentz の方法によって，気体分子が仮想的な面積素片を通過する際の運動量輸送から圧力の式を導き，Maxwell 分布を用いて計算すると，理想気体の圧力は $p=nkT$ となることが示された．
