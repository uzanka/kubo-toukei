# 演習問題【5-A-15】

## 解答

### (i) 古典的な分配関数

#### 1．ハミルトニアンと分配関数

質量 $m$ ，固有角振動数 $\omega$ の1個の調和振動子を考える．
位置を $q$ ，運動量を $p$ とすると，ハミルトニアン，すなわち系の全エネルギーは

```math
\mathcal H(p,q)=\frac{p^2}{2m}+\frac12m\omega^2q^2
```

である．
第1項は運動エネルギー，第2項はポテンシャルエネルギーである．

古典的な分配関数 $Z_{\mathrm{cl}}$ は，位相空間 $(p,q)$ 全体にわたってボルツマン因子を積分したものであり，

```math
Z_{\mathrm{cl}}
=\frac1h
\int_{-\infty}^{\infty}dp
\int_{-\infty}^{\infty}dq\,
e^{-\beta\mathcal H(p,q)}
```

と定義される．
ここで，

```math
\beta=\frac1{kT}
```

であり， $k$ はボルツマン定数， $T$ は絶対温度， $h$ はプランク定数である．
位相空間の面積を $h$ で割ることにより，分配関数を無次元量として定義している．

#### 2．ガウス積分による計算

ハミルトニアンは $p$ と $q$ に関する項に分離できるため，

```math
\begin{aligned}
Z_{\mathrm{cl}}
={}&\frac1h
\left(\int_{-\infty}^{\infty}
e^{-\beta p^2/(2m)}\,dp\right)\\
&\times
\left(\int_{-\infty}^{\infty}
e^{-\beta m\omega^2q^2/2}\,dq\right)
\end{aligned}
```

となる．
ここで，ガウス積分の公式

```math
\int_{-\infty}^{\infty}e^{-ax^2}\,dx
=\sqrt{\frac{\pi}{a}}
\qquad(a>0)
```

を用いると，

```math
\int_{-\infty}^{\infty}
e^{-\beta p^2/(2m)}\,dp
=\sqrt{\frac{2\pi m}{\beta}}
=\sqrt{2\pi mkT}
```

および

```math
\int_{-\infty}^{\infty}
e^{-\beta m\omega^2q^2/2}\,dq
=\sqrt{\frac{2\pi}{\beta m\omega^2}}
=\sqrt{\frac{2\pi kT}{m\omega^2}}
```

を得る．
これらを掛け合わせると，

```math
\begin{aligned}
Z_{\mathrm{cl}}
&=\frac1h
\sqrt{2\pi mkT}
\sqrt{\frac{2\pi kT}{m\omega^2}}\\
&=\frac{2\pi kT}{h\omega}
\end{aligned}
```

となる．
換算プランク定数 $\hbar=h/(2\pi)$ を用いれば，求める古典的な分配関数は

```math
\boxed{
Z_{\mathrm{cl}}=\frac{kT}{\hbar\omega}
}
\tag{1}
```

である．

### (ii) 量子論的な分配関数

#### 1．エネルギー準位

量子力学的な調和振動子のエネルギー固有値は，

```math
\varepsilon_n=\left(n+\frac12\right)\hbar\omega,
\qquad n=0,1,2,\ldots
```

である．
ここで $\hbar=h/(2\pi)$ である．
量子論ではエネルギーが連続的な値ではなく，このような離散的な値をとる．
また，最低エネルギーはゼロではなく， $\hbar\omega/2$ である．

量子論的な分配関数 $Z_{\mathrm{q}}$ は，各エネルギー準位のボルツマン因子をすべて足し合わせることで定義される．
したがって，

```math
\begin{aligned}
Z_{\mathrm{q}}
&=\sum_{n=0}^{\infty}e^{-\beta\varepsilon_n}\\
&=\sum_{n=0}^{\infty}
e^{-\beta(n+1/2)\hbar\omega}\\
&=e^{-\beta\hbar\omega/2}
\sum_{n=0}^{\infty}
\left(e^{-\beta\hbar\omega}\right)^n
\end{aligned}
```

となる．

#### 2．無限等比級数による計算

右辺の級数は，公比 $r=e^{-\beta\hbar\omega}$ の無限等比級数である．
$T>0$ では $0<r<1$ であるため，

```math
\sum_{n=0}^{\infty}r^n=\frac1{1-r}
```

を用いることができる．
よって，

```math
Z_{\mathrm{q}}
=\frac{e^{-\beta\hbar\omega/2}}
{1-e^{-\beta\hbar\omega}}
```

となる．
分子と分母を整理すると，

```math
\begin{aligned}
Z_{\mathrm{q}}
&=\frac1{e^{\beta\hbar\omega/2}
-e^{-\beta\hbar\omega/2}}\\
&=\frac1{2\sinh(\beta\hbar\omega/2)}
\end{aligned}
```

を得る．
したがって，求める量子論的な分配関数は

```math
\boxed{
Z_{\mathrm{q}}
=\frac1{2\sinh\left(\dfrac{\hbar\omega}{2kT}\right)}
}
\tag{2}
```

である．

#### 3．古典的な分配関数との比較

高温極限では，

```math
\frac{\hbar\omega}{kT}\to0
```

となる．
このとき， $\sinh z\simeq z$ という近似を用いると，

```math
\begin{aligned}
Z_{\mathrm{q}}
&\simeq
\frac1{2\left(\dfrac{\hbar\omega}{2kT}\right)}\\
&=\frac{kT}{\hbar\omega}
\end{aligned}
```

となる．
これは式 (1) で求めた古典的な分配関数に一致する．
したがって，高温では量子論的な結果が古典論の結果に近づくことが確認できる．

### (iii) $N$ 個の振動子からなる系の内部エネルギー，エントロピー，熱容量

#### 1．系全体の分配関数

同じ振動数 $\omega$ をもち，互いに独立な振動子 $N$ 個からなる系を考える．
各振動子は独立にエネルギー状態をとるため，系全体の分配関数 $Z$ は，1個の振動子の分配関数の積である．
したがって，

```math
\begin{aligned}
Z
&=(Z_{\mathrm{q}})^N\\
&=\left[
2\sinh\left(\frac{\beta\hbar\omega}{2}\right)
\right]^{-N}
\end{aligned}
```

となる．
よって，

```math
\boxed{
Z=
\left[
2\sinh\left(\frac{\hbar\omega}{2kT}\right)
\right]^{-N}
}
\tag{3}
```

である．
以下では，この量子論的な分配関数から熱力学量を求める．
計算を簡潔にするため，

```math
y=\frac{\hbar\omega}{kT}=\beta\hbar\omega
```

とおく．

#### 2．内部エネルギー $U$

正準集団における内部エネルギーは，分配関数の対数を逆温度 $\beta$ で微分することで求められる．
すなわち，

```math
U=-\frac{\partial\ln Z}{\partial\beta}
```

である．
式 (3) より，

```math
\ln Z=-N\ln\left[
2\sinh\left(\frac{\beta\hbar\omega}{2}\right)
\right]
```

であるから，

```math
\begin{aligned}
U
&=N\frac{\partial}{\partial\beta}
\ln\left[
2\sinh\left(\frac{\beta\hbar\omega}{2}\right)
\right]\\
&=N\frac{\hbar\omega}{2}
\frac{\cosh(\beta\hbar\omega/2)}
{\sinh(\beta\hbar\omega/2)}
\end{aligned}
```

となる．
ここで双曲線関数の関係

```math
\coth z=\frac{\cosh z}{\sinh z}
```

を用いると，

```math
U=N\frac{\hbar\omega}{2}
\coth\left(\frac{\beta\hbar\omega}{2}\right)
```

を得る．
さらに，指数関数を用いた恒等式

```math
\coth\frac y2=1+\frac2{e^y-1}
```

により，

```math
\boxed{
U=N\left[
\frac{\hbar\omega}{2}
+\frac{\hbar\omega}{e^{\hbar\omega/(kT)}-1}
\right]
}
\tag{4}
```

となる．

第1項 $N\hbar\omega/2$ は，温度がゼロに近づいても残る零点エネルギーである．
第2項は，温度上昇によって励起された量子状態の寄与である．

#### 3．熱容量 $C$

熱容量は，振動子数 $N$ と固有角振動数 $\omega$ を一定に保ったときの内部エネルギーの温度微分である．
すなわち，

```math
C=\left(\frac{\partial U}{\partial T}\right)_{N,\omega}
```

である．
式 (4) を用いると，

```math
\frac{\partial U}{\partial T}
=N\hbar\omega
\frac{\partial}{\partial T}
\left(e^{\hbar\omega/(kT)}-1\right)^{-1}
```

となる．
ここで，

```math
y=\frac{\hbar\omega}{kT},
\qquad
\frac{dy}{dT}=-\frac{y}{T}
```

であるから，

```math
\begin{aligned}
C
&=N\hbar\omega
\frac{e^y}{(e^y-1)^2}\frac{y}{T}\\
&=Nk\,y^2\frac{e^y}{(e^y-1)^2}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
C=Nk
\frac{\left(\dfrac{\hbar\omega}{kT}\right)^2
e^{\hbar\omega/(kT)}}
{\left(e^{\hbar\omega/(kT)}-1\right)^2}
}
\tag{5}
```

を得る．

#### 4．エントロピー $S$

エントロピーは，ヘルムホルツ自由エネルギー $F$ を用いて求める．
自由エネルギーは，

```math
F=-kT\ln Z
```

と定義される．
式 (3) を代入すると，

```math
F=NkT\ln\left[
2\sinh\left(\frac{\beta\hbar\omega}{2}\right)
\right]
```

となる．
また，

```math
2\sinh\frac y2=e^{y/2}(1-e^{-y})
```

であるため，

```math
\boxed{
F=N\left[
\frac{\hbar\omega}{2}
+kT\ln(1-e^{-y})
\right]
}
\tag{6}
```

と書ける．

熱力学の関係 $F=U-TS$ より，

```math
S=\frac{U-F}{T}
```

である．
式 (4)，(6) を代入すると，

```math
\begin{aligned}
S
&=\frac NT\left[
\frac{\hbar\omega}{2}
+\frac{\hbar\omega}{e^y-1}
-\frac{\hbar\omega}{2}
-kT\ln(1-e^{-y})
\right]\\
&=Nk\left[
\frac{y}{e^y-1}
-\ln(1-e^{-y})
\right]
\end{aligned}
```

を得る．
ここで，

```math
\frac y2\coth\frac y2
=\frac y2+\frac{y}{e^y-1}
```

および

```math
\ln\left(2\sinh\frac y2\right)
=\frac y2+\ln(1-e^{-y})
```

を用いれば，エントロピーは次のようにも表せる．

```math
\boxed{
S=Nk\left[
\frac{\hbar\omega}{2kT}
\coth\left(\frac{\hbar\omega}{2kT}\right)
-\ln\left\{
2\sinh\left(\frac{\hbar\omega}{2kT}\right)
\right\}
\right]
}
\tag{7}
```

これが，量子調和振動子 $N$ 個からなる系のエントロピーである．

#### 5．高温極限と低温極限の確認

得られた式の物理的な意味を確かめるため，温度の極限を考える．

高温極限 $kT\gg\hbar\omega$ では $y\ll1$ であり，

```math
U\simeq NkT,\qquad C\simeq Nk
```

となる．
これは古典的な調和振動子の結果と一致する．
また，エントロピーは

```math
S\simeq Nk\left[
1+\ln\left(\frac{kT}{\hbar\omega}\right)
\right]
```

と近似できる．

一方，低温極限 $kT\ll\hbar\omega$ では，励起状態の寄与が指数関数的に小さくなるため，

```math
U\to N\frac{\hbar\omega}{2},
\qquad
S\to0,
\qquad
C\to0
```

となる．
零点エネルギーは残るが，温度がゼロに近づくとエントロピーと熱容量はゼロに近づくのである．

以上より，古典的・量子的な分配関数と，それらを用いて求めた内部エネルギー，エントロピー，熱容量が得られた．
