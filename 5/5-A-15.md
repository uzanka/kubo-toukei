# 演習問題【5-A-15】

## 解答

### (i) 古典的な分配関数の計算

古典力学における1個の調和振動子のハミルトニアン $\mathcal{H}$ は，位置 $q$ と運動量 $p$ を用いて次のように書ける．

$$\mathcal{H}(p, q) = \frac{p^2}{2m} + \frac{1}{2}m\omega^2q^2$$

ここで， $m$ は質量， $\omega$ は固有角振動数である．

古典的な統計力学において，単一の微視的状態を積分して得る分配関数 $Z_\mu$ は，位相空間 $(p, q)$ についての積分として次のように定義される．

$$Z_\mu = \frac{1}{h} \int_{-\infty}^{\infty} dp \int_{-\infty}^{\infty} dq \, e^{-\beta\mathcal{H}(p, q)}$$

ただし， $\beta = \frac{1}{kT}$ （ $k$ はボルツマン定数， $T$ は絶対温度）であり， $h$ はプランク定数である．

この積分を計算する．
指数関数の中身が $p$ と $q$ について分離していることに注目すると，

$$Z_\mu = \frac{1}{h} \left( \int_{-\infty}^{\infty} e^{-\frac{\beta p^2}{2m}} dp \right) \left( \int_{-\infty}^{\infty} e^{-\frac{\beta m\omega^2 q^2}{2}} dq \right)$$

となる．
ここで，ガウス積分 $\int_{-\infty}^{\infty} e^{-ax^2} dx = \sqrt{\frac{\pi}{a}}$ の公式を利用すると，

$$\int_{-\infty}^{\infty} e^{-\frac{\beta p^2}{2m}} dp = \sqrt{\frac{2\pi m}{\beta}} = \sqrt{2\pi mkT}$$

$$\int_{-\infty}^{\infty} e^{-\frac{\beta m\omega^2 q^2}{2}} dq = \sqrt{\frac{2\pi}{\beta m\omega^2}} = \sqrt{\frac{2\pi kT}{m\omega^2}}$$

したがって，

$$Z_\mu = \frac{1}{h} \sqrt{2\pi mkT} \cdot \sqrt{\frac{2\pi kT}{m\omega^2}} = \frac{2\pi kT}{h\omega} = \frac{kT}{\hbar\omega}$$

となる．
（ここで $\hbar = h/2\pi$ である．）

### (ii) 量子論的な分配関数の計算

量子力学的な調和振動子のエネルギー準位 $\varepsilon_n$ は，次のように離散的な値をとる．

$$\varepsilon_n = \left( n + \frac{1}{2} \right) \hbar\omega \quad (n = 0, 1, 2, \dots)$$

量子論的な分配関数 $Z_\mu$ は，すべての可能なエネルギー準位についてのボルツマン因子の和として求められる．

$$Z_\mu = \sum_{n=0}^{\infty} e^{-\beta\varepsilon_n} = \sum_{n=0}^{\infty} e^{-\beta(n+1/2)\hbar\omega} = e^{-\frac{\beta\hbar\omega}{2}} \sum_{n=0}^{\infty} \left( e^{-\beta\hbar\omega} \right)^n$$

右辺の総和は，公比 $r = e^{-\beta\hbar\omega}$ の無限等比級数である．
$|r| < 1$ であるから，

$$\sum_{n=0}^{\infty} r^n = \frac{1}{1-r} = \frac{1}{1 - e^{-\beta\hbar\omega}}$$

となる．
したがって，

$$Z_\mu = \frac{e^{-\frac{\beta\hbar\omega}{2}}}{1 - e^{-\beta\hbar\omega}}$$
分母と分子に $e^{\frac{\beta\hbar\omega}{2}}$ を掛けると，

$$Z_\mu = \frac{1}{e^{\frac{\beta\hbar\omega}{2}} - e^{-\frac{\beta\hbar\omega}{2}}} = \frac{1}{2 \sinh \left( \frac{\beta\hbar\omega}{2} \right)}$$

となる．

ここで，高温極限 $\beta\hbar\omega \to 0$ を考えると， $\sinh x \approx x$ より，

$$Z_\mu \approx \frac{1}{2 \cdot \frac{\beta\hbar\omega}{2}} = \frac{1}{\beta\hbar\omega} = \frac{kT}{\hbar\omega}$$

となり，(i) の古典的な結果と一致することが確認できる．

### (iii) $N$ 個の振動子からなる系の熱力学量

独立な $N$ 個の振動子から成る系の全分配関数 $Z$ は，各振動子の分配関数の積で与えられる．

$$Z = (Z_\mu)^N = \left[ 2 \sinh \left( \frac{\beta\hbar\omega}{2} \right) \right]^{-N}$$

#### 内部エネルギー $U$
内部エネルギー $U$ は，分配関数を用いて次のように計算できる．

$$U = -\frac{\partial}{\partial \beta} \log Z$$

ここで， $Z = (\dots)^{-N}$ より $\log Z = -N \log\left( 2 \sinh \frac{\beta\hbar\omega}{2} \right)$ であるから，

$$U = -\frac{\partial}{\partial \beta} \left[ -N \log \left( 2 \sinh \frac{\beta\hbar\omega}{2} \right) \right] = N \frac{\partial}{\partial \beta} \log \left( 2 \sinh \frac{\beta\hbar\omega}{2} \right)$$

$$U = N \frac{1}{2 \sinh \frac{\beta\hbar\omega}{2}} \cdot 2 \cosh \left( \frac{\beta\hbar\omega}{2} \right) \cdot \frac{\hbar\omega}{2} = N \frac{\hbar\omega}{2} \coth \left( \frac{\beta\hbar\omega}{2} \right)$$

さらに $\coth x = \frac{e^x + e^{-x}}{e^x - e^{-x}} = \frac{1 + e^{-2x}}{1 - e^{-2x}} = 1 + \frac{2}{e^{2x}-1}$ という関係を用いると，

$$U = N \frac{\hbar\omega}{2} \left( 1 + \frac{2}{e^{\beta\hbar\omega} - 1} \right) = N \left( \frac{\hbar\omega}{2} + \frac{\hbar\omega}{e^{\beta\hbar\omega} - 1} \right)$$

温度 $T$ を用いて書き直すと，

$$U = N \left( \frac{\hbar\omega}{2} + \frac{\hbar\omega}{e^{\hbar\omega/(kT)} - 1} \right)$$

#### 熱容量 $C$

熱容量 $C$ は，内部エネルギーを温度 $T$ で微分することで求められる．

$$C = \frac{dU}{dT} = \frac{dU}{d\beta} \frac{d\beta}{dT}$$

ここで $\beta = \frac{1}{kT}$ より $\frac{d\beta}{dT} = -\frac{1}{kT^2}$ である．

$$\frac{dU}{d\beta} = N \frac{\partial}{\partial \beta} \left( \frac{\hbar\omega}{2} + \hbar\omega (e^{\beta\hbar\omega} - 1)^{-1} \right) = N \hbar\omega \cdot (-1)(e^{\beta\hbar\omega}-1)^{-2} \cdot \hbar\omega e^{\beta\hbar\omega} = -N \frac{(\hbar\omega)^2 e^{\beta\hbar\omega}}{(e^{\beta\hbar\omega}-1)^2}$$

よって，

$$C = \left( -N \frac{(\hbar\omega)^2 e^{\beta\hbar\omega}}{(e^{\beta\hbar\omega}-1)^2} \right) \left( -\frac{1}{kT^2} \right) = Nk \frac{(\hbar\omega/kT)^2 e^{\hbar\omega/(kT)}}{(e^{\hbar\omega/(kT)} - 1)^2}$$

これは解答例 (5) と一致する．

#### エントロピー $S$

ヘルムホルツの自由エネルギー $F$ は，

$$F = -kT \log Z = -kT \log \left[ 2 \sinh \left( \frac{\hbar\omega}{2kT} \right) \right]^{-N} = NkT \log \left( 2 \sinh \frac{\hbar\omega}{2kT} \right)$$

ここで， $\sinh x = \frac{e^x - e^{-x}}{2}$ を用いると，

$$F = NkT \log \left( e^{\frac{\hbar\omega}{2kT}} (1 - e^{-\frac{\hbar\omega}{kT}}) \right) = NkT \left( \frac{\hbar\omega}{2kT} + \log(1 - e^{-\frac{\hbar\omega}{kT}}) \right) = N \left( \frac{\hbar\omega}{2} + kT \log(1 - e^{-\frac{\hbar\omega}{kT}}) \right)$$

エントロピー $S$ は，熱力学の関係式 $F = U - TS$ より， $S = \frac{U - F}{T}$ と書ける．

$$S = \frac{1}{T} \left[ N \left( \frac{\hbar\omega}{2} + \frac{\hbar\omega}{e^{\beta\hbar\omega} - 1} \right) - N \left( \frac{\hbar\omega}{2} + kT \log(1 - e^{-\beta\hbar\omega}) \right) \right]$$

$$S = \frac{N\hbar\omega}{T(e^{\beta\hbar\omega}-1)} - Nk \log(1 - e^{-\beta\hbar\omega})$$

以下，エントロピーを整理する．

$$S = \frac{N\hbar\omega}{T} \frac{1}{e^{\beta\hbar\omega}-1} - Nk \log(1 - e^{-\beta\hbar\omega})$$

ここで， $\frac{1}{e^{\beta\hbar\omega}-1} = \frac{e^{-\beta\hbar\omega/2}}{e^{\beta\hbar\omega/2}-e^{-\beta\hbar\omega/2}} = \frac{e^{-\beta\hbar\omega/2}}{2\sinh(\beta\hbar\omega/2)}$ である．
また， $\log(1-e^{-\beta\hbar\omega}) = \log(e^{-\beta\hbar\omega/2}(e^{\beta\hbar\omega/2}-e^{-\beta\hbar\omega/2})) = -\frac{\beta\hbar\omega}{2} + \log(2\sinh(\beta\hbar\omega/2))$ である．
これを代入すると，

$$S = \frac{N\hbar\omega}{T} \frac{e^{-\beta\hbar\omega/2}}{2\sinh(\beta\hbar\omega/2)} + Nk \frac{\beta\hbar\omega}{2} - Nk \log(2\sinh(\beta\hbar\omega/2))$$

$\frac{\beta\hbar\omega}{2} = \frac{\hbar\omega}{2kT}$ であり， $N\hbar\omega \cdot \frac{\hbar\omega}{2kT} = Nk \cdot \frac{\hbar\omega}{2kT}$ なので，第2項は $Nk \frac{\beta\hbar\omega}{2} = \frac{N\hbar\omega}{2T}$ となる．
また， $\frac{e^{-\beta\hbar\omega/2}}{2\sinh(\beta\hbar\omega/2)} = \frac{1}{e^{\beta\hbar\omega/2}-e^{-\beta\hbar\omega/2}} = \frac{1}{2}\cdot\frac{2}{e^{\beta\hbar\omega/2}-e^{-\beta\hbar\omega/2}}$ であるが，ここでは $\coth x = \frac{e^x+e^{-x}}{e^x-e^{-x}}$ の公式を利用して次のように整理する．

$$S = Nk \left[ \frac{\beta\hbar\omega}{2} \coth\left(\frac{\beta\hbar\omega}{2}\right) - \log\left(2\sinh\left(\frac{\beta\hbar\omega}{2}\right)\right) \right]$$

ただし，第1項の変形では $\frac{\beta\hbar\omega}{2} \coth(\frac{\beta\hbar\omega}{2}) = \frac{\beta\hbar\omega}{2} + \frac{\beta\hbar\omega}{e^{\beta\hbar\omega}-1}$ を用いた．
したがって，

```math
S = Nk \left\{ \frac{\hbar\omega}{2kT} \coth \left( \frac{\hbar\omega}{2kT} \right) - \log \left( 2 \sinh \frac{\hbar\omega}{2kT} \right) \right\}
```

## 解説

本問題では，単一の調和振動子をモデルとした系における統計力学的な記述を行いました．

1.  **分配関数 (Partition Function) とは**：
    系の微視的状態の数（あるいはエネルギー状態）と，それらが占有される確率をすべて集約した量である．
    分配関数 $Z$ が分かれば，系のあらゆる熱力学的な性質（内部エネルギー，エントロピー，自由エネルギーなど）を導出することができる．

2.  **古典的 vs 量子論的**：
    - 古典的には，エネルギーは連続的な値をとると考え，位相空間における積分で計算する．
    - 量子論的には，エネルギーは離散的な値 $\varepsilon_n$ をとると考え，その和（総和）として計算する．
    - 高温では量子的な離散性が無視できるようになり，古典的な結果に収束する．

3.  **ハミルトニアン (Hamiltonian)**：
    系の全エネルギーを表す関数である．
    調和振動子の場合は，「運動エネルギー」と「ポテンシャルエネルギー」の和となる．

4.  **熱力学量との関係**：
    - **内部エネルギー $U$**：温度 $T$ の関数としてのエネルギーの期待値である．
      分配関数の対数微分によって求められる．
    - **ヘルムホルツの自由エネルギー $F$**：熱力学的な仕事に使えるエネルギーの指標であり， $F = -kT \log Z$ で定義される．
    - **エントロピー $S$**：系の乱雑さを表す量であり， $S = (U - F)/T$ という関係を用いて導出できる．
    - **熱容量 $C$**：温度の変化に対して，内部エネルギーがどれだけ変化するかを示す指標である．

このように，分配関数という「情報の入り口」から，統計力学の公式を順次適用することで，系のマクロな性質をすべて明らかにすることができる．
