# 演習問題【5-R-5】

## 解答

### (i) 熱の流れる向きとエントロピーの変化

#### 1．状態数とエントロピー，温度の関係

系 $i$ のエネルギーを $E_i$ ，粒子数を $N_i$ とする．
問題文の条件より，粒子数が十分に大きい場合，状態数 $\Omega_i(E_i)$ は

```math
\Omega_i(E_i)\sim
\exp\left\{
N_i\phi_i\left(\frac{E_i}{N_i}\right)
\right\}
\tag{1}
```

という形で表される．
ここで， $\phi_i$ はエネルギーを粒子数で割った量の関数である．
この式では，状態数の主要な寄与を決める指数関数の部分に注目している．

ボルツマンの関係式 $S_i=k\log\Omega_i$ より，系 $i$ のエントロピーは，主要項までの近似として

```math
S_i(E_i)\simeq
kN_i\phi_i\left(\frac{E_i}{N_i}\right)
\tag{2}
```

となる．
一方，温度 $T_i$ はエントロピーのエネルギー微分によって定義されるため，

```math
\frac{1}{T_i}
=\left(\frac{\partial S_i}{\partial E_i}\right)_{N_i}
\tag{3}
```

である．
式 (2) を $E_i$ で微分すると，

```math
\begin{aligned}
\frac{1}{T_i}
&\simeq
kN_i\phi_i'\left(\frac{E_i}{N_i}\right)
\frac{1}{N_i}\\
&=k\phi_i'\left(\frac{E_i}{N_i}\right)
\end{aligned}
\tag{4}
```

を得る．
以下では，熱の移動によるエントロピー変化をこの近似で求める．

#### 2．熱の移動に伴うエントロピー変化

最初，系1と系2の温度をそれぞれ $T_1$ ， $T_2$ とし， $T_1>T_2$ とする．
両系を熱的に接触させ，系1から系2へ微小な熱量 $d'Q$ が移動したとする．
ここでは，系1から系2へ移動する熱量を正と定める．
全エネルギーは保存されるため，各系のエネルギー変化は

```math
dE_1=-d'Q,\qquad dE_2=d'Q
\tag{5}
```

となる．

合成系全体のエントロピーは，各部分系のエントロピーの和であるから，その微小変化は

```math
dS_{1+2}=dS_1+dS_2
\tag{6}
```

と表される．
式 (3) の温度の定義を用いると，

```math
dS_1=\frac{dE_1}{T_1},
\qquad
dS_2=\frac{dE_2}{T_2}
```

である．
これらに式 (5) を代入すると，

```math
\begin{aligned}
dS_{1+2}
&=\frac{-d'Q}{T_1}+\frac{d'Q}{T_2}\\
&=d'Q\left(\frac{1}{T_2}-\frac{1}{T_1}\right)
\end{aligned}
```

となる．
したがって，

```math
\boxed{
dS_{1+2}=d'Q\left(T_2^{-1}-T_1^{-1}\right)
}
\tag{7}
```

である．

ここで， $T_1>T_2>0$ であるから，

```math
\frac{1}{T_2}-\frac{1}{T_1}>0
```

が成り立つ．
したがって， $d'Q>0$ ，すなわち熱が系1から系2へ移動するとき，合成系全体のエントロピーは増大する．
逆向きに熱が移動すればエントロピーは減少する．
よって，エントロピーが増大する方向は高温の系1から低温の系2への熱の移動である．
これにより，(i) が示された．

### (ii) 熱平衡状態におけるエントロピーの加法性

#### 1．合成系の状態数

系1と系2を熱的に接触させた合成系を考え，全エネルギーを一定値 $E$ とする．
系1のエネルギーが $E_1$ ならば，系2のエネルギーはエネルギー保存則より

```math
E_2=E-E_1
\tag{8}
```

である．

系1がエネルギー $E_1$ をもつ微視状態の数が $\Omega_1(E_1)$ ，系2がエネルギー $E-E_1$ をもつ微視状態の数が $\Omega_2(E-E_1)$ である．
二つの系は独立であるから，そのような組合せの状態数は積

```math
\Omega_1(E_1)\Omega_2(E-E_1)
```

となる．
系1のエネルギー $E_1$ をさまざまに変化させて，すべての場合を数え上げると，合成系の状態数は

```math
W(E)=\int
\Omega_1(E_1)\Omega_2(E-E_1)\,dE_1
\tag{9}
```

で与えられる．
ここでは，エネルギーが微小な幅をもつ区間ごとに数え上げる連続近似を用いている．

式 (1) を用い，指数関数の肩にある関数を

```math
f(E_1)=
N_1\phi_1\left(\frac{E_1}{N_1}\right)
+
N_2\phi_2\left(\frac{E-E_1}{N_2}\right)
\tag{10}
```

と定義すると，状態数の主要な寄与は

```math
W(E)\sim\int e^{f(E_1)}\,dE_1
\tag{11}
```

で表される．
粒子数が非常に大きい場合，積分への寄与は $f(E_1)$ が最大となるエネルギーの近傍に集中する．
この最大値を与える系1，系2のエネルギーをそれぞれ $E_1^*$ ， $E_2^*$ とする．
これらは，全エネルギー保存の条件

```math
E_1^*+E_2^*=E
\tag{12}
```

を満たす．

#### 2．最大条件と熱平衡条件

まず，式 (10) を $E_1$ で微分する．
式 (8) より， $E_2=E-E_1$ であるから，

```math
f'(E_1)=
\phi_1'\left(\frac{E_1}{N_1}\right)
-
\phi_2'\left(\frac{E_2}{N_2}\right)
\tag{13}
```

となる．
最大値を与える点では $f'(E_1^*)=0$ であるため，

```math
\phi_1'\left(\frac{E_1^*}{N_1}\right)
=
\phi_2'\left(\frac{E_2^*}{N_2}\right)
\tag{14}
```

が成り立つ．
式 (4) より，これは

```math
\boxed{
T_1=T_2
}
\tag{15}
```

を意味する．
すなわち，エネルギーが最も多くの状態を生み出すように分配された状態が熱平衡状態である．

#### 3．最大値の近傍でのガウス近似

安定な熱平衡状態では， $f(E_1)$ は $E_1^*$ で極大となるため，

```math
f''(E_1^*)<0
```

である．
そこで， $E_1^*$ の近傍で $f(E_1)$ をテイラー展開すると，1次の項は消え，

```math
f(E_1)\simeq
f(E_1^*)+
\frac12 f''(E_1^*)(E_1-E_1^*)^2
\tag{16}
```

となる．
ここで，

```math
\Delta^2=-\frac{1}{f''(E_1^*)}>0
\tag{17}
```

とおけば，式 (16) は

```math
e^{f(E_1)}
\simeq e^{f(E_1^*)}
\exp\left\{-\frac{(E_1-E_1^*)^2}{2\Delta^2}\right\}
\tag{18}
```

と書ける．

これを式 (11) に代入し，最大値の近傍で積分すると，

```math
\begin{aligned}
W(E)
&\sim e^{f(E_1^*)}
\int_{-\infty}^{\infty}
\exp\left\{-\frac{(E_1-E_1^*)^2}{2\Delta^2}\right\}
dE_1\\
&=e^{f(E_1^*)}\sqrt{2\pi\Delta^2}
\end{aligned}
\tag{19}
```

となる．
積分範囲を無限区間に置き換えたのは，粒子数が大きいとき，主要な寄与が極大点の十分近くに集中するためである．
また，状態数に含まれる指数関数以外の緩やかな変化をする因子は，極大点での値に近似できる．
これらの因子はエントロピーの主要項には影響しない．

式 (19) の対数を取ると，

```math
\log W(E)\simeq
f(E_1^*)+\frac12\log(2\pi\Delta^2)
\tag{20}
```

となる．
粒子数が $N$ のオーダーで大きいとき， $\Delta^2$ は $N$ のオーダーとなるため，

```math
\log(2\pi\Delta^2)=O(\log N)
```

である．
一方， $f(E_1^*)$ は $O(N)$ のオーダーである．
したがって，熱力学的極限では，対数の第2項は主要項に比べて無視できる．

よって，合成系のエントロピーは，

```math
\begin{aligned}
S_{1+2}(E)
&=k\log W(E)\\
&\simeq kf(E_1^*)\\
&=kN_1\phi_1\left(\frac{E_1^*}{N_1}\right)
+kN_2\phi_2\left(\frac{E_2^*}{N_2}\right)
\end{aligned}
\tag{21}
```

となる．
式 (2) を用いれば，

```math
\boxed{
S_{1+2}(E)\simeq
S_1(E_1^*)+S_2(E_2^*)
}
\tag{22}
```

を得る．
したがって，熱平衡状態では，合成系のエントロピーは部分系のエントロピーの和に等しい．
ここでの等号は，粒子数が十分に大きい熱力学的極限において，エントロピーの主要項が一致するという意味である．

### (iii) 熱平衡状態におけるエネルギーのゆらぎ

#### 1．エネルギーの確率分布

合成系の全エネルギー $E$ を固定すると，系1のエネルギーが $E_1$ となる確率は，そのエネルギー分配に対応する状態数に比例する．
したがって，

```math
P(E_1)\propto
\Omega_1(E_1)\Omega_2(E-E_1)
\tag{23}
```

である．
式 (11)，(18) より，熱平衡状態の $E_1^*$ の近傍では，

```math
P(E_1)\propto
\exp\left\{-\frac{(E_1-E_1^*)^2}{2\Delta^2}\right\}
\tag{24}
```

となる．
規格化すれば，

```math
P(E_1)=
\frac{1}{\sqrt{2\pi\Delta^2}}
\exp\left\{-\frac{(E_1-E_1^*)^2}{2\Delta^2}\right\}
\tag{25}
```

というガウス分布で近似できる．

平均値が $E_1^*$ であるガウス分布の分散は $\Delta^2$ であるから，

```math
\boxed{
\overline{(E_1-E_1^*)^2}=\Delta^2
}
\tag{26}
```

となる．
また，全エネルギーが一定であるため，

```math
E_2-E_2^*=-(E_1-E_1^*)
```

であり，その二乗は両系で等しい．
したがって，

```math
\boxed{
\overline{(E_2-E_2^*)^2}=\Delta^2
}
\tag{27}
```

も成り立つ．
残るのは， $\Delta^2$ を熱容量で表すことである．

#### 2．ガウス分布の幅と熱容量の関係

式 (10) を2回微分すると，

```math
f''(E_1)=
\frac{1}{N_1}\phi_1''\left(\frac{E_1}{N_1}\right)
+
\frac{1}{N_2}\phi_2''\left(\frac{E_2}{N_2}\right)
\tag{28}
```

となる．
よって，式 (17) より，

```math
\Delta^2=
-\left[
\frac{1}{N_1}\phi_1''\left(\frac{E_1^*}{N_1}\right)
+
\frac{1}{N_2}\phi_2''\left(\frac{E_2^*}{N_2}\right)
\right]^{-1}
\tag{29}
```

である．

次に，各部分系 $i$ について，式 (4) の関係

```math
\frac{1}{T_i}
=k\phi_i'\left(\frac{E_i}{N_i}\right)
\tag{30}
```

をエネルギー $E_i$ で微分する．
左辺については，

```math
\frac{d}{dE_i}\left(\frac{1}{T_i}\right)
=-\frac{1}{T_i^2}\frac{dT_i}{dE_i}
\tag{31}
```

となる．
熱容量を

```math
C_i=\left(\frac{\partial E_i}{\partial T_i}\right)_{N_i}
\tag{32}
```

と定義すれば，

```math
\frac{dT_i}{dE_i}=\frac{1}{C_i}
```

である．
一方，式 (30) の右辺を微分すると，

```math
\frac{d}{dE_i}
\left[
k\phi_i'\left(\frac{E_i}{N_i}\right)
\right]
=\frac{k}{N_i}\phi_i''\left(\frac{E_i}{N_i}\right)
\tag{33}
```

となる．
したがって，

```math
-\frac{1}{T_i^2 C_i}
=\frac{k}{N_i}\phi_i''\left(\frac{E_i}{N_i}\right)
```

であり，

```math
\boxed{
\frac{1}{N_i}\phi_i''\left(\frac{E_i}{N_i}\right)
=-\frac{1}{kT_i^2 C_i}
}
\tag{34}
```

を得る．

熱平衡状態では $T_1=T_2=T$ であるため，式 (34) を式 (29) に代入すると，

```math
\begin{aligned}
\Delta^2
&=-\left[
-\frac{1}{kT^2C_1}
-\frac{1}{kT^2C_2}
\right]^{-1}\\
&=\left[
\frac{1}{kT^2}
\left(\frac{1}{C_1}+\frac{1}{C_2}\right)
\right]^{-1}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\Delta^2=
\frac{kT^2}{C_1^{-1}+C_2^{-1}}
}
\tag{35}
```

が得られる．

式 (26)，(27)，(35) を合わせると，

```math
\boxed{
\overline{(E_1-E_1^*)^2}
=
\overline{(E_2-E_2^*)^2}
=
\frac{kT^2}{C_1^{-1}+C_2^{-1}}
}
\tag{36}
```

となる．
これが求めるエネルギーゆらぎの式である．

### 結論

(i) 高温の系1から低温の系2へ微小な熱量 $d'Q$ が移動すると，合成系のエントロピーは

```math
dS_{1+2}=d'Q(T_2^{-1}-T_1^{-1})>0
```

だけ増加する．

(ii) 熱平衡状態では，熱力学的極限において合成系のエントロピーは部分系のエントロピーの和となり，

```math
S_{1+2}\simeq S_1(E_1^*)+S_2(E_2^*)
```

が成立する．

(iii) 両系のエネルギーゆらぎは等しく，その二乗平均は

```math
\overline{(E_1-E_1^*)^2}
=
\overline{(E_2-E_2^*)^2}
=
\frac{kT^2}{C_1^{-1}+C_2^{-1}}
```

で与えられる．
以上により，3つの主張が示された．
