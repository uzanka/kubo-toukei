# 演習問題【5-R-5】

## 解答

### (i) 熱の流れとエントロピーの変化について

まず，エントロピー $S$ と状態数 $\Omega$ の関係を整理する．
統計力学において，エントロピーはボルツマン定数 $k$ を用いて次のように定義される：

$$S = k \log \Omega$$

問題文の条件より，状態数は $\Omega(E) \sim \exp\{N \phi(E/N)\}$ という形をしている．
これをエントロピーの式に代入すると，

$$S(E) = k \log \left( \exp\{N \phi(E/N)\} \right) = k N \phi(E/N)$$

となる．
ここで， $N$ は粒子数， $E$ はエネルギーである．

次に，温度 $T$ とエントロピーの関係を考える．
熱力学における温度の定義の一つに， $\frac{1}{T} = \frac{dS}{dE}$ がある．
この問題の設定に基づくと，

$$\frac{dS}{dE} = k N \cdot \frac{d}{dE} \phi(E/N) = k N \cdot \phi'(E/N) \cdot \frac{1}{N} = k \phi'(E/N)$$

となる．
したがって，温度 $T$ は $T^{-1} = k \phi'(E/N)$ と表される．

ここで，系１から系２へ熱 $dQ$ が移動した状況を考える．
このとき，各系のエネルギーの変化は以下のようになる：
- 系１のエネルギーの変化： $dE_1 = -dQ$
- 系２のエネルギーの変化： $dE_2 = dQ$

合成系全体のエネルギーは一定であるが，エントロピーは変化する．
全エントロピーの変化 $dS_{1+2}$ は，それぞれの系のエントロピー変化の和として書ける：

$$dS_{1+2} = dS_1 + dS_2$$

$$dS_{1+2} = \frac{dS_1}{dE_1} dE_1 + \frac{dS_2}{dE_2} dE_2$$

$$dS_{1+2} = \frac{1}{T_1} (-dQ) + \frac{1}{T_2} (dQ) = (T_2^{-1} - T_1^{-1}) dQ$$

となる．

問題の条件 $T_1 > T_2$ より， $T_1^{-1} < T_2^{-1}$ である．
したがって， $T_2^{-1} - T_1^{-1} > 0$ となる．
熱が１から２へ流れるとき ( $dQ > 0$ )，エントロピーの変化 $dS_{1+2}$ は正の値をとる．
これはエントロピーが増大することを意味しており，熱が温度の高い方から低い方へ流れる自然な現象と一致する．
以上より，示された．

### (ii) エントロピーの加法性について

合成系１＋２の全状態数 $W(E)$ は，各系の状態数の積を全エネルギー $E$ の範囲で積分することで求められる：

$$W(E) = \int \Omega_1(E_1) \Omega_2(E - E_1) dE_1$$

指数関数の性質を利用すると，これは次のように書ける：

$$W(E) = \int \exp\{N_1 \phi_1(E_1/N_1) + N_2 \phi_2(E_2/N_2)\} dE_1$$

ここで， $N_1, N_2$ は非常に大きな値であるため，指数関数の肩にある関数 $f(E_1) = N_1 \phi_1(E_1/N_1) + N_2 \phi_2(E_2/N_2)$ は，$E_1 + E_2 = E$ という制約の下で極めて鋭いピークを持つ．

このピークの位置を $E_1^{\ast}, E_2^{\ast}$ （すなわち $f(E_1)$ が最大となる点）とすると，ピークの近傍で $f(E_1)$ をテイラー展開（近似）することができる：

```math
f(E_1) \approx f(E_1^*) + \frac{1}{2} f''(E_1^*) (E_1 - E_1^*)^2
```

ここで，$f''(E_1^*)$ は負の値をとる．
これを指数関数の式に戻すと，

```math
\exp\{f(E_1)\} \approx \exp\{f(E_1^*)\} \cdot \exp\left\{ \frac{1}{2} f''(E_1^*) (E_1 - E_1^*)^2 \right\}
```

となる．
これを $W(E)$ の積分式に代入すると，

```math
W(E) \approx \exp\{f(E_1^*)\} \int \exp\left\{ \frac{1}{2} f''(E_1^*) (E_1 - E_1^*)^2 \right\} dE_1
```

となる．
この積分はガウス積分（正規分布の積分）の形をしており，積分を実行すると $\exp\{f(E_1^*)\}$ に定数倍（ガウス積分の結果）がかかった形になる．

エントロピー $S_{1+2}$ は $k \log W(E)$ であるから，

$$S_{1+2} = k \log \left( (\text{定数}) \cdot \exp\{f(E_1^*)\} \right)$$

$$S_{1+2} = k f(E_1^*) + k \log(\text{定数})$$

ここで，粒子数 $N \to \infty$ の極限では，$k f(E_1^*)$ は $O(N)$ のオーダーで増大するのに対し，$k \log(\text{定数})$ は $O(\log N)$ のオーダーにしかならない．
したがって，非常に大きな $N$ に対しては定数項は無視できる．

よって，

```math
S_{1+2} \approx k f(E_1^*) = k N_1 \phi_1(E_1^*/N_1) + k N_2 \phi_2(E_2^*/N_2)
```

```math
S_{1+2} = S_1(E_1^*) + S_2(E_2^*)
```

となり，熱平衡状態における合成系のエントロピーは部分系のエントロピーの和に等しいことが示された．

### (iii) エネルギーのゆらぎについて

熱平衡状態におけるエネルギーのゆらぎを求めるために，系１のエネルギー $E_1$ がある値をとる確率 $P(E_1)$ を考える．
これは全状態数に対する，その状態の割合として表される：

$$P(E_1) \propto \Omega_1(E_1) \Omega_2(E - E_1)$$

(ii) の議論と同様に，この確率は $E_1^*$ の周りでガウス分布（正規分布）に従う．

$$P(E_1) \propto \exp\left[ -\frac{(E_1 - E_1^*)^2}{2\Delta^2} \right]$$

ここで $\Delta^2$ は確率分布の分散であり，これがエネルギーのゆらぎ $\overline{(E_1 - E_1^*)^2}$ に相当する．

ガウス分布の形から， $\frac{1}{2\Delta^2}$ は指数の肩にある関数の２階微分 $\left( -\frac{1}{2} f''(E_1^*) \right)$ に等しい．

$$f(E_1) = N_1 \phi_1(E_1/N_1) + N_2 \phi_2((E-E_1)/N_2)$$

を $E_1$ で微分すると，

$$f'(E_1) = \phi'_1(E_1/N_1) - \phi'_2(E_2/N_2)$$

さらに $E_1$ でもう一度微分すると，

$$f''(E_1) = \frac{1}{N_1} \phi''_1(E_1/N_1) + \frac{1}{N_2} \phi''_2(E_2/N_2)$$

となる．
したがって，

```math
\frac{1}{2\Delta^2} = -\frac{1}{2} \left[ \frac{1}{N_1} \phi''_1(E_1^*/N_1) + \frac{1}{N_2} \phi''_2(E_2^*/N_2) \right]
```

```math
\Delta^2 = - \left[ \frac{1}{N_1} \phi''_1(E_1^*/N_1) + \frac{1}{N_2} \phi''_2(E_2^*/N_2) \right]^{-1}
```

が得られる．

ここで，熱容量 $C$ と温度 $T$ の関係を用いる．
$\frac{1}{T} = k \phi'(E/N)$ の両辺を $E$ で微分すると，

$$\frac{d}{dE} \left( \frac{1}{T} \right) = k \frac{d}{dE} \phi'(E/N) = k \cdot \frac{1}{N} \phi''(E/N)$$

左辺は， $\frac{d}{dE} (T^{-1}) = -T^{-2} \frac{dT}{dE}$ である．
熱容量の定義 $C = \frac{dE}{dT}$ より， $\frac{dT}{dE} = \frac{1}{C}$ であるから，

$$-\frac{1}{T^2 C} = \frac{k}{N} \phi''(E/N)$$

これより， $\frac{1}{N} \phi''(E/N) = -\frac{1}{k T^2 C}$ となる．

これを $\Delta^2$ の式に代入すると，熱平衡状態（ $T_1 = T_2 = T$ ）において，

$$\Delta^2 = - \left[ -\frac{1}{k T^2 C_1} - \frac{1}{k T^2 C_2} \right]^{-1}$$

$$\Delta^2 = \left[ \frac{1}{k T^2} \left( \frac{1}{C_1} + \frac{1}{C_2} \right) \right]^{-1}$$

$$\Delta^2 = \frac{k T^2}{\frac{1}{C_1} + \frac{1}{C_2}}$$

あるいは，

$$\Delta^2 = \frac{k T^2 (C_1 C_2)}{C_1 + C_2}$$

と書ける．
したがって，ゆらぎの大きさは $\Delta^2 = \frac{k T^2}{C_1^{-1} + C_2^{-1}}$ と与えられ，示された．

## 解説

本問題は，統計力学の基礎的な概念である「エントロピー，温度，熱容量，およびエネルギーのゆらぎ」の関係を，数学的な展開を通して理解することを目的としている．

1.  **エントロピーと温度の関係**：
    エントロピーが増大する方向にエネルギーが移動するという熱力学第二法則は，統計力学的には「より状態数が多い（確率が高い）状態へ移る」という現象として理解される．
    温度とは，エネルギーが変化したときにエントロピーがどれだけ変化するかという指標（の逆数）である．
2.  **巨大な $N$ の役割**：
    統計力学の計算において，粒子数 $N$ が非常に大きいことは極めて重要である．
    $N$ が大きいことで，確率分布のピークが非常に鋭くなり，ピーク以外の領域の寄与を無視できるようになる（これがガウス近似の根拠である）．
    これにより，複雑な積分計算が単純な代数計算に置き換わる．
3.  **ゆらぎと熱容量**：
    エネルギーのゆらぎは，熱平衡状態であっても系が一定のエネルギーに留まっているわけではなく，微小な範囲でエネルギーが変動していることを示している．
    このゆらぎの大きさ $\Delta^2$ が，熱容量 $C$ に比例（正確には $C$ が大きいほどゆらぎも大きい）することは，熱容量が大きい系ほどエネルギーを吸収しても温度が上がりにくく，エネルギーの状態を安定して保持できるという物理的直感と一致している．
