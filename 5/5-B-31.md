# 演習問題【5-B-31】

## 解答

### (i) 熱力学的重率 $W\{N_j\}$ の導出

系の状態の総数（熱力学的重率） $W\{N_j\}$ は，各エネルギーグループ $j$ における状態の数の積として与えられる．

#### (a) ボース・アインシュタイン（B.E.）統計

B.E. 統計では，粒子は区別できず，かつ一つの量子状態に複数の粒子が入ることを許す．
エネルギーグループ $j$ における $C_j$ 個の量子状態に， $N_j$ 個の粒子を分配する方法を考える．
これは，「 $N_j$ 個の区別できない球を， $C_j$ 個の区別できる箱に入れる方法の数」という組合せ問題に帰着する．
この場合の組み合わせの数は，いわゆる「重複組合せ」の公式を用いて，

$$\frac{(N_j + C_j - 1)!}{N_j! (C_j - 1)!}$$

と与えられる．
全系の状態数は，すべてのグループ $j$ についてこれらを掛け合わせたものであるから，

$$W\{N_j\} = \prod_j \frac{(N_j + C_j - 1)!}{N_j! (C_j - 1)!}$$

が得られる．

#### (b) フェルミ・ディラック（F.D.）統計

F.D. 統計では，粒子は区別できず，かつ一つの量子状態には高々1個の粒子しか入ることができない（パウリの排他原理）．
エネルギーグループ $j$ における $C_j$ 個の量子状態から， $N_j$ 個の粒子が入る状態を $N_j$ 個選ぶ方法の数を考える．
これは，「 $C_j$ 個のものから $N_j$ 個を選ぶ組合せ」そのものである．
この場合の組み合わせの数は，

$$\frac{C_j!}{N_j! (C_j - N_j)!}$$

である．
したがって，全系の状態数は，

$$W\{N_j\} = \prod_j \frac{C_j!}{N_j! (C_j - N_j)!}$$

となる．

### (ii) カノニカル分布における最も確からしい分配

全系が温度 $T$ の熱浴と接しているとき，分配 $\{N_j\}$ を持つ系の実現確率は，そのエネルギー $E = \sum_j \varepsilon_j N_j$ を用いて，

$$P(\{N_j\}) \propto W\{N_j\} \exp(-\beta \sum_j \varepsilon_j N_j)$$

（ここで $\beta = 1/kT$ ）と書ける．
最も確からしい分配 $\{N_j^*\}$ を求めることは，この確率 $P(\{N_j\})$ を最大化すること，すなわち $\ln P(\{N_j\})$ を最大化することと等価である．

ここで， $\ln P(\{N_j\})$ は次のように書ける：

$$\ln P(\{N_j\}) = \ln W\{N_j\} - \beta \sum_j \varepsilon_j N_j + (\text{定数})$$

熱力学的な関係式 $F = E - TS = E - \frac{1}{\beta} \ln W$ を用いると，これは

$$\ln P(\{N_j\}) = -\beta (E - \frac{1}{\beta} \ln W) + \text{const.} = -\beta F + \text{const.}$$

となる．
したがって，確率を最大化することは，ヘルムホルツの自由エネルギー $F$ を最小化することに対応する．

#### 自由エネルギー $F$ の近似

$N_j$ および $C_j$ が十分に大きいとして，スターリングの公式 $\ln n! \approx n \ln n - n$ を用いて $\ln W\{N_j\}$ を近似する．

**B.E. の場合：**

$$\ln W\{N_j\} = \sum_j [ (N_j + C_j - 1) \ln(N_j + C_j - 1) - N_j \ln N_j - (C_j - 1) \ln(C_j - 1) ]$$

$C_j, N_j \gg 1$ より，

$$\ln W\{N_j\} \approx \sum_j [ (N_j + C_j) \ln(N_j + C_j) - N_j \ln N_j - C_j \ln C_j ]$$

これより， $F/kT = \beta E - \ln W$ は，

$$\frac{F}{kT} \approx \beta \sum_j \varepsilon_j N_j - \sum_j [ (N_j + C_j) \ln(N_j + C_j) - N_j \ln N_j - C_j \ln C_j ]$$

となる．

**F.D. の場合：**

$$\ln W\{N_j\} \approx \sum_j [ C_j \ln C_j - N_j \ln N_j - (C_j - N_j) \ln(C_j - N_j) ]$$

これより， $F/kT$ は，

$$\frac{F}{kT} \approx \beta \sum_j \varepsilon_j N_j - \sum_j [ C_j \ln C_j - N_j \ln N_j - (C_j - N_j) \ln(C_j - N_j) ]$$

$$= \beta \sum_j \varepsilon_j N_j + \sum_j [ -(C_j - N_j) \ln(C_j - N_j) - N_j \ln N_j + C_j \ln C_j ]$$

となる．

#### 変分法による最大化

粒子数一定の条件 $\sum_j N_j = N$ の下で， $F$ を最小にする $\{N_j\}$ を求めるために，ラグランジュの未定係数法を用いる．
制約条件 $\sum_j \delta N_j = 0$ に対する未定係数を $-\mu/kT$ とすると，次の変分が $0$ になる必要がある：

$$\frac{\delta (F - \mu N)}{kT} = 0$$

各統計における変分 $\frac{\delta F}{kT}$ を計算すると，

$$\frac{\delta F}{kT} = \sum_j \left[ \beta \varepsilon_j + \ln \frac{N_j}{C_j \pm N_j} \right] \delta N_j$$

（ここで $\pm$ は B.E. では $+$, F.D. では $-$ を表す）
これにラグランジュの条件を加えると，

$$\sum_j \left[ \beta (\varepsilon_j - \mu) + \ln \frac{N_j}{C_j \pm N_j} \right] \delta N_j = 0$$

これが任意の $\delta N_j$ に対して成り立つためには，括弧内が $0$ でなければならない．

$$\ln \frac{N_j}{C_j \pm N_j} = -\beta (\varepsilon_j - \mu)$$

$$\frac{N_j}{C_j \pm N_j} = e^{-\beta (\varepsilon_j - \mu)}$$

これを $N_j$ について解くと，

$$\frac{N_j}{C_j} = \frac{e^{-\beta (\varepsilon_j - \mu)}}{1 \mp e^{-\beta (\varepsilon_j - \mu)}} = \frac{1}{e^{\beta (\varepsilon_j - \mu)} \mp 1}$$

が得られる．
これが求める分布である．
また，全粒子数 $N$ については，

$$N = \sum_j N_j = \sum_j \frac{C_j}{e^{\beta (\varepsilon_j - \mu)} \mp 1}$$

となり，これにより $\mu$ が定まる．

### (iii) ミクロカノニカル分布における結果

ミクロカノニカル分布では，全系のエネルギー $E = \sum_j \varepsilon_j N_j$ と全粒子数 $N = \sum_j N_j$ が一定である．
この条件下では，確率 $P(\{N_j\})$ を最大化することは，重率 $W\{N_j\}$ を最大化することに他ならない．

ラグランジュの未定係数 $\alpha$ と $\beta'$ を用いて，次の関数を最大化する．

$$\Phi = \ln W\{N_j\} - \alpha \sum_j N_j - \beta' \sum_j \varepsilon_j N_j$$

変分 $\delta \Phi = 0$ を考えると，

$$\delta \ln W - \alpha \sum_j \delta N_j - \beta' \sum_j \varepsilon_j \delta N_j = 0$$

ここで， $\delta \ln W = \sum_j \delta N_j \ln \left[ \frac{C_j \pm N_j}{N_j} \right]$ であるから，

$$\sum_j \left[ \ln \left( \frac{C_j \pm N_j}{N_j} \right) - \alpha - \beta' \varepsilon_j \right] \delta N_j = 0$$

括弧内を $0$ と置くと，

$$\ln \frac{C_j \pm N_j}{N_j} = \alpha + \beta' \varepsilon_j$$

$$\frac{C_j \pm N_j}{N_j} = e^{\alpha + \beta' \varepsilon_j}$$

$$\frac{N_j}{C_j \pm N_j} = e^{-(\alpha + \beta' \varepsilon_j)}$$

ここで， $\alpha = -\beta \mu$ および $\beta' = -\beta$ と置き換えることで，(ii) で得られた結果と全く同じ形式が得られる．
すなわち，

$$\frac{N_j}{C_j} = \frac{1}{e^{\beta (\varepsilon_j - \mu)} \mp 1}$$

となる．
この場合，未定係数 $\beta$ と $\mu$ は，

$$N = \sum_j \frac{C_j}{e^{\beta (\varepsilon_j - \mu)} \mp 1}$$

$$E = \sum_j \frac{C_j \varepsilon_j}{e^{\beta (\varepsilon_j - \mu)} \mp 1}$$

という 2 つの条件式によって決定される．
