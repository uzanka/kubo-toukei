# 演習問題【5-B-31】

## 解答

### (i) 熱力学的重率 $W\{N_j\}$ の導出

エネルギーがほぼ等しい量子状態をまとめた第 $j$ グループについて，エネルギーを $\varepsilon_j$ ，量子状態の数を $C_j$ ，そのグループに属する粒子数を $N_j$ とする．
全系の粒子数は

```math
\sum_j N_j=N
```

である．
熱力学的重率 $W\{N_j\}$ とは，粒子数の分配 $\{N_j\}$ を実現する微視的状態の総数である．
各グループにおける状態の選び方は互いに独立なので，全系の重率は各グループの状態数を掛け合わせることで求められる．

#### (a) ボース・アインシュタイン統計

ボース・アインシュタイン統計では，同じ量子状態に複数の粒子が入ることが許される．
第 $j$ グループには $C_j$ 個の量子状態があり，そこに $N_j$ 個の粒子を分配する方法の数を求めればよい．

これは，区別できない $N_j$ 個の粒子を，区別できる $C_j$ 個の量子状態に分配する問題である．
各状態に入る粒子数を $n_1,\ldots,n_{C_j}$ とすれば，

```math
n_1+n_2+\cdots+n_{C_j}=N_j,
\qquad n_a\geq 0
```

を満たす整数の組の数に等しい．
この組合せの数は，重複組合せの公式より，

```math
\frac{(N_j+C_j-1)!}{N_j!(C_j-1)!}
```

である．
したがって，すべてのグループについて掛け合わせると，

```math
\boxed{
W\{N_j\}
=\prod_j
\frac{(N_j+C_j-1)!}{N_j!(C_j-1)!}
}
\qquad \text{(B.E.)}
```

となる．

#### (b) フェルミ・ディラック統計

フェルミ・ディラック統計では，パウリの排他原理により，一つの量子状態に入る粒子は高々1個である．
したがって，第 $j$ グループの $C_j$ 個の量子状態から，粒子が入る $N_j$ 個の状態を選ぶ必要がある．

その選び方は組合せの数

```math
\binom{C_j}{N_j}
=\frac{C_j!}{N_j!(C_j-N_j)!}
```

で与えられる．
よって，全系の熱力学的重率は，

```math
\boxed{
W\{N_j\}
=\prod_j
\frac{C_j!}{N_j!(C_j-N_j)!}
}
\qquad \text{(F.D.)}
```

である．
この場合には， $0\leq N_j\leq C_j$ が必要である．

### (ii) カノニカル分布から最も確からしい分配を求める

全系が温度 $T$ の熱浴に接しているとする．
逆温度を

```math
\beta=\frac{1}{kT}
```

とおく．
分配 $\{N_j\}$ の全エネルギーは，

```math
E=\sum_j\varepsilon_jN_j
```

である．
カノニカル分布では，エネルギーが $E$ の微視的状態の確率は Boltzmann 因子 $e^{-\beta E}$ に比例する．
分配 $\{N_j\}$ を実現する微視的状態は $W\{N_j\}$ 個あるため，その分配の実現確率は，

```math
P(\{N_j\})
\propto W\{N_j\}
\exp\left(-\beta\sum_j\varepsilon_jN_j\right)
\tag{1}
```

である．

したがって，最も確からしい分配 $\{N_j^*\}$ を求めるには，式 (1) の右辺を最大にすればよい．
対数関数は単調増加なので，その対数を最大にしても同じ分配が得られる．
すなわち，

```math
\ln P(\{N_j\})
=\ln W\{N_j\}
-\beta\sum_j\varepsilon_jN_j
+\text{定数}
```

を最大化すればよい．

#### 1．Stirling の公式による近似

重率には階乗が含まれるため，そのままでは変分を計算しにくい．
そこで， $N_j$ ， $C_j$ ，および必要な場合には $C_j-N_j$ が十分大きいと仮定し，Stirling の公式

```math
\ln n!\simeq n\ln n-n
```

を用いる．

以下では，変分計算において $N_j$ を連続変数のように扱う．
これは，粒子数が十分大きい場合の近似である．

**ボース・アインシュタイン統計の場合**

(i) で求めた重率の対数を近似すると，

```math
\begin{aligned}
\ln W
&\simeq \sum_j\bigl[
(N_j+C_j)\ln(N_j+C_j)\\
&\qquad -N_j\ln N_j-C_j\ln C_j
\bigr]
\end{aligned}
\tag{2}
```

となる．

**フェルミ・ディラック統計の場合**

同様に，

```math
\begin{aligned}
\ln W
\simeq \sum_j\bigl[
&C_j\ln C_j-N_j\ln N_j\\
&-(C_j-N_j)\ln(C_j-N_j)
\bigr]
\end{aligned}
\tag{3}
```

を得る．

ここで，確率の最大化に相当する量を

```math
F_{\mathrm{eff}}
=E-kT\ln W
```

と定義する．
式 (1) より，

```math
\ln P=-\beta F_{\mathrm{eff}}+\text{定数}
```

であるため， $P$ を最大にすることは $F_{\mathrm{eff}}$ を最小にすることと等価である．
ここで $F_{\mathrm{eff}}$ は，分配ごとの重率を考慮した自由エネルギーに相当する量である．

#### 2．変分法による分配の決定

式 (2)，(3) を用いて $F_{\mathrm{eff}}/kT$ を計算し， $N_j$ について変分すると，

```math
\frac{\delta F_{\mathrm{eff}}}{kT}
=\sum_j\left[
\beta\varepsilon_j+
\ln\frac{N_j}{C_j\pm N_j}
\right]\delta N_j
\tag{4}
```

が得られる．
ここでは複号の上側が B.E. 統計，下側が F.D. 統計に対応する．
すなわち，B.E. では分母が $C_j+N_j$ ，F.D. では $C_j-N_j$ である．

全粒子数 $N$ は一定なので，

```math
\sum_jN_j=N,\qquad
\sum_j\delta N_j=0
\tag{5}
```

を満たす必要がある．
この制約条件を考慮するため，ラグランジュの未定係数 $\mu$ を導入し，

```math
F_{\mathrm{eff}}-\mu\sum_jN_j
```

を最小化する．
ここで $\mu$ は化学ポテンシャルに相当する量である．

式 (4) より，

```math
\begin{aligned}
0
&=\frac{\delta(F_{\mathrm{eff}}-\mu N)}{kT}\\
&=\sum_j\left[
\beta(\varepsilon_j-\mu)
+\ln\frac{N_j}{C_j\pm N_j}
\right]\delta N_j
\end{aligned}
\tag{6}
```

となる．
粒子数一定の条件をラグランジュの未定係数によって組み込んだため，式 (6) の変分 $\delta N_j$ は独立に扱える．
したがって，それぞれの $\delta N_j$ の係数がゼロでなければならない．
ゆえに，

```math
\beta(\varepsilon_j-\mu)
+\ln\frac{N_j}{C_j\pm N_j}=0
```

を得る．
整理すると，

```math
\frac{N_j}{C_j\pm N_j}
=e^{-\beta(\varepsilon_j-\mu)}
\tag{7}
```

である．

B.E. 統計では式 (7) の分母が $C_j+N_j$ なので，

```math
N_j e^{\beta(\varepsilon_j-\mu)}
=C_j+N_j
```

となる．
これを $N_j$ について解けば，

```math
\boxed{
\frac{N_j}{C_j}
=\frac{1}{e^{\beta(\varepsilon_j-\mu)}-1}
}
\qquad \text{(B.E.)}
\tag{8}
```

を得る．

一方，F.D. 統計では式 (7) の分母が $C_j-N_j$ なので，

```math
N_j e^{\beta(\varepsilon_j-\mu)}
=C_j-N_j
```

となる．
したがって，

```math
\boxed{
\frac{N_j}{C_j}
=\frac{1}{e^{\beta(\varepsilon_j-\mu)}+1}
}
\qquad \text{(F.D.)}
\tag{9}
```

である．

式 (8)，(9) は，それぞれボース・アインシュタイン分布とフェルミ・ディラック分布である．
ここで，

```math
\frac{N_j}{C_j}
```

は，エネルギー $\varepsilon_j$ を持つ一つの量子状態あたりの平均占有数を表す．
F.D. 統計では一つの状態の占有数が $0$ または $1$ なので，この平均占有数は，その状態が占有される確率にも一致する．
B.E. 統計では，同じ状態に複数の粒子が入ることができるため，式 (8) は平均占有数を表す．

未定係数 $\mu$ は，全粒子数の条件

```math
\boxed{
N=\sum_j
\frac{C_j}{e^{\beta(\varepsilon_j-\mu)}\mp1}
}
\tag{10}
```

によって定まる．
この式の分母は，B.E. 統計では $e^{\beta(\varepsilon_j-\mu)}-1$ ，F.D. 統計では $e^{\beta(\varepsilon_j-\mu)}+1$ である．

### (iii) ミクロカノニカル分布から同じ結果を導く

ミクロカノニカル分布では，全系のエネルギー $E$ と全粒子数 $N$ が一定である．
この条件の下では，許される微視的状態は等しい確率で実現する．
したがって，分配 $\{N_j\}$ の実現確率は，その重率 $W\{N_j\}$ に比例する．

よって，最も確からしい分配は，制約条件

```math
\sum_j\varepsilon_jN_j=E,\qquad
\sum_jN_j=N
\tag{11}
```

の下で $\ln W\{N_j\}$ を最大にする分配である．
ここでも， $N_j$ や $C_j$ が十分大きいとし，Stirling の公式による近似を用いる．

(i) の重率を変分すると，B.E. 統計では

```math
\frac{\partial\ln W}{\partial N_j}
=\ln\frac{C_j+N_j}{N_j}
```

となり，F.D. 統計では

```math
\frac{\partial\ln W}{\partial N_j}
=\ln\frac{C_j-N_j}{N_j}
```

となる．
これらをまとめると，

```math
\delta\ln W
=\sum_j\ln\frac{C_j\pm N_j}{N_j}\,\delta N_j
\tag{12}
```

である．
複号の上側は B.E. 統計，下側は F.D. 統計に対応する．

式 (11) の二つの制約条件を満たすため，ラグランジュの未定係数 $\beta$ と $\beta\mu$ を用いて，

```math
\Phi
=\ln W-\beta\sum_j\varepsilon_jN_j
+\beta\mu\sum_jN_j
\tag{13}
```

を最大化する．
ここでの $\beta$ と $\mu$ は，制約条件を取り入れるための未定係数として導入するものである．

式 (12)，(13) より，

```math
\begin{aligned}
\delta\Phi
=\sum_j\biggl[
&\ln\frac{C_j\pm N_j}{N_j}\\
&-\beta\varepsilon_j+\beta\mu
\biggr]\delta N_j
=0
\end{aligned}
\tag{14}
```

を得る．
未定係数を用いて制約条件を組み込んだため，各 $\delta N_j$ の係数をゼロとおくことができる．
よって，

```math
\ln\frac{C_j\pm N_j}{N_j}
=\beta(\varepsilon_j-\mu)
```

であり，

```math
\frac{N_j}{C_j\pm N_j}
=e^{-\beta(\varepsilon_j-\mu)}
\tag{15}
```

となる．
これは，カノニカル分布から得た式 (7) と同じである．
したがって，式 (15) を各統計に応じて解けば，

```math
\boxed{
\frac{N_j}{C_j}
=\frac{1}{e^{\beta(\varepsilon_j-\mu)}-1}
}
\qquad \text{(B.E.)}
```

および

```math
\boxed{
\frac{N_j}{C_j}
=\frac{1}{e^{\beta(\varepsilon_j-\mu)}+1}
}
\qquad \text{(F.D.)}
```

が得られる．

ミクロカノニカル分布の場合，未定係数 $\beta$ と $mu$ は，粒子数の条件に加え，エネルギーが一定であるという条件によって決まる．
具体的には，

```math
\boxed{
N=\sum_j
\frac{C_j}{e^{\beta(\varepsilon_j-\mu)}\mp1}
}
\tag{16}
```

および

```math
\boxed{
E=\sum_j
\frac{C_j\varepsilon_j}
{e^{\beta(\varepsilon_j-\mu)}\mp1}
}
\tag{17}
```

を同時に満たすように決定される．
ここでも，分母の複号は B.E. 統計ではマイナス，F.D. 統計ではプラスである．
熱力学的平衡においては， $\beta=1/(kT)$ と解釈される．

以上により，カノニカル分布とミクロカノニカル分布のどちらから出発しても，最も確からしい分配は同じ形式のボース・アインシュタイン分布およびフェルミ・ディラック分布に従うことが示された．
