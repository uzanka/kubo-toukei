# 例題【5-R-8】

## 解答

### 1．基本設定と適用条件

単原子分子 N 個からなる古典理想気体を考える．
分子の質量を m，ボルツマン定数を k，プランク定数を h，温度を T，体積を V，圧力を p とする．

また，

```math
\beta=\frac{1}{kT}
```

とおく．

以下では，分子間相互作用を無視し，分子は非相対論的に運動するものとする．
さらに，分子の内部自由度は考慮せず，三つの並進自由度のみを扱う．

古典統計力学を適用するためには，熱的ド・ブロイ波長

```math
\lambda_T=\frac{h}{\sqrt{2\pi mkT}}
```

を用いて，

```math
\frac NV\lambda_T^3\ll1
```

が成立することが必要である．
また，非相対論的近似の適用条件として，

```math
kT\ll mc^2
```

を仮定する．

ここで，容器は粒子を閉じ込める剛体壁を持ち，容器内には粒子間相互作用や外部ポテンシャルが存在しないものとする．

### 2．カノニカル分布による解析

#### 2.1 ハミルトニアン

単原子分子は三つの並進自由度を持つため，全粒子のハミルトニアンは

```math
\mathcal H
=
\sum_{i=1}^{N}
\frac{\boldsymbol p_i^2}{2m}
=
\sum_{i=1}^{3N}\frac{p_i^2}{2m}
```

である．

ここで， $\boldsymbol p_i$ は第 i 粒子の運動量ベクトルである．

#### 2.2 カノニカル分配関数

同種粒子の重複計数を除くと，古典カノニカル分配関数は

```math
Z(T,V,N)
=
\frac{1}{N!h^{3N}}
\int
e^{-\beta\mathcal H}
\,d\Gamma
```

となる．

位相空間の体積要素は

```math
d\Gamma
=
\prod_{i=1}^{N}
d^3r_i\,d^3p_i
```

である．

ハミルトニアンは位置座標に依存しないため，位置座標について積分すると，

```math
\int d^{3N}r=V^N
```

を得る．

一方，運動量についての積分は

```math
\begin{aligned}
\int_{-\infty}^{\infty}
e^{-\beta p^2/(2m)}\,dp
&=
\sqrt{\frac{2m}{\beta}}
\int_{-\infty}^{\infty}e^{-x^2}\,dx\\
&=
\sqrt{\frac{2\pi m}{\beta}}\\
&=
\sqrt{2\pi mkT}
\end{aligned}
```

となる．

したがって，

```math
Z(T,V,N)
=
\frac{V^N}{h^{3N}N!}
(2\pi mkT)^{3N/2}
```

である．

熱的ド・ブロイ波長

```math
\lambda_T=\frac{h}{\sqrt{2\pi mkT}}
```

を導入すると，

```math
\boxed{
Z(T,V,N)
=
\frac{1}{N!}
\left(\frac{V}{\lambda_T^3}\right)^N
}
\tag{1}
```

と書ける．

#### 2.3 ヘルムホルツ自由エネルギー

ヘルムホルツ自由エネルギーは

```math
F=-kT\ln Z
```

で定義される．

式 (1) より，

```math
F
=
-kT
\left[
N\ln\frac{V}{\lambda_T^3}
-\ln N!
\right]
```

となる．

粒子数が十分大きい場合には，Stirling の近似

```math
\ln N!\simeq N\ln N-N
```

を使用できる．

これを代入して整理すると，

```math
\boxed{
F\simeq
-NkT
\left[
\ln\left(
\frac{V}{N\lambda_T^3}
\right)+1
\right]
}
\tag{2}
```

を得る．

この近似は熱力学極限における主要な項を表している．

#### 2.4 状態方程式

ヘルムホルツ自由エネルギーから圧力を求めると，

```math
p=
-\left(\frac{\partial F}{\partial V}\right)_{T,N}
```

である．

式 (2) を微分すると，

```math
p=\frac{NkT}{V}
```

となる．

したがって，

```math
\boxed{
pV=NkT
}
\tag{3}
```

を得る．

これは理想気体の状態方程式である．

なお，Stirling 近似を使用していない厳密な有限粒子数の分配関数から計算しても，同じ状態方程式が得られる．

#### 2.5 エントロピー

エントロピーは，

```math
S=
-\left(\frac{\partial F}{\partial T}\right)_{V,N}
```

で定義される．

式 (2) より，

```math
\boxed{
S\simeq
Nk\left[
\ln\left(
\frac{V}{N\lambda_T^3}
\right)
+\frac52
\right]
}
\tag{4}
```

となる．

これは単原子分子理想気体の Sackur-Tetrode の式である．

ここで，対数の引数

```math
\frac{V}{N\lambda_T^3}
```

は無次元である．

#### 2.6 化学ポテンシャル

化学ポテンシャルは，

```math
\mu=
\left(\frac{\partial F}{\partial N}\right)_{T,V}
```

で定義される．

Stirling 近似を用いた式 (2) を N で微分すると，

```math
\boxed{
\mu=
kT\ln\left(
\frac{N\lambda_T^3}{V}
\right)
}
\tag{5}
```

となる．

数密度を

```math
n=\frac NV
```

とすれば，

```math
\boxed{
\mu=kT\ln(n\lambda_T^3)
}
\tag{6}
```

である．

この式は古典理想気体の化学ポテンシャルを表している．

なお，粒子数 N は離散変数であるため，この微分による定義は熱力学極限における連続変数近似である．

#### 2.7 内部エネルギーと比熱

内部エネルギーは，

```math
U
=
-T^2
\left(
\frac{\partial(F/T)}{\partial T}
\right)_{V,N}
```

から求められる．

式 (2) を代入すると，

```math
\boxed{
U=\frac32NkT
}
\tag{7}
```

を得る．

これは三つの並進自由度に対する等分配則とも一致する．

定積熱容量は，

```math
C_V=
\left(\frac{\partial U}{\partial T}\right)_{V,N}
```

より，

```math
\boxed{
C_V=\frac32Nk
}
\tag{8}
```

である．

また，エンタルピーは，

```math
H=U+pV
```

であり，式 (3) を用いると，

```math
H=\frac32NkT+NkT
```

となる．

したがって，

```math
\boxed{
H=\frac52NkT
}
\tag{9}
```

である．

定圧熱容量は，

```math
C_p=
\left(\frac{\partial H}{\partial T}\right)_{p,N}
```

より，

```math
\boxed{
C_p=\frac52Nk
}
\tag{10}
```

となる．

### 3．T-p 分布による解析

#### 3.1 T-p 分布の定義

温度 T，圧力 p，粒子数 N を一定に保ち，体積 V が揺らぐ分布を考える．

体積が V である状態のカノニカル分配関数を Z(T,V,N) とすると，T-p 分布の体積に関する重みは，

```math
e^{-\beta pV}Z(T,V,N)
```

で与えられる．

したがって，体積についての分配関数は，

```math
Y(T,p,N)
=
\int_0^\infty
e^{-\beta pV}Z(T,V,N)\,dV
```

と定義される．

この積分が収束するためには，

```math
p>0
```

が必要である．

ここで，Y は体積について積分しているため，体積の次元を持つ．

したがって，そのままでは $\ln Y$ の引数として使用できない．

この問題を解消するため，温度や圧力に依存しない任意の基準体積 $V_*>0$ を導入し，

```math
\boxed{
\mathcal Y(T,p,N)=\frac{Y(T,p,N)}{V_*}
}
```

と定義する．

これにより， $\mathcal Y$ は無次元となる．

この定数による規格化は，体積の確率分布には影響しない．

以下では，この無次元分配関数を使用する．

#### 3.2 T-p 分配関数の計算

式 (1) を代入すると，

```math
\begin{aligned}
\mathcal Y
&=
\frac{1}{V_*N!\lambda_T^{3N}}
\int_0^\infty
V^Ne^{-\beta pV}\,dV
\end{aligned}
```

となる．

ここで，

```math
I=
\int_0^\infty V^Ne^{-\alpha V}\,dV
```

とおく．

$\alpha>0$ のとき，

```math
I=\frac{\Gamma(N+1)}{\alpha^{N+1}}
```

である．

整数 N について，

```math
\Gamma(N+1)=N!
```

なので，

```math
\int_0^\infty
V^Ne^{-\alpha V}\,dV
=
\frac{N!}{\alpha^{N+1}}
```

を得る．

ここで，

```math
\alpha=\beta p=\frac{p}{kT}
```

とすれば，

```math
\int_0^\infty
V^Ne^{-pV/(kT)}\,dV
=
N!\left(\frac{kT}{p}\right)^{N+1}
```

となる．

これを代入すると，

```math
\begin{aligned}
\mathcal Y
&=
\frac{1}{V_*N!\lambda_T^{3N}}
N!\left(\frac{kT}{p}\right)^{N+1}\\
&=
\frac{1}{V_*\lambda_T^{3N}}
\left(\frac{kT}{p}\right)^{N+1}
\end{aligned}
```

である．

したがって，

```math
\boxed{
\mathcal Y
=
\frac{kT}{pV_*}
\left(
\frac{kT}{p\lambda_T^3}
\right)^N
}
\tag{11}
```

を得る．

これは有限粒子数 N に対する厳密な結果である．

特に， $N+1$ を N に置き換える近似は行っていない．

#### 3.3 ギブス自由エネルギーに対応する熱力学ポテンシャル

無次元分配関数 $\mathcal Y$ に対応する熱力学ポテンシャルを

```math
\mathcal G_*=-kT\ln\mathcal Y
```

と定義する．

式 (11) より，

```math
\boxed{
\begin{aligned}
\mathcal G_*
={}&
-NkT\ln\left(
\frac{kT}{p\lambda_T^3}
\right)\\
&-kT\ln\left(
\frac{kT}{pV_*}
\right)
\end{aligned}
}
\tag{12}
```

となる．

ここで，

```math
\frac{kT}{p\lambda_T^3}
```

および

```math
\frac{kT}{pV_*}
```

はいずれも無次元である．

式 (12) は，選択した基準体積 $V_*$ に対応する有限粒子数の等温等圧分布の熱力学ポテンシャルである．

基準体積 $V_*$ の選択を変更すると， $\mathcal G_*$ には粒子数に比例しない定数項が加わる．

したがって，有限粒子数での絶対的な値には規格化の規約が関係するが，以下の体積に関する期待値などは変化しない．

#### 3.4 T-p 分布における平均体積

T-p 分布において，体積 V の確率密度は，

```math
P(V)
=
\frac{
e^{-\beta pV}Z(T,V,N)
}{
Y(T,p,N)
}
```

である．

式 (1) を代入すると，

```math
P(V)
=
\frac{(\beta p)^{N+1}}{N!}
V^Ne^{-\beta pV}
```

となる．

これはガンマ分布である．

平均体積は，

```math
\langle V\rangle
=
\int_0^\infty VP(V)\,dV
```

で定義される．

したがって，

```math
\begin{aligned}
\langle V\rangle
&=
\frac{
\int_0^\infty V^{N+1}e^{-\beta pV}\,dV
}{
\int_0^\infty V^Ne^{-\beta pV}\,dV
}\\
&=
\frac{
(N+1)!(\beta p)^{-(N+2)}
}{
N!(\beta p)^{-(N+1)}
}\\
&=
\frac{N+1}{\beta p}
\end{aligned}
```

となる．

よって，

```math
\boxed{
\langle V\rangle
=
\frac{(N+1)kT}{p}
}
\tag{13}
```

である．

この結果は，式 (12) からも確認できる．

実際，

```math
\left(
\frac{\partial\mathcal G_*}{\partial p}
\right)_{T,N}
=
\frac{(N+1)kT}{p}
```

であるから，

```math
\boxed{
\left(
\frac{\partial\mathcal G_*}{\partial p}
\right)_{T,N}
=
\langle V\rangle
}
```

が成立する．

さらに，体積の分散は，

```math
\boxed{
\langle(\Delta V)^2\rangle
=
\frac{N+1}{(\beta p)^2}
}
```

である．

したがって，相対的な体積揺らぎは，

```math
\frac{
\sqrt{\langle(\Delta V)^2\rangle}
}{
\langle V\rangle
}
=
\frac1{\sqrt{N+1}}
```

となる．

N が十分大きい場合，この相対揺らぎはゼロに近づく．

また，体積の最頻値は確率密度 $P(V)$ を最大にする条件から求められる．

```math
\frac{d}{dV}\ln P(V)
=
\frac NV-\beta p=0
```

より，

```math
\boxed{
V_{\mathrm{mode}}
=
\frac{NkT}{p}
}
\tag{14}
```

となる．

したがって，有限粒子数では，

```math
V_{\mathrm{mode}}
\neq
\langle V\rangle
```

である．

一方，熱力学極限では相対的な揺らぎが消失するため，両者は巨視的には一致する．

#### 3.5 熱力学極限におけるギブス自由エネルギー

式 (12) は，

```math
\frac{\mathcal G_*}{N}
=
-kT\ln\left(
\frac{kT}{p\lambda_T^3}
\right)
-
\frac{kT}{N}
\ln\left(
\frac{kT}{pV_*}
\right)
```

と書ける．

ここで，N を無限大にする熱力学極限を考える．
温度 T，圧力 p，基準体積 $V_*$ は固定する．

このとき，

```math
\frac1N
\ln\left(
\frac{kT}{pV_*}
\right)
\longrightarrow0
```

であるため，

```math
\boxed{
G_{\mathrm{th}}
=
-NkT
\ln\left(
\frac{kT}{p\lambda_T^3}
\right)
}
\tag{15}
```

が熱力学極限におけるギブス自由エネルギーとなる．

ここで $G_{\mathrm{th}}$ は，通常の熱力学的なギブス自由エネルギーであり，有限粒子数の規格化された分配関数から得られる $\mathcal G_*$ の主要な N 依存項である．

実際，カノニカル分布から得られる式 (2) に，

```math
V=\frac{NkT}{p}
```

を代入すると，

```math
F
=
-NkT
\left[
\ln\left(
\frac{kT}{p\lambda_T^3}
\right)+1
\right]
```

となる．

さらに，

```math
pV=NkT
```

を使用すると，

```math
\begin{aligned}
F+pV
&=
-NkT
\left[
\ln\left(
\frac{kT}{p\lambda_T^3}
\right)+1
\right]
+NkT\\
&=
-NkT
\ln\left(
\frac{kT}{p\lambda_T^3}
\right)
\end{aligned}
```

を得る．

したがって，

```math
\boxed{
G_{\mathrm{th}}=F+pV
}
\tag{16}
```

が確認できる．

なお，式 (11) の厳密な分配関数からは，

```math
\ln\mathcal Y
=
N\ln\left(
\frac{kT}{p\lambda_T^3}
\right)
+
\ln\left(
\frac{kT}{pV_*}
\right)
```

である．

したがって，熱力学極限では，

```math
\frac{\ln\mathcal Y}{N}
=
\ln\left(
\frac{kT}{p\lambda_T^3}
\right)+O\left(\frac1N\right)
```

とするのが正確である．

分配関数自体を単純に $N+1$ から N に置き換えているのではなく，対数を取った後で粒子数に比例しない項を無視している．

#### 3.6 エントロピーと内部エネルギー

有限粒子数の等温等圧分布に対応するエントロピーは，

```math
\mathcal S_*
=
-\left(
\frac{\partial\mathcal G_*}{\partial T}
\right)_{p,N}
```

で与えられる．

ここで，

```math
\lambda_T^{-3}
\propto T^{3/2}
```

であるため，

```math
\frac{kT}{p\lambda_T^3}
\propto T^{5/2}
```

となる．

式 (12) を微分すると，

```math
\boxed{
\begin{aligned}
\mathcal S_*
={}&
Nk\ln\left(
\frac{kT}{p\lambda_T^3}
\right)\\
&+
k\ln\left(
\frac{kT}{pV_*}
\right)
+
\left(
\frac{5N}{2}+1
\right)k
\end{aligned}
}
\tag{17}
```

を得る．

この式の第2項は，体積を連続変数として積分したことに由来する有限粒子数の規格化依存項である．

一方，内部エネルギーは運動量の自由度にのみ依存するため，

```math
\boxed{
\langle U\rangle=\frac32NkT
}
\tag{18}
```

である．

平均体積については式 (13) より，

```math
p\langle V\rangle=(N+1)kT
```

である．

したがって，等温等圧分布における平均エンタルピーは，

```math
\begin{aligned}
\langle H\rangle
&=
\langle U+pV\rangle\\
&=
\frac32NkT+(N+1)kT
\end{aligned}
```

となり，

```math
\boxed{
\langle H\rangle
=
\left(
\frac{5N}{2}+1
\right)kT
}
\tag{19}
```

を得る．

また，有限粒子数の等温等圧分布に対応する定圧熱容量は，

```math
C_{p,*}
=
\left(
\frac{\partial\langle H\rangle}{\partial T}
\right)_{p,N}
```

で与えられるから，

```math
\boxed{
C_{p,*}
=
\left(
\frac{5N}{2}+1
\right)k
}
\tag{20}
```

である．

#### 3.7 熱力学極限での熱力学関数

熱力学極限では，粒子数に比例しない補正項を無視できる．

このとき，

```math
\frac{\langle V\rangle}{N}
\longrightarrow
\frac{kT}{p}
```

となり，

```math
\boxed{
pV=NkT
}
```

という通常の状態方程式が得られる．

また，式 (17) からは，

```math
\boxed{
S_{\mathrm{th}}
=
Nk\left[
\ln\left(
\frac{kT}{p\lambda_T^3}
\right)
+\frac52
\right]
}
\tag{21}
```

を得る．

これはカノニカル分布から導いた式 (4) に，

```math
V=\frac{NkT}{p}
```

を代入した結果と一致する．

内部エネルギーおよびエンタルピーは，

```math
\boxed{
U=\frac32NkT
}
```

```math
\boxed{
H=\frac52NkT
}
```

である．

さらに，定積熱容量と定圧熱容量は，

```math
\boxed{
C_V=\frac32Nk
}
```

```math
\boxed{
C_p=\frac52Nk
}
```

となる．

また，化学ポテンシャルは式 (6) より，

```math
\mu=kT\ln\left(
\frac{N\lambda_T^3}{V}
\right)
```

である．

状態方程式を代入すると，

```math
\boxed{
\mu
=
kT\ln\left(
\frac{p\lambda_T^3}{kT}
\right)
}
\tag{22}
```

となる．

式 (15) と比較すれば，

```math
\boxed{
G_{\mathrm{th}}=N\mu
}
\tag{23}
```

が確認できる．

### 4．最終結果のまとめ

単原子分子 N 個からなる古典理想気体について，熱力学極限で得られる熱力学関数は以下のとおりである．

カノニカル分配関数：

```math
\boxed{
Z=
\frac1{N!}
\left(
\frac{V}{\lambda_T^3}
\right)^N
}
```

ヘルムホルツ自由エネルギー：

```math
\boxed{
F=
-NkT
\left[
\ln\left(
\frac{V}{N\lambda_T^3}
\right)+1
\right]
}
```

状態方程式：

```math
\boxed{
pV=NkT
}
```

エントロピー：

```math
\boxed{
S=
Nk\left[
\ln\left(
\frac{V}{N\lambda_T^3}
\right)+\frac52
\right]
}
```

化学ポテンシャル：

```math
\boxed{
\mu=kT\ln\left(
\frac{N\lambda_T^3}{V}
\right)
}
```

内部エネルギー：

```math
\boxed{
U=\frac32NkT
}
```

エンタルピー：

```math
\boxed{
H=\frac52NkT
}
```

ギブス自由エネルギー：

```math
\boxed{
G_{\mathrm{th}}
=
-NkT\ln\left(
\frac{kT}{p\lambda_T^3}
\right)
}
```

定積熱容量：

```math
\boxed{
C_V=\frac32Nk
}
```

定圧熱容量：

```math
\boxed{
C_p=\frac52Nk
}
```

以上より，カノニカル分布と T-p 分布の両方から得られる熱力学極限での熱力学関数は一致する．

なお，有限粒子数の T-p 分布では，平均体積が

```math
\langle V\rangle=\frac{(N+1)kT}{p}
```

となるなど，粒子数に比例しない有限サイズ補正が存在する．
これらは熱力学極限では相対的に無視できるが，有限粒子数の厳密な統計力学的計算では保持する必要がある．
