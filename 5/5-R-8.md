# 演習問題【5-R-8】

## 解答

### 単原子分子理想気体の熱力学関数の導出

単原子分子 $N$ 個からなる古典理想気体について，カノニカル分布と $T-p$ 分布を用いて熱力学関数を導出する．
以下では，分子の質量を $m$ ，ボルツマン定数を $k$ ，プランク定数を $h$ とする．
また， $\beta=1/(kT)$ とおく．

#### 1．カノニカル分布による解析

##### 1.1 ハミルトニアン

理想気体では，分子間の相互作用を無視できるため，系の全エネルギーは各分子の運動エネルギーの和である．
各分子は三つの並進自由度をもつので，ハミルトニアンは

```math
\mathcal H=\sum_{i=1}^{3N}\frac{p_i^2}{2m}
```

と書ける．
ここで $p_i$ は運動量の各直交成分である．

##### 1.2 分配関数 $Z$

カノニカル分布では，温度 $T$ ，体積 $V$ ，粒子数 $N$ を固定する．
古典統計力学における分配関数は

```math
Z(T,V,N)=\frac{1}{h^{3N}N!}
\int e^{-\beta\mathcal H}\,d\Gamma
```

である．
ここで

```math
d\Gamma=\prod_{i=1}^{3N}dq_i\,dp_i
```

は位相空間の体積要素である．
因子 $h^{3N}$ は位相空間積分を無次元化するためのものであり， $N!$ は同種粒子の重複計数を除くために導入される．

ハミルトニアンは位置座標に依存しないので，位置座標について積分すると $V^N$ が得られる．
運動量についての積分は，各成分に分離できるため，

```math
Z=\frac{V^N}{h^{3N}N!}
\left(
\int_{-\infty}^{\infty}
e^{-\beta p^2/(2m)}\,dp
\right)^{3N}
```

となる．
ガウス積分

```math
\int_{-\infty}^{\infty}e^{-x^2}\,dx=\sqrt{\pi}
```

を用いる．
$x=\sqrt{\beta/(2m)}\,p$ と置換すれば，

```math
\begin{aligned}
\int_{-\infty}^{\infty}e^{-\beta p^2/(2m)}\,dp
&=\sqrt{\frac{2m}{\beta}}
\int_{-\infty}^{\infty}e^{-x^2}\,dx\\
&=\sqrt{\frac{2\pi m}{\beta}}
=\sqrt{2\pi mkT}
\end{aligned}
```

である．
したがって，分配関数は

```math
\boxed{
Z(T,V,N)=
\frac{V^N}{h^{3N}N!}(2\pi mkT)^{3N/2}
}
\tag{1}
```

となる．

##### 1.3 ヘルムホルツ自由エネルギー $F$

カノニカル分布に対応する熱力学ポテンシャルは，ヘルムホルツ自由エネルギーである．
その定義は

```math
F=-kT\ln Z
```

である．
式 (1) を代入すると，

```math
F=-kT\left[
N\ln V-\ln N!-3N\ln h
+\frac{3N}{2}\ln(2\pi mkT)
\right]
```

となる．
粒子数 $N$ が十分大きいとき，Stirling の近似

```math
\ln N!\simeq N\ln N-N
```

を用いることができる．
これを代入して整理すると，

```math
\boxed{
F=-NkT\left\{
\frac32\ln T+\ln\frac VN
+\ln\left[\frac{(2\pi mk)^{3/2}e}{h^3}\right]
\right\}
}
\tag{2}
```

が得られる．
ここで，対数の中の物理量は，それぞれを組み合わせた全体が無次元となるように解釈する．

#### 2．$T-p$ 分布による解析

##### 2.1 分配関数 $Y$

次に，温度 $T$ ，圧力 $p$ ，粒子数 $N$ が固定された $T-p$ 分布を考える．
この分布では体積 $V$ が変動するため，分配関数 $Y$ はカノニカル分配関数を体積について積分することで得られる．

```math
Y(T,p,N)=\int_0^\infty
e^{-pV/(kT)}Z(T,V,N)\,dV
```

式 (1) を代入すると，

```math
Y=\frac{(2\pi mkT)^{3N/2}}{h^{3N}N!}
\int_0^\infty e^{-pV/(kT)}V^N\,dV
```

となる．
ここで $\alpha=p/(kT)>0$ とおくと，積分は

```math
I=\int_0^\infty e^{-\alpha V}V^N\,dV
```

である．
まず，

```math
\int_0^\infty e^{-\alpha V}\,dV=\frac1\alpha
```

が成り立つ．
両辺を $\alpha$ で $N$ 回微分し，積分と微分の順序を交換すると，

```math
\begin{aligned}
I
&=\left(-\frac{\partial}{\partial\alpha}\right)^N
\frac1\alpha\\
&=\frac{N!}{\alpha^{N+1}}
\end{aligned}
```

を得る．
したがって，

```math
\int_0^\infty e^{-pV/(kT)}V^N\,dV
=N!\left(\frac{kT}{p}\right)^{N+1}
```

であり， $N!$ が約分されるので，分配関数は厳密には

```math
\boxed{
Y(T,p,N)=
\frac{(2\pi mkT)^{3N/2}}{h^{3N}}
\left(\frac{kT}{p}\right)^{N+1}
}
\tag{3}
```

となる．

解答例と同様に，巨視的な系で $N\gg1$ とし，熱力学関数の主要な $N$ 依存性を求める場合には，指数の $N+1$ を $N$ で近似できる．
よって，

```math
\boxed{
Y(T,p,N)\simeq
\frac{(2\pi mkT)^{3N/2}}{h^{3N}}
\left(\frac{kT}{p}\right)^N
}
\tag{4}
```

である．
式 (3) が体積積分の厳密な結果であり，式 (4) は解答例で採用されている熱力学極限での近似である．

##### 2.2 ギブス自由エネルギー $G$

$T-p$ 分布に対応する熱力学ポテンシャルはギブス自由エネルギーであり，

```math
G=-kT\ln Y
```

で与えられる．
式 (4) を用いると，

```math
\begin{aligned}
G\simeq-kT\bigg[
&\frac{3N}{2}\ln(2\pi mkT)-3N\ln h\\
&+N\ln\frac{kT}{p}
\bigg]
\end{aligned}
```

となる．
対数を整理すれば，

```math
\boxed{
G\simeq-NkT\left\{
\frac52\ln T-\ln p
+\ln\left[\frac{(2\pi m)^{3/2}k^{5/2}}{h^3}\right]
\right\}
}
\tag{5}
```

が得られる．
ここでも，式 (5) は式 (4) に対応する熱力学極限での表式である．

#### 3．熱力学関数の導出

##### 3.1 状態方程式と自由エネルギーの関係

ヘルムホルツ自由エネルギーから圧力を求める関係式は

```math
p=-\left(\frac{\partial F}{\partial V}\right)_{T,N}
```

である．
式 (2) を $V$ で微分すると，

```math
p=\frac{NkT}{V}
```

となる．
したがって，理想気体の状態方程式

```math
\boxed{pV=NkT}
\tag{6}
```

が得られる．

一方，ギブス自由エネルギーから体積を求める関係式は

```math
V=\left(\frac{\partial G}{\partial p}\right)_{T,N}
```

である．
式 (5) を $p$ で微分しても $V=NkT/p$ が得られ，式 (6) と一致する．
また，式 (2)，(5) と状態方程式を用いれば，熱力学極限で

```math
\boxed{
G\simeq F+pV
}
```

が確認できる．

##### 3.2 エントロピー $S$

エントロピーは，ヘルムホルツ自由エネルギーを用いて

```math
S=-\left(\frac{\partial F}{\partial T}\right)_{V,N}
```

と求められる．
式 (2) を微分すると，

```math
\boxed{
S=Nk\left\{
\frac32\ln T+\ln\frac VN
+\ln\left[\frac{(2\pi mk)^{3/2}e^{5/2}}{h^3}\right]
\right\}
}
\tag{7}
```

となる．
ここで $\frac32\ln T$ が現れるのは，体積 $V$ を一定にして温度微分を行っているためである．

状態方程式 $V=NkT/p$ を式 (7) に代入すれば，

```math
\boxed{
S=Nk\left\{
\frac52\ln T-\ln p
+\ln\left[\frac{(2\pi m)^{3/2}k^{5/2}e^{5/2}}{h^3}\right]
\right\}
}
\tag{8}
```

となる．
これは式 (5) から $S=-(\partial G/\partial T)_{p,N}$ として求めた結果とも一致する．

##### 3.3 化学ポテンシャル $\mu$

化学ポテンシャルは，ヘルムホルツ自由エネルギーを粒子数で微分して

```math
\mu=\left(\frac{\partial F}{\partial N}\right)_{T,V}
```

と定義される．
式 (2) を用いると，

```math
\mu=kT\ln\left[
\frac{N}{V}
\left(\frac{h^2}{2\pi mkT}\right)^{3/2}
\right]
```

を得る．
ここで $pV=NkT$ より $N/V=p/(kT)$ であるため，

```math
\boxed{
\mu=kT\ln\left[
\frac{p}{kT}
\left(\frac{h^2}{2\pi mkT}\right)^{3/2}
\right]
}
\tag{9}
```

とも書ける．
同じ結果は，熱力学極限での関係 $G\simeq N\mu$ を式 (5) に適用しても得られる．

##### 3.4 内部エネルギー $U$ と比熱

内部エネルギーは，ヘルムホルツ自由エネルギーから

```math
U=-T^2\left(\frac{\partial(F/T)}{\partial T}\right)_{V,N}
```

として求められる．
式 (2) を代入すると，

```math
\boxed{
U=\frac32NkT
}
\tag{10}
```

となる．
これは，単原子分子が三つの並進自由度をもち，各自由度が平均して $kT/2$ のエネルギーをもつこととも一致する．

定積熱容量 $C_V$ は

```math
C_V=\left(\frac{\partial U}{\partial T}\right)_{V,N}
```

で定義されるため，

```math
\boxed{
C_V=\frac32Nk
}
\tag{11}
```

である．
また，エンタルピー $H=U+pV$ と式 (6) より，

```math
H=\frac32NkT+NkT=\frac52NkT
```

である．
したがって，定圧熱容量 $C_p$ は

```math
C_p=\left(\frac{\partial H}{\partial T}\right)_{p,N}
```

から，

```math
\boxed{
C_p=\frac52Nk
}
\tag{12}
```

となる．

#### 4．結果のまとめ

単原子分子 $N$ 個からなる古典理想気体について，カノニカル分布と $T-p$ 分布を用いると，熱力学極限で次の結果が得られる．

- カノニカル分配関数：

```math
Z=\frac{V^N}{h^{3N}N!}(2\pi mkT)^{3N/2}
```

- ヘルムホルツ自由エネルギー：

```math
F=-NkT\left\{
\frac32\ln T+\ln\frac VN
+\ln\left[\frac{(2\pi mk)^{3/2}e}{h^3}\right]
\right\}
```

- $T-p$ 分配関数の熱力学極限での近似：

```math
Y\simeq\frac{(2\pi mkT)^{3N/2}}{h^{3N}}
\left(\frac{kT}{p}\right)^N
```

- ギブス自由エネルギー：

```math
G\simeq-NkT\left\{
\frac52\ln T-\ln p
+\ln\left[\frac{(2\pi m)^{3/2}k^{5/2}}{h^3}\right]
\right\}
```

- 状態方程式，内部エネルギー，比熱：

```math
pV=NkT,\qquad U=\frac32NkT
```

```math
C_V=\frac32Nk,\qquad C_p=\frac52Nk
```

以上より，二つの分布から得られる熱力学関数は整合しており，単原子分子理想気体の熱力学的性質が導出された．
