# 演習問題【5-A-3】

## 解答

### 1．孔から流出する分子数の計算

体積 $V$ の容器に，圧力 $p$ ，絶対温度 $T$ の希薄な理想気体が入っているとする．
容器の壁を $yz$ 面とし，面積 $A$ の小さな孔があいているものとする．
器外は真空であるため，孔を通って外から容器内へ入る分子は存在しない．

分子の質量を $m$ ，Boltzmann 定数を $k$ ，容器内の単位体積当たりの分子数を $n$ とする．
また，分子の速度を $\boldsymbol{v}=(v_x,v_y,v_z)$ とする．
ここで， $v_x>0$ の分子は容器内から孔を通って外へ向かい， $v_x<0$ の分子は外から容器内へ向かうものとする．

分子の速度分布が Maxwell 分布に従うとき，規格化された速度分布関数は

```math
f(v_x,v_y,v_z)
=\left(\frac{m}{2\pi kT}\right)^{3/2}
\exp\left[-\frac{m}{2kT}
(v_x^2+v_y^2+v_z^2)\right]
\tag{1}
```

である．
この関数は，

```math
\iiint_{-\infty}^{\infty}
f(v_x,v_y,v_z)\,dv_x\,dv_y\,dv_z=1
```

を満たす．
したがって，速度成分がそれぞれ $v_x$ から $v_x+dv_x$ ， $v_y$ から $v_y+dv_y$ ， $v_z$ から $v_z+dv_z$ の範囲にある分子の単位体積当たりの数は，

```math
n f(v_x,v_y,v_z)\,dv_x\,dv_y\,dv_z
```

である．

微小時間 $\delta t$ の間に孔から流出する分子を考える．
速度の $x$ 成分が $v_x>0$ の分子は，この時間内に $x$ 方向へ距離 $v_x\delta t$ だけ進む．
したがって，この間に孔を通過する分子は，孔を底面とし，厚さ $v_x\delta t$ をもつ領域内に最初から存在していた分子である．
その領域の体積は $Av_x\delta t$ であるから，流出する分子数は

```math
\delta N_{\mathrm{out}}
=A\delta t
\int_0^\infty dv_x
\int_{-\infty}^{\infty}dv_y
\int_{-\infty}^{\infty}dv_z\,
v_x n f(v_x,v_y,v_z)
\tag{2}
```

となる．
ここで， $\delta N_{\mathrm{out}}$ は正の流出分子数である．
一方，容器内に残る分子数を $N$ とすれば， $dN/dt<0$ であり，

```math
-\frac{dN}{dt}
=\frac{\delta N_{\mathrm{out}}}{\delta t}
```

である．
よって，流出分子数の単位時間当たりの量は，

```math
-\frac{dN}{dt}
=A n\int_0^\infty dv_x
\int_{-\infty}^{\infty}dv_y
\int_{-\infty}^{\infty}dv_z\,
v_x f(v_x,v_y,v_z)
\tag{3}
```

と表される．

式 (1) を代入すると，指数関数を速度成分ごとに分離できるので，

```math
\begin{aligned}
-\frac{dN}{dt}
={}&An\left(\frac{m}{2\pi kT}\right)^{3/2}\\
&\times\int_0^\infty
v_x e^{-\frac{mv_x^2}{2kT}}\,dv_x\\
&\times\int_{-\infty}^{\infty}
e^{-\frac{mv_y^2}{2kT}}\,dv_y\\
&\times\int_{-\infty}^{\infty}
e^{-\frac{mv_z^2}{2kT}}\,dv_z
\end{aligned}
\tag{4}
```

となる．

ここで，ガウス積分の公式

```math
\int_{-\infty}^{\infty}e^{-ax^2}\,dx
=\sqrt{\frac{\pi}{a}}
\qquad(a>0)
```

を用いると，

```math
\int_{-\infty}^{\infty}
e^{-\frac{mv_y^2}{2kT}}\,dv_y
=
\int_{-\infty}^{\infty}
e^{-\frac{mv_z^2}{2kT}}\,dv_z
=\sqrt{\frac{2\pi kT}{m}}
\tag{5}
```

を得る．
これらを式 (4) に代入すれば，

```math
-\frac{dN}{dt}
=An\sqrt{\frac{m}{2\pi kT}}
\int_0^\infty v_x
e^{-\frac{mv_x^2}{2kT}}\,dv_x
\tag{6}
```

となる．

残った積分を計算するため，

```math
u=\frac{mv_x^2}{2kT}
```

とおく．
このとき，

```math
du=\frac{mv_x}{kT}\,dv_x
```

であり，積分区間は $v_x=0$ で $u=0$ ， $v_x\to\infty$ で $u\to\infty$ となる．
したがって，

```math
\begin{aligned}
\int_0^\infty
v_xe^{-\frac{mv_x^2}{2kT}}\,dv_x
&=\frac{kT}{m}\int_0^\infty e^{-u}\,du\\
&=\frac{kT}{m}
\end{aligned}
\tag{7}
```

である．

式 (7) を式 (6) に代入すると，

```math
\begin{aligned}
-\frac{dN}{dt}
&=An\sqrt{\frac{m}{2\pi kT}}\frac{kT}{m}\\
&=An\sqrt{\frac{kT}{2\pi m}}
\end{aligned}
\tag{8}
```

となる．

さらに，理想気体の状態方程式を分子数密度 $n$ で表すと，

```math
p=nkT
\tag{9}
```

である．
したがって，式 (8) は，

```math
\boxed{
-\frac{dN}{dt}
=A\sqrt{\frac{np}{2\pi m}}
}
\tag{10}
```

と書ける．
これが，単位時間当たりに孔から流出する分子数である．

### 2．孔から流出する分子の $x$ 方向の速度分布

次に，孔から流出する分子の $x$ 方向の速度分布を求める．

容器内の分子全体の速度分布は Maxwell 分布であるが，孔から流出する分子の速度分布は，そのまま Maxwell 分布にはならない．
これは，速度の $x$ 成分 $v_x$ が大きい分子ほど，単位時間に孔を通過する確率が高いためである．
したがって，流出分子の分布は $v_x$ による重み付けを受ける．

式 (2) より， $x$ 方向の速度成分が $v_x$ から $v_x+dv_x$ の範囲にある流出分子数は， $v_y,v_z$ について積分すると，

```math
\begin{aligned}
dN_{\mathrm{out}}
={}&A\delta t\,n
\left(\frac{m}{2\pi kT}\right)^{3/2}\\
&\times v_x e^{-\frac{mv_x^2}{2kT}}\,dv_x\\
&\times\int_{-\infty}^{\infty}
e^{-\frac{mv_y^2}{2kT}}\,dv_y\\
&\times\int_{-\infty}^{\infty}
e^{-\frac{mv_z^2}{2kT}}\,dv_z
\end{aligned}
\tag{11}
```

となる．
式 (5) を用いると， $v_x$ に依存しない因子をまとめることができ，

```math
dN_{\mathrm{out}}
\propto v_x e^{-\frac{mv_x^2}{2kT}}\,dv_x
\qquad(v_x>0)
\tag{12}
```

を得る．
すなわち，流出分子の $x$ 方向の速度分布は，

```math
f_{\mathrm{out}}(v_x)
=Cv_xe^{-\frac{mv_x^2}{2kT}}
\qquad(v_x>0)
\tag{13}
```

という形で表される．
ここで， $C$ は規格化定数である．

確率分布として用いるためには，すべての流出分子について確率を積分した値が $1$ でなければならない．
したがって，

```math
\int_0^\infty f_{\mathrm{out}}(v_x)\,dv_x=1
\tag{14}
```

という条件を課す．
式 (13) を代入すると，

```math
C\int_0^\infty
v_xe^{-\frac{mv_x^2}{2kT}}\,dv_x=1
```

となる．
式 (7) で求めた積分値を用いれば，

```math
C\frac{kT}{m}=1
```

であるから，

```math
C=\frac{m}{kT}
```

となる．
よって，孔から流出する分子の $x$ 方向の速度分布は，

```math
\boxed{
f_{\mathrm{out}}(v_x)
=\frac{m}{kT}v_x
e^{-\frac{mv_x^2}{2kT}}
\qquad(v_x>0)
}
\tag{15}
```

である．
すなわち，速度が $v_x$ から $v_x+dv_x$ の範囲にある流出分子の確率は，

```math
\boxed{
f_{\mathrm{out}}(v_x)\,dv_x
=\frac{m}{kT}v_x
e^{-\frac{mv_x^2}{2kT}}\,dv_x
}
```

となる．

以上より，孔から流出する分子数は式 (10) で与えられ，流出分子の $x$ 方向の速度分布は式 (15) で与えられる．
