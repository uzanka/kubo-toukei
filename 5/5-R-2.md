# 演習問題【5-R-2】
## 解答

本問題では，$N$ 個の質点から成る理想気体の状態数 $\Omega_{\text{cl}}(E, N, V)$ を求め，そこから状態方程式 $PV = NkT$ を導出する．

### 1. 系のハミルトニアンと相空間の微小体積

まず，この系の全エネルギー（ハミルトニアン） $H$ を考える．
各質点の質量を $m$ ，その運動量を $p_i$ とすると，全エネルギーは次のように書ける：

$$H = \sum_{i=1}^{3N} \frac{p_i^2}{2m}$$

ここで， $N$ 個の質点はそれぞれ 3 次元の運動量成分を持つため，合計で $3N$ 個の運動量成分 $p_1, p_2, \dots, p_{3N}$ が存在する．

統計力学における状態数 $\Omega_{\text{cl}}(E, N, V)$ は，エネルギーが $E$ 以下となる相空間（位置座標と運動量の組み合わせの空間）の体積を，プランク定数 $h$ の $3N$ 乗と粒子数 $N!$ （粒子の区別がつかないことによる補正）で割ることで求められる：

$$\Omega_{\text{cl}}(E, N, V) = \frac{1}{h^{3N} N!} \int \dots \int d\mathbf{r}_1 \dots d\mathbf{r}_N \int \dots \int_{\sum \frac{p_i^2}{2m} \le E} dp_1 \dots dp_{3N}$$

ここで，位置座標に関する積分 $\int d\mathbf{r}_1 \dots d\mathbf{r}_N$ は，各粒子が体積 $V$ の箱の中にいるため，単に $V^N$ となる．
したがって，

$$\Omega_{\text{cl}}(E, N, V) = \frac{V^N}{h^{3N} N!} \int \dots \int_{\sum p_i^2 \le 2mE} dp_1 \dots dp_{3N}$$

となる．

### 2. 運動量空間における積分（球の体積）

運動量に関する積分は， $\sum_{i=1}^{3N} p_i^2 \le 2mE$ という条件を満たす $3N$ 次元の球の体積を求めていることに相当する．
この球の半径 $R$ は， $R^2 = 2mE$ より $R = \sqrt{2mE}$ である．

$n$ 次元空間における半径 $R$ の球の体積 $V_n(R)$ は， $n$ 次元における単位球の体積 $C_n$ を用いて $V_n(R) = C_n R^n$ と表される．
問題のヒントより， $C_n = \frac{\pi^{n/2}}{\Gamma(\frac{n}{2} + 1)}$ である．
本問では $n = 3N$ であるから，運動量積分の値は次のように計算できる：

$$\text{積分値} = C_{3N} (2mE)^{3N/2} = \frac{\pi^{3N/2}}{\Gamma(\frac{3N}{2} + 1)} (2mE)^{3N/2} = \frac{(2\pi mE)^{3N/2}}{\Gamma(\frac{3N}{2} + 1)}$$

これらをまとめると，状態数 $\Omega_{\text{cl}}$ は以下のようになる：

$$\Omega_{\text{cl}}(E, N, V) = \frac{V^N}{h^{3N} N!} \frac{(2\pi mE)^{3N/2}}{\Gamma(\frac{3N}{2} + 1)}$$

### 3. エントロピーと状態方程式の導出

次に，ボルツマンの原理 $S = k \log \Omega_{\text{cl}}$ を用いてエントロピー $S$ を求める．

$$\log \Omega_{\text{cl}} = \log \left[ \frac{V^N}{h^{3N} N!} \frac{(2\pi mE)^{3N/2}}{\Gamma(\frac{3N}{2} + 1)} \right]$$

$$= N \log V - 3N \log h - \log N! + \frac{3N}{2} \log(2\pi mE) - \log \Gamma\left(\frac{3N}{2} + 1\right)$$

ここで，粒子数 $N$ が非常に大きいとき（熱力学的極限），Stirling の近似 $\log N! \approx N \log N - N$ を用いる．
また， $\log \Gamma(\frac{3N}{2} + 1) = \log ((\frac{3N}{2})!) \approx \frac{3N}{2} \log(\frac{3N}{2}) - \frac{3N}{2}$ を用いる．
これらを整理すると，エントロピー $S(E, N, V)$ は次のように書ける（定数項をまとめる）：

```math
S(E, N, V) = Nk \left\{ \log \frac{V}{N} + \frac{3}{2} \log \frac{2E}{3N} + \text{const} \right\}
```

状態方程式を導くために，熱力学的な関係式を用いる．
温度 $T$ は， $ \frac{1}{T} = \left( \frac{\partial S}{\partial E} \right)_{V,N} $ で定義される．

$$\frac{1}{T} = Nk \frac{\partial}{\partial E} \left( \frac{3}{2} \log E \right) = Nk \cdot \frac{3}{2E} = \frac{3Nk}{2E}$$

これより， $E = \frac{3}{2} NkT$ となる．

また，圧力 $P$ は， $ \frac{P}{T} = \left( \frac{\partial S}{\partial V} \right)_{E,N} $ で定義される．

$$\frac{P}{T} = Nk \frac{\partial}{\partial V} (\log V) = \frac{Nk}{V}$$

これより，$PV = NkT$ が得られる．

以上により，理想気体の状態方程式が導かれた．

## 解説

本解答では，統計力学の基本的な手続きである「相空間の体積計算 $\to$ エントロピーの算出 $\to$ 熱力学的な微分による状態量の決定」という流れに従った．

1.  **相空間の積分**:
  理想気体の問題では，位置座標 $r$ と運動量 $p$ の両方を積分する必要がある．
  位置座標は単なる体積 $V$ の積となるが，運動量座標については「エネルギーが一定以下」という条件が，多次元空間における「球の内部」という幾何学的な条件に置き換わる．
  この「球の体積」を求める計算が，多次元のガンマ関数 $\Gamma(x)$ を用いた形で行われている．
2.  **Stirling の近似**:
  統計力学では粒子数 $N$ が $10^{23}$ 程度の極めて大きな数として扱われるため，階乗 $N!$ をそのまま扱うことはできない．
  そのため，$\log N! \approx N \log N - N$ という近似を用いることで，計算を扱いやすい対数形式へと変換している．
3.  **熱力学的な関係**:
  エントロピー $S$ はエネルギー $E$ や体積 $V$ の関数として 求まる．
  物理学における「温度」や「圧力」は，これらの変数に対するエントロピーの変化率（偏微分）として定義されている．
  この定義に従って微分を行うことで，マクロな物理量である $P, V, T$ の間の関係式を導き出すことができる．
