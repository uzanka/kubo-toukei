# 演習問題【5-R-2】
## 解答

### 1．ハミルトニアンと状態数の定式化

$N$ 個の質点からなる理想気体を考える．
各質点の質量を $m$ ，系の体積を $V$ ，全エネルギーを $E$ とする．
理想気体では質点間の相互作用を無視できるため，系のハミルトニアン $H$ は各質点の運動エネルギーの和で与えられる．

各質点は3個の運動量成分を持つので，運動量成分を $p_1,p_2,\ldots,p_{3N}$ と書けば，

```math
H=\sum_{i=1}^{3N}\frac{p_i^2}{2m}
\tag{1}
```

である．

状態数 $\Omega_{\mathrm{cl}}(E,N,V)$ は，エネルギーが $E$ 以下となる相空間の体積を $h^{3N}N!$ で割ったものである．
ここで，相空間とは，すべての質点の位置座標と運動量によって指定される空間である．
また， $h$ はプランク定数であり， $N!$ は同一の質点の並べ方による重複を補正するための因子である．
したがって，

```math
\begin{aligned}
\Omega_{\mathrm{cl}}(E,N,V)
={}&\frac{1}{h^{3N}N!}
\int d\mathbf r_1\cdots d\mathbf r_N\\
&\times
\int_{\sum_{i=1}^{3N}p_i^2\le 2mE}
dp_1\cdots dp_{3N}
\end{aligned}
\tag{2}
```

となる．

各質点の位置座標は体積 $V$ の箱の内部を自由に動くことができる．
したがって，位置座標について積分すると，各質点について体積 $V$ が1つずつ得られ，全体では $V^N$ となる．
よって，式 (2) は

```math
\Omega_{\mathrm{cl}}(E,N,V)
=\frac{V^N}{h^{3N}N!}
\int_{\sum_{i=1}^{3N}p_i^2\le 2mE}
dp_1\cdots dp_{3N}
\tag{3}
```

と書ける．

### 2．運動量空間の積分

式 (3) の運動量積分では，

```math
\sum_{i=1}^{3N}p_i^2\le 2mE
\tag{4}
```

を満たす領域の体積を求めればよい．
式 (4) は， $3N$ 次元の運動量空間において，原点を中心とする半径 $\sqrt{2mE}$ の球の内部を表している．

$n$ 次元空間における半径 $R$ の球の体積は，単位球の体積を $C_n$ とすると，

```math
V_n(R)=C_nR^n
```

である．
問題文のヒントより，

```math
C_n=\frac{\pi^{n/2}}{\Gamma\left(\frac n2+1\right)}
```

であるから， $n=3N$ ， $R=\sqrt{2mE}$ を代入すると，運動量積分は

```math
\begin{aligned}
&\int_{\sum_{i=1}^{3N}p_i^2\le 2mE}
dp_1\cdots dp_{3N}\\
&\quad=C_{3N}(\sqrt{2mE})^{3N}\\
&\quad=\frac{\pi^{3N/2}}{\Gamma\left(\frac{3N}{2}+1\right)}
(2mE)^{3N/2}\\
&\quad=\frac{(2\pi mE)^{3N/2}}
{\Gamma\left(\frac{3N}{2}+1\right)}
\end{aligned}
\tag{5}
```

となる．
これを式 (3) に代入すると，状態数は

```math
\boxed{
\Omega_{\mathrm{cl}}(E,N,V)
=\frac{V^N}{h^{3N}N!}
\frac{(2\pi mE)^{3N/2}}
{\Gamma\left(\frac{3N}{2}+1\right)}
}
\tag{6}
```

と求まる．

### 3．エントロピーの導出

ボルツマンの関係式より，エントロピー $S$ は状態数を用いて

```math
S(E,N,V)=k\log\Omega_{\mathrm{cl}}(E,N,V)
\tag{7}
```

と定義される．
ここで， $k$ はボルツマン定数である．
式 (6) の対数を取ると，

```math
\begin{aligned}
\log\Omega_{\mathrm{cl}}
={}&N\log V-3N\log h-\log N!\\
&+\frac{3N}{2}\log(2\pi mE)\\
&-\log\Gamma\left(\frac{3N}{2}+1\right)
\end{aligned}
\tag{8}
```

となる．

通常の気体では $N$ は非常に大きいため，Stirling の近似

```math
\log N!\simeq N\log N-N
\tag{9}
```

を用いることができる．
また，Gamma 関数についても同様に，

```math
\log\Gamma(x+1)\simeq x\log x-x
```

が成り立つので， $x=3N/2$ とすれば，

```math
\log\Gamma\left(\frac{3N}{2}+1\right)
\simeq
\frac{3N}{2}\log\frac{3N}{2}-\frac{3N}{2}
\tag{10}
```

となる．

式 (9)，(10) を式 (8) に代入し，項を整理すると，

```math
\begin{aligned}
\log\Omega_{\mathrm{cl}}
\simeq{}&
N\log\frac{V}{N}
+\frac{3N}{2}\log\frac{2E}{3N}\\
&+N\log\frac{(2\pi m)^{3/2}e^{5/2}}{h^3}
\end{aligned}
\tag{11}
```

を得る．
したがって，エントロピーは

```math
\boxed{
S(E,N,V)
=Nk\left\{
\log\frac{V}{N}
+\frac32\log\frac{2E}{3N}
+\log\frac{(2\pi m)^{3/2}e^{5/2}}{h^3}
\right\}
}
\tag{12}
```

となる．
これは熱力学的極限で Stirling の近似を用いて得られたエントロピーである．

### 4．状態方程式の導出

エントロピーを用いると，温度 $T$ と圧力 $P$ はそれぞれ，

```math
\frac{1}{T}
=\left(\frac{\partial S}{\partial E}\right)_{V,N},
\qquad
\frac{P}{T}
=\left(\frac{\partial S}{\partial V}\right)_{E,N}
\tag{13}
```

によって定義される．
ここで，添字は偏微分の際に一定に保つ変数を表す．

まず，式 (12) をエネルギー $E$ について偏微分する．
$E$ に依存する項は $\frac32\log(2E/(3N))$ だけであるから，

```math
\begin{aligned}
\frac{1}{T}
&=\left(\frac{\partial S}{\partial E}\right)_{V,N}\\
&=Nk\frac32\frac{1}{E}\\
&=\frac{3Nk}{2E}
\end{aligned}
\tag{14}
```

となる．
これを $E$ について解けば，

```math
\boxed{
E=\frac32 NkT
}
\tag{15}
```

を得る．
したがって，1質点あたりの平均エネルギーを $\bar{\epsilon}=E/N$ と書くと，

```math
\boxed{
kT=\frac23\bar{\epsilon}
}
\tag{16}
```

である．

次に，式 (12) を体積 $V$ について偏微分する．
$V$ に依存する項は $\log(V/N)$ だけであるため，

```math
\begin{aligned}
\frac{P}{T}
&=\left(\frac{\partial S}{\partial V}\right)_{E,N}\\
&=Nk\frac{1}{V}\\
&=\frac{Nk}{V}
\end{aligned}
\tag{17}
```

となる．
両辺に $VT$ を掛けると，

```math
\boxed{
PV=NkT
}
\tag{18}
```

が得られる．

以上より，古典的な状態数 $\Omega_{\mathrm{cl}}(E,N,V)$ からエントロピーを求め，そのエネルギーおよび体積についての偏微分を用いることで，理想気体の状態方程式

```math
\boxed{
PV=NkT
}
```

が導かれた．
