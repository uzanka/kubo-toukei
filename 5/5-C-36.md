# 演習問題【5-C-36】

## 解答

### 1．平衡条件と自由エネルギーの変分

平衡状態における粒子数密度 $n(\boldsymbol r)$ は，全粒子数 $N$ を一定に保つという条件のもとで，ヘルムホルツの自由エネルギー

```math
F=U-TS
```

を最小にする分布として求められる．
ここで， $U$ は全位置エネルギー， $S$ はエントロピー， $T$ は温度， $k$ はボルツマン定数である．
全粒子数は

```math
N=\int n(\boldsymbol r)\,d\boldsymbol r
```

で与えられる．
したがって，求める条件は，全粒子数を変えない任意の変分 $\delta n(\boldsymbol r)$ に対して $\delta F=0$ となることである．

この制約条件を扱うため，ラグランジュの未定乗数 $\mu$ を導入し，

```math
\delta(F-\mu N)=0
\tag{1}
```

を考える．
ここで $\mu$ は，後に数密度の規格化条件によって決まる定数である．

### 2．位置エネルギーの変分

与えられた位置エネルギーは，

```math
\begin{aligned}
U={}&\frac{e^2}{2}
\iint\frac{n(\boldsymbol r)n(\boldsymbol r')}
{|\boldsymbol r-\boldsymbol r'|}
\,d\boldsymbol r\,d\boldsymbol r'\\
&+e\int n(\boldsymbol r)\varphi_{\mathrm{ext}}(\boldsymbol r)
\,d\boldsymbol r
\end{aligned}
```

である．
これを $n(\boldsymbol r)$ について変分する．

まず，クーロン相互作用の項について， $n(\boldsymbol r)$ を $n(\boldsymbol r)+\delta n(\boldsymbol r)$ に変化させたときの一次の項を取り出すと，

```math
\begin{aligned}
\delta U_{\mathrm{int}}
={}&\frac{e^2}{2}
\iint
\frac{
\delta n(\boldsymbol r)n(\boldsymbol r')
+n(\boldsymbol r)\delta n(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|}
\,d\boldsymbol r\,d\boldsymbol r'
\end{aligned}
```

となる．
ここで，積分変数 $\boldsymbol r$ と $\boldsymbol r'$ を入れ替えても積分値は変わらない．
そのため，右辺の2つの項は等しく，係数 $1/2$ が消える．
よって，

```math
\delta U_{\mathrm{int}}
=e^2\iint
\frac{n(\boldsymbol r')}{|\boldsymbol r-\boldsymbol r'|}
\delta n(\boldsymbol r)\,d\boldsymbol r\,d\boldsymbol r'
```

を得る．

次に，外場による位置エネルギーの変分は，

```math
\delta U_{\mathrm{ext}}
=e\int\varphi_{\mathrm{ext}}(\boldsymbol r)
\delta n(\boldsymbol r)\,d\boldsymbol r
```

である．
以上をまとめると，

```math
\begin{aligned}
\delta U
=\int\Bigg[
&e^2\int\frac{n(\boldsymbol r')}
{|\boldsymbol r-\boldsymbol r'|}\,d\boldsymbol r'\\
&+e\varphi_{\mathrm{ext}}(\boldsymbol r)
\Bigg]\delta n(\boldsymbol r)\,d\boldsymbol r
\end{aligned}
\tag{2}
```

となる．

### 3．エントロピーの変分と平衡方程式

エントロピーは，

```math
S=-k\int n(\boldsymbol r)
\{\log n(\boldsymbol r)-1\}\,d\boldsymbol r
```

で与えられている．
関数 $n(\log n-1)$ を $n$ で微分すると，

```math
\frac{d}{dn}\{n(\log n-1)\}=\log n
```

である．
したがって，エントロピーの変分は，

```math
\delta S=-k\int\log n(\boldsymbol r)
\delta n(\boldsymbol r)\,d\boldsymbol r
\tag{3}
```

となる．

また，全粒子数の変分は，

```math
\delta N=\int\delta n(\boldsymbol r)\,d\boldsymbol r
\tag{4}
```

である．
式 (1) に $\delta F=\delta U-T\delta S$ と式 (2)～(4) を代入すると，

```math
\begin{aligned}
0=\delta(F-\mu N)
=\int\Bigg[
& e^2\int\frac{n(\boldsymbol r')}
{|\boldsymbol r-\boldsymbol r'|}\,d\boldsymbol r'\\
&+e\varphi_{\mathrm{ext}}(\boldsymbol r)
+kT\log n(\boldsymbol r)-\mu
\Bigg]\delta n(\boldsymbol r)\,d\boldsymbol r
\end{aligned}
```

となる．
この式は任意の $\delta n(\boldsymbol r)$ に対して成り立つ必要がある．
よって，積分の中の角括弧内が各点でゼロでなければならない．
したがって，

```math
\boxed{
kT\log n(\boldsymbol r)
+e^2\int\frac{n(\boldsymbol r')}
{|\boldsymbol r-\boldsymbol r'|}\,d\boldsymbol r'
+e\varphi_{\mathrm{ext}}(\boldsymbol r)-\mu=0
}
\tag{5}
```

を得る．
これが平衡状態における数密度 $n(\boldsymbol r)$ の満たす式である．

### 4．静電ポテンシャルを用いた表現

静電ポテンシャル $\varphi(\boldsymbol r)$ は，外場によるポテンシャルと，粒子の電荷分布が作るポテンシャルの和として，

```math
\boxed{
\varphi(\boldsymbol r)
=\varphi_{\mathrm{ext}}(\boldsymbol r)
+e\int\frac{n(\boldsymbol r')}
{|\boldsymbol r-\boldsymbol r'|}\,d\boldsymbol r'
}
\tag{6}
```

と定義される．
式 (6) の両辺に $e$ を掛けると，

```math
e\varphi(\boldsymbol r)
=e\varphi_{\mathrm{ext}}(\boldsymbol r)
+e^2\int\frac{n(\boldsymbol r')}
{|\boldsymbol r-\boldsymbol r'|}\,d\boldsymbol r'
```

となる．
これを式 (5) に代入すれば，

```math
kT\log n(\boldsymbol r)+e\varphi(\boldsymbol r)-\mu=0
```

を得る．
これを $n(\boldsymbol r)$ について解くと，

```math
\boxed{
n(\boldsymbol r)
=\exp\left[-\frac{e\varphi(\boldsymbol r)-\mu}{kT}\right]
}
\tag{7}
```

となる．

ここで， $\varphi(\boldsymbol r)=0$ となる点が存在する場合，その点での数密度を $n_0$ と定義すれば，

```math
n_0=\exp\left(\frac{\mu}{kT}\right)
```

である．
したがって，式 (7) は，

```math
\boxed{
n(\boldsymbol r)=n_0
\exp\left[-\frac{e\varphi(\boldsymbol r)}{kT}\right]
}
\tag{8}
```

とも表せる．
より一般的には，式 (7) を用い，定数 $\mu$ を全粒子数条件 $\int n(\boldsymbol r)\,d\boldsymbol r=N$ によって決定すればよい．

### 5．静電ポテンシャルの満たす方程式

式 (6) に，式 (7) で得られた数密度を代入する．
すると，

```math
\boxed{
\begin{aligned}
\varphi(\boldsymbol r)
={}&\varphi_{\mathrm{ext}}(\boldsymbol r)\\
&+e\int
\frac{
\exp\left[-\dfrac{e\varphi(\boldsymbol r')-\mu}{kT}\right]
}{
|\boldsymbol r-\boldsymbol r'|
}\,d\boldsymbol r'
\end{aligned}
}
\tag{9}
```

となる．
$n_0=\exp(\mu/kT)$ と表せる場合には，

```math
\boxed{
\varphi(\boldsymbol r)
=\varphi_{\mathrm{ext}}(\boldsymbol r)
+e n_0\int
\frac{\exp[-e\varphi(\boldsymbol r')/(kT)]}
{|\boldsymbol r-\boldsymbol r'|}\,d\boldsymbol r'
}
\tag{10}
```

とも書ける．
これが静電ポテンシャル $\varphi(\boldsymbol r)$ の満たす積分方程式である．

結論として，平衡状態の数密度は式 (7) のボルツマン分布に従い，静電ポテンシャルは式 (9) または式 (10) を満たす．
これらの式は互いに結びついており，ポテンシャルが数密度を決める一方，数密度が電荷分布を通してポテンシャルを決めるという自己無撞着な関係を表している．
外場 $\varphi_{\mathrm{ext}}$ ，温度 $T$ ，全粒子数 $N$ などの条件を与え，これらの式を同時に解くことで，平衡状態の粒子分布と静電ポテンシャルが定まるのである．
