# 演習問題【5-C-36】

## 解答

### 1．平衡条件と自由エネルギー

電荷 $e$ を持つ粒子の数密度を $n(\boldsymbol r)$ とする．
温度 $T$ が一定であり，全粒子数 $N$ が保存される系の平衡状態は，ヘルムホルツの自由エネルギー

```math
F=U-TS
```

を，全粒子数の拘束条件のもとで最小にする分布として求められる．

ここでは，問題文で与えられたエネルギー汎関数とエントロピー汎関数を用いる古典的平均場モデルを考える．
また， $T>0$ とし， $\log$ は自然対数を表すものとする．

数密度 $n$ は次元を持つため，対数の引数を無次元にする目的で，基準密度 $n_*>0$ を導入する．
したがって，エントロピーは

```math
S=-k\int n(\boldsymbol r)
\left\{
\log\frac{n(\boldsymbol r)}{n_*}-1
\right\}
\,d\boldsymbol r
```

と表す．

これは，元のエントロピーにおける対数を無次元化した表現である．
$n_*$ は任意の基準密度であり，全粒子数が一定の場合には，この基準の変更は自由エネルギーに粒子数に比例する定数を加えることに対応するため，平衡分布の変分条件は変わらない．

全粒子数は

```math
N=\int n(\boldsymbol r)\,d\boldsymbol r
```

で与えられる．

したがって，平衡条件は，粒子数を一定に保つ任意の変分に対して

```math
\delta F=0
```

となることである．

この拘束条件を扱うため，ラグランジュ未定乗数 $\mu$ を導入し，

```math
\delta(F-\mu N)=0
\tag{1}
```

を考える．
ここで， $\mu$ は粒子数の規格化条件によって決まる定数であり，平衡状態における化学ポテンシャルに相当する．

以下では，粒子が存在できる領域を $\Omega$ とする．
この領域は有限であるか，あるいは外場によって粒子が十分に閉じ込められ，粒子数の積分が収束するものとする．
変分はこの領域内で行い，粒子数の拘束条件

```math
\int_\Omega \delta n(\boldsymbol r)\,d\boldsymbol r=0
```

を満たすものとする．

### 2．位置エネルギーの変分

与えられた位置エネルギーは

```math
\begin{aligned}
U={}&
\frac{e^2}{2}
\iint_{\Omega}
\frac{
n(\boldsymbol r)n(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r\,d\boldsymbol r'
\\
&+
e\int_\Omega
n(\boldsymbol r)\varphi_{\mathrm{ext}}(\boldsymbol r)
\,d\boldsymbol r
\end{aligned}
```

である．

まず，クーロン相互作用の項を変分する．
$n(\boldsymbol r)$ を $n(\boldsymbol r)+\delta n(\boldsymbol r)$ に変化させたとき，一次の変分は

```math
\begin{aligned}
\delta U_{\mathrm{int}}
={}&
\frac{e^2}{2}
\iint_\Omega
\frac{
\delta n(\boldsymbol r)n(\boldsymbol r')
+n(\boldsymbol r)\delta n(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r\,d\boldsymbol r'
\end{aligned}
```

となる．

ここで，積分変数 $\boldsymbol r$ と $\boldsymbol r'$ を入れ替えても積分値は変わらない．
実際，

```math
|\boldsymbol r-\boldsymbol r'|
=
|\boldsymbol r'-\boldsymbol r|
```

であるため，右辺の二つの項は等しい．
したがって，

```math
\begin{aligned}
\delta U_{\mathrm{int}}
&=
e^2
\iint_\Omega
\frac{
n(\boldsymbol r')\delta n(\boldsymbol r)
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r\,d\boldsymbol r'
\\
&=
e^2\int_\Omega
\left[
\int_\Omega
\frac{
n(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r'
\right]
\delta n(\boldsymbol r)\,d\boldsymbol r
\end{aligned}
```

を得る．

次に，外場による位置エネルギーの変分は

```math
\delta U_{\mathrm{ext}}
=
e\int_\Omega
\varphi_{\mathrm{ext}}(\boldsymbol r)
\delta n(\boldsymbol r)\,d\boldsymbol r
```

である．

以上をまとめると，

```math
\begin{aligned}
\delta U
=
\int_\Omega
\Bigg[
&e^2\int_\Omega
\frac{
n(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r'
\\
&+e\varphi_{\mathrm{ext}}(\boldsymbol r)
\Bigg]
\delta n(\boldsymbol r)\,d\boldsymbol r
\end{aligned}
\tag{2}
```

となる．

### 3．エントロピーの変分

エントロピーは

```math
S=-k\int_\Omega
n(\boldsymbol r)
\left\{
\log\frac{n(\boldsymbol r)}{n_*}-1
\right\}
\,d\boldsymbol r
```

である．

被積分関数について，

```math
\frac{d}{dn}
\left[
n\left\{
\log\frac{n}{n_*}-1
\right\}
\right]
=
\log\frac{n}{n_*}
```

が成立する．

したがって，エントロピーの変分は

```math
\delta S
=
-k\int_\Omega
\log\frac{n(\boldsymbol r)}{n_*}
\delta n(\boldsymbol r)\,d\boldsymbol r
\tag{3}
```

となる．

また，全粒子数の変分は

```math
\delta N
=
\int_\Omega
\delta n(\boldsymbol r)\,d\boldsymbol r
\tag{4}
```

である．

### 4．平衡状態における数密度の方程式

式 (1) に

```math
\delta F=\delta U-T\delta S
```

および式 (2)～(4) を代入すると，

```math
\begin{aligned}
0
=
\int_\Omega
\Bigg[
&e^2\int_\Omega
\frac{
n(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r'
\\
&+e\varphi_{\mathrm{ext}}(\boldsymbol r)
+kT\log\frac{n(\boldsymbol r)}{n_*}
-\mu
\Bigg]
\delta n(\boldsymbol r)\,d\boldsymbol r
\end{aligned}
```

となる．

ここで，ラグランジュ未定乗数を導入した後は， $\delta n(\boldsymbol r)$ を領域内で任意に選ぶことができる．
したがって，積分の被積分関数は各点でゼロでなければならない．

よって，

```math
\boxed{
kT\log\frac{n(\boldsymbol r)}{n_*}
+
e^2\int_\Omega
\frac{
n(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r'
+
e\varphi_{\mathrm{ext}}(\boldsymbol r)
-\mu
=0
}
\tag{5}
```

を得る．

これが平衡状態における数密度の満たす方程式である．

### 5．静電ポテンシャルを用いた表現

問題文のクーロン相互作用の係数は，ガウス単位系に対応している．
この単位系では，粒子の電荷分布が作るポテンシャルは

```math
\varphi_{\mathrm{self}}(\boldsymbol r)
=
e\int_\Omega
\frac{
n(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r'
```

で与えられる．

したがって，全静電ポテンシャルを

```math
\boxed{
\varphi(\boldsymbol r)
=
\varphi_{\mathrm{ext}}(\boldsymbol r)
+
e\int_\Omega
\frac{
n(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r'
}
\tag{6}
```

と定義する．

式 (6) より，

```math
e\varphi(\boldsymbol r)
=
e\varphi_{\mathrm{ext}}(\boldsymbol r)
+
e^2\int_\Omega
\frac{
n(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r'
```

である．

これを式 (5) に代入すると，

```math
kT\log\frac{n(\boldsymbol r)}{n_*}
+
e\varphi(\boldsymbol r)-\mu=0
```

となる．

これを $n(\boldsymbol r)$ について解くと，

```math
\boxed{
n(\boldsymbol r)
=
n_*
\exp\left[
\frac{
\mu-e\varphi(\boldsymbol r)
}{
kT
}
\right]
}
\tag{7}
```

を得る．

これが平衡状態におけるボルツマン分布である．

また，全粒子数の規格化条件は

```math
\boxed{
N=
n_*\int_\Omega
\exp\left[
\frac{
\mu-e\varphi(\boldsymbol r)
}{
kT
}
\right]
\,d\boldsymbol r
}
\tag{8}
```

となる．

したがって， $\mu$ は数密度と静電ポテンシャルの自己無撞着な関係を考慮したうえで，全粒子数 $N$ によって決定される．

なお，任意の基準ポテンシャル $\varphi_{\mathrm{ref}}$ を選び，

```math
n_{\mathrm{ref}}
=
n_*
\exp\left[
\frac{
\mu-e\varphi_{\mathrm{ref}}
}{
kT
}
\right]
```

と定義すると，式 (7) は

```math
\boxed{
n(\boldsymbol r)
=
n_{\mathrm{ref}}
\exp\left[
-\frac{
e\{\varphi(\boldsymbol r)-\varphi_{\mathrm{ref}}\}
}{
kT
}
\right]
}
\tag{9}
```

と書ける．

特に，ポテンシャルの基準を $\varphi_{\mathrm{ref}}=0$ と選べば，

```math
n_0=n_*\exp\left(\frac{\mu}{kT}\right)
```

として，

```math
\boxed{
n(\boldsymbol r)
=
n_0
\exp\left[
-\frac{
e\varphi(\boldsymbol r)
}{
kT
}
\right]
}
\tag{10}
```

となる．

ここで， $n_0$ は数密度の次元を持つ．
また，ポテンシャルの零点の選択に依存するため，ゲージを指定せずに絶対的な物理量として扱うことはできない．

実際，ポテンシャルに定数 $C$ を加えて

```math
\varphi\longrightarrow\varphi+C
```

とする場合，化学ポテンシャルを

```math
\mu\longrightarrow\mu+eC
```

と変換すれば，数密度は不変である．

### 6．静電ポテンシャルの積分方程式

式 (6) に式 (7) を代入すると，

```math
\boxed{
\begin{aligned}
\varphi(\boldsymbol r)
={}&
\varphi_{\mathrm{ext}}(\boldsymbol r)
\\
&+
e n_*
\int_\Omega
\frac{
\exp\left[
\dfrac{
\mu-e\varphi(\boldsymbol r')
}{
kT
}
\right]
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r'
\end{aligned}
}
\tag{11}
```

を得る．

これが静電ポテンシャルの満たす積分方程式である．

式 (7) と式 (11) は相互に依存している．
ポテンシャルが数密度を決め，数密度が電荷分布を通してポテンシャルを決めるため，両式を同時に解く必要がある．

### 7．ポアソン・ボルツマン方程式

さらに，静電ポテンシャルの微分方程式を導く．

三次元自由空間では，

```math
\nabla^2
\frac{1}{
|\boldsymbol r-\boldsymbol r'|
}
=
-4\pi
\delta^{(3)}(\boldsymbol r-\boldsymbol r')
```

が成立する．

これを式 (6) に適用すると，

```math
\begin{aligned}
\nabla^2\varphi(\boldsymbol r)
={}&
\nabla^2\varphi_{\mathrm{ext}}(\boldsymbol r)
\\
&+
e\int_\Omega
n(\boldsymbol r')
\nabla^2
\frac{
1
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r'
\end{aligned}
```

となる．

デルタ関数の性質を用いれば，

```math
\boxed{
\nabla^2\varphi(\boldsymbol r)
=
\nabla^2\varphi_{\mathrm{ext}}(\boldsymbol r)
-
4\pi e n(\boldsymbol r)
}
\tag{12}
```

を得る．

ここに式 (7) を代入すると，

```math
\boxed{
\begin{aligned}
\nabla^2\varphi(\boldsymbol r)
={}&
\nabla^2\varphi_{\mathrm{ext}}(\boldsymbol r)
\\
&-
4\pi e n_*
\exp\left[
\frac{
\mu-e\varphi(\boldsymbol r)
}{
kT
}
\right]
\end{aligned}
}
\tag{13}
```

となる．

これが本系のポアソン・ボルツマン方程式である．

外場が領域内に電荷源を持たず，

```math
\nabla^2\varphi_{\mathrm{ext}}=0
```

である場合には，

```math
\boxed{
\nabla^2\varphi(\boldsymbol r)
=
-4\pi e n_*
\exp\left[
\frac{
\mu-e\varphi(\boldsymbol r)
}{
kT
}
\right]
}
\tag{14}
```

となる．

また，外場が電荷密度 $\rho_{\mathrm{ext}}$ によって生成される場合には，

```math
\nabla^2\varphi_{\mathrm{ext}}
=
-4\pi\rho_{\mathrm{ext}}
```

であるため，

```math
\boxed{
\nabla^2\varphi
=
-4\pi
\left[
\rho_{\mathrm{ext}}
+
e n_*
\exp\left(
\frac{\mu-e\varphi}{kT}
\right)
\right]
}
\tag{15}
```

と表せる．

### 8．境界条件と粒子数の有限性

式 (6) および式 (11) のクーロン核

```math
\frac{1}{|\boldsymbol r-\boldsymbol r'|}
```

は，三次元自由空間のグリーン関数である．

したがって，ここでは粒子の電荷分布が作るポテンシャルについて，

```math
\varphi_{\mathrm{self}}(\boldsymbol r)
\longrightarrow 0
\qquad
(|\boldsymbol r|\longrightarrow\infty)
```

という境界条件を採用している．

粒子が有限領域 $\Omega$ に閉じ込められる場合には，

```math
n(\boldsymbol r)=0
\qquad
(\boldsymbol r\notin\Omega)
```

とし，粒子の電荷分布が作るポテンシャルは自由空間全体で計算する．

ただし，境界が導体壁などであり，その影響によって電場が変化する場合には，自由空間のクーロン核をそのまま使用することはできない．
その場合には，実際の境界条件を満たすグリーン関数に置き換える必要がある．

また，無限空間で外場が存在しない場合，

```math
\varphi_{\mathrm{ext}}=0
```

とすると，有限の粒子数を持つ非自明な局在平衡分布は一般には存在しない．

実際，有限の全粒子数 $N$ を持つ分布であれば，十分遠方では，

```math
\varphi(\boldsymbol r)\longrightarrow0
```

となる．
したがって，式 (7) より，

```math
n(\boldsymbol r)
\longrightarrow
n_*\exp\left(\frac{\mu}{kT}\right)
```

となる．

有限の $\mu$ であれば，この値は正であるため，

```math
\int_{\mathbb R^3}n(\boldsymbol r)\,d\boldsymbol r
```

は発散してしまう．

したがって，有限粒子数の平衡状態を得るためには，有限領域への閉じ込め，あるいは十分に強い外場による閉じ込めなどが必要である．

例えば，無限領域の場合には，外場によるボルツマン因子が十分速く減衰し，

```math
\int_{\mathbb R^3}
\exp\left[
-\frac{
e\varphi_{\mathrm{ext}}(\boldsymbol r)
}{
kT
}
\right]
d\boldsymbol r
```

が収束することが，粒子数の有限性を確保するための一つの重要な条件となる．

### 9．自由エネルギーの最小性の確認

ここまでの変分計算から得られた条件は，一階変分がゼロとなる停留条件である．
停留条件が自由エネルギーの最小条件に対応することを確認するため，二次変分を調べる．

変分方向を $\eta(\boldsymbol r)$ とし，

```math
\int_\Omega\eta(\boldsymbol r)\,d\boldsymbol r=0
```

を満たすものとする．

このとき，

```math
\begin{aligned}
\delta^2(F-\mu N)
={}&
kT\int_\Omega
\frac{
\eta(\boldsymbol r)^2
}{
n(\boldsymbol r)
}
\,d\boldsymbol r
\\
&+
e^2
\iint_\Omega
\frac{
\eta(\boldsymbol r)\eta(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r\,d\boldsymbol r'
\end{aligned}
\tag{16}
```

となる．

第一項は，

```math
kT>0
```

および

```math
n(\boldsymbol r)>0
```

より，非負である．

次に，第二項について，

```math
\psi_\eta(\boldsymbol r)
=
\int_\Omega
\frac{
\eta(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r'
```

と定義する．

自由空間のポアソン方程式より，

```math
\nabla^2\psi_\eta(\boldsymbol r)
=
-4\pi\eta(\boldsymbol r)
```

である．

十分な減衰条件のもとで部分積分すると，

```math
\begin{aligned}
\iint_\Omega
\frac{
\eta(\boldsymbol r)\eta(\boldsymbol r')
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r\,d\boldsymbol r'
&=
\int_\Omega
\eta(\boldsymbol r)\psi_\eta(\boldsymbol r)
\,d\boldsymbol r
\\
&=
\frac{1}{4\pi}
\int_{\mathbb R^3}
|\nabla\psi_\eta(\boldsymbol r)|^2
\,d\boldsymbol r
\\
&\geq 0
\end{aligned}
```

となる．

したがって，式 (16) は非負であり，非零の変分方向に対して第一項が正となる．

よって，この自由エネルギー汎関数は許容される密度分布の集合上で厳密に凸である．

したがって，適切な条件のもとで解が存在すれば，停留解は自由エネルギーの唯一の大域的最小解となる．

### 10．結論

以上より，平衡状態における数密度は，

```math
\boxed{
n(\boldsymbol r)
=
n_*
\exp\left[
\frac{
\mu-e\varphi(\boldsymbol r)
}{
kT
}
\right]
}
```

を満たす．

また，静電ポテンシャルは，

```math
\boxed{
\begin{aligned}
\varphi(\boldsymbol r)
={}&
\varphi_{\mathrm{ext}}(\boldsymbol r)
\\
&+
e n_*
\int_\Omega
\frac{
\exp\left[
\dfrac{
\mu-e\varphi(\boldsymbol r')
}{
kT
}
\right]
}{
|\boldsymbol r-\boldsymbol r'|
}
\,d\boldsymbol r'
\end{aligned}
}
```

という積分方程式を満たす．

さらに，その微分方程式は，

```math
\boxed{
\nabla^2\varphi
=
\nabla^2\varphi_{\mathrm{ext}}
-
4\pi e n_*
\exp\left[
\frac{
\mu-e\varphi
}{
kT
}
\right]
}
```

で与えられる．

これらの式は，数密度と静電ポテンシャルが互いに影響を及ぼす自己無撞着な関係を表している．

したがって，外場，温度，粒子数，空間領域および境界条件を指定し，数密度の規格化条件とポアソン・ボルツマン方程式を同時に満たす解を求めることで，平衡状態が定まる．

なお，この結論は問題文で与えられた古典的平均場汎関数の範囲内で成立するものであり，粒子間相関や量子統計による補正は含んでいない．
