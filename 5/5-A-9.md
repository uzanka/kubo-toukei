# 演習問題【5-A-9】

## 解答

### (i) 分子数 $n$ の確率分布 $f(n)$

体積 $V$ の箱に $N$ 個の分子があり，そのうち体積 $v$ の領域にある分子の数を $n$ とする．
平衡状態では，1個の分子がこの領域に見出される確率は

```math
p=\frac{v}{V}
```

である．
したがって，分子が領域 $v$ の外側に見出される確率は

```math
1-p=1-\frac{v}{V}
```

である．

各分子の位置が互いに独立であるとする．このとき，特定の $n$ 個の分子が領域 $v$ に入り，残りの $N-n$ 個がその外側に入る確率は

```math
p^n(1-p)^{N-n}
```

である．
ただし，領域 $v$ に入る $n$ 個の分子の選び方は

```math
\binom{N}{n}=\frac{N!}{n!(N-n)!}
```

通りある．
これらの組合せは互いに重複しないため，求める確率分布は

```math
f(n)=\binom{N}{n}p^n(1-p)^{N-n}
```

となる．
よって，

```math
\boxed{
f(n)=\frac{N!}{n!(N-n)!}
\left(\frac{v}{V}\right)^n
\left(1-\frac{v}{V}\right)^{N-n}
}
```

である．
ここで $n=0,1,\ldots,N$ である．
これは二項分布である．

### (ii) 平均値 $\bar n$ と分散 $\overline{(n-\bar n)^2}$

#### 1．母関数の導入

確率分布 $f(n)$ の母関数 $F(x)$ を

```math
F(x)=\sum_{n=0}^{N}f(n)x^n
```

と定義する．
（i）で求めた二項分布を代入すると，

```math
F(x)=\sum_{n=0}^{N}
\binom{N}{n}(px)^n(1-p)^{N-n}
```

となる．
二項定理

```math
(a+b)^N=\sum_{n=0}^{N}\binom{N}{n}a^n b^{N-n}
```

を用いれば，

```math
\boxed{
F(x)=(1-p+px)^N
}
```

を得る．
特に $F(1)=1$ であり，確率分布が規格化されていることも確認できる．

#### 2．平均値 $\bar n$

母関数を1回微分すると，

```math
F'(x)=Np(1-p+px)^{N-1}
```

となる．
一方，母関数の定義から

```math
F'(x)=\sum_{n=1}^{N}nf(n)x^{n-1}
```

であるため， $x=1$ とおけば，

```math
\bar n=\sum_{n=0}^{N}nf(n)=F'(1)
```

が得られる．
したがって，

```math
\boxed{
\bar n=Np=\frac{Nv}{V}
}
```

である．

#### 3．分散 $\overline{(n-\bar n)^2}$

母関数をもう1回微分すると，

```math
F''(x)=N(N-1)p^2(1-p+px)^{N-2}
```

となる．
定義より，

```math
F''(1)=\sum_{n=0}^{N}n(n-1)f(n)
```

であるため，

```math
\overline{n(n-1)}=N(N-1)p^2
```

を得る．

ここで，

```math
n^2=n(n-1)+n
```

であるから，

```math
\begin{aligned}
\overline{(n-\bar n)^2}
&=\overline{n^2}-\bar n^2\\
&=\overline{n(n-1)}+\bar n-\bar n^2\\
&=N(N-1)p^2+Np-(Np)^2\\
&=Np(1-p)
\end{aligned}
```

となる．
よって，

```math
\boxed{
\overline{(n-\bar n)^2}
=Np(1-p)
=\frac{Nv}{V}\left(1-\frac{v}{V}\right)
}
```

である．

### (iii) Stirling の公式による Gauss 分布への近似

$N$ ， $\bar n=Np$ ，および $N-\bar n=N(1-p)$ が十分に大きい場合を考える．
この条件のもとで Stirling の公式

```math
\log k!\simeq k\log k-k
```

を用い，二項分布の対数を近似する．

#### 1．対数確率の近似

二項分布

```math
f(n)=\frac{N!}{n!(N-n)!}p^n(1-p)^{N-n}
```

の対数を取ると，

```math
\begin{aligned}
\log f(n)
={}&\log N!-\log n!-\log(N-n)!\\
&+n\log p+(N-n)\log(1-p)
\end{aligned}
```

である．
Stirling の公式を適用すると，

```math
\begin{aligned}
\log f(n)\simeq{}&
N\log N-n\log n\\
&-(N-n)\log(N-n)\\
&+n\log p+(N-n)\log(1-p)
\end{aligned}
```

となる．
右辺を $\phi(n)$ とおく．

#### 2．最大点を求める

$\phi(n)$ を $n$ で微分すると，

```math
\phi'(n)
=-\log\frac{n}{N-n}+\log\frac{p}{1-p}
```

である．
最大点 $n^*$ は $\phi'(n^*)=0$ を満たすため，

```math
\frac{n^*}{N-n^*}=\frac{p}{1-p}
```

となる．
これを整理すると，

```math
n^*(1-p)=p(N-n^*)
```

したがって，

```math
\boxed{
n^*=Np=\bar n
}
```

を得る．
これは Stirling 近似した対数確率の最大点であり，二項分布の厳密な最頻値と必ずしも一致するわけではない．

#### 3．最大点の近傍で Taylor 展開する

2階微分は

```math
\phi''(n)=-\frac1n-\frac1{N-n}
```

である．
したがって，

```math
\begin{aligned}
\phi''(n^*)
&=-\frac1{Np}-\frac1{N(1-p)}\\
&=-\frac1{Np(1-p)}
\end{aligned}
```

となる．
最大点の近傍で2次まで Taylor 展開すると，

```math
\phi(n)\simeq
\phi(n^*)+\frac12\phi''(n^*)(n-n^*)^2
```

であるから，

```math
\phi(n)\simeq
\phi(n^*)-\frac{(n-n^*)^2}{2Np(1-p)}
```

を得る．
よって，確率は最大点の近傍で

```math
f(n)\propto
\exp\left[
-\frac{(n-Np)^2}{2Np(1-p)}
\right]
```

となる．

ここで，（ii）で求めた分散

```math
\Delta^2=Np(1-p)
```

を用いれば，

```math
f(n)\propto
\exp\left[-\frac{(n-\bar n)^2}{2\Delta^2}\right]
```

と表される．
規格化係数も含めた近似式は，

```math
\boxed{
f(n)\simeq
\frac{1}{\sqrt{2\pi Np(1-p)}}
\exp\left[
-\frac{(n-Np)^2}{2Np(1-p)}
\right]
}
```

である．
この近似式は，整数 $n$ に対する二項分布を，平均値 $Np$ ，分散 $Np(1-p)$ の Gauss 分布で近似したものである．

### (iv) Poisson 分布への近似

ここでは，

```math
p=\frac{v}{V}\to0,\qquad
N\to\infty,\qquad
Np=\bar n
```

を有限の値に保つ極限を考える．
この条件は， $N/V$ を一定に保ちながら $V\to\infty$ とし，部分領域 $v$ の体積を一定に保つ場合に満たされる．

#### 1．母関数の極限

（ii）で求めた母関数は

```math
F(x)=(1-p+px)^N
=\{1+p(x-1)\}^N
```

である．
ここで $p=\bar n/N$ と書けば，

```math
F(x)=\left\{
1+\frac{\bar n(x-1)}{N}
\right\}^{N}
```

となる．
極限公式

```math
\lim_{N\to\infty}
\left(1+\frac{a}{N}\right)^N=e^a
```

を用いると，

```math
\begin{aligned}
\lim_{N\to\infty}F(x)
&=\exp\{\bar n(x-1)\}\\
&=e^{-\bar n}e^{\bar n x}
\end{aligned}
```

を得る．

#### 2．展開係数から確率分布を求める

指数関数 $e^{\bar n x}$ を級数展開すると，

```math
e^{\bar n x}
=\sum_{n=0}^{\infty}\frac{\bar n^n}{n!}x^n
```

である．
したがって，

```math
\begin{aligned}
\lim_{N\to\infty}F(x)
&=e^{-\bar n}\sum_{n=0}^{\infty}
\frac{\bar n^n}{n!}x^n\\
&=\sum_{n=0}^{\infty}
\frac{e^{-\bar n}\bar n^n}{n!}x^n
\end{aligned}
```

となる．
一方，母関数の定義は

```math
F(x)=\sum_{n=0}^{N}f(n)x^n
```

であるため， $x$ の各次数の係数を比較すれば，

```math
\boxed{
f(n)=e^{-\bar n}\frac{\bar n^n}{n!},
\qquad n=0,1,2,\ldots
}
```

を得る．
これは Poisson 分布である．

以上より，分子数の分布は一般には二項分布であるが，領域 $v$ に分子が入る確率が小さく，分子数 $N$ が十分に大きく，平均粒子数 $\bar n=Nv/V$ が有限に保たれる極限では Poisson 分布に近づくことが示された．
