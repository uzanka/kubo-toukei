# 演習問題【5-A-9】

## 解答

### (i) 分子数 $n$ の確率分布 $f(n)$ の導出

この問題は，「$N$ 個の試行（分子）のうち，特定の条件（体積 $v$ の中にいる）を満たすものが $n$ 個ある確率」を求める問題であり，これは**二項分布**の形になる．

1.  **1つの分子が体積 $v$ の中に入る確率 $p$**:
    系が平衡状態にあるとき，分子は体積 $V$ の中を一様に分布していると考えられる．
    したがって，ある1つの分子が特定の体積 $v$ の中に存在する確率は，体積の比に等しくなる．
    $$p = \frac{v}{V}$$
    同様に，その外側（体積 $V-v$ の中）に存在する確率は $1-p$ である．

2.  **$n$ 個の分子が体積 $v$ に入る組み合わせ**:
    $N$ 個の分子のうち，どの $n$ 個が体積 $v$ の中に入るかという組み合わせの数は，コンビネーション（組合せ）の公式を用いて次のように表される．
    $$\binom{N}{n} = \frac{N!}{n!(N-n)!}$$

3.  **全体の確率 $f(n)$**:
    各分子の挙動は独立であると仮定するため，全体の確率は「組み合わせの数」に「各分子が特定の領域にいる確率」を掛け合わせたものになる．
    - $n$ 個の分子が $v$ に入る確率: $p^n$
    - 残りの $N-n$ 個の分子が $V-v$ に入る確率: $(1-p)^{N-n}$

    これらをまとめると，求める確率分布 $f(n)$ は以下のようになる．
    $$f(n) = \frac{N!}{n!(N-n)!} p^n (1-p)^{N-n}$$

---

### (ii) 平均 $\bar{n}$ と分散 $\overline{(n-\bar{n})^2}$ の計算

統計学において，確率分布のモーメント（平均や分散など）を計算する際，**母関数（生成関数）**を用いると非常に効率的である．

1.  **母関数の定義**:
    確率分布 $f(n)$ に対する母関数 $F(x)$ を次のように定義する．
    $$F(x) = \sum_{n=0}^{N} f(n) x^n$$
    これに (i) の結果を代入すると，
    $$F(x) = \sum_{n=0}^{N} \frac{N!}{n!(N-n)!} p^n (1-p)^{N-n} x^n = \sum_{n=0}^{N} \frac{N!}{n!(N-n)!} (px)^n (1-p)^{N-n}$$
    これは二項定理 $(a+b)^N = \sum_{n=0}^{N} \binom{N}{n} a^n b^{N-n}$ の形そのものであり， $a=px, b=1-p$ とおくと，
    $$F(x) = (px + 1 - p)^N = (1 - p + px)^N$$
    となる．

2.  **平均 $\bar{n}$ の計算**:
    期待値（平均） $\bar{n} = \sum n f(n)$ は，母関数の $x=1$ における1階微分で求められる．
    $$\bar{n} = \left. \frac{d}{dx} F(x) \right|_{x=1}$$
    $F(x)$ を $x$ で微分すると，
    $$\frac{d}{dx} F(x) = N(1 - p + px)^{N-1} \cdot p$$
    $x=1$ を代入すると，
    $$\bar{n} = N(1 - p + p)^{N-1} \cdot p = Np$$
    $p = v/V$ なので， $\bar{n} = \frac{Nv}{V}$ である．

3.  **分散 $\overline{(n-\bar{n})^2}$ の計算**:
    分散は $\overline{(n-\bar{n})^2} = \overline{n^2} - \bar{n}^2$ であるが，直接 $n^2$ を計算するより，**階乗モーメント** $\overline{n(n-1)}$ を利用するのが簡単である．
    $$\overline{n(n-1)} = \sum n(n-1) f(n) = \left. \frac{d^2}{dx^2} F(x) \right|_{x=1}$$
    $F(x)$ をもう一度微分すると，
    $$\frac{d^2}{dx^2} F(x) = \frac{d}{dx} [Np(1-p+px)^{N-1}] = N(N-1)p^2(1-p+px)^{N-2}$$
    $x=1$ を代入すると，
    $$\overline{n(n-1)} = N(N-1)p^2$$

    ここで，分散の公式の変形を利用する．
    $$\overline{(n-\bar{n})^2} = \overline{n^2} - \bar{n}^2 = \overline{n(n-1) + n} - \bar{n}^2 = \overline{n(n-1)} + \bar{n} - \bar{n}^2$$
    これに求めた値を代入すると，
    $$\overline{(n-\bar{n})^2} = N(N-1)p^2 + Np - (Np)^2$$
    $$= N^2p^2 - Np^2 + Np - N^2p^2 = Np - Np^2 = Np(1-p)$$
    $p = v/V$ を代入して整理すると，
    $$\overline{(n-\bar{n})^2} = N \frac{v}{V} \left( 1 - \frac{v}{V} \right)$$

### (iii) ガウス分布（正規分布）への近似

$N$ および $\bar{n}$ が十分に大きいとき，二項分布はガウス分布に近似できる．
これを示すために **Stirling の公式**（ $\log N! \approx N \log N - N$ ）を用いる．

1.  **$\log f(n)$ の近似**:
    $f(n)$ の対数を取る．
    $$\log f(n) = \log N! - \log n! - \log(N-n)! + n \log p + (N-n) \log(1-p)$$
    Stirling の公式を各項に適用すると，
    $$\log f(n) \approx (N \log N - N) - (n \log n - n) - ((N-n) \log(N-n) - (N-n)) + n \log p + (N-n) \log(1-p)$$
    $$-N + n + (N-n) = 0$$ となるため，
    $$\log f(n) \approx N \log N - n \log n - (N-n) \log(N-n) + n \log p + (N-n) \log(1-p) \equiv \phi(n)$$

2.  **最大値 $n^*$ の決定**:
    $f(n)$ が最大となる $n$ は， $\phi(n)$ が最大となる $n$ である．
    $\phi'(n) = 0$ を解く．
    $$\phi'(n) = -\log n - 1 - (-1) \log(N-n) - (-1) + \log p - \log(1-p) = -\log \frac{n}{N-n} + \log \frac{p}{1-p} = 0$$
    $$\log \frac{n}{N-n} = \log \frac{p}{1-p} \implies \frac{n}{N-n} = \frac{p}{1-p} \implies n(1-p) = p(N-n) \implies n = Np$$
    よって，最大値は $n^* = \bar{n} = Np$ である．

3.  **$n^*$ 付近でのテイラー展開**:
    $\phi(n)$ を $n^*$ のまわりで2次まで展開する．
    $$\phi(n) \approx \phi(n^*) + \frac{1}{2} \phi''(n^*) (n-n^*)^2$$
    $\phi'(n) = -\log n + \log(N-n) + \log p - \log(1-p)$ なので，
    $$\phi''(n) = -\frac{1}{n} - \frac{1}{N-n}$$
    $n = n^* = Np$ を代入すると，
    $$\phi''(n^*) = -\left( \frac{1}{Np} + \frac{1}{N-Np} \right) = -\left( \frac{1}{Np} + \frac{1}{N(1-p)} \right) = -\frac{(1-p) + p}{Np(1-p)} = -\frac{1}{Np(1-p)}$$
    分散を $\Delta^2 = Np(1-p)$ とおくと， $\phi''(n^*) = -1/\Delta^2$ である．
    したがって，
    $$\phi(n) \approx \phi(n^*) - \frac{1}{2\Delta^2}(n-n^*)^2$$
    これを指数関数に戻すと，
    $$f(n) = \exp(\phi(n)) \propto \exp \left[ -\frac{1}{2\Delta^2} (n-n^*)^2 \right]$$
    これはガウス分布の形をしている．

### (iv) ポアソン分布への近似

$v/V \to 0$ かつ $V \to \infty$ で $N/V = \text{一定}$ という極限を考える．
このとき， $\bar{n} = N(v/V)$ は有限の定数となる．

1.  **母関数の極限**:
    母関数 $F(x) = (1 - p + px)^N$ について考える．
    $p = v/V$ なので，
    $$F(x) = (1 - p(1-x))^N$$
    ここで， $\bar{n} = Np$ より $p = \bar{n}/N$ である．
    これを代入すると，
    $$F(x) = \left( 1 - \frac{\bar{n}(1-x)}{N} \right)^N$$
    $N \to \infty$ の極限では，定義 $\lim_{N \to \infty} (1 + \frac{a}{N})^N = e^a$ を用いて，
    $$\lim_{N \to \infty} F(x) = \exp [ -\bar{n}(1-x) ] = e^{-\bar{n}} e^{\bar{n}x}$$

2.  **展開係数の比較**:
    $e^{\bar{n}x}$ を $x$ についてテイラー展開すると，
    $$e^{\bar{n}x} = \sum_{n=0}^{\infty} \frac{(\bar{n}x)^n}{n!} = \sum_{n=0}^{\infty} \frac{(\bar{n})^n}{n!} x^n$$
    したがって，
    $$\lim_{N \to \infty} F(x) = e^{-\bar{n}} \sum_{n=0}^{\infty} \frac{(\bar{n})^n}{n!} x^n = \sum_{n=0}^{\infty} \left( \frac{(\bar{n})^n e^{-\bar{n}}}{n!} \right) x^n$$
    母関数の定義 $F(x) = \sum f(n) x^n$ と比較すると，
    $$\lim_{N \to \infty} f(n) = \frac{(\bar{n})^n e^{-\bar{n}}}{n!}$$
    これはポアソン分布の確率質量関数である．
