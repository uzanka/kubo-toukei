# 演習問題【5-A-9】

## 解答

### （i）分子数 $n$ の確率分布 $f(n)$

体積 $V$ の箱に $N$ 個の分子があり，そのうち体積 $v$ の領域にある分子の数を $n$ とする．
平衡状態では，1個の分子が領域 $v$ に見出される確率は

```math
p=\frac{v}{V}
```

である．
したがって，領域 $v$ の外側に見出される確率は $1-p$ である．

各分子の位置が互いに独立であると仮定する．
このとき，特定の $n$ 個の分子が領域 $v$ に入り，残りの $N-n$ 個がその外側に入る確率は

```math
p^n(1-p)^{N-n}
```

である．
領域 $v$ に入る $n$ 個の分子の選び方は

```math
\binom{N}{n}=\frac{N!}{n!(N-n)!}
```

通りある．
これらの組合せは互いに排反であるから，求める確率分布は

```math
f(n)=\binom{N}{n}p^n(1-p)^{N-n}
```

となる．
よって，

```math
\boxed{
f(n)=\frac{N!}{n!(N-n)!}
\left(\frac{v}{V}\right)^n
\left(1-\frac{v}{V}\right)^{N-n}
}
```

である．
ただし，

```math
n=0,1,\ldots,N
```

である．
これは二項分布である．

### （ii）平均値 $\bar n$ と分散 $\overline{(n-\bar n)^2}$

#### 1．母関数の導入

確率分布 $f(n)$ の母関数 $F(x)$ を

```math
F(x)=\sum_{n=0}^{N}f(n)x^n
```

と定義する．
（i）で求めた二項分布を代入すると，

```math
F(x)=\sum_{n=0}^{N}
\binom{N}{n}(px)^n(1-p)^{N-n}
```

となる．
二項定理より，

```math
\boxed{
F(x)=(1-p+px)^N
}
```

を得る．
特に $F(1)=1$ であり，確率分布が規格化されていることが分かる．

#### 2．平均値 $\bar n$

母関数を1回微分すると，

```math
F'(x)=Np(1-p+px)^{N-1}
```

となる．
一方，母関数の定義から，

```math
F'(x)=\sum_{n=1}^{N}nf(n)x^{n-1}
```

である．
したがって，

```math
\bar n=\sum_{n=0}^{N}nf(n)=F'(1)
```

より，

```math
\boxed{
\bar n=Np=\frac{Nv}{V}
}
```

を得る．

#### 3．分散 $\overline{(n-\bar n)^2}$

母関数をもう1回微分すると，

```math
F''(x)=N(N-1)p^2(1-p+px)^{N-2}
```

となる．
したがって，

```math
F''(1)=\sum_{n=0}^{N}n(n-1)f(n)
```

より，

```math
\overline{n(n-1)}=N(N-1)p^2
```

である．
ここで，

```math
n^2=n(n-1)+n
```

を用いると，

```math
\begin{aligned}
\overline{(n-\bar n)^2}
&=\overline{n^2}-\bar n^2\\
&=\overline{n(n-1)}+\bar n-\bar n^2\\
&=N(N-1)p^2+Np-(Np)^2\\
&=Np(1-p)
\end{aligned}
```

となる．
よって，

```math
\boxed{
\overline{(n-\bar n)^2}
=Np(1-p)
=\frac{Nv}{V}\left(1-\frac{v}{V}\right)
}
```

である．

### （iii）Stirling の公式による Gauss 分布への近似

```math
\bar n=Np,\qquad N-\bar n=N(1-p)
```

とする．
ここでは，

```math
Np\gg1,\qquad N(1-p)\gg1
```

を仮定する．
この条件のもとでは，分布の中心付近において Stirling の公式を適用できる．

#### 1．対数確率の近似

二項分布の対数は，

```math
\begin{aligned}
\log f(n)
={}&\log N!-\log n!-\log(N-n)!\\
&+n\log p+(N-n)\log(1-p)
\end{aligned}
```

である．
規格化係数まで求めるため，Stirling の公式を補正項まで含めて

```math
\log k!
=
\left(k+\frac12\right)\log k-k
+\frac12\log(2\pi)
+O\left(\frac1k\right)
```

とする．
これを $N!,n!,(N-n)!$ に適用すると，

```math
\begin{aligned}
\log f(n)
\simeq{}&
N\log N-n\log n\\
&-(N-n)\log(N-n)\\
&+n\log p+(N-n)\log(1-p)\\
&+\frac12\log\frac{N}{2\pi n(N-n)}
\end{aligned}
```

を得る．
ここで，指数部分を

```math
\phi(n)=
N\log N-n\log n
-(N-n)\log(N-n)
+n\log p+(N-n)\log(1-p)
```

とおく．
したがって，

```math
\log f(n)
\simeq
\phi(n)+\frac12\log\frac{N}{2\pi n(N-n)}
```

である．

#### 2．指数部分の最大点

$\phi(n)$ を微分すると，

```math
\phi'(n)
=
-\log\frac{n}{N-n}
+\log\frac{p}{1-p}
```

となる．
最大点 $n^*$ は $\phi'(n^*)=0$ を満たすから，

```math
\frac{n^*}{N-n^*}=\frac{p}{1-p}
```

である．
これを整理すると，

```math
\boxed{n^*=Np=\bar n}
```

を得る．

なお，これは Stirling 近似した指数部分の最大点である．
二項分布の厳密な最頻値は一般に $\lfloor(N+1)p\rfloor$ であり，必ずしも $Np$ と一致するわけではない．

#### 3．最大点の近傍での Taylor 展開

2階微分は，

```math
\phi''(n)
=-\frac1n-\frac1{N-n}
```

である．
したがって，

```math
\begin{aligned}
\phi''(n^*)
&=-\frac1{Np}-\frac1{N(1-p)}\\
&=-\frac1{Np(1-p)}
\end{aligned}
```

となる．
また，

```math
\phi(n^*)=0
```

である．
よって， $n^*$ の近傍で2次まで Taylor 展開すると，

```math
\phi(n)
\simeq
-\frac{(n-Np)^2}{2Np(1-p)}
```

を得る．

この2次近似が妥当となる範囲を確認する．
分布の中心付近，すなわち

```math
|n-Np|=O\left(\sqrt{Np(1-p)}\right)
```

を考える．
この範囲では，

```math
\frac{|n-Np|}{Np}
=O\left(\frac1{\sqrt{Np}}\right),
\qquad
\frac{|n-Np|}{N(1-p)}
=O\left(\frac1{\sqrt{N(1-p)}}\right)
```

である．
したがって， $Np\gg1$ かつ $N(1-p)\gg1$ ならば， $n$ は $Np$ と $N(1-p)$ の双方に比べて十分小さい幅で変動する．

実際，3階微分は

```math
\phi'''(n)=\frac1{n^2}-\frac1{(N-n)^2}
```

である．
中心付近における3次の Taylor 項の大きさは，それぞれの項の尺度から

```math
O\left(\frac1{\sqrt{Np}}+
\frac1{\sqrt{N(1-p)}}\right)
```

となり，仮定した極限で0に近づく．
よって，中心付近では3次以上の項を無視できる．
また，Stirling 公式の誤差項も $Np,N(1-p)\gg1$ のもとで小さい．

さらに，Stirling 近似で得た前置因子

```math
\sqrt{\frac{N}{2\pi n(N-n)}}
```

は中心付近では，

```math
\sqrt{\frac{N}{2\pi(Np)N(1-p)}}
=
\frac1{\sqrt{2\pi Np(1-p)}}
```

と近似できる．
以上より，

```math
f(n)\simeq
\frac1{\sqrt{2\pi Np(1-p)}}
\exp\left[
-\frac{(n-Np)^2}{2Np(1-p)}
\right]
```

を得る．
（ii）で求めた

```math
\bar n=Np,\qquad
\Delta^2=Np(1-p)
```

を用いれば，

```math
\boxed{
f(n)\simeq
\frac1{\sqrt{2\pi\Delta^2}}
\exp\left[
-\frac{(n-\bar n)^2}{2\Delta^2}
\right]
}
```

となる．

これは，平均値 $\bar n$ ，分散 $\Delta^2$ の Gauss 分布による二項分布の近似である．
ここでの近似は，特に分布の中心から標準偏差程度の範囲で成立する局所的な近似である．
また， $\Delta\gg1$ では整数上の確率の和を連続積分で近似でき，

```math
\int_{-\infty}^{\infty}
\frac1{\sqrt{2\pi\Delta^2}}
\exp\left[-\frac{(x-\bar n)^2}{2\Delta^2}\right]dx=1
```

となるため，この近似式は規格化されている．

### （iv）Poisson 分布への近似

```math
p=\frac{v}{V}\to0,\qquad
N\to\infty
```

とし，

```math
\lambda=Np=\bar n
```

を有限の一定値に保つ極限を考える．
このとき，

```math
p=\frac{\lambda}{N}
```

である．
問題文の条件 $N/V=\rho$ 一定のもとでは，

```math
\lambda=N\frac{v}{V}=\rho v
```

であるため， $\lambda$ を有限の一定値に保つには， $v$ を有限の一定値に保つ，または少なくとも $\rho v$ が有限の一定値に収束するようにする必要がある．

二項分布は，

```math
f_N(n)=
\frac{N!}{n!(N-n)!}
p^n(1-p)^{N-n}
```

である．
$p=\lambda/N$ を代入すると，

```math
f_N(n)
=
\frac{N!}{n!(N-n)!}
\left(\frac{\lambda}{N}\right)^n
\left(1-\frac{\lambda}{N}\right)^{N-n}
```

となる．
ここで， $n$ を固定して $N\to\infty$ とする．
階乗の比について，

```math
\begin{aligned}
\frac{N!}{(N-n)!}
\left(\frac{\lambda}{N}\right)^n
&=
\frac{N(N-1)\cdots(N-n+1)}{N^n}\lambda^n\\
&=
\lambda^n
\prod_{k=0}^{n-1}\left(1-\frac{k}{N}\right)
\end{aligned}
```

である．
したがって，

```math
\lim_{N\to\infty}
\frac{N!}{(N-n)!}
\left(\frac{\lambda}{N}\right)^n
=\lambda^n
```

となる．
また，

```math
\left(1-\frac{\lambda}{N}\right)^{N-n}
=
\left(1-\frac{\lambda}{N}\right)^N
\left(1-\frac{\lambda}{N}\right)^{-n}
```

であり，極限公式から，

```math
\lim_{N\to\infty}
\left(1-\frac{\lambda}{N}\right)^N
=e^{-\lambda}
```

かつ，

```math
\lim_{N\to\infty}
\left(1-\frac{\lambda}{N}\right)^{-n}=1
```

である．
よって，

```math
\lim_{N\to\infty}
\left(1-\frac{\lambda}{N}\right)^{N-n}
=e^{-\lambda}
```

を得る．
以上を二項分布の式に適用すると，

```math
\begin{aligned}
\lim_{N\to\infty}f_N(n)
&=
\frac1{n!}\lambda^n e^{-\lambda}\\
&=
e^{-\lambda}\frac{\lambda^n}{n!}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
f(n)=e^{-\bar n}\frac{\bar n^n}{n!},
\qquad n=0,1,2,\ldots
}
```

を得る．
これは Poisson 分布である．

なお，この極限では各固定された $n$ に対する確率が上式に収束する．
Poisson 分布は全確率が1であるため，極限分布としても確率の総和は1となる．

以上より，分子数の分布は一般には二項分布であり， $Np$ と $N(1-p)$ がともに十分大きい場合には中心付近で Gauss 分布に近似される．
また， $p\to0$ ， $N\to\infty$ ， $Np=\bar n$ 一定の極限では Poisson 分布に近づく．
