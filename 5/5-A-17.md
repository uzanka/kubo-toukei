# 演習問題【5-A-17】

## 解答

### 1．単一粒子の分配関数

#### 1.1 分配関数の定義

古典統計に従う，互いに相互作用しない粒子 $N$ 個からなる理想気体を考える．
粒子の内部構造は無視し，1個の粒子のエネルギーは運動量の大きさに比例して，

```math
\varepsilon=cr,\qquad r=|\mathbf p|
```

と与えられるものとする．
ここで $c$ は比例定数であり，相対論的極限では光速に相当する．
$\mathbf p=(p_x,p_y,p_z)$ は運動量ベクトルである．

温度 $T$ にある1個の粒子の古典的な分配関数 $Z_1$ は，位相空間全体にわたってボルツマン因子を積分することで，

```math
Z_1=\frac1{h^3}\int e^{-\varepsilon/(kT)}\,d^3r\,d^3p
```

と定義される．
ここで $h$ はプランク定数， $k$ はボルツマン定数である．
理想気体ではエネルギーは位置に依存しないため，位置についての積分は容器の体積 $V$ となる．
したがって，

```math
Z_1=\frac{V}{h^3}
\iiint_{-\infty}^{\infty}
e^{-cr/(kT)}\,dp_x\,dp_y\,dp_z
\tag{1}
```

となる．

#### 1.2 運動量空間の積分

運動量の大きさ $r=\sqrt{p_x^2+p_y^2+p_z^2}$ のみにエネルギーが依存するので，運動量空間で球座標を用いる．
球対称な関数の積分では，

```math
d^3p=r^2\sin\theta\,dr\,d\theta\,d\phi
```

であり，角度についての積分は $4\pi$ となる．
よって，

```math
\iiint e^{-cr/(kT)}\,d^3p
=4\pi\int_0^\infty r^2e^{-cr/(kT)}\,dr
```

である．
ここで，

```math
\alpha=\frac{c}{kT}>0
```

とおくと，必要な積分は

```math
\int_0^\infty r^2e^{-\alpha r}\,dr
```

となる．
部分積分を2回行うと，

```math
\begin{aligned}
\int_0^\infty r^2e^{-\alpha r}\,dr
&=\frac2\alpha\int_0^\infty re^{-\alpha r}\,dr\\
&=\frac2{\alpha^2}\int_0^\infty e^{-\alpha r}\,dr\\
&=\frac2{\alpha^3}
\end{aligned}
```

を得る．
したがって，

```math
\begin{aligned}
\iiint e^{-cr/(kT)}\,d^3p
&=4\pi\frac2{\alpha^3}\\
&=8\pi\left(\frac{kT}{c}\right)^3
\end{aligned}
```

となる．
式 (1) に代入すれば，1個の粒子の分配関数は

```math
\boxed{
Z_1=\frac{8\pi V(kT)^3}{h^3c^3}
}
\tag{2}
```

である．

### 2．全系の分配関数と Helmholtz 自由エネルギー

粒子間の相互作用がないため，粒子を区別できるものとして扱えば，全系の分配関数は $Z_1^N$ となる．
しかし，古典理想気体の粒子は不可弁別であるため，同じ物理状態を重複して数えないように $N!$ で割る必要がある．
よって，

```math
\boxed{
Z(V,T,N)=\frac{Z_1^N}{N!}
=\frac1{N!}
\left[
\frac{8\pi V(kT)^3}{h^3c^3}
\right]^N
}
\tag{3}
```

となる．

Helmholtz 自由エネルギー $F$ は，分配関数を用いて

```math
F=-kT\ln Z
```

と表される．
式 (3) を代入すると，

```math
F=-kT\left[
N\ln Z_1-\ln N!
\right]
```

である．
ここで $N\gg1$ とし，Stirling の公式

```math
\ln N!\simeq N\ln N-N
```

を用いると，

```math
\begin{aligned}
F
&\simeq-NkT
\left[
\ln Z_1-\ln N+1
\right]\\
&=-NkT\ln\left(\frac{eZ_1}{N}\right)
\end{aligned}
```

となる．
式 (2) を代入すれば，

```math
\boxed{
F\simeq
-NkT\ln\left(
\frac{8\pi e k^3}{h^3c^3}
\frac{V}{N}T^3
\right)
}
\tag{4}
```

を得る．
ここで $e$ は自然対数の底である．
以後，Stirling の近似を用いる自由エネルギー，エントロピー，Gibbs 自由エネルギーの式には近似記号 $\simeq$ を用いる．

### 3．圧力と状態方程式

気体の圧力を $p$ とすると，Helmholtz 自由エネルギーとの関係は

```math
p=-\left(\frac{\partial F}{\partial V}\right)_{T,N}
```

である．
式 (4) で $V$ に依存するのは対数の中の $V$ だけであるため，

```math
\begin{aligned}
p
&=-(-NkT)\frac{\partial}{\partial V}\ln V\\
&=\frac{NkT}{V}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
pV=NkT
}
\tag{5}
```

を得る．
この状態方程式の形は通常の古典理想気体と同じである．

### 4．内部エネルギー $U$

分配関数から内部エネルギーを求める公式は，

```math
U=-\frac{\partial\ln Z}{\partial\beta},
\qquad
\beta=\frac1{kT}
```

である．
式 (3) より，

```math
\ln Z=N\ln Z_1-\ln N!
```

である．
また，式 (2) から $Z_1\propto T^3$ であり， $\beta=1/(kT)$ を用いると $Z_1\propto\beta^{-3}$ となる．
したがって，

```math
\ln Z=\text{定数}-3N\ln\beta
```

と書ける．
よって，

```math
\begin{aligned}
U
&=-\frac{\partial}{\partial\beta}
(-3N\ln\beta)\\
&=\frac{3N}{\beta}
\end{aligned}
```

である．
$\beta=1/(kT)$ を代入すると，

```math
\boxed{
U=3NkT
}
\tag{6}
```

を得る．
この結果は，Stirling の近似を用いなくても成立する．

### 5．エンタルピー $H$

エンタルピーは，

```math
H=U+pV
```

と定義される．
式 (5)，(6) を代入すると，

```math
H=3NkT+NkT
```

となる．
したがって，

```math
\boxed{
H=4NkT
}
\tag{7}
```

である．

### 6．エントロピー $S$

エントロピーは，内部エネルギーと Helmholtz 自由エネルギーから

```math
S=\frac{U-F}{T}
```

と求められる．
式 (4)，(6) を代入すると，

```math
S\simeq
3Nk+Nk\ln\left(\frac{eZ_1}{N}\right)
```

となる．
ここで $\ln(eZ_1/N)=1+\ln(Z_1/N)$ であるため，

```math
S\simeq Nk\left[
4+\ln\left(\frac{Z_1}{N}\right)
\right]
```

を得る．
式 (2) を代入すれば，

```math
\boxed{
S\simeq Nk\left[
4+\ln\left(
\frac{8\pi V(kT)^3}{Nh^3c^3}
\right)
\right]
}
\tag{8}
```

である．
これは Stirling の近似を用いたエントロピーである．

### 7．Gibbs 自由エネルギー $G$

Gibbs 自由エネルギーは，

```math
G=F+pV
```

で定義される．
式 (4)，(5) を用いると，

```math
\begin{aligned}
G
&\simeq-NkT\ln\left(\frac{eZ_1}{N}\right)+NkT\\
&=-NkT\ln\left(\frac{Z_1}{N}\right)
\end{aligned}
```

となる．
したがって，

```math
\boxed{
G\simeq-NkT\ln\left(
\frac{8\pi V(kT)^3}{Nh^3c^3}
\right)
}
\tag{9}
```

を得る．

### 8．定積熱容量と定圧熱容量

定積熱容量 $C_V$ は，体積と粒子数を一定に保ったときの内部エネルギーの温度微分である．
式 (6) より，

```math
\boxed{
C_V=\left(\frac{\partial U}{\partial T}\right)_{V,N}
=3Nk
}
\tag{10}
```

となる．

同様に，定圧熱容量 $C_p$ は，圧力と粒子数を一定に保ったときのエンタルピーの温度微分である．
式 (7) より，

```math
\boxed{
C_p=\left(\frac{\partial H}{\partial T}\right)_{p,N}
=4Nk
}
\tag{11}
```

を得る．

### 9．結果のまとめと物理的意味

以上で得られた熱力学関数は，

```math
\boxed{
pV=NkT
}
```

```math
\boxed{
U=3NkT,\qquad H=4NkT
}
```

```math
\boxed{
C_V=3Nk,\qquad C_p=4Nk
}
```

である．
エントロピーと Gibbs 自由エネルギーは，それぞれ式 (8)，(9) で与えられる．

通常の非相対論的な理想気体では粒子の運動エネルギーは $\varepsilon=r^2/(2m)$ であるのに対し，本問では $\varepsilon=cr$ と運動量の大きさに比例する．
この違いにより，分配関数は $T^{3/2}$ ではなく $T^3$ に比例し，内部エネルギーは $U=3NkT$ となる．
一方，圧力については $pV=NkT$ が成立するため，

```math
\boxed{
p=\frac{U}{3V}
}
```

という関係も得られる．
この結果は，相対論的極限における粒子の運動エネルギーの性質を反映している．
