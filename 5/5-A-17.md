# 演習問題【5-A-17】

## 解答

古典統計学に基づき，相互作用のない $N$ 個の区別できない粒子からなる理想気体の分配関数 $Z$ を考える．
まず，単一粒子の分配関数 $Z_1$ を求める．
位相空間における微小体積要素は，位置 $\mathbf{r}$ と運動量 $\mathbf{p}$ を用いて $d^3r d^3p$ で表され，量子力学的な大きさの基準としてプランク定数 $h$ を用いると，単一粒子の分配関数 $Z_1$ は次のように書ける：

$$Z_1 = \frac{1}{h^3} \int \int e^{-\varepsilon(\mathbf{r}, \mathbf{p})/kT} d^3r d^3p$$

ここで，粒子間の相互作用がない理想気体では，エネルギー $\varepsilon$ は粒子の位置 $\mathbf{r}$ には依存せず，運動量 $\mathbf{p}$ のみに依存する：$\varepsilon = \varepsilon(\mathbf{p})$ ．
したがって，位置に関する積分は体積 $V$ となり，次のように整理できる：

$$Z_1 = \frac{V}{h^3} \iiint_{-\infty}^{\infty} e^{-\varepsilon(\mathbf{p})/kT} dp_x dp_y dp_z$$

問題の設定より，エネルギーは $\varepsilon = cp$ である．
これを用いて運動量空間の積分 $I$ を計算する．
運動量の大きさ $p = \sqrt{p_x^2 + p_y^2 + p_z^2}$ を用いるために，球面座標系を採用すると，運動量空間の体積要素は $d^3p = p^2 \sin\theta dp d\theta d\phi$ であり，全方位にわたる積分は $4\pi p^2 dp$ となる．

$$I = \iiint_{-\infty}^{\infty} e^{-cp/kT} d^3p = 4\pi \int_0^{\infty} e^{-cp/kT} p^2 dp$$

ここで， $a = c/kT$ と置くと，積分は $\int_0^\infty e^{-ap} p^2 dp$ となり，部分積分を繰り返すことで次のように計算される：

$$\int_0^\infty e^{-ap} p^2 dp = \left[ -\frac{1}{a} e^{-ap} p^2 \right]_0^\infty + \frac{2}{a} \int_0^\infty e^{-ap} p dp = 0 + \frac{2}{a} \left[ -\frac{1}{a} e^{-ap} p \right]_0^\infty + \frac{2}{a^2} \int_0^\infty e^{-ap} dp = \frac{2}{a^3}$$

したがって， $I = 4\pi \cdot \frac{2}{a^3} = 8\pi \left(\frac{kT}{c}\right)^3$ となる．
よって，単一粒子の分配関数は

$$Z_1 = \frac{V}{h^3} \cdot 8\pi \left(\frac{kT}{c}\right)^3 = \frac{8\pi V (kT)^3}{h^3 c^3}$$

粒子は区別できないため，全系の分配関数 $Z$ は $Z = \frac{1}{N!} Z_1^N$ となる：

$$Z(V,T,N) = \frac{1}{N!} \left( \frac{8\pi V (kT)^3}{h^3 c^3} \right)^N$$

次に，ヘルムホルツの自由エネルギー $F$ を求める．
Stirling の近似 $\ln N! \approx N \ln N - N$ を用いると，

$$F = -kT \ln Z = -kT \left( \ln \frac{1}{N!} + N \ln Z_1 \right) \approx -kT \left( -N \ln N + N + N \ln Z_1 \right)$$

$$F = -NkT \left( \ln \frac{Z_1}{N} + 1 \right) = -NkT \ln \left( \frac{e Z_1}{N} \right)$$

$$F = -NkT \ln \left( \frac{8\pi e V (kT)^3}{h^3 c^3 N} \right) = -NkT \ln \left( \frac{8\pi e k^3}{h^3 c^3} \frac{V}{N} T^3 \right)$$

この $F$ を用いて，熱力学関数を導出する．
圧力 $p$ は，

$$p = -\left( \frac{\partial F}{\partial V} \right)_{T,N} = -(-NkT) \frac{\partial}{\partial V} \ln V = \frac{NkT}{V}$$

となり，状態方程式 $pV = NkT$ が得られる．
内部エネルギー $U$ は，

$$U = -T^2 \left( \frac{\partial}{\partial T} \left( \frac{F}{T} \right) \right)_{V,N}$$

において， $\frac{F}{T} = -Nk \ln \left( \text{const} \cdot V \cdot T^3 \right) = -Nk \ln(\text{const}') - Nk \ln(T^3)$ であるから，

$$\frac{\partial}{\partial T} \left( \frac{F}{T} \right) = -Nk \frac{\partial}{\partial T} (3 \ln T) = -3Nk \frac{1}{T}$$

よって，

$$U = -T^2 \left( -\frac{3Nk}{T} \right) = 3NkT$$

エンタルピー $H$ は，

$$H = U + pV = 3NkT + NkT = 4NkT$$

となる．
定積熱容量 $C_V$ と定圧熱容量 $C_p$ は，

$$C_V = \left( \frac{\partial U}{\partial T} \right)_{V,N} = 3Nk, \quad C_p = \left( \frac{\partial H}{\partial T} \right)_{p,N} = 4Nk$$

である．

## 解説

本問題で扱ったエネルギー $\varepsilon = cp$ は，相対論的な極限（非常に大きなエネルギーをもつ粒子）における粒子のエネルギーを表している．
通常の非相対論的な粒子では，運動エネルギーは $\varepsilon = \frac{p^2}{2m}$ で与えられる．
この非相対論的な場合の熱力学関数と比較すると，本問題の結果には顕著な違いが見られる．

1.  **内部エネルギーの差**：
    非相対論的な場合，内部エネルギーは $U = \frac{3}{2}NkT$ であるのに対し，本問題（相対論的極限）では $U = 3NkT$ となり，エネルギーが 2 倍大きい．
2.  **定積熱容量の差**：
    非相対論的な場合の $C_V = \frac{3}{2}Nk$ に対し，本問題では $C_V = 3Nk$ となる．
3.  **圧力の関係**：
    状態方程式 $pV = NkT$ はどちらの場合も同じ形式であるが，エネルギーとの関係（ $p = \frac{2}{3}\frac{U}{V}$ vs $p = \frac{1}{3}\frac{U}{V}$ ）が異なる．

このような違いは，エネルギーと運動量の依存関係（ $\varepsilon \propto p^2$ か $\varepsilon \propto p$ か）が，位相空間における積分結果（運動量空間の「有効な」次元数のようなもの）に影響を与えるために生じるものである．
