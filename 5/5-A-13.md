# 演習問題【5-A-13】

## 解答

### 1．鎖の配列数 $W(x)$

長さ $a$ の要素 $n$ 個を連結した一次元の鎖を考える．
各要素は右向きまたは左向きに配置され，関節は自由に折れ曲がるものとする．

ここでは，鎖の両端の位置の差 $x$ を，右向きを正とする符号付き変位として定義する．

右向きの要素数を $n_+$ ，左向きの要素数を $n_-$ とすると，全要素数は $n$ であるから，

```math
n=n_++n_-
```

が成立する．

また，鎖の両端の変位は，

```math
x=(n_+-n_-)a
```

である．

この2式を連立させると，

```math
\boxed{
n_+=\frac{na+x}{2a},\qquad
n_-=\frac{na-x}{2a}
}
\tag{1}
```

を得る．

右向きの要素が $n_+$ 個，左向きの要素が $n_-$ 個となる配列の数は， $n$ 個の要素から右向きとなる $n_+$ 個を選ぶ組合せの数に等しい．

したがって，配列数 $W(x)$ は，

```math
\boxed{
W(x)=\frac{n!}{n_+!n_-!}
}
\tag{2}
```

である．

ここで， $n_++n_-=n$ を用いた．

なお， $n_+$ および $n_-$ は整数でなければならないため， $x$ は連続的な任意の値を取るわけではない．
実際に許される変位は，

```math
x=(2n_+-n)a
```

で与えられる離散的な値である．

また，鎖の両端間の距離を $x\geq0$ と解釈する場合には，正方向および負方向の配列を区別せずに数えるため， $x>0$ では式（2）の2倍となる．
この場合，エントロピーには $k\ln2$ が加わるが，定数項であるため，以下で求める張力には影響しない．

### 2．エントロピー $S(x)$ の導出

ボルツマンの原理により，エントロピー $S(x)$ は微視状態数 $W(x)$ を用いて，

```math
S(x)=k\ln W(x)
```

と表される．
ここで， $k$ はボルツマン定数である．

式（2）を代入すると，

```math
S(x)
=
k\left\{
\ln n!-\ln n_+!-\ln n_-!
\right\}
```

となる．

$n\gg1$ であり，さらに $n_+$ と $n_-$ も十分に大きい場合には，Stirling の公式，

```math
\ln m!\simeq m\ln m-m
```

を用いることができる．

したがって，

```math
\begin{aligned}
S(x)
&\simeq k\{
n\ln n-n\\
&\quad-n_+\ln n_++n_+\\
&\quad-n_-\ln n_-+n_-
\}
\end{aligned}
```

となる．

ここで，

```math
n=n_++n_-
```

であるから，定数項について，

```math
-n+n_++n_-=0
```

が成立する．

よって，

```math
\boxed{
S(x)\simeq
k\left\{
n\ln n-n_+\ln n_+-n_-\ln n_-
\right\}
}
\tag{3}
```

を得る．

次に，式（1）を用いて，

```math
n_+=\frac n2\left(1+\frac{x}{na}\right)
```

```math
n_-=\frac n2\left(1-\frac{x}{na}\right)
```

と書く．

ここで，

```math
u=\frac{x}{na}
```

とおくと，

```math
n_+=\frac n2(1+u),\qquad
n_-=\frac n2(1-u)
```

である．

これらを式（3）に代入すると，

```math
\begin{aligned}
S(x)
&\simeq k\bigg\{
n\ln n\\
&\quad-\frac n2(1+u)
\ln\left[\frac n2(1+u)\right]\\
&\quad-\frac n2(1-u)
\ln\left[\frac n2(1-u)\right]
\bigg\}
\end{aligned}
```

となる．

対数の性質と，

```math
(1+u)+(1-u)=2
```

を用いて整理すると，

```math
\boxed{
\begin{aligned}
S(x)\simeq nk\bigg\{&
\ln2\\
&-\frac12\left(1+\frac{x}{na}\right)
\ln\left(1+\frac{x}{na}\right)\\
&-\frac12\left(1-\frac{x}{na}\right)
\ln\left(1-\frac{x}{na}\right)
\bigg\}
\end{aligned}
}
\tag{4}
```

となる．

これが鎖の両端の符号付き変位 $x$ に対するエントロピーである．

なお，式（4）はStirling の近似に基づく結果であり，その適用には，

```math
n_+\gg1,\qquad n_-\gg1
```

が必要である．
すなわち，

```math
\boxed{
n(1+u)\gg1,\qquad
n(1-u)\gg1
}
```

が成立する範囲で使用できる．

厳密には $x$ は離散的な値を取るが， $n\gg1$ であり，両方向の要素数が十分に大きい領域では，連続変数として近似的に扱うことができる．

### 3．張力 $X$ と温度 $T$ の関係

#### 3.1 自由エネルギーから張力を求める

温度 $T$ におけるヘルムホルツ自由エネルギー $F$ は，

```math
F=U-TS
```

で定義される．
ここで， $U$ は内部エネルギーである．

本モデルでは，各要素の長さは一定であり，関節は自由に折れ曲がる．
また，要素間に相互作用や曲げエネルギーがなく，各要素の向きによってエネルギーが変化しないものとする．

したがって，内部エネルギー $U$ は鎖の配列や両端の変位 $x$ に依存しない．

すなわち，

```math
\left(\frac{\partial U}{\partial x}\right)_T=0
```

である．

鎖の両端の符号付き変位を $x$ に保つために外部から加える一般化力を $X$ とすると，温度一定のもとで，

```math
X=\left(\frac{\partial F}{\partial x}\right)_T
```

である．

したがって，

```math
\begin{aligned}
X
&=\left(\frac{\partial(U-TS)}{\partial x}\right)_T\\
&=-T\left(\frac{\partial S}{\partial x}\right)_T
\end{aligned}
```

となる．

よって，

```math
\boxed{
X=-T\left(\frac{\partial S}{\partial x}\right)_T
}
\tag{5}
```

を得る．

ここで， $X$ は鎖を伸ばす方向に外部から加える力を正とする．
鎖自身が及ぼす復元力は，これと反対向きである．

#### 3.2 エントロピーを微分する

式（4）の微分を簡単にするため，

```math
u=\frac{x}{na}
```

とおくと，

```math
S(u)\simeq nk\left\{
\ln2-\frac12(1+u)\ln(1+u)
-\frac12(1-u)\ln(1-u)
\right\}
```

となる．

これを $u$ で微分すると，

```math
\begin{aligned}
\frac{dS}{du}
&\simeq-\frac{nk}{2}
\left\{\ln(1+u)+1\right\}\\
&\quad-\frac{nk}{2}
\left\{-\ln(1-u)-1\right\}\\
&=\frac{nk}{2}
\ln\left(\frac{1-u}{1+u}\right)
\end{aligned}
```

を得る．

また，

```math
\frac{du}{dx}=\frac{1}{na}
```

であるため，連鎖律より，

```math
\begin{aligned}
\frac{dS}{dx}
&=\frac{dS}{du}\frac{du}{dx}\\
&\simeq\frac{k}{2a}
\ln\left(\frac{1-u}{1+u}\right)
\end{aligned}
```

となる．

#### 3.3 張力の式

式（5）に代入すると，

```math
\begin{aligned}
X
&=-T\frac{dS}{dx}\\
&\simeq-\frac{kT}{2a}
\ln\left(\frac{1-u}{1+u}\right)
\end{aligned}
```

である．

対数の性質を用いて整理すると，

```math
X\simeq
\frac{kT}{2a}
\ln\left(\frac{1+u}{1-u}\right)
```

となる．

ここに，

```math
u=\frac{x}{na}
```

を代入すれば，

```math
\boxed{
X\simeq\frac{kT}{2a}
\ln\left(
\frac{1+x/(na)}{1-x/(na)}
\right)
}
\tag{6}
```

を得る．

これが鎖の両端の変位を $x$ に保つために必要な外力と温度との関係である．

また，

```math
0<x<na
```

の場合には，

```math
\frac{1+x/(na)}{1-x/(na)}>1
```

であるため，

```math
X>0
```

となる．
これは，鎖を伸ばした状態に保つには，伸長方向に外力を加える必要があることを表している．

さらに，固定した変位 $x$ に対して，

```math
X\propto T
```

であり，張力は絶対温度に比例する．

なお，式（6）はStirling の近似が成立する領域での結果である．
完全伸長に近づき $n_-$ が小さくなる領域では，この近似式をそのまま適用することはできない．

### 4．小さな伸びに対するフックの法則

最後に，鎖の伸びが十分に小さい場合，

```math
\left|\frac{x}{na}\right|\ll1
```

を考える．

このとき，

```math
\ln(1+u)
=u-\frac{u^2}{2}+\frac{u^3}{3}+\cdots
```

```math
\ln(1-u)
=-u-\frac{u^2}{2}-\frac{u^3}{3}+\cdots
```

であるから，

```math
\ln(1+u)-\ln(1-u)
\simeq2u
```

となる．

したがって，

```math
\begin{aligned}
X
&\simeq\frac{kT}{2a}
\left\{
\ln(1+u)-\ln(1-u)
\right\}\\
&\simeq\frac{kT}{2a}(2u)\\
&=\frac{kT}{a}u
\end{aligned}
```

となる．

ここに，

```math
u=\frac{x}{na}
```

を代入すると，

```math
\boxed{
X\simeq\frac{kT}{na^2}x
}
```

を得る．

これはフックの法則，

```math
X=Kx
```

と同じ形である．
したがって，このモデルの小さな伸びに対する有効なばね定数は，

```math
\boxed{
K=\frac{kT}{na^2}
}
```

である．

すなわち，この鎖の弾性は，主として配列のエントロピーが減少することによって生じるエントロピー弾性である．

なお，さらに高次の項まで考えると，

```math
X\simeq\frac{kT}{a}
\left(u+\frac{u^3}{3}+\cdots\right)
```

となるため，伸びが大きくなるとフックの法則からずれ，非線形な弾性を示す．

### 5．補足：完全伸長における極限

完全伸長では，

```math
x=na
```

であり，

```math
n_+=n,\qquad n_-=0
```

となる．

このとき，鎖の配列はすべての要素が同じ方向を向く1通りだけであるため，

```math
W(na)=1
```

となる．

したがって，厳密なエントロピーは，

```math
\boxed{
S(na)=k\ln1=0
}
```

である．

一方，式（6）では $x\to na$ とすると，

```math
X\to\infty
```

となる．
これは，鎖が完全伸長に近づくほど，さらに伸ばすために大きな力が必要になることを表している．

ただし，完全伸長に近づくと $n_-$ が小さくなり，Stirling の近似条件が満たされなくなる．
そのため，式（6）の発散は連続近似における漸近的な結果として理解すべきであり，有限の $n$ に対して完全伸長近傍の張力を定量的に求めるには，式（2）の厳密な配列数を用いる必要がある．

以上より，理想的な一次元自由関節鎖では，鎖を伸ばすために必要な張力はエントロピーの減少によって生じ，小さな伸びに対してはフックの法則に従うことが示された．
