# 演習問題【5-A-13】

## 解答

### 1．鎖の配列数 $W(x)$

長さ $a$ の要素 $n$ 個を連結した1次元の鎖を考える．
各要素は右向きまたは左向きに配置され，関節は自由に折れ曲がるものとする．
右向きの要素数を $n_+$ ，左向きの要素数を $n_-$ とする．
全要素数は $n$ であるから，

```math
n=n_++n_-
```

が成立する．
また，両端の位置の差を $x$ とすると，

```math
x=(n_+-n_-)a
```

である．
この2式を連立させると，

```math
\boxed{
n_+=\frac{na+x}{2a},\qquad
n_-=\frac{na-x}{2a}
}
\tag{1}
```

を得る．

鎖の両端の位置が指定されたとき，右向きの要素が $n_+$ 個，左向きの要素が $n_-$ 個となる配列の数は， $n$ 個の要素から右向きとなる $n_+$ 個を選ぶ組合せの数に等しい．
したがって，その配列数 $W(x)$ は

```math
\boxed{
W(x)=\frac{n!}{n_+!n_-!}
}
\tag{2}
```

である．
ここで， $n_++n_-=n$ を用いた．

### 2．エントロピー $S(x)$ の導出

ボルツマンの原理により，エントロピー $S(x)$ は微視状態数 $W(x)$ を用いて，

```math
S(x)=k\ln W(x)
```

と表される．
ここで $k$ はボルツマン定数である．
式 (2) を代入すると，

```math
S(x)=k\{\ln n!-\ln n_+!-\ln n_-!\}
```

となる．

$n\gg1$ であり，さらに $n_+$ と $n_-$ も十分に大きい場合には，Stirling の公式

```math
\ln m!\simeq m\ln m-m
```

を用いることができる．
したがって，

```math
\begin{aligned}
S(x)
&\simeq k\{n\ln n-n
-n_+\ln n_++n_-
+n_--n_-\}
\end{aligned}
```

となる．
定数項を正しく整理すると， $n_++n_-=n$ であるため，

```math
S(x)\simeq
k\{n\ln n-n_+\ln n_+-n_-\ln n_-\}
\tag{3}
```

を得る．

式 (1) を用いて，

```math
n_+=\frac n2\left(1+\frac{x}{na}\right),
\qquad
n_-=\frac n2\left(1-\frac{x}{na}\right)
```

と書く．
これらを式 (3) に代入して整理すると，

```math
\boxed{
\begin{aligned}
S(x)\simeq nk\bigg\{&
\ln2
-\frac12\left(1+\frac{x}{na}\right)
\ln\left(1+\frac{x}{na}\right)\\
&-\frac12\left(1-\frac{x}{na}\right)
\ln\left(1-\frac{x}{na}\right)
\bigg\}
\end{aligned}
}
\tag{4}
```

となる．
これが鎖の両端の位置の差 $x$ に対するエントロピーである．

式 (4) は，$|x|<na$ で，Stirling の近似が成立する範囲に対する結果である．
厳密には $x$ は離散的な値を取るが， $n\gg1$ の場合には連続変数として近似的に扱える．

### 3．張力 $X$ と温度 $T$ の関係

#### 3.1 自由エネルギーから張力を求める

温度 $T$ におけるヘルムツホルツ自由エネルギー $F$ は，

```math
F=U-TS
```

で定義される．
ここで $U$ は内部エネルギーである．
本モデルでは，関節が自由に折れ曲がり，要素の長さが一定であるため，鎖の配列によって内部エネルギーは変化しない．
したがって， $U$ は $x$ に依存しない．

鎖の両端の位置の差を $x$ に保つために外部から加える力を $X$ とすると，温度一定のもとで，

```math
X=\left(\frac{\partial F}{\partial x}\right)_T
```

である．
よって，

```math
\begin{aligned}
X
&=\left(\frac{\partial (U-TS)}{\partial x}\right)_T\\
&=-T\left(\frac{\partial S}{\partial x}\right)_T
\end{aligned}
\tag{5}
```

となる．

#### 3.2 エントロピーを微分する

式 (4) の微分を簡単にするため，

```math
u=\frac{x}{na}
```

とおくと，

```math
S(u)\simeq nk\left\{
\ln2-\frac12(1+u)\ln(1+u)
-\frac12(1-u)\ln(1-u)
\right\}
```

となる．
これを $u$ で微分すると，

```math
\begin{aligned}
\frac{dS}{du}
&\simeq-\frac{nk}{2}
\left\{\ln(1+u)+1\right\}\\
&\quad-\frac{nk}{2}
\left\{-\ln(1-u)-1\right\}\\
&=\frac{nk}{2}\ln\left(\frac{1-u}{1+u}\right)
\end{aligned}
```

を得る．
また，

```math
\frac{du}{dx}=\frac{1}{na}
```

であるため，連鎖律より，

```math
\begin{aligned}
\frac{dS}{dx}
&=\frac{dS}{du}\frac{du}{dx}\\
&\simeq\frac{k}{2a}
\ln\left(\frac{1-u}{1+u}\right)
\end{aligned}
```

となる．

#### 3.3 張力の式

式 (5) に代入すると，

```math
\begin{aligned}
X
&=-T\frac{dS}{dx}\\
&\simeq-\frac{kT}{2a}
\ln\left(\frac{1-u}{1+u}\right)
\end{aligned}
```

である．
したがって， $u=x/(na)$ を戻せば，

```math
\boxed{
X\simeq\frac{kT}{2a}
\ln\left(
\frac{1+x/(na)}{1-x/(na)}
\right)
}
\tag{6}
```

を得る．
これが，鎖の両端の位置の差を $x$ に保つために必要な力と温度との関係である．
$x>0$ の場合，必要な力 $X$ も正となる．
また，式 (6) から，固定した $x$ に対して張力は温度 $T$ に比例することが分かる．

### 4．小さな伸びに対するフックの法則

最後に，鎖の伸びが十分に小さい場合，

```math
\left|\frac{x}{na}\right|\ll1
```

を考える．
このとき，

```math
\ln(1+u)\simeq u,\qquad
\ln(1-u)\simeq-u
```

であるから，

```math
\begin{aligned}
X
&\simeq\frac{kT}{2a}
\{\ln(1+u)-\ln(1-u)\}\\
&\simeq\frac{kT}{2a}(u-(-u))\\
&=\frac{kT}{a}\frac{x}{na}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
X\simeq\frac{kT}{na^2}x
}
```

を得る．
これはフックの法則 $X=Kx$ と同じ形であり，このモデルの有効なばね定数は

```math
\boxed{
K=\frac{kT}{na^2}
}
```

である．
すなわち，この鎖の弾性は，主に配列のエントロピーを変化させることによって生じるものである．
