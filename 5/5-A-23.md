# 演習問題【5-A-23】

## 解答

### 1．考える系と基本的な定義

質量 $m$ の粒子からなる三次元の一様な理想気体を考える．
粒子間相互作用は無視し，内部状態の縮退度を $g$ とする．
$g=1$ は内部自由度を持たない場合に相当する．

粒子数を $N$ ，容積を $V$ ，数密度を

```math
\rho=\frac{N}{V}
```

とする．
温度は $T>0$ である．

大正準アンサンブルを用い，化学ポテンシャルを $\mu$ ，フガシティを

```math
z=e^{\beta\mu},
\qquad
\beta=\frac{1}{kT}
```

と定義する．
このとき，粒子数は平均値として

```math
\langle N\rangle=N
```

となるように $\mu$ を定める．
大正準分布で記述することにより，1粒子状態の平均占有数を直接扱える．
巨視的な熱力学的極限では，この平均粒子数による記述は固定粒子数の記述と同じ熱力学的状態を与える．

1粒子状態の運動量を $\mathbf p$ とすると，エネルギーは

```math
\varepsilon_{\mathbf p}
=
\frac{\mathbf p^2}{2m}\geq0
```

である．
エネルギーの基準は最低エネルギーをゼロとするように選ぶ．

熱的ド・ブロイ波長を，

```math
\boxed{
\Lambda=\frac{h}{\sqrt{2\pi mkT}}
}
\tag{1}
```

と定義する．
ここで $h$ は Planck 定数である．

### 2．Fermi・Bose 統計の厳密な平均占有数

Fermi 統計では，1粒子状態の平均占有数は，

```math
\boxed{
\langle n_{\mathbf p}\rangle_{\mathrm F}
=
\frac{1}{z^{-1}e^{\beta\varepsilon_{\mathbf p}}+1}
}
\tag{2}
```

である．

Bose 統計では，

```math
\boxed{
\langle n_{\mathbf p}\rangle_{\mathrm B}
=
\frac{1}{z^{-1}e^{\beta\varepsilon_{\mathbf p}}-1}
}
\tag{3}
```

である．

Bose 粒子については，最低エネルギーをゼロとしたため，分母が正であるための条件は

```math
0<z<1
```

である．

ここでは，まだボルツマン近似を仮定しない．
まず，これらの厳密な分布からフガシティ $z$ の大きさを決める．

### 3．厳密な粒子数の式からフガシティを求める

1粒子状態の縮退度を含めた粒子数の平均は，

```math
N=\sum_r\langle n_r\rangle
\tag{4}
```

である．
ここで $r$ は運動量状態と内部状態を合わせた全1粒子状態を表す．

巨視的な容器を考え，容器の各方向の大きさが熱的ド・ブロイ波長に比べて十分大きいとする．
このとき，状態和を連続状態密度による積分で近似できる．

1粒子状態の熱的分配関数は，

```math
\begin{aligned}
Q_1
&\simeq
\frac{g}{h^3}
\int_Vd^3r
\int_{\mathbb R^3}
e^{-\beta\mathbf p^2/(2m)}\,d^3p\\
&=
\frac{gV}{h^3}
(2\pi mkT)^{3/2}\\
&=
\frac{gV}{\Lambda^3}.
\end{aligned}
\tag{5}
```

ここで，位置積分は $V$ を与え，運動量積分には三次元ガウス積分を用いた．

同様に，

```math
Q_\ell
=
\sum_r e^{-\ell\beta\varepsilon_r}
\simeq
\frac{gV}{\Lambda^3\ell^{3/2}}
\tag{6}
```

となる．

#### 3.1 Fermi 統計の場合

式 (2) より，

```math
N
=
\sum_r
\frac{ze^{-\beta\varepsilon_r}}
{1+ze^{-\beta\varepsilon_r}}
```

である．
これを連続状態密度で積分すると，

```math
\frac{\rho\Lambda^3}{g}
=
\mathcal F_{3/2}(z)
\tag{7}
```

を得る．
ここで，

```math
\mathcal F_{3/2}(z)
=
-\operatorname{Li}_{3/2}(-z)
```

であり，積分表示では，

```math
\mathcal F_{3/2}(z)
=
\frac{1}{\Gamma(3/2)}
\int_0^\infty
\frac{x^{1/2}}{z^{-1}e^x+1}\,dx
\tag{8}
```

である．

この関数は $z>0$ において単調増加し， $z\to0$ でゼロに近づく．

#### 3.2 Bose 統計の場合

同様に式 (3) から，

```math
\frac{\rho\Lambda^3}{g}
=
\mathcal B_{3/2}(z)
\tag{9}
```

を得る．
ここで，

```math
\mathcal B_{3/2}(z)
=
\operatorname{Li}_{3/2}(z)
```

であり，

```math
\mathcal B_{3/2}(z)
=
\frac{1}{\Gamma(3/2)}
\int_0^\infty
\frac{x^{1/2}}{z^{-1}e^x-1}\,dx
\tag{10}
```

である．

この関数も $0<z<1$ で単調増加し， $z\to0$ でゼロに近づく．

#### 3.3 希薄極限におけるフガシティ

式 (8)，(10) を $z\ll1$ の範囲で展開すると，

```math
\mathcal F_{3/2}(z)
=
z-\frac{z^2}{2^{3/2}}+O(z^3)
```

および，

```math
\mathcal B_{3/2}(z)
=
z+\frac{z^2}{2^{3/2}}+O(z^3)
```

となる．
したがって，両統計で，

```math
\frac{\rho\Lambda^3}{g}
=
z+O(z^2)
```

である．
よって，

```math
\boxed{
z
=
\frac{\rho\Lambda^3}{g}
+
O\left((\rho\Lambda^3/g)^2\right)
}
\tag{11}
```

を得る．

ここで重要なのは，式 (11) がボルツマン近似を最初に仮定して導かれたものではないという点である．
厳密な Fermi 分布と Bose 分布から得られる粒子数の式を，希薄極限で展開した結果である．

したがって，

```math
\rho\Lambda^3\ll1
```

であれば，有限の内部縮退度 $g$ に対して，

```math
\boxed{z\ll1}
\tag{12}
```

が成立する．

### 4．平均占有数の Boltzmann 近似

フガシティが十分小さいことが示されたので，式 (2)，(3) を展開できる．

まず，

```math
x_{\mathbf p}
=
ze^{-\beta\varepsilon_{\mathbf p}}
```

とおく．
エネルギーは非負であるため，

```math
0<x_{\mathbf p}\leq z\ll1
```

である．

Fermi 統計では，

```math
\begin{aligned}
\langle n_{\mathbf p}\rangle_{\mathrm F}
&=
\frac{x_{\mathbf p}}{1+x_{\mathbf p}}\\
&=
x_{\mathbf p}
-x_{\mathbf p}^2
+O(x_{\mathbf p}^3).
\end{aligned}
```

したがって，

```math
\langle n_{\mathbf p}\rangle_{\mathrm F}
\simeq
ze^{-\beta\varepsilon_{\mathbf p}}
\tag{13}
```

となる．

一方，Bose 統計では，

```math
\begin{aligned}
\langle n_{\mathbf p}\rangle_{\mathrm B}
&=
\frac{x_{\mathbf p}}{1-x_{\mathbf p}}\\
&=
x_{\mathbf p}
+x_{\mathbf p}^2
+O(x_{\mathbf p}^3).
\end{aligned}
```

よって，

```math
\langle n_{\mathbf p}\rangle_{\mathrm B}
\simeq
ze^{-\beta\varepsilon_{\mathbf p}}
\tag{14}
```

となる．

両者の先頭項は共通であり，

```math
\boxed{
\langle n_{\mathbf p}\rangle
\simeq
ze^{-\beta\varepsilon_{\mathbf p}}
=
e^{-\beta(\varepsilon_{\mathbf p}-\mu)}
}
\tag{15}
```

である．
これは Maxwell-Boltzmann 統計における平均占有数である．

さらに，誤差がすべての1粒子状態について小さいことも確認できる．
Fermi 統計では，

```math
\left|
\frac{\langle n_{\mathbf p}\rangle_{\mathrm F}}
{x_{\mathbf p}}-1
\right|
=
\frac{x_{\mathbf p}}{1+x_{\mathbf p}}
\leq z
```

である．
Bose 統計では，

```math
\left|
\frac{\langle n_{\mathbf p}\rangle_{\mathrm B}}
{x_{\mathbf p}}-1
\right|
=
\frac{x_{\mathbf p}}{1-x_{\mathbf p}}
\leq\frac{z}{1-z}.
```

したがって $z\ll1$ ならば，どの1粒子状態についても相対誤差は十分小さい．

### 5．分配関数から見た Boltzmann 統計への移行

平均占有数だけでなく，統計全体についても同じ結論が得られる．

大正準分配関数を $\Xi$ とすると，Bose 統計では，

```math
\begin{aligned}
\ln\Xi_{\mathrm B}
&=
-\sum_r\ln(1-ze^{-\beta\varepsilon_r})\\
&=
\sum_{\ell=1}^{\infty}
\frac{z^\ell}{\ell}Q_\ell .
\end{aligned}
\tag{16}
```

Fermi 統計では，

```math
\begin{aligned}
\ln\Xi_{\mathrm F}
&=
\sum_r\ln(1+ze^{-\beta\varepsilon_r})\\
&=
\sum_{\ell=1}^{\infty}
\frac{(-1)^{\ell+1}z^\ell}{\ell}Q_\ell .
\end{aligned}
\tag{17}
```

いずれも $z\ll1$ では，

```math
\ln\Xi_{\mathrm B}
=
zQ_1+O(z^2Q_1)
```

および，

```math
\ln\Xi_{\mathrm F}
=
zQ_1+O(z^2Q_1)
```

となる．
ここでは式 (6) の $Q_\ell\propto\ell^{-3/2}$ を用いている．

したがって，

```math
\boxed{
\ln\Xi_{\mathrm B}
\simeq
\ln\Xi_{\mathrm F}
\simeq zQ_1
}
\tag{18}
```

である．

右辺は Maxwell-Boltzmann 統計の大正準分配関数，

```math
\Xi_{\mathrm{MB}}=e^{zQ_1}
```

の対数に一致する．

このように，平均占有数だけでなく，大正準分配関数も同じ Boltzmann 極限に帰着する．

### 6．平均粒子間距離と熱的ド・ブロイ波長

数密度を $\rho=N/V$ とすると，1粒子当たりの体積は $V/N=1/\rho$ である．
したがって，平均粒子間距離の代表的な尺度を，

```math
d=\left(\frac VN\right)^{1/3}
=\rho^{-1/3}
\tag{19}
```

と定義する．

式 (12) の条件は，

```math
\rho\Lambda^3\ll1
```

である．
式 (19) を用いると，

```math
\left(\frac{\Lambda}{d}\right)^3
=
\rho\Lambda^3
```

なので，

```math
\boxed{
\Lambda\ll d
}
\tag{20}
```

となる．

すなわち，熱的ド・ブロイ波長が平均粒子間距離の代表尺度より十分小さいことが，Fermi 統計と Bose 統計の量子統計的な差を無視できる条件である．

なお，「平均 de Broglie 波長」を Maxwell-Boltzmann 分布における文字どおりの平均値として定義する場合には，

```math
\overline{\lambda}
=
\left\langle\frac{h}{|\mathbf p|}\right\rangle
=
2\Lambda
```

となる．
したがって，その定義を用いても，

```math
\overline{\lambda}\ll d
```

は，数値係数を除いて式 (20) と同じ希薄条件を表す．
ここでの $d$ は最近接粒子間距離の厳密な平均値ではなく，数密度から定めた平均間隔の尺度である．

### 結論

Fermi 統計と Bose 統計の厳密な粒子数の式から，

```math
\rho\Lambda^3\ll1
```

のとき，

```math
z\ll1
```

となることを示した．
このとき，両統計の平均占有数と大正準分配関数は，ともに Maxwell-Boltzmann 統計の結果に一致する．

また，

```math
\rho\Lambda^3
=
\left(\frac{\Lambda}{d}\right)^3
```

であるから，

```math
\boxed{
\Lambda\ll d
}
```

が成立すれば，Fermi 統計と Bose 統計の区別は十分小さくなり，Boltzmann 統計を良い近似として使用できる．

したがって，粒子の熱的ド・ブロイ波長が平均粒子間距離より十分小さい場合には，量子統計の違いを無視してよい．

なお，この結論は量子統計に由来する交換効果が小さいことを示すものである．
粒子間相互作用が存在する場合，古典的な Boltzmann 分布においても相互作用ポテンシャルを残す必要があり，理想気体の状態方程式まで自動的に成立するわけではない．
