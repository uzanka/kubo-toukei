# 演習問題【5-A-23】

## 解答

### 1．量子統計からボルツマン統計への近似

質量 $m$ の粒子 $N$ 個からなる理想気体を考える．
粒子の内部構造は無視し，粒子間の相互作用がないものとする．

フェルミ・ディラック統計では，エネルギー $\varepsilon_r$ の1粒子状態 $r$ の平均占有数は，

```math
\langle n_r\rangle_{\mathrm F}
=\frac{1}{e^{(\varepsilon_r-\mu)/(kT)}+1}
```

である．
一方，ボース・アインシュタイン統計では，

```math
\langle n_r\rangle_{\mathrm B}
=\frac{1}{e^{(\varepsilon_r-\mu)/(kT)}-1}
```

である．
ここで， $\mu$ は化学ポテンシャル， $T$ は絶対温度， $k$ はボルツマン定数である．

ここで，

```math
e^{(\varepsilon_r-\mu)/(kT)}\gg1
\tag{1}
```

が成立するとする．
このとき，分母の $\pm1$ は指数関数に比べて無視できるため，どちらの統計でも，

```math
\boxed{
\langle n_r\rangle
\simeq e^{-(\varepsilon_r-\mu)/(kT)}
}
```

となる．
右辺はボルツマン統計における平均占有数である．
したがって，条件 (1) がすべての1粒子状態について成立すれば，フェルミ統計とボース統計のどちらもボルツマン統計で近似できる．

また，この条件は平均占有数が十分小さいこと，

```math
\langle n_r\rangle\ll1
```

に対応する．
以下では，この条件を粒子密度と熱的ド・ブロイ波長を用いて表す．

### 2．粒子数から化学ポテンシャルを求める

全粒子数 $N$ は，すべての1粒子状態の平均占有数の和であるため，

```math
N=\sum_r\langle n_r\rangle
```

と表される．
ボルツマン近似を代入すると，

```math
\begin{aligned}
N
&\simeq\sum_r e^{-(\varepsilon_r-\mu)/(kT)}\\
&=e^{\mu/(kT)}
\sum_r e^{-\varepsilon_r/(kT)}
\end{aligned}
\tag{2}
```

となる．

ここで，古典的な極限では，1粒子状態についての和を位相空間積分に置き換えることができる．
1粒子の位相空間では，体積 $h^3$ が状態数を数える基本単位に対応するため，

```math
\sum_r e^{-\varepsilon_r/(kT)}
\simeq
\frac1{h^3}
\int_Vd^3r
\int_{\mathbb R^3}
e^{-\mathbf p^2/(2mkT)}\,d^3p
```

である．
理想気体では運動エネルギーは位置に依存しないため，位置積分は体積 $V$ を与える．
よって，

```math
\sum_r e^{-\varepsilon_r/(kT)}
\simeq
\frac{V}{h^3}
\int_{\mathbb R^3}
e^{-\mathbf p^2/(2mkT)}\,d^3p
```

となる．

運動量ベクトル $\mathbf p=(p_x,p_y,p_z)$ の各成分について積分が分離できるため，

```math
\begin{aligned}
\int_{\mathbb R^3}
e^{-\mathbf p^2/(2mkT)}\,d^3p
&=
\left(
\int_{-\infty}^{\infty}
e^{-p_x^2/(2mkT)}\,dp_x
\right)^3\\
&=(2\pi mkT)^{3/2}
\end{aligned}
```

である．
ここではガウス積分の公式

```math
\int_{-\infty}^{\infty}e^{-ax^2}\,dx
=\sqrt{\frac{\pi}{a}}
\qquad(a>0)
```

を用いた．
したがって，

```math
\sum_r e^{-\varepsilon_r/(kT)}
\simeq
\frac{V(2\pi mkT)^{3/2}}{h^3}
```

を得る．
これを式 (2) に代入すると，

```math
N\simeq
e^{\mu/(kT)}
\frac{V(2\pi mkT)^{3/2}}{h^3}
```

となる．
よって，

```math
\boxed{
e^{\mu/(kT)}
\simeq
\frac NV\frac{h^3}{(2\pi mkT)^{3/2}}
}
\tag{3}
```

を得る．

### 3．平均粒子間距離と熱的ド・ブロイ波長の関係

粒子の運動エネルギーは，

```math
\varepsilon_r=\frac{\mathbf p^2}{2m}\geq0
```

であり，最小値は $\varepsilon_r=0$ である．
したがって，条件 (1) がすべての状態について成立するためには，最も厳しい条件である $\varepsilon_r=0$ の場合に，

```math
e^{-\mu/(kT)}\gg1
```

となればよい．
これは，

```math
e^{\mu/(kT)}\ll1
\tag{4}
```

と同値である．

式 (3) を式 (4) に代入すると，

```math
\frac NV\frac{h^3}{(2\pi mkT)^{3/2}}\ll1
```

となる．
これを整理すれば，

```math
\frac{h^3}{(2\pi mkT)^{3/2}}
\ll\frac VN
```

であり，両辺の立方根を取ると，

```math
\boxed{
\left(\frac VN\right)^{1/3}
\gg\frac{h}{\sqrt{2\pi mkT}}
}
\tag{5}
```

を得る．

ここで，熱的ド・ブロイ波長を

```math
\Lambda=\frac{h}{\sqrt{2\pi mkT}}
```

と定義すると，式 (5) は，

```math
\boxed{
\Lambda\ll\left(\frac VN\right)^{1/3}
}
```

となる．
左辺は粒子の熱運動に対応する波長の尺度であり，右辺は1粒子当たりの体積から見積もった平均粒子間距離である．

問題で用いられているように，

```math
\lambda_B=\frac{h}{\sqrt{mkT}}
```

を de Broglie 波長の尺度として定義すれば，

```math
\Lambda=\frac{\lambda_B}{\sqrt{2\pi}}
```

であるから，

```math
\boxed{
\left(\frac VN\right)^{1/3}
\gg\frac{\lambda_B}{\sqrt{2\pi}}
}
```

とも表される．

さらに，粒子数密度 $\rho=N/V$ を用いれば，同じ条件は，

```math
\boxed{
\rho\Lambda^3\ll1
}
```

となる．
これは，熱的ド・ブロイ波長程度の体積に存在する平均粒子数が1より十分小さいことを意味する．

### 結論

以上より，平均粒子間距離が熱的ド・ブロイ波長より十分に大きい場合には，各1粒子状態の平均占有数が十分小さくなる．
そのため，フェルミ・ディラック統計とボース・アインシュタイン統計のいずれでも，平均占有数をボルツマン因子で近似できる．

したがって，

```math
\boxed{
\text{平均 de Broglie 波長}
\ll
\text{平均粒子間距離}
}
```

という条件のもとで，ボルツマン統計を十分に良い近似として用いることができる．
