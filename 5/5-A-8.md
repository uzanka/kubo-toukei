# 演習問題【5-A-8】

## 解答

### (i) 1個の振動子が量子状態 $n$ にある確率

#### 1．全系の熱力学的重率

振動数 $\nu$ の独立な量子振動子 $N$ 個からなる系を考える．
各振動子のエネルギー固有値は

```math
\epsilon_n=\left(n+\frac12\right)h\nu,
\qquad n=0,1,2,\ldots
```

である．
ここで $h$ はプランク定数である．

全系のエネルギーを $E$ とすると，

```math
E=\sum_{i=1}^{N}\left(n_i+\frac{1}{2}\right)h\nu
=\frac{N}{2}h\nu+Mh\nu
```

と書ける．
ただし，

```math
M=\sum_{i=1}^{N}n_i
```

は全振動子の量子数の総和である．

したがって，全系のエネルギーが指定されたとき， $N$ 個の非負整数 $n_1,\ldots,n_N$ の和が $M$ となる組合せの数を求めればよい．
この組合せの数，すなわち熱力学的重率は

```math
W_M=\frac{(M+N-1)!}{M!(N-1)!}
```

である．
これは， $M$ 個の同じものを $N$ 個の振動子に分配する場合の組合せの数である．

#### 2．特定の振動子が状態 $n$ にある確率

特定の1個の振動子が量子状態 $n$ にあるとする．
この振動子のエネルギーは

```math
\epsilon_n=\left(n+\frac{1}{2}\right)h\nu
```

であるため，残りの $N-1$ 個の振動子がもつエネルギーは

```math
\begin{aligned}
E'
&=E-\epsilon_n\\
&=\frac{N-1}{2}h\nu+(M-n)h\nu
\end{aligned}
```

となる．
よって，残りの振動子に分配される量子数の総和は $M-n$ である．
この条件を満たす残りの系の重率は

```math
W'_{M-n}
=\frac{(M-n+N-2)!}{(M-n)!(N-2)!}
```

となる．

等重率の原理によれば，指定された量子状態にある確率は，その条件を満たす状態数を全状態数で割ったものである．
したがって， $0\leq n\leq M$ に対して，

```math
P(n)=\frac{W'_{M-n}}{W_M}
```

であり，階乗を展開すると，

```math
\boxed{
P(n)=
\frac{(N-1)M!}{(M-n)!}
\frac{(M+N-n-2)!}{(M+N-1)!}
}
```

となる．
さらに，積の形に書き直すと，

```math
P(n)=
\frac{(N-1)M(M-1)\cdots(M-n+1)}
{(M+N-1)(M+N-2)\cdots(M+N-n-1)}
```

である．
ここで，分母には $n+1$ 個の因子があることに注意する．
$n>M$ のときは条件を満たす状態が存在しないため， $P(n)=0$ である．

#### 3．多数の振動子に対する近似

ここで， $N\gg1$ ， $M\gg1$ とし，量子数 $n$ は固定された有限の値とする．
このとき，

```math
\begin{aligned}
M(M-1)\cdots(M-n+1)&\simeq M^n,\\
(M+N-1)\cdots(M+N-n-1)&\simeq(M+N)^{n+1},\\
N-1&\simeq N
\end{aligned}
```

と近似できる．
したがって，

```math
\begin{aligned}
P(n)
&\simeq\frac{NM^n}{(M+N)^{n+1}}\\
&=\frac{N}{M+N}
\left(\frac{M}{M+N}\right)^n
\end{aligned}
```

となる．

ここで，1個の振動子当たりの平均励起量を

```math
\bar n=\frac{M}{N}
```

と定義する．
すると，

```math
\frac{N}{M+N}=\frac{1}{1+\bar n},
\qquad
\frac{M}{M+N}=\frac{\bar n}{1+\bar n}
```

であるから，

```math
\boxed{
P(n)\simeq
\frac{1}{1+\bar n}
\left(\frac{\bar n}{1+\bar n}\right)^n
}
\tag{1}
```

を得る．

#### 4．温度を用いた表現

この確率を温度 $T$ で表すため，逆温度

```math
\beta=\frac{1}{kT}
```

を導入する．
ここで $k$ はボルツマン定数である．
$\beta$ と $\bar n$ の関係は，全系の重率から導くことができる．

エントロピーを $S=k\ln W_M$ とし，大きな $M,N$ に対してスターリングの近似を用いると，

```math
\ln W_M
\simeq
(M+N)\ln(M+N)-M\ln M-N\ln N
```

となる．
エネルギー $E=Nh\nu/2+Mh\nu$ より，

```math
\beta=\frac{1}{k}
\left(\frac{\partial S}{\partial E}\right)_N
=\left(\frac{\partial\ln W_M}{\partial E}\right)_N
```

である．
$N$ を一定として $M$ で微分すると，

```math
\beta\simeq\frac{1}{h\nu}
\ln\frac{M+N}{M}
=\frac{1}{h\nu}
\ln\frac{1+\bar n}{\bar n}
```

を得る．
したがって，

```math
e^{-\beta h\nu}
=\frac{\bar n}{1+\bar n}
```

である．
これを式 (1) に代入すると，

```math
\frac{1}{1+\bar n}=1-e^{-\beta h\nu}
```

であるから，

```math
\boxed{
P(n)\simeq
(1-e^{-\beta h\nu})e^{-\beta nh\nu}
}
```

となる．
よって，温度 $T$ を用いれば，

```math
\boxed{
P(n)\simeq
(1-e^{-h\nu/(kT)})
e^{-nh\nu/(kT)}
}
```

である．

この確率分布は規格化されている．
実際，

```math
\begin{aligned}
\sum_{n=0}^{\infty}P(n)
&\simeq(1-e^{-\beta h\nu})
\sum_{n=0}^{\infty}e^{-\beta nh\nu}\\
&=(1-e^{-\beta h\nu})
\frac{1}{1-e^{-\beta h\nu}}\\
&=1
\end{aligned}
```

となる．
以上より，多数の振動子からなる系では，1個の振動子が量子状態 $n$ にある確率は，その励起エネルギー $nh\nu$ に対するボルツマン因子に比例することが示された．

### (ii) 理想気体の粒子の運動状態の確率

#### 1．理想気体の状態数

体積 $V$ の容器に入った，質量 $m$ の単原子分子 $N$ 個からなる理想気体を考える．
全エネルギーは各粒子の運動エネルギーの和であり，

```math
E=\sum_{i=1}^{N}\frac{\boldsymbol p_i^2}{2m}
```

である．
ここで $\boldsymbol p_i$ は第 $i$ 粒子の運動量ベクトルである．

例題 [2] の結果より，エネルギー $E$ 以下の位相空間状態数は，定数係数を明示すると，

```math
\Omega_0(E,N)
=
\frac{V^N}{h^{3N}N!}
\frac{(2\pi mE)^{3N/2}}
{\Gamma(3N/2+1)}
```

と表される．
したがって， $E,N,V,m$ 以外のエネルギーに依存しない因子をまとめれば，

```math
\Omega_0(E,N)=C_N E^{3N/2}
```

と書ける．
ここで $C_N$ は $E$ に依存しない定数である．

全エネルギーが $E$ 付近の幅 $\delta E$ に入る状態数，すなわち熱力学的重率は，

```math
W(E,N)\simeq
\frac{\partial\Omega_0(E,N)}{\partial E}\delta E
```

である．
よって，

```math
W(E,N)\propto E^{3N/2-1}
```

となる．
この薄いエネルギー殻に含まれる状態数を使うことで，全エネルギーが指定された系の状態を数えることができる．

#### 2．1個の粒子の運動状態を指定する

系の中の1個の粒子の運動量を $\boldsymbol p$ とし，その運動エネルギーを

```math
\epsilon=\frac{\boldsymbol p^2}{2m}
```

とする．
この粒子の運動状態を指定すると，残りの $N-1$ 個の粒子がもつ全エネルギーは $E-\epsilon$ である．
したがって，残りの粒子について可能な状態数は，エネルギー $E-\epsilon$ における $N-1$ 粒子系の熱力学的重率で与えられる．

等重率の原理から，指定した粒子の運動量状態に対応する確率密度は，

```math
\rho(\boldsymbol p)
\propto
\frac{W(E-\epsilon,N-1)}{W(E,N)}
```

と表される．
ここで，運動量は連続変数であるため， $\rho(\boldsymbol p)$ は運動量空間における確率密度を意味する．

前節で求めた重率のエネルギー依存性を代入すると，

```math
\rho(\boldsymbol p)
\propto
\frac{(E-\epsilon)^{3(N-1)/2-1}}
{E^{3N/2-1}}
```

となる．
$E$ は全系に対して固定されているので， $\epsilon$ に依存しない因子を比例定数に吸収すれば，

```math
\boxed{
\rho(\boldsymbol p)
\propto
\left(1-\frac{\epsilon}{E}\right)^{3(N-1)/2-1}
}
\tag{2}
```

を得る．

#### 3．熱力学的極限

$N\gg1$ とし，1個の粒子のエネルギー $\epsilon$ は全エネルギー $E$ に比べて十分小さいものとする．
すなわち，

```math
\frac{\epsilon}{E}\ll1
```

である．
式 (2) の対数を取ると，

```math
\ln\rho(\boldsymbol p)
=C+
\left(\frac{3(N-1)}{2}-1\right)
\ln\left(1-\frac{\epsilon}{E}\right)
```

となる．
ここで $C$ は $\boldsymbol p$ に依存しない定数である．

$x\ll1$ に対する近似 $\ln(1-x)\simeq-x$ を用いると，

```math
\ln\rho(\boldsymbol p)
\simeq C-
\left(\frac{3(N-1)}{2}-1\right)
\frac{\epsilon}{E}
```

を得る．

単原子分子からなる古典的理想気体では，熱力学的極限において内部エネルギーと温度の関係は

```math
E=\frac{3}{2}NkT
```

である．
また $N\gg1$ では，

```math
\frac{\frac{3}{2}(N-1)-1}{E}
\simeq\frac{\frac{3}{2}N}{E}
=\frac{1}{kT}
```

となる．
したがって，

```math
\ln\rho(\boldsymbol p)
\simeq C-\frac{\epsilon}{kT}
```

であり，指数関数に戻せば，

```math
\rho(\boldsymbol p)
\propto e^{-\epsilon/(kT)}
```

を得る．
ここに $\epsilon=\boldsymbol p^2/(2m)$ を代入すると，

```math
\boxed{
\rho(\boldsymbol p)
\propto
\exp\left(-\frac{\boldsymbol p^2}{2mkT}\right)
}
```

となる．
よって，理想気体において，粒子の特定の運動量状態に対する確率密度は，その運動エネルギー $\epsilon$ に対するボルツマン因子

```math
\boxed{
e^{-\epsilon/(kT)}
}
```

に比例することが示された．

なお，ここで導いたのは運動量状態に対する確率密度である．
粒子のエネルギー $\epsilon$ のみについて確率密度を求める場合には，同じエネルギーをもつ運動量状態の数も考慮するため，エネルギー分布には別途状態密度の因子が現れる．
