# 演習問題【5-A-22】

## 解答

### 1．Fermi 統計と Bose 統計の判定原理

量子力学では，粒子の統計性はその粒子のスピンと関係している．
スピンが整数である粒子はボソンと呼ばれ，Bose 統計に従う．
一方，スピンが半整数である粒子はフェルミオンと呼ばれ，Fermi 統計に従う．
これはスピンと統計性の関係として知られる原理である．

陽子 $\mathrm P$ ，中性子 $\mathrm N$ ，電子 $\mathrm e^-$ ，陽電子 $\mathrm e^+$ は，いずれもスピン $1/2$ のフェルミ粒子であり，Fermi 統計に従う．

これらのフェルミ粒子から構成される複合粒子については，構成するフェルミ粒子の総数を数えることで統計性を判定できる．
スピン $1/2$ の粒子を偶数個合成すると全スピンは整数となり，奇数個合成すると全スピンは半整数となる．
軌道角運動量は整数であるため，これを加えても整数・半整数の区別は変わらない．
したがって，

- 構成するフェルミ粒子が偶数個ならば，Bose 統計に従う．
- 構成するフェルミ粒子が奇数個ならば，Fermi 統計に従う．

この原理を各粒子に適用する．

### 2．各粒子の分類

#### （1）$\alpha$ 粒子

$\alpha$ 粒子はヘリウム原子核であり，陽子2個と中性子2個からなる．
したがって，

```math
\alpha=2\mathrm P+2\mathrm N
```

である．
構成するフェルミ粒子の総数は

```math
2+2=4
```

であり，偶数である．
よって， $\alpha$ 粒子は **Bose 統計に従うボソン** である．

#### （2）${}^3\mathrm{He}$

${}^3\mathrm{He}$ は陽子2個，中性子1個，電子2個からなる中性原子である．
したがって，

```math
{}^3\mathrm{He}=2\mathrm P+\mathrm N+2\mathrm e^-
```

である．
構成するフェルミ粒子の総数は

```math
2+1+2=5
```

であり，奇数である．
よって， ${}^3\mathrm{He}$ は **Fermi 統計に従うフェルミオン** である．

#### （3）$\mathrm{H}_2$ 分子

水素分子 $\mathrm{H}_2$ は，水素原子2個からなる．
各水素原子は陽子1個と電子1個を含むため，

```math
\mathrm{H}_2=2(\mathrm P+\mathrm e^-)
```

である．
構成するフェルミ粒子の総数は

```math
2(1+1)=4
```

であり，偶数である．
よって， $\mathrm{H}_2$ 分子は **Bose 統計に従うボソン** である．

#### （4）陽電子 $\mathrm e^+$

陽電子は，それ自体がスピン $1/2$ のフェルミ粒子である．
構成するフェルミ粒子の数は1個であり，奇数である．
したがって，陽電子は **Fermi 統計に従うフェルミオン** である．

#### （5）${}^6\mathrm{Li}^+$ イオン

${}^6\mathrm{Li}$ の原子核は陽子3個と中性子3個からなる．
リチウムの原子番号は3であり， $\mathrm{Li}^+$ は電子を1個失ったイオンであるため，電子は2個である．
したがって，

```math
{}^6\mathrm{Li}^+
=3\mathrm P+3\mathrm N+2\mathrm e^-
```

である．
構成するフェルミ粒子の総数は

```math
3+3+2=8
```

であり，偶数である．
よって， ${}^6\mathrm{Li}^+$ イオンは **Bose 統計に従うボソン** である．

#### （6）${}^7\mathrm{Li}^+$ イオン

${}^7\mathrm{Li}$ の原子核は陽子3個と中性子4個からなり， $\mathrm{Li}^+$ の電子数は2個である．
したがって，

```math
{}^7\mathrm{Li}^+
=3\mathrm P+4\mathrm N+2\mathrm e^-
```

である．
構成するフェルミ粒子の総数は

```math
3+4+2=9
```

であり，奇数である．
よって， ${}^7\mathrm{Li}^+$ イオンは **Fermi 統計に従うフェルミオン** である．

### 3．分類結果のまとめ

| 粒子 | 構成するフェルミ粒子の総数 | 偶奇 | 統計性 |
|---|---:|---|---|
| $\alpha$ 粒子 | $2+2=4$ | 偶数 | Bose 統計 |
| ${}^3\mathrm{He}$ | $2+1+2=5$ | 奇数 | Fermi 統計 |
| $\mathrm{H}_2$ 分子 | $2(1+1)=4$ | 偶数 | Bose 統計 |
| 陽電子 $\mathrm e^+$ | $1$ | 奇数 | Fermi 統計 |
| ${}^6\mathrm{Li}^+$ イオン | $3+3+2=8$ | 偶数 | Bose 統計 |
| ${}^7\mathrm{Li}^+$ イオン | $3+4+2=9$ | 奇数 | Fermi 統計 |

以上より，構成するフェルミ粒子の総数が偶数である $\alpha$ 粒子， $\mathrm{H}_2$ 分子， ${}^6\mathrm{Li}^+$ イオンは Bose 統計に従う．
一方，総数が奇数である ${}^3\mathrm{He}$ ，陽電子， ${}^7\mathrm{Li}^+$ イオンは Fermi 統計に従う．
