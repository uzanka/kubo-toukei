# 演習問題【5-A-22】

## 解答

粒子が Fermi 統計に従うか Bose 統計に従うかは，その粒子の全スピンの大きさによって決まる．

スピン $1/2$ を持つ粒子（陽子，中性子，電子，陽電子など）は，Fermi 統計に従う．
一方，これらを複数組み合わせて構成される複合粒子において，構成要素である Fermi 粒子の総数が偶数であれば，全スピンは整数となり，Bose 統計に従う．
逆に，構成要素である Fermi 粒子の総数が奇数であれば，全スピンは半整数となり，Fermi 統計に従う．

以下に，与えられた各粒子の構成要素と，それに基づく統計の分類を示す．

1. **$\alpha$ 粒子**
   構成： $2\text{P} + 2\text{N}$
   Fermi 粒子の総数： $2 + 2 = 4$ （偶数）
   したがって，Bose 統計に従う．

2. **${}^3\text{He}$**
   構成： $2\text{P} + \text{N} + 2\text{e}^-$
   Fermi 粒子の総数： $2 + 1 + 2 = 5$ （奇数）
   したがって，Fermi 統計に従う．

3. **$\text{H}_2$ 分子**
   構成： $2(\text{P} + \text{e}^-)$
   Fermi 粒子の総数： $2 \times (1 + 1) = 4$ （偶数）
   したがって，Bose 統計に従う．

4. **陽電子 ( $\text{e}^+$ )**
   構成： $1$ 個の Fermi 粒子
   Fermi 粒子の総数： $1$ （奇数）
   したがって，Fermi 統計に従う．

5. **${}^6\text{Li}^+$ イオン**
   構成： $3\text{P} + 3\text{N} + 2\text{e}^-$
   Fermi 粒子の総数： $3 + 3 + 2 = 8$ （偶数）
   したがって，Bose 統計に従う．

6. **${}^7\text{Li}^+$ イオン**
   構成： $3\text{P} + 4\text{N} + 2\text{e}^-$
   Fermi 粒子の総数： $3 + 4 + 2 = 9$ （奇数）
   したがって，Fermi 統計に従う．

## 解説

複合粒子の統計性を決定する原理について解説する．

量子力学において，粒子の種類はスピン量子数 $s$ によって分類される．
スピン $s$ が整数（ $0, 1, 2, \dots$ ）の粒子をボソン（Bose 統計に従う粒子），スピン $s$ が半整数（ $1/2, 3/2, \dots$ ）の粒子をフェルミオン（Fermi 統計に従う粒子）と呼ぶ．

素粒子である陽子 ( $\text{P}$ )，中性子 ( $\text{N}$ )，電子 ( $\text{e}^-$ )，陽電子 ( $\text{e}^+$ ) は，すべてスピン $1/2$ を持つフェルミオンである．

複数のフェルミオンを組み合わせて一つの複合粒子を作る場合，その複合粒子の全スピン $\mathbf{S}_{\text{total}}$ は，構成要素の個別のスピン $\mathbf{s}_i$ のベクトル和として表される：

$$\mathbf{S}_{\text{total}} = \sum_{i=1}^{n} \mathbf{s}_i$$

ここで，スピンの合成則に基づくと，スピン $1/2$ の粒子を $n$ 個合成した場合，全スピンの量子数 $S$ がとりうる値は，構成要素の数 $n$ が偶数であれば整数となり，奇数であれば半整数となる．
具体的には，全スピンの大きさ $S$ がとりうる値は，

$$S = \frac{n}{2}, \frac{n}{2}-1, \dots, \text{0 または } \frac{1}{2}$$

である．

したがって，複合粒子のスピン統計性は，構成するフェルミオンの総数 $n$ の偶奇のみによって判定できる：
- $n$ が偶数 $\implies S$ は整数 $\implies$ Bose 統計
- $n$ が奇数 $\implies S$ は半整数 $\implies$ Fermi 統計

この性質を用いることで，複雑な構成を持つ原子核や分子であっても，構成要素となるフェルミオンの数を数えるだけで，その粒子がどのような統計に従うかを容易に判断することができる．
