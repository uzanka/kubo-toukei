# 演習問題【5-A-11】

## 解答

座標 $x$ が時間とともに変化する断熱過程を考える．
座標の変化速度を

```math
v=\frac{dx}{dt}
```

とおく．
断熱過程では外界との熱の出入りがないため，エントロピー増大の原理より，

```math
\frac{dS}{dt}\geq0
```

が成立する．
この条件を用いて， $x$ を極めてゆっくり変化させたときにエントロピーが変化しないことを示す．

### 1．エントロピーの時間変化率の展開

座標 $x$ を固定すれば，その変化速度は $v=0$ であり，座標の変化に伴うエントロピーの時間変化率もゼロとなる．
したがって， $dS/dt$ を $v$ の関数として表し， $v=0$ の近傍で展開すると，

```math
\frac{dS}{dt}
=c_1v+c_2v^2+c_3v^3+\cdots
```

となる．

ここで，断熱過程ではエントロピー増大の原理により， $v$ の正負によらず $dS/dt\geq0$ でなければならない．
もし $c_1\neq0$ であれば， $v$ の符号を $c_1$ と反対に選ぶことで， $v$ が十分に小さいときに

```math
\frac{dS}{dt}\simeq c_1v<0
```

となり，エントロピー増大の原理に反する．
よって，

```math
c_1=0
```

である．

したがって， $dS/dt$ は少なくとも $v$ の2次から始まり，

```math
\boxed{
\frac{dS}{dt}=Av^2+O(v^3)
}
```

と表せる．
ここで $A$ は係数であり， $O(v^3)$ は $v$ の3次以上の項を表す．
エントロピー増大の原理から，2次の項が最初の非零項であれば $A>0$ である．
2次の項もゼロの場合には，さらに高次の項から始まることもある．
なお，エントロピー増大の原理だけから，すべての奇数次の項がゼロになるとは限らない．

### 2．準静的極限におけるエントロピー変化

$v\neq0$ のとき，連鎖律より，

```math
\frac{dS}{dx}
=\frac{dS/dt}{dx/dt}
```

である．
前節の結果を代入すると，

```math
\begin{aligned}
\frac{dS}{dx}
&=\frac{Av^2+O(v^3)}{v}\\
&=Av+O(v^2)
\end{aligned}
```

となる．
したがって，

```math
\lim_{v\to0}\frac{dS}{dx}=0
```

を得る．

これは，座標 $x$ を変化させる速度を限りなく小さくすると，座標の微小変化に伴うエントロピーの変化もゼロに近づくことを意味する．

さらに，有限の座標変化 $x_i\to x_f$ に対するエントロピー変化は，

```math
\Delta S
=\int_{x_i}^{x_f}\frac{dS}{dx}\,dx
```

である．
座標を変化させる速度を区間全体で一様にゼロへ近づけると，被積分関数 $dS/dx$ もゼロへ近づく．
したがって，準静的極限では，

```math
\boxed{
\Delta S\to0
}
```

となる．

以上より，座標 $x$ を極めてゆっくりと変化させる準静的断熱過程では，エントロピーは一定に保たれる．
すなわち，

```math
\boxed{
S(x_f)=S(x_i)
}
```

である．
これが求める結果である．
