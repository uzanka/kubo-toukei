# 演習問題【5-A-11】

## 解答

準静的断熱過程において，座標 $x$ の変化速度を

```math
v=\frac{dx}{dt}
```

とおく．
ここで考える $S$ は熱力学的エントロピーであり，ハミルトン力学における微視的な分布の細粒度ギブズエントロピーではない．

以下では，問題のヒントに従い，準平衡的な熱力学的記述を用いる．
同一の初期平衡状態，外部条件および駆動条件によって指定される平衡状態の枝を $\alpha$ とする．
この枝は，エントロピー一定を条件として定義するのではなく，初期状態，状態方程式および外部条件によって指定する．

この枝に沿った操作について，有限の操作速度におけるエントロピー生成率が

```math
\frac{dS}{dt}=g_\alpha(x,v)
```

と表されるものとする．
ここでは，局所平衡が成立し，エントロピー生成率が $x$ と $v$ で記述できることを仮定する．
内部状態の独立な緩和や履歴依存性はないものとする．

系は閉じた断熱系であり，仕事源との機械的仕事の授受はエントロピーの移動を伴わない．
したがって，エントロピー収支とエントロピー増大の原理から，

```math
\frac{dS}{dt}=\dot S_{\mathrm i}
=g_\alpha(x,v)\geq0
\tag{1}
```

となる．

まず，操作速度がゼロのとき，系は対応する平衡状態にあり，内部緩和によるエントロピー生成もないとする．
このとき，

```math
g_\alpha(x,0)=0
\tag{2}
```

である．

次に，同じ平衡状態から，正負両方向の十分小さな操作速度 $v$ が許されるものとする．
式 (1)，(2) より，固定した $x$ において $v=0$ は $g_\alpha(x,v)$ の局所最小点である．
したがって，

```math
\left.
\frac{\partial g_\alpha}{\partial v}
\right|_{v=0}=0
\tag{3}
```

となる．

さらに， $g_\alpha$ は $v$ について2回連続微分可能であり，考える $x$ のコンパクトな範囲 $I$ と，十分小さな速度 $|v|\leq\delta$ に対して，

```math
\left|
\frac{\partial^2g_\alpha}{\partial v^2}(x,v)
\right|\leq M
```

を満たす定数 $M$ が存在するとする．

テイラーの定理の積分形の剰余項を用いると，式 (2)，(3) から，

```math
g_\alpha(x,v)
=
v^2\int_0^1(1-\theta)
\frac{\partial^2g_\alpha}{\partial v^2}
(x,\theta v)\,d\theta
```

を得る．
したがって，

```math
\begin{aligned}
|g_\alpha(x,v)|
&\leq
v^2\int_0^1(1-\theta)M\,d\theta\\
&=\frac{M}{2}v^2 .
\end{aligned}
```

さらに，式 (1) より $g_\alpha(x,v)\geq0$ であるから，

```math
\boxed{
0\leq g_\alpha(x,v)\leq\frac{M}{2}v^2
}
\tag{4}
```

となる．

ここで，有限の変化量をもつ操作を考える．

```math
X\in C^1([s_i,s_f]),\qquad s_f>s_i
```

とし，

```math
X(s_i)=x_i,\qquad X(s_f)=x_f
```

を満たす経路 $X(s)$ を与える．
操作速度を小さくするため， $\varepsilon>0$ を用いて，

```math
x_\varepsilon(t)=X(s_i+\varepsilon t)
```

と定義する．
操作時間は

```math
T_\varepsilon=\frac{s_f-s_i}{\varepsilon}
```

である．
この定義から，

```math
x_\varepsilon(0)=X(s_i)=x_i,
```

```math
x_\varepsilon(T_\varepsilon)
=X(s_i+\varepsilon T_\varepsilon)
=X(s_f)=x_f
```

となり，指定した始点と終点が一致する．

また，速度は

```math
\frac{dx_\varepsilon}{dt}
=\varepsilon X'(s_i+\varepsilon t)
\tag{5}
```

である．
$X'$ はコンパクト区間上で有界なので， $\varepsilon\to0^+$ とすれば，操作中の速度は一様にゼロへ収束する．

式 (4)，(5) を時間積分すると，

```math
\begin{aligned}
0
&\leq
S_\varepsilon(T_\varepsilon)-S_\varepsilon(0)\\
&=
\int_0^{T_\varepsilon}
g_\alpha\left(
x_\varepsilon(t),
\frac{dx_\varepsilon}{dt}
\right)dt\\
&\leq
\frac{M}{2}
\int_0^{T_\varepsilon}
\varepsilon^2
\left|X'(s_i+\varepsilon t)\right|^2dt .
\end{aligned}
```

ここで，

```math
s=s_i+\varepsilon t,\qquad
dt=\frac{ds}{\varepsilon}
```

と変数変換すれば，

```math
\begin{aligned}
0
&\leq
S_\varepsilon(T_\varepsilon)-S_\varepsilon(0)\\
&\leq
\frac{M\varepsilon}{2}
\int_{s_i}^{s_f}|X'(s)|^2ds .
\end{aligned}
\tag{6}
```

$X'$ は連続関数なので，右辺の積分は有限である．
よって，

```math
\lim_{\varepsilon\to0^+}
\left[
S_\varepsilon(T_\varepsilon)-S_\varepsilon(0)
\right]=0
\tag{7}
```

となる．

最後に，準静的極限では，操作の始点と終点の状態が，それぞれ同じ平衡状態の枝 $\alpha$ 上の平衡状態に収束し，エントロピーがその極限で連続であるとする．
すなわち，

```math
\lim_{\varepsilon\to0^+}S_\varepsilon(0)
=S_{\mathrm{eq},\alpha}(x_i),
```

```math
\lim_{\varepsilon\to0^+}S_\varepsilon(T_\varepsilon)
=S_{\mathrm{eq},\alpha}(x_f).
```

この条件では，操作後に別途行う有限のエントロピー生成を伴う緩和過程は含めない．

これらを式 (7) に適用すると，

```math
S_{\mathrm{eq},\alpha}(x_f)
-S_{\mathrm{eq},\alpha}(x_i)=0
```

を得る．
始点 $x_i$ と終点 $x_f$ は，同じ平衡状態の枝 $\alpha$ 上で任意に選べるので，

```math
\boxed{
S_{\mathrm{eq},\alpha}(x)=\text{一定}
}
```

となる．

したがって，準静的断熱過程においては，熱力学的エントロピーは変化しない．

### 適用範囲について

以上の証明は，問題のヒントに沿った準平衡的な熱力学的記述の下で成立する．
特に，エントロピー生成率が $g_\alpha(x,\dot x)$ で表されること，操作速度ゼロで平衡状態にあること，および準静的極限で端点が対応する平衡状態に収束することを用いた．

式 (5.35) のハミルトニアンの変化だけから，これらの性質が任意の孤立ハミルトン系について自動的に導かれるわけではない．
微視的な細粒度ギブズエントロピーはリウヴィルの定理によって保存される一方，ここで扱った熱力学的エントロピーは平衡状態に対して定義される量である．
したがって，両者を混同せず，上記の準平衡的な熱力学的条件の下で結論を理解する必要がある．
