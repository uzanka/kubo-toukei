# 演習問題【5-B-28】

## 解答

本問題では，結晶内部から表面へ原子を移動させることで生じる「Schottky（ショットキー）型」の欠陥について，熱平衡状態における欠陥の数 $n$ を求める．

### 1．物理的状況の設定

まず，系の状態を整理する．
完全結晶において， $N$ 個の原子が規則正しく格子点に配置されている．
ここから $n$ 個の原子を結晶内部の格子点から結晶の表面へと移動させる．
このとき，以下の変化が生じる．
- 結晶内部には，原子がいなくなった空の格子点（空孔，または孔）が $n$ 個生じる．
- 結晶の表面には，移動してきた $n$ 個の原子が配置される．
- 全体としての格子点の総数は，もともとの $N$ 個に，内部から空いた $n$ 個分が加わり， $N+n$ 個となる．

したがって，この不完全結晶の状態は，「 $N+n$ 個の格子点のうち， $n$ 個が空孔であり，$N$ 個が原子である」という配置の組み合わせとして記述できる．

### 2．エントロピーの導出

統計力学において，系のエントロピー $S$ は，その状態がとり得る微視的な状態の数（配置の数） $W$ を用いて，ボルツマンの原理により次のように表される．

$$S = k \ln W$$

ここで， $k$ はボルツマン定数である．

$N+n$ 個の格子点から $n$ 個の空孔の位置を選ぶ組み合わせの数 $W$ は，次のように与えられる．

$$W = \frac{(N+n)!}{n!N!}$$

この $\ln W$ を計算するために，スターリングの近似公式 $\ln M! \approx M \ln M - M$ （ $M$ が十分に大きいとき）を用いる．

$$\ln W = \ln(N+n)! - \ln n! - \ln N!$$

$$\ln W \approx (N+n) \ln (N+n) - (N+n) - [n \ln n - n] - [N \ln N - N]$$

$$\ln W \approx (N+n) \ln (N+n) - N - n - n \ln n + n - N \ln N + N$$

$$\ln W \approx (N+n) \ln (N+n) - n \ln n - N \ln N$$

これより，エントロピー $S(n)$ は次のように求まる．

$$S(n) = k [(N+n) \ln (N+n) - n \ln n - N \ln N] \quad \cdots (1)$$

### 3．エネルギーと自由エネルギーの構成

次に，系のエネルギー $E(n)$ を考える．
1個の原子を内部から表面へ移動させるのに必要なエネルギーを $w$ とする．
$n$ 個の原子を移動させたときの全エネルギーの変化（内部エネルギー）は，

$$E(n) = nw \quad \cdots (2)$$

となる．

熱力学において，温度 $T$ の系が平衡状態にあるとき，ヘルムホルツの自由エネルギー $F$ が最小となる．
自由エネルギー $F$ は，内部エネルギー $E$ とエントロピー $S$ を用いて次のように定義される．

$$F(n) = E(n) - T S(n)$$

式 (1) および (2) を代入すると，

$$F(n) = nw - kT \{(N+n) \ln (N+n) - n \ln n - N \ln N\} \quad \cdots (3)$$

となる．

### 4．平衡状態の導出

自由エネルギー $F(n)$ を最小にする $n$ を求めるため， $n$ に関する微分を行い，その値を $0$ と置く．

$$\left( \frac{\partial F}{\partial n} \right)_{T,N} = 0$$

式 (3) を $n$ で微分する．

$$\frac{\partial F}{\partial n} = w - kT \left[ \frac{\partial}{\partial n} \{(N+n) \ln (N+n) - n \ln n - N \ln N\} \right]$$

ここで，括弧内の微分を計算すると，

$$\frac{\partial}{\partial n} \{(N+n) \ln (N+n) - n \ln n - N \ln N\}$$

$$= \left[ 1 \cdot \ln(N+n) + (N+n) \cdot \frac{1}{N+n} \right] - \left[ 1 \cdot \ln n + n \cdot \frac{1}{n} \right] - 0$$

$$= \ln(N+n) + 1 - \ln n - 1$$

$$= \ln\left( \frac{N+n}{n} \right)$$

したがって，

$$\frac{\partial F}{\partial n} = w - kT \ln\left( \frac{N+n}{n} \right) = 0$$

となる．
これを整理すると，

$$kT \ln\left( \frac{N+n}{n} \right) = w$$

$$\ln\left( \frac{N+n}{n} \right) = \frac{w}{kT}$$

$$\frac{N+n}{n} = e^{w/kT}$$

両辺の逆数をとると，

$$\frac{n}{N+n} = e^{-w/kT} \quad \cdots (4)$$

が得られる．
これが前半の示すべき式である．

また，問題の条件 $n \ll N$ （欠陥の数は原子の総数に比べて極めて少ない）を用いると，分母において $N+n \approx N$ とみなせるため，

$$\frac{n}{N} \cong e^{-w/kT} \quad \text{すなわち} \quad n \cong Ne^{-w/kT}$$

が得られる．
これにより，後半の式も示された．

## 解説

この問題は，固体物理学における「欠陥の熱平衡」に関する基本的な問題である．

**Schottky 欠陥とは**
結晶の中に原子が欠けている部分（空孔）ができる現象を指す．
原子を無理やり動かすにはエネルギーが必要だが，一方で空孔ができることで「配置の仕方の数（エントロピー）」が増大する．

**エネルギーとエントロピーのトレードオフ**
熱力学的な平衡状態とは，「エネルギーを低く保ちたい（ $E$ を小さくしたい）」という性質と，「バラバラな状態（エントロピー $S$ を大きくしたい）」という性質のバランスが取れた状態である．
- $n$ を増やすと，エネルギー $E = nw$ は増大する（不利な方向）．
- $n$ を増やすと，空孔の配置のパターンが増え，エントロピー $S$ も増大する（有利な方向）．
自由エネルギー $F = E - TS$ は，この両者の「勝ち負け」を判定する指標であり，この $F$ が最も小さくなる $n$ が，自然界で実際に観測される欠陥の数となる．

**温度の影響**
導出された式 $n \cong Ne^{-w/kT}$ からわかるように，温度 $T$ が高くなると，指数関数の肩の絶対値が小さくなり，$n$ が急激に増大する．
これは高温になるほど熱運動が激しくなり，エネルギー的な不利を乗り越えて空孔が作られやすくなることを物理的に意味している．
