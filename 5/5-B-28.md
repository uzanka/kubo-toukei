# 演習問題【5-B-28】

## 解答

### 1．配置数とエントロピー

完全結晶において，原子は $N$ 個の格子点をすべて占めている．
ここから $n$ 個の原子を結晶内部から表面へ移動させると，内部には $n$ 個の空孔が生じる．
問題の設定では，表面に移動した原子の位置も含め，格子点の総数は $N+n$ 個となる．
したがって，欠陥が $n$ 個ある状態は， $N+n$ 個の格子点のうち， $n$ 個が空孔であり，残りの $N$ 個が原子で占められている状態である．

空孔の位置を $N+n$ 個の格子点から $n$ 個選ぶ方法の数は，組み合わせの公式より

```math
W(n)=\binom{N+n}{n}
=\frac{(N+n)!}{n!N!}
```

である．
空孔の位置が決まれば，残りの格子点には原子が配置されるため，この式が配置数となる．

ボルツマンの原理によれば，エントロピー $S(n)$ は配置数 $W(n)$ を用いて

```math
S(n)=k\ln W(n)
```

と表される．
ここで， $k$ はボルツマン定数である．
よって，

```math
S(n)=k\ln\frac{(N+n)!}{n!N!}
```

となる．

ここで，問題の条件 $1\ll n\ll N$ より，スターリングの近似公式

```math
\ln M!\simeq M\ln M-M
```

を用いることができる．
これを各階乗に適用すると，

```math
\begin{aligned}
\ln W(n)
&\simeq (N+n)\ln(N+n)-(N+n)\\
&\quad -n\ln n+n-N\ln N+N\\
&=(N+n)\ln(N+n)\\
&\quad -n\ln n-N\ln N
\end{aligned}
```

となる．
最後の式では， $-(N+n)+n+N=0$ であることを用いた．
したがって，エントロピーは

```math
\boxed{
S(n)\simeq k\bigl[
(N+n)\ln(N+n)-n\ln n-N\ln N
\bigr]
}
\tag{1}
```

と求められる．

### 2．エネルギーと自由エネルギー

原子を1個，結晶内部から表面へ移動させるのに必要なエネルギーが $w$ であるため， $n$ 個の原子を移動させたときのエネルギー変化は

```math
\boxed{
E(n)=nw
}
\tag{2}
```

である．

温度 $T$ が一定の熱平衡状態では，ヘルムホルツの自由エネルギー

```math
F(n)=E(n)-TS(n)
```

が最小となる．
これは，エネルギーを増加させる欠陥形成の効果と，配置数を増加させてエントロピーを大きくする効果の釣り合いによって，平衡状態が決まることを意味する．

式 (1)，(2) を代入すると，

```math
\begin{aligned}
F(n)
&=nw-kT\bigl[
(N+n)\ln(N+n)\\
&\qquad\qquad-n\ln n-N\ln N
\bigr]
\end{aligned}
\tag{3}
```

となる．

### 3．自由エネルギーの最小化

自由エネルギーを最小にする $n$ を求めるため， $T$ と $N$ を一定に保って，式 (3) を $n$ で微分する．
極値では一階微分がゼロとなるので，

```math
\left(\frac{\partial F}{\partial n}\right)_{T,N}=0
```

である．
まず，式 (3) の角括弧内を微分すると，

```math
\begin{aligned}
&\frac{\partial}{\partial n}
\bigl[(N+n)\ln(N+n)\\
&\qquad-n\ln n-N\ln N\bigr]\\
&=\ln(N+n)+1-\ln n-1\\
&=\ln\frac{N+n}{n}
\end{aligned}
```

となる．
ここでは，積の微分公式を用いており， $N\ln N$ は $n$ に依存しないため，その微分はゼロである．

したがって，

```math
\frac{\partial F}{\partial n}
=w-kT\ln\frac{N+n}{n}
```

であり，これをゼロと置くと，

```math
w-kT\ln\frac{N+n}{n}=0
```

を得る．
両辺を整理して，

```math
\ln\frac{N+n}{n}=\frac{w}{kT}
```

となる．
両辺の指数を取れば，

```math
\frac{N+n}{n}=e^{w/(kT)}
```

であるから，逆数を取ることにより，

```math
\boxed{
\frac{n}{N+n}=e^{-w/(kT)}
}
\tag{4}
```

が得られる．
これが示すべき第一の式である．

なお，この極値が最小値であることも確認できる．
もう一度微分すると，

```math
\begin{aligned}
\frac{\partial^2F}{\partial n^2}
&=-kT\left(\frac{1}{N+n}-\frac{1}{n}\right)\\
&=kT\left(\frac{1}{n}-\frac{1}{N+n}\right)\\
&=\frac{kTN}{n(N+n)}>0
\end{aligned}
```

となる．
ここで $k>0$ ， $T>0$ ， $N>0$ ， $n>0$ を用いた．
したがって，得られた極値は自由エネルギーの最小値であり，熱平衡状態に対応する．

### 4．欠陥数が少ない場合の近似

問題では $n\ll N$ であるため，

```math
N+n\simeq N
```

と近似できる．
これを式 (4) に代入すると，

```math
\frac{n}{N}\simeq e^{-w/(kT)}
```

となる．
両辺に $N$ を掛ければ，

```math
\boxed{
n\simeq Ne^{-w/(kT)}
}
```

が得られる．
これが示すべき第二の式である．

以上より，Schottky 型欠陥の平衡数は，欠陥形成に必要なエネルギー $w$ が大きいほど少なくなり，温度 $T$ が高いほど多くなることが分かる．
