# 演習問題【5-C-35】

## 解答

### 1．スピン系のエントロピーと温度

エネルギーが $+\epsilon_0$ の状態にある粒子数を $N_+$ ，エネルギーが $-\epsilon_0$ の状態にある粒子数を $N_-$ とする．
粒子数と全エネルギーについて，

```math
N_++N_-=N
```

```math
E=(N_+-N_-)\epsilon_0
```

が成立する．
これらを解くと，

```math
N_+=\frac{N}{2}
\left(1+\frac{E}{N\epsilon_0}\right),
\qquad
N_-=\frac{N}{2}
\left(1-\frac{E}{N\epsilon_0}\right)
```

を得る．
エネルギーの範囲は，

```math
-N\epsilon_0\leq E\leq N\epsilon_0
```

である．

エネルギー $E$ に対応する微視的状態数は，

```math
\Omega(E)=\frac{N!}{N_+!N_-!}
```

である．
Boltzmannの原理 $S=k\ln\Omega$ より，

```math
S(E)=k\ln\frac{N!}{N_+!N_-!}
```

となる．

ここで， $N$ が十分大きいとしてStirlingの近似

```math
\ln m!\simeq m\ln m-m
```

を用いると，

```math
S(E)\simeq
k\left(N\ln N-N_+\ln N_+-N_-\ln N_-\right)
```

を得る．

```math
y=\frac{E}{N\epsilon_0}
```

とおいて整理すると，

```math
\begin{aligned}
S(E)=Nk\Bigg[\ln2-\frac12\Bigg\{&
(1-y)\ln(1-y)\\
&+(1+y)\ln(1+y)
\Bigg\}\Bigg]
\end{aligned}
\tag{1}
```

となる．
以下では，この熱力学的近似を用いる．

温度の定義は，

```math
\frac1T=\left(\frac{\partial S}{\partial E}\right)_N
```

である．
式（1）を微分すると，

```math
\begin{aligned}
\frac1T
&=-\frac{k}{2\epsilon_0}
\left[
-\ln(1-y)+\ln(1+y)
\right]\\
&=\frac{k}{2\epsilon_0}
\ln\frac{1-y}{1+y}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\frac1{T(E)}
=\frac{k}{2\epsilon_0}
\ln\frac{N\epsilon_0-E}{N\epsilon_0+E}
}
\tag{2}
```

を得る．

$E>0$ では，

```math
N\epsilon_0-E<N\epsilon_0+E
```

なので，式（2）の対数は負である．
よって，

```math
\boxed{T<0}
```

となる．
すなわち，このスピン系は負の温度を持つ．

これは，エネルギーを増加させると高エネルギー状態にある粒子が増え，微視的状態数が減少するためである．
二準位系のようにエネルギーに上限が存在する系では，このような負の温度が実現できる．

### 2．理想気体温度計と接触させたときの平衡条件

温度計は，体積 $V_g$ が一定の古典単原子理想気体とし，粒子数を $n$ とする．
温度計も熱力学的な温度を定義できるように $n\gg1$ とする．
また，スピン系の粒子数に比べて十分小さいものとし，

```math
1\ll n\ll N
```

を仮定する．

スピン系と温度計を接触させた後は，両者を合わせた系が外界から孤立しているとする．
初期のスピン系のエネルギーを $E$ ，温度計の初期エネルギーを $E_{g,i}$ とすると，全エネルギーは，

```math
E_0=E+E_{g,i}>0
```

である．
接触後のスピン系のエネルギーを $E'$ ，気体のエネルギーを $E_g$ とすれば，エネルギー保存則より，

```math
E_0=E'+E_g
```

となる．
したがって，

```math
E_g=E_0-E'
\tag{3}
```

である．

二つの系の相互作用エネルギーは無視できるとする．
平衡状態では，全系のエントロピー

```math
S_{\mathrm{total}}(E')
=S(E')+S_g(E_0-E')
```

が最大となる．
ここで $S_g$ は気体のエントロピーである．

古典単原子理想気体の熱力学的エントロピーは，固定体積のもとでエネルギー依存部分を

```math
S_g(E_g)=\frac32 nk\ln E_g+\text{const.}
```

と書ける．
ここで，対数の引数は適当な基準エネルギーで無次元化しているものとする．
したがって，

```math
\frac{\partial S_g}{\partial E_g}
=\frac{3nk}{2E_g}
=\frac1{T_g}
```

であり，

```math
E_g=\frac32 nkT_g
\tag{4}
```

となる．
この関係は，十分大きな粒子数を持つ古典理想気体の熱力学的近似である．

全エントロピーを $E'$ で微分すると，

```math
\frac{dS_{\mathrm{total}}}{dE'}
=
\frac{\partial S}{\partial E'}
-\frac{\partial S_g}{\partial E_g}
```

である．
平衡条件は，

```math
\frac{dS_{\mathrm{total}}}{dE'}=0
```

なので，

```math
\boxed{
\frac1{T(E')}=\frac1{T_g}
}
\tag{5}
```

となる．
つまり，平衡状態では両系の温度が等しい．

式（2），（3），（4）を式（5）に代入すると，

```math
\frac{k}{2\epsilon_0}
\ln\frac{N\epsilon_0-E'}{N\epsilon_0+E'}
=
\frac{3nk}{2(E_0-E')}
```

を得る．
両辺を整理すれば，

```math
\boxed{
\ln\frac{N\epsilon_0-E'}{N\epsilon_0+E'}
=
\frac{3n\epsilon_0}{E_0-E'}
}
\tag{6}
```

となる．
これが平衡エネルギー $E'$ を決める方程式である．

右辺は $E_g=E_0-E'>0$ である限り正である．
したがって左辺も正でなければならず，

```math
\boxed{E'<0}
```

が従う．
つまり，平衡後のスピン系は正のエネルギー状態から負のエネルギー状態へ移る．

### 3．平衡エネルギー $E'$ の近似計算

式（6）を解くため，

```math
x=-E'>0,
\qquad
q=\frac{x}{N\epsilon_0}
```

とおく．
すると，

```math
\ln\frac{1+q}{1-q}
=
\frac{3n\epsilon_0}{E_0+x}
\tag{7}
```

となる．

まず， $E_0>0$ と $0<q<1$ より，

```math
\ln\frac{1+q}{1-q}\geq 2q
```

である．
また，

```math
\frac{3n\epsilon_0}{E_0+x}
\leq\frac{3n\epsilon_0}{x}
```

なので，式（7）から，

```math
2q\leq\frac{3n}{Nq}
```

を得る．
したがって，

```math
\boxed{
q^2\leq\frac{3n}{2N}
}
\tag{8}
```

である．
$n\ll N$ なので， $q\ll1$ が確認できる．

そこで，対数を展開すると，

```math
\begin{aligned}
\ln\frac{1+q}{1-q}
&=\ln(1+q)-\ln(1-q)\\
&=2q+\frac{2q^3}{3}+\cdots\\
&\simeq 2q
\end{aligned}
```

となる．
式（7）に代入すると，

```math
\frac{2x}{N\epsilon_0}
\simeq\frac{3n\epsilon_0}{E_0+x}
```

であるから，

```math
x(E_0+x)\simeq\frac32 nN\epsilon_0^2
```

を得る．
この二次方程式を解き， $x>0$ の解を選べば，

```math
x\simeq
\frac{\sqrt{E_0^2+6nN\epsilon_0^2}-E_0}{2}
```

となる．
したがって，

```math
\boxed{
E'\simeq
-\frac{\sqrt{E_0^2+6nN\epsilon_0^2}-E_0}{2}
}
\tag{9}
```

である．

この式は， $n/N\ll1$ のもとで対数を一次近似した結果であり，初期全エネルギー $E_0$ の大きさを限定せずに使える．

特に，

```math
E_0^2\gg 6nN\epsilon_0^2
```

であれば，

```math
\sqrt{E_0^2+6nN\epsilon_0^2}
\simeq E_0+\frac{3nN\epsilon_0^2}{E_0}
```

と近似できる．
この場合には，

```math
\boxed{
E'\simeq-\frac{3nN\epsilon_0^2}{2E_0}
}
\tag{10}
```

となる．
この追加近似のもとでは，確かに $|E'|\ll E_0$ である．

一方，式（9）を用いれば，この追加条件が成立しない場合も扱える．

### 4．温度計が示す温度

式（4）より，平衡後の気体の温度は，

```math
T_g=\frac{2(E_0-E')}{3nk}
```

である．
式（9）を代入すると，

```math
E_0-E'
\simeq
\frac{E_0+\sqrt{E_0^2+6nN\epsilon_0^2}}{2}
```

なので，

```math
\boxed{
T_g\simeq
\frac{E_0+\sqrt{E_0^2+6nN\epsilon_0^2}}
{3nk}
}
\tag{11}
```

となる．

特に，式（10）の追加近似が成立する場合には，

```math
\boxed{
T_g\simeq\frac{2E_0}{3nk}
}
\tag{12}
```

となる．

また，温度計の粒子数を十分大きく保ちながら，スピン系に対する比 $n/N$ を小さくする極限を考える．
式（8）から，

```math
q\leq\sqrt{\frac{3n}{2N}}\longrightarrow0
```

となる．
平衡後のスピン系の温度は，

```math
T(E')
=
\frac{2\epsilon_0}
{k\ln\left(\dfrac{1+q}{1-q}\right)}
```

であるため， $q\to0$ では，

```math
T(E')\simeq\frac{\epsilon_0}{kq}
\longrightarrow+\infty
```

となる．
平衡条件から $T_g=T(E')$ であるので，温度計の示す温度も非常に大きな正の値になる．

ここでいう極限は，温度計の粒子数を文字どおりゼロにすることではなく，

```math
1\ll n\ll N
```

を保ちながら $n/N$ を十分小さくする熱力学的な極限である．
有限の粒子数を持つ温度計の温度が厳密に無限大になるわけではない．

### 5．物理的な意味

初期状態では，

```math
T_{\mathrm{spin}}<0,
\qquad
T_{\mathrm{gas}}>0
```

である．
負の温度は正の温度より高温側に位置する．
実際，気体へ微小エネルギー $dE_g>0$ を移すと，スピン系のエネルギーは $dE'=-dE_g$ だけ減少し，全エントロピーの変化は，

```math
dS_{\mathrm{total}}
=
\left(
\frac1{T_g}-\frac1{T_{\mathrm{spin}}}
\right)dE_g
```

となる．
初期状態では $1/T_g>0$ ， $1/T_{\mathrm{spin}}<0$ なので，この変化は正である．
したがって，エネルギーはスピン系から気体へ流れる．

最終的には両系の温度が等しくなり，スピン系は $E'<0$ の正の温度状態に移る．
温度計は大きな正の温度を示し，初期の負の温度をそのまま測定することはできない．

以上より，正のエネルギーを持つ負の温度のスピン系に理想気体温度計を接触させると，エネルギーはスピン系から温度計へ移り，平衡後には両者とも正の温度となる．
温度計をスピン系に比べて十分小さくすると，その示す温度は非常に大きくなる．
