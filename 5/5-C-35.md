# 演習問題【5-C-35】

## 解答

### 1．スピン系のエントロピーと温度

エネルギーが $+\epsilon_0$ の状態にある粒子数を $N_+$ ，エネルギーが $-\epsilon_0$ の状態にある粒子数を $N_-$ とする．
全粒子数が $N$ であるから，

```math
N_++N_-=N
```

である．
また，スピン系の全エネルギーを $E$ とすると，

```math
E=(N_+-N_-)\epsilon_0
```

である．
この2式を $N_+$ ， $N_-$ について解くと，

```math
N_+=\frac{N}{2}\left(1+\frac{E}{N\epsilon_0}\right),
\qquad
N_-=\frac{N}{2}\left(1-\frac{E}{N\epsilon_0}\right)
```

となる．
したがって，エネルギーの範囲は $-N\epsilon_0\leq E\leq N\epsilon_0$ である．

粒子のうち，どの $N_+$ 個がエネルギー $+\epsilon_0$ の状態にあるかを選ぶ方法の数が微視的状態数 $\Omega(E)$ である．
よって，

```math
\Omega(E)=\frac{N!}{N_+!N_-!}
```

となる．
ボルツマンの原理 $S=k\log\Omega$ により，エントロピーは

```math
S(E)=k\log\frac{N!}{N_+!N_-!}
```

で与えられる．
ここで， $k$ はボルツマン定数である．

粒子数 $N$ が十分大きいとして，Stirling の近似

```math
\log m!\simeq m\log m-m
```

を用いると，

```math
S(E)\simeq k\left(N\log N-N_+\log N_+-N_-\log N_-\right)
```

を得る．
先ほど求めた $N_+$ ， $N_-$ を代入して整理すれば，

```math
\begin{aligned}
S(E)=Nk\Bigg[\log 2-\frac12\Bigg\{&
\left(1-\frac{E}{N\epsilon_0}\right)
\log\left(1-\frac{E}{N\epsilon_0}\right)\\
+&
\left(1+\frac{E}{N\epsilon_0}\right)
\log\left(1+\frac{E}{N\epsilon_0}\right)
\Bigg\}\Bigg]
\end{aligned}
\tag{1}
```

となる．
以下では，この近似式を用いる．

熱力学的な温度 $T$ は，粒子数を一定に保ったとき，

```math
\frac{1}{T}=\left(\frac{\partial S}{\partial E}\right)_N
```

によって定義される．
式 (1) を $E$ で微分すると，

```math
\boxed{
\frac{1}{T(E)}
=\frac{k}{\epsilon_0}
\log\frac{N\epsilon_0-E}{N\epsilon_0+E}
}
\tag{2}
```

となる．

ここで $E>0$ ならば，

```math
N\epsilon_0-E<N\epsilon_0+E
```

であるため，式 (2) の対数の中身は $1$ より小さい．
したがって $1/T<0$ ，すなわち $T<0$ である．
このスピン系は負の温度を持つ状態にある．

### 2．理想気体温度計と接触させたときの平衡条件

次に，このスピン系に $n$ 個の分子からなる理想気体温度計を接触させる．
接触後のスピン系のエネルギーを $E'$ ，気体のエネルギーを $E_g$ とし，接触前の全エネルギーを $E_0$ とする．
外界とのエネルギーのやり取りがないとすれば，

```math
E_0=E'+E_g
```

が成り立つ．
したがって，

```math
E_g=E_0-E'
```

である．

二つの系が熱平衡に達したとき，全系の微視的状態数は

```math
\Omega_{\mathrm{total}}
=\Omega(E')\Omega_g(E_0-E')
```

で表される．
ここで $\Omega_g(E_g)$ は，エネルギー $E_g$ における気体の微視的状態数である．
平衡状態では，全系の微視的状態数が最大となる．
よって， $E'$ は

```math
\Omega(E')\Omega_g(E_0-E')=\max
\tag{3}
```

を満たす値として決まる．

理想気体の状態数は，エネルギーに依存する部分について，

```math
\Omega_g(E_g)\propto E_g^{3n/2}
```

と書ける．
したがって，式 (3) の両辺の対数をとり， $E'$ で微分すると，

```math
\frac{d\log\Omega(E')}{dE'}
-\frac{d\log\Omega_g(E_g)}{dE_g}=0
```

を得る．
エントロピーの定義 $S=k\log\Omega$ と温度の定義 $1/T=\partial S/\partial E$ から，

```math
\frac{d\log\Omega}{dE}=\frac{1}{kT}
```

である．
したがって，平衡条件は

```math
\boxed{
\frac{1}{T(E')}=\frac{1}{T_g(E_g)}
}
```

となる．
すなわち，平衡状態ではスピン系と気体の温度が等しい．

単原子理想気体の内部エネルギーは

```math
E_g=\frac32 nkT_g
```

であるから，

```math
\frac{1}{T_g}=\frac{3nk}{2E_g}
=\frac{3nk}{2(E_0-E')}
```

となる．
これと式 (2) を平衡条件に代入すると，

```math
\frac{k}{\epsilon_0}
\log\frac{N\epsilon_0-E'}{N\epsilon_0+E'}
=\frac{3nk}{2(E_0-E')}
```

を得る．
両辺から $k$ を消去して整理すれば，

```math
\boxed{
\log\frac{N\epsilon_0-E'}{N\epsilon_0+E'}
=\frac{3n\epsilon_0}{2(E_0-E')}
}
\tag{4}
```

となる．
これが平衡エネルギー $E'$ を決める方程式である．

### 3．平衡エネルギー $E'$ の近似計算

温度計はスピン系に比べて小さいとし，

```math
n\ll N
```

を仮定する．
このとき，平衡後のスピン系のエネルギーは $E'=0$ の近くにあると予想される．
そこで，

```math
\left|\frac{E'}{N\epsilon_0}\right|\ll1
```

として，式 (4) の左辺を近似する．

```math
\begin{aligned}
\log\frac{N\epsilon_0-E'}{N\epsilon_0+E'}
&=\log\left(1-\frac{E'}{N\epsilon_0}\right)
-\log\left(1+\frac{E'}{N\epsilon_0}\right)\\
&\simeq-\frac{E'}{N\epsilon_0}
-\frac{E'}{N\epsilon_0}\\
&=-\frac{2E'}{N\epsilon_0}
\end{aligned}
```

ここでは，$|x|\ll1$ に対して $\log(1+x)\simeq x$ となることを用いた．
これを式 (4) に代入すると，

```math
-\frac{2E'}{N\epsilon_0}
\simeq\frac{3n\epsilon_0}{2(E_0-E')}
```

となる．
両辺を整理して，

```math
E'\simeq-\frac{3nN\epsilon_0^2}{4(E_0-E')}
\tag{5}
```

を得る．

温度計は小さく，スピン系から移るエネルギーもスピン系の全エネルギーに比べて小さいため， $E'\ll E_0$ と近似できる．
したがって，式 (5) の分母について $E_0-E'\simeq E_0$ とすれば，

```math
\boxed{
E'\simeq-\frac{3nN\epsilon_0^2}{4E_0}
}
\tag{6}
```

となる．
初期の全エネルギーは正であり，温度計の初期エネルギーが十分小さいならば $E_0=O(N\epsilon_0)>0$ である．
よって，式 (6) から $E'<0$ であることが分かる．

さらに，

```math
\frac{|E'|}{N\epsilon_0}
\simeq\frac34\frac{n\epsilon_0}{E_0}
```

である．
$E_0=O(N\epsilon_0)$ であることを用いれば，

```math
\boxed{
\frac{|E'|}{N\epsilon_0}=O\left(\frac{n}{N}\right)\ll1
}
```

となる．
これは，最初に仮定した $|E'|/(N\epsilon_0)\ll1$ と整合しており，近似が妥当であることを示している．

### 4．温度計が示す温度

平衡後の気体の温度は，

```math
T_g=\frac{2(E_0-E')}{3nk}
```

である．
$E'$ は $E_0$ に比べて小さいので，

```math
\boxed{
T_g\simeq\frac{2E_0}{3nk}
}
\tag{7}
```

となる．
したがって，温度計の粒子数 $n$ がスピン系の粒子数 $N$ に比べて非常に小さいとき，温度計の示す温度は非常に大きな正の値となる．
特に， $N$ と初期エネルギー $E_0$ を固定して $n\to0$ とする極限では，式 (7) の温度は発散する．

結論として，正の全エネルギーを持つ負の温度のスピン系に小さな理想気体温度計を接触させると，スピン系のエネルギーは $E>0$ から $E'\simeq0^-$ へと大きく変化する．
その結果，負の温度状態はほぼ失われ，温度計は非常に大きな正の温度を示す．
温度計を系に比べて無限に小さくする極限では，その示す温度は $T_g\to+\infty$ となる．
ただし，有限の粒子数 $n$ を持つ温度計の温度が厳密に無限大になるわけではなく，無限大という結論は $n\to0$ の極限に関するものである．

### 補足：負の温度の物理的意味

負の温度は，温度の定義 $1/T=\partial S/\partial E$ において，エネルギーを増やすとエントロピーが減少する状態に対応する．
このスピン系では，エネルギーが正になると高エネルギー状態 $+\epsilon_0$ の粒子が低エネルギー状態 $-\epsilon_0$ の粒子より多くなり，負の温度が実現する．

一方，理想気体はエネルギーが増えると状態数が増加するため，通常の正の温度しか持たない．
負の温度の系と正の温度の系を接触させると，平衡に向かう過程でスピン系のエネルギーが減少し，気体がエネルギーを受け取る．
最終的にスピン系は $E'\simeq0^-$ に移り，両系は大きな正の温度で平衡する．
このため，理想気体温度計では，接触前の負の温度をそのまま測定することはできないのである．
