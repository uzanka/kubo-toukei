# 演習問題【4-A-7】

## 解答

曲面の両側の圧力差を，表面張力と曲面の曲率半径を用いて表すラプラスの公式

```math
\Delta p=\gamma\left(\frac{1}{\rho_1}+\frac{1}{\rho_2}\right)
```

を導出する．
ここで， $\Delta p=p'-p''$ は曲面の内側の圧力 $p'$ と外側の圧力 $p''$ の差， $\gamma$ は表面張力， $\rho_1,\rho_2$ は主曲率半径である．
以下では，外向きに曲面を移動させると囲まれた体積が増加する場合を考える．

### 1．熱力学的な平衡条件

曲面によって隔てられた二つの相を考え，内側の体積を $V'$ ，外側の体積を $V''$ ，境界面の面積を $\sigma$ とする．
全体積は一定であるため，

```math
dV''=-dV'
```

が成り立つ．
また，全エントロピーと各相の粒子数を一定に保つ仮想変化を考える．

この条件のもとでは，平衡状態で内部エネルギー $U$ が極小となる．
したがって，平衡状態からの一次の変化については

```math
dU=0
```

である．
圧力による仕事と表面エネルギーの変化を考慮すると，

```math
dU=-p'\,dV'-p''\,dV''+\gamma\,d\sigma
```

となる．
ここに $dV''=-dV'$ を代入すると，

```math
dU=(-p'+p'')\,dV'+\gamma\,d\sigma=0
```

を得る．
よって，

```math
(p'-p'')\,dV'=\gamma\,d\sigma
```

であるから，圧力差 $\Delta p=p'-p''$ は

```math
\boxed{
\Delta p=\gamma\frac{d\sigma}{dV'}
}
\tag{1}
```

と表される．
したがって，ラプラスの公式を導くには，曲面を微小距離だけ移動させたときの面積変化 $d\sigma$ と体積変化 $dV'$ の比を求めればよい．

### 2．曲面の微小領域における体積変化

曲面上の任意の点の近傍に，二つの主曲率方向に沿った微小な矩形領域を考える．
主曲率半径を $\rho_1,\rho_2$ ，それぞれの方向に対応する微小角を $\theta_1,\theta_2$ とする．
微小領域の各辺の長さは，それぞれ $\rho_1\theta_1$ ， $\rho_2\theta_2$ と近似できるため，その面積は

```math
\sigma=\rho_1\rho_2\theta_1\theta_2
```

である．

この領域を，曲面の法線方向に外向きに微小距離 $\delta\rho$ だけ移動させる．
微小距離が曲率半径に比べて十分小さいとき，移動による体積変化は，元の面積に移動距離を掛けたものとして近似できる．
したがって，

```math
dV'=\rho_1\rho_2\theta_1\theta_2\,\delta\rho
\tag{2}
```

となる．

### 3．曲面の微小領域における面積変化

曲面を法線方向に $\delta\rho$ だけ外向きに移動させると，主曲率方向に対応する半径は，それぞれ $\rho_1+\delta\rho$ ， $\rho_2+\delta\rho$ となる．
よって，移動後の面積は

```math
\sigma+d\sigma
=(\rho_1+\delta\rho)(\rho_2+\delta\rho)
\theta_1\theta_2
```

である．
これから元の面積を引くと，

```math
\begin{aligned}
d\sigma
&=\left[(\rho_1+\delta\rho)(\rho_2+\delta\rho)
-\rho_1\rho_2\right]\theta_1\theta_2\\
&=\left[(\rho_1+\rho_2)\delta\rho
+(\delta\rho)^2\right]\theta_1\theta_2
\end{aligned}
```

となる．
ここで， $\delta\rho$ は微小量であるため，二次の微小量 $(\delta\rho)^2$ を無視する．
すると，

```math
d\sigma\simeq
(\rho_1+\rho_2)\delta\rho\,\theta_1\theta_2
\tag{3}
```

を得る．

### 4．ラプラスの公式の導出

式 (2)，(3) より，面積変化と体積変化の比は

```math
\begin{aligned}
\frac{d\sigma}{dV'}
&=\frac{(\rho_1+\rho_2)\delta\rho\,
\theta_1\theta_2}
{\rho_1\rho_2\delta\rho\,\theta_1\theta_2}\\
&=\frac{\rho_1+\rho_2}{\rho_1\rho_2}\\
&=\frac{1}{\rho_1}+\frac{1}{\rho_2}
\end{aligned}
```

となる．
これを式 (1) に代入すると，

```math
\boxed{
\Delta p=\gamma\left(\frac{1}{\rho_1}
+\frac{1}{\rho_2}\right)
}
```

が得られる．
これがラプラスの公式である．

なお，平均曲率を

```math
H=\frac{1}{2}\left(\frac{1}{\rho_1}
+\frac{1}{\rho_2}\right)
```

と定義すれば，この公式は $\Delta p=2\gamma H$ と書ける．
特に，半径 $\rho$ の球面では $\rho_1=\rho_2=\rho$ であるため，

```math
\Delta p=\frac{2\gamma}{\rho}
```

となる．
この結果は，球面の半径が小さいほど内外の圧力差が大きくなることを示しているのである．
