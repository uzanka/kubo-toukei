# 演習問題【4-A-7】

## 解答

**【問題の目的】**

本問題では，曲面における表面張力 $\gamma$ が，その曲面の両側の圧力差 $\Delta p$ にどのように影響するかを示す「ラプラスの公式 (Laplace's formula)」を導出する．

**1. 熱力学的な平衡条件**

まず，二つの相（例えば液体と気体）の境界となる曲面が，平衡状態にあるための条件を考える．
系の内部エネルギーの変化を $dU$ とすると，平衡状態では，仮想的な微小変化に対して $dU \ge 0$ が成り立つ．
ここで，曲面が半径方向に $\delta\rho$ だけ移動したとすると，一次の微小変化のみを考慮する場合，エネルギーの変化は以下のようになる．

$$dU = (-p' + p'') dV' + \gamma \, d\sigma = 0$$

ここで，
- $p'$ は曲面の内側の圧力
- $p''$ は曲面の外側の圧力
- $\Delta p = p' - p''$ は圧力の差
- $dV'$ は移動したことによる体積の変化
- $d\sigma$ は移動したことによる表面積の変化
- $\gamma$ は表面張力

である．
これを整理すると，

$$\Delta p \, dV' = \gamma \, d\sigma \quad \implies \quad \Delta p = \gamma \frac{d\sigma}{dV'}$$

となる．
したがって，圧力差 $\Delta p$ を求めるには，微小な体積変化 $dV'$ に対する面積変化 $d\sigma$ の比率を計算すればよいことになる．

**2. 幾何学的な導出**

曲面の形状を記述するために，その地点における2つの主曲率半径 $\rho_1, \rho_2$ を用いる．
曲面上の微小な領域を，曲率線に沿った「矩形（長方形）」として考える．
この矩形の各辺を張る微小な角を $\theta_1, \theta_2$ とする．

この微小な矩形の面積 $A$ は，次のように表される．

$$A = \rho_1 \theta_1 \cdot \rho_2 \theta_2 = \rho_1 \rho_2 \theta_1 \theta_2$$

この面が，半径方向に $\delta\rho$ だけ移動したときの変化を考える．

**(i) 体積変化 $dV'$**

微小な矩形が厚さ $\delta\rho$ だけ移動したときの体積は，面積に厚さを掛けたものになる．

$$dV' = A \times \delta\rho = \rho_1 \rho_2 \theta_1 \theta_2 \delta\rho$$

**(ii) 面積変化 $d\sigma$**

面が移動した後の新しい面積 $A'$ は，半径が $\rho_1 + \delta\rho$ および $\rho_2 + \delta\rho$ になったものとして計算できる．

$$A' = (\rho_1 + \delta\rho) \theta_1 \cdot (\rho_2 + \delta\rho) \theta_2 = (\rho_1 + \delta\rho)(\rho_2 + \delta\rho) \theta_1 \theta_2$$

面積の変化 $d\sigma$ は，新しい面積と元の面積の差である．

$$d\sigma = A' - A = [(\rho_1 + \delta\rho)(\rho_2 + \delta\rho) - \rho_1 \rho_2] \theta_1 \theta_2$$

括弧の中を展開すると，

$$(\rho_1 + \delta\rho)(\rho_2 + \delta\rho) - \rho_1 \rho_2 = \rho_1 \rho_2 + \rho_1 \delta\rho + \rho_2 \delta\rho + (\delta\rho)^2 - \rho_1 \rho_2$$

$$= (\rho_1 + \rho_2) \delta\rho + (\delta\rho)^2$$

ここで， $\delta\rho$ は微小量であるため， $(\delta\rho)^2$ の項は無視できる（一次の近似）．
したがって，

$$d\sigma \approx (\rho_1 + \rho_2) \delta\rho \theta_1 \theta_2$$

**3. 圧力差の決定**

上で求めた $dV'$ と $d\sigma$ の比をとる．

$$\frac{d\sigma}{dV'} = \frac{(\rho_1 + \rho_2) \delta\rho \theta_1 \theta_2}{\rho_1 \rho_2 \theta_1 \theta_2 \delta\rho} = \frac{\rho_1 + \rho_2}{\rho_1 \rho_2} = \frac{1}{\rho_2} + \frac{1}{\rho_1}$$

これを最初の圧力差の式 $\Delta p = \gamma \frac{d\sigma}{dV'}$ に代入すると，

$$\Delta p = \gamma \left( \frac{1}{\rho_1} + \frac{1}{\rho_2} \right)$$

が得られる．
これがラプラスの公式である．

## 解説

**ラプラスの公式とは？**

この公式は，曲がった境界（例えば水滴の表面や泡の膜）において，曲率が大きくなる（半径 $\rho$ が小さくなる）ほど，内側と外側の圧力差 $\Delta p$ が大きくなることを示している．

**物理的な意味**

- **表面張力 $\gamma$**: 表面積を小さくしようとする力である．
曲面では，表面積を維持しようとする力と，圧力が押し返そうとする力がつり合っている．
- **曲率半径 $\rho_1, \rho_2$**: 曲面の「曲がり具合」を表す．
半径が小さいほど，急激に曲がっていることを意味する．
- **平均曲率**: $\frac{1}{\rho} = \frac{1}{2} \left( \frac{1}{\rho_1} + \frac{1}{\rho_2} \right)$ と定義されることが多く，公式は $\Delta p = \frac{2\gamma}{\rho}$ とも書ける．

**直感的な理解**

例えば，小さな水滴を想像してみる．
水滴が小さければ小さいほど，表面は急激に曲がっている（ $\rho$ が小さい）．
ラプラスの公式によれば，このとき水滴の内部の圧力は外気よりもずっと高くなければならない．
これは，表面張力が水滴を収縮させようとする力に対して，高い圧力がそれを支えている状態に対応している．
