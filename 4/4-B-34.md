# 演習問題【4-B-34】

## 解答

### （i）液滴の飽和蒸気圧 $p_r$ と半径 $r$ の関係

#### 1．液滴の力学的平衡条件

半径 $r$ の球形液滴を考える．
液滴内部の圧力を $p'$ ，液滴と接している蒸気の圧力を $p_r$ ，表面張力を $\gamma$ とする．

表面張力があるため，液滴内部の圧力は外部の蒸気圧よりも高くなる．
球形の液滴に対するラプラスの式より，

```math
p'-p_r=\frac{2\gamma}{r}
\tag{1}
```

である．
したがって，

```math
p'=p_r+\frac{2\gamma}{r}
\tag{2}
```

となる．

#### 2．液相と気相の化学的平衡条件

液滴と蒸気が平衡状態にあるとき，両相の化学ポテンシャルは等しい．
液相と気相の化学ポテンシャルをそれぞれ $\mu_l$ ， $\mu_g$ とすると，

```math
\mu_l(T,p')=\mu_g(T,p_r)
\tag{3}
```

である．

一方，液面が平面である場合の飽和蒸気圧を $p_\infty$ とする．
このときも液相と気相は平衡にあるため，

```math
\mu_l(T,p_\infty)=\mu_g(T,p_\infty)
\tag{4}
```

が成立する．

式（3），（4）から化学ポテンシャルの差を取ると，

```math
\begin{aligned}
&\mu_l(T,p')-\mu_l(T,p_\infty)\\
&\qquad=\mu_g(T,p_r)-\mu_g(T,p_\infty)
\end{aligned}
\tag{5}
```

を得る．

#### 3．化学ポテンシャルの圧力依存性

一定温度における化学ポテンシャルの微小変化は，

```math
d\mu=v\,dp
\tag{6}
```

と表される．
ここで $v$ は分子1個当たりの体積である．

まず，液体は圧縮されにくいため，その体積 $v_l$ は圧力によらずほぼ一定と近似できる．
式（6）を圧力 $p_\infty$ から $p'$ まで積分すると，

```math
\begin{aligned}
\mu_l(T,p')-\mu_l(T,p_\infty)
&=\int_{p_\infty}^{p'}v_l\,dp\\
&\approx v_l(p'-p_\infty)
\end{aligned}
\tag{7}
```

となる．

次に，蒸気を理想気体とみなす．理想気体の化学ポテンシャルは，圧力 $p$ に対して $kT\ln p$ に比例する形で変化する．
したがって，同じ温度における圧力 $p_\infty$ と $p_r$ の間の化学ポテンシャルの差は，

```math
\mu_g(T,p_r)-\mu_g(T,p_\infty)
=kT\ln\left(\frac{p_r}{p_\infty}\right)
\tag{8}
```

である．
ここで $k$ はボルツマン定数であり，対数の中は無次元の圧力比である．

式（7），（8）を式（5）に代入すると，

```math
v_l(p'-p_\infty)
=kT\ln\left(\frac{p_r}{p_\infty}\right)
\tag{9}
```

となる．
さらに，式（2）の $p'=p_r+2\gamma/r$ を代入すれば，

```math
\boxed{
v_l\left(p_r-p_\infty+\frac{2\gamma}{r}\right)
=kT\ln\left(\frac{p_r}{p_\infty}\right)
}
\tag{10}
```

を得る．
これは，液体を非圧縮性，蒸気を理想気体とみなした近似のもとでの関係式である．

#### 4．ケルビン式の導出

蒸気の分子1個当たりの体積を $v_g$ とすると，理想気体の状態方程式より，

```math
p_\infty v_g=kT
```

である．
よって，

```math
\frac{v_l p_\infty}{kT}
=\frac{v_l}{v_g}\ll1
\tag{11}
```

となる．
液体の分子1個当たりの体積は蒸気のそれよりもはるかに小さいため，この比は通常 $10^{-3}\sim10^{-4}$ 程度である．

式（10）を $kT$ で割り，式（11）を用いて整理すると，

```math
\ln\left(\frac{p_r}{p_\infty}\right)
=\frac{v_l}{v_g}
\left(
\frac{p_r}{p_\infty}-1+
\frac{2\gamma}{rp_\infty}
\right)
\tag{12}
```

となる．
ここで，

```math
\frac{p_r}{p_\infty}=1+y
```

とおくと，

```math
\ln(1+y)
=\frac{v_l}{v_g}
\left(y+\frac{2\gamma}{rp_\infty}\right)
\tag{13}
```

である．

液滴の飽和蒸気圧は平面液面の飽和蒸気圧よりも高いが，通常の条件ではその差は小さいため， $y\ll1$ である．
また，式（13）の右辺では， $v_l/v_g$ が非常に小さいため， $y$ の項の寄与を無視できる．
そこで，

```math
\ln(1+y)\approx
\frac{v_l}{v_g}\frac{2\gamma}{rp_\infty}
```

と近似する．
$y\ll1$ に対して $\ln(1+y)\approx y$ であることを用いても，同じ近似結果が得られる．
したがって，

```math
\ln\left(\frac{p_r}{p_\infty}\right)
\approx\frac{2v_l\gamma}{rp_\infty v_g}
```

である．
ここで $p_\infty v_g=kT$ を使うと，

```math
\boxed{
\ln\left(\frac{p_r}{p_\infty}\right)
=\frac{2v_l\gamma}{rkT}
}
\tag{14}
```

を得る．
よって，半径 $r$ の液滴に対する飽和蒸気圧は，

```math
\boxed{
p_r=p_\infty
\exp\left(\frac{2v_l\gamma}{rkT}\right)
}
\tag{15}
```

である．
これがケルビン式である．
指数部は正であるため，

```math
p_r>p_\infty
```

となる．
また，半径 $r$ が小さいほど指数部が大きくなり，液滴の飽和蒸気圧が高くなることが分かる．

### （ii）限界半径 $r_c$

周囲の蒸気圧が $p$ であり，

```math
p>p_\infty
```

を満たす過飽和蒸気を考える．
液滴が成長するか蒸発するかは，周囲の蒸気圧 $p$ と，その半径の液滴に対する飽和蒸気圧 $p_r$ の大小によって決まる．

- $p<p_r$ のとき，周囲の蒸気は液滴と平衡するには不十分であり，液滴は蒸発する．
- $p>p_r$ のとき，周囲の蒸気は液滴に対して過飽和であり，液滴は蒸気を取り込んで成長する．

成長と蒸発の境界では，

```math
p=p_r
```

である．
このときの液滴半径を限界半径 $r_c$ とする．
式（14）に $p_r=p$ ， $r=r_c$ を代入すると，

```math
\ln\left(\frac{p}{p_\infty}\right)
=\frac{2v_l\gamma}{r_c kT}
```

となる．
これを $r_c$ について解けば，

```math
\boxed{
r_c=
\frac{2v_l\gamma}
{kT\ln(p/p_\infty)}
}
\tag{16}
```

を得る．
$p>p_\infty$ であるため，対数は正であり， $r_c$ も正となる．

したがって，

```math
\boxed{
\begin{array}{ll}
r<r_c & \text{液滴は蒸発する}\\[3pt]
r>r_c & \text{液滴は成長する}
\end{array}
}
```

である．
$r=r_c$ は成長と蒸発を分ける臨界状態であり，限界半径より大きな液滴は成長できる一方，それより小さな液滴は蒸発してしまう．

### 物理的な意味

表面張力は液滴の表面積を小さくしようとするため，液滴内部には外部よりも高い圧力が生じる．
このラプラス圧によって液相の化学ポテンシャルが上昇し，液滴と平衡する蒸気圧も平面液面の場合より高くなる．
これが，半径の小さい液滴ほど飽和蒸気圧が高くなる理由である．

また，過飽和蒸気であっても，微小な液滴は表面張力の影響が大きいため，成長できるとは限らない．
液滴が限界半径を超えて初めて，周囲の蒸気を取り込んで成長できる．
そのため，塵などの凝結核が存在しない蒸気では液滴が発生しにくく，過飽和状態が生じやすいのである．
