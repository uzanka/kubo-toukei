# 例題【4-R-4】

## 解答

### 1．気相のエントロピーを求める

気相の 1 mol 当たりのエントロピーを $\bar S(T,p)$ とする．
解答例の式 (4.14)，(4.15) から，気相の Gibbs 自由エネルギー $\bar G$ に対する関係式

```math
\bar S(T,p) =-\left(\frac{\partial\bar G}{\partial T}\right)_p
```

を用いると，気相のエントロピーは次のように表される．

```math
\begin{aligned}
\bar S(T,p)={}&C_p^0\log T\\
&+\int_0^T\frac{dt}{t^2} \int_0^t C'(u)\,du\\
&+\frac{1}{T}\int_0^T C'(t)\,dt\\
&+Ri+C_p^0-R\log p .
\end{aligned}
\tag{1}
```

ここで， $C_p^0$ は気相の定圧モル比熱の基準となる定数， $C'(T)$ はその温度依存部分を表す関数， $i$ は積分定数に由来する定数である．また， $R$ は気体定数である．

以下では，このエントロピーを，凝縮相から気相への相転移に伴うエントロピー変化と比較する．

### 2．第三法則を用いてエントロピー変化を表す

熱力学第三法則により， $0\,\mathrm{K}$ における凝縮相のエントロピーをゼロとする．
凝縮相を $0\,\mathrm{K}$ から $T\,\mathrm{K}$ まで定圧で準静的に加熱し，その後，同じ温度 $T$ で蒸発させる過程を考える．

凝縮相の定圧モル比熱を $C_p''(T)$ とすると，加熱過程におけるエントロピー変化は

```math
\Delta S_{\mathrm{heat}} =\int_0^T\frac{C_p''(t)}{t}\,dt
```

である．
また，温度 $T$ におけるモル蒸発潜熱を $L$ とすると，蒸発過程におけるエントロピー変化は

```math
\Delta S_{\mathrm{vap}}=\frac{L}{T}
```

である．
したがって，気相のエントロピーは両過程のエントロピー変化の和に等しく，

```math
\boxed{
\bar S(T,p) =\int_0^T\frac{C_p''(t)}{t}\,dt+\frac{L}{T}
}
\tag{2}
```

となる．

### 3．蒸発潜熱 $L$ を温度の関数として表す

蒸発潜熱 $L$ は，気相と凝縮相のモルエンタルピーの差である．
気相のモルエンタルピーを $\bar H'$ ，凝縮相のモルエンタルピーを $\bar H''$ とすると，

```math
L=\bar H'-\bar H''
```

である．
定圧におけるエンタルピーの温度微分は定圧モル比熱に等しいため，

```math
\left(\frac{\partial\bar H}{\partial T}\right)_p=C_p
```

が成立する．
したがって， $0\,\mathrm{K}$ から $T\,\mathrm{K}$ まで積分すると，

```math
L=L_0+\int_0^T \left[C_p'(t)-C_p''(t)\right]dt
```

を得る．
ここで， $L_0$ は $0\,\mathrm{K}$ におけるモル蒸発潜熱， $C_p'(T)$ は気相の定圧モル比熱である．

気相の定圧モル比熱を

```math
C_p'(T)=C_p^0+C'(T)
```

と表せば，

```math
\boxed{
L=L_0+C_p^0T+ \int_0^T\left[C'(t)-C_p''(t)\right]dt
}
\tag{3}
```

となる．

### 4．部分積分を用いてエントロピーの式を整理する

式 (1) の積分には，気相の比熱 $C'(T)$ が含まれている．
これを凝縮相の比熱との差で表すため，

```math
C'(t)= \left[C'(t)-C_p''(t)\right]+C_p''(t)
```

と分解する．

その際，次の部分積分の公式を用いる．

```math
\begin{aligned}
&\int_0^T\frac{dt}{t^2} \int_0^t C_p''(u)\,du\\
&\qquad=-\frac{1}{T}\int_0^T C_p''(u)\,du +\int_0^T\frac{C_p''(t)}{t}\,dt .
\end{aligned}
\tag{4}
```

この公式を確認するため，

```math
A(t)=\int_0^t C_p''(u)\,du
```

とおくと，部分積分によって

```math
\begin{aligned}
\int_0^T\frac{A(t)}{t^2}\,dt &=\left[-\frac{A(t)}{t}\right]_0^T +\int_0^T\frac{A'(t)}{t}\,dt\\
&=-\frac{1}{T}\int_0^T C_p''(u)\,du +\int_0^T\frac{C_p''(t)}{t}\,dt
\end{aligned}
```

となる．
ここでは $A'(t)=C_p''(t)$ を用いた．
また，境界項の $t\to0$ における極限は，第三法則に対応する $C_p''(0)=0$ と低温での正則性の仮定のもとでゼロとなる．

式 (1) にこの分解と式 (4) を適用すると，凝縮相の比熱に由来する項が整理され，

```math
\begin{aligned}
\bar S(T,p)={}&C_p^0\log T\\
&+\int_0^T\frac{dt}{t^2}  \int_0^t\left[C'(u)-C_p''(u)\right]du\\
&+\int_0^T\frac{C_p''(t)}{t}\,dt\\
&+\frac{1}{T}\int_0^T  \left[C'(t)-C_p''(t)\right]dt\\
&+Ri+C_p^0-R\log p
\end{aligned}
\tag{5}
```

となる．

### 5．エントロピーを等置して飽和蒸気圧を導く

式 (2) と式 (5) は，同じ温度・圧力における気相のエントロピーを表しているため，両者を等置する．
すると，両辺に共通する凝縮相の比熱の積分

```math
\int_0^T\frac{C_p''(t)}{t}\,dt
```

が相殺される．
よって，

```math
\begin{aligned}
&C_p^0\log T\\
&+\int_0^T\frac{dt}{t^2}  \int_0^t\left[C'(u)-C_p''(u)\right]du\\
&+\frac{1}{T}\int_0^T  \left[C'(t)-C_p''(t)\right]dt\\
&+Ri+C_p^0-R\log p =\frac{L}{T}
\end{aligned}
\tag{6}
```

を得る．

ここに式 (3) の蒸発潜熱を代入すると，

```math
\begin{aligned}
\frac{L}{T} ={}&\frac{L_0}{T}+C_p^0\\
&+\frac{1}{T}\int_0^T  \left[C'(t)-C_p''(t)\right]dt
\end{aligned}
```

となる．
これを式 (6) に代入し，両辺に共通する $C_p^0$ および

```math
\frac{1}{T}\int_0^T \left[C'(t)-C_p''(t)\right]dt
```

を消去すると，

```math
\begin{aligned}
&C_p^0\log T\\
&+\int_0^T\frac{dt}{t^2}  \int_0^t\left[C'(u)-C_p''(u)\right]du\\
&+Ri-R\log p=\frac{L_0}{T}
\end{aligned}
```

を得る．
これを $\log p$ について整理すれば，

```math
\begin{aligned}
R\log p={}&-\frac{L_0}{T} +C_p^0\log T\\
&+\int_0^T\frac{dt}{t^2}  \int_0^t\left[C'(u)-C_p''(u)\right]du +Ri
\end{aligned}
```

となる．
飽和状態では $p=p_s(T)$ であるため，両辺を $R$ で割ると，

```math
\boxed{
\begin{aligned}
\log p_s(T)={}&-\frac{L_0}{RT} +\frac{C_p^0}{R}\log T\\
&+\int_0^T\frac{dt}{t^2}  \int_0^t\frac{C'(u)-C_p''(u)}{R}\,du +i
\end{aligned}
}
```

を得る．
以上により，求める飽和蒸気圧の公式が導かれた．

注意： 問題文の公式の第1項は $-L_0/T$ であるが， $L_0$ を通常の単位 $\mathrm{J\,mol^{-1}}$ で表されるモル蒸発潜熱とする場合，正しい項は $-L_0/(RT)$ である．
したがって，問題文の公式は， $R$ が欠落していると解釈するのが妥当である．
また， $\log p_s$ は厳密には無次元量の対数であり，圧力の単位や基準圧力の取り方は定数 $i$ に反映される．
