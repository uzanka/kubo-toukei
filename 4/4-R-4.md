# 例題【4-R-4】

## 解答

以下では，気相を $'$ ，凝縮相を $''$ で表す．
通常のモル蒸発潜熱を $\mathcal L$ とし，単位は $\mathrm{J/mol}$ とする．

気相については理想気体を仮定する．
また，凝縮相のモル体積および凝縮相の圧力変化による潜熱補正が，要求する精度に対して無視できる場合を扱う．
したがって，以下で導く公式は，これらの近似条件のもとで成立する．

### 1．Clapeyron の式から Clausius–Clapeyron の近似式を導く

飽和状態において，気相と凝縮相のモルエントロピーをそれぞれ $S'$ ， $S''$ ，モル体積を $V'$ ， $V''$ とする．
相平衡における Clapeyron の式は，

```math
\frac{dp_s}{dT}
=
\frac{S'-S''}{V'-V''}
```

である．

相平衡では，モル蒸発潜熱が

```math
\mathcal L=H'-H''=T(S'-S'')
```

であるから，

```math
\boxed{
\frac{dp_s}{dT}
=
\frac{\mathcal L}{T(V'-V'')}
}
\tag{1}
```

を得る．

気相を理想気体とすると，

```math
V'=\frac{RT}{p_s}
```

である．
凝縮相のモル体積が気相のモル体積に比べて十分小さい場合，

```math
\varepsilon
=
\frac{V''}{V'}
=
\frac{p_sV''}{RT}
\ll1
```

となる．
したがって，

```math
V'-V''
=
\frac{RT}{p_s}(1-\varepsilon)
```

を式 (1) に代入すれば，

```math
\frac{d\ln p_s}{dT}
=
\frac{\mathcal L}{RT^2}
\frac{1}{1-\varepsilon}
```

となる．
よって， $\varepsilon\ll1$ の範囲では，

```math
\boxed{
\frac{d\ln p_s}{dT}
\simeq
\frac{\mathcal L}{RT^2}
}
\tag{2}
```

を得る．
これが Clausius–Clapeyron の近似式である．

### 2．飽和曲線に沿った潜熱の温度微分

蒸発潜熱は飽和状態におけるエンタルピー差であるから，

```math
\mathcal L(T)
=
H'(T,p_s(T))-H''(T,p_s(T))
```

である．

単純圧縮系のエンタルピーの全微分は，

```math
dH
=
C_p\,dT+
\left[
V-T\left(\frac{\partial V}{\partial T}\right)_p
\right]dp
```

である．
これを飽和曲線に沿って適用すると，

```math
\begin{aligned}
\frac{d\mathcal L}{dT}
={}&C_p'-C_p''\\
&+
\left[
V'-T\left(\frac{\partial V'}{\partial T}\right)_p
-V''+T\left(\frac{\partial V''}{\partial T}\right)_p
\right]\frac{dp_s}{dT}
\end{aligned}
\tag{3}
```

を得る．

気相が理想気体ならば，

```math
V'=\frac{RT}{p}
```

なので，

```math
V'-T\left(\frac{\partial V'}{\partial T}\right)_p
=
\frac{RT}{p}-T\frac{R}{p}
=0
```

である．

一方，凝縮相の熱膨張係数を

```math
\alpha''
=
\frac{1}{V''}
\left(\frac{\partial V''}{\partial T}\right)_p
```

とすれば，

```math
-V''+T\left(\frac{\partial V''}{\partial T}\right)_p
=
V''(T\alpha''-1)
```

となる．
したがって，

```math
\boxed{
\frac{d\mathcal L}{dT}
=
C_p'-C_p''
+
V''(T\alpha''-1)\frac{dp_s}{dT}
}
\tag{4}
```

である．

ここで，

```math
\Delta C_p=C_p'-C_p''
```

および，

```math
\Delta_p=
V''(T\alpha''-1)\frac{dp_s}{dT}
```

と定義する．
すると，

```math
\frac{d\mathcal L}{dT}
=
\Delta C_p+\Delta_p
```

となる．

圧力補正項 $\Delta_p$ が無視できる条件を，誤差によって評価する．
保持する項 $\Delta C_p\neq0$ に対する相対誤差を $\eta$ 以下とする場合には，

```math
\boxed{
|\Delta_p|
\leq\eta|\Delta C_p|,
\qquad 0<\eta\ll1
}
\tag{5}
```

を満たせばよい．

一方， $\Delta C_p$ がゼロまたは非常に小さい場合には，相対誤差による評価は適切でない．
この場合には，許容絶対誤差を $\delta_C$ と定め，

```math
\boxed{
|\Delta_p|\leq\delta_C
}
\tag{6}
```

とする．
これらは圧力補正項を無視するための十分な誤差条件である．

この条件のもとで，

```math
\boxed{
\frac{d\mathcal L}{dT}
\simeq C_p'-C_p''
}
\tag{7}
```

となる．

さらに，気相の定圧モル比熱を

```math
C_p'(T)=C_p^0+C'(T)
```

と表し，

```math
D(T)=C'(T)-C_p''(T)
```

と定義すれば，

```math
\boxed{
\frac{d\mathcal L}{dT}
\simeq C_p^0+D(T)
}
\tag{8}
```

を得る．
ここで， $C_p^0$ は温度に依存しない定数であり，各比熱はその温度における各相の状態に対応する．

### 3．有限温度を基準とした潜熱の表示

正の基準温度 $T_0$ を選び，その温度での蒸発潜熱を $\mathcal L(T_0)$ とする．

式 (8) を $T_0$ から $T$ まで積分すると，

```math
\mathcal L(T)-\mathcal L(T_0)
\simeq
C_p^0(T-T_0)+\int_{T_0}^{T}D(u)\,du
```

となる．
したがって，

```math
\boxed{
\mathcal L(T)
\simeq
\mathcal L(T_0)
+C_p^0(T-T_0)
+\int_{T_0}^{T}D(u)\,du
}
\tag{9}
```

である．

この式は，同一の気相－凝縮相平衡曲線上で適用する．
固液転移をまたぐ場合は，転移温度で積分区間を分け，転移潜熱を別に考慮する．

### 4．固相の場合の0 Kを下端とする表示

まず，固相が0 Kまで安定な平衡相として存在する場合を考える．

固相の昇華潜熱を $\mathcal L_s(T)$ ，固相の定圧モル比熱を $C_{p,s}(T)$ とする．
この場合，

```math
D_s(T)=C'(T)-C_{p,s}(T)
```

とおく．

低温で，

```math
\int_0^{T_1}\frac{|D_s(u)|}{u}\,du<\infty
\tag{10}
```

が成立すると仮定する．
これは，後に現れる二重積分の絶対収束を保証する十分条件である．
例えば，

```math
D_s(T)=O(T^\alpha),\qquad\alpha>0
```

であれば成立する．

また，固相の0 Kにおける昇華潜熱を，

```math
\boxed{
\mathcal L_{s,0}
=
\lim_{T\to0^+}\mathcal L_s(T)
}
\tag{11}
```

とする．

式 (9) で $T_0\to0^+$ とすれば，

```math
\boxed{
\mathcal L_s(T)
\simeq
\mathcal L_{s,0}
+C_p^0T
+\int_0^T D_s(u)\,du
}
\tag{12}
```

を得る．

式 (2) に代入すると，

```math
\frac{d\ln p_s^{(s)}}{dT}
\simeq
\frac{\mathcal L_{s,0}}{RT^2}
+\frac{C_p^0}{RT}
+\frac{1}{RT^2}\int_0^TD_s(u)\,du
```

となる．

ここで，

```math
\frac{d}{dT}
\left[
\int_0^T\frac{dt}{t^2}
\int_0^tD_s(u)\,du
\right]
=
\frac{1}{T^2}\int_0^TD_s(u)\,du
```

であるから，積分して，

```math
\boxed{
\begin{aligned}
\ln\frac{p_s^{(s)}(T)}{p_*}
\simeq{}&
-\frac{\mathcal L_{s,0}}{RT}
+\frac{C_p^0}{R}\ln\frac{T}{T_*}\\
&+\frac{1}{R}
\int_0^T\frac{dt}{t^2}
\int_0^tD_s(u)\,du+i_s
\end{aligned}
}
\tag{13}
```

を得る．
ここで $p_*$ ， $T_*$ は対数の引数を無次元にするための基準圧力と基準温度であり， $i_s$ は積分定数である．

したがって，固相については，

```math
L_{0,s}=\frac{\mathcal L_{s,0}}{R}
```

とすれば，問題文の公式の形になる．

### 5．液相の場合の固液転移を含む表示

次に液相の場合を考える．
液体は一般に0 Kで安定な平衡相として存在しないため，液体－蒸気間の潜熱を0 Kまで外挿した極限を，物理的な0 Kの蒸発潜熱とはみなせない．

そこで，固液転移温度を $T_{\mathrm{tr}}$ ，その温度におけるモル融解熱を $\mathcal L_f$ とする．
ここで $T_{\mathrm{tr}}$ は，固体－蒸気枝と液体－蒸気枝を接続する相転移点であり，通常は三重点に対応する．

転移点では，

```math
\mathcal L_s(T_{\mathrm{tr}}^-)
=
H_g-H_s
```

および，

```math
\mathcal L_\ell(T_{\mathrm{tr}}^+)
=
H_g-H_\ell
```

である．
一方，融解熱の定義から，

```math
\mathcal L_f=H_\ell-H_s
```

である．
したがって，

```math
\boxed{
\mathcal L_\ell(T_{\mathrm{tr}}^+)
=
\mathcal L_s(T_{\mathrm{tr}}^-)-\mathcal L_f
}
\tag{14}
```

となる．
すなわち，液体の気化潜熱は，同じ温度における固体の昇華潜熱から融解熱を差し引いた値である．

固相側では式 (12) が成立するから，

```math
\mathcal L_s(T_{\mathrm{tr}}^-)
\simeq
\mathcal L_{s,0}
+C_p^0T_{\mathrm{tr}}
+\int_0^{T_{\mathrm{tr}}}
[C'(u)-C_{p,s}(u)]\,du
```

である．

液相側では，式 (8) を固液転移点から $T$ まで積分して，

```math
\begin{aligned}
\mathcal L_\ell(T)
\simeq{}&
\mathcal L_\ell(T_{\mathrm{tr}}^+)
+C_p^0(T-T_{\mathrm{tr}})\\
&+\int_{T_{\mathrm{tr}}}^{T}
[C'(u)-C_{p,\ell}(u)]\,du
\end{aligned}
```

となる．

これに式 (14) を代入すると，

```math
\begin{aligned}
\mathcal L_\ell(T)
\simeq{}&
\mathcal L_{s,0}-\mathcal L_f
+C_p^0T\\
&+\int_0^{T_{\mathrm{tr}}}
[C'(u)-C_{p,s}(u)]\,du\\
&+\int_{T_{\mathrm{tr}}}^{T}
[C'(u)-C_{p,\ell}(u)]\,du
\end{aligned}
\tag{15}
```

を得る．

ここで，液相の式を0 Kからの積分形式にまとめるため，凝縮相の比熱を区分的に，

```math
\boxed{
C_p''(u)=
\begin{cases}
C_{p,s}(u),&0<u<T_{\mathrm{tr}},\\
C_{p,\ell}(u),&T_{\mathrm{tr}}<u<T
\end{cases}
}
\tag{16}
```

と定義する．

また，

```math
D_\ell(u)=C'(u)-C_p''(u)
```

とおく．
すると式 (15) は，

```math
\boxed{
\mathcal L_\ell(T)
\simeq
(\mathcal L_{s,0}-\mathcal L_f)
+C_p^0T+\int_0^TD_\ell(u)\,du
}
\tag{17}
```

となる．

ここで，

```math
\boxed{
\mathcal L_{0,\ell}^{\mathrm{formal}}
=
\mathcal L_{s,0}-\mathcal L_f
}
\tag{18}
```

と定義する．
これは液体の0 Kにおける物理的な蒸発潜熱ではなく，固液転移に伴う融解熱を反映した形式的な積分定数である．

式 (17) を Clausius–Clapeyron の近似式に代入すると，

```math
\frac{d\ln p_s^{(\ell)}}{dT}
\simeq
\frac{1}{RT^2}
\left[
\mathcal L_{0,\ell}^{\mathrm{formal}}
+C_p^0T+\int_0^TD_\ell(u)\,du
\right]
```

となる．
この微分式は液体－蒸気平衡が成立する温度範囲で用いる．

その範囲内で積分すると，

```math
\boxed{
\begin{aligned}
\ln\frac{p_s^{(\ell)}(T)}{p_*}
\simeq{}&
-\frac{\mathcal L_{0,\ell}^{\mathrm{formal}}}{RT}
+\frac{C_p^0}{R}\ln\frac{T}{T_*}\\
&+\frac{1}{R}\int_0^T\frac{dt}{t^2}
\int_0^tD_\ell(u)\,du+i_\ell
\end{aligned}
}
\tag{19}
```

を得る．
ここで $i_\ell$ は，液体－蒸気平衡が成立する温度範囲内の基準状態によって定まる積分定数である．

重要なのは，式 (19) の積分下端を0 Kとした部分が，液体－蒸気平衡の存在しない低温領域まで Clausius–Clapeyron の式を適用したことを意味しない点である．
0 Kから固液転移点までの積分は，式 (16) の固相比熱を用いたエンタルピーの基準値を表している．
実際の液体－蒸気平衡に対する圧力の積分は，その平衡が成立する温度範囲で行い，基準状態の情報は $i_\ell$ に含める．

また，通常のモル潜熱 $\mathcal L_{s,0}$ を第1項に使用する場合には，式 (19) の第1項は，

```math
-\frac{\mathcal L_{s,0}}{RT}
+\frac{\mathcal L_f}{RT}
```

と書くこともできる．
したがって，融解熱を無視して単に固相の0 K潜熱を液相の $L_0$ とすることはできない．

式 (16) の区分的な比熱の取り扱いは，参照式 (4.74) において，0 Kから固体の比熱を積分し，融解熱を加え，その後液体の比熱を積分する経路と整合している．
式 (4.74) の融解項 $+\mathcal L_f/T_{\mathrm{tr}}$ はエントロピーの増加を表すのに対し，ここではエンタルピー差 $H_g-H_\ell$ を求めるため，固相の昇華潜熱から融解熱を差し引く．

### 6．最終公式のまとめ

固相については，

```math
\boxed{
\begin{aligned}
\ln\frac{p_s^{(s)}(T)}{p_*}
\simeq{}&
-\frac{\mathcal L_{s,0}}{RT}
+\frac{C_p^0}{R}\ln\frac{T}{T_*}\\
&+\int_0^T\frac{dt}{t^2}
\int_0^t
\frac{C'(u)-C_{p,s}(u)}{R}\,du+i_s
\end{aligned}
}
\tag{20}
```

となる．

液相については，

```math
\boxed{
\begin{aligned}
\ln\frac{p_s^{(\ell)}(T)}{p_*}
\simeq{}&
-\frac{\mathcal L_{s,0}-\mathcal L_f}{RT}
+\frac{C_p^0}{R}\ln\frac{T}{T_*}\\
&+\int_0^T\frac{dt}{t^2}
\int_0^t
\frac{C'(u)-C_p''(u)}{R}\,du+i_\ell
\end{aligned}
}
\tag{21}
```

となる．
ただし，液相の $C_p''(u)$ は式 (16) の区分的な比熱である．

したがって，問題文の共通形式

```math
\boxed{
\begin{aligned}
\ln\frac{p_s(T)}{p_*}
\simeq{}&
-\frac{\mathcal L_0}{RT}
+\frac{C_p^0}{R}\ln\frac{T}{T_*}\\
&+\int_0^T\frac{dt}{t^2}
\int_0^t
\frac{C'(u)-C_p''(u)}{R}\,du+i
\end{aligned}
}
\tag{22}
```

は，次のように解釈すれば固相と液相の両方に適用できる．
- 固相の場合， $\mathcal L_0=\mathcal L_{s,0}$ は物理的な0 Kの昇華潜熱である．
- 液相の場合， $\mathcal L_0=\mathcal L_{s,0}-\mathcal L_f$ は形式的な積分定数であり，物理的な0 Kの液体－蒸気間の潜熱ではない．

問題文の第1項を

```math
-\frac{L_0}{T}
```

とする場合には，

```math
L_0=\frac{\mathcal L_0}{R}
```

と定義する必要がある．
また，ここでは $\log$ を自然対数とした．
常用対数を用いる場合には，右辺全体を $\ln 10$ で割る必要がある．
