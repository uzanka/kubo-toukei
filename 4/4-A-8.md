# 演習問題【4-A-8】

## 解答

### 1．等温膨張の際に吸収する熱量

表面膜の面積を $\sigma$ ，表面張力を $\gamma(T)$ ，温度を $T$ とする．
例題［3］より，表面エントロピー $S_\sigma$ は

```math
S_\sigma=-\sigma\frac{d\gamma}{dT}
```

で与えられる．

面積が $\sigma_1$ から $\sigma_2$ まで変化する等温準静的過程を考える．
この過程を可逆過程とすると，熱力学第二法則より，吸収する微小熱量 $dQ$ とエントロピーの変化 $dS_\sigma$ の間には

```math
dQ=T\,dS_\sigma
```

が成り立つ．
したがって，過程全体で吸収する熱量 $Q$ は

```math
Q=\int_{\sigma_1}^{\sigma_2}T\,dS_\sigma
```

である．

ここで，表面エントロピーの式を微分すると，

```math
dS_\sigma
=-\frac{d\gamma}{dT}\,d\sigma
-\sigma\frac{d^2\gamma}{dT^2}\,dT
```

となる．
等温過程では $dT=0$ であるため，

```math
dS_\sigma=-\frac{d\gamma}{dT}\,d\sigma
```

を得る．
温度 $T$ が一定であることから， $d\gamma/dT$ も一定であり，

```math
\begin{aligned}
Q
&=\int_{\sigma_1}^{\sigma_2}
-T\frac{d\gamma}{dT}\,d\sigma\\
&=-T\frac{d\gamma}{dT}
\int_{\sigma_1}^{\sigma_2}d\sigma
\end{aligned}
```

となる．
よって，等温膨張の際に吸収する熱量は

```math
\boxed{
Q=-T\frac{d\gamma}{dT}(\sigma_2-\sigma_1)
}
```

である．

通常の液体では，温度が上昇すると表面張力が低下するため， $d\gamma/dT<0$ である．
したがって，面積が増加する場合には $\sigma_2>\sigma_1$ であり， $Q>0$ となる．
すなわち，表面膜は熱を吸収する．

### 2．断熱膨張の条件

次に，表面膜が準静的かつ可逆的に断熱膨張する場合を考える．
断熱過程では熱の出入りがなく，さらに可逆過程であるため，表面エントロピーは一定である．
したがって，

```math
dS_\sigma=0
```

が成り立つ．

表面エントロピー

```math
S_\sigma=-\sigma\frac{d\gamma}{dT}
```

を全微分すると，

```math
dS_\sigma
=-\frac{d\gamma}{dT}\,d\sigma
-\sigma\frac{d^2\gamma}{dT^2}\,dT
```

である．
これに断熱条件 $dS_\sigma=0$ を代入すると，

```math
\frac{d\gamma}{dT}\,d\sigma
+\sigma\frac{d^2\gamma}{dT^2}\,dT=0
```

となる．

ここで， $\sigma>0$ かつ $d\gamma/dT\neq0$ と仮定し，両辺を $\sigma(d\gamma/dT)$ で割ると，

```math
\frac{d\sigma}{\sigma}
+\frac{\dfrac{d^2\gamma}{dT^2}}
{\dfrac{d\gamma}{dT}}\,dT=0
```

を得る．
第2項は対数微分を用いて

```math
\frac{\dfrac{d^2\gamma}{dT^2}}
{\dfrac{d\gamma}{dT}}\,dT
=d\ln\left|\frac{d\gamma}{dT}\right|
```

と表せる．
また，

```math
\frac{d\sigma}{\sigma}=d\ln\sigma
```

であるから，

```math
d\ln\sigma
+d\ln\left|\frac{d\gamma}{dT}\right|=0
```

となる．
対数の性質を用いると，

```math
d\ln\left(
\sigma\left|\frac{d\gamma}{dT}\right|
\right)=0
```

である．
よって，

```math
\sigma\left|\frac{d\gamma}{dT}\right|
=\text{const.}
```

を得る．
ここで，膨張の途中で $d\gamma/dT$ の符号が変わらないとすれば，絶対値を外して，

```math
\boxed{
\sigma\frac{d\gamma}{dT}=\text{const.}
}
```

となる．
これが断熱膨張の条件である．

### 3．膨張前後の温度の関係

膨張前の面積を $\sigma_1$ ，温度を $T_1$ ，膨張後の面積を $\sigma_2$ ，温度を $T_2$ とする．
断熱膨張の条件を膨張前後に適用すると，

```math
\sigma_1\frac{d\gamma(T_1)}{dT_1}
=
\sigma_2\frac{d\gamma(T_2)}{dT_2}
```

となる．
したがって，表面張力の温度依存性 $\gamma(T)$ が与えられれば，この式を解くことによって，面積の変化に伴う断熱膨張後の温度 $T_2$ を求めることができる．
