# 演習問題【4-A-18】

## 解答

### 1．沸点の条件を立てる

溶媒を成分1，溶質を成分2とする理想希薄溶液を考える．溶媒と溶質のモル分率をそれぞれ $x_1$ ， $x_2$ とすると，

```math
x_1+x_2=1
```

である．
溶質が希薄であるという条件は $x_2\ll1$ であり，したがって $x_1=1-x_2\approx1$ となる．

溶液の沸点 $T_b$ は，溶液全体の蒸気圧が外圧 $p_0$ に等しくなる温度である．
溶媒と溶質の蒸気圧をそれぞれ $p_1$ ， $p_2$ とすると，ドルトンの分圧の法則より，

```math
p=p_1+p_2
```

である．
よって，沸点では

```math
p_1+p_2=p_0
\tag{1}
```

が成り立つ．

### 2．ラウールの法則とヘンリーの法則を用いる

理想希薄溶液では，溶媒の蒸気圧にラウールの法則が成り立つ．
すなわち，

```math
p_1=p_1^0(T)x_1
```

である．
ここで， $p_1^0(T)$ は温度 $T$ における純溶媒の飽和蒸気圧である．

一方，溶質が揮発性である場合も含め，希薄溶液では溶質の蒸気圧にヘンリーの法則が成り立つ．
したがって，

```math
p_2=k(T)x_2
```

と表せる．
$k(T)$ は温度 $T$ におけるヘンリー定数である．
溶質が不揮発性の場合は，その蒸気圧を無視できるため， $k(T)=0$ とみなせる．

これらの関係を式 (1) に代入すると，沸点 $T_b$ では

```math
p_1^0(T_b)x_1+k(T_b)x_2=p_0
```

となる．
$x_1=1-x_2$ を用いれば，

```math
p_1^0(T_b)(1-x_2)+k(T_b)x_2=p_0
\tag{2}
```

を得る．

ここで，純溶媒の沸点を $T_b^0$ とする．
純溶媒では $x_1=1$ ， $x_2=0$ であるから，沸点の条件は

```math
p_1^0(T_b^0)=p_0
\tag{3}
```

である．

### 3．溶質のモル分率が小さいとして一次近似する

溶質を加えたことによる沸点の変化を $\Delta T$ とし，

```math
T_b=T_b^0+\Delta T
```

とおく．
ここでは， $x_2\ll1$ であり，沸点変化 $\Delta T$ も小さいと仮定する．

式 (2) に $T_b=T_b^0+\Delta T$ を代入すると，

```math
\begin{aligned}
&p_1^0(T_b^0+\Delta T)(1-x_2)\\
&\qquad+k(T_b^0+\Delta T)x_2=p_0
\end{aligned}
\tag{4}
```

となる．

まず，純溶媒の飽和蒸気圧を $T_b^0$ の周りでテイラー展開し，一次の項まで残すと，

```math
p_1^0(T_b^0+\Delta T)
\approx
p_1^0(T_b^0)
+
\left(\frac{\partial p_1^0}{\partial T}\right)_{T_b^0}
\Delta T
```

である．
また， $k(T_b^0+\Delta T)x_2$ では， $k$ の温度変化による項は $x_2\Delta T$ に比例する二次の微小量となるため，一次近似では無視できる．
よって，

```math
k(T_b^0+\Delta T)x_2
\approx k(T_b^0)x_2
```

である．

これらを式 (4) に代入し， $x_2\Delta T$ などの二次以上の項を無視すると，

```math
\begin{aligned}
&p_1^0(T_b^0)
-p_1^0(T_b^0)x_2\\
&\quad+
\left(\frac{\partial p_1^0}{\partial T}\right)_{T_b^0}
\Delta T
+k(T_b^0)x_2
\approx p_0
\end{aligned}
```

となる．
式 (3) の $p_1^0(T_b^0)=p_0$ を代入して両辺から $p_0$ を引き，整理すれば，

```math
\left(\frac{\partial p_1^0}{\partial T}\right)_{T_b^0}
\Delta T
\approx
\bigl[p_1^0(T_b^0)-k(T_b^0)\bigr]x_2
```

を得る．
したがって，

```math
\Delta T\approx
\frac{p_1^0(T_b^0)-k(T_b^0)}
{\left(\dfrac{\partial p_1^0}{\partial T}\right)_{T_b^0}}
x_2
\tag{5}
```

である．
この時点で，沸点変化 $\Delta T$ が溶質のモル分率 $x_2$ に一次比例することが分かる．次に，比例係数を具体的に求める．

### 4．クラウジウス・クラペイロンの式を用いる

純溶媒の飽和蒸気圧の温度依存性は，クラウジウス・クラペイロンの式によって表される．
純溶媒のモル蒸発潜熱を $\overline L$ ，飽和蒸気と液体のモル体積をそれぞれ $\overline V_g$ ， $\overline V_l$ とすると，

```math
\left(\frac{\partial p_1^0}{\partial T}\right)_{T_b^0}
=
\frac{\overline L}
{T_b^0(\overline V_g-\overline V_l)}
```

である．
通常，蒸気のモル体積は液体のモル体積より十分に大きいため，

```math
\overline V_g-\overline V_l\approx\overline V_g
```

と近似できる．
さらに，飽和蒸気を理想気体とみなせば，

```math
p_1^0(T_b^0)\overline V_g=RT_b^0
```

が成り立つ．
これらを用いると，

```math
\begin{aligned}
\left(\frac{\partial p_1^0}{\partial T}\right)_{T_b^0}
&\approx\frac{\overline L}{T_b^0\overline V_g}\\
&=\frac{p_1^0(T_b^0)\overline L}
{R(T_b^0)^2}
\end{aligned}
\tag{6}
```

を得る．

式 (6) を式 (5) に代入すると，

```math
\Delta T\approx
\frac{R(T_b^0)^2}{\overline L}
\left(
1-\frac{k(T_b^0)}{p_1^0(T_b^0)}
\right)x_2
```

となる．
両辺を $T_b^0$ で割れば，

```math
\boxed{
\frac{\Delta T}{T_b^0}
\approx
\frac{RT_b^0}{\overline L}
\left(
1-\frac{k(T_b^0)}{p_1^0(T_b^0)}
\right)x_2
}
```

が得られる．
ここで， $\overline L$ は純溶媒のモル蒸発潜熱である．

以上より，理想希薄溶液では，沸点の変化は溶質のモル分率 $x_2$ に一次比例することが示された．
ただし，比例係数には溶質の揮発性を表すヘンリー定数 $k(T_b^0)$ も含まれる．

### 5．溶質の揮発性と沸点変化

得られた式から，沸点変化の符号は $1-k(T_b^0)/p_1^0(T_b^0)$ によって決まる．

- **不揮発性溶質の場合** ： $k(T_b^0)\approx0$ であるため，

  ```math
  \frac{\Delta T}{T_b^0}
  \approx\frac{RT_b^0}{\overline L}x_2
  ```

  となり，沸点は上昇する．
  この場合，希薄溶液の沸点上昇は溶媒の性質だけで決まり，分子量の決定にも利用できる．

- **揮発性溶質の場合** ： 溶質自身も蒸気圧に寄与するため，沸点変化の大きさと符号は $k(T_b^0)$ に依存する．
  $k(T_b^0)<p_1^0(T_b^0)$ なら一次近似で沸点上昇， $k(T_b^0)=p_1^0(T_b^0)$ なら一次の沸点変化はゼロ， $k(T_b^0)>p_1^0(T_b^0)$ なら一次近似で沸点降下となる．

したがって，溶質が揮発性であっても，沸点変化は希薄極限で $x_2$ に一次比例する．
ただし，その比例係数は溶媒と溶質の両方の性質に依存するのである．
