# 演習問題【4-A-25】

## 解答

問題は，気体 $A_2$ が固体 C に吸蔵される際の，気体の圧力 $p_{A_2}$ と吸蔵量（ここでは固溶体中の A のモル分率 $x_{\text{A}}$ とする）の関係を求めることである．

### 1. 化学平衡の条件

気体 $A_2$ が固体 C の中に吸蔵され，原子 A として存在する場合，以下の反応が起こっていると考えることができる．

$$A_2(\text{gas}) \rightleftharpoons 2\text{A}(\text{in C})$$

この反応が平衡状態にあるとき，反応前後の化学ポテンシャルの変化がゼロ，すなわち反応全体のギブス自由エネルギーの変化 $\Delta G$ がゼロである必要がある．
これは，以下の式で表される．

$$\bar{G}_{A_2(\text{gas})} = 2\bar{G}_{A(\text{C})}$$

ここで， $\bar{G}_{A_2(\text{gas})}$ は気体相における $A_2$ の化学ポテンシャルであり， $\bar{G}_{A(\text{C})}$ は固体 C に溶け込んだ原子 A の化学ポテンシャルである．

### 2. 化学ポテンシャルの式

問題の仮定に基づき，それぞれの化学ポテンシャルを次のように表す．

**(i) 気体相 ( $A_2$ ) について**

気体は理想気体であるため，気体 $A_2$ の化学ポテンシャル $\bar{G}_{A_2(\text{gas})}$ は，その圧力 $p_{A_2}$ を用いて次のように書ける．

$$\bar{G}_{A_2(\text{gas})} = \bar{G}_{A_2}^\circ(T) + RT \ln \left( \frac{p_{A_2}}{p^\circ} \right)$$

ここで， $\bar{G}_{A_2}^\circ(T)$ は標準状態における $A_2$ の化学ポテンシャル， $R$ は気体定数， $T$ は絶対温度， $p^\circ$ は標準圧力である．

**(ii) 固溶体相 (A in C) について**

固溶体は理想的であるため，固体 C に溶け込んだ原子 A の化学ポテンシャル $\bar{G}_{A(\text{C})}$ は，そのモル分率 $x_{\text{A}}$ を用いて次のように書ける．

$$\bar{G}_{A(\text{C})} = \bar{G}_{A}^*(\text{in C}, T) + RT \ln x_{\text{A}}$$

ここで， $\bar{G}_{A}^*(\text{in C}, T)$ は，純粋な A が固体 C の中に存在する（あるいは極限的に希薄な状態の）化学ポテンシャルである．

### 3. 平衡条件への代入と整理

平衡条件 $\bar{G}_{A_2(\text{gas})} = 2\bar{G}_{A(\text{C})}$ に，上記の式を代入する．

$$\bar{G}_{A_2}^\circ(T) + RT \ln \left( \frac{p_{A_2}}{p^\circ} \right) = 2 \left[ \bar{G}_{A}^*(\text{in C}, T) + RT \ln x_{\text{A}} \right]$$

右辺を展開する．

$$\bar{G}_{A_2}^\circ(T) + RT \ln p_{A_2} - RT \ln p^\circ = 2\bar{G}_{A}^*(\text{in C}, T) + 2RT \ln x_{\text{A}}$$

$RT \ln x_{\text{A}}$ の項を左辺に，それ以外の項を右辺にまとめる．

$$RT \ln p_{A_2} - 2RT \ln x_{\text{A}} = 2\bar{G}_{A}^*(\text{in C}, T) - \bar{G}_{A_2}^\circ(T) + RT \ln p^\circ$$

両辺を $RT$ で割る．

$$\ln p_{A_2} - 2 \ln x_{\text{A}} = \frac{2\bar{G}_{A}^*(\text{in C}, T) - \bar{G}_{A_2}^\circ(T) + RT \ln p^\circ}{RT}$$

右辺の括弧内は温度 $T$ のみの関数であるため，これを $f(T)$ と置く．

$$\ln p_{A_2} - 2 \ln x_{\text{A}} = f(T)$$

あるいは，

$$\ln p_{A_2} = 2 \ln x_{\text{A}} + f(T)$$

常用対数 ( $\log_{10}$ ) に変換すると，

$$\log p_{A_2} = 2 \log x_{\text{A}} + f'(T)$$

（ここで $f'(T)$ は $f(T)$ を定数倍・定数項変更した新しい温度の関数である）

### 4. 結論

上式から $x_{\text{A}}$ と $p_{A_2}$ の関係を導く．

$$2 \log x_{\text{A}} = \log p_{A_2} - f'(T)$$

$$\log x_{\text{A}}^2 = \log (p_{A_2} \cdot 10^{-f'(T)})$$

$$x_{\text{A}}^2 \propto p_{A_2}$$

したがって，

$$x_{\text{A}} \propto p_{A_2}^{1/2}$$

すなわち，吸蔵量（モル分率 $x_{\text{A}}$ ）は，気体の圧力 $p_{A_2}$ の平方根に比例することが期待される．

## 解説

この問題は，気相と固相の間で行われる化学平衡の基本原理を問うものである．

1. **化学ポテンシャルの役割**:
  物質が移動したり反応したりする駆動力は，化学ポテンシャルの差である．
  平衡状態とは，移動する物質の化学ポテンシャルが，どの方向から見ても等しくなった状態を指す．
  本問では， $A_2$ 分子が解離して $2\text{A}$ になるという反応の平衡を考えているため，気相の $A_2$ の化学ポテンシャルと，固相中の $2\text{A}$ の化学ポテンシャルが等しくなる条件を考える．

2. **理想気体と理想溶液の仮定**: 
   - **理想気体**:
     分子間の相互作用を無視できる理想的な状態であり，化学ポテンシャルは圧力の対数に比例する．
   - **理想溶液（固溶体）**:
     溶質（A）と溶媒（C）の相互作用が，純粋な成分同士の相互作用と同じであると仮定できる状態であり，化学ポテンシャルは濃度（モル分率）の対数に比例する．

   これらの仮定があることで，化学ポテンシャルを扱いやすい数学的形（ $\ln p$ や $\ln x$ ）で記述できる．

3. **指数の意味**:
  導出過程で現れた $2 \ln x_{\text{A}}$ という項は，反応式 $A_2 \rightleftharpoons 2\text{A}$ における係数「2」に由来している．
  反応で分子が2つに分かれる場合，溶質の化学ポテンシャルは溶質の濃度の2乗の半分（あるいは濃度の対数の2倍）として効いてくる．
  この「2」が，最終的な関係式において $p_{A_2}^{1/2}$ という平方根の形を生み出す決定的な要因となっている．
