# 演習問題【4-A-25】

## 解答

### 1．化学平衡の条件

気体 $A_2$ が固体 $C$ に吸蔵され，固体中では原子 $A$ として存在するとする．
この過程は，次の化学反応で表される．

```math
A_2(\mathrm{gas})\rightleftharpoons 2A(\mathrm{in\ C})
\tag{1}
```

化学ポテンシャルとは，温度，圧力などを一定に保ちながら物質の量を変化させたときの，ギブズ自由エネルギーの変化を表す量である．
化学反応が平衡に達すると，反応が微小に進んでもギブズ自由エネルギーは変化しない．
したがって，反応 (1) の平衡条件は，

```math
\mu_{A_2}=2\mu_A
\tag{2}
```

となる．
ここで， $\mu_{A_2}$ は気体 $A_2$ の化学ポテンシャル， $\mu_A$ は固体 $C$ に溶け込んだ原子 $A$ の化学ポテンシャルである．
右辺に係数 2 が付くのは， $A_2$ 分子1個から $A$ 原子が2個生じるためである．

### 2．気体と固溶体の化学ポテンシャル

気体は理想気体であると仮定する．
このとき，気体 $A_2$ の化学ポテンシャルは，

```math
\mu_{A_2}
=\mu_{A_2}^{\circ}(T)
+RT\ln\left(\frac{p_{A_2}}{p^\circ}\right)
\tag{3}
```

と表される．
ここで， $R$ は気体定数， $T$ は絶対温度， $p_{A_2}$ は気体 $A_2$ の分圧， $p^\circ$ は標準圧力である．
$\mu_{A_2}^{\circ}(T)$ は標準状態における化学ポテンシャルであり，温度 $T$ の関数である．

一方，固体 $C$ と原子 $A$ からなる固溶体も理想的であると仮定する．
固溶体中の $A$ のモル分率を $x_A$ とすると，原子 $A$ の化学ポテンシャルは，

```math
\mu_A=\mu_A^{\circ}(T)+RT\ln x_A
\tag{4}
```

と表される．
ここで， $\mu_A^{\circ}(T)$ は固溶体中の成分 $A$ に対する標準化学ポテンシャルである．
理想固溶体では，組成に依存する部分が $RT\ln x_A$ で表される．

### 3．平衡条件から圧力と吸蔵量の関係を導く

式 (3)，(4) を平衡条件 (2) に代入すると，

```math
\begin{aligned}
&\mu_{A_2}^{\circ}(T)
+RT\ln\left(\frac{p_{A_2}}{p^\circ}\right)\\
&\qquad=2\mu_A^{\circ}(T)+2RT\ln x_A
\end{aligned}
\tag{5}
```

となる．
対数の項を左辺にまとめると，

```math
RT\ln\left(\frac{p_{A_2}}{p^\circ}\right)
-2RT\ln x_A
=2\mu_A^{\circ}(T)-\mu_{A_2}^{\circ}(T)
\tag{6}
```

である．
両辺を $RT$ で割り，対数の性質

```math
\ln(a^n)=n\ln a
```

を用いると，

```math
\ln\left(\frac{p_{A_2}}{p^\circ}\right)
-2\ln x_A
=\frac{2\mu_A^{\circ}(T)-\mu_{A_2}^{\circ}(T)}{RT}
\tag{7}
```

を得る．
右辺は温度 $T$ のみの関数であり，圧力や組成には依存しない．
したがって，温度を一定に保つと，右辺は定数である．
これを $f(T)$ と書けば，

```math
\ln\left(\frac{p_{A_2}}{p^\circ}\right)
=2\ln x_A+f(T)
\tag{8}
```

となる．
両辺の指数を取ると，

```math
\frac{p_{A_2}}{p^\circ}
=e^{f(T)}x_A^2
\tag{9}
```

を得る．
したがって，

```math
x_A^2=\frac{p_{A_2}}{p^\circ}e^{-f(T)}
\tag{10}
```

である．
温度一定では $p^\circ$ と $e^{-f(T)}$ は定数であるから，

```math
x_A^2\propto p_{A_2}
```

となる．
$x_A$ と $p_{A_2}$ はいずれも正であるため，平方根を取れば，

```math
\boxed{
x_A\propto p_{A_2}^{1/2}
}
```

が得られる．

### 結論

気体 $A_2$ が固体 $C$ に吸蔵され，固体中では原子 $A$ として存在し，気体と固溶体がともに理想的であると仮定すると， **温度一定のもとで，固溶体中の $A$ のモル分率 $x_A$ は，気体 $A_2$ の分圧 $p_{A_2}$ の平方根に比例する** ．
すなわち，

```math
\boxed{
x_A\propto\sqrt{p_{A_2}}
}
```

である．
この平方根の関係は，反応式 $A_2\rightleftharpoons 2A$ において，気体分子1個から固体中の原子が2個生じることに由来する．
