# 例題【4-R-6】

## 解答

溶媒の蒸気圧，浸透圧，沸点上昇・氷点降下は，いずれも溶媒の化学ポテンシャルと相平衡の条件から導出できる．
以下では，活動度を $a_1$ ，気体を理想気体とし，液体の体積変化および温度変化に関する一次近似を用いる．

### (i) 蒸気圧の導出

溶液中の溶媒の化学ポテンシャルは，純溶媒の化学ポテンシャルを用いて

```math
\overline{G}_1(T,p) =\overline{G}_1^o(T,p)+RT\ln a_1
\tag{1}
```

と表される．
ここで， $R$ は気体定数， $T$ は絶対温度， $p$ は液相の圧力である．

溶媒の蒸気を理想気体と仮定すると，その化学ポテンシャルは

```math
\overline{G}_{1,\mathrm{gas}}(T,p_1) =\overline{G}_{1,\mathrm{gas}}^o(T)+RT\ln p_1
\tag{2}
```

と表される．
式(2)では，圧力の対数の中に基準圧力が省略されているが，これは基準圧力を一定に選んだ表記である．

液相と気相が平衡にあるとき，溶媒の化学ポテンシャルは両相で等しい．
したがって，

```math
\overline{G}_1^o(T,p)+RT\ln a_1 =\overline{G}_{1,\mathrm{gas}}^o(T)+RT\ln p_1
\tag{3}
```

となる．

一方，純溶媒の飽和蒸気圧を $p_1^o$ とすると，純溶媒とその蒸気が平衡にあるため，

```math
\overline{G}_1^o(T,p_1^o) =\overline{G}_{1,\mathrm{gas}}^o(T)+RT\ln p_1^o
\tag{4}
```

が成り立つ．

式(3)から式(4)を引くと，

```math
\begin{aligned}
&\overline{G}_1^o(T,p) -\overline{G}_1^o(T,p_1^o) +RT\ln a_1\\
&\qquad=RT\ln\frac{p_1}{p_1^o}
\end{aligned}
```

を得る．
これを整理すれば，

```math
p_1=p_1^o a_1 \exp\left[ \frac{\overline{G}_1^o(T,p) -\overline{G}_1^o(T,p_1^o)}{RT} \right]
\tag{5}
```

となる．

次に，液体のモル体積を $\overline{V}_1^o$ とする．
ギブズエネルギーの圧力に関する微分関係

```math
\left(\frac{\partial \overline{G}_1^o}{\partial p}\right)_T =\overline{V}_1^o
```

を用いると，圧力差が小さい範囲で

```math
\overline{G}_1^o(T,p) -\overline{G}_1^o(T,p_1^o) \simeq \overline{V}_1^o(p-p_1^o)
\tag{6}
```

と近似できる．

液体のモル体積は気体のモル体積に比べて非常に小さい．
また，気体のモル体積は理想気体の状態方程式からおよそ $RT/p_1^o$ である．
したがって，通常の条件では

```math
\left| \frac{\overline{V}_1^o(p-p_1^o)}{RT} \right|\ll 1
```

であり，式(5)の指数関数を $1$ と近似できる．
よって，

```math
\boxed{
p_1\simeq p_1^o a_1
}
```

を得る．
これは，溶媒の蒸気圧が純溶媒の飽和蒸気圧に活動度を掛けた値で近似されることを示している．

### (ii) 浸透圧の導出

温度 $T$ において，圧力 $p_0$ の純溶媒と圧力 $p$ の溶液が半透膜を隔てて接しているとする．
半透膜は溶媒を通すが溶質は通さないものとする．

溶媒が膜を通って移動しなくなった平衡状態では，両側の溶媒の化学ポテンシャルが等しい．したがって，

```math
\overline{G}_1^o(T,p_0) =\overline{G}_1(T,p)
```

である．
式(1)を代入すると，

```math
\overline{G}_1^o(T,p_0) =\overline{G}_1^o(T,p)+RT\ln a_1
```

となり，整理すれば，

```math
\overline{G}_1^o(T,p) -\overline{G}_1^o(T,p_0) =-RT\ln a_1
\tag{7}
```

を得る．

圧力変化による液体のモル体積の変化は小さいため，式(7)の左辺を一次近似すると，

```math
\overline{G}_1^o(T,p) -\overline{G}_1^o(T,p_0) \simeq \overline{V}_1^o(p-p_0)
\tag{8}
```

となる．

浸透圧を

```math
\pi=p-p_0
```

と定義すれば，式(7)，(8)より，

```math
\boxed{
\pi\overline{V}_1^o=-RT\ln a_1
}
```

が得られる．
溶液中の溶媒の活動度は通常 $a_1<1$ であるため， $\ln a_1<0$ となり，浸透圧 $\pi$ は正になる．

### (iii) 沸点上昇・氷点降下の導出

ここでは，温度変化が小さいとし，化学ポテンシャルの温度依存性を一次近似する．
ギブズエネルギーについて，

```math
\left(\frac{\partial \overline{G}}{\partial T}\right)_p =-\overline{S}
\tag{9}
```

が成り立つ．
ここで $\overline{S}$ はモルエントロピーである．

#### (a) 沸点上昇

純溶媒の沸点を $T_1^o$ ，溶液の沸点を $T_1$ とし，

```math
\Delta T=T_1-T_1^o
```

と定義する．
沸点では，液相の溶媒と気相の純溶媒が平衡にある．
外圧を $p_0$ とすると，純溶媒の沸点では

```math
\overline{G}_1^o(T_1^o,p_0) =\overline{G}_{1,\mathrm{gas}}^o(T_1^o,p_0)
\tag{10}
```

が成り立つ．
溶液の沸点では，

```math
\overline{G}_1^o(T_1,p_0)+RT_1\ln a_1 =\overline{G}_{1,\mathrm{gas}}^o(T_1,p_0)
\tag{11}
```

となる．

式(10)，(11)を用いて整理すると，

```math
\begin{aligned}
-RT_1\ln a_1 ={}&\overline{G}_1^o(T_1,p_0) -\overline{G}_1^o(T_1^o,p_0)\\
&-\left[ \overline{G}_{1,\mathrm{gas}}^o(T_1,p_0) -\overline{G}_{1,\mathrm{gas}}^o(T_1^o,p_0) \right]
\end{aligned}
\tag{12}
```

を得る．

$\Delta T$ が小さいとき，式(9)を用いて一次近似すると，

```math
\overline{G}_1^o(T_1,p_0) -\overline{G}_1^o(T_1^o,p_0) \simeq-\overline{S}\_1^o\Delta T
```

および

```math
\overline{G}_{1,\mathrm{gas}}^o(T_1,p_0) -\overline{G}_{1,\mathrm{gas}}^o(T_1^o,p_0) \simeq-\overline{S}_{1,\mathrm{gas}}^o\Delta T
```

となる．
これらを式(12)に代入すれば，

```math
-RT_1\ln a_1 \simeq \left( \overline{S}_{1,\mathrm{gas}}^o-\overline{S}_1^o \right)\Delta T
\tag{13}
```

を得る．

純溶媒の沸点では液相と気相が平衡にあるため，蒸発モル潜熱 $\overline{L}_1$ は

```math
\overline{L}_1 =T_1^o \left( \overline{S}_{1,\mathrm{gas}}^o-\overline{S}_1^o \right)>0
\tag{14}
```

と表される．
式(13)，(14)より，

```math
-\ln a_1 \simeq \frac{\overline{L}_1}{R} \frac{\Delta T}{T_1T_1^o}
```

となる．
沸点上昇が小さく $T_1\simeq T_1^o$ とみなせるため，

```math
-\ln a_1 \simeq \frac{\overline{L}_1\Delta T}{R(T_1^o)^2}
```

を得る．
したがって，

```math
\boxed{
\Delta T =-\frac{R(T_1^o)^2}{\overline{L}_1}\ln a_1
}
```

である．
通常，溶液中では $a_1<1$ なので $\ln a_1<0$ であり， $\overline{L}_1>0$ から $\Delta T>0$ となる．
すなわち，沸点上昇が生じる．

#### (b) 氷点降下

次に，純溶媒の凝固温度を $T_1^o$ ，溶液から純溶媒の固相が析出する温度を $T_1$ とする．
この場合も，

```math
\Delta T=T_1-T_1^o
```

と定義する．
氷点降下では $T_1<T_1^o$ なので， $\Delta T<0$ である．

純溶媒の凝固温度では，液相と固相の化学ポテンシャルが等しいため，

```math
\overline{G}_1^o(T_1^o,p_0) =\overline{G}_{1,\mathrm{solid}}^o(T_1^o,p_0)
\tag{15}
```

となる．
溶液から純溶媒の固相が析出する温度では，

```math
\overline{G}_1^o(T_1,p_0)+RT_1\ln a_1 =\overline{G}_{1,\mathrm{solid}}^o(T_1,p_0)
\tag{16}
```

である．

式(15)，(16)を用いて整理し，温度差について一次近似すると，

```math
-RT_1\ln a_1 \simeq \left( \overline{S}_{1,\mathrm{solid}}^o-\overline{S}_1^o \right)\Delta T
\tag{17}
```

を得る．

問題文の $\overline{L}_1$ を，解答例と同じく凝固の場合にも

```math
\overline{L}_1 =T_1^o \left( \overline{S}_{1,\mathrm{solid}}^o-\overline{S}_1^o \right)<0
\tag{18}
```

と定義する．
これは，凝固に伴うエントロピー変化が負であることによる．
式(17)，(18)より，

```math
-\ln a_1 \simeq \frac{\overline{L}_1}{R} \frac{\Delta T}{T_1T_1^o}
```

となる．
ここでも $T_1\simeq T_1^o$ と近似すれば，

```math
-\ln a_1 \simeq \frac{\overline{L}_1\Delta T}{R(T_1^o)^2}
```

である．
したがって，

```math
\boxed{
\Delta T =-\frac{R(T_1^o)^2}{\overline{L}_1}\ln a_1
}
```

を得る．
氷点降下では $\overline{L}_1<0$ かつ $\ln a_1<0$ であるため，右辺は負となり， $\Delta T<0$ が得られる．
よって，溶液の凝固温度は純溶媒の凝固温度より低くなる．

## 3．結論

以上より，求める3つの近似式は，

```math
\boxed{
p_1\simeq p_1^o a_1
}
```

```math
\boxed{
\pi\overline{V}_1^o=-RT\ln a_1
}
```

```math
\boxed{
\Delta T=-\frac{R(T_1^o)^2}{\overline{L}_1}\ln a_1
}
```

である．
最後の式では， $\overline{L}_1$ は蒸発の場合には正，凝固の場合には負となるように定義している．
この符号規約により，同じ式で沸点上昇と氷点降下の両方を表せる．

なお，これらは液相の体積変化と温度変化に関する近似に基づく式である．
また，沸点上昇・氷点降下の導出では，気相または固相が純粋な溶媒からなるという問題文の仮定が重要である．
溶質が気相へ移行したり，固相に取り込まれたりする場合には，同じ結論が必ずしも成り立つわけではない．
