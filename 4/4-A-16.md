# 演習問題【4-A-16】

## 解答

**(1) 平衡条件**

液相と気相が平衡状態にあるとき，成分 $j$ の液相における化学ポテンシャル $\bar{G}_{j, \text{liq}}$ と気相における化学ポテンシャル $\bar{G}_{j, \text{gas}}$ は等しくなる：

$$\bar{G}_{j, \text{liq}} = \bar{G}_{j, \text{gas}}$$

**(2) 化学ポテンシャルの式**

理想溶液において，温度 $T$ ，圧力 $p$ ，成分 $j$ のモル分率 $x_j$ のときの成分 $j$ の液相における化学ポテンシャルは次のように書ける：

$$\bar{G}_{j, \text{liq}}(T, p, x_j) = \bar{G}_{j, \text{liq}}^0(T, p) + RT \log x_j$$

ここで， $\bar{G}_{j, \text{liq}}^0(T, p)$ は圧力 $p$ における純粋な液相 $j$ の化学ポテンシャルである．

一方，成分 $j$ が理想気体として振る舞うとき，その分圧 $p_j$ における気相の化学ポテンシャルは次のように書ける：

$$\bar{G}_{j, \text{gas}}(T, p_j) = \bar{G}_{j, \text{gas}}^0(T) + RT \log p_j$$

ここで， $\bar{G}_{j, \text{gas}}^0(T)$ は純粋な理想気体 $j$ の化学ポテンシャルであり，理想気体では圧力に依存しない．

**(3) 平衡条件の代入**

これらを平衡条件の式に代入すると：

$$\bar{G}_{j, \text{liq}}^0(T, p) + RT \log x_j = \bar{G}_{j, \text{gas}}^0(T) + RT \log p_j \quad \cdots (\text{A})$$

また，純粋な成分 $j$ がその蒸気圧 $p_j^0$ の気相と平衡にあるとき：

$$\bar{G}_{j, \text{liq}}^0(T, p_j^0) = \bar{G}_{j, \text{gas}}^0(T) + RT \log p_j^0 \quad \cdots (\text{B})$$

**(4) 関係式の導出**

式(A)から式(B)を引くことで， $\bar{G}_{j, \text{gas}}^0(T)$ を消去する：

$$\bar{G}_{j, \text{liq}}^0(T, p) - \bar{G}_{j, \text{liq}}^0(T, p_j^0) + RT \log x_j = RT (\log p_j - \log p_j^0)$$

左辺の差を $\Delta \bar{G}_{j, \text{liq}}^0 = \bar{G}_{j, \text{liq}}^0(T, p) - \bar{G}_{j, \text{liq}}^0(T, p_j^0)$ とおくと：

$$\Delta \bar{G}_{j, \text{liq}}^0 + RT \log x_j = RT \log \left( \frac{p_j}{p_j^0} \right)$$

$$\log \left( \frac{p_j}{p_j^0} \right) = \log x_j + \frac{\Delta \bar{G}_{j, \text{liq}}^0}{RT}$$

指数関数をとると：

$$\frac{p_j}{p_j^0} = x_j \exp \left( \frac{\Delta \bar{G}_{j, \text{liq}}^0}{RT} \right)$$

**(5) 近似の実行**

$\Delta \bar{G}_{j, \text{liq}}^0$ について， $p_j^0$ のまわりでテイラー展開を行う．

$$\Delta \bar{G}_{j, \text{liq}}^0 \approx \left( \frac{\partial \bar{G}_{j, \text{liq}}^0}{\partial p} \right)_T (p - p_j^0)$$

熱力学の基本関係式 $\left( \frac{\partial \bar{G}}{\partial p} \right)_T = \bar{V}$ （モル体積）より：

$$\Delta \bar{G}_{j, \text{liq}}^0 \approx \bar{V}_{j, \text{liq}}^0 (p - p_j^0)$$

これを指数関数の項に代入する：

$$\frac{\Delta \bar{G}_{j, \text{liq}}^0}{RT} \approx \frac{\bar{V}_{j, \text{liq}}^0 (p - p_j^0)}{RT}$$

理想気体の状態方程式より，純粋な気体のモル体積は $\bar{V}_{j, \text{gas}}^0 = \frac{RT}{p_j^0}$ である．
これを用いると $RT = p_j^0 \bar{V}_{j, \text{gas}}^0$ と書けるので：

$$\frac{\Delta \bar{G}_{j, \text{liq}}^0}{RT} \approx \frac{\bar{V}_{j, \text{liq}}^0 (p - p_j^0)}{p_j^0 \bar{V}_{j, \text{gas}}^0} = \frac{\bar{V}_{j, \text{liq}}^0}{\bar{V}_{j, \text{gas}}^0} \frac{p - p_j^0}{p_j^0}$$

通常，液体のモル体積 $\bar{V}_{j, \text{liq}}^0$ は気体のモル体積 $\bar{V}_{j, \text{gas}}^0$ に比べて極めて小さいため， $\frac{\bar{V}_{j, \text{liq}}^0}{\bar{V}_{j, \text{gas}}^0} \ll 1$ である．
したがって，この項は非常に小さくなり：

$$\frac{\bar{V}_{j, \text{liq}}^0}{\bar{V}_{j, \text{gas}}^0} \frac{p - p_j^0}{p_j^0} \ll 1$$

ゆえに $\exp(\text{微小量}) \approx 1$ と近似できる．
したがって，

$$\frac{p_j}{p_j^0} \approx x_j \cdot 1 \implies p_j \approx x_j p_j^0$$

となり，蒸気圧がモル分率に比例することが示された．

## 解説

- **化学ポテンシャル ( $\bar{G}$ ):**
  物質が移動しようとする「勢い」や「エネルギーの余裕」を表す指標である．
  平衡状態では，液相と気相の間でこの「勢い」が等しくなる．
- **モル分率 ( $x_j$ ):**
  混合物全体の中に，成分 $j$ がどのくらいの割合で含まれているかを示す数値である．
- **理想溶液・理想気体:**
  分子間の相互作用が非常に単純化されており，扱いやすいモデルである．
- **なぜ近似が成り立つのか:**
  この問題の本質は，「液体を気体にするために必要なエネルギー」が，「液体と気体の体積の差」に依存している点にある．
  液体は非常に密度が高いため，気体と比較して体積が極めて小さいである．
  そのため，圧力が多少変化しても，液相の化学ポテンシャルの変化量は気相のそれに対して無視できるほど小さくなる．
  これが，蒸気圧がモル分率に単純に比例するという結果を導いている．
