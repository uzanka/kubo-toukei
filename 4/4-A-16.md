# 演習問題【4-A-16】

## 解答

### (1) 液相と気相の平衡条件

成分 $j$ を含む理想溶液が，その蒸気と平衡状態にあるとする．
このとき，成分 $j$ の液相における化学ポテンシャルと気相における化学ポテンシャルは等しい．
したがって，

```math
\bar G_{j,\mathrm{liq}}=\bar G_{j,\mathrm{gas}}
```

が成り立つ．
ここで，化学ポテンシャルとは，物質の出入りに伴うギブズエネルギーの変化を表す量であり，液相と気相の間で物質が移動し続けない平衡状態では，両相の化学ポテンシャルが等しくなる．

### (2) 化学ポテンシャルの式を代入する

温度を $T$ ，液相の圧力を $p$ ，成分 $j$ の液相中のモル分率を $x_j$ とする．
理想溶液では，成分 $j$ の液相における化学ポテンシャルは

```math
\bar G_{j,\mathrm{liq}}
=
\bar G_{j,\mathrm{liq}}^0(T,p)+RT\log x_j
```

と表される．
ここで， $\bar G_{j,\mathrm{liq}}^0(T,p)$ は，温度 $T$ ，圧力 $p$ における純粋な液体 $j$ の化学ポテンシャルであり， $R$ は気体定数である．

一方，気相が理想気体とみなせる場合，成分 $j$ の分圧を $p_j$ とすると，その化学ポテンシャルは

```math
\bar G_{j,\mathrm{gas}}
=
\bar G_{j,\mathrm{gas}}^0(T)+RT\log p_j
```

と書ける．
この式の対数は，厳密には基準圧力で割った無次元量に対して取るものであるが，以下では解答例と同じ表記を用いる．
$\bar G_{j,\mathrm{gas}}^0(T)$ は気相の基準状態における化学ポテンシャルである．

これらの式を平衡条件に代入すると，

```math
\begin{aligned}
&\bar G_{j,\mathrm{liq}}^0(T,p)+RT\log x_j\\
&\qquad=\bar G_{j,\mathrm{gas}}^0(T)+RT\log p_j
\end{aligned}
\tag{1}
```

を得る．

### (3) 純物質の蒸気圧を用いて整理する

次に，成分 $j$ が純粋な液体として存在し，その蒸気と平衡にある場合を考える．
このときの飽和蒸気圧を $p_j^0$ とする．
純粋な液体のモル分率は $1$ であるため，液相の化学ポテンシャルは $\bar G_{j,\mathrm{liq}}^0(T,p_j^0)$ である．
平衡条件より，

```math
\bar G_{j,\mathrm{liq}}^0(T,p_j^0)
=
\bar G_{j,\mathrm{gas}}^0(T)+RT\log p_j^0
\tag{2}
```

が成り立つ．

式 (1) から式 (2) を引くと，気相の基準化学ポテンシャルが消去され，

```math
\begin{aligned}
&\bar G_{j,\mathrm{liq}}^0(T,p)
-\bar G_{j,\mathrm{liq}}^0(T,p_j^0)
+RT\log x_j\\
&\qquad=RT\log\frac{p_j}{p_j^0}
\end{aligned}
```

となる．
両辺を $RT$ で割り，対数の項を整理すると，

```math
\log\frac{p_j}{p_j^0}
=
\log x_j+
\frac{\Delta\bar G_{j,\mathrm{liq}}^0}{RT}
```

を得る．
ただし，

```math
\Delta\bar G_{j,\mathrm{liq}}^0
=
\bar G_{j,\mathrm{liq}}^0(T,p)
-\bar G_{j,\mathrm{liq}}^0(T,p_j^0)
```

と定義した．
両辺の指数を取れば，

```math
\boxed{
\frac{p_j}{p_j^0}
=
x_j\exp\left(
\frac{\Delta\bar G_{j,\mathrm{liq}}^0}{RT}
\right)
}
\tag{3}
```

となる．
この式から，蒸気圧とモル分率の比例関係が成り立つかどうかは，指数関数の肩にある $\Delta\bar G_{j,\mathrm{liq}}^0/(RT)$ が十分小さいかどうかで決まることが分かる．

### (4) 液相の化学ポテンシャルの変化を評価する

$\Delta\bar G_{j,\mathrm{liq}}^0$ は，純粋な液体の圧力が $p_j^0$ から $p$ に変化したときの化学ポテンシャルの変化である．
圧力変化が十分小さい範囲では， $p_j^0$ の周りでテイラー展開し，1次の項まで残すことで，

```math
\Delta\bar G_{j,\mathrm{liq}}^0
\approx
\left(
\frac{\partial\bar G_{j,\mathrm{liq}}^0}{\partial p}
\right)_T
(p-p_j^0)
```

と近似できる．

熱力学の関係式

```math
\left(\frac{\partial\bar G}{\partial p}\right)_T
=\bar V
```

によれば，温度一定での化学ポテンシャルの圧力微分はモル体積 $\bar V$ に等しい．
したがって，

```math
\Delta\bar G_{j,\mathrm{liq}}^0
\approx
\bar V_{j,\mathrm{liq}}^0(p-p_j^0)
```

である．
ここで， $\bar V_{j,\mathrm{liq}}^0$ は純粋な液体 $j$ のモル体積である．
よって，

```math
\frac{\Delta\bar G_{j,\mathrm{liq}}^0}{RT}
\approx
\frac{\bar V_{j,\mathrm{liq}}^0(p-p_j^0)}{RT}
\tag{4}
```

となる．

さらに，純粋な成分 $j$ の蒸気を理想気体とみなすと，飽和蒸気圧 $p_j^0$ におけるモル体積は，理想気体の状態方程式より，

```math
\bar V_{j,\mathrm{gas}}^0=\frac{RT}{p_j^0}
```

である．
これを式 (4) に用いると，

```math
\boxed{
\frac{\Delta\bar G_{j,\mathrm{liq}}^0}{RT}
\approx
\frac{\bar V_{j,\mathrm{liq}}^0}
{\bar V_{j,\mathrm{gas}}^0}
\frac{p-p_j^0}{p_j^0}
}
\tag{5}
```

が得られる．

### (5) 近似がほとんどの場合に許されることを示す

通常，液体は気体に比べて密度が非常に大きいため，同じ物質について，液体のモル体積は飽和蒸気のモル体積よりはるかに小さい．
すなわち，

```math
\frac{\bar V_{j,\mathrm{liq}}^0}
{\bar V_{j,\mathrm{gas}}^0}\ll 1
```

である．
また，通常の条件では，液相の圧力 $p$ が飽和蒸気圧 $p_j^0$ に対して極端に大きく異なるわけではないため， $\lvert p-p_j^0\rvert/p_j^0$ が体積比の小ささを打ち消すほど大きくなることは一般にない．
したがって，式 (5) の右辺は十分小さく，

```math
\left|
\frac{\Delta\bar G_{j,\mathrm{liq}}^0}{RT}
\right|\ll1
```

とみなせる場合が多い．

指数関数の肩が十分小さいとき，

```math
\exp(\varepsilon)\approx1
\qquad (|\varepsilon|\ll1)
```

という近似が成り立つ．
これを式 (3) に適用すると，

```math
\frac{p_j}{p_j^0}
\approx x_j
```

となる．
したがって，

```math
\boxed{
p_j\approx x_jp_j^0
}
```

が得られる．

以上より，気相が理想気体とみなせ，液相の圧力条件が通常の範囲にある場合，理想溶液中の成分 $j$ の蒸気の分圧は，液相中のモル分率に近似的に比例することが示された．
