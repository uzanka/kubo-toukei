# 演習問題【4-A-16】

## 解答

成分 $j$ の液相と気相が相平衡にあるとき，化学ポテンシャルは等しいので，

```math
\mu_{j,\mathrm{liq}}=\mu_{j,\mathrm{gas}}
\tag{1}
```

が成り立つ．

理想溶液では，液相中の成分 $j$ の化学ポテンシャルは

```math
\mu_{j,\mathrm{liq}}
=\mu_{j,\mathrm{liq}}^0(T,p)+RT\ln x_j
\tag{2}
```

と表される．
また，気相を理想気体とみなすと，

```math
\mu_{j,\mathrm{gas}}
=\mu_{j,\mathrm{gas}}^0(T)
+RT\ln\frac{p_j}{p^\circ}
\tag{3}
```

である．
ここで， $x_j$ は液相中の成分 $j$ のモル分率， $p_j$ は気相中の成分 $j$ の分圧， $p^\circ$ は標準圧力である．

純粋な成分 $j$ の液体とその飽和蒸気が平衡にあるとき，飽和蒸気圧を $p_j^0$ とすると，

```math
\mu_{j,\mathrm{liq}}^0(T,p_j^0)
=
\mu_{j,\mathrm{gas}}^0(T)
+RT\ln\frac{p_j^0}{p^\circ}
\tag{4}
```

が成り立つ．

式 (1)～(4) より，

```math
\ln\frac{p_j}{p_j^0}
=
\ln x_j+
\frac{
\mu_{j,\mathrm{liq}}^0(T,p)
-\mu_{j,\mathrm{liq}}^0(T,p_j^0)
}{RT}
```

したがって，

```math
p_j
=x_jp_j^0
\exp\left[
\frac{
\mu_{j,\mathrm{liq}}^0(T,p)
-\mu_{j,\mathrm{liq}}^0(T,p_j^0)
}{RT}
\right]
\tag{5}
```

を得る．

ここで，化学ポテンシャルの圧力微分は部分モル体積に等しいため，

```math
\left(
\frac{\partial\mu_{j,\mathrm{liq}}^0}{\partial p}
\right)_T
=V_{j,\mathrm{liq}}^0(T,p)
```

である．
よって，

```math
\mu_{j,\mathrm{liq}}^0(T,p)
-\mu_{j,\mathrm{liq}}^0(T,p_j^0)
=
\int_{p_j^0}^{p}
V_{j,\mathrm{liq}}^0(T,p')\,dp'
```

となる．
これを式 (5) に代入すると，

```math
p_j
=x_jp_j^0
\exp\left[
\frac{1}{RT}
\int_{p_j^0}^{p}
V_{j,\mathrm{liq}}^0(T,p')\,dp'
\right]
\tag{6}
```

を得る．

通常，液体の圧縮率は小さいため，圧力範囲内で液体のモル体積がほとんど変化しないと近似できる．
このとき，

```math
\int_{p_j^0}^{p}
V_{j,\mathrm{liq}}^0(T,p')\,dp'
\simeq
V_{j,\mathrm{liq}}^0(T)(p-p_j^0)
```

であり，式 (6) は

```math
p_j
\simeq x_jp_j^0
\exp\left[
\frac{V_{j,\mathrm{liq}}^0(T)(p-p_j^0)}{RT}
\right]
\tag{7}
```

となる．

したがって，指数部の絶対値

```math
\left|
\frac{V_{j,\mathrm{liq}}^0(T)(p-p_j^0)}{RT}
\right|
```

が十分小さければ，指数関数を一次近似して，

```math
\exp\left[
\frac{V_{j,\mathrm{liq}}^0(T)(p-p_j^0)}{RT}
\right]
\simeq 1
```

とできる．
この条件のもとで，

```math
\boxed{p_j\simeq x_jp_j^0}
\tag{8}
```

が得られる．
すなわち，理想溶液の成分 $j$ の蒸気圧は，その液相中のモル分率に近似的に比例する．

最後に，この近似が通常の条件で十分よく成り立つことを確認する．
常温付近では，液体のモル体積はおおむね

```math
V_{j,\mathrm{liq}}^0\sim10^{-4}\ \mathrm{m^3\,mol^{-1}}
```

程度である．
また，圧力差を通常の大気圧程度，

```math
|p-p_j^0|\sim10^5\ \mathrm{Pa}
```

とすると，

```math
V_{j,\mathrm{liq}}^0|p-p_j^0|
\sim10\ \mathrm{J\,mol^{-1}}
```

である．
一方，常温では

```math
RT\sim2.5\times10^3\ \mathrm{J\,mol^{-1}}
```

なので，

```math
\left|
\frac{V_{j,\mathrm{liq}}^0(p-p_j^0)}{RT}
\right|
\sim 4\times10^{-3}\ll1
```

となる．
したがって，通常の液体および圧力条件では指数部は十分小さく，式 (8) の近似はよく成り立つ．
ただし，非常に高い圧力などでは圧力補正を無視できない場合がある．
