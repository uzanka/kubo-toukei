# 演習問題【4-A-12】

## 解答

### 証明

温度 $T$ と圧力 $p$ が一定の2成分系において，Gibbs–Duhem の関係式は

```math
x_1\,d\bar{G}_1+x_2\,d\bar{G}_2=0
\tag{1}
```

と表される．
ここで， $\bar{G}_i$ は成分 $i$ の化学ポテンシャル， $x_i$ は成分 $i$ のモル分率である．
また，モル分率の和は1であるため，

```math
x_1+x_2=1
```

が成り立つ．
これを微分すると，

```math
dx_1+dx_2=0
```

したがって，

```math
dx_1=-dx_2
\tag{2}
```

を得る．

次に，問題で与えられた成分1の化学ポテンシャル

```math
\bar{G}_1=\bar{G}_1^*(T,p)+RT\log x_1
\tag{3}
```

を考える．
温度 $T$ と圧力 $p$ は一定であるため， $\bar{G}_1^*(T,p)$ と $RT$ は定数として扱える．
よって，式(3)を微分すると，

```math
d\bar{G}_1
=RT\,d(\log x_1)
=\frac{RT}{x_1}\,dx_1
\tag{4}
```

となる．

式(4)を式(1)に代入すると，

```math
x_1\frac{RT}{x_1}\,dx_1
+x_2\,d\bar{G}_2=0
```

すなわち，

```math
RT\,dx_1+x_2\,d\bar{G}_2=0
\tag{5}
```

である．
ここに式(2)の $dx_1=-dx_2$ を代入すると，

```math
-RT\,dx_2+x_2\,d\bar{G}_2=0
```

したがって，

```math
d\bar{G}_2=\frac{RT}{x_2}\,dx_2
\tag{6}
```

を得る．

式(6)の両辺を積分する．
温度 $T$ と圧力 $p$ を一定に保ち，純粋な成分2の状態 $x_2=1$ から任意の組成 $x_2$ まで積分すると，

```math
\int_{\bar{G}_2^*(T,p)}^{\bar{G}_2}
d\bar{G}_2
=
RT\int_1^{x_2}\frac{1}{u}\,du
```

となる．
ここで， $u$ は積分のために導入した変数である．
左辺を積分すると $\bar{G}_2-\bar{G}_2^*(T,p)$ ，右辺を積分すると $RT\log x_2$ となるため，

```math
\bar{G}_2-\bar{G}_2^*(T,p)
=RT\log x_2
```

を得る．
ここでは， $\log 1=0$ を用いた．

以上より，

```math
\boxed{
\bar{G}_2=\bar{G}_2^*(T,p)+RT\log x_2
}
```

となる．
したがって，成分1の化学ポテンシャルが問題で与えられた形で表されるならば，成分2の化学ポテンシャルも同じ形で表されることが示された．

## 解説

### 1．化学ポテンシャルとは何か

化学ポテンシャル $\bar{G}_i$ は，温度と圧力を一定に保ち，他の成分の物質量も一定としたときに，成分 $i$ の物質量を変化させた際の Gibbs 自由エネルギーの変化率である．
つまり，成分を系に加えたときに Gibbs 自由エネルギーがどの程度変化するかを表す量である．

### 2．Gibbs–Duhem の関係式が示すこと

Gibbs–Duhem の関係式

```math
x_1\,d\bar{G}_1+x_2\,d\bar{G}_2=0
```

は，温度と圧力が一定のとき，混合系の各成分の化学ポテンシャルの変化が互いに独立ではないことを示している．
2成分系では，モル分率の和が1であるため，一方のモル分率が変化すれば他方も変化する．
この制約と Gibbs–Duhem の関係式を組み合わせることで，一方の成分の化学ポテンシャルが分かれば，他方の成分の組成依存性も導くことができる．

本問では，成分1の化学ポテンシャルを微分して Gibbs–Duhem の関係式に代入し，成分2の化学ポテンシャルの微分を求めた後，積分によってその式を導出したのである．
