# 演習問題【4-A-12】

## 解答

**【問題の整理】**
2成分系の溶液において，成分1と成分2のモル分率を $x_1, x_2$ とする．
一方の成分（成分1）の化学ポテンシャル $\bar{G}_1$ が次のように表されるとき，

$$\bar{G}_1 = \bar{G}_1^*(T, p) + RT \log x_1$$

もう一方の成分（成分2）の化学ポテンシャル $\bar{G}_2$ も次のように表されることを示す．

$$\bar{G}_2 = \bar{G}_2^*(T, p) + RT \log x_2$$

ここで， $\bar{G}_i^*$ は純粋な成分 $i$ の化学ポテンシャル， $R$ は気体定数， $T$ は絶対温度， $p$ は圧力である．

**【証明】**

**1. Gibbs-Duhem（ギブス-デュエム）の関係式を用いる**

温度 $T$ と圧力 $p$ が一定のとき，2成分系における化学ポテンシャルの変化の間には，以下の **Gibbs-Duhem の関係式** が成り立つ．

$$x_1 d\bar{G}_1 + x_2 d\bar{G}_2 = 0 \quad \cdots (1)$$

また，成分1と成分2のモル分率には，合計が1になるという制約がある．

$$x_1 + x_2 = 1 \quad \cdots (2)$$

式(2)の両辺を微分すると， $dx_1 + dx_2 = 0$ となり，以下の関係が得られる．

$$dx_1 = -dx_2 \quad \cdots (3)$$

**2. 成分1の化学ポテンシャルの微分を求める**

与えられた成分1の化学ポテンシャルの式を微分する．
温度 $T$ と圧力 $p$ は一定であるため， $\bar{G}_1^*(T, p)$ は定数として扱える．

$$\bar{G}_1 = \bar{G}_1^*(T, p) + RT \log x_1$$

これを微分すると，

$$d\bar{G}_1 = d(\bar{G}_1^*(T, p)) + d(RT \log x_1)$$

$$d\bar{G}_1 = 0 + RT \frac{d(\log x_1)}{dx_1} dx_1$$

$\frac{d(\log x_1)}{dx_1} = \frac{1}{x_1}$ なので，

$$d\bar{G}_1 = \frac{RT}{x_1} dx_1 \quad \cdots (4)$$

となる．

**3. Gibbs-Duhem の関係式に代入する**

式(4)を，式(1)の $d\bar{G}_1$ の部分に代入する．

$$x_1 \left( \frac{RT}{x_1} dx_1 \right) + x_2 d\bar{G}_2 = 0$$

式を整理すると，

$$RT dx_1 + x_2 d\bar{G}_2 = 0 \quad \cdots (5)$$

となる．

**4. $dx_1$ を $dx_2$ に書き換える**

式(3)の関係 $dx_1 = -dx_2$ を，式(5)に代入する．

$$RT (-dx_2) + x_2 d\bar{G}_2 = 0$$

$$-RT dx_2 + x_2 d\bar{G}_2 = 0$$

これを $d\bar{G}_2$ について解くと，

$$x_2 d\bar{G}_2 = RT dx_2$$

$$d\bar{G}_2 = \frac{RT}{x_2} dx_2 \quad \cdots (6)$$

が得られる．

**5. 積分して $\bar{G}_2$ を求める**

式(6)の両辺を積分する．
積分範囲は，純粋な成分2の状態 ( $x_2 = 1$ ) から，溶液中の状態 ( $x_2$ ) までとする．

$$\int_{\bar{G}_2^*(T, p)}^{\bar{G}_2} d\bar{G}_2 = \int_{1}^{x_2} \frac{RT}{x_2} dx_2$$

左辺の積分は，

$$\bar{G}_2 - \bar{G}_2^*(T, p)$$

右辺の積分は，

$$RT [\log x_2]_1^{x_2} = RT (\log x_2 - \log 1)$$

$\log 1 = 0$ なので，

$$\bar{G}_2 - \bar{G}_2^*(T, p) = RT \log x_2$$

したがって，

$$\bar{G}_2 = \bar{G}_2^*(T, p) + RT \log x_2$$

が示された．

## 解説

この問題は，多成分系の熱力学における非常に重要な関係式である **Gibbs-Duhem（ギブス-デュエム）の関係式** を用いて，成分間の化学ポテンシャルの依存性を導出するものである．

### 1. 化学ポテンシャルとは？

化学ポテンシャル $\bar{G}_i$ とは，ある成分 $i$ が系に加わったときに，系のギブス自由エネルギーがどれくらい変化するかを表す量である．
溶液中の成分の「化学的な勢い」のようなものだと考えると分かりやすい．

### 2. Gibbs-Duhem の関係式

溶液のように複数の成分が混ざっている系では，各成分の化学ポテンシャルは互いに独立ではなく，何らかの制約を受けている．
それが Gibbs-Duhem の関係式である．
「温度と圧力が一定ならば，各成分のモル分率の変化と，それに対応する化学ポテンシャルの変化の間には，特定のバランス（ $x_1 d\bar{G}_1 + x_2 d\bar{G}_2 = 0$ ）が保たれる」ということを意味している．

### 3. 解法のポイント

この問題を解く鍵は，以下の2点である．
- **制約条件の利用**:
  モル分率の和が1であること（ $x_1 + x_2 = 1$ ）から，一方が増えればもう一方が減るという関係（ $dx_1 = -dx_2$ ）を導き出すこと．
- **微分と積分の往復**:
  与えられた式を微分して Gibbs-Duhem の式に代入し，そこから得られた $d\bar{G}_2$ の式を再び積分することで，元の $\bar{G}_2$ の形を復元すること．

このように，Gibbs-Duhem の式を使うことで，一つの成分の挙動が分かれば，もう一方の成分の挙動も自動的に決まることが数学的に示される．
