# 演習問題【4-A-3】

## 解答

液体と気体の相平衡に対する Clausius–Clapeyron の式は，

```math
\frac{dp}{dT}=\frac{q}{T(v_g-v_l)}
```

である．
ここで， $p$ は圧力， $T$ は絶対温度， $q$ は単位質量あたりの気化熱， $v_g$ は水蒸気の比容， $v_l$ は液体の水の比容である．
この式を $q$ について解くと，

```math
q=T(v_g-v_l)\frac{dp}{dT}
```

となる．

水蒸気の比容は液体の水の比容に比べて非常に大きいため，

```math
v_g-v_l\approx v_g
```

と近似できる．
したがって，

```math
q\approx Tv_g\frac{dp}{dT}
\tag{1}
```

である．

問題文より， $100\,^\circ\mathrm{C}$ ， $1\,\mathrm{atm}$ において，

```math
T=373\ \mathrm{K},\qquad
\frac{dT}{dp}=\frac{1}{27.12}\ 
\mathrm{K/mmHg}
```

である．
よって，

```math
\frac{dp}{dT}=27.12\ \mathrm{mmHg/K}
```

となる．

次に，水蒸気の比容 $v_g$ を理想気体の状態方程式から求める．
モル質量を $M=18.02\ \mathrm{g/mol}$ ，気体定数を $R=1.987\ \mathrm{cal/(mol\cdot K)}$ とすると，

```math
pv_g=\frac{RT}{M}
```

より，

```math
v_g=\frac{RT}{pM}
```

である．
この式で圧力 $p$ を $\mathrm{cal/cm^3}$ で表すため，圧力の単位を換算する．

```math
1\ \mathrm{cal}=4.18\times10^7\ \mathrm{erg}
```

かつ，

```math
1\ \mathrm{erg/cm^3}=1\ \mathrm{dyn/cm^2}
```

である．
水銀の密度を $13.6\ \mathrm{g/cm^3}$ ，重力加速度を $980\ \mathrm{cm/s^2}$ とすると，

```math
1\ \mathrm{cmHg}
=13.6\times980\ \mathrm{dyn/cm^2}
```

であるから，

```math
1\ \mathrm{cal/cm^3}
=\frac{4.18\times10^7}{13.6\times980}
\ \mathrm{cmHg}
\approx3.13\times10^3\ \mathrm{cmHg}
```

を得る．
したがって，

```math
1\ \mathrm{cal/cm^3}
\approx3.13\times10^4\ \mathrm{mmHg}
```

である．
よって， $1\,\mathrm{atm}=760\,\mathrm{mmHg}$ は，

```math
p=\frac{760}{3.13\times10^4}
\ \mathrm{cal/cm^3}
```

と表せる．
これを理想気体の状態方程式に代入すると，

```math
\begin{aligned}
v_g
&=\frac{1.987\times373}
{\left(760/(3.13\times10^4)\right)\times18.02}\\
&\approx1.69\times10^3\ \mathrm{cm^3/g}
\end{aligned}
```

となる．

最後に，式 (1) に代入する．圧力の単位換算を反映するため，

```math
1\ \mathrm{mmHg}\cdot\mathrm{cm^3}
=\frac{1}{3.13\times10^4}\ \mathrm{cal}
```

を用いると，

```math
\begin{aligned}
q
&\approx373\times
\left(1.69\times10^3\right)\times27.12
\times\frac{1}{3.13\times10^4}\\
&\approx5.47\times10^2\ \mathrm{cal/g}
\end{aligned}
```

である．
したがって，求める気化熱は，

```math
\boxed{
q\approx547\ \mathrm{cal/g}
}
```

である．
