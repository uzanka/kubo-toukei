# 例題【4-R-10】

## 解答

Daniell電池の各相を，問題の指示に従い以下のように定義する．

- 相 I: $\text{Cu}$ 金属
- 相 II: $\text{CuSO}_4(\text{aq})$ 溶液
- 相 III: $\text{ZnSO}_4(\text{aq})$ 溶液
- 相 IV: $\text{Zn}$ 金属
- 相 V: $\text{Cu}$ 金属（端子）

各相の静電位を $\phi_{\text{I}}, \phi_{\text{II}}, \phi_{\text{III}}, \phi_{\text{IV}}, \phi_{\text{V}}$ とする．
また，ある成分 $i$ の電気化学ポテンシャル $\bar{\mu}_i$ は，化学ポテンシャル $\mu_i$ と電荷 $z_i e$ ，静電位 $\phi$ を用いて $\bar{\mu}_i = \mu_i + z_i e \phi$ と表される．

### 1. 各界面における平衡条件

隣接する相の間では，電気化学ポテンシャルが等しくなる（平衡条件）必要がある．

**相 I と 相 II の間 ( $\text{Cu}^{++}$ の平衡):**

$\text{Cu}$ 金属（相 I）と $\text{CuSO}_4$ 溶液（相 II）の間で $\text{Cu}^{++}$ が平衡状態にあると考える．

$$\bar{\mu}_{\text{Cu}^{++}}(\text{I}) = \bar{\mu}_{\text{Cu}^{++}}(\text{II})$$

ここで， $\text{Cu}^{++}$ は相 I には直接存在しないが，金属中の平衡 $\text{Cu} \rightleftharpoons \text{Cu}^{++} + 2\text{e}$ を用いて，相 I における $\text{Cu}^{++}$ の化学ポテンシャルを $\mu_{\text{Cu}^{++}}(\text{I}) = \mu_{\text{Cu}}(\text{I}) - 2\mu_{\text{e}}(\text{I})$ と定義できる．
これを用いると，

$$\mu_{\text{Cu}^{++}}(\text{I}) + 2e\phi_{\text{I}} = \mu_{\text{Cu}^{++}}(\text{II}) + 2e\phi_{\text{II}} \quad \cdots (1)$$

**相 II と 相 III の間 ( $\text{SO}_4^{--}$ の平衡):**

$\text{SO}_4^{--}$ は両方の溶液相に存在するため，

$$\bar{\mu}_{\text{SO}_4^{--}}(\text{II}) = \bar{\mu}_{\text{SO}_4^{--}}(\text{III})$$

$$\mu_{\text{SO}_4^{--}}(\text{II}) - 2e\phi_{\text{II}} = \mu_{\text{SO}_4^{--}}(\text{III}) - 2e\phi_{\text{III}} \quad \cdots (2)$$

ただし，問題の仮定より， $\text{CuSO}_4$ 溶液と $\text{ZnSO}_4$ 溶液の境界には電位差がないため， $\phi_{\text{II}} = \phi_{\text{III}}$ である．
これにより，式 (2) は $\mu_{\text{SO}_4^{--}}(\text{II}) = \mu_{\text{SO}_4^{--}}(\text{III})$ となり，この項は計算から除外できる．

**相 III と 相 IV の間 ( $\text{Zn}^{++}$ の平衡):**

$\text{ZnSO}_4$ 溶液（相 III）と $\text{Zn}$ 金属（相 IV）の間で，

$$\bar{\mu}_{\text{Zn}^{++}}(\text{III}) = \bar{\mu}_{\text{Zn}^{++}}(\text{IV})$$

$$\mu_{\text{Zn}^{++}}(\text{III}) + 2e\phi_{\text{III}} = \mu_{\text{Zn}^{++}}(\text{IV}) + 2e\phi_{\text{IV}} \quad \cdots (3)$$

**相 IV と 相 V の間 (電子の平衡):**

電池の外部回路（端子 IV から端子 V）を通じて電子が移動するため，電子の電気化学ポテンシャルは平衡している．

$$\bar{\mu}_{\text{e}}(\text{IV}) = \bar{\mu}_{\text{e}}(\text{V})$$

$$\mu_{\text{e}}(\text{IV}) - e\phi_{\text{IV}} = \mu_{\text{e}}(\text{V}) - e\phi_{\text{V}} \quad \cdots (4)$$

### 2. 金属相における化学ポテンシャルの関係

金属中での反応 $\text{M} \rightleftharpoons \text{M}^{++} + 2\text{e}$ ( $\text{M} = \text{Cu}, \text{Zn}$ ) を考えると，化学ポテンシャルの間には以下の関係がある．

$$\mu_{\text{M}} = \mu_{\text{M}^{++}} + 2\mu_{\text{e}} \quad \cdots (5)$$

### 3. 起電力の導出

起電力 $E$ は，端子間の電位差 $E = \phi_{\text{I}} - \phi_{\text{V}}$ である．
式 (1), (3), (4) を組み合わせることで，中間的な項を消去する．
具体的には， $(1) + (3) - 2 \times (4)$ を計算する．

左辺:

$$(\mu_{\text{Cu}^{++}}(\text{I}) + 2e\phi_{\text{I}}) + (\mu_{\text{Zn}^{++}}(\text{III}) + 2e\phi_{\text{III}}) - 2(\mu_{\text{e}}(\text{IV}) - e\phi_{\text{IV}})$$

$$= \mu_{\text{Cu}^{++}}(\text{I}) + \mu_{\text{Zn}^{++}}(\text{III}) - 2\mu_{\text{e}}(\text{IV}) + 2e\phi_{\text{I}} + 2e\phi_{\text{III}} + 2e\phi_{\text{IV}}$$

右辺:

$$(\mu_{\text{Cu}^{++}}(\text{II}) + 2e\phi_{\text{II}}) + (\mu_{\text{Zn}^{++}}(\text{IV}) + 2e\phi_{\text{IV}}) - 2(\mu_{\text{e}}(\text{V}) - e\phi_{\text{V}})$$

$$= \mu_{\text{Cu}^{++}}(\text{II}) + \mu_{\text{Zn}^{++}}(\text{IV}) - 2\mu_{\text{e}}(\text{V}) + 2e\phi_{\text{II}} + 2e\phi_{\text{IV}} + 2e\phi_{\text{V}}$$

両辺の共通項 $\mu_{\text{Cu}^{++}}(\text{II})$ (※ $\mu_{\text{Cu}^{++}}(\text{I}) = \mu_{\text{Cu}^{++}}(\text{II})$ と仮定), $\mu_{\text{Zn}^{++}}(\text{IV})$, $-2\mu_{\text{e}}$ の一部, $2e\phi_{\text{IV}}$ を整理する．
また，仮定 $\phi_{\text{II}} = \phi_{\text{III}}$ を用いる．

整理すると，以下の関係が得られる．

$$2e(\phi_{\text{I}} - \phi_{\text{V}}) = \mu_{\text{Cu}^{++}}(\text{II}) - \mu_{\text{Cu}^{++}}(\text{I}) + \mu_{\text{Zn}^{++}}(\text{IV}) - \mu_{\text{Zn}^{++}}(\text{III}) \quad (\text{※ 途中の項の整理結果})$$

より正確には，式(5)を用いて $\mu_{\text{Cu}^{++}}(\text{I}) = \mu_{\text{Cu}}(\text{I}) - 2\mu_{\text{e}}(\text{I})$ などを代入すると：

$$2e(\phi_{\text{I}} - \phi_{\text{V}}) = \mu_{\text{Cu}^{++}} - \mu_{\text{Cu}} + \mu_{\text{Zn}} - \mu_{\text{Zn}^{++}}$$

(ここで $\mu$ の添字は各相における値を指す)．

### 4. 熱力学との関係

電池の反応 $\text{Cu}^{++} + \text{Zn} \rightarrow \text{Cu} + \text{Zn}^{++}$ におけるギブス自由エネルギーの変化 $\Delta G$ は，

$$\Delta G = \mu_{\text{Cu}} + \mu_{\text{Zn}^{++}} - \mu_{\text{Cu}^{++}} - \mu_{\text{Zn}}$$

である．
したがって，

$$2eE = -(\mu_{\text{Cu}} + \mu_{\text{Zn}^{++}} - \mu_{\text{Cu}^{++}} - \mu_{\text{Zn}}) = -\Delta G$$

すなわち，

$$2eE = -\Delta G (\text{Cu}^{++} + \text{Zn} \rightarrow \text{Cu} + \text{Zn}^{++})$$

が導かれた．

## 解説

### 電気化学ポテンシャルの考え方

通常の化学ポテンシャル $\mu$ は，物質の「化学的なエネルギー」を表すが，電荷を持つ粒子の場合，電場の中での「電気的なエネルギー」も考慮しなければならない．
これが**電気化学ポテンシャル** $\bar{\mu}$ である．

$$\bar{\mu} = \mu + ze\phi$$

電池の反応が進むとき，物質は化学ポテンシャルの差によって動こうとするが，同時に電荷の移動に伴う電位の変化も関わっている．

### Daniell電池の仕組み

Daniell電池では，銅（ $\text{Cu}$ ）が酸化されて $\text{Cu}^{++}$ となり，その電子が外部回路を通って亜鉛（ $\text{Zn}$ ）側に流れる．
亜鉛側では $\text{Zn}^{++}$ が生成される．
この電子の流れが，端子間の電位差（起電力 $E$ ）を生み出す．

### ギブス自由エネルギーとの関係

電池が仕事をする能力は，反応によって放出される自由エネルギー $\Delta G$ に比例する．
物理学的な関係式 $W = -\Delta G$ に基づき，電荷 $2e$ が電位差 $E$ で動くときの仕事 $2eE$ が，化学的なエネルギー変化 $-\Delta G$ と等しくなることが，この問題の導出の核心である．
