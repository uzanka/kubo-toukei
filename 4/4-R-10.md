# 例題【4-R-10】

## 解答

## 1．Daniell 電池の各相と電気化学ポテンシャル

Daniell 電池を，問題文に従って次の5つの相に分ける．

```math
\mathrm{Cu} \mid \mathrm{CuSO_4(aq)} \mid \mathrm{ZnSO_4(aq)} \mid \mathrm{Zn} \mid \mathrm{Cu}
```

それぞれを相 I，II，III，IV，V とし，静電位を $\phi_{\mathrm I},\phi_{\mathrm{II}},\phi_{\mathrm{III}},\phi_{\mathrm{IV}},\phi_{\mathrm V}$ とする．
端子はどちらも銅でできているため，端子金属の違いによる接触電位差は生じないものとする．
また，問題の仮定から，

```math
\boxed{
\phi_{\mathrm{II}}=\phi_{\mathrm{III}}
}
\tag{1}
```

である．

電荷数 $z$ をもつ粒子の電気化学ポテンシャルは，

```math
\boxed{
\widetilde{\mu}=\mu+ze\phi
}
\tag{2}
```

で表される．
ここで， $\mu$ は化学ポテンシャル， $e$ は電気素量， $\phi$ は静電位である．

熱力学的平衡では，膜や界面を通過できる粒子について，隣接する相の電気化学ポテンシャルが等しくなる．
この条件を各界面に適用する．

## 2．各界面の平衡条件

### （1）相 I と相 II：銅イオンの平衡

銅金属と硫酸銅水溶液の界面では，銅の酸化還元反応

```math
\mathrm{Cu}\rightleftharpoons\mathrm{Cu}^{2+}+2e
\tag{3}
```

が平衡にある．
金属中の銅の化学ポテンシャルを $\mu_{\mathrm{Cu}}$ ，電子の化学ポテンシャルを $\mu_e^{\mathrm I}$ とする．
金属中での反応の関係から，

```math
\mu_{\mathrm{Cu}} =\mu\_{\mathrm{Cu}^{2+}}^{\mathrm{I},{\ast}} +2\mu_e^{\mathrm I}
\tag{4}
```

と書ける．
ここで $\mu_{\mathrm{Cu}^{2+}}^{\mathrm{I},{\ast}}$ は，この反応関係を用いて定義した金属相側の形式的な化学ポテンシャルである．
金属中に自由な $\mathrm{Cu}^{2+}$ イオンが存在するという意味ではない．

銅イオンの電気化学ポテンシャルが相 I と相 II で等しいという条件は，

```math
\mu_{\mathrm{Cu}^{2+}}^{\mathrm{I},{\ast}}+2e\phi_{\mathrm I} = \mu_{\mathrm{Cu}^{2+}}^{\mathrm{II}}+2e\phi_{\mathrm{II}}
\tag{5}
```

である．

### （2）相 II と相 III：硫酸イオンの平衡

硫酸イオン $\mathrm{SO_4^{2-}}$ は両方の溶液相に存在するため，

```math
\mu_{\mathrm{SO_4^{2-}}}^{\mathrm{II}}-2e\phi_{\mathrm{II}} = \mu_{\mathrm{SO_4^{2-}}}^{\mathrm{III}}-2e\phi_{\mathrm{III}}
\tag{6}
```

が成り立つ．
式（1）の仮定を使うと，

```math
\mu_{\mathrm{SO_4^{2-}}}^{\mathrm{II}} = \mu_{\mathrm{SO_4^{2-}}}^{\mathrm{III}}
```

となる．
したがって，この界面の条件には電位差の項が残らず，以下の起電力の導出には直接現れない．

### （3）相 III と相 IV：亜鉛イオンの平衡

亜鉛金属と硫酸亜鉛水溶液の界面では，

```math
\mathrm{Zn}\rightleftharpoons\mathrm{Zn}^{2+}+2e
\tag{7}
```

が平衡にある．
金属中の亜鉛の化学ポテンシャルを $\mu_{\mathrm{Zn}}$ ，電子の化学ポテンシャルを $\mu_e^{\mathrm{IV}}$ とすると，

```math
\mu_{\mathrm{Zn}} =\mu_{\mathrm{Zn}^{2+}}^{\mathrm{IV},{\ast}} +2\mu_e^{\mathrm{IV}}
\tag{8}
```

である．
ここでも， $\mu_{\mathrm{Zn}^{2+}}^{\mathrm{IV},{\ast}}$ は金属相側の形式的な化学ポテンシャルである．

亜鉛イオンの電気化学ポテンシャルの平衡条件は，

```math
\mu_{\mathrm{Zn}^{2+}}^{\mathrm{III}}+2e\phi_{\mathrm{III}} = \mu_{\mathrm{Zn}^{2+}}^{\mathrm{IV},{\ast}}+2e\phi_{\mathrm{IV}}
\tag{9}
```

となる．

### （4）相 IV と相 V：電子の平衡

亜鉛金属と銅端子の接触部では，電子の電気化学ポテンシャルが等しい．
電子の電荷は $-e$ であるため，

```math
\boxed{
\mu_e^{\mathrm{IV}}-e\phi_{\mathrm{IV}} = \mu_e^{\mathrm V}-e\phi_{\mathrm V}
}
\tag{10}
```

となる．

## 3．各平衡条件を組み合わせて起電力を導く

式（5），（9），（10）をそれぞれ等式として扱い，式（5）と式（9）を加え，式（10）の2倍を引く．
この操作を行うと，

```math
\begin{aligned}
&\mu_{\mathrm{Cu}^{2+}}^{\mathrm{I},{\ast}} +\mu_{\mathrm{Zn}^{2+}}^{\mathrm{III}} -2\mu_e^{\mathrm{IV}}\\
&\quad +2e\phi_{\mathrm I} +2e\phi_{\mathrm{III}} +2e\phi_{\mathrm{IV}}\\
&= \mu_{\mathrm{Cu}^{2+}}^{\mathrm{II}} +\mu_{\mathrm{Zn}^{2+}}^{\mathrm{IV},{\ast}} -2\mu_e^{\mathrm V}\\
&\quad +2e\phi_{\mathrm{II}} +2e\phi_{\mathrm{IV}} +2e\phi_{\mathrm V}
\end{aligned}
\tag{11}
```

を得る．

式（1）より $\phi_{\mathrm{II}}=\phi_{\mathrm{III}}$ であるため，両辺の中間相の電位の項を消去すると，

```math
\begin{aligned}
&\mu_{\mathrm{Cu}^{2+}}^{\mathrm{I},{\ast}} +\mu_{\mathrm{Zn}^{2+}}^{\mathrm{III}} -2\mu_e^{\mathrm{IV}} +2e\phi_{\mathrm I}\\
&= \mu_{\mathrm{Cu}^{2+}}^{\mathrm{II}} +\mu_{\mathrm{Zn}^{2+}}^{\mathrm{IV},{\ast}} -2\mu_e^{\mathrm V} +2e\phi_{\mathrm V}
\end{aligned}
\tag{12}
```

となる．

ここで，式（4），（8）を用いて，金属相側の形式的な化学ポテンシャルを消去する．
さらに，両端の金属は同じ銅であるため，その化学ポテンシャルと電子の化学ポテンシャルは同じ値である．
これらを整理すると，

```math
\mu_{\mathrm{Cu}} +\mu_{\mathrm{Zn}^{2+}}^{\mathrm{III}} +2e\phi_{\mathrm I} = \mu_{\mathrm{Cu}^{2+}}^{\mathrm{II}} +\mu_{\mathrm{Zn}} +2e\phi_{\mathrm V}
\tag{13}
```

が得られる．
よって，

```math
\boxed{
2e(\phi_{\mathrm I}-\phi_{\mathrm V}) = \mu_{\mathrm{Cu}^{2+}}^{\mathrm{II}} -\mu_{\mathrm{Cu}} +\mu_{\mathrm{Zn}} -\mu_{\mathrm{Zn}^{2+}}^{\mathrm{III}}
}
\tag{14}
```

となる．

端子間の起電力を

```math
\boxed{
E=\phi_{\mathrm I}-\phi_{\mathrm V}
}
\tag{15}
```

と定義すると，式（14）は，

```math
2eE = \mu_{\mathrm{Cu}^{2+}} +\mu_{\mathrm{Zn}} -\mu_{\mathrm{Cu}} -\mu_{\mathrm{Zn}^{2+}}
\tag{16}
```

と書ける．
ここで， $\mu_{\mathrm{Cu}^{2+}}$ は相 II， $\mu_{\mathrm{Zn}^{2+}}$ は相 III の化学ポテンシャルである．

## 4．Gibbs 自由エネルギー変化との関係

Daniell 電池の正味の反応は，

```math
\mathrm{Cu}^{2+}+\mathrm{Zn} \longrightarrow \mathrm{Cu}+\mathrm{Zn}^{2+}
\tag{17}
```

である．
この反応の Gibbs 自由エネルギー変化は，

```math
\boxed{
\Delta_rG = \mu_{\mathrm{Cu}} +\mu_{\mathrm{Zn}^{2+}} -\mu_{\mathrm{Cu}^{2+}} -\mu_{\mathrm{Zn}}
}
\tag{18}
```

である．

式（16）と式（18）を比較すると，

```math
\boxed{
2eE=-\Delta_rG
}
\tag{19}
```

が得られる．
これが求める起電力と反応の Gibbs 自由エネルギー変化との関係式である．

## 5．結論

各界面における電気化学ポテンシャルの平衡条件を用い，金属中の酸化還元反応の化学ポテンシャル関係と，溶液境界で電位差がないという仮定を組み合わせることで，

```math
\boxed{
2eE=-\Delta_rG
}
```

を導いた．
すなわち，可逆な Daniell 電池の起電力は，電池反応による Gibbs 自由エネルギーの減少を電子2個分の電荷 $2e$ で割ったものに対応する．

なお， $\Delta_rG$ を1 mol の反応に対するモル Gibbs 自由エネルギー変化で表す場合は，電子のモル電荷 $2F$ を用いて，

```math
\boxed{
2FE=-\Delta_rG
}
```

と書く．
ここで $F=N_Ae$ はファラデー定数である．
