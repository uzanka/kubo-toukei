# 演習問題【4-A-23】

## 解答

本問題では，理想混合気体中での化学反応における平衡定数 $K_p$ （圧力に基づく平衡定数）および $K_c$ （濃度に基づく平衡定数）の温度依存性について，それぞれ導出を行う．

### 1. $K_p$ に関する式の導出 (van't Hoffの式)

まず，圧力に基づく平衡定数 $K_p$ と標準ギブズ自由エネルギー変化 $\Delta \overline{G}$ の関係は，次のように表される．

$$\log K_p = -\frac{\Delta \overline{G}}{RT}$$

ここで， $R$ は気体定数， $T$ は絶対温度である．

この式の両辺を温度 $T$ で微分する．
左辺は $\frac{d \log K_p}{dT}$ となる．
右辺について，商の微分公式 $\left( \frac{u}{v} \right)' = \frac{u'v - uv'}{v^2}$ を用いると，

$$\frac{d}{dT} \left( -\frac{\Delta \overline{G}}{RT} \right) = -\frac{d}{dT} \left( \frac{\Delta \overline{G}}{RT} \right)$$

となる．
ここで $u = \Delta \overline{G}$ ， $v = RT$ とおくと，

$$\frac{d}{dT} \left( \frac{\Delta \overline{G}}{RT} \right) = \frac{\left(\frac{d \Delta \overline{G}}{dT}\right) RT - (\Delta \overline{G}) \left(\frac{d(RT)}{dT}\right)}{(RT)^2}$$

となる．
熱力学的関係式 $\left(\frac{\partial G}{\partial T}\right)_P = -S$ より， $\frac{d \Delta \overline{G}}{dT} = -\Delta \overline{S}$ であることを用いると，

$$\frac{d}{dT} \left( \frac{\Delta \overline{G}}{RT} \right) = \frac{(-\Delta \overline{S}) RT - (\Delta \overline{G}) R}{(RT)^2}$$

$$= \frac{-T \Delta \overline{S} - \Delta \overline{G}}{RT^2}$$

となる．
ここで，ギブズ自由エネルギーの定義 $\Delta \overline{G} = \Delta \overline{H} - T \Delta \overline{S}$ より，

$$-T \Delta \overline{S} - \Delta \overline{G} = -T \Delta \overline{S} - (\Delta \overline{H} - T \Delta \overline{S}) = -\Delta \overline{H}$$

となる．
したがって，

$$\frac{d}{dT} \left( \frac{\Delta \overline{G}}{RT} \right) = \frac{-\Delta \overline{H}}{RT^2}$$

これを用いると，

$$\frac{d \log K_p}{dT} = - \left( \frac{-\Delta \overline{H}}{RT^2} \right) = \frac{\Delta \overline{H}}{RT^2}$$

が得られる．

### 2. $K_c$ に関する式の導出 (反応定容式)

次に，濃度に基づく平衡定数 $K_c$ の温度依存性を導出する．
問題の条件および一般的な関係式より， $\log K_c$ は次のように表せる．

$$\log K_c = -\frac{1}{RT} \sum \nu_j (\overline{G}_j^0 + RT \log [RT])$$

ここで， $\nu_j$ は反応物・生成物の係数， $\overline{G}_j^0$ は標準ギブズ自由エネルギーである．
この式を展開すると，

$$\log K_c = -\frac{1}{RT} \sum \nu_j \overline{G}_j^0 - \sum \nu_j \log [RT]$$

となる．
この両辺を $T$ で微分する．

第1項の微分は，先ほどの $K_p$ の導出と同様の手順により，

$$\frac{d}{dT} \left( -\frac{1}{RT} \sum \nu_j \overline{G}_j^0 \right) = \frac{\sum \nu_j \overline{H}_j^0}{RT^2}$$

となる．

第2項の微分を計算する．
$\sum \nu_j$ は定数であることに注意すると，

$$\frac{d}{dT} \left( -(\sum \nu_j) \log [RT] \right) = -(\sum \nu_j) \frac{1}{RT} \frac{d(RT)}{dT}$$

$$= -(\sum \nu_j) \frac{1}{RT} \cdot R = -\frac{\sum \nu_j}{T}$$

となる．

これらを合わせると，

$$\frac{d \log K_c}{dT} = \frac{\sum \nu_j \overline{H}_j^0}{RT^2} - \frac{\sum \nu_j}{T}$$

$$= \frac{1}{RT^2} \left( \sum \nu_j \overline{H}_j^0 - RT \sum \nu_j \right)$$

$$= \frac{1}{RT^2} \sum \nu_j (\overline{H}_j^0 - RT)$$

となる．

理想気体の状態方程式およびエンタルピーと内部エネルギーの関係 $\overline{H} = \overline{U} + P\overline{V}$ を用いる．
標準圧力 $p^0$ において，理想気体 $1 \text{ mol}$ の体積は $p^0 \overline{V}^0 = RT$ と表されるため，

$$\overline{H}_j^0 - RT = \overline{H}_j^0 - p^0 \overline{V}_j^0 = \overline{U}_j^0$$

となる．
これを代入すると，

$$\frac{d \log K_c}{dT} = \frac{1}{RT^2} \sum \nu_j \overline{U}_j^0 = \frac{\Delta \overline{U}}{RT^2}$$

が得られる．

## 解説

本問題で扱った式は，化学平衡が温度によってどのように変化するかを記述する非常に重要な式である．

- **van't Hoffの式 ( $K_p$ )**:
  平衡定数が温度に対して指数関数的に変化することを示しており，反応の標準エンタルピー $\Delta \overline{H}$ の符号によって，温度上昇に伴う平衡の移動方向（吸熱か発熱か）を判定できる．
- **反応定容式 ( $K_c$ )**:
  濃度に基づく平衡定数の変化は，反応の標準内部エネルギー $\Delta \overline{U}$ に依存する．
 これは，体積が一定の条件下での反応挙動を記述する際に用いられる．

**主要な変数の定義:**
- $K_p, K_c$ : それぞれ圧力および濃度に基づく平衡定数
- $\Delta \overline{G}$ : 標準ギブズ自由エネルギー変化
- $\Delta \overline{H}$ : 標準エンタルピー変化
- $\Delta \overline{U}$ : 標準内部エネルギー変化
- $R$ : 気体定数
- $T$ : 絶対温度
- $\nu_j$ : 反応式における物質 $j$ の係数
