# 演習問題【4-A-23】

## 解答

化学反応を

```math
\sum_j\nu_j A_j=0
```

と表す．
ここで， $A_j$ は物質 $j$ ， $\nu_j$ はその化学量論係数であり，生成物では正，反応物では負とする．
また，

```math
\Delta\overline{H}^{\circ}
=\sum_j\nu_j\overline{H}_j^{\circ},\qquad
\Delta\overline{U}^{\circ}
=\sum_j\nu_j\overline{U}_j^{\circ}
```

と定義する．
これらは，それぞれ反応の標準モルエンタルピー変化および標準モル内部エネルギー変化である．
以下では，標準圧力を $p^\circ$ ，標準濃度を $c^\circ$ とする．

### 1．圧力に基づく平衡定数 $K_p$ の導出

圧力に基づく平衡定数 $K_p$ と反応の標準ギブズ自由エネルギー変化との間には，次の関係がある．

```math
\ln K_p=-\frac{\Delta\overline{G}^{\circ}}{RT}
\tag{1}
```

ここで， $R$ は気体定数， $T$ は絶対温度である．
式 (1) を $T$ で微分すると，

```math
\frac{d\ln K_p}{dT}
=-\frac{d}{dT}
\left(\frac{\Delta\overline{G}^{\circ}}{RT}\right)
\tag{2}
```

を得る．

標準ギブズ自由エネルギー，標準エンタルピー，標準エントロピーの間には，

```math
\Delta\overline{G}^{\circ}
=\Delta\overline{H}^{\circ}
-T\Delta\overline{S}^{\circ}
\tag{3}
```

という関係がある．
また，標準圧力を一定に保ったとき，

```math
\frac{d\Delta\overline{G}^{\circ}}{dT}
=-\Delta\overline{S}^{\circ}
\tag{4}
```

が成立する．
したがって，

```math
\begin{aligned}
\frac{d}{dT}
\left(\frac{\Delta\overline{G}^{\circ}}{T}\right)
&=\frac{1}{T}
\frac{d\Delta\overline{G}^{\circ}}{dT}
-\frac{\Delta\overline{G}^{\circ}}{T^2}\\
&=-\frac{\Delta\overline{S}^{\circ}}{T}
-\frac{\Delta\overline{G}^{\circ}}{T^2}\\
&=-\frac{T\Delta\overline{S}^{\circ}
+\Delta\overline{G}^{\circ}}{T^2}\\
&=-\frac{\Delta\overline{H}^{\circ}}{T^2}.
\end{aligned}
\tag{5}
```

最後の等号では，式 (3) より

```math
T\Delta\overline{S}^{\circ}
+\Delta\overline{G}^{\circ}
=\Delta\overline{H}^{\circ}
```

を用いた．
式 (2)，(5) から，

```math
\boxed{
\frac{d\ln K_p}{dT}
=\frac{\Delta\overline{H}^{\circ}}{RT^2}
}
```

が得られる．
これが van't Hoff の式である．

### 2．濃度に基づく平衡定数 $K_c$ の導出

次に，濃度に基づく平衡定数 $K_c$ を考える．
平衡定数を無次元量として扱うため，

```math
K_p=\prod_j\left(\frac{p_j}{p^\circ}\right)^{\nu_j},
\qquad
K_c=\prod_j\left(\frac{c_j}{c^\circ}\right)^{\nu_j}
\tag{6}
```

と定義する．
ここで， $p_j$ は物質 $j$ の分圧， $c_j$ はそのモル濃度である．

理想気体では，状態方程式から各成分について

```math
p_j=c_jRT
\tag{7}
```

が成立する．
これを式 (6) の $K_p$ に代入すると，

```math
\begin{aligned}
K_p
&=\prod_j\left(\frac{c_jRT}{p^\circ}\right)^{\nu_j}\\[4pt]
&=\left(\frac{RTc^\circ}{p^\circ}\right)^{\sum_j\nu_j}
\prod_j\left(\frac{c_j}{c^\circ}\right)^{\nu_j}\\[4pt]
&=\left(\frac{RTc^\circ}{p^\circ}\right)^{\Delta\nu}K_c,
\end{aligned}
\tag{8}
```

となる．
ここで，

```math
\Delta\nu=\sum_j\nu_j
\tag{9}
```

は，生成物側の気体の化学量論係数の和から反応物側の係数の和を引いた値である．

式 (8) の対数を取り，温度 $T$ で微分する．
$p^\circ$ と $c^\circ$ は温度によらない定数であるから，

```math
\frac{d\ln K_p}{dT}
=\frac{\Delta\nu}{T}
+\frac{d\ln K_c}{dT}
\tag{10}
```

を得る．
したがって，

```math
\frac{d\ln K_c}{dT}
=\frac{d\ln K_p}{dT}-\frac{\Delta\nu}{T}.
\tag{11}
```

ここに，先ほど導いた van't Hoff の式

```math
\frac{d\ln K_p}{dT}
=\frac{\Delta\overline{H}^{\circ}}{RT^2}
```

を代入すると，

```math
\begin{aligned}
\frac{d\ln K_c}{dT}
&=\frac{\Delta\overline{H}^{\circ}}{RT^2}
-\frac{\Delta\nu}{T}\\[4pt]
&=\frac{\Delta\overline{H}^{\circ}
-RT\Delta\nu}{RT^2}.
\end{aligned}
\tag{12}
```

ここで，理想気体のエンタルピー $\overline{H}_j^\circ$ と内部エネルギー $\overline{U}_j^\circ$ の間には，

```math
\overline{H}_j^\circ
=\overline{U}_j^\circ+p^\circ\overline{V}_j^\circ
\tag{13}
```

が成立する．
さらに，理想気体 1 mol に対する状態方程式より，

```math
p^\circ\overline{V}_j^\circ=RT
\tag{14}
```

である．
式 (13)，(14) から，

```math
\overline{H}_j^\circ-RT
=\overline{U}_j^\circ
\tag{15}
```

を得る．
両辺に $\nu_j$ を掛けて全成分について和を取ると，

```math
\begin{aligned}
\Delta\overline{H}^{\circ}-RT\Delta\nu
&=\sum_j\nu_j
\left(\overline{H}_j^\circ-RT\right)\\
&=\sum_j\nu_j\overline{U}_j^\circ\\
&=\Delta\overline{U}^{\circ}.
\end{aligned}
\tag{16}
```

これを式 (12) に代入すれば，

```math
\boxed{
\frac{d\ln K_c}{dT}
=\frac{\Delta\overline{U}^{\circ}}{RT^2}
}
```

が得られる．
これが反応定容式である．

### 結論

理想混合気体中の化学反応について，圧力に基づく平衡定数と濃度に基づく平衡定数の温度依存性は，それぞれ

```math
\boxed{
\frac{d\ln K_p}{dT}
=\frac{\Delta\overline{H}^{\circ}}{RT^2}
}
```

および

```math
\boxed{
\frac{d\ln K_c}{dT}
=\frac{\Delta\overline{U}^{\circ}}{RT^2}
}
```

と表される．
すなわち， $K_p$ の温度依存性は反応の標準エンタルピー変化により決まり， $K_c$ の温度依存性は反応の標準内部エネルギー変化により決まる．
なお，ここでの $\ln$ は自然対数である．
問題文の $\log$ を常用対数と解釈する場合には，両式の右辺に $1/\ln 10$ を掛ける必要がある．
