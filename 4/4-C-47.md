# 演習問題【4-C-47】

## 解答

### 1．液相と気相の相平衡条件

純物質 $n$ mol の液相と気相が共存する状態を考える．
液相の状態点を A，気相の状態点を E とする．両相の相平衡条件は，

```math
T_A=T_E=T_0
```

```math
p_A=p_E=p_0
```

```math
\mu_A=\mu_E
```

である．
ここで， $T_0$ は共存温度， $p_0$ は共存圧力である．

純物質の Gibbs 自由エネルギーは，

```math
G=n\mu
```

で表される．
A と E では物質量 $n$ が等しいため，化学ポテンシャルの一致から，

```math
G_A=G_E
```

が成立する．

また，Gibbs 自由エネルギーの定義，

```math
G=U-TS+pV
```

を用いると，

```math
U_A-T_0S_A+p_0V_A
=
U_E-T_0S_E+p_0V_E
```

となる．
したがって，

```math
\boxed{
(U_E-U_A)-T_0(S_E-S_A)
+p_0(V_E-V_A)=0
}
\tag{1}
```

を得る．

以下では，この式に含まれるエントロピー差と内部エネルギー差を求め，Maxwell の等面積則を導く．

なお，以下では van der Waals 定数について $a>0,\ b>0$ ，物理的な体積の定義域について $V>nb$ とする．
また，液相と気相が異なる体積を持つ共存状態を考えるため，臨界温度より低い温度を対象とする．

### 2．定積比熱が体積に依存しないことの導出

van der Waals の状態方程式は，

```math
\boxed{
p=\frac{nRT}{V-nb}-\frac{n^2a}{V^2}
}
\tag{2}
```

である．

ここで，定積比熱を

```math
C_V\equiv
\left(\frac{\partial U}{\partial T}\right)_V
```

と定義する．

熱力学の基本関係式と Maxwell の関係式から，エントロピーの全微分は，

```math
dS=
\frac{C_V}{T}\,dT
+
\left(\frac{\partial p}{\partial T}\right)_VdV
\tag{3}
```

と表される．

式 (2) を温度で偏微分すると，

```math
\left(\frac{\partial p}{\partial T}\right)_V
=
\frac{nR}{V-nb}
```

である．
したがって，

```math
dS=
\frac{C_V}{T}\,dT
+
\frac{nR}{V-nb}\,dV
\tag{4}
```

となる．

エントロピー $S$ は状態関数であり，その全微分は完全微分である．
したがって，混合二階偏微分の交換可能性から，

```math
\frac{\partial}{\partial V}
\left(\frac{\partial S}{\partial T}\right)_V
=
\frac{\partial}{\partial T}
\left(\frac{\partial S}{\partial V}\right)_T
```

が成立する．
式 (4) を代入すると，

```math
\left(\frac{\partial}{\partial V}
\frac{C_V}{T}\right)_T
=
\left(\frac{\partial}{\partial T}
\frac{nR}{V-nb}\right)_V
=0
```

である．
温度 $T$ は正であるから，

```math
\frac{1}{T}
\left(\frac{\partial C_V}{\partial V}\right)_T=0
```

となり，

```math
\boxed{
\left(\frac{\partial C_V}{\partial V}\right)_T=0
}
\tag{5}
```

を得る．

したがって，van der Waals の状態方程式と熱力学的整合性から，

```math
\boxed{C_V=C_V(T)}
\tag{6}
```

が導かれる．

この結果は，定積比熱の温度依存性を決定するものではないが，体積には依存しないことを示している．
以下では，熱的にも安定な物質として，考える温度範囲において $C_V(T)>0$ とする．

式 (6) は，状態方程式が定義される連結領域 $V>nb$ において，熱力学量が滑らかな状態関数として整合的に定義されていることから得られる性質である．
この関係を導くことは，不安定領域を準静過程で通過することを意味しない．
実際の状態変化には，以下で構成する安定な経路を用いる．

### 3．不安定領域を避ける準静過程の構成

問題文の条件を満たすため，A から E までの間に機械的不安定領域を通らない準静過程を構成する．

#### 3.1 van der Waals 気体の機械的安定条件

機械的に安定な状態では，等温圧縮率が正である．
したがって，

```math
\kappa_T
=
-\frac{1}{V}
\left(\frac{\partial V}{\partial p}\right)_T>0
```

であり，これは，

```math
\boxed{
\left(\frac{\partial p}{\partial V}\right)_T<0
}
\tag{7}
```

と同値である．

式 (2) を体積で偏微分すると，

```math
\boxed{
\left(\frac{\partial p}{\partial V}\right)_T
=
-\frac{nRT}{(V-nb)^2}
+\frac{2n^2a}{V^3}
}
\tag{8}
```

となる．

A と E は液相および気相の安定な共存状態であるから，

```math
\left(\frac{\partial p}{\partial V}\right)_{T_0,V_A}<0
```

および，

```math
\left(\frac{\partial p}{\partial V}\right)_{T_0,V_E}<0
```

が成立する．

また，式 (8) を温度で偏微分すると，

```math
\left.
\frac{\partial}{\partial T}
\left(\frac{\partial p}{\partial V}\right)_T
\right|_V
=
-\frac{nR}{(V-nb)^2}<0
\tag{9}
```

である．

したがって，体積を一定に保ったまま温度を上昇させると， $(\partial p/\partial V)_T$ はさらに小さくなり，機械的安定性が維持される．

#### 3.2 臨界温度より高い温度での安定性

モル体積を

```math
v=\frac{V}{n}
```

とすると，状態方程式は，

```math
p=\frac{RT}{v-b}-\frac{a}{v^2}
```

と書ける．

その等温微分は，

```math
\left(\frac{\partial p}{\partial v}\right)_T
=
-\frac{RT}{(v-b)^2}
+\frac{2a}{v^3}
\tag{10}
```

である．

臨界点では，

```math
\left(\frac{\partial p}{\partial v}\right)_{T_c}=0
```

および，

```math
\left(\frac{\partial^2p}{\partial v^2}\right)_{T_c}=0
```

が成立する．

式 (10) とその体積微分から，

```math
-\frac{RT_c}{(v_c-b)^2}
+\frac{2a}{v_c^3}=0
```

```math
\frac{2RT_c}{(v_c-b)^3}
-\frac{6a}{v_c^4}=0
```

を得る．
これらを連立して解くと，

```math
v_c=3b
```

および，

```math
\boxed{
T_c=\frac{8a}{27Rb}
}
\tag{11}
```

となる．

ここで，

```math
T_1>T_c
```

となる温度 $T_1$ を選ぶ．

温度 $T_1$ における式 (10) の符号を調べるため，

```math
f(v)=\frac{2a(v-b)^2}{v^3}
```

とおく．
その導関数は，

```math
f'(v)
=
\frac{2a(v-b)(3b-v)}{v^4}
```

である．
したがって， $v>b$ において $f(v)$ は $v=3b$ で最大となり，

```math
f(v)\leq f(3b)
=\frac{8a}{27b}
```

が成立する．

一方，

```math
RT_1>RT_c=\frac{8a}{27b}
```

であるから，

```math
\frac{2a(v-b)^2}{v^3}<RT_1
```

となる．
これを式 (10) に用いると，

```math
\boxed{
\left(\frac{\partial p}{\partial v}\right)_{T_1}<0
\qquad (v>b)
}
\tag{12}
```

を得る．

すなわち，臨界温度より高い温度 $T_1$ では，すべての物理的な体積領域において機械的に安定である．

#### 3.3 準静過程の具体的な構成

以上の結果を用いて，次の三段階からなる経路を考える．

第一段階：A から $J_1$

体積を $V_A$ に一定に保ち，温度を $T_0$ から $T_1$ まで準静的に上昇させる．

式 (9) より，

```math
\left(\frac{\partial p}{\partial V}\right)_{T,V_A}
\leq
\left(\frac{\partial p}{\partial V}\right)_{T_0,V_A}<0
```

である．
したがって，この過程では機械的安定性が維持される．

第二段階：$J_1$ から $J_2$

温度を $T_1$ に一定に保ち，体積を $V_A$ から $V_E$ まで準静的に膨張させる．

式 (12) より，この等温過程の全範囲で，

```math
\left(\frac{\partial p}{\partial V}\right)_{T_1}<0
```

が成立する．
したがって，この過程も機械的に安定である．

第三段階： $J_2$ から E

体積を $V_E$ に一定に保ち，温度を $T_1$ から $T_0$ まで準静的に低下させる．

式 (9) より， $T\geq T_0$ において，

```math
\left(\frac{\partial p}{\partial V}\right)_{T,V_E}
\leq
\left(\frac{\partial p}{\partial V}\right)_{T_0,V_E}<0
```

である．
したがって，この過程でも機械的安定性が維持される．

以上より，

```math
\boxed{A\longrightarrow J_1
\longrightarrow J_2\longrightarrow E}
```

という準静過程は，機械的不安定領域を一切通過しない．
また， $C_V(T)>0$ の仮定により，熱的安定性も満たされる．

したがって，この経路に沿ってエントロピーと内部エネルギーの変化を計算することができる．

### 4．エントロピー差の計算

式 (4) より，

```math
dS=
\frac{C_V(T)}{T}\,dT
+
\frac{nR}{V-nb}\,dV
```

である．

この式を，前節で構成した準静過程に沿って A から E まで積分する．

```math
\begin{aligned}
S_E-S_A
&=\int_A^E dS\\
&=\int_A^E\frac{C_V(T)}{T}\,dT
+\int_A^E\frac{nR}{V-nb}\,dV
\end{aligned}
```

まず，温度だけに依存する項について考える．
第一段階では温度が $T_0$ から $T_1$ に上昇し，第三段階では $T_1$ から $T_0$ に低下する．
したがって，

```math
\begin{aligned}
\int_A^E\frac{C_V(T)}{T}\,dT
&=
\int_{T_0}^{T_1}\frac{C_V(T)}{T}\,dT
+
\int_{T_1}^{T_0}\frac{C_V(T)}{T}\,dT\\
&=0
\end{aligned}
```

となる．

次に，体積に関する項を考える．
第一段階と第三段階では体積は一定であり，第二段階でのみ体積が $V_A$ から $V_E$ まで変化する．
よって，

```math
\int_A^E\frac{nR}{V-nb}\,dV
=
\int_{V_A}^{V_E}\frac{nR}{V-nb}\,dV
```

である．

以上から，

```math
\begin{aligned}
S_E-S_A
&=
nR\int_{V_A}^{V_E}\frac{1}{V-nb}\,dV\\
&=
nR\left[\log(V-nb)\right]_{V_A}^{V_E}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
S_E-S_A
=
nR\log
\left(
\frac{V_E-nb}{V_A-nb}
\right)
}
\tag{13}
```

を得る．

### 5．内部エネルギー差の計算

内部エネルギーの基本関係式は，

```math
dU=T\,dS-p\,dV
```

である．

定積比熱の定義から，

```math
\left(\frac{\partial U}{\partial T}\right)_V=C_V
```

である．
また，

```math
\left(\frac{\partial U}{\partial V}\right)_T
=
T\left(\frac{\partial S}{\partial V}\right)_T-p
```

と書ける．

Maxwell の関係式より，

```math
\left(\frac{\partial S}{\partial V}\right)_T
=
\left(\frac{\partial p}{\partial T}\right)_V
```

であるから，

```math
\left(\frac{\partial U}{\partial V}\right)_T
=
T\left(\frac{\partial p}{\partial T}\right)_V-p
```

となる．

式 (2) より，

```math
T\left(\frac{\partial p}{\partial T}\right)_V
=
\frac{nRT}{V-nb}
```

であるため，

```math
\begin{aligned}
\left(\frac{\partial U}{\partial V}\right)_T
&=
\frac{nRT}{V-nb}
-
\left(
\frac{nRT}{V-nb}-\frac{n^2a}{V^2}
\right)\\
&=\frac{n^2a}{V^2}
\end{aligned}
```

を得る．

したがって，内部エネルギーの全微分は，

```math
\boxed{
dU=C_V(T)\,dT+\frac{n^2a}{V^2}\,dV
}
\tag{14}
```

となる．

これを A から E までの準静過程に沿って積分する．

```math
\begin{aligned}
U_E-U_A
&=
\int_A^E C_V(T)\,dT
+
\int_A^E\frac{n^2a}{V^2}\,dV
\end{aligned}
```

温度に関する項は，

```math
\begin{aligned}
\int_A^E C_V(T)\,dT
&=
\int_{T_0}^{T_1}C_V(T)\,dT
+
\int_{T_1}^{T_0}C_V(T)\,dT\\
&=0
\end{aligned}
```

である．

また，体積に関する項については，第二段階でのみ体積が変化するので，

```math
\begin{aligned}
\int_A^E\frac{n^2a}{V^2}\,dV
&=
n^2a\int_{V_A}^{V_E}\frac{1}{V^2}\,dV\\
&=
n^2a\left[-\frac{1}{V}\right]_{V_A}^{V_E}
\end{aligned}
```

となる．

したがって，

```math
\boxed{
U_E-U_A
=
n^2a
\left(
\frac{1}{V_A}-\frac{1}{V_E}
\right)
}
\tag{15}
```

を得る．

### 6．Gibbs 自由エネルギーの等式から Maxwell の規則を導く

式 (1) に式 (13)，(15) を代入すると，

```math
\begin{aligned}
&n^2a
\left(
\frac{1}{V_A}-\frac{1}{V_E}
\right)\\
&\quad
-nRT_0\log
\left(
\frac{V_E-nb}{V_A-nb}
\right)
+p_0(V_E-V_A)=0
\end{aligned}
```

となる．
これを整理すると，

```math
\boxed{
p_0(V_E-V_A)
=
nRT_0\log
\left(
\frac{V_E-nb}{V_A-nb}
\right)
+
n^2a
\left(
\frac{1}{V_E}-\frac{1}{V_A}
\right)
}
\tag{16}
```

を得る．

一方，van der Waals の状態方程式は，

```math
p_{\mathrm{vdW}}(V,T_0)
=
\frac{nRT_0}{V-nb}
-\frac{n^2a}{V^2}
```

である．
これを $V_A$ から $V_E$ まで数学的に積分すると，

```math
\begin{aligned}
\int_{V_A}^{V_E}
p_{\mathrm{vdW}}(V,T_0)\,dV
&=
\int_{V_A}^{V_E}
\left(
\frac{nRT_0}{V-nb}
-\frac{n^2a}{V^2}
\right)dV\\
&=
nRT_0
\left[\log(V-nb)\right]_{V_A}^{V_E}
+
n^2a
\left[\frac{1}{V}\right]_{V_A}^{V_E}\\
&=
nRT_0\log
\left(
\frac{V_E-nb}{V_A-nb}
\right)
+
n^2a
\left(
\frac{1}{V_E}-\frac{1}{V_A}
\right)
\end{aligned}
```

である．

これを式 (16) と比較すると，

```math
\boxed{
\int_{V_A}^{V_E}
p_{\mathrm{vdW}}(V,T_0)\,dV
=
p_0(V_E-V_A)
}
\tag{17}
```

を得る．

ここで， $p_0$ は A と E に共通する相共存圧力である．

したがって，

```math
\boxed{
\int_{V_A}^{V_E}
\left\{
p_{\mathrm{vdW}}(V,T_0)-p_0
\right\}dV=0
}
\tag{18}
```

となる．

これが van der Waals の状態方程式に対する Maxwell の等面積則である．

なお，式 (17)，(18) の積分は，van der Waals 状態方程式が定める等温線の数学的な定積分である．
積分区間に機械的不安定領域が含まれていても，それはその領域を準静過程で通過することを意味しない．
実際の状態変化には，前節で構成した不安定領域を避ける経路を使用している．

### 7．図形的な意味と結論

式 (18) は，温度 $T_0$ における van der Waals 等温線と，相共存圧力 $p_0$ を表す水平線との差の符号付き面積がゼロになることを意味する．

したがって，

```math
\boxed{
\text{水平線より下側の面積}
=
\text{水平線より上側の面積}
}
```

が成立する．

すなわち，van der Waals 等温線において，液相 A と気相 E を結ぶ相共存圧力の水平線は，その両側の面積が等しくなる位置に定められる．

なお，臨界点では，

```math
V_A=V_E=V_c
```

となり，式 (18) は積分区間がゼロとなる自明な極限として成立する．

以上より，液相 A と気相 E の化学ポテンシャルが等しいという相平衡条件から，van der Waals の状態方程式に対する Maxwell の等面積則が証明された．
