# 演習問題【4-C-47】

## 解答

### 1．液相と気相の熱平衡条件

van der Waals の状態方程式が与える等温線において，液相に対応する点を A，気相に対応する点を E とする．
両相が熱平衡にあるためには，温度 $T$ と圧力 $p$ が等しく，さらに化学ポテンシャルも等しくなければならない．
したがって，

```math
\boxed{\mu_A(p,T)=\mu_E(p,T)}
\tag{1}
```

が成り立つ．

温度と圧力は A と E で等しいので，示すべきことは式 (1) の化学ポテンシャルの等式から Maxwell の等面積則を導くことである．

### 2．Gibbs 自由エネルギーによる表現

純物質 $n$ mol の Gibbs 自由エネルギー $G$ は，化学ポテンシャル $\mu$ を用いて，

```math
G=n\mu=U-TS+pV
```

と表される．
ここで， $U$ は内部エネルギー， $S$ はエントロピー， $V$ は体積である．

A と E では物質量 $n$ ，温度 $T$ ，圧力 $p$ が等しい．
したがって，式 (1) は $G_A=G_E$ と同値であり，

```math
\boxed{
(U_E-U_A)-T(S_E-S_A)+p(V_E-V_A)=0
}
\tag{2}
```

と書ける．

そこで，式 (2) に含まれる内部エネルギー差 $U_E-U_A$ とエントロピー差 $S_E-S_A$ を求める．

### 3．エントロピー差の計算

van der Waals の状態方程式は，

```math
p=\frac{nRT}{V-nb}-\frac{n^2a}{V^2}
\tag{3}
```

である．
ここで， $R$ は気体定数， $a,b$ は物質に固有の定数である．

エントロピー $S$ は状態関数であるため，その変化量は経路によらず始点と終点だけで決まる．
そこで，問題文の指示に従い，図の BLD のような安定条件を満たさない領域を通らない準静過程を考える．
この経路を AJE とする．

エントロピーの全微分は，

```math
dS=
\left(\frac{\partial S}{\partial T}\right)_VdT
+\left(\frac{\partial S}{\partial V}\right)_TdV
```

である．
定積比熱を $C_V$ とすると，

```math
\left(\frac{\partial S}{\partial T}\right)_V
=\frac{C_V}{T}
```

である．
また，Maxwell の関係式から，

```math
\left(\frac{\partial S}{\partial V}\right)_T
=\left(\frac{\partial p}{\partial T}\right)_V
```

が成り立つ．
したがって，

```math
\begin{aligned}
S_E-S_A
&=\int_A^E dS\\
&=\int_A^E\frac{C_V}{T}\,dT
+\int_A^E
\left(\frac{\partial p}{\partial T}\right)_VdV
\end{aligned}
```

となる．
積分経路の途中で温度が変化してもよいが，始点 A と終点 E の温度は等しい．
温度だけに依存する項の積分は，

```math
\int_{T_A}^{T_E}\frac{C_V}{T}\,dT=0
```

となる．
よって，

```math
S_E-S_A
=\int_{V_A}^{V_E}
\left(\frac{\partial p}{\partial T}\right)_VdV
```

である．
式 (3) を温度 $T$ で偏微分すると，

```math
\left(\frac{\partial p}{\partial T}\right)_V
=\frac{nR}{V-nb}
```

であるから，

```math
\begin{aligned}
S_E-S_A
&=\int_{V_A}^{V_E}\frac{nR}{V-nb}\,dV\\
&=nR\left[\log(V-nb)\right]_{V_A}^{V_E}.
\end{aligned}
```

したがって，

```math
\boxed{
S_E-S_A
=nR\log\left(\frac{V_E-nb}{V_A-nb}\right)
}
\tag{4}
```

を得る．

### 4．内部エネルギー差の計算

内部エネルギー $U$ も状態関数であるため，エントロピーと同様に，安定条件を満たす準静経路に沿って変化量を計算できる．

内部エネルギーの全微分は，

```math
dU=
\left(\frac{\partial U}{\partial T}\right)_VdT
+\left(\frac{\partial U}{\partial V}\right)_TdV
```

である．
定積比熱の定義から，

```math
\left(\frac{\partial U}{\partial T}\right)_V=C_V
```

である．
また，熱力学の基本関係式と Maxwell の関係式から，

```math
\left(\frac{\partial U}{\partial V}\right)_T
=T\left(\frac{\partial p}{\partial T}\right)_V-p
```

が得られる．
したがって，

```math
dU=C_VdT+
\left\{
T\left(\frac{\partial p}{\partial T}\right)_V-p
\right\}dV
```

となる．
A と E は同温であるため，温度だけに依存する項の積分は消える．
よって，

```math
U_E-U_A
=\int_{V_A}^{V_E}
\left\{
T\left(\frac{\partial p}{\partial T}\right)_V-p
\right\}dV
```

である．
式 (3) より，

```math
T\left(\frac{\partial p}{\partial T}\right)_V
=\frac{nRT}{V-nb}
```

であるから，

```math
\begin{aligned}
U_E-U_A
&=\int_{V_A}^{V_E}
\left\{
\frac{nRT}{V-nb}
-\left(\frac{nRT}{V-nb}-\frac{n^2a}{V^2}\right)
\right\}dV\\
&=\int_{V_A}^{V_E}\frac{n^2a}{V^2}\,dV\\
&=n^2a\left[-\frac{1}{V}\right]_{V_A}^{V_E}.
\end{aligned}
```

したがって，

```math
\boxed{
U_E-U_A=n^2a
\left(\frac{1}{V_A}-\frac{1}{V_E}\right)
}
\tag{5}
```

を得る．

### 5．Maxwell の等面積則の導出

式 (4) と式 (5) を式 (2) に代入すると，

```math
\begin{aligned}
&n^2a\left(\frac{1}{V_A}-\frac{1}{V_E}\right)\\
&\quad-nRT\log\left(\frac{V_E-nb}{V_A-nb}\right)
+p(V_E-V_A)=0
\end{aligned}
```

となる．
これを整理すると，

```math
\boxed{
p(V_E-V_A)
=nRT\log\left(\frac{V_E-nb}{V_A-nb}\right)
+n^2a\left(\frac{1}{V_E}-\frac{1}{V_A}\right)
}
\tag{6}
```

である．

一方，van der Waals の状態方程式 (3) を $V_A$ から $V_E$ まで積分すると，

```math
\begin{aligned}
\int_{V_A}^{V_E}p_{\mathrm{vdW}}(V,T)\,dV
&=\int_{V_A}^{V_E}
\left(\frac{nRT}{V-nb}-\frac{n^2a}{V^2}\right)dV\\
&=\left[
nRT\log(V-nb)+\frac{n^2a}{V}
\right]_{V_A}^{V_E}\\
&=nRT\log\left(\frac{V_E-nb}{V_A-nb}\right)
+n^2a\left(\frac{1}{V_E}-\frac{1}{V_A}\right).
\end{aligned}
```

これを式 (6) と比較すれば，

```math
\boxed{
\int_{V_A}^{V_E}p_{\mathrm{vdW}}(V,T)\,dV
=p(V_E-V_A)
}
\tag{7}
```

が得られる．
ここで， $p$ は A と E に共通する相共存圧力である．

式 (7) の両辺を整理すると，

```math
\boxed{
\int_{V_A}^{V_E}
\left\{p_{\mathrm{vdW}}(V,T)-p\right\}dV=0
}
\tag{8}
```

となる．
これが Maxwell の等面積則である．

### 6．図形的な意味と結論

式 (7) の左辺は，体積 $V_A$ から $V_E$ までの van der Waals 等温線の下側の面積である．
右辺は，相共存圧力 $p$ を高さとし，幅 $V_E-V_A$ を持つ長方形の面積である．

したがって，式 (8) は，等温線と水平な相共存圧力線との差の符号付き面積がゼロになることを意味する．
図では，水平線より下にある領域 ABL の面積と，水平線より上にある領域 LDE の面積が等しくなる．
すなわち，

```math
\boxed{
\text{面積 ABL}=\text{面積 LDE}
}
```

である．

以上より，液相 A と気相 E の化学ポテンシャルが等しいという熱力学的平衡条件から，van der Waals の状態方程式に対する Maxwell の等面積則が導かれた．
