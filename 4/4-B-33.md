# 演習問題【4-B-33】

## 解答

### 1．飽和蒸気の比熱の導出

#### （1）飽和曲線に沿った比熱の式

飽和蒸気を飽和状態に保ちながら加熱する場合，圧力 $p$ と温度 $T$ は飽和蒸気圧曲線 $p=p(T)$ に従って変化する．
このときの単位質量当たりのエントロピーを $s$ とすると，比熱 $c$ は，可逆的な微小変化に対して

```math
\delta q_{\mathrm{rev}}=T\,ds
```

であり，比熱の定義 $\delta q_{\mathrm{rev}}=c\,dT$ より，

```math
\boxed{
c=T\frac{ds}{dT}
}
```

と表される．
ここで， $ds/dT$ は圧力を一定にした微分ではなく，飽和曲線に沿った全微分である．

エントロピー $s$ は温度 $T$ と圧力 $p$ の関数であるため，連鎖律を用いると，

```math
\frac{ds}{dT}
=
\left(\frac{\partial s}{\partial T}\right)_p
+
\left(\frac{\partial s}{\partial p}\right)_T
\frac{dp}{dT}
```

となる．
したがって，

```math
c=T\left[
\left(\frac{\partial s}{\partial T}\right)_p
+
\left(\frac{\partial s}{\partial p}\right)_T
\frac{dp}{dT}
\right]
\tag{1}
```

を得る．

#### （2）マクスウェルの関係式とクラペイロン・クラウジウスの式

まず，定圧比熱の定義より，

```math
c_p=T\left(\frac{\partial s}{\partial T}\right)_p
```

である．
蒸気相の定圧比熱を $c_p^g$ とすれば，

```math
T\left(\frac{\partial s}{\partial T}\right)_p=c_p^g
\tag{2}
```

となる．

次に，マクスウェルの関係式を用いる．
単位質量当たりの体積を $v$ ，定圧熱膨張係数を

```math
\beta=\frac{1}{v}
\left(\frac{\partial v}{\partial T}\right)_p
```

と定義すると，

```math
\left(\frac{\partial s}{\partial p}\right)_T
=
-\left(\frac{\partial v}{\partial T}\right)_p
=-v\beta
\tag{3}
```

である．
蒸気相については， $v=v^g$ ， $\beta=\beta^g$ と書く．

さらに，液相と蒸気相が平衡にあるとき，クラペイロン・クラウジウスの式は

```math
\frac{dp}{dT}
=\frac{r}{T(v^g-v^l)}
\tag{4}
```

となる．
ここで， $r$ は単位質量当たりの気化熱， $v^g$ と $v^l$ はそれぞれ蒸気相と液相の単位質量当たりの体積である．

式（2）～（4）を式（1）に代入すると，

```math
\begin{aligned}
c
&=c_p^g
-Tv^g\beta^g
\frac{r}{T(v^g-v^l)}\\
&=c_p^g
-\frac{v^g\beta^g r}{v^g-v^l}
\end{aligned}
```

を得る．
したがって，飽和曲線に沿った比熱の式は

```math
\boxed{
c=c_p^g-\frac{v^g\beta^g r}{v^g-v^l}
}
\tag{5}
```

である．

#### （3）蒸気を理想気体とみなす近似

沸点付近では，蒸気の比体積は液体の比体積より十分に大きい．
すなわち，

```math
v^g\gg v^l
```

と近似できるため，

```math
v^g-v^l\approx v^g
```

である．
これを式（5）に代入すると，

```math
c\approx c_p^g-\beta^g r
```

となる．
さらに，蒸気を理想気体とみなすと，

```math
v^g=\frac{R_{\mathrm{sp}}T}{p}
```

である．
ここで $R_{\mathrm{sp}}$ は単位質量当たりの気体定数である．
圧力を一定にして温度で微分すると，

```math
\left(\frac{\partial v^g}{\partial T}\right)_p
=\frac{v^g}{T}
```

であるから，

```math
\beta^g
=\frac{1}{v^g}
\left(\frac{\partial v^g}{\partial T}\right)_p
=\frac{1}{T}
```

となる．
したがって，

```math
\boxed{
c\approx c_p^g-\frac{r}{T}
}
\tag{6}
```

を得る．

#### （4）液体の定圧比熱を用いた表現

気化熱は，蒸気相と液相の比エンタルピーの差であるため，

```math
r=h^g-h^l
```

と表される．
ここで， $h^g$ と $h^l$ はそれぞれ蒸気相と液相の比エンタルピーである．

蒸気相と液相の比エンタルピーを飽和曲線に沿って微分すると，厳密には圧力変化の寄与も含まれる．
一般に，

```math
dh=c_p\,dT+
\left[
v-T\left(\frac{\partial v}{\partial T}\right)_p
\right]dp
```

である．
したがって，両相の差を取ると，

```math
\begin{aligned}
\frac{dr}{dT}
={}&c_p^g-c_p^l\\
&+\left[
v^g(1-T\beta^g)
-v^l(1-T\beta^l)
\right]\frac{dp}{dT}
\end{aligned}
```

となる．
ここに式（4）を代入して整理すると，

```math
c_p^g-c_p^l
=
\frac{dr}{dT}
-\frac{r}{T}
+\frac{r(v^g\beta^g-v^l\beta^l)}
{v^g-v^l}
```

を得る．
これを式（5）に代入すると，

```math
\boxed{
c=c_p^l+\frac{dr}{dT}
-\frac{r}{T}
-\frac{rv^l\beta^l}{v^g-v^l}
}
\tag{7}
```

となる．

最後の項は，液体の熱膨張による補正項である．
通常の沸点付近では $v^l\ll v^g$ であるため，この項は十分に小さく，無視できる．
よって，

```math
\boxed{
c\approx c_p^l+\frac{dr}{dT}-\frac{r}{T}
}
\tag{8}
```

となる．

また，積の微分ではなく商の微分を用いると，

```math
\begin{aligned}
T\frac{d}{dT}\left(\frac{r}{T}\right)
&=T\left(
\frac{1}{T}\frac{dr}{dT}
-\frac{r}{T^2}
\right)\\[4pt]
&=\frac{dr}{dT}-\frac{r}{T}
\end{aligned}
```

である．
したがって，式（8）は

```math
\boxed{
c\approx c_p^l+\frac{dr}{dT}-\frac{r}{T}
=c_p^l+T\frac{d}{dT}\left(\frac{r}{T}\right)
}
```

と書ける．
これにより，問題文の関係式が導かれた．

### 2．数値計算

与えられた値は，

```math
\begin{aligned}
c_p^l&=1.01\ \mathrm{cal/(g\,K)},\\
\frac{dr}{dT}&=-0.64\ \mathrm{cal/(g\,K)},\\
r&=539\ \mathrm{cal/g}
\end{aligned}
```

である．
温度 $100^\circ\mathrm{C}$ を絶対温度に直すと，

```math
T=100+273.15=373.15\ \mathrm{K}
```

となる．
式（8）に代入すれば，

```math
\begin{aligned}
c
&\approx c_p^l+\frac{dr}{dT}-\frac{r}{T}\\[4pt]
&=1.01-0.64-\frac{539}{373.15}\\[4pt]
&=0.37-1.4443\ldots\\[4pt]
&\approx-1.07\ \mathrm{cal/(g\,K)}
\end{aligned}
```

である．
したがって，飽和蒸気の比熱は

```math
\boxed{
c\approx-1.07\ \mathrm{cal/(g\,K)}
}
```

となる．

### 3．比熱が負であることの意味

飽和状態を保つ過程では，比熱の定義から

```math
\delta q_{\mathrm{rev}}=c\,dT
```

である．
今回のように $c<0$ であれば，熱量 $\delta q_{\mathrm{rev}}$ と温度変化 $dT$ の符号は反対になる．
すなわち，

- 系に熱を加えると，温度は低下する．
- 系から熱を取り去ると，温度は上昇する．

という関係が成立する．

これは，通常の定圧加熱とは異なり，圧力と温度を飽和曲線に沿って変化させながら，蒸気と液体の相平衡を維持しているためである．
この過程では，温度変化だけでなく，凝縮や蒸発による相の割合の変化も同時に生じる．
そのため，熱量と温度変化の関係が通常の比熱とは逆向きになる場合がある．

なお，ここで得られた負の比熱は，飽和曲線に沿った過程についての比熱である．
通常の安定な単一相を一定圧力で加熱する場合の定圧比熱 $c_p$ が負であることを意味するものではない．
