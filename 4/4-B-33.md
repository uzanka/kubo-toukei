# 演習問題【4-B-33】

## 解答

### 1. 式の導出

まず，飽和状態を保ちながら蒸気を熱する場合の比熱 $c$ を導出する．
比熱 $c$ の定義は，単位質量あたりのエントロピー $s$ の温度 $T$ による変化を用いて，次のように書ける．

$$c = T \frac{ds}{dT}$$

ここで，飽和状態は圧力 $p$ と温度 $T$ が一意に決まる関係（飽和蒸気圧曲線 $p = p(T)$ ）にある．
したがって，エントロピー $s(T, p)$ の全微分は，連鎖律（チェインルール）を用いて次のように展開できる．

$$ds = \left( \frac{\partial s}{\partial T} \right)_p dT + \left( \frac{\partial s}{\partial p} \right)_T dp$$

これを $c = T \frac{ds}{dT}$ に代入すると，

$$c = T \left[ \left( \frac{\partial s}{\partial T} \right)_p + \left( \frac{\partial s}{\partial p} \right)_T \frac{dp}{dT} \right]$$
となる．

ここで，各項を熱力学の基本関係式を用いて書き換える．

1.  **定圧比熱の項**:
  定圧比熱 $c_p^g$ の定義より， $\left( \frac{\partial s}{\partial T} \right)_p = \frac{c_p^g}{T}$ である．
2.  **マクスウェルの関係式**:
  エントエントロピーの偏微分に関するマクスウェルの関係式 $\left( \frac{\partial s}{\partial p} \right)_T = -\left( \frac{\partial v}{\partial T} \right)_p$ を用いる．
  ここで $v$ は単位質量あたりの体積であり，熱膨張係数を $\beta$ とすると， $\left( \frac{\partial v}{\partial T} \right)_p = v\beta$ と書ける．
  したがって， $\left( \frac{\partial s}{\partial p} \right)_T = -v\beta$ である．
3.  **クラペイロン（Clapeyron）の式**:
  相平衡における圧力と温度の関係式 $\frac{dp}{dT} = \frac{r}{T(v^g - v^l)}$ を用いる．
  ここで $r$ は気化熱， $v^g$ は蒸気の体積， $v^l$ は液体の体積である．

これらをまとめると，

$$c = T \left[ \frac{c_p^g}{T} - v^g \beta \frac{r}{T(v^g - v^l)} \right] = c_p^g - \frac{v^g \beta r}{v^g - v^l}$$

が得られる．

ここで，蒸気の体積 $v^g$ が液体の体積 $v^l$ に比べて十分に大きい（ $v^g \gg v^l$ ）という近似を行うと， $v^g - v^l \approx v^g$ とみなせるため，

$$c \approx c_p^g - \frac{v^g \beta r}{v^g} = c_p^g - \beta r$$

となる．
さらに，理想気体近似 $\beta = 1/T$ を用いると，

$$c \approx c_p^g - \frac{r}{T}$$

が得られる．

次に，この式を $c_p^l$ を用いた形に変形する．
気化熱 $r$ は，蒸気のエンタルピー $h^g$ と液体のエンタルピー $h^l$ の差（ $r = h^g - h^l$ ）であるため，

$$\frac{dr}{dT} = \frac{d}{dT}(h^g - h^l) = \frac{dh^g}{dT} - \frac{dh^l}{dT} = c_p^g - c_p^l$$

となる．
これより $c_p^g = c_p^l + \frac{dr}{dT}$ であることがわかる．
これを先ほどの式に代入すると，

$$c = c_p^l + \frac{dr}{dT} - \frac{r}{T} = c_p^l + T \frac{d}{dT}\left(\frac{r}{T}\right)$$

（※ $T \frac{d}{dT}(\frac{r}{T}) = T (\frac{1}{T}\frac{dr}{dT} - \frac{r}{T^2}) = \frac{dr}{dT} - \frac{r}{T}$ より）

となり，問題文の式が導かれた．

### 2. 数値計算

$100^\circ\text{C}$ の水に対する値を代入する．
温度 $T$ は絶対温度（ケルビン）を用いる必要があるため， $T = 100 + 273.15 = 373.15\,\text{K}$ である．

与えられた数値：
- $c_p^l = 1.01\,\text{cal}/(\text{g deg})$
- $\frac{dr}{dT} = -0.64\,\text{cal}/(\text{g deg})$
- $r = 539\,\text{cal}/\text{g}$
- $T = 373.15\,\text{K}$

$$c = 1.01 + (-0.64) - \frac{539}{373.15}$$

$$c = 0.37 - 1.4443...$$

$$c \approx -1.07\,\text{cal}/(\text{g deg})$$

したがって， $c = -1.07\,\text{cal}/(\text{g deg})$ となる．

### 3. $c < 0$ の意味

比熱の定義 $dq = c dT$ において， $c < 0$ であることは，熱量 $dq$ と温度変化 $dT$ の符号が逆であることを意味する．
つまり，**系から熱量を奪う（ $dq < 0$ ）と，温度が上昇する（ $dT > 0$ ）** という現象を表している．

これは，蒸気が飽和状態を保ちながら冷却される際，一部が液体へと凝縮する．
凝縮によって放出される潜熱（気化熱の逆）が，周囲への放熱量よりも非常に大きいため，放出された熱が蒸気の温度を押し上げる結果，温度が上昇するのである．

## 解説

この問題の本質は，相変化を伴う系の熱力学的な振る舞いにある．

1.  **潜熱の影響力**:
  通常の物質の比熱（ $c_p$ ）は，物質の温度を上げるために必要なエネルギーを示するが，相変化（蒸発や凝縮）が絡む場合，エネルギーの大部分は「状態を変えること（潜熱）」に使われる．
  今回のケースでは，凝縮によって放出されるエネルギーが，温度を下げようとする効果を上回ってしまうため，負の比熱という一見直感に反する結果が現れる．
2.  **近似の妥当性**:
  計算で用いた $v^g \gg v^l$ という近似は，液体と気体の体積差が極めて大きいという物理的事実に基づいている．
  水の場合，沸点付近での蒸気の体積は液体の数百倍から千倍以上に達するため，この近似は非常に精度良く機能する．
3.  **マクスウェルの関係式とクラペイロンの式**:
  これらは，熱力学的な状態量（エントロピー，圧力，体積，温度）の間の深い繋がりを示す強力な道具である．
  これらを用いることで，直接測定が難しいエントロピーの変化を，測定可能な圧力や体積の変化として扱うことができる．
