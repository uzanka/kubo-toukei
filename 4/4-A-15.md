# 演習問題【4-A-15】

## 解答

### 1．準備：理想溶液の Gibbs 自由エネルギー

2成分理想溶液において，各成分 $i$ の化学ポテンシャルは

```math
\bar G_i=\bar G_i^0(T,p)+RT\log x_i
```

で与えられる．
ここで， $\bar G_i^0(T,p)$ は純粋な成分 $i$ の化学ポテンシャル， $x_i$ は溶液中の成分 $i$ のモル分率， $R$ は気体定数， $T$ は絶対温度， $p$ は圧力である．

系全体の Gibbs 自由エネルギー $G$ は，各成分の物質量 $n_i$ と化学ポテンシャルを用いて

```math
G=\sum_{i=1}^{2}n_i\bar G_i
```

と表される．
したがって，

```math
\begin{aligned}
G={}&n_1\bar G_1^0(T,p)+n_2\bar G_2^0(T,p)\\
&+RT(n_1\log x_1+n_2\log x_2)
\end{aligned}
\tag{1}
```

となる．
以下では，この式を用いて，混合に伴う体積，エントロピー，エンタルピー，内部エネルギーの変化を求める．
混合前後で温度，圧力および各成分の物質量は同じとする．

### 2．(i) 混合による体積変化がないことの証明

温度と各成分の物質量を一定にしたとき，系全体の体積 $V$ は Gibbs 自由エネルギーを圧力 $p$ で偏微分することによって求められる．
すなわち，

```math
V=\left(\frac{\partial G}{\partial p}\right)_{T,n_1,n_2}
\tag{2}
```

である．
式(1)を圧力で偏微分すると，

```math
\begin{aligned}
V={}&n_1\left(\frac{\partial\bar G_1^0}{\partial p}\right)_T
+n_2\left(\frac{\partial\bar G_2^0}{\partial p}\right)_T
\end{aligned}
```

となる．
ここで，モル分率 $x_i=n_i/(n_1+n_2)$ は各成分の物質量だけで決まるため，この偏微分では一定である．
したがって，式(1)の $\log x_i$ を含む項は圧力微分に寄与しない．

純粋な成分 $i$ のモル体積を

```math
\bar V_i^0
=\left(\frac{\partial\bar G_i^0}{\partial p}\right)_T
```

と定義すると，

```math
\boxed{V=n_1\bar V_1^0+n_2\bar V_2^0}
\tag{3}
```

を得る．

一方，混合前は各成分が純粋な液体として存在するため，全体の体積は

```math
V_{\mathrm{before}}
=n_1\bar V_1^0+n_2\bar V_2^0
```

である．
式(3)より，混合後の体積 $V_{\mathrm{after}}$ も同じ値である．
したがって，

```math
\boxed{\Delta V=V_{\mathrm{after}}-V_{\mathrm{before}}=0}
```

となる．
よって， **混合の前後で体積の変化はない** ことが示された．

### 3．(iii) 混合によるエントロピー変化の証明

系全体のエントロピー $S$ は，Gibbs 自由エネルギーを温度で偏微分することによって求められる．
すなわち，

```math
S=-\left(\frac{\partial G}{\partial T}\right)_{p,n_1,n_2}
\tag{4}
```

である．
式(1)を温度で偏微分すると，

```math
\begin{aligned}
S={}&-n_1\left(\frac{\partial\bar G_1^0}{\partial T}\right)_p
-n_2\left(\frac{\partial\bar G_2^0}{\partial T}\right)_p\\
&-R(n_1\log x_1+n_2\log x_2)
\end{aligned}
\tag{5}
```

となる．
ここでは，物質量 $n_i$ を一定に保って温度微分するため，モル分率 $x_i$ は一定である．また， $RT$ を温度で微分すると $R$ になることを用いた．

純粋な成分 $i$ のモルエントロピーを

```math
\bar S_i^0
=-\left(\frac{\partial\bar G_i^0}{\partial T}\right)_p
```

と定義すると，式(5)は

```math
\begin{aligned}
S={}&n_1\bar S_1^0+n_2\bar S_2^0\\
&-R(n_1\log x_1+n_2\log x_2)
\end{aligned}
\tag{6}
```

となる．

混合前には各成分が純粋な状態にあるため，混合前のエントロピーは

```math
S_{\mathrm{before}}
=n_1\bar S_1^0+n_2\bar S_2^0
```

である．
したがって，混合によるエントロピー変化は，式(6)から混合前のエントロピーを差し引いて，

```math
\Delta S=S_{\mathrm{after}}-S_{\mathrm{before}}
=-R(n_1\log x_1+n_2\log x_2)
```

となる．
ここで，全物質量を $n=n_1+n_2$ とすると， $n_i=nx_i$ であるから，

```math
\boxed{
\Delta S=-Rn(x_1\log x_1+x_2\log x_2)
}
\tag{7}
```

を得る．
これは問題文の式(4.19)で与えられた混合エントロピーである．

なお， $0<x_i<1$ では $\log x_i<0$ であるため，式(7)の右辺は正となる．
したがって， **混合によってエントロピーは混合エントロピーの分だけ増加する** ことが示された．

### 4．(ii) 混合に際して熱の発生・吸収がないことの証明

エンタルピー $H$ は Gibbs 自由エネルギー $G$ とエントロピー $S$ を用いて

```math
H=G+TS
\tag{8}
```

と表される．
式(1)と式(6)を式(8)に代入すると，

```math
\begin{aligned}
H={}&n_1\bar G_1^0+n_2\bar G_2^0
+RT(n_1\log x_1+n_2\log x_2)\\
&+T\left[
n_1\bar S_1^0+n_2\bar S_2^0
-R(n_1\log x_1+n_2\log x_2)
\right]
\end{aligned}
```

となる．
ここで， $RT(n_1\log x_1+n_2\log x_2)$ の項は，エントロピーに由来する項と打ち消し合う．
よって，

```math
H=n_1(\bar G_1^0+T\bar S_1^0)
+n_2(\bar G_2^0+T\bar S_2^0)
```

を得る．
純粋な成分 $i$ のモルエンタルピーは

```math
\bar H_i^0=\bar G_i^0+T\bar S_i^0
```

であるから，

```math
\boxed{
H=n_1\bar H_1^0+n_2\bar H_2^0
}
\tag{9}
```

となる．

式(9)は，混合後のエンタルピーが，混合前の純粋な各成分のエンタルピーの和に等しいことを示している．
したがって，

```math
\boxed{
\Delta H=0
}
```

である．

定圧で，仕事が体積変化に伴う $pV$ 仕事のみである過程では，系が受け取る熱量 $Q_p$ はエンタルピー変化に等しい．
すなわち，

```math
Q_p=\Delta H=0
```

である．
よって， **混合に際して熱の発生も吸収もない** ことが示された．

### 5．内部エネルギーの変化

最後に，内部エネルギー $U$ の変化を求める．
内部エネルギー，エンタルピー，体積の間には

```math
U=H-pV
\tag{10}
```

の関係がある．
混合前後で圧力 $p$ は一定であるため，

```math
\Delta U=\Delta H-p\Delta V
```

となる．
すでに示したように，

```math
\Delta H=0,\qquad \Delta V=0
```

であるから，

```math
\boxed{
\Delta U=0
}
```

を得る．
したがって， **理想溶液の混合では内部エネルギーも変化しない** のである．

実際，式(3)，式(9)を式(10)に代入すると，

```math
\begin{aligned}
U
&=n_1\bar H_1^0+n_2\bar H_2^0
-p(n_1\bar V_1^0+n_2\bar V_2^0)\\
&=n_1(\bar H_1^0-p\bar V_1^0)
+n_2(\bar H_2^0-p\bar V_2^0)
\end{aligned}
```

となる．
純粋な成分 $i$ のモル内部エネルギーを

```math
\bar U_i^0=\bar H_i^0-p\bar V_i^0
```

と定義すれば，

```math
\boxed{
U=n_1\bar U_1^0+n_2\bar U_2^0
}
```

である．
これは混合前の内部エネルギーの和に等しいことからも，内部エネルギー変化がゼロであると確認できる．

### 結論

2成分理想溶液の化学ポテンシャルの式から Gibbs 自由エネルギーを構成し，その温度・圧力微分を用いることで，次の結果が得られた．

```math
\boxed{
\Delta V=0
}
```

```math
\boxed{
\Delta S=-R\sum_{i=1}^{2}n_i\log x_i
}
```

```math
\boxed{
\Delta H=0
}
```

```math
\boxed{
\Delta U=0
}
```

すなわち，理想溶液では，混合によってエントロピーは混合エントロピーの分だけ増加する一方，体積，エンタルピー，内部エネルギーは変化しないのである．
