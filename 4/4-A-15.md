# 演習問題【4-A-15】

## 解答

2成分理想溶液の各成分 $i$ ( $i=1, 2$ ) の化学ポテンシャル $\bar{G}_i$ は，問題文より次のように与えられる：

$\bar{G}_i = \bar{G}_i^0(T, p) + RT \log x_i$

ここで，系全体のギブズ自由エネルギー $G$ は，各成分のモル数 $n_i$ と化学ポテンシャルの和として次のように書ける：

$$G = \sum_{i=1}^2 n_i \bar{G}_i = n_1 \bar{G}_1 + n_2 \bar{G}_2$$

$$G = n_1 [\bar{G}_1^0(T, p) + RT \log x_1] + n_2 [\bar{G}_2^0(T, p) + RT \log 
x_2]$$

$$G = n_1 \bar{G}_1^0(T, p) + n_2 \bar{G}_2^0(T, p) + RT (n_1 \log x_1 + n_2 \log x_2)$$

**(i) 体積の変化について**

系の体積 $V$ は，ギブズ自由エネルギーを圧力 $p$ で偏微分することで得られる：

$$V = \left( \frac{\partial G}{\partial p} \right)_{T, n}$$

これを計算すると，

$$V = \frac{\partial}{\partial p} \left[ n_1 \bar{G}_1^0(T, p) + n_2 \bar{G}_2^0(T, p) + RT (n_1 \log x_1 + n_2 \log x_2) \right]_{T, n}$$

ここで， $n_1, n_2, x_1, x_2$ は圧力 $p$ に依存しない（ $n_i$ は一定で $x_i = n_i / (n_1+n_2)$ であるため）ので，第3項の微分は 0 になる．

$$V = n_1 \left( \frac{\partial \bar{G}_1^0}{\partial p} \right)_{T, n} + n_2 \left( \frac{\partial \bar{G}_2^0}{\partial p} \right)_{T, n}$$

純粋な成分 $i$ のモル体積を $\bar{V}_i^0 = \left( \frac{\partial \bar{G}_i^0}{\partial p} \right)_{T}$ と定義すると，

$$V = n_1 \bar{V}_1^0 + n_2 \bar{V}_2^0$$

となる．
これは混合前の各成分の純粋な体積の和と等しく，したがって，混合の前後で体積の変化はない．

**(iii) エントロピーの変化について**

系のエントロピー $S$ は，ギブズ自由エネルギーを温度 $T$ で偏微分することにより得られる：

$$S = -\left( \frac{\partial G}{\partial T} \right)_{p, n}$$

これを計算すると，

$$S = -\frac{\partial}{\partial T} \left[ n_1 \bar{G}_1^0(T, p) + n_2 \bar{G}_2^0(T, p) + RT (n_1 \log x_1 + n_2 \log x_2) \right]_{p, n}$$

第3項の微分は， $\frac{\partial}{\partial T} [RT (n_1 \log x_1 + n_2 \log x_2)] = R (n_1 \log x_1 + n_2 \log x_2)$ となる．

$$S = -n_1 \left( \frac{\partial \bar{G}_1^0}{\partial T} \right)_{p, n} - n_2 \left( \frac{\partial \bar{G}_2^0}{\partial T} \right)_{p, n} - R (n_1 \log x_1 + n_2 \log x_2)$$

純粋な成分 $i$ のモルエントロピーを $\bar{S}_i^0 = -\left( \frac{\partial \bar{G}_i^0}{\partial T} \right)_{p}$ と定義すると，

$$S = n_1 \bar{S}_1^0 + n_2 \bar{S}_2^0 - R (n_1 \log x_1 + n_2 \log x_2)$$

となる．
混合前のエントロピー $S_{before} = n_1 \bar{S}_1^0 + n_2 \bar{S}_2^0$ と比較すると，

$$\Delta S = S - S_{before} = -R (n_1 \log x_1 + n_2 \log x_2)$$

となり，これは混合エントロピーの式そのものである．
したがって，エントロピーは混合のエントロピーの分だけ増加する．

**(ii) エンタルピーおよび内部エネルギーの変化について**

まず，エンタルピー $H$ を考える．
$H = G + TS$ より，

$$H = [n_1 \bar{G}_1^0 + n_2 \bar{G}_2^0 + RT (n_1 \log x_1 + n_2 \log x_2)] + T [n_1 \bar{S}_1^0 + n_2 \bar{S}_2^0 - R (n_1 \log x_1 + n_2 \log x_2)]$$

$$H = n_1 (\bar{G}_1^0 + T \bar{S}_1^0) + n_2 (\bar{G}_2^0 + T \bar{S}_2^0)$$

ここで，純粋な成分 $i$ のモルエンタルピーを $\bar{H}_i^0 = \bar{G}_i^0 + T \bar{S}_i^0$ とすると，

$$H = n_1 \bar{H}_1^0 + n_2 \bar{H}_2^0$$

となる．
これは混合前の各成分の純粋なエンタルピーの和と等しく，したがって，混合に際してエンタルピーの変化はない．
エンタルピーの変化 $\Delta H = 0$ は，定圧条件下での熱の授受 $Q = \Delta H$ が 0 であることを意味するため，混合に際して熱の発生や吸収がないことを示している．

さらに，内部エネルギー $U$ は $U = H - pV$ で与えられる．
混合後の $U$ は，

$$U = (n_1 \bar{H}_1^0 + n_2 \bar{H}_2^0) - p(n_1 \bar{V}_1^0 + n_2 \bar{V}_2^0)$$

$$U = n_1 (\bar{H}_1^0 - p \bar{V}_1^0) + n_2 (\bar{H}_2^0 - p \bar{V}_2^0)$$

純粋な成分 $i$ のモル内部エネルギーを $\bar{U}_i^0 = \bar{H}_i^0 - p \bar{V}_i^0$ と定義すると，

$$U = n_1 \bar{U}_1^0 + n_2 \bar{U}_2^0$$

となる．
これは混合前の各成分の純粋な内部エネルギーの和と一致するため，内部エネルギーの変化も 0 である．

## 解説

この問題は，理想溶液の定義から，混合に伴う熱力学的な量の変化がどのように起こるかを導出するものである．

1.  **化学ポテンシャルの意味**:
  化学ポテンシャル $\bar{G}_i$ は，その成分が系全体に与えるギブズ自由エネルギーの変化量である．
  理想溶液では，成分の存在が互いに干渉しないため，純粋な状態の化学ポテンシャル $\bar{G}_i^0$ に，濃度（モル分率 $x_i$ ）に依存する項 $RT \log x_i$ が加わる形で記述される．

2.  **熱力学的な関係式**:
    *   **体積 ( $V$ )**:
       ギブズ自由エネルギーを圧力で微分することで得られる．
       $V = (\partial G / \partial p)_{T, n}$ ．
       理想溶液では，この微分が濃度項（ $\log x_i$ ）を通り抜けて 0 になるため，体積は単なる成分の和になる．
    *   **エントロピー ( $S$ )**:
       ギブズ自由エネルギーを温度で微分することで得られる．
       $S = -(\partial G / \partial T)_{p, n}$ ．
       温度による変化は $\log x_i$ 項の係数 $RT$ に現れ，これが混合によるエントロピーの増加を記述する．
    *   **エンタルピー ( $H$ )**:
       $H = G + TS$ である．
       混合によるエントロピーの増加と，ギブズ自由エネルギーの減少がちょうど打ち消し合うため，エンタルピーは変化しない．
       これは「混合熱」が 0 であることを意味する．
    *   **内部エネルギー ( $U$ )**:
       $U = H - pV$ である．
       $H$ も $V$ も変化しないため，結果として $U$ も変化しない．

3.  **結論**:
  理想溶液とは，混合によって「乱雑さ（エントロピー）」は増えるものの，成分間の相互作用がないために「エネルギー（エンタルピーや内部エネルギー）」や「体積」には変化が起きないような理想的な混合状態を指している．
