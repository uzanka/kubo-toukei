# 演習問題【4-A-21】

## 解答

### (i) 固相線・液相線を定める一般的な方程式

#### 1．液相と固相の平衡条件

成分 A を成分1，成分 B を成分2と表し，液相を $l$ ，固相を $s$ で表す．
各相における成分 $i$ のモル分率をそれぞれ $x_{il}$ ， $x_{is}$ とする．

液相と固相が平衡にあるとき，各成分の化学ポテンシャルは両相で等しい．
また，両相が理想溶液であるため，成分 $i$ の化学ポテンシャルは，それぞれ

```math
\mu_{il}=\bar G_{il}^{0}+RT\ln x_{il},
\qquad
\mu_{is}=\bar G_{is}^{0}+RT\ln x_{is}
```

と表される．
ここで， $\bar G_{il}^{0}$ ， $\bar G_{is}^{0}$ は純粋な成分 $i$ の液相および固相におけるモルギブスエネルギー， $R$ は気体定数， $T$ は絶対温度である．
したがって，平衡条件は

```math
\bar G_{il}^{0}+RT\ln x_{il}
=
\bar G_{is}^{0}+RT\ln x_{is}
\tag{1}
```

となる．
これを整理すると，

```math
\ln\frac{x_{il}}{x_{is}}
=
\frac{\bar G_{is}^{0}-\bar G_{il}^{0}}{RT}
```

を得る．
ここで，

```math
\lambda_i
\equiv
\frac{\bar G_{is}^{0}-\bar G_{il}^{0}}{RT}
```

と定義すれば，

```math
\boxed{
\frac{x_{il}}{x_{is}}=e^{\lambda_i}
}
\tag{2}
```

となる．
この式は，平衡状態における各成分の液相と固相のモル分率の関係を表している．

#### 2．液相線と固相線の導出

2成分系では，それぞれの相におけるモル分率の和が1であるため，

```math
x_{1l}+x_{2l}=1,
\qquad
x_{1s}+x_{2s}=1
\tag{3}
```

が成り立つ．
式 (2) より，

```math
x_{1s}=x_{1l}e^{-\lambda_1},
\qquad
x_{2s}=x_{2l}e^{-\lambda_2}
```

である．
これらを固相のモル分率の和の式に代入すると，

```math
x_{1l}e^{-\lambda_1}
+x_{2l}e^{-\lambda_2}=1
```

となる．
さらに， $x_{1l}=1-x_{2l}$ を代入して整理すれば，

```math
(1-x_{2l})e^{-\lambda_1}
+x_{2l}e^{-\lambda_2}=1
```

を得る．
したがって，

```math
x_{2l}
\left(e^{-\lambda_2}-e^{-\lambda_1}\right)
=1-e^{-\lambda_1}
```

であり，液相中の成分2のモル分率は

```math
\boxed{
x_{2l}
=\frac{1-e^{-\lambda_1}}
{e^{-\lambda_2}-e^{-\lambda_1}}
}
\tag{4}
```

と表される．
これが液相線の方程式である．

一方，式 (2) より，

```math
x_{1l}=x_{1s}e^{\lambda_1},
\qquad
x_{2l}=x_{2s}e^{\lambda_2}
```

である．
これらを液相のモル分率の和の式に代入すると，

```math
x_{1s}e^{\lambda_1}
+x_{2s}e^{\lambda_2}=1
```

となる．
$x_{1s}=1-x_{2s}$ を代入して整理すれば，

```math
(1-x_{2s})e^{\lambda_1}
+x_{2s}e^{\lambda_2}=1
```

である．
よって，

```math
x_{2s}
\left(e^{\lambda_1}-e^{\lambda_2}\right)
=e^{\lambda_1}-1
```

となり，固相中の成分2のモル分率は

```math
\boxed{
x_{2s}
=\frac{e^{\lambda_1}-1}
{e^{\lambda_1}-e^{\lambda_2}}
}
\tag{5}
```

と表される．
これが固相線の方程式である．

したがって，式 (4)，(5) によって液相線と固相線が定まる．
ただし，温度 $T$ における $\lambda_i$ を求めるには，融点と融解熱を用いて $\lambda_i$ を表す必要がある．
これは次の (ii) で行う．

### (ii) 仮定を用いた近似と葉巻型相図

#### 1．$\lambda_i$ の表式

成分 $i$ の融点を $T_i$ ，融解熱を $L_i$ とする．
融解熱の温度変化を無視するという仮定 (b) のもとでは，ギブス・ヘルムホルツの式を融点 $T_i$ から温度 $T$ まで積分することにより，

```math
\frac{\bar G_{is}^{0}-\bar G_{il}^{0}}{RT}
=\frac{L_i}{RT_i}
\left(1-\frac{T_i}{T}\right)
```

を得る．
したがって，

```math
\lambda_i=\alpha_i
\left(1-\frac{T_i}{T}\right),
\qquad
\alpha_i\equiv\frac{L_i}{RT_i}
\tag{6}
```

である．

仮定 (a) より，2成分の融解エントロピー $L_i/T_i$ は等しいため，

```math
\alpha_1=\alpha_2=\alpha
```

とおける．
さらに， $\alpha$ は1程度の大きさである．
よって，

```math
\boxed{
\lambda_i=\alpha\left(1-\frac{T_i}{T}\right)
}
\tag{7}
```

となる．

仮定 (c) は，2つの融点の差が各融点に比べて小さいことを意味する．
温度 $T$ が両融点の間にあるとき， $T-T_i$ は融点に比べて小さいため，式 (7) より $\lambda_i$ も小さい．
この性質を用いて，式 (4)，(5) を $\lambda_1,\lambda_2$ のべき級数として展開する．

#### 2．液相線と固相線の近似式

指数関数のテイラー展開は

```math
e^z=1+z+\frac{z^2}{2!}
+\frac{z^3}{3!}+\cdots
```

である．
これを式 (4)，(5) に適用し， $\lambda_1-\lambda_2$ を保ったまま整理すると，

```math
\begin{aligned}
x_{2l}
&=\frac{\lambda_1}{\lambda_1-\lambda_2}
\left[
1+\frac{\lambda_2}{2}
+\frac{\lambda_2(\lambda_1+\lambda_2)}{12}
+\cdots
\right],
\end{aligned}
\tag{8}
```

```math
\begin{aligned}
x_{2s}
&=\frac{\lambda_1}{\lambda_1-\lambda_2}
\left[
1-\frac{\lambda_2}{2}
+\frac{\lambda_2(\lambda_1+\lambda_2)}{12}
+\cdots
\right]
\end{aligned}
\tag{9}
```

となる．
ここで，省略した項は $\lambda_i$ のさらに高次の項である．

葉巻型の形状を理解するため，まず括弧内の $\lambda_2$ に比例する項までを残す．
式 (7) から，

```math
\lambda_1-\lambda_2
=\alpha\frac{T_2-T_1}{T}
```

であるため，

```math
\frac{\lambda_1}{\lambda_1-\lambda_2}
=\frac{T-T_1}{T_2-T_1}
```

となる．
また，

```math
\frac{\lambda_2}{2}
=\frac{\alpha}{2}
\left(1-\frac{T_2}{T}\right)
=-\frac{\alpha}{2}\frac{T_2-T}{T}
```

である．
これらを式 (8)，(9) に代入すると，

```math
\boxed{
x_{2l}\simeq
\frac{T-T_1}{T_2-T_1}
-\frac{\alpha}{2}
\frac{(T_2-T)(T-T_1)}
{T(T_2-T_1)}
}
\tag{10}
```

および

```math
\boxed{
x_{2s}\simeq
\frac{T-T_1}{T_2-T_1}
+\frac{\alpha}{2}
\frac{(T_2-T)(T-T_1)}
{T(T_2-T_1)}
}
\tag{11}
```

を得る．
ここでは， $\lambda_i$ の2次以上の補正項を省略した．
また， $\alpha$ は1程度であるが，近似式の導出ではその係数を明示的に残した．
$\alpha\simeq1$ とすれば，解答例の式 (9)，(10) に一致する．

#### 3．葉巻型になることの確認

一般性を失わず， $T_1<T_2$ とする．
式 (10)，(11) の第1項は，両端の融点を結ぶ直線

```math
x_2^{(0)}=\frac{T-T_1}{T_2-T_1}
```

を表す．
一方，第2項は，液相線と固相線をこの直線から反対方向にずらす補正項である．

$T_1<T<T_2$ では，

```math
(T_2-T)(T-T_1)>0
```

であるため， $\alpha>0$ より，式 (10)，(11) から

```math
x_{2l}<x_2^{(0)}<x_{2s}
```

が得られる．
したがって，

```math
\boxed{
x_{2l}<x_{2s}
}
```

である．
すなわち，同じ温度において，液相の成分2のモル分率は固相の成分2のモル分率より小さい．
横軸を成分2のモル分率，縦軸を温度とする相図では，液相線と固相線は中間組成で互いに離れる．

さらに， $T=T_1$ または $T=T_2$ では，

```math
(T_2-T)(T-T_1)=0
```

となるため，式 (10)，(11) の補正項はともにゼロである．
このとき，

- $T=T_1$ では $x_{2l}=x_{2s}=0$ である．
- $T=T_2$ では $x_{2l}=x_{2s}=1$ である．

つまり，2本の境界線は純成分1と純成分2の融点で一致し，その間の組成では離れている．
この形状が，葉巻型（レンズ型）の相図である．

#### 4．相領域の意味

液相線より高温側では，合金は完全な液相となる．
固相線より低温側では，合金は完全な固相となる．
そして，液相線と固相線の間では，液相と固相が共存する．

以上より，(i) で導いた一般式に，仮定 (a)～(c) を適用して近似すると，両端の純成分の融点で一致し，中間組成で液相線と固相線が離れる葉巻型の相図が得られる．
