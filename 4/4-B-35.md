# 演習問題【4-B-35】

## 解答

### 1．飽和水蒸気の比熱が負であることの意味

Wilson の霧箱では，飽和水蒸気を急に膨張させることで，過飽和水蒸気を作り出す．
その原理を理解するため，温度 $T$ と圧力 $p$ の関係を表す $p$-$T$ 図上で，飽和蒸気圧曲線と断熱線を比較する．
以下では，水蒸気を理想気体と近似し，断熱膨張を等エントロピー過程として扱う．

飽和蒸気の比熱 $c$ は，飽和蒸気圧曲線に沿った単位質量当たりのエントロピー $s$ の変化を用いて，

```math
c=T\frac{ds}{dT}
```

と定義される．
したがって， $c<0$ であれば，

```math
\frac{ds}{dT}<0
```

である．
つまり，飽和曲線上では，温度が高いほどエントロピーが小さい．

### 2．飽和蒸気圧曲線と等エントロピー線の比較

#### （1）状態 A，B，C の設定

$p$-$T$ 図上に，飽和蒸気圧曲線上の2点 A，B を取り，それぞれの温度を $T_A$ ， $T_B$ とする．
ただし，

```math
T_A<T_B
```

とする．
飽和比熱が負であるため，温度が高い B のエントロピーは A のエントロピーより小さく，

```math
s_A>s_B
\tag{1}
```

となる．

次に，B から温度 $T_B$ を一定に保ちながら圧力を下げる．
等温変化におけるエントロピーの圧力依存性は，マクスウェルの関係式より，

```math
\left(\frac{\partial s}{\partial p}\right)_T
=-\left(\frac{\partial v}{\partial T}\right)_p
```

である．
理想気体では $v=RT/p$ であるから，

```math
\left(\frac{\partial s}{\partial p}\right)_T
=-\frac{R}{p}<0
\tag{2}
```

となる．
ここで $v$ はモル体積， $R$ は気体定数である．

式（2）から，温度一定で圧力を下げるとエントロピーは増加することが分かる．
したがって，B から圧力を下げ，エントロピーが $s_A$ に等しくなる点 C を取ることができる．
このとき，

```math
s_C=s_A
```

であり，B と C は同じ温度にあるため，

```math
p_C<p_B
```

である．
A と C は同じエントロピーを持つので，両点を結ぶ線 AC は等エントロピー線である．

#### （2）飽和曲線の傾き

飽和蒸気圧曲線を $p=p_s(T)$ とする．
その傾きは，クラペイロン・クラウジウスの式より，

```math
\frac{dp_s}{dT}
=\frac{L}{T(v_g-v_l)}
\tag{3}
```

で与えられる．
ここで， $L$ はモル当たりの気化熱， $v_g$ ， $v_l$ はそれぞれ蒸気相と液相のモル体積である．

一方，飽和曲線に沿ったエントロピーの微分は，

```math
\frac{ds}{dT}
=
\left(\frac{\partial s}{\partial T}\right)_p
+
\left(\frac{\partial s}{\partial p}\right)_T
\frac{dp_s}{dT}
```

である．
定圧モル比熱を $c_p$ とすると，

```math
\left(\frac{\partial s}{\partial T}\right)_p
=\frac{c_p}{T}
```

であり，理想気体の関係式（2）を用いれば，

```math
\frac{ds}{dT}
=\frac{c_p}{T}
-\frac{R}{p}\frac{dp_s}{dT}
```

となる．
両辺に $T$ を掛けると，

```math
c=c_p-\frac{RT}{p}\frac{dp_s}{dT}
\tag{4}
```

を得る．
これを飽和曲線の傾きについて解くと，

```math
\boxed{
\frac{dp_s}{dT}
=\frac{p}{RT}(c_p-c)
}
\tag{5}
```

となる．

#### （3）等エントロピー線の傾き

理想気体のエントロピーの微小変化は，

```math
ds=\frac{c_p}{T}\,dT-\frac{R}{p}\,dp
```

である．
等エントロピー過程では $ds=0$ であるため，

```math
\frac{c_p}{T}\,dT
=\frac{R}{p}\,dp
```

となる．
よって，等エントロピー線の傾きは，

```math
\boxed{
\left(\frac{\partial p}{\partial T}\right)_s
=\frac{c_p}{R}\frac{p}{T}
}
\tag{6}
```

である．

ここで $c<0$ であることから，

```math
c_p-c>c_p
```

が成立する．
式（5），（6）を飽和曲線上の同じ状態で比較すると，

```math
\frac{dp_s}{dT}
=\frac{p}{RT}(c_p-c)
>
\frac{c_p}{R}\frac{p}{T}
=\left(\frac{\partial p}{\partial T}\right)_s
\tag{7}
```

を得る．
したがって， **飽和蒸気圧曲線の傾きは等エントロピー線の傾きより大きい** ．
すなわち， $p$-$T$ 図上では，等エントロピー線 AC の方が飽和蒸気圧曲線 AB よりも傾斜が緩やかになる．

### 3．断熱膨張によって過飽和水蒸気が生じる理由

Wilson の霧箱内の飽和水蒸気を状態 A にあるとする．
霧箱を急に膨張させると，水蒸気の温度と圧力が低下する．
この過程を等エントロピー過程と近似すると，状態は A を通る等エントロピー線に沿って移動する．

飽和蒸気圧曲線の傾きは等エントロピー線の傾きより大きいため，A から温度が低下する方向へ進むと，等エントロピー線上の圧力は，同じ温度における飽和蒸気圧より高くなる．
これを式で確認する．

状態 A の温度と圧力を $T_A$ ， $p_A=p_s(T_A)$ とし，膨張後の温度を $T_D<T_A$ とする．
A 付近で曲線を直線近似すれば，

```math
p_D-p_A
\approx
\left(\frac{\partial p}{\partial T}\right)_s
(T_D-T_A)
```

であり，同じ温度における飽和蒸気圧については，

```math
p_s(T_D)-p_A
\approx
\frac{dp_s}{dT}(T_D-T_A)
```

である．
式（7）より，

```math
\left(\frac{\partial p}{\partial T}\right)_s
<
\frac{dp_s}{dT}
```

である．
一方， $T_D-T_A<0$ であるため，両辺に $T_D-T_A$ を掛けると不等号が逆転する．
したがって，

```math
p_D-p_A>p_s(T_D)-p_A
```

となり，

```math
\boxed{
p_D>p_s(T_D)
}
```

を得る．
これは，膨張後の水蒸気の圧力が，その温度での飽和蒸気圧を上回っていることを意味する．
すなわち，水蒸気は過飽和状態になるのである．

### 4．Wilson の霧箱で放射線の軌跡が見える理由

過飽和状態になった水蒸気は，液滴を形成することで平衡に近づこうとする．
しかし，凝結核が存在しない場合，液滴は容易には発生しない．

一方，放射線が霧箱内を通過すると，その通路に沿ってイオンが生じる．
これらのイオンは凝結核として働き，過飽和水蒸気の凝縮を促進する．
その結果，放射線の通路に沿って多数の微小な霧粒子が生じ，放射線の軌跡を目で観察できるようになる．
これが Wilson の霧箱の原理である．

以上より，飽和水蒸気の比熱が負であると，飽和蒸気圧曲線と等エントロピー線の傾きの大小関係が決まり，断熱膨張によって水蒸気が過飽和状態に入ることが説明できる．
