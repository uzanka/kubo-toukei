# 演習問題【4-B-35】

## 解答

霧箱内の気体を，乾燥空気と水蒸気からなる理想気体混合物とする．
凝結が始まるまでは，霧箱内の乾燥空気と水蒸気の質量分率が一定であると仮定する．
また，膨張前の状態を $A$ ，膨張後で凝結が始まる前の状態を $D$ とし，この間の温度変化の範囲で飽和水蒸気の比熱 $c$ は負であるとする．

急速な膨張では外部との熱交換が小さいため，断熱膨張として近似できる．
ただし，断熱過程が必ず可逆過程になるわけではない．
そこで，まず可逆断熱膨張を理想化された基準過程として扱い，その後，不可逆性がある場合の条件も調べる．

水蒸気の分圧を $p_v$ ，混合気体の全圧を $P$ ，温度 $T$ における飽和水蒸気圧を $p_s(T)$ とする．
膨張前には水蒸気が飽和しているので，

```math
p_{v,A}=p_s(T_A)
```

が成り立つ．
水蒸気が過飽和であるための条件は，その温度において，

```math
p_v>p_s(T)
```

となることである．

### 1．飽和水蒸気圧曲線の傾き

水蒸気の比エントロピーを $s_v$ ，定圧比熱を $c_{p,v}$ ，比気体定数を $R_v$ とする．
以下，水蒸気の比熱，比エントロピー，比気体定数はすべて水蒸気の単位質量当たりの量とする．

理想気体の水蒸気について，Maxwell の関係式から，

```math
\left(\frac{\partial s_v}{\partial p_v}\right)_T
=
-\left(\frac{\partial v_v}{\partial T}\right)_{p_v}
=
-\frac{R_v}{p_v}
```

を得る．
また，

```math
\left(\frac{\partial s_v}{\partial T}\right)_{p_v}
=
\frac{c_{p,v}}{T}
```

であるから，

```math
ds_v
=
\frac{c_{p,v}}{T}\,dT
-
\frac{R_v}{p_v}\,dp_v
```

となる．

ここで，飽和状態にある水蒸気の比エントロピーを

```math
s_{v,s}(T)=s_v\bigl(T,p_s(T)\bigr)
```

と定義する．
問題で与えられている飽和水蒸気の比熱 $c$ は，飽和曲線に沿った比エントロピーの温度微分，

```math
c(T)=T\frac{ds_{v,s}}{dT}
```

である．
これは水蒸気の通常の定圧比熱 $c_{p,v}$ とは異なる．

飽和曲線上では $p_v=p_s(T)$ であるから，

```math
c
=
c_{p,v}
-
\frac{R_vT}{p_s}
\frac{dp_s}{dT}
```

したがって，

```math
\boxed{
\frac{dp_s}{dT}
=
\frac{p_s}{R_vT}(c_{p,v}-c)
}
\tag{1}
```

を得る．

### 2．空気と水蒸気の混合気体の断熱線

乾燥空気と水蒸気の質量分率をそれぞれ $Y_a$ ， $Y_v$ とする．
混合気体の定圧比熱 $c_{p,m}$ と比気体定数 $R_m$ は，

```math
c_{p,m}=Y_a c_{p,a}+Y_v c_{p,v}
```

```math
R_m=Y_aR_a+Y_vR_v
```

で与えられる．
ここで， $c_{p,a}$ と $R_a$ は乾燥空気の定圧比熱と比気体定数である．

凝結前は気体の組成が一定であるため，水蒸気のモル分率 $x_v$ も一定である．
したがって，

```math
p_v=x_vP
```

より，

```math
d\ln p_v=d\ln P
```

が成り立つ．

組成一定の理想気体混合物の比エントロピーを $s_m$ とすると，

```math
ds_m
=
\frac{c_{p,m}}{T}\,dT
-
\frac{R_m}{P}\,dP
```

である．
可逆断熱過程では $ds_m=0$ なので，

```math
\frac{dP}{dT}
=
\frac{c_{p,m}}{R_m}\frac{P}{T}
```

を得る．
水蒸気の分圧についても同じ関係が成り立ち，

```math
\boxed{
\left(\frac{dp_v}{dT}\right)_{s_m}
=
\frac{p_v}{R_mT}c_{p,m}
}
\tag{2}
```

となる．

### 3．飽和曲線と断熱線の傾きの比較

式 (1)，(2) を，膨張前の飽和状態 $A$ において比較する．
このとき $p_{v,A}=p_s(T_A)$ であるから，

```math
\left.
\left(
\frac{dp_s}{dT}
-
\left(\frac{dp_v}{dT}\right)_{s_m}
\right)
\right|_A
=
\frac{p_{s,A}}{T_A}
\left[
\frac{c_{p,v}-c}{R_v}
-
\frac{c_{p,m}}{R_m}
\right]
\tag{3}
```

となる．

通常の温度域における空気と水蒸気の比熱・比気体定数は，およそ

```math
\frac{c_{p,v}}{R_v}
\simeq
\frac{1.86}{0.4615}
>
\frac{1.005}{0.287}
\simeq
\frac{c_{p,a}}{R_a}
```

である．
ここで比熱と比気体定数の数値の単位は，いずれも $\mathrm{kJ/(kg\,K)}$ である．

また，

```math
\frac{c_{p,m}}{R_m}
=
\frac{
Y_aR_a(c_{p,a}/R_a)
+
Y_vR_v(c_{p,v}/R_v)
}{
Y_aR_a+Y_vR_v
}
```

であるから， $c_{p,m}/R_m$ は $c_{p,a}/R_a$ と $c_{p,v}/R_v$ の加重平均である．
したがって，

```math
\frac{c_{p,m}}{R_m}
\leq
\frac{c_{p,v}}{R_v}
```

が成り立つ．
さらに，問題の条件 $c<0$ より，

```math
\frac{c_{p,v}-c}{R_v}
>
\frac{c_{p,v}}{R_v}
\geq
\frac{c_{p,m}}{R_m}
```

となる．
よって式 (3) から，

```math
\boxed{
\left.\frac{dp_s}{dT}\right|_A
>
\left.\left(\frac{dp_v}{dT}\right)_{s_m}\right|_A
}
```

が得られる．

すなわち， $p-T$ 面では，初期状態 $A$ において飽和水蒸気圧曲線の傾きが混合気体の可逆断熱線の傾きより大きい．
この傾きの比較から，状態 $A$ の近傍で温度を下げると，水蒸気の分圧 $p_v$ は飽和水蒸気圧 $p_s(T)$ より大きくなる方向に変化することが分かる．

ただし，この傾きの比較だけで有限の温度変化に対する結論までは得られないため，次に積分によって確認する．

### 4．有限の温度変化と過飽和の条件

まず，可逆断熱膨張によって温度が $T_A$ から $T_D$ まで低下した場合を考える．
混合気体のエントロピー変化がゼロであることから，

```math
\ln\frac{p_{v,D}}{p_{v,A}}
=
-\int_{T_D}^{T_A}
\frac{c_{p,m}}{R_m}\frac{dT}{T}
```

である．
一方，式 (1) より，

```math
\ln\frac{p_s(T_D)}{p_s(T_A)}
=
-\int_{T_D}^{T_A}
\frac{c_{p,v}-c}{R_v}\frac{dT}{T}
```

となる．
初期状態では $p_{v,A}=p_s(T_A)$ なので，両式を差し引くと，

```math
\boxed{
\ln\frac{p_{v,D}}{p_s(T_D)}
=
\int_{T_D}^{T_A}
\left[
\frac{c_{p,v}-c}{R_v}
-
\frac{c_{p,m}}{R_m}
\right]\frac{dT}{T}
}
\tag{4}
```

を得る．

膨張中の温度範囲で $c<0$ が保たれ，空気と水蒸気について前述の比熱・比気体定数の大小関係が成り立つなら，式 (4) の被積分関数は正である．
したがって，

```math
\ln\frac{p_{v,D}}{p_s(T_D)}>0
```

すなわち，

```math
\boxed{p_{v,D}>p_s(T_D)}
```

となる．
よって，可逆断熱膨張の理想化の下では，有限の温度低下の後に水蒸気は過飽和状態になる．

次に，不可逆な断熱膨張の場合を考える．
霧箱内の気体を閉じた系とし，単位質量当たりのエントロピー生成量を $s_{\mathrm{gen}}\geq0$ とする．
断熱条件の下ではエントロピー収支より，

```math
s_{m,D}-s_{m,A}=s_{\mathrm{gen}}
```

である．
組成一定の理想気体混合物について，

```math
ds_m
=
\frac{c_{p,m}}{T}\,dT
-
R_m\,d\ln P
```

なので，初期状態から最終状態まで積分すると，

```math
\ln\frac{P_D}{P_A}
=
-\int_{T_D}^{T_A}
\frac{c_{p,m}}{R_m}\frac{dT}{T}
-
\frac{s_{\mathrm{gen}}}{R_m}
```

を得る．
また，水蒸気のモル分率は一定なので，

```math
\ln\frac{p_{v,D}}{p_{v,A}}
=
\ln\frac{P_D}{P_A}
```

である．
これと飽和水蒸気圧の積分式を用いれば，

```math
\boxed{
\ln\frac{p_{v,D}}{p_s(T_D)}
=
\int_{T_D}^{T_A}
\left[
\frac{c_{p,v}-c}{R_v}
-
\frac{c_{p,m}}{R_m}
\right]\frac{dT}{T}
-
\frac{s_{\mathrm{gen}}}{R_m}
}
\tag{5}
```

となる．

したがって，不可逆な断熱膨張で過飽和になるための条件は，

```math
\boxed{
s_{\mathrm{gen}}
<
R_m
\int_{T_D}^{T_A}
\left[
\frac{c_{p,v}-c}{R_v}
-
\frac{c_{p,m}}{R_m}
\right]\frac{dT}{T}
}
\tag{6}
```

である．
等号の場合は最終状態が飽和状態となり，左辺が右辺より大きい場合には，このモデルでは過飽和にならない．
可逆断熱膨張は $s_{\mathrm{gen}}=0$ の場合であるから，式 (4) のとおり過飽和が生じる．

ここで重要なのは，急速な膨張であること自体は熱交換を小さくする条件であり，エントロピー生成量を決める条件ではないことである．
したがって，実際の霧箱で過飽和が生じるためには，膨張中のエントロピー生成量が式 (6) の上限より小さくなければならない．
問題の意図する理想化では，可逆断熱膨張，またはそれに十分近い膨張を考えることで，この条件を満たす．

### 5．Wilson の霧箱で霧が生じる理由

以上より，可逆断熱膨張の理想化，または式 (6) を満たす十分に小さなエントロピー生成を伴う断熱膨張では，飽和水蒸気圧曲線と混合気体の断熱線との傾きの違いによって，水蒸気の分圧がその温度における飽和水蒸気圧を上回り，過飽和状態になる．

ただし，過飽和になっただけで必ず直ちに液滴が生じるわけではなく，凝結には核となるものが必要である．
Wilson の霧箱では，放射線の通過によって気体中に生じたイオンが凝結核となる．
水蒸気がこれらのイオンに凝結して微小な液滴を形成し，その液滴が光を散乱することで，放射線の通過した経路が飛跡として観察される．

したがって，飽和水蒸気の比熱 $c$ が負であることは，飽和水蒸気圧曲線の傾きを混合気体の断熱線の傾きより大きくし，理想化された断熱膨張，またはエントロピー生成が十分小さい断熱膨張のもとで過飽和を生じさせる原因となる．
