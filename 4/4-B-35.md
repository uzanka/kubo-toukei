# 演習問題【4-B-35】

## 解答

下の図で実線 AB を飽和蒸気圧曲線とする．
飽和蒸気の比熱 $c$ が負であることを利用し，Wilson の霧箱で過飽和蒸気がどのように形成されるかを解答例の構成に沿って説明する．
なお以下の議論では，水蒸気を理想気体近似し，膨張過程を準静的な等エントロピー過程とみなす．
また，凝結核が存在しない場合にのみ過飽和状態が維持されることを前提とする．

### 1. 飽和比熱 $c$ と定圧比熱 $c_p$ の区別

まず明確にしておくべきは，二つの「比熱」の違いである．

**飽和水蒸気の比熱 $c$** は，**飽和曲線に沿った過程** での比熱であって，

$$c = T \left(\frac{ds}{dT}\right)_{\text{sat}}$$

と定義される．
ここで $s$ は飽和線上のエントロピーであり，$(ds/dT)_{\text{sat}}$ は飽和曲線に沿ったエントロピーの温度変化率である．
問題[33]で与えられている「負になる比熱」とはこれのことである．

一方，**定圧比熱 $c_p$** は，圧力を一定に保った過程での比熱であり，

$$c_p = T \left(\frac{\partial s}{\partial T}\right)_p$$

で定義される．
実在する物質では常に $c_p > 0$ である（水蒸気の場合，約 $40.5\ \text{J}/(\text{mol}\cdot\text{K})$ ）．

この二つは一般に等しくない．
エントロピーを $s(T, p)$ の関数と見て飽和曲線 $p = p_s(T)$ を沿って $T$ で微分すると，

$$\frac{ds}{dT} = \left(\frac{\partial s}{\partial T}\right)_p + \left(\frac{\partial s}{\partial p}\right)_T \frac{dp_s}{dT}$$

マクスウェル関係式 $(\partial s/\partial p)_T = -(\partial v/\partial T)_p$ を用いると，

$$\frac{ds}{dT} = \frac{c_p}{T} - \left(\frac{\partial v}{\partial T}\right)_p \frac{dp_s}{dT}$$

理想気体近似 $v = RT/p_s$ を代入して両辺に $T$ を掛けると，

$$c = c_p - \frac{RT}{p_s} \frac{dp_s}{dT}$$

Clapeyron-Clausius の式 $dp_s/dT = L/[T(v_g - v_l)] > 0$ より第2項は正である．
この絶対値が $c_p$ より大きいとき **$c < 0$** となる（問題[33]で示されている）．
つまり「飽和比熱が負」であっても「定圧比熱が負」ではない．

### 2. 解答例の構成：A, B, C の3状態

解答例の議論に従い，p-T 面上に3状態 A, B, C を設定する．

**状態 A**:
飽和曲線上の点，温度 $T_A$ ，圧力 $p_A = p_s(T_A)$ ．
飽和水蒸気．

**状態 B**:
飽和曲線上の点，温度 $T_B$（ $T_B > T_A$ ），圧力 $p_B = p_s(T_B)$ ．
飽和水蒸気．

$c < 0$ より，飽和曲線上では温度が上がるとエントロピーが減少する．
したがって，

$$s_A > s_B \qquad\cdots(1)$$

**状態 C**:
B と同じ温度 $T_B$ の等温線上の点で，圧力 $p_C$ を調節して $s_C = s_A$ とした状態．
$(\partial s/\partial p)_T < 0$ より，圧力を下げる方向に進むとエントロピーが増すから，B から圧力を下げて $s = s_A$ となる C が存在する．

ここで重要な比較を行う．
飽和曲線上の任意の点において，等エントロピー線（ $s = \text{一定}$ ）の勾配 $(\partial p/\partial T)_s$ と飽和蒸気圧曲線の勾配 $dp_s/dT$ を比較する．
理想気体近似では，

$$\left(\frac{\partial p}{\partial T}\right)_{s} = \frac{c_p}{R} \frac{p}{T} \qquad\cdots(2)$$

一方，(1) の $c < c_p$ を変形すると，

$$c_p - c = \frac{RT}{p_s}\frac{dp_s}{dT} > c_p \qquad\cdots(3)$$

状態 A において $p = p_s$ であるから，(2), (3) より，

$$\left(\frac{\partial p}{\partial T}\right)_{s}\Big|_A = \frac{c_p}{R} \frac{p_s}{T} < \frac{c_p - c}{R} \frac{p_s}{T} = \frac{dp_s}{dT}\Big|_A$$

つまり，**等エントロピー線は飽和蒸気圧曲線よりも傾斜が緩い** ．

### 3. 断熱膨張と過飽和状態の到達

Wilson の霧箱において，飽和水蒸気 A を急に膨張させる．
この過程は速いため断熱（等エントロピー）過程とみなせる．
状態 A から始まる変化は等エントロピー線 $s = s_A$ に沿って進む．

第2段階で見たように，等エントロピー線は飽和蒸気圧曲線よりも傾斜が緩い．
膨張によって圧力と温度がともに下がるとき（ $\Delta T < 0, \Delta p < 0$ ），緩やかな勾配のため，状態は飽和曲線の「内側」に残る（図では左側に位置する）．

具体的には，同じ温度降下 $\Delta T < 0$ に対して，

$$\Delta p_{\text{isentropic}} = \left(\frac{\partial p}{\partial T}\right)_{s} \Delta T > \frac{dp_s}{dT} \Delta T = p_{\text{sat}}(T_D) - p_A$$

（ $\Delta T < 0$ なので不等号の向きが反転する）．
よって，膨張後の状態 D $(T_D, p_D)$ において，

$$p_D > p_{\text{sat}}(T_D)$$

この不等式は，水蒸気の分圧 $p_D$ が現在の温度 $T_D$ での飽和蒸気圧 $p_s(T_D)$ を上回っていることを意味する．
この状態を **過飽和水蒸気** と呼ぶ．
本来ならば凝結して液相になるはずのところ，凝結核がないため液相への転移ができず，一時的に気相のまま留まっている．

### 4. Wilson の霧箱の原理：なぜ $c < 0$ が重要か

過飽和が生じる本質的な理由は，**飽和曲線と等エントロピー線の傾きの違い** にある．
この違いをもたらす原因は $c < 0$ である．

もし $c \geq 0$ ならば，(3) の不等号の向きが逆（あるいは等号）となり，両者の勾配関係も変わる．
その場合，断熱膨張後も過飽和にはならない可能性がある．
実際， $c < 0$ が成り立つ条件は，凝縮に伴うlatent heat の放出が大きい場合に生じ，Wilson の霧箱で過飽和を実現できるための本質的な条件なのである．

過飽和状態そのものでは液滴は生じない．
しかし，放射線が霧箱を通り抜けると，その軌跡に沿ってイオンが生じる（問題[49]参照）．
これらのイオンが凝結核として働き，過飽和水蒸気が急速に凝縮して霧粒子となる．
まさにこれが Wilson の霧箱の基本原理であり，荷電粒子の軌跡を目に見える形にするものである．

## 解説

### 解答例との対応

解答例の議論を整理すると：
- A, B を飽和線上で $T_A < T_B$ とし，$c < 0$ より $s_A > s_B$
- B から等温膨張して $s = s_A$ となる C を取る
- 等エントロピー線 AC は飽和曲線 AB より傾斜が緩い
- 断熱膨張では A →（等エントロピー線上の点）へ移動し，飽和曲線の左側に入る

上記解答はこの流れを厳密に追って， $c$ と $c_p$ の区別，Clapeyron-Clausius の式の活用，過飽和条件 $p > p_{\text{sat}}(T)$ の明示を行った．
