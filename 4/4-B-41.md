# 演習問題【4-B-41】

## 解答

### 導出プロセス

本問題では，半透膜を隔てた2つの相（相Iおよび相II）の間におけるイオンの平衡状態を考える．
このとき，イオンの移動を支配するのは化学ポテンシャルだけでなく，電荷による電気的な影響も加わった「電気化学ポテンシャル」である．

#### 1. 電気化学ポテンシャルの定義

各相におけるイオンの電気化学ポテンシャル $\eta$ は，化学ポテンシャル $\mu$ と静電ポテンシャル $\Phi$ を用いて次のように定義される：

$$\eta = \mu + ze\Phi$$

ここで， $z$ はイオンの電荷数， $e$ は電気素量である．

本問で扱うイオンについて，電荷数 $z$ は以下の通りである：
- カチオン $\mathrm{M}^+$： $z = +1$
- アニオン $\mathrm{X}^-$： $z = -1$

したがって，相I（静電位 $\Phi_{\mathrm{I}}$ ）と相II（静電位 $\Phi_{\mathrm{II}}$ ）におけるそれぞれの電気化学ポテンシャルは次のように書ける：

**相Iにおける電気化学ポテンシャル:**

$$\eta'_{\mathrm{M}+} = \mu'_{\mathrm{M}+} + e\Phi_{\mathrm{I}}$$

$$\eta'_{\mathrm{X}-} = \mu'_{\mathrm{X}-} - e\Phi_{\mathrm{I}}$$

**相IIにおける電気化学ポテンシャル:**

$$\eta''_{\mathrm{M}+} = \mu''_{\mathrm{M}+} + e\Phi_{\mathrm{II}}$$

$$\eta''_{\mathrm{X}-} = \mu''_{\mathrm{X}-} - e\Phi_{\mathrm{II}}$$

#### 2. 平衡条件の設定

系が熱力学的平衡状態にあるとき，各成分（イオン）の電気化学ポテンシャルは，膜の両側で等しくなければならない．
すなわち，以下の平衡条件が成り立つ：

$$\eta'_{\mathrm{M}+} = \eta''_{\mathrm{M}+} \quad \text{および} \quad \eta'_{\mathrm{X}-} = \eta''_{\mathrm{X}-}$$

これらの条件に先ほどの定義式を代入する：

**カチオン $\mathrm{M}^+$ について:**

$$\mu'_{\mathrm{M}+} + e\Phi_{\mathrm{I}} = \mu''_{\mathrm{M}+} + e\Phi_{\mathrm{II}}$$

$$\mu'_{\mathrm{M}+} - \mu''_{\mathrm{M}+} = -e(\Phi_{\mathrm{I}} - \Phi_{\mathrm{II}}) \quad \cdots (\text{A})$$

**アニオン $\mathrm{X}^-$ について:**

$$\mu'_{\mathrm{X}-} - e\Phi_{\mathrm{I}} = \mu''_{\mathrm{X}-} - e\Phi_{\mathrm{II}}$$

$$\mu'_{\mathrm{X}-} - \mu''_{\mathrm{X}-} = e(\Phi_{\mathrm{I}} - \Phi_{\mathrm{II}}) \quad \cdots (\text{B})$$

#### 3. 化学ポテンシャルと濃度の関係

化学ポテンシャル $\mu$ とモル分率（あるいは濃度） $x$ の間には，次のような関係がある：

$$\mu = \mu^0 + kT \ln x$$

ここで， $k$ はボルツマン定数， $T$ は絶対温度である．

これを用いると，両相間の化学ポテンシャルの差は，濃度の比を用いて次のように表せる：

$$\mu' - \mu'' = (\mu^0 + kT \ln x') - (\mu^0 + kT \ln x'') = kT \ln \left( \frac{x'}{x''} \right)$$

#### 4. 式の結合と導出

式(A)および(B)にこの関係を適用する：

**カチオン $\mathrm{M}^+$ について:**

$$kT \ln \left( \frac{x'_{\mathrm{M}+}}{x''_{\mathrm{M}+}} \right) = -e(\Phi_{\mathrm{I}} - \Phi_{\mathrm{II}})$$

$$\frac{x'_{\mathrm{M}+}}{x''_{\mathrm{M}+}} = \exp \left( -\frac{e(\Phi_{\mathrm{I}} - \Phi_{\mathrm{II}})}{kT} \right) \quad \cdots (1)$$

**アニオン $\mathrm{X}^-$ について:**

$$kT \ln \left( \frac{x'_{\mathrm{X}-}}{x''_{\mathrm{X}-}} \right) = e(\Phi_{\mathrm{I}} - \Phi_{\mathrm{II}})$$

$$\frac{x'_{\mathrm{X}-}}{x''_{\mathrm{X}-}} = \exp \left( \frac{e(\Phi_{\mathrm{I}} - \Phi_{\mathrm{II}})}{kT} \right) \quad \cdots (2)$$

これらは解答例に示された式(1)と一致する．

次に，アニオン $\mathrm{X}^-$ についての式(2)を $\Phi_{\mathrm{I}} - \Phi_{\mathrm{II}}$ について解く：

$$\ln \left( \frac{x'_{\mathrm{X}-}}{x''_{\mathrm{X}-}} \right) = \frac{e(\Phi_{\mathrm{I}} - \Phi_{\mathrm{II}})}{kT}$$

$$\Phi_{\mathrm{I}} - \Phi_{\mathrm{II}} = \frac{kT}{e} \ln \left( \frac{x'_{\mathrm{X}-}}{x''_{\mathrm{X}-}} \right)$$

ここで，前問の結果より $\frac{x'_{\mathrm{X}-}}{x''_{\mathrm{X}-}} = 1 + \frac{x_2^0}{x_1^0}$ であることを用いると，最終的な式が得られる：

$$\Phi_{\mathrm{I}} - \Phi_{\mathrm{II}} = \frac{kT}{e} \ln \left( 1 + \frac{x_2^0}{x_1^0} \right)$$

## 解説

### 電気化学ポテンシャルとは？

物質が移動しようとする力は，単に「濃度が高い方から低い方へ」という化学的な力（化学ポテンシャル）だけでなく，電荷を持つ粒子が「電位の低い方から高い方へ」と引き寄せられる電気的な力も合わさっている．
この両方の効果を統合したものが**電気化学ポテンシャル**である．

### なぜ平衡状態では電位差が生じるのか？

半透膜によってイオンの移動が制限されている場合，濃度差が生じるとイオンが移動しようとする．
しかし，イオンが移動すると，電荷の偏りによって電位差（電圧）が生じる．
この電位差による「電気的な押し戻す力」が，濃度差による「化学的な進もうとする力」と釣り合ったとき，イオンの正味の移動が止まる．
これが平衡状態である．

本問で導出した式は，この「濃度差（ $x_2^0/x_1^0$ ）」と「生じている電位差（ $\Phi_{\mathrm{I}} - \Phi_{\mathrm{II}}$ ）」が，熱エネルギー（ $kT$ ）を介してどのように結びついているかを示している．
