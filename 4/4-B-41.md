# 演習問題【4-B-41】

## 解答

### 1．電気化学ポテンシャルを定義する

前問と同様に，半透膜で仕切られたI室とII室を考える．
$\mathrm{M^+}$ と $\mathrm{X^-}$ は膜を通過できるが， $\mathrm{R^-}$ は通過できない．

I室とII室の静電位をそれぞれ $\Phi_{\mathrm I}$ ， $\Phi\_{\mathrm{II}}$ とする．イオンの電気化学ポテンシャル $\eta$ は，化学ポテンシャル $\mu$ と電気的な位置エネルギーの和であり，

```math
\boxed{
\eta=\mu+ze\Phi
}
\tag{1}
```

と定義される．
ここで， $z$ はイオンの電荷数， $e$ は電気素量， $\Phi$ は静電位である．

$\mathrm{M^+}$ は電荷数 $z=+1$ ， $\mathrm{X^-}$ は電荷数 $z=-1$ である．
したがって，各室での電気化学ポテンシャルは，

```math
\begin{aligned}
\eta'_{\mathrm{M^+}} &=\mu'_{\mathrm{M^+}}+e\Phi_{\mathrm I},\\
\eta'_{\mathrm{X^-}} &=\mu'_{\mathrm{X^-}}-e\Phi_{\mathrm I},\\
\eta''_{\mathrm{M^+}} &=\mu''_{\mathrm{M^+}}+e\Phi_{\mathrm{II}},\\
\eta''_{\mathrm{X^-}} &=\mu''_{\mathrm{X^-}}-e\Phi_{\mathrm{II}}
\end{aligned}
\tag{2}
```

となる．
プライムはI室，ダブルプライムはII室を表す．

### 2．平衡条件を立てる

熱力学的平衡では，膜を通過できる各イオンについて，膜の両側の電気化学ポテンシャルが等しくなる．
したがって，

```math
\eta'_{\mathrm{M^+}}=\eta''_{\mathrm{M^+}}, \qquad \eta'_{\mathrm{X^-}}=\eta''_{\mathrm{X^-}}
\tag{3}
```

である．

まず，正イオン $\mathrm{M^+}$ について式（2），（3）を用いると，

```math
\mu'_{\mathrm{M^+}}+e\Phi_{\mathrm I} =\mu''_{\mathrm{M^+}}+e\Phi_{\mathrm{II}}
```

となる．
よって，

```math
\mu'_{\mathrm{M^+}}-\mu''_{\mathrm{M^+}} =-e(\Phi_{\mathrm I}-\Phi_{\mathrm{II}})
\tag{4}
```

を得る．

次に，負イオン $\mathrm{X^-}$ については，

```math
\mu'_{\mathrm{X^-}}-e\Phi_{\mathrm I} =\mu''_{\mathrm{X^-}}-e\Phi_{\mathrm{II}}
```

であるから，

```math
\mu'_{\mathrm{X^-}}-\mu''_{\mathrm{X^-}} =e(\Phi_{\mathrm I}-\Phi_{\mathrm{II}})
\tag{5}
```

となる．
ここでは電荷数が $(-1$ であるため，式（4）と電位差の項の符号が逆になる．

### 3．化学ポテンシャルを濃度で表す

理想希薄溶液では，イオンの化学ポテンシャルは活動度 $a$ を用いて，

```math
\mu=\mu^0+k_{\mathrm B}T\ln a
\tag{6}
```

と書ける．
ここで， $k_{\mathrm B}$ はボルツマン定数， $T$ は絶対温度である．
理想希薄溶液では活動度は濃度に比例するため，同じイオンについて両室の化学ポテンシャルの差をとると，

```math
\boxed{
\mu'-\mu'' =k_{\mathrm B}T\ln\frac{x'}{x''}
}
\tag{7}
```

となる．
ここで $x'$ ， $x''$ は，それぞれI室とII室におけるそのイオンの濃度である．
同じイオンの濃度比をとるため，比例定数や基準濃度は相殺される．

式（7）を正イオンの平衡条件（4）に代入すると，

```math
k_{\mathrm B}T \ln\frac{x'_{\mathrm{M^+}}}{x''_{\mathrm{M^+}}} =-e(\Phi_{\mathrm I}-\Phi_{\mathrm{II}})
```

である．
したがって，

```math
\boxed{
\frac{x'_{\mathrm{M^+}}}{x''_{\mathrm{M^+}}} =\exp\left[ -\frac{e(\Phi_{\mathrm I}-\Phi_{\mathrm{II}})} {k_{\mathrm B}T} \right]
}
\tag{8}
```

を得る．
同様に，負イオンの平衡条件（5）から，

```math
k_{\mathrm B}T \ln\frac{x'_{\mathrm{X^-}}}{x''_{\mathrm{X^-}}} =e(\Phi_{\mathrm I}-\Phi_{\mathrm{II}})
```

となり，

```math
\boxed{
\frac{x'_{\mathrm{X^-}}}{x''_{\mathrm{X^-}}} =\exp\left[ \frac{e(\Phi_{\mathrm I}-\Phi_{\mathrm{II}})} {k_{\mathrm B}T} \right]
}
\tag{9}
```

を得る．

### 4．前問の結果を代入して電位差を求める

式（9）の両辺の自然対数をとると，

```math
\ln\frac{x'_{\mathrm{X^-}}}{x''_{\mathrm{X^-}}} =\frac{e(\Phi_{\mathrm I}-\Phi_{\mathrm{II}})} {k_{\mathrm B}T}
```

である．
これを電位差について解けば，

```math
\boxed{
\Phi_{\mathrm I}-\Phi_{\mathrm{II}} =\frac{k_{\mathrm B}T}{e} \ln\frac{x'_{\mathrm{X^-}}}{x''_{\mathrm{X^-}}}
}
\tag{10}
```

となる．

前問で求めた濃度は，

```math
x'_{\mathrm{X^-}} =x_1' =\frac{x_1^0(x_1^0+x_2^0)} {2x_1^0+x_2^0}
```

および

```math
x''_{\mathrm{X^-}} =x_1'' =\frac{(x_1^0)^2} {2x_1^0+x_2^0}
```

であった．
したがって，

```math
\frac{x'_{\mathrm{X^-}}}{x''_{\mathrm{X^-}}} =\frac{x_1^0+x_2^0}{x_1^0} =1+\frac{x_2^0}{x_1^0}
\tag{11}
```

となる．
これを式（10）に代入すると，求める電位差は，

```math
\boxed{
\Phi_{\mathrm I}-\Phi_{\mathrm{II}} =\frac{k_{\mathrm B}T}{e} \ln\left(1+\frac{x_2^0}{x_1^0}\right)
}
\tag{12}
```

である．

## 3．結論と物理的な意味

求める電位差は，

```math
\boxed{
\displaystyle \Phi_{\mathrm I}-\Phi_{\mathrm{II}} =\frac{k_{\mathrm B}T}{e} \ln\left(1+\frac{x_2^0}{x_1^0}\right)
}
```

である．
$x_1^0>0$ ， $x_2^0>0$ ならば対数の中身は1より大きいため，

```math
\Phi_{\mathrm I}>\Phi_{\mathrm{II}}
```

となる．
つまり，この条件ではI室の静電位がII室より高い．

この電位差は，イオンの濃度差だけで生じるのではなく，膜を通過できない $\mathrm{R^-}$ の存在と，電気的中性を維持しながら膜を通過できるイオンが再分配されることによって生じる．
濃度差による化学的な駆動力と電気的な駆動力が釣り合った状態が Donnan 膜平衡である．
