# 演習問題【4-A-11】

## 解答

### 1．Gibbs–Duhem の関係式

混合気体の各成分の化学ポテンシャルを $\mu_i$ ，モル数を $n_i$ とする．
ギブスエネルギー $G$ は容量性の量であるため，

```math
G=\sum_{i=1}^{c}n_i\mu_i
\tag{1}
```

と表される．
この式を全微分すると，

```math
dG=\sum_{i=1}^{c}\mu_i\,dn_i
+\sum_{i=1}^{c}n_i\,d\mu_i
\tag{2}
```

となる．
一方，熱力学の基本関係式より，

```math
dG=-S\,dT+V\,dp
+\sum_{i=1}^{c}\mu_i\,dn_i
\tag{3}
```

である．
ここで， $S$ はエントロピー， $V$ は体積である．

圧力 $p$ と温度 $T$ を一定に保つと， $dp=dT=0$ となるため，式 (3) は

```math
dG=\sum_{i=1}^{c}\mu_i\,dn_i
```

となる．
これを式 (2) と比較すると，

```math
\boxed{
\sum_{i=1}^{c}n_i\,d\mu_i=0
}
\tag{4}
```

を得る．
これが一定の圧力と温度のもとで成り立つ Gibbs–Duhem の関係式である．

### 2．部分圧についての関係式

混合気体の全圧を $p$ ，成分 $i$ のモル分率を $x_i$ とすると，

```math
x_i=\frac{n_i}{\sum_{j=1}^{c}n_j}
```

である．
成分 $i$ の部分圧 $p_i$ は，

```math
p_i=px_i
=p\frac{n_i}{\sum_{j=1}^{c}n_j}
\tag{5}
```

と表される．

式 (5) の両辺の対数をとると，

```math
\log p_i
=\log p+\log n_i
-\log\left(\sum_{j=1}^{c}n_j\right)
```

となる．
ここで，圧力 $p$ は一定であるから，両辺を微分すると，

```math
d\log p_i
=\frac{dn_i}{n_i}
-\frac{\sum_{j=1}^{c}dn_j}
{\sum_{j=1}^{c}n_j}
\tag{6}
```

を得る．

式 (6) の両辺に $n_i$ を掛け，成分 $i$ について総和をとると，

```math
\begin{aligned}
\sum_{i=1}^{c}n_i\,d\log p_i
&=\sum_{i=1}^{c}dn_i\\
&\quad-\sum_{i=1}^{c}n_i
\frac{\sum_{j=1}^{c}dn_j}
{\sum_{j=1}^{c}n_j}
\end{aligned}
```

となる．
第2項では，分数の部分が $i$ に依存しないため，総和の外に取り出すことができる．
したがって，

```math
\begin{aligned}
\sum_{i=1}^{c}n_i\,d\log p_i
&=\sum_{i=1}^{c}dn_i\\
&\quad-\frac{\sum_{i=1}^{c}n_i}
{\sum_{j=1}^{c}n_j}
\sum_{j=1}^{c}dn_j\\
&=\sum_{i=1}^{c}dn_i-\sum_{j=1}^{c}dn_j\\
&=0
\end{aligned}
```

となる．
よって，

```math
\boxed{
\sum_{i=1}^{c}n_i\,d\log p_i=0
}
\tag{7}
```

が示された．

### 3．逃散係数の関係式を導く

実在気体の化学ポテンシャルは，逃散 $f_i$ を用いて，

```math
\mu_i=\mu_i^\circ(T)
+RT\log\left(\frac{f_i}{p^\circ}\right)
\tag{8}
```

と表される．
ここで， $\mu_i^\circ(T)$ は標準状態の化学ポテンシャル， $R$ は気体定数， $T$ は絶対温度， $p^\circ$ は標準圧力である．
逃散 $f_i$ と部分圧 $p_i$ の間には，

```math
f_i=\nu_i p_i
\tag{9}
```

という関係がある．
ここで， $\nu_i$ は成分 $i$ の逃散係数である．

式 (9) を式 (8) に代入すると，

```math
\mu_i=\mu_i^\circ(T)
+RT\log\left(\frac{\nu_i p_i}{p^\circ}\right)
```

となる．
対数の性質を用いて整理すると，

```math
\mu_i=\mu_i^\circ(T)
+RT\left(\log\nu_i+\log p_i-\log p^\circ\right)
\tag{10}
```

である．

ここで，温度 $T$ は一定であるため， $\mu_i^\circ(T)$ は一定であり， $RT$ も定数である．
また，標準圧力 $p^\circ$ も定数である．
したがって，式 (10) を微分すると，

```math
\boxed{
d\mu_i=RT\left(d\log\nu_i+d\log p_i\right)
}
\tag{11}
```

を得る．

式 (11) を式 (4) の Gibbs–Duhem の関係式に代入すると，

```math
\sum_{i=1}^{c}
n_iRT\left(d\log\nu_i+d\log p_i\right)=0
```

となる．
$RT$ はゼロでない定数であるため，両辺を $RT$ で割ると，

```math
\sum_{i=1}^{c}n_i\,d\log\nu_i
+\sum_{i=1}^{c}n_i\,d\log p_i=0
\tag{12}
```

を得る．

式 (7) より，

```math
\sum_{i=1}^{c}n_i\,d\log p_i=0
```

であるから，これを式 (12) に代入すると，

```math
\sum_{i=1}^{c}n_i\,d\log\nu_i+0=0
```

となる．
したがって，

```math
\boxed{
\displaystyle
\sum_{i=1}^{c}n_i\,d\log\nu_i=0
}
```

が得られる．
以上により，題意の関係式が示された．
