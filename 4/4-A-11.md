# 演習問題【4-A-11】

## 解答

本問題は，混合気体の各成分の逃散係数（fugacity coefficient） $\nu_i$ が，一定の圧力 $p$ と温度 $T$ の下で満たすべき関係式を導出するものである．

### 1. 基礎となる物理量の定義

まず，熱力学的な基礎となる概念を整理する．

- **化学ポテンシャル $\mu_i$**:
  混合物中の成分 $i$ が持つ，化学的なエネルギーの状態を表す量である．
- **逃散（fugacity） $f_i$**:
  理想気体からのずれを考慮した，実在気体の「有効な圧力」のような量である．
  一般に，成分 $i$ の化学ポテンシャル $\mu_i$ は，逃散 $f_i$ を用いて次のように書ける：
  $$\mu_i = \mu_i^\circ(T) + RT \ln \left( \frac{f_i}{p^\circ} \right)$$
  ここで， $\mu_i^\circ(T)$ は標準状態における化学ポテンシャル， $R$ は気体定数， $T$ は絶対温度， $p^\circ$ は標準圧力である．

問題文では，逃散係数 $\nu_i$ が与えられている．
逃散 $f_i$ と部分圧 $p_i$ の関係は， $f_i = \nu_i p_i$ と表される．
これを用いると，化学ポテンシャルは次のように書き換えられる：

$$\mu_i = \mu_i^\circ(T) + RT \ln \left( \frac{\nu_i p_i}{p^\circ} \right)$$

### 2. Gibbs-Duhem（ギブス・デュエム）の関係式

熱力学において，一定の温度 $T$ と圧力 $p$ の条件下では，混合物を構成する各成分の化学ポテンシャルの変化量 $d\mu_i$ は，互いに独立ではなく，以下の**Gibbs-Duhemの関係式**を満たすことが知られている：

$$\sum_{i=1}^{c} n_i \, d\mu_i = 0 \quad \cdots (1)$$

ここで， $n_i$ は成分 $i$ のモル数である．

### 3. 式の導出

化学ポテンシャルの式 $\mu_i = \mu_i^\circ(T) + RT \ln \left( \frac{\nu_i p_i}{p^\circ} \right)$ の両辺の微分をとる．
温度 $T$ が一定であるため， $\mu_i^\circ(T)$ は定数となり，その微分は $0$ となる．
また， $R$ と $p^\circ$ も定数である．

$$d\mu_i = d \left[ \mu_i^\circ(T) + RT \ln \left( \frac{\nu_i p_i}{p^\circ} \right) \right]$$

$$d\mu_i = 0 + RT \, d \left[ \ln \nu_i + \ln p_i - \ln p^\circ \right]$$

$$d\mu_i = RT (d \ln \nu_i + d \ln p_i)$$

ここで， $\ln x$ の微分は $d \ln x = \frac{1}{x} dx = d \log x$ であることを利用すると：

$$d\mu_i = RT (d \log \nu_i + d \log p_i) \quad \cdots (2)$$

次に，この式 $(2)$ を Gibbs-Duhem の関係式 $(1)$ に代入する：

$$\sum_{i=1}^{c} n_i \left[ RT (d \log \nu_i + d \log p_i) \right] = 0$$

$RT$ は定数であり，かつ $0$ ではないため，両辺を $RT$ で割ることができる：

$$\sum_{i=1}^{c} n_i (d \log \nu_i + d \log p_i) = 0$$

$$\sum_{i=1}^{c} n_i \, d \log \nu_i + \sum_{i=1}^{c} n_i \, d \log p_i = 0 \quad \cdots (3)$$

ここで，理想混合気体における部分圧 $p_i$ の性質を考える．
全圧 $p$ と全モル数 $n_{total} = \sum n_i$ が一定であるとき，各成分の部分圧は $p_i = p \frac{n_i}{\sum n_j}$ と表される．
このとき， $\sum n_i d \log p_i = 0$ が成り立つ（これは解答例でも示されている性質である）．

したがって，式 $(3)$ において $\sum n_i d \log p_i = 0$ を適用すると：

$$\sum_{i=1}^{c} n_i \, d \log \nu_i + 0 = 0$$
$$\sum_{i=1}^{c} n_i \, d \log \nu_i = 0$$

以上により，題意の関係式が示された．

## 解説

この問題は，実在気体の挙動を記述する「逃散（fugacity）」という概念と，熱力学の基本的な制約条件である「Gibbs-Duhemの関係式」を結びつけるものである．

1.  **なぜこのような関係が必要なのか？**
    熱力学では，系の状態（温度，圧力，組成など）が決まれば，その系のエネルギー的な性質（化学ポテンシャルなど）も一意に決まる必要がある．
    しかし，混合物の各成分の化学ポテンシャル $\mu_i$ を，成分の数だけバラバラに自由に変化させることはできない．
    Gibbs-Duhemの関係式は，「成分が増えたら，その分，他の成分の化学ポテンシャルはどう変化しなければならないか」という整合性を保証している．

2.  **逃散係数 $\nu_i$ の役割**
    理想気体では，分子間の相互作用がないため，化学ポテンシャルは単純に圧力 $\ln p_i$ に依存する．
    しかし，実際の気体では分子同士が引き合ったり反発したりするため，理想的な圧力 $p_i$ に修正係数 $\nu_i$ を掛けた「逃散 $f_i = \nu_i p_i$」を用いることで，理想気体の公式をそのまま使えるようにしている．

3.  **物理的な意味**
    導出された $\sum n_i d \log \nu_i = 0$ という式は，「一定の圧力と温度の下では，各成分の逃散係数の変化は，成分のモル数で重み付けして合計するとゼロにならなければならない」ということを意味している．
    これは，実在気体の相互作用による「理想からのずれ」も，熱力学的な整合性を保った形で変化しなければならないことを示している．
