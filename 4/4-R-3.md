# 例題【4-R-3】

## 解答

### 1．表面の Helmholtz 自由エネルギーの定義

二つの相が熱平衡にあり，その間に明確な境界面が存在する系を考える．
系全体を，境界面から十分に離れた二つのバルク部分と，境界面に由来する部分とに分ける．
二つのバルク部分の体積を $V'$ ， $V''$ ，粒子数を $N'$ ， $N''$ とし，境界面の面積を $\sigma$ とする．

系全体の内部エネルギーを $U$ ，エントロピーを $S$ とすると，Helmholtz 自由エネルギー $F$ は

```math
F=U-TS
```

で定義される．
同様に，二つのバルク部分の Helmholtz 自由エネルギーをそれぞれ $F'$ ， $F''$ とする．

境界面が存在することによる自由エネルギーの寄与を，表面の Helmholtz 自由エネルギー $F_\sigma$ と定義する．
すなわち，

```math
\boxed{
F\_\sigma=F-(F'+F'')
}
\tag{1}
```

である．

ここで， $F_\sigma$ は，系全体の自由エネルギーから二つのバルク部分の自由エネルギーを差し引いた量である．
したがって，境界面に由来する自由エネルギーの寄与を表す．

### 2．表面張力係数 $\gamma$ と表面自由エネルギーの関係

まず，式 (4.8) に基づいて，系全体の Helmholtz 自由エネルギーの微分を求める．

式 (4.8) は

```math
\begin{aligned}
dU={}&T\,dS-p'\,dV'-p''\,dV''\\
&+\gamma\,d\sigma +\mu'\,dN'+\mu''\,dN''
\end{aligned}
```

である．
Helmholtz 自由エネルギー $F=U-TS$ を微分すると，

```math
dF=dU-T\,dS-S\,dT
```

であるから，これに式 (4.8) を代入して，

```math
\begin{aligned}
dF={}&-S\,dT-p'\,dV'-p''\,dV''\\
&+\gamma\,d\sigma +\mu'\,dN'+\mu''\,dN''
\end{aligned}
\tag{2}
```

を得る．

一方，二つのバルク部分については，それぞれ

```math
dF'=-S'\,dT-p'\,dV'+\mu'\,dN'
\tag{3}
```

および

```math
dF''=-S''\,dT-p''\,dV''+\mu''\,dN''
\tag{4}
```

が成立する．

式 (1) を微分すると，

```math
dF_\sigma=dF-dF'-dF''
\tag{5}
```

である．
ここに式 (2)，(3)，(4) を代入すると，体積に関する項と粒子数に関する項はそれぞれ相殺される．
したがって，

```math
dF_\sigma=-(S-S'-S'')\,dT+\gamma\,d\sigma
```

となる．
ここで，表面エントロピー $S_\sigma$ を

```math
S_\sigma\equiv S-(S'+S'')
\tag{6}
```

と定義すれば，

```math
\boxed{
dF_\sigma=-S_\sigma\,dT+\gamma\,d\sigma
}
\tag{7}
```

を得る．

この式から， $F_\sigma$ は温度 $T$ と表面積 $\sigma$ の関数であり，その表面積に関する偏微分は

```math
\boxed{
\left(\frac{\partial F_\sigma}{\partial\sigma}\right)_T =\gamma
}
\tag{8}
```

であることがわかる．
すなわち，表面張力係数 $\gamma$ は，温度を一定に保ったときの，表面積の増加に対する表面自由エネルギーの変化率である．

次に，表面自由エネルギーの示量性を利用する．
系の寸法を $\alpha^{1/2}$ 倍に拡大すると，表面積は $\alpha$ 倍になる．
表面自由エネルギーも表面積に比例するため，

```math
F_\sigma(T,\alpha\sigma) =\alpha F_\sigma(T,\sigma)
\tag{9}
```

が成立する．

式 (9) の両辺を $\alpha$ で微分すると，

```math
\sigma \left(\frac{\partial F\_\sigma}{\partial\sigma}\right)_T =F\_\sigma(T,\sigma)
```

となる．
ここで $\alpha=1$ とした．
さらに，式 (8) を用いれば，

```math
F_\sigma=\sigma\gamma
```

を得る．
したがって，

```math
\boxed{
\frac{F_\sigma}{\sigma}=\gamma
}
\tag{10}
```

である．

よって，単位表面積当たりの Helmholtz 自由エネルギーは表面張力係数 $\gamma$ に等しいことが示された．

### 3．単位表面積当たりの内部エネルギーの導出

続いて，表面の内部エネルギー $U_\sigma$ を求める．
表面の Helmholtz 自由エネルギー，内部エネルギーおよびエントロピーの間にも，通常の熱力学と同じ関係

```math
F_\sigma=U_\sigma-TS_\sigma
```

が成立する．
したがって，

```math
U_\sigma=F_\sigma+TS_\sigma
\tag{11}
```

である．

式 (7) より，表面積 $\sigma$ を一定に保ったとき，

```math
S_\sigma =-\left(\frac{\partial F_\sigma}{\partial T}\right)_\sigma
\tag{12}
```

が成立する．

ここで，式 (10) から $F_\sigma=\sigma\gamma$ である．
また，表面張力係数 $\gamma$ は温度 $T$ のみの関数であるため，

```math
F_\sigma(T,\sigma)=\sigma\gamma(T)
```

と書ける．
これを式 (12) に代入すると， $\sigma$ を一定に保って微分することにより，

```math
\begin{aligned}
S_\sigma &=-\left(\frac{\partial(\sigma\gamma)}{\partial T}\right)_\sigma\\
&=-\sigma\frac{d\gamma}{dT}
\end{aligned}
\tag{13}
```

を得る．

式 (13) を式 (11) に代入し，さらに $F_\sigma=\sigma\gamma$ を用いると，

```math
\begin{aligned}
U_\sigma &=F_\sigma+TS_\sigma\\
&=\sigma\gamma-T\sigma\frac{d\gamma}{dT}\\
&=\sigma\left(\gamma-T\frac{d\gamma}{dT}\right)
\end{aligned}
```

となる．
したがって，両辺を表面積 $\sigma$ で割れば，

```math
\boxed{
\frac{U_\sigma}{\sigma} =\gamma-T\frac{d\gamma}{dT}
}
\tag{14}
```

を得る．

以上より，単位表面積当たりの内部エネルギーは $\gamma-T\dfrac{d\gamma}{dT}$ に等しいことが示された．
