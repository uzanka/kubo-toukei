# 例題【4-R-3】

## 解答

本問題では，表面張力 $\gamma$ と，単位表面積あたりのヘルムホルツの自由エネルギー $F_\sigma$ ，および内部エネルギー $U_\sigma$ の関係を導出する．

### 1. 表面の自由エネルギー $F_\sigma$ の定義

まず，系全体を考える．
系には，二つの異なる相（例えば，液体相と気相）が存在し，その間に明確な境界（境界面）がある状況を想定する．

系全体のヘルムホルツの自由エネルギーを $F$ とする．
系を，境界から十分に離れた二つのバルク部分（体積 $V'$ と $V''$ ，粒子数 $N'$ と $N''$ ）と，その間の境界（表面積 $\sigma$ ）に分割して考える．

バルク部分の自由エネルギーをそれぞれ $F'$ と $F''$ とすると，系全体の自由エネルギー $F$ は，これら二つのバルク部分の自由エネルギーの和に，境界部分に特有のエネルギー（表面の自由エネルギー $F_\sigma$ ）を加えたものとして定義される．

$$F = F' + F'' + F_\sigma$$

したがって，表面の自由エネルギー $F_\sigma$ は次のように定義される．

$$F_\sigma = F - (F' + F'') \quad \cdots (1)$$

### 2. $F_\sigma$ と表面張力 $\gamma$ の関係

次に，自由エネルギーの微小変化（全微分）を考える．

系全体の自由エネルギー $F$ の微小変化 $dF$ は，温度 $T$ ，体積 $V$ ，粒子数 $N$ ，および表面積 $\sigma$ を変数として，次のように書ける．

$$dF = -S dT - p dV + \mu dN + \gamma d\sigma$$

ここで， $S$ はエントロピー， $p$ は圧力， $\mu$ は化学ポテンシャル， $\gamma$ は表面張力である．

同様に，二つのバルク部分の自由エネルギー $F'$ と $F''$ の微小変化は，それぞれ次のように書ける．

$$dF' = -S' dT - p' dV' + \mu' dN'$$

$$dF'' = -S'' dT - p'' dV'' + \mu'' dN''$$

ここで，二つの相が熱平衡状態にあるとすると，温度 $T$ ，圧力 $p$ ，および化学ポテンシャル $\mu$ は系全体で共通である（ $T'=T''=T$, $p'=p''=p$, $\mu'= \mu'' = \mu$ ）．

式(1)の両辺の全微分をとると，

$$dF_\sigma = dF - dF' - dF''$$

となる．
ここに各微分の式を代入すると，

$$dF_\sigma = (-S dT - p dV + \mu dN + \gamma d\sigma) - (-S' dT - p' dV' + \mu' dN') - (-S'' dT - p'' dV'' + \mu'' dN'')$$

ここで，体積の成分分解 $V = V' + V''$ （表面の体積を無視できるほど小さいと仮定）および粒子数の成分分解 $N = N' + N''$ を用いると，体積項 $-p dV$ と $-p' dV' - p'' dV''$ ，および粒子数項 $\mu dN$ と $-\mu' dN' - \mu'' dN''$ は互いに打ち消し合う．

残った項をまとめると，

$$dF_\sigma = -(S - S' - S'') dT + \gamma d\sigma$$

ここで， $S_\sigma = S - (S' + S'')$ を「表面エントロピー」と定義すると，

$$dF_\sigma = -S_\sigma dT + \gamma d\sigma \quad \cdots (2)$$

が得られる．

ここで，表面積 $\sigma$ についての依存性を調べる．
表面の自由エネルギー $F_\sigma$ は，面積 $\sigma$ に対して「示量性」を持つ．
つまり，系の寸法を $\alpha^{1/2}$ 倍に拡大すると，面積 $\sigma$ は $\alpha$ 倍になり，それに応じて $F_\sigma$ も $\alpha$ 倍になる．

$$F_\sigma(T, \alpha\sigma) = \alpha F_\sigma(T, \sigma)$$

この式の両辺を $\alpha$ で微分し， $\alpha = 1$ とおくと，

$$\frac{\partial}{\partial \alpha} F_\sigma(T, \alpha\sigma) \Big|_{\alpha=1} = F_\sigma(T, \sigma)$$

$$\sigma \left( \frac{\partial F_\sigma}{\partial \sigma} \right)_{\alpha=1} = F_\sigma(T, \sigma)$$

したがって，

$$F_\sigma = \sigma \frac{\partial F_\sigma}{\partial \sigma}$$

となる．
これを式(2)の $\sigma$ に関する偏微分 $\left( \frac{\partial F_\sigma}{\partial \sigma} \right) = \gamma$ と比較すると，

$$F_\sigma = \sigma \gamma \quad \text{すなわち} \quad \gamma = \frac{F_\sigma}{\sigma}$$

であることがわかる．
これは， $\gamma$ が「単位表面積あたりのヘルムホルツの自由エネルギー」であることを示している．

### 3. 内部エネルギー $U_\sigma$ の導出

最後に，表面の内部エネルギー $U_\sigma$ を求める．
熱力学の関係式から，自由エネルギー，内部エネルギー，エントロピーの間には次の関係がある．

$$U_\sigma = F_\sigma + TS_\sigma$$

ここで， $F_\sigma = \sigma \gamma$ であることと，式(2)から $S_\sigma = - \left( \frac{\partial F_\sigma}{\partial T} \right)_\sigma$ であることを利用する．

$F_\sigma$ を $T$ で偏微分すると，

$$S_\sigma = - \left( \frac{\partial (\sigma \gamma)}{\partial T} \right)_\sigma = - \sigma \left( \frac{\partial \gamma}{\partial T} \right)_\sigma$$

となる（ $\sigma$ は $T$ と独立な変数として扱える）．

これを $U_\sigma$ の式に代入すると，

$$U_\sigma = \sigma \gamma + T \left( - \sigma \frac{d\gamma}{dT} \right) = \sigma \left( \gamma - T \frac{d\gamma}{dT} \right)$$

両辺を $\sigma$ で割ることで，単位表面積あたりの内部エネルギーが得られる．

$$\frac{U_\sigma}{\sigma} = \gamma - T \frac{d\gamma}{dT}$$

以上により，題意が示された．

## 解説

この問題のポイントは，**「表面」という現象を，バルク（体積を持つ部分）とは別の独立した自由度（面積 $\sigma$ ）を持つものとして数学的に扱う**点にある．

1.  **自由エネルギーの分割**: 通常の熱力学では $F(T, V, N)$ と考えるが，表面がある場合は $F(T, V, N, \sigma)$ と，面積 $\sigma$ を独立な変数として追加する．
2.  **示量性と相似性**: 面積 $\sigma$ が増えると $F_\sigma$ も比例して増える（ $\alpha$ 倍になる）という性質を利用して， $\gamma = F_\sigma / \sigma$ という関係を導き出している．
これは， $\gamma$ が「広がり」に対するエネルギーの密度であることを意味している．
3.  **熱力学的関係式の適用**: 内部エネルギー $U$ ，自由エネルギー $F$ ，エントロピー $S$ の間には $U = F + TS$ という基本公式があるが，これを「表面」という特定の領域に対して適用することで，表面の熱力学量を導出している．
4.  **温度依存性**: 最終的な式 $\gamma - T \frac{d\gamma}{dT}$ は，表面張力が温度によってどのように変化するか（ $\frac{d\gamma}{dT}$ ）が，表面のエネルギー状態にどのように寄与するかを表している．

このように，表面の現象をバルクの熱力学の拡張として捉えることで，表面張力という物理量を厳密に定義し，その熱力学的な振る舞いを記述することができる．
