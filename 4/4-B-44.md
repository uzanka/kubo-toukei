# 演習問題【4-B-44】

## 解答

## 1．各成分の数密度を定義する

n型不純物半導体では，中性のドナー $D$ が電離して，正に帯電したドナー $D^+$ と伝導電子 $e$ を生じる．
反応式は

```math
D\rightleftharpoons D^++e
\tag{1}
```

である．

ドナーの全数密度を $N_d$ ，伝導電子の数密度を $n_e$ とする．
本問では，ドナー以外の電荷担体を無視し，電気的中性を満たすと仮定する．
電離反応では $D^+$ と $e$ が1対1で生成されるため，

```math
n\_{D^+}=n_e
\tag{2}
```

である．
また，ドナーの総数は保存されるため，

```math
n_D+n\_{D^+}=N_d
\tag{3}
```

となる．
式（2），（3）より，

```math
\boxed{
n_D=N_d-n_e,\qquad n\_{D^+}=n_e
}
\tag{4}
```

を得る．
すなわち，中性のドナー，イオン化したドナー，伝導電子の数密度は，それぞれ $N_d-n_e$ ， $n_e$ ， $n_e$ である．

## 2．各成分の化学ポテンシャルを求める

### 2.1 伝導電子の化学ポテンシャル

問題の仮定により，伝導電子を希薄な理想気体とみなす．
このとき，電子の化学ポテンシャルは教科書の式に従って，

```math
\mu_e =u_e^0-\frac32 k_BT\ln T-k_BT i_e +k_BT\ln n_e
\tag{5}
```

と書ける．
ここで， $k_B$ はボルツマン定数， $u_e^0$ と $i_e$ は基準状態や電子の状態数に関わる定数である．
式（5）の対数項は，基準となる密度や温度を含む表記を簡略化したものであり，その基準量に由来する定数は後の比例定数に含まれる．

電子の化学ポテンシャルには，数密度 $n_e$ に由来する項だけでなく，温度に関する $-\frac32 k_BT\ln T$ の項も含まれる．
この温度依存性が，最終的な公式に現れる $T^{3/4}$ の因子につながる．

### 2.2 中性ドナー $D$ の化学ポテンシャル

ドナー $D$ と $D^+$ は結晶中の格子に関係づけられた成分であり，本問では理想的希薄固溶体として扱う．
この近似では，各成分の化学ポテンシャルは，その存在割合の対数に比例する項を含む．
したがって，

```math
\begin{aligned}
\mu_D &=\mu_D^0(T,p) +k_BT\ln\frac{n_D}{N_d}\\
&=\mu_D^0(T,p) +k_BT\ln\frac{N_d-n_e}{N_d}
\end{aligned}
\tag{6}
```

である．
ここで， $\mu_D^0(T,p)$ は中性ドナーの基準化学ポテンシャルである．

### 2.3 イオン化ドナー $D^+$ の化学ポテンシャル

同様に，イオン化したドナーの化学ポテンシャルは，

```math
\begin{aligned}
\mu\_{D^+} &=\mu\_{D^+}^0(T,p) +k_BT\ln\frac{n\_{D^+}}{N_d}\\
&=\mu\_{D^+}^0(T,p) +k_BT\ln\frac{n_e}{N_d}
\end{aligned}
\tag{7}
```

となる．
ここで， $\mu\_{D^+}^0(T,p)$ はイオン化ドナーの基準化学ポテンシャルである．

## 3．化学平衡の条件から関係式を導く

反応

```math
D\rightleftharpoons D^++e
```

が熱力学的平衡に達したとき，反応前後の化学ポテンシャルの関係は

```math
\boxed{
\mu_D=\mu\_{D^+}+\mu_e
}
\tag{8}
```

である．
これは，1個の $D$ が $D^+$ と電子に変化することによる自由エネルギー変化が，平衡でゼロになるという条件である．

式（5），（6），（7）を式（8）に代入すると，

```math
\begin{aligned}
&\mu_D^0 +k_BT\ln\frac{N_d-n_e}{N_d}\\
&\quad= \mu\_{D^+}^0 +k_BT\ln\frac{n_e}{N_d} +u_e^0-\frac{3}{2} k_BT\ln T-k_BT i_e +k_BT\ln n_e
\end{aligned}
\tag{9}
```

となる．
これを整理すると，数密度に関する項は，

```math
\ln\frac{n_e^2}{N_d-n_e}
```

にまとめられる．
定数項を右辺へ移せば，

```math
\ln\frac{n_e^2}{N_d-n_e} =-\frac{u_e^0+\mu\_{D^+}^0-\mu_D^0}{k_BT} +\frac{3}{2}\ln T+i_e
\tag{10}
```

となる．
この式でも，対数の基準量は教科書の表記に従って省略している．

ここで，

```math
\boxed{
E_d=u_e^0+\mu\_{D^+}^0-\mu_D^0
}
\tag{11}
```

と定義する．
これは，中性のドナーを電離して $D^+$ と伝導電子を生じさせるのに必要な電離エネルギーである．
$E_d$ を温度によらない一定値として扱い，定数項をまとめると，式（10）を指数関数に直して，

```math
\boxed{
\frac{n_e^2}{N_d-n_e} \propto T^{3/2}\exp\left(-\frac{E_d}{k_BT}\right)
}
\tag{12}
```

を得る．
これが，電離平衡から導かれる伝導電子密度の基本関係式である．

## 4．弱電離の近似を適用する

式（12）は，ドナーが部分的にしか電離していない場合にも成り立つ基本関係式である．
さらに，

```math
n_e\ll N_d
\tag{13}
```

という近似が成り立つ場合を考える．
この条件では，中性ドナーの数密度について，

```math
N_d-n_e\simeq N_d
```

と近似できる．
式（12）は，

```math
\frac{n_e^2}{N_d} \propto T^{3/2}\exp\left(-\frac{E_d}{k_BT}\right)
```

となる．
両辺に $N_d$ を掛けると，

```math
n_e^2 \propto N_d T^{3/2} \exp\left(-\frac{E_d}{k_BT}\right)
\tag{14}
```

である．
ここで両辺の平方根をとれば，

```math
\boxed{
n_e\propto N_d^{1/2}T^{3/4} \exp\left(-\frac{E_d}{2k_BT}\right)
}
\tag{15}
```

を得る．
これが求める伝導電子密度の公式である．

## 5．近似の適用範囲について

式（15）は，ドナーの電離割合が小さく，伝導電子密度がドナー総数密度より十分小さい場合に成立する近似式である．
ドナー濃度が結晶全体に対して希薄であることだけから， $n_e\ll N_d$ が保証されるわけではない．

近似を行う前の式（12）を，

```math
\frac{n_e^2}{N_d-n_e} =A(T)
```

と書けば，

```math
A(T)\propto T^{3/2}\exp\left(-\frac{E_d}{k_BT}\right)
```

であり， $n_e$ は次の二次方程式を満たす．

```math
n_e^2+A(T)n_e-A(T)N_d=0
```

物理的に意味のある正の解は，

```math
n_e= \frac{\sqrt{A(T)^2+4A(T)N_d}-A(T)}{2}
\tag{16}
```

である．
$A(T)\ll N_d$ のときに限り，この式は式（15）の弱電離近似に帰着する．
一方，ドナーがほぼ完全に電離している領域では $n_e\simeq N_d$ となり，式（15）をそのまま使うことはできない．

したがって，本問の熱力学的な導出の要点は，化学平衡条件から式（12）を得て，弱電離の条件 $n_e\ll N_d$ のもとで式（15）を導くことである．
