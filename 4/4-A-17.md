# 演習問題【4-A-17】

## 解答

### 1．系の設定と平衡条件

溶媒（成分1）と溶質（成分2）からなる理想溶液と，純粋な溶媒とが，半透膜によって隔てられている系を考える．
半透膜は溶媒だけを通し，溶質は通さないものとする．

溶液側の圧力を $p'$ ，純溶媒側の圧力を $p''$ とする．
また，溶液中の溶質のモル分率を $x_2$ とすると，溶媒のモル分率 $x_1$ は

```math
x_1=1-x_2
```

である．

半透膜を通して溶媒が正味で移動しない平衡状態では，溶液側と純溶媒側における溶媒の化学ポテンシャルが等しくなる．
したがって，

```math
\overline G_1(T,p',x_2)
=
\overline G_1^0(T,p'')
\tag{1}
```

が成り立つ．
ここで， $\overline G_1$ は溶液中の溶媒の化学ポテンシャル， $\overline G_1^0$ は純溶媒の化学ポテンシャルである．
化学ポテンシャルは，物質の移動に伴うギブズエネルギーの変化を表す量であり，両側でその値が等しいことが溶媒の移動平衡の条件となる．

### 2．理想溶液の化学ポテンシャルを代入する

温度 $T$ ，圧力 $p'$ における理想溶液中の溶媒の化学ポテンシャルは，

```math
\overline G_1(T,p',x_2)
=
\overline G_1^0(T,p')+RT\log x_1
```

と表される．
ここで， $R$ は気体定数である．
$x_1=1-x_2$ を代入すると，

```math
\overline G_1(T,p',x_2)
=
\overline G_1^0(T,p')+RT\log(1-x_2)
```

となる．
これを平衡条件 (1) に代入すれば，

```math
\overline G_1^0(T,p')
+RT\log(1-x_2)
=
\overline G_1^0(T,p'')
```

を得る．
したがって，

```math
\overline G_1^0(T,p')
-\overline G_1^0(T,p'')
=
-RT\log(1-x_2)
\tag{2}
```

である．

### 3．浸透圧を導入する

浸透圧 $\pi$ とは，半透膜を通した溶媒の正味の移動を平衡にするために必要な圧力差である．
溶液側の圧力が純溶媒側より高くなるため，

```math
p'=p''+\pi
```

とおける．
よって，

```math
p'-p''=\pi
\tag{3}
```

である．

ここで，浸透圧が十分小さく，この圧力範囲では純溶媒のモル体積がほぼ一定とみなせると仮定する．
すると，純溶媒の化学ポテンシャルの圧力差による変化は，圧力 $p''$ の周りでテイラー展開し，一次の項まで残すことで，

```math
\begin{aligned}
&\overline G_1^0(T,p')
-\overline G_1^0(T,p'')\\
&\quad\approx
\left(
\frac{\partial\overline G_1^0}{\partial p}
\right)_T(p'-p'')
\end{aligned}
\tag{4}
```

と近似できる．

熱力学の基本関係式

```math
dG=V\,dp-S\,dT
```

を物質1モルあたりの量について考えると，温度一定では

```math
\left(
\frac{\partial\overline G_1^0}{\partial p}
\right)_T
=
\overline V_1
```

となる．
ここで， $\overline V_1$ は純溶媒のモル体積である．
式 (3) とこの関係を式 (4) に代入すると，

```math
\overline G_1^0(T,p')
-\overline G_1^0(T,p'')
\approx
\overline V_1\pi
\tag{5}
```

を得る．

### 4．浸透圧の公式を導く

式 (2) と式 (5) を組み合わせると，

```math
\overline V_1\pi
\approx -RT\log(1-x_2)
```

となる．
したがって，理想溶液の浸透圧は，

```math
\boxed{
\pi\approx
-\frac{RT}{\overline V_1}\log(1-x_2)
}
```

で与えられる．
この式は，浸透圧が十分小さく，圧力変化に伴う純溶媒のモル体積の変化を無視できるという近似の下で成り立つものである．

### 5．希薄溶液の場合

特に，溶質のモル分率が十分小さく，

```math
x_2\ll1
```

である場合を考える．
このとき，対数関数のテイラー展開から，

```math
\log(1-x_2)\approx-x_2
```

と近似できる．
これを浸透圧の公式に代入すると，

```math
\pi\approx
-\frac{RT}{\overline V_1}(-x_2)
```

すなわち，

```math
\boxed{
\pi\overline V_1\approx RTx_2
}
```

を得る．

この式は，理想気体の状態方程式 $pV=nRT$ をモル体積で表した $pV_m=RT$ とよく似た形である．
ただし，ここでの $\pi$ は溶液と純溶媒の間の圧力差であり，気体の圧力そのものではない．

以上より，理想溶液の浸透圧は，溶媒の化学ポテンシャルの平衡条件から導かれ，希薄溶液では溶質のモル分率に比例することが示された．
