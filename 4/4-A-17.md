# 演習問題【4-A-17】

## 解答

### 1. 設定の整理

まず，どのような物理的状況を考えているかを明確にする．
- **系**: 半透膜によって仕切られた2つの領域がある．
  - **溶液側**: 溶媒（成分1）と溶質（成分2）が混ざった溶液である．
  溶質のモル分率を $x_2$ とすると，溶媒のモル分率は $x_1 = 1 - x_2$ である．
  この溶液にかかっている圧力を $p'$ とする．
  - **純溶媒側**: 溶媒のみが存在する領域である．
  この領域にかかっている圧力を $p''$ とする．
- **半透膜**: 溶媒（成分1）だけを通し，溶質（成分2）は通さない性質を持つ．

### 2. 平衡条件

半透膜を介して溶媒が移動しない（平衡状態にある）とき，溶液中の溶媒の化学ポテンシャル $\overline{G}_1(p', x_2)$ と，純溶媒側の溶媒の化学ポテンシャル $\overline{G}_1^0(p'')$ は等しくなければならない．

$$\overline{G}_1(p', x_2) = \overline{G}_1^0(p'')$$

### 3. 理想溶液の化学ポテンシャル

溶液が「理想溶液」であると仮定すると，溶液中の溶媒の化学ポテンシャルは，純溶媒の化学ポテンシャル $\overline{G}_1^0(T, p')$ を用いて次のように表される．

$$\overline{G}_1(T, p', x_2) = \overline{G}_1^0(T, p') + RT \ln(x_1)$$

ここで， $x_1 = 1 - x_2$ なので，

$$\overline{G}_1(T, p', x_2) = \overline{G}_1^0(T, p') + RT \ln(1 - x_2)$$

となる．

これらを平衡条件の式に代入すると，

$$\overline{G}_1^0(T, p') + RT \ln(1 - x_2) = \overline{G}_1^0(T, p'')$$

整理すると，

$$\overline{G}_1^0(T, p') - \overline{G}_1^0(T, p'') = -RT \ln(1 - x_2)$$

が得られる．

### 4. 浸透圧 $\pi$ の導入と近似

浸透圧 $\pi$ は，溶液側と純溶媒側の圧力の差として定義される．

$$p' = p'' + \pi$$

ここで， $\pi$ が十分に小さいと仮定する．
このとき，左辺の差 $\overline{G}_1^0(T, p') - \overline{G}_1^0(T, p'')$ は，圧力 $p$ に関する $\overline{G}_1^0$ の微小な変化とみなすことができる．
テイラー展開の第1項（一次近似）を用いると，

$$\overline{G}_1^0(T, p') - \overline{G}_1^0(T, p'') \cong \left( \frac{\partial \overline{G}_1^0}{\partial p} \right)_T (p' - p'') = \left( \frac{\partial \overline{G}_1^0}{\partial p} \right)_T \pi$$

となる．

ここで，熱力学の基本関係式 $dG = V dp - S dT$ より，定温条件 $(dT=0)$ では $\left( \frac{\partial G}{\partial p} \right)_T = V$ である．
したがって，

$$\frac{\partial \overline{G}_1^0}{\partial p} = \overline{V}_1$$

となる．
ここで $\overline{V}_1$ は純溶媒のモル体積である．

これらを合わせると，

$$\pi \overline{V}_1 \cong -RT \ln(1 - x_2)$$

となる．

### 5. 結論

したがって，浸透圧 $\pi$ は以下の公式で与えられる．

$$\pi = -\frac{RT}{\overline{V}_1} \ln(1 - x_2)$$

### (補足) 希薄溶液の場合

溶質の濃度が非常に低い場合（ $x_2 \ll 1$ ）， $\ln(1 - x_2) \approx -x_2$ という近似が成り立つ．
これを代入すると，

$$\pi \approx -\frac{RT}{\overline{V}_1} (-x_2) = \frac{RT x_2}{\overline{V}_1}$$

すなわち，

$$\pi \overline{V}_1 = RT x_2$$

となり，これは理想気体の状態方程式 $PV = nRT$ （モル体積 $V_m = V/n$ を用いると $P V_m = RT$ ）に非常に近い形式になる．

## 解説

### 各変数の意味

- $\pi$ : 浸透圧 [Pa]．
  半透膜を介して溶媒の移動を止めるために溶液側に加えるべき圧力．
- $R$ : 気体定数．
- $T$ : 絶対温度 [K]．
- $\overline{V}_1$ : 純溶媒のモル体積 [m $^3$ /mol]．
  溶媒1モルあたりの体積．
- $x_2$ : 溶質のモル分率．
  溶液全体における溶質の割合．

### 物理的なイメージ

浸透圧とは，「溶媒が溶質を薄めようとして，純溶媒側から溶液側へ移動しようとする力」を，圧力をかけることで食い止めたときの圧力のことである．
数学的には，溶媒の「化学ポテンシャル（＝溶媒がその状態に留まろうとするエネルギーの指標）」の差が，圧力の差によって釣り合っている状態を記述している．

### 近似のポイント

今回の導出では， $\pi$ が小さいという近似を用いた．
これは，現実的な多くの溶液において，溶液と純溶媒の圧力差は極めて小さいことを利用している．
この近似により，複雑な関数としての化学ポテンシャルの差を，単純な「圧力 $\times$ 体積」の形に落とし込むことができている．
