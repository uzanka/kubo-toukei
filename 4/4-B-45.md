# 演習問題【4-B-45】

## 解答

## 1．起電力と銀の活動度の関係

この電池では，銀が純粋な液体状態から溶融金中に溶け込む反応

```math
\mathrm{Ag(l)} \longrightarrow \mathrm{Ag(in\ Au(l))}
\tag{1}
```

が起こる．
電池の反応による Gibbs 自由エネルギー変化は，銀の化学ポテンシャルを用いて，

```math
\Delta_rG =\mu_{\mathrm{Ag(in\ Au)}}-\mu_{\mathrm{Ag(l)}}
\tag{2}
```

と表せる．

純粋な液体銀を標準状態にとると，溶融金中の銀の化学ポテンシャルは，

```math
\mu_{\mathrm{Ag(in\ Au)}} =\mu_{\mathrm{Ag(l)}}+RT\ln a_{\mathrm{Ag}}
\tag{3}
```

と書ける．
ここで $a_{\mathrm{Ag}}$ は，溶融金中における銀の活動度である．
式（2），（3）から，

```math
\boxed{
\Delta_rG=RT\ln a\_{\mathrm{Ag}}
}
\tag{4}
```

を得る．

一方，可逆電池では，反応が進むことで得られる最大電気仕事と Gibbs 自由エネルギー変化との間に，

```math
\boxed{
\Delta_rG=-\mathfrak F E
}
\tag{5}
```

という関係がある．
ここで $\mathfrak F$ はファラデー定数， $E$ は起電力である．
銀1 molの移動に対応する電子は1 molであるため，この式では電子数の係数は1である．

式（4），（5）を組み合わせると，

```math
-\mathfrak F E=RT\ln a_{\mathrm{Ag}}
```

となり，銀の活動度と起電力の関係は，

```math
\boxed{
a_{\mathrm{Ag}} =\exp\left(-\frac{\mathfrak F E}{RT}\right)
}
\tag{6}
```

と求まる．

常用対数を用いる場合は， $\ln z=2.303\log_{10}z$ であるから，

```math
\boxed{
\log_{10}a_{\mathrm{Ag}} =-\frac{\mathfrak F E}{2.303RT}
}
\tag{7}
```

となる．

## 2．理想溶液で $x=0.5$ のときの起電力

理想溶液では，活動度係数 $\gamma_{\mathrm{Ag}}$ は1である．
銀のモル分率を $x$ とすると，

```math
a_{\mathrm{Ag}}=x\gamma_{\mathrm{Ag}}=x
\tag{8}
```

である．
したがって，理想溶液では式（5），（4）から，

```math
E=-\frac{RT}{\mathfrak F}\ln x
\tag{9}
```

となる．

問題で指定された

```math
T=1360\ \mathrm K,\qquad x=0.5
```

および

```math
R=1.987\ \mathrm{cal/(mol\,K)},\qquad \mathfrak F=23060\ \mathrm{cal/(V\,mol)}
```

を代入すると，

```math
\begin{aligned}
E &=-\frac{1.987\times1360}{23060}\ln(0.5)\\
&\simeq0.0812\ \mathrm V
\end{aligned}
```

を得る．
よって，理想溶液で $x=0.5$ の場合に期待される起電力は，

```math
\boxed{
E\simeq0.0812\ \mathrm V\approx0.082\ \mathrm V
}
```

である．

## 3．実測値から銀の活動度を求める

式（6）より，活動度は起電力から直接求められる．

```math
\boxed{
a_{\mathrm{Ag}} =\exp\left(-\frac{\mathfrak F E}{RT}\right) =10^{-\mathfrak F E/(2.303RT)}
}
\tag{10}
```

今回の温度と定数では，

```math
\frac{\mathfrak F}{2.303RT} =\frac{23060}{2.303\times1.987\times1360} \simeq3.7053\ \mathrm{V^{-1}}
```

である．
したがって，

```math
\boxed{
\log_{10}a_{\mathrm{Ag}}\simeq-3.7053E
}
\tag{11}
```

となる．
ここで， $E$ は V 単位で代入する．

例えば， $x=0.846$ ， $E=0.021\ \mathrm V$ の場合，

```math
\log_{10}a_{\mathrm{Ag}} =-3.7053\times0.021 \simeq-0.0778
```

であるため，

```math
a_{\mathrm{Ag}}=10^{-0.0778}\simeq0.836
```

となる．

同様にして各測定値について計算すると，次の表が得られる．

| 銀のモル分率 $x$ | 起電力 $E$ （V） | $\log_{10}a_{\mathrm{Ag}}$ | 銀の活動度 $a_{\mathrm{Ag}}$ |
| -------------- | -------------- | -------------------------------- | ---------------------------- |
| 0.846          | 0.021          | −0.0778                          | 0.836                        |
| 0.716          | 0.045          | −0.1667                          | 0.681                        |
| 0.602          | 0.074          | −0.2742                          | 0.532                        |
| 0.471          | 0.114          | −0.4224                          | 0.378                        |
| 0.263          | 0.198          | −0.7337                          | 0.185                        |

したがって，表から求めた銀の活動度は，それぞれ約 $0.836$ ， $0.681$ ， $0.532$ ， $0.378$ ， $0.185$ である．

## 4．活動度係数も求める

実測値を理想溶液の予測と比較するため，活動度係数 $\gamma_{\mathrm{Ag}}$ も求める．活動度と活動度係数の関係は，

```math
a_{\mathrm{Ag}}=x\gamma_{\mathrm{Ag}}
```

であるから，

```math
\boxed{
\gamma_{\mathrm{Ag}}=\frac{a_{\mathrm{Ag}}}{x}
}
\tag{12}
```

となる．
対数で表すと，

```math
\boxed{
\log_{10}\gamma_{\mathrm{Ag}} =-\frac{\mathfrak F E}{2.303RT} -\log_{10}x
}
\tag{13}
```

である．
これを用いて計算した結果を示す．

| $x$ | $\log_{10}x$ | $\log_{10}\gamma_{\mathrm{Ag}}$ | $\gamma_{\mathrm{Ag}}$ |
| ------- | ----------------- | ------------------------------------- | --------------------------- |
| 0.846   | −0.0726           | −0.0052                               | 0.988                       |
| 0.716   | −0.1451           | −0.0216                               | 0.951                       |
| 0.602   | −0.2204           | −0.0538                               | 0.884                       |
| 0.471   | −0.3269           | −0.0955                               | 0.803                       |
| 0.263   | −0.5800           | −0.1536                               | 0.702                       |

この結果から，銀の活動度係数はすべて1より小さく，銀のモル分率が小さくなるにつれて，活動度係数も小さくなる傾向が認められる．
すなわち，溶融 $\mathrm{Ag}_x\mathrm{Au}_{1-x}$ は，この濃度範囲では銀について理想溶液から負に偏倚する系である．

## 5．結論

理想溶液で $x=0.5$ ， $T=1360\ \mathrm K$ の場合に期待される起電力は，

```math
\boxed{
E\simeq0.0812\ \mathrm V
}
```

である．

また，実測起電力から得られる銀の活動度は，

```math
\boxed{
a_{\mathrm{Ag}}\simeq 0.836,\ 0.681,\ 0.532,\ 0.378,\ 0.185
}
```

である．
活動度係数は，

```math
\boxed{
\gamma_{\mathrm{Ag}}\simeq 0.988,\ 0.951,\ 0.884,\ 0.803,\ 0.702
}
```

となる．

活動度 $a_{\mathrm{Ag}}$ は実測起電力から直接計算され，活動度係数 $\gamma_{\mathrm{Ag}}$ はさらにモル分率 $x$ で割ることによって求められる．
この2つを区別することで，問題文が求める活動度と，解答例で示されている活動度係数の両方を明確に得られるのである．
