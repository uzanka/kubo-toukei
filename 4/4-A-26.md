# 演習問題【4-A-26】

## 解答

### 1．化学反応の平衡条件

炭酸カルシウムの熱分解反応は，次のように表される．

```math
\mathrm{CaCO_3(s)}
\rightleftharpoons
\mathrm{CaO(s)}+\mathrm{CO_2(g)}
```

ここで， $\mathrm{(s)}$ は固体， $\mathrm{(g)}$ は気体を表す．

化学反応が平衡にあるとき，各物質の化学ポテンシャルを用いて，

```math
\mu_{\mathrm{CaCO_3}}
=\mu_{\mathrm{CaO}}+\mu_{\mathrm{CO_2}}
```

と書ける．
化学ポテンシャルとは，物質の量をわずかに増加させたときのギブス自由エネルギーの変化を表す量である．

反応の標準ギブス自由エネルギー変化を $\Delta G_T^0$ とすると，

```math
\Delta G_T^0
=\mu_{\mathrm{CaO}}^0
+\mu_{\mathrm{CO_2}}^0
-\mu_{\mathrm{CaCO_3}}^0
```

である．
標準状態における各物質の化学ポテンシャルを $\mu_i^0$ と表した．
添字 $T$ は，この量が温度 $T$ に依存することを示す．

固体の圧力依存性を無視し，純固体の活量を1とみなす．
一方，理想気体の化学ポテンシャルは，

```math
\mu_{\mathrm{CO_2}}
=\mu_{\mathrm{CO_2}}^0
+RT\ln\left(\frac{p_{\mathrm{CO_2}}}{p^0}\right)
```

と表される．
ここで， $R$ は気体定数， $p_{\mathrm{CO_2}}$ は二酸化炭素の圧力， $p^0=1\,\mathrm{atm}$ は標準圧力である．

平衡条件に代入すると，

```math
\Delta G_T^0
+RT\ln\left(\frac{p_{\mathrm{CO_2}}}{p^0}\right)=0
```

となる．
したがって，

```math
\boxed{
\Delta G_T^0
=-RT\ln\left(\frac{p_{\mathrm{CO_2}}}{p^0}\right)
}
\tag{1}
```

を得る．
つまり，解離圧の温度依存性を調べれば，標準ギブス自由エネルギー変化の温度依存性が分かる．

### 2．ギブス・ヘルムホルツの式を用いる

標準エンタルピー変化 $\Delta H_T^0$ と標準ギブス自由エネルギー変化 $\Delta G_T^0$ の間には，ギブス・ヘルムホルツの式

```math
\frac{d}{dT}
\left(\frac{\Delta G_T^0}{T}\right)
=-\frac{\Delta H_T^0}{T^2}
\tag{2}
```

が成り立つ．
この式は，ギブス自由エネルギーの温度変化からエンタルピー変化を求めるための関係式である．

式 (1) を $T$ で割ると，

```math
\frac{\Delta G_T^0}{T}
=-R\ln\left(\frac{p_{\mathrm{CO_2}}}{p^0}\right)
```

となる．
これを式 (2) に代入し， $R$ と $p^0$ が一定であることを用いて微分すると，

```math
-R\frac{d}{dT}
\ln\left(\frac{p_{\mathrm{CO_2}}}{p^0}\right)
=-\frac{\Delta H_T^0}{T^2}
```

を得る．
両辺の符号を整理すれば，

```math
\boxed{
\Delta H_T^0
=RT^2\frac{d}{dT}
\ln\left(\frac{p_{\mathrm{CO_2}}}{p^0}\right)
}
\tag{3}
```

となる．
したがって，求める標準エンタルピー変化は，解離圧の対数を温度で微分すれば計算できる．

### 3．与えられた実験式を微分する

問題で与えられた実験式は，

```math
\log_{10}p_{\mathrm{CO_2}}
=-\frac{11355}{T}
-5.388\log_{10}T+26.238
\tag{4}
```

である．
圧力の数値は気圧単位で表されているため，ここでは $p^0=1\,\mathrm{atm}$ とし， $\log_{10}p_{\mathrm{CO_2}}$ を $\log_{10}(p_{\mathrm{CO_2}}/p^0)$ の略記として扱う．

式 (3) には自然対数 $\ln$ が必要であるため，

```math
\ln x=(\ln 10)\log_{10}x
```

という関係を使う．
式 (4) の両辺に $\ln 10$ を掛けると，

```math
\begin{aligned}
\ln\left(\frac{p_{\mathrm{CO_2}}}{p^0}\right)
={}&-\frac{11355\ln 10}{T}\\
&-5.388\ln T+26.238\ln 10
\end{aligned}
\tag{5}
```

となる．
ここでは， $\log_{10}T=\ln T/\ln 10$ を用いた．

次に，式 (5) の両辺を $T$ で微分する．
各項について，

```math
\frac{d}{dT}\left(-\frac{11355\ln 10}{T}\right)
=\frac{11355\ln 10}{T^2}
```

```math
\frac{d}{dT}(-5.388\ln T)
=-\frac{5.388}{T}
```

であり，定数項 $26.238\ln 10$ の微分は0である．
よって，

```math
\boxed{
\frac{d}{dT}
\ln\left(\frac{p_{\mathrm{CO_2}}}{p^0}\right)
=\frac{11355\ln 10}{T^2}
-\frac{5.388}{T}
}
\tag{6}
```

を得る．

### 4．標準エンタルピー変化を計算する

式 (6) を式 (3) に代入すると，

```math
\begin{aligned}
\Delta H_T^0
&=RT^2
\left(
\frac{11355\ln 10}{T^2}
-\frac{5.388}{T}
\right)\\
&=11355R\ln 10-5.388RT
\end{aligned}
```

となる．
ここで，気体定数を

```math
R=1.987\,
\mathrm{cal\,mol^{-1}K^{-1}}
```

とし， $\ln 10\simeq2.302585$ を用いる．

第1項の係数は，

```math
11355\times1.987\times2.302585
\simeq51957
```

であり，第2項の係数は，

```math
5.388\times1.987\simeq10.707
```

である．
したがって，求める標準エンタルピー変化は，

```math
\boxed{
\Delta H_T^0
=51957-10.707T
\quad\mathrm{cal\,mol^{-1}}
}
```

である．
ここで， $T$ は絶対温度（K）であり，式は問題で与えられた温度範囲 $1100\text{～}1500\,\mathrm{K}$ に適用される．

なお，kcal 単位で表せば，

```math
\boxed{
\Delta H_T^0
=51.957-0.010707T
\quad\mathrm{kcal\,mol^{-1}}
}
```

となる．

**答**

```math
\boxed{
\displaystyle
\Delta H_T^0
=(51957-10.707T)\,
\mathrm{cal\,mol^{-1}}
}
```

### 補足

反応エンタルピーが温度に依存するのは，反応物と生成物の熱容量が一般には異なるためである．
今回の実験式から得られた結果では， $\Delta H_T^0$ は温度 $T$ に対して直線的に変化する．
また，この反応の標準エンタルピー変化は対象温度範囲で正の値であり，炭酸カルシウムの熱分解が吸熱反応であることとも整合する．
