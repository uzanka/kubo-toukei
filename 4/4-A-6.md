# 演習問題【4-A-6】

## 解答

気液平衡における圧力と温度の関係は，クラペイロンの式

```math
\frac{dp_s}{dT}
=\frac{L}{T(V_g-V_l)}
```

で与えられる．
ここで， $p_s$ は液体の飽和蒸気圧， $L$ はモル当たりの気化潜熱， $V_g$ は気相のモル体積， $V_l$ は液相のモル体積， $T$ は絶対温度である．

### 1．液相の体積を無視する近似

条件 (a) より，温度は臨界温度から十分に離れており，飽和蒸気圧は十分に低い．
このとき，気相のモル体積は液相のモル体積よりもはるかに大きく，

```math
V_g\gg V_l
```

とみなせる．
したがって，

```math
V_g-V_l\simeq V_g
```

であるから，クラペイロンの式は

```math
\frac{dp_s}{dT}\simeq\frac{L}{TV_g}
\tag{1}
```

となる．

### 2．蒸気を理想気体とみなす近似

飽和蒸気圧が十分に低いので，蒸気を理想気体と近似する．
理想気体の状態方程式をモル量で表すと，

```math
p_sV_g=RT
```

である．
よって，

```math
V_g=\frac{RT}{p_s}
```

となる．
これを式 (1) に代入すると，

```math
\frac{dp_s}{dT}
\simeq\frac{L}{T}\frac{p_s}{RT}
=\frac{Lp_s}{RT^2}
```

を得る．
両辺を $p_s$ で割り，温度に関する微分方程式を変数分離すると，

```math
\frac{dp_s}{p_s}
=\frac{L}{RT^2}\,dT
\tag{2}
```

となる．

### 3．潜熱一定の条件のもとで積分する

条件 (b) より，考える温度範囲では気化潜熱 $L$ を一定とみなせる．
また，気体定数 $R$ も定数であるため，式 (2) の両辺を積分すると，

```math
\int\frac{dp_s}{p_s}
=\frac{L}{R}\int T^{-2}\,dT
```

である．
したがって，

```math
\ln p_s=-\frac{L}{RT}+C
```

となる．
ここで， $C$ は積分定数である．
両辺の指数をとると，

```math
p_s=\exp(C)\exp\left(-\frac{L}{RT}\right)
```

を得る．
$\exp(C)$ は温度によらない定数であるため，比例定数 $A$ とおけば，

```math
p_s=A\exp\left(-\frac{L}{RT}\right)
```

と書ける．

ゆえに，求める関係は

```math
\boxed{
p_s\propto\exp\left(-\frac{L}{RT}\right)
}
```

である．
