# 演習問題【4-A-22】

## 解答

### 証明

#### 1. 平衡条件の導出

体積 $V$ ，温度 $T$ で一定に保たれた系において，成分 $j$ の物質量を $n_j$ とすると，系の状態はヘルムホルツ自由エネルギー $F(V, T, \{n_j\})$ によって記述される．
等温・等容条件下での自発的な変化は，ヘルムホルツ自由エネルギーが減少する方向に進み，平衡状態ではその値が極小となる．
したがって，反応の進行度 $\lambda$ に対する平衡条件は次のように書ける．

$$\left( \frac{\partial F}{\partial \lambda} \right)_{V,T} = 0 \quad \cdots (\text{A})$$

ここで，各成分 $j$ の物質量の変化 $\delta n_j$ は，反応式における化学量論係数 $\nu_j$ を用いて，反応進行度 $\delta \lambda$ と次のように結び付けられる．

$$\delta n_j = \nu_j \delta \lambda$$

（例：反応物 $\text{A}$ については $\nu_{\text{A}} = -a$ ，生成物 $\text{L}$ については $\nu_{\text{L}} = l$ となる）

全自由エネルギーの変化 $\delta F$ は，各成分の物質量の変化に伴う変化の総和として，

$$\delta F = \sum_j \left( \frac{\partial F}{\partial n_j} \right)_{V,T} \delta n_j$$

と表される．
これに $\delta n_j = \nu_j \delta \lambda$ を代入すると，

$$\delta F = \sum_j \left( \frac{\partial F}{\partial n_j} \right)_{V,T} \nu_j \delta \lambda = \left( \sum_j \nu_j \left( \frac{\partial F}{\partial n_j} \right)_{V,T} \right) \delta \lambda$$

となる．
これを式 $(\text{A})$ に適用すると，平衡条件は次のように得られる．

$$\sum_j \nu_j \left( \frac{\partial F}{\partial n_j} \right)_{V,T} = 0 \quad \cdots (1)$$

ここで，化学ポテンシャル $`\overline{G}_j`$ を $`\overline{G}_j = \left( \frac{\partial F}{\partial n_j} \right)_{V,T}`$ と定義すると，平衡条件は $`\sum_j \nu_j \overline{G}_j = 0`$ となる．

#### 2. 理想気体の化学ポテンシャルの利用

理想気体の成分 $j$ の化学ポテンシャル $\overline{G}_j$ は，濃度 $c_j = n_j/V$ を用いて次のように表される．

$$\overline{G}_j = \overline{G}_j^0(T) + RT \log\left(\frac{n_j RT}{V}\right) \quad \cdots (2)$$

ここで， $\overline{G}_j^0(T)$ は標準状態における化学ポテンシャルである．

式 $(1)$ に式 $(2)$ を代入する．

$$\sum_j \nu_j \left[ \overline{G}_j^0(T) + RT \log\left(\frac{n_j RT}{V}\right) \right] = 0$$

括弧を展開して整理すると，

$$\sum_j \nu_j \overline{G}_j^0(T) + RT \sum_j \nu_j \log\left(\frac{n_j RT}{V}\right) = 0$$

$$RT \sum_j \nu_j \log\left(\frac{n_j RT}{V}\right) = -\sum_j \nu_j \overline{G}_j^0(T)$$

両辺を $RT$ で割る．

$$\sum_j \nu_j \log\left(\frac{n_j RT}{V}\right) = -\frac{\sum_j \nu_j \overline{G}_j^0(T)}{RT}$$

対数の性質 $\sum \log(x_j) = \log(\prod x_j)$ および $a \log(x) = \log(x^a)$ を用いると，

$$\log \left[ \prod_j \left( \frac{n_j RT}{V} \right)^{\nu_j} \right] = -\frac{\sum_j \nu_j \overline{G}_j^0(T)}{RT}$$

両辺の指数をとると，

$$\prod_j \left( \frac{n_j RT}{V} \right)^{\nu_j} = \exp\left[ -\frac{\sum_j \nu_j \overline{G}_j^0(T)}{RT} \right]$$

左辺を整理する．

$$\prod_j \left( \frac{n_j}{V} \cdot RT \right)^{\nu_j} = \left( \prod_j \left( \frac{n_j}{V} \right)^{\nu_j} \right) \cdot (RT)^{\sum_j \nu_j} = \exp\left[ -\frac{\sum_j \nu_j \overline{G}_j^0(T)}{RT} \right]$$

したがって，

$$\prod_j \left( \frac{n_j}{V} \right)^{\nu_j} = (RT)^{-\sum_j \nu_j} \exp\left[ -\frac{\sum_j \nu_j \overline{G}_j^0(T)}{RT} \right]$$

右辺の全ての項は，温度 $T$ と定数（化学量論係数 $\nu_j$ や標準化学ポテンシャル $\overline{G}_j^0(T)$ ）のみに依存するため，これは温度 $T$ だけの関数となる．
これを $K_c(T)$ とおけば，

$$K_c(T) = \prod_j \left( \frac{n_j}{V} \right)^{\nu_j} = \frac{[\text{L}]^l [\text{M}]^m \cdots}{[\text{A}]^a [\text{B}]^b \cdots}$$

となり，題意は証明された．

## 解説

### 重要な概念の整理

1.  **ヘルムホルツ自由エネルギー ( $F$ )**:
  等温・等容条件における系の「利用可能なエネルギー」を表す．
  この系が自然に変化する際，この値が最小になる場所が「平衡状態」である．
2.  **化学ポテンシャル ( $\overline{G}_j$ )**:
  ある成分 $j$ の物質量をわずかに増やしたときに，自由エネルギーがどれだけ変化するかを表す指標である．
3.  **化学量論係数 ( $\nu_j$ )**:
  反応式における各物質の係数である．
  反応物（減るもの）にはマイナスの符号，生成物（増えるもの）にはプラスの符号を割り当てる．
4.  **理想気体の化学ポテンシャル**:
  粒子が互いに干渉しない理想的な状況では，化学ポテンシャルは濃度（単位体積あたりのモル数）の対数に比例して変化する．

### 証明のポイント

この問題の核心は，「平衡条件（ $\sum \nu_j \overline{G}_j = 0$ ）」という微視的なエネルギーのバランスの関係を，「濃度を用いた式（ $K_c$ ）」というマクロな定数の関係へと変換することにある．

式変形のプロセスでは，対数関数の性質（和を積に変える，係数を指数に上げる）を駆使して， $\nu_j$ が含まれる複雑な和の形を，一つの積の形へと集約させている．
最終的に，右辺に現れる項がすべて $T$ に依存することを示すことで，濃度比の積が温度のみによって決まることを証明している．
