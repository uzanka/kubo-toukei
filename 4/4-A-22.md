# 演習問題【4-A-22】

## 解答

### 1．等温・等容条件における平衡条件

気体反応

```math
a\mathrm A+b\mathrm B+\cdots
\rightleftharpoons
l\mathrm L+m\mathrm M+\cdots
```

を考える．
系の体積 $V$ と温度 $T$ は一定である．
成分 $j$ の物質量を $n_j$ とし，ヘルムホルツ自由エネルギーを

```math
F=F(V,T,\{n_j\})
```

と表す．

等温・等容条件では，自発的な変化に伴ってヘルムホルツ自由エネルギー $F$ が減少し，平衡状態では $F$ が最小となる．
したがって，反応の進行度を $\lambda$ とすると，平衡条件は

```math
\left(\frac{\partial F}{\partial\lambda}\right)_{V,T}=0
\tag{1}
```

である．

反応の進行度 $\lambda$ が微小量 $\delta\lambda$ だけ変化すると，各成分の物質量は化学量論係数 $\nu_j$ に従って変化する．
すなわち，

```math
\delta n_j=\nu_j\delta\lambda
```

である．
反応物では物質量が減少するため $\nu_j<0$ ，生成物では物質量が増加するため $\nu_j>0$ とする．
具体的には，

```math
\nu_{\mathrm A}=-a,\quad
\nu_{\mathrm B}=-b,\quad
\nu_{\mathrm L}=l,\quad
\nu_{\mathrm M}=m
```

である．

自由エネルギーの微小変化は，

```math
\delta F
=\sum_j
\left(\frac{\partial F}{\partial n_j}\right)_{V,T}
\delta n_j
```

と表される．
ここで，成分 $j$ の化学ポテンシャルを

```math
\mu_j\equiv
\left(\frac{\partial F}{\partial n_j}\right)_{V,T}
```

と定義する．
これは，温度，体積およびほかの成分の物質量を一定に保ちながら成分 $j$ を微小量だけ増やしたときの，自由エネルギーの変化率である．

したがって，

```math
\begin{aligned}
\delta F
&=\sum_j\mu_j\nu_j\delta\lambda\\
&=\left(\sum_j\nu_j\mu_j\right)\delta\lambda
\end{aligned}
```

となる．
平衡では任意の微小な反応進行に対して一次の自由エネルギー変化がゼロであるから，

```math
\boxed{
\sum_j\nu_j\mu_j=0
}
\tag{2}
```

を得る．
反応物と生成物を具体的に書けば，

```math
-a\mu_{\mathrm A}
-b\mu_{\mathrm B}
+\cdots
+l\mu_{\mathrm L}
+m\mu_{\mathrm M}
+\cdots=0
```

である．
これが反応平衡の条件である．

### 2．理想気体の化学ポテンシャル

理想気体では，各成分の化学ポテンシャルはその分圧 $p_j$ を用いて，

```math
\mu_j=\mu_j^\circ(T)
+RT\ln\left(\frac{p_j}{p^\circ}\right)
\tag{3}
```

と表される．
ここで， $\mu_j^\circ(T)$ は標準状態における化学ポテンシャル， $p^\circ$ は一定の標準圧力である．
対数の中身を無次元にするため，分圧を標準圧力で割っている．

理想気体の状態方程式より，各成分の分圧は

```math
p_j=\frac{n_jRT}{V}
```

である．
単位体積あたりのモル数を

```math
c_j\equiv\frac{n_j}{V}
```

と定義すると，

```math
p_j=c_jRT
```

となる．
これを式 (3) に代入すれば，

```math
\mu_j
=\mu_j^\circ(T)
+RT\ln\left(\frac{c_jRT}{p^\circ}\right)
\tag{4}
```

を得る．
ここで $c_j$ は問題文の $[j]$ に相当する濃度である．

### 3．平衡条件から平衡定数を導く

式 (4) を平衡条件 (2) に代入すると，

```math
\sum_j\nu_j
\left[
\mu_j^\circ(T)
+RT\ln\left(\frac{c_jRT}{p^\circ}\right)
\right]=0
```

となる．
和を分けて整理すると，

```math
\sum_j\nu_j\mu_j^\circ(T)
+RT\sum_j\nu_j
\ln\left(\frac{c_jRT}{p^\circ}\right)=0
```

である．
したがって，

```math
\sum_j\nu_j
\ln\left(\frac{c_jRT}{p^\circ}\right)
=-\frac{\sum_j\nu_j\mu_j^\circ(T)}{RT}
\tag{5}
```

となる．

対数の性質

```math
\sum_j\nu_j\ln y_j
=\ln\left(\prod_j y_j^{\nu_j}\right)
```

を用いると，式 (5) は

```math
\ln\left[
\prod_j
\left(\frac{c_jRT}{p^\circ}\right)^{\nu_j}
\right]
=-\frac{\sum_j\nu_j\mu_j^\circ(T)}{RT}
```

と書き換えられる．
両辺の指数を取れば，

```math
\prod_j
\left(\frac{c_jRT}{p^\circ}\right)^{\nu_j}
=
\exp\left[
-\frac{\sum_j\nu_j\mu_j^\circ(T)}{RT}
\right]
\tag{6}
```

を得る．

左辺を濃度の積と温度に依存する因子に分けると，

```math
\left(\frac{RT}{p^\circ}\right)^{\sum_j\nu_j}
\prod_j c_j^{\nu_j}
=
\exp\left[
-\frac{\sum_j\nu_j\mu_j^\circ(T)}{RT}
\right]
```

である．
したがって，

```math
\boxed{
\prod_j c_j^{\nu_j}
=
\left(\frac{p^\circ}{RT}\right)^{\sum_j\nu_j}
\exp\left[
-\frac{\sum_j\nu_j\mu_j^\circ(T)}{RT}
\right]
}
\tag{7}
```

となる．
右辺は温度 $T$ ，標準状態および反応の化学量論係数だけで決まる．
体積や各成分の平衡濃度には依存しない．

ここで，反応物については $\nu_{\mathrm A}=-a$ ， $\nu_{\mathrm B}=-b$ ，生成物については $\nu_{\mathrm L}=l$ ， $\nu_{\mathrm M}=m$ であることに注意すると，

```math
\prod_j c_j^{\nu_j}
=
\frac{c_{\mathrm L}^{\,l}c_{\mathrm M}^{\,m}\cdots}
{c_{\mathrm A}^{\,a}c_{\mathrm B}^{\,b}\cdots}
```

となる．
問題文の記号 $c_j=[j]$ を用いれば，

```math
\boxed{
\frac{[\mathrm L]^l[\mathrm M]^m\cdots}
{[\mathrm A]^a[\mathrm B]^b\cdots}
=K_c(T)
}
```

と表せる．
ここで $K_c(T)$ は式 (7) の右辺に対応する温度の関数である．
よって，題意が証明された．

### 4．分圧で定義した平衡定数との関係

参考として，分圧を用いた平衡定数を

```math
K_p(T)\equiv\prod_j
\left(\frac{p_j}{p^\circ}\right)^{\nu_j}
```

と定義する．
理想気体の関係 $p_j=c_jRT$ より，

```math
\begin{aligned}
K_p(T)
&=\prod_j
\left(\frac{c_jRT}{p^\circ}\right)^{\nu_j}\\
&=\left(\frac{RT}{p^\circ}\right)^{\sum_j\nu_j}
K_c(T)
\end{aligned}
```

となる．
したがって，

```math
\boxed{
K_p(T)=
\left(\frac{RT}{p^\circ}\right)^{\Delta\nu}
K_c(T)
}
```

である．
ここで，

```math
\Delta\nu=\sum_j\nu_j
```

は生成物の化学量論係数の和から反応物の化学量論係数の和を引いた値である．

この関係から，濃度で定義した平衡定数と分圧で定義した平衡定数は一般に異なるが，理想気体ではどちらも温度だけで決まることが分かる．
