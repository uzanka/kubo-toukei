# 演習問題【4-A-10】

## 解答

### 1．容量性の性質から基本関係式を導く

$J$ は，成分1の物質量 $n_1$ と成分2の物質量 $n_2$ に依存する容量性の量である．
容量性とは，系の組成を変えずに物質量を一様に $\lambda$ 倍すると，その量も $\lambda$ 倍になる性質である．
したがって，圧力 $p$ と温度 $T$ を一定に保つと，

```math
J(\lambda n_1,\lambda n_2)
=\lambda J(n_1,n_2)
\tag{1}
```

が成り立つ．

式 (1) の両辺を $\lambda$ で微分する．
左辺は合成関数の微分法により，

```math
\begin{aligned}
\frac{d}{d\lambda}J(\lambda n_1,\lambda n_2)
={}&n_1\left(\frac{\partial J}{\partial n_1}\right)_{p,T,n_2}\\
&+n_2\left(\frac{\partial J}{\partial n_2}\right)_{p,T,n_1}
\end{aligned}
```

となる．
一方，右辺の微分は $J(n_1,n_2)$ である．
よって， $\lambda=1$ とおくと，

```math
J=n_1\left(\frac{\partial J}{\partial n_1}\right)_{p,T,n_2}
+n_2\left(\frac{\partial J}{\partial n_2}\right)_{p,T,n_1}
```

を得る．
ここで，

```math
J_1\equiv
\left(\frac{\partial J}{\partial n_1}\right)_{p,T,n_2},
\qquad
J_2\equiv
\left(\frac{\partial J}{\partial n_2}\right)_{p,T,n_1}
```

と定義すると，

```math
\boxed{
J=n_1J_1+n_2J_2
}
\tag{2}
```

となる．

### 2．モル分率を用いて $J$ を表す

全物質量を

```math
n=n_1+n_2
```

とし，第2成分のモル分率を

```math
x_2=\frac{n_2}{n_1+n_2}
```

と定義する．
すると，第1成分のモル分率は

```math
x_1=\frac{n_1}{n_1+n_2}=1-x_2
```

である．

式 (2) を全物質量 $n=n_1+n_2$ で割ると，

```math
\begin{aligned}
\frac{J}{n}
&=\frac{n_1}{n}J_1+\frac{n_2}{n}J_2\\
&=(1-x_2)J_1+x_2J_2
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
\frac{J}{n}=(1-x_2)J_1+x_2J_2
}
\tag{3}
```

である．

ただし， $J_1$ と $J_2$ は一般にモル分率 $x_2$ に依存するため，式 (3) だけから $J/n$ が $x_2$ の一次関数であるとは結論できない．
そこで，次に $x_2$ による微分を考える．

### 3．Gibbs–Duhem の関係式を導く

圧力 $p$ と温度 $T$ を一定に保ったとき， $J$ の全微分は，

```math
dJ=J_1\,dn_1+J_2\,dn_2
\tag{4}
```

である．

一方，式 (2) を全微分すると，積の微分法により，

```math
\begin{aligned}
dJ
&=d(n_1J_1+n_2J_2)\\
&=J_1\,dn_1+n_1\,dJ_1
  +J_2\,dn_2+n_2\,dJ_2
\end{aligned}
```

となる．
これを式 (4) と比較すると，共通する項が消去され，

```math
\boxed{
n_1\,dJ_1+n_2\,dJ_2=0
}
\tag{5}
```

を得る．
これが Gibbs–Duhem の関係式である．

この関係式は，圧力と温度が一定のもとでは， $J_1$ と $J_2$ の変化が独立ではないことを表している．

ここで，式 (5) を全物質量 $n=n_1+n_2$ で割ると，

```math
\frac{n_1}{n}dJ_1+\frac{n_2}{n}dJ_2=0
```

であるから，

```math
\boxed{
(1-x_2)dJ_1+x_2dJ_2=0
}
\tag{6}
```

となる．

圧力 $p$ と温度 $T$ を一定に保ちながら組成 $x_2$ を変化させるとき， $J_1$ と $J_2$ も $x_2$ に依存する．
したがって，

```math
dJ_1=\frac{dJ_1}{dx_2}\,dx_2,
\qquad
dJ_2=\frac{dJ_2}{dx_2}\,dx_2
```

である．
これらを式 (6) に代入し， $dx_2\neq0$ に対して整理すると，

```math
\boxed{
(1-x_2)\frac{dJ_1}{dx_2}
+x_2\frac{dJ_2}{dx_2}=0
}
\tag{7}
```

を得る．

### 4．グラフの接線の傾きを求める

式 (3) を $x_2$ で微分する．
積の微分法により，

```math
\begin{aligned}
\frac{d}{dx_2}\left(\frac{J}{n}\right)
={}&-J_1+(1-x_2)\frac{dJ_1}{dx_2}\\
&+J_2+x_2\frac{dJ_2}{dx_2}
\end{aligned}
```

となる．
これを整理すると，

```math
\begin{aligned}
\frac{d}{dx_2}\left(\frac{J}{n}\right)
={}&J_2-J_1\\
&+(1-x_2)\frac{dJ_1}{dx_2}
+x_2\frac{dJ_2}{dx_2}
\end{aligned}
```

である．
式 (7) より，第2行の2項の和はゼロである．
したがって，

```math
\boxed{
\frac{d}{dx_2}\left(\frac{J}{n}\right)
=J_2-J_1
}
\tag{8}
```

を得る．

グラフの縦軸を $y=J/n$ ，横軸を $x_2$ とする．
式 (8) は，任意の組成における曲線の接線の傾きが $J_2-J_1$ であることを示している．

点 P におけるモル分率を $x_2'$ とすると，P 点の座標は，

```math
P=\left(
x_2',
(1-x_2')J_1+x_2'J_2
\right)
```

である．
よって，点 P を通り，傾きが $J_2-J_1$ である接線 QPR の方程式は，

```math
\begin{aligned}
y={}&(1-x_2')J_1+x_2'J_2\\
&+(J_2-J_1)(x_2-x_2')
\end{aligned}
```

となる．
右辺を展開して整理すると，

```math
\begin{aligned}
y={}&J_1-x_2'J_1+x_2'J_2\\
&+(J_2-J_1)x_2-x_2'J_2+x_2'J_1\\
={}&J_1+(J_2-J_1)x_2
\end{aligned}
```

である．
したがって，接線の方程式は，

```math
\boxed{
y=J_1+(J_2-J_1)x_2
}
\tag{9}
```

となる．

### 5．$QO=J_1$ および $RO'=J_2$ を示す

まず，Q 点は接線 QPR と $x_2=0$ の直線との交点である．
式 (9) に $x_2=0$ を代入すると，

```math
y=J_1+(J_2-J_1)\cdot0=J_1
```

となる．
したがって，Q 点の座標は $(0,J_1)$ である．
原点 O の座標は $(0,0)$ であるから，

```math
\boxed{
QO=J_1
}
```

となる．

次に，R 点は接線 QPR と $x_2=1$ の直線との交点である．
式 (9) に $x_2=1$ を代入すると，

```math
\begin{aligned}
y&=J_1+(J_2-J_1)\cdot1\\
&=J_2
\end{aligned}
```

となる．
したがって，R 点の座標は $(1,J_2)$ である．
$O'$ の座標は $(1,0)$ であるから，

```math
\boxed{
RO'=J_2
}
```

となる．

以上より，

```math
\boxed{
QO=
\left(\frac{\partial J}{\partial n_1}\right)_{p,T,n_2}
=J_1
}
```

および

```math
\boxed{
RO'=
\left(\frac{\partial J}{\partial n_2}\right)_{p,T,n_1}
=J_2
}
```

が示された．


## 解説

本問題の要点は，容量性の性質から得られる式 (2) と，そこから導かれる Gibbs–Duhem の関係式を組み合わせることにある．

式 (3) の $J_1,J_2$ は組成に依存するため， $J/n$ は一般に一次関数ではない．
しかし，Gibbs–Duhem の関係式によって微分時に現れる追加項が相殺されるため，接線の傾きは $J_2-J_1$ と表される．
この結果，接線を $x_2=0$ まで延長したときの縦軸切片は $J_1$ ， $x_2=1$ まで延長したときの縦軸の値は $J_2$ となるのである．

なお，直線になるのは各点における接線であり，元の $J/n$ の曲線そのものが直線になるとは限らない．
また，線分の長さとしての等式は，図のように各切片が正の側にある場合の表記であり，符号が負になる場合には，有向線分または切片の絶対値として解釈する必要がある．
