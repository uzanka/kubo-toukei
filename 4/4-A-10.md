# 演習問題【4-A-10】

## 解答

### 1. 容量性（Extensive Property）の性質

まず，与えられた量 $J$ が「容量性（extensive property）」であるという性質について考える．
容量性とは，系のサイズ（物質量など）を $\lambda$ 倍にすると，その量も $\lambda$ 倍になる性質のことである．

問題文の定義より，物質量 $n_1, n_2$ を $\lambda$ 倍にすると，

$$J(\lambda n_1, \lambda n_2) = \lambda J(n_1, n_2) \quad \cdots (1)$$
が成り立つ．

この式を $\lambda$ について微分する．
左辺の微分は，多変数関数の連鎖律（チェインルール）を用いる．

$$\frac{\partial}{\partial \lambda} J(\lambda n_1, \lambda n_2) = \frac{\partial J}{\partial (\lambda n_1)} \cdot \frac{d(\lambda n_1)}{d\lambda} + \frac{\partial J}{\partial (\lambda n_2)} \cdot \frac{d(\lambda n_2)}{d\lambda} = \left( \frac{\partial J}{\partial (\lambda n_1)} \right) n_1 + \left( \frac{\partial J}{\partial (\lambda n_2)} \right) n_2$$

右辺の微分は，

$$\frac{d}{d\lambda} (\lambda J(n_1, n_2)) = J(n_1, n_2)$$

これらを等置して， $\lambda = 1$ とおくと，以下の関係が得られる．

$$J(n_1, n_2) = n_1 \left( \frac{\partial J}{\partial n_1} \right)_{n_2} + n_2 \left( \frac{\partial J}{\partial n_2} \right)_{n_1} \quad \cdots (2)$$

ここで， $J_1 \equiv \left( \frac{\partial J}{\partial n_1} \right)_{n_2}$ および $J_2 \equiv \left( \frac{\partial J}{\partial n_2} \right)_{n_1}$ と定義すると，

$$J = n_1 J_1 + n_2 J_2$$

となる．

### 2. モル分率とモル容量性

次に，系の全物質量を $n = n_1 + n_2$ とし，第2成分のモル分率を $x_2 = \frac{n_2}{n_1 + n_2}$ と定義する．
このとき， $x_1 = 1 - x_2 = \frac{n_1}{n_1 + n_2}$ である．

式(2)の両辺を $n = n_1 + n_2$ で割ると，

$$\frac{J}{n_1 + n_2} = \frac{n_1}{n_1 + n_2} J_1 + \frac{n_2}{n_1 + n_2} J_2 = (1 - x_2)J_1 + x_2 J_2 \quad \cdots (3)$$

が得られる．
これは，モル容量性の量がモル分率 $x_2$ の一次関数であることを示している．

### 3. Gibbs-Duhemの関係式

ここで，全微分 $dJ$ を考える．

$$dJ = \left( \frac{\partial J}{\partial n_1} \right)_{n_2} dn_1 + \left( \frac{\partial J}{\partial n_2} \right)_{n_1} dn_2 = J_1 dn_1 + J_2 dn_2 \quad \cdots (4)$$

一方で，式(2)を全微分すると，

$$dJ = d(n_1 J_1 + n_2 J_2) = (J_1 dn_1 + n_1 dJ_1) + (J_2 dn_2 + n_2 dJ_2) = (J_1 dn_1 + J_2 dn_2) + (n_1 dJ_1 + n_2 dJ_2)$$

となる．
式(4)と比較すると，以下の関係が導かれる．

$$n_1 dJ_1 + n_2 dJ_2 = 0 \quad \cdots (5)$$

これは「Gibbs-Duhem（ギブス・デュエム）の関係式」として知られている．

この式(5)は， $J_1$ と $J_2$ が独立に変化することはできず，モル分率の変化に伴って連動して変化しなければならないことを意味している．

これを用いると，式(3)の $x_2$ による微分は，

$$\frac{d}{dx_2} \left( \frac{J}{n} \right) = \frac{d}{dx_2} [ (1 - x_2)J_1 + x_2 J_2 ] = -J_1 + (1 - x_2) \frac{dJ_1}{dx_2} + J_2 + x_2 \frac{dJ_2}{dx_2} = (J_2 - J_1) + (1 - x_2) \frac{dJ_1}{dx_2} + x_2 \frac{dJ_2}{dx_2}$$

となるが，Gibbs-Duhemの関係により，この第2項以降は 0 になる．
（※詳細な導出は後述の解説を参照）
したがって，

$$\frac{d}{dx_2} \left( \frac{J}{n} \right) = J_2 - J_1 \quad \cdots (6)$$

となる．
これは，図のグラフの傾きが常に $(J_2 - J_1)$ で一定であることを示している．

### 4. 接線 QPR の方程式と $QO, RO'$ の導出

図において，点 P はモル分率 $x_2$ がある値 $x_2'$ のときの点である．
点 P における接線の傾きは，式(6)より $J_2 - J_1$ である．

接線 QPR の方程式を $y = f(x_2)$ とすると，点 P $(x_2', y_P)$ を通り，傾き $J_2 - J_1$ の直線の方程式は，

$$y - y_P = (J_2 - J_1)(x_2 - x_2')$$

ここで， $y_P$ は点 P における $J/n$ の値なので，式(3)より $y_P = (1 - x_2')J_1 + x_2'J_2$ である．
これを代入して整理すると，

$$y = (1 - x_2')J_1 + x_2'J_2 + (J_2 - J_1)x_2 - (J_2 - J_1)x_2'$$

$$y = J_1 - x_2'J_1 + x_2'J_2 + (J_2 - J_1)x_2 - x_2'J_2 + x_2'J_1$$

$$y = J_1 + (J_2 - J_1)x_2 \quad \cdots (7)$$

となる．

接線 QPR が $x_2 = 0$（y軸）と交わる点を Q とすると，式(7)に $x_2 = 0$ を代入して，

$$y = J_1$$

よって，点 Q の座標は $(0, J_1)$ である．
原点 O $(0,0)$ との距離は $QO = J_1$ となる．

接線 QPR が $x_2 = 1$ と交わる点を R とすると，式(7)に $x_2 = 1$ を代入して，

$$y = J_1 + (J_2 - J_1) \cdot 1 = J_2$$

よって，点 R の座標は $(1, J_2)$ である．
$x_2 = 1$ における y 軸上の点 O' $(1, 0)$ との距離は $RO' = J_2$ となる．

以上により，題意は示された．

## 解説

### 容量性 (Extensivity) と Gibbs-Duhem 関係式

熱力学において，物質量（mol）に比例して変化する量を「容量性（extensive）」と呼ぶ．
例えば，エネルギーや体積がこれに当たる．
逆に，物質量に依存しない量（比体積や温度など）を「示量性（intensive）」と呼ぶ．
本問題の $J_1, J_2$ は，成分1, 2の「化学ポテンシャル」のような，示量的な量 $J$ を物質量で割ったものであるため，示量的な性質を持つ．

Gibbs-Duhemの関係式 $n_1 dJ_1 + n_2 dJ_2 = 0$ は，示量的な量 $J$ が容量性であるという制約から自動的に導かれる非常に重要な関係式である．
これは，「ある成分の化学ポテンシャルが変化すれば，他の成分の化学ポテンシャルも，全系の平衡を保つように必ず変化しなければならない」という物理的な制約を数学的に表している．

### なぜグラフが直線になるのか

式(6)が示す通り，モル容量性の量 $J/n$ をモル分率 $x_2$ で微分すると，常に定数 $J_2 - J_1$ になる．
微分が定数であるということは，その関数が $x_2$ に関して一次関数であることを意味する．
したがって，どのような組成であっても，グラフ $y = (1-x_2)J_1 + x_2 J_2$ は一本の直線になる．
問題の図にある曲線は，実は「接線の集合」としての性質を議論するためのものであり，接線 QPR は常にこの直線の方程式と同じになる．

### 接線の意味

点 P における接線が，常に $x_2=0$ で $J_1$ を通り， $x_2=1$ で $J_2$ を通るということは，その接線の方程式が組成に関わらず一定であることを示している．
これは，成分の比率を変えても，各成分が持つ「単位物質量あたりの寄与（ $J_1, J_2$ ）」が変化しない限り，全体の平均的な値 $J/n$ は単純な加重平均で決まることを視覚的に示している．
