# 演習問題【4-B-40】

## 解答

### 1. 設定の整理

まず，問題の設定を整理する．
2つの部屋（I と II）があり，それらは半透膜で仕切られている．

*   **部屋 I (初期状態):**
    *   溶質: $\text{M}^+\text{X}^-$ 水溶液
    *   濃度: $[\text{M}^+] = [\text{X}^-] = x_1^0$
    *   溶液の体積: $1\text{L}$
*   **部屋 II (初期状態):**
    *   溶質: $\text{M}^+\text{R}^-$ 水溶液
    *   濃度: $[\text{M}^+] = [\text{R}^-] = x_2^0$
    *   溶液の体積: $1\text{L}$
*   **半透膜の性質:**
    *   $\text{M}^+$ イオン: 通す
    *   $\text{X}^-$ イオン: 通す
    *   $\text{R}^-$ イオン: **通さない**

### 2. 平衡状態における条件

拡散が進み，新しい平衡状態に達したときの各イオンの濃度を以下のように定義する．

*   **部屋 I における濃度:**
    *   $[\text{M}^+]_I = x_1'$
    *   $[\text{X}^-]_I = x_1'$ （電気的中性の条件より）
*   **部屋 II における濃度:**
    *   $[\text{M}^+]_{II} = x''_{\text{M}^+}$
    *   $[\text{X}^-]_{II} = x''_{\text{X}^-}$
    *   $[\text{R}^-]_{II} = x_2^0$ （ $\text{R}^-$ は膜を通らないため，濃度は変化しない）

ここで，以下の3つの物理的な原理に基づいた方程式を立てる．

#### (A) 電気的中性の条件

溶液は常に電気的に中性でなければならない．

*   **部屋 I:** $\text{M}^+$ と $\text{X}^-$ しかないため，
    $$x_1' = x_1' \quad (\text{これは自動的に満たされる})$$
    すなわち， $[\text{M}^+]_I = [\text{X}^-]_I$ である．
*   **部屋 II:** $\text{M}^+, \text{X}^-, \text{R}^-$ が存在するため，正電荷の総量と負電荷の総量が等しくなければならない．
    $$[\text{M}^+]_{II} = [\text{X}^-]_{II} + [\text{R}^-]_{II}$$
    $$x''_{\text{M}^+} = x''_{\text{X}^-} + x_2^0 \quad \cdots \text{(式1)}$$

#### (B) イオンの総量の保存

系全体のイオンの総量は，拡散前後で変わらない．

*   **$\text{X}^-$ イオンの総量:**
    部屋 I と II の $\text{X}^-$ の合計は，最初に部屋 I にあった量と等しい．
    $$x_1' + x''_{\text{X}^-} = x_1^0 \quad \cdots \text{(式2)}$$
*   **$\text{M}^+$ イオンの総量:**
    部屋 I と II の $\text{M}^+$ の合計は，最初に両方の部屋にあった量の合計と等しい．
    $$x_1' + x''_{\text{M}^+} = x_1^0 + x_2^0 \quad \cdots \text{(式3)}$$

#### (C) ドナン（Donnan）の膜平衡条件

$\text{M}^+$ と $\text{X}^-$ は膜を自由に通過できるため，平衡状態ではこれらのイオンによる $\text{M}^+\text{X}^-$ の化学ポテンシャルが両方の部屋で等しくなる．
理想希薄溶液の場合，これは以下の関係式で表される．

$$[\text{M}^+]_I \cdot [\text{X}^-]_I = [\text{M}^+]_{II} \cdot [\text{X}^-]_{II}$$

$$(x_1')^2 = x''_{\text{M}^+} \cdot x''_{\text{X}^-} \quad \cdots \text{(式4)}$$

### 3. 数学的導出

(式1), (式2), (式3), (式4) を用いて $x_1'$ と $x''_{\text{X}^-}$ を求める．

まず，(式3) に (式1) を代入して， $x_1'$ を $x''_{\text{X}^-}$ で表す．

$$x_1' + (x''_{\text{X}^-} + x_2^0) = x_1^0 + x_2^0$$

$$x_1' + x''_{\text{X}^-} = x_1^0$$

これは (式2) と一致しており，矛盾がないことが確認できる．
したがって，

$$x_1' = x_1^0 - x''_{\text{X}^-} \quad \cdots \text{(式5)}$$

次に，(式4) に (式1) と (式5) を代入する．

$$(x_1^0 - x''_{\text{X}^-})^2 = (x''_{\text{X}^-} + x_2^0) \cdot x''_{\text{X}^-}$$

左辺を展開する．

$$(x_1^0)^2 - 2x_1^0 x''_{\text{X}^-} + (x''_{\text{X}^-})^2 = (x''_{\text{X}^-})^2 + x_2^0 x''_{\text{X}^-}$$

両辺から $(x''_{\text{X}^-})^2$ を消去し，整理する．

$$(x_1^0)^2 = (2x_1^0 + x_2^0) x''_{\text{X}^-}$$

よって，部屋 II における $\text{X}^-$ の濃度 $x_2'$ は，

$$x_2' = x''_{\text{X}^-} = \frac{(x_1^0)^2}{2x_1^0 + x_2^0}$$

次に，部屋 I における濃度 $x_1'$ を求める．
(式5) に代入する．

$$x_1' = x_1^0 - \frac{(x_1^0)^2}{2x_1^0 + x_2^0}$$

$$x_1' = \frac{x_1^0(2x_1^0 + x_2^0) - (x_1^0)^2}{2x_1^0 + x_2^0}$$

$$x_1' = \frac{2(x_1^0)^2 + x_1^0 x_2^0 - (x_1^0)^2}{2x_1^0 + x_2^0}$$

$$x_1' = \frac{(x_1^0)^2 + x_1^0 x_2^0}{2x_1^0 + x_2^0} = \frac{x_1^0(x_1^0 + x_2^0)}{2x_1^0 + x_2^0}$$

### 答え

部屋 I における $\text{M}^+\text{X}^-$ の濃度 $x_1'$ は，

$$x_1' = \frac{x_1^0(x_1^0 + x_2^0)}{2x_1^0 + x_2^0}$$

部屋 II における $\text{M}^+\text{X}^-$ の濃度 $x_2'$ は，

$$x_2' = \frac{(x_1^0)^2}{2x_1^0 + x_2^0}$$

## 解説

この問題は，**ドナン効果（Donnan effect）**と呼ばれる現象を扱っている．

1.  **なぜ濃度が不均一になるのか？**
    もし全てのイオンが膜を通り抜けることができれば，最終的に両方の部屋の濃度は等しくなる．
    しかし，今回は $\text{R}^-$ イオンが膜を通り抜けることができない．
    この「片方の部屋にだけ存在するイオン」の存在が，電気的中性を保とうとする力と，拡散によって濃度を均一にしようとする力のバランスを崩し，結果として $\text{M}^+$ や $\text{X}^-$ の濃度に差を生じさせる．

2.  **電気的中性の重要性**
    溶液は常にプラスとマイナスの電荷が釣り合っている必要がある．
    部屋 II では，膜を通れない $\text{R}^-$ が負の電荷を持って居座っているため，それを打ち消すために，プラスの $\text{M}^+$ もマイナスの $\text{X}^-$ も，部屋 I よりも高い濃度で存在しなければならない．

3.  **化学平衡の考え方**
    「$\text{M}^+\text{X}^-$ の濃度が等しい」という直感的な考え方は，この問題では少し注意が必要である．
    化学平衡の条件は「$\text{M}^+$ の化学ポテンシャル」と「$\text{X}^-$ の化学ポテンシャル」がそれぞれ等しくなることである．
    理想溶液では，これは $[\text{M}^+][\text{X}^-]$ の積が両部屋で等しくなることを意味している．
