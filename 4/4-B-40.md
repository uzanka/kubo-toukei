# 演習問題【4-B-40】

## 解答

### 1．平衡状態における各イオンの濃度を定義する

半透膜で仕切られたI室とII室を考える．
初期状態では，I室には濃度 $x_1^0$ の $\mathrm{M^+X^-}$ 水溶液が $1\,\mathrm{L}$ ，II室には濃度 $x_2^0$ の $\mathrm{M^+R^-}$ 水溶液が $1\,\mathrm{L}$ 入っている．

$\mathrm{M^+}$ と $\mathrm{X^-}$ は膜を通過できるが， $\mathrm{R^-}$ は通過できない．
拡散後も各室の体積は $1\,\mathrm{L}$ のままと仮定する．

平衡状態における各イオンの濃度を次のように定義する．

- I室では， $\mathrm{M^+}$ と $\mathrm{X^-}$ の濃度はいずれも $x_1'$ とする．
- II室では， $\mathrm{X^-}$ の濃度を $x_1''$ とする．
- II室では， $\mathrm{R^-}$ の濃度は $x_2^0$ のままである．
- II室の $\mathrm{M^+}$ の濃度は，これから電気的中性の条件によって求める．

ここで $x_1'$ と $x_1''$ は，それぞれI室とII室における $\mathrm{M^+X^-}$ に対応する濃度である．
完全解離のため，この濃度は各室の $\mathrm{X^-}$ 濃度に一致する．

### 2．電気的中性の条件

溶液の巨視的な電荷はゼロでなければならない．
これを電気的中性の条件という．

I室には $\mathrm{M^+}$ と $\mathrm{X^-}$ のみが存在するため，

```math
[\mathrm{M^+}]_I=[\mathrm{X^-}]_I=x_1'
\tag{1}
```

である．

一方，II室には $\mathrm{M^+}$ ， $\mathrm{X^-}$ ， $\mathrm{R^-}$ が存在する．
正電荷の濃度と負電荷の濃度の合計が等しくなるため，

```math
[\mathrm{M^+}]_{II} = [\mathrm{X^-}]_{II}+[\mathrm{R^-}]_{II}
```

である．
したがって，

```math
\boxed{
[\mathrm{M^+}]\_{II}=x_1''+x_2^0
}
\tag{2}
```

となる．

### 3．イオンの物質量保存

次に，膜を通過できるイオンの物質量保存を考える．
各室の体積がともに $1\,\mathrm{L}$ であるため，各イオンの全物質量は，濃度を足し合わせることで表せる．

まず， $\mathrm{X^-}$ は初めI室にだけ存在し，初期濃度は $x_1^0$ である．
したがって，

```math
\boxed{
x_1'+x_1''=x_1^0
}
\tag{3}
```

である．
これを変形すると，

```math
\boxed{
x_1'=x_1^0-x_1''
}
\tag{4}
```

となる．

また， $\mathrm{M^+}$ は初めI室とII室の両方に存在するため，全物質量保存より，

```math
[\mathrm{M^+}]_I+[\mathrm{M^+}]_{II} =x_1^0+x_2^0
```

である．
式（1），（2）を代入すると，

```math
x_1'+x_1''+x_2^0=x_1^0+x_2^0
```

となる．
これは式（3）と同じ関係であり， $\mathrm{M^+}$ の物質量保存も満たされている．
したがって，独立に用いる必要のある物質量保存の式は式（3）である．

### 4．Donnan 膜平衡の条件

半透膜を通過できるイオンは，平衡状態では電気化学ポテンシャルが両室で等しくなる．
電気化学ポテンシャルとは，化学ポテンシャルに電場中での電気的な位置エネルギーを加えた量である．

イオン $i$ の電気化学ポテンシャルは，

```math
\widetilde{\mu}_i=\mu_i+z_iF\psi
```

と書ける．
ここで， $\mu_i$ は化学ポテンシャル， $z_i$ はイオンの電荷数， $F$ は Faraday 定数， $\psi$ は電位である．

$\mathrm{M^+}$ と $\mathrm{X^-}$ は電荷数がそれぞれ $+1$ ， $-1$ であるから，平衡条件は，

```math
\mu_{\mathrm{M^+},I}+F\psi_I = \mu_{\mathrm{M^+},II}+F\psi_{II}
\tag{5}
```

および

```math
\mu_{\mathrm{X^-},I}-F\psi_I = \mu_{\mathrm{X^-},II}-F\psi_{II}
\tag{6}
```

となる．
式（5）と式（6）を加えると，電位の項が打ち消し合い，

```math
\mu_{\mathrm{M^+},I}+\mu_{\mathrm{X^-},I} = \mu_{\mathrm{M^+},II}+\mu_{\mathrm{X^-},II}
\tag{7}
```

が得られる．

理想希薄溶液では，イオンの化学ポテンシャルは濃度の対数で表される．
すなわち，

```math
\mu_i=\mu_i^0+RT\ln c_i
\tag{8}
```

である．
ここで $c_i$ はイオン濃度であり， $\mu_i^0$ は標準化学ポテンシャルである．
同じイオンを同じ温度・圧力で比較しているため，標準化学ポテンシャルの項は左右で打ち消し合う．
式（7）に式（8）を代入すると，

```math
RT\ln\left( [\mathrm{M^+}]_I[\mathrm{X^-}]_I \right) = RT\ln\left( [\mathrm{M^+}]_{II}[\mathrm{X^-}]_{II} \right)
```

となる．
両辺を $RT$ で割り，指数関数に直すと，

```math
\boxed{
[\mathrm{M^+}]_I[\mathrm{X^-}]_I = [\mathrm{M^+}]_{II}[\mathrm{X^-}]_{II}
}
\tag{9}
```

を得る．
これが，本問で用いる Donnan 膜平衡の条件である．

式（1），（2）を式（9）に代入すると，

```math
\boxed{
(x_1')^2=(x_1''+x_2^0)x_1''
}
\tag{10}
```

となる．

### 5．連立方程式を解く

式（4）より，

```math
x_1'=x_1^0-x_1''
```

である．
これを式（10）に代入すると，

```math
(x_1^0-x_1'')^2 =(x_1''+x_2^0)x_1''
```

となる．
左辺を展開すると，

```math
(x_1^0)^2-2x_1^0x_1''+(x_1'')^2 =(x_1'')^2+x_2^0x_1''
```

である．
両辺から $(x_1'')^2$ を消去し， $x_1''$ について整理すると，

```math
(x_1^0)^2=(2x_1^0+x_2^0)x_1''
```

を得る．
したがって，II室の濃度は，

```math
\boxed{
x_1''=\frac{(x_1^0)^2}{2x_1^0+x_2^0}
}
\tag{11}
```

である．

次に，式（4）に代入してI室の濃度を求めると，

```math
\begin{aligned}
x_1' &=x_1^0-\frac{(x_1^0)^2}{2x_1^0+x_2^0}\\
&=\frac{x_1^0(2x_1^0+x_2^0)-(x_1^0)^2} {2x_1^0+x_2^0}\\
&=\frac{(x_1^0)^2+x_1^0x_2^0} {2x_1^0+x_2^0}.
\end{aligned}
```

よって，

```math
\boxed{
x_1'=\frac{x_1^0(x_1^0+x_2^0)}{2x_1^0+x_2^0}
}
\tag{12}
```

である．

## 3．最終結果

求める濃度は，次のとおりである．

```math
\boxed{
\begin{aligned}
x_1'&=\frac{x_1^0(x_1^0+x_2^0)} {2x_1^0+x_2^0},\\
x_1''&=\frac{(x_1^0)^2} {2x_1^0+x_2^0}.
\end{aligned}
}
```

また，両者の比をとると，

```math
\boxed{
\frac{x_1'}{x_1''} =1+\frac{x_2^0}{x_1^0} =\frac{x_1^0+x_2^0}{x_1^0}
}
```

である．
したがって，I室とII室に分配される $\mathrm{M^+X^-}$ に対応する濃度の比は，

```math
\boxed{
x_1':x_1''=(x_1^0+x_2^0):x_1^0
}
```

となる．

### 4．物理的な意味

$x_2^0>0$ の場合，式（11），（12）から，

```math
x_1'>x_1''
```

である．
つまり，透過可能な $\mathrm{X^-}$ は，II室よりI室に高い濃度で存在する．
一方，II室では膜を通れない $\mathrm{R^-}$ が存在するため，電気的中性を保つために，

```math
[\mathrm{M^+}]_{II}=x_1''+x_2^0
```

となり， $\mathrm{M^+}$ はII室に多く存在する．

このように，Donnan 平衡では，膜を通過できるイオンが単純に両室で同じ濃度になるわけではない．
電気的中性の条件と，イオンの電気化学ポテンシャルが平衡で等しくなる条件を同時に満たすように，各イオンの濃度が決まるのである．
