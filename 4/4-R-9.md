# 例題【4-R-9】

## 解答

**1. 質量作用の法則と分圧の関係**

金属蒸気の熱電離反応を次のように考える：

$$\text{A} \rightleftharpoons \text{A}^+ + \text{e}$$

電離度を $\alpha$ とすると，初期の $\text{A}$ の物質量を $1 \, \text{mol}$ としたとき，平衡状態における各成分の物質量は以下のようになる：
- $\text{A}$ の物質量： $1 - \alpha \, [\text{mol}]$
- $\text{A}^+$ の物質量： $\alpha \, [\text{mol}]$
- $\text{e}$ の物質量： $\alpha \, [\text{mol}]$

全物質量は $(1 - \alpha) + \alpha + \alpha = 1 + \alpha \, [\text{mol}]$ である．
理想気体の混合物において，各成分の分圧 $p_i$ は，全圧 $p$ と各成分のモル比を用いて次のように表される：

$$p_{\text{A}} = \frac{1 - \alpha}{1 + \alpha} p, \quad p_{\text{A}^+} = \frac{\alpha}{1 + \alpha} p, \quad p_{\text{e}} = \frac{\alpha}{1 + \alpha} p$$

質量作用の法則より，平衡定数 $K_p$ は次のように書ける：

$$K_p = \frac{p_{\text{A}^+} p_{\text{e}}}{p_{\text{A}}} = \frac{\left( \frac{\alpha}{1+\alpha} p \right) \left( \frac{\alpha}{1+\alpha} p \right)}{\frac{1-\alpha}{1+\alpha} p} = \frac{\alpha^2}{1-\alpha^2} p \quad \cdots (1)$$

**2. 標準自由エネルギーと平衡定数の関係**

平衡定数 $K_p$ と標準ギブズ自由エネルギー変化 $\Delta \bar{G}^\circ$ の間には，次の関係がある：

$$K_p = e^{-\Delta \bar{G}^\circ / RT} \quad \cdots (2)$$

ここで， $\Delta \bar{G}^\circ$ は反応の標準モルギブズ自由エネルギー変化である．
統計力学的な定義に基づくと，単原子理想気体の標準モルギブズ自由エネルギー $\bar{G}^\circ_j$ は，標準状態における分配関数 $Z^\circ_j$ を用いて次のように表される（ $N_A$ はアボガドロ定数）：

$$\bar{G}^\circ_j = -RT \ln \left( \frac{Z^\circ_j}{N_A} \right) + RT$$

反応 $\text{A} \to \text{A}^+ + \text{e}$ に対する $\Delta \bar{G}^\circ$ は：

$$\Delta \bar{G}^\circ = \bar{G}^\circ_{\text{A}^+} + \bar{G}^\circ_{\text{e}} - \bar{G}^\circ_{\text{A}}$$

$$\Delta \bar{G}^\circ = -RT \ln \left( \frac{Z^\circ_{\text{A}^+} Z^\circ_{\text{e}}}{N_A Z^\circ_{\text{A}}} \right) + RT \quad (\text{注: } \sum \nu_j = 1 \text{ より})$$

単原子理想気体の並進分配関数は $Z_{trans} \propto T^{3/2}$ であるため，全分配関数 $Z = Z_{trans} \cdot i$ ( $i$ は内部自由度，ここでは電子の分配関数) を用いると，

$$\frac{Z^\circ_{\text{A}^+} Z^\circ_{\text{e}}}{N_A Z^\circ_{\text{A}}} \propto \frac{T^{3/2} \cdot T^{3/2}}{T^{3/2}} \cdot \frac{i_{\text{A}^+} i_{\text{e}}}{i_{\text{A}}} = T^{3/2} \frac{i_{\text{A}^+} i_{\text{e}}}{i_{\text{A}}}$$

これを用いると， $\Delta \bar{G}^\circ$ は次のように書ける：

$$\Delta \bar{G}^\circ = -RT \left( \frac{3}{2} \ln T + \ln (\text{const}) + \ln \frac{i_{\text{A}^+} i_{\text{e}}}{i_{\text{A}}} \right) + RT$$

$$\Delta \bar{G}^\circ = -\frac{3}{2} RT \ln T - RT \ln \frac{i_{\text{A}^+} i_{\text{e}}}{i_{\text{A}}} + \text{const}'$$

ここで，電離エネルギー $W$ を含めた形として，解答例に従うと：

$$\Delta \bar{G}^\circ = W - \frac{5}{2} RT \ln T - RT (i_{\text{A}^+} + i_{\text{e}} - i_{\text{A}}) \quad (\text{注: } i_j \text{は } \ln(\text{電子分配関数}) \text{ と定義})$$

*(注: 係数 $5/2$ は，分圧を用いた平衡定数 $K_p$ と数密度を用いた定数の関係 $K_p = K_n \cdot kT$ から生じる．)*

**3. $\alpha$ の温度・圧力依存性の導出**

式 (1) と 式 (2) より：

$$\frac{\alpha^2}{1-\alpha^2} p = e^{-\Delta \bar{G}^\circ / RT}$$

$\Delta \bar{G}^\circ$ に先ほどの形を代入すると：

$$\frac{\alpha^2}{1-\alpha^2} p = \exp \left( -\frac{W - \frac{5}{2} RT \ln T - RT (i_{\text{A}^+} + i_{\text{e}} - i_{\text{A}})}{RT} \right)$$

$$\frac{\alpha^2}{1-\alpha^2} p = \exp \left( -\frac{W}{RT} + \frac{5}{2} \ln T + (i_{\text{A}^+} + i_{\text{e}} - i_{\text{A}}) \right)$$

$$\frac{\alpha^2}{1-\alpha^2} p \propto T^{5/2} e^{-W/RT}$$

よって，求める関係式が得られた．

## 解説

この問題は，**質量作用の法則**（化学平衡）と**統計力学的な分配関数**を組み合わせて，電離度 $\alpha$ の依存性を導出するものである．

### ポイント1：質量作用の法則と分圧

平衡状態では，反応物と生成物の「反応商」が一定の値（平衡定数）をとる．
気相反応の場合，通常は分圧を用いた平衡定数 $K_p$ を用いる．
問題文にある $\alpha$ を用いて，各成分の分圧を全圧 $p$ とモル比から書き下ろすのが最初のステップである．

### ポイント2：温度依存性の由来 ( $T^{5/2}$ )

なぜ $T^{3/2}$ ではなく $T^{5/2}$ になるのかという点は，非常に重要である．
- 統計力学的な「数密度（単位体積あたりの粒子数）」の比 $K_n = \frac{n_{\text{A}^+} n_{\text{e}}}{n_{\text{A}}}$ は，並進分配関数 $Z_{trans} \propto T^{3/2}$ の寄与により $T^{3/2}$ に比例する．
- 一方，我々が求めるのは分圧を用いた平衡定数 $K_p$ である．
- 理想気体の状態方程式 $p = nkT$ より， $p \propto nT$ である．
- 分圧の比と数密度の比の関係は， $K_p = \frac{p_{\text{A}^+} p_{\text{e}}}{p_{\text{A}}} = \frac{(n_{\text{A}^+} kT) (n_{\text{e}} kT)}{n_{\text{A}} kT} = \left( \frac{n_{\text{A}^+} n_{\text{e}}}{n_{\text{A}}} \right) kT$ となる．
- したがって， $K_p \propto T^{3/2} \cdot T = T^{5/2}$ となるのである．

### ポイント3：物理的意味

結果として得られた $\frac{\alpha^2}{1-\alpha^2} p \propto T^{5/2} e^{-W/RT}$ は，**サハの電離式 (Saha equation)** と呼ばれるものに相当する．
- $e^{-W/RT}$ の項は，温度が上がると熱エネルギーによって電離が指数関数的に促進されることを示している．
- $T^{5/2}$ の項は，温度上昇に伴うエントロピー増大（自由体積の拡大や運動状態の増加）の寄与を表している．

このように，温度 $T$ が上昇すると電離度 $\alpha$ は著しく増大することがわかる．
