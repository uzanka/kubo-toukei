# 例題【4-R-9】

## 解答

## 1．電離度と各成分の分圧の関係

金属蒸気の電離反応は，

```math
\mathrm A\rightleftharpoons\mathrm{A^+}+e
\tag{1}
```

である．
電離度 $\alpha$ は，初めに存在した中性原子のうち，電離した原子の割合である．
初めに $\mathrm A$ が1 mol存在したとすると，平衡状態における各成分の物質量は，

```math
\begin{aligned}
n_{\mathrm A}&=1-\alpha,\\
n_{\mathrm{A^+}}&=\alpha,\\
n_e&=\alpha
\end{aligned}
\tag{2}
```

となる．
したがって，全物質量は

```math
n_{\mathrm{total}}=(1-\alpha)+\alpha+\alpha=1+\alpha
\tag{3}
```

である．

理想気体の混合物では，各成分の分圧は，全圧 $p$ に各成分のモル分率を掛けたものである．
よって，

```math
\boxed{
\begin{aligned}
p_{\mathrm A}&=\frac{1-\alpha}{1+\alpha}p,\\
p_{\mathrm{A^+}}&=\frac{\alpha}{1+\alpha}p,\\
p_e&=\frac{\alpha}{1+\alpha}p
\end{aligned}
}
\tag{4}
```

となる．

## 2．質量作用の法則を適用する

反応 $\mathrm A\rightleftharpoons\mathrm{A^+}+e$ に対する質量作用の法則は，平衡定数を用いて，

```math
K^\circ= \frac{(p_{\mathrm{A^+}}/p^\circ)(p_e/p^\circ)} {p_{\mathrm A}/p^\circ}
\tag{5}
```

と書ける．
ここで $p^\circ$ は標準圧力であり， $K^\circ$ は無次元の平衡定数である．
式（5）を整理すると，

```math
p^\circ K^\circ =\frac{p_{\mathrm{A^+}}p_e}{p_{\mathrm A}}
\tag{6}
```

となる．

式（4）を代入すると，

```math
\begin{aligned}
\frac{p_{\mathrm{A^+}}p_e}{p_{\mathrm A}} &= \frac{ \left(\dfrac{\alpha}{1+\alpha}p\right) \left(\dfrac{\alpha}{1+\alpha}p\right) }{ \dfrac{1-\alpha}{1+\alpha}p }\\
&=\frac{\alpha^2}{(1+\alpha)(1-\alpha)}p\\
&=\frac{\alpha^2}{1-\alpha^2}p.
\end{aligned}
\tag{7}
```

したがって，

```math
\boxed{
\frac{\alpha^2}{1-\alpha^2}p=p^\circ K^\circ
}
\tag{8}
```

が得られる．
以下では，右辺の標準圧力を含む定数を比例定数に吸収し，解答例と同じ形に整理する．

## 3．標準 Gibbs 自由エネルギーから平衡定数を求める

平衡定数と反応の標準 Gibbs 自由エネルギー変化の間には，

```math
\boxed{
K^\circ=\exp\left(-\frac{\Delta_rG^\circ}{RT}\right)
}
\tag{9}
```

という関係がある．
ここで $R$ は気体定数， $T$ は絶対温度， $\Delta_rG^\circ$ は電離反応の標準モル Gibbs 自由エネルギー変化である．

内部自由度の寄与を省略すると，教科書で用いられる標準 Gibbs 自由エネルギーの式は，

```math
\bar G_j^\circ =U_{0j}-\frac52RT\ln T-RTi_j
\tag{10}
```

と書ける．
ここで $U_{0j}$ は基準内部エネルギー， $i_j$ は温度によらない定数である．
式（10）の $\ln T$ は，基準温度による規格化を省略した表記である．

電離反応の標準 Gibbs 自由エネルギー変化は，生成物の標準 Gibbs 自由エネルギーの和から，反応物の標準 Gibbs 自由エネルギーを引いたものである．
したがって，

```math
\Delta_rG^\circ =\bar G_{\mathrm{A^+}}^\circ +\bar G_e^\circ-\bar G_{\mathrm A}^\circ
\tag{11}
```

である．
式（10）を代入すると，

```math
\begin{aligned}
\Delta_rG^\circ ={}&U_{0\mathrm{A^+}}+U_{0e}-U_{0\mathrm A}\\
&-\frac{5}{2}RT\ln T\\
&-RT(i_{\mathrm{A^+}}+i_e-i_{\mathrm A})
\end{aligned}
\tag{12}
```

となる．

電離反応に必要な1 mol 当たりの電離エネルギーを $W$ とすると，

```math
U_{0\mathrm{A^+}}+U_{0e}-U_{0\mathrm A}=W
\tag{13}
```

である．
よって，

```math
\boxed{
\begin{aligned}
\Delta_rG^\circ ={}&W-\frac{5}{2}RT\ln T\\
&-RT(i_{\mathrm{A^+}}+i_e-i_{\mathrm A})
\end{aligned}
}
\tag{14}
```

を得る．

## 4．電離度の温度・圧力依存性を導く

式（9），（14）から，

```math
\begin{aligned}
K^\circ &=\exp\left(-\frac{\Delta_rG^\circ}{RT}\right)\\
&=\exp\left[ -\frac{W}{RT} +\frac{5}{2}\ln T +i_{\mathrm{A^+}}+i_e-i_{\mathrm A} \right].
\end{aligned}
```

したがって，温度に依存しない因子を定数にまとめれば，

```math
\boxed{
K^\circ\propto T^{5/2} \exp\left(-\frac{W}{RT}\right)
}
\tag{15}
```

となる．
式（8）に代入し，標準圧力などの定数もまとめると，

```math
\boxed{
\frac{\alpha^2}{1-\alpha^2}p =C\,T^{5/2} \exp\left(-\frac{W}{RT}\right)
}
\tag{16}
```

を得る．
ここで $C$ は，内部状態の寄与や標準圧力などを含む，温度に依存しない正の比例定数である．
これが求める質量作用の関係式である．

さらに，右辺を

```math
P_{\ast}(T)=C\,T^{5/2}\exp\left(-\frac{W}{RT}\right)
\tag{17}
```

とおく．
式（16）は，

```math
\frac{\alpha^2}{1-\alpha^2}p=P_{\ast}(T)
```

である．
これを $\alpha$ について解くと，

```math
p\alpha^2=P_{\ast}(T)(1-\alpha^2)
```

より，

```math
\alpha^2[p+P_{\ast}(T)]=P_{\ast}(T)
```

となる．
したがって，

```math
\boxed{
\alpha= \left[ \frac{P_{\ast}(T)}{p+P_{\ast}(T)} \right]^{1/2}
}
\tag{18}
```

である．
これにより，電離度の温度および圧力依存性が明示された．

## 5．温度と圧力が電離度に及ぼす影響

式（17）から，

```math
\ln P_{\ast}(T)=\ln C+\frac{5}{2}\ln T-\frac{W}{RT}
```

である．
したがって，

```math
\frac{d\ln P_{\ast}}{dT} =\frac{5}{2T}+\frac{W}{RT^2}>0
\tag{19}
```

となる．
よって，電離エネルギー $W>0$ のもとで $P_{\ast}(T)$ は温度とともに増加する．
式（18）より，圧力を一定に保てば，温度が上昇するほど電離度 $\alpha$ は増大する．

一方，温度を一定にして式（18）を見ると，圧力 $p$ が増加するほど分母が大きくなるため，電離度 $\alpha$ は減少する．
すなわち，温度が一定ならば，圧力が高いほど電離は抑制される．

特に，電離度が小さく，

```math
\alpha\ll1
```

と近似できる場合には，

```math
1-\alpha^2\simeq1
```

であるから，式（16）は

```math
\alpha^2p \simeq C\,T^{5/2}\exp\left(-\frac{W}{RT}\right)
```

となる．
したがって，

```math
\boxed{
\alpha\propto T^{5/4}p^{-1/2} \exp\left(-\frac{W}{2RT}\right) \qquad(\alpha\ll1)
}
\tag{20}
```

を得る．
この式から，弱電離の範囲では，電離度は温度とともに増加し，圧力の平方根に反比例することが直接分かる．

## 6．結論

質量作用の法則と標準 Gibbs 自由エネルギーの関係を用いると，

```math
\boxed{
\frac{\alpha^2}{1-\alpha^2}p \propto T^{5/2}\exp\left(-\frac{W}{RT}\right)
}
```

が得られる．
したがって，温度一定では圧力が高いほど電離度は小さくなり，圧力一定では温度が高いほど電離度は大きくなる．
電離度が十分に小さい場合には，

```math
\boxed{
\alpha\propto T^{5/4}p^{-1/2} \exp\left(-\frac{W}{2RT}\right)
}
```

と近似できる．
これが，本問で求める熱電離の温度・圧力依存性である．
