# 演習問題【4-B-42】

## 解答

### 1．問題の設定と浸透圧の式

半透膜は水， $\mathrm{M^+}$ ， $\mathrm{X^-}$ を通過させるが， $\mathrm{R^-}$ は通過させないものとする．
膜の両側をI室，II室とし，初めに純水が入っている側をI室， $\mathrm{M^+R^-}$ 水溶液が入っている側をII室とする．
電解質 $\mathrm{M^+X^-}$ はII室に添加する．
添加された塩は完全に解離し，膜を通過する両イオンが同じ標準状態で扱えるものとする．

前問と同様に，平衡状態で両室の水の物質量は等しく，それぞれ $n_w$ とする．
水のモル体積を $\bar V$ とし，理想希薄溶液近似により，各室の溶液体積を $n_w\bar V$ と近似する．
また，イオンの標準化学ポテンシャルに対する静水圧差の補正と，膜への選択的な分配効果は無視する．

各イオンの物質量を，その室に含まれる水の物質量 $n_w$ で割った無次元量を $x_i$ と定義する．すなわち，

```math
x_i=\frac{n_i}{n_w}
```

である．
したがって，溶質イオンの通常のモル濃度 $c_i$ は，

```math
c_i\simeq\frac{x_i}{\bar V}
```

となる．
以下では，各室のイオン濃度をこの無次元濃度比 $x_i$ で表す．

II室に初めから存在する，膜を通過できない $\mathrm{R^-}$ の濃度比を $x_2^0$ ，添加した $\mathrm{M^+X^-}$ の初期濃度比を $x_1^0$ とする．
添加した塩の陽イオンと陰イオンの初期濃度比は，それぞれ $x_1^0$ である．

平衡状態における各イオンの濃度比を次のように表す．

- I室の $\mathrm{M^+}$ ， $\mathrm{X^-}$ の濃度比を，ともに $x_1'$ とする．
- II室の $\mathrm{X^-}$ の濃度比を $x_1''$ とする．
- II室の $\mathrm{R^-}$ の濃度比は，膜を通過できないため $x_2^0$ である．

各室のバルク溶液は電気的中性を満たす．
したがってI室では，

```math
x_{\mathrm{M},I}=x_{\mathrm{X},I}=x_1'
\tag{1}
```

である．
II室では，

```math
x_{\mathrm{M},II}
=
x_{\mathrm{X},II}+x_{\mathrm{R},II}
=x_1''+x_2^0
\tag{2}
```

となる．

ここで，浸透圧 $\pi$ を，II室とI室の静水圧差 $p_{II}-p_I$ とする．
理想希薄溶液では van't Hoff の式により，浸透圧は溶質粒子の濃度の総和に比例する．
したがって，

```math
\begin{aligned}
\pi
=\frac{RT}{\bar V}
\bigl[
&x_{\mathrm{M},II}
+x_{\mathrm{X},II}
+x_{\mathrm{R},II}\\
&-x_{\mathrm{M},I}
-x_{\mathrm{X},I}
\bigr]
\end{aligned}
\tag{3}
```

で表される．
ここで $R$ は気体定数， $T$ は絶対温度である．
各イオンを独立した溶質粒子として数えている．

### 2．Donnan 平衡から各イオンの濃度を求める

#### 2.1 物質量保存

$\mathrm{X^-}$ は膜を通過できるが，系全体から失われない．
両室の水の物質量が等しいため，添加した $\mathrm{X^-}$ の全物質量の保存から，

```math
x_1'+x_1''=x_1^0
\tag{4}
```

となる．
したがって，

```math
x_1'=x_1^0-x_1''
\tag{5}
```

である．

なお， $\mathrm{M^+}$ の全物質量も保存される．
初期の総量は $n_w(x_1^0+x_2^0)$ であり，平衡後には，

```math
n_w\left(x_1'+x_1''+x_2^0\right)
=n_w(x_1^0+x_2^0)
```

となるため，この条件とも整合する．

#### 2.2 電気化学ポテンシャルによる Donnan 平衡条件

膜を通過できる荷電イオンが平衡にあるとき，各イオンについて等しくなるのは，化学ポテンシャル単独ではなく，電気化学ポテンシャルである．

イオン $i$ の電気化学ポテンシャルは，

```math
\widetilde{\mu}_i
=
\mu_i^0+RT\ln a_i+z_iF\phi
```

で表される．
ここで， $\mu_i^0$ は標準化学ポテンシャル， $a_i$ は活量， $z_i$ は価数， $F$ は Faraday 定数， $\phi$ は電位である．

両室の温度は等しく，イオンの標準化学ポテンシャルは等しいとする．
膜を通過できる $\mathrm{M^+}$ と $\mathrm{X^-}$ の平衡条件は，

```math
\widetilde{\mu}_{\mathrm{M},I}
=
\widetilde{\mu}_{\mathrm{M},II}
```

```math
\widetilde{\mu}_{\mathrm{X},I}
=
\widetilde{\mu}_{\mathrm{X},II}
```

である．
これらを展開すると，

```math
RT\ln\frac{a_{\mathrm{M},I}}{a_{\mathrm{M},II}}
+F(\phi_I-\phi_{II})=0
```

```math
RT\ln\frac{a_{\mathrm{X},I}}{a_{\mathrm{X},II}}
-F(\phi_I-\phi_{II})=0
```

となる．
この2式を加えると電位差の項が相殺され，

```math
RT\ln
\frac{
a_{\mathrm{M},I}a_{\mathrm{X},I}
}{
a_{\mathrm{M},II}a_{\mathrm{X},II}
}
=0
```

を得る．
したがって，

```math
a_{\mathrm{M},I}a_{\mathrm{X},I}
=
a_{\mathrm{M},II}a_{\mathrm{X},II}
```

である．
理想希薄溶液では活量は濃度に比例するため，

```math
\boxed{
x_{\mathrm{M},I}x_{\mathrm{X},I}
=
x_{\mathrm{M},II}x_{\mathrm{X},II}
}
\tag{6}
```

が成立する．
これが Donnan 平衡の濃度積の関係である．

#### 2.3 各イオン濃度の決定

式 (1)，(2)，(6) を用いると，

```math
(x_1')^2=(x_1''+x_2^0)x_1''
\tag{7}
```

となる．
さらに，式 (5) を代入すると，

```math
(x_1^0-x_1'')^2
=
(x_1''+x_2^0)x_1''
```

である．
両辺を展開して整理すれば，

```math
(x_1^0)^2
=
(2x_1^0+x_2^0)x_1''
```

を得る．
したがって，

```math
\boxed{
x_1''=
\frac{(x_1^0)^2}{2x_1^0+x_2^0}
}
\tag{8}
```

となる．

式 (5) よりI室の濃度比は，

```math
\boxed{
x_1'=
\frac{x_1^0(x_1^0+x_2^0)}
{2x_1^0+x_2^0}
}
\tag{9}
```

である．

したがって，各室のイオン濃度比は，

```math
\begin{aligned}
x_{\mathrm{M},I}
&=x_{\mathrm{X},I}
=\frac{x_1^0(x_1^0+x_2^0)}
{2x_1^0+x_2^0},\\
x_{\mathrm{X},II}
&=\frac{(x_1^0)^2}{2x_1^0+x_2^0},\\
x_{\mathrm{R},II}
&=x_2^0,\\
x_{\mathrm{M},II}
&=\frac{(x_1^0+x_2^0)^2}{2x_1^0+x_2^0}.
\end{aligned}
\tag{10}
```

### 3．浸透圧を求める

式 (3) に式 (1)，(2) を代入すると，

```math
\begin{aligned}
\frac{\pi\bar V}{RT}
&=(x_1''+x_2^0)+x_1''+x_2^0-2x_1'\\
&=2(x_1''+x_2^0-x_1')
\end{aligned}
\tag{11}
```

となる．

式 (8)，(9) より，

```math
\begin{aligned}
x_1''+x_2^0-x_1'
&=
\frac{(x_1^0)^2}{2x_1^0+x_2^0}
+x_2^0
-\frac{x_1^0(x_1^0+x_2^0)}
{2x_1^0+x_2^0}\\
&=
\frac{x_2^0(x_1^0+x_2^0)}
{2x_1^0+x_2^0}
\end{aligned}
\tag{12}
```

となる．
したがって，浸透圧は，

```math
\boxed{
\pi=
\frac{RT}{\bar V}
\frac{2x_2^0(x_1^0+x_2^0)}
{2x_1^0+x_2^0}
}
\tag{13}
```

である．

### 4．添加前の値と比較する

まず， $\mathrm{M^+X^-}$ を加えない場合を考える．
このとき，II室には $\mathrm{M^+}$ と $\mathrm{R^-}$ がそれぞれ $x_2^0$ 存在し，I室は純水である．
したがって，

```math
\boxed{
\pi_0=\frac{RT}{\bar V}\,2x_2^0
}
\tag{14}
```

となる．

式 (13) と式 (14) の比をとると，

```math
\boxed{
\frac{\pi}{\pi_0}
=
\frac{x_1^0+x_2^0}
{2x_1^0+x_2^0}
}
\tag{15}
```

である．
$x_1^0>0$ ， $x_2^0>0$ ならば，

```math
0<
\frac{x_1^0+x_2^0}
{2x_1^0+x_2^0}
<1
```

であるから，

```math
\boxed{\pi<\pi_0}
```

となる．
すなわち，膜を通過できる電解質 $\mathrm{M^+X^-}$ を加えると浸透圧は減少する．

さらに，添加量 $x_1^0$ に対して式 (13) を微分すると，

```math
\boxed{
\frac{d\pi}{dx_1^0}
=
-\frac{RT}{\bar V}
\frac{2(x_2^0)^2}
{(2x_1^0+x_2^0)^2}
<0
}
\tag{16}
```

となる．
したがって， $x_2^0>0$ のもとで，浸透圧は添加量の増加に対して単調に減少する．

式 (13) の数学的な極限は，

```math
\lim_{x_1^0\to\infty}\pi
=
\frac{RT}{\bar V}x_2^0
=
\frac{\pi_0}{2}
\tag{17}
```

である．
ただし，これは理想希薄溶液モデルを形式的に外挿した数学的極限である．
実際の溶液では $x_1^0\to\infty$ とすると希薄溶液近似が成立しなくなる．
物理的には，希薄性を保ちながら $x_1^0\gg x_2^0$ となる濃度範囲で，浸透圧が添加前の値の約半分に近づくと解釈する．

### 5．なぜ浸透圧が減少するのか

添加前は，膜を通過できない $\mathrm{R^-}$ がII室に存在する．
その負電荷を打ち消すため，対イオンである $\mathrm{M^+}$ もII室に存在する．
したがって，II室には $\mathrm{M^+}$ と $\mathrm{R^-}$ という2種類の溶質粒子があり，浸透圧は $2x_2^0$ に比例する．

ここに $\mathrm{M^+X^-}$ を加えると，両イオンが膜を通過できるため，両室の電気的中性と電気化学ポテンシャルの平衡条件を満たすように再分配される．
その結果，Donnan 電位が生じ，透過可能な陽イオンと陰イオンの濃度分布が変化する．

実際に，透過可能なイオンだけについて両室の粒子濃度差を計算すると，

```math
\begin{aligned}
&\left(
x_{\mathrm{M},II}+x_{\mathrm{X},II}
\right)
-\left(
x_{\mathrm{M},I}+x_{\mathrm{X},I}
\right)\\
&\qquad=
\frac{(x_2^0)^2}{2x_1^0+x_2^0}
\end{aligned}
\tag{18}
```

となる．
これは $x_1^0$ の増加とともに減少し，ゼロに近づく．

一方，膜を通過できない $\mathrm{R^-}$ の濃度差は常に $x_2^0$ である．
したがって，添加量が大きくなると，透過可能なイオンによる粒子濃度差の寄与が小さくなり，浸透圧差は主に膜を通過できない $\mathrm{R^-}$ の寄与によって決まる．
このため，理想希薄溶液モデルの形式的な極限では，浸透圧は添加前の値の半分となる．

以上より，膜を通過できる電解質を加えると，Donnan 平衡による透過可能なイオンの再分配によって両室の全溶質粒子濃度の差が小さくなり，浸透圧が減少する．
