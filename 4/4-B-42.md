# 演習問題【4-B-42】

## 解答

### 1．問題の設定と浸透圧の式

$\mathrm{R^-}$ は通過できないが， $\mathrm{M^+}$ と $\mathrm{X^-}$ は通過できる半透膜を考える．
膜の一方には $\mathrm{M^+R^-}$ 水溶液があり，これに膜を通過できる電解質 $\mathrm{M^+X^-}$ を加える．

前問と同様に，膜の両側の体積は等しく，溶液は理想希薄溶液で近似できるとする．
添加した $\mathrm{M^+X^-}$ の量を濃度に換算した値を $x_1^0$ ，膜を通過できない $\mathrm{R^-}$ の濃度を $x_2^0$ とする．
濃度と物質量の関係は，前問と同じように扱うことができる．

平衡状態におけるイオン濃度を次のように表す．

- I室の $\mathrm{M^+}$ と $\mathrm{X^-}$ の濃度を，ともに $x_1'$ とする．
- II室の $\mathrm{X^-}$ の濃度を $x_1''$ とする．
- II室の $\mathrm{R^-}$ の濃度は，膜を通過できないため $x_2^0$ である．

溶液は各室で電気的中性を満たさなければならない．I室では，

```math
[\mathrm{M^+}]_I=[\mathrm{X^-}]_I=x_1'
\tag{1}
```

である．
II室では， $\mathrm{R^-}$ の負電荷を含めて電気的中性を満たすため，

```math
[\mathrm{M^+}]_{II}=x_1''+x_2^0
\tag{2}
```

となる．

理想希薄溶液では，浸透圧は溶質粒子の濃度に比例する．
水のモル体積を $\bar V$ とすると，両室の浸透圧差は

```math
\pi=\frac{RT}{\bar V} \left[ [\mathrm{M^+}]_{II}+[\mathrm{X^-}]_{II} +[\mathrm{R^-}]_{II} -[\mathrm{M^+}]_I-[\mathrm{X^-}]_I \right]
\tag{3}
```

で表される．
ここで $R$ は気体定数， $T$ は絶対温度である．

### 2．Donnan 平衡から各イオンの濃度を求める

まず， $\mathrm{X^-}$ は膜を通過でき，添加した塩に由来する総量が保存されるため，

```math
x_1'+x_1''=x_1^0
\tag{4}
```

である．
したがって，

```math
x_1'=x_1^0-x_1''
\tag{5}
```

となる．

次に，Donnan 平衡の条件を用いる．
理想希薄溶液では，膜を通過できる陽イオンと陰イオンの化学ポテンシャルをそれぞれの室で等しくすると，濃度の積について

```math
[\mathrm{M^+}]_I[\mathrm{X^-}]_I = [\mathrm{M^+}]_{II}[\mathrm{X^-}]_{II}
\tag{6}
```

が得られる．

式（1），（2）を代入すると，

```math
(x_1')^2=(x_1''+x_2^0)x_1''
\tag{7}
```

である．
さらに，式（5）を代入すると，

```math
(x_1^0-x_1'')^2=(x_1''+x_2^0)x_1''
```

となる．
両辺を展開して整理すれば，

```math
(x_1^0)^2=(2x_1^0+x_2^0)x_1''
```

を得る．
よって，

```math
\boxed{
x_1''=\frac{(x_1^0)^2}{2x_1^0+x_2^0}
}
\tag{8}
```

である．
式（5）からI室の濃度も求められる．

```math
\boxed{
x_1'=\frac{x_1^0(x_1^0+x_2^0)} {2x_1^0+x_2^0}
}
\tag{9}
```

したがって，II室の各イオンの濃度は，

```math
\begin{aligned}
[\mathrm{X^-}]_{II}&=x_1'',\\
[\mathrm{R^-}]_{II}&=x_2^0,\\
[\mathrm{M^+}]_{II}&=x_1''+x_2^0
\end{aligned}
\tag{10}
```

となる．

### 3．浸透圧を求める

式（3）に式（1），（2）を代入すると，

```math
\begin{aligned}
\frac{\pi\bar V}{RT} &=(x_1''+x_2^0)+x_1''+x_2^0-2x_1'\\
&=2(x_1''+x_2^0-x_1')
\end{aligned}
\tag{11}
```

となる．
ここに式（8），（9）を代入して整理すると，

```math
\begin{aligned}
x_1''+x_2^0-x_1' &=\frac{(x_1^0)^2}{2x_1^0+x_2^0} +x_2^0 -\frac{x_1^0(x_1^0+x_2^0)}{2x_1^0+x_2^0}\\
&=\frac{x_2^0(x_1^0+x_2^0)} {2x_1^0+x_2^0}.
\end{aligned}
\tag{12}
```

よって，浸透圧は

```math
\boxed{
\pi=\frac{RT}{\bar V} \frac{2x_2^0(x_1^0+x_2^0)} {2x_1^0+x_2^0}
}
\tag{13}
```

となる．
これが，膜を通過できる電解質 $\mathrm{M^+X^-}$ を加えたときの浸透圧である．

### 4．添加前の値と比較する

まず， $\mathrm{M^+X^-}$ を加えない場合を考える．
このとき $\mathrm{X^-}$ は存在せず，溶液側には $\mathrm{M^+}$ と $\mathrm{R^-}$ が濃度 $x_2^0$ で存在する．
反対側は純水であるため，理想希薄溶液の近似では，

```math
\boxed{
\pi_0=\frac{RT}{\bar V}\\,2x_2^0
}
\tag{14}
```

となる．

式（13）と式（14）の比をとると，

```math
\boxed{
\frac{\pi}{\pi_0} =\frac{x_1^0+x_2^0}{2x_1^0+x_2^0}
}
\tag{15}
```

である．
$x_1^0>0$ ならば，

```math
\frac{x_1^0+x_2^0}{2x_1^0+x_2^0}<1
```

であるから，

```math
\pi<\pi_0
```

となる．
すなわち， $\mathrm{M^+X^-}$ を加えると浸透圧は減少する．

さらに，添加量 $x_1^0$ について式（13）を微分すると，

```math
\boxed{
\frac{d\pi}{dx_1^0} =-\frac{RT}{\bar V} \frac{2(x_2^0)^2}{(2x_1^0+x_2^0)^2}<0
}
\tag{16}
```

である．
したがって，浸透圧は添加量の増加に対して単調に減少する．

添加量を十分に大きくすると，

```math
\lim_{x_1^0\to\infty}\pi =\frac{RT}{\bar V}x_2^0 =\frac{\pi_0}{2}
\tag{17}
```

となる．
つまり，浸透圧は添加前の値の半分に近づくのである．

## 3．なぜ浸透圧が減少するのか

添加前は，膜を通過できない $\mathrm{R^-}$ が溶液側に存在する．
その負電荷を打ち消すための $\mathrm{M^+}$ も溶液側に存在するので，溶液側には $\mathrm{M^+}$ と $\mathrm{R^-}$ という2種類の溶質粒子がある．
そのため，浸透圧は $2x_2^0$ に比例する．

ここに $\mathrm{M^+X^-}$ を加えると， $\mathrm{M^+}$ と $\mathrm{X^-}$ が膜を通過できるため，両イオンは電気的中性と Donnan 平衡の条件を満たすように再分配される．
この結果，透過可能なイオンの濃度差が浸透圧に与える正味の寄与は小さくなる．

実際に，透過可能なイオンの濃度差の和は，

```math
\begin{aligned}
&\left([\mathrm{M^+}]_{II}+[\mathrm{X^-}]_{II}\right) -\left([\mathrm{M^+}]_I+[\mathrm{X^-}]_I\right)\\
&\qquad=\frac{(x_2^0)^2}{2x_1^0+x_2^0}
\end{aligned}
\tag{18}
```

となり，添加量 $x_1^0$ が大きくなるほどゼロに近づく．
一方，膜を通過できない $\mathrm{R^-}$ の濃度差は常に $x_2^0$ である．
したがって，添加量が大きい極限では，浸透圧差は主に $\mathrm{R^-}$ の寄与によって決まり，添加前の半分になるのである．

以上より，膜を通過できる電解質を加えると，Donnan 平衡によって透過可能なイオンの分布が変化し，両室の全溶質粒子濃度の差が小さくなるため，浸透圧が減少することが説明された．
