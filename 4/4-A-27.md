# 演習問題【4-A-27】

## 解答

### 1．反応式と電子移動数

与えられた電池の正味の反応は，

```math
\mathrm{Ag(c)}+\frac12\mathrm{Hg_2Cl_2(c)}
\longrightarrow
\mathrm{AgCl(c)}+\mathrm{Hg(l)}
```

である．
ここで， $\mathrm{(c)}$ は固体結晶， $\mathrm{(l)}$ は液体を表す．

この反応において，銀 $\mathrm{Ag}$ は電子を1個放出して酸化される．
半反応式は，

```math
\mathrm{Ag(c)}+\mathrm{Cl^-}
\longrightarrow \mathrm{AgCl(c)}+e^-
```

と書ける．
一方，塩化水銀(I)は還元される．
対応する半反応式は，

```math
\frac12\mathrm{Hg_2Cl_2(c)}+e^-
\longrightarrow \mathrm{Hg(l)}+\mathrm{Cl^-}
```

である．
これらを加えると電子と塩化物イオンが相殺され，問題で与えられた正味の反応が得られる．

したがって，反応式における電子移動数は

```math
n=1
```

である．

### 2．ギブス自由エネルギー変化 $\Delta G$ を求める

電池の可逆起電力 $E$ と反応のギブス自由エネルギー変化 $\Delta G$ には，

```math
\Delta G=-nFE
```

という関係がある．
ここで， $F$ はファラデー定数であり，電子1 molが運ぶ電気量を表す定数である．
この式の負号は，起電力をもつ電池が自発的な反応によって電気的仕事を取り出せることに対応する．

解答例に合わせ，エネルギーをカロリー単位で計算するため，

```math
nF \simeq 23068\ 
\mathrm{cal\,V^{-1}}
```

を用いる．
これは，今回 $n=1$ であることを反映した換算係数である．
よって，

```math
\Delta G=-23068E
```

となる．
25°Cにおける起電力 $E=0.0455\ \mathrm{V}$ を代入すると，

```math
\begin{aligned}
\Delta G
&=-23068\times0.0455\\
&=-1049.594\\
&\simeq-1050\ \mathrm{cal}
\end{aligned}
```

である．

したがって，ギブス自由エネルギー変化は，

```math
\boxed{
\Delta G=-1050\ \mathrm{cal}
}
```

である．

なお，反応に関与する物質は純粋な固体および液体であり，その活量を1とみなせる．
したがって，この反応の自由エネルギー変化は，標準状態における反応の標準ギブス自由エネルギー変化に等しい．

### 3．エントロピー変化 $\Delta S$ を求める

ギブス自由エネルギー $G$ ，エンタルピー $H$ ，エントロピー $S$ の間には，

```math
G=H-TS
```

という関係がある．
温度 $T$ と圧力 $p$ が変化するとき，ギブス自由エネルギーの微分は，

```math
dG=V\,dp-S\,dT
```

と表される．
圧力を一定に保つと $dp=0$ であるため，

```math
\left(\frac{\partial G}{\partial T}\right)_p=-S
```

となる．
これを反応のギブス自由エネルギー変化に適用すると，

```math
\boxed{
\Delta S=-\left(\frac{\partial\Delta G}{\partial T}\right)_p
}
```

を得る．

前節で用いた起電力とギブス自由エネルギーの関係

```math
\Delta G=-nFE
```

において， $n$ と $F$ は温度によらない定数である．
したがって，温度 $T$ で微分すると，

```math
\begin{aligned}
\Delta S
&=-\left(\frac{\partial(-nFE)}{\partial T}\right)_p\\
&=nF\left(\frac{\partial E}{\partial T}\right)_p
\end{aligned}
```

となる．
今回は $n=1$ であり，カロリー単位の換算係数を用いると，

```math
\boxed{
\Delta S
=23068\left(\frac{\partial E}{\partial T}\right)_p
}
```

である．

問題で与えられた温度係数

```math
\left(\frac{\partial E}{\partial T}\right)_p
=0.000338\ \mathrm{V\,K^{-1}}
```

を代入すると，

```math
\begin{aligned}
\Delta S
&=23068\times0.000338\\
&=7.797\\
&\simeq7.80\ \mathrm{cal\,K^{-1}}
\end{aligned}
```

となる．

したがって，エントロピー変化は，

```math
\boxed{
\Delta S=7.80\ \mathrm{cal\,K^{-1}}
}
```

である．

### 4．エンタルピー変化 $\Delta H$ を求める

ギブス自由エネルギーの定義式

```math
\Delta G=\Delta H-T\Delta S
```

をエンタルピー変化について整理すると，

```math
\boxed{
\Delta H=\Delta G+T\Delta S
}
```

となる．
ここで，温度には必ず絶対温度を用いる．
25°Cは，

```math
T=25+273.16=298.16\ \mathrm{K}
```

である．
これまでに求めた値を代入すると，

```math
\begin{aligned}
\Delta H
&=-1050+298.16\times7.80\\
&=-1050+2325.648\\
&=1275.648\\
&\simeq1276\ \mathrm{cal}
\end{aligned}
```

である．

したがって，エンタルピー変化は，

```math
\boxed{
\Delta H=1276\ \mathrm{cal}
}
```

である．

### 答

25°C，1 atmにおける，問題の反応式に対応する熱力学量は，

```math
\boxed{
\Delta G=-1050\ \mathrm{cal}
}
```

```math
\boxed{
\Delta S=7.80\ \mathrm{cal\,K^{-1}}
}
```

```math
\boxed{
\Delta H=1276\ \mathrm{cal}
}
```

である．
ここで， $\Delta G$ はギブス自由エネルギー変化， $\Delta S$ はエントロピー変化， $\Delta H$ はエンタルピー変化を表す．
いずれも，問題の反応式に記載された化学量論量の反応あたりの値である．
