# 演習問題【4-A-9】

## 解答

### (i) A点で現れる溶液の組成

混合気体を一定圧力の下で冷却すると，露点曲線である実線上のA点に到達したとき，液相が初めて現れる．
このとき，気相と液相は同じ温度で平衡にあるため，両相の組成は同じ温度における露点曲線と沸点曲線から読み取ることができる．

A点から横軸に平行な直線を引き，沸点曲線である点線との交点を $A'$ とする．
A点で初めて現れる液相の組成は，この $A'$ の成分2のモル分率である．

したがって，求める組成は

```math
\boxed{
x_2^L=x_2(A')
}
```

である．

### (ii) C点の気相の組成

冷却を続けると，液相の割合が増加し，C点では気相が消失する直前の状態となる．
このときも，気相と液相は同じ温度で平衡にある．

C点から横軸に平行な直線を引き，露点曲線である実線との交点を $C'$ とする．
C点で最後に残る気相の組成は，この $C'$ の成分2のモル分率である．

したがって，求める組成は

```math
\boxed{
x_2^G=x_2(C')
}
```

である．

### (iii) B点における気相と液相の組成およびモル数比

#### 1．気相と液相の組成

B点は気液共存領域にあるため，気相と液相が同時に存在する．
B点と同じ温度で水平線を引くと，実線との交点が $B''$ ，点線との交点が $B'$ である．

したがって，気相の成分2のモル分率は $B''$ の横軸座標，液相の成分2のモル分率は $B'$ の横軸座標で与えられる．

```math
\boxed{
x_2^G=x_2(B''),\qquad x_2^L=x_2(B')
}
```

また，B点の横軸座標を混合物全体の成分2のモル分率 $x_2$ とする．

#### 2．気相と液相のモル数比

気相の全モル数を $N_G$ ，液相の全モル数を $N_L$ とする．
混合物全体のモル数は

```math
N=N_G+N_L
```

である．
成分2の物質収支より，混合物全体に含まれる成分2のモル数は，気相と液相に含まれる成分2のモル数の和に等しい．
したがって，

```math
N_Gx_2^G+N_Lx_2^L
=(N_G+N_L)x_2
```

となる．
右辺を展開して整理すると，

```math
N_G(x_2^G-x_2)
=N_L(x_2-x_2^L)
```

を得る．
よって，気相と液相のモル数比は

```math
\frac{N_G}{N_L}
=\frac{x_2-x_2^L}{x_2^G-x_2}
```

である．

ここで，B点の横軸座標を $x_2(B)$ と書けば，

```math
x_2=x_2(B),\qquad
x_2^L=x_2(B'),\qquad
x_2^G=x_2(B'')
```

である．
図の横軸上で $B'$ ，B，$B''$ がこの順に並んでいるため，

```math
x_2-x_2^L=BB'
```

および

```math
x_2^G-x_2=B''B
```

が成り立つ．
ここで線分の長さは，横軸上での座標の差を表す．
したがって，

```math
\boxed{
\frac{N_G}{N_L}
=\frac{BB'}{B''B}
}
```

となる．
すなわち，気相と液相のモル数比は

```math
\boxed{
N_G:N_L=BB':B''B
}
```

である．

以上より，B点における気相と液相の組成はそれぞれ $B''$ と $B'$ の横軸座標であり，両相のモル数比はレバー・ルールによって $BB':B''B$ と求められる．


## 解説

この方法はレバー・ルールと呼ばれる．
全体の組成は気相と液相の組成を各相のモル数で重み付けした平均であるため，全体の組成に近い相ほど多く存在する．
なお，実際の数値比を求めるには，相図上の各点の横軸座標または線分の長さが必要である．
