# 演習問題【4-A-9】

## 解答

### 前提条件

系は閉鎖系であり，冷却過程を通じて全体の物質量および各成分の物質量が保存されるものとする．
また，冷却は準静的に行われ，各温度において気液平衡が成立しているものとする．

気相における成分2のモル分率を $y_2^G$ ，液相における成分2のモル分率を $x_2^L$ ，混合物全体における成分2のモル分率を $z_2$ とする．

なお，相図の横軸は成分2のモル分率を表すものとする．

### (i) A点で現れる溶液の組成

混合気体を一定圧力のもとで冷却すると，露点曲線である実線上のA点に到達したとき，液相が初めて出現する．

このとき，A点は気液平衡における露点であり，A点の横軸座標は気相の成分2のモル分率を表す．

A点と同じ温度において水平線を引き，沸点曲線である点線との交点をA'とする．

A'の横軸座標は，A点の気相と平衡にある液相の成分2のモル分率を表す．

したがって，A点で初めて現れる溶液の組成は，

```math
\boxed{
x_2^L=x_{\mathrm{axis}}(A')
}
```

である．

### (ii) C点の気相の組成

冷却を続けると液相の割合が増加し，C点では気相が消失する直前の状態となる．

このとき，C点は気液平衡における泡点であり，C点の横軸座標は液相の成分2のモル分率を表す．

C点と同じ温度において水平線を引き，露点曲線である実線との交点をC'とする．

C'の横軸座標は，C点の液相と平衡にある気相の成分2のモル分率を表す．

したがって，C点で最後に残る気相の組成は，

```math
\boxed{
y_2^G=x_{\mathrm{axis}}(C')
}
```

である．

### (iii) B点における気相と液相の組成およびモル数比

#### 1．気相と液相の組成

B点は気液共存領域にあるため，気相と液相が同時に存在する．

B点と同じ温度において水平線を引くと，露点曲線である実線との交点がB''，沸点曲線である点線との交点がB'である．

したがって，気相の成分2のモル分率はB''の横軸座標，液相の成分2のモル分率はB'の横軸座標で与えられる．

よって，

```math
\boxed{
y_2^G=x_{\mathrm{axis}}(B'')
}
```

```math
\boxed{
x_2^L=x_{\mathrm{axis}}(B')
}
```

である．

また，B点の横軸座標は混合物全体の成分2のモル分率を表すため，

```math
\boxed{
z_2=x_{\mathrm{axis}}(B)
}
```

である．

#### 2．気相と液相のモル数比

気相の全モル数を $N_G$ ，液相の全モル数を $N_L$ ，混合物全体のモル数を $N$ とする．

気相と液相の2相のみが存在するため，全モル数について，

```math
N=N_G+N_L
```

が成り立つ．

次に，成分2の物質収支を考える．

混合物全体に含まれる成分2のモル数は，気相と液相に含まれる成分2のモル数の和に等しい．

したがって，

```math
Nz_2=N_Gy_2^G+N_Lx_2^L
```

となる．

ここに，

```math
N=N_G+N_L
```

を代入すると，

```math
(N_G+N_L)z_2
=N_Gy_2^G+N_Lx_2^L
```

となる．

右辺を整理すると，

```math
N_Gz_2+N_Lz_2
=N_Gy_2^G+N_Lx_2^L
```

よって，

```math
N_G(y_2^G-z_2)
=N_L(z_2-x_2^L)
```

を得る．

したがって，気相と液相のモル数比は，

```math
\boxed{
\frac{N_G}{N_L}
=
\frac{z_2-x_2^L}{y_2^G-z_2}
}
```

である．

ここで，B点の横軸座標と各相の組成との関係は，

```math
z_2=x_{\mathrm{axis}}(B)
```

```math
x_2^L=x_{\mathrm{axis}}(B')
```

```math
y_2^G=x_{\mathrm{axis}}(B'')
```

である．

図の横軸上でB'，B，B''がこの順に並んでいるため，

```math
z_2-x_2^L=BB'
```

および，

```math
y_2^G-z_2=B''B
```

が成り立つ．

ここで，線分の長さは横軸上における座標の差を表す．

したがって，

```math
\frac{N_G}{N_L}
=
\frac{BB'}{B''B}
```

となる．

よって，求める気相と液相のモル数比は，

```math
\boxed{
N_G:N_L=BB':B''B
}
```

である．

以上より，B点における気相と液相の組成は，それぞれB''とB'の横軸座標であり，両相のモル数比はレバー・ルールによって求められる．

## 解説

このように，気相と液相のモル数比を全体組成と各相の組成から求める方法をレバー・ルールという．

混合物全体の組成は，気相と液相の組成をそれぞれのモル数で重み付けした平均である．

すなわち，

```math
z_2=
\frac{N_Gy_2^G+N_Lx_2^L}
{N_G+N_L}
```

である．

この関係から，全体組成に近い組成を持つ相ほど，その相のモル数が多いことが分かる．

また，気相と液相のモル数比は，相図上の全体組成の位置と各相の組成の位置から，反対側の線分の長さの比として求められる．

なお，レバー・ルールは気液二相が共存し，両相の組成が異なる領域で適用する．
相の一方が消失する相境界では，その相のモル数はゼロとなる．

実際の数値比を求めるには，相図上の各点の横軸座標または線分の長さが必要である．
