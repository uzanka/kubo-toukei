# 演習問題【4-A-9】

## 解答

この問題は，一定の圧力の下で2成分系の混合物を冷却したときの，相変化に伴う組成変化と相の割合（モル比）を扱うものである．
図に示された温度 $T$ と成分2のモル分率 $x_2$ の関係図（相図）を用いて解いていく．

### 設定の整理

- **実線 (Solid line)**: 気相（蒸気）の組成を表す曲線（露点曲線）．
- **点線 (Dashed line)**: 液相（溶液）の組成を表す曲線（沸点曲線）．
- **冷却過程**: 混合気体の組成 $x_2$ は一定のまま，温度 $T$ を下げていく．
  これは，図上で垂直な直線（ $x_2$ が一定の線）に沿って，上から下へ移動することに対応する．
- **点 $P$**: 冷却を開始する前の，すべてが気相の状態．
- **点 $A$**: 冷却により，気相から液相が分離し始める点（露点）．
- **点 $C$**: すべての気相が液相に変化し，液相のみとなる点（沸点）．

### (i) $A$ 点で現れる溶液の組成

混合気体を冷却していくと，温度が下がり，気相の組成が露点曲線（実線）に接触する点 $A$ に到達する．
このとき，最初の液滴（溶液）が現れる．

この現れた液相は，その時点での気相と平衡状態にある．
平衡状態にある2つの相の組成は，同じ温度において，一方が実線上に，もう一方が点線上に位置しなければならない．

図において，点 $A$ は実線上にあり，その温度での液相の組成は，点 $A$ から水平に（ $x_2$ 軸に平行に）右図の点線へ引いた直線との交点である．
この交点を $A'$ とすると，現れた溶液の組成は，点 $A'$ の $x_2$ 座標で与えられる．

**答: 点 $A'$ の $x_2$ 座標**

### (ii) $C$ 点の気相の組成

さらに冷却を続けると，気相と液相が混在する領域を通って，点 $C$ に到達する．
点 $C$ は，最後に残った気相が消失する点であり，液相の組成が沸点曲線（点線）に接触する．

この点 $C$ において平衡状態にある気相の組成は，点 $C$ と同じ温度において，点線から水平に実線へと引いた直線との交点である．
この交点を $C'$ とすると，残っている気相の組成は，点 $C'$ の $x_2$ 座標で与えられる．

**答: 点 $C'$ の $x_2$ 座標**

### (iii) $B$ 点における気相と液相の組成およびその成分の比

点 $B$ は， $A$ 点と $C$ 点の間の，気相と液相が共存している領域にある．

#### 1. 組成

点 $B$ における混合物の組成は， $B$ 点の $x_2$ 座標である．
このとき，平衡状態にある各相の組成は以下の通りである．
- **気相の組成 ( $x_G$ )**: 点 $B$ から水平に実線（気相曲線）へ引いた直線との交点．
  図中の点 $B''$ の $x_2$ 座標．
- **液相の組成 ( $x_L$ )**: 点 $B$ から水平に点線（液相曲線）へ引いた直線との交点．
  図中の点 $B'$ の $x_2$ 座標．

#### 2. 成分（モル数）の比

気相のモル数を $N_G$ ，液相のモル数を $N_L$ とする．
混合物全体の成分2のモル分率を $x$ ，全体のモル数を $N = N_G + N_L$ とすると，成分2の物質収支（マスバランス）は次のように書ける．

$$N_G x_G + N_L x_L = (N_G + N_L) x$$

この式を整理して， $N_G$ と $N_L$ の比を求める．

$$N_G x_G + N_L x_L = N_G x + N_L x$$

$$N_G (x_G - x) = N_L (x - x_L)$$

$$\frac{N_G}{N_L} = \frac{x - x_L}{x_G - x}$$

図において，各点の $x_2$ 座標をそれぞれ $x_B, x_{B'}, x_{B''}$ とすると：
- $x = x_B$
- $x_L = x_{B'}$
- $x_G = x_{B''}$

したがって，

$$\frac{N_G}{N_L} = \frac{x_B - x_{B'}}{x_{B''} - x_B}$$

これは，図上の線分の長さの比に相当する．
- 分子 $x_B - x_{B'}$ は，点 $B$ と点 $B'$ の間の距離，すなわち線分 $B B'$ の長さである．
- 分母 $x_{B''} - x_B$ は，点 $B''$ と点 $B$ の間の距離，すなわち線分 $B'' B$ の長さである．

よって，気相と液相のモル数の比は $B B' : B'' B$ となる．

**答: 気相の組成は点 $B''$ の $x_2$ 座標，液相の組成は点 $B'$ の $x_2$ 座標，モル数の比は $B B' : B'' B$**

## 解説

### 相図の読み方

この問題で扱っているのは，**等圧下での冷却に伴う相平衡**である．
2成分系の相図において，ある温度 $T$ で組成が一定のまま冷却される場合，組成 $x$ は変化しないため，図上では垂直な線（等組成線）に沿って移動することになる．

- **露点曲線 (Dew point curve)**: 気体が凝縮し始める組成を示す．
  図では実線．
- **沸点曲線 (Bubble point curve)**: 液体が蒸発し始める組成を示す．
  図では点線．

### レバー・ルール (Lever Rule)

(iii) で用いた計算手法は，統計力学や熱力学で非常に重要な**レバー・ルール**と呼ばれるものである．
2相が共存しているとき，全体の組成 $x$ は，各相の組成 $x_i$ と，それらの存在量（モル数など）の加重平均として表される．

$$x = \sum w_i x_i$$

（ここで $w_i$ はその相の割合）

この関係から，相の存在比は「相手の組成との距離」に反比例することが導かれる．
つまり，全体の組成が液相の組成に近いほど，液相の割合が多くなるという直感的な結果が得られる．

### なぜ途中の式変形が重要か

(iii) の解答では，単に「図の長さの比」とするだけでなく，物質収支の式からその関係を導出した．
これにより，なぜ図の線分の比がモル数の比に対応するのかという物理的な根拠が明確になる．

$$N_G (x_G - x) = N_L (x - x_L)$$

この式は，**「成分2の過剰分が，もう一方の相にどれだけ分配されるか」**というバランスを表している．
