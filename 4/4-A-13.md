# 演習問題【4-A-13】

## 解答

### 1．Gibbs–Duhem の関係式を蒸気圧の関係式に変換する

溶媒を成分1，溶質を成分2とし，それぞれの化学ポテンシャルを $\bar G_1,\bar G_2$ ，モル分率を $x_1,x_2$ ，蒸気圧を $p_1,p_2$ とする．
温度 $T$ と液相の圧力 $p$ を一定に保つと，Gibbs–Duhem の関係式は

```math
x_1\,d\bar G_1+x_2\,d\bar G_2=0
\tag{1}
```

である．

液相と平衡にある蒸気相を理想気体とみなすと，温度一定での化学ポテンシャルの微小変化は，蒸気圧 $p_i$ を用いて

```math
d\bar G_i=RT\,d\log p_i
=RT\frac{dp_i}{p_i}
\tag{2}
```

と表される．
ここで， $R$ は気体定数である．
この関係を式(1)に代入し，両辺を $RT$ で割ると，

```math
x_1\frac{dp_1}{p_1}
+x_2\frac{dp_2}{p_2}=0
\tag{3}
```

を得る．
これが，化学ポテンシャルの Gibbs–Duhem の関係式を蒸気圧で表した式である．

### 2．Henry の法則を導く

問題の条件より，溶媒1は Raoult の法則

```math
p_1=x_1p_1^0
\tag{4}
```

に従う．
ここで， $p_1^0$ は温度 $T$ における純溶媒の蒸気圧であり，温度一定では定数である．
式(4)を微分すると，

```math
dp_1=p_1^0\,dx_1
```

である．
また， $p_1=x_1p_1^0$ より，

```math
\frac{dp_1}{p_1}=\frac{dx_1}{x_1}
\tag{5}
```

となる．

2成分系ではモル分率の和が1であるから，

```math
x_1+x_2=1
```

であり，これを微分すると，

```math
dx_1=-dx_2
\tag{6}
```

を得る．

式(5)，(6)を式(3)に代入すると，

```math
x_1\left(-\frac{dx_2}{x_1}\right)
+x_2\frac{dp_2}{p_2}=0
```

となる．
整理すれば，

```math
-dx_2+x_2\frac{dp_2}{p_2}=0
```

したがって，

```math
\frac{dp_2}{p_2}=\frac{dx_2}{x_2}
\tag{7}
```

である．

式(7)を積分すると，

```math
\int\frac{dp_2}{p_2}
=\int\frac{dx_2}{x_2}
```

より，

```math
\log p_2=\log x_2+C
```

を得る．
ここで， $C$ は温度一定のもとでの積分定数である．
両辺の指数を取ると，

```math
p_2=e^C x_2
```

となる．
$e^C$ を Henry 定数 $k_2$ とおけば，

```math
\boxed{
p_2=k_2x_2
}
\tag{4.29}
```

が得られる．
これが Henry の法則である．
この法則は，溶質のモル分率 $x_2$ が十分小さい希薄溶液の範囲で成り立つ．

### 3．溶質の化学ポテンシャルの式を導く

蒸気相を理想気体とみなすと，温度一定での化学ポテンシャルは，基準圧力 $p^\circ$ を用いて

```math
\bar G_2
=\bar G_2^\circ(T)
+RT\log\left(\frac{p_2}{p^\circ}\right)
\tag{8}
```

と表せる．
ここで， $\bar G_2^\circ(T)$ は基準状態における化学ポテンシャルであり， $p^\circ$ は一定の基準圧力である．
式(8)は，蒸気相と平衡にある溶質の化学ポテンシャルを表す式として用いる．

ここに，Henry の法則 $p_2=k_2x_2$ を代入すると，

```math
\bar G_2
=\bar G_2^\circ(T)
+RT\log\left(\frac{k_2x_2}{p^\circ}\right)
````

となる．
対数の性質を用いて整理すれば，

```math
\bar G_2
=\bar G_2^\circ(T)
+RT\log\left(\frac{k_2}{p^\circ}\right)
+RT\log x_2
\tag{9}
```

である．

ここで，組成 $x_2$ に依存しない項を

```math
\phi_2^0(T)
\equiv
\bar G_2^\circ(T)
+RT\log\left(\frac{k_2}{p^\circ}\right)
\tag{10}
```

と定義する．
温度一定のもとでは Henry 定数 $k_2$ と基準圧力 $p^\circ$ は定数であり， $\phi_2^0(T)$ は温度のみの関数として表される．
したがって，式(9)は

```math
\boxed{
\bar G_2=\phi_2^0(T)+RT\log x_2
}
\tag{4.30b}
```

となる．
これが求める溶質の化学ポテンシャルの式である．

## 解説

### 導出における近似について

上の導出では，液相の圧力 $p$ を一定とした Gibbs–Duhem の関係式を用いながら，液相と平衡にある蒸気相の蒸気圧 $p_1,p_2$ を変化させている．
厳密には，全圧力が $p=p_1+p_2$ である場合，組成変化に伴って全圧力も変化するため，液相の圧力を完全に一定とする条件とは両立しない場合がある．

解答例では，この圧力変化に由来する補正項が十分小さいとして無視している．
したがって，ここでの導出はその近似のもとで成立するものである．
この近似を採用すると，溶媒が希薄溶液の極限で Raoult の法則に従うことから，溶質は Henry の法則に従い，さらに溶質の化学ポテンシャルが $\log x_2$ に比例する項を含むことが導かれるのである．
