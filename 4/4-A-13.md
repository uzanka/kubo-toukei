# 演習問題【4-A-13】

## 解答

温度 $T$ および液相圧力 $p$ を一定に保ち，気相を理想気体とする．
また，液相と気相の間で各成分が相平衡にあるとする．
成分 $i$ の化学ポテンシャルについて，相平衡条件は

```math
\mu_i^L(T,p,x_i)=\mu_i^V(T,p_i)
```

である．
理想気体の化学ポテンシャルの微分は

```math
d\mu_i^V=RT\,d\ln p_i
```

で与えられる．

一方，液相に対するギブズ・デュエムの式は，温度と圧力を一定に保つと

```math
x_1d\mu_1^L+x_2d\mu_2^L=0
```

となる．
相平衡条件を用いると，

```math
RT\left(x_1d\ln p_1+x_2d\ln p_2\right)=0
```

したがって，

```math
x_1\frac{dp_1}{p_1}
+x_2\frac{dp_2}{p_2}=0
\tag{1}
```

を得る．

ここで，溶媒についてラウールの法則が希薄極限 $x_2\to0$ で成立するとする．
さらに，式を微分できるように，その漸近展開が

```math
p_1=p_1^0(1-x_2)+O(x_2^2),
```

```math
\frac{dp_1}{dx_2}=-p_1^0+O(x_2)
```

を満たすと仮定する．
このとき，

```math
\frac{d\ln p_1}{dx_2}
=\frac{1}{p_1}\frac{dp_1}{dx_2}
=-1+O(x_2)
```

である．
また， $x_1=1-x_2$ なので，式 (1) を $x_2$ で微分する形に書けば，

```math
(1-x_2)\frac{d\ln p_1}{dx_2}
+x_2\frac{d\ln p_2}{dx_2}=0
```

となる．
これに上の漸近式を代入すると，

```math
x_2\frac{d\ln p_2}{dx_2}
=1+O(x_2)
```

を得る．
よって，

```math
\frac{d}{dx_2}\ln\left(\frac{p_2}{x_2}\right)
=O(1)
```

である．
右辺は $x_2\to0$ で積分可能なので， $\ln(p_2/x_2)$ は有限な極限をもつ．
したがって，有限かつ正の定数 $k_2$ が存在して，

```math
\lim_{x_2\to0}\frac{p_2}{x_2}=k_2
```

となる．
すなわち，

```math
\boxed{p_2=k_2x_2[1+O(x_2)]}
```

を得る．
希薄極限において，これはヘンリーの法則

```math
\boxed{p_2=k_2x_2}
```

を意味する．
ここで $k_2$ は温度および圧力に依存するヘンリー定数である．

次に，成分 2 の化学ポテンシャルを求める．
理想気体の化学ポテンシャルは

```math
\mu_2^V(T,p_2)
=\mu_2^{V,0}(T)+RT\ln\frac{p_2}{p^\circ}
```

と書ける．
ここで $p^\circ$ は標準圧力である．
相平衡条件より，

```math
\mu_2^L=\mu_2^V
```

だから，

```math
\mu_2^L
=\mu_2^{V,0}(T)
+RT\ln\frac{k_2x_2[1+O(x_2)]}{p^\circ}
```

となる．
対数の性質を用いると，

```math
\mu_2^L
=\mu_2^{V,0}(T)
+RT\ln\frac{k_2}{p^\circ}
+RT\ln x_2
+O(x_2)
```

である．
ここで，

```math
\phi_2^0(T,p)
\equiv
\mu_2^{V,0}(T)
+RT\ln\frac{k_2(T,p)}{p^\circ}
```

と定義すれば，

```math
\boxed{
\mu_2^L
=\phi_2^0(T,p)+RT\ln x_2+O(x_2)
}
```

を得る．
したがって，希薄溶液極限における主要項は

```math
\boxed{
\bar G_2(T,p)
\simeq \phi_2^0(T,p)+RT\ln x_2
}
```

である．
ここで $\bar G_2$ は成分 2 の部分モルギブズ自由エネルギー，すなわち化学ポテンシャルを表す．
圧力 $p$ を固定した条件では， $\phi_2^0(T,p)$ の圧力依存性を省略して $\phi_2^0(T)$ と表記することもある．

以上より，ギブズ・デュエムの式と溶媒に対するラウールの法則から，希薄極限における溶質のヘンリーの法則，および化学ポテンシャルの対数表示が得られる．

なお，ここでの導出は液相圧力 $p$ を一定に保つ条件に基づく．
気相が成分 1 と 2 のみからなり，平面界面で液相と気相の全圧が等しい場合には，全圧 $p=p_1+p_2$ が組成とともに変化し得る．
その場合は圧力変化に伴う補正を考慮する必要がある．
