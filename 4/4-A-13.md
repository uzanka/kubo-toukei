# 演習問題【4-A-13】

## 解答

本問題では，2成分の理想希薄溶液において，Gibbs-Duhem の関係式を用いることで，溶質の蒸気圧に関する Henry の法則と，溶質の化学ポテンシャルの式を導出する．

### 1. 準備：Gibbs-Duhem の関係式と化学ポテンシャルの関係

まず，温度 $T$ と圧力 $p$ が一定の条件下における，成分 $i$ ( $i=1, 2$ ) のモルあたりの化学ポテンシャルを $\overline{G}_i$ とする．
このとき，Gibbs-Duhem の関係式は次のように書ける．

$$x_1 d\overline{G}_1 + x_2 d\overline{G}_2 = 0 \quad \cdots (1)$$

ここで， $x_i$ は成分 $i$ のモル分率である．

次に，化学ポテンシャル $\overline{G}_i$ と，その成分の分圧 $p_i$ の関係を考える．
理想気体の振る舞いをする蒸気との平衡を考えると，成分 $i$ の化学ポテンシャルは次のように表される．

$$\overline{G}_i = \overline{G}_i^0(T, p_i^0) + RT \ln\left(\frac{p_i}{p_i^0}\right) \quad \cdots (2)$$

ここで， $\overline{G}_i^0(T, p_i^0)$ は，純粋な成分 $i$ の化学ポテンシャル（標準状態の化学ポテンシャル）であり，温度 $T$ と標準圧力 $p_i^0$ の関数である．

式 (2) の両辺を微分すると，以下のようになる（ $T$ と $p_i^0$ は一定とする）．

$$d\overline{G}_i = RT \cdot d\left(\ln \frac{p_i}{p_i^0}\right) = RT \cdot d(\ln p_i - \ln p_i^0) = RT \frac{dp_i}{p_i} \quad \cdots (3)$$

### 2. Gibbs-Duhem の関係式への代入

式 (3) を式 (1) に代入する．

$$x_1 \left( RT \frac{dp_1}{p_1} \right) + x_2 \left( RT \frac{dp_2}{p_2} \right) = 0$$

両辺を $RT$ で割ると，蒸気圧 $p_1, p_2$ に関する以下の関係式が得られる．

$$x_1 \frac{dp_1}{p_1} + x_2 \frac{dp_2}{p_2} = 0 \quad \cdots (4)$$

### 3. Henry の法則の導出

ここで，成分 1 を溶媒，成分 2 を溶質とする．
溶媒については，理想希薄溶液において **Raoult の法則**が成り立つ．
すなわち，

$$p_1 = x_1 p_1^0 \quad \cdots (5)$$

である．
この式の対数をとると，

$$\ln p_1 = \ln x_1 + \ln p_1^0$$

となり，これを微分すると（ $\ln p_1^0$ は定数なので），

$$\frac{dp_1}{p_1} = \frac{dx_1}{x_1} \quad \cdots (6)$$

が得られる．

また，モル分率の定義より $x_1 + x_2 = 1$ であるから，微分形式では $dx_1 + dx_2 = 0$ ，すなわち $dx_1 = -dx_2$ である．
これを式 (6) に代入すると，

$$\frac{dp_1}{p_1} = -\frac{dx_2}{x_1}$$

となる．
これを式 (4) に代入して整理する．

$$x_1 \left( -\frac{dx_2}{x_1} \right) + x_2 \frac{dp_2}{p_2} = 0$$

$$-dx_2 + x_2 \frac{dp_2}{p_2} = 0$$

$$x_2 \frac{dp_2}{p_2} = dx_2$$

両辺を $x_2$ で割ると，

$$\frac{dp_2}{p_2} = \frac{dx_2}{x_2} \quad \cdots (7)$$

が得られる．
これは $x_2 \to 0$ （希薄溶液）の範囲で成り立つ．

この式 (7) を積分する．

$$\int \frac{dp_2}{p_2} = \int \frac{dx_2}{x_2}$$

$$\ln p_2 = \ln x_2 + C \quad (C \text{ は積分定数})$$

指数関数をとると，

$$p_2 = e^C \cdot x_2$$

$e^C$ を定数 $k_2$ と置くと，

$$p_2 = k_2 x_2 \quad \cdots (8)$$

が得られる．
これが **Henry の法則**である．

### 4. 溶質の化学ポテンシャルの式の導出

最後に，得られた Henry の法則 $p_2 = k_2 x_2$ を，化学ポテンシャルの式 (2) に代入する．

$$\overline{G}_2 = \overline{G}_2^0(T, p_2^0) + RT \ln\left(\frac{k_2 x_2}{p_2^0}\right)$$

対数の性質 $\ln(abc) = \ln a + \ln b + \ln c$ を用いて展開すると，

$$\overline{G}_2 = \overline{G}_2^0(T, p_2^0) + RT \ln\left(\frac{k_2}{p_2^0}\right) + RT \ln x_2$$

ここで， $\overline{G}_2^0(T, p_2^0) + RT \ln(k_2/p_2^0)$ は温度 $T$ のみの関数であるため，これを $\phi_2^0(T)$ と定義する．

$$\phi_2^0(T) = \overline{G}_2^0(T, p_2^0) + RT \ln\left(\frac{k_2}{p_2^0}\right)$$

したがって，

$$\overline{G}_2 = \phi_2^0(T) + RT \ln x_2 \quad \cdots (9)$$

が得られる．
これが求める式である．

## 解説

### 1. Gibbs-Duhem の関係式とは

Gibbs-Duhem の関係式は，多成分系の熱力学量（エンタルピー，エントロピー，化学ポテンシャルなど）が互いに関連していることを示す非常に重要な式である．
溶液において，成分が増えれば他の成分が減るという制約を，熱力学的な変化量として記述している．
今回の導出では，「成分1の化学ポテンシャルの変化」と「成分2の化学ポテンシャルの変化」が，それぞれのモル分率によって重み付けされてゼロになる，という性質を利用している．

### 2. Raoult の法則と Henry の法則の違い

- **Raoult の法則**:
  溶媒のように，溶液中に大量に含まれる成分（ $x \approx 1$ ）が従う法則である．
  純粋な状態の蒸気圧 $p^0$ に対して，溶媒の濃度に比例して蒸気圧が下がる．
- **Henry の法則**:
  溶質のように，溶液中にわずかしか含まれない成分（ $x \approx 0$ ）が従う法則である．
  溶媒の場合とは異なり，蒸気圧は「純粋な状態の蒸気圧」ではなく，その濃度に比例する「定数 $k_2$」を用いて記述される．

今回の問題では，Gibbs-Duhem の式から出発することで，「溶媒が Raoult の法則に従うならば，必然的に溶質は Henry の法則に従う」という関係を数学的に導いている．

### 3. 化学ポテンシャルの項 $\phi_2^0(T)$ について

式 (9) で現れる $\phi_2^0(T)$ は，溶質の化学ポテンシャルにおける「標準的な寄与」を表している．
純粋な状態の化学ポテンシャル $\overline{G}_2^0$ に，Henry の法則の定数 $k_2$ に由来する補正項が加わったものと解釈できる．
