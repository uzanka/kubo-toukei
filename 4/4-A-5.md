# 演習問題【4-A-5】

## 解答

水の三重点とは，氷，液体の水，水蒸気の三相が共存する温度と圧力のことである．
三重点の温度は，氷－水の平衡曲線と水－水蒸気の平衡曲線の交点から求められる．

相平衡曲線の傾きは，クラペイロンの式

```math
\frac{dp}{dT}=\frac{q}{T(v_b-v_a)}
```

で与えられる．
ここで， $q$ は相 $a$ から相 $b$ への転移に伴う潜熱， $v_a,v_b$ はそれぞれの相の比体積である．

### 1．氷－水の平衡曲線の傾き

氷の比体積を $v_s$ ，水の比体積を $v_l$ とする．
問題文の体積比は，水：氷 $=1:1.091$ である．
水の密度を約 $1\,\mathrm{g/cm^3}$ とすると，

```math
v_l=1.000\,\mathrm{cm^3/g},\qquad
v_s=1.091\,\mathrm{cm^3/g}
```

となる．

融解熱は $q=80\,\mathrm{cal/g}$ ，温度は $T_0=273\,\mathrm{K}$ であるから，氷－水の平衡曲線の傾きは

```math
\frac{dp_{sl}}{dT}
=\frac{q}{T_0(v_l-v_s)}
=\frac{80}{273(1.000-1.091)}
```

である．
したがって，

```math
\frac{dp_{sl}}{dT}
\simeq-3.22\,
\frac{\mathrm{cal}}{\mathrm{K\,cm^3}}
```

となる．
ここでは，潜熱を質量当たり，比体積も質量当たりで表しているため，両者の質量単位は相殺される．

圧力の単位を $\mathrm{atm}$ に換算するため，

```math
1\,\mathrm{cal/cm^3}
=4.184\times10^6\,\mathrm{Pa}
\simeq41.3\,\mathrm{atm}
```

を用いる．
よって，

```math
\frac{dp_{sl}}{dT}
\simeq-3.22\times41.3
=-133\,\mathrm{atm/K}
```

であり，その逆数は

```math
\frac{dT}{dp_{sl}}
\simeq-\frac{1}{133}
=-0.00752\,\mathrm{K/atm}
```

となる．

この傾きが負であるのは，氷が融解すると体積が減少するためである．
すなわち，圧力が低下すると，氷－水の平衡温度は上昇する．

### 2．水－水蒸気の平衡曲線の近似

水－水蒸気の平衡曲線についても，クラペイロンの式より

```math
\frac{dp_{lv}}{dT}
=\frac{q_{lv}}{T(v_v-v_l)}
```

である．
ここで，蒸発熱は $q_{lv}=600\,\mathrm{cal/g}$ ，水蒸気の比体積を $v_v$ とする．

水蒸気の比体積は液体の水の比体積に比べて非常に大きく，問題文の条件ではおよそ $10^5$ 倍である．
したがって，分母はほぼ $T v_v$ で決まり，蒸発熱が融解熱の約 $7.5$ 倍であっても，この平衡曲線の傾きは氷－水の平衡曲線に比べて非常に小さい．
よって，水－水蒸気の平衡曲線は，この近傍ではほぼ水平とみなせる．

0℃における水の飽和蒸気圧は $4.58\,\mathrm{mmHg}$ であるため，三重点の圧力は近似的にこの値となる．

### 3．三重点の温度

0℃における氷－水の平衡圧力は $760\,\mathrm{mmHg}=1\,\mathrm{atm}$ である．
三重点では圧力がほぼ $4.58\,\mathrm{mmHg}$ まで低下するため，圧力変化は

```math
\Delta p
=\frac{4.58-760}{760}\,\mathrm{atm}
\simeq-0.994\,\mathrm{atm}
```

である．

氷－水の平衡曲線の傾きを用いると，温度変化は

```math
\Delta T\simeq\frac{dT}{dp_{sl}}\Delta p
```

である．
したがって，

```math
\begin{aligned}
\Delta T
&\simeq(-0.00752\,\mathrm{K/atm})
(-0.994\,\mathrm{atm})\\
&\simeq0.00748\,\mathrm{K}.
\end{aligned}
```

基準温度は $0^\circ\mathrm{C}$ であり，温度差については $1\,\mathrm{K}=1\,^\circ\mathrm{C}$ であるため，三重点の温度は

```math
T_{\mathrm{tp}}\simeq0.0075\,^\circ\mathrm{C}
```

と求められる．

したがって，与えられたデータから得られる水の三重点の温度の近似値は， $\boxed{0.0075^\circ\mathrm{C}}$ である．
