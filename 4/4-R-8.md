# 例題【4-R-8】

## 解答

### 1. 準備と基本式の整理

まず，溶媒（成分1）と溶質（成分2，ここでは強電解質）の化学ポテンシャルを考える．
溶媒の化学ポテンシャル $\bar{G}_1$ は，活動度 $a_1$ を用いて次のように表される：

$$\bar{G}_1 = \bar{G}_1^0 + RT \ln a_1$$

したがって，その微小変化 $d\bar{G}_1$ は次のように書ける：

$$d\bar{G}_1 = RT d \ln a_1 \quad (T, p \text{ 一定})$$

次に，強電解質 $A_{\nu} + B_{\nu-} \longrightarrow \nu_+ A^{z+} + \nu_- B^{z-}$ の解離を考える．
溶質の化学ポテンシャルを $\bar{G}_2$ とすると，Gibbs-Duhem の関係式は次のように与えられる：

$$n_1 d\bar{G}_1 + n_2 d\bar{G}_2 = 0$$

ここで， $n_1$ は溶媒のモル数， $n_2$ は溶質（塩）のモル数である．
この式を変形すると，溶媒の化学ポテンシャルの変化は次のように得られる：

$$d\bar{G}_1 = -\frac{n_2}{n_1} d\bar{G}_2$$

強電解質の場合，溶質 1 モルが解離して $\nu$ モルのイオンを生じると考えると，溶質の化学ポテンシャル $\bar{G}_2$ は，イオンの平均的な活動度に関連付けられる．
具体的には，溶質の活動度 $a_2$ と，イオンの活動度係数 $\bar{\gamma}$ の関係を考慮すると，式(1)のように次のような関係式が導かれる：

$$d \log a_1 + \nu \frac{x_2}{1 - x_2} \{d \log x_2 + d \log \bar{\gamma}\} = 0 \quad \cdots (1)$$

（ここで $x_2$ は溶質のモル分率， $1-x_2 = x_1$ は溶媒のモル分率である．）

### 2. 式(1)の積分

式(1)を，純溶媒の状態（ $x_2 = 0$ ）から現在のモル分率 $x_2$ まで積分する．
$x_2 = 0$ のとき，溶媒は純粋なので $a_1 = 1$ である．

$$\int_1^{a_1} d \log a_1 = -\nu \int_0^{x_2} \frac{x}{1 - x} \{d \log x + d \log \bar{\gamma}\} \quad (\text{変数 } x \text{ を用いて書き換え})$$

これより，

$$\log a_1 = -\nu \int_0^{x_2} \left( \frac{1}{1 - x} + \frac{x}{1 - x} \frac{\partial \log \bar{\gamma}}{\partial x} \right) dx$$

積分の中身を整理すると：

$$\log a_1 = -\nu \left[ \int_0^{x_2} \frac{1}{1 - x} dx + \int_0^{x_2} \frac{x}{1 - x} \frac{\partial \log \bar{\gamma}}{\partial x} dx \right]$$
第1項の積分は $\int \frac{1}{1-x} dx = -\log(1-x)$ であるから，

$$\log a_1 = -\nu \left[ -\log(1-x_2) + \int_0^{x_2} \frac{x}{1 - x} \frac{\partial \log \bar{\gamma}}{\partial x} dx \right] \quad \cdots (1)'$$

が得られる．

### 3. 浸透圧 $\pi$ の導出

浸透圧 $\pi$ と溶媒の化学ポテンシャルの関係は， $\pi \bar{V} = -RT \log a_1$ で与えられる．
これに式(1)'を代入する．

$$\pi \bar{V} = -RT \{ -\nu [ -\log(1-x_2) + \int_0^{x_2} \frac{x}{1 - x} \frac{\partial \log \bar{\gamma}}{\partial x} dx ] \}$$

$$\pi \bar{V} = \nu RT \{ -\log(1-x_2) + \int_0^{x_2} \frac{x}{1 - x} \frac{\partial \log \bar{\gamma}}{\partial x} dx \}$$

ここで，希薄溶液（ $x_2 \ll 1$ ）の近似を用いる．
$-\log(1-x_2) \approx x_2$ および $\frac{1}{1-x} \approx 1$ とすると，

$$\pi \bar{V} \approx \nu RT \{ x_2 + \int_0^{x_2} x \frac{\partial \log \bar{\gamma}}{\partial x} dx \}$$

$$\pi \bar{V} \approx \nu x_2 RT \{ 1 + \frac{1}{x_2} \int_0^{x_2} x \frac{\partial \log \bar{\gamma}}{\partial x} dx \}$$

両辺を $\bar{V}$ （溶媒のモル体積）で割ると，

$$\pi \cong \frac{\nu x_2 RT}{\bar{V}} \{ 1 + \frac{1}{x_2} \int_0^{x_2} x \frac{\partial \log \bar{\gamma}}{\partial x} dx \}$$

### 4. モル濃度 $C_2$ とモル質量 $m_2$ への変換

モル分率 $x_2$ とモル濃度 $C_2$ （mol/L）の関係を用いる．
希薄溶液では，溶媒のモル体積 $\bar{V}_1^0$ を用いて，溶質のモル数は $n_2 \approx C_2 \cdot V / 1000$ と書ける．
また， $x_2 = \frac{n_2}{n_1+n_2} \approx \frac{n_2}{n_1}$ である．
さらに， $x_2 / \bar{V}_1^0 \approx C_2 / 1000$ であることが導かれる．
（詳細： $x_2 = \frac{n_2}{n_1} \approx \frac{C_2 \bar{V}_1^0}{1000}$ ）

これを用いると，

$$\pi \cong \frac{\nu C_2 RT}{1000} \{ 1 + \frac{1}{m_2} \int_0^{m_2} m \frac{\partial \log \bar{\gamma}}{\partial m} dm \}$$
（ここで変数を $x$ から $m$ に置き換えた）

よって，題意の式が証明された．

## 解説

### 浸透圧と活動度

浸透圧は，溶液中の溶媒の化学ポテンシャルが，純溶媒の化学ポテンシャルよりも低下することによって生じる現象である．
この低下の度合いは溶媒の「活動度（実効的な濃度）」に依存する．

### 浸透圧係数 $g$ の意味

理想溶液では，浸透圧は $\pi = CRT$ （van't Hoffの法則）に従うが，実際の溶液（特に強電解質溶液）では，イオン間の相互作用によりこの法則からズレが生じる．
この「理想からのズレ」を補正するための因子が浸透圧係数 $g$ である．

$$g = \frac{\pi}{\pi_{ideal}}$$

この $g$ が 1 であれば理想溶液，1 から離れるほど相互作用が強いことを意味する．

### Gibbs-Duhem の式の役割

溶液中の成分間の化学ポテンシャルの変化は互いに関連している（一方が増えれば，もう一方は減る方向へ働く）．
Gibbs-Duhem の式は，この「成分間のバランス」を記述する非常に強力なツールであり，溶質の性質から溶媒の性質（浸透圧に直結する $a_1$ ）を導き出すために使用された．

### まとめ

本問題では，Gibbs-Duhem の式から出発し，モル分率を用いた積分，そして希薄溶液近似を用いることで，浸透圧がモル質量やモル濃度，および活動度係数の微積分によって決定されることを示した．
