# 例題【4-R-8】

## 解答

### 1．Gibbs–Duhem の関係式を用いる

成分1を溶媒，成分2を強電解質とする．
溶質の解離反応は，

```math
A_{\nu_+}B\_{\nu_-} \longrightarrow \nu_+ A^{z+}+\nu_-B^{z-}
```

であり，溶質1 molから生成するイオンの総物質量は，

```math
\nu=\nu_++\nu_-
```

である．

溶媒の化学ポテンシャルを $\bar G_1$ ，溶質の化学ポテンシャルを $\bar G_2$ とする．
溶媒の活動度を $a_1$ とすると，

```math
\bar G_1=\bar G_1^0+RT\ln a_1
\tag{1}
```

である．
ここで， $\bar G_1^0$ は純溶媒の化学ポテンシャルである．
温度 $T$ と圧力 $P$ を一定にすると，

```math
d\bar G_1=RT\,d\ln a_1
\tag{2}
```

となる．

一方，強電解質の化学ポテンシャルは，平均イオン活動度係数 $\bar\gamma$ を用いて，

```math
\bar G_2 =\bar G_2^0+\nu RT\ln(x_2\bar\gamma)
\tag{3}
```

と表される．
$\bar G_2^0$ は溶質の標準化学ポテンシャル， $x_2$ は溶質のモル分率である．
この式を微分すると，

```math
d\bar G_2 =\nu RT\left(d\ln x_2+d\ln\bar\gamma\right)
\tag{4}
```

を得る．

温度と圧力が一定の二成分系に対する Gibbs–Duhem の関係式は，

```math
n_1\,d\bar G_1+n_2\,d\bar G_2=0
\tag{5}
```

である．
ここで， $n_1$ ， $n_2$ はそれぞれ溶媒と溶質の物質量である．
モル分率の定義から，

```math
\frac{n_2}{n_1}=\frac{x_2}{x_1} =\frac{x_2}{1-x_2}
\tag{6}
```

となる．
式（2），（4）を式（5）に代入し， $n_1RT$ で割ると，

```math
\boxed{
d\ln a_1 +\nu\frac{x_2}{1-x_2} \left(d\ln x_2+d\ln\bar\gamma\right)=0
}
\tag{7}
```

が得られる．
これが，溶媒の活動度と溶質の平均イオン活動度係数を結び付ける式である．

### 2．微分方程式を積分して溶媒の活動度を求める

式（7）を変形すると，

```math
d\ln a_1 =-\nu\frac{x_2}{1-x_2} \left(d\ln x_2+d\ln\bar\gamma\right)
```

となる．
ここで，

```math
d\ln x_2=\frac{dx_2}{x_2}
```

を用いれば，

```math
d\ln a_1 =-\nu\left[ \frac{dx_2}{1-x_2} +\frac{x_2}{1-x_2} \frac{\partial\ln\bar\gamma}{\partial x_2}\\,dx_2 \right]
\tag{8}
```

と書ける．

純溶媒の極限 $x_2=0$ では $a_1=1$ ，すなわち $\ln a_1=0$ である．
この条件のもとで，式（8）を $0$ から $x_2$ まで積分すると，

```math
\ln a_1 =-\nu\int_0^{x_2} \left[ \frac{1}{1-x} +\frac{x}{1-x} \frac{\partial\ln\bar\gamma}{\partial x} \right]dx
\tag{9}
```

となる．
ここでは積分変数を $x$ とした．

第1項の積分は，

```math
\int_0^{x_2}\frac{dx}{1-x} =-\ln(1-x_2)
```

である．
したがって，

```math
\boxed{
\begin{aligned}
\ln a_1 =-\nu\left[ -\ln(1-x_2) +\int_0^{x_2} \frac{x}{1-x} \frac{\partial\ln\bar\gamma}{\partial x}\,dx \right]
\end{aligned}
}
\tag{10}
```

を得る．

### 3．浸透圧の式を導く

希薄溶液において，溶媒の活動度と浸透圧 $\pi$ の間には，

```math
\boxed{
\pi\bar V_1^0=-RT\ln a_1
}
\tag{11}
```

の関係がある．
ここで $\bar V_1^0$ は純溶媒のモル体積である．
この式は，半透膜を隔てて純溶媒と溶液が平衡になるために必要な圧力差を表している．

式（10）を式（11）に代入すると，

```math
\pi =\frac{\nu RT}{\bar V_1^0} \left[ -\ln(1-x_2) +\int_0^{x_2} \frac{x}{1-x} \frac{\partial\ln\bar\gamma}{\partial x}\,dx \right]
\tag{12}
```

となる．

ここで，希薄溶液では $x_2\ll1$ であるから，

```math
-\ln(1-x_2)\simeq x_2, \qquad \frac{1}{1-x}\simeq1
```

と近似できる．
これを式（12）に用いると，

```math
\pi\simeq \frac{\nu RT}{\bar V_1^0} \left[ x_2+ \int_0^{x_2} x\frac{\partial\ln\bar\gamma}{\partial x}\,dx \right]
\tag{13}
```

を得る．
$x_2$ をくくり出せば，

```math
\boxed{
\pi\simeq \frac{\nu x_2RT}{\bar V_1^0} \left[ 1+\frac{1}{x_2} \int_0^{x_2} x\frac{\partial\ln\bar\gamma}{\partial x}\,dx \right]
}
\tag{14}
```

である．

### 4．モル分率から質量モル濃度に変換する

次に，式（14）を問題文で用いられている質量モル濃度 $m_2$ で表す．

溶媒のモル質量を $M_1$ （ $\mathrm{g/mol}$ ）とすると，溶媒 $n_1$ mol の質量は $n_1M_1$ g である．
したがって，質量モル濃度は，

```math
m_2=\frac{1000n_2}{n_1M_1}
\tag{15}
```

である．
希薄溶液では $x_2\simeq n_2/n_1$ であるから，

```math
\boxed{
x_2\simeq\frac{m_2M_1}{1000}
}
\tag{16}
```

となる．

また，純溶媒のモル体積とモル質量の関係は，

```math
\bar V_1^0=\frac{M_1}{\rho_1}
\tag{17}
```

である．
ここで $\rho_1$ は純溶媒の密度である．
したがって，

```math
\frac{x_2}{\bar V_1^0} \simeq \frac{m_2M_1}{1000\bar V_1^0} =\frac{\rho_1m_2}{1000}
\tag{18}
```

を得る．
問題文の濃度 $C_2$ を $C_2=\rho_1m_2$ と表せば，

```math
\boxed{
\frac{x_2}{\bar V_1^0}\simeq\frac{C_2}{1000}
}
\tag{19}
```

である．
ここでは， $C_2$ を問題文および教科書の単位規約に従って用いている．

式（14），（19）を用いると，

```math
\boxed{
\pi\simeq \frac{\nu C_2RT}{1000} \left[ 1+\frac{1}{x_2} \int_0^{x_2} x\frac{\partial\ln\bar\gamma}{\partial x}\,dx \right]
}
\tag{20}
```

となる．

### 5．積分変数を $m_2$ に変換する

式（20）の積分項を，質量モル濃度 $m_2$ で表す．
変数変換の近似式を，

```math
x=\lambda m,\qquad \lambda=\frac{M_1}{1000}
\tag{21}
```

と書く．
ここで $m$ は積分変数であり，積分上限が現在の質量モル濃度 $m_2$ である．
このとき，

```math
\frac{dx}{dm}=\lambda,\qquad \frac{\partial\ln\bar\gamma}{\partial x} =\frac{1}{\lambda} \frac{\partial\ln\bar\gamma}{\partial m}
\tag{22}
```

が成り立つ．
したがって，

```math
\begin{aligned}
\int_0^{x_2} x\frac{\partial\ln\bar\gamma}{\partial x}\,dx &=\int_0^{m_2} (\lambda m) \left(\frac{1}{\lambda} \frac{\partial\ln\bar\gamma}{\partial m}\right) \lambda\,dm\\
&=\lambda\int_0^{m_2} m\frac{\partial\ln\bar\gamma}{\partial m}\,dm
\end{aligned}
\tag{23}
```

となる．

一方，式（21）より $x_2=\lambda m_2$ であるため，

```math
\boxed{
\frac{1}{x_2} \int_0^{x_2} x\frac{\partial\ln\bar\gamma}{\partial x}\,dx = \frac{1}{m_2} \int_0^{m_2} m\frac{\partial\ln\bar\gamma}{\partial m}\,dm
}
\tag{24}
```

を得る．
ここで $\lambda=M_1/1000$ は，分子と分母で相殺される．

### 6．浸透圧係数 $g$ の公式を得る

式（20），（24）を組み合わせると，

```math
\pi\simeq \frac{\nu C_2RT}{1000} \left[ 1+\frac{1}{m_2} \int_0^{m_2} m\frac{\partial\ln\bar\gamma}{\partial m}\\,dm \right]
\tag{25}
```

となる．
一方，問題文では浸透圧係数 $g$ を用いて，

```math
\pi=\frac{\nu C_2RT}{1000}g
\tag{26}
```

と表している．
式（25）と式（26）を比較すれば，

```math
\boxed{
g= 1+\frac{1}{m_2} \int_0^{m_2} m\left(\frac{\partial\ln\bar\gamma}{\partial m}\right)\_{T,P} \,dm
}
\tag{27}
```

を得る．
これが証明すべき関係式である．

## 3．結論と補足

本問の導出では，Gibbs–Duhem の関係式を用いて溶媒の活動度を溶質の平均イオン活動度係数に結び付け，浸透圧の式に代入した後，希薄溶液近似と変数変換を用いることで，浸透圧係数 $g$ の積分表示を得た．

```math
\boxed{
g= 1+\frac{1}{m_2} \int_0^{m_2} m\left(\frac{\partial\ln\bar\gamma}{\partial m}\right)\_{T,P} \,dm
}
```

この結果は，理想希薄溶液では $\bar\gamma=1$ となり，積分項がゼロになるため $g=1$ となることを示している．
実際の強電解質溶液では，イオン間の相互作用によって $\bar\gamma$ が濃度とともに変化し，その影響が積分項を通じて浸透圧係数に反映されるのである．
