# 演習問題【4-A-2】

## 解答

氷の融解曲線に対して，Clausius–Clapeyron の式を適用する．
融点 $T_m$ の圧力 $p$ による変化率は，

```math
\frac{dT_m}{dp}
=\frac{T_m(v_l-v_s)}{q_m}
```

で与えられる．
ここで， $v_s$ は氷の比容， $v_l$ は水の比容， $q_m$ は単位質量あたりの融解熱である．

問題で与えられた条件は，

```math
T_m=273\ \mathrm{K},\qquad
q_m=80\ \mathrm{cal/g}
```

および

```math
v_s:v_l=1.091:1.000
```

である．
水の比容を $v_l=1.000\ \mathrm{cm^3/g}$ とすれば，氷の比容は $v_s=1.091\ \mathrm{cm^3/g}$ である．
したがって，比容の差は

```math
v_l-v_s
=(1.000-1.091)\ \mathrm{cm^3/g}
=-0.091\ \mathrm{cm^3/g}
```

となる．

次に，圧力の単位を $\mathrm{cmHg}$ にそろえるため，エネルギー密度を圧力に換算する．

```math
1\ \mathrm{cal}=4.18\times10^7\ \mathrm{erg}
```

であり，

```math
1\ \mathrm{erg/cm^3}
=1\ \mathrm{dyn/cm^2}
```

であるため，

```math
1\ \mathrm{cal/cm^3}
=4.18\times10^7\ \mathrm{dyn/cm^2}
```

となる．
一方，水銀柱の高さを $h\ \mathrm{cm}$ とすると，水銀の密度 $\rho_{\mathrm{Hg}}=13.6\ \mathrm{g/cm^3}$ ，重力加速度 $g=980\ \mathrm{cm/s^2}$ より，水銀柱による圧力は

```math
p=\rho_{\mathrm{Hg}}gh
```

である．
したがって，

```math
1\ \mathrm{cmHg}
=13.6\times980\ \mathrm{dyn/cm^2}
```

である．
以上より，

```math
\begin{aligned}
1\ \mathrm{cal/cm^3}
&=\frac{4.18\times10^7}{13.6\times980}
\ \mathrm{cmHg}\\
&\approx3.13\times10^3\ \mathrm{cmHg}
\end{aligned}
```

を得る．

Clausius–Clapeyron の式に数値を代入すると，

```math
\frac{dT_m}{dp}
=\frac{273\times(-0.091)}{80}
\ \frac{\mathrm{cm^3}}{\mathrm{cal}}
```

となる．
ここで，

```math
1\ \mathrm{cal/cm^3}
=3.13\times10^3\ \mathrm{cmHg}
```

であるから，

```math
1\ \frac{\mathrm{cm^3}}{\mathrm{cal}}
=\frac{1}{3.13\times10^3}\ \frac{1}{\mathrm{cmHg}}
```

と換算できる．
よって，

```math
\begin{aligned}
\frac{dT_m}{dp}
&=\frac{273(-0.091)}{80}
  \frac{1}{3.13\times10^3}
  \ \frac{\mathrm{K}}{\mathrm{cmHg}}\\
&\approx-0.99\times10^{-4}
  \ \frac{\mathrm{K}}{\mathrm{cmHg}}
\end{aligned}
```

となる．

したがって，求める融点の圧力による変化率は，

```math
\boxed{
\frac{dT_m}{dp}
=-0.99\times10^{-4}\ \mathrm{K/cmHg}
}
```

である．
温度変化の大きさは $\mathrm{K}$ と ${}^\circ\mathrm{C}$ で等しいため， $-0.99\times10^{-4}\ {}^\circ\mathrm{C}/\mathrm{cmHg}$ と表してもよい．

この値が負であることは，圧力を上げると氷の融点が下がることを意味する．
これは，氷の比容が水の比容より大きく，融解に伴って体積が減少するためである．
