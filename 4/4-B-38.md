# 演習問題【4-B-38】

## 解答

### 1．設定と分離定数

長さ $L$ ，断面積1の棒を考える．
初めは棒全体が溶融状態にあり，不純物 $B$ の濃度は一様に $C_m^0$ である．
棒の左端から固化が進み，左端から距離 $x$ までが固相になった状態を考える．

このとき，固相は $0\leq x'\leq x$ ，液相は $x<x'\leq L$ に存在する．
液相中では拡散が十分に速いため，残った液体の濃度はどこでも一様であるとする．
その濃度を $C_m(x)$ と表す．

分離定数 $k$ の定義より，濃度 $C_m(x)$ の液体から新たに析出する固体の不純物濃度は

```math
\boxed{
C(x)=kC_m(x)
}
\tag{1}
```

である．
固相では拡散が起こらないため，固化した部分の濃度は，その部分が固化した瞬間の値に保たれる．
したがって，式（1）から固相の濃度分布を求めるには，まず液相の濃度 $C_m(x)$ を求めればよい．

### 2．液相中の不純物量について物質収支を立てる

左端から $x$ まで固化したとき，残っている液相の長さは $L-x$ である．
断面積を1とし，濃度を単位体積あたりの不純物量として扱うと，液相中の不純物の総量 $M(x)$ は

```math
M(x)=C_m(x)(L-x)
\tag{2}
```

と表される．

ここから，固化がさらに微小距離 $dx$ だけ進み，固化境界が $x$ から $x+dx$ に移動した場合を考える．

新たに固化する部分の長さは $dx$ であり，その不純物濃度は，固化直前の液相の濃度 $C_m(x)$ に分離定数 $k$ を掛けた $kC_m(x)$ である．
したがって，新たに固相に取り込まれる不純物量は

```math
kC_m(x)\,dx
```

である．
液相中の不純物量は，この分だけ減少するため，

```math
dM=-kC_m(x)\,dx
\tag{3}
```

が成り立つ．
式（2）を代入すると，

```math
d \left\{C_m(x)(L-x) \right\} =-kC_m(x)\,dx
\tag{4}
```

となる．

### 3．微分方程式を導く

式（4）の左辺を積の微分公式で展開すると，

```math
(L-x)\,dC_m-C_m(x)\,dx =-kC_m(x)\,dx
```

である．
両辺を整理すれば，

```math
(L-x)\,dC_m =-(k-1)C_m(x)\,dx
```

となる．
したがって，液相中の濃度について次の微分方程式が得られる．

```math
\boxed{
(L-x)\frac{dC_m}{dx}=-(k-1)C_m
}
\tag{5}
```

この式は，固化が進むにつれて液相の長さが短くなり，同時に不純物の一部が固相へ移ることによって，残った液相の濃度が変化することを表している．

### 4．微分方程式を積分する

式（5）を変数分離すると，

```math
\frac{1}{C_m}\,dC_m =-\frac{k-1}{L-x}\,dx
```

となる．
両辺を積分して，

```math
\int\frac{1}{C_m}\,dC_m =-(k-1)\int\frac{1}{L-x}\,dx
```

を得る．
ここで，

```math
\int\frac{1}{L-x}\,dx=-\ln(L-x)
```

であることに注意すると，

```math
\ln C_m=(k-1)\ln(L-x)+\text{定数}
```

となる．
両辺の指数をとり，積分定数を $A$ とおけば，

```math
\boxed{
C_m(x)=A(L-x)^{k-1}
}
\tag{6}
```

と表される．

### 5．初期条件を用いて積分定数を決定する

初期状態では，まだ固化が進んでいないため $x=0$ であり，液相全体の不純物濃度は $C_m^0$ である．
したがって，

```math
C_m(0)=C_m^0
```

である．
式（6）に $x=0$ を代入すると，

```math
C_m^0=AL^{k-1}
```

となるので，

```math
A=\frac{C_m^0}{L^{k-1}}
```

を得る．
これを式（6）に代入すると，

```math
\begin{aligned}
C_m(x) &=\frac{C_m^0}{L^{k-1}}(L-x)^{k-1}\\
&=C_m^0\left(\frac{L-x}{L}\right)^{k-1}
\end{aligned}
```

である．
よって，液相の濃度は

```math
\boxed{
C_m(x)=C_m^0\left(1-\frac{x}{L}\right)^{k-1}
}
\tag{7}
```

と求められる．

### 6．固相の濃度分布を求める

求める量は，棒の左端から距離 $x$ の位置で固化した固体の不純物濃度 $C(x)$ である．
式（1）の分離定数の定義

```math
C(x)=kC_m(x)
```

と式（7）を用いると，

```math
C(x)=kC_m^0 \left(1-\frac{x}{L}\right)^{k-1}
```

となる．
したがって，示すべき結果は

```math
\boxed{
C(x)=kC_m^0\left(1-\frac{x}{L}\right)^{k-1}
}
```

である．

## 3．結果の物理的な意味

特に $0<k<1$ の場合について考える．
このとき $k-1<0$ であるため，

```math
\left(1-\frac{x}{L}\right)^{k-1}
```

は $x$ が大きくなるほど増加する．
したがって，固化が左端から右端へ進むにつれて，後から固化する部分ほど不純物濃度が高くなる．

これは，固相よりも液相に不純物が残りやすいことを意味する．
固化が進むと不純物は液相に濃縮され，最後に固化する側へ集まりやすくなるのである．

ただし，左端の濃度は

```math
C(0)=kC_m^0
```

であり， $k$ がゼロでない限り不純物濃度もゼロではない．
$k<1$ であれば初期の液相濃度 $C_m^0$ より低くなる，というのが正確な説明である．

また， $k<1$ では式（7）から $x\to L$ のとき $C_m(x)$ が発散するように見えるが，これは濃度が小さい範囲に限って $k$ を一定とした近似を，濃度が高くなる領域まで適用したことによる．
終端付近では，この近似をそのまま使うことはできない．

この原理は帯域溶融法にも利用される．溶融領域を棒に沿って移動させると，不純物が液相側に残りやすい場合には，固化した部分の不純物濃度を下げながら，不純物を棒の一端へ集めることができる．この操作を繰り返すことで，シリコンやゲルマニウムなどの材料を高純度化できるのである．
