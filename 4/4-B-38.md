# 演習問題【4-B-38】

## 解答

### 1. 設定と変数定義

まず，問題の設定を整理し，変数を定義する．

*   棒の全長を $L$ とする．
*   棒の断面積を $1$ とする．
*   棒の左端から $x$ の地点までが固化した状態を考える．
このとき，固化している部分は $0 \le \text{位置} \le x$ ，まだ溶けている（液相の）部分は $x < \text{位置} \le L$ である．
*   液相部分の不純物濃度を $C_m(x)$ とする．
問題の仮定により，液体の中では拡散が非常に速いため，液相内の濃度はどこでも一様（ $C_m(x)$ ）であるとみなせる．
*   固相部分の不純物濃度を $C(x)$ とする．
固相の中では拡散が起こらないため，各位置 $x$ で固化したときの濃度 $C(x)$ は，その瞬間の液相濃度 $C_m(x)$ に分離定数 $k$ を掛けたものになる．
    $$C(x) = k C_m(x)$$

### 2. 不純物量の変化に関する微分方程式の導出

次に，固化が進むにつれて液相に含まれる不純物の量がどのように変化するかを考える．

液相部分（長さ $L-x$ ，断面積 $1$ ）に含まれる不純物の総量 $M(x)$ は次のように書ける．

$$M(x) = C_m(x) \cdot (L - x)$$

ここで，固化がさらにわずかな距離 $dx$ だけ進んだとき（すなわち，固化の境界が $x$ から $x + dx$ へ移動したとき），液相に含まれる不純物量はどのように変化するかを考える．

1.  **液相から失われる不純物の量**:
    固化が進むことで，新たに固相となる体積は $dx$ （断面積 $1$ なので）である．
    このとき，新しく固化する部分の不純物濃度は $C(x) = k C_m(x)$ なので，液相から取り去られる不純物の量は $k C_m(x) dx$ となる．
2.  **液相中の不純物量の変化**:
    不純物量の変化 $dM$ は，液相から取り去られる量に等しいため，
    $$dM = d\{C_m(x)(L - x)\} = -k C_m(x) dx$$

この式を展開する．
積の微分公式 $(fg)' = f'g + fg'$ を用いると，

$$d\{C_m(x)(L - x)\} = (L - x) dC_m + C_m d(L - x)$$

ここで， $d(L - x) = -dx$ であるため，

$$(L - x) dC_m - C_m dx = -k C_m dx$$

$$(L - x) dC_m = -(k - 1) C_m dx$$

両辺を $dx$ で割り，整理すると以下の微分方程式が得られる．

$$\frac{dC_m}{dx} (L - x) = -(k - 1) C_m \quad \cdots \text{(A)}$$

### 3. 微分方程式の解法

式 (A) を変数分離法を用いて解く．

$$\frac{1}{C_m} dC_m = -\frac{k - 1}{L - x} dx$$

両辺を積分する．

$$\int \frac{1}{C_m} dC_m = -(k - 1) \int \frac{1}{L - x} dx$$

左辺は $\ln C_m$ ，右辺の積分は $\int \frac{1}{L - x} dx = -\ln(L - x)$ であることに注意すると，

$$\ln C_m = -(k - 1) \{ -\ln(L - x) \} + \text{constant}$$

$$\ln C_m = (k - 1) \ln(L - x) + \text{constant}$$

指数関数の形に直すと，

$$C_m(x) = e^{\text{constant}} \cdot (L - x)^{k-1}$$

ここで， $e^{\text{constant}}$ を改めて定数 $A$ と置くと，

$$C_m(x) = A (L - x)^{k-1} \quad \cdots \text{(B)}$$

### 4. 初期条件の適用

はじめの状態（ $x = 0$ のとき）では，棒全体が溶融状態にあり，その不純物濃度は $C_m^0$ である．
したがって，式 (B) に $x = 0$ を代入すると，

$$C_m(0) = A (L - 0)^{k-1} = A L^{k-1} = C_m^0$$

これより，定数 $A$ は次のように求まる．

$$A = \frac{C_m^0}{L^{k-1}} = C_m^0 \left( \frac{1}{L} \right)^{k-1}$$

これを式 (B) に代入すると，液相の濃度分布 $C_m(x)$ が得られる．

$$C_m(x) = C_m^0 \left( \frac{1}{L} \right)^{k-1} (L - x)^{k-1} = C_m^0 \left( \frac{L - x}{L} \right)^{k-1}$$

$$C_m(x) = C_m^0 \left( 1 - \frac{x}{L} \right)^{k-1} \quad \cdots \text{(C)}$$

### 5. 最終的な固相の濃度 $C(x)$

求めたいのは，位置 $x$ で固化した固相の濃度 $C(x)$ である．
関係式 $C(x) = k C_m(x)$ を用いると，

$$C(x) = k C_m^0 \left( 1 - \frac{x}{L} \right)^{k-1}$$

となり，題意が示された．

## 解説

### 物理的な意味

この結果は，**「固化が進むにつれて，不純物が液相の奥（右側）へと押しやられていく」**様子を表している．
特に $k < 1$ の場合（不純物が固相よりも液相に溶け込みやすい場合）， $x$ が大きくなる（液相の端に近づく）ほど，式 $(1 - x/L)^{k-1}$ の値は大きくなる．
これは，液相の末端に不純物が集中していくことを意味する．

### 帯域溶融法（Zone Melting）への応用

この原理を利用したのが「帯域溶融法（Zone Refining）」である．
1.  棒の一部を加熱して溶融部（液相）を作る．
2.  その加熱部を棒の端から端へとゆっくり移動させる．
3.  加熱部が通過した跡（固相）では，不純物が少なくなった「純粋な部分」が残る．
4.  一方で，不純物は常に移動する液相の末端へと押しやられるため，最終的に棒の反対側の端に不純物が集まる．

この操作を繰り返すことで，半導体材料（SiやGeなど）から極めて微量な不純物を取り除き，超高純度な結晶を得ることが可能になる．
