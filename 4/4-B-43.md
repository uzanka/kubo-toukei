# 演習問題【4-B-43】

## 解答

### 1．氷点降下と溶媒活動度の関係

#### 1.1 固液平衡からの導出

純水の氷点を $T_0$ ，溶液の氷点を $T_f$ とし，氷点降下を

```math
\theta=T_0-T_f
```

と定義する．

溶媒である水の液相の標準化学ポテンシャルを $\mu_1^{(l,0)}$ ，氷相の化学ポテンシャルを $\mu_1^{(s)}$ とする．
溶液中の水の化学ポテンシャルは，

```math
\mu_1^{(l)}
=
\mu_1^{(l,0)}+RT\ln a_1
```

で表される．
ここで $a_1$ は水の活動度である．

溶液の氷点 $T_f$ では，氷と溶液中の水が平衡にあるため，

```math
\mu_1^{(s)}(T_f)
=
\mu_1^{(l,0)}(T_f)+RT_f\ln a_1
```

となる．
一方，純水の氷点 $T_0$ では，

```math
\mu_1^{(s)}(T_0)=\mu_1^{(l,0)}(T_0)
```

である．

水のモル融解熱を正の量 $L_f>0$ とし，氷点付近でこれを一定と近似する．
液相と固相の化学ポテンシャルの温度微分はそれぞれのモルエントロピーの負であるため，

```math
\frac{d}{dT}
\left[
\mu_1^{(l,0)}-\mu_1^{(s)}
\right]
=
-\frac{L_f}{T}
```

となる．
これを $T_0$ から $T_f$ まで積分すると，

```math
\mu_1^{(l,0)}(T_f)-\mu_1^{(s)}(T_f)
=
L_f\ln\frac{T_0}{T_f}
```

である．
固液平衡条件を代入すれば，

```math
-RT_f\ln a_1
=
L_f\ln\frac{T_0}{T_f}
```

を得る．
したがって，

```math
-\ln a_1
=
\frac{L_f}{RT_f}\ln\frac{T_0}{T_f}
\tag{1}
```

となる．

今回の氷点降下は十分小さいので，

```math
\theta=T_0-T_f\ll T_0
```

である．
よって，

```math
\ln\frac{T_0}{T_f}
=
\ln\frac{T_0}{T_0-\theta}
\simeq \frac{\theta}{T_0}
```

および $T_f\simeq T_0$ と近似できる．
式 (1) は，

```math
-\ln a_1
\simeq
\frac{L_f}{RT_0^2}\theta
```

となる．
よって，

```math
\boxed{
\theta
=
-\frac{RT_0^2}{L_f}\ln a_1
}
\tag{2}
```

を得る．

ここで $L_f>0$ である．
通常，溶液中の水の活動度は $a_1<1$ であるため $\ln a_1<0$ となり，式 (2) は正の氷点降下を与える．

### 2．浸透圧係数 $g$ と水の活動度

HCl は水溶液中で，

```math
\mathrm{HCl}\longrightarrow\mathrm{H^+}+\mathrm{Cl^-}
```

と解離する．
したがって，化学量論係数は，

```math
\nu=2
```

である．

molality 基準の浸透圧係数 $g$ は，溶媒の活動度を用いて，

```math
\boxed{
\ln a_1=-\nu M_1m_2g
}
\tag{3}
```

と定義される．
ここで $M_1$ は溶媒のモル質量を $\mathrm{kg/mol}$ で表した値であり，

```math
M_1=0.018016\ \mathrm{kg/mol}
```

である．
$m_2$ は電解質 HCl の molality である．

この関係は molality 基準の浸透圧係数の定義であり， $g$ は無限希釈極限で1に近づく．
理想希薄溶液では $g\simeq14 となる．

式 (2) に式 (3) を代入すると，

```math
\theta
=
\frac{RT_0^2}{L_f}\nu M_1m_2g
```

を得る．
したがって，

```math
\boxed{
\theta=\nu\lambda m_2g
}
\tag{4}
```

ただし，

```math
\lambda=\frac{RT_0^2M_1}{L_f}
```

である．

与えられた数値を代入する．

```math
\begin{aligned}
\lambda
&=
\frac{
1.9870(273.16)^2(18.016)
}{
1000(1436)
}\\
&\simeq1.8601\ \mathrm{K\,kg/mol}
\end{aligned}
```

よって， $\nu=2$ から，

```math
\boxed{
\theta=3.7202\,m_2g
}
\tag{5}
```

となる．
ここで $m_2$ は $\mathrm{mol/kg}$ 単位で代入する．

したがって，実験値から浸透圧係数を求める式は，

```math
\boxed{
g=\frac{\theta}{3.7202m_2}
}
\tag{6}
```

である．

### 3．実験値から浸透圧係数 $g$ を求める

表の第1列には $10^3m_2$ ，第2列には $10^2\theta$ が記載されている．
表示値をそれぞれ $a,b$ とすれば，

```math
m_2=a\times10^{-3}\ \mathrm{mol/kg}
```

および，

```math
\theta=b\times10^{-2}\ \mathrm K
```

である．
温度差の単位は $\mathrm{K}$ と ${}^\circ\mathrm C$ で数値が等しいため，表の温度降下をこのまま使用できる．

例えば，最初の測定値では，

```math
m_2=0.627\times10^{-3}\ \mathrm{mol/kg}
```

```math
\theta=0.228\times10^{-2}\ \mathrm K
=0.00228\ \mathrm K
```

である．
式 (6) より，

```math
\begin{aligned}
g
&=\frac{0.00228}{3.7202(0.000627)}\\
&\simeq0.97747
\end{aligned}
```

となる．
したがって，

```math
1-g\simeq0.02253
```

である．

同様に全測定値について計算すると，次の結果を得る．

### 4．Debye–Hückel の極限法則による浸透圧係数

#### 4.1 平均イオン活量係数

HCl は一価の電解質であるため，

```math
\mathrm{HCl}\longrightarrow\mathrm{H^+}+\mathrm{Cl^-}
```

であり，イオン強度 $I$ は，

```math
I=\frac12\sum_i m_i z_i^2
=\frac12(m_2+m_2)
=m_2
```

となる．

Debye–Hückel の極限法則によれば，十分に希薄な電解質溶液では，平均イオン活量係数 $\bar\gamma$ は，

```math
\boxed{
\ln\bar\gamma=-\alpha\sqrt{m_2}
}
\tag{7}
```

と表される．
ここでは自然対数を用いる．
$m_2$ は $\mathrm{mol/kg}$ 単位であり， $\alpha$ の単位は $(\mathrm{kg/mol})^{1/2}$ である．

#### 4.2 Debye–Hückel 係数 $\alpha$ の計算

水の比誘電率を $D$ ，真空の誘電率を $\varepsilon_0$ ，Boltzmann 定数を $k_B$ ，水の密度を $\rho_1$ ，素電荷を $e$ ，Avogadro 定数を $N_A$ とする．

1:1 電解質では，Debye の遮蔽定数 $\kappa$ は，

```math
\kappa^2
=
\frac{2e^2N_A\rho_1m_2}
{\varepsilon_0Dk_BT_0}
```

である．
また，Debye–Hückel の極限法則における平均イオン活量係数は，

```math
\ln\bar\gamma
=
-\frac{e^2\kappa}
{8\pi\varepsilon_0Dk_BT_0}
```

となる．
この2式を組み合わせれば，

```math
\ln\bar\gamma=-\alpha\sqrt{m_2}
```

であり，

```math
\boxed{
\alpha
=
\frac{e^2}{8\pi\varepsilon_0Dk_BT_0}
\left(
\frac{2e^2N_A\rho_1}
{\varepsilon_0Dk_BT_0}
\right)^{1/2}
}
\tag{8}
```

を得る．

氷点付近の水の密度を，

```math
\rho_1\simeq0.99984\times10^3\ \mathrm{kg/m^3}
```

とし，問題で与えられた

```math
D=88.23,\qquad T_0=273.16\ \mathrm K
```

を用いる．
さらに，

```math
\begin{aligned}
e&=1.60218\times10^{-19}\ \mathrm C,\\
\varepsilon_0&=8.85419\times10^{-12}\ \mathrm{F/m},\\
k_B&=1.38065\times10^{-23}\ \mathrm{J/K},\\
N_A&=6.02214\times10^{23}\ \mathrm{mol^{-1}}
\end{aligned}
```

を代入すると，

```math
\boxed{
\alpha\simeq1.123\ (\mathrm{kg/mol})^{1/2}
}
```

となる．
したがって，3桁程度に丸めて，

```math
\boxed{\alpha\simeq1.12}
```

を用いる．

#### 4.3 平均イオン活量係数から浸透圧係数を求める

浸透圧係数 $g$ と平均イオン活量係数 $\bar\gamma$ の間には，Gibbs–Duhem の関係から，

```math
\boxed{
g
=
1+\frac1{m_2}
\int_0^{m_2}
m\frac{d\ln\bar\gamma}{dm}\,dm
}
\tag{9}
```

が成立する．
ここで $m$ は積分変数である．

式 (7) を $m$ で微分すると，

```math
\frac{d\ln\bar\gamma}{dm}
=
-\frac{\alpha}{2\sqrt m}
```

となる．
これを式 (9) に代入すれば，

```math
\begin{aligned}
g
&=
1-\frac{\alpha}{2m_2}
\int_0^{m_2}\sqrt m\,dm\\
&=
1-\frac{\alpha}{2m_2}
\left[\frac23m^{3/2}\right]_0^{m_2}\\
&=
1-\frac{\alpha}{3}\sqrt{m_2}
\end{aligned}
```

を得る．
よって，

```math
\boxed{
g=1-\frac{1.12}{3}\sqrt{m_2}
\simeq1-0.3733\sqrt{m_2}
}
\tag{10}
```

となる．
したがって，

```math
\boxed{
1-g\simeq0.3733\sqrt{m_2}
}
\tag{11}
```

である．

### 5．実験値と理論値の比較

式 (11) を用いて各濃度における理論値を求め，実験値と比較する．

| $m_2$ （mol/kg） | $1-g$ （実験値） | $1-g$ （Debye–Hückel） |
|---:|---:|---:|
| $0.627\times10^{-3}$ | 0.02253 | 0.00935 |
| $1.179\times10^{-3}$ | 0.01051 | 0.01282 |
| $1.245\times10^{-3}$ | 0.01763 | 0.01317 |
| $1.474\times10^{-3}$ | 0.01159 | 0.01433 |
| $2.228\times10^{-3}$ | 0.01672 | 0.01762 |
| $3.526\times10^{-3}$ | 0.01962 | 0.02217 |
| $4.520\times10^{-3}$ | 0.02232 | 0.02510 |
| $6.879\times10^{-3}$ | 0.02545 | 0.03096 |
| $10.633\times10^{-3}$ | 0.02849 | 0.03850 |

実験値には測定点ごとのばらつきがあり，特に最初の測定点では理論値との差が大きい．
一方，濃度の高い領域では，Debye–Hückel の極限法則による $1-g$ が実験値より大きくなる傾向が見られる．

Debye–Hückel の極限法則は無限希釈に近い領域で成立する漸近的な近似である．
有限濃度ではイオンの有限サイズや溶媒和，より高次のイオン間相互作用などが影響するため，実験値とのずれが生じる．
また，表の実験値だけから個々のずれの原因を特定することはできない．

### 6．結論

氷点降下から得られる浸透圧係数は，

```math
\boxed{
g=\frac{\theta}{3.7202m_2}
}
```

である．
また，Debye–Hückel の極限法則からは，

```math
\boxed{
g\simeq1-0.3733\sqrt{m_2}
}
```

が得られる．

実験値は測定点ごとにばらつくものの，浸透圧係数が1より小さくなること，および濃度の増加に伴って $1-g$ が概ね増加する傾向を示す．
Debye–Hückel の極限法則は，希薄溶液でのこの濃度依存性を表すが，有限濃度では実験値とのずれが見られる．
