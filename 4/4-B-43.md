# 演習問題【4-B-43】

## 解答

## 1．氷点降下と浸透圧係数 $g$ の関係

### 1.1 氷点降下と溶媒の活動度

溶液の氷点降下を $\theta$ ，純水の氷点を $T_1^0$ とする．
氷点降下は，純水の氷点と溶液の氷点との差であるため，

```math
\theta=T_1^0-T_f
```

と定義する．
ここで $T_f$ は溶液の氷点である．

溶媒の活動度を $a_1$ ，水の融解熱の絶対値を $L_f$ とすると，希薄溶液では，氷点降下は

```math
\boxed{
\theta=-\frac{R(T_1^0)^2}{L_1}\ln a_1
}
\tag{1}
```

と表せる．
ここで $L_1=-L_f=-1436\ \mathrm{cal/mol}$ とする．
また，

```math
R=1.9870\ \mathrm{cal/(mol\,K)},\qquad T_1^0=273.16\ \mathrm K
```

である．

### 1.2 活動度と浸透圧係数の関係

HCl は水溶液中で

```math
\mathrm{HCl}\longrightarrow\mathrm{H^+}+\mathrm{Cl^-}
```

と電離するため，1 mol の HCl から生じるイオンの数は2である．
したがって，化学量論係数を $\nu=2$ とする．

希薄溶液では，溶媒の活動度 $a_1$ と浸透圧係数 $g$ の間に

```math
\ln a_1=-\nu x_2 g
\tag{2}
```

という関係がある．
ここで $x_2$ は溶質のモル分率である．

溶質の質量モル濃度を $m_2$ ，溶媒のモル質量を $\overline M_1$ とすると，希薄溶液では

```math
x_2\simeq \frac{m_2\overline M_1}{1000}
\tag{3}
```

と近似できる．
ここで $\overline M_1=18.016\ \mathrm{g/mol}$ は水のモル質量である．

式（2），（3）から，

```math
\ln a_1 =-\nu\frac{m_2\overline M_1}{1000}g
\tag{4}
```

となる．

### 1.3 $g$ を求める式の導出

式（4）を式（1）に代入すると，

```math
\theta =\frac{R(T_1^0)^2}{L_1} \nu\frac{m_2\overline M_1}{1000}g
```

を得る．
$L_1=-1436\ \mathrm{cal/mol}$ であるから，

```math
\theta =-\nu\frac{R(T_1^0)^2\overline M_1} {1000L_1}m_2g
```

となる．
ここで，

```math
\lambda\equiv -\frac{R(T_1^0)^2\overline M_1}{1000L_1}
```

とおく．
与えられた数値を代入すると，

```math
\lambda =-\frac{1.9870(273.16)^2(18.016)} {1000(-1436)} \simeq1.860\ \mathrm{K\,kg/mol}
```

である．
したがって，

```math
\theta=\nu\lambda m_2g
```

であり， $\nu=2$ より，

```math
\boxed{
\theta=3.72\,m_2g
}
\tag{5}
```

が得られる．
ただし， $m_2$ は $\mathrm{mol/kg}$ 単位で代入する．

ゆえに，実験で測定された $\theta$ と $m_2$ から，浸透圧係数は

```math
\boxed{
g=\frac{\theta}{3.72m_2}
}
\tag{6}
```

と求められる．

## 2．実験値から浸透圧係数 $g$ を求める

表の第1列には $10^3m_2$ ，第2列には $10^2\theta$ が記載されている．
したがって，表示値をそれぞれ $a$ ， $b$ とすれば，

```math
m_2=a\times10^{-3}\ \mathrm{mol/kg}
```

および

```math
\theta=b\times10^{-2}\ \mathrm K
```

である．
これらを式（6）に代入することで，各濃度の $g$ を求める．

例えば，最初の測定値では，

```math
m_2=0.627\times10^{-3}\ \mathrm{mol/kg}, \qquad \theta=0.228\times10^{-2}\ \mathrm K
```

である．
よって，

```math
\begin{aligned}
g&=\frac{0.00228}{3.72\times0.000627}\\
&=\frac{0.00228}{0.00233244}\\
&\simeq0.97752
\end{aligned}
```

となる．
したがって，

```math
1-g\simeq0.02248
```

である．

同様にして全測定値について計算すると，次の結果を得る．

| $m_2$（mol/kg）         | $g$ （実験値） | $1-g$ （実験値） |
| ------------------------- | ------------ | -------------- |
| $0.627\times10^{-3}$  | 0.978        | 0.022          |
| $1.179\times10^{-3}$  | 0.990        | 0.010          |
| $1.245\times10^{-3}$  | 0.982        | 0.018          |
| $1.474\times10^{-3}$  | 0.988        | 0.012          |
| $2.228\times10^{-3}$  | 0.983        | 0.017          |
| $3.526\times10^{-3}$  | 0.980        | 0.020          |
| $4.520\times10^{-3}$  | 0.978        | 0.022          |
| $6.879\times10^{-3}$  | 0.975        | 0.025          |
| $10.633\times10^{-3}$ | 0.972        | 0.028          |

表の $g$ および $1-g$ は，丸める前の値を用いて計算しているため，表示された $g$ から単純に $1-g$ を計算すると，最終桁に差が生じる場合がある．

## 3．Debye–Hückel の極限法則による浸透圧係数

### 3.1 平均イオン活量係数

Debye–Hückel の極限法則によれば，十分に希薄な電解質溶液では，平均イオン活量係数 $\bar\gamma$ は

```math
\boxed{
\ln\bar\gamma=-\alpha\sqrt{m_2}
}
\tag{7}
```

と表される．

水の誘電率 $D=88.23$ など，問題で指定された定数を用いて Debye–Hückel の係数を計算すると，

```math
\alpha\simeq1.12
```

となる．
ここでは，対数を自然対数 $\ln$ としている．
$m_2$ を $\mathrm{mol/kg}$ 単位で扱う場合， $\alpha$ の数値はこの濃度単位に対応する値である．

### 3.2 理論式から $g$ を求める

浸透圧係数と平均イオン活量係数の関係式は，

```math
g=1+\frac{1}{m_2} \int_0^{m_2} m\frac{d\ln\bar\gamma}{dm}\,dm
\tag{8}
```

である．
ここで $m$ は積分変数である．

式（7）を $m$ で微分すると，

```math
\frac{d\ln\bar\gamma}{dm} =-\frac{\alpha}{2\sqrt m}
```

となる．
これを式（8）に代入すれば，

```math
\begin{aligned}
g &=1-\frac{\alpha}{2m_2} \int_0^{m_2}\sqrt m\,dm\\
&=1-\frac{\alpha}{2m_2} \left[\frac23m^{3/2}\right]_0^{m_2}\\
&=1-\frac{\alpha}{3}\sqrt{m_2}.
\end{aligned}
```

したがって，Debye–Hückel の極限法則による浸透圧係数は，

```math
\boxed{
g=1-\frac{1.12}{3}\sqrt{m_2} \simeq1-0.3733\sqrt{m_2}
}
\tag{9}
```

である．
よって，

```math
\boxed{
1-g\simeq0.3733\sqrt{m_2}
}
\tag{10}
```

となる．

## 4．実験値と理論値の比較

式（10）を用いて理論値を計算し，実験値と比較すると次のようになる．

| $m_2$ （mol/kg）         | $1-g$ （実験値） | $1-g$ （Debye–Hückel） |
| ------------------------- | -------------- | ----------------------- |
| $0.627\times10^{-3}$  | 0.022          | 0.009                   |
| $1.179\times10^{-3}$  | 0.010          | 0.013                   |
| $1.245\times10^{-3}$  | 0.018          | 0.013                   |
| $1.474\times10^{-3}$  | 0.012          | 0.014                   |
| $2.228\times10^{-3}$  | 0.017          | 0.018                   |
| $3.526\times10^{-3}$  | 0.020          | 0.022                   |
| $4.520\times10^{-3}$  | 0.022          | 0.025                   |
| $6.879\times10^{-3}$  | 0.025          | 0.031                   |
| $10.633\times10^{-3}$ | 0.028          | 0.039                   |

以上の比較から，次のことが分かる．

- 実験値では，濃度が高くなるにつれて $1-g$ が概ね増加している．したがって，浸透圧係数 $g$ は1より小さくなり，濃度の増加とともに1からのずれが大きくなる傾向がある．
- Debye–Hückel の極限法則は， $1-g$ が $\sqrt{m_2}$ に比例することを予測する．実験値はこの傾向と概ね整合するが，特に最初の測定点では差が大きく，実験値にはばらつきが見られる．
- 高濃度側では，Debye–Hückel の理論値が実験値より大きくなる傾向がある．極限法則は非常に希薄な溶液に対する近似であり，有限のイオンサイズ，水和，より高次のイオン間相互作用などの影響を完全には含んでいないためである．

## 5．結論

氷点降下の測定値から求めた浸透圧係数は，

```math
\boxed{
g=\frac{\theta}{3.72m_2}
}
```

であり，Debye–Hückel の極限法則からは，

```math
\boxed{
g\simeq1-0.3733\sqrt{m_2}
}
```

が得られる．
両者を比較すると，希薄溶液における浸透圧係数の濃度依存性は理論と概ね整合する一方，測定値のばらつきや高濃度側での乖離も確認できる．
これは，Debye–Hückel の極限法則が希薄溶液で成立する近似式であることと整合する結果である．
