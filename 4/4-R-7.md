# 例題【4-R-7】

## 解答

本問題では，成分間の相互作用を表すパラメータ $A$ を持つ「正規溶液（Regular Solution）」モデルにおける，蒸気圧の挙動と相分離の条件，および相図の形状について検討する．

### 1. 系の設定とギブス自由エネルギー

2成分系の正規溶液において，混合によるエンタルピー変化 $\Delta H$ が成分比 $x_1, x_2$ を用いて次のように与えられているとする．

$$\Delta H = A(n_1 + n_2)x_1x_2$$

ここで， $x_1, x_2$ は各成分のモル分率 ( $x_1 + x_2 = 1$ ) である．

混合系の全ギブス自由エネルギー $G(n_1, n_2)$ は，各成分の純粋状態のギブス自由エネルギー $\bar{G}_i^0$ と，混合による追加項（過剰ギブス自由エネルギー）を用いて次のように書ける．

$$G(n_1, n_2) = n_1 \bar{G}_1^0 + n_2 \bar{G}_2^0 + (n_1 + n_2) [A x_1 x_2 + RT(x_1 \log x_1 + x_2 \log x_2)]$$

各成分のモルギブス自由エネルギー $\bar{G}_i$ は， $\bar{G}_i = \left( \frac{\partial G}{\partial n_i} \right)_{T, P, n_j}$ により求められ，次のような形になる．

$$\bar{G}_i = \bar{G}_i^0 + A(1-x_i)x_i + RT \log x_i$$

### 2. 蒸気圧の導出

成分 $i$ の化学ポテンシャル $\mu_i$ は，モルギブス自由エネルギー $\bar{G}_i$ そのものである．
また，気相を理想気体と仮定すると，液相中の成分 $i$ の化学ポテンシャルは蒸気圧 $p_i$ を用いて次のように表せる．

$$\mu_i = \bar{G}_{i,\text{gas}}^0(T) + RT \log p_i$$

これらを等置すると，

$$\bar{G}_i^0(T) + A(1-x_i)x_i + RT \log x_i = \bar{G}_{i,\text{gas}}^0(T) + RT \log p_i$$

整理すると，蒸気圧 $p_i$ は次のように求まる．

$$p_i = p_i^0 \exp \left[ \frac{A(1-x_i)x_i}{RT} \right]$$

ここで， $p_i^0$ は純粋な成分 $i$ の飽和蒸気圧である．

**挙動の考察:**
- **$A < 0$ の場合（混合が発熱的）**: 成分同士が引き合いやすく，混じりやすい状態である．
このとき $\exp[\dots]$ の項は 1 より小さくなるため，蒸気圧は Raoult の法則（ $p_i = x_i p_i^0$ ）よりも低くなる．
- **$A > 0$ の場合（混合が吸熱的）**: 成分同士が反発しやすく，混じりにくい状態である．
このとき $\exp[\dots]$ の項は 1 より大きくなるため，蒸気圧は Raoult の法則よりも高くなる．

### 3. 相分離の条件

相分離が起こるかどうかは，系のギブス自由エネルギー $G$ が組成 $x$ に対して「凸（convex）」であるかによって決まる．
$G$ の曲率が負になる領域（ $\frac{\partial^2 G}{\partial x^2} < 0$ ）が存在する場合，系はより安定な2つの相に分離しようとする．

混合の自由エネルギー（モルあたりの $G$ ）を $g(x)$ とすると，

$$g(x) = x \bar{G}_1^0 + (1-x) \bar{G}_2^0 + A x(1-x) + RT [x \log x + (1-x) \log (1-x)]$$

これを $x$ で2階微分すると，

$$\frac{\partial g}{\partial x} = (\bar{G}_1^0 - \bar{G}_2^0) + A(1-2x) + RT \log \left( \frac{x}{1-x} \right)$$

$$\frac{\partial^2 g}{\partial x^2} = -2A + RT \left( \frac{1}{x} + \frac{1}{1-x} \right) = -2A + \frac{RT}{x(1-x)}$$

相分離が起こり得る条件は，ある $x$ で $\frac{\partial^2 g}{\partial x^2} < 0$ となることである．
$\frac{RT}{x(1-x)}$ の最小値は $x=1/2$ のときで， $\frac{RT}{1/4} = 4RT$ である．
したがって， $-2A + 4RT < 0$ ，すなわち $2A > 4RT \implies A/RT > 2$ が相分離が起こる条件となる．

### 4. 相図の形状と臨界温度

相分離が起こる場合，系は共通接線（common tangent）によって決まる2つの組成 $x_1^a, x_1^b$ を持つ2相に分離する．
これらの組成は，温度 $T$ の関数として決まる．
相分離が始まる限界の温度を**臨界温度 $T_c$** と呼ぶ．

上記の条件 $A/RT = 2$ を $T$ について解くと，

$$T_c = \frac{A}{2R}$$

となる．

**相図の形状:**
- $T > T_c$ のとき：系は単一の相（均一な混合状態）として存在する．
- $T < T_c$ のとき：組成によって，1つの相が存在する領域と，2つの相が共存する領域（binodal 曲線に囲まれた領域）に分かれる．

この相図は，温度が下がるにつれて分離領域が広がっていく，典型的な「スペード」のような形（あるいは釣鐘型）の曲線を描く．

## 解説

### 正規溶液モデルとは

正規溶液（Regular Solution）とは，混合によるエントロピー変化は理想溶液と同じ（混合によってバラバラになる傾向）であるが，混合によるエンタルピー変化 $\Delta H$ が成分間の相互作用によって変化するモデルである．
今回の問題では， $\Delta H \propto A x_1 x_2$ としており，この $A$ が「成分同士がどれくらい仲が悪いか」を表している．

### なぜ $A > 0$ で分離するのか？

熱力学的な安定性は，「自由エネルギー $G$ を最小にする」ことによって決まる．
$G$ は「エネルギー（エンタルピー $H$ ）」と「乱雑さ（エントロピー $S$ ）」のバランスである．
- **エントロピー項 ( $RT \sum x_i \log x_i$ )**: 混ぜることで乱雑さが増え，自由エネルギーを**下げよう**とする（混ぜる方向）．
- **エンタルピー項 ( $Ax_1x_2$ )**: $A > 0$ の場合，混ぜることでエネルギーが増え，自由エネルギーを**上げよう**とする（分かれる方向）．

$A$ が十分に大きい（あるいは温度 $T$ が十分に低い）と，混ぜることによるエネルギーの増加が，エントロピーによる減少分を上回ってしまう．
その結果，系は「全体として混ざるよりも，成分1だけの集まりと成分2だけの集まりに分かれたほうが，全体のエネルギーが低くて済む」と判断し，相分離が起こる．
これが，熱力学的な相分離の物理的な本質である．
