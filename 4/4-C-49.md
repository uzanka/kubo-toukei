# 演習問題【4-C-49】

## 解答

### 1．過飽和水蒸気の凝結による自由エネルギー変化

水蒸気の分圧を $p_w$ ，温度 $T$ における飽和水蒸気圧を $p_s(T)$ とし，過飽和度を

```math
S=\frac{p_w}{p_s(T)}
```

と定義する．
したがって，過飽和状態では $S>1$ である．

飽和状態では水蒸気と液体水の化学ポテンシャルが等しいため，

```math
\mu_v(T,p_s)=\mu_l(T,p_s)
```

である．
水蒸気を理想気体とすると，

```math
\mu_v(T,p_w)-\mu_v(T,p_s)
=RT\ln\frac{p_w}{p_s}
```

であるから，

```math
\begin{aligned}
\mu_v(T,p_w)-\mu_l(T,p_s)
&\simeq
\mu_v(T,p_w)-\mu_v(T,p_s)\\
&=RT\ln\frac{p_w}{p_s}\\
&=RT\ln S
\end{aligned}
```

となる．
ここでは液体水の圧力依存性による補正（Poynting 補正）を無視している．

液滴の半径を $r$ ，水のモル体積を $v_l$ とすると，液滴を構成する水の物質量は

```math
n=\frac{4\pi r^3}{3v_l}
```

である．
したがって，水蒸気から液体水への凝結に伴うバルク自由エネルギー変化は

```math
\boxed{
\Delta G_{\mathrm{bulk}}
=-\frac{4\pi r^3}{3v_l}RT\ln S
}
```

となる．
$S>1$ では $\ln S>0$ なので，この項は負であり，凝結を促進する．

一方，液滴の表面を形成するには自由エネルギーが必要である．
水の表面張力を $\gamma$ とすると，球形液滴の表面自由エネルギーは

```math
\boxed{
\Delta G_{\mathrm{surf}}=4\pi r^2\gamma
}
```

である．
この項は正であり，液滴形成を妨げる．

### 2．イオンによる分極自由エネルギー

電荷 $q$ を持つイオンの有効半径を $a$ ，その周囲に形成される水滴の半径を $r$ とする．
連続体近似を適用する領域を $r\geq a$ とする．
水の比誘電率を $\varepsilon_w$ ，水蒸気の比誘電率を $\varepsilon_v\simeq1$ とする．

イオンを中心とする距離 $\rho$ の位置では，球対称性と Gauss の法則から，電束密度は

```math
D(\rho)=\frac{q}{4\pi\rho^2}
```

である．

自由電荷 $q$ を一定に保った線形誘電体では，電場のエネルギー密度は

```math
u=\frac{D^2}{2\varepsilon_0\varepsilon_r}
```

で与えられる．
ここで $\varepsilon_0$ は真空の誘電率， $\varepsilon_r$ は媒質の比誘電率である．

したがって，水蒸気が水に置き換わることで生じるエネルギー密度の変化は，

```math
\begin{aligned}
u_w-u_v
&=\frac{D^2}{2\varepsilon_0}
\left(
\frac1{\varepsilon_w}
-\frac1{\varepsilon_v}
\right)\\
&=\frac{q^2}{32\pi^2\varepsilon_0\rho^4}
\left(
\frac1{\varepsilon_w}
-\frac1{\varepsilon_v}
\right)
\end{aligned}
```

となる．

これをイオンの有効半径 $a$ から液滴表面 $r$ まで積分すると，

```math
\begin{aligned}
\Delta F_{\mathrm{pol}}
&=\int_a^r4\pi\rho^2(u_w-u_v)\,d\rho\\
&=\frac{q^2}{8\pi\varepsilon_0}
\left(
\frac1{\varepsilon_w}
-\frac1{\varepsilon_v}
\right)
\int_a^r\frac{1}{\rho^2}\,d\rho\\
&=\frac{q^2}{8\pi\varepsilon_0}
\left(
\frac1{\varepsilon_w}
-\frac1{\varepsilon_v}
\right)
\left(
\frac1a-\frac1r
\right)
\end{aligned}
```

を得る．
ここで，

```math
\boxed{
B=\frac{q^2}{8\pi\varepsilon_0}
\left(
\frac1{\varepsilon_v}
-\frac1{\varepsilon_w}
\right)>0
}
```

と定義すれば，

```math
\boxed{
\Delta F_{\mathrm{pol}}
=-B\left(
\frac1a-\frac1r
\right)
}
```

となる．
水は水蒸気より比誘電率が大きいため， $B>0$ であり， $r>a$ では

```math
\boxed{
\Delta F_{\mathrm{pol}}<0
}
```

である．

つまり，イオンの電場によって水分子が分極し，水滴が形成されると静電自由エネルギーが低下する．
この効果は凝結を促進する．

### 3．全自由エネルギーと Kelvin–Thomson の関係

過飽和度 $S>1$ に対して，

```math
A=\frac{RT\ln S}{v_l}>0
```

とおく．
イオンを含まない球形液滴の自由エネルギーの半径依存部分は，

```math
G_0(r)=4\pi\gamma r^2-\frac{4\pi}{3}Ar^3
```

である．

イオンを含む場合には，分極自由エネルギーが加わるため，その自由エネルギーの半径依存部分は，

```math
G_{\mathrm{ion}}(r)
=
4\pi\gamma r^2
-\frac{4\pi}{3}Ar^3
-B\left(\frac1a-\frac1r\right)
```

となる．
ここで，イオン中心の固定された寄与は半径に依存しない定数として扱い，省略している．

核生成の自由エネルギーは定数の加算によって変化しないため， $r=a$ を基準として自由エネルギーの差を定義すると，

```math
\begin{aligned}
\Delta G_{\mathrm{ion}}(r)
&=G_{\mathrm{ion}}(r)-G_{\mathrm{ion}}(a)\\
&=4\pi\gamma(r^2-a^2)
-\frac{4\pi}{3}A(r^3-a^3)\\
&\quad
-B\left(\frac1a-\frac1r\right)
\end{aligned}
```

である．

ここで注意すべきことは， $r=a$ は連続体モデルの下限および自由エネルギーの基準を定める半径であり，必ずしも熱力学的に安定な初期状態ではないということである．
実際の核生成障壁は，後述する自由エネルギーの極小点から極大点までの差で評価する．

核生成の停留条件は，

```math
\frac{d\Delta G_{\mathrm{ion}}}{dr}=0
```

である．
微分すると，

```math
8\pi\gamma r
-4\pi Ar^2
-\frac{B}{r^2}=0
```

となる．
したがって，

```math
\boxed{
A=\frac{2\gamma}{r}-\frac{B}{4\pi r^4}
}
```

すなわち，

```math
\boxed{
\ln S
=\frac{v_l}{RT}
\left(
\frac{2\gamma}{r}
-\frac{B}{4\pi r^4}
\right)
}
```

を得る．
これは Kelvin–Thomson の関係である．

次に，停留点の性質を調べるため，

```math
h(r)=\frac{2\gamma}{r}-\frac{B}{4\pi r^4}
```

とおく．
停留条件は $A=h(r)$ である．
微分すると，

```math
h'(r)
=-\frac{2\gamma}{r^2}
+\frac{B}{\pi r^5}
```

である．
したがって， $h(r)$ の極大点は，

```math
-\frac{2\gamma}{r^2}
+\frac{B}{\pi r^5}=0
```

より，

```math
\boxed{
r_m=\left(\frac{B}{2\pi\gamma}\right)^{1/3}
}
```

となる．
このとき，

```math
h(r_m)=\frac{3\gamma}{2r_m}
```

である．

$a<r_m$ かつ，

```math
h(a)<A<h(r_m)
```

となる領域では，停留条件 $A=h(r)$ を満たす半径が2つ存在する．
これを

```math
r_s<r_m<r_u
```

とする．

停留点において二階微分を評価すると，

```math
\left.
\frac{d^2\Delta G_{\mathrm{ion}}}{dr^2}
\right|_{A=h(r)}
=4\pi r^2h'(r)
```

である．

$r_s<r_m$ では $h'(r_s)>0$ なので，

```math
\left.
\frac{d^2\Delta G_{\mathrm{ion}}}{dr^2}
\right|_{r_s}>0
```

となり， $r_s$ は極小点である．
一方， $r_u>r_m$ では $h'(r_u)<0$ なので，

```math
\left.
\frac{d^2\Delta G_{\mathrm{ion}}}{dr^2}
\right|_{r_u}<0
```

となり， $r_u$ は極大点である．

したがって，イオンの周囲には，小さい安定な前駆クラスターと，大きい不安定な臨界クラスターが存在する．

この2つの停留点が存在する領域では，核生成障壁は，

```math
\boxed{
\Delta G_{\mathrm{ion}}^\ddagger
=
\Delta G_{\mathrm{ion}}(r_u)
-\Delta G_{\mathrm{ion}}(r_s)
}
```

である．
すなわち，安定な前駆クラスターから臨界クラスターへ成長するために必要な自由エネルギー障壁である．
このように極小点と極大点を区別することは，古典的なイオン誘起核生成理論において重要である．

### 4．均質核生成との障壁の比較

イオンが存在しない場合の自由エネルギーは，

```math
G_0(r)=4\pi\gamma r^2-\frac{4\pi}{3}Ar^3
```

である．
停留条件は，

```math
\frac{dG_0}{dr}
=8\pi\gamma r-4\pi Ar^2=0
```

であるから，臨界半径は，

```math
\boxed{
r_0^*=\frac{2\gamma}{A}
=\frac{2\gamma v_l}{RT\ln S}
}
```

となる．

この半径で自由エネルギーは極大となり，均質核生成の障壁は，

```math
\begin{aligned}
\Delta G_{\mathrm{hom}}^\ddagger
&=G_0(r_0^*)-G_0(0)\\
&=\frac{16\pi\gamma^3}{3A^2}
\end{aligned}
```

である．
したがって，

```math
\boxed{
\Delta G_{\mathrm{hom}}^\ddagger
=
\frac{16\pi\gamma^3v_l^2}
{3(RT\ln S)^2}
}
```

となる．

次に，イオンが存在する場合の障壁が均質核生成より小さいことを示す．

```math
W(r)=4\pi\gamma r^2-\frac{4\pi}{3}Ar^3
```

と定義すると，

```math
\Delta G_{\mathrm{ion}}^\ddagger
=
W(r_u)-W(r_s)
-B\left(\frac1{r_s}-\frac1{r_u}\right)
```

である．

停留条件から，

```math
A=\frac{2\gamma}{r}-\frac{B}{4\pi r^4}
<\frac{2\gamma}{r}
```

である．
したがって，2つの停留点について，

```math
\boxed{
r_s<r_u<\frac{2\gamma}{A}=r_0^*
}
```

が成立する．

また，

```math
W'(r)=4\pi r(2\gamma-Ar)
```

であるから， $0<r<r_0^*$ では $W'(r)>0$ となり， $W(r)$ は単調増加する．
よって，

```math
W(r_u)-W(r_s)
<
W(r_0^*)-W(0)
```

である．
さらに $r_u>r_s$ および $B>0$ より，

```math
-B\left(\frac1{r_s}-\frac1{r_u}\right)<0
```

である．
以上から，

```math
\begin{aligned}
\Delta G_{\mathrm{ion}}^\ddagger
&=W(r_u)-W(r_s)
-B\left(\frac1{r_s}-\frac1{r_u}\right)\\
&<W(r_0^*)-W(0)\\
&=\Delta G_{\mathrm{hom}}^\ddagger
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\Delta G_{\mathrm{ion}}^\ddagger
<
\Delta G_{\mathrm{hom}}^\ddagger
}
```

である．

つまり，イオンによる分極効果は，均質核生成の場合に比べて核生成障壁を低下させる．
ただし，障壁の低下量は $B$ ，温度，過飽和度，表面張力などに依存するため，分極効果が常に支配的であるとは限らない．

なお，上の障壁比較は2つの停留点 $r_s,r_u$ が存在する領域についての結果である．
過飽和度が十分に高くなり停留点が消失する場合は，核生成障壁そのものがなくなり，液滴の成長が自由エネルギー的に有利となる．

### 5．均質核生成とイオンを核とした凝結の違い

核生成率は概略的に，

```math
J=J_0\exp\left(
-\frac{\Delta G^\ddagger}{k_BT}
\right)
```

と表される．
ここで， $J_0$ は頻度因子， $k_B$ は Boltzmann 定数である．

均質核生成では，

```math
\Delta G^\ddagger=\Delta G_{\mathrm{hom}}^\ddagger
```

である．
一方，イオンを核とした核生成では，

```math
\Delta G^\ddagger=\Delta G_{\mathrm{ion}}^\ddagger
```

となる．
前節で示したように，

```math
\Delta G_{\mathrm{ion}}^\ddagger
<
\Delta G_{\mathrm{hom}}^\ddagger
```

なので，イオン1個あたりの核生成は起こりやすくなる．

ただし，均質核生成率とイオン核生成率を比較するときは，頻度因子とイオン数密度も考慮する必要がある．
均質核生成率を単位体積・単位時間あたり $J_{\mathrm{hom}}$ ，イオン1個あたりの核生成率を $j_{\mathrm{ion}}$ ，イオン数密度を $n_i$ とすると，

```math
J_{\mathrm{ion}}=n_i j_{\mathrm{ion}}
```

である．
したがって，実際に観測される凝結の程度は，障壁の高さだけでなく，イオン数密度や観測時間などにも依存する．

Wilson chamber では，均質核生成による背景の水滴がほとんど発生せず，イオンの周囲では水滴が十分に発生するような過飽和度を選ぶ．
その結果，イオンの存在する場所に限って凝結が目立つようになる．

### 6．Wilson chamber の断熱膨張と過飽和

Wilson chamber では，容器内の気体を急激に膨張させる．
膨張が十分速ければ周囲との熱交換は小さくなり，気体はほぼ断熱膨張する．

ここで，膨張による温度変化を定量的に求めるため，空気と水蒸気の混合気体を理想気体とし，組成と比熱比が一定の可逆断熱（等エントロピー）膨張で近似する．

体積比を，

```math
x=\frac{V_2}{V_1}>1
```

比熱比を，

```math
\kappa=\frac{C_p}{C_v}
```

とする．
理想気体の可逆断熱膨張では，

```math
TV^{\kappa-1}=\mathrm{const.}
```

であるから，

```math
\boxed{
T_2=T_1x^{1-\kappa}
}
```

となる．
また，凝結が起きる前は水蒸気のモル分率が一定なので，水蒸気分圧も気体全体の圧力と同じ比率で低下する．
したがって，

```math
\boxed{
p_{w,2}=p_{w,1}x^{-\kappa}
}
```

である．

このとき，Clausius–Clapeyron の関係は，水のモル蒸発潜熱を $L_m$ として，

```math
\frac{d\ln p_s}{dT}
=\frac{L_m}{RT^2}
```

である．
蒸発潜熱を温度範囲内で一定と近似して積分すると，

```math
\ln\frac{p_s(T_2)}{p_s(T_1)}
=
-\frac{L_m}{R}
\left(
\frac1{T_2}-\frac1{T_1}
\right)
```

となる．

したがって，膨張前後の過飽和度の比は，

```math
\begin{aligned}
\ln\frac{S_2}{S_1}
&=
\ln\frac{p_{w,2}}{p_{w,1}}
-\ln\frac{p_s(T_2)}{p_s(T_1)}\\
&=
-\kappa\ln x
+\frac{L_m}{R}
\left(
\frac1{T_2}-\frac1{T_1}
\right)
\end{aligned}
```

となる．
よって，膨張後に過飽和状態 $S_2>1$ となる条件は，

```math
\boxed{
\ln S_1
-\kappa\ln x
+\frac{L_m}{R}
\left(
\frac1{T_2}-\frac1{T_1}
\right)>0
}
```

である．

膨張によって水蒸気分圧は低下するが，温度低下によって飽和水蒸気圧も低下する．
後者の低下が十分に大きければ，水蒸気分圧が下がっても過飽和状態が実現する．

なお，上記の温度・圧力の関係式は可逆断熱膨張の近似式である．
実際の急激な膨張が非可逆である場合には，これらの式は厳密には成立しないため，実際の温度と水蒸気分圧を用いて過飽和度を評価する必要がある．

### 7．イオンの飛跡が可視化される理由

過飽和状態になった Wilson chamber 内を荷電粒子が通過すると，粒子と気体分子との衝突によって，その飛跡に沿って気体分子が電離され，正負のイオンが生じる．

イオンの周囲では，水分子が電場によって分極する．
その結果，前述の分極自由エネルギーが負となり，均質核生成より低い障壁で水滴が形成される．

適切な過飽和度では，イオンのない領域では均質核生成がほとんど起こらない一方，イオンの存在する飛跡に沿って水滴が発生する．
形成された微小水滴は光を散乱するため，荷電粒子の通過経路が白い筋状の ion track として観察される．

したがって，Wilson chamber で ion track が見えるのは，急激な膨張によって過飽和状態が生じ，荷電粒子の飛跡に沿って発生したイオンを核として水滴が凝結し，その水滴が光を散乱するためである．

### 8．近似と適用範囲

以上の議論では，液滴を球形とし，水蒸気を理想気体，液体水を非圧縮性液体として扱った．
また，表面張力 $\gamma$ と比誘電率 $\varepsilon_w$ を一定とし，液体の圧力補正を無視した．

分極自由エネルギーの導出では，水を線形誘電体として扱い，電荷 $q$ が一定であると仮定した．
実際にはイオン近傍の強い電場で誘電飽和が生じ，水分子の配向や水和構造も分子スケールで変化する．
したがって，イオンの有効半径 $a$ は連続体近似の下限を表す有効パラメータであり，イオン中心の短距離相互作用はこのモデルでは詳細に記述していない．

また，連続体近似による自由エネルギーは，液滴半径が分子スケールより十分大きい範囲で用いる古典的近似である．
臨界半径が分子スケールに近い場合には，表面張力や誘電率を一定とする近似の定量的な精度は低下する．
