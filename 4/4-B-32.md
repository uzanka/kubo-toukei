# 演習問題【4-B-32】

## 解答

### 1. 定義と基本関係式の整理

まず，問題の設定に基づき，各物理量を定義する．

*   **転移熱 $L$**: 相1から相2への転移に伴って吸収される熱量（1モル当たり）は，エンタルピーの差として次のように表される．
    $$L = \overline{H}_2 - \overline{H}_1$$
    ここで $\overline{H}_1, \overline{H}_2$ はそれぞれの相のモルエンタルピーである．

*   **定圧モル比熱 $C_{p}$**: 温度 $T$ によるエンタルピーの変化率である．
    $$C_{p1} = \left(\frac{\partial \overline{H}_1}{\partial T}\right)_p, \quad C_{p2} = \left(\frac{\partial \overline{H}_2}{\partial T}\right)_p$$

*   **体積熱膨張係数 $\beta$**: 温度による体積の変化率である．
    $$\beta_1 = \frac{1}{\overline{V}_1} \left(\frac{\partial \overline{V}_1}{\partial T}\right)_p, \quad \beta_2 = \frac{1}{\overline{V}_2} \left(\frac{\partial \overline{V}_2}{\partial T}\right)_p$$

転移熱 $L$ は，圧力 $p$ と温度 $T$ の関数 $L(p, T)$ とみなせる．
全微分を用いると，温度 $T$ を変化させたときの $L$ の変化 $dL/dT$ は次のように書ける．

$$\frac{dL}{dT} = \left(\frac{\partial L}{\partial T}\right)_p + \left(\frac{\partial L}{\partial p}\right)_T \frac{dp}{dT} \quad \cdots (1)$$

### 2. 各項の導出

式(1)の各項を求める．

#### (a) $\left(\frac{\partial L}{\partial T}\right)_p$ の計算

$L = \overline{H}_2 - \overline{H}_1$ を $T$ で偏微分する．

$$\left(\frac{\partial L}{\partial T}\right)_p = \frac{\partial \overline{H}_2}{\partial T} - \frac{\partial \overline{H}_1}{\partial T} = C_{p2} - C_{p1} \quad \cdots (2)$$

#### (b) $\frac{dp}{dT}$ (Clapeyron-Clausiusの式)

相平衡においては，両相の化学ポテンシャル（モルギブス自由エネルギー）が等しくなる（ $\overline{G}_1 = \overline{G}_2$ ）．
この平衡状態が温度 $T$ と圧力 $p$ の変化に対して維持される条件から，Clapeyron（クラペイロン）の式が得られる．

$$\frac{dp}{dT} = \frac{L}{T(\overline{V}_2 - \overline{V}_1)} \quad \cdots (3)$$

#### (c) $\left(\frac{\partial L}{\partial p}\right)_T$ の計算

$L = \overline{H}_2 - \overline{H}_1$ を $p$ で偏微分する．

$$\left(\frac{\partial L}{\partial p}\right)_T = \left(\frac{\partial \overline{H}_2}{\partial p}\right)_T - \left(\frac{\partial \overline{H}_1}{\partial p}\right)_T$$

熱力学的基本関係式 $d\overline{H} = T d\overline{S} + \overline{V} dp$ より， $\left(\frac{\partial \overline{H}}{\partial p}\right)_T = T \left(\frac{\partial \overline{S}}{\partial p}\right)_T + \overline{V}$ である．
ここで，Maxwell（マックスウェル）の関係式 $\left(\frac{\partial \overline{S}}{\partial p}\right)_T = -\left(\frac{\partial \overline{V}}{\partial T}\right)_p$ を用いると，

$$\left(\frac{\partial \overline{H}}{\partial p}\right)_T = -T \left(\frac{\partial \overline{V}}{\partial T}\right)_p + \overline{V} = -T(\overline{V} \beta) + \overline{V} = \overline{V}(1 - T\beta)$$

となる．
したがって，

$$\left(\frac{\partial L}{\partial p}\right)_T = \overline{V}_2(1 - T\beta_2) - \overline{V}_1(1 - T\beta_1) = (\overline{V}_2 - \overline{V}_1) - T(\overline{V}_2 \beta_2 - \overline{V}_1 \beta_1) \quad \cdots (4)$$

### 3. 式のまとめ

式(2), (3), (4) を式(1)に代入する．

$$\frac{dL}{dT} = (C_{p2} - C_{p1}) + \left[ (\overline{V}_2 - \overline{V}_1) - T(\overline{V}_2 \beta_2 - \overline{V}_1 \beta_1) \right] \frac{L}{T(\overline{V}_2 - \overline{V}_1)}$$

括弧を展開すると，

$$\frac{dL}{dT} = C_{p2} - C_{p1} + \frac{L(\overline{V}_2 - \overline{V}_1)}{T(\overline{V}_2 - \overline{V}_1)} - \frac{L T(\overline{V}_2 \beta_2 - \overline{V}_1 \beta_1)}{T(\overline{V}_2 - \overline{V}_1)}$$

$$\frac{dL}{dT} = C_{p2} - C_{p1} + \frac{L}{T} - L \frac{\overline{V}_2 \beta_2 - \overline{V}_1 \beta_1}{\overline{V}_2 - \overline{V}_1}$$

となり，題意が示された．

### 4. 近似の導出

次に，相2が理想気体であり，相1が固体または液体である場合を考える．

*   **理想気体の場合**: 体積熱膨張係数は $\beta_2 = \frac{1}{T}$ となる．
*   **相1が固体・液体のとき**: 相2（気体）に比べて体積が非常に小さいため， $\overline{V}_1 \ll \overline{V}_2$ とみなせる．

これらの条件を，先ほど求めた第3項の係数部分に適用する．

$$\frac{\overline{V}_2 \beta_2 - \overline{V}_1 \beta_1}{\overline{V}_2 - \overline{V}_1} = \frac{\overline{V}_2 (1/T) - \overline{V}_1 \beta_1}{\overline{V}_2 - \overline{V}_1}$$

分母・分子を $\overline{V}_2$ で割ると，

$$= \frac{1/T - (\overline{V}_1/\overline{V}_2) \beta_1}{1 - (\overline{V}_1/\overline{V}_2)}$$

ここで $\overline{V}_1/\overline{V}_2 \approx 0$ であるため，

$$\frac{\overline{V}_2 \beta_2 - \overline{V}_1 \beta_1}{\overline{V}_2 - \overline{V}_1} \approx \frac{1/T}{1} = \frac{1}{T}$$

となる．
これを元の式に代入すると，

$$\frac{dL}{dT} \cong C_{p2} - C_{p1} + \frac{L}{T} - L \left(\frac{1}{T}\right) = C_{p2} - C_{p1}$$

となり，近似が成立することが示された．

## 解説

この問題は，相転移に伴う熱量（潜熱）が，温度や圧力の変化によってどのように変化するかを熱力学の基本関係式を用いて導出するものである．

1.  **全微分の利用**: 物理量 $L$ が $T$ と $p$ の関数であるとき，その変化率 $dL/dT$ を求めるには，温度による直接的な変化 $(\partial L/\partial T)_p$ と，圧力変化を介した間接的な変化 $(\partial L/\partial p)_T (dp/dT)$ の両方を考慮する必要がある．
2.  **Clapeyron（クラペイロン）の式**: 相転移が起こる際の圧力と温度の関係（相境界の傾き）を示す非常に重要な式である．
これを用いることで，圧力変化の寄与を温度変化に変換できる．
3.  **Maxwell（マックスウェル）の関係式**: エンタルピーやエントロピーの変化を，測定可能な体積や温度，圧力の変化に結びつけるための強力な道具である．
ここでは，エントロピーの変化を体積膨張係数 $\beta$ を用いて書き換えるために使用した．
4.  **近似の物理的意味**: 相2が気体，相1が液体・固体の場合，気体の体積が支配的になるため，転移熱の変化は主に「各相の定圧比熱の差」によって決まるという直感的な結果が得られる．
