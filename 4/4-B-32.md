# 演習問題【4-B-32】

## 解答

### 1．転移熱の定義と全微分

相1から相2への転移熱 $L$ を，転移に伴って吸収される熱量（1 mol 当たり）と定義する．
このとき，転移熱は両相のモルエンタルピーの差で与えられる．

```math
L=\overline H_2-\overline H_1
```

ここで， $\overline H_1,\overline H_2$ はそれぞれ相1，相2のモルエンタルピーである．

転移熱 $L$ は温度 $T$ と圧力 $p$ の関数である．
相平衡を保ちながら温度を変化させると，平衡圧力 $p$ も変化するため，連鎖律より，

```math
\frac{dL}{dT}
=
\left(\frac{\partial L}{\partial T}\right)_p
+
\left(\frac{\partial L}{\partial p}\right)_T
\frac{dp}{dT}
\tag{1}
```

となる．
したがって，式 (1) の右辺にある3つの量を求めればよい．

### 2．温度に関する偏微分

転移熱の定義

```math
L=\overline H_2-\overline H_1
```

を，圧力を一定に保って温度で偏微分する．
定圧モル比熱の定義は，

```math
C_{p1}=
\left(\frac{\partial\overline H_1}{\partial T}\right)_p,
\qquad
C_{p2}=
\left(\frac{\partial\overline H_2}{\partial T}\right)_p
```

である．
したがって，

```math
\begin{aligned}
\left(\frac{\partial L}{\partial T}\right)_p
&=
\left(\frac{\partial\overline H_2}{\partial T}\right)_p
-
\left(\frac{\partial\overline H_1}{\partial T}\right)_p\\
&=C_{p2}-C_{p1}
\end{aligned}
\tag{2}
```

を得る．

### 3．相平衡条件と Clapeyron の式

相1と相2が平衡にあるとき，両相のモル Gibbs 自由エネルギーは等しい．

```math
\overline G_1=\overline G_2
```

Gibbs 自由エネルギーの微分関係

```math
d\overline G=-\overline S\,dT+\overline V\,dp
```

を用いると，相平衡の変化に沿って，

```math
-\overline S_1\,dT+\overline V_1\,dp
=
-\overline S_2\,dT+\overline V_2\,dp
```

となる．
これを整理すると，

```math
(\overline V_2-\overline V_1)\,dp
=
(\overline S_2-\overline S_1)\,dT
```

したがって，

```math
\frac{dp}{dT}
=
\frac{\overline S_2-\overline S_1}
{\overline V_2-\overline V_1}
```

である．
一方，相平衡では $\Delta G=0$ であるため，転移熱について

```math
L=T(\overline S_2-\overline S_1)
```

が成り立つ．
これを代入すれば，Clapeyron の式

```math
\boxed{
\frac{dp}{dT}
=
\frac{L}{T(\overline V_2-\overline V_1)}
}
\tag{3}
```

が得られる．

### 4．圧力に関する偏微分

次に，

```math
\left(\frac{\partial L}{\partial p}\right)_T
=
\left(\frac{\partial\overline H_2}{\partial p}\right)_T
-
\left(\frac{\partial\overline H_1}{\partial p}\right)_T
\tag{4}
```

を求める．

モルエンタルピーの基本関係式は，

```math
d\overline H=T\,d\overline S+\overline V\,dp
```

である．
温度を一定にして圧力で偏微分すると，

```math
\left(\frac{\partial\overline H}{\partial p}\right)_T
=
T\left(\frac{\partial\overline S}{\partial p}\right)_T
+\overline V
\tag{5}
```

となる．

ここで，Maxwell の関係式

```math
\left(\frac{\partial\overline S}{\partial p}\right)_T
=
-\left(\frac{\partial\overline V}{\partial T}\right)_p
```

を用いる．
また，熱膨張係数 $\beta$ の定義は，

```math
\beta=
\frac{1}{\overline V}
\left(\frac{\partial\overline V}{\partial T}\right)_p
```

であるため，

```math
\left(\frac{\partial\overline V}{\partial T}\right)_p
=\overline V\beta
```

となる．
これを式 (5) に代入すると，

```math
\begin{aligned}
\left(\frac{\partial\overline H}{\partial p}\right)_T
&=-T\overline V\beta+\overline V\\
&=\overline V(1-T\beta)
\end{aligned}
```

を得る．

この関係を相1と相2にそれぞれ適用して式 (4) に代入すると，

```math
\begin{aligned}
\left(\frac{\partial L}{\partial p}\right)_T
={}&\overline V_2(1-T\beta_2)
-\overline V_1(1-T\beta_1)\\
={}&(\overline V_2-\overline V_1)
-T(\overline V_2\beta_2-\overline V_1\beta_1)
\end{aligned}
\tag{6}
```

となる．

### 5．各式を組み合わせて転移熱の変化を求める

式 (2)，(3)，(6) を全微分の式 (1) に代入する．

```math
\begin{aligned}
\frac{dL}{dT}
={}&C_{p2}-C_{p1}\\
&+\left[
(\overline V_2-\overline V_1)
-T(\overline V_2\beta_2-\overline V_1\beta_1)
\right]
\frac{L}{T(\overline V_2-\overline V_1)}
\end{aligned}
```

右辺の第2項を展開すると，

```math
\begin{aligned}
\frac{dL}{dT}
={}&C_{p2}-C_{p1}
+\frac{L}{T}\\
&-L\frac{\overline V_2\beta_2-\overline V_1\beta_1}
{\overline V_2-\overline V_1}
\end{aligned}
```

したがって，求める関係式は，

```math
\boxed{
\frac{dL}{dT}
=
C_{p2}-C_{p1}
+\frac{L}{T}
-L\frac{\overline V_2\beta_2-\overline V_1\beta_1}
{\overline V_2-\overline V_1}
}
```

である．

### 6．相2が理想気体で，相1が固体または液体の場合

最後に，転移熱の変化が

```math
\frac{dL}{dT}\cong C_{p2}-C_{p1}
```

と近似できることを示す．

相2が理想気体の場合，状態方程式は

```math
p\overline V_2=RT
```

である．
圧力一定で温度を変化させると，

```math
\left(\frac{\partial\overline V_2}{\partial T}\right)_p
=\frac{R}{p}
=\frac{\overline V_2}{T}
```

となる．
よって，理想気体の熱膨張係数は，

```math
\boxed{
\beta_2=\frac{1}{T}
}
```

である．

また，相1が固体または液体で，相2が気体である場合，通常は気体のモル体積が固体・液体のモル体積より十分大きい．
すなわち，

```math
\overline V_1\ll\overline V_2
```

と近似できる．
このとき，

```math
\begin{aligned}
&\frac{\overline V_2\beta_2-\overline V_1\beta_1}
{\overline V_2-\overline V_1}\\
&\qquad=
\frac{\beta_2-(\overline V_1/\overline V_2)\beta_1}
{1-\overline V_1/\overline V_2}
\cong\beta_2
=\frac{1}{T}
\end{aligned}
```

となる．
したがって，導出した一般式の最後の項は，

```math
-L\frac{\overline V_2\beta_2-\overline V_1\beta_1}
{\overline V_2-\overline V_1}
\cong-\frac{L}{T}
```

と近似できる．
これは式中の $+L/T$ と相殺されるため，

```math
\frac{dL}{dT}
\cong C_{p2}-C_{p1}
+\frac{L}{T}-\frac{L}{T}
```

となる．
ゆえに，

```math
\boxed{
\frac{dL}{dT}\cong C_{p2}-C_{p1}
}
```

が示された．

この近似は，気体と固体・液体のモル体積の差が十分大きく，相1の体積と熱膨張係数の寄与を無視できる場合に成立するものである．
