# 演習問題【4-A-1】

## 解答

### (i) 2相間の転移と共通接線について

#### 1. 相平衡の条件

2つの相（相aと相b）が温度 $T$ において平衡状態にあるためには，以下の3つの物理量が等しくなければならない．
1. 温度 $T$
2. 圧力 $p$
3. モルあたりのギブズ自由エネルギー $G$

したがって，平衡状態においては次が成り立つ．

$$T_a = T_b = T$$

$$p_a = p_b = p$$

$$G_a = G_b = G$$

#### 2. 自由エネルギーと圧力の関係

等温条件下（ $T$ が一定）において，ヘルムホルツ自由エネルギー $F(V, T)$ と圧力 $p$ の間には以下の関係がある．

$$p = -\left( \frac{\partial F}{\partial V} \right)_T$$

これは，等温線（ $F$ - $V$ グラフ）における接線の傾きが圧力の負の値であることを意味している．

相aと相bが圧力 $p$ で平衡にあるとき，それぞれの相の自由エネルギー $F_a$ と $F_b$ のグラフの接線の傾きは，圧力の負の値として等しくなければならない．

$$p = -\left( \frac{\partial F_a}{\partial V_a} \right)_T = -\left( \frac{\partial F_b}{\partial V_b} \right)_T \quad \cdots (\text{A})$$

式(A)は，相aの点 $A(V_A, F_a)$ と相bの点 $B(V_B, F_b)$ における接線の傾きが等しいことを示している．

#### 3. ギブズ自由エネルギーの等しさ

次に，ギブズ自由エネルギー $G$ は $F$ と $p, V$ を用いて以下のように表される．

$$G = F + pV$$

平衡条件 $G_a = G_b$ を代入すると，

$$F_a + pV_a = F_b + pV_b$$

これを整理して $p$ について解くと，

$$p(V_b - V_a) = F_a - F_b$$

$$p = \frac{F_a - F_b}{V_b - V_a} \quad \cdots (\text{B})$$

式(B)は，2点 $A(V_A, F_a)$ と $B(V_B, F_b)$ を結ぶ直線の傾きが $p$ であることを示している．

#### 4. 結論

式(A)は「2点における接線の傾きが等しい」ことを示し，式(B)は「2点を結ぶ直線の傾きがその時の圧力 $p$ である」ことを示している．
これら2つの条件が同時に満たされるとき，その直線は相aのグラフ $F_a$ と相bのグラフ $F_b$ の両方に接する「共通接線」となる．
したがって，2相の間の転移（相転移）は，これら2つのグラフの共通接線を引くことによって定まる．

### (ii) Maxwell の規則の証明

#### 1. 積分による関係式の導出

(i) で示した平衡条件 $G_a = G_b$ ，すなわち $F_a + pV_a = F_b + pV_b$ から出発する．
これを変形すると，

$$F_b - F_a = -p(V_b - V_a) \quad \cdots (\text{C})$$

となる．

ここで，関数 $F(V)$ が相aと相bの間で連続的に定義されていると仮定する．
このとき，微積分学の基本定理を用いると，左辺は次のように積分形式で書くことができる．

$$F_b - F_a = \int_{V_a}^{V_b} \left( \frac{\partial F}{\partial V} \right)_T dV$$

ここで，圧力の定義 $p(V) = -\left( \frac{\partial F}{\partial V} \right)_T$ ，すなわち $\left( \frac{\partial F}{\partial V} \right)_T = -p(V)$ を用いると，

$$F_b - F_a = \int_{V_a}^{V_b} (-p(V)) dV = -\int_{V_a}^{V_b} p(V) dV$$

となる．

これを式(C)に代入すると，

$$-\int_{V_a}^{V_b} p(V) dV = -p(V_b - V_a)$$

両辺のマイナスを払って，

$$\int_{V_a}^{V_b} p(V) dV = p(V_b - V_a) \quad \cdots (\text{D})$$

が得られる．

#### 2. 幾何学的な解釈（Maxwell の規則）

式(D)の幾何学的な意味を考える．
- 左辺 $\int_{V_a}^{V_b} p(V) dV$ は，圧力 $p(V)$ の曲線と $V$ 軸で囲まれた面積を表す．
- 右辺 $p(V_b - V_a)$ は，高さ $p$ ，幅 $V_b - V_a$ の長方形の面積を表す．

この関係は，曲線 $p(V)$ と水平な直線 $p = \text{const.}$ とによって囲まれる領域において，曲線の下側にある面積（「くぼみ」の部分）と曲線の上側にある面積（「膨らみ」の部分）が等しいことを意味する．
すなわち，

$$\int_{V_a}^{V_b} (p(V) - p) dV = 0$$

となり，これは曲線の下にできる面積（ADCA）と，曲線の上にできる面積（CBEC）が相殺してゼロになることを示している．
これが，相転移における圧力 $p$ を決定するための **Maxwell の規則** である．

## 解説

### 相平衡と自由エネルギー

物質が相転移を起こすとき，系は最も安定な状態（自由エネルギーが最小の状態）になろうとする．
2つの相が共存している状態では，どちらの相にいても自由エネルギーが変わらないため， $G_a = G_b$ という条件が重要になる．

### なぜ共通接線なのか？

$F$-$V$ グラフにおいて，ある点での接線の傾きは圧力のマイナスを表す．
- 共通接線が引けるということは，その接線の傾き（圧力）が，2つのグラフの両方の点で一致していることを意味する．
- 同時に，その接線が2つの点を結んでいるということは，その接線上の点における $F + pV$ （つまり $G$ ）の値が等しくなっていることを意味する．
これらこそが相平衡の条件そのものなのである．

### Maxwell の規則の物理的意義

実際の物質（例えば水と水蒸気）の圧力 $p$ と体積 $V$ の関係（状態方程式）は，相転移領域では単純な形にならない．
Maxwell の規則は，実験的に得られた $p(V)$ の曲線から，どこで相転移が起こるのか（どの圧力が共存圧力なのか）を，面積の等価性を用いて数学的に決定できる非常に強力な手法である．
