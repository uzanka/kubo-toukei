# 演習問題【4-A-1】

## 解答

### (i) 2相間の転移と共通接線

温度 $T$ において，相 $a$ と相 $b$ が平衡にある条件は，両相の温度，圧力，および化学ポテンシャルがそれぞれ等しいことである．
純物質では，化学ポテンシャルはモルあたりのギブズ自由エネルギーに等しい．
以下では，記号 $F$ ， $V$ ， $G$ をそれぞれモルあたりのヘルムホルツ自由エネルギー，モル体積，モルあたりのギブズ自由エネルギーとして用いる．
全系の量を用いる場合も，同じ基準に統一すれば同様の議論が成り立つ．

したがって，平衡条件は

```math
T_a=T_b=T,\qquad p_a=p_b=p,
```

```math
G_a=G_b
```

である．

まず，ヘルムホルツ自由エネルギー $F$ の微分形は

```math
dF=-S\,dT-p\,dV
```

である．
ここで， $S$ はモルあたりのエントロピーである．
温度 $T$ を一定に保つと $dT=0$ となるため，

```math
\left(\frac{\partial F}{\partial V}\right)_T=-p
```

を得る．
したがって， $F$-$V$ グラフにおける接線の傾きは，圧力の負の値である．

相 $a$ と相 $b$ の平衡状態におけるモル体積をそれぞれ $V_a$ ， $V_b$ とすると，両相の圧力が等しいことから，

```math
-\left(\frac{\partial F_a}{\partial V_a}\right)_T
=
-\left(\frac{\partial F_b}{\partial V_b}\right)_T
=p
\tag{1}
```

が成り立つ．
すなわち，2つの自由エネルギー曲線の接線の傾きは等しい．

次に，モルあたりのギブズ自由エネルギーは

```math
G=F+pV
```

で与えられる．
平衡条件 $G_a=G_b$ より，

```math
F_a+pV_a=F_b+pV_b
```

となる．
これを整理すると，

```math
p(V_b-V_a)=F_a-F_b
```

したがって，

```math
\frac{F_b-F_a}{V_b-V_a}=-p
\tag{2}
```

を得る．
式 (2) の左辺は， $F$-$V$ グラフ上の2点
$(V_a,F_a)$ ， $(V_b,F_b)$ を結ぶ直線の傾きである．
この傾きは $-p$ であり，式 (1) による各曲線の接線の傾きとも等しい．

ゆえに，2点を結ぶ直線は相 $a$ と相 $b$ の自由エネルギー曲線の両方に接する共通接線である．
したがって，一定温度における2相間の転移は，両相の自由エネルギー曲線に共通接線を引くことによって定まる．
共通接線の傾きの負の値が，2相の共存圧力 $p$ である．

### (ii) Maxwell の規則の証明

(i) で示したように，2相の平衡条件から

```math
F_b-F_a=-p(V_b-V_a)
\tag{3}
```

が得られる．

ここで，解答例と同様に，両相の間の体積領域にも $F(V)$ が連続的かつ微分可能な関数として形式的に定義されていると仮定する．
この領域には，実際には安定な平衡状態として実現しない状態が含まれていてもよい．
この仮定のもとでは，微積分学の基本定理より，

```math
F_b-F_a
=
\int_{V_a}^{V_b}
\left(\frac{\partial F}{\partial V}\right)_T dV
```

と表せる．
さらに，

```math
\left(\frac{\partial F}{\partial V}\right)_T=-p(V)
```

を用いると，

```math
F_b-F_a=-\int_{V_a}^{V_b}p(V)\,dV
\tag{4}
```

となる．
ここで， $p(V)$ は形式的に定義された曲線上の体積 $V$ における圧力であり， $p$ は両相が共存するときの一定の圧力である．

式 (3) と式 (4) を等置すると，

```math
-\int_{V_a}^{V_b}p(V)\,dV
=-p(V_b-V_a)
```

であるから，

```math
\int_{V_a}^{V_b}p(V)\,dV
=p(V_b-V_a)
\tag{5}
```

を得る．
両辺をまとめると，

```math
\boxed{
\int_{V_a}^{V_b}[p(V)-p]\,dV=0
}
\tag{6}
```

となる．

式 (6) の左辺は，圧力曲線 $p(V)$ と水平線 $p(V)=p$ の間の符号付き面積を表す．
したがって，曲線が水平線の上側にある領域の面積と，下側にある領域の面積は等しい．

以上より，2相の平衡圧力は，圧力曲線と水平線との間にできる2つの領域の面積が等しくなるように定められる．
これが Maxwell の規則である．
