# 例題【4-R-5】

## 解答

Cu–Ag（二元合金）の状態図を用いて，冷却・加熱したときの相の変化を考える．

### (i) K 点の溶液を冷却した場合

K 点は液相領域にあるため，最初は液体である．
冷却すると，次の経過をたどる．

1. 液相 $L$ ：冷却を始めた直後は，全体が液体である．
2. 液相線に到達：液相線を横切ると，固相 $\beta$ が析出し始め，液相 $L+\beta$ の二相共存状態となる．
3. 共融点 $E$ （779°C）に到達：残っている液相が，一定温度で $L\longrightarrow\alpha+\beta$ の共融反応を起こす．
4. 779°C以下：液相がなくなり，固相 $\alpha+\beta$ の二相組織となる．

したがって，冷却に伴う相変化は

```math
\boxed{L\ \longrightarrow\ L+\beta\ \longrightarrow\ \alpha+\beta}
```

である．

### (ii) H 点の $\alpha$ 固溶体を加熱した場合

H 点は $\alpha$ 固溶相の単相領域にあるため，最初は固体である．
加熱すると，次の経過をたどる．

1. 固相 $\alpha$ ：加熱を始めた直後は，全体が $\alpha$ 固溶体である．
2. 固相線 ACF に到達：部分的に溶融が始まり，固相 $\alpha$ と液相 $L$ が共存する．
3. 液相線 AEB に到達：残っていた固相 $\alpha$ が溶けきり，全体が液体となる．

したがって，加熱に伴う相変化は

```math
\boxed{\alpha\ \longrightarrow\ L+\alpha\ \longrightarrow\ L}
```

である．

ポイント： 冷却では液相から固相が析出し，共融点で残りの液体が $\alpha+\beta$ に変化する．
一方，加熱では $\alpha$ 固溶体が部分的に溶け，最終的に液相になる．
