# 例題【4-R-5】

## 解答

以下では，閉じたCu–Ag合金を考え，全体の組成は冷却・加熱によって変化しないものとする．
また，十分に遅い冷却・加熱を行い，各温度で相平衡が成立するものとする．
急冷の場合には，原子の拡散が追いつかず，以下の平衡経路から外れることがある．

組成を表す変数を $x$ とする．
以下では，4-6図の横軸を左から右へ増加する組成座標として読み，問題文の相の指定に従って，β相側を低組成側，α相側を高組成側とする．
したがって，

```math
x_\beta<x_\alpha
```

である．
横軸がAg分率で表示されている場合，この座標では右へ進むほどAg分率が増加する．

### (i) K点で表される温度・組成の溶液を冷却した場合

K点は液相領域にあり，β初晶が析出する側の組成にある．
したがって，冷却開始時には合金は均一な液相 $L$ である．
全体組成を $x_0$ とする．

#### （1）液相線に到達するまで

K点から垂直に温度を下げる．液相線BE上のK′に到達するまでは，合金は液相のままである．

この間，温度は低下するが，液相の組成は全体組成 $x_0$ と等しく，変化しない．

#### （2）K′でβ初晶が析出し始める

K′の温度に達すると，β固溶体が初めて析出する．このとき，
- 液相の組成はK′
- β相の組成は同じ温度の固相側の点K″
で表される．

この図の組成座標では，

```math
x_\beta<x_0
```

であり，析出するβ相は液相より低組成側にある．
したがって，β相が析出していくと，残液の組成は高組成側へ移動する．横軸がAg分率の場合には，残液のAg分率が増加する．

#### （3）さらに冷却してβ相の析出が進行する

温度が低下するにつれてβ相の割合が増加し，液相の割合は減少する．

それぞれの相の組成は，各温度におけるタイラインの両端で決まり，
- 液相の組成は液相線BEに沿って変化する．
- β相の組成は固相側の境界BDに沿って変化する．
液相の組成は共融点Eの組成に近づく．

この二相共存状態での相の割合は，てこの法則から求められる．
液相の組成を $x_L$ ，β相の組成を $x_\beta$ とすると，

```math
x_\beta<x_0<x_L
```

であり，

```math
\boxed{
\frac{f_\beta}{f_L}
=
\frac{x_L-x_0}{x_0-x_\beta}
}
```

となる．
ここで $f_\beta$ ， $f_L$ はそれぞれβ相と液相の割合である．

#### （4）共融点Eに到達する

共融点Eの温度 $779^\circ\mathrm C$ に達すると，残っていた液相が一定温度で共融反応を起こす．

```math
\boxed{
L\longrightarrow\alpha+\beta
}
```

液相はα固溶体とβ固溶体に変化する．
共融点でのα相とβ相の組成は，それぞれ固相側の共融組成で決まる．

このとき，冷却前から存在していた初晶β相はそのまま残り，残液からα相とβ相が生成する．
したがって，共融反応直後の組織は，

```math
\boxed{
\text{初晶β相}
+
\text{共晶組織（α相＋β相）}
}
```

である．

つまり，合金全体はα相とβ相からなる二相組織であるが，組織形成の過程では初晶β相と共晶組織を区別する必要がある．

#### （5）共融点以下に冷却した場合

共融点以下では液相は存在せず，α相とβ相からなる固体となる．
さらに温度を下げると，固溶限が温度によって変化するため，α相とβ相の平衡組成および割合も変化する．

十分な時間が経過して固相内拡散が進めば，各相の組成はその温度での固溶限に近づく．

ここで，二相共存領域内の温度 $T_1$ を選ぶ．
その温度の水平なタイラインと，全体組成 $x_0$ を示す垂直線との交点を $K_1$ とする．
タイラインとα相側，β相側の境界との交点を，それぞれ $K_\alpha$ ， $K_\beta$ とする．
したがって，

```math
x_\beta<x_0<x_\alpha
```

である．

この温度におけるα相とβ相の割合を $f_\alpha$ ， $f_\beta$$ とすれば，てこの法則より，

```math
\boxed{
\frac{f_\alpha}{f_\beta}
=
\frac{x_0-x_\beta}{x_\alpha-x_0}
=
\frac{\overline{K_\beta K_1}}
{\overline{K_1K_\alpha}}
}
```

となる．

ここで，組成軸が質量分率の場合， $f_\alpha$ ， $f_\beta$ は各相の質量分率である．
原子分率またはモル分率の場合は，対応する原子数または物質量の割合となる．

以上より，K点から冷却したときの相変化は，

```math
\boxed{
L\longrightarrow L+\beta
\longrightarrow\alpha+\beta
}
```

である．
ただし，共融反応直後の組織は，初晶β相と共晶組織（α＋β）からなる．

### (ii) H点で表される組成のα固溶体を加熱した場合

H点はα固溶相の単相領域にあるため，加熱開始時には均一なα固溶体である．全体組成を \(x_0\) とする．

#### （1）固相線に到達するまで

H点から垂直に温度を上げる．固相線ACF上のH′に到達するまでは，α固溶体のままである．

この間，温度は上昇するが，固相の組成は全体組成 $x_0$ と等しく，変化しない．

#### （2）H′で液相が出現する

H′の温度に達すると，液相が初めて出現し，α固溶相と液相が共存する．
このとき，
- 固相の組成はH′に対応する．
- 液相の組成は同じ温度の液相線上のH″に対応する．

この図の組成座標では，

```math
x_L<x_0\leq x_\alpha
```

となる．
したがって，液相が生じると，残存するα固溶相は高組成側へ移動する．
横軸がAg分率の場合には，残存するα固溶相のAg分率が増加する．

#### （3）さらに加熱して融解が進行する

温度をさらに上げると，液相の割合が増加し，α固溶相の割合が減少する．

この間，
- α固溶相の組成は固相線ACFに沿って変化する．
- 液相の組成は液相線に沿って変化する．

また，残存するα固溶相の組成は高組成側へ移動し，液相の組成は全体組成に近づく．

α相と液相の割合は，てこの法則によって求められる．
各相の組成を $x_\alpha$ ， $x_L$ とすれば，

```math
x_L<x_0<x_\alpha
```

であり，

```math
\boxed{
\frac{f_L}{f_\alpha}
=
\frac{x_\alpha-x_0}{x_0-x_L}
}
```

となる．

#### （4）液相線に到達する

全体組成 $x_0$ に対応する液相線上の温度に達すると，最後に残っていたα固溶相が融解する．

このとき，合金全体が液相となり，液相の組成は全体組成と一致する．
すなわち，

```math
x_L=x_0
```

となる．

以後，さらに温度を上げても相変化は起こらず，液相のまま温度が上昇する．

以上より，加熱時の相変化は，

```math
\boxed{
\alpha\longrightarrow L+\alpha\longrightarrow L
}
```

である．

### 補足：てこの法則

二相共存領域では，温度を一定にしたとき，タイラインの両端が各相の組成を示す．
全体組成 $x_0$ が両相の組成 $x_\alpha$ ， $x_\beta$ の間にある場合，

```math
x_\beta<x_0<x_\alpha
```

である．

全体に占めるα相とβ相の割合をそれぞれ $f_\alpha$ ， $f_\beta$ とすると，

```math
f_\alpha+f_\beta=1
```

および，

```math
x_0=f_\alpha x_\alpha+f_\beta x_\beta
```

が成立する．
これらから，

```math
\boxed{
\frac{f_\alpha}{f_\beta}
=
\frac{x_0-x_\beta}{x_\alpha-x_0}
}
```

を得る．

この式は，組成 $x$ と相の割合 $f$ を同じ基準で定義した場合に成立する．
横軸が質量分率なら質量基準の相分率を，原子分率なら原子数または物質量基準の相分率を用いる．
