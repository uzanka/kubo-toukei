# 例題【4-R-5】

## 解答

### (i) K 点で表される温度・組成の溶液を冷却した場合

K 点は液相領域にあるため，冷却を開始したとき，合金は均一な液相 $L$ である．
全体の組成は冷却によって変化しないものとする．

（1）液相線に到達するまで

K 点から垂直に温度を下げると，液相線 BE 上の K′ に到達するまでは，液相のままである．
この間，温度は低下するが，液相の組成は全体の組成と等しく，変化しない．

（2）K′ で β 固溶体が析出し始める

K′ の温度に達すると，初めて β 固溶体が析出する．
このとき，液相の組成は K′ に対応し，析出する β 相の組成は，同じ温度における固相線 BD 上の K″ に対応する．

Cu–Ag 系では，β 相は Cu を主成分とする固溶体であり，析出した β 相の Ag 分率は液相より小さい．
したがって，β 相が析出して Cu を多く取り込むほど，残液の Ag 分率は増加する．

（3）さらに冷却すると，β 相の析出が進行する

温度をさらに下げると，β 相が引き続き析出する．
温度が低下するにつれて，液相の組成は液相線 BE に沿って E に近づき，β 相の組成は固相線 BD に沿って変化する．

このとき，液相と β 相の分率も温度とともに変化する．
各温度での二相の組成を状態図から読み取り，てこの法則を適用すれば，それぞれの分率を求められる．

（4）共融点 E に到達する

共融点 E の温度 $779^\circ\mathrm{C}$ に達すると，残っていた液相は一定温度で共融反応を起こす．

```math
L\longrightarrow\alpha+\beta
```

すなわち，液相が α 固溶体と β 固溶体に変化する．
共融点での α 相の組成は C，β 相の組成は D に対応する．
この反応が完了すると，液相はすべて消失し，合金は α 相と β 相からなる固体となる．

（5）共融点以下で十分に時間が経過した場合

さらに温度を下げると，α 相と β 相からなる固体のままである．
ただし，固体内部での原子の拡散が進行するため，α 相と β 相の組成はそれぞれの温度における固溶限に近づく．

例えば，十分低い温度 $K_1$ で平衡に達したとすると，α 相と β 相の組成はそれぞれ $K_\alpha$ ， $K_\beta$ に対応する．
全体の組成が $K_1$ で示される場合，両相の量の比は，てこの法則により

```math
\boxed{
\frac{N(K_\alpha)}{N(K_\beta)} = \frac{\overline{K_\beta K_1}} {\overline{K_1K_\alpha}}
}
```

となる．
ここで， $N(K_\alpha)$ ， $N(K_\beta)$ は各相に含まれる原子数を表す．
このような平衡状態に達するには，固相内の拡散が必要であるため，相当な時間を要する場合がある．

以上より，冷却時の相変化は

```math
\boxed{
L\longrightarrow L+\beta \longrightarrow\alpha+\beta
}
```

である．
ただし，最初の二相共存状態では，冷却に伴って各相の組成と分率が変化することが重要である．

### (ii) H 点で表される組成の α 固溶体を加熱した場合

H 点は α 固溶相の単相領域にあるため，加熱を開始したとき，合金は均一な α 固溶体である．
全体の組成は加熱によって変化しないものとする．

（1）固相線に到達するまで

H 点から垂直に温度を上げると，固相線 ACF 上の H′ に到達するまでは，α 固溶体のままである．
この間，温度は上昇するが，固相の組成は全体の組成と等しく，変化しない．

（2）H′ で液相が出現する

H′ の温度に達すると，初めて液相が出現し，α 固溶相と液相が共存する．
このとき，固相の組成は H′ に対応し，液相の組成は同じ温度の液相線上の H″ に対応する．

H″ の Ag 分率は H の Ag 分率より小さい．
そのため，融解によって Ag の少ない液相が生成すると，残った α 固溶相の Ag 分率は増加する．

（3）さらに加熱すると，融解が進行する

温度をさらに上げると，液相の割合が増加し，固相の割合が減少する．
このとき，固相の組成は固相線 ACF に沿って A の方向へ変化し，液相の組成も液相線に沿って変化する．

したがって，残存する α 固溶相の Ag 分率は次第に増加し，二相の組成と分率は温度とともに変化する．

（4）液相線に到達する

全体の組成に対応する液相線上の温度 $H_1'$ に達すると，最後に残っていた α 固溶相が融解する．
このとき，全量が液相となり，その組成は全体の組成と一致する．
図では，この液相の組成が $H_1''$ に対応する．

以後，さらに温度を上げても相変化は起こらず，液相のまま温度が上昇する．

以上より，加熱時の相変化は

```math
\boxed{
\alpha\longrightarrow L+\alpha \longrightarrow L
}
```

である．

なお，解答例のように，融解して生じた液相を順次取り除く操作を行う場合は，通常の加熱とは異なる．
液相を取り除くと残存する固相の全体組成が変化するため，固相の組成は通常の加熱過程とは異なる経路をたどり，条件によっては最終的に純 Ag に近づく．

## 3．補足：てこの法則

二相共存領域では，温度を一定にしたとき，状態図上のタイラインの両端がそれぞれの相の組成を示す．
全体の組成がその間にある場合，各相の量の比はタイラインの長さの比で求められる．

例えば，α 相と β 相が共存し，全体の組成を $x_0$ ，各相の組成を $x_\alpha$ ， $x_\beta$ とすると，原子数を基準にしたてこの法則は

```math
\frac{N\_\alpha}{N_\beta} =\frac{x_\beta-x_0}{x_0-x_\alpha}
```

である．
これにより，状態図から各相の組成だけでなく，その割合も定量的に求めることができる．
