# 演習問題【4-A-30】

## 解答

### 1. 正味の反応の特定

与えられた電極反応は以下の通りである：
(1) $\frac{1}{2}\text{H}_2(\text{g}) \rightarrow \text{H}^+(\text{HCl}, \text{aq}, x) + \text{e}$
(2) $\text{AgCl}(\text{c}) + \text{e} \rightarrow \text{Ag}(\text{c}) + \text{Cl}^-(\text{HCl}, \text{aq}, x)$

これら2つの反応を足し合わせると，電子 ( $\text{e}$ ) が相殺され，正味の反応が得られる：

$$\frac{1}{2}\text{H}_2(\text{g}) + \text{AgCl}(\text{c}) \rightarrow \text{Ag}(\text{c}) + \text{H}^+(\text{HCl}, \text{aq}, x) + \text{Cl}^-(\text{HCl}, \text{aq}, x)$$

ここで， $\text{H}^+$ と $\text{Cl}^-$ は溶液中において $\text{HCl}$ 分子として振る舞うため，

$$\frac{1}{2}\text{H}_2(\text{g}) + \text{AgCl}(\text{c}) \rightarrow \text{Ag}(\text{c}) + \text{HCl}(\text{aq}, x)$$

となる．
これが電池の正味の反応である．

### 2. ギブズ自由エネルギー変化 $\Delta G$ の計算

反応の自由エネルギー変化 $\Delta G$ は，反応物の化学ポテンシャルの和と，生成物の化学ポテンシャルの和の差として定義される．
反応式 $\frac{1}{2}\text{H}_2(\text{g}) + \text{AgCl}(\text{c}) \rightarrow \text{Ag}(\text{c}) + \text{HCl}(\text{aq}, x)$ に基づくと：

$$\Delta G = \bar{G}_{\text{Ag}(\text{c})} + \bar{G}_{\text{HCl}(\text{aq})} - \left( \frac{1}{2}\bar{G}_{\text{H}_2(\text{g})} + \bar{G}_{\text{AgCl}(\text{c})} \right)$$

$$\Delta G = \bar{G}_{\text{Ag}(\text{c})} + \bar{G}_{\text{HCl}(\text{aq})} - \frac{1}{2}\bar{G}_{\text{H}_2(\text{g})} - \bar{G}_{\text{AgCl}(\text{c})}$$

各成分の化学ポテンシャル $\bar{G}_i$ を，標準状態の化学ポテンシャル $\bar{G}_i^0$ と，濃度や圧力による補正項を用いて表す．

*   **固体成分 (Ag, AgCl):**
    純粋な固体であるため，化学ポテンシャルは標準状態の化学ポテンシャルに等しくなる．
    $\bar{G}_{\text{Ag}(\text{c})} = \bar{G}_{\text{Ag}(\text{c})}^0$
    $\bar{G}_{\text{AgCl}(\text{c})} = \bar{G}_{\text{AgCl}(\text{c})}^0$

*   **気体成分 ( $\text{H}_2$ ):**
    理想気体の化学ポテンシャルは，圧力 $p_{\text{H}_2}$ を用いて以下のように表される．
    $\bar{G}_{\text{H}_2(\text{g})} = \bar{G}_{\text{H}_2(\text{g})}^0 + RT \ln p_{\text{H}_2}$

*   **溶液成分 ( $\text{HCl}$ ):**
    $\text{HCl}$ 溶液の化学ポテンシャルは，濃度 $x$ と平均イオン活動度 $\gamma$ を用いて，次のように表される（問題の条件に基づく）．
    $\bar{G}_{\text{HCl}(\text{aq})} = \phi_{\text{HCl}}^0 + 2RT \ln(x\gamma)$
    (※これは $\text{H}^+$ と $\text{Cl}^-$ の活動度 $a = x\gamma$ を用いた $\mu = \mu^0 + 2RT \ln a$ の形に対応している)

これらを $\Delta G$ の式に代入する：

$$\Delta G = \bar{G}_{\text{Ag}(\text{c})}^0 + (\phi_{\text{HCl}}^0 + 2RT \ln(x\gamma)) - \frac{1}{2}(\bar{G}_{\text{H}_2(\text{g})}^0 + RT \ln p_{\text{H}_2}) - \bar{G}_{\text{AgCl}(\text{c})}^0$$

$$\Delta G = \left( \bar{G}_{\text{Ag}(\text{c})}^0 + \phi_{\text{HCl}}^0 - \frac{1}{2}\bar{G}_{\text{H}_2(\text{g})}^0 - \bar{G}_{\text{AgCl}(\text{c})}^0 \right) + 2RT \ln(x\gamma) - \frac{1}{2}RT \ln p_{\text{H}_2}$$

ここで，括弧内の項を標準反応自由エネルギー変化 $\Delta G^0$ と定義する．

$$\Delta G^0 = \bar{G}_{\text{Ag}(\text{c})}^0 + \phi_{\text{HCl}}^0 - \frac{1}{2}\bar{G}_{\text{H}_2(\text{g})}^0 - \bar{G}_{\text{AgCl}(\text{c})}^0$$

また， $\frac{1}{2}RT \ln p_{\text{H}_2} = RT \ln(p_{\text{H}_2}^{1/2})$ と書き換えられるので，

$$\Delta G = \Delta G^0 + 2RT \ln(x\gamma) - RT \ln(p_{\text{H}_2}^{1/2})$$

### 3. 起電力を $E$ で表す

電池の起電力 $E$ と自由エネルギー変化 $\Delta G$ の間には，以下の関係がある．

$$\Delta G = -\mathcal{F}E$$

（ここで $\mathcal{F}$ はファラデー定数である）

これを用いて $E$ を求める：

$$-\mathcal{F}E = \Delta G^0 + 2RT \ln(x\gamma) - RT \ln(p_{\text{H}_2}^{1/2})$$

$$E = -\frac{\Delta G^0}{\mathcal{F}} - \frac{2RT}{\mathcal{F}} \ln(x\gamma) + \frac{RT}{\mathcal{F}} \ln(p_{\text{H}_2}^{1/2})$$

ここで， $E^0 = -\frac{\Delta G^0}{\mathcal{F}}$ と定義すると，

$$E = E^0 - \frac{2RT}{\mathcal{F}} \ln(x\gamma) + \frac{RT}{\mathcal{F}} \ln(p_{\text{H}_2}^{1/2})$$

となり，題意の形式が示された．

## 解説

この問題は，化学平衡と電気化学の基本原理である「化学ポテンシャル」と「自由エネルギー変化」の関係を理解しているかを問うものである．

1.  **正味の反応**:
  電池の反応は，個別の電極反応の組み合わせである．
  電子が移動して打ち消し合う（相殺される）プロセスを考えることで，電池全体として何が起こっているか（どの物質が消費され，何が生成されるか）を明らかにできる．
2.  **化学ポテンシャル ( $\mu$ または $\bar{G}$ )**:
  物質がその環境（圧力，濃度など）によって持つ「化学的なエネルギーの勢い」である．
    *   理想的な気体の場合，圧力が増えると化学ポテンシャルは対数的に増加する．
    *   溶液中のイオンの場合，濃度（正確には活動度）が増えると化学ポテンシャルは増加する．
3.  **自由エネルギー変化 ( $\Delta G$ )**:
  反応が進むとき，反応物側の「勢い」の合計が，生成物側の「勢い」の合計よりも大きい場合，反応は自発的に進む．
  その「勢いの差」が $\Delta G$ である．
4.  **起電力 ( $E$ ) と $\Delta G$ の関係**:
  電気化学において，化学的なエネルギーの差 ( $\Delta G$ ) は，電子を押し出す電気的な力 ( $\mathcal{F}E$ ) に変換される．
  そのため， $\Delta G = -\mathcal{F}E$ という関係が成り立つ．
  負の符号は，反応が自発的に進むとき ( $\Delta G < 0$ )，起電力 $E$ が正になることを意味している．
