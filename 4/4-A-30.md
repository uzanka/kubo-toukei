# 演習問題【4-A-30】

## 解答

### 1．正味の反応を求める

与えられた電極反応は，次の2つである．

水素電極での酸化反応：

```math
\frac{1}{2}\mathrm{H_2(g)}
\longrightarrow
\mathrm{H^+(aq)}+\mathrm{e^-}
```

銀－塩化銀電極での還元反応：

```math
\mathrm{AgCl(c)}+\mathrm{e^-}
\longrightarrow
\mathrm{Ag(c)}+\mathrm{Cl^-(aq)}
```

これらの反応を加えると，生成物側の電子 $\mathrm{e^-}$ と反応物側の電子 $\mathrm{e^-}$ が相殺される．
したがって，電池全体の正味の反応は，

```math
\frac{1}{2}\mathrm{H_2(g)}+\mathrm{AgCl(c)}
\longrightarrow
\mathrm{Ag(c)}+\mathrm{H^+(aq)}+\mathrm{Cl^-(aq)}
```

となる．
水溶液中では， $\mathrm{H^+}$ と $\mathrm{Cl^-}$ がそれぞれ $\mathrm{HCl}$ の構成イオンに対応するため，この反応は次のように表せる．

```math
\boxed{
\frac12\mathrm{H_2(g)}+\mathrm{AgCl(c)}
\longrightarrow
\mathrm{Ag(c)}+\mathrm{HCl(aq)}
}
```

これが電池の正味の反応である．

### 2．反応のギブズ自由エネルギー変化を求める

反応のギブズ自由エネルギー変化 $\Delta G$ は，生成物の化学ポテンシャルの総和から，反応物の化学ポテンシャルの総和を差し引いたものである．

正味の反応に基づいて，

```math
\begin{aligned}
\Delta G={}&
\bar G_{\mathrm{Ag(c)}}+
\bar G_{\mathrm{HCl(aq)}}\\
&-\frac{1}{2}\bar G_{\mathrm{H_2(g)}}-
\bar G_{\mathrm{AgCl(c)}}
\end{aligned}
```

と書ける．
ここで， $\bar G_i$ は成分 $i$ のモルギブズ自由エネルギー，すなわち化学ポテンシャルを表す．

各成分の化学ポテンシャルを，標準状態の値と濃度または圧力に依存する項に分けて表す．

#### (1) 固体 Ag と AgCl

純粋な固体については，圧力による化学ポテンシャルの変化を無視すると，標準状態の化学ポテンシャルで近似できる．
したがって，

```math
\bar G_{\mathrm{Ag(c)}}=
\bar G_{\mathrm{Ag(c)}}^0
```

```math
\bar G_{\mathrm{AgCl(c)}}=
\bar G_{\mathrm{AgCl(c)}}^0
```

である．

#### (2) 気体 H₂

理想気体の化学ポテンシャルは，標準圧力 $p^0$ を用いて，

```math
\bar G_{\mathrm{H_2(g)}}=
\bar G_{\mathrm{H_2(g)}}^0+
RT\ln\frac{p_{\mathrm{H_2}}}{p^0}
```

と表される．
以下では，圧力を標準圧力で割った無次元量を用いる表記を簡略化し，問題文の記法に従って圧力項を $\ln p_{\mathrm{H_2}}$ と書く．
よって，

```math
\bar G_{\mathrm{H_2(g)}}=
\bar G_{\mathrm{H_2(g)}}^0+
RT\ln p_{\mathrm{H_2}}
```

となる．

#### (3) 水溶液中の HCl

$\mathrm{HCl}$ は水溶液中で $\mathrm{H^+}$ と $\mathrm{Cl^-}$ に対応するため，$\mathrm{HCl}$ 1 mol に対する化学ポテンシャルには両イオンの寄与が含まれる．
$\mathrm{HCl}$ の濃度を $x$ ，平均イオン活動度係数を $\bar\gamma$ とすると，

```math
\bar G_{\mathrm{HCl(aq)}}=
\phi_{\mathrm{HCl}}^0+
2RT\ln(x\bar\gamma)
```

と表される．
ここで， $\phi_{\mathrm{HCl}}^0$ は $\mathrm{HCl}$ の標準状態に対応する化学ポテンシャルである．
係数 2 は，1 mol の $\mathrm{HCl}$ に対応する $\mathrm{H^+}$ と $\mathrm{Cl^-}$ の2種類のイオンの寄与に由来する．

#### (4) 各成分の式を代入する

以上の式を $\Delta G$ に代入すると，

```math
\begin{aligned}
\Delta G={}&
\bar G_{\mathrm{Ag(c)}}^0+
\phi_{\mathrm{HCl}}^0+
2RT\ln(x\bar\gamma)\\
&-\frac12\left(
\bar G_{\mathrm{H_2(g)}}^0+
RT\ln p_{\mathrm{H_2}}
\right)
-\bar G_{\mathrm{AgCl(c)}}^0
\end{aligned}
```

となる．
括弧を展開して整理すると，

```math
\begin{aligned}
\Delta G={}&
\bar G_{\mathrm{Ag(c)}}^0+
\phi_{\mathrm{HCl}}^0
-\frac12\bar G_{\mathrm{H_2(g)}}^0
-\bar G_{\mathrm{AgCl(c)}}^0\\
&+2RT\ln(x\bar\gamma)
-\frac12RT\ln p_{\mathrm{H_2}}
\end{aligned}
```

を得る．
ここで，標準反応ギブズ自由エネルギー変化を

```math
\begin{aligned}
\Delta G^0={}&
\bar G_{\mathrm{Ag(c)}}^0+
\phi_{\mathrm{HCl}}^0\\
&-\frac12\bar G_{\mathrm{H_2(g)}}^0
-\bar G_{\mathrm{AgCl(c)}}^0
\end{aligned}
```

と定義する．
また，対数の性質から，

```math
\frac{1}{2}\ln p_{\mathrm{H_2}}
=\ln p_{\mathrm{H_2}}^{1/2}
```

である．
したがって，反応のギブズ自由エネルギー変化は，

```math
\boxed{
\Delta G=
\Delta G^0+
2RT\ln(x\bar\gamma)
-RT\ln(p_{\mathrm{H_2}}^{1/2})
}
```

と表される．

### 3．ギブズ自由エネルギー変化から起電力を求める

電池が可逆的に動作するとき，反応のギブズ自由エネルギー変化と起電力 $E$ の間には，

```math
\Delta G=-n\mathcal F E
```

という関係がある．
ここで， $n$ は正味の反応に対応する電子の物質量を反応式の進行度 1 mol あたりで表した値， $\mathcal F$ はファラデー定数である．
今回の正味の反応では， $\frac12\mathrm{H_2}$ 1 mol 分の反応進行に対して電子 1 mol が移動するため， $n=1$ である．
よって，

```math
\Delta G=-\mathcal F E
```

となる．

先ほど得た $\Delta G$ の式を代入すると，

```math
\begin{aligned}
-\mathcal F E={}&
\Delta G^0+
2RT\ln(x\bar\gamma)\\
&-RT\ln(p_{\mathrm{H_2}}^{1/2})
\end{aligned}
```

である．
両辺を $-\mathcal F$ で割ると，

```math
\begin{aligned}
E={}&-\frac{\Delta G^0}{\mathcal F}
-\frac{2RT}{\mathcal F}\ln(x\bar\gamma)\\
&+\frac{RT}{\mathcal F}\ln(p_{\mathrm{H_2}}^{1/2})
\end{aligned}
```

となる．
ここで，標準起電力を

```math
E^0=-\frac{\Delta G^0}{\mathcal F}
```

と定義すれば，

```math
\boxed{
E=E^0
-\frac{2RT}{\mathcal F}\ln(x\bar\gamma)
+\frac{RT}{\mathcal F}\ln(p_{\mathrm{H_2}}^{1/2})
}
```

を得る．
したがって，題意の式が示された．

なお，問題文の $\log$ が自然対数を意味する場合，上式の $\ln$ をすべて $\log$ に置き換えれば，問題文で指定された形と一致する．
