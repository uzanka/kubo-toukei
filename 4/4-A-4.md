# 演習問題【4-A-4】

## 解答

相平衡曲線の傾きは，クラペイロンの式

```math
\frac{dp}{dT}=\frac{\Delta S}{\Delta V}
```

によって与えられる．
ここで， $\Delta S$ は相転移に伴うエントロピー変化， $\Delta V$ は体積変化である．

まず，固相－気相の平衡曲線（昇華曲線）の傾きは，

```math
\left(\frac{dp}{dT}\right)_{s-g}
=\frac{S_g-S_s}{V_g-V_s}
```

である．
一方，液相－気相の平衡曲線（蒸発曲線）の傾きは，

```math
\left(\frac{dp}{dT}\right)_{l-g}
=\frac{S_g-S_l}{V_g-V_l}
```

である．
ここで， $S_s,S_l,S_g$ はそれぞれ固相，液相，気相のエントロピー， $V_s,V_l,V_g$ はそれぞれの体積である．

三重点近傍では，一般に気相の体積は固相および液相の体積よりも十分に大きいため，

```math
V_g\gg V_s,\ V_l
```

が成り立つ．
したがって，

```math
V_g-V_s\simeq V_g,\qquad
V_g-V_l\simeq V_g
```

と近似できる．
これを用いると，両曲線の傾きはそれぞれ

```math
\left(\frac{dp}{dT}\right)_{s-g}
\simeq\frac{S_g-S_s}{V_g},
```

```math
\left(\frac{dp}{dT}\right)_{l-g}
\simeq\frac{S_g-S_l}{V_g}
```

となる．

同じ物質の三重点近傍では，一般にエントロピーは

```math
S_g>S_l>S_s
```

の順に大きい．
よって，

```math
S_g-S_s>S_g-S_l
```

である．
両式の分母はともに $V_g$ で近似できるため，

```math
\left(\frac{dp}{dT}\right)_{s-g}
>
\left(\frac{dp}{dT}\right)_{l-g}
```

となる．

したがって，圧力 $p$ を縦軸，温度 $T$ を横軸にとった相図では，固相－気相の平衡曲線の傾き $dp/dT$ は液相－気相の平衡曲線の傾きより大きい．
すなわち，固相－気相の平衡曲線は，液相－気相の平衡曲線よりも温度軸に対して急な傾斜をもつのである．
