# 演習問題【4-A-24】

## 解答

反応

```math
A_2\rightleftharpoons 2A
```

について，18 ℃および19 ℃，圧力1 atmにおける解離度を求める．

### 1．18 ℃における解離度

#### (1) 混合気体の全濃度を求める

理想気体の状態方程式は，

```math
pV=nRT
```

である．
両辺を $VRT$ で整理すると，

```math
\frac{n}{V}=\frac{p}{RT}
```

となる．

気相中に存在する化学種が $A$ と $A_2$ のみであるため，混合気体の全濃度 $c$ は，

```math
c=[A]+[A_2]=\frac{p}{RT}
\tag{1}
```

である．

CGS単位系を用いると，

```math
\begin{aligned}
p&=1.013\times10^6\ \mathrm{dyn/cm^2},\\
R&=8.31\times10^7\ \mathrm{erg/(mol\cdot K)},\\
T&=273+18=291\ \mathrm K
\end{aligned}
```

である．
したがって，

```math
\begin{aligned}
c&=\frac{1.013\times10^6}
{8.31\times10^7\times291}\\
&\simeq4.19\times10^{-5}\ 
\mathrm{mol/cm^3}
\end{aligned}
\tag{2}
```

を得る．

#### (2) 平衡時の濃度を求める

18 ℃における平衡定数は，

```math
K_c=\frac{[A]^2}{[A_2]}
=1.70\times10^{-4}\ \mathrm{mol/cm^3}
\tag{3}
```

である．

式 (1) より，

```math
[A_2]=c-[A]
\tag{4}
```

である．
これを式 (3) に代入すると，

```math
K_c=\frac{[A]^2}{c-[A]}
```

となる．
整理すれば，

```math
[A]^2+K_c[A]-K_cc=0
\tag{5}
```

という二次方程式を得る．

二次方程式の解の公式を用いると，

```math
[A]=\frac{-K_c\pm\sqrt{K_c^2+4K_cc}}{2}
```

である．
濃度は負にならないため，正の解を採用する．
よって，

```math
[A]=\frac{-K_c+\sqrt{K_c^2+4K_cc}}{2}
\tag{6}
```

となる．
式 (2)，(3) の値を代入すると，

```math
[A]\simeq3.48\times10^{-5}\ 
\mathrm{mol/cm^3}
\tag{7}
```

を得る．
さらに，

```math
\begin{aligned}
[A_2]&=c-[A]\\
&\simeq(4.19-3.48)\times10^{-5}\\
&=0.71\times10^{-5}\ \mathrm{mol/cm^3}
\end{aligned}
\tag{8}
```

である．

#### (3) 解離度を求める

解離度 $\alpha$ とは，初めに存在した $A_2$ 分子のうち，解離した分子の割合である．
初めに $A_2$ が $n_0$ mol存在し，そのうち割合 $\alpha$ が解離したとすると，平衡時には，

```math
n_A=2\alpha n_0
```

```math
n_{A_2}=(1-\alpha)n_0
```

となる．
したがって，

```math
\alpha
=\frac{n_A}{n_A+2n_{A_2}}
=\frac{[A]}{[A]+2[A_2]}
\tag{9}
```

である．

式 (4) を用いれば，

```math
\begin{aligned}
\alpha
&=\frac{[A]}{[A]+2(c-[A])}\\
&=\frac{[A]}{2c-[A]}
\end{aligned}
\tag{10}
```

となる．

式 (2)，(7) の値を代入すると，

```math
\begin{aligned}
\alpha
&=\frac{3.48}{2\times4.19-3.48}\\
&=\frac{3.48}{4.90}\\
&\simeq0.71
\end{aligned}
```

である．

したがって，18 ℃，1 atmにおける解離度は，

```math
\boxed{\alpha\simeq0.71}
```

となる．

### 2．19 ℃における解離度

#### (1) 温度変化による平衡定数の変化を求める

平衡定数の温度依存性を表す反応定容式は，

```math
\frac{d\ln K_c}{dT}
=\frac{\Delta U}{RT^2}
\tag{11}
```

である．
ここで， $\Delta U$ は反応の標準内部エネルギー変化である．

問題で与えられた反応熱を定圧反応熱，すなわち反応エンタルピー変化 $\Delta H$ と解釈する．
理想気体反応では，

```math
\Delta H=\Delta U+\Delta n_gRT
```

が成り立つ．
ここで， $\Delta n_g$ は気体生成物の化学量論係数の総和から気体反応物の化学量論係数の総和を引いた値である．
今回の反応では，

```math
\Delta n_g=2-1=1
```

なので，

```math
\Delta U=\Delta H-RT
\tag{12}
```

となる．

問題で与えられた反応熱は，

```math
\Delta H=5.0\times10^4\ \mathrm{cal/mol}
```

である．
したがって，18 ℃付近では，

```math
\begin{aligned}
\Delta U
&=\Delta H-RT\\
&=5.0\times10^4
-1.987\times291\\
&\simeq4.94\times10^4\ \mathrm{cal/mol}
\end{aligned}
\tag{13}
```

となる．

1 Kの温度範囲では $\Delta U$ の変化を無視できると近似し，式 (11) を291 Kから292 Kまで積分する．

```math
\int_{K_c(291)}^{K_c(292)}d\ln K_c
=
\frac{\Delta U}{R}
\int_{291}^{292}\frac{dT}{T^2}
```

ここで，

```math
\int\frac{dT}{T^2}=-\frac1T
```

であるから，

```math
\ln\frac{K_c(292)}{K_c(291)}
=
\frac{\Delta U}{R}
\left(\frac1{291}-\frac1{292}\right)
\tag{14}
```

となる．

式 (13) と，

```math
R=1.987\ \mathrm{cal/(mol\cdot K)}
```

を代入すると，

```math
\begin{aligned}
\ln\frac{K_c(292)}{K_c(291)}
&=\frac{4.94\times10^4}{1.987}
\left(\frac1{291}-\frac1{292}\right)\\
&\simeq0.294
\end{aligned}
\tag{15}
```

である．
両辺の指数を取れば，

```math
\frac{K_c(292)}{K_c(291)}
\simeq e^{0.294}
\simeq1.342
\tag{16}
```

となる．
したがって，19 ℃における平衡定数は，

```math
\begin{aligned}
K_c(19^\circ\mathrm C)
&\simeq1.342K_c(18^\circ\mathrm C)\\
&=1.342\times1.70\times10^{-4}\\
&\simeq2.28\times10^{-4}\ 
\mathrm{mol/cm^3}
\end{aligned}
\tag{17}
```

である．

#### (2) 19 ℃における全濃度と平衡濃度を求める

圧力が1 atmのままなので，19 ℃における全濃度 $c'$ は，

```math
c'=\frac{p}{RT}
```

である．
温度を $292\ \mathrm K$ とすると，

```math
\begin{aligned}
c'
&=\frac{1.013\times10^6}
{8.31\times10^7\times292}\\
&\simeq4.18\times10^{-5}\ 
\mathrm{mol/cm^3}
\end{aligned}
\tag{18}
```

を得る．

18 ℃の場合と同様に，

```math
[A_2]=c'-[A]
```

および，

```math
K_c(19^\circ\mathrm C)=\frac{[A]^2}{[A_2]}
```

を用いると，

```math
[A]^2+K_c(19^\circ\mathrm C)[A]
-K_c(19^\circ\mathrm C)c'=0
\tag{19}
```

となる．

正の解は，

```math
[A]=
\frac{-K_c(19^\circ\mathrm C)
+\sqrt{K_c(19^\circ\mathrm C)^2
+4K_c(19^\circ\mathrm C)c'}}{2}
\tag{20}
```

である．
式 (17)，(18) を代入すると，

```math
[A]\simeq3.60\times10^{-5}\ 
\mathrm{mol/cm^3}
\tag{21}
```

となる．

#### (3) 19 ℃における解離度を求める

18 ℃の場合と同じく，

```math
\alpha'=\frac{[A]}{2c'-[A]}
```

である．
式 (18)，(21) を用いると，

```math
\begin{aligned}
\alpha'
&=\frac{3.60}{2\times4.18-3.60}\\
&=\frac{3.60}{4.76}\\
&\simeq0.76
\end{aligned}
```

となる．

したがって，19 ℃，1 atmにおける解離度は，

```math
\boxed{\alpha'\simeq0.76}
```

である．

### 3．最終結果

```math
\boxed{
\begin{aligned}
18^\circ\mathrm C,\ 1\ \mathrm{atm}:&
\quad \alpha\simeq0.71,\\
19^\circ\mathrm C,\ 1\ \mathrm{atm}:&
\quad \alpha'\simeq0.76.
\end{aligned}
}
```

反応は吸熱反応であるため，温度上昇に伴って平衡定数は大きくなる．
その結果，19 ℃では18 ℃より解離が進み，解離度が大きくなる．

なお，問題文の「反応熱」が定圧反応熱ではなく，定容反応熱，すなわち $\Delta U$ を意味する場合には，式 (13) の補正は不要である．
その場合は，

```math
\Delta U=5.0\times10^4\ \mathrm{cal/mol}
```

として計算し，19 ℃の解離度は約 $0.76$ となる．
