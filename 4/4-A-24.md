# 演習問題【4-A-24】

## 解答

反応

```math
A_2\rightleftharpoons 2A
```

について，18 ℃および19 ℃，圧力1 atmにおける解離度を求める．

### 1．18 ℃における解離度

#### (1) 混合気体の全濃度を求める

理想気体の状態方程式は

```math
pV=nRT
```

である．
ここで， $p$ は圧力， $V$ は体積， $n$ は物質量， $R$ は気体定数， $T$ は絶対温度である．
両辺を $VRT$ で整理すると，

```math
\frac{n}{V}=\frac{p}{RT}
```

となる．
問題では角括弧 $[\,]$ を単位体積あたりのモル数としているため，混合気体の全濃度 $c$ は

```math
c=[A]+[A_2]=\frac{p}{RT}
\tag{1}
```

である．

CGS単位系を用いると，

```math
\begin{aligned}
p&=1.013\times10^6\ \mathrm{dyn/cm^2},\\
R&=8.31\times10^7\ \mathrm{erg/(mol\cdot K)},\\
T&=273+18=291\ \mathrm K
\end{aligned}
```

である．
したがって，

```math
\begin{aligned}
c&=\frac{1.013\times10^6}
{8.31\times10^7\times291}\\
&\simeq4.19\times10^{-5}\ 
\mathrm{mol/cm^3}
\end{aligned}
\tag{2}
```

を得る．

#### (2) 平衡時の濃度を求める

18 ℃における平衡定数は

```math
K_c=\frac{[A]^2}{[A_2]}
=1.70\times10^{-4}\ \mathrm{mol/cm^3}
\tag{3}
```

と与えられている．

式 (1) より，

```math
[A_2]=c-[A]
\tag{4}
```

である．
これを式 (3) に代入すると，

```math
K_c=\frac{[A]^2}{c-[A]}
```

となる．
両辺に $c-[A]$ を掛けて整理すれば，

```math
[A]^2+K_c[A]-K_cc=0
\tag{5}
```

という二次方程式を得る．

二次方程式の解の公式を用いると，

```math
[A]=\frac{-K_c\pm\sqrt{K_c^2+4K_cc}}{2}
```

である．
濃度は負にならないため，正の解を採用する．よって，

```math
[A]=\frac{-K_c+\sqrt{K_c^2+4K_cc}}{2}
\tag{6}
```

となる．
式 (2)，(3) の値を代入すると，

```math
[A]\simeq3.48\times10^{-5}\ 
\mathrm{mol/cm^3}
\tag{7}
```

を得る．
さらに，

```math
\begin{aligned}
[A_2]&=c-[A]\\
&\simeq(4.19-3.48)\times10^{-5}\\
&=0.71\times10^{-5}\ \mathrm{mol/cm^3}
\end{aligned}
\tag{8}
```

である．

#### (3) 解離度を求める

解離度 $\alpha$ とは，反応前に存在した $A_2$ 分子のうち，解離した分子の割合である．
解離反応では， $A_2$ 分子1個から $A$ 原子が2個生じる．
したがって，平衡時の $A$ 原子の濃度を使って解離度を表すと，

```math
\alpha=\frac{[A]}{[A]+2[A_2]}
\tag{9}
```

となる．
式 (4) を用いれば，

```math
\begin{aligned}
\alpha
&=\frac{[A]}{[A]+2(c-[A])}\\
&=\frac{[A]}{2c-[A]}
\end{aligned}
\tag{10}
```

である．

式 (2)，(7) の値を代入すると，

```math
\begin{aligned}
\alpha
&=\frac{3.48}{2\times4.19-3.48}\\
&=\frac{3.48}{4.90}\\
&\simeq0.71
\end{aligned}
```

したがって，18 ℃，1 atmにおける解離度は

```math
\boxed{
\alpha\simeq0.71
}
```

である．

### 2．19 ℃における解離度

#### (1) 温度変化による平衡定数の変化を求める

平衡定数の温度依存性を表す反応定容式は，

```math
\frac{d\ln K_c}{dT}
=\frac{\Delta U}{RT^2}
\tag{11}
```

である．
ここで， $\Delta U$ は反応の標準内部エネルギー変化である．
問題で与えられた反応熱をこの $\Delta U$ として用いる．

与えられた値は，

```math
\Delta U=5.0\times10^4\ \mathrm{cal/mol}
```

である．
$1\ \mathrm{cal}\simeq4.2\times10^7\ \mathrm{erg}$ としてCGS単位系に変換すると，

```math
\Delta U
=5.0\times10^4\times4.2\times10^7
=2.1\times10^{12}\ \mathrm{erg/mol}
\tag{12}
```

となる．

温度が291 Kから292 Kに変わるとき，この1 Kの範囲で $\Delta U$ を一定と近似し，式 (11) を積分する．

```math
\int_{K_c(291)}^{K_c(292)}d\ln K_c
=\frac{\Delta U}{R}
\int_{291}^{292}\frac{dT}{T^2}
```

ここで，

```math
\int\frac{dT}{T^2}=-\frac1T
```

であるから，

```math
\ln\frac{K_c(292)}{K_c(291)}
=\frac{\Delta U}{R}
\left(\frac1{291}-\frac1{292}\right)
\tag{13}
```

となる．

式 (12) と $R=8.31\times10^7\ \mathrm{erg/(mol\cdot K)}$ を代入すると，

```math
\begin{aligned}
\ln\frac{K_c(292)}{K_c(291)}
&=\frac{2.1\times10^{12}}{8.31\times10^7}
\left(\frac1{291}-\frac1{292}\right)\\
&\simeq0.30
\end{aligned}
\tag{14}
```

両辺の指数を取れば，

```math
\frac{K_c(292)}{K_c(291)}
\simeq e^{0.30}\simeq1.35
\tag{15}
```

である．
したがって，19 ℃における平衡定数は，

```math
\begin{aligned}
K_c(19^\circ\mathrm C)
&\simeq1.35K_c(18^\circ\mathrm C)\\
&=1.35\times1.70\times10^{-4}\\
&\simeq2.30\times10^{-4}\ 
\mathrm{mol/cm^3}
\end{aligned}
\tag{16}
```

となる．

#### (2) 19 ℃における全濃度と平衡濃度を求める

圧力が1 atmのままなので，19 ℃における全濃度 $c'$ は，状態方程式から

```math
c'=\frac{p}{RT}
```

である．
温度を $292\ \mathrm K$ とすると，

```math
\begin{aligned}
c'
&=\frac{1.013\times10^6}
{8.31\times10^7\times292}\\
&\simeq4.18\times10^{-5}\ 
\mathrm{mol/cm^3}
\end{aligned}
\tag{17}
```

を得る．

18 ℃の場合と同様に，

```math
[A_2]=c'-[A]
```

および

```math
K_c(19^\circ\mathrm C)=\frac{[A]^2}{[A_2]}
```

を用いると，

```math
[A]^2+K_c(19^\circ\mathrm C)[A]
-K_c(19^\circ\mathrm C)c'=0
\tag{18}
```

となる．
正の解は，

```math
[A]=
\frac{-K_c(19^\circ\mathrm C)
+\sqrt{K_c(19^\circ\mathrm C)^2
+4K_c(19^\circ\mathrm C)c'}}{2}
\tag{19}
```

である．
式 (16)，(17) を代入すると，

```math
[A]\simeq3.61\times10^{-5}\ 
\mathrm{mol/cm^3}
\tag{20}
```

となる．

#### (3) 19 ℃における解離度を求める

式 (10) と同じ関係から，

```math
\alpha'=\frac{[A]}{2c'-[A]}
```

である．
式 (17)，(20) を用いると，

```math
\begin{aligned}
\alpha'
&=\frac{3.61}{2\times4.18-3.61}\\
&=\frac{3.61}{4.75}\\
&\simeq0.76
\end{aligned}
```

したがって，19 ℃，1 atmにおける解離度は，

```math
\boxed{\alpha'\simeq0.76}
```

である．

### 最終結果

```math
\boxed{
\begin{aligned}
18^\circ\mathrm C,\ 1\ \mathrm{atm}:&\quad \alpha\simeq0.71,\\
19^\circ\mathrm C,\ 1\ \mathrm{atm}:&\quad \alpha'\simeq0.76.
\end{aligned}
}
```

反応熱が正であるため，温度の上昇に伴って平衡定数 $K_c$ は大きくなる．
このため，19 ℃では18 ℃より解離が進み，解離度が大きくなる．
