# 演習問題【4-C-50】

## 解答

### 1．混合自由エネルギーの導出

高分子溶液の相分離を調べるため，まず問題 [39] の化学ポテンシャルから，混合によるギブス自由エネルギーを求める．

以下では，

```math
\phi=\phi_2,\qquad \phi_1=1-\phi
```

とおく．

問題 [39] では $N_1,N_2$ は分子数として定義されている．
一方，化学ポテンシャルの式にはモル気体定数 $R$ が用いられているため， $\bar G_i$ はモル化学ポテンシャルとして扱う．
そこで，アボガドロ定数を $N_A$ とし，各成分のモル数を

```math
n_1=\frac{N_1}{N_A},\qquad
n_2=\frac{N_2}{N_A}
```

と定義する．
また，

```math
n_0=n_1+rn_2
```

を格子サイトのモル数とする．
体積分率は，

```math
\phi=\frac{rn_2}{n_0}
```

であり，元の問題の定義と一致する．

純物質を基準とした混合自由エネルギーを，

```math
\boxed{
\Delta G_{\mathrm{mix}}
=
G-n_1\bar G_1^0-n_2\bar G_2^0
}
```

と定義する．
ここで $G$ は混合物全体のギブス自由エネルギーである．
温度と圧力を一定にすると，

```math
d(\Delta G_{\mathrm{mix}})
=
(\bar G_1-\bar G_1^0)dn_1
+
(\bar G_2-\bar G_2^0)dn_2
```

が成立する．

混合自由エネルギーを格子サイトのモル数 $n_0$ に比例する形で，

```math
\boxed{
\Delta G_{\mathrm{mix}}
=RTn_0\psi(\phi)
}
\tag{1}
```

と表す．
ここで $\psi(\phi)$ は無次元の格子サイトあたりの混合自由エネルギーである．

$n_0=n_1+rn_2$ ， $\phi=rn_2/n_0$ より，

```math
\frac{\partial n_0}{\partial n_1}=1,\qquad
\frac{\partial n_0}{\partial n_2}=r
```

および，

```math
\frac{\partial\phi}{\partial n_1}
=-\frac{\phi}{n_0},\qquad
\frac{\partial\phi}{\partial n_2}
=\frac{r(1-\phi)}{n_0}
```

である．
したがって，式 (1) を偏微分すると，

```math
\boxed{
\bar G_1-\bar G_1^0
=RT\left[\psi(\phi)-\phi\psi'(\phi)\right]
}
\tag{2}
```

および，

```math
\boxed{
\bar G_2-\bar G_2^0
=rRT\left[\psi(\phi)+(1-\phi)\psi'(\phi)\right]
}
\tag{3}
```

を得る．
ここでプライムは $\phi$ による微分を表す．

問題 [39] の化学ポテンシャルと比較すると，

```math
\boxed{
\psi(\phi)
=
(1-\phi)\ln(1-\phi)
+\frac{\phi}{r}\ln\phi
+\frac{w}{RT}\phi(1-\phi)
}
\tag{4}
```

とすれば式 (2)，式 (3) の両方を再現できる．
ここでは問題 [39] の $\log$ を自然対数とする．

実際，

```math
\psi-\phi\psi'
=
\ln(1-\phi)
+\left(1-\frac1r\right)\phi
+\frac{w}{RT}\phi^2
```

および，

```math
r[\psi+(1-\phi)\psi']
=
\ln\phi
-(r-1)(1-\phi)
+\frac{rw}{RT}(1-\phi)^2
```

となるからである．

したがって，混合自由エネルギーは，

```math
\boxed{
\Delta G_{\mathrm{mix}}
=
RTn_0
\left[
(1-\phi)\ln(1-\phi)
+\frac{\phi}{r}\ln\phi
+\frac{w}{RT}\phi(1-\phi)
\right]
}
\tag{5}
```

で与えられる．

なお，分子数 $N_0=N_1+rN_2$ を直接用いると，この式は

```math
\Delta G_{\mathrm{mix}}
=k_BTN_0\psi(\phi)
```

とも書ける．
ここで $k_B=R/N_A$ であり，この表現ならばエネルギーの次元も整合する．

また，

```math
\lim_{\phi\to0}\phi\ln\phi=0,\qquad
\lim_{\phi\to1}(1-\phi)\ln(1-\phi)=0
```

であるため，

```math
\psi(0)=\psi(1)=0
```

となる．
これは純溶媒および純高分子を基準とした混合自由エネルギーの定義と整合している．

### 2．相分離を判定する自由エネルギーの条件

相分離の安定性は，全系の自由エネルギーに比例する格子サイトあたりの自由エネルギー密度 $\psi(\phi)$ の凸性によって判定する．

```math
\chi=\frac{w}{RT}
```

とおけば，

```math
\boxed{
\psi(\phi)
=
(1-\phi)\ln(1-\phi)
+\frac{\phi}{r}\ln\phi
+\chi\phi(1-\phi)
}
\tag{6}
```

である．

均一相の局所安定性を調べるため， $\psi(\phi)$ を組成 $\phi$ で微分する．

```math
\psi'(\phi)
=
-\ln(1-\phi)-1
+\frac1r(\ln\phi+1)
+\chi(1-2\phi)
```

さらに微分すると，

```math
\boxed{
\psi''(\phi)
=
\frac1{1-\phi}
+\frac1{r\phi}
-2\chi
}
\tag{7}
```

を得る．

組成 $\phi$ のまわりに小さな組成揺らぎを与えたとき， $\psi''(\phi)>0$ であれば，その揺らぎによって自由エネルギーは増加する．
したがって，均一相は局所的に安定である．

一方，

```math
\psi''(\phi)<0
```

であれば，小さな組成揺らぎによって自由エネルギーが減少するため，均一相は局所的に不安定となる．

したがって，スピノーダル曲線は，

```math
\boxed{
\psi''(\phi)=0
}
\tag{8}
```

で与えられる．

臨界点では，二相の共存組成が一致し，スピノーダル曲線の極小点に到達する．
したがって臨界条件は，

```math
\boxed{
\psi''(\phi_c)=0,\qquad
\psi'''(\phi_c)=0
}
\tag{9}
```

である．

ここでは $\psi'(\phi_c)=0$ は要求されない．
一次微分は共通接線の傾きに関係し，臨界点で必ずゼロになるわけではない．

### 3．臨界体積分率 $\phi_c$ を求める

式 (7) をもう一度微分すると，

```math
\boxed{
\psi'''(\phi)
=
\frac1{(1-\phi)^2}
-\frac1{r\phi^2}
}
\tag{10}
```

となる．

臨界条件の第2式，

```math
\psi'''(\phi_c)=0
```

より，

```math
\frac1{(1-\phi_c)^2}
-\frac1{r\phi_c^2}=0
```

したがって，

```math
\frac1{(1-\phi_c)^2}
=
\frac1{r\phi_c^2}
```

である．

体積分率の定義から $0<\phi_c<1$ であり， $r>0$ であるため，平方根を取ると，

```math
\frac1{1-\phi_c}
=
\frac1{\sqrt r\,\phi_c}
```

となる．
これを整理すれば，

```math
\sqrt r\,\phi_c=1-\phi_c
```

であるから，

```math
(1+\sqrt r)\phi_c=1
```

を得る．
よって，臨界体積分率は，

```math
\boxed{
\phi_c=\frac1{1+\sqrt r}
}
\tag{11}
```

である．

### 4．臨界温度 $T_c$ を求める

次に，臨界条件の第1式，

```math
\psi''(\phi_c)=0
```

を用いると，

```math
\frac1{1-\phi_c}
+\frac1{r\phi_c}
-\frac{2w}{RT_c}=0
```

となる．

式 (11) から，

```math
\frac1{\phi_c}=1+\sqrt r
```

および，

```math
\frac1{1-\phi_c}
=\frac{1+\sqrt r}{\sqrt r}
```

である．
これらを代入すると，

```math
\frac{1+\sqrt r}{\sqrt r}
+\frac{1+\sqrt r}{r}
=
\frac{2w}{RT_c}
```

となる．
左辺を整理すれば，

```math
\frac{(1+\sqrt r)^2}{r}
=
\frac{2w}{RT_c}
```

である．
したがって，

```math
\boxed{
\frac{w}{RT_c}
=
\frac12\left(1+\frac1{\sqrt r}\right)^2
}
\tag{12}
```

を得る．
よって臨界温度は，

```math
\boxed{
T_c
=
\frac{2w}
{R\left(1+\dfrac1{\sqrt r}\right)^2}
}
\tag{13}
```

である．

さらに，通常の臨界点であることを確認するため，四階微分を求めると，

```math
\boxed{
\psi''''(\phi)
=
\frac2{(1-\phi)^3}
+\frac2{r\phi^3}>0
}
\tag{14}
```

となる．
したがって，臨界組成で四階微分は正であり，得られた臨界点は通常の臨界点である．

### 5．二相分離が起こる条件

式 (7) の二階微分は，

```math
\psi''(\phi)
=
\frac1{1-\phi}
+\frac1{r\phi}
-2\chi
```

である．

その極小点は，

```math
\psi'''(\phi)=0
```

を満たす組成で生じる．
この組成が式 (11) の $\phi_c$ である．

また，

```math
\psi''''(\phi)>0
```

なので， $\psi''(\phi)$ は $\phi_c$ で唯一の極小値を取る．
その値は，

```math
\begin{aligned}
\psi''(\phi_c)
&=
\frac{(1+\sqrt r)^2}{r}-2\chi\\
&=2\chi_c-2\chi
\end{aligned}
```

である．
ここで，

```math
\boxed{
\chi_c
=
\frac12\left(1+\frac1{\sqrt r}\right)^2
}
```

とした．

したがって，

```math
\chi>\chi_c
```

のときには，

```math
\psi''(\phi_c)<0
```

となり，自由エネルギー密度が非凸になる組成領域が現れる．

一方，

```math
\chi\leq\chi_c
```

では，自由エネルギー密度は全組成領域で凸であり，このモデルでは均一相が安定である．

$w$ が正で温度に依存しない定数ならば，

```math
\chi=\frac{w}{RT}
```

なので，

```math
\boxed{
T<T_c
\quad\Longleftrightarrow\quad
\frac{w}{RT}>
\frac12\left(1+\frac1{\sqrt r}\right)^2
}
\tag{15}
```

となる．

つまり，臨界温度より低い温度では，二相分離が可能になる自由エネルギーの非凸領域が現れる．

### 6．実際に二相共存する組成

ただし， $T<T_c$ であれば，どの平均組成でも必ず二相に分かれるという意味ではない．
実際の平衡二相共存は，共通接線条件によって決まる．

二相の高分子体積分率を $\phi_\alpha,\phi_\beta$ とすると，共通接線条件は，

```math
\boxed{
\psi'(\phi_\alpha)
=
\psi'(\phi_\beta)
=
\frac{\psi(\phi_\beta)-\psi(\phi_\alpha)}
{\phi_\beta-\phi_\alpha}
}
\tag{16}
```

である．

これは，二相の化学ポテンシャルが等しく，両相の自由エネルギー曲線に同じ接線を引けることを意味する．
この条件によって求められる共存組成の境界をビノーダルと呼ぶ．

一方，式 (8) の

```math
\psi''(\phi)=0
```

で定義される境界はスピノーダルであり，均一相が局所的に安定でなくなる境界である．

したがって，二相分離の状態は次のように分類できる．
- ビノーダルの外側： 均一相が熱力学的に安定である．
- ビノーダルとスピノーダルの間： 均一相は準安定であり，核生成を経て二相分離し得る．
- スピノーダルの内側： 均一相は不安定であり，小さな組成揺らぎによって自発的に相分離する．

したがって，平均組成がビノーダルで囲まれた共存領域に入ると，平衡状態では異なる組成の二相に分離する．
各相の割合は物質保存則によって決まり，格子サイト数の割合を $\lambda$ とすれば，

```math
\boxed{
\bar\phi
=
\lambda\phi_\alpha+(1-\lambda)\phi_\beta
}
```

を満たす．
ここで $\bar\phi$ は系全体の平均高分子体積分率である．

なお， $w$ が温度に依存する場合には，式 (15) の $T<T_c$ という表現に代えて，

```math
\boxed{
\frac{w(T)}{RT}>
\frac12\left(1+\frac1{\sqrt r}\right)^2
}
```

を用いる．

**答**

問題 [39] の高分子溶液では，格子サイトあたりの混合自由エネルギー密度が非凸になると，二相分離が可能になる．
その臨界点は，

```math
\boxed{
\phi_c=\frac1{1+\sqrt r}
}
```

および，

```math
\boxed{
\frac{w}{RT_c}
=
\frac12\left(1+\frac1{\sqrt r}\right)^2
}
```

で与えられる．

$w>0$ が温度に依存しない場合， $T<T_c$ で二相分離が可能となる．
ただし，実際に二相共存するかどうかは平均組成にも依存し，その共存組成は共通接線条件によって決まる．
