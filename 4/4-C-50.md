# 演習問題【4-C-50】

## 解答

### 1．自由エネルギーの式

高分子溶液が一つの均一な相として存在するか，二つの異なる組成の相に分離するかは，混合によるギブス自由エネルギーの組成依存性によって決まる．

問題 [39] で得られた自由エネルギー変化を用い，

```math
f(\phi)\equiv\frac{\Delta G}{RT}
```

とおくと，

```math
\boxed{
f(\phi)=
\frac{
r(1-\phi)\ln(1-\phi)
+\phi\ln\phi
+\dfrac{rw}{RT}\phi(1-\phi)
}{
r-(r-1)\phi
}
}
\tag{1}
```

となる．
ここで， $\phi$ は高分子の体積分率， $r$ は高分子と溶媒の分子サイズの比を表すパラメータ， $w$ は分子間相互作用を表すエネルギーパラメータ， $R$ は気体定数， $T$ は絶対温度である．
また， $\ln$ は自然対数を表す．

式 (1) の分子に含まれる最初の二項は混合によるエントロピーの寄与であり，第3項は分子間相互作用の寄与である．
$w>0$ の場合，温度が低下すると $w/(RT)$ が大きくなり，組成による自由エネルギーの変化に相互作用の影響が強く現れる．
その結果，自由エネルギー曲線に複数の極値が現れ，二相分離が可能になる．

以下では，解答例と同様に，臨界点において極値が合体する条件を用いて，相分離が起こり始める臨界温度を求める．

### 2．臨界点の条件

臨界点では，自由エネルギー曲線の極小と極大が合体する．
数学的には，停留点を与える導関数の根が重なる条件として表せる．
このモデルでは，

```math
f'(\phi_c)=0,\qquad
f''(\phi_c)=0,\qquad
f'''(\phi_c)=0
\tag{2}
```

を用いる．
ここで，プライムは $\phi$ による微分を表し， $\phi_c$ は臨界体積分率である．

微分計算を簡単にするため，式 (1) を

```math
f(\phi)=\frac{g(\phi)}{h(\phi)}
```

と書き，

```math
g(\phi)=
r(1-\phi)\ln(1-\phi)
+\phi\ln\phi
+\frac{rw}{RT}\phi(1-\phi)
\tag{3}
```

```math
h(\phi)=r-(r-1)\phi
```

と定義する．
このとき，

```math
h'(\phi)=-(r-1)
```

である．
商の微分公式を用いると，

```math
f'(\phi)=
\frac{g'(\phi)}{h(\phi)}
+\frac{(r-1)g(\phi)}{h(\phi)^2}
\tag{4}
```

となる．
さらに微分すると，

```math
f''(\phi)
=\frac{g''(\phi)}{h(\phi)}
+\frac{2(r-1)}{h(\phi)}f'(\phi)
\tag{5}
```

を得る．
式 (5) において $f'(\phi_c)=0$ であるため，

```math
f''(\phi_c)=0
\quad\Longleftrightarrow\quad
g''(\phi_c)=0
```

となる．
式 (5) をもう一度微分し， $f'(\phi_c)=f''(\phi_c)=g''(\phi_c)=0$ を用いると，

```math
f'''(\phi_c)=\frac{g'''(\phi_c)}{h(\phi_c)}
```

となる．
$h(\phi_c)>0$ であるから，

```math
f'''(\phi_c)=0
\quad\Longleftrightarrow\quad
g'''(\phi_c)=0
```

である．
したがって，臨界条件は次の二つの式に帰着する．

```math
\boxed{
g''(\phi_c)=0,\qquad
g'''(\phi_c)=0
}
\tag{6}
```

### 3．臨界体積分率 $\phi_c$ を求める

まず，式 (3) を微分する．
第1項については，

```math
\frac{d}{d\phi}
\left[(1-\phi)\ln(1-\phi)\right]
=-\ln(1-\phi)-1
```

であり，第2項については，

```math
\frac{d}{d\phi}(\phi\ln\phi)=\ln\phi+1
```

である．
これらを用いて微分すると，

```math
\begin{aligned}
g'(\phi)
={}&-r\ln(1-\phi)-r+\ln\phi+1\\
&+\frac{rw}{RT}(1-2\phi)
\end{aligned}
```

となる．
さらに微分して，

```math
\boxed{
g''(\phi)=
\frac{r}{1-\phi}
+\frac{1}{\phi}
-\frac{2rw}{RT}
}
\tag{7}
```

を得る．
もう一度微分すると，

```math
\boxed{
g'''(\phi)=
\frac{r}{(1-\phi)^2}
-\frac{1}{\phi^2}
}
\tag{8}
```

となる．

式 (6) の第2条件 $g'''(\phi_c)=0$ を式 (8) に代入すると，

```math
\frac{r}{(1-\phi_c)^2}
-\frac{1}{\phi_c^2}=0
```

したがって，

```math
\frac{r}{(1-\phi_c)^2}
=\frac{1}{\phi_c^2}
```

である．
体積分率の定義から $0<\phi_c<1$ であるため，両辺の平方根を取る際には正の値を選ぶ．
よって，

```math
\frac{\sqrt r}{1-\phi_c}
=\frac{1}{\phi_c}
```

となる．
これを整理すると，

```math
\sqrt r\,\phi_c=1-\phi_c
```

であり，

```math
(1+\sqrt r)\phi_c=1
```

を得る．
したがって，臨界体積分率は，

```math
\boxed{
\phi_c=\frac{1}{1+\sqrt r}
}
\tag{9}
```

である．

### 4．臨界温度 $T_c$ を求める

次に，式 (6) の第1条件 $g''(\phi_c)=0$ を式 (7) に代入する．

```math
\frac{r}{1-\phi_c}
+\frac{1}{\phi_c}
-\frac{2rw}{RT_c}=0
\tag{10}
```

式 (9) より，

```math
\frac{1}{\phi_c}=1+\sqrt r
```

であり，

```math
1-\phi_c
=\frac{\sqrt r}{1+\sqrt r}
```

だから，

```math
\frac{1}{1-\phi_c}
=\frac{1+\sqrt r}{\sqrt r}
```

である．
これらを式 (10) に代入すると，

```math
r\frac{1+\sqrt r}{\sqrt r}
+(1+\sqrt r)
=\frac{2rw}{RT_c}
```

となる．
左辺を整理すると，

```math
\sqrt r(1+\sqrt r)+(1+\sqrt r)
=\frac{2rw}{RT_c}
```

すなわち，

```math
(1+\sqrt r)^2=\frac{2rw}{RT_c}
```

である．
両辺を $2r$ で割れば，

```math
\frac{w}{RT_c}
=\frac{(1+\sqrt r)^2}{2r}
```

を得る．
ここで，

```math
\frac{(1+\sqrt r)^2}{r}
=\left(1+\frac{1}{\sqrt r}\right)^2
```

であるため，臨界温度の条件は，

```math
\boxed{
\frac{w}{RT_c}
=\frac{1}{2}\left(1+\frac{1}{\sqrt r}\right)^2
}
\tag{11}
```

となる．
したがって，臨界温度そのものは，

```math
\boxed{
T_c=
\frac{2w}{
R\left(1+\dfrac{1}{\sqrt r}\right)^2
}
}
\tag{12}
```

と表される．

### 5．二相分離が起こる条件

$w>0$ の場合， $w/(RT)$ は温度 $T$ が低下するほど大きくなる．
臨界温度 $T_c$ は式 (11) で与えられるため，

```math
T<T_c
\quad\Longleftrightarrow\quad
\frac{w}{RT}>
\frac{1}{2}\left(1+\frac{1}{\sqrt r}\right)^2
```

となる．
この温度領域では，混合によるエントロピーの効果に対して分子間相互作用の効果が強くなり，溶液が異なる組成をもつ二相に分離することが可能となる．

ただし， $T<T_c$ であれば，どの組成でも必ず二相に分かれるという意味ではない．
実際に二相が共存する組成は，両相の化学ポテンシャルが等しくなる条件，すなわち自由エネルギー曲線に共通接線を引く条件から決まる．

**答**

高分子溶液が二相に分離し始める臨界点は，

```math
\boxed{
\phi_c=\frac{1}{1+\sqrt r}
}
```

```math
\boxed{
\frac{w}{RT_c}
=\frac{1}{2}\left(1+\frac{1}{\sqrt r}\right)^2
}
```

で与えられる．
したがって， $w>0$ の場合，臨界温度 $T_c$ より低い温度 $T<T_c$ では，二相分離が起こり得る．
