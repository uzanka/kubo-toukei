# 演習問題【4-A-28】

## 解答

### 1．水銀蒸気のモルエントロピーを求める

求める化学定数 $i$ を算出するため，まず沸点 $T_b=630\,\mathrm{K}$ ，圧力 $p=1\,\mathrm{atm}$ における水銀蒸気のモルエントロピー $\overline S_{\mathrm{gas}}$ を求める．

第三法則によれば，完全結晶のエントロピーは絶対零度でゼロである．
したがって，問題で与えられた定圧比熱の積分値を用いることで，融点における固体水銀のモルエントロピーを求められる．
さらに，融解，液体の温度上昇，蒸発の各過程に伴うエントロピー変化を加えれば，沸点における水銀蒸気のモルエントロピーが得られる．

#### (1) 固体水銀のエントロピー

第三法則より，絶対零度における固体水銀のエントロピーはゼロである．
したがって，融点 $T_m=234.2\,\mathrm{K}$ における固体水銀のモルエントロピーは，

```math
\begin{aligned}
S_s(T_m)
&=\int_0^{T_m}\frac{C_p}{T}\,dT\\
&=59.9\times10^7\,
\mathrm{erg/(mol\,K)}
\end{aligned}
```

である．

#### (2) 融解に伴うエントロピー変化

融点では固体と液体が平衡にあり，融解は一定温度で起こる．
温度 $T$ で可逆的に吸収される熱量を $Q_{\mathrm{rev}}$ とすると，エントロピー変化は $\Delta S=Q_{\mathrm{rev}}/T$ である．
融解熱は融解に伴うエンタルピー変化に等しいため，

```math
\Delta S_{\mathrm{fus}}
=\frac{\Delta H_{\mathrm{fus}}}{T_m}
```

となる．
与えられた値を代入すると，

```math
\begin{aligned}
\Delta S_{\mathrm{fus}}
&=\frac{2330\times10^7}{234.2}\\
&\approx9.95\times10^7\,
\mathrm{erg/(mol\,K)}
\end{aligned}
```

である．
したがって，融点における液体水銀のモルエントロピーは，

```math
S_l(T_m)=S_s(T_m)+\Delta S_{\mathrm{fus}}
```

である．

#### (3) 液体水銀の温度上昇に伴うエントロピー変化

融点から沸点まで液体水銀を加熱するときのエントロピー変化は，定圧比熱を用いて

```math
\Delta S_{\mathrm{liq}}
=\int_{T_m}^{T_b}\frac{C_p}{T}\,dT
```

と表される．
この積分値は問題文で与えられており，

```math
\Delta S_{\mathrm{liq}}
=26.2\times10^7\,
\mathrm{erg/(mol\,K)}
```

である．

#### (4) 蒸発に伴うエントロピー変化

沸点 $T_b=630\,\mathrm{K}$ では，液体水銀が蒸発して水銀蒸気になる．
蒸発も一定温度で起こるため，蒸発に伴うエントロピー変化は，

```math
\Delta S_{\mathrm{vap}}
=\frac{\Delta H_{\mathrm{vap}}}{T_b}
```

である．
よって，

```math
\begin{aligned}
\Delta S_{\mathrm{vap}}
&=\frac{59300\times10^7}{630}\\
&\approx94.13\times10^7\,
\mathrm{erg/(mol\,K)}
\end{aligned}
```

となる．

#### (5) 沸点における水銀蒸気のエントロピー

エントロピーは状態量であるため，固体から液体を経て気体になるまでの全エントロピー変化は，各過程の変化量の和で求められる．
したがって，

```math
\begin{aligned}
\overline S_{\mathrm{gas}}(T_b,p)
={}&S_s(T_m)
+\Delta S_{\mathrm{fus}}\\
&+\Delta S_{\mathrm{liq}}
+\Delta S_{\mathrm{vap}}
\end{aligned}
```

である．
各項を代入すると，

```math
\begin{aligned}
\overline S_{\mathrm{gas}}(630,1\,\mathrm{atm})
={}&\left(
59.9+\frac{2330}{234.2}
+26.2+\frac{59300}{630}
\right)\\
&\times10^7\,
\mathrm{erg/(mol\,K)}
\end{aligned}
```

となる．
数値計算により，

```math
\boxed{
\overline S_{\mathrm{gas}}(630,1\,\mathrm{atm})
\approx190.2\times10^7\,
\mathrm{erg/(mol\,K)}
}
```

を得る．
解答例では $190.1\times10^7$ と丸めているが，この差は丸め方によるものであり，化学定数の結論には実質的な影響を与えない．

### 2．単原子理想気体のエントロピー式から化学定数 $i$ を求める

水銀蒸気を単原子理想気体とみなすと，そのモルエントロピーは，

```math
\boxed{
\overline S(T,p)
=R\left(
\frac52\ln T-\ln p+\frac52+i
\right)
}
```

と表される．
ここで， $R$ は気体定数， $i$ は求める化学定数であり， $\ln$ は自然対数を表す．
この式では， $T$ の数値を K で， $p$ の数値を atm で表すという約束を用いる．

沸点 $T=630\,\mathrm{K}$ ，圧力 $p=1\,\mathrm{atm}$ において，先ほど求めた実験値とこの理論式を等しくする．
気体定数を

```math
R=8.32\times10^7\,
\mathrm{erg/(mol\,K)}
```

とすると，

```math
\begin{aligned}
\frac{190.2\times10^7}{8.32\times10^7}
&=\frac52\ln630-\ln1+\frac52+i\\
22.86&\approx16.11+0+2.5+i
\end{aligned}
```

である．
これを $i$ について解くと，

```math
\begin{aligned}
i&\approx22.86-16.11-2.5\\
&\approx4.25
\end{aligned}
```

となる．
有効数字を考慮すれば，

```math
\boxed{
i\approx4.2
}
```

を得る．
これは解答例の値と一致する．

なお，常用対数を用いる化学定数 $j$ は，解答例の定義に従って

```math
j=\frac{i}{\ln10}
```

と定義される．
したがって，丸めた $i=4.2$ を用いれば，

```math
\boxed{
j\approx1.8
}
```

である．
より細かな値を用いれば約 $1.84$ となる．

### 結論

第三法則と与えられた比熱・潜熱のデータから，沸点 $630\,\mathrm{K}$ ，圧力 $1\,\mathrm{atm}$ における水銀蒸気のモルエントロピーを求めた．
これを単原子理想気体のエントロピー式に代入することで，化学定数は

```math
\boxed{
i\approx4.2
}
```

と算出された．
