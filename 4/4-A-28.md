# 演習問題【4-A-28】

## 解答

本問題の目的は，与えられた水銀の熱力学データを用いて，水銀蒸気を単原子理想気体と見なしたときの化学定数 $i$ の値を求めることである．

### 1. 水銀蒸気の $630\,\text{K}, 1\,\text{atm}$ におけるエントロピー $S_{\text{gas}}$ の算出

まず，与えられた測定値を利用して，沸点である $T_b = 630\,\text{K}$ かつ圧力 $p = 1\,\text{atm}$ における水銀蒸気のエントロピー $S_{\text{gas}}(630\,\text{K}, 1\,\text{atm})$ を求める．
エントロピーの変化は，状態の変化（相転移）と温度変化のプロセスを辿って合算することができる．

以下の経路でエントロピーを計算する：
1. **固体のエントロピー（融点 $T_m = 234.2\,\text{K}$ において）**:
   問題文より， $S_s(234.2) = 59.9 \times 10^7\,\text{erg}/(\text{mol deg})$ である．
2. **融解に伴うエントロピー変化 ( $\Delta S_{\text{fus}}$ )**:
   融解熱 $\Delta H_{\text{fus}} = 2330 \times 10^7\,\text{erg}/\text{mol}$ を融点 $T_m$ で割ることで得られる．
   $$\Delta S_{\text{fus}} = \frac{\Delta H_{\text{fus}}}{T_m} = \frac{2330 \times 10^7}{234.2} \approx 9.95 \times 10^7\,\text{erg}/(\text{mol deg})$$
3. **液体の温度上昇に伴うエントロピー変化 ( $\Delta S_{\text{liq}}$ )**:
   融点 $T_m$ から沸点 $T_b = 630\,\text{K}$ までの液体のエントロピー変化は，定圧比熱の積分値として与えられている．
   $$\Delta S_{\text{liq}} = S_l(630) - S_l(234.2) = 26.2 \times 10^7\,\text{erg}/(\text{mol deg})$$
4. **蒸発に伴うエントロピー変化 ( $\Delta S_{\text{vap}}$ )**:
   蒸発熱 $\Delta H_{\text{vap}} = 59300 \times 10^7\,\text{erg}/\text{mol}$ を沸点 $T_b$ で割ることで得られる．
   $$\Delta S_{\text{vap}} = \frac{\Delta H_{\text{vap}}}{T_b} = \frac{59300 \times 10^7}{630} \approx 94.13 \times 10^7\,\text{erg}/(\text{mol deg})$$

これらをすべて合計すると，沸点における水銀蒸気のエントロピー $S_{\text{gas}}(630\,\text{K}, 1\,\text{atm})$ が求まる．
$$S_{\text{gas}}(630\,\text{K}, 1\,\text{atm}) = S_s(234.2) + \Delta S_{\text{fus}} + \Delta S_{\text{liq}} + \Delta S_{\text{vap}}$$
$$S_{\text{gas}}(630\,\text{K}, 1\,\text{atm}) = (59.9 + 9.95 + 26.2 + 94.13) \times 10^7 \approx 190.18 \times 10^7\,\text{erg}/(\text{mol deg})$$
（解答例では，計算の簡略化のため $190.1 \times 10^7\,\text{erg}/(\text{mol deg})$ とされている．）

### 2. 化学定数 $i$ の算出

単原子理想気体のモルエントロピー $\overline{S}(T, p)$ は，以下の式で与えられる：

$$\overline{S}(T, p) = R \left( \frac{5}{2} \ln T - \ln p + \frac{5}{2} + i \right)$$

ここで， $R$ は気体定数， $i$ は求めたい化学定数である．

得られたエントロピーの値と，与えられた条件（ $T = 630\,\text{K}, p = 1\,\text{atm}$ ）を代入する．
気体定数 $R = 8.32 \times 10^7\,\text{erg}/(\text{mol deg})$ を用いると，

$$\frac{190.1 \times 10^7}{8.32 \times 10^7} = \frac{5}{2} \ln(630) - \ln(1) + \frac{5}{2} + i$$

各項を計算する：
- 左辺: $\frac{190.1}{8.32} \approx 22.85$
- $\frac{5}{2} \ln(630) \approx 2.5 \times 6.445 \approx 16.11$
- $\ln(1) = 0$
- $\frac{5}{2} = 2.5$

これらを代入すると：
$$22.85 = 16.11 - 0 + 2.5 + i$$
$$22.85 = 18.61 + i$$
$$i = 22.85 - 18.61 = 4.24$$

解答例に従い，有効数字を考慮してまとめると：

$$\therefore i = 4.2$$

## 解説

### 1. 化学定数 $i$ とは何か

理想気体のエントロピーの式に含まれる定数 $i$ は，原子や分子の質量，プランク定数，ボルツマン定数などを用いた「統計力学的な情報」をひとまとめにしたものである．
これは**サックール・テトローデの式 (Sackur-Tetrode equation)** に基づいている．

具体的には，単原子理想気体のエントロピーは以下のように書ける：

$$S = nR \left[ \ln \left( \frac{V}{n} \left( \frac{2\pi mkT}{h^2} \right)^{3/2} \right) + \frac{5}{2} \right]$$

これを圧力 $p$ を用いた形式に書き換えると，先ほどの式のように $\ln T$ や $\ln p$ の項が現れ，その定数部分が $i$ に相当する．

### 2. 化学定数 $i$ の単位について

化学定数 $i$ は **無次元量** （純粋な数）である．
式の中の $\ln p$ の項では，圧力を標準状態（ここでは $p_0 = 1\,\text{atm}$ ）で割った無次元量 $\ln(p/p_0)$ として扱う．
$i$ そのものには物理的な単位がなく，その数値は圧力の **単位系に依存する** （例：atm でなく Pa を使えば異なる数値になる）が，「atm という単位を持つ」わけではない．
以下では圧力の単位を atm としたときの値を示す．

### 3. 計算プロセスのまとめ

1.  **エントロピーの加法性**:
  エントロピーは状態量であり，ある状態から別の状態へ変化する際の経路に関わらず，各ステップの「変化量」を足し合わせることで全体の値を求めることができる．

2.  **相転移の扱い**:
  固体 $\to$ 液体 $\to$ 気体へと変化する際，温度一定での相転移（融解・蒸発）では $\Delta S = \Delta H / T$ を用いる．

3.  **理想気体のモデル**:
  水銀蒸気を単原子理想気体と見なすことで，エントロピーの理論式を適用し，未知の定数 $i$ を実験値（測定値）から逆算することができる．
