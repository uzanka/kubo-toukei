# 演習問題【4-B-37】

## 解答

### 1．気液平衡の条件

2成分の混合物を考え，成分1のモル分率を $x$ ，成分2のモル分率を $1-x$ とする．
気相と液相をそれぞれ添字 $g$ ， $l$ で表す．

気液平衡にあるとき，各成分の化学ポテンシャルは気相と液相で等しい．
化学ポテンシャルは，その成分の部分モル Gibbs 自由エネルギー $\bar G_i$ に等しいため，平衡条件は

```math
\begin{aligned}
\bar G_{1g}(T,x_g)&=\bar G_{1l}(T,x_l),\\
\bar G_{2g}(T,x_g)&=\bar G_{2l}(T,x_l)
\end{aligned}
\tag{1}
```

と書ける．
ここで， $x_g$ と $x_l$ は，それぞれ気相と液相における成分1のモル分率である．

共沸点では気相と液相の組成が一致するので，その温度と組成を $T_0$ ， $x_0$ とすると，

```math
x_g=x_l=x_0
```

が成り立つ．
したがって，共沸点では式（1）の両方の等式が，同じ温度，同じ組成において成立する．

### 2．共沸点の近傍で平衡条件を一次展開する

共沸点からの微小な変化を

```math
\begin{aligned}
T&=T_0+\delta T,\\
x_g&=x_0+\delta x_g,\\
x_l&=x_0+\delta x_l
\end{aligned}
```

とおく．

部分モル Gibbs 自由エネルギーの微小変化は，温度と組成について一次まで展開すると，

```math
\delta\bar G_i
=
\left(\frac{\partial\bar G_i}{\partial T}\right)_x\delta T
+
\left(\frac{\partial\bar G_i}{\partial x}\right)_T\delta x
\tag{2}
```

である．
熱力学の関係式

```math
\left(\frac{\partial\bar G_i}{\partial T}\right)_{P,x}
=-\bar S_i
```

を用いると，

```math
\delta\bar G_i
=
-\bar S_i\delta T
+
\left(\frac{\partial\bar G_i}{\partial x}\right)_{T,P}\delta x
\tag{3}
```

となる．
ここで， $\bar S_i$ は成分 $i$ の部分モルエントロピーである．
圧力は一定としている．

式（3）を式（1）に適用すると，一次の項について

```math
-\bar S_{1g}\delta T
+
\left(\frac{\partial\bar G_{1g}}{\partial x_g}\right)_{T,P}
\delta x_g
=
-\bar S_{1l}\delta T
+
\left(\frac{\partial\bar G_{1l}}{\partial x_l}\right)_{T,P}
\delta x_l
\tag{4a}
```

および

```math
-\bar S_{2g}\delta T
+
\left(\frac{\partial\bar G_{2g}}{\partial x_g}\right)_{T,P}
\delta x_g
=
-\bar S_{2l}\delta T
+
\left(\frac{\partial\bar G_{2l}}{\partial x_l}\right)_{T,P}
\delta x_l
\tag{4b}
```

を得る．
これらの式に現れるエントロピーと微分係数は，すべて共沸点での値である．

### 3．Gibbs–Duhem の関係式を用いて組成変化の項を消去する

次に，気相および液相それぞれについて Gibbs–Duhem の関係式を用いる．
圧力一定の二成分混合物では，

```math
x_1\,d\bar G_1+x_2\,d\bar G_2
=-\bar S\,dT
\tag{5}
```

が成り立つ．
ここで， $\bar S$ は混合物全体のモルエントロピーであり，

```math
\bar S=x_1\bar S_1+x_2\bar S_2
\tag{6}
```

である．

式（5）は，各成分の化学ポテンシャルの変化が互いに独立ではないことを表している．
特に，温度を固定した $dT=0$ の変化では，

```math
x_1\,d\bar G_1+x_2\,d\bar G_2=0
```

となる．
したがって，組成の変化による微分係数には，

```math
x_{1,0}
\left(\frac{\partial\bar G_{1\alpha}}{\partial x_\alpha}\right)_{T,P}
+
x_{2,0}
\left(\frac{\partial\bar G_{2\alpha}}{\partial x_\alpha}\right)_{T,P}
=0
\qquad (\alpha=l,g)
\tag{7}
```

という関係がある．
ここで $x_{1,0}=x_0$ ， $x_{2,0}=1-x_0$ である．

この式を用いて，式（4a）の両辺に $x_{1,0}$ を掛け，式（4b）の両辺に $x_{2,0}$ を掛けて，それらを加える．

左辺と右辺の組成変化の項は，式（7）によりそれぞれゼロとなる．
また，式（6）を用いると，残るエントロピーの項はそれぞれ混合物全体のモルエントロピーで表せる．
よって，

```math
-\bar S_l\delta T=-\bar S_g\delta T
```

を得る．
これを整理すると，

```math
(\bar S_g-\bar S_l)\delta T=0
\tag{8}
```

となる．

通常の共沸点が気液臨界点ではなく，蒸発に伴うモルエントロピーの差がゼロでない，すなわち

```math
\bar S_g-\bar S_l\ne0
```

であるとする．
すると，式（8）から，

```math
\boxed{\delta T=0
\quad\text{（一次の近似において）}}
\tag{9}
```

が得られる．

### 4．気相線と液相線が極値をとること

式（9）は，共沸点の近傍では，平衡条件を満たす温度変化に一次の項が現れないことを意味する．
すなわち，気相線および液相線に沿って，組成が微小に変化しても，温度は一次の近似では変化しない．

温度を組成の関数として表すと，両曲線について

```math
\boxed{
\left.\frac{dT_g}{dx_g}\right|_{x_0}=0,
\qquad
\left.\frac{dT_l}{dx_l}\right|_{x_0}=0
}
\tag{10}
```

となる．
したがって，共沸点では，気相線と液相線の接線はどちらも組成軸に平行となり，両曲線の温度は停留値をとる．

さらに，通常の共沸曲線のように，温度の二次の変化を決める項がゼロでない場合には，この停留値は極大または極小となる．
よって，共沸点においては，気相線と液相線は同じ温度で極大または極小をとることが示された．

### 3．結論と補足

証明の要点は，次のとおりである．
1. 気液平衡では，各成分の化学ポテンシャルが液相と気相で等しい．
2. その平衡条件を共沸点の近傍で一次展開する．
3. Gibbs–Duhem の関係式を使い，二つの成分について加え合わせることで，組成変化の項を消去する．
4. 気相と液相のモルエントロピー差がゼロでないことから，温度変化の一次の項がゼロとなる．したがって，共沸点では気相線と液相線の傾きがともにゼロとなる．

なお，厳密には，一次展開だけで証明できるのは温度の傾きがゼロであることまでである．
極大か極小かを判定するには，二次の項などを調べる必要がある．
問題の図のような通常の共沸曲線を想定すれば，その停留値が極大または極小となる．
