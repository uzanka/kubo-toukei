# 演習問題【4-B-37】

## 解答

### 1．気液平衡の条件

2成分の混合物を考え，成分1のモル分率を $x$ ，成分2のモル分率を $1-x$ とする．

気相と液相をそれぞれ添字 $g$ ， $l$ で表す．
また，気相および液相における成分 $i$ の化学ポテンシャルを，それぞれ $\mu_i^g$ ， $\mu_i^l$ とする．

気液平衡では，各成分の化学ポテンシャルが両相で等しいため，

```math
\boxed{
\mu_1^g(T,x_g)=\mu_1^l(T,x_l)
}
```

```math
\boxed{
\mu_2^g(T,x_g)=\mu_2^l(T,x_l)
}
\tag{1}
```

が成立する．

共沸点では気相と液相の組成が一致するので，その温度と組成を $T_0$ ， $x_0$ とすると，

```math
x_g=x_l=x_0
```

となる．

以下では，圧力 $P$ を一定とし，各相の化学ポテンシャルおよびモル Gibbs 自由エネルギーが共沸点近傍で十分滑らかであるとする．
また，気相と液相はそれぞれ組成について局所安定な均一相であり，共沸点は気液臨界点ではないものとする．

### 2．Gibbs–Duhem の関係式による停留点の証明

圧力一定の二成分系における Gibbs–Duhem の関係式は，

```math
x_1d\mu_1+x_2d\mu_2
=-\bar S\,dT
```

である．

したがって，気相と液相について，それぞれ

```math
x_gd\mu_1^g+(1-x_g)d\mu_2^g
=-\bar S_gdT
\tag{2a}
```

```math
x_ld\mu_1^l+(1-x_l)d\mu_2^l
=-\bar S_ldT
\tag{2b}
```

が成立する．

ここで， $\bar S_g$ ， $\bar S_l$ はそれぞれ気相と液相のモルエントロピーである．

気液平衡条件（1）を平衡曲線に沿って微分すると，

```math
d\mu_1^g=d\mu_1^l
```

```math
d\mu_2^g=d\mu_2^l
```

となる．

これらの共通の微小変化を，それぞれ $d\mu_1$ ， $d\mu_2$ と書く．

式（2a）から式（2b）を引くと，

```math
(x_g-x_l)d\mu_1
+(x_l-x_g)d\mu_2
=-(\bar S_g-\bar S_l)dT
```

となる．

左辺を整理すると，

```math
(x_g-x_l)(d\mu_1-d\mu_2)
=-(\bar S_g-\bar S_l)dT
```

したがって，

```math
\boxed{
(\bar S_g-\bar S_l)dT
=(x_l-x_g)d(\mu_1-\mu_2)
}
\tag{3}
```

を得る．

ここで，通常の気液相転移を考え，共沸点において，

```math
\boxed{
\bar S_g-\bar S_l\neq0
}
\tag{4}
```

とする．

共沸点では，

```math
x_g=x_l=x_0
```

であるため，式（3）から，

```math
(\bar S_g-\bar S_l)dT=0
```

となる．

式（4）より，

```math
\boxed{dT=0}
```

を得る．

すなわち，共沸点において，気液平衡曲線に沿った温度の一次の変化はゼロである．

気相と液相の組成をそれぞれ独立変数として平衡曲線を局所的に表すと，

```math
T=T_l(x_l),\qquad x_g=x_g(x_l)
```

および，

```math
T=T_g(x_g),\qquad x_l=x_l(x_g)
```

となる．

したがって，

```math
\boxed{
\left.\frac{dT_l}{dx_l}\right|_{x_0}=0
}
\tag{5a}
```

```math
\boxed{
\left.\frac{dT_g}{dx_g}\right|_{x_0}=0
}
\tag{5b}
```

が成立する．

よって，共沸点は気相線と液相線の双方における停留点である．

### 3．二階微分による極大・極小の判定

ここまでの結果だけでは，共沸点が極大点または極小点であるとは断定できない．

そこで，気相線と液相線の二階微分を求める．

気相および液相のモル Gibbs 自由エネルギーを，それぞれ

```math
g^g(T,x_g),\qquad g^l(T,x_l)
```

とする．

二成分系では，各成分の化学ポテンシャルは，

```math
\mu_1^\alpha
=
g^\alpha+(1-x_\alpha)
\left(\frac{\partial g^\alpha}{\partial x_\alpha}\right)_{T,P}
```

```math
\mu_2^\alpha
=
g^\alpha-x_\alpha
\left(\frac{\partial g^\alpha}{\partial x_\alpha}\right)_{T,P}
```

と表される．
ここで， $\alpha=g,l$ である．

したがって，

```math
\mu_1^\alpha-\mu_2^\alpha
=
\left(\frac{\partial g^\alpha}{\partial x_\alpha}\right)_{T,P}
```

となる．

これをさらに組成で微分すると，

```math
\frac{\partial(\mu_1^\alpha-\mu_2^\alpha)}
{\partial x_\alpha}
=
\left(\frac{\partial^2g^\alpha}
{\partial x_\alpha^2}\right)_{T,P}
```

を得る．

ここで，共沸点において，

```math
K_g=
\left(\frac{\partial^2g^g}{\partial x_g^2}\right)_{T,P}
```

```math
K_l=
\left(\frac{\partial^2g^l}{\partial x_l^2}\right)_{T,P}
```

と定義する．

気相と液相がそれぞれ組成について局所安定な均一相であるため，

```math
\boxed{
K_g>0,\qquad K_l>0
}
\tag{6}
```

が成立する．

以下では，すべての微分係数を共沸点で評価する．

#### 3.1 液相線の二階微分

式（3）を液相組成 $x_l$ に沿って表すと，

```math
(\bar S_g-\bar S_l)
\frac{dT_l}{dx_l}
=
(x_l-x_g)
\frac{d(\mu_1-\mu_2)}{dx_l}
\tag{7}
```

となる．

この式をさらに $x_l$ で微分すると，

```math
\begin{aligned}
&\frac{d(\bar S_g-\bar S_l)}{dx_l}
\frac{dT_l}{dx_l}
+
(\bar S_g-\bar S_l)
\frac{d^2T_l}{dx_l^2}
\\
&=
\left(1-\frac{dx_g}{dx_l}\right)
\frac{d(\mu_1-\mu_2)}{dx_l}
+
(x_l-x_g)
\frac{d^2(\mu_1-\mu_2)}{dx_l^2}
\end{aligned}
```

となる．

共沸点では，

```math
\left.\frac{dT_l}{dx_l}\right|_{x_0}=0
```

および，

```math
x_l-x_g=0
```

であるため，

```math
(\bar S_g-\bar S_l)
\left.\frac{d^2T_l}{dx_l^2}\right|_{x_0}
=
\left(1-\left.\frac{dx_g}{dx_l}\right|_{x_0}\right)
\left.\frac{d(\mu_1-\mu_2)}{dx_l}\right|_{x_0}
\tag{8}
```

となる．

式（5a）より，共沸点では温度の一次微分がゼロであるから，

```math
\left.\frac{d(\mu_1-\mu_2)}{dx_l}\right|_{x_0}
=K_l
```

である．

次に，気液平衡条件（1）を液相組成 $x_l$ に沿って微分する．

共沸点では，

```math
\left.\frac{dT_l}{dx_l}\right|_{x_0}=0
```

なので，成分1および成分2についての微分式を引くと，

```math
K_g\left.\frac{dx_g}{dx_l}\right|_{x_0}
=K_l
```

を得る．

したがって，

```math
\left.\frac{dx_g}{dx_l}\right|_{x_0}
=
\frac{K_l}{K_g}
```

である．

これらを式（8）に代入すると，

```math
(\bar S_g-\bar S_l)
\left.\frac{d^2T_l}{dx_l^2}\right|_{x_0}
=
\left(1-\frac{K_l}{K_g}\right)K_l
```

となる．

整理すると，

```math
\boxed{
\left.\frac{d^2T_l}{dx_l^2}\right|_{x_0}
=
\frac{K_l(K_g-K_l)}
{(\bar S_g-\bar S_l)K_g}
}
\tag{9}
```

を得る．

#### 3.2 気相線の二階微分

同様に，式（3）を気相組成 $x_g$ に沿って表すと，

```math
(\bar S_g-\bar S_l)
\frac{dT_g}{dx_g}
=
(x_l-x_g)
\frac{d(\mu_1-\mu_2)}{dx_g}
\tag{10}
```

となる．

この式を $x_g$ で微分し，共沸点で評価すると，

```math
\begin{aligned}
&\frac{d(\bar S_g-\bar S_l)}{dx_g}
\frac{dT_g}{dx_g}
+
(\bar S_g-\bar S_l)
\frac{d^2T_g}{dx_g^2}
\\
&=
\left(\frac{dx_l}{dx_g}-1\right)
\frac{d(\mu_1-\mu_2)}{dx_g}
+
(x_l-x_g)
\frac{d^2(\mu_1-\mu_2)}{dx_g^2}
\end{aligned}
```

となる．

式（5b）および共沸条件より，

```math
(\bar S_g-\bar S_l)
\left.\frac{d^2T_g}{dx_g^2}\right|_{x_0}
=
\left(
\left.\frac{dx_l}{dx_g}\right|_{x_0}-1
\right)
\left.\frac{d(\mu_1-\mu_2)}{dx_g}\right|_{x_0}
\tag{11}
```

を得る．

ここで，

```math
\left.\frac{d(\mu_1-\mu_2)}{dx_g}\right|_{x_0}
=K_g
```

である．

また，気液平衡条件を気相組成 $x_g$ に沿って微分し，成分1と成分2についての式を引くと，

```math
K_l\left.\frac{dx_l}{dx_g}\right|_{x_0}
=K_g
```

となる．

したがって，

```math
\left.\frac{dx_l}{dx_g}\right|_{x_0}
=
\frac{K_g}{K_l}
```

である．

これらを式（11）に代入すると，

```math
(\bar S_g-\bar S_l)
\left.\frac{d^2T_g}{dx_g^2}\right|_{x_0}
=
\left(\frac{K_g}{K_l}-1\right)K_g
```

となる．

整理すると，

```math
\boxed{
\left.\frac{d^2T_g}{dx_g^2}\right|_{x_0}
=
\frac{K_g(K_g-K_l)}
{(\bar S_g-\bar S_l)K_l}
}
\tag{12}
```

を得る．

### 4．極大・極小となる条件

式（9），式（12）より，

```math
\operatorname{sgn}
\left(
\left.\frac{d^2T_l}{dx_l^2}\right|_{x_0}
\right)
=
\operatorname{sgn}
\left(
\left.\frac{d^2T_g}{dx_g^2}\right|_{x_0}
\right)
=
\operatorname{sgn}
\left(
\frac{K_g-K_l}{\bar S_g-\bar S_l}
\right)
```

が成立する．

ここで，

```math
\boxed{
K_g\neq K_l
}
\tag{13}
```

という非退化条件を追加する．

この条件のもとでは，式（6）および式（4）より，気相線と液相線の二階微分はいずれもゼロではない．

したがって，二階微分判定法により，両曲線は共沸点において極大または極小をとる．

具体的には，

```math
\frac{K_g-K_l}{\bar S_g-\bar S_l}>0
```

ならば，両曲線とも極小となる．

一方，

```math
\frac{K_g-K_l}{\bar S_g-\bar S_l}<0
```

ならば，両曲線とも極大となる．

よって，非退化条件 $K_g\neq K_l$ が成立する場合には，気相線と液相線は共沸点において同じ温度で，同じ種類の極値をとることが示された．

### 5．追加条件が必要であることについての注意

ここで注意すべきことは，

```math
K_g>0,\qquad K_l>0
```

から，

```math
K_g\neq K_l
```

が必ず導かれるわけではないことである．

局所安定性は両者が正であることを保証するが，両者が異なることまでは保証しない．

したがって， $K_g\neq K_l$ は二階微分判定によって極値を証明するための十分条件であり，問題文から自動的に導かれる条件ではない．

実際に，

```math
K_g=K_l=K>0
```

となる場合も考えられる．

この場合，式（9），式（12）から，

```math
\left.\frac{d^2T_l}{dx_l^2}\right|_{x_0}
=
\left.\frac{d^2T_g}{dx_g^2}\right|_{x_0}
=0
```

となり，二階微分判定法では極値を確定できない．

さらに，三次の項が最初に現れる場合には，停留変曲点となる可能性がある．

例えば，局所的なモル Gibbs 自由エネルギーを，

```math
u=x_l-x_0,\qquad
v=x_g-x_0,\qquad
t=T-T_0
```

として，

```math
g^l
=
g_0-s_lt+\frac{K}{2}u^2+\frac{a_l}{6}u^3
```

```math
g^g
=
g_0-s_gt+\frac{K}{2}v^2+\frac{a_g}{6}v^3
```

と表す．

ここで，

```math
K>0,\qquad
s_g-s_l\neq0,\qquad
a_g-a_l\neq0
```

とする．

このとき，共沸点では，

```math
K_g=K_l=K>0
```

かつ，

```math
\bar S_g-\bar S_l=s_g-s_l\neq0
```

が成立する．

気液平衡条件を用いて展開すると，

```math
v
=
u+\frac{a_l-a_g}{2K}u^2+O(u^3)
```

となり，さらに，

```math
\boxed{
T-T_0
=
\frac{a_g-a_l}{6(s_g-s_l)}
(x_l-x_0)^3
+O((x_l-x_0)^4)
}
```

を得る．

したがって，この場合には温度の一次微分と二次微分がともにゼロであっても，三次の項によって温度が共沸点の前後で単調に変化する可能性がある．

すなわち，共沸点が必ず極大または極小になるとは限らない．

なお，この局所モデルに両相共通の滑らかな温度関数を加えても，気液平衡条件と上記の結論は変わらない．

### 6．結論

以上より，次のことが示された．

1．気液平衡では，各成分の化学ポテンシャルが気相と液相で等しい．

2．Gibbs–Duhem の関係式を用いると，気液間のモルエントロピー差がゼロでない場合，共沸点において気相線と液相線の温度の一次微分がともにゼロとなる．

3．したがって，共沸点は気相線と液相線の双方における停留点である．

4．さらに，モル Gibbs 自由エネルギーの組成に関する二階微分を用いると，両曲線の温度の二階微分を求めることができる．

5． $K_g\neq K_l$ という非退化条件が成立すれば，両曲線の二階微分はゼロではなく，同じ符号となる．
したがって，両曲線は共沸点において同じ種類の極大または極小をとる．

6．一方， $K_g=K_l$ の場合には，二階微分がともにゼロとなるため，高次の項を調べなければ極値であるかどうかを確定できない．

したがって，気液平衡条件と Gibbs–Duhem の関係式から一般に証明できるのは，共沸点が気相線と液相線の停留点になることである．
極大または極小になることまで厳密に証明するには，非退化条件または高次の微分に関する追加条件が必要である．

問題の図が両曲線の極大または極小を示している場合には，その図形上の条件と合わせて，通常の非退化な共沸点では両曲線が同じ種類の極値をとると結論できる．
