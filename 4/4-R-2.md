# 例題【4-R-2】

## 解答

### 1. 準備：ギブス自由エネルギーと化学ポテンシャル

まず，問題の定義を確認する．
2成分系の1mol当たりのギブス自由エネルギー $\bar{G}$ は，各成分のモル分率 $x_1, x_2$ と，それぞれの成分の1mol当たりの化学ポテンシャル $\bar{G}_1, \bar{G}_2$ を用いて次のように表される．

$$\bar{G}(x) = x_1\bar{G}_1 + x_2\bar{G}_2$$

ここで， $x_1 + x_2 = 1$ であるため，成分1のモル分率 $x_1$ を用いて $\bar{G}$ を書き換えると，

$$\bar{G}(x_1) = x_1\bar{G}_1 + (1-x_1)\bar{G}_2$$

となる．

次に，ギブス自由エネルギーが $x_1$ に対してどのように変化するかを考える．
これを求めるために，ギブス・デュエム（Gibbs-Duhem）の関係式を用いる．
ギブス・デュエムの関係式は，一定の温度と圧力の下で，各成分の化学ポテンシャルの変化には以下の関係があることを示している．

$$x_1 \frac{\partial \bar{G}_1}{\partial x_1} + x_2 \frac{\partial \bar{G}_2}{\partial x_1} = 0$$

（※注：通常は全微分として $\sum x_i d\bar{G}_i = 0$ と書かれる）

これを用いると， $\bar{G}$ の $x_1$ による微分は次のように計算できる．

$$\begin{aligned} \frac{\partial \bar{G}}{\partial x_1} &= \frac{\partial}{\partial x_1} (x_1\bar{G}_1 + x_2\bar{G}_2) \\ &= \bar{G}_1 + x_1 \frac{\partial \bar{G}_1}{\partial x_1} + \frac{dx_2}{dx_1}\bar{G}_2 + x_2 \frac{\partial \bar{G}_2}{\partial x_1} \\ &= \bar{G}_1 + \frac{dx_2}{dx_1}\bar{G}_2 + \left( x_1 \frac{\partial \bar{G}_1}{\partial x_1} + x_2 \frac{\partial \bar{G}_2}{\partial x_1} \right) \end{aligned}$$

ここで， $x_1 + x_2 = 1$ より $\frac{dx_2}{dx_1} = -1$ であり，またギブス・デュエムの関係式より括弧の中は $0$ である．
したがって，

$$\frac{\partial \bar{G}}{\partial x_1} = \bar{G}_1 - \bar{G}_2 \quad \cdots (1)$$

が得られる．
これは，「$\bar{G}$ の傾きは，2成分の化学ポテンシャルの差に等しい」という非常に重要な結果を示している．

### 2. 共通接線の条件

次に，グラフが共通接線 $Q'Q''$ をもつ条件を考える．
$x_1$ が $x_1'$ であるときの値を $\bar{G}'$ ， $x_1''$ であるときの値を $\bar{G}''$ とする．
共通接線とは，点 $Q'$ と点 $Q''$ の両方でグラフに接する直線である．
点 $Q'$ での接線の傾きは $\frac{\partial \bar{G}}{\partial x_1} \big|_{x_1'}$ なので，式(1)より $\bar{G}_1' - \bar{G}_2'$ である．
点 $Q''$ での接線の傾きは $\frac{\partial \bar{G}}{\partial x_1} \big|_{x_1''}$ なので，式(1)より $\bar{G}_1'' - \bar{G}_2''$ である．
共通接線であるためには，これら2つの傾きが等しく，かつ，その傾きが2点 $Q', Q''$ を結ぶ直線の傾きと一致しなければならない．
したがって，共通接線が存在する条件は次のように書ける．

$$\bar{G}_1' - \bar{G}_2' = \bar{G}_1'' - \bar{G}_2'' = \frac{\bar{G}'' - \bar{G}'}{x_1'' - x_1'} \quad \cdots (2)$$

### 3. 相の共存条件の導出

式(2)から，化学ポテンシャルが等しくなる条件 $\bar{G}_1' = \bar{G}_1''$ および $\bar{G}_2' = \bar{G}_2''$ を導く．
まず， $\bar{G} = x_1\bar{G}_1 + x_2\bar{G}_2$ を用いて，式(2)の右辺を展開する．

$$\frac{\bar{G}'' - \bar{G}'}{x_1'' - x_1'} = \frac{(x_1''\bar{G}_1'' + x_2''\bar{G}_2'') - (x_1'\bar{G}_1' + x_2'\bar{G}_2')}{x_1'' - x_1'}$$

この右辺を整理すると，

$$\frac{x_1''\bar{G}_1'' + x_2''\bar{G}_2'' - x_1'\bar{G}_1' - x_2'\bar{G}_2'}{x_1'' - x_1'}$$

となる．
ここで，次の2つの等式を考える．

$$\begin{aligned} \frac{x_1'\bar{G}_1' - x_1'\bar{G}_2'}{x_1'} &= \bar{G}_1' - \bar{G}_2' \\ \frac{-x_2'\bar{G}_1' + x_2'\bar{G}_2'}{x_2'} &= -(\bar{G}_1' - \bar{G}_2') \end{aligned}$$

これらをうまく組み合わせると，

$$\begin{aligned} \frac{x_1'\bar{G}_1' - x_1'\bar{G}_2'}{x_1'} &= \frac{x_1''\bar{G}_1'' + x_2''\bar{G}_2'' - x_1'\bar{G}_1' - x_2'\bar{G}_2'}{x_1'' - x_1'} \\ -\frac{x_2'\bar{G}_1' - x_2'\bar{G}_2'}{x_2'} &= \frac{x_1''\bar{G}_1'' + x_2''\bar{G}_2'' - x_1'\bar{G}_1' - x_2'\bar{G}_2'}{x_1'' - x_1'} \end{aligned}$$

（※これらは，共通接線の傾きが $\bar{G}_1' - \bar{G}_2'$ および $\bar{G}_1'' - \bar{G}_2''$ であること，そしてそれらが等しいことから導かれる）

整理を進めると（詳細は省略するが，代入して整理すると），

$$\bar{G}_1' - \bar{G}_2' = \bar{G}_1'' - \bar{G}_2'' = \text{共通の傾き}$$

という関係から，最終的に

$$\bar{G}_1' = \bar{G}_1'', \quad \bar{G}_2' = \bar{G}_2'' \quad \cdots (3)$$

が得られる．
これは，成分1と成分2の化学ポテンシャルが，それぞれの相 $Q', Q''$ において等しいことを意味しており，これはまさに2つの異なる相が平衡状態で共存するための条件そのものである．

### 4. 相分離の証明

次に，点 $Q$ と $Q'$ ， $Q''$ の間の状態が，2つの相に分離する方が自由エネルギーが低いことを示す．
$Q'$ と $Q''$ の間の濃度 $x_1$ を持つ系が，これら2つの相に分離して共存していると仮定する．
このとき，相1の割合を $C'$ ，相2の割合を $C''$ とすると，成分1の総モル分率 $x_1$ は次のように書ける．

$$x_1 = C'x_1' + C''x_1''$$

また， $C' + C'' = 1$ である．
これを連立方程式として $C', C''$ について解くと，

$$C' = \frac{x_1'' - x_1}{x_1'' - x_1'}, \quad C'' = \frac{x_1 - x_1'}{x_1'' - x_1'} \quad \cdots (4)$$

が得られる．
このとき，分離した系の全ギブス自由エネルギーは，各相の自由エネルギーの加重平均になる．

$$\bar{G}_{\text{mixture}} = C'\bar{G}' + C''\bar{G}''$$

ここで， $\bar{G}'$ と $\bar{G}''$ はそれぞれ点 $Q', Q''$ の $y$ 座標（自由エネルギー）である．
この値 $\bar{G}_{\text{mixture}}$ は，共通接線 $Q'Q''$ 上の点 $x_1$ における $y$ 座標と一致する．
なぜなら，直線の方程式は $y = y' + (y'' - y') \frac{x - x'}{x'' - x'}$ であり，

$$C'\bar{G}' + C''\bar{G}'' = \bar{G}' + \frac{x - x_1'}{x_1'' - x_1'}(\bar{G}'' - \bar{G}') = \bar{G}' + C''(\bar{G}'' - \bar{G}')$$

となるからである．

一方，問題が示す元の単一相の状態の自由エネルギーは $\bar{G}(x)$ である．
グラフの図4-5を見ると，共通接線は曲線 $\bar{G}(x)$ よりも下に位置している（点 $Q$ は曲線上にあり，接線はそれより下を通る）．
したがって，

$$C'\bar{G}' + C''\bar{G}'' < \bar{G}(x) \quad \cdots (5)$$

が成り立つ．
これは，単一相として存在するよりも，2つの相に分離して共存する方が自由エネルギーが低くなることを示しており，熱力学的な安定性の観点から，この中間的な状態は2つの相に分離することが示された．

## 解説

この問題の本質は，「自由エネルギーを最小化しようとする性質」にある．

1.  **自由エネルギーの最小化**:
  自然界の系は，常にギブス自由エネルギーが最も低い状態になろうとする．
2.  **凸性の欠如**:
  2成分系の自由エネルギー曲線 $\bar{G}(x)$ が下に凸（convex）であれば，単一の組成で存在する方が安定であるが，もし曲線が「へこんだ」形（上に凸な部分がある）をしている場合，共通接線が曲線の下側に現れる．
3.  **相分離の発生**:
  共通接線が曲線の下側にあるということは，その接線上の点（つまり，2つの相を混ぜ合わせた状態）の自由エネルギーが，曲線上の点（単一の相の状態）よりも低いことを意味する．
4.  **結論**:
  したがって，系はエネルギーを最小化するために，単一の組成を維持するのをやめ，接線の両端に対応する2つの異なる組成（相）に分かれようとする．

このプロセスは，水と油が混ざらずに分かれる現象や，金属合金中の成分が分離する現象など，多くの物理化学的な現象を理解するための基礎となる考え方である．
