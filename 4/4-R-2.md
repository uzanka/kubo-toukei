# 例題【4-R-2】

## 解答

## 1．Gibbs 自由エネルギーの傾きと化学ポテンシャルの関係

2成分系の1 mol 当たりの Gibbs 自由エネルギーは，

```math
\bar G=x_1\bar G_1+x_2\bar G_2
\tag{1}
```

で与えられる．
ここで， $x_1$ ， $x_2$ は成分1，2のモル分率， $\bar G_1$ ， $\bar G_2$ はそれぞれの成分の化学ポテンシャルである．

以下では，

```math
x=x_1,\qquad x_2=1-x
```

とおき，温度と圧力は一定とする．
このとき，式（1）は

```math
\bar G(x)=x\bar G_1+(1-x)\bar G_2
\tag{2}
```

と書ける．

ここで，Gibbs–Duhem の関係式を用いる．
一定温度，圧力では，

```math
x_1\,d\bar G_1+x_2\,d\bar G_2=0
\tag{3}
```

が成り立つ．
組成 $x_1$ による微分をとると，

```math
x_1\frac{\partial\bar G_1}{\partial x_1} +x_2\frac{\partial\bar G_2}{\partial x_1}=0
\tag{4}
```

となる．

一方，式（2）を $x=x_1$ で微分すると，

```math
\begin{aligned}
\frac{d\bar G}{dx} &=\bar G_1+x_1\frac{\partial\bar G_1}{\partial x_1} -\bar G_2+x_2\frac{\partial\bar G_2}{\partial x_1}\\
&=\bar G_1-\bar G_2 +\left( x_1\frac{\partial\bar G_1}{\partial x_1} +x_2\frac{\partial\bar G_2}{\partial x_1} \right).
\end{aligned}
```

式（4）より，括弧内の項はゼロである．
したがって，

```math
\boxed{
\frac{d\bar G}{dx_1}=\bar G_1-\bar G_2
}
\tag{5}
```

を得る．
すなわち，Gibbs 自由エネルギー曲線の傾きは，成分1と成分2の化学ポテンシャルの差に等しいのである．

## 2．共通接線の条件から各成分の化学ポテンシャルが等しいことを示す

図の共通接線 $Q'Q''$ が接する組成を，それぞれ $x_1'$ ， $x_1''$ とする．
そのときの Gibbs 自由エネルギーを

```math
\bar G'=\bar G(x_1'),\qquad \bar G''=\bar G(x_1'')
```

と表し，各組成での化学ポテンシャルを $\bar G_i'$ ， $\bar G_i''$ と表す．

共通接線であるためには， $Q'$ と $Q''$ における接線の傾きが等しく，さらにその傾きは2点を結ぶ直線の傾きに等しい．
式（5）を用いると，

```math
\boxed{
\bar G_1'-\bar G_2' = \bar G_1''-\bar G_2'' = \frac{\bar G''-\bar G'}{x_1''-x_1'}
}
\tag{6}
```

が成り立つ．

ここから，各成分の化学ポテンシャルがそれぞれ等しいことを示す．
まず，

```math
\Delta\bar G_1=\bar G_1''-\bar G_1', \qquad \Delta\bar G_2=\bar G_2''-\bar G_2'
```

とおく．
式（6）の最初の等式から，

```math
\bar G_1'-\bar G_2' = \bar G_1''-\bar G_2''
```

であるため，

```math
\Delta\bar G_1=\Delta\bar G_2
```

となる．
この共通の値を $\delta$ とする．
すなわち，

```math
\bar G_1''=\bar G_1'+\delta,\qquad \bar G_2''=\bar G_2'+\delta
\tag{7}
```

である．

式（1）により，

```math
\bar G'' =x_1''\bar G_1''+x_2''\bar G_2'', \qquad \bar G' =x_1'\bar G_1'+x_2'\bar G_2'
```

である．
ここに式（7）を代入すると，

```math
\begin{aligned}
\bar G''-\bar G' &=x_1''(\bar G_1'+\delta) +x_2''(\bar G_2'+\delta)\\
&\quad-x_1'\bar G_1'-x_2'\bar G_2'\\
&=(x_1''-x_1')\bar G_1' +(x_2''-x_2')\bar G_2'\\
&\quad+(x_1''+x_2'')\delta.
\end{aligned}
```

モル分率の和は各相で1であるため，

```math
x_1''+x_2''=1
```

である．
また，

```math
x_2''-x_2'=-(x_1''-x_1')
```

なので，

```math
\bar G''-\bar G' =(x_1''-x_1')(\bar G_1'-\bar G_2')+\delta
\tag{8}
```

となる．

式（6）から，

```math
\bar G''-\bar G' =(x_1''-x_1')(\bar G_1'-\bar G_2')
\tag{9}
```

も成り立つ．
式（8），（9）を比較すると，

```math
\delta=0
```

である．
よって，

```math
\Delta\bar G_1=\Delta\bar G_2=0
```

となり，

```math
\boxed{
\bar G_1'=\bar G_1'',\qquad \bar G_2'=\bar G_2''
}
\tag{10}
```

を得る．

これは，2つの異なる組成 $x_1'$ ， $x_1''$ をもつ相の間で，各成分の化学ポテンシャルがそれぞれ等しいということである．
したがって，両相は化学平衡にあり，2相が共存できる条件を満たしている．

## 3．共通接線の間の状態が相分離することを示す

次に，組成 $x_1$ が

```math
x_1'\<x_1\<x_1''
\tag{11}
```

を満たす系を考える．
この系が組成 $x_1'$ の相と組成 $x_1''$ の相に分離するとする．
全物質量のうち，前者の相の割合を $C'$ ，後者の相の割合を $C''$ とおく．

2相の割合の和は1であるため，

```math
C'+C''=1
\tag{12}
```

が成り立つ．
また，全体の組成は各相の組成の加重平均なので，

```math
x_1=C'x_1'+C''x_1''
\tag{13}
```

となる．
式（12），（13）を連立して解くと，

```math
\boxed{
C'=\frac{x_1''-x_1}{x_1''-x_1'}, \qquad C''=\frac{x_1-x_1'}{x_1''-x_1'}
}
\tag{14}
```

を得る．
これが2相の割合を与える式である．

2相に分離した系の Gibbs 自由エネルギーは，それぞれの相の自由エネルギーの加重平均であるため，

```math
\bar G_{\mathrm{sep}}=C'\bar G'+C''\bar G''
\tag{15}
```

となる．
式（14）を代入すると，

```math
\begin{aligned}
\bar G_{\mathrm{sep}} &=\frac{x_1''-x_1}{x_1''-x_1'}\bar G' +\frac{x_1-x_1'}{x_1''-x_1'}\bar G''\\
&=\bar G' +\frac{x_1-x_1'}{x_1''-x_1'}(\bar G''-\bar G').
\end{aligned}
\tag{16}
```

これは，点 $Q'$ と点 $Q''$ を結ぶ直線上で，組成 $x_1$ に対応する高さそのものである．
すなわち，2相に分離した系の Gibbs 自由エネルギーは，共通接線 $Q'Q''$ 上の値に等しい．

問題の図では，共通接線 $Q'Q''$ は，その間の組成における元の Gibbs 自由エネルギー曲線よりも下側にある．
したがって，

```math
\boxed{
\bar G_{\mathrm{sep}}<\bar G(x_1)
}
\tag{17}
```

となる．
ここで $\bar G(x_1)$ は，同じ全体組成をもつ均一な1相の状態の Gibbs 自由エネルギーである．

一定温度，圧力では，安定な平衡状態は Gibbs 自由エネルギーが最小となる状態である．
式（17）は，均一な1相として存在するよりも，組成 $x_1'$ と $x_1''$ をもつ2相に分離した方が自由エネルギーが低いことを示している．
よって，共通接線の両接点の間の組成をもつ系は，その2つの相に分離して共存するのである．

## 4．幾何学的な意味と結論

共通接線 $Q'Q''$ の両端は，それぞれ共存する2相の組成 $x_1'$ ， $x_1''$ を表す．
この間にある全体組成 $x_1$ の系は，2相の混合として表され，それぞれの相の割合は，

```math
\boxed{
C'=\frac{x_1''-x_1}{x_1''-x_1'}, \qquad C''=\frac{x_1-x_1'}{x_1''-x_1'}
}
```

によって決まる．
幾何学的には，組成軸上で点 $x_1$ が $x_1'$ と $x_1''$ の間のどこに位置するかによって，相の割合が決定されるのである．

また，共通接線が曲線より下側にあることは，2相に分離した状態の Gibbs 自由エネルギーが均一な1相の状態より低いことを意味する．
これにより，共通接線の両接点に対応する2つの相が共存し，その間の組成をもつ系は相分離することが示された．
