# 演習問題【4-R-1】

## 解答

van der Waals の状態方程式によって描かれる $(V, p)$ 面の等温線において，臨界温度以下では「谷」と「山」を持つ曲線が得られる．
このとき，系の状態が液相と気相に分離して共存する条件（2相共存）を幾何学的に導出する．

### 1. 2相共存の圧力の決定（Maxwell の規則）

2相（液相と気相）が平衡状態にあるためには，以下の2つの条件が満たされなければならない．

1.  **圧力の等しさ**: $p_{liquid} = p_{gas} = p_{coex}$
2.  **化学ポテンシャルの等しさ**: $\mu_{liquid} = \mu_{gas}$
    *   ここで，1molあたりの化学ポテンシャルは Gibbs 自由エネルギー $\overline{G}$ に等しい．

等温過程における Gibbs 自由エネルギーの変化 $d\overline{G}$ は，圧力 $p$ とモル体積 $\overline{V}$ を用いて次のように表される．

$$d\overline{G} = \overline{V} dp$$

等温線上の任意の2点 $A$ と $B$ の間の自由エネルギーの差は，積分によって次のように求められる．

$$\overline{G}(B) - \overline{G}(A) = \int_{p_A}^{p_B} \overline{V} dp$$

図において，等温線が「谷」と「山」を持つ場合，任意の水平線（一定の圧力 $p$ ）との交点を $B, D, F$ とし，図の形状（曲線 $ABCDEFG$ ）に基づいた面積の関係を考える．

*   点 $D$ を基準としたとき，点 $F$ までの自由エネルギー変化：
    $$\overline{G}(D) - \overline{G}(F) = \int_{p_F}^{p_D} \overline{V} dp = \text{面積 (FEDF)}$$
*   点 $D$ を基準としたとき，点 $B$ までの自由エネルギー変化：
    $$\overline{G}(D) - \overline{G}(B) = \int_{p_B}^{p_D} \overline{V} dp = \text{面積 (DCBD)}$$

ここで， $\overline{G}(B) - \overline{G}(F) = (\overline{G}(D) - \overline{G}(F)) - (\overline{G}(D) - \overline{G}(B))$ であるから，

$$\overline{G}(B) - \overline{G}(F) = \text{面積 (FEDF)} - \text{面積 (DCBD)}$$

となる．

2相平衡の条件 $\overline{G}(B) = \overline{G}(F)$ を満たすためには，上式の右辺が $0$ になればよい．
すなわち，

$$\text{面積 (FEDF)} = \text{面積 (DCBD)}$$

が成り立つときである．
これは，**等温線が作る「山」の部分の面積と「谷」の部分の面積が等しくなるような水平線を引くこと**を意味する．
この条件を満たす圧力を **Maxwell の規則** と呼び，このときの圧力が 2相共存の圧力（飽和蒸気圧）となる．

### 2. 共存する2相の割合の決定

次に，全物質量 $n$ [mol] の系において，圧力が共存圧力 $p_{coex}$ にあるとき，液相の割合を $x$ とすると，気相の割合は $(1-x)$ となる．

このとき，全体の体積 $V_{total}$ は，各相の体積の和として次のように書ける．

$$V_{total} = n x \overline{V}_B + n(1-x) \overline{V}_F$$

ここで， $\overline{V}_B$ は液相のモル体積， $\overline{V}_F$ は気相のモル体積である．

また，混合状態の平均的なモル体積を $\overline{V}_M$ とすると， $V_{total} = n \overline{V}_M$ である．
これらを等式で結ぶと，

$$n \overline{V}_M = n x \overline{V}_B + n(1-x) \overline{V}_F$$

両辺を $n$ で割って整理すると，

$$\overline{V}_M = x \overline{V}_B + (1-x) \overline{V}_F$$

となる．
これを $x$ について解く．

$$\overline{V}_M = x \overline{V}_B + \overline{V}_F - x \overline{V}_F$$

$$\overline{V}_M - \overline{V}_F = x (\overline{V}_B - \overline{V}_F)$$

$$x = \frac{\overline{V}_M - \overline{V}_F}{\overline{V}_B - \overline{V}_F} = \frac{\overline{V}_F - \overline{V}_M}{\overline{V}_F - \overline{V}_B}$$

また， $\frac{x}{1-x}$ の形に整理すると，

$$\overline{V}_M = x \overline{V}_B + \overline{V}_F - x \overline{V}_F \implies \overline{V}_M - \overline{V}_F = x(\overline{V}_B - \overline{V}_F)$$

これを用いると，

$$\frac{x}{1-x} = \frac{\overline{V}_F - \overline{V}_M}{\overline{V}_M - \overline{V}_B}$$

が得られる．

したがって，共存する2相の割合（質量比・モル比）は，等温線上の共存圧力における点 $M$ が，液相の点 $B$ と気相の点 $F$ を結ぶ線分上でどのような位置にあるかによって決まる．
幾何学的には，線分 $BF$ 上の点 $M$ における，**点 $F$ からの距離と点 $B$ からの距離の比**として求められる．

## 解説

本問題は，van der Waals 方程式のような「不安定な領域（圧力が増すと体積が増える領域）」を持つ状態方程式において，物理的に安定な「相転移（液相から気相への変化）」がどのように決定されるかを問うている．

1.  **Maxwell の規則の物理的意味**: 
    単に圧力が等しい（水平線である）だけでは不十分で，系の自由エネルギーが最小化される必要がある．
    等温線の「山」と「谷」の面積が等しくなるように水平線を引くことは，液相の状態と気相の状態の自由エネルギーが一致すること，つまり両者が平衡状態にあることを保証している．
    
2.  **相の割合（レバー・ルール）**:
    混合物において，ある成分の割合を求める際，体積（またはモル数）の加成性を用いる．
    これは「レバー・ルール（てこの原理）」と呼ばれ，混合状態の性質は，両端の純粋な相の性質を，それぞれの割合で重み付けした平均として表される．

3.  **熱力学的安定性**:
    問題文にある「不安定な領域」とは， $\left(\frac{\partial p}{\partial V}\right)_T > 0$ となる領域であり，通常の物質ではありえない（圧力をかけると体積が増える）状態である．
    自然界では，系は自由エネルギーがより低い，等面積条件を満たす水平線上の状態（相分離した状態）へと移行する．
