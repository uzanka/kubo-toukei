# 演習問題【4-R-1】

## 解答

### 1．2相共存の圧力を決定する条件

van der Waals の状態方程式による等温線は，臨界温度以下では谷と山をもつ S 字型の曲線となる．
以下，その等温線に水平線を引いたときの3つの交点を，左から B，D，F とする．B は液相側，F は気相側に対応し，D は不安定な部分にある交点である．

2相が平衡にあるためには，次の2つの条件を満たす必要がある．

1. 液相と気相の圧力が等しいこと．
2. 液相と気相の化学ポテンシャルが等しいこと．

圧力を $p_{\mathrm{coex}}$ ，液相と気相のモル Gibbs 自由エネルギーをそれぞれ $\overline G_B$ ， $\overline G_F$ とすると，平衡条件は

```math
p_B=p_F=p_{\mathrm{coex}}
```

および

```math
\boxed{
\overline G_B=\overline G_F
}
\tag{1}
```

である．
ここで，純物質について1 mol 当たりの Gibbs 自由エネルギーは化学ポテンシャルに等しい．

### 2．Gibbs 自由エネルギーから等面積則を導く

一定温度でのモル Gibbs 自由エネルギーの微分は，

```math
d\overline G=\overline V\,dp
\tag{2}
```

である．
したがって，形式的に等温線に沿って積分すると，

```math
\overline G(D)-\overline G(F) =\int_{F\to D}\overline V\,dp
\tag{3}
```

および

```math
\overline G(D)-\overline G(B) =\int_{B\to D}\overline V\,dp
\tag{4}
```

となる．
ここでの積分は，単に端点の圧力の間で行う積分ではなく，それぞれ F から D，B から D までの等温線に沿った経路積分である．

水平線の圧力を $p_{\mathrm{coex}}$ とする．
式（3），（4）に部分積分を用い，始点と終点の圧力がともに $p_{\mathrm{coex}}$ であることを利用すると，

```math
\overline G(D)-\overline G(F) =\int_{\overline V_D}^{\overline V_F} [p(\overline V)-p_{\mathrm{coex}}]\,d\overline V
\tag{5}
```

となる．
右辺は，等温線と水平線に挟まれた，D と F の間の面積を表す．
この面積を $A_{\mathrm{upper}}$ とする．
同様に，

```math
\overline G(D)-\overline G(B) =\int_{\overline V_B}^{\overline V_D} [p_{\mathrm{coex}}-p(\overline V)]\,d\overline V
\tag{6}
```

となり，右辺は B と D の間の面積を表す．
これを $A_{\mathrm{lower}}$ とする．

式（5），（6）を組み合わせると，

```math
\begin{aligned}
\overline G(B)-\overline G(F) &=[\overline G(D)-\overline G(F)]\\
&\quad-[\overline G(D)-\overline G(B)]\\
&=A_{\mathrm{upper}}-A_{\mathrm{lower}}
\end{aligned}
\tag{7}
```

を得る．

2相平衡では式（1）より $\overline G(B)=\overline G(F)$ であるから，

```math
\boxed{
A_{\mathrm{upper}}=A_{\mathrm{lower}}
}
\tag{8}
```

となる．
すなわち，等温線の山側と谷側で，水平線と等温線に挟まれた2つの面積が等しくなるように水平線を引けばよい．
この条件が Maxwell の等面積則であり，その水平線の圧力が2相共存圧力，すなわち飽和蒸気圧 $p_{\mathrm{coex}}$ となる．

等面積則は，圧力が等しいという条件だけでは決まらない2相共存圧力を，液相と気相の Gibbs 自由エネルギーが等しいという条件によって選び出すものである．

### 3．共存する液相と気相の割合を求める

次に，共存圧力 $p_{\mathrm{coex}}$ において，液相と気相が混在している状態を考える．
液相のモル体積を $\overline V_B$ ，気相のモル体積を $\overline V_F$ とする．
全物質量を $n\ \mathrm{mol}$ ，そのうち液相に存在する物質量を $nx\ \mathrm{mol}$ とすれば，気相に存在する物質量は $n(1-x)\ \mathrm{mol}$ である．

液相と気相の体積は加算できるため，全体の平均モル体積を $\overline V_M$ とすると，

```math
n\overline V_M =nx\overline V_B+n(1-x)\overline V_F
\tag{9}
```

となる．
両辺を $n$ で割ると，

```math
\overline V_M =x\overline V_B+(1-x)\overline V_F
\tag{10}
```

である．
これを整理すると，

```math
\overline V_F-\overline V_M =x(\overline V_F-\overline V_B)
```

を得る．
したがって，液相のモル分率 $x$ は，

```math
\boxed{
x=\frac{\overline V_F-\overline V_M} {\overline V_F-\overline V_B}
}
\tag{11}
```

である．
また，気相の割合は

```math
1-x=\frac{\overline V_M-\overline V_B} {\overline V_F-\overline V_B}
\tag{12}
```

であるから，液相と気相の割合の比は，

```math
\boxed{
\frac{x}{1-x} =\frac{\overline V_F-\overline V_M} {\overline V_M-\overline V_B}
}
\tag{13}
```

となる．

幾何学的には，共存圧力の水平線上において，B と F を結ぶ線分の間に M をとると，

```math
\boxed{
\text{液相}:\text{気相} =FM:MB
}
\tag{14}
```

である．
これはレバー・ルール，すなわち，てこの規則である．
液相の割合が大きいほど M は B に近づき，気相の割合が大きいほど M は F に近づく．

## 4．幾何学的な結論

以上より，求める2相共存状態は次のように決定される．

- 共存圧力：水平線と等温線の間で，山側と谷側の面積が等しくなる圧力 $p_{\mathrm{coex}}$ である．
- 共存する相の割合：その水平線上の液相側の交点 B と気相側の交点 F を結び，全体の平均モル体積に対応する点 M の位置を用いて，液相と気相の比を $FM:MB$ から求める．

なお，導出の途中では，不安定な中間枝 D を含む等温線に対して $d\overline G=\overline V\,dp$ を形式的に適用している．
これは Maxwell の等面積則を導く標準的な説明であるが，不安定な枝を実在する安定な平衡状態とみなしているわけではない．
厳密な熱力学では，安定な自由エネルギーを最小化することによって，液相と気相の共存が選ばれるのである．
