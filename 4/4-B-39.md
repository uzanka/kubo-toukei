# 演習問題【4-B-39】

## 解答

与えられた化学ポテンシャルは，

```math
\begin{aligned}
\bar G_1 ={}&\bar G_1^0 +RT\left[ \ln\phi_1+ \left(1-\frac1r\right)\phi_2 \right]+w\phi_2^2,\\
\bar G_2 ={}&\bar G_2^0 +RT\left[ \ln\phi_2-(r-1)\phi_1 \right]+rw\phi_1^2
\end{aligned}
\tag{1}
```

である．
ここで，成分1は溶媒，成分2は高分子溶質であり， $\bar G_i$ は成分 $i$ の部分モル Gibbs エネルギー，すなわち化学ポテンシャルである．
また，

```math
\phi_1=\frac{N_1}{N_1+rN_2}, \qquad \phi_2=\frac{rN_2}{N_1+rN_2}
\tag{2}
```

であり，

```math
\phi_1+\phi_2=1
\tag{3}
```

が成り立つ．重合度 $r$ は，高分子1分子が占める体積を溶媒分子の体積を単位として表したものである．
以下では，特に断らない限り， $w$ は温度に依存しない定数とする．

## （i）Gibbs–Duhem の関係を満たすことの証明

温度 $T$ と圧力 $p4 が一定のとき，2成分系の Gibbs–Duhem の関係式は

```math
N_1\,d\bar G_1+N_2\,d\bar G_2=0
\tag{4}
```

である．
式（2）から，

```math
\frac{N_1}{N_1+rN_2}=\phi_1, \qquad \frac{N_2}{N_1+rN_2}=\frac{\phi_2}{r}
```

であるため，式（4）は

```math
\boxed{
\phi_1\,d\bar G_1+\frac{\phi_2}{r}\,d\bar G_2=0
}
\tag{5}
```

と同値である．
これが与えられた化学ポテンシャルについて成り立つことを示せばよい．

### 1．化学ポテンシャルを微分する

式（3）より，

```math
d\phi_2=-d\phi_1
```

である．
温度と圧力を一定に保つと，式（1）の純成分の項 $\bar G_i^0(T,p)$ は変化しない．
したがって，溶媒については

```math
\begin{aligned}
d\bar G_1 &=RT\left[ \frac{d\phi_1}{\phi_1} -\left(1-\frac1r\right)d\phi_1 \right]-2w\phi_2\,d\phi_1\\
&=\left[ RT\left(\frac1{\phi_1}-1+\frac1r\right) -2w\phi_2 \right]d\phi_1.
\end{aligned}
\tag{6}
```

一方，溶質については，

```math
\begin{aligned}
d\bar G_2 &=RT\left[ \frac{d\phi_2}{\phi_2} -(r-1)d\phi_1 \right]-2rw\phi_1\,d\phi_1\\
&=\left[ -\frac{RT}{\phi_2} -RT(r-1)+2rw\phi_1 \right]d\phi_1.
\end{aligned} \tag{7}
```

### 2．Gibbs–Duhem の関係式に代入する

式（6），（7）を式（5）の左辺に代入すると，

```math
\begin{aligned}
&\phi_1\,d\bar G_1+\frac{\phi_2}{r}\,d\bar G_2\\
&=\Bigg\{ RT\left(1-\phi_1+\frac{\phi_1}{r}\right) -2w\phi_1\phi_2\\
&\qquad -RT\left[\frac1r+\frac{r-1}{r}\phi_2\right] +2w\phi_1\phi_2 \Bigg\}d\phi_1.
\end{aligned}
\tag{8}
```

相互作用に由来する $w$ の項は，互いに打ち消し合う．
また，

```math
\frac{\phi_1}{r}-\frac1r=-\frac{\phi_2}{r}
```

であるから， $RT$ に比例する項は

```math
RT(1-\phi_1-\phi_2)=0
```

となる．
ここで式（3）を用いた．
よって，

```math
\boxed{
\phi_1\,d\bar G_1+\frac{\phi_2}{r}\,d\bar G_2=0
}
```

が得られる．
したがって，与えられた化学ポテンシャルは Gibbs–Duhem の関係式を満たす．

## （ii）混合エントロピーを理想溶液のそれと比較する

### 1．混合エントロピーを求める

部分モルエントロピーと部分モル Gibbs エネルギーの関係は，

```math
\bar S_i=-\left(\frac{\partial\bar G_i}{\partial T}\right)_{p,\text{組成}}
\tag{9}
```

である．
$w$ が温度に依存しないことを用いると，式（1）から

```math
\begin{aligned}
\bar S_1 &=\bar S_1^0 -R\left[ \ln\phi_1+ \left(1-\frac1r\right)\phi_2 \right],\\
\bar S_2 &=\bar S_2^0 -R\left[ \ln\phi_2-(r-1)\phi_1 \right]
\end{aligned}
\tag{10}
```

を得る．
ここで， $\bar S_i^0$ は純成分の部分モルエントロピーである．

混合によるエントロピー変化は，混合状態のエントロピーから，それぞれの成分が純物質として存在した場合のエントロピーを差し引いたものである．
したがって，

```math
\Delta S_{\mathrm{mix}} =N_1(\bar S_1-\bar S_1^0) +N_2(\bar S_2-\bar S_2^0)
\tag{11}
```

と書ける．
式（10）を代入すると，

```math
\begin{aligned}
\Delta S_{\mathrm{mix}} ={}&-R\left(N_1\ln\phi_1+N_2\ln\phi_2\right)\\
&-R N_1\left(1-\frac1r\right)\phi_2 +R N_2(r-1)\phi_1.
\end{aligned}
\tag{12}
```

ここで，式（2）から

```math
N_1\phi_2=rN_2\phi_1
\tag{13}
```

である．
よって，式（12）の対数以外の項は打ち消し合う．
最終的に，

```math
\boxed{
\Delta S_{\mathrm{mix}} =-R\left(N_1\ln\phi_1+N_2\ln\phi_2\right)
}
\tag{14}
```

となる．
この式には，溶媒と高分子の体積分率が現れることが特徴である．

### 2．理想溶液の混合エントロピーと比較する

実際の溶媒分子と高分子分子をそれぞれ1分子として数えたとき，分子数に基づくモル分率を

```math
x_1=\frac{N_1}{N_1+N_2}, \qquad x_2=\frac{N_2}{N_1+N_2}
\tag{15}
```

と定義する．
このとき，

```math
x_1+x_2=1
```

であり，式（2）を $x_1,x_2$ で表すと，

```math
\phi_1=\frac{x_1}{x_1+rx_2}, \qquad \phi_2=\frac{rx_2}{x_1+rx_2}
\tag{16}
```

となる．
また， $x_1=1-x_2$ より，

```math
x_1+rx_2=1+(r-1)x_2
```

である．
したがって，

```math
\begin{aligned}
\ln\phi_1 &=\ln x_1-\ln[1+(r-1)x_2],\\
\ln\phi_2 &=\ln x_2+\ln r-\ln[1+(r-1)x_2].
\end{aligned}
\tag{17}
```

これらを式（14）に代入すると，

```math
\begin{aligned}
\Delta S_{\mathrm{mix}} ={}&-R(N_1\ln x_1+N_2\ln x_2)\\
&+R(N_1+N_2) \left[ \ln[1+(r-1)x_2]-x_2\ln r \right].
\end{aligned}
\tag{18}
```

通常の理想溶液の混合エントロピーは，

```math
\Delta S_{\mathrm{mix}}^{\mathrm{ideal}} =-R(N_1\ln x_1+N_2\ln x_2)
\tag{19}
```

である．
したがって，両者の差は

```math
\boxed{
\begin{aligned}
\Delta S_{\mathrm{mix}} -\Delta S_{\mathrm{mix}}^{\mathrm{ideal}} =R(N_1+N_2) \left[ \ln(1+(r-1)x_2)-x_2\ln r \right].
\end{aligned}
}
\tag{20}
```

ここで， $r>1$ の場合を考える．対数関数 $\ln y$ は上に凸ではなく凹関数であるため，

```math
\ln[(1-x_2)\cdot1+x_2\cdot r] \geq (1-x_2)\ln1+x_2\ln r
```

が成立する．
右辺は $x_2\ln r$ ，左辺は $\ln[1+(r-1)x_2]$ である．
よって，

```math
\ln[1+(r-1)x_2]-x_2\ln r\geq0
```

であるから，

```math
\boxed{
\Delta S_{\mathrm{mix}} \geq \Delta S_{\mathrm{mix}}^{\mathrm{ideal}} \qquad (r>1)
}
\tag{21}
```

となる．
純成分だけの場合を除けば，不等号は厳密に成立する．

結論： 実際の溶媒分子と高分子分子をそれぞれ1分子として数えた理想溶液と比べると，このモデルの混合エントロピーは $r>1$ で大きい．

ただし，比較対象を「高分子1分子を構成する $r$ 個の単量体がそれぞれ独立に混合する仮想的な低分子系」とした場合は，結果が異なる．
高分子鎖では $r$ 個の単量体がひとつの分子につながっているため，そのような低分子系よりも並進的な混合エントロピーは小さい．
これは比較の基準が異なるためであり，式（21）と矛盾するものではない．

## （iii）混合熱と濃度との関係を調べる

混合熱は，定圧での混合エンタルピー変化として求める．

### 1．混合エンタルピーを求める

エンタルピーと Gibbs エネルギーの関係から，各成分の部分モルエンタルピーは

```math
\bar H_i=\bar G_i+T\bar S_i
\tag{22}
```

である．
式（1）および式（10）を用いると， $RT$ を含む混合項が打ち消し合い，

```math
\begin{aligned}
\bar H_1&=\bar H_1^0+w\phi_2^2,\\
\bar H_2&=\bar H_2^0+rw\phi_1^2
\end{aligned}
\tag{23}
```

となる．
ここで， $\bar H_i^0$ は純成分の部分モルエンタルピーである．

したがって，混合によるエンタルピー変化の総量は

```math
\begin{aligned}
\Delta H\_{\mathrm{mix}} &=N_1(\bar H_1-\bar H_1^0)  +N_2(\bar H_2-\bar H_2^0)\\
&=wN_1\phi_2^2+rwN_2\phi_1^2.
\end{aligned}
\tag{24}
```

式（2）から $N_1=(N_1+rN_2)\phi_1$ ， $rN_2=(N_1+rN_2)\phi_2$ であるため，

```math
\begin{aligned}
\Delta H_{\mathrm{mix}} &=w(N_1+rN_2) \left(\phi_1\phi_2^2+\phi_2\phi_1^2\right)\\
&=w(N_1+rN_2)\phi_1\phi_2(\phi_1+\phi_2).
\end{aligned}
```

ここで $\phi_1+\phi_2=1$ を用いると，

```math
\boxed{
\Delta H_{\mathrm{mix}} =w(N_1+rN_2)\phi_1\phi_2
}
\tag{25}
```

を得る．

### 2．分子数に基づくモル分率 $x_2$ で表す

解答例と同様に，混合エンタルピーを実際の分子数 $N_1+N_2$ で規格化し， $x_2$ の関数として表す．
式（15），（16）より，

```math
\begin{aligned}
\frac{\Delta H_{\mathrm{mix}}}{N_1+N_2} &=w(x_1+rx_2)\phi_1\phi_2\\
&=w\frac{rx_1x_2}{x_1+rx_2}.
\end{aligned}
```

したがって，混合エンタルピーを分子数に基づいて規格化した量は，

```math
\boxed{
\Delta\bar H_{\mathrm{mix}} =\frac{\Delta H_{\mathrm{mix}}}{N_1+N_2} =\frac{rw x_1x_2}{x_1+rx_2}
}
\tag{26}
```

である．
ここで $x_1=1-x_2$ である．

純成分では混合が起こらないため，

```math
\Delta\bar H_{\mathrm{mix}}=0 \qquad (x_2=0,\ 1)
\tag{27}
```

である．
中間濃度における極値を調べるため，

```math
f(x_2)=\frac{r x_2(1-x_2)}{1+(r-1)x_2}
```

とおくと，式（26）は $\Delta\bar H_{\mathrm{mix}}=wf(x_2)$ と表せる．
微分すると，

```math
f'(x_2) =\frac{r[1-2x_2-(r-1)x_2^2]} {[1+(r-1)x_2]^2}.
\tag{28}
```

したがって，極値の条件は

```math
1-2x_2-(r-1)x_2^2=0
```

である．
$0<x_2<1$ の解を求めると，

```math
\boxed{
x_2=\frac{1}{1+\sqrt r}
}
\tag{29}
```

となる．
この濃度では，

```math
\boxed{
\Delta\bar H_{\mathrm{mix}} =\frac{rw}{(1+\sqrt r)^2}
}
\tag{30}
```

である．
よって， $w>0$ であれば式（30）は最大値， $w<0$ であれば最小値である．
$w=0$ ならば混合エンタルピーはすべての濃度でゼロとなる．

### 3．体積分率を使った表し方

式（25）から，格子サイト数に相当する $N_1+rN_2$ で規格化すると，

```math
\boxed{
\frac{\Delta H_{\mathrm{mix}}}{N_1+rN_2} =w\phi_1\phi_2=w\phi_2(1-\phi_2)
}
\tag{31}
```

となる．
こちらは体積分率 $\phi_2$ に関する二次関数であるため， $w>0$ の場合は $\phi_2=1/2$ で最大となり，その値は $w/4$ である．
$w<0$ では同じ濃度で最小となる．

式（29）と式（31）の結果が異なるのは，混合エンタルピーを規格化する量と，濃度を表す変数が異なるためである．

結論： 混合エンタルピーは，溶媒と高分子溶質の相互作用を表す $w$ に比例し，混合組成に応じて変化する．

## （iv）溶媒の蒸気圧および浸透圧と濃度との関係を調べる

### 1．溶媒の蒸気圧

溶液中の溶媒の活動度 $a_1$ は，純溶媒を基準として

```math
\ln a_1=\frac{\bar G_1-\bar G_1^0}{RT}
\tag{32}
```

と定義される．
式（1）から，

```math
\ln a_1 =\ln\phi_1+ \left(1-\frac1r\right)\phi_2 +\frac{w}{RT}\phi_2^2.
\tag{33}
```

したがって，

```math
\boxed{
a_1=\phi_1 \exp\left[ \left(1-\frac1r\right)\phi_2 +\frac{w}{RT}\phi_2^2 \right]
}
\tag{34}
```

となる．

溶液上の溶媒蒸気を理想気体とみなし，溶液上の蒸気圧を $p_1$ ，同じ温度での純溶媒の蒸気圧を $p_1^0$ とする．
このとき，溶媒の化学ポテンシャルと蒸気圧の関係から

```math
\frac{p_1}{p_1^0}=a_1
```

が成り立つ．
よって，

\\[ \boxed{ \frac{p_1}{p_1^0} =(1-\phi_2) \exp\left[ \left(1-\frac1r\right)\phi_2 +\frac{w}{RT}\phi_2^2 \right] } \tag{35} \\]

を得る．
これが蒸気圧と濃度との関係である．

### 2．希薄溶液での蒸気圧の変化

$\phi_2\ll1$ のとき，

```math
\ln(1-\phi_2) =-\phi_2-\frac{\phi_2^2}{2} -\frac{\phi_2^3}{3}-\cdots
\tag{36}
```

である．
式（33）を用いると，

```math
\begin{aligned}
\ln\frac{p_1}{p_1^0} &=\ln(1-\phi_2) +\left(1-\frac1r\right)\phi_2 +\frac{w}{RT}\phi_2^2\\
&=-\frac{\phi_2}{r} +\left(\frac{w}{RT}-\frac12\right)\phi_2^2 -\frac{\phi_2^3}{3}-\cdots.
\end{aligned}
```

したがって，低濃度では，

```math
\boxed{
\ln\frac{p_1}{p_1^0} \simeq-\frac{\phi_2}{r}
}
\tag{37}
```

となる．
さらに一次の近似で指数関数を展開すれば，

```math
\boxed{
\frac{p_1}{p_1^0} \simeq1-\frac{\phi_2}{r}
}
\tag{38}
```

である．

この結果から，同じ体積分率 $\phi_2$ で比較すると，重合度 $r$ が大きいほど，希薄溶液における蒸気圧降下は小さくなることが分かる．
相互作用パラメータ $w$ は二次以降の項に現れ，濃度が高くなるほど蒸気圧への影響が重要になる．

なお，分子数に基づくモル分率 $x_2$ で比較する場合は，希薄極限で $\phi_2\simeq rx_2$ となるため，式（37）は

```math
\ln\frac{p_1}{p_1^0}\simeq-x_2
```

となる．
この場合，蒸気圧降下の一次項は $r$ に依存しない．
濃度の表し方を区別することが重要である．

### 3．浸透圧

浸透圧 $\Pi$ は，半透膜を隔てて純溶媒と溶液を平衡に保つために必要な圧力差である．
溶液側の圧力を純溶媒側より $\Pi$ だけ高くすると，平衡条件は

```math
\bar G_1(T,p+\Pi,\text{溶液}) =\bar G_1^0(T,p,\text{純溶媒})
\tag{39}
```

と書ける．
浸透圧が十分小さく，溶媒の部分モル体積を純溶媒のモル体積 $v_1^0$ で近似できる場合には，

```math
\bar G_1(T,p+\Pi,\text{溶液}) \simeq \bar G_1(T,p,\text{溶液})+v_1^0\Pi
```

である．
したがって，式（39）より，

```math
v_1^0\Pi =-\left(\bar G_1-\bar G_1^0\right)
\tag{40}
```

となる．
式（1）を代入すると，

```math
\boxed{
\Pi =-\frac{RT}{v_1^0} \left[ \ln\phi_1+ \left(1-\frac1r\right)\phi_2 \right] -\frac{w}{v_1^0}\phi_2^2
}
\tag{41}
```

を得る．
$\phi_1=1-\phi_2$ を用いれば，

```math
\boxed{
\Pi =-\frac{RT}{v_1^0} \left[ \ln(1-\phi_2)+ \left(1-\frac1r\right)\phi_2 \right] -\frac{w}{v_1^0}\phi_2^2
}
\tag{42}
```

である．

### 4．希薄溶液での浸透圧

式（36）を用いて式（42）を展開すると，

```math
\begin{aligned}
\Pi &=\frac{RT}{v_1^0} \left[ \frac{\phi_2}{r} +\frac{\phi_2^2}{2} +\frac{\phi_2^3}{3}+\cdots \right] -\frac{w}{v_1^0}\phi_2^2\\
&=\frac{RT}{v_1^0} \left[ \frac{\phi_2}{r} +\left(\frac12-\frac{w}{RT}\right)\phi_2^2 +\frac{\phi_2^3}{3}+\cdots \right].
\end{aligned}
```

したがって，二次までの近似では，

```math
\boxed{
\Pi\simeq \frac{RT}{v_1^0} \left[ \frac{\phi_2}{r} +\left(\frac12-\frac{w}{RT}\right)\phi_2^2 \right]
}
\tag{43}
```

となる．

特に十分に希薄な極限では，一次項が支配的であるから，

```math
\boxed{
\Pi\simeq\frac{RT}{rv_1^0}\phi_2
}
\tag{44}
```

である．
溶液の体積を $V\simeq v_1^0(N_1+rN_2)$ と近似すると，高分子分子の濃度 $c_2=N_2/V$ は

```math
c_2\simeq\frac{\phi_2}{rv_1^0}
```

と表せる．
これを式（44）に代入すれば，

```math
\boxed{
\Pi\simeq c_2RT
}
\tag{45}
```

が得られる．
これは希薄溶液に対する van’t Hoff の浸透圧の法則である．

二次項には相互作用パラメータ $w$ が現れる．
$w<RT/2$ であれば二次の係数は正であり， $w>RT/2$ では負となる．
したがって，相互作用は浸透圧の濃度依存性を変化させる．
ただし，この係数の符号だけから，任意の濃度範囲における溶液の安定性まで判断することはできない．

## 3．最終結果のまとめ

| 設問 | 主な結果 |
| ---- | -------- |
| (i) Gibbs–Duhem の関係 | $\displaystyle \phi_1\,d\bar G_1+\frac{\phi_2}{r}\,d\bar G_2=0$                                                    |
| (ii) 混合エントロピー | $\displaystyle \Delta S_{\mathrm{mix}}=-R(N_1\ln\phi_1+N_2\ln\phi_2)$ |
| (ii) 理想溶液との比較 | $r>1$ では，実際の分子数に基づく理想溶液より混合エントロピーが大きい |
| (iii) 混合エンタルピー | $\displaystyle \Delta H_{\mathrm{mix}}=w(N_1+rN_2)\phi_1\phi_2$ |
| (iii) 分子数基準の極値 | $\displaystyle x_2=1/(1+\sqrt r)$ |
| (iv) 蒸気圧            | $\displaystyle \frac{p_1}{p_1^0}=(1-\phi_2)\exp\left[\left(1-\frac1r\right)\phi_2+\frac{w}{RT}\phi_2^2\right]$ |
| (iv) 浸透圧            | $\displaystyle \Pi=-\frac{RT}{v_1^0}\left[\ln(1-\phi_2)+\left(1-\frac1r\right)\phi_2\right]-\frac{w}{v_1^0}\phi_2^2$ |

以上より，高分子溶液では，重合度 $r$ が混合エントロピーや浸透圧の濃度依存性に影響し，相互作用パラメータ $w$ が混合エンタルピー，蒸気圧，浸透圧の非理想性を表すことが分かる．
