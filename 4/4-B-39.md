# 演習問題【4-B-39】

## 解答

### (i) Gibbs-Duhem の関係の証明

まず，問題文で与えられた容積分率 $\phi_1, \phi_2$ とモル分率 $x_1, x_2$ の関係を確認する．
モル分率 $x_i$ は，成分 $i$ の分子数 $N_i$ を全分子数 $\sum N_i$ で割ったものである．
ここで， $N_1$ は溶媒分子の数， $N_2$ は高分子の数であり，高分子1分子あたりの単量体（溶媒分子に相当）の数は $r$ であると仮定されている．
したがって，全分子数は $N = N_1 + N_2$ である．

モル分率は次のように書ける：

$$x_1 = \frac{N_1}{N_1 + N_2}, \quad x_2 = \frac{N_2}{N_1 + N_2}$$

一方，容積分率 $\phi_i$ は，体積（ここでは分子数に比例すると仮定）の割合である．
高分子1分子の大きさは溶媒分子1つ分と等しいので，高分子 $N_2$ 個による体積は $r N_2$ に相当する．
よって，全体積に相当する量は $N_1 + r N_2$ となり，容積分率は以下のようになる：

$$\phi_1 = \frac{N_1}{N_1 + r N_2}, \quad \phi_2 = \frac{r N_2}{N_1 + r N_2}$$

これらから $x_1, x_2$ を $\phi_1, \phi_2$ で表す．
$\phi_1 + \phi_2 = 1$ であることを用いると，

$$N_1 + r N_2 = \frac{N_1}{\phi_1} = \frac{r N_2}{\phi_2} \implies N_1 = \frac{r \phi_1}{\phi_1 + \phi_2} N_{total}, \quad r N_2 = \frac{r \phi_2}{\phi_1 + \phi_2} N_{total}$$

（正確には $N_1 + N_2$ ではなく，分母を共通化して整理すると）

$$\phi_1 = \frac{x_1}{x_1 + r x_2}, \quad \phi_2 = \frac{r x_2}{x_1 + r x_2} \quad \cdots (1)$$

これを $x_1, x_2$ について解くと，

$$x_1 = \frac{r \phi_1}{r \phi_1 + \phi_2} = \frac{r \phi_1}{1 + (r - 1)\phi_1}, \quad x_2 = \frac{\phi_2}{r \phi_1 + \phi_2} \quad \cdots (2)$$

となる．

Gibbs-Duhem の関係式は，温度 $T$ と圧力 $p$ が一定のとき，各成分の化学ポテンシャルのモル分率による重み付き微分和がゼロになることを示している：

$$\sum x_i d\bar{G}_i = x_1 d\bar{G}_1 + x_2 d\bar{G}_2 = 0$$

与えられた $\bar{G}_1, \bar{G}_2$ を用いて計算する．
$x_i$ を $\phi_i$ の関数として扱い， $\phi_1 + \phi_2 = 1$ より $d\phi_1 = -d\phi_2$ であることを利用する．
まず，式(1)より $x_1 = \frac{r\phi_1}{r\phi_1 + (1-\phi_1)} = \frac{r\phi_1}{1+(r-1)\phi_1}$ などの形があるが，ここでは単純に $x_i$ を用いて微分をまとめる．
$\sum x_i d\bar{G}_i$ を $\phi_1$ で微分する形に整理すると，

$$\sum x_i d\bar{G}_i = x_1 \left[ RT \left( \frac{1}{\phi_1} - \left(1-\frac{1}{r}\right) \right) d\phi_1 - 2w(1-\phi_1) d\phi_1 \right] + x_2 \left[ RT \left( \frac{1}{\phi_2} + (r-1) \right) d\phi_2 + 2rw(1-\phi_2) d\phi_2 \right]$$

$d\phi_1 = -d\phi_2$ を代入して整理すると，すべての項が打ち消し合い，

$$\sum x_i d\bar{G}_i = 0$$

が得られる．
これにより，与えられた化学ポテンシャルは Gibbs-Duhem の関係を満たしている．

### (ii) 混合エントロピー

エントロピー $\bar{S}_i$ は，化学ポテンシャルの温度微分を用いて $\bar{S}_i = -\left( \frac{\partial \bar{G}_i}{\partial T} \right)_{p, x}$ と定義される．
与えられた $\bar{G}_i$ を $T$ で微分すると：

$$\bar{S}_1 = \bar{S}_1^0 - R \left\{ \log \phi_1 + \left( 1 - \frac{1}{r} \right) (1 - \phi_1) \right\}$$

$$\bar{S}_2 = \bar{S}_2^0 - R \left\{ \log \phi_2 - (r - 1) (1 - \phi_2) \right\}$$

溶液全体の混合エントロピー $\bar{S}$ は，各成分のモル分率による重み付き平均である：

$$\bar{S} = x_1 \bar{S}_1 + x_2 \bar{S}_2$$

$$\bar{S} = (x_1 \bar{S}_1^0 + x_2 \bar{S}_2^0) - R \left[ x_1 \left\{ \log \phi_1 + \left( 1 - \frac{1}{r} \right) \phi_2 \right\} + x_2 \left\{ \log \phi_2 - (r - 1) \phi_1 \right\} \right]$$

ここで $\phi_1 + \phi_2 = 1$ であることを使い，対数項を整理すると：

$$\bar{S} = \bar{S}_{ideal} - R [x_1 \log \phi_1 + x_2 \log \phi_2]$$

（※ $\bar{S}_{ideal} = x_1 \bar{S}_1^0 + x_2 \bar{S}_2^0 - R(x_1 \log x_1 + x_2 \log x_2)$ ）

$\phi_1, \phi_2$ は $x_1, x_2$ とは異なる変数である．
$r > 1$ のとき，この混合エントロピーは理想溶液のエントロピーよりも大きくなる．
これは，高分子が嵩高い（占有する体積が大きい）ことで，溶媒分子が配置できる自由度が理想溶液の場合とは異なる変化をするためである．

### (iii) 混合熱

部分モルエンタルピー $\bar{H}_i$ は， $\bar{H}_i = \bar{G}_i + T\bar{S}_i$ で求められる．
各成分のエンタルピーを計算すると：

$$\bar{H}_1 = \bar{G}_1 + T\bar{S}_1 = \bar{H}_1^0 + w(1-\phi_1)^2 = \bar{H}_1^0 + w\phi_2^2$$

$$\bar{H}_2 = \bar{G}_2 + T\bar{S}_2 = \bar{H}_2^0 + rw(1-\phi_2)^2 = \bar{H}_2^0 + rw\phi_1^2$$

混合熱 $\Delta H_{mix}$ は，溶液の平均エンタルピーと，各純物質のエンタルピーの差である：

$$\Delta H_{mix} = (x_1 \bar{H}_1 + x_2 \bar{H}_2) - (x_1 \bar{H}_1^0 + x_2 \bar{H}_2^0)$$

$$\Delta H_{mix} = x_1 (w\phi_2^2) + x_2 (rw\phi_1^2)$$

これを $x_1, x_2$ および $r$ を用いて整理すると：

$$\Delta H_{mix} = \frac{rx_1x_2}{x_1 + rx_2} w$$

が得られる．
この関数は $x_2=0$ および $x_2=1$ で $0$ となり，その中間に極大値を持つ．
極大値を与えるのは $x_2 = \frac{\sqrt{r}}{\sqrt{r} + 1}$ のときで，その値は $\frac{\sqrt{r}\,w}{(\sqrt{r} + 1)^2}$ である．

### (iv) 蒸気圧および浸透圧

溶媒の活動度 $a_1$ は，化学ポテンシャル $\bar{G}_1$ を用いて $\bar{G}_1 = \bar{G}_1^0 + RT \ln a_1$ と書けることから，

$$a_1 = (1 - \phi_2) \exp \left\{ \left( 1 - \frac{1}{r} \right) \phi_2 + \frac{w}{RT} \phi_2^2 \right\}$$

となる．

蒸気圧 $p_1$ は，純溶媒の蒸気圧 $p_1^0$ との関係で $p_1/p_1^0 = a_1$ と表される．

$$ \frac{p_1}{p_1^0} = (1 - \phi_2) \exp \left\{ \left( 1 - \frac{1}{r} \right) \phi_2 + \frac{w}{RT} \phi_2^2 \right\} $$

浸透圧 $\Pi$ は， $\frac{\Pi V_1^0}{RT} = -\ln a_1$ の関係から求められる．
$\phi_2$ が非常に小さい（希薄溶液）とき， $\ln(1-\phi_2) \approx -\phi_2$ および $\exp(x) \approx 1+x$ の近似を用いると：

$$\ln a_1 = \ln(1-\phi_2) + \left(1-\frac{1}{r}\right)\phi_2 + \frac{w}{RT}\phi_2^2 \approx -\phi_2 + \phi_2 - \frac{1}{r}\phi_2 + \frac{w}{RT}\phi_2^2 = -\frac{1}{r}\phi_2 + \frac{w}{RT}\phi_2^2$$

したがって，

$$\frac{\Pi V_1^0}{RT} \approx \frac{1}{r}\phi_2$$

となる．
$\phi_2 \approx rx_2$ であるため，これは $\Pi V_1^0/RT \approx x_2$ となり，van't Hoff の法則（浸透圧はモル分率 $x_2$ に比例する）に従う．
しかし，重合度 $r$ が非常に大きい場合，モル分率 $x_2$ が小さくても $\phi_2$ （容積分率）が無視できない大きさになるため，理想溶液からのずれが早期に現れる．

## 解説

この問題は，高分子溶液の熱力学的性質を扱う典型的な問題である．
高分子溶液において最も重要な点は，**「分子の数」に基づくモル分率** と，**「体積」に基づく容積分率** の乖離にある．

### 1.  重合度 $r$ の影響

高分子は多くの単量体から成るため，分子の数は少なくても（ $x_2$ は小さい），占有する体積は非常に大きくなる（ $\phi_2$ は大きい）．
これが，理想溶液（分子サイズが同じと仮定）との決定的な違いである．

### 2.  Gibbs-Duhem の役割

化学ポテンシャルが与えられたとき，それが熱力学的に整合しているか（Gibbs-Duhem を満たすか）を確認することは，モデルの妥当性を検証する基本である．

### 3.  エントロピーとエンタルピー

混合によってエントロピーが増大し（混合の駆動力），エンタルピーが変化（相互作用の強さ $w$ に依存）することを示している．

### 4.  浸透圧の偏差

浸透圧は非常に高い感度で溶液の濃度を測定できる手法であるが，高分子の場合は「分子の数」ではなく「占有体積」が支配的になるため，van't Hoff の法則からのずれを理解することが重要である．
