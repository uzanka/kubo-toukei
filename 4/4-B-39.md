# 演習問題【4-B-39】

## 解答

与えられた化学ポテンシャルは、高分子溶液に対する Flory–Huggins 型の式である．
溶媒を成分 1，高分子溶質を成分 2 とし，

```math
\phi_1=\frac{N_1}{N_1+rN_2},\qquad
\phi_2=\frac{rN_2}{N_1+rN_2}
```

とおく．
したがって， $\phi_1+\phi_2=1$ である．
また， $r$ は高分子 1 分子を構成する単量体の数， $w$ は相互作用に由来するエネルギーの次元をもつ定数とする．

与えられた化学ポテンシャルは

```math
\begin{aligned}
\bar G_1
&=\bar G_1^0
+RT\left[
\ln\phi_1+
\left(1-\frac1r\right)\phi_2
\right]+w\phi_2^2,\\[4pt]
\bar G_2
&=\bar G_2^0
+RT\left[
\ln\phi_2-(r-1)\phi_1
\right]+rw\phi_1^2.
\end{aligned}
```

ここで， $\bar G_i^0=\bar G_i^0(T,p)$ は純成分の化学ポテンシャルである．


## (i) Gibbs–Duhem の関係を満たすことの証明

一定温度・一定圧力では、Gibbs–Duhem の関係は

```math
N_1\,d\bar G_1+N_2\,d\bar G_2=0
```

である．
$N_1/(N_1+rN_2)=\phi_1$ ， $N_2/(N_1+rN_2)=\phi_2/r$ より，これは

```math
\phi_1\,d\bar G_1+\frac{\phi_2}{r}\,d\bar G_2=0
```

と同値である．

### 1. 各化学ポテンシャルを微分する

温度と圧力を一定に保ち， $\phi_2=1-\phi_1$ を用いる．

溶媒について，

```math
\begin{aligned}
d\bar G_1
&=RT\left[
\frac{d\phi_1}{\phi_1}
-\left(1-\frac1r\right)d\phi_1
\right]-2w\phi_2\,d\phi_1\\
&=\left[
RT\left(\frac1{\phi_1}-1+\frac1r\right)
-2w\phi_2
\right]d\phi_1.
\end{aligned}
```

溶質については $d\phi_2=-d\phi_1$ なので，

```math
\begin{aligned}
d\bar G_2
&=RT\left[
\frac{d\phi_2}{\phi_2}
+(r-1)d\phi_2
\right]-2rw\phi_1\,d\phi_2\\
&=\left[
-\frac{RT}{\phi_2}-RT(r-1)+2rw\phi_1
\right]d\phi_1.
\end{aligned}
```

### 2. Gibbs–Duhem の関係に代入する

これらを左辺に代入すると，

```math
\begin{aligned}
&\phi_1d\bar G_1+\frac{\phi_2}{r}d\bar G_2\\
&=\Bigg\{
RT\left[1-\phi_1+\frac{\phi_1}{r}\right]
-2w\phi_1\phi_2\\
&\qquad
-RT\left[\frac1r+\frac{(r-1)\phi_2}{r}\right]
+2w\phi_1\phi_2
\Bigg\}d\phi_1.
\end{aligned}
```

相互作用項は相殺する．
また， $\phi_2=1-\phi_1$ を使えば， $RT$ に比例する項も相殺する．
よって，

```math
\boxed{
\phi_1d\bar G_1+\frac{\phi_2}{r}d\bar G_2=0
}
```

となる．
したがって，与えられた化学ポテンシャルは Gibbs–Duhem の関係を満たす．


## (ii) 混合エントロピーを理想溶液と比較する

### 1. 混合 Gibbs エネルギーを求める

混合による Gibbs エネルギー変化を $\Delta G_{\mathrm{mix}}$ とする．
Euler の関係より，

```math
\Delta G_{\mathrm{mix}}
=N_1(\bar G_1-\bar G_1^0)
+N_2(\bar G_2-\bar G_2^0).
```

与えられた式を代入すると，

```math
\begin{aligned}
\Delta G_{\mathrm{mix}}
={}&RT\left[
N_1\ln\phi_1+N_2\ln\phi_2
\right]\\
&+RTN_1\left(1-\frac1r\right)\phi_2
-RTN_2(r-1)\phi_1\\
&+wN_1\phi_2^2+rwN_2\phi_1^2.
\end{aligned}
```

ここで，

```math
N_1\phi_2=rN_2\phi_1
```

なので，線形の交差項は相殺する．
また，

```math
N_1\phi_2^2+rN_2\phi_1^2
=(N_1+rN_2)\phi_1\phi_2
```

である．
したがって，

```math
\boxed{
\Delta G_{\mathrm{mix}}
=RT(N_1\ln\phi_1+N_2\ln\phi_2)
+w(N_1+rN_2)\phi_1\phi_2
}
```

となる．

### 2. 混合エントロピーを求める

混合エントロピーは，

```math
\Delta S_{\mathrm{mix}}
=-\left(
\frac{\partial\Delta G_{\mathrm{mix}}}{\partial T}
\right)_{p,N_1,N_2}
```

で与えられる．
$w$ が温度に依存しないと仮定すれば，

```math
\boxed{
\Delta S_{\mathrm{mix}}
=-R(N_1\ln\phi_1+N_2\ln\phi_2)
}
```

である．

### 3. 理想溶液との比較

通常の理想溶液では，分子数に基づくモル分率

```math
x_1=\frac{N_1}{N_1+N_2},\qquad
x_2=\frac{N_2}{N_1+N_2}
```

を用いて，

```math
\Delta S_{\mathrm{mix}}^{\mathrm{ideal}}
=-R(N_1\ln x_1+N_2\ln x_2)
```

と表される．

一方，高分子溶液では，

```math
\phi_1=\frac{N_1}{N_1+rN_2},\qquad
\phi_2=\frac{rN_2}{N_1+rN_2}
```

である．
高分子 1 分子は $r$ 個の単量体に相当する体積を占めるため，体積分率と分子数に基づくモル分率は一致しない．

したがって，混合エントロピーは一般に理想溶液の式とは異なる．
特に $r>1$ の高分子では，同じ単量体体積をもつ小分子溶質と比較すると，高分子の並進的な混合エントロピーは小さくなる．

**結論：**

```math
\boxed{
\Delta S_{\mathrm{mix}}
=-R(N_1\ln\phi_1+N_2\ln\phi_2)
}
```

高分子溶液では，溶質の分子数が少ないため，低分子溶質の場合に比べて混合エントロピーの増加が抑えられる．


## (iii) 混合熱と濃度との関係

### 1. 混合エンタルピーを求める

混合エンタルピーは，

```math
\Delta H_{\mathrm{mix}}
=\Delta G_{\mathrm{mix}}+T\Delta S_{\mathrm{mix}}
```

から求められる．
(ii) の結果を代入すると，エントロピーに由来する対数項は相殺し，

```math
\boxed{
\Delta H_{\mathrm{mix}}
=w(N_1+rN_2)\phi_1\phi_2
}
```

となる．
ただし，これは $w$ が温度に依存しない場合である．
温度依存性がある場合には，

```math
\Delta H_{\mathrm{mix}}
=(N_1+rN_2)\phi_1\phi_2
\left(w-T\frac{dw}{dT}\right)
```

となる．

### 2. 濃度との関係を調べる

全体の体積に相当する格子サイト数を $N=N_1+rN_2$ とおけば，

```math
\boxed{
\frac{\Delta H_{\mathrm{mix}}}{N}
=w\phi_1\phi_2=w\phi_2(1-\phi_2)
}
```

である．
これは濃度 $\phi_2$ に関する二次関数である．

- \(w>0\)：混合は吸熱的で、混合熱は中間濃度で最大になる．
- \(w<0\)：混合は発熱的で、中間濃度で混合熱が最も負になる．
- \(w=0\)：混合熱はゼロである．

最大値または最小値は $\phi_1=\phi_2=1/2$ のときに生じ，その値は

```math
\left(\frac{\Delta H_{\mathrm{mix}}}{N}\right)_{\phi_2=1/2}
=\frac{w}{4}
```

である．

**結論：** 混合熱は溶媒と溶質の接触に比例し， $\phi_1\phi_2$ に従って変化する．


## (iv) 溶媒の蒸気圧および浸透圧と濃度との関係

### 1. 溶媒の蒸気圧

溶液中の溶媒の化学ポテンシャルは，

```math
\bar G_1
=\bar G_1^0+
RT\left[
\ln\phi_1+
\left(1-\frac1r\right)\phi_2
\right]+w\phi_2^2
```

である．
溶媒蒸気を理想気体とみなすと，純溶媒の蒸気圧を $p_1^0$ ，溶液上の溶媒蒸気圧を $p_1$ として，

```math
\bar G_1-\bar G_1^0
=RT\ln\frac{p_1}{p_1^0}
```

と書ける．
これを与式と比較すると，

```math
\ln\frac{p_1}{p_1^0}
=\ln\phi_1+
\left(1-\frac1r\right)\phi_2
+\frac{w}{RT}\phi_2^2.
```

したがって，

```math
\boxed{
\frac{p_1}{p_1^0}
=\phi_1\exp\left[
\left(1-\frac1r\right)\phi_2
+\frac{w}{RT}\phi_2^2
\right]
}
```

が得られる．
$\phi_1=1-\phi_2$ を使えば，

```math
\boxed{
p_1=p_1^0(1-\phi_2)
\exp\left[
\left(1-\frac1r\right)\phi_2
+\frac{w}{RT}\phi_2^2
\right]
}
```

である．

#### 濃度依存性

- **低濃度極限：** $\phi_2\to0$ では $p_1\to p_1^0$ となる．
- **高分子の重合度が大きい場合：** $r\gg1$ では $1-1/r\simeq1$ となる．
- **相互作用の影響：** $w$ は指数項を通じて蒸気圧に影響する．蒸気圧の変化全体は、体積分率の対数項を含むすべての項によって決まる．

特に希薄溶液では， $\phi_2\ll1$ として展開すると，

```math
\begin{aligned}
\ln\frac{p_1}{p_1^0}
&=\ln(1-\phi_2)
+\left(1-\frac1r\right)\phi_2
+\frac{w}{RT}\phi_2^2\\
&\simeq-\frac{\phi_2}{r}
+\left(\frac{w}{RT}-\frac12\right)\phi_2^2.
\end{aligned}
```

したがって，一次近似では

```math
\boxed{
\ln\frac{p_1}{p_1^0}\simeq-\frac{\phi_2}{r}
}
```

となる．
高分子の重合度が大きいほど，希薄溶液における蒸気圧降下は体積分率に対して小さくなる．

### 2. 浸透圧

浸透圧 $\Pi$ は，半透膜を隔てて純溶媒と溶液が平衡にあるときに必要な圧力差である．
溶媒の部分モル体積を $v_1$ とし，圧力による化学ポテンシャルの変化を

```math
d\bar G_1^0=v_1\,dp
```

で近似する．
浸透圧の平衡条件より，

```math
v_1\Pi
=-RT\left[
\ln\phi_1+
\left(1-\frac1r\right)\phi_2
\right]-w\phi_2^2.
```

よって，浸透圧は

```math
\boxed{
\Pi
=-\frac{RT}{v_1}
\left[
\ln\phi_1+
\left(1-\frac1r\right)\phi_2
\right]
-\frac{w}{v_1}\phi_2^2
}
```

となる．
$\phi_1=1-\phi_2$ を代入すると，

```math
\boxed{
\Pi
=-\frac{RT}{v_1}
\left[
\ln(1-\phi_2)+
\left(1-\frac1r\right)\phi_2
\right]
-\frac{w}{v_1}\phi_2^2
}
```

である．

#### 希薄溶液での近似

$\phi_2\ll1$ では，

```math
\ln(1-\phi_2)
=-\phi_2-\frac{\phi_2^2}{2}
-\frac{\phi_2^3}{3}-\cdots
```

なので，

```math
\begin{aligned}
\Pi
&=\frac{RT}{v_1}
\left[
\frac{\phi_2}{r}+\frac{\phi_2^2}{2}
+\frac{\phi_2^3}{3}+\cdots
\right]
-\frac{w}{v_1}\phi_2^2\\
&=\frac{RT}{v_1}
\left[
\frac{\phi_2}{r}
+\left(\frac12-\frac{w}{RT}\right)\phi_2^2
+\frac{\phi_2^3}{3}+\cdots
\right].
\end{aligned}
```

したがって，二次までの近似は

```math
\boxed{
\Pi\simeq
\frac{RT}{v_1}
\left[
\frac{\phi_2}{r}
+\left(\frac12-\frac{w}{RT}\right)\phi_2^2
\right]
}
```

となる．
特に，十分に希薄な極限では一次項が支配的であり，

```math
\boxed{
\Pi\simeq\frac{RT}{rv_1}\phi_2
}
```

である．
高分子の分子数濃度は，希薄溶液で $c_2=N_2/V\simeq\phi_2/(rv_1)$ なので，

```math
\boxed{\Pi\simeq c_2RT}
```

が得られる．
これは希薄溶液における van't Hoff の浸透圧の式である．

二次項には相互作用パラメータ $w$ が現れる．
$w$ が小さい場合には正の二次補正が生じ， $w$ が十分に大きい場合には相互作用によって浸透圧の増加が抑制される．


## 最終結果のまとめ

| 設問 | 主要な結果 |
|---|---|
| (i) Gibbs–Duhem の関係 | $\displaystyle \phi_1d\bar G_1+\frac{\phi_2}{r}d\bar G_2=0$ |
| (ii) 混合エントロピー | $\displaystyle \Delta S_{\mathrm{mix}}=-R(N_1\ln\phi_1+N_2\ln\phi_2)$（ $w$ 一定） |
| (iii) 混合熱 | $\displaystyle \Delta H_{\mathrm{mix}}=w(N_1+rN_2)\phi_1\phi_2$（ $w$ 一定） |
| (iv) 蒸気圧 | $\displaystyle \frac{p_1}{p_1^0}=\phi_1\exp\left[(1-1/r)\phi_2+\frac{w}{RT}\phi_2^2\right]$ |
| (iv) 浸透圧 | $\displaystyle \Pi=-\frac{RT}{v_1}\left[\ln\phi_1+(1-1/r)\phi_2\right]-\frac{w}{v_1}\phi_2^2$ |

以上より，高分子溶液では重合度 $r$ が混合エントロピーや浸透圧の濃度依存性に大きく影響し，相互作用パラメータ $w$ が混合熱，蒸気圧，浸透圧の非理想性を決定することがわかる．
