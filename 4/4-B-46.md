# 演習問題【4-B-46】

## 解答

### 1．化学平衡と Gibbs 自由エネルギー

次の化学反応を考える．

```math
aA+bB+\cdots
\rightleftharpoons
lL+mM+\cdots
\tag{1}
```

反応物の化学量論係数を負，生成物の化学量論係数を正と定め，成分 $k$ の係数を $\nu_k$ とする．
このとき，反応は

```math
\sum_k\nu_k X_k=0
\tag{2}
```

と表される．

以下では，独立な化学反応が一つである閉鎖系を考える．
系の元素総量は保存され，反応以外による物質の出入りはないものとする．
また，系は単一の均一相にあり，相転移を伴わず，各熱力学量が必要な範囲で微分可能であるとする．

反応の進みを表す反応進行度を $\xi$ とすると，各成分の物質量 $n_k$ は，

```math
n_k=n_{k,0}+\nu_k\xi
```

に従って変化する．
したがって，

```math
dn_k=\nu_k\,d\xi
\tag{3}
```

である．
ここで， $\xi$ はすべての成分の物質量が非負となる許容範囲内にあるものとする．

成分 $k$ の化学ポテンシャルを $\mu_k$ ，部分モルエントロピーを $\bar S_k$ ，部分モルエンタルピーを $\bar H_k$ ，部分モル体積を $\bar V_k$ とする．

系の Gibbs 自由エネルギーを $G$ とすると，その基本関係は，

```math
dG=-S\,dT+V\,dp+\sum_k\mu_k\,dn_k
```

である．

定温・定圧条件のもとでは，

```math
dG=\sum_k\mu_k\,dn_k
```

となる．
式 (3) を代入すると，

```math
dG=\sum_k\nu_k\mu_k\,d\xi
```

を得る．
したがって，

```math
\left(\frac{\partial G}{\partial\xi}\right)_{T,p}
=
\sum_k\nu_k\mu_k
\equiv\Delta_{\mathrm r}G
\tag{4}
```

である．
ここで， $\Delta_{\mathrm r}G$ は正方向の反応に伴う反応 Gibbs エネルギーである．

平衡状態では，Gibbs 自由エネルギーが反応進行度について極小となる．
平衡点 $\xi_{\mathrm{eq}}$ が許容範囲の内部にある場合，極値の必要条件から，

```math
\boxed{\Delta_{\mathrm r}G=0}
\tag{5}
```

が成立する．

また，二回微分可能な関数が内点で極小となるための二階微分の必要条件は，

```math
\left(\frac{\partial^2G}{\partial\xi^2}\right)_{T,p}
\geq0
```

である．
ただし，二階微分がゼロであっても厳密な極小点となる場合があるため，正値であることは一般的な必要条件ではない．

以下では，平衡点が非退化な安定極小点であることを仮定し，

```math
\boxed{
\left(\frac{\partial^2G}{\partial\xi^2}\right)_{T,p}>0
}
\tag{6}
```

とする．
この条件は，後で平衡反応進行度の微分を求める際に必要となる．

式 (4) より，

```math
\left(\frac{\partial\Delta_{\mathrm r}G}{\partial\xi}\right)_{T,p}
=
\left(\frac{\partial^2G}{\partial\xi^2}\right)_{T,p}
```

であるから，

```math
\left(\frac{\partial\Delta_{\mathrm r}G}{\partial\xi}\right)_{T,p}>0
\tag{7}
```

となる．

この条件のもとでは，陰関数定理により，平衡条件 $\Delta_{\mathrm r}G=0$ を満たす平衡反応進行度 $\xi_{\mathrm{eq}}$ を，温度および圧力の近傍で微分可能な関数として表すことができる．

以下では，この関係を用いて温度および圧力の変化に対する平衡移動の方向を求める．

### 2．温度を高めた場合（i）

圧力 $p$ を一定に保ち，温度 $T$ を変化させる．

平衡状態では，

```math
\Delta_{\mathrm r}G(T,p,\xi_{\mathrm{eq}})=0
```

が成立する．
これを圧力一定のもとで温度について微分すると，

```math
\left(\frac{\partial\Delta_{\mathrm r}G}{\partial T}\right)_{p,\xi}
+
\left(\frac{\partial\Delta_{\mathrm r}G}{\partial\xi}\right)_{T,p}
\frac{d\xi_{\mathrm{eq}}}{dT}
=0
```

となる．

したがって，

```math
\frac{d\xi_{\mathrm{eq}}}{dT}
=
-\frac{
\left(\dfrac{\partial\Delta_{\mathrm r}G}{\partial T}\right)_{p,\xi}
}{
\left(\dfrac{\partial\Delta_{\mathrm r}G}{\partial\xi}\right)_{T,p}
}
\tag{8}
```

を得る．

ここで，式 (8) の分子を求める．

化学ポテンシャルと部分モルエントロピーの間には，

```math
\left(\frac{\partial\mu_k}{\partial T}\right)_{p,\boldsymbol{x}}
=-\bar S_k
\tag{9}
```

という熱力学的関係が成立する．
ここで $\boldsymbol{x}$ は組成を表す．

反応進行度 $\xi$ を一定に保つと，各成分の物質量 $n_k$ は一定であり，組成も一定である．
したがって，式 (4)，(9) より，

```math
\begin{aligned}
\left(\frac{\partial\Delta_{\mathrm r}G}{\partial T}\right)_{p,\xi}
&=
\frac{\partial}{\partial T}
\sum_k\nu_k\mu_k\\
&=
\sum_k\nu_k
\left(\frac{\partial\mu_k}{\partial T}\right)_{p,\boldsymbol{x}}\\
&=
-\sum_k\nu_k\bar S_k
\end{aligned}
```

となる．
ここで，

```math
\Delta_{\mathrm r}S
\equiv\sum_k\nu_k\bar S_k
```

と定義すると，

```math
\boxed{
\left(\frac{\partial\Delta_{\mathrm r}G}{\partial T}\right)_{p,\xi}
=-\Delta_{\mathrm r}S
}
\tag{10}
```

を得る．

次に，反応エンタルピーを，

```math
\Delta_{\mathrm r}H
\equiv\sum_k\nu_k\bar H_k
\tag{11}
```

と定義する．

各成分について，

```math
\mu_k=\bar H_k-T\bar S_k
```

であるから，

```math
\begin{aligned}
\Delta_{\mathrm r}G
&=\sum_k\nu_k\mu_k\\
&=\sum_k\nu_k(\bar H_k-T\bar S_k)\\
&=\Delta_{\mathrm r}H-T\Delta_{\mathrm r}S
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\Delta_{\mathrm r}G
=
\Delta_{\mathrm r}H-T\Delta_{\mathrm r}S
}
\tag{12}
```

である．

平衡状態では式 (5) より，

```math
\Delta_{\mathrm r}G=0
```

であるから，式 (12) より，

```math
\Delta_{\mathrm r}H-T\Delta_{\mathrm r}S=0
```

となる．
よって，

```math
\boxed{
\left.\Delta_{\mathrm r}S\right|_{\mathrm{eq}}
=
\frac{\left.\Delta_{\mathrm r}H\right|_{\mathrm{eq}}}{T}
}
\tag{13}
```

を得る．

式 (13) は平衡状態で成立する関係である．
これを式 (10) に代入すると，平衡点において，

```math
\boxed{
\left.
\left(\frac{\partial\Delta_{\mathrm r}G}{\partial T}\right)_{p,\xi}
\right|_{\mathrm{eq}}
=
-\frac{\Delta_{\mathrm r}H}{T}
}
\tag{14}
```

となる．

さらに，系全体のエンタルピーを $H$ とすると，部分モルエンタルピーの定義および式 (3) より，

```math
\begin{aligned}
\left(\frac{\partial H}{\partial\xi}\right)_{T,p}
&=
\sum_k
\left(\frac{\partial H}{\partial n_k}\right)_{T,p}
\frac{\partial n_k}{\partial\xi}\\
&=
\sum_k\bar H_k\nu_k\\
&=\Delta_{\mathrm r}H
\end{aligned}
```

である．
したがって，

```math
\boxed{
\left(\frac{\partial H}{\partial\xi}\right)_{T,p}
=\Delta_{\mathrm r}H
}
\tag{15}
```

となる．

ここで，式 (7)，(8)，(14)，(15) を用いると，

```math
\begin{aligned}
\frac{d\xi_{\mathrm{eq}}}{dT}
&=
-\frac{
-\dfrac{\Delta_{\mathrm r}H}{T}
}{
\left(\dfrac{\partial\Delta_{\mathrm r}G}{\partial\xi}\right)_{T,p}
}\\[6pt]
&=
\frac{\Delta_{\mathrm r}H}{
T\left(\dfrac{\partial\Delta_{\mathrm r}G}{\partial\xi}\right)_{T,p}
}\\[6pt]
&=
\frac{1}{T}
\frac{
\left(\dfrac{\partial H}{\partial\xi}\right)_{T,p}
}{
\left(\dfrac{\partial^2G}{\partial\xi^2}\right)_{T,p}
}
\end{aligned}
```

を得る．
すなわち，

```math
\boxed{
\frac{d\xi_{\mathrm{eq}}}{dT}
=
\frac{\Delta_{\mathrm r}H}{
T\left(\dfrac{\partial^2G}{\partial\xi^2}\right)_{T,p}
}
}
\tag{16}
```

である．

絶対温度について，

```math
T>0
```

であり，式 (6) より，

```math
\left(\frac{\partial^2G}{\partial\xi^2}\right)_{T,p}>0
```

である．
したがって，

```math
\operatorname{sgn}
\left(\frac{d\xi_{\mathrm{eq}}}{dT}\right)
=
\operatorname{sgn}(\Delta_{\mathrm r}H)
\tag{17}
```

となる．

ここで，正方向の反応について，

- $\Delta_{\mathrm r}H>0$ の場合，正方向の反応は吸熱反応である．
  式 (17) より，

  ```math
  \frac{d\xi_{\mathrm{eq}}}{dT}>0
  ```

  となるため，温度を上昇させると正方向へ平衡が移動する．

- $\Delta_{\mathrm r}H<0$ の場合，正方向の反応は発熱反応である．
  式 (17) より，

  ```math
  \frac{d\xi_{\mathrm{eq}}}{dT}<0
  ```

  となるため，温度を上昇させると逆方向へ平衡が移動する．
  逆反応は吸熱反応であるため，この場合も吸熱方向への移動となる．

- $\Delta_{\mathrm r}H=0$ の場合，

  ```math
  \frac{d\xi_{\mathrm{eq}}}{dT}=0
  ```

  となり，一次の微分では平衡の移動方向は現れない．

また，式 (15)，(16) より，平衡移動による反応エンタルピーの微小変化は，

```math
\begin{aligned}
dH_{\mathrm{rxn}}
&\equiv
\left(\frac{\partial H}{\partial\xi}\right)_{T,p}
d\xi_{\mathrm{eq}}\\
&=\Delta_{\mathrm r}H
\frac{d\xi_{\mathrm{eq}}}{dT}\,dT\\
&=
\frac{(\Delta_{\mathrm r}H)^2}{
T\left(\dfrac{\partial^2G}{\partial\xi^2}\right)_{T,p}
}\,dT
\end{aligned}
```

である．
したがって， $dT>0$ のとき，

```math
\boxed{dH_{\mathrm{rxn}}\geq0}
\tag{18}
```

となる．
これは，温度上昇に伴う反応進行の寄与が吸熱方向であることを示している．

以上より，一定圧力のもとで温度を高めると，化学平衡は熱を吸収する方向に移動する．

### 3．圧力を増加させた場合（ii）

次に，温度 $T$ を一定に保ち，圧力 $p$ を変化させる．

平衡条件は，

```math
\Delta_{\mathrm r}G(T,p,\xi_{\mathrm{eq}})=0
```

である．
これを温度一定のもとで圧力について微分すると，

```math
\left(\frac{\partial\Delta_{\mathrm r}G}{\partial p}\right)_{T,\xi}
+
\left(\frac{\partial\Delta_{\mathrm r}G}{\partial\xi}\right)_{T,p}
\frac{d\xi_{\mathrm{eq}}}{dp}
=0
```

となる．

したがって，

```math
\frac{d\xi_{\mathrm{eq}}}{dp}
=
-\frac{
\left(\dfrac{\partial\Delta_{\mathrm r}G}{\partial p}\right)_{T,\xi}
}{
\left(\dfrac{\partial\Delta_{\mathrm r}G}{\partial\xi}\right)_{T,p}
}
\tag{19}
```

を得る．

ここで，化学ポテンシャルと部分モル体積の間には，

```math
\left(\frac{\partial\mu_k}{\partial p}\right)_{T,\boldsymbol{x}}
=\bar V_k
\tag{20}
```

という熱力学的関係が成立する．

反応進行度 $\xi$ を一定に保つと，各成分の物質量および組成も一定である．
したがって，式 (4)，(20) より，

```math
\begin{aligned}
\left(\frac{\partial\Delta_{\mathrm r}G}{\partial p}\right)_{T,\xi}
&=
\frac{\partial}{\partial p}
\sum_k\nu_k\mu_k\\
&=
\sum_k\nu_k
\left(\frac{\partial\mu_k}{\partial p}\right)_{T,\boldsymbol{x}}\\
&=
\sum_k\nu_k\bar V_k
\end{aligned}
```

となる．
ここで，

```math
\Delta_{\mathrm r}V
\equiv\sum_k\nu_k\bar V_k
```

と定義すると，

```math
\boxed{
\left(\frac{\partial\Delta_{\mathrm r}G}{\partial p}\right)_{T,\xi}
=
\Delta_{\mathrm r}V
}
\tag{21}
```

を得る．

また，系全体の体積を $V$ とすると，部分モル体積の定義および式 (3) より，

```math
\begin{aligned}
\left(\frac{\partial V}{\partial\xi}\right)_{T,p}
&=
\sum_k
\left(\frac{\partial V}{\partial n_k}\right)_{T,p}
\frac{\partial n_k}{\partial\xi}\\
&=
\sum_k\bar V_k\nu_k\\
&=\Delta_{\mathrm r}V
\end{aligned}
```

である．
したがって，

```math
\boxed{
\left(\frac{\partial V}{\partial\xi}\right)_{T,p}
=
\Delta_{\mathrm r}V
}
\tag{22}
```

となる．

ここで，式 (7)，(19)，(21)，(22) を用いると，

```math
\begin{aligned}
\frac{d\xi_{\mathrm{eq}}}{dp}
&=
-\frac{
\Delta_{\mathrm r}V
}{
\left(\dfrac{\partial\Delta_{\mathrm r}G}{\partial\xi}\right)_{T,p}
}\\
&=
-\frac{
\Delta_{\mathrm r}V
}{
\left(\dfrac{\partial^2G}{\partial\xi^2}\right)_{T,p}
}
\end{aligned}
```

を得る．
すなわち，

```math
\boxed{
\frac{d\xi_{\mathrm{eq}}}{dp}
=
-\frac{\Delta_{\mathrm r}V}{
\left(\dfrac{\partial^2G}{\partial\xi^2}\right)_{T,p}
}
}
\tag{23}
```

である．

式 (6) より分母は正であるから，

```math
\operatorname{sgn}
\left(\frac{d\xi_{\mathrm{eq}}}{dp}\right)
=
-\operatorname{sgn}(\Delta_{\mathrm r}V)
\tag{24}
```

となる．

したがって，

- $\Delta_{\mathrm r}V>0$ の場合，正方向の反応によって体積が増加する．
  式 (24) より，

  ```math
  \frac{d\xi_{\mathrm{eq}}}{dp}<0
  ```

  となるため，圧力を増加させると逆反応方向へ平衡が移動する．逆反応では体積が減少する．

- $\Delta_{\mathrm r}V<0$ の場合，正方向の反応によって体積が減少する．
  式 (24) より，

  ```math
  \frac{d\xi_{\mathrm{eq}}}{dp}>0
  ```

 となるため，圧力を増加させると正反応方向へ平衡が移動する．正反応では体積が減少する．

- $\Delta_{\mathrm r}V=0$ の場合，

  ```math
  \frac{d\xi_{\mathrm{eq}}}{dp}=0
  ```

  となり，一次の微分では平衡の移動方向は現れない．

さらに，式 (22)，(23) より，平衡移動による反応進行の体積変化は，

```math
\begin{aligned}
dV_{\mathrm{rxn}}
&\equiv
\left(\frac{\partial V}{\partial\xi}\right)_{T,p}
d\xi_{\mathrm{eq}}\\
&=
\Delta_{\mathrm r}V
\frac{d\xi_{\mathrm{eq}}}{dp}\,dp\\
&=
-\frac{(\Delta_{\mathrm r}V)^2}{
\left(\dfrac{\partial^2G}{\partial\xi^2}\right)_{T,p}
}\,dp
\end{aligned}
```

である．
したがって，圧力増加 $dp>0$ に対して，

```math
\boxed{dV_{\mathrm{rxn}}\leq0}
\tag{25}
```

となる．

これは，圧力上昇に伴う反応進行の寄与が，体積を減少させる方向であることを直接示している．

なお，ここでいう反応による体積変化と，圧力上昇そのものによる機械的な圧縮は区別する必要がある．
系全体の実際の体積変化についても，等温圧縮率を

```math
\kappa_T
\equiv
-\frac{1}{V}
\left(\frac{\partial V}{\partial p}\right)_{T,\xi}
```

と定義し，機械的安定性から $\kappa_T\geq0$ とすれば，

```math
\begin{aligned}
\frac{dV_{\mathrm{eq}}}{dp}
&=
\left(\frac{\partial V}{\partial p}\right)_{T,\xi}
+
\left(\frac{\partial V}{\partial\xi}\right)_{T,p}
\frac{d\xi_{\mathrm{eq}}}{dp}\\
&=
-\kappa_T V
-
\frac{(\Delta_{\mathrm r}V)^2}{
\left(\dfrac{\partial^2G}{\partial\xi^2}\right)_{T,p}
}\\
&\leq0
\end{aligned}
```

となる．
したがって，機械的にも安定な系では，圧力上昇によって平衡状態における系全体の体積が増加することもない．

以上より，一定温度のもとで圧力を増加させると，化学平衡は体積が減少する方向に移動する．

### 4．有限の温度変化および圧力変化について

これまでの式は，微分可能な平衡状態の近傍で成立する関係である．
ただし，平衡点が非退化な安定極小点であり，平衡状態を連続的に追跡できる範囲では，式 (18)，(25) を変化の全区間にわたって積分できる．

一定圧力のもとで温度を $T_1$ から $T_2$ まで上昇させると，反応進行によるエンタルピーの累積変化は，

```math
\int_{T_1}^{T_2}dH_{\mathrm{rxn}}
=
\int_{T_1}^{T_2}
\frac{(\Delta_{\mathrm r}H)^2}{
T\left(\dfrac{\partial^2G}{\partial\xi^2}\right)_{T,p}
}\,dT
\geq0
```

となる．

同様に，一定温度のもとで圧力を $p_1$ から $p_2$ まで上昇させると，反応進行による体積の累積変化は，

```math
\int_{p_1}^{p_2}dV_{\mathrm{rxn}}
=
-\int_{p_1}^{p_2}
\frac{(\Delta_{\mathrm r}V)^2}{
\left(\dfrac{\partial^2G}{\partial\xi^2}\right)_{T,p}
}\,dp
\leq0
```

となる．

したがって，反応エンタルピーや反応体積の符号が変化する場合であっても，平衡枝が連続的かつ非退化な安定平衡として追跡できる限り，温度上昇に伴う反応進行のエンタルピー寄与は非負であり，圧力上昇に伴う反応進行の体積寄与は非正である．

ただし，反応エンタルピーや反応体積の符号が変化すれば，反応進行度 $\xi_{\mathrm{eq}}$ 自体の増減方向が途中で変わることはあり得る．
ここで証明されたのは，各段階で平衡が吸熱方向または体積減少方向へ移動するという性質である．
また，平衡枝が退化したり，相転移などによって微分可能性が失われたりする場合には，別途その状態に応じた平衡条件を検討する必要がある．

### 5．結論

定温・定圧条件における Gibbs 自由エネルギーの極小条件から，平衡状態の温度および圧力に対する反応進行度の変化率を導いた．

その結果，

```math
\boxed{
\frac{d\xi_{\mathrm{eq}}}{dT}
=
\frac{\Delta_{\mathrm r}H}{
T\left(\dfrac{\partial^2G}{\partial\xi^2}\right)_{T,p}
}
}
```

が得られた．分母および絶対温度は正であるため，温度上昇に対する平衡移動は吸熱方向となる．

また，

```math
\boxed{
\frac{d\xi_{\mathrm{eq}}}{dp}
=
-\frac{\Delta_{\mathrm r}V}{
\left(\dfrac{\partial^2G}{\partial\xi^2}\right)_{T,p}
}
}
```

が得られた．
したがって，圧力上昇に対する平衡移動は体積が減少する方向となる．

以上より，

**(i)** 一定圧力のもとで温度を高めると，化学平衡は熱を吸収する方向に移動する．

**(ii)** 一定温度のもとで圧力を増加させると，化学平衡は体積が減少する方向に移動する．

したがって，Le Chatelier の原理が証明された．
