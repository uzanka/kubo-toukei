# 演習問題【4-C-48】

## 解答

### 1．自由エネルギーの展開と熱力学的条件

体積変化を無視し，単位体積当たりの Helmholtz 自由エネルギーを $f(M,T)$ とする．
ここで， $M$ は磁化， $T$ は絶対温度である．

Curie 温度 $T_c$ の近傍では磁化が小さくなるため，自由エネルギーを磁化 $M$ のべき級数として展開できると仮定する．
すなわち，

```math
\boxed{
f(M,T)=f_0(T)
+\frac{\alpha(T)}2M^2
+\frac{\beta(T)}{4!}M^4
+O(M^6)
}
\tag{1}
```

とする．
ここで，

```math
f_0(T)\equiv f(0,T)
```

である．

また，磁化の向きを反転しても自由エネルギーが変化しないものとする．
すなわち，

```math
f(M,T)=f(-M,T)
```

である．
この対称性により，自由エネルギーの展開には磁化の奇数次の項は現れない．

以下では，単一の磁化成分をもつ一様な磁性体を考え，磁化以外の秩序変数や磁区形成の影響は無視する．
また， $\alpha(T)$ ， $\beta(T)$ および高次項の係数は Curie 温度近傍で十分滑らかであり，

```math
\beta(T_c)>0
```

とする．

ここで，磁化 $M$ に共役な熱力学的磁場を $h$ と定義し，磁場によるエネルギー密度を $-hM$ とする．
したがって，磁場が存在する場合の熱力学ポテンシャルは，

```math
f_h(M,T)=f(M,T)-hM
\tag{2}
```

である．
問題文の磁場 $H$ は，以下ではこの共役磁場 $h$ に対応するものとする．
SI 単位系で通常の磁場 $H_{\mathrm{SI}}$ を使用する場合には，

```math
h=\mu_0H_{\mathrm{SI}}
```

である．

平衡状態では，式 (2) が磁化 $M$ に関して最小となる．
したがって，停留条件は，

```math
\frac{\partial f_h}{\partial M}=0
\tag{3}
```

である．
ただし，この条件だけでは極大点も含まれるため，極小条件も確認する必要がある．

なお，Landau 展開は Curie 温度近傍の局所的な自由エネルギーを表すものであり，その係数だけから遠方の別の自由エネルギー極小の不存在まで証明できるわけではない．
以下では，本問が扱う転移が連続転移であり，競合する別の相や低自由エネルギー状態への一次転移が先行せず，磁化の極小から生じる状態が熱力学的に選択される平衡状態であると仮定する．

### 2．Curie 温度以上における磁化率

まず， $T>T_c$ の常磁性領域を考える．

外部磁場が十分に弱いとき，磁化は磁場に比例する．
したがって，

```math
M=\chi_T h+O(h^3)
\tag{4}
```

と表される．

式 (1)，(2) より，平衡条件は，

```math
\frac{\partial f_h}{\partial M}
=
\alpha(T)M+\frac{\beta(T)}6M^3+O(M^5)-h=0
```

である．
よって，

```math
h=
\alpha(T)M+\frac{\beta(T)}6M^3+O(M^5)
```

となる．

ここで，常磁性領域における線形磁化率は，弱磁場極限で，

```math
\chi_T
=
\left.
\frac{\partial M}{\partial h}
\right|_{h=0}
```

と定義される．
このとき， $h\to0$ では $M\to0$ であるから，

```math
\boxed{
\chi_T=\frac1{\alpha(T)}
}
\tag{5}
```

を得る．

問題文で与えられた Curie-Weiss の法則，

```math
\chi_T=\frac{A}{T-T_c}
\qquad(T>T_c)
```

を代入すると，

```math
\frac1{\alpha(T)}
=
\frac{A}{T-T_c}
```

であるから，

```math
\boxed{
\alpha(T)=\frac{T-T_c}{A}
\qquad(T>T_c)
}
\tag{6}
```

となる．

ここで注意すべきことは，この等式が Curie-Weiss の法則から直接導かれるのは $T>T_c$ の領域に限られることである．
この式を低温側にも厳密な等式として適用することはできない．

ただし， $\alpha(T)$ は $T_c$ を含む近傍で滑らかであると仮定している．
したがって，式 (6) から，

```math
\boxed{
\alpha(T_c)=0
}
```

および，

```math
\boxed{
\alpha'(T_c)=\frac1A
}
\tag{7}
```

が得られる．

ここで，プライムは温度 $T$ に関する微分を表す．

さらに， $T_c$ の近傍で Taylor 展開すると，

```math
\boxed{
\alpha(T)
=
\frac{T-T_c}{A}
+O\left((T-T_c)^2\right)
}
\tag{8}
```

となる．

したがって， $A>0$ より，Curie 温度の十分近くでは，

```math
T>T_c
\quad\Longrightarrow\quad
\alpha(T)>0
```

および，

```math
T<T_c
\quad\Longrightarrow\quad
\alpha(T)<0
```

となる．

この係数の符号変化が，自発磁化の出現を決定する．

### 3．Curie 温度以下における自発磁化

次に， $T<T_c$ の Curie 温度近傍を考える．

外部磁場がない場合，

```math
h=0
```

であるため，平衡条件は，

```math
\frac{\partial f}{\partial M}=0
```

となる．

式 (1) を微分すると，

```math
\alpha(T)M+\frac{\beta(T)}6M^3+O(M^5)=0
```

である．

これを変形すると，

```math
M\left\{
\alpha(T)+\frac{\beta(T)}6M^2+O(M^4)
\right\}=0
```

となる．
したがって，

```math
M=0
```

または，

```math
\alpha(T)+\frac{\beta(T)}6M^2+O(M^4)=0
```

である．

ここで，

```math
x=M^2
```

とおくと，

```math
\alpha(T)+\frac{\beta(T)}6x+O(x^2)=0
\tag{9}
```

となる．

$T=T_c$ では，

```math
\alpha(T_c)=0,\qquad \beta(T_c)>0
```

であるため，陰関数定理を適用すると， $T_c$ 近傍の非自明な解は，

```math
\boxed{
M_s^2
=
-\frac{6\alpha(T)}{\beta(T)}
+O(\alpha(T)^2)
}
\tag{10}
```

となる．

式 (8) より， $T<T_c$ の十分近傍では $\alpha(T)<0$ である．
また， $\beta(T_c)>0$ と連続性から，その近傍では $\beta(T)>0$ である．
したがって，

```math
M_s^2>0
```

となり，非零の実数解が存在する．

自発磁化の大きさを $M_s>0$ とすると，磁化反転対称性により，平衡磁化の候補は，

```math
\boxed{
M=\pm M_s
}
```

である．

#### 3.1 極小条件の確認

実際に平衡状態を与えることを確認するため，自由エネルギーを二階微分する．

```math
\frac{\partial^2f}{\partial M^2}
=
\alpha(T)+\frac{\beta(T)}2M^2+O(M^4)
\tag{11}
```

である．

まず， $M=0$ では，

```math
\left.
\frac{\partial^2f}{\partial M^2}
\right|_{M=0}
=
\alpha(T)<0
```

となるため， $M=0$ は局所極大点である．

一方， $M=\pm M_s$ では，式 (10) より，

```math
\begin{aligned}
\left.
\frac{\partial^2f}{\partial M^2}
\right|_{M=\pm M_s}
&=
\alpha(T)
+\frac{\beta(T)}2
\left\{
-\frac{6\alpha(T)}{\beta(T)}
+O(\alpha(T)^2)
\right\}
+O(\alpha(T)^2)\\
&=-2\alpha(T)+O(\alpha(T)^2)
\end{aligned}
```

となる．

$\alpha(T)<0$ であるから，Curie 温度の十分近傍では，

```math
\boxed{
\left.
\frac{\partial^2f}{\partial M^2}
\right|_{M=\pm M_s}>0
}
```

である．
したがって， $M=\pm M_s$ は局所極小点である．

本問で仮定した連続転移の平衡枝では，これらが熱力学的に選択される平衡状態となる．

#### 3.2 自発磁化の臨界的振る舞い

式 (8)，(10) より，

```math
\begin{aligned}
M_s^2
&=
-\frac6{\beta(T)}
\left\{
\frac{T-T_c}{A}
+O((T-T_c)^2)
\right\}
+O((T-T_c)^2)\\
&=
\frac{6(T_c-T)}{A\beta(T_c)}
+O((T_c-T)^2)
\end{aligned}
```

となる．

したがって，

```math
\boxed{
M_s
\sim
\left\{
\frac{6(T_c-T)}{A\beta(T_c)}
\right\}^{1/2}
\qquad(T\to T_c-0)
}
\tag{12}
```

を得る．

ここで， $\sim$ は両辺の比が 1 に近づく漸近関係を表す．

つまり，

```math
\boxed{
M_s\propto(T_c-T)^{1/2}
}
```

であり，この Landau 理論における自発磁化の臨界指数は $1/2$ である．

なお，四次までの自由エネルギーで打ち切った近似では，

```math
M_s^2=-\frac{6\alpha(T)}{\beta(T)}
```

が厳密に成立するが，高次項を含む元の自由エネルギーに対しては，式 (10)，(12) が正しい漸近式である．

また，自発磁化は厳密には熱力学極限を先に取り，その後に磁場をゼロに近づけることで定義する．
すなわち，

```math
\boxed{
M_s(T)
=
\lim_{h\to0^+}
\lim_{\mathcal V\to\infty}
M(T,h)
}
```

である．
ここで $\mathcal V$ は試料の体積である．
正の微小磁場は $+M_s$ の状態を選択し，負の微小磁場は $-M_s$ の状態を選択する．

### 4．平衡自由エネルギーの計算

次に，Curie 温度における比熱の不連続を求める．

そのため，外部磁場がゼロのときの平衡自由エネルギー密度を，

```math
f_{\mathrm{eq}}(T)
=
\min_M f(M,T)
\tag{13}
```

と定義する．

ここでは，前述の連続転移の平衡枝を採用する．

**(i)** $T>T_c$ の場合

この領域では，

```math
\alpha(T)>0
```

である．
したがって，Curie 温度の十分近傍では磁化 $M=0$ が平衡状態となる．

よって，

```math
\boxed{
f_{\mathrm{eq}}(T)=f_0(T)
}
\qquad(T>T_c)
\tag{14}
```

である．

**(ii)** $T<T_c$ の場合

この領域では，

```math
M=\pm M_s
```

が平衡状態となる．

式 (1) に代入すると，

```math
f_{\mathrm{eq}}(T)
=
f_0(T)
+\frac{\alpha(T)}2M_s^2
+\frac{\beta(T)}{24}M_s^4
+O(M_s^6)
```

となる．

式 (10) より，

```math
M_s^2
=
-\frac{6\alpha(T)}{\beta(T)}
+O(\alpha(T)^2)
```

であるから，

```math
\begin{aligned}
\frac{\alpha(T)}2M_s^2
&=
-\frac{3\alpha(T)^2}{\beta(T)}
+O(\alpha(T)^3)
\end{aligned}
```

となる．

また，

```math
\begin{aligned}
\frac{\beta(T)}{24}M_s^4
&=
\frac{\beta(T)}{24}
\left\{
\frac{36\alpha(T)^2}{\beta(T)^2}
+O(\alpha(T)^3)
\right\}\\
&=
\frac{3\alpha(T)^2}{2\beta(T)}
+O(\alpha(T)^3)
\end{aligned}
```

である．

さらに，

```math
M_s^6=O(\alpha(T)^3)
```

であるため，高次項も $O(\alpha(T)^3)$ に含まれる．

したがって，

```math
\begin{aligned}
f_{\mathrm{eq}}(T)
&=
f_0(T)
-\frac{3\alpha(T)^2}{\beta(T)}
+\frac{3\alpha(T)^2}{2\beta(T)}
+O(\alpha(T)^3)\\
&=
f_0(T)-\frac{3\alpha(T)^2}{2\beta(T)}
+O(\alpha(T)^3)
\end{aligned}
```

となる．

よって，

```math
\boxed{
f_{\mathrm{eq}}(T)
=
f_0(T)
-\frac{3\alpha(T)^2}{2\beta(T)}
+O(\alpha(T)^3)
}
\qquad(T<T_c)
\tag{15}
```

を得る．

この式は四次 Landau 近似の主要項を表すものであり，高次項を含む場合にも，Curie 温度近傍での漸近式として成立する．

### 5．エントロピーと比熱の不連続

以下では，体積一定，外部磁場ゼロの条件で比熱を考える．

自由エネルギー密度から求められる単位体積当たりのエントロピーを $s$ ，単位体積当たりの比熱を $c_V$ とすると，

```math
\boxed{
s=-\frac{\partial f_{\mathrm{eq}}}{\partial T}
}
```

および，

```math
\boxed{
c_V=-T\frac{\partial^2 f_{\mathrm{eq}}}{\partial T^2}
}
\tag{16}
```

である．

ここで，微分は外部磁場をゼロに保ち，平衡磁化が温度に応じて変化することも含めた平衡自由エネルギーについて行う．

また，背景自由エネルギー $f_0(T)$ は $T_c$ 近傍で二階微分可能であり，それ自身には別の比熱の不連続が存在しないと仮定する．

#### 5.1 エントロピーの連続性

まず，

```math
t=T-T_c
```

とおく．

式 (8) より，

```math
\alpha(T)
=
\frac{t}{A}+O(t^2)
```

であり， $\beta(T)$ の滑らかさから，

```math
\beta(T)=\beta(T_c)+O(t)
```

である．

したがって，

```math
\frac{\alpha(T)^2}{\beta(T)}
=
\frac{t^2}{A^2\beta(T_c)}
+O(|t|^3)
```

となる．

これを式 (15) に代入すると，

```math
f_{\mathrm{eq}}(T)
=
f_0(T)
-\frac{3t^2}{2A^2\beta(T_c)}
+O(|t|^3)
\qquad(t<0)
\tag{17}
```

である．

一方， $t>0$ では，

```math
f_{\mathrm{eq}}(T)=f_0(T)
```

である．

ここで，

```math
K\equiv
\frac{3}{2A^2\beta(T_c)}
```

とおけば，

```math
f_{\mathrm{eq}}(T)
=
\begin{cases}
f_0(T),&t>0,\\[4pt]
f_0(T)-Kt^2+O(|t|^3),&t<0
\end{cases}
\tag{18}
```

となる．

これを温度で微分すると， $t>0$ では，

```math
s_+
=
-\frac{\partial f_0}{\partial T}
```

であり， $t<0$ では，

```math
s_-
=
-\frac{\partial f_0}{\partial T}
+2Kt+O(t^2)
```

となる．

したがって，

```math
\boxed{
s(T_c-0)=s(T_c+0)
}
\tag{19}
```

が成立する．

すなわち，Curie 温度でエントロピーは連続であり，潜熱は生じない．

#### 5.2 比熱の跳び

式 (18) を二階微分する．

$T>T_c$ では，

```math
\frac{\partial^2 f_{\mathrm{eq}}}{\partial T^2}
=
\frac{\partial^2f_0}{\partial T^2}
```

であるから，

```math
c_{T_c+0}
=
-T_c
\left.
\frac{\partial^2f_0}{\partial T^2}
\right|_{T=T_c}
\tag{20}
```

となる．

一方， $T<T_c$ では，

```math
\frac{\partial^2 f_{\mathrm{eq}}}{\partial T^2}
=
\frac{\partial^2f_0}{\partial T^2}
-2K+O(|t|)
```

である．
したがって，

```math
c_{T_c-0}
=
-T_c
\left.
\frac{\partial^2f_0}{\partial T^2}
\right|_{T=T_c}
+2KT_c
\tag{21}
```

となる．

式 (20)，(21) の差を取ると，

```math
\begin{aligned}
\Delta c_V
&\equiv c_{T_c-0}-c_{T_c+0}\\
&=2KT_c\\
&=
\frac{3T_c}{A^2\beta(T_c)}
\end{aligned}
```

である．

よって，

```math
\boxed{
\Delta c_V
=
c_{T_c-0}-c_{T_c+0}
=
\frac{3T_c}{A^2\beta(T_c)}
}
\tag{22}
```

を得る．

```math
A>0,\qquad \beta(T_c)>0,\qquad T_c>0
```

であるから，

```math
\boxed{\Delta c_V>0}
```

である．

したがって，Curie 温度の低温側の比熱は，高温側の比熱よりも大きい．

なお，この結果は単位体積当たりの比熱の跳びである．試料全体の比熱の跳びは，試料体積を $\mathcal V$ とすると，

```math
\Delta C_V
=
\mathcal V\Delta c_V
```

で与えられる．

#### 5.3 高次項が比熱の跳びに及ぼす影響

ここで，式 (15) に含まれる高次項が比熱の跳びに影響しないことを確認する．

```math
\alpha(T)=O(T-T_c)
```

であるから，

```math
O(\alpha^3)=O((T-T_c)^3)
```

となる．

この項を二階微分すると，

```math
O(T-T_c)
```

となるため，Curie 温度に近づけるとゼロになる．

したがって，高次項は比熱の両側極限の差には寄与しない．

よって，式 (22) は四次 Landau 近似でのみ成立する値ではなく，滑らかな高次項を含む連続転移の Landau 展開においても成立する主要結果である．

### 6．結論

Curie-Weiss の法則から，Landau 自由エネルギー展開の二次係数について，

```math
\alpha(T_c)=0
```

および，

```math
\alpha'(T_c)=\frac1A
```

が導かれる．

このため，Curie 温度近傍では，

```math
\alpha(T)
=
\frac{T-T_c}{A}
+O((T-T_c)^2)
```

となる．

この係数の符号変化によって， $T<T_c$ では磁化ゼロの状態が不安定となり，二つの自発磁化状態が現れる．
その大きさは，

```math
\boxed{
M_s
\sim
\left[
\frac{6(T_c-T)}
{A\beta(T_c)}
\right]^{1/2}
}
```

で与えられる．

したがって，自発磁化の臨界指数は，

```math
\boxed{\beta_{\mathrm{mag}}=\frac12}
```

である．
ここで， $\beta_{\mathrm{mag}}$ は磁化の臨界指数であり，自由エネルギー展開の四次係数 $\beta(T)$ とは別の量である．

また，平衡自由エネルギーは Curie 温度で連続であり，その一階温度微分も連続である．
したがって，エントロピーは連続で潜熱は生じない．

一方，平衡自由エネルギーの二階温度微分には有限の不連続が生じるため，比熱には跳びが現れる．
その大きさは，

```math
\boxed{
\Delta c_V
=
c_{T_c-0}-c_{T_c+0}
=
\frac{3T_c}{A^2\beta(T_c)}
}
```

である．

以上より，Landau の熱力学的理論によって，Curie 温度以下の自発磁化と Curie 温度における比熱の不連続が説明された．
