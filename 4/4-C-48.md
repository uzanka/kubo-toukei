# 演習問題【4-C-48】

## 解答

### 1. 自由エネルギーの展開と平衡条件

磁化 $M$ と温度 $T$ に依存する自由エネルギー密度 $F(M, T)$ を， $M=0$ の近傍で次のように展開する．

$$F(M, T) = F(0, T) + \frac{\alpha(T)}{2}M^2 + \frac{\beta(T)}{4!}M^4 + \dots \quad \cdots (1)$$

ここで，磁場 $H$ が与えられた場合の系の平衡条件は，磁場を含めた有効な自由エネルギー（ギブス自由エネルギーに相当）を最小にする $M$ を選ぶことである．

$$F_{\text{eff}}(M, T) = F(M, T) - HM = \text{min.} \quad \cdots (2)$$

### 2. 高温領域 ( $T > T_c$ ) における磁化率

$T > T_c$ の領域（常磁性領域）では，磁化 $M$ は磁場 $H$ に対して線形に比例する小さな値をとると考えられる．
このとき， $M^4$ 以上の高次の項は無視できる．
平衡条件 (2) を $M$ で微分して $0$ と置くと：

$$\frac{\partial}{\partial M} \left( F(0, T) + \frac{\alpha(T)}{2}M^2 - HM \right) = \alpha(T)M - H = 0$$

これより，磁化 $M$ は次のように求まる．

$$M = \frac{H}{\alpha(T)} \quad \cdots (3)$$

磁化率 $\chi_T$ は $M/H$ で定義されるため， $\chi_T = 1/\alpha(T)$ となる．
問題文にある Curie-Weiss の法則 $\chi_T = \frac{A}{T - T_c}$ と比較すると， $\alpha(T)$ は次のように書ける．

$$\frac{1}{\alpha(T)} = \frac{A}{T - T_c} \implies \alpha(T) = \frac{T - T_c}{A} \quad \cdots (4)$$

これより， $\alpha(T_c) = 0$ であることがわかる．

### 3. 低温領域 ( $T < T_c$ ) における自発磁化

$T < T_c$ の領域（強磁性領域）では， $\alpha(T) < 0$ となる．
このとき，式 (1) の $M^2$ の項の係数が負になるため， $M=0$ は自由エネルギーの極大点となる．
一方で， $\beta(T) > 0$ であれば， $M^4$ の項によって $M \neq 0$ の位置に新たに極小点が生まれる．
磁場がない場合 ( $H=0$ )，平衡条件 $\frac{\partial F}{\partial M} = 0$ は以下のようになる．

$$\alpha(T)M + \frac{\beta(T)}{6}M^3 = 0 \implies M \left( \alpha(T) + \frac{\beta(T)}{6}M^2 \right) = 0$$

$M \neq 0$ の解（自発磁化 $M_s$ ）は：

$$M_s^2 = -\frac{6\alpha(T)}{\beta(T)} \implies M_s = \sqrt{-\frac{6\alpha(T)}{\beta(T)}} \quad \cdots (5)$$

ここで $\alpha(T) = (T - T_c)/A = -(T_c - T)/A$ を代入すると：

$$M_s = \sqrt{\frac{6(T_c - T)}{A\beta(T)}} \simeq \sqrt{\frac{6(T_c - T)}{A\beta(T_c)}} \quad (T \lesssim T_c \text{ のとき})$$

となり，温度が $T_c$ に近づくにつれて自発磁化が $0$ に向かって減少していく様子がわかる．

### 4. 自由エネルギー，エントロピー，および比熱の計算

次に，温度変化に伴う比熱の不連続性を調べるため，自由エネルギー $F(T)$ を計算する．

**$T > T_c$ のとき：**

$M = 0$ なので， $F(T) = F(0, T)$ である．

**$T < T_c$ のとき：**

$M = M_s$ を式 (1) に代入する（ $M^4$ の項まで考慮）．

$$F(T) = F(0, T) + \frac{\alpha}{2}M_s^2 + \frac{\beta}{24}M_s^4$$

$M_s^2 = -6\alpha/\beta$ を代入すると：

$$F(T) = F(0, T) + \frac{\alpha}{2}\left( -\frac{6\alpha}{\beta} \right) + \frac{\beta}{24}\left( \frac{36\alpha^2}{\beta^2} \right) = F(0, T) - \frac{3\alpha^2}{\beta} + \frac{3\alpha^2}{2\beta} = F(0, T) - \frac{3\alpha^2}{2\beta} \quad \cdots (6\text{b})$$

**エントロピー $S$ の計算：**

エントロピーは $S = -\frac{\partial F}{\partial T}$ で求められる．
$T \to T_c^+$ では $S_{T_c+0} = -\frac{\partial F(0, T)}{\partial T}\big|_{T_c}$ である．
$T \to T_c^-$ では：

$$S_{T_c-0} = -\frac{\partial}{\partial T} \left( F(0, T) - \frac{3\alpha(T)^2}{2\beta(T)} \right) \bigg|_{T_c} = S_{T_c+0} + \frac{3}{2} \frac{\partial}{\partial T} \left( \frac{\alpha^2}{\beta} \right) \bigg|_{T_c}$$

ここで， $\frac{\partial}{\partial T} \left( \frac{\alpha^2}{\beta} \right) = \frac{2\alpha \alpha' \beta - \alpha^2 \beta'}{\beta^2}$ であるが， $T = T_c$ において $\alpha(T_c) = 0$ であるため，この微分値は $0$ となる．
したがって，エントロピーは連続である ( $S_{T_c-0} = S_{T_c+0}$ )．

**比熱 $C$ の計算：**

比熱は $C = -T \frac{\partial^2 F}{\partial T^2}$ で求められる．
$T \to T_c^+$ では $C_{T_c+0} = -T_c \frac{\partial^2 F(0, T)}{\partial T^2}\big|_{T_c}$ である．
$T \to T_c^-$ では：

$$C_{T_c-0} = -T_c \frac{\partial^2}{\partial T^2} \left( F(0, T) - \frac{3\alpha^2}{2\beta} \right) \bigg|_{T_c} = C_{T_c+0} + \frac{3T_c}{2} \frac{\partial^2}{\partial T^2} \left( \frac{\alpha^2}{\beta} \right) \bigg|_{T_c}$$

$\frac{\alpha^2}{\beta}$ の 2 階微分を計算する．

1 階微分： $\frac{\partial}{\partial T} \left( \frac{\alpha^2}{\beta} \right) = \frac{2\alpha \alpha'}{\beta} - \frac{\alpha^2 \beta'}{\beta^2}$

2 階微分： $\frac{\partial^2}{\partial T^2} \left( \frac{\alpha^2}{\beta} \right) = \frac{2(\alpha')^2 + 2\alpha \alpha''}{\beta} - \frac{4\alpha \alpha' \beta'}{\beta^2} + \frac{2\alpha^2 (\beta')^2}{\beta^3} - \frac{\alpha^2 \beta''}{\beta^2}$

$T = T_c$ において $\alpha = 0$ であることを用いると，項の多くが消えて次のように簡略化される．

$$\frac{\partial^2}{\partial T^2} \left( \frac{\alpha^2}{\beta} \right) \bigg|_{T_c} = \frac{2(\alpha'(T_c))^2}{\beta(T_c)}$$

$\alpha(T) = (T - T_c)/A$ より $\alpha'(T) = 1/A$ なので，

$$C_{T_c-0} = C_{T_c+0} + \frac{3T_c}{2} \cdot \frac{2(1/A)^2}{\beta(T_c)} = C_{T_c+0} + \frac{3T_c}{A^2 \beta(T_c)}$$

したがって，比熱の不連続量 $\Delta C$ は：

$$\Delta C = C_{T_c-0} - C_{T_c+0} = \frac{3T_c}{A^2 \beta(T_c)}$$

が得られる．

## 解説

この問題は，相転移（特に 2 次相転移）の典型的なモデルであるランダウ理論（Landau theory）に基づいている．

1.  **$\alpha(T)$ の役割**:
  $\alpha(T)$ は秩序変数（ここでは磁化 $M$ ）の安定性を制御するパラメータである．
  $\alpha > 0$ のときは $M=0$ が安定な「無秩序相（常磁性）」であり， $\alpha < 0$ になると $M=0$ が不安定になり， $M \neq 0$ の「秩序相（強磁性）」が現れる．
  $\alpha(T_c)=0$ となることで，温度によってこの状態が切り替わることを示している．
2.  **自由エネルギーの形状**:
  温度が $T_c$ を下回ると，自由エネルギーのグラフは「中央が凹んだ（ $M=0$ が山になる）」形状に変化する．
  系はエネルギーを最小化しようとするため，山を避けて左右の谷（ $M = \pm M_s$ ）へと落ち込む．
  これが「自発磁化」の物理的な正体である．
3.  **比熱の跳び**:
  このモデルでは，エントロピー自体は連続であるが，その傾き（比熱）に不連続が生じる．
  これは，相転移に伴ってエネルギーの蓄え方（秩序の形成）が劇的に変わることを反映している．

比熱が急上昇する様子は，実験的にも強磁性体においてよく観察される現象である．
