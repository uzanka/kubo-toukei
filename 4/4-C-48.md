# 演習問題【4-C-48】

## 解答

### 1．自由エネルギーの展開と平衡条件

体積変化を無視し，単位体積当たりの自由エネルギーを $F(M,T)$ とする．
ここで， $M$ は磁化， $T$ は温度である．
Curie 温度 $T_c$ の近傍では磁化が小さいため，自由エネルギーを $M$ のべき級数として展開できると仮定する．
すなわち，

```math
F(M,T)=F(0,T)
+\frac{\alpha(T)}{2}M^2
+\frac{\beta(T)}{4!}M^4+\cdots
\tag{1}
```

である．

磁化の向きを反転しても系の自由エネルギーは変化しないと仮定する．
すなわち， $F(M,T)=F(-M,T)$ である．
この対称性により，式 (1) には $M$ の奇数次の項は現れない．

磁場 $H$ が加わると，磁場によるエネルギーの寄与は $-HM$ である．
したがって，平衡状態の磁化は，

```math
F_{\mathrm{eff}}(M,T)=F(M,T)-HM
\tag{2}
```

を最小にする値として決まる．
平衡条件を求めるには，

```math
\frac{\partial F_{\mathrm{eff}}}{\partial M}=0
```

を満たす必要がある．
ただし，この条件だけでは極大点も含まれるため，実際の平衡状態を決めるには自由エネルギーが最小となることも確認する必要がある．

以下では，Curie 温度近傍で式 (1) の $M^4$ の項までを考える．
また， $\beta(T_c)>0$ とし， $\alpha(T)$ と $\beta(T)$ は $T_c$ の近傍で滑らかな関数であると仮定する．

### 2．Curie 温度以上における磁化率

まず， $T>T_c$ の常磁性領域を考える．
磁場が十分に弱いとき，磁化は磁場に比例し，

```math
M=\chi_T H
\tag{3}
```

となる．
この領域では磁化が小さいため，式 (1) の $M^4$ 以上の項を無視できる．
よって，

```math
F_{\mathrm{eff}}(M,T)
\simeq F(0,T)+\frac{\alpha(T)}{2}M^2-HM
```

である．
これを $M$ で微分し，平衡条件を適用すると，

```math
\frac{\partial F_{\mathrm{eff}}}{\partial M}
=\alpha(T)M-H=0
```

を得る．
したがって，

```math
M=\frac{H}{\alpha(T)}
\tag{4}
```

である．
式 (3) と式 (4) を比較すると，

```math
\chi_T=\frac{1}{\alpha(T)}
```

となる．
問題文で与えられた Curie-Weiss の法則

```math
\chi_T=\frac{A}{T-T_c}
```

を代入すれば，

```math
\frac{1}{\alpha(T)}=\frac{A}{T-T_c}
```

より，

```math
\boxed{
\alpha(T)=\frac{T-T_c}{A}
}
\tag{5}
```

が得られる．
ここで $A>0$ であるから，

```math
\alpha(T_c)=0
```

であり， $T>T_c$ では $\alpha(T)>0$ ， $T<T_c$ では $\alpha(T)<0$ となる．
この符号の変化が，自発磁化の出現を決定する．

### 3．Curie 温度以下における自発磁化

次に， $T<T_c$ の強磁性領域を考える．
外部磁場がない場合， $H=0$ であるから，平衡状態は $F(M,T)$ を最小にする磁化によって決まる．
式 (1) を $M$ で微分すると，

```math
\frac{\partial F}{\partial M}
=\alpha(T)M+\frac{\beta(T)}{6}M^3=0
```

となる．
これを因数分解すると，

```math
M\left\{\alpha(T)+\frac{\beta(T)}{6}M^2\right\}=0
```

である．
したがって，停留点は，

```math
M=0
```

または，

```math
M^2=-\frac{6\alpha(T)}{\beta(T)}
```

で与えられる．

$T<T_c$ では $\alpha(T)<0$ であり， $\beta(T)>0$ とすれば，後者の解は実数となる．
そこで，自発磁化の大きさを $M_s>0$ と定義すると，

```math
M_s=\sqrt{-\frac{6\alpha(T)}{\beta(T)}}
\tag{6}
```

である．
実際の平衡磁化は，磁化反転対称性により，

```math
M=\pm M_s
```

の二つの値をとる．

これらが極小点であることを確認するため，二階微分を求めると，

```math
\frac{\partial^2F}{\partial M^2}
=\alpha(T)+\frac{\beta(T)}{2}M^2
```

となる．
$M=0$ では，

```math
\left.\frac{\partial^2F}{\partial M^2}\right|_{M=0}
=\alpha(T)<0
```

であるため， $M=0$ は極大点である．
一方， $M=\pm M_s$ では，式 (6) を用いて，

```math
\left.\frac{\partial^2F}{\partial M^2}\right|_{M=\pm M_s}
=\alpha(T)+\frac{\beta(T)}{2}
\left(-\frac{6\alpha(T)}{\beta(T)}\right)
=-2\alpha(T)>0
```

となる．
したがって， $M=\pm M_s$ は極小点であり，安定な平衡状態を与える．

式 (5) を式 (6) に代入すると，

```math
M_s=\sqrt{\frac{6(T_c-T)}{A\beta(T)}}
```

となる．
Curie 温度の十分近くでは， $\beta(T)\simeq\beta(T_c)$ と近似できるため，

```math
\boxed{
M_s\simeq
\left\{
\frac{6(T_c-T)}{A\beta(T_c)}
\right\}^{1/2}
}
\qquad (T\lesssim T_c)
\tag{7}
```

を得る．

したがって，Curie 温度以下では自発磁化が生じ，その大きさは $T_c-T$ の平方根に比例する．
すなわち， $T\to T_c-0$ で自発磁化はゼロに近づく．
これは，このモデルにおける自発磁化の臨界指数が $1/2$ であることを意味する．

### 4．平衡自由エネルギーの計算

次に，Curie 温度における比熱の不連続を求める．
そのためには，平衡状態における自由エネルギーを温度の関数として求める必要がある．

#### (i) $T>T_c$ の場合

この領域では $\alpha(T)>0$ であるため， $H=0$ における自由エネルギーの極小は $M=0$ にある．
したがって，

```math
\boxed{
F(T)=F(0,T)
}
\qquad (T>T_c)
\tag{8}
```

である．

#### (ii) $T<T_c$ の場合

この領域では，平衡磁化は $M=\pm M_s$ である．
式 (1) に $M=M_s$ を代入すると，

```math
F(T)=F(0,T)
+\frac{\alpha(T)}{2}M_s^2
+\frac{\beta(T)}{24}M_s^4
```

となる．
ここで，

```math
M_s^2=-\frac{6\alpha(T)}{\beta(T)}
```

であるから，

```math
\begin{aligned}
F(T)
&=F(0,T)
+\frac{\alpha(T)}{2}
\left(-\frac{6\alpha(T)}{\beta(T)}\right)\\
&\quad+\frac{\beta(T)}{24}
\left(\frac{36\alpha(T)^2}{\beta(T)^2}\right)\\
&=F(0,T)-\frac{3\alpha(T)^2}{\beta(T)}
+\frac{3\alpha(T)^2}{2\beta(T)}\\
&=F(0,T)-\frac{3\alpha(T)^2}{2\beta(T)}.
\end{aligned}
```

したがって，

```math
\boxed{
F(T)=F(0,T)-\frac{3\alpha(T)^2}{2\beta(T)}
}
\qquad (T<T_c)
\tag{9}
```

である．

式 (8)，式 (9) より，平衡自由エネルギーは，

```math
F(T)=
\begin{cases}
F(0,T),&T>T_c,\\[4pt]
F(0,T)-\dfrac{3\alpha(T)^2}{2\beta(T)},&T<T_c
\end{cases}
```

と表される．
以下では，この平衡自由エネルギーからエントロピーと比熱を計算する．

### 5．エントロピーと比熱の不連続

体積一定の条件では，エントロピー $S$ と比熱 $C$ は，平衡自由エネルギーから，

```math
S=-\frac{\partial F}{\partial T},
\qquad
C=T\frac{\partial S}{\partial T}
=-T\frac{\partial^2F}{\partial T^2}
\tag{10}
```

によって求められる．
ここで，微分は平衡自由エネルギーの温度依存性について行う．

まず， $T>T_c$ では式 (8) より，

```math
S(T)=-\frac{\partial F(0,T)}{\partial T}
```

である．
一方， $T<T_c$ では式 (9) より，

```math
S(T)=
-\frac{\partial F(0,T)}{\partial T}
+\frac{3}{2}\frac{\partial}{\partial T}
\left(\frac{\alpha(T)^2}{\beta(T)}\right)
```

となる．
ここで，

```math
\frac{\partial}{\partial T}
\left(\frac{\alpha^2}{\beta}\right)
=\frac{2\alpha\alpha'}{\beta}
-\frac{\alpha^2\beta'}{\beta^2}
```

である．
プライムは温度 $T$ に関する微分を表す．
Curie 温度では $\alpha(T_c)=0$ であるため，

```math
\left.
\frac{\partial}{\partial T}
\left(\frac{\alpha^2}{\beta}\right)
\right|_{T=T_c}=0
```

となる．
したがって，エントロピーは Curie 温度で連続である．

次に，比熱を求める．
式 (10) より， $T>T_c$ では，

```math
C_{T_c+0}
=-T_c
\left.
\frac{\partial^2F(0,T)}{\partial T^2}
\right|_{T=T_c}
```

である．
一方， $T<T_c$ では，

```math
\begin{aligned}
C_{T_c-0}
&=-T_c
\left.
\frac{\partial^2}{\partial T^2}
\left\{
F(0,T)-\frac{3\alpha(T)^2}{2\beta(T)}
\right\}
\right|_{T=T_c}\\
&=C_{T_c+0}
+\frac{3T_c}{2}
\left.
\frac{\partial^2}{\partial T^2}
\left(\frac{\alpha(T)^2}{\beta(T)}\right)
\right|_{T=T_c}.
\end{aligned}
```

ここで，

```math
\frac{\partial^2}{\partial T^2}
\left(\frac{\alpha^2}{\beta}\right)
=
\frac{2(\alpha')^2+2\alpha\alpha''}{\beta}
-\frac{4\alpha\alpha'\beta'}{\beta^2}
-\frac{\alpha^2\beta''}{\beta^2}
+\frac{2\alpha^2(\beta')^2}{\beta^3}
```

である．
$\alpha(T_c)=0$ を用いると， $\alpha(T_c)$ を含む項はすべて消え，

```math
\left.
\frac{\partial^2}{\partial T^2}
\left(\frac{\alpha^2}{\beta}\right)
\right|_{T=T_c}
=\frac{2\{\alpha'(T_c)\}^2}{\beta(T_c)}
```

となる．
また，式 (5) より，

```math
\alpha'(T_c)=\frac{1}{A}
```

である．
したがって，

```math
\begin{aligned}
C_{T_c-0}
&=C_{T_c+0}
+\frac{3T_c}{2}
\frac{2}{A^2\beta(T_c)}\\
&=C_{T_c+0}
+\frac{3T_c}{A^2\beta(T_c)}.
\end{aligned}
```

よって，比熱の不連続量を解答例と同じく，

```math
\Delta C=C_{T_c-0}-C_{T_c+0}
```

と定義すると，

```math
\boxed{
\Delta C=\frac{3T_c}{A^2\beta(T_c)}
}
\tag{11}
```

を得る．
$\beta(T_c)>0$ であるため， $\Delta C>0$ である．
したがって，このモデルでは Curie 温度の低温側の比熱が高温側よりも大きい．

### 6．結論

Curie-Weiss の法則から，Landau 自由エネルギー展開における二次の係数は，

```math
\alpha(T)=\frac{T-T_c}{A}
```

と決まる．
この係数は Curie 温度でゼロとなり，その上下で符号が反転する．
その結果， $T<T_c$ では磁化ゼロの状態が不安定となり，二つの安定な自発磁化 $M=\pm M_s$ が現れる．
その大きさは Curie 温度の近傍で，

```math
M_s\simeq
\left\{
\frac{6(T_c-T)}{A\beta(T_c)}
\right\}^{1/2}
```

となる．

また，平衡自由エネルギーは Curie 温度で連続であり，その一階温度微分も連続であるため，エントロピーは連続である．
しかし，二階温度微分には不連続が生じるため，比熱には有限の跳びが現れる．
その大きさは，

```math
\boxed{
C_{T_c-0}-C_{T_c+0}
=\frac{3T_c}{A^2\beta(T_c)}
}
```

で与えられる．
以上が，Landau の熱力学的理論による自発磁化と Curie 温度における比熱の不連続の説明である．
