# 演習問題【4-B-31】

## 解答

### 1．Gibbs 自由エネルギーと圧力の関係

物質量一定の単純圧縮系について，Gibbs 自由エネルギー $G$ の全微分は，

```math
dG=-S\,dT+V\,dp
```

である．

温度を一定に保つ等温過程では，

```math
dT=0
```

なので，

```math
dG=V\,dp
```

となる．
したがって，滑らかな単一相の状態枝に沿って，

```math
\boxed{
\left(\frac{\partial G}{\partial p}\right)_T=V
}
\tag{1}
```

が成立する．

体積は正であるから，

```math
V>0
```

より，

```math
\boxed{
\left(\frac{\partial G}{\partial p}\right)_T>0
}
\tag{2}
```

となる．
すなわち，気相であっても液相であっても，圧力の増加に伴って Gibbs 自由エネルギーは増加する．

また，式（1）は，気相枝と液相枝をそれぞれ区別して適用する必要がある．
臨界温度以下では，同じ温度・圧力に対して複数の体積が対応する場合があり， $V$ を全領域で単一値関数として扱うことはできないからである．

以下では，温度を一定に保ち，常に安定な平衡状態を選ぶ準静的な過程を考える．
また，巨視的な系を対象とし，気液界面の自由エネルギーは無視する．

### 2．van der Waals 状態方程式と臨界点

van der Waals 状態方程式は，

```math
p=\frac{nRT}{V-nb}-\frac{n^2a}{V^2}
\tag{3}
```

で与えられる．
ここで， $n$ は物質量， $R$ は気体定数， $a,b$ は van der Waals 定数である．

モル体積

```math
v=\frac{V}{n}
```

を導入すると，

```math
\boxed{
p=\frac{RT}{v-b}-\frac{a}{v^2}
}
\tag{4}
```

と書ける．

臨界点では，等温線が水平な変曲点を持つため，

```math
\left(\frac{\partial p}{\partial v}\right)_T=0,
\qquad
\left(\frac{\partial^2p}{\partial v^2}\right)_T=0
\tag{5}
```

が成立する．

式（4）を微分すると，

```math
\left(\frac{\partial p}{\partial v}\right)_T
=
-\frac{RT}{(v-b)^2}
+\frac{2a}{v^3}
\tag{6}
```

および，

```math
\left(\frac{\partial^2p}{\partial v^2}\right)_T
=
\frac{2RT}{(v-b)^3}
-\frac{6a}{v^4}
\tag{7}
```

を得る．

式（5）～（7）を連立して解くと，

```math
v_c=3b
```

```math
p_c=\frac{a}{27b^2}
```

```math
\boxed{
T_c=\frac{8a}{27Rb}
}
\tag{8}
```

となる．

したがって，臨界温度以下の $T<T_c$ では，van der Waals 等温線は極大と極小を持つ．

この等温線には，次の三つの領域が存在する．

1. 液相側の低体積領域．
2. 気相側の高体積領域．
3. それらの間にある中間領域．

中間領域では，

```math
\left(\frac{\partial p}{\partial v}\right)_T>0
```

となる．
等温圧縮率

```math
\kappa_T
=
-\frac{1}{v}
\left(\frac{\partial v}{\partial p}\right)_T
```

を考えると，この領域では $\kappa_T<0$ となり，機械的に不安定である．

一方，等温線の外側の二つの枝では，

```math
\left(\frac{\partial p}{\partial v}\right)_T<0
```

となり，機械的な局所安定性を持つ．
ただし，この二つの枝のうち，どちらが真の安定平衡相となるかは，Gibbs 自由エネルギーを比較して決めなければならない．

### 3．Maxwell の等面積則と気液相平衡

温度 $T<T_c$ において，気相と液相が共存する圧力を飽和蒸気圧 $p_{\mathrm{sat}}$ とする．
気液共存の両端におけるモル体積をそれぞれ，

```math
v_l,\qquad v_g
```

とする．
ここで，

```math
v_l<v_g
```

である．

純物質の気液平衡では，両相の温度，圧力および化学ポテンシャルが等しくなる．
したがって，

```math
\boxed{
\mu_l(T,p_{\mathrm{sat}})
=
\mu_g(T,p_{\mathrm{sat}})
}
\tag{9}
```

が成立する．

一方，純物質のモル Gibbs 自由エネルギーは化学ポテンシャルに等しく，

```math
d\mu=-s\,dT+v\,dp
```

である．
温度一定では，

```math
d\mu=v\,dp
\tag{10}
```

となる．

これを van der Waals 等温線に沿って，液相側の体積 $v_l$ から気相側の体積 $v_g$ まで積分すると，

```math
\mu_g-\mu_l
=
\int_{v_l}^{v_g}
v\frac{dp}{dv}\,dv
```

である．
部分積分を用いれば，

```math
\begin{aligned}
\mu_g-\mu_l
&=
[vp]_{v_l}^{v_g}
-\int_{v_l}^{v_g}p(v,T)\,dv\\
&=
p_{\mathrm{sat}}(v_g-v_l)
-\int_{v_l}^{v_g}p(v,T)\,dv\\
&=
-\int_{v_l}^{v_g}
[p(v,T)-p_{\mathrm{sat}}]\,dv
\end{aligned}
```

となる．

式（9）の気液平衡条件を適用すると，

```math
\mu_g-\mu_l=0
```

であるから，

```math
\boxed{
\int_{v_l}^{v_g}
[p(v,T)-p_{\mathrm{sat}}]\,dv=0
}
\tag{11}
```

を得る．

これが Maxwell の等面積則である．
すなわち，van der Waals 等温線と飽和圧力の水平線との間にできる二つの面積が等しくなるように，飽和圧力を定める．

この規則によって，気相と液相の化学ポテンシャルが等しくなる圧力が決定され，実際の安定な気液共存状態が定まる．

### 4．気相枝と液相枝の Gibbs 自由エネルギー

気相および液相の Gibbs 自由エネルギーをそれぞれ，

```math
G_g=G_g(T,p),
\qquad
G_l=G_l(T,p)
```

と表す．

式（1）より，それぞれの相の圧力に対する微分は，

```math
\boxed{
\left(\frac{\partial G_g}{\partial p}\right)_T
=V_g>0
}
\tag{12}
```

```math
\boxed{
\left(\frac{\partial G_l}{\partial p}\right)_T
=V_l>0
}
\tag{13}
```

である．

気相の体積は液相の体積より大きいため，

```math
V_g>V_l>0
\tag{14}
```

である．

したがって，両相の Gibbs 自由エネルギーの差について，

```math
\frac{\partial(G_g-G_l)}{\partial p}
=
V_g-V_l>0
\tag{15}
```

となる．

気液共存圧力では，式（9）より，

```math
G_g(T,p_{\mathrm{sat}})
=
G_l(T,p_{\mathrm{sat}})
\tag{16}
```

である．

式（15），（16）から，気液両相が候補となる圧力範囲では，

```math
p<p_{\mathrm{sat}}
\quad\Longrightarrow\quad
G_g<G_l
```

および，

```math
p>p_{\mathrm{sat}}
\quad\Longrightarrow\quad
G_l<G_g
```

となる．

温度と圧力を一定に保つ条件で安定な相は，Gibbs 自由エネルギーが最小となる相である．
したがって，

- $p<p_{\mathrm{sat}}$ では気相が安定である．
- $p=p_{\mathrm{sat}}$ では気相と液相の Gibbs 自由エネルギーが等しく，共存する．
- $p>p_{\mathrm{sat}}$ では液相が安定である．

これにより，安定相が気相から液相へ切り替わることが分かる．

なお，気相または液相の準安定枝は，安定相でなくなった後も局所的な状態として存在し得る．
しかし，安定平衡を考える場合は，Gibbs 自由エネルギーの小さい枝を採用する．
また，中間の機械的不安定枝は安定な平衡状態として採用しない．

### 5．圧力増加に伴う Gibbs 自由エネルギーの変化

温度一定で圧力を低い値から増加させる準静的過程を考える．

#### （1）気相の圧縮

圧力が飽和蒸気圧より低い間は，系は気相として存在する．
圧力が増加すると気相の体積は減少する．
このとき，

```math
\frac{dG_g}{dp}=V_g>0
```

なので，Gibbs 自由エネルギーは増加する．

気相はモル体積が大きいため， $p$-$G$ 図では比較的大きな傾きを持つ．

#### （2）飽和蒸気圧における気液共存

圧力が飽和蒸気圧 $p_{\mathrm{sat}}$ に達すると，気相の一部が液相へ変化し始める．
この間，温度と圧力は一定に保たれ，

```math
p=p_{\mathrm{sat}}
```

となる．

気液共存状態における全 Gibbs 自由エネルギーは，界面自由エネルギーを無視できる巨視的極限では，

```math
G=n_g\mu_g+n_l\mu_l
```

と表せる．
ここで， $n_g,n_l$ は気相と液相の物質量であり，

```math
n_g+n_l=n
```

である．

気液平衡では，

```math
\mu_g=\mu_l=\mu_{\mathrm{sat}}
```

なので，

```math
\begin{aligned}
G
&=n_g\mu_{\mathrm{sat}}
+n_l\mu_{\mathrm{sat}}\\
&=(n_g+n_l)\mu_{\mathrm{sat}}\\
&=n\mu_{\mathrm{sat}}
\end{aligned}
```

となる．
全物質量と温度，飽和圧力は一定であるから，

```math
\boxed{G=n\mu_{\mathrm{sat}}=\text{一定}}
\tag{17}
```

である．

したがって，液化が進み気相と液相の割合が変化しても，圧力と Gibbs 自由エネルギーは変化しない．

この間の状態は $p$-$G$ 図ではすべて同じ座標，

```math
\boxed{
(p,G)=(p_{\mathrm{sat}},n\mu_{\mathrm{sat}})
}
```

に対応する．
つまり，気液共存中の状態は， $p$-$G$ 図上では一点に重なる．
圧力が一定のまま体積が変化することと，Gibbs 自由エネルギーが一定となることは矛盾しない．

#### （3）液相の圧縮

気相がすべて液体に変化すると，系は液相のみとなる．
その後，さらに圧力を増加させると液体が圧縮される．

このとき，

```math
\frac{dG_l}{dp}=V_l>0
```

なので，Gibbs 自由エネルギーは再び増加する．

ただし，

```math
V_l<V_g
```

であるため，液相側の $p$-$G$ 曲線の傾きは気相側より小さい．

### 6．相転移点における Gibbs 自由エネルギーの形状

気相から液相への変化は一次相転移である．
気液共存圧力では，

```math
G_g(T,p_{\mathrm{sat}})
=
G_l(T,p_{\mathrm{sat}})
```

であるため，Gibbs 自由エネルギーは連続である．

一方，その左右からの微分係数は，

```math
\boxed{
\left(\frac{\partial G_{\mathrm{eq}}}{\partial p}\right)_{T,p\to p_{\mathrm{sat}}-}
=V_g
}
\tag{18}
```

および，

```math
\boxed{
\left(\frac{\partial G_{\mathrm{eq}}}{\partial p}\right)_{T,p\to p_{\mathrm{sat}}+}
=V_l
}
\tag{19}
```

となる．

ここで，

```math
V_g>V_l
```

であるため，気相側から液相側へ移ると，傾きは不連続に小さくなる．
したがって，安定平衡状態の Gibbs 自由エネルギーは，飽和圧力で連続であるが，一般に微分可能ではない．
この折れ曲がりは，気液一次相転移に対応している．

以上をまとめると，安定平衡の Gibbs 自由エネルギーは，

```math
\boxed{
G_{\mathrm{eq}}(p,T)=
\begin{cases}
G_g(p,T),&p<p_{\mathrm{sat}},\\[2mm]
n\mu_{\mathrm{sat}},&p=p_{\mathrm{sat}},\\[2mm]
G_l(p,T),&p>p_{\mathrm{sat}}
\end{cases}
}
\tag{20}
```

と表せる．

この曲線は全体として圧力とともに増加するが，飽和圧力で傾きが気相の体積から液相の体積へ不連続に変化する．

### 7．van der Waals 等温線から得られる複数の枝との違い

van der Waals 状態方程式をそのまま用いると，臨界温度以下では気相枝，液相枝，中間の不安定枝が得られる．
同じ圧力に複数の体積が対応する場合があるため，これらをすべて安定な平衡状態とみなすことはできない．

気相枝と液相枝のうち，その圧力で Gibbs 自由エネルギーが小さい方が安定相であり，大きい方は準安定相となり得る．
中間の枝は機械的に不安定である．Maxwell の等面積則は，気液両相の Gibbs 自由エネルギーが等しくなる飽和圧力を決め，安定相が切り替わる位置を定める．

なお，枝ごとに Gibbs 自由エネルギーが定義される滑らかな範囲では，

```math
\frac{dG}{dp}=V>0
```

である．
したがって，正の体積を持つ枝において，圧力の増加に伴って Gibbs 自由エネルギーが減少する部分は存在しない．
枝の多価性や折り返しは，Gibbs 自由エネルギーが圧力に対して多価となることを意味し，負の傾きを意味するものではない．

### 8．結論

臨界温度以下では，van der Waals 状態方程式の等温線に極大と極小が現れ，気相と液相に対応する異なる状態枝が存在する．
安定な平衡状態は Gibbs 自由エネルギーが最小となる枝によって決まる．

温度一定で圧力を増加させると，

1. 飽和蒸気圧より低い領域では，気相が圧縮され，Gibbs 自由エネルギーは増加する．
2. 飽和蒸気圧では気相と液相が共存し，液化が進んでも圧力と Gibbs 自由エネルギーは一定である．
したがって， $p$-$G$ 図では一点に対応する．
3. すべての気体が液体に変化した後は，液相が圧縮され，Gibbs 自由エネルギーは再び増加する．

したがって，安定平衡の $p$-$G$ 曲線は，気相側では大きな正の傾きを持ち，飽和蒸気圧で連続ながら傾きが不連続に小さくなり，液相側では小さな正の傾きを持つ．
この変化が，臨界温度以下における気液一次相転移に対応する．
