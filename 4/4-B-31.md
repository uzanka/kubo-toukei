# 演習問題【4-B-31】

## 解答

### 1．Gibbs 自由エネルギーと圧力の関係

温度 $T$ ，圧力 $p$ ，体積 $V$ ，エントロピー $S$ の系について，Gibbs 自由エネルギー $G$ の微分は

```math
dG=-S\,dT+V\,dp
```

で与えられる．
温度を一定に保つ等温過程では $dT=0$ であるから，

```math
dG=V\,dp
```

となる．
したがって，

```math
\boxed{
\left(\frac{\partial G}{\partial p}\right)_T=V
}
```

である．
これが本問題の基本となる関係式である．

圧力を $p_1$ から $p_2$ まで変化させたとき，Gibbs 自由エネルギーの変化は

```math
G(p_2,T)-G(p_1,T)
=\int_{p_1}^{p_2}V(p,T)\,dp
```

となる．
つまり， $G$ の圧力依存性は，van der Waals 状態方程式から得られる等温線 $V(p,T)$ を積分することによって求められる．

ここで重要なのは，通常の気体や液体では体積 $V$ は正であるという点である．
したがって，圧力を増加させると，

```math
dp>0,\qquad dG=V\,dp>0
```

となる．
**体積が正である限り，平衡状態の $G$ は圧力の増加とともに増加する** のである．

### 2．van der Waals 状態方程式と臨界温度

van der Waals 状態方程式は，

```math
p=\frac{nRT}{V-nb}-\frac{n^2a}{V^2}
```

で与えられる．
ここで， $n$ は物質量， $R$ は気体定数， $a$ は分子間引力の効果， $b$ は分子の有限の大きさを表す定数である．

この状態方程式の臨界温度は，

```math
T_c=\frac{8a}{27Rb}
```

である．
臨界温度より低い $T<T_c$ では，van der Waals の等温線は $p$-$V$ 図において極大と極小を持つ．
この形状は，気体から液体への相転移に関係している．

ただし，van der Waals 状態方程式をそのまま用いて得られる等温線には，安定な平衡状態だけでなく，準安定状態や不安定状態に対応する部分も含まれる．
そのため，実際に観測される相変化を説明するには，安定な平衡状態を選び出す必要がある．

### 3．Maxwell の規則と気液相平衡

$T<T_c$ では，圧力を増加させると気体は圧縮され，やがて液化が始まる．
実際の気液相平衡では，気相と液相の Gibbs 自由エネルギーが平衡条件を満たす必要がある．
純物質の気液共存では，両相のモル Gibbs 自由エネルギー，すなわち化学ポテンシャルが等しい．

```math
\mu_{\mathrm{gas}}(T,p_{\mathrm{sat}})
=
\mu_{\mathrm{liq}}(T,p_{\mathrm{sat}})
```

ここで $p_{\mathrm{sat}}$ は，その温度における飽和蒸気圧である．

van der Waals 状態方程式から得られる等温線に対しては，この相平衡条件を満たす飽和圧力を求めるために Maxwell の規則を用いる．
$p$-$V$ 図では，van der Waals 等温線と $p=p_{\mathrm{sat}}$ の水平線に挟まれた2つの面積が等しくなるように水平線を定める．
この操作によって，数学的な等温線のうち，実際の気液共存に対応する部分が決まる．

### 4．圧力を増加させたときの Gibbs 自由エネルギー

$T<T_c$ で，系の温度を一定に保ちながら圧力を増加させる過程を考える．

#### (1) 気相の圧縮

圧力が飽和蒸気圧 $p_{\mathrm{sat}}$ より低いとき，系は気相として存在する．
圧力の増加とともに気体の体積は減少するが，体積は正であるため，

```math
\left(\frac{\partial G}{\partial p}\right)_T=V>0
```

に従い，Gibbs 自由エネルギーは増加する．

#### (2) 気液共存と液化

圧力が飽和蒸気圧 $p_{\mathrm{sat}}$ に達すると，気体の液化が始まる．
このとき，気相と液相が共存し，気相の一部が液相へと変化する．
温度と圧力は気液平衡を保つため一定であり，圧力は $p_{\mathrm{sat}}$ に保たれる．

この間，系全体の Gibbs 自由エネルギーは

```math
G=n_{\mathrm{gas}}\mu_{\mathrm{gas}}
+n_{\mathrm{liq}}\mu_{\mathrm{liq}}
```

と表される．
ここで $n_{\mathrm{gas}}$ と $n_{\mathrm{liq}}$ はそれぞれ気相と液相の物質量である．
気液平衡では $\mu_{\mathrm{gas}}=\mu_{\mathrm{liq}}=\mu_{\mathrm{sat}}$ であるから，

```math
G=(n_{\mathrm{gas}}+n_{\mathrm{liq}})\mu_{\mathrm{sat}}
=n\mu_{\mathrm{sat}}
```

となる．
全物質量 $n$ が一定であるため，液化が進んで気相と液相の割合が変化しても，系全体の Gibbs 自由エネルギーは一定である．

したがって， $p$-$G$ 図では，気液共存の過程における気相側の点と液相側の点は同じ点に重なる．
**これは，Gibbs 自由エネルギーが圧力に対して水平に変化する区間が生じることを意味するのではなく，気液共存中は圧力も Gibbs 自由エネルギーも一定であるため，図上では1つの点に対応することを意味する** ．

#### (3) 液相の圧縮

すべての気体が液体になると，系は液相のみとなる．
その後さらに圧力を増加させると，液体は圧縮され，Gibbs 自由エネルギーは再び増加する．このときも，

```math
\left(\frac{\partial G}{\partial p}\right)_T=V>0
```

が成り立つ．

ただし，液体の体積は気体の体積よりはるかに小さいため， $G$ の圧力に対する傾きも気相の場合より小さくなる．

### 5．結論

臨界温度以下では，圧力を徐々に増加させると，系は気相として圧縮され，飽和蒸気圧 $p_{\mathrm{sat}}$ で液化を開始する．
液化の間は気液共存状態となり，温度と圧力が一定に保たれ，系全体の Gibbs 自由エネルギーも一定である．
すべての気体が液体になった後は，液体の圧縮に伴って Gibbs 自由エネルギーが再び増加する．

したがって，安定な平衡状態に対応する $p$-$G$ 曲線は，気相の領域で増加し，飽和蒸気圧で傾きが大きく変わり，液相の領域でも増加する．
気体のモル体積は液体のモル体積より大きいため，気相側の傾きの方が大きい．

なお，問題文の右図に示されたような，圧力の増加に伴って $G$ が減少する部分は，正の体積を持つ平衡状態の $G(p,T)$ とは整合しない．
実際， $(\partial G/\partial p)_T=V>0$ であるため，そのような落ち込みを安定な平衡状態の Gibbs 自由エネルギー曲線として解釈することはできない．
van der Waals 状態方程式から得られる非物理的な枝と，Maxwell の規則を適用した安定な平衡曲線とを区別する必要がある．
