# 演習問題【4-A-19】

## 解答

### 1．液相と固相における溶媒の化学ポテンシャル

溶媒を成分1，溶質を成分2とする．
溶液から結晶が析出し，液相と固相が平衡状態にあるとき，溶媒の化学ポテンシャルは両相で等しい．
したがって，

```math
\bar G_l(T,x_2)=\bar G_s(T,x_2')
\tag{1}
```

が成り立つ．
ここで， $x_2$ は液相中の溶質のモル分率， $x_2'$ は固相中の溶質のモル分率である．
また， $\bar G_l$ と $\bar G_s$ は，それぞれ液相と固相における溶媒の化学ポテンシャルを表す．

問題の条件より，固相中の溶質濃度は液相中の溶質濃度に比例し，

```math
x_2'=kx_2
\tag{2}
```

である．
ここで， $k$ は一般に温度に依存する分配係数である．

### 2．希薄溶液の近似を用いる

液相と固相をそれぞれ理想希薄溶液，理想希薄混晶とみなす．
溶媒のモル分率を液相で $x_1$ ，固相で $x_1'$ とすると，

```math
x_1=1-x_2,\qquad x_1'=1-x_2'
```

である．
溶質が希薄であり， $x_2\ll1$ ， $x_2'\ll1$ と仮定すると，対数関数の近似

```math
\ln(1-y)\approx-y\qquad (y\ll1)
```

を使うことができる．
したがって，

```math
\ln x_1=\ln(1-x_2)\approx-x_2
```

および

```math
\ln x_1'=\ln(1-x_2')\approx-x_2'
```

となる．

理想溶液では，溶媒の化学ポテンシャルは純粋な溶媒の化学ポテンシャルに $RT\ln x_1$ を加えた形で表される．
よって，液相では

```math
\bar G_l(T,x_2)
=\bar G_l^0(T)+RT\ln x_1
\approx\bar G_l^0(T)-RTx_2
```

となる．
同様に，固相では

```math
\bar G_s(T,x_2')
=\bar G_{1s}^0(T)+RT\ln x_1'
\approx\bar G_{1s}^0(T)-RTx_2'
```

である．
ここで， $\bar G_l^0(T)$ は純粋な液体の溶媒の化学ポテンシャル， $\bar G_{1s}^0(T)$ は純粋な固体の溶媒の化学ポテンシャルである．

これらを平衡条件 (1) に代入すると，

```math
\bar G_l^0(T)-RTx_2
=
\bar G_{1s}^0(T)-RTx_2'
```

となる．
式 (2) の $x_2'=kx_2$ を用いて整理すれば，

```math
\boxed{
\bar G_l^0(T)-\bar G_{1s}^0(T)
=RT(1-k)x_2
}
\tag{3}
```

を得る．
この式は，溶液から固相が析出する温度を決める条件である．

### 3．純粋な溶媒の氷点を基準にする

純粋な溶媒の融点，すなわち氷点を $T_f^0$ とする．
この温度では純粋な液相と固相が平衡にあるため，

```math
\bar G_l^0(T_f^0)=\bar G_{1s}^0(T_f^0)
```

であり，

```math
\bar G_l^0(T_f^0)-\bar G_{1s}^0(T_f^0)=0
\tag{4}
```

となる．

溶液から固相が析出する温度を $T_f$ とし，純粋な溶媒の氷点からの変化を

```math
\Delta T_f=T_f-T_f^0
```

と定義する．
希薄溶液では氷点の変化も小さいため， $\Delta T_f$ を微小量として，化学ポテンシャルを $T_f^0$ の周りで一次まで展開する．

温度一定ではなく圧力一定の条件で，化学ポテンシャルは

```math
\left(\frac{\partial\bar G}{\partial T}\right)_p=-\bar S
```

を満たす．
したがって，

```math
\bar G_l^0(T_f)
\approx
\bar G_l^0(T_f^0)
-\Delta T_f\,\bar S_l^0(T_f^0)
```

および

```math
\bar G_{1s}^0(T_f)
\approx
\bar G_{1s}^0(T_f^0)
-\Delta T_f\,\bar S_{1s}^0(T_f^0)
```

である．
ここで， $\bar S_l^0$ と $\bar S_{1s}^0$ はそれぞれ純液体と純固体の溶媒のモルエントロピーである．

両式の差を取ると，

```math
\begin{aligned}
&\bar G_l^0(T_f)-\bar G_{1s}^0(T_f)\\
&\quad\approx
\bigl[\bar G_l^0(T_f^0)-\bar G_{1s}^0(T_f^0)\bigr]\\
&\qquad-\Delta T_f
\bigl[\bar S_l^0(T_f^0)-\bar S_{1s}^0(T_f^0)\bigr]
\end{aligned}
```

となる．
式 (4) より，角括弧の最初の項はゼロである．
したがって，

```math
\bar G_l^0(T_f)-\bar G_{1s}^0(T_f)
\approx
-\Delta T_f
\bigl(\bar S_l^0-\bar S_{1s}^0\bigr)
\tag{5}
```

を得る．
右辺のエントロピーは，特に断らない限り $T_f^0$ における値を表す．

### 4．融解熱を用いて氷点の変化を求める

純溶媒が固体から液体へ融解するときのモル融解熱を $\bar L_1$ とする．
相転移温度 $T_f^0$ では，

```math
\bar L_1
=
T_f^0\bigl(\bar S_l^0-\bar S_{1s}^0\bigr)
```

が成り立つ．
よって，

```math
\bar S_l^0-\bar S_{1s}^0
=\frac{\bar L_1}{T_f^0}
```

である．
これを式 (5) に代入すると，

```math
\bar G_l^0(T_f)-\bar G_{1s}^0(T_f)
\approx
-\frac{\bar L_1}{T_f^0}\Delta T_f
\tag{6}
```

となる．

一方，式 (3) より，

```math
\bar G_l^0(T_f)-\bar G_{1s}^0(T_f)
=RT_f(1-k)x_2
```

である．
これと式 (6) を等置すると，

```math
-\frac{\bar L_1}{T_f^0}\Delta T_f
\approx RT_f(1-k)x_2
```

を得る．
ここで，右辺は $x_2$ に比例する一次の微小量であるため， $T_f=T_f^0+\Delta T_f$ の $RT_f$ に含まれる $\Delta T_f$ の寄与は $x_2\Delta T_f$ に比例する二次の項となり，無視できる．
したがって，右辺の $T_f$ を $T_f^0$ で置き換えると，

```math
-\frac{\bar L_1}{T_f^0}\Delta T_f
\approx RT_f^0(1-k)x_2
```

となる．
整理すれば，

```math
\boxed{
\frac{\Delta T_f}{T_f^0}
\approx
-\frac{RT_f^0}{\bar L_1}(1-k)x_2
}
\tag{7}
```

が得られる．
これが求める氷点の変化と溶質濃度との関係である．

### 5．結果の解釈

式 (7) から，氷点の変化 $\Delta T_f$ は溶質のモル分率 $x_2$ に一次比例することが分かる．
また，その符号は分配係数 $k$ によって決まる．

- $k<1$ の場合，溶質は液相に比べて固相に取り込まれにくい．このとき $1-k>0$ であるため， $\Delta T_f<0$ となり，氷点は降下する．
- $k=1$ の場合，液相と固相の溶質モル分率が等しい．この近似では $\Delta T_f=0$ となる．
- $k>1$ の場合，溶質は液相に比べて固相に取り込まれやすい．このとき $1-k<0$ であるため， $\Delta T_f>0$ となり，氷点は上昇する．

以上より，理想希薄溶液と理想希薄混晶の仮定の下では，氷点の変化は溶質のモル分率に比例し，その比例係数は溶媒の融解熱と液相・固相間の溶質の分配係数によって決まるのである．
