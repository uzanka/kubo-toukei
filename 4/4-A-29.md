# 演習問題【4-A-29】

## 解答

### 1．電子ガスと金属内部の電子の平衡条件

金属を高温にすると，金属表面から電子が放出され，金属外部に電子ガスが形成される．
金属と電子ガスの間で電子の移動が平衡に達している状態を考える．

本問では，問題文の意図に従い，金属と電子ガスとの間の電位差および空間電荷による電気的な寄与を無視する理想化を採用する．
したがって，電子の移動に関する平衡条件は，両者の化学ポテンシャルの一致として，

```math
\boxed{
\mu_e(T,p)=\mu_i=\text{一定}
}
\tag{1}
```

と表される．
ここで， $\mu_e$ は外部電子ガスのモル化学ポテンシャル， $\mu_i$ は金属内部の電子のモル化学ポテンシャルである．

また，外部電子ガスは，電子間相互作用を無視できる非縮退・非相対論的な単原子理想気体として扱う．
すなわち，古典的な Maxwell-Boltzmann 統計が適用できるものとする．
金属は測定温度範囲で金属相を維持し，金属内部の電子の化学ポテンシャルは一定であるとする．

### 2．電子ガスの化学ポテンシャル

単原子理想気体のモル化学ポテンシャルは，

```math
\mu_e
=
U_{e0}
+RT\ln\left(\frac{n\lambda_T^3}{g}\right)
\tag{2}
```

と表される．
ここで，

```math
\lambda_T=
\frac{h}{\sqrt{2\pi m_e k_{\mathrm B}T}}
```

は熱的ド・ブロイ波長， $n$ は電子の数密度， $g$ はスピンなどの内部自由度による縮退度である．
また， $U_{e0}$ はエネルギーの基準に対応する温度・圧力に依存しない定数である．

理想気体の状態方程式

```math
p=nk_{\mathrm B}T
```

から，

```math
n=\frac{p}{k_{\mathrm B}T}
```

である．
また，

```math
\lambda_T^3
=
\frac{h^3}{(2\pi m_e k_{\mathrm B}T)^{3/2}}
```

なので，

```math
\frac{n\lambda_T^3}{g}
=
\frac{p h^3}
{g(2\pi m_e)^{3/2}(k_{\mathrm B}T)^{5/2}}
```

となる．

基準温度 $T_0$ と基準圧力 $p_0$ を導入すると，

```math
\frac{n\lambda_T^3}{g}
=
\frac{p}{p_0}
\left(\frac{T_0}{T}\right)^{5/2}
\frac{p_0h^3}
{g(2\pi m_e)^{3/2}(k_{\mathrm B}T_0)^{5/2}}
```

と書ける．
ここで，

```math
i=
\ln\left[
\frac{g(2\pi m_e)^{3/2}(k_{\mathrm B}T_0)^{5/2}}
{p_0h^3}
\right]
\tag{3}
```

と定義すれば，

```math
\ln\left(\frac{n\lambda_T^3}{g}\right)
=
\ln\frac{p}{p_0}
-\frac52\ln\frac{T}{T_0}
-i
```

となる．
したがって，式（2）は，

```math
\boxed{
\mu_e(T,p)
=
U_{e0}
-\frac52RT\ln\frac{T}{T_0}
-RTi
+RT\ln\frac{p}{p_0}
}
\tag{4}
```

と表される．

ここで，すべての対数の引数は無次元である．
また， $i$ は基準温度 $T_0$ と基準圧力 $p_0$ に対応する無次元の化学定数である．

### 3．圧力 $p$ と温度 $T$ の関係

平衡条件（1）に式（4）を代入すると，

```math
U_{e0}
-\frac52RT\ln\frac{T}{T_0}
-RTi
+RT\ln\frac{p}{p_0}
=
\mu_i
```

となる．
これを対数項について整理すれば，

```math
RT\ln\frac{p}{p_0}
=
\mu_i-U_{e0}
+\frac52RT\ln\frac{T}{T_0}
+RTi
```

である．
両辺を $RT$ で割ると，

```math
\ln\frac{p}{p_0}
=
\frac{\mu_i-U_{e0}}{RT}
+\frac52\ln\frac{T}{T_0}
+i
```

を得る．

ここで，

```math
W=U_{e0}-\mu_i
\tag{5}
```

とおく．
$U_{e0}$ と $\mu_i$ は一定であるから， $W$ も一定である．
したがって，

```math
\ln\frac{p}{p_0}
=
-\frac{W}{RT}
+\frac52\ln\frac{T}{T_0}
+i
```

となる．
対数の性質を用いて整理すると，

```math
\boxed{
\ln\left[
\frac{p/p_0}{(T/T_0)^{5/2}}
\right]
=
i-\frac{W}{RT}
}
\tag{6}
```

を得る．

指数関数で表せば，

```math
\boxed{
p=p_0\left(\frac{T}{T_0}\right)^{5/2}
\exp\left(i-\frac{W}{RT}\right)
}
\tag{7}
```

である．

### 4．圧力の温度変化から化学定数 $i$ を求める

式（6）を測定値から直線を描ける形に変形する．

```math
x=\frac1T,
\qquad
y=\ln\left[
\frac{p/p_0}{(T/T_0)^{5/2}}
\right]
```

とおくと，

```math
\boxed{
y=-\frac WRx+i
}
\tag{8}
```

となる．
これは，

```math
y=ax+b
```

という一次関数の形であり，傾きは $-W/R$ ，縦軸との切片は $i$ である．

したがって，複数の温度 $T$ において，金属と平衡にある電子ガスの圧力 $p$ を測定し，横軸を $1/T$ ，縦軸を

```math
\ln\left[
\frac{p/p_0}{(T/T_0)^{5/2}}
\right]
```

とするグラフを描けば，直線の切片から化学定数 $i$ を求めることができる．
この方法では，定数 $W$ の値をあらかじめ知る必要はない．
複数の測定値から傾きと切片を同時に決定すればよい．

なお，統計力学的なモデルで $g$ ， $T_0$ ， $p_0$ などが既知であれば，式（3）から $i$ を理論的にも計算できる．
圧力の温度依存性の測定は，その値を実験的に決定し，理論値と比較する方法にもなる．

縦軸切片は $1/T=0$ に対応する数学的な外挿値である．実際に無限大の温度で測定することを意味しない．
実際の測定では，金属相が維持され，電子ガスが古典的理想気体として近似できる有限の温度範囲でデータを取得し，その範囲で成立する直線関係を用いて切片を推定する．

### 5．結論

金属内部の電子の化学ポテンシャルが一定であり，電位差による寄与を無視できる理想化のもとでは，金属と電子ガスの平衡条件から，

```math
\boxed{
\ln\left[
\frac{p/p_0}{(T/T_0)^{5/2}}
\right]
=
i-\frac{W}{RT}
}
```

が導かれる．

したがって，

```math
\boxed{
y=-\frac WRx+i,
\qquad
x=\frac1T,\quad
y=\ln\left[
\frac{p/p_0}{(T/T_0)^{5/2}}
\right]
}
```

という直線関係が成立する．
その縦軸切片が化学定数 $i$ である．

よって，金属と平衡にある電子ガスの圧力の温度依存性を測定し，直線近似によって切片を求めることで，電子の化学定数 $i$ を決定できる．
