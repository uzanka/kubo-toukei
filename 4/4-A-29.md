# 演習問題【4-A-29】

## 解答

**【問題の整理】**

金属が十分に高温になると，電子が放出されて金属の外部に「電子ガス」が形成される．
この問題では，以下の条件が与えられている．
1. 金属内部の電子の化学ポテンシャル $\overline{G}_i$ は，一定であると仮定する．
2. 金属内部の電子と，外部の電子ガスが熱平衡状態にある（ $\overline{G}_e = \overline{G}_i$ ）．
3. 外部の電子ガスの化学ポテンシャル $\overline{G}_e$ は，温度 $T$ と圧力 $p$ を用いて次のように表される：
$$\overline{G}_e(T, p) = U_{e0} - \frac{5}{2} RT \log T - RTi + RT \log p$$
ここで， $R$ は気体定数， $U_{e0}$ は定数， $i$ は求めるべき「化学定数」である．

これらを用いて，外部電子ガスの圧力 $p$ の温度変化を測定することで，定数 $i$ を求めることができることを示す．

**【導出過程】**

1. **熱平衡条件の適用**
   金属内部と外部が熱平衡にあるとき，両者の化学ポテンシャルは等しくなる．
   $$\overline{G}_e = \overline{G}_i$$
   与えられた $\overline{G}_e$ の式を代入すると，
   $$U_{e0} - \frac{5}{2} RT \log T - RTi + RT \log p = \overline{G}_i$$

2. **圧力 $p$ に関する式への変形**
   未知の定数 $i$ を含む式を整理するために， $\log p$ を含む項を左辺に残し，それ以外を右辺に移項する．
   $$RT \log p = \overline{G}_i - U_{e0} + \frac{5}{2} RT \log T + RTi$$

   両辺を $RT$ で割る．
   $$\log p = \frac{\overline{G}_i - U_{e0}}{RT} + \frac{5}{2} \log T + i$$

3. **定数の整理**
   ここで， $W = U_{e0} - \overline{G}_i$ と置く．
   $U_{e0}$ と $\overline{G}_i$ はともに定数なので， $W$ も定数である．
   すると，上式は次のように書き換えられる．
   $$\log p = -\frac{W}{RT} + \log(T^{5/2}) + i$$

4. **変数の分離と線形関係の導出**
   測定可能な値である圧力 $p$ と温度 $T$ の関係をより分かりやすくするために，両辺から $\log(T^{5/2})$ を引く．
   $$\log p - \log(T^{5/2}) = i - \frac{W}{RT}$$
   対数の性質 ( $\log A - \log B = \log \frac{A}{B}$ ) を用いると，
   $$\log \left( \frac{p}{T^{5/2}} \right) = i - \frac{W}{RT}$$

5. **実験的な決定方法**
   ここで， $y = \log \left( \frac{p}{T^{5/2}} \right)$ ， $x = \frac{1}{T}$ と置くと，式は次のような一次関数の形になる．
   $$y = -W x + i$$
   これは，縦軸を $y$ ，横軸を $x$ としたグラフにおいて，傾きが $-W$ ，切片が $i$ である直線を表している．

   したがって，異なる温度 $T$ において電子ガスの圧力 $p$ を測定し， $\left(\frac{1}{T}, \log \frac{p}{T^{5/2}}\right)$ の関係をグラフにプロット（描画）すれば，その直線の縦軸との交点（ $x=0$ すなわち $T \to \infty$ のときの値）から，求めるべき化学定数 $i$ を直接得ることができる．

   $$\lim_{T \to \infty} \log \left( \frac{p}{T^{5/2}} \right) = i$$

以上により，圧力の温度変化を測定することで化学定数 $i$ がわかることが示された．

## 解説

### 1. 化学ポテンシャルとは？

化学ポテンシャルとは，物質の「化学的な圧力」のようなもので，粒子（ここでは電子）が移動しようとする傾向を示す量である．
物質が熱平衡状態にあるとき，異なる相（金属内部と外部のガス）の間でこの化学ポテンシャルは等しくなる．

### 2. なぜこの式変形を行うのか？

実験で直接測定できるのは「圧力 $p$」と「温度 $T$」である．
しかし，求めたい定数 $i$ は複雑な式の中に隠れている．
数学的なテクニックとして，式を $y = ax + b$ という「直線」の形に変形することで，グラフの交点という非常に単純な方法で値を特定できるようにしている．

### 3. 変数の意味

- $R$: 気体定数．
  物理学や化学の計算で頻繁に現れる定数である．
- $T$: 絶対温度．
- $p$: 電子ガスの圧力．
- $W$: 金属内部のエネルギー状態に関連する定数．
- $i$: 今回の目的である「化学定数」．
  この値を知ることで，電子の状態に関するより深い物理的理解が得られる．
- $T^{5/2}$: 電子の運動エネルギーや状態密度に関わる，統計力学特有の温度依存性を示す項である．
