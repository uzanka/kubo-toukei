# 演習問題【4-A-29】

## 解答

### 1．金属内部と外部の電子の化学ポテンシャル

金属を十分に高温にすると，金属表面から電子が放出され，金属外部に電子ガスが形成される．
金属内部の電子と外部の電子ガスが平衡にあるとき，両者の化学ポテンシャルは等しい．

金属外部の電子ガスを単原子理想気体とみなすと，その化学ポテンシャルは，

```math
\overline G_e(T,p)
=U_{e0}-\frac52RT\ln T-RTi+RT\ln p
```

と表される．
ここで， $U_{e0}$ は定数， $R$ は気体定数， $T$ は絶対温度， $p$ は電子ガスの圧力， $i$ は求める化学定数である．
以下では，解答例と同じく，対数は自然対数とする．

一方，金属内部の電子の化学ポテンシャル $\overline G_i$ は，問題の仮定により一定である．
したがって，熱平衡条件は

```math
\overline G_e(T,p)=\overline G_i
```

である．
これに化学ポテンシャルの式を代入すると，

```math
U_{e0}-\frac{5}{2}RT\ln T-RTi+RT\ln p
=\overline G_i
```

となる．

### 2．圧力 $p$ と温度 $T$ の関係を導く

上式を $\ln p$ について整理すると，

```math
RT\ln p
=\overline G_i-U_{e0}
+\frac{5}{2}RT\ln T+RTi
```

である．
両辺を $RT$ で割ると，

```math
\ln p
=\frac{\overline G_i-U_{e0}}{RT}
+\frac{5}{2}\ln T+i
```

となる．
ここで，

```math
W=U_{e0}-\overline G_i
```

とおく．
$U_{e0}$ と $\overline G_i$ は一定であるから， $W$ も一定である．
したがって，

```math
\ln p=-\frac{W}{RT}+\frac52\ln T+i
```

を得る．
対数の性質を用いて整理すれば，

```math
\boxed{
\ln\frac{p}{T^{5/2}}
=i-\frac{W}{RT}
}
\tag{1}
```

となる．
さらに指数関数で表すと，

```math
\boxed{
p=e^iT^{5/2}e^{-W/(RT)}
}
```

である．
これにより，電子ガスの圧力 $p$ と温度 $T$ の関係が得られた．

### 3．圧力の温度変化から化学定数 $i$ を求める

式 (1) を，測定値から直線を描ける形に変形する．

```math
x=\frac1T,\qquad
y=\ln\frac{p}{T^{5/2}}
```

とおくと，式 (1) は

```math
\boxed{
y=-\frac WRx+i
}
\tag{2}
```

となる．
これは $y=ax+b$ という一次関数の形であり，傾きは $-W/R$ ，縦軸との切片は $i$ である．

したがって，異なる温度 $T$ において電子ガスの圧力 $p$ を測定し，横軸を $1/T$ ，縦軸を $\ln(p/T^{5/2})$ とするグラフを描けば，その直線の切片から化学定数 $i$ を求められる．
この方法では，定数 $W$ の値をあらかじめ知る必要はない．

式 (1) からも，

```math
\lim_{T\to\infty}\frac{W}{RT}=0
```

であるため，

```math
\boxed{
i=\lim_{T\to\infty}
\ln\frac{p}{T^{5/2}}
}
```

と表されることがわかる．
これは，グラフ上では $1/T\to0$ に外挿したときの縦軸との切片に相当する．
実際の測定では有限の温度範囲のデータから直線を求め，その切片を推定する．

以上より，金属と平衡にある電子ガスの圧力の温度依存性を測定することで，化学定数 $i$ を決定できることが示された．
