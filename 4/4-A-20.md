# 演習問題【4-A-20】

## 解答

### 1. 設定の整理

2種類の金属 1, 2 があり，それぞれの融点 $T_1, T_2$ および融解熱 $L_1, L_2$ を持つとする．
問題の条件より，以下のことがわかる．
- **液相**： 2成分がよく混ざり合う「理想溶液」を形成する．
- **固相**： 成分1と成分2は全く混ざり合わない（純粋な成分1の固相と，純粋な成分2の固相が独立して存在する）．
- **融解熱**： $L_i$ は温度 $T$ に依存せず一定であるとみなす．

### 2. 平衡条件の記述

ある温度 $T$ において，液相と固相が平衡状態にあるとき，各成分の化学ポテンシャルは等しくなければならない．
成分 $i$ ( $i=1, 2$ ) について，液相における化学ポテンシャルを $`\bar{G}_{il}^0`$ ，固相における化学ポテンシャルを $`\bar{G}_{is}^0`$ とすると，平衡条件は次のように書ける．

$$\bar{G}_{il}^0 + RT \ln x_{il} = \bar{G}_{is}^0 \quad \cdots (1)$$

ここで， $x_{il}$ は液相中の成分 $i$ のモル分率である．
これを変形すると，

$$RT \ln x_{il} = \bar{G}_{is}^0 - \bar{G}_{il}^0$$

$$\ln x_{il} = \frac{\bar{G}_{is}^0 - \bar{G}_{il}^0}{RT} \quad \cdots (2)$$

となる．
ここで $`\lambda_i = \frac{\bar{G}_{is}^0 - \bar{G}_{il}^0}{RT}`$ と定義する．

### 3. 化学ポテンシャルの温度依存性の導出

ギブス・ヘルムホルツの式 $\left( \frac{\partial (G/T)}{\partial (1/T)} \right)_P = -H$ を用いて， $\lambda_i$ の温度依存性を求める．
$\lambda_i$ の微分の形を考えるために， $1/T$ を変数として微分を行う．

$$\frac{d\lambda_i}{d(1/T)} = \frac{1}{R} \frac{d}{d(1/T)} \left( \frac{\bar{G}_{is}^0 - \bar{G}_{il}^0}{T} \right)$$

ギブス・ヘルムホルツの式より，

$$\frac{d}{d(1/T)} \left( \frac{\bar{G}_{is}^0 - \bar{G}_{il}^0}{T} \right) = - (\bar{H}_{is}^0 - \bar{H}_{il}^0)$$

ここで， $`\bar{H}_{il}^0 - \bar{H}_{is}^0 = L_i`$ は成分 $i$ の融解熱（固相 $\to$ 液相）であるから， $`\bar{H}_{is}^0 - \bar{H}_{il}^0 = -L_i`$ である．
したがって，

$$\frac{d\lambda_i}{d(1/T)} = \frac{1}{R} (-(-L_i)) = \frac{L_i}{R}$$

となる．
これを $1/T_i$ から $1/T$ まで積分する．
なお， $T=T_i$ のとき純粋物質の融点では $`\bar{G}_{is}^0 = \bar{G}_{il}^0`$ であるから， $`\lambda_i(1/T_i) = 0`$ である．

$$\lambda_i = \int_{1/T_i}^{1/T} \frac{L_i}{R} d(1/T') = \frac{L_i}{R} \left[ \frac{1}{T'} \right]_{1/T_i}^{1/T} = \frac{L_i}{R} \left( \frac{1}{T} - \frac{1}{T_i} \right)$$

ここで， $u = 1/T$ と置換すると $du = -dT/T^2$ であるから，これを $T$ で直接積分し直す．
融解熱 $L_i$ は温度に依存しないので，

$$\lambda_i = \int_{T_i}^{T} \frac{L_i}{RT^2} dT = \frac{L_i}{R} \left[ -\frac{1}{T} \right]_{T_i}^{T} = \frac{L_i}{R} \left( \frac{1}{T_i} - \frac{1}{T} \right)$$

これを整理すると，

$$\lambda_i = \frac{L_i T_i}{RT_i} \left( \frac{T - T_i}{T_i T} \right) = \frac{L_i}{RT_i} \left( 1 - \frac{T_i}{T} \right)$$

ここで， $\alpha_i = L_i / RT_i$ とおくと，

$$\lambda_i = \alpha_i \left( 1 - \frac{T_i}{T} \right)$$
これより，液相線の方程式は，

```math
x_{1l} = \exp \left\{ \alpha_1 \left(1 - \frac{T_1}{T}\right) \right\} \quad \cdots (3a)
```

```math
x_{2l} = \exp \left\{ \alpha_2 \left(1 - \frac{T_2}{T}\right) \right\} \quad \cdots (3b)
```

となる．

### 4. 共融点 (Eutectic Point) の決定

液相において，成分 1 と成分 2 のモル分率の和は 1 である（ $x_{1l} + x_{2l} = 1$ ）．
共融点 E は，成分 1 の液相線と成分 2 の液相線が交わる点である．
そのときの温度を $T_E$ ，成分比を $x_{1E}, x_{2E}$ とすると，

$$x_{1E} + x_{2E} = 1$$

式 (3a), (3b) を代入して，

```math
\exp \left\{ \alpha_1 \left(1 - \frac{T_1}{T_E}\right) \right\} + \exp \left\{ \alpha_2 \left(1 - \frac{T_2}{T_E}\right) \right\} = 1 \quad \cdots (4)
```

が得られる．
この方程式を解くことで，共融温度 $T_E$ が定まる．
共融点における成分比は，求まった $T_E$ を用いて次のように求められる．

```math
x_{1E} = \exp \left\{ \alpha_1 \left(1 - \frac{T_1}{T_E}\right) \right\}, \quad x_{2E} = \exp \left\{ \alpha_2 \left(1 - \frac{T_2}{T_E}\right) \right\}
```

### 5. まとめ：相図を定める方程式

相図における各領域（液相，固相 1，固相 2）の境界を定める方程式は以下の通りである．

- **成分 1 の固相と液相の境界 (液相線 1)** : ($x_{1l} \in [x_{1E}, 1]$)

```math
x_{1l} = \exp \left\{ \alpha_1 \left(1 - \frac{T_1}{T}\right) \right\}
```

- **成分 2 の固相と液相の境界 (液相線 2)** : ($x_{1l} \in [0, x_{1E}]$)

```math
1 - x_{1l} = \exp \left\{ \alpha_2 \left(1 - \frac{T_2}{T}\right) \right\}
```

- **共融点の共融温度 $T_E$** : ($T_E < \min(T_1, T_2)$，超越方程式のため数値求解が必要)

```math
\exp \left\{ \alpha_1 \left(1 - \frac{T_1}{T_E}\right) \right\} + \exp \left\{ \alpha_2 \left(1 - \frac{T_2}{T_E}\right) \right\} = 1
```

## 解説

### 1. 化学ポテンシャルの意味

化学ポテンシャル $\mu$ は，成分がその相に留まろうとする「安定性の指標」である．
平衡状態では，物質は化学ポテンシャルが等しい状態に分布しようとする．
液相と固相の境界では，液相中の成分の化学ポテンシャルと固相中の成分の化学ポテンシャルが一致しなければならない．

### 2. 理想溶液の仮定

「液相ではよく混ざり合い理想溶液を作る」という仮定は，成分間の相互作用が，成分同士の相互作用と成分単独の相互作用の平均と同じであることを意味する．
これにより，液相中の化学ポテンシャルに $\ln x_i$ という項（混合によるエントロピーの変化を表す項）を単純に加えることができる．

### 3. 固相が混ざり合わないことの影響

「固相では全く溶け合わない」という条件は，固相において成分 1 は純粋な成分 1 として，成分 2 は純粋な成分 2 としてのみ存在することを意味する．
もし固相でも混ざり合う（固溶体を作る）場合は，固相側の化学ポテンシャルにもモル分率の項が現れ，相図の形が大きく変わる．

### 4. 共融点 (Eutectic Point) の物理的イメージ

温度を下げていくと，ある温度（共融温度 $T_E$ ）で，液相が成分 1 と成分 2 の両方の固相と同時に平衡になる．
このとき，液相中の成分比がちょうど「成分 1 が固化し始めても，成分 2 が固化し始めてもよい」という絶妙なバランス（ $x_{1l} + x_{2l} = 1$ ）になった瞬間である．
これより温度が下がると，液相は存在できず，一気に固相 1 と固相 2 の混合物へと相転移する．
