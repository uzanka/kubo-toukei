# 演習問題【4-A-20】

## 解答

### 1．平衡条件

成分1，2の液相は理想溶液を形成し，固相では互いに溶け合わないものとする．
したがって，固相は純粋な成分1の固相と純粋な成分2の固相からなる．

温度 $T$ ，一定圧力のもとで，液相中の成分 $i$ のモル分率を $x_{il}$ とする．
液相が理想溶液であることから，成分 $i$ の液相における化学ポテンシャルは

```math
\mu_{il}=\bar G_{il}^{0}+RT\ln x_{il}
```

で表される．
ここで， $\bar G_{il}^{0}$ は純粋な成分 $i$ の液相におけるモルギブスエネルギー， $R$ は気体定数である．
また，純固相 $i$ の化学ポテンシャルは

```math
\mu_{is}=\bar G_{is}^{0}
```

である．

液相と固相 $i$ が平衡にあるとき，成分 $i$ の化学ポテンシャルは両相で等しい．
よって，

```math
\bar G_{il}^{0}+RT\ln x_{il}
=\bar G_{is}^{0}
```

となる．
これを整理すると，

```math
\ln x_{il}
=\frac{\bar G_{is}^{0}-\bar G_{il}^{0}}{RT}
```

を得る．
ここで，

```math
\lambda_i
=\frac{\bar G_{is}^{0}-\bar G_{il}^{0}}{RT}
```

と定義すれば，

```math
x_{il}=e^{\lambda_i}
\tag{1}
```

である．
以下では， $\lambda_i$ を温度 $T$ の関数として求める．

### 2．$\lambda_i$ の導出

ギブス・ヘルムホルツの式は，圧力一定のもとで

```math
\frac{d}{dT}\left(\frac{\bar G}{T}\right)
=-\frac{\bar H}{T^2}
```

と表される．
ここで， $\bar H$ はモルエンタルピーである．

この式を純固相 $i$ と純液相 $i$ にそれぞれ適用し，差を取ると，

```math
\begin{aligned}
&\frac{d}{dT}
\left(\frac{\bar G_{is}^{0}-\bar G_{il}^{0}}{T}\right)\\
&\qquad
=-\frac{\bar H_{is}^{0}-\bar H_{il}^{0}}{T^2}
\end{aligned}
```

となる．
成分 $i$ の融解熱を

```math
L_i=\bar H_{il}^{0}-\bar H_{is}^{0}
```

と定義すると，上式は

```math
\frac{d}{dT}
\left(\frac{\bar G_{is}^{0}-\bar G_{il}^{0}}{T}\right)
=\frac{L_i}{T^2}
\tag{2}
```

となる．

純粋な成分 $i$ の融点は $T_i$ である．
融点では純固相と純液相が平衡にあるため，

```math
\bar G_{is}^{0}(T_i)=\bar G_{il}^{0}(T_i)
```

が成り立つ．
そこで，式 (2) を $T_i$ から $T$ まで積分すると，

```math
\begin{aligned}
&\frac{\bar G_{is}^{0}(T)-\bar G_{il}^{0}(T)}{T}\\
&\quad-\frac{\bar G_{is}^{0}(T_i)-\bar G_{il}^{0}(T_i)}{T_i}
=\int_{T_i}^{T}\frac{L_i}{T'^2}\,dT'
\end{aligned}
```

を得る．
積分変数を $T'$ と表した．
融点ではギブスエネルギーの差がゼロであるから，

```math
\frac{\bar G_{is}^{0}(T)-\bar G_{il}^{0}(T)}{T}
=\int_{T_i}^{T}\frac{L_i}{T'^2}\,dT'
```

である．

問題の仮定より，融解熱 $L_i$ は温度によらず一定とみなせる．
したがって，

```math
\begin{aligned}
\lambda_i
&=\frac{\bar G_{is}^{0}-\bar G_{il}^{0}}{RT}\\
&=\frac{1}{R}\int_{T_i}^{T}\frac{L_i}{T'^2}\,dT'\\
&=\frac{L_i}{R}
\left(\frac{1}{T_i}-\frac{1}{T}\right)\\
&=\frac{L_i}{RT_i}
\left(1-\frac{T_i}{T}\right)
\end{aligned}
\tag{3}
```

となる．
ここで，

```math
\alpha_i=\frac{L_i}{RT_i}
```

とおくと，

```math
\boxed{
\lambda_i=\alpha_i\left(1-\frac{T_i}{T}\right)
}
\tag{4}
```

を得る．
なお， $L_i/T_i$ は融点における融解エントロピーであるため， $\alpha_i$ は融解エントロピーを気体定数 $R$ で割った無次元量である．

### 3．液相線の方程式

式 (1) と式 (4) より，成分1の固相と液相が平衡にある条件は

```math
\boxed{
x_{1l}
=\exp\left\{
\alpha_1\left(1-\frac{T_1}{T}\right)
\right\}
}
\tag{5a}
```

となる．
同様に，成分2の固相と液相が平衡にある条件は

```math
\boxed{
x_{2l}
=\exp\left\{
\alpha_2\left(1-\frac{T_2}{T}\right)
\right\}
}
\tag{5b}
```

となる．
これらが2本の液相線の方程式である．

液相中のモル分率の和は1であるため，

```math
x_{1l}+x_{2l}=1
\tag{6}
```

が成り立つ．
したがって，成分2の液相線は，成分1のモル分率 $x_{1l}$ を使って

```math
\boxed{
1-x_{1l}
=\exp\left\{
\alpha_2\left(1-\frac{T_2}{T}\right)
\right\}
}
\tag{7}
```

とも表せる．

式 (5a) は純成分1の融点 $T_1$ ，組成 $x_{1l}=1$ から共融点までの液相線を表す．
式 (5b) は純成分2の融点 $T_2$ ，組成 $x_{2l}=1$ から共融点までの液相線を表す．

### 4．共融点を定める方程式

共融点 E では，液相が純固相1と純固相2の両方と同時に平衡にある．
その温度を $T_E$ ，液相のモル分率を $x_{1E}$ ， $x_{2E}$ とする．

式 (5a)，式 (5b) に $T=T_E$ を代入すると，

```math
x_{1E}
=\exp\left\{
\alpha_1\left(1-\frac{T_1}{T_E}\right)
\right\}
```

および

```math
x_{2E}
=\exp\left\{
\alpha_2\left(1-\frac{T_2}{T_E}\right)
\right\}
```

となる．
共融点でも $x_{1E}+x_{2E}=1$ であるから，これらを足し合わせると，

```math
\boxed{
\begin{aligned}
&\exp\left\{
\alpha_1\left(1-\frac{T_1}{T_E}\right)
\right\}\\
&\quad+
\exp\left\{
\alpha_2\left(1-\frac{T_2}{T_E}\right)
\right\}
=1
\end{aligned}
}
\tag{8}
```

を得る．
これが共融温度 $T_E$ を定める方程式である．
一般にはこの方程式を解析的に解くことはできず，数値計算によって $T_E$ を求める．
共融点の組成は，得られた $T_E$ を式 (5a)，式 (5b) に代入することで求まる．

共融温度は，通常，両純成分の融点より低く，

```math
T_E<\min(T_1,T_2)
```

となる．

### 5．相図を定める方程式のまとめ

以上より，相図を定める主な式は次のとおりである．

**成分1の固相と液相の平衡を表す液相線**

```math
x_{1l}
=\exp\left\{
\alpha_1\left(1-\frac{T_1}{T}\right)
\right\},
\qquad
x_{1E}\leq x_{1l}\leq 1
```

**成分2の固相と液相の平衡を表す液相線**

```math
1-x_{1l}
=\exp\left\{
\alpha_2\left(1-\frac{T_2}{T}\right)
\right\},
\qquad
0\leq x_{1l}\leq x_{1E}
```

**共融温度を定める方程式**

```math
\begin{aligned}
&\exp\left\{
\alpha_1\left(1-\frac{T_1}{T_E}\right)
\right\}\\
&\quad+
\exp\left\{
\alpha_2\left(1-\frac{T_2}{T_E}\right)
\right\}
=1
\end{aligned}
```

ただし，

```math
\alpha_i=\frac{L_i}{RT_i}
```

である．
共融温度より低い温度では液相は平衡状態として存在せず，純固相1と純固相2が共存する．
このように，2本の液相線と共融点の条件によって，相図が定まる．
