# 演習問題【6-A-2】

## 解答

### 1．力学的な関係から平均張力を求める方法

#### 1.1 幾何学的な関係

全長 $l$ の糸の中央に質量 $m$ のおもりが取り付けられているため，おもりから糸の各端までの長さは $l/2$ である．
糸の両端間の距離を $x$ ，おもりから回転軸までの距離を $r$ とする．

おもりと糸の両端を結ぶと，斜辺が $l/2$ ，軸方向の辺が $x/2$ ，軸に垂直な辺が $r$ の直角三角形ができる．
したがって，三平方の定理より，

```math
\left(\frac l2\right)^2
=r^2+\left(\frac x2\right)^2
```

である．
これを整理すると，

```math
\boxed{
r^2=\frac{l^2-x^2}{4}
}
\tag{1}
```

となる．

#### 1.2 力のつり合いから張力を求める

糸の各部分に生じる張力を $S$ とし，糸の各部分と回転軸とのなす角を $\theta$ とする．
幾何学的な関係から，

```math
\cos\theta=\frac{x/2}{l/2}=\frac xl
```

および，

```math
\sin\theta=\frac{r}{l/2}=\frac{2r}{l}
```

である．

おもりが角速度 $\omega$ で回転するとき，必要な向心力の大きさは $mr\omega^2$ である．
おもりに作用する糸の張力は2本あり，それぞれの回転軸に垂直な成分は $S\sin\theta$ である．
したがって，回転軸に垂直な方向の力のつり合いは，

```math
2S\sin\theta=mr\omega^2
```

となる．
ここに $\sin\theta=2r/l$ を代入すると，

```math
2S\frac{2r}{l}=mr\omega^2
```

であるから，

```math
\boxed{
S=\frac{ml\omega^2}{4}
}
\tag{2}
```

を得る．

次に，糸の両端に加える軸方向の力を $X$ とする．
この力は，糸の張力 $S$ の回転軸方向の成分に等しいため，

```math
X=S\cos\theta
```

である．
式 (2) と $\cos\theta=x/l$ を代入すると，

```math
X=\frac{ml\omega^2}{4}\frac xl
```

となる．
したがって，

```math
\boxed{X=\frac{mx\omega^2}{4}}
\tag{3}
```

が得られる．

#### 1.3 角運動量を用いて張力を表す

おもりの回転運動の慣性モーメントは $mr^2$ である．
回転角を $\varphi$ とすると，角運動量に対応する正準運動量 $p_\varphi$ は，

```math
p_\varphi=mr^2\omega
```

である．
したがって，

```math
\omega=\frac{p_\varphi}{mr^2}
```

となる．
これを式 (3) に代入すると，

```math
\begin{aligned}
X
&=\frac{mx}{4}
\left(\frac{p_\varphi}{mr^2}\right)^2\\
&=\frac{xp_\varphi^2}{4mr^4}
\end{aligned}
\tag{4}
```

を得る．

ここで，式 (1) より $4r^2=l^2-x^2$ であるから，式 (4) は，

```math
\boxed{
X=\frac{2x}{l^2-x^2}
\frac{p_\varphi^2}{2mr^2}
}
\tag{5}
```

とも表せる．

式 (5) の $p_\varphi^2/(2mr^2)$ は，おもりの回転運動の運動エネルギーである．
この量の熱平衡状態での平均値を求めれば，平均張力が得られる．

#### 1.4 エネルギーの等分配則を用いる

温度 $T$ の熱浴と熱平衡にある古典系では，ハミルトニアンに2次形式で現れる独立な自由度1つにつき，平均エネルギーは $kT/2$ となる．
これをエネルギーの等分配則という．
ここで $k$ はボルツマン定数である．

本問題の回転運動のエネルギーは，

```math
\frac{p_\varphi^2}{2mr^2}
```

という運動量の2次形式である．
したがって，等分配則より，

```math
\boxed{
\overline{\frac{p_\varphi^2}{2mr^2}}
=\frac12 kT
}
\tag{6}
```

となる．

式 (5) で， $x$ と $r$ は固定されているため，両辺の平均をとると，

```math
\overline X
=\frac{2x}{l^2-x^2}
\overline{\frac{p_\varphi^2}{2mr^2}}
```

である．
式 (6) を代入すれば，

```math
\begin{aligned}
\overline X
&=\frac{2x}{l^2-x^2}\frac{kT}{2}\\
&=\frac{x}{l^2-x^2}kT
\end{aligned}
```

となる．
よって，求める平均張力は，

```math
\boxed{\displaystyle
\overline X=\frac{xkT}{l^2-x^2}
}
```

である．

### 2．別解：分配関数を用いる方法

#### 2.1 ハミルトニアンと分配関数

式 (1) より，回転運動のハミルトニアンは，

```math
\begin{aligned}
\mathcal H
&=\frac{p_\varphi^2}{2mr^2}\\
&=\frac{2p_\varphi^2}{m(l^2-x^2)}
\end{aligned}
\tag{7}
```

である．
ここでは， $x$ を固定した状態で，回転角 $\varphi$ と正準運動量 $p_\varphi$ を変数として扱う．

カノニカル分布における分配関数は，

```math
Z=\frac1h\int_0^{2\pi}d\varphi
\int_{-\infty}^{\infty}
e^{-\mathcal H/(kT)}\,dp_\varphi
```

である．
ここで $h$ は位相空間の積分を規格化する定数であり，最終的な力の計算には影響しない．

式 (7) を代入すると，

```math
Z=\frac1h\int_0^{2\pi}d\varphi
\int_{-\infty}^{\infty}
\exp\left[
-\frac{2p_\varphi^2}{m(l^2-x^2)kT}
\right]dp_\varphi
```

となる．
角度についての積分は $2\pi$ であり，運動量についての積分はガウス積分である．
公式

```math
\int_{-\infty}^{\infty}e^{-ap^2}\,dp
=\sqrt{\frac{\pi}{a}}
\qquad (a>0)
```

を用いると，

```math
Z=\frac{2\pi}{h}
\sqrt{\frac{\pi m(l^2-x^2)kT}{2}}
```

を得る．
したがって， $x$ に依存する部分だけに注目すれば，

```math
\boxed{Z\propto(l^2-x^2)^{1/2}}
\tag{8}
```

となる．

#### 2.2 自由エネルギーから平均張力を求める

ヘルムホルツ自由エネルギー $F$ と分配関数 $Z$ の関係は，

```math
F=-kT\log Z
```

である．
両端間の距離 $x$ を変化させるための一般化力は，温度一定のもとで，

```math
\overline X
=\left(\frac{\partial F}{\partial x}\right)_T
=-kT\left(\frac{\partial\log Z}{\partial x}\right)_T
\tag{9}
```

と表される．
これは，距離 $x$ をゆっくり変化させるときの自由エネルギーの変化率が，その変化に対する一般化力を与えるためである．

式 (8) より，

```math
\log Z=\frac12\log(l^2-x^2)+\text{定数}
```

である．
これを $x$ で微分すると，

```math
\frac{\partial\log Z}{\partial x}
=\frac12\frac{-2x}{l^2-x^2}
=-\frac{x}{l^2-x^2}
```

となる．
したがって，式 (9) に代入すれば，

```math
\begin{aligned}
\overline X
&=-kT\left(-\frac{x}{l^2-x^2}\right)\\
&=\frac{x}{l^2-x^2}kT
\end{aligned}
```

を得る．
よって，別解でも，

```math
\boxed{
\displaystyle
\overline X=\frac{xkT}{l^2-x^2}
}
```

となり，主解と同じ結果が得られる．
