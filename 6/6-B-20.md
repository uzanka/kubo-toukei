# 演習問題【6-B-20】

## 解答

### 熱容量曲線と零点エネルギーの関係

#### 1．固体の定積熱容量

固体の結晶格子は，多数の固有振動モードからなる．角振動数 $\omega$ の固有振動モードを量子調和振動子として扱い，そのモード数の分布をスペクトル関数 $g(\omega,V,N)$ で表す．
ここで， $V$ は体積， $N$ は原子数である．
$g(\omega,V,N)d\omega$ は，角振動数が $\omega$ から $\omega+d\omega$ の範囲にある固有振動モードの数を表す．

角振動数 $\omega$ の1つの振動モードの平均エネルギーは，

```math
\epsilon(\omega,T)
=\frac{\hbar\omega}{2}
+\frac{\hbar\omega}{e^{\hbar\omega/(kT)}-1}
\tag{1}
```

で与えられる．
ここで， $\hbar$ は換算 Planck 定数， $k$ は Boltzmann 定数， $T$ は絶対温度である．
式(1)の第1項は零点エネルギー，第2項は熱励起によるエネルギーである．

定積熱容量 $C_v$ は，体積を一定に保ったときの内部エネルギー $U$ の温度変化率であり，

```math
C_v=\left(\frac{\partial U}{\partial T}\right)_V
```

と定義される．
固体の内部エネルギーは各振動モードの平均エネルギーの総和なので，

```math
U(V,T,N)
=\int_0^\infty
\epsilon(\omega,T)g(\omega,V,N)\,d\omega
```

である．
したがって，定積熱容量は

```math
\boxed{
C_v(V,T,N)
=\int_0^\infty
\frac{\partial\epsilon(\omega,T)}{\partial T}
g(\omega,V,N)\,d\omega
}
\tag{2}
```

となる．

#### 2．高温における古典値 $C_\infty$

まず，温度が十分に高い場合を考える．
このとき，

```math
x=\frac{\hbar\omega}{kT}\ll1
```

となる．
指数関数の展開を用いると，

```math
\frac{1}{e^x-1}
=\frac1x-\frac12+\frac{x}{12}+O(x^3)
```

であるから，式(1)は

```math
\begin{aligned}
\epsilon(\omega,T)
&=\frac{\hbar\omega}{2}
+\hbar\omega
\left(
\frac{kT}{\hbar\omega}
-\frac12
+\frac{\hbar\omega}{12kT}
+\cdots
\right)\\[4pt]
&=kT+\frac{(\hbar\omega)^2}{12kT}
+\cdots
\end{aligned}
```

となる．
よって，高温極限では

```math
\epsilon(\omega,T)\simeq kT
```

であり，特に，

```math
\lim_{T\to\infty}
\{kT-\epsilon(\omega,T)\}=0
\tag{3}
```

が成り立つ．

したがって，式(2)で各モードの平均エネルギーを古典的な値 $kT$ に置き換えると，高温における古典的な熱容量は

```math
\begin{aligned}
C_\infty(V,N)
&=\int_0^\infty
\frac{\partial(kT)}{\partial T}
g(\omega,V,N)\,d\omega\\[4pt]
&=k\int_0^\infty
g(\omega,V,N)\,d\omega
\end{aligned}
\tag{4}
```

となる．

ここで，固体に含まれる固有振動モードの総数を $f$ とすると，スペクトル関数の定義より，

```math
\int_0^\infty g(\omega,V,N)\,d\omega=f
```

である．
したがって，

```math
\boxed{
C_\infty=fk
}
\tag{5}
```

を得る．
これは Dulong–Petit の法則に対応する古典値である．

#### 3．網掛け部分の面積を積分で表す

問題の網掛け部分は，古典値 $C_\infty$ と実際の定積熱容量 $C_v$ の差を温度について積分したものである．
したがって，その面積 $A$ は

```math
A=\int_0^\infty
\left[C_\infty(V,N)-C_v(V,T,N)\right]\,dT
\tag{6}
```

で表される．
この積分の単位は「熱容量×温度」であり，エネルギーの単位を持つ．

式(2)と式(4)を代入すると，

```math
\begin{aligned}
A
&=\int_0^\infty
\left[
\int_0^\infty
\left(
\frac{\partial(kT)}{\partial T}
-\frac{\partial\epsilon(\omega,T)}{\partial T}
\right)
g(\omega,V,N)\,d\omega
\right]dT\\[4pt]
&=\int_0^\infty
\left[
\int_0^\infty
\frac{\partial}{\partial T}
\{kT-\epsilon(\omega,T)\}
\,dT
\right]
g(\omega,V,N)\,d\omega
\end{aligned}
```

となる．
積分の順序を入れ替えたのは，まず各振動モードについて温度積分を実行し，その後で全モードについて足し合わせるためである．

微積分の基本定理を用いれば，

```math
A=
\int_0^\infty
\left[
kT-\epsilon(\omega,T)
\right]_{T=0}^{T=\infty}
g(\omega,V,N)\,d\omega
\tag{7}
```

となる．

#### 4．境界値を評価して零点エネルギーを得る

式(7)の境界値を評価する．

まず，高温極限では式(3)より，

```math
\lim_{T\to\infty}
\{kT-\epsilon(\omega,T)\}=0
```

である．
一方，絶対零度 $T=0$ では，熱励起によるエネルギーがゼロになるため，式(1)より，

```math
\epsilon(\omega,0)=\frac{\hbar\omega}{2}
```

となる．
したがって，

```math
\left[kT-\epsilon(\omega,T)\right]_{T=0}^{T=\infty}
=0-\left(-\frac{\hbar\omega}{2}\right)
=\frac{\hbar\omega}{2}
```

である．
これを式(7)に代入すると，

```math
\boxed{
A=\int_0^\infty
\frac{\hbar\omega}{2}
g(\omega,V,N)\,d\omega
}
\tag{8}
```

を得る．

ここで，絶対零度における固体の内部エネルギーは，

```math
U(V,0,N)
=\int_0^\infty
\epsilon(\omega,0)g(\omega,V,N)\,d\omega
```

であるから，

```math
U(V,0,N)
=\int_0^\infty
\frac{\hbar\omega}{2}
g(\omega,V,N)\,d\omega
\tag{9}
```

となる．
式(8)と式(9)を比較すれば，

```math
\boxed{
A=U(V,0,N)
}
```

が得られる．
すなわち， **定積熱容量の古典値 $C_\infty$ と実際の熱容量 $C_v$ の間の網掛け部分の面積は，固体の格子振動の零点エネルギーに等しい** のである．
