# 演習問題【6-A-3】
## 解答

本問題では，一様な重力場の中に置かれた理想気体の統計力学的な性質を求める．

### 1．単一粒子のハミルトニアン

容器の軸を $z$ 軸とし，重力加速度を $g$ とする．
粒子の質量を $m$ ，座標を $(x, y, z)$ ，それらに共役な運動量を $(p_x, p_y, p_z)$ とすると，単一粒子のハミルトニアン $\varepsilon_{\text{trans}}$ は，運動エネルギーと位置エネルギーの和として次のように書ける：

$$\varepsilon_{\text{trans}} = \frac{p_x^2 + p_y^2 + p_z^2}{2m} + mgz \quad \cdots (1)$$

### 2．単一粒子の分配関数 $Z_{\text{trans}}$ の導出

古典統計学における単一粒子の分配関数 $Z_{\text{trans}}$ は，相空間（位置と運動量の空間）にわたる積分として次のように定義される：

$$Z_{\text{trans}} = \frac{1}{h^3} \int dx\,dy\,dz \iiint dp_x\,dp_y\,dp_z \, e^{-\beta \varepsilon_{\text{trans}}}$$

ここで， $\beta = 1/(kT)$ であり， $k$ はボルツマン定数， $T$ は絶対温度である．

この積分を，位置に関する積分と運動量に関する積分に分離して計算する．
容器の断面積を $\sigma$ とすると，位置に関する積分は次のように書ける：

$$\int dx\,dy\,dz = \iint_{\text{area } \sigma} dx\,dy \int_0^\infty dz = \sigma \int_0^\infty dz$$

したがって，

$$Z_{\text{trans}} = \frac{\sigma}{h^3} \left( \int_0^\infty e^{-\beta mgz} dz \right) \left( \iiint_{-\infty}^\infty e^{-\beta (p_x^2 + p_y^2 + p_z^2)/2m} dp_x\,dp_y\,dp_z \right)$$

まず，位置に関する $z$ の積分を計算する：

$$\int_0^\infty e^{-\beta mgz} dz = \left[ -\frac{1}{\beta mg} e^{-\beta mgz} \right]_0^\infty = \frac{1}{\beta mg} = \frac{kT}{mg}$$

次に，運動量に関する積分を計算する．
これはガウス積分の公式 $\int_{-\infty}^\infty e^{-ax^2} dx = \sqrt{\pi/a}$ を用いることで，

$$\iiint_{-\infty}^\infty e^{-\frac{\beta}{2m}(p_x^2 + p_y^2 + p_z^2)} dp_x\,dp_y\,dp_z = \left( \int_{-\infty}^\infty e^{-\frac{\beta}{2m}p_x^2} dp_x \right)^3 = \left( \sqrt{\frac{2\pi m}{\beta}} \right)^3 = (2\pi mkT)^{3/2}$$

となる．

これらをまとめると，単一粒子の分配関数 $Z_{\text{trans}}$ は以下のようになる：

$$Z_{\text{trans}} = \frac{\sigma}{h^3} \cdot \frac{kT}{mg} \cdot (2\pi mkT)^{3/2} = \sigma \frac{kT}{mg} \left( \frac{2\pi mkT}{h^2} \right)^{3/2} \quad \cdots (2)$$

### 3．$N$ 体の分配関数 $Z$ とヘルムホルツの自由エネルギー $F$

粒子 $N$ 個からなる理想気体の全分配関数 $Z$ は，粒子が区別できないことを考慮して次のように書ける：

$$Z = \frac{1}{N!} (Z_{\text{trans}})^N \quad \cdots (3)$$

ヘルムホルツの自由エネルギー $F$ は $F = -kT \log Z$ で与えられる．
スターリングの近似 $\log N! \approx N \log N - N$ を用いると，

$$\log Z = \log \left( \frac{1}{N!} (Z_{\text{trans}})^N \right) \approx N \log Z_{\text{trans}} - (N \log N - N) = N \log \left( \frac{e Z_{\text{trans}}}{N} \right)$$

となる．
したがって，

$$F = -NkT \log \left( \frac{e Z_{\text{trans}}}{N} \right) = -NkT \log \left[ \frac{e}{N} \cdot \sigma \frac{kT}{mg} \left( \frac{2\pi mkT}{h^2} \right)^{3/2} \right]$$

整理すると，

$$F = -NkT \log \left[ \frac{\sigma kT e}{Nmg} \left( \frac{2\pi mkT}{h^2} \right)^{3/2} \right] \quad \cdots (4)$$

### 4．内部エネルギー $E$ と熱容量 $C$

系の内部エネルギー $E$ は，分配関数を用いて次のように計算できる：

$$E = kT^2 \frac{\partial \log Z}{\partial T}$$

$\log Z$ の $T$ 依存性を調べると，

$$\log Z = N \log Z_{\text{trans}} - \log N! = N \left( \log \left( \frac{\sigma}{h^3} \frac{1}{mg} \right) + \log(kT) + \frac{3}{2} \log(2\pi mkT) \right) - \log N!$$

$$\log Z = \text{const} + N \log T + \frac{3}{2} N \log T = \text{const} + \frac{5}{2} N \log T$$

よって，

$$\frac{\partial \log Z}{\partial T} = \frac{5}{2} \frac{N}{T}$$

これを $E$ の式に代入すると，

$$E = kT^2 \cdot \frac{5N}{2T} = \frac{5}{2} NkT$$

また，熱容量 $C$ はエネルギーの温度による変化率である：

$$C = \frac{\partial E}{\partial T} = \frac{5}{2} Nk$$

## 解説

単原子分子の理想気体において，重力がない場合の定積熱容量は $C_v = \frac{3}{2}Nk$ である．
重力場がある場合，本問題の結果である $C = \frac{5}{2}Nk$ はそれよりも大きな値を示す．

この違いが生じる理由は，重力によって粒子が垂直方向に分布を持つためである．
温度が上昇すると，粒子がより高い位置（位置エネルギーが高い場所）に分布する確率が増加する．
この位置エネルギーの変化が，系全体のエネルギーおよび熱容量に寄与するため，重力がない場合よりも熱容量が大きくなるのである．
