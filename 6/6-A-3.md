# 演習問題【6-A-3】

## 解答

### 1．単一粒子のハミルトニアン

質量 $m$ の粒子 $N$ 個からなる古典理想気体が，一様な重力場の中に立てられた無限に高い筒型容器に入っている．
容器の軸を $z$ 軸とし，底面を $z=0$ にとる．
重力加速度を $g$ ，容器の断面積を $\sigma$ ，絶対温度を $T$ とする．

粒子の位置を $(x,y,z)$ ，それぞれに正準共役な運動量を $(p_x,p_y,p_z)$ とすると，粒子1個のハミルトニアンは，運動エネルギーと重力による位置エネルギーの和として，

```math
\varepsilon_{\mathrm{trans}}
=\frac{p_x^2+p_y^2+p_z^2}{2m}+mgz
\tag{1}
```

と表される．

### 2．単一粒子の古典的分配関数

古典統計力学では，単一粒子の分配関数 $Z_{\mathrm{trans}}$ は，位置と運動量からなる相空間全体にわたる積分によって，

```math
Z_{\mathrm{trans}}
=\frac{1}{h^3}
\int dx\,dy\,dz
\iiint_{-\infty}^{\infty}
e^{-\varepsilon_{\mathrm{trans}}/(kT)}
\,dp_x\,dp_y\,dp_z
```

と定義される．
ここで， $k$ はボルツマン定数， $h$ はプランク定数である．
因子 $h^{-3}$ は，古典的な相空間積分を無次元の分配関数にするために導入される．

容器の断面積が $\sigma$ であり，粒子の存在できる高さが $z\geq 0$ であることから，位置に関する積分は，

```math
\int dx\,dy\,dz
=\sigma\int_0^\infty dz
```

となる．
式 (1) を代入し，位置と運動量の積分を分離すると，

```math
\begin{aligned}
Z_{\mathrm{trans}}
={}&\frac{\sigma}{h^3}
\int_0^\infty e^{-mgz/(kT)}\,dz\\
&\times
\iiint_{-\infty}^{\infty}
e^{-(p_x^2+p_y^2+p_z^2)/(2mkT)}
\,dp_x\,dp_y\,dp_z
\end{aligned}
\tag{2}
```

を得る．

まず，高さ $z$ に関する積分を計算する．

```math
\begin{aligned}
\int_0^\infty e^{-mgz/(kT)}\,dz
&=\left[-\frac{kT}{mg}e^{-mgz/(kT)}\right]_0^\infty\\
&=\frac{kT}{mg}
\end{aligned}
\tag{3}
```

となる．

次に，運動量に関する積分を計算する．
ガウス積分の公式

```math
\int_{-\infty}^{\infty}e^{-ap^2}\,dp
=\sqrt{\frac{\pi}{a}}
\qquad (a>0)
```

を用いると，各運動量成分の積分は独立に計算できる．
したがって，

```math
\begin{aligned}
&\iiint_{-\infty}^{\infty}
e^{-(p_x^2+p_y^2+p_z^2)/(2mkT)}
\,dp_x\,dp_y\,dp_z\\
&\quad=
\left(\int_{-\infty}^{\infty}
e^{-p_x^2/(2mkT)}\,dp_x\right)^3\\
&\quad=(2\pi mkT)^{3/2}
\end{aligned}
\tag{4}
```

となる．

式 (3)，(4) を式 (2) に代入すれば，

```math
\begin{aligned}
Z_{\mathrm{trans}}
&=\frac{\sigma}{h^3}\frac{kT}{mg}(2\pi mkT)^{3/2}\\
&=\sigma\frac{kT}{mg}
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\end{aligned}
```

を得る．
よって，単一粒子の古典的分配関数は，

```math
\boxed{
Z_{\mathrm{trans}}
=\sigma\frac{kT}{mg}
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
}
\tag{5}
```

である．

### 3．粒子 $N$ 個の分配関数

理想気体では粒子間の相互作用を無視できるため，全系のエネルギーは各粒子のエネルギーの和である．
また，粒子は同種の粒子であり，区別できないものとして扱うため，全分配関数には $1/N!$ の因子が付く．
したがって，

```math
Z=\frac{1}{N!}(Z_{\mathrm{trans}})^N
```

である．
式 (5) を代入すると，

```math
\boxed{
Z=\frac{1}{N!}
\left[
\sigma\frac{kT}{mg}
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\right]^N
}
\tag{6}
```

となる．
これが粒子 $N$ 個からなる系の古典的分配関数である．

### 4．Helmholtz の自由エネルギー

Helmholtz の自由エネルギー $F$ は，分配関数 $Z$ を用いて，

```math
F=-kT\log Z
```

と表される．
式 (6) の対数をとると，

```math
\log Z
=N\log Z_{\mathrm{trans}}-\log N!
```

であるから，

```math
F=-NkT\log Z_{\mathrm{trans}}+kT\log N!
\tag{7}
```

を得る．
これは近似を用いない厳密な表式である．

ここで，粒子数 $N$ が十分大きいときには，スターリングの近似

```math
\log N!\simeq N\log N-N
```

が成り立つ．
これを式 (7) に代入すると，

```math
\begin{aligned}
F
&\simeq -NkT\log Z_{\mathrm{trans}}
+NkT\log N-NkT\\
&=-NkT\log\left(\frac{eZ_{\mathrm{trans}}}{N}\right)
\end{aligned}
```

となる．
さらに，式 (5) を代入すれば，

```math
\boxed{
F\simeq
-NkT\log\left[
\frac{\sigma kT e}{Nmg}
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\right]
}
\tag{8}
```

を得る．
これがスターリングの近似を用いた Helmholtz の自由エネルギーである．

### 5．平均エネルギー

カノニカル分布における系の平均エネルギー $E$ は，分配関数を用いて，

```math
E=kT^2\frac{\partial\log Z}{\partial T}
\tag{9}
```

と求められる．

式 (6) より，

```math
\log Z
=N\log Z_{\mathrm{trans}}-\log N!
```

である．
ここで，温度 $T$ に依存するのは $Z_{\mathrm{trans}}$ だけである．
式 (5) の温度依存性に注目すると，

```math
Z_{\mathrm{trans}}\propto T\cdot T^{3/2}=T^{5/2}
```

であるから，

```math
\log Z=\text{定数}+\frac52N\log T
```

と書ける．
したがって，

```math
\frac{\partial\log Z}{\partial T}
=\frac{5N}{2T}
```

となる．
これを式 (9) に代入すると，

```math
\begin{aligned}
E
&=kT^2\frac{5N}{2T}\\
&=\frac52NkT
\end{aligned}
```

を得る．
よって，系の平均エネルギーは，

```math
\boxed{
E=\frac52NkT
}
\tag{10}
```

である．

この結果は，運動エネルギーと重力による位置エネルギーに分けて考えることでも理解できる．
運動量に関する3つの二次形式から，粒子1個当たりの平均運動エネルギーは $\frac32kT$ である．
一方，高さ方向の確率密度は $e^{-mgz/(kT)}$ に比例するため，

```math
\overline z
=\frac{\displaystyle\int_0^\infty
z e^{-mgz/(kT)}\,dz}
{\displaystyle\int_0^\infty
e^{-mgz/(kT)}\,dz}
=\frac{kT}{mg}
```

となる．
したがって，粒子1個当たりの平均位置エネルギーは，

```math
mg\overline z=kT
```

である．
よって，全系の平均エネルギーは，

```math
E=N\left(\frac32kT+kT\right)
=\frac52NkT
```

となり，式 (10) と一致する．

### 6．熱容量

この系の熱容量 $C$ は，粒子数 $N$ ，容器の断面積 $\sigma$ ，重力加速度 $g$ を一定に保ったときの平均エネルギーの温度微分として，

```math
C=\left(\frac{\partial E}{\partial T}\right)_{N,\sigma,g}
```

と定義する．
式 (10) を微分すると，

```math
C=\frac{\partial}{\partial T}
\left(\frac52NkT\right)
```

であるから，

```math
\boxed{
C=\frac52Nk
}
\tag{11}
```

を得る．

通常，重力のない単原子分子理想気体の定積熱容量は $\frac32Nk$ である．
本問題で得られた熱容量がこれより大きいのは，粒子が高さ方向に分布し，重力による位置エネルギーも平均エネルギーに寄与するためである．
温度が上昇すると，粒子の平均高度 $\overline z=kT/(mg)$ も上昇し，位置エネルギーが増加するのである．
