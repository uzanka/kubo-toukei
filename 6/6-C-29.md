# 演習問題【6-C-29】

## 解答

### 磁場中の電子の密度行列とスピンの平均値

磁場 $\boldsymbol H$ の中にある電子のハミルトニアンは，

```math
\mathcal H=-\mu_{\mathrm B}\boldsymbol\sigma\cdot\boldsymbol H
```

で与えられる．
ここで， $\mu_{\mathrm B}$ は Bohr 磁子， $\boldsymbol\sigma=(\sigma_x,\sigma_y,\sigma_z)$ は Pauli 行列からなるスピン演算子である．
磁場の方向を $z$ 軸に選ぶと，

```math
\boldsymbol H=(0,0,H)
```

であるため，ハミルトニアンは

```math
\boxed{
\mathcal H=-\mu_{\mathrm B}H\sigma_z
}
\tag{1}
```

となる．

温度 $T$ における密度行列は，カノニカル分布により，

```math
\boxed{
\rho=\frac{e^{-\beta\mathcal H}}
{\operatorname{Tr}(e^{-\beta\mathcal H})}
}
\qquad
\left(\beta=\frac{1}{k_{\mathrm B}T}\right)
\tag{2}
```

で定義される．
ここで， $k_{\mathrm B}$ は Boltzmann 定数， $\operatorname{Tr}$ は行列の対角成分の和を表すトレースである．

以下では，

```math
a=\beta\mu_{\mathrm B}H
```

とおく．

#### (i) $\sigma_z$ を対角化する表示での密度行列

$\sigma_z$ を対角化する $z$ 基底では，Pauli 行列は

```math
\sigma_x=
\begin{pmatrix}
0&1\\
1&0
\end{pmatrix},
\quad
\sigma_y=
\begin{pmatrix}
0&-i\\
i&0
\end{pmatrix},
\quad
\sigma_z=
\begin{pmatrix}
1&0\\
0&-1
\end{pmatrix}
\tag{3}
```

である．

式(1)から，ハミルトニアンは

```math
\mathcal H=
\begin{pmatrix}
-\mu_{\mathrm B}H&0\\
0&\mu_{\mathrm B}H
\end{pmatrix}
```

となる．
したがって，Boltzmann 因子は

```math
e^{-\beta\mathcal H}
=
\begin{pmatrix}
e^a&0\\
0&e^{-a}
\end{pmatrix}
```

であり，そのトレースは

```math
Z=\operatorname{Tr}(e^{-\beta\mathcal H})
=e^a+e^{-a}=2\cosh a
```

である．
これを式(2)に代入すると，

```math
\boxed{
\rho_z=
\frac{1}{e^a+e^{-a}}
\begin{pmatrix}
e^a&0\\
0&e^{-a}
\end{pmatrix}
}
\tag{4}
```

を得る．
ここで，添字 $z$ は $z$ 基底で表した行列であることを示している．

#### (ii) $\sigma_x$ を対角化する表示での密度行列

次に， $\sigma_x$ を対角化する $x$ 基底に移る．
そのために，次のユニタリ行列を用いる．

```math
U=\frac{1}{\sqrt2}
\begin{pmatrix}
1&1\\
1&-1
\end{pmatrix}
\tag{5}
```

この行列は $U^\dagger=U$ ， $U^\dagger U=I$ を満たす．
その列ベクトルは，もとの $z$ 基底で表した $\sigma_x$ の固有ベクトルである．

演算子 $A$ の $x$ 基底での行列表現は，

```math
A_x=U^\dagger A_zU
\tag{6}
```

で与えられる．
実際に $\sigma_x$ を変換すると，

```math
\begin{aligned}
(\sigma_x)_x
&=U^\dagger\sigma_xU\\
&=\frac12
\begin{pmatrix}
1&1\\
1&-1
\end{pmatrix}
\begin{pmatrix}
0&1\\
1&0
\end{pmatrix}
\begin{pmatrix}
1&1\\
1&-1
\end{pmatrix}\\
&=
\begin{pmatrix}
1&0\\
0&-1
\end{pmatrix}
\end{aligned}
\tag{7}
```

となる．
よって，この基底では $\sigma_x$ が対角化されている．

同じ基底変換を $\sigma_z$ に適用すると，

```math
\begin{aligned}
(\sigma_z)_x
&=U^\dagger\sigma_zU\\
&=\frac12
\begin{pmatrix}
1&1\\
1&-1
\end{pmatrix}
\begin{pmatrix}
1&0\\
0&-1
\end{pmatrix}
\begin{pmatrix}
1&1\\
1&-1
\end{pmatrix}\\
&=
\begin{pmatrix}
0&1\\
1&0
\end{pmatrix}
\end{aligned}
\tag{8}
```

を得る．
したがって， $x$ 基底ではハミルトニアンは

```math
\mathcal H_x=-\mu_{\mathrm B}H(\sigma_z)_x
=-\mu_{\mathrm B}H
\begin{pmatrix}
0&1\\
1&0
\end{pmatrix}
```

となり，この基底では対角行列ではない．

密度行列も同じ基底変換によって，

```math
\rho_x=U^\dagger\rho_zU
\tag{9}
```

と表される．
式(4)と式(5)を代入すれば，

```math
\begin{aligned}
\rho_x
&=\frac{1}{e^a+e^{-a}}
U
\begin{pmatrix}
e^a&0\\
0&e^{-a}
\end{pmatrix}
U^\dagger\\[4pt]
&=\frac{1}{2(e^a+e^{-a})}
\begin{pmatrix}
e^a+e^{-a}&e^a-e^{-a}\\
e^a-e^{-a}&e^a+e^{-a}
\end{pmatrix}
\end{aligned}
```

である．
双曲線正接

```math
\tanh a=\frac{e^a-e^{-a}}{e^a+e^{-a}}
```

を用いると，

```math
\boxed{
\rho_x=\frac12
\begin{pmatrix}
1&\tanh a\\
\tanh a&1
\end{pmatrix}
}
\tag{10}
```

となる．
これが $\sigma_x$ を対角化する表示での密度行列である．

なお， $\sigma_x$ の固有ベクトルの一方の符号を反転して基底を定義すると，式(10)の非対角成分は負になる．
その場合には式(8)の $(\sigma_z)_x$ にも同じ符号反転が生じるため，物理的な期待値は変わらない．

#### (iii) 二つの表示での $\sigma_z$ の平均値

観測量 $A$ の熱平衡における期待値は，

```math
\langle A\rangle=\operatorname{Tr}(\rho A)
\tag{11}
```

で定義される．

##### $z$ 基底での計算

式(4)と式(3)を用いると，

```math
\begin{aligned}
\langle\sigma_z\rangle
&=\operatorname{Tr}(\rho_z\sigma_z)\\
&=\frac{1}{e^a+e^{-a}}
\operatorname{Tr}
\begin{pmatrix}
e^a&0\\
0&-e^{-a}
\end{pmatrix}\\
&=\frac{e^a-e^{-a}}{e^a+e^{-a}}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\langle\sigma_z\rangle_z
=\tanh(\beta\mu_{\mathrm B}H)
}
\tag{12}
```

を得る．

##### $x$ 基底での計算

この基底では，密度行列は式(10)， $\sigma_z$ の行列表現は式(8)である．
したがって，

```math
\begin{aligned}
\langle\sigma_z\rangle
&=\operatorname{Tr}\{\rho_x(\sigma_z)_x\}\\
&=\operatorname{Tr}
\left[
\frac12
\begin{pmatrix}
1&\tanh a\\
\tanh a&1
\end{pmatrix}
\begin{pmatrix}
0&1\\
1&0
\end{pmatrix}
\right]\\[4pt]
&=\frac12
\operatorname{Tr}
\begin{pmatrix}
\tanh a&1\\
1&\tanh a
\end{pmatrix}\\
&=\tanh a
\end{aligned}
```

である．
したがって，

```math
\boxed{
\langle\sigma_z\rangle_x
=\tanh(\beta\mu_{\mathrm B}H)
}
\tag{13}
```

となる．

式(12)と式(13)は一致する．
これは，トレースがユニタリな基底変換に対して不変であることによる．
すなわち，密度行列と観測量を同じ基底で表せば，期待値は表示の選択によらないのである．
