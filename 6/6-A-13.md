# 演習問題【6-A-13】

## 解答

### 1. 系（システム）の設定

$N$ 個の単量体からなる鎖状分子を考える．
各単量体は独立に，以下の二つの状態のいずれかをとるものとする：
- 状態 $\alpha$ ： 長さ $a$ ，エネルギー $E_\alpha$
- 状態 $\beta$ ： 長さ $b$ ，エネルギー $E_\beta$

単量体が $\alpha$ 状態である数を $N_\alpha$ ， $\beta$ 状態である数を $N_\beta$ とすると，全単量体数 $N = N_\alpha + N_\beta$ である．
このとき，鎖状分子全体のエネルギー $E$ および長さ $L$ は次のように表される：

$$E = N_\alpha E_\alpha + N_\beta E_\beta$$

$$L = N_\alpha a + N_\beta b$$

### 2. 張力一定のカノニカル集団における分配関数

分子の両端に張力 $X$ をかけて引張っている場合，系が外部になす仕事は $X \cdot L$ である．
張力一定のカノニカル集団（ギブス集団）において，微視的状態の確率は，エネルギー $E$ と仕事 $X \cdot L$ の和 $E - XL$ に基づいて決まる．
したがって，分配関数 $Y$ は次のように書ける：

$$Y = \sum_{\{ \text{states} \}} \exp \left[ -\frac{E - XL}{kT} \right]$$

ここで， $\sum_{\{ \text{states} \}}$ はすべての可能な単量体の状態の組み合わせについての和である．
同じ $N_\alpha, N_\beta$ を持つ状態の数は，組み合わせの数 $\frac{N!}{N_\alpha! N_\beta!}$ であるから，

$$Y = \sum_{N_\alpha=0}^{N} \frac{N!}{N_\alpha! (N-N_\alpha)!} \exp \left[ -\frac{N_\alpha E_\alpha + (N-N_\alpha)E_\beta - X(N_\alpha a + (N-N_\alpha)b)}{kT} \right]$$

指数部を整理すると：

$$-\frac{N_\alpha (E_\alpha - Xa) + (N-N_\alpha)(E_\beta - Xb)}{kT} = \frac{N_\alpha(Xa - E_\alpha)}{kT} + \frac{(N-N_\alpha)(Xb - E_\beta)}{kT}$$

となる．
よって，

$$Y = \sum_{N_\alpha=0}^{N} \frac{N!}{N_\alpha! (N-N_\alpha)!} \left( e^{(Xa - E_\alpha)/kT} \right)^{N_\alpha} \left( e^{(Xb - E_\beta)/kT} \right)^{N-N_\alpha}$$

これは二項定理の展開式そのものであるため，次のように簡略化できる：

$$Y = \left( e^{(Xa - E_\alpha)/kT} + e^{(Xb - E_\beta)/kT} \right)^N \quad \cdots (3)$$

### 3. 平均的な長さ $\overline{L}$ の導出

張力 $X$ に対する平均的な長さ $\overline{L}$ は，分配関数を用いて次のように求められる：

$$\overline{L} = \frac{\sum L e^{-(E-XL)/kT}}{Y} = kT \frac{\partial \log Y}{\partial X}$$

実際に計算を行う．
$\log Y = N \log \left( e^{(Xa - E_\alpha)/kT} + e^{(Xb - E_\beta)/kT} \right)$ であるから，

$$\frac{\partial \log Y}{\partial X} = N \frac{1}{e^{(Xa - E_\alpha)/kT} + e^{(Xb - E_\beta)/kT}} \cdot \frac{\partial}{\partial X} \left( e^{(Xa - E_\alpha)/kT} + e^{(Xb - E_\beta)/kT} \right)$$

ここで，

$$\frac{\partial}{\partial X} e^{(Xa - E_\alpha)/kT} = \frac{a}{kT} e^{(Xa - E_\alpha)/kT}$$

$$\frac{\partial}{\partial X} e^{(Xb - E_\beta)/kT} = \frac{b}{kT} e^{(Xb - E_\beta)/kT}$$

である．
これを代入すると，

$$\overline{L} = N \frac{a e^{(Xa - E_\alpha)/kT} + b e^{(Xb - E_\beta)/kT}}{e^{(Xa - E_\alpha)/kT} + e^{(Xb - E_\beta)/kT}} \quad \cdots (4)$$

が得られる．

### 4. 張力が弱いときの近似（線形近似）

張力が非常に弱く， $Xa \ll kT$ および $Xb \ll kT$ であるとき， $\overline{L}$ を $X$ の1次まで展開する．
まず， $\Delta = (E_\alpha - E_\beta)/kT$ と定義する．
式(4)の分母と分子を $e^{(Xb - E_\beta)/kT}$ で割ると，

$$\frac{\overline{L}}{N} = \frac{a e^{(X(a-b) - (E_\alpha - E_\beta))/kT} + b}{e^{(X(a-b) - (E_\alpha - E_\beta))/kT} + 1}$$

ここで，指数部を $\epsilon = \frac{X(a-b)}{kT} - \Delta$ と置く．
$X$ が小さいとき， $\epsilon \approx -\Delta$ である．
関数 $f(\epsilon) = \frac{a e^\epsilon + b}{e^\epsilon + 1}$ の $\epsilon = -\Delta$ 付近での展開を考える．

$$f(-\Delta) = \frac{a e^{-\Delta} + b}{e^{-\Delta} + 1} = \frac{a + b e^\Delta}{1 + e^\Delta}$$

また， $\frac{df}{d\epsilon} = \frac{(a e^\epsilon)(e^\epsilon + 1) - (a e^\epsilon + b)(e^\epsilon)}{(e^\epsilon + 1)^2} = \frac{a e^{2\epsilon} + a e^\epsilon - a e^{2\epsilon} - b e^\epsilon}{(e^\epsilon + 1)^2} = \frac{(a-b)e^\epsilon}{(e^\epsilon + 1)^2}$
したがって， $\epsilon \approx -\Delta$ のとき，

$$f(\epsilon) \approx f(-\Delta) + (\epsilon + \Delta) f'(-\Delta)$$

$$\epsilon + \Delta = \frac{X(a-b)}{kT}$$

$$f'(-\Delta) = \frac{(a-b) e^{-\Delta}}{(1 + e^{-\Delta})^2} = \frac{(a-b) e^{-\Delta}}{(e^{-\Delta}(e^\Delta + 1))^2} = \frac{(a-b) e^\Delta}{(1 + e^\Delta)^2}$$

これを代入すると，

$$\frac{\overline{L}}{N} \simeq \frac{a + b e^\Delta}{1 + e^\Delta} + \frac{X(a-b)}{kT} \frac{(a-b) e^\Delta}{(1 + e^\Delta)^2} = \frac{a + b e^\Delta}{1 + e^\Delta} + \frac{X}{kT} \frac{(a-b)^2 e^\Delta}{(1 + e^\Delta)^2} \quad \cdots (5)$$

ここで， $\frac{(a-b)^2 e^\Delta}{(1 + e^\Delta)^2} = \frac{a^2 + b^2 e^\Delta}{1 + e^\Delta} - \left( \frac{a + b e^\Delta}{1 + e^\Delta} \right)^2$ である．

（証明： $\frac{(a^2 + b^2 e^\Delta)(1 + e^\Delta) - (a + b e^\Delta)^2}{(1 + e^\Delta)^2} = \frac{a^2 + a^2 e^\Delta + b^2 e^\Delta + b^2 e^{2\Delta} - (a^2 + 2ab e^\Delta + b^2 e^{2\Delta})}{(1 + e^\Delta)^2} = \frac{(a-b)^2 e^\Delta}{(1 + e^\Delta)^2}$ ）

以上より，単量体あたりの平均的な長さ $\overline{l} = \overline{L}/N$ は，

$$\overline{l} \simeq \frac{a + b e^\Delta}{1 + e^\Delta} + \frac{X}{kT} \left\{ \frac{a^2 + b^2 e^\Delta}{1 + e^\Delta} - \left( \frac{a + b e^\Delta}{1 + e^\Delta} \right)^2 \right\} \quad \cdots (5)$$

を得る．

## 解説

本問題は，定張力下における鎖状分子の統計力学的な振る舞いを扱うものである．

### 1. カノニカル集団と仕事の項

通常のカノニカル集団では，エネルギー $E$ のみに基づいて状態の確率が決まるが，本問のように外力 $X$ が作用している場合，系がその力に対して行う仕事 $X \cdot L$ を考慮する必要がある．
このとき，有効なエネルギー（ギブス自由エネルギーに相当する量）は $E - XL$ となり，分配関数にはこの項が含まれることになる．

### 2. 二項分布との関連

各単量体が独立に二つの状態をとれるという設定は，統計学における二項分布の考え方と直接結びついている．
分配関数 $Y$ の計算において，二項定理を用いることで，複雑な和の計算を非常に簡潔な積の形へと帰着させることができている．

### 3. 物理的な解釈

式(5)の第一項は，張力が全くかかっていないとき ( $X=0$ ) の平均的な長さを示している．
第二項は，張力 $X$ が加わることによって，どれだけ分子が引き伸ばされるか（弾性的な応答）を線形近似で表したものである．
この係数は，単量体状態のゆらぎに関連しており，張力によって状態 $\alpha$ と $\beta$ の占有確率が変化することに起因している．
