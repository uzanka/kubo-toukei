# 演習問題【6-A-13】

## 解答

### 1．張力一定のカノニカル集団と分配関数

$N$ 個の単量体からなる鎖状分子を考える．
各単量体は，状態 $\alpha$ または状態 $\beta$ をとり，それぞれの長さとエネルギーは，

```math
(\alpha):\quad (a,E_\alpha),\qquad
(\beta):\quad (b,E_\beta)
```

である．
状態 $\alpha$ の単量体数を $N_\alpha$ ，状態 $\beta$ の単量体数を $N_\beta$ とすると，

```math
N=N_\alpha+N_\beta
```

である．
このとき，鎖全体のエネルギー $E$ と長さ $L$ は，

```math
E=N_\alpha E_\alpha+N_\beta E_\beta
```

```math
L=N_\alpha a+N_\beta b
\tag{1}
```

となる．

鎖の両端に一定の張力 $X$ を加えると，張力によって系が受ける仕事を考慮した有効エネルギーは，

```math
E^*=E-XL
\tag{2}
```

である．
したがって，温度 $T$ において，各微視的状態の統計的な重みは，

```math
e^{-(E-XL)/(kT)}
```

となる．
ここで $k$ はボルツマン定数である．
このように，有効エネルギー $E-XL$ を用いて状態の確率を定める集団を，張力一定のカノニカル集団とよぶ．

### 2．分配関数の導出

状態 $\alpha$ の単量体が $N_\alpha$ 個，状態 $\beta$ の単量体が $N_\beta=N-N_\alpha$ 個ある場合，同じ状態数の組合せは，

```math
\frac{N!}{N_\alpha!N_\beta!}
```

通りである．
したがって，系全体の分配関数 $Y$ は，

```math
\begin{aligned}
Y={}&\sum_{N_\alpha=0}^{N}
\frac{N!}{N_\alpha!(N-N_\alpha)!}\\
&\times
\exp\left[
-\frac{
N_\alpha(E_\alpha-Xa)
+(N-N_\alpha)(E_\beta-Xb)
}{kT}
\right]
\end{aligned}
\tag{3}
```

となる．

ここで，

```math
A=e^{(Xa-E_\alpha)/(kT)},\qquad
B=e^{(Xb-E_\beta)/(kT)}
```

とおくと，式 (3) は，

```math
Y=\sum_{N_\alpha=0}^{N}
\frac{N!}{N_\alpha!(N-N_\alpha)!}
A^{N_\alpha}B^{N-N_\alpha}
```

と書ける．
これは二項定理

```math
(A+B)^N
=\sum_{r=0}^{N}
\frac{N!}{r!(N-r)!}A^rB^{N-r}
```

そのものである．
したがって，分配関数は，

```math
\boxed{
Y=
\left[
e^{(Xa-E_\alpha)/(kT)}
+e^{(Xb-E_\beta)/(kT)}
\right]^N
}
\tag{4}
```

となる．

### 3．平均鎖長と張力の関係

分配関数の定義から，その張力 $X$ による微分は，

```math
\frac{\partial Y}{\partial X}
=\frac{1}{kT}\sum_{\text{states}}
L\,e^{-(E-XL)/(kT)}
```

である．
両辺を $Y$ で割ると，平均鎖長 $\overline L$ の定義より，

```math
\boxed{
\overline L
=kT\left(\frac{\partial\log Y}{\partial X}\right)_{T,N}
}
\tag{5}
```

を得る．

式 (4) の対数は，

```math
\begin{aligned}
\log Y
=N\log\biggl[
&e^{(Xa-E_\alpha)/(kT)}\\
&+e^{(Xb-E_\beta)/(kT)}
\biggr]
\end{aligned}
```

である．
これを $X$ で微分すると，

```math
\begin{aligned}
\frac{\partial\log Y}{\partial X}
=\frac{N}{kT}
\frac{
ae^{(Xa-E_\alpha)/(kT)}
+be^{(Xb-E_\beta)/(kT)}
}{
e^{(Xa-E_\alpha)/(kT)}
+e^{(Xb-E_\beta)/(kT)}
}
\end{aligned}
```

となる．
式 (5) に代入すれば，平均鎖長と張力の関係は，

```math
\boxed{
\overline L
=N\frac{
ae^{(Xa-E_\alpha)/(kT)}
+be^{(Xb-E_\beta)/(kT)}
}{
e^{(Xa-E_\alpha)/(kT)}
+e^{(Xb-E_\beta)/(kT)}
}
}
\tag{6}
```

である．
これが求める一般的な関係式である．

### 4．弱い張力での近似

次に，張力が弱く，

```math
|Xa|\ll kT,\qquad |Xb|\ll kT
```

である場合を考える．
単量体当たりの平均長さを，

```math
\overline l=\frac{\overline L}{N}
```

と定義する．
式 (6) より，

```math
\overline l(X)
=\frac{
ae^{(Xa-E_\alpha)/(kT)}
+be^{(Xb-E_\beta)/(kT)}
}{
e^{(Xa-E_\alpha)/(kT)}
+e^{(Xb-E_\beta)/(kT)}
}
\tag{7}
```

となる．

ここで，

```math
\Delta=\frac{E_\alpha-E_\beta}{kT}
\tag{8}
```

とおく．
まず，張力がゼロのときの平均長さを求める．
式 (7) に $X=0$ を代入し，分子と分母を $e^{-E_\alpha/(kT)}$ で割ると，

```math
\boxed{
\overline l(0)=\frac{a+be^\Delta}{1+e^\Delta}
}
\tag{9}
```

を得る．

次に，張力による長さの変化を調べる．
式 (7) を $X$ で微分すると，

```math
\begin{aligned}
\frac{d\overline l}{dX}
=\frac{1}{kT}\biggl[
&\frac{
a^2e^{(Xa-E_\alpha)/(kT)}
+b^2e^{(Xb-E_\beta)/(kT)}
}{
e^{(Xa-E_\alpha)/(kT)}
+e^{(Xb-E_\beta)/(kT)}
}\\
&-\overline l^{\,2}
\biggr]
\end{aligned}
\tag{10}
```

となる．
この式は，張力による平均長さの変化率が，長さの分散を $kT$ で割ったものに等しいことを表している．

特に $X=0$ では，式 (8)，(9) より，

```math
\begin{aligned}
\left.\frac{d\overline l}{dX}\right|_{X=0}
=\frac{1}{kT}\biggl[
&\frac{a^2+b^2e^\Delta}{1+e^\Delta}\\
&-\left(\frac{a+be^\Delta}{1+e^\Delta}\right)^2
\biggr]
\end{aligned}
\tag{11}
```

となる．

したがって， $X$ の1次までのテイラー展開は，

```math
\begin{aligned}
\overline l(X)\simeq{}&
\frac{a+be^\Delta}{1+e^\Delta}\\
&+\frac{X}{kT}
\left[
\frac{a^2+b^2e^\Delta}{1+e^\Delta}
-\left(\frac{a+be^\Delta}{1+e^\Delta}\right)^2
\right]
\end{aligned}
```

である．
よって，

```math
\boxed{
\begin{aligned}
\overline l\simeq{}&
\frac{a+be^\Delta}{1+e^\Delta}\\
&+\frac{X}{kT}
\left\{
\frac{a^2+b^2e^\Delta}{1+e^\Delta}
-\left(\frac{a+be^\Delta}{1+e^\Delta}\right)^2
\right\}
\end{aligned}
}
\tag{12}
```

を得る．
これが単量体当たりの平均長さの弱張力近似である．

さらに，中括弧内の量は，

```math
\frac{a^2+b^2e^\Delta}{1+e^\Delta}
-\left(\frac{a+be^\Delta}{1+e^\Delta}\right)^2
=\frac{(a-b)^2e^\Delta}{(1+e^\Delta)^2}
```

と整理できるため，

```math
\boxed{
\overline l\simeq
\frac{a+be^\Delta}{1+e^\Delta}
+\frac{X}{kT}
\frac{(a-b)^2e^\Delta}{(1+e^\Delta)^2}
}
\tag{13}
```

とも表せる．

鎖全体の平均長さは $\overline L=N\overline l$ であるから，

```math
\boxed{
\begin{aligned}
\overline L\simeq N\biggl[
&\frac{a+be^\Delta}{1+e^\Delta}\\
&+\frac{X}{kT}
\left\{
\frac{a^2+b^2e^\Delta}{1+e^\Delta}
-\left(\frac{a+be^\Delta}{1+e^\Delta}\right)^2
\right\}
\biggr]
\end{aligned}
}
\tag{14}
```

が得られる．
これが鎖全体の長さと弱い張力との関係である．

### 5．結果の物理的意味

式 (12) の第1項は，張力がゼロのときの単量体当たりの平均長さであり，エネルギーが異なる2つの状態の占有確率によって決まる．
第2項は，張力による平均長さの変化であり，状態間の長さの差と熱揺らぎに関係する．

特に，この項の係数は長さの分散に等しく，必ず非負である．
したがって，張力を加えると平均鎖長は増加するか，不変となる．
また， $a=b$ の場合は両方の状態の長さが等しいため，状態の占有率が変化しても鎖全体の長さは変わらない．
