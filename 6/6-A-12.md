# 演習問題【6-A-12】

## 解答

### 1．固体の分配関数

固相に $N_s$ 個，気相に $N_g$ 個の原子が存在するものとする．
全原子数 $N$ は一定であるため，

```math
N=N_s+N_g
\tag{1}
```

が成り立つ．

まず，固体の分配関数を求める．
問題文の仮定により，固体内の各原子は振動数 $\omega$ の独立な3次元量子調和振動子として扱える．

1次元調和振動子のエネルギー準位は，

```math
E_n=\left(n+\frac12\right)\hbar\omega,
\qquad n=0,1,2,\ldots
```

である．
したがって，1次元調和振動子の分配関数は，

```math
\begin{aligned}
z_{\mathrm{1D}}
&=\sum_{n=0}^{\infty}e^{-E_n/(kT)}\\
&=e^{-\hbar\omega/(2kT)}
\sum_{n=0}^{\infty}e^{-n\hbar\omega/(kT)}\\
&=\frac{e^{-\hbar\omega/(2kT)}}
{1-e^{-\hbar\omega/(kT)}}\\
&=\frac{1}{2\sinh(\hbar\omega/(2kT))}
\end{aligned}
```

となる．
ここで，等比級数の和を用いた．

3次元調和振動子は，互いに独立な3つの1次元調和振動子からなるため，その分配関数は，

```math
z_{\mathrm{osc}}
=\left[2\sinh\left(\frac{\hbar\omega}{2kT}\right)\right]^{-3}
```

である．

次に，固体内の原子は，分離した原子に比べてエネルギーが $\phi$ だけ低い．
したがって，エネルギーの基準を分離原子の状態にとると，原子1個のエネルギーには $-\phi$ が加わり，分配関数には $e^{\phi/(kT)}$ が掛かる．

よって，固体内の原子1個の分配関数 $z_s(T)$ は，

```math
z_s(T)
=e^{\phi/(kT)}
\left[2\sinh\left(\frac{\hbar\omega}{2kT}\right)\right]^{-3}
```

である．
原子は独立に振動するため，固相全体の分配関数は，

```math
\boxed{
Z_s(T,N_s)
=\left[
e^{\phi/(kT)}
\left\{2\sinh\left(\frac{\hbar\omega}{2kT}\right)\right\}^{-3}
\right]^{N_s}
}
\tag{2}
```

となる．

### 2．気体の分配関数

気相は，質量 $m$ の単原子分子からなる古典的な理想気体である．
1粒子の並進分配関数は，相空間積分から，

```math
\begin{aligned}
z_g(T,V)
&=\frac{1}{h^3}\int_V d^3r
\int_{-\infty}^{\infty}
e^{-(p_x^2+p_y^2+p_z^2)/(2mkT)}
\,dp_x\,dp_y\,dp_z\\
&=\frac{V}{h^3}(2\pi mkT)^{3/2}\\
&=V\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\end{aligned}
```

と求められる．
ここで $h=2\pi\hbar$ であるため，

```math
\boxed{
z_g(T,V)=V\left(\frac{mkT}{2\pi\hbar^2}\right)^{3/2}
}
\tag{3}
```

となる．

同種原子 $N_g$ 個からなる理想気体の分配関数には，粒子の区別による重複を除く $1/N_g!$ の因子が付く．
したがって，

```math
\boxed{
Z_g(T,V,N_g)=\frac{\{z_g(T,V)\}^{N_g}}{N_g!}
}
\tag{4}
```

である．

### 3．平衡条件の導出

全系の分配関数は，固体と気体の分配関数の積で表される．
すなわち，

```math
Z=Z_s(T,N_s)Z_g(T,V,N_g)
```

である．
温度 $T$ ，体積 $V$ ，全原子数 $N$ を一定に保った平衡状態では，全系の Helmholtz 自由エネルギー

```math
F=-kT\log Z
```

が最小となる．
式 (1) より $N_s=N-N_g$ であるから，

```math
F(N_g)=F_s(T,N-N_g)+F_g(T,V,N_g)
```

となる．

平衡点が $0<N_g<N$ の範囲にあるとき，必要条件は，

```math
\frac{\partial F}{\partial N_g}=0
\tag{5}
```

である．

まず，固相の自由エネルギーは，式 (2) より，

```math
F_s=-kTN_s\log z_s(T)
```

となる．
したがって，

```math
\frac{\partial F_s}{\partial N_s}
=-kT\log z_s(T)
\tag{6}
```

である．

次に，気相の自由エネルギーは，式 (4) より，

```math
F_g=-kT\left\{N_g\log z_g-\log N_g!\right\}
```

となる．
$N_g\gg1$ に対して Stirling の近似

```math
\log N_g!\simeq N_g\log N_g-N_g
```

を用いると，

```math
\begin{aligned}
F_g
&\simeq-kTN_g
\left(\log z_g-\log N_g+1\right)\\
&=kTN_g\left(\log\frac{N_g}{z_g}-1\right)
\end{aligned}
```

である．
よって，

```math
\boxed{
\frac{\partial F_g}{\partial N_g}
=kT\log\frac{N_g}{z_g(T,V)}
}
\tag{7}
```

となる．

ここで $N_s=N-N_g$ であるため，式 (5) は，

```math
\frac{\partial F_g}{\partial N_g}
-\frac{\partial F_s}{\partial N_s}=0
```

と書ける．
式 (6)，(7) を代入すると，

```math
kT\log\frac{N_g}{z_g}
+kT\log z_s=0
```

となり，

```math
\log\frac{N_gz_s}{z_g}=0
```

を得る．
したがって，

```math
\boxed{
N_g=\frac{z_g(T,V)}{z_s(T)}
}
\tag{8}
```

が平衡条件である．

### 4．蒸気圧の導出

気相を理想気体とみなすと，状態方程式は，

```math
pV=N_gkT
```

である．
したがって，

```math
p=\frac{N_gkT}{V}
\tag{9}
```

となる．

式 (8) に式 (2)，(3) で定義した1原子当たりの分配関数を代入すると，

```math
\begin{aligned}
N_g
&=\frac{
V\left(\dfrac{mkT}{2\pi\hbar^2}\right)^{3/2}
}{
e^{\phi/(kT)}
\left[2\sinh\left(\dfrac{\hbar\omega}{2kT}\right)\right]^{-3}
}\\
&=V\left(\frac{mkT}{2\pi\hbar^2}\right)^{3/2}
\left[2\sinh\left(\frac{\hbar\omega}{2kT}\right)\right]^3
e^{-\phi/(kT)}
\end{aligned}
```

となる．
これを式 (9) に代入すれば，

```math
\boxed{
p(T)=kT
\left(\frac{mkT}{2\pi\hbar^2}\right)^{3/2}
\left[2\sinh\left(\frac{\hbar\omega}{2kT}\right)\right]^3
e^{-\phi/(kT)}
}
\tag{10}
```

が得られる．
これが，Einstein モデルに基づく固体とその蒸気の平衡における蒸気圧の温度依存性である．
