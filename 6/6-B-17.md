# 演習問題【6-B-17】
## 解答

### 1．張力一定のカノニカル集団

長さ $a$ の要素 $N$ 個が自由に回転できるつなぎ目で連結された鎖状分子を考える．
両端に加える張力を $X$ ，温度を $T$ とする．

張力の方向を $z$ 軸にとり，第 $i$ 要素と $z$ 軸とのなす角を $\theta_i$ ，方位角を $\varphi_i$ とする．
各要素の長さは $a$ であるから，張力方向への射影成分は $a\cos\theta_i$ である．
したがって，鎖の両端間の張力方向の成分 $l$ は，

```math
\boxed{l=\sum_{i=1}^{N}a\cos\theta_i}
\tag{1}
```

と表される．

ここで， $l$ は鎖の両端を結ぶベクトルの張力方向への射影成分を意味する．
張力一定の条件では，この量が外力に対する仕事に関与する．

通常のカノニカル分布では，エネルギー $E$ の状態の統計的な重みは $e^{-E/(kT)}$ である．
一方，張力 $X$ が一定のとき，鎖が張力方向に $l$ だけ伸びることによる仕事の寄与を考慮すると，有効エネルギーは $E-Xl$ である．
したがって，状態の重みは，

```math
e^{-(E-Xl)/(kT)}
=e^{-E/(kT)}e^{Xl/(kT)}
```

となる．

問題文の仮定により，振動などの運動エネルギーは分子の形状に依存しない．
そのため，長さと張力の関係を求める際には，向きに依存する因子 $e^{Xl/(kT)}$ だけを考えればよい．
以下では，

```math
\beta=\frac{1}{kT}
```

と定義する．

### 2．分配関数の計算

各要素の向きは，立体角要素

```math
d\omega_i=\sin\theta_i\,d\theta_i\,d\varphi_i
```

によって指定される．
したがって，張力一定の集団における分配関数 $Y$ は，

```math
Y=\int\cdots\int
e^{\beta Xl}
\prod_{i=1}^{N}d\omega_i
\tag{2}
```

と書ける．
式 (1) を代入すると，

```math
Y=\int\cdots\int
\exp\left(\beta Xa\sum_{i=1}^{N}\cos\theta_i\right)
\prod_{i=1}^{N}d\omega_i
```

となる．
指数関数の中の和を積の形に変形すれば，

```math
Y=\int\cdots\int
\prod_{i=1}^{N}e^{\beta Xa\cos\theta_i}
\prod_{i=1}^{N}d\omega_i
```

である．
各要素は独立に回転できるため，多重積分を各要素の積分に分離できる．
すなわち，

```math
Y=
\left[
\int_0^{2\pi}d\varphi
\int_0^\pi
e^{\beta Xa\cos\theta}\sin\theta\,d\theta
\right]^N
\tag{3}
```

となる．

ここで，1個の要素に関する角度積分を $I$ とする．
まず，方位角について積分すると，

```math
\int_0^{2\pi}d\varphi=2\pi
```

である．
次に，極角について積分する．

```math
I=2\pi\int_0^\pi
e^{\beta Xa\cos\theta}\sin\theta\,d\theta
```

ここで，

```math
u=\cos\theta,\qquad du=-\sin\theta\,d\theta
```

と置換すると，積分範囲は $\theta=0$ で $u=1$ ， $\theta=\pi$ で $u=-1$ となる．
よって，

```math
\begin{aligned}
I
&=2\pi\int_{-1}^{1}e^{\beta Xa u}\,du\\
&=2\pi\left[
\frac{e^{\beta Xa u}}{\beta Xa}
\right]_{-1}^{1}\\
&=\frac{2\pi}{\beta Xa}
\left(e^{\beta Xa}-e^{-\beta Xa}\right)\\
&=4\pi\frac{\sinh(\beta Xa)}{\beta Xa}
\end{aligned}
\tag{4}
```

を得る．
これを式 (3) に代入すれば，分配関数は，

```math
\boxed{
Y=\left[
4\pi\frac{\sinh(\beta Xa)}{\beta Xa}
\right]^N
}
\tag{5}
```

となる．
なお， $X=0$ では $\sinh x/x\to1$ であるから，式 (5) は $Y=(4\pi)^N$ に連続的に帰着する．
これは，各要素が球面全体のあらゆる方向を等しい重みでとることに対応する．

### 3．平均鎖長と張力の関係

分配関数 $Y$ の定義から，

```math
Y=\int\cdots\int e^{\beta Xl}\,d\omega_1\cdots d\omega_N
```

である．
これを張力 $X$ で微分すると，

```math
\frac{\partial Y}{\partial X}
=\beta\int\cdots\int
l\,e^{\beta Xl}\,d\omega_1\cdots d\omega_N
```

となる．
両辺を $Y$ で割れば，平均鎖長の定義より，

```math
\frac{\partial\log Y}{\partial X}
=\beta\overline l
```

である．
したがって，

```math
\boxed{
\overline l
=kT\left(\frac{\partial\log Y}{\partial X}\right)_{T,N}
}
\tag{6}
```

を得る．

式 (5) の対数をとると，

```math
\log Y
=N\left[
\log(4\pi)+\log\sinh(\beta Xa)-\log(\beta Xa)
\right]
```

となる．
これを $X$ で微分すれば，

```math
\frac{\partial\log Y}{\partial X}
=N\beta a\left[
\coth(\beta Xa)-\frac{1}{\beta Xa}
\right]
```

である．
これを式 (6) に代入すると，

```math
\begin{aligned}
\overline l
&=Na\left[
\coth(\beta Xa)-\frac{1}{\beta Xa}
\right]
\end{aligned}
```

を得る．
ここで，ランジュバン関数 $L(x)$ を，

```math
L(x)=\coth x-\frac1x
\tag{7}
```

と定義する．
また， $\beta=1/(kT)$ であるから，最終的に，

```math
\boxed{
\overline l=NaL\left(\frac{Xa}{kT}\right)
}
\tag{8}
```

となる．
これが求める鎖長と張力の関係である．

### 4．弱い張力および強い張力での振る舞い

式 (8) の物理的な意味を調べるため，張力の大きさによる極限を考える．

#### 4.1 弱い張力の場合

```math
x=\frac{Xa}{kT}\ll1
```

のとき，ランジュバン関数は，

```math
L(x)\simeq\frac{x}{3}
```

と近似できる．
したがって，

```math
\begin{aligned}
\overline l
&\simeq Na\frac{Xa}{3kT}\\
&=\frac{Na^2}{3kT}X
\end{aligned}
```

となる．
すなわち，

```math
\boxed{
\overline l\simeq\frac{Na^2}{3kT}X
}
\tag{9}
```

である．
弱い張力では，平均鎖長は張力に比例する．
これはフックの法則に対応する線形弾性である．
この近似では，有効なばね定数は $3kT/(Na^2)$ となる．

#### 4.2 強い張力の場合

一方，

```math
x=\frac{Xa}{kT}\gg1
```

のとき， $\coth x\to1$ ， $1/x\to0$ であるから，

```math
L(x)\to1
```

となる．
したがって，

```math
\boxed{
\overline l\to Na
}
\tag{10}
```

を得る．
これは，すべての要素が張力の方向にほぼ平行になり，鎖が最大長 $Na$ に近づくことを意味する．

以上より，この自由回転鎖モデルでは，平均鎖長と張力の関係はランジュバン関数によって与えられる．
