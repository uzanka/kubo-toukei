# 演習問題【6-B-18】

## 解答

透明・一様・等方的な媒質中を伝播する電磁波を考える．
対象とするのは，二つの横偏光をもつ単一の分枝であり，その位相屈折率 $n(\nu)$ と群屈折率

```math
n_g(\nu)=n(\nu)+\nu\frac{dn}{d\nu}
```

は，考察する周波数範囲でともに正であると仮定する．
したがって，波数の大きさは

```math
q(\nu)=\frac{2\pi\nu n(\nu)}{c}
```

で与えられ，周波数とともに単調に増加する．
媒質は損失をもたず，熱平衡温度を $T$ とする．

## 1．状態密度

体積 $V$ の媒質を考え，周期境界条件を課す．
波数空間で一つの状態が占める体積は $(2\pi)^3/V$ である．
二つの横偏光を考慮すると，波数の大きさが $q$ 以下の状態数は

```math
N(q)
=2\frac{V}{(2\pi)^3}\frac{4\pi q^3}{3}
=\frac{Vq^3}{3\pi^2}
```

となる．
これを微分すると，

```math
dN=\frac{Vq^2}{\pi^2}\,dq
```

を得る．

したがって，単位体積・単位周波数あたりの状態密度 $g(\nu)$ は

```math
g(\nu)
=\frac{1}{V}\frac{dN}{d\nu}
=\frac{q^2}{\pi^2}\frac{dq}{d\nu}
```

である．
ここで，

```math
\frac{dq}{d\nu}
=\frac{2\pi}{c}
\left(n+\nu\frac{dn}{d\nu}\right)
=\frac{2\pi n_g}{c}
```

および

```math
q^2=\frac{4\pi^2\nu^2n^2}{c^2}
```

を代入すると，

```math
\boxed{
g(\nu)=\frac{8\pi\nu^2}{c^3}n^2(\nu)n_g(\nu)
}
```

となる．

## 2．熱平衡における平均エネルギー

熱平衡にある周波数 $\nu$ の各正規モードは，エネルギー間隔 $h\nu$ のボース振動子として振る舞う．
零点エネルギーを除いた平均熱エネルギーは

```math
\overline{E}(\nu)
=\frac{h\nu}{\exp\!\left(\frac{h\nu}{k_BT}\right)-1}
```

である．

よって，単位体積・単位周波数あたりのエネルギー密度は，状態密度と各モードの平均エネルギーの積で与えられる：

```math
u_\nu(\nu)=g(\nu)\overline{E}(\nu).
```

先ほど求めた状態密度を代入して，

```math
\boxed{
u_\nu(\nu)
=
\frac{8\pi h\nu^3}{c^3}
\frac{n^2(\nu)n_g(\nu)}
{\exp\!\left(\frac{h\nu}{k_BT}\right)-1}
}
```

を得る．
これが，周波数に依存する屈折率をもつ媒質中のプランク型スペクトルエネルギー密度である．

## 3．角周波数による表示

角周波数を $\omega=2\pi\nu$ ，換算プランク定数を $\hbar=h/(2\pi)$ とする．
単位体積・単位角周波数あたりの状態密度は

```math
g_\omega(\omega)
=\frac{1}{2\pi}g\!\left(\frac{\omega}{2\pi}\right)
=\frac{\omega^2}{\pi^2c^3}n^2(\omega)n_g(\omega)
```

である．
したがって，

```math
\boxed{
u_\omega(\omega)
=
\frac{\hbar\omega^3}{\pi^2c^3}
\frac{n^2(\omega)n_g(\omega)}
{\exp\!\left(\frac{\hbar\omega}{k_BT}\right)-1}
}
```

となる．

ここで $u_\nu$ および $u_\omega$ は，電磁場と媒質の自由度が結合した正規モード全体の熱エネルギー密度を表す．
電磁場だけのエネルギー密度ではない．

## 4．非分散極限と真空極限

屈折率が周波数に依存しない非分散極限では，

```math
\frac{dn}{d\nu}=0,\qquad n_g=n
```

であるから，

```math
u_\nu(\nu)
=
\frac{8\pi h\nu^3}{c^3}
\frac{n^3}{\exp\!\left(\frac{h\nu}{k_BT}\right)-1}
```

となる．
さらに真空では $n=1$ であり，

```math
\boxed{
u_\nu(\nu)
=
\frac{8\pi h\nu^3}{c^3}
\frac{1}{\exp\!\left(\frac{h\nu}{k_BT}\right)-1}
}
```

を得る．
これは真空中の通常のプランクの法則に一致する．

以上より，透明・一様・等方的な媒質の，正の位相屈折率および正の群屈折率をもつ単一横波分枝について，分散媒質中のスペクトルエネルギー密度は

```math
\boxed{
u_\nu(\nu)
=
\frac{8\pi h\nu^3}{c^3}
\frac{n^2(\nu)n_g(\nu)}
{\exp\!\left(\frac{h\nu}{k_BT}\right)-1},
\qquad
n_g(\nu)=n(\nu)+\nu\frac{dn}{d\nu}
}
```

で与えられる．
