# 演習問題【6-B-18】

## 解答

### 分散性媒質中の Planck の法則の導出

#### 1．媒質中の波数と電磁振動のモード数

屈折率 $n$ が振動数 $\nu$ に依存する一様・等方的な媒質を考える．
真空中の光速を $c$ とすると，媒質中の光の波数 $q$ は

```math
q=\frac{2\pi\nu n(\nu)}{c}
\tag{1}
```

である．

次に，体積 $V$ の媒質において，波数の大きさが $q$ から $q+dq$ の範囲にある電磁振動のモード数 $dN$ を考える．
波数空間では，1つの偏光に対して単位体積当たりのモード数は $(2\pi)^{-3}$ である．
電磁波には独立な偏光状態が2つあり，波数の大きさが $q$ から $q+dq$ の範囲は，波数空間で半径 $q$ ，厚さ $dq$ の球殻に相当する．
その体積は $4\pi q^2dq$ である．
したがって，この球殻に含まれるモード数は

```math
dN
=2\frac{V}{(2\pi)^3}4\pi q^2dq
=\frac{Vq^2}{\pi^2}dq
\tag{2}
```

となる．
ここで，係数2は電磁波の2つの偏光状態を数えるためのものである．

#### 2．波数分布を振動数分布に変換する

分散性媒質では $n=n(\nu)$ であるため，波数 $q$ と振動数 $\nu$ の関係は式(1)のようになる．
両辺を $\nu$ で微分すると，

```math
\frac{dq}{d\nu}
=\frac{2\pi}{c}
\left[
n(\nu)+\nu\frac{dn(\nu)}{d\nu}
\right]
```

を得る．
したがって，

```math
dq
=\frac{2\pi}{c}
\left[
n(\nu)+\nu\frac{dn(\nu)}{d\nu}
\right]d\nu
\tag{3}
```

である．

ここで，解答例と同様に，括弧内の項を対数微分を用いて整理する．
まず，

```math
\begin{aligned}
\frac{d\log\{n(\nu)\nu\}}{d\log\nu}
&=\nu\frac{d}{d\nu}
\log\{n(\nu)\nu\}\\
&=\nu\frac{1}{n(\nu)\nu}
\frac{d}{d\nu}\{n(\nu)\nu\}\\
&=\frac{1}{n(\nu)}
\left[
n(\nu)+\nu\frac{dn(\nu)}{d\nu}
\right]
\end{aligned}
```

となる．
ここでは，対数微分の関係

```math
\frac{d\log f}{d\log\nu}
=\nu\frac{d\log f}{d\nu}
```

を用いた．

したがって，

```math
n(\nu)+\nu\frac{dn(\nu)}{d\nu}
=n(\nu)\frac{d\log\{n(\nu)\nu\}}{d\log\nu}
```

である．
これを式(3)に代入すれば，

```math
dq=\frac{2\pi n(\nu)}{c}
\frac{d\log\{n(\nu)\nu\}}{d\log\nu}
d\nu
\tag{4}
```

を得る．
これにより，波数の微小区間 $dq$ を，振動数の微小区間 $d\nu$ で表すことができた．

#### 3．振動数ごとの状態密度を求める

式(2)に式(1)と式(4)を代入すると，振動数が $\nu$ から $\nu+d\nu$ の範囲にあるモード数は

```math
\begin{aligned}
dN
&=\frac{V}{\pi^2}
\left(\frac{2\pi\nu n(\nu)}{c}\right)^2
\frac{2\pi n(\nu)}{c}
\frac{d\log\{n(\nu)\nu\}}{d\log\nu}
d\nu\\[4pt]
&=\frac{8\pi V\nu^2n^3(\nu)}{c^3}
\frac{d\log\{n(\nu)\nu\}}{d\log\nu}
d\nu
\end{aligned}
\tag{5}
```

となる．

ここで，状態密度 $g(\nu)$ を，単位体積・単位振動数当たりのモード数として

```math
dN=Vg(\nu)d\nu
```

により定義する．
式(5)と比較すれば，

```math
\boxed{
g(\nu)=\frac{8\pi\nu^2n^3(\nu)}{c^3}
\frac{d\log\{n(\nu)\nu\}}{d\log\nu}
}
\tag{6}
```

を得る．

なお，群屈折率を

```math
n_g(\nu)=n(\nu)+\nu\frac{dn(\nu)}{d\nu}
```

と定義すると，

```math
\frac{d\log\{n(\nu)\nu\}}{d\log\nu}
=\frac{n_g(\nu)}{n(\nu)}
```

であるため，状態密度は同じ式を用いて

```math
g(\nu)=\frac{8\pi\nu^2n^2(\nu)n_g(\nu)}{c^3}
```

とも表せる．
これは，屈折率の振動数依存性が，モードの数え上げに影響することを示している．

#### 4．Planck の法則を導出する

温度 $T$ において，振動数 $\nu$ の電磁振動の1モード当たりの平均熱エネルギーは，Planck の量子仮説により

```math
\varepsilon(\nu,T)
=\frac{h\nu}{\exp\!\left(\dfrac{h\nu}{kT}\right)-1}
\tag{7}
```

で与えられる．
ここで， $h$ は Planck 定数， $k$ は Boltzmann 定数である．
式(7)は熱的なエネルギーを表すものであり，零点エネルギーは含めない．

振動数が $\nu$ から $\nu+d\nu$ の範囲にあるモードの数は $Vg(\nu)d\nu$ であるから，その区間に含まれる熱エネルギーを体積 $V$ で割れば，単位体積・単位振動数当たりの輻射エネルギー密度 $u(\nu,T)$ が得られる．
したがって，

```math
u(\nu,T)=g(\nu)\varepsilon(\nu,T)
```

である．
式(6)と式(7)を代入すると，

```math
u(\nu,T)
=\frac{8\pi\nu^2n^3(\nu)}{c^3}
\frac{d\log\{n(\nu)\nu\}}{d\log\nu}
\frac{h\nu}{\exp\!\left(\dfrac{h\nu}{kT}\right)-1}
```

となる．
よって，分散性媒質中の Planck の輻射式は

```math
\boxed{
u(\nu,T)
=\frac{8\pi}{c^3}
\frac{
n^3(\nu)h\nu^3
\dfrac{d\log\{n(\nu)\nu\}}{d\log\nu}
}{
\exp\!\left(\dfrac{h\nu}{kT}\right)-1
}
}
\tag{8}
```

である．

最後に，真空の場合 $n(\nu)=1$ とすると，

```math
\frac{d\log\{n(\nu)\nu\}}{d\log\nu}=1
```

であるから，式(8)は

```math
\boxed{
u(\nu,T)
=\frac{8\pi h\nu^3}{c^3}
\frac{1}{\exp\!\left(\dfrac{h\nu}{kT}\right)-1}
}
```

となる．
これは真空中の通常の Planck の輻射式である．
以上より，状態密度に分散性媒質の屈折率とその振動数依存性を反映させることによって，媒質中の Planck の法則が導かれた．
