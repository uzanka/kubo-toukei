# 演習問題【6-B-23】

## 解答

### 古典的理想気体の状態密度の導出

#### 1．分配関数と状態密度の関係

古典的理想気体について，分子の並進運動のみを考え，分子の質量を $m$ ，分子数を $N$ ，容器の体積を $V$ とする．
分配関数は

```math
Z(\beta)
=\frac{V^N}{N!}
\left(\frac{2\pi m}{\beta h^2}\right)^{3N/2}
\tag{1}
```

である．
ここで，

```math
\beta=\frac{1}{kT}
```

であり， $k$ は Boltzmann 定数， $T$ は絶対温度， $h$ は Planck 定数である．

一方，状態密度 $\Omega(E)$ は，エネルギーが $E$ から $E+dE$ の範囲にある微視的状態の数を

```math
\Omega(E)dE
```

と表す関数である．
分配関数は，各状態の Boltzmann 因子をすべて足し合わせたものであるから，

```math
Z(\beta)=\int_0^\infty \Omega(E)e^{-\beta E}\,dE
\tag{2}
```

と書ける．
すなわち，分配関数は状態密度のラプラス変換であり，状態密度は分配関数の逆ラプラス変換によって求められる．

逆ラプラス変換の公式は，

```math
\Omega(E)=\frac{1}{2\pi i}
\int_{\beta'-i\infty}^{\beta'+i\infty}
Z(\beta)e^{\beta E}\,d\beta,
\qquad \beta'>0
\tag{3}
```

である．
この積分路は，複素 $\beta$ 平面上で実部が正の一定値 $\beta'$ をもつ垂直直線である．

式(1)を式(3)に代入すると，

```math
\begin{aligned}
\Omega(E)
={}&\frac{V^N}{N!}
\left(\frac{2\pi m}{h^2}\right)^{3N/2}\\
&\times\frac{1}{2\pi i}
\int_{\beta'-i\infty}^{\beta'+i\infty}
\frac{e^{\beta E}}{\beta^{3N/2}}\,d\beta
\end{aligned}
\tag{4}
```

を得る．
したがって，残る問題は複素積分を評価することである．

#### 2．$E<0$ の場合

理想気体の並進運動エネルギーは非負であるため，負のエネルギーをもつ状態は存在しない．
したがって，物理的には

```math
\Omega(E)=0\qquad(E<0)
```

である．
これを逆ラプラス変換の積分からも確認する．

式(4)の被積分関数は

```math
f(\beta)=\frac{e^{\beta E}}{\beta^{3N/2}}
```

である．
$E<0$ のとき， $\operatorname{Re}\beta$ が大きくなるほど $e^{\beta E}$ は指数関数的に減衰する．
そこで，逆ラプラス変換の積分路を右側の大きな半円で閉じる．
この領域には $\beta=0$ は含まれず，特異点も存在しないため，Cauchy の積分定理によって閉曲線上の積分はゼロとなる．
半円の半径を無限大にすると，半円部分の積分もゼロに収束するので，元の垂直積分もゼロとなる．

よって，

```math
\boxed{
\Omega(E)=0\qquad(E<0)
}
\tag{5}
```

である．

#### 3．$E>0$ の場合

式(4)の積分を計算するため，次の記号を導入する．

```math
s=\frac{3N}{2},
\qquad
A_N=\frac{V^N}{N!}
\left(\frac{2\pi m}{h^2}\right)^{3N/2}
```

すると，

```math
\Omega(E)=A_N I_s(E)
```

ただし，

```math
I_s(E)=\frac{1}{2\pi i}
\int_{\beta'-i\infty}^{\beta'+i\infty}
e^{\beta E}\beta^{-s}\,d\beta
\tag{6}
```

である．
ここで $N\geq1$ なので $s>0$ である．

この積分に対して，逆ラプラス変換の一般公式

```math
\boxed{
\frac{1}{2\pi i}
\int_{\beta'-i\infty}^{\beta'+i\infty}
\frac{e^{\beta E}}{\beta^s}\,d\beta
=\frac{E^{s-1}}{\Gamma(s)}
\qquad(E>0,\ s>0)
}
\tag{7}
```

が成り立つ．
ここで， $\Gamma(s)$ はガンマ関数であり，

```math
\Gamma(s)=\int_0^\infty t^{s-1}e^{-t}\,dt
\qquad(s>0)
\tag{8}
```

で定義される．

##### 一般公式の意味

式(7)は，逆ラプラス変換の積分路を適切に変形することで得られる．
$E>0$ では，積分路を負の実軸上の分岐切断を囲む Hankel 型の積分路に変形できる．
ここで変数を $z=\beta E$ と置くと，

```math
\begin{aligned}
I_s(E)
&=\frac{E^{s-1}}{2\pi i}
\int_{\mathcal H}e^z z^{-s}\,dz\\
&=\frac{E^{s-1}}{\Gamma(s)}
\end{aligned}
```

となる．
$\mathcal H$ は負の実軸上の分岐切断を囲む Hankel 型積分路であり，最後の等式はガンマ関数の逆数に関する積分表示によるものである．
この表示によって， $s$ が整数でない場合にも式(7)が成立する．

なお， $s$ が正の整数である場合には， $\beta=0$ は極となり，Cauchy の積分公式から同じ結果を得られる．
一方，整数でない場合には $\beta=0$ は分岐点となるため，極に対する留数計算だけでは不十分である．
式(7)を用いることで， $N$ の偶奇による場合分けをせずに計算できる．

##### 状態密度の計算

式(7)を式(6)に適用すると，

```math
I_s(E)=\frac{E^{s-1}}{\Gamma(s)}
\qquad(E>0)
```

を得る．
$s=3N/2$ を代入すれば，

```math
I_{3N/2}(E)
=\frac{E^{3N/2-1}}{\Gamma(3N/2)}
```

である．
したがって，

```math
\boxed{
\Omega(E)=
\frac{V^N}{N!}
\left(\frac{2\pi m}{h^2}\right)^{3N/2}
\frac{E^{3N/2-1}}{\Gamma(3N/2)}
\qquad(E>0)
}
\tag{9}
```

となる．

#### 4．$E=0$ の場合と最終結果

式(9)のエネルギー依存性は $E^{3N/2-1}$ である．
$N\geq1$ ならば，

```math
\frac{3N}{2}-1\geq\frac12>0
```

であるから，

```math
\lim_{E\to0^+}\Omega(E)=0
```

となる．
したがって， $E=0$ でも $\Omega(0)=0$ と定められる．

以上をまとめると，古典的理想気体の状態密度は，

```math
\boxed{
\Omega(E)=
\begin{cases}
\displaystyle
\frac{V^N}{N!}
\left(\frac{2\pi m}{h^2}\right)^{3N/2}
\frac{E^{3N/2-1}}{\Gamma(3N/2)}
& (E>0),\\[12pt]
0 & (E\leq0)
\end{cases}
}
\tag{10}
```

である．

最後に，この結果を式(2)に代入すると，

```math
\begin{aligned}
Z(\beta)
&=A_N\int_0^\infty
\frac{E^{s-1}}{\Gamma(s)}e^{-\beta E}\,dE\\
&=A_N\frac{1}{\Gamma(s)}
\frac{\Gamma(s)}{\beta^s}\\
&=A_N\beta^{-s}
\end{aligned}
```

となる．
ここでは，ガンマ関数の積分表示において $t=\beta E$ と変数変換した．
これは最初に与えられた分配関数(1)と一致する．
したがって，求めた状態密度は分配関数の逆ラプラス変換として整合している．
