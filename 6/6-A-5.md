# 演習問題【6-A-5】

## 解答

### 1．エネルギーを運動量で表す

特殊相対論では，質量 $m$ の粒子のエネルギー $\varepsilon$ と運動量 $\mathbf p=(p_x,p_y,p_z)$ の間に，

```math
\varepsilon^2=p^2c^2+m^2c^4
```

という関係が成り立つ．
ここで，

```math
p^2=p_x^2+p_y^2+p_z^2
```

であり， $c$ は光速度である．
したがって，エネルギーは運動量の関数として，

```math
\begin{aligned}
\varepsilon
&=\sqrt{c^2(p_x^2+p_y^2+p_z^2)+m^2c^4}\\
&=c\sqrt{p_x^2+p_y^2+p_z^2+(mc)^2}
\end{aligned}
\tag{1}
```

と表される．

### 2．カノニカル分布における運動量の平均値の関係

絶対温度 $T$ の熱平衡状態にある粒子の運動量は，Maxwell–Boltzmann 分布に従う．
逆温度を

```math
\beta=\frac{1}{kT}
```

とすると，運動量 $\mathbf p$ に関する確率密度は $e^{-\beta\varepsilon}$ に比例する．
したがって，運動量だけに依存する物理量 $A(\mathbf p)$ の平均値は，

```math
\overline A=
\frac{
\displaystyle\int_{\mathbb R^3}A(\mathbf p)e^{-\beta\varepsilon}\,d^3p
}{
\displaystyle\int_{\mathbb R^3}e^{-\beta\varepsilon}\,d^3p
}
\tag{2}
```

と書ける．
ここで， $d^3p=dp_x\,dp_y\,dp_z$ である．

この分布から，次の恒等式を導く．
運動量成分 $p_i$ と $p_j$ を考え，

```math
\frac{\partial}{\partial p_j}
\left(p_i e^{-\beta\varepsilon}\right)
=
\delta_{ij}e^{-\beta\varepsilon}
-\beta p_i\frac{\partial\varepsilon}{\partial p_j}
e^{-\beta\varepsilon}
\tag{3}
```

が成り立つ．
ここで， $\delta_{ij}$ はクロネッカーのデルタである．

式 (3) を運動量空間全体で積分する．
運動量の絶対値が無限大に近づくと $e^{-\beta\varepsilon}$ は指数関数的に減少するため，積分の境界項はゼロとなる．
したがって，

```math
\int_{\mathbb R^3}
\frac{\partial}{\partial p_j}
\left(p_i e^{-\beta\varepsilon}\right)d^3p=0
```

である．
よって，

```math
\delta_{ij}\int_{\mathbb R^3}e^{-\beta\varepsilon}\,d^3p
=
\beta\int_{\mathbb R^3}
p_i\frac{\partial\varepsilon}{\partial p_j}
e^{-\beta\varepsilon}\,d^3p
```

となる．
両辺を分配関数に相当する運動量積分で割り，式 (2) の平均値の定義を用いれば，

```math
\overline{p_i\frac{\partial\varepsilon}{\partial p_j}}
=\frac{\delta_{ij}}{\beta}
```

を得る．
ここで $\beta=1/(kT)$ を代入すると，

```math
\boxed{
\overline{p_i\frac{\partial\varepsilon}{\partial p_j}}
=\delta_{ij}kT
}
\tag{4}
```

となる．
これが本問題で用いる統計力学的な関係式である．

### 3．エネルギーの運動量微分を計算する

式 (1) から，エネルギーを運動量成分 $p_j$ で偏微分すると，

```math
\frac{\partial\varepsilon}{\partial p_j}
=\frac{c^2p_j}{\varepsilon}
\tag{5}
```

となる．
これを式 (4) に代入すると，

```math
\boxed{
\overline{\frac{c^2p_ip_j}{\varepsilon}}
=\delta_{ij}kT
}
\tag{6}
```

を得る．

### 4．運動量を速度で表す

問題文で与えられた相対論的な運動量とエネルギーの式は，

```math
p_i=\frac{mv_i}{\sqrt{1-(v/c)^2}}
```

および，

```math
\varepsilon=\frac{mc^2}{\sqrt{1-(v/c)^2}}
```

である．
これらを式 (6) の左辺に代入すると，

```math
\begin{aligned}
\frac{c^2p_ip_j}{\varepsilon}
&=
\frac{
c^2
\displaystyle\frac{mv_i}{\sqrt{1-(v/c)^2}}
\displaystyle\frac{mv_j}{\sqrt{1-(v/c)^2}}
}{
\displaystyle\frac{mc^2}{\sqrt{1-(v/c)^2}}
}\\
&=\frac{mv_iv_j}{\sqrt{1-(v/c)^2}}
\end{aligned}
```

となる．
したがって，式 (6) は，

```math
\boxed{
\overline{
\frac{mv_iv_j}{\sqrt{1-(v/c)^2}}
}
=\delta_{ij}kT
}
\tag{7}
```

と書ける．

### 5．求める式を導く

式 (7) において $i=j$ とすると， $\delta_{ii}=1$ であるから，

```math
\overline{
\frac{mv_i^2}{\sqrt{1-(v/c)^2}}
}=kT
```

となる．
両辺を $2$ で割れば，

```math
\boxed{
\overline{
\frac{\frac12 mv_i^2}{\sqrt{1-(v/c)^2}}
}
=\frac12 kT
}
```

を得る．
これが求める式である．
