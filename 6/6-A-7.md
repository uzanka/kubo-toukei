# 演習問題【6-A-7】

## 解答

### 1．電磁波の定常振動モードと分配関数

体積 $V$ の真空の箱が温度 $T$ の熱浴に接している場合を考える．
箱の内部の電磁波は，境界条件によって定まる多数の定常振動モードから構成される．
角振動数が $\omega$ から $\omega+d\omega$ の間にあるモードの数は，

```math
Vg(\omega)\,d\omega
=\frac{V\omega^2}{\pi^2c^3}\,d\omega
\tag{1}
```

で与えられる．
ここで， $c$ は光速度であり， $g(\omega)$ は単位体積当たりのモードの状態密度である．

角振動数 $\omega$ の各モードは，量子調和振動子として扱える．
通常の熱輻射のエネルギーを求めるため，以下では真空のゼロ点エネルギーを基準から差し引き，熱的な励起エネルギーのみを扱う．
このとき，角振動数 $\omega$ のモードの分配関数 $z_\omega$ は，

```math
z_\omega
=\sum_{n=0}^{\infty}e^{-n\hbar\omega/(kT)}
=\frac{1}{1-e^{-\hbar\omega/(kT)}}
\tag{2}
```

となる．
ここで， $\hbar$ は換算プランク定数， $n$ はそのモードに存在する光子の数である．

各モードは独立に扱えるため，全分配関数は各モードの分配関数の積で表される．
したがって，Helmholtz の自由エネルギー $F$ は，

```math
F=-kT\log Z
=-kT\sum_{\text{modes}}\log z_\omega
```

である．
式 (1)，(2) を用いて，モードの和を積分に置き換えると，

```math
\boxed{
F(V,T)
=kTV\int_0^\infty
\frac{\omega^2}{\pi^2c^3}
\log\left(1-e^{-\hbar\omega/(kT)}\right)d\omega
}
\tag{3}
```

を得る．
これはゼロ点エネルギーを差し引いた熱的な自由エネルギーである．

### 2．自由エネルギーから圧力を求める

温度一定のもとで体積を変化させたとき，Helmholtz の自由エネルギーと圧力の関係は，

```math
p=-\left(\frac{\partial F}{\partial V}\right)_T
\tag{4}
```

である．
式 (3) では，積分の被積分関数は体積 $V$ に依存しない．
したがって，体積で微分すると，

```math
\boxed{
p=-kT\int_0^\infty
\frac{\omega^2}{\pi^2c^3}
\log\left(1-e^{-\hbar\omega/(kT)}\right)d\omega
}
\tag{5}
```

となる．

### 3．部分積分による圧力の変形

式 (5) の積分を部分積分で変形する．
計算を簡潔にするため，

```math
a=\frac{\hbar}{kT}
```

と置く．
このとき，

```math
p=-\frac{kT}{\pi^2c^3}
\int_0^\infty \omega^2
\log(1-e^{-a\omega})\,d\omega
\tag{6}
```

である．

部分積分において，

```math
f(\omega)=\log(1-e^{-a\omega}),
\qquad
dg=\omega^2\,d\omega
```

とすると，

```math
df=\frac{a}{e^{a\omega}-1}\,d\omega,
\qquad
g=\frac{\omega^3}{3}
```

となる．
したがって，

```math
\begin{aligned}
\int_0^\infty\omega^2\log(1-e^{-a\omega})\,d\omega
&=\left[
\frac{\omega^3}{3}\log(1-e^{-a\omega})
\right]_0^\infty\\
&\quad-\frac{a}{3}\int_0^\infty
\frac{\omega^3}{e^{a\omega}-1}\,d\omega
\end{aligned}
\tag{7}
```

を得る．

ここで，境界項を確認する．
$\omega\to\infty$ では，

```math
\log(1-e^{-a\omega})\sim-e^{-a\omega}
```

であるため，

```math
\omega^3\log(1-e^{-a\omega})\to0
```

となる．
また， $\omega\to0$ では，

```math
\log(1-e^{-a\omega})\sim\log(a\omega)
```

であるが，

```math
\omega^3\log(a\omega)\to0
```

となる．
したがって，式 (7) の境界項は両端でゼロである．
よって，

```math
\boxed{
\int_0^\infty\omega^2\log(1-e^{-a\omega})\,d\omega
=-\frac{a}{3}\int_0^\infty
\frac{\omega^3}{e^{a\omega}-1}\,d\omega
}
\tag{8}
```

となる．
これを式 (6) に代入し， $a=\hbar/(kT)$ を用いると，

```math
\begin{aligned}
p
&=\frac{kTa}{3\pi^2c^3}
\int_0^\infty\frac{\omega^3}{e^{a\omega}-1}\,d\omega\\
&=\frac{\hbar}{3\pi^2c^3}
\int_0^\infty
\frac{\omega^3}{e^{\hbar\omega/(kT)}-1}\,d\omega
\end{aligned}
```

を得る．
すなわち，

```math
\boxed{
p=\frac13\int_0^\infty
\frac{\omega^2}{\pi^2c^3}
\frac{\hbar\omega}{e^{\hbar\omega/(kT)}-1}\,d\omega
}
\tag{9}
```

である．

### 4．エネルギー密度との比較

角振動数 $\omega$ のモードの平均エネルギーは，分配関数から，

```math
\begin{aligned}
\varepsilon(\omega,T)
&=-\frac{\partial\log z_\omega}{\partial\beta}\\
&=\frac{\hbar\omega}{e^{\hbar\omega/(kT)}-1}
\end{aligned}
\tag{10}
```

と求められる．
ここで， $\beta=1/(kT)$ である．

式 (1) より，単位体積当たりのモード数は $g(\omega)d\omega$ である．
したがって，単位体積当たりの全輻射エネルギー，すなわちエネルギー密度 $u$ は，

```math
\begin{aligned}
u
&=\int_0^\infty g(\omega)\varepsilon(\omega,T)\,d\omega\\
&=\int_0^\infty
\frac{\omega^2}{\pi^2c^3}
\frac{\hbar\omega}{e^{\hbar\omega/(kT)}-1}\,d\omega
\end{aligned}
\tag{11}
```

である．

式 (9) と式 (11) を比較すれば，

```math
\boxed{
p=\frac13u
}
```

が得られる．
これにより，熱輻射が箱の壁に及ぼす圧力は，熱的な輻射エネルギー密度の $1/3$ に等しいことが示された．

### 5．ゼロ点エネルギーに関する注意

量子調和振動子のエネルギーを $(n+\frac12)\hbar\omega$ と定義すると，平均エネルギーにはゼロ点エネルギー $\hbar\omega/2$ も含まれる．
しかし，これを全モードについて積分すると，

```math
\frac12\int_0^\infty
\frac{\omega^2}{\pi^2c^3}\hbar\omega\,d\omega
```

となり，無限大に発散する．
また，その寄与は自由エネルギーでは体積に比例するため，温度に依存しないという理由だけで体積微分の際に消えるわけではない．

本問で求める通常の熱輻射の圧力とエネルギー密度は，真空のゼロ点エネルギーの寄与を差し引いた熱的な量として扱う必要がある．
この定義のもとで，部分積分の境界項も適切に消え， $p=u/3$ が得られるのである．
