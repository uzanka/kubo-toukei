# 演習問題【6-B-21】

## 解答

### 1次元および2次元の結晶の Debye 熱容量

Debye 模型では，固体中の格子振動を，分散関係が線形である音響振動モードの集まりとして近似する．
本問題では，この考え方を1次元および2次元の結晶に適用し，熱容量の温度依存性を求める．

以下では，原子数を $N$ ，Boltzmann 定数を $k$ ，換算 Planck 定数を $\hbar$ とする．
解答例と同様に，縦波1分枝と横波2分枝を考え，全振動モード数は $3N$ とする．

#### 1．振動数の状態密度

状態密度 $g(\omega)$ を，角振動数が $\omega$ から $\omega+d\omega$ の範囲にある振動モードの総数が $g(\omega)d\omega$ となるように定義する．
Debye 模型では，振動数が切断振動数 $\omega_D$ を超えるモードは含めず，モード数が全体で $3N$ となるように $\omega_D$ を定める．

##### (1) 1次元の場合

長さ $L$ の結晶に周期境界条件を課すと，許される波数は間隔 $2\pi/L$ で並ぶ．
正の振動数をもつモードを数える際には，波数 $q$ と $-q$ の両方を数えるので，波数の大きさが $q$ から $q+dq$ の範囲にある状態数は

```math
dN_q=2\frac{L}{2\pi}dq
=\frac{L}{\pi}dq
```

である．

縦波の速さを $c_l$ ，横波の速さを $c_t$ とすると，それぞれの分散関係は

```math
\omega_l=c_lq,\qquad
\omega_t=c_tq
```

である．
横波は2つの独立な偏極をもつため，振動数が $\omega$ から $\omega+d\omega$ の範囲にあるモード数は

```math
\begin{aligned}
g_1(\omega)d\omega
&=\frac{L}{\pi}
\left(\frac{1}{c_l}+\frac{2}{c_t}\right)d\omega\\
&=\frac{L}{\pi}S_1\,d\omega
\end{aligned}
\tag{1}
```

となる．
ただし，

```math
S_1=\frac{1}{c_l}+\frac{2}{c_t}
```

とおいた．

Debye 切断振動数 $\omega_D$ は，すべてのモード数が $3N$ となる条件

```math
\int_0^{\omega_D}g_1(\omega)d\omega=3N
```

によって定める．
式(1)を代入すれば，

```math
\frac{L}{\pi}S_1\omega_D=3N
```

となるため，

```math
\omega_D=\frac{3\pi N}{LS_1}
\tag{2}
```

を得る．
ここで，平均音速 $\bar c$ を

```math
\frac{1}{\bar c}
=\frac{1}{3}
\left(\frac{1}{c_l}+\frac{2}{c_t}\right)
```

で定義すると，

```math
\boxed{
\omega_D=\frac{\pi N\bar c}{L}
}
\tag{3}
```

である．

さらに，式(1)を全モード数 $3N$ で規格化すれば，

```math
\boxed{
g_1(\omega)=\frac{3N}{\omega_D}
\qquad (0<\omega<\omega_D)
}
\tag{4}
```

となる．

##### (2) 2次元の場合

面積 $L^2$ の結晶を考える．
波数空間で，波数の大きさが $q$ から $q+dq$ の範囲にある領域は，半径 $q$ ，厚さ $dq$ の円環である．
その面積は $2\pi q\,dq$ であるため，この範囲にある状態数は

```math
dN_q
=\frac{L^2}{(2\pi)^2}2\pi q\,dq
=\frac{L^2}{2\pi}q\,dq
```

となる．

各分枝について $\omega=cq$ であるから，

```math
q=\frac{\omega}{c},
\qquad
dq=\frac{d\omega}{c}
```

である．
これを用いて縦波1分枝と横波2分枝のモード数を加えると，

```math
\begin{aligned}
g_2(\omega)d\omega
&=\frac{L^2}{2\pi}
\left(\frac{1}{c_l^2}+\frac{2}{c_t^2}\right)
\omega\,d\omega\\
&=\frac{L^2}{2\pi}S_2\omega\,d\omega
\end{aligned}
\tag{5}
```

を得る．
ただし，

```math
S_2=\frac{1}{c_l^2}+\frac{2}{c_t^2}
```

である．

同様に，全モード数が $3N$ となる条件

```math
\int_0^{\omega_D}g_2(\omega)d\omega=3N
```

を用いると，

```math
\frac{L^2}{2\pi}S_2
\int_0^{\omega_D}\omega\,d\omega=3N
```

となる．
よって，

```math
\frac{L^2}{4\pi}S_2\omega_D^2=3N
```

である．
したがって，

```math
\boxed{
\omega_D^2=\frac{12\pi N}{L^2S_2}
}
\tag{6}
```

を得る．
また，状態密度は

```math
\boxed{
g_2(\omega)=\frac{6N}{\omega_D^2}\omega
\qquad (0<\omega<\omega_D)
}
\tag{7}
```

となる．

#### 2．熱容量の一般式

角振動数 $\omega$ の1つの振動モードは量子調和振動子として扱える．
その平均熱エネルギーは

```math
\epsilon(\omega,T)
=\frac{\hbar\omega}
{e^{\hbar\omega/(kT)}-1}
```

である．
ここでは温度に依存しない零点エネルギーを省略しているが，これは熱容量には寄与しない．

定積熱容量 $C$ は内部エネルギーを温度で微分したものである．
したがって，

```math
C=\int_0^{\omega_D}
g(\omega)
\frac{\partial\epsilon(\omega,T)}{\partial T}
\,d\omega
```

となる．

```math
x=\frac{\hbar\omega}{kT}
```

とおいて温度微分を計算すると，

```math
\frac{\partial\epsilon}{\partial T}
=kx^2\frac{e^x}{(e^x-1)^2}
```

を得る．
よって，熱容量の一般式は

```math
\boxed{
C=k\int_0^{\omega_D}
g(\omega)
\left(\frac{\hbar\omega}{kT}\right)^2
\frac{e^{\hbar\omega/(kT)}}
{\left(e^{\hbar\omega/(kT)}-1\right)^2}
\,d\omega
}
\tag{8}
```

である．

以下では，

```math
\Theta=\frac{\hbar\omega_D}{k}
```

と定義する．
これは Debye 温度である．

#### 3．1次元の熱容量 $C_1$

式(4)を式(8)に代入すると，

```math
C_1
=3Nk\int_0^{\omega_D}
\frac{1}{\omega_D}
\left(\frac{\hbar\omega}{kT}\right)^2
\frac{e^{\hbar\omega/(kT)}}
{\left(e^{\hbar\omega/(kT)}-1\right)^2}
\,d\omega
\tag{9}
```

となる．
ここで，

```math
\xi=\frac{\hbar\omega}{kT},
\qquad
d\omega=\frac{kT}{\hbar}d\xi
```

と変数変換する．
積分範囲は $0\leq\xi\leq\Theta/T$ である．
また，

```math
\frac{kT}{\hbar\omega_D}=\frac{T}{\Theta}
```

であることから，

```math
\boxed{
C_1=3Nk\frac{T}{\Theta}
\int_0^{\Theta/T}
\frac{\xi^2e^\xi}{(e^\xi-1)^2}\,d\xi
}
\tag{10}
```

を得る．

#### 4．2次元の熱容量 $C_2$

式(7)を式(8)に代入すると，

```math
\begin{aligned}
C_2
=6Nk\int_0^{\omega_D}
&\frac{\omega}{\omega_D^2}
\left(\frac{\hbar\omega}{kT}\right)^2\\
&\times
\frac{e^{\hbar\omega/(kT)}}
{\left(e^{\hbar\omega/(kT)}-1\right)^2}
\,d\omega
\end{aligned}
\tag{11}
```

となる．
ここでも，

```math
\xi=\frac{\hbar\omega}{kT}
```

とおく．
このとき，

```math
\omega\,d\omega
=\left(\frac{kT}{\hbar}\right)^2\xi\,d\xi
```

であるから，式(11)は

```math
\boxed{
C_2=6Nk\left(\frac{T}{\Theta}\right)^2
\int_0^{\Theta/T}
\frac{\xi^3e^\xi}{(e^\xi-1)^2}\,d\xi
}
\tag{12}
```

となる．

#### 5．高温極限

高温 $T\gg\Theta$ では，積分範囲において $\hbar\omega/(kT)\ll1$ となる．
したがって，

```math
\frac{x^2e^x}{(e^x-1)^2}\longrightarrow1
\qquad (x\to0)
```

を利用できる．
このとき式(8)より，

```math
C\simeq k\int_0^{\omega_D}g(\omega)d\omega
```

である．
全モード数は $3N$ なので，

```math
\boxed{
C\longrightarrow3Nk
}
```

となる．
これは Dulong–Petit の法則に対応する古典極限であり，1次元・2次元のどちらでも成立する．

#### 6．低温極限

低温 $T\ll\Theta$ では， $\Theta/T\gg1$ である．
したがって，式(10)および式(12)の積分上限を $+\infty$ に置き換えることができる．

積分を計算するために，次の関係を用いる．
$m>1$ に対して，

```math
\begin{aligned}
I_m
&=\int_0^\infty
\frac{\xi^m e^\xi}{(e^\xi-1)^2}\,d\xi\\
&=m\int_0^\infty\frac{\xi^{m-1}}{e^\xi-1}\,d\xi\\
&=\Gamma(m+1)\zeta(m)
\end{aligned}
\tag{13}
```

である．
第2行は部分積分によるものであり， $\Gamma(s)$ はガンマ関数， $\zeta(s)$ は Riemann のゼータ関数である．

##### (1) 1次元

式(10)より，

```math
C_1\simeq3Nk\frac{T}{\Theta}
\int_0^\infty
\frac{\xi^2e^\xi}{(e^\xi-1)^2}\,d\xi
```

である．
式(13)に $m=2$ を代入すると，

```math
\int_0^\infty
\frac{\xi^2e^\xi}{(e^\xi-1)^2}\,d\xi
=2\zeta(2)
=\frac{\pi^2}{3}
```

となる．
したがって，

```math
\boxed{
C_1\simeq\pi^2Nk\frac{T}{\Theta}
}
\tag{14}
```

を得る．
よって，1次元の低温熱容量は温度 $T$ に比例する．

##### (2) 2次元

式(12)より，

```math
C_2\simeq6Nk\left(\frac{T}{\Theta}\right)^2
\int_0^\infty
\frac{\xi^3e^\xi}{(e^\xi-1)^2}\,d\xi
```

である．
式(13)に $m=3$ を代入すると，

```math
\int_0^\infty
\frac{\xi^3e^\xi}{(e^\xi-1)^2}\,d\xi
=6\zeta(3)
```

となる．
したがって，

```math
\boxed{
C_2\simeq36\zeta(3)Nk
\left(\frac{T}{\Theta}\right)^2
}
\tag{15}
```

を得る．
$\zeta(3)\simeq1.2020569$ なので，

```math
\boxed{
C_2\simeq43.27Nk
\left(\frac{T}{\Theta}\right)^2
}
\tag{16}
```

である．
よって，2次元の低温熱容量は温度の2乗に比例する．

#### 7．結論

以上より，Debye 模型では，低温における熱容量は空間次元によって異なる温度依存性を示す．

```math
\boxed{
\begin{aligned}
C_1&\propto T &&\text{（1次元）}\\
C_2&\propto T^2 &&\text{（2次元）}\\
C_3&\propto T^3 &&\text{（3次元）}
\end{aligned}
}
```

すなわち，線形分散関係をもつ音響振動モードを考えると，低温での熱容量は空間次元 $d$ に対して $T^d$ に比例する．
これは，次元による状態密度の違いが熱容量の温度依存性に反映されるためである．
