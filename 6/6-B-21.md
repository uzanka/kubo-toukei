# 演習問題【6-B-21】

## 解答

### 1次元および2次元の結晶の Debye 熱容量

#### 1．模型の設定

Debye 模型では，結晶中の格子振動を，線形分散関係をもつ音響振動モードの集まりとして近似する．

ここでは，結晶の空間次元を $d$ とし，各原子の変位自由度は結晶の次元内に限られるものとする．
したがって，1原子あたりの振動自由度は $d$ 個であり，全振動モード数は $dN$ である．
また，面外振動や光学分枝は考えず，すべての音響分枝を線形分散で近似する．

このとき，1次元では縦波1分枝，2次元では縦波1分枝と横波1分枝を考える．
各分枝の分散関係は

```math
\omega_s=c_s q
```

とする．
ここで $q$ は波数の大きさ， $c_s$ は分枝 $s$ の音速である．

以下では，結晶の大きさと原子数を固定し，音速および振動数が温度に依存しない調和 Debye 模型を扱う．

#### 2．振動数の状態密度

状態密度 $g(\omega)$ は，角振動数が $\omega$ から $\omega+d\omega$ の範囲にある振動モード数が

```math
g(\omega)d\omega
```

となるように定義する．
Debye 振動数 $\omega_D$ は，全モード数が $dN$ となるように定める．

##### 2.1．1次元の場合

長さ $L$ の結晶に周期境界条件を課すと，許される波数の間隔は

```math
\Delta q=\frac{2\pi}{L}
```

である．
波数の大きさが $q$ から $q+dq$ の範囲にある状態数は，正負の波数を数えて

```math
dN_q=2\frac{L}{2\pi}dq
=\frac{L}{\pi}dq
```

となる．

1次元では縦波1分枝のみを考える．
その分散関係は

```math
\omega=c_lq
```

であり，

```math
dq=\frac{d\omega}{c_l}
```

だから，状態密度は

```math
g_1(\omega)d\omega
=\frac{L}{\pi c_l}d\omega
```

となる．
すなわち，

```math
g_1(\omega)=\frac{L}{\pi c_l}
\qquad (0<\omega<\omega_D)
```

である．

1次元結晶の全振動モード数は $N$ なので，

```math
\int_0^{\omega_D}g_1(\omega)d\omega=N
```

と規格化する．
よって，

```math
\frac{L}{\pi c_l}\omega_D=N
```

から，

```math
\boxed{
\omega_D=\frac{\pi Nc_l}{L}
}
```

を得る．
したがって状態密度は

```math
\boxed{
g_1(\omega)=\frac{N}{\omega_D}
\qquad (0<\omega<\omega_D)
}
\tag{1}
```

となる．

##### 2.2．2次元の場合

面積 $A$ の結晶に周期境界条件を課す．
波数空間で一つの状態が占める面積は

```math
\frac{(2\pi)^2}{A}
```

である．
波数の大きさが $q$ から $q+dq$ の範囲にある領域は，半径 $q$ ，幅 $dq$ の円環であり，その面積は $2\pi q\,dq$ である．
したがって，この範囲にある状態数は

```math
dN_q
=\frac{A}{(2\pi)^2}2\pi q\,dq
=\frac{A}{2\pi}q\,dq
```

となる．

2次元では，縦波1分枝と横波1分枝を考える．
各分枝について

```math
\omega_s=c_sq,\qquad
q=\frac{\omega}{c_s},\qquad
dq=\frac{d\omega}{c_s}
```

である．
したがって，両分枝を合計した状態密度は

```math
\begin{aligned}
g_2(\omega)d\omega
&=\frac{A}{2\pi}
\left(
\frac{1}{c_l^2}+\frac{1}{c_t^2}
\right)\omega\,d\omega .
\end{aligned}
```

ここで

```math
S_2=\frac{1}{c_l^2}+\frac{1}{c_t^2}
```

とおけば，

```math
g_2(\omega)=\frac{A}{2\pi}S_2\omega
\qquad (0<\omega<\omega_D)
```

である．

2次元結晶の全振動モード数は $2N$ なので，

```math
\int_0^{\omega_D}g_2(\omega)d\omega=2N
```

と規格化する．
これより，

```math
\frac{A}{2\pi}S_2
\int_0^{\omega_D}\omega\,d\omega=2N
```

すなわち，

```math
\frac{A}{4\pi}S_2\omega_D^2=2N
```

を得る．
したがって，

```math
\boxed{
\omega_D^2=\frac{8\pi N}{A S_2}
}
```

である．
これを状態密度に代入すれば，

```math
\boxed{
g_2(\omega)=\frac{4N}{\omega_D^2}\omega
\qquad (0<\omega<\omega_D)
}
\tag{2}
```

となる．

#### 3．熱容量の一般式

角振動数 $\omega$ の1つの振動モードを量子調和振動子として扱う．
零点エネルギーを除いた平均熱エネルギーは

```math
\epsilon(\omega,T)
=\frac{\hbar\omega}
{\exp\!\left(\frac{\hbar\omega}{kT}\right)-1}
```

である．
零点エネルギーは温度に依存しないため，熱容量には寄与しない．

したがって，結晶全体の内部エネルギーの温度依存部分は

```math
U(T)=\int_0^{\omega_D}g(\omega)\epsilon(\omega,T)d\omega
```

である．
結晶の大きさと振動数が温度に依存しないので，定積熱容量は

```math
C=\left(\frac{\partial U}{\partial T}\right)
=\int_0^{\omega_D}g(\omega)
\frac{\partial\epsilon(\omega,T)}{\partial T}
d\omega
```

となる．

ここで

```math
x=\frac{\hbar\omega}{kT}
```

とおくと，

```math
\frac{\partial\epsilon}{\partial T}
=kx^2\frac{e^x}{(e^x-1)^2}
```

である．
よって，

```math
\boxed{
C=k\int_0^{\omega_D}
g(\omega)
\left(\frac{\hbar\omega}{kT}\right)^2
\frac{e^{\hbar\omega/(kT)}}
{\left(e^{\hbar\omega/(kT)}-1\right)^2}
d\omega
}
\tag{3}
```

を得る．

以下では Debye 温度を

```math
\boxed{
\Theta_D=\frac{\hbar\omega_D}{k}
}
```

と定義する．

#### 4．1次元結晶の熱容量

式 (1) を式 (3) に代入すると，

```math
C_1
=Nk\int_0^{\omega_D}
\frac{1}{\omega_D}
\left(\frac{\hbar\omega}{kT}\right)^2
\frac{e^{\hbar\omega/(kT)}}
{\left(e^{\hbar\omega/(kT)}-1\right)^2}
d\omega
```

となる．

ここで

```math
\xi=\frac{\hbar\omega}{kT},
\qquad
d\omega=\frac{kT}{\hbar}d\xi
```

と変数変換する．
積分範囲は

```math
0\leq \xi\leq\frac{\Theta_D}{T}
```

であり，

```math
\frac{kT}{\hbar\omega_D}=\frac{T}{\Theta_D}
```

だから，

```math
\boxed{
C_1
=Nk\frac{T}{\Theta_D}
\int_0^{\Theta_D/T}
\frac{\xi^2e^\xi}{(e^\xi-1)^2}d\xi
}
\tag{4}
```

を得る．

#### 5．2次元結晶の熱容量

式 (2) を式 (3) に代入すると，

```math
\begin{aligned}
C_2
=4Nk\int_0^{\omega_D}
&\frac{\omega}{\omega_D^2}
\left(\frac{\hbar\omega}{kT}\right)^2\\
&\times
\frac{e^{\hbar\omega/(kT)}}
{\left(e^{\hbar\omega/(kT)}-1\right)^2}
d\omega
\end{aligned}
```

となる．

ここでも

```math
\xi=\frac{\hbar\omega}{kT}
```

とおくと，

```math
\omega\,d\omega
=\left(\frac{kT}{\hbar}\right)^2\xi\,d\xi
```

である．
したがって，

```math
\boxed{
C_2
=4Nk\left(\frac{T}{\Theta_D}\right)^2
\int_0^{\Theta_D/T}
\frac{\xi^3e^\xi}{(e^\xi-1)^2}d\xi
}
\tag{5}
```

を得る．

#### 6．高温極限

高温 $T\gg\Theta_D$ では，積分範囲全体で

```math
x=\frac{\hbar\omega}{kT}\ll1
```

となる．
このとき，

```math
\frac{x^2e^x}{(e^x-1)^2}\longrightarrow1
\qquad (x\to0)
```

である．

式 (3) にこの極限を適用すれば，

```math
C\simeq k\int_0^{\omega_D}g(\omega)d\omega
```

となる．
全モード数は1次元では $N$ ，2次元では $2N$ だから，

```math
\boxed{
C_1\longrightarrow Nk
}
```

および

```math
\boxed{
C_2\longrightarrow 2Nk
}
```

を得る．
これは各振動自由度が古典極限で熱容量 $k$ を与えることに対応する．

#### 7．低温極限

低温 $T\ll\Theta_D$ では，

```math
\frac{\Theta_D}{T}\gg1
```

となるため，式 (4)，(5) の積分上限を無限大に置き換えられる．

積分を評価するために，

```math
I_m=\int_0^\infty
\frac{\xi^m e^\xi}{(e^\xi-1)^2}d\xi
```

とおく．
$m>1$ について，

```math
\frac{e^\xi}{(e^\xi-1)^2}
=-\frac{d}{d\xi}\frac{1}{e^\xi-1}
```

なので，部分積分により

```math
\begin{aligned}
I_m
&=m\int_0^\infty
\frac{\xi^{m-1}}{e^\xi-1}d\xi\\
&=\Gamma(m+1)\zeta(m)
\end{aligned}
```

となる．
ここで $\Gamma$ はガンマ関数， $\zeta$ は Riemann のゼータ関数である．

##### 7.1．1次元結晶

式 (4) より，

```math
C_1\simeq
Nk\frac{T}{\Theta_D}
\int_0^\infty
\frac{\xi^2e^\xi}{(e^\xi-1)^2}d\xi
```

である．

積分値は

```math
\begin{aligned}
I_2
&=\Gamma(3)\zeta(2)\\
&=2\cdot\frac{\pi^2}{6}\\
&=\frac{\pi^2}{3}
\end{aligned}
```

だから，

```math
\boxed{
C_1\simeq
\frac{\pi^2}{3}Nk\frac{T}{\Theta_D}
}
\tag{6}
```

となる．
したがって，1次元結晶の低温熱容量は温度 $T$ に比例する．

##### 7.2．2次元結晶

式 (5) より，

```math
C_2\simeq
4Nk\left(\frac{T}{\Theta_D}\right)^2
\int_0^\infty
\frac{\xi^3e^\xi}{(e^\xi-1)^2}d\xi
```

である．

積分値は

```math
\begin{aligned}
I_3
&=\Gamma(4)\zeta(3)\\
&=6\zeta(3)
\end{aligned}
```

だから，

```math
\boxed{
C_2\simeq
24\zeta(3)Nk
\left(\frac{T}{\Theta_D}\right)^2
}
\tag{7}
```

となる．
したがって，2次元結晶の低温熱容量は温度の2乗に比例する．

#### 8．結論

結晶の変位自由度を空間次元内に限り，すべての音響分枝を線形分散で近似する Debye 模型では，1次元および2次元の熱容量は次のようになる．

高温極限では，

```math
\boxed{
C_1\longrightarrow Nk,\qquad
C_2\longrightarrow 2Nk
}
```

低温極限では，

```math
\boxed{
C_1\simeq
\frac{\pi^2}{3}Nk\frac{T}{\Theta_D}
\qquad (1\text{次元})
}
```

および

```math
\boxed{
C_2\simeq
24\zeta(3)Nk
\left(\frac{T}{\Theta_D}\right)^2
\qquad (2\text{次元})
}
```

となる．

したがって，線形分散をもつ音響振動モードに対する Debye 模型では，低温熱容量は空間次元 $d$ に応じて

```math
\boxed{C\propto T^d}
```

と振る舞う．
