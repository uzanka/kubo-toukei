# 演習問題【6-A-15】

## 解答

### 1．二相間で粒子数を交換するときの平衡条件

相 I と相 II が粒子 A，B，……を交換できる状態にあり，温度 $T$ が一定である場合を考える．
相 I に存在する粒子 A の数を $N_A'$ ，相 II に存在する数を $N_A''$ とする．
粒子 A の全数 $N_A$ は保存されるため，

```math
N_A'+N_A''=N_A=\text{一定}
\tag{1}
```

である．
粒子 B，……についても同様の関係が成り立つ．

相 I に粒子 A，B，……がそれぞれ $N_A',N_B',\ldots$ 個あるときの正準分配関数を

```math
Z_{\mathrm I}(N_A',N_B',\ldots)
```

とし，相 II の正準分配関数を

```math
Z_{\mathrm{II}}(N_A'',N_B'',\ldots)
```

とする．
二相間の相互作用を無視できるとき，それぞれの粒子数が与えられた状態に対する全系の分配関数は，

```math
Z_{\mathrm I}Z_{\mathrm{II}}
```

である．
したがって，固定された全粒子数のもとで最も確からしい粒子数の分配は，この積を最大にするものとなる．
これは，Helmholtz の自由エネルギーを最小にすることと同値である．

そこで，粒子数の微小変化を考える．
粒子 A の総数は一定なので，

```math
\delta N_A''=-\delta N_A'
```

である．
全分配関数の対数の変化は，

```math
\begin{aligned}
\delta\log(Z_{\mathrm I}Z_{\mathrm{II}})
={}&
\frac{\partial\log Z_{\mathrm I}}{\partial N_A'}
\delta N_A'
+
\frac{\partial\log Z_{\mathrm{II}}}{\partial N_A''}
\delta N_A''
\\
={}&
\left(
\frac{\partial\log Z_{\mathrm I}}{\partial N_A'}
-
\frac{\partial\log Z_{\mathrm{II}}}{\partial N_A''}
\right)\delta N_A'
\end{aligned}
```

となる．
平衡では，任意の微小な粒子移動に対してこの変化がゼロとなるため，

```math
\boxed{
\frac{\partial\log Z_{\mathrm I}}{\partial N_A'}
=
\frac{\partial\log Z_{\mathrm{II}}}{\partial N_A''}
}
\tag{2}
```

を得る．
粒子 B，……についても同様に，

```math
\frac{\partial\log Z_{\mathrm I}}{\partial N_B'}
=
\frac{\partial\log Z_{\mathrm{II}}}{\partial N_B''},
\quad\ldots
\tag{3}
```

が成り立つ．
これらが，二相間の粒子交換に関する平衡条件である．

### 2．正準分配関数と大分配関数の関係

次に，式 (2) を大分配関数で表す．
相 I または相 II のいずれかを相 $r$ と書き，粒子数を固定した正準分配関数を $Z_r(N_A,N_B,\ldots)$ とする．
対応する大分配関数は，

```math
\Xi_r(\lambda_A,\lambda_B,\ldots)
=
\sum_{N_A,N_B,\ldots}
Z_r(N_A,N_B,\ldots)
\lambda_A^{N_A}\lambda_B^{N_B}\cdots
\tag{4}
```

と定義される．
ここで， $\lambda_A,\lambda_B,\ldots$ は各粒子種の絶対活動度であり，化学ポテンシャル $\mu_A,\mu_B,\ldots$ と，

```math
\lambda_A=e^{\mu_A/(kT)},\qquad
\lambda_B=e^{\mu_B/(kT)},\quad\ldots
\tag{5}
```

の関係にある．

粒子数が十分に大きい場合，大分配関数の和では，次の項が最も大きく寄与すると考えられる．

```math
Z_r(N_A,N_B,\ldots)
\lambda_A^{N_A}\lambda_B^{N_B}\cdots
```

その対数は，

```math
\log Z_r
+N_A\log\lambda_A
+N_B\log\lambda_B+\cdots
```

である．
最も確からしい粒子数では，この式が粒子数について極大になるため，

```math
\frac{\partial\log Z_r}{\partial N_A}
+\log\lambda_A=0
```

が成り立つ．
よって，

```math
\boxed{
\frac{\partial\log Z_r}{\partial N_A}
=-\log\lambda_A
}
\tag{6}
```

を得る．
これは，粒子数が十分に大きく，粒子数を連続変数として扱える熱力学的極限での関係である．
粒子 B，……についても同様の式が得られる．

### 3．二相の活動度が等しいことの導出

相 I では式 (6) より，

```math
\frac{\partial\log Z_{\mathrm I}}{\partial N_A'}
=-\log\lambda_A^{\mathrm I}
```

である．
同様に，相 II では，

```math
\frac{\partial\log Z_{\mathrm{II}}}{\partial N_A''}
=-\log\lambda_A^{\mathrm{II}}
```

である．
これらを式 (2) に代入すると，

```math
-\log\lambda_A^{\mathrm I}
=-\log\lambda_A^{\mathrm{II}}
```

となるため，

```math
\boxed{
\lambda_A^{\mathrm I}
=\lambda_A^{\mathrm{II}}
=\lambda_A
}
\tag{7}
```

が得られる．
粒子 B，……についても同様に，

```math
\lambda_B^{\mathrm I}=\lambda_B^{\mathrm{II}}=\lambda_B,
\quad\ldots
\tag{8}
```

が成り立つ．

式 (5) から，活動度が等しいことは化学ポテンシャルが等しいことを意味する．
すなわち，各粒子種について，

```math
\mu_A^{\mathrm I}=\mu_A^{\mathrm{II}},
\qquad
\mu_B^{\mathrm I}=\mu_B^{\mathrm{II}},
\quad\ldots
```

となる．
これが二相間で粒子交換が可能な場合の熱平衡条件である．

### 4．平均粒子数と大分配関数の関係

最後に，粒子数を大分配関数の微分で表す．
式 (4) を $\lambda_A$ で微分すると，

```math
\frac{\partial\Xi_r}{\partial\lambda_A}
=
\sum_{N_A,N_B,\ldots}
N_A Z_r
\lambda_A^{N_A-1}
\lambda_B^{N_B}\cdots
```

となる．
両辺に $\lambda_A$ を掛けると，

```math
\lambda_A\frac{\partial\Xi_r}{\partial\lambda_A}
=
\sum_{N_A,N_B,\ldots}
N_A Z_r
\lambda_A^{N_A}
\lambda_B^{N_B}\cdots
```

である．
大分配関数で割れば，平均粒子数の定義により，

```math
\boxed{
\overline N_A^{\,r}
=
\lambda_A
\frac{\partial\log\Xi_r}{\partial\lambda_A}
}
\tag{9}
```

を得る．

二相が平衡にあるとき，式 (7) より両相で共通の活動度 $\lambda_A$ を用いることができる．
粒子数が十分に大きく，平均粒子数と最も確からしい粒子数が近似的に一致するとすれば，

```math
N_A'
\simeq
\lambda_A\frac{\partial\log\Xi_{\mathrm I}}{\partial\lambda_A},
\qquad
N_A''
\simeq
\lambda_A\frac{\partial\log\Xi_{\mathrm{II}}}{\partial\lambda_A}
\tag{10}
```

である．
したがって，両式の比をとると共通因子 $\lambda_A$ が消え，

```math
\boxed{
N_A':N_A''
=
\frac{\partial\log\Xi_{\mathrm I}}{\partial\lambda_A}
:
\frac{\partial\log\Xi_{\mathrm{II}}}{\partial\lambda_A}
}
\tag{11}
```

を得る．
また，粒子 A の総数は保存されるため，

```math
\boxed{
N_A'+N_A''=N_A
}
\tag{12}
```

である．
粒子 B，……についても同様の関係が成り立つ．
以上により，問題文の条件が示された．
