# 演習問題【6-A-15】

## 解答

二つの相 $\text{I}$ と $\text{II}$ が粒子を交換できる状態で平衡にあるとき，その分配状態がどのように定まるかを，統計力学の原理に基づいて導出する．

### 1．最も確からしい分配の条件

相 $\text{I}$ に粒子 $\text{A}$ が $N_{\text{A}}'$ 個，相 $\text{II}$ に粒子 $\text{A}$ が $N_{\text{A}}''$ 個存在するとする．
粒子 $\text{A}$ の総数は $N_{\text{A}} = N_{\text{A}}' + N_{\text{A}}''$ で一定である．
それぞれの相の分配関数を $Z_{\text{I}}(N_{\text{A}}', \dots)$ ， $Z_{\text{II}}(N_{\text{A}}'', \dots)$ とすると，系全体の分配関数は， $Z_{\text{total}} = Z_{\text{I}} Z_{\text{II}}$ と表される．

統計力学において，平衡状態は系全体の分配関数（またはその対数）を最大にするような状態として与えられる．
ここで，粒子数の微小な変化 $\delta N_{\text{A}}'$ ， $\delta N_{\text{A}}''$ を考えると，総粒子数の保存則より $\delta N_{\text{A}}' + \delta N_{\text{A}}'' = 0$ が成り立つ．
この制約条件下で $\log Z_{\text{total}}$ を最大化する条件を求めると，以下の変分原理が得られる：

$$\delta \log (Z_{\text{I}} Z_{\text{II}}) = \delta (\log Z_{\text{I}} + \log Z_{\text{II}}) = \frac{\partial \log Z_{\text{I}}}{\partial N_{\text{A}}'} \delta N_{\text{A}}' + \frac{\partial \log Z_{\text{II}}}{\partial N_{\text{A}}''} \delta N_{\text{A}}'' = 0$$

$\delta N_{\text{A}}'' = -\delta N_{\text{A}}'$ を代入すると，

$$\left( \frac{\partial \log Z_{\text{I}}}{\partial N_{\text{A}}'} - \frac{\partial \log Z_{\text{II}}}{\partial N_{\text{A}}''} \right) \delta N_{\text{A}}' = 0$$

これが任意の $\delta N_{\text{A}}'$ に対して成り立つためには，次の条件が満たされる必要がある：

$$\frac{\partial \log Z_{\text{I}}}{\partial N_{\text{A}}'} = \frac{\partial \log Z_{\text{II}}}{\partial N_{\text{A}}''} \quad \cdots (1)$$

これが，二つの相が粒子交換に関して平衡にあるための条件である．

### 2．大分配関数との関係

次に，分配関数 $Z$ と大分配関数 $\Xi$ の関係を用いる．
大分配関数 $\Xi$ は，粒子数 $N$ が変化しうる大正準集合において，分配関数 $Z(N)$ と化学ポテンシャルに関連する変数 $\lambda$（活性度または湧出因子）を用いて以下のように定義される：

$$\Xi(\lambda) = \sum_{N} Z(N) \lambda^N$$

この $\Xi(\lambda)$ の $\lambda$ による対数微分を計算すると，

$$\frac{\partial \log \Xi}{\partial \lambda} = \frac{1}{\Xi} \frac{\partial \Xi}{\partial \lambda} = \frac{1}{\Xi} \sum_{N} N Z(N) \lambda^{N-1} = \frac{1}{\lambda \Xi} \sum_{N} N Z(N) \lambda^N = \frac{\langle N \rangle}{\lambda}$$

したがって， $\lambda \frac{\partial \log \Xi}{\partial \lambda} = \langle N \rangle$ が得られる．
熱力学的極限において，最も確からしい粒子数 $N$ は期待値 $\langle N \rangle$ に一致するため， $N \approx \lambda \frac{\partial \log \Xi}{\partial \lambda}$ とみなすことができる．

また，大正準集合における $\log \Xi$ と正準集合における $\log Z$ の関係は，熱力学的極限において次のように近似できる：

$$\log \Xi(\lambda) \approx \log Z(N) + N \log \lambda$$

これを $N$ について微分すると，

$$\frac{\partial \log Z(N)}{\partial N} \approx \frac{\partial \log \Xi(\lambda)}{\partial N} - \log \lambda$$

ここで， $\log \Xi$ は $\lambda$ の関数であり， $N$ は $\lambda$ を通じて $\log \Xi$ に依存していることに注意して，全微分 $\frac{d \log \Xi}{d N} = \frac{\partial \log \Xi}{\partial N} + \frac{\partial \log \Xi}{\partial \lambda} \frac{d\lambda}{dN}$ を考えると， $\frac{\partial \log \Xi}{\partial N} = 0$ であることから $\frac{\partial \log Z}{\partial N} \approx -\log \lambda$ が導かれる．

### 3．結論の導出

条件 (1) にこれを用いると，

$$-\log \lambda_{\text{A}}' = -\log \lambda_{\text{A}}'' \implies \lambda_{\text{A}}' = \lambda_{\text{A}}'' = \lambda_{\text{A}}$$

となり，二つの相における $\lambda_{\text{A}}$ が等しくなることが示された．
これを用いて，粒子数 $N_{\text{A}}', N_{\text{A}}''$ の比を計算すると，

$$N_{\text{A}}' : N_{\text{A}}'' = \langle N_{\text{A}}' \rangle : \langle N_{\text{A}}'' \rangle = \lambda_{\text{A}} \frac{\partial \log \Xi_{\text{I}}}{\partial \lambda_{\text{A}}} : \lambda_{\text{A}} \frac{\partial \log \Xi_{\text{II}}}{\partial \lambda_{\text{A}}} = \frac{\partial \log \Xi_{\text{I}}}{\partial \lambda_{\text{A}}} : \frac{\partial \log \Xi_{\text{II}}}{\partial \lambda_{\text{A}}}$$

よって，問題文の条件が示された．

## 解説

本問題は，統計力学における「平衡状態」の定義を，分配関数を用いて具体的に示すものである．

### 1.  平衡の条件

二つの系が粒子を交換できるとき，それらが平衡にあるとは，「系全体の分配関数が最大になる状態」を指す．
これは，あたかもエネルギーが最小になる状態を探すのと同じ原理である．

### 2.  アンサンブル（集団）の使い分け

- **正準集合（Canonical Ensemble）**：
  粒子数 $N$ が固定されている場合に考える．
- **大正準集合（Grand Canonical Ensemble）**：
  粒子数 $N$ が変動しうる（交換可能である）場合に考える．
  この問題では，粒子が交換可能であるため，大正準集合の性質を用いることが鍵となる．

### 3.  変数 $\lambda$ について

$\lambda$ は，化学ポテンシャル $\mu$ と $\lambda = e^{\beta \mu}$ という関係にある．
「 $\lambda$ が等しい」ということは，「化学ポテンシャル $\mu$ が等しい」ことを意味しており，これが粒子交換における平衡の条件そのものである．

### 4.  導出のポイント

正準集合の $\log Z$ の微分が $-\log \lambda$ になるという関係を用いることで，粒子数の比を大分配関数の微分へと結びつけている．
