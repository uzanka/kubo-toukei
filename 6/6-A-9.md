# 演習問題【6-A-9】

## 解答

磁場 $\boldsymbol{H}$ の方向に磁気モーメント $\boldsymbol{\mu}$ が置かれているとき，そのエネルギー $E$ は，磁気モーメントと磁場の内積を用いて次のように書ける．

$$E = -\boldsymbol{\mu} \cdot \boldsymbol{H}$$

本問題では，磁気モーメントは磁場 $\boldsymbol{H}$ の方向（ $z$ 軸とする）に，値 $g\mu_B m$ （ $m = J, J-1, \dots, -J$ ）をとる．
したがって，エネルギー $E_i$ は次のように表される．

$$E_i = -g\mu_B H m_i$$

ここで， $m_i$ は $i$ 番目の磁気モーメントの磁気量子数である．

単位体積中に $n$ 個の独立な磁気モーメントが存在するとする．
全磁気モーメントを $M = \sum_{i=1}^n g\mu_B m_i$ とすると，系全体のエネルギー $E$ は

$$E = \sum_{i=1}^n E_i = -g\mu_B H \sum_{i=1}^n m_i$$

となる．

統計力学において，温度 $T$ の熱平衡状態における系の分配関数 $Z$ は，すべての可能な状態についてのエネルギーの指数関数の和として定義される．

$$Z = \sum_{\{m_i\}} \exp(-\beta E) = \sum_{m_1=-J}^{J} \dots \sum_{m_n=-J}^{J} \exp\left( \beta g\mu_B H \sum_{i=1}^n m_i \right)$$

ここで $\beta = 1/(kT)$ は逆温度である．
各磁気モーメントは互いに独立であるため，分配関数は個々の磁気モーメントの分配関数の積として計算できる．

$$Z = \left\{ \sum_{m=-J}^{J} \exp(\beta g\mu_B H m) \right\}^n$$

括弧内の和を $z$ と置くと， $z = \sum_{m=-J}^{J} e^{\alpha m}$ （ただし $\alpha = \beta g\mu_B H$ ）となる．
これは等比数列の和の公式を用いて次のように計算できる．

$$z = \frac{e^{\alpha(J+1)} - e^{-\alpha J}}{e^{\alpha} - 1} = \frac{e^{\alpha(J+1/2)} - e^{-\alpha(J+1/2)}}{e^{\alpha/2} - e^{-\alpha/2}} = \frac{\sinh\left(\alpha \frac{2J+1}{2}\right)}{\sinh\left(\frac{\alpha}{2}\right)}$$

よって，全分配関数 $Z$ は

$$Z = \left[ \frac{\sinh\left(\beta g\mu_B H \frac{2J+1}{2}\right)}{\sinh\left(\frac{1}{2} \beta g\mu_B H\right)} \right]^n$$

となる．

平均の磁化 $\overline{M}$ は，磁場 $H$ による自由エネルギーの微分，あるいは分配関数の対数微分として次のように求められる．

$$\overline{M} = \frac{1}{V} \langle \sum_{i=1}^n g\mu_B m_i \rangle = \frac{n}{V} \langle g\mu_B m \rangle \quad (\text{単位体積あたりの平均を求めるため})$$

問題文では $n$ を単位体積あたりの個数としているので，

$$\overline{M} = \frac{1}{\beta} \frac{\partial}{\partial H} \ln Z = kT \frac{\partial}{\partial H} \ln Z$$

である．
これを計算すると，

$$\ln Z = n \left\{ \ln \sinh\left(\beta g\mu_B H \frac{2J+1}{2}\right) - \ln \sinh\left(\frac{1}{2} \beta g\mu_B H\right) \right\}$$

$$\overline{M} = n kT \left[ \frac{\partial}{\partial H} \ln \sinh\left(\frac{2J+1}{2} \beta g\mu_B H\right) - \frac{\partial}{\partial H} \ln \sinh\left(\frac{1}{2} \beta g\mu_B H\right) \right]$$

$$\overline{M} = n kT \left[ \frac{2J+1}{2} \beta g\mu_B \coth\left(\frac{2J+1}{2} \beta g\mu_B H\right) - \frac{1}{2} \beta g\mu_B \coth\left(\frac{1}{2} \beta g\mu_B H\right) \right]$$

$$\overline{M} = n g\mu_B J \left[ \frac{2J+1}{2J} \coth\left(\frac{2J+1}{2J} \cdot \frac{g\mu_B JH}{kT}\right) - \frac{1}{2J} \coth\left(\frac{1}{2J} \cdot \frac{g\mu_B JH}{kT}\right) \right]$$

ここで， $x = \frac{g\mu_B JH}{kT}$ と置くと，ブリュアン関数 $B_J(x)$ を用いて次のように書ける．

$$\overline{M} = n g\mu_B J B_J(x)$$

ただし，

$$B_J(x) = \frac{2J+1}{2J} \coth\left(\frac{2J+1}{2J} x\right) - \frac{1}{2J} \coth\left(\frac{x}{2J}\right)$$

である．

次に，磁場が弱い場合，あるいは温度が高い場合（ $x = \frac{g\mu_B JH}{kT} \ll 1$ ）を考える．
$\coth y \approx \frac{1}{y} + \frac{y}{3}$ （ $y \to 0$ ）という近似を用いると，

$$B_J(x) \approx \frac{2J+1}{2J} \left( \frac{2J}{2J+1} \frac{1}{x} + \frac{2J+1}{6J} x \right) - \frac{1}{2J} \left( \frac{2J}{x} + \frac{x}{6J} \right)$$

$$= \frac{1}{x} + \frac{(2J+1)^2}{6J^2} x - \frac{1}{x} - \frac{1}{6J^2} x = \frac{(2J+1)^2 - 1}{6J^2} x = \frac{4J^2 + 4J}{6J^2} x = \frac{4J(J+1)}{6J^2} x = \frac{J+1}{3J} x$$

したがって，磁化 $\overline{M}$ は

$$\overline{M} \approx n g\mu_B J \left( \frac{J+1}{3J} \cdot \frac{g\mu_B JH}{kT} \right) = n \frac{J(J+1)g^2 \mu_B^2}{3kT} H$$

となる．
磁化率 $\chi$ は $\chi = \frac{\partial \overline{M}}{\partial H}$ であるから，

$$\chi = n \frac{J(J+1)g^2 \mu_B^2}{3kT}$$

が得られる．
これは Curie の法則に従っている．

次に，特定の条件について検討する．
1. $J = 1/2$ のとき：
$x = \frac{g\mu_B (1/2) H}{kT} = \frac{g\mu_B H}{2kT}$ である．
$B_{1/2}(x) = \frac{2}{1} \coth(2x) - 1 \coth(x)$ は誤りで，定義に従うと
$B_{1/2}(x) = \frac{2(1/2)+1}{2(1/2)} \coth\left(\frac{2(1/2)+1}{2(1/2)} x\right) - \frac{1}{2(1/2)} \coth\left(\frac{x}{2(1/2)}\right)$
$= 2 \coth(2x) - \coth(x)$
ここで $\coth(2x) = \frac{1}{2}(\tanh x + \coth x)$ なので，
$B_{1/2}(x) = (\tanh x + \coth x) - \coth x = \tanh x$ となる．
よって，磁化は $\overline{M} = n g\mu_B (1/2) \tanh x = \frac{1}{2} n g\mu_B \tanh\left(\frac{g\mu_B H}{2kT}\right)$ である．
磁化率は $\chi = \frac{\partial \overline{M}}{\partial H} \big|_{H \to 0}$ より，
$$\chi = \frac{1}{2} n g\mu_B \cdot \frac{g\mu_B}{2kT} = \frac{n g^2 \mu_B^2}{4kT}$$
となる．

2. $J \to \infty, \mu_B \to 0, g\mu_B J \to \mu_0$ の極限：
このとき， $x = \frac{g\mu_B JH}{kT} \to \frac{\mu_0 H}{kT}$ である．
また， $B_J(x)$ において $\frac{1}{2J} \to 0$ であることに注意すると，

$$B_J(x) = \frac{2J+1}{2J} \coth\left(\frac{2J+1}{2J} x\right) - \frac{1}{2J} \coth\left(\frac{x}{2J}\right) \to 1 \cdot \coth(x) - 0 = \coth x$$

ではない．
正しくは， $\frac{2J+1}{2J} \to 1$ であり， $\frac{1}{2J} \coth\left(\frac{x}{2J}\right) = \frac{1}{2J} \left( \frac{2J}{x} + \frac{x}{6J} + \dots \right) = \frac{1}{x} + \dots \to \frac{1}{x}$ である．
したがって， $B_\infty(x) = \coth x - \frac{1}{x} = L(x)$ （Langevin 関数）となる．
この極限での磁化は，

$$\overline{M} = n \mu_0 L\left(\frac{\mu_0 H}{kT}\right)$$

であり，磁化率は

$$\chi = \frac{\partial \overline{M}}{\partial H} \bigg|_{H \to 0} = n \mu_0 L'(0)$$

ここで $L(x) = \coth x - 1/x$ の微分は $L'(x) = -\text{csch}^2 x + 1/x^2$ である．
$x \to 0$ のとき， $\text{csch}^2 x = \frac{1}{\sinh^2 x} \approx \frac{1}{(x + x^3/6)^2} \approx \frac{1}{x^2(1 + x^2/3)} \approx \frac{1}{x^2}(1 - x^2/3) = \frac{1}{x^2} - \frac{1}{3}$ なので，
$L'(x) \approx -(\frac{1}{x^2} - \frac{1}{3}) + \frac{1}{x^2} = \frac{1}{3}$ となる．
よって，磁化率は

$$\chi = n \mu_0 \cdot \frac{1}{3} \cdot \frac{\mu_0}{kT} \text{ (微分に } H \text{ の係数がかかるので注意) }$$

正しくは， $\overline{M} = n \mu_0 L(ax)$ ( $a = \mu_0/kT$ ) の微分は $n \mu_0 L'(ax) \cdot a$ である．
したがって，

$$\chi = n \mu_0 \cdot \frac{1}{3} \cdot \frac{\mu_0}{kT} = \frac{n \mu_0^2}{3kT}$$

が得られる．

## 解説

本問題は，古典的な磁性体の性質を量子力学的な磁気モーメントのモデル（量子磁性）から導出するものである．

### 1. エネルギーと磁気量子数

磁場中での磁気モーメントのエネルギーは，磁気量子数 $m$ に依存する．
$m$ が $J, J-1, \dots, -J$ という飛び飛びの値をとることは，量子化されていることを意味する．

### 2. 分配関数と磁化

統計力学の基本原理に基づき，分配関数 $Z$ を求めることで，系の平均的な物理量（ここでは磁化 $\overline{M}$ ）を導出できる．
独立な粒子の場合，全体の分配関数は個々の粒子の分配関数の積になる．

### 3. ブリュアン関数

磁気モーメントの量子数 $J$ に依存する磁化の振る舞いを記述するのがブリュアン関数である．
$J$ が大きいほど，磁化の立ち上がりは古典的な Langevin 関数の形に近づく．

### 4. Curie の法則

高温または弱磁場の極限では，磁化率 $\chi$ が温度 $T$ に反比例する（ $\chi \propto 1/T$ ）ことが示される．
これは多くの常磁性体で見られる典型的な性質である．

### 5. 極限の物理的意味

- $J = 1/2$ は電子スピンのみを考慮する最も単純な量子モデル（パウリ常磁性など）に対応する．
- $J \to \infty$ の極限は，磁気モーメントの方向が連続的に変化できる古典的な近似に対応し，Langevin 関数へと帰着する．
