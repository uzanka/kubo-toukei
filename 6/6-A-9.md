# 演習問題【6-A-9】

## 解答

### 1．磁気モーメントのエネルギーと分配関数

磁場 $H$ の方向を $z$ 軸とする．
磁気モーメント1個の磁場方向成分は，

```math
\mu_z=g\mu_B m
```

であり，磁気量子数 $m$ は，

```math
m=J,J-1,\ldots,-J+1,-J
```

の $2J+1$ 個の値をとる．
ここで， $g$ は $g$ 因子， $\mu_B$ はボーア磁子， $J$ は全角運動量に対応する量子数である．

磁場中で磁気モーメントがもつエネルギーは，問題文の規約に従って，

```math
E_m=-\mu_z H=-g\mu_B mH
\tag{1}
```

と表される．

単位体積中に $n$ 個の独立な磁気モーメントが存在するとする．
磁気モーメント間の相互作用を無視できるため，全系のエネルギーは各モーメントのエネルギーの和である．

体積 $V$ 中のモーメント数を $N=nV$ とすると，系全体の分配関数 $Z$ は，

```math
Z=\sum_{m_1=-J}^{J}\cdots
\sum_{m_N=-J}^{J}
\exp\left(
\beta g\mu_B H\sum_{i=1}^{N}m_i
\right)
```

となる．
ここで，

```math
\beta=\frac{1}{kT}
```

であり， $k$ はボルツマン定数， $T$ は絶対温度である．

各磁気モーメントが独立であるため，和を各モーメントについて分離できる．
したがって，

```math
Z=\left(
\sum_{m=-J}^{J}e^{\beta g\mu_B Hm}
\right)^N
=z^N
\tag{2}
```

となる．
ここで $z$ は磁気モーメント1個の分配関数であり，

```math
z=\sum_{m=-J}^{J}e^{\alpha m},
\qquad
\alpha=\beta g\mu_B H
```

とおいた．

この和は等比数列の和であるから，

```math
\begin{aligned}
z
&=e^{-\alpha J}
\frac{e^{\alpha(2J+1)}-1}{e^\alpha-1}\\
&=\frac{e^{\alpha(J+1/2)}-e^{-\alpha(J+1/2)}}
{e^{\alpha/2}-e^{-\alpha/2}}\\
&=\frac{\sinh\left((2J+1)\alpha/2\right)}
{\sinh(\alpha/2)}
\end{aligned}
```

となる．
よって，

```math
\boxed{
Z=\left[
\frac{
\sinh\left(\dfrac{2J+1}{2}\beta g\mu_BH\right)
}{
\sinh\left(\dfrac12\beta g\mu_BH\right)
}
\right]^N
}
\tag{3}
```

が得られる．

### 2．磁化とブリュアン関数

磁化 $M$ は単位体積当たりの磁気モーメントの平均値である．
体積 $V$ 中の全磁気モーメントを $\mathcal M$ とすると，

```math
\mathcal M=g\mu_B\sum_{i=1}^{N}m_i,
\qquad
M=\frac{\overline{\mathcal M}}{V}
```

である．

分配関数の定義から，

```math
\frac{\partial\log Z}{\partial H}
=\beta\overline{\mathcal M}
```

が成り立つ．
したがって，

```math
M=\frac{kT}{V}\frac{\partial\log Z}{\partial H}
```

である．
式 (2) と $N/V=n$ を用いれば，

```math
M=nkT\frac{\partial\log z}{\partial H}
\tag{4}
```

となる．

式 (3) の対数をとると，

```math
\begin{aligned}
\log z
={}&\log\sinh\left(\frac{2J+1}{2}\beta g\mu_BH\right)\\
&-\log\sinh\left(\frac12\beta g\mu_BH\right)
\end{aligned}
```

である．
ここで，

```math
\frac{d}{dx}\log\sinh x=\coth x
```

を用いて式 (4) を計算すると，

```math
\begin{aligned}
M
={}&\frac{ng\mu_B}{2}
\biggl[
(2J+1)
\coth\left(\frac{2J+1}{2}\beta g\mu_BH\right)\\
&\hspace{35mm}
-\coth\left(\frac12\beta g\mu_BH\right)
\biggr]
\end{aligned}
\tag{5}
```

を得る．

ここで，

```math
x=\frac{g\mu_B JH}{kT}
\tag{6}
```

とおく．
さらに，ブリュアン関数 $B_J(x)$ を，

```math
\boxed{
B_J(x)=
\frac{2J+1}{2J}
\coth\left(\frac{2J+1}{2J}x\right)
-\frac{1}{2J}\coth\left(\frac{x}{2J}\right)
}
\tag{7}
```

と定義する．
式 (5) は，

```math
\boxed{
M=ng\mu_B J
B_J\left(\frac{g\mu_B JH}{kT}\right)
}
\tag{8}
```

と書ける．
これが求める磁化の一般式である．

### 3．弱磁場・高温極限と磁化率

次に，

```math
g\mu_B JH\ll kT
```

すなわち $x\ll1$ の場合を考える．
このとき，双曲線余接関数は，

```math
\coth y=\frac1y+\frac{y}{3}+O(y^3)
\qquad (y\to0)
```

と展開できる．

式 (7) にこの展開を代入すると，

```math
\begin{aligned}
B_J(x)
&=\frac{2J+1}{2J}
\left[
\frac{2J}{(2J+1)x}
+\frac{2J+1}{6J}x+O(x^3)
\right]\\
&\quad-\frac{1}{2J}
\left[
\frac{2J}{x}+\frac{x}{6J}+O(x^3)
\right]
\end{aligned}
```

となる．
整理すると， $1/x$ の項は相殺され，

```math
\begin{aligned}
B_J(x)
&=\left[
\frac{(2J+1)^2-1}{12J^2}
\right]x+O(x^3)\\
&=\frac{J+1}{3J}x+O(x^3)
\end{aligned}
```

を得る．
したがって，

```math
B_J(x)\simeq\frac{J+1}{3J}x
\tag{9}
```

である．

これを式 (8) に代入すると，

```math
\begin{aligned}
M
&\simeq ng\mu_BJ
\frac{J+1}{3J}
\frac{g\mu_BJH}{kT}\\
&=\frac{nJ(J+1)g^2\mu_B^2}{3kT}H
\end{aligned}
```

となる．
弱磁場では $M\simeq\chi H$ であるから，磁化率 $\chi$ は，

```math
\boxed{
\chi=\frac{nJ(J+1)g^2\mu_B^2}{3kT}
}
\tag{10}
```

である．
これをキュリーの法則という．
磁化率が絶対温度 $T$ に反比例することが分かる．

### 4．$J=1/2$ の場合

$J=1/2$ の場合，式 (7) は，

```math
B_{1/2}(x)=2\coth(2x)-\coth x
```

となる．
双曲線関数の恒等式

```math
\coth(2x)=\frac12(\coth x+\tanh x)
```

を用いると，

```math
\begin{aligned}
B_{1/2}(x)
&=2\cdot\frac12(\coth x+\tanh x)-\coth x\\
&=\tanh x
\end{aligned}
```

を得る．
したがって，

```math
B_{1/2}(x)=\tanh x
\tag{11}
```

である．
式 (8) より，磁化は，

```math
\boxed{
M=\frac{ng\mu_B}{2}
\tanh\left(\frac{g\mu_BH}{2kT}\right)
}
\tag{12}
```

となる．

弱磁場では $\tanh x\simeq x$ であるため，

```math
M\simeq
\frac{ng\mu_B}{2}\frac{g\mu_BH}{2kT}
=\frac{ng^2\mu_B^2}{4kT}H
```

を得る．
よって，磁化率は，

```math
\boxed{
\chi=\frac{ng^2\mu_B^2}{4kT}
}
\tag{13}
```

である．
これは式 (10) に $J=1/2$ を代入した結果とも一致する．

### 5．古典極限 $J\to\infty$ ， $\mu_B\to0$ ， $g\mu_BJ\to\mu_0$

最後に，

```math
J\to\infty,\qquad
\mu_B\to0,\qquad
g\mu_BJ\to\mu_0
```

という極限を考える．
ここで， $\mu_0$ はこの極限における1個の磁気モーメントの大きさを表す．
また，式 (6) の変数は，

```math
x=\frac{g\mu_BJH}{kT}
\longrightarrow\frac{\mu_0H}{kT}
```

となる．

ブリュアン関数の第1項では，

```math
\frac{2J+1}{2J}\longrightarrow1
```

であるから，

```math
\frac{2J+1}{2J}
\coth\left(\frac{2J+1}{2J}x\right)
\longrightarrow\coth x
```

となる．
一方，第2項は，

```math
\frac{1}{2J}\coth\left(\frac{x}{2J}\right)
```

である．
$J\to\infty$ では $x/(2J)\to0$ となるため， $\coth y\simeq1/y$ を用いると，

```math
\begin{aligned}
\frac{1}{2J}\coth\left(\frac{x}{2J}\right)
&\simeq\frac{1}{2J}\frac{2J}{x}\\
&=\frac1x
\end{aligned}
```

となる．
したがって，

```math
\boxed{
B_J(x)\longrightarrow\coth x-\frac1x
}
\tag{14}
```

である．
この関数をランジュバン関数 $L(x)$ とよび，

```math
L(x)=\coth x-\frac1x
```

と定義する．
よって，式 (8) の古典極限では，

```math
\boxed{
M=n\mu_0L\left(\frac{\mu_0H}{kT}\right)
}
\tag{15}
```

を得る．

さらに，弱磁場では，

```math
L(x)=\frac{x}{3}+O(x^3)
\qquad (x\to0)
```

であるから，

```math
M\simeq n\mu_0\frac{\mu_0H}{3kT}
```

となる．
したがって，この極限における磁化率は，

```math
\boxed{
\chi=\frac{n\mu_0^2}{3kT}
}
\tag{16}
```

である．
以上により，一般の量子数 $J$ の場合， $J=1/2$ の場合，および古典極限における磁化と磁化率がすべて求められた．
