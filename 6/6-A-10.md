# 演習問題【6-A-10】

## 解答

本問題では，吸着サイトの数 $N_0$ に対して $N$ 個の気体分子が吸着している系の化学ポテンシャル $\mu$ を求める．
各吸着サイトは独立であり，吸着分子間の相互作用は無視できるものとする．

### 1．大分配関数の導出

まず，単一の吸着サイトにおける状態を考える．
各サイトは以下のいずれかの状態をとる：
- 吸着分子をもたない状態（状態 $0$ ）：
  このときのエネルギーは $0$ である．
- 吸着分子が $1$ 個ある状態（状態 $i$ ， $i=1, 2, \dots$ ）：
  このときのエネルギーは $\varepsilon_i$ である．

絶対活動度を $\lambda = \exp(\mu / kT)$ とすると，単一の吸着サイトにおける大分配関数 $\xi$ は，次のように書ける：

$$\xi = \sum_{\text{states } s} \lambda^{n_s} e^{-\beta \varepsilon_s}$$

ここで， $n_s$ は状態 $s$ における分子数， $\beta = 1/(kT)$ である．
吸着サイトは独立であるため，全 $N_0$ 個の吸着サイトからなる系の全大分配関数 $\Xi$ は，単一サイトの大分配関数の積となる：

$$\Xi = \xi^{N_0}$$

単一サイトにおいて，分子が $0$ 個の状態の寄与は $\lambda^0 e^{-\beta \cdot 0} = 1$ である．
分子が $1$ 個の状態（状態 $i$ ）の寄与の総和は，

$$\sum_{i=1}^{\infty} \lambda^1 e^{-\beta \varepsilon_i} = \lambda \sum_{i=1}^{\infty} e^{-\varepsilon_i / (kT)}$$

ここで， $a(T) = \sum_{i=1}^{\infty} e^{-\varepsilon_i / (kT)}$ と定義すると，単一サイトの大分配関数は $\xi = 1 + \lambda a(T)$ となる．
したがって，系全体の全大分配関数 $\Xi$ は次のように与えられる：

$$\Xi = (1 + \lambda a(T))^{N_0} \quad \cdots (1)$$

### 2．平均吸着分子数 $N$ と $\lambda$ の関係

系における平均の吸着分子数 $N$ は，大分配関数を用いて次のように求められる：

$$N = \lambda \frac{\partial \log \Xi}{\partial \lambda}$$

式 $(1)$ を用いて計算を進めると，

$$\log \Xi = N_0 \log(1 + \lambda a(T))$$

となるので，

$$\frac{\partial \log \Xi}{\partial \lambda} = N_0 \frac{a(T)}{1 + \lambda a(T)}$$

である．
したがって，

$$N = \lambda \cdot N_0 \frac{a(T)}{1 + \lambda a(T)} = N_0 \frac{\lambda a(T)}{1 + \lambda a(T)}$$

この式を $\lambda a(T)$ について解くと，

$$N(1 + \lambda a(T)) = N_0 \lambda a(T)$$

$$N + N \lambda a(T) = N_0 \lambda a(T)$$

$$N = (N_0 - N) \lambda a(T)$$

より，

$$\lambda a(T) = \frac{N}{N_0 - N} \quad \cdots (2)$$

が得られる．

### 3．化学ポテンシャル $\mu$ の導出

絶対活動度 $\lambda$ と化学ポテンシャル $\mu$ の関係は $\lambda = e^{\mu / kT}$ であるから，

$$\ln \lambda = \frac{\mu}{kT} \implies \mu = kT \ln \lambda$$

である．
式 $(2)$ より，

$$\lambda = \frac{N}{(N_0 - N) a(T)}$$

である．
この両辺の自然対数をとると，

$$\ln \lambda = \ln \left( \frac{N}{N_0 - N} \cdot \frac{1}{a(T)} \right) = \ln \frac{N}{N_0 - N} - \ln a(T)$$

となる．
これを $\mu = kT \ln \lambda$ に代入することで，求める式が得られる：

$$\mu = kT \left\{ \log \frac{N}{N_0 - N} - \log a(T) \right\}$$

（ここで $\log$ は自然対数 $\ln$ を表す．）

## 解説

本問題は，統計力学における「大正準集団（グランドカノニカルアンサンブル）」を用いた典型的な問題である．

### 1.  独立なサイトの扱い

吸着サイトが互いに影響を及ぼさない（相互作用を無視できる）場合，全系の性質は単一サイトの性質の組み合わせとして非常に簡潔に記述できる．
これが大分配関数 $\Xi = \xi^{N_0}$ の形に現れている．

### 2.  絶対活動度 $\lambda$

$\lambda$ は系の粒子数 $N$ の揺らぎを制御するパラメータであり，化学ポテンシャル $\mu$ と直接結びついている．
化学ポテンシャルは「粒子を $1$ 個追加したときに系の自由エネルギーがどれだけ変化するか」を表す物理量である．

### 3.  結果の物理的意味

得られた式 $\mu = kT \log \frac{N}{N_0 - N} - kT \log a(T)$ は，吸着サイトが埋まっていく（ $N$ が増える）ほど，あるいは空いているサイトが減る（ $N_0 - N$ が減る）ほど，化学ポテンシャル $\mu$ が大きくなることを示している．
これは，粒子をさらに追加するのが難しくなることを直感的に表している．
