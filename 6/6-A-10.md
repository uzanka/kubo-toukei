# 演習問題【6-A-10】

## 解答

### 1．単一吸着サイトの大分配関数

表面に $N_0$ 個の吸着中心があり，気体分子がそのうち $N$ 個に吸着している系を考える．
吸着分子間の相互作用は無視し，各吸着サイトには分子が最大1個まで吸着できるものとする．

まず，1個の吸着サイトについて考える．
サイトは，次のいずれかの状態をとる．

- 空の状態：吸着分子が存在せず，エネルギーを基準値 $0$ とする状態である．
- 吸着状態：エネルギー $\varepsilon_i$ をもつ分子が1個吸着している状態である．ここで $i$ は吸着分子の状態を区別する番号である．

温度 $T$ において，逆温度を

```math
\beta=\frac{1}{kT}
```

と定義する．
また，化学ポテンシャルを $\mu$ とし，絶対活動度を

```math
\lambda=e^{\beta\mu}=e^{\mu/(kT)}
```

と定義する．
ここで $k$ はボルツマン定数である．

大分配関数では，分子が $n$ 個ある状態のボルツマン因子に $\lambda^n$ を掛けて，各状態の寄与を合計する．
したがって，空のサイトの寄与は $1$ であり，分子が1個吸着している状態の寄与の総和は，

```math
\lambda\sum_i e^{-\beta\varepsilon_i}
```

となる．
吸着状態にある分子1個の分配関数を

```math
a(T)=\sum_i e^{-\varepsilon_i/(kT)}
```

と定義すると，単一サイトの大分配関数 $\xi$ は，

```math
\boxed{
\xi=1+\lambda a(T)
}
\tag{1}
```

である．

### 2．系全体の大分配関数

吸着サイトは互いに独立であるため，全体の大分配関数は各サイトの大分配関数の積となる．
すべてのサイトが同じ性質をもつので，

```math
\Xi=\xi^{N_0}
```

である．
式 (1) を代入すると，

```math
\boxed{
\Xi=(1+\lambda a(T))^{N_0}
}
\tag{2}
```

を得る．
これが系全体の大分配関数である．

### 3．平均吸着分子数と絶対活動度の関係

大分配関数 $\Xi$ を用いると，平均吸着分子数 $N$ は，

```math
N=\lambda\frac{\partial\log\Xi}{\partial\lambda}
\tag{3}
```

と表される．
この関係は，大分配関数を粒子数ごとの寄与に分けたとき， $\lambda$ で対数微分することで，各粒子数を重みとする平均が得られることによる．

式 (2) の対数をとると，

```math
\log\Xi=N_0\log(1+\lambda a(T))
```

である．
温度 $T$ を固定すると $a(T)$ は $\lambda$ に依存しないため，

```math
\frac{\partial\log\Xi}{\partial\lambda}
=\frac{N_0a(T)}{1+\lambda a(T)}
```

となる．
これを式 (3) に代入すると，

```math
N=N_0\frac{\lambda a(T)}{1+\lambda a(T)}
\tag{4}
```

を得る．

式 (4) の両辺に $1+\lambda a(T)$ を掛けると，

```math
N+N\lambda a(T)=N_0\lambda a(T)
```

である．
これを整理すれば，

```math
N=(N_0-N)\lambda a(T)
```

となるので，

```math
\boxed{
\lambda a(T)=\frac{N}{N_0-N}
}
\tag{5}
```

が得られる．

### 4．化学ポテンシャルの導出

絶対活動度の定義

```math
\lambda=e^{\mu/(kT)}
```

より，両辺の自然対数をとると，

```math
\log\lambda=\frac{\mu}{kT}
```

となる．
したがって，

```math
\mu=kT\log\lambda
\tag{6}
```

である．

式 (5) より，

```math
\lambda=\frac{N}{(N_0-N)a(T)}
```

であるから，両辺の自然対数をとると，

```math
\begin{aligned}
\log\lambda
&=\log\left(\frac{N}{(N_0-N)a(T)}\right)\\
&=\log\frac{N}{N_0-N}-\log a(T)
\end{aligned}
```

となる．
これを式 (6) に代入すれば，

```math
\boxed{
\mu=kT\left\{
\log\frac{N}{N_0-N}-\log a(T)
\right\}
}
```

が得られる．
これが求める式である．
ここで $\log$ は自然対数を表す．
