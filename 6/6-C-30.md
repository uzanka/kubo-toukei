# 演習問題【6-C-30】

## 解答

### 1次元調和振動子の密度行列

#### 1．固有関数による密度行列の表示

1次元調和振動子のハミルトニアンは，

```math
\mathcal H=\frac{p^2}{2m}+\frac12m\omega^2q^2
```

である．
問題で与えられた密度演算子は

```math
\rho=e^{-\beta\mathcal H},
\qquad
\beta=\frac{1}{kT}
```

である．
ここでは，規格化因子 $Z^{-1}$ を含まない密度演算子を扱う．

エネルギー固有値と固有関数は，

```math
E_n=\left(n+\frac12\right)\hbar\omega,
\qquad n=0,1,2,\ldots
```

および

```math
\psi_n(q)=
\left(\frac{m\omega}{\pi\hbar}\right)^{1/4}
\frac{H_n(\xi)}{\sqrt{2^n n!}}e^{-\xi^2/2},
\qquad
\xi=\sqrt{\frac{m\omega}{\hbar}}q
```

で与えられる．
したがって，位置表示での密度行列の行列要素は，

```math
\begin{aligned}
\rho(q,q')
&=\langle q|e^{-\beta\mathcal H}|q'\rangle\\
&=\sum_{n=0}^{\infty}
e^{-\beta E_n}\psi_n(q)\psi_n(q')
\end{aligned}
\tag{1}
```

と書ける．
ここで，

```math
x=\beta\hbar\omega,
\qquad
\xi=\sqrt{\frac{m\omega}{\hbar}}q,
\qquad
\xi'=\sqrt{\frac{m\omega}{\hbar}}q'
```

と定義する．
固有関数を式(1)に代入すると，

```math
\begin{aligned}
\rho(q,q')
={}&\sqrt{\frac{m\omega}{\pi\hbar}}
e^{-(\xi^2+\xi'^2)/2}e^{-x/2}\\
&\times
\sum_{n=0}^{\infty}
\frac{e^{-xn}}{2^n n!}H_n(\xi)H_n(\xi')
\end{aligned}
\tag{2}
```

となる．
よって，以下では Hermite 多項式の級数

```math
S(\xi,\xi';x)
=\sum_{n=0}^{\infty}
\frac{e^{-xn}}{2^n n!}H_n(\xi)H_n(\xi')
\tag{3}
```

を求めればよい．

#### 2．Hermite 多項式の積分表示を用いる

問題文で与えられた積分表示は，

```math
H_n(\xi)=
\frac{e^{\xi^2}}{\sqrt\pi}
\int_{-\infty}^{\infty}
(-2iu)^n e^{-u^2+2i\xi u}\,du
\tag{4}
```

である．
これを式(3)の2つの Hermite 多項式に適用し，もう一方の積分変数を $v$ とすると，

```math
\begin{aligned}
S={}&\frac{e^{\xi^2+\xi'^2}}{\pi}
\int_{-\infty}^{\infty}\!\!du
\int_{-\infty}^{\infty}\!\!dv\,
e^{-u^2-v^2+2i\xi u+2i\xi'v}\\
&\times
\sum_{n=0}^{\infty}
\frac{e^{-xn}}{2^n n!}
(-2iu)^n(-2iv)^n
\end{aligned}
\tag{5}
```

を得る．
ここで，

```math
(-2iu)^n(-2iv)^n=(-4uv)^n
```

であるから，

```math
\frac{e^{-xn}}{2^n n!}(-4uv)^n
=\frac{(-2e^{-x}uv)^n}{n!}
```

となる．
指数関数の Taylor 展開

```math
e^z=\sum_{n=0}^{\infty}\frac{z^n}{n!}
```

を使えば，無限級数は

```math
\sum_{n=0}^{\infty}
\frac{(-2e^{-x}uv)^n}{n!}
=e^{-2e^{-x}uv}
```

となる．
したがって，式(5)は

```math
\begin{aligned}
S={}&\frac{e^{\xi^2+\xi'^2}}{\pi}
\int_{-\infty}^{\infty}\!\!du
\int_{-\infty}^{\infty}\!\!dv\\
&\times
\exp\left[
-u^2-v^2-2e^{-x}uv+2i\xi u+2i\xi'v
\right]
\end{aligned}
\tag{6}
```

と書ける．
これで無限級数が消え，2変数の Gaussian 積分に帰着した．

#### 3．Gaussian 積分の計算

```math
a=e^{-x}
```

とおくと，式(6)の二次形式は

```math
u^2+v^2+2auv
=
\begin{pmatrix}u&v\end{pmatrix}
A
\begin{pmatrix}u\\v\end{pmatrix}
```

と表される．
ここで，

```math
A=\begin{pmatrix}1&a\\a&1\end{pmatrix},
\qquad
\det A=1-a^2
```

であり，その逆行列は

```math
A^{-1}=\frac{1}{1-a^2}
\begin{pmatrix}1&-a\\-a&1\end{pmatrix}
\tag{7}
```

である．
$x>0$ では $0<a<1$ であり，この行列は正定値である．

2変数の Gaussian 積分の公式

```math
\int_{\mathbb R^2}
e^{-\boldsymbol z^{\mathsf T}A\boldsymbol z
+2\boldsymbol b^{\mathsf T}\boldsymbol z}
\,d^2z
=
\frac{\pi}{\sqrt{\det A}}
e^{\boldsymbol b^{\mathsf T}A^{-1}\boldsymbol b}
\tag{8}
```

を用いる．
ここで，

```math
\boldsymbol z=
\begin{pmatrix}u\\v\end{pmatrix},
\qquad
\boldsymbol b=
\begin{pmatrix}i\xi\\i\xi'\end{pmatrix}
```

である．
式(7)から，

```math
\boldsymbol b^{\mathsf T}A^{-1}\boldsymbol b
=-\frac{\xi^2+\xi'^2-2a\xi\xi'}{1-a^2}
```

となる．
これを式(6)に代入すると，

```math
S=
\frac{1}{\sqrt{1-a^2}}
\exp\left[
\frac{-a^2(\xi^2+\xi'^2)+2a\xi\xi'}{1-a^2}
\right]
```

を得る．
$a=e^{-x}$ を戻せば，

```math
\boxed{
S=
\frac{1}{\sqrt{1-e^{-2x}}}
\exp\left[
\frac{2e^{-x}\xi\xi'
-e^{-2x}(\xi^2+\xi'^2)}
{1-e^{-2x}}
\right]
}
\tag{9}
```

である．

#### 4．密度行列の厳密解

式(9)を式(2)に代入すると，

```math
\begin{aligned}
\rho(q,q')
={}&\sqrt{\frac{m\omega}{\pi\hbar}}
\frac{e^{-x/2}}{\sqrt{1-e^{-2x}}}\\
&\times
\exp\left[
-\frac{\xi^2+\xi'^2}{2}
+\frac{2e^{-x}\xi\xi'-e^{-2x}(\xi^2+\xi'^2)}
{1-e^{-2x}}
\right]
\end{aligned}
\tag{10}
```

となる．
前置因子について，

```math
\frac{e^{-x/2}}{\sqrt{1-e^{-2x}}}
=\frac{1}{\sqrt{e^x-e^{-x}}}
=\frac{1}{\sqrt{2\sinh x}}
```

である．
また，指数部は

```math
-\frac12(\xi^2+\xi'^2)
+\frac{2e^{-x}\xi\xi'-e^{-2x}(\xi^2+\xi'^2)}
{1-e^{-2x}}
=
-\frac{(\xi^2+\xi'^2)\cosh x-2\xi\xi'}{2\sinh x}
```

と整理できる．
したがって，

```math
\rho(q,q')
=
\sqrt{\frac{m\omega}{2\pi\hbar\sinh x}}
\exp\left[
-\frac{(\xi^2+\xi'^2)\cosh x-2\xi\xi'}{2\sinh x}
\right]
```

を得る．
最後に，

```math
x=\beta\hbar\omega,
\qquad
\xi=\sqrt{\frac{m\omega}{\hbar}}q,
\qquad
\xi'=\sqrt{\frac{m\omega}{\hbar}}q'
```

を代入すると，求める密度行列の行列要素は

```math
\boxed{
\begin{aligned}
\rho(q,q')={}&
\sqrt{\frac{m\omega}{2\pi\hbar\sinh(\beta\hbar\omega)}}\\
&\times
\exp\left[
-\frac{m\omega}{2\hbar\sinh(\beta\hbar\omega)}
\left\{
(q^2+q'^2)\cosh(\beta\hbar\omega)-2qq'
\right\}
\right]
\end{aligned}
}
\tag{11}
```

である．

#### 5．高温極限 $\beta\hbar\omega\ll1$

高温では，

```math
x=\beta\hbar\omega\ll1
```

である．
式(11)を高温で扱いやすい形に書き換えるため，双曲線関数の恒等式を用いると，

```math
\boxed{
\begin{aligned}
\rho(q,q')={}&
\sqrt{\frac{m\omega}{2\pi\hbar\sinh x}}\\
&\times
\exp\left[
-\frac{m\omega}{4\hbar}
\left\{
(q+q')^2\tanh\frac{x}{2}
+(q-q')^2\coth\frac{x}{2}
\right\}
\right]
\end{aligned}
}
\tag{12}
```

となる．
ここで $x\ll1$ に対し，

```math
\sinh x\simeq x,
\qquad
\tanh\frac{x}{2}\simeq\frac{x}{2},
\qquad
\coth\frac{x}{2}\simeq\frac{2}{x}
```

を用いる．
すると，前置因子は

```math
\sqrt{\frac{m\omega}{2\pi\hbar\sinh x}}
\simeq
\sqrt{\frac{m}{2\pi\beta\hbar^2}}
```

となり，密度行列は

```math
\boxed{
\begin{aligned}
\rho(q,q')\simeq{}&
\sqrt{\frac{m}{2\pi\beta\hbar^2}}\\
&\times
\exp\left[
-\frac{m(q-q')^2}{2\beta\hbar^2}
-\frac{\beta m\omega^2}{8}(q+q')^2
\right]
\end{aligned}
}
\tag{13}
```

となる．
これは高温における密度行列の主要な漸近形である．

この式の第1の指数項は， $q-q'$ のまわりに鋭く集中する Gaussian である．
実際，

```math
\lim_{\beta\to0^+}
\sqrt{\frac{m}{2\pi\beta\hbar^2}}
\exp\left[
-\frac{m(q-q')^2}{2\beta\hbar^2}
\right]
=\delta(q-q')
\tag{14}
```

というデルタ関数の表現が成り立つ．
Gaussian の幅は $\sqrt{\beta}$ に比例してゼロに近づき，その面積は1に保たれるためである．

この Gaussian がデルタ関数に近づくと，残りの緩やかに変化する因子は 4q'=q$ 上で評価される．
したがって，

```math
\exp\left[
-\frac{\beta m\omega^2}{8}(q+q')^2
\right]\delta(q-q')
=
e^{-\beta m\omega^2q^2/2}\delta(q-q')
```

であり，高温極限の密度行列は

```math
\boxed{
\rho(q,q')
\simeq
e^{-\beta m\omega^2q^2/2}\delta(q-q')
}
\tag{15}
```

となる．
これは，古典的な Boltzmann 因子

```math
e^{-\beta V(q)},
\qquad
V(q)=\frac12m\omega^2q^2
```

が位置表示で対角成分に現れ，異なる位置 $q\neq q'$ の間の行列要素がデルタ関数によって抑えられることを示している．

なお，式(13)の精度について補足する．
式(11)の指数部を $x$ について固定した $q,q'$ で展開すると，

```math
\frac{(q^2+q'^2)\cosh x-2qq'}{\sinh x}
=
\frac{(q-q')^2}{x}
+\frac{x}{3}(q^2+qq'+q'^2)+O(x^3)
```

も得られる．
これは指数部のより細かな展開であるが，式(13)とは $O\!\left(\beta(q-q')^2\right)$ の項が異なる．
式(13)は，Gaussian が集中する幅 $(q-q')^2=O(\beta)$ の領域で有効な高温近似であり，式(15)のデルタ関数極限を得る目的に適している．
両方の近似は $q=q'$ 上では同じポテンシャル因子を与える．

以上より，密度行列の厳密な行列要素は式(11)であり，高温極限では古典的 Boltzmann 因子とデルタ関数の積に近づく．
