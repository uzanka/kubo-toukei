# 演習問題【6-C-30】

## 解答

## 1. 固有状態展開

ハミルトニアンと密度演算子を

```math
\mathcal H=\frac{p^2}{2m}+\frac12m\omega^2q^2, \qquad \rho=e^{-\beta\mathcal H}
```

とする．
求める行列要素は

```math
\langle q|\rho|q'\rangle =\sum\_{n=0}^{\infty}e^{-\beta E_n} \psi_n(q)\psi_n^*(q')
```

である．
固有関数は実関数なので， $\psi_n^*(q')=\psi_n(q')$ である．

```math
E_n=\left(n+\frac12\right)\hbar\omega,\qquad \xi=\sqrt{\frac{m\omega}{\hbar}}q,\quad \xi'=\sqrt{\frac{m\omega}{\hbar}}q'
```

および

```math
\psi_n(q)= \left(\frac{m\omega}{\pi\hbar}\right)^{1/4} \frac{H_n(\xi)}{\sqrt{2^n n!}}e^{-\xi^2/2}
```

を代入する．
$x=\beta\hbar\omega$ とおけば，

```math
\begin{aligned} \langle q|\rho|q'\rangle ={}&\left(\frac{m\omega}{\pi\hbar}\right)^{1/2} e^{-(\xi^2+\xi'^2)/2}\\\ &\times\sum\_{n=0}^{\infty} \frac{e^{-x(n+1/2)}}{2^n n!} H_n(\xi)H_n(\xi'). \end{aligned}
```

## 2. ヒントの積分表示を用いる

与えられた積分表示

```math
H_n(\xi)=\frac{e^{\xi^2}}{\sqrt{\pi}} \int\_{-\infty}^{\infty} (-2iu)^n e^{-u^2+2i\xi u}\\,du
```

を $H_n(\xi)$ と $H_n(\xi')$ の両方に用いる．
後者の積分変数を $v$ とすると，

```math
\begin{aligned} H_n(\xi)H_n(\xi') ={}&\frac{e^{\xi^2+\xi'^2}}{\pi} \int\_{-\infty}^{\infty}du \int\_{-\infty}^{\infty}dv\\\ &\times(-2iu)^n(-2iv)^n e^{-u^2-v^2+2i\xi u+2i\xi'v}. \end{aligned}
```

したがって，級数部分は

```math
\begin{aligned} S={}&\sum\_{n=0}^{\infty} \frac{e^{-x(n+1/2)}}{2^n n!} H_n(\xi)H_n(\xi')\\\ ={}&\frac{e^{-x/2}e^{\xi^2+\xi'^2}}{\pi} \int du\\,dv\\,e^{-u^2-v^2+2i\xi u+2i\xi'v}\\\ &\times\sum\_{n=0}^{\infty} \frac{e^{-xn}}{2^n n!}(-2iu)^n(-2iv)^n. \end{aligned}
```

ここで

```math
\frac{(-2iu)(-2iv)}{2}=-2uv
```

だから，指数関数の級数展開を使うと

```math
\begin{aligned} \sum\_{n=0}^{\infty} \frac{e^{-xn}}{2^n n!}(-2iu)^n(-2iv)^n &=\sum\_{n=0}^{\infty}\frac{(-2e^{-x}uv)^n}{n!}\\\ &=e^{-2e^{-x}uv}. \end{aligned}
```

よって

```math
S=\frac{e^{-x/2}e^{\xi^2+\xi'^2}}{\pi} \int du\\,dv\\, e^{-u^2-v^2-2e^{-x}uv+2i\xi u+2i\xi'v}.
```

## 3. 二重 Gaussian 積分を実行する

$r=e^{-x}$ とおくと，積分中の二次形式は

```math
u^2+v^2+2ruv = \begin{pmatrix}u&v\end{pmatrix} \begin{pmatrix}1&r\\\r&1\end{pmatrix} \begin{pmatrix}u\\\v\end{pmatrix}.
```

行列 $A$ とその行列式は

```math
A=\begin{pmatrix}1&r\\\r&1\end{pmatrix}, \qquad \det A=1-r^2.
```

Gaussian 積分公式

```math
\int\_{\mathbb R^2}d^2u\\, e^{-\mathbf u^{\mathsf T}A\mathbf u+\mathbf b^{\mathsf T}\mathbf u} = \frac{\pi}{\sqrt{\det A}} \exp\left(\frac14\mathbf b^{\mathsf T}A^{-1}\mathbf b\right)
```

に $\mathbf b=(2i\xi,2i\xi')^{\mathsf T}$ を代入して積分すると，

```math
S= \frac{e^{-x/2}}{\sqrt{1-e^{-2x}}} \exp\left[ \frac{2e^{-x}\xi\xi'-e^{-2x}(\xi^2+\xi'^2)} {1-e^{-2x}} \right].
```

これを最初の固有状態展開に代入し，指数を整理する．
双曲線関数を用いると，密度行列の厳密な結果は

```math
\boxed{ \begin{aligned} \langle q|e^{-\beta\mathcal H}|q'\rangle ={}&\sqrt{\frac{m\omega}{2\pi\hbar\sinh(\beta\hbar\omega)}}\\\ &\times\exp\left[ -\frac{m\omega}{2\hbar\sinh(\beta\hbar\omega)} \left((q^2+q'^2)\cosh(\beta\hbar\omega)-2qq'\right) \right]. \end{aligned} }
```

## 4. 高温極限 $\beta\hbar\omega\ll1$

$x=\beta\hbar\omega\ll1$ では

```math
\sinh x\simeq x,\qquad \cosh x\simeq1+\frac{x^2}{2}.
```

これを厳密解に代入し，指数の主要項を残すと

```math
\begin{aligned} \langle q|e^{-\beta\mathcal H}|q'\rangle &\simeq \sqrt{\frac{m\omega}{2\pi\hbar x}}\\\ &\quad\times \exp\left[ -\frac{m\omega(q-q')^2}{2\hbar x} -\frac{m\omega x}{4\hbar}(q^2+q'^2) \right]. \end{aligned}
```

$x=\beta\hbar\omega$ を戻せば，

```math
\boxed{ \begin{aligned} \langle q|e^{-\beta\mathcal H}|q'\rangle \simeq{}& \sqrt{\frac{m}{2\pi\beta\hbar^2}}\\\ &\times\exp\left[ -\frac{m(q-q')^2}{2\beta\hbar^2} -\frac{\beta m\omega^2}{4}(q^2+q'^2) \right]. \end{aligned} }
```

特に対角要素 $q'=q$ は

```math
\boxed{ \langle q|e^{-\beta\mathcal H}|q\rangle \simeq \sqrt{\frac{m}{2\pi\beta\hbar^2}} e^{-\beta m\omega^2q^2/2} }
```

となる．
これは古典的な Boltzmann 因子 $e^{-\beta V(q)}$ に比例する．
また，非対角要素は $q-q'$ に関して Gaussian 型に減衰する．

## 5. 規格化について

問題で定義された $\rho=e^{-\beta\mathcal H}$ は，トレース 1 に規格化された密度演算子ではない．
規格化された密度演算子が必要なら，

```math
\hat\rho=\frac{e^{-\beta\mathcal H}}{Z}, \qquad Z=\operatorname{Tr}(e^{-\beta\mathcal H}) =\frac{1}{2\sinh(\beta\hbar\omega/2)}
```

とする．
上で求めた行列要素を $Z$ で割ればよい．


## [別解]

ヒントの積分表示を使わない解法

## 1. 固有状態によるスペクトル展開

ハミルトニアンを

```math
\mathcal H=\frac{p^2}{2m}+\frac12m\omega^2q^2
```

とし，密度演算子（規格化前）を

```math
\rho=e^{-\beta\mathcal H},\qquad \beta=\frac{1}{kT}
```

とする．
エネルギー固有値と固有関数は

```math
E_n=\left(n+\frac12\right)\hbar\omega
```

および

```math
\psi_n(q)=
\left(\frac{m\omega}{\pi\hbar}\right)^{1/4}
\frac{H_n(\xi)}{\sqrt{2^n n!}}e^{-\xi^2/2},
\qquad
\xi=\sqrt{\frac{m\omega}{\hbar}}q
```

である．

エネルギー固有状態の完全性を用いると，位置表示での行列要素は

```math
\langle q|\rho|q'\rangle
=\sum_{n=0}^{\infty}e^{-\beta E_n}\psi_n(q)\psi_n^*(q')
```

と書ける．
固有関数は実関数なので， $\psi_n^*(q')=\psi_n(q')$ である．
ここで

```math
x=\sqrt{\frac{m\omega}{\hbar}}q,\qquad
y=\sqrt{\frac{m\omega}{\hbar}}q',\qquad
a=\beta\hbar\omega
```

とおくと，

```math
\begin{aligned}
\langle q|\rho|q'\rangle
&=\left(\frac{m\omega}{\pi\hbar}\right)^{1/2}
e^{-(x^2+y^2)/2}
\sum_{n=0}^{\infty}
\frac{e^{-a(n+1/2)}}{2^n n!}H_n(x)H_n(y).
\end{aligned}
```

この級数を Hermite 多項式の母関数（Mehler の公式）で和を取る．

## 2. Hermite 多項式の級数を和する

Mehler の公式は、$|z|<1$ に対して

```math
\sum_{n=0}^{\infty}
\frac{z^n}{2^n n!}H_n(x)H_n(y)
=
\frac{1}{\sqrt{1-z^2}}
\exp\left[
\frac{2zxy-z^2(x^2+y^2)}{1-z^2}
\right]
```

である．
ここで $z=e^{-a}$ とおけば，

```math
\begin{aligned}
\langle q|\rho|q'\rangle
={}&\left(\frac{m\omega}{\pi\hbar}\right)^{1/2}
e^{-(x^2+y^2)/2}e^{-a/2}\\
&\times\frac{1}{\sqrt{1-e^{-2a}}}
\exp\left[
\frac{2e^{-a}xy-e^{-2a}(x^2+y^2)}
{1-e^{-2a}}
\right].
\end{aligned}
```

指数関数の係数を整理する．
恒等式

```math
\frac{1+e^{-2a}}{1-e^{-2a}}=\coth a,
\qquad
\frac{2e^{-a}}{1-e^{-2a}}=\frac{1}{\sinh a}
```

および

```math
\frac{e^{-a/2}}{\sqrt{1-e^{-2a}}}
=\frac{1}{\sqrt{2\sinh a}}
```

を使うと，

```math
\boxed{
\langle q|e^{-\beta\mathcal H}|q'\rangle
=
\sqrt{\frac{m\omega}{2\pi\hbar\sinh(\beta\hbar\omega)}}
\exp\left[
-\frac{m\omega}{2\hbar\sinh(\beta\hbar\omega)}
\left\{(q^2+q'^2)\cosh(\beta\hbar\omega)-2qq'\right\}
\right]
}
```

を得る．
これは調和振動子の熱密度行列の位置表示である．

同じ式は，指数部を変形して

```math
\boxed{
\langle q|\rho|q'\rangle
=
\sqrt{\frac{m\omega}{2\pi\hbar\sinh a}}
\exp\left[
-\frac{m\omega}{4\hbar}
\left\{
(q+q')^2\tanh\frac a2
+(q-q')^2\coth\frac a2
\right\}
\right],
\quad a=\beta\hbar\omega
}
```

とも表せる．

## 3. 高温極限 $\beta\hbar\omega\ll1$

$a=\beta\hbar\omega\ll1$ とする．
近似

```math
\sinh a\simeq a,\qquad
\cosh a\simeq1+\frac{a^2}{2}
```

を使うと，密度行列は先頭次数で

```math
\boxed{
\langle q|e^{-\beta\mathcal H}|q'\rangle
\simeq
\sqrt{\frac{m}{2\pi\beta\hbar^2}}
\exp\left[
-\frac{m(q-q')^2}{2\beta\hbar^2}
-\frac{\beta m\omega^2}{4}(q^2+q'^2)
\right]
}
```

となる．
これは高温（古典極限）での近似式である．

特に対角成分 $q'=q$ は

```math
\boxed{
\langle q|e^{-\beta\mathcal H}|q\rangle
\simeq
\sqrt{\frac{m}{2\pi\beta\hbar^2}}
e^{-\beta m\omega^2q^2/2}
}
```

となり，古典的な Boltzmann 因子に比例する位置分布を与える．

## 4. 規格化された密度演算子について

問題文の $\rho=e^{-\beta\mathcal H}$ は一般にはトレースが 1 ではない．
規格化された熱平衡密度演算子は

```math
\hat\rho=\frac{e^{-\beta\mathcal H}}{Z},
\qquad
Z=\operatorname{Tr}(e^{-\beta\mathcal H})
=\sum_{n=0}^{\infty}e^{-\beta E_n}
=\frac{1}{2\sinh(\beta\hbar\omega/2)}
```

である．
したがって，

```math
\boxed{
\langle q|\hat\rho|q'\rangle
=
\sqrt{\frac{m\omega\tanh(\beta\hbar\omega/2)}{\pi\hbar}}
\exp\left[
-\frac{m\omega}{2\hbar\sinh(\beta\hbar\omega)}
\left\{(q^2+q'^2)\cosh(\beta\hbar\omega)-2qq'\right\}
\right]
}
```

となる．
上で求めた非規格化の行列要素を分配関数 $Z$ で割ったものに等しい．

## 結果

問題文の定義 $\rho=e^{-\beta\mathcal H}$ に対する位置表示の行列要素は

```math
\boxed{
\langle q|\rho|q'\rangle
=
\sqrt{\frac{m\omega}{2\pi\hbar\sinh(\beta\hbar\omega)}}
\exp\left[
-\frac{m\omega}{2\hbar\sinh(\beta\hbar\omega)}
\left\{(q^2+q'^2)\cosh(\beta\hbar\omega)-2qq'\right\}
\right]
}
```

であり，高温極限では

```math
\boxed{
\langle q|\rho|q'\rangle
\simeq
\sqrt{\frac{m}{2\pi\beta\hbar^2}}
\exp\left[
-\frac{m(q-q')^2}{2\beta\hbar^2}
-\frac{\beta m\omega^2}{4}(q^2+q'^2)
\right]
}
```

となる．
