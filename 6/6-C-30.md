# 演習問題【6-C-30】

## 解答

### 1. 固有関数による密度行列の表示

```math
\rho(q,q')
=\langle q|e^{-\beta\mathcal H}|q'\rangle
=\sum_{n=0}^{\infty}e^{-\beta E_n}\psi_n(q)\psi_n(q')
```

とする．
ここで

```math
E_n=\left(n+\frac{1}{2}\right)\hbar\omega, \quad x=\beta\hbar\omega,
```

```math
\xi=\sqrt{\frac{m\omega}{\hbar}}q, \qquad \xi'=\sqrt{\frac{m\omega}{\hbar}}q'
```

を用いる．
固有関数を代入すると，

```math
\begin{aligned}
\rho(q,q')
={}&\sqrt{\frac{m\omega}{\pi\hbar}} e^{-(\xi^2+\xi'^2)/2}e^{-x/2} \\
&\times\sum_{n=0}^{\infty} \frac{e^{-xn}}{2^n n!}H_n(\xi)H_n(\xi').
\end{aligned}
```

したがって，次の級数を計算すればよいことになる．

```math
S(\xi,\xi';x)= \sum_{n=0}^{\infty} \frac{e^{-xn}}{2^n n!}H_n(\xi)H_n(\xi').
```

### 2. ヒントの積分表示を代入する

問題文の積分表示

```math
H_n(\xi)=\frac{e^{\xi^2}}{\sqrt{\pi}} \int_{-\infty}^{\infty} (-2iu)^n e^{-u^2+2i\xi u} du
```

を，2 つの Hermite 多項式にそれぞれ適用する．
積分変数を $u,v$ とすれば，

```math
\begin{aligned}
S ={}&\frac{e^{\xi^2+\xi'^2}}{\pi} \int_{-\infty}^{\infty}du \int_{-\infty}^{\infty}dv e^{-u^2-v^2+2i\xi u+2i\xi'v} \\
&\times\sum_{n=0}^{\infty} \frac{e^{-xn}}{2^n n!} (-2iu)^n(-2iv)^n.
\end{aligned}
```

ここで

```math
(-2iu)^n(-2iv)^n=(-4uv)^n
```

なので，級数の各項は

```math
\frac{e^{-xn}}{2^n n!}(-4uv)^n =\frac{(-2e^{-x}uv)^n}{n!}
```

となる．
指数関数の Taylor 展開

```math
e^z=\sum_{n=0}^{\infty}\frac{z^n}{n!}
```

を使うと，

```math
\boxed{ \sum_{n=0}^{\infty} \frac{e^{-xn}}{2^n n!} (-2iu)^n(-2iv)^n =e^{-2e^{-x}uv} }
```

である．
これにより無限和が消え，二重積分だけが残る．

```math
\begin{aligned}
S =\frac{e^{\xi^2+\xi'^2}}{\pi} \int \int du dv \exp\big[ -u^2-v^2-2e^{-x}uv +2i\xi u+2i\xi'v \big].
\end{aligned}
```

### 3. 二重 Gaussian 積分を実際に計算する

$a=e^{-x}$ とおくと，積分は

```math
S=\frac{e^{\xi^2+\xi'^2}}{\pi} \int \int e^{-u^2-v^2-2auv+2i\xi u+2i\xi'v} du dv
```

となる．

まず，指数部の $u,v$ に関する二次形式を平方完成する．
行列を使うと，

```math
A= \begin{pmatrix} 1&a \\
a&1 \end{pmatrix},
\qquad \det A=1-a^2,
```

```math
A^{-1}=\frac{1}{1-a^2} \begin{pmatrix} 1&-a \\
-a&1 \end{pmatrix}.
```

Gaussian 積分の公式

```math
\begin{aligned}
&\int_{\mathbb R^2} e^{-\boldsymbol z^{\mathsf T}A\boldsymbol z +2\boldsymbol b^{\mathsf T}\boldsymbol z} d^2z \\
&\qquad=\frac{\pi}{\sqrt{\det A}} e^{\boldsymbol b^{\mathsf T}A^{-1}\boldsymbol b}
\end{aligned}
```

を使う．
ここで

```math
\boldsymbol z= \begin{pmatrix}u \\
v\end{pmatrix}, \qquad \boldsymbol b= \begin{pmatrix}i\xi \\
i\xi'\end{pmatrix}
```

とする．
すると，

```math
\boldsymbol b^{\mathsf T}A^{-1}\boldsymbol b =-\frac{\xi^2+\xi'^2-2a\xi\xi'}{1-a^2}
```

なので，

```math
\begin{aligned}
S &=\frac{e^{\xi^2+\xi'^2}}{\sqrt{1-a^2}} \exp\left[ -\frac{\xi^2+\xi'^2-2a\xi\xi'}{1-a^2} \right] \\
&=\frac{1}{\sqrt{1-a^2}} \exp\left[ \frac{-a^2(\xi^2+\xi'^2)+2a\xi\xi'}{1-a^2} \right].
\end{aligned}
```

$a=e^{-x}$ を戻し，分子と分母に適切に $e^x$ を掛けると，

```math
\boxed{
S= \frac{1}{\sqrt{1-e^{-2x}}} \exp\left[ \frac{2e^{-x}\xi\xi' -e^{-2x}(\xi^2+\xi'^2)} {1-e^{-2x}} \right]
}
```

を得る．
これが，ヒントの積分表示から導かれた Hermite 多項式の和である．

### 4. 密度行列の厳密解

得られた $S$ を第 1 節の密度行列に代入する．

```math
\begin{aligned}
\rho(q,q') ={}&\sqrt{\frac{m\omega}{\pi\hbar}} e^{-(\xi^2+\xi'^2)/2}e^{-x/2} \\
&\times\frac{1}{\sqrt{1-e^{-2x}}} \\
&\times\exp\left[ \frac{2e^{-x}\xi\xi' -e^{-2x}(\xi^2+\xi'^2)} {1-e^{-2x}} \right].
\end{aligned}
```

前置因子について，

```math
e^{-x/2}\sqrt{1\over1-e^{-2x}} =\frac{1}{\sqrt{e^x-e^{-x}}} =\frac{1}{\sqrt{2\sinh x}}
```

が成り立つ．

また，指数部は

```math
-\frac{\xi^2+\xi'^2}{2} +\frac{2e^{-x}\xi\xi' -e^{-2x}(\xi^2+\xi'^2)} {1-e^{-2x}}
```

であり，整理すると

```math
-\frac{(\xi^2+\xi'^2)\cosh x-2\xi\xi'}{2\sinh x}
```

となる．
最後に

```math
x=\beta\hbar\omega,\qquad \xi=\sqrt{\frac{m\omega}{\hbar}}q
```

を戻せば，

```math
\boxed{
\begin{aligned}
\rho(q,q')={}& \sqrt{\frac{m\omega} {2\pi\hbar\sinh(\beta\hbar\omega)}} \\
&\times\exp\left[ -\frac{m\omega}{2\hbar\sinh(\beta\hbar\omega)} \left\{(q^2+q'^2)\cosh(\beta\hbar\omega)-2qq'\right\} \right].
\end{aligned}
}
```

これが求める密度行列の厳密解である．

### 5. 高温極限 $\beta\hbar\omega\ll1$

$x=\beta\hbar\omega\ll1$ とおくと，

```math
\sinh x\simeq x,\qquad \cosh x\simeq1+\frac{x^2}{2}.
```

まず前置因子は

```math
\sqrt{\frac{m\omega}{2\pi\hbar\sinh x}} \simeq \sqrt{\frac{m}{2\pi\beta\hbar^2}}.
```

指数部については， $x$ の一次の補正まで残すため，

```math
\frac{(q^2+q'^2)\cosh x-2qq'}{\sinh x} \simeq \frac{(q-q')^2}{x} +\frac{x}{3}(q^2+qq'+q'^2)
```

と展開できる．
したがって，

```math
\boxed{
\begin{aligned}
\rho(q,q')\simeq& \sqrt{\frac{m}{2\pi\beta\hbar^2}} \\
&\times\exp\left[ -\frac{m(q-q')^2}{2\beta\hbar^2} -\frac{\beta m\omega^2}{6} (q^2+qq'+q'^2) \right].
\end{aligned}
}
```

特に，ポテンシャルによる補正を無視した主要項では，

```math
\boxed{
\rho(q,q')\simeq \sqrt{\frac{m}{2\pi\beta\hbar^2}} \exp\left[-\frac{m(q-q')^2}{2\beta\hbar^2}\right]
}
```

となる．
これは自由粒子の密度行列に対応する．
