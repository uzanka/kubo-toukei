# 演習問題【6-B-19】

## 解答

### 分散関係が $\omega=Aq^n$ である波動の低温比熱

#### 1．状態密度 $g(\omega)$ の導出

波動の分散関係が

```math
\omega=Aq^n
\tag{1}
```

で与えられる固体を考える．
ここで， $\omega$ は角振動数， $q$ は波数の大きさ， $A>0$ と $n>0$ は定数である．

まず，体積 $V$ の3次元空間で，波数ベクトルの各成分がそれぞれ微小区間 $dq_x,dq_y,dq_z$ にある状態の数は，

```math
\frac{V}{(2\pi)^3}\,dq_x\,dq_y\,dq_z
```

である．
波数空間を球座標で表し，波数の大きさが $q$ から $q+dq$ の範囲にある状態を数えると，方向に関する積分によって

```math
dq_x\,dq_y\,dq_z
\longrightarrow 4\pi q^2dq
```

となる．
したがって，波数の大きさが $q$ から $q+dq$ の範囲にあるモードの総数 $dN$ は，

```math
dN=\frac{V}{(2\pi)^3}4\pi q^2dq
=\frac{V}{2\pi^2}q^2dq
\tag{2}
```

である．

次に，式(1)から波数 $q$ を振動数 $\omega$ で表すと，

```math
q=\left(\frac{\omega}{A}\right)^{1/n}
```

となる．
これを $\omega$ で微分すると，

```math
\frac{dq}{d\omega}
=\frac{1}{nA^{1/n}}\omega^{1/n-1}
\tag{3}
```

を得る．

ここで，状態密度 $g(\omega)$ を，振動数区間 $(\omega,\omega+d\omega)$ に含まれるモードの総数が $g(\omega)d\omega$ となるように定義する．
式(2)より，

```math
g(\omega)d\omega
=\frac{V}{2\pi^2}q^2dq
```

であるから，

```math
g(\omega)
=\frac{V}{2\pi^2}q^2
\left|\frac{dq}{d\omega}\right|
\tag{4}
```

となる．
式(3)と $q=(\omega/A)^{1/n}$ を代入すると，

```math
\begin{aligned}
g(\omega)
&=\frac{V}{2\pi^2}
\left(\frac{\omega}{A}\right)^{2/n}
\frac{1}{nA^{1/n}}\omega^{1/n-1}\\[4pt]
&=\frac{VA^{-3/n}}{2\pi^2n}
\omega^{3/n-1}
\end{aligned}
```

を得る．
したがって，状態密度は

```math
\boxed{
g(\omega)=
\frac{VA^{-3/n}}{2\pi^2n}
\omega^{(3-n)/n}
}
\tag{5}
```

である．
ただし，固体に存在するモード数は有限であるため，最大角振動数を $\omega_c$ とし，この式は $0<\omega\leq\omega_c$ の範囲で用いる．

#### 2．各モードの熱容量

振動数 $\omega$ の1つのモードを量子調和振動子とみなすと，温度 $T$ における平均熱エネルギーは，

```math
\varepsilon(\omega,T)
=\frac{\hbar\omega}
{\exp\!\left(\dfrac{\hbar\omega}{kT}\right)-1}
\tag{6}
```

である．
ここで， $\hbar$ は換算 Planck 定数， $k$ は Boltzmann 定数である．
式(6)では零点エネルギー $\hbar\omega/2$ を除いているが，これは温度に依存しないため，熱容量には寄与しない．

一定の $\omega$ に対するモード当たりの熱容量 $c_\omega$ は，平均熱エネルギーを温度 $T$ で微分して

```math
c_\omega=\frac{\partial\varepsilon(\omega,T)}{\partial T}
\tag{7}
```

と求められる．
計算を簡単にするため，

```math
x=\frac{\hbar\omega}{kT}
```

とおくと，

```math
\frac{dx}{dT}=-\frac{x}{T}
```

である．
したがって，

```math
\begin{aligned}
c_\omega
&=\hbar\omega
\frac{\exp(x)}{[\exp(x)-1]^2}
\frac{x}{T}\\[4pt]
&=k\frac{\exp(x)}{[\exp(x)-1]^2}x^2
\end{aligned}
```

を得る．
よって，モード当たりの熱容量は

```math
\boxed{
c_\omega
=k\frac{\exp\!\left(\dfrac{\hbar\omega}{kT}\right)}
{\left[\exp\!\left(\dfrac{\hbar\omega}{kT}\right)-1\right]^2}
\left(\frac{\hbar\omega}{kT}\right)^2
}
\tag{8}
```

である．

#### 3．固体全体の熱容量

振動数が $\omega$ から $\omega+d\omega$ の範囲にあるモードの数は $g(\omega)d\omega$ であり，各モードの熱容量は $c_\omega$ である．
したがって，固体全体の熱容量 $C$ は，各モードの熱容量を状態密度で重み付けして積分したものとなる．

```math
C=\int_0^{\omega_c}g(\omega)c_\omega\,d\omega
\tag{9}
```

式(5)と式(8)を代入すると，

```math
\begin{aligned}
C
={}&\frac{VA^{-3/n}k}{2\pi^2n}
\int_0^{\omega_c}
\omega^{(3-n)/n}\\
&\qquad\times
\frac{\exp\!\left(\dfrac{\hbar\omega}{kT}\right)}
{\left[\exp\!\left(\dfrac{\hbar\omega}{kT}\right)-1\right]^2}
\left(\frac{\hbar\omega}{kT}\right)^2
d\omega
\end{aligned}
\tag{10}
```

となる．

ここで，積分変数を

```math
\xi=\frac{\hbar\omega}{kT}
```

に変換する．
このとき，

```math
\omega=\frac{kT}{\hbar}\xi,
\qquad
d\omega=\frac{kT}{\hbar}d\xi
```

である．
さらに，

```math
T_c=\frac{\hbar\omega_c}{k}
```

と定義すると，積分範囲は $0\leq\xi\leq T_c/T$ となる．

これらを式(10)に代入すれば，

```math
\begin{aligned}
C
={}&\frac{VA^{-3/n}k}{2\pi^2n}
\left(\frac{kT}{\hbar}\right)^{(3-n)/n+1}\\
&\times\int_0^{T_c/T}
\frac{e^\xi}{(e^\xi-1)^2}
\xi^{\,2+(3-n)/n}\,d\xi
\end{aligned}
```

である．
ここで，

```math
\frac{3-n}{n}+1=\frac{3}{n}
```

および，

```math
2+\frac{3-n}{n}=1+\frac{3}{n}
```

であるから，

```math
\boxed{
C=
\frac{VA^{-3/n}k}{2\pi^2n}
\left(\frac{kT}{\hbar}\right)^{3/n}
\int_0^{T_c/T}
\frac{e^\xi\,\xi^{1+3/n}}{(e^\xi-1)^2}\,d\xi
}
\tag{11}
```

を得る．

#### 4．低温極限

低温領域 $T\ll T_c$ では，

```math
\frac{T_c}{T}\gg1
```

である．
そのため，式(11)の積分上限を十分よい近似で $+\infty$ に置き換えられる．
したがって，

```math
C\simeq
\frac{VA^{-3/n}k}{2\pi^2n}
\left(\frac{kT}{\hbar}\right)^{3/n}
I_n
\tag{12}
```

と書ける．
ただし，

```math
I_n=
\int_0^\infty
\frac{e^\xi\,\xi^{1+3/n}}{(e^\xi-1)^2}\,d\xi
\tag{13}
```

である．

ここで， $I_n$ は温度 $T$ に依存しない定数であることを確認する．
$\xi\to0$ では $e^\xi-1\simeq\xi$ であるから，被積分関数は

```math
\frac{e^\xi\,\xi^{1+3/n}}{(e^\xi-1)^2}
\sim \xi^{-1+3/n}
```

と振る舞う．
$n>0$ ならば原点付近で積分は収束する．
また， $\xi\to\infty$ では被積分関数は $e^{-\xi}\xi^{1+3/n}$ に比例するため，無限大でも積分は収束する．
よって $I_n$ は有限な正の定数である．

したがって，式(12)で温度に依存する因子は $T^{3/n}$ のみである．
ゆえに，

```math
\boxed{
C\propto T^{3/n}
}
```

が示された．

特に， $n=1$ の格子振動では $C\propto T^3$ となり，Debye の低温比熱則が得られる．
また， $n=2$ のスピン波では $C\propto T^{3/2}$ となる．
