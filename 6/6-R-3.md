# 例題【6-R-3】

## 解答

デバイ模型における振動数の状態密度は，

```math
g(\omega)=
\begin{cases}
\displaystyle\frac{9N}{\omega_D^3}\omega^2,
&0\leq\omega\leq\omega_D,\\
0,&\text{otherwise}
\end{cases}
\tag{1}
```

である．
ここで， $N$ は原子数， $\omega_D$ はデバイ振動数である．
この状態密度は全振動モード数が $3N$ となるように規格化されている．

振動の熱エネルギーは，

```math
U(T)=
\int_0^{\omega_D}
g(\omega)\frac{\hbar\omega}
{e^{\hbar\omega/(kT)}-1}\,d\omega
\tag{2}
```

で与えられる．
したがって，式（1）を代入すると，

```math
U(T)=
\frac{9N\hbar}{\omega_D^3}
\int_0^{\omega_D}
\frac{\omega^3}
{e^{\hbar\omega/(kT)}-1}\,d\omega
\tag{3}
```

となる．

定積比熱は，

```math
C_V=\left(\frac{\partial U}{\partial T}\right)_V
\tag{4}
```

で定義される．
デバイ振動数 $\omega_D$ を温度に依存しないものとして，式（3）を温度で微分すると，

```math
C_V=
\frac{9N\hbar}{\omega_D^3}
\int_0^{\omega_D}
\omega^3
\frac{\partial}{\partial T}
\left[
\frac{1}{e^{\hbar\omega/(kT)}-1}
\right]d\omega
\tag{5}
```

を得る．

ここで，

```math
x=\frac{\hbar\omega}{kT}
\tag{6}
```

とおくと，

```math
\frac{\partial x}{\partial T}
=-\frac{\hbar\omega}{kT^2}
\tag{7}
```

である．
よって，

```math
\begin{aligned}
\frac{\partial}{\partial T}
\left(\frac{1}{e^x-1}\right)
&=-\frac{e^x}{(e^x-1)^2}
\frac{\partial x}{\partial T}\\
&=\frac{\hbar\omega}{kT^2}
\frac{e^x}{(e^x-1)^2}
\end{aligned}
\tag{8}
```

となる．
式（8）を式（5）に代入すると，

```math
C_V=
\frac{9N}{\omega_D^3}
\int_0^{\omega_D}
\frac{\hbar^2\omega^4}{kT^2}
\frac{e^{\hbar\omega/(kT)}}
{\left(e^{\hbar\omega/(kT)}-1\right)^2}
\,d\omega
\tag{9}
```

を得る．

次に，積分変数を

```math
\xi=\frac{\hbar\omega}{kT}
\tag{10}
```

と変換する．
このとき，

```math
\omega=\frac{kT}{\hbar}\xi,
\qquad
d\omega=\frac{kT}{\hbar}\,d\xi
\tag{11}
```

である．
また，デバイ温度を

```math
\Theta_D=\frac{\hbar\omega_D}{k}
\tag{12}
```

と定義すると，積分範囲は

```math
0\leq\xi\leq\frac{\Theta_D}{T}
\tag{13}
```

となる．
さらに，

```math
\frac{\hbar^2\omega^4}{kT^2}\,d\omega
=
\frac{k(kT)^3}{\hbar^3}\xi^4\,d\xi
\tag{14}
```

であるから，式（9）は，

```math
C_V=
\frac{9N}{\omega_D^3}
\frac{k(kT)^3}{\hbar^3}
\int_0^{\Theta_D/T}
\frac{\xi^4e^\xi}{(e^\xi-1)^2}\,d\xi
\tag{15}
```

となる．

式（12）より，

```math
\omega_D^3=\frac{k^3\Theta_D^3}{\hbar^3}
\tag{16}
```

である．
これを式（15）に代入すると，デバイ比熱の一般式

```math
\boxed{
C_V=
9Nk\left(\frac{T}{\Theta_D}\right)^3
\int_0^{\Theta_D/T}
\frac{\xi^4e^\xi}{(e^\xi-1)^2}\,d\xi
}
\tag{17}
```

が得られる．

## 高温極限

高温領域 $T\gg\Theta_D$ では，

```math
\frac{\Theta_D}{T}\ll1
\tag{18}
```

である．
このとき，積分の被積分関数は，

```math
\frac{\xi^4e^\xi}{(e^\xi-1)^2}
\simeq\xi^2
\tag{19}
```

と近似できる．
したがって，

```math
\begin{aligned}
C_V
&\simeq
9Nk\left(\frac{T}{\Theta_D}\right)^3
\int_0^{\Theta_D/T}\xi^2\,d\xi\\
&=
9Nk\left(\frac{T}{\Theta_D}\right)^3
\frac{1}{3}
\left(\frac{\Theta_D}{T}\right)^3\\
&=3Nk
\end{aligned}
\tag{20}
```

となる．
ゆえに，高温極限では，

```math
\boxed{C_V\longrightarrow3Nk}
\tag{21}
```

となり，デュロン・プティの法則が得られる．
高温では熱エネルギー $kT$ がデバイエネルギー $\hbar\omega_D=k\Theta_D$ より十分大きく，すべての振動モードが熱的に励起されるためである．

## 低温極限

低温領域 $T\ll\Theta_D$ では，

```math
\frac{\Theta_D}{T}\gg1
\tag{22}
```

である．
したがって，積分の上限を無限大に置き換えることができ，

```math
C_V\simeq
9Nk\left(\frac{T}{\Theta_D}\right)^3
\int_0^\infty
\frac{\xi^4e^\xi}{(e^\xi-1)^2}\,d\xi
\tag{23}
```

となる．

積分を評価するため，

```math
\frac{e^\xi}{(e^\xi-1)^2}
=
\sum_{n=1}^{\infty}ne^{-n\xi}
\tag{24}
```

を用いる．
すると，

```math
\begin{aligned}
\int_0^\infty
\frac{\xi^4e^\xi}{(e^\xi-1)^2}\,d\xi
&=
\sum_{n=1}^{\infty}
n\int_0^\infty\xi^4e^{-n\xi}\,d\xi\\
&=
\sum_{n=1}^{\infty}
n\frac{\Gamma(5)}{n^5}\\
&=
24\sum_{n=1}^{\infty}\frac{1}{n^4}\\
&=
24\zeta(4)\\
&=
24\frac{\pi^4}{90}\\
&=
\frac{4\pi^4}{15}
\end{aligned}
\tag{25}
```

である．
よって，式（23）から，

```math
C_V\simeq
9Nk\left(\frac{T}{\Theta_D}\right)^3
\frac{4\pi^4}{15}
\tag{26}
```

となる．
したがって，低温極限では，

```math
\boxed{
C_V\simeq
\frac{12\pi^4}{5}Nk
\left(\frac{T}{\Theta_D}\right)^3
}
\tag{27}
```

を得る．

以上より，デバイ模型は高温でデュロン・プティの法則 $C_V\to3Nk$ を再現し，低温では比熱が温度の3乗に比例することを示す．
