# 例題【6-R-3】

## 解答

### 1．Debyeモデルにおける内部エネルギー

固体中の原子は，平衡点の付近で小振動を行う．
Debyeモデルでは，これらの振動を等方性連続弾性体の弾性振動として近似し，振動モードの角振動数の分布を考える．

角振動数が $\omega$ と $\omega+d\omega$ の間にある振動モードの数を $g(\omega)d\omega$ とすると，Debyeモデルでは

```math
g(\omega)=
\begin{cases}
\displaystyle\frac{9N}{\omega_D^3}\omega^2
& (0\leq\omega\leq\omega_D),\\[6pt]
0 & (\omega>\omega_D)
\end{cases}
\tag{1}
```

と表される．
ここで， $N$ は原子数， $\omega_D$ はDebye振動数である．
Debye振動数は，全振動モードの数が固体の自由度の数 $3N$ に一致する条件

```math
\int_0^{\omega_D}g(\omega)\,d\omega=3N
\tag{2}
```

によって定められる．
実際に式 (1) を積分すると，

```math
\int_0^{\omega_D}
\frac{9N}{\omega_D^3}\omega^2\,d\omega
=\frac{9N}{\omega_D^3}\frac{\omega_D^3}{3}
=3N
```

となり，条件 (2) が満たされる．

次に，角振動数 $\omega$ をもつ1つの振動モードを，量子力学的な調和振動子として扱う．
そのエネルギー準位は

```math
E_n=\left(n+\frac12\right)\hbar\omega,
\qquad n=0,1,2,\ldots
\tag{3}
```

で与えられる．
ここで， $\hbar$ は換算プランク定数である．

温度 $T$ における調和振動子の分配関数は，カノニカル分布から

```math
\begin{aligned}
Z_\omega
&=\sum_{n=0}^{\infty}
e^{-E_n/kT}\\
&=\sum_{n=0}^{\infty}
e^{-(n+1/2)\hbar\omega/kT}\\
&=\frac{e^{-\hbar\omega/(2kT)}}
{1-e^{-\hbar\omega/kT}}\\
&=\frac{1}{2\sinh(\hbar\omega/2kT)}
\end{aligned}
\tag{4}
```

となる．
ここで， $k$ はボルツマン定数である．

分配関数 $Z_\omega$ を用いると，この振動モードの平均エネルギーは

```math
\begin{aligned}
\epsilon(\omega,T)
&=-\frac{\partial}{\partial\beta}
\ln Z_\omega,
\qquad \beta=\frac{1}{kT}\\
&=\frac{\hbar\omega}{2}
\coth\left(\frac{\hbar\omega}{2kT}\right)\\
&=\frac{\hbar\omega}{2}
+\frac{\hbar\omega}
{e^{\hbar\omega/kT}-1}
\end{aligned}
\tag{5}
```

で与えられる．
式 (5) の第1項は零点エネルギーであり，第2項は熱励起によるエネルギーである．
零点エネルギーは温度に依存しないため，定積熱容量を求める際には寄与しない．

固体全体の内部エネルギー $U$ は，それぞれの振動モードの平均エネルギーをすべてのモードについて足し合わせたものである．
角振動数が $\omega$ から $\omega+d\omega$ の範囲にあるモードの数が $g(\omega)d\omega$ であるから，

```math
U=\int_0^{\omega_D}
\epsilon(\omega,T)g(\omega)\,d\omega
\tag{6}
```

と表される．
式 (1)，(5) を代入すると，

```math
\begin{aligned}
U
=\frac{9N}{\omega_D^3}
\int_0^{\omega_D}
\left(
\frac{\hbar\omega}{2}
+\frac{\hbar\omega}{e^{\hbar\omega/kT}-1}
\right)\omega^2\,d\omega
\end{aligned}
\tag{7}
```

となる．

### 2．定積熱容量 $C_V$ の導出

定積熱容量 $C_V$ は，体積 $V$ と原子数 $N$ を一定に保ったときの内部エネルギーの温度微分として定義される．
すなわち，

```math
C_V=\left(\frac{\partial U}{\partial T}\right)_{V,N}
\tag{8}
```

である．

式 (7) の第1項は温度に依存しないため，式 (8) の微分によって消える．
したがって，

```math
C_V=
\frac{9N}{\omega_D^3}
\int_0^{\omega_D}
\hbar\omega^3
\frac{\partial}{\partial T}
\left(
\frac{1}{e^{\hbar\omega/kT}-1}
\right)d\omega
\tag{9}
```

となる．

ここで，

```math
x=\frac{\hbar\omega}{kT}
```

とおくと，

```math
\frac{\partial x}{\partial T}
=-\frac{\hbar\omega}{kT^2}
```

である．
連鎖律を用いて微分すると，

```math
\begin{aligned}
\frac{\partial}{\partial T}
\left(\frac{1}{e^{\hbar\omega/kT}-1}\right)
&=-\frac{e^x}{(e^x-1)^2}
\frac{\partial x}{\partial T}\\
&=\frac{\hbar\omega}{kT^2}
\frac{e^{\hbar\omega/kT}}
{(e^{\hbar\omega/kT}-1)^2}.
\end{aligned}
\tag{10}
```

式 (10) を式 (9) に代入すると，

```math
C_V=
\frac{9N}{\omega_D^3}
\int_0^{\omega_D}
\frac{(\hbar\omega)^4}{kT^2}
\frac{e^{\hbar\omega/kT}}
{(e^{\hbar\omega/kT}-1)^2}\,d\omega
\tag{11}
```

を得る．

ここで，積分を無次元化するため，

```math
\xi=\frac{\hbar\omega}{kT},
\qquad
d\omega=\frac{kT}{\hbar}\,d\xi
\tag{12}
```

と変数変換する．
また，Debye温度 $\Theta_D$ を

```math
\Theta_D=\frac{\hbar\omega_D}{k}
\tag{13}
```

と定義する．
積分範囲は $\omega=0$ で $\xi=0$ ， $\omega=\omega_D$ で $\xi=\Theta_D/T$ となる．

式 (11) に式 (12) を代入すると，

```math
\begin{aligned}
C_V
&=\frac{9N}{\omega_D^3}
\frac{(kT)^3}{\hbar^3}
\int_0^{\Theta_D/T}
\frac{\xi^4e^\xi}{(e^\xi-1)^2}\,d\xi.
\end{aligned}
\tag{14}
```

さらに，式 (13) より

```math
\omega_D^3=\frac{k^3\Theta_D^3}{\hbar^3}
```

であるから，式 (14) は

```math
\boxed{
C_V=9Nk\left(\frac{T}{\Theta_D}\right)^3
\int_0^{\Theta_D/T}
\frac{\xi^4e^\xi}{(e^\xi-1)^2}\,d\xi
}
\tag{15}
```

となる．
これがDebyeモデルによる定積熱容量の一般式である．

### 3．高温極限 $T\gg\Theta_D$

高温では，

```math
\frac{\Theta_D}{T}\ll1
```

であるため，式 (15) の積分範囲において $\xi\ll1$ が成り立つ．
指数関数をテイラー展開すると，

```math
e^\xi=1+\xi+O(\xi^2)
```

であり，

```math
e^\xi-1=\xi+O(\xi^2)
```

となる．
したがって，被積分関数は

```math
\begin{aligned}
\frac{\xi^4e^\xi}{(e^\xi-1)^2}
&\simeq\frac{\xi^4}{\xi^2}\\
&=\xi^2
\end{aligned}
\tag{16}
```

と近似できる．

この近似を式 (15) に代入すると，

```math
\begin{aligned}
C_V
&\simeq9Nk\left(\frac{T}{\Theta_D}\right)^3
\int_0^{\Theta_D/T}\xi^2\,d\xi\\
&=9Nk\left(\frac{T}{\Theta_D}\right)^3
\left[\frac{\xi^3}{3}\right]_0^{\Theta_D/T}\\
&=9Nk\left(\frac{T}{\Theta_D}\right)^3
\frac13\left(\frac{\Theta_D}{T}\right)^3\\
&=3Nk.
\end{aligned}
```

よって，高温極限では，

```math
\boxed{
C_V\simeq3Nk
}
\tag{17}
```

となる．
これは古典統計力学から得られるDulong–Petit則である．
高温では振動モードが十分に熱励起され，量子力学的なエネルギー準位の離散性の影響が小さくなるため，定積熱容量は温度に依存しない値 $3Nk$ に近づくのである．

### 4．低温極限 $T\ll\Theta_D$

低温では，

```math
\frac{\Theta_D}{T}\gg1
```

となるため，式 (15) の積分上限を無限大に置き換えることができる．
したがって，

```math
C_V\simeq9Nk\left(\frac{T}{\Theta_D}\right)^3
\int_0^\infty
\frac{\xi^4e^\xi}{(e^\xi-1)^2}\,d\xi
\tag{18}
```

となる．

この積分を計算するため，まず $\xi>0$ に対して幾何級数を用いる．

```math
\frac{1}{e^\xi-1}
=\sum_{n=1}^{\infty}e^{-n\xi}
```

であるから，両辺を $\xi$ で微分すると，

```math
\frac{e^\xi}{(e^\xi-1)^2}
=\sum_{n=1}^{\infty}ne^{-n\xi}
\tag{19}
```

を得る．
したがって，

```math
\begin{aligned}
I
&=\int_0^\infty
\frac{\xi^4e^\xi}{(e^\xi-1)^2}\,d\xi\\
&=\sum_{n=1}^{\infty}
n\int_0^\infty \xi^4e^{-n\xi}\,d\xi.
\end{aligned}
\tag{20}
```

ここで，積分公式

```math
\int_0^\infty x^m e^{-ax}\,dx
=\frac{m!}{a^{m+1}}
\qquad(a>0)
\tag{21}
```

を用いる．
これは，変数変換 $y=ax$ とガンマ関数の積分公式から得られる．
式 (21) に $m=4$ ， $a=n$ を代入すると，

```math
\int_0^\infty \xi^4e^{-n\xi}\,d\xi
=\frac{4!}{n^5}
=\frac{24}{n^5}
```

となる．
よって，

```math
\begin{aligned}
I
&=24\sum_{n=1}^{\infty}\frac{1}{n^4}\\
&=24\zeta(4)\\
&=24\frac{\pi^4}{90}\\
&=\frac{4\pi^4}{15}.
\end{aligned}
\tag{22}
```

ここで， $\zeta(s)$ はリーマンゼータ関数であり，その既知の値 $\zeta(4)=\pi^4/90$ を用いた．

式 (22) を式 (18) に代入すると，

```math
\begin{aligned}
C_V
&\simeq9Nk\left(\frac{T}{\Theta_D}\right)^3
\frac{4\pi^4}{15}\\
&=\frac{12\pi^4}{5}Nk
\left(\frac{T}{\Theta_D}\right)^3.
\end{aligned}
```

したがって，低温極限では，

```math
\boxed{
C_V\simeq
\frac{12\pi^4}{5}Nk
\left(\frac{T}{\Theta_D}\right)^3
}
\tag{23}
```

となる．
すなわち，

```math
\boxed{
C_V\propto T^3
}
\tag{24}
```

である．

低温では，熱エネルギー $kT4 がDebyeエネルギー $k\Theta_D=\hbar\omega_D$ よりも小さく，高い角振動数をもつ振動モードはほとんど励起されない．
そのため，低角振動数の振動モードが熱容量に主に寄与する．
Debyeモデルでは状態密度が $g(\omega)\propto\omega^2$ であるため，熱容量が温度の3乗に比例する結果が得られるのである．

### 5．結論

Debyeモデルに基づいて固体の定積熱容量を計算すると，

```math
C_V=9Nk\left(\frac{T}{\Theta_D}\right)^3
\int_0^{\Theta_D/T}
\frac{\xi^4e^\xi}{(e^\xi-1)^2}\,d\xi
```

となる．
この式から，高温および低温での漸近的な振る舞いはそれぞれ

```math
\boxed{
T\gg\Theta_D:
\quad C_V\simeq3Nk
}
```

および

```math
\boxed{
T\ll\Theta_D:
\quad C_V\simeq
\frac{12\pi^4}{5}Nk
\left(\frac{T}{\Theta_D}\right)^3
}
```

と求められる．

したがって，Debyeモデルは，高温でのDulong–Petit則と低温での $T^3$ 則の両方を説明するモデルである．
