# 演習問題【6-A-8】

## 解答

### 1．黒体表面から単位時間当たりに放射されるエネルギー

温度 $T$ の黒体の表面積を $A$ とする．
まず，単位面積から単位時間当たりに放射される全エネルギー $J(T)$ を求める．

問題文より，角振動数が $\omega$ から $\omega+d\omega$ の範囲にあり，表面の法線と角度 $\theta$ をなす方向の立体角要素 $d\Omega$ 内に放射されるエネルギーは，

```math
J(\omega,T,\theta)\,d\omega\,d\Omega
=c\,u(\omega,T)\cos\theta
\frac{d\Omega}{4\pi}\,d\omega
```

である．
ここで， $c$ は光速度， $u(\omega,T)$ は角振動数当たりの熱輻射エネルギー密度である．

黒体表面から外向きに放射される全エネルギーを求めるため，角振動数については $0\leq\omega<\infty$ ，方向については $0\leq\theta\leq\pi/2$ ， $0\leq\varphi<2\pi$ の範囲で積分する．
立体角要素は，

```math
d\Omega=\sin\theta\,d\theta\,d\varphi
```

であるから，

```math
\begin{aligned}
J(T)
&=\int_0^\infty d\omega
\int_0^{2\pi}d\varphi
\int_0^{\pi/2}
J(\omega,T,\theta)\sin\theta\,d\theta\\
&=\frac{c}{4\pi}
\int_0^\infty u(\omega,T)\,d\omega
\int_0^{2\pi}d\varphi
\int_0^{\pi/2}\cos\theta\sin\theta\,d\theta
\end{aligned}
```

となる．
ここで，

```math
\int_0^{2\pi}d\varphi=2\pi
```

および，

```math
\int_0^{\pi/2}\cos\theta\sin\theta\,d\theta
=\frac12
```

である．
したがって，

```math
\boxed{
J(T)=\frac{c}{4}\int_0^\infty u(\omega,T)\,d\omega
}
\tag{1}
```

を得る．

熱平衡にある黒体輻射のスペクトルエネルギー密度は，Planck の分布則より，

```math
u(\omega,T)
=\frac{\hbar\omega^3}{\pi^2c^3}
\frac{1}{e^{\hbar\omega/(kT)}-1}
```

で与えられる．
これを式 (1) に代入すると，

```math
J(T)=
\frac{\hbar}{4\pi^2c^2}
\int_0^\infty
\frac{\omega^3}{e^{\hbar\omega/(kT)}-1}\,d\omega
```

となる．
ここで，

```math
y=\frac{\hbar\omega}{kT}
```

と置換すると，

```math
\omega=\frac{kT}{\hbar}y,\qquad
d\omega=\frac{kT}{\hbar}dy
```

であるから，

```math
J(T)=
\frac{k^4T^4}{4\pi^2c^2\hbar^3}
\int_0^\infty\frac{y^3}{e^y-1}\,dy
```

を得る．
積分公式

```math
\int_0^\infty\frac{y^3}{e^y-1}\,dy
=\frac{\pi^4}{15}
```

を用いれば，

```math
J(T)=\frac{\pi^2k^4}{60c^2\hbar^3}T^4
```

となる．
比例定数をシュテファン＝ボルツマン定数 $\sigma_{\mathrm{SB}}$ と書くと，

```math
\boxed{J(T)=\sigma_{\mathrm{SB}}T^4}
\tag{2}
```

である．
問題で与えられた cgs 単位系では，

```math
\sigma_{\mathrm{SB}}
=5.672\times10^{-5}
\ \mathrm{erg\,cm^{-2}\,s^{-1}\,K^{-4}}
```

である．

### 2．立方体が放射するエネルギー

問題の黒体は，辺の長さが $1\,\mathrm{cm}$ の立方体である．
したがって，その表面積 $A$ は，

```math
A=6(1\,\mathrm{cm})^2=6\,\mathrm{cm^2}
```

である．

式 (2) より，温度 $T$ の黒体が単位時間当たりに放射する全エネルギー $W(T)$ は，

```math
W(T)=A\sigma_{\mathrm{SB}}T^4
```

となる．
よって，

```math
\begin{aligned}
W(T)
&=6\times5.672\times10^{-5}T^4\\
&=3.4032\times10^{-4}T^4
\quad\mathrm{erg/s}
\end{aligned}
\tag{3}
```

を得る．

### 3．温度 $300\,\mathrm{K}$ の壁から受ける輻射

周囲の壁は温度 $T_0=300\,\mathrm{K}$ の黒体である．
この壁から放射された熱輻射は，中央の黒体に入射し，完全黒体である中央の黒体にすべて吸収される．

ここで，中央の黒体を周囲の壁と同じ温度 $300\,\mathrm{K}$ にした場合を考える．
このとき，壁と中央の黒体は同じ温度の放射場にあり，熱平衡では中央の黒体が放射するエネルギーと吸収するエネルギーは等しい．
したがって，壁から中央の黒体に吸収される単位時間当たりのエネルギーは，

```math
W_{\mathrm{in}}=W(300)
```

である．
式 (3) より，

```math
W_{\mathrm{in}}
=3.4032\times10^{-4}\times300^4
\quad\mathrm{erg/s}
```

となる．

したがって，中央の黒体が温度 $T$ を保つために外部から供給すべきエネルギーは，放射による損失から吸収するエネルギーを差し引いた正味の損失である．
これを $P(T)$ とすると，

```math
\begin{aligned}
P(T)
&=W(T)-W(300)\\
&=3.4032\times10^{-4}(T^4-300^4)
\quad\mathrm{erg/s}
\end{aligned}
\tag{4}
```

となる．

### 4．必要な供給電力の計算

求める単位は $\mathrm{watt}$ である．
ここで，

```math
1\,\mathrm{erg}=10^{-7}\,\mathrm J,
\qquad
1\,\mathrm W=10^7\,\mathrm{erg/s}
```

であるから，式 (4) を変換すると，

```math
\boxed{
P(T)=3.4032\times10^{-11}
(T^4-300^4)\,\mathrm W
}
\tag{5}
```

となる．

#### （i）$T=500\,\mathrm K$ の場合

```math
500^4=6.25\times10^{10},\qquad
300^4=0.81\times10^{10}
```

であるから，

```math
\begin{aligned}
P(500)
&=3.4032\times10^{-11}
(6.25-0.81)\times10^{10}\\
&=3.4032\times0.544\\
&=1.8513408\,\mathrm W
\end{aligned}
```

となる．
したがって，

```math
\boxed{
P(500\,\mathrm K)\simeq1.851\,\mathrm W
}
```

である．

#### （ii）$T=800\,\mathrm K$ の場合

```math
800^4=40.96\times10^{10},\qquad
300^4=0.81\times10^{10}
```

であるから，

```math
\begin{aligned}
P(800)
&=3.4032\times10^{-11}
(40.96-0.81)\times10^{10}\\
&=3.4032\times4.015\\
&=13.663848\,\mathrm W
\end{aligned}
```

となる．
したがって，

```math
\boxed{
P(800\,\mathrm K)\simeq13.66\,\mathrm W
}
```

である．

#### （iii）$T=1000\,\mathrm K$ の場合

```math
1000^4=100\times10^{10},\qquad
300^4=0.81\times10^{10}
```

であるから，

```math
\begin{aligned}
P(1000)
&=3.4032\times10^{-11}
(100-0.81)\times10^{10}\\
&=3.4032\times9.919\\
&=33.7563408\,\mathrm W
\end{aligned}
```

となる．
したがって，

```math
\boxed{
P(1000\,\mathrm K)\simeq33.76\,\mathrm W
}
```

である．

### 5．答

真空中にある辺の長さ $1\,\mathrm{cm}$ の黒体を，各温度に保つために必要な供給電力は次のとおりである．

```math
\boxed{
\begin{array}{c|c}
\text{黒体の温度} & \text{必要な供給電力}\\ \hline
500\,\mathrm K & 1.851\,\mathrm W\\
800\,\mathrm K & 13.66\,\mathrm W\\
1000\,\mathrm K & 33.76\,\mathrm W
\end{array}
}
```

これらは，黒体からの放射電力と，温度 $300\,\mathrm K$ の周囲の壁から吸収する輻射電力との差に等しい．
