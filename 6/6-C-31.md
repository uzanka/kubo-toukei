# 演習問題【6-C-31】

## 解答

### 1次元調和振動子の $\overline{q^2}$ および $\overline{p^2}$

#### 1．密度行列と分配関数

1次元調和振動子のハミルトニアンは，

```math
\mathcal H=\frac{\hat p^2}{2m}
+\frac12m\omega^2\hat q^2
```

である．
ここで， $m$ は質量， $\omega$ は角振動数である．
また，

```math
\beta=\frac{1}{kT}
```

とする．

前問で求めた密度行列の行列要素を

```math
K(q,q')=\langle q|e^{-\beta\mathcal H}|q'\rangle
```

とおく．
この $K$ は規格化されていない行列要素である．
分配関数は

```math
Z=\operatorname{Tr}(e^{-\beta\mathcal H})
=\int_{-\infty}^{\infty}K(q,q)\,dq
\tag{1}
```

であり，物理量 $\hat A$ の熱平均は

```math
\overline{A}
=\frac{1}{Z}\operatorname{Tr}(e^{-\beta\mathcal H}\hat A)
\tag{2}
```

で求められる．

前問の結果より，

```math
\begin{aligned}
K(q,q')={}&
\left[
\frac{m\omega}{2\pi\hbar\sinh(\beta\hbar\omega)}
\right]^{1/2}\\
&\times
\exp\left[
-\frac{m\omega}{2\hbar\sinh(\beta\hbar\omega)}
\left\{(q^2+q'^2)\cosh(\beta\hbar\omega)-2qq'\right\}
\right]
\end{aligned}
\tag{3}
```

である．
以下では，この式を用いて二つの期待値を求める．

#### 2．位置の2乗の期待値 $\overline{q^2}$

位置の2乗の期待値は，式(2)より，

```math
\overline{q^2}
=\frac{1}{Z}\int_{-\infty}^{\infty}q^2K(q,q)\,dq
\tag{4}
```

である．
まず，

```math
x=\beta\hbar\omega
```

とおく．
式(3)で $q'=q$ とすると，

```math
\begin{aligned}
K(q,q)
&=\left[
\frac{m\omega}{2\pi\hbar\sinh x}
\right]^{1/2}
\exp\left[
-\frac{m\omega}{\hbar}
q^2\frac{\cosh x-1}{\sinh x}
\right]
\end{aligned}
```

となる．
恒等式

```math
\frac{\cosh x-1}{\sinh x}
=\tanh\frac{x}{2}
```

を用い，

```math
a=\frac{m\omega}{\hbar}\tanh\frac{x}{2}
```

とおくと，

```math
K(q,q)=
\left[
\frac{m\omega}{2\pi\hbar\sinh x}
\right]^{1/2}e^{-aq^2}
\tag{5}
```

である．

Gaussian 積分の公式

```math
\int_{-\infty}^{\infty}e^{-aq^2}\,dq
=\sqrt{\frac{\pi}{a}}
\qquad(a>0)
```

から，両辺を $a$ で微分すると，

```math
-\int_{-\infty}^{\infty}q^2e^{-aq^2}\,dq
=-\frac{1}{2a}\sqrt{\frac{\pi}{a}}
```

を得る．
したがって，

```math
\frac{
\displaystyle\int_{-\infty}^{\infty}q^2e^{-aq^2}\,dq
}{
\displaystyle\int_{-\infty}^{\infty}e^{-aq^2}\,dq
}
=\frac{1}{2a}
\tag{6}
```

である．

式(1)，(4)，(5)，(6)を用いると，式(5)の前置因子は分子と分母で相殺されるため，

```math
\overline{q^2}=\frac{1}{2a}
```

となる．
$a$ の定義を代入すれば，

```math
\overline{q^2}
=\frac{\hbar}{2m\omega}
\frac{1}{\tanh(x/2)}
```

である．
よって，

```math
\boxed{
\overline{q^2}
=\frac{\hbar}{2m\omega}
\coth\left(\frac{\beta\hbar\omega}{2}\right)
}
\tag{7}
```

を得る．

#### 3．運動量の2乗の期待値 $\overline{p^2}$

位置表示において，運動量演算子は

```math
\hat p=-i\hbar\frac{\partial}{\partial q}
```

である．
したがって，

```math
\hat p^2=-\hbar^2\frac{\partial^2}{\partial q^2}
```

となる．
トレースの巡回性を用いると，運動量の2乗の期待値は

```math
\boxed{
\overline{p^2}
=-\frac{\hbar^2}{Z}
\int_{-\infty}^{\infty}
\left[
\frac{\partial^2}{\partial q^2}K(q,q')
\right]_{q'=q}\,dq
}
\tag{8}
```

で与えられる．
ここでは，第1引数 $q$ について微分を実行し，その後で $q'=q$ とする．

計算を簡単にするため，式(3)を

```math
K(q,q')=C
\exp\left[-A(q^2+q'^2)+Bqq'\right]
\tag{9}
```

と表す．
ここで，

```math
C=\left[
\frac{m\omega}{2\pi\hbar\sinh x}
\right]^{1/2},
\qquad
A=\frac{m\omega}{2\hbar}\coth x,
\qquad
B=\frac{m\omega}{\hbar\sinh x}
\tag{10}
```

である．

まず，式(9)を $q$ について微分すると，

```math
\frac{\partial K}{\partial q}
=(-2Aq+Bq')K(q,q')
```

となる．
さらに微分すれば，

```math
\begin{aligned}
\frac{\partial^2 K}{\partial q^2}
&=-2AK+(-2Aq+Bq')\frac{\partial K}{\partial q}\\
&=\left[-2A+(-2Aq+Bq')^2\right]K(q,q')
\end{aligned}
```

である．
ここで $q'=q$ とすると，

```math
\boxed{
\left[
\frac{\partial^2 K}{\partial q^2}
\right]_{q'=q}
=\left[-2A+(B-2A)^2q^2\right]K(q,q)
}
\tag{11}
```

を得る．

式(8)と式(11)を組み合わせると，

```math
\begin{aligned}
\overline{p^2}
&=-\frac{\hbar^2}{Z}
\int_{-\infty}^{\infty}
\left[-2A+(B-2A)^2q^2\right]K(q,q)\,dq\\
&=\hbar^2
\left[
2A-(B-2A)^2\overline{q^2}
\right]
\end{aligned}
\tag{12}
```

となる．
ここでは，式(1)，(4)の定義から，

```math
\frac{1}{Z}\int_{-\infty}^{\infty}q^2K(q,q)\,dq
=\overline{q^2}
```

を用いた．

次に，式(10)の $A,B$ を整理する．
双曲線関数の恒等式

```math
\frac{1}{\sinh x}-\coth x
=-\tanh\frac{x}{2}
```

より，

```math
B-2A
=\frac{m\omega}{\hbar}
\left(\frac{1}{\sinh x}-\coth x\right)
=-\frac{m\omega}{\hbar}\tanh\frac{x}{2}
\tag{13}
```

である．
したがって，

```math
(B-2A)^2\overline{q^2}
=\left(\frac{m\omega}{\hbar}\right)^2
\tanh^2\frac{x}{2}
\cdot
\frac{\hbar}{2m\omega}\coth\frac{x}{2}
```

となる．
$\tanh^2y\,\coth y=\tanh y$ を使えば，

```math
(B-2A)^2\overline{q^2}
=\frac{m\omega}{2\hbar}\tanh\frac{x}{2}
\tag{14}
```

を得る．
また，

```math
2A=\frac{m\omega}{\hbar}\coth x
```

であるから，式(12)は

```math
\overline{p^2}
=\hbar^2\frac{m\omega}{\hbar}
\left[
\coth x-\frac12\tanh\frac{x}{2}
\right]
\tag{15}
```

となる．

ここで，恒等式

```math
\coth x
=\frac12\left(
\coth\frac{x}{2}+\tanh\frac{x}{2}
\right)
```

を用いると，

```math
\coth x-\frac12\tanh\frac{x}{2}
=\frac12\coth\frac{x}{2}
```

である．
これを式(15)に代入すれば，

```math
\boxed{
\overline{p^2}
=\frac{\hbar m\omega}{2}
\coth\left(\frac{\beta\hbar\omega}{2}\right)
}
\tag{16}
```

を得る．

#### 4．結果の確認と物理的意味

式(7)，(16)から，位置エネルギーと運動エネルギーの平均はそれぞれ，

```math
\begin{aligned}
\overline{V}
&=\frac12m\omega^2\overline{q^2}\\
&=\frac{\hbar\omega}{4}
\coth\left(\frac{\beta\hbar\omega}{2}\right)
\end{aligned}
```

および

```math
\begin{aligned}
\overline{T}
&=\frac{\overline{p^2}}{2m}\\
&=\frac{\hbar\omega}{4}
\coth\left(\frac{\beta\hbar\omega}{2}\right)
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\overline{T}=\overline{V}
}
```

であり，平均エネルギーは両者の和として，

```math
\boxed{
\overline{\mathcal H}
=\frac{\hbar\omega}{2}
\coth\left(\frac{\beta\hbar\omega}{2}\right)
}
```

である．

さらに，高温極限 $\beta\hbar\omega\ll1$ では $\coth y\simeq1/y$ であるため，

```math
\boxed{
\overline{q^2}\simeq\frac{kT}{m\omega^2},
\qquad
\overline{p^2}\simeq mkT
}
```

となる．
したがって，

```math
\overline{V}\simeq\frac12kT,
\qquad
\overline{T}\simeq\frac12kT
```

を得る．
これは古典的なエネルギー等分配則に一致する．

一方，低温極限 $\beta\hbar\omega\gg1$ では $\coth(\beta\hbar\omega/2)\to1$ であるから，

```math
\overline{q^2}\to\frac{\hbar}{2m\omega},
\qquad
\overline{p^2}\to\frac{\hbar m\omega}{2}
```

となる．
この有限値は，調和振動子が絶対零度でも零点エネルギーをもつことに対応する．
