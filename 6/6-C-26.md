# 演習問題【6-C-26】

## 解答

### 特殊な熱源に接触した系のカノニカル分布

#### 1．熱源と仕事源のエントロピー

熱源 $R$ に接触した系 $S$ を考える．
系 $S$ がエネルギー $E$ をもつとき，熱源 $R$ と仕事源 $W$ がもつエントロピーを合わせて $S_{\mathrm{W+R}}(E)$ と表す．

統計力学では，エントロピー $S$ と微視的状態数 $\mathcal W$ の間に

```math
S=k\log\mathcal W
```

という関係がある．
したがって，微視的状態数は

```math
\mathcal W=\exp\left(\frac{S}{k}\right)
```

と書ける．
系 $S$ のある微視的状態の確率は，それと両立する熱源側の微視的状態数に比例するため，

```math
\rho(E)\propto
\exp\left(\frac{S_{\mathrm{W+R}}(E)}{k}\right)
```

となる．
ここで $k$ は Boltzmann 定数である．
基準状態 $E=0$ の確率を基準として定数因子を吸収すれば，

```math
\boxed{
\rho(E)\propto
\exp\left[
\frac{S_{\mathrm{W+R}}(E)-S_{\mathrm{W+R}}(0)}{k}
\right]
}
\tag{1}
```

を得る．

仕事源 $W$ は，エネルギーを供給する際に仕事をする装置であり，そのエントロピーは変化しないものと仮定する．
したがって，式(1)におけるエントロピー変化は，熱源 $R$ のエントロピー変化だけで決まる．
熱源のエネルギーを $E_{\mathrm R}$ とし，系 $S$ のエネルギーが $0$ のときの値を $E_{\mathrm R}^0$ とすると，

```math
\boxed{
\rho(E)\propto
\exp\left[
\frac{S_{\mathrm R}(E_{\mathrm R})-S_{\mathrm R}(E_{\mathrm R}^0)}{k}
\right]
}
\tag{2}
```

である．

#### 2．エネルギー収支を考える

問題の条件より，熱源 $R$ から系 $S$ にエネルギー $E$ が与えられるごとに，仕事源 $W$ から熱源 $R$ にエネルギー $nE$ が供給される．

したがって，熱源 $R$ は系 $S$ にエネルギー $E$ を与えることで $E$ を失う一方，仕事源 $W$ から $nE$ を受け取る．
このため，熱源 $R$ のエネルギーは

```math
E_{\mathrm R}=E_{\mathrm R}^0-E+nE
```

となる．
整理すると，

```math
\boxed{
E_{\mathrm R}=E_{\mathrm R}^0-(1-n)E
}
\tag{3}
```

を得る．
この式が重要である．
通常の熱源では熱源のエネルギー変化は $-E$ であるが，本問題では仕事源からのエネルギー供給があるため，変化量は $-(1-n)E$ となる．

#### 3．熱源のエントロピーを Taylor 展開する

式(3)を式(2)に代入すると，

```math
\rho(E)\propto
\exp\left[
\frac{
S_{\mathrm R}\{E_{\mathrm R}^0-(1-n)E\}
-S_{\mathrm R}(E_{\mathrm R}^0)
}{k}
\right]
\tag{4}
```

となる．
ここで，熱源 $R$ は十分に大きく，エネルギーの授受によって温度がほとんど変化しないと仮定する．
このとき，エントロピーを基準エネルギー $E_{\mathrm R}^0$ の近くで一次まで Taylor 展開できる．

熱力学の基本関係より，

```math
\left(\frac{\partial S_{\mathrm R}}{\partial E_{\mathrm R}}\right)_{V,N}
=\frac{1}{T_{\mathrm R}}
```

である．
ここで $T_{\mathrm R}$ は，基準状態 $E_{\mathrm R}^0$ における熱源 $R$ の温度である．したがって，

```math
\begin{aligned}
&S_{\mathrm R}(E_{\mathrm R})-S_{\mathrm R}(E_{\mathrm R}^0)\\
&\qquad\simeq
\left(\frac{\partial S_{\mathrm R}}{\partial E_{\mathrm R}}\right)_{E_{\mathrm R}^0}
(E_{\mathrm R}-E_{\mathrm R}^0)\\
&\qquad=\frac{E_{\mathrm R}-E_{\mathrm R}^0}{T_{\mathrm R}}
\end{aligned}
\tag{5}
```

となる．
式(3)より，

```math
E_{\mathrm R}-E_{\mathrm R}^0=-(1-n)E
```

であるため，

```math
\boxed{
S_{\mathrm R}(E_{\mathrm R})-S_{\mathrm R}(E_{\mathrm R}^0)
\simeq-\frac{(1-n)E}{T_{\mathrm R}}
}
\tag{6}
```

を得る．

#### 4．カノニカル分布の形を導く

式(6)を式(2)に代入すると，

```math
\begin{aligned}
\rho(E)
&\propto
\exp\left[-\frac{(1-n)E}{kT_{\mathrm R}}\right]
\end{aligned}
```

となる．
ここで，

```math
\beta=\frac{1}{kT_{\mathrm R}}
```

と定義すれば，

```math
\boxed{
\rho(E)\propto\exp\{-\beta(1-n)E\}
}
```

を得る．
これが求める分布である．

通常のカノニカル分布 $\rho(E)\propto e^{-\beta E}$ と比べると，指数部分の $\beta$ が $\beta(1-n)$ に置き換わっていることが分かる．
これは，仕事源 $W$ によるエネルギー供給のために，熱源 $R$ の実効的なエネルギー変化が $-(1-n)E$ となることによるものである．

なお，エネルギーが上限なく大きくなり得る系では，この重みが正規化可能であるためには $1-n>0$ ，すなわち $n<1$ が必要である．
$n=1$ ではエネルギーに依存しない重みとなり， $n>1$ では高エネルギーほど重みが大きくなるため，そのような系では通常の正規化可能なカノニカル分布にならない．
