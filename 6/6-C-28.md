# 演習問題【6-C-28】

## 解答

### 1次元粒子系における圧力と長さの関係

#### 1．ハミルトニアンと定温定圧分配関数

一直線上に並んだ $N$ 個の粒子を考える．
第 $j$ 粒子の座標，運動量，質量をそれぞれ $x_j,p_j,m_j$ とする．
粒子の配列順序は変わらず，隣接粒子間の相互作用のみを考えるので，ハミルトニアンは

```math
\mathcal H
=\sum_{j=1}^{N}\frac{p_j^2}{2m_j}
+\sum_{j=1}^{N-1}\phi(x_{j+1}-x_j)
\tag{1}
```

である．
ここで， $\phi(\xi)$ は粒子間距離 $\xi$ のみの関数である．

1次元系の長さは，両端の粒子の間隔

```math
L=x_N-x_1
```

で与えられる．
圧力 $p$ の外部環境と温度 $T$ で熱平衡にある定温定圧アンサンブルを考えると，分配関数には圧力による仕事 $pL$ が含まれ，

```math
Y=\int
\exp[-\beta(\mathcal H+pL)]\,d\Gamma
\tag{2}
```

と書ける．
ここで， $\beta=1/(kT)$ ， $k$ は Boltzmann 定数， $d\Gamma$ は位相空間の積分測度である．
並進運動による重心の自由な移動は，重心を固定することで除く．

運動量に関する積分はガウス積分であり，圧力 $p$ に依存しない因子を与える．
したがって，平均長さと圧力の関係を求めるには，位置積分の圧力依存性を調べれば十分である．

#### 2．粒子間距離を用いた分配関数の分解

隣接粒子間の距離を

```math
\xi_j=x_{j+1}-x_j
\qquad(j=1,\ldots,N-1)
\tag{3}
```

と定義する．
配列順序が変わらないという条件から，

```math
\xi_j\geq0
```

である．
また，長さ $L$ はすべての隣接距離の和なので，

```math
L=\sum_{j=1}^{N-1}\xi_j
\tag{4}
```

となる．

ここで，重心座標を

```math
X_{\mathrm{cm}}
=\frac{1}{M}\sum_{i=1}^{N}m_i x_i,
\qquad
M=\sum_{i=1}^{N}m_i
```

と定義する．
座標 $x_1,\ldots,x_N$ の代わりに，重心座標 $X_{\mathrm{cm}}$ と粒子間距離 $\xi_1,\ldots,\xi_{N-1}$ を用いる．
この変数変換のヤコビアンは1である．
さらに，重心を原点に固定するために $\delta(X_{\mathrm{cm}})$ を導入すれば，重心座標の積分は

```math
\int_{-\infty}^{\infty}
\delta(X_{\mathrm{cm}})\,dX_{\mathrm{cm}}=1
```

となる．
よって，位置積分において残る変数は粒子間距離だけである．

式(1)，(4)から，位置に依存するエネルギーは

```math
\sum_{j=1}^{N-1}\phi(\xi_j)+p\sum_{j=1}^{N-1}\xi_j
=\sum_{j=1}^{N-1}\{\phi(\xi_j)+p\xi_j\}
```

と書ける．
したがって，位置積分は

```math
Q(\beta,p)
=\prod_{j=1}^{N-1}
\int_0^\infty
e^{-\beta\{\phi(\xi_j)+p\xi_j\}}\,d\xi_j
```

となる．
各積分は同じ形であるから，

```math
I(\beta,p)
=\int_0^\infty
e^{-\beta\phi(\xi)}e^{-\beta p\xi}\,d\xi
\tag{5}
```

と定義すれば，

```math
\boxed{
Q(\beta,p)=I(\beta,p)^{N-1}
}
\tag{6}
```

である．
運動量積分や重心固定に由来する，圧力 $p$ に依存しない定数因子は，以下の微分計算には影響しない．

#### 3．平均長さと圧力の関係

定温定圧アンサンブルでは，平均長さ $\bar L$ は分配関数の対数を圧力で微分することで求められる．
式(2)より，

```math
\boxed{
\bar L
=-\frac{1}{\beta}
\left(\frac{\partial\log Y}{\partial p}\right)_{\beta}
}
\tag{7}
```

である．
運動量積分などの因子は圧力に依存しないため，式(6)を用いると，

```math
\begin{aligned}
\bar L
&=-\frac{1}{\beta}
\frac{\partial\log Q}{\partial p}\\
&=-\frac{N-1}{\beta}
\frac{\partial\log I}{\partial p}
\end{aligned}
\tag{8}
```

を得る．

次に， $\bar L$ が圧力 $p$ の単調減少関数であることを示す．
式(5)において，

```math
w(\xi)=e^{-\beta\phi(\xi)}e^{-\beta p\xi}
```

とおくと，

```math
I=\int_0^\infty w(\xi)\,d\xi
```

である．
圧力について微分すると，

```math
I'=-\beta\int_0^\infty \xi w(\xi)\,d\xi
\tag{9}
```

および

```math
I''=\beta^2\int_0^\infty \xi^2w(\xi)\,d\xi
\tag{10}
```

となる．
ここで，プライムは圧力 $p$ に関する微分を表す．

対数の2階微分は，

```math
\frac{\partial^2\log I}{\partial p^2}
=\frac{I''}{I}-\left(\frac{I'}{I}\right)^2
\tag{11}
```

である．

この式の意味を明確にするため，粒子間距離 $\xi$ の確率密度を

```math
P_p(\xi)
=\frac{w(\xi)}{I}
\tag{12}
```

と定義する．
これは $\int_0^\infty P_p(\xi)\,d\xi=1$ を満たす規格化された分布である．
この分布における平均値を $\langle\cdot\rangle_p$ と書けば，

```math
\frac{I'}{I}=-\beta\langle\xi\rangle_p,
\qquad
\frac{I''}{I}=\beta^2\langle\xi^2\rangle_p
```

となる．
したがって，

```math
\begin{aligned}
\frac{\partial^2\log I}{\partial p^2}
&=\beta^2
\left(
\langle\xi^2\rangle_p
-\langle\xi\rangle_p^2
\right)\\
&=\beta^2\operatorname{Var}_p(\xi)
\end{aligned}
\tag{13}
```

である．
ここで，

```math
\operatorname{Var}_p(\xi)
=\langle\xi^2\rangle_p-\langle\xi\rangle_p^2
```

は粒子間距離の分散であり，定義から非負である．
有限温度で粒子間距離が連続的に変動できる場合には，その分布が一点に集中することはないため，

```math
\operatorname{Var}_p(\xi)>0
```

となる．

式(8)，(13)から，

```math
\begin{aligned}
\left(\frac{\partial\bar L}{\partial p}\right)_T
&=-\frac{N-1}{\beta}
\frac{\partial^2\log I}{\partial p^2}\\
&=-(N-1)\beta\operatorname{Var}_p(\xi)<0
\end{aligned}
```

を得る．
よって，

```math
\boxed{
\left(\frac{\partial\bar L}{\partial p}\right)_T<0
}
\tag{14}
```

である．
すなわち，温度を一定に保てば，圧力が増加すると平均長さは必ず減少する．

#### 4．相転移に相当する特異な現象が起こらないこと

式(5)の $I(\beta,p)$ は，非負の関数 $e^{-\beta\phi(\xi)}$ の Laplace 変換である．
この積分が収束し，その微分も積分と交換できる圧力範囲の内部では，通常の条件の下で $I(\beta,p)$ は $p$ の解析関数であり，また $I>0$ であるから $\log I$ も解析的である．

式(6)より，圧力に依存する分配関数は $I^{N-1}$ であり，その対数は

```math
\log Q=(N-1)\log I
```

となる．
したがって，1粒子間隔当たりの熱力学ポテンシャルは $\log I$ に比例し，熱力学極限 $N\to\infty$ でも，この積分が正則な範囲では特異性を生じない．
さらに，式(14)によって平均長さは圧力の厳密な単調減少関数であるため，同じ平均長さに複数の圧力が対応することもない．

以上より， **粒子が一直線上に並び，隣接粒子間の相互作用のみを考える古典系では，分配関数が粒子間距離ごとの積分に分解されるため，圧力と平均長さの関係は単調な一価関数となり，通常の有限温度で相転移に対応する特異な現象は起こらない** ．
