# 演習問題【6-C-28】

## 解答

本問題では，1次元に並んだ $N$ 個の粒子の系において，圧力 $p$ と平均体積 $\bar{L}$ の関係が単調減少であることを証明する．

### 1. ハミルトニアンと分配関数

$N$ 個の粒子の質量を $m_j$ ，座標を $x_j$ ，運動量を $p_j$ とする．
粒子間の相互作用が隣接する粒子間のみに働く場合，ハミルトニアン $\mathcal{H}$ は次のように書ける：

$$\mathcal{H} = \sum_{j=1}^N \frac{p_j^2}{2m_j} + \sum_{j=1}^{N-1} \phi(x_{j+1} - x_j)$$

ここで， $\phi$ は相対距離の関数である相互作用ポテンシャルである．

定温定圧（ $T$ - $p$ ）アンサンブルにおける分配関数 $Y$ は，温度 $T$ （逆温度 $\beta = 1/kT$ ）および圧力 $p$ を用いて次のように表される：

$$Y = \int_{0}^{\infty} dL \int \dots \int \frac{dp_1 \dots dp_N}{h^N} \int \dots \int dx_1 \dots dx_N e^{-\beta(\mathcal{H} + pL)}$$

ここで， $L$ は系の体積（1次元なので長さ）であり， $L = x_N - x_1$ である．

### 2. 座標積分の簡略化

運動量の積分はガウス積分として容易に計算でき，その結果は $p$ に依存しない定数として $Q$ にまとめられる．

$$Y = Q \cdot \prod_{j=1}^N \left( \frac{2\pi m_j kT}{h^2} \right)^{1/2}$$

次に，座標についての積分を考える．
粒子が一直線上に並び，その順序が入れ替わらない条件 $x_1 \le x_2 \le \dots \le x_N$ を考慮する．
また，重心の位置を原点に固定するためのデルタ関数 $\delta(\frac{1}{M} \sum m_i x_i)$ を導入することで，全質量 $M = \sum m_i$ の重心が動かない条件を課す．

変数変換として，隣接する粒子間の距離 $\xi_j = x_{j+1} - x_j$ ( $j=1, \dots, N-1$ ) を導入する．
このとき， $L = \sum_{j=1}^{N-1} \xi_j$ となる．
デルタ関数のフーリエ展開を用いて積分を実行すると，分配関数 $Q$ は次のように簡略化される：

$$Q = \left[ \int_{0}^{\infty} e^{-\beta \phi(\xi) - \beta p \xi} d\xi \right]^{N-1}$$

ここで，積分の中身を $I(\beta, p) = \int_{0}^{\infty} e^{-\beta \phi(\xi)} e^{-\beta p \xi} d\xi$ とおくと， $Q = [I(\beta, p)]^{N-1}$ と書ける．

### 3. 平均体積と単調性の証明

定圧アンサンブルにおける体積の期待値 $\bar{L}$ は，分配関数 $Y$ を用いて次のように与えられる：

$$\bar{L} = -\frac{1}{\beta} \left( \frac{\partial \log Y}{\partial p} \right)_{\beta}$$

$Y$ の $p$ 依存性は $Q$ に集約されているため，

$$\bar{L} = -\frac{1}{\beta} \frac{\partial \log Q}{\partial p} = -\frac{N-1}{\beta} \frac{\partial \log I(\beta, p)}{\partial p}$$

となる．
$\bar{L}$ が $p$ に関して単調減少であることを示すには， $\frac{\partial \bar{L}}{\partial p} < 0$ を示せばよい．

$$\frac{\partial \bar{L}}{\partial p} = -\frac{N-1}{\beta} \frac{\partial^2 \log I}{\partial p^2}$$

ここで， $I(\beta, p)$ を $p$ に関する関数として微分すると，

$$\frac{\partial \log I}{\partial p} = \frac{1}{I} \frac{\partial I}{\partial p}$$

$$\frac{\partial^2 \log I}{\partial p^2} = \frac{\partial}{\partial p} \left( \frac{1}{I} \frac{\partial I}{\partial p} \right) = \frac{1}{I} \frac{\partial^2 I}{\partial p^2} - \frac{1}{I^2} \left( \frac{\partial I}{\partial p} \right)^2 = \frac{I'' I - (I')^2}{I^2}$$

となる．
ここで， $I = \int_{0}^{\infty} w(x) dx$ ， $I' = \int_{0}^{\infty} (-\beta x) w(x) dx$ ， $I'' = \int_{0}^{\infty} (-\beta x)^2 w(x) dx$ とおいた（ただし $w(x) = e^{-\beta \phi(x) - \beta px} \ge 0$ である．
すると，

$$\frac{I'' I - (I')^2}{I^2} = \frac{1}{I} \int_{0}^{\infty} (-\beta x)^2 w(x) dx - \left( \frac{1}{I} \int_{0}^{\infty} (-\beta x) w(x) dx \right)^2$$

これは，分布 $w(x)$ における変数 $X = -\beta x$ の分散 $\langle X^2 \rangle - \langle X \rangle^2$ に相当する．
統計学における分散の性質により，これは常に非負であり，分布が一点に集中しない限り正となる．
したがって，

$$\frac{\partial \bar{L}}{\partial p} = -\frac{N-1}{\beta} \cdot (\text{分散}) < 0$$

が成立する．
これにより，圧力 $p$ が増加すると平均体積 $\bar{L}$ は単調に減少し，相転移のような不連続な現象は起こらないことが証明された．

## 解説

### 1. 定圧アンサンブル（ $T$-$p$ アンサンブル）

通常の定積アンサンブル（ $T$ - $V$ アンサンブル）では体積 $V$ が固定されているが，定圧アンサンブルでは圧力 $p$ が外部から一定に保たれている．
このとき，系は体積を変化させることで圧力と釣り合う．
分配関数に $e^{-\beta p L}$ という項が現れるのは，系が体積 $L$ を持つことによって外部へなす仕事（あるいは外部から受ける圧力によるエネルギー変化）を考慮しているためである．

### 2. 変数変換と相対座標

1次元の鎖状の系では，粒子の位置 $x_j$ を直接扱うよりも，隣接する粒子間の距離 $\xi_j = x_{j+1} - x_j$ を用いるほうが数学的に扱いやすい．
なぜなら，相互作用ポテンシャル $\phi$ が相対距離の関数であるため， $\xi_j$ を使うことでハミルトニアンが各 $\xi_j$ の独立な項の和として分離できるからである．
この「分離可能性」が，分配関数が $[I(\beta, p)]^{N-1}$ という累乗の形になる理由である．

### 3. 分散と単調性

$\frac{\partial^2 \log I}{\partial p^2}$ が分散に関連している点は重要である．
統計力学において，対数分配関数の微分は物理量の期待値（平均値）を導き，そのさらなる微分は物理量のゆらぎ（分散）を導く．
今回， $\log I$ の 1 階微分が体積に関連する量であり，その 2 階微分が体積のゆらぎに関連している．
$\frac{\partial \bar{L}}{\partial p}$ が負であることは，圧力を上げると系が押しつぶされて体積が減るという直感的な挙動を数学的に裏付けている．
また，分散が正であることは，圧力の変化に対して体積が滑らかに変化することを意味し，これが相転移（体積が不連続に変化する現象）が起こらないことの根拠となっている．
