# 例題【6-R-1】

## 解答

### 等分配の法則の証明

絶対温度 $T$ の熱浴と熱平衡にある古典的な系を考える．
独立な正準座標を

```math
q=(q_1,\ldots,q_n),\qquad
p=(p_1,\ldots,p_n)
```

とし，ハミルトニアンを

```math
\mathcal H=K(p)+V(q)
```

とする．
ここで，運動エネルギー $K$ は運動量について正定値の斉次二次形式であり，ポテンシャルエネルギー $V$ は座標のみに依存するとする．

カノニカル分布において，物理量 $A$ の平均値は

```math
\overline A
=C\int A e^{-\beta\mathcal H}\,d\Gamma
```

で与えられる．
ここで，

```math
\beta=\frac1{kT},\qquad
C^{-1}=Z=\int e^{-\beta\mathcal H}\,d\Gamma
```

であり，

```math
d\Gamma=dq_1\cdots dq_n\,dp_1\cdots dp_n
```

である．
分配関数 $Z$ は有限とし，以下で用いる平均値は絶対収束するものとする．
規格化条件は

```math
C\int e^{-\beta\mathcal H}\,d\Gamma=1
\tag{1}
```

である．

#### 1．（ii）の証明

示すべき式は

```math
\boxed{
\overline{q_i\frac{\partial V}{\partial q_j}}
=kT\delta_{ij}
}
\tag{2}
```

である．

ハミルトニアンは

```math
\mathcal H=K(p)+V(q)
```

であり，運動エネルギーは座標に依存しないため，

```math
\frac{\partial\mathcal H}{\partial q_j}
=\frac{\partial V}{\partial q_j}
\tag{3}
```

となる．
Boltzmann 因子を微分すると，

```math
\frac{\partial}{\partial q_j}e^{-\beta\mathcal H}
=-\beta\frac{\partial V}{\partial q_j}
e^{-\beta\mathcal H}
```

である．
したがって，

```math
\frac{\partial V}{\partial q_j}e^{-\beta\mathcal H}
=-\frac1\beta
\frac{\partial}{\partial q_j}e^{-\beta\mathcal H}
\tag{4}
```

を得る．

平均値の定義に式 (3)，(4) を代入すると，

```math
\begin{aligned}
\overline{q_i\frac{\partial V}{\partial q_j}}
&=C\int q_i\frac{\partial V}{\partial q_j}
e^{-\beta\mathcal H}\,d\Gamma\\
&=-\frac C\beta
\int q_i\frac{\partial}{\partial q_j}
e^{-\beta\mathcal H}\,d\Gamma
\end{aligned}
\tag{5}
```

となる．

ここで，他の座標を固定して $q_j$ について部分積分する．
固定した他の座標に対し，

```math
f(q_j)=e^{-\beta V(q)}
```

とおくと，

```math
\frac{df}{dq_j}
=-\beta\frac{\partial V}{\partial q_j}f
\tag{6}
```

である．

分配関数と平均値の絶対収束，および $K(p)$ の正定値性から，ほとんどすべての固定した他の座標について，

```math
\int_{a_j}^{b_j} f(q_j)\,dq_j<\infty
\tag{7}
```

および

```math
\int_{a_j}^{b_j}
\left|q_i\frac{\partial V}{\partial q_j}\right|
f(q_j)\,dq_j<\infty
\tag{8}
```

が成立する．
したがって，

```math
\int_{a_j}^{b_j}|q_i f'(q_j)|\,dq_j<\infty
\tag{9}
```

である．
ここで $q_i$ は $i=j$ の場合には $q_j$ を表す．

まず，部分積分の境界項を調べる．
$q_j$ の有限端点では，問題文の条件 $V\to+\infty$ から $f\to0$ となるため， $q_i$ が有限であることと合わせて

```math
q_i f(q_j)\longrightarrow0
\tag{10}
```

となる．

無限端点で $i\ne j$ の場合には，他の座標を固定すると $q_i$ は有限の定数であり， $V\to+\infty$ から同じく式 (10) が成立する．

無限端点で $i=j$ の場合には，式 (7)，(9) を用いる．

```math
g(q_j)=q_jf(q_j)
```

とおくと，

```math
g'(q_j)=f(q_j)+q_jf'(q_j)
```

である．
式 (7)，(9) より $g'$ は絶対可積分であるため， $g(q_j)$ は無限端点で有限の極限をもつ．
仮にその極限がゼロでなければ，ある正定数 $c$ に対して十分大きな $|q_j|$ で

```math
f(q_j)\geq\frac{c}{|q_j|}
```

となる．
これは式 (7) の積分可能性に反する．
よって，

```math
\boxed{
\lim_{q_j\to\pm\infty}q_jf(q_j)=0
}
\tag{11}
```

である．

以上から，ほとんどすべての固定した他の座標について，部分積分の両端の境界項は消える．
したがって，

```math
\begin{aligned}
\int_{a_j}^{b_j}
q_i\frac{df}{dq_j}\,dq_j
&=
\left[q_if(q_j)\right]_{a_j}^{b_j}
-\int_{a_j}^{b_j}
\frac{\partial q_i}{\partial q_j}f(q_j)\,dq_j\\
&=-\delta_{ij}
\int_{a_j}^{b_j}f(q_j)\,dq_j
\end{aligned}
\tag{12}
```

となる．

式 (12) を残りの座標および運動量について積分する．
ここでは，式 (7)～(9) に対応する絶対収束条件のもとで Fubini の定理を適用できる．
したがって，

```math
\int q_i\frac{\partial}{\partial q_j}
e^{-\beta\mathcal H}\,d\Gamma
=
-\delta_{ij}\int e^{-\beta\mathcal H}\,d\Gamma
\tag{13}
```

を得る．

これを式 (5) に代入すると，

```math
\begin{aligned}
\overline{q_i\frac{\partial V}{\partial q_j}}
&=\frac C\beta\delta_{ij}
\int e^{-\beta\mathcal H}\,d\Gamma\\
&=\frac1\beta\delta_{ij}\\
&=kT\delta_{ij}
\end{aligned}
```

となる．
第2行では規格化条件 (1) を用いた．
よって，

```math
\boxed{
\overline{q_i\frac{\partial V}{\partial q_j}}
=kT\delta_{ij}
}
```

が証明された．

#### 2．（i）の証明

次に，運動量について同様の計算を行う．
ポテンシャルエネルギー $V$ は運動量に依存しないため，

```math
\frac{\partial\mathcal H}{\partial p_j}
=\frac{\partial K}{\partial p_j}
\tag{14}
```

である．
Boltzmann 因子の運動量微分は

```math
\frac{\partial}{\partial p_j}e^{-\beta\mathcal H}
=-\beta\frac{\partial K}{\partial p_j}
e^{-\beta\mathcal H}
```

であるから，

```math
\overline{p_i\frac{\partial K}{\partial p_j}}
=-\frac C\beta
\int p_i\frac{\partial}{\partial p_j}
e^{-\beta\mathcal H}\,d\Gamma
```

となる．

運動エネルギー $K$ は正定値の斉次二次形式なので，運動量が無限遠に向かうとき Boltzmann 因子は Gaussian 型に減衰する．
したがって，運動量についての部分積分の境界項は消える．
よって，

```math
\begin{aligned}
\overline{p_i\frac{\partial K}{\partial p_j}}
&=\frac C\beta\int
\frac{\partial p_i}{\partial p_j}
e^{-\beta\mathcal H}\,d\Gamma\\
&=\frac C\beta\delta_{ij}
\int e^{-\beta\mathcal H}\,d\Gamma\\
&=kT\delta_{ij}
\end{aligned}
\tag{15}
```

を得る．

ここで，運動エネルギー $K$ は運動量について斉次二次式である．
すなわち，

```math
K(\lambda p)=\lambda^2K(p)
```

を満たす．
Euler の定理より，

```math
\sum_{\alpha=1}^{f}
p_\alpha\frac{\partial K}{\partial p_\alpha}
=2K
\tag{16}
```

が成り立つ．
ここで $f$ は独立な運動量自由度の数である．

式 (16) の両辺の平均をとると，

```math
2\overline K
=\sum_{\alpha=1}^{f}
\overline{
p_\alpha\frac{\partial K}{\partial p_\alpha}
}
\tag{17}
```

となる．
式 (15) から，

```math
\overline{
p_\alpha\frac{\partial K}{\partial p_\alpha}
}
=kT
```

なので，

```math
\begin{aligned}
2\overline K
&=\sum_{\alpha=1}^{f}kT\\
&=fkT
\end{aligned}
```

である．
したがって，

```math
\boxed{
\overline K=\frac f2kT
}
```

を得る．
すなわち，運動エネルギーの平均値は1自由度あたり

```math
\boxed{
\frac{\overline K}{f}=\frac12kT
}
```

となる．

以上より，（i）は運動エネルギーが運動量について斉次二次式であることから，（ii）は座標についての部分積分と境界項の消失から，それぞれ導かれる．
これが等分配の法則である．
