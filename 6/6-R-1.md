# 演習問題【6-R-1】

## 解答

### 等分配の法則の証明

絶対温度 $T$ の熱浴と熱平衡にある古典的な系を考える．
ハミルトニアンを

```math
\mathcal H=K(p)+V(q)
```

とする．
ここで， $q=(q_1,\ldots,q_n)$ は一般化座標， $p=(p_1,\ldots,p_n)$ はそれらに共役な一般化運動量であり， $K$ は運動エネルギー， $V$ はポテンシャルエネルギーである．

カノニカル分布において，物理量 $A$ の平均値は

```math
\overline A
=C\int A e^{-\beta\mathcal H}\,d\Gamma
```

で与えられる．
ここで，

```math
\beta=\frac{1}{kT},\qquad
C^{-1}=\int e^{-\beta\mathcal H}\,d\Gamma
```

であり， $k$ はボルツマン定数， $d\Gamma$ は相空間の微小体積要素

```math
d\Gamma=dq_1\cdots dq_n\,dp_1\cdots dp_n
```

である．
この規格化条件から，

```math
C\int e^{-\beta\mathcal H}\,d\Gamma=1
\tag{1}
```

が成り立つ．

#### (ii) の証明

示すべき式は

```math
\overline{q_i\frac{\partial V}{\partial q_j}}
=kT\delta_{ij}
\tag{2}
```

である．
ハミルトニアンは $\mathcal H=K(p)+V(q)$ であり，運動エネルギー $K$ は座標に依存しないため，

```math
\frac{\partial\mathcal H}{\partial q_j}
=\frac{\partial V}{\partial q_j}
\tag{3}
```

となる．

まず，ボルツマン因子を $q_j$ で微分すると，

```math
\frac{\partial}{\partial q_j}e^{-\beta\mathcal H}
=-\beta\frac{\partial\mathcal H}{\partial q_j}
e^{-\beta\mathcal H}
```

である．
したがって，

```math
\frac{\partial\mathcal H}{\partial q_j}
e^{-\beta\mathcal H}
=-\frac{1}{\beta}
\frac{\partial}{\partial q_j}e^{-\beta\mathcal H}
\tag{4}
```

を得る．

平均値の定義に式 (3)，(4) を代入すると，

```math
\begin{aligned}
\overline{q_i\frac{\partial V}{\partial q_j}}
&=C\int q_i\frac{\partial\mathcal H}{\partial q_j}
e^{-\beta\mathcal H}\,d\Gamma\\
&=-\frac{C}{\beta}
\int q_i\frac{\partial}{\partial q_j}
e^{-\beta\mathcal H}\,d\Gamma
\end{aligned}
\tag{5}
```

となる．

ここで，ほかの座標とすべての運動量を固定して， $q_j$ について部分積分を行う．
境界項が消えると仮定すると，

```math
\begin{aligned}
&\int q_i\frac{\partial}{\partial q_j}
e^{-\beta\mathcal H}\,d\Gamma\\
&\quad=
-\int\frac{\partial q_i}{\partial q_j}
e^{-\beta\mathcal H}\,d\Gamma\\
&\quad=
-\delta_{ij}\int e^{-\beta\mathcal H}\,d\Gamma
\end{aligned}
\tag{6}
```

となる．
ここで，

```math
\frac{\partial q_i}{\partial q_j}=\delta_{ij}
```

を用いた．クロネッカーのデルタ $\delta_{ij}$ は， $i=j$ のとき $1$ ， $i\ne j$ のとき $0$ である．

式 (6) を式 (5) に代入すると，

```math
\begin{aligned}
\overline{q_i\frac{\partial V}{\partial q_j}}
&=\frac{C}{\beta}\delta_{ij}
\int e^{-\beta\mathcal H}\,d\Gamma\\
&=\frac{1}{\beta}\delta_{ij}\\
&=kT\delta_{ij}
\end{aligned}
```

となる．
第2行では規格化条件 (1) を用いた．
よって，(ii) が証明された．

なお，部分積分の境界項が消えるためには，積分領域の端で $q_i e^{-\beta\mathcal H}$ がゼロに収束することが必要である．
問題の境界条件のもとで，この条件と積分の収束が満たされるものとする．

#### (i) の証明

次に，運動量について同様の計算を行う．
ポテンシャルエネルギー $V$ は運動量に依存しないため，

```math
\frac{\partial\mathcal H}{\partial p_j}
=\frac{\partial K}{\partial p_j}
\tag{7}
```

である．

平均値の定義から，

```math
\begin{aligned}
\overline{p_i\frac{\partial\mathcal H}{\partial p_j}}
&=C\int p_i\frac{\partial\mathcal H}{\partial p_j}
e^{-\beta\mathcal H}\,d\Gamma\\
&=-\frac{C}{\beta}
\int p_i\frac{\partial}{\partial p_j}
e^{-\beta\mathcal H}\,d\Gamma
\end{aligned}
```

となる．
$p_j$ について部分積分を行い，境界項が消えることを用いると，

```math
\begin{aligned}
\overline{p_i\frac{\partial\mathcal H}{\partial p_j}}
&=\frac{C}{\beta}\int
\frac{\partial p_i}{\partial p_j}
e^{-\beta\mathcal H}\,d\Gamma\\
&=\frac{C}{\beta}\delta_{ij}
\int e^{-\beta\mathcal H}\,d\Gamma\\
&=kT\delta_{ij}
\end{aligned}
\tag{8}
```

を得る．
最後の等号では規格化条件 (1) を用いた．

ここで，運動エネルギー $K$ は運動量について斉次2次式であるとする．
すなわち，運動量のすべてを同じ倍率で $\lambda$ 倍すると， $K$ は $\lambda^2$ 倍になる．例えば，

```math
K=\frac{p^2}{2m}
```

がその例である．
斉次関数に関する Euler の定理より，

```math
\sum_{\alpha=1}^{f}
p_\alpha\frac{\partial K}{\partial p_\alpha}
=2K
\tag{9}
```

が成り立つ．
ここで， $f$ は独立な運動量自由度の数である．

式 (9) の両辺の平均を取ると，

```math
\overline K
=\frac12\sum_{\alpha=1}^{f}
\overline{p_\alpha\frac{\partial K}{\partial p_\alpha}}
\tag{10}
```

となる．
式 (7)，(8) より，各自由度について

```math
\overline{p_\alpha\frac{\partial K}{\partial p_\alpha}}
=\overline{p_\alpha\frac{\partial\mathcal H}{\partial p_\alpha}}
=kT
```

である．
これを式 (10) に代入すれば，

```math
\overline K
=\frac12\sum_{\alpha=1}^{f}kT
=\frac f2 kT
```

となる．
したがって，1自由度当たりの運動エネルギーの平均値は

```math
\boxed{
\frac{\overline K}{f}=\frac12 kT
}
```

である．
これにより，(i) も証明された．

以上より，(i)，(ii) はいずれもカノニカル分布の平均値に対する部分積分から導かれる．
(i) では運動エネルギーの斉次2次性を用い，(ii) では座標微分と部分積分によってクロネッカーのデルタが現れることを用いたのである．
