# 例題【6-R-7】

## 解答

質量 $m$ の自由粒子1個について，密度演算子

```math
\rho=e^{-\beta\mathcal H},
\qquad
\mathcal H=\frac{\boldsymbol p^2}{2m}
```

の座標表示 $\langle\boldsymbol r|\rho|\boldsymbol r'\rangle$ を求める．
ここで， $\beta=1/(k_{\mathrm B}T)$ ， $k_{\mathrm B}$ は Boltzmann 定数， $T$ は絶対温度である．
問題の定義に従い， $\rho$ は分配関数で規格化されていないものとする．

### 1．自由粒子の固有状態

自由粒子の Hamilton 演算子は

```math
\mathcal H=\frac{\boldsymbol p^2}{2m}
=-\frac{\hbar^2}{2m}\nabla^2
```

である．
エネルギー固有状態 $\varphi_{\boldsymbol k}(\boldsymbol r)$ は Schrödinger 方程式

```math
-\frac{\hbar^2}{2m}\nabla^2
\varphi_{\boldsymbol k}(\boldsymbol r)
=E_{\boldsymbol k}\varphi_{\boldsymbol k}(\boldsymbol r)
\tag{1}
```

を満たす．
自由粒子にはポテンシャルエネルギーが存在しないため，固有関数は平面波の形

```math
\varphi_{\boldsymbol k}(\boldsymbol r)
=C e^{i\boldsymbol k\cdot\boldsymbol r}
```

で表される．
ここで， $\boldsymbol k=(k_x,k_y,k_z)$ は波数ベクトルであり， $C$ は規格化定数である．
これを式 (1) に代入すると，固有エネルギーは

```math
E_{\boldsymbol k}
=\frac{\hbar^2k^2}{2m}
=\frac{\hbar^2}{2m}(k_x^2+k_y^2+k_z^2)
\tag{2}
```

となる．

次に，問題で指定された周期境界条件を適用する．
立方体の一辺を $L$ とすると，

```math
\varphi_{\boldsymbol k}(x+L,y,z)
=\varphi_{\boldsymbol k}(x,y,z)
```

でなければならない．
平面波の形を代入すると，

```math
e^{ik_xL}=1
```

となるため，

```math
k_xL=2\pi n_x,
\qquad n_x\in\mathbb Z
```

を得る．
$y,z$ 方向についても同様であるから，

```math
\boxed{
k_x=\frac{2\pi n_x}{L},\quad
k_y=\frac{2\pi n_y}{L},\quad
k_z=\frac{2\pi n_z}{L}
}
\tag{3}
```

となる．
したがって，許される波数は離散的な値を取る．

波動関数を体積 $L^3$ で規格化すると，

```math
\int_{L^3}|\varphi_{\boldsymbol k}(\boldsymbol r)|^2
\,d^3r=1
```

である．
平面波の絶対値は一定であるため，

```math
|C|^2L^3=1
```

となり，位相を適切に選べば規格化された固有関数は

```math
\boxed{
\varphi_{\boldsymbol k}(\boldsymbol r)
=\frac{1}{L^{3/2}}e^{i\boldsymbol k\cdot\boldsymbol r}
}
\tag{4}
```

である．

### 2．密度演算子の座標表示

エネルギー固有状態の完全性を用いると，密度演算子の座標表示は

```math
\begin{aligned}
\langle\boldsymbol r|\rho|\boldsymbol r'\rangle
&=\sum_{\boldsymbol k}
\langle\boldsymbol r|\boldsymbol k\rangle
e^{-\beta E_{\boldsymbol k}}
\langle\boldsymbol k|\boldsymbol r'\rangle\\
&=\sum_{\boldsymbol k}
\varphi_{\boldsymbol k}(\boldsymbol r)
e^{-\beta E_{\boldsymbol k}}
\varphi_{\boldsymbol k}^{*}(\boldsymbol r')
\end{aligned}
\tag{5}
```

と表される．
ここで， $\sum_{\boldsymbol k}$ は，周期境界条件を満たすすべての波数ベクトルについて和を取ることを意味する．

式 (2)～(4) を代入すると，

```math
\begin{aligned}
\langle\boldsymbol r|\rho|\boldsymbol r'\rangle
=\frac{1}{L^3}
\sum_{n_x,n_y,n_z=-\infty}^{\infty}
\exp\Bigg[
&-\frac{\beta\hbar^2}{2m}
(k_x^2+k_y^2+k_z^2)\\
&+i\boldsymbol k\cdot(\boldsymbol r-\boldsymbol r')
\Bigg]
\end{aligned}
\tag{6}
```

を得る．
指数部は $x,y,z$ の各成分について独立に分解できるため，この和は三つの一次元の和の積に分けられる．
すなわち，

```math
\langle\boldsymbol r|\rho|\boldsymbol r'\rangle
=K_L(x,x')K_L(y,y')K_L(z,z')
\tag{7}
```

と書ける．
ここで，一次元の因子 $K_L(x,x')$ を

```math
\boxed{
K_L(x,x')
=\frac1L\sum_{n=-\infty}^{\infty}
\exp\left[
-\frac{\beta\hbar^2}{2m}
\left(\frac{2\pi n}{L}\right)^2
+i\frac{2\pi n}{L}(x-x')
\right]
}
\tag{8}
```

と定義した．
したがって，まず式 (8) の $L\to\infty$ の極限を求めればよい．

### 3．$L\to\infty$ の極限

式 (3) より，隣り合う波数の間隔は

```math
\Delta k=\frac{2\pi}{L}
```

である．
$L\to\infty$ とすると $\Delta k\to0$ となり，波数の和は連続積分に移行する．
具体的には，

```math
\frac1L\sum_{n=-\infty}^{\infty}
=\frac1{2\pi}\sum_{n=-\infty}^{\infty}\Delta k
\ \longrightarrow
\frac1{2\pi}\int_{-\infty}^{\infty}dk
\tag{9}
```

である．
これを式 (8) に適用すると，

```math
K_\infty(x,x')
=\frac1{2\pi}\int_{-\infty}^{\infty}
\exp\left[
-\frac{\beta\hbar^2}{2m}k^2
+ik(x-x')
\right]dk
\tag{10}
```

となる．

この積分は Gaussian 積分である．
公式

```math
\int_{-\infty}^{\infty}
e^{-ak^2/2+iky}\,dk
=\sqrt{\frac{2\pi}{a}}
\exp\left(-\frac{y^2}{2a}\right),
\qquad a>0
\tag{11}
```

を用いる．
式 (10) では，

```math
a=\frac{\beta\hbar^2}{m},
\qquad y=x-x'
```

に対応する．
したがって，

```math
\begin{aligned}
K_\infty(x,x')
&=\frac1{2\pi}
\sqrt{\frac{2\pi m}{\beta\hbar^2}}
\exp\left[
-\frac{m(x-x')^2}{2\beta\hbar^2}
\right]\\
&=\boxed{
\left(\frac{m}{2\pi\beta\hbar^2}\right)^{1/2}
\exp\left[
-\frac{m(x-x')^2}{2\beta\hbar^2}
\right]
}
\end{aligned}
\tag{12}
```

を得る．

$y,z$ 方向についても同じ計算ができる．
式 (7) に式 (12) の結果を代入し，三つの因子を掛け合わせると，

```math
\begin{aligned}
\langle\boldsymbol r|\rho|\boldsymbol r'\rangle
&=\left(\frac{m}{2\pi\beta\hbar^2}\right)^{3/2}\\
&\quad\times
\exp\left[
-\frac{m}{2\beta\hbar^2}
\left\{(x-x')^2+(y-y')^2+(z-z')^2\right\}
\right].
\end{aligned}
```

ここで，

```math
|\boldsymbol r-\boldsymbol r'|^2
=(x-x')^2+(y-y')^2+(z-z')^2
```

を用いると，求める座標表示は

```math
\boxed{
\displaystyle
\lim_{L\to\infty}
\langle\boldsymbol r|\rho|\boldsymbol r'\rangle
=
\left(\frac{m}{2\pi\beta\hbar^2}\right)^{3/2}
\exp\left[
-\frac{m|\boldsymbol r-\boldsymbol r'|^2}
{2\beta\hbar^2}
\right]
}
\tag{13}
```

となる．
これが自由粒子の密度演算子 $\rho=e^{-\beta\mathcal H}$ の座標表示である．

### 補足：結果の意味と規格化について

式 (13) は， $\boldsymbol r$ と $\boldsymbol r'$ の距離が大きくなるほど，座標表示の値が Gaussian 型に減少することを示している．
指数部から，減衰の長さの尺度は

```math
\ell_\beta=\hbar\sqrt{\frac{\beta}{m}}
=\frac{\hbar}{\sqrt{mk_{\mathrm B}T}}
```

であることが分かる．
したがって，温度が低いほど $\beta$ が大きくなって減衰の長さは大きくなり，温度が高いほど減衰は速くなる．
また，質量 $m$ が大きいほど減衰の長さは小さくなる．

なお，式 (13) は，問題で指定された非規格化の演算子 $\rho=e^{-\beta\mathcal H}$ の結果である．
有限体積では，通常の規格化された熱平衡密度演算子は

```math
\rho_{\mathrm{norm}}
=\frac{e^{-\beta\mathcal H}}{Z},
\qquad
Z=\operatorname{Tr}(e^{-\beta\mathcal H})
```

で定義される．
一方， $L\to\infty$ では空間体積が無限大となり，非規格化の演算子のトレースも発散する．
それでも，式 (13) のように，座標表示の核そのものは有限な極限をもつのである．
