# 演習問題【6-B-24】

## 解答

### 1. 分配関数の計算

古典的な調和振動子 1 個のハミルトニアン $H(p, q)$ は，次のように書ける．

$$H(p, q) = \frac{p^2}{2m} + \frac{1}{2} m \omega^2 q^2$$

ここで， $p$ は運動量， $q$ は座標， $m$ は質量， $\omega$ は角振動数である．

古典的な 1 個の調和振動子の分配関数 $Z_1$ は，位相空間の積分として次のように定義される．

$$Z_1 = \frac{1}{h} \iint e^{-\beta H(p, q)} \, dp \, dq$$

ここで， $h$ はプランク定数であり，位相空間の体積を無次元化するために用いられる．
$\beta = 1/(k_B T)$ は逆温度である．

積分を実行すると，

$$Z_1 = \frac{1}{h} \int_{-\infty}^{\infty} e^{-\frac{\beta p^2}{2m}} \, dp \int_{-\infty}^{\infty} e^{-\frac{\beta m \omega^2 q^2}{2}} \, dq$$

ガウス積分の公式 $\int_{-\infty}^{\infty} e^{-ax^2} \, dx = \sqrt{\frac{\pi}{a}}$ を用いると，

$$Z_1 = \frac{1}{h} \sqrt{\frac{2\pi m}{\beta}} \sqrt{\frac{2\pi}{\beta m \omega^2}} = \frac{1}{h} \frac{2\pi}{\beta \omega}$$

$\hbar = h / (2\pi)$ を用いると，

$$Z_1 = \frac{1}{\beta \hbar \omega}$$

となる．

次に， $N$ 個の独立で区別可能な古典的調和振動子から成る系の分配関数 $Z_N$ は， $Z_1$ の $N$ 乗で与えられる．

$$Z_N = (Z_1)^N = (\beta \hbar \omega)^{-N} \quad \cdots (1)$$

### 2. 状態密度の計算

状態密度 $\Omega(E)$ は，分配関数 $Z(\beta)$ の逆ラプラス変換として次のように求められる．

$$\Omega(E) = \frac{1}{2\pi i} \int_{\beta' - i\infty}^{\beta' + i\infty} e^{\beta E} Z(\beta) \, d\beta \quad (\Re \beta' > 0)$$

式 (1) を代入すると，

$$\Omega(E) = \frac{1}{2\pi i} \int_{\beta' - i\infty}^{\beta' + i\infty} e^{\beta E} (\beta \hbar \omega)^{-N} \, d\beta$$

ここで， $z = \beta \hbar \omega$ と変数変換を行う．
すると $d\beta = dz / (\hbar \omega)$ であり，積分路も同様に $z$ 平面上の直線となる．

$$\Omega(E) = \frac{1}{2\pi i} \int_{z' - i\infty}^{z' + i\infty} e^{(zE/(\hbar \omega))} z^{-N} \frac{dz}{\hbar \omega} = \frac{1}{\hbar \omega} \frac{1}{2\pi i} \int_{z' - i\infty}^{z' + i\infty} e^{z (E/\hbar \omega)} z^{-N} \, dz$$

ここで，ガンマ関数 $\Gamma(n)$ と複素積分との関係式 $\frac{1}{2\pi i} \int_{c-i\infty}^{c+i\infty} e^{zt} z^{-n} \, dz = \frac{t^{n-1}}{\Gamma(n)}$ を用いると（これは $t > 0, n > 0$ のとき成立する），

$$\Omega(E) = \frac{1}{\hbar \omega} \frac{(E/\hbar \omega)^{N-1}}{\Gamma(N)} = \frac{1}{\hbar \omega} \left( \frac{E}{\hbar \omega} \right)^{N-1} \frac{1}{\Gamma(N)} \quad \cdots (2)$$

が得られる．

### 3. 鞍点法による漸近近似

式 (2) の積分 $\phi(x) = \frac{1}{2\pi i} \int e^{zx} z^{-N} \, dz$ （ただし $x = E/\hbar \omega$ ）の漸近形を鞍点法で求める．
被積分関数を $\exp(f(z))$ の形で書くと，

$$f(z) = zx - N \log z$$

である．
$N, x \gg 1$ のとき，積分は $f(z)$ が極大値（あるいは鞍点）をとる点 $z^*$ の近傍に集中する．
鞍点 $z^*$ は $f'(z^*) = 0$ を満たすため，

$$\frac{d}{dz}(zx - N \log z) \Big|_{z=z^*} = x - \frac{N}{z^*} = 0 \quad \implies \quad z^* = \frac{N}{x}$$

となる．
鞍点近似によれば， $\log \phi(x) \sim f(z^*)$ であるから，

$$\log \phi(x) \sim z^* x - N \log z^* = \left(\frac{N}{x}\right)x - N \log\left(\frac{N}{x}\right) = N - N(\log N - \log x) = N - N \log N + N \log x$$

したがって，

$$\log \phi(x) \sim N - N \log N + N \log x \quad \cdots (3)$$

を得る．
これを式 (2) の $\Omega(E)$ に適用すると，

$$\log \Omega(E) = \log \left( \frac{1}{\hbar \omega} \right) + \log \phi(x) \sim -\log(\hbar \omega) + N - N \log N + N \log (E/\hbar \omega)$$
$$= N \log \frac{E}{\hbar \omega} + N - N \log N \quad \cdots (4)$$

となる．

### 4. Stirling の公式の導出

式 (2) より，

$$\log \Omega(E) = -\log(\hbar \omega) + (N-1) \log \left( \frac{E}{\hbar \omega} \right) - \log \Gamma(N)$$

$$= -\log(\hbar \omega) + (N-1) \log E - (N-1) \log(\hbar \omega) - \log \Gamma(N)$$

$$= (N-1) \log E - N \log(\hbar \omega) - \log \Gamma(N)$$

これと式 (4) を比較する．
両辺において $N$ に関する主要な項（ $E$ に依存しない項）を比較すると，

$$- N \log(\hbar \omega) - \log \Gamma(N) \sim - N \log(\hbar \omega) + N - N \log N$$

よって，

$$-\log \Gamma(N) \sim N - N \log N \quad \implies \quad \log \Gamma(N) \sim N \log N - N \quad \cdots (5)$$

が得られる．
$\Gamma(N+1) = N!$ であり， $N \gg 1$ のとき $\log(N+1)! \approx \log(N!) + \log N \approx \log(N!)$ であることを用いると，

$$\log (N!) \sim N \log N - N \quad \cdots (6)$$

となり，Stirling の公式が導かれた．

## 解説

本問題では，古典的な調和振動子系から状態密度を求め，その漸近形を鞍点法を用いて導出することで，Stirling の公式を再構成している．

### 1. 分配関数と状態密度の関係

分配関数 $Z(\beta)$ は系のエネルギーに関するラプラス変換であり，その逆変換として状態密度 $\Omega(E)$ が得られる．
これは統計力学における基本的な対応関係である．

### 2. 鞍点法 (Saddle Point Method)

積分路上の特定の点（鞍点）の近傍で被積分関数が急激に変化する場合，その点のみを評価することで積分値を近似する手法である．
これは $N \to \infty$ の極限（熱力学的極限）において非常に強力な道具となる．

### 3. Stirling の公式

ガンマ関数の対数に関する漸近展開 $\log \Gamma(N) \approx N \log N - N$ は，大量の粒子数 $N$ を扱う統計力学において，エントロピーの計算などに不可欠な公式である．
本解法は，物理的な系（調和振動子）の性質からこの数学的な公式を自然に導いている．
