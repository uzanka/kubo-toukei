# 演習問題【6-B-24】

## 解答

### 古典的調和振動子の状態密度と Stirling の公式

#### 1．古典的調和振動子の分配関数

角振動数 $\omega$ の古典的調和振動子1個の Hamiltonian は，

```math
H(p,q)=\frac{p^2}{2m}+\frac12m\omega^2q^2
```

である．
ここで， $p$ は運動量， $q$ は座標， $m$ は質量である．

古典的な分配関数は，位相空間全体にわたる Boltzmann 因子の積分として，

```math
Z_1=\frac1h\iint e^{-\beta H(p,q)}\,dp\,dq
```

と定義される．
ここで， $\beta=1/(kT)$ ， $k$ は Boltzmann 定数， $h$ は Planck 定数である．

運動量と座標の積分を分離すると，

```math
Z_1=\frac1h
\int_{-\infty}^{\infty}e^{-\beta p^2/(2m)}\,dp
\int_{-\infty}^{\infty}e^{-\beta m\omega^2q^2/2}\,dq
```

となる．ガウス積分

```math
\int_{-\infty}^{\infty}e^{-ax^2}\,dx
=\sqrt{\frac{\pi}{a}}
\qquad(a>0)
```

を用いると，

```math
\begin{aligned}
Z_1
&=\frac1h
\sqrt{\frac{2\pi m}{\beta}}
\sqrt{\frac{2\pi}{\beta m\omega^2}}\\[4pt]
&=\frac{2\pi}{\beta h\omega}
=\frac1{\beta\hbar\omega}
\end{aligned}
```

を得る．
ここで $\hbar=h/(2\pi)$ は換算 Planck 定数である．

次に，互いに独立な調和振動子 $N$ 個から成る系を考える．
各振動子の分配関数は独立に掛け合わせられるため，

```math
Z_N=(Z_1)^N
```

である．
したがって，

```math
\boxed{
Z_N(\beta)=(\beta\hbar\omega)^{-N}
}
\tag{1}
```

となる．

#### 2．逆ラプラス変換による状態密度の導出

状態密度 $\Omega(E)$ を，エネルギーが $E$ から $E+dE$ の範囲にある状態数が $\Omega(E)dE$ となる関数として定義する．
分配関数と状態密度の関係は，

```math
Z_N(\beta)=\int_0^\infty\Omega(E)e^{-\beta E}\,dE
```

である．
したがって，逆ラプラス変換の公式により，

```math
\Omega(E)=\frac1{2\pi i}
\int_{\beta'-i\infty}^{\beta'+i\infty}
e^{\beta E}Z_N(\beta)\,d\beta
\qquad(\beta'>0)
```

と表せる．
式(1)を代入すると，

```math
\Omega(E)=
\frac1{2\pi i}
\int_{\beta'-i\infty}^{\beta'+i\infty}
e^{\beta E}(\beta\hbar\omega)^{-N}\,d\beta
\tag{2}
```

となる．

ここで，

```math
z=\beta\hbar\omega,\qquad
x=\frac{E}{\hbar\omega}
```

と変数変換する．
このとき，

```math
d\beta=\frac{dz}{\hbar\omega}
```

であるから，式(2)は

```math
\Omega(E)=\frac1{\hbar\omega}
\frac1{2\pi i}
\int_{z'-i\infty}^{z'+i\infty}
e^{zx}z^{-N}\,dz
\tag{3}
```

となる．
ただし $z'>0$ である．

まず $E>0$ ，すなわち $x>0$ とする．
$N$ は正の整数なので，積分路を左側に閉じると，原点 $z=0$ は $N$ 位の極となる．
Cauchy の積分公式から，

```math
\begin{aligned}
\frac1{2\pi i}
\int e^{zx}z^{-N}\,dz
&=\frac1{(N-1)!}
\left.\frac{d^{N-1}}{dz^{N-1}}e^{zx}\right|_{z=0}\\[4pt]
&=\frac{x^{N-1}}{(N-1)!}
\end{aligned}
```

を得る．
ここで，閉曲線上の積分は，半円部分の積分が無限遠で消えることを用いて元の積分に等しいとした．
また， $\Gamma(N)=(N-1)!$ であるから，

```math
\boxed{
\Omega(E)=
\frac1{\hbar\omega}
\frac{(E/\hbar\omega)^{N-1}}{\Gamma(N)}
\qquad(E>0)
}
\tag{4}
```

となる．

一方，古典的調和振動子のエネルギーは非負であるため， $E<0$ では状態が存在せず，

```math
\Omega(E)=0\qquad(E<0)
```

である．
問題では $N\gg1$ を考えているので， $E\to0^+$ で式(4)もゼロに近づく．
よって，この場合には $\Omega(0)=0$ とできる．

#### 3．鞍点法による状態密度の漸近形

式(3)の積分を

```math
\phi_N(x)=\frac1{2\pi i}
\int_{z'-i\infty}^{z'+i\infty}
e^{zx}z^{-N}\,dz
```

とおく．
すると，

```math
\Omega(E)=\frac1{\hbar\omega}\phi_N(x)
```

である．
$N\gg1$ のとき，この積分を鞍点法で評価する．

被積分関数を指数関数としてまとめると，

```math
\phi_N(x)=\frac1{2\pi i}
\int \exp\{f(z)\}\,dz
```

ただし，

```math
f(z)=zx-N\log z
\tag{5}
```

である．
積分路は複素平面上の垂直直線であり，鞍点を通るように選ぶことができる．
鞍点 $z_*$ は，

```math
f'(z_*)=0
```

を満たす点である．
式(5)を微分すると，

```math
f'(z)=x-\frac Nz
```

となるため，

```math
\boxed{
z_*=\frac Nx
}
\tag{6}
```

を得る．
$x>0$ なので，この鞍点は正の実軸上にある．

鞍点での指数関数の値は，

```math
\begin{aligned}
f(z_*)
&=z_*x-N\log z_*\\
&=N-N\log\left(\frac Nx\right)\\
&=N-N\log N+N\log x
\end{aligned}
\tag{7}
```

である．

ただし，鞍点での指数関数の値だけで積分を近似すると，前置因子が失われる．
通常の Stirling の公式を得るためには，鞍点近傍で $f(z)$ を2次まで展開する必要がある．

積分路を鞍点 $z_*=N/x$ を通る垂直直線に選び，

```math
z=z_*+it
```

とおく．
このとき，

```math
f''(z)=\frac{N}{z^2},
\qquad
f''(z_*)=\frac{x^2}{N}
```

である．
鞍点の近傍では，

```math
f(z)\simeq f(z_*)+\frac12f''(z_*)(it)^2
=f(z_*)-\frac{x^2t^2}{2N}
\tag{8}
```

となる．
ここで $f'(z_*)=0$ のため，一次の項は消えている．

式(8)を積分に代入すると，

```math
\begin{aligned}
\phi_N(x)
&\simeq\frac1{2\pi}
e^{f(z_*)}
\int_{-\infty}^{\infty}
\exp\left(-\frac{x^2t^2}{2N}\right)\,dt\\[4pt]
&=\frac1{2\pi}e^{f(z_*)}
\frac{\sqrt{2\pi N}}{x}\\[4pt]
&=\frac{\sqrt N}{\sqrt{2\pi}\,x}
e^{f(z_*)}
\end{aligned}
\tag{9}
```

を得る．
第2行では，ガウス積分の公式を用いた．
$x>0$ なので，平方根の分母は $x$ である．

式(7)を式(9)に代入すると，

```math
\begin{aligned}
\phi_N(x)
&\simeq
\frac{\sqrt N}{\sqrt{2\pi}\,x}
\exp\{N-N\log N+N\log x\}\\[4pt]
&=\frac{e^N x^{N-1}}
{\sqrt{2\pi}\,N^{N-1/2}}
\end{aligned}
\tag{10}
```

となる．
したがって，状態密度の漸近形は，

```math
\boxed{
\Omega(E)\simeq
\frac1{\hbar\omega}
\frac{e^N(E/\hbar\omega)^{N-1}}
{\sqrt{2\pi}\,N^{N-1/2}}
}
\tag{11}
```

である．

#### 4．Stirling の公式の導出

式(4)から得られる厳密な積分結果は，

```math
\phi_N(x)=\frac{x^{N-1}}{\Gamma(N)}
\tag{12}
```

である．
一方，鞍点法による漸近形は式(10)である．
両者を比較すると，

```math
\frac{x^{N-1}}{\Gamma(N)}
\simeq
\frac{e^Nx^{N-1}}
{\sqrt{2\pi}\,N^{N-1/2}}
```

となる．
$x>0$ であるから $x^{N-1}$ を約分でき，

```math
\boxed{
\Gamma(N)\simeq
\sqrt{2\pi}\,N^{N-1/2}e^{-N}
}
\tag{13}
```

を得る．
これがガンマ関数に対する Stirling の漸近公式である．

正の整数 \(N\) に対して，

```math
\Gamma(N+1)=N\Gamma(N)=N!
```

である．
したがって，

```math
\begin{aligned}
N!
&=N\Gamma(N)\\
&\simeq N\sqrt{2\pi}\,N^{N-1/2}e^{-N}\\
&=\sqrt{2\pi N}\,N^Ne^{-N}
\end{aligned}
```

となる．
よって，

```math
\boxed{
N!\simeq\sqrt{2\pi N}\left(\frac Ne\right)^N
}
\tag{14}
```

が導かれた．

両辺の対数を取れば，

```math
\boxed{
\log(N!)
\simeq N\log N-N+\frac12\log(2\pi N)
}
\tag{15}
```

である．
特に， $N$ に比例する主要項のみを残す近似では，

```math
\boxed{
\log(N!)\sim N\log N-N
}
\tag{16}
```

となる．
これは解答例で示された Stirling の公式の主要項に一致する．
