# 演習問題【6-A-6】

## 解答

### 1．一般的なビリアル定理の導出

#### 1.1 カノニカル分布における平均値

自由度 $3N$ の体系を考え，そのハミルトニアンを $\mathcal H$ ，一般化座標を $q_1,\ldots,q_{3N}$ とする．
座標 $q_j$ に対応する力 $X_j$ は，

```math
X_j=-\frac{\partial\mathcal H}{\partial q_j}
\tag{1}
```

と定義される．

温度 $T$ の熱平衡状態において，カノニカル分布に従う物理量 $A$ の平均値は，

```math
\overline A
=\frac{1}{Z}\int A e^{-\beta\mathcal H}\,d\Gamma
\tag{2}
```

と表される．
ここで，

```math
\beta=\frac{1}{kT},\qquad
Z=\int e^{-\beta\mathcal H}\,d\Gamma
```

であり， $k$ はボルツマン定数， $Z$ は分配関数， $d\Gamma$ は位置と運動量からなる位相空間の体積要素である．

#### 1.2 部分積分による恒等式の導出

座標 $q_i$ と $q_j$ に対して，積の微分を行うと，

```math
\frac{\partial}{\partial q_j}
\left(q_i e^{-\beta\mathcal H}\right)
=
\delta_{ij}e^{-\beta\mathcal H}
-\beta q_i\frac{\partial\mathcal H}{\partial q_j}
e^{-\beta\mathcal H}
\tag{3}
```

となる．
ここで， $\delta_{ij}$ はクロネッカーのデルタであり， $i=j$ ならば $1$ ， $i\ne j$ ならば $0$ である．

式 (3) を位相空間全体で積分する．
積分の境界で $q_i e^{-\beta\mathcal H}$ が消えると仮定すると，部分積分により左辺の積分はゼロとなる．
したがって，

```math
0=\delta_{ij}Z
-\beta\int q_i\frac{\partial\mathcal H}{\partial q_j}
e^{-\beta\mathcal H}\,d\Gamma
```

を得る．
両辺を $Z$ で割り，平均値の定義式 (2) を用いれば，

```math
\delta_{ij}
=\beta\overline{q_i\frac{\partial\mathcal H}{\partial q_j}}
```

となる．
よって，

```math
\boxed{
\overline{q_i\frac{\partial\mathcal H}{\partial q_j}}
=kT\delta_{ij}
}
\tag{4}
```

が得られる．
これはカノニカル分布における座標と力の関係を表す基本的な恒等式である．

#### 1.3 ビリアル定理

式 (1) より，

```math
\overline{q_jX_j}
=-\overline{q_j\frac{\partial\mathcal H}{\partial q_j}}
```

である．
式 (4) に $i=j$ を代入すると，

```math
\overline{q_j\frac{\partial\mathcal H}{\partial q_j}}
=kT
```

となる．
したがって，

```math
\overline{q_jX_j}=-kT
```

である．
これを $j=1,\ldots,3N$ について足し合わせると，

```math
\begin{aligned}
\overline{\sum_{j=1}^{3N}q_jX_j}
&=\sum_{j=1}^{3N}\overline{q_jX_j}\\
&=-\sum_{j=1}^{3N}kT\\
&=-3NkT
\end{aligned}
```

を得る．
ゆえに，

```math
\boxed{
\overline{\sum_{j=1}^{3N}q_jX_j}=-3NkT
}
\tag{5}
```

が示された．
これをビリアル定理とよぶ．

なお，部分積分の境界項が消えるという仮定は重要である．
容器の壁がある場合には，壁の力を含めて考える必要があり，以下ではその寄与を圧力で表す．

### 2．圧力を用いたビリアル定理

#### 2.1 分子間相互作用と壁の力への分解

次に，分子間の相互作用ポテンシャルエネルギーを

```math
U=U(q_1,\ldots,q_{3N})
```

とし，質量をもつ分子 $N$ 個からなる気体が体積 $V$ の容器内にある場合を考える．

各分子に働く力には，分子間相互作用による力と，容器の壁から受ける力がある．
壁から受ける力の $q_j$ 方向の成分を $F_j$ とすると，

```math
X_j=-\frac{\partial U}{\partial q_j}+F_j
\tag{6}
```

と書ける．

式 (6) を式 (5) に代入すると，

```math
\begin{aligned}
-3NkT
&=\overline{\sum_{j=1}^{3N}q_jX_j}\\
&=-\overline{\sum_{j=1}^{3N}
q_j\frac{\partial U}{\partial q_j}}
+\overline{\sum_{j=1}^{3N}q_jF_j}
\end{aligned}
\tag{7}
```

となる．
以下では，右辺第2項の壁の力による寄与を求める．

#### 2.2 壁の力と圧力の関係

分子 $s$ の位置ベクトルを $\mathbf r_s$ ，壁がその分子に及ぼす力を $\mathbf F_s$ とする．
一般化座標 $q_1,\ldots,q_{3N}$ を各分子の位置ベクトルの直交成分に対応させると，

```math
\sum_{j=1}^{3N}q_jF_j
=\sum_{s=1}^{N}\mathbf r_s\cdot\mathbf F_s
\tag{8}
```

である．

ここで，容器の表面を $S$ ，容器の外向き単位法線ベクトルを $\mathbf n$ とする．
気体が壁に及ぼす力は，圧力 $p$ により，面積要素 $dA$ に対して

```math
p\mathbf n\,dA
```

と表される．
作用・反作用の法則により，壁が気体に及ぼす力は，

```math
-p\mathbf n\,dA
```

である．
したがって，平衡状態における壁の力の平均的な寄与は，

```math
\overline{\sum_{s=1}^{N}\mathbf r_s\cdot\mathbf F_s}
=\oint_S\mathbf r\cdot(-p\mathbf n)\,dA
\tag{9}
```

と表せる．
ここで， $p$ は容器の壁における平衡圧力である．

圧力が容器表面で一様であるとし，ガウスの発散定理を用いると，

```math
\begin{aligned}
\oint_S\mathbf r\cdot(-p\mathbf n)\,dA
&=-p\oint_S\mathbf r\cdot\mathbf n\,dA\\
&=-p\int_V\nabla\cdot\mathbf r\,dV
\end{aligned}
\tag{10}
```

となる．
位置ベクトルを $\mathbf r=(x,y,z)$ とすると，

```math
\nabla\cdot\mathbf r
=\frac{\partial x}{\partial x}
+\frac{\partial y}{\partial y}
+\frac{\partial z}{\partial z}
=3
\tag{11}
```

である．
よって，

```math
\begin{aligned}
\overline{\sum_{s=1}^{N}\mathbf r_s\cdot\mathbf F_s}
&=-p\int_V3\,dV\\
&=-3pV
\end{aligned}
```

を得る．
式 (8) より，

```math
\boxed{
\overline{\sum_{j=1}^{3N}q_jF_j}=-3pV
}
\tag{12}
```

である．

#### 2.3 圧力に関するビリアル定理

式 (12) を式 (7) に代入すると，

```math
-3NkT
=-\overline{\sum_{j=1}^{3N}q_j
\frac{\partial U}{\partial q_j}}
-3pV
```

となる．
両辺に $-1$ を掛けて整理すれば，

```math
3NkT
=\overline{\sum_{j=1}^{3N}q_j
\frac{\partial U}{\partial q_j}}
+3pV
```

である．
したがって，

```math
3pV
=3NkT-\overline{\sum_{j=1}^{3N}q_j
\frac{\partial U}{\partial q_j}}
```

となり，両辺を $3$ で割ると，

```math
\boxed{
pV=NkT-\frac13
\overline{\sum_{j=1}^{3N}q_j
\frac{\partial U}{\partial q_j}}
}
```

が得られる．
これが求める圧力に関するビリアル定理である．
