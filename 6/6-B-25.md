# 演習問題【6-B-25】

## 解答

### 二つの剛体双極子の間にはたらく平均力

#### 1．双極子間の相互作用エネルギー

二つの剛体双極子のモーメントをそれぞれ $\boldsymbol m$ ， $\boldsymbol m'$ とし，その大きさを $m$ ， $m'$ とする．
二つの中心を結ぶベクトルを $\boldsymbol R$ ，その大きさを $R=|\boldsymbol R|$ とする．

以下では，解答例と同じく CGS（ガウス）単位系を用いる．
この単位系では，双極子間の相互作用エネルギー $\Phi$ は

```math
\Phi
=-\boldsymbol m\cdot
\frac{3\boldsymbol R\boldsymbol R-R^2\boldsymbol 1}{R^5}
\cdot\boldsymbol m'
\tag{1}
```

で与えられる．
ここで， $\boldsymbol 1$ は単位テンソルであり， $\boldsymbol R\boldsymbol R$ はベクトル $\boldsymbol R$ の dyadic 積である．

二つの双極子の向きを，中心を結ぶ方向を基準とする球座標で表す．
それぞれの極角を $\theta,\theta'$ ，方位角を $\varphi,\varphi'$ とすれば，式(1)は

```math
\Phi=-\frac{mm'}{R^3}
\left[
2\cos\theta\cos\theta'
-\sin\theta\sin\theta'\cos(\varphi-\varphi')
\right]
\tag{2}
```

となる．

以下では，この相互作用エネルギーを用いて，温度 $T$ における平均力を求める．

#### 2．配向に関する分配関数の高温展開

熱平衡にある双極子の向きは，Boltzmann 因子 $\exp(-\Phi/kT)$ によって重み付けされる．
そこで，配向に関する分配関数を

```math
Z(R,T)=\int d\omega\int d\omega'\,
e^{-\Phi/(kT)}
\tag{3}
```

と定義する．
ここで，

```math
d\omega=\sin\theta\,d\theta\,d\varphi,
\qquad
d\omega'=\sin\theta'\,d\theta'\,d\varphi'
```

はそれぞれの双極子の立体角要素である．
双極子の回転運動の運動量に関する積分は，相互作用エネルギーに依存しない因子を与えるため，平均力の計算では省略できる．

高温条件は，

```math
\left|\frac{mm'}{kTR^3}\right|\ll1
```

である．
そこで，

```math
\lambda=\frac{mm'}{kTR^3}
```

および

```math
A=2\cos\theta\cos\theta'
-\sin\theta\sin\theta'\cos(\varphi-\varphi')
```

とおくと，式(2)より $\Phi/(kT)=-\lambda A$ となる．
したがって，

```math
e^{-\Phi/(kT)}
=e^{\lambda A}
=1+\lambda A+\frac{\lambda^2A^2}{2}
+O(\lambda^3)
\tag{4}
```

である．

まず，定数項の積分は

```math
\int d\omega\int d\omega'=(4\pi)^2
```

となる．
一方，向きが等方的に分布しているときには，双極子の方向を逆転させる操作によって $A$ の符号が反転し，積分領域と積分測度は変わらない．
したがって，

```math
\int d\omega\int d\omega'\,A=0
\tag{5}
```

であり，1次の項は消える．
同じ対称性から，奇数次の項の積分もすべてゼロとなる．
よって，最初の非零の補正は2次の項である．

次に， $A^2$ の平均を求める．
規格化した等方的な角度平均を $\langle\cdot\rangle_0$ と表すと，二つの向きは独立なので，

```math
\langle\cos^2\theta\rangle_0
=\langle\cos^2\theta'\rangle_0
=\frac13
```

および

```math
\langle\sin^2\theta\rangle_0
=\langle\sin^2\theta'\rangle_0
=\frac23
```

である．
さらに，方位角が一様に分布するため，

```math
\langle\cos(\varphi-\varphi')\rangle_0=0,
\qquad
\langle\cos^2(\varphi-\varphi')\rangle_0=\frac12
```

となる．

式(2)の $A$ を2乗すると，

```math
\begin{aligned}
A^2={}&4\cos^2\theta\cos^2\theta'\\
&-4\cos\theta\cos\theta'
\sin\theta\sin\theta'\cos(\varphi-\varphi')\\
&+\sin^2\theta\sin^2\theta'
\cos^2(\varphi-\varphi')
\end{aligned}
```

である．
交差項は方位角平均によって消えるので，

```math
\begin{aligned}
\langle A^2\rangle_0
&=4\left(\frac13\right)^2
+\left(\frac23\right)^2\frac12\\
&=\frac49+\frac29\\
&=\frac23
\end{aligned}
\tag{6}
```

を得る．
したがって，

```math
\int d\omega\int d\omega'\,A^2
=(4\pi)^2\frac23
\tag{7}
```

である．

これらを式(4)に代入すると，

```math
\begin{aligned}
Z(R,T)
&=(4\pi)^2
\left[1+\frac{\lambda^2}{2}\langle A^2\rangle_0
+O(\lambda^4)\right]\\
&=(4\pi)^2
\left[1+\frac{\lambda^2}{3}+O(\lambda^4)\right]
\end{aligned}
```

となる．
すなわち，

```math
\boxed{
Z(R,T)=(4\pi)^2
\left[
1+\frac{m^2m'^2}{3k^2T^2R^6}
+O\left(\frac{m^4m'^4}{k^4T^4R^{12}}\right)
\right]
}
\tag{8}
```

を得る．

#### 3．平均力の導出

二つの双極子の中心間距離を $R$ とし，距離が増加する方向を正とする動径方向の力を $F_R$ とする．
ある配向における力は

```math
F_R=-\frac{\partial\Phi}{\partial R}
```

である．
熱平衡における平均力は，この力を Boltzmann 因子で重み付けした平均である．
したがって，

```math
\overline{F_R}
=-\frac{1}{Z}
\int d\omega\int d\omega'\,
\frac{\partial\Phi}{\partial R}
e^{-\Phi/(kT)}
\tag{9}
```

と書ける．

一方，式(3)を $R$ で微分すると，

```math
\frac{\partial Z}{\partial R}
=-\frac{1}{kT}
\int d\omega\int d\omega'\,
\frac{\partial\Phi}{\partial R}
e^{-\Phi/(kT)}
```

となる．
よって式(9)から，

```math
\boxed{
\overline{F_R}
=kT\frac{\partial\log Z}{\partial R}
}
\tag{10}
```

を得る．
この式は，配向の自由度を熱平衡平均した後の平均力を，分配関数から求める関係である．

式(8)を用い，高温近似で $\log(1+x)\simeq x$ を適用すると，

```math
\log Z
=\log(4\pi)^2
+\frac{m^2m'^2}{3k^2T^2R^6}
+O\left(\frac{m^4m'^4}{k^4T^4R^{12}}\right)
```

となる．
これを $R$ で微分すれば，

```math
\frac{\partial\log Z}{\partial R}
=-\frac{2m^2m'^2}{k^2T^2R^7}
+O\left(\frac{m^4m'^4}{k^4T^4R^{13}}\right)
```

である．
したがって，式(10)より，

```math
\boxed{
\overline{F_R}
=-\frac{2m^2m'^2}{kTR^7}
}
\tag{11}
```

を得る．
ここでは高温展開の最初の非零の項までを残した．

距離が増加する方向を正としたため，式(11)の負号は，引力がはたらくことを意味する．
ベクトル形式では，

```math
\boxed{
\overline{\boldsymbol F}
=-\frac{2m^2m'^2}{kTR^7}
\,\hat{\boldsymbol R}
}
```

である．
ここで $\hat{\boldsymbol R}=\boldsymbol R/R$ は二つの中心を結ぶ方向の単位ベクトルであり， $\boldsymbol R$ の向きをどちらの中心からどちらの中心へ取るかに応じて，力の作用対象に対応する符号を定める．

以上より，高温において，二つの剛体双極子の間には，距離の7乗に反比例する引力がはたらく．
この熱平衡平均によって現れる引力は Keesom の力と呼ばれる．
