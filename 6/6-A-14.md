# 演習問題【6-A-14】

## 解答

### 1．成立条件

求める関係式は，巨視的な一成分系に対して，熱力学極限で成立する関係式である．
有限粒子数の系について厳密に成立する恒等式ではない．

以下では，系が安定な熱力学系であり，相互作用が短距離的で，加法性が成立すると仮定する．
このとき，境界の寄与は体積に比例するバルクの寄与に比べて無視できるため，熱力学極限におけるHelmholtz自由エネルギー $F$ は示量性を持つ．

すなわち，温度 $T$ を一定にして粒子数 $N$ と体積 $V$ を同じ倍率で変化させると，

```math
F(T,xN,xV)=xF(T,N,V)
```

となる．
以下では，この熱力学極限におけるバルクの自由エネルギーを $F$ と表す．

### 2．Helmholtz自由エネルギーの示量性

一成分系では，比体積

```math
v=\frac{V}{N}
```

を用いることができる．
示量性より，Helmholtz自由エネルギーは

```math
F(T,V,N)=Nf(T,v)
```

と表せる．
ここで， $f(T,v)$ は一粒子あたりの自由エネルギーである．

この式を，温度を一定に保って粒子数 $N$ で偏微分する．
$V$ が一定であることから，

```math
\left(\frac{\partial v}{\partial N}\right)_{V}
=-\frac{V}{N^2}
=-\frac{v}{N}
```

である．
したがって，

```math
\begin{aligned}
\left(\frac{\partial F}{\partial N}\right)_{V,T}
&=f(T,v)
+N\left(\frac{\partial f}{\partial v}\right)_T
\left(\frac{\partial v}{\partial N}\right)_V\\
&=f(T,v)-v\left(\frac{\partial f}{\partial v}\right)_T
\end{aligned}
\tag{1}
```

を得る．

同様に，粒子数 $N$ を一定にして体積 $V$ で偏微分すると，

```math
\left(\frac{\partial v}{\partial V}\right)_N
=\frac{1}{N}
```

であるため，

```math
\begin{aligned}
\left(\frac{\partial F}{\partial V}\right)_{N,T}
&=N\left(\frac{\partial f}{\partial v}\right)_T
\left(\frac{\partial v}{\partial V}\right)_N\\
&=\left(\frac{\partial f}{\partial v}\right)_T
\end{aligned}
\tag{2}
```

となる．

式（1），（2）を用いると，

```math
\begin{aligned}
&N\left(\frac{\partial F}{\partial N}\right)_{V,T}
+V\left(\frac{\partial F}{\partial V}\right)_{N,T}\\
&=N\left[
f-v\left(\frac{\partial f}{\partial v}\right)_T
\right]
+V\left(\frac{\partial f}{\partial v}\right)_T\\
&=Nf-(Nv-V)\left(\frac{\partial f}{\partial v}\right)_T\\
&=Nf\\
&=F
\end{aligned}
```

を得る．
ここで $Nv=V$ を用いた．
したがって，

```math
\boxed{
N\left(\frac{\partial F}{\partial N}\right)_{V,T}
+V\left(\frac{\partial F}{\partial V}\right)_{N,T}
=F
}
\tag{3}
```

が成立する．

### 3．分配関数の関係式の導出

カノニカル集団の分配関数 $Z(N,V,T)$ とHelmholtz自由エネルギー $F$ の関係は，

```math
F=-kT\ln Z
\tag{4}
```

である．
したがって，

```math
\ln Z=-\frac{F}{kT}
```

となる．

温度 $T$ は一定であるから，

```math
\begin{aligned}
&N\left(\frac{\partial\ln Z}{\partial N}\right)_{V,T}
+V\left(\frac{\partial\ln Z}{\partial V}\right)_{N,T}\\
&=-\frac{1}{kT}
\left[
N\left(\frac{\partial F}{\partial N}\right)_{V,T}
+V\left(\frac{\partial F}{\partial V}\right)_{N,T}
\right].
\end{aligned}
```

式（3）を代入すると，

```math
\begin{aligned}
&N\left(\frac{\partial\ln Z}{\partial N}\right)_{V,T}
+V\left(\frac{\partial\ln Z}{\partial V}\right)_{N,T}\\
&=-\frac{F}{kT}\\
&=\ln Z
\end{aligned}
```

となる．
よって，求める関係式は，

```math
\boxed{
N\left(\frac{\partial\ln Z}{\partial N}\right)_{V,T}
+V\left(\frac{\partial\ln Z}{\partial V}\right)_{N,T}
=\ln Z
}
```

である．

### 4．熱力学的関係との整合性

化学ポテンシャルと圧力は，

```math
\mu=\left(\frac{\partial F}{\partial N}\right)_{V,T},
\qquad
p=-\left(\frac{\partial F}{\partial V}\right)_{N,T}
```

で定義される．
これらを式（3）に代入すると，

```math
N\mu-pV=F
```

となる．
したがって，

```math
\boxed{F+pV=N\mu}
```

を得る．
これは一成分系の示量的な熱力学関係であり，上で導いた結果と整合している．

### 5．有限系についての注意

上の関係式は，熱力学極限における示量的な部分について成立する．
有限系の分配関数では，境界効果や有限粒子数による補正が残るため，一般には厳密な恒等式ではない．

例えば，単原子古典理想気体の分配関数は，

```math
Z(N,V,T)=\frac{V^N}{N!\Lambda^{3N}}
```

である．
ここで，

```math
\Lambda=\frac{h}{\sqrt{2\pi mkT}}
```

は熱的ド・ブロイ波長である．
このとき，

```math
\frac{Z(xN,xV,T)}{[Z(N,V,T)]^x}
=
\frac{x^{xN}(N!)^x}{(xN)!}
```

となり，一般には1ではない．
したがって，有限系に対して

```math
Z(xN,xV,T)=[Z(N,V,T)]^x
```

とすることはできない．

一方，Stirling近似を用いると，

```math
\begin{aligned}
\ln Z
&=N\ln\left(\frac{V}{\Lambda^3}\right)-\ln N!\\
&\simeq
N\left[
\ln\left(\frac{V}{N\Lambda^3}\right)+1
\right]
-\frac12\ln(2\pi N)
\end{aligned}
```

となる．
右辺の第1項は $N,V$ に関して一次同次であり，第2項は示量的な主項に比べて小さい有限粒子数補正である．

以上より，問題の関係式は，通常の巨視的な一成分系において，有限サイズの補正を無視できる熱力学極限で成立する．
