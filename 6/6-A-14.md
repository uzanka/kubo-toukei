# 演習問題【6-A-14】

## 解答

### 1．分配関数の示量性を用いた導出

#### 1.1 独立な系を複数個集めた場合

温度 $T$ において，粒子数 $N$ ，体積 $V$ の一成分系のカノニカル分配関数を $Z(N,V,T)$ とする．

まず，同じ系を $x$ 個集めた合成系を考える．
各系は同じ温度 $T$ に保たれ，互いに独立であり，系どうしの相互作用や境界の影響は無視できるものとする．

独立な系を組み合わせたとき，全系の分配関数は，それぞれの系の分配関数の積となる．
したがって，合成系の分配関数は，

```math
Z_{\mathrm{total}}=[Z(N,V,T)]^x
```

である．
合成系の粒子数は $xN$ ，体積は $xV$ であるため，

```math
\boxed{
Z(xN,xV,T)=[Z(N,V,T)]^x
}
\tag{1}
```

と書ける．
この関係は，巨視的な系に対して境界効果を無視した場合の示量性を表すものである．

式 (1) の両辺の自然対数をとると，

```math
\log Z(xN,xV,T)=x\log Z(N,V,T)
\tag{2}
```

となる．

#### 1.2 両辺を $x$ で微分する

式 (2) の両辺を $x$ で微分する．
左辺では， $N'=xN$ ， $V'=xV$ とおくと，連鎖律より，

```math
\begin{aligned}
\frac{d}{dx}\log Z(xN,xV,T)
={}&
\left(\frac{\partial\log Z}{\partial N'}\right)_{V',T}
\frac{dN'}{dx}\\
&+
\left(\frac{\partial\log Z}{\partial V'}\right)_{N',T}
\frac{dV'}{dx}
\end{aligned}
```

となる．
ここで，

```math
\frac{dN'}{dx}=N,\qquad
\frac{dV'}{dx}=V
```

であるから，

```math
\begin{aligned}
\frac{d}{dx}\log Z(xN,xV,T)
={}&
N\left(\frac{\partial\log Z}{\partial N'}\right)_{V',T}\\
&+
V\left(\frac{\partial\log Z}{\partial V'}\right)_{N',T}
\end{aligned}
\tag{3}
```

を得る．

一方，式 (2) の右辺を微分すると，

```math
\frac{d}{dx}
\left[x\log Z(N,V,T)\right]
=\log Z(N,V,T)
\tag{4}
```

となる．

式 (3)，(4) を等置すると，

```math
\begin{aligned}
&N\left(\frac{\partial\log Z}{\partial N'}\right)_{V',T}
+V\left(\frac{\partial\log Z}{\partial V'}\right)_{N',T}\\
&\qquad=\log Z(N,V,T)
\end{aligned}
```

である．
ここで $x=1$ とすると， $N'=N$ ， $V'=V$ となる．
したがって，

```math
\boxed{
N\left(\frac{\partial\log Z}{\partial N}\right)_{V,T}
+V\left(\frac{\partial\log Z}{\partial V}\right)_{N,T}
=\log Z
}
```

が得られる．
これが求める関係式である．

この式は， $\log Z$ が粒子数 $N$ と体積 $V$ に関して示量性をもつことを表している．
すなわち，粒子数と体積を同じ倍率で増加させると， $\log Z$ も同じ倍率で増加するのである．

### 2．Helmholtz の自由エネルギーを用いた別解

カノニカル集団の Helmholtz の自由エネルギー $F$ は，

```math
F=-kT\log Z
\tag{5}
```

と定義される．
したがって，

```math
\log Z=-\frac{F}{kT}
```

である．
これを先に示した関係式に代入し，温度 $T$ を一定に保つと，

```math
\begin{aligned}
&N\frac{\partial}{\partial N}
\left(-\frac{F}{kT}\right)_{V,T}
+V\frac{\partial}{\partial V}
\left(-\frac{F}{kT}\right)_{N,T}
=-\frac{F}{kT}
\end{aligned}
```

となる．
両辺に $-kT$ を掛けると，

```math
\boxed{
N\left(\frac{\partial F}{\partial N}\right)_{V,T}
+V\left(\frac{\partial F}{\partial V}\right)_{N,T}
=F
}
\tag{6}
```

を得る．

ここで，圧力 $p$ と化学ポテンシャル $\mu$ は，それぞれ，

```math
p=-\left(\frac{\partial F}{\partial V}\right)_{N,T},
\qquad
\mu=\left(\frac{\partial F}{\partial N}\right)_{V,T}
```

で定義される．
これらを式 (6) に代入すると，

```math
N\mu-pV=F
```

となる．
よって，

```math
\boxed{F+pV=N\mu}
\tag{7}
```

を得る．
これは，一成分系に対して成り立つ熱力学的な関係である．

式 (7) は，自由エネルギーが示量性をもつことと整合している．
したがって，分配関数から得られる問題の関係式は，巨視的な熱力学の関係とも一致することが確認できる．
