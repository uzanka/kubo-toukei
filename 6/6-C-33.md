# 演習問題【6-C-33】

## 解答

### 密度行列の古典極限と古典的分配関数

#### 1．密度行列の位置表示

$N$ 個の区別可能な粒子からなる系を考える．
ハミルトニアンは

```math
\mathcal H
=\sum_{i=1}^{N}\frac{\mathbf p_i^2}{2m}
+V(\mathbf r_1,\ldots,\mathbf r_N)
\tag{1}
```

で与えられる．
ここで， $\mathbf r_i$ と $\mathbf p_i$ は第 $i$ 粒子の位置と運動量であり， $V$ は位置のみに依存するポテンシャルエネルギーである．
以下では，ポテンシャルが十分滑らかで，古典的分配関数の積分が収束する場合を考える．

逆温度を

```math
\beta=\frac{1}{kT}
```

とする．
密度演算子 $e^{-\beta\mathcal H}$ の位置表示は，前問の結果より，

```math
\begin{aligned}
K(\mathbf r',\mathbf r'')
&=\langle \mathbf r'|e^{-\beta\mathcal H}|\mathbf r''\rangle\\
&=\exp\left[
-\beta\left\{
\sum_{i=1}^{N}
\frac{1}{2m}
\left(\frac{\hbar}{i}\nabla_i'\right)^2
+V(\mathbf r')
\right\}
\right]\delta(\mathbf r'-\mathbf r'')
\end{aligned}
\tag{2}
```

と書ける．
ここで，

```math
\mathbf r'=(\mathbf r_1',\ldots,\mathbf r_N'),
\qquad
\mathbf r''=(\mathbf r_1'',\ldots,\mathbf r_N'')
```

であり，

```math
\delta(\mathbf r'-\mathbf r'')
=\prod_{i=1}^{N}\delta^{(3)}(\mathbf r_i'-\mathbf r_i'')
```

である．
また， $\nabla_i'$ は $\mathbf r_i'$ に関する勾配である．
式(2)では，指数演算子全体が右側のデルタ関数に作用する．

#### 2．デルタ関数を平面波で展開する

まず，粒子が辺の長さ $L$ の立方体の箱にあり，周期境界条件を満たすとする．
$3N$ 次元の配置空間における平面波は，

```math
\psi_{\mathbf k}(\mathbf r)
=L^{-3N/2}
\exp\left(i\sum_{j=1}^{N}\mathbf k_j\cdot\mathbf r_j\right)
\tag{3}
```

で与えられる．
ここで，各波数ベクトルの成分は

```math
k_{jx},k_{jy},k_{jz}
=\frac{2\pi}{L}\times\text{整数}
```

である．
これらの平面波は完全な直交系をなすため，デルタ関数は

```math
\begin{aligned}
\delta(\mathbf r'-\mathbf r'')
={}&L^{-3N}
\sum_{\mathbf k_1,\ldots,\mathbf k_N}
\exp\left[
i\sum_{j=1}^{N}
\mathbf k_j\cdot(\mathbf r_j'-\mathbf r_j'')
\right]
\end{aligned}
\tag{4}
```

と表される．

箱の体積を無限大にする極限では，波数の和を積分に置き換えられる．
その結果，

```math
\boxed{
\delta(\mathbf r'-\mathbf r'')
=\frac{1}{(2\pi)^{3N}}
\int d\mathbf k_1\cdots d\mathbf k_N
\exp\left[
i\sum_{j=1}^{N}
\mathbf k_j\cdot(\mathbf r_j'-\mathbf r_j'')
\right]
}
\tag{5}
```

となる．

#### 3．変位公式によって運動量積分に変換する

位置表示の運動量演算子を

```math
\hat{\mathbf p}_i'
=\frac{\hbar}{i}\nabla_i'
```

とする．
平面波については，

```math
\hat{\mathbf p}_i'
e^{i\mathbf k_i\cdot\mathbf r_i'}f(\mathbf r')
=
e^{i\mathbf k_i\cdot\mathbf r_i'}
(\hbar\mathbf k_i+\hat{\mathbf p}_i')f(\mathbf r')
\tag{6}
```

が成立する．
これは，微分演算子を平面波の右側へ移す変位公式である．

重要なのは，この公式を指数演算子全体に適用することである．
運動エネルギー演算子と $V(\mathbf r')$ は一般に可換ではないため，指数関数を両者の積に分けることはできない．
しかし，平面波による共役変換を行えば，

```math
\begin{aligned}
&\exp\left[
-\beta\left\{
\sum_i\frac{(\hat{\mathbf p}_i')^2}{2m}
+V(\mathbf r')
\right\}
\right]
e^{i\sum_j\mathbf k_j\cdot\mathbf r_j'}\\
&\quad=
e^{i\sum_j\mathbf k_j\cdot\mathbf r_j'}
\exp\left[
-\beta\left\{
\sum_i\frac{(\hbar\mathbf k_i+\hat{\mathbf p}_i')^2}{2m}
+V(\mathbf r')
\right\}
\right]\mathbf 1
\end{aligned}
\tag{7}
```

となる．
ここで， $\mathbf 1$ は定数関数 $1$ であり，右辺の微分演算子を作用させる対象である．
式(7)は，運動エネルギーとポテンシャルを別々に指数関数へ分解したものではない．

式(5)を式(2)に代入し，式(7)を用いると，

```math
\begin{aligned}
K(\mathbf r',\mathbf r'')
={}&\frac{1}{(2\pi)^{3N}}
\int d\mathbf k_1\cdots d\mathbf k_N\,
e^{i\sum_j\mathbf k_j\cdot(\mathbf r_j'-\mathbf r_j'')}\\
&\times
\left[
\exp\left(
-\beta\left\{
\sum_i\frac{(\hbar\mathbf k_i+\hat{\mathbf p}_i')^2}{2m}
+V(\mathbf r')
\right\}
\right)\mathbf 1
\right]
\end{aligned}
\tag{8}
```

を得る．

ここで，積分変数を

```math
\mathbf p_i=\hbar\mathbf k_i
```

と置き換える．
このとき，

```math
d\mathbf k_1\cdots d\mathbf k_N
=\frac{d\mathbf p_1\cdots d\mathbf p_N}{\hbar^{3N}}
```

である．
また，Planck 定数 $h=2\pi\hbar$ を用いると，

```math
\frac{1}{(2\pi)^{3N}\hbar^{3N}}=\frac{1}{h^{3N}}
```

となる．
よって，密度行列の位置表示は，

```math
\boxed{
\begin{aligned}
K(\mathbf r',\mathbf r'')
={}&\frac{1}{h^{3N}}
\int d\mathbf p_1\cdots d\mathbf p_N\,
e^{\frac{i}{\hbar}\sum_j\mathbf p_j\cdot(\mathbf r_j'-\mathbf r_j'')}\\
&\times
\left[
\exp\left(
-\beta\left\{
\sum_i\frac{(\mathbf p_i+\hat{\mathbf p}_i')^2}{2m}
+V(\mathbf r')
\right\}
\right)\mathbf 1
\right]
\end{aligned}
}
\tag{9}
```

となる．
ここで $\hat{\mathbf p}_i'=(\hbar/i)\nabla_i'$ は微分演算子であり， $\mathbf p_i$ は通常の積分変数である．

#### 4．トレースを取り，古典極限を考える

分配関数は密度行列のトレースで定義される．
位置表示では，

```math
Z=\operatorname{Tr}(e^{-\beta\mathcal H})
=\int d\mathbf r_1\cdots d\mathbf r_N\,
K(\mathbf r,\mathbf r)
\tag{10}
```

である．
ここでは $\mathbf r'=\mathbf r''=\mathbf r$ とおくため，式(9)の位相因子は

```math
\exp\left[
\frac{i}{\hbar}
\sum_j\mathbf p_j\cdot(\mathbf r_j'-\mathbf r_j'')
\right]=1
```

となる．
したがって，

```math
\begin{aligned}
Z
={}&\frac{1}{h^{3N}}
\int d\mathbf r_1\cdots d\mathbf r_N
\int d\mathbf p_1\cdots d\mathbf p_N\\
&\times
\left[
\exp\left(
-\beta\left\{
\sum_i\frac{(\mathbf p_i+\hat{\mathbf p}_i')^2}{2m}
+V(\mathbf r')
\right\}
\right)\mathbf 1
\right]_{\mathbf r'=\mathbf r}
\end{aligned}
\tag{11}
```

を得る．

ここで古典極限を考える．
運動量演算子は

```math
\hat{\mathbf p}_i'=-i\hbar\nabla_i'
```

であり， $\hbar\to0$ では微分演算子に伴う項が半古典補正となる．
より具体的には，

```math
(\mathbf p_i+\hat{\mathbf p}_i')^2
=\mathbf p_i^2
+2\mathbf p_i\cdot\hat{\mathbf p}_i'
+(\hat{\mathbf p}_i')^2
```

であり，右辺の第2項は $\hbar$ の1次，第3項は $\hbar$ の2次の項である．
ポテンシャルが十分滑らかであるとき，このような微分項による補正を無視した先頭の半古典項では，

```math
\begin{aligned}
&\left[
\exp\left(
-\beta\left\{
\sum_i\frac{(\mathbf p_i+\hat{\mathbf p}_i')^2}{2m}
+V(\mathbf r')
\right\}
\right)\mathbf 1
\right]_{\mathbf r'=\mathbf r}\\
&\qquad\sim
\exp\left[
-\beta\left\{
\sum_i\frac{\mathbf p_i^2}{2m}
+V(\mathbf r)
\right\}
\right]
\end{aligned}
\tag{12}
```

となる．
これは， $\hbar\to0$ で，演算子の指数関数の先頭の半古典項が，古典的な Hamiltonian の Boltzmann 因子に一致することを意味する．

式(12)を式(11)に代入すると，

```math
\begin{aligned}
Z
&\sim\frac{1}{h^{3N}}
\int d\mathbf r_1\cdots d\mathbf r_N
\int d\mathbf p_1\cdots d\mathbf p_N\\
&\qquad\times
\exp\left[
-\beta\left\{
\sum_i\frac{\mathbf p_i^2}{2m}
+V(\mathbf r_1,\ldots,\mathbf r_N)
\right\}
\right]
\end{aligned}
```

となる．
したがって，先頭の半古典項は

```math
\boxed{
Z_{\mathrm{cl}}
=\frac{1}{h^{3N}}
\int d\mathbf p_1\cdots d\mathbf p_N\,
d\mathbf r_1\cdots d\mathbf r_N\,
\exp\left[
-\beta\mathcal H(\mathbf p_1,\ldots,\mathbf r_N)
\right]
}
\tag{13}
```

で与えられる．
これが問題で示すべき古典的分配関数である．
粒子は区別可能であるため，式(13)には $1/N!$ の因子は含まれない．

なお，式(13)は，量子分配関数の半古典展開における先頭項を表す．
$h=2\pi\hbar$ も同時にゼロへ近づける場合，位相空間積分の係数 $h^{-3N}$ 自体は発散するため，式(13)との「一致」は，通常の分配関数の規格化を保持したうえでの先頭半古典項の一致という意味である．
