# 演習問題【6-B-16】

## 解答

### 1．ポテンシャルの安定性と準平衡状態

ポテンシャルは

```math
V(q)=cq^2-gq^3-fq^4
```

である．
ただし， $c,g,f>0$ とする．

まず，このポテンシャルの安定性を確認する．

```math
\lim_{|q|\to\infty}V(q)=-\infty
```

であるため，元のポテンシャルは下に有界ではない．
したがって，通常の正準配置積分

```math
z_q=\int_{-\infty}^{\infty}
e^{-V(q)/(kT)}\,dq
```

は発散する．
実際，

```math
e^{-V(q)/(kT)}
\sim e^{fq^4/(kT)}
\longrightarrow\infty
```

なので，

```math
\boxed{z_q=\infty}
```

である．

したがって，元のポテンシャルを全実数領域で扱う場合，正規化可能な正準分布は存在せず，厳密な平衡熱容量および平均座標は定義できない．

一方， $q=0$ は

```math
V'(0)=0,\qquad V''(0)=2c>0
```

を満たす局所安定点である．
そこで，以下ではこの局所安定点の周囲に形成される準安定井戸に限定して摂動計算を行う．

ポテンシャルの停留点は

```math
V'(q)=q(2c-3gq-4fq^2)=0
```

より，

```math
q=0,\qquad
q_\pm=\frac{-3g\pm\sqrt{9g^2+32fc}}{8f}
```

である．
$q_-<0<q_+$ は局所最大点であり， $q=0$ を挟む局所安定井戸の境界となる．

そこで，準平衡状態の配置積分を

```math
\boxed{
z_{\mathrm{well}}
=\int_{q_-}^{q_+}
e^{-V(q)/(kT)}\,dq
}
\tag{1}
```

と定義する．
これは元の全実数領域の配置積分ではなく，局所安定井戸に限定した配置積分である．
物理的には，井戸から脱出する前の準平衡状態，または井戸の外への移動を禁止した系に対応する．

以下の摂動計算では，この準平衡分配関数を用いる．

### 2．摂動パラメータと分配関数の展開

調和振動子の熱的な典型変位を

```math
q_T=\sqrt{\frac{kT}{c}}
```

とおく．
さらに，

```math
\varepsilon_g=\frac{g\sqrt{kT}}{c^{3/2}},
\qquad
\varepsilon_f=\frac{fkT}{c^2}
```

と定義する．
問題文の条件は

```math
\varepsilon_g\ll1,\qquad
\varepsilon_f\ll1
```

に対応する．

無次元変数

```math
x=\frac{q}{q_T}
```

を用いると，

```math
\frac{V(q)}{kT}
=x^2-\varepsilon_gx^3-\varepsilon_fx^4
```

となる．

停留点 $q_\pm$ に対応する $x_\pm=q_\pm/q_T$ は

```math
2=3\varepsilon_gx_\pm+4\varepsilon_fx_\pm^2
```

を満たす．
$\varepsilon_g,\varepsilon_f\ll1$ では，両境界は熱的な典型変位より十分遠くにある．
実際，停留点での障壁高さは

```math
\frac{V(q_\pm)}{kT}
=\frac{x_\pm^2+\varepsilon_fx_\pm^4}{3}
\gg1
```

である．
したがって，局所安定井戸の境界付近の寄与は指数関数的に小さく，べき級数の摂動計算では積分範囲を $(-\infty,\infty)$ に拡張しても，代数的な摂動次数には影響しない．

よって，

```math
z_{\mathrm{well}}
\simeq
\int_{-\infty}^{\infty}
e^{-cq^2/(kT)}
e^{(gq^3+fq^4)/(kT)}\,dq
```

として，熱的に重要な領域で指数関数を展開する．

```math
\begin{aligned}
e^{(gq^3+fq^4)/(kT)}
={}&1+\frac{gq^3}{kT}
+\frac{fq^4}{kT}\\
&+\frac{g^2q^6}{2(kT)^2}
+\cdots
\end{aligned}
```

配置積分は $q\to-q$ の対称性により $g$ の奇数次の寄与をもたない．
$O(f)$ および $O(g^2)$ まで残すと，

```math
\begin{aligned}
z_{\mathrm{well}}
\simeq{}&
\int_{-\infty}^{\infty}
e^{-cq^2/(kT)}
\left[
1+\frac{fq^4}{kT}
+\frac{g^2q^6}{2(kT)^2}
\right]dq .
\end{aligned}
\tag{2}
```

ガウス積分

```math
\int_{-\infty}^{\infty}e^{-aq^2}\,dq
=\sqrt{\frac{\pi}{a}},
```

```math
\int_{-\infty}^{\infty}q^4e^{-aq^2}\,dq
=\frac{3}{4a^2}\sqrt{\frac{\pi}{a}},
```

```math
\int_{-\infty}^{\infty}q^6e^{-aq^2}\,dq
=\frac{15}{8a^3}\sqrt{\frac{\pi}{a}}
```

を用いると，

```math
\begin{aligned}
z_{\mathrm{well}}
\simeq{}&
\sqrt{\frac{\pi kT}{c}}
\left[
1+\frac34\frac{fkT}{c^2}
+\frac{15}{16}\frac{g^2kT}{c^3}
\right].
\end{aligned}
```

したがって，

```math
\boxed{
z_{\mathrm{well}}
\simeq
\sqrt{\frac{\pi kT}{c}}
\left[
1+\frac34
\left(
\frac{f}{c^2}
+\frac54\frac{g^2}{c^3}
\right)kT
\right]
}
\tag{3}
```

である．
ここでは $O(f)$ ， $O(g^2)$ までを保持し， $O(f^2)$ ， $O(fg^2)$ ， $O(g^4)$ などを省略した．

### 3．内部エネルギーと熱容量

運動量の分配関数は

```math
z_p=\int_{-\infty}^{\infty}
e^{-p^2/(2mkT)}\,dp
=\sqrt{2\pi mkT}
```

である．
したがって，運動エネルギーの平均値と熱容量への寄与は

```math
u_p=\frac12kT,\qquad C_p=\frac12k
```

となる．

一方，準平衡井戸における平均ポテンシャルエネルギーは

```math
u_q=kT^2\frac{\partial\ln z_{\mathrm{well}}}{\partial T}
\tag{4}
```

で与えられる．
ここで，微分は $c,g,f$ および井戸の境界 $q_\pm$ を固定して行う．

式(3)の対数をとり，補正項の二次以上を省略すると，

```math
\begin{aligned}
\ln z_{\mathrm{well}}
\simeq{}&
\frac12\ln\frac{\pi kT}{c}\\
&+\frac34
\left(
\frac{f}{c^2}
+\frac54\frac{g^2}{c^3}
\right)kT .
\end{aligned}
\tag{5}
```

これを式(4)に代入すると，

```math
\boxed{
u_q\simeq
\frac12kT+
\frac34
\left(
\frac{f}{c^2}
+\frac54\frac{g^2}{c^3}
\right)(kT)^2
}
\tag{6}
```

を得る．

配置の熱容量への寄与は

```math
C_q=\frac{\partial u_q}{\partial T}
```

であるから，

```math
\boxed{
C_q\simeq
\frac{k}{2}
+\frac32
\left(
\frac{f}{c^2}
+\frac54\frac{g^2}{c^3}
\right)k^2T
}
\tag{7}
```

となる．

運動エネルギーの寄与 $C_p=k/2$ を加えると，1次元振動子全体の熱容量は

```math
\boxed{
C_{\mathrm{total}}
\simeq
k+
\frac32
\left(
\frac{f}{c^2}
+\frac54\frac{g^2}{c^3}
\right)k^2T
}
\tag{8}
```

である．

### 4．座標 $q$ の平均値

準平衡井戸における座標の平均値は

```math
\overline q_{\mathrm{well}}
=
\frac{
\displaystyle\int_{q_-}^{q_+}
q\,e^{-V(q)/(kT)}\,dq
}{
\displaystyle z_{\mathrm{well}}
}
\tag{9}
```

で定義する．

分配関数と同様に，熱的に重要な領域で摂動展開し，境界の指数関数的に小さい寄与を無視すると，

```math
\begin{aligned}
\overline q_{\mathrm{well}}
\simeq
\frac{1}{z_{\mathrm{well}}}
\int_{-\infty}^{\infty}
q e^{-cq^2/(kT)}
\left[
1+\frac{gq^3}{kT}
+\frac{fq^4}{kT}
+\frac{g^2q^6}{2(kT)^2}
+\cdots
\right]dq .
\end{aligned}
```

奇関数の項は積分するとゼロになる．
最初に残る項は

```math
\frac{gq^4}{kT}
```

である．
したがって， $O(g)$ までの精度では分母を調和振動子の配置積分で近似してよい．

```math
\begin{aligned}
\overline q_{\mathrm{well}}
&\simeq
\frac{g}{kT}
\frac{
\displaystyle\int_{-\infty}^{\infty}
q^4e^{-cq^2/(kT)}\,dq
}{
\displaystyle\int_{-\infty}^{\infty}
e^{-cq^2/(kT)}\,dq
}\\
&=
\frac{g}{kT}\frac34
\left(\frac{kT}{c}\right)^2 .
\end{aligned}
```

よって，

```math
\boxed{
\overline q_{\mathrm{well}}
\simeq
\frac34\frac{gkT}{c^2}
}
\tag{10}
```

を得る．

したがって，最低次の摂動近似では，

```math
\boxed{\overline q_{\mathrm{well}}\propto T}
```

であり，比例係数は正である．
これは，ポテンシャルの $-gq^3$ 項によって正の $q$ 側が相対的に有利になることと整合する．

### 5．最終結果と物理的な適用範囲

局所安定井戸に条件づけた準平衡状態について，求める結果は

```math
\boxed{
C_{\mathrm{total}}
\simeq
k+
\frac32
\left(
\frac{f}{c^2}
+\frac54\frac{g^2}{c^3}
\right)k^2T
}
```

および

```math
\boxed{
\overline q_{\mathrm{well}}
\simeq
\frac34\frac{gkT}{c^2}
}
```

である．

これらは

```math
\frac{g\sqrt{kT}}{c^{3/2}}\ll1,
\qquad
\frac{fkT}{c^2}\ll1
```

のもとでの，局所安定井戸に対する摂動結果である．

ただし，元のポテンシャルは下に有界でないため，全実数領域における厳密な正準平衡は存在しない．
したがって，式(8)，式(10)を元のポテンシャルの大域的な平衡物理量と解釈してはならない．
これらは，局所安定井戸からの脱出を無視できる準平衡状態に対する結果である．
