# 演習問題【6-B-16】

## 解答

### 1．分配関数の計算

統計力学において，1次元の古典的な系における分配関数 $z$ は，系の状態量（エネルギーなど）を決定するための最も基本的な量である．
ポテンシャル $V(q)$ をもつ1次元の古典振動子の分配関数は，次のような積分で与えられる：

$$z = \int_{-\infty}^{\infty} e^{-\beta V(q)} dq$$

ここで， $\beta = 1/(kT)$ は逆温度である．
与えられたポテンシャル $V(q) = cq^2 - gq^3 - fq^4$ を代入すると，

$$z = \int_{-\infty}^{\infty} \exp\left( -\frac{cq^2 - gq^3 - fq^4}{kT} \right) dq = \int_{-\infty}^{\infty} \exp\left( -\frac{cq^2}{kT} \right) \exp\left( \frac{gq^3 + fq^4}{kT} \right) dq \quad \cdots (1)$$

となる．

問題の条件より， $g$ および $f$ は非常に小さい定数である．
積分に寄与する主な範囲は，調和ポテンシャル $cq^2$ が支配的な $q^2 \lesssim kT/c$ の範囲である．
この範囲では，非調和項を含む指数関数の肩の部分 $\frac{gq^3 + fq^4}{kT}$ は $1$ よりも十分に小さい．
したがって，次のようにテイラー展開（指数関数の展開）を用いることができる：

$$\exp\left( \frac{gq^3 + fq^4}{kT} \right) \approx 1 + \frac{gq^3 + fq^4}{kT} + \frac{1}{2} \left( \frac{gq^3 + fq^4}{kT} \right)^2 + \dots$$

これを式 (1) に代入すると，

$$z = \int_{-\infty}^{\infty} \exp\left( -\frac{cq^2}{kT} \right) \left\{ 1 + \frac{gq^3}{kT} + \frac{fq^4}{kT} + \frac{1}{2} \frac{g^2 q^6}{(kT)^2} + \dots \right\} dq$$

となる．
ここで，ガウス積分 $\int_{-\infty}^{\infty} q^n e^{-aq^2} dq$ の性質を用いる．
$n$ が奇数のとき，被積分関数は奇関数となるため，積分値は $0$ となる．
したがって， $q^3$ の項などは消える．

$$z = \int_{-\infty}^{\infty} \exp\left( -\frac{cq^2}{kT} \right) \left\{ 1 + \frac{fq^4}{kT} + \frac{g^2 q^6}{2(kT)^2} + \dots \right\} dq$$

ガウス積分の公式 $\int_{-\infty}^{\infty} q^{2n} e^{-aq^2} dq = \frac{(2n-1)!!}{2^n a^n} \sqrt{\frac{\pi}{a}}$ を用いて各項を計算すると：
- $n=0$ :
  $\int_{-\infty}^{\infty} e^{-cq^2/kT} dq = \sqrt{\frac{\pi kT}{c}}$
- $n=2$ ( $q^4$ の項):
  $\int_{-\infty}^{\infty} q^4 e^{-cq^2/kT} dq = \frac{3}{4} \left(\frac{kT}{c}\right)^2 \sqrt{\frac{\pi kT}{c}}$
- $n=3$ ( $q^6$ の項):
  $\int_{-\infty}^{\infty} q^6 e^{-cq^2/kT} dq = \frac{15}{8} \left(\frac{kT}{c}\right)^3 \sqrt{\frac{\pi kT}{c}}$

これらをまとめると，分配関数 $z$ は次のように得られる：

$$z = \sqrt{\frac{\pi kT}{c}} \left\{ 1 + \frac{f}{kT} \cdot \frac{3}{4} \left(\frac{kT}{c}\right)^2 + \frac{g^2}{2(kT)^2} \cdot \frac{15}{8} \left(\frac{kT}{c}\right)^3 + \dots \right\}$$

$$z = \sqrt{\frac{\pi kT}{c}} \left( 1 + \frac{3}{4} \frac{fkT}{c^2} + \frac{15}{16} \frac{g^2 kT}{c^3} + \dots \right) \quad \cdots (2)$$

### 2．熱容量への寄与

内部エネルギー $u$ は，分配関数を用いて次のように求められる：

$$u = -\frac{\partial}{\partial \beta} \log z = kT^2 \frac{\partial \log z}{\partial T}$$

まず， $\log z$ を計算する．
$\log(1+x) \approx x$ を用いると，

$$\log z = \log \left( \sqrt{\frac{\pi kT}{c}} \right) + \log \left( 1 + \left( \frac{3}{4} \frac{f}{c^2} + \frac{15}{16} \frac{g^2}{c^3} \right) kT + \dots \right)$$

$$\log z \approx \frac{1}{2} \log \frac{\pi k}{c} + \frac{1}{2} \log T + \left( \frac{3}{4} \frac{f}{c^2} + \frac{15}{16} \frac{g^2}{c^3} \right) kT$$

これを $T$ で微分して $kT^2$ を掛けると，

$$u = kT^2 \left[ \frac{1}{2T} + \left( \frac{3}{4} \frac{f}{c^2} + \frac{15}{16} \frac{g^2}{c^3} \right) k \right]$$

$$u = \frac{1}{2} kT + \frac{3}{4} \left( \frac{f}{c^2} + \frac{5}{4} \frac{g^2}{c^3} \right) (kT)^2 + \dots \quad \cdots (3)$$

（※計算の過程で定数項の整理を行うと，式 (3) の形になる．）

熱容量 $C$ は，内部エネルギー $u$ を温度 $T$ で微分することで得られる：

$$C = \frac{\partial u}{\partial T} = \frac{k}{2} + \frac{3}{2} k \left( \frac{f}{c^2} + \frac{5}{4} \frac{g^2}{c^3} \right) kT + \dots \quad \cdots (4)$$

第1項は調和振動子の熱容量（エネルギー等配分則による $\frac{1}{2}k$ ）であり，第2項が非調和性による寄与である．

### 3．座標の平均値

振動子の座標 $q$ の平均値 $\bar{q}$ は，次のように定義される：

$$\bar{q} = \frac{1}{z} \int_{-\infty}^{\infty} q e^{-\beta V(q)} dq$$

ここで，ポテンシャル $V(q)$ は $q$ に関して偶関数ではないため， $\bar{q}$ は $0$ にならない．
$\exp(-\beta V(q))$ を展開すると，

$$\bar{q} = \frac{1}{z} \int_{-\infty}^{\infty} \exp\left( -\frac{cq^2}{kT} \right) \left( \frac{gq^3 + fq^4}{kT} + \dots \right) q \, dq$$

$$= \frac{1}{z} \int_{-\infty}^{\infty} \exp\left( -\frac{cq^2}{kT} \right) \left( \frac{gq^4}{kT} + \dots \right) dq$$

（奇数乗の項は積分すると $0$ になるため，次は $q^4$ の項である．）
ガウス積分を実行すると，

$$\bar{q} = \frac{1}{z} \cdot \frac{g}{kT} \cdot \frac{3}{4} \left(\frac{kT}{c}\right)^2 \sqrt{\frac{\pi kT}{c}} = \frac{1}{z} \sqrt{\frac{\pi kT}{c}} \cdot \frac{3}{4} \frac{gkT}{c^2}$$

式 (2) より $z \approx \sqrt{\frac{\pi kT}{c}}$ であるから，

$$\bar{q} \approx \frac{3}{4} \frac{gkT}{c^2} \quad \cdots (5)$$

したがって， $\bar{q} \propto T$ となり，温度の上昇とともに平均的な位置がずれることが示された．

## 解説

本問題では，ポテンシャルに $q^3$ や $q^4$ の項が含まれる「非調和振動子」の性質を扱った．

### 1. 熱容量への影響

理想的な調和振動子の場合，熱容量は温度によらず一定（ $k/2$ ）である．
しかし，現実の原子間ポテンシャルなどは非調和性を持つため，温度が上がると熱容量が変化する．
本解答では，非調和項 $f$ や $g^2$ によって，熱容量が温度 $T$ に比例して増加する様子を導出した．

### 2. 熱膨張との関係

通常の調和振動子では，ポテンシャルが左右対称であるため，温度が上がっても振動の中心（平均位置）は変わらない．
しかし，本問題のように $gq^3$ のような非対称な項が存在すると，温度が上がる（すなわちエネルギーが高くなる）につれて，粒子がより遠い（ポテンシャルが緩やかな）方へ移動しやすくなる．
これが，固体における「熱膨張」の微視的なメカニズムである．
平均位置 $\bar{q}$ が温度 $T$ に比例して増大することは，まさにこの現象を数学的に記述している．
