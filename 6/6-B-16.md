# 演習問題【6-B-16】

## 解答

### 1．分配関数の摂動展開

1次元の古典振動子のポテンシャルエネルギーを，

```math
V(q)=cq^2-gq^3-fq^4
```

とする．
ここで， $c,g,f$ は正の定数であり，

```math
g\ll\frac{c^{3/2}}{\sqrt{kT}},
\qquad
f\ll\frac{c^2}{kT}
```

という条件を仮定する．

なお，このポテンシャルは大きな $|q|$ に対して下に有界ではないため，以下の計算は厳密な分配関数の計算ではない．
実際には，振動子を安定化する高次項などが存在し，熱的に重要な領域では上記のポテンシャルによる摂動展開が有効であると仮定する．

まず，座標に関する配置積分を，

```math
z_q=\int_{-\infty}^{\infty}
e^{-V(q)/(kT)}\,dq
\tag{1}
```

と定義する．
式 (1) にポテンシャルを代入すると，

```math
z_q=
\int_{-\infty}^{\infty}
e^{-cq^2/(kT)}
e^{(gq^3+fq^4)/(kT)}\,dq
\tag{2}
```

となる．

非調和項が小さいので，第2の指数関数を展開する．

```math
\begin{aligned}
e^{(gq^3+fq^4)/(kT)}
={}&1+\frac{gq^3+fq^4}{kT}\\
&+\frac{(gq^3+fq^4)^2}{2(kT)^2}
+\cdots
\end{aligned}
```

所定の近似次数まで残すと，

```math
e^{(gq^3+fq^4)/(kT)}
\simeq
1+\frac{gq^3}{kT}
+\frac{fq^4}{kT}
+\frac{g^2q^6}{2(kT)^2}
+\cdots
```

となる．
ここで， $gf$ や $f^2$ を含む高次の補正項などは省略した．

これを式 (2) に代入すると，

```math
\begin{aligned}
z_q\simeq
\int_{-\infty}^{\infty}e^{-cq^2/(kT)}
\left(
1+\frac{gq^3}{kT}
+\frac{fq^4}{kT}
+\frac{g^2q^6}{2(kT)^2}
\right)dq
\end{aligned}
\tag{3}
```

となる．
積分範囲が $(-\infty,\infty)$ であるため，奇関数 $q^3e^{-cq^2/(kT)}$ の積分はゼロとなる．
したがって，

```math
\begin{aligned}
z_q\simeq
\int_{-\infty}^{\infty}e^{-cq^2/(kT)}
\left(
1+\frac{fq^4}{kT}
+\frac{g^2q^6}{2(kT)^2}
\right)dq
\end{aligned}
\tag{4}
```

を得る．

ここで，ガウス積分の公式

```math
\int_{-\infty}^{\infty}q^{2n}e^{-aq^2}\,dq
=
\frac{(2n-1)!!}{2^na^n}
\sqrt{\frac{\pi}{a}}
```

を用いる．
特に，

```math
\int_{-\infty}^{\infty}e^{-cq^2/(kT)}\,dq
=\sqrt{\frac{\pi kT}{c}}
```

```math
\int_{-\infty}^{\infty}q^4e^{-cq^2/(kT)}\,dq
=\frac34\left(\frac{kT}{c}\right)^2
\sqrt{\frac{\pi kT}{c}}
```

```math
\int_{-\infty}^{\infty}q^6e^{-cq^2/(kT)}\,dq
=\frac{15}{8}\left(\frac{kT}{c}\right)^3
\sqrt{\frac{\pi kT}{c}}
```

である．
これらを式 (4) に代入すると，

```math
\begin{aligned}
z_q
&\simeq\sqrt{\frac{\pi kT}{c}}
\left[
1+\frac34\frac{f}{kT}\left(\frac{kT}{c}\right)^2
+\frac{15}{16}\frac{g^2}{(kT)^2}
\left(\frac{kT}{c}\right)^3
\right]\\
&=\sqrt{\frac{\pi kT}{c}}
\left(
1+\frac34\frac{fkT}{c^2}
+\frac{15}{16}\frac{g^2kT}{c^3}
\right)
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
z_q\simeq\sqrt{\frac{\pi kT}{c}}
\left[
1+\frac34
\left(
\frac{f}{c^2}+\frac54\frac{g^2}{c^3}
\right)kT
\right]
}
\tag{5}
```

となる．
ここでは，省略した高次の摂動項を考慮しない近似を用いている．

### 2．内部エネルギーと熱容量への寄与

配置積分 $z_q$ から得られる平均エネルギーは，ポテンシャルエネルギーの平均値であり，

```math
u_q=kT^2\frac{\partial\log z_q}{\partial T}
\tag{6}
```

で与えられる．
これは， $V(q)$ が温度に直接依存しないことから得られる関係である．

式 (5) の対数をとる．

```math
\begin{aligned}
\log z_q
\simeq{}&
\frac12\log\frac{\pi kT}{c}\\
&+\log\left[
1+\frac34
\left(
\frac{f}{c^2}+\frac54\frac{g^2}{c^3}
\right)kT
\right]
\end{aligned}
```

ここで，補正項が小さいため， $\log(1+x)\simeq x$ を用いると，

```math
\begin{aligned}
\log z_q\simeq{}&
\frac12\log\frac{\pi kT}{c}\\
&+\frac34\left(
\frac{f}{c^2}+\frac54\frac{g^2}{c^3}
\right)kT
\end{aligned}
\tag{7}
```

となる．
これを式 (6) に代入すれば，

```math
\begin{aligned}
u_q
&\simeq kT^2
\left[
\frac{1}{2T}
+\frac34\left(
\frac{f}{c^2}+\frac54\frac{g^2}{c^3}
\right)k
\right]\\
&=\frac12kT
+\frac34\left(
\frac{f}{c^2}+\frac54\frac{g^2}{c^3}
\right)(kT)^2
\end{aligned}
```

となる．
したがって，ポテンシャルエネルギーの寄与は，

```math
\boxed{
u_q\simeq\frac12kT
+\frac34\left(
\frac{f}{c^2}+\frac54\frac{g^2}{c^3}
\right)(kT)^2
}
\tag{8}
```

である．

熱容量への配置の寄与 $C_q$ は，

```math
C_q=\frac{\partial u_q}{\partial T}
```

で定義される．
式 (8) を温度 $T$ で微分すると，

```math
\boxed{
C_q\simeq
\frac{k}{2}
+\frac32 k
\left(
\frac{f}{c^2}+\frac54\frac{g^2}{c^3}
\right)kT
}
\tag{9}
```

を得る．
第1項は調和振動子のポテンシャルエネルギーに由来する寄与であり，第2項は非調和性による補正である．

なお，ここまでの $C_q$ は配置積分から求めたポテンシャルエネルギーの寄与である．
振動子全体の熱容量を求める場合には，運動量の積分から得られる運動エネルギーの寄与 $k/2$ を加える必要がある．
したがって，1次元振動子全体の熱容量 $C_{\mathrm{total}}$ は，

```math
\boxed{
C_{\mathrm{total}}\simeq
k+\frac32 k
\left(
\frac{f}{c^2}+\frac54\frac{g^2}{c^3}
\right)kT
}
\tag{10}
```

となる．

### 3．座標 $q$ の平均値

座標 $q$ の平均値は，配置積分を用いて，

```math
\overline q
=\frac{1}{z_q}
\int_{-\infty}^{\infty}
q\,e^{-V(q)/(kT)}\,dq
\tag{11}
```

と定義される．

式 (2) と同じ摂動展開を用いると，

```math
\begin{aligned}
\overline q
\simeq\frac{1}{z_q}
\int_{-\infty}^{\infty}q\,e^{-cq^2/(kT)}
\left(
1+\frac{gq^3}{kT}
+\frac{fq^4}{kT}
+\frac{g^2q^6}{2(kT)^2}
+\cdots
\right)dq
\end{aligned}
\tag{12}
```

となる．
この被積分関数のうち， $q$ の1次の項， $fq^5$ の項， $g^2q^7$ の項は奇関数に比例するため，積分するとゼロになる．
最初に残る項は $gq^4/(kT)$ の項である．
よって，

```math
\overline q
\simeq\frac{g}{kT\,z_q}
\int_{-\infty}^{\infty}
q^4e^{-cq^2/(kT)}\,dq
```

となる．
先ほど求めたガウス積分を用いると，

```math
\overline q
\simeq
\frac{g}{kT\,z_q}
\frac34\left(\frac{kT}{c}\right)^2
\sqrt{\frac{\pi kT}{c}}
```

である．
この次数の計算では，分母の $z_q$ を調和振動子の値

```math
z_q\simeq\sqrt{\frac{\pi kT}{c}}
```

で近似してよい．
したがって，

```math
\boxed{
\overline q\simeq\frac34\frac{gkT}{c^2}
}
\tag{13}
```

を得る．
すなわち，

```math
\boxed{
\overline q\propto T
}
```

である．
これは，非対称な非調和ポテンシャルにおいて，温度の上昇に伴い粒子の平均位置が移動することを示している．
