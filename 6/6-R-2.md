# 演習問題【6-R-2】

## 解答

### 1．電場中にある分子のポテンシャルエネルギーと確率分布

大きさが一定値 $\mu$ の電気双極子モーメントを持つ分子を考える．
外部電場を $\boldsymbol{E}$ ，双極子モーメントと電場のなす角を $\theta$ とする．
電場の方向を $z$ 軸に選ぶと，分子のポテンシャルエネルギー $u$ は，双極子モーメントと電場の内積から

```math
u=-\boldsymbol{\mu}\cdot\boldsymbol{E}
=-\mu E\cos\theta
\tag{1}
```

と表される．
ここで， $E=|\boldsymbol{E}|$ である．

温度 $T$ の熱平衡状態にある系では，カノニカル分布により，エネルギーが $u$ である状態の確率密度は $e^{-u/kT}$ に比例する．
したがって，双極子モーメントの方向が立体角要素 $d\omega$ の中に存在する確率は

```math
\begin{aligned}
f(\theta)\,d\omega
&=C e^{-u/kT}\,d\omega\\
&=C\exp\left(
\frac{\mu E\cos\theta}{kT}
\right)d\omega
\end{aligned}
\tag{2}
```

となる．
ここで， $k$ はボルツマン定数， $C$ は確率の総和が $1$ になるように定める規格化定数である．
また，球面座標における立体角要素は

```math
d\omega=\sin\theta\,d\theta\,d\phi
\tag{3}
```

である．

式 (2) から， $\theta=0$ ，すなわち双極子モーメントが電場と平行な方向ではポテンシャルエネルギーが最小になるため，その方向が熱平衡状態で相対的に現れやすいことがわかる．

### 2．電場方向の双極子モーメントの平均値

電気分極を求めるため，まず双極子モーメントの電場方向の成分 $\mu\cos\theta$ の平均値を計算する．
確率密度 $f(\theta)$ を用いると，

```math
\left\langle\mu\cos\theta\right\rangle
=\int \mu\cos\theta\,f(\theta)\,d\omega
\tag{4}
```

である．
ここで，積分は双極子モーメントの全方向について行う．

式 (2) を代入すると，

```math
\left\langle\mu\cos\theta\right\rangle
=
\frac{
\displaystyle\int
\mu\cos\theta\,
e^{\mu E\cos\theta/kT}\,d\omega
}{
\displaystyle\int
e^{\mu E\cos\theta/kT}\,d\omega
}
\tag{5}
```

となる．
分母は確率の規格化に対応する積分であり，規格化定数 $C$ は分子と分母で相殺されている．

式 (3) を用いて方位角 $\phi$ について積分すると，分子と分母の両方に $2\pi$ が現れて相殺される．
したがって，

```math
\begin{aligned}
\left\langle\mu\cos\theta\right\rangle
&=\mu
\frac{
\displaystyle\int_0^\pi
\cos\theta\,
e^{\mu E\cos\theta/kT}
\sin\theta\,d\theta
}{
\displaystyle\int_0^\pi
e^{\mu E\cos\theta/kT}
\sin\theta\,d\theta
}.
\end{aligned}
\tag{6}
```

ここで，計算を簡単にするため，

```math
a=\frac{\mu E}{kT},
\qquad
\zeta=\cos\theta
\tag{7}
```

と置く．
このとき，

```math
d\zeta=-\sin\theta\,d\theta
```

であり，積分範囲は $\theta=0$ で $\zeta=1$ ， $\theta=\pi$ で $\zeta=-1$ となる．
積分の上下限を反転させることで，

```math
\left\langle\mu\cos\theta\right\rangle
=\mu
\frac{
\displaystyle\int_{-1}^{1}\zeta e^{a\zeta}\,d\zeta
}{
\displaystyle\int_{-1}^{1}e^{a\zeta}\,d\zeta
}
\tag{8}
```

を得る．

まず，分母の積分を計算する．
$a\neq0$ のとき，

```math
\begin{aligned}
\int_{-1}^{1}e^{a\zeta}\,d\zeta
&=\left[\frac{e^{a\zeta}}{a}\right]_{-1}^{1}\\
&=\frac{e^a-e^{-a}}{a}\\
&=\frac{2\sinh a}{a}.
\end{aligned}
\tag{9}
```

次に，分子の積分を計算する．
指数関数を $a$ で微分すると，

```math
\frac{\partial}{\partial a}e^{a\zeta}
=\zeta e^{a\zeta}
```

であるから，

```math
\begin{aligned}
\int_{-1}^{1}\zeta e^{a\zeta}\,d\zeta
&=\frac{d}{da}
\int_{-1}^{1}e^{a\zeta}\,d\zeta\\
&=\frac{d}{da}\left(\frac{2\sinh a}{a}\right)\\
&=2\frac{a\cosh a-\sinh a}{a^2}.
\end{aligned}
\tag{10}
```

式 (9)，(10) を式 (8) に代入すると，

```math
\begin{aligned}
\left\langle\mu\cos\theta\right\rangle
&=\mu
\frac{
2(a\cosh a-\sinh a)/a^2
}{
2\sinh a/a
}\\[4pt]
&=\mu\left(
\frac{\cosh a}{\sinh a}-\frac1a
\right)\\[4pt]
&=\mu\left(\coth a-\frac1a\right).
\end{aligned}
\tag{11}
```

ここで，関数

```math
L(a)=\coth a-\frac1a
\tag{12}
```

をランジュヴァン関数と呼ぶ．
したがって，式 (7) を戻せば，

```math
\boxed{
\left\langle\mu\cos\theta\right\rangle
=\mu L\left(\frac{\mu E}{kT}\right)
}
\tag{13}
```

となる．
なお， $a=0$ では式 (9)，(10) の途中式に $1/a$ が現れるが，積分そのものは正則である．
ランジュヴァン関数についても $L(0)=0$ と連続的に定義できる．

### 3．電気分極 $P$ の導出

電気分極 $P$ は，単位体積当たりの電気双極子モーメントのベクトル和である．
分子数が $N$ ，気体の体積が $V$ であるため，単位体積当たりの分子数は $N/V$ である．

分子の方向は熱運動によって分布しているが，外部電場の方向を軸とする回転対称性により，電場に垂直な方向の平均成分は $0$ となる．
したがって，電気分極は電場方向の平均成分だけで決まり，

```math
P=\frac NV\left\langle\mu\cos\theta\right\rangle
\tag{14}
```

で与えられる．

式 (13) を式 (14) に代入すると，

```math
P=\frac NV\mu
L\left(\frac{\mu E}{kT}\right)
```

を得る．
さらに，式 (12) のランジュヴァン関数の定義を用いれば，

```math
\boxed{
P=\frac NV\mu
\left\{
\coth\left(\frac{\mu E}{kT}\right)
-\frac{kT}{\mu E}
\right\}
}
\tag{15}
```

となる．
これで，問題文の第1式が証明された．

### 4．弱電場近似による誘電率の導出

次に，

```math
|\mu E|\ll kT
\tag{16}
```

が成り立つ場合を考える．
この条件は，式 (7) で定義した無次元量 $a$ を用いると $|a|\ll1$ と表せる．

ランジュヴァン関数を $a=0$ の周りでテイラー展開すると，

```math
L(a)=\frac a3-\frac{a^3}{45}
+O(a^5)
\tag{17}
```

となる．
したがって， $|a|\ll1$ では高次の項を無視でき，

```math
L(a)\simeq\frac a3
\tag{18}
```

と近似できる．
式 (15) に式 (18) を代入すると，

```math
\begin{aligned}
P
&\simeq\frac NV\mu\frac13
\frac{\mu E}{kT}\\[4pt]
&=\frac{N\mu^2}{3VkT}E.
\end{aligned}
\tag{19}
```

すなわち，弱電場では電気分極 $P$ は電場 $E$ に比例する．

最後に，誘電率を求める．
ここではガウス単位系を用いる．
誘導分極を無視し，電場が各分子に作用する電場に等しいとする問題の仮定の下で，電気変位 $D$ と電場 $E$ の関係は

```math
D=E+4\pi P
\tag{20}
```

である．
一方，誘電率 $\epsilon$ は

```math
D=\epsilon E
\tag{21}
```

によって定義される．
式 (19) を式 (20) に代入すると，

```math
\begin{aligned}
D
&=E+4\pi\frac{N\mu^2}{3VkT}E\\[4pt]
&=\left(
1+4\pi\frac NV\frac{\mu^2}{3kT}
\right)E.
\end{aligned}
\tag{22}
```

これを式 (21) と比較すれば，

```math
\boxed{
\epsilon=1+4\pi\frac NV\frac{\mu^2}{3kT}
}
\tag{23}
```

を得る．
これで，問題文の第2式も証明された．

### 5．物理的な意味

本問題で得られた結果は，外部電場によって永久双極子モーメントを持つ分子の向きに偏りが生じることを表している．

- **電場がない場合** ： 分子の向きは等方的に分布するため，双極子モーメントの平均値は $0$ であり，配向分極も $0$ である．
- **弱電場の場合** ： 熱運動による配向の乱れが支配的であるが，分子の向きは電場方向にわずかに偏る．その結果，分極は電場に比例し，誘電率の式 (23) が得られる．
- **強電場の場合** ： $a=\mu E/(kT)\to+\infty$ では $L(a)\to1$ となり，双極子モーメントは電場方向に強く配向する．そのため，分極は $P\to(N/V)\mu$ に近づく．

特に，式 (23) は，配向分極による誘電率の増加分が分子数密度 $N/V$ と双極子モーメントの二乗 $\mu^2$ に比例し，絶対温度 $T$ に反比例することを示している．
これは，温度が高いほど熱運動が分子の配向を乱し，温度が低いほど電場による配向が起こりやすくなるという物理的な解釈と整合する．

以上より，カノニカル分布からランジュヴァン関数を導出し，その弱電場展開を用いることで，電気分極と誘電率の両方が求められた．
