# 例題【6-R-5】

## 解答

### 1．分配関数 $Z_N(\beta)$ の導出

固有角振動数 $\omega$ をもつ，互いに独立な $N$ 個の量子調和振動子からなる系を考える．
各振動子は互いに区別される独立な自由度であるとする．

一つの量子調和振動子のエネルギー固有値は，

```math
E_n=\left(n+\frac12\right)\hbar\omega,
\qquad n=0,1,2,\ldots
```

である．
ここで， $\hbar$ は換算 Planck 定数である．
また，

```math
\beta=\frac{1}{kT}
```

とする．
ここで， $k$ は Boltzmann 定数， $T$ は絶対温度である．
分配関数が収束するため， $\beta>0$ とする．

まず，一つの振動子の分配関数 $Z_1(\beta)$ を求める．
分配関数の定義より，

```math
Z_1(\beta)
=\sum_{n=0}^{\infty}e^{-\beta E_n}
```

である．
エネルギー固有値を代入すると，

```math
\begin{aligned}
Z_1(\beta)
&=\sum_{n=0}^{\infty}
e^{-\beta(n+1/2)\hbar\omega}\\
&=e^{-\beta\hbar\omega/2}
\sum_{n=0}^{\infty}
\left(e^{-\beta\hbar\omega}\right)^n
\end{aligned}
```

となる．

ここで，等比級数の公式

```math
\sum_{n=0}^{\infty}x^n
=\frac{1}{1-x},
\qquad |x|<1
```

を用いる．
$\beta>0$ ， $\hbar\omega>0$ より，

```math
0<e^{-\beta\hbar\omega}<1
```

であるから，等比級数は収束する．
したがって，

```math
\boxed{
Z_1(\beta)
=
\frac{e^{-\beta\hbar\omega/2}}
{1-e^{-\beta\hbar\omega}}
}
```

を得る．

次に， $N$ 個の振動子は互いに独立であるため，系全体の分配関数は各振動子の分配関数の積となる．
よって，

```math
Z_N(\beta)=\left[Z_1(\beta)\right]^N
```

であるから，

```math
\boxed{
Z_N(\beta)
=
e^{-N\beta\hbar\omega/2}
\left(1-e^{-\beta\hbar\omega}\right)^{-N}
}
\tag{1}
```

を得る．

### 2．分配関数から厳密な状態数 $W(E)$ を求める

#### 2.1 分配関数の展開

式（1）を展開するため，二項級数の公式

```math
(1-x)^{-N}
=
\sum_{M=0}^{\infty}
\binom{N+M-1}{M}x^M
```

を用いる．
ここで， $N$ は正の整数であり，

```math
\binom{N+M-1}{M}
=
\frac{(N+M-1)!}{(N-1)!\,M!}
```

である．

式（1）に $x=e^{-\beta\hbar\omega}$ を代入すると，

```math
\begin{aligned}
Z_N(\beta)
&=
e^{-N\beta\hbar\omega/2}
\sum_{M=0}^{\infty}
\binom{N+M-1}{M}
e^{-M\beta\hbar\omega}\\
&=
\sum_{M=0}^{\infty}
\binom{N+M-1}{M}
e^{-\beta(M+N/2)\hbar\omega}
\end{aligned}
\tag{2}
```

となる．

一方，分配関数は，各エネルギー固有値 $E$ をもつ状態の数を $W(E)$ とすれば，

```math
Z_N(\beta)=\sum_E W(E)e^{-\beta E}
```

と表される．

式（2）と比較すると，全エネルギーは，

```math
\boxed{
E_M=\left(M+\frac N2\right)\hbar\omega,
\qquad M=0,1,2,\ldots
}
\tag{3}
```

である．
また，エネルギー $E_M$ に対応する状態数は，

```math
\boxed{
W_M=W(E_M)
=
\frac{(N+M-1)!}{(N-1)!\,M!}
}
\tag{4}
```

となる．

したがって，求める状態数は，

```math
\boxed{
W(E)=
\begin{cases}
\dfrac{(N+M-1)!}{(N-1)!\,M!},
&
E=\left(M+\dfrac N2\right)\hbar\omega,\\
0,
&
\text{それ以外}
\end{cases}
}
```

である．
ただし， $M$ は非負整数とする．

すなわち，この系の全エネルギーは離散的な値しか取らず，式（3）の形で表せないエネルギーには状態が存在しない．

#### 2.2 状態数の組合せ論的な意味

式（4）の意味を，振動子に与えられた励起量子の分配から確認する．

各振動子の励起量子数を $n_i$ とすると，全励起量子数 $M$ は，

```math
n_1+n_2+\cdots+n_N=M,
\qquad n_i=0,1,2,\ldots
```

を満たす．

したがって，求める状態数は，上式を満たす非負整数解の個数である．

これは， $M$ 個の同じ励起量子を，区別できる $N$ 個の振動子に分配する重複組合せの数に等しい．

この場合， $M$ 個の量子と $N-1$ 個の仕切りを一列に並べることを考えると，全体で $M+N-1$ 個の位置から $N-1$ 個の仕切りの位置を選べばよい．
したがって，

```math
\begin{aligned}
W_M
&=\binom{N+M-1}{N-1}\\
&=\frac{(N+M-1)!}{(N-1)!\,M!}
\end{aligned}
```

となる．
これは，式（4）と一致する．

#### 2.3 状態密度による表現

離散的なエネルギー準位に対する状態密度は，Dirac のデルタ関数を用いて，

```math
\boxed{
\Omega(E)=
\sum_{M=0}^{\infty}
W_M
\delta\left(
E-\left(M+\frac N2\right)\hbar\omega
\right)
}
\tag{5}
```

と表される．
ここで， $\delta$ は Dirac のデルタ関数である．

この状態密度を用いれば，

```math
Z_N(\beta)
=
\int_0^\infty
\Omega(E)e^{-\beta E}\,dE
```

となり，分配関数が状態密度の Laplace 変換であることが確認できる．

ただし， $\Omega(E)$ は滑らかな関数ではなく，デルタ関数の和である．
したがって，状態密度を通常の関数のように各エネルギー固有値で評価して，その値を状態数とすることはできない．

このため，以下の漸近評価では，逆 Laplace 変換の被積分関数に直接鞍点近似を適用するのではなく，分配関数の生成関数から係数を取り出す方法を用いる．

### 3．大きな $N$ に対する状態数の漸近評価

ここから， $N$ が十分に大きい場合を考える．

基底状態の全エネルギーは，

```math
E_0=\frac N2\hbar\omega
```

である．
励起エネルギーを，

```math
E'=E-E_0
\tag{6}
```

とおく．
式（3）より，許されるエネルギーでは，

```math
E'=M\hbar\omega
```

となる．

以下では，

```math
x=\frac{M}{N}
=\frac{E'}{N\hbar\omega}
\tag{7}
```

とおく．
漸近評価では，

```math
N\to\infty,\qquad M\to\infty,
\qquad \frac MN=x>0
```

を一定に保つ極限を考える．
すなわち， $M$ と $N$ がともに大きく， $M/N$ が正の有限値である場合を対象とする．

#### 3.1 生成関数の係数抽出

式（1）において，

```math
z=e^{-\beta\hbar\omega}
```

とおく．
すると，

```math
Z_N(\beta)
=
e^{-N\beta\hbar\omega/2}(1-z)^{-N}
```

である．
ここで，生成関数を，

```math
G_N(z)=(1-z)^{-N}
```

と定義する．
式（2）より，

```math
G_N(z)
=
\sum_{M=0}^{\infty}W_Mz^M
\tag{8}
```

となる．

したがって，求める状態数 $W_M$ は，生成関数 $G_N(z)$ の $z^M$ の係数である．
Cauchy の係数公式を用いると，

```math
\boxed{
W_M=
\frac{1}{2\pi i}
\oint_C
\frac{dz}{z^{M+1}(1-z)^N}
}
\tag{9}
```

を得る．
ここで，積分経路 $C$ は原点を正の向きに一周する閉曲線であり，特異点 $z=1$ を内部に含まないものとする．

この積分表示は，離散的な状態数 $W_M$ を直接与えるものである．

#### 3.2 鞍点の決定

$M/N=x>0$ を一定に保つ極限を考える．
Cauchy の積分経路として，

```math
z=re^{i\theta},
\qquad -\pi\leq\theta\leq\pi,
\qquad 0<r<1
```

という円周を選ぶ．
式（9）は，

```math
W_M
=
\frac{1}{2\pi}
\int_{-\pi}^{\pi}
\exp\{\Psi(\theta)\}\,d\theta
```

と書ける．
ただし，

```math
\Psi(\theta)
=
-N\ln(1-re^{i\theta})
-M\ln r
-iM\theta
\tag{10}
```

と定義した．

この積分の主要な寄与は， $\theta=0$ の近傍から生じるように $r$ を選ぶ．

まず，式（10）を $\theta$ で微分すると，

```math
\frac{d\Psi}{d\theta}
=
iN\frac{re^{i\theta}}{1-re^{i\theta}}
-iM
```

である．
$\theta=0$ で停留点となる条件は，

```math
\left.\frac{d\Psi}{d\theta}\right|_{\theta=0}=0
```

であるから，

```math
N\frac{r}{1-r}=M
```

となる．
これを解くと，

```math
\boxed{
r=\frac{M}{N+M}
=\frac{x}{1+x}
}
\tag{11}
```

を得る．

このとき，

```math
1-r=\frac{1}{1+x}
```

である．
また，

```math
\left.\frac{d^2\Psi}{d\theta^2}\right|_{\theta=0}
=
-\frac{Nr}{(1-r)^2}
```

となるので，

```math
\boxed{
\left.\frac{d^2\Psi}{d\theta^2}\right|_{\theta=0}
=
-Nx(1+x)<0
}
\tag{12}
```

である．
したがって， $\theta=0$ は実部が最大となる停留点である．
実際，積分の絶対値を決める因子は $|1-re^{i\theta}|^{-N}$ であり，

```math
|1-re^{i\theta}|^2
=
1+r^2-2r\cos\theta
```

は $\theta=0$ で最小となる．
よって，円周上では $\theta=0$ が主要な寄与を与える点である．

#### 3.3 鞍点近似

$\theta=0$ の近傍で，式（10）を Taylor 展開すると，

```math
\Psi(\theta)
=
\Psi(0)
-\frac12Nx(1+x)\theta^2
+O(N|\theta|^3)
```

となる．

まず，停留点における指数部の値を求める．
式（11）より，

```math
\begin{aligned}
\Psi(0)
&=-N\ln(1-r)-M\ln r\\
&=N\ln(1+x)
-M\ln\left(\frac{x}{1+x}\right)\\
&=N(1+x)\ln(1+x)-Nx\ln x
\end{aligned}
```

である．
したがって，

```math
\boxed{
\Psi(0)
=
N\left[(1+x)\ln(1+x)-x\ln x\right]
}
\tag{13}
```

となる．

積分の主要な寄与は $\theta=0$ の近傍に集中するので，指数部を二次まで残して Gauss 積分を行うと，

```math
\begin{aligned}
W_M
&\simeq
\frac{e^{\Psi(0)}}{2\pi}
\int_{-\infty}^{\infty}
\exp\left[
-\frac12Nx(1+x)\theta^2
\right]d\theta\\
&=
\frac{e^{\Psi(0)}}{2\pi}
\sqrt{\frac{2\pi}{Nx(1+x)}}
\end{aligned}
```

となる．
よって，

```math
\boxed{
W_M
\simeq
\frac{
\exp\left\{
N[(1+x)\ln(1+x)-x\ln x]
\right\}
}{
\sqrt{2\pi Nx(1+x)}
}
}
\tag{14}
```

を得る．
この式は， $N\to\infty$ で $x=M/N$ を正の有限値に保つ場合の漸近式である．
より正確には，固定された $x>0$ に対して，右辺に相対誤差 $1+O(N^{-1})$ を伴う．

両辺の対数を取ると，

```math
\boxed{
\begin{aligned}
\ln W_M
={}&N\left[(1+x)\ln(1+x)-x\ln x\right]\\
&-\frac12\ln[2\pi Nx(1+x)]
+O(N^{-1})
\end{aligned}
}
\tag{15}
```

となる．

特に，主要項だけを残せば，

```math
\boxed{
\ln W_M
\simeq
N\left[(1+x)\ln(1+x)-x\ln x\right]
}
\tag{16}
```

である．

#### 3.4 Stirling の公式による検算

上の漸近評価を，厳密な状態数に Stirling の公式を適用することによって独立に確認する．

式（4）より，

```math
\ln W_M
=
\ln(N+M-1)!
-\ln(N-1)!
-\ln M!
```

である．

ここで，Stirling の公式を，

```math
\ln n!
=
\left(n+\frac12\right)\ln n-n
+\frac12\ln(2\pi)+O(n^{-1})
```

という形で用いる．

$N$ ， $M$ ， $N+M$ がいずれも大きい場合，

```math
\boxed{
\begin{aligned}
\ln W_M
={}&(N+M)\ln(N+M)\\
&-N\ln N-M\ln M\\
&-\frac12\ln\left[
2\pi\frac{M(N+M)}{N}
\right]
+O(N^{-1})
\end{aligned}
}
```

となる．

ここで，

```math
M=Nx
```

を代入すると，

```math
\begin{aligned}
&(N+M)\ln(N+M)-N\ln N-M\ln M\\
&=N(1+x)\ln[N(1+x)]
-N\ln N-Nx\ln(Nx)\\
&=N\left[(1+x)\ln(1+x)-x\ln x\right]
\end{aligned}
```

である．
また，

```math
\frac{M(N+M)}{N}
=
Nx(1+x)
```

なので，

```math
\begin{aligned}
\ln W_M
={}&N\left[(1+x)\ln(1+x)-x\ln x\right]\\
&-\frac12\ln[2\pi Nx(1+x)]
+O(N^{-1})
\end{aligned}
```

を得る．

これは式（15）と一致する．
したがって，生成関数の係数抽出による鞍点近似は，厳密な状態数に Stirling の公式を適用した結果と整合している．

### 4．エントロピー $S(E)$ の導出

ここでは，エネルギー $E$ に対する状態数を，そのエネルギー固有値に属する状態の縮退度 $W(E)$ とする．
このとき，Boltzmann のエントロピーは，

```math
\boxed{
S(E)=k\ln W(E)
}
\tag{17}
```

で定義される．

式（16）を用いれば，

```math
S(E)
\simeq
kN\left[(1+x)\ln(1+x)-x\ln x\right]
\tag{18}
```

となる．

式（6），（7）より，

```math
x=\frac{M}{N}
=
\frac{E-N\hbar\omega/2}{N\hbar\omega}
=
\frac{E}{N\hbar\omega}-\frac12
```

である．
したがって，

```math
1+x=\frac{E}{N\hbar\omega}+\frac12
```

となる．
これらを式（18）に代入すると，

```math
\boxed{
\begin{aligned}
S(E)\simeq kN\Bigg[
&\left(\frac{E}{N\hbar\omega}+\frac12\right)
\ln\left(\frac{E}{N\hbar\omega}+\frac12\right)\\
-&\left(\frac{E}{N\hbar\omega}-\frac12\right)
\ln\left(\frac{E}{N\hbar\omega}-\frac12\right)
\Bigg]
\end{aligned}
}
\tag{19}
```

を得る．
これが大きな $N$ に対するエントロピーの主要項である．

さらに，式（15）から対数補正項まで含めると，

```math
\boxed{
\begin{aligned}
S(E)
={}&kN\left[(1+x)\ln(1+x)-x\ln x\right]\\
&-\frac{k}{2}\ln[2\pi Nx(1+x)]
+O(kN^{-1})
\end{aligned}
}
\tag{20}
```

となる．
ただし，ここでも $x>0$ を一定に保つ熱力学的極限を考えている．

#### 4.1 基底状態におけるエントロピー

基底状態では，

```math
M=0,\qquad E=E_0=\frac N2\hbar\omega
```

である．
式（4）より，

```math
W_0=
\frac{(N-1)!}{(N-1)!\,0!}=1
```

なので，

```math
\boxed{S(E_0)=k\ln1=0}
```

となる．

式（19）でも，

```math
\lim_{x\to0+}x\ln x=0
```

を用いれば，主要項の連続極限はゼロとなり，基底状態の結果と一致する．

ただし，式（14），（15），（20）のガウス近似および対数補正項は $x>0$ を一定に保つ場合の漸近式であるため， $M=0$ では適用せず，厳密な状態数 $W_0=1$ を用いる．

また，式（19）は許される離散的なエネルギーに対して適用する．
すなわち，

```math
E=\left(M+\frac N2\right)\hbar\omega,
\qquad M=0,1,2,\ldots
```

である．
この条件を満たさないエネルギーには状態が存在しない．

### 5．温度との関係による整合性の確認

得られたエントロピーが熱力学的に整合することを確認する．

熱力学的極限では，エネルギーに関するエントロピーの微分から温度を，

```math
\frac1T=
\left(\frac{\partial S}{\partial E}\right)_N
```

によって定義できる．
この関係は，大きな $N$ における連続的なエントロピーの近似に対して用いる．

式（18）と，

```math
x=\frac{E-N\hbar\omega/2}{N\hbar\omega}
```

から，

```math
\frac{dx}{dE}=\frac{1}{N\hbar\omega}
```

である．
また，

```math
\frac{d}{dx}
\left[(1+x)\ln(1+x)-x\ln x\right]
=
\ln\frac{1+x}{x}
```

なので，

```math
\frac{\partial S}{\partial E}
=
\frac{k}{\hbar\omega}
\ln\frac{1+x}{x}
```

を得る．
したがって，

```math
\boxed{
kT=
\frac{\hbar\omega}
{\ln[(1+x)/x]}
}
\tag{21}
```

となる．

この式を変形すると，

```math
\boxed{
e^{-\hbar\omega/(kT)}
=
\frac{x}{1+x}
}
\tag{22}
```

である．

一方，係数抽出の鞍点条件からは，

```math
z_*=\frac{x}{1+x}
```

を得ている．
ここで，

```math
z_*=e^{-\beta^*\hbar\omega}
```

と解釈すれば，

```math
\beta^*
=
\frac{1}{\hbar\omega}
\ln\frac{1+x}{x}
```

となる．
これは式（21）から得られる逆温度と一致する．

したがって，状態数の漸近評価から導いたエントロピーと，正準分布における鞍点条件は整合している．

また，

```math
\frac{\partial^2S}{\partial E^2}
=
-\frac{k}{N(\hbar\omega)^2x(1+x)}<0
```

であるため，エントロピーはエネルギーに対して凹関数となる．
これは熱力学的安定性とも整合する．

### 6．結論

互いに独立な $N$ 個の量子調和振動子からなる系の分配関数は，

```math
\boxed{
Z_N(\beta)
=
e^{-N\beta\hbar\omega/2}
\left(1-e^{-\beta\hbar\omega}\right)^{-N}
}
```

である．

この分配関数を二項級数で展開すると，全エネルギーは，

```math
\boxed{
E_M=\left(M+\frac N2\right)\hbar\omega
}
```

となり，その状態数は，

```math
\boxed{
W_M=
\frac{(N+M-1)!}{(N-1)!\,M!}
}
```

である．

さらに，

```math
x=\frac{E-N\hbar\omega/2}{N\hbar\omega}
```

とおき， $N\to\infty$ で $x>0$ を一定に保つと，

```math
\boxed{
\ln W(E)
\simeq
N\left[(1+x)\ln(1+x)-x\ln x\right]
}
```

を得る．

したがって，エントロピーの主要項は，

```math
\boxed{
S(E)\simeq
kN\left[(1+x)\ln(1+x)-x\ln x\right]
}
```

である．
これをエネルギー $E$ で表せば，

```math
\boxed{
\begin{aligned}
S(E)\simeq kN\Bigg[
&\left(\frac{E}{N\hbar\omega}+\frac12\right)
\ln\left(\frac{E}{N\hbar\omega}+\frac12\right)\\
-&\left(\frac{E}{N\hbar\omega}-\frac12\right)
\ln\left(\frac{E}{N\hbar\omega}-\frac12\right)
\Bigg]
\end{aligned}
}
```

となる．

以上により，分配関数からエネルギーごとの厳密な状態数を求め，生成関数の係数抽出および Stirling の公式によって大きな $N$ に対する漸近評価を行い，エントロピーの形を導出した．
