# 演習問題【6-R-5】

## 解答

固有角振動数 $\omega$ をもつ $N$ 個の独立な量子調和振動子から成る系を考える．
分配関数 $Z_N(\beta)$ から全エネルギー $E$ に対応する状態数 $W(E)$ を求め，さらに $N$ が十分に大きい場合のエントロピー $S(E)$ を導出する．
ここで，

```math
\beta=\frac{1}{kT}
```

であり， $k$ は Boltzmann 定数， $T$ は絶対温度である．

### 1．分配関数 $Z_N(\beta)$ の導出

角振動数 $\omega$ の量子調和振動子のエネルギー準位は，

```math
E_n=\left(n+\frac12\right)\hbar\omega,
\qquad n=0,1,2,\ldots
```

である．
ここで， $\hbar$ は換算 Planck 定数である．

まず，振動子一つあたりの分配関数 $Z_1(\beta)$ を求める．
分配関数は，各エネルギー準位に対する Boltzmann 因子 $e^{-\beta E_n}$ をすべて足し合わせたものであるため，

```math
\begin{aligned}
Z_1(\beta)
&=\sum_{n=0}^{\infty}e^{-\beta E_n}\\
&=\sum_{n=0}^{\infty}
e^{-\beta(n+1/2)\hbar\omega}\\
&=e^{-\beta\hbar\omega/2}
\sum_{n=0}^{\infty}
\left(e^{-\beta\hbar\omega}\right)^n
\end{aligned}
```

となる．
等比級数の公式

```math
\sum_{n=0}^{\infty}x^n=\frac{1}{1-x}
\qquad (|x|<1)
```

を用いると，

```math
Z_1(\beta)
=\frac{e^{-\beta\hbar\omega/2}}
{1-e^{-\beta\hbar\omega}}
```

を得る．

各振動子は互いに独立であるため，系全体の分配関数は一つの振動子の分配関数の $N$ 乗で与えられる．
したがって，

```math
\boxed{
Z_N(\beta)
=e^{-N\beta\hbar\omega/2}
\left(1-e^{-\beta\hbar\omega}\right)^{-N}
}
\tag{1}
```

である．

### 2．分配関数から状態数 $W(E)$ を求める

#### 2.1　分配関数の展開

式 (1) の状態数を明らかにするため，二項級数の公式

```math
(1-x)^{-N}
=\sum_{M=0}^{\infty}
\binom{N+M-1}{M}x^M
```

を用いる．
ここで，

```math
\binom{N+M-1}{M}
=\frac{(N+M-1)!}{(N-1)!\,M!}
```

である．
$x=e^{-\beta\hbar\omega}$ とおくと，

```math
\begin{aligned}
Z_N(\beta)
&=e^{-N\beta\hbar\omega/2}
\sum_{M=0}^{\infty}
\binom{N+M-1}{M}e^{-M\beta\hbar\omega}\\
&=\sum_{M=0}^{\infty}
\frac{(N+M-1)!}{(N-1)!\,M!}
e^{-\beta(M+N/2)\hbar\omega}
\end{aligned}
\tag{2}
```

となる．

一方，エネルギーが $E$ である状態の数を $W(E)$ とすると，分配関数は

```math
Z_N(\beta)=\sum_E W(E)e^{-\beta E}
```

と表される．
これは，各エネルギー $E$ に対して，そのエネルギーをもつ状態の Boltzmann 因子を $W(E)$ 個分足し合わせるという定義に基づくものである．

式 (2) と比較すると，系のエネルギーは

```math
E_M=\left(M+\frac N2\right)\hbar\omega,
\qquad M=0,1,2,\ldots
\tag{3}
```

という離散的な値を取ることが分かる．
このエネルギーに対応する状態数は，

```math
\boxed{
W_M=W(E_M)
=\frac{(N+M-1)!}{(N-1)!\,M!}
}
\tag{4}
```

である．
式 (4) が求める厳密な状態数である．
エネルギーが式 (3) の形で表されない場合，そのエネルギーをもつ状態は存在しない．

#### 2.2　状態数の組合せ論的な意味

式 (4) の意味は，振動子に与えられた励起量子の分配を数えることによって理解できる．
各振動子の励起量子数を $n_i$ とすると，系全体の励起量子数 $M$ は，

```math
n_1+n_2+\cdots+n_N=M,
\qquad n_i=0,1,2,\ldots
```

を満たす．
つまり， $M$ 個の同じ励起量子を，区別できる $N$ 個の振動子に，重複を許して分配する方法の数が $W_M$ である．
この非負整数解の個数は，

```math
W_M=\binom{N+M-1}{N-1}
=\frac{(N+M-1)!}{(N-1)!\,M!}
```

となり，式 (4) と一致する．

状態密度を Dirac のデルタ関数で表すならば，

```math
\boxed{
\Omega(E)=
\sum_{M=0}^{\infty}
W_M\,
\delta\!\left(
E-\left(M+\frac N2\right)\hbar\omega
\right)
}
\tag{5}
```

である．
ここで， $\delta$ は Dirac のデルタ関数である．
式 (5) は，エネルギー準位 $E_M$ に状態数 $W_M$ の重みがあることを表す．
離散的な準位をもつため， $\Omega(E)$ は滑らかな関数ではなくデルタ関数の和として表現される．

### 3．大きな $N$ に対する漸近評価

ここから， $N$ が十分に大きい場合を考える．
エネルギーを

```math
E'=E-\frac N2\hbar\omega
\tag{6}
```

とおく．
$E'$ は，系の基底状態のエネルギーを差し引いた励起エネルギーである．
式 (3) より，許されるエネルギーでは

```math
E'=M\hbar\omega
```

が成立する．

#### 3.1　逆 Laplace 変換と鞍点条件

分配関数と状態密度の関係は，

```math
Z_N(\beta)
=\int_0^\infty \Omega(E)e^{-\beta E}\,dE
```

である．
これを逆 Laplace 変換すると，

```math
\Omega(E)
=\frac{1}{2\pi i}
\int_{\gamma-i\infty}^{\gamma+i\infty}
Z_N(\beta)e^{\beta E}\,d\beta
```

となる．
ここで積分経路は， $\operatorname{Re}\beta=\gamma>0$ の直線である．
この逆変換は，前節のデルタ関数の和を再現するものである．

式 (1)，(6) を代入すると，被積分関数は

```math
\left(1-e^{-\beta\hbar\omega}\right)^{-N}
e^{\beta E'}
```

となる．
その指数部を

```math
\Phi(\beta)
=-N\ln\left(1-e^{-\beta\hbar\omega}\right)
+\beta E'
\tag{7}
```

と定義する．
$N$ が大きいとき，積分の主要な寄与は指数部の停留点の近くから生じる．
そこで，鞍点 $\beta^*$ を

```math
\frac{d\Phi}{d\beta}=0
```

によって定める．
式 (7) を微分すると，

```math
\frac{d\Phi}{d\beta}
=E'-
N\frac{\hbar\omega e^{-\beta\hbar\omega}}
{1-e^{-\beta\hbar\omega}}
```

となるので，鞍点条件は

```math
\boxed{
N\frac{\hbar\omega e^{-\beta^*\hbar\omega}}
{1-e^{-\beta^*\hbar\omega}}
=E'
}
\tag{8}
```

である．

式 (8) を整理すると，

```math
\frac{e^{-\beta^*\hbar\omega}}
{1-e^{-\beta^*\hbar\omega}}
=\frac{E'}{N\hbar\omega}
```

となる．
したがって，

```math
\boxed{
e^{-\beta^*\hbar\omega}
=\frac{E'/(N\hbar\omega)}
{1+E'/(N\hbar\omega)}
}
\tag{9}
```

および

```math
\boxed{
1-e^{-\beta^*\hbar\omega}
=\frac{1}{1+E'/(N\hbar\omega)}
}
\tag{10}
```

を得る．

鞍点近似では，対数を取った状態数の主要項は式 (7) の鞍点での値となる．
すなわち，

```math
\ln W(E)\simeq \Phi(\beta^*)
```

である．
ここで， $W(E)$ は許されるエネルギー $E=E_M$ に対する状態数を意味する．
ガウス積分による前置因子などは対数を取ると $O(\ln N)$ 程度の補正となるため，エントロピーの主要項を求める段階では省略できる．

式 (9)，(10) を式 (7) に代入すると，

```math
\begin{aligned}
\ln W(E)
&\simeq
N\ln\left(1+\frac{E'}{N\hbar\omega}\right)\\
&\quad-\frac{E'}{\hbar\omega}
\ln\left[
\frac{E'/(N\hbar\omega)}
{1+E'/(N\hbar\omega)}
\right]
\end{aligned}
```

となる．
ここで，

```math
x=\frac{E'}{N\hbar\omega}
\tag{11}
```

とおくと，

```math
\boxed{
\ln W(E)
\simeq N\left[(1+x)\ln(1+x)-x\ln x\right]
}
\tag{12}
```

を得る．
この式は $N$ が大きく， $x=M/N$ が有限の値に保たれる極限における主要項である．
より詳しく書けば， $\ln W(E)$ の主要項に対する補正は $O(\ln N)$ である．

#### 3.2　Stirling の公式による確認

同じ結果は，厳密な状態数 (4) に Stirling の公式

```math
\ln n!=n\ln n-n+O(\ln n)
\qquad (n\gg1)
```

を適用しても得られる．
実際，

```math
\ln W_M
=\ln(N+M-1)!-\ln(N-1)!-\ln M!
```

であるため， $N$ と $M$ が大きいとき，

```math
\begin{aligned}
\ln W_M
&\simeq (N+M)\ln(N+M)\\
&\quad-N\ln N-M\ln M
\end{aligned}
```

となる．
ここで $x=M/N$ とおき，対数の性質を使って整理すると，

```math
\begin{aligned}
\ln W_M
&\simeq N\left[
(1+x)\ln(1+x)-x\ln x
\right]
\end{aligned}
```

を得る．
これは式 (12) と一致する．
したがって，鞍点法による評価は，厳密な状態数に Stirling の公式を適用した結果と整合している．

### 4．エントロピー $S(E)$

統計力学におけるエントロピーは，許されるエネルギー $E=E_M$ に対して，

```math
S(E)=k\ln W(E)
```

と定義される．
式 (12) を代入すると，

```math
S(E)\simeq
kN\left[(1+x)\ln(1+x)-x\ln x\right]
```

を得る．
式 (6)，(11) より，

```math
x=\frac{E-N\hbar\omega/2}{N\hbar\omega}
=\frac{E}{N\hbar\omega}-\frac12
```

であるため，エントロピーは最終的に

```math
\boxed{
\begin{aligned}
S(E)\simeq kN\Bigg[
&\left(\frac{E}{N\hbar\omega}+\frac12\right)
\ln\left(\frac{E}{N\hbar\omega}+\frac12\right)\\
-&\left(\frac{E}{N\hbar\omega}-\frac12\right)
\ln\left(\frac{E}{N\hbar\omega}-\frac12\right)
\Bigg]
\end{aligned}
}
\tag{13}
```

と表される．
これは大きな $N$ に対するエントロピーの主要項である．

基底状態 $E=N\hbar\omega/2$ では $M=0$ であり，式 (4) から $W_0=1$ となるため，エントロピーは $S=0$ である．
式 (13) でも $x\ln x$ の $x\to0^+$ における極限を $0$ と定めれば，この結果と一致する．

以上より，分配関数を展開することでエネルギーごとの厳密な状態数を求めることができ，さらに鞍点法または Stirling の公式を用いることで，大きな $N$ に対するエントロピーの形を導出できる．
