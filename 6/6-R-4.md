# 例題【6-R-4】

## 解答

本問題では，温度 $T$ の熱浴と熱平衡にある体積 $V$ の箱の中の電磁波を考え，箱の壁にあけられた小さな穴から漏れ出す輻射の強度と波長の関係を導出する．
この関係を Planck の輻射式という．
導出は，電磁波の状態密度，振動モード一つあたりの平均エネルギー，波長ごとのエネルギー密度，穴から漏れ出す輻射の強度の順に進める．

### 1．電磁波の状態密度 $(\omega)$

箱の中の電磁波は，互いに独立な調和振動子の集まりとして扱うことができる．
ここで，各振動モードは角振動数 $\omega$ をもつ電磁場の自由度に対応する．
角振動数が $\omega$ から $\omega+d\omega$ の範囲にある振動モード数を $Vg(\omega)d\omega$ と表すと， $g(\omega)$ は単位体積あたりの状態密度である．

まず，この状態密度を導出する．
箱の一辺を $L$ とし，体積を $V=L^3$ とする．
箱の中の電磁波の波数ベクトルを $\boldsymbol{k}$ ，その大きさを $k=|\boldsymbol{k}|$ とする．
大きな箱を考え，周期境界条件を用いると，波数空間では一つの状態が占める体積は $(2\pi/L)^3=(2\pi)^3/V$ である．
したがって，波数空間の単位体積あたりの状態数は $V/(2\pi)^3$ となる．

波数の大きさが $k$ から $k+dk$ の範囲にある状態は，波数空間で半径 $k$ ，厚さ $dk$ の球殻に含まれる．
この球殻の体積は $4\pi k^2dk$ である．
さらに，電磁波は横波であり，各進行方向について二つの偏光状態をもつため，偏光の自由度を考慮すると，この範囲にある振動モード数は

```math
2\frac{V}{(2\pi)^3}4\pi k^2dk
=\frac{V}{\pi^2}k^2dk
```

となる．
よって，単位体積あたりの振動モード数は

```math
\frac{1}{V}dN
=\frac{k^2}{\pi^2}dk
```

である．
ここで， $dN$ は波数の大きさが $k$ から $k+dk$ の範囲にある振動モード数である．

電磁波の角振動数と波数の大きさには， $\omega=ck$ の関係がある．
したがって，

```math
k=\frac{\omega}{c},
\qquad
dk=\frac{d\omega}{c}
```

である．
これらを代入すると，

```math
\frac{1}{V}dN
=\frac{1}{\pi^2}\left(\frac{\omega}{c}\right)^2
\frac{d\omega}{c}
=\frac{\omega^2}{\pi^2c^3}d\omega
```

となる．
ゆえに，電磁波の状態密度は

```math
\boxed{
g(\omega)=\frac{\omega^2}{\pi^2c^3}
}
\tag{1}
```

である．
ここで， $c$ は真空中の光速度である．

### 2．調和振動子の平均エネルギーとエネルギー密度

量子力学によれば，角振動数 $\omega$ の調和振動子のエネルギー準位は

```math
E_n=\left(n+\frac12\right)\hbar\omega,
\qquad n=0,1,2,\ldots
```

である．
ここで， $\hbar=h/(2\pi)$ は換算 Planck 定数であり， $h$ は Planck 定数である．

温度 $T$ の熱平衡状態では，エネルギー $E_n$ の状態が占められる確率は Boltzmann 因子 $e^{-E_n/(kT)}$ に比例する．
ここで， $k$ は Boltzmann 定数である．
この確率を正規化するための分配関数 $Z_\omega$ は，

```math
\begin{aligned}
Z_\omega
&=\sum_{n=0}^{\infty}e^{-E_n/(kT)}\\
&=\sum_{n=0}^{\infty}
e^{-(n+1/2)\hbar\omega/(kT)}\\
&=\frac{e^{-\hbar\omega/(2kT)}}
{1-e^{-\hbar\omega/(kT)}}
\end{aligned}
```

となる．

分配関数を用いると，調和振動子一つあたりの平均エネルギーは

```math
\langle E\rangle
=-\frac{\partial}{\partial\beta}\ln Z_\omega,
\qquad
\beta=\frac{1}{kT}
```

で求められる．
上の分配関数を代入して計算すると，

```math
\langle E\rangle
=\frac{\hbar\omega}{2}
+\frac{\hbar\omega}{e^{\hbar\omega/(kT)}-1}
```

を得る．
第一項 $\hbar\omega/2$ は零点エネルギーであり，温度 $T$ に依存しない．
本問題では，温度に応じて変化する輻射エネルギーを考えるため，この零点エネルギーを除く．
したがって，振動モード一つあたりの平均エネルギーは

```math
\boxed{
\varepsilon(\omega,T)
=\frac{\hbar\omega}{e^{\hbar\omega/(kT)}-1}
}
\tag{2}
```

である．

次に，角振動数が $\omega$ から $\omega+d\omega$ の範囲にある電磁波がもつ，単位体積あたりのエネルギーを $u(\omega,T)d\omega$ と表す．
この範囲には $g(\omega)d\omega$ 個の振動モードが単位体積あたり存在し，それぞれの平均エネルギーが $\varepsilon(\omega,T)$ である．
したがって，

```math
u(\omega,T)d\omega
=\varepsilon(\omega,T)g(\omega)d\omega
```

となる．
式 (1)，(2) を代入すると，

```math
\boxed{
u(\omega,T)d\omega
=\frac{\hbar\omega^3}{\pi^2c^3}
\frac{d\omega}{e^{\hbar\omega/(kT)}-1}
}
\tag{3}
```

を得る．
これが角振動数で表した Planck の輻射式である．

### 3．波長 $\lambda$ による表現

次に，式 (3) を波長 $\lambda$ で表す．
波長 $\lambda$ と角振動数 $\omega$ の間には，

```math
\omega=2\pi\nu=\frac{2\pi c}{\lambda}
```

の関係がある．
ここで， $\nu$ は振動数である．
この関係を微分すると，

```math
\frac{d\omega}{d\lambda}
=-\frac{2\pi c}{\lambda^2}
```

となる．
角振動数は波長が大きくなると小さくなるため， $d\omega$ と $d\lambda$ の符号は逆になる．
エネルギー密度は正の量であり，波長区間 $(\lambda,\lambda+d\lambda)$ に含まれるエネルギーは，対応する角振動数区間のエネルギーと等しい．
したがって，

```math
u(\lambda,T)d\lambda
=u(\omega,T)|d\omega|
```

であり，

```math
|d\omega|=\frac{2\pi c}{\lambda^2}d\lambda
```

を用いる．
式 (3) に $\omega=2\pi c/\lambda$ とこの微分要素を代入すると，

```math
\begin{aligned}
u(\lambda,T)d\lambda
&=\frac{\hbar}{\pi^2c^3}
\left(\frac{2\pi c}{\lambda}\right)^3
\frac{1}{e^{2\pi\hbar c/(\lambda kT)}-1}
\frac{2\pi c}{\lambda^2}d\lambda\\
&=\frac{16\pi^2\hbar c}{\lambda^5}
\frac{d\lambda}{e^{2\pi\hbar c/(\lambda kT)}-1}.
\end{aligned}
```

ここで $h=2\pi\hbar$ を用いると，

```math
\boxed{
u(\lambda,T)
=\frac{8\pi hc}{\lambda^5}
\frac{1}{e^{hc/(\lambda kT)}-1}
}
\tag{4}
```

を得る．
これが波長で表した Planck の輻射式である．
$u(\lambda,T)d\lambda$ は，波長が $\lambda$ から $\lambda+d\lambda$ の範囲にある電磁波の，単位体積あたりのエネルギーを表す．

### 4．穴から漏れ出す輻射の強度

ここまでは，箱の中に存在する電磁波のエネルギー密度を求めた．
次に，箱の壁に小さな穴をあけたとき，穴を通じて外部へ漏れ出す輻射を考える．
穴をあけても箱の中の電磁波は熱平衡状態に保たれると仮定する．

穴の面積を $dS$ ，穴の外向き法線と輻射の進行方向とのなす角を $\theta$ ，その方向を含む微小立体角を $d\Omega$ とする．
波長が $\lambda$ から $\lambda+d\lambda$ の範囲にある電磁波について，この穴から単位時間あたりに漏れ出すエネルギーを考える．

箱の中の電磁波は，熱平衡状態ではあらゆる方向に等方的に分布している．
全立体角は $4\pi$ であるため，立体角 $d\Omega$ に含まれる方向のエネルギー密度は，全体の $d\Omega/(4\pi)$ に相当する．
また，電磁波は速さ $c$ で進むので，単位時間あたりに穴を通過するエネルギーには $c$ が掛かる．
さらに，進行方向が穴の法線から角度 $\theta$ だけ傾いている場合，穴の面に垂直な方向への投影面積は $dS\cos\theta$ となる．

以上から，波長区間 $(\lambda,\lambda+d\lambda)$ ，立体角要素 $d\Omega$ に対応し，穴の面積 $dS$ を単位時間あたりに通過するエネルギーは，

```math
\begin{aligned}
&J(\lambda,T,\theta)d\lambda\,d\Omega\,dS\\
&\qquad=c\,u(\lambda,T)d\lambda
\frac{d\Omega}{4\pi}\cos\theta\,dS
\end{aligned}
\tag{5}
```

と表される．
ここで， $J(\lambda,T,\theta)$ は，解答例と同じく，単位面積・単位立体角・単位波長あたりの輻射の強度を表す量として定義したものである．

式 (4) を式 (5) に代入すると，

```math
\begin{aligned}
J(\lambda,T,\theta)
&=\frac{c}{4\pi}u(\lambda,T)\cos\theta\\
&=\frac{c}{4\pi}
\frac{8\pi hc}{\lambda^5}
\frac{\cos\theta}{e^{hc/(\lambda kT)}-1}.
\end{aligned}
```

よって，

```math
\boxed{
J(\lambda,T,\theta)
=\frac{2hc^2}{\lambda^5}
\frac{\cos\theta}{e^{hc/(\lambda kT)}-1}
}
\tag{6}
```

を得る．
特に，穴の法線方向 $\theta=0$ では $\cos\theta=1$ であるため，

```math
\boxed{
J(\lambda,T,0)
=\frac{2hc^2}{\lambda^5}
\frac{1}{e^{hc/(\lambda kT)}-1}
}
```

となる．
以上で，箱の小さな穴から漏れ出す輻射の強度と波長の関係が導出された．

### 補足：Planck の輻射式の極限

#### 1．長波長・高温極限（Rayleigh–Jeans 則）

```math
\frac{hc}{\lambda kT}\ll1
```

のとき，指数関数を展開すると，

```math
e^{hc/(\lambda kT)}-1
\simeq \frac{hc}{\lambda kT}
```

である．
この近似を式 (4) に代入すると，

```math
u(\lambda,T)
\simeq \frac{8\pi hc}{\lambda^5}
\frac{\lambda kT}{hc}
=\frac{8\pi kT}{\lambda^4}
```

を得る．
これは Rayleigh–Jeans 則であり，古典的な等分配則から得られる結果に対応する．
ただし，この近似を短波長まで適用すると， $\lambda\to0$ でエネルギー密度が発散する．
これが古典論における紫外破綻である．

#### 2．短波長・低温極限（Wien の輻射式）

```math
\frac{hc}{\lambda kT}\gg1
```

のとき，指数関数は十分に大きいため，

```math
e^{hc/(\lambda kT)}-1
\simeq e^{hc/(\lambda kT)}
```

と近似できる．
したがって，式 (4) は

```math
u(\lambda,T)
\simeq\frac{8\pi hc}{\lambda^5}
e^{-hc/(\lambda kT)}
```

となる．
これを Wien の輻射式という．
Planck の輻射式は，長波長・高温極限では Rayleigh–Jeans 則に，短波長・低温極限では Wien の輻射式に近づく．
このように，Planck の輻射式は異なる極限で得られる二つの法則を統一的に記述するものである．
