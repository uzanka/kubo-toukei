# 演習問題【6-A-1】

## 解答

### 0．問題文の補足・修正

問題文の最後に示された2つの式は，分母がそれぞれ $\overline{E^2}$ ， $\overline{E^3}$ である場合，有限の粒子数 $N$ に対する厳密な等式ではない．

古典的な単原子分子理想気体について，有限の $N$ で厳密に成立する式は，

```math
\boxed{
\frac{\overline{(E-\overline E)^2}}{\overline{E^2}}
=\frac{2}{3N+2}
}
```

および，

```math
\boxed{
\frac{\overline{(E-\overline E)^3}}{\overline{E^3}}
=\frac{8}{(3N+2)(3N+4)}
}
```

である．

一方，問題文に記載された

```math
\frac{2}{3N},
\qquad
\frac{8}{9N^2}
```

は， $N\gg1$ における近似値である．

したがって，以下では有限の $N$ に対する厳密式を導出した後，大粒子数極限において問題文の式が得られることを示す．

### 1．カノニカル分布におけるエネルギーのゆらぎの導出

#### 1.1 分配関数と平均エネルギー

カノニカル分布において，逆温度を

```math
\beta=\frac{1}{kT}
```

と定義する．
ここで， $k$ はボルツマン定数， $T$ は絶対温度である．

系のエネルギー固有値を $E_i$ とすると，分配関数 $Z$ は

```math
Z=\sum_i e^{-\beta E_i}
```

で与えられる．
また，物理量 $A$ のカノニカル平均を

```math
\overline A
=\frac{1}{Z}\sum_i A_i e^{-\beta E_i}
```

と定義する．

したがって，平均エネルギーは

```math
\overline E
=\frac{1}{Z}\sum_i E_i e^{-\beta E_i}
```

である．

分配関数を $\beta$ で微分すると，

```math
\frac{\partial Z}{\partial\beta}
=-\sum_i E_i e^{-\beta E_i}
```

となる．
よって，

```math
\begin{aligned}
\overline E
&=-\frac{1}{Z}\frac{\partial Z}{\partial\beta}\\
&=-\frac{\partial}{\partial\beta}\ln Z
\end{aligned}
\tag{1}
```

を得る．

以下では，体積 $V$ と粒子数 $N$ を一定とし，エネルギー固有値 $E_i$ は温度に陽には依存しないものとする．
また，温度は $T>0$ とする．

#### 1.2 エネルギーの2次の中心モーメント

式 (1) を $\beta$ で微分すると，

```math
\frac{\partial\overline E}{\partial\beta}
=-\frac{\partial^2}{\partial\beta^2}\ln Z
```

である．
商の微分を用いると，

```math
\begin{aligned}
\frac{\partial\overline E}{\partial\beta}
&=-\frac{Z''}{Z}
+\left(\frac{Z'}{Z}\right)^2\\
&=-\overline{E^2}+(\overline E)^2
\end{aligned}
\tag{2}
```

となる．
ただし，

```math
Z'=\frac{\partial Z}{\partial\beta},
\qquad
Z''=\frac{\partial^2 Z}{\partial\beta^2}
```

とした．
実際，

```math
\frac{Z''}{Z}
=\frac{1}{Z}\sum_i E_i^2e^{-\beta E_i}
=\overline{E^2}
```

であり，

```math
\frac{Z'}{Z}=-\overline E
```

である．

一方，エネルギーの2次の中心モーメントは，

```math
\begin{aligned}
\overline{(E-\overline E)^2}
&=\overline{E^2-2E\overline E+(\overline E)^2}\\
&=\overline{E^2}-2(\overline E)^2+(\overline E)^2\\
&=\overline{E^2}-(\overline E)^2
\end{aligned}
```

である．

これを式 (2) と比較すると，

```math
\frac{\partial\overline E}{\partial\beta}
=-\overline{(E-\overline E)^2}
\tag{3}
```

を得る．

ここで，

```math
\beta=\frac{1}{kT}
```

より，

```math
\frac{\partial T}{\partial\beta}=-kT^2
```

である．
したがって，連鎖律から，

```math
\frac{\partial}{\partial\beta}
=-kT^2\frac{\partial}{\partial T}
```

となる．

定積熱容量 $C_v$ は，体積 $V$ と粒子数 $N$ を一定にしたときの平均エネルギーの温度微分であるから，

```math
C_v=
\left(\frac{\partial\overline E}{\partial T}\right)_{V,N}
```

である．
よって，

```math
\frac{\partial\overline E}{\partial\beta}
=-kT^2C_v
\tag{4}
```

となる．

式 (3)，(4) を比較すれば，

```math
\boxed{
\overline{(E-\overline E)^2}=kT^2C_v
}
\tag{5}
```

が得られる．

#### 1.3 エネルギーの3次の中心モーメント

続いて，平均エネルギーを $\beta$ でさらに1回微分することにより，3次の中心モーメントを導く．

一般に，

```math
\overline{E^n}
=\frac{1}{Z}\sum_i E_i^n e^{-\beta E_i}
```

であるから，商の微分により，

```math
\begin{aligned}
\frac{\partial\overline{E^n}}{\partial\beta}
&=-\frac{1}{Z}\sum_i E_i^{n+1}e^{-\beta E_i}
-\frac{Z'}{Z}\overline{E^n}\\
&=-\overline{E^{n+1}}
+\overline E\,\overline{E^n}
\end{aligned}
\tag{6}
```

を得る．

特に $n=2$ のとき，

```math
\frac{\partial\overline{E^2}}{\partial\beta}
=-\overline{E^3}+\overline E\,\overline{E^2}
\tag{7}
```

である．

式 (2) を $\beta$ で微分すると，

```math
\begin{aligned}
\frac{\partial^2\overline E}{\partial\beta^2}
&=-\frac{\partial\overline{E^2}}{\partial\beta}
+2\overline E\frac{\partial\overline E}{\partial\beta}\\
&=-\left(-\overline{E^3}
+\overline E\,\overline{E^2}\right)\\
&\quad
+2\overline E
\left(-\overline{E^2}+(\overline E)^2\right)\\
&=\overline{E^3}
-3\overline E\,\overline{E^2}
+2(\overline E)^3
\end{aligned}
\tag{8}
```

となる．

一方，3次の中心モーメントを展開すると，

```math
\begin{aligned}
\overline{(E-\overline E)^3}
&=\overline{
E^3-3E^2\overline E
+3E(\overline E)^2-(\overline E)^3
}\\
&=\overline{E^3}
-3\overline E\,\overline{E^2}
+3(\overline E)^3-(\overline E)^3\\
&=\overline{E^3}
-3\overline E\,\overline{E^2}
+2(\overline E)^3
\end{aligned}
```

である．

したがって，式 (8) より，

```math
\boxed{
\frac{\partial^2\overline E}{\partial\beta^2}
=\overline{(E-\overline E)^3}
}
\tag{9}
```

を得る．

次に，式 (4) を用いて左辺を温度微分で表す．

```math
\begin{aligned}
\frac{\partial^2\overline E}{\partial\beta^2}
&=-kT^2\frac{\partial}{\partial T}
\left(-kT^2C_v\right)\\
&=k^2T^2\frac{\partial}{\partial T}(T^2C_v)\\
&=k^2T^2
\left(
2TC_v+T^2\frac{\partial C_v}{\partial T}
\right)\\
&=k^2\left(
2T^3C_v+T^4\frac{\partial C_v}{\partial T}
\right)
\end{aligned}
```

ここで，温度微分は体積 $V$ と粒子数 $N$ を一定にして行う．

これを式 (9) に代入すれば，

```math
\boxed{
\overline{(E-\overline E)^3}
=k^2\left\{
T^4\left(\frac{\partial C_v}{\partial T}\right)_{V,N}
+2T^3C_v
\right\}
}
\tag{10}
```

が得られる．

以上により，カノニカル分布におけるエネルギーの2次および3次の中心モーメントの関係式が示された．

### 2．単原子分子理想気体への適用

内部構造を持たない単原子分子 $N$ 個からなる古典的理想気体を考える．
分子は非相対論的な並進運動のみを行い，分子間相互作用および量子統計効果は無視する．

また，古典統計を適用するため，熱的ド・ブロイ波長を

```math
\lambda_T=\frac{h}{\sqrt{2\pi mkT}}
```

とすると，数密度 $n=N/V$ に対して，

```math
n\lambda_T^3\ll1
```

が成立する領域を考える．
ここで $m$ は分子の質量， $h$ はプランク定数である．

#### 2.1 分配関数と平均エネルギー

単原子分子の並進運動の自由度は3である．
古典的な正準分配関数は，

```math
Z_N
=\frac{1}{N!h^{3N}}
\int d^{3N}q\,d^{3N}p\,
e^{-\beta H}
```

で与えられる．

理想気体では，

```math
H=\sum_{j=1}^{N}\frac{\boldsymbol p_j^2}{2m}
```

である．
位置についての積分は，

```math
\int d^{3N}q=V^N
```

となる．

また，各粒子の運動量についてガウス積分を実行すると，

```math
\int d^3p\,
e^{-\beta\boldsymbol p^2/(2m)}
=
\left(\frac{2\pi m}{\beta}\right)^{3/2}
```

である．
したがって，

```math
\begin{aligned}
Z_N
&=\frac{V^N}{N!h^{3N}}
\left(\frac{2\pi m}{\beta}\right)^{3N/2}\\
&=\frac{V^N}{N!}
\left(\frac{2\pi m}{\beta h^2}\right)^{3N/2}
\end{aligned}
```

となる．

ここで，

```math
a=\frac{3N}{2}
```

とおけば，

```math
Z_N=K\beta^{-a}
```

と表せる．
ただし， $K$ は $\beta$ に依存しない定数である．

この分配関数から，

```math
\begin{aligned}
\overline E
&=-\frac{\partial}{\partial\beta}\ln Z_N\\
&=\frac{a}{\beta}\\
&=\frac32NkT
\end{aligned}
```

を得る．

よって，定積熱容量は，

```math
\begin{aligned}
C_v
&=\left(\frac{\partial\overline E}{\partial T}\right)_{V,N}\\
&=\frac32Nk
\end{aligned}
```

である．
したがって，

```math
\left(\frac{\partial C_v}{\partial T}\right)_{V,N}=0
```

となる．

#### 2.2 エネルギーの2次の中心モーメントと生の2次モーメント

式 (5) より，

```math
\overline{(E-\overline E)^2}=kT^2C_v
```

である．
ここに，

```math
C_v=\frac32Nk
```

を代入すると，

```math
\begin{aligned}
\overline{(E-\overline E)^2}
&=kT^2\frac32Nk\\
&=\frac32Nk^2T^2
\end{aligned}
\tag{11}
```

となる．

一方，分散の定義から，

```math
\overline{(E-\overline E)^2}
=\overline{E^2}-(\overline E)^2
```

である．
したがって，

```math
\begin{aligned}
\overline{E^2}
&=(\overline E)^2
+\overline{(E-\overline E)^2}\\
&=\left(\frac32NkT\right)^2
+\frac32Nk^2T^2\\
&=\frac94N^2k^2T^2+\frac32Nk^2T^2\\
&=\frac34N(3N+2)k^2T^2
\end{aligned}
\tag{12}
```

を得る．

式 (11)，(12) より，

```math
\begin{aligned}
\frac{\overline{(E-\overline E)^2}}{\overline{E^2}}
&=\frac{\frac32Nk^2T^2}
{\frac34N(3N+2)k^2T^2}\\
&=\boxed{\frac{2}{3N+2}}
\end{aligned}
\tag{13}
```

となる．

#### 2.3 エネルギーの3次の中心モーメントと生の3次モーメント

式 (10) より，

```math
\overline{(E-\overline E)^3}
=k^2\left\{
T^4\left(\frac{\partial C_v}{\partial T}\right)_{V,N}
+2T^3C_v
\right\}
```

である．

ここで，

```math
C_v=\frac32Nk,
\qquad
\left(\frac{\partial C_v}{\partial T}\right)_{V,N}=0
```

を代入すると，

```math
\begin{aligned}
\overline{(E-\overline E)^3}
&=k^2\left\{
0+2T^3\frac32Nk
\right\}\\
&=3Nk^3T^3
\end{aligned}
\tag{14}
```

となる．

次に，生の3次モーメント $\overline{E^3}$ を分配関数から求める．

カノニカル分布では，エネルギー固有値が $\beta$ に陽に依存しないため，

```math
\overline{E^n}
=\frac{(-1)^n}{Z_N}
\frac{\partial^n Z_N}{\partial\beta^n}
```

が成立する．

ここで，

```math
Z_N=K\beta^{-a}
```

より，

```math
\frac{\partial Z_N}{\partial\beta}
=-aK\beta^{-a-1}
```

```math
\frac{\partial^2 Z_N}{\partial\beta^2}
=a(a+1)K\beta^{-a-2}
```

```math
\frac{\partial^3 Z_N}{\partial\beta^3}
=-a(a+1)(a+2)K\beta^{-a-3}
```

となる．

したがって，

```math
\begin{aligned}
\overline{E^2}
&=\frac{1}{Z_N}
\frac{\partial^2 Z_N}{\partial\beta^2}\\
&=\frac{a(a+1)}{\beta^2}
\end{aligned}
```

および，

```math
\begin{aligned}
\overline{E^3}
&=-\frac{1}{Z_N}
\frac{\partial^3 Z_N}{\partial\beta^3}\\
&=\frac{a(a+1)(a+2)}{\beta^3}
\end{aligned}
\tag{15}
```

を得る．

式 (15) に，

```math
a=\frac{3N}{2},
\qquad
\frac{1}{\beta}=kT
```

を代入すると，

```math
\begin{aligned}
\overline{E^3}
&=\frac{3N}{2}
\left(\frac{3N}{2}+1\right)
\left(\frac{3N}{2}+2\right)k^3T^3\\
&=\frac{3N}{2}
\cdot\frac{3N+2}{2}
\cdot\frac{3N+4}{2}
k^3T^3\\
&=\boxed{
\frac{3N}{8}(3N+2)(3N+4)k^3T^3
}
\end{aligned}
\tag{16}
```

となる．

式 (14)，(16) より，

```math
\begin{aligned}
\frac{\overline{(E-\overline E)^3}}{\overline{E^3}}
&=
\frac{3Nk^3T^3}
{\frac{3N}{8}(3N+2)(3N+4)k^3T^3}\\
&=\boxed{
\frac{8}{(3N+2)(3N+4)}
}
\end{aligned}
\tag{17}
```

を得る．

#### 2.4 中心モーメントと生のモーメントの独立照合

ここまでに得られた3次の生のモーメントが正しいことを，中心モーメントからも確認する．

3次の中心モーメントと生の3次モーメントの関係は，

```math
\overline{(E-\overline E)^3}
=
\overline{E^3}
-3\overline E\,\overline{E^2}
+2(\overline E)^3
```

である．
したがって，

```math
\overline{E^3}
=
\overline{(E-\overline E)^3}
+3\overline E\,\overline{E^2}
-2(\overline E)^3
```

となる．

式 (11)，(12)，(14) と，

```math
\overline E=\frac32NkT
```

を代入すると，

```math
\begin{aligned}
\overline{E^3}
&=3Nk^3T^3\\
&\quad+
3\left(\frac32NkT\right)
\left(\frac34N(3N+2)k^2T^2\right)\\
&\quad-
2\left(\frac32NkT\right)^3\\
&=\frac{3N}{8}(3N+2)(3N+4)k^3T^3
\end{aligned}
```

となる．

これは式 (16) と一致する．
よって，生の3次モーメントの計算も正しい．

### 3．大粒子数極限と問題文の式との関係

以上で得られた2つの比は，有限の $N$ に対して厳密に成立する式である．

すなわち，

```math
\boxed{
\frac{\overline{(E-\overline E)^2}}{\overline{E^2}}
=\frac{2}{3N+2}
}
\tag{18}
```

および，

```math
\boxed{
\frac{\overline{(E-\overline E)^3}}{\overline{E^3}}
=\frac{8}{(3N+2)(3N+4)}
}
\tag{19}
```

である．

ここで，粒子数が十分に大きい場合，

```math
N\gg1
```

には，

```math
3N+2=3N\left(1+\frac{2}{3N}\right)
```

および，

```math
3N+4=3N\left(1+\frac{4}{3N}\right)
```

であるから，

```math
\begin{aligned}
\frac{2}{3N+2}
&=\frac{2}{3N}
\left(1+\frac{2}{3N}\right)^{-1}\\
&\simeq\frac{2}{3N}
\end{aligned}
```

となる．

同様に，

```math
\begin{aligned}
\frac{8}{(3N+2)(3N+4)}
&=\frac{8}{9N^2}
\left(1+\frac{2}{3N}\right)^{-1}
\left(1+\frac{4}{3N}\right)^{-1}\\
&\simeq\frac{8}{9N^2}
\end{aligned}
```

となる．

したがって，問題文に記載された2つの式は， $N\gg1$ における近似式として，

```math
\boxed{
\frac{\overline{(E-\overline E)^2}}{\overline{E^2}}
\simeq\frac{2}{3N}
}
```

および，

```math
\boxed{
\frac{\overline{(E-\overline E)^3}}{\overline{E^3}}
\simeq\frac{8}{9N^2}
}
```

と表される．

#### 3.1 元の右辺が有限の $N$ でも厳密に成立する別の表記

なお，分母を生のモーメントではなく，平均エネルギーのべき乗に変更した場合には，有限の $N$ でも，

```math
\begin{aligned}
\frac{\overline{(E-\overline E)^2}}{(\overline E)^2}
&=\frac{\frac32Nk^2T^2}
{\frac94N^2k^2T^2}\\
&=\boxed{\frac{2}{3N}}
\end{aligned}
```

および，

```math
\begin{aligned}
\frac{\overline{(E-\overline E)^3}}{(\overline E)^3}
&=\frac{3Nk^3T^3}
{\frac{27}{8}N^3k^3T^3}\\
&=\boxed{\frac{8}{9N^2}}
\end{aligned}
```

が厳密に成立する．

ただし，

```math
\overline{E^2}\neq(\overline E)^2,
\qquad
\overline{E^3}\neq(\overline E)^3
```

であるため，これらの比は問題文に記載された比とは異なる量である．

以上より，カノニカル分布におけるエネルギーの2次および3次の中心モーメントと定積熱容量との関係が示された．
また，単原子分子理想気体に対して，有限粒子数での厳密な比と，大粒子数極限での近似式が得られた．
