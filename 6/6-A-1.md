# 演習問題【6-A-1】

## 解答

### 1．エネルギーのゆらぎの導出

#### 1.1 分配関数と平均エネルギー

カノニカル分布において，逆温度を

```math
\beta=\frac{1}{kT}
```

と定義する．
ここで， $k$ はボルツマン定数， $T$ は絶対温度である．
系のエネルギー固有値を $E_i$ とすると，分配関数 $Z$ は

```math
Z=\sum_i e^{-\beta E_i}
```

で与えられる．
また，物理量 $A$ のカノニカル平均を

```math
\overline A=\frac{1}{Z}\sum_i A_i e^{-\beta E_i}
```

と定義する．
したがって，平均エネルギーは

```math
\overline E
=\frac{1}{Z}\sum_i E_i e^{-\beta E_i}
```

である．

分配関数を $\beta$ で微分すると，

```math
\frac{\partial Z}{\partial\beta}
=-\sum_i E_i e^{-\beta E_i}
```

となる．
よって，

```math
\overline E
=-\frac{1}{Z}\frac{\partial Z}{\partial\beta}
=-\frac{\partial}{\partial\beta}\log Z
\tag{1}
```

を得る．
この式を $\beta$ で微分することにより，平均エネルギーとエネルギーのゆらぎとの関係を導くことができる．

#### 1.2 エネルギーの2次の中心モーメント

式 (1) を $\beta$ で微分すると，

```math
\frac{\partial\overline E}{\partial\beta}
=-\frac{\partial^2}{\partial\beta^2}\log Z
```

である．
ここで，商の微分を用いると，

```math
\begin{aligned}
\frac{\partial\overline E}{\partial\beta}
&=-\frac{Z''}{Z}
+\left(\frac{Z'}{Z}\right)^2\\
&=-\overline{E^2}+\overline E^{\,2}
\end{aligned}
\tag{2}
```

となる．
ただし， $Z'=\partial Z/\partial\beta$ ， $Z''=\partial^2 Z/\partial\beta^2$ である．

実際，

```math
\frac{Z''}{Z}
=\frac{1}{Z}\sum_i E_i^2 e^{-\beta E_i}
=\overline{E^2}
```

であり，また $Z'/Z=-\overline E$ である．

一方，エネルギーの分散は，平均値からのずれの2乗の平均として定義される．
すなわち，

```math
\begin{aligned}
\overline{(E-\overline E)^2}
&=\overline{E^2-2E\overline E+\overline E^{\,2}}\\
&=\overline{E^2}-2\overline E^{\,2}
+\overline E^{\,2}\\
&=\overline{E^2}-\overline E^{\,2}
\end{aligned}
```

である．
これを式 (2) と比較すると，

```math
\frac{\partial\overline E}{\partial\beta}
=-\overline{(E-\overline E)^2}
\tag{3}
```

を得る．

ここで，逆温度と絶対温度の関係 $\beta=1/(kT)$ から，

```math
\frac{\partial T}{\partial\beta}=-kT^2
```

である．
したがって，連鎖律により，

```math
\frac{\partial}{\partial\beta}
=-kT^2\frac{\partial}{\partial T}
```

と書ける．
定積熱容量は，体積 $V$ を一定に保ったときの内部エネルギーの温度微分であるから，

```math
C_v=\left(\frac{\partial\overline E}{\partial T}\right)_V
```

である．
よって，

```math
\frac{\partial\overline E}{\partial\beta}
=-kT^2 C_v
\tag{4}
```

となる．
式 (3)，(4) を比較すれば，

```math
\boxed{
\overline{(E-\overline E)^2}=kT^2C_v
}
```

が得られる．
これにより，エネルギーの分散が定積熱容量に比例することが示された．

#### 1.3 エネルギーの3次の中心モーメント

続いて，式 (1) を $\beta$ でさらに1回微分する．
式 (2) より，

```math
\frac{\partial^2\overline E}{\partial\beta^2}
=-\frac{\partial\overline{E^2}}{\partial\beta}
+2\overline E\frac{\partial\overline E}{\partial\beta}
\tag{5}
```

である．

ここで，一般に

```math
\overline{E^n}
=\frac{1}{Z}\sum_i E_i^n e^{-\beta E_i}
```

であるから，商の微分により，

```math
\begin{aligned}
\frac{\partial\overline{E^n}}{\partial\beta}
&=-\frac{1}{Z}\sum_i E_i^{n+1}e^{-\beta E_i}
-\frac{Z'}{Z}\overline{E^n}\\
&=-\overline{E^{n+1}}
+\overline{E^n}\,\overline E
\end{aligned}
\tag{6}
```

を得る．
特に $n=2$ のとき，

```math
\frac{\partial\overline{E^2}}{\partial\beta}
=-\overline{E^3}+\overline{E^2}\,\overline E
```

である．
これと式 (3) を式 (5) に代入すると，

```math
\begin{aligned}
\frac{\partial^2\overline E}{\partial\beta^2}
&=-\left(-\overline{E^3}
+\overline{E^2}\,\overline E\right)
+2\overline E\left(-\overline{E^2}+\overline E^{\,2}\right)\\
&=\overline{E^3}
-3\overline{E^2}\,\overline E
+2\overline E^{\,3}
\end{aligned}
\tag{7}
```

となる．

一方，3次の中心モーメントを展開すると，

```math
\begin{aligned}
\overline{(E-\overline E)^3}
&=\overline{E^3-3E^2\overline E
+3E\overline E^{\,2}-\overline E^{\,3}}\\
&=\overline{E^3}
-3\overline{E^2}\,\overline E
+2\overline E^{\,3}
\end{aligned}
```

である．
したがって，式 (7) より，

```math
\boxed{
\frac{\partial^2\overline E}{\partial\beta^2}
=\overline{(E-\overline E)^3}
}
\tag{8}
```

を得る．

次に，左辺を温度 $T$ の微分で表す．
式 (4) より，

```math
\begin{aligned}
\frac{\partial^2\overline E}{\partial\beta^2}
&=-kT^2\frac{\partial}{\partial T}
\left(-kT^2 C_v\right)\\
&=k^2T^2\frac{\partial}{\partial T}(T^2C_v)\\
&=k^2T^2\left(
2TC_v+T^2\frac{\partial C_v}{\partial T}
\right)\\
&=k^2\left(
2T^3C_v+T^4\frac{\partial C_v}{\partial T}
\right)
\end{aligned}
```

である．
ここで，温度微分は体積一定で行う．
これを式 (8) に代入すれば，

```math
\boxed{
\overline{(E-\overline E)^3}
=k^2\left\{
T^4\left(\frac{\partial C_v}{\partial T}\right)_V
+2T^3C_v
\right\}
}
```

が得られる．
以上で，求める2つの関係式が示された．

### 2．単原子分子理想気体への適用

#### 2.1 平均エネルギーと定積熱容量

内部構造を持たない単原子分子 $N$ 個からなる理想気体を考える．
各分子の並進運動は3つの自由度を持つため，平均エネルギーは

```math
\overline E=\frac32 NkT
```

である．
したがって，定積熱容量は

```math
C_v=\left(\frac{\partial\overline E}{\partial T}\right)_V
=\frac32 Nk
```

となる．
このとき $C_v$ は温度に依存しないので，

```math
\left(\frac{\partial C_v}{\partial T}\right)_V=0
```

である．

#### 2.2 2次の中心モーメント

すでに導いた関係式

```math
\overline{(E-\overline E)^2}=kT^2C_v
```

に $C_v=\frac32 Nk$ を代入すると，

```math
\begin{aligned}
\overline{(E-\overline E)^2}
&=kT^2\frac32 Nk\\
&=\frac32 Nk^2T^2
\end{aligned}
```

を得る．
また，

```math
(\overline E)^2
=\left(\frac32 NkT\right)^2
=\frac94 N^2k^2T^2
```

である．
よって，

```math
\begin{aligned}
\frac{\overline{(E-\overline E)^2}}{(\overline E)^2}
&=\frac{\frac32 Nk^2T^2}
{\frac94 N^2k^2T^2}\\
&=\boxed{\frac{2}{3N}}
\end{aligned}
```

となる．

#### 2.3 3次の中心モーメント

3次の中心モーメントについては，

```math
\overline{(E-\overline E)^3}
=k^2\left\{
T^4\left(\frac{\partial C_v}{\partial T}\right)_V
+2T^3C_v
\right\}
```

である．
$C_v=\frac32 Nk$ は温度に依存しないため，

```math
\begin{aligned}
\overline{(E-\overline E)^3}
&=k^2\left\{0+2T^3\frac32 Nk\right\}\\
&=3Nk^3T^3
\end{aligned}
```

を得る．
また，

```math
(\overline E)^3
=\left(\frac32 NkT\right)^3
=\frac{27}{8}N^3k^3T^3
```

である．
したがって，

```math
\begin{aligned}
\frac{\overline{(E-\overline E)^3}}{(\overline E)^3}
&=\frac{3Nk^3T^3}
{\frac{27}{8}N^3k^3T^3}\\
&=\boxed{\frac{8}{9N^2}}
\end{aligned}
```

となる．
以上より，分母を平均エネルギーの2乗および3乗とした場合，求める2つの式が示された．
