# 例題【6-R-6】

## 解答

### 1. 物理モデルと分配関数

#### 1.1 物理モデル

大きさが一定値 $\mu$ の電気双極子モーメント $N$ 個からなる系を考える．

各双極子は互いに独立であり，自由に向きを変えられるものとする．
また，双極子間相互作用は無視する．

各双極子のモーメントを $\boldsymbol{\mu}_i$ とし，合成双極子モーメントを

```math
\boldsymbol M=\sum_{i=1}^{N}\boldsymbol{\mu}_i
```

とする．

その $z$ 方向成分は

```math
M_z=\sum_{i=1}^{N}\mu_{iz}
```

である．

以下では外部電場が $z$ 方向のみを向く場合を考え，

```math
\boldsymbol{\mathcal E}
=\mathcal E_z\boldsymbol e_z
```

とする．
ここで $\mathcal E_z$ は符号付きの量である．

双極子と電場の相互作用エネルギーは

```math
U_i=-\boldsymbol{\mu}_i\cdot\boldsymbol{\mathcal E}
```

であるから，系全体では

```math
\begin{aligned}
U_{\mathrm{int}}
&=\sum_{i=1}^{N}U_i\\
&=-\sum_{i=1}^{N}
\boldsymbol{\mu}_i\cdot\boldsymbol{\mathcal E}\\
&=-\boldsymbol M\cdot\boldsymbol{\mathcal E}\\
&=-\mathcal E_zM_z.
\end{aligned}
```

したがって，

```math
\boxed{
U_{\mathrm{int}}=-\mathcal E_zM_z
}
```

である．

#### 1.2 状態密度を用いた分配関数

問題文に従い，合成モーメント $M_z$ が

```math
M_z\leq M<M_z+dM_z
```

の範囲に存在する状態の位相体積を

```math
\Omega(M_z)dM_z
```

とする．

ここで $\Omega(M_z)$ は状態密度であり，状態数そのものではない．

Boltzmann 定数を $k$ ，絶対温度を $T$ として，

```math
\beta=\frac1{kT}
```

と置く．

Boltzmann 因子は

```math
e^{-\beta U_{\mathrm{int}}}
=e^{\beta\mathcal E_zM_z}
```

である．

また，各双極子について

```math
-\mu\leq\mu_{iz}\leq\mu
```

なので，

```math
-N\mu\leq M_z\leq N\mu
```

である．

したがって，分配関数は

```math
\boxed{
Z(\mathcal E_z)
=
\int_{-N\mu}^{N\mu}
e^{\beta\mathcal E_zM_z}
\Omega(M_z)\,dM_z
}
\tag{1}
```

となる．

#### 1.3 1個の双極子の分配関数

双極子の向きと正の $z$ 軸とのなす角を $\theta$ とする．

すると，

```math
\mu_z=\mu\cos\theta
```

である．

1個の双極子について，

```math
U_1=-\mu\mathcal E_z\cos\theta
```

となる．

無次元変数

```math
\boxed{
y=\frac{\mu\mathcal E_z}{kT}
}
\tag{2}
```

を導入すれば，

```math
e^{-\beta U_1}=e^{y\cos\theta}.
```

配向に関する分配関数は

```math
Z_1(y)
=
\int e^{y\cos\theta}\,d\Omega
```

である．

ここで，

```math
d\Omega=\sin\theta\,d\theta\,d\phi
```

なので，

```math
\begin{aligned}
Z_1(y)
&=2\pi\int_0^\pi
e^{y\cos\theta}\sin\theta\,d\theta.
\end{aligned}
```

$u=\cos\theta$ と置換すると，

```math
\begin{aligned}
Z_1(y)
&=2\pi\int_{-1}^{1}e^{yu}\,du\\
&=2\pi\frac{e^y-e^{-y}}{y}\\
&=4\pi\frac{\sinh y}{y}.
\end{aligned}
```

よって，

```math
\boxed{
Z_1(y)=4\pi\frac{\sinh y}{y}
}
```

である．

$y=0$ では，

```math
\lim_{y\to0}\frac{\sinh y}{y}=1
```

なので，

```math
Z_1(0)=4\pi
```

となり，電場がない場合の全立体角と一致する．

#### 1.4 $N$ 個の双極子の分配関数

双極子は独立であるから，

```math
Z(y)=Z_1(y)^N.
```

したがって，

```math
\boxed{
Z(y)=(4\pi)^N
\left(\frac{\sinh y}{y}\right)^N
}
\tag{3}
```

を得る．

### 2. Langevin 関数と熱平均

式（1）を $\mathcal E_z$ で微分すると，

```math
\frac{\partial Z}{\partial\mathcal E_z}
=
\beta\int
M_z e^{\beta\mathcal E_zM_z}
\Omega(M_z)\,dM_z.
```

よって，

```math
\boxed{
\frac{\partial\ln Z}{\partial\mathcal E_z}
=
\beta\langle M_z\rangle
}
\tag{4}
```

である．

一方，式（3）から，

```math
\ln Z
=
N\ln(4\pi)
+
N\ln\left(\frac{\sinh y}{y}\right).
```

また，

```math
\frac{\partial y}{\partial\mathcal E_z}
=\frac{\mu}{kT}
```

および

```math
\frac{d}{dy}
\ln\left(\frac{\sinh y}{y}\right)
=
\coth y-\frac1y
```

なので，

```math
\frac{\partial\ln Z}{\partial\mathcal E_z}
=
\frac{N\mu}{kT}
\left(\coth y-\frac1y\right).
```

ここで Langevin 関数を

```math
\boxed{
L(y)=\coth y-\frac1y
}
\tag{5}
```

と定義する．

式（4）と比較すれば，

```math
\boxed{
\langle M_z\rangle=N\mu L(y)
}
\tag{6}
```

が得られる．

これは正準分布における合成モーメントの熱平均である．

なお，以下で指定する $M_z$ は状態密度を求めるための値であり，この熱平均と最初から同一視するものではない．

#### 2.1 Langevin 関数の単調性

Langevin 関数の微分は

```math
L'(y)=\frac1{y^2}-\frac1{\sinh^2y}
```

である．

$y\neq0$ では，

```math
|\sinh y|>|y|
```

なので，

```math
L'(y)>0.
```

また，原点では Taylor 展開から，

```math
L(y)=\frac y3-\frac{y^3}{45}+O(y^5)
```

であるため，

```math
L'(0)=\frac13>0.
```

さらに，

```math
\lim_{y\to+\infty}L(y)=1,
\qquad
\lim_{y\to-\infty}L(y)=-1.
```

したがって，Langevin 関数は実数全体で単調増加し，その値域は

```math
-1<L(y)<1
```

である．

よって，逆関数

```math
L^{-1}(\xi)
```

は

```math
\boxed{-1<\xi<1}
```

で一意に定義される．

### 3. 状態密度の大偏差型漸近評価

#### 3.1 無次元変数の導入

次の無次元変数を導入する．

```math
\boxed{
X=\frac{M_z}{\mu}
}
\tag{7}
```

すると，

```math
M_z=\mu X,\qquad dM_z=\mu\,dX.
```

無次元変数 $X$ に関する状態密度を

```math
\boxed{
\Omega_X(X)=\mu\Omega(\mu X)
}
\tag{8}
```

と定義する．

この定義により，

```math
\Omega(M_z)dM_z=\Omega_X(X)dX
```

が成立する．

#### 3.2 等方的配向における確率密度

電場がない場合を考える．

一つの双極子について，

```math
u_i=\frac{\mu_{iz}}{\mu}=\cos\theta_i
```

と置く．

等方的配向では，

```math
\frac{d\Omega_i}{4\pi}
=
\frac{d\phi_i}{2\pi}\frac{du_i}{2}
```

となる．

したがって， $u_i$ は区間 $[-1,1]$ 上の一様分布に従い，その確率密度は

```math
f_1(u)=
\begin{cases}
\dfrac12,&-1\leq u\leq1,\\
0,&\text{それ以外}
\end{cases}
```

である．

また，

```math
X=u_1+\cdots+u_N
```

なので， $X$ の確率密度 $f_N(X)$ は $f_1$ の $N$ 回の畳み込みである．

全配向位相体積は

```math
\prod_{i=1}^{N}\int d\Omega_i=(4\pi)^N
```

であるから，

```math
\boxed{
\Omega_X(X)=(4\pi)^Nf_N(X)
}
```

となる．

式（8）を使えば，

```math
\boxed{
\Omega(M_z)
=
\frac{(4\pi)^N}{\mu}
f_N\left(\frac{M_z}{\mu}\right)
}
\tag{9}
```

を得る．

これは状態密度と確率密度の間の厳密な関係である．

#### 3.3 指数傾斜分布

ここで，

```math
m(x)=\frac12\int_{-1}^{1}e^{xu}\,du
```

と定義する．

積分すると，

```math
\boxed{
m(x)=\frac{\sinh x}{x}
}
```

であり，原点では連続極限によって $m(0)=1$ とする．

次の確率密度を導入する．

```math
\boxed{
f_{1,x}(u)=\frac{e^{xu}}{2m(x)},
\qquad -1\leq u\leq1
}
\tag{10}
```

これは，

```math
\int_{-1}^{1}f_{1,x}(u)\,du=1
```

を満たす．

この分布における平均は，

```math
\begin{aligned}
\langle u\rangle_x
&=\frac{d}{dx}\ln m(x)\\
&=\coth x-\frac1x\\
&=L(x).
\end{aligned}
```

分散は，

```math
\begin{aligned}
\operatorname{Var}_x(u)
&=\frac{d^2}{dx^2}\ln m(x)\\
&=L'(x).
\end{aligned}
```

したがって，

```math
\boxed{
\langle u\rangle_x=L(x),
\qquad
\operatorname{Var}_x(u)=L'(x)
}
\tag{11}
```

となる．

この指数傾斜分布から独立に $N$ 個の変数を取り，その和の確率密度を $f_{N,x}(X)$ とする．

元の一様分布との関係は，

```math
f_{1,x}(u)=\frac{e^{xu}}{m(x)}f_1(u)
```

である．

よって，

```math
\begin{aligned}
\prod_{i=1}^{N}f_{1,x}(u_i)
&=
\frac{e^{x(u_1+\cdots+u_N)}}{m(x)^N}
\prod_{i=1}^{N}f_1(u_i)\\
&=\frac{e^{xX}}{m(x)^N}
\prod_{i=1}^{N}f_1(u_i).
\end{aligned}
```

両辺を和 $X$ に関する確率密度に直すと，

```math
\boxed{
f_{N,x}(X)
=
\frac{e^{xX}}{m(x)^N}f_N(X)
}
\tag{12}
```

となる．

したがって，

```math
\boxed{
f_N(X)=m(x)^Ne^{-xX}f_{N,x}(X)
}
\tag{13}
```

を得る．

この変換は任意の実数 $x$ について成立する．

#### 3.4 指定された合成モーメントに対応する $x$

問題文の定義に従い，

```math
\boxed{
\xi=\frac{M_z}{N\mu}=\frac XN
}
\tag{14}
```

と置く．

前述した Langevin 関数の単調性から，

```math
-1<\xi<1
```

に対して，

```math
\boxed{
x=L^{-1}(\xi)
}
\tag{15}
```

が一意に定まる．

この定義から，

```math
L(x)=\xi
```

なので，指数傾斜分布では

```math
\langle X\rangle_x=NL(x)=N\xi.
```

一方，分散は独立性から，

```math
\operatorname{Var}_x(X)=NL'(x).
```

したがって，指定された値

```math
X=N\xi
```

は指数傾斜分布における平均値と一致する．

#### 3.5 局所中心極限定理の適用

ここでは，確率密度を近似するために局所中心極限定理を用いる．

指数傾斜分布 $f_{1,x}$ の特性関数を

```math
\varphi_x(t)
=
\int_{-1}^{1}e^{itu}f_{1,x}(u)\,du
```

とする．

式（10）から，

```math
\boxed{
\varphi_x(t)
=
\frac{\sinh(x+it)}
{m(x)(x+it)}
}
```

である．

固定された有限の実数 $x$ について，この特性関数は次の性質を持つ．

- $t\neq0$ で $|\varphi_x(t)|<1$ ．
- 大きな $|t|$ に対して $\varphi_x(t)=O_x(|t|^{-1})$ ．
- $\varphi_x$ は二乗可積分である．
- 分布の平均・分散は有限で，分散 $L'(x)$ は正である．

したがって，この分布について密度の局所中心極限定理を適用できる．

特に，和の平均値 $NL(x)$ において，

```math
f_{N,x}(NL(x))
=
\frac{1+o(1)}
{\sqrt{2\pi NL'(x)}}
```

が成立する．

ここで $x$ は固定された有限値であり，したがって $\xi=L(x)$ も固定された内部の値である．

$L(x)=\xi$ より，

```math
\boxed{
f_{N,x}(N\xi)
=
\frac{1+o(1)}
{\sqrt{2\pi NL'(x)}}
}
\tag{16}
```

を得る．

#### 3.6 状態密度の漸近式

式（13）に式（16）を代入する．

```math
\begin{aligned}
f_N(N\xi)
&=m(x)^Ne^{-xN\xi}f_{N,x}(N\xi)\\
&=
\frac{1+o(1)}
{\sqrt{2\pi NL'(x)}}
\exp\left\{
N[\ln m(x)-\xi x]
\right\}.
\end{aligned}
```

さらに，

```math
m(x)=\frac{\sinh x}{x}
```

および式（9）を使えば，

```math
\boxed{
\begin{aligned}
\Omega(M_z)
={}&
\frac{(4\pi)^N}
{\mu\sqrt{2\pi NL'(x)}}\\
&\times
\exp\left\{
N\left[
\ln\left(\frac{\sinh x}{x}\right)-\xi x
\right]
\right\}
[1+o(1)].
\end{aligned}
}
\tag{17}
```

ただし，

```math
\boxed{
\xi=\frac{M_z}{N\mu},
\qquad x=L^{-1}(\xi)
}
```

である．

この式は，

```math
-1<\xi<1
```

の内部で， $\xi$ を固定して $N\to\infty$ とする場合の漸近式である．

両辺の対数を取ると，

```math
\begin{aligned}
\log\Omega(M_z)
={}&N\log(4\pi)\\
&+N\left[
\ln\left(\frac{\sinh x}{x}\right)-\xi x
\right]\\
&-\frac12\log(2\pi NL'(x))
-\log\mu+o(1).
\end{aligned}
\tag{18}
```

なお， $\Omega$ は次元を持つため，厳密に対数を取る場合には固定した基準モーメント $\mu_0$ を用いて $\log(\mu_0\Omega)$ とする．
式（18）の主要な $N$ に比例する部分には影響しない．

ここで $\xi$ に依存しない項を定数にまとめると，

```math
\boxed{
\log\Omega(M_z)
\cong
N\left[
\mathrm{const.}
+\log\left(\frac{\sinh x}{x}\right)
-\xi x
\right]
}
\tag{19}
```

となる．

これが問題文で要求されている主要漸近式である．

なお，式（17）の前置因子に由来する対数項は $O(\log N)$ であるため， $O(N)$ の主要項には影響しない．

#### 3.7 対称性と端点

Langevin 関数は奇関数なので，その逆関数も奇関数である．

したがって，

```math
x(-\xi)=-x(\xi).
```

また，

```math
\frac{\sinh x}{x}
```

は偶関数なので，

```math
\ln\left(\frac{\sinh x}{x}\right)-\xi x
```

は $\xi$ の偶関数である．

よって，

```math
\boxed{
\Omega(-M_z)=\Omega(M_z)
}
```

という対称性と整合している．

また，

```math
\xi=\pm1
```

では全双極子がそれぞれ $+z$ または $-z$ 方向に完全に揃う必要があり， $x\to\pm\infty$ となる．

このような端点では式（17）の内部領域に対する局所中心極限定理による漸近評価を適用しない．

一方，

```math
\xi=0
```

では，

```math
x=0,\qquad L'(0)=\frac13
```

であり，

```math
\lim_{x\to0}\frac{\sinh x}{x}=1
```

を用いれば，式（17）は連続的に定義される．

### 4. 小さい $\xi$ に対するガウス近似

ここからは，

```math
|\xi|=\left|\frac{M_z}{N\mu}\right|\ll1
```

を考える．

#### 4.1 Langevin 関数の逆関数の展開

Langevin 関数は

```math
L(x)=\frac x3-\frac{x^3}{45}+O(x^5)
```

である．

```math
\xi=L(x)
```

を逆に解く．

$x$ を $\xi$ のべき級数として，

```math
x=a_1\xi+a_3\xi^3+O(\xi^5)
```

と仮定する．

Langevin 関数に代入すると，

```math
\xi
=
\frac{a_1}{3}\xi
+
\left(
\frac{a_3}{3}-\frac{a_1^3}{45}
\right)\xi^3
+O(\xi^5).
```

係数比較から，

```math
a_1=3,
\qquad
a_3=\frac95.
```

したがって，

```math
\boxed{
x=3\xi+\frac95\xi^3+O(\xi^5)
}
\tag{20}
```

である．

#### 4.2 指数部の展開

双曲線正弦関数の Taylor 展開から，

```math
\ln\left(\frac{\sinh x}{x}\right)
=
\frac{x^2}{6}-\frac{x^4}{180}
+O(x^6).
```

式（20）を代入する．

まず，

```math
x^2=9\xi^2+\frac{54}{5}\xi^4+O(\xi^6)
```

および，

```math
x^4=81\xi^4+O(\xi^6)
```

なので，

```math
\begin{aligned}
\ln\left(\frac{\sinh x}{x}\right)
&=
\frac32\xi^2
+\frac95\xi^4
-\frac9{20}\xi^4
+O(\xi^6)\\
&=
\frac32\xi^2+\frac{27}{20}\xi^4
+O(\xi^6).
\end{aligned}
```

一方，

```math
\xi x
=
3\xi^2+\frac95\xi^4+O(\xi^6).
```

したがって，

```math
\boxed{
\ln\left(\frac{\sinh x}{x}\right)-\xi x
=
-\frac32\xi^2-\frac9{20}\xi^4
+O(\xi^6)
}
\tag{21}
```

となる．

特に二次まで残すと，

```math
\boxed{
\ln\left(\frac{\sinh x}{x}\right)-\xi x
=
-\frac32\xi^2+O(\xi^4)
}
\tag{22}
```

である．

式（18）に代入すれば，

```math
\begin{aligned}
\log(\mu_0\Omega(M_z))
={}&C_N
-\frac32N\xi^2
-\frac9{20}N\xi^4\\
&+O(N\xi^6)+O(\xi^2)+o(1)
\end{aligned}
\tag{23}
```

となる．

ここで $C_N$ は $M_z$ に依存しない項である．

したがって，対数状態密度の主要な $N$ に比例する部分は，

```math
\boxed{
\frac1N\log(\mu_0\Omega(M_z))
=
\mathrm{const.}
-\frac32\xi^2+O(\xi^4)+o(1)
}
\tag{24}
```

である．

```math
\xi=\frac{M_z}{N\mu}
```

を代入すれば，

```math
\boxed{
\log\Omega(M_z)
=
C_N'
-\frac{3M_z^2}{2N\mu^2}
+O\left(\frac{M_z^4}{N^3\mu^4}\right)
+O(\xi^2)+o(1)
}
\tag{25}
```

となる．

ここまでで，大偏差関数の二次近似は導出された．

ただし，ここで注意すべきことがある．

指数部の四次の補正は

```math
-\frac9{20}N\xi^4
```

なので， $|\xi|\ll1$ という条件だけでは，その補正が $N\to\infty$ で消えるとは限らない．

したがって，式（24）は対数状態密度の主要関数の二次近似であり，状態密度そのものの相対誤差が消えるガウス近似を得るには，さらに条件を明確にする必要がある．

#### 4.3 中心領域での相対誤差付きガウス近似

指数部の四次補正を消すため，

```math
N\xi^4\to0
```

を考える．

例えば，

```math
\boxed{
|M_z|\leq C\mu\sqrt N
}
\tag{26}
```

という領域を取る．
ここで $C>0$ は $N$ に依存しない定数である．

この領域では，

```math
\xi=O(N^{-1/2})
```

なので，

```math
N\xi^4=O(N^{-1})\to0
```

となる．

ただし，式（17）は固定された $\xi$ に対する漸近式であるため，それだけから $N$ 依存の $\xi$ に対する相対漸近式を導くことはしない．

この中心領域のガウス近似は，以下のように，元の確率分布に対する局所中心極限定理から直接導く．

### 5. 中心領域のガウス近似の独立な証明

電場がない等方的配向において，各双極子の無次元成分は

```math
u_i=\cos\theta_i
```

である．

各 $u_i$ は独立な一様分布 $[-1,1]$ に従う．

したがって，

```math
\langle u_i\rangle
=
\frac12\int_{-1}^{1}u\,du=0
```

であり，

```math
\begin{aligned}
\langle u_i^2\rangle
&=\frac12\int_{-1}^{1}u^2\,du\\
&=\frac13.
\end{aligned}
```

よって，

```math
\boxed{
\langle u_i\rangle=0,
\qquad
\operatorname{Var}(u_i)=\frac13
}
\tag{27}
```

である．

合成変数

```math
X=\sum_{i=1}^{N}u_i
```

について，独立性から，

```math
\langle X\rangle=0,
\qquad
\operatorname{Var}(X)=\frac N3.
```

ここで $X$ の確率密度を $f_N(X)$ とする．

各 $u_i$ の特性関数は，

```math
\varphi(t)
=
\frac12\int_{-1}^{1}e^{itu}\,du
=
\frac{\sin t}{t}.
```

この特性関数は

```math
|\varphi(t)|<1
\qquad(t\neq0)
```

を満たし，さらに，

```math
|\varphi(t)|=O(|t|^{-1})
```

であるため，局所中心極限定理を適用できる．

その結果，

```math
\boxed{
f_N(X)
=
\sqrt{\frac{3}{2\pi N}}
\exp\left(-\frac{3X^2}{2N}\right)
[1+o(1)]
}
\tag{28}
```

が得られる．

ここで，この相対漸近式は

```math
|X|\leq C\sqrt N
```

の任意の固定された $C$ に対して一様に成立する．

厳密には，局所中心極限定理がまず与えるのは，密度についての絶対誤差 $o(N^{-1/2})$ である．
上記の有界な中心領域では，ガウス密度の係数部分が正の定数で下から抑えられるため，相対誤差 $o(1)$ に書き換えられる．

これが通常の中心極限定理との重要な違いである．

式（9）より，

```math
\Omega(M_z)
=
\frac{(4\pi)^N}{\mu}
f_N\left(\frac{M_z}{\mu}\right).
```

式（28）に

```math
X=\frac{M_z}{\mu}
```

を代入すると，

```math
\boxed{
\begin{aligned}
\Omega(M_z)
={}&
\frac{(4\pi)^N}{\mu}
\sqrt{\frac{3}{2\pi N}}\\
&\times
\exp\left(
-\frac{3M_z^2}{2N\mu^2}
\right)
[1+o(1)].
\end{aligned}
}
\tag{29}
```

適用範囲は，

```math
\boxed{
|M_z|\leq C\mu\sqrt N
}
```

である．

したがって，

```math
\boxed{
\Omega(M_z)
\propto
\mathrm{const.}
\exp\left(
-\frac{3M_z^2}{2N\mu^2}
\right)
}
\tag{30}
```

が得られる．

これは問題文で要求されているガウス近似である．

### 6. 最終結果

互いに独立な大きさ一定の電気双極子 $N$ 個からなる系について，合成モーメント $M_z$ の状態密度は，固定された

```math
-1<\xi<1,
\qquad
\xi=\frac{M_z}{N\mu}
```

に対して，

```math
\boxed{
\log\Omega(M_z)
\cong
N\left[
\mathrm{const.}
+\log\left(\frac{\sinh x}{x}\right)
-\xi x
\right]
}
```

となる．

ここで，

```math
\boxed{
x=L^{-1}(\xi),
\qquad
L(x)=\coth x-\frac1x
}
```

である．

また，小さい $|\xi|$ に対して，

```math
\boxed{
\log\left(\frac{\sinh x}{x}\right)-\xi x
=
-\frac32\xi^2-\frac9{20}\xi^4+O(\xi^6)
}
```

である．

したがって，対数状態密度の主要項は二次までで

```math
\boxed{
\log\Omega(M_z)
=
\mathrm{const.}
-\frac{3M_z^2}{2N\mu^2}
+\text{高次補正}
}
```

となる．

さらに，中心領域

```math
|M_z|=O(\mu\sqrt N)
```

では，局所中心極限定理から相対誤差付きで，

```math
\boxed{
\Omega(M_z)
=
\frac{(4\pi)^N}{\mu}
\sqrt{\frac{3}{2\pi N}}
\exp\left(
-\frac{3M_z^2}{2N\mu^2}
\right)
[1+o(1)]
}
```

が成立する．

よって，問題文の要求する

```math
\boxed{
\Omega(M_z)\propto
\mathrm{const.}
\exp\left(
-\frac{3M_z^2}{2N\mu^2}
\right)
}
```

が導かれる．
