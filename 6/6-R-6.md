# 演習問題【6-R-6】

## 解答

問題文では，電気2重極モーメント $N$ 個の系について，合成モーメント $\boldsymbol{M} = \sum_{i=1}^{N} \boldsymbol{\mu}_i$ のある方向の成分 $M_z$ を指定したときの位相体積 $\Omega(M_z)$ の漸近評価を求める．

まず，系に電場 $\mathcal{E}$ が掛かっているとき，電場方向の成分 $M_z$ に関するポテンシャルエネルギーは $-\mathcal{E} M_z$ である．
系の分配関数 $Z(\mathcal{E})$ は，エネルギーの全ての状態についての和（連続近似では積分）として次のように書ける：

```math
Z(\mathcal{E}) = \int \exp\left\{\frac{\mathcal{E} M_z}{kT}\right\} \Omega(M_z) \, dM_z \quad \cdots (1)
```

ここで， $k$ はボルツマン定数， $T$ は絶対温度である．

ここで， $N$ が大きいときの漸近評価を考える．
熱力学的な関係を用いると， $\mathcal{E}$ を独立変数とする熱力学関数 $\log Z(\mathcal{E})$ と， $M_z$ を独立変数とする熱力学関数 $\log \Omega(M_z)$ の間には，Legendre（ルジャンドル）変換の関係がある．
具体的には，以下の関係式が成り立つ：

$$\log \Omega(M_z) = \log Z(\mathcal{E}) - \frac{M_z \mathcal{E}}{kT} \quad \cdots (2)$$

この変換における $\mathcal{E}$ と $M_z$ の関係は， $\log Z(\mathcal{E})$ を $\mathcal{E}$ で微分したものが $M_z/(kT)$ に等しいことである：

$$\frac{\partial \log Z(\mathcal{E})}{\partial \mathcal{E}} = \frac{M_z}{kT} \quad \cdots (3)$$

式(3)を用いて， $\mathcal{E}$ を $M_z$ の関数として表し，それを式(2)に代入することで $\log \Omega(M_z)$ を求める．

例題［２］の結果を用いると，分配関数 $Z$ は次のような形を持つことがわかっている：

$$Z = \frac{\alpha^N}{N!} \left( \frac{\sinh(\mu\mathcal{E}/kT)}{\mu\mathcal{E}/kT} \right)^N \quad \cdots (4)$$

ここで $\mu$ は電気2重極モーメントの大きさ， $x = \mu\mathcal{E}/kT$ とおいた．
$\alpha$ は $\mathcal{E}$ に依存しない定数であり，立体角積分に由来する因子 $4\pi$ などが含まれる．
式(4)の形は，1個の電気2重極の分配関数が角度積分

$$Z_1 = \int e^{\beta\mu\mathcal{E}\cos\theta} d\Omega = 4\pi \frac{\sinh(\mu\mathcal{E}/kT)}{\mu\mathcal{E}/kT}$$

によって導かれることから来る．
これより， $\log Z$ を $\mathcal{E}$ で微分すると：

$$\log Z = N \log \alpha - \log N! + N \log \left( \frac{\sinh x}{x} \right)$$

$$\frac{\partial \log Z}{\partial \mathcal{E}} = N \frac{\partial}{\partial \mathcal{E}} \log \left( \frac{\sinh x}{x} \right) = N \frac{\coth x - 1/x}{\mu\mathcal{E}/kT} \cdot \frac{\mu}{kT} = \frac{N\mu}{kT} (\coth x - 1/x)$$

ここで Langevin関数 $L(x) = \coth x - 1/x$ を用いれば：

$$\frac{\partial \log Z}{\partial \mathcal{E}} = \frac{N\mu}{kT} L(x)$$

これを式(3)と比較すると：

$$\frac{N\mu}{kT} L(x) = \frac{M_z}{kT} \implies \frac{M_z}{N\mu} = L(x)$$

$\xi = M_z/(N\mu)$ とおけば， $x = L^{-1}(\xi)$ である．
次に式(2)に $\log Z$ を代入すると：

$$\begin{aligned} \log \Omega(M_z) &= \text{const.} + N \log \left( \frac{\sinh x}{x} \right) - N\xi x \\ &= \text{const.} + N \left[ \log \left( \frac{\sinh x}{x} \right) - \xi x \right] \end{aligned}$$

$x = L^{-1}(\xi)$ より，これは問題文の形：

$$\log \Omega(M_z) \cong N [\text{const.} + \log (\sinh x/x) - \xi x]$$

と一致する．

次に， $\xi \ll 1$ すなわち $M_z / (N\mu) \ll 1$ のときの近似を行う．
このとき， Langevin関数の展開 $L(x) = x/3 - x^3/45 + \cdots$ より：

$$\xi = L(x) \approx x/3 \implies x \approx 3\xi$$

また， $\frac{\sinh x}{x}$ のテイラー展開は：

$$\frac{\sinh x}{x} = 1 + \frac{1}{6}x^2 + \cdots$$

これに $x \approx 3\xi$ を代入すると：

$$\frac{\sinh x}{x} \approx 1 + \frac{1}{6}(3\xi)^2 = 1 + \frac{3}{2}\xi^2$$

これを用いて $\log \Omega(M_z)$ を計算すると：

$$\begin{aligned} \log \Omega(M_z) &\cong \text{const.} + N \left[ \log \left( 1 + \frac{3}{2}\xi^2 \right) - \xi(3\xi) \right] \\ &\cong \text{const.} + N \left[ \frac{3}{2}\xi^2 - 3\xi^2 \right] \\ &= \text{const.} - \frac{3}{2} N\xi^2 \end{aligned}$$

$\xi = M_z / (N\mu)$ を代入すると：

$$\log \Omega(M_z) \cong \text{const.} - \frac{3}{2} N \left( \frac{M_z}{N\mu} \right)^2 = \text{const.} - \frac{3M_z^2}{2N\mu^2}$$

よって，

$$\Omega(M_z) \propto \text{const.} \exp \left[ - \frac{3M_z^2}{2N\mu^2} \right]$$

となる．

## 解説

本問題は，統計力学における分配関数と位相体積（状態の数）の関係，および $N \to \infty$ の極限における漸近評価（鞍点法に関連する概念）を扱うものである．

### 1. Legendre変換の物理的意味

統計力学において，外部場（ここでは電場 $\mathcal{E}$ ）を固定したときの分配関数 $Z(\mathcal{E})$ と，系の状態量（ここでは合成モーメント $M_z$ ）を固定したときの位相体積 $\Omega(M_z)$ は，数学的にはLegendre変換の関係にある．
これは，熱力学におけるヘルムホルツの自由エネルギーとエントロピーの関係と同様の構造を持っている．

### 2. Langevin関数

$N$ 個の独立な磁気モーメント（あるいは電気2重極モーメント）が外部場中にあるとき，それらの合成モーメントの期待値はLangevin関数 $L(x)$ を用いて表される．
$x$ が小さいとき（外部場が弱いとき），Langevin関数は線形近似 $L(x) \approx x/3$ ができることが重要である．

### 3. 漸近評価とガウス近似

$M_z / (N\mu) \ll 1$ という条件は，合成モーメントが系の最大値 $N\mu$ に対して非常に小さいことを意味する．
このとき， $\Omega(M_z)$ は $M_z$ に関してガウス分布（正規分布）に従うことが導かれる．
これは，中心極限定理の統計力学的な現れと言える．

### 4. 分配関数の形

1個の電気2重極の分配関数は立体角積分によって $Z_1 = 4\pi (\sinh x)/x$ と求まる．
この $(\sinh x)/x$ の形が，後のLegendre変換において $\log(\sinh x/x)$ という項をもたらし，最終的なガウス分布の幅 $3/2$ を決める重要な因子である．
