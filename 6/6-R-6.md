# 演習問題【6-R-6】

## 解答

電気双極子モーメントの大きさが $\mu$ である双極子 $N$ 個から成る系を考える．
各双極子は独立に向きを変えられるものとし，合成モーメントを

```math
\boldsymbol M=\sum_{i=1}^{N}\boldsymbol\mu_i
```

とする．
本問では，その $z$ 方向成分 $M_z$ が区間 $[M_z,M_z+dM_z]$ に入る状態の数を $\Omega(M_z)dM_z$ と定義する．
このとき， $N$ が十分に大きい場合の $\log\Omega(M_z)$ を求め，さらに $M_z/(N\mu)\ll1$ の範囲でガウス型の近似を導く．

### 1．分配関数と状態密度の関係

まず， $z$ 方向に大きさ $\mathcal E$ の電場を加えた系を考える．
電場と双極子モーメントの相互作用によるポテンシャルエネルギーは

```math
U=-\mathcal E M_z
```

である．
したがって，状態の Boltzmann 因子は

```math
e^{-\beta U}
=e^{\mathcal E M_z/(kT)},
\qquad
\beta=\frac{1}{kT}
```

となる．
ここで， $k$ は Boltzmann 定数， $T$ は絶対温度である．

$M_z$ が $M_z+dM_z$ の範囲にある状態の数は $\Omega(M_z)dM_z$ であるから，分配関数 $Z(\mathcal E)$ は

```math
\boxed{
Z(\mathcal E)
=\int_{-N\mu}^{N\mu}
e^{\mathcal E M_z/(kT)}
\Omega(M_z)\,dM_z
}
\tag{1}
```

と表される．
積分範囲は， $N$ 個の双極子がすべて同じ向きを向いた場合に $|M_z|=N\mu$ となることによる．

式 (1) は，外部電場を固定した分配関数と，合成モーメント $M_z$ ごとの状態密度を結びつける式である．
以下では，既知の分配関数から状態密度を逆に求める．

### 2．分配関数から $M_z$ と電場の関係を求める

#### 2.1　分配関数の形

一つの双極子が電場となす角を $\theta$ とする．
この双極子のポテンシャルエネルギーは

```math
U_1=-\mu\mathcal E\cos\theta
```

であり，Boltzmann 因子は $e^{x\cos\theta}$ となる．
ただし，

```math
x=\frac{\mu\mathcal E}{kT}
\tag{2}
```

とおいた．
双極子の向きを表す立体角について積分すると，

```math
\begin{aligned}
Z_1
&=\int e^{x\cos\theta}\,d\Omega\\
&=2\pi\int_0^\pi e^{x\cos\theta}\sin\theta\,d\theta\\
&=4\pi\frac{\sinh x}{x}
\end{aligned}
```

を得る．
ここで， $d\Omega=\sin\theta\,d\theta\,d\phi$ は立体角要素である．
最後の積分は $u=\cos\theta$ と置換すれば計算できる．

双極子は互いに独立であるため，系全体の分配関数は各双極子の分配関数の積として表される．
位置の積分や $N!$ など，電場に依存しない因子をまとめて定数 $\alpha$ で表すと，

```math
\boxed{
Z(\mathcal E)
=\frac{\alpha^N}{N!}
\left(\frac{\sinh x}{x}\right)^N
}
\tag{3}
```

となる．
この式で， $\alpha$ は電場 $\mathcal E$ に依存しない定数である．

#### 2.2　Langevin 関数を用いた関係式

式 (1) を電場 $\mathcal E$ で微分すると，

```math
\begin{aligned}
\frac{\partial Z}{\partial\mathcal E}
&=\int
\frac{M_z}{kT}
e^{\mathcal E M_z/(kT)}
\Omega(M_z)\,dM_z
\end{aligned}
```

である．
両辺を $Z$ で割ると，

```math
\frac{\partial\log Z}{\partial\mathcal E}
=\frac{\langle M_z\rangle}{kT}
```

となる．
ここで， $\langle M_z\rangle$ は電場 $\mathcal E$ の下での合成モーメントの熱平均である．
大きな $N$ の漸近評価では，指定された巨視的な値 $M_z$ と対応する熱平均を結びつけて考える．

一方，式 (3) の対数を取ると，

```math
\log Z
=N\log\alpha-\log N!
+N\log\left(\frac{\sinh x}{x}\right)
```

である．
式 (2) より，

```math
\frac{\partial x}{\partial\mathcal E}
=\frac{\mu}{kT}
```

である．
また，

```math
\frac{d}{dx}\log\left(\frac{\sinh x}{x}\right)
=\coth x-\frac1x
```

であるから，連鎖律により，

```math
\begin{aligned}
\frac{\partial\log Z}{\partial\mathcal E}
&=N\left(\coth x-\frac1x\right)
\frac{\mu}{kT}
\end{aligned}
```

となる．
ここで，Langevin 関数を

```math
L(x)=\coth x-\frac1x
\tag{4}
```

と定義すれば，

```math
\frac{\partial\log Z}{\partial\mathcal E}
=\frac{N\mu}{kT}L(x)
```

である．
これを熱平均の関係式と比較すると，

```math
M_z=N\mu L(x)
```

を得る．
ここで，

```math
\boxed{
\xi=\frac{M_z}{N\mu}
}
\tag{5}
```

と定義すれば，

```math
\boxed{
\xi=L(x),
\qquad x=L^{-1}(\xi)
}
\tag{6}
```

となる．
すなわち，指定された合成モーメント $M_z$ に対応する無次元電場 $x$ は，Langevin 関数の逆関数によって決まる．
物理的に許される範囲は $-1<\xi<1$ である．

### 3．鞍点法による $\log\Omega(M_z)$ の漸近評価

#### 3.1　逆変換と鞍点条件

式 (1) において，

```math
X=\frac{M_z}{\mu}
```

とおくと， $M_z=\mu X$ ， $dM_z=\mu\,dX$ である．
変数 $X$ に関する状態密度を $\Omega_X(X)$ と書けば，

```math
\Omega_X(X)=\mu\Omega(\mu X)
```

であり，式 (1) は

```math
Z(x)=\int e^{xX}\Omega_X(X)\,dX
\tag{7}
```

と書ける．
したがって，逆 Laplace 変換によって，

```math
\Omega_X(X)
=\frac{1}{2\pi i}
\int_{x^*-i\infty}^{x^*+i\infty}
Z(x)e^{-xX}\,dx
\tag{8}
```

を得る．
ここで， $x^*$ は積分経路の実部であり，後で被積分関数の指数部が停留するように選ぶ．

式 (8) の被積分関数を

```math
\exp\!\left[\log Z(x)-xX\right]
```

と表す．
$N$ が十分に大きい場合，積分の主要な寄与は指数部

```math
\Phi(x)=\log Z(x)-xX
```

の停留点の近くから生じる．
そこで，鞍点 $x^*$ を

```math
\left.\frac{d\Phi}{dx}\right|_{x=x^*}=0
```

によって定める．
これは，

```math
\left.\frac{\partial\log Z}{\partial x}\right|_{x=x^*}=X
\tag{9}
```

を意味する．

式 (3) より，

```math
\frac{\partial\log Z}{\partial x}
=N\left(\coth x-\frac1x\right)
=NL(x)
```

であるため，式 (9) は

```math
NL(x^*)=X
```

となる．
$X=M_z/\mu=N\xi$ であることから，

```math
L(x^*)=\xi
```

である．
したがって，先に求めた関係と同じく，

```math
\boxed{
x^*=L^{-1}(\xi)
}
\tag{10}
```

を得る．

#### 3.2　鞍点での評価

鞍点の周りでは，指数部を Taylor 展開して二次の項まで残すことにより，積分を Gaussian 積分で近似できる．
その結果，

```math
\Omega_X(X)\sim
\frac{Z(x^*)e^{-x^*X}}
{\sqrt{2\pi\left.\dfrac{\partial^2\log Z}{\partial x^2}\right|_{x=x^*}}}
```

となる．
ここで，

```math
\frac{\partial^2\log Z}{\partial x^2}
=NL'(x)
```

であるから，分母は $\sqrt{2\pi N L'(x^*)}$ となる．
この前置因子の対数は $O(\log N)$ であり， $\log\Omega$ の主要な $N$ に比例する項よりも小さい．
よって，

```math
\log\Omega_X(X)
=\log Z(x^*)-x^*X+O(\log N)
```

である．
また， $\Omega(M_z)=\Omega_X(X)/\mu$ であるため，変数変換による $-\log\mu$ は $M_z$ に依存しない定数に吸収できる．

式 (3) を代入すると，

```math
\begin{aligned}
\log\Omega(M_z)
&=N\log\alpha-\log N!
+N\log\left(\frac{\sinh x^*}{x^*}\right)\\
&\quad-x^*X+O(\log N)+\text{\(M_z\) に依存しない定数}
\end{aligned}
```

となる．
さらに $X=N\xi$ を用い， $M_z$ に依存しない項をまとめれば，

```math
\boxed{
\log\Omega(M_z)
\cong N\left[
\text{const.}
+\log\left(\frac{\sinh x}{x}\right)
-\xi x
\right],
\qquad x=L^{-1}(\xi)
}
\tag{11}
```

を得る．
ここで $\cong$ は，大きな $N$ における主要項を表す．
$\text{const.}$ は $M_z$ ，すなわち $\xi$ に依存しない項をまとめたものであり，分配関数の規格化や前置因子などを含む．
これが問題文で求められている漸近評価である．

### 4．$\xi\ll1$ におけるガウス近似

次に，合成モーメントが最大値 $N\mu$ と比べて小さい場合，

```math
|\xi|=\left|\frac{M_z}{N\mu}\right|\ll1
```

を考える．
このとき，Langevin 関数を $x=0$ の近くで Taylor 展開すると，

```math
L(x)=\frac{x}{3}-\frac{x^3}{45}+O(x^5)
```

である．
式 (6) より，

```math
\xi=L(x)
```

であるから，主要項では

```math
x=3\xi+O(\xi^3)
\tag{12}
```

となる．

また，双曲線正弦関数の Taylor 展開は，

```math
\frac{\sinh x}{x}
=1+\frac{x^2}{6}+O(x^4)
```

である．
したがって，

```math
\begin{aligned}
\log\left(\frac{\sinh x}{x}\right)
&=\frac{x^2}{6}+O(x^4)\\
&=\frac32\xi^2+O(\xi^4)
\end{aligned}
\tag{13}
```

を得る．
式 (12) からも，

```math
\xi x=3\xi^2+O(\xi^4)
\tag{14}
```

である．
式 (13)，(14) を式 (11) に代入すると，

```math
\begin{aligned}
\log\Omega(M_z)
&=C_N+
N\left[
\frac32\xi^2-3\xi^2+O(\xi^4)
\right]+O(\log N)\\
&=C_N-\frac32N\xi^2
+O(N\xi^4)+O(\log N)
\end{aligned}
```

となる．
ここで $C_N$ は $M_z$ に依存しない項である．
主要な二次の項を残せば，

```math
\log\Omega(M_z)
\cong C_N-\frac32N\xi^2
```

である．
最後に， $\xi=M_z/(N\mu)$ を代入すると，

```math
\begin{aligned}
\log\Omega(M_z)
&\cong C_N-\frac32N
\left(\frac{M_z}{N\mu}\right)^2\\
&=C_N-\frac{3M_z^2}{2N\mu^2}
\end{aligned}
```

を得る．
両辺の指数を取ると，

```math
\boxed{
\Omega(M_z)\propto
A_N\exp\left(-\frac{3M_z^2}{2N\mu^2}\right)
}
\tag{15}
```

となる．
ここで $A_N$ は $M_z$ に依存しない正の係数であり，規格化や前置因子を含む．
式 (15) は， $M_z/(N\mu)\ll1$ の範囲で状態密度がガウス型で近似できることを示している．

以上より，分配関数から鞍点法を用いて $\log\Omega(M_z)$ の主要項を求めると，問題文の漸近式が得られる．
さらに，合成モーメントが $N\mu$ より十分に小さい範囲では，状態密度は $\exp[-3M_z^2/(2N\mu^2)]$ に比例するガウス型となる．
