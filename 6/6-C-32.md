# 演習問題【6-C-32】
## 解答

### 1. 密度行列の $q$ 表示の導出

まず，ハミルトニアン $\mathcal{H}$ の固有値問題を考える．
$\mathcal{H}$ の固有関数を $\varphi_l(q)$ ，固有値を $E_l$ とすると，次の方程式が成り立つ：

$$\mathcal{H} \varphi_l(q) = E_l \varphi_l(q)$$

これを $q$ 表示（位置表示）の演算子として書き直すと，運動量演算子 $\hat{p} = \frac{\hbar}{i} \frac{\partial}{\partial q}$ を用いて，

$$\mathcal{H}\left( \frac{\hbar}{i} \frac{\partial}{\partial q}, q \right) \varphi_l(q) = E_l \varphi_l(q)$$

と表される．

次に，密度行列 $e^{-\beta \mathcal{H}}$ の $q$ 表示 $\langle q' | e^{-\beta \mathcal{H}} | q'' \rangle$ を求める．
固有関数 $\{\varphi_l(q)\}$ が完全系をなすとき，任意の演算子 $\hat{A}$ の行列要素は，固有関数による展開を用いて次のように書くことができる：

$$\langle q' | \hat{A} | q'' \rangle = \sum_l \langle q' | \varphi_l \rangle \langle \varphi_l | \hat{A} | q'' \rangle = \sum_l \varphi_l(q') \langle \varphi_l | \hat{A} | q'' \rangle$$

ここで， $\hat{A} = e^{-\beta \mathcal{H}}$ とおくと，

$$\langle q' | e^{-\beta \mathcal{H}} | q'' \rangle = \sum_l \varphi_l(q') \langle \varphi_l | e^{-\beta \mathcal{H}} | q'' \rangle$$

となる．
$\varphi_l$ は $\mathcal{H}$ の固有関数であるから， $e^{-\beta \mathcal{H}} \varphi_l = e^{-\beta E_l} \varphi_l$ が成り立つ．
したがって，

$$\langle q' | e^{-\beta \mathcal{H}} | q'' \rangle = \sum_l \varphi_l(q') e^{-\beta E_l} \langle \varphi_l | q'' \rangle = \sum_l e^{-\beta E_l} \varphi_l(q') \varphi_l^*(q'')$$

が得られる．

ここで，指数関数 $\exp(-\beta \mathcal{H})$ のテイラー展開を考えると，

$$\exp(-\beta \mathcal{H}) = \sum_{n=0}^{\infty} \frac{(-\beta)^n}{n!} \mathcal{H}^n$$

である．
これを用いると，固有関数 $\varphi_l(q')$ に対して次が成り立つ：

```math
\exp\left\{ -\beta \mathcal{H}\left( \frac{\hbar}{i} \frac{\partial}{\partial q'}, q' \right) \right\} \varphi_l(q') = \sum_{n=0}^{\infty} \frac{(-\beta)^n}{n!} \mathcal{H}^n \varphi_l(q') = \sum_{n=0}^{\infty} \frac{(-\beta)^n}{n!} E_l^n \varphi_l(q') = e^{-\beta E_l} \varphi_l(q')
```

したがって，

```math
\langle q' | e^{-\beta \mathcal{H}} | q'' \rangle = \sum_l \left[ \exp\left\{ -\beta \mathcal{H}\left( \frac{\hbar}{i} \frac{\partial}{\partial q'}, q' \right) \right\} \varphi_l(q') \right] \varphi_l^*(q'')
```

```math
\quad = \exp\left\{ -\beta \mathcal{H}\left( \frac{\hbar}{i} \frac{\partial}{\partial q'}, q' \right) \right\} \sum_l \varphi_l(q') \varphi_l^*(q'')
```

ここで，完全系 $\sum_l \varphi_l(q') \varphi_l^*(q'') = \delta(q' - q'')$ を用いることで，

```math
\langle q' | e^{-\beta \mathcal{H}} | q'' \rangle = \exp\left\{ -\beta \mathcal{H}\left( \frac{\hbar}{i} \frac{\partial}{\partial q'}, q' \right) \right\} \delta(q' - q'')
```

が導かれる．

### 2. 自由粒子の $q$ 表示の導出

自由粒子のハミルトニアンは $\mathcal{H} = \frac{p^2}{2m} = \frac{1}{2m} \left( \frac{\hbar}{i} \frac{\partial}{\partial x} \right)^2 = -\frac{\hbar^2}{2m} \frac{\partial^2}{\partial x^2}$ である．
これを用いると，密度行列の演算子は $\exp\left( \frac{\beta \hbar^2}{2m} \frac{\partial^2}{\partial x^2} \right)$ と書ける．

デルタ関数 $\delta(\mathbf{x}' - \mathbf{x}'')$ の積分表示を，

$$\delta(\mathbf{x}' - \mathbf{x}'') = \left( \frac{1}{2\pi} \right)^3 \int_{-\infty}^{\infty} e^{i\mathbf{k}\cdot(\mathbf{x}'-\mathbf{x}'')} d\mathbf{k}$$

とする．
これに対して演算子を作用させると，

$$\langle \mathbf{x}' | e^{-\beta \mathcal{H}} | \mathbf{x}'' \rangle = \left( \frac{1}{2\pi} \right)^3 \int_{-\infty}^{\infty} \exp\left( \frac{\beta \hbar^2}{2m} \nabla'^2 \right) e^{i\mathbf{k}\cdot(\mathbf{x}'-\mathbf{x}'')} d\mathbf{k}$$

となる．
ここで，ラプラス演算子 $\nabla'^2$ を平面波に作用させると，

$$\nabla'^2 e^{i\mathbf{k}\cdot(\mathbf{x}'-\mathbf{x}'')} = -k^2 e^{i\mathbf{k}\cdot(\mathbf{x}'-\mathbf{x}'')} \quad (\text{ただし } k = |\mathbf{k}|)$$

であるため，

$$\exp\left( \frac{\beta \hbar^2}{2m} \nabla'^2 \right) e^{i\mathbf{k}\cdot(\mathbf{x}'-\mathbf{x}'')} = \exp\left( -\frac{\beta \hbar^2}{2m} k^2 \right) e^{i\mathbf{k}\cdot(\mathbf{x}'-\mathbf{x}'')} \quad \cdots (\text{式 A})$$

が得られる．
ゆえに，

$$\langle \mathbf{x}' | e^{-\beta \mathcal{H}} | \mathbf{x}'' \rangle = \left( \frac{1}{2\pi} \right)^3 \int_{-\infty}^{\infty} \exp\left[ -\frac{\beta \hbar^2}{2m} k^2 + i\mathbf{k}\cdot(\mathbf{x}'-\mathbf{x}'') \right] d\mathbf{k}$$

となる．
この積分はガウス積分の公式 $\int_{-\infty}^{\infty} e^{-ak^2 + bk} dk = \sqrt{\frac{\pi}{a}} e^{b^2/4a}$ を用いて計算できる．
各成分 $j = \{x, y, z\}$ について， $a = \frac{\beta \hbar^2}{2m}$ ， $b = i(x'_j - x''_j)$ とすると，

$$\int_{-\infty}^{\infty} e^{-\frac{\beta \hbar^2}{2m} k_j^2 + i k_j (x'_j - x''_j)} dk_j = \sqrt{\frac{2\pi m}{\beta \hbar^2}} \exp\left[ -\frac{m}{2\beta \hbar^2} (x'_j - x''_j)^2 \right]$$

である．
3次元の積分全体では，

$$\langle \mathbf{x}' | e^{-\beta \mathcal{H}} | \mathbf{x}'' \rangle = \left( \frac{1}{2\pi} \right)^3 \left( \sqrt{\frac{2\pi m}{\beta \hbar^2}} \right)^3 \exp\left[ -\frac{m}{2\beta \hbar^2} \sum_{j} (x'_j - x''_j)^2 \right]$$

$$\quad = \left( \frac{1}{2\pi} \right)^3 \frac{(2\pi m)^{3/2}}{(\beta \hbar^2)^{3/2}} \exp\left[ -\frac{m}{2\beta \hbar^2} (\mathbf{x}' - \mathbf{x}'')^2 \right]$$

$$\quad = \left( \frac{m}{2\pi\beta\hbar^2} \right)^{3/2} \exp\left[ -\frac{m}{2\beta\hbar^2} (\mathbf{x}' - \mathbf{x}'')^2 \right]$$

が得られる．

## 解説

本問題では，量子統計力学における密度行列の $q$ 表示（位置表示）を求めるプロセスを扱った．
まず，密度行列 $e^{-\beta \mathcal{H}}$ が固有関数に対してどのように作用するかを，テイラー展開と固有値問題の関係から導いた．
次に，完全系としてのデルタ関数の性質を利用して，演算子の作用をデルタ関数との積として表現する手法を示した．
最後に，具体的な例として自由粒子のハミルトニアンを用い，運動量表示の平面波を用いた積分計算によって，具体的な形を導出した．
この一連の流れは，量子統計力学における相関関数や分配関数の計算における基礎となる重要なものである．
