# 演習問題【6-C-32】

## 解答

### 密度行列の $q$ 表示と自由粒子への適用

#### 1．密度行列の $q$ 表示の導出

ハミルトニアン $\mathcal H$ の固有関数を $\varphi_l(q)$ ，固有値を $E_l$ とする．
位置表示では，運動量演算子は

```math
\hat p=\frac{\hbar}{i}\frac{\partial}{\partial q}
=-i\hbar\frac{\partial}{\partial q}
```

で表される．
したがって，固有値方程式は

```math
\mathcal H\left(
\frac{\hbar}{i}\frac{\partial}{\partial q},q
\right)\varphi_l(q)
=E_l\varphi_l(q)
\tag{1}
```

と書ける．
ここで，ハミルトニアンは既に演算子として定義されており，位置表示における演算子の順序も定まっているものとする．

次に，規格化されていない密度演算子 $e^{-\beta\mathcal H}$ の行列要素を考える．
固有状態による完全系を用いると，

```math
\begin{aligned}
\langle q'|e^{-\beta\mathcal H}|q''\rangle
&=\sum_l
\langle q'|l\rangle
\langle l|e^{-\beta\mathcal H}|q''\rangle\\
&=\sum_l e^{-\beta E_l}
\varphi_l(q')\varphi_l^*(q'')
\end{aligned}
\tag{2}
```

となる．
ここで， $|l\rangle$ はハミルトニアンの固有状態であり，

```math
e^{-\beta\mathcal H}|l\rangle
=e^{-\beta E_l}|l\rangle
```

を用いた．

一方，式(1)より， $q'$ に関する微分演算子としてのハミルトニアンを固有関数に作用させれば，

```math
\mathcal H\left(
\frac{\hbar}{i}\frac{\partial}{\partial q'},q'
\right)\varphi_l(q')
=E_l\varphi_l(q')
```

である．
この関係を繰り返し適用すると，任意の非負整数 $n$ に対して，

```math
\left[
\mathcal H\left(
\frac{\hbar}{i}\frac{\partial}{\partial q'},q'
\right)
\right]^n\varphi_l(q')
=E_l^n\varphi_l(q')
```

を得る．
指数関数の Taylor 展開

```math
e^{-\beta\mathcal H}
=\sum_{n=0}^{\infty}
\frac{(-\beta)^n}{n!}\mathcal H^n
```

を用いると，

```math
\boxed{
\begin{aligned}
&\exp\left[
-\beta\mathcal H\left(
\frac{\hbar}{i}\frac{\partial}{\partial q'},q'
\right)
\right]\varphi_l(q')\\
&\qquad=e^{-\beta E_l}\varphi_l(q')
\end{aligned}
}
\tag{3}
```

となる．

式(2)に式(3)を用いれば，

```math
\begin{aligned}
\langle q'|e^{-\beta\mathcal H}|q''\rangle
={}&
\sum_l
\left[
\exp\left\{
-\beta\mathcal H\left(
\frac{\hbar}{i}\frac{\partial}{\partial q'},q'
\right)
\right\}
\varphi_l(q')
\right]\varphi_l^*(q'')\\
={}&
\exp\left\{
-\beta\mathcal H\left(
\frac{\hbar}{i}\frac{\partial}{\partial q'},q'
\right)
\right\}
\sum_l\varphi_l(q')\varphi_l^*(q'')
\end{aligned}
\tag{4}
```

を得る．

固有関数が完全系をなすとき，完全性の関係は

```math
\sum_l\varphi_l(q')\varphi_l^*(q'')
=\delta(q'-q'')
\tag{5}
```

である．
連続スペクトルをもつ場合には，この和は対応する積分を含む意味で理解する．

式(5)を式(4)に代入すると，求める関係式

```math
\boxed{
\begin{aligned}
\langle q'|e^{-\beta\mathcal H}|q''\rangle
={}&\exp\left[
-\beta\mathcal H\left(
\frac{\hbar}{i}\frac{\partial}{\partial q'},q'
\right)
\right]\\
&\qquad\times\delta(q'-q'')
\end{aligned}
}
\tag{6}
```

が得られる．
ここで，右辺の微分演算子は，その右側にあるデルタ関数に作用する．
これにより，問題で示すべき式が証明された．

#### 2．自由粒子の密度行列

##### 2.1 1次元の場合

自由粒子のハミルトニアンは，

```math
\mathcal H=\frac{\hat p^2}{2m}
```

である．
位置表示では，

```math
\hat p=\frac{\hbar}{i}\frac{\partial}{\partial q'}
```

なので，

```math
\mathcal H
=-\frac{\hbar^2}{2m}
\frac{\partial^2}{\partial q'^2}
```

となる．
したがって，式(6)より，

```math
\boxed{
\langle q'|e^{-\beta\mathcal H}|q''\rangle
=
\exp\left(
\frac{\beta\hbar^2}{2m}
\frac{\partial^2}{\partial q'^2}
\right)\delta(q'-q'')
}
\tag{7}
```

である．

これを具体的に計算するため，デルタ関数を Fourier 積分で表す．

```math
\delta(q'-q'')
=\frac{1}{2\pi}
\int_{-\infty}^{\infty}
e^{ik(q'-q'')}\,dk
\tag{8}
```

平面波 $e^{ik(q'-q'')}$ に対して，

```math
\frac{\partial^2}{\partial q'^2}
e^{ik(q'-q'')}
=-k^2e^{ik(q'-q'')}
```

である．
したがって，

```math
\exp\left(
\frac{\beta\hbar^2}{2m}
\frac{\partial^2}{\partial q'^2}
\right)e^{ik(q'-q'')}
=
e^{-\beta\hbar^2k^2/(2m)}
e^{ik(q'-q'')}
```

となる．
式(8)を式(7)に代入すれば，

```math
\begin{aligned}
\langle q'|e^{-\beta\mathcal H}|q''\rangle
&=\frac{1}{2\pi}
\int_{-\infty}^{\infty}
\exp\left[
-\frac{\beta\hbar^2}{2m}k^2
+ik(q'-q'')
\right]dk
\end{aligned}
\tag{9}
```

を得る．

ここで，Gaussian 積分の公式

```math
\int_{-\infty}^{\infty}e^{-ak^2+bk}\,dk
=\sqrt{\frac{\pi}{a}}e^{b^2/(4a)}
\qquad(a>0)
```

を用いる．
式(9)では，

```math
a=\frac{\beta\hbar^2}{2m},
\qquad
b=i(q'-q'')
```

であるから，

```math
\begin{aligned}
\langle q'|e^{-\beta\mathcal H}|q''\rangle
&=\frac{1}{2\pi}
\sqrt{\frac{2\pi m}{\beta\hbar^2}}
\exp\left[
-\frac{m(q'-q'')^2}{2\beta\hbar^2}
\right]
\end{aligned}
```

となる．
よって，1次元の自由粒子の密度行列の行列要素は，

```math
\boxed{
\langle q'|e^{-\beta\mathcal H}|q''\rangle
=
\sqrt{\frac{m}{2\pi\beta\hbar^2}}
\exp\left[
-\frac{m(q'-q'')^2}{2\beta\hbar^2}
\right]
}
\tag{10}
```

である．

##### 2.2 3次元への拡張

位置をベクトル $\boldsymbol r$ ，運動量をベクトル $\boldsymbol p$ とする3次元の自由粒子では，

```math
\mathcal H=\frac{\boldsymbol p^2}{2m}
=-\frac{\hbar^2}{2m}\nabla'^2
```

である．
デルタ関数の Fourier 表示は

```math
\delta^{(3)}(\boldsymbol r'-\boldsymbol r'')
=\frac{1}{(2\pi)^3}
\int_{\mathbb R^3}
e^{i\boldsymbol k\cdot(\boldsymbol r'-\boldsymbol r'')}
\,d^3\boldsymbol k
```

となる．
ここで，

```math
\nabla'^2
e^{i\boldsymbol k\cdot(\boldsymbol r'-\boldsymbol r'')}
=-k^2e^{i\boldsymbol k\cdot(\boldsymbol r'-\boldsymbol r'')}
```

を利用すると，

```math
\begin{aligned}
&\langle\boldsymbol r'|e^{-\beta\mathcal H}|
\boldsymbol r''\rangle\\
&\quad=\frac{1}{(2\pi)^3}
\int_{\mathbb R^3}
\exp\left[
-\frac{\beta\hbar^2k^2}{2m}
+i\boldsymbol k\cdot(\boldsymbol r'-\boldsymbol r'')
\right]d^3\boldsymbol k
\end{aligned}
```

となる．
積分は3つの直交座標成分に分離できるため，1次元の Gaussian 積分を3回実行すればよい．
その結果，

```math
\boxed{
\begin{aligned}
&\langle\boldsymbol r'|e^{-\beta\mathcal H}|
\boldsymbol r''\rangle\\
&\qquad=
\left(\frac{m}{2\pi\beta\hbar^2}\right)^{3/2}
\exp\left[
-\frac{m|\boldsymbol r'-\boldsymbol r''|^2}
{2\beta\hbar^2}
\right]
\end{aligned}
}
\tag{11}
```

を得る．
これは解答例に示された3次元の結果である．
