# 演習問題【6-B-22】

## 解答

### Mie–Grüneisen の式と固体の熱膨張

#### 1．Mie–Grüneisen の式の導出

##### 1.1 固体の分配関数と自由エネルギー

原子数 $N$ の固体を考える．
体積を $V$ とし，原子が平衡位置にあるときの原子間ポテンシャルエネルギーを $\Phi(V)$ ，各基準振動の振動数を $\nu_j(V)$ とする．
振動モードの数は $3N-6$ である．

各振動モードを量子調和振動子として扱うと，量子数 $n_j=0,1,2,\ldots$ に対応する固体のエネルギーは

```math
E(V,\{n_j\})
=\Phi(V)+\sum_{j=1}^{3N-6}
\left(n_j+\frac12\right)h\nu_j(V)
\tag{1}
```

である．
ここで， $h$ は Planck 定数である．

温度 $T$ における分配関数は，すべての量子状態に対する Boltzmann 因子の和として定義される．
各振動モードの量子数は独立に変化するため，

```math
\begin{aligned}
Z(T,V,N)
&=\sum_{\{n_j\}}\exp\left[-\frac{E(V,\{n_j\})}{kT}\right]\\
&=e^{-\Phi(V)/(kT)}
\prod_{j=1}^{3N-6}
\sum_{n_j=0}^{\infty}
e^{-(n_j+1/2)h\nu_j/(kT)}
\end{aligned}
```

となる．
ここで $k$ は Boltzmann 定数である．
各モードについて等比級数を計算すると，

```math
\begin{aligned}
\sum_{n_j=0}^{\infty}
e^{-(n_j+1/2)h\nu_j/(kT)}
&=\frac{e^{-h\nu_j/(2kT)}}{1-e^{-h\nu_j/(kT)}}\\
&=\frac{1}{2\sinh\{h\nu_j/(2kT)\}}
\end{aligned}
```

を得る．
したがって，

```math
Z=e^{-\Phi(V)/(kT)}
\prod_{j=1}^{3N-6}
\frac{1}{2\sinh\{h\nu_j(V)/(2kT)\}}
\tag{2}
```

である．

Helmholtz 自由エネルギー $F=-kT\log Z$ は，

```math
F(T,V,N)
=\Phi(V)+kT\sum_{j=1}^{3N-6}
\log\left[2\sinh\left(\frac{h\nu_j(V)}{2kT}\right)\right]
\tag{3}
```

となる．

##### 1.2 圧力の導出

Helmholtz 自由エネルギーと圧力の関係は，

```math
p=-\left(\frac{\partial F}{\partial V}\right)_{T,N}
```

である．
式(3)を体積 $V$ で偏微分すると，

```math
p=-\frac{d\Phi}{dV}
-\sum_{j=1}^{3N-6}
\frac{h}{2}
\coth\left(\frac{h\nu_j}{2kT}\right)
\frac{d\nu_j}{dV}
\tag{4}
```

となる．
ここで， $\coth x=\cosh x/\sinh x$ である．

次に，角括弧内の双曲線関数を整理する．恒等式

```math
\coth x=1+\frac{2}{e^{2x}-1}
```

を用いると，

```math
\begin{aligned}
\frac{h\nu_j}{2}
\coth\left(\frac{h\nu_j}{2kT}\right)
&=\frac{h\nu_j}{2}
+\frac{h\nu_j}{e^{h\nu_j/(kT)}-1}
\end{aligned}
\tag{5}
```

である．
右辺は，角振動数 $\omega_j=2\pi\nu_j$ ではなく振動数 $\nu_j$ を用いた，各振動モードの平均エネルギーそのものである．
そこで，

```math
\epsilon_j
=\frac{h\nu_j}{2}
+\frac{h\nu_j}{e^{h\nu_j/(kT)}-1}
```

と定義し，振動モード全体の内部エネルギーを

```math
U(V,T,N)=\sum_{j=1}^{3N-6}\epsilon_j
\tag{6}
```

とおく．
式(4)は，

```math
p=-\frac{d\Phi}{dV}
-\sum_{j=1}^{3N-6}
\epsilon_j\frac{d\log\nu_j}{dV}
\tag{7}
```

と書き直せる．

ここで，Grüneisen の仮定は，

```math
\frac{\partial\log\nu_j}{\partial\log V}
=-\gamma
```

である．
したがって，

```math
\frac{d\log\nu_j}{dV}=-\frac{\gamma}{V}
```

となる．
これを式(7)に代入すると，

```math
\begin{aligned}
p
&=-\frac{d\Phi}{dV}
+\frac{\gamma}{V}\sum_{j=1}^{3N-6}\epsilon_j\\
&=-\frac{d\Phi}{dV}+\gamma\frac{U}{V}
\end{aligned}
```

を得る．
ゆえに，

```math
\boxed{
p=-\frac{d\Phi}{dV}+\gamma\frac{U}{V}
}
\tag{8}
```

が示された．
これが Mie–Grüneisen の式である．

##### 1.3 各項の物理的意味

式(8)の第1項，

```math
-\frac{d\Phi}{dV}
```

は，原子が平衡位置に静止している場合のポテンシャルエネルギーの体積依存性から生じる圧力である．
ポテンシャルエネルギーが最小になる体積では $d\Phi/dV=0$ となるため，この項はゼロとなる．
その体積から膨張・圧縮すると，原子間結合による復元作用が圧力として現れる．

第2項，

```math
\gamma\frac{U}{V}
```

は，原子の振動に由来する圧力である．
Grüneisen の仮定では $\nu_j\propto V^{-\gamma}$ であるため，体積を小さくすると振動数が増加する．
振動エネルギーが体積に依存することで圧力が生じ，その大きさは振動による内部エネルギー $U$ に比例する．
ここで $U$ には，熱励起によるエネルギーだけでなく，零点エネルギーも含まれる．

#### 2．熱膨張係数の導出

##### 2.1 与えられたポテンシャルエネルギーを使う

ポテンシャルエネルギーが

```math
\Phi(V)=\frac12\frac{(V-V_0)^2}{\kappa_0V_0}
```

で与えられるとする．
ここで， $\kappa_0$ と $V_0$ は定数である．
体積微分すると，

```math
\frac{d\Phi}{dV}
=\frac{V-V_0}{\kappa_0V_0}
```

となるため，式(8)は

```math
\boxed{
p=-\frac{V-V_0}{\kappa_0V_0}
+\gamma\frac{U}{V}
}
\tag{9}
```

となる．

定圧体膨張係数 $\alpha$ と定積熱容量 $C_V$ を，

```math
\alpha=\frac1V\left(\frac{\partial V}{\partial T}\right)_{p,N},
\qquad
C_V=\left(\frac{\partial U}{\partial T}\right)_{V,N}
\tag{10}
```

と定義する．

圧力 $p$ を一定に保って温度 $T$ を変化させると，体積 $V$ も変化する．
式(9)を $T$ で全微分すると，

```math
\begin{aligned}
0={}&-\frac{1}{\kappa_0V_0}
\left(\frac{\partial V}{\partial T}\right)_{p,N}\\
&+\gamma\left[
\frac{1}{V}\left(\frac{\partial U}{\partial T}\right)_{V,N}
+\left\{
\frac{1}{V}\left(\frac{\partial U}{\partial V}\right)_{T,N}
-\frac{U}{V^2}
\right\}
\left(\frac{\partial V}{\partial T}\right)_{p,N}
\right]
\end{aligned}
\tag{11}
```

を得る．
ここで，

```math
\left(\frac{\partial V}{\partial T}\right)_{p,N}
=\alpha V,
\qquad
\left(\frac{\partial U}{\partial T}\right)_{V,N}=C_V
```

であるから，式(11)は

```math
0=-\frac{\alpha V}{\kappa_0V_0}
+\gamma\frac{C_V}{V}
+\gamma\alpha
\left[
\left(\frac{\partial U}{\partial V}\right)_{T,N}
-\frac{U}{V}
\right]
```

となる．
これを整理すると，

```math
\boxed{
\alpha\left[
\frac{V}{\kappa_0V_0}
+\gamma\left\{
\frac{U}{V}
-\left(\frac{\partial U}{\partial V}\right)_{T,N}
\right\}
\right]
=\gamma\frac{C_V}{V}
}
\tag{12}
```

を得る．

##### 2.2 振動エネルギーの体積依存性を求める

式(12)を整理するために，内部エネルギー $U$ の体積微分を求める．
各振動モードの平均エネルギーは，

```math
\epsilon_j
=\frac{h\nu_j}{2}
+\frac{h\nu_j}{e^{h\nu_j/(kT)}-1}
```

である．
この式を振動数 $\nu_j$ で微分する．
ここで，

```math
x_j=\frac{h\nu_j}{kT}
```

とおくと，

```math
\frac{\partial\epsilon_j}{\partial\log\nu_j}
=\nu_j\frac{\partial\epsilon_j}{\partial\nu_j}
=\epsilon_j
-kT\,x_j^2\frac{e^{x_j}}{(e^{x_j}-1)^2}
\tag{13}
```

となる．
一方，各モードの定積熱容量を

```math
c_{Vj}
=kx_j^2\frac{e^{x_j}}{(e^{x_j}-1)^2}
```

と定義すると，式(13)は

```math
\nu_j\frac{\partial\epsilon_j}{\partial\nu_j}
=\epsilon_j-Tc_{Vj}
```

である．
これを全振動モードについて合計すれば，

```math
\sum_j c_{Vj}=C_V
```

より，

```math
\sum_j\nu_j\frac{\partial\epsilon_j}{\partial\nu_j}
=U-TC_V
\tag{14}
```

となる．

Grüneisen の仮定を用いると，

```math
\frac{d\nu_j}{dV}=-\gamma\frac{\nu_j}{V}
```

であるから，連鎖律により，

```math
\begin{aligned}
\left(\frac{\partial U}{\partial V}\right)_{T,N}
&=\sum_j\frac{\partial\epsilon_j}{\partial\nu_j}
\frac{d\nu_j}{dV}\\
&=-\frac{\gamma}{V}
\sum_j\nu_j\frac{\partial\epsilon_j}{\partial\nu_j}\\
&=-\frac{\gamma}{V}(U-TC_V)
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\left(\frac{\partial U}{\partial V}\right)_{T,N}
=\frac{\gamma}{V}(TC_V-U)
}
\tag{15}
```

である．
なお，式(15)の $TC_V$ はエネルギーの次元をもち， $U$ と整合する．

##### 2.3 熱膨張係数の一般式

式(15)を式(12)に代入すると，

```math
\begin{aligned}
\alpha\bigg[
\frac{V}{\kappa_0V_0}
+\frac{\gamma U}{V}
+\frac{\gamma^2(U-TC_V)}{V}
\bigg]
=\gamma\frac{C_V}{V}
\end{aligned}
\tag{16}
```

を得る．

一方，状態方程式(9)から，

```math
\frac{\gamma U}{V}
=p+\frac{V-V_0}{\kappa_0V_0}
\tag{17}
```

である．
式(17)を式(16)に代入し，体積に関する項を整理する．

```math
\frac{V}{\kappa_0V_0}
=\frac{1}{\kappa_0}
+\frac{V-V_0}{\kappa_0V_0}
```

であることに注意すると，

```math
\boxed{
\alpha=
\frac{\gamma C_V/V}
{\displaystyle
\frac{1}{\kappa_0}
+(1+\gamma)p
+(2+\gamma)\frac{V-V_0}{\kappa_0V_0}
-\gamma^2\frac{C_VT}{V}}
}
\tag{18}
```

となる．

##### 2.4 圧力 $p=0$ における熱膨張

ここで，外圧を $p=0$ とする．
さらに，体積ひずみが小さく，

```math
\left|\frac{V-V_0}{V_0}\right|\ll1
```

であり，問題文の条件

```math
\frac{\kappa_0 C_VT}{V_0}\ll1
```

が満たされるとする．
$\gamma$ は通常1から3程度の値であるため，これらの条件のもとでは，式(18)の分母にある

```math
(2+\gamma)\frac{V-V_0}{\kappa_0V_0},
\qquad
\gamma^2\frac{C_VT}{V}
```

の項は， $1/\kappa_0$ に比べて十分小さいとみなせる．
また，体積ひずみが小さいことから $V\simeq V_0$ と近似できる．
したがって，式(18)は

```math
\alpha\simeq
\frac{\gamma C_V/V_0}{1/\kappa_0}
```

となり，

```math
\boxed{
\alpha\simeq\frac{\gamma\kappa_0}{V_0}C_V
}
\tag{19}
```

を得る．

すなわち，この近似の範囲では， **定圧体膨張係数 $\alpha$ は定積熱容量 $C_V$ に比例する** ．
また， $\gamma>0$ ， $\kappa_0>0$ ， $C_V>0$ であるため，熱膨張係数は正となる．
温度上昇に伴って振動エネルギーが増加すると，振動による圧力が増し，外圧を一定に保つために体積が増加するという物理的描像に対応する．
