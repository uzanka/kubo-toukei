# 演習問題【6-A-4】

## 解答

### 1．回転座標系におけるハミルトニアン

半径 $R$ ，長さ $L$ の円筒が，中心軸の周りに一定の角速度 $\omega$ で回転している．
この円筒内に，質量 $m$ の粒子が $N$ 個入っており，気体は絶対温度 $T$ で熱平衡にあるものとする．
重力の影響は無視する．

円筒の中心軸を $z$ 軸とし，粒子 $j$ の位置を $(x_j,y_j,z_j)$ ，正準運動量を $(p_{xj},p_{yj},p_{zj})$ とする．
静止系における粒子1個のハミルトニアンは，

```math
\mathcal H_j
=\frac{p_{xj}^2+p_{yj}^2+p_{zj}^2}{2m}
+\phi(x_j,y_j,z_j)
```

である．
ここで， $\phi$ は円筒の壁によるポテンシャルであり，円筒内部では $0$ ，外部では $+\infty$ である．
すなわち，

```math
\phi(x,y,z)=
\begin{cases}
0 & (x^2+y^2\leq R^2,\ 0\leq z\leq L)\\
+\infty & (\text{円筒の外部})
\end{cases}
```

である．

回転座標系におけるハミルトニアンは，静止系のハミルトニアンから角速度と角運動量の積を差し引いたものである．

```math
\mathcal H^*=\mathcal H-\omega L_z
```

ここで $L_z$ は $z$ 軸周りの全角運動量であり，

```math
L_z=\sum_{j=1}^{N}(x_jp_{yj}-y_jp_{xj})
```

と表される．
したがって，全系のハミルトニアンは，

```math
\boxed{
\mathcal H^*
=\sum_{j=1}^{N}
\left[
\frac{p_{xj}^2+p_{yj}^2+p_{zj}^2}{2m}
+\phi(x_j,y_j,z_j)
-\omega(x_jp_{yj}-y_jp_{xj})
\right]
}
\tag{1}
```

となる．

### 2．分配関数の計算

#### 2.1 単一粒子の分配関数

逆温度を

```math
\beta=\frac{1}{kT}
```

と定義する．
ここで $k$ はボルツマン定数である．
古典統計力学における単一粒子の分配関数 $z_1$ は，相空間全体にわたる積分として，

```math
z_1=\frac{1}{h^3}
\int_{\text{円筒内}}d^3r
\int_{-\infty}^{\infty}d^3p\,
e^{-\beta\mathcal H_1^*}
\tag{2}
```

と書ける．
ここで $h$ はプランク定数であり， $d^3r=dx\,dy\,dz$ ， $d^3p=dp_x\,dp_y\,dp_z$ である．

まず，回転座標系における単一粒子のハミルトニアンを平方完成する．
円筒内部では $\phi=0$ であるから，

```math
\begin{aligned}
\mathcal H_1^*
&=\frac{p_x^2+p_y^2+p_z^2}{2m}
-\omega(xp_y-yp_x)\\
&=\frac{(p_x+m\omega y)^2
+(p_y-m\omega x)^2+p_z^2}{2m}\\
&\qquad-\frac12m\omega^2(x^2+y^2)
\end{aligned}
\tag{3}
```

となる．
円筒座標を $(r,\varphi,z)$ とすれば， $r^2=x^2+y^2$ であるため，

```math
\mathcal H_1^*
=\frac{(p_x+m\omega y)^2
+(p_y-m\omega x)^2+p_z^2}{2m}
-\frac12m\omega^2r^2
\tag{4}
```

と表せる．

式 (4) から，運動量に関する積分は，位置 $(x,y,z)$ を固定して実行できる．
その際，

```math
P_x=p_x+m\omega y,\qquad
P_y=p_y-m\omega x,\qquad
P_z=p_z
```

と変数変換する．
この変換のヤコビアンは $1$ であるため，積分値は変わらない．
よって，

```math
\begin{aligned}
&\int_{-\infty}^{\infty}d^3p\,
e^{-\beta\mathcal H_1^*}\\
&\quad=
e^{\beta m\omega^2r^2/2}
\iiint_{-\infty}^{\infty}
e^{-\beta(P_x^2+P_y^2+P_z^2)/(2m)}
\,dP_x\,dP_y\,dP_z
\end{aligned}
```

となる．

ここで，ガウス積分の公式

```math
\int_{-\infty}^{\infty}e^{-ap^2}\,dp
=\sqrt{\frac{\pi}{a}}
\qquad(a>0)
```

を用いると，

```math
\begin{aligned}
&\iiint_{-\infty}^{\infty}
e^{-\beta(P_x^2+P_y^2+P_z^2)/(2m)}
\,d^3P\\
&\quad=\left(\frac{2\pi m}{\beta}\right)^{3/2}
=(2\pi mkT)^{3/2}
\end{aligned}
```

を得る．
したがって，運動量積分は，

```math
\boxed{
\int d^3p\,e^{-\beta\mathcal H_1^*}
=(2\pi mkT)^{3/2}
e^{m\omega^2r^2/(2kT)}
}
\tag{5}
```

となる．

この式を式 (2) に代入し，円筒座標の体積要素

```math
d^3r=r\,dr\,d\varphi\,dz
```

を用いると，

```math
\begin{aligned}
z_1
&=\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\int_0^L dz\int_0^{2\pi}d\varphi
\int_0^R r
e^{m\omega^2r^2/(2kT)}\,dr
\end{aligned}
\tag{6}
```

となる．

#### 2.2 空間積分

指数関数の中の定数を

```math
a=\frac{m\omega^2}{2kT}
```

と置く．
半径方向の積分は，

```math
\int_0^R r e^{ar^2}\,dr
=\frac{1}{2a}(e^{aR^2}-1)
```

である．
実際， $u=ar^2$ と置けば $du=2ar\,dr$ であるため，この式が得られる．

したがって，

```math
\begin{aligned}
&\int_0^L dz\int_0^{2\pi}d\varphi
\int_0^R r e^{ar^2}\,dr\\
&\quad=2\pi L\frac{1}{2a}(e^{aR^2}-1)\\
&\quad=\frac{2\pi LkT}{m\omega^2}
\left[
\exp\left(\frac{m\omega^2R^2}{2kT}\right)-1
\right]
\end{aligned}
\tag{7}
```

となる．
よって，式 (6)，(7) から，単一粒子の分配関数は，

```math
\boxed{
\begin{aligned}
z_1={}&
\left(\frac{2\pi mkT}{h^2}\right)^{3/2}
\frac{2\pi LkT}{m\omega^2}\\
&\times
\left[
\exp\left(\frac{m\omega^2R^2}{2kT}\right)-1
\right]
\end{aligned}
}
\tag{8}
```

である．

#### 2.3 粒子 $N$ 個の分配関数

理想気体では粒子間の相互作用を無視できるため，粒子 $N$ 個の分配関数は，単一粒子の分配関数を用いて，

```math
\boxed{
Z=\frac{z_1^N}{N!}
}
\tag{9}
```

と書ける．
ここで $1/N!$ は，同種粒子の区別による重複を除く因子である．

### 3．密度分布の導出

#### 3.1 密度の定義

位置 $\mathbf r=(x,y,z)$ における質量密度を $\rho(\mathbf r)$ とする．
微視的な質量密度は，Dirac のデルタ関数を用いて，

```math
\hat\rho(\mathbf r)
=m\sum_{j=1}^{N}
\delta^{(3)}(\mathbf r-\mathbf r_j)
\tag{10}
```

と表せる．
ここで $\delta^{(3)}$ は3次元の Dirac のデルタ関数である．
求める密度分布は，この量をカノニカル分布で平均したものである．

粒子は互いに相互作用しない同種粒子であるため，どの粒子についても同じ位置分布を持つ．
したがって，

```math
\rho(\mathbf r)
=Nm\,P(\mathbf r)
\tag{11}
```

と表せる．
ここで $P(\mathbf r)$ は，1個の粒子が位置 $\mathbf r$ の単位体積当たりに存在する確率密度である．

単一粒子の分配関数における運動量積分は式 (5) で与えられるので，

```math
P(\mathbf r)
=\frac{(2\pi mkT)^{3/2}h^{-3}
e^{m\omega^2r^2/(2kT)}}{z_1}
\tag{12}
```

となる．
式 (8) と比較すると，これは，

```math
P(\mathbf r)
=\frac{
e^{m\omega^2r^2/(2kT)}
}{
\displaystyle
\int_{\text{円筒内}}
e^{m\omega^2r'^2/(2kT)}\,d^3r'
}
\tag{13}
```

と書ける．
この式は，粒子の位置分布が $e^{m\omega^2r^2/(2kT)}$ に比例し，円筒全体で積分すると確率が $1$ になるよう規格化されることを表している．

#### 3.2 密度分布の規格化

式 (7) より，式 (13) の分母は，

```math
\begin{aligned}
&\int_{\text{円筒内}}
e^{m\omega^2r'^2/(2kT)}\,d^3r'\\
&\quad=\frac{2\pi LkT}{m\omega^2}
\left[
\exp\left(\frac{m\omega^2R^2}{2kT}\right)-1
\right]
\end{aligned}
\tag{14}
```

である．
式 (11)，(13)，(14) を組み合わせると，

```math
\begin{aligned}
\rho(r)
&=\frac{Nm}{
\displaystyle
\frac{2\pi LkT}{m\omega^2}
\left[
\exp\left(\frac{m\omega^2R^2}{2kT}\right)-1
\right]
}
e^{m\omega^2r^2/(2kT)}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\rho(r)=
\frac{Nm^2\omega^2}{
2\pi LkT
\left[
\exp\left(\frac{m\omega^2R^2}{2kT}\right)-1
\right]
}
\exp\left(\frac{m\omega^2r^2}{2kT}\right)
}
\tag{15}
```

を得る．
これは円筒の内部 $0\leq r\leq R$ ， $0\leq z\leq L$ で成立し，円筒外部では $\rho=0$ である．

さらに，式 (15) は解答例と同じ形で，

```math
\boxed{
\begin{aligned}
\rho(x,y,z)
={}&\frac{Nm}{\pi R^2L}\\
&\times
\frac{
\exp\left[\dfrac{m\omega^2}{2kT}(x^2+y^2)\right]
}{
\dfrac{2kT}{m\omega^2R^2}
\left[
\exp\left(\dfrac{m\omega^2R^2}{2kT}\right)-1
\right]
}
\end{aligned}
}
\tag{16}
```

とも表される．
したがって，密度は中心軸からの距離 $r$ が大きくなるほど指数関数的に増加する．

なお， $\omega=0$ の場合には式 (15) の極限をとればよく，

```math
\boxed{
\rho=\frac{Nm}{\pi R^2L}
}
```

となる．
これは重力も回転もない円筒内で，質量密度が一様であることに対応する．

### 4．物理的な意味

式 (4) のハミルトニアンには，

```math
-\frac12m\omega^2r^2
```

という項が現れる．
これは回転系での遠心力に対応する有効ポテンシャルである．
遠心力は粒子を回転軸から遠ざける向きにはたらくため，回転系でのカノニカル分布には，

```math
\exp\left(\frac{m\omega^2r^2}{2kT}\right)
```

という因子が現れる．
その結果，気体の密度は中心軸付近で小さく，円筒の外壁に近い領域で大きくなる．

また，運動量積分の平方完成では，角運動量に由来する項はガウス積分の中心をずらすだけである．
積分領域が運動量空間全体であるため，この平行移動は積分値に影響しない．
したがって，平衡密度分布は遠心力に対応する有効ポテンシャルによって決まり，コリオリの力に関係する運動量の結合項は，運動量を積分した後の密度分布に独立した因子としては残らない．
