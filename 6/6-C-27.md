# 演習問題【6-C-27】

## 解答

### Bohr–van Leeuwen の定理の証明

#### 1．磁場中のハミルトニアンと分配関数

磁場中にある $N$ 個の古典的荷電粒子からなる系を考える．
第 $j$ 粒子の質量を $m_j$ ，電荷を $e_j$ ，位置を $\boldsymbol r_j$ ，正準運動量を $\boldsymbol p_j$ とする．
磁場を導くベクトルポテンシャルを $\boldsymbol A(\boldsymbol r_j)$ とすれば，ハミルトニアンは

```math
\mathscr H
=\sum_{j=1}^{N}
\frac{1}{2m_j}
\left[
\boldsymbol p_j+
\frac{e_j}{c}\boldsymbol A(\boldsymbol r_j)
\right]^2
+U(\boldsymbol r_1,\ldots,\boldsymbol r_N)
\tag{1}
```

である．
ここで， $c$ は光速， $U$ は粒子間相互作用のポテンシャルエネルギーであり，磁場に陽には依存しないものとする．

温度 $T$ における古典的なカノニカル分配関数は，

```math
Z=\frac{1}{N!h^{3N}}
\int
e^{-\beta\mathscr H}
\prod_{j=1}^{N}d^3\boldsymbol p_j\,d^3\boldsymbol r_j
\tag{2}
```

と書ける．
ここで，

```math
\beta=\frac{1}{kT}
```

であり， $k$ は Boltzmann 定数， $h$ は Planck 定数である．
因子 $1/N!$ は同種の粒子を数える場合のものであり，今回の証明にはこの因子の有無は影響しない．

#### 2．運動量積分から磁場依存性が消えることを示す

式(1)を式(2)に代入すると，運動量に依存する項と位置のみに依存する項を分離できる．
したがって，

```math
\begin{aligned}
Z={}&\frac{1}{N!h^{3N}}
\int e^{-\beta U(\boldsymbol r_1,\ldots,\boldsymbol r_N)}
\\
&\quad\times
\prod_{j=1}^{N}
\left[
\int
\exp\left\{
-\frac{\beta}{2m_j}
\left(
\boldsymbol p_j+
\frac{e_j}{c}\boldsymbol A(\boldsymbol r_j)
\right)^2
\right\}
d^3\boldsymbol p_j
\right]
\prod_{j=1}^{N}d^3\boldsymbol r_j
\end{aligned}
\tag{3}
```

となる．

ここで，第 $j$ 粒子の運動量積分を考える．
位置 $\boldsymbol r_j$ を固定したとき， $\boldsymbol A(\boldsymbol r_j)$ は運動量に依存しないため，

```math
\boldsymbol p_j'
=\boldsymbol p_j+
\frac{e_j}{c}\boldsymbol A(\boldsymbol r_j)
\tag{4}
```

という変数変換ができる．
この変換は運動量空間における平行移動であるから，ヤコビアンは1であり，

```math
d^3\boldsymbol p_j'=d^3\boldsymbol p_j
```

となる．
また，運動量積分の範囲は全空間であるため，変数変換によって積分範囲も変化しない．

したがって，

```math
\begin{aligned}
I_j
&=\int
\exp\left[
-\frac{\beta}{2m_j}
\left(
\boldsymbol p_j+
\frac{e_j}{c}\boldsymbol A(\boldsymbol r_j)
\right)^2
\right]d^3\boldsymbol p_j\\
&=\int
\exp\left(
-\frac{\beta|\boldsymbol p_j'|^2}{2m_j}
\right)d^3\boldsymbol p_j'
\end{aligned}
\tag{5}
```

である．
右辺はベクトルポテンシャルを含まない通常のガウス積分である．
3次元のガウス積分を実行すると，

```math
\begin{aligned}
I_j
&=\left[
\int_{-\infty}^{\infty}
\exp\left(-\frac{\beta p^2}{2m_j}\right)dp
\right]^3\\
&=\left(\frac{2\pi m_j}{\beta}\right)^{3/2}\\
&=(2\pi m_j kT)^{3/2}
\end{aligned}
\tag{6}
```

を得る．
重要なのは，この結果が $\boldsymbol A$ に依存しないことである．

式(6)を式(3)に代入すると，分配関数は

```math
\boxed{
Z=
\frac{1}{N!h^{3N}}
\left[
\prod_{j=1}^{N}(2\pi m_j kT)^{3/2}
\right]
\int
e^{-\beta U(\boldsymbol r_1,\ldots,\boldsymbol r_N)}
\prod_{j=1}^{N}d^3\boldsymbol r_j
}
\tag{7}
```

となる．
右辺には磁場 $\boldsymbol H$ もベクトルポテンシャル $\boldsymbol A$ も現れない．
したがって，分配関数 $Z$ は磁場に依存しない．

#### 3．自由エネルギーと磁化率

Helmholtz 自由エネルギーは，

```math
F=-kT\log Z
\tag{8}
```

で定義される．
分配関数 $Z$ が磁場に依存しないため，

```math
\left(\frac{\partial F}{\partial\boldsymbol H}\right)_{T,V,N}
=-kT
\left(\frac{\partial\log Z}{\partial\boldsymbol H}\right)_{T,V,N}
=\boldsymbol 0
\tag{9}
```

である．

自由エネルギーと磁化の関係

```math
\boldsymbol M
=-\left(\frac{\partial F}{\partial\boldsymbol H}\right)_{T,V,N}
```

を用いると，

```math
\boxed{
\boldsymbol M=\boldsymbol 0
}
\tag{10}
```

となる．
したがって，磁場に対する磁化率も

```math
\boxed{
\chi_{ab}
=\left(\frac{\partial M_a}{\partial H_b}\right)_{T,V,N}
=0
}
\tag{11}
```

である．
ここで， $a,b$ は磁化と磁場の成分を表す添字である．

以上より， **古典力学と古典統計に従い，ハミルトニアンが式(1)で与えられる荷電粒子系では，磁化も磁化率も厳密にゼロである** ．
これが Bohr–van Leeuwen の定理である．
