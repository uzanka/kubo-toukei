# 演習問題【6-C-27】

## 解答

磁場 $\boldsymbol{H}$ が存在する場合の荷電粒子系のハミルトニアン $\mathscr{H}$ は，ベクトルポテンシャル $\boldsymbol{A}(\boldsymbol{r}_j)$ を用いて以下のように書かれる．

```math
\mathscr{H} = \sum_{j=1}^{N} \frac{1}{2m_j} \left\{ \boldsymbol{p}_j + \frac{e_j}{c} \boldsymbol{A}(\boldsymbol{r}_j) \right\}^2 + U(\boldsymbol{r}_1, \dots, \boldsymbol{r}_N)
```

ここで， $m_j$ は $j$ 番目の粒子の質量， $e_j$ はその電荷， $U(\boldsymbol{r}_1, \dots, \boldsymbol{r}_N)$ は粒子間の相互作用によるポテンシャルエネルギーである．

古典統計力学における系の分配関数 $Z$ は，位相空間全体にわたる次のような積分で与えられる．

$$Z = \frac{1}{N! h^{3N}} \int \dots \int \exp \left( -\beta \mathscr{H} \right) d\boldsymbol{r}_1 \dots d\boldsymbol{r}_N d\boldsymbol{p}_1 \dots d\boldsymbol{p}_N$$

ここで， $\beta = \frac{1}{kT}$ （ $k$ はボルツマン定数， $T$ は絶対温度）である．

この積分を，位置座標 $\boldsymbol{r}_j$ に関する積分と運動量 $\boldsymbol{p}_j$ に関する積分に分離して考える．

```math
\exp(-\beta \mathscr{H}) = \exp\left( -\beta \sum_{j=1}^N \frac{1}{2m_j} \left\{ \boldsymbol{p}_j + \frac{e_j}{c} \boldsymbol{A}(\boldsymbol{r}_j) \right\}^2 \right) \exp(-\beta U(\boldsymbol{r}_1, \dots, \boldsymbol{r}_N))
```

であるから，分配関数は次のように書ける．

```math
Z = \frac{1}{N! h^{3N}} \int \dots \int \exp(-\beta U(\boldsymbol{r}_1, \dots, \boldsymbol{r}_N)) \left[ \prod_{j=1}^{N} \int \exp \left( -\frac{\beta}{2m_j} \left\{ \boldsymbol{p}_j + \frac{e_j}{c} \boldsymbol{A}(\boldsymbol{r}_j) \right\}^2 \right) d\boldsymbol{p}_j \right] d\boldsymbol{r}_1 \dots d\boldsymbol{r}_N
```

ここで，各粒子 $j$ についての運動量積分 $I_j$ を計算する．

```math
I_j = \int \exp \left( -\frac{\beta}{2m_j} \left\{ \boldsymbol{p}_j + \frac{e_j}{c} \boldsymbol{A}(\boldsymbol{r}_j) \right\}^2 \right) d\boldsymbol{p}_j
```

ここで， $\boldsymbol{p}'_j = \boldsymbol{p}_j + \frac{e_j}{c} \boldsymbol{A}(\boldsymbol{r}_j)$ という変数の変換を行う．
このとき，ヤコビアンは $1$ であり，積分範囲は全空間であるから， $d\boldsymbol{p}_j = d\boldsymbol{p}'_j$ となる．
したがって，

$$I_j = \int \exp \left( -\frac{\beta}{2m_j} (\boldsymbol{p}'_j)^2 \right) d\boldsymbol{p}'_j$$

となる．
これは標準的なガウス積分であり，3次元空間全体での積分は次のようになる．

$$I_j = \left( \int_{-\infty}^{\infty} \exp \left( -\frac{\beta p'^2}{2m_j} \right) dp' \right)^3 = \left( \sqrt{\frac{2\pi m_j}{\beta}} \right)^3 = (2\pi m_j kT)^{3/2}$$

重要な点は，この積分結果 $I_j$ がベクトルポテンシャル $\boldsymbol{A}(\boldsymbol{r}_j)$ に依存しないということである．

これを用いると，全体の分配関数 $Z$ は以下のように整理される．

$$Z = \frac{1}{N! h^{3N}} \left[ \prod_{j=1}^{N} (2\pi m_j kT)^{3/2} \right] \int \dots \int \exp(-\beta U(\boldsymbol{r}_1, \dots, \boldsymbol{r}_N)) d\boldsymbol{r}_1 \dots d\boldsymbol{r}_N$$

この式において，右辺の積分項および係数部分は磁場 $\boldsymbol{H}$（およびそれに付随する $\boldsymbol{A}$ ）に依存しない．
したがって，分配関数 $Z$ は磁場 $\boldsymbol{H}$ に対して不変である．

系のヘルムホルツの自由エネルギー $F$ は $F = -kT \ln Z$ で与えられるため， $\boldsymbol{H}$ に関する偏微分は次のように求まる．

$$\frac{\partial F}{\partial \boldsymbol{H}} = -kT \frac{\partial (\ln Z)}{\partial \boldsymbol{H}} = -kT \frac{1}{Z} \frac{\partial Z}{\partial \boldsymbol{H}}$$

$Z$ は $\boldsymbol{H}$ に依存しないので， $\frac{\partial Z}{\partial \boldsymbol{H}} = 0$ であり，したがって $\frac{\partial F}{\partial \boldsymbol{H}} = 0$ である．
磁化 $\boldsymbol{M}$ と自由エネルギーの関係式 $\boldsymbol{M} = -\left( \frac{\partial F}{\partial \boldsymbol{H}} \right)_{T,V}$ を用いると，

$$\boldsymbol{M} = 0$$

であることが証明された．

## 解説

Bohr-van Leeuwenの定理は，古典統計力学の枠組みにおいては，磁場が存在しても荷電粒子の磁化が必ずゼロになることを示している．

この物理的な理由は，ハミルトニアンが運動量 $\boldsymbol{p}$ の2次形式であり，磁場による補正項 $\frac{e_j}{c}\boldsymbol{A}$ が運動量の中心をずらすだけで，運動量空間における積分値（つまり，粒子の運動状態の統計的な重み）を変えないことにある．
具体的には，運動量 $\boldsymbol{p}$ の積分において， $\boldsymbol{p} + \text{定数}$ という変数変換を行っても，積分範囲が全空間であれば積分結果は変わらない．

量子力学においては，エネルギー準位が磁場によって変化（ゼーマン効果など）し，それによって統計的な重みが変わるため，磁化が生じる．
しかし，古典力学ではこの「ずれ」が統計的な結果に影響を及ぼさないため，磁性は現れないのである．
