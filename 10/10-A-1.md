# 演習問題【10-A-1】

## 解答

一様な大きな体系の中から，分子数が一定の部分を取り出し，その部分における熱力学的変数の平衡値からのゆらぎを考える．
平衡状態の近傍では，ゆらぎが十分小さいとき，その確率分布は Gaussian 分布で近似できる．
この性質を利用して，(i) 確率分布の一般形，(ii) 体積と温度のゆらぎ，(iii) 圧力のゆらぎを求める．

以下では，平衡値を表す量に $^{\ast}$ を付け， $C_V$ と $C_p$ は考えている部分全体の定積熱容量，定圧熱容量を表すものとする．

### (i) ゆらぎの確率分布の一般形

#### 1．最小仕事と内部エネルギーの展開

内部エネルギーを $U=U(S,V)$ とする．
平衡状態 $(S^{\ast},V^{\ast})$ から，エントロピーと体積がそれぞれ $\Delta S,\Delta V$ だけ変化した状態を考える．
この変化に対応する最小仕事は，

```math
W_{\min}
=\Delta U-T^*\Delta S+p^*\Delta V
\tag{1}
```

と表される．

ここで，内部エネルギーの変化を平衡状態のまわりで二次まで Taylor 展開すると，

```math
\begin{aligned}
\Delta U
={}&\left(\frac{\partial U}{\partial S}\right)^*\Delta S
+\left(\frac{\partial U}{\partial V}\right)^*\Delta V\\
&+\frac{1}{2}\left\{
\left(\frac{\partial^2U}{\partial S^2}\right)^*(\Delta S)^2
+2\left(\frac{\partial^2U}{\partial S\partial V}\right)^*
\Delta S\Delta V
+\left(\frac{\partial^2U}{\partial V^2}\right)^*(\Delta V)^2
\right\}
+\cdots
\end{aligned}
\tag{2}
```

となる．
熱力学の基本関係式

```math
dU=T\,dS-p\,dV
```

から，

```math
\left(\frac{\partial U}{\partial S}\right)^*=T^*,
\qquad
\left(\frac{\partial U}{\partial V}\right)^*=-p^*
```

である．
よって式（2）の一次の項を式（1）に代入すると相殺され，

```math
\begin{aligned}
W_{\min}
=\frac12\biggl\{
&\left(\frac{\partial^2U}{\partial S^2}\right)^*(\Delta S)^2\\
&+2\left(\frac{\partial^2U}{\partial S\partial V}\right)^*
\Delta S\Delta V\\
&+\left(\frac{\partial^2U}{\partial V^2}\right)^*(\Delta V)^2
\biggr\}
\end{aligned}
\tag{3}
```

を得る．

#### 2．温度と圧力の変化を用いた表現

温度と圧力は，

```math
T=\left(\frac{\partial U}{\partial S}\right)_V,
\qquad
p=-\left(\frac{\partial U}{\partial V}\right)_S
```

で定義される．
平衡状態の近傍で一次まで展開すると，

```math
\Delta T
=\left(\frac{\partial^2 U}{\partial S^2}\right)^*\Delta S
+\left(\frac{\partial^2 U}{\partial S\partial V}\right)^*
\Delta V
\tag{4}
```

および

```math
-\Delta p
=\left(\frac{\partial^2 U}{\partial V\partial S}\right)^*\Delta S
+\left(\frac{\partial^2 U}{\partial V^2}\right)^*\Delta V
\tag{5}
```

となる．
混合二階偏微分の等しさを用いると，式（3）の二次形式は，

```math
\boxed{
W_{\min}
=\frac{1}{2}(\Delta T\,\Delta S-\Delta p\,\Delta V)
}
\tag{6}
```

と書き換えられる．
ここでは，ゆらぎの二次までを考えているため， $\Delta T,\Delta p$ は一次の変化として扱っている．

#### 3．確率分布の導出

例題［1］の結果によれば，平衡状態から小さくずれた状態の確率は，最小仕事 $W_{\min}$ を用いて，

```math
P\propto \exp\left(-\frac{W_{\min}}{kT^*}\right)
```

と表される．
式（6）を代入し，規格化定数を $C$ とすると，

```math
\boxed{
P(\alpha')
=C\exp\left[
\frac{1}{2kT^*}
(\Delta p\,\Delta V-\Delta T\,\Delta S)
\right]
}
```

を得る．
これが求める一般形である．
この式は，平衡状態の近傍でゆらぎを二次まで近似した結果であり，確率分布の指数が二次形式になることから Gaussian 分布が得られる．

### (ii) $\overline{(\Delta V)^2}$ ， $\overline{\Delta V\Delta T}$ ， $\overline{(\Delta T)^2}$ の導出

### 1．圧力とエントロピーの変化を表す

独立変数として $V,T$ を選ぶ．
平衡状態の近傍で圧力の変化は，

```math
\Delta p
=\left(\frac{\partial p}{\partial V}\right)_T^*\Delta V
+\left(\frac{\partial p}{\partial T}\right)_V^*\Delta T
\tag{7}
```

となる．

一方，エントロピーの変化は，

```math
\Delta S
=\left(\frac{\partial S}{\partial V}\right)_T^*\Delta V
+\left(\frac{\partial S}{\partial T}\right)_V^*\Delta T
\tag{8}
```

である．
Maxwell の関係式

```math
\left(\frac{\partial S}{\partial V}\right)_T
=\left(\frac{\partial p}{\partial T}\right)_V
```

および定積熱容量の定義

```math
C_V=T\left(\frac{\partial S}{\partial T}\right)_V
```

を用いると，

```math
\boxed{
\Delta S
=\left(\frac{\partial p}{\partial T}\right)_V^*\Delta V
+\frac{C_V^*}{T^*}\Delta T
}
\tag{9}
```

となる．

#### 2．確率分布を $\Delta V,\Delta T$ で表す

式（7），（9）より，

```math
\begin{aligned}
\Delta p\,\Delta V
={}&\left(\frac{\partial p}{\partial V}\right)_T^*(\Delta V)^2\\
&+\left(\frac{\partial p}{\partial T}\right)_V^*\Delta T\Delta V
\end{aligned}
\tag{10}
```

および

```math
\begin{aligned}
\Delta T\,\Delta S
={}&\left(\frac{\partial p}{\partial T}\right)_V^*
\Delta T\Delta V
+\frac{C_V^*}{T^*}(\Delta T)^2
\end{aligned}
\tag{11}
```

を得る．
式（10）から式（11）を引くと，交差項 $\Delta T\Delta V$ が相殺され，

```math
\begin{aligned}
\Delta p\,\Delta V-\Delta T\,\Delta S
={}&\left(\frac{\partial p}{\partial V}\right)_T^*
(\Delta V)^2\\
&-\frac{C_V^*}{T^*}(\Delta T)^2
\end{aligned}
\tag{12}
```

となる．
これを (i) で求めた確率分布に代入すると，

```math
\boxed{
\begin{aligned}
P(\Delta V,\Delta T)
=C\exp\biggl[
&\frac{1}{2kT^*}
\left(\frac{\partial p}{\partial V}\right)_T^*
(\Delta V)^2\\
&-\frac{C_V^*}{2k(T^*)^2}(\Delta T)^2
\biggr]
\end{aligned}
}
\tag{13}
```

が得られる．

式（13）の指数には $\Delta V\Delta T$ の項がなく，確率分布は $\Delta V$ のみの関数と $\Delta T$ のみの関数の積に分離できる．
したがって，この Gaussian 近似の範囲内では，体積と温度のゆらぎは独立であり，

```math
\boxed{
\overline{\Delta V\Delta T}=0
}
\tag{14}
```

となる．

#### 3．体積ゆらぎと温度ゆらぎの分散

平均値からのずれについて，平均二乗ゆらぎを考える．
一次元 Gaussian 分布

```math
P(x)\propto \exp\left(-\frac{x^2}{2\sigma_x^2}\right)
```

の分散は $\overline{x^2}=\sigma_x^2$ である．

式（13）の $(\Delta V)^2$ の項と比較すると，

```math
\boxed{
\overline{(\Delta V)^2}
=-\frac{kT^*}{
\left(\dfrac{\partial p}{\partial V}\right)_T^*}
=-kT^*\left(\frac{\partial V}{\partial p}\right)_T^*
}
\tag{15}
```

を得る．
等温圧縮率

```math
\kappa_T=-\frac{1}{V}
\left(\frac{\partial V}{\partial p}\right)_T
```

を用いると，

```math
\boxed{
\overline{(\Delta V)^2}
=kT^*V^*\kappa_T^*
}
\tag{16}
```

となる．
ここで重要なのは符号である．
$(\partial V/\partial p)_T<0$ なので，平均二乗ゆらぎが正になるには，式（16）の符号はプラスでなければならない．

同様に，式（13）の $(\Delta T)^2$ の項から，

```math
\boxed{
\overline{(\Delta T)^2}
=\frac{k(T^*)^2}{C_V^*}
}
\tag{17}
```

が得られる．

以上より，(ii) の答えは，

```math
\boxed{
\begin{aligned}
\overline{(\Delta V)^2}
&=kT^*V^*\kappa_T^*,\\
\overline{\Delta V\Delta T}
&=0,\\
\overline{(\Delta T)^2}
&=\frac{k(T^*)^2}{C_V^*}
\end{aligned}
}
```

である．

### (iii) 圧力ゆらぎ $\overline{(\Delta p)^2}$ の導出

#### 1．独立変数として圧力とエントロピーを選ぶ

今度は，独立変数として $p,S$ を選ぶ．
温度と体積の変化は，

```math
\Delta T
=\left(\frac{\partial T}{\partial p}\right)_S^*\Delta p
+\left(\frac{\partial T}{\partial S}\right)_p^*\Delta S
\tag{18}
```

```math
\Delta V
=\left(\frac{\partial V}{\partial p}\right)_S^*\Delta p
+\left(\frac{\partial V}{\partial S}\right)_p^*\Delta S
\tag{19}
```

と表せる．

エンタルピーを $H=U+pV$ とすると，その全微分は，

```math
dH=T\,dS+V\,dp
```

である．
したがって，

```math
T=\left(\frac{\partial H}{\partial S}\right)_p,
\qquad
V=\left(\frac{\partial H}{\partial p}\right)_S
```

となる．
混合二階偏微分の等しさから，

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_S
=\left(\frac{\partial V}{\partial S}\right)_p
}
\tag{20}
```

という Maxwell の関係式を得る．

また，定圧熱容量の定義

```math
C_p=T\left(\frac{\partial S}{\partial T}\right)_p
```

より，

```math
\boxed{
\left(\frac{\partial T}{\partial S}\right)_p
=\frac{T}{C_p}
}
\tag{21}
```

である．

#### 2．確率分布の変形

式（18），（19）を用いて， $\Delta T\Delta S-\Delta p\Delta V$ を計算する．
まず，

```math
\begin{aligned}
\Delta T\,\Delta S
={}&\left(\frac{\partial T}{\partial p}\right)_S^*
\Delta p\Delta S\\
&+\left(\frac{\partial T}{\partial S}\right)_p^*
(\Delta S)^2
\end{aligned}
```

であり，

```math
\begin{aligned}
\Delta p\,\Delta V
={}&\left(\frac{\partial V}{\partial p}\right)_S^*
(\Delta p)^2\\
&+\left(\frac{\partial V}{\partial S}\right)_p^*
\Delta p\Delta S
\end{aligned}
```

である．
Maxwell の関係式（20）によって交差項が相殺される．
さらに式（21）を用いると，

```math
\boxed{
\Delta T\,\Delta S-\Delta p\,\Delta V
=\frac{T^*}{C_p^*}(\Delta S)^2
-\left(\frac{\partial V}{\partial p}\right)_S^*
(\Delta p)^2
}
\tag{22}
```

となる．

これを (i) の確率分布に代入すると，

```math
\boxed{
\begin{aligned}
P(\Delta p,\Delta S)
=C'\exp\biggl[
&\frac{1}{2kT^*}
\left(\frac{\partial V}{\partial p}\right)_S^*
(\Delta p)^2\\
&-\frac{1}{2kC_p^*}(\Delta S)^2
\biggr]
\end{aligned}
}
\tag{23}
```

を得る．
ここで $C'$ は，変数の選択に応じた規格化定数である．
式（23）では $\Delta p\Delta S$ の交差項が消えているため，圧力とエントロピーのゆらぎも Gaussian 近似の範囲内で独立となる．

#### 3．圧力ゆらぎの分散

式（23）の $(\Delta p)^2$ の項を Gaussian 分布の標準形と比較すると，

```math
\boxed{
\overline{(\Delta p)^2}
=-\frac{kT^*}{
\left(\dfrac{\partial V}{\partial p}\right)_S^*}
=-kT^*\left(\frac{\partial p}{\partial V}\right)_S^*
}
\tag{24}
```

を得る．
断熱圧縮率を

```math
\kappa_S=-\frac{1}{V}
\left(\frac{\partial V}{\partial p}\right)_S
```

と定義すると，

```math
\left(\frac{\partial p}{\partial V}\right)_S
=-\frac{1}{V\kappa_S}
```

である．
これを式（24）に代入すれば，

```math
\boxed{
\overline{(\Delta p)^2}
=\frac{kT^*}{V^*\kappa_S^*}
}
\tag{25}
```

となる．
これが求める圧力ゆらぎの分散である．

### 最終結果

以上より，平衡状態の近傍における Gaussian 近似では，

```math
\boxed{
\begin{aligned}
\text{(i)}\quad
P(\alpha')
&=C\exp\left[
\frac{\Delta p\Delta V-\Delta T\Delta S}{2kT^*}
\right],\\
\text{(ii)}\quad
\overline{(\Delta V)^2}
&=kT^*V^*\kappa_T^*,\\
\overline{\Delta V\Delta T}
&=0,\\
\overline{(\Delta T)^2}
&=\frac{k(T^*)^2}{C_V^*},\\
\text{(iii)}\quad
\overline{(\Delta p)^2}
&=\frac{kT^*}{V^*\kappa_S^*}
\end{aligned}
}
```

が得られる．
この結果は，平衡状態における体積・温度・圧力のゆらぎが，等温圧縮率，断熱圧縮率，定積熱容量などの巨視的な熱力学量によって決まることを示している．
