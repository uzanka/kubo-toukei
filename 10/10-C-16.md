# 演習問題【10-C-16】

## 解答

### 1．弱電場近似と配向分布

分子の永久電気双極子モーメントの大きさを $\mu$ ，電場の大きさを $E(t)$ とする．
双極子モーメントと電場のなす角を $\theta$ とすると，その相互作用エネルギーは $-\mu E(t)\cos\theta$ である．
したがって，電場が分子の配向に与える影響は，分子の熱運動のエネルギー尺度 $kT$ と比較して決まる．

問題では

```math
|\mu E(t)|\ll kT
```

と仮定されているため，電場の一次の効果までを考えればよい．
電場がない場合，分子の配向は等方的であり，単位体積あたりの分子数を $n$ とすると，配向分布は $n/(4\pi)$ である．
弱い電場による一次の変化を考慮し，分布関数を

```math
\boxed{
f(\theta,\varphi,t)
=\frac{n}{4\pi}
\left[
1+\frac{\mu F(t)}{kT}\cos\theta
\right]
}
\tag{1}
```

と仮定する．
ここで， $F(t)$ は電場 $E(t)$ に応答する未知の関数である．
この式は，電場がない場合には $F=0$ となり，電場が弱い場合には分布が $\cos\theta$ に比例する形でわずかに変化することを表す．

式 (1) は方位角 $\varphi$ に依存しないため，

```math
\frac{\partial^2 f}{\partial\varphi^2}=0
```

である．
また，時間微分と極角についての微分はそれぞれ，

```math
\frac{\partial f}{\partial t}
=\frac{n\mu}{4\pi kT}
\frac{dF}{dt}\cos\theta
\tag{2}
```

```math
\frac{\partial f}{\partial\theta}
=-\frac{n\mu F}{4\pi kT}\sin\theta
\tag{3}
```

となる．

### 2．配向分布の微分方程式

与えられた配向分布の発展方程式は，

```math
\begin{aligned}
\frac{\partial f}{\partial t}
={}&\frac{B}{\sin\theta}
\frac{\partial}{\partial\theta}
\left[
\sin\theta
\left(
\frac{\partial f}{\partial\theta}
+\frac{\mu E(t)\sin\theta}{kT}f
\right)
\right]\\
&+\frac{B}{\sin^2\theta}
\frac{\partial^2 f}{\partial\varphi^2}
\end{aligned}
\tag{4}
```

である．
式 (1)，(3) を代入する．
電場の一次の項までを残すと，

```math
\begin{aligned}
\frac{\partial f}{\partial\theta}
+\frac{\mu E(t)\sin\theta}{kT}f
&\simeq
\frac{n\mu}{4\pi kT}
\{E(t)-F(t)\}\sin\theta
\end{aligned}
\tag{5}
```

となる．
ここでは， $E(t)F(t)$ に比例する項は電場の二次の項にあたるため，無視した．

したがって，式 (4) の右辺は，

```math
\begin{aligned}
&\frac{B}{\sin\theta}
\frac{\partial}{\partial\theta}
\left[
\frac{n\mu}{4\pi kT}
\{E(t)-F(t)\}\sin^2\theta
\right]\\
&\qquad=
\frac{n\mu}{4\pi kT}
\,2B\{E(t)-F(t)\}\cos\theta
\end{aligned}
\tag{6}
```

となる．
これを式 (2) と等置して整理すると，

```math
\boxed{
\frac{dF(t)}{dt}+2BF(t)=2BE(t)
}
\tag{7}
```

が得られる．
この式は，電場によって分子の配向が生じる効果と，分子の回転拡散によって配向が緩和する効果を表すものである．

### 3．微分方程式の解

式 (7) は，積分因子 $e^{2Bt}$ を用いて解くことができる．
両辺にこの積分因子を掛けると，

```math
\frac{d}{dt}\left(e^{2Bt}F(t)\right)
=2B e^{2Bt}E(t)
```

となる．
これを過去から時刻 $t$ まで積分し，十分過去では電場も配向もゼロであるという条件を用いると，

```math
e^{2Bt}F(t)
=2B\int_{-\infty}^{t}e^{2Bt'}E(t')\,dt'
```

である．
よって，

```math
\boxed{
F(t)=2B\int_{-\infty}^{t}
e^{-2B(t-t')}E(t')\,dt'
}
\tag{8}
```

となる．
すなわち，時刻 $t$ における配向は，その瞬間の電場だけではなく，過去の電場の時間的な履歴にも依存する．

### 4．電気分極の計算

分子の双極子モーメントの電場方向の成分は $\mu\cos\theta$ である．
したがって，単位体積あたりの電気分極 $P(t)$ は，配向分布を用いて

```math
P(t)=
\int_0^{2\pi}d\varphi
\int_0^\pi
\mu\cos\theta\,
f(\theta,\varphi,t)\sin\theta\,d\theta
\tag{9}
```

と表される．
ここに式 (1) を代入すると，

```math
\begin{aligned}
P(t)
={}&\frac{n\mu}{4\pi}
\int_0^{2\pi}d\varphi
\int_0^\pi
\cos\theta
\left[
1+\frac{\mu F(t)}{kT}\cos\theta
\right]
\sin\theta\,d\theta .
\end{aligned}
```

次の積分を用いる．

```math
\int_0^\pi\cos\theta\sin\theta\,d\theta=0
```

```math
\int_0^\pi\cos^2\theta\sin\theta\,d\theta=\frac23
```

最初の積分は，双極子が等方的に分布しているとき，配向による平均分極がゼロであることを表す．
したがって，分極に寄与するのは電場の一次の項である．
方位角の積分は $\int_0^{2\pi}d\varphi=2\pi$ なので，

```math
\begin{aligned}
P(t)
&=\frac{n\mu}{4\pi}
\frac{\mu F(t)}{kT}\,
2\pi\frac23\\
&=\frac{n\mu^2}{3kT}F(t)
\end{aligned}
```

となる．
ゆえに，

```math
\boxed{
P(t)=\frac{n\mu^2}{3kT}F(t)
}
\tag{10}
```

である．

### 5．緩和関数と複素誘電率

解答例と同じく Gaussian 単位系を用いると，電気変位 $D(t)$ は

```math
D(t)=E(t)+4\pi P(t)
\tag{11}
```

で与えられる．
式 (8)，(10) を代入すると，

```math
\begin{aligned}
D(t)
={}&E(t)+\frac{4\pi n\mu^2}{3kT}\,
2B\int_{-\infty}^{t}
e^{-2B(t-t')}E(t')\,dt'
\end{aligned}
\tag{12}
```

となる．

問題文の定義

```math
D(t)=\varepsilon_\infty E(t)
+\int_{-\infty}^{t}
\varphi(t-t')E(t')\,dt'
\tag{13}
```

と比較すると，高周波極限の誘電率は

```math
\boxed{\varepsilon_\infty=1}
\tag{14}
```

であり，緩和関数は

```math
\boxed{
\varphi(t)=
\frac{8\pi n\mu^2B}{3kT}e^{-2Bt}
\qquad (t\geq0)
}
\tag{15}
```

となる．
ここで， $t<0$ では因果律により緩和関数はゼロである．

緩和時間 $\tau$ を

```math
\tau=\frac{1}{2B}
\tag{16}
```

と定義すれば，

```math
\varphi(t)=
\frac{4\pi n\mu^2}{3kT}
\frac{1}{\tau}e^{-t/\tau}
\qquad (t\geq0)
\tag{17}
```

と書ける．

問題文に従って Fourier 変換を行うと，

```math
\varepsilon(\omega)
=\varepsilon_\infty+
\int_0^\infty\varphi(t)e^{-i\omega t}\,dt
```

であるから，

```math
\begin{aligned}
\varepsilon(\omega)
&=1+\frac{4\pi n\mu^2}{3kT}
\frac{1}{\tau}
\int_0^\infty e^{-(1/\tau+i\omega)t}\,dt\\
&=1+\frac{4\pi n\mu^2}{3kT}
\frac{1}{1+i\omega\tau}
\end{aligned}
```

となる．
よって，求める複素誘電率は

```math
\boxed{
\varepsilon(\omega)=
1+\frac{4\pi n\mu^2}{3kT}
\frac{1}{1+i\omega\tau}
}
\tag{18}
```

である．

最後に，問題で与えられた回転拡散係数

```math
B=\frac{kT}{8\pi\eta a^3}
```

を式 (16) に代入すると，

```math
\boxed{
\tau=\frac{4\pi\eta a^3}{kT}
}
\tag{19}
```

となる．
したがって，緩和時間は流体の粘性係数と分子の有効半径の三乗に比例し，温度に反比例する．

### 6．静誘電率と周波数依存性

静電場に対応する $\omega=0$ では，

```math
\varepsilon_s=\varepsilon(0)
=1+\frac{4\pi n\mu^2}{3kT}
\tag{20}
```

となる．
ここで，

```math
\Delta\varepsilon=\varepsilon_s-\varepsilon_\infty
=\frac{4\pi n\mu^2}{3kT}
```

と定義すれば，式 (18) は Debye の式

```math
\boxed{
\varepsilon(\omega)=
\varepsilon_\infty+
\frac{\varepsilon_s-\varepsilon_\infty}{1+i\omega\tau}
}
\tag{21}
```

となる．

問題文の Fourier 変換の定義では，

```math
\varepsilon(\omega)=\varepsilon'(\omega)
+i\varepsilon''(\omega)
```

と書いたとき，

```math
\boxed{
\varepsilon'(\omega)-\varepsilon_\infty
=\frac{\varepsilon_s-\varepsilon_\infty}
{1+\omega^2\tau^2}
}
\tag{22}
```

```math
\boxed{
\varepsilon''(\omega)=
-\frac{(\varepsilon_s-\varepsilon_\infty)\omega\tau}
{1+\omega^2\tau^2}
}
\tag{23}
```

となる．
虚部の符号は Fourier 変換の符号規約に依存する．
問題文のように $e^{-i\omega t}$ を使う場合は式 (23) の符号となる．
反対の規約を用いる場合には虚部の符号が反転する．
誘電損失を正の量として表す場合は，この規約では $-\operatorname{Im}\varepsilon$ を用いる．

以上より，弱電場下での永久双極子の配向緩和による複素誘電率が得られた．
この応答は Debye 型の誘電緩和であり，周波数が高くなるほど分子の配向が電場の変化に追随できなくなり，誘電率は $\varepsilon_\infty=1$ に近づく．
