# 演習問題【10-C-16】

## 解答

### 永久双極子の配向緩和と複素誘電率

#### 1．弱電場近似と配向分布

分子の永久電気双極子モーメントの大きさを $\mu$ ，電場の大きさを $E(t)$ とする．
電場の方向を極軸に選び，双極子モーメントと電場のなす角を $\theta$ とする．
双極子と電場の相互作用エネルギーは

```math
U=-\mu E(t)\cos\theta
```

である．

問題では，

```math
|\mu E(t)|\ll k_{\mathrm B}T
```

が仮定されているため，電場の一次の効果までを考える．
ここで，分子数密度を $n$ とする．

電場がない場合，分子の配向は等方的であるから，単位立体角あたりの分布は

```math
f_0=\frac{n}{4\pi}
```

である．

弱電場による一次の変化を $\delta f$ とすると，

```math
f=f_0+\delta f
```

と書ける．
与えられた発展方程式の電場項は，等方分布 $f_0$ に対して $\cos\theta$ に比例する項を生じる．
また，球面上の角度についての Laplace 演算子を

```math
\nabla_\Omega^2
=
\frac{1}{\sin\theta}
\frac{\partial}{\partial\theta}
\left(\sin\theta\frac{\partial}{\partial\theta}\right)
+\frac{1}{\sin^2\theta}
\frac{\partial^2}{\partial\varphi^2}
```

と定義すると，

```math
\nabla_\Omega^2\cos\theta=-2\cos\theta
```

である．
したがって，等方分布から生じる一次の変化は $\cos\theta$ に比例する成分だけで閉じている．

そこで，

```math
f(\theta,\varphi,t)
=\frac{n}{4\pi}
\left[
1+\frac{\mu F(t)}{k_{\mathrm B}T}\cos\theta
\right]
\tag{1}
```

とおく．
ここで $F(t)$ は電場に対する配向の応答を表す未知関数であり，電場と同じ次元をもつ．

この分布は方位角 $\varphi$ に依存せず，

```math
\frac{\partial^2 f}{\partial\varphi^2}=0
```

である．
また，

```math
\frac{\partial f}{\partial t}
=\frac{n\mu}{4\pi k_{\mathrm B}T}
\frac{dF}{dt}\cos\theta
\tag{2}
```

および

```math
\frac{\partial f}{\partial\theta}
=-\frac{n\mu F}{4\pi k_{\mathrm B}T}\sin\theta
\tag{3}
```

となる．

なお，

```math
\int f\,d\Omega=n
```

であり，式 (1) は分子数の規格化を保っている．

#### 2．配向分布の微分方程式

与えられた配向分布の発展方程式は，

```math
\begin{aligned}
\frac{\partial f}{\partial t}
={}&\frac{B}{\sin\theta}
\frac{\partial}{\partial\theta}
\left[
\sin\theta
\left(
\frac{\partial f}{\partial\theta}
+\frac{\mu E(t)\sin\theta}{k_{\mathrm B}T}f
\right)
\right]\\
&+\frac{B}{\sin^2\theta}
\frac{\partial^2 f}{\partial\varphi^2}
\end{aligned}
\tag{4}
```

である．

式 (1)，(3) を代入する．
電場の一次の項までを残すと，

```math
\begin{aligned}
\frac{\partial f}{\partial\theta}
+\frac{\mu E(t)\sin\theta}{k_{\mathrm B}T}f
&\simeq
-\frac{n\mu F}{4\pi k_{\mathrm B}T}\sin\theta
+\frac{n\mu E}{4\pi k_{\mathrm B}T}\sin\theta\\
&=\frac{n\mu}{4\pi k_{\mathrm B}T}
(E-F)\sin\theta .
\end{aligned}
\tag{5}
```

ここでは $EF$ に比例する二次の項を無視した．

したがって，式 (4) の右辺は，

```math
\begin{aligned}
&\frac{B}{\sin\theta}
\frac{\partial}{\partial\theta}
\left[
\frac{n\mu}{4\pi k_{\mathrm B}T}
(E-F)\sin^2\theta
\right]\\
&\qquad=
\frac{n\mu}{4\pi k_{\mathrm B}T}
2B(E-F)\cos\theta
\end{aligned}
\tag{6}
```

となる．
これを式 (2) と等置すると，

```math
\frac{dF}{dt}=2B(E-F)
```

を得る．
よって，

```math
\boxed{
\frac{dF}{dt}+2BF=2BE
}
\tag{7}
```

である．

この式は，電場による分子の配向と，回転拡散による配向の緩和を表している．

#### 3．微分方程式の解

式 (7) は，積分因子 $e^{2Bt}$ を用いると，

```math
\frac{d}{dt}\left(e^{2Bt}F(t)\right)
=2Be^{2Bt}E(t)
```

と書ける．

十分過去では電場がなく，配向分布の等方状態からのずれがゼロであるとする．
すなわち，異方的な成分について

```math
F(-\infty)=0
```

とする．
この初期条件のもとで積分すると，

```math
e^{2Bt}F(t)
=2B\int_{-\infty}^{t}e^{2Bt'}E(t')\,dt'
```

である．
したがって，

```math
\boxed{
F(t)=2B\int_{-\infty}^{t}
e^{-2B(t-t')}E(t')\,dt'
}
\tag{8}
```

となる．

この式は，時刻 $t$ の配向が，その瞬間の電場だけでなく過去の電場の履歴にも依存することを示している．

#### 4．電気分極の計算

分子の双極子モーメントの電場方向の成分は $\mu\cos\theta$ である．
したがって，単位体積あたりの電気分極 $P(t)$ は，

```math
P(t)=
\int_0^{2\pi}d\varphi
\int_0^\pi
\mu\cos\theta\,
f(\theta,\varphi,t)\sin\theta\,d\theta
\tag{9}
```

である．

式 (1) を代入すると，

```math
\begin{aligned}
P(t)
={}&\frac{n\mu}{4\pi}
\int_0^{2\pi}d\varphi
\int_0^\pi
\cos\theta
\left[
1+\frac{\mu F(t)}{k_{\mathrm B}T}\cos\theta
\right]
\sin\theta\,d\theta .
\end{aligned}
```

ここで，

```math
\int_0^\pi\cos\theta\sin\theta\,d\theta=0
```

および

```math
\int_0^\pi\cos^2\theta\sin\theta\,d\theta=\frac23
```

を用いる．
方位角についての積分は

```math
\int_0^{2\pi}d\varphi=2\pi
```

である．
したがって，

```math
\begin{aligned}
P(t)
&=\frac{n\mu}{4\pi}
\frac{\mu F(t)}{k_{\mathrm B}T}
2\pi\frac23\\
&=\frac{n\mu^2}{3k_{\mathrm B}T}F(t).
\end{aligned}
```

ゆえに，

```math
\boxed{
P(t)=\frac{n\mu^2}{3k_{\mathrm B}T}F(t)
}
\tag{10}
```

となる．

さらに，式 (8) を代入すると，

```math
\boxed{
P(t)=
\frac{2Bn\mu^2}{3k_{\mathrm B}T}
\int_{-\infty}^{t}
e^{-2B(t-t')}E(t')\,dt'
}
\tag{11}
```

を得る．
ここまでの分極の導出は，電気変位と分極を結びつける単位系の選択に依存しない．

#### 5．電気変位と緩和関数

電気変位 $D(t)$ と分極 $P(t)$ の関係は，採用する単位系によって異なる．
問題文では単位系が指定されていないため，ここではSI単位系とGaussian単位系をそれぞれ示す．

##### 5.1 SI単位系

SI単位系では，背景の高速な分極応答を含む絶対誘電率を $\varepsilon_\infty$ とすれば，

```math
D(t)=\varepsilon_\infty E(t)+P(t)
\tag{12}
```

である．
ここで $\varepsilon_\infty$ は絶対誘電率であり，真空を背景とする場合は $\varepsilon_\infty=\varepsilon_0$ となる．

式 (11) を代入すると，

```math
\begin{aligned}
D(t)
={}&\varepsilon_\infty E(t)\\
&+\frac{2Bn\mu^2}{3k_{\mathrm B}T}
\int_{-\infty}^{t}
e^{-2B(t-t')}E(t')\,dt'
\end{aligned}
\tag{13}
```

となる．

問題文の定義

```math
D(t)=\varepsilon_\infty E(t)
+\int_{-\infty}^{t}
\varphi(t-t')E(t')\,dt'
```

と比較すれば，緩和関数は

```math
\boxed{
\varphi_{\mathrm{SI}}(t)
=\frac{2Bn\mu^2}{3k_{\mathrm B}T}
e^{-2Bt}
\qquad (t\geq0)
}
\tag{14}
```

であり， $t<0$ では因果律によりゼロである．

##### 5.2 Gaussian単位系

Gaussian単位系では，

```math
D(t)=\varepsilon_\infty E(t)+4\pi P(t)
\tag{15}
```

である．
ここで $\varepsilon_\infty$ は背景の無次元誘電率である．

式 (11) を代入すると，

```math
\begin{aligned}
D(t)
={}&\varepsilon_\infty E(t)\\
&+\frac{8\pi Bn\mu^2}{3k_{\mathrm B}T}
\int_{-\infty}^{t}
e^{-2B(t-t')}E(t')\,dt'
\end{aligned}
\tag{16}
```

となる．
したがって，緩和関数は

```math
\boxed{
\varphi_{\mathrm G}(t)
=\frac{8\pi Bn\mu^2}{3k_{\mathrm B}T}
e^{-2Bt}
\qquad (t\geq0)
}
\tag{17}
```

であり， $t<0$ ではゼロである．

なお，Gaussian単位系を採用した場合でも，背景の高速分極応答を無視できるという追加仮定がなければ， $\varepsilon_\infty=1$ とはならない．

#### 6．複素誘電率の計算

回転拡散係数は

```math
B=\frac{k_{\mathrm B}T}{8\pi\eta a^3}
```

である．
微分方程式 (7) の緩和時間を

```math
\tau=\frac{1}{2B}
```

と定義すると，

```math
\boxed{
\tau=\frac{4\pi\eta a^3}{k_{\mathrm B}T}
}
\tag{18}
```

となる．

問題文で指定された Fourier 変換

```math
\varepsilon(\omega)
=\varepsilon_\infty+
\int_0^\infty\varphi(t)e^{-i\omega t}\,dt
```

を用いる．
基本となる積分は，

```math
\begin{aligned}
\int_0^\infty
2B e^{-2Bt}e^{-i\omega t}\,dt
&=\frac{2B}{2B+i\omega}\\
&=\frac{1}{1+i\omega\tau}.
\end{aligned}
\tag{19}
```

したがって，SI単位系では，

```math
\boxed{
\varepsilon_{\mathrm{SI}}(\omega)
=\varepsilon_\infty+
\frac{n\mu^2}{3k_{\mathrm B}T}
\frac{1}{1+i\omega\tau}
}
\tag{20}
```

となる．
ここで $\varepsilon_\infty$ は絶対誘電率である．

相対誘電率で表す場合， $\varepsilon_\infty=\varepsilon_0\varepsilon_{r,\infty}$ とおけば，

```math
\boxed{
\varepsilon_r(\omega)
=\varepsilon_{r,\infty}
+\frac{n\mu^2}{3\varepsilon_0 k_{\mathrm B}T}
\frac{1}{1+i\omega\tau}
}
\tag{21}
```

となる．

一方，Gaussian単位系では，

```math
\boxed{
\varepsilon_{\mathrm G}(\omega)
=\varepsilon_\infty+
\frac{4\pi n\mu^2}{3k_{\mathrm B}T}
\frac{1}{1+i\omega\tau}
}
\tag{22}
```

である．
ここで $\varepsilon_\infty$ は背景の無次元誘電率である．

したがって，単位系を特定しない場合でも，分極応答と緩和時間は一意に導けるが，電気変位から定義される誘電率の係数は単位系に応じて表記する必要がある．

#### 7．静誘電率と周波数依存性

誘電率増分を $\Delta\varepsilon$ とおけば，いずれの単位系でも Debye 型の形式

```math
\boxed{
\varepsilon(\omega)
=\varepsilon_\infty+
\frac{\Delta\varepsilon}{1+i\omega\tau}
}
\tag{23}
```

で表せる．
その増分は，

```math
\Delta\varepsilon=
\begin{cases}
\dfrac{n\mu^2}{3k_{\mathrm B}T},
&\text{SI単位系で絶対誘電率を用いる場合},\\[8pt]
\dfrac{n\mu^2}{3\varepsilon_0 k_{\mathrm B}T},
&\text{SI単位系で相対誘電率を用いる場合},\\[8pt]
\dfrac{4\pi n\mu^2}{3k_{\mathrm B}T},
&\text{Gaussian単位系}.
\end{cases}
\tag{24}
```

静的極限 $\omega=0$ では，

```math
\boxed{
\varepsilon_s=\varepsilon(0)
=\varepsilon_\infty+\Delta\varepsilon
}
\tag{25}
```

となる．
一方，高周波極限では，

```math
\boxed{
\lim_{\omega\to\infty}\varepsilon(\omega)
=\varepsilon_\infty
}
\tag{26}
```

である．

さらに，

```math
\varepsilon(\omega)=\varepsilon'(\omega)
+i\varepsilon''(\omega)
```

と書くと，

```math
\boxed{
\varepsilon'(\omega)-\varepsilon_\infty
=\frac{\Delta\varepsilon}{1+\omega^2\tau^2}
}
\tag{27}
```

および

```math
\boxed{
\varepsilon''(\omega)
=-\frac{\Delta\varepsilon\,\omega\tau}
{1+\omega^2\tau^2}
}
\tag{28}
```

を得る．
虚部の符号は Fourier 変換の規約に依存する．
ここでは問題文の $e^{-i\omega t}$ に従っているため，正の周波数に対して虚部は負となる．
この規約では誘電損失を正の量で表すとき， $-\operatorname{Im}\varepsilon$ を用いる．

以上より，弱電場下での永久双極子の配向緩和による複素誘電率は Debye 型となり，緩和時間は

```math
\boxed{
\tau=\frac{4\pi\eta a^3}{k_{\mathrm B}T}
}
```

で与えられる．
なお，背景誘電率 $\varepsilon_\infty$ は問題文からは決定されず，実際の媒質における高速な分極応答を表す量として残す必要がある．
