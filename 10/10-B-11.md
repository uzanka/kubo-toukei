# 演習問題【10-B-11】

## 解答

### 粒子数ゆらぎと二体位置相関関数および等温圧縮率の関係

#### 1．領域内の粒子数を指示関数で表す

一様な流体の中から，体積 $V_A$ の領域を取り出す．
この領域に含まれる粒子数を $N_A$ ，流体の平均粒子数密度を $n$ とする．
まず，領域内の粒子数の平均と分散を二体位置相関関数 $g(R)$ を用いて表す．
次に，大分配関数から粒子数ゆらぎと等温圧縮率との関係を導き，両者を結び付ける．

領域 $V_A$ の中にあるかどうかを判定する関数 $m(\mathbf r)$ を，

```math
m(\mathbf r)=
\begin{cases}
1,&\mathbf r\in V_A,\\
0,&\mathbf r\notin V_A
\end{cases}
\tag{1}
```

と定義する．
この関数を用いると，粒子 $i$ の位置を $\mathbf r_i$ として，領域内の粒子数は

```math
\boxed{N_A=\sum_{i=1}^{N}m(\mathbf r_i)}
\tag{2}
```

と表せる．
ここで $N$ は流体全体の粒子数であり， $N_A$ はそのうち領域 $V_A$ に入っている粒子数である．

#### 2．粒子数の平均を求める

流体が一様であるとき，位置 $\mathbf r$ における平均粒子数密度は，どこでも一定値 $n$ である．
したがって，式 (2) の平均を取ると，

```math
\begin{aligned}
\langle N_A\rangle
&=\left\langle\sum_{i=1}^{N}m(\mathbf r_i)\right\rangle\\
&=\int m(\mathbf r)n\,d\mathbf r\\
&=n\int_{V_A}d\mathbf r
\end{aligned}
```

となる．
よって，

```math
\boxed{\langle N_A\rangle=nV_A}
\tag{3}
```

である．
これは，一様な流体では，ある領域に含まれる平均粒子数が，その領域の体積と粒子数密度の積で与えられることを意味する．

#### 3．粒子数の二乗平均を求める

##### 3.1．二体位置相関関数を用いる

式 (2) を二乗すると，

```math
N_A^2
=\sum_{i=1}^{N}m(\mathbf r_i)^2
+\sum_{i\ne j}m(\mathbf r_i)m(\mathbf r_j)
\tag{4}
```

となる．
$m(\mathbf r)$ は0または1しか取らないため，

```math
m(\mathbf r)^2=m(\mathbf r)
```

である．
したがって，式 (4) の第1項は $N_A$ に等しく，

```math
\langle N_A^2\rangle
=\langle N_A\rangle
+\left\langle
\sum_{i\ne j}m(\mathbf r_i)m(\mathbf r_j)
\right\rangle
\tag{5}
```

となる．

ここで，粒子対の位置相関を表す二体数密度を

```math
\rho^{(2)}(\mathbf r_1,\mathbf r_2)
=
\left\langle
\sum_{i\ne j}
\delta(\mathbf r_1-\mathbf r_i)
\delta(\mathbf r_2-\mathbf r_j)
\right\rangle
\tag{6}
```

と定義する．
この定義では，粒子対の個数を表す和がすでに含まれているため，後から $N(N-1)$ を掛ける必要はない．
一様な流体では，二体位置相関関数 $g(R)$ を用いて，

```math
\boxed{
\rho^{(2)}(\mathbf r_1,\mathbf r_2)
=n^2g(|\mathbf r_1-\mathbf r_2|)
}
\tag{7}
```

と書ける．
ここで $R=|\mathbf r_1-\mathbf r_2|$ は二粒子間の距離である．
$g(R)$ は，二粒子の位置が互いにどの程度相関しているかを表し，相関が十分弱い遠距離では $g(R)\to1$ となる．

式 (5) の第2項は，式 (6)，(7) を使って，

```math
\begin{aligned}
&\left\langle
\sum_{i\ne j}m(\mathbf r_i)m(\mathbf r_j)
\right\rangle\\
&\qquad
=\iint m(\mathbf r_1)m(\mathbf r_2)
\rho^{(2)}(\mathbf r_1,\mathbf r_2)
\,d\mathbf r_1d\mathbf r_2\\
&\qquad
=n^2\iint_{V_A\times V_A}
g(|\mathbf r_1-\mathbf r_2|)
\,d\mathbf r_1d\mathbf r_2
\end{aligned}
\tag{8}
```

となる．
したがって，

```math
\boxed{
\langle N_A^2\rangle
=nV_A+n^2
\iint_{V_A\times V_A}g(R)\,
d\mathbf r_1d\mathbf r_2
}
\tag{9}
```

を得る．

##### 3.2．粒子数の分散を求める

粒子数の分散は，

```math
\operatorname{Var}(N_A)
\equiv
\langle(N_A-\langle N_A\rangle)^2\rangle
=\langle N_A^2\rangle-\langle N_A\rangle^2
\tag{10}
```

で定義される．
式 (3)，(9) を代入すると，

```math
\begin{aligned}
\operatorname{Var}(N_A)
={}&nV_A
+n^2\iint_{V_A\times V_A}g(R)\,
d\mathbf r_1d\mathbf r_2
-n^2V_A^2
\end{aligned}
```

となる．
ここで，

```math
V_A^2
=\iint_{V_A\times V_A}1\,
d\mathbf r_1d\mathbf r_2
```

であることを用いると，

```math
\boxed{
\operatorname{Var}(N_A)
=nV_A+n^2
\iint_{V_A\times V_A}[g(R)-1]\,
d\mathbf r_1d\mathbf r_2
}
\tag{11}
```

を得る．
このように $g(R)-1$ で表すことで，長距離で相関が消失する性質を利用できる．

##### 3.3．領域が十分大きい場合の近似

二体位置相関関数は，短距離では粒子間相互作用などの影響を受けるが，相関の及ぶ距離を十分に超えると $g(R)-1$ はほぼゼロとなる．
この相関の及ぶ距離を $l$ とする．

領域 $V_A$ の線形寸法が $l$ より十分大きければ，領域の境界付近を除いて，ある位置 $\mathbf r_1$ の近くにある相関相手の位置 $\mathbf r_2$ は領域内に含まれると考えられる．
そのため，境界の寄与を無視すれば，

```math
\begin{aligned}
&\iint_{V_A\times V_A}
[g(|\mathbf r_1-\mathbf r_2|)-1]\,
d\mathbf r_1d\mathbf r_2\\
&\qquad\simeq V_A\int
[g(R)-1]\,d\mathbf R
\end{aligned}
\tag{12}
```

となる．
右辺の積分は，相対座標 $\mathbf R=\mathbf r_2-\mathbf r_1$ について全空間で行うものである．
この近似は， $g(R)-1$ が十分速く減衰し，相関長に比べて領域が十分大きい場合に成立する．

式 (11) に式 (12) を代入すると，

```math
\operatorname{Var}(N_A)
\simeq nV_A+n^2V_A
\int[g(R)-1]\,d\mathbf R
```

を得る．
式 (3) の $\langle N_A\rangle=nV_A$ を用いて整理すると，

```math
\boxed{
\frac{\langle(N_A-\langle N_A\rangle)^2\rangle}
{\langle N_A\rangle}
=1+n\int[g(R)-1]\,d\mathbf R
}
\tag{13}
```

となる．
両辺に $\langle N_A\rangle$ を掛ければ，

```math
\boxed{
\langle(N_A-\langle N_A\rangle)^2\rangle
=\langle N_A\rangle
\left\{1+n\int[g(R)-1]\,d\mathbf R\right\}
}
\tag{14}
```

が示された．
これが最初に求める関係式である．

#### 4．粒子数のゆらぎと等温圧縮率の関係

次に，粒子数のゆらぎを等温圧縮率 $\kappa_T$ で表す．
そのため，大きな流体の中の部分系を考え，部分系が周囲と粒子を交換できるものとする．
この場合，部分系の粒子数は固定されておらず，温度 $T$ と化学ポテンシャル $\mu$ が一定の外界と接触した系として扱える．

##### 4.1．大分配関数から粒子数の分散を導く

体積 $V$ ，温度 $T$ の系に対する大分配関数は，

```math
\Xi=\sum_N
\exp\left[-\frac{F_N(V,T)-N\mu}{kT}\right]
\tag{15}
```

である．
ここで $F_N(V,T)$ は粒子数 $N$ のときの Helmholtz 自由エネルギーである．
粒子数の平均と分散は，大分配関数の微分を用いて，

```math
\boxed{
\langle N\rangle
=kT\left(\frac{\partial\ln\Xi}{\partial\mu}\right)_{V,T}
}
\tag{16}
```

および

```math
\boxed{
\operatorname{Var}(N)
=(kT)^2
\left(\frac{\partial^2\ln\Xi}{\partial\mu^2}\right)_{V,T}
}
\tag{17}
```

と表される．
第1式は平均粒子数を，第2式は粒子数のゆらぎの分散を与える関係である．

巨視的な系では，

```math
kT\ln\Xi=pV
\tag{18}
```

が成り立つ．
したがって， $V,T$ を固定した微分を取ることで，

```math
\operatorname{Var}(N)
=VkT\left(\frac{\partial^2p}{\partial\mu^2}\right)_T
\tag{19}
```

となる．

##### 4.2．圧力の化学ポテンシャルによる微分

一様な純流体について，Gibbs–Duhem の関係式は，

```math
d\mu=v\,dp-s\,dT
\tag{20}
```

と表せる．
ここで $v=V/\langle N\rangle=1/n$ は粒子1個当たりの体積， $s$ は粒子1個当たりのエントロピーである．
温度を一定に保つと，

```math
d\mu=v\,dp
```

であるから，

```math
\boxed{
\left(\frac{\partial p}{\partial\mu}\right)_T
=\frac1v=n
}
\tag{21}
```

となる．

これをもう一度 $\mu$ で微分し，連鎖律を適用すると，

```math
\begin{aligned}
\left(\frac{\partial^2p}{\partial\mu^2}\right)_T
&=\left(\frac{\partial n}{\partial\mu}\right)_T\\
&=\left(\frac{\partial n}{\partial p}\right)_T
\left(\frac{\partial p}{\partial\mu}\right)_T\\
&=n\left(\frac{\partial n}{\partial p}\right)_T
\end{aligned}
\tag{22}
```

を得る．

等温圧縮率は，

```math
\kappa_T=-\frac1v\left(\frac{\partial v}{\partial p}\right)_T
\tag{23}
```

と定義される．
ここで $n=1/v$ なので，

```math
\begin{aligned}
\left(\frac{\partial n}{\partial p}\right)_T
&=-\frac1{v^2}
\left(\frac{\partial v}{\partial p}\right)_T\\
&=\frac{\kappa_T}{v}
=n\kappa_T
\end{aligned}
\tag{24}
```

となる．
式 (22) に代入すると，

```math
\boxed{
\left(\frac{\partial^2p}{\partial\mu^2}\right)_T
=n^2\kappa_T
}
\tag{25}
```

を得る．

##### 4.3．粒子数の分散を圧縮率で表す

式 (25) を式 (19) に代入すれば，

```math
\boxed{
\operatorname{Var}(N)=VkTn^2\kappa_T
}
\tag{26}
```

となる．
平均粒子数は $\langle N\rangle=nV$ であるため，

```math
\begin{aligned}
\frac{\operatorname{Var}(N)}{\langle N\rangle}
&=\frac{VkTn^2\kappa_T}{nV}\\
&=nkT\kappa_T
\end{aligned}
```

である．
よって，

```math
\boxed{
\frac{\langle(N-\langle N\rangle)^2\rangle}
{\langle N\rangle}
=nkT\kappa_T
}
\tag{27}
```

を得る．
これは，粒子数の相対的なゆらぎの大きさが，等温圧縮率によって決まることを示している．

#### 5．相関関数と等温圧縮率の関係

式 (13) より，大きな領域内の粒子数ゆらぎは，

```math
\frac{\langle(N_A-\langle N_A\rangle)^2\rangle}
{\langle N_A\rangle}
=1+n\int[g(R)-1]\,d\mathbf R
\tag{28}
```

と表される．
一方，その領域を大きな流体の中の部分系とみなし，境界からの寄与を無視できる極限では，式 (27) の粒子数ゆらぎの関係が適用される．
したがって，

```math
1+n\int[g(R)-1]\,d\mathbf R
=nkT\kappa_T
\tag{29}
```

となる．
両辺から1を引けば，

```math
\boxed{
n\int\{g(R)-1\}\,d\mathbf R
=nkT\kappa_T-1
}
\tag{30}
```

が得られる．
これが第二に示すべき関係式である．

#### 結論

領域 $V_A$ 内の粒子数ゆらぎは，二体位置相関関数 $g(R)$ によって，

```math
\boxed{
\langle(N_A-\langle N_A\rangle)^2\rangle
=\langle N_A\rangle
\left\{1+n\int[g(R)-1]\,d\mathbf R\right\}
}
```

と表される．
さらに，大分配関数を用いた粒子数ゆらぎの式と等温圧縮率の関係から，

```math
\boxed{
n\int\{g(R)-1\}\,d\mathbf R
=nkT\kappa_T-1
}
```

を得る．
この結果は，粒子間の空間相関が，巨視的な熱力学量である圧縮率と直接結び付いていることを示しているのである．
