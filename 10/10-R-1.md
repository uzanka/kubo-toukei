# 演習問題【10-R-1】

## 解答

問題文で与えられた確率分布の式 (5.68) は，以下の形式である：

$$P(\alpha') = C \exp \left\{ -\frac{W_{\text{min}}(\alpha^*, \alpha')}{kT^*} \right\} \quad \text{--- (5.68)}$$

と書けることを示す．ここで， $W_{\text{min}}(\alpha^*, \alpha')$ は部分系 I を熱平衡状態 $\alpha^*$ から状態 $\alpha^* + \alpha'$ に移すに必要な最小仕事である．

### 1. 合成系の設定と最小仕事の定義

合成系（部分系 I + 部分 II）を考える．部分系 I の状態を $\alpha^*$ から $\alpha^* + \alpha'$ に変化させるために外部から仕事を加える．
合成系の全エネルギー，エントロピーをそれぞれ $E$ ， $S_{\text{tot}}$ とする．

準静的（可逆的）過程では，熱力学第一法則および第二法則より，状態 $E$ から $E'$ への変化における最小仕事 $W_{\text{min}}$ は，

$$W_{\text{min}}(\alpha^*, \alpha') = \int (dE - T dS_{\text{tot}}) \quad \text{--- (1)}$$

と表される．可逆過程では $dQ_{\text{rev}} = T dS_{\text{tot}}$ が成り立ち，仕事は $dW = dE - T dS_{\text{tot}}$ となる．

### 2. 孤立系の条件と近似

ゆらぎを考える際，合成系 I + II は外部とエネルギーをやり取りしない孤立系である．したがって状態 $\alpha^*$ と $\alpha^* + \alpha'$ は同じ全エネルギー $E$ の値を持つ：

$$dE = 0$$

また， $\alpha'$ は「十分小さい部分系 I」に対する変化であり，合成系全体から見れば極めて微小である．したがって，変化の途中の温度 $T$ を平衡温度 $T^*$（部分 II の温度）で近似してよい：

$$T \approx T^*$$

### 3. 最小仕事の計算

上記の条件を式 (1) に代入すると，

$$W_{\text{min}}(\alpha^*, \alpha') = - T^* \int dS_{\text{tot}} = - T^* \{ S_{\text{tot}}(E, \alpha^* + \alpha') - S_{\text{tot}}(E, \alpha^*) \}$$

ここで，エントロピーの引数について明確にするため，合成系の全エネルギー $E$ および他の広範性（粒子数 $N$ ，体積 $V$ ）を明示して，

$$W_{\text{min}}(\alpha^*, \alpha') = - T^* \{ S(E, N, V, \alpha^* + \alpha') - S(E, N, V, \alpha^*) \} \quad \text{--- (2)}$$

と書く．
式 (2) の右辺の差は，固定エネルギー $E$ 下でのエントロピー変化である．

### 4. 確率分布の導出

式 (2) を式 (5.68) に代入すると，

$$P(\alpha') = C \exp \left\{ -\frac{- T^* \{ S(E, N, V, \alpha^* + \alpha') - S(E, N, V, \alpha^*) \}}{kT^*} \right\}$$

$T^*$ が約分されて，

$$P(\alpha') = C \exp \left\{ \frac{S(E, N, V, \alpha^* + \alpha') - S(E, N, V, \alpha^*)}{k} \right\}$$

これは $P(\alpha') = C \exp \left\{ -\dfrac{W_{\text{min}}(\alpha^*, \alpha')}{kT^*} \right\}$ の形に等しい．これにより，示すべき確率分布が得られた．

### 5. $W_{\text{min}}$ の $\alpha'$ 依存性について（補足）

平衡状態 $\alpha^*$ ではエントロピー $S(E, N, V, \alpha)$ が最大となるから， $\alpha'$ で展開すると一次の項は消え，二次の項が主要な寄与を与える：

$$S(E, N, V, \alpha^* + \alpha') - S(E, N, V, \alpha^*) = -\frac{1}{2} \left| \frac{\partial^2 S}{\partial \alpha^2} \right|_{\alpha^*} |\alpha'|^2 + O(|\alpha'|^3)$$

したがって，

$$W_{\text{min}}(\alpha^*, \alpha') \approx \frac{T^*}{2} \left| \frac{\partial^2 S}{\partial \alpha^2} \right|_{\alpha^*} |\alpha'|^2$$

となり， $W_{\text{min}} > 0$ （平衡から離れるのに正の仕事が必要）かつ確率分布がガウス分布 $P(\alpha') \propto \exp\left\{-\dfrac{a|\alpha'|^2}{2k}\right\}$ として規格化可能であることがわかる．

### 6. 物理的解釈（補足）

この結果は， $S(E, N, V, \alpha)$ は固定エネルギー下で平衡状態 $\alpha^*$ で最大となるため，$\Delta S \equiv S(\alpha^* + \alpha') - S(\alpha^*) \leq 0$ を満たす．ゆえに

$$P(\alpha') = C \exp\left( \frac{\Delta S}{k} \right)$$

は，平衡状態（ $\Delta S = 0$ ）から離れるほど確率が指数関数的に減少することを示している．
また，式 (2) の二次近似係数 $a = T^* \left| \dfrac{\partial^2 S}{\partial \alpha^2} \right|_{\alpha^*}$ は，部分系の応答関数 $\chi$ と fluctuation-dissipation theorem を通じて結びつく：

$$a = kT^* \chi$$

これにより，ゆらぎの分散 $\langle |\alpha'|^2 \rangle = \dfrac{k}{a} = \dfrac{1}{\chi}$ が得られ，ゆらぎと応答が同一物理現象の両側面であることが示される．

## 解説

### 1. なぜ最小仕事が可逆過程なのか？

非可逆な過程では摩擦や急激な変化によってエネルギーが熱として散逸するため，余分な仕事が必要になる．一方で，準静的（可逆的）な過程は系が常に平衡状態を保ちながら極めてゆっくり変化するため，理論上の最小仕事のみで状態を変化させることができる．

### 2. なぜ内部エネルギーが一定なのか？

「ゆらぎ」は系が外部からの強制操作なしに自然に起こす微小な状態変化である．系全体は外部とエネルギーをやり取りしていない（孤立している）と想定するため，合成系の全エネルギー $E$ は変化しない．

### 3. ゆらぎの物理的な意味

得られた式 $P(\alpha') = C \exp(\Delta S/k)$ において，平衡でエントロピーが最大であることから $\Delta S \leq 0$ が常に成り立つ．これは「平衡状態から遠ざかるほど確率が減少する」ことを意味し，ゆらぎが通常極めて小さい量であることを説明する．特に二次近似によれば分布はガウス型となり，その分散は応答関数と fluctuation-dissipation theorem で結びつく．
