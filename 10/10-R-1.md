# 例題【10-R-1】

## 解答

### 1．揺らぎの確率分布

部分系 I の状態を特徴づける半巨視的変数を $\alpha$ ，その平衡値を $\alpha^*$ とする．
平衡状態からのずれを $\alpha'$ とすれば，揺らぎが生じた状態は

```math
\alpha=\alpha^*+\alpha'
```

と表される．

部分系 I とその周囲の部分系 II を合わせた合成系 I＋II は孤立しているとする．
合成系全体のエネルギー，粒子数，体積をそれぞれ $E,N,V$ とする．

部分系間の相互作用エネルギーを無視できるとき，合成系全体のエントロピーは

```math
S_{\mathrm{total}}=S_I+S_{II}
```

と表される．
ここで $S_I,S_{II}$ はそれぞれ部分系 I，II のエントロピーである．

式（5.68）に基づけば，揺らぎの確率は，合成系全体のエントロピーを用いて，

```math
\begin{aligned}
P(\alpha')=C\exp\bigg\{&
\frac{S(E,N,V,\alpha^*+\alpha')}{k}\\
&-\frac{S(E,N,V,\alpha^*)}{k}
\bigg\}
\end{aligned}
\tag{1}
```

と表される．
ここで $S(E,N,V,\alpha)$ は，全エネルギー $E$ ，全粒子数 $N$ ，全体積 $V$ を固定した合成系全体のエントロピー， $k$ はBoltzmann定数， $C$ は規格化定数である．

以下では，このエントロピー差を，部分系 I を状態 $\alpha^*$ から $\alpha^*+\alpha'$ へ変化させるための最小仕事 $W_{\min}$ に結び付ける．

### 2．部分系 I を変化させる最小仕事

部分系 II は十分に大きな熱浴であり，その温度と圧力をそれぞれ $T^*,p^*$ とする．
部分系 I の体積変化は許すが，粒子交換はないものとする．

まず，部分系 I を部分系 II と接触させたまま，可逆的かつ準静的に変化させる仮想的な操作を考える．
この操作では，部分系 II の温度と圧力は一定に保たれるとする．

ここで， $W_{\min}$ は，部分系 I の体積変化に伴う圧力体積仕事を除き，状態変化のために外部から追加して加える仕事の最小値と定義する．
部分系 I が受け取る熱量を $\delta Q_I$ ，外部から加える仕事を $\delta W_{\mathrm{ext}}$ とする．
部分系 I が受ける圧力体積仕事は $-p^*dV_I$ であるから，第一法則は

```math
dU_I
=
\delta Q_I+\delta W_{\mathrm{ext}}-p^*dV_I
\tag{2}
```

となる．
ここで $U_I,V_I$ は部分系 I の内部エネルギーと体積である．

可逆過程では，

```math
\delta Q_{I,\mathrm{rev}}=T^*dS_I
\tag{3}
```

が成立する．
式（2），（3）から，

```math
\delta W_{\mathrm{ext,rev}}
=dU_I-T^*dS_I+p^*dV_I
```

を得る．
これを初期状態から最終状態まで積分すると，

```math
\begin{aligned}
W_{\min}
&=\int_{\mathrm{rev}}\delta W_{\mathrm{ext,rev}}\\
&=\Delta U_I-T^*\Delta S_I+p^*\Delta V_I
\end{aligned}
\tag{4}
```

となる．
ここで，

```math
\begin{aligned}
\Delta U_I&=U_{I,f}-U_{I,i},\\
\Delta S_I&=S_{I,f}-S_{I,i},\\
\Delta V_I&=V_{I,f}-V_{I,i}
\end{aligned}
```

である．
したがって，

```math
\boxed{
W_{\min}
=\Delta U_I-T^*\Delta S_I+p^*\Delta V_I
}
\tag{5}
```

となる．
これは部分系 I のGibbs自由エネルギーの変化に相当する．

可逆過程が最小仕事を与えることは，エントロピー生成を $S_{\mathrm{gen}}\geq0$ とすると確認できる．
温度 $T^*$ ，圧力 $p^*$ の熱浴に接する過程では，

```math
\Delta S_I=\frac{Q_I}{T^*}+S_{\mathrm{gen}}
```

である．
第一法則に代入すれば，

```math
W_{\mathrm{ext}}
=
\Delta U_I-T^*\Delta S_I+p^*\Delta V_I
+T^*S_{\mathrm{gen}}
```

となる．
したがって，

```math
W_{\mathrm{ext}}\geq
\Delta U_I-T^*\Delta S_I+p^*\Delta V_I
```

であり，等号は可逆過程で成立する．

### 3．実際の揺らぎにおける全エントロピー変化

ここでは，前節の仮想的な仕事の計算とは区別して，実際に起こる揺らぎを考える．
この場合，合成系 I＋II は孤立しているため，エネルギー保存則と体積保存則より，

```math
\Delta U_I+\Delta U_{II}=0,
\qquad
\Delta V_I+\Delta V_{II}=0
\tag{6}
```

が成立する．
粒子交換はないので，部分系 I と II の粒子数はそれぞれ一定である．

部分系 II は十分に大きいため，揺らぎに伴う温度と圧力の変化を無視できる．
その平衡温度と圧力を $T^*,p^*$ とすると，部分系 II の熱力学関係から，

```math
dS_{II}
=
\frac{1}{T^*}dU_{II}
+\frac{p^*}{T^*}dV_{II}
```

である．
これを初期状態から最終状態まで積分し，熱浴の温度と圧力を一定とみなすと，

```math
\begin{aligned}
\Delta S_{II}
&\simeq
\frac{\Delta U_{II}+p^*\Delta V_{II}}{T^*}\\
&=
-\frac{\Delta U_I+p^*\Delta V_I}{T^*}
\end{aligned}
\tag{7}
```

となる．

合成系全体のエントロピー変化は，

```math
\Delta S_{\mathrm{total}}
=\Delta S_I+\Delta S_{II}
\tag{8}
```

である．
式（7），（8）から，

```math
\begin{aligned}
\Delta S_{\mathrm{total}}
&\simeq
\Delta S_I-\frac{\Delta U_I+p^*\Delta V_I}{T^*}\\
&=
-\frac{
\Delta U_I-T^*\Delta S_I+p^*\Delta V_I
}{T^*}\\
&=-\frac{W_{\min}}{T^*}
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
W_{\min}\simeq-T^*\Delta S_{\mathrm{total}}
}
\tag{9}
```

となる．

この関係は，部分系 II の温度と圧力の変化を無視できる近似のもとで成立する．
有限の熱浴では，その熱容量や体積応答に由来する高次の補正が生じるが，熱浴の熱力学極限ではこれらを無視できる．

### 4．粒子交換がある場合

前節までは部分系 I と II の間で粒子交換がない場合を扱った．
粒子交換が可能な場合には，化学ポテンシャル $\mu^*$ に対応する項が必要となる．

この場合，部分系 II のエントロピー変化は，

```math
\Delta S_{II}
\simeq
\frac{
\Delta U_{II}+p^*\Delta V_{II}
-\mu^*\Delta N_{II}
}{T^*}
```

である．
全粒子数保存より $\Delta N_{II}=-\Delta N_I$ なので，

```math
\Delta S_{II}
\simeq
-\frac{
\Delta U_I+p^*\Delta V_I-\mu^*\Delta N_I
}{T^*}
```

となる．
したがって，粒子交換を許す場合の一般化された最小仕事は，

```math
\boxed{
W_{\min}^{\mathrm{gen}}
=
\Delta U_I-T^*\Delta S_I
+p^*\Delta V_I-\mu^*\Delta N_I
}
\tag{10}
```

である．
ここで $W_{\min}^{\mathrm{gen}}$ は，圧力仕事および粒子移動に伴う化学的なエネルギー供給を除いた，外部から加える一般化仕事である．
この定義を用いれば，式（9）と同じ関係が得られる．

### 5．求める確率分布

式（1）から，

```math
P(\alpha')
=
C\exp\left(
\frac{\Delta S_{\mathrm{total}}}{k}
\right)
\tag{11}
```

である．
式（9）を代入すると，

```math
P(\alpha')
\simeq
C\exp\left[
-\frac{W_{\min}(\alpha^*,\alpha')}{kT^*}
\right]
```

となる．
したがって，求める確率分布は，

```math
\boxed{
P(\alpha')
\simeq
C\exp\left\{
-\frac{W_{\min}(\alpha^*,\alpha')}{kT^*}
\right\}
}
\tag{12}
```

である．

部分系 II を熱力学的に十分大きな熱浴とする極限では，温度と圧力の変化に伴う補正が無視できるため，

```math
\boxed{
P(\alpha')
=
C\exp\left\{
-\frac{W_{\min}(\alpha^*,\alpha')}{kT^*}
\right\}
}
```

と表せる．

### 6．物理的な意味

平衡状態 $\alpha^*$ では，孤立した合成系全体のエントロピーが最大となる．
したがって，揺らぎによるエントロピー変化は，

```math
\Delta S_{\mathrm{total}}\leq0
```

である．
式（9）から，

```math
W_{\min}\geq0
```

となる．
すなわち，平衡状態から別の状態へ部分系 I を移すには，非負の最小仕事が必要である．

式（12）によれば，最小仕事 $W_{\min}$ が大きいほど，その揺らぎが生じる確率は小さくなる．
また，温度 $T^*$ が高いほど，仕事に対する確率の減少は緩やかになる．

以上より，部分系 I の揺らぎの確率は，熱浴 II の温度と圧力，および揺らぎを生じさせるために必要な最小仕事によって決まる．
