# 演習問題【10-R-1】

## 解答

### 1．揺らぎの確率分布と合成系

部分系 I の状態を特徴づける半巨視的変数を $\alpha$ とし，その平衡値を $\alpha^*$ とする．
平衡状態からのずれを $\alpha'$ とすれば，揺らぎが生じた状態は

```math
\alpha=\alpha^*+\alpha'
```

と表される．

部分系 I とその周囲の部分系 II を合わせた合成系 I＋II を考える．
平衡状態での合成系全体の内部エネルギーを $E$ ，粒子数を $N$ ，体積を $V$ とする．
合成系全体が孤立している場合，揺らぎの前後でこれらの全体量は一定である．

平衡状態からの揺らぎの確率は，式 (5.68) によってエントロピー差を用いて

```math
\begin{aligned}
P(\alpha')=C\exp\bigg\{&
\frac{
S(E,N,V,\alpha^*+\alpha')
}{
k
}\\
&-\frac{
S(E,N,V,\alpha^*)
}{
k
}
\bigg\}
\end{aligned}
\tag{1}
```

と表される．
ここで， $S(E,N,V,\alpha)$ は，合成系全体が指定された状態にあるときのエントロピー， $k$ は Boltzmann 定数， $C$ は確率分布の規格化定数である．

以下では，この式を最小仕事 $W_{\min}$ を用いた形に書き換える．
そのために，まず最小仕事とエントロピー変化の関係を導く．

### 2．最小仕事とエントロピー変化の関係

部分系 I の状態を $\alpha^*$ から $\alpha^*+\alpha'$ へ変化させるために，合成系に外部から仕事を加えることを考える．
状態変化に必要な仕事が最小となるのは，可逆的な準静的過程で変化させる場合である．

可逆過程では，系が受け取る微小な熱量を $dQ_{\mathrm{rev}}$ とすると，

```math
dQ_{\mathrm{rev}}=T\,dS
\tag{2}
```

が成り立つ．
また，熱力学第一法則より，系に加える仕事 $dW$ は

```math
dU=dQ_{\mathrm{rev}}+dW
```

である．
ここで $U$ は合成系の内部エネルギー， $S$ は合成系のエントロピー， $T$ は過程中の温度である．
式 (2) を代入すれば，

```math
dW=dU-T\,dS
\tag{3}
```

となる．
したがって，最小仕事は

```math
\boxed{
W_{\min}(\alpha^*,\alpha')
=\int_{\mathrm{rev}}(dU-T\,dS)
}
\tag{4}
```

で表される．
積分は，平衡状態 $\alpha^*$ から揺らぎが生じた状態 $\alpha^*+\alpha'$ までの可逆過程に沿って行う．

### 3．孤立系の条件と温度一定の近似

揺らぎを考える合成系 I＋II は孤立系であるため，始状態と終状態での合成系全体の内部エネルギーは等しい．
したがって，

```math
U_{\mathrm{final}}=U_{\mathrm{initial}}=E
```

であり，

```math
\int_{\mathrm{rev}}dU=0
\tag{5}
```

となる．

また，部分系 I は合成系全体に比べて十分に小さい．
そのため，部分系 I の状態を変化させても，合成系全体の温度はほとんど変化しないとみなせる．
過程中の温度 $T$ を，平衡状態にある部分系 II の温度 $T^*$ で近似すると，

```math
T\simeq T^*
\tag{6}
```

である．
この近似を式 (4) に用いると，

```math
\begin{aligned}
W_{\min}(\alpha^*,\alpha')
&\simeq \int_{\mathrm{rev}}dU
-T^*\int_{\mathrm{rev}}dS\\
&=-T^*\int_{\mathrm{rev}}dS
\end{aligned}
```

となる．
ここで，式 (5) より内部エネルギーの項はゼロである．
エントロピーの変化は始状態と終状態での値の差なので，

```math
\begin{aligned}
W_{\min}(\alpha^*,\alpha')
\simeq -T^*\big\{&
S(E,N,V,\alpha^*+\alpha')\\
&-S(E,N,V,\alpha^*)\big\}
\end{aligned}
```

を得る．
したがって，部分系 I が十分に小さく，合成系の温度を一定とみなせる近似のもとで，

```math
\boxed{
W_{\min}(\alpha^*,\alpha')
\simeq -T^*\Delta S
}
\tag{7}
```

である．
ここで，

```math
\Delta S=
S(E,N,V,\alpha^*+\alpha')
-S(E,N,V,\alpha^*)
\tag{8}
```

と定義した．

### 4．求める確率分布の導出

式 (7) より，

```math
\Delta S\simeq-\frac{W_{\min}(\alpha^*,\alpha')}{T^*}
\tag{9}
```

である．
これを，エントロピー差で表された確率分布 (1) に代入すると，

```math
\begin{aligned}
P(\alpha')
&=C\exp\left(\frac{\Delta S}{k}\right)\\
&\simeq C\exp\left[
-\frac{W_{\min}(\alpha^*,\alpha')}{kT^*}
\right]
\end{aligned}
```

となる．
よって，求める分布は

```math
\boxed{
P(\alpha')=
C\exp\left\{
-\frac{W_{\min}(\alpha^*,\alpha')}{kT^*}
\right\}
}
\tag{10}
```

である．
この式は，合成系全体の温度変化を無視できる近似のもとで成立する．

### 5．物理的な意味

平衡状態では，孤立系のエントロピーは最大となる．
したがって，揺らぎによって平衡状態からずれたときには，

```math
\Delta S\leq 0
```

である．
式 (7) から，このとき最小仕事は

```math
W_{\min}\geq 0
```

となる．
つまり，平衡状態から揺らぎた状態を作るには，最小でも非負の仕事が必要である．

式 (10) では，必要な最小仕事 $W_{\min}$ が大きいほど，その状態の確率は小さくなる．
また，温度 $T^*$ が高いほど，仕事に対する確率の減少は緩やかになる．
これは，熱揺らぎによって平衡状態から離れた状態が生じる確率を，必要な仕事と熱エネルギー $kT^*$ の比で表したものである．
