# 演習問題【10-B-12】

## 解答

### 1次元ランダムウォークの到達確率と大ステップ数での漸近形

#### 1．問題の設定

粒子は，時間 $\tau$ ごとに位置を右または左へ距離 $a$ だけ移動し，それぞれの確率は $1/2$ である．
初期位置を $xa$ ， $n$ ステップ後の位置を $ya$ とする．
ここで $x,y$ は整数である．
到達確率を $P_n(x|y)$ と書く．

1ステップの確率と初期条件は，

```math
P_1(x|y)
=\frac12\delta_{y,x-1}+\frac12\delta_{y,x+1},
\qquad
P_0(x|y)=\delta_{x,y}
\tag{1}
```

である．
ここで $\delta_{i,j}$ は $i=j$ のとき1，それ以外では0となる Kronecker のデルタである．

求めるのは，Smoluchowski の方程式

```math
P_n(x|y)=\sum_{z=-\infty}^{\infty}
P_{n-1}(x|z)P_1(z|y)
\tag{2}
```

を解いて到達確率を求め，さらに $n$ が大きいときの漸近形を示すことである．

#### 2．漸化式を導く

式 (2) に式 (1) の $P_1(z|y)$ を代入すると，

```math
\begin{aligned}
P_n(x|y)
&=\sum_{z=-\infty}^{\infty}P_{n-1}(x|z)
\left[
\frac12\delta_{y,z-1}+\frac12\delta_{y,z+1}
\right].
\end{aligned}
```

第1項は $z=y+1$ ，第2項は $z=y-1$ のときだけ寄与する．
したがって，

```math
\boxed{
P_n(x|y)
=\frac12P_{n-1}(x|y+1)
+\frac12P_{n-1}(x|y-1)
}
\tag{3}
```

を得る．
これが，到達確率を求めるための漸化式である．

#### 3．生成関数を用いて漸化式を解く

##### 3.1．生成関数を定義する

ヒントに従い，

```math
\boxed{
Q_n(\xi)=\sum_{y=-\infty}^{\infty}P_n(x|y)\xi^y
}
\tag{4}
```

と定義する．
ここで $\xi$ は形式的な変数である．
この変換を用いると，位置 $y$ のずれを伴う漸化式を，生成関数の簡単な代数関係へと変換できる．

式 (3) の両辺に $\xi^y$ を掛け，すべての整数 $y$ について和をとると，

```math
\begin{aligned}
Q_n(\xi)
={}&\frac12\sum_yP_{n-1}(x|y+1)\xi^y\\
&+\frac12\sum_yP_{n-1}(x|y-1)\xi^y
\end{aligned}
\tag{5}
```

となる．
第1項では $y'=y+1$ と置くと，

```math
\sum_yP_{n-1}(x|y+1)\xi^y
=\xi^{-1}Q_{n-1}(\xi)
```

である．
第2項では $y'=y-1$ と置くと，

```math
\sum_yP_{n-1}(x|y-1)\xi^y
=\xi Q_{n-1}(\xi)
```

となる．
したがって，

```math
\boxed{
Q_n(\xi)=\frac12\left(\xi+\frac1{\xi}\right)
Q_{n-1}(\xi)
}
\tag{6}
```

が得られる．

##### 3.2．生成関数を解く

初期条件 $P_0(x|y)=\delta_{x,y}$ より，

```math
Q_0(\xi)=\sum_y\delta_{x,y}\xi^y=\xi^x
\tag{7}
```

である．
式 (6) を繰り返し適用すると，

```math
\boxed{
Q_n(\xi)=
\left[\frac12\left(\xi+\frac1{\xi}\right)\right]^n\xi^x
}
\tag{8}
```

を得る．
これで生成関数が求まった．

#### 4．展開係数から厳密な到達確率を求める

式 (8) を二項定理で展開する．

```math
\begin{aligned}
Q_n(\xi)
&=\frac{\xi^x}{2^n}(\xi+\xi^{-1})^n\\
&=\frac1{2^n}
\sum_{j=0}^n
\binom nj\,\xi^{x+n-2j}
\end{aligned}
\tag{9}
```

ここで， $\xi$ の指数を $y=x+n-2j$ と比較する．
すなわち，

```math
j=\frac{n+x-y}{2}
```

である．
二項係数の対称性 $\binom nj=\binom n{n-j}$ を用いれば，確率は次のように表される．

```math
\boxed{
P_n(x|y)=
\begin{cases}
\displaystyle
\frac{n!}{
\left(\dfrac{n+y-x}{2}\right)!
\left(\dfrac{n-y+x}{2}\right)!}\,2^{-n},
&
\begin{array}{l}
|y-x|\leq n,\\[-2pt]
n+y-x\text{ が偶数}
\end{array}\\[12pt]
0,&\text{それ以外}
\end{cases}
}
\tag{10}
```

これが厳密解である．

この結果は，二項分布としても理解できる．
$n$ 回の移動のうち，右向きの移動を $r$ 回，左向きの移動を $n-r$ 回行ったとする．
そのときの変位は $m=y-x$ であるため，

```math
m=r-(n-r)=2r-n
```

となる．
よって，

```math
r=\frac{n+m}{2}
```

である．
右向きの移動を $r$ 回選ぶ方法は $\binom nr$ 通りであり，各経路の確率は $2^{-n}$ なので，式 (10) と一致する．

また，変位 $m$ は $n$ と同じ偶奇性をもつ必要がある．
そのため， $n$ ステップ後には，格子点の半分にしか到達できない．

#### 5．大きな $n$ における Gaussian 近似

##### 5.1．Stirling の公式を適用する

変位を

```math
m=y-x
\tag{11}
```

とおく．
到達可能で $|m|\leq n$ のとき，式 (10) は，

```math
P_n(x|y)
=\frac{n!}{
\left(\dfrac{n+m}{2}\right)!
\left(\dfrac{n-m}{2}\right)!}\,2^{-n}
\tag{12}
```

である．

階乗が大きい場合には，Stirling の公式

```math
\log N!\simeq N\log N-N+\frac12\log(2\pi N)
\tag{13}
```

を用いる．
$q=m/n$ とおくと，式 (12) は，

```math
\begin{aligned}
\log P_n(x|y)\simeq
&-\frac n2\left[
(1+q)\log(1+q)+(1-q)\log(1-q)
\right]\\
&+\frac12\log\left(\frac{2}{\pi n(1-q^2)}\right)
\end{aligned}
\tag{14}
```

となる．
これは， $n$ が大きく，両方向の移動回数が十分に大きい場合の Stirling 近似である．

典型的な変位では $m=O(\sqrt n)$ なので， $q=m/n$ は小さい．
このとき，

```math
\begin{aligned}
&(1+q)\log(1+q)+(1-q)\log(1-q)\\
&\qquad=q^2+O(q^4)
\end{aligned}
\tag{15}
```

である．
式 (14) の主要項を残すと，

```math
\log P_n(x|y)
\simeq-\frac{m^2}{2n}
+\frac12\log\left(\frac{2}{\pi n}\right)
```

となる．
したがって，到達可能な格子点について，

```math
\boxed{
P_n(x|y)\simeq
\sqrt{\frac{2}{\pi n}}
\exp\left[-\frac{(y-x)^2}{2n}\right]
}
\tag{16}
```

を得る．
これは $n$ が大きく，典型的な変位 $|y-x|=O(\sqrt n)$ に対する Gaussian 近似である．
到達不可能な偶奇の格子点では，確率は厳密にゼロのままである．

**注意：** Gaussian 近似の係数は $\sqrt{2/(\pi n)}$ であり， $1/\sqrt{2\pi n}$ ではない．
偶奇条件によって，各時刻に到達可能な格子点が半分に限られるため，確率が非ゼロの各格子点の確率密度は，通常の全格子点に対する Gaussian 近似の2倍となる．

#### 6．拡散方程式との関係

物理的な位置を $R=a(y-x)=am$ ，経過時間を $t=n\tau$ とする．
式 (16) から，物理的な変位の分散は，

```math
\boxed{
\overline{R^2}=na^2
}
\tag{17}
```

である．
一方，1次元拡散方程式

```math
\frac{\partial p_{\mathrm{cont}}}{\partial t}
=D\frac{\partial^2p_{\mathrm{cont}}}{\partial R^2}
\tag{18}
```

の基本解は，

```math
\boxed{
p_{\mathrm{cont}}(R,t)
=\frac1{\sqrt{4\pi Dt}}
\exp\left(-\frac{R^2}{4Dt}\right)
}
\tag{19}
```

である．
この分布の分散は $2Dt$ なので，式 (17) と比較すると，

```math
2Dt=na^2,\qquad t=n\tau
```

である．
したがって，

```math
\boxed{
D=\frac{a^2}{2\tau}
}
\tag{20}
```

となる．
これがランダムウォークの拡散係数である．

固定したステップ数 $n$ では，粒子は $2a$ 間隔の格子点にのみ到達できる．
そのため，到達可能な格子点の確率と連続的な確率密度の関係は，

```math
P_n(x|y)\simeq
2a\,p_{\mathrm{cont}}(a(y-x),n\tau)
\tag{21}
```

である．
式 (19)，(20) を用いると，

```math
\boxed{
P_n(x|y)\simeq
\sqrt{\frac{2}{\pi n}}
\exp\left[-\frac{(y-x)^2}{2n}\right]
}
\tag{22}
```

となり，式 (16) と一致する．
ここで確率密度 $p_{\mathrm{cont}}$ は単位長さあたりの量であるため，格子点の確率を得るには，その点に対応する間隔を掛ける必要がある．

なお，空間的に粗視化して偶奇の格子点をまとめて扱う場合には，滑らかな Gaussian の包絡線を用いることができる．
その場合は連続密度を格子間隔 $a$ と対応させた表現も可能であるが，固定したステップ数における各格子点の厳密な確率と，粗視化した連続密度は区別する必要がある．

#### 結論

生成関数による解法から，ランダムウォークの厳密な到達確率は，

```math
\boxed{
P_n(x|y)=
\begin{cases}
\displaystyle
\frac{n!}{
\left(\dfrac{n+y-x}{2}\right)!
\left(\dfrac{n-y+x}{2}\right)!}\,2^{-n},
&
|y-x|\leq n,\quad n+y-x\text{ が偶数},\\[8pt]
0,&\text{それ以外}
\end{cases}
}
```

となる．
さらに，到達可能な位置で $n$ が大きいとき，

```math
\boxed{
P_n(x|y)\simeq
\sqrt{\frac{2}{\pi n}}
\exp\left[-\frac{(y-x)^2}{2n}\right]
}
```

である．
物理的な変位と時間を用いると，拡散係数は

```math
\boxed{D=\frac{a^2}{2\tau}}
```

となる．
このように，離散的なランダムウォークの到達確率は，長時間・長距離の極限で拡散方程式の Gaussian 型分布へとつながるのである．
