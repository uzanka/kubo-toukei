# 演習問題【10-B-13】

## 解答

### 1．Langevin の式と緩和時間

微粒子の速度 $v(t)$ は，次の Langevin の式に従う．

```math
m\frac{dv}{dt}=-\zeta v+F(t)
```

ここで， $m$ は粒子の質量， $\zeta$ は摩擦係数， $F(t)$ は流体分子との衝突などによる揺動力である．
揺動力については，

```math
\overline{F(t)}=0
```

```math
\overline{F(t)F(t')}=2\zeta kT\delta(t-t')
```

が仮定されている．
上線は確率的な揺らぎについての平均を表し， $k$ は Boltzmann 定数， $T$ は絶対温度である．
また， $\delta(t-t')$ は Dirac のデルタ関数であり，異なる時刻の揺動力の相関がゼロであるという性質を表している．

まず，緩和時間

```math
\tau=\frac{m}{\zeta}
```

を定義する．
これは，摩擦によって粒子の速度が減衰する時間の尺度である．
これを用いると，運動方程式は

```math
\frac{dv}{dt}=-\frac{1}{\tau}v+\frac{1}{m}F(t)
```

と書き換えられる．

### 2．速度の平均を求める

上の微分方程式は，積分因子 $e^{t/\tau}$ を用いると解くことができる．
両辺にこの積分因子を掛けると，

```math
\frac{d}{dt}\left(v(t)e^{t/\tau}\right)
=\frac{1}{m}F(t)e^{t/\tau}
```

となる．
これを初期時刻 $t_0$ から時刻 $t$ まで積分すると，

```math
v(t)e^{t/\tau}-v(t_0)e^{t_0/\tau}
=\frac{1}{m}\int_{t_0}^{t}F(s)e^{s/\tau}\,ds
```

を得る．
したがって，

```math
v(t)=v(t_0)e^{-(t-t_0)/\tau}
+\frac{1}{m}\int_{t_0}^{t}
e^{-(t-s)/\tau}F(s)\,ds
\tag{1}
```

である．
この式は，初期速度の影響と，その後に加わる揺動力の影響を分けて表している．

初期速度 $v(t_0)$ が固定されているとして，式 (1) の平均をとると，

```math
\begin{aligned}
\overline{v(t)}
&=v(t_0)e^{-(t-t_0)/\tau}\\
&\quad+\frac{1}{m}\int_{t_0}^{t}
e^{-(t-s)/\tau}\overline{F(s)}\,ds
\end{aligned}
```

となる．
揺動力の平均は $\overline{F(s)}=0$ であるため，

```math
\boxed{\overline{v(t)}
=v(t_0)e^{-(t-t_0)/\tau}}
\tag{2}
```

が得られる．
つまり，初期速度の平均は緩和時間 $\tau$ で指数関数的に減衰する．

十分に時間が経過した定常状態では，初期速度の影響は消失する．
有限の初期速度を仮定して $t_0\to-\infty$ とすると，式 (1) は

```math
v(t)=\frac{1}{m}\int_{-\infty}^{t}
e^{-(t-s)/\tau}F(s)\,ds
\tag{3}
```

となる．
この式の平均をとると，

```math
\overline{v(t)}
=\frac{1}{m}\int_{-\infty}^{t}
e^{-(t-s)/\tau}\overline{F(s)}\,ds=0
```

である．
よって，定常状態における速度の平均は

```math
\boxed{\overline{v(t)}=0}
\tag{4}
```

となる．

### 3．速度の相関関数を求める

次に，定常状態の速度相関関数

```math
C(t,t')=\overline{v(t)v(t')}
```

を求める．
式 (3) を時刻 $t$ と $t'$ についてそれぞれ書き，掛け合わせて平均すると，

```math
\begin{aligned}
C(t,t')
&=\frac{1}{m^2}
\int_{-\infty}^{t}ds
\int_{-\infty}^{t'}ds'\\
&\quad\times e^{-(t-s)/\tau}
e^{-(t'-s')/\tau}
\overline{F(s)F(s')}
\end{aligned}
```

となる．
揺動力の相関関数

```math
\overline{F(s)F(s')}=2\zeta kT\delta(s-s')
```

を代入すると，

```math
\begin{aligned}
C(t,t')
&=\frac{2\zeta kT}{m^2}
\int_{-\infty}^{t}ds
\int_{-\infty}^{t'}ds'\\
&\quad\times e^{-(t-s)/\tau}
e^{-(t'-s')/\tau}\delta(s-s')
\end{aligned}
```

を得る．

デルタ関数には，積分の中で $\delta(s-s')$ が $s=s'$ の点を選び出すという性質がある．
したがって，二つの積分のうち一つを実行すると，

```math
C(t,t')
=\frac{2\zeta kT}{m^2}
\int_{-\infty}^{\min(t,t')}
e^{-(t-s)/\tau}e^{-(t'-s)/\tau}\,ds
\tag{5}
```

となる．
積分の上限が $\min(t,t')$ となるのは，もともとの積分範囲が $s\leq t$ と $s\leq t'$ の両方を満たさなければならないためである．

ここで，まず $t\geq t'$ の場合を考えると，式 (5) は

```math
\begin{aligned}
C(t,t')
&=\frac{2\zeta kT}{m^2}
\int_{-\infty}^{t'}
e^{-(t-s)/\tau}e^{-(t'-s)/\tau}\,ds\\
&=\frac{2\zeta kT}{m^2}
e^{-(t+t')/\tau}
\int_{-\infty}^{t'}e^{2s/\tau}\,ds
\end{aligned}
```

となる．
積分を実行すれば，

```math
\begin{aligned}
C(t,t')
&=\frac{2\zeta kT}{m^2}
e^{-(t+t')/\tau}
\frac{\tau}{2}e^{2t'/\tau}\\
&=\frac{\zeta kT\tau}{m^2}
e^{-(t-t')/\tau}
\end{aligned}
```

である．
ここで $\tau=m/\zeta$ を代入すると，

```math
\frac{\zeta kT\tau}{m^2}=\frac{kT}{m}
```

となるため，

```math
C(t,t')=\frac{kT}{m}e^{-(t-t')/\tau}
\qquad (t\geq t')
```

を得る．

一方，速度相関関数は $t$ と $t'$ の交換について対称であるため， $t<t'$ の場合も含めると，

```math
\boxed{
\overline{v(t)v(t')}
=\frac{kT}{m}e^{-|t-t'|/\tau}
}
\tag{6}
```

となる．
これが定常状態における速度の相関関数である．

特に $t=t'$ とすれば，

```math
\boxed{\overline{v(t)^2}=\frac{kT}{m}}
\tag{7}
```

となる．
これは速度の二乗平均が $kT/m$ であることを意味する．
また，式 (6) から，二つの時刻の隔たり $|t-t'|$ が大きくなるほど速度の相関が指数関数的に小さくなることが分かる．

### 4．変位の平均二乗を求める

時刻 $0$ から時刻 $t$ までの変位は，速度を積分して

```math
x(t)-x(0)=\int_0^t v(t_1)\,dt_1
```

と表せる．
したがって，変位の二乗平均は

```math
\begin{aligned}
\overline{\{x(t)-x(0)\}^2}
&=\overline{\left(\int_0^t v(t_1)\,dt_1\right)^2}\\
&=\int_0^t dt_1\int_0^t dt_2\,
\overline{v(t_1)v(t_2)}
\end{aligned}
```

となる．
ここに式 (6) を代入すると，

```math
\overline{\{x(t)-x(0)\}^2}
=\frac{kT}{m}
\int_0^t dt_1\int_0^t dt_2\,
e^{-|t_1-t_2|/\tau}
\tag{8}
```

を得る．

この二重積分は， $t_1$-$t_2$ 平面上の正方形 $0\leq t_1,t_2\leq t$ にわたる積分である．
被積分関数は $t_1$ と $t_2$ を交換しても変わらないため，正方形を対角線 $t_1=t_2$ で二つの三角形に分け，一方の積分を 2 倍すればよい．
対角線は積分領域の面積をもたないので，二重計算には影響しない．

よって，

```math
\begin{aligned}
\overline{\{x(t)-x(0)\}^2}
&=2\frac{kT}{m}\int_0^t dt_1
\int_0^{t_1}dt_2\,
e^{-(t_1-t_2)/\tau}
\end{aligned}
```

である．
内側の積分で $u=t_1-t_2$ と置くと，

```math
\begin{aligned}
\int_0^{t_1}e^{-(t_1-t_2)/\tau}\,dt_2
&=\int_0^{t_1}e^{-u/\tau}\,du\\
&=\tau\left(1-e^{-t_1/\tau}\right)
\end{aligned}
```

となる．
これを代入すると，

```math
\begin{aligned}
\overline{\{x(t)-x(0)\}^2}
&=2\frac{kT}{m}\int_0^t
\tau\left(1-e^{-t_1/\tau}\right)\,dt_1\\
&=2\frac{kT\tau}{m}
\left[t-\tau\left(1-e^{-t/\tau}\right)\right]
\end{aligned}
```

を得る．
さらに $\tau=m/\zeta$ より，

```math
\boxed{
\overline{\{x(t)-x(0)\}^2}
=\frac{2kT}{\zeta}
\left[t-\tau\left(1-e^{-t/\tau}\right)\right]
}
\tag{9}
```

となる．
これが変位の平均二乗の厳密な式である．

### 5．長時間極限と拡散係数

十分に長い時間間隔 $t\gg\tau$ では，

```math
e^{-t/\tau}\simeq 0
```

である．
また，この極限では $\tau$ に比べて $t$ が十分大きいため，式 (9) の括弧内では $t$ が支配的となる．
したがって，

```math
\overline{\{x(t)-x(0)\}^2}
\simeq \frac{2kT}{\zeta}t
```

となり，

```math
\boxed{
\overline{\{x(t)-x(0)\}^2}
\simeq 2Dt,\qquad D=\frac{kT}{\zeta}
}
\tag{10}
```

を得る．
ここで $D$ は拡散係数である．

拡散係数は，時間の経過に伴って粒子の位置の分布がどれほど広がるかを表す量である．
長時間では平均二乗変位が時間に比例して増加するため，粒子の運動は拡散として記述される．

一方，短時間 $t\ll\tau$ では，指数関数を

```math
e^{-t/\tau}\simeq 1-\frac{t}{\tau}
+\frac{t^2}{2\tau^2}
```

と近似できる．
式 (9) に代入すると，

```math
\overline{\{x(t)-x(0)\}^2}
\simeq \frac{kT}{m}t^2
```

となる．
この時間領域では，摩擦によって速度が十分に緩和する前であり，運動は慣性の影響を強く受ける．
このように，短時間では平均二乗変位が $t^2$ に比例し，長時間では $t$ に比例するという違いが現れる．

### 6．Einstein の関係

一定の力 $F_0$ を粒子に加え，揺動力の平均をゼロとすると，平均速度の定常値は運動方程式から

```math
0=-\zeta v+F_0
```

を満たす．
したがって，

```math
v=\frac{F_0}{\zeta}
```

である．
力に対する速度の比例係数を易動度 $\mu$ と定義すると，

```math
v=\mu F_0,\qquad \mu=\frac{1}{\zeta}
```

となる．
これを式 (10) の拡散係数に代入すれば，

```math
\boxed{D=\mu kT}
```

を得る．
これが Einstein の関係式である．
すなわち，拡散係数は，粒子が熱運動によって拡散する度合いと，外力に対してどれだけ動きやすいかを結びつける量である．
