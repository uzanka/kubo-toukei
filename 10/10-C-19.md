# 演習問題【10-C-19】

## 解答

### 1．問題の設定と基本仮定

電子系の Boltzmann 方程式を考える．

以下では，空間的に一様な電子系に一様な外部電場 $\boldsymbol{E}(t)$ が作用する場合を考える．

したがって，分布関数の空間依存性はなく，空間移流項は現れない．

また，古典的かつ非縮退の電子系を仮定し，平衡分布には Maxwell-Boltzmann 分布を用いる．

速度と運動量の関係は，

```math
\boldsymbol{p}=m\boldsymbol{v}
```

である．

問題文では衝突演算子が速度空間で定義されているため，以下では速度空間に統一して議論する．

運動量空間の分布関数を $f_p(\boldsymbol{p},t)$ ，速度空間の分布関数を $F(\boldsymbol{v},t)$ とする．

電子数の保存から，

```math
f_p(\boldsymbol{p},t)\,d^3p
=
F(\boldsymbol{v},t)\,d^3v
```

である．

```math
d^3p=m^3d^3v
```

より，

```math
\boxed{
F(\boldsymbol{v},t)
=
m^3f_p(m\boldsymbol{v},t)
}
```

となる．

電子の数密度を $n$ ，温度を $T$ とすると，平衡分布は，

```math
\boxed{
F_0(\boldsymbol{v})
=
n\left(\frac{m}{2\pi k_{\mathrm B}T}\right)^{3/2}
\exp\left(
-\frac{m\boldsymbol{v}^2}{2k_{\mathrm B}T}
\right)
}
```

である．

ここで，

```math
\int F_0(\boldsymbol{v})\,d^3v=n
```

である．

### 2．衝突演算子と平衡分布

問題文で与えられた衝突演算子を速度空間で書くと，

```math
\boxed{
\begin{aligned}
DF(\boldsymbol{v})
={}&
F(\boldsymbol{v})
\int W(\boldsymbol{v},\boldsymbol{v}')\,d^3v'\\
&-
\int W(\boldsymbol{v}',\boldsymbol{v})
F(\boldsymbol{v}')\,d^3v'
\end{aligned}
}
\tag{1}
```

である．

第一項は速度 $\boldsymbol{v}$ から他の速度への散乱による分布の減少を表し，第二項は他の速度から $\boldsymbol{v}$ への散乱による分布の増加を表す．

この演算子は電子数を保存する．

実際，速度空間全体で積分すると，

```math
\begin{aligned}
\int DF(\boldsymbol{v})\,d^3v
={}&
\iint
F(\boldsymbol{v})
W(\boldsymbol{v},\boldsymbol{v}')
\,d^3v\,d^3v'\\
&-
\iint
W(\boldsymbol{v}',\boldsymbol{v})
F(\boldsymbol{v}')
\,d^3v'\,d^3v
\end{aligned}
```

となる．

第二項で積分変数を交換すれば，第一項と一致するため，

```math
\boxed{
\int DF(\boldsymbol{v})\,d^3v=0
}
\tag{2}
```

である．

#### 平衡分布に関する条件

衝突直後の平衡状態では分布関数が時間的に変化しないため，

```math
\boxed{
DF_0=0
}
\tag{3}
```

が成立する．

ただし，散乱によってエネルギーが保存されるという条件だけでは，一般に式 (3) は保証されない．

そのため，衝突過程が平衡分布に対して詳細釣り合いを満たすことを仮定する．

詳細釣り合い条件は，

```math
\boxed{
W(\boldsymbol{v},\boldsymbol{v}')
F_0(\boldsymbol{v})
=
W(\boldsymbol{v}',\boldsymbol{v})
F_0(\boldsymbol{v}')
}
\tag{4}
```

である．

散乱が弾性的であるため，

```math
|\boldsymbol{v}|=|\boldsymbol{v}'|
```

が成立する．

Maxwell-Boltzmann 分布は速度の大きさだけに依存するため，

```math
F_0(\boldsymbol{v})
=
F_0(\boldsymbol{v}')
```

となる．

したがって，詳細釣り合い条件は，許される散乱状態間で，

```math
W(\boldsymbol{v},\boldsymbol{v}')
=
W(\boldsymbol{v}',\boldsymbol{v})
```

を意味する．

これを式 (1) に代入すると，

```math
DF_0=0
```

が得られる．

したがって，式 (3) が正当化される．

なお，詳細釣り合いは弾性という条件だけから自動的に導かれるものではなく，平衡状態の微視的可逆性に関する追加条件である．

### 3．Boltzmann 方程式の線形化

電子の電荷は $-e$ であるため，電場による力は，

```math
\boldsymbol{F}=-e\boldsymbol{E}(t)
```

である．

速度空間における Boltzmann 方程式は，

```math
\frac{\partial F}{\partial t}
-\frac{e}{m}\boldsymbol{E}(t)
\cdot\nabla_{\boldsymbol{v}}F
=-DF
```

である．

ここで，

```math
F(\boldsymbol{v},t)
=
F_0(\boldsymbol{v})
+
g(\boldsymbol{v},t)
\tag{5}
```

と置く．

$g$ は電場の一次の摂動である．

式 (5) を Boltzmann 方程式に代入すると，

```math
\begin{aligned}
\frac{\partial g}{\partial t}
-\frac{e}{m}\boldsymbol{E}(t)
\cdot\nabla_{\boldsymbol{v}}F_0
-\frac{e}{m}\boldsymbol{E}(t)
\cdot\nabla_{\boldsymbol{v}}g
=-Dg
\end{aligned}
```

となる．

ここで，

```math
\boldsymbol{E}\cdot\nabla_{\boldsymbol{v}}g
```

は電場と一次摂動 $g$ の積であるため，電場の二次の項となる．

したがって，電場の一次までの近似では無視する．

整理すると，

```math
\boxed{
\frac{\partial g}{\partial t}+Dg
=
\frac{e}{m}
\boldsymbol{E}(t)
\cdot\nabla_{\boldsymbol{v}}F_0
}
\tag{6}
```

となる．

次に，平衡分布を速度で微分する．

```math
F_0(\boldsymbol{v})
\propto
\exp\left(
-\frac{m\boldsymbol{v}^2}{2k_{\mathrm B}T}
\right)
```

より，

```math
\nabla_{\boldsymbol{v}}F_0
=
-\frac{m\boldsymbol{v}}{k_{\mathrm B}T}F_0
\tag{7}
```

である．

これを式 (6) に代入すると，

```math
\boxed{
\frac{\partial g}{\partial t}
+Dg
=
-\frac{e}{k_{\mathrm B}T}
\boldsymbol{v}\cdot\boldsymbol{E}(t)
F_0
}
\tag{8}
```

を得る．

これが電場の一次までの Boltzmann 方程式である．

### 4．時間を含む Boltzmann 方程式の形式解

まず，線形方程式，

```math
\frac{\partial g}{\partial t}+Dg=S(t)
```

を考える．

有限の初期時刻 $t_0$ における初期条件を $g(t_0)$ とすると，形式解は，

```math
\boxed{
\begin{aligned}
g(t)
={}&
e^{-D(t-t_0)}g(t_0)\\
&+
\int_{t_0}^{t}
e^{-D(t-t')}S(t')\,dt'
\end{aligned}
}
\tag{9}
```

である．

ここで，$e^{-Ds}$ は衝突演算子 $D$ による時間 $s$ の発展を表す演算子である．

実際に式 (9) を時間微分すると，

```math
\begin{aligned}
\frac{\partial g}{\partial t}
={}&
-De^{-D(t-t_0)}g(t_0)\\
&+
S(t)
-
D\int_{t_0}^{t}
e^{-D(t-t')}S(t')\,dt'
\end{aligned}
```

となる．

したがって，

```math
\frac{\partial g}{\partial t}+Dg=S(t)
```

が成立する．

問題では $t=-\infty$ において電場がなく，電子系は平衡分布 $F_0$ にある．

したがって，因果的な初期条件として，

```math
g(-\infty)=0
```

を採用する．

ただし，この極限を取るには，初期項が消失し，時間積分が収束することが必要である．

特に，弾性散乱では速度の大きさだけに依存する分布が衝突演算子の零モードとなるため， $e^{-Ds}$ が任意の分布に対して減衰するとは限らない．

ここで必要なのは，電場による駆動項

```math
v_lF_0
```

を含む電流応答の部分空間で十分な緩和が起こることである．

すなわち，

```math
\lim_{t_0\to-\infty}
e^{-D(t-t_0)}g(t_0)=0
```

となり，対応する畳み込み積分が収束することを仮定する．

この条件のもとで，

```math
g(t)
=
\int_{-\infty}^{t}
e^{-D(t-t')}S(t')\,dt'
```

となる．

式 (8) を代入し，電場を成分表示すると，

```math
\boxed{
\begin{aligned}
g(\boldsymbol{v},t)
={}&
-\frac{e}{k_{\mathrm B}T}
\sum_l
\int_{-\infty}^{t}
E_l(t')\\
&\quad\times
\left[
e^{-D(t-t')}
(v_lF_0)
\right](\boldsymbol{v})\,dt'
\end{aligned}
}
\tag{10}
```

となる．

ここで，演算子 $e^{-D(t-t')}$ は $v_lF_0$ 全体に作用する．

### 5．電流と応答核

分布関数から得られる巨視的な平均電流密度を $j_i^{\mathrm{resp}}(t)$ とする．

その定義は，

```math
j_i^{\mathrm{resp}}(t)
=
-e\int v_iF(\boldsymbol{v},t)\,d^3v
\tag{11}
```

である．

平衡分布は等方的であるため，

```math
\int v_iF_0(\boldsymbol{v})\,d^3v=0
```

となる．

したがって，

```math
j_i^{\mathrm{resp}}(t)
=
-e\int v_ig(\boldsymbol{v},t)\,d^3v
```

である．

式 (10) を代入すると，

```math
\begin{aligned}
j_i^{\mathrm{resp}}(t)
={}&
\frac{e^2}{k_{\mathrm B}T}
\sum_l
\int_{-\infty}^{t}
E_l(t')\\
&\quad\times
\left\{
\int v_i
\left[
e^{-D(t-t')}(v_lF_0)
\right](\boldsymbol{v})
\,d^3v
\right\}dt'
\end{aligned}
\tag{12}
```

となる．

ここで，時間差 $s\geq0$ に対して，

```math
\boxed{
\phi_{li}(s)
=
\frac{e^2}{k_{\mathrm B}T}
\int
v_i
\left[
e^{-Ds}(v_lF_0)
\right](\boldsymbol{v})
\,d^3v
}
\tag{13}
```

と定義する．

すると，

```math
\boxed{
j_i^{\mathrm{resp}}(t)
=
\sum_l
\int_{-\infty}^{t}
E_l(t')\phi_{li}(t-t')\,dt'
}
\tag{14}
```

となる．

これは電流の応答が現在の電場だけでなく，過去の電場の履歴にも依存することを表す．

### 6．応答核と平衡電流相関関数

ここでは，巨視的な平均電流と微視的な電流の揺らぎを区別する．

Boltzmann 方程式から得られる $j_i^{\mathrm{resp}}$ は平均電流密度である．

一方，平衡状態における電流相関関数は，電子の微視的な速度の揺らぎを用いて定義する必要がある．

#### 6.1 微視的電流の定義

導体の体積を $V$，電子数を $N$ とする．

電子1個の速度を $\boldsymbol{v}_a(t)$ とすると，系全体の微視的電流を，

```math
\boxed{
\mathcal{J}_i(t)
=
-e\sum_{a=1}^{N}v_{a,i}(t)
}
\tag{15}
```

と定義する．

その体積平均は微視的電流密度である．

```math
j_i^{\mathrm{mic}}(t)
=
\frac{\mathcal{J}_i(t)}{V}
```

平衡状態では速度分布が等方的であるため，

```math
\langle\mathcal{J}_i\rangle_{\mathrm{eq}}=0
```

である．

一般には電流の揺らぎを，

```math
\delta\mathcal{J}_i
=
\mathcal{J}_i
-
\langle\mathcal{J}_i\rangle_{\mathrm{eq}}
```

と定義する．

ここでは平衡平均がゼロなので，

```math
\delta\mathcal{J}_i=\mathcal{J}_i
```

となる．

#### 6.2 電子の遷移確率と時間発展演算子

時刻 $0$ に速度 $\boldsymbol{v}_0$ を持つ電子が，時間 $s$ 後に速度 $\boldsymbol{v}$ を持つ確率密度を，

```math
P(\boldsymbol{v},s\mid\boldsymbol{v}_0,0)
```

とする．

衝突過程が Markov 過程として記述できるとき，この遷移確率は，

```math
\frac{\partial P}{\partial s}
=
-D_{\boldsymbol{v}}P
```

を満たす．

初期条件は，

```math
P(\boldsymbol{v},0\mid\boldsymbol{v}_0,0)
=
\delta^{(3)}(\boldsymbol{v}-\boldsymbol{v}_0)
```

である．

したがって，任意の速度分布 $h$ に対して，

```math
\boxed{
\left[
e^{-Ds}h
\right](\boldsymbol{v})
=
\int
P(\boldsymbol{v},s\mid\boldsymbol{v}_0,0)
h(\boldsymbol{v}_0)\,d^3v_0
}
\tag{16}
```

が成立する．

特に，

```math
\boxed{
\begin{aligned}
&
\left[
e^{-Ds}(v_lF_0)
\right](\boldsymbol{v})\\
&=
\int
P(\boldsymbol{v},s\mid\boldsymbol{v}_0,0)
v_{0l}F_0(\boldsymbol{v}_0)
\,d^3v_0
\end{aligned}
}
\tag{17}
```

となる．

#### 6.3 一電子の速度相関関数

平衡状態における一電子の速度分布は，

```math
p_0(\boldsymbol{v})
=
\frac{F_0(\boldsymbol{v})}{n}
```

である．

したがって，一電子の速度相関関数は，

```math
\begin{aligned}
\langle v_i(s)v_l(0)\rangle_1
={}&
\int d^3v_0\,p_0(\boldsymbol{v}_0)
v_{0l}\\
&\quad\times
\int d^3v\,
P(\boldsymbol{v},s\mid\boldsymbol{v}_0,0)
v_i
\end{aligned}
\tag{18}
```

で与えられる．

式 (17) を用いると，

```math
\boxed{
\begin{aligned}
&e^2
\int
v_i
\left[
e^{-Ds}(v_lF_0)
\right](\boldsymbol{v})
\,d^3v\\
&=
ne^2
\langle v_i(s)v_l(0)\rangle_1
\end{aligned}
}
\tag{19}
```

となる．

#### 6.4 独立電子近似

Boltzmann 方程式による一粒子分布の記述に対応して，ここでは電子間の動的相関を無視し，電子が独立に運動する近似を用いる．

このとき，異なる電子に由来する速度相関は，

```math
\langle
v_{a,i}(s)v_{b,l}(0)
\rangle=0
\qquad(a\neq b)
```

となる．

したがって，系全体の電流相関関数は，

```math
\begin{aligned}
&
\left\langle
\delta\mathcal{J}_i(s)
\delta\mathcal{J}_l(0)
\right\rangle\\
&=
e^2
\sum_{a,b}
\left\langle
v_{a,i}(s)v_{b,l}(0)
\right\rangle\\
&=
Ne^2
\langle v_i(s)v_l(0)\rangle_1
\end{aligned}
\tag{20}
```

となる．

ここで，

```math
n=\frac{N}{V}
```

であるため，式 (19)，式 (20) から，

```math
\boxed{
e^2
\int
v_i
\left[
e^{-Ds}(v_lF_0)
\right](\boldsymbol{v})
\,d^3v
=
\frac{1}{V}
\left\langle
\delta\mathcal{J}_i(s)
\delta\mathcal{J}_l(0)
\right\rangle
}
\tag{21}
```

を得る．

したがって，式 (13) は，

```math
\boxed{
\phi_{li}(s)
=
\frac{1}{Vk_{\mathrm B}T}
\left\langle
\delta\mathcal{J}_i(s)
\delta\mathcal{J}_l(0)
\right\rangle
}
\tag{22}
```

となる．

#### 6.5 問題文の相関関数の規格化

ここで，問題文の相関関数の表記を明確にする．

全電流 $\mathcal{J}_i$ と電流密度 $j_i^{\mathrm{mic}}=\mathcal{J}_i/V$ は異なる量であり，それぞれの相関関数の体積因子は異なる．

体積規格化した電流相関関数を，

```math
\boxed{
C_{il}(s)
=
\frac{1}{V}
\left\langle
\delta\mathcal{J}_i(s)
\delta\mathcal{J}_l(0)
\right\rangle
}
\tag{23}
```

と定義する．

このとき，

```math
C_{il}(s)
=
V
\left\langle
\delta j_i^{\mathrm{mic}}(s)
\delta j_l^{\mathrm{mic}}(0)
\right\rangle
```

である．

問題文の記号を用いる場合には， $\langle j_i(s)j_l(0)\rangle$ をこの体積規格化された相関関数の意味で用いる．

すると，式 (22) は，

```math
\boxed{
\phi_{li}(s)
=
\frac{\langle j_i(s)j_l(0)\rangle}{k_{\mathrm B}T}
}
\tag{24}
```

となる．

これが示すべき関係である．

なお，もし $j_i$ を通常の電流密度として定義し，その相関を単純に

```math
\langle
\delta j_i^{\mathrm{mic}}(s)
\delta j_l^{\mathrm{mic}}(0)
\rangle
```

とする場合には，式 (24) の右辺に体積因子 $V$ が必要である．

したがって，式 (24) は相関関数の体積規格化を上記のように定義した場合，または単位体積の規約を採用した場合の表式である．

### 7．静的伝導率

式 (14) より，

```math
j_i^{\mathrm{resp}}(t)
=
\sum_l
\int_{-\infty}^{t}
E_l(t')\phi_{li}(t-t')\,dt'
```

である．

一定の電場を長時間印加し，定常な電流応答が存在すると仮定する．

時間差を，

```math
s=t-t'
```

と置けば，

```math
\begin{aligned}
j_i^{\mathrm{resp}}
&=
\sum_l E_l
\int_0^\infty\phi_{li}(s)\,ds
\end{aligned}
```

となる．

静的 Ohm の法則を，

```math
j_i^{\mathrm{resp}}
=
\sum_l\sigma_{il}(0)E_l
```

と定義する．

係数を比較すると，

```math
\boxed{
\sigma_{il}(0)
=
\int_0^\infty\phi_{li}(s)\,ds
}
\tag{25}
```

である．

式 (24) を代入すると，

```math
\boxed{
\sigma_{il}(0)
=
\frac{1}{k_{\mathrm B}T}
\int_0^\infty
\langle j_i(s)j_l(0)\rangle\,ds
}
\tag{26}
```

となる．

全電流を用いて書けば，

```math
\boxed{
\sigma_{il}(0)
=
\frac{1}{Vk_{\mathrm B}T}
\int_0^\infty
\left\langle
\delta\mathcal{J}_i(s)
\delta\mathcal{J}_l(0)
\right\rangle ds
}
\tag{27}
```

である．

また，通常の電流密度の相関を用いる場合には，

```math
\boxed{
\sigma_{il}(0)
=
\frac{V}{k_{\mathrm B}T}
\int_0^\infty
\left\langle
\delta j_i^{\mathrm{mic}}(s)
\delta j_l^{\mathrm{mic}}(0)
\right\rangle ds
}
\tag{28}
```

となる．

これが静的伝導率の Green-Kubo 表式である．

ただし，有限の静的伝導率を得るには，

```math
\int_0^\infty
|\phi_{li}(s)|\,ds<\infty
```

となるなど，電流相関関数の時間積分が収束する必要がある．

衝突による電流緩和が起こらない場合には，静的伝導率が発散することもある．

したがって，この収束条件は別途必要である．

### 8．動的伝導率

次に，角周波数 $\omega$ で振動する電場を考える．

時間依存性の規約を，

```math
E_l(t)=E_l(\omega)e^{i\omega t}
```

とする．

式 (14) において，

```math
s=t-t'
```

と変数変換すると，

```math
j_i^{\mathrm{resp}}(t)
=
\sum_l
\int_0^\infty
E_l(t-s)\phi_{li}(s)\,ds
```

となる．

ここで，

```math
E_l(t-s)
=
E_l(\omega)e^{i\omega t}e^{-i\omega s}
```

であるため，

```math
\begin{aligned}
j_i^{\mathrm{resp}}(t)
={}&
\sum_l E_l(\omega)e^{i\omega t}\\
&\quad\times
\int_0^\infty
\phi_{li}(s)e^{-i\omega s}\,ds
\end{aligned}
```

となる．

動的伝導率を，

```math
j_i^{\mathrm{resp}}(t)
=
\sum_l
\sigma_{il}(\omega)
E_l(\omega)e^{i\omega t}
```

で定義する．

したがって，

```math
\boxed{
\sigma_{il}(\omega)
=
\int_0^\infty
\phi_{li}(s)e^{-i\omega s}\,ds
}
\tag{29}
```

となる．

式 (24) を代入すると，

```math
\boxed{
\sigma_{il}(\omega)
=
\frac{1}{k_{\mathrm B}T}
\int_0^\infty
\langle j_i(s)j_l(0)\rangle
e^{-i\omega s}\,ds
}
\tag{30}
```

を得る．

全電流で表すと，

```math
\boxed{
\sigma_{il}(\omega)
=
\frac{1}{Vk_{\mathrm B}T}
\int_0^\infty
\left\langle
\delta\mathcal{J}_i(s)
\delta\mathcal{J}_l(0)
\right\rangle
e^{-i\omega s}\,ds
}
\tag{31}
```

となる．

これが電流相関関数による動的伝導率の表式である．

時間依存性に $e^{i\omega t}$ を採用したため，積分核には $e^{-i\omega s}$ が現れる．

反対の時間依存性 $e^{-i\omega t}$ を採用した場合には，指数関数の符号が反転する．

相関関数が実数である場合，伝導率の成分の実部は，

```math
\boxed{
\operatorname{Re}\sigma_{il}(\omega)
=
\frac{1}{k_{\mathrm B}T}
\int_0^\infty
\langle j_i(s)j_l(0)\rangle
\cos(\omega s)\,ds
}
\tag{32}
```

である．

ただし，一般のテンソル伝導率において，実際の時間平均散逸電力を決めるのは，伝導率テンソルの Hermitian 部分，

```math
\boxed{
\sigma_{\mathrm H}(\omega)
=
\frac{
\sigma(\omega)+\sigma^\dagger(\omega)
}{2}
}
```

である．

時間平均散逸電力密度は，

```math
\boxed{
\overline{P}
=
\frac12
\operatorname{Re}
\left[
\sum_{i,l}
E_i^*(\omega)
\sigma_{il}(\omega)
E_l(\omega)
\right]
}
```

で与えられる．

したがって，一般のテンソルの場合には，単に各成分の実部だけで散逸を判断するのではなく，Hermitian 部分を用いる必要がある．

なお，式 (29) の Fourier 積分が存在するには，相関関数の減衰などの収束条件が必要である．
必要に応じて，

```math
\sigma_{il}(\omega)
=
\lim_{\eta\downarrow0}
\int_0^\infty
\phi_{li}(s)e^{-(\eta+i\omega)s}\,ds
```

として因果的な極限を定義する．

### 9．結論

空間的に一様な古典電子系を考え，衝突過程が平衡分布 $F_0$ に対して詳細釣り合いを満たし，電子間の動的相関を無視できると仮定する．

Boltzmann 方程式を電場の一次まで線形化すると，

```math
\frac{\partial g}{\partial t}
+Dg
=
-\frac{e}{k_{\mathrm B}T}
\boldsymbol{v}\cdot\boldsymbol{E}(t)F_0
```

を得る．

これを因果的な境界条件のもとで形式的に解き，巨視的な平均電流を計算すると，

```math
j_i^{\mathrm{resp}}(t)
=
\sum_l
\int_{-\infty}^{t}
E_l(t')\phi_{li}(t-t')\,dt'
```

となる．

一方，遷移確率と独立電子近似を用いて平衡電流相関関数を評価すると，

```math
\boxed{
\phi_{li}(s)
=
\frac{\langle j_i(s)j_l(0)\rangle}
{k_{\mathrm B}T}
}
```

が得られる．

ここで，相関関数は体積規格化された電流相関を表す．

したがって，静的伝導率は，

```math
\boxed{
\sigma_{il}(0)
=
\frac{1}{k_{\mathrm B}T}
\int_0^\infty
\langle j_i(s)j_l(0)\rangle\,ds
}
```

であり，動的伝導率は，

```math
\boxed{
\sigma_{il}(\omega)
=
\frac{1}{k_{\mathrm B}T}
\int_0^\infty
\langle j_i(s)j_l(0)\rangle
e^{-i\omega s}\,ds
}
```

である．

以上により，電場の一次の線形応答と，平衡状態における電流揺らぎの時間相関関数との関係が得られた．

ただし，この導出には詳細釣り合い，独立電子近似，電流相関関数の体積規格化，および時間積分の収束条件が必要である．
