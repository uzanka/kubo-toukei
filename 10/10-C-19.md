# 演習問題【10-C-19】

## 解答

### 1．Boltzmann 方程式の線形化

電子系の Boltzmann 方程式を

```math
\frac{\partial f}{\partial t}
-e\boldsymbol E(t)\cdot
\frac{\partial f}{\partial\boldsymbol p}
=-Df
\tag{1}
```

とする．
ここで， $f(\boldsymbol p,t)$ は電子の分布関数， $-e$ は電子の電荷， $\boldsymbol E(t)$ は外部電場， $D$ は衝突演算子である．
衝突演算子は問題文の定義により，

```math
Df(\boldsymbol v)
=f(\boldsymbol v)\int W(\boldsymbol v,\boldsymbol v')\,d^3v'
-\int W(\boldsymbol v',\boldsymbol v)
f(\boldsymbol v')\,d^3v'
\tag{2}
```

と表される．
第一項は速度 $\boldsymbol v$ から別の速度へ散乱されることによる分布の減少，第二項は他の速度から $\boldsymbol v$ へ散乱されることによる分布の増加を表す．

電場がない平衡状態の分布関数を $f_0$ とする．
散乱によってエネルギーが変わらないという仮定のもとでは，エネルギーだけに依存する平衡分布は衝突によって変化しないため，

```math
Df_0=0
\tag{3}
```

である．

電場が弱いとして，分布関数を平衡分布と電場の一次の摂動 $g$ に分ける．

```math
f(\boldsymbol p,t)=f_0(\boldsymbol p)+g(\boldsymbol p,t)
\tag{4}
```

ここで $g$ は電場の一次の量である．
式 (4) を式 (1) に代入すると，

```math
\frac{\partial g}{\partial t}
-e\boldsymbol E(t)\cdot
\frac{\partial f_0}{\partial\boldsymbol p}
=-Dg
```

を得る．
このとき， $\boldsymbol E\cdot\partial g/\partial\boldsymbol p$ は電場と $g$ の積であり，電場の二次の項なので無視した．
これを整理すると，

```math
\frac{\partial g}{\partial t}+Dg
=e\boldsymbol E(t)\cdot
\frac{\partial f_0}{\partial\boldsymbol p}
\tag{5}
```

となる．

古典的な平衡分布は

```math
f_0(\boldsymbol p)\propto
\exp\left(-\frac{p^2}{2mkT}\right)
```

である．
速度 $\boldsymbol v=\boldsymbol p/m$ を用いて微分すると，

```math
\frac{\partial f_0}{\partial\boldsymbol p}
=-\frac{\boldsymbol p}{mkT}f_0
=-\frac{\boldsymbol v}{kT}f_0
\tag{6}
```

となる．
したがって，式 (5) は

```math
\boxed{
\frac{\partial g}{\partial t}+Dg
=-\frac{e}{kT}
\boldsymbol v\cdot\boldsymbol E(t)f_0
}
\tag{7}
```

となる．
これが電場の一次までの近似における方程式である．

### 2．時間を含む Boltzmann 方程式の形式解

まず，演算子 $D$ を含む線形方程式

```math
\frac{\partial g}{\partial t}+Dg=S(t)
```

を考える．
初期条件を $g(-\infty)=0$ とすると，その形式解は

```math
g(t)=\int_{-\infty}^{t}
e^{-D(t-t')}S(t')\,dt'
\tag{8}
```

である．
ここで $e^{-Ds}$ は，衝突演算子 $D$ によって速度分布が時間 $s$ だけ発展することを表す演算子であり，分布関数に作用する．

式 (7) の右辺を $S(t)$ に代入すると，

```math
\boxed{
g(\boldsymbol v,t)
=-\frac{e}{kT}
\sum_l\int_{-\infty}^{t}
E_l(t')\,
e^{-D(t-t')}
\left[v_l f_0\right]\,dt'
}
\tag{9}
```

となる．
ここで $E_l$ と $v_l$ は，それぞれ電場と速度の $l$ 成分である．
重要なのは，演算子 $e^{-D(t-t')}$ が $v_l f_0$ 全体に作用することである．

### 3．電流と応答関数

電流密度の $i$ 成分は，

```math
j_i(t)=-e\int v_i f(\boldsymbol p,t)\,d\Gamma
\tag{10}
```

である．
ここで $d\Gamma$ は，分布関数の定義と整合する運動量空間または速度空間の積分測度である．
平衡状態では速度の平均がゼロなので，

```math
\int v_i f_0\,d\Gamma=0
```

となる．
よって，電流に寄与するのは一次の摂動 $g$ のみであり，

```math
j_i(t)=-e\int v_i g(\boldsymbol p,t)\,d\Gamma
\tag{11}
```

である．
式 (9) を代入すると，

```math
\begin{aligned}
j_i(t)
&=\frac{e^2}{kT}
\sum_l\int_{-\infty}^{t}
E_l(t')\\
&\qquad\times
\left\{
\int v_i
e^{-D(t-t')}\left[v_lf_0\right]\,d\Gamma
\right\}dt'
\end{aligned}
\tag{12}
```

となる．
ここで，電場に対する電流の応答核を

```math
\boxed{
\phi_{li}(s)=
\frac{e^2}{kT}
\int v_i e^{-Ds}\left[v_lf_0\right]\,d\Gamma
\qquad(s\geq0)
}
\tag{13}
```

と定義する．
式 (12) は，

```math
\boxed{
j_i(t)=\sum_l\int_{-\infty}^{t}
E_l(t')\phi_{li}(t-t')\,dt'
}
\tag{14}
```

となる．
これは，電流が現在の電場だけではなく，過去の電場の時間的な履歴にも依存することを表している．

### 4．応答核と平衡電流の相関関数

次に，式 (13) の応答核が，平衡状態での電流の時間相関関数に等しいことを示す．

平衡状態において，時刻 $0$ に速度 $\boldsymbol v_0$ をもつ電子が，時間 $s$ 後に速度 $\boldsymbol v$ をもつ確率密度を

```math
P(\boldsymbol v,s\mid\boldsymbol v_0,0)
```

とする．
すると，時刻 $0$ の速度が $\boldsymbol v_0$ であった電子の分布は，時間 $s$ 後にはこの遷移確率に従って広がる．

平衡状態の電流相関関数

```math
C_{il}(s)=\langle j_i(s)j_l(0)\rangle
```

を考える．
独立な電子の平衡ゆらぎを用いると，異なる電子に由来する交差項は平均ゼロになる．
したがって，同じ電子の運動による寄与は

```math
\begin{aligned}
C_{il}(s)
={}&e^2\int d\Gamma_0\,f_0(\boldsymbol v_0)v_l(\boldsymbol v_0)\\
&\quad\times
\int d\Gamma\,P(\boldsymbol v,s\mid\boldsymbol v_0,0)
v_i(\boldsymbol v)
\end{aligned}
\tag{15}
```

と表せる．
ここで $e^2$ が現れるのは，電流相関関数が電流を二回掛け合わせた量であり，それぞれの電流に電荷 $-e$ が一つずつ含まれるためである．

一方，衝突演算子による分布の時間発展は，初期分布 $h(\boldsymbol v,0)$ に対して

```math
h(\boldsymbol v,s)=e^{-Ds}h(\boldsymbol v,0)
\tag{16}
```

で与えられる．
式 (15) の遷移確率による積分は，初期の重み付き分布 $v_lf_0$ を時間 $s$ だけ発展させたものにほかならない．
したがって，

```math
\boxed{
C_{il}(s)
=e^2\int v_i e^{-Ds}\left[v_lf_0\right]\,d\Gamma
}
\tag{17}
```

となる．
式 (13) と比較すると，

```math
\boxed{
\phi_{li}(s)
=\frac{\langle j_i(s)j_l(0)\rangle}{kT}
}
\tag{18}
```

が得られる．
これが，線形応答を平衡状態でのゆらぎの時間相関によって表す関係であり，ゆらぎ・散逸定理の一つの形である．

### 5．静的伝導率

静的伝導率は，一定の電場を十分長い時間加えたときの電流応答から求められる．
式 (14) で電場が一定であるとすると，

```math
j_i=\sum_l E_l\int_0^\infty\phi_{li}(s)\,ds
```

となる．
一方，静的な Ohm の法則は

```math
j_i=\sum_l\sigma_{il}(0)E_l
```

であるから，

```math
\sigma_{il}(0)=\int_0^\infty\phi_{li}(s)\,ds
```

を得る．
式 (18) を用いれば，

```math
\boxed{
\sigma_{il}(0)=
\frac{1}{kT}\int_0^\infty
\langle j_i(s)j_l(0)\rangle\,ds
}
\tag{19}
```

となる．
特に， $x$ 方向の静的伝導率は

```math
\boxed{
\sigma_{xx}(0)=
\frac{1}{kT}\int_0^\infty
\langle j_x(s)j_x(0)\rangle\,ds
}
\tag{20}
```

である．

### 6．動的伝導率

次に，電場が角周波数 $\omega$ で振動する場合を考える．
複素振幅を用いて，

```math
E_l(t)=E_l(\omega)e^{i\omega t}
```

と表す．
式 (14) において $s=t-t'$ と置くと，

```math
j_i(t)=\sum_l\int_0^\infty
E_l(t-s)\phi_{li}(s)\,ds
```

となる．
ここで，

```math
E_l(t-s)=E_l(\omega)e^{i\omega t}e^{-i\omega s}
```

であるから，

```math
j_i(t)=\sum_l E_l(\omega)e^{i\omega t}
\int_0^\infty\phi_{li}(s)e^{-i\omega s}\,ds
```

を得る．
この式を複素動的伝導率の定義

```math
j_i(t)=\sum_l\sigma_{il}(\omega)
E_l(\omega)e^{i\omega t}
```

と比較すると，

```math
\sigma_{il}(\omega)
=\int_0^\infty\phi_{li}(s)e^{-i\omega s}\,ds
```

である．
よって，式 (18) を代入して，

```math
\boxed{
\sigma_{il}(\omega)=
\frac{1}{kT}\int_0^\infty
\langle j_i(s)j_l(0)\rangle e^{-i\omega s}\,ds
}
\tag{21}
```

を得る．
これが電流相関関数による動的伝導率の表式である．

なお，式 (21) は複素伝導率全体を表している．
その実部は，

```math
\boxed{
\operatorname{Re}\sigma_{il}(\omega)
=\frac{1}{kT}\int_0^\infty
\langle j_i(s)j_l(0)\rangle\cos(\omega s)\,ds
}
\tag{22}
```

で与えられる．
この実部は，交流電場に対してエネルギー散逸に寄与する成分である．
ここでは $E(t)\propto e^{i\omega t}$ という時間依存の規約を採用したため，Fourier 積分には $e^{-i\omega s}$ が現れる．
反対の時間依存規約を採用した場合には，指数関数の符号が反転する．

以上より，Boltzmann 方程式を電場の一次まで形式的に解くと，電流の応答核は平衡電流の相関関数によって決まり，静的伝導率および動的伝導率はそれぞれ式 (19) と式 (21) で与えられる．
