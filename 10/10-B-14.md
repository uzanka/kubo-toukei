# 演習問題【10-B-14】

## 解答

### 1．Boltzmann 方程式と分布関数のずれ

電場がなく，時間に依存しない温度勾配が $x$ 方向に存在する場合を考える．
平衡状態からのずれが小さいとして，Boltzmann 方程式を緩和時間近似で表すと，

```math
v_x\frac{\partial f}{\partial x}
=-\frac{f-f_0}{\tau}
\tag{1}
```

となる．
ここで， $f$ は実際の電子の分布関数， $f_0$ は局所的な Fermi 分布， $v_x$ は速度の $x$ 成分， $\tau$ は緩和時間である．

平衡分布関数は

```math
f_0=
\frac{1}{\exp[(\epsilon-\mu)/(kT)]+1}
\tag{2}
```

である．
ここで， $\epsilon$ は電子のエネルギー， $\mu$ は化学ポテンシャル， $k$ は Boltzmann 定数， $T$ は絶対温度である．

温度勾配がないときは $f=f_0$ であるため， $f-f_0$ は温度勾配の一次の量である．
したがって，式 (1) の左辺にある $f$ は，この一次の近似では $f_0$ に置き換えられる．
よって，

```math
f-f_0\simeq-\tau v_x\frac{\partial f_0}{\partial x}
```

であり，

```math
f\simeq f_0-\tau v_x\frac{\partial f_0}{\partial x}
\tag{3}
```

となる．

次に， $\partial f_0/\partial x$ を温度勾配と化学ポテンシャルの勾配で表す．
式 (2) より， $f_0$ は $(\epsilon-\mu)/(kT)$ の関数である．
エネルギー $\epsilon$ は位置に依存しないものとして微分すると，

```math
\frac{\partial f_0}{\partial x}
=
\frac{\partial f_0}{\partial\epsilon}
\left[
-\frac{\partial\mu}{\partial x}
-\frac{\epsilon-\mu}{T}\frac{\partial T}{\partial x}
\right]
\tag{4}
```

となる．
角括弧内は，次のように書き換えられる．

```math
-\frac{\partial\mu}{\partial x}
-\frac{\epsilon-\mu}{T}\frac{\partial T}{\partial x}
=
-\epsilon\frac{\partial\log T}{\partial x}
-T\frac{\partial}{\partial x}\left(\frac{\mu}{T}\right)
```

そこで，

```math
B(\epsilon)=
-\epsilon\frac{\partial\log T}{\partial x}
-T\frac{\partial}{\partial x}\left(\frac{\mu}{T}\right)
\tag{5}
```

とおくと，

```math
\frac{\partial f_0}{\partial x}
=\frac{\partial f_0}{\partial\epsilon}B(\epsilon)
```

である．
これを式 (3) に代入すると，

```math
\boxed{
f\simeq f_0+
\tau v_x\left(-\frac{\partial f_0}{\partial\epsilon}\right)
B(\epsilon)
}
\tag{6}
```

を得る．
ここでは， $-\partial f_0/\partial\epsilon$ が正であることを用いて符号を整理した．
式 (6) が，温度勾配と化学ポテンシャルの勾配によって生じる分布関数の一次のずれを表す式である．

### 2．電子流と輸送係数 $L_\nu$

電子の粒子流の $x$ 成分を $J$ とすると，

```math
J=\int v_x f\,\frac{2d^3p}{h^3}
\tag{7}
```

である．
ここで， $h$ は Planck 定数であり，係数 $2$ は電子のスピンの縮退度である．

平衡分布 $f_0$ は運動量の向きによらないため， $v_x f_0$ を運動量全体について積分するとゼロになる．
したがって，電子流に寄与するのは式 (6) の一次のずれだけである．
よって，

```math
J=
\int v_x^2\tau
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
B(\epsilon)\frac{2d^3p}{h^3}
\tag{8}
```

となる．

エネルギー分散が

```math
\epsilon(\mathbf p)=\frac{\mathbf p^2}{2m^*}
\tag{9}
```

であるため，

```math
v_x=\frac{p_x}{m^*},
\qquad
v^2=\frac{2\epsilon}{m^*}
```

である．
運動量の向きについて平均すると，

```math
\langle v_x^2\rangle=\frac{v^2}{3}
=\frac{2\epsilon}{3m^*}
\tag{10}
```

が成り立つ．

また，三次元の状態密度を $D(\epsilon)$ とすると，

```math
D(\epsilon)=
\frac{\sqrt{2}(m^*)^{3/2}}{\pi^2\hbar^3}
\sqrt{\epsilon}
\tag{11}
```

である．
ここで $\hbar=h/(2\pi)$ である．
これにより，運動量についての積分をエネルギーについての積分に変換できる．

式 (8) は，

```math
J=\int_0^\infty
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
\tau\frac{v^2}{3}
B(\epsilon)D(\epsilon)\,d\epsilon
\tag{12}
```

となる．
ここで式 (5) を代入し，エネルギーのべき乗ごとに積分をまとめるため，

```math
\boxed{
L_\nu=
\int_0^\infty
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
\tau\frac{v^2}{3}\epsilon^\nu
D(\epsilon)\,d\epsilon
}
\tag{13}
```

と定義する．
この $L_\nu$ を使えば，電子流は

```math
\boxed{
J=L_1\left(-\frac{\partial\log T}{\partial x}\right)
+L_0\left\{-T\frac{\partial}{\partial x}
\left(\frac{\mu}{T}\right)\right\}
}
\tag{14}
```

と表される．

### 3．電子流がゼロとなる条件

熱伝導率を求める際は，電流が流れない状態における熱流を考える．
電子のみが電荷を運ぶとき，電流がゼロである条件は粒子流 $J=0$ と等価である．
式 (14) に $J=0$ を代入すると，

```math
0=L_1\left(-\frac{\partial\log T}{\partial x}\right)
+L_0\left\{-T\frac{\partial}{\partial x}
\left(\frac{\mu}{T}\right)\right\}
```

であるから，

```math
\boxed{
-T\frac{\partial}{\partial x}\left(\frac{\mu}{T}\right)
=-\frac{L_1}{L_0}
\left(-\frac{\partial\log T}{\partial x}\right)
}
\tag{15}
```

を得る．
すなわち，温度勾配による電子の流れを打ち消すように，化学ポテンシャルの勾配が定まるのである．

### 4．熱流と熱伝導率

電子が運ぶエネルギー流の $x$ 成分を $q$ とすると，

```math
q=\int\epsilon v_x f\,\frac{2d^3p}{h^3}
\tag{16}
```

である．
平衡分布の寄与は，速度の向きについての対称性によりゼロとなる．
したがって，式 (6) を代入すると，

```math
q=\int_0^\infty
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
\tau\frac{v^2}{3}\epsilon
B(\epsilon)D(\epsilon)\,d\epsilon
\tag{17}
```

を得る．
式 (13) の $L_\nu$ を使えば，

```math
\boxed{
q=L_2\left(-\frac{\partial\log T}{\partial x}\right)
+L_1\left\{-T\frac{\partial}{\partial x}
\left(\frac{\mu}{T}\right)\right\}
}
\tag{18}
```

となる．

式 (15) を式 (18) に代入して，電流がゼロの条件を用いると，

```math
\begin{aligned}
q
&=\left(L_2-\frac{L_1^2}{L_0}\right)
\left(-\frac{\partial\log T}{\partial x}\right)\\
&=-\frac{L_0L_2-L_1^2}{TL_0}
\frac{\partial T}{\partial x}
\end{aligned}
\tag{19}
```

となる．
一方，Fourier の法則は

```math
q=-\lambda\frac{\partial T}{\partial x}
\tag{20}
```

である．
式 (19) と比較すると，熱伝導率は

```math
\boxed{
\lambda=\frac{L_0L_2-L_1^2}{TL_0}
}
\tag{21}
```

であることが分かる．

### 5．低温展開による熱伝導率の計算

式 (21) を計算するには，輸送係数 $L_\nu$ を求める必要がある．
問題で与えられた緩和時間は，

```math
\tau=Av^s
=A\left(\frac{2\epsilon}{m^*}\right)^{s/2}
\tag{22}
```

である．
これと式 (10)，式 (11) を式 (13) に代入すると，

```math
\begin{aligned}
L_\nu
&=\frac{A}{m^*}
\left(\frac{2}{m^*}\right)^{s/2}
\frac{(2m^*)^{3/2}}{3\pi^2\hbar^3}\\
&\quad\times
\int_0^\infty
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
\epsilon^{\nu+(s+3)/2}\,d\epsilon
\end{aligned}
\tag{23}
```

となる．

ここで，低温の縮退 Fermi 気体を考え，粒子密度 $n$ を一定に保つ．
$\mu_0$ を $T=0$ における化学ポテンシャル，すなわち Fermi エネルギーとする．
このとき，

```math
n=\frac{(2m^*\mu_0)^{3/2}}{3\pi^2\hbar^3}
\tag{24}
```

である．
また，有限温度の化学ポテンシャルは Sommerfeld 展開により，

```math
\mu(T)=\mu_0
\left[
1-\frac{\pi^2}{12}
\left(\frac{kT}{\mu_0}\right)^2
+\cdots
\right]
\tag{25}
```

と表される．
この展開は $kT\ll\mu_0$ の場合に有効である．

積分の指数を

```math
r=\nu+\frac{s+3}{2}
```

とおく．
Fermi 分布の低温展開を使うと，

```math
\begin{aligned}
&\int_0^\infty
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
\epsilon^r\,d\epsilon\\
&\quad=
\mu(T)^r
\left[
1+\frac{\pi^2}{6}r(r-1)
\left(\frac{kT}{\mu(T)}\right)^2+\cdots
\right]
\end{aligned}
\tag{26}
```

となる．
式 (25) を用いて $\mu(T)$ を $\mu_0$ で表すと，

```math
\begin{aligned}
&\int_0^\infty
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
\epsilon^r\,d\epsilon\\
&\quad=
\mu_0^r
\left[
1+\frac{1}{6}r
\left(\nu+\frac{s}{2}\right)
\left(\frac{\pi kT}{\mu_0}\right)^2
+\cdots
\right]
\end{aligned}
\tag{27}
```

を得る．
ここでは，有限温度における化学ポテンシャルの変化も含めて展開している．

式 (23)，式 (24)，式 (27) より，

```math
\boxed{
\begin{aligned}
L_\nu
&=\frac{n}{m^*}\tau(\mu_0)\mu_0^\nu\\
&\quad\times
\left[
1+\frac{1}{6}
\left(\nu+\frac{s+3}{2}\right)
\left(\nu+\frac{s}{2}\right)
\left(\frac{\pi kT}{\mu_0}\right)^2
+\cdots
\right]
\end{aligned}
}
\tag{28}
```

となる．
ここで，

```math
\tau(\mu_0)=A\left(\frac{2\mu_0}{m^*}\right)^{s/2}
```

である．

計算を簡単にするため，

```math
C=\frac{n}{m^*}\tau(\mu_0),
\qquad
y=\frac{\pi kT}{\mu_0}
```

とおき，さらに

```math
a_\nu=
\frac{1}{6}
\left(\nu+\frac{s+3}{2}\right)
\left(\nu+\frac{s}{2}\right)
```

と定義すると，式 (28) は

```math
L_\nu=C\mu_0^\nu(1+a_\nu y^2+\cdots)
\tag{29}
```

と書ける．
したがって，

```math
\begin{aligned}
L_0L_2-L_1^2
&=C^2\mu_0^2
\left[(1+a_0y^2)(1+a_2y^2)
-(1+a_1y^2)^2\right]+\cdots\\
&=C^2\mu_0^2
(a_0+a_2-2a_1)y^2+\cdots
\end{aligned}
\tag{30}
```

である．
$a_\nu$ は $\nu$ の二次式であり，その二次の係数は $1/6$ であるため，

```math
a_0+a_2-2a_1=\frac{1}{3}
```

となる．
よって，

```math
L_0L_2-L_1^2
=\frac{C^2\mu_0^2}{3}
\left(\frac{\pi kT}{\mu_0}\right)^2+\cdots
\tag{31}
```

を得る．

式 (29) より $L_0=C+\cdots$ であるため，式 (21) に式 (31) を代入し，最低次の非ゼロ項を残すと，

```math
\begin{aligned}
\lambda
&=\frac{C\mu_0^2}{3T}
\left(\frac{\pi kT}{\mu_0}\right)^2\\
&=\frac{n}{m^*}\tau(\mu_0)
\frac{\pi^2}{3}k^2T
\end{aligned}
```

となる．
したがって，求める熱伝導率は

```math
\boxed{
\lambda=
\frac{n}{m^*}\tau(\mu_0)
\frac{\pi^2}{3}k^2T
}
\tag{32}
```

である．

### 6．物理的な意味

式 (32) は，低温の縮退 Fermi 気体における熱伝導率が温度 $T$ に比例することを示している．
また，電気伝導率を $\sigma$ ，電子の電荷の大きさを $e$ とすると，Drude 型の電気伝導率は

```math
\sigma=\frac{ne^2}{m^*}\tau(\mu_0)
\tag{33}
```

と表される．
式 (32) と比較すると，

```math
\boxed{
\frac{\lambda}{\sigma T}
=\frac{\pi^2}{3}\left(\frac{k}{e}\right)^2
}
\tag{34}
```

が得られる．
これは Wiedemann–Franz 則であり，低温の金属では，熱伝導と電気伝導の比が共通の定数によって関係づけられることを示す結果である．

なお，式 (23) の積分は $\epsilon\to0$ で $\epsilon^{(s+3)/2}$ に比例するため，その積分が厳密に収束する条件は $s>-5$ である．
問題文の $s>-7$ だけではこの収束条件を保証しない点に注意が必要である．
