# 演習問題【10-B-14】

## 解答

### 1．Boltzmann 方程式と分布関数の一次近似

電場がなく，時間に依存しない温度勾配が $x$ 方向に存在する場合を考える．
温度勾配は十分小さく，分布関数の局所平衡状態からのずれが一次の範囲で記述できるとする．

緩和時間近似による定常 Boltzmann 方程式は

```math
v_x\frac{\partial f}{\partial x}
=-\frac{f-f_0}{\tau}
```

である．
ここで， $f$ は実際の分布関数， $f_0$ は局所 Fermi 分布である．

一次の近似では，左辺の $f$ を $f_0$ に置き換えることができる．
したがって，

```math
f=f_0-\tau v_x\frac{\partial f_0}{\partial x}
```

を得る．

局所 Fermi 分布は

```math
f_0(\epsilon,x)
=\frac{1}{\exp[(\epsilon-\mu(x))/(k_{\mathrm B}T(x))]+1}
```

である．
これを $x$ で微分すると，

```math
\frac{\partial f_0}{\partial x}
=
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
\left[
\frac{\partial\mu}{\partial x}
+\frac{\epsilon-\mu}{T}\frac{\partial T}{\partial x}
\right]
```

となる．

よって，分布関数の一次のずれは

```math
\boxed{
f-f_0
=-\tau v_x
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
\left[
\frac{\partial\mu}{\partial x}
+\frac{\epsilon-\mu}{T}\frac{\partial T}{\partial x}
\right]
}
\tag{1}
```

である．

### 2．熱流と輸送積分

粒子密度が一定であるという条件を採用する．
電子の粒子流が一般にゼロではないため，熱流 $q$ はエネルギー流から化学ポテンシャルに対応する粒子流の寄与を差し引いて，

```math
q=\int(\epsilon-\mu)v_x f\,
\frac{2d^3p}{h^3}
\tag{2}
```

と定義する．

平衡分布 $f_0$ は運動量の向きによらないため，その寄与は角度積分でゼロになる．
したがって，式 (1) の一次のずれだけが熱流に寄与する．

放物線型のエネルギー分散

```math
\epsilon=\frac{\mathbf p^2}{2m^*}
```

に対して，

```math
v_x=\frac{p_x}{m^*},
\qquad
v^2=\frac{2\epsilon}{m^*}
```

である．
等方性から，

```math
\langle v_x^2\rangle=\frac{v^2}{3}
```

となる．

スピン縮退度 2 を含む三次元状態密度は

```math
D(\epsilon)
=\frac{\sqrt{2}(m^*)^{3/2}}{\pi^2\hbar^3}
\sqrt{\epsilon}
```

である．
ここで $\hbar=h/(2\pi)$ とした．

輸送関数を

```math
\boxed{
\Xi(\epsilon)
=\frac{1}{3}D(\epsilon)\tau(\epsilon)v^2
}
\tag{3}
```

と定義する．
さらに，

```math
\boxed{
K_j
=\int_0^\infty
\Xi(\epsilon)(\epsilon-\mu)^j
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
d\epsilon
\qquad (j=0,1,2)
}
\tag{4}
```

とおく．

式 (1) を粒子流および熱流に代入し，運動量の角度積分を行うと，粒子流 $J$ と熱流 $q$ は

```math
\boxed{
J=-K_0\frac{\partial\mu}{\partial x}
-\frac{K_1}{T}\frac{\partial T}{\partial x}
}
\tag{5}
```

および

```math
\boxed{
q=-K_1\frac{\partial\mu}{\partial x}
-\frac{K_2}{T}\frac{\partial T}{\partial x}
}
\tag{6}
```

となる．

ここでは電場をゼロとしており，粒子流をゼロとはしていない．

### 3．一定粒子密度の条件

粒子密度 $n$ は

```math
n=\int_0^\infty D(\epsilon)f_0(\epsilon)\,d\epsilon
\tag{7}
```

である．
低温の縮退 Fermi 気体を考え，この粒子密度を一定とする．

$T=0$ における化学ポテンシャルを $\mu_0$ とする．
Sommerfeld 展開から，

```math
n=\frac{(2m^*\mu_0)^{3/2}}{3\pi^2\hbar^3}
```

であり，有限温度の化学ポテンシャルは

```math
\boxed{
\mu(T)=\mu_0
\left[
1-\frac{\pi^2}{12}
\left(\frac{k_{\mathrm B}T}{\mu_0}\right)^2
+O\left(\frac{k_{\mathrm B}^4T^4}{\mu_0^4}\right)
\right]
}
\tag{8}
```

となる．
ここでの展開条件は

```math
k_{\mathrm B}T\ll\mu_0
```

である．

したがって，

```math
\boxed{
\frac{d\mu}{dT}
=-\frac{\pi^2k_{\mathrm B}^2T}{6\mu_0}
+O(T^3)
}
\tag{9}
```

を得る．

一定密度の条件では，

```math
\frac{\partial\mu}{\partial x}
=\frac{d\mu}{dT}\frac{\partial T}{\partial x}
\tag{10}
```

である．

式 (6) に式 (10) を代入すると，

```math
q
=-\left[
\frac{K_2}{T}
+\frac{d\mu}{dT}K_1
\right]\frac{\partial T}{\partial x}
```

となる．
よって，電場ゼロ，一定粒子密度の条件における熱伝導率は

```math
\boxed{
\lambda_{E=0,n}
=\frac{K_2}{T}+\frac{d\mu}{dT}K_1
}
\tag{11}
```

である．

なお，この条件では粒子流 $J$ は一般にゼロではない．
実際，式 (5) に式 (9)，式 (10) を代入すれば，粒子流が温度勾配に比例して生じることが分かる．
したがって，一定密度条件と粒子流ゼロ条件を同時に仮定してはいない．

### 4．輸送関数 $\Xi(\epsilon)$ の計算と収束条件

問題で与えられた緩和時間は

```math
\tau=Av^s
=A\left(\frac{2\epsilon}{m^*}\right)^{s/2}
```

である．
これを式 (3) に代入すると，

```math
\begin{aligned}
\Xi(\epsilon)
&=\frac13
\frac{\sqrt2(m^*)^{3/2}}{\pi^2\hbar^3}
\epsilon^{1/2}
A\left(\frac{2\epsilon}{m^*}\right)^{s/2}
\frac{2\epsilon}{m^*}\\
&=
\frac{A\,2^{(s+3)/2}(m^*)^{(1-s)/2}}
{3\pi^2\hbar^3}
\epsilon^{(s+3)/2}.
\end{aligned}
```

したがって，

```math
\boxed{
\Xi(\epsilon)=C_s\epsilon^{(s+3)/2}
}
\tag{12}
```

である．
ただし，

```math
C_s=
\frac{A\,2^{(s+3)/2}(m^*)^{(1-s)/2}}
{3\pi^2\hbar^3}
```

とおいた．

ここで，式 (4) の積分が低エネルギー側で収束する条件を確認する．
有限温度 $T>0$ では，

```math
-\frac{\partial f_0}{\partial\epsilon}
```

は $\epsilon=0$ で有限かつ正の値を取る．
また，縮退状態では $\mu>0$ であるため，

```math
(\epsilon-\mu)^j\longrightarrow(-\mu)^j
\qquad(\epsilon\to0)
```

となる．
したがって， $K_0,K_1,K_2$ はいずれも低エネルギー側で

```math
\int_0^\delta \epsilon^{(s+3)/2}\,d\epsilon
```

と同じ収束条件を持つ．

この積分が収束する条件は

```math
\frac{s+3}{2}>-1
```

すなわち，

```math
\boxed{s>-5}
\tag{13}
```

である．

よって，問題文で指定された $s>-7$ だけでは不十分である．

```math
-7<s\leq-5
```

では，今回必要な熱流の輸送積分が発散するため，このモデルから有限の熱伝導率は得られない．
以下では，追加条件 $s>-5$ を満たす場合を計算する．

### 5．低温展開による熱伝導率

Sommerfeld 展開を用いる．低温では，

```math
\boxed{
K_1=
\frac{\pi^2}{3}(k_{\mathrm B}T)^2
\Xi'(\mu)
+O(T^4)
}
\tag{14}
```

および

```math
\boxed{
K_2=
\frac{\pi^2}{3}(k_{\mathrm B}T)^2
\Xi(\mu)
+O(T^4)
}
\tag{15}
```

となる．
ここで， $\Xi'(\mu)$ はエネルギーについての微分である．

式 (12) から，

```math
\Xi'(\mu)
=\frac{s+3}{2}\frac{\Xi(\mu)}{\mu}
```

である．

式 (9)，式 (14)，式 (15) を式 (11) に代入すると，

```math
\begin{aligned}
\lambda_{E=0,n}
&=\frac{\pi^2}{3}k_{\mathrm B}^2T\Xi(\mu)
+\frac{d\mu}{dT}
\frac{\pi^2}{3}(k_{\mathrm B}T)^2\Xi'(\mu)
+O(T^3)\\
&=\frac{\pi^2}{3}k_{\mathrm B}^2T\Xi(\mu_0)
+O(T^3).
\end{aligned}
```

ここで， $\mu(T)-\mu_0=O(T^2)$ であり，また

```math
\frac{d\mu}{dT}=O(T)
```

なので，第2項は $O(T^3)$ である．
したがって，最低次の非零項は

```math
\boxed{
\lambda_{E=0,n}
=\frac{\pi^2}{3}k_{\mathrm B}^2T\Xi(\mu_0)
+O(T^3)
}
\tag{16}
```

となる．

最後に，

```math
\Xi(\mu_0)
=\frac13D(\mu_0)v_F^2\tau(\mu_0)
```

である．
ここで，

```math
v_F^2=\frac{2\mu_0}{m^*}
```

であり，式 (7) の $T=0$ の粒子密度から，

```math
\frac13D(\mu_0)v_F^2=\frac{n}{m^*}
```

が得られる．
したがって，

```math
\Xi(\mu_0)=\frac{n}{m^*}\tau(\mu_0)
```

である．

また，

```math
\tau(\mu_0)
=A\left(\frac{2\mu_0}{m^*}\right)^{s/2}
```

である．
これを式 (16) に代入すると，

```math
\boxed{
\lambda_{E=0,n}
=
\frac{n}{m^*}\tau(\mu_0)
\frac{\pi^2}{3}k_{\mathrm B}^2T
+O(T^3)
}
\tag{17}
```

を得る．

したがって，低温の縮退 Fermi 気体における熱伝導率の主要項は温度 $T$ に比例する．

### 6．開回路熱伝導率との違い

今回の計算では，問題文に従って電場をゼロとし，粒子流もゼロとは仮定しなかった．
これに対して，開回路の熱伝導率では粒子流 $J=0$ を別途課す．

式 (5) から，

```math
J=0
```

とすれば，

```math
\frac{\partial\mu}{\partial x}
=-\frac{K_1}{K_0T}\frac{\partial T}{\partial x}
```

となる．
これを式 (6) に代入すると，

```math
q=-\frac1T
\left(K_2-\frac{K_1^2}{K_0}\right)
\frac{\partial T}{\partial x}
```

である．
したがって，開回路条件における熱伝導率は

```math
\boxed{
\lambda_{J=0}
=\frac1T\left(K_2-\frac{K_1^2}{K_0}\right)
}
\tag{18}
```

となる．

式 (18) は今回の電場ゼロ，一定密度条件における式 (11) とは一般に異なる．
電流をゼロにする開回路条件では，電子系の電気化学的な応答を考慮する必要があるためである．

ただし，低温では

```math
K_1=O(T^2),\qquad K_0=O(1)
```

なので，

```math
\frac{K_1^2}{TK_0}=O(T^3)
```

となる．
そのため，両方の条件で低温の主要項は一致し，

```math
\lambda
\simeq
\frac{n}{m^*}\tau(\mu_0)
\frac{\pi^2}{3}k_{\mathrm B}^2T
```

となる．

### 7．結論と適用範囲

電場ゼロ，一定粒子密度の条件において，熱流を

```math
q=\int(\epsilon-\mu)v_xf\,\frac{2d^3p}{h^3}
```

と定義すると，低温の縮退 Fermi 気体に対する熱伝導率は

```math
\boxed{
\lambda
=
\frac{n}{m^*}\tau(\mu_0)
\frac{\pi^2}{3}k_{\mathrm B}^2T
}
```

である．
ただし，この式は最低次の低温近似であり，

```math
k_{\mathrm B}T\ll\mu_0,\qquad s>-5
```

を必要とする．

問題文の条件 $s>-7$ のうち，

```math
-7<s\leq-5
```

では輸送積分が発散するため，追加の低エネルギーカットオフや緩和時間モデルの修正なしには有限の熱伝導率を定義できない．

また，問題文だけでは化学ポテンシャルの空間変化，または粒子密度の条件が明示されていない．
式 (17) は一定粒子密度という物理的条件を追加した結果である．
この条件を採用しない場合の一般式は式 (5)，式 (6) で与えられ，熱伝導率を温度勾配だけの係数として確定するには，さらに \(\mu(x)\) の条件が必要となる．
