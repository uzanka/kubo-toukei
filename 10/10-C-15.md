# 演習問題【10-C-15】

## 解答

### 1．座標系と分子の速度分布

球体の速度を $\mathbf V$ ，速さを $V=|\mathbf V|4 とする．
気体分子の実験室系での速度を $\mathbf u4 ，分子の質量を $m$ とする．
球体とともに動く座標系で見た分子の相対速度は

```math
\mathbf w=\mathbf u-\mathbf V
```

である．
ここで，球体の進行方向を $x$ 軸の正方向とする．
求める抵抗力は $x$ 方向に働くので，その成分を $K$ と表す．
球体の進行方向と逆向きの抵抗力は $K<0$ となる．

気体は温度 $T$ で熱平衡にあり，分子の実験室系での速度は Maxwell 分布に従う．
球体の座標系では，速度 $\mathbf w$ をもつ分子の単位体積あたりの分布は

```math
g(\mathbf w)=
n\left(\frac{m}{2\pi kT}\right)^{3/2}
\exp\left[-\frac{m|\mathbf w+\mathbf V|^2}{2kT}\right]
\tag{1}
```

である．
ここで， $n$ は分子数密度， $k$ は Boltzmann 定数である．
$g(\mathbf w)d^3w$ は，相対速度が $d^3w$ の範囲にある分子の数密度を表す．

球体の半径を $R$ ，分子の半径を $a$ とする．
分子の中心が接触するとき，その中心は球体の表面から距離 $a$ だけ離れているため，有効半径は

```math
B=R+a
\tag{2}
```

となる．
問題の条件 $R\gg a$ は，最後に $B\simeq R$ と近似するために用いる．

### 2．一回の衝突による力積と衝突率

球体表面の外向き単位法線ベクトルを $\hat{\mathbf n}$ とする．
球体の座標系では，分子が表面に向かって進む条件は

```math
\mathbf w\cdot\hat{\mathbf n}<0
```

である．
滑らかな球面との完全弾性衝突では，分子の相対速度の接線成分は変わらず，法線成分の符号が反転する．
そのため，衝突前後の相対速度は

```math
\mathbf w_{\rm out}
=\mathbf w_{\rm in}
-2(\mathbf w_{\rm in}\cdot\hat{\mathbf n})
\hat{\mathbf n}
\tag{3}
```

となる．

分子の運動量変化は $m(\mathbf w_{\rm out}-\mathbf w_{\rm in})$ である．
運動量保存則より，球体が受ける力積はその反対向きとなり，

```math
\Delta\mathbf p_{\rm sphere}
=2m(\mathbf w\cdot\hat{\mathbf n})\hat{\mathbf n}
\tag{4}
```

である．
これは $\mathbf w\cdot\hat{\mathbf n}<0$ なので，表面の内向きに働く力積である．

一方，表面積 $dA$ あたり，速度範囲 $d^3w$ にある分子が単位時間に衝突する数は，

```math
(-\mathbf w\cdot\hat{\mathbf n})
\,g(\mathbf w)\,d^3w\,dA
\tag{5}
```

である．
ここで $-\mathbf w\cdot\hat{\mathbf n}>0$ は，表面へ向かう相対速度の法線成分である．
したがって，この速度範囲の分子が球体に及ぼす力は，力積 (4) と衝突率 (5) の積を表面全体で積分したものとなる．

```math
d\mathbf F
=-2m(\mathbf w\cdot\hat{\mathbf n})^2
\hat{\mathbf n}\,
g(\mathbf w)\,d^3w\,dA
\tag{6}
```

ここで， $\Theta$ を $-\mathbf w$ と $\hat{\mathbf n}$ のなす角とすると，

```math
\mathbf w\cdot\hat{\mathbf n}=-w\cos\Theta,
\qquad
w=|\mathbf w|
```

であり，衝突が起こるのは $0\leq\Theta<\pi/2$ の範囲である．
有効半径 $B$ の球面について $dA=B^2\sin\Theta\,d\Theta\,d\Phi$ である．
対称性により，表面法線のうち $-\mathbf w$ に垂直な方向の成分は積分すると打ち消し合う．
残る成分を積分すると，

```math
\int_{\mathbf w\cdot\hat{\mathbf n}<0}
\cos^2\Theta\,\hat{\mathbf n}\,dA
=-\frac{\pi B^2}{2}\frac{\mathbf w}{w}
\tag{7}
```

を得る．
実際， $\hat{\mathbf n}$ の $-\mathbf w/w$ 方向への成分は $\cos\Theta$ なので，この積分は

```math
-B^2\frac{\mathbf w}{w}
\,2\pi\int_0^{\pi/2}
\cos^3\Theta\sin\Theta\,d\Theta
=-\frac{\pi B^2}{2}\frac{\mathbf w}{w}
```

となる．

式 (6)，(7) を用いて表面積分を実行すると，速度範囲 $d^3w$ の分子による力は

```math
d\mathbf F
=m\pi B^2\,w\mathbf w\,
g(\mathbf w)\,d^3w
```

となる．
よって，全抵抗力は

```math
\boxed{
\mathbf F=m\pi B^2
\int w\mathbf w\,g(\mathbf w)\,d^3w
}
\tag{8}
```

である．
この式は，一つ一つの衝突による運動量移動を，速度分布について足し合わせた結果である．

### 3．Maxwell 分布を用いた速度積分

球体の進行方向を $x$ 軸にとる．
$\theta$ を $-\mathbf w$ と $\mathbf V$ のなす角とし，

```math
\mu=\cos\theta
```

とおく．
このとき，

```math
w_x=-w\mu,
\qquad
|\mathbf w+\mathbf V|^2
=w^2+V^2-2wV\mu
\tag{9}
```

である．
式 (1)，(8) より，抵抗力の $x$ 成分は

```math
\begin{aligned}
K={}&-2\pi^2 mnB^2
\left(\frac{m}{2\pi kT}\right)^{3/2}\\
&\times\int_0^\infty w^4\,dw
\int_{-1}^{1}\mu
\exp\left[-\frac{m}{2kT}
(w^2+V^2-2wV\mu)\right]d\mu
\end{aligned}
\tag{10}
```

となる．
ここでは，速度の方位角についての積分が $2\pi$ であることを用いた．

角度積分を行うため，

```math
b=\frac{m wV}{kT}
```

とおくと，

```math
\int_{-1}^{1}\mu e^{b\mu}\,d\mu
=\frac{(b-1)e^b+(b+1)e^{-b}}{b^2}
\tag{11}
```

である．
式 (11) を式 (10) に代入して整理すると，

```math
\begin{aligned}
K={}&-2\pi^2 nB^2
\left(\frac{m}{2\pi kT}\right)^{3/2}
\frac{(kT)^2}{mV^2}\\
&\times\int_0^\infty w^2
\left[
\left(\frac{mwV}{kT}-1\right)
e^{-m(w-V)^2/(2kT)}
\right.\\
&\hspace{35mm}\left.
+\left(\frac{mwV}{kT}+1\right)
e^{-m(w+V)^2/(2kT)}
\right]dw
\end{aligned}
\tag{12}
```

を得る．
式 (12) の係数には $(kT)^2/(mV^2)$ が現れる．
これは次元を合わせるためにも必要な因子である．

この積分を誤差関数で表すため，

```math
x_0=V\sqrt{\frac{m}{2kT}}
\tag{13}
```

と定義する．
さらに，第一項では $x=(w-V)\sqrt{m/(2kT)}$ ，第二項では $x=(w+V)\sqrt{m/(2kT)}$ と変数変換する．
すると，

```math
\begin{aligned}
K={}&-\frac{p\pi B^2}{x_0^2}
\left\{
\frac{2}{\sqrt{\pi}}
\int_{-x_0}^{\infty}
(x+x_0)^2
\left(xx_0+x_0^2-\frac12\right)e^{-x^2}\,dx
\right.\\
&\left.\quad+
\frac{2}{\sqrt{\pi}}
\int_{x_0}^{\infty}
(x-x_0)^2
\left(xx_0-x_0^2+\frac12\right)e^{-x^2}\,dx
\right\}
\end{aligned}
\tag{14}
```

となる．
ここでは気体の圧力 $p=nkT$ を導入した．

### 4．誤差関数による積分

誤差関数を

```math
\Phi(x_0)=\frac{2}{\sqrt{\pi}}
\int_0^{x_0}e^{-x^2}\,dx
\tag{15}
```

と定義する．
この定義を使うと，必要な積分は次のように表せる．

```math
\frac{2}{\sqrt{\pi}}\int_{x_0}^{\infty}
e^{-x^2}\,dx=1-\Phi(x_0)
```

```math
\frac{2}{\sqrt{\pi}}\int_{x_0}^{\infty}
xe^{-x^2}\,dx
=\frac{1}{\sqrt{\pi}}e^{-x_0^2}
```

```math
\frac{2}{\sqrt{\pi}}\int_{x_0}^{\infty}
x^2e^{-x^2}\,dx
=\frac12-\frac12\Phi(x_0)
+\frac{x_0}{\sqrt{\pi}}e^{-x_0^2}
```

```math
\frac{2}{\sqrt{\pi}}\int_{x_0}^{\infty}
x^3e^{-x^2}\,dx
=\frac{x_0^2+1}{\sqrt{\pi}}e^{-x_0^2}
```

これらを式 (14) の多項式ごとに適用して整理すると，

```math
\boxed{
\begin{aligned}
K=-p\pi B^2\bigg\{&
\frac{e^{-x_0^2}}{\sqrt{\pi}x_0}(1+2x_0^2)\\
&+\left(2x_0^2+2-\frac{1}{2x_0^2}\right)
\Phi(x_0)
\bigg\}
\end{aligned}
}
\tag{16}
```

を得る．
これが，球体の速度 $V$ に対する抵抗力の式である．
$x_0$ は，球体の速度と気体分子の熱運動の速さとの比を表す無次元量である．

### 5．低速極限での抵抗力

球体の速さが分子の熱運動の速さより十分に小さい場合，

```math
mV^2\ll kT
```

であるから， $x_0\ll1$ となる．
このとき，誤差関数の展開は

```math
\Phi(x_0)=\frac{2}{\sqrt{\pi}}
\left(
x_0-\frac{x_0^3}{3}
+\frac{x_0^5}{10}-\cdots
\right)
\tag{17}
```

である．
式 (17) を式 (16) に代入して展開すると， $x_0^{-1}$ に比例する項は互いに打ち消し合い，最初に残る項は $x_0$ に比例する項となる．
計算すると，

```math
K=-p\pi B^2\frac{16}{3\sqrt{\pi}}
x_0\left(1+\frac15x_0^2+\cdots\right)
\tag{18}
```

を得る．

ここで $R\gg a$ であるから $B=R+a\simeq R$ と近似し，式 (13) を代入すると，

```math
\boxed{
K=-p\pi R^2\frac{16}{3}
\sqrt{\frac{m}{2\pi kT}}\,V
\left(
1+\frac15\frac{mV^2}{2kT}+\cdots
\right)
}
\tag{19}
```

となる．
したがって，最も低次の近似では，

```math
\boxed{
K\simeq-\frac{16}{3}p\pi R^2
\sqrt{\frac{m}{2\pi kT}}\,V
}
\tag{20}
```

である．
抵抗力は球体の進行方向と逆向きであり，低速では速さ $V$ に比例する．

### 6．結果の物理的な意味

この問題では，球体の半径が分子の平均自由行程より十分に小さいため，球体のまわりで気体分子同士が頻繁に衝突する効果を無視できる．
抵抗力は，球体表面で分子が弾性反射するときの運動量移動を，Maxwell 分布について足し合わせることで得られる．

低速極限の式 (20) は，抵抗力が球体の速さに比例することを示している．
ただし，ここで得られたのは希薄気体中の分子衝突による抵抗力であり，連続流体に対する Stokes の抵抗則と同じものではない．
