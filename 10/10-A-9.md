# 演習問題【10-A-9】

## 解答

### 一様な静磁場中における電気伝導率テンソル

#### 1．Boltzmann 方程式と線形応答近似

有効質量 $m^*$ をもつ伝導電子について，エネルギーと速度の関係を

```math
\epsilon(\boldsymbol p)=\frac{p^2}{2m^*},
\qquad
\boldsymbol v=\frac{\partial\epsilon}{\partial\boldsymbol p}
=\frac{\boldsymbol p}{m^*}
\tag{1}
```

とする．
電子の電荷は $-e$ であり，ここで $e>0$ は電気素量である．
一様な電場 $\boldsymbol E$ と一様な静磁場 $\boldsymbol H$ が作用するとき，定常状態の Boltzmann 方程式は，緩和時間近似のもとで

```math
-e\left(\boldsymbol E+\frac{\boldsymbol v}{c}\times\boldsymbol H\right)
\cdot\frac{\partial f}{\partial\boldsymbol p}
=-\frac{f-f_0}{\tau}
\tag{2}
```

と書ける．
ここで $f$ は電場中の分布関数， $f_0$ は平衡分布関数， $\tau$ は緩和時間， $c$ は光速である．

電場が十分に弱いとし，分布関数を

```math
f=f_0+\delta f
\tag{3}
```

と分ける．
ここで $\delta f$ は電場に比例する一次の補正である．
平衡分布関数はエネルギーのみの関数なので，

```math
\frac{\partial f_0}{\partial\boldsymbol p}
=\frac{\partial f_0}{\partial\epsilon}\boldsymbol v
\tag{4}
```

が成り立つ．
したがって，

```math
(\boldsymbol v\times\boldsymbol H)\cdot
\frac{\partial f_0}{\partial\boldsymbol p}
=\frac{\partial f_0}{\partial\epsilon}
(\boldsymbol v\times\boldsymbol H)\cdot\boldsymbol v=0
\tag{5}
```

である．
これは，磁場による力が速度に垂直であり，平衡分布 $f_0$ を直接変化させないことを意味する．
ただし，磁場項が分布関数の補正 $\delta f$ に作用する効果は残さなければならない．
これが Hall 効果を含む磁場の寄与を記述するために必要である．

式 (2) に式 (3) を代入し，電場について一次まで残すと，

```math
-e(\boldsymbol v\cdot\boldsymbol E)
\frac{\partial f_0}{\partial\epsilon}
-\frac{e}{c}(\boldsymbol v\times\boldsymbol H)
\cdot\frac{\partial\delta f}{\partial\boldsymbol p}
=-\frac{\delta f}{\tau}
\tag{6}
```

を得る．

#### 2．分布関数の一次補正を求める

式 (6) を解くため，解答例と同様に，

```math
\boxed{
f=f_0-\boldsymbol v\cdot\boldsymbol c(\epsilon)
\frac{\partial f_0}{\partial\epsilon}
}
\tag{7}
```

と仮定する．
ここで $\boldsymbol c(\epsilon)$ は，エネルギーに依存する未知のベクトルである．

$\delta f=-\boldsymbol v\cdot\boldsymbol c\,(\partial f_0/\partial\epsilon)$ を運動量で微分すると， $\boldsymbol v$ に平行な項と $-\boldsymbol c/m^*$ に比例する項が得られる．
$\boldsymbol v\times\boldsymbol H$ は $\boldsymbol v$ と直交するため，前者の項は式 (6) の磁場項との内積で消える．
したがって，

```math
(\boldsymbol v\times\boldsymbol H)\cdot
\frac{\partial\delta f}{\partial\boldsymbol p}
=-\frac{1}{m^*}
\frac{\partial f_0}{\partial\epsilon}
(\boldsymbol v\times\boldsymbol H)\cdot\boldsymbol c
\tag{8}
```

となる．
これを式 (6) に代入し， $\partial f_0/\partial\epsilon$ を共通因子として除くと，

```math
-e\boldsymbol v\cdot\boldsymbol E
+\frac{e}{m^*c}(\boldsymbol v\times\boldsymbol H)\cdot\boldsymbol c
=\frac{\boldsymbol v\cdot\boldsymbol c}{\tau}
\tag{9}
```

を得る．

スカラー三重積の関係

```math
(\boldsymbol v\times\boldsymbol H)\cdot\boldsymbol c
=(\boldsymbol H\times\boldsymbol c)\cdot\boldsymbol v
```

を用いれば，式 (9) は $\boldsymbol v$ の係数を比較することにより，

```math
-e\boldsymbol E+\frac{e}{m^*c}
\boldsymbol H\times\boldsymbol c
=\frac{\boldsymbol c}{\tau}
\tag{10}
```

と書ける．
ここで，サイクロトロン振動数ベクトルを

```math
\boxed{
\boldsymbol\omega=\frac{e\boldsymbol H}{m^*c}
}
\tag{11}
```

と定義する．
すると，

```math
\boxed{
-e\boldsymbol E+\boldsymbol\omega\times\boldsymbol c
=\frac{\boldsymbol c}{\tau}
}
\tag{12}
```

となる．
以下では $\omega=|\boldsymbol\omega|$ をその大きさとする．

#### 3．ベクトル $\boldsymbol c$ を解く

まず，式 (12) と $\boldsymbol\omega$ の内積をとる．
$\boldsymbol\omega\cdot(\boldsymbol\omega\times\boldsymbol c)=0$ なので，

```math
\boxed{
\boldsymbol\omega\cdot\boldsymbol c
=-e\tau(\boldsymbol\omega\cdot\boldsymbol E)
}
\tag{13}
```

を得る．

次に，式 (12) の両辺に左から $\boldsymbol\omega$ との外積を作用させる．
ベクトル三重積の公式

```math
\boldsymbol\omega\times(\boldsymbol\omega\times\boldsymbol c)
=\boldsymbol\omega(\boldsymbol\omega\cdot\boldsymbol c)
-\omega^2\boldsymbol c
```

を使うと，

```math
\boldsymbol\omega\times\boldsymbol c
=-e\tau(\boldsymbol\omega\times\boldsymbol E)
+\tau(\boldsymbol\omega\cdot\boldsymbol c)\boldsymbol\omega
-\tau\omega^2\boldsymbol c
\tag{14}
```

となる．
式 (13) を代入すれば，

```math
\boldsymbol\omega\times\boldsymbol c
=-e\tau(\boldsymbol\omega\times\boldsymbol E)
-e\tau^2(\boldsymbol\omega\cdot\boldsymbol E)\boldsymbol\omega
-\tau\omega^2\boldsymbol c
\tag{15}
```

を得る．
これを式 (12) に代入して整理すると，

```math
\boxed{
(1+\omega^2\tau^2)\boldsymbol c
=-e\tau\left[
\boldsymbol E
+\tau(\boldsymbol\omega\times\boldsymbol E)
+\tau^2(\boldsymbol\omega\cdot\boldsymbol E)\boldsymbol\omega
\right]
}
\tag{16}
```

となる．
ここで重要なのは，式 (15) を式 (12) に代入した直後には，

```math
\frac{\boldsymbol c}{\tau}+e\boldsymbol E
=-e\tau(\boldsymbol\omega\times\boldsymbol E)
-e\tau^2(\boldsymbol\omega\cdot\boldsymbol E)\boldsymbol\omega
-\tau\omega^2\boldsymbol c
```

となることである．
この符号で整理すると式 (16) が得られる．

式 (16) を式 (7) に代入すると，分布関数は，

```math
\boxed{
\begin{aligned}
f=f_0
+\frac{e\tau}{1+\omega^2\tau^2}
\bigl[
&\boldsymbol v
+\tau(\boldsymbol v\times\boldsymbol\omega)\\
&+\tau^2(\boldsymbol v\cdot\boldsymbol\omega)\boldsymbol\omega
\bigr]\cdot\boldsymbol E\,
\frac{\partial f_0}{\partial\epsilon}
\end{aligned}
}
\tag{17}
```

となる．
ここでは，スカラー三重積により

```math
\boldsymbol v\cdot(\boldsymbol\omega\times\boldsymbol E)
=(\boldsymbol v\times\boldsymbol\omega)\cdot\boldsymbol E
```

を用いた．

#### 4．電流密度と電気伝導率テンソル

電子の電流密度は，

```math
\boldsymbol J=-e\int\boldsymbol v f
\frac{2\,d^3p}{h^3}
\tag{18}
```

である．
ここで因子 $2$ は電子のスピン縮退度を表す．
平衡分布 $f_0$ の寄与は速度についての対称性からゼロとなるため，式 (17) の一次補正だけが電流に寄与する．
これを代入すると，

```math
\begin{aligned}
J_\alpha
=e^2\int&
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
\frac{\tau}{1+\omega^2\tau^2}\\
&\times\left[
v_\alpha v_\beta
+\tau^2(\boldsymbol v\cdot\boldsymbol\omega)
v_\alpha\omega_\beta
+\tau v_\alpha(\boldsymbol v\times\boldsymbol\omega)_\beta
\right]
E_\beta\,\frac{2\,d^3p}{h^3}
\end{aligned}
\tag{19}
```

となる．
ここで，同じ添字 $\beta$ について和をとる．

放物線型のエネルギー分散は球対称であるため，速度の方向についての平均は，

```math
\langle v_\alpha v_\beta\rangle_{\mathrm{ang}}
=\frac{v^2}{3}\delta_{\alpha\beta}
\tag{20}
```

となる．
また，Levi-Civita 記号 $\epsilon_{\alpha\beta\gamma}$ を用いれば，

```math
\left\langle
v_\alpha(\boldsymbol v\times\boldsymbol\omega)_\beta
\right\rangle_{\mathrm{ang}}
=-\frac{v^2}{3}
\epsilon_{\alpha\beta\gamma}\omega_\gamma
\tag{21}
```

である．
ここで $\delta_{\alpha\beta}$ は Kronecker のデルタである．
これらの関係から，電流密度と電場を結ぶ一般的な電気伝導率テンソルは，

```math
\boxed{
\begin{aligned}
\sigma_{\alpha\beta}
=e^2\int_0^\infty&
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
D(\epsilon)\,
\frac{\tau(\epsilon)v^2(\epsilon)}
{3[1+\omega^2\tau^2(\epsilon)]}\\
&\times
\left[
\delta_{\alpha\beta}
+\tau^2(\epsilon)\omega_\alpha\omega_\beta
-\tau(\epsilon)\epsilon_{\alpha\beta\gamma}\omega_\gamma
\right]d\epsilon
\end{aligned}
}
\tag{22}
```

と表される．
ここで $D(\epsilon)$ は，スピン縮退度を含む単位体積あたりの状態密度である．
式 (22) は，緩和時間がエネルギーに依存する場合も含んだ形である．

##### 4.1．解答例と同じ近似による簡略化

解答例と同様に，伝導に寄与するエネルギー領域で緩和時間が大きく変化しないと仮定し，

```math
\tau(\epsilon)\simeq\tau(\mu)
\tag{23}
```

と近似する．
これは，低温の縮退電子系で， $-\partial f_0/\partial\epsilon$ が化学ポテンシャル $\mu$ の近くに集中する場合に妥当な近似である．
緩和時間がもともと一定の場合にも，同じ簡略化が厳密に成立する．

放物線型バンドでは，

```math
\boxed{
\int_0^\infty
\left(-\frac{\partial f_0}{\partial\epsilon}\right)
\frac{v^2(\epsilon)}{3}
D(\epsilon)\,d\epsilon
=\frac{n}{m^*}
}
\tag{24}
```

が成り立つ．
ここで

```math
n=\int_0^\infty f_0(\epsilon)D(\epsilon)\,d\epsilon
```

は電子数密度である．
この関係は，放物線型バンドの状態密度が $D(\epsilon)\propto\sqrt{\epsilon}$ であり， $v^2=2\epsilon/m^*$ であることを用いて部分積分すると得られる．

式 (23)，(24) を式 (22) に適用すると，

```math
\boxed{
\sigma_{\alpha\beta}
=\frac{ne^2}{m^*}
\frac{\tau(\mu)}{1+\omega^2\tau^2(\mu)}
\left[
\delta_{\alpha\beta}
+\tau^2(\mu)\omega_\alpha\omega_\beta
-\tau(\mu)\epsilon_{\alpha\beta\gamma}\omega_\gamma
\right]
}
\tag{25}
```

を得る．
これが，解答例と同じ近似のもとでの一般的な電気伝導率テンソルである．

#### 5．磁場を $z$ 方向にとった場合

放物線型バンドは球対称なので，座標軸を回転させても一般性は失われない．
そこで，磁場を $z$ 軸の正方向にとる．
このとき，

```math
\boldsymbol\omega=(0,0,\omega),
\qquad
\omega=\frac{eH}{m^*c}
\tag{26}
```

である．
式 (25) に代入すると，

```math
\boxed{
\boldsymbol\sigma
=\frac{ne^2\tau(\mu)}{m^*}
\begin{pmatrix}
\dfrac{1}{1+\omega^2\tau^2(\mu)}
&
-\dfrac{\omega\tau(\mu)}{1+\omega^2\tau^2(\mu)}
&0\\[9pt]
\dfrac{\omega\tau(\mu)}{1+\omega^2\tau^2(\mu)}
&
\dfrac{1}{1+\omega^2\tau^2(\mu)}
&0\\[9pt]
0&0&1
\end{pmatrix}
}
\tag{27}
```

を得る．
すなわち，テンソルの各成分は，

```math
\boxed{
\begin{aligned}
\sigma_{xx}=\sigma_{yy}
&=\frac{ne^2}{m^*}
\frac{\tau(\mu)}{1+\omega^2\tau^2(\mu)},\\[5pt]
\sigma_{zz}
&=\frac{ne^2}{m^*}\tau(\mu),\\[5pt]
\sigma_{xy}
&=-\frac{ne^2}{m^*}
\frac{\omega\tau^2(\mu)}{1+\omega^2\tau^2(\mu)},\\[5pt]
\sigma_{yx}
&=+\frac{ne^2}{m^*}
\frac{\omega\tau^2(\mu)}{1+\omega^2\tau^2(\mu)},\\[5pt]
\sigma_{xz}=\sigma_{zx}
&=\sigma_{yz}=\sigma_{zy}=0
\end{aligned}
}
\tag{28}
```

である．

#### 6．物理的意味

磁場に垂直な $x,y$ 方向の伝導率には分母 $1+\omega^2\tau^2(\mu)$ が現れる．
これは，電子が散乱を受けるまでに磁場によって進行方向を曲げられる効果を表している．
一方，磁場に平行な $z$ 方向にはローレンツ力が作用しないため， $\sigma_{zz}$ は磁場に依存しない．

また，非対角成分 $\sigma_{xy}$ と $\sigma_{yx}$ の符号が反対であることは，磁場によって電流が電場と垂直な方向にも応答することを示す．
これは Hall 効果に対応する．

以上より，Boltzmann 方程式を線形応答近似で解き，放物線型バンドの球対称性を用いて電流を積分することにより，解答例と同じ近似のもとで磁場中の電気伝導率テンソルが得られるのである．
