# 演習問題【10-A-3】

## 解答

本問題では，２成分溶液（溶媒と溶質）において，溶媒分子の数 $N_0$ が一定の微小部分を考え，溶質分子数 $N_1$ のゆらぎが浸透圧にどのように関わるかを導出する．

### 1. 系のエネルギーとゆらぎの確率分布

まず，系が平衡状態から溶質分子数 $N_1$ だけ変化したときの最小仕事 $W_{\min}$ を考える．
定温（ $T$ 一定）での系の自由エネルギーの変化 $\Delta G$ は，熱力学の基本関係式より次のように書ける：

$$dG = -S dT + V dp + \mu_1 dN_1 + \mu_0 dN_0$$

ここで，溶媒分子の数 $N_0$ は一定であるため， $dN_0 = 0$ である．
また，温度も一定であるため， $dT = 0$ である．
したがって，

$$dG = V dp + \mu_1 dN_1$$

となる．

微小な変化 $\Delta p$ および $\Delta N_1$ に対する自由エネルギーの変化 $\Delta G$ を２次の項までテイラー展開すると，

$$\Delta G \approx V \Delta p + \mu_1 \Delta N_1 + \frac{1}{2} \left[ \left( \frac{\partial V}{\partial p} \right)_{T,N_1,N_0} (\Delta p)^2 + 2\left( \frac{\partial V}{\partial p \partial N_1} \right)_{T,N_1,N_0} \Delta p \Delta N_1 + \left( \frac{\partial^2 G}{\partial N_1^2} \right)_{T,p,N_0} (\Delta N_1)^2 \right]$$

となる．
しかし，ここで問題文にある仕事の定義 $W_{\min} = \Delta U - T \Delta S + p \Delta V - \mu_1 \Delta N_1$ を用いる．
熱力学の第一法則 $dU = T dS - p dV + \mu_1 dN_1$ より，

$$W_{\min} = (T \Delta S - p \Delta V + \mu_1 \Delta N_1) - T \Delta S + p \Delta V - \mu_1 \Delta N_1 = 0$$

となるが，これは一次の項が相殺されることを意味している．
したがって，ゆらぎの効果は二次以上の項に現れる．

Maxwell の関係式

```math
\left( \frac{\partial V}{\partial N_1} \right)_{T,p} = \left( \frac{\partial \mu_1}{\partial p} \right)_{T,N_1}
```

を用いると， $\Delta p$ と $\Delta N_1$ の交差項が消去され，定温・定圧条件での仕事 $W_{\min}$ は次のように整理できる：

```math
W_{\min} = \frac{1}{2} \left\{ -\left( \frac{\partial V}{\partial p} \right)_{T,N} (\Delta p)^2 + \left( \frac{\partial \mu_1}{\partial N_1} \right)_{T,p} (\Delta N_1)^2 \right\}
```

ここで，溶質分子数 $N_1$ のゆらぎに関する確率分布 $P(\Delta N_1)$ は，ボルツマン因子 $\exp\left( -\frac{W_{\min}}{kT} \right)$ に比例するため，

$$P(\Delta N_1) \propto \exp \left[ -\frac{1}{2kT} \left( \frac{\partial \mu_1}{\partial N_1} \right)_{T,p} (\Delta N_1)^2 \right]$$

という正規分布（ガウス分布）を得る．

この正規分布 $P(x) \propto \exp\left( -\frac{x^2}{2\sigma^2} \right)$ において，分散 $\sigma^2 = \overline{x^2}$ は $\frac{1}{\sigma^2} = \frac{1}{kT} \left( \frac{\partial \mu_1}{\partial N_1} \right)_{T,p}$ となることから，

$$\overline{(\Delta N_1)^2} = \frac{kT}{\left( \frac{\partial \mu_1}{\partial N_1} \right)_{T,p}} \quad \dots (5)$$

が得られる．

### 2. Gibbs-Duhem の関係式を用いた変換

次に，化学ポテンシャルの微分項を浸透圧 $\pi$ で表すために，Gibbs-Duhem の関係式を用いる．
定温・定圧における Gibbs-Duhem の関係式は，

$$N_0 d\mu_0 + N_1 d\mu_1 = 0$$

である．
これを $N_1$ で微分すると，

$$\frac{\partial \mu_1}{\partial N_1} = -\frac{N_0}{N_1} \frac{\partial \mu_0}{\partial N_1}$$

となる．
ここで， $\mu_0$ は溶媒の化学ポテンシャルであり，純溶媒の化学ポテンシャル $\mu_0^0$ と浸透圧 $\pi$ を用いて $\mu_0 = \mu_0^0 - \text{（浸透圧の影響）}$ と表される．
より正確には，溶媒の活性 $a_0$ を用いて $\mu_0 = \mu_0^0 + kT \log a_0$ である．
ここで， $a_0$ は溶媒のモル分率 $x_0$ に依存する．

$$\frac{\partial \mu_0}{\partial N_1} = \frac{\partial}{\partial N_1} (kT \log a_0) = \frac{kT}{a_0} \frac{\partial a_0}{\partial N_1}$$

これを用いると，

$$\frac{\partial \mu_1}{\partial N_1} = -\frac{N_0}{N_1} \frac{\partial}{\partial N_1} (kT \log a_0) \simeq \frac{\overline{V}_0}{N_A N_0 x} \frac{\partial \pi}{\partial x} \quad \dots (6)$$

が得られる．
（ここで $N_A$ はアボガドロ数， $\overline{V}_0$ は溶媒 $1\,\text{mol}$ の体積， $x \cong N_1/N_0$ はモル分率である．）

これを式 (5) に代入すると，

$$\overline{(\Delta N_1)^2} = \frac{RT N_0 x}{\overline{V}_0 \left( \frac{\partial \pi}{\partial x} \right)} \quad \dots (7)$$

となる．

### 3. 光散乱と分子量の決定

溶液中の濃度ゆらぎ $\Delta x$ は，屈折率のゆらぎ $\Delta \nu$ を引き起こす．
屈折率 $\nu$ がモル分率 $x$ の関数であるとき，

$$\Delta \nu = \left( \frac{\partial \nu}{\partial x} \right)_0 \Delta x = \frac{1}{N_0} \left( \frac{\partial \nu}{\partial x} \right)_0 \Delta N_1$$

となる．
このゆらぎの平均 $\overline{(\Delta \nu)^2}$ を求めると，

$$\overline{(\Delta \nu)^2} = \frac{1}{N_0^2} \left( \frac{\partial \nu}{\partial x} \right)_0^2 \overline{(\Delta N_1)^2} \simeq \frac{1}{V} \left( \frac{\partial \nu}{\partial x} \right)_0^2 M_0 RT x / \left( \rho N_A \overline{V}_0 \frac{\partial \pi}{\partial x} \right) \quad \dots (8)$$

が得られる．
ここで $V$ は体積， $\rho$ は密度， $M_0$ は溶媒の分子量である．
濁り度 $\tau$ が $V(\Delta \nu)^2$ に比例することを利用すれば，屈折率の微分と浸透圧の微分 $\partial \pi / \partial x$ が関連付けられる．

特に，重量濃度 $c \cong M_1 x / \overline{V}_0$ （ $M_1$ は溶質の分子量）を用いて浸透圧 $\pi$ を表すと，

$$\frac{\partial \pi}{\partial c} = \frac{RT}{M_1} + \alpha c + \beta c^2 + \dots$$

という展開が得られる．
したがって，濃度 $c$ に対する浸透圧の勾配 $\partial \pi / \partial c$ を測定することで，溶質の分子量 $M_1$ を決定することができる．
これは高分子の分子量測定において極めて重要な手法である．

## 解説

本問題は，統計力学的な「ゆらぎ」という微視的な現象が，浸透圧や光散乱といった巨視的な物理量にどのように結びつくかを記述している．

1.  **ゆらぎと確率分布**: 
    熱力学的な平衡状態において，系の状態量は完全に固定されているわけではなく，微小なゆらぎが存在する．
    このゆらぎの大きさは，その状態を実現するために必要なエネルギー（仕事 $W_{\min}$ ）によって制限される．
    エネルギーが高い状態ほど実現確率は低くなるため，ボルツマン分布 $\exp(-E/kT)$ に従って，ゆらぎの大きさ $\Delta N_1$ は正規分布に従うことが導かれる．

2.  **Gibbs-Duhem の役割**: 
    溶液のような多成分系では，成分ごとの化学ポテンシャルは独立ではなく，互いに関連し合っている．
    これが Gibbs-Duhem の関係式である．
    これを用いることで，未知の「溶質分子数の変化に伴う化学ポテンシャルの変化」を，測定可能な「浸透圧の変化」へと変換することができる．

3.  **光散乱と分子量の関係**: 
    溶液中の溶質が不均一に分布すると（濃度ゆらぎ），その場所によって屈折率がわずかに異なる．
    この屈折率のゆらぎが光を散乱させ，溶液が濁って見える（光散乱）．
    この散乱の強さを精密に測定することは，間接的に濃度ゆらぎの大きさを知ることであり，そこから溶液の熱力学的な性質である浸透圧の勾配を導き出し，最終的に未知の分子量 $M_1$ を算出する一連の流れとなっている．
