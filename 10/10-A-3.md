# 演習問題【10-A-3】

## 解答

### 溶質分子数のゆらぎと浸透圧の関係

#### 1．問題の設定

溶媒分子を $N_0$ 個含む部分系を考える．
溶媒分子数 $N_0$ は一定であるが，溶質分子数 $N_1$ は周囲のリザーバーとの交換によって変化し，平衡値のまわりでゆらぐものとする．
温度 $T$ は一定であり，温度のゆらぎは考えない．
また，系は温度 $T$ ，外部圧力 $p_{\mathrm{ext}}$ ，溶質の化学ポテンシャル $\mu_{1,\mathrm{ext}}$ を規定する外部環境と接しているものとする．

このとき，系の体積 $V$ と溶質分子数 $N_1$ はゆらぐ．
一方，溶媒分子数 $N_0$ は固定される．

溶質分子数のゆらぎの分散

```math
\overline{(\Delta N_1)^2}
```

を求め，それを希薄溶液の浸透圧 $\pi$ と結び付ける．
ここで，

```math
\Delta N_1=N_1-N_1^*
```

は平衡値 $N_1^*$ からのずれを表す．
以下では，熱力学量とその偏微分は平衡状態で評価するものとし，式を簡潔にするため必要に応じて上付きの $^{*}$ を省略する．

#### 2． $T-p-\mu$ 分布による溶質分子数のゆらぎ

##### 2.1．熱力学ポテンシャルと確率分布

温度 $T$ ，外部圧力 $p_{\mathrm{ext}}$ ，溶質の外部化学ポテンシャル $\mu_{1,\mathrm{ext}}$ が一定の系を考える．
溶媒分子数 $N_0$ は一定である．

Helmholtz 自由エネルギーを

```math
F=F(T,V,N_0,N_1)
```

とする．
このとき，系の熱力学ポテンシャルは

```math
\Phi
=
F(T,V,N_0,N_1)
+p_{\mathrm{ext}}V
-\mu_{1,\mathrm{ext}}N_1
\tag{1}
```

である．

このアンサンブルにおいて，体積 $V$ と溶質分子数 $N_1$ の確率分布は，平衡状態近傍で

```math
P(V,N_1)
\propto
\exp\left(-\frac{\Phi}{kT}\right)
\tag{2}
```

と表される．
ここで，体積については連続変数としての確率密度を考え，溶質分子数については本来整数値の確率を考える．
以下では，平均溶質分子数が十分大きい場合に，その離散分布を連続変数で近似する．

平衡状態では，熱力学ポテンシャル $\Phi$ が極小となるため，

```math
\left(\frac{\partial F}{\partial V}\right)_{T,N_0,N_1}
+p_{\mathrm{ext}}=0
\tag{3}
```

および

```math
\left(\frac{\partial F}{\partial N_1}\right)_{T,V,N_0}
-\mu_{1,\mathrm{ext}}=0
\tag{4}
```

が成立する．

系内部の圧力と溶質の化学ポテンシャルを

```math
p_{\mathrm{int}}
=
-\left(\frac{\partial F}{\partial V}\right)_{T,N_0,N_1}
```

```math
\mu_1
=
\left(\frac{\partial F}{\partial N_1}\right)_{T,V,N_0}
```

と定義すると，平衡条件は

```math
p_{\mathrm{int}}=p_{\mathrm{ext}},
\qquad
\mu_1=\mu_{1,\mathrm{ext}}
```

となる．
すなわち，平衡状態では系内部の圧力が外部圧力に等しく，系内部の化学ポテンシャルが外部リザーバーの化学ポテンシャルに等しい．

##### 2.2．熱力学ポテンシャルの二次展開

平衡状態の体積と溶質分子数をそれぞれ $V^*$ ， $N_1^*$ とし，

```math
\Delta V=V-V^*,
\qquad
\Delta N_1=N_1-N_1^*
```

とおく．

熱力学ポテンシャル $\Phi$ を平衡点のまわりで二次まで Taylor 展開すると，一次の項は平衡条件 (3)，(4) によって消える．
したがって，

```math
\Delta\Phi
=
\frac12
\left[
a(\Delta V)^2
+2b\Delta V\Delta N_1
+c(\Delta N_1)^2
\right]
+O(\Delta^3)
\tag{5}
```

となる．
ここで，

```math
a=
\left(\frac{\partial^2F}{\partial V^2}\right)_{T,N_0,N_1}
```

```math
b=
\left(\frac{\partial^2F}{\partial V\partial N_1}\right)_{T,N_0}
```

```math
c=
\left(\frac{\partial^2F}{\partial N_1^2}\right)_{T,V,N_0}
```

であり，いずれも平衡点で評価する．

式 (2)，(5) から，

```math
\begin{aligned}
P(\Delta V,\Delta N_1)
\propto
\exp\biggl[
-\frac{1}{2kT}
\bigl\{
&a(\Delta V)^2\\
&+2b\Delta V\Delta N_1\\
&+c(\Delta N_1)^2
\bigr\}
\biggr]
\end{aligned}
\tag{6}
```

を得る．

##### 2.3．体積ゆらぎの積分

式 (6) の指数部分を平方完成すると，

```math
\begin{aligned}
&a(\Delta V)^2
+2b\Delta V\Delta N_1
+c(\Delta N_1)^2\\
&=
a\left(
\Delta V+\frac{b}{a}\Delta N_1
\right)^2
+
\left(c-\frac{b^2}{a}\right)(\Delta N_1)^2
\end{aligned}
\tag{7}
```

となる．

したがって，体積ゆらぎを積分して溶質分子数だけの確率分布を求めると，

```math
\begin{aligned}
P(\Delta N_1)
&\propto
\int_{-\infty}^{\infty}
P(\Delta V,\Delta N_1)\,d(\Delta V)\\
&\propto
\exp\left[
-\frac{1}{2kT}
\left(c-\frac{b^2}{a}\right)
(\Delta N_1)^2
\right]
\end{aligned}
\tag{8}
```

となる．
ここでは二次近似を用いているため，積分範囲を平衡点近傍から実数全体に拡張した．
また，この Gaussian 積分から得られる前置因子は平衡点で評価した定数であり， $\Delta N_1$ に依存しないため規格化定数に吸収される．

##### 2.4．係数と化学ポテンシャルの微分との関係

ここで，

```math
p_{\mathrm{int}}
=
-\left(\frac{\partial F}{\partial V}\right)_{T,N_0,N_1}
```

であるため，平衡点の近傍で温度と溶媒分子数を固定すると，

```math
dp_{\mathrm{int}}
=
-a\,dV-b\,dN_1
\tag{9}
```

となる．

外部圧力一定のもとで平衡体積が変化する経路では，

```math
dp_{\mathrm{int}}=0
```

であるから，

```math
\left(\frac{\partial V}{\partial N_1}\right)_{T,p,N_0}
=-\frac{b}{a}
\tag{10}
```

を得る．

一方，

```math
\mu_1=
\left(\frac{\partial F}{\partial N_1}\right)_{T,V,N_0}
```

であるから，温度と圧力を一定にしたとき，

```math
\begin{aligned}
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
&=
c+
b\left(\frac{\partial V}{\partial N_1}\right)_{T,p,N_0}\\
&=
c-\frac{b^2}{a}
\end{aligned}
\tag{11}
```

となる．

式 (8)，(11) から，

```math
\boxed{
P(\Delta N_1)
=C\exp\left[
-\frac{1}{2kT}
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
(\Delta N_1)^2
\right]
}
\tag{12}
```

を得る．

したがって，Gaussian 分布の分散は，

```math
\boxed{
\overline{(\Delta N_1)^2}
=
\frac{kT}{
\left(\dfrac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}}
}
\tag{13}
```

となる．

ここでは，安定な平衡状態において熱力学ポテンシャルの二次形式が正定値であることを仮定している．
特に，

```math
a>0,
\qquad
c-\frac{b^2}{a}>0
```

が必要である．
第1の条件は体積方向の力学的安定性，第2の条件は体積を緩和させた後の溶質分子数方向の安定性に対応する．

また，Gaussian 近似は平衡値の近傍で二次以上の項を無視できる場合に適用される．
溶質分子数は本来整数であるため，連続変数近似には平均溶質分子数が十分大きいことも必要である．

#### 3．Gibbs–Duhem の関係式を用いる

##### 3.1．化学ポテンシャルの微分関係

二成分系の Gibbs–Duhem の関係式は，

```math
-S\,dT+V\,dp+N_0\,d\mu_0+N_1\,d\mu_1=0
\tag{14}
```

である．
温度と圧力を一定にすると，

```math
N_0\,d\mu_0+N_1\,d\mu_1=0
\tag{15}
```

となる．

ここで， $T,p,N_0$ を固定した経路に沿って $N_1$ を変化させる．

```math
d\mu_0=
\left(\frac{\partial\mu_0}{\partial N_1}\right)_{T,p,N_0}dN_1
```

および

```math
d\mu_1=
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}dN_1
```

を式 (15) に代入すると，

```math
\begin{aligned}
&N_0
\left(\frac{\partial\mu_0}{\partial N_1}\right)_{T,p,N_0}dN_1\\
&\quad+
N_1
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}dN_1
=0
\end{aligned}
```

となる．
$dN_1\neq0$ として両辺を $dN_1$ で割れば，

```math
N_0
\left(\frac{\partial\mu_0}{\partial N_1}\right)_{T,p,N_0}
+
N_1
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
=0
```

である．
したがって，

```math
\boxed{
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
=
-\frac{N_0}{N_1}
\left(\frac{\partial\mu_0}{\partial N_1}\right)_{T,p,N_0}
}
\tag{16}
```

を得る．

##### 3.2．溶媒の化学ポテンシャルと浸透圧

溶媒の化学ポテンシャル $\mu_0$ は，溶媒の活量 $a_0$ を用いて，

```math
\mu_0(T,p,x)
=
\mu_0^0(T,p)+kT\log a_0
\tag{17}
```

と表される．
ここで， $\mu_0^0(T,p)$ は同じ温度と圧力における純溶媒の化学ポテンシャルである．

浸透圧 $\pi$ は，半透膜を隔てて純溶媒と溶液を平衡にするために必要な圧力差である．
溶液側の圧力を $p$ ，純溶媒側の圧力を $p-\pi$ とする．
半透膜を介した溶媒の化学ポテンシャルの平衡条件は，

```math
\mu_0(T,p,x)=\mu_0^0(T,p-\pi)
\tag{18}
```

である．

純溶媒の化学ポテンシャルについて，

```math
\left(\frac{\partial\mu_0^0}{\partial p}\right)_T
=
\frac{\overline V_0}{N_A}
```

が成立する．
ここで， $\overline V_0$ は純溶媒のモル体積， $N_A$ はアボガドロ定数である．

希薄溶液で溶媒のモル体積を一定と近似すると，

```math
\begin{aligned}
\mu_0^0(T,p-\pi)
&\simeq
\mu_0^0(T,p)
-\frac{\overline V_0}{N_A}\pi
\end{aligned}
```

となる．
したがって，式 (17)，(18) より，

```math
kT\log a_0
\simeq
-\frac{\overline V_0}{N_A}\pi
\tag{19}
```

を得る．
ここでは，浸透圧による圧力変化に伴う溶媒のモル体積の変化も無視している．

式 (19) を $T,p,N_0$ 一定のもとで $N_1$ について微分すると，

```math
\boxed{
\left(\frac{\partial\mu_0}{\partial N_1}\right)_{T,p,N_0}
\simeq
-\frac{\overline V_0}{N_A}
\left(\frac{\partial\pi}{\partial N_1}\right)_{T,N_0}
}
\tag{20}
```

となる．
ここでは $\overline V_0$ を組成に依存しない定数として扱った．

式 (20) を式 (16) に代入すれば，

```math
\boxed{
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
\simeq
\frac{N_0}{N_1}
\frac{\overline V_0}{N_A}
\left(\frac{\partial\pi}{\partial N_1}\right)_{T,N_0}
}
\tag{21}
```

を得る．

#### 4．希薄溶液での近似と最終結果

溶質のモル分率を

```math
x=\frac{N_1}{N_0+N_1}
\tag{22}
```

と定義する．
このとき，

```math
\left(\frac{\partial x}{\partial N_1}\right)_{N_0}
=
\frac{N_0}{(N_0+N_1)^2}
=
\frac{(1-x)^2}{N_0}
\tag{23}
```

である．

希薄溶液では $x\ll1$ なので，

```math
\left(\frac{\partial x}{\partial N_1}\right)_{N_0}
\simeq\frac1{N_0}
```

となる．

連鎖律から，

```math
\left(\frac{\partial\pi}{\partial N_1}\right)_{T,N_0}
=
\left(\frac{\partial\pi}{\partial x}\right)_T
\left(\frac{\partial x}{\partial N_1}\right)_{N_0}
```

であるから，

```math
\left(\frac{\partial\pi}{\partial N_1}\right)_{T,N_0}
\simeq
\frac1{N_0}
\left(\frac{\partial\pi}{\partial x}\right)_T
\tag{24}
```

となる．

式 (21) に代入すると，

```math
\begin{aligned}
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
&\simeq
\frac{N_0}{N_1}
\frac{\overline V_0}{N_A N_0}
\left(\frac{\partial\pi}{\partial x}\right)_T\\
&=
\frac{\overline V_0}{N_A N_1}
\left(\frac{\partial\pi}{\partial x}\right)_T
\end{aligned}
```

である．
さらに，希薄溶液では $N_1\simeq N_0x$ なので，

```math
\boxed{
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
\simeq
\frac{\overline V_0}{N_A N_0x}
\left(\frac{\partial\pi}{\partial x}\right)_T
}
\tag{25}
```

を得る．

これを分散の式 (13) に代入すると，

```math
\boxed{
\overline{(\Delta N_1)^2}
\simeq
\frac{kT N_A N_0x}
{\overline V_0\left(\dfrac{\partial\pi}{\partial x}\right)_T}
}
\tag{26}
```

となる．
気体定数 $R=N_Ak$ を用いれば，

```math
\boxed{
\overline{(\Delta N_1)^2}
\simeq
\frac{RTN_0x}
{\overline V_0\left(\dfrac{\partial\pi}{\partial x}\right)_T}
}
\tag{27}
```

である．
これが，希薄溶液における溶質分子数のゆらぎと浸透圧との関係である．

#### 5．結果の意味と検算

式 (27) は，溶質のモル分率 $x$ に対する浸透圧の傾き $(\partial\pi/\partial x)_T$ が，溶質分子数のゆらぎの大きさを決めることを示している．

安定な均一溶液では，溶質分子数方向の熱力学的安定性から，

```math
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}>0
```

である必要がある．
式 (25) より，希薄溶液近似のもとでは，

```math
\left(\frac{\partial\pi}{\partial x}\right)_T>0
```

に対応する．
浸透圧の傾きが小さいほど分散は大きくなり，濃度ゆらぎが大きくなる．

さらに，希薄な理想溶液では，van ’t Hoff の式から，

```math
\pi\simeq\frac{RT}{\overline V_0}x
```

である．
したがって，

```math
\left(\frac{\partial\pi}{\partial x}\right)_T
\simeq
\frac{RT}{\overline V_0}
```

となる．
これを式 (27) に代入すると，

```math
\begin{aligned}
\overline{(\Delta N_1)^2}
&\simeq
\frac{RTN_0x}
{\overline V_0(RT/\overline V_0)}\\
&=N_0x\\
&\simeq N_1
\end{aligned}
```

を得る．
すなわち，

```math
\boxed{
\overline{(\Delta N_1)^2}\simeq N_1
}
\tag{28}
```

である．

これは，希薄な理想溶液では，溶質分子数の分散が平均溶質分子数に等しくなることを示している．
この結果は，理想希薄系で期待される Poisson 型のゆらぎと整合する．
ただし，式 (28) は分散の一致を示すものであり，Gaussian 近似から Poisson 分布そのものが導かれるわけではない．
平均溶質分子数が十分大きい場合には，Poisson 分布は Gaussian 分布で近似できる．

以上より，溶質分子数のゆらぎは $T-p-\mu$ 分布の Gaussian 近似によって決まり，Gibbs–Duhem の関係式と浸透圧の定義を用いることで，希薄溶液における浸透圧の濃度依存性と結び付けられる．
