# 演習問題【10-A-3】

## 解答

### 溶質分子数のゆらぎと浸透圧の関係

#### 1．問題の設定

溶媒分子を $N_0$ 個含む部分系を考える．
溶媒分子数 $N_0$ は一定であるが，溶質分子数 $N_1$ は周囲との交換によって変化し，平衡値のまわりでゆらぐものとする．
温度 $T$ は一定であり，温度のゆらぎは考えない．

この問題では，溶質分子数 $N_1$ のゆらぎの分散

```math
\overline{(\Delta N_1)^2}
```

を求め，それを希薄溶液の浸透圧 $\pi$ と結び付ける．
ここで，

```math
\Delta N_1=N_1-N_1^*
```

は，平衡値 $N_1^*$ からのずれを表す．
以下では，熱力学量とその偏微分は平衡状態で評価するものとし，式を簡潔にするため必要に応じて上付きの $^*$ を省略する．

#### 2．最小仕事と溶質分子数のゆらぎ

##### 2.1．最小仕事の二次展開

溶媒分子数 $N_0$ が一定の系では，熱力学の基本関係式は

```math
dU=T\,dS-p\,dV+\mu_1\,dN_1
\tag{1}
```

である．
ここで， $U$ は内部エネルギー， $S$ はエントロピー， $V$ は体積， $p$ は圧力， $\mu_1$ は溶質の化学ポテンシャルである．
化学ポテンシャルとは，温度，圧力および他の成分の量を適切に固定したときに，その成分を1分子加えることで変化する自由エネルギーを表す量である．

平衡状態からのずれを実現するための最小仕事を

```math
W_{\min}
=\Delta U-T\Delta S+p\Delta V-\mu_1\Delta N_1
\tag{2}
```

とする．
右辺の $T,p,\mu_1$ は平衡状態の値である．

重要なのは，式 (1) は微小変化に対する一次の関係式であり，有限の変化に対してそのまま式 (2) に代入してよいわけではないことである．
正しくは，内部エネルギー $U(S,V,N_1)$ を平衡点のまわりで二次まで Taylor 展開する．
その一次の項は式 (1) に対応し，式 (2) の $-T\Delta S+p\Delta V-\mu_1\Delta N_1$ と相殺する．
したがって，最小仕事は二次の項から決まる．

二次の項は，温度，圧力，化学ポテンシャルの平衡値からの一次の変化を用いて，

```math
\boxed{
W_{\min}
=\frac12\left(
\Delta T\,\Delta S
-\Delta p\,\Delta V
+\Delta\mu_1\,\Delta N_1
\right)
}
\tag{3}
```

と表せる．
ここで， $\Delta T,\Delta p,\Delta\mu_1$ はすべて平衡点の近傍で一次まで評価した変化である．
温度のゆらぎを考えないという条件から， $\Delta T=0$ となり，

```math
W_{\min}
=\frac12\left(
-\Delta p\,\Delta V
+\Delta\mu_1\,\Delta N_1
\right)
\tag{4}
```

を得る．

##### 2.2．圧力と溶質分子数による表現

温度を一定にしたまま，圧力 $p$ と溶質分子数 $N_1$ の変化を考える．
平衡点の近傍では，

```math
\begin{aligned}
\Delta V
={}&
\left(\frac{\partial V}{\partial p}\right)_{T,N_0,N_1}
\Delta p\\
&+
\left(\frac{\partial V}{\partial N_1}\right)_{T,p,N_0}
\Delta N_1
\end{aligned}
\tag{5}
```

および

```math
\begin{aligned}
\Delta\mu_1
={}&
\left(\frac{\partial\mu_1}{\partial p}\right)_{T,N_0,N_1}
\Delta p\\
&+
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
\Delta N_1
\end{aligned}
\tag{6}
```

である．

ここで，Gibbs 自由エネルギーを

```math
G=U-TS+pV
```

とおくと，

```math
dG=-S\,dT+V\,dp+\mu_0\,dN_0+\mu_1\,dN_1
```

となる．
$N_0$ を固定して混合二階偏微分の等しさを用いると，Maxwell の関係式

```math
\boxed{
\left(\frac{\partial V}{\partial N_1}\right)_{T,p,N_0}
=
\left(\frac{\partial\mu_1}{\partial p}\right)_{T,N_0,N_1}
}
\tag{7}
```

が得られる．

式 (5)，(6) を式 (4) に代入すると，

```math
\begin{aligned}
W_{\min}=\frac12\biggl[
&-\left(\frac{\partial V}{\partial p}\right)_{T,N_0,N_1}
(\Delta p)^2\\
&+\left\{
-\left(\frac{\partial V}{\partial N_1}\right)_{T,p,N_0}
+\left(\frac{\partial\mu_1}{\partial p}\right)_{T,N_0,N_1}
\right\}\Delta p\Delta N_1\\
&+\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
(\Delta N_1)^2
\biggr]
\end{aligned}
\tag{8}
```

となる．
式 (7) により，交差項 $\Delta p\Delta N_1$ の係数はゼロになる．
したがって，

```math
\boxed{
\begin{aligned}
W_{\min}=\frac12\biggl[
&-\left(\frac{\partial V}{\partial p}\right)_{T,N_0,N_1}
(\Delta p)^2\\
&+\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
(\Delta N_1)^2
\biggr]
\end{aligned}
}
\tag{9}
```

を得る．
これが，溶質分子数のゆらぎを導くための重要な式である．

##### 2.3．溶質分子数の確率分布

平衡状態からのずれの確率は，最小仕事を用いて Boltzmann 因子

```math
P\propto\exp\left(-\frac{W_{\min}}{kT}\right)
\tag{10}
```

に比例すると表される．
式 (9) を代入すると，圧力と溶質分子数の同時確率分布は，

```math
\begin{aligned}
P(\Delta p,\Delta N_1)\propto
\exp\biggl[
&\frac{1}{2kT}
\left(\frac{\partial V}{\partial p}\right)_{T,N_0,N_1}
(\Delta p)^2\\
&-\frac{1}{2kT}
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
(\Delta N_1)^2
\biggr]
\end{aligned}
\tag{11}
```

となる．
この式は $\Delta p$ のみを含む因子と $\Delta N_1$ のみを含む因子に分離している．
したがって，圧力のゆらぎを積分して取り除けば，溶質分子数について，

```math
\boxed{
P(\Delta N_1)=C
\exp\left[
-\frac{1}{2kT}
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
(\Delta N_1)^2
\right]
}
\tag{12}
```

という Gaussian 分布を得る．
ここで $C$ は規格化定数である．
この近似は，ゆらぎが平衡値の近傍に限られる場合に適用するものである．

平均値からのずれ $y$ に対する Gaussian 分布

```math
P(y)\propto\exp\left(-\frac{y^2}{2\sigma^2}\right)
```

では，分散は $\overline{y^2}=\sigma^2$ である．
式 (12) と比較すると，

```math
\boxed{
\overline{(\Delta N_1)^2}
=
\frac{kT}{
\left(\dfrac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}}
}
\tag{13}
```

となる．
したがって，溶質分子数のゆらぎを求めるには，化学ポテンシャルの $N_1$ に関する微分を浸透圧で表せばよい．

#### 3．Gibbs–Duhem の関係式を用いる

##### 3.1．化学ポテンシャルの微分関係

二成分系の Gibbs–Duhem の関係式は，

```math
-S\,dT+V\,dp+N_0\,d\mu_0+N_1\,d\mu_1=0
\tag{14}
```

である．
温度と圧力を一定にすると，

```math
N_0\,d\mu_0+N_1\,d\mu_1=0
\tag{15}
```

となる．
ここで $N_0$ は一定であるため，式 (15) を $N_1$ で微分することで，

```math
\boxed{
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
=-\frac{N_0}{N_1}
\left(\frac{\partial\mu_0}{\partial N_1}\right)_{T,p,N_0}
}
\tag{16}
```

を得る．
これにより，溶質の化学ポテンシャルの微分を，溶媒の化学ポテンシャルの微分に置き換えられる．

##### 3.2．溶媒の化学ポテンシャルと浸透圧

溶媒の化学ポテンシャル $\mu_0$ は，溶媒の活量 $a_0$ を用いて，

```math
\mu_0(T,p,x)=\mu_0^0(T,p)+kT\log a_0
\tag{17}
```

と表される．
ここで $\mu_0^0(T,p)$ は同じ温度と圧力における純溶媒の化学ポテンシャルである．

浸透圧 $\pi$ は，半透膜を隔てて純溶媒と溶液を平衡にするために必要な圧力差である．
溶媒のモル体積 $\overline V_0$ を希薄溶液中でも一定と近似すると，圧力差による純溶媒の化学ポテンシャルの変化は，溶媒1分子当たりの体積 $\overline V_0/N_A$ を用いて表せる．
ここで $N_A$ はアボガドロ定数である．
溶媒の化学ポテンシャルが半透膜を隔てて等しいという条件から，

```math
\mu_0(T,p,x)
\simeq\mu_0^0(T,p-\pi)
\simeq\mu_0^0(T,p)-\frac{\overline V_0}{N_A}\pi
\tag{18}
```

となる．
式 (17)，(18) より，

```math
kT\log a_0\simeq-\frac{\overline V_0}{N_A}\pi
\tag{19}
```

が得られる．
したがって，温度と圧力を一定にして $N_1$ で微分すると，

```math
\boxed{
\left(\frac{\partial\mu_0}{\partial N_1}\right)_{T,p,N_0}
\simeq
-\frac{\overline V_0}{N_A}
\left(\frac{\partial\pi}{\partial N_1}\right)_{T,N_0}
}
\tag{20}
```

となる．
ここでは，希薄溶液で溶媒のモル体積がほぼ一定であることを用いた．

式 (20) を式 (16) に代入すれば，

```math
\boxed{
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
\simeq
\frac{N_0}{N_1}\frac{\overline V_0}{N_A}
\left(\frac{\partial\pi}{\partial N_1}\right)_{T,N_0}
}
\tag{21}
```

を得る．
この式が，化学ポテンシャルの微分と浸透圧の微分を結ぶ関係である．

#### 4．希薄溶液での近似と最終結果

溶質のモル分率を

```math
x=\frac{N_1}{N_0+N_1}
\tag{22}
```

と定義する．
希薄溶液では $N_1\ll N_0$ であるため，

```math
x\simeq\frac{N_1}{N_0},
\qquad
\left(\frac{\partial x}{\partial N_1}\right)_{N_0}
\simeq\frac1{N_0}
\tag{23}
```

と近似できる．
したがって，

```math
\left(\frac{\partial\pi}{\partial N_1}\right)_{T,N_0}
\simeq
\frac1{N_0}
\left(\frac{\partial\pi}{\partial x}\right)_T
\tag{24}
```

であり，式 (21) は，

```math
\boxed{
\left(\frac{\partial\mu_1}{\partial N_1}\right)_{T,p,N_0}
\simeq
\frac{\overline V_0}{N_A N_0x}
\left(\frac{\partial\pi}{\partial x}\right)_T
}
\tag{25}
```

となる．
これを分散の式 (13) に代入すると，

```math
\overline{(\Delta N_1)^2}
\simeq
\frac{kT N_A N_0x}
{\overline V_0\left(\dfrac{\partial\pi}{\partial x}\right)_T}
\tag{26}
```

を得る．
気体定数 $R=N_Ak$ を用いれば，求める結果は，

```math
\boxed{
\overline{(\Delta N_1)^2}
\simeq
\frac{RTN_0x}
{\overline V_0\left(\dfrac{\partial\pi}{\partial x}\right)_T}
}
\tag{27}
```

である．
これが，希薄溶液における溶質分子数のゆらぎと浸透圧との関係である．

#### 5．結果の意味と検算

式 (27) は，溶質のモル分率 $x$ に対する浸透圧の傾き $(\partial\pi/\partial x)_T$ が，溶質分子数のゆらぎの大きさを決めることを示している．
安定な均一溶液では，分散が正であるために，

```math
\left(\frac{\partial\pi}{\partial x}\right)_T>0
```

であることが必要である．
浸透圧の傾きが小さければ分散は大きくなり，濃度のゆらぎが大きいことを意味する．

さらに，希薄な理想溶液では，van ’t Hoff の式から，

```math
\pi\simeq\frac{RT}{\overline V_0}x
```

である．
したがって，

```math
\left(\frac{\partial\pi}{\partial x}\right)_T
\simeq\frac{RT}{\overline V_0}
```

となる．
これを式 (27) に代入すれば，

```math
\boxed{
\overline{(\Delta N_1)^2}\simeq N_0x\simeq N_1
}
\tag{28}
```

を得る．
すなわち，希薄な理想溶液では，溶質分子数の分散は平均溶質分子数に等しい．
これは，互いの相互作用を無視できる希薄系で期待される Poisson 型のゆらぎと整合する結果である．

以上より，溶質分子数のゆらぎは Gaussian 近似のもとで化学ポテンシャルの微分によって決まり，Gibbs–Duhem の関係式と浸透圧の定義を用いることで，希薄溶液における浸透圧の濃度依存性と結び付けられるのである．
