# 演習問題【10-A-7】

## 解答

### 電場中の電子の平均速度と電気伝導率

#### 1．電子にはたらく力と加速度

金属内に $x$ 方向の一様な電場 $E$ をかける．
電子の電荷を $-e$ ，質量を $m$ とすると，電子にはたらく電場の力は

```math
F_x=-eE
\tag{1}
```

である．
ニュートンの運動方程式 $F_x=ma_x$ より，電子の加速度は

```math
\boxed{a_x=-\frac{eE}{m}}
\tag{2}
```

となる．
したがって，散乱が起こらない間，電子の速度は電場と反対の向きに変化する．

#### 2．散乱の間の電子の平均速度

電子は金属内で熱運動しており，不純物などによって一定時間 $\tau$ ごとに等方的に散乱されると仮定する．
等方的な散乱では，散乱直後の熱運動の方向に偏りがなく，平均速度はゼロとなる．
ここでは，問題文の仮定に従い，散乱直後の平均速度がゼロに戻るものとする．

散乱直後から次の散乱までの時間を $t$ とする．
この間は加速度が一定であるため，式 (2) から電子の平均速度は

```math
v_x(t)=a_xt=-\frac{eE}{m}t
\qquad (0\leq t<\tau)
\tag{3}
```

となる．
この式は，散乱直後には平均速度がゼロであるが，電場によって次の散乱まで徐々に負の方向へ増加することを表している．

##### 時間平均を求める

すべての電子が同時に散乱されるわけではなく，電子ごとに散乱の時刻は異なる．
そのため，観測時刻における電子集団の平均速度は，散乱からの経過時間 $t$ が $0$ から $\tau$ まで一様に分布すると考えて求められる．
したがって，平均速度は，

```math
\begin{aligned}
\overline{v_x}
&=\frac1{\tau}\int_0^\tau v_x(t)\,dt\\
&=\frac1{\tau}\int_0^\tau
\left(-\frac{eE}{m}t\right)\,dt\\
&=-\frac{eE}{m\tau}
\left[\frac{t^2}{2}\right]_0^\tau\\
&=-\frac{eE\tau}{2m}
\end{aligned}
```

となる．
よって，

```math
\boxed{\overline{v_x}=-\frac{eE\tau}{2m}}
\tag{4}
```

を得る．
この係数 $1/2$ は，散乱直後のゼロから次の散乱直前の $-eE\tau/m$ まで，平均速度が時間に対して直線的に変化することから生じるものである．

#### 3．電流密度と電気伝導率

金属内の電子数密度を $n$ とする．
電荷 $q$ をもつ粒子の数密度が $n$ ，平均速度が $\overline{v_x}$ であるとき，電流密度は $j_x=nq\overline{v_x}$ である．
電子の電荷は $-e$ なので，

```math
j_x=-en\overline{v_x}
\tag{5}
```

となる．
式 (4) を代入すると，

```math
\begin{aligned}
j_x
&=-en\left(-\frac{eE\tau}{2m}\right)\\
&=\frac{ne^2\tau}{2m}E
\end{aligned}
```

を得る．
したがって，

```math
j_x=\sigma E
\tag{6}
```

と定義される電気伝導率 $\sigma$ は，

```math
\boxed{\sigma=\frac{ne^2\tau}{2m}}
\tag{7}
```

となる．
電子は負電荷を持つため，電子の平均速度は電場と反対向きであるが，電流密度は電場と同じ向きとなる．

#### 4．標準的な Drude モデルとの違い

以上の結果は，散乱が一定時間 $\tau$ ごとに起こるという問題文の仮定に基づくものである．
この場合，散乱間の時間平均から係数 $1/2$ が現れる．

一方，標準的な Drude モデルでは，散乱が一定間隔で起きるのではなく，平均散乱時間が $\tau$ となる確率的な過程として扱うことがある．
このとき，散乱からの経過時間 $t$ の確率密度は，

```math
P(t)=\frac1{\tau}e^{-t/\tau}
\qquad (t\geq0)
\tag{8}
```

となる．
この確率密度を用いて平均速度を求めると，

```math
\begin{aligned}
\overline{v_x}
&=\int_0^\infty
\left(-\frac{eE}{m}t\right)
\frac1{\tau}e^{-t/\tau}\,dt\\
&=-\frac{eE}{m\tau}
\int_0^\infty te^{-t/\tau}\,dt\\
&=-\frac{eE\tau}{m}
\end{aligned}
\tag{9}
```

となる．
したがって，このモデルでは

```math
\boxed{\sigma=\frac{ne^2\tau}{m}}
\tag{10}
```

となり，固定間隔モデルの結果の2倍となる．
これは計算の矛盾ではなく，散乱時間の扱いが異なるためである．

#### 結論

問題文の「一定時間 $\tau$ ごとに等方的に散乱される」という仮定のもとでは，電子の平均速度は

```math
\boxed{\overline{v_x}=-\frac{eE\tau}{2m}}
```

であり，電流密度と電場の比例関係 $j_x=\sigma E$ から，電気伝導率は

```math
\boxed{\sigma=\frac{ne^2\tau}{2m}}
```

となる．
これが本問題で求める略算値である．
