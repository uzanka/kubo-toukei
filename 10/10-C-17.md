# 演習問題【10-C-17】

## 解答

この問題では，希薄気体の Boltzmann 方程式を **緩和時間近似（BGK 型近似）** で解き，局所 Maxwell 分布からのずれを求めることで，粘性係数 $\eta$ と熱伝導係数 $\kappa$ を導く．

重要なのは，分子の流速に対する相対速度

```math
\boldsymbol c=\boldsymbol v-\boldsymbol V(\boldsymbol x)
```

を導入することである．
緩和時間は問題文の指定どおり，

```math
\tau(c)=Ac^s,\qquad A>0
```

とする．

以下では，三次元の単原子理想気体を考え，分子1個の質量を $m$ ，Boltzmann 定数を $k\_{\mathrm B}$ とする．

## 1. 局所平衡分布と Boltzmann 方程式

与えられた方程式は

```math
\frac{\partial f}{\partial t} +\boldsymbol v\cdot\nabla\_{\boldsymbol x}f =-\frac{f-f_0}{\tau(c)}
```

である．
局所 Maxwell 分布は

```math
f_0=n\left(\frac{m}{2\pi k\_{\mathrm B}T}\right)^{3/2} \exp\left(-\frac{mc^2}{2k\_{\mathrm B}T}\right)
```

で与えられる．
ここで $n=n(\boldsymbol x,t)$ ， $T=T(\boldsymbol x,t)$ ， $\boldsymbol V=\boldsymbol V(\boldsymbol x,t)$ は，それぞれ局所数密度，温度，流速である．

分布関数を

```math
f=f_0+f_1,\qquad |f_1|\ll f_0
```

と近似し，空間・時間変化の一次まで考えると，

```math
\boxed{ f_1=-\tau(c) \left(\frac{\partial}{\partial t} +\boldsymbol v\cdot\nabla\_{\boldsymbol x}\right)f_0 }
```

となる．
右辺の微分は，速度 $\boldsymbol v$ を固定して作用させる．

この式を流速の勾配と温度の勾配に分けると，粘性と熱伝導に対応する項が得られる．
なお，局所平衡の保存則を用いて，密度や圧力の勾配に由来する項を整理する必要がある．

## 2. 粘性係数 $\eta$ の導出

局所平衡分布からのずれ $f_1$ のうち，流速の空間変化に関係する項を考える．
粘性応力テンソルは

```math
P\_{ij}=m\int c_i c_j f\\,d^3c
```

で定義される．
局所平衡分布は等方的なので，非平衡補正 $f_1$ だけが粘性応力を生む．

速度分布の等方性を利用すると，粘性係数は

```math
\boxed{ \eta=\frac{m}{15k\_{\mathrm B}T} \int \tau(c)c^4 f_0\\,d^3c }
```

と書ける．

ここで，Maxwell 分布による速度のモーメントを

```math
\langle c^q\rangle =\frac{1}{n}\int c^q f_0\\,d^3c
```

と定義する．
すると，

```math
\eta=\frac{nmA}{15k\_{\mathrm B}T} \langle c^{s+4}\rangle
```

である．

Maxwell 分布のモーメントは

```math
\boxed{ \langle c^q\rangle =\left(\frac{2k\_{\mathrm B}T}{m}\right)^{q/2} \frac{\Gamma\left(\frac{q+3}{2}\right)} {\Gamma\left(\frac32\right)} }
```

で与えられる．
これに $q=s+4$ を代入すると，

```math
\langle c^{s+4}\rangle =\left(\frac{2k\_{\mathrm B}T}{m}\right)^{(s+4)/2} \frac{\Gamma\left(\frac{s+7}{2}\right)} {\Gamma\left(\frac32\right)}
```

となる．

したがって，粘性係数は

```math
\boxed{ \displaystyle \eta= \frac{2nmA}{15\sqrt{\pi}\\,k\_{\mathrm B}T} \left(\frac{2k\_{\mathrm B}T}{m}\right)^{(s+4)/2} \Gamma\left(\frac{s+7}{2}\right) }
```

である．
ここでは $\Gamma(3/2)=\sqrt{\pi}/2$ を使った．

## 3. 熱伝導係数 \\(\kappa\\) の導出

熱流束ベクトルは，局所流速に対する相対速度を用いて

```math
\boldsymbol q=\frac{m}{2} \int c^2\boldsymbol c\\,f\\,d^3c
```

と定義される．
局所平衡分布 $f_0$ からの熱流束はゼロなので，

```math
\boldsymbol q=\frac{m}{2} \int c^2\boldsymbol c\\,f_1\\,d^3c
```

である．

温度勾配に比例する $f_1$ の項を用いると，

```math
\boldsymbol q=-\kappa\nabla T
```

となり，熱伝導係数は

```math
\boxed{ \kappa= \frac{m^2}{12k\_{\mathrm B}T^2} \int \tau(c)c^6 f_0\\,d^3c -\frac{5m}{12T} \int \tau(c)c^4 f_0\\,d^3c }
```

と表される．

第1項は分子速度の高次モーメント，第2項は局所平衡の流体方程式を使うことで現れる補正項である．
両方を含めることが重要である．

$\tau(c)=Ac^s$ と電子数密度ではなく分子数密度 $n$ を用いた Maxwell 分布のモーメントを代入すると，

```math
\begin{aligned} \kappa={}& \frac{nm^2A}{12k\_{\mathrm B}T^2} \langle c^{s+6}\rangle\\\ &-\frac{5nmA}{12T} \langle c^{s+4}\rangle . \end{aligned}
```

それぞれのモーメントを評価し，ガンマ関数の漸化式

```math
\Gamma(z+1)=z\Gamma(z)
```

を用いて整理すると，

```math
\boxed{ \displaystyle \kappa= \frac{nmA(s+2)}{6\sqrt{\pi}\\,T} \left(\frac{2k\_{\mathrm B}T}{m}\right)^{(s+4)/2} \Gamma\left(\frac{s+7}{2}\right) }
```

が得られる．

## 4. 最終結果と収束条件

以上より，粘性係数と熱伝導係数は次のようになる．

```math
\boxed{ \eta= \frac{2nmA}{15\sqrt{\pi}\\,k\_{\mathrm B}T} \left(\frac{2k\_{\mathrm B}T}{m}\right)^{(s+4)/2} \Gamma\left(\frac{s+7}{2}\right) }
```

```math
\boxed{ \kappa= \frac{nmA(s+2)}{6\sqrt{\pi}\\,T} \left(\frac{2k\_{\mathrm B}T}{m}\right)^{(s+4)/2} \Gamma\left(\frac{s+7}{2}\right) }
```

ただし，これらの積分が有限となる条件は，いずれも

```math
\boxed{s>-7}
```

である．
問題文には $s>-9$ とありますが，この条件だけでは粘性係数の積分は収束しない．

また，速度依存の緩和時間を単純に BGK 型衝突項に代入した今回のモデルでは， $-7<s<-2$ の範囲で上式の $\kappa$ が負になる．
これは通常の物理的な熱伝導係数としては不自然であり，速度依存緩和時間を用いる衝突モデルの保存則との整合性に注意が必要である．

### 確認：緩和時間が一定の場合

$s=0$ ，すなわち $\tau=A$ とすると，

```math
\boxed{\eta=nk\_{\mathrm B}TA}
```

```math
\boxed{\kappa=\frac52\frac{k\_{\mathrm B}}{m} nk\_{\mathrm B}TA}
```

となる．
これは単原子理想気体の BGK 緩和時間近似で得られる標準的な結果と一致する．
