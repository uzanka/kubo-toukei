# 演習問題【10-C-17】

## 解答

### 1．Chapman–Enskog展開と整合条件

局所場 $n,\boldsymbol V,T$ は位置と時間の関数とする．

```math
\boldsymbol c=\boldsymbol v-\boldsymbol V,\qquad
c=|\boldsymbol c|,\qquad
a=\frac{m}{2kT},\qquad
\theta=\nabla\cdot\boldsymbol V
```

とおく．局所Maxwell分布は

```math
f_0=n\left(\frac{a}{\pi}\right)^{3/2}e^{-ac^2}
```

である．

分布関数を

```math
f=f_0+f_1+\cdots
```

と展開する．
ここで，局所場 $n,\boldsymbol V,T$ は分布関数 $f$ の通常のモーメントで定義する．
すなわち，

```math
n=\int f\,d^3v,
```

```math
n\boldsymbol V=\int\boldsymbol v f\,d^3v,
```

```math
\frac32nkT=\frac m2\int c^2f\,d^3v
```

とする．
したがって，一次の補正項には整合条件

```math
\boxed{
\int f_1
\begin{pmatrix}
1\\
\boldsymbol c\\
c^2
\end{pmatrix}
d^3c=0
}
\tag{1}
```

を課す．

緩和時間は

```math
\tau=Ac^s
```

である．
$s\ne0$ では衝突項は一般に質量・運動量・エネルギーを保存しないため，通常の保存則から導かれるEuler方程式をそのまま用いることはできない．
以下では，式(1)の整合条件から局所場の時間発展を求める．

一次のChapman–Enskog方程式は

```math
\left(\partial_t^{(0)}+\boldsymbol v\cdot\nabla\right)f_0
=-\frac{f_1}{\tau}
```

である．

```math
H=\frac{1}{f_0}
\left(\partial_t^{(0)}+\boldsymbol v\cdot\nabla\right)f_0
```

とおけば，

```math
\boxed{
f_1=-Ac^sf_0H
}
\tag{2}
```

となる．

### 2．局所場の時間発展

```math
D_t=\partial_t^{(0)}+\boldsymbol V\cdot\nabla
```

とおく．
局所Maxwell分布を微分すると，

```math
\begin{aligned}
H={}&D_t\ln n+
\left(ac^2-\frac32\right)D_t\ln T
+2a\boldsymbol c\cdot D_t\boldsymbol V\\
&+\boldsymbol c\cdot\nabla\ln n
+\left(ac^2-\frac32\right)
 \boldsymbol c\cdot\nabla\ln T
+2a\boldsymbol c\boldsymbol c:\nabla\boldsymbol V
\end{aligned}
\tag{3}
```

を得る．

ここで，

```math
\alpha=D_t\ln n-\frac32D_t\ln T,
```

```math
\beta=a\left(D_t\ln T+\frac23\theta\right),
```

```math
\boldsymbol B=
\nabla\ln n-\frac32\nabla\ln T+2aD_t\boldsymbol V
```

と定義する．
また，

```math
\boldsymbol c\boldsymbol c:\nabla\boldsymbol V
=
\left(\boldsymbol c\boldsymbol c-\frac13c^2\boldsymbol I\right):
\nabla\boldsymbol V
+\frac13c^2\theta
```

を用いると，式(3)は

```math
\boxed{
\begin{aligned}
H={}&\alpha+\beta c^2
+\boldsymbol c\cdot\boldsymbol B
+ac^2\boldsymbol c\cdot\nabla\ln T\\
&+2a\left(
\boldsymbol c\boldsymbol c-\frac13c^2\boldsymbol I
\right):\nabla\boldsymbol V
\end{aligned}
}
\tag{4}
```

となる．

モーメント

```math
M_r=\int c^{s+2r}f_0\,d^3c
```

を定義する．
極座標で積分すると，

```math
\boxed{
M_r=
n\left(\frac{2kT}{m}\right)^{(s+2r)/2}
\frac{\Gamma\!\left(\frac{s+2r+3}{2}\right)}
{\Gamma(3/2)}
}
\tag{5}
```

である．
この積分が通常の意味で有限となる条件は

```math
s+2r>-3
```

である．

#### 2.1 質量・エネルギーの整合条件

まず $s>-3$ の場合を考える．
このとき $M_0,M_1,M_2$ は有限である．
式(1)に式(2)，式(4)を代入し，奇関数の積分と等方的な角度積分を用いると，質量およびエネルギーの条件から

```math
\alpha M_0+\beta M_1=0,
```

```math
\alpha M_1+\beta M_2=0
```

を得る．

ここで，正の重み $c^sf_0d^3c$ に関する $c^2$ の分散が正であるため，

```math
M_0M_2-M_1^2>0
```

である．
したがって，

```math
\alpha=\beta=0
```

となる．

次に， $-4<s\le-3$ の場合を考える．
この範囲では $M_0$ が発散するため，上の二つのモーメント方程式をそのまま用いることはできない．

一方，分布関数の一次補正 $f_1$ が通常の分布関数として整合条件(1)を満たすためには，少なくとも

```math
\int |f_1|\,d^3c<\infty
```

でなければならない．
式(4)において $c\to0$ とすると，

```math
H=\alpha+O(c)
```

である．
したがって， $\alpha\ne0$ ならば

```math
|f_1|\sim Ac^sf_0|\alpha|
```

となり，低速側の絶対積分は

```math
\int_0 c^{s+2}\,dc
```

に比例する．
これは $s\le-3$ で発散する．
よって，

```math
\alpha=0
```

でなければならない．

この条件の下では， $-4<s\le-3$ において式(4)の残りの各項に対応する $f_1$ はすべて低速側で絶対可積分である．
具体的には， $\beta$ 項，速度勾配項，温度勾配項の絶対積分の低速側の主要部分は，それぞれ

```math
\int_0c^{s+4}\,dc,\qquad
\int_0c^{s+4}\,dc,\qquad
\int_0c^{s+5}\,dc
```

に比例し，いずれも $s>-4$ で収束する．
また， $\boldsymbol c\cdot\boldsymbol B$ の項は

```math
\int_0c^{s+3}\,dc
```

に比例し，同じく $s>-4$ で収束する．

そこで質量の整合条件を適用すると，奇関数の項と角度平均がゼロとなる traceless 項は消え，

```math
\beta M_1=0
```

を得る．
この範囲では $M_1$ は有限かつ正であるため，

```math
\beta=0
```

となる．

以上より，通常の分布関数としての整合条件が成立する範囲 $s>-4$ では，

```math
\alpha=\beta=0
```

である．
したがって，

```math
\boxed{
D_t\ln n=-\theta,\qquad
D_t\ln T=-\frac23\theta
}
\tag{6}
```

を得る．

#### 2.2 運動量の整合条件

式(1)の運動量の条件に式(2)，式(4)を代入する．
等方性から，

```math
\int c_ic_jc^sf_0\,d^3c
=\frac13\delta_{ij}M_1,
```

```math
\int c_ic_jc^{s+2}f_0\,d^3c
=\frac13\delta_{ij}M_2
```

である．
よって，

```math
0=-\frac A3
\left(
M_1\boldsymbol B+aM_2\nabla\ln T
\right)
```

を得る．

したがって，

```math
\boldsymbol B+a\frac{M_2}{M_1}\nabla\ln T=0
```

である．
式(5)から

```math
a\frac{M_2}{M_1}=\frac{s+5}{2}
```

なので，

```math
2aD_t\boldsymbol V+\nabla\ln n
+\frac{s+2}{2}\nabla\ln T=0
```

となる．
よって，

```math
\boxed{
D_t\boldsymbol V
=-\frac{kT}{m}
\left(
\nabla\ln n+\frac{s+2}{2}\nabla\ln T
\right)
}
\tag{7}
```

を得る．

### 3．一次の分布関数

式(6)，式(7)を式(3)に代入する．
密度勾配に比例する項は相殺される．
また，速度勾配の等方部分は式(6)の温度発展式によって相殺される．
したがって，

```math
\boxed{
\begin{aligned}
H={}&
\left(ac^2-\frac{s+5}{2}\right)
\boldsymbol c\cdot\nabla\ln T\\
&+2a\left(
\boldsymbol c\boldsymbol c-\frac13c^2\boldsymbol I
\right):\nabla\boldsymbol V
\end{aligned}
}
\tag{8}
```

となる．

式(2)から，一次の分布関数は

```math
\boxed{
\begin{aligned}
f_1=-Ac^sf_0\Bigg[
&\left(ac^2-\frac{s+5}{2}\right)
\boldsymbol c\cdot\nabla\ln T\\
&+2a\left(
\boldsymbol c\boldsymbol c-\frac13c^2\boldsymbol I
\right):\nabla\boldsymbol V
\Bigg]
\end{aligned}
}
\tag{9}
```

である．

### 4．粘性係数

圧力テンソルの一次補正は

```math
P_{ij}^{(1)}
=m\int c_ic_jf_1\,d^3c
```

で定義される．
式(9)のうち，圧力テンソルに寄与するのは速度勾配に比例する項だけである．

等方的な角度積分から，

```math
\begin{aligned}
&\int c_ic_j
\left(c_kc_l-\frac13c^2\delta_{kl}\right)
c^sf_0\,d^3c\\
&\quad=
\frac{M_2}{15}
\left(
\delta_{ik}\delta_{jl}
+\delta_{il}\delta_{jk}
-\frac23\delta_{ij}\delta_{kl}
\right)
\end{aligned}
```

を得る．
したがって，

```math
P_{ij}^{(1)}
=-\frac{2amA}{15}M_2
\left(
\partial_iV_j+\partial_jV_i
-\frac23\delta_{ij}\theta
\right)
```

となる．

Newton粘性則

```math
P_{ij}^{(1)}
=-\eta\left(
\partial_iV_j+\partial_jV_i
-\frac23\delta_{ij}\theta
\right)
```

と比較すると，

```math
\eta=\frac{2amA}{15}M_2
```

である．
式(5)と

```math
\Gamma(7/2)=\frac{15}{4}\Gamma(3/2)
```

を用いて整理すると，

```math
\boxed{
\eta
=AnkT\left(\frac{2kT}{m}\right)^{s/2}
\frac{\Gamma\!\left(\frac{s+7}{2}\right)}
{\Gamma(7/2)}
}
\tag{10}
```

を得る．

### 5．熱伝導係数

熱流束の一次補正は

```math
q_i^{(1)}
=\frac m2\int c^2c_if_1\,d^3c
```

で定義される．
式(9)のうち，熱流束に寄与するのは温度勾配に比例する項だけである．等方性から，

```math
q_i^{(1)}
=-\frac{mA}{6}\partial_i\ln T
\int c^{s+4}f_0
\left(ac^2-\frac{s+5}{2}\right)d^3c
```

となる．

式(5)のガンマ関数の漸化式から，

```math
\int c^{s+6}f_0\,d^3c
=\frac{s+7}{2a}
\int c^{s+4}f_0\,d^3c
```

である．
よって，

```math
\begin{aligned}
&\int c^{s+4}f_0
\left(ac^2-\frac{s+5}{2}\right)d^3c\\
&\quad=
\left(\frac{s+7}{2}-\frac{s+5}{2}\right)
\int c^{s+4}f_0\,d^3c\\
&\quad=M_2
\end{aligned}
```

を得る．
したがって，

```math
q_i^{(1)}
=-\frac{mA}{6T}M_2\,\partial_iT
```

である．
Fourier則

```math
q_i^{(1)}=-\lambda\partial_iT
```

と比較して，

```math
\lambda=\frac{mA}{6T}M_2
```

となる．
式(5)を代入すると，

```math
\boxed{
\lambda
=\frac{2Ank}{3\sqrt{\pi}}
\left(\frac{2kT}{m}\right)^{1+s/2}
\Gamma\!\left(\frac{s+7}{2}\right)
}
\tag{11}
```

を得る．

### 6．輸送係数と適用範囲

通常の分布関数としてのChapman–Enskog展開が成立する範囲 $s>-4$ では，粘性係数および熱伝導係数は

```math
\boxed{
\eta
=AnkT\left(\frac{2kT}{m}\right)^{s/2}
\frac{\Gamma\!\left(\frac{s+7}{2}\right)}
{\Gamma(7/2)}
}
```

および

```math
\boxed{
\lambda
=\frac{2Ank}{3\sqrt{\pi}}
\left(\frac{2kT}{m}\right)^{1+s/2}
\Gamma\!\left(\frac{s+7}{2}\right)
}
```

である．
その比は

```math
\boxed{
\frac{\lambda}{\eta}=\frac{5k}{2m}
}
```

となる．
単原子理想気体の質量比熱

```math
c_V=\frac{3k}{2m}
```

を用いれば，

```math
\boxed{
\frac{\lambda}{\eta c_V}=\frac53
}
```

である．

特に $s=0$ では，

```math
\eta=AnkT,\qquad
\lambda=\frac52\frac{k}{m}AnkT
```

となり，通常のBGKモデルの結果と一致する．

ここで，問題文の指定範囲 $s>-9$ に対する低速側の収束条件を検討する．
輸送係数の積分に現れる

```math
M_2=\int c^{s+4}f_0\,d^3c
```

は，低速側で

```math
\int_0c^{s+6}\,dc
```

に比例する．
したがって，粘性係数と熱伝導係数の積分そのものが有限となる条件は

```math
\boxed{s>-7}
```

である．

一方，標準的なChapman–Enskog展開では，一次補正 $f_1$ 自体も速度空間で絶対可積分でなければならない．
これを式(9)の温度勾配項とせん断項に分けて確認する．

温度勾配項は

```math
f_{1,T}
=-Ac^sf_0
\left(ac^2-\frac{s+5}{2}\right)
\boldsymbol c\cdot\nabla\ln T
```

である．
$s\ne-5$ かつ $\nabla T\ne0$ の場合，低速側では

```math
|f_{1,T}|\sim c^{s+1}
```

となる．
したがって，その絶対積分は

```math
\int_0c^{s+3}\,dc
```

に比例し，収束条件は

```math
s>-4
```

である．

ただし， $s=-5$ では

```math
ac^2-\frac{s+5}{2}=ac^2
```

となり，温度勾配項の最低次の係数が消える．
この場合，

```math
|f_{1,T}|\sim c^{s+3}=c^{-2}
```

であり，その絶対積分は

```math
\int_0c^0\,dc
```

に比例して収束する．
したがって，温度勾配項だけからは $s=-5$ を除外できない．

しかし，せん断項は

```math
f_{1,S}
=-2aAc^sf_0
\left(
\boldsymbol c\boldsymbol c-\frac13c^2\boldsymbol I
\right):\nabla\boldsymbol V
```

である．
せん断変形が存在するとき，低速側では

```math
|f_{1,S}|\sim c^{s+2}
```

となる．
その絶対積分は

```math
\int_0c^{s+4}\,dc
```

に比例するため，収束条件は

```math
s>-5
```

である．
特に $s=-5$ では

```math
\int_0c^{-1}\,dc
```

となり，対数発散する．

したがって， $s=-5$ では温度勾配項は絶対可積分であるが，せん断項が絶対可積分でない．
また， $s\ne-5$ では温度勾配項の収束条件が $s>-4$ である．
以上から，一般の独立な温度勾配とせん断変形を含む一次補正 $f_1$ が絶対可積分となる条件は

```math
\boxed{s>-4}
```

である．

以上をまとめると，問題文の範囲 $s>-9$ は次のように分類される．

```math
\begin{array}{c|l}
s\text{ の範囲}&\text{結論}\\ \hline
s>-4&
f_1\text{ が絶対可積分であり，通常のChapman–Enskog展開が成立する}\\
-7<s\le-4&
輸送係数の積分は有限だが，一般の温度勾配とせん断を含む
f_1\text{ は絶対可積分でない}\\
-9<s\le-7&
輸送係数の積分そのものが発散し，有限な係数は得られない
\end{array}
```

したがって，式(10)，式(11)は，通常の分布関数としてのChapman–Enskog展開が成立する

```math
\boxed{s>-4}
```

の範囲で物理的な輸送係数を与える．
$-7<s\le-4$ では輸送係数のモーメント積分だけは形式的に有限であるが，一次補正が通常の分布関数として成立しないため，その式を通常のChapman–Enskog輸送係数として適用することはできない．
また， $-9<s\le-7$ では輸送係数の積分自体が発散する．
