# 演習問題【10-C-17】

## 解答

希薄気体の Boltzmann 方程式を緩和時間近似で扱い，局所平衡分布からのわずかなずれを求めることによって，粘性係数および熱伝導係数を導く．
解答例と同様に，流体力学的な保存則を用いて分布関数の一次近似を求め，速度空間で積分する方法を用いる．

最終的に，緩和時間が

```math
\tau=A|\boldsymbol v-\boldsymbol V|^s
```

で与えられるとき，せん断粘性係数 $\eta$ と熱伝導係数 $\lambda$ は

```math
\boxed{
\eta =AnkT \left(\frac{2kT}{m}\right)^{s/2} \frac{\Gamma\left(\dfrac{s+7}{2}\right)} {\Gamma\left(\dfrac72\right)}
}
\quad \cdots (1)
```

```math
\boxed{
\lambda =Ank \left(\frac{2kT}{m}\right)^{1+s/2} \frac{s+2}{3\sqrt{\pi}} \Gamma\left(\frac{s+7}{2}\right)
}
\quad \cdots (2)
```

となる．
ここで， $m$ は分子1個の質量， $n$ は分子数密度， $T$ は温度， $k$ は Boltzmann 定数であり， $\Gamma$ はガンマ関数である．
以下で，これらの式を順に導く．

## 1．局所平衡分布と巨視的な物理量

### 1.1　分布関数の意味

気体分子はさまざまな速度で運動している．
分布関数 $f(\boldsymbol x,\boldsymbol v,t)$ は，位置 $\boldsymbol x$ ，速度 $\boldsymbol v$ ，時刻 $t$ の近くにある分子の分布を表す関数である．

分子の質量を $m$ とすると，気体の質量密度 $\rho$ ，流速 $\boldsymbol V$ ，単位体積当たりの内部エネルギー $e$ は，それぞれ

```math
\rho=m\int f\,d^3v=mn,
```

```math
\rho\boldsymbol V =\int m\boldsymbol v f\,d^3v,
```

```math
e=\int\frac{1}{2}m|\boldsymbol v-\boldsymbol V|^2 f\,d^3v
\quad \cdots (3)
```

で与えられる．
ここで，

```math
d^3v=dv_x\,dv_y\,dv_z
```

である．
内部エネルギーでは，気体全体の流れによる運動エネルギーを除き，分子の平均流速に対する相対運動のエネルギーを数えている．

局所平衡状態では，分布関数は Maxwell 分布

```math
\boxed{
f_0 =n\left(\frac{m}{2\pi kT}\right)^{3/2} \exp\left(-\frac{m|\boldsymbol v-\boldsymbol V|^2}{2kT}\right)
}
\quad \cdots (4)
```

で近似できる．
これは，分子速度が平均流速 $\boldsymbol V$ の周りに温度 $T$ に応じて分布していることを表す．
温度が高いほど，分子速度のばらつきが大きくなる．

以下では，流速からの相対速度を

```math
\boxed{
\boldsymbol c=\boldsymbol v-\boldsymbol V
}
\quad \cdots (5)
```

と定義する．
すると，局所平衡分布は

```math
f_0=n\left(\frac{m}{2\pi kT}\right)^{3/2} e^{-mc^2/(2kT)
}
\quad \cdots (6)
```

となる．
ここで $c=|\boldsymbol c|$ である．

### 1.2　圧力テンソルと熱流ベクトル

圧力テンソル $P_{\mu\nu}$ と熱流ベクトル $q_\mu$ を

```math
\boxed{
P\_{\mu\nu} =m\int c\_\mu c\_\nu f\,d^3c
}
\quad \cdots (7)
```

```math
\boxed{
q\_\mu =\frac m2\int c^2c\_\mu f\,d^3c
}
\quad \cdots (8)
```

と定義する．
添字 $\mu,\nu$ は $x,y,z$ のいずれかを表す．

圧力テンソルは，分子の運動によって各方向に伝わる運動量を表す．
一方，熱流ベクトルは，分子のランダムな運動によって運ばれるエネルギーの流れを表す．

局所平衡分布 $f_0$ は速度空間で等方的であるため，

```math
P_{\mu\nu}^{(0)}=nkT\delta_{\mu\nu}, \qquad \boldsymbol q^{(0)}=\boldsymbol 0
\quad \cdots (9)
```

となる．
ここで $\delta_{\mu\nu}$ は Kronecker のデルタである．
したがって，局所平衡状態の圧力は

```math
\boxed{
p=nkT
}
\quad \cdots (10)
```

である．
また，単原子理想気体の内部エネルギーは

```math
e=\frac{3}{2} nkT
\quad \cdots (11)
```

となる．

このように，局所平衡状態では圧力は等方的であり，熱流は存在しない．
粘性係数と熱伝導係数を求めるには，局所平衡からのずれを計算すればよい．

## 2．Boltzmann 方程式の一次近似

### 2.1　分布関数のずれ

与えられた Boltzmann 方程式は

```math
\frac{\partial f}{\partial t} +\boldsymbol v\cdot\nabla_{\boldsymbol x}f =-\frac{f-f_0}{\tau(c)}
\quad \cdots (12)
```

である．
ここで $\tau(c)$ は分子の相対速度の大きさ $c$ に依存する緩和時間である．

分布関数を

```math
f=f_0+f_1,\qquad |f_1|\ll f_0
\quad \cdots (13)
```

とおく．
$f_1$ は局所平衡分布からの小さなずれを表す．
粘性と熱伝導は，このずれによって生じる．

空間・時間変化の一次まで考えると，式(12)の左辺にある $f$ を $f_0$ で置き換えられる．
したがって，

```math
\frac{\partial f_0}{\partial t} +\boldsymbol v\cdot\nabla_{\boldsymbol x}f_0 \simeq-\frac{f-f_0}{\tau(c)}
```

より，

```math
\boxed{
f_1=-\tau(c) \left( \frac{\partial}{\partial t} +\boldsymbol v\cdot\nabla_{\boldsymbol x} \right)f_0
}
\quad \cdots (14)
```

を得る．

つまり，局所平衡分布が空間や時間とともに変化する速さを求めれば，その変化に対して分子分布がどれだけ遅れるかを緩和時間 $\tau$ から計算できる．
これが一次近似の基本である．

### 2.2　局所平衡分布の微分

物質微分を

```math
\frac{D}{Dt} =\frac{\partial}{\partial t} +\boldsymbol V\cdot\nabla_{\boldsymbol x}
\quad \cdots (15)
```

と定義する．
これは，気体の流れとともに移動する立場で見た時間変化を表す．

すると，

```math
\frac{\partial}{\partial t} +\boldsymbol v\cdot\nabla_{\boldsymbol x} = \frac{D}{Dt} +\boldsymbol c\cdot\nabla_{\boldsymbol x}
\quad \cdots (16)
```

である．

式(6)の対数を取ると，

```math
\ln f_0 =\ln n+\frac{3}{2}\ln\left(\frac{m}{2\pi kT}\right) -\frac{mc^2}{2kT}
\quad \cdots (17)
```

となる．
これを時間・空間について微分すれば， $n$ ， $T$ ， $\boldsymbol V$ の変化を通じて $f_0$ の変化を求められる．

その際，物質微分に必要な $n,T,\boldsymbol V$ の時間変化を定めるために，解答例と同じく局所平衡状態での流体力学方程式を用いる．

連続の式から，

```math
\boxed{
\frac{Dn}{Dt}=-n\nabla\cdot\boldsymbol V
}
\quad \cdots (18)
```

を得る．

局所平衡での運動方程式

```math
\rho\frac{D\boldsymbol V}{Dt}=-\nabla p
```

と $p=nkT$ ， $\rho=mn$ を用いると，

```math
\boxed{
\frac{D\boldsymbol V}{Dt} =-\frac{kT}{m} \left(\nabla\ln n+\nabla\ln T\right)
}
\quad \cdots (19)
```

となる．

さらに，単原子理想気体の内部エネルギーが $e=\frac{3}{2} nkT$ であることから，局所平衡でのエネルギー式を用いると，

```math
\boxed{
\frac{DT}{Dt} =-\frac{2}{3} T\nabla\cdot\boldsymbol V
}
\quad \cdots (20)
```

を得る．

これらの式を式(17)の微分に代入して整理すると，

```math
\begin{aligned}
\frac1{f_0} \left( \frac{\partial}{\partial t} +\boldsymbol v\cdot\nabla_{\boldsymbol x} \right)f_0 ={}& \left(\frac{mc^2}{2kT}-\frac{5}{2}\right) \boldsymbol c\cdot\nabla\ln T \\
&+\frac{m}{kT} \left( \boldsymbol c\boldsymbol c -\frac{c^2}{3}\boldsymbol 1 \right):\nabla\boldsymbol V
\end{aligned}
\quad \cdots (21)
```

となる．

ここで， $\boldsymbol 1$ は単位テンソル， $:$ は二階テンソルの二重縮約を表す．
例えば，

```math
\left(\boldsymbol c\boldsymbol c\right):\nabla\boldsymbol V =\sum_{\mu,\nu}c_\mu c_\nu \frac{\partial V_\mu}{\partial x_\nu}
```

である．

式(21)には二種類の項がある．
第1項は温度勾配 $\nabla T$ に比例し，第2項は速度勾配 $\nabla\boldsymbol V$ に比例する．
前者が熱伝導を生み，後者が粘性応力を生む．

式(14)に代入すれば，

```math
\boxed{
\begin{aligned}
f_1=-\tau(c)f_0\Bigg[ &\left(\frac{mc^2}{2kT}-\frac{5}{2}\right) \boldsymbol c\cdot\nabla\ln T \\
&+\frac{m}{kT} \left( \boldsymbol c\boldsymbol c -\frac{c^2}{3}\boldsymbol 1 \right):\nabla\boldsymbol V \Bigg]
\end{aligned}
}
\quad \cdots (22)
```

を得る．

この式が以降の計算の出発点である．

## 3．粘性係数 $\eta$ の導出

### 3.1　圧力テンソルの非平衡補正

圧力テンソルは式(7)より

```math
P_{\mu\nu}=m\int c_\mu c_\nu(f_0+f_1)\,d^3c
```

である．
局所平衡分布からの寄与は $p\delta_{\mu\nu}$ なので，

```math
P_{\mu\nu} =p\delta_{\mu\nu} +m\int c_\mu c_\nu f_1\,d^3c
\quad \cdots (23)
```

となる．

粘性係数を求めるために，例えば $\mu=x,\nu=y$ とした非対角成分を考える．
式(22)のうち，速度勾配に比例する項だけが寄与する．
したがって，

```math
\begin{aligned}
P'_{xy} =-\frac{m^2}{kT} \int \tau(c)f_0 c_x^2c_y^2\,d^3c \left( \frac{\partial V_x}{\partial y} +\frac{\partial V_y}{\partial x} \right)
\end{aligned}
\quad \cdots (24)
```

となる．

ここで，粘性係数の定義

```math
P'_{xy} =-\eta \left( \frac{\partial V_x}{\partial y} +\frac{\partial V_y}{\partial x} \right)
\quad \cdots (25)
```

と比較すると，

```math
\boxed{
\eta=\frac{m^2}{kT} \int\tau(c)f_0c_x^2c_y^2\,d^3c
}
\quad \cdots (26)
```

を得る．

### 3.2　角度積分

分布関数 $f_0$ と緩和時間 $\tau(c)$ は $c=|\boldsymbol c|$ だけに依存する．
そこで，相対速度空間を球座標で表し，

```math
d^3c=c^2\sin\theta\,dc\,d\theta\,d\phi
\quad \cdots (27)
```

とする．

相対速度の成分は

```math
c_x=c\sin\theta\cos\phi,\qquad c_y=c\sin\theta\sin\phi
```

と書けるため，

```math
\begin{aligned}
\int c_x^2c_y^2\,d\Omega &=c^4\int_0^\pi\sin^5\theta\,d\theta \int_0^{2\pi}\cos^2\phi\sin^2\phi\,d\phi \\
&=c^4\cdot\frac{16}{15}\cdot\frac{\pi}{4} \\
&=\frac{4\pi}{15}c^4
\end{aligned}
\quad \cdots (28)
```

となる．
ここで $d\Omega=\sin\theta\\,d\theta\\,d\phi$ は立体角要素である．

式(26)に式(28)を代入すると，

```math
\eta =\frac{4\pi m^2}{15kT} \int_0^\infty \tau(c)f_0(c)c^6\,dc
\quad \cdots (29)
```

を得る．

### 3.3　緩和時間 \\(\tau=Ac^s\\) の場合

式(6)および $\tau(c)=Ac^s$ を代入すると，

```math
\boxed{
\eta =\frac{4\pi Am^2n}{15kT} \left(\frac{m}{2\pi kT}\right)^{3/2} \int_0^\infty c^{s+6}e^{-mc^2/(2kT)}\,dc
}
\quad \cdots (30)
```

となる．

ここで，

```math
\alpha=\frac{m}{2kT}
```

とおくと，ガンマ関数の積分公式

```math
\int_0^\infty x^{q-1}e^{-\alpha x^2}\,dx =\frac{1}{2}\alpha^{-q/2}\Gamma\left(\frac q2\right)
\quad \cdots (31)
```

を使える．
式(30)では $q=s+7$ なので，

```math
\int_0^\infty c^{s+6}e^{-\alpha c^2}\,dc =\frac{1}{2}\alpha^{-(s+7)/2} \Gamma\left(\frac{s+7}{2}\right)
\quad \cdots (32)
```

となる．

したがって，

```math
\eta =\frac{2\pi Am^2n}{15kT} \left(\frac{m}{2\pi kT}\right)^{3/2} \left(\frac{2kT}{m}\right)^{(s+7)/2} \Gamma\left(\frac{s+7}{2}\right)
\quad \cdots (33)
```

を得る．
係数を整理し，

```math
\Gamma\left(\frac72\right)=\frac{15\sqrt{\pi}}8
```

を用いると，

```math
\boxed{
\eta =AnkT \left(\frac{2kT}{m}\right)^{s/2} \frac{\Gamma\left(\frac{s+7}{2}\right)} {\Gamma\left(\frac72\right)}
}
\quad \cdots (34)
```

となる．
これが求める粘性係数である．

また，速度勾配に比例する補正はトレースレスなテンソルから生じるため，解答例と同じ近似では体積粘性係数は

```math
\boxed{
\kappa=0
}
\quad \cdots (35)
```

である．

## 4．熱伝導係数 $\lambda$ の導出

### 4.1　熱流ベクトル

熱流ベクトルは式(8)より，

```math
q_\mu=\frac m2\int c^2c_\mu f\,d^3c
\quad \cdots (36)
```

である．
局所平衡分布 $f_0$ からの熱流はゼロなので，式(36)において $f_1$ の温度勾配項だけを取り出す．
式(22)から，

```math
\begin{aligned}
q_\mu =-\frac{m}{2T}\sum_{\gamma} \int \tau(c)f_0c^2c_\mu c_\gamma \left(\frac{mc^2}{2kT}-\frac52\right)d^3c \frac{\partial T}{\partial x_\gamma}
\end{aligned}
\quad \cdots (37)
```

となる．

速度空間での等方性から，任意の $c$ だけの関数 $g(c)$ に対して

```math
\int c_\mu c_\gamma g(c)\,d^3c =\frac{\delta_{\mu\gamma}}3 \int c^2g(c)\,d^3c
\quad \cdots (38)
```

が成り立つ．
これは， $x,y,z$ の各方向が局所平衡状態では対等であるためである．

式(38)を用いて式(37)を整理すると，

```math
q_\mu =-\frac{m}{6T} \int \tau(c)f_0c^4 \left(\frac{mc^2}{2kT}-\frac{5}{2}\right)d^3c \frac{\partial T}{\partial x\_\mu}
\quad \cdots (39)
```

を得る．

Fourier の法則

```math
q_\mu=-\lambda\frac{\partial T}{\partial x_\mu}
\quad \cdots (40)
```

と比較すると，

```math
\boxed{
\lambda =\frac{m}{6T} \int \tau(c)f_0c^4 \left(\frac{mc^2}{2kT}-\frac{5}{2}\right)d^3c
}
\quad \cdots (41)
```

となる．同じ式は，

```math
\boxed{
\lambda =\frac{k}{3} \int \tau(c)f_0 \frac{mc^2}{2kT}c^2 \left(\frac{mc^2}{2kT}-\frac{5}{2}\right)d^3c
}
\quad \cdots (42)
```

とも表せる．

### 4.2　球座標による積分

式(42)に

```math
f_0=n\left(\frac{m}{2\pi kT}\right)^{3/2} e^{-mc^2/(2kT)},\qquad \tau(c)=Ac^s
```

を代入し， $d^3c=4\pi c^2dc$ で積分すると，

```math
\begin{aligned}
\lambda ={}&\frac{4\pi k}{3} An\left(\frac{m}{2\pi kT}\right)^{3/2} \\
&\times \int_0^\infty \frac{mc^{s+6}}{2kT} \left(\frac{mc^2}{2kT}-\frac{5}{2}\right) e^{-mc^2/(2kT)}\,dc
\end{aligned}
\quad \cdots (43)
```

を得る．

粘性係数の場合と同じく，

```math
\alpha=\frac{m}{2kT}
```

とおく．
すると，積分部分に現れる式は

```math
\begin{aligned}
&\int_0^\infty c^{s+6} \left(\alpha c^2-\frac52\right)e^{-\alpha c^2}\,dc \\
&\quad= \frac12\alpha^{-(s+7)/2} \left[ \Gamma\left(\frac{s+9}{2}\right) -\frac{5}{2}\Gamma\left(\frac{s+7}{2}\right) \right]
\end{aligned}
\quad \cdots (44)
```

と書ける．

ガンマ関数には

```math
\Gamma(z+1)=z\Gamma(z)
\quad \cdots (45)
```

という関係があるので，

```math
\Gamma\left(\frac{s+9}{2}\right) =\frac{s+7}{2} \Gamma\left(\frac{s+7}{2}\right)
```

である．
したがって式(44)は，

```math
\begin{aligned}
&\int_0^\infty c^{s+6} \left(\alpha c^2-\frac52\right)e^{-\alpha c^2}\,dc \\
&\quad= \frac{s+2}{4} \alpha^{-(s+7)/2} \Gamma\left(\frac{s+7}{2}\right)
\end{aligned}
\quad \cdots (46)
```

となる．

式(43)に式(46)を代入して整理すると，

```math
\boxed{
\lambda =Ank\left(\frac{2kT}{m}\right)^{1+s/2} \frac{s+2}{3\sqrt{\pi}} \Gamma\left(\frac{s+7}{2}\right)
}
\quad \cdots (47)
```

を得る．
これが求める熱伝導係数である．

## 5．粘性係数と熱伝導係数の比

単原子理想気体の定積比熱を単位質量当たりで表すと，

```math
\boxed{
c_V=\frac{3k}{2m}
}
\quad \cdots (48)
```

である．
式(34)および式(47)を割り算すると，共通因子が消えて，

```math
\begin{aligned}
\frac{\lambda}{\eta} &= \frac{ Ank\left(\dfrac{2kT}{m}\right)^{1+s/2} \dfrac{s+2}{3\sqrt{\pi}} \Gamma\left(\dfrac{s+7}{2}\right) }{ AnkT\left(\dfrac{2kT}{m}\right)^{s/2} \dfrac{\Gamma\left(\dfrac{s+7}{2}\right)} {\Gamma\left(\dfrac{7}{2}\right)} } \\
&=\frac{2k}{m}\frac{s+2}{3\sqrt{\pi}} \Gamma\left(\frac{7}{2}\right)
\end{aligned}
\quad \cdots (49)
```

となる．
ここで，

```math
\Gamma\left(\frac{7}{2}\right)=\frac{15\sqrt{\pi}}8
```

を代入すれば，

```math
\boxed{
\frac{\lambda}{\eta} =\frac{5(s+2)}4\frac{k}{m}
}
\quad \cdots (50)
```

を得る．
さらに式(48)を用いると，

```math
\begin{aligned}
\frac{\lambda}{\eta c_V} &=\frac{\dfrac{5(s+2)}4\dfrac{k}{m}} {\dfrac{3k}{2m}} \\
&=\boxed{\frac{5}{6}(s+2)}
\end{aligned}
\quad \cdots (51)
```

となる．
これは解答例の式(18)である．

## 6．特殊な場合

### 6.1　緩和時間が一定の場合 $s=0$

このとき，

```math
\tau=A
```

である．
式(34)から，

```math
\eta=AnkT
```

となる．
$p=nkT$ なので，

```math
\boxed{
\eta=pA
}
\quad \cdots (52)
```

である．
したがって，粘性係数は圧力と緩和時間の積に等しい．

一方，式(47)から，

```math
\begin{aligned}
\lambda &=Ank\frac{2kT}{m} \frac{2}{3\sqrt{\pi}} \Gamma\left(\frac{7}{2}\right) \\
&=\frac{5}{2}\frac{k}{m}AnkT
\end{aligned}
```

となる．
よって，

```math
\boxed{
\lambda=\frac{5}{2}\frac{k}{m}AnkT
}
\quad \cdots (53)
```

であり，比は

```math
\boxed{
\frac{\lambda}{\eta c_V}=\frac{5}{3}
}
\quad \cdots (54)
```

となる．

### 6.2　緩和時間が速度に反比例する場合 $s=-1$

このとき，

```math
\tau=\frac{A}{c}
```

である．
式(34)に $s=-1$ を代入すると，

```math
\begin{aligned}
\eta &=AnkT\left(\frac{2kT}{m}\right)^{-1/2} \frac{\Gamma(3)}{\Gamma(7/2)} \\
&=\frac{16}{15}An \sqrt{\frac{mkT}{2\pi}}
\end{aligned}
```

となる．
すなわち，

```math
\boxed{
\eta=\frac{16}{15}An\sqrt{\frac{mkT}{2\pi}}
}
\quad \cdots (55)
```

である．

同様に式(47)に $s=-1$ を代入すると，

```math
\begin{aligned}
\lambda &=Ank\left(\frac{2kT}{m}\right)^{1/2} \frac{1}{3\sqrt{\pi}}\Gamma(3) \\
&=\frac{2}{3} Ank\sqrt{\frac{2kT}{\pi m}}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\lambda=\frac{2}{3} Ank\sqrt{\frac{2kT}{\pi m}}
}
\quad \cdots (56)
```

である．
この場合には，

```math
\boxed{
\frac{\lambda}{\eta c_V}=\frac{5}{6}
}
\quad \cdots (57)
```

となる．

## 7．Chapman の式との違い

以上の結果は，緩和時間近似によって得られたものである．
一方，分子間の衝突をより詳細に扱う Boltzmann 方程式では，衝突積分をより正確に評価することによって，単原子気体について

```math
\boxed{
\frac{\lambda}{\eta c_V}=\frac{5}{2}
}
\quad \cdots (58)
```

という関係が得られる．
これを Chapman の式という．

例えば $s=0$ の緩和時間近似では式(54)の $5/3$ が得られるため，Chapman の式の $5/2$ とは異なる．
この差は，衝突過程の扱いが異なることに由来する．

## 8．適用条件についての注意

粘性係数と熱伝導係数を表す積分には，

```math
\int_0^\infty c^{s+6}e^{-mc^2/(2kT)}\,dc
```

が現れる．
$c\to0$ で積分が収束するためには，

```math
s+6>-1
```

が必要である．
したがって，輸送係数が有限になる条件は

```math
\boxed{
s>-7
}
\quad \cdots (59)
```

である．
問題文の $s>-9$ という指定の範囲内でも， $-9\<s\le -7$ では積分が収束しないため，有限の係数は得られない．
また，式(47)から熱伝導係数が正となるには $s>-2$ が必要である．
物理的に適切な範囲を考える際には，この点にも注意する必要がある．

さらに，厳密には，緩和時間が速度依存すると，単純な衝突項 $-(f-f_0)/\tau(c)$ は質量・運動量・エネルギーのモーメントを一般に保存しない．
したがって，保存則を厳密に成立させるには衝突項への追加の修正が必要となる．
ここでは，解答例と同じく，局所平衡での流体力学的方程式を用いる一次近似の導出を採用した．

## 最終結果

緩和時間 $\tau=Ac^s$ に対し，解答例と同様の方法で得られる粘性係数と熱伝導係数は，

```math
\boxed{
\eta =AnkT \left(\frac{2kT}{m}\right)^{s/2} \frac{\Gamma\left(\dfrac{s+7}{2}\right)} {\Gamma\left(\dfrac{7}{2}\right)}
}
```

```math
\boxed{
\lambda =Ank \left(\frac{2kT}{m}\right)^{1+s/2} \frac{s+2}{3\sqrt{\pi}} \Gamma\left(\frac{s+7}{2}\right)
}
```

であり，それらの比は，

```math
\boxed{
\frac{\lambda}{\eta c_V}=\frac{5}{6}(s+2)
}
```

となる．
また，この近似では体積粘性係数は $\kappa=0$ である．
積分が収束するためには $s>-7$ が必要であり，物理的に正の熱伝導係数を得るには，さらに $s>-2$ が必要である．
