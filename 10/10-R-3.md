# 演習問題【10-R-3】

## 解答

### 1．熱流と熱伝導率

金属中の電子を，一定の速さ $v$ で運動し，一定時間 $\tau$ ごとに等方的に散乱される粒子とみなす．
また，散乱直後の電子は，その散乱点における電子気体の内部エネルギー $u$ を持つと仮定する．
ここで $u$ は電子1個当たりの内部エネルギーである．

温度 $T$ が $z$ 方向に緩やかに変化している状況を考える．
$z=0$ の平面を単位面積当たり，単位時間当たりに通過する正味のエネルギーを熱流 $q$ とする．
熱伝導率 $\lambda$ は Fourier の法則

```math
q=-\lambda\frac{\partial T}{\partial z}
\tag{1}
```

によって定義される．
負の符号は，熱が温度の高い方から低い方へ流れることを表す．

### 2．散乱点における電子の内部エネルギー

電子が散乱されてから次の散乱までの時間を，この略算では $\tau$ と仮定する．
電子の速さは一定値 $v$ であるから，その間に移動する距離は

```math
\boxed{l=v\tau}
\tag{2}
```

となる．
この距離 $l$ を平均自由行程と呼ぶ．

次に， $z=0$ の平面を通過する電子の運動方向を考える．
その速度ベクトルと $+z$ 軸との角を $\theta$ と定義する．
電子の $z$ 方向の速度成分は $v\cos\theta$ である．

電子は，散乱後に時間 $\tau$ だけ運動して $z=0$ に到達したものと仮定するため，散乱点の $z$ 座標は

```math
z=-v\tau\cos\theta=-l\cos\theta
\tag{3}
```

である．
この式は， $\cos\theta>0$ の電子は $z<0$ 側から， $\cos\theta<0$ の電子は $z>0$ 側から平面に到達することを表す．

温度勾配は自由行程 $l$ の距離では十分に小さいとする．
したがって，散乱点での内部エネルギーを Taylor 展開すると，

```math
\begin{aligned}
u(-l\cos\theta)
&\simeq u(0)+(-l\cos\theta)
\left(\frac{\partial u}{\partial z}\right)_{z=0}\\
&=u(0)-l\cos\theta
\left(\frac{\partial u}{\partial z}\right)_{z=0}
\end{aligned}
\tag{4}
```

となる．
この近似では，温度勾配に比例する一次の項までを残している．

### 3．平面を通過する電子の正味のエネルギー流

散乱は等方的であるため，電子の運動方向は全立体角にわたって一様に分布する．
角度が $\theta$ から $\theta+d\theta$ の範囲にある確率は，

```math
dP=\frac{2\pi\sin\theta\,d\theta}{4\pi}
=\frac12\sin\theta\,d\theta
\tag{5}
```

となる．

電子数密度を $n$ とすると，この角度範囲に属する電子が $z=0$ の平面を通過する正味の粒子流束は，

```math
dJ_N=nv\cos\theta\,dP
=\frac12nv\cos\theta\sin\theta\,d\theta
\tag{6}
```

である．
ここで $dJ_N$ は符号付きの流束である．
すなわち， $\cos\theta>0$ の場合は $+z$ 方向への流束， $\cos\theta<0$ の場合は $-z$ 方向への流束を表す．

したがって，平面を通過する正味のエネルギー流は，式 (4) の内部エネルギーに式 (6) の粒子流束を掛け，すべての方向について積分することで求められる．

```math
\begin{aligned}
q
&=\int_0^\pi u(-l\cos\theta)\,dJ_N\\
&=\frac12nv\int_0^\pi
\left[
u(0)-l\cos\theta
\left(\frac{\partial u}{\partial z}\right)_{z=0}
\right]\cos\theta\sin\theta\,d\theta
\end{aligned}
\tag{7}
```

この積分の第一項は，

```math
\frac12nvu(0)\int_0^\pi\cos\theta\sin\theta\,d\theta=0
\tag{8}
```

となる．
これは，平衡エネルギー $u(0)$ を運ぶ電子が正負両方向に同じだけ流れ，正味の粒子流束がゼロになるためである．
したがって，熱流に寄与するのは，温度勾配による内部エネルギーの差の項だけである．

式 (7) は，

```math
q=-\frac12nvl
\left(\frac{\partial u}{\partial z}\right)_{z=0}
\int_0^\pi\cos^2\theta\sin\theta\,d\theta
\tag{9}
```

となる．
ここで，

```math
\begin{aligned}
\int_0^\pi\cos^2\theta\sin\theta\,d\theta
&=\int_{-1}^{1}w^2\,dw\\
&=\left[\frac{w^3}{3}\right]_{-1}^{1}
=\frac23
\end{aligned}
\tag{10}
```

である．
途中では $w=\cos\theta$ と置いた．
式 (10) を式 (9) に代入すると，

```math
\boxed{
q=-\frac13nvl\frac{\partial u}{\partial z}
}
\tag{11}
```

を得る．
これが，電子の内部エネルギーの空間勾配によって生じる熱流である．

### 4．熱伝導率の導出

まず，電子1個当たりの内部エネルギー $u$ が，局所的な温度 $T$ のみに依存すると近似する．
このとき，連鎖律より，

```math
\frac{\partial u}{\partial z}
=\frac{\partial u}{\partial T}\frac{\partial T}{\partial z}
\tag{12}
```

となる．
電子1個当たりの熱容量を $\partial u/\partial T$ とすれば，電子数密度 $n$ を掛けた

```math
\boxed{C=n\frac{\partial u}{\partial T}}
\tag{13}
```

は，単位体積当たりの熱容量である．

式 (12)，(13) を式 (11) に代入すると，

```math
q=-\frac13nvl
\frac{\partial u}{\partial T}
\frac{\partial T}{\partial z}
=-\frac13Cvl\frac{\partial T}{\partial z}
\tag{14}
```

となる．
これを Fourier の法則 (1) と比較すれば，

```math
\boxed{\lambda=\frac13Cvl}
\tag{15}
```

を得る．
したがって，この電子気体モデルでは，熱伝導率は単位体積当たりの熱容量 $C$ ，電子の速さ $v$ ，平均自由行程 $l$ の積の3分の1で与えられる．

### 5．熱容量の扱いに関する注意

式 (12) では，内部エネルギー $u$ が温度だけに依存すると仮定した．
しかし，一般には $u=u(n,T)$ のように，電子数密度 $n$ にも依存する可能性がある．
この場合には，

```math
\frac{\partial u}{\partial z}
=
\left(\frac{\partial u}{\partial T}\right)_n
\frac{\partial T}{\partial z}
+
\left(\frac{\partial u}{\partial n}\right)_T
\frac{\partial n}{\partial z}
\tag{16}
```

であるため，密度の空間変化も熱流に影響する．

したがって，式 (15) の $C$ を単純に $n(\partial u/\partial T)_n$ と解釈できるのは，密度一定の近似が成立する場合などである．
密度も温度とともに変化する場合には，その変化を含めた条件に沿って $du/dT$ を定義し，それに対応する有効な体積熱容量を用いる必要がある．

また，電子が正負両方向へ同じだけ流れることから，このモデルでは正味の電子流束はゼロになる．
しかし，正味の電流がゼロであることと，温度勾配のもとで密度も一定であることは同じではない．
解答例が指摘するように，圧力などの力学的条件を指定しなければ， $u$ の温度依存性を一意に決められない場合がある．

以上の注意点を踏まえ，電子の内部エネルギーの勾配を温度勾配に比例する量として扱える範囲では，

```math
\boxed{\lambda=\frac13Cvl}
```

が求める熱伝導率の略算式である．
