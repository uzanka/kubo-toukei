# 例題【10-R-3】

## 解答

### 1．モデルの前提と熱流の定義

金属中の電子気体に対して，問題文の仮定を次のように解釈する．

1. すべての電子の輸送速度の大きさを一定値 $v$ とする．
2. 各電子は厳密に一定時間 $\tau$ ごとに散乱され，散乱後の運動方向は等方的に分布する．
3. 散乱直後の電子には，散乱点における局所的な電子気体の内部エネルギー $u$ が割り当てられる．

さらに，次の条件を明示的に仮定する．

- 電子集団は定常状態にある．
- 各電子の散乱周期の位相は一様に分布している．
- 散乱後の運動方向は，散乱周期の位相や過去の運動履歴に依存せず，独立に等方的に選ばれる．
- 散乱と散乱の間では外力による加速がなく，電子は等速直線運動する．
- 電子数密度 $n$ は空間的に一定であり，巨視的な電子のドリフト速度はゼロである．
- 温度勾配は $z$ 方向だけに存在する．
- 表面や境界から十分離れたバルク領域を対象とし，境界散乱の影響は無視する．

なお，ここでの $v$ は電子の輸送を記述する代表速度であり， $u$ は散乱点の局所状態に応じて電子に割り当てられる熱輸送エネルギーである．
この現象論的モデルでは， $u$ を固定された速度 $v$ に対応する並進運動エネルギー $\frac12mv^2$ と同一視しない．

もし $u$ を文字どおり電子の並進運動エネルギーと解釈し，すべての電子の速さを厳密に一定とするならば， $u$ も一定となり，温度依存性を持つ熱輸送モデルとは整合しない．

$z=0$ の平面を単位面積当たり，単位時間当たりに通過する正味のエネルギーを $q$ と定義する．
このモデルでは，正味の粒子流束がゼロであるため，正味のエネルギー流を熱流として扱うことができる．

熱伝導率 $\lambda$ は Fourier の法則

```math
q=-\lambda\frac{\partial T}{\partial z}
\tag{1}
```

によって定義される．

### 2．平均自由行程と散乱後の経過時間

各電子は散乱から次の散乱までの時間 $\tau$ を運動する．
速さが一定値 $v$ であるため，散乱間の移動距離は

```math
\boxed{l=v\tau}
\tag{2}
```

である．
この距離を平均自由行程とする．

ただし，任意の時刻に平面を通過する電子が，最後の散乱から必ず時間 $\tau$ 経過しているわけではない．

各電子の散乱周期の位相が一様に分布している定常状態では，最後の散乱から平面通過までの経過時間を $s$ とすると，

```math
0\leq s<\tau
```

であり，その確率密度は

```math
p(s)=\frac1\tau
\qquad (0\leq s<\tau)
\tag{3}
```

となる．

この分布は，

```math
\int_0^\tau p(s)\,ds
=\frac1\tau\int_0^\tau ds
=1
```

を満たしている．

したがって，平均経過時間は

```math
\begin{aligned}
\langle s\rangle
&=\int_0^\tau s\,p(s)\,ds\\
&=\frac1\tau\int_0^\tau s\,ds\\
&=\frac1\tau\left[\frac{s^2}{2}\right]_0^\tau\\
&=\frac{\tau}{2}.
\end{aligned}
```

よって，

```math
\boxed{\langle s\rangle=\frac{\tau}{2}}
\tag{4}
```

である．

また，平面通過時の方向別の粒子流束は，速度の法線成分の絶対値に比例する．
しかし，その重みは $s$ に依存しない．
したがって，経過時間と方向が独立であれば，平面通過電子についても経過時間の確率密度は $p(s)=1/\tau$ のままである．

実際，平面通過数の重みは

```math
|v\cos\theta|\,p(s)\,dP\,ds
```

と因数分解されるため，角度について積分して規格化しても，経過時間の分布は変化しない．

ここで重要なのは，散乱間の移動距離 $l=v\tau$ と，平面通過時における最後の散乱点からの平均距離 $v\langle s\rangle=l/2$ は異なることである．

### 3．散乱点における内部エネルギー

$z=0$ の平面を通過する電子の速度ベクトルと $+z$ 軸との角度を $\theta$ とする．

この電子の速度の $z$ 成分は

```math
v_z=v\cos\theta
```

である．

最後の散乱から時間 $s$ だけ経過して平面に到達した電子の散乱点の座標は，

```math
\boxed{z=-vs\cos\theta}
\tag{5}
```

となる．

温度勾配は平均自由行程に比べて十分緩やかであると仮定する．
内部エネルギーの空間変化の代表的な長さ尺度を $L_u$ とすれば，

```math
l\ll L_u
```

である．

散乱点における内部エネルギーを $z=0$ の近傍で Taylor 展開すると，

```math
\begin{aligned}
u(-vs\cos\theta)
&=u(0)-vs\cos\theta
\left(\frac{\partial u}{\partial z}\right)_{z=0}\\
&\quad+\frac{v^2s^2\cos^2\theta}{2}
\left(\frac{\partial^2u}{\partial z^2}\right)_{z=0}
+\cdots.
\end{aligned}
```

一次の項まで残せば，

```math
\boxed{
u(-vs\cos\theta)
\simeq
u(0)-vs\cos\theta
\left(\frac{\partial u}{\partial z}\right)_{z=0}
}
\tag{6}
```

となる．

### 4．等方的な方向分布と粒子流束

散乱後の運動方向は等方的に分布するため，速度方向が立体角 $d\Omega$ に含まれる確率は

```math
dP=\frac{d\Omega}{4\pi}
```

である．

方位角を積分すると，

```math
\begin{aligned}
dP
&=\frac{2\pi\sin\theta\,d\theta}{4\pi}\\
&=\frac12\sin\theta\,d\theta.
\end{aligned}
\tag{7}
```

ここで $dP$ は速度方向の確率であり，平面を通過する粒子数の割合そのものではない．
平面を横切る粒子数を計算するには，法線方向速度成分を掛ける必要がある．

最後の散乱からの経過時間が $s$ から $s+ds$ の範囲にあり，方向が $\theta$ から $\theta+d\theta$ の範囲にある電子の符号付き粒子流束は，

```math
\begin{aligned}
dJ_N
&=nv\cos\theta\,p(s)\,ds\,dP\\
&=\frac{nv}{2\tau}
\cos\theta\sin\theta\,d\theta\,ds.
\end{aligned}
\tag{8}
```

ここで $n$ は電子数密度である．

$\cos\theta>0$ は $+z$ 方向への流束を表し， $\cos\theta<0$ は $-z$ 方向への流束を表す．

正味の粒子流束は，

```math
\begin{aligned}
J_N
&=nv\int_0^\tau p(s)\,ds
\int_0^\pi\cos\theta
\frac12\sin\theta\,d\theta\\
&=\frac{nv}{2\tau}
\int_0^\tau ds
\int_0^\pi\cos\theta\sin\theta\,d\theta\\
&=0.
\end{aligned}
\tag{9}
```

したがって，このモデルでは正味の電子流束はゼロである．

### 5．平面を通過する正味のエネルギー流

平面を通過する電子は，最後に散乱された位置の内部エネルギーを運ぶ．

したがって，正味のエネルギー流は，

```math
\boxed{
q=
nv\int_0^\tau p(s)\,ds
\int_0^\pi
u(-vs\cos\theta)\cos\theta
\frac12\sin\theta\,d\theta
}
```

である．

ここでは，角度分布の確率要素

```math
dP=\frac12\sin\theta\,d\theta
```

を一度だけ用いている．
したがって，角度の微分要素 $d\theta$ が二重に計上されることはない．

式 (3)，(6) を代入すると，

```math
\begin{aligned}
q
&=\frac{nv}{2\tau}
\int_0^\tau ds
\int_0^\pi
\left[
u(0)-vs\cos\theta
\left(\frac{\partial u}{\partial z}\right)_{z=0}
\right]\\
&\qquad\qquad\times
\cos\theta\sin\theta\,d\theta.
\end{aligned}
\tag{10}
```

まず， $u(0)$ を含む項は，

```math
\begin{aligned}
&\frac{nv}{2\tau}u(0)
\int_0^\tau ds
\int_0^\pi
\cos\theta\sin\theta\,d\theta\\
&=0.
\end{aligned}
\tag{11}
```

これは，等方的な方向分布により，正方向と負方向の粒子流束が相殺されるためである．

したがって，温度勾配に起因する項だけが残り，

```math
q
=-\frac{nv^2}{2\tau}
\left(\frac{\partial u}{\partial z}\right)_{z=0}
\int_0^\tau s\,ds
\int_0^\pi
\cos^2\theta\sin\theta\,d\theta.
\tag{12}
```

時間積分は，

```math
\begin{aligned}
\int_0^\tau s\,ds
&=\left[\frac{s^2}{2}\right]_0^\tau\\
&=\frac{\tau^2}{2}.
\end{aligned}
\tag{13}
```

また，角度積分は，

```math
\begin{aligned}
\int_0^\pi\cos^2\theta\sin\theta\,d\theta
&=-\int_1^{-1}w^2\,dw\\
&=\int_{-1}^{1}w^2\,dw\\
&=\left[\frac{w^3}{3}\right]_{-1}^{1}\\
&=\frac23.
\end{aligned}
\tag{14}
```

ただし， $w=\cos\theta$ と置いた．

式 (13)，(14) を式 (12) に代入すると，

```math
\begin{aligned}
q
&=-\frac{nv^2}{2\tau}
\left(\frac{\partial u}{\partial z}\right)_{z=0}
\frac{\tau^2}{2}\cdot\frac23\\
&=-\frac16nv^2\tau
\left(\frac{\partial u}{\partial z}\right)_{z=0}.
\end{aligned}
```

ここで $l=v\tau$ であるから，

```math
\boxed{
q=-\frac16nvl\frac{\partial u}{\partial z}
}
\tag{15}
```

を得る．

これが，厳密に一定時間 $\tau$ ごとに散乱される定常モデルにおける正味のエネルギー流である．

### 6．熱伝導率の導出

電子1個当たりの内部エネルギー $u$ が，局所温度 $T$ と数密度 $n$ の関数であるとする．

この問題では数密度一定を仮定しているので，

```math
u=u(T;n=\mathrm{const.})
```

と書ける．

したがって，連鎖律より，

```math
\frac{\partial u}{\partial z}
=
\left(\frac{\partial u}{\partial T}\right)_n
\frac{\partial T}{\partial z}.
\tag{16}
```

電子1個当たりの数密度一定での熱容量を

```math
c_e=
\left(\frac{\partial u}{\partial T}\right)_n
```

と定義する．

数密度 $n$ を掛けた

```math
\boxed{
C=n\left(\frac{\partial u}{\partial T}\right)_n
}
\tag{17}
```

は，単位体積当たりの電子の熱容量である．

式 (16)，(17) を式 (15) に代入すると，

```math
\begin{aligned}
q
&=-\frac16nvl
\left(\frac{\partial u}{\partial T}\right)_n
\frac{\partial T}{\partial z}\\
&=-\frac16Cvl\frac{\partial T}{\partial z}.
\end{aligned}
\tag{18}
```

Fourier の法則

```math
q=-\lambda\frac{\partial T}{\partial z}
```

と比較すれば，

```math
\boxed{
\lambda=\frac16Cvl
}
\tag{19}
```

を得る．

したがって，問題文の b) を厳密な周期散乱として解釈した定常モデルでは，熱伝導率は

```math
\boxed{\lambda=\frac16Cvl}
```

で与えられる．

### 7．密度が変化する場合の注意

これまでは数密度 $n$ を一定とした．しかし，一般には電子1個当たりの内部エネルギーは

```math
u=u(n,T)
```

と書かれる．

この場合，空間微分は，

```math
\boxed{
\frac{\partial u}{\partial z}
=
\left(\frac{\partial u}{\partial T}\right)_n
\frac{\partial T}{\partial z}
+
\left(\frac{\partial u}{\partial n}\right)_T
\frac{\partial n}{\partial z}
}
\tag{20}
```

となる．

したがって，密度勾配がある場合には，温度勾配だけでなく密度勾配も内部エネルギーの空間変化に影響する．

また，内部エネルギー密度は

```math
e=nu
```

であるため，密度が温度に依存する経路に沿った微分は，

```math
\frac{de}{dT}
=
u\frac{dn}{dT}
+n\frac{du}{dT}
\tag{21}
```

である．

さらに，

```math
\frac{du}{dT}
=
\left(\frac{\partial u}{\partial T}\right)_n
+
\left(\frac{\partial u}{\partial n}\right)_T
\frac{dn}{dT}
\tag{22}
```

となる．

よって，一般に

```math
\frac{de}{dT}
\neq
n\frac{du}{dT}
```

である．

すなわち，数密度が変化する場合には，電子1個当たりの内部エネルギーの変化と，単位体積当たりの内部エネルギーの変化を区別しなければならない．

また，密度勾配がある場合には粒子流束や方向分布も変化し得るため，式 (19) に単純に有効熱容量を代入すればよいとは限らない．
粒子輸送とエネルギー輸送を同時に扱う必要がある．

したがって，式 (19) は数密度一定の条件で用いる．

### 8．熱流とエネルギー保存に関する注意

このモデルでは，式 (9) に示したように正味の粒子流束がゼロである．

したがって，電子1個当たりのエネルギーの基準を一定量 $u_0$ だけ変更して

```math
u\longrightarrow u+u_0
```

としても，エネルギー流の変化は

```math
\Delta q=u_0J_N=0
```

である．

よって，このモデルでは正味のエネルギー流はエネルギーの基準の取り方に依存せず，熱流として扱うことができる．

ただし，仮定 c) では，散乱直後に電子のエネルギーが散乱点の局所値へ更新される．
そのため，散乱前後で電子のエネルギーが変化する場合には，その差に対応するエネルギー交換の相手を考える必要がある．

例えば，格子との相互作用によってエネルギーが交換されるならば，電子が受け取るエネルギーと格子が失うエネルギーは，符号が反対になる．電子系だけでなく，エネルギー交換の相手も含めて考えることで，全体系のエネルギー保存が成立する．

通常の不純物による電子散乱は弾性散乱であり，運動方向を変えても電子のエネルギーを局所的な内部エネルギーに更新するとは限らない．
したがって，仮定 c) は不純物による弾性散乱そのものから導かれる性質ではなく，局所的なエネルギー緩和を含む独立した現象論的仮定である．

この略算モデルは熱流を見積もるモデルであり，微視的な散乱機構やエネルギー交換の詳細まで導出するものではない．

### 9．係数 $1/3$ が得られる別の散乱モデル

なお，標準的な緩和時間近似で用いられるように，散乱がポアソン過程に従い， $\tau$ を平均散乱時間と解釈する場合には結果が異なる．

この場合，最後の散乱からの経過時間 $s$ の確率密度は，

```math
p(s)=\frac1\tau e^{-s/\tau}
\qquad (s\geq0)
```

である．

その平均経過時間は，

```math
\begin{aligned}
\langle s\rangle
&=\int_0^\infty s\frac1\tau e^{-s/\tau}\,ds\\
&=\tau.
\end{aligned}
```

一般に，散乱後の経過時間と方向が独立であり，その平均経過時間を $\langle s\rangle$ とすると，

```math
q=-\frac13nv^2\langle s\rangle
\frac{\partial u}{\partial z}
```

となる．

したがって，ポアソン型散乱モデルでは，

```math
q=-\frac13nv^2\tau
\frac{\partial u}{\partial z}
```

となり，数密度一定の条件で，

```math
\boxed{\lambda=\frac13Cvl}
```

が得られる．

一方，厳密な周期散乱モデルでは，

```math
\langle s\rangle=\frac{\tau}{2}
```

であるため，

```math
\boxed{\lambda=\frac16Cvl}
```

となる．

つまり，係数 $1/3$ と $1/6$ の違いは，角度積分の違いではなく，最後の散乱から平面通過までの平均経過時間の違いによる．

したがって，問題文の b) を文字どおり厳密な周期散乱として採用する場合の結果は，

```math
\boxed{\lambda=\frac16Cvl}
```

である．
