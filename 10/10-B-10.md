# 演習問題【10-B-10】

## 解答

### 張られた弦の熱ゆらぎ

#### 1．弦の変位を Fourier 級数で表す

長さ $L$ の弦が両端で固定されており，張力 $F$ が一定であるとする．
平衡状態からの弦の垂直方向の変位を $\xi(x)$ とする．
弦のふれは十分に小さいものとする．
両端は固定されているため，

```math
\xi(0)=\xi(L)=0
\tag{1}
```

である．

この境界条件を満たすように，変位を Fourier 級数で展開する．

```math
\boxed{
\xi(x)=\sum_{n=1}^{\infty}
A_n\sqrt{\frac{2}{L}}
\sin\left(\frac{n\pi x}{L}\right)
}
\tag{2}
```

ここで， $A_n$ は $n$ 番目の振動モードの振幅を表す展開係数である．
両端ではすべての正弦関数がゼロになるため，式 (2) は固定端の条件を自動的に満たす．
また，係数 $\sqrt{2/L}$ は正弦関数を規格化するために導入したものである．

#### 2．弦の弾性エネルギーを求める

弦が平衡位置から変位すると，張力に逆らって弦を伸ばす仕事が必要となる．
変位が小さい場合，弦の弾性エネルギー $\Phi$ は，

```math
\boxed{
\Phi=\frac{F}{2}\int_0^L
\left(\frac{d\xi}{dx}\right)^2dx
}
\tag{3}
```

と表される．
これは，小さな変位に対して，弦の伸びが弦の傾きの二乗に比例することから得られる式である．

式 (2) を $x$ で微分すると，

```math
\frac{d\xi}{dx}
=\sum_{n=1}^{\infty}
A_n\sqrt{\frac{2}{L}}
\frac{n\pi}{L}
\cos\left(\frac{n\pi x}{L}\right)
\tag{4}
```

となる．
これを式 (3) に代入すると，

```math
\begin{aligned}
\Phi
={}&\frac{F}{2}\sum_{n,n'=1}^{\infty}
A_nA_{n'}\frac{2}{L}
\frac{n\pi}{L}\frac{n'\pi}{L}\\
&\qquad\times
\int_0^L
\cos\left(\frac{n\pi x}{L}\right)
\cos\left(\frac{n'\pi x}{L}\right)dx
\end{aligned}
\tag{5}
```

を得る．

ここで，余弦関数の直交性

```math
\int_0^L
\cos\left(\frac{n\pi x}{L}\right)
\cos\left(\frac{n'\pi x}{L}\right)dx
=\frac{L}{2}\delta_{nn'}
\tag{6}
```

を用いる．
$\delta_{nn'}$ は， $n=n'$ のとき1，それ以外では0となる Kronecker のデルタである．
この直交性により，異なるモード間の交差項が消え，

```math
\boxed{
\Phi=\frac{F}{2}\sum_{n=1}^{\infty}
A_n^2\left(\frac{n\pi}{L}\right)^2
}
\tag{7}
```

となる．
つまり，弦のエネルギーは各モードの振幅 $A_n$ の二乗の和に分離される．

#### 3．Boltzmann 分布から各モードのゆらぎを求める

温度 $T$ の熱平衡では，エネルギー $\Phi$ をもつ弦の形が現れる確率は，Boltzmann 因子

```math
e^{-\Phi/(kT)}
\tag{8}
```

に比例する．
ここで $k$ は Boltzmann 定数である．
式 (7) を代入すると，

```math
e^{-\Phi/(kT)}
=\prod_{n=1}^{\infty}
\exp\left[
-\frac{F}{2kT}
\left(\frac{n\pi}{L}\right)^2A_n^2
\right]
\tag{9}
```

となる．
この式は $A_n$ ごとの因子の積であるため，各 Fourier 係数は互いに独立な Gaussian 分布に従う．

ここで，平均値からのずれ $y$ に関する Gaussian 分布

```math
P(y)\propto e^{-ay^2/2}
```

では，

```math
\overline{y}=0,\qquad
\overline{y^2}=\frac1a
\tag{10}
```

である．
式 (9) と比較すると， $A_n$ に対応する係数は

```math
a_n=\frac{F}{kT}\left(\frac{n\pi}{L}\right)^2
\tag{11}
```

となる．
したがって，

```math
\boxed{
\overline{A_n}=0,\qquad
\overline{A_n^2}
=\frac{kT}{F}\left(\frac{L}{n\pi}\right)^2
}
\tag{12}
```

を得る．
また，異なるモードの分布が独立であり，各 $A_n$ の平均がゼロであることから，

```math
\boxed{
\overline{A_nA_{n'}}
=\delta_{nn'}\frac{kT}{F}
\left(\frac{L}{n\pi}\right)^2
}
\tag{13}
```

となる．
これが，変位のゆらぎを求めるために必要な関係式である．

#### 4．各点における平均二乗変位を求める

式 (2) から，

```math
\begin{aligned}
\overline{\xi^2(x)}
={}&
\overline{
\left[
\sum_{n=1}^{\infty}
A_n\sqrt{\frac{2}{L}}
\sin\left(\frac{n\pi x}{L}\right)
\right]^2
}\\
={}&\frac{2}{L}
\sum_{n,n'=1}^{\infty}
\overline{A_nA_{n'}}
\sin\left(\frac{n\pi x}{L}\right)
\sin\left(\frac{n'\pi x}{L}\right)
\end{aligned}
\tag{14}
```

となる．
式 (13) を代入すると， $n\ne n'$ の項はすべて消えるため，

```math
\begin{aligned}
\overline{\xi^2(x)}
&=\frac{2}{L}\sum_{n=1}^{\infty}
\frac{kT}{F}\left(\frac{L}{n\pi}\right)^2
\sin^2\left(\frac{n\pi x}{L}\right)\\
&=\frac{2kTL}{F\pi^2}
\sum_{n=1}^{\infty}
\frac{\sin^2(n\pi x/L)}{n^2}
\end{aligned}
\tag{15}
```

を得る．

最後に，この Fourier 級数を評価する．
$0\leq y\leq1$ に対して，

```math
\sum_{n=1}^{\infty}
\frac{\cos(2n\pi y)}{n^2}
=\pi^2\left(y^2-y+\frac16\right)
\tag{16}
```

および

```math
\sum_{n=1}^{\infty}\frac1{n^2}
=\frac{\pi^2}{6}
\tag{17}
```

が成り立つ．
ここで，

```math
\sin^2(n\pi y)=\frac{1-\cos(2n\pi y)}2
```

を用いると，

```math
\begin{aligned}
\sum_{n=1}^{\infty}
\frac{\sin^2(n\pi y)}{n^2}
&=\frac12\left[
\sum_{n=1}^{\infty}\frac1{n^2}
-\sum_{n=1}^{\infty}
\frac{\cos(2n\pi y)}{n^2}
\right]\\
&=\frac{\pi^2}{2}y(1-y)
\end{aligned}
\tag{18}
```

となる．
ここで $y=x/L$ とおけば，

```math
\boxed{
\sum_{n=1}^{\infty}
\frac{\sin^2(n\pi x/L)}{n^2}
=\frac{\pi^2}{2}
\frac{x}{L}\left(1-\frac{x}{L}\right)
}
\tag{19}
```

を得る．
これを式 (15) に代入して整理すると，

```math
\begin{aligned}
\overline{\xi^2(x)}
&=\frac{2kTL}{F\pi^2}
\frac{\pi^2}{2}
\frac{x}{L}\left(1-\frac{x}{L}\right)\\
&=\frac{kT}{FL}x(L-x)
\end{aligned}
```

となる．
したがって，求める平均二乗変位は，

```math
\boxed{
\overline{\xi^2(x)}=\frac{kT}{FL}x(L-x)
}
\tag{20}
```

である．

#### 5．結果の物理的意味

対称な平衡状態では，弦が上向きに変位する場合と下向きに変位する場合が同じ確率で起こる．
そのため，

```math
\overline{\xi(x)}=0
```

である．
一方，ゆらぎの大きさを表す平均二乗変位 $\overline{\xi^2(x)}$ は，一般にゼロではない．
式 (20) は，この平均二乗変位を与えている．

この式から，両端 $x=0,L$ では，

```math
\overline{\xi^2(0)}=\overline{\xi^2(L)}=0
```

となることが分かる．
固定端では変位そのものがゼロなので，ゆらぎも生じない．
また，式 (20) は $x=L/2$ で最大となり，

```math
\boxed{
\overline{\xi^2(L/2)}=\frac{kTL}{4F}
}
\tag{21}
```

である．
したがって，弦の中央でゆらぎが最も大きくなる．

さらに，温度 $T$ が高いほど熱ゆらぎは大きくなり，張力 $F$ が大きいほど弦が変形しにくくなってゆらぎは小さくなる．
以上より，Fourier 展開，弾性エネルギー，Boltzmann 分布を組み合わせることで，弦の各点における熱ゆらぎを求めることができたのである．
