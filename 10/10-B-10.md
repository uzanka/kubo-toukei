# 演習問題【10-B-10】

## 解答

### 弦の横変位の熱ゆらぎ

長さ $L$ ，張力 $F$ の弦を考え，両端を固定する．
弦の横変位を $\xi(x)$ とし，境界条件は

```math
\xi(0)=\xi(L)=0
```

である．

古典的な連続弦モデルでは，高波数モードまで無制限に含めると傾きの二乗平均が発散する．
そこで，まず最大モード数を $N$ として計算する．

#### 1．モード展開と弦のエネルギー

変位を正規直交関数で展開する：

```math
\xi_N(x)=\sum_{n=1}^{N}A_n\varphi_n(x),
\qquad
\varphi_n(x)=\sqrt{\frac{2}{L}}
\sin\frac{n\pi x}{L}.
```

ここで $A_n$ は各モードの振幅である．
正規直交性より，

```math
\int_0^L\varphi_n(x)\varphi_m(x)\,dx
=\delta_{nm}
```

が成り立つ．
また，

```math
\int_0^L\varphi_n'(x)\varphi_m'(x)\,dx
=\left(\frac{n\pi}{L}\right)^2\delta_{nm}
```

である．

弦の傾きが十分小さい場合，

```math
\left|\frac{\partial \xi_N}{\partial x}\right|\ll1
```

と仮定できる．
このとき，変位した弦の長さの増分は

```math
\begin{aligned}
\Delta L
&=\int_0^L
\left[
\sqrt{1+\left(\frac{\partial \xi_N}{\partial x}\right)^2}
-1
\right]dx\\
&\simeq
\frac12\int_0^L
\left(\frac{\partial \xi_N}{\partial x}\right)^2dx
\end{aligned}
```

となる．
張力 $F$ に逆らって弦を伸ばす仕事が弾性エネルギーの増分なので，

```math
\Phi_N
=\frac{F}{2}\int_0^L
\left(\frac{\partial \xi_N}{\partial x}\right)^2dx.
```

モード展開と直交性を用いると，

```math
\boxed{
\Phi_N
=\frac{F}{2}\sum_{n=1}^{N}
A_n^2\left(\frac{n\pi}{L}\right)^2
}
```

を得る．

#### 2．各モードの熱平衡分布

温度を $T$ とすると，カノニカル分布における振幅の確率密度は

```math
P_N(A_1,\ldots,A_N)
\propto
\exp\left(-\frac{\Phi_N}{k_{\mathrm B}T}\right)
```

である．
したがって，

```math
P_N(A_1,\ldots,A_N)
\propto
\prod_{n=1}^{N}
\exp\left[
-\frac{F}{2k_{\mathrm B}T}
\left(\frac{n\pi}{L}\right)^2 A_n^2
\right].
```

この分布は各 $A_n$ について独立なガウス分布の積である．
よって，

```math
\overline{A_n}=0
```

および

```math
\overline{A_nA_m}
=\delta_{nm}\frac{k_{\mathrm B}T}{F}
\left(\frac{L}{n\pi}\right)^2
```

となる．
ここで，上線は熱平衡アンサンブル平均を表す．

なお，弦の運動エネルギーを含めても，速度自由度を積分した結果は振幅 $A_n$ に依存しない規格化因子となるため，上記の振幅分布は変わらない．

#### 3．平均変位と平均二乗変位

まず，平均変位は

```math
\begin{aligned}
\overline{\xi_N(x)}
&=\sum_{n=1}^{N}\overline{A_n}\varphi_n(x)\\
&=0
\end{aligned}
```

である．
したがって，

```math
\boxed{\overline{\xi_N(x)}=0}
```

となる．

一方，平均二乗変位は

```math
\overline{\xi_N^2(x)}
=\sum_{n=1}^{N}\sum_{m=1}^{N}
\overline{A_nA_m}\varphi_n(x)\varphi_m(x)
```

である．
モード間の相関が

```math
\overline{A_nA_m}=0
\qquad(n\ne m)
```

であることから，

```math
\begin{aligned}
\overline{\xi_N^2(x)}
&=\sum_{n=1}^{N}
\overline{A_n^2}\varphi_n^2(x)\\
&=\sum_{n=1}^{N}
\frac{k_{\mathrm B}T}{F}
\left(\frac{L}{n\pi}\right)^2
\frac{2}{L}
\sin^2\frac{n\pi x}{L}.
\end{aligned}
```

したがって，

```math
\boxed{
\overline{\xi_N^2(x)}
=\frac{2k_{\mathrm B}TL}{F\pi^2}
\sum_{n=1}^{N}
\frac{\sin^2(n\pi x/L)}{n^2}
}
```

を得る．
これは有限個のモードを含む場合の平均二乗変位である．

#### 4．連続弦の級数極限

数学的な連続弦の極限として $N\to\infty$ とすると，次の級数公式

```math
\sum_{n=1}^{\infty}
\frac{\sin^2(n\pi y)}{n^2}
=\frac{\pi^2}{2}y(1-y),
\qquad 0\le y\le1
```

を用いることができる．

ここで $y=x/L$ とおけば，

```math
\begin{aligned}
\lim_{N\to\infty}\overline{\xi_N^2(x)}
&=\frac{2k_{\mathrm B}TL}{F\pi^2}
\frac{\pi^2}{2}
\frac{x}{L}\left(1-\frac{x}{L}\right)\\
&=\frac{k_{\mathrm B}T}{FL}x(L-x).
\end{aligned}
```

したがって，連続弦の調和近似で得られる平均二乗変位は

```math
\boxed{
\overline{\xi^2(x)}
=\frac{k_{\mathrm B}T}{FL}x(L-x)
}
```

である．
この式から，二乗平均平方根は

```math
\boxed{
\sqrt{\overline{\xi^2(x)}}
=\sqrt{\frac{k_{\mathrm B}T}{FL}x(L-x)}
}
```

となる．

特に弦の中央 $x=L/2$ では，

```math
\boxed{
\overline{\xi^2(L/2)}
=\frac{k_{\mathrm B}TL}{4F}
}
```

であり，二乗平均平方根は

```math
\boxed{
\sqrt{\overline{\xi^2(L/2)}}
=\frac12\sqrt{\frac{k_{\mathrm B}TL}{F}}
}
```

である．

#### 5．小傾斜近似と高波数カットオフの整合性

上で用いた小傾斜近似が妥当であるためには，熱平衡における傾きの二乗平均が十分小さい必要がある．
有限モード数 $N$ について，

```math
\begin{aligned}
\overline{
\left(\frac{\partial \xi_N}{\partial x}\right)^2
}
&=\sum_{n=1}^{N}
\overline{A_n^2}
\left(\frac{2}{L}\right)
\left(\frac{n\pi}{L}\right)^2
\cos^2\frac{n\pi x}{L}\\
&=\frac{2k_{\mathrm B}T}{FL}
\sum_{n=1}^{N}
\cos^2\frac{n\pi x}{L}\\
&\leq\frac{2Nk_{\mathrm B}T}{FL}.
\end{aligned}
```

したがって，小傾斜近似が典型的な熱ゆらぎに対して成り立つための十分条件は，

```math
\boxed{
\frac{2Nk_{\mathrm B}T}{FL}\ll1
}
```

である．
一方，無限和による結果を有限モード数で近似するには $N\gg1$ が必要である．
よって，両方の条件を満たす範囲として，

```math
\boxed{
1\ll N\ll\frac{FL}{2k_{\mathrm B}T}
}
```

が考えられる．
この範囲が存在するには，少なくとも $FL\gg k_{\mathrm B}T$ であることが必要となる．

なお，有限 $N$ の平均二乗変位と無限和の結果との差は，

```math
\begin{aligned}
0
&\leq
\frac{k_{\mathrm B}T}{FL}x(L-x)
-\overline{\xi_N^2(x)}\\
&\leq
\frac{2k_{\mathrm B}TL}{F\pi^2}
\sum_{n>N}\frac{1}{n^2}\\
&\leq
\frac{2k_{\mathrm B}TL}{F\pi^2N}
\end{aligned}
```

と評価できる．
したがって，大きな $N$ では有限モード数の結果は上記の連続弦の式に近づく．

ただし，固定した $F,L,T$ のもとで $N\to\infty$ とすると傾きの二乗平均は発散する．
また，各モードの平均ポテンシャルエネルギーは $k_{\mathrm B}T/2$ であり，その総和は発散する．
運動エネルギーも含めると，各モードの平均運動エネルギーも $k_{\mathrm B}T/2$ であるため，各モードの平均全エネルギーは $k_{\mathrm B}T$ となり，その総和も発散する．

したがって，無限個の古典モードを含む連続弦を，小傾斜近似が全モードで妥当な物理モデルと解釈してはならない．
上の無限和の式は，調和近似における数学的な連続弦極限の結果であり，実際の弦では微視的な長さに対応する高波数カットオフを考慮する必要がある．

以上より，平均変位はゼロである一方，平均二乗変位は

```math
\boxed{
\overline{\xi^2(x)}
=\frac{k_{\mathrm B}T}{FL}x(L-x)
}
```

となる．
