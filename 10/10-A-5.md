# 演習問題【10-A-5】

## 解答

### 1．流れと分子運動の設定

気体の平均流速を $x$ 方向とし，その大きさが $z$ のみの関数であるとする．
すなわち，

```math
\boldsymbol V(z)=V(z)\boldsymbol e_x
```

とする．
分子の質量を $m$ ，数密度を $n$ ，熱運動の速さを $v$ ，衝突間隔を $\tau$ とする．

問題の仮定 a）より，熱運動の速さは一定である．
仮定 b）より，衝突後の熱運動の方向は等方的に分布する．
仮定 c）より，衝突直後の分子の平均速度は，衝突位置での気体の流速に等しい．
したがって，衝突直後の分子の速度は

```math
\boldsymbol v_{\mathrm{total}}
=
\boldsymbol V(z')+\boldsymbol v_{\mathrm{th}}
```

と表される．
ここで， $z'$ は衝突位置の $z$ 座標であり，

```math
|\boldsymbol v_{\mathrm{th}}|=v
```

である．

一回の自由飛行で分子が進む代表的な距離を平均自由行程 $l$ とすると，

```math
l=v\tau
```

である．

以下では，数密度 $n$ は一様であり，考えている領域は壁面などの境界から十分離れた気体内部であるとする．
また，平均自由行程が流速の空間変化の代表的な長さ $L$ より十分小さい，

```math
l\ll L
```

という条件を仮定する．
流速 $V(z)$ はこの領域で十分滑らかであり，流速勾配による平均自由行程程度の距離での流速差は熱運動の速さに比べて十分小さいものとする．

```math
l\left|\frac{\partial V}{\partial z}\right|\ll v
```

### 2．衝突後経過時間の確率分布

#### 2.1 経過時間の定義と輸送方程式

$z=0$ の平面を通過する分子について，直前の衝突から面を通過するまでの経過時間を $s$ とする．
衝突間隔が一定時間 $\tau$ であるから，

```math
0\leq s\leq\tau
```

である．

ここで， $p(s,t)$ を時刻 $t$ における衝突後経過時間 $s$ の確率密度とする．
分子は衝突と衝突の間に自由飛行するため，

```math
\frac{ds}{dt}=1
```

である．
したがって，経過時間の確率保存則は，

```math
\frac{\partial p}{\partial t}
+
\frac{\partial}{\partial s}
\left(\frac{ds}{dt}p\right)
=0
```

となる．
よって，

```math
\boxed{
\frac{\partial p}{\partial t}
+
\frac{\partial p}{\partial s}=0
}
```

を得る．

衝突時には，経過時間が $s=\tau$ から $s=0$ にリセットされる．
経過時間の変化率は両側で1であるため，確率流束の連続性から周期境界条件

```math
\boxed{
p(0,t)=p(\tau,t)
}
```

が成立する．

#### 2.2 定常状態での確率密度

ここでは，衝突周期の位相が統計的に定常な分子集団を考える．
定常状態では，

```math
\frac{\partial p}{\partial t}=0
```

なので，輸送方程式から

```math
\frac{\partial p}{\partial s}=0
```

となる．
したがって， $p(s)$ は $s$ に依存せず一定である．

確率密度の規格化条件

```math
\int_0^\tau p(s)\,ds=1
```

を用いると，

```math
p(s)\tau=1
```

であるから，

```math
\boxed{
p(s)=\frac1\tau
\qquad (0\leq s\leq\tau)
}
```

を得る．

ここで，定常状態とは，衝突周期の位相が一様に分布する定常な統計状態を意味する．
一般の初期分布が時間発展によって一様分布に収束するという意味ではない．

このとき，衝突後経過時間の平均は，

```math
\begin{aligned}
\langle s\rangle
&=\int_0^\tau s\,p(s)\,ds\\
&=\frac1\tau\int_0^\tau s\,ds\\
&=\frac{\tau}{2}
\end{aligned}
```

となる．

また，三次モーメントは，

```math
\begin{aligned}
\langle s^3\rangle
&=\int_0^\tau s^3p(s)\,ds\\
&=\frac1\tau\int_0^\tau s^3\,ds\\
&=\frac{\tau^3}{4}
\end{aligned}
```

である．

### 3．運動量流束の導出

#### 3.1 分子の速度と衝突位置

熱運動速度の方向を，正の $z$ 軸から測った極角 $\theta$ と方位角 $\phi$ で表す．
すると，

```math
v_{\mathrm{th},x}=v\sin\theta\cos\phi
```

```math
v_{\mathrm{th},z}=v\cos\theta
```

である．

面を通過する分子は，直前の衝突から時間 $s$ の間に， $z$ 方向へ $vs\cos\theta$ だけ移動している．
したがって，その分子の直前の衝突位置は，

```math
\boxed{
z'=-vs\cos\theta
}
```

である．

仮定 c）より，衝突直後の分子の平均速度は衝突位置での流速に等しい．
したがって，面を通過する分子の速度成分は，

```math
v_{\mathrm{total},x}
=
V(-vs\cos\theta)+v\sin\theta\cos\phi
```

および

```math
v_{\mathrm{total},z}=v\cos\theta
```

となる．

#### 3.2 運動量流束の定義

$P_{xz}$ を，正の $z$ 方向への $x$ 方向運動量の符号付き流束と定義する．

熱運動方向は等方的であるから，立体角 $d\Omega$ に含まれる分子の割合は，

```math
\frac{d\Omega}{4\pi}
```

である．
また，経過時間が $s$ から $s+ds$ の分子の割合は，

```math
p(s)\,ds
```

である．
ここでは，衝突後経過時間と熱運動方向が統計的に独立であると仮定する．

単位面積・単位時間あたりの符号付き通過分子数には，法線方向の速度成分 $v\cos\theta$ を掛ける．
したがって，

```math
P_{xz}
=
\frac{mnv}{4\pi}
\int_0^\tau p(s)\,ds
\int
\left[
V(-vs\cos\theta)+v\sin\theta\cos\phi
\right]
\cos\theta\,d\Omega
```

となる．
ここで，立体角積分は全立体角について行う．

熱運動に由来する項は，方位角について積分すると，

```math
\int_0^{2\pi}\cos\phi\,d\phi=0
```

となるため，その寄与は消える．
したがって，

```math
P_{xz}
=
\frac{mnv}{4\pi}
\int_0^\tau p(s)\,ds
\int V(-vs\cos\theta)\cos\theta\,d\Omega
```

である．

極角の範囲は，

```math
0\leq\theta\leq\pi
```

であり， $\cos\theta>0$ は正の $z$ 方向へ進む分子， $\cos\theta<0$ は負の $z$ 方向へ進む分子を表す．
両方向の運動量輸送を符号付きで扱うため，全立体角を積分する．
方位角について積分すると，

```math
\boxed{
P_{xz}
=
\frac{mnv}{2}
\int_0^\tau p(s)\,ds
\int_0^\pi
V(-vs\cos\theta)
\cos\theta\sin\theta\,d\theta
}
```

を得る．

### 4．テイラー展開と角度積分

$V(z)$ は考えている領域で少なくとも三階微分可能であるとする．
また，

```math
M_3=\sup_{|z|\leq l}|V'''(z)|<\infty
```

と定義する．

$z=0$ のまわりで二次までテイラー展開すると，

```math
\begin{aligned}
V(-vs\cos\theta)
={}&V(0)-vs\cos\theta V'(0)\\
&+\frac{v^2s^2\cos^2\theta}{2}V''(0)
+R_2(s,\theta)
\end{aligned}
```

となる．
テイラーの定理より，

```math
|R_2(s,\theta)|
\leq
\frac{v^3s^3|\cos\theta|^3}{6}M_3
```

である．
ここで $0\leq s\leq\tau$ なので，

```math
|vs\cos\theta|\leq v\tau=l
```

となり， $M_3$ の評価区間は適切である．

これを運動量流束の式に代入する．
角度積分について，

```math
\int_0^\pi\cos\theta\sin\theta\,d\theta=0
```

```math
\int_0^\pi\cos^2\theta\sin\theta\,d\theta
=\frac23
```

```math
\int_0^\pi\cos^3\theta\sin\theta\,d\theta=0
```

である．
したがって，定数項と二次の展開項は消え，一次の展開項が残る．
よって，

```math
\begin{aligned}
P_{xz}
&=
-\frac{mnv}{2}vV'(0)
\int_0^\tau sp(s)\,ds
\int_0^\pi\cos^2\theta\sin\theta\,d\theta
+\Delta P\\
&=
-\frac{mnv^2}{2}V'(0)
\langle s\rangle\cdot\frac23
+\Delta P\\
&=
-\frac13mnv^2\langle s\rangle V'(0)
+\Delta P
\end{aligned}
```

を得る．

したがって，一次の流速勾配に対する一般式は，

```math
\boxed{
P_{xz}
=
-\frac13mnv^2\langle s\rangle
\frac{\partial V}{\partial z}
}
```

である．

#### 4.1 剰余項の評価

剰余項については，

```math
\begin{aligned}
|\Delta P|
&\leq
\frac{mnv}{4\pi}
\int_0^\tau p(s)\,ds\,
\frac{v^3s^3M_3}{6}
\int |\cos\theta|^4\,d\Omega\\
&=
\frac{mnv^4M_3}{30}\langle s^3\rangle
\end{aligned}
```

となる．
ここで，

```math
\int |\cos\theta|^4\,d\Omega
=
2\pi\int_0^\pi|\cos\theta|^4\sin\theta\,d\theta
=
\frac{4\pi}{5}
```

を用いた．
したがって，

```math
\boxed{
|\Delta P|
\leq
\frac{mnv^4M_3}{30}\langle s^3\rangle
}
```

である．

定常・位相一様の場合には，

```math
\langle s^3\rangle=\frac{\tau^3}{4}
```

なので，

```math
\boxed{
|\Delta P|
\leq
\frac{mnv^4\tau^3M_3}{120}
}
```

となる．

また， $V'''(z)$ が連続であれば，三次の展開項まで明示できる．
このとき，

```math
P_{xz}
=
-\frac13mnv^2\langle s\rangle V'(0)
-\frac1{30}mnv^4\langle s^3\rangle V'''(0)
+o(l^3)
```

である．
定常・位相一様の場合には，

```math
\boxed{
P_{xz}
=
-\frac16mnv^2\tau V'(0)
-\frac1{120}mnv^4\tau^3V'''(0)
+o(l^3)
}
```

となる．
したがって，一次近似の次には一般に三次の補正が残る．

### 5．粘性係数の導出

$P_{xz}$ は正の $z$ 方向への $x$ 方向運動量の輸送流束であり，粘性応力そのものとは符号が反対である．
ニュートン流体のせん断応力を，

```math
\sigma_{xz}
=
\eta\frac{\partial V}{\partial z}
```

と定義すると，運動量流束は，

```math
P_{xz}
=
-\eta\frac{\partial V}{\partial z}
```

となる．

これと一般式，

```math
P_{xz}
=
-\frac13mnv^2\langle s\rangle
\frac{\partial V}{\partial z}
```

を比較すると，

```math
\eta=\frac13mnv^2\langle s\rangle
```

を得る．
質量密度を $\rho=mn$ とすれば，

```math
\boxed{
\eta=\frac13\rho v^2\langle s\rangle
}
```

となる．

### 6．衝突時間モデルによる係数の違い

#### 6.1 固定周期・定常・位相一様モデル

問題文の仮定 b）を，各分子が厳密に時間 $\tau$ ごとに衝突する固定周期モデルとして解釈し，定常な位相分布を採用する．
このとき，

```math
\langle s\rangle=\frac{\tau}{2}
```

であるから，

```math
\eta
=
\frac13\rho v^2\frac{\tau}{2}
```

となる．
したがって，

```math
\boxed{
\eta
=
\frac16\rho v^2\tau
=
\frac16\rho vl
}
```

を得る．

これは，固定周期の衝突モデルを定常・位相一様な統計集団として扱った場合の結果である．

#### 6.2 標準的な平均自由行程による略算

一方，標準的な平均自由行程近似では，面を通過する分子が直前の衝突から代表的な時間 $\tau$ だけ自由飛行したとみなす．
すなわち，

```math
\langle s\rangle\simeq\tau
```

と近似する．
この場合，

```math
\eta
\simeq
\frac13\rho v^2\tau
```

となり，

```math
\boxed{
\eta
\simeq
\frac13\rho v^2\tau
=
\frac13\rho vl
}
```

を得る．

同じ係数は，衝突がポアソン過程で起こり，平均衝突時間が $\tau$ であるモデルでも得られる．
その場合，定常な経過時間分布は，

```math
p(s)=\frac1\tau e^{-s/\tau}
\qquad (s\geq0)
```

であり，

```math
\langle s\rangle
=
\int_0^\infty s\frac1\tau e^{-s/\tau}\,ds
=
\tau
```

となるためである．

したがって，係数 $1/3$ と $1/6$ の違いは角度積分や数式変形の誤りによるものではなく，衝突後経過時間の統計モデルの違いによる．

### 7．結論と適用条件

標準的な平均自由行程による略算では，

```math
\boxed{
\eta\simeq\frac13\rho vl
=\frac13\rho v^2\tau
}
```

となる．
これが代表飛行時間を $\tau$ と置く平均自由行程近似の結果である．

一方，問題文の「一定時間 $\tau$ ごとに衝突する」という条件を厳密な固定周期モデルと解釈し，さらに定常・位相一様な分子集団を考える場合には，

```math
\boxed{
\eta=\frac16\rho vl
=\frac16\rho v^2\tau
}
```

となる．

したがって，例題[3]が通常の平均自由行程近似を採用している場合には，主結果として係数 $1/3$ を用いるのが適切である．
固定周期・定常位相一様モデルでは係数が $1/6$ になることも，衝突時間の統計的な扱いの違いとして理解できる．

この導出は，数密度が局所的に一様であり，境界から十分離れた気体内部において，平均自由行程が流速の変化する代表的な長さより十分小さい場合に適用される．
すなわち，

```math
l/L\ll1
```

の流体力学的近似を用いている．
また，流速は平均自由行程程度の距離で十分滑らかに変化し，流速勾配による流速差が熱運動の速さに比べて小さいものとする．

以上は，分子の速さが一定で，衝突後の方向が等方的であるという問題文の簡略化されたモデルによる粘性係数の略算であり，実在気体の粘性係数を厳密に求めるものではない．
