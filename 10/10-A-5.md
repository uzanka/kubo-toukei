# 演習問題【10-A-5】

## 解答

### 希薄気体の粘性係数の略算

#### 1．問題の設定と考え方

希薄気体の粘性係数 $\eta$ を，次の仮定に基づいて求める．

- すべての分子は一定の速さ $v$ で熱運動する．
- 分子は時間 $\tau$ ごとに衝突し，衝突後の運動方向は等方的に散乱される．
- 衝突直後の分子の平均速度は，衝突位置における気体の流速に等しい．

分子の平均自由行程を

```math
l=v\tau
\tag{1}
```

とする．
ここで， $v$ は熱運動の速さ， $\tau$ は衝突間の時間である．

気体は $x$ 方向に流れており，流速 $V$ は $z$ 座標だけの関数 $V(z)$ であるとする．
すなわち，異なる $z$ の位置で流速が少しずつ異なる．
このとき，分子が一つの層から別の層へ移動することで， $x$ 方向の運動量が $z$ 方向に輸送される．
この運動量輸送が，粘性の原因である．

流速の変化は自由行程 $l$ に比べて十分小さいと仮定し， $V(z)$ を局所的に一次まで展開する．

#### 2．分子が運ぶ運動量

##### 2.1．衝突位置と流速

$z=0$ の面を通過する分子を考える．
分子の進行方向と正の $z$ 軸とのなす角を $\theta$ とする．
分子の $z$ 方向速度成分は $v\cos\theta$ である．

分子は，時間 $\tau$ 前に次の衝突を受けている．
その間の $z$ 方向の変位は $v\tau\cos\theta=l\cos\theta$ であるため，直前の衝突位置は

```math
z=-l\cos\theta
\tag{2}
```

である．
$\cos\theta$ が正なら衝突位置は $z<0$ 側にあり，負なら $z>0$ 側にある．

仮定 c) より，この分子が直前の衝突位置で持つ $x$ 方向の平均速度は，その位置の流速 $V(-l\cos\theta)$ である．
したがって，その平均 $x$ 方向運動量は

```math
mV(-l\cos\theta)
```

となる．
ここで $m$ は分子の質量である．

流速勾配が十分に小さいので， $z=0$ の近傍で Taylor 展開して，

```math
\begin{aligned}
V(-l\cos\theta)
&\simeq V(0)
-l\cos\theta
\left(\frac{\partial V}{\partial z}\right)_{z=0}
\end{aligned}
\tag{3}
```

と近似できる．
これが，分子が運ぶ平均運動量を求めるための式である．

##### 2.2．運動量流束を求める

次に，単位面積を単位時間に通過する $x$ 方向運動量を求める．
これを $P_{xz}$ と表す．
これは， $z$ 方向に輸送される $x$ 方向運動量の流束である．

衝突後の分子の運動方向は等方的であるため，方向が微小立体角 $d\Omega$ に入る分子の割合は

```math
\frac{d\Omega}{4\pi}
```

である．
また，その方向の分子が面を横切る速さは，面の法線方向成分 $v\cos\theta$ によって決まる．
したがって，その方向に対応する符号付きの分子通過数は，単位面積・単位時間あたり，

```math
\frac{nv\cos\theta}{4\pi}\,d\Omega
\tag{4}
```

となる．
ここで $n$ は気体の分子数密度である．
$\cos\theta$ が正の分子は $+z$ 方向に面を横切り，負の分子は反対向きに横切る．
そのため，式 (4) では移動方向の符号が自動的に考慮されている．

方向角の方位角について積分すると，

```math
d\Omega=2\pi\sin\theta\,d\theta
```

である．
したがって，面を横切る分子が運ぶ平均 $x$ 方向運動量を積分すると，

```math
\begin{aligned}
P_{xz}
&=\frac{mnv}{4\pi}
\int V(-l\cos\theta)\cos\theta\,d\Omega\\
&=\frac{mnv}{2}
\int_0^\pi
V(-l\cos\theta)\cos\theta\sin\theta\,d\theta
\end{aligned}
\tag{5}
```

となる．
この式では， $z<0$ 側から $z>0$ 側へ向かう分子と，逆方向へ向かう分子の両方が含まれている．

式 (3) を式 (5) に代入すると，

```math
\begin{aligned}
P_{xz}=\frac{mnv}{2}\int_0^\pi
\biggl[
&V(0)
-l\cos\theta
\left(\frac{\partial V}{\partial z}\right)_{z=0}
\biggr]\\
&\qquad\times\cos\theta\sin\theta\,d\theta
\end{aligned}
\tag{6}
```

となる．
ここで，積分を二つの項に分けて考える．
第1項に含まれる積分は，

```math
\int_0^\pi\cos\theta\sin\theta\,d\theta=0
\tag{7}
```

である．
これは，面の両側から運ばれる一様な流速 $V(0)$ による寄与が相殺されることを意味する．
したがって，運動量流束に寄与するのは流速勾配を含む第2項である．

その角度積分は，

```math
\begin{aligned}
\int_0^\pi\cos^2\theta\sin\theta\,d\theta
&=\left[-\frac{\cos^3\theta}{3}\right]_0^\pi\\
&=\frac23
\end{aligned}
\tag{8}
```

である．
よって，式 (6) は

```math
\begin{aligned}
P_{xz}
&=-\frac{mnv}{2}l
\left(\frac{\partial V}{\partial z}\right)_{z=0}
\frac23\\[3pt]
&=-\frac13 mnvl
\left(\frac{\partial V}{\partial z}\right)_{z=0}
\end{aligned}
```

となる．
すなわち，

```math
\boxed{
P_{xz}
=-\frac13 mnvl\frac{\partial V}{\partial z}
}
\tag{9}
```

を得る．

#### 3．粘性係数を求める

流速 $V$ が $z$ 方向に変化する単純せん断流では，粘性による運動量流束は，

```math
P_{xz}=-\eta\frac{\partial V}{\partial z}
\tag{10}
```

と表される．
この式は，粘性による運動量輸送が流速勾配を小さくする向きに働くことを示している．

式 (9) と式 (10) を比較すると，

```math
\eta=\frac13 mnvl
```

となる．
気体の質量密度を

```math
\rho=mn
\tag{11}
```

と定義すれば，求める粘性係数は，

```math
\boxed{
\eta=\frac13\rho vl
}
\tag{12}
```

である．
さらに $l=v\tau$ より，

```math
\boxed{
\eta=\frac13\rho v^2\tau
}
\tag{13}
```

とも表せる．

#### 4．結果の物理的意味と適用条件

得られた式

```math
\eta=\frac13\rho vl
```

は，粘性係数が気体の質量密度 $\rho$ ，分子の熱運動の速さ $v$ ，平均自由行程 $l$ の積に比例することを示す．
分子が遠くの層まで移動して運動量を運ぶほど，層間の運動量輸送が大きくなり，粘性係数が大きくなる．
ほかの量を一定とすれば，平均自由行程が短くなるほど，この近似で得られる粘性係数は小さくなる．

ここで，速度勾配が小さいという仮定は，分子の直前の衝突位置から面までの範囲で，流速を一次展開できることを保証するものである．
また，希薄気体について分子間衝突の影響を無視する近似が成り立つには，平均自由行程が細孔や系の代表的な寸法に比べて十分長い分子流領域であることが必要である．

以上より，気体分子の運動方向が等方的であり，衝突間に平均自由行程だけ移動すると仮定して運動量流束を計算することで，

```math
\boxed{\eta=\frac13\rho vl}
```

が得られたのである．
