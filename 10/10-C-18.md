# 演習問題【10-C-18】

## 解答

### 1．問題の設定と追加仮定

分子内の電子を調和振動子として扱い，電子の位置を $\boldsymbol{x}$，運動量を $\boldsymbol{p}$ とする．

なお，問題文では位置の表記に $x$ と $\boldsymbol{x}$ が混在しているが，以下では三次元のベクトルとして $\boldsymbol{x}$ に統一する．

電子の運動方程式は，

```math
\frac{d\boldsymbol{x}}{dt}
=
\frac{\boldsymbol{p}}{m},
\qquad
\frac{d\boldsymbol{p}}{dt}
=
-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)
```

である．

ここで，$m$ は電子の質量，$-e$ は電子の電荷，$\omega_0$ は固有角振動数，$\boldsymbol{E}(t)$ は外部電場である．

まず，分子間の衝突がない場合を考える．
また，衝突後の電子分布は，指定された分布

```math
f_0(\boldsymbol{x},\boldsymbol{p},t)
```

にリセットされるものとする．

#### 衝突過程についての仮定

平均自由時間が $\tau$ であるという条件だけでは，衝突間隔の確率分布は一意に定まらない．

そこで，以下では，衝突が時間的に一様な率

```math
\lambda=\frac{1}{\tau}
```

で独立に起こる Poisson 過程であると仮定する．

すなわち，過去の衝突履歴や電子の位相空間座標によらず，微小時間 $dt$ の間に衝突が起こる確率は，

```math
\Pr(\text{衝突が }dt\text{ 内に起こる})
=
\frac{dt}{\tau}+o(dt)
```

である．

また，異なる時間区間における衝突の発生は独立であるとする．

この仮定により，衝突間隔は平均値 $\tau$ の指数分布に従う．

なお，外部電場 $\boldsymbol{E}(t)$ と分布 $f_0$ は時間依存していてもよい．ここで定常と仮定しているのは衝突過程であり，電子の運動や分布まで定常である必要はない．

以下では，この仮定のもとで要求された方程式を導く．


### 2．衝突がない場合の Liouville 方程式

衝突がない場合，位相空間分布 $f(\boldsymbol{x},\boldsymbol{p},t)$ は Liouville 方程式に従う．

位相空間における速度場を，

```math
\boldsymbol{v}
=
\left(
\frac{\boldsymbol{p}}{m},
-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)
\right)
```

とする．

位相空間における分布関数の保存則は，

```math
\frac{\partial f}{\partial t}
+
\nabla_{(\boldsymbol{x},\boldsymbol{p})}
\cdot(f\boldsymbol{v})
=0
```

である．

これを展開すると，

```math
\begin{aligned}
\frac{\partial f}{\partial t}
&+
\frac{\boldsymbol{p}}{m}
\cdot\nabla_{\boldsymbol{x}}f\\
&+
\left(
-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)
\right)
\cdot\nabla_{\boldsymbol{p}}f\\
&+
f\nabla_{(\boldsymbol{x},\boldsymbol{p})}
\cdot\boldsymbol{v}
=0
\end{aligned}
```

となる．

ここで，位相空間の速度場の発散は，

```math
\begin{aligned}
\nabla_{(\boldsymbol{x},\boldsymbol{p})}
\cdot\boldsymbol{v}
&=
\nabla_{\boldsymbol{x}}\cdot
\frac{\boldsymbol{p}}{m}\\
&\quad+
\nabla_{\boldsymbol{p}}\cdot
\left(
-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)
\right)\\
&=0
\end{aligned}
```

である．

したがって，

```math
\boxed{
\begin{aligned}
\frac{\partial f}{\partial t}
&+
\frac{\boldsymbol{p}}{m}
\cdot\nabla_{\boldsymbol{x}}f\\
&+
\left(
-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)
\right)
\cdot\nabla_{\boldsymbol{p}}f
=0
\end{aligned}
}
\tag{1}
```

を得る．

ここで，時間依存する Liouville 演算子を，

```math
\boxed{
\mathcal{L}_t
=
\frac{\boldsymbol{p}}{m}
\cdot\nabla_{\boldsymbol{x}}
+
\left(
-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)
\right)
\cdot\nabla_{\boldsymbol{p}}
}
```

と定義すれば，式 (1) は，

```math
\frac{\partial f}{\partial t}
+
\mathcal{L}_t f
=0
```

と表せる．


### 3．衝突が起こらない確率

最後の衝突からの経過時間を $\theta$ とする．

時間 $\theta$ の間に衝突が一度も起こらない確率を $S(\theta)$ と定義する．

Poisson 過程の仮定から，微小時間 $d\theta$ の間に衝突が起こらない確率は，

```math
1-\frac{d\theta}{\tau}+o(d\theta)
```

である．

したがって，

```math
S(\theta+d\theta)
=
S(\theta)
\left(
1-\frac{d\theta}{\tau}
+o(d\theta)
\right)
```

となる．

両辺から $S(\theta)$ を引き，$d\theta$ で割って極限を取ると，

```math
\frac{dS}{d\theta}
=
-\frac{S}{\tau}
```

を得る．

初期条件

```math
S(0)=1
```

のもとで解けば，

```math
\boxed{
S(\theta)=e^{-\theta/\tau}
}
\tag{2}
```

となる．

これは，時間 $\theta$ の間に衝突が起こらない確率である．

次に，最後の衝突からの経過時間が $\theta$ から $\theta+d\theta$ の間にある確率密度を考える．

定常な Poisson 過程では，時刻 $t-\theta$ 付近に衝突が起こる確率は，

```math
\frac{d\theta}{\tau}+o(d\theta)
```

である．

その後の時間 $\theta$ にわたって衝突が起こらない確率は式 (2) で与えられる．

したがって，

```math
P(\theta)d\theta
=
\frac{d\theta}{\tau}
e^{-\theta/\tau}
+o(d\theta)
```

となる．

よって，経過時間 $\theta$ の確率密度は，

```math
\boxed{
P(\theta)
=
\frac{1}{\tau}e^{-\theta/\tau},
\qquad
\theta\geq0
}
\tag{3}
```

である．

規格化を確認すると，

```math
\begin{aligned}
\int_0^\infty P(\theta)\,d\theta
&=
\frac{1}{\tau}
\int_0^\infty e^{-\theta/\tau}\,d\theta\\
&=1
\end{aligned}
```

となる．

したがって，式 (3) は正しく規格化された確率密度である．

なお，この確率密度が成立するのは Poisson 過程を仮定したためであり，平均自由時間が $\tau$ であるという条件だけから導かれるものではない．


### 4．有限の初期時刻からの平均分布関数

無限過去から積分する前に，有限の初期時刻 $t_0$ から考える．

時刻 $t_0$ における初期分布を，

```math
f_{\mathrm{in}}(\boldsymbol{x},\boldsymbol{p})
=
\bar{f}(\boldsymbol{x},\boldsymbol{p},t_0)
```

とする．

Liouville 方程式の時間発展演算子を $U(t,s)$ と定義する．これは任意の初期分布 $g$ に対して，

```math
\frac{\partial}{\partial t}
U(t,s)g
=
-\mathcal{L}_t U(t,s)g
```

および，

```math
U(s,s)g=g
```

を満たす演算子である．

ここで，$U(t,s)$ は位相空間上の関数に作用する時間発展演算子であり，時間依存する Liouville 演算子に対応している．

したがって，時刻 $s$ に与えられた分布 $g$ は，時刻 $t$ には，

```math
U(t,s)g
```

に発展する．

特に，時刻 $s$ に衝突が起こった場合，衝突直後の分布は $f_0(\boldsymbol{x},\boldsymbol{p},s)$ であるため，時刻 $t$ での分布は，

```math
U(t,s)f_0(s)
```

となる．

ここで，

```math
f_0(s)
=
f_0(\boldsymbol{x},\boldsymbol{p},s)
```

を表す．

次に，時刻 $t$ における衝突履歴を考える．

時刻 $t_0$ から時刻 $t$ まで一度も衝突が起こらない確率は，

```math
e^{-(t-t_0)/\tau}
```

である．

この場合，時刻 $t$ の分布は，

```math
U(t,t_0)f_{\mathrm{in}}
```

となる．

一方，時刻 $s$ 付近に最後の衝突が起こり，その後時刻 $t$ まで衝突が起こらない確率密度は，

```math
\frac{1}{\tau}e^{-(t-s)/\tau}
```

である．

したがって，時刻 $t$ における平均分布関数は，

```math
\boxed{
\begin{aligned}
\bar{f}(\boldsymbol{x},\boldsymbol{p},t)
={}&
e^{-(t-t_0)/\tau}
U(t,t_0)f_{\mathrm{in}}\\
&+
\int_{t_0}^{t}
\frac{1}{\tau}e^{-(t-s)/\tau}
U(t,s)f_0(s)\,ds
\end{aligned}
}
\tag{4}
```

で与えられる．

第1項は，初期時刻から一度も衝突しなかった集団の寄与である．

第2項は，時刻 $s$ に最後の衝突が起こり，その後衝突が起こらなかった集団の寄与である．

この式は，衝突が一度も起こらなかった場合も含めている．

また，確率の規格化は，

```math
\begin{aligned}
&e^{-(t-t_0)/\tau}
+
\int_{t_0}^{t}
\frac{1}{\tau}e^{-(t-s)/\tau}\,ds\\
&=
e^{-(t-t_0)/\tau}
+
1-e^{-(t-t_0)/\tau}\\
&=1
\end{aligned}
```

となり，正しい．

さらに，$t=t_0$ とすれば，

```math
\bar{f}(\boldsymbol{x},\boldsymbol{p},t_0)
=
f_{\mathrm{in}}(\boldsymbol{x},\boldsymbol{p})
```

となるので，初期条件も満たしている．


### 5．有限初期時刻からの式を微分する

式 (4) を，

```math
\bar{f}(t)=A(t)+B(t)
```

と置く．

ここで，

```math
A(t)
=
e^{-(t-t_0)/\tau}
U(t,t_0)f_{\mathrm{in}}
```

および，

```math
B(t)
=
\int_{t_0}^{t}
\frac{1}{\tau}e^{-(t-s)/\tau}
U(t,s)f_0(s)\,ds
```

とする．


#### 5.1 第1項の微分

まず，

```math
A(t)
=
e^{-(t-t_0)/\tau}
U(t,t_0)f_{\mathrm{in}}
```

を微分する．

積の微分法より，

```math
\begin{aligned}
\frac{\partial A}{\partial t}
={}&
-\frac{1}{\tau}
e^{-(t-t_0)/\tau}
U(t,t_0)f_{\mathrm{in}}\\
&+
e^{-(t-t_0)/\tau}
\frac{\partial U(t,t_0)}{\partial t}
f_{\mathrm{in}}
\end{aligned}
```

である．

時間発展演算子の定義から，

```math
\frac{\partial U(t,t_0)}{\partial t}
=
-\mathcal{L}_t U(t,t_0)
```

なので，

```math
\boxed{
\frac{\partial A}{\partial t}
=
-\frac{A}{\tau}
-\mathcal{L}_t A
}
\tag{5}
```

となる．


#### 5.2 第2項の微分

次に，

```math
B(t)
=
\int_{t_0}^{t}
\frac{1}{\tau}e^{-(t-s)/\tau}
U(t,s)f_0(s)\,ds
```

を微分する．

Leibniz の積分公式を用いると，

```math
\begin{aligned}
\frac{\partial B}{\partial t}
={}&
\frac{1}{\tau}U(t,t)f_0(t)\\
&+
\int_{t_0}^{t}
\frac{\partial}{\partial t}
\left[
\frac{1}{\tau}e^{-(t-s)/\tau}
U(t,s)f_0(s)
\right]ds
\end{aligned}
```

となる．

ここで，

```math
U(t,t)=I
```

であるため，上端から生じる項は，

```math
\frac{f_0(t)}{\tau}
```

である．

また，積分の中身を微分すると，

```math
\begin{aligned}
&\frac{\partial}{\partial t}
\left[
\frac{1}{\tau}e^{-(t-s)/\tau}
U(t,s)f_0(s)
\right]\\
&=
-\frac{1}{\tau^2}
e^{-(t-s)/\tau}
U(t,s)f_0(s)\\
&\quad+
\frac{1}{\tau}e^{-(t-s)/\tau}
\frac{\partial U(t,s)}{\partial t}
f_0(s)
\end{aligned}
```

である．

時間発展演算子について，

```math
\frac{\partial U(t,s)}{\partial t}
=
-\mathcal{L}_t U(t,s)
```

を代入すると，

```math
\begin{aligned}
\frac{\partial B}{\partial t}
={}&
\frac{f_0(t)}{\tau}\\
&-
\frac{1}{\tau}
\int_{t_0}^{t}
\frac{1}{\tau}e^{-(t-s)/\tau}
U(t,s)f_0(s)\,ds\\
&-
\int_{t_0}^{t}
\frac{1}{\tau}e^{-(t-s)/\tau}
\mathcal{L}_t U(t,s)f_0(s)\,ds
\end{aligned}
```

となる．

$\mathcal{L}_t$ は積分変数 $s$ に依存しないため，演算子を積分の外に出せる．

ただし，この操作は，必要な正則性があり，微分と積分の交換が正当化されることを前提とする．

したがって，

```math
\begin{aligned}
\frac{\partial B}{\partial t}
={}&
\frac{f_0(t)}{\tau}
-\frac{1}{\tau}B(t)
-\mathcal{L}_t B(t)
\end{aligned}
```

を得る．

すなわち，

```math
\boxed{
\frac{\partial B}{\partial t}
=
\frac{f_0(t)}{\tau}
-\frac{B}{\tau}
-\mathcal{L}_t B
}
\tag{6}
```

である．


### 6．平均分布関数の支配方程式

式 (4) より，

```math
\bar{f}=A+B
```

であるため，

```math
\frac{\partial\bar{f}}{\partial t}
=
\frac{\partial A}{\partial t}
+
\frac{\partial B}{\partial t}
```

となる．

ここに式 (5)，式 (6) を代入すると，

```math
\begin{aligned}
\frac{\partial\bar{f}}{\partial t}
={}&
-\frac{A}{\tau}
-\mathcal{L}_t A\\
&+
\frac{f_0}{\tau}
-\frac{B}{\tau}
-\mathcal{L}_t B
\end{aligned}
```

である．

$A+B=\bar{f}$ を用いると，

```math
\frac{\partial\bar{f}}{\partial t}
=
\frac{f_0}{\tau}
-\frac{\bar{f}}{\tau}
-\mathcal{L}_t\bar{f}
```

を得る．

整理すれば，

```math
\boxed{
\frac{\partial\bar{f}}{\partial t}
+
\mathcal{L}_t\bar{f}
=
-\frac{\bar{f}-f_0}{\tau}
}
```

となる．

ここで Liouville 演算子を元の形に戻すと，

```math
\boxed{
\begin{aligned}
\frac{\partial\bar{f}}{\partial t}
&+
\frac{\boldsymbol{p}}{m}
\cdot
\frac{\partial\bar{f}}{\partial\boldsymbol{x}}\\
&+
\left(
-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)
\right)
\cdot
\frac{\partial\bar{f}}{\partial\boldsymbol{p}}\\
&=
-\frac{\bar{f}-f_0}{\tau}
\end{aligned}
}
\tag{7}
```

となる．

これが示すべき方程式である．


### 7．無限過去からの積分表示との関係

元の解答では，最後の衝突時刻について，

```math
\int_{-\infty}^{t}
\frac{1}{\tau}
e^{-(t-t_c)/\tau}\,dt_c
```

という積分を用いていた．

この表現は，有限初期時刻 $t_0$ からの式 (4) において，

```math
t_0\rightarrow-\infty
```

とすることによって得られる．

ただし，この極限を正当化するには，初期項が消失することと，積分項が収束することをそれぞれ確認する必要がある．

具体的には，初期分布が，

```math
\sup_{t_0<t}
\left\|
f_{\mathrm{in}}^{(t_0)}
\right\|_\infty
<\infty
```

を満たすとする．

また，$f_0$ について，

```math
\sup_{s\leq t}
\left\|
f_0(s)
\right\|_\infty
<\infty
```

を仮定する．

Liouville 方程式は位相空間の非圧縮な流れに対応するため，分布関数の最大値を保存する．したがって，

```math
\left\|
U(t,s)g
\right\|_\infty
=
\|g\|_\infty
```

である．

このとき，初期項について，

```math
\begin{aligned}
&
\left\|
e^{-(t-t_0)/\tau}
U(t,t_0)f_{\mathrm{in}}^{(t_0)}
\right\|_\infty\\
&\leq
e^{-(t-t_0)/\tau}
\left\|
f_{\mathrm{in}}^{(t_0)}
\right\|_\infty
\end{aligned}
```

となる．

したがって，

```math
\boxed{
e^{-(t-t_0)/\tau}
U(t,t_0)f_{\mathrm{in}}^{(t_0)}
\rightarrow0
\qquad
(t_0\rightarrow-\infty)
}
```

である．

また，積分項についても，その被積分関数のノルムは，

```math
\left\|
\frac{1}{\tau}
e^{-(t-s)/\tau}
U(t,s)f_0(s)
\right\|_\infty
\leq
\frac{C}{\tau}
e^{-(t-s)/\tau}
```

と評価できる．

ここで $C$ は $s\leq t$ における $\|f_0(s)\|_\infty$ の一様な上界である．

さらに，

```math
\int_{-\infty}^{t}
\frac{C}{\tau}
e^{-(t-s)/\tau}\,ds
=C<\infty
```

であるため，積分項は収束する．

以上より，式 (4) の極限は，

```math
\boxed{
\begin{aligned}
\bar{f}(\boldsymbol{x},\boldsymbol{p},t)
=
\int_{-\infty}^{t}
\frac{1}{\tau}
e^{-(t-t_c)/\tau}
U(t,t_c)f_0(t_c)\,dt_c
\end{aligned}
}
\tag{8}
```

となる．

ここで，

```math
f_{t_c}(\boldsymbol{x},\boldsymbol{p},t)
=
U(t,t_c)
f_0(\boldsymbol{x},\boldsymbol{p},t_c)
```

と定義すれば，

```math
\boxed{
\bar{f}(\boldsymbol{x},\boldsymbol{p},t)
=
\int_{-\infty}^{t}
f_{t_c}(\boldsymbol{x},\boldsymbol{p},t)
\frac{e^{-(t-t_c)/\tau}}{\tau}
\,dt_c
}
```

となり，元の解答の積分表示と一致する．

したがって，元の解答の積分表示は，無限過去から衝突履歴が存在する場合の表現である．

有限初期時刻から議論する場合には，式 (4) に示した初期分布の寄与を省略してはならない．


### 8．保存則と物理的な整合性

#### 8.1 粒子数保存

位相空間全体にわたって式 (7) を積分する．

位相空間境界からの流束が消えると仮定すると，

```math
\int
\mathcal{L}_t\bar{f}
\,d\boldsymbol{x}\,d\boldsymbol{p}
=0
```

となる．

したがって，

```math
\begin{aligned}
\frac{d}{dt}
\int\bar{f}\,d\boldsymbol{x}\,d\boldsymbol{p}
=
-\frac{1}{\tau}
\left(
\int\bar{f}\,d\boldsymbol{x}\,d\boldsymbol{p}
-
\int f_0\,d\boldsymbol{x}\,d\boldsymbol{p}
\right)
\end{aligned}
```

である．

ここで，

```math
N_{\mathrm{bar}}(t)
=
\int
\bar{f}(\boldsymbol{x},\boldsymbol{p},t)
\,d\boldsymbol{x}\,d\boldsymbol{p}
```

および，

```math
N_0(t)
=
\int
f_0(\boldsymbol{x},\boldsymbol{p},t)
\,d\boldsymbol{x}\,d\boldsymbol{p}
```

と定義すれば，

```math
\boxed{
\frac{dN_{\mathrm{bar}}}{dt}
=
-\frac{N_{\mathrm{bar}}-N_0(t)}{\tau}
}
```

となる．

ここで，$f_0$ がすべての時刻において同じ電子数 $N$ に規格化されていると仮定する．すなわち，

```math
\boxed{
\int
f_0(\boldsymbol{x},\boldsymbol{p},t)
\,d\boldsymbol{x}\,d\boldsymbol{p}
=N
\qquad
(\text{すべての }t)
}
```

である．

また，初期分布について，

```math
\int
f_{\mathrm{in}}(\boldsymbol{x},\boldsymbol{p})
\,d\boldsymbol{x}\,d\boldsymbol{p}
=N
```

とする．

すると，

```math
\frac{dN_{\mathrm{bar}}}{dt}
=
-\frac{N_{\mathrm{bar}}-N}{\tau}
```

であり，初期条件

```math
N_{\mathrm{bar}}(t_0)=N
```

から，

```math
\boxed{
N_{\mathrm{bar}}(t)=N
}
```

が得られる．

したがって，この規格化条件のもとでは衝突項は電子の粒子数を保存する．

なお，この規格化条件が満たされない場合には，一般に粒子数は保存されない．


#### 8.2 運動量・エネルギー保存

この緩和時間近似の衝突項は，

```math
-\frac{\bar{f}-f_0}{\tau}
```

である．

この項がある物理量のモーメントを変化させないためには，その物理量に対応する関数 $\psi(\boldsymbol{x},\boldsymbol{p})$ について，

```math
\boxed{
\int
\psi(\boldsymbol{x},\boldsymbol{p})
\left(
\bar{f}-f_0
\right)
\,d\boldsymbol{x}\,d\boldsymbol{p}
=0
}
```

が成立する必要がある．

例えば，粒子数については，

```math
\psi=1
```

であり，運動量については，

```math
\psi=\boldsymbol{p}
```

であり，調和振動子のエネルギーについては，

```math
\psi=
\frac{\boldsymbol{p}^2}{2m}
+
\frac12m\omega_0^2\boldsymbol{x}^2
```

に対応する．

ただし，これは衝突項による各モーメントの変化をゼロにする条件である．

電子系全体の運動量やエネルギーが保存される条件とは区別しなければならない．

実際，電子の運動量は外力を受けるため，衝突がなくても一般には保存されない．

また，調和振動子のエネルギーを，

```math
H_0=
\frac{\boldsymbol{p}^2}{2m}
+
\frac12m\omega_0^2\boldsymbol{x}^2
```

とすると，電子の運動方程式から，

```math
\begin{aligned}
\frac{dH_0}{dt}
&=
\frac{\boldsymbol{p}}{m}
\cdot
\frac{d\boldsymbol{p}}{dt}
+
m\omega_0^2\boldsymbol{x}
\cdot
\frac{d\boldsymbol{x}}{dt}\\
&=
\frac{\boldsymbol{p}}{m}
\cdot
\left(
-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)
\right)\\
&\quad+
m\omega_0^2\boldsymbol{x}
\cdot
\frac{\boldsymbol{p}}{m}\\
&=
-\frac{e}{m}
\boldsymbol{E}(t)\cdot\boldsymbol{p}
\end{aligned}
```

となる．

したがって，外部電場が仕事をする場合には，調和振動子のエネルギーも保存されない．

この緩和時間近似は，電子分布を指定された $f_0$ にリセットするモデルであり，厳密な二体衝突の Boltzmann 衝突積分を直接表すものではない．

分子側とのエネルギーや運動量の交換をどのように扱うかによって，保存させるべきモーメントが決まる．


#### 8.3 $\tau$ の極限

まず，

```math
\tau\rightarrow\infty
```

を考える．

有限の初期時刻 $t_0$ を固定すると，

```math
e^{-(t-t_0)/\tau}\rightarrow1
```

となる．

また，$f_0$ が有界であるとき，積分項は，

```math
\left\|
\int_{t_0}^{t}
\frac{1}{\tau}
e^{-(t-s)/\tau}
U(t,s)f_0(s)\,ds
\right\|_\infty
\leq
\frac{C(t-t_0)}{\tau}
```

と評価できるため，$\tau\rightarrow\infty$ でゼロとなる．

したがって，

```math
\boxed{
\bar{f}(t)
\rightarrow
U(t,t_0)f_{\mathrm{in}}
}
```

となる．

これは衝突が起こらない場合の Liouville 発展であり，物理的に整合する．

次に，

```math
\tau\rightarrow0
```

を考える．

式 (4) の積分項で，

```math
\theta=t-s
```

と置くと，

```math
\begin{aligned}
B(t)
=
\int_0^{t-t_0}
\frac{1}{\tau}
e^{-\theta/\tau}
U(t,t-\theta)
f_0(t-\theta)\,d\theta
\end{aligned}
```

となる．

このとき，指数関数の核は $\tau\rightarrow0$ で $\theta=0$ の近傍に集中する．

また，

```math
U(t,t)=I
```

であり，$f_0$ と時間発展演算子が必要な意味で連続であれば，

```math
U(t,t-\theta)f_0(t-\theta)
\rightarrow f_0(t)
\qquad
(\theta\rightarrow0)
```

となる．

したがって，固定した $t>t_0$ に対して，

```math
\boxed{
\bar{f}(t)\rightarrow f_0(t)
\qquad
(\tau\rightarrow0)
}
```

が得られる．

初期項は，

```math
e^{-(t-t_0)/\tau}U(t,t_0)f_{\mathrm{in}}
\rightarrow0
```

となるため，この極限に寄与しない．

したがって，衝突が非常に頻繁に起こる極限では，電子分布は指定された分布に近づく．

以上より，両極限において物理的な整合性が確認できる．


### 9．数学的な成立条件

以上の導出では，次の条件を仮定している．

- $\boldsymbol{E}(t)$ が時間について十分滑らかであること．

- $f_0$ と初期分布が必要な範囲で微分可能であること．

- 積分と微分の交換が可能であること．

- 位相空間境界からの流束が消えること．

- 時間発展演算子 $U(t,s)$ が定義され，必要な微分関係を満たすこと．

- 無限過去からの積分表示を使う場合には，初期項の消失と積分の収束を保証する一様有界性などの条件が成立すること．

これらの条件のもとで，Leibniz の積分公式と時間発展演算子による微分が正当化される．

また，粒子数保存を主張する場合には，$f_0$ がすべての時刻で同じ電子数に規格化されており，初期分布も同じ電子数に規格化されていることが必要である．


### 10．結論

分子間衝突が一定率 $1/\tau$ で独立に発生する Poisson 過程であり，衝突直後の電子分布が $f_0$ にリセットされると仮定する．

有限初期時刻から最後の衝突時刻について平均を取り，その時間発展を Liouville 方程式に従って記述すると，

```math
\frac{\partial\bar{f}}{\partial t}
+
\mathcal{L}_t\bar{f}
=
-\frac{\bar{f}-f_0}{\tau}
```

が得られる．

Liouville 演算子を展開すると，

```math
\boxed{
\begin{aligned}
\frac{\partial\bar{f}}{\partial t}
&+
\frac{\boldsymbol{p}}{m}
\cdot
\frac{\partial\bar{f}}{\partial\boldsymbol{x}}\\
&+
\left(
-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)
\right)
\cdot
\frac{\partial\bar{f}}{\partial\boldsymbol{p}}\\
&=
-\frac{\bar{f}-f_0}{\tau}
\end{aligned}
}
```

となる．

これは問題で示すべき方程式である．

ただし，この導出には一定率の Poisson 衝突過程という追加仮定が必要であり，平均自由時間 $\tau$ という条件だけから一般に導かれるものではない．

また，有限初期時刻から導出する場合には，初期分布からの寄与を含める必要がある．
