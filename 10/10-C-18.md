# 演習問題【10-C-18】

## 解答

### 1．衝突がない場合の分布関数

分子内の電子を調和振動子とみなし，電子の位置を $\boldsymbol{x}$ ，運動量を $\boldsymbol{p}$ とする．
電子の運動方程式は

```math
\frac{d\boldsymbol{x}}{dt}=\frac{\boldsymbol{p}}{m},
\qquad
\frac{d\boldsymbol{p}}{dt}
=-m\omega_0^2\boldsymbol{x}-e\boldsymbol{E}(t)
```

である．
ここで， $m$ は電子の質量， $\omega_0$ は固有角振動数， $-e$ は電子の電荷， $\boldsymbol{E}(t)$ は外部電場である．

まず，分子間の衝突がない場合を考える．
位相空間における分布関数を $f(\boldsymbol{x},\boldsymbol{p},t)$ とすると，Liouville 方程式は

```math
\frac{\partial f}{\partial t}
+\frac{\boldsymbol{p}}{m}\cdot
\frac{\partial f}{\partial\boldsymbol{x}}
+\left(-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)\right)\cdot
\frac{\partial f}{\partial\boldsymbol{p}}
=0
\tag{1}
```

である．
この式は，衝突がないとき，電子の運動に伴って位相空間内の分布が移動することを表している．

以下では，分子間衝突が電子の分布に与える影響を考慮し，問題文で定義された衝突時刻について平均した分布関数 $\bar f$ を求める．

### 2．最後の衝突からの経過時間の確率密度

衝突が平均自由時間 $\tau$ をもってランダムに起こると仮定する．
この仮定では，微小時間 $d\theta$ の間に衝突が起こる確率は $d\theta/\tau$ である．
ここで， $\theta$ は最後の衝突から現在までの経過時間である．

最初に，時間 $\theta$ の間に一度も衝突しない確率を $S(\theta)$ とする．
時間が $d\theta$ だけ増えたとき，追加の衝突が起こらない確率は $1-d\theta/\tau$ であるから，

```math
S(\theta+d\theta)
=S(\theta)\left(1-\frac{d\theta}{\tau}\right)
```

となる．
両辺を整理して $d\theta\to0$ の極限を取ると，

```math
\frac{dS}{d\theta}=-\frac{S}{\tau}
```

を得る．
初期条件 $S(0)=1$ のもとで解けば，

```math
S(\theta)=e^{-\theta/\tau}
\tag{2}
```

である．
これは，時間 $\theta$ の間に衝突が一度も起こらない確率である．

次に，最後の衝突からの経過時間が $\theta$ から $\theta+d\theta$ の範囲にある確率を考える．
定常な衝突過程では，時刻 $t-\theta$ 付近で衝突が起こる確率は単位時間あたり $1/\tau$ であり，その後の時間 $\theta$ にわたって衝突が起こらない確率は式 (2) で与えられる．
したがって，経過時間 $\theta$ の確率密度は

```math
\boxed{
P(\theta)=\frac{1}{\tau}e^{-\theta/\tau}
\qquad (\theta\geq0)
}
\tag{3}
```

となる．
この確率密度は，

```math
\int_0^\infty P(\theta)\,d\theta
=\frac{1}{\tau}\int_0^\infty e^{-\theta/\tau}\,d\theta
=1
```

を満たすため，正しく規格化されている．

### 3．衝突時刻について平均した分布関数

時刻 $t_c$ に衝突が起こり，その直後の電子分布が

```math
f(\boldsymbol{x},\boldsymbol{p},t_c)
=f_0(\boldsymbol{x},\boldsymbol{p},t_c)
```

になると仮定する．
その後，時刻 $t$ まで衝突が起こらなければ，分布関数は式 (1) の Liouville 方程式に従って発展する．
このようにして得られた分布関数を

```math
f_{t_c}(\boldsymbol{x},\boldsymbol{p},t)
```

と表す．

時刻 $t$ における平均分布関数 $\bar f$ は，最後に衝突が起こった時刻 $t_c$ の確率密度で重み付けした平均である．
式 (3) を用いると，

```math
\boxed{
\bar f(\boldsymbol{x},\boldsymbol{p},t)
=\int_{-\infty}^{t}
f_{t_c}(\boldsymbol{x},\boldsymbol{p},t)
\frac{e^{-(t-t_c)/\tau}}{\tau}\,dt_c
}
\tag{4}
```

となる．
ここで，積分範囲を $-\infty$ から $t$ としたのは，最後の衝突時刻 $t_c$ が現在時刻 $t$ より前であればよいためである．

### 4．平均分布関数を時間微分する

式 (4) を時刻 $t$ で偏微分する．
積分の上端も $t$ に依存しているため，Leibniz の積分公式

```math
\frac{d}{dt}\int_{-\infty}^{t}g(t_c,t)\,dt_c
=g(t,t)+\int_{-\infty}^{t}
\frac{\partial g(t_c,t)}{\partial t}\,dt_c
```

を用いる．

まず，

```math
g(t_c,t)=
f_{t_c}(\boldsymbol{x},\boldsymbol{p},t)
\frac{e^{-(t-t_c)/\tau}}{\tau}
```

と置く．
積分の上端から生じる項は，

```math
g(t,t)=\frac{1}{\tau}
f_t(\boldsymbol{x},\boldsymbol{p},t)
```

である．
$t_c=t$ は，時刻 $t$ に衝突が起こった場合に対応する．
衝突直後の分布は $f_0$ であるという仮定から，

```math
f_t(\boldsymbol{x},\boldsymbol{p},t)
=f_0(\boldsymbol{x},\boldsymbol{p},t)
```

となる．
したがって，上端からの項は $f_0/\tau$ である．

次に，積分の中身を $t$ で微分すると，

```math
\begin{aligned}
\frac{\partial g}{\partial t}
={}&
\frac{\partial f_{t_c}}{\partial t}
\frac{e^{-(t-t_c)/\tau}}{\tau}\\
&-\frac{1}{\tau}
f_{t_c}\frac{e^{-(t-t_c)/\tau}}{\tau}
\end{aligned}
```

となる．
これを式 (4) の積分範囲で積分すると，

```math
\begin{aligned}
\frac{\partial\bar f}{\partial t}
={}&\frac{f_0}{\tau}
+\int_{-\infty}^{t}
\frac{\partial f_{t_c}}{\partial t}
\frac{e^{-(t-t_c)/\tau}}{\tau}\,dt_c\\
&-\frac{1}{\tau}
\int_{-\infty}^{t}
f_{t_c}\frac{e^{-(t-t_c)/\tau}}{\tau}\,dt_c
\end{aligned}
```

である．
最後の積分は式 (4) の $\bar f$ そのものであるから，

```math
\boxed{
\frac{\partial\bar f}{\partial t}
=\frac{f_0}{\tau}
+\int_{-\infty}^{t}
\frac{\partial f_{t_c}}{\partial t}
\frac{e^{-(t-t_c)/\tau}}{\tau}\,dt_c
-\frac{\bar f}{\tau}
}
\tag{5}
```

を得る．

### 5．Liouville 方程式を代入する

最後の衝突から時刻 $t$ までの運動は衝突なしであるため， $f_{t_c}$ は Liouville 方程式 (1) を満たす．
よって，

```math
\begin{aligned}
\frac{\partial f_{t_c}}{\partial t}
={}&-\frac{\boldsymbol{p}}{m}\cdot
\frac{\partial f_{t_c}}{\partial\boldsymbol{x}}\\
&-\left(-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)\right)\cdot
\frac{\partial f_{t_c}}{\partial\boldsymbol{p}}
\end{aligned}
\tag{6}
```

である．

式 (6) を式 (5) の積分項に代入する．
時刻 $t$ における微分演算子

```math
\mathcal L_t=
\frac{\boldsymbol{p}}{m}\cdot
\frac{\partial}{\partial\boldsymbol{x}}
+\left(-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)\right)\cdot
\frac{\partial}{\partial\boldsymbol{p}}
```

は，変数 $t_c$ には依存しない．
そのため，この演算子を $t_c$ に関する積分の外に出すことができる．
したがって，

```math
\begin{aligned}
&\int_{-\infty}^{t}
\frac{\partial f_{t_c}}{\partial t}
\frac{e^{-(t-t_c)/\tau}}{\tau}\,dt_c\\
&\qquad=-\mathcal L_t
\int_{-\infty}^{t}
f_{t_c}\frac{e^{-(t-t_c)/\tau}}{\tau}\,dt_c\\
&\qquad=-\mathcal L_t\bar f
\end{aligned}
\tag{7}
```

となる．
ここでは，式 (4) で定義した平均分布関数を用いた．

式 (7) を式 (5) に代入すると，

```math
\frac{\partial\bar f}{\partial t}
=\frac{f_0}{\tau}-\mathcal L_t\bar f
-\frac{\bar f}{\tau}
```

を得る．
移流項を左辺に移し，右辺を整理すると，

```math
\frac{\partial\bar f}{\partial t}
+\mathcal L_t\bar f
=-\frac{\bar f-f_0}{\tau}
```

となる．
演算子 $\mathcal L_t$ を元の形に戻せば，

```math
\boxed{
\begin{aligned}
\frac{\partial\bar f}{\partial t}
&+\frac{\boldsymbol{p}}{m}\cdot
\frac{\partial\bar f}{\partial\boldsymbol{x}}\\
&+\left\{-m\omega_0^2\boldsymbol{x}
-e\boldsymbol{E}(t)\right\}\cdot
\frac{\partial\bar f}{\partial\boldsymbol{p}}
=-\frac{\bar f-f_0}{\tau}
\end{aligned}
}
```

となり，問題で示すべき式が得られた．

### 6．結果の意味

導出された式の左辺は，衝突がない場合に電子の分布関数が運動に伴って変化する効果を表す．
右辺は，衝突によって分布関数が衝突直後の分布 $f_0$ に緩和する効果を表している．

衝突の平均自由時間 $\tau$ が大きければ，衝突による緩和は遅くなる．
逆に， $\tau$ が小さければ，分布関数は短時間で $f_0$ に近づく．
このような形の衝突項を持つ Boltzmann 方程式は，衝突によって分布が指定された形へ緩和するという仮定に基づくものである．
