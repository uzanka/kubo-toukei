# 演習問題【10-R-2】

## 解答

### 1．衝突断面積と衝突頻度

半径 $a$ ，質量 $m$ の分子が Maxwell の速度分布に従う希薄気体を考える．
分子数密度を $n$ ，絶対温度を $T$ とする．
まず，特定の一分子が単位時間あたりに他の分子と衝突する平均回数，すなわち衝突頻度 $z$ を求める．

分子同士は半径 $a$ の弾性球とみなされるため，二つの分子の中心間距離が $2a$ 以下になると衝突する．
したがって，二分子の衝突断面積は

```math
\boxed{\sigma=\pi(2a)^2=4\pi a^2}
\tag{1}
```

である．

二つの分子の速度をそれぞれ $\boldsymbol v_1$ ， $\boldsymbol v_2$ とすると，相対速度ベクトルは

```math
\boldsymbol u=\boldsymbol v_2-\boldsymbol v_1
```

であり，その大きさを $u=|\boldsymbol u|$ とする．
相対速度が一定であると仮定すると，時間 $dt$ の間に，二分子は衝突断面積 $\sigma$ を底面積とし，高さ $u\,dt$ をもつ円柱状の領域を相対的に通過する．
この領域の体積は

```math
dV=\sigma u\,dt
\tag{2}
```

である．
数密度が $n$ であるため，この領域内に存在する分子の平均数は $n\sigma u\,dt$ となる．
したがって，相対速度が $u$ である場合の単位時間あたりの衝突頻度は $n\sigma u$ である．

実際には分子の速度は Maxwell 分布に従い，衝突ごとに相対速度も異なる．
そのため，相対速度の大きさについて平均を取る必要がある．
相対速度の平均を $\overline{u}$ とすれば，

```math
\boxed{z=n\sigma\overline{u}}
\tag{3}
```

となる．
ここで， $\overline{u}$ は二分子の相対速度の大きさの平均であり，一つの分子の平均速度とは異なる量である．

### 2．相対速度の平均

分子の速度が Maxwell 分布に従うとき，速度の各直交成分は平均ゼロ，分散 $kT/m$ の独立な Gaussian 分布に従う．
二分子の相対速度の各成分は速度成分の差であるため，その平均はゼロ，分散は

```math
\begin{aligned}
\langle u_x^2\rangle
&=\langle(v_{2x}-v_{1x})^2\rangle\\
&=\langle v_{2x}^2\rangle+\langle v_{1x}^2\rangle\\
&=\frac{kT}{m}+\frac{kT}{m}
=\frac{2kT}{m}
\end{aligned}
\tag{4}
```

となる．
ここでは，二分子の速度が互いに独立であり，それぞれの速度成分の平均がゼロであることを用いた．
他の二方向の成分についても同様である．

この相対速度分布は，換算質量

```math
m_r=\frac{m\,m}{m+m}=\frac{m}{2}
\tag{5}
```

をもつ Maxwell 分布と同じ形になる．
相対速度の大きさ $u$ に関する確率密度は，

```math
f_{\mathrm{rel}}(u)
=4\pi u^2
\left(\frac{m_r}{2\pi kT}\right)^{3/2}
\exp\left(-\frac{m_r u^2}{2kT}\right)
\tag{6}
```

である．
ここで $f_{\mathrm{rel}}(u)\,du$ は，相対速度の大きさが $u$ から $u+du$ の間にある確率を表す．

この分布から相対速度の平均を計算すると，

```math
\overline{u}
=\int_0^\infty u\,f_{\mathrm{rel}}(u)\,du
=\sqrt{\frac{8kT}{\pi m_r}}
\tag{7}
```

となる．
式 (5) の $m_r=m/2$ を代入すれば，

```math
\boxed{\overline{u}
=\sqrt{\frac{16kT}{\pi m}}}
\tag{8}
```

を得る．

一方，一つの分子の速度の大きさの平均は，通常の Maxwell 分布から

```math
\boxed{\overline{v}=\sqrt{\frac{8kT}{\pi m}}}
\tag{9}
```

である．
したがって，

```math
\boxed{\overline{u}=\sqrt{2}\,\overline{v}}
\tag{10}
```

が成り立つ．
この $\sqrt{2}$ は，衝突頻度を求める際に分子自身の速度だけでなく，相手の分子の速度も考慮することから生じる．

### 3．平均自由時間

平均自由時間 $\tau$ は，特定の分子が連続する二つの衝突の間に過ごす時間の平均である．
衝突頻度 $z$ は単位時間あたりの平均衝突回数なので，平均自由時間はその逆数となる．

```math
\tau=\frac{1}{z}
```

式 (3)，(8) を代入すると，

```math
\begin{aligned}
\tau
&=\frac{1}{n\sigma\overline{u}}\\
&=\frac{1}{n\sigma}
\sqrt{\frac{\pi m}{16kT}}
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
\tau=\frac{1}{4n\sigma}
\sqrt{\frac{\pi m}{kT}}
}
\tag{11}
```

である．
ここで $\sigma=4\pi a^2$ を用いれば，平均自由時間が数密度 $n$ と分子の衝突断面積 $\sigma$ が大きいほど短くなり，温度 $T$ が高いほど短くなることが分かる．

### 4．平均自由行程

平均自由行程 $l$ は，分子が連続する二つの衝突の間に進む距離の平均である．
気体分子の平均の速さを $\overline v$ とすると，

```math
l=\overline v\,\tau
\tag{12}
```

と表される．
式 (9)，(11) を代入すると，

```math
\begin{aligned}
l
&=\sqrt{\frac{8kT}{\pi m}}\,
\frac{1}{4n\sigma}
\sqrt{\frac{\pi m}{kT}}\\
&=\frac{1}{4n\sigma}\sqrt{8}\\
&=\frac{1}{\sqrt{2}\,n\sigma}
\end{aligned}
```

となる．
ゆえに，

```math
\boxed{l=\frac{1}{\sqrt{2}\,n\sigma}}
\tag{13}
```

である．
さらに， $\sigma=4\pi a^2$ を代入すると，

```math
\boxed{l=\frac{1}{4\sqrt{2}\,\pi n a^2}}
\tag{14}
```

を得る．
これが，Maxwell の速度分布に従う希薄気体の平均自由行程である．

### 5．標準状態の $\mathrm{N_2}$ 気体の数値計算

温度 $T=273.15\,\mathrm K$ ，圧力 $p=1\,\mathrm{atm}=1.01325\times10^5\,\mathrm{Pa}$ の窒素気体を考える．
与えられた分子半径は

```math
a=1.90\,\text{\AA}=1.90\times10^{-10}\,\mathrm m
```

である．

#### (1) 分子数密度

理想気体の状態方程式は

```math
p=nkT
```

であるから，

```math
n=\frac{p}{kT}
```

となる．
Boltzmann 定数 $k=1.380649\times10^{-23}\,\mathrm{J/K}$ を用いると，

```math
\begin{aligned}
n
&=\frac{1.01325\times10^5}
{(1.380649\times10^{-23})(273.15)}\\
&\simeq2.69\times10^{25}\,\mathrm{m^{-3}}
\end{aligned}
\tag{15}
```

である．

#### (2) 衝突断面積

式 (1) より，

```math
\begin{aligned}
\sigma
&=4\pi a^2\\
&=4\pi(1.90\times10^{-10})^2\\
&\simeq4.54\times10^{-19}\,\mathrm{m^2}
\end{aligned}
\tag{16}
```

となる．

#### (3) 分子の質量と平均速度

窒素分子のモル質量を $M=0.0280\,\mathrm{kg/mol}$ ，Avogadro 定数を $N_A=6.02214\times10^{23}\,\mathrm{mol^{-1}}$ とすると，一分子の質量は

```math
m=\frac{M}{N_A}
\simeq4.65\times10^{-26}\,\mathrm{kg}
\tag{17}
```

である．
式 (9) より，分子の平均速度は

```math
\begin{aligned}
\overline v
&=\sqrt{\frac{8kT}{\pi m}}\\
&\simeq4.54\times10^2\,\mathrm{m/s}
\end{aligned}
\tag{18}
```

となる．
したがって，

```math
\boxed{\overline v\simeq454\,\mathrm{m/s}}
```

である．

#### (4) 平均自由行程

式 (13) に数密度と衝突断面積を代入すると，

```math
\begin{aligned}
l
&=\frac{1}{\sqrt{2}\,n\sigma}\\
&=\frac{1}
{\sqrt{2}(2.69\times10^{25})(4.54\times10^{-19})}\\
&\simeq5.80\times10^{-8}\,\mathrm m
\end{aligned}
```

となる．
よって，

```math
\boxed{l\simeq5.8\times10^{-8}\,\mathrm m
=5.8\times10^{-6}\,\mathrm{cm}}
\tag{19}
```

である．

#### (5) 平均自由時間

平均自由時間は $\tau=l/\overline v$ であるから，

```math
\begin{aligned}
\tau
&=\frac{5.80\times10^{-8}}{454}\\
&\simeq1.28\times10^{-10}\,\mathrm s
\end{aligned}
```

となる．
したがって，

```math
\boxed{\tau\simeq1.3\times10^{-10}\,\mathrm s}
\tag{20}
```

である．

### 6．結論

求める平均自由時間および平均自由行程は，

```math
\boxed{
\tau=\frac{1}{4n\sigma}
\sqrt{\frac{\pi m}{kT}},
\qquad
l=\frac{1}{\sqrt{2}\,n\sigma},
\qquad
\sigma=4\pi a^2
}
```

である．
標準状態の窒素気体については，

```math
\boxed{
\tau\simeq1.3\times10^{-10}\,\mathrm s,
\qquad
l\simeq5.8\times10^{-8}\,\mathrm m
}
```

を得る．
平均自由行程は分子数密度と衝突断面積に反比例するため，気体の密度が高いほど，また分子が大きいほど短くなる．
