# 演習問題【10-A-2】

## 解答

### $T-p$ 分布を用いたエネルギーと体積のゆらぎの導出

#### 1．4T-p$ 分布から確率分布を導く

分子数が一定の部分系を考え，その部分系が温度 $T^*$ ，圧力 $p^*$ の外界と熱および体積変化に伴う仕事をやり取りしているとする．
部分系のエネルギーを $E$ ，体積を $V$ ，状態密度を $\Omega(E,V)$ とする．
状態密度は，エネルギーと体積がそれぞれ $E,V$ である状態の数を表す量である．
エントロピーは

```math
S(E,V)=k\log\Omega(E,V)
\tag{1}
```

で定義される．
ここで $k$ はボルツマン定数である．

外界の温度と圧力が一定であるとき，部分系がエネルギー $E$ ，体積 $V$ をとる確率密度は， $T-p$ 分布より，

```math
P(E,V)=C\,\Omega(E,V)
\exp\left[-\frac{E+p^*V}{kT^*}\right]
\tag{2}
```

と表される．
ここで $C$ は規格化定数である．
式 (1) を用いると，

```math
P(E,V)
=C\exp\left[
\frac{S(E,V)}{k}
-\frac{E+p^*V}{kT^*}
\right]
\tag{3}
```

となる．

##### 1.1．平衡条件

式 (3) の指数を最大にする $E,V$ が，確率の最も高い平衡状態を与える．
したがって，平衡値 $E^*,V^*$ は，

```math
\left(\frac{\partial S}{\partial E}\right)^*
=\frac{1}{T^*},
\qquad
\left(\frac{\partial S}{\partial V}\right)^*
=\frac{p^*}{T^*}
\tag{4}
```

を満たす．
実際，熱力学の関係式

```math
\left(\frac{\partial S}{\partial E}\right)_V
=\frac1T,
\qquad
\left(\frac{\partial S}{\partial V}\right)_E
=\frac pT
```

から，式 (4) は部分系と外界の温度および圧力が一致する条件であることが分かる．

##### 1.2．平衡値の近傍で二次まで展開する

平衡値からのずれを

```math
\Delta E=E-E^*,
\qquad
\Delta V=V-V^*
```

とする．
エントロピーを平衡点のまわりで Taylor 展開すると，

```math
\begin{aligned}
S(E,V)={}&S^*
+\left(\frac{\partial S}{\partial E}\right)^*\Delta E
+\left(\frac{\partial S}{\partial V}\right)^*\Delta V\\
&+\frac12\biggl[
\left(\frac{\partial^2S}{\partial E^2}\right)^*(\Delta E)^2
+2\left(\frac{\partial^2S}{\partial E\partial V}\right)^*
\Delta E\Delta V\\
&\qquad\quad
+\left(\frac{\partial^2S}{\partial V^2}\right)^*(\Delta V)^2
\biggr]+\cdots
\end{aligned}
\tag{5}
```

となる．
この式を確率分布 (3) に代入する．
式 (4) によって， $\Delta E,\Delta V$ に比例する一次の項は，指数に含まれる $-(E+p^*V)/(kT^*)$ の一次の項と相殺する．
その結果，二次までの近似では，

```math
\boxed{
\begin{aligned}
P(\Delta E,\Delta V)=C'\exp\biggl[
\frac{1}{2k}\biggl\{
&\left(\frac{\partial^2S}{\partial E^2}\right)^*(\Delta E)^2\\
&+2\left(\frac{\partial^2S}{\partial E\partial V}\right)^*
\Delta E\Delta V\\
&+\left(\frac{\partial^2S}{\partial V^2}\right)^*(\Delta V)^2
\biggr\}
\biggr]
\end{aligned}
}
\tag{6}
```

を得る．
$C'$ は新たな規格化定数である．
安定な平衡点では，この二次形式は負定値であるため，式 (6) は二変数の Gaussian 分布を表す．

##### 1.3．前問の (i) の確率分布を再現する

前問と同じ形にするため，次の量を導入する．

```math
\theta=\frac1T,
\qquad
\pi=\frac pT
\tag{7}
```

エントロピーの微分関係から，

```math
\theta=\frac{\partial S}{\partial E},
\qquad
\pi=\frac{\partial S}{\partial V}
```

である．
したがって，式 (6) の指数に含まれる二次形式を $Q$ とすると，

```math
\begin{aligned}
Q={}&
\left(\frac{\partial^2S}{\partial E^2}\right)^*(\Delta E)^2
+2\left(\frac{\partial^2S}{\partial E\partial V}\right)^*
\Delta E\Delta V\\
&+\left(\frac{\partial^2S}{\partial V^2}\right)^*(\Delta V)^2
\end{aligned}
```

であり，これは一次の変化を用いて，

```math
Q=\Delta E\,\Delta\theta+\Delta V\,\Delta\pi
\tag{8}
```

と書ける．
ここで，

```math
\Delta\theta=-\frac{\Delta T}{(T^*)^2},
\qquad
\Delta\pi=\frac{\Delta p}{T^*}
-\frac{p^*\Delta T}{(T^*)^2}
\tag{9}
```

である．
また，エントロピーの一次変化は，

```math
\Delta S
=\frac{\Delta E+p^*\Delta V}{T^*}
\tag{10}
```

となる．
式 (9)，(10) を式 (8) に代入すると，

```math
\begin{aligned}
Q
&=-\frac{\Delta T}{(T^*)^2}\Delta E
+\left(\frac{\Delta p}{T^*}
-\frac{p^*\Delta T}{(T^*)^2}\right)\Delta V\\
&=\frac{1}{T^*}
\left(\Delta p\Delta V-\Delta T\Delta S\right)
\end{aligned}
\tag{11}
```

を得る．
したがって，式 (6) は，

```math
\boxed{
P=C'\exp\left[
\frac{\Delta p\Delta V-\Delta T\Delta S}{2kT^*}
\right]
}
\tag{12}
```

と書き換えられる．
これは前問の (i) で求めた一般形である．
よって， $T-p$ 分布を用いて前問の (i) が再現された．

#### 2．分散共分散行列を求める

エネルギーと体積のゆらぎの分散共分散行列を

```math
\boldsymbol{\Sigma}
=
\begin{pmatrix}
\overline{(\Delta E)^2}&\overline{\Delta E\Delta V}\\
\overline{\Delta E\Delta V}&\overline{(\Delta V)^2}
\end{pmatrix}
\tag{13}
```

とする．
Gaussian 分布の標準形は，

```math
P(\boldsymbol x)\propto
\exp\left(-\frac12\boldsymbol x^{\mathsf T}
\boldsymbol{\Sigma}^{-1}\boldsymbol x\right)
```

である．
これと式 (6) を比較すると，

```math
\boldsymbol{\Sigma}^{-1}
=-\frac1k
\begin{pmatrix}
\left(\dfrac{\partial^2S}{\partial E^2}\right)^*
&
\left(\dfrac{\partial^2S}{\partial E\partial V}\right)^*
\\
\left(\dfrac{\partial^2S}{\partial V\partial E}\right)^*
&
\left(\dfrac{\partial^2S}{\partial V^2}\right)^*
\end{pmatrix}
```

となる．
したがって，

```math
\boxed{\boldsymbol{\Sigma}=-kH_S^{-1}}
\tag{14}
```

である．
ここで $H_S$ はエントロピーの二階微分行列である．

式 (7) より，

```math
H_S
=\frac{\partial(\theta,\pi)}{\partial(E,V)}
```

であるから，逆行列の関係を用いて，

```math
\boxed{
\boldsymbol{\Sigma}
=-k
\begin{pmatrix}
\left(\dfrac{\partial E}{\partial\theta}\right)_\pi&
\left(\dfrac{\partial E}{\partial\pi}\right)_\theta\\
\left(\dfrac{\partial V}{\partial\theta}\right)_\pi&
\left(\dfrac{\partial V}{\partial\pi}\right)_\theta
\end{pmatrix}
}
\tag{15}
```

と表せる．
以下では，すべての熱力学量と偏微分を平衡値で評価するものとし，必要に応じて上付きの $^*$ を省略する．

#### 3．体積ゆらぎ $\overline{(\Delta V)^2}$

式 (15) の右下成分から，

```math
\overline{(\Delta V)^2}
=-k\left(\frac{\partial V}{\partial\pi}\right)_\theta
\tag{16}
```

である．
$\theta=1/T$ 一定は温度一定を意味する．
また， $\pi=p/T$ であるから，温度一定では，

```math
\left(\frac{\partial V}{\partial\pi}\right)_\theta
=T\left(\frac{\partial V}{\partial p}\right)_T
```

となる．
したがって，

```math
\boxed{
\overline{(\Delta V)^2}
=-kT^*\left(\frac{\partial V}{\partial p}\right)_{T^*}
}
\tag{17}
```

を得る．

等温圧縮率を

```math
\kappa_T=-\frac1V
\left(\frac{\partial V}{\partial p}\right)_T
\tag{18}
```

と定義すると，

```math
\boxed{
\overline{(\Delta V)^2}
=kT^*V^*\kappa_T^*
}
\tag{19}
```

となる．
安定な単相状態では $\kappa_T^*>0$ であるため，体積ゆらぎの分散も正である．

#### 4．エネルギーと体積の共分散 $\overline{\Delta E\Delta V}$

式 (15) の非対角成分から，

```math
\overline{\Delta E\Delta V}
=-k\left(\frac{\partial E}{\partial\pi}\right)_\theta
\tag{20}
```

である．
温度を一定に保つと $p=T\pi$ なので，

```math
\left(\frac{\partial E}{\partial\pi}\right)_\theta
=T\left(\frac{\partial E}{\partial p}\right)_T
```

となる．
さらに，連鎖律を用いると，

```math
\left(\frac{\partial E}{\partial p}\right)_T
=
\left(\frac{\partial E}{\partial V}\right)_T
\left(\frac{\partial V}{\partial p}\right)_T
```

である．
よって，

```math
\overline{\Delta E\Delta V}
=-kT\left(\frac{\partial E}{\partial V}\right)_T
\left(\frac{\partial V}{\partial p}\right)_T
\tag{21}
```

を得る．

ここで，内部エネルギーの微分関係

```math
dE=T\,dS-p\,dV
```

を用いる．
温度一定のもとでは，

```math
\left(\frac{\partial E}{\partial V}\right)_T
=T\left(\frac{\partial S}{\partial V}\right)_T-p
\tag{22}
```

である．
Maxwell の関係式

```math
\left(\frac{\partial S}{\partial V}\right)_T
=\left(\frac{\partial p}{\partial T}\right)_V
```

より，

```math
\boxed{
\left(\frac{\partial E}{\partial V}\right)_T
=T\left(\frac{\partial p}{\partial T}\right)_V-p
}
\tag{23}
```

となる．
式 (21) に式 (23) と， $(\partial V/\partial p)_T=-V\kappa_T$ を代入すれば，

```math
\boxed{
\overline{\Delta E\Delta V}
=kT^*V^*\kappa_T^*
\left[
T^*\left(\frac{\partial p}{\partial T}\right)_{V^*}
-p^*
\right]
}
\tag{24}
```

を得る．
ここで， $V^*$ は平衡体積であり，偏微分は平衡状態で評価している．

同じ結果は，

```math
\boxed{
\overline{\Delta E\Delta V}
=kT^*\left[
T^*\left(\frac{\partial V}{\partial T}\right)_{p^*}
+p^*\left(\frac{\partial V}{\partial p}\right)_{T^*}
\right]
}
\tag{25}
```

とも表せる．
これは，式 (24) と連鎖律の関係から得られる表現である．

この共分散は，エネルギーが体積に依存する場合に一般にはゼロではない．
一方，理想気体の内部エネルギーは体積に依存しないため，式 (24) から共分散はゼロとなる．

#### 5．エネルギーゆらぎ $\overline{(\Delta E)^2}$

式 (15) の左上成分から，

```math
\overline{(\Delta E)^2}
=-k\left(\frac{\partial E}{\partial\theta}\right)_\pi
\tag{26}
```

である．
ここでは， $\pi=p/T$ を一定に保つことに注意する必要がある．
この条件のもとでは，

```math
p=\pi T
```

であるから，

```math
\left(\frac{\partial p}{\partial T}\right)_\pi
=\frac pT
\tag{27}
```

となる．
また， $\theta=1/T$ より，

```math
\left(\frac{\partial T}{\partial\theta}\right)_\pi=-T^2
```

である．
したがって，連鎖律によって，

```math
\begin{aligned}
\left(\frac{\partial E}{\partial\theta}\right)_\pi
&=-T^2\left[
\left(\frac{\partial E}{\partial T}\right)_p
+\frac pT\left(\frac{\partial E}{\partial p}\right)_T
\right]
\end{aligned}
```

を得る．
式 (26) に代入すると，

```math
\boxed{
\overline{(\Delta E)^2}
=kT^2\left[
\left(\frac{\partial E}{\partial T}\right)_p
+\frac pT\left(\frac{\partial E}{\partial p}\right)_T
\right]
}
\tag{28}
```

となる．

この式を定積熱容量 $C_V$ を用いた形に整理する．
定積熱容量の定義は，

```math
C_V=\left(\frac{\partial E}{\partial T}\right)_V
\tag{29}
```

である．
連鎖律から，

```math
\left(\frac{\partial E}{\partial T}\right)_p
=C_V+\left(\frac{\partial E}{\partial V}\right)_T
\left(\frac{\partial V}{\partial T}\right)_p
\tag{30}
```

および

```math
\left(\frac{\partial E}{\partial p}\right)_T
=\left(\frac{\partial E}{\partial V}\right)_T
\left(\frac{\partial V}{\partial p}\right)_T
\tag{31}
```

が成り立つ．
式 (30)，(31) を式 (28) に代入すると，

```math
\begin{aligned}
\overline{(\Delta E)^2}
=kT^2\biggl[
C_V
+\left(\frac{\partial E}{\partial V}\right)_T
\left\{
\left(\frac{\partial V}{\partial T}\right)_p
+\frac pT\left(\frac{\partial V}{\partial p}\right)_T
\right\}
\biggr]
\end{aligned}
\tag{32}
```

となる．

状態方程式 $p=p(T,V)$ を微分すれば，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=-\frac{(\partial p/\partial T)_V}
{(\partial p/\partial V)_T},
\qquad
\left(\frac{\partial V}{\partial p}\right)_T
=\frac{1}{(\partial p/\partial V)_T}
\tag{33}
```

である．
これを用いると，式 (32) の波括弧内は，

```math
\begin{aligned}
\left(\frac{\partial V}{\partial T}\right)_p
+\frac pT\left(\frac{\partial V}{\partial p}\right)_T
&=\frac{-T(\partial p/\partial T)_V+p}
{T(\partial p/\partial V)_T}\\
&=-\frac{1}{T}
\frac{(\partial E/\partial V)_T}
{(\partial p/\partial V)_T}
\end{aligned}
\tag{34}
```

と書ける．
さらに，式 (18) から，

```math
-\frac{1}{(\partial p/\partial V)_T}
=V\kappa_T
\tag{35}
```

である．
したがって，式 (32) は，

```math
\boxed{
\overline{(\Delta E)^2}
=k(T^*)^2C_V^*
+kT^*V^*\kappa_T^*
\left[
\left(\frac{\partial E}{\partial V}\right)_{T^*}
\right]^2
}
\tag{36}
```

となる．
式 (23) を用いれば，最後の因子は

```math
\left[
T^*\left(\frac{\partial p}{\partial T}\right)_{V^*}
-p^*
\right]^2
```

とも表せる．

この結果の第1項は，体積を固定したときの内部エネルギーのゆらぎに対応する．
第2項は，体積がゆらぐことによって内部エネルギーも変化する効果を表す．
理想気体のように内部エネルギーが体積に依存しない場合は，第2項が消え，

```math
\overline{(\Delta E)^2}=k(T^*)^2C_V^*
```

となる．

#### 6．最終結果

前問の (i) の確率分布は，

```math
\boxed{
P=C'\exp\left[
\frac{\Delta p\Delta V-\Delta T\Delta S}{2kT^*}
\right]
}
```

である．
また，エネルギーと体積のゆらぎについて，

```math
\boxed{
\overline{(\Delta V)^2}
=kT^*V^*\kappa_T^*
}
```

```math
\boxed{
\overline{\Delta E\Delta V}
=kT^*V^*\kappa_T^*
\left(\frac{\partial E}{\partial V}\right)_{T^*}
}
```

```math
\boxed{
\overline{(\Delta E)^2}
=k(T^*)^2C_V^*
+kT^*V^*\kappa_T^*
\left[
\left(\frac{\partial E}{\partial V}\right)_{T^*}
\right]^2
}
```

となる．
ここで，

```math
\left(\frac{\partial E}{\partial V}\right)_{T^*}
=T^*\left(\frac{\partial p}{\partial T}\right)_{V^*}-p^*
```

である．
以上により， $T-p$ 分布を用いて前問の確率分布を導出し，エネルギーと体積の分散および共分散を熱力学量で表すことができたのである．
