# 演習問題【10-A-8】

## 解答

### 半導体の伝導電子の電気伝導率

#### 1．Boltzmann 方程式を用いた電気伝導率の導出

縮退していない伝導電子に対しては，平衡分布関数を Maxwell–Boltzmann 分布で近似できる．
電子のエネルギーは

```math
\epsilon(\boldsymbol p)=\frac{p^2}{2m^*}
```

であり，群速度は

```math
\boldsymbol v=\frac{\partial\epsilon}{\partial\boldsymbol p}
=\frac{\boldsymbol p}{m^*}
\tag{1}
```

である．
ここで $m^*$ は電子の有効質量である．

緩和時間近似における Boltzmann 方程式は，

```math
\frac{\partial f}{\partial t}
+\boldsymbol v\cdot\frac{\partial f}{\partial\boldsymbol x}
-e\boldsymbol E\cdot\frac{\partial f}{\partial\boldsymbol p}
=-\frac{f-f_0}{\tau}
\tag{2}
```

である．
ここで，電子の電荷は $-e$ ， $f$ は電場中の分布関数， $f_0$ は平衡分布関数， $\boldsymbol E$ は電場， $\tau$ は緩和時間である．
緩和時間は，電子の散乱によって非平衡な分布が平衡分布に戻る時間の尺度である．

電場は一様であり，定常状態を考えるため，時間微分と空間微分はゼロになる．
したがって，

```math
-e\boldsymbol E\cdot\frac{\partial f}{\partial\boldsymbol p}
=-\frac{f-f_0}{\tau}
\tag{3}
```

となる．
電場が十分に弱いとして，

```math
f=f_0+f_1
```

とおく．
ここで $f_1$ は電場に比例する一次の補正である．
式 (3) の右辺では $f-f_0=f_1$ なので，電場に関して一次まで考えると，

```math
\boxed{
f_1=e\tau(\boldsymbol v)\,
\boldsymbol E\cdot\frac{\partial f_0}{\partial\boldsymbol p}
}
\tag{4}
```

を得る．

#### 2．Maxwell–Boltzmann 分布を代入する

縮退していない電子の平衡分布は，

```math
f_0(\epsilon)=
\exp\left(\frac{\mu-\epsilon}{k_{\mathrm B}T}\right)
\tag{5}
```

と表される．
ここで $\mu$ は化学ポテンシャル， $k_{\mathrm B}$ は Boltzmann 定数， $T$ は絶対温度である．
式 (5) をエネルギーで微分すると，

```math
\frac{\partial f_0}{\partial\epsilon}
=-\frac{f_0}{k_{\mathrm B}T}
\tag{6}
```

となる．
また，連鎖律と式 (1) により，

```math
\frac{\partial f_0}{\partial\boldsymbol p}
=\frac{\partial f_0}{\partial\epsilon}
\frac{\partial\epsilon}{\partial\boldsymbol p}
=-\frac{f_0}{k_{\mathrm B}T}\boldsymbol v
\tag{7}
```

である．
したがって，式 (4) は

```math
\boxed{
f_1=-\frac{e\tau(\boldsymbol v)}{k_{\mathrm B}T}
(\boldsymbol E\cdot\boldsymbol v)f_0
}
\tag{8}
```

となる．

#### 3．電流密度から電気伝導率を求める

電子の電荷が $-e$ であるため，電流密度は

```math
\boldsymbol j
=-e\int\boldsymbol v f(\boldsymbol p)
\frac{d^3p}{(2\pi\hbar)^3}
\tag{9}
```

と表せる．
平衡分布 $f_0$ は運動量について対称であり，その平均速度はゼロであるため，平衡分布からの電流は生じない．
よって，

```math
\boldsymbol j
=-e\int\boldsymbol v f_1
\frac{d^3p}{(2\pi\hbar)^3}
\tag{10}
```

である．
式 (8) を代入すると，成分表示で

```math
j_i=\frac{e^2}{k_{\mathrm B}T}E_j
\int\tau(\boldsymbol v)v_i v_j f_0
\frac{d^3p}{(2\pi\hbar)^3}
\tag{11}
```

を得る．
ここでは，同じ添字 $j$ について和を取っている．

放物線型バンドでは速度分布は等方的であるため，方向による平均の違いはなく，

```math
\int\tau(v)v_i v_j f_0\,d^3p
=\frac{\delta_{ij}}3
\int\tau(v)v^2f_0\,d^3p
\tag{12}
```

が成り立つ．
ここで $\delta_{ij}$ は $i=j$ のとき1，それ以外では0となる Kronecker のデルタである．
したがって，

```math
\boldsymbol j=\sigma\boldsymbol E
```

における電気伝導率は，

```math
\boxed{
\sigma=\frac{e^2}{3k_{\mathrm B}T}
\int_0^\infty\tau(v)v^2f_0(\epsilon)
D(\epsilon)\,d\epsilon
}
\tag{13}
```

となる．
これは解答例と同じ電気伝導率の式である．
ここで $D(\epsilon)$ は単位体積・単位エネルギーあたりの状態密度であり，スピンの縮退度は状態密度に含めるものとする．

電子数密度を

```math
n=\int_0^\infty f_0(\epsilon)D(\epsilon)\,d\epsilon
\tag{14}
```

と定義し，平衡分布による平均を $\langle\cdots\rangle$ で表すと，式 (13) は，

```math
\boxed{
\sigma=\frac{ne^2}{3k_{\mathrm B}T}
\langle\tau(v)v^2\rangle
}
\tag{15}
```

とも書ける．

#### 4．緩和時間 $\tau=Av^s$ を代入する

問題の仮定は，

```math
\tau(v)=Av^s,\qquad A>0
\tag{16}
```

である．
これを式 (15) に代入すると，

```math
\boxed{
\sigma=\frac{ne^2A}{3k_{\mathrm B}T}
\langle v^{s+2}\rangle
}
\tag{17}
```

を得る．
したがって，必要なのは Maxwell–Boltzmann 分布における速度のモーメント $\langle v^{s+2}\rangle$ である．

速度の大きさ $v=|\boldsymbol v|$ の確率密度は，

```math
P(v)=4\pi
\left(\frac{m^*}{2\pi k_{\mathrm B}T}\right)^{3/2}
v^2\exp\left(-\frac{m^*v^2}{2k_{\mathrm B}T}\right)
\tag{18}
```

である．
この分布は $\int_0^\infty P(v)\,dv=1$ となるように規格化されている．
したがって，

```math
\begin{aligned}
\langle v^{s+2}\rangle
={}&\int_0^\infty v^{s+2}P(v)\,dv\\
={}&4\pi\left(\frac{m^*}{2\pi k_{\mathrm B}T}\right)^{3/2}
\int_0^\infty v^{s+4}
\exp\left(-\frac{m^*v^2}{2k_{\mathrm B}T}\right)\,dv
\end{aligned}
\tag{19}
```

となる．

ここで，次のガンマ関数の積分公式を用いる．

```math
\int_0^\infty x^{\mu-1}e^{-\beta x^2}\,dx
=\frac12\beta^{-\mu/2}
\Gamma\left(\frac{\mu}{2}\right),
\qquad \beta>0
\tag{20}
```

式 (19) では，

```math
\mu=s+5,\qquad
\beta=\frac{m^*}{2k_{\mathrm B}T}
```

とおけばよい．
積分を計算して係数を整理すると，

```math
\boxed{
\langle v^{s+2}\rangle
=\frac{2}{\sqrt{\pi}}
\left(\frac{2k_{\mathrm B}T}{m^*}\right)^{(s+2)/2}
\Gamma\left(\frac{s+5}{2}\right)
}
\tag{21}
```

を得る．
ここで $\Gamma(x)$ はガンマ関数である．

#### 5．電気伝導率の最終結果

式 (21) を式 (17) に代入すると，

```math
\boxed{
\sigma=
\frac{2ne^2A}{3\sqrt{\pi}\,k_{\mathrm B}T}
\left(\frac{2k_{\mathrm B}T}{m^*}\right)^{(s+2)/2}
\Gamma\left(\frac{s+5}{2}\right)
}
\tag{22}
```

となる．
同値な形として，

```math
\boxed{
\sigma=
\frac{ne^2A}{m^*}
\frac{4}{3\sqrt{\pi}}
\left(\frac{2k_{\mathrm B}T}{m^*}\right)^{s/2}
\Gamma\left(\frac{s+5}{2}\right)
}
\tag{23}
```

とも表せる．
これが求める電気伝導率である．

##### 5.1．緩和時間が一定の場合

$s=0$ ならば， $\tau=A$ は一定である．
このとき，

```math
\Gamma\left(\frac52\right)=\frac{3\sqrt{\pi}}4
```

を用いると，式 (23) は，

```math
\boxed{
\sigma=\frac{ne^2A}{m^*}
}
\tag{24}
```

となる．
$A=\tau$ であるため，これは Drude 型の結果

```math
\sigma=\frac{ne^2\tau}{m^*}
```

に一致する．

##### 5.2．平均自由行程が一定の場合

$s=-1$ ならば，

```math
\tau=\frac{A}{v}
```

であり，平均自由行程 $l=\tau v$ は一定で， $l=A$ となる．
式 (23) に $s=-1$ と $\Gamma(2)=1$ を代入すると，

```math
\sigma=\frac{ne^2}{m^*}
\frac{4}{3\sqrt{\pi}}
\left(\frac{2k_{\mathrm B}T}{m^*}\right)^{-1/2}l
\tag{25}
```

を得る．
平均速さ

```math
\bar v=\sqrt{\frac{8k_{\mathrm B}T}{\pi m^*}}
\tag{26}
```

を用いれば，

```math
\boxed{
\sigma=\frac{ne^2}{m^*}
\frac{l}{\bar v}\frac{8}{3\pi}
}
\tag{27}
```

となる．

なお，解答例の式 (8) にある係数 $4/(3\pi)$ は，式 (6) と同様に係数が $1/2$ だけ小さくなっており，正しくは $8/(3\pi)$ である．

#### 6．積分の収束条件について

式 (19) の被積分関数は $v\to0$ の極限で $v^{s+4}$ に比例する．
そのため，原点付近の積分

```math
\int_0^1 v^{s+4}\,dv
```

が収束する条件は，

```math
s+4>-1
```

すなわち，

```math
\boxed{s>-5}
\tag{28}
```

である．
同じことはエネルギー表示からも確認できる．
式 (13) の被積分関数は低エネルギーで

```math
\tau(v)v^2D(\epsilon)
\propto \epsilon^{s/2}\epsilon\epsilon^{1/2}
=\epsilon^{(s+3)/2}
```

に比例するため， $\int_0\epsilon^{(s+3)/2}\,d\epsilon$ が収束する条件も $s>-5$ である．

したがって，問題文の条件 $s>-7$ だけでは，有限の電気伝導率が得られることは保証されない．
追加の低速カットオフなどがない限り，式 (22)，(23) が通常の積分として有限値を与えるのは $s>-5$ の場合である．

以上より，Boltzmann 方程式と Maxwell–Boltzmann 分布を用いて電気伝導率を求めると，緩和時間が速度のべき $v^s$ に比例する場合の結果は式 (22) または式 (23) で与えられるのである．
