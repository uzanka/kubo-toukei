# 演習問題【10-A-8】

## 解答

電気伝導率 $\sigma$ を，Boltzmann 方程式を緩和時間近似で解き，Maxwell–Boltzmann 分布を用いて求める．

## 1. Boltzmann 方程式を解く

与えられた Boltzmann 方程式は

```math
\frac{\partial f}{\partial t} +\boldsymbol v\cdot\frac{\partial f}{\partial\boldsymbol x} -e\boldsymbol E\cdot\frac{\partial f}{\partial\boldsymbol p} =-\frac{f-f_0}{\tau}
```

である．

一様な電場中の定常状態を考えると，時間微分と空間微分はゼロとなるため，

```math
-e\boldsymbol E\cdot\frac{\partial f}{\partial\boldsymbol p} =-\frac{f-f_0}{\tau}
```

となる．
電場が十分弱いとして，分布関数を

```math
f=f_0+f_1
```

とおき， $f_1$ について一次まで考えると，

```math
\boxed{ f_1=e\tau\boldsymbol E\cdot \frac{\partial f_0}{\partial\boldsymbol p} }
```

を得る．

ここで，電子のエネルギーと速度の関係は

```math
\epsilon(\boldsymbol p)=\frac{p^2}{2m^*}, \qquad \boldsymbol v=\frac{\partial\epsilon}{\partial\boldsymbol p} =\frac{\boldsymbol p}{m^*}
```

である．
したがって，

```math
\frac{\partial f_0}{\partial\boldsymbol p} =\frac{\partial f_0}{\partial\epsilon}\boldsymbol v
```

より，

```math
\boxed{ f_1=e\tau(\boldsymbol v) (\boldsymbol E\cdot\boldsymbol v) \frac{\partial f_0}{\partial\epsilon} }
```

となる．

## 2. Maxwell–Boltzmann 分布を代入する

縮退していない伝導電子に対して，平衡分布関数は

```math
f_0(\epsilon)=C \exp\left(-\frac{\epsilon}{k\_{\mathrm B}T}\right)
```

と書ける．
ここで $C$ は規格化定数， $k\_{\mathrm B}$ は Boltzmann 定数， $T$ は絶対温度である．

これをエネルギーで微分すると，

```math
\frac{\partial f_0}{\partial\epsilon} =-\frac{f_0}{k\_{\mathrm B}T}
```

なので，

```math
\boxed{ f_1=-\frac{e\tau(\boldsymbol v)} {k\_{\mathrm B}T} (\boldsymbol E\cdot\boldsymbol v)f_0 }
```

となる．

## 3. 電流密度を計算する

電子の電荷は $-e$ （ $e>0$ ）なので，電流密度は

```math
\boldsymbol j=-e\int \boldsymbol v f(\boldsymbol p) \frac{d^3p}{(2\pi\hbar)^3}
```

である．
平衡分布 $f_0$ による電流は速度の対称性からゼロとなるため，

```math
\boldsymbol j=-e\int \boldsymbol v f_1 \frac{d^3p}{(2\pi\hbar)^3}
```

となる．
先ほどの $f_1$ を代入すると，

```math
j_i=\frac{e^2}{k\_{\mathrm B}T} E_j\int \tau(v)v_i v_j f_0 \frac{d^3p}{(2\pi\hbar)^3}
```

を得る．

等方的な放物線型バンドでは，

```math
\langle v_i v_j\rangle =\frac{v^2}{3}\delta\_{ij}
```

が成り立つ．
したがって，

```math
\boldsymbol j=\sigma\boldsymbol E
```

における電気伝導率は

```math
\boxed{ \sigma=\frac{e^2}{3k\_{\mathrm B}T} \int \tau(v)v^2 f_0 \frac{d^3p}{(2\pi\hbar)^3} }
```

である．

ここで電子密度を

```math
n=\int f_0\frac{d^3p}{(2\pi\hbar)^3}
```

と定義すれば，

```math
\boxed{ \sigma=\frac{ne^2}{3k\_{\mathrm B}T} \langle\tau(v)v^2\rangle }
```

と表せる．
ただし， $\langle\cdots\rangle$ は Maxwell–Boltzmann 分布による平均である．

## 4. 緩和時間 \\(\tau=Av^s\\) を代入する

問題の条件

```math
\tau(v)=Av^s
```

を用いると，

```math
\sigma=\frac{ne^2A}{3k\_{\mathrm B}T} \langle v^{s+2}\rangle
```

となる．
したがって，必要なのは速度のモーメント $\langle v^{s+2}\rangle$ の計算である．

Maxwell–Boltzmann 分布に従う三次元速度の大きさ $v$ の確率密度は，

```math
P(v)=4\pi \left(\frac{m^*}{2\pi k\_{\mathrm B}T}\right)^{3/2} v^2\exp\left(-\frac{m^*v^2}{2k\_{\mathrm B}T}\right)
```

である．
よって，

```math
\langle v^{s+2}\rangle =\int_0^\infty v^{s+2}P(v)\\,dv
```

```math
=4\pi\left(\frac{m^*}{2\pi k\_{\mathrm B}T}\right)^{3/2} \int_0^\infty v^{s+4} \exp\left(-\frac{m^*v^2}{2k\_{\mathrm B}T}\right)dv
```

となる．

ここで積分公式

```math
\int_0^\infty x^{\mu-1}e^{-\beta x^2}dx =\frac12\beta^{-\mu/2} \Gamma\left(\frac{\mu}{2}\right)
```

を用いる．
$\mu=s+5$ ， $\beta=m^*/(2k\_{\mathrm B}T)$ とおくと，

```math
\boxed{ \langle v^{s+2}\rangle =\frac{2}{\sqrt{\pi}} \left(\frac{2k\_{\mathrm B}T}{m^*}\right)^{(s+2)/2} \Gamma\left(\frac{s+5}{2}\right) }
```

を得る．

## 5. 電気伝導率の最終結果

上の式を電気伝導率に代入すると，

```math
\sigma= \frac{ne^2A}{3k\_{\mathrm B}T} \frac{2}{\sqrt{\pi}} \left(\frac{2k\_{\mathrm B}T}{m^*}\right)^{(s+2)/2} \Gamma\left(\frac{s+5}{2}\right)
```

したがって，求める電気伝導率は

```math
\boxed{ \displaystyle \sigma= \frac{2ne^2A}{3\sqrt{\pi}\\,k\_{\mathrm B}T} \left(\frac{2k\_{\mathrm B}T}{m^*}\right)^{\frac{s+2}{2}} \Gamma\left(\frac{s+5}{2}\right) }
```

である．

ここで $\Gamma(x)$ はガンマ関数である．

## 補足：条件 $s>-7$ について

上の計算で重要なのは，積分の収束条件である．
伝導率の速度積分は原点付近で

```math
\int_0 v^{s+4}\\,dv
```

の形になるため，収束条件は

```math
s+4>-1 \quad\Longrightarrow\quad \boxed{s>-5}
```

である．

したがって，問題文の $s>-7$ という条件だけでは，電気伝導率の積分の収束は保証されない．
通常の三次元 Maxwell–Boltzmann 分布を用いる限り，有限の電気伝導率を得るには $s>-5$ が必要である．
問題文の条件が $s>-7$ で正しい場合は，別の定義や追加条件があるか，問題文の条件に誤記がある可能性がある．
