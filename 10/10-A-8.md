# 演習問題【10-A-8】

## 解答

### 1．Boltzmann 方程式と線形応答

#### 1.1 エネルギーと群速度

縮退していない伝導電子の平衡分布は Maxwell–Boltzmann 分布で近似できる．
電子のエネルギーは

```math
\epsilon(\boldsymbol p)=\frac{p^2}{2m^*}
```

である．
したがって，群速度は

```math
\boldsymbol v
=
\frac{\partial\epsilon}{\partial\boldsymbol p}
=
\frac{\boldsymbol p}{m^*}
```

となる．
ここで $m^*$ は電子の有効質量である．
また，電子の電荷を $-e$ とし， $e>0$ とする．

以下では，単一の等方的な放物線型伝導帯を考え，スピン縮退度を

```math
g_s=2
```

とする．

#### 1.2 Boltzmann 方程式

速度依存の緩和時間を

```math
\tau(\boldsymbol v)=A|\boldsymbol v|^s,
\qquad A>0
```

とする．
緩和時間近似における Boltzmann 方程式は，

```math
\frac{\partial f}{\partial t}
+\boldsymbol v\cdot\nabla_{\boldsymbol x}f
-e\boldsymbol E\cdot\nabla_{\boldsymbol p}f
=
-\frac{f-f_0}{\tau(\boldsymbol v)}
```

である．
ここで， $f$ は非平衡状態の分布関数， $f_0$ は平衡状態の分布関数である．

均質なバルク半導体を考え，温度 $T$ ，化学ポテンシャル $\mu$ ，電子数密度 $n$ は空間的に一様であるとする．
また，電場は一様であり，定常状態を考える．
この条件のもとで，

```math
\frac{\partial f}{\partial t}=0,
\qquad
\nabla_{\boldsymbol x}f=0
```

となる．
したがって，

```math
-e\boldsymbol E\cdot\nabla_{\boldsymbol p}f
=
-\frac{f-f_0}{\tau(\boldsymbol v)}
```

を得る．

電場が十分に弱いとして，

```math
f=f_0+f_1
```

とおく．
ここで $f_1$ は電場に関する一次の補正である．
左辺では一次の精度で $f$ を $f_0$ に置き換えられるので，

```math
-e\boldsymbol E\cdot\nabla_{\boldsymbol p}f_0
=
-\frac{f_1}{\tau(\boldsymbol v)}
```

となる．
したがって，

```math
\boxed{
f_1
=
e\tau(\boldsymbol v)
\boldsymbol E\cdot\nabla_{\boldsymbol p}f_0
}
```

を得る．

### 2．Maxwell–Boltzmann 分布の代入

#### 2.1 状態占有数としての平衡分布

$f_0^{\mathrm{occ}}$ を1スピン状態あたりの占有数と定義する．
非縮退条件では，

```math
f_0^{\mathrm{occ}}(\epsilon)
=
\exp\left(
\frac{\mu-\epsilon}{k_{\mathrm B}T}
\right)
```

である．
ここで， $\mu$ は化学ポテンシャルであり，エネルギー $\epsilon$ は伝導帯下端を基準とする．

この分布をエネルギーで微分すると，

```math
\frac{\partial f_0^{\mathrm{occ}}}{\partial\epsilon}
=
-\frac{f_0^{\mathrm{occ}}}{k_{\mathrm B}T}
```

となる．
また，連鎖律と

```math
\nabla_{\boldsymbol p}\epsilon=\boldsymbol v
```

より，

```math
\nabla_{\boldsymbol p}f_0^{\mathrm{occ}}
=
-\frac{f_0^{\mathrm{occ}}}{k_{\mathrm B}T}
\boldsymbol v
```

である．

したがって，非平衡分布の一次補正は，

```math
\boxed{
f_1
=
-\frac{e\tau(\boldsymbol v)}{k_{\mathrm B}T}
(\boldsymbol E\cdot\boldsymbol v)
f_0^{\mathrm{occ}}
}
```

となる．

### 3．電流密度と電気伝導率

#### 3.1 スピン縮退度を含めた電流密度

電子の電荷が $-e$ なので，電流密度は，

```math
\boldsymbol j
=
-g_se
\int
\boldsymbol v f(\boldsymbol p)
\frac{d^3p}{(2\pi\hbar)^3}
```

である．
ここで， $f$ は1スピン状態あたりの占有数であり，スピン縮退度 $g_s=2$ は積分の外に明示している．

平衡分布 $f_0^{\mathrm{occ}}$ は運動量について偶関数であり，速度は奇関数であるため，

```math
\int
\boldsymbol v f_0^{\mathrm{occ}}
\,d^3p=0
```

となる．
よって，

```math
\boldsymbol j
=
-g_se
\int
\boldsymbol v f_1
\frac{d^3p}{(2\pi\hbar)^3}
```

である．

先ほど求めた $f_1$ を代入すると，

```math
j_i
=
\frac{g_se^2}{k_{\mathrm B}T}
E_j
\int
\tau(v)v_iv_jf_0^{\mathrm{occ}}
\frac{d^3p}{(2\pi\hbar)^3}
```

を得る．
ここでは，同じ添字 $j$ について和を取っている．

放物線型バンドでは，平衡分布と緩和時間は速度の大きさだけに依存するため，速度分布は等方的である．
したがって，

```math
\int
\tau(v)v_iv_jf_0^{\mathrm{occ}}\,d^3p
=
\frac{\delta_{ij}}{3}
\int
\tau(v)v^2f_0^{\mathrm{occ}}\,d^3p
```

が成立する．
ここで $\delta_{ij}$ は Kronecker のデルタである．

したがって，

```math
\boldsymbol j=\sigma\boldsymbol E
```

における電気伝導率は，

```math
\sigma
=
\frac{g_se^2}{3k_{\mathrm B}T}
\int
\tau(v)v^2f_0^{\mathrm{occ}}
\frac{d^3p}{(2\pi\hbar)^3}
```

となる．

#### 3.2 状態密度を用いた表示

状態占有数 $f_0^{\mathrm{occ}}$ と，スピン縮退度を含む状態密度 $D(\epsilon)$ を用いる．
3次元の等方的な放物線型バンドでは，

```math
D(\epsilon)
=
\frac{g_s}{4\pi^2}
\left(\frac{2m^*}{\hbar^2}\right)^{3/2}
\sqrt{\epsilon}
\qquad(\epsilon\geq0)
```

である．
電子数密度は，

```math
n
=
\int_0^\infty
f_0^{\mathrm{occ}}(\epsilon)
D(\epsilon)\,d\epsilon
```

となる．

運動量積分をエネルギー積分に変換すれば，

```math
\boxed{
\sigma
=
\frac{e^2}{3k_{\mathrm B}T}
\int_0^\infty
\tau(v)v^2
f_0^{\mathrm{occ}}(\epsilon)
D(\epsilon)\,d\epsilon
}
```

を得る．
ここでは $D(\epsilon)$ にスピン縮退度が含まれているため，積分式に別途 $g_s$ を掛ける必要はない．

#### 3.3 規格化された Maxwell 速度確率密度

速度の平均を明確にするため，状態占有数 $f_0^{\mathrm{occ}}$ と区別して，規格化された速度確率密度 $\mathcal P_0(\boldsymbol v)$ を定義する．

電子数密度によって規格化すると，

```math
\mathcal P_0(\boldsymbol v)
=
\frac{g_s(m^*)^3}{n(2\pi\hbar)^3}
f_0^{\mathrm{occ}}(m^*\boldsymbol v)
```

である．
この分布は，

```math
\int\mathcal P_0(\boldsymbol v)\,d^3v=1
```

を満たす．
Maxwell–Boltzmann 分布を代入すると，

```math
\boxed{
\mathcal P_0(\boldsymbol v)
=
\left(
\frac{m^*}{2\pi k_{\mathrm B}T}
\right)^{3/2}
\exp\left(
-\frac{m^*v^2}{2k_{\mathrm B}T}
\right)
}
```

となる．

したがって，電気伝導率は，

```math
\boxed{
\sigma
=
\frac{ne^2}{3k_{\mathrm B}T}
\langle\tau(v)v^2\rangle
}
```

と表せる．
ここで，

```math
\langle g(v)\rangle
=
\int g(v)\mathcal P_0(\boldsymbol v)\,d^3v
```

は，平衡状態における電子1個あたりの平均を表す．

### 4．速度依存緩和時間を代入する

問題の仮定は，

```math
\tau(v)=Av^s,
\qquad A>0
```

である．
したがって，

```math
\sigma
=
\frac{ne^2A}{3k_{\mathrm B}T}
\langle v^{s+2}\rangle
```

となる．

速度の大きさ $v=|\boldsymbol v|$ の確率密度は，

```math
P(v)
=
4\pi
\left(
\frac{m^*}{2\pi k_{\mathrm B}T}
\right)^{3/2}
v^2
\exp\left(
-\frac{m^*v^2}{2k_{\mathrm B}T}
\right)
```

であり，

```math
\int_0^\infty P(v)\,dv=1
```

を満たす．
したがって，

```math
\begin{aligned}
\langle v^{s+2}\rangle
={}&
\int_0^\infty v^{s+2}P(v)\,dv\\
={}&
4\pi
\left(
\frac{m^*}{2\pi k_{\mathrm B}T}
\right)^{3/2}\\
&\times
\int_0^\infty
v^{s+4}
\exp\left(
-\frac{m^*v^2}{2k_{\mathrm B}T}
\right)dv
\end{aligned}
```

となる．

ここで，ガンマ関数の積分公式

```math
\int_0^\infty
x^{\mu-1}e^{-\beta x^2}\,dx
=
\frac12\beta^{-\mu/2}
\Gamma\left(\frac{\mu}{2}\right)
```

を用いる．
この公式の適用条件は，

```math
\beta>0,\qquad\mu>0
```

である．
今回，

```math
\mu=s+5,\qquad
\beta=\frac{m^*}{2k_{\mathrm B}T}
```

と置くと，積分条件は $s>-5$ となる．

この条件のもとで積分を実行すると，

```math
\boxed{
\langle v^{s+2}\rangle
=
\frac{2}{\sqrt{\pi}}
\left(
\frac{2k_{\mathrm B}T}{m^*}
\right)^{(s+2)/2}
\Gamma\left(\frac{s+5}{2}\right)
}
```

を得る．

### 5．電気伝導率の最終結果

求めた速度モーメントを電気伝導率の式に代入すると，

```math
\boxed{
\sigma
=
\frac{2ne^2A}{3\sqrt{\pi}\,k_{\mathrm B}T}
\left(
\frac{2k_{\mathrm B}T}{m^*}
\right)^{(s+2)/2}
\Gamma\left(\frac{s+5}{2}\right)
}
```

となる．

同値な形に整理すると，

```math
\boxed{
\sigma
=
\frac{ne^2A}{m^*}
\frac{4}{3\sqrt{\pi}}
\left(
\frac{2k_{\mathrm B}T}{m^*}
\right)^{s/2}
\Gamma\left(\frac{s+5}{2}\right)
}
```

である．
これが，積分が収束する場合の電気伝導率である．

#### 5.1 緩和時間が一定の場合

$s=0$ の場合，

```math
\tau(v)=A
```

である．

```math
\Gamma\left(\frac52\right)
=
\frac{3\sqrt{\pi}}4
```

を用いると，

```math
\boxed{
\sigma=\frac{ne^2A}{m^*}
}
```

となる．
これは緩和時間が一定の場合の Drude 型の結果と一致する．

#### 5.2 平均自由行程が一定の場合

$s=-1$ の場合，

```math
\tau(v)=\frac A v
```

なので，平均自由行程は，

```math
l=v\tau=A
```

で一定となる．
また，Maxwell 分布における平均速さは，

```math
\bar v
=
\sqrt{\frac{8k_{\mathrm B}T}{\pi m^*}}
```

である．
このとき，

```math
\langle v^{s+2}\rangle
=
\langle v\rangle
=
\bar v
```

であるから，

```math
\sigma
=
\frac{ne^2l\bar v}{3k_{\mathrm B}T}
```

となる．

```math
\bar v^2=\frac{8k_{\mathrm B}T}{\pi m^*}
```

を用いれば，

```math
\boxed{
\sigma
=
\frac{ne^2}{m^*}
\frac{8}{3\pi}
\frac l{\bar v}
}
```

を得る．

### 6．積分の収束条件

問題文では，

```math
s>-7
```

と指定されている．
しかし，実際に必要な速度モーメントは，

```math
\langle v^{s+2}\rangle
\propto
\int_0^\infty
v^{s+4}
\exp\left(
-\frac{m^*v^2}{2k_{\mathrm B}T}
\right)dv
```

である．

$v\to\infty$ では指数関数によって積分は収束する．
一方， $v\to0$ では指数関数は1に近づくので，原点付近の収束条件は，

```math
\int_0^1 v^{s+4}\,dv<\infty
```

である．
したがって，

```math
s+4>-1
```

すなわち，

```math
\boxed{s>-5}
```

が必要である．

よって，問題文の指定範囲は次のように分かれる．

- $s>-5$ ： 有限の電気伝導率が得られる．
- $s=-5$ ： 対数発散する．
- $-7<s<-5$ ： 原点付近でべき発散する．

したがって，問題文の条件 $s>-7$ だけでは，有限な電気伝導率は保証されない．
$s\leq-5$ について有限値を得るためには，低速領域での緩和時間の正則化や，低速カットオフなどの追加物理条件が必要である．
ガンマ関数の解析接続による形式的な値は，発散する元の速度積分の値を表すものではない．

### 7．線形応答近似の適用条件

一次補正と平衡分布の比は，

```math
\frac{|f_1|}{f_0^{\mathrm{occ}}}
=
\frac{eA}{k_{\mathrm B}T}
|\boldsymbol E\cdot\boldsymbol v|v^s
```

である．
したがって，電場に関する一次近似は，この比が電子の分布に対して十分小さい範囲で適用する．

特に $s<-1$ では，この比は $v\to0$ で発散し，低速領域で分布関数の一次展開が一様には成立しない．
一方， $-5<s<-1$ の範囲では，一次応答係数を定める速度積分自体は収束する．
したがって，上で求めた式は線形化した緩和時間近似における形式的な線形応答係数である．
低速領域での散乱モデルまで厳密に扱う場合には，追加の正則化の検討が必要となる．

### 8．結論

緩和時間近似の Boltzmann 方程式を線形化し，3次元 Maxwell–Boltzmann 速度分布を用いると，電気伝導率は，

```math
\boxed{
\sigma
=
\frac{ne^2A}{m^*}
\frac{4}{3\sqrt{\pi}}
\left(
\frac{2k_{\mathrm B}T}{m^*}
\right)^{s/2}
\Gamma\left(\frac{s+5}{2}\right)
}
```

となる．
ただし，通常の速度積分として有限値を得るためには，

```math
\boxed{s>-5}
```

が必要である．

問題文の $s>-7$ のうち， $-7<s\leq-5$ では，指定された緩和時間モデルのままでは低速電子の寄与が発散し，有限の電気伝導率は得られない．
