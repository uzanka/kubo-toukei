# 例題【10-R-4】

## 解答

### 1．Boltzmann 方程式の線形化

一様な金属に一定の電場 $\boldsymbol E$ が加わっている場合を考える．
Boltzmann 方程式は

```math
\frac{\partial f}{\partial t}
+\boldsymbol v\cdot\frac{\partial f}{\partial\boldsymbol x}
-e\boldsymbol E\cdot\frac{\partial f}{\partial\boldsymbol p}
=-\frac{f-f_0}{\tau}
\tag{1}
```

である．
ここで， $f(\boldsymbol p)$ は電子の分布関数， $f_0(\varepsilon)$ は平衡状態の Fermi 分布， $\boldsymbol v$ は電子の速度， $-e$ は電子の電荷である．
緩和時間 $\tau$ は一般にエネルギー $\varepsilon$ と温度 $T$ に依存する．

電場が一定で空間的にも一様であり，定常状態を考えるので，

```math
\frac{\partial f}{\partial t}=0,
\qquad
\frac{\partial f}{\partial\boldsymbol x}=0
```

である．
よって，式 (1) は

```math
-e\boldsymbol E\cdot
\frac{\partial f}{\partial\boldsymbol p}
=-\frac{f-f_0}{\tau}
\tag{2}
```

となる．

電場が十分に弱いとして，分布関数を平衡分布と電場による一次のずれに分ける．

```math
f=f_0+g
\tag{3}
```

ここで $g$ は電場の一次の量である．
式 (2) の左辺にある $f$ について，電場の一次までの近似では $f_0$ を代入すればよい．
したがって，

```math
-e\boldsymbol E\cdot
\frac{\partial f_0}{\partial\boldsymbol p}
=-\frac{g}{\tau}
```

であり，

```math
g=e\tau\boldsymbol E\cdot
\frac{\partial f_0}{\partial\boldsymbol p}
\tag{4}
```

となる．

平衡分布 $f_0$ は電子のエネルギー

```math
\varepsilon=\varepsilon(\boldsymbol p)
```

の関数であるため，連鎖律を用いると，

```math
\frac{\partial f_0}{\partial\boldsymbol p}
=\frac{\partial f_0}{\partial\varepsilon}
\frac{\partial\varepsilon}{\partial\boldsymbol p}
```

となる．
電子の速度は

```math
\boldsymbol v=\frac{\partial\varepsilon}{\partial\boldsymbol p}
```

であるから，

```math
\frac{\partial f_0}{\partial\boldsymbol p}
=\frac{\partial f_0}{\partial\varepsilon}\boldsymbol v
\tag{5}
```

を得る．
したがって，式 (4) は

```math
\boxed{
f=f_0+
e\tau(\varepsilon,T)
\frac{\partial f_0}{\partial\varepsilon}
\boldsymbol v\cdot\boldsymbol E
}
\tag{6}
```

となる．
ここで， $\partial f_0/\partial\varepsilon$ は Fermi 分布のエネルギー微分であり，通常は負の値である．

### 2．電流密度と電気伝導率テンソル

電子の電荷は $-e$ なので，電流密度は

```math
\boldsymbol j
=-e\int\boldsymbol v f
\frac{2\,d^3p}{h^3}
\tag{7}
```

である．
ここで， $h$ は Planck 定数，係数 2 は電子のスピンの縮退度である．

式 (6) を式 (7) に代入すると，

```math
\begin{aligned}
\boldsymbol j
={}&-e\int\boldsymbol v f_0
\frac{2\,d^3p}{h^3}\\
&-e^2\int
\tau(\varepsilon,T)
\frac{\partial f_0}{\partial\varepsilon}
(\boldsymbol v\cdot\boldsymbol E)\boldsymbol v
\frac{2\,d^3p}{h^3}
\end{aligned}
\tag{8}
```

となる．
平衡分布 $f_0$ は運動量の向きについて対称である一方，速度 $\boldsymbol v$ は運動量の反転で符号が反転する．
したがって，第一項はゼロである．
よって，

```math
\boxed{
\boldsymbol j
=e^2\int
\tau(\varepsilon,T)
\left(-\frac{\partial f_0}{\partial\varepsilon}\right)
(\boldsymbol v\cdot\boldsymbol E)\boldsymbol v
\frac{2\,d^3p}{h^3}
}
\tag{9}
```

を得る．

電場の成分を $E_\beta$ と書けば，電流の成分 $j_\alpha$ は

```math
j_\alpha=\sum_\beta\sigma_{\alpha\beta}E_\beta
\tag{10}
```

と表される．
ここで， $\sigma_{\alpha\beta}$ は電気伝導率テンソルの成分である．
式 (9) から，

```math
\boxed{
\sigma_{\alpha\beta}
=e^2\int
\tau(\varepsilon,T)
v_\alpha v_\beta
\left(-\frac{\partial f_0}{\partial\varepsilon}\right)
\frac{2\,d^3p}{h^3}
}
\tag{11}
```

となる．

### 3．状態密度を用いた表示

運動量空間でエネルギーが $\varepsilon$ から $\varepsilon+d\varepsilon$ の範囲にある電子状態の数を $D(\varepsilon)d\varepsilon$ と定義する．
この $D(\varepsilon)$ はスピンの縮退度 2 を含む状態密度である．

また， $\overline{v_\alpha v_\beta}$ を，エネルギー $\varepsilon$ の等エネルギー面上での $v_\alpha v_\beta$ の平均値とする．
すると，運動量積分をエネルギー積分へ変換して，

```math
\boxed{
\sigma_{\alpha\beta}
=e^2\int_0^\infty
\tau(\varepsilon,T)
\overline{v_\alpha v_\beta}
\left(-\frac{\partial f_0}{\partial\varepsilon}\right)
D(\varepsilon)\,d\varepsilon
}
\tag{12}
```

を得る．
これが，一般のエネルギー分散に対する電気伝導率テンソルの式である．

### 4．強縮退近似

平衡分布は Fermi 分布

```math
f_0(\varepsilon)
=\frac{1}{\exp[(\varepsilon-\mu)/(kT)]+1}
\tag{13}
```

で与えられる．
ここで， $\mu$ は化学ポテンシャルである．
十分に強く縮退した電子系では， $kT$ が Fermi エネルギーに比べて小さいため，

```math
-\frac{\partial f_0}{\partial\varepsilon}
```

は $\varepsilon=\mu$ の近傍に鋭く集中する．
さらに，この狭いエネルギー範囲では $\tau$ ，状態密度および速度の二次の積が大きく変化しないと考えられる．
したがって，式 (12) の積分を Fermi 準位で評価でき，

```math
\boxed{
\sigma_{\alpha\beta}
\simeq e^2\tau(\mu,T)
\overline{v_\alpha v_\beta}^{\,F}D(\mu)
}
\tag{14}
```

となる．
ここで， $\overline{v_\alpha v_\beta}^{\,F}$ は Fermi 面 $\varepsilon=\mu$ 上での平均値である．

### 5．放物線型エネルギー分散の場合

特に，

```math
\varepsilon(\boldsymbol p)
=\frac{\boldsymbol p^2}{2m^*}
\tag{15}
```

とする．
このとき，電子速度は

```math
\boldsymbol v=\frac{\boldsymbol p}{m^*}
```

であり，速度の大きさは

```math
v^2=\frac{2\varepsilon}{m^*}
\tag{16}
```

である．

エネルギー分散が等方的であるため，等エネルギー面上では速度の各方向が等価である．
そのため，異なる成分の積の平均はゼロであり，同じ成分の二乗平均は全速度の二乗平均の 3 分の 1 となる．
すなわち，

```math
\boxed{
\overline{v_\alpha v_\beta}
=\delta_{\alpha\beta}\frac{v^2}{3}
=\delta_{\alpha\beta}\frac{2\varepsilon}{3m^*}
}
\tag{17}
```

である．
ここで $\delta_{\alpha\beta}$ は， $\alpha=\beta$ なら 1，それ以外なら 0 となる Kronecker のデルタである．

スピンの縮退度 2 を含む三次元の状態密度は，

```math
\boxed{
D(\varepsilon)
=\frac{\sqrt{2}(m^*)^{3/2}}{\pi^2\hbar^3}
\sqrt{\varepsilon}
}
\tag{18}
```

である．
ここで $\hbar=h/(2\pi)$ は換算 Planck 定数である．

式 (17)，(18) を式 (14) に代入すると，

```math
\begin{aligned}
\sigma_{\alpha\beta}
&\simeq e^2\tau(\mu,T)
\delta_{\alpha\beta}\frac{2\mu}{3m^*}
\frac{\sqrt{2}(m^*)^{3/2}\sqrt{\mu}}
{\pi^2\hbar^3}\\
&=\delta_{\alpha\beta}
\frac{e^2\tau(\mu,T)}{3m^*}
\frac{(2m^*\mu)^{3/2}}{\pi^2\hbar^3}
\end{aligned}
\tag{19}
```

となる．

次に，強縮退近似における電子数密度 $n$ を求める．
$T$ が十分低いとき，Fermi 準位以下の状態がほぼすべて電子で占有されるため，

```math
n=\int_0^\mu D(\varepsilon)\,d\varepsilon
\tag{20}
```

である．
式 (18) を代入すると，

```math
\begin{aligned}
n
&=\frac{\sqrt{2}(m^*)^{3/2}}{\pi^2\hbar^3}
\int_0^\mu\sqrt{\varepsilon}\,d\varepsilon\\
&=\frac{\sqrt{2}(m^*)^{3/2}}{\pi^2\hbar^3}
\frac23\mu^{3/2}\\
&=\frac{(2m^*\mu)^{3/2}}{3\pi^2\hbar^3}
\end{aligned}
\tag{21}
```

を得る．
よって，式 (19) は

```math
\sigma_{\alpha\beta}
=\delta_{\alpha\beta}\frac{ne^2}{m^*}\tau(\mu,T)
```

と書ける．
したがって，等方的な金属では電気伝導率はスカラーとなり，

```math
\boxed{
\sigma=\frac{ne^2}{m^*}\tau(\mu,T)
}
\tag{22}
```

が求める結果である．

これは Drude 型の電気伝導率と同じ形であるが，強縮退電子系では，電子の伝導への寄与が主として Fermi 準位近傍の状態によって決まるため，緩和時間は $\tau(\mu,T)$ で評価される．

### 6．物理的な意味

電場を加えると，平衡分布 $f_0$ はわずかに変形する．
電子は負の電荷を持つので，この変形によって電流が生じる．
式 (22) は，電子数密度 $n$ が大きいほど電流を運ぶ電子が多くなり，緩和時間 $\tau$ が長いほど散乱までの運動が続くため，伝導率が大きくなることを示している．
また，実効質量 $m^*$ が大きいほど電場による加速が小さくなるため，伝導率は小さくなる．

強縮退近似では，Fermi 準位から大きく離れた電子状態は伝導率の積分にほとんど寄与しない．
したがって，金属の電気伝導率は，Fermi 準位における状態密度，速度，緩和時間によって評価できるのである．
