# 演習問題【9-R-3】

## 解答

### 平板コンデンサー中のイオンの空間電荷分布

#### 1．問題の設定

平板コンデンサーの間に，電荷が $+e$ の正イオンと電荷が $-e$ の負イオンからなる溶液が満たされているとする．
両極間の電位差は $V_0$ であり，イオンは電流を流さずに熱平衡に達している．
また，電位差は十分に小さく，

```math
|eV_0|\ll kT
```

を満たすものとする．
ここで， $e$ は電気素量， $k$ はボルツマン定数， $T$ は絶対温度である．

コンデンサーの中央を $x=0$ ，両極の位置を $x=\pm a$ とする．
電位の基準を中央に取り，境界条件を

```math
\varphi(0)=0,\qquad
\varphi(a)=\frac{V_0}{2},\qquad
\varphi(-a)=-\frac{V_0}{2}
```

と設定する．
中央では電位がゼロであるため，正イオンと負イオンの数密度は等しくなる．
その数密度をそれぞれ $n$ とする．

求める量は，位置 $x$ における空間電荷密度 $\rho(x)$ である．

#### 2．電位と電荷密度の関係

平板間の電位は $x$ だけの関数であるとする．
ガウス単位系におけるポアソン方程式は，

```math
\frac{d^2\varphi}{dx^2}
=-\frac{4\pi}{D}\rho(x)
\tag{1}
```

である．
ここで， $D$ は溶液の誘電率である．
したがって，空間電荷密度 $\rho(x)$ が分かれば，電位分布を決定できる．

#### 3．熱平衡におけるイオン密度

熱平衡にある粒子の数密度は，ポテンシャルエネルギーに応じたボルツマン分布に従う．
電荷 $q$ のイオンの電位エネルギーは $q\varphi(x)$) であるため，その数密度は

```math
n_q(x)=n\exp\left(-\frac{q\varphi(x)}{kT}\right)
```

と表される．
これを正イオンと負イオンに適用すると，

```math
n_+(x)=n\exp\left(-\frac{e\varphi(x)}{kT}\right)
```

```math
n_-(x)=n\exp\left(\frac{e\varphi(x)}{kT}\right)
```

となる．
正イオンは電位が高い領域で少なくなり，負イオンは反対に多くなる傾向がある．

空間電荷密度は，正イオンによる電荷密度と負イオンによる電荷密度の和であるから，

```math
\rho(x)=en_+(x)-en_-(x)
```

である．
上のボルツマン分布を代入すると，

```math
\begin{aligned}
\rho(x)
&=en\left[
\exp\left(-\frac{e\varphi(x)}{kT}\right)
-\exp\left(\frac{e\varphi(x)}{kT}\right)
\right]\\
&=-2en\sinh\left(\frac{e\varphi(x)}{kT}\right).
\end{aligned}
\tag{2}
```

この式は，電位によって正負のイオン密度に差が生じ，その差が空間電荷を生むことを表している．

#### 4．ポアソン方程式の線形化

式 (2) をポアソン方程式 (1) に代入すると，

```math
\frac{d^2\varphi}{dx^2}
=\frac{8\pi en}{D}
\sinh\left(\frac{e\varphi}{kT}\right)
\tag{3}
```

となる．
これは電位 $\varphi$ に関する非線形微分方程式である．

問題では電位差が十分に小さいため，溶液中で

```math
\left|\frac{e\varphi(x)}{kT}\right|\ll1
```

と近似できる．
このとき，双曲線正弦関数のテイラー展開

```math
\sinh u=u+\frac{u^3}{3!}+\cdots
```

において，高次の項を無視し，

```math
\sinh u\simeq u
```

とすることができる．
これを式 (3) に適用すると，

```math
\begin{aligned}
\frac{d^2\varphi}{dx^2}
&\simeq \frac{8\pi en}{D}\frac{e\varphi}{kT}\\
&=\frac{8\pi e^2n}{DkT}\varphi
\end{aligned}
\tag{4}
```

を得る．
この近似によって，非線形微分方程式が線形微分方程式に変わる．

ここで，解答例と同様に長さの次元をもつ量 $l$ を

```math
l^2=\frac{DkT}{4\pi e^2n}
\tag{5}
```

と定義する．
式 (4) は，

```math
\frac{d^2\varphi}{dx^2}
=\frac{2}{l^2}\varphi
\tag{6}
```

と書ける．

#### 5．電位分布を求める

式 (6) の一般解は，

```math
\varphi(x)
=A\sinh\left(\frac{\sqrt{2}x}{l}\right)
+B\cosh\left(\frac{\sqrt{2}x}{l}\right)
```

である．
ここで， $A$ と $B$ は境界条件によって決まる定数である．

まず，中央 $x=0$ では $\varphi(0)=0$ である．
したがって，

```math
\varphi(0)=A\sinh 0+B\cosh 0=B=0
```

となり， $B=0$ である．
よって，

```math
\varphi(x)
=A\sinh\left(\frac{\sqrt{2}x}{l}\right)
```

を得る．

次に，正側の極 $x=a$ では電位が $V_0/2$ であるから，

```math
\frac{V_0}{2}
=A\sinh\left(\frac{\sqrt{2}a}{l}\right)
```

となる．これより，

```math
A=\frac{V_0}
{2\sinh\left(\frac{\sqrt{2}a}{l}\right)}
```

である．
したがって，電位分布は

```math
\boxed{
\varphi(x)=
\frac{V_0}{2}
\frac{\sinh\left(\frac{\sqrt{2}x}{l}\right)}
{\sinh\left(\frac{\sqrt{2}a}{l}\right)}
}
\tag{7}
```

となる．
この解は $x$ の奇関数であるため， $\varphi(-a)=-V_0/2$ も満たしている．

#### 6．空間電荷分布を求める

式 (2) に小電位近似 $\sinh(e\varphi/kT)\simeq e\varphi/kT$ を適用すると，

```math
\rho(x)\simeq-\frac{2e^2n}{kT}\varphi(x)
\tag{8}
```

となる．
式 (7) の電位分布を代入すれば，

```math
\begin{aligned}
\rho(x)
&=-\frac{2e^2n}{kT}
\left[
\frac{V_0}{2}
\frac{\sinh\left(\frac{\sqrt{2}x}{l}\right)}
{\sinh\left(\frac{\sqrt{2}a}{l}\right)}
\right]\\[4pt]
&=-\frac{e^2nV_0}{kT}
\frac{\sinh\left(\frac{\sqrt{2}x}{l}\right)}
{\sinh\left(\frac{\sqrt{2}a}{l}\right)}.
\end{aligned}
```

したがって，求める空間電荷分布は

```math
\boxed{
\rho(x)=
-\frac{e^2nV_0}{kT}
\frac{\sinh\left(\frac{\sqrt{2}x}{l}\right)}
{\sinh\left(\frac{\sqrt{2}a}{l}\right)}
}
\tag{9}
```

である．

#### 7．結果の物理的意味

$V_0>0$ とすると， $x>0$ では $\varphi(x)>0$ である．
正の電位は正イオンを遠ざけ，負イオンを引き寄せるため，この領域では負イオンが相対的に多くなり， $\rho(x)<0$ となる．
反対に， $x<0$ では正イオンが相対的に多くなり， $\rho(x)>0$ となる．
中央 $x=0$ では正負のイオン密度が等しいため，

```math
\rho(0)=0
```

である．
つまり，空間電荷はコンデンサーの中央ではゼロであり，両側で符号が反対となる分布を形成する．

なお，式 (6) は

```math
\varphi''=\frac{1}{\lambda_D^2}\varphi
```

とも書ける．
ここで，

```math
\lambda_D
=\sqrt{\frac{DkT}{8\pi e^2n}}
=\frac{l}{\sqrt{2}}
```

と定義した $\lambda_D$ が，この問題のイオン密度の定義に対応する通常のデバイ長さである．
電位の解に現れる双曲線関数の引数は $x/\lambda_D$ であり，極から十分離れた領域で電位が指数関数的に変化する際の特徴的な長さも $\lambda_D=l/\sqrt{2}$ となる．

以上より，小電位差のもとでは，イオンのボルツマン分布とポアソン方程式を組み合わせることにより，コンデンサー内の電位分布と空間電荷分布を線形近似で求められるのである．
