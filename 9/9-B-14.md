# 演習問題【9-B-14】

## 解答

### 1. 秩序状態と分子場

問題 [3] で与えられた分子場を用いる．
外部磁場 $\mathbf H$ を加えたとき，部分格子 a，b に作用する有効磁場をそれぞれ

```math
\begin{aligned}
\mathbf H_a^{\mathrm{eff}} &=\mathbf H-q_2\mathbf M_a-q_1\mathbf M_b, \\
\mathbf H_b^{\mathrm{eff}} &=\mathbf H-q_2\mathbf M_b-q_1\mathbf M_a
\end{aligned}
```

とする．

$T<T_N$ で外部磁場がないとき，ヒントに従って

```math
\mathbf M_a=\mathbf M', \qquad
\mathbf M_b=-\mathbf M'
```

とおく．
ここで $\mathbf M'$ は反強磁性秩序を表す部分格子磁化である．

$\mathbf M'$ の方向を $z$ 軸にとると，部分格子 a，b に作用する有効磁場は

```math
\begin{aligned}
\mathbf H_{a0}^{\mathrm{eff}} &=(q_1-q_2)\mathbf M', \\
\mathbf H_{b0}^{\mathrm{eff}} &=-(q_1-q_2)\mathbf M'
\end{aligned}
```

である．
したがって，各部分格子に作用する分子場の大きさを

```math
\boxed{H_0=(q_1-q_2)M'}
```

と書ける．

以下では $q_1>q_2$ とし，部分格子の磁化は各部分格子あたりの量，巨視的な磁化は等しい二つの部分格子の平均として扱う．

### 2. 局所的な磁化応答を区別する

反強磁性体では，外部磁場が $\mathbf M'$ に平行か垂直かによって，各部分格子の応答が異なる．

有効磁場 $h$ に対する単一部分格子の磁化の大きさを $f(h,T)$ と書く．
秩序状態では

```math
M'=f(H_0,T)
```

である．

有効磁場に平行な小さな変化に対しては，局所的な縦磁化率を

```math
\boxed{
\chi_0^\parallel= \left.\frac{\partial f(h,T)}{\partial h}\right|_{h=H_0}
}
```

と定義できる．

一方，有効磁場に垂直な小さな変化は，磁化の大きさの変化ではなく，主に磁化の方向の変化を引き起こす．
そのため，局所的な横磁化率は

```math
\boxed{
\chi_0^\perp=\frac{M'}{H_0} =\frac{1}{q_1-q_2}
}
```

となる．

このように，まず局所応答 $\chi_0^\parallel$ と $\chi_0^\perp$ を区別し，その後に分子場による自己無撞着な補正を加えることが重要である．

### 3. 外部磁場を加えたときの線形応答

外部磁場が十分小さいとして，各部分格子の磁化の変化を $\delta\mathbf M_a,\delta\mathbf M_b$ とする．
有効磁場の変化は

```math
\begin{aligned}
\delta\mathbf H_a^{\mathrm{eff}} &=\mathbf H-q_2\delta\mathbf M_a-q_1\delta\mathbf M_b, \\
\delta\mathbf H_b^{\mathrm{eff}} &=\mathbf H-q_2\delta\mathbf M_b-q_1\delta\mathbf M_a.
\end{aligned}
```

一様な外部磁場に対する一様磁化応答では，対称性から

```math
\delta\mathbf M_a=\delta\mathbf M_b =\delta\mathbf M
```

となる．
よって，両部分格子に生じる有効磁場の変化は

```math
\boxed{
\delta\mathbf H^{\mathrm{eff}} =\mathbf H-(q_1+q_2)\delta\mathbf M
}
```

である．

外部磁場の方向に対応する局所磁化率を $\chi_0$ とすると，

```math
\delta M=\chi_0 \left[H-(q_1+q_2)\delta M\right]
```

が得られる．
これを $\delta M$ について解けば，

```math
\delta M\left[1+(q_1+q_2)\chi_0\right] =\chi_0 H
```

したがって，巨視的な磁化率は

```math
\boxed{
\chi=\frac{\delta M}{H} =\frac{\chi_0}{1+(q_1+q_2)\chi_0}
}
```

となる．

この一般式に，外部磁場の向きに応じた局所磁化率を代入すればよいことになる．

### 4. 垂直磁化率 $\chi_\perp$

外部磁場 $\mathbf H$ が $\mathbf M'$ に垂直な場合，部分格子磁化は「大きさ不変で回転する（剛体回転）」という制約に従う．
解答例に倣って幾何学的に導く．

$\mathbf M'$ の方向を $z$ 軸， $\mathbf H$ の方向を $x$ 軸とする．
部分格子磁化はそれぞれ角度 $\theta_a, \theta_b$ だけ $\mathbf H$ 方向に回転し，

```math
\mathbf M_a = M'(\sin\theta_a\,\hat{\mathbf x} + \cos\theta_a\,\hat{\mathbf z}), \qquad
\mathbf M_b = -M'(\sin\theta_b\,\hat{\mathbf x} + \cos\theta_b\,\hat{\mathbf z})
```

と書ける．
$\mathbf H$ が小さいとき $\theta_a, \theta_b$ も微小なので $\sin\theta \simeq \theta, \cos\theta \simeq 1$ である．

有効磁場が磁化と平行という条件（ $\mathbf H_a^{\mathrm{eff}} \parallel \mathbf M_a$, $\mathbf H_b^{\mathrm{eff}} \parallel \mathbf M_b$ ）から，

```math
\begin{aligned}
H_{a,x}/H_{a,z} &= \tan\theta_a \simeq \theta_a, \\
H_{b,x}/H_{b,z} &= \tan\theta_b \simeq \theta_b
\end{aligned}
```

である．
$z$ 成分は支配的なので $H_{a,z} \simeq (q_1-q_2)M'$, $H_{b,z} \simeq -(q_1-q_2)M'$ ．
$x$ 成分は

```math
H_{a,x} = H - q_1(-M'\sin\theta_b) - q_2(M'\sin\theta_a) \simeq H + (q_1-q_2)M'\theta,
```

ただし $\theta = (\theta_a+\theta_b)/2$ とした．
平行条件より

```math
\theta_a \simeq \frac{H + (q_1-q_2)M'\theta_a}{(q_1-q_2)M'}, \qquad
\theta_b \simeq \frac{H - (q_1-q_2)M'\theta_b}{-(q_1-q_2)M'}.
```

これを解いて $2\theta = \theta_a + \theta_b = H/(M'q_1)$ が得られる．

全磁化は $M_x = M'(\theta_a + \theta_b) = 2M'\theta = H/q_1$ なので，

```math
\boxed{
\displaystyle \chi_\perp=\frac{1}{q_1}
}
```

となる．

垂直磁化率は分子場近似において $T<T_N$ で温度に依存しない．
この結果は，外部磁場によって二つの部分格子の磁化が反対向きのまま傾き，一様な磁化成分が生じることに相当する．

### 5. 平行磁化率 $\chi_\parallel$

外部磁場 $\mathbf H$ が $\mathbf M'$ に平行な場合，局所磁化率は縦磁化率 $\chi_0^\parallel$ である．
したがって，一般式に代入すると

```math
\boxed{
\displaystyle \chi_\parallel(T)= \frac{\chi_0^\parallel(T)} {1+(q_1+q_2)\chi_0^\parallel(T)}
}
```

となる．

ここで

```math
\chi_0^\parallel(T)= \left.\frac{\partial f(h,T)}{\partial h}\right|_{h=(q_1-q_2)M'}
```

であり， $M'=f((q_1-q_2)M',T)$ は無磁場での自発的な部分格子磁化を表す．

スピン $S$ の Brillouin 関数 $B_S(y)$ を用いるなら，部分格子の飽和磁化を $M_{\rm sat}$ として

```math
f(h,T)=M_{\rm sat} B_S\left(\frac{g\mu_{\rm B}S h}{k_{\rm B}T}\right)
```

と書けるため，

```math
\boxed{
\chi_0^\parallel(T)= \frac{M_{\rm sat}g\mu_{\rm B}S}{k_{\rm B}T} B'_S(y_0)
}
```

である．
ただし，

```math
y_0=\frac{g\mu_{\rm B}S(q_1-q_2)M'}{k_{\rm B}T}.
```

したがって， $\chi_\parallel$ は自発磁化 $M'(T)$ を通して温度に依存する．
一般に温度一定の局所縦応答は温度とともに変化し，垂直磁化率とは異なる振る舞いを示す．

### 6. $T_N$ 極限での確認

#### 6a. Néel 温度の条件

問題 [13] の Neél 温度の条件は，転移点で $M'\to0$ としたとき

```math
(q_1-q_2)\chi_0^\parallel(T_N)=1
```

である．
ここで $\chi_0^\parallel(T_N)$ は，Brillouin関数を用いて

```math
\chi_0^\parallel(T_N) = \frac{M_{\rm sat}g\mu_{\rm B}S}{k_{\rm B}T_N} B_S'(0), \qquad B_S'(0)=\frac{S+1}{3S}
```

と書ける．
一方，自発磁化の条件 $M' = M_{\rm sat} B_S(y_0)$ の $y_0\to0$ での振る舞い

```math
B_S(y_0) \simeq \frac{S+1}{3S}\, y_0, \quad y_0 = \frac{g\mu_{\rm B}S(q_1-q_2)M'}{k_{\rm B}T}
```

を用いると， $T\to T_N$ で

```math
1 = \frac{g\mu_{\rm B}S}{k_{\rm B}T_N}\,\frac{S+1}{3S}\,M_{\rm sat}(q_1-q_2)
```

すなわち

```math
M_{\rm sat}\frac{g\mu_{\rm B}S}{k_{\rm B}T_N}\,\frac{S+1}{3S} = \frac{1}{q_1-q_2}.
```

これと $M' = M_{\rm sat}B_S(y_0)$ の線形近似から

```math
\chi_0^\parallel(T_N) \equiv \lim_{M'\to 0}\frac{\partial M'}{\partial H_{\mathrm{eff}}} = \frac{M_{\rm sat}g\mu_{\rm B}S}{k_{\rm B}T_N}\,\frac{S+1}{3S} = \frac{1}{q_1-q_2}.
```

が得られる．

#### 6b. $T_N$ での連続性

Curie定数 $C = \frac{n g^2 \mu_{\rm B}^2 S(S+1)}{3k_{\rm B}}$ を用いて書き表すと，Brillouin関数の微分の極限 $B_S'(0) = (S+1)/(3S)$ より

```math
\chi_0^\parallel(T_N) = \frac{C}{T_N}.
```

Néel 温度の条件 $(q_1-q_2)\chi_0^\parallel(T_N)=1$ から $\chi_0^\parallel(T_N) = \frac{1}{q_1-q_2}$ ，すなわち $T_N = C/(q_1-q_2)$ である．

これを用いて平行磁化率の $T_N^-$ 極限を計算すると，解答例の式(7)より

```math
\begin{aligned}
\chi_\parallel(T_N^-) &= \frac{C}{T_N + \tfrac{1}{2}(q_1+q_2)C} \\
&= \frac{C}{\tfrac{1}{2}(q_1-q_2)C + \tfrac{1}{2}(q_1+q_2)C} \\
&= \frac{C}{q_1 C} = \frac{1}{q_1}.
\end{aligned}
```

となり，垂直磁化率 $\chi_\perp$ と一致する．
このことは，秩序が消失していく $T\to T_N^{-}$ の極限で，磁場の方向による区別がなくなるという要請と整合している．

### 最終結果

```math
\boxed{
\displaystyle \chi_\perp=\frac{1}{q_1}
}
```

```math
\boxed{
\displaystyle \chi_\parallel(T)= \frac{\chi_0^\parallel(T)} {1+(q_1+q_2)\chi_0^\parallel(T)}
}
```

ただし，

```math
\chi_0^\parallel(T)= \left.\frac{\partial f(h,T)}{\partial h}\right|_{h=(q_1-q_2)M'}, \qquad M'=f((q_1-q_2)M',T).
```

以上が分子場近似による結果である．
垂直磁化率は温度に依存せず，平行磁化率は自発磁化を決める局所応答を通して温度に依存するという違いが，この問題の要点である．

※磁化率の数値係数は，部分格子磁化を「各部分格子あたりの平均」とするか「試料全体の体積に対する寄与」とするかで定義上の係数が変わる．
上の式は，本文で明示した平均規約と，問題 [3] の分子場係数の規約に基づいている．
