# 演習問題【9-B-14】

## 解答

### 1．分子場近似と無磁場での反強磁性状態

問題 [3]，[13] と同様に，反強磁性体を二つの部分格子 $a,b$ からなる系として扱う．
各部分格子に作用する有効磁場は

```math
\begin{cases}
\boldsymbol H_a'
=\boldsymbol H-q_2\boldsymbol M_a-q_1\boldsymbol M_b,\\[2mm]
\boldsymbol H_b'
=\boldsymbol H-q_2\boldsymbol M_b-q_1\boldsymbol M_a
\end{cases}
\tag{1}
```

である．
ここで， $q_1$ は異なる部分格子間の相互作用に関する分子場係数， $q_2$ は同じ部分格子内の相互作用に関する分子場係数である．

各部分格子の磁化の大きさは，Brillouin 関数 $B_S(x)$ によって

```math
\begin{aligned}
M_a&=\frac n2 g\mu_BS
B_S\left(\frac{g\mu_BS H_a'}{kT}\right),\\
M_b&=\frac n2 g\mu_BS
B_S\left(\frac{g\mu_BS H_b'}{kT}\right)
\end{aligned}
\tag{2}
```

と表される．
ここで， $n$ は単位体積あたりの全格子点数， $g$ は Landé の $g$ 因子， $\mu_B$ は Bohr 磁子， $S$ はスピン量子数， $k$ は Boltzmann 定数， $T$ は絶対温度である．

$T<T_N$ では，外部磁場がないときに反強磁性的な自発磁化が存在する．
磁化の向きを共通の軸に沿った符号付き成分として表せば，

```math
\boldsymbol M_a=\boldsymbol M',
\qquad
\boldsymbol M_b=-\boldsymbol M'
\tag{3}
```

と書ける．
また，以下では反強磁性的な秩序が成立する条件 $q_1>q_2$ を仮定する．

無磁場での自発磁化の大きさ $M'=|\boldsymbol M'|$ は，

```math
M'=\frac n2g\mu_BS
B_S\left(
\frac{g\mu_BS}{kT}(q_1-q_2)M'
\right)
\tag{4}
```

を満たす．
この式は $M'$ を陽に解く式ではなく，温度 $T$ ごとの $M'$ を定める自己無撞着方程式である．

磁化率は，外部磁場を十分小さくしたときの全磁化の変化を $\Delta M$ として，

```math
\chi=\frac{\Delta M}{H}
\tag{5}
```

で定義する．
反強磁性状態では，外部磁場が自発磁化 $\boldsymbol M'$ に平行か垂直かによって応答が異なるため，それぞれを分けて計算する必要がある．

### 2．垂直磁化率 $\chi_\perp$

まず，外部磁場 $\boldsymbol H$ が自発磁化 $\boldsymbol M'$ に垂直な場合を考える．
このとき，磁化の主な変化は大きさの変化ではなく，向きの変化である．
外部磁場が十分小さい場合，二つの部分格子の磁化は同じ方向へわずかに傾く．

$\boldsymbol M'$ を $z$ 方向，外部磁場を $x$ 方向とする．
二つの部分格子の磁化がそれぞれ同じ角度 $\theta$ だけ傾くとすると，

```math
\begin{aligned}
\boldsymbol M_a
&=M'(\sin\theta\,\hat{\boldsymbol x}
+\cos\theta\,\hat{\boldsymbol z}),\\
\boldsymbol M_b
&=M'(\sin\theta\,\hat{\boldsymbol x}
-\cos\theta\,\hat{\boldsymbol z})
\end{aligned}
\tag{6}
```

と表せる．
したがって，全磁化 $\boldsymbol M=\boldsymbol M_a+\boldsymbol M_b$ は

```math
M_x=2M'\sin\theta
\simeq 2M'\theta
\tag{7}
```

となる．
ここでは $\theta\ll1$ として $\sin\theta\simeq\theta$ を用いた．

次に，分子場の方向と磁化の方向が平行であるという条件を用いる．
式 (1) から，部分格子 $a$ が受ける有効磁場の成分は

```math
\begin{aligned}
H_{a,x}'&=H-(q_1+q_2)M'\sin\theta,\\
H_{a,z}'&=(q_1-q_2)M'\cos\theta
\end{aligned}
\tag{8}
```

である．
有効磁場 $\boldsymbol H_a'$ と $\boldsymbol M_a$ は平行なので，

```math
\frac{H_{a,x}'}{H_{a,z}'}
=\tan\theta
\tag{9}
```

が成り立つ．
式 (8)，(9) に $\sin\theta\simeq\theta$ ， $\cos\theta\simeq1$ ， $\tan\theta\simeq\theta$ を代入すると，

```math
\frac{H-(q_1+q_2)M'\theta}
{(q_1-q_2)M'}=\theta
```

を得る．
両辺に $(q_1-q_2)M'$ を掛けて整理すると，

```math
\begin{aligned}
H
&=\{(q_1-q_2)+(q_1+q_2)\}M'\theta\\
&=2q_1M'\theta
\end{aligned}
```

である．
したがって，

```math
\theta=\frac{H}{2q_1M'}
\tag{10}
```

となる．
これを式 (7) に代入すれば，

```math
M_x\simeq 2M'\frac{H}{2q_1M'}
=\frac{H}{q_1}
```

である．
よって，垂直磁化率は

```math
\boxed{\chi_\perp=\frac{M_x}{H}=\frac1{q_1}}
\tag{11}
```

となる．
この結果は，分子場近似の範囲で $T<T_N$ において温度に依存しない．

### 3．平行磁化率 $\chi_\parallel$

次に，外部磁場 $\boldsymbol H$ が $\boldsymbol M'$ と平行な場合を考える．
この場合，外部磁場は部分格子磁化の大きさを変化させる．
したがって，Brillouin 関数を用いた自己無撞着方程式を，外部磁場と磁化の小さな変化について一次まで展開する．

磁化を

```math
M_a=M'+\Delta M_a,
\qquad
M_b=-M'+\Delta M_b
\tag{12}
```

とおく．
ここで $\Delta M_a,\Delta M_b$ は，外部磁場によって生じる各部分格子の符号付き磁化の変化である．
全磁化は無磁場ではゼロであるため，外部磁場による全磁化の変化は

```math
\Delta M=\Delta M_a+\Delta M_b
\tag{13}
````

となる．

式 (2) を外部磁場 $H$ と磁化の変化について一次まで展開する．
Brillouin 関数の微分を $B_S'(x)=dB_S(x)/dx$ と表し，

```math
x=\frac{g\mu_BS}{kT}(q_1-q_2)M'
\tag{14}
```

と定義する．
無磁場では，部分格子 $a$ と $b$ が受ける有効磁場は大きさが等しく向きが反対である．
Brillouin 関数は奇関数であり，その導関数は偶関数であるため，二つの部分格子における一次応答の係数は等しくなる．

そこで，

```math
A(T)=\frac{n g^2\mu_B^2S^2}{2kT}B_S'(x)
\tag{15}
```

とおけば，線形化した自己無撞着方程式は

```math
\begin{cases}
\Delta M_a
=A(T)\{H-q_2\Delta M_a-q_1\Delta M_b\},\\[2mm]
\Delta M_b
=A(T)\{H-q_1\Delta M_a-q_2\Delta M_b\}
\end{cases}
\tag{16}
```

となる．

式 (16) の二つの式を加えると，

```math
\Delta M
=A(T)\{2H-(q_1+q_2)\Delta M\}
\tag{17}
```

である．
ここで，磁場に対する全磁化の応答を求めるため， $\Delta M$ について整理する．

```math
\{1+(q_1+q_2)A(T)\}\Delta M
=2A(T)H
```

したがって，

```math
\boxed{
\chi_\parallel(T)
=\frac{\Delta M}{H}
=\frac{2A(T)}
{1+(q_1+q_2)A(T)}
}
\tag{18}
```

を得る．
分子に係数 $2$ があるのは，外部磁場に対して二つの部分格子の磁化がともに変化し，全磁化の変化がその和で与えられるためである．

#### 3.1．Curie 定数 $C$ を用いた表現

解答例と同様に，

```math
C=\frac{n g^2\mu_B^2S(S+1)}{3k}
\tag{19}
```

を用いる．
式 (15) の $A(T)$ は

```math
A(T)=\frac{C}{2T}\frac{3S}{S+1}B_S'(x)
\tag{20}
```

と書ける．
さらに，

```math
D(T)=\frac{3CS}{S+1}B_S'(x)
\tag{21}
```

と定義すれば $A(T)=D(T)/(2T)$ である．
これを式 (18) に代入して分子と分母に $T$ を掛けると，

```math
\boxed{
\chi_\parallel(T)=
\frac{D(T)}
{T+\dfrac12(q_1+q_2)D(T)}
}
\tag{22}
```

となる．
すなわち，

```math
\boxed{
\chi_\parallel(T)=
\frac{\dfrac{3CS}{S+1}B_S'(x)}
{T+\dfrac12(q_1+q_2)
\dfrac{3CS}{S+1}B_S'(x)}
}
\tag{23}
```

である．
ここで $x$ は式 (14) で定義したものであり， $M'$ は式 (4) の自己無撞着方程式で定まる．
したがって，平行磁化率は $M'(T)$ を通して温度に依存する．

### 4．Néel 温度での極限の確認

$T\to T_N^{-}$ では，自発磁化 $M'\to0$ となる．
したがって式 (14) より $x\to0$ であり，Brillouin 関数の微分は

```math
B_S'(0)=\frac{S+1}{3S}
\tag{24}
```

となる．
式 (21) から，

```math
D(T)\longrightarrow C
\qquad (T\to T_N^-)
\tag{25}
```

を得る．
よって，式 (22) より，

```math
\chi_\parallel(T_N^-)
=\frac{C}{T_N+\dfrac12(q_1+q_2)C}
\tag{26}
```

である．

一方，問題 [13] で求めた Néel 温度は

```math
T_N=\frac C2(q_1-q_2)
\tag{27}
```

である．
式 (27) を式 (26) に代入すると，

```math
\begin{aligned}
\chi_\parallel(T_N^-)
&=\frac{C}
{\dfrac C2(q_1-q_2)+\dfrac C2(q_1+q_2)}\\[2mm]
&=\frac{C}{q_1C}\\[2mm]
&=\frac1{q_1}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\chi_\parallel(T_N^-)=\chi_\perp=\frac1{q_1}
}
\tag{28}
```

である．
Néel 温度に近づくと自発磁化が消失し，磁場の方向による磁化率の差も消失することが分かる．

### 最終結果

分子場近似による $T<T_N$ の磁化率は，外部磁場の方向によって異なる．
垂直磁化率は

```math
\boxed{\chi_\perp=\frac1{q_1}}
```

であり，平行磁化率は

```math
\boxed{
\chi_\parallel(T)=
\frac{\dfrac{3CS}{S+1}B_S'(x)}
{T+\dfrac12(q_1+q_2)
\dfrac{3CS}{S+1}B_S'(x)}
}
```

である．
ここで，

```math
C=\frac{n g^2\mu_B^2S(S+1)}{3k},
\qquad
x=\frac{g\mu_BS}{kT}(q_1-q_2)M'
```

であり， $M'$ は式 (4) の自己無撞着方程式で定まる．
平行磁化率は温度とともに変化する一方，垂直磁化率は分子場近似のもとでは $T<T_N$ で一定である．
また，Néel 温度では両者は同じ値 $1/q_1$ に一致する．
