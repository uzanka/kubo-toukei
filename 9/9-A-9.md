# 演習問題【9-A-9】

## 解答

### 1．電子密度とポテンシャルの関係

金属表面を $x=0$ とし，金属の外側 $x>0$ に存在する電子の密度を $n(x)$ ，静電ポテンシャルを $\varphi(x)$ とする．
金属表面のポテンシャルを基準として，

```math
\varphi(0)=0
```

と定める．

電子の電荷は $-e$ であるため，電子のポテンシャルエネルギー $V(x)$ は

```math
\boxed{V(x)=-e\varphi(x)}
\tag{1}
```

である．

金属の外側の電子ガスは十分に希薄であり，古典的なボルツマン分布で扱えるとする．
このとき，電子密度はポテンシャルエネルギーに従って

```math
n(x)=n_0\exp\left(-\frac{V(x)}{kT}\right)
\tag{2}
```

と表される．
ここで， $k$ はボルツマン定数， $T$ は絶対温度， $n_0=n(0)$ は金属表面での電子密度である．
式 (1) を用いれば，

```math
n(x)=n_0\exp\left(\frac{e\varphi(x)}{kT}\right)
```

とも書ける．

### 2．ポアソン方程式による微分方程式

次に，静電ポテンシャルと電子密度を結び付けるポアソン方程式を用いる．
ガウス単位系では，

```math
\frac{d^2\varphi}{dx^2}=-4\pi\rho(x)
```

である．
ここで $\rho(x)$ は電荷密度であり，金属外部の電子の電荷密度は

```math
\rho(x)=-en(x)
```

である．
したがって，

```math
\boxed{
\frac{d^2\varphi}{dx^2}=4\pi en(x)
}
\tag{3}
```

となる．

式 (1) より $\varphi(x)=-V(x)/e$ であるから，式 (3) は

```math
-\frac1e\frac{d^2V}{dx^2}=4\pi en(x)
```

すなわち，

```math
\frac{d^2V}{dx^2}=-4\pi e^2n(x)
```

と書ける．
これに式 (2) を代入すると，

```math
\boxed{
V''(x)=-4\pi e^2n_0
\exp\left(-\frac{V(x)}{kT}\right)
}
\tag{4}
```

を得る．
これが，電子密度とポテンシャルを結び付ける非線形微分方程式である．

### 3．微分方程式の積分

式 (4) の両辺に $V'(x)=dV/dx$ を掛けると，

```math
V'V''=-4\pi e^2n_0
\exp\left(-\frac{V}{kT}\right)V'
\tag{5}
```

となる．
左辺は

```math
V'V''=\frac{d}{dx}
\left[\frac12(V')^2\right]
```

と表される．
一方，右辺は

```math
-4\pi e^2n_0
\exp\left(-\frac{V}{kT}\right)V'
=
\frac{d}{dx}
\left[
4\pi e^2n_0kT
\exp\left(-\frac{V}{kT}\right)
\right]
```

である．
したがって，式 (5) を積分すると，

```math
\frac12(V')^2
=4\pi e^2n_0kT
\exp\left(-\frac{V}{kT}\right)+C
\tag{6}
```

を得る．
ここで $C$ は積分定数である．

次に，無限遠 $x\to\infty$ での境界条件を考える．
電子密度は無限遠でゼロになるため，式 (2) より

```math
n(x)\to0
\quad\Longrightarrow\quad
V(x)\to+\infty
\qquad (x\to\infty)
\tag{7}
```

となる．
また，無限遠では電場がゼロに近づく．
電場は

```math
E_x=-\frac{d\varphi}{dx}=\frac{V'}{e}
```

であるため，

```math
V'(x)\to0
\qquad (x\to\infty)
\tag{8}
```

となる．
式 (7)，(8) を式 (6) に代入すると $C=0$ である．
よって，

```math
\frac12(V')^2
=4\pi e^2n_0kT
\exp\left(-\frac{V}{kT}\right)
```

となり，

```math
(V')^2
=8\pi e^2n_0kT
\exp\left(-\frac{V}{kT}\right)
\tag{9}
```

を得る．
金属表面から離れるにつれて $V(x)$ は増加するので，正の平方根を選ぶ．
したがって，

```math
\boxed{
V'=\sqrt{8\pi e^2n_0kT}
\exp\left(-\frac{V}{2kT}\right)
}
\tag{10}
```

である．

### 4．変数分離と積分定数 $x_0$ の決定

式 (10) を変数分離すると，

```math
\exp\left(\frac{V}{2kT}\right)dV
=\sqrt{8\pi e^2n_0kT}\,dx
\tag{11}
```

となる．
両辺を積分すれば，

```math
2kT\exp\left(\frac{V}{2kT}\right)
=\sqrt{8\pi e^2n_0kT}(x+x_0)
```

を得る．
ここで $x_0$ は積分定数を長さの次元で表したものである．
整理すると，

```math
\boxed{
\exp\left(\frac{V}{2kT}\right)
=\sqrt{\frac{2\pi n_0e^2}{kT}}(x+x_0)
}
\tag{12}
```

となる．

$x_0$ を求めるために，表面での境界条件 $V(0)=0$ を用いる．
式 (12) に $x=0$ ， $V=0$ を代入すると，

```math
1=\sqrt{\frac{2\pi n_0e^2}{kT}}x_0
```

であるから，

```math
\boxed{
x_0=\sqrt{\frac{kT}{2\pi n_0e^2}}
}
\tag{13}
```

となる．
これを式 (12) に代入すると，

```math
\exp\left(\frac{V}{2kT}\right)
=\frac{x+x_0}{x_0}
=1+\frac{x}{x_0}
\tag{14}
```

を得る．
両辺の対数をとれば，

```math
\boxed{
V(x)=2kT\log\left(1+\frac{x}{x_0}\right)
}
\tag{15}
```

となる．

### 5．電子密度分布の導出

最後に，式 (15) をボルツマン分布の式 (2) に代入する．

```math
\begin{aligned}
n(x)
&=n_0\exp\left(-\frac{V(x)}{kT}\right)\\
&=n_0\exp\left[
-2\log\left(1+\frac{x}{x_0}\right)
\right]\\
&=n_0\left(1+\frac{x}{x_0}\right)^{-2}
\end{aligned}
```

したがって，

```math
\boxed{
n(x)=n_0\left(\frac{x_0}{x+x_0}\right)^2
}
\tag{16}
```

を得る．
$n_0x_0^2$ は $x$ に依存しない定数であるため，

```math
\boxed{
n(x)\propto(x+x_0)^{-2}
}
```

となり，題意が示された．

ここで $x_0$ は，電子密度分布が減衰する距離を特徴付ける長さ尺度である．
Debye length と関連した尺度であり，式 (13) がこのモデルにおける具体的な値である．
