# 演習問題【9-A-12】

## 解答

### 1．分配関数と圧力の関係

粒子数 $N$ ，体積 $V$ ，温度 $T$ の古典的な気体を考える．
粒子 $i$ の位置を $\mathbf r_i$ とし，粒子間の全相互作用ポテンシャルを

```math
U(\mathbf r_1,\ldots,\mathbf r_N)
=\sum_{i<j}u(r_{ij})
```

とする．
ここで，

```math
r_{ij}=|\mathbf r_i-\mathbf r_j|
```

は粒子 $i$ と粒子 $j$ の距離である．

配置に関する分配関数は

```math
Q_N(V)=\frac{1}{N!}
\int_V\cdots\int_V
e^{-\beta U(\mathbf r_1,\ldots,\mathbf r_N)}
\,d\mathbf r_1\cdots d\mathbf r_N
```

と表される．
ただし， $\beta=1/(kT)$ であり， $k$ はボルツマン定数である．
運動量についての積分は体積 $V$ に依存しないため，圧力を求める際にはこの配置分配関数を用いればよい．
すなわち，

```math
p=kT\frac{\partial\ln Q_N}{\partial V}
=\frac{kT}{Q_N}\frac{\partial Q_N}{\partial V}
\tag{1}
```

である．

### 2．座標のスケーリングによるビリアルの式の導出

問題のヒントに従い，すべての粒子の座標を

```math
\mathbf r_i=\alpha\mathbf r_i'
```

と変換する．
このとき，体積要素は

```math
d\mathbf r_i=\alpha^3d\mathbf r_i'
```

と変換される．
また，変換前後の体積を $V$ ， $V'$ とすれば，

```math
V=\alpha^3V'
```

である．
したがって，分配関数は

```math
Q_N(V)=\frac{\alpha^{3N}}{N!}
\int_{V'}\cdots\int_{V'}
e^{-\beta U(\alpha\mathbf r_1',\ldots,\alpha\mathbf r_N')}
\,d\mathbf r_1'\cdots d\mathbf r_N'
\tag{2}
```

と書ける．

ここでは，変換後の積分領域 $V'$ を固定して $\alpha$ で微分し，最後に元の系に対応する $\alpha=1$ を代入する．

$V=\alpha^3V'$ より，

```math
\frac{dV}{d\alpha}=\frac{3V}{\alpha}
```

である．
したがって，連鎖律から

```math
\frac{\partial Q_N}{\partial V}
=\frac{\partial Q_N}{\partial\alpha}
\frac{d\alpha}{dV}
=\frac{\alpha}{3V}\frac{\partial Q_N}{\partial\alpha}
```

となり， $\alpha=1$ では

```math
\left.\frac{\partial Q_N}{\partial V}\right|_{\alpha=1}
=\frac{1}{3V}
\left.\frac{\partial Q_N}{\partial\alpha}\right|_{\alpha=1}
\tag{3}
```

を得る．

次に，式 (2) を $\alpha$ で微分する．
積分の前にある $\alpha^{3N}$ を微分すると $3N\alpha^{3N-1}$ が生じる．
また，指数関数を微分すると，ポテンシャルの微分から項が生じる．
これらを合わせ， $\alpha=1$ とすると，

```math
\left.\frac{\partial Q_N}{\partial\alpha}\right|_{\alpha=1}
=
3NQ_N
-\frac{\beta}{N!}
\int_V\cdots\int_V
\left(
\sum_{i=1}^{N}\nabla_{\mathbf r_i}U\cdot\mathbf r_i
\right)
e^{-\beta U}\,
d\mathbf r_1\cdots d\mathbf r_N
\tag{4}
```

となる．
ここで， $\nabla_{\mathbf r_i}U$ は粒子 $i$ の座標についての勾配である．

式 (3)，(4) を用いると，

```math
\begin{aligned}
\frac{\partial Q_N}{\partial V}
={}&\frac{N}{V}Q_N\\
&-\frac{\beta}{3VN!}
\int_V\cdots\int_V
\left(
\sum_{i=1}^{N}\nabla_{\mathbf r_i}U\cdot\mathbf r_i
\right)
e^{-\beta U}\,
d\mathbf r_1\cdots d\mathbf r_N
\end{aligned}
\tag{5}
```

を得る．

ここで，2体相互作用の形 $U=\sum_{i<j}u(r_{ij})$ を利用する．
粒子対 $i,j$ によるポテンシャル $u(r_{ij})$ について，

```math
\nabla_{\mathbf r_i}u(r_{ij})
=\frac{du(r_{ij})}{dr_{ij}}
\frac{\mathbf r_i-\mathbf r_j}{r_{ij}}
```

であり，粒子 $i$ と粒子 $j$ の座標に関する寄与を合わせると，

```math
\begin{aligned}
&\mathbf r_i\cdot\nabla_{\mathbf r_i}u(r_{ij})
+\mathbf r_j\cdot\nabla_{\mathbf r_j}u(r_{ij})\\
&\qquad=
\frac{du(r_{ij})}{dr_{ij}}
\frac{(\mathbf r_i-\mathbf r_j)\cdot(\mathbf r_i-\mathbf r_j)}
{r_{ij}}\\
&\qquad=r_{ij}\frac{du(r_{ij})}{dr_{ij}}
\end{aligned}
```

となる．
すべての粒子対について和を取れば，

```math
\sum_{i=1}^{N}\nabla_{\mathbf r_i}U\cdot\mathbf r_i
=\sum_{i<j}r_{ij}\frac{du(r_{ij})}{dr_{ij}}
\tag{6}
```

である．

式 (5)，(6) を式 (1) に代入する．
$n=N/V$ とすれば，

```math
\boxed{
p=nkT-\frac{1}{3V}
\left\langle
\sum_{i<j}r_{ij}\frac{du(r_{ij})}{dr_{ij}}
\right\rangle
}
\tag{7}
```

を得る．
ここで，山括弧 $\langle\cdots\rangle$ は熱平衡分布に関する平均を表す．
式 (7) は，圧力が理想気体の項 $nkT$ と，相互作用に由来する補正項からなることを示している．
これが本問題で用いるビリアルの式である．

### 3．2粒子分布関数を用いた表現

全粒子の規格化された分布関数を

```math
F_N(\mathbf r_1,\ldots,\mathbf r_N)
=\frac{1}{N!Q_N}e^{-\beta U}
```

とする．
この分布関数を用いて，2粒子分布関数を

```math
F_2(\mathbf r_1,\mathbf r_2)
=N(N-1)\int
F_N(\mathbf r_1,\ldots,\mathbf r_N)
\,d\mathbf r_3\cdots d\mathbf r_N
\tag{8}
```

と定義する．

式 (8) の $F_2$ は，順序を区別した粒子対を数える分布関数である．
一方，式 (7) の和 $\sum_{i<j}$ は，各粒子対を一度ずつ数えている．
この違いから，任意の粒子対の関数 $f(r_{ij})$ について，

```math
\left\langle\sum_{i<j}f(r_{ij})\right\rangle
=\frac12\iint
F_2(\mathbf r_1,\mathbf r_2)
f(r_{12})\,d\mathbf r_1d\mathbf r_2
\tag{9}
```

となる．
右辺に $1/2$ があるのは，順序を区別した粒子対では，同じ対が $(i,j)$ と $(j,i)$ の2回数えられるためである．

式 (9) で

```math
f(r_{12})=r_{12}\frac{du(r_{12})}{dr_{12}}
```

とすれば，式 (7) は

```math
p=nkT-\frac{1}{6V}
\iint
F_2(\mathbf r_1,\mathbf r_2)
r_{12}\frac{du(r_{12})}{dr_{12}}
\,d\mathbf r_1d\mathbf r_2
\tag{10}
```

と書き換えられる．

前問で定義された2粒子相関関数を用いると，一様な流体では

```math
F_2(\mathbf r_1,\mathbf r_2)
=n^2g(\mathbf r_2-\mathbf r_1)
=n^2g(r_{12})
\tag{11}
```

である．
ここで，中心力を考えているため， $g$ は粒子間距離 $r_{12}$ のみの関数である．

式 (11) を式 (10) に代入すると，

```math
p=nkT-\frac{n^2}{6V}
\iint
r_{12}\frac{du(r_{12})}{dr_{12}}
g(r_{12})\,d\mathbf r_1d\mathbf r_2
\tag{12}
```

となる．

### 4．相対座標による積分の変換

式 (12) の被積分関数は，粒子1と粒子2の絶対位置ではなく，両者の相対位置だけに依存する．
そこで，相対座標

```math
\mathbf r=\mathbf r_2-\mathbf r_1
```

を導入する．
一様な巨視的流体で境界の影響を無視すれば， $\mathbf r_1$ に関する積分は体積 $V$ を与え，二重積分は

```math
\begin{aligned}
&\iint
r_{12}\frac{du(r_{12})}{dr_{12}}
g(r_{12})\,d\mathbf r_1d\mathbf r_2\\
&\qquad=
V\int
r\frac{du(r)}{dr}g(r)\,d^3\mathbf r
\end{aligned}
\tag{13}
```

と変形できる．

さらに，系は球対称であり，被積分関数は距離 $r=|\mathbf r|$ のみの関数である．
球座標の体積要素

```math
d^3\mathbf r=4\pi r^2dr
```

を用いると，

```math
\begin{aligned}
\int r\frac{du(r)}{dr}g(r)\,d^3\mathbf r
&=4\pi\int_0^\infty
r\frac{du(r)}{dr}g(r)r^2\,dr\\
&=4\pi\int_0^\infty
\frac{du(r)}{dr}g(r)r^3\,dr
\end{aligned}
\tag{14}
```

である．

式 (13)，(14) を式 (12) に代入すれば，

```math
\begin{aligned}
p
&=nkT-\frac{n^2}{6V}\,
V\,4\pi\int_0^\infty
\frac{du(r)}{dr}g(r)r^3\,dr\\
&=nkT-\frac{2\pi}{3}n^2
\int_0^\infty
\frac{du(r)}{dr}g(r)r^3\,dr
\end{aligned}
```

となる．
したがって，題意の

```math
\boxed{
p=nkT-\frac{2\pi}{3}n^2
\int_0^\infty
\frac{du(r)}{dr}g(r)r^3\,dr
}
```

が得られる．

### 補足：式の物理的意味

第1項 $nkT$ は理想気体の圧力であり，第2項は粒子間相互作用による補正である．
例えば，ポテンシャルが距離とともに減少する斥力領域では $du/dr<0$ となり，この領域の寄与は圧力を増加させる方向に働く．
一方，距離とともに増加する引力領域では $du/dr>0$ となり，その寄与は圧力を減少させる方向に働く．
実際の補正の符号と大きさは，ポテンシャル $u(r)$ と相関関数 $g(r)$ の双方によって決まる．

なお，前問の $F_2=n^2g$ という規約を用いている．
有限粒子数で相関関数の遠距離極限を厳密に $1$ と定める場合には，粒子数に関する有限サイズ補正を区別する必要があるが，本問題の式は巨視的な一様流体で用いる標準的な形である．
