# 演習問題【9-C-19】

## 解答

## 1．分配関数とスピン変数の定義

等原子比の二元合金規則格子を考え，二つの副格子 $a,b$ の格子点数をそれぞれ $N/2$ とする．

問題 [15] の対応によって導入された変換後の Ising スピンを $\sigma_i$ とする．
元の占有スピンを $s_i$ ，副格子を表す符号を

```math
\eta_i=
\begin{cases}
+1 &(i\in a),\\
-1 &(i\in b)
\end{cases}
```

とすれば，この対応は

```math
\boxed{\sigma_i=\eta_i s_i}
\tag{1}
```

と表せる．

最近接結合は異なる副格子間にあるため，

```math
\eta_i\eta_j=-1
```

であり，

```math
\boxed{\sigma_i\sigma_j=-s_i s_j}
\tag{2}
```

となる．
以下では，問題文で与えられた変換後の分配関数の符号をそのまま用いる．

規則度 $X$ を固定した配置平均において，変換後のスピンの平均は両副格子ともに

```math
\boxed{
\langle\sigma_i\rangle_a
=
\langle\sigma_j\rangle_b=X
}
\tag{3}
```

である．

全格子点数を $N$ ，各格子点の配位数を $z$ ，最近接結合の総数を $Q$ とする．
周期的境界条件を課すか，熱力学極限で表面の影響を無視すれば，

```math
\boxed{Q=\frac{Nz}{2}}
\tag{4}
```

となる．

問題文の分配関数は，

```math
Z(X)=
\sum_{(x)}
\exp\left(
\beta\sum_{\langle ij\rangle}
\sigma_i\sigma_j
\right)
\tag{5}
```

である．
ここで，

```math
A=\sum_{\langle ij\rangle}\sigma_i\sigma_j,
\qquad
\beta=\frac{v}{2kT}
\tag{6}
```

とおく．

配置数を

```math
W(X)=\sum_{(x)}1
```

とし，条件付き配置平均を

```math
\langle A\rangle
=
\frac{\sum_{(x)}A}{W(X)}
```

と定義すれば，

```math
\boxed{
Z(X)=W(X)\langle e^{\beta A}\rangle
}
\tag{7}
```

となる．

指数関数を展開すると，

```math
\boxed{
\langle e^{\beta A}\rangle
=
1+\beta\langle A\rangle
+\frac{\beta^2}{2}\langle A^2\rangle
+O(\beta^3)
}
\tag{8}
```

である．
したがって， $\log Z(X)$ を $\beta^2$ まで求めるには，一次および二次モーメントを計算すればよい．

## 2．規則度 $X$ と配置数 $W(X)$

各副格子には $M=N/2$ 個の格子点がある．
規則度 $X$ を固定すると，各副格子の変換後のスピン $+1$ ， $-1$ の格子点数は，

```math
N_+=\frac N4(1+X),
\qquad
N_-=\frac N4(1-X)
\tag{9}
```

となる．

それぞれの副格子で $+1$ の格子点を選ぶ組合せ数は，

```math
\frac{(N/2)!}{N_+!N_-!}
```

である．
二つの副格子の配置は独立に選べるため，

```math
\boxed{
W(X)=
\left[
\frac{(N/2)!}
{\{N(1+X)/4\}!\{N(1-X)/4\}!}
\right]^2
}
\tag{10}
```

となる．

Stirling の公式

```math
\log m!=m\log m-m+o(m)
```

を用いると，

```math
\boxed{
\begin{aligned}
\log W(X)\simeq -N\bigg[
&\frac{1+X}{2}\log\frac{1+X}{2}\\
&+\frac{1-X}{2}\log\frac{1-X}{2}
\bigg]
\end{aligned}
}
\tag{11}
```

を得る．

ここでは自由エネルギー密度に寄与しない $o(N)$ の項を無視した．
また， $X=\pm1$ では $0\log0=0$ とする．

## 3．一次モーメント $\langle A\rangle$

規則度を固定した配置集合は，二つの副格子の配置集合の直積である．
したがって，副格子間の配置は独立である．

最近接結合は異なる副格子間にあるため，

```math
\begin{aligned}
\langle\sigma_i\sigma_j\rangle
&=\langle\sigma_i\rangle_a
\langle\sigma_j\rangle_b\\
&=X^2.
\end{aligned}
\tag{12}
```

したがって，

```math
\begin{aligned}
\langle A\rangle
&=\sum_{\langle ij\rangle}
\langle\sigma_i\sigma_j\rangle\\
&=QX^2.
\end{aligned}
```

よって，

```math
\boxed{\langle A\rangle=QX^2}
\tag{13}
```

となる．

## 4．二次モーメント $\langle A^2\rangle$

二次モーメントは，

```math
\langle A^2\rangle
=
\sum_{\langle ij\rangle}
\sum_{\langle kl\rangle}
\langle\sigma_i\sigma_j\sigma_k\sigma_l\rangle
\tag{14}
```

である．

二つの結合の関係を，同一の結合を選ぶ場合，1点を共有する場合，共有点を持たない場合の三つに分類する．

### 4.1．同一の結合を選ぶ場合

```math
\langle ij\rangle=\langle kl\rangle
```

ならば，

```math
\sigma_i\sigma_j\sigma_k\sigma_l
=\sigma_i^2\sigma_j^2=1.
```

結合数は $Q$ であるため，寄与は

```math
Q
\tag{15}
```

となる．

### 4.2．1点を共有する異なる結合を選ぶ場合

二つの結合が格子点 $i$ を共有するとき，

```math
\sigma_i\sigma_j\sigma_i\sigma_l
=\sigma_i^2\sigma_j\sigma_l
=\sigma_j\sigma_l.
```

$j,l$ は同じ副格子に属する異なる格子点である．
その相関を

```math
c=\langle\sigma_j\sigma_l\rangle
\tag{16}
```

とする．

一つの副格子には $M=N/2$ 個の格子点があり，そのうち $N_+$ 個が $+1$ ， $N_-$ 個が $-1$ である．
異なる二格子点のスピン積の平均は，

```math
c=
\frac{
N_+(N_+-1)+N_-(N_--1)-2N_+N_-
}{
M(M-1)
}.
\tag{17}
```

ここに，

```math
N_++N_-=M,
\qquad
N_+-N_-=MX
```

を代入すると，

```math
\begin{aligned}
c
&=\frac{MX^2-1}{M-1}\\
&=X^2-\frac{1-X^2}{M-1}.
\end{aligned}
```

したがって，

```math
\boxed{
c=X^2-\delta,
\qquad
\delta=\frac{1-X^2}{N/2-1}
}
\tag{18}
```

となる．

最初の結合は $Q$ 通りあり，その二つの端点のいずれかを共有する二つ目の結合は，それぞれ $z-1$ 通りある．
したがって，順序付き結合の組合せ数は，

```math
2Q(z-1)
```

である．
この場合の寄与は，

```math
\boxed{
2Q(z-1)(X^2-\delta)
}
\tag{19}
```

となる．

### 4.3．共有点を持たない異なる結合を選ぶ場合

二つの結合が共有点を持たない場合， $i,k$ は一方の副格子に属し， $j,l$ は他方の副格子に属する．

両副格子の配置は独立であるため，

```math
\begin{aligned}
\langle\sigma_i\sigma_j\sigma_k\sigma_l\rangle
&=\langle\sigma_i\sigma_k\rangle
\langle\sigma_j\sigma_l\rangle\\
&=(X^2-\delta)^2.
\end{aligned}
\tag{20}
```

この因数分解は，本問の固定規則度の配置集合では厳密に成立する．

全ての結合の順序付き組は $Q^2$ 通りである．
ここから，同一結合 $Q$ 通りと，1点を共有する異なる結合 $2Q(z-1)$ 通りを除くと，

```math
Q^2-Q-2Q(z-1)=Q^2-Q(2z-1).
```

したがって，この場合の寄与は，

```math
\boxed{
[Q^2-Q(2z-1)](X^2-\delta)^2
}
\tag{21}
```

となる．

### 4.4．二次モーメントの合計

以上を加えると，

```math
\boxed{
\begin{aligned}
\langle A^2\rangle
={}&Q+2Q(z-1)(X^2-\delta)\\
&+[Q^2-Q(2z-1)](X^2-\delta)^2
\end{aligned}
}
\tag{22}
```

を得る．

ここで，

```math
Q=\frac{Nz}{2}=O(N)
```

であり，

```math
\delta
=
\frac{2(1-X^2)}{N}+O(N^{-2})
\tag{23}
```

である．

式 (22) を $O(N)$ まで展開すると，

```math
\begin{aligned}
\langle A^2\rangle
={}&Q^2X^4\\
&+Q\left[
1+2(z-1)X^2-(2z-1)X^4
\right]\\
&-2Q^2X^2\delta+O(1).
\end{aligned}
\tag{24}
```

ここで，

```math
\begin{aligned}
-2Q^2X^2\delta
&\simeq
-2\left(\frac{Nz}{2}\right)^2
X^2\frac{2(1-X^2)}{N}\\
&=-2QzX^2(1-X^2).
\end{aligned}
\tag{25}
```

角括弧内を整理すると，

```math
\begin{aligned}
&1+2(z-1)X^2-(2z-1)X^4\\
&\qquad-2zX^2(1-X^2)\\
&=1-2X^2+X^4\\
&=(1-X^2)^2.
\end{aligned}
```

したがって，

```math
\boxed{
\langle A^2\rangle
=
Q^2X^4+Q(1-X^2)^2+O(1)
}
\tag{26}
```

となる．

## 5． $\log Z(X)$ の二次累積量近似

累積量展開を用いると，

```math
\boxed{
\begin{aligned}
\log\langle e^{\beta A}\rangle
={}&\beta\langle A\rangle\\
&+\frac{\beta^2}{2}
\left[
\langle A^2\rangle-\langle A\rangle^2
\right]
+O(\beta^3)
\end{aligned}
}
\tag{27}
```

となる．

式 (13)，(26) より，

```math
\begin{aligned}
\langle A^2\rangle-\langle A\rangle^2
&=Q^2X^4+Q(1-X^2)^2\\
&\qquad-Q^2X^4+O(1)\\
&=Q(1-X^2)^2+O(1).
\end{aligned}
```

よって，

```math
\log\langle e^{\beta A}\rangle
\simeq
\beta QX^2+
\frac{\beta^2}{2}Q(1-X^2)^2.
```

したがって，

```math
\boxed{
\log Z(X)
\simeq
\log W(X)+\beta QX^2
+\frac{\beta^2}{2}Q(1-X^2)^2
}
\tag{28}
```

となる．

式 (4)，(11) および

```math
\beta=\frac{v}{2kT}
```

を代入すると，

```math
\boxed{
\begin{aligned}
\log Z(X)\simeq{}&
-N\left[
\frac{1+X}{2}\log\frac{1+X}{2}\right.\\
&\left.\qquad+
\frac{1-X}{2}\log\frac{1-X}{2}
\right]\\
&+\frac{Nzv}{4kT}X^2\\
&+\frac{Nzv^2}{16(kT)^2}(1-X^2)^2.
\end{aligned}
}
\tag{29}
```

これは $\beta^2$ までの高温展開である．
三次以上の累積量は一般に自由エネルギー密度にも寄与し得るため，厳密な分配関数ではなく，二次近似として扱う．

## 6．自由エネルギーと平衡条件

規則度 $X$ を固定した拘束付き Helmholtz 自由エネルギーを，

```math
F(X)=-kT\log Z(X)
\tag{30}
```

と定義する．

式 (29) より，

```math
\boxed{
\begin{aligned}
F(X)\simeq{}&
-N\left[
\frac{zv}{4}X^2
+\frac{zv^2}{16kT}(1-X^2)^2
\right]\\
&+NkT\left[
\frac{1+X}{2}\log\frac{1+X}{2}\right.\\
&\left.\qquad+
\frac{1-X}{2}\log\frac{1-X}{2}
\right].
\end{aligned}
}
\tag{31}
```

全体系の分配関数は，

```math
Z_{\mathrm{tot}}=\sum_X Z(X)
```

で与えられる．
熱力学極限では，この和は拘束付き自由エネルギー $F(X)$ が最小となる規則度によって支配される．
したがって，平衡規則度は $F(X)$ の大域的最小値によって決まる．

停留条件は，

```math
\frac{\partial F}{\partial X}=0
\tag{32}
```

である．

式 (31) を微分すると，

```math
\begin{aligned}
0={}&-\frac{Nzv}{2}X
+\frac{Nzv^2}{4kT}X(1-X^2)\\
&+\frac{NkT}{2}\log\frac{1+X}{1-X}.
\end{aligned}
```

したがって，

```math
\boxed{
\frac12\log\frac{1+X}{1-X}
=
X\left[
\frac{zv}{2kT}
-\frac{zv^2}{4(kT)^2}(1-X^2)
\right]
}
\tag{33}
```

を得る．

## 7．転移条件とその適用範囲

無次元変数

```math
u=\frac{zv}{2kT}
\tag{34}
```

を導入する．
以下では $v>0$ とする．
温度を下げると $u$ は増加する．

式 (33) は，

```math
\frac12\log\frac{1+X}{1-X}
=
X\left[
u-\frac{u^2}{z}(1-X^2)
\right]
\tag{35}
```

となる．

自由エネルギー差を，

```math
\Delta f(X;u)=\frac{F(X)-F(0)}{NkT}
\tag{36}
```

と定義する．
また，

```math
h(X)=
\frac{1+X}{2}\log(1+X)
+
\frac{1-X}{2}\log(1-X)
\tag{37}
```

とおくと，

```math
\boxed{
\Delta f(X;u)
=
h(X)-\frac u2X^2
+\frac{u^2}{2z}X^2
-\frac{u^2}{4z}X^4
}
\tag{38}
```

となる．

関数 $h(X)$ は，

```math
\boxed{
h(X)=
\sum_{n=1}^{\infty}
\frac{X^{2n}}{(2n)(2n-1)}
}
\qquad (|X|\leq1)
\tag{39}
```

と展開できる．
したがって，

```math
\begin{aligned}
\Delta f(X;u)
={}&
\frac12\left(1-u+\frac{u^2}{z}\right)X^2\\
&+\left(\frac1{12}-\frac{u^2}{4z}\right)X^4\\
&+\sum_{n=3}^{\infty}
\frac{X^{2n}}{(2n)(2n-1)}.
\end{aligned}
\tag{40}
```

### 7.1．連続転移の条件

無秩序相は $X=0$ である．
その局所安定性は，二次係数

```math
a_2(u)=\frac12\left(1-u+\frac{u^2}{z}\right)
```

によって決まる．

無秩序相の局所安定性が変化する条件は，

```math
\boxed{
1-u+\frac{u^2}{z}=0
}
\tag{41}
```

である．

これを解くと，

```math
u^2-zu+z=0
```

となり，

```math
\boxed{
u_{\pm}
=
\frac z2
\left(
1\pm\sqrt{1-\frac4z}
\right)
}
\tag{42}
```

を得る．

実数解が存在するには，

```math
z\geq4
```

が必要である．
高温側から温度を下げると $u$ は増加するため，最初に局所安定性の条件に到達するのは小さい方の根，

```math
\boxed{
u_-=
\frac z2
\left(
1-\sqrt{1-\frac4z}
\right)
}
\tag{43}
```

である．

四次係数を，

```math
b_4(u)=\frac1{12}-\frac{u^2}{4z}
\tag{44}
```

とする．
局所安定性の境界 $u=u_-$ では，

```math
1-u_-+\frac{u_-^2}{z}=0
```

であるから，

```math
\frac{u_-^2}{z}=u_--1
```

となる．
したがって，

```math
\boxed{
b_4(u_-)=\frac{4-3u_-}{12}
}
\tag{45}
```

を得る．

四次係数が非負となる条件は，

```math
u_-\leq\frac43
```

である．
式 (43) を用いると，

```math
\boxed{
z\geq\frac{16}{3}
}
\tag{46}
```

となる．

この範囲では， $0\leq u\leq u_-$ に対して，

```math
a_2(u)\geq0,
\qquad
b_4(u)\geq0
```

が成立する．
さらに，式 (40) の六次以上の係数はすべて正である．
よって，

```math
\boxed{
\Delta f(X;u)\geq0
\qquad
(0\leq X\leq1,\ 0\leq u\leq u_-)
}
\tag{47}
```

となり，この範囲では $X=0$ が自由エネルギーの大域的最小値である．

$z>16/3$ では， $u=u_-$ における四次係数が正であり，その直後に二次係数が負になる．
このため，平衡規則度は $X=0$ から連続的に生じる．

一方， $z=16/3$ では四次係数もゼロになるが，六次係数は正である．
この場合も規則度は連続的に生じる．

したがって，

```math
\boxed{z\geq\frac{16}{3}}
```

が，今回の二次累積量近似における連続転移の条件である．

### 7.2．一次転移となる条件

次に，

```math
4\leq z<\frac{16}{3}
```

の場合を考える．
式 (45) より，

```math
b_4(u_-)<0
```

となる．

二次係数は $u=u_-$ でゼロであるから，

```math
\Delta f(X;u_-)
=
b_4(u_-)X^4+O(X^6)
```

である．
したがって，十分小さい非零の $X$ に対して，

```math
\boxed{\Delta f(X;u_-)<0}
\tag{48}
```

となる．

一方，高温極限 $u=0$ では，

```math
\Delta f(X;0)=h(X)>0
\qquad (X>0)
```

である．

したがって，高温側から $u$ を増加させると，ある $u_t<u_-$ において，有限の規則度を持つ状態と無秩序相の自由エネルギーが等しくなる．

このとき $u_t<u_-$ なので，

```math
a_2(u_t)>0
```

である．
したがって，共存する秩序相の規則度はゼロではなく，

```math
0<X_t<1
```

を満たす有限の値である．
よって，この転移は一次転移である．

特に $z=4$ では，

```math
a_2(u)=\frac{(u-2)^2}{8}
```

となる．
この場合，二次係数は負にならず， $u=2$ でゼロに接するだけである．
したがって，無秩序相の局所安定性が失われるわけではない．
それにもかかわらず四次係数は負であるため，無秩序相の局所安定性を保ったまま，有限規則度を持つ相が先に大域的に安定になる．
これも一次転移である．

一次転移温度は，無秩序相と秩序相の自由エネルギーが等しくなる条件，

```math
\Delta f(X_t;u_t)=0
```

と，秩序相の停留条件，

```math
\frac{\partial\Delta f(X_t;u_t)}{\partial X}=0
```

を連立して求める．
すなわち，

```math
\boxed{
\begin{cases}
h(X_t)-\dfrac{u_t}{2}X_t^2
+\dfrac{u_t^2}{2z}X_t^2
-\dfrac{u_t^2}{4z}X_t^4=0,\\[3mm]
\operatorname{artanh}X_t-u_tX_t
+\dfrac{u_t^2}{z}X_t(1-X_t^2)=0,\\[2mm]
0<X_t<1.
\end{cases}
}
\tag{49}
```

さらに，両相が大域的最小値であることを確認する．
解が得られれば，

```math
\boxed{
T_t=\frac{zv}{2ku_t}
}
\tag{50}
```

となる．
一般には，式 (49) を数値的に解く必要がある．

### 7.3．配位数が $4$ 未満の場合

$0<z<4$ では，

```math
a_2(u)
=
\frac12\left(1-u+\frac{u^2}{z}\right)
```

を平方完成すると，

```math
\boxed{
a_2(u)
=
\frac{(u-z/2)^2}{2z}
+\frac12\left(1-\frac z4\right)
}
\tag{51}
```

となる．
したがって，

```math
a_2(u)>0
```

がすべての $u\geq0$ で成立する．

このため，無秩序相の局所安定性が失われる条件から転移温度を求めることはできない．

切り詰めた自由エネルギーを全温度範囲に形式的に外挿し，有限規則度の状態と比較することは数学的には可能である．
しかし，そのような操作で得られる閾値は高温展開の適用範囲外の寄与に依存するため，実際の物理的な臨界配位数として解釈することはできない．

したがって， $z<4$ の物理的な転移の有無や転移温度については，本問の二次累積量近似だけから確定しない．

### 7.4．高温側から最初に現れる転移の分類

以上より，二次累積量近似に基づいて，高温側から冷却した際に最初に現れる転移は，次のように分類される．

```math
\boxed{
\begin{array}{ll}
z\geq16/3
&\text{連続転移},\\[1mm]
4\leq z<16/3
&\text{一次転移},\\[1mm]
0<z<4
&\text{本近似だけでは物理的転移を確定できない}.
\end{array}
}
\tag{52}
```

ここでの分類は，あくまで指定された高温展開の二次近似によるものであり，全温度範囲にわたる厳密な相図ではない．

## 8．低温側への外挿と近似の限界

式 (38) は，

```math
\Delta f(X;u)
=
h(X)+X^2
\left[
\frac{u^2}{4z}(2-X^2)-\frac u2
\right]
```

と書き換えられる．

ここで，

```math
0<X\leq1
```

であるから，

```math
2-X^2\geq1.
```

したがって，

```math
\begin{aligned}
\Delta f(X;u)
&\geq
h(X)+X^2
\left[
\frac{u^2}{4z}-\frac u2
\right]\\
&=
h(X)+\frac{u(u-2z)}{4z}X^2.
\end{aligned}
```

ゆえに，

```math
\boxed{
u\geq2z
\quad\Longrightarrow\quad
\Delta f(X;u)>0
\qquad (0<X\leq1)
}
\tag{53}
```

が成立する．

したがって，二次累積量近似の自由エネルギーを全温度範囲に形式的に外挿すると，\(u\geq2z\) では必ず $X=0$ が大域的最小値となる．

これは単なる可能性ではなく，今回の近似式から必然的に導かれる性質である．

しかし，

```math
u=\frac{zv}{2kT}
```

および

```math
\beta=\frac{v}{2kT}
```

より，

```math
u\geq2z
\quad\Longleftrightarrow\quad
\beta\geq2
```

である．
この領域は高温展開の適用範囲を大きく外れている．

したがって，低温側で現れる再入的な無秩序相は，二次累積量近似を適用範囲外まで外挿したことによる人工的な結果であり，実際の合金の低温相を表すものではない．

同様に， $z<4$ について切り詰めた自由エネルギーを全温度範囲で最小化して得られる形式的な閾値も，物理的な臨界配位数として用いてはならない．

したがって，本問では高温側から最初に現れる転移だけを求め，低温側の外挿結果を物理的な相転移として採用しない．

## 9．連続転移温度 $T_c$ の導出

通常の整数配位数では， $z\geq6$ の場合に

```math
z\geq\frac{16}{3}
```

が成立し，連続転移となる．

この場合，転移条件は小さい方の根，

```math
u_-=
\frac z2
\left(
1-\sqrt{1-\frac4z}
\right)
```

で与えられる．

定義

```math
u_-=\frac{zv}{2kT_c}
```

から，

```math
T_c=\frac{zv}{2ku_-}
\tag{54}
```

である．

式 (43) を代入すると，

```math
\begin{aligned}
T_c
&=
\frac{zv}
{2k\cdot\frac z2
\left(1-\sqrt{1-\frac4z}\right)}\\
&=
\frac{v}
{k\left(1-\sqrt{1-\frac4z}\right)}.
\end{aligned}
```

したがって，

```math
\boxed{
T_c=
\frac{v}{k}
\left(
1-\sqrt{1-\frac4z}
\right)^{-1}
\qquad
\left(z\geq\frac{16}{3},\ v>0\right)
}
\tag{55}
```

を得る．

これが二次累積量近似による連続転移温度である．

なお，臨界点における展開パラメータは，

```math
\beta_c
=
\frac{v}{2kT_c}
=
\frac12\left(1-\sqrt{1-\frac4z}\right)
```

であり， $z\geq16/3$ では，

```math
0<\beta_c\leq\frac14
```

となる．

ただし，この値だけで高次累積量の誤差が厳密に評価できるわけではない．
三次以上の累積量を省略したことによる誤差は残るため，式 (55) はあくまで指定された二次近似による転移温度である．

$4\leq z<16/3$ の一次転移では，式 (49)，(50) の共存条件によって転移温度を求める．

以上により，Kirkwood の二次累積量近似による規則格子変態の転移条件と転移温度が求められた．
