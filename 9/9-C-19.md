# 演習問題【9-C-19】

## 解答

### 1．分配関数の展開

長距離規則度 $X$ を固定した二元合金規則格子の分配関数は，

```math
Z(X)=\sum_{(x)}
\exp\left(\beta\sum_{\langle ij\rangle}\sigma_i\sigma_j\right)
=W(X)\left\langle e^{\beta A}\right\rangle
\tag{1}
```

と与えられる．
ここで，

```math
A=\sum_{\langle ij\rangle}\sigma_i\sigma_j,
\qquad
\beta=\frac{v}{2kT}
\tag{2}
```

である．
$\langle ij\rangle$ は隣接する格子点の組を表し， $\sum_{(x)}$ は長距離規則度 $X$ を満たす配置だけについて和を取ることを意味する．
また，

```math
W(X)=\sum_{(x)}1
```

は，規則度 $X$ を持つ配置の総数であり， $\langle\cdots\rangle$ はその配置に関する平均である．

指数関数を $\beta$ について展開すると，

```math
e^{\beta A}=1+\beta A+\frac{\beta^2}{2}A^2+\cdots
```

であるから，

```math
\boxed{
\left\langle e^{\beta A}\right\rangle
=1+\beta\langle A\rangle
+\frac{\beta^2}{2}\langle A^2\rangle+\cdots
}
\tag{3}
```

となる．
したがって， $\log Z(X)$ を $\beta^2$ の項まで求めるには， $\langle A\rangle$ と $\langle A^2\rangle$ を計算すればよい．

### 2．規則度 $X$ と配置数 $W(X)$

全格子点数を $N$ とし，二つの部分格子 $a,b$ のそれぞれには $N/2$ 個の格子点があるものとする．
規則度 $X$ が指定されているとき，各部分格子でスピン $+1$ を取る格子点数と $-1$ を取る格子点数は，それぞれ

```math
N_+=\frac{N}{4}(1+X),
\qquad
N_-=\frac{N}{4}(1-X)
\tag{4}
```

である．
したがって，規則度 $X$ を持つ配置の数は，

```math
\boxed{
W(X)=
\left[
\frac{(N/2)!}
{\{N(1+X)/4\}!\{N(1-X)/4\}!}
\right]^2
}
\tag{5}
```

となる．
二乗が付くのは，二つの部分格子でそれぞれ同じ組合せ数を数えるためである．

Stirling の公式

```math
\log m!\simeq m\log m-m
```

を用いると，

```math
\boxed{
\begin{aligned}
\log W(X)\simeq -N\bigg[
&\frac{1+X}{2}\log\frac{1+X}{2}\\
&+\frac{1-X}{2}\log\frac{1-X}{2}
\bigg]
\end{aligned}
}
\tag{6}
```

を得る．
これは，以下で自由エネルギーを求める際に用いる配置エントロピーの項である．

### 3．一次のモーメント $\langle A\rangle$

隣接結合の総数を $Q$ とする．
各格子点には $z$ 個の隣接格子点があるが，1つの結合は両端の格子点から重複して数えられるため，

```math
Q=\frac{Nz}{2}
\tag{7}
```

である．

ここで，最近接結合は異なる部分格子の間にある．
規則度 $X$ を固定した配置平均では，両部分格子の各スピンの平均は $X$ であり，異なる部分格子のスピンは独立に配置される．
したがって，

```math
\langle\sigma_i\sigma_j\rangle
=\langle\sigma_i\rangle\langle\sigma_j\rangle
=X^2
```

である．
よって，

```math
\begin{aligned}
\langle A\rangle
&=\sum_{\langle ij\rangle}
\langle\sigma_i\sigma_j\rangle\\
&=QX^2
\end{aligned}
```

すなわち，

```math
\boxed{\langle A\rangle=QX^2}
\tag{8}
```

となる．

### 4．二次のモーメント $\langle A^2\rangle$

二次のモーメントは，

```math
\langle A^2\rangle
=\sum_{\langle ij\rangle}
\sum_{\langle kl\rangle}
\langle\sigma_i\sigma_j\sigma_k\sigma_l\rangle
\tag{9}
```

である．
この和では，2つの結合の関係を，次の3種類に分類する．

#### 4.1．同一の結合を選ぶ場合

$\langle ij\rangle=\langle kl\rangle$ ならば，

```math
\sigma_i\sigma_j\sigma_k\sigma_l
=\sigma_i^2\sigma_j^2=1
```

である．
結合は $Q$ 本あるため，この場合の寄与は

```math
Q
\tag{10}
```

である．

#### 4.2．1点を共有する異なる結合を選ぶ場合

例えば，2つの結合が格子点 $i$ を共有する場合を考える．
このとき，

```math
\sigma_i\sigma_j\sigma_i\sigma_l
=\sigma_i^2\sigma_j\sigma_l
=\sigma_j\sigma_l
```

となる．
$j,l$ は同じ部分格子に属する異なる格子点であるため，その相関を

```math
c\equiv\langle\sigma_j\sigma_l\rangle
\tag{11}
```

とおく．

同じ部分格子には $M=N/2$ 個の格子点があり，そのうち $N_+$ 個が $+1$ ， $N_-$ 個が $-1$ である．
異なる2格子点のスピンの積の平均は，

```math
c=
\frac{
N_+(N_+-1)+N_-(N_--1)-2N_+N_-
}{M(M-1)}
```

となる．
分子の第1項と第2項は同符号のスピン対，第3項は異符号のスピン対の寄与である．
これを整理すると，

```math
c=\frac{MX^2-1}{M-1}
=X^2-\frac{1-X^2}{M-1}
```

である．
よって，

```math
\boxed{
c=X^2-\delta,
\qquad
\delta=\frac{1-X^2}{N/2-1}
\simeq\frac{2(1-X^2)}{N}
}
\tag{12}
```

を得る．

この分類の組合せ数を数える．
最初の結合は $Q$ 通りあり，その結合の端点は2つである．
一方の端点を共有する2つ目の結合は，最初の結合を除いた $z-1$ 通りである．
したがって，組合せ数は

```math
2Q(z-1)
```

であり，この場合の寄与は

```math
2Q(z-1)(X^2-\delta)
\tag{13}
```

となる．

#### 4.3．共有点を持たない異なる結合を選ぶ場合

2つの結合が共有点を持たない場合，Kirkwood の近似として，4スピンの相関を同じ部分格子内の2スピン相関の積で近似する．
すなわち，

```math
\langle\sigma_i\sigma_j\sigma_k\sigma_l\rangle
\simeq
\langle\sigma_i\sigma_k\rangle
\langle\sigma_j\sigma_l\rangle
=(X^2-\delta)^2
\tag{14}
```

とする．

全ての結合の組は $Q^2$ 通りであり，同一の結合 $Q$ 通りと，1点を共有する結合 $2Q(z-1)$ 通りを除くと，組合せ数は

```math
Q^2-Q-2Q(z-1)
=Q^2-Q(2z-1)
\tag{15}
```

である．
したがって，この場合の寄与は

```math
[Q^2-Q(2z-1)](X^2-\delta)^2
\tag{16}
```

となる．

#### 4.4．3種類の寄与を合計する

式 (10)，(13)，(16) より，

```math
\begin{aligned}
\langle A^2\rangle
={}&Q+2Q(z-1)(X^2-\delta)\\
&+[Q^2-Q(2z-1)](X^2-\delta)^2
\end{aligned}
\tag{17}
```

を得る．

ここで $Q=Nz/2=O(N)$ ， $\delta=2(1-X^2)/N+O(N^{-2})$ である．
自由エネルギーのような巨視的量を求めるため，式 (17) では $O(N)$ までの項を残す．
展開すると，

```math
\begin{aligned}
\langle A^2\rangle
={}&Q^2X^4
+Q\{1+2(z-1)X^2-(2z-1)X^4\}\\
&-2Q^2X^2\delta+O(1)
\end{aligned}
\tag{18}
```

となる．
ここで， $-2Q^2X^2\delta$ は $Q^2=O(N^2)$ と $\delta=O(N^{-1})$ の積であるため， $O(N)$ の項として残さなければならない．

式 (7)，(12) を用いると，

```math
\begin{aligned}
-2Q^2X^2\delta
&\simeq
-2\left(\frac{Nz}{2}\right)^2X^2
\frac{2(1-X^2)}{N}\\
&=-2QzX^2(1-X^2)
\end{aligned}
\tag{19}
```

となる．
したがって，

```math
\begin{aligned}
\langle A^2\rangle
\simeq{}&Q^2X^4\\
&+Q\big[
1+2(z-1)X^2-(2z-1)X^4\\
&\hspace{23mm}-2zX^2(1-X^2)
\big]+O(1)
\end{aligned}
```

である．
角括弧内を整理すると，

```math
\begin{aligned}
&1+2(z-1)X^2-(2z-1)X^4
-2zX^2(1-X^2)\\
&\qquad=1-2X^2+X^4
=(1-X^2)^2
\end{aligned}
```

となる．
よって，

```math
\boxed{
\langle A^2\rangle
\simeq Q^2X^4+Q(1-X^2)^2
}
\tag{20}
```

を得る．
これが Kirkwood の近似における二次モーメントである．

### 5．$\log Z(X)$ を $\beta^2$ まで求める

式 (3)，(8)，(20) から，

```math
\begin{aligned}
\langle e^{\beta A}\rangle
\simeq{}&
1+\beta QX^2\\
&+\frac{\beta^2}{2}
\left[Q^2X^4+Q(1-X^2)^2\right]
+\cdots
\end{aligned}
\tag{21}
```

である．
ここで，

```math
Z(X)=W(X)\langle e^{\beta A}\rangle
```

なので，

```math
\log Z(X)
=\log W(X)+\log\langle e^{\beta A}\rangle
\tag{22}
```

となる．

```math
\log(1+y)\simeq y-\frac{y^2}{2}
```

を用いて，式 (21) の対数を $\beta^2$ まで展開すると，

```math
\begin{aligned}
\log\langle e^{\beta A}\rangle
\simeq{}&
\beta QX^2\\
&+\frac{\beta^2}{2}
\left[Q^2X^4+Q(1-X^2)^2\right]\\
&-\frac{\beta^2}{2}Q^2X^4
\end{aligned}
```

となる．
このとき， $Q^2X^4$ に比例する項が相殺される．
したがって，

```math
\boxed{
\log Z(X)
\simeq\log W(X)+\beta QX^2
+\frac{\beta^2}{2}Q(1-X^2)^2
}
\tag{23}
```

を得る．
ここでは， $\log W$ と同様に $O(N)$ の項を保持し，巨視的な自由エネルギー密度に寄与しない $O(1)$ の補正項は無視している．

式 (6)，(7) を用いて書き換えると，

```math
\begin{aligned}
\log Z(X)\simeq{}&
-N\left[
\frac{1+X}{2}\log\frac{1+X}{2}
+\frac{1-X}{2}\log\frac{1-X}{2}
\right]\\
&+\frac{Nzv}{4kT}X^2
+\frac{Nzv^2}{16(kT)^2}(1-X^2)^2
\end{aligned}
\tag{24}
```

となる．

### 6．自由エネルギーと転移条件

Helmholtz の自由エネルギーを

```math
F(X)=-kT\log Z(X)
```

と定義する．
式 (24) を代入すると，

```math
\boxed{
\begin{aligned}
F(X)\simeq{}&
-N\left[
\frac{zv}{4}X^2+
\frac{zv^2}{16kT}(1-X^2)^2
\right]\\
&+NkT\left[
\frac{1+X}{2}\log\frac{1+X}{2}
+\frac{1-X}{2}\log\frac{1-X}{2}
\right]
\end{aligned}
}
\tag{25}
```

を得る．

平衡状態の規則度は自由エネルギーを最小にする値であり，停留条件は

```math
\frac{\partial F}{\partial X}=0
\tag{26}
```

である．
式 (25) を $X$ で微分すると，

```math
\begin{aligned}
0={}&-\frac{Nzv}{2}X
+\frac{Nzv^2}{4kT}X(1-X^2)\\
&+\frac{NkT}{2}\log\frac{1+X}{1-X}
\end{aligned}
```

となる．
両辺を $NkT$ で割って整理すれば，

```math
\boxed{
\frac12\log\frac{1+X}{1-X}
=X\left[
\frac{zv}{2kT}
-\frac{zv^2}{4(kT)^2}(1-X^2)
\right]
}
\tag{27}
```

を得る．

転移点では，無秩序相の $X=0$ から秩序度が生じ始める．
$X\to0$ では，

```math
\frac12\log\frac{1+X}{1-X}\simeq X
```

であるため，式 (27) を $X$ で割り，転移温度を $T_c$ と書けば，

```math
\boxed{
1=\frac{zv}{2kT_c}
-\frac{zv^2}{4(kT_c)^2}
}
\tag{28}
```

となる．

### 7．転移温度 $T_c$ の導出

式 (28) を解くため，

```math
u=\frac{zv}{2kT_c}
\tag{29}
```

とおく．
すると，

```math
\frac{zv^2}{4(kT_c)^2}=\frac{u^2}{z}
```

であるから，式 (28) は

```math
1=u-\frac{u^2}{z}
```

となる．
これを整理すると，

```math
u^2-zu+z=0
\tag{30}
```

である．
二次方程式の解は，

```math
u=\frac{z}{2}
\left(1\pm\sqrt{1-\frac4z}\right)
\tag{31}
```

となる．

この近似式で高温の無秩序相から温度を下げていくとき，最初に転移条件に達するのは，小さい方の $u$ に対応する解である．
$u=zv/(2kT_c)$ は温度に反比例するため，小さい $u$ は高い転移温度に対応する．
したがって，

```math
u=\frac{z}{2}
\left(1-\sqrt{1-\frac4z}\right)
```

を選ぶ．
式 (29) から，

```math
T_c=\frac{zv}{2ku}
```

であるため，

```math
\boxed{
T_c=
\frac{v}{k}
\left(1-\sqrt{1-\frac4z}\right)^{-1}
}
\tag{32}
```

を得る．
これが Kirkwood の近似により求められる規則格子変態の転移温度である．

なお，実数解が存在するには $z\ge4$ が必要である．
$z<4$ では，この二次近似から実数の転移温度は得られない．
また，式 (32) は $\beta^2$ までの高温展開に基づく近似値である．
