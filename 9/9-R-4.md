# 例題【9-R-4】

## 解答

### $n$ 体分布関数が満たす関係式の導出

#### 1．証明の方針

示すべき式は，

```math
\begin{aligned}
&\frac{\partial}{\partial\boldsymbol r_i}F_n\{\boldsymbol n\}
+\frac{1}{kT}
\frac{\partial U\{\boldsymbol n\}}{\partial\boldsymbol r_i}
F_n\{\boldsymbol n\}\\
&\quad+\frac{1}{kT}\int
\frac{\partial\phi(\boldsymbol r_i,\boldsymbol r_{n+1})}
{\partial\boldsymbol r_i}
F_{n+1}\{\boldsymbol n+1\}
\,d\boldsymbol r_{n+1}=0
\end{aligned}
\tag{1}
```

である．
ここで， $\boldsymbol n=(\boldsymbol r_1,\ldots,\boldsymbol r_n)$ は最初の $n$ 個の粒子の座標を表す．
また， $F_n$ は $n$ 体分布関数， $U\{\boldsymbol n\}$ は最初の $n$ 個の粒子間の相互作用ポテンシャル， $\phi(\boldsymbol r_i,\boldsymbol r_j)$ は粒子 $i$ と粒子 $j$ の二体相互作用ポテンシャルである．

証明では，まず系全体の分布に関する量を微分し，その後，残りの粒子の座標を積分する．
その際， $n$ 体分布関数と $n+1$ 体分布関数の定義を用いることで，式 (1) を導く．
以下では， $1\leq i\leq n<N$ とする．

#### 2．$D_N\{N\}$ を微分する

逆温度を

```math
\beta=\frac{1}{kT}
```

と定義する．
解答例に従い，

```math
D_N\{N\}
=\exp\left[\beta\left(F-U\{N\}\right)\right]
\tag{2}
```

とおく．
ここで， $F$ はヘルムホルツの自由エネルギー， $U\{N\}$ は $N$ 個すべての粒子の相互作用ポテンシャルである．
$F$ と $\beta$ は粒子の座標に依存しない定数である．

式 (2) を粒子 $i$ の座標 $\boldsymbol r_i$ について微分すると，指数関数の微分公式より，

```math
\frac{\partial D_N\{N\}}{\partial\boldsymbol r_i}
=-\beta
\frac{\partial U\{N\}}{\partial\boldsymbol r_i}
D_N\{N\}
```

となる．
したがって，

```math
\boxed{
\frac{\partial D_N\{N\}}{\partial\boldsymbol r_i}
+\beta
\frac{\partial U\{N\}}{\partial\boldsymbol r_i}
D_N\{N\}=0
}
\tag{3}
```

を得る．
これが証明の出発点である．

#### 3．$n$ 体分布関数の定義を用いる

$n$ 体分布関数は，式 (9.38) より，

```math
F_n\{\boldsymbol n\}
=\frac{\lambda^N}{(N-n)!}
\int\cdots\int D_N\{N\}\,
d\boldsymbol r_{n+1}\cdots d\boldsymbol r_N
\tag{4}
```

と定義される．
ここで， $\lambda$ は熱的ド・ブロイ波長に関係する量であり，積分は最初の $n$ 個の粒子の座標を固定し，残りの粒子の座標について行う．

式 (3) の両辺に $\lambda^N/(N-n)!$ を掛け， $\boldsymbol r_{n+1},\ldots,\boldsymbol r_N$ について積分する．
すると，

```math
\begin{aligned}
&\frac{\lambda^N}{(N-n)!}
\int\cdots\int
\frac{\partial D_N\{N\}}{\partial\boldsymbol r_i}
\,d\boldsymbol r_{n+1}\cdots d\boldsymbol r_N\\
&\quad+
\beta\frac{\lambda^N}{(N-n)!}
\int\cdots\int
\frac{\partial U\{N\}}{\partial\boldsymbol r_i}
D_N\{N\}\,
d\boldsymbol r_{n+1}\cdots d\boldsymbol r_N=0
\end{aligned}
\tag{5}
```

となる．

第1項では，積分領域が $\boldsymbol r_i$ に依存しないため，微分と積分の順序を交換できる．
したがって，式 (4) の定義から，

```math
\begin{aligned}
&\frac{\lambda^N}{(N-n)!}
\int\cdots\int
\frac{\partial D_N\{N\}}{\partial\boldsymbol r_i}
\,d\boldsymbol r_{n+1}\cdots d\boldsymbol r_N\\
&\qquad =
\frac{\partial F_n\{\boldsymbol n\}}{\partial\boldsymbol r_i}
\end{aligned}
\tag{6}
```

である．

#### 4．全相互作用ポテンシャルを分解する

全粒子の相互作用ポテンシャルは，

```math
U\{N\}
=\sum_{1\leq j<k\leq N}
\phi(\boldsymbol r_j,\boldsymbol r_k)
\tag{7}
```

である．
この和を，最初の $n$ 個の粒子どうしの相互作用，最初の $n$ 個と残りの粒子の相互作用，残りの粒子どうしの相互作用に分けると，

```math
\begin{aligned}
U\{N\}
={}&U\{\boldsymbol n\}\\
&+\sum_{\substack{1\leq j\leq n\\n<k\leq N}}
\phi(\boldsymbol r_j,\boldsymbol r_k)\\
&+\sum_{n<j<k\leq N}
\phi(\boldsymbol r_j,\boldsymbol r_k)
\end{aligned}
\tag{8}
```

となる．
ここで，

```math
U\{\boldsymbol n\}
=\sum_{1\leq j<k\leq n}
\phi(\boldsymbol r_j,\boldsymbol r_k)
\tag{9}
```

である．

式 (8) を $\boldsymbol r_i$ について微分する．
$i\leq n$ なので，最後の和は $\boldsymbol r_i$ に依存せず，微分するとゼロになる．
また，二体相互作用は粒子の入れ替えに対して対称であるとする．
したがって，

```math
\boxed{
\frac{\partial U\{N\}}{\partial\boldsymbol r_i}
=
\frac{\partial U\{\boldsymbol n\}}{\partial\boldsymbol r_i}
+\sum_{j=n+1}^{N}
\frac{\partial\phi(\boldsymbol r_i,\boldsymbol r_j)}
{\partial\boldsymbol r_i}
}
\tag{10}
```

となる．
この式は，粒子 $i$ に関係するポテンシャルの寄与を，最初の $n$ 個の粒子からの寄与と，残りの粒子からの寄与に分けたものである．

#### 5．積分した式を整理する

式 (10) を式 (5) の第2項に代入する．
すると，式 (5) は

```math
\begin{aligned}
0={}&
\frac{\partial F_n\{\boldsymbol n\}}{\partial\boldsymbol r_i}
+\beta\frac{\partial U\{\boldsymbol n\}}{\partial\boldsymbol r_i}
F_n\{\boldsymbol n\}\\
&+\beta\frac{\lambda^N}{(N-n)!}
\sum_{j=n+1}^{N}
\int\cdots\int
\frac{\partial\phi(\boldsymbol r_i,\boldsymbol r_j)}
{\partial\boldsymbol r_i}
D_N\{N\}\,
d\boldsymbol r_{n+1}\cdots d\boldsymbol r_N
\end{aligned}
\tag{11}
```

となる．
残るのは，式 (11) の最後の項を $F_{n+1}$ で表すことである．

和の中の $j$ 番目の項を考える．
この項では， $\boldsymbol r_j$ 以外の未指定座標を先に積分することができる．
$n+1$ 体分布関数の定義は，

```math
\begin{aligned}
F_{n+1}
&(\boldsymbol r_1,\ldots,\boldsymbol r_n,\boldsymbol r_j)\\
&=\frac{\lambda^N}{(N-n-1)!}
\int\cdots\int
D_N\{N\}\,
\prod_{\substack{k=n+1\\k\ne j}}^N
d\boldsymbol r_k
\end{aligned}
\tag{12}
```

である．
式 (12) の積分は，粒子 $j$ の座標を固定し，それ以外の未指定粒子の座標について行う．
これを変形すれば，

```math
\boxed{
\int\cdots\int D_N\{N\}
\prod_{\substack{k=n+1\\k\ne j}}^N
d\boldsymbol r_k
=
\frac{(N-n-1)!}{\lambda^N}
F_{n+1}(\boldsymbol r_1,\ldots,\boldsymbol r_n,\boldsymbol r_j)
}
\tag{13}
```

となる．

ここで，式 (11) の $j$ 番目の項では， $\boldsymbol r_j$ に関する積分も残っている．
式 (13) を使うと，その項は

```math
\begin{aligned}
&\int\cdots\int
\frac{\partial\phi(\boldsymbol r_i,\boldsymbol r_j)}
{\partial\boldsymbol r_i}
D_N\{N\}\,
d\boldsymbol r_{n+1}\cdots d\boldsymbol r_N\\
&\quad=
\frac{(N-n-1)!}{\lambda^N}
\int
\frac{\partial\phi(\boldsymbol r_i,\boldsymbol r_j)}
{\partial\boldsymbol r_i}
F_{n+1}(\boldsymbol r_1,\ldots,\boldsymbol r_n,\boldsymbol r_j)
\,d\boldsymbol r_j
\end{aligned}
\tag{14}
```

と書ける．

これを式 (11) の最後の項に代入すると，

```math
\begin{aligned}
&\beta\frac{\lambda^N}{(N-n)!}
\sum_{j=n+1}^{N}
\frac{(N-n-1)!}{\lambda^N}\\
&\quad\times
\int
\frac{\partial\phi(\boldsymbol r_i,\boldsymbol r_j)}
{\partial\boldsymbol r_i}
F_{n+1}(\boldsymbol r_1,\ldots,\boldsymbol r_n,\boldsymbol r_j)
\,d\boldsymbol r_j
\end{aligned}
\tag{15}
```

を得る．
係数を整理すると，

```math
\frac{\lambda^N}{(N-n)!}
\frac{(N-n-1)!}{\lambda^N}
=\frac{1}{N-n}
\tag{16}
```

である．
したがって，式 (15) は，

```math
\begin{aligned}
\frac{\beta}{N-n}
\sum_{j=n+1}^{N}
\int&
\frac{\partial\phi(\boldsymbol r_i,\boldsymbol r_j)}
{\partial\boldsymbol r_i}\\
&\times
F_{n+1}(\boldsymbol r_1,\ldots,\boldsymbol r_n,\boldsymbol r_j)
\,d\boldsymbol r_j
\end{aligned}
\tag{17}
```

となる．

#### 6．和を一つの積分にまとめる

同種粒子の交換対称性と積分変数の付け替えにより，式 (17) の和に現れる $N-n$ 個の項はすべて同じ値になる．
具体的には，積分変数 $\boldsymbol r_j$ を $\boldsymbol r_{n+1}$ と名前を付け替えれば，各項は

```math
\begin{aligned}
\int&
\frac{\partial\phi(\boldsymbol r_i,\boldsymbol r_{n+1})}
{\partial\boldsymbol r_i}\\
&\times
F_{n+1}(\boldsymbol r_1,\ldots,\boldsymbol r_n,\boldsymbol r_{n+1})
\,d\boldsymbol r_{n+1}
\end{aligned}
```

と同じ形で表される．
よって，その和はこの積分の $N-n$ 倍である．
式 (17) では分母にも $N-n$ があるため，これらが相殺される．
したがって，式 (11) の最後の項は，

```math
\begin{aligned}
\beta\int&
\frac{\partial\phi(\boldsymbol r_i,\boldsymbol r_{n+1})}
{\partial\boldsymbol r_i}\\
&\times
F_{n+1}(\boldsymbol r_1,\ldots,\boldsymbol r_n,\boldsymbol r_{n+1})
\,d\boldsymbol r_{n+1}
\end{aligned}
\tag{18}
```

となる．

#### 7．結論

式 (18) を式 (11) に代入すると，

```math
\begin{aligned}
&\frac{\partial F_n\{\boldsymbol n\}}{\partial\boldsymbol r_i}
+\beta\frac{\partial U\{\boldsymbol n\}}{\partial\boldsymbol r_i}
F_n\{\boldsymbol n\}\\
&\quad+\beta\int
\frac{\partial\phi(\boldsymbol r_i,\boldsymbol r_{n+1})}
{\partial\boldsymbol r_i}
F_{n+1}\{\boldsymbol n+1\}
\,d\boldsymbol r_{n+1}=0
\end{aligned}
\tag{19}
```

を得る．
最後に $\beta=1/(kT)$ を代入すれば，

```math
\boxed{
\begin{aligned}
&\frac{\partial}{\partial\boldsymbol r_i}F_n\{\boldsymbol n\}
+\frac{1}{kT}
\frac{\partial U\{\boldsymbol n\}}{\partial\boldsymbol r_i}
F_n\{\boldsymbol n\}\\
&\quad+\frac{1}{kT}\int
\frac{\partial\phi(\boldsymbol r_i,\boldsymbol r_{n+1})}
{\partial\boldsymbol r_i}
F_{n+1}\{\boldsymbol n+1\}
\,d\boldsymbol r_{n+1}=0
\end{aligned}
}
```

となり，示すべき式が得られたのである．

この式は， $n$ 体分布関数 $F_n$ が，隣接する階層の $n+1$ 体分布関数 $F_{n+1}$ と結び付いていることを示す関係式であり，BBGKY階層に属する式の一つである．
