# 演習問題【9-A-2】

## 解答

### 1．分子場近似と自発磁化の方程式

強磁性体の Heisenberg モデルにおいて，分子場近似を用いて自発磁化 $M$ を求める．
外部磁場を $\mathbf H$ ，磁化を $\mathbf M$ ，分子場定数を $q$ とすると，有効磁場は

```math
\mathbf H_{\mathrm{eff}}=\mathbf H+q\mathbf M
\tag{1}
```

である．

自発磁化は，外部磁場をゼロにしたときに自発的に生じる磁化である．
したがって， $\mathbf H=0$ とすると，

```math
\mathbf H_{\mathrm{eff}}=q\mathbf M
\tag{2}
```

となる．

スピン量子数を $S$ ，単位体積当たりのスピン数を $n$ ，ランデの $g$ 因子を $g$ ，ボーア磁子を $\mu_{\mathrm B}$ ，ボルツマン定数を $k$ ，絶対温度を $T$ とする．
分子場近似では，磁化の大きさはブリルアン関数 $B_S(x)$ を用いて

```math
M=ng\mu_{\mathrm B}S B_S(x)
\tag{3}
```

と表される．
ブリルアン関数の引数 $x$ は，有効磁場による磁気エネルギーと熱エネルギーの比であり，

```math
x=\frac{g\mu_{\mathrm B}S H_{\mathrm{eff}}}{kT}
```

で定義される．
式 (2) を代入すると，

```math
\boxed{x=\frac{qg\mu_{\mathrm B}SM}{kT}}
\tag{4}
```

となる．

したがって，自発磁化を決める自己無撞着方程式は，

```math
\boxed{
M=ng\mu_{\mathrm B}S
B_S\left(\frac{qg\mu_{\mathrm B}SM}{kT}\right)
}
\tag{5}
```

である．
これは，磁化 $M$ が周囲のスピンによって生じる有効磁場を決め，その有効磁場が再び磁化を決めるという関係を表す方程式である．

### 2．キュリー温度 $T_c$ の近傍

キュリー温度 $T_c$ の近くでは，自発磁化 $M$ が小さくなるため，式 (4) の $x$ も小さい．
このとき，ブリルアン関数を $x$ のべき級数で展開すると，

```math
B_S(x)=
\frac{S+1}{3S}x
-\frac{(S+1)\{(S+1)^2+S^2\}}{90S^3}x^3
+O(x^5)
\tag{6}
```

となる．

式 (6) を式 (3) に代入し，式 (4) を用いると，

```math
\begin{aligned}
M={}&
\frac{ng^2\mu_{\mathrm B}^2qS(S+1)}
{3kT}M\\
&-\frac{ng^4\mu_{\mathrm B}^4q^3S(S+1)
\{(S+1)^2+S^2\}}
{90k^3T^3}M^3
+O(M^5)
\end{aligned}
\tag{7}
```

を得る．
ここで，

```math
a=\frac{ng^2\mu_{\mathrm B}^2qS(S+1)}{3k}
\tag{8}
```

および

```math
b=\frac{ng^4\mu_{\mathrm B}^4q^3S(S+1)
\{(S+1)^2+S^2\}}{90k^3}
\tag{9}
```

と定義すると，式 (7) は

```math
M=\frac{a}{T}M-\frac{b}{T^3}M^3+O(M^5)
\tag{10}
```

となる．

自発磁化がゼロでない解が現れる境界では，式 (10) の一次の係数が $1$ となる．
この温度をキュリー温度 $T_c$ と定義すると，

```math
\frac{a}{T_c}=1
```

である．
したがって，

```math
\boxed{
T_c=\frac{ng^2\mu_{\mathrm B}^2qS(S+1)}{3k}
}
\tag{11}
```

が得られる．

式 (10) で $a=T_c$ とし，非零の磁化 $M$ を考えると，

```math
1=\frac{T_c}{T}-\frac{b}{T^3}M^2
```

である．
これを $M^2$ について解けば，

```math
M^2=\frac{T^3}{b}
\left(\frac{T_c}{T}-1\right)
=\frac{T^2}{b}(T_c-T)
\tag{12}
```

となる．
キュリー温度の直下では $T\approx T_c$ であるため，

```math
M^2\approx\frac{T_c^2}{b}(T_c-T)
```

したがって，

```math
\boxed{
M\approx\frac{T_c}{\sqrt b}\sqrt{T_c-T}
}
\tag{13}
```

となる．
すなわち，キュリー温度の直下では，自発磁化は $T_c-T$ の平方根に比例してゼロから立ち上がる．

一方， $T>T_c$ では自発磁化は $M=0$ である．
このように， $T_c$ を境にして，常磁性状態から強磁性状態への転移が起こる．

### 3．低温 $T\to0$ における自発磁化

次に，温度がゼロに近づく場合を考える．
このとき，磁化は飽和磁化

```math
\boxed{M_0=ng\mu_{\mathrm B}S}
\tag{14}
```

に近づく．
したがって，式 (4) の $x$ は非常に大きくなる．

ブリルアン関数の大きな $x$ における漸近形は，

```math
B_S(x)\approx1-\frac1S e^{-x/S}
\qquad (x\gg1)
\tag{15}
```

である．
これを式 (3) に代入すると，

```math
M\approx M_0
\left[
1-\frac1S
\exp\left(-\frac{qg\mu_{\mathrm B}M}{kT}\right)
\right]
\tag{16}
```

となる．

低温では $M\approx M_0$ であるため，指数関数の中の $M$ も $M_0$ で近似できる．
よって，

```math
\boxed{
M\approx M_0
\left[
1-\frac1S
\exp\left(-\frac{qg\mu_{\mathrm B}M_0}{kT}\right)
\right]
}
\tag{17}
```

が得られる．
この式は，低温では自発磁化が飽和磁化 $M_0$ に指数関数的に近づくことを示している．

ただし，実際の強磁性体では，低温においてスピン波の効果が重要になる．
スピン波理論によれば，低温では磁化が

```math
M=M_0\left[1-\left(\frac{T}{T_0}\right)^{3/2}\right]
\tag{18}
```

の形で減少することが知られている．
ここで $T_0$ は物質の性質によって決まる温度定数である．
この $T^{3/2}$ 則は，分子場近似では考慮されないスピンの集団的な励起を反映したものである．

以上より，分子場近似では，自発磁化を決める方程式は式 (5) で与えられ，キュリー温度直下では $M\propto\sqrt{T_c-T}$ ，低温では磁化が飽和磁化に指数関数的に近づくことが示された．
