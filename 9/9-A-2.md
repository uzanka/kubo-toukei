# 演習問題【9-A-2】

## 解答

### 1．分子場近似と Heisenberg モデル

強磁性体の Heisenberg モデルについて，分子場近似を用いて自発磁化を求める．

以下では，SI 単位系を採用する．
外部磁場の強さを $\boldsymbol H$ ，磁化を $\boldsymbol M$ ，真空の透磁率を $\mu_0$ とする．
また，磁場の強さと磁束密度の関係は，真空中の関係に対応させて，

```math
\boldsymbol B_{\mathrm{eff}}
=
\mu_0\boldsymbol H_{\mathrm{eff}}
```

と表す．

分子場近似では，有効磁場の強さを

```math
\boxed{
\boldsymbol H_{\mathrm{eff}}
=
\boldsymbol H+q\boldsymbol M
}
\tag{1}
```

とする．
ここで， $q>0$ は強磁性的相互作用に対応する分子場定数であり，SI 単位系では無次元量である．

スピン量子数を $S$ ，単位体積当たりのスピン数を $n$ ，ランデの $g$ 因子を $g$ ，ボーア磁子を $\mu_{\mathrm B}$ ，ボルツマン定数を $k$ とする．

スピンの磁気モーメントの熱平均から，磁化の大きさはブリルアン関数を用いて

```math
M=ng\mu_{\mathrm B}S B_S(x)
\tag{2}
```

と表される．

ここで，ブリルアン関数は

```math
B_S(x)
=
\frac{2S+1}{2S}
\coth\left(\frac{2S+1}{2S}x\right)
-
\frac{1}{2S}
\coth\left(\frac{x}{2S}\right)
```

であり，その引数は

```math
x=
\frac{\mu_0g\mu_{\mathrm B}S H_{\mathrm{eff}}}{kT}
\tag{3}
```

である．

なお，ここでは試料の形状による反磁場の影響は無視するか，外部磁場を内部に作用する磁場として扱う．

### 2．自発磁化の自己無撞着方程式

自発磁化は，熱力学極限で対称性が自発的に破れた状態において定義される．

厳密には，外部磁場をゼロにした有限系では対称性によって熱平均磁化がゼロとなるため，先に熱力学極限を取り，その後に外部磁場をゼロにする．

すなわち，

```math
M_s(T)
=
\lim_{H\to0^+}
\lim_{\substack{N,V\to\infty\\N/V=n}}
M(T,H)
```

と定義する．

この極限において，磁化の向きを外部磁場の方向に選び， $\boldsymbol H=0$ とすると，

```math
H_{\mathrm{eff}}=qM
```

である．

これを式 (3) に代入すると，

```math
x=
\frac{\mu_0qg\mu_{\mathrm B}SM}{kT}
```

となる．

したがって，自発磁化を決める自己無撞着方程式は，

```math
\boxed{
M=
ng\mu_{\mathrm B}S
B_S\left(
\frac{\mu_0qg\mu_{\mathrm B}SM}{kT}
\right)
}
\tag{4}
```

である．

これが分子場近似による自発磁化の基本方程式である．

### 3．Heisenberg 交換相互作用と分子場定数の関係

分子場定数 $q$ と交換相互作用の関係を明確にするため，最近接 Heisenberg 模型を考える．

各スピン演算子を無次元化された演算子とし，ハミルトニアンを

```math
\mathcal H
=
-J\sum_{\langle i,j\rangle}
\boldsymbol S_i\cdot\boldsymbol S_j
-
\mu_0g\mu_{\mathrm B}
\boldsymbol H\cdot
\sum_i\boldsymbol S_i
\tag{5}
```

と定義する．

ここで，

- $J>0$ は強磁性的な交換相互作用定数である．
- $\langle i,j\rangle$ は最近接ペアを一度ずつ数えることを表す．
- $z$ は最近接配位数である．

分子場近似では，周囲のスピンをその熱平均で置き換え，

```math
\boldsymbol S_j
\longrightarrow
\langle\boldsymbol S\rangle
```

とする．

したがって，あるスピンが受ける有効ハミルトニアンは，

```math
\mathcal H_i^{\mathrm{MF}}
=
-Jz\boldsymbol S_i\cdot
\langle\boldsymbol S\rangle
-
\mu_0g\mu_{\mathrm B}
\boldsymbol H\cdot\boldsymbol S_i
```

となる．

これを有効磁場で表すと，

```math
\mathcal H_i^{\mathrm{MF}}
=
-\mu_0g\mu_{\mathrm B}
\boldsymbol H_{\mathrm{eff}}\cdot\boldsymbol S_i
```

であるから，

```math
\mu_0g\mu_{\mathrm B}
\boldsymbol H_{\mathrm{eff}}
=
\mu_0g\mu_{\mathrm B}\boldsymbol H
+
Jz\langle\boldsymbol S\rangle
```

となる．

一方，磁化とスピンの熱平均の関係は，

```math
\boldsymbol M
=
ng\mu_{\mathrm B}
\langle\boldsymbol S\rangle
```

である．

したがって，

```math
\boldsymbol H_{\mathrm{eff}}
=
\boldsymbol H
+
\frac{zJ}{\mu_0ng^2\mu_{\mathrm B}^2}
\boldsymbol M
```

を得る．

よって，このハミルトニアンの規約では，

```math
\boxed{
q=
\frac{zJ}{\mu_0ng^2\mu_{\mathrm B}^2}
}
\tag{6}
```

となる．

なお，交換相互作用を $-2J\sum_{\langle i,j\rangle}\boldsymbol S_i\cdot\boldsymbol S_j$ と定義する規約では，係数に 2 が付く．
したがって， $q$ の具体的な値は Heisenberg ハミルトニアンの定義に依存する．

### 4．キュリー温度 $T_c$ の近傍

キュリー温度付近では，自発磁化 $M$ が小さくなるため，式 (4) の引数 $x$ も小さくなる．

ブリルアン関数を小さい $x$ について展開すると，

```math
\begin{aligned}
B_S(x)
={}&
\frac{S+1}{3S}x\\
&-
\frac{(S+1)\{(S+1)^2+S^2\}}
{90S^3}x^3
+O(x^5)
\end{aligned}
\tag{7}
```

となる．

これを式 (4) に代入すると，

```math
\begin{aligned}
M={}&
\frac{
\mu_0ng^2\mu_{\mathrm B}^2qS(S+1)
}{
3kT
}M\\
&-
\frac{
\mu_0^3ng^4\mu_{\mathrm B}^4q^3S(S+1)
\{(S+1)^2+S^2\}
}{
90k^3T^3
}M^3
+O(M^5)
\end{aligned}
\tag{8}
```

を得る．

ここで，

```math
a=
\frac{
\mu_0ng^2\mu_{\mathrm B}^2qS(S+1)
}{
3k
}
\tag{9}
```

および，

```math
b=
\frac{
\mu_0^3ng^4\mu_{\mathrm B}^4q^3S(S+1)
\{(S+1)^2+S^2\}
}{
90k^3
}
\tag{10}
```

と定義すると，

```math
M=
\frac aT M
-
\frac b{T^3}M^3
+O(M^5)
\tag{11}
```

となる．

ここで， $M=0$ 以外の解がゼロから連続的に発生する温度を，分子場近似によるキュリー温度 $T_c^{\mathrm{MF}}$ とする．

一次の項の係数が 1 となる条件から，

```math
\frac a{T_c^{\mathrm{MF}}}=1
```

である．

したがって，

```math
\boxed{
T_c^{\mathrm{MF}}
=
\frac{
\mu_0ng^2\mu_{\mathrm B}^2qS(S+1)
}{
3k
}
}
\tag{12}
```

を得る．

式 (6) を代入すると，

```math
\boxed{
T_c^{\mathrm{MF}}
=
\frac{zJS(S+1)}{3k}
}
\tag{13}
```

となる．

これは，今回定義した Heisenberg ハミルトニアンに対する分子場近似のキュリー温度である．

#### 4.1 キュリー温度直下での自発磁化

以下では， $T_c^{\mathrm{MF}}$ を簡単に $T_c$ と書く．

$T<T_c$ の非零解について，式 (11) を $M$ で割ると，

```math
1=
\frac{T_c}{T}
-
\frac b{T^3}M^2
+O(M^4)
```

となる．

したがって，

```math
M^2
=
\frac{T^3}{b}
\left(
\frac{T_c}{T}-1
\right)
+O((T_c-T)^2)
```

である．

これを整理すると，

```math
M^2
=
\frac{T^2}{b}(T_c-T)
+O((T_c-T)^2)
```

となる．

キュリー温度直下では $T\simeq T_c$ であるため，

```math
T^2\simeq T_c^2
```

として，

```math
\boxed{
M\simeq
\frac{T_c}{\sqrt b}
\sqrt{T_c-T}
}
\tag{14}
```

を得る．

したがって，分子場近似では，自発磁化はキュリー温度直下で，

```math
\boxed{
M\propto(T_c-T)^{1/2}
}
```

と振る舞う．

この臨界指数は，

```math
\boxed{\beta_{\mathrm{MF}}=\frac12}
```

である．

ここで得られた指数は平均場理論の結果であり，実際の強磁性体では，臨界揺らぎによって異なる臨界指数が現れる場合がある．

#### 4.2 $T>T_c$ に非零の自発磁化が存在しないことの確認

式 (4) において， $M>0$ の解が存在すると仮定する．

このとき，

```math
x=
\frac{\mu_0qg\mu_{\mathrm B}SM}{kT}>0
```

である．

自己無撞着方程式を $M$ で割ると，

```math
1=
\frac{ng\mu_{\mathrm B}S}{M}B_S(x)
```

となる．

$M$ を $x$ で表せば，

```math
1=
\frac{
\mu_0ng^2\mu_{\mathrm B}^2qS^2
}{
kT
}
\frac{B_S(x)}{x}
```

である．

ブリルアン関数については， $x>0$ で，

```math
\frac{B_S(x)}{x}
<
\frac{S+1}{3S}
```

が成立する．

これは， $B_S(0)=0$ ， $B_S'(0)=(S+1)/(3S)$ であり， $B_S(x)/x$ が正の $x$ に対して単調減少することによる．

したがって，

```math
1<
\frac{
\mu_0ng^2\mu_{\mathrm B}^2qS(S+1)
}{
3kT
}
=
\frac{T_c}{T}
```

でなければならない．

よって，非零解が存在するための必要条件は，

```math
T<T_c
```

である．

したがって，

```math
\boxed{
T\geq T_c
\quad\Longrightarrow\quad
M_s=0
}
\tag{15}
```

となる．

一方， $T<T_c$ では， $B_S(x)/x$ が正の $x$ に対して単調減少し， $x\to\infty$ でゼロに近づくため，正の非零解が一つ存在する．

負の解も対称性によって存在するが，外部磁場を $H\to0^+$ とすることで正の磁化方向が選択される．

### 5．低温 $T\to0$ における自発磁化

#### 5.1 飽和磁化

すべてのスピンが同じ方向に揃ったとき，磁化は飽和する．

したがって，飽和磁化は，

```math
\boxed{
M_0=ng\mu_{\mathrm B}S
}
\tag{16}
```

である．

温度がゼロに近づくと，熱励起が抑制され，分子場近似では，

```math
M\longrightarrow M_0
```

となる．

このとき，ブリルアン関数の引数は，

```math
x=
\frac{\mu_0qg\mu_{\mathrm B}SM}{kT}
```

であるため，非常に大きくなる．

#### 5.2 ブリルアン関数の大きな引数での漸近形

$x\to\infty$ では，

```math
\boxed{
B_S(x)
=
1-\frac1S e^{-x/S}
+O(e^{-2x/S})
}
\tag{17}
```

となる．

この式を式 (2) に代入すると，

```math
M\simeq
M_0
\left[
1-\frac1S
\exp\left(
-\frac{x}{S}
\right)
\right]
```

を得る．

ここで，

```math
\frac{x}{S}
=
\frac{\mu_0qg\mu_{\mathrm B}M}{kT}
```

であるため，

```math
\boxed{
M\simeq
M_0
\left[
1-\frac1S
\exp\left(
-\frac{\mu_0qg\mu_{\mathrm B}M}{kT}
\right)
\right]
}
\tag{18}
```

となる．

#### 5.3 低温における主要漸近形

低温では $M\simeq M_0$ であるため，指数関数の中の $M$ を $M_0$ で近似できる．

そこで，

```math
A=
\frac{\mu_0qg\mu_{\mathrm B}M_0}{k}
```

と定義する．

このとき，

```math
\frac{M}{M_0}
\simeq
1-\frac1S
\exp\left(
-\frac{A}{T}
\right)
```

となる．

より厳密には，

```math
\boxed{
M=
M_0
\left[
1-\frac1S e^{-A/T}
+
O\left(
\left(1+\frac AT\right)e^{-2A/T}
\right)
\right]
}
\tag{19}
```

である．

したがって，分子場近似では，低温における磁化の飽和は指数関数的に進行する．

すなわち，

```math
\boxed{
M_0-M
\propto e^{-A/T}
}
```

である．

### 6．スピン波による低温磁化の補正

ここまでの結果は分子場近似に基づくものである．

しかし，実際の三次元強磁性 Heisenberg 模型では，低温においてスピンの集団的な励起であるスピン波が重要になる．

スピン波の長波長領域における分散関係が，

```math
\varepsilon_{\boldsymbol k}
\simeq Dk^2
```

で表される場合を考える．

ここで， $D>0$ はスピン波剛性を表す定数である．

一つのスピン波励起は，全磁化を $g\mu_{\mathrm B}$ だけ減少させるため，低温における磁化の減少は，

```math
\Delta M
=
g\mu_{\mathrm B}
\int
\frac{d^3k}{(2\pi)^3}
\frac{1}{
\exp(Dk^2/kT)-1
}
```

で表される．

この積分を評価すると，

```math
\Delta M
=
\frac{
g\mu_{\mathrm B}\zeta(3/2)
}{
8\pi^{3/2}
}
\left(
\frac{kT}{D}
\right)^{3/2}
```

となる．

したがって，低温での磁化は，

```math
\boxed{
M(T)
=
M_0
-
\frac{
g\mu_{\mathrm B}\zeta(3/2)
}{
8\pi^{3/2}
}
\left(
\frac{kT}{D}
\right)^{3/2}
+o(T^{3/2})
}
\tag{20}
```

と表される．

ここで， $\zeta(s)$ はリーマンのゼータ関数である．

この結果は，

```math
\boxed{
M(T)
\simeq
M_0
\left[
1-\left(\frac{T}{T_0}\right)^{3/2}
\right]
}
\tag{21}
```

と書くこともできる．

ここで，

```math
T_0=
\frac{D}{k}
\left[
\frac{
8\pi^{3/2}M_0
}{
g\mu_{\mathrm B}\zeta(3/2)
}
\right]^{2/3}
```

である．

これが三次元の等方的な強磁性体に対する Bloch の $T^{3/2}$ 則である．

ただし，この法則には以下の条件が必要である．

- 三次元の強磁性体であること．
- 長波長スピン波の分散関係が二次形式であること．
- スピン波にエネルギーギャップが存在しないこと．
- 温度が十分低く，長波長スピン波が主要な熱励起であること．
- スピン波間の相互作用などの高次補正が主要項に影響しないこと．

異方性や外部磁場によってスピン波にエネルギーギャップが存在する場合には，低温の磁化の温度依存性は変化する．

また，二次元や一次元の等方的 Heisenberg 模型では，有限温度の長距離磁気秩序について Mermin-Wagner の定理が関係するため，三次元の場合の Bloch 則をそのまま適用することはできない．

重要なのは，分子場近似では，

```math
M_0-M\propto e^{-A/T}
```

である一方，スピン波理論では，

```math
M_0-M\propto T^{3/2}
```

となることである．

これは，分子場近似では各スピンが平均的な有効磁場を受けると考えるのに対し，スピン波理論では多数のスピンの集団的な励起を考慮するためである．

したがって，両者は異なる近似に基づく低温の振る舞いを示している．

### 7．結論

分子場近似による自発磁化の自己無撞着方程式は，

```math
\boxed{
M=
ng\mu_{\mathrm B}S
B_S\left(
\frac{\mu_0qg\mu_{\mathrm B}SM}{kT}
\right)
}
```

である．

分子場近似によるキュリー温度は，

```math
\boxed{
T_c^{\mathrm{MF}}
=
\frac{
\mu_0ng^2\mu_{\mathrm B}^2qS(S+1)
}{
3k
}
}
```

であり，最近接 Heisenberg 模型の交換相互作用を

```math
-J\sum_{\langle i,j\rangle}
\boldsymbol S_i\cdot\boldsymbol S_j
```

と定義した場合には，

```math
\boxed{
T_c^{\mathrm{MF}}
=
\frac{zJS(S+1)}{3k}
}
```

となる．

キュリー温度直下では，

```math
\boxed{
M\propto(T_c-T)^{1/2}
}
```

であり，分子場近似の臨界指数は $1/2$ である．

また，低温では分子場近似によって，

```math
\boxed{
M_0-M\propto e^{-A/T}
}
```

となる．

一方，三次元の等方的 Heisenberg 強磁性体では，スピン波の効果によって，

```math
\boxed{
M_0-M\propto T^{3/2}
}
```

という Bloch の法則が得られる．

以上より，分子場近似ではキュリー温度付近の自発磁化の立ち上がりと低温での指数関数的な飽和が導かれる．
また，実際の強磁性体の低温磁化には，分子場近似では記述されないスピン波の寄与が現れる．
