# 例題【9-R-2】

## 解答

### 1．モデルと規則度の定義

2元合金 AB の全原子数を $N$ とし，二つの部分格子 $a,b$ のそれぞれに $N/2$ 個の格子点があるとする．
全体として A 原子と B 原子は同数であり，隣接する格子点はすべて異なる部分格子に属するものとする．
また，各格子点には $z$ 個の隣接格子点がある．

規則度 $X$ は，部分格子 $a$ に A 原子が多く，部分格子 $b$ に B 原子が多いほど大きくなるように定義する．
各部分格子上の原子数は，

```math
\begin{aligned}
N_{A,a}&=\frac{N}{4}(1+X),&
N_{B,a}&=\frac{N}{4}(1-X),\\
N_{A,b}&=\frac{N}{4}(1-X),&
N_{B,b}&=\frac{N}{4}(1+X)
\end{aligned}
\tag{1}
```

である．
ここで， $N_{A,a}$ は部分格子 $a$ 上の A 原子数を表す．

$X=0$ は両部分格子に A，B 原子が等しい割合で分布する無秩序状態， $X=1$ は $a$ がすべて A， $b$ がすべて B となる完全規則状態である．

### 2．相互作用エネルギーを求める

隣接する原子対の相互作用エネルギーを，AA 対，AB 対，BB 対についてそれぞれ $u_{\mathrm{AA}},u_{\mathrm{AB}},u_{\mathrm{BB}}$ とする．
Bragg–Williams 近似では，各部分格子内の原子の分布を平均的な組成で表し，隣接原子対の数を平均値で近似する．

#### 2.1．隣接原子対の数

部分格子 $a$ 上の原子は，それぞれ $z$ 個の隣接格子点を持つ．
隣接格子点はすべて部分格子 $b$ にあるため，部分格子 $b$ 上で原子が占める割合を掛ければ，隣接原子対の平均数が求まる．

AA 対の数は，

```math
\begin{aligned}
N_{\mathrm{AA}}
&\simeq N_{A,a}\,z\frac{N_{A,b}}{N/2}\\
&=\frac{N}{4}(1+X)\,z\frac{1-X}{2}\\
&=\frac{zN}{8}(1-X^2)
\end{aligned}
\tag{2}
```

である．
同様に，部分格子 $a$ 上の A 原子と部分格子 $b$ 上の B 原子の対は，

```math
\begin{aligned}
N_{\mathrm{AB}}
&\simeq N_{A,a}\,z\frac{N_{B,b}}{N/2}\\
&=\frac{zN}{8}(1+X)^2
\end{aligned}
\tag{3}
```

となる．
部分格子 $a$ 上の B 原子と部分格子 $b$ 上の A 原子の対は，

```math
\begin{aligned}
N_{\mathrm{BA}}
&\simeq N_{B,a}\,z\frac{N_{A,b}}{N/2}\\
&=\frac{zN}{8}(1-X)^2
\end{aligned}
\tag{4}
```

である．
最後に，BB 対の数は，

```math
\begin{aligned}
N_{\mathrm{BB}}
&\simeq N_{B,a}\,z\frac{N_{B,b}}{N/2}\\
&=\frac{zN}{8}(1-X^2)
\end{aligned}
\tag{5}
```

となる．
なお，AB 対と BA 対は，部分格子 $a,b$ のどちら側に A 原子があるかを区別した数であるため，両方を足して AB 型の相互作用の総数とする．

この数え上げが整合していることは，すべての隣接対の数を加えると，

```math
N_{\mathrm{AA}}+N_{\mathrm{AB}}
+N_{\mathrm{BA}}+N_{\mathrm{BB}}
=\frac{zN}{2}
\tag{6}
```

となることからも確認できる．
右辺は，格子点数 $N$ に配位数 $z$ を掛け，それぞれの結合を両端から二重に数えることを避けるために 2 で割った値である．

#### 2.2．エネルギーと規則度の関係

全相互作用エネルギーは，それぞれの原子対の数に対応する相互作用エネルギーを掛けて足し合わせることにより，

```math
E(X)=u_{\mathrm{AA}}N_{\mathrm{AA}}
+u_{\mathrm{AB}}(N_{\mathrm{AB}}+N_{\mathrm{BA}})
+u_{\mathrm{BB}}N_{\mathrm{BB}}
\tag{7}
```

と表される．
式 (2)～(5) を代入すると，

```math
\begin{aligned}
E(X)=\frac{zN}{8}\big[
& (u_{\mathrm{AA}}+u_{\mathrm{BB}})(1-X^2)\\
&+u_{\mathrm{AB}}\{(1+X)^2+(1-X)^2\}
\big]
\end{aligned}
```

となる．
ここで，

```math
(1+X)^2+(1-X)^2=2(1+X^2)
```

を用いて整理すると，

```math
\begin{aligned}
E(X)
={}&\frac{zN}{8}
(u_{\mathrm{AA}}+2u_{\mathrm{AB}}+u_{\mathrm{BB}})\\
&-\frac{zN}{4}X^2
\left(
\frac{u_{\mathrm{AA}}+u_{\mathrm{BB}}}{2}
-u_{\mathrm{AB}}
\right)
\end{aligned}
```

を得る．
ここで，

```math
E_0=\frac{zN}{8}
(u_{\mathrm{AA}}+2u_{\mathrm{AB}}+u_{\mathrm{BB}})
```

および，

```math
v=\frac{u_{\mathrm{AA}}+u_{\mathrm{BB}}}{2}
-u_{\mathrm{AB}}
\tag{8}
```

と定義すれば，

```math
\boxed{
E(X)=E_0-\frac{zN}{4}vX^2
}
\tag{9}
```

となる．
以後，規則化によってエネルギーが低下する場合，すなわち $v>0$ を考える．
このとき $X^2$ が大きいほど相互作用エネルギーが低くなり，規則状態がエネルギー的に有利となる．

### 3．配置エントロピーを求める

同じ原子数を持つ原子配置の数が多いほど，配置エントロピーは大きくなる．
Boltzmann の関係式

```math
S=k\log W
\tag{10}
```

を用いてエントロピーを求める．
ここで $W$ は，規則度 $X$ を満たす原子配置の数である．

部分格子 $a$ では $N/2$ 個の格子点に A 原子 $N(1+X)/4$ 個と B 原子 $N(1-X)/4$ 個を配置する．
その配置数は組合せの数

```math
\frac{(N/2)!}
{\{N(1+X)/4\}!\{N(1-X)/4\}!}
```

である．
部分格子 $b$ でも対応する原子数は入れ替わるだけで，配置数は同じである．
したがって，全体の配置数は，

```math
\boxed{
W(X)=
\left[
\frac{(N/2)!}
{\{N(1+X)/4\}!\{N(1-X)/4\}!}
\right]^2
}
\tag{11}
```

となる．

原子数が十分大きい場合，Stirling の公式

```math
\log n!\simeq n\log n-n
```

を用いることができる．
これを式 (11) に適用して整理すると，

```math
\boxed{
S(X)\simeq
-Nk\left[
\frac{1+X}{2}\log\frac{1+X}{2}
+\frac{1-X}{2}\log\frac{1-X}{2}
\right]
}
\tag{12}
```

を得る．

この式は， $X=0$ でエントロピーが最大値 $Nk\log2$ となり， $X=\pm1$ では 0 となることを示す．
つまり，無秩序状態では配置の自由度が最大となり，完全規則状態では原子の配置がほぼ一意に決まる．

### 4．自由エネルギー $F(X,T)$ の導出

温度 $T$ における Helmholtz の自由エネルギーは，

```math
F=E-TS
\tag{13}
```

で与えられる．
式 (9)，(12) を代入すると，

```math
\boxed{
\begin{aligned}
F(X,T)={}&E_0-\frac{zN}{4}vX^2\\
&+NkT\left[
\frac{1+X}{2}\log\frac{1+X}{2}
+\frac{1-X}{2}\log\frac{1-X}{2}
\right]
\end{aligned}
}
\tag{14}
```

を得る．
これが Bragg–Williams 近似における規則度 $X$ の関数としての自由エネルギーである．
平衡状態では， $F(X,T)$ を最小にする $X$ が実現する．

### 5．臨界温度 $T_c$ 付近の自由エネルギー

$X=0$ の近傍では，対数項を $X$ について展開できる．
実際，

```math
\begin{aligned}
&\frac{1+X}{2}\log\frac{1+X}{2}
+\frac{1-X}{2}\log\frac{1-X}{2}\\
&\qquad=-\log2+\frac{X^2}{2}
+\frac{X^4}{12}+O(X^6)
\end{aligned}
```

である．
これを式 (14) に代入すると，

```math
\begin{aligned}
F(X,T)\simeq{}&
E_0-NkT\log2\\
&+\frac{N}{2}
\left(kT-\frac{zv}{2}\right)X^2
+\frac{NkT}{12}X^4+O(X^6)
\end{aligned}
\tag{15}
```

となる．

ここで， $X^2$ の係数が 0 になる温度を臨界温度 $T_c$ と定めると，

```math
kT_c-\frac{zv}{2}=0
```

であるから，

```math
\boxed{
T_c=\frac{zv}{2k}
}
\tag{16}
```

を得る．
ただし，これは $v>0$ の場合である．

式 (15) から自由エネルギーの形を調べると，次のようになる．

- $T>T_c$ のとき， $X^2$ の係数は正であり， $X=0$ が自由エネルギーの極小点である．したがって，無秩序状態が安定である．
- $T=T_c$ のとき， $X^2$ の項が消え，先頭の $X$ に依存する項は正の $X^4$ の項となる．自由エネルギーは $X=0$ において平坦になるが，依然として極小である．
- $T<T_c$ のとき， $X^2$ の係数は負となり， $X=0$ は極大点となる．一方， $X\ne0$ の位置に自由エネルギーの極小点が2つ現れ，規則状態が安定となる．

特に $T_c$ のすぐ下では，式 (15) を微分して非零の極小点を求めることができる．
一次近似と四次の項までを用いると，

```math
X^2\simeq\frac{3(T_c-T)}{T}
```

となるため，臨界温度に近づくときには，

```math
\boxed{
|X|\simeq
\sqrt{\frac{3(T_c-T)}{T_c}}
\qquad(T\to T_c^-)
}
\tag{17}
```

である．
したがって，Bragg–Williams 近似では，規則度は臨界温度で連続的に 0 となり，その近傍では $(T_c-T)^{1/2}$ に比例して増加する．

### 6．規則度 $X$ を定める方程式

平衡状態では，自由エネルギーが $X$ に関して極小となるため，

```math
\frac{\partial F}{\partial X}=0
\tag{18}
```

が成り立つ．
式 (14) を微分すると，

```math
-\frac{zNv}{2}X
+\frac{NkT}{2}
\log\frac{1+X}{1-X}=0
```

となる．
これを整理すると，

```math
\boxed{
\frac{zv}{2kT}X
=\frac12\log\frac{1+X}{1-X}
}
\tag{19}
```

を得る．
これが問題文で指定された式 (9.17) の形の方程式である．

$X=0$ はすべての温度で解であり， $T>T_c$ では平衡状態の解となる．
一方， $T<T_c$ では $X=0$ は極大点となるため， $X\ne0$ の解のうち自由エネルギーを最小にするものを選ぶ．
二つの部分格子の役割を入れ替えると $X$ の符号が反転するため，規則状態の解は $+X$ と $-X$ の対で現れる．

以上より，Bragg–Williams 近似では，規則化によるエネルギー低下と配置エントロピーの競合から自由エネルギーの二重極小構造が生じ，臨界温度は

```math
\boxed{T_c=\frac{zv}{2k}}
```

で与えられる．
また，平衡規則度は式 (19) によって決まるのである．
