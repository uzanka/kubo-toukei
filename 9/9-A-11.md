# 演習問題【9-A-11】

## 解答

### 1．粒子数密度と1体分布関数の関係

体積 $V$ ，粒子数 $N$ の純粋物質の流体を考える．
各粒子の位置を $\mathbf r_1,\ldots,\mathbf r_N$ とし，系全体の $N$ 体分布関数を

```math
F_N(\mathbf r_1,\ldots,\mathbf r_N)
```

とする．
これは，粒子の位置がそれぞれの微小体積要素にある確率密度を表すものであり，規格化条件

```math
\int\cdots\int
F_N(\mathbf r_1,\ldots,\mathbf r_N)
\,d\mathbf r_1\cdots d\mathbf r_N=1
```

を満たす．

位置 $\mathbf r$ における局所的な粒子数密度を，ディラックのデルタ関数 $\delta$ を用いて

```math
\widehat n(\mathbf r)
=\sum_{i=1}^{N}\delta(\mathbf r-\mathbf r_i)
\tag{1}
```

と表す．
この熱平衡平均が，位置 $\mathbf r$ における平均粒子数密度 $n(\mathbf r)$ である．したがって，

```math
\begin{aligned}
n(\mathbf r)
&=\langle\widehat n(\mathbf r)\rangle\\
&=\int\cdots\int
\sum_{i=1}^{N}\delta(\mathbf r-\mathbf r_i)
F_N(\mathbf r_1,\ldots,\mathbf r_N)
\,d\mathbf r_1\cdots d\mathbf r_N
\end{aligned}
\tag{2}
```

となる．

純粋物質ではすべての粒子は同等であり， $F_N$ は粒子の座標の入れ替えに対して対称である．
そのため，式 (2) の和に含まれる各項の積分値はすべて等しい．
よって，

```math
\begin{aligned}
n(\mathbf r)
&=N\int\cdots\int
\delta(\mathbf r-\mathbf r_1)
F_N(\mathbf r_1,\ldots,\mathbf r_N)
\,d\mathbf r_1\cdots d\mathbf r_N\\
&=N\int
\delta(\mathbf r-\mathbf r_1)
\left[
\int\cdots\int
F_N(\mathbf r_1,\ldots,\mathbf r_N)
\,d\mathbf r_2\cdots d\mathbf r_N
\right]d\mathbf r_1
\end{aligned}
\tag{3}
```

となる．

ここで，1体分布関数 $F_1(\mathbf r_1)$ を

```math
F_1(\mathbf r_1)
=N\int\cdots\int
F_N(\mathbf r_1,\ldots,\mathbf r_N)
\,d\mathbf r_2\cdots d\mathbf r_N
\tag{4}
```

と定義する．
式 (3) は，

```math
\begin{aligned}
n(\mathbf r)
&=\int\delta(\mathbf r-\mathbf r_1)
F_1(\mathbf r_1)\,d\mathbf r_1\\
&=F_1(\mathbf r)
\end{aligned}
\tag{5}
```

となる．

一様な流体では，平均粒子数密度は位置に依存せず一定であり，

```math
n=\frac NV
```

である．
したがって，

```math
\boxed{F_1(\mathbf r)=n}
\tag{6}
```

が示された．

### 2．二体分布関数を用いた平均相互作用エネルギー

粒子間の相互作用エネルギーの総和は，

```math
U=\sum_{i<j}u(\mathbf r_i-\mathbf r_j)
\tag{7}
```

である．
ここで， $u(\mathbf r_i-\mathbf r_j)$ は粒子 $i$ と粒子 $j$ の間の相互作用エネルギーであり，二つの粒子の相対位置だけに依存するとする．

この平均値は， $N$ 体分布関数を用いて

```math
\begin{aligned}
\langle U\rangle
={}&\int\cdots\int
\sum_{i<j}u(\mathbf r_i-\mathbf r_j)\\
&\qquad\times
F_N(\mathbf r_1,\ldots,\mathbf r_N)
\,d\mathbf r_1\cdots d\mathbf r_N
\end{aligned}
\tag{8}
```

と表される．

式 (8) の和には，異なる粒子の組合せが

```math
\binom N2=\frac{N(N-1)}2
```

個含まれる．
粒子の同等性と $F_N$ の対称性により，各粒子対に対応する積分値はすべて等しい．
したがって，

```math
\begin{aligned}
\langle U\rangle
={}&\frac{N(N-1)}2
\int\cdots\int
u(\mathbf r_1-\mathbf r_2)\\
&\qquad\times
F_N(\mathbf r_1,\ldots,\mathbf r_N)
\,d\mathbf r_1\cdots d\mathbf r_N
\end{aligned}
\tag{9}
```

となる．

ここで，二体分布関数 $F_2$ を

```math
\begin{aligned}
F_2(\mathbf r_1,\mathbf r_2)
={}&N(N-1)\int\cdots\int
F_N(\mathbf r_1,\ldots,\mathbf r_N)\\
&\qquad\qquad\times d\mathbf r_3\cdots d\mathbf r_N
\end{aligned}
\tag{10}
```

と定義する．
これは，粒子1と粒子2の位置に関する分布を，残りの粒子について積分して得られる縮約分布関数である．
式 (9) に式 (10) を用いれば，

```math
\boxed{
\langle U\rangle
=\frac12\iint
u(\mathbf r_1-\mathbf r_2)
F_2(\mathbf r_1,\mathbf r_2)
\,d\mathbf r_1\,d\mathbf r_2
}
\tag{11}
```

を得る．
ここで係数 $1/2$ は，各粒子対を二重に数えないための係数である．

### 3．相関関数 $g(\mathbf r)$ を用いた表式

問題文では，二体分布関数を

```math
\boxed{
F_2(\mathbf r_1,\mathbf r_2)
=n^2g(\mathbf r_1-\mathbf r_2)
}
\tag{12}
```

と定義している．
ここで， $g(\mathbf r_1-\mathbf r_2)$ は二つの粒子の位置の相関を表す関数である．
粒子間の相関が十分小さくなるほど離れた位置では，通常 $g(\mathbf r)\to1$ となる．

式 (12) を式 (11) に代入すると，

```math
\begin{aligned}
\langle U\rangle
&=\frac{n^2}{2}\iint
u(\mathbf r_1-\mathbf r_2)
g(\mathbf r_1-\mathbf r_2)
\,d\mathbf r_1\,d\mathbf r_2\\
&=\frac{n^2}{2}\int d\mathbf r_1
\int u(\mathbf r_1-\mathbf r_2)
g(\mathbf r_1-\mathbf r_2)\,d\mathbf r_2
\end{aligned}
\tag{13}
```

となる．

ここで，流体が一様であり， $u$ と $g$ が相対位置のみに依存することを用いる．
内側の積分に対して，

```math
\mathbf r=\mathbf r_2-\mathbf r_1
```

と変数変換すると，体積要素は $d\mathbf r_2=d\mathbf r$ である．
また，粒子間の相互作用は粒子の入れ替えに対して対称であるため， $u(-\mathbf r)g(-\mathbf r)=u(\mathbf r)g(\mathbf r)$ としてよい．
したがって，

```math
\int u(\mathbf r_1-\mathbf r_2)
g(\mathbf r_1-\mathbf r_2)\,d\mathbf r_2
=\int u(\mathbf r)g(\mathbf r)\,d\mathbf r
\tag{14}
```

となる．
右辺は $\mathbf r_1$ に依存しないため，式 (13) の外側の積分は単に体積 $V$ を与える．
よって，

```math
\langle U\rangle
=\frac{n^2V}{2}\int u(\mathbf r)g(\mathbf r)\,d\mathbf r
\tag{15}
```

を得る．
最後に，粒子数密度  $n=N/V$ を代入すると，

```math
\frac{n^2V}{2}
=\frac{1}{2}\left(\frac NV\right)^2V
=\frac{N^2}{2V}
```

である．
したがって，

```math
\boxed{
\langle U\rangle
=\frac{N^2}{2V}
\int u(\mathbf r)g(\mathbf r)\,d\mathbf r
}
```

が得られ，題意が示された．

ここで得られた式は，一様な流体における二体相関を用いて，相互作用エネルギーの平均を表したものである．
有限粒子数での厳密な規格化には $N(N-1)$ が現れるが，巨視的な流体では $N$ が十分大きいため，問題文の $F_2=n^2g$ という表記と最終式を用いることができる．
