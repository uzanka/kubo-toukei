# 演習問題【9-A-4】

## 解答

### 1．Bragg–Williams 近似と秩序変数

AB 型2元合金では，A 原子と B 原子が規則的に配列する秩序状態と，両者がランダムに混ざる無秩序状態が存在する．
Bragg–Williams 近似では，原子間の相関を細かく扱う代わりに，各サイトにおける原子の占有確率を用いて，系の内部エネルギーとエントロピーを計算する．

全サイト数を $N$ とし，A 原子と B 原子が等量存在する合金を考える．
結晶を二つの部分格子 $\mathrm a$ ， $\mathrm b$ に分け，部分格子 $\mathrm a$ のサイトが A 原子で占有される確率を $(1+X)/2$ ，部分格子 $\mathrm b$ のサイトが A 原子で占有される確率を $(1-X)/2$ と定義する．
ここで， $X$ は規則的な配列の程度を表す秩序変数であり，

```math
-1\leq X\leq1
```

である．
$X=0$ は無秩序状態， $X=1$ または $X=-1$ は完全秩序状態を表す．
以下では $X\geq0$ の場合を考える．

### 2．内部エネルギーとエントロピー

隣接サイト間の相互作用を Bragg–Williams 近似で扱うと，秩序に依存する内部エネルギーは

```math
\boxed{
E=-\frac{zNv}{4}X^2
}
\tag{1}
```

と表される．
ここで， $z$ は1サイト当たりの最近接サイト数， $v>0$ は規則化によるエネルギー低下を表す相互作用定数である．
式 (1) では，秩序に依存しない定数項は省略している．

次に，配置エントロピーを求める．
Boltzmann の原理によれば，エントロピー $S$ は微視的状態数 $W$ を用いて $S=k\log W$ と表される．
Bragg–Williams 近似では，各サイトの占有確率から配置数を評価することにより，

```math
\boxed{
S=-Nk\left[
\frac{1+X}{2}\log\frac{1+X}{2}
+\frac{1-X}{2}\log\frac{1-X}{2}
\right]
}
\tag{2}
```

を得る．
ここで， $k$ はボルツマン定数である．

$X=0$ では原子がランダムに配置され， $S=Nk\log2$ となる．
一方， $X=1$ では原子が完全に規則配列し，配置の自由度がなくなるため $S=0$ となる．

### 3．平衡条件と転移温度

ヘルムホルツ自由エネルギー $F$ は

```math
F=E-TS
```

で与えられる．
式 (1)，(2) を代入すると，

```math
\begin{aligned}
F(X)={}&-\frac{zNv}{4}X^2\\
&+NkT\left[
\frac{1+X}{2}\log\frac{1+X}{2}
+\frac{1-X}{2}\log\frac{1-X}{2}
\right]
\end{aligned}
\tag{3}
```

となる．
平衡状態では，自由エネルギーが最小になるため，

```math
\frac{dF}{dX}=0
\tag{4}
```

が成り立つ．
式 (3) を微分すると，

```math
-\frac{zNv}{2}X
+\frac{NkT}{2}\log\frac{1+X}{1-X}=0
```

である．
これを整理すれば，

```math
\boxed{
\frac{zv}{2kT}X
=\frac12\log\frac{1+X}{1-X}
}
\tag{5}
```

となる．
ここで，

```math
\boxed{
T_c=\frac{zv}{2k}
}
\tag{6}
```

とおくと，式 (5) は

```math
\frac{T_c}{T}X
=\frac12\log\frac{1+X}{1-X}
```

と書ける．
両辺に双曲線正接を適用すると，

```math
\boxed{
X=\tanh\left(\frac{T_c}{T}X\right)
}
\tag{7}
```

を得る．
これが秩序変数 $X$ を決める自己無撞着方程式である．

$T>T_c$ では平衡解は $X=0$ であり，合金は無秩序状態にある．
$T<T_c$ では $X=0$ 以外の解が現れ，規則配列が生じる．
したがって， $T_c$ は秩序・無秩序転移の臨界温度である．

### 4．異常比熱の導出

比熱 $C$ は，温度を変化させたときの内部エネルギーの変化率である．
このモデルでは，内部エネルギーの温度依存性は秩序変数 $X(T)$ を通じて生じるため，

```math
C=\frac{dE}{dT}
=\frac{dE}{dX}\frac{dX}{dT}
```

となる．
式 (1) より，

```math
\boxed{
C=-\frac{zNv}{2}X\frac{dX}{dT}
}
\tag{8}
```

を得る．
以下では，式 (7) を用いて比熱を求める．

#### 4.1．一般の温度 $T<T_c$

式 (7) を微分するため，

```math
x=\frac{T_cX}{T}
\tag{9}
```

とおく．
すると，

```math
X=\tanh x
\tag{10}
```

であり，

```math
\frac{T}{T_c}=\frac{\tanh x}{x}
\tag{11}
```

が成り立つ．

式 (7) を温度 $T$ で微分すると，

```math
\frac{1}{\cosh^2x}
\left(
-\frac{T_cX}{T^2}
+\frac{T_c}{T}\frac{dX}{dT}
\right)
=\frac{dX}{dT}
```

となる．
これを整理し， $x=T_cX/T$ を用いると，

```math
\boxed{
\frac{dX}{dT}
=-\frac{x}
{T\left(\cosh^2x-\dfrac{T_c}{T}\right)}
}
\tag{12}
```

を得る．
さらに，式 (11) より，

```math
\frac{T_c}{T}=\frac{x}{\tanh x}
\tag{13}
```

である．
式 (12)，(13) を式 (8) に代入し， $zv/(2k)=T_c$ を使って整理すると，

```math
\boxed{
C=Nk\frac{x^2}
{\cosh^2x-\dfrac{x}{\tanh x}}
}
\tag{14}
```

となる．
式 (11) と式 (14) により， $x$ を媒介変数として，比熱 $C$ を温度 $T/T_c$ の関数として表すことができる．

#### 4.2．転移温度 $T_c$ 近傍

$T$ が $T_c$ に近いとき，秩序変数 $X$ は小さい．
このとき，

```math
\tanh y=y-\frac{y^3}{3}+O(y^5)
```

を式 (7) に適用すると，

```math
X\approx\frac{T_c}{T}X
-\frac13\left(\frac{T_c}{T}\right)^3X^3
```

となる．
非零の解について整理すると，

```math
X^2\approx
3\frac{\dfrac{T_c}{T}-1}
{\left(\dfrac{T_c}{T}\right)^3}
```

である．
特に $T\approx T_c$ では，

```math
\boxed{
X^2\approx3\frac{T_c-T}{T_c}
}
\tag{15}
```

となる．

式 (15) を温度 $T$ で微分すると，

```math
2X\frac{dX}{dT}\approx-\frac{3}{T_c}
```

であるため，

```math
\boxed{
X\frac{dX}{dT}\approx-\frac{3}{2T_c}
}
\tag{16}
```

を得る．
式 (8)，(16) より，

```math
C(T\to T_c-0)
=\frac{3zNv}{4T_c}
```

となる．
式 (6) の $T_c=zv/(2k)$ を用いれば，

```math
\boxed{
C(T\to T_c-0)=\frac32Nk
}
\tag{17}
```

である．

一方， $T>T_c$ では $X=0$ であるため，式 (1) の秩序に依存する内部エネルギーは一定となる．
したがって，このモデルの異常比熱は

```math
\boxed{
C(T\to T_c+0)=0
}
\tag{18}
```

である．

よって，比熱は転移温度で

```math
\boxed{
\Delta C=C(T_c-0)-C(T_c+0)=\frac32Nk
}
\tag{19}
```

という有限の不連続を示す．
秩序変数 $X$ 自体は転移温度で連続的にゼロとなるが，比熱は不連続に変化する．
これは，Bragg–Williams 近似における第2種相転移の特徴である．

#### 4.3．低温 $T\ll T_c$

低温では，式 (11) より $x\to\infty$ となる．
このとき，

```math
\tanh x\approx1,\qquad
\cosh^2x\approx\frac14e^{2x}
```

であるから，

```math
x\approx\frac{T_c}{T}
```

となる．
また，

```math
\cosh^2x\gg\frac{x}{\tanh x}
```

であるため，式 (14) より，

```math
C\approx4Nkx^2e^{-2x}
```

を得る．
したがって，

```math
\boxed{
C\approx4Nk
\left(\frac{T_c}{T}\right)^2
\exp\left(-\frac{2T_c}{T}\right)
}
\tag{20}
```

となる．
この式から，低温では異常比熱が指数関数的に小さくなり， $T\to0$ で急速にゼロへ近づくことが分かる．

### 5．結論

Bragg–Williams 近似による AB 型2元合金の秩序変数は，

```math
X=\tanh\left(\frac{T_c}{T}X\right),
\qquad
T_c=\frac{zv}{2k}
```

によって定まる．
この式を内部エネルギー

```math
E=-\frac{zNv}{4}X^2
```

に適用すると，比熱は式 (14) の形で得られる．
特に，転移温度直下では $C=3Nk/2$ ，直上では $C=0$ となり，比熱に有限の跳びが生じる．
また，低温では式 (20) のように指数関数的に減少する．
以上より，Bragg–Williams 近似では，AB 型2元合金の秩序・無秩序転移に伴う異常比熱が求められた．
