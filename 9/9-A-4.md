# 演習問題【9-A-4】

## 解答

### 1．Bragg–Williams 近似と秩序変数

AB型2元合金について，Bragg–Williams 近似を用いて秩序変数と比熱を求める．

全サイト数を $N$ とし，A原子とB原子が等量存在する合金を考える．
したがって，

```math
N_A=N_B=\frac N2
```

である．

結晶を二つの部分格子 $\mathrm a$ ， $\mathrm b$ に分け，それぞれのサイト数を $N/2$ とする．
また，最近接サイトはすべて異なる部分格子に属する二部格子構造を仮定する．

部分格子 $\mathrm a$ におけるA原子の占有確率を

```math
p_{\mathrm a}=\frac{1+X}{2}
```

部分格子 $\mathrm b$ におけるA原子の占有確率を

```math
p_{\mathrm b}=\frac{1-X}{2}
```

と定義する．

ここで， $X$ は秩序変数であり，

```math
-1\leq X\leq1
```

である．

この定義では，

- $X=0$ ： 無秩序状態
- $X=1$ ： 部分格子aがA，部分格子bがBである完全秩序状態
- $X=-1$ ： 部分格子aがB，部分格子bがAである完全秩序状態

を表す．

以下では，対称性によって等価な二つの秩序状態のうち， $X\geq0$ の状態を考える．

Bragg–Williams 近似では，各サイトの占有状態を平均的な占有確率で表し，原子間の配置相関を無視する．
また，結晶の表面効果は無視し，最近接配位数 $z$ はすべてのサイトで一定とする．

### 2．内部エネルギー

最近接原子対の相互作用エネルギーを，

```math
\epsilon_{AA},\qquad
\epsilon_{BB},\qquad
\epsilon_{AB}
```

とする．
ここでは $\epsilon_{AB}=\epsilon_{BA}$ とし，すべての最近接結合は異なる部分格子間を結ぶものとする．

部分格子aと部分格子bの間にある最近接対について，それぞれの占有確率を用いると，

```math
P(AA)=\frac{1-X^2}{4}
```

```math
P(BB)=\frac{1-X^2}{4}
```

```math
P(AB)=\frac{1+X^2}{2}
```

となる．

したがって，最近接対1個当たりの平均エネルギーは，

```math
\begin{aligned}
\overline{\epsilon}
={}&
\frac{\epsilon_{AA}+\epsilon_{BB}}{4}(1-X^2)\\
&+\frac{\epsilon_{AB}}{2}(1+X^2)
\end{aligned}
```

である．

最近接結合の総数は $zN/2$ なので，

```math
E=\frac{zN}{2}\overline{\epsilon}
```

となる．

これを整理すると，

```math
E=E_0
-\frac{zN}{8}
(\epsilon_{AA}+\epsilon_{BB}-2\epsilon_{AB})X^2
```

を得る．

ここで，

```math
v=
\frac{\epsilon_{AA}+\epsilon_{BB}-2\epsilon_{AB}}{2}
```

と定義する．

このとき，

```math
E=E_0-\frac{zNv}{4}X^2
```

となる．

秩序化によってエネルギーが低下する場合には，

```math
v>0
```

である．
以下では，秩序に依存しない定数 $E_0$ を省略し，

```math
\boxed{
E(X)=-\frac{zNv}{4}X^2
}
\tag{1}
```

を用いる．

ここで，相互作用定数 $v$ は温度に依存しないものとする．

### 3．配置エントロピー

Boltzmann の原理より，

```math
S=k\ln W
```

である．

部分格子aにおけるA原子とB原子の数は，

```math
N_{A,\mathrm a}=\frac{N(1+X)}4
```

```math
N_{B,\mathrm a}=\frac{N(1-X)}4
```

である．

部分格子bでは，

```math
N_{A,\mathrm b}=\frac{N(1-X)}4
```

```math
N_{B,\mathrm b}=\frac{N(1+X)}4
```

となる．

したがって，配置数は，

```math
W=
\left[
\frac{(N/2)!}
{
\{N(1+X)/4\}!
\{N(1-X)/4\}!
}
\right]^2
```

である．

よって，

```math
S=k\ln W
```

から，

```math
\begin{aligned}
S=2k\Bigg[
&\ln\left(\frac N2\right)!
\\
&-\ln\left\{\frac{N(1+X)}4\right\}!
\\
&-\ln\left\{\frac{N(1-X)}4\right\}!
\Bigg]
\end{aligned}
```

となる．

ここで $N\gg1$ とし，Stirling の近似

```math
\ln n!\simeq n\ln n-n
```

を適用する．

これを整理すると，

```math
\boxed{
S(X)
=
-Nk\left[
\frac{1+X}{2}\ln\frac{1+X}{2}
+
\frac{1-X}{2}\ln\frac{1-X}{2}
\right]
}
\tag{2}
```

を得る．

この式は熱力学極限における配置エントロピーを表す．

特に，

```math
S(0)=Nk\ln2
```

であり，

```math
S(1)=S(-1)=0
```

である．

したがって，無秩序状態では配置エントロピーが最大となり，完全秩序状態では配置エントロピーがゼロとなる．

### 4．自由エネルギーと平衡条件

ヘルムホルツ自由エネルギーは，

```math
F=E-TS
```

である．

式 (1)，(2) を代入すると，

```math
\begin{aligned}
F(X)={}&-\frac{zNv}{4}X^2\\
&+NkT\left[
\frac{1+X}{2}\ln\frac{1+X}{2}
+
\frac{1-X}{2}\ln\frac{1-X}{2}
\right]
\end{aligned}
\tag{3}
```

となる．

平衡状態では，自由エネルギーが最小になる．
まず，停留条件

```math
\frac{dF}{dX}=0
```

を求める．

式 (3) を微分すると，

```math
\frac{dF}{dX}
=
-\frac{zNv}{2}X
+
\frac{NkT}{2}\ln\frac{1+X}{1-X}
```

である．

したがって，

```math
\frac{zv}{2kT}X
=
\frac12\ln\frac{1+X}{1-X}
```

を得る．

ここで，

```math
\boxed{
T_c=\frac{zv}{2k}
}
\tag{4}
```

と定義すると，

```math
\operatorname{artanh}X
=
\frac{T_c}{T}X
```

となる．

両辺に双曲線正接を適用すれば，

```math
\boxed{
X=\tanh\left(\frac{T_c}{T}X\right)
}
\tag{5}
```

を得る．

これがBragg–Williams近似による秩序変数の自己無撞着方程式である．

### 5．平衡解の安定性と一意性

式 (5) の解が実際に自由エネルギーを最小にすることを確認する．

自由エネルギーの二階微分は，

```math
\boxed{
\frac{d^2F}{dX^2}
=
NkT\left[
\frac{1}{1-X^2}
-\frac{T_c}{T}
\right]
}
\tag{6}
```

である．

まず，無秩序状態 $X=0$ について，

```math
\left.\frac{d^2F}{dX^2}\right|_{X=0}
=
Nk(T-T_c)
```

となる．

したがって，

```math
T>T_c
```

では，

```math
F''(0)>0
```

であり，無秩序状態 $X=0$ は局所的な極小点である．

一方，

```math
T<T_c
```

では，

```math
F''(0)<0
```

となるため，無秩序状態は極大点であり，平衡状態ではない．

次に，非零解 $X_*>0$ の安定性を調べる．

自己無撞着方程式より，

```math
\operatorname{artanh}X_*
=
\frac{T_c}{T}X_*
```

である．

したがって，

```math
F''(X_*)
=
NkT
\left[
\frac{1}{1-X_*^2}
-
\frac{\operatorname{artanh}X_*}{X_*}
\right]
```

となる．

ここで，

```math
h(X)=
\frac{X}{1-X^2}
-\operatorname{artanh}X
```

とおく．

微分すると，

```math
h'(X)
=
\frac{2X^2}{(1-X^2)^2}>0
\qquad (0<X<1)
```

であり，

```math
h(0)=0
```

である．

したがって，

```math
h(X)>0
```

であり，

```math
\frac{1}{1-X^2}
>
\frac{\operatorname{artanh}X}{X}
```

が成立する．

よって，

```math
\boxed{
F''(X_*)>0
}
\tag{7}
```

となり，非零解は自由エネルギーの極小点である．

さらに，非零解の一意性を確認する．

式 (5) は，

```math
\frac{T_c}{T}
=
\frac{\operatorname{artanh}X}{X}
```

と書ける．

ここで，

```math
g(X)=\frac{\operatorname{artanh}X}{X}
```

と定義する．

その導関数は，

```math
g'(X)
=
\frac{
\dfrac{X}{1-X^2}-\operatorname{artanh}X
}{
X^2
}
```

である．

前述のとおり，分子は $0<X<1$ で正なので，

```math
g'(X)>0
```

となる．

また，

```math
\lim_{X\to0^+}g(X)=1
```

および，

```math
\lim_{X\to1^-}g(X)=\infty
```

である．

したがって，

- $T>T_c$ では正の非零解は存在しない．
- $T=T_c$ でも正の非零解は存在しない．
- $T<T_c$ では正の非零解がただ一つ存在する．

ことが分かる．

さらに，

```math
\frac{dF}{dX}
=
NkT\,X
\left[
g(X)-\frac{T_c}{T}
\right]
```

である．

$T<T_c$ では， $X=0$ 付近で $F'(X)<0$ ，唯一の正の非零解より大きい領域では $F'(X)>0$ となる．

したがって，この非零解は $0\leq X\leq1$ における大域的な最小点である．

自由エネルギーは $X$ の偶関数であるため，負の側にも対称な最小点が存在する．

以上から，平衡状態は，

```math
\boxed{
\begin{cases}
X=0,&T\geq T_c,\\
X=\pm X_*,&T<T_c
\end{cases}
}
\tag{8}
```

で与えられる．

ここでは $X\geq0$ を選んでいるため，低温では $X=X_*$ を採用する．

### 6．一般温度での異常比熱

以下で求める比熱は，秩序・無秩序転移に起因する配置比熱である．
格子振動などによる他の比熱成分は含めない．

また， $v$ は温度に依存しない定数とする．

内部エネルギーは，

```math
E=-\frac{zNv}{4}X^2
```

であるから，平衡状態に沿った比熱は，

```math
C_{\mathrm{conf}}
=
\frac{dE}{dT}
```

となる．

したがって，

```math
\boxed{
C_{\mathrm{conf}}
=
-\frac{zNv}{2}X\frac{dX}{dT}
}
\tag{9}
```

を得る．

ここで，秩序変数は温度に依存するため，その温度微分を求める．

式 (5) について，

```math
x=\frac{T_cX}{T}
\tag{10}
```

とおくと，

```math
X=\tanh x
\tag{11}
```

であり，

```math
\frac{T}{T_c}=\frac{\tanh x}{x}
\tag{12}
```

が成立する．

式 (5) を温度で微分すると，

```math
\frac{dX}{dT}
=
\frac{1}{\cosh^2x}
\left(
-\frac{T_cX}{T^2}
+
\frac{T_c}{T}\frac{dX}{dT}
\right)
```

となる．

これを整理すると，

```math
\boxed{
\frac{dX}{dT}
=
-\frac{x}
{T\left(
\cosh^2x-\dfrac{T_c}{T}
\right)}
}
\tag{13}
```

である．

また，式 (12) より，

```math
\frac{T_c}{T}
=
\frac{x}{\tanh x}
```

である．

これを式 (9)，(13) に代入し，

```math
T_c=\frac{zv}{2k}
```

を用いて整理すると，

```math
\boxed{
C_{\mathrm{conf}}(T)
=
Nk
\frac{x^2}
{
\cosh^2x-\dfrac{x}{\tanh x}
}
}
\tag{14}
```

を得る．

ここで， $x$ は，

```math
\boxed{
\frac{T}{T_c}=\frac{\tanh x}{x}
}
\tag{15}
```

によって温度と関係づけられる．

式 (14)，(15) が， $T<T_c$ における比熱の媒介変数表示である．

なお，非零平衡解では $F''(X)>0$ であるため，式 (14) の分母は正であり，比熱は正となる．

一方， $T>T_c$ では平衡状態は $X=0$ であり，秩序に依存する内部エネルギーは一定である．

したがって，

```math
\boxed{
C_{\mathrm{conf}}(T)=0
\qquad (T>T_c)
}
\tag{16}
```

となる．

### 7．転移温度 $T_c$ の近傍

転移温度直下では秩序変数 $X$ が小さくなる．

そこで，

```math
\tanh y
=
y-\frac{y^3}{3}
+O(y^5)
```

を自己無撞着方程式に適用する．

すると，

```math
X=
\frac{T_c}{T}X
-
\frac13
\left(\frac{T_c}{T}\right)^3X^3
+O(X^5)
```

を得る．

非零解について整理すると，

```math
X^2
=
3
\frac{
\dfrac{T_c}{T}-1
}{
\left(\dfrac{T_c}{T}\right)^3
}
+O\left[
\left(\frac{T_c-T}{T_c}\right)^2
\right]
```

となる．

したがって， $T\simeq T_c$ では，

```math
\boxed{
X^2
\simeq
3\frac{T_c-T}{T_c}
}
\tag{17}
```

である．

よって，

```math
X\propto(T_c-T)^{1/2}
```

となり，Bragg–Williams 近似における秩序変数の臨界指数は，

```math
\boxed{
\beta_{\mathrm{ord}}=\frac12
}
```

である．

式 (17) を温度で微分すると，

```math
2X\frac{dX}{dT}
\simeq
-\frac3{T_c}
```

となるため，

```math
\boxed{
X\frac{dX}{dT}
\simeq
-\frac{3}{2T_c}
}
\tag{18}
```

を得る．

これを式 (9) に代入すると，

```math
C_{\mathrm{conf}}(T_c-0)
=
\frac{3zNv}{4T_c}
```

となる．

さらに，

```math
T_c=\frac{zv}{2k}
```

を代入すれば，

```math
\boxed{
C_{\mathrm{conf}}(T_c-0)
=
\frac32Nk
}
\tag{19}
```

を得る．

一方， $T>T_c$ では，

```math
X=0
```

であるため，

```math
\boxed{
C_{\mathrm{conf}}(T_c+0)=0
}
\tag{20}
```

となる．

したがって，比熱の跳びは，

```math
\boxed{
\Delta C_{\mathrm{conf}}
=
C_{\mathrm{conf}}(T_c-0)
-
C_{\mathrm{conf}}(T_c+0)
=
\frac32Nk
}
\tag{21}
```

である．

この転移では，秩序変数は連続的にゼロとなり，潜熱は生じない一方，比熱は有限の不連続を示す．
したがって，Bragg–Williams 近似では連続的な二次相転移が得られる．

### 8．低温 $T\ll T_c$ における比熱

低温では，

```math
x\to\infty
```

となる．

このとき，

```math
\tanh x
=
1-2e^{-2x}+O(e^{-4x})
```

および，

```math
\cosh^2x
=
\frac14e^{2x}
\left[
1+O(e^{-2x})
\right]
```

である．

式 (15) より，

```math
\frac{T_c}{T}
=
\frac{x}{\tanh x}
```

なので，低温では，

```math
x\simeq\frac{T_c}{T}
```

となる．

また，

```math
\cosh^2x
\gg
\frac{x}{\tanh x}
```

であるため，式 (14) は，

```math
C_{\mathrm{conf}}
\simeq4Nkx^2e^{-2x}
```

となる．

ここで，

```math
y=\frac{T_c}{T}
```

とすると， $x=y+O(ye^{-2y})$ であるから，

```math
\boxed{
C_{\mathrm{conf}}
=
4Nk
\left(\frac{T_c}{T}\right)^2
\exp\left(-\frac{2T_c}{T}\right)
\left[
1+O\left(
\frac{T_c}{T}e^{-2T_c/T}
\right)
\right]
}
\tag{22}
```

を得る．

したがって，

```math
\boxed{
C_{\mathrm{conf}}
\propto
T^{-2}e^{-2T_c/T}
}
```

となり，低温では比熱は指数関数的にゼロへ近づく．

### 9．熱力学極限とBragg–Williams近似の適用範囲

ここまでの自由エネルギーとエントロピーは，配置数に Stirling 近似を適用した熱力学極限の表式である．

したがって，

```math
N\to\infty
```

において相転移と比熱の不連続を議論している．

有限の $N$ では秩序変数 $X$ は離散的な値しか取らず，厳密な分配関数は温度について解析的であるため，真の相転移に対応する不連続は生じない．

また，Bragg–Williams 近似では短距離秩序や臨界揺らぎを無視している．
したがって，実際の合金における臨界指数や転移温度は，この近似の予測と異なる場合がある．

さらに，ここで求めた比熱は秩序変数に依存する配置比熱であり，格子振動や電子励起などに由来する通常の比熱成分は含まれていない．

### 10．結論

AB型2元合金のBragg–Williams近似では，秩序変数は，

```math
\boxed{
X=\tanh\left(\frac{T_c}{T}X\right)
}
```

によって定まる．

転移温度は，

```math
\boxed{
T_c=\frac{zv}{2k}
}
```

である．

この自己無撞着方程式の平衡解は，自由エネルギーの最小条件を満たし，

```math
X=
\begin{cases}
0,&T\geq T_c,\\
X_*>0,&T<T_c
\end{cases}
```

となる．

転移温度直下では，

```math
\boxed{
X^2\simeq
3\frac{T_c-T}{T_c}
}
```

である．

一般温度 $T<T_c$ における配置比熱は，

```math
\boxed{
C_{\mathrm{conf}}
=
Nk
\frac{x^2}
{
\cosh^2x-\dfrac{x}{\tanh x}
}
}
```

ただし，

```math
\frac{T}{T_c}=\frac{\tanh x}{x}
```

で与えられる．

転移温度では，

```math
\boxed{
C_{\mathrm{conf}}(T_c-0)=\frac32Nk
}
```

および，

```math
\boxed{
C_{\mathrm{conf}}(T_c+0)=0
}
```

となり，比熱に有限の跳びが生じる．

また，低温では，

```math
\boxed{
C_{\mathrm{conf}}
\simeq
4Nk
\left(\frac{T_c}{T}\right)^2
e^{-2T_c/T}
}
```

と指数関数的に減少する．

以上より，Bragg–Williams 近似では，AB型2元合金の秩序・無秩序転移に伴う配置比熱の異常が得られる．
