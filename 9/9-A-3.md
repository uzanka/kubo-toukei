# 演習問題【9-A-3】

## 解答

### 1．分子場近似と部分格子の磁化

反強磁性体では，隣り合うスピンが互いに逆向きにそろう傾向がある．
この性質を考慮するため，結晶を二つの部分格子 $\mathrm a$ ， $\mathrm b$ に分ける．
それぞれの部分格子内ではスピンが平行にそろい，二つの部分格子の磁化は互いに逆向きになることができる．

各部分格子の磁化を $\mathbf M_a$ ， $\mathbf M_b$ とし，単位体積当たりの全原子数を $n$ とする．
各部分格子の原子数密度は $n/2$ であるため，全磁化は

```math
\mathbf M=\mathbf M_a+\mathbf M_b
```

で与えられる．

問題のヒントに従い，部分格子 $\mathrm a$ ， $\mathrm b$ に作用する有効磁場をそれぞれ

```math
\boxed{
\begin{aligned}
\mathbf H'_a&=\mathbf H-q_2\mathbf M_a-q_1\mathbf M_b,\\
\mathbf H'_b&=\mathbf H-q_2\mathbf M_b-q_1\mathbf M_a
\end{aligned}
}
\tag{1}
```

とする．
ここで， $\mathbf H$ は外部磁場， $q_1$ は異なる部分格子間の相互作用を表す分子場定数， $q_2$ は同じ部分格子内の相互作用を表す分子場定数である．

### 2．高温における磁化の連立方程式

温度 $T$ がネール温度 $T_N$ 以上の常磁性相では，磁化が十分小さい．
したがって，ブリルアン関数を磁場について一次近似することで，各部分格子の磁化に Curie の法則を適用できる．

スピン量子数を $S$ ，ランデの $g$ 因子を $g$ ，ボーア磁子を $\mu_{\mathrm B}$ ，ボルツマン定数を $k$ とすると，系全体の Curie 定数は

```math
\boxed{
C=\frac{n(g\mu_{\mathrm B})^2S(S+1)}{3k}
}
\tag{2}
```

である．
各部分格子の原子数密度は全体の半分であるため，それぞれの Curie 定数は $C/2$ となる．
よって，各部分格子の磁化は

```math
\mathbf M_a=\frac{C}{2T}\mathbf H'_a
```

```math
\mathbf M_b=\frac{C}{2T}\mathbf H'_b
```

と表される．
式 (1) を代入すると，

```math
\boxed{
\mathbf M_a=
\frac{C}{2T}
\left(\mathbf H-q_2\mathbf M_a-q_1\mathbf M_b\right)
}
\tag{3}
```

```math
\boxed{
\mathbf M_b=
\frac{C}{2T}
\left(\mathbf H-q_2\mathbf M_b-q_1\mathbf M_a\right)
}
\tag{4}
```

を得る．

### 3．全磁化と常磁性磁化率

全磁化 $\mathbf M=\mathbf M_a+\mathbf M_b$ を求めるため，式 (3) と式 (4) を加える．
すると，

```math
\begin{aligned}
\mathbf M_a+\mathbf M_b
={}&\frac{C}{2T}
\bigl[
2\mathbf H\\
&-(q_1+q_2)(\mathbf M_a+\mathbf M_b)
\bigr]
\end{aligned}
```

となる．
したがって，

```math
\mathbf M=
\frac{C}{T}\mathbf H
-\frac{C}{2T}(q_1+q_2)\mathbf M
\tag{5}
```

である．
これを $\mathbf M$ について整理すると，

```math
\left[1+\frac{C(q_1+q_2)}{2T}\right]\mathbf M
=\frac{C}{T}\mathbf H
```

となる．
よって，

```math
\mathbf M=
\frac{C}{T+\dfrac{C}{2}(q_1+q_2)}\mathbf H
\tag{6}
```

を得る．
ここで，

```math
\boxed{
\theta=\frac{C}{2}(q_1+q_2)
}
\tag{7}
```

と定義すれば，

```math
\boxed{
\mathbf M=\frac{C}{T+\theta}\mathbf H
}
\tag{8}
```

となる．
磁化率を $\mathbf M=\chi\mathbf H$ によって定義すると，求める常磁性磁化率は

```math
\boxed{
\chi=\frac{C}{T+\theta}
}
\tag{9}
```

である．

これが反強磁性体の高温における Curie-Weiss 型の磁化率である．
解答例の規約では $q_1,q_2>0$ であるため $\theta>0$ となり，

```math
\chi=\frac{C}{T+\theta}<\frac{C}{T}
```

が成り立つ．
すなわち，反強磁性相互作用によって隣接するスピンが逆向きになろうとするため，磁化率は相互作用のない場合の Curie の法則による値より小さくなるのである．

なお，標準的な Curie-Weiss の表記を

```math
\chi=\frac{C}{T-\theta_{\mathrm{CW}}}
```

とする場合には， $\theta_{\mathrm{CW}}=-\theta$ である．

### 4．分子場定数とネール温度

参考として，反強磁性秩序が現れる条件を考える．
外部磁場をゼロとし，二つの部分格子の磁化が逆向きである状態

```math
\mathbf M_b=-\mathbf M_a
```

を考える．
これを式 (3) に代入すると，

```math
\mathbf M_a
=\frac{C}{2T}
\left(-q_2\mathbf M_a+q_1\mathbf M_a\right)
```

すなわち，

```math
\mathbf M_a
=\frac{C}{2T}(q_1-q_2)\mathbf M_a
\tag{10}
```

となる．
非零の磁化が現れ始める境界では，

```math
1=\frac{C}{2T_N}(q_1-q_2)
```

であるから，

```math
\boxed{
T_N=\frac{C}{2}(q_1-q_2)
}
\tag{11}
```

を得る．
したがって，この分子場モデルで $T_N>0$ となるためには $q_1>q_2$ が必要である．
これは，異なる部分格子間の反強磁性的相互作用が，同じ部分格子内の相互作用よりも強いことに対応する．

また，交換相互作用を $2|J|\mathbf S_i\cdot\mathbf S_j$ とし， $z_1,J_1$ を異なる部分格子間の隣接原子数と交換相互作用， $z_2,J_2$ を同じ部分格子内のそれらとすると，解答例の規約では

```math
\boxed{
q_1=\frac{2z_1|J_1|}{(n/2)g^2\mu_{\mathrm B}^2},
\qquad
q_2=\frac{2z_2|J_2|}{(n/2)g^2\mu_{\mathrm B}^2}
}
\tag{12}
```

で与えられる．

以上より，分子場近似による反強磁性体の高温常磁性磁化率は

```math
\boxed{
\chi=\frac{C}{T+\dfrac{C}{2}(q_1+q_2)}
}
```

である．
この式は，反強磁性相互作用によって磁化率が Curie の法則による値より小さくなることを示している．
