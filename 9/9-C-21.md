# 演習問題【9-C-21】

## 解答

本問題は，Ising 模型の Bethe 近似において，隣接するスピン対の平均数 $\overline{N_{++}}, \overline{N_{--}}, \overline{N_{+-}}$ が満たす特定の関係式を導出するものである．

### 1. 分配関数とスピン対の平均数の関係

Bethe 近似では，ある中心的なスピン $\sigma_0$ とその隣接する $z$ 個のスピン $\sigma_1, \dots, \sigma_z$ の相互作用を考慮する．
前問で得られた分配関数 $Z$ は，中心と第1隣接スピン対 $(\sigma_0, \sigma_1)$ の状態（ $\pm 1$ の組み合わせ）によって以下のように分解できる．

$$Z = Z_{++} + Z_{+-} + Z_{--}$$

ここで，$Z_{\sigma_0 \sigma_1}$ はスピン対 $(\sigma_0, \sigma_1)$ の状態が固定されたときの部分分配関数を表す．
隣接スピン対の平均数 $\overline{N_{\sigma_0 \sigma_1}}$ は，統計力学の定義に基づきこれらの部分分配関数に比例する．

$$\overline{N_{++}} : \overline{N_{+-}} : \overline{N_{--}} = Z_{++} : Z_{+-} : Z_{--} \quad \cdots (A)$$

### 2. 部分分配関数の導出

#### 2.1 $Z_{++}$ の計算

$\sigma_0 = +1, \sigma_1 = +1$ のとき，指数部の各項は：

- $\alpha \sigma_0 = \alpha$
- $(\alpha + \alpha') \sigma_1 = \alpha + \alpha'$
- $\beta \sigma_0 \sigma_1 = \beta$

残り $z-1$ 個の結合（ $\sigma_1$ と他の隣接スピン間）から $\cosh$ の項が現れる．
$\sigma_0 = +1$ なのでその引数は $\alpha + \alpha' + \beta\sigma_0 = \alpha + \alpha' + \beta$ である．

$$Z_{++} \propto e^{2\alpha + \alpha' + \beta} \,[2 \cosh (\alpha + \alpha' + \beta)]^{z-1} \quad \cdots (B)$$

#### 2.2 $Z_{+-}$ の計算と自己整合条件の適用

$+-$ 対には2つの配置がある．

**(i) $\sigma_0 = +1, \sigma_1 = -1$ のとき**：

指数部は $\alpha - (\alpha + \alpha') - \beta = -\alpha' - \beta$．
残り $z-1$ 個の結合の $\cosh$ 引数は $\alpha + \alpha' + \beta$ である．

$$\text{(i) の寄与} = e^{-\alpha' - \beta} \,[2 \cosh (\alpha + \alpha' + \beta)]^{z-1}$$

**(ii) $\sigma_0 = -1, \sigma_1 = +1$ のとき**：

指数部は $-\alpha + (\alpha + \alpha') - \beta = \alpha' - \beta$．
残り $z-1$ 個の結合の $\cosh$ 引数は $\alpha + \alpha' - \beta$ である．

$$\text{(ii) の寄与} = e^{\alpha' - \beta} \,[2 \cosh (\alpha + \alpha' - \beta)]^{z-1}$$

これらを合わせて：

$$Z_{+-} \propto e^{-\alpha' - \beta} [2 \cosh (\alpha + \alpha' + \beta)]^{z-1} + e^{\alpha' - \beta} [2 \cosh (\alpha + \alpha' - \beta)]^{z-1}$$

**ここで，前問9-C-20で得られた自己整合条件（つじつまが合う条件）$\overline{\sigma_0} = \overline{\sigma_j}$ から以下の関係式が導かれる：**

$$\left[ \frac{\cosh (\alpha + \alpha' + \beta)}{\cosh (\alpha + \alpha' - \beta)} \right]^{z-1} = e^{\,2\alpha'} \quad \cdots (C)$$

この式(C)を用いると，第2項は：

$$e^{\alpha' - \beta} [2 \cosh (\alpha + \alpha' - \beta)]^{z-1}
= e^{\alpha' - \beta} \left( e^{-2\alpha'/(z-1)} \cdot 2 \cosh (\alpha + \alpha' + \beta) \right)^{z-1}
= e^{-\alpha' - \beta} [2 \cosh (\alpha + \alpha' + \beta)]^{z-1}$$

となり，第1項と等しい．したがって：

$$Z_{+-} \propto 2e^{-\alpha' - \beta} \,[2 \cosh (\alpha + \alpha' + \beta)]^{z-1} \quad \cdots (D)$$

#### 2.3 $Z_{--}$ の計算

$\sigma_0 = -1, \sigma_1 = -1$ のとき：
指数部は $-\alpha - (\alpha + \alpha') + \beta = -2\alpha - \alpha' + \beta$．
$\sigma_0 = -1$ なので，残り $z-1$ 個の結合の $\cosh$ 引数は $\alpha + \alpha' + \beta(-1) = \alpha + \alpha' - \beta$ である．

$$Z_{--} \propto e^{-2\alpha - \alpha' + \beta} \,[2 \cosh (\alpha + \alpha' - \beta)]^{z-1}$$

自己整合条件(C)を用いて $\cosh(\alpha+\alpha'-\beta)$ を書き換える：

$$[2 \cosh (\alpha + \alpha' - \beta)]^{z-1} = e^{-2\alpha'} \,[2 \cosh (\alpha + \alpha' + \beta)]^{z-1}$$

ゆえに：

$$Z_{--} \propto e^{-2\alpha - 3\alpha' + \beta} \,[2 \cosh (\alpha + \alpha' + \beta)]^{z-1} \quad \cdots (E)$$

### 3. 関係式の証明

式(B), (D), (E)より：

$$\overline{N_{++}} : \overline{N_{+-}} : \overline{N_{--}} = e^{2\alpha + \alpha' + \beta} : 2e^{-\alpha' - \beta} : e^{-2\alpha - 3\alpha' + \beta}$$

共通因子 $[2 \cosh (\alpha + \alpha' + \beta)]^{z-1}$ は比においてキャンセルされるので：

$$\frac{\overline{N_{+-}}^{\,2}}{\overline{N_{++}} \,\overline{N_{--}}}
= \frac{(2e^{-\alpha' - \beta})^2}{(e^{2\alpha + \alpha' + \beta})(e^{-2\alpha - 3\alpha' + \beta})}$$

分母： $e^{(2\alpha + \alpha' + \beta) + (-2\alpha - 3\alpha' + \beta)} = e^{-2\alpha' + 2\beta}$

分子： $4e^{-2\alpha' - 2\beta}$

したがって：

$$\frac{\overline{N_{+-}}^{\,2}}{\overline{N_{++}} \,\overline{N_{--}}}
= \frac{4e^{-2\alpha' - 2\beta}}{e^{-2\alpha' + 2\beta}}
= 4e^{-4\beta}$$

$\beta = J/kT$ であるから：

$$\frac{\overline{N_{+-}}^{\,2}}{\overline{N_{++}} \,\overline{N_{--}}} = 4e^{-4J/kT}$$

となり，題意の関係が示された．

## 解説

この結果は，統計力学における「質量作用の法則」の近似的な形態とみなすことができる．

二つのスピン対 $(++)$ と $(--)$ が存在するとき，その間のスピンを入れかえることで2つの $(+-)$ 対を作ることができる．
これを化学反応 $\text{Pair}_{++} + \text{Pair}_{--} \rightleftharpoons 2\,\text{Pair}_{+-}$ の平衡と解釈すると，平衡定数 $K$ は

$$K = \frac{\overline{N_{+-}}^{\,2}}{\overline{N_{++}} \,\overline{N_{--}}} = 4e^{-4J/kT}$$

と与えられる．Bethe近似という手法が，スピン間の局所的な統計的平衡を記述していることを示す．

この手法は Fowler と Guggenheim によって「擬化学的方法 (quasi-chemical method)」として体系化され，結晶格子の欠陥統計や合金の構造解析などに応用されている．
