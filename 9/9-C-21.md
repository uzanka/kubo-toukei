# 演習問題【9-C-21】

## 解答

### 1．隣接スピン対の部分分配関数

前問の Bethe 近似では，中心スピン $\sigma_0$ とその周囲の $z$ 個のスピン $\sigma_1,\ldots,\sigma_z$ を考え，中心スピンと周囲のスピンとの相互作用を直接扱う．

次の無次元量を用いる．

```math
\alpha=\frac{\mu_0H}{kT},\qquad
\alpha'=\frac{\mu_0H'}{kT},\qquad
\beta=\frac{J}{kT}
\tag{1}
```

ここで， $H$ は外部磁場， $H'$ は分子場， $J$ は隣接スピン間の相互作用定数， $k$ は Boltzmann 定数， $T$ は絶対温度である．

隣接スピン対 $(\sigma_0,\sigma_1)$ の状態を固定し，残りのスピン $\sigma_2,\ldots,\sigma_z$ について和を取る．
各スピン $\sigma_j$ は中心スピン $\sigma_0$ と相互作用するため，その和は

```math
\sum_{\sigma_j=\pm1}
e^{(\alpha+\alpha'+\beta\sigma_0)\sigma_j}
=2\cosh(\alpha+\alpha'+\beta\sigma_0)
```

である．
よって，固定したスピン対の状態に対応する部分分配関数は

```math
\boxed{
\begin{aligned}
Z_{\sigma_0\sigma_1}
={}&e^{\alpha\sigma_0+
(\alpha+\alpha')\sigma_1+
\beta\sigma_0\sigma_1}\\
&\times
[2\cosh(\alpha+\alpha'+\beta\sigma_0)]^{z-1}
\end{aligned}
}
\tag{2}
```

となる．

ここで， $Z_{++}$ と $Z_{--}$ はそれぞれ $++$ 対と $--$ 対の部分分配関数である．
一方， $Z_{+-}$) は， $(+,-)$ と $(-,+)$ の両方の状態を合わせた部分分配関数とする．

式 (2) に各スピンの値を代入すると，

```math
\boxed{
Z_{++}
=e^{2\alpha+\alpha'+\beta}
[2\cosh(\alpha+\alpha'+\beta)]^{z-1}
}
\tag{3}
```

である．
混合対には2通りの向きがあるため，

```math
\boxed{
\begin{aligned}
Z_{+-}={}&
e^{-\alpha'-\beta}
[2\cosh(\alpha+\alpha'+\beta)]^{z-1}\\
&+e^{\alpha'-\beta}
[2\cosh(\alpha+\alpha'-\beta)]^{z-1}
\end{aligned}
}
\tag{4}
```

となる．
同様に，

```math
\boxed{
Z_{--}
=e^{-2\alpha-\alpha'+\beta}
[2\cosh(\alpha+\alpha'-\beta)]^{z-1}
}
\tag{5}
```

を得る．
全分配関数は，

```math
Z=Z_{++}+Z_{+-}+Z_{--}
\tag{6}
```

である．

### 2．平均スピン対数と部分分配関数の関係

隣接結合の総数を $Q$ とする．
Bethe 近似では各結合は等価であり，ある結合が特定のスピン対の状態を取る確率は，その状態の部分分配関数を全分配関数 $Z$ で割ったものである．
したがって，

```math
\overline{N_{++}}=Q\frac{Z_{++}}{Z},\qquad
\overline{N_{+-}}=Q\frac{Z_{+-}}{Z},\qquad
\overline{N_{--}}=Q\frac{Z_{--}}{Z}
```

と書ける．
ここで $\overline{N_{+-}}$ は，向きが $+-$ または $-+$ の混合対の総数の平均である．
よって，

```math
\boxed{
\overline{N_{++}}:\overline{N_{+-}}:\overline{N_{--}}
=Z_{++}:Z_{+-}:Z_{--}
}
\tag{7}
```

となる．
共通因子 $Q/Z$ は比を取ると消えるため，示すべき関係は部分分配関数によって計算できる．

### 3．Bethe 近似の自己無撞着条件を使う

前問で，中心スピンと周囲のスピンの平均値が一致するという自己無撞着条件から，

```math
\boxed{
\left[
\frac{\cosh(\alpha+\alpha'+\beta)}
{\cosh(\alpha+\alpha'-\beta)}
\right]^{z-1}
=e^{2\alpha'}
}
\tag{8}
```

を得ている．
したがって，

```math
[2\cosh(\alpha+\alpha'-\beta)]^{z-1}
=e^{-2\alpha'}
[2\cosh(\alpha+\alpha'+\beta)]^{z-1}
\tag{9}
```

である．

これを式 (4) の第2項に代入すると，

```math
\begin{aligned}
&e^{\alpha'-\beta}
[2\cosh(\alpha+\alpha'-\beta)]^{z-1}\\
&\qquad =
e^{\alpha'-\beta}e^{-2\alpha'}
[2\cosh(\alpha+\alpha'+\beta)]^{z-1}\\
&\qquad =
e^{-\alpha'-\beta}
[2\cosh(\alpha+\alpha'+\beta)]^{z-1}
\end{aligned}
```

となる．
したがって，式 (4) の2つの項は等しく，

```math
\boxed{
Z_{+-}
=2e^{-\alpha'-\beta}
[2\cosh(\alpha+\alpha'+\beta)]^{z-1}
}
\tag{10}
```

を得る．

同様に，式 (5) に式 (9) を適用すると，

```math
\begin{aligned}
Z_{--}
&=e^{-2\alpha-\alpha'+\beta}
e^{-2\alpha'}
[2\cosh(\alpha+\alpha'+\beta)]^{z-1}\\
&=e^{-2\alpha-3\alpha'+\beta}
[2\cosh(\alpha+\alpha'+\beta)]^{z-1}
\end{aligned}
```

である．
すなわち，

```math
\boxed{
Z_{--}
=e^{-2\alpha-3\alpha'+\beta}
[2\cosh(\alpha+\alpha'+\beta)]^{z-1}
}
\tag{11}
```

となる．

### 4．求める関係式の導出

式 (3)，(10)，(11) を比べると，それぞれに共通する因子

```math
[2\cosh(\alpha+\alpha'+\beta)]^{z-1}
```

を取り除くことができる．
よって，

```math
\overline{N_{++}}:\overline{N_{+-}}:\overline{N_{--}}
=
e^{2\alpha+\alpha'+\beta}:
2e^{-\alpha'-\beta}:
e^{-2\alpha-3\alpha'+\beta}
\tag{12}
```

である．

この比を用いて，求める比を計算する．
分子は

```math
(2e^{-\alpha'-\beta})^2
=4e^{-2\alpha'-2\beta}
```

であり，分母は

```math
\begin{aligned}
&e^{2\alpha+\alpha'+\beta}
e^{-2\alpha-3\alpha'+\beta}\\
&\qquad=e^{-2\alpha'+2\beta}
\end{aligned}
```

である．
したがって，

```math
\begin{aligned}
\frac{\overline{N_{+-}}^2}
{\overline{N_{++}}\overline{N_{--}}
}
&=\frac{4e^{-2\alpha'-2\beta}}
{e^{-2\alpha'+2\beta}}\\
&=4e^{-4\beta}
\end{aligned}
```

となる．
ここで， $\beta=J/(kT)$ を代入すれば，

```math
\boxed{
\frac{\overline{N_{+-}}^2}
{\overline{N_{++}}\overline{N_{--}}
}
=4e^{-4J/(kT)}
}
```

が得られる．
これで題意が示された．

### 補足：物理的な意味

この関係は，擬化学的方法の観点から， $++$ 対と $--$ 対が組み替わって2個の混合対 $+-$ を作る過程に対する平衡関係とみなすことができる．
Bethe 近似では，スピン対の局所的な相互作用を明示的に考慮し，残りのスピンの影響を分子場で表すことで，平均対数間の関係が得られるのである．
