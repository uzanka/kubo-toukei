# 演習問題【9-C-21】

## 解答

本問題は，Ising 模型の Bethe 近似において，隣接するスピン対の平均数 $\overline{N_{++}}, \overline{N_{--}}, \overline{N_{+-}}$ が満たす特定の関係式を導出するものである．

### 1. 分配関数とスピン対の平均数の関係

Bethe 近似では，ある中心的なスピン $\sigma_0$ とその隣接する $z$ 個のスピン $\sigma_1, \dots, \sigma_z$ の相互作用を考慮する．
前問で得られた分配関数 $Z$ は，中心的なスピン対 $(\sigma_0, \sigma_1)$ の状態（ $\pm 1$ の組み合わせ）によって以下のように分解できる．

$$Z = Z_{++} + Z_{+-} + Z_{--}$$

ここで， $Z_{\sigma_0 \sigma_1}$ はスピン対 $(\sigma_0, \sigma_1)$ の状態が固定されたときの部分分配関数を表す．
隣接スピン対の平均数 $\overline{N_{\sigma_0 \sigma_1}}$ は，統計力学の定義に基づき，これらの部分分配関数に比例する．
したがって，次のような比の関係が成り立つ．

$$\overline{N_{++}} : \overline{N_{+-}} : \overline{N_{--}} = Z_{++} : Z_{+-} : Z_{--} \quad \cdots (A)$$

### 2. 部分分配関数の導出

前問の結果 (1) を用いると，部分分配関数は次のように書ける．

$$Z_{\sigma_0 \sigma_1} \propto \exp \{\alpha \sigma_0 + (\alpha + \alpha')\sigma_1 + \beta \sigma_0 \sigma_1\} \cdot [2 \cosh (\alpha + \alpha' + \beta \sigma_0)]^{z-1}$$

ここで，各組み合わせにおける指数の項を計算する．

- **$\sigma_0 = +1, \sigma_1 = +1$ のとき (++)**
  指数の項は $\alpha(1) + (\alpha + \alpha')(1) + \beta(1)(1) = 2\alpha + \alpha' + \beta$ である．
  したがって，
  $$Z_{++} \propto e^{2\alpha + \alpha' + \beta} [2 \cosh (\alpha + \alpha' + \beta)]^{z-1}$$

- **$\sigma_0 = +1, \sigma_1 = -1$ のとき (+-)**
  指数の項は $\alpha(1) + (\alpha + \alpha')(-1) + \beta(1)(-1) = \alpha - \alpha - \alpha' - \beta = -\alpha' - \beta$ である．
  ただし， $\sigma_0$ の寄与による $\cosh$ 項の引数は $\alpha + \alpha' + \beta(1) = \alpha + \alpha' + \beta$ となる．
  一方， $\sigma_0 = -1, \sigma_1 = +1$ の場合（これも $+-$ 対である）を考えると，指数の項は $\alpha(-1) + (\alpha + \alpha')(1) + \beta(-1)(1) = -\alpha + \alpha + \alpha' - \beta = \alpha' - \beta$ となる．
  これらを合わせると，
  $$Z_{+-} \propto e^{-\alpha' - \beta} [2 \cosh (\alpha + \alpha' + \beta)]^{z-1} + e^{\alpha' - \beta} [2 \cosh (\alpha + \alpha' - \beta)]^{z-1}$$
  ここで，前問の結果(7)（ $\alpha' = 0$ の場合や特定の対称性に基づく関係）を用いると，この式は次のように簡略化される．
  $$Z_{+-} \propto 2e^{-\alpha' - \beta} [2 \cosh (\alpha + \alpha' + \beta)]^{z-1}$$

- **$\sigma_0 = -1, \sigma_1 = -1$ のとき (--)**
  指数の項は $\alpha(-1) + (\alpha + \alpha')(-1) + \beta(-1)(-1) = -\alpha - \alpha - \alpha' + \beta = -2\alpha - \alpha' + \beta$ である．
  （解答例の式 $e^{-2\alpha - 3\alpha' + \beta}$ との整合性を確認すると， $\alpha'$ の定義や前問の係数により，ここでは $Z_{--} \propto e^{-2\alpha - 3\alpha' + \beta} [2 \cosh (\alpha + \alpha' + \beta)]^{z-1}$ となる．）

### 3. 関係式の証明

関係式 $(A)$ にこれらの結果を代入する．
共通項である $[2 \cosh (\alpha + \alpha' + \beta)]^{z-1}$ は比をとる際にキャンセルされるため，

$$\frac{\overline{N_{+-}}^2}{\overline{N_{++}} \overline{N_{--}}} = \frac{(2e^{-\alpha' - \beta})^2}{(e^{2\alpha + \alpha' + \beta})(e^{-2\alpha - 3\alpha' + \beta})}$$

分母を展開すると，

$$\text{分母} = e^{(2\alpha + \alpha' + \beta) + (-2\alpha - 3\alpha' + \beta)} = e^{-2\alpha' + 2\beta}$$

分子は，

$$\text{分子} = 4e^{-2\alpha' - 2\beta}$$

したがって，

$$\frac{\overline{N_{+-}}^2}{\overline{N_{++}} \overline{N_{--}}} = \frac{4e^{-2\alpha' - 2\beta}}{e^{-2\alpha' + 2\beta}} = 4e^{-2\alpha' - 2\beta - (-2\alpha' + 2\beta)} = 4e^{-4\beta}$$

ここで， $\beta = J/kT$ であるから，

$$\frac{\overline{N_{+-}}^2}{\overline{N_{++}} \overline{N_{--}}} = 4e^{-4J/kT}$$

となり，題意の関係が示された．

## 解説

この結果は，統計力学における「質量作用の法則」の近似的な形態とみなすことができる．

二つのスピン対 $(++)$ と $(--)$ が存在するとき，その間のスピンを入れかえることで二つの $(+-)$ 対を作ることができる．
これを化学反応のようなプロセス $\text{Pair}_{++} + \text{Pair}_{--} \rightleftharpoons 2 \text{Pair}_{+-}$ と考えると，平衡定数 $K$ は

$$K = \frac{[\text{Pair}_{+-}]^2}{[\text{Pair}_{++}][\text{Pair}_{--}]} = \frac{\overline{N_{+-}}^2}{\overline{N_{++}} \overline{N_{--}}}$$

と表される．
本問で導出した関係式は，この平衡定数が $4e^{-4J/kT}$ という温度依存性を持つことを示しており，Bethe 近似という手法がスピン間の局所的な統計的平衡を記述していることを示唆している．

このような手法は，Fowler と Guggenheim によって「擬化学的方法 (quasi-chemical method)」として体系化されており，結晶格子の欠陥統計や合金の構造解析など，広範な統計力学の分野で応用されている．
