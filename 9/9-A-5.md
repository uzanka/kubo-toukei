# 演習問題【9-A-5】

## 解答

### 1．設定と規則度の定義

A 原子と B 原子からなる AB 型合金を考える．
全原子数を $N=N_{\mathrm A}+N_{\mathrm B}$ ，各原子の濃度を

```math
x_{\mathrm A}=\frac{N_{\mathrm A}}{N},\qquad
x_{\mathrm B}=\frac{N_{\mathrm B}}{N}=1-x_{\mathrm A}
```

とする．
問題では $x_{\mathrm A}<1/2$ である．
結晶を二つの部分格子 $\mathrm a$ ， $\mathrm b$ に分け，各部分格子のサイト数は $N/2$ とする．

長距離規則度 $X$ を，問題の指定に従って

```math
\begin{aligned}
N_{\mathrm{A,a}}&=\frac N2x_{\mathrm A}(1+X),\\
N_{\mathrm{A,b}}&=\frac N2x_{\mathrm A}(1-X),\\
N_{\mathrm{B,a}}&=\frac N2(x_{\mathrm B}-x_{\mathrm A}X),\\
N_{\mathrm{B,b}}&=\frac N2(x_{\mathrm B}+x_{\mathrm A}X)
\end{aligned}
\tag{1}
```

と定義する．
ここで $N_{\mathrm{A,a}}$ は部分格子 $\mathrm a$ に存在する A 原子数などを表す．

式 (1) を見ると， $X=0$ では各部分格子に A 原子と B 原子が同じ濃度で分布しているため，不規則状態となる．
一方， $X=\pm1$ は，この組成で実現できる最大の規則化に対応する．
ただし，A 原子と B 原子の濃度が等しくないため，最大規則化の状態でも過剰な B 原子は存在する．

以下では，Bragg–Williams 近似を用いて内部エネルギーとエントロピーを求め，自由エネルギーの最小条件から $X$ を定める方程式を導く．

### 2．内部エネルギーの導出

隣接する原子対の相互作用エネルギーを，A–A 対について $v_{\mathrm{AA}}$ ，A–B 対について $v_{\mathrm{AB}}$ ，B–B 対について $v_{\mathrm{BB}}$ とする．
また，各サイトの隣接サイト数を $z$ とする．
Bragg–Williams 近似では，隣接するサイトの占有確率を独立とみなし，原子対の数を各部分格子の占有数の積から評価する．

このとき，内部エネルギーは

```math
\begin{aligned}
E={}&\frac{zN}{2}\bigl[
v_{\mathrm{AA}}x_{\mathrm A}^2(1-X^2)\\
&+v_{\mathrm{BB}}(x_{\mathrm B}^2-x_{\mathrm A}^2X^2)\\
&+v_{\mathrm{AB}}(2x_{\mathrm A}x_{\mathrm B}
+2x_{\mathrm A}^2X^2)
\bigr]
\end{aligned}
\tag{2}
```

と表される．
係数 $zN/2$ は，全原子対の数を二重に数えないための係数である．

式 (2) を $X$ に依存する項と依存しない項に分けると，

```math
\begin{aligned}
E={}&\frac{zN}{2}
\left(v_{\mathrm{AA}}x_{\mathrm A}^2
+2v_{\mathrm{AB}}x_{\mathrm A}x_{\mathrm B}
+v_{\mathrm{BB}}x_{\mathrm B}^2\right)\\
&-\frac{zN}{2}x_{\mathrm A}^2
\left(v_{\mathrm{AA}}+v_{\mathrm{BB}}
-2v_{\mathrm{AB}}\right)X^2
\end{aligned}
\tag{3}
```

となる．
ここで，

```math
\boxed{
v=\frac12\left(
v_{\mathrm{AA}}+v_{\mathrm{BB}}-2v_{\mathrm{AB}}
\right)
}
\tag{4}
```

と定義する．
すると，

```math
\boxed{
E=E_0-zNx_{\mathrm A}^2vX^2
}
\tag{5}
```

を得る．
ただし，

```math
E_0=\frac{zN}{2}
\left(v_{\mathrm{AA}}x_{\mathrm A}^2
+2v_{\mathrm{AB}}x_{\mathrm A}x_{\mathrm B}
+v_{\mathrm{BB}}x_{\mathrm B}^2\right)
```

である．
$E_0$ は規則度 $X$ に依存しない項である．
規則化によってエネルギーが低下する場合を考え，以下では $v>0$ とする．

### 3．配置エントロピーの導出

次に，配置エントロピー $S$ を求める．
各部分格子の配置数は，組合せの公式から，

```math
W=
\frac{(N/2)!}{N_{\mathrm{A,a}}!N_{\mathrm{B,a}}!}
\frac{(N/2)!}{N_{\mathrm{A,b}}!N_{\mathrm{B,b}}!}
\tag{6}
```

である．
Boltzmann の原理

```math
S=k\log W
\tag{7}
```

によりエントロピーが定まる．
ここで $k$ はボルツマン定数である．

原子数が十分大きいとき，Stirling の公式

```math
\log m!\approx m\log m-m
```

を用いると，

```math
\begin{aligned}
S\approx-\frac{Nk}{2}\bigl[&
x_{\mathrm A}(1+X)\log\{x_{\mathrm A}(1+X)\}\\
&+(x_{\mathrm B}-x_{\mathrm A}X)
\log(x_{\mathrm B}-x_{\mathrm A}X)\\
&+x_{\mathrm A}(1-X)\log\{x_{\mathrm A}(1-X)\}\\
&+(x_{\mathrm B}+x_{\mathrm A}X)
\log(x_{\mathrm B}+x_{\mathrm A}X)
\bigr]
\end{aligned}
\tag{8}
```

を得る．

この式は，規則度 $X$ によって各部分格子の原子の占有確率が変化し，それに伴って配置の数も変わることを表している．

### 4．自由エネルギーの最小化と規則度方程式

温度 $T$ におけるヘルムホルツ自由エネルギーは

```math
F=E-TS
\tag{9}
```

である．
平衡状態では，組成を一定に保って自由エネルギーが最小となるため，

```math
\frac{\partial F}{\partial X}
=\frac{\partial E}{\partial X}
-T\frac{\partial S}{\partial X}=0
\tag{10}
```

が成り立つ．

式 (5) より，

```math
\frac{\partial E}{\partial X}
=-2zNx_{\mathrm A}^2vX
\tag{11}
```

である．
また，式 (8) を微分すると，

```math
\begin{aligned}
\frac{\partial S}{\partial X}
=-\frac{Nkx_{\mathrm A}}2
\log\left[
\frac{1+X}{1-X}
\frac{x_{\mathrm B}+x_{\mathrm A}X}
{x_{\mathrm B}-x_{\mathrm A}X}
\right]
\end{aligned}
\tag{12}
```

を得る．
式 (11)，(12) を式 (10) に代入すると，

```math
\begin{aligned}
-2zNx_{\mathrm A}^2vX
+\frac{NkTx_{\mathrm A}}2
\log\left[
\frac{1+X}{1-X}
\frac{x_{\mathrm B}+x_{\mathrm A}X}
{x_{\mathrm B}-x_{\mathrm A}X}
\right]=0
\end{aligned}
```

となる．
両辺を $NkTx_{\mathrm A}/2$ で割れば，

```math
\boxed{
\frac{zx_{\mathrm A}v}{kT}X
=\frac14\log\left[
\frac{1+X}{1-X}
\frac{x_{\mathrm B}+x_{\mathrm A}X}
{x_{\mathrm B}-x_{\mathrm A}X}
\right]
}
\tag{13}
```

が得られる．
これが Bragg–Williams 近似による規則度方程式である．

式 (13) を双曲線正接を用いた形に変形する．

```math
y=\frac{2zx_{\mathrm A}v}{kT}X
\tag{14}
```

とおくと，式 (13) より，

```math
e^{2y}=
\frac{1+X}{1-X}
\frac{x_{\mathrm B}+x_{\mathrm A}X}
{x_{\mathrm B}-x_{\mathrm A}X}
\tag{15}
```

となる．
一方，

```math
\tanh y=\frac{e^{2y}-1}{e^{2y}+1}
```

であるから，式 (15) を用いて分子と分母を整理すると，

```math
\tanh y=
\frac{X}{x_{\mathrm B}+x_{\mathrm A}X^2}
```

を得る．
したがって，規則度方程式は

```math
\boxed{
\frac{X}{x_{\mathrm B}+x_{\mathrm A}X^2}
=\tanh\left(\frac{2zx_{\mathrm A}v}{kT}X\right)
}
\tag{16}
```

となる．

### 5．転移温度と原子濃度比の関係

規則・不規則転移の温度を求めるため， $X\to0$ の極限を考える．
このとき，

```math
\frac{X}{x_{\mathrm B}+x_{\mathrm A}X^2}
=\frac{X}{x_{\mathrm B}}+O(X^3)
\tag{17}
```

である．
また， $\tanh u=u+O(u^3)$ であるから，式 (16) の右辺は

```math
\tanh\left(\frac{2zx_{\mathrm A}v}{kT}X\right)
=\frac{2zx_{\mathrm A}v}{kT}X+O(X^3)
\tag{18}
```

となる．

非零の規則度 $X$ が現れ始める転移温度 $T_c$ では，式 (17)，(18) の一次の係数が等しい．
したがって，

```math
\frac1{x_{\mathrm B}}
=\frac{2zx_{\mathrm A}v}{kT_c}
```

となり，

```math
\boxed{
T_c=\frac{2zx_{\mathrm A}x_{\mathrm B}v}{k}
}
\tag{19}
```

を得る．

ここで，A 原子と B 原子の濃度が等しい場合の転移温度を

```math
\boxed{
T_c^0=\frac{zv}{2k}
}
\tag{20}
```

と定義すると，式 (19) は

```math
\boxed{
T_c=4x_{\mathrm A}x_{\mathrm B}T_c^0
=4x_{\mathrm A}(1-x_{\mathrm A})T_c^0
}
\tag{21}
```

となる．
これが，転移温度と原子濃度比の関係である．

式 (21) は，転移温度が $x_{\mathrm A}=1/2$ のとき最大となり，

```math
T_c=T_c^0
```

を満たすことを示している．
組成が $1:1$ から外れると $x_{\mathrm A}x_{\mathrm B}$ が小さくなるため，転移温度も低下する．
これは，規則配列を形成するために必要な原子の一方が不足するほど，規則化が熱揺らぎに対して不安定になることに対応する．

### 6．転移温度以下で非零の規則度が現れることの確認

転移温度を求める際には， $X\to0$ での一次の係数を比較した．
ここでは，転移温度以下で実際に非零の規則度が現れることを確認する．

式 (16) の左辺を $X$ の三次まで展開すると，

```math
\frac{X}{x_{\mathrm B}+x_{\mathrm A}X^2}
=\frac{X}{x_{\mathrm B}}
-\frac{x_{\mathrm A}}{x_{\mathrm B}^2}X^3
+O(X^5)
\tag{22}
```

となる．
一方，右辺は

```math
\begin{aligned}
\tanh\left(\frac{2zx_{\mathrm A}v}{kT}X\right)
={}&\frac{2zx_{\mathrm A}v}{kT}X\\
&-\frac13\left(\frac{2zx_{\mathrm A}v}{kT}\right)^3X^3
+O(X^5)
\end{aligned}
\tag{23}
```

である．
両式を等置して整理すると，

```math
\begin{aligned}
0={}&\left(
\frac1{x_{\mathrm B}}-\frac{2zx_{\mathrm A}v}{kT}
\right)X\\
&+\left[
-\frac{x_{\mathrm A}}{x_{\mathrm B}^2}
+\frac13\left(\frac{2zx_{\mathrm A}v}{kT}\right)^3
\right]X^3+O(X^5)
\end{aligned}
\tag{24}
```

を得る．

転移温度 $T_c$ では，

```math
\frac{2zx_{\mathrm A}v}{kT_c}=\frac1{x_{\mathrm B}}
```

である．
よって，三次の係数を転移温度で評価すると，

```math
\begin{aligned}
-\frac{x_{\mathrm A}}{x_{\mathrm B}^2}
+\frac1{3x_{\mathrm B}^3}
&=\frac{1-3x_{\mathrm A}x_{\mathrm B}}
{3x_{\mathrm B}^3}
\end{aligned}
\tag{25}
```

となる．
$x_{\mathrm A}x_{\mathrm B}\leq1/4$ であるため，

```math
1-3x_{\mathrm A}x_{\mathrm B}\geq\frac14>0
```

が成り立つ．
したがって，三次の係数は正である．

$T<T_c$ では一次の係数が負になるため，式 (24) は $X=0$ 以外の解をもつ．
これによって，転移温度以下で規則度が非零となることが確認できる．

### 結論

Bragg–Williams 近似による AB 型合金の規則度方程式は，

```math
\boxed{
\frac{X}{x_{\mathrm B}+x_{\mathrm A}X^2}
=\tanh\left(\frac{2zx_{\mathrm A}v}{kT}X\right)
}
```

である．
この方程式を $X\to0$ で展開することにより，転移温度と濃度比の関係

```math
\boxed{
T_c=4x_{\mathrm A}x_{\mathrm B}T_c^0
=4x_{\mathrm A}(1-x_{\mathrm A})T_c^0,
\qquad
T_c^0=\frac{zv}{2k}
}
```

が得られる．
転移温度は等濃度組成 $x_{\mathrm A}=x_{\mathrm B}=1/2$ で最大となり，組成が $1:1$ から離れるほど低下する．
