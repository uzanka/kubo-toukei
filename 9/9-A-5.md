# 演習問題【9-A-5】

## 解答

### 1．設定と規則度の定義

A原子とB原子からなるAB型合金を考える．

全原子数をNとし，A原子とB原子の濃度を

```math
x_{\mathrm A}=\frac{N_{\mathrm A}}{N},
\qquad
x_{\mathrm B}=\frac{N_{\mathrm B}}{N}
=1-x_{\mathrm A}
```

とする．

問題の条件より，

```math
0<x_{\mathrm A}<\frac12,
\qquad
x_{\mathrm B}>\frac12
```

である．

結晶を二つの部分格子a，bに分け，それぞれのサイト数をN/2とする．
また，最近接サイトはすべて異なる部分格子に属する二部格子構造を仮定する．

問題文で指定された長距離規則度Xを，

```math
\begin{aligned}
N_{\mathrm{A,a}}&=\frac N2x_{\mathrm A}(1+X),\\
N_{\mathrm{A,b}}&=\frac N2x_{\mathrm A}(1-X),\\
N_{\mathrm{B,a}}&=\frac N2(x_{\mathrm B}-x_{\mathrm A}X),\\
N_{\mathrm{B,b}}&=\frac N2(x_{\mathrm B}+x_{\mathrm A}X)
\end{aligned}
\tag{1}
```

と定義する．

A原子とB原子の総数を確認すると，

```math
N_{\mathrm{A,a}}+N_{\mathrm{A,b}}
=Nx_{\mathrm A}=N_{\mathrm A}
```

および，

```math
N_{\mathrm{B,a}}+N_{\mathrm{B,b}}
=Nx_{\mathrm B}=N_{\mathrm B}
```

となる．
したがって，全体の組成は保存される．

また，各部分格子の占有確率の和は1である．

規則度の範囲は，

```math
-1\leq X\leq1
```

である．
ここで， $X=0$ は無秩序状態を表し， $X=1$ および $X=-1$ は，それぞれ二つの等価な最大規則化状態を表す．

以下では，対称性によって等価な二つの状態のうち， $X\geq0$ の状態を考える．

Bragg–Williams近似では，隣接サイトの占有状態を独立とみなし，原子間の配置相関を無視する．
また，最近接配位数zはすべてのサイトで一定とし，表面効果は無視する．

### 2．内部エネルギーの導出

最近接原子対の相互作用エネルギーを，

```math
\epsilon_{\mathrm{AA}},
\qquad
\epsilon_{\mathrm{BB}},
\qquad
\epsilon_{\mathrm{AB}}
```

とする．

ここで，

```math
\epsilon_{\mathrm{AB}}=\epsilon_{\mathrm{BA}}
```

とする．

部分格子aにおける占有確率は，

```math
P_{\mathrm a}(\mathrm A)=x_{\mathrm A}(1+X)
```

```math
P_{\mathrm a}(\mathrm B)=x_{\mathrm B}-x_{\mathrm A}X
```

であり，部分格子bでは，

```math
P_{\mathrm b}(\mathrm A)=x_{\mathrm A}(1-X)
```

```math
P_{\mathrm b}(\mathrm B)=x_{\mathrm B}+x_{\mathrm A}X
```

である．

Bragg–Williams近似では，隣接サイトの占有状態が独立であるとする．

したがって，A–A対の確率は，

```math
\begin{aligned}
P(\mathrm{AA})
&=P_{\mathrm a}(\mathrm A)P_{\mathrm b}(\mathrm A)\\
&=x_{\mathrm A}(1+X)x_{\mathrm A}(1-X)\\
&=\boxed{x_{\mathrm A}^2(1-X^2)}
\end{aligned}
```

となる．

同様に，B–B対の確率は，

```math
\begin{aligned}
P(\mathrm{BB})
&=P_{\mathrm a}(\mathrm B)P_{\mathrm b}(\mathrm B)\\
&=(x_{\mathrm B}-x_{\mathrm A}X)
(x_{\mathrm B}+x_{\mathrm A}X)\\
&=\boxed{x_{\mathrm B}^2-x_{\mathrm A}^2X^2}
\end{aligned}
```

である．

A–B対は，A原子が部分格子aに存在する場合と部分格子bに存在する場合の両方を含むため，

```math
\begin{aligned}
P(\mathrm{AB})
={}&P_{\mathrm a}(\mathrm A)P_{\mathrm b}(\mathrm B)\\
&+P_{\mathrm a}(\mathrm B)P_{\mathrm b}(\mathrm A)\\
={}&x_{\mathrm A}(1+X)(x_{\mathrm B}+x_{\mathrm A}X)\\
&+(x_{\mathrm B}-x_{\mathrm A}X)x_{\mathrm A}(1-X)\\
={}&\boxed{
2x_{\mathrm A}x_{\mathrm B}
+2x_{\mathrm A}^2X^2
}
\end{aligned}
```

となる．

これらの確率の総和は，

```math
\begin{aligned}
&P(\mathrm{AA})+P(\mathrm{BB})+P(\mathrm{AB})\\
&=x_{\mathrm A}^2+x_{\mathrm B}^2
+2x_{\mathrm A}x_{\mathrm B}\\
&=(x_{\mathrm A}+x_{\mathrm B})^2=1
\end{aligned}
```

であり，正しく規格化されている．

最近接対1個当たりの平均相互作用エネルギーは，

```math
\begin{aligned}
\overline{\epsilon}
={}&
\epsilon_{\mathrm{AA}}P(\mathrm{AA})
+\epsilon_{\mathrm{BB}}P(\mathrm{BB})\\
&+\epsilon_{\mathrm{AB}}P(\mathrm{AB})
\end{aligned}
```

である．

最近接結合の総数はzN/2なので，

```math
E=\frac{zN}{2}\overline{\epsilon}
```

となる．

これに各確率を代入すると，

```math
\begin{aligned}
E={}&\frac{zN}{2}\bigl[
\epsilon_{\mathrm{AA}}x_{\mathrm A}^2(1-X^2)\\
&+\epsilon_{\mathrm{BB}}
(x_{\mathrm B}^2-x_{\mathrm A}^2X^2)\\
&+\epsilon_{\mathrm{AB}}
(2x_{\mathrm A}x_{\mathrm B}
+2x_{\mathrm A}^2X^2)
\bigr]
\end{aligned}
```

を得る．

これを整理すると，

```math
\begin{aligned}
E={}&E_0\\
&-\frac{zN}{2}x_{\mathrm A}^2
(\epsilon_{\mathrm{AA}}+\epsilon_{\mathrm{BB}}
-2\epsilon_{\mathrm{AB}})X^2
\end{aligned}
```

となる．

ここで，

```math
E_0=\frac{zN}{2}
\left(
\epsilon_{\mathrm{AA}}x_{\mathrm A}^2
+2\epsilon_{\mathrm{AB}}x_{\mathrm A}x_{\mathrm B}
+\epsilon_{\mathrm{BB}}x_{\mathrm B}^2
\right)
```

は規則度に依存しない定数である．

また，相互作用定数を，

```math
v=
\frac{
\epsilon_{\mathrm{AA}}+\epsilon_{\mathrm{BB}}
-2\epsilon_{\mathrm{AB}}
}{2}
```

と定義する．

このとき，

```math
E=E_0-zNx_{\mathrm A}^2vX^2
```

となる．

以下では，規則化によってエネルギーが低下する場合を考え，

```math
v>0
```

とする．

秩序に依存しない定数項E0を省略すれば，

```math
\boxed{
E(X)=-zNx_{\mathrm A}^2vX^2
}
\tag{2}
```

を得る．

なお，vは温度に依存しない定数とする．

### 3．配置エントロピー

Boltzmannの原理より，

```math
S=k\ln W
```

である．

部分格子aにおける原子数は，

```math
N_{\mathrm{A,a}}=\frac N2x_{\mathrm A}(1+X)
```

```math
N_{\mathrm{B,a}}=\frac N2
(x_{\mathrm B}-x_{\mathrm A}X)
```

である．

部分格子bでは，

```math
N_{\mathrm{A,b}}=\frac N2x_{\mathrm A}(1-X)
```

```math
N_{\mathrm{B,b}}=\frac N2
(x_{\mathrm B}+x_{\mathrm A}X)
```

である．

したがって，配置数は，

```math
W=
\frac{(N/2)!}
{N_{\mathrm{A,a}}!N_{\mathrm{B,a}}!}
\frac{(N/2)!}
{N_{\mathrm{A,b}}!N_{\mathrm{B,b}}!}
```

となる．

これにStirlingの近似，

```math
\ln n!\simeq n\ln n-n
```

を適用すると，

```math
\begin{aligned}
S=-\frac{Nk}{2}\bigl[&
x_{\mathrm A}(1+X)
\ln\{x_{\mathrm A}(1+X)\}\\
&+(x_{\mathrm B}-x_{\mathrm A}X)
\ln(x_{\mathrm B}-x_{\mathrm A}X)\\
&+x_{\mathrm A}(1-X)
\ln\{x_{\mathrm A}(1-X)\}\\
&+(x_{\mathrm B}+x_{\mathrm A}X)
\ln(x_{\mathrm B}+x_{\mathrm A}X)
\bigr]
\end{aligned}
\tag{3}
```

を得る．

この式は熱力学極限における配置エントロピーである．

特に，X=0では，

```math
S(0)=
-Nk(x_{\mathrm A}\ln x_{\mathrm A}
+x_{\mathrm B}\ln x_{\mathrm B})
```

となる．

これは非等量組成におけるランダム配置のエントロピーである．

また，xAが1/2より小さいため，X=1でも過剰なB原子が残り，配置エントロピーは一般にゼロとはならない．

### 4．自由エネルギーと規則度方程式

ヘルムホルツ自由エネルギーは，

```math
F=E-TS
```

である．

式 (2)，(3) を代入すると，

```math
\begin{aligned}
F(X)={}&-zNx_{\mathrm A}^2vX^2\\
&+\frac{NkT}{2}\bigl[
x_{\mathrm A}(1+X)
\ln\{x_{\mathrm A}(1+X)\}\\
&+(x_{\mathrm B}-x_{\mathrm A}X)
\ln(x_{\mathrm B}-x_{\mathrm A}X)\\
&+x_{\mathrm A}(1-X)
\ln\{x_{\mathrm A}(1-X)\}\\
&+(x_{\mathrm B}+x_{\mathrm A}X)
\ln(x_{\mathrm B}+x_{\mathrm A}X)
\bigr]
\end{aligned}
\tag{4}
```

となる．

組成を一定に保った平衡状態では，自由エネルギーが最小となるため，停留条件は，

```math
\frac{\partial F}{\partial X}=0
```

である．

まず，内部エネルギーについて，

```math
\frac{\partial E}{\partial X}
=-2zNx_{\mathrm A}^2vX
```

となる．

また，エントロピーを微分すると，

```math
\boxed{
\frac{\partial S}{\partial X}
=
-\frac{Nkx_{\mathrm A}}{2}
\ln\left[
\frac{1+X}{1-X}
\frac{x_{\mathrm B}+x_{\mathrm A}X}
{x_{\mathrm B}-x_{\mathrm A}X}
\right]
}
\tag{5}
```

を得る．

したがって，

```math
\frac{\partial F}{\partial X}
=
\frac{\partial E}{\partial X}
-T\frac{\partial S}{\partial X}=0
```

より，

```math
-2zNx_{\mathrm A}^2vX
+
\frac{NkTx_{\mathrm A}}2
\ln\left[
\frac{1+X}{1-X}
\frac{x_{\mathrm B}+x_{\mathrm A}X}
{x_{\mathrm B}-x_{\mathrm A}X}
\right]
=0
```

となる．

整理すると，

```math
\boxed{
\frac{zx_{\mathrm A}v}{kT}X
=
\frac14
\ln\left[
\frac{1+X}{1-X}
\frac{x_{\mathrm B}+x_{\mathrm A}X}
{x_{\mathrm B}-x_{\mathrm A}X}
\right]
}
\tag{6}
```

を得る．

これがBragg–Williams近似による規則度方程式である．

さらに，

```math
y=\frac{2zx_{\mathrm A}v}{kT}X
```

とおくと，

```math
e^{2y}
=
\frac{1+X}{1-X}
\frac{x_{\mathrm B}+x_{\mathrm A}X}
{x_{\mathrm B}-x_{\mathrm A}X}
```

となる．

双曲線正接の定義より，

```math
\tanh y=\frac{e^{2y}-1}{e^{2y}+1}
```

なので，

```math
\frac{e^{2y}-1}{e^{2y}+1}
=
\frac{X}{x_{\mathrm B}+x_{\mathrm A}X^2}
```

を得る．

したがって，

```math
\boxed{
\frac{X}{x_{\mathrm B}+x_{\mathrm A}X^2}
=
\tanh\left(
\frac{2zx_{\mathrm A}v}{kT}X
\right)
}
\tag{7}
```

となる．

### 5．転移温度の導出

転移温度では，無秩序状態X=0から非零の規則度が連続的に発生する．

式 (7) でXが十分小さいとき，

```math
\frac{X}{x_{\mathrm B}+x_{\mathrm A}X^2}
=
\frac{X}{x_{\mathrm B}}+O(X^3)
```

である．

また，

```math
\tanh u=u+O(u^3)
```

なので，

```math
\tanh\left(
\frac{2zx_{\mathrm A}v}{kT}X
\right)
=
\frac{2zx_{\mathrm A}v}{kT}X+O(X^3)
```

となる．

非零の規則度が発生する転移温度 $T_c$ では，一次の係数を比較して，

```math
\frac1{x_{\mathrm B}}
=
\frac{2zx_{\mathrm A}v}{kT_c}
```

となる．

したがって，

```math
\boxed{
T_c=
\frac{2zx_{\mathrm A}x_{\mathrm B}v}{k}
}
\tag{8}
```

を得る．

等量組成の場合の転移温度を，

```math
T_c^0=\frac{zv}{2k}
```

と定義すると，

```math
\boxed{
T_c=4x_{\mathrm A}x_{\mathrm B}T_c^0
}
\tag{9}
```

となる．

さらに，

```math
x_{\mathrm B}=1-x_{\mathrm A}
```

より，

```math
\boxed{
T_c=4x_{\mathrm A}(1-x_{\mathrm A})T_c^0
}
\tag{10}
```

である．

したがって，転移温度は等量組成で最大となる．

### 6．非零解の存在と一意性の証明

前節では $X=0$ の近傍の展開から転移温度を求めた．
ここでは， $T<T_c$ の全温度範囲で非零解が存在し，その解が一意であることを確認する．

簡単のため，

```math
a=x_{\mathrm A},\qquad b=x_{\mathrm B}
```

および，

```math
r=\frac ab
```

とおく．

問題の条件から，

```math
0<a<b,\qquad 0<r<1
```

である．

式 (6) の対数部分は，

```math
\begin{aligned}
&\ln\left[
\frac{1+X}{1-X}
\frac{b+aX}{b-aX}
\right]\\
&=2\operatorname{artanh}X
+2\operatorname{artanh}(rX)
\end{aligned}
```

と書ける．

したがって，非零解の条件は，

```math
\boxed{
Q(X)=\frac{zav}{kT}
}
\tag{11}
```

となる．

ただし，

```math
\boxed{
Q(X)=
\frac{
\operatorname{artanh}X+
\operatorname{artanh}(rX)
}{
2X
}
}
\tag{12}
```

である．

逆双曲線正接の級数展開，

```math
\operatorname{artanh}u
=
u+\frac{u^3}{3}
+\frac{u^5}{5}+\cdots
```

を用いると，

```math
\begin{aligned}
Q(X)=\frac12\Bigg[
&1+r\\
&+\frac{1+r^3}{3}X^2\\
&+\frac{1+r^5}{5}X^4+\cdots
\Bigg]
\end{aligned}
```

となる．

したがって，

```math
Q'(X)
=
\frac12
\sum_{n=1}^{\infty}
\frac{2n(1+r^{2n+1})}{2n+1}
X^{2n-1}>0
```

である．

よって， $Q(X)$ は $0<X<1$ で厳密に単調増加する．

また，

```math
\lim_{X\to0^+}Q(X)
=
\frac{1+r}{2}
=
\frac1{2b}
```

であり，

```math
\lim_{X\to1^-}Q(X)=\infty
```

となる．

したがって，式 (11) の正の解が存在するためには，

```math
\frac{zav}{kT}>\frac1{2b}
```

が必要十分である．

これを整理すると，

```math
T<\frac{2zabv}{k}=T_c
```

となる．

さらに $Q(X)$ は厳密に単調増加するため，正の非零解はただ一つ存在する．

したがって，

```math
\boxed{
\begin{cases}
X=0,&T\geq T_c,\\
X=X_*>0,&T<T_c
\end{cases}
}
\tag{13}
```

となる．

負の規則度についても，自由エネルギーのXに関する対称性から， $X=-X_*$ という等価な解が存在する．

### 7．自由エネルギーの大域的最小性

式 (6)，(12) を用いると，自由エネルギーの一階微分は，

```math
\boxed{
\frac{\partial F}{\partial X}
=
2Nx_{\mathrm A}X
\left[
kTQ(X)-zx_{\mathrm A}v
\right]
}
\tag{14}
```

と書ける．

ここで，

```math
Q(0^+)=\frac1{2x_{\mathrm B}}
```

であり，Q(X)は正の範囲で厳密に単調増加する．

T>Tcの場合には，

```math
\frac{zx_{\mathrm A}v}{kT}
<
Q(0^+)
```

となる．
したがって，

```math
\frac{\partial F}{\partial X}>0
\qquad (X>0)
```

であり， $X=0$ が大域的最小点となる．

$T=T_c$ の場合にも， $X>0$ では，

```math
Q(X)>Q(0^+)
```

であるため， $X=0$ が大域的最小点である．

一方， $T<T_c$ では， $Q(X)$ の単調性からただ一つの正の解 $X_*$ が存在する．

このとき，

```math
\frac{\partial F}{\partial X}<0
\qquad (0<X<X_*)
```

および，

```math
\frac{\partial F}{\partial X}>0
\qquad (X_*<X<1)
```

となる．

よって， $X_*$ は $0\leq X\leq1$ における大域的最小点である．

また， $F(X)$ は偶関数なので，負の側にも同じ自由エネルギーを持つ最小点が存在する．

したがって，自己無撞着方程式の非零解は，実際に自由エネルギーを最小にする平衡状態である．

### 8．転移温度近傍の規則度

転移温度近傍ではXが小さいため， $Q(X)$ を展開すると，

```math
Q(X)
=
\frac1{2x_{\mathrm B}}
+
\frac{1+r^3}{6}X^2
+O(X^4)
```

となる．

一方，

```math
\frac{zx_{\mathrm A}v}{kT}
=
\frac1{2x_{\mathrm B}}\frac{T_c}{T}
```

である．

したがって， $T$ が $T_c$ よりわずかに低い場合，

```math
\frac1{2x_{\mathrm B}}
+
\frac{1+r^3}{6}X^2
\simeq
\frac1{2x_{\mathrm B}}
\left(
1+\frac{T_c-T}{T_c}
\right)
```

となる．

これを整理すると，

```math
\boxed{
X^2\simeq
\frac{3}{x_{\mathrm B}(1+r^3)}
\frac{T_c-T}{T_c}
}
\tag{15}
```

を得る．

したがって，

```math
X\propto(T_c-T)^{1/2}
```

となる．

よって，転移温度以下では，規則度はゼロから連続的に増加する．

この結果は，Bragg–Williams近似による連続的な秩序・無秩序転移と整合する．

### 9．転移温度と濃度比の関係

式 (10) より，

```math
T_c=4x_{\mathrm A}(1-x_{\mathrm A})T_c^0
```

である．

これを濃度 $x_A$ で微分すると，

```math
\frac{dT_c}{dx_{\mathrm A}}
=
4T_c^0(1-2x_{\mathrm A})
```

となる．

今回の条件，

```math
0<x_{\mathrm A}<\frac12
```

では，

```math
\frac{dT_c}{dx_{\mathrm A}}>0
```

である．

さらに，

```math
\frac{d^2T_c}{dx_{\mathrm A}^2}
=
-8T_c^0<0
```

である．

したがって，転移温度はxAが1/2に近づくほど上昇し，等量組成で最大となる．

特に，

```math
x_{\mathrm A}\to0
```

では，

```math
T_c\to0
```

となる．

また，

```math
x_{\mathrm A}=\frac12
```

では，

```math
T_c=T_c^0
```

となる．

以上より，転移温度と組成の関係が明確になる．

### 10．結論

Bragg–Williams近似による非等量組成AB型合金の規則度方程式は，

```math
\boxed{
\frac{X}{x_{\mathrm B}+x_{\mathrm A}X^2}
=
\tanh\left(
\frac{2zx_{\mathrm A}v}{kT}X
\right)
}
```

である．

転移温度は，

```math
\boxed{
T_c=
\frac{2zx_{\mathrm A}x_{\mathrm B}v}{k}
}
```

となる．

等量組成の転移温度を，

```math
T_c^0=\frac{zv}{2k}
```

とすれば，

```math
\boxed{
T_c=4x_{\mathrm A}x_{\mathrm B}T_c^0
}
```

である．

この転移温度は，等量組成で最大となり，組成が1:1から離れるほど低下する．

また， $T<T_c$ では正の非零規則度がただ一つ存在し，その解は自由エネルギーの大域的最小点である．

転移温度直下では，

```math
X\propto(T_c-T)^{1/2}
```

となり，規則度は連続的に発生する．

以上より，Bragg–Williams近似による規則度方程式と，転移温度の濃度依存性が導かれた．
