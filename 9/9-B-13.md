# 演習問題【9-B-13】

## 解答

### 1．分子場近似による自己無撞着方程式

反強磁性体を，部分格子 $a$ と部分格子 $b$ からなる系として考える．
反強磁性状態では，両部分格子の自発磁化は互いに反平行となる．

問題 [3] の分子場近似に従い，それぞれの部分格子が受ける有効磁場を

```math
\begin{cases}
\boldsymbol H_a'
=\boldsymbol H-q_2\boldsymbol M_a-q_1\boldsymbol M_b,\\[2mm]
\boldsymbol H_b'
=\boldsymbol H-q_2\boldsymbol M_b-q_1\boldsymbol M_a
\end{cases}
\tag{1}
```

とする．
ここで， $q_1$ は異なる部分格子間の相互作用を表す定数， $q_2$ は同じ部分格子内の相互作用を表す定数である．

各部分格子の磁化の大きさは，Brillouin 関数 $B_S(x)$ を用いて

```math
M_a=\frac{n}{2}g\mu_BS
B_S\left(\frac{g\mu_BS H_a'}{kT}\right),
```

```math
M_b=\frac{n}{2}g\mu_BS
B_S\left(\frac{g\mu_BS H_b'}{kT}\right)
\tag{2}
```

と表される．
ここで， $n$ は単位体積あたりの全格子点数， $g$ は Landé の $g$ 因子， $\mu_B$ は Bohr 磁子， $S$ はスピン量子数， $k$ は Boltzmann 定数， $T$ は絶対温度である．
各部分格子には全格子点の半数が属するため，磁化の式には $n/2$ が現れる．

自発磁化を求めるため，外部磁場をゼロとする．
すなわち，

```math
\boldsymbol H=\boldsymbol 0
```

とする．
反強磁性状態では，両部分格子の磁化は反平行である．
以下では，共通の軸に沿った符号付き磁化成分を $M_a，M_b$ として扱う．
式 (1)，(2) より，

```math
\begin{cases}
M_a=-\dfrac{n}{2}g\mu_BS
B_S\left(
\dfrac{g\mu_BS}{kT}(q_2M_a+q_1M_b)
\right),\\[3mm]
M_b=-\dfrac{n}{2}g\mu_BS
B_S\left(
\dfrac{g\mu_BS}{kT}(q_1M_a+q_2M_b)
\right)
\end{cases}
\tag{3}
```

を得る．
これらは，部分格子の磁化が，その磁化自身と相手側の部分格子の磁化によって定まるという自己無撞着方程式である．

### 2．臨界温度近傍での展開

Néel 温度 $T_N$ は，反強磁性的な自発磁化が消失する温度である．
したがって，臨界温度近傍では磁化が小さくなり，式 (3) の Brillouin 関数を引数 $x=0$ の近傍で展開できる．

Brillouin 関数の一次の項は

```math
B_S(x)=\frac{S+1}{3S}x+O(x^3)
```

である．
一次の項だけを式 (3) に代入すると，

```math
M_a=-\frac{n g^2\mu_B^2 S(S+1)}{6kT}
(q_2M_a+q_1M_b)+O(M^3),
```

```math
M_b=-\frac{n g^2\mu_B^2 S(S+1)}{6kT}
(q_1M_a+q_2M_b)+O(M^3)
\tag{4}
```

となる．
ここで $O(M^3)$ は，磁化の三次以上の項を表す．

定数

```math
\boxed{
C=\frac{n g^2\mu_B^2 S(S+1)}{3k}
}
\tag{5}
```

を定義すれば，式 (4) は

```math
\begin{cases}
M_a=-\dfrac{C}{2T}(q_2M_a+q_1M_b)+O(M^3),\\[2mm]
M_b=-\dfrac{C}{2T}(q_1M_a+q_2M_b)+O(M^3)
\end{cases}
\tag{6}
```

と書ける．
この $C$ は，部分格子全体ではなく，系全体の格子点数密度 $n$ を用いて定義した定数である．

解答例と同様に，磁化の三次項まで残すと，

```math
\begin{cases}
M_a=-\dfrac{C}{2T}(q_2M_a+q_1M_b)
+\gamma(T)(q_2M_a+q_1M_b)^3+\cdots,\\[2mm]
M_b=-\dfrac{C}{2T}(q_1M_a+q_2M_b)
+\gamma(T)(q_1M_a+q_2M_b)^3+\cdots
\end{cases}
\tag{7}
```

となる．
ここで， $\gamma(T)>0$ は三次項の係数である．
三次項の係数には，Brillouin 関数の引数に含まれる $1/T$ の三乗が含まれるため，厳密には温度に依存する．

### 3．反強磁性状態の条件

反強磁性的な秩序を考えるため，

```math
M_a=-M_b=M'
\tag{8}
```

とおく．
これは，部分格子 $a$ と $b$ の磁化が大きさの等しい反対向きの成分を持つことを意味する．

このとき，

```math
q_2M_a+q_1M_b
=(q_2-q_1)M'
=-(q_1-q_2)M'
```

である．
この関係を式 (7) の第1式に代入すれば，

```math
M'=\frac{C}{2T}(q_1-q_2)M'
-\gamma(T)(q_1-q_2)^3M'^3+\cdots
```

となる．
したがって，

```math
\boxed{
M'\left\{1-\frac{C}{2T}(q_1-q_2)\right\}
=-\gamma(T)(q_1-q_2)^3M'^3+\cdots
}
\tag{9}
```

を得る．

ここで，

```math
\Delta q=q_1-q_2
```

とおく．
反強磁性的な秩序が生じるためには，異なる部分格子間の反平行配列を促す相互作用が，同じ部分格子内の相互作用に対して十分強くなければならない．
この分子場モデルでは，その条件を

```math
\Delta q=q_1-q_2>0
\tag{10}
```

と表せる．

$M'\neq0$ の解を考え，式 (9) を $M'$ で割ると，

```math
1-\frac{C\Delta q}{2T}
=-\gamma(T)(\Delta q)^3M'^2+\cdots
\tag{11}
```

となる．
右辺の主要な項は， $\gamma(T)>0$ かつ $\Delta q>0$ のもとで負またはゼロである．
したがって，臨界温度近傍において非零の磁化が現れるには，

```math
1-\frac{C\Delta q}{2T}<0
```

すなわち，

```math
T<\frac{C\Delta q}{2}
\tag{12}
```

であることが必要となる．
実際，三次までの近似では，

```math
M'^2\simeq
\frac{\dfrac{C\Delta q}{2T}-1}
{\gamma(T)(\Delta q)^3}
\tag{13}
```

となり， $T<C\Delta q/2$ で $M'^2>0$ の小さな非零解が現れる．
一方，この近似では $T>C\Delta q/2$ において反強磁性的な非零解は生じない．

### 4．Néel 温度

反強磁性の自発磁化が消失する境界では，式 (11) の磁化の一次項の係数がゼロになる．
したがって，

```math
1-\frac{C}{2T_N}(q_1-q_2)=0
```

である．
よって，Néel 温度は

```math
\boxed{
T_N=\frac{C}{2}(q_1-q_2)
}
\tag{14}
```

と定まる．
式 (5) の $C$ を代入すれば，

```math
\boxed{
T_N=
\frac{n g^2\mu_B^2 S(S+1)}{6k}(q_1-q_2)
}
\tag{15}
```

となる．
ただし，この反強磁性モードが不安定化するには $q_1>q_2$ が必要であり，それが満たされない場合，この近似のもとで上記の反強磁性的秩序は生じない．

以上より，分子場近似では，部分格子間と同一部分格子内の相互作用の差 $q_1-q_2$ が，Néel 温度を決定することが示された．
