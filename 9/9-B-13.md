# 演習問題【9-B-13】

## 解答

### 1．分子場近似による自己無撞着方程式

反強磁性体を，二つの部分格子 $a$ ， $b$ からなる系として考える．
外部磁場を $\boldsymbol H$ ，各部分格子の有効磁場を $\boldsymbol H_a'$ ， $\boldsymbol H_b'$ とする．

問題 [3] の分子場近似に従うと，

```math
\begin{cases}
\boldsymbol H_a'
=\boldsymbol H-q_2\boldsymbol M_a-q_1\boldsymbol M_b,\\
\boldsymbol H_b'
=\boldsymbol H-q_2\boldsymbol M_b-q_1\boldsymbol M_a
\end{cases}
\tag{1}
```

である．

ここで， $q_1$ は異なる部分格子間の相互作用を表す定数， $q_2$ は同じ部分格子内の相互作用を表す定数である．

各部分格子には全格子点の半数が属するため，その磁化はBrillouin関数 $B_S(x)$ を用いて，

```math
M_a=
\frac n2g\mu_BS
B_S\left(\frac{g\mu_BSH_a'}{kT}\right)
```

```math
M_b=
\frac n2g\mu_BS
B_S\left(\frac{g\mu_BSH_b'}{kT}\right)
\tag{2}
```

と表される．
ここで， $n$ は単位体積あたりの全格子点数， $g$ はLandéの $g$ 因子， $\mu_B$ はBohr磁子， $S$ はスピン量子数， $k$ はBoltzmann定数， $T$ は絶対温度である．

自発磁化を求めるため，外部磁場をゼロとする．
すなわち，

```math
\boldsymbol H=\boldsymbol 0
```

とする．

反強磁性状態の磁化を扱うため，共通の軸に沿った符号付き磁化成分を $M_a,M_b$ とする．
式 (1)，(2) より，

```math
\begin{cases}
M_a=-\dfrac n2g\mu_BS
B_S\left(
\dfrac{g\mu_BS}{kT}(q_2M_a+q_1M_b)
\right),\\
M_b=-\dfrac n2g\mu_BS
B_S\left(
\dfrac{g\mu_BS}{kT}(q_1M_a+q_2M_b)
\right)
\end{cases}
\tag{3}
```

を得る．

これらが部分格子の磁化に関する自己無撞着方程式である．

### 2．臨界温度近傍での展開

Néel温度の近傍では自発磁化が小さくなるため，Brillouin関数を原点近傍で展開できる．

```math
B_S(x)
=
\frac{S+1}{3S}x
-
\frac{(S+1)(2S^2+2S+1)}{90S^3}x^3
+O(x^5)
```

である．

まず一次の項だけを残すと，

```math
M_a=
-\frac{ng^2\mu_B^2S(S+1)}{6kT}
(q_2M_a+q_1M_b)+O(M^3)
```

```math
M_b=
-\frac{ng^2\mu_B^2S(S+1)}{6kT}
(q_1M_a+q_2M_b)+O(M^3)
\tag{4}
```

となる．

ここで，

```math
\boxed{
C=\frac{ng^2\mu_B^2S(S+1)}{3k}
}
\tag{5}
```

と定義すれば，

```math
\begin{cases}
M_a=-\dfrac{C}{2T}(q_2M_a+q_1M_b)+O(M^3),\\
M_b=-\dfrac{C}{2T}(q_1M_a+q_2M_b)+O(M^3)
\end{cases}
\tag{6}
```

となる．

三次項まで残すと，

```math
\begin{cases}
M_a=-\dfrac{C}{2T}(q_2M_a+q_1M_b)
+\gamma(T)(q_2M_a+q_1M_b)^3+O(M^5),\\
M_b=-\dfrac{C}{2T}(q_1M_a+q_2M_b)
+\gamma(T)(q_1M_a+q_2M_b)^3+O(M^5)
\end{cases}
\tag{7}
```

である．
ここで，

```math
\boxed{
\gamma(T)=
\frac n2g\mu_BS
\frac{(S+1)(2S^2+2S+1)}{90S^3}
\left(\frac{g\mu_BS}{kT}\right)^3>0
}
```

である．
この係数は $T^{-3}$ に比例するため，温度に依存する．

### 3．反強磁性モードと強磁性モードの臨界条件

ここでは反強磁性モードだけに限定せず，式 (6) の連立方程式から二つの独立な磁化モードを調べる．

臨界温度近傍では磁化が微小であるため，三次以上の項を無視できる．
式 (6) を変形すると，

```math
\begin{pmatrix}
1+\dfrac{Cq_2}{2T}&\dfrac{Cq_1}{2T}\\
\dfrac{Cq_1}{2T}&1+\dfrac{Cq_2}{2T}
\end{pmatrix}
\begin{pmatrix}
M_a\\M_b
\end{pmatrix}
=
\begin{pmatrix}
0\\0
\end{pmatrix}
\tag{8}
```

となる．

非零の磁化が存在するためには，係数行列の行列式がゼロでなければならない．
したがって，

```math
\left(1+\frac{Cq_2}{2T}\right)^2
-
\left(\frac{Cq_1}{2T}\right)^2=0
```

である．
因数分解すると，

```math
\boxed{
\left[1+\frac{C(q_1+q_2)}{2T}\right]
\left[1-\frac{C(q_1-q_2)}{2T}\right]=0
}
\tag{9}
```

を得る．

この二つの因子は，それぞれ異なる磁化モードに対応する．

#### （a）強磁性モード

```math
M_a=M_b
```

とすると，式 (6) より，

```math
M_a=-\frac{C}{2T}(q_1+q_2)M_a
```

である．
非零解の条件は，

```math
1+\frac{C(q_1+q_2)}{2T}=0
```

となる．
したがって，強磁性モードの臨界温度は，

```math
\boxed{
T_{\mathrm F}=-\frac C2(q_1+q_2)
}
\tag{10}
```

である．
ただし，正の臨界温度が存在するのは $q_1+q_2<0$ の場合である．

#### （b）反強磁性モード

```math
M_a=-M_b=M'
```

とすると，

```math
q_2M_a+q_1M_b
=-(q_1-q_2)M'
```

である．
したがって，式 (6) より，

```math
M'=\frac{C}{2T}(q_1-q_2)M'
```

となる．
非零解の条件は，

```math
1-\frac{C(q_1-q_2)}{2T}=0
```

である．
したがって，反強磁性モードの臨界温度は，

```math
\boxed{
T_{\mathrm{AF}}=\frac C2(q_1-q_2)
}
\tag{11}
```

である．
このモードに正の臨界温度が存在する条件は，

```math
\boxed{q_1>q_2}
\tag{12}
```

である．

### 4．反強磁性モードが最初に不安定化する条件

高温の常磁性状態から冷却するとき，正の臨界温度を持つモードのうち，温度の高い方が先に不安定化する．

したがって，反強磁性秩序が最初に現れるには，

```math
T_{\mathrm{AF}}>0
```

かつ，

```math
T_{\mathrm{AF}}>T_{\mathrm F}
```

であることが必要である．

式 (10)，(11) より，

```math
\begin{aligned}
T_{\mathrm{AF}}-T_{\mathrm F}
&=\frac C2(q_1-q_2)+\frac C2(q_1+q_2)\\
&=Cq_1
\end{aligned}
\tag{13}
```

となる．
したがって，反強磁性モードが強磁性モードより先に不安定化する条件は，

```math
q_1>0
```

である．
これと式 (12) を合わせると，

```math
\boxed{
q_1>0,\qquad q_1>q_2
}
\tag{14}
```

が，この分子場モデルで反強磁性秩序が最初に現れる条件となる．

実際，この条件では，

```math
T_{\mathrm{AF}}>T_{\mathrm F}
```

となる．
$T_{\mathrm F}\leq0$ の場合には，強磁性モードに正の臨界温度は存在せず，反強磁性モードが正の温度で先に不安定化する．

一方， $q_1=0$ では両モードの臨界温度が一致し， $q_1<0$ では正の臨界温度を持つ場合，強磁性モードが反強磁性モードより先に不安定化する．

したがって， $q_1>q_2$ だけでは反強磁性秩序が最初に現れることは保証されない．

### 5．三次項による反強磁性秩序の確認

反強磁性モードについて，

```math
M_a=-M_b=M'
```

を式 (7) に代入する．

```math
q_2M_a+q_1M_b
=-(q_1-q_2)M'
```

なので，

```math
M'=
\frac{C}{2T}(q_1-q_2)M'
-\gamma(T)(q_1-q_2)^3M'^3
+O(M'^5)
```

となる．
よって，

```math
M'\left[
1-\frac{C(q_1-q_2)}{2T}
\right]
=
-\gamma(T)(q_1-q_2)^3M'^3
+O(M'^5)
```

である．

非零解について三次近似を用いると，

```math
\boxed{
M'^2\simeq
\frac{
\dfrac{C(q_1-q_2)}{2T}-1
}{
\gamma(T)(q_1-q_2)^3
}
}
\tag{15}
```

を得る．

$q_1>q_2$ かつ $\gamma(T)>0$ の場合，この式は

```math
T<T_{\mathrm{AF}}
```

で正の $M'^2$ を与える．
したがって，反強磁性モードはその臨界温度以下で非零の自発磁化を持つ．
三次項の係数が正であるため，この近似では反強磁性秩序は連続的に現れる．

### 6．Néel温度

以上より，反強磁性モードが強磁性モードより先に不安定化する条件，

```math
q_1>0,\qquad q_1>q_2
```

のもとでは，系全体のNéel温度は反強磁性モードの臨界温度に一致する．

したがって，

```math
\boxed{
T_N=\frac C2(q_1-q_2)
}
\tag{16}
```

である．

式 (5) を代入すると，

```math
\boxed{
T_N=
\frac{ng^2\mu_B^2S(S+1)}{6k}(q_1-q_2)
}
\tag{17}
```

となる．

このように，Néel温度は異なる部分格子間の相互作用 $q_1$ と，同じ部分格子内の相互作用 $q_2$ の差によって決まる．
ただし，これは反強磁性モードが最初に不安定化するという条件を満たす場合の結果である．
