# 演習問題【9-A-8】

## 解答

### 1．Ising モデルの相互作用とスピンの確率分布

Ising モデルでは，各スピン変数 $\sigma$ は $+1$ または $-1$ の値を取る．
隣接する2つのスピン $\sigma$ ， $\sigma'$ の間の相互作用エネルギーを

```math
\boxed{
u(\sigma,\sigma')=-J\sigma\sigma'
}
\tag{1}
```

とする．
ここで， $J$ は相互作用定数であり，以下では強磁性体に対応する $J>0$ を考える．
このとき，隣接するスピンが同じ向きであるほど相互作用エネルギーは低くなる．

各スピンが状態 $\sigma$ にある確率を $f(\sigma)$ とし，スピンの平均値を

```math
X=\langle\sigma\rangle
=\sum_{\sigma=\pm1}\sigma f(\sigma)
\tag{2}
```

と定義する．
確率の規格化条件は

```math
f(1)+f(-1)=1
\tag{3}
```

である．
式 (2)，(3) より，

```math
X=f(1)-f(-1)
```

となるため，連立方程式を解くと，

```math
f(1)=\frac{1+X}{2},\qquad
f(-1)=\frac{1-X}{2}
```

を得る．
したがって，両方のスピン状態をまとめて表すと，

```math
\boxed{
f(\sigma)=\frac12(1+X\sigma)
}
\tag{4}
```

となる．
ここで， $X$ はスピンの平均値であり，磁化の向きと大きさを表す秩序変数である．

### 2．前問の変分方程式への適用

前問で導出した Bragg–Williams 近似の変分方程式は，

```math
f(\sigma)=C\exp\left[
-\frac{z}{kT}
\sum_{\sigma'=\pm1}
u(\sigma,\sigma')f(\sigma')
\right]
\tag{5}
```

である．
ここで， $z$ は1つのスピンに隣接するスピンの数， $k$ はボルツマン定数， $T$ は絶対温度， $C$ は確率の規格化定数である．

式 (1) を式 (5) に代入すると，

```math
f(\sigma)=C\exp\left[
\frac{zJ\sigma}{kT}
\sum_{\sigma'=\pm1}\sigma'f(\sigma')
\right]
\tag{6}
```

となる．
式 (2) の定義より，

```math
\sum_{\sigma'=\pm1}\sigma'f(\sigma')=X
```

であるから，式 (6) は

```math
\boxed{
f(\sigma)=C\exp\left(\frac{zJX\sigma}{kT}\right)
}
\tag{7}
```

と書ける．

さらに，式 (4) を使って同じ関係を表すと，

```math
\begin{aligned}
f(\sigma)
&=C\exp\left[
\frac{zJ}{2kT}
\sum_{\sigma'=\pm1}\sigma\sigma'(1+X\sigma')
\right]
\end{aligned}
\tag{8}
```

となる．
ここで， $\sigma'=\pm1$ であるから，

```math
\begin{aligned}
\sum_{\sigma'=\pm1}\sigma\sigma'(1+X\sigma')
&=\sigma\left[(1+X)-(1-X)\right]\\
&=2X\sigma
\end{aligned}
\tag{9}
```

である．
したがって，式 (8) は式 (7) と一致する．
指数部にある係数 $1/2$ は，式 (9) の和から生じる係数 $2$ と相殺されるのである．

### 3．自己無撞着方程式の導出

式 (7) において， $\sigma=+1$ ， $\sigma=-1$ の場合をそれぞれ考えると，

```math
f(1)=Ce^{zJX/(kT)}
\tag{10}
```

```math
f(-1)=Ce^{-zJX/(kT)}
\tag{11}
```

を得る．
確率の規格化条件 (3) より，

```math
1=C\left(
e^{zJX/(kT)}+e^{-zJX/(kT)}
\right)
\tag{12}
```

となる．
一方，スピンの平均値の定義 (2) より，

```math
X=C\left(
e^{zJX/(kT)}-e^{-zJX/(kT)}
\right)
\tag{13}
```

である．
式 (13) を式 (12) で割ると，

```math
X=
\frac{
e^{zJX/(kT)}-e^{-zJX/(kT)}
}{
e^{zJX/(kT)}+e^{-zJX/(kT)}
}
```

となる．
双曲線正接の定義

```math
\tanh y=\frac{e^y-e^{-y}}{e^y+e^{-y}}
```

を用いれば，求める方程式は

```math
\boxed{
X=\tanh\left(\frac{zJX}{kT}\right)
}
\tag{14}
```

となる．
これが Bragg–Williams 近似による Ising モデルの自己無撞着方程式である．

### 4．臨界温度との関係

得られた方程式から，磁化が温度によってどのように変わるかを確認する．
式 (14) は $X=0$ を常に解として持つ．強磁性相互作用 $J>0$ に対して，この自明でない解が現れる条件を調べるため， $X$ が小さい場合の展開

```math
\tanh y=y-\frac{y^3}{3}+O(y^5)
```

を用いる．
すると，

```math
X=\frac{zJ}{kT}X
-\frac13\left(\frac{zJ}{kT}\right)^3X^3
+O(X^5)
\tag{15}
```

となる．
非零の $X$ が現れ始める温度では，一次の係数が1となる．
したがって，臨界温度 $T_c$ は

```math
\boxed{
T_c=\frac{zJ}{k}
}
\tag{16}
```

である．

$T>T_c$ では自発磁化の非零解は存在せず，平衡状態は $X=0$ である．
一方， $T<T_c$ では $X=0$ 以外の解が現れ，スピンが自発的に同じ向きにそろう強磁性状態となる．

さらに， $T$ が $T_c$ に近く， $X$ が十分小さい場合には，式 (15) から

```math
X^2\approx
3\frac{\dfrac{T_c}{T}-1}
{\left(\dfrac{T_c}{T}\right)^3}
```

が得られる．
転移温度の直下では，

```math
\boxed{
X\approx
\sqrt{3\frac{T_c-T}{T_c}}
}
\tag{17}
```

となる．
したがって，分子場近似では，自発磁化は臨界温度の直下で $(T_c-T)^{1/2}$ に比例して現れるのである．

以上より，前問の変分方程式を Ising モデルに適用することで，自己無撞着方程式

```math
\boxed{
X=\tanh\left(\frac{zJX}{kT}\right)
}
```

が導出された．
