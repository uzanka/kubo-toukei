# 演習問題【9-A-8】

## 解答

Ising モデルにおいて，スピン変数 $\sigma$ は $\pm 1$ の値をとる．
あるスピン $\sigma$ とその近傍のスピン $\sigma'$ との間の相互作用エネルギーは，次のように与えられる：

$$u(\sigma, \sigma') = -J \sigma \sigma' \quad (1)$$

ここで， $J$ は相互作用定数である．

まず， $\sigma$ の任意の関数 $f(\sigma)$ がどのように記述できるかを考える．
$\sigma$ がとりうる値は $1$ と $-1$ のみの二通りであるため，関数 $f(\sigma)$ は $f(1)$ と $f(-1)$ という二つの値によって完全に決定される．
このとき， $f(\sigma)$ は $\sigma$ に関する一次式として次のように書くことができる：

$$f(\sigma) = a + b\sigma \quad (2)$$

ここで， $a$ と $b$ を $f(1)$ と $f(-1)$ を用いて表すと，

$$f(1) = a + b, \quad f(-1) = a - b$$

より，

$$a = \frac{f(1) + f(-1)}{2}, \quad b = \frac{f(1) - f(-1)}{2}$$

となる．
したがって，

$$f(\sigma) = \frac{1}{2}\{f(1) + f(-1)\} + \sigma \frac{1}{2}\{f(1) - f(-1)\}$$

と書き下せる．

次に，スピン $\sigma$ がとる確率を $f(\sigma)$ ，その期待値（平均値）を $X = \langle \sigma \rangle$ とする．
期待値の定義より， $X = \sum_{\sigma} \sigma f(\sigma)$ である．
また，確率の性質から $\sum_{\sigma} f(\sigma) = 1$ が成り立つ．
これらを用いると， $f(\sigma)$ は $X$ を用いて次のように表される：

$$f(\sigma) = \frac{1}{2}(1 + X\sigma) \quad (3)$$

（確認： $\sum_{\sigma} f(\sigma) = \frac{1}{2}(1+X) + \frac{1}{2}(1-X) = 1$ であり， $\sum_{\sigma} \sigma f(\sigma) = \frac{1}{2}(1+X) - \frac{1}{2}(1-X) = X$ となる．）

前問の手法を Ising モデルに適用する．
スピン $\sigma$ が受ける有効な相互作用エネルギーは，近傍のスピン $\sigma'$ との相互作用の総和として次のように表される：

$$\text{Effective Energy} = \sum_{\sigma'} u(\sigma, \sigma') f(\sigma') = -J \sigma \sum_{\sigma'} \sigma' f(\sigma')$$

ここで， $\sum_{\sigma'} \sigma' f(\sigma')$ は近傍のスピンの期待値であるから，これは $X$ に等しい．
したがって，スピン $\sigma$ が受けるエネルギーの寄与は $-J \sigma X$ となり，近傍の数 $z$ を考慮すると，スピン $\sigma$ がとる確率はボルツマン因子を用いて次のように比例する：

$$f(\sigma) \propto \exp\left[ \frac{zJ}{2kT} \sum_{\sigma'} \sigma\sigma'(1 + X\sigma') \right] \quad (4)$$

（ここで，係数の $2$ は正規化定数 $C$ に含まれる．）

式 (4) の指数部分の和 $\sum_{\sigma'} \sigma\sigma'(1 + X\sigma')$ を計算する．

$$\begin{aligned} \sum_{\sigma'} \sigma\sigma'(1 + X\sigma') &= \sigma \sum_{\sigma'} (\sigma' + X(\sigma')^2) \\ &= \sigma \left( \sum_{\sigma'} \sigma' + X \sum_{\sigma'} (\sigma')^2 \right) \end{aligned}$$

ここで， $\sigma'$ は $\pm 1$ の値をとるため，

$$\sum_{\sigma'} \sigma' = 1 + (-1) = 0$$

$$\sum_{\sigma'} (\sigma')^2 = 1^2 + (-1)^2 = 2$$

となる．
これらを代入すると，

$$\sigma (0 + X \cdot 2) = 2X\sigma$$

となる．
これを式 (4) に戻すと，

$$\begin{aligned} \frac{1}{2}(1 + X\sigma) &= C \exp\left[ \frac{zJ}{2kT} (2X\sigma) \right] \\ &= C \exp\left( \frac{zJ\sigma X}{kT} \right) \quad (5) \end{aligned}$$

となる．

最後に，この式 (5) を $\sigma = 1$ と $\sigma = -1$ の場合について書き下し， $X$ について解く．
$\sigma = 1$ のとき：

$$\frac{1}{2}(1 + X) = C e^{zJX/kT} \quad (6)$$

$\sigma = -1$ のとき：

$$\frac{1}{2}(1 - X) = C e^{-zJX/kT} \quad (7)$$

(6) 式を (7) 式で割ると，

$$\frac{1 + X}{1 - X} = \frac{e^{zJX/kT}}{e^{-zJX/kT}} = e^{2zJX/kT}$$

両辺の自然対数をとると，

$$\ln\left(\frac{1 + X}{1 - X}\right) = \frac{2zJX}{kT}$$

ここで，左辺は $\text{artanh}(X)$ の $2$ 倍である（ $\text{artanh}(x) = \frac{1}{2}\ln\frac{1+x}{1-x}$ ）ため，

$$2 \text{artanh}(X) = \frac{2zJX}{kT} \implies \text{artanh}(X) = \frac{zJX}{kT}$$

したがって，

$$X = \tanh\left( \frac{zJX}{kT} \right)$$

が得られる．
これは Ising モデルの自己整合方程式である．

## 解説

この結果は，Ising モデルにおけるスピンの平均値 $X$ が，温度 $T$ や相互作用の強さ $J$ に依存してどのように決まるかを示している．

### 1. 温度の影響

分母に $T$ があるため，温度 $T$ が非常に高い場合（ $T \to \infty$ ），引数 $\frac{zJX}{kT}$ は $0$ に近づく．
このとき $\tanh(0) = 0$ であるため， $X = 0$ となる．
これは，熱運動によってスピンの向きがバラバラになり，全体として磁化が消失することを意味している．

### 2. 相互作用の影響

相互作用 $J$ が大きい場合，あるいは温度 $T$ が低い場合，引数 $\frac{zJX}{kT}$ が大きくなる．
$\tanh(x)$ は $x$ が大きくなると $1$ に近づくため， $X$ は $1$ （あるいは対称性を考慮して $-1$ ）に近い値をとるようになる．
これは，スピンが互いに揃おうとする力が強まり，自発的な磁化が生じることを示している．

### 3. 相転移

この方程式 $X = \tanh(\text{constant} \cdot X)$ は， $X=0$ という解を常に持つが，温度が低くなると $X=0$ 以外の解（正または負の $X$ ）が現れる．
この現象は，統計力学における「相転移」を表している．
