# 演習問題【9-C-22】

## 解答

### 1．相関関数の密度展開と逐次計算

粒子間の相互作用ポテンシャルを $\phi(r_{ij})$ ，粒子 $s$ 個の全相互作用ポテンシャルを

```math
U_s=\sum_{1\le i<j\le s}\phi(r_{ij}),
\qquad r_{ij}=|\mathbf r_i-\mathbf r_j|
```

とする．
また，逆温度を

```math
\beta=\frac{1}{kT}
```

とする．
問題文では， $v^{-1}=N/V$ が粒子数密度であり， $v$ は1粒子あたりの体積である．

$s$ 体分布関数は

```math
F_s(\mathbf r_1,\ldots,\mathbf r_s)
=v^{-s}g_s(\mathbf r_1,\ldots,\mathbf r_s)
\tag{1}
```

と定義され，すべての粒子間距離が十分大きくなる極限では $g_s\to1$ となる．
そこで， $g_s$ を密度のべき級数として

```math
g_s=g_s^{(0)}+v^{-1}g_s^{(1)}
+v^{-2}g_s^{(2)}+\cdots
\tag{2}
```

と展開する．

#### 1.1．階層方程式から各項を求める

例題 [4] で導かれた階層方程式は，密度 $v^{-1}$ を明示すると，

```math
\begin{aligned}
&\nabla_i g_s
+\beta(\nabla_i U_s)g_s\\
&\quad+\frac{\beta}{v}
\int \nabla_i\phi(r_{i,s+1})
g_{s+1}(\mathbf r_1,\ldots,\mathbf r_{s+1})
\,d\mathbf r_{s+1}=0
\end{aligned}
\tag{3}
```

と書ける．
ここで $\nabla_i$ は $\mathbf r_i$ に関する勾配である．
式 (3) の積分項には $v^{-1}$ が掛かっているため，式 (2) を代入して密度の各次数を比較できる．

まず， $v^0$ の項を比較すると，

```math
\nabla_i g_s^{(0)}
+\beta(\nabla_i U_s)g_s^{(0)}=0
\tag{4}
```

となる．
これは，

```math
\nabla_i\left(e^{\beta U_s}g_s^{(0)}\right)=0
```

と書き換えられる．
したがって，すべての粒子座標について

```math
g_s^{(0)}=C_s^{(0)}e^{-\beta U_s}
\tag{5}
```

である．
ここで，式 (4) がすべての $i$ について成り立つことから， $C_s^{(0)}$ は粒子座標に依存しない定数である．

すべての粒子間距離が無限大に近づくと， $U_s\to0$ かつ $g_s^{(0)}\to1$ である．
よって $C_s^{(0)}=1$ となり，

```math
\boxed{g_s^{(0)}=e^{-\beta U_s}}
\tag{6}
```

を得る．
これは，密度が十分低い場合の相関関数の主要項である．

次に， $v^{-1}$ の項を比較すると，

```math
\begin{aligned}
&\nabla_i g_s^{(1)}
+\beta(\nabla_i U_s)g_s^{(1)}\\
&\quad+
\beta\int\nabla_i\phi(r_{i,s+1})
g_{s+1}^{(0)}\,d\mathbf r_{s+1}=0
\end{aligned}
\tag{7}
```

となる．
ここでは，右辺の積分に $g_{s+1}^{(0)}$ しか含まれないことが重要である．
式 (6) によって $g_{s+1}^{(0)}$ が既知であれば，式 (7) は $g_s^{(1)}$ に関する方程式として解ける．

同様に， $v^{-m}$ の項を比較すると， $m\ge1$ に対して，

```math
\begin{aligned}
&\nabla_i g_s^{(m)}
+\beta(\nabla_i U_s)g_s^{(m)}\\
&\quad=-\beta\int\nabla_i\phi(r_{i,s+1})
g_{s+1}^{(m-1)}\,d\mathbf r_{s+1}
\end{aligned}
\tag{8}
```

を得る．
したがって，前の次数の相関関数が分かっていれば，次の次数の方程式を逐次解くことができる．
この意味で，階層方程式を用いて $g_s$ の各係数を原理的に順番に求められるのである．

### 2．第1補正項 $g_s^{(1)}$ の導出

Mayer 関数を

```math
f_{ij}=f(r_{ij})
=e^{-\beta\phi(r_{ij})}-1
\tag{9}
```

と定義する． $s+1$ 粒子の全ポテンシャルは

```math
U_{s+1}=U_s+\sum_{j=1}^{s}\phi(r_{j,s+1})
```

であるため，

```math
\begin{aligned}
g_{s+1}^{(0)}
&=e^{-\beta U_{s+1}}\\
&=e^{-\beta U_s}
\prod_{j=1}^{s}(1+f_{j,s+1})
\end{aligned}
\tag{10}
```

となる．
式 (10) を式 (7) に代入する．

恒等式

```math
\nabla_i e^{-\beta\phi(r_{i,s+1})}
=-\beta\nabla_i\phi(r_{i,s+1})
e^{-\beta\phi(r_{i,s+1})}
```

を用いると，

```math
\begin{aligned}
&\beta\int\nabla_i\phi(r_{i,s+1})
g_{s+1}^{(0)}\,d\mathbf r_{s+1}\\
&\quad=-e^{-\beta U_s}
\nabla_i\int
\prod_{j=1}^{s}(1+f_{j,s+1})
\,d\mathbf r_{s+1}
\end{aligned}
\tag{11}
```

である．
したがって，式 (7) は

```math
\begin{aligned}
&\nabla_i g_s^{(1)}
+\beta(\nabla_i U_s)g_s^{(1)}\\
&\quad=e^{-\beta U_s}
\nabla_i\int\prod_{j=1}^{s}(1+f_{j,s+1})
\,d\mathbf r_{s+1}
\end{aligned}
\tag{12}
```

となる．
ここで，

```math
g_s^{(1)}=C_s^{(1)}e^{-\beta U_s}
\tag{13}
```

とおくと，

```math
\nabla_i C_s^{(1)}
=\nabla_i\int
\prod_{j=1}^{s}(1+f_{j,s+1})
\,d\mathbf r_{s+1}
```

である．
したがって，

```math
C_s^{(1)}
=\int\prod_{j=1}^{s}(1+f_{j,s+1})
\,d\mathbf r_{s+1}+k_s
\tag{14}
```

となる．
$k_s$ は座標に依存しない積分定数であり，境界条件によって定める必要がある．

#### 2.1．積分定数と発散項の処理

式 (14) の積分を展開すると，定数項 $1$ の積分は容器体積 $V$ となる．
また，粒子 $i$ の近くに積分変数 $\mathbf r_{s+1}$ があるときには， $f_{i,s+1}$ を含む項が寄与する．
すべての粒子間距離を十分大きくした極限では，これらの領域が互いに重ならなくなるため，

```math
\int\prod_{j=1}^{s}(1+f_{j,s+1})
\,d\mathbf r_{s+1}
\longrightarrow
V+\sum_{j=1}^{s}\int f_{j,s+1}\,d\mathbf r_{s+1}
\tag{15}
```

となる．

一方，規格化条件 $g_s\to1$ は，式 (2) の各密度次数について，

```math
g_s^{(0)}\to1,\qquad
g_s^{(1)}\to0,\qquad \ldots
```

を要求する．
したがって，式 (13)，(14) において $C_s^{(1)}\to0$ となるように積分定数を選ぶ．
式 (15) より，

```math
k_s=-V-\sum_{j=1}^{s}
\int f_{j,s+1}\,d\mathbf r_{s+1}
```

である．
これを式 (14) に代入すれば，

```math
\begin{aligned}
C_s^{(1)}
=\int\bigg[
&\prod_{j=1}^{s}(1+f_{j,s+1})\\
&-1-\sum_{j=1}^{s}f_{j,s+1}
\bigg]\,d\mathbf r_{s+1}
\end{aligned}
```

となる．
よって，

```math
\boxed{
\begin{aligned}
g_s^{(1)}
=e^{-\beta U_s}\int\bigg[
&\prod_{j=1}^{s}(1+f_{j,s+1})\\
&-1-\sum_{j=1}^{s}f_{j,s+1}
\bigg]\,d\mathbf r_{s+1}
\end{aligned}
}
\tag{16}
```

を得る．
この式では，発散する体積項と単独の Mayer 関数の項が取り除かれ，残るのは2つ以上の粒子に結びつく項である．

特に $s=2$ とすれば，

```math
(1+f_{13})(1+f_{23})-1-f_{13}-f_{23}
=f_{13}f_{23}
```

であるため，

```math
\boxed{
g_2(\mathbf r_1,\mathbf r_2)
=e^{-\beta\phi(r_{12})}
\left[
1+\frac1v\int
f(r_{13})f(r_{23})\,d\mathbf r_3
+O(v^{-2})
\right]
}
\tag{17}
```

を得る．
これが圧力公式に代入する2体相関関数の低密度展開である．

### 3．圧力公式への代入

問題 [12] で導いた圧力公式は，

```math
\frac{p}{kT}
=\frac1v\left[
1-\frac{\beta}{6v}
\int r_{12}\frac{d\phi(r_{12})}{dr_{12}}
g_2(r_{12})\,d\mathbf r_{12}
\right]
\tag{18}
```

である．
式 (17) を代入すると，

```math
\begin{aligned}
\frac{p}{kT}
=\frac1v\bigg[
1&-\frac{\beta}{6v}
\int r_{12}\phi'(r_{12})
e^{-\beta\phi(r_{12})}\,d\mathbf r_{12}\\
&-\frac{\beta}{6v^2}
\iint r_{12}\phi'(r_{12})
e^{-\beta\phi(r_{12})}
f(r_{13})f(r_{23})\,
d\mathbf r_{12}d\mathbf r_3
+\cdots
\bigg]
\end{aligned}
\tag{19}
```

となる．
ここで $\phi'(r)=d\phi(r)/dr$ とした．

ビリアル展開を，解答例と同じ規約で

```math
\boxed{
\frac{p}{kT}
=\frac1v\left[
1-\frac{\beta_1}{2v}
-\frac{2\beta_2}{3v^2}
+\cdots
\right]
}
\tag{20}
```

と書く．
式 (19) と式 (20) の同じ次数の係数を比較すると，

```math
\boxed{
\beta_1=\frac{\beta}{3}
\int r_{12}\phi'(r_{12})
e^{-\beta\phi(r_{12})}\,d\mathbf r_{12}
}
\tag{21}
```

および

```math
\boxed{
\begin{aligned}
\beta_2=\frac{\beta}{4}
\iint&r_{12}\phi'(r_{12})
e^{-\beta\phi(r_{12})}\\
&\times f(r_{13})f(r_{23})\,
d\mathbf r_{12}d\mathbf r_3
\end{aligned}
}
\tag{22}
```

を得る．
これらを Mayer 関数を用いた表式に変形する．

### 4．第2ビリアル係数 $\beta_1$

式 (9) の Mayer 関数を用いると，

```math
\frac{df(r)}{dr}
=-\beta\phi'(r)e^{-\beta\phi(r)}
\tag{23}
```

である．
したがって，式 (21) は

```math
\beta_1=-\frac13
\int r\frac{df(r)}{dr}\,d\mathbf r
\tag{24}
```

となる．

ここで， $\mathbf r$ は相対位置ベクトルであり， $r=|\mathbf r|$ である．
相互作用が十分遠方で速やかに消失し，境界項が消えるとする．
発散定理から，

```math
\int\nabla\cdot[\mathbf r f(r)]\,d\mathbf r=0
```

である．
一方，

```math
\nabla\cdot[\mathbf r f(r)]
=3f(r)+\mathbf r\cdot\nabla f(r)
=3f(r)+r\frac{df(r)}{dr}
```

であるため，

```math
\int r\frac{df(r)}{dr}\,d\mathbf r
=-3\int f(r)\,d\mathbf r
\tag{25}
```

となる．
これを式 (24) に代入すれば，

```math
\boxed{
\beta_1=\int f(r_{12})\,d\mathbf r_{12}
}
\tag{26}
```

を得る．
したがって，第2ビリアル係数は Mayer 関数の全空間積分で与えられる．

### 5．第3ビリアル係数 $\beta_2$

式 (22)，(23) より，

```math
\beta_2
=-\frac14
\iint r_{12}\frac{df(r_{12})}{dr_{12}}
f(r_{13})f(r_{23})\,
d\mathbf r_2d\mathbf r_3
\tag{27}
```

となる．
ここで，粒子1の位置を原点に固定し，

```math
T_3=\iint
f(r_{12})f(r_{13})f(r_{23})\,
d\mathbf r_2d\mathbf r_3
\tag{28}
```

と定義する．
これは3粒子が互いに Mayer 関数で結びついた積分である．

式 (27) の積分を簡潔に評価するため，次のベクトル恒等式を使う．

```math
\nabla_2\cdot(\mathbf r_2 P)
+\nabla_3\cdot(\mathbf r_3 P)
=6P+
(\mathbf r_2\cdot\nabla_2+
\mathbf r_3\cdot\nabla_3)P
\tag{29}
```

ただし，

```math
P=f(r_{12})f(r_{13})f(r_{23})
```

である．
全空間で積分し，十分な遠方で境界項が消えるとすると，左辺の積分はゼロとなる．
したがって，

```math
0=6T_3+
\iint
(\mathbf r_2\cdot\nabla_2+
\mathbf r_3\cdot\nabla_3)P\,
d\mathbf r_2d\mathbf r_3
\tag{30}
```

である．

積 $P$ の微分を各因子について実行すると，

```math
\begin{aligned}
&(\mathbf r_2\cdot\nabla_2+
\mathbf r_3\cdot\nabla_3)P\\
={}&
r_{12}f'(r_{12})f_{13}f_{23}\\
&+f_{12}r_{13}f'(r_{13})f_{23}\\
&+f_{12}f_{13}r_{23}f'(r_{23})
\end{aligned}
\tag{31}
```

を得る．
3つの粒子のラベルを入れ替えても積分の値は変わらないので，式 (31) の各項の積分は等しい．
そこで，

```math
I=\iint r_{12}f'(r_{12})f_{13}f_{23}\,
d\mathbf r_2d\mathbf r_3
```

とおけば，式 (30) は

```math
0=6T_3+3I
```

となり，

```math
I=-2T_3
\tag{32}
```

が得られる．
式 (27)，(32) より，

```math
\beta_2=-\frac14 I
=\frac12T_3
```

である．
したがって，第3ビリアル係数は

```math
\boxed{
\beta_2=
\frac12\iint
f(r_{12})f(r_{13})f(r_{23})\,
d\mathbf r_2d\mathbf r_3
}
\tag{33}
```

と表される．

### 6．結論

以上より，問題で指定された規約

```math
\frac{p}{kT}
=\frac1v\left[
1-\frac{\beta_1}{2v}
-\frac{2\beta_2}{3v^2}+\cdots
\right]
```

における第2，第3ビリアル係数は，

```math
\boxed{
\beta_1=\int f(r_{12})\,d\mathbf r_{12}
}
```

および

```math
\boxed{
\beta_2=
\frac12\iint
f(r_{12})f(r_{13})f(r_{23})\,
d\mathbf r_2d\mathbf r_3
}
```

となる．
ここで，

```math
f(r)=e^{-\beta\phi(r)}-1,
\qquad
\beta=\frac1{kT}
```

である．

なお，標準的なビリアル展開を

```math
\frac{p}{kT}=\rho+B_2\rho^2+B_3\rho^3+\cdots,
\qquad \rho=v^{-1}
```

と書く場合には，係数の対応は

```math
\boxed{
B_2=-\frac12\int f(r_{12})\,d\mathbf r_{12}
}
```

および

```math
\boxed{
B_3=-\frac13\iint
f(r_{12})f(r_{13})f(r_{23})\,
d\mathbf r_2d\mathbf r_3
}
```

である．
以上により，階層方程式から相関関数を密度の逆数について逐次計算できること，およびその結果から第2，第3ビリアル係数を導けることが示された．
