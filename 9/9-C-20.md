# 演習問題【9-C-20】

## 解答

問題で与えられた $z+1$ 個のスピンのエネルギー（ハミルトニアン）は以下の通りである．

$$\mathcal{H}_{z+1} = -\mu_0 H \sigma_0 - \mu_0(H + H') \sum_{j=1}^z \sigma_j - J \sum_{j=1}^z \sigma_0 \sigma_j$$

ここで， $\sigma_0$ は注目している一つのスピンであり， $\sigma_1, \dots, \sigma_z$ はその周囲にある $z$ 個のスピンである．

まず，分配関数 $Z$ を求める．
分配関数は，すべてのスピンの状態についてのエネルギーの指数関数の和として定義される．

$$Z(H, H', T) = \sum_{\sigma_0 = \pm 1} \sum_{\sigma_1 = \pm 1} \dots \sum_{\sigma_z = \pm 1} \exp \left[ -\frac{\mathcal{H}_{z+1}}{kT} \right]$$

ここで， $k$ はボルツマン定数， $T$ は絶対温度である．
計算を簡略化するために，以下の変数をおく．

$$\alpha = \frac{\mu_0 H}{kT}, \quad \alpha' = \frac{\mu_0 H'}{kT}, \quad \beta = \frac{J}{kT}$$

これを用いると，ハミルトニアンの指数部分は次のように書ける．

$$\frac{-\mathcal{H}_{z+1}}{kT} = \alpha \sigma_0 + (\alpha + \alpha') \sum_{j=1}^z \sigma_j + \beta \sum_{j=1}^z \sigma_0 \sigma_j$$

したがって，分配関数は

$$Z = \sum_{\sigma_0 = \pm 1} \exp(\alpha \sigma_0) \sum_{\sigma_1, \dots, \sigma_z} \exp \left[ (\alpha + \alpha' + \beta \sigma_0) \sum_{j=1}^z \sigma_j \right]$$

となる．
$\sigma_0$ の和を $\sigma_0 = +1$ と $\sigma_0 = -1$ の場合に分けて考える．
$\sigma_0 = +1$ のとき，内側の和は

$$\sum_{\sigma_1, \dots, \sigma_z} \exp [(\alpha + \alpha' + \beta) \sum_{j=1}^z \sigma_j] = \left( \sum_{\sigma_j = \pm 1} e^{(\alpha + \alpha' + \beta)\sigma_j} \right)^z = [2 \cosh(\alpha + \alpha' + \beta)]^z$$

となる．
同様に $\sigma_0 = -1$ のときは，

$$\sum_{\sigma_1, \dots, \sigma_z} \exp [(\alpha + \alpha' - \beta) \sum_{j=1}^z \sigma_j] = [2 \cosh(\alpha + \alpha' - \beta)]^z$$

となる．
よって，全体の分配関数 $Z$ は

$$Z = e^\alpha [2 \cosh(\alpha + \alpha' + \beta)]^z + e^{-\alpha} [2 \cosh(\alpha + \alpha' - \beta)]^z \equiv Z_+ + Z_-$$

と書ける．

次に，スピンの平均値を求める．
スピン $\sigma_0$ の平均値 $\overline{\sigma_0}$ は，

$$\overline{\sigma_0} = \frac{\sum_{\sigma_0} \sigma_0 e^{-\beta \mathcal{H}}}{Z} = \frac{(+1) Z_+ + (-1) Z_-}{Z} = \frac{Z_+ - Z_-}{Z}$$

である．
また，周囲のスピン $\sigma_j$ の平均値 $\overline{\sigma_j}$ は， $\sigma_j$ に関する分配関数の微分を用いて求められる．

$$\overline{\sigma_j} = \frac{1}{z} \frac{\sum \sigma_j e^{-\beta \mathcal{H}}}{Z} = \frac{1}{z} \frac{1}{Z} \frac{\partial Z}{\partial \alpha'} = \frac{1}{zZ} \frac{\partial (Z_+ + Z_-)}{\partial \alpha'}$$

ここで， $Z_\pm$ の $\alpha'$ 依存性を計算すると，

$$\frac{\partial Z_+}{\partial \alpha'} = e^\alpha \cdot z [2 \cosh(\alpha + \alpha' + \beta)]^{z-1} \cdot 2 \sinh(\alpha + \alpha' + \beta)$$

となる．
これを用いると $\overline{\sigma_j}$ は

$$\overline{\sigma_j} = \frac{1}{zZ} \left[ e^\alpha \cdot z [2 \cosh(\alpha + \alpha' + \beta)]^{z-1} \cdot 2 \sinh(\alpha + \alpha' + \beta) + e^{-\alpha} \cdot z [2 \cosh(\alpha + \alpha' - \beta)]^{z-1} \cdot 2 \sinh(\alpha + \alpha' - \beta) \right]$$

整理すると，

$$\overline{\sigma_j} = \frac{Z_+ \tanh(\alpha + \alpha' + \beta) + Z_- \tanh(\alpha + \alpha' - \beta)}{Z}$$

となる．

Bethe の近似の条件は， $\overline{\sigma_0} = \overline{\sigma_j}$ である．

$$\frac{Z_+ - Z_-}{Z} = \frac{Z_+ \tanh(\alpha + \alpha' + \beta) + Z_- \tanh(\alpha + \alpha' - \beta)}{Z}$$

$$Z_+ (1 - \tanh(\alpha + \alpha' + \beta)) = Z_- (1 + \tanh(\alpha + \alpha' - \beta))$$

これに $Z_\pm$ の式を代入して整理する．

$$e^\alpha [2 \cosh(\alpha + \alpha' + \beta)]^z \{1 - \tanh(\alpha + \alpha' + \beta)\} = e^{-\alpha} [2 \cosh(\alpha + \alpha' - \beta)]^z \{1 + \tanh(\alpha + \alpha' - \beta)\}$$

ここで， $\frac{1-\tanh x}{1+\tanh x} = e^{-2x}$ であることを用いる．
左辺の括弧内は $\frac{1-\tanh A}{\cosh A} = \frac{2 e^{-A}}{2 \cosh A}$ ではなく，
$1 - \tanh A = \frac{2 e^{-A}}{e^A + e^{-A}} = \frac{2}{e^{2A} + 1}$ である．
これを用いると，

$$Z_+ (1 - \tanh A) = e^\alpha [2 \cosh A]^z \frac{2 e^{-A}}{2 \cosh A} = e^\alpha [2 \cosh A]^{z-1} \cdot 2 e^{-A}$$
$$Z_- (1 + \tanh B) = e^{-\alpha} [2 \cosh B]^z \frac{2 e^{B}}{2 \cosh B} = e^{-\alpha} [2 \cosh B]^{z-1} \cdot 2 e^{B}$$

これらを等置すると，

$$e^\alpha [2 \cosh(\alpha + \alpha' + \beta)]^{z-1} \cdot 2 e^{-(\alpha + \alpha' + \beta)} = e^{-\alpha} [2 \cosh(\alpha + \alpha' - \beta)]^{z-1} \cdot 2 e^{(\alpha + \alpha' - \beta)}$$

両辺の $2$ を消し，指数の項をまとめると，

$$e^\alpha \cdot e^{-\alpha - \alpha' - \beta} [\cosh(\alpha + \alpha' + \beta)]^{z-1} = e^{-\alpha} \cdot e^{\alpha + \alpha' - \beta} [\cosh(\alpha + \alpha' - \beta)]^{z-1}$$

$$e^{-\alpha' - \beta} [\cosh(\alpha + \alpha' + \beta)]^{z-1} = e^{\alpha' - \beta} [\cosh(\alpha + \alpha' - \beta)]^{z-1}$$

$$[\frac{\cosh(\alpha + \alpha' + \beta)}{\cosh(\alpha + \alpha' - \beta)}]^{z-1} = e^{2\alpha'}$$

が得られる．

Curie 温度 $T_c$ を求めるために，外部磁場がない場合 ( $H = 0 \implies \alpha = 0$ ) の方程式を考える．

$$\left[ \frac{\cosh(\alpha' + \beta)}{\cosh(\alpha' - \beta)} \right]^{z-1} = e^{2\alpha'}$$

両辺の自然対数をとると，

$$(z-1) \log \left[ \frac{\cosh(\alpha' + \beta)}{\cosh(\alpha' - \beta)} \right] = 2\alpha'$$

$$\frac{\alpha'}{z-1} = \frac{1}{2} \log \left[ \frac{\cosh(\beta + \alpha')}{\cosh(\beta - \alpha')} \right]$$

これは $\alpha' = 0$ を解に持つ．
非自明な解 $\alpha' \neq 0$ が現れる条件を調べるため， $\alpha' \ll 1$ の近似を行う．
右辺の対数の中身を展開する．
$\cosh(x \pm y) = \cosh x \cosh y \pm \sinh x \sinh y$ を用いると，

$$\frac{\cosh(\beta + \alpha')}{\cosh(\beta - \alpha')} = \frac{\cosh \beta \cosh \alpha' + \sinh \beta \sinh \alpha'}{\cosh \beta \cosh \alpha' - \sinh \beta \sinh \alpha'}$$

$\alpha' \ll 1$ において， $\cosh \alpha' \approx 1$ ， $\sinh \alpha' \approx \alpha'$ とすると，

$$\frac{\cosh(\beta + \alpha')}{\cosh(\beta - \alpha')} \approx \frac{\cosh \beta + \alpha' \sinh \beta}{\cosh \beta - \alpha' \sinh \beta} = \frac{1 + \alpha' \tanh \beta}{1 - \alpha' \tanh \beta}$$

これを用いると，

$$\log \left[ \frac{\cosh(\beta + \alpha')}{\cosh(\beta - \alpha')} \right] \approx \log \left( \frac{1 + \alpha' \tanh \beta}{1 - \alpha' \tanh \beta} \right) \approx 2 \alpha' \tanh \beta$$

したがって，

$$\frac{\alpha'}{z-1} = \frac{1}{2} (2 \alpha' \tanh \beta) = \alpha' \tanh \beta$$

$\alpha' \neq 0$ の解が存在するためには， $\alpha'$ の 1 次の係数を比較して，

$$\frac{1}{z-1} = \tanh \beta$$

であればよい．
したがって，Curie 温度 $T_c$ は

$$\tanh \beta_c = \tanh \frac{J}{kT_c} = \frac{1}{z-1}$$

によって定まる．

## 解説

本問題では，Ising模型における分子場近似（平均場近似）の改良版である「Bethe近似」を用いて，Curie温度を求める手順を扱った．

通常の分子場近似では，あるスピン $\sigma_0$ が周囲のスピンから受ける影響を，周囲のスピンの平均値 $\langle \sigma \rangle$ による一定の有効磁場（分子場）として扱う．
これに対し，Bethe近似では，注目するスピン $\sigma_0$ とその近傍のスピン $z$ 個の間の直接的な相互作用を正確に扱い，それ以外のスピンの影響を分子場として扱うことで，より高精度な近似を実現している．

計算のポイントは以下の通りである．
1. **分配関数の構成**：
  $\sigma_0$ と $\sigma_j$ の相互作用を分離して扱うことで，和の計算を容易にしている．
2. **自己整合性（Self-consistency）条件**：
  Bethe近似の肝は，「注目スピンの平均値」と「近傍スピンの平均値」が一致するという条件（ $\overline{\sigma_0} = \overline{\sigma_j}$ ）を用いる点にある．
  これにより，近似の「つじつま」を合わせている．
3. **相転移の判定**：
  磁場がない状態 ( $H=0$ ) で，自発磁化（ $\alpha' \neq 0$ ）が現れる条件を， $\alpha'$ に関する方程式の微小展開から導いている．
  $\alpha'$ の 1 次の係数が $1/(z-1)$ に一致するときに，非自明な解（磁化を持つ状態）が現れる．

単純な分子場近似における結果は $\tanh \beta_c = 1/z$ であるが，Bethe近似では $\tanh \beta_c = 1/(z-1)$ となり，より正確な値を与える．
特に配位数 $z$ が小さい場合において，この差は顕著になる．
