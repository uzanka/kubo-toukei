# 演習問題【9-C-20】

## 解答

### 1．クラスターの分配関数

注目する中心スピンを $\sigma_0$ ，その周囲の $z$ 個のスピンを $\sigma_1,\ldots,\sigma_z$ とする．
問題で与えられたクラスターの Hamiltonian は，

```math
\mathcal H_{z+1}
=-\mu_0H\sigma_0
-\mu_0(H+H')\sum_{j=1}^{z}\sigma_j
-J\sum_{j=1}^{z}\sigma_0\sigma_j
\tag{1}
```

である．
ここで， $H$ は外部磁場， $H'$ は周囲のスピンに作用する分子場， $J$ は隣接スピン間の相互作用定数である．
以下では，強磁性的相互作用 $J>0$ を考える．

分配関数 $Z$ は，すべてのスピン配置について Boltzmann 因子を足し合わせたものである．
すなわち，

```math
Z=
\sum_{\sigma_0=\pm1}
\sum_{\sigma_1=\pm1}\cdots
\sum_{\sigma_z=\pm1}
\exp\left(-\frac{\mathcal H_{z+1}}{kT}\right)
\tag{2}
```

である．
計算を簡潔にするため，次の無次元量を導入する．

```math
\alpha=\frac{\mu_0H}{kT},
\qquad
\alpha'=\frac{\mu_0H'}{kT},
\qquad
\beta=\frac{J}{kT}
\tag{3}
```

すると，

```math
-\frac{\mathcal H_{z+1}}{kT}
=\alpha\sigma_0
+(\alpha+\alpha')\sum_{j=1}^{z}\sigma_j
+\beta\sum_{j=1}^{z}\sigma_0\sigma_j
\tag{4}
```

となる．

中心スピンは $\sigma_0=+1$ または $\sigma_0=-1$ のどちらかである．
そこで，分配関数を

```math
Z=Z_++Z_-
\tag{5}
```

と分ける．
ここで $Z_+$ は $\sigma_0=+1$ の場合の寄与， $Z_-$ は $\sigma_0=-1$ の場合の寄与である．

$\sigma_0=+1$ の場合，周囲の各スピンに関する和は独立に計算できる．
恒等式

```math
\sum_{\sigma=\pm1}e^{a\sigma}=2\cosh a
```

を用いると，

```math
Z_+=e^\alpha
\left[2\cosh(\alpha+\alpha'+\beta)\right]^z
\tag{6}
```

となる．
同様に， $\sigma_0=-1$ の場合は

```math
Z_-=e^{-\alpha}
\left[2\cosh(\alpha+\alpha'-\beta)\right]^z
\tag{7}
```

となる．
したがって，分配関数は

```math
\boxed{
Z=e^\alpha[2\cosh(\alpha+\alpha'+\beta)]^z
+e^{-\alpha}[2\cosh(\alpha+\alpha'-\beta)]^z
}
\tag{8}
```

である．

### 2．中心スピンと周囲のスピンの平均値

Bethe の近似では，中心スピンの平均値と周囲のスピンの平均値が等しいという自己無撞着条件を課す．
すなわち，

```math
\overline{\sigma_0}=\overline{\sigma_j}
\tag{9}
```

である．

まず，中心スピンの平均値は， $\sigma_0=+1$ と $\sigma_0=-1$ の寄与をそれぞれ $+1$ と $-1$ の重みで平均すればよい．
したがって，

```math
\boxed{
\overline{\sigma_0}=\frac{Z_+-Z_-}{Z_++Z_-}
}
\tag{10}
```

となる．

次に，周囲の $z$ 個のスピンの平均値を求める．
$\alpha'$ は式 (4) において $\sum_j\sigma_j$ の係数であるため，分配関数を $\alpha'$ で微分すると，

```math
\frac{\partial Z}{\partial\alpha'}
=\sum_{\{\sigma\}}
\left(\sum_{j=1}^{z}\sigma_j\right)
e^{-\mathcal H_{z+1}/(kT)}
```

となる．
周囲のスピンは対称に扱われるため，平均値は

```math
\overline{\sigma_j}
=\frac{1}{zZ}\frac{\partial Z}{\partial\alpha'}
\tag{11}
```

と表される．
式 (6)，(7) を微分すると，

```math
\frac{\partial Z_+}{\partial\alpha'}
=zZ_+\tanh(\alpha+\alpha'+\beta)
```

および

```math
\frac{\partial Z_-}{\partial\alpha'}
=zZ_-\tanh(\alpha+\alpha'-\beta)
```

である．
したがって，

```math
\boxed{
\overline{\sigma_j}
=
\frac{
Z_+\tanh(\alpha+\alpha'+\beta)
+Z_-\tanh(\alpha+\alpha'-\beta)}
{Z_++Z_-}
}
\tag{12}
```

を得る．

式 (10)，(12) を自己無撞着条件 (9) に代入し，両辺に $Z_++Z_-$ を掛けると，

```math
\begin{aligned}
Z_+-Z_-={}&
Z_+\tanh(\alpha+\alpha'+\beta)\\
&+Z_-\tanh(\alpha+\alpha'-\beta)
\end{aligned}
```

となる．
整理すれば，

```math
\begin{aligned}
Z_+\{1-\tanh(\alpha+\alpha'+\beta)\}\\
=Z_-\{1+\tanh(\alpha+\alpha'-\beta)\}
\end{aligned}
\tag{13}
```

である．

ここで，

```math
1-\tanh x=\frac{e^{-x}}{\cosh x},
\qquad
1+\tanh x=\frac{e^x}{\cosh x}
\tag{14}
```

を用いる．
式 (6)，(7) と式 (14) を式 (13) に代入すると，指数関数の因子が整理され，

```math
e^{-\alpha'-\beta}
[\cosh(\alpha+\alpha'+\beta)]^{z-1}
=
e^{\alpha'-\beta}
[\cosh(\alpha+\alpha'-\beta)]^{z-1}
```

となる．
両辺の $e^{-\beta}$ を消去して整理すれば，

```math
\boxed{
\left[
\frac{\cosh(\alpha+\alpha'+\beta)}
{\cosh(\alpha+\alpha'-\beta)}
\right]^{z-1}
=e^{2\alpha'}
}
\tag{15}
```

を得る．
これが，Bethe の近似において分子場 $\alpha'$ を決める自己無撞着方程式である．

### 3．Curie 温度の条件

Curie 温度 $T_c$ は，外部磁場がないときに自発磁化が現れ始める温度である．
そこで，

```math
H=0,\qquad \alpha=0
```

とする．
式 (15) は，

```math
\left[
\frac{\cosh(\alpha'+\beta)}
{\cosh(\alpha'-\beta)}
\right]^{z-1}
=e^{2\alpha'}
\tag{16}
```

となる．
両辺の自然対数を取り，整理すれば，

```math
\boxed{
\frac{\alpha'}{z-1}
=\frac12\log
\frac{\cosh(\beta+\alpha')}
{\cosh(\beta-\alpha')}
}
\tag{17}
```

を得る．

この方程式には，常に $\alpha'=0$ という解がある．
これは自発磁化が存在しない状態に対応する．
Curie 温度を求めるには， $\alpha'\neq0$ の解が現れ始める条件を調べればよい．

転移点の近傍では $\alpha'$ が小さいため，右辺を $\alpha'$ について展開する．
関数 $\log\cosh x$ を用いると，

```math
\begin{aligned}
&\frac12\log
\frac{\cosh(\beta+\alpha')}
{\cosh(\beta-\alpha')}\\
&\qquad=
\frac12\left[
\log\cosh(\beta+\alpha')
-\log\cosh(\beta-\alpha')
\right]
\end{aligned}
```

である．
これを Taylor 展開すると，

```math
\boxed{
\frac12\log
\frac{\cosh(\beta+\alpha')}
{\cosh(\beta-\alpha')}
=
\alpha'\tanh\beta
-\frac{\alpha'^3}{3}
\frac{\tanh\beta}{\cosh^2\beta}
+O(\alpha'^5)
}
\tag{18}
```

となる．

式 (18) を式 (17) に代入すると，

```math
\frac{\alpha'}{z-1}
=
\alpha'\tanh\beta
-\frac{\alpha'^3}{3}
\frac{\tanh\beta}{\cosh^2\beta}
+O(\alpha'^5)
\tag{19}
```

である．
Curie 温度では，自発磁化のない解 $\alpha'=0$ から非ゼロの解が現れ始める．
このとき， $\alpha'$ の一次の係数が一致するため，

```math
\frac{1}{z-1}=\tanh\beta_c
```

となる．
ここで $\beta_c=J/(kT_c)$ である．
したがって，

```math
\boxed{
\tanh\left(\frac{J}{kT_c}\right)
=\frac{1}{z-1}
}
\tag{20}
```

を得る．
これが Bethe の近似による Curie 温度の条件である．

### 4．Curie 温度を明示する

$z>2$ では，式 (20) を逆双曲線正接で解くことができる．

```math
\frac{J}{kT_c}
=\operatorname{artanh}\left(\frac{1}{z-1}\right)
```

であるから，

```math
\boxed{
T_c=
\frac{J}{
k\,\operatorname{artanh}\left(\dfrac{1}{z-1}\right)}
}
\tag{21}
```

となる．
ここで，

```math
\operatorname{artanh}x
=\frac12\log\frac{1+x}{1-x}
```

を用いると，

```math
\boxed{
T_c=\frac{2J}{k\log\left(\dfrac{z}{z-2}\right)}
\qquad(z>2)
}
\tag{22}
```

とも表せる．

さらに，式 (19) の三次項までを残し，非ゼロの $\alpha'$ について解くと，

```math
\boxed{
\alpha'^2\simeq
3\frac{\cosh^3\beta}{\sinh\beta}
\left(\tanh\beta-\frac{1}{z-1}\right)
}
\tag{23}
```

となる．
したがって， $J>0$ のとき，この近似で非ゼロの解が現れるのは

```math
\tanh\beta>\frac{1}{z-1}
```

すなわち $T<T_c$ の領域である．
これは，式 (20) が自発磁化の発生する温度を与えることを確認している．

なお， $z=2$ では式 (20) の右辺は $1$ である．
有限温度では $\tanh(J/kT)<1$ であるため，Curie 温度は

```math
\boxed{T_c=0\qquad(z=2)}
\tag{24}
```

となる．

以上より，Bethe の近似による Curie 温度は式 (20) で定まり， $z>2$ では式 (21) または式 (22) と表される．
