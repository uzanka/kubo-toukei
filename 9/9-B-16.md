# 演習問題【9-B-16】

## 解答

### 1．分配関数の導出

$N$ 個の Ising スピンが環状に並ぶ系を考える．
各スピン $\sigma_j$ は $+1$ または $-1$ の値を取り，Hamiltonian は

```math
\mathcal H=-J\sum_{j=1}^{N}\sigma_j\sigma_{j+1},
\qquad \sigma_{N+1}=\sigma_1
\tag{1}
```

である．
ここで， $J$ は隣接スピン間の相互作用定数である．
また，周期境界条件 $\sigma_{N+1}=\sigma_1$ により，最後のスピン $N$ と最初のスピン $1$ も相互作用する．

温度 $T$ における分配関数 $Z$ は，すべてのスピン配置について Boltzmann 因子を足し合わせたものであり，

```math
Z=\sum_{\sigma_1=\pm1}\cdots
\sum_{\sigma_N=\pm1}e^{-\mathcal H/(kT)}
\tag{2}
```

と定義される．
ここで， $k$ は Boltzmann 定数である．

計算を簡単にするため，無次元量

```math
\kappa=\frac{J}{kT}
\tag{3}
```

を導入する．
式 (1)，(2) より，

```math
Z=\sum_{\{\sigma_j\}}
\exp\left(\kappa\sum_{j=1}^{N}
\sigma_j\sigma_{j+1}\right)
\tag{4}
```

となる．
指数関数の性質を用いると，

```math
Z=\sum_{\{\sigma_j\}}
\prod_{j=1}^{N}
e^{\kappa\sigma_j\sigma_{j+1}}
\tag{5}
```

と書ける．

ここで，問題のヒントにある恒等式

```math
e^{a\sigma\sigma'}
=\cosh a+\sigma\sigma'\sinh a
\tag{6}
```

を利用する．
この恒等式が成立するのは， $\sigma\sigma'$ が $+1$ または $-1$ のどちらかであり，

```math
e^{a}=\cosh a+\sinh a,\qquad
e^{-a}=\cosh a-\sinh a
```

だからである．
式 (6) を式 (5) に適用すると，

```math
Z=\sum_{\{\sigma_j\}}
\prod_{j=1}^{N}
\left(\cosh\kappa+
\sigma_j\sigma_{j+1}\sinh\kappa\right)
\tag{7}
```

を得る．

### 2．積を展開してスピン和を取る

式 (7) の積を展開すると，各因子から $\cosh\kappa$ または $\sigma_j\sigma_{j+1}\sinh\kappa$ を選んで掛け合わせた項が現れる．
各項について，そのスピン配置の全ての組み合わせを和に取る必要がある．

このとき，次の二つの性質が重要である．

```math
\sigma_j^2=1,\qquad
\sum_{\sigma_j=\pm1}\sigma_j=1+(-1)=0
\tag{8}
```

すなわち，あるスピンが積の中に奇数回現れる項は，そのスピンについて和を取るとゼロになる．
これを踏まえて，式 (7) の展開項を調べる．

#### 2.1．全ての因子から $\cosh\kappa$ を選ぶ項

全ての因子から $\cosh\kappa$ を選ぶと，

```math
(\cosh\kappa)^N
```

となる．
この項にはスピン変数が含まれないため，スピン配置は全部で $2^N$ 通りあることから，その寄与は

```math
Z_1=2^N(\cosh\kappa)^N
\tag{9}
```

である．

#### 2.2．全ての因子から $\sigma_j\sigma_{j+1}\sinh\kappa$ を選ぶ項

全ての因子から $\sigma_j\sigma_{j+1}\sinh\kappa$ を選ぶと，

```math
(\sinh\kappa)^N
\prod_{j=1}^{N}\sigma_j\sigma_{j+1}
```

となる．
周期境界条件を用いてスピンの積を展開すると，

```math
\begin{aligned}
\prod_{j=1}^{N}\sigma_j\sigma_{j+1}
&=(\sigma_1\sigma_2)(\sigma_2\sigma_3)
\cdots(\sigma_N\sigma_1)\\
&=\sigma_1^2\sigma_2^2\cdots\sigma_N^2\\
&=1
\end{aligned}
\tag{10}
```

である．
したがって，この項もスピン変数に依存しない．
その寄与は

```math
Z_2=2^N(\sinh\kappa)^N
\tag{11}
```

となる．

#### 2.3．その他の項

それ以外の項では，隣接スピンの積 $\sigma_j\sigma_{j+1}$ を選んだ箇所と選ばなかった箇所が混在する．
これらは，環状に並んだ $N$ 個のスピンを結ぶ辺の一部を選んだものと考えられる．

スピン $\sigma_j$) が奇数回現れる項は，式 (8) よりスピン和を取ると消える．
項が消えずに残るには，各スピンが偶数回現れなければならない．
環状の一次元配置では，この条件を満たすのは，全ての辺を選ばない場合と，全ての辺を選ぶ場合だけである．

したがって，式 (9)，(11) 以外の項は全てゼロになる．
以上より，有限の $N$ に対する厳密な分配関数は

```math
\boxed{
Z=2^N\left[(\cosh\kappa)^N+
(\sinh\kappa)^N\right]
}
\tag{12}
```

となる．
また， $\cosh\kappa\neq0$ であることから，

```math
\boxed{
Z=(2\cosh\kappa)^N
\left[1+(\tanh\kappa)^N\right]
}
\tag{13}
```

と書き換えられる．

### 3．自由エネルギー

Helmholtz の自由エネルギー $F$ は，分配関数を用いて

```math
F=-kT\ln Z
\tag{14}
```

と表される．
式 (13) を代入すると，

```math
\begin{aligned}
F
&=-kT\ln\left\{
(2\cosh\kappa)^N
[1+(\tanh\kappa)^N]\right\}\\
&=-NkT\ln(2\cosh\kappa)
-kT\ln[1+(\tanh\kappa)^N]
\end{aligned}
\tag{15}
```

を得る．
これが有限 $N$ に対する厳密な自由エネルギーである．

ただし，有限の温度 $T>0$ では，

```math
|\tanh\kappa|<1
```

であるため，熱力学極限 $N\to\infty$ では

```math
(\tanh\kappa)^N\longrightarrow0
```

となる．
このため，式 (15) の第2項は消失し，

```math
F=-NkT\ln(2\cosh\kappa)
```

となる．
$\kappa=J/(kT)$ を戻せば，

```math
\boxed{
F=-NkT\ln\left\{
2\cosh\left(\frac{J}{kT}\right)
\right\}
}
\tag{16}
```

である．
したがって，問題文の自由エネルギーの式は，熱力学極限において厳密に成立する．
有限の $N$ では，式 (15) の有限サイズ補正を含める必要がある．

### 4．内部エネルギー

内部エネルギー $E$ は，分配関数を用いて

```math
E=-\frac{\partial\ln Z}{\partial\beta},
\qquad
\beta=\frac{1}{kT}
\tag{17}
```

と表される．
ここでは $\kappa=\beta J=J/(kT)$ を用いる．

式 (13) の対数を取ると，

```math
\ln Z=N\ln(2\cosh\kappa)
+\ln[1+(\tanh\kappa)^N]
\tag{18}
```

である．
また，

```math
\frac{d\kappa}{d\beta}=J,\qquad
\frac{d}{d\kappa}\ln(\cosh\kappa)=\tanh\kappa
```

が成り立つ．
よって，式 (17)，(18) から，

```math
\begin{aligned}
E
&=-NJ\tanh\kappa\\
&\quad-J\frac{
N(\tanh\kappa)^{N-1}
\left[1-\tanh^2\kappa\right]}
{1+(\tanh\kappa)^N}
\end{aligned}
\tag{19}
```

を得る．
ここで，分子と分母を整理すると，

```math
\boxed{
E=-NJ\frac{\tanh\kappa+
(\tanh\kappa)^{N-1}}
{1+(\tanh\kappa)^N}
}
\tag{20}
```

となる．
これが有限 $N$ での厳密な内部エネルギーである．

熱力学極限では $|\tanh\kappa|<1$ より有限サイズ補正が消失するため，

```math
\boxed{
E=-NJ\tanh\left(\frac{J}{kT}\right)
}
\tag{21}
```

となる．

### 5．比熱と温度の関係

体積一定での比熱を $C_V$ とすると，

```math
C_V=\frac{dE}{dT}
\tag{22}
```

である．
熱力学極限の式 (21) を用いて比熱を求める．

```math
\kappa=\frac{J}{kT}
```

とおくと，

```math
\frac{d\kappa}{dT}=-\frac{J}{kT^2}
```

であり，

```math
\frac{d}{d\kappa}\tanh\kappa
=\frac{1}{\cosh^2\kappa}
```

である．
したがって，

```math
\begin{aligned}
C_V
&=\frac{d}{dT}
\left[-NJ\tanh\left(\frac{J}{kT}\right)\right]\\
&=-NJ\frac{1}{\cosh^2\kappa}
\left(-\frac{J}{kT^2}\right)
\end{aligned}
```

となる．
よって，

```math
\boxed{
C_V=
\frac{NJ^2}{kT^2\cosh^2(J/kT)}
}
\tag{23}
```

を得る．
これは問題文で求められた比熱の温度依存性である．

有限 $N$ での厳密な比熱は，式 (20) を温度で微分して得られる．
$t=\tanh\kappa$ とおけば，

```math
C_V=
\frac{NJ^2}{kT^2}
\frac{d}{d\kappa}
\left(\frac{t+t^{N-1}}{1+t^N}\right)
\tag{24}
```

である．
さらに，微分を実行すると，

```math
\boxed{
C_V=
\frac{NJ^2}{kT^2}
\frac{(1-t^2)
\left\{
[1+(N-1)t^{N-2}](1+t^N)
-Nt^{N-1}(t+t^{N-1})
\right\}}
{(1+t^N)^2}
}
\tag{25}
```

となる．
ここで $t=\tanh(J/(kT))$ である．
熱力学極限では，式 (25) の有限サイズ補正が消失し，式 (23) に帰着する．

### 6．比熱の温度依存性

式 (23) から，比熱の温度依存性を確認できる．

高温 $T\to\infty$ では $J/(kT)\to0$ であるため，

```math
C_V\simeq\frac{NJ^2}{kT^2}\longrightarrow0
```

となる．

一方， $J>0$ の場合の低温 $T\to0^+$ では $J/(kT)\to\infty$ である．
このとき，

```math
\frac{1}{\cosh^2(J/kT)}
\simeq4e^{-2J/(kT)}
```

となるため，

```math
C_V\simeq
\frac{4NJ^2}{kT^2}e^{-2J/(kT)}
\longrightarrow0
```

である．
したがって，比熱は高温でも低温でもゼロに近づき，中間の温度で有限の値を取る．

以上より，環状 Ising スピン系の分配関数を直接展開することで，有限 $N$ に対する厳密な自由エネルギーと内部エネルギーを導くことができる．
さらに，熱力学極限では問題文の自由エネルギー

```math
\boxed{
F=-NkT\ln\left\{
2\cosh\left(\frac{J}{kT}\right)
\right\}
}
```

および比熱

```math
\boxed{
C_V=\frac{NJ^2}{kT^2\cosh^2(J/kT)}
}
```

が得られる．
