# 演習問題【9-B-16】

## 解答

## 1．分配関数の導出

$N$ 個の Ising スピンが環状に並ぶ系を考える．
各スピン $\sigma_j$ は $+1$ または $-1$ の値を取り，Hamiltonian は，

```math
\mathcal H=-J\sum_{j=1}^{N}\sigma_j\sigma_{j+1},
\qquad \sigma_{N+1}=\sigma_1
\tag{1}
```

である．
ここで， $J$ は隣接スピン間の相互作用定数である．
また，周期境界条件 $\sigma_{N+1}=\sigma_1$ により，最後のスピン $N$ と最初のスピン $1$ も相互作用する．

温度 $T$ における分配関数 $Z$ は，

```math
Z=\sum_{\sigma_1=\pm1}\cdots
\sum_{\sigma_N=\pm1}e^{-\mathcal H/(kT)}
\tag{2}
```

である．

計算を簡単にするため，無次元量

```math
\kappa=\frac{J}{kT}
\tag{3}
```

を導入する．
式 (1)，(2) より，

```math
Z=\sum_{\{\sigma_j\}}
\exp\left(\kappa\sum_{j=1}^{N}
\sigma_j\sigma_{j+1}\right)
\tag{4}
```

となる．
指数関数の性質から，

```math
Z=\sum_{\{\sigma_j\}}
\prod_{j=1}^{N}
e^{\kappa\sigma_j\sigma_{j+1}}
\tag{5}
```

と書ける．

問題のヒントにある恒等式，

```math
e^{a\sigma\sigma'}
=\cosh a+\sigma\sigma'\sinh a
\tag{6}
```

を用いる．
これは， $\sigma\sigma'=\pm1$ であることから，

```math
e^a=\cosh a+\sinh a,\qquad
e^{-a}=\cosh a-\sinh a
```

となることによる．

式 (6) を式 (5) に適用すると，

```math
Z=\sum_{\{\sigma_j\}}
\prod_{j=1}^{N}
\left(
\cosh\kappa+
\sigma_j\sigma_{j+1}\sinh\kappa
\right)
\tag{7}
```

を得る．

## 2．積の展開とスピン和

式 (7) の積を展開する．
各因子から $\cosh\kappa$ または $\sigma_j\sigma_{j+1}\sinh\kappa$ のいずれかを選ぶことになる．

スピン和を取る際には，

```math
\sigma_j^2=1,\qquad
\sigma_j^{2m}=1,\qquad
\sigma_j^{2m+1}=\sigma_j
```

という関係を利用する．
したがって，

```math
\sum_{\sigma_j=\pm1}\sigma_j^m
=
\begin{cases}
2 &(m\text{ が偶数}),\\
0 &(m\text{ が奇数})
\end{cases}
\tag{8}
```

となる．

すなわち，各スピンが偶数回現れる項だけが残り，奇数回現れるスピンを含む項は消える．

### 2.1．全ての因子から $\cosh\kappa$ を選ぶ項

全ての因子から $\cosh\kappa$ を選ぶと，

```math
(\cosh\kappa)^N
```

となる．
この項にはスピン変数が含まれないため，全てのスピン配置 $2^N$ 通りが寄与する．
したがって，

```math
Z_1=2^N(\cosh\kappa)^N
\tag{9}
```

である．

### 2.2．全ての因子から $\sinh\kappa$ を選ぶ項

全ての因子から $\sigma_j\sigma_{j+1}\sinh\kappa$ を選ぶと，

```math
(\sinh\kappa)^N
\prod_{j=1}^{N}\sigma_j\sigma_{j+1}
```

となる．
周期境界条件を用いると，

```math
\begin{aligned}
\prod_{j=1}^{N}\sigma_j\sigma_{j+1}
&=(\sigma_1\sigma_2)(\sigma_2\sigma_3)
\cdots(\sigma_N\sigma_1)\\
&=\sigma_1^2\sigma_2^2\cdots\sigma_N^2\\
&=1
\end{aligned}
\tag{10}
```

である．

したがって，この項もスピン変数に依存せず，全てのスピン配置が寄与する．
その寄与は，

```math
Z_2=2^N(\sinh\kappa)^N
\tag{11}
```

となる．

### 2.3．その他の項が消えることの証明

各結合 $(j,j+1)$ について，その因子から $\sinh\kappa$ の項を選ぶ場合を $s_j=1$ ， $\cosh\kappa$ の項を選ぶ場合を $s_j=0$ と定義する．

すなわち，

```math
s_j=
\begin{cases}
1 &(\sigma_j\sigma_{j+1}\sinh\kappa\text{ を選択}),\\
0 &(\cosh\kappa\text{ を選択})
\end{cases}
\tag{12}
```

である．

この選択によって得られる展開項は，

```math
(\cosh\kappa)^{N-\sum_j s_j}
(\sinh\kappa)^{\sum_j s_j}
\prod_{j=1}^{N}
(\sigma_j\sigma_{j+1})^{s_j}
\tag{13}
```

である．

ここで，スピン $\sigma_j$ が積の中に現れる回数は，

```math
s_{j-1}+s_j
```

である．
ただし，周期境界条件により $s_0=s_N$ とする．

したがって，ある選択 $s_1,\ldots,s_N$ に対応する項のスピン和は，

```math
\begin{aligned}
&\sum_{\{\sigma_j\}}
\prod_{j=1}^{N}
\sigma_j^{s_{j-1}+s_j}\\
&\qquad=
\prod_{j=1}^{N}
\left(
\sum_{\sigma_j=\pm1}
\sigma_j^{s_{j-1}+s_j}
\right).
\end{aligned}
\tag{14}
```

式 (8) より，この積がゼロでないためには，各 $j$ について，

```math
s_{j-1}+s_j
```

が偶数でなければならない．

$s_{j-1},s_j$ はそれぞれ $0$ または $1$ なので，この条件は，

```math
\boxed{s_{j-1}=s_j}
\tag{15}
```

と同値である．

周期境界条件のもとで，これが全ての $j$ について成立するため，

```math
s_1=s_2=\cdots=s_N
\tag{16}
```

となる．

したがって，スピン和を取ったときに消えずに残る選択は，

```math
(s_1,\ldots,s_N)=(0,\ldots,0)
```

または，

```math
(s_1,\ldots,s_N)=(1,\ldots,1)
```

の2通りだけである．

これは，それぞれ2.1節と2.2節で計算した項に対応する．
したがって，それ以外の全ての展開項はスピン和によってゼロになる．

以上から，有限の $N$ に対する厳密な分配関数は，

```math
\boxed{
Z_N=2^N\left[
(\cosh\kappa)^N+(\sinh\kappa)^N
\right]
}
\tag{17}
```

となる．

また， $\cosh\kappa\neq0$ であることから，

```math
\boxed{
Z_N=(2\cosh\kappa)^N
\left[1+(\tanh\kappa)^N\right]
}
\tag{18}
```

と書き換えられる．

## 3．自由エネルギー

Helmholtz の自由エネルギー $F_N$ は，

```math
F_N=-kT\ln Z_N
\tag{19}
```

である．
式 (18) を代入すると，

```math
\begin{aligned}
F_N
&=-kT\ln\left\{
(2\cosh\kappa)^N
[1+(\tanh\kappa)^N]
\right\}\\
&=-NkT\ln(2\cosh\kappa)
-kT\ln[1+(\tanh\kappa)^N]
\end{aligned}
\tag{20}
```

を得る．

これが有限 $N$ に対する厳密な自由エネルギーである．

ここで，有限の温度 $T>0$ では，

```math
|\tanh\kappa|<1
```

であるため，

```math
\lim_{N\to\infty}(\tanh\kappa)^N=0
\tag{21}
```

となる．

したがって，有限サイズ補正は，

```math
-kT\ln[1+(\tanh\kappa)^N]\longrightarrow0
```

である．

自由エネルギー $F_N$ 自体は $N$ に比例するため，その極限を直接取るのではなく，自由エネルギー密度 $f(T)$ を定義する．

```math
\begin{aligned}
f(T)
&=\lim_{N\to\infty}\frac{F_N}{N}\\
&=-kT\ln(2\cosh\kappa)
\end{aligned}
```

したがって，

```math
\boxed{
f(T)=-kT\ln\left\{
2\cosh\left(\frac{J}{kT}\right)
\right\}
}
\tag{22}
```

である．

また，有限系の自由エネルギーは，

```math
\boxed{
F_N=Nf(T)+o(1)
}
\tag{23}
```

となる．
ここで $o(1)$ は，固定した有限温度 $T>0$ に対して $N\to\infty$ でゼロに収束する項を表す．

したがって，問題文の自由エネルギーの式は，熱力学極限における全自由エネルギーの主要な示量的寄与として，

```math
\boxed{
F_{\mathrm{th}}
=-NkT\ln\left\{
2\cosh\left(\frac{J}{kT}\right)
\right\}
}
\tag{24}
```

と表される．
有限 $N$ では，式 (20) の有限サイズ補正を含める必要がある．

なお，反強磁性 $J<0$ で $N$ が奇数の場合には，環状格子において全ての結合を同時に反平行にできないため，フラストレーションが生じる．
この場合， $T\to0^+$ を有限 $N$ で先に取ると，

```math
1+(\tanh\kappa)^N
\sim 2N\exp\left(-\frac{2|J|}{kT}\right)
```

となる．
したがって，自由エネルギーの有限サイズ補正は，

```math
-kT\ln[1+(\tanh\kappa)^N]
\longrightarrow 2|J|
```

となる．

一方，有限の $T>0$ で先に熱力学極限を取れば，この補正はゼロになる．
したがって，低温極限と熱力学極限の順序には注意が必要である．

## 4．内部エネルギー

内部エネルギー $E_N$ は，

```math
E_N=-\frac{\partial\ln Z_N}{\partial\beta},
\qquad
\beta=\frac{1}{kT}
\tag{25}
```

で与えられる．
ここで，

```math
\kappa=\beta J
```

なので，

```math
\frac{d\kappa}{d\beta}=J,
\qquad
\frac{d}{d\kappa}\ln(\cosh\kappa)
=\tanh\kappa
```

である．

```math
t=\tanh\kappa
```

と置くと，式 (18) より，

```math
\ln Z_N
=N\ln(2\cosh\kappa)+\ln(1+t^N)
\tag{26}
```

となる．

また，

```math
\frac{dt}{d\kappa}=1-t^2
```

なので，

```math
\begin{aligned}
\frac{d\ln Z_N}{d\kappa}
&=Nt+
\frac{Nt^{N-1}(1-t^2)}{1+t^N}
\end{aligned}
```

である．

したがって，

```math
\begin{aligned}
E_N
&=-J\frac{d\ln Z_N}{d\kappa}\\
&=-NJt
-J\frac{Nt^{N-1}(1-t^2)}{1+t^N}.
\end{aligned}
```

分子を通分して整理すると，

```math
t(1+t^N)+t^{N-1}(1-t^2)
=t+t^{N-1}
```

となるため，

```math
\boxed{
E_N=-NJ
\frac{t+t^{N-1}}{1+t^N}
}
\tag{27}
```

を得る．

これが有限 $N$ での厳密な内部エネルギーである．

熱力学極限での内部エネルギー密度 $u(T)$ は，

```math
\begin{aligned}
u(T)
&=\lim_{N\to\infty}\frac{E_N}{N}\\
&=-J\tanh\left(\frac{J}{kT}\right)
\end{aligned}
```

である．
したがって，全内部エネルギーの主要な示量的寄与は，

```math
\boxed{
E_{\mathrm{th}}
=-NJ\tanh\left(\frac{J}{kT}\right)
}
\tag{28}
```

となる．

## 5．比熱と温度の関係

体積一定での比熱 $C_V$ は，

```math
C_V=\frac{dE}{dT}
\tag{29}
```

である．

まず，熱力学極限での式 (28) を用いる．

```math
\kappa=\frac{J}{kT}
```

と置けば，

```math
\frac{d\kappa}{dT}
=-\frac{J}{kT^2}
```

および，

```math
\frac{d}{d\kappa}\tanh\kappa
=\frac{1}{\cosh^2\kappa}
```

である．

したがって，

```math
\begin{aligned}
C_V
&=\frac{d}{dT}
\left[-NJ\tanh\left(\frac{J}{kT}\right)\right]\\
&=-\frac{NJ}{\cosh^2\kappa}
\left(-\frac{J}{kT^2}\right).
\end{aligned}
```

よって，

```math
\boxed{
C_V=
\frac{NJ^2}
{kT^2\cosh^2(J/kT)}
}
\tag{30}
```

を得る．

これが熱力学極限における比熱の温度依存性である．

なお，有限 $N$ での厳密な比熱は，式 (27) を温度で微分すれば得られる．

```math
t=\tanh\kappa
```

と置くと，

```math
C_V=
\frac{NJ^2}{kT^2}
\frac{d}{d\kappa}
\left(
\frac{t+t^{N-1}}{1+t^N}
\right)
\tag{31}
```

である．

商の微分を実行すると，

```math
\boxed{
\begin{aligned}
C_V
={}&\frac{NJ^2}{kT^2}
\frac{1-t^2}{(1+t^N)^2}\\
&\times
\left\{
[1+(N-1)t^{N-2}](1+t^N)
-Nt^{N-1}(t+t^{N-1})
\right\}
\end{aligned}
}
\tag{32}
```

となる．
ここで，

```math
t=\tanh\left(\frac{J}{kT}\right)
```

である．

## 6．比熱の温度依存性と極大

式 (30) の比熱をさらに調べるため，

```math
x=\frac{|J|}{kT}
```

と置く．
すると，

```math
\boxed{
\frac{C_V}{Nk}
=\frac{x^2}{\cosh^2x}
}
\tag{33}
```

となる．

この式から，比熱は $J$ の符号には依存せず， $|J|$ のみに依存することが分かる．
したがって，熱力学極限では強磁性と反強磁性の比熱は同じ温度依存性を示す．

### 6.1．高温極限

高温 $T\to\infty$ では，

```math
x=\frac{|J|}{kT}\to0
```

である．
このとき，

```math
\cosh x\simeq1
```

なので，

```math
C_V\simeq Nkx^2
=\frac{NJ^2}{kT^2}
```

となる．
したがって，

```math
\boxed{
\lim_{T\to\infty}C_V=0
}
\tag{34}
```

である．

### 6.2．低温極限

低温 $T\to0^+$ では，

```math
x=\frac{|J|}{kT}\to\infty
```

である．
このとき，

```math
\frac{1}{\cosh^2x}\simeq4e^{-2x}
```

なので，

```math
C_V\simeq
\frac{4NJ^2}{kT^2}
\exp\left(-\frac{2|J|}{kT}\right).
```

したがって，

```math
\boxed{
\lim_{T\to0^+}C_V=0
}
\tag{35}
```

となる．

### 6.3．比熱の極大

比熱の極大温度を求めるため，

```math
g(x)=\frac{x^2}{\cosh^2x}
```

と置く．
微分すると，

```math
\begin{aligned}
g'(x)
&=\frac{2x}{\cosh^2x}
-\frac{2x^2\tanh x}{\cosh^2x}\\
&=\frac{2x}{\cosh^2x}(1-x\tanh x).
\end{aligned}
\tag{36}
```

$x>0$ において極値条件は，

```math
\boxed{x\tanh x=1}
\tag{37}
```

である．

関数 $x\tanh x$ は，

```math
\frac{d}{dx}(x\tanh x)
=\tanh x+\frac{x}{\cosh^2x}>0
```

なので， $x>0$ で単調増加する．
また，

```math
\lim_{x\to0^+}x\tanh x=0,
\qquad
\lim_{x\to\infty}x\tanh x=\infty
```

であるため，式 (37) は正の解をただ1つ持つ．

その数値解は，

```math
x_{\max}\simeq1.19968
```

である．
したがって，比熱が最大となる温度は，

```math
\boxed{
T_{\max}
=\frac{|J|}{1.19968\,k}
\simeq0.83356\frac{|J|}{k}
}
\tag{38}
```

となる．

また，極大条件 $x_{\max}\tanh x_{\max}=1$ を用いると，

```math
\frac{C_{V,\max}}{Nk}
=x_{\max}^2
\left(1-\tanh^2x_{\max}\right)
=x_{\max}^2-1
```

である．
したがって，

```math
\boxed{
C_{V,\max}\simeq0.43923Nk
}
\tag{39}
```

となる．

以上より，比熱は高温と低温の両方でゼロに近づき，中間の温度で1つの極大を持つ．

なお， $J=0$ の場合にはスピン間相互作用がなく，比熱は全温度でゼロとなる．

以上から，環状 Ising スピン系の有限 $N$ に対する厳密な分配関数は，

```math
\boxed{
Z_N=2^N\left[
(\cosh(J/kT))^N+
(\sinh(J/kT))^N
\right]
}
```

であり，熱力学極限では，自由エネルギー密度と比熱はそれぞれ，

```math
\boxed{
f(T)=-kT\ln\left[
2\cosh\left(\frac{J}{kT}\right)
\right]
}
```

および，

```math
\boxed{
C_V=
\frac{NJ^2}
{kT^2\cosh^2(J/kT)}
}
```

で与えられる．
