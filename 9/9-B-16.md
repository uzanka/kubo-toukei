# 演習問題【9-B-16】

## 解答

$N$ 個の Ising スピンが環状（一次元の閉じた鎖）に並んでいる系を考える．
各スピン $\sigma_j$ ( $j=1, \dots, N$ ) は $\pm 1$ の値をとる．
系のハミルトニアン（エネルギー関数）は次のように与えられる：

$$\mathcal{H} = -J \sum_{j=1}^{N} \sigma_j \sigma_{j+1}$$

ここで，環状の境界条件として $\sigma_{N+1} \equiv \sigma_1$ を課す．
$J > 0$ はスピンが隣り合う向きを揃えようとする相互作用の強さを表している．

### 1. 分配関数の計算

統計力学において，系の性質を決定する最も重要な量である分配関数 $Z$ は，すべての可能なスピンの状態についてのボルツマン因子 $\exp(-\beta_{\text{std}} \mathcal{H})$ の和として定義される（ただし $\beta_{\text{std}} = 1/(kT)$ ）．
無次元量 $\kappa \equiv J/(kT)$ を導入すると，

$$Z = \sum_{\{\sigma\}} \exp(-\beta_{\text{std}} \mathcal{H}) = \sum_{\sigma_1=\pm 1} \dots \sum_{\sigma_N=\pm 1} \exp \left( \kappa \sum_{j=1}^{N} \sigma_j \sigma_{j+1} \right)$$

指数関数の性質を用いると，和の中の指数部分を積の形に書き換えることができる：

$$Z = \sum_{\sigma_1, \dots, \sigma_N} \prod_{j=1}^{N} \exp(\kappa \sigma_j \sigma_{j+1})$$

ここで，ヒントにある通り，次の恒等式を用いる：

$$\exp(a \sigma \sigma') = \cosh a + \sigma \sigma' \sinh a$$

これを用いると，各積の因子は次のように書ける：

$$\exp(\kappa \sigma_j \sigma_{j+1}) = \cosh \kappa + \sigma_j \sigma_{j+1} \sinh \kappa$$

したがって，分配関数は次のような積の和の形になる：

$$Z = \sum_{\sigma_1, \dots, \sigma_N} \prod_{j=1}^{N} \left( \cosh \kappa + \sigma_j \sigma_{j+1} \sinh \kappa \right) \quad \cdots (1)$$

式(1)の積を展開すると， $2^N$ 個の項が現れる．
それぞれの項は，各因子から $\cosh \kappa$ または $\sigma_j \sigma_{j+1} \sinh \kappa$ のいずれかを選択して掛け合わせたものである．
一般に，ある項は $\cosh^{N-k}\kappa \,\sinh^k\kappa \times (\text{スピンの積})$ という形をとる（ $k$ は $\sinh \kappa$ の個数 ）．
この項をすべてのスピンの組み合わせについて和をとる（ $\sum_{\sigma_1, \dots, \sigma_N}$ ）とき，スピンの積の部分に注目する．
スピン $\sigma_i$ の値についての和 $\sum_{\sigma_i = \pm 1} \sigma_i = 1 + (-1) = 0$ であるため，もしあるスピン $\sigma_i$ が積の中で奇数回しか現れなければ，その和は $0$ になって消えてしまう．

- **$k=0$ の場合**：
 すべての因子から $\cosh \kappa$ を選んだ項は $\cosh^N\kappa$ であり，スピンの積は $1$ である．
 この項の和は $\sum_{\{\sigma\}} \cosh^N\kappa = 2^N \cosh^N\kappa$ となる．

- **$k=N$ の場合**：
  すべての因子から $\sigma_j \sigma_{j+1} \sinh \kappa$ を選んだ項は $\sinh^N\kappa \prod_{j=1}^N \sigma_j \sigma_{j+1}$ である．
  環状の境界条件を用いると，スピンの積は次のように整理できる：
  $$\prod_{j=1}^N \sigma_j \sigma_{j+1} = (\sigma_1 \sigma_2)(\sigma_2 \sigma_3) \dots (\sigma_{N-1} \sigma_N)(\sigma_N \sigma_1) = \sigma_1^2 \sigma_2^2 \dots \sigma_N^2 = 1$$
  （なぜなら $\sigma_i^2 = (\pm 1)^2 = 1$ だからである．）
  したがって，この項の和は $\sum_{\{\sigma\}} \sinh^N\kappa = 2^N \sinh^N\kappa$ となる．

- **$0 < k < N$ の場合**：
  一次元環状配置において，積 $\prod_{j\in S} \sigma_j \sigma_{j+1}$ （ $S$ は $k$ 個の隣接対の集合 ）のうちで，すべてのスピンが偶数回現れるのは，選択した辺が閉路を形成する場合に限られる．
  一次元環において閉路となるのは全域閉路（ $k=N$ ）のみであり， $0 < k < N$ の範囲では少なくとも一つのスピンが奇数回しか現れないため，スピンの和をとると $0$ になる．

したがって，分配関数は次のように求められる：

```math
Z = 2^N \left\{ \cosh^N\kappa + \sinh^N\kappa \right\} \quad \cdots (2)
```

これは有限 $N$ における厳密な結果である．
これを $Z = 2^N \cosh^N\kappa \left[ 1 + (\tanh \kappa)^N \right]$ と変形すると，物理的性質が明確になる．
 $|\tanh \kappa| < 1$ （ $T > 0$ ）であるから，熱力学極限 $N \to \infty$ を取ると $(\tanh \kappa)^N \to 0$ となり，

$$Z = 2^N \cosh^N\kappa \quad \cdots (3)$$

が得られる．
問題文で求められている「正確に $F = -NkT \log\{2 \cosh(J/kT)\}$ なる形」は，この熱力学極限において厳密に成立する．

### 2. 自由エネルギーの導出

自由エネルギー $F$ は，分配関数 $Z$ を用いて $F = -kT \log Z$ と定義される．
式(3)を用いると，

$$F = -kT \log \left[ 2^N \cosh^N\kappa \right] = -kT \left[ N \log 2 + N \log(\cosh \kappa) \right]$$

```math
F = -NkT \log \left\{ 2 \cosh \left( \frac{J}{kT} \right) \right\} \quad \cdots (4)
```

となり，問題で与えられた形が示された．

### 3. エネルギーと比熱の導出

内部エネルギー $E$ は，問題文の公式 $E = \frac{\partial}{\partial T^{-1}} \frac{F}{T}$ に従って計算する．
$\beta F = -NJ \log[2 \cosh(J/kT)]$ であるから， $x \equiv J/(kT)$ とおいて $x$ の関数として扱うと便利である．

$$E = \frac{\partial (\beta F)}{\partial x} = -NJ \frac{d}{dx} \log[2 \cosh x] = -NJ \frac{\sinh x}{\cosh x} = -NJ \tanh x$$

すなわち，

$$E = -NJ \tanh \left( \frac{J}{kT} \right)$$

である．

次に，比熱 $C$ はエネルギーの温度による変化率 $C = \frac{dE}{dT}$ である．
$x \equiv J/(kT)$ とおいて連鎖律を適用する．

$$\frac{dx}{dT} = -\frac{J}{kT^2}$$

より，

$$C = \frac{dE}{dx} \frac{dx}{dT} = [-NJ \cdot \text{sech}^2(x)] \cdot \left(-\frac{J}{kT^2}\right) = \frac{NJ^2}{kT^2} \text{sech}^2\left(\frac{J}{kT}\right)$$

（※注：ここで $\text{sech}^2 x = 1/\cosh^2 x$ である．）

式を整理すると，

$$C = \frac{NJ^2}{kT^2} \frac{1}{\cosh^2(J/kT)}$$

となる．

## 解説

本問題は，統計力学における最も基本的なモデルの一つである「一次元 Ising 模型」の解法を扱っている．

1. **Ising 模型とは**：
 スピンが上下（ $\pm 1$ ）の状態のみをとるモデルである．
 隣り合うスピン間の相互作用 $J$ が正の場合，スピンは同じ向きに揃おうとする（強磁性的相互作用）．

2. **分配関数の物理的意味**：
 分配関数 $Z$ は，系が取りうるすべてのエネルギー状態の「重み」の総和であり，これさえ分かれば，熱力学的なあらゆる量（自由エネルギー，内部エネルギー，比熱など）を導出できる．

3. **転送行列法の考え方**：
 今回の解法では，積の展開とスピンの和をとる操作を行っているが，これは「転送行列法（Transfer Matrix Method）」と呼ばれる手法の特殊なケースに相当する．
 行列の固有値を用いて分配関数を求める手法であり，一次元系における解法として非常に強力である．

4. **比熱の振る舞い**：
 導出された比熱 $C$ の式を見ると，温度 $T$ が非常に高いとき ( $T \to \infty$ )， $C$ は $0$ に近づく．
 また， $T \to 0$ のときも， $1/\cosh^2(J/kT)$ の項が指数関数的に減少するため， $C$ は $0$ に収束する．
 これは，低温ではスピンが完全に揃ってしまい，エネルギーのゆらぎがなくなることを物理的に示唆している．

5. **熱力学極限について**：
 有限 $N$ では分配関数に $(\tanh \kappa)^N$ の項が残る（式(2)）．
 しかし熱力学極限 $N \to \infty$ ではこの項が消失し，問題文の結果が「正確に」得られる（式(3)）．
 このことは，一次元Ising模型には有限サイズ効果しかないことを意味する——現実の巨視的な系では問題なく成立する結果である．
