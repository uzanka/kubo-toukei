# 演習問題【9-B-18】

## 解答

固定された正電荷の密度が $n_0e$ であり，平均電子数密度が $n_0$ である物質を考える．
この物質中の原点に点電荷 $ze$ を置くと，電子が引き寄せられ，その周囲の電子密度と静電ポテンシャルが変化する．

点電荷と電子分布は球対称であるため，ポテンシャルを原点からの距離 $r$ の関数 $\varphi(r)$ として表す．
原点以外の領域では，Poisson 方程式は

```math
\boxed{
\nabla^2\varphi(r)=4\pi e[n(r)-n_0]
}
\tag{1}
```

となる．
ここでは， $\varphi\sim ze/r$ という境界条件に対応する Gaussian 単位系を用いる．
また，境界条件は

```math
\varphi(r)\sim\frac{ze}{r}\quad(r\to0),
\qquad
\varphi(r)\to0\quad(r\to\infty)
\tag{2}
```

である．
以下では，(i) 電子ガスが縮退していない高温の場合と，(ii) $T=0$ で電子気体が完全に縮退している場合をそれぞれ考える．

### (i) 高温の場合：Debye 遮蔽

#### 1．Boltzmann 分布を用いて電子密度を表す

電子の電荷は $-e$ であるため，静電ポテンシャル $\varphi(r)$ による電子の位置エネルギーは $-e\varphi(r)$ である．
電子ガスが縮退していない場合，Boltzmann 分布により電子密度は

```math
\boxed{
n(r)=n_0\exp\left(\frac{e\varphi(r)}{kT}\right)
}
\tag{3}
```

と表される．
ここで， $k$ は Boltzmann 定数， $T$ は絶対温度である．
無限遠では $\varphi\to0$ であるため， $n\to n_0$ となるように係数を $n_0$ としている．

式 (3) を Poisson 方程式 (1) に代入すると，

```math
\nabla^2\varphi
=4\pi en_0
\left[
\exp\left(\frac{e\varphi}{kT}\right)-1
\right]
\tag{4}
```

を得る．
この式は，右辺に指数関数を含むため非線形である．

#### 2．電位が小さい領域で線形化する

点電荷から十分離れた領域では，電子の位置エネルギーの変化が熱エネルギー $kT$ より十分小さいと考えられる．
すなわち，

```math
\left|\frac{e\varphi}{kT}\right|\ll1
```

である．
このとき，

```math
e^x\simeq1+x\qquad(|x|\ll1)
```

という一次近似を用いると，

```math
\exp\left(\frac{e\varphi}{kT}\right)-1
\simeq\frac{e\varphi}{kT}
```

となる．
したがって，式 (4) は

```math
\nabla^2\varphi
\simeq\frac{4\pi n_0e^2}{kT}\varphi
\tag{5}
```

となる．
ここで Debye 遮蔽定数 $\kappa$ を

```math
\boxed{
\kappa^2=\frac{4\pi n_0e^2}{kT}
}
\tag{6}
```

と定義すれば，

```math
\boxed{\nabla^2\varphi=\kappa^2\varphi}
\tag{7}
```

という線形方程式が得られる．

#### 3．ポテンシャルの分布を求める

球対称な関数の Laplacian は

```math
\nabla^2\varphi
=\frac{1}{r^2}\frac{d}{dr}
\left(r^2\frac{d\varphi}{dr}\right)
```

である．
したがって，式 (7) の球対称な一般解は

```math
\varphi(r)=\frac{A e^{-\kappa r}+B e^{\kappa r}}{r}
```

となる．
無限遠でポテンシャルがゼロに近づくという条件から，増大する項の係数は $B=0$ である．
よって，

```math
\varphi(r)=\frac{A}{r}e^{-\kappa r}
```

となる．
さらに，原点近傍で点電荷による Coulomb ポテンシャル $\varphi\sim ze/r$ と一致するように係数を定めると， $A=ze$ である．
したがって，

```math
\boxed{
\varphi(r)=\frac{ze}{r}e^{-\kappa r}
}
\tag{8}
```

を得る．
これは，点電荷のポテンシャルが距離とともに指数関数的に減衰することを示す遮蔽ポテンシャルである．

#### 4．電子密度の分布を求める

電子密度については，線形化した式 (3) より，

```math
n(r)\simeq n_0
\left(1+\frac{e\varphi(r)}{kT}\right)
```

である．
式 (8) を代入すれば，

```math
\boxed{
n(r)\simeq n_0+
\frac{zn_0e^2}{kT}
\frac{e^{-\kappa r}}{r}
}
\tag{9}
```

となる．
これは，正の点電荷の周囲で電子密度が $n_0$ より増加することを示す．

同じ結果は，式 (1) と式 (7) から

```math
n(r)-n_0=\frac{\kappa^2}{4\pi e}\varphi(r)
```

としても得られる．

したがって，高温で電子ガスが縮退していない場合の結果は，

```math
\boxed{
\begin{aligned}
\varphi(r)&=\frac{ze}{r}e^{-\kappa r},\\
n(r)&\simeq n_0+
\frac{zn_0e^2}{kT}\frac{e^{-\kappa r}}{r},\\
\kappa^2&=\frac{4\pi n_0e^2}{kT}
\end{aligned}
}
```

である．

### (ii) $T=0$ で完全に縮退した場合：Thomas–Fermi 遮蔽

#### 1．電子密度と最大運動量の関係

絶対零度では，電子は Pauli の排他原理に従い，運動量の小さい状態から順に占有する．
局所的な電子密度は，その位置で占有されている運動量状態の数によって定まる．

スピンの自由度が $2$ であることを考慮すると，位置 $r$ の電子数密度は，局所的な最大運動量を $P(r)$ として，

```math
\boxed{
n(r)=2\frac{4\pi}{3}\frac{P(r)^3}{h^3}
=\frac{8\pi}{3h^3}P(r)^3
}
\tag{10}
```

となる．
ここで， $h$ は Planck 定数である．

#### 2．平衡条件から最大運動量を求める

絶対零度での平衡状態では，電子の全エネルギーは位置によらず一定である．
電子の位置エネルギーが $-e\varphi(r)$ であることから，

```math
\frac{P(r)^2}{2m}-e\varphi(r)
=\frac{P_\infty^2}{2m}
\tag{11}
```

と書ける．
ここで， $m$ は電子の質量， $P_\infty$ は無限遠での最大運動量である．
式 (11) を変形すると，

```math
P(r)^2=P_\infty^2+2me\varphi(r)
\tag{12}
```

を得る．

式 (12) を式 (10) に代入すれば，

```math
n(r)=\frac{8\pi}{3h^3}
\left[P_\infty^2+2me\varphi(r)\right]^{3/2}
\tag{13}
```

である．

無限遠では $\varphi\to0$ ， $n\to n_0$ であるため，

```math
n_0=\frac{8\pi}{3h^3}P_\infty^3
\tag{14}
```

となる．
$h=2\pi\hbar$ を用いると，式 (14) は

```math
\boxed{
P_\infty=\hbar(3\pi^2n_0)^{1/3}
}
\tag{15}
```

と書き換えられる．
ここで $\hbar=h/(2\pi)$ は換算 Planck 定数である．

#### 3．電子密度を電位について一次まで展開する

点電荷から十分離れた領域では，ポテンシャルエネルギーの変化がフェルミエネルギーに比べて小さいと考えられる．
すなわち，

```math
\left|\frac{2me\varphi}{P_\infty^2}\right|\ll1
```

である．
式 (13) を書き換えると，

```math
n(r)=\frac{8\pi P_\infty^3}{3h^3}
\left(1+\frac{2me\varphi(r)}{P_\infty^2}\right)^{3/2}
```

となる．
ここで，

```math
(1+x)^{3/2}\simeq1+\frac32x
\qquad(|x|\ll1)
```

を用いると，

```math
\begin{aligned}
n(r)
&\simeq n_0
\left(1+\frac32\frac{2me\varphi(r)}{P_\infty^2}\right)\\
&=n_0+\frac{3me n_0}{P_\infty^2}\varphi(r)
\end{aligned}
\tag{16}
```

を得る．

さらに，式 (15) より

```math
P_\infty^2=\hbar^2(3\pi^2n_0)^{2/3}
```

である．
これを式 (16) の係数に代入すると，

```math
\begin{aligned}
\frac{3me n_0}{P_\infty^2}
&=\frac{3me n_0}
{\hbar^2(3\pi^2n_0)^{2/3}}\\
&=\frac{me}{\pi\hbar^2}
\left(\frac{3n_0}{\pi}\right)^{1/3}
\end{aligned}
```

となる．
したがって，正しい一次近似式は

```math
\boxed{
n(r)\simeq n_0+
\frac{me}{\pi\hbar^2}
\left(\frac{3n_0}{\pi}\right)^{1/3}\varphi(r)
}
\tag{17}
```

である．
ここでは，係数に $1/\pi$ が含まれることが重要である．

#### 4．Thomas–Fermi 遮蔽定数とポテンシャル

式 (17) を Poisson 方程式 (1) に代入すると，

```math
\begin{aligned}
\nabla^2\varphi
&=4\pi e[n(r)-n_0]\\
&\simeq
4\pi e\frac{me}{\pi\hbar^2}
\left(\frac{3n_0}{\pi}\right)^{1/3}\varphi\\
&=\frac{4me^2}{\hbar^2}
\left(\frac{3n_0}{\pi}\right)^{1/3}\varphi
\end{aligned}
\tag{18}
```

となる．
そこで Thomas–Fermi 遮蔽定数 $q$ を

```math
\boxed{
q^2=\frac{4me^2}{\hbar^2}
\left(\frac{3n_0}{\pi}\right)^{1/3}
}
\tag{19}
```

と定義すると，

```math
\nabla^2\varphi=q^2\varphi
\tag{20}
```

を得る．
これは (i) で得た線形方程式と同じ形である．
したがって，同じ境界条件を適用すると，

```math
\boxed{
\varphi(r)=\frac{ze}{r}e^{-qr}
}
\tag{21}
```

となる．

電子密度は式 (17) に式 (21) を代入すればよい．
また，式 (18) より

```math
n(r)-n_0=\frac{q^2}{4\pi e}\varphi(r)
```

であるから，

```math
\boxed{
n(r)\simeq n_0+\frac{zq^2}{4\pi r}e^{-qr}
}
\tag{22}
```

を得る．

したがって，絶対零度で完全に縮退した電子気体の場合の結果は，

```math
\boxed{
\begin{aligned}
\varphi(r)&=\frac{ze}{r}e^{-qr},\\[1mm]
n(r)&\simeq n_0+\frac{zq^2}{4\pi r}e^{-qr},\\[1mm]
q^2&=\frac{4me^2}{\hbar^2}
\left(\frac{3n_0}{\pi}\right)^{1/3}
\end{aligned}
}
```

である．

### まとめ

高温で電子ガスが縮退していない場合は Boltzmann 分布を用い，絶対零度で完全に縮退した場合は運動量空間の状態数とフェルミエネルギーの一定性を用いる．
どちらの場合も，電位が十分小さい領域で電子密度を一次まで展開することで，Poisson 方程式は線形化される．
その結果，ポテンシャルは指数関数的に減衰する形となる．

```math
\boxed{
\varphi(r)=\frac{ze}{r}e^{-\alpha r}
}
```

と書けば， $\alpha=\kappa$ は Debye 遮蔽定数， $\alpha=q$ は Thomas–Fermi 遮蔽定数である．
それぞれの電子密度は上記の一次近似式で与えられる．
なお，線形化は電位が小さい領域での近似であり，点電荷のごく近傍では一般に成立しない．
