# 演習問題【9-A-1】

## 解答

### はじめに

本問題では，強磁性体のモデルとして知られる Ising モデルについて，分子場近似（平均場近似）を用いてその熱力学的性質を調べる．
Ising モデルは，各スピンが隣接するスピンとの相互作用によって向きを決める系であり，統計力学における相転移の研究において非常に重要なモデルである．

分子場近似とは，あるスピンが受ける相互作用を，周囲のスピンの平均的な値（平均場）による効果として置き換える手法である．
これにより，多体問題を単一スピンの挙動を考える問題へと単純化することができる．

### 1. エネルギーと分子場近似

Ising モデルのハミルトニアン（全エネルギー）は，スピン $\sigma_i \in \{+1, -1\}$ の相互作用を用いて以下のように書ける：

$$H = -J \sum_{\langle i,j \rangle} \sigma_i \sigma_j$$

ここで， $J > 0$ は交換相互作用の強さ， $\sum_{\langle i,j \rangle}$ は隣接するスピン対についての和を表す．

分子場近似では，あるスピン $\sigma_i$ が受けるエネルギーを，周囲の $z$ 個のスピンの平均値 $X = \langle \sigma \rangle$ を用いた有効磁場 $h_{\text{eff}} = z J X$ によるものとみなす．
このとき，単一スピンのエネルギーは $-h_{\text{eff}} \sigma_i = -z J X \sigma_i$ となる．

系全体のエネルギー $E$ を計算すると，各スピンの相互作用を二重に数えないように注意して，次のように求められる：

$$E = -\frac{1}{2} z N J X^2$$

ここで， $N$ は全スピン数である．

### 2. 自己一致方程式とキュリー温度

単一スピンが有効磁場 $h_{\text{eff}}$ 中にあるときの統計力学的な平均値 $X$ は，ボルツマン分布を用いて次のように計算される：

$$X = \frac{e^{\beta z J X} - e^{-\beta z J X}}{e^{\beta z J X} + e^{-\beta z J X}} = \tanh(\beta z J X)$$

ここで $\beta = 1/kT$（$k$ はボルツマン定数，$T$ は絶対温度）である．

ここで， $T_c = zJ/k$ と定義すると，方程式は次のように書き換えられる：

$$\tanh\left(\frac{T_c}{T} X\right) = X$$

これが $X$ に関する自己一致方程式である．

この方程式の解を検討すると，
- $T > T_c$ のとき： $X=0$ （常磁性状態）のみが解となる．
- $T < T_c$ のとき： $X=0$ に加えて， $X \neq 0$ となる解（強磁性状態）が現れる．

この $T = T_c$ をキュリー温度と呼ぶ．

### 3. 比熱 $C$ の導出

比熱 $C$ はエネルギーの温度微分 $C = \frac{dE}{dT}$ で定義される．
$E = -\frac{1}{2} z N J X^2$ を $T$ で微分すると：

$$C = -z N J X \frac{dX}{dT}$$

ここで， $zJ/k = T_c$ より $zJ = k T_c$ であるから，

$$C = -N k T_c X \frac{dX}{dT} \tag{1}$$

となる．

次に，自己一致方程式 $\tanh(\frac{T_c}{T} X) = X$ を $T$ で微分する．
計算を簡略化するため，$x = \frac{T_c X}{T}$ とおくと，方程式は $\tanh x = \frac{X}{T_c/T} = \frac{X T}{T_c}$ となり，これは $X = \frac{T_c}{T} \tanh x$ である．

$\tanh(\frac{T_c}{T} X) = X$ を直接 $T$ で微分すると，

$$\frac{1}{\cosh^2(\frac{T_c}{T} X)} \left( -\frac{T_c}{T^2} X + \frac{T_c}{T} \frac{dX}{dT} \right) = \frac{dX}{dT}$$

整理すると，

$$\frac{dX}{dT} = -\frac{x}{\cosh^2 x - \frac{T_c}{T}} \tag{2}$$

（ここで $x = T_c X / T$ を用いた．）

これを式 (1) に代入し， $\frac{T_c}{T} = \frac{x}{\tanh x}$ という関係を用いると，比熱 $C$ は以下のように表される：

$$C = \frac{N k x^2}{\cosh^2 x - \frac{x}{\tanh x}}$$

#### 比熱の挙動の検討

- **キュリー温度付近 ( $T \to T_c^-$ )**：
  $T \approx T_c$ では $x$ は非常に小さい．
  $\tanh x \approx x - \frac{1}{3}x^3$ を用いて展開すると，
  $$X^2 \approx 3 \left( \frac{T_c}{T} - 1 \right)$$
  となり，これを用いると比熱は $T \to T_c$ で有限の値 $\frac{3}{2}Nk$ に不連続に跳ね上がる．
- **低温領域 ( $T \ll T_c$ )**：
  $T \to 0$ では $x \to \infty$ となる．
  このとき $\cosh x \approx \frac{1}{2} e^x$ であり， $\frac{x}{\tanh x} \approx x$ となる．
  したがって， $C \propto x^2 e^{-2x}$ の形となり， $T \to 0$ で指数関数的に $0$ に近づく．

### 4. エントロピー差 $\Delta S$ の計算

エントロピーの変化は，比熱を用いて次のように表される：

$$\Delta S = S(T) - S(0) = \int_0^T \frac{C}{T'} dT'$$

ここで， $C = -zNJX \frac{dX}{dT}$ であるから，

$$\Delta S = \int_{X(0)}^{X(T)} \frac{-zNJX}{T} \frac{dT}{dX} \frac{1}{T} \dots \text{ (変数を } X \text{ に変換する) }$$

具体的には， $\frac{dX}{dT}$ を用いて積分変数を $X$ に変換すると，

$$\Delta S = -zNJ \int_{X(0)}^{X(T)} \frac{X}{T} \frac{dT}{dX} dX$$

ここで $T/T_c = \tanh x / x$ などの関係を用い，計算を進めると（解答例のプロセスに従い），

$$\Delta S = -Nk \left\{ \frac{1}{2}(1+X)\log\left(\frac{1}{2}(1+X)\right) + \frac{1}{2}(1-X)\log\left(\frac{1}{2}(1-X)\right) \right\}$$

が得られる．

$T > T_c$ では $X=0$ であるため，

$$\Delta S = S(T > T_c) - S(0) = Nk \log 2$$

となる．
これは，スピンが完全にバラバラな状態（エントロピー最大）と，完全に揃った状態（エントロピー最小）の差として物理的に正当である．

## 解説

本演習では，Ising モデルの分子場近似を通じて，強磁性相転移の基本的な性質を学んだ．

### 1.  相転移の理解

温度がキュリー温度 $T_c$ を下回ると，自発的にスピンが揃い，磁化 $X$ が現れる．
これは，スピン間の相互作用が熱運動による乱れに打ち勝つためである．

### 2.  比熱の不連続性

$T_c$ において比熱が不連続に変化するのは，系の秩序（スピンの揃い具合）が急激に変化することに対応している．

### 3.  エントロピーの意味

最後に求めた $\Delta S = Nk \log 2$ は，各スピンが $2$ つの状態（上向き・下向き）から自由に入れ替われる状態から，一つの状態に固定されるまでのエントロピーの変化量を表している．
