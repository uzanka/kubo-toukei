# 演習問題【9-A-1】

## 解答

### 1．分子場近似と自己無撞着方程式

スピンの値を $\sigma_i=\pm1$ ，隣接するスピン間の交換相互作用を $J>0$ ，1つのスピンに隣接するスピンの数を $z$ とする．
スピン間の相互作用を表す Ising モデルのハミルトニアンは

```math
H=-J\sum_{\langle i,j\rangle}\sigma_i\sigma_j
```

である．
ここで， $\langle i,j\rangle$ は隣接するスピン対についての和を表す．

分子場近似では，各スピンが周囲から受ける相互作用を，周囲のスピンの平均値

```math
X=\langle\sigma_i\rangle
```

を用いて表す．
このとき，系全体の内部エネルギー $E$ は

```math
\boxed{E=-\frac12 zNJX^2}
\tag{1}
```

となる．
ここで， $N$ はスピンの総数であり，係数 $1/2$ は隣接するスピン対を二重に数えないために必要である．

分子場中の1つのスピンのエネルギーは $-zJX\sigma_i$ であるから，ボルツマン分布に従ってスピンの平均値を計算すると，

```math
X=\frac{e^{\beta zJX}-e^{-\beta zJX}}
{e^{\beta zJX}+e^{-\beta zJX}}
=\tanh\left(\frac{zJX}{kT}\right)
\tag{2}
```

となる．
ここで， $\beta=1/(kT)$ である．

Curie 温度を

```math
\boxed{T_c=\frac{zJ}{k}}
\tag{3}
```

と定義すると，式 (2) は

```math
\boxed{
X=\tanh\left(\frac{T_c}{T}X\right)
}
\tag{4}
```

となる．
これが磁化 $X$ を決定する自己無撞着方程式である．

$T>T_c$ では平衡解は $X=0$ であり，常磁性状態となる．
一方， $T<T_c$ では，平衡状態として $X\neq0$ の解が現れ，自発磁化をもつ強磁性状態となる．
以下では，この強磁性状態のうち $X\geq0$ の解を考える．

### 2．比熱の導出

比熱 $C$ は，温度一定の制約ではなく，体積とスピン数を一定に保って内部エネルギーを温度で微分した量である．
したがって，

```math
C=\frac{dE}{dT}
```

である．
式 (1) より，

```math
\boxed{
C=-zNJX\frac{dX}{dT}
}
\tag{5}
```

となる．

次に，式 (4) を温度 $T$ で微分する．
計算を簡単にするため，

```math
x=\frac{T_cX}{T}
\tag{6}
```

とおくと，式 (4) より

```math
X=\tanh x
\tag{7}
```

および

```math
\boxed{
\frac{T}{T_c}=\frac{\tanh x}{x}
}
\tag{8}
```

が得られる．

式 (4) を直接温度で微分すると，

```math
\frac{1}{\cosh^2x}
\left(
-\frac{T_cX}{T^2}
+\frac{T_c}{T}\frac{dX}{dT}
\right)
=\frac{dX}{dT}
\tag{9}
```

となる．
ここで， $T_cX/T=x$ を用いて整理すれば，

```math
\boxed{
\frac{dX}{dT}
=-\frac{x}
{T\left(\cosh^2x-\dfrac{T_c}{T}\right)}
}
\tag{10}
```

を得る．
さらに，式 (8) より

```math
\frac{T_c}{T}=\frac{x}{\tanh x}
\tag{11}
```

である．
式 (10)，(11) を式 (5) に代入し， $zJ=kT_c$ ， $X=Tx/T_c$ を使って整理すると，

```math
\boxed{
C=
Nk\frac{x^2}
{\cosh^2x-\dfrac{x}{\tanh x}}
}
\tag{12}
```

が得られる．

式 (8) と式 (12) によって， $x$ を媒介変数として，比熱 $C$ を温度 $T/T_c$ の関数として表すことができる．
$T\to T_c-0$ では $x\to0$ ， $T\to0$ では $x\to\infty$ となる．

### 3．Curie 温度近傍の比熱

まず， $T$ が $T_c$ に近い場合を考える．
このとき $X$ は小さいので，

```math
\tanh y=y-\frac{y^3}{3}+O(y^5)
```

を用いて，式 (4) を展開すると，

```math
X=\frac{T_c}{T}X
-\frac13\left(\frac{T_c}{T}\right)^3X^3
+O(X^5)
\tag{13}
```

となる．
強磁性状態の解 $X\neq0$ について両辺を整理すると，

```math
X^2\approx
3\frac{\dfrac{T_c}{T}-1}
{\left(\dfrac{T_c}{T}\right)^3}
\tag{14}
```

を得る．
特に $T\approx T_c$ では，

```math
\boxed{
X^2\approx3\frac{T_c-T}{T_c}
}
\tag{15}
```

である．

式 (1) に式 (15) を代入すると，

```math
E\approx
-\frac32 Nk(T_c-T)
\qquad (T\to T_c-0)
\tag{16}
```

となる．
したがって，比熱は

```math
\boxed{
C(T\to T_c-0)=\frac32 Nk
}
\tag{17}
```

である．

一方， $T>T_c$ では平衡状態は $X=0$ であり，式 (1) より内部エネルギーは $E=0$ となる．
したがって，

```math
\boxed{
C(T\to T_c+0)=0
}
\tag{18}
```

である．

よって，分子場近似では Curie 温度において比熱が不連続に変化する．
その不連続量は

```math
\boxed{
C(T_c-0)-C(T_c+0)=\frac32 Nk
}
\tag{19}
```

となる．

### 4．低温 $T\ll T_c$ における比熱

次に，温度が Curie 温度に比べて十分低い場合を考える．
式 (8) より，

```math
\frac{T}{T_c}=\frac{\tanh x}{x}
```

であり， $T\to0$ では $x\to\infty$ となる．
このとき，

```math
\tanh x\approx1,\qquad
\cosh^2x\approx\frac14e^{2x}
\tag{20}
```

であるから，

```math
x\approx\frac{T_c}{T}
\tag{21}
```

となる．
また， $x\gg1$ では

```math
\cosh^2x\gg\frac{x}{\tanh x}
```

であるため，式 (12) は

```math
C\approx4Nkx^2e^{-2x}
\tag{22}
```

と近似できる．
式 (21) を代入すると，

```math
\boxed{
C\approx4Nk\left(\frac{T_c}{T}\right)^2
\exp\left(-\frac{2T_c}{T}\right)
}
\tag{23}
```

を得る．
したがって，低温では比熱は指数関数的に減少し， $T\to0$ で急速にゼロに近づく．

### 5．エントロピー差 $\Delta S=S(T)-S(0)$ の導出

エントロピーの温度変化は，比熱を用いて

```math
\Delta S=S(T)-S(0)
=\int_0^T\frac{C(T')}{T'}\,dT'
\tag{24}
```

と表される．
式 (5) より，

```math
dS=\frac{C}{T}\,dT
=-zNJ\frac{X}{T}\,dX
\tag{25}
```

である．

ここで，自己無撞着方程式 (4) を逆関数で表すと，

```math
\operatorname{artanh}X=\frac{T_cX}{T}
=\frac{zJX}{kT}
\tag{26}
```

となる．
したがって，

```math
\frac{zJX}{T}=k\operatorname{artanh}X
```

であるから，式 (25) は

```math
\boxed{
dS=-Nk\operatorname{artanh}X\,dX
}
\tag{27}
```

となる．

絶対零度では $X=1$ であり，スピンが完全に揃った状態のエントロピーを $S(0)=0$ とする．
温度を上げると $X$ は $1$ からその温度に対応する値 $X$ まで減少する．
したがって，

```math
\Delta S
=-Nk\int_1^X\operatorname{artanh}u\,du
\tag{28}
```

である．
ここで，

```math
\int\operatorname{artanh}u\,du
=\frac12\left[
(1+u)\log(1+u)
+(1-u)\log(1-u)
\right]
\tag{29}
```

を用いる．
式 (28)，(29) より，

```math
\boxed{
\begin{aligned}
\Delta S
={}&Nk\log2\\
&-\frac{Nk}{2}
\left[
(1+X)\log(1+X)
+(1-X)\log(1-X)
\right]
\end{aligned}
}
\tag{30}
```

となる．
同じ結果を，スピンが上向きと下向きである割合

```math
\frac{1+X}{2},\qquad\frac{1-X}{2}
```

を用いて書けば，

```math
\boxed{
\begin{aligned}
\Delta S=-Nk\bigg\{&
\frac{1+X}{2}
\log\frac{1+X}{2}\\
&+\frac{1-X}{2}
\log\frac{1-X}{2}
\bigg\}
\end{aligned}
}
\tag{31}
```

である．
ここで $X$ は，式 (4) から定まる温度 $T$ における磁化である．

特に $T>T_c$ では， $X=0$ であるから，式 (31) より，

```math
\boxed{
S(T>T_c)-S(0)=Nk\log2
}
\tag{32}
```

となる．
これは，高温では各スピンが上向きと下向きの2状態を等確率でとり，1スピン当たり $k\log2$ のエントロピーをもつためである．
一方，絶対零度ではスピンが揃い，エントロピーはゼロであるため，両者のエントロピー差は $Nk\log2$ となる．

以上より，分子場近似では，Curie 温度で比熱が不連続に変化し，低温では比熱が指数関数的にゼロへ近づくこと，さらに $T>T_c$ でのエントロピー差が $Nk\log2$ となることが示された．
