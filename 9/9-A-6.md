# 演習問題【9-A-6】

## 解答

### 1．モデルの仮定

成分 A と成分 B からなる二成分溶液を考える．
それぞれの分子数を $N_{\mathrm A}$ ， $N_{\mathrm B}$ ，全分子数を

```math
N=N_{\mathrm A}+N_{\mathrm B}
```

とする．
格子点はすべて A または B の分子で占有され，空格子点は存在しないものとする．

各格子点の最近接点の数を $z$ とし，最近接分子間の相互作用のみを考える．
A–A，A–B，B–B の分子対の相互作用エネルギーをそれぞれ $v_{\mathrm{AA}}$ ， $v_{\mathrm{AB}}$ ， $v_{\mathrm{BB}}$ とする．
これらは組成や温度によらない定数とする．

さらに，以下を仮定する．

- 格子は十分大きく，表面効果は無視できる．
- 各格子点の配位数 $z$ は一定である．
- Bragg–Williams 近似を用い，隣接サイトの占有に相関はないものとする．
- 分子数は十分大きく，配置エントロピーの計算には Stirling 近似を用いる．

格子点一つ当たりの体積を $v_0$ とする非圧縮格子溶液を考え，体積を

```math
V=v_0N
```

とする．
したがって，分子数の変化に伴って体積も変化する．
この条件のもとで，化学ポテンシャルは一定温度・一定圧力における Gibbs 自由エネルギーから求める．

モル分率に相当する濃度を

```math
x_{\mathrm A}=\frac{N_{\mathrm A}}{N},
\qquad
x_{\mathrm B}=\frac{N_{\mathrm B}}{N}
```

と定義する．
当然，

```math
x_{\mathrm A}+x_{\mathrm B}=1
```

である．

### 2．内部エネルギー $E$ の導出

A–A，A–B，B–B の分子対の数をそれぞれ $N_{\mathrm{AA}}$ ， $N_{\mathrm{AB}}$ ， $N_{\mathrm{BB}}$ とする．
全エネルギーは

```math
E=v_{\mathrm{AA}}N_{\mathrm{AA}}
+v_{\mathrm{AB}}N_{\mathrm{AB}}
+v_{\mathrm{BB}}N_{\mathrm{BB}}
\tag{1}
```

である．

Bragg–Williams 近似では，各分子の隣接サイトにどの成分が存在するかは，溶液全体の組成によって決まると考える．
したがって，A 分子の最近接サイトに A 分子が存在する確率は $x_{\mathrm A}$ ，B 分子が存在する確率は $x_{\mathrm B}$ である．

同種分子対では各対を二度数えるため $1/2$ を掛ける．
異種分子対では A 分子側から数えれば各対を一度だけ数えるので，

```math
N_{\mathrm{AA}}
=\frac{z}{2}N_{\mathrm A}x_{\mathrm A}
=\frac{zN_{\mathrm A}^{2}}{2N}
```

```math
N_{\mathrm{BB}}
=\frac{z}{2}N_{\mathrm B}x_{\mathrm B}
=\frac{zN_{\mathrm B}^{2}}{2N}
```

```math
N_{\mathrm{AB}}
=zN_{\mathrm A}x_{\mathrm B}
=\frac{zN_{\mathrm A}N_{\mathrm B}}{N}
\tag{2}
```

となる．

なお，これらの対の数の和は

```math
N_{\mathrm{AA}}+N_{\mathrm{AB}}+N_{\mathrm{BB}}
=\frac{zN}{2}
```

となり，格子全体の最近接対の総数と一致する．

式 (2) を式 (1) に代入すると，

```math
E=\frac{z}{2N}
\left(
v_{\mathrm{AA}}N_{\mathrm A}^{2}
+2v_{\mathrm{AB}}N_{\mathrm A}N_{\mathrm B}
+v_{\mathrm{BB}}N_{\mathrm B}^{2}
\right)
\tag{3}
```

を得る．

次に，純粋な A および純粋な B の状態を基準とするエネルギーを

```math
E_0=\frac z2v_{\mathrm{AA}}N_{\mathrm A}
+\frac z2v_{\mathrm{BB}}N_{\mathrm B}
\tag{4}
```

とおく．
また，相互作用の差を表すパラメータ $v$ を

```math
v=\frac12(v_{\mathrm{AA}}+v_{\mathrm{BB}})-v_{\mathrm{AB}}
\tag{5}
```

と定義する．

式 (3) と式 (4) の差を計算すると，

```math
\begin{aligned}
E-E_0
&=-\frac{z}{2N}
(v_{\mathrm{AA}}+v_{\mathrm{BB}}-2v_{\mathrm{AB}})
N_{\mathrm A}N_{\mathrm B}\\
&=-zv\frac{N_{\mathrm A}N_{\mathrm B}}{N}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
E=E_0-zv\frac{N_{\mathrm A}N_{\mathrm B}}{N}
=E_0-Nzv x_{\mathrm A}x_{\mathrm B}
}
\tag{6}
```

を得る．

ここで $E_0$ は純粋成分を基準とした参照エネルギーであり，式 (6) の第2項が混合によるエネルギー変化を表す．

### 3．配置エントロピー $S$ と自由エネルギー $F$

格子点の総数は $N$ であり，そのうち $N_{\mathrm A}$ 個に A 分子，残りの $N_{\mathrm B}$ 個に B 分子を配置する．
したがって，配置の総数 $W$ は

```math
W=\frac{N!}{N_{\mathrm A}!N_{\mathrm B}!}
\tag{7}
```

である．

Boltzmann の原理 $S=k\ln W$ より，

```math
S=k\ln\frac{N!}{N_{\mathrm A}!N_{\mathrm B}!}
\tag{8}
```

となる．

分子数が十分大きい場合，Stirling の公式

```math
\ln m!\simeq m\ln m-m
```

を適用できる．
これにより，

```math
\begin{aligned}
S
&=k(N\ln N-N_{\mathrm A}\ln N_{\mathrm A}
-N_{\mathrm B}\ln N_{\mathrm B})\\
&=-k\left(
N_{\mathrm A}\ln x_{\mathrm A}
+N_{\mathrm B}\ln x_{\mathrm B}
\right)
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
S=-k\left(
N_{\mathrm A}\ln x_{\mathrm A}
+N_{\mathrm B}\ln x_{\mathrm B}
\right)
}
\tag{9}
```

である．

体積一定の条件で定義される Helmholtz 自由エネルギーは $F=E-TS$ である．
式 (6)，(9) より，

```math
\boxed{
\begin{aligned}
F={}&E_0-Nzv x_{\mathrm A}x_{\mathrm B}\\
&+NkT\left(
x_{\mathrm A}\ln x_{\mathrm A}
+x_{\mathrm B}\ln x_{\mathrm B}
\right)
\end{aligned}
}
\tag{10}
```

となる．
ここでは，格子点数 $N$ を固定した組成変化に対する Helmholtz 自由エネルギーを表している．

### 4．各成分の化学ポテンシャル

空格子点のない格子モデルでは，格子点数と分子数の和が等しいため，

```math
N=N_{\mathrm A}+N_{\mathrm B}
```

である．
このため，体積一定のまま一方の分子数だけを独立に変えることはできない．
そこで，非圧縮格子溶液として $V=v_0N$ とし，一定温度・一定圧力での Gibbs 自由エネルギー

```math
G=F+PV
=F+Pv_0(N_{\mathrm A}+N_{\mathrm B})
\tag{11}
```

を用いる．
ここで $P$ は圧力であり， $v_0$ は格子点一つ当たりの一定体積である．

化学ポテンシャルは，

```math
\mu_{\mathrm A}
=\left(\frac{\partial G}{\partial N_{\mathrm A}}\right)_{T,P,N_{\mathrm B}},
\qquad
\mu_{\mathrm B}
=\left(\frac{\partial G}{\partial N_{\mathrm B}}\right)_{T,P,N_{\mathrm A}}
\tag{12}
```

で定義される．

まず，式 (4) より，

```math
\frac{\partial E_0}{\partial N_{\mathrm A}}
=\frac z2v_{\mathrm{AA}}
```

である．
また， $N=N_{\mathrm A}+N_{\mathrm B}$ であることから，

```math
\frac{\partial}{\partial N_{\mathrm A}}
\left(\frac{N_{\mathrm A}N_{\mathrm B}}{N}\right)
=\frac{N_{\mathrm B}^{2}}{N^{2}}
=x_{\mathrm B}^{2}
```

となる．

エントロピーに由来する項については，

```math
\frac{\partial}{\partial N_{\mathrm A}}
\left(
N_{\mathrm A}\ln x_{\mathrm A}
+N_{\mathrm B}\ln x_{\mathrm B}
\right)
=\ln x_{\mathrm A}
```

である．
さらに，

```math
\frac{\partial}{\partial N_{\mathrm A}}
\left[ Pv_0(N_{\mathrm A}+N_{\mathrm B})\right]
=Pv_0
```

である．
したがって，

```math
\boxed{
\mu_{\mathrm A}
=\frac z2v_{\mathrm{AA}}
-zv x_{\mathrm B}^{2}
+kT\ln x_{\mathrm A}
+Pv_0
}
\tag{13}
```

を得る．

同様に，

```math
\frac{\partial E_0}{\partial N_{\mathrm B}}
=\frac z2v_{\mathrm{BB}}
```

```math
\frac{\partial}{\partial N_{\mathrm B}}
\left(\frac{N_{\mathrm A}N_{\mathrm B}}{N}\right)
=x_{\mathrm A}^{2}
```

であり，エントロピー項の微分は $\ln x_{\mathrm B}$ となる．
よって，

```math
\boxed{
\mu_{\mathrm B}
=\frac z2v_{\mathrm{BB}}
-zv x_{\mathrm A}^{2}
+kT\ln x_{\mathrm B}
+Pv_0
}
\tag{14}
```

である．

以上が，非圧縮格子溶液モデルにおける各成分の化学ポテンシャルである．
圧力項 $Pv_0$ は両成分に共通であるため，化学ポテンシャル差では相殺される．

```math
\boxed{
\begin{aligned}
\mu_{\mathrm A}-\mu_{\mathrm B}
={}&\frac z2(v_{\mathrm{AA}}-v_{\mathrm{BB}})\\
&-zv(x_{\mathrm B}^{2}-x_{\mathrm A}^{2})
+kT\ln\frac{x_{\mathrm A}}{x_{\mathrm B}}
\end{aligned}
}
\tag{15}
```

### 5．混ざりやすい場合と混ざりにくい場合

混合による自由エネルギー変化を考えるため，純粋成分の基準エネルギー $E_0$ を差し引いた1分子当たりの混合自由エネルギーを

```math
\boxed{
\Delta f_{\mathrm{mix}}
=-zv x_{\mathrm A}x_{\mathrm B}
+kT\left(
x_{\mathrm A}\ln x_{\mathrm A}
+x_{\mathrm B}\ln x_{\mathrm B}
\right)
}
\tag{16}
```

と定義する．

ここで $x_{\mathrm B}=1-x_{\mathrm A}$ である．

#### 5.1 $v>0$ の場合

式 (5) より，

```math
v_{\mathrm{AB}}
<\frac12(v_{\mathrm{AA}}+v_{\mathrm{BB}})
```

である．
すなわち，異種分子対を形成する方が，同種分子対の平均的な相互作用と比較してエネルギー的に有利である．

この場合，混合によるエネルギー変化は

```math
-zv x_{\mathrm A}x_{\mathrm B}<0
```

となり，混合によってエネルギーが低下する．
また，配置エントロピーも混合状態を安定化する．

実際，混合自由エネルギーの組成に関する二階微分は，

```math
\frac{\partial^2\Delta f_{\mathrm{mix}}}
{\partial x_{\mathrm A}^{2}}
=2zv+\frac{kT}{x_{\mathrm A}x_{\mathrm B}}
\tag{17}
```

である．
$v>0$ ， $T>0$ ， $0<x_{\mathrm A},x_{\mathrm B}<1$ では，

```math
\frac{\partial^2\Delta f_{\mathrm{mix}}}
{\partial x_{\mathrm A}^{2}}>0
```

が常に成り立つ．
したがって，混合自由エネルギーは組成に関して凸であり，この近似では均一混合状態が安定で，相分離は起こらない．

#### 5.2 $v=0$ の場合

この場合，

```math
v_{\mathrm{AB}}
=\frac12(v_{\mathrm{AA}}+v_{\mathrm{BB}})
```

であり，混合によるエネルギー変化はゼロである．
混合自由エネルギーは

```math
\Delta f_{\mathrm{mix}}
=kT\left(
x_{\mathrm A}\ln x_{\mathrm A}
+x_{\mathrm B}\ln x_{\mathrm B}
\right)
```

となる．
これは理想混合に対応し， $T>0$ では曲率が正であるため，均一混合状態が安定である．

#### 5.3 $v<0$ の場合

式 (5) より，

```math
v_{\mathrm{AB}}
>\frac12(v_{\mathrm{AA}}+v_{\mathrm{BB}})
```

である．
すなわち，異種分子対を形成するよりも，同種分子同士が集まる方がエネルギー的に有利である．

この場合，

```math
-zv x_{\mathrm A}x_{\mathrm B}>0
```

となり，混合によってエネルギーが増加する．
一方，配置エントロピーの増加は混合状態を安定化するため，温度によって両者の競合が変化する．

式 (17) の曲率がゼロになる条件は，

```math
2zv+\frac{kT}{x_{\mathrm A}x_{\mathrm B}}=0
```

である．
したがって，

```math
T=-\frac{2zv}{k}x_{\mathrm A}x_{\mathrm B}
=\frac{2z|v|}{k}x_{\mathrm A}x_{\mathrm B}
\tag{18}
```

となる．

ここで，

```math
x_{\mathrm A}x_{\mathrm B}
=x_{\mathrm A}(1-x_{\mathrm A})
\leq\frac14
```

であり，等号は $x_{\mathrm A}=x_{\mathrm B}=1/2$ のときに成立する．
したがって，曲率がゼロとなる温度の最大値は，

```math
\boxed{
T_c=\frac{z|v|}{2k}
}
\tag{19}
```

である．

臨界点では，曲率がゼロになるだけでなく，曲率が極値をとる条件も満たす．
実際，

```math
\frac{\partial^3\Delta f_{\mathrm{mix}}}
{\partial x_{\mathrm A}^{3}}
=kT\left[
-\frac{1}{x_{\mathrm A}^{2}}
+\frac{1}{x_{\mathrm B}^{2}}
\right]
```

であるため， $x_{\mathrm A}=x_{\mathrm B}=1/2$ では三階微分もゼロとなる．
よって，式 (19) は対称な二成分格子溶液の臨界温度である．

$T>T_c$ では，すべての組成で曲率が正となり，均一混合状態が安定である．

一方， $T<T_c$ では，曲率が負となる組成域が現れる．
この領域はスピノーダル領域と呼ばれ，均一混合状態は局所的にも不安定となる．
ただし，曲率が正であっても，均一混合状態が全体として最も安定とは限らない．
二相共存領域は，混合自由エネルギーに対する共通接線条件によって決定される．
この領域はビノーダル領域と呼ばれ，スピノーダル領域を含む．

したがって， $T<T_c$ では組成によって A に富む相と B に富む相への相分離が起こり得るが，すべての組成が必ず二相分離するわけではない．

### 6．結論

Bragg–Williams 近似による二成分格子溶液の Helmholtz 自由エネルギーは，

```math
\boxed{
\begin{aligned}
F={}&E_0-Nzv x_{\mathrm A}x_{\mathrm B}\\
&+NkT\left(
x_{\mathrm A}\ln x_{\mathrm A}
+x_{\mathrm B}\ln x_{\mathrm B}
\right)
\end{aligned}
}
```

である．

非圧縮格子溶液として $V=v_0N$ を仮定した場合，各成分の化学ポテンシャルは，

```math
\boxed{
\mu_{\mathrm A}
=\frac z2v_{\mathrm{AA}}
-zv x_{\mathrm B}^{2}
+kT\ln x_{\mathrm A}
+Pv_0
}
```

```math
\boxed{
\mu_{\mathrm B}
=\frac z2v_{\mathrm{BB}}
-zv x_{\mathrm A}^{2}
+kT\ln x_{\mathrm B}
+Pv_0
}
```

である．

$v>0$ では異種分子対の形成がエネルギー的に有利であり，エネルギーとエントロピーの両方が混合を促進するため，均一混合状態が安定である．
$v=0$ では理想混合となる．
一方， $v<0$ では異種分子対の形成がエネルギー的に不利であり，低温では相分離が起こり得る．
対称な組成 $x_{\mathrm A}=x_{\mathrm B}=1/2$ における臨界温度は，

```math
\boxed{
T_c=\frac{z|v|}{2k}
}
```

である．

なお，Bragg–Williams 近似は隣接分子間の局所的な組成相関を無視する平均場近似である．
したがって，実際の液体における短距離秩序や，平均場近似からの揺らぎの補正までは記述しない．
