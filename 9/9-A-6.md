# 演習問題【9-A-6】

## 解答

### 1．内部エネルギー $E$ の導出

成分 A と成分 B からなる2成分溶液を考え，それぞれの分子数を $N_{\mathrm A}$ ， $N_{\mathrm B}$ ，全分子数を

```math
N=N_{\mathrm A}+N_{\mathrm B}
```

とする．
各格子点の最隣接点の数を $z$ とし，分子間の相互作用は最隣接分子間のみを考える．

A–A，A–B，B–B の分子対の数をそれぞれ $N_{\mathrm{AA}}$ ， $N_{\mathrm{AB}}$ ， $N_{\mathrm{BB}}$ ，それらの相互作用エネルギーを $v_{\mathrm{AA}}$ ， $v_{\mathrm{AB}}$ ， $v_{\mathrm{BB}}$ とする．
このとき，全エネルギーは

```math
E=v_{\mathrm{AA}}N_{\mathrm{AA}}
+v_{\mathrm{AB}}N_{\mathrm{AB}}
+v_{\mathrm{BB}}N_{\mathrm{BB}}
\tag{1}
```

である．

Bragg–Williams 近似では，各分子の隣接サイトにどの成分が存在するかは，溶液全体の組成によって決まると仮定する．
モル分率に相当する濃度を

```math
x_{\mathrm A}=\frac{N_{\mathrm A}}{N},\qquad
x_{\mathrm B}=\frac{N_{\mathrm B}}{N}
```

とすると，原子対の数は

```math
N_{\mathrm{AA}}=\frac{z}{2}N_{\mathrm A}x_{\mathrm A}
=\frac{zN_{\mathrm A}^2}{2N}
```

```math
N_{\mathrm{BB}}=\frac{z}{2}N_{\mathrm B}x_{\mathrm B}
=\frac{zN_{\mathrm B}^2}{2N}
```

```math
N_{\mathrm{AB}}=zN_{\mathrm A}x_{\mathrm B}
=\frac{zN_{\mathrm A}N_{\mathrm B}}{N}
\tag{2}
```

となる．
同種分子対では各対を2回数えるため $1/2$ を掛けるが，異種分子対では A 分子側から数えれば各対を1回だけ数えるので，その係数は不要である．

式 (2) を式 (1) に代入すると，

```math
E=\frac{z}{2N}
\left(
v_{\mathrm{AA}}N_{\mathrm A}^2
+2v_{\mathrm{AB}}N_{\mathrm A}N_{\mathrm B}
+v_{\mathrm{BB}}N_{\mathrm B}^2
\right)
\tag{3}
```

を得る．

次に，A と B がそれぞれ純粋な状態で存在するときのエネルギーを

```math
E_0=\frac z2v_{\mathrm{AA}}N_{\mathrm A}
+\frac z2v_{\mathrm{BB}}N_{\mathrm B}
\tag{4}
```

とおく．
また，相互作用の差を表すパラメータ $v$ を

```math
\boxed{
v=\frac12(v_{\mathrm{AA}}+v_{\mathrm{BB}})-v_{\mathrm{AB}}
}
\tag{5}
```

と定義する．
式 (3) を整理すると，

```math
\boxed{
E=E_0-zv\frac{N_{\mathrm A}N_{\mathrm B}}{N}
=E_0-Nzv x_{\mathrm A}x_{\mathrm B}
}
\tag{6}
```

となる．
ここで $E_0$ は混合によって変化しない基準エネルギーである．

### 2．配置エントロピー $S$ と自由エネルギー $F$

Bragg–Williams 近似では，配置の数は分子を格子点に並べる組合せの数として評価される．
その総数 $W$ は

```math
W=\frac{(N_{\mathrm A}+N_{\mathrm B})!}
{N_{\mathrm A}!N_{\mathrm B}!}
\tag{7}
```

である．
Boltzmann の原理 $S=k\log W$ を用いると，

```math
S=k\log\frac{N!}{N_{\mathrm A}!N_{\mathrm B}!}
\tag{8}
```

となる．
分子数が十分大きい場合，Stirling の公式

```math
\log m!\approx m\log m-m
```

を適用できる．
これにより，

```math
\boxed{
S=-k\left(
N_{\mathrm A}\log x_{\mathrm A}
+N_{\mathrm B}\log x_{\mathrm B}
\right)
}
\tag{9}
```

を得る．

体積一定のもとでのヘルムホルツ自由エネルギーは $F=E-TS$ である．
式 (6)，(9) より，

```math
\boxed{
\begin{aligned}
F={}&E_0-Nzv x_{\mathrm A}x_{\mathrm B}\\
&+NkT\left(
x_{\mathrm A}\log x_{\mathrm A}
+x_{\mathrm B}\log x_{\mathrm B}
\right)
\end{aligned}
}
\tag{10}
```

となる．
これが Bragg–Williams 近似による自由エネルギーである．
第2項は混合によるエネルギー変化を，第3項は混合による配置エントロピーの寄与を表す．

### 3．各成分の化学ポテンシャル

化学ポテンシャルは，温度と体積を一定にして，その成分の分子数を変化させたときの自由エネルギーの変化率である．
したがって，

```math
\mu_{\mathrm A}
=\left(\frac{\partial F}{\partial N_{\mathrm A}}\right)_{T,V,N_{\mathrm B}},
\qquad
\mu_{\mathrm B}
=\left(\frac{\partial F}{\partial N_{\mathrm B}}\right)_{T,V,N_{\mathrm A}}
\tag{11}
```

で定義される．
ここでは，微分するとき他方の成分の分子数を固定することが重要である．

まず，式 (10) のエネルギー項について， $N_{\mathrm B}$ を固定して $N_{\mathrm A}$ で微分すると，

```math
\frac{\partial E_0}{\partial N_{\mathrm A}}
=\frac z2v_{\mathrm{AA}}
```

および

```math
\frac{\partial}{\partial N_{\mathrm A}}
\left(-zv\frac{N_{\mathrm A}N_{\mathrm B}}{N}\right)
=-zv\frac{N_{\mathrm B}^2}{N^2}
=-zv x_{\mathrm B}^2
\tag{12}
```

となる．
また，配置エントロピーに由来する項については，

```math
\frac{\partial}{\partial N_{\mathrm A}}
\left[
N_{\mathrm A}\log x_{\mathrm A}
+N_{\mathrm B}\log x_{\mathrm B}
\right]
=\log x_{\mathrm A}
\tag{13}
```

である．
したがって，

```math
\boxed{
\mu_{\mathrm A}
=\frac z2v_{\mathrm{AA}}
-zv x_{\mathrm B}^2
+kT\log x_{\mathrm A}
}
\tag{14}
```

を得る．

同様に， $N_{\mathrm A}$ を固定して $N_{\mathrm B}$ で微分すると，

```math
\boxed{
\mu_{\mathrm B}
=\frac z2v_{\mathrm{BB}}
-zv x_{\mathrm A}^2
+kT\log x_{\mathrm B}
}
\tag{15}
```

となる．
これらが各成分の化学ポテンシャルである．

### 4．混ざりやすい場合と混ざりにくい場合

混合による自由エネルギー変化を考えるため，純粋な成分の基準エネルギー $E_0$ を差し引き，1分子当たりの混合自由エネルギーを

```math
\boxed{
\Delta f_{\mathrm{mix}}
=-zv x_{\mathrm A}x_{\mathrm B}
+kT\left(
x_{\mathrm A}\log x_{\mathrm A}
+x_{\mathrm B}\log x_{\mathrm B}
\right)
}
\tag{16}
```

と定義する．

#### $v>0$ の場合

式 (5) より，

```math
v_{\mathrm{AB}}
<\frac12(v_{\mathrm{AA}}+v_{\mathrm{BB}})
```

である．
すなわち，異種分子対を形成する方が，同種分子対の平均的な相互作用と比較してエネルギー的に有利である．
式 (16) のエネルギー寄与は

```math
-zv x_{\mathrm A}x_{\mathrm B}<0
```

となり，混合によってエネルギーが低下する．
また，混合によって配置エントロピーも増加するため，両方の効果が混合状態を安定化する．

実際，濃度 $x_{\mathrm A}$ に関する自由エネルギーの曲率は，

```math
\frac{\partial^2\Delta f_{\mathrm{mix}}}{\partial x_{\mathrm A}^2}
=2zv+\frac{kT}{x_{\mathrm A}x_{\mathrm B}}
\tag{17}
```

であり， $v>0$ では常に正である．
したがって，この近似では自由エネルギーは組成に関して凸であり，相分離を起こさず，均一な混合状態が安定である．

ただし，これはランダム混合を仮定したモデルの結論である．
結晶性合金では，異種原子が特定の位置に規則的に配列する規則格子が形成される場合があり，そのような秩序化は別の規則度を導入して扱う必要がある．

#### $v<0$ の場合

式 (5) より，

```math
v_{\mathrm{AB}}
>\frac12(v_{\mathrm{AA}}+v_{\mathrm{BB}})
```

となり，異種分子対を形成するよりも，同種分子同士が集まる方がエネルギー的に有利である．
この場合，

```math
-zv x_{\mathrm A}x_{\mathrm B}>0
```

であるため，混合によってエネルギーが増加する．
一方，混合による配置エントロピーの増加は混合状態を安定化するため，温度によって両者の競合が変化する．

式 (17) の曲率がゼロになる条件を考えると，

```math
2zv+\frac{kT}{x_{\mathrm A}x_{\mathrm B}}=0
```

より，

```math
T=-\frac{2zv}{k}x_{\mathrm A}x_{\mathrm B}
\tag{18}
```

となる．
$v<0$ では，この温度は

```math
T=\frac{2z|v|}{k}x_{\mathrm A}x_{\mathrm B}
```

である．
$x_{\mathrm A}x_{\mathrm B}$ は $x_{\mathrm A}=x_{\mathrm B}=1/2$ で最大値 $1/4$ をとるため，臨界温度は等モル組成で

```math
\boxed{
T_c=\frac{z|v|}{2k}
}
\tag{19}
```

となる．

$T>T_c$ では，あらゆる組成において曲率が正であり，均一な混合状態が安定である．
一方， $T<T_c$ では，自由エネルギーが組成に関して非凸になる領域が現れ，組成によっては A に富む相と B に富む相に分離する．
ただし，すべての組成が必ず二相分離するわけではなく，実際の二相共存範囲は自由エネルギーの共通接線条件によって定まる．

### 結論

Bragg–Williams 近似による2成分溶液の自由エネルギーは，

```math
\boxed{
F=E_0-Nzv x_{\mathrm A}x_{\mathrm B}
+NkT\left(
x_{\mathrm A}\log x_{\mathrm A}
+x_{\mathrm B}\log x_{\mathrm B}
\right)
}
```

であり，各成分の化学ポテンシャルは，

```math
\boxed{
\mu_{\mathrm A}
=\frac z2v_{\mathrm{AA}}
-zv x_{\mathrm B}^2+kT\log x_{\mathrm A}
}
```

```math
\boxed{
\mu_{\mathrm B}
=\frac z2v_{\mathrm{BB}}
-zv x_{\mathrm A}^2+kT\log x_{\mathrm B}
}
```

である．
$v>0$ では混合によってエネルギーが低下し，均一混合が安定である．
一方， $v<0$ では混合によってエネルギーが増加し，低温では相分離が起こり得る．
対称な組成 $x_{\mathrm A}=x_{\mathrm B}=1/2$ における臨界温度は $T_c=z|v|/(2k)$ である．
