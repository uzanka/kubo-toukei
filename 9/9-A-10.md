# 演習問題【9-A-10】

## 解答

### 1．Debye–Hückel 理論における電位成分

Debye–Hückel 理論では，イオン $\alpha$ に対応する電位成分 $\psi_\alpha$ は，自由エネルギー $F$ をイオンの電荷 $e_\alpha$ で偏微分したものとして定義される．
すなわち，

```math
\psi_\alpha=\frac{\partial F}{\partial e_\alpha}
\tag{1}
```

である．

式 (9.28) で得られる関係は，

```math
\boxed{
\psi_\alpha=-\frac{e_\alpha}{D}
\frac{\kappa}{1+\kappa a}
}
\tag{2}
```

である．
ここで， $D$ は誘電率に対応する定数， $a$ はイオンの大きさを表すパラメータ， $\kappa$ は Debye 遮蔽長の逆数である．
以下では，温度 $T$ ，体積 $V$ ， $D$ ， $a$ は一定として扱う．

示すべきことは，

```math
\boxed{
\frac{\partial\psi_\alpha}{\partial e_\beta}
=
\frac{\partial\psi_\beta}{\partial e_\alpha}
}
\tag{3}
```

が成り立つことである．
まず， $\alpha\ne\beta$ の場合について示す．

### 2．$\kappa$ の電荷依存性

Debye 遮蔽定数 $\kappa$ は，

```math
\boxed{
\kappa^2=
\frac{4\pi}{Dk_{\mathrm B}TV}
\sum_\gamma e_\gamma^2
}
\tag{4}
```

と定義される．
ここで， $k_{\mathrm B}$ はボルツマン定数であり，和は溶液中のすべてのイオンについて取る．

式 (4) の両辺を電荷 $e_\beta$ で偏微分する．
右辺の和では， $e_\beta^2$ の項だけが $e_\beta$ に依存するため，

```math
\frac{\partial}{\partial e_\beta}
\left(\sum_\gamma e_\gamma^2\right)
=2e_\beta
```

となる．
したがって，

```math
\frac{\partial\kappa^2}{\partial e_\beta}
=\frac{8\pi e_\beta}{Dk_{\mathrm B}TV}
\tag{5}
```

である．
一方，連鎖律より，

```math
\frac{\partial\kappa^2}{\partial e_\beta}
=2\kappa\frac{\partial\kappa}{\partial e_\beta}
```

であるから，両式を等置して整理すると，

```math
2\kappa\frac{\partial\kappa}{\partial e_\beta}
=\frac{8\pi e_\beta}{Dk_{\mathrm B}TV}
```

を得る．
よって，

```math
\boxed{
\frac{\partial\kappa}{\partial e_\beta}
=\frac{4\pi e_\beta}
{\kappa Dk_{\mathrm B}TV}
}
\tag{6}
```

となる．

### 3．混合偏微分の対称性

式 (2) を $e_\beta$ で偏微分する．
ここでは $\alpha\ne\beta$ であるため，明示的な因子 $e_\alpha$ は $e_\beta$ に依存せず， $\kappa$ を通じた依存性だけを微分すればよい．
したがって，

```math
\frac{\partial\psi_\alpha}{\partial e_\beta}
=-\frac{e_\alpha}{D}
\frac{\mathrm d}{\mathrm d\kappa}
\left(\frac{\kappa}{1+\kappa a}\right)
\frac{\partial\kappa}{\partial e_\beta}
\tag{7}
```

となる．

ここで，商の微分を計算すると，

```math
\begin{aligned}
\frac{\mathrm d}{\mathrm d\kappa}
\left(\frac{\kappa}{1+\kappa a}\right)
&=\frac{(1+\kappa a)-a\kappa}
{(1+\kappa a)^2}\\
&=\frac{1}{(1+\kappa a)^2}
\end{aligned}
\tag{8}
```

である．
式 (6)，(8) を式 (7) に代入すると，

```math
\boxed{
\frac{\partial\psi_\alpha}{\partial e_\beta}
=-\frac{4\pi e_\alpha e_\beta}
{D^2k_{\mathrm B}TV\,\kappa(1+\kappa a)^2}
}
\tag{9}
```

を得る．

式 (9) では，電荷 $e_\alpha$ と $e_\beta$ は積 $e_\alpha e_\beta$ として現れている．
また，残りの因子は $\alpha$ と $\beta$ の交換によって変化しない．
したがって，

```math
\frac{\partial\psi_\beta}{\partial e_\alpha}
=-\frac{4\pi e_\beta e_\alpha}
{D^2k_{\mathrm B}TV\,\kappa(1+\kappa a)^2}
\tag{10}
```

であり，式 (9)，(10) を比較すると，

```math
\boxed{
\frac{\partial\psi_\alpha}{\partial e_\beta}
=
\frac{\partial\psi_\beta}{\partial e_\alpha}
}
```

が成り立つ．
なお， $\alpha=\beta$ の場合には，両辺は同一の偏微分であるため，等式は自明に成立する．
これで題意が示された．

### 4．物理的意味

この対称性は，自由エネルギー $F$ が電荷 $e_\alpha,e_\beta,\ldots$ の十分滑らかな関数であることと整合する条件である．
式 (1) より，

```math
\psi_\alpha=\frac{\partial F}{\partial e_\alpha}
```

であるため，混合偏微分の対称性は，自由エネルギーの二階混合偏微分が等しいことに対応する．

この条件が満たされると，電荷を変化させて自由エネルギーを積分するとき，適切な定義域では積分結果が変化の経路に依存しない．
したがって，Debye–Hückel 理論で得られた電位成分 $\psi_\alpha$ は，自由エネルギーの偏微分として熱力学的に整合していることが確認できるのである．
