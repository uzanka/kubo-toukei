# 演習問題【9-R-1】

## 解答

### 1．交換相互作用と分子場近似

各原子が大きさ $S$ のスピンを持ち，隣接するスピン間に交換相互作用

```math
U_{\mathrm{ex}}=-2J\mathbf S_j\cdot\mathbf S_l,
\qquad J>0
```

が働く強磁性体を考える．
ここで， $J>0$ であるため，隣接スピンは平行にそろう傾向を持つ．

ある原子のスピンを $\mathbf S_0$ ，その隣接原子のスピンを $\mathbf S_1,\ldots,\mathbf S_z$ とする．
外部磁場を $\mathbf H$ とすると，注目するスピンに関係するエネルギーは

```math
U=-2J\mathbf S_0\cdot\sum_{m=1}^{z}\mathbf S_m
-g\mu_{\mathrm B}\mathbf H\cdot\mathbf S_0
\tag{1}
```

である．
ここで， $g$ は $g$ 因子， $\mu_{\mathrm B}$ は Bohr 磁子， $z$ は隣接原子の数である．

分子場近似では，周囲のスピンをそれぞれの熱平均 $\overline{\mathbf S}$ で置き換える．
すると，

```math
\begin{aligned}
U&\simeq
-2zJ\overline{\mathbf S}\cdot\mathbf S_0
-g\mu_{\mathrm B}\mathbf H\cdot\mathbf S_0\\
&=-g\mu_{\mathrm B}
\left(\mathbf H+
\frac{2zJ}{g\mu_{\mathrm B}}\overline{\mathbf S}\right)
\cdot\mathbf S_0
\end{aligned}
\tag{2}
```

となる．

単位体積あたりの原子数を $n$ とすれば，磁化 $\mathbf M$ は

```math
\mathbf M=ng\mu_{\mathrm B}\overline{\mathbf S}
\tag{3}
```

である．
したがって，式 (2) の有効磁場は

```math
\mathbf H_{\mathrm{eff}}=\mathbf H+q\mathbf M
\tag{4}
```

と表せる．
ここで，

```math
\boxed{
q=\frac{2zJ}{ng^2\mu_{\mathrm B}^2}
}
\tag{5}
```

である．
このように，分子場近似では，注目するスピンは外部磁場と磁化に比例する分子場の和を受けると考える．

### 2．高温における磁化

磁化は有効磁場 $\mathbf H_{\mathrm{eff}}$ の方向を向くため，その方向を $z$ 軸に取る．
有効磁場の大きさを $H_{\mathrm{eff}}$ とすると，スピンの $z$ 成分の固有値を $m=-S,-S+1,\ldots,S$ として，磁化は

```math
M=ng\mu_{\mathrm B}
\frac{\displaystyle\sum_{m=-S}^{S}
m\,e^{g\mu_{\mathrm B}mH_{\mathrm{eff}}/(kT)}}
{\displaystyle\sum_{m=-S}^{S}
e^{g\mu_{\mathrm B}mH_{\mathrm{eff}}/(kT)}}
\tag{6}
```

と表される．
ここで， $k$ は Boltzmann 定数， $T$ は絶対温度である．

高温かつ弱い有効磁場の条件

```math
g\mu_{\mathrm B}H_{\mathrm{eff}}\ll kT
```

のもとでは，指数関数を一次まで展開できる．
すなわち，

```math
e^{g\mu_{\mathrm B}mH_{\mathrm{eff}}/(kT)}
\simeq
1+\frac{g\mu_{\mathrm B}mH_{\mathrm{eff}}}{kT}
```

である．
式 (6) の分子では， $\sum_m m=0$ であるため定数項が消える．
分母では，磁場に比例する項の和が $\sum_m m=0$ によって消える．
したがって，

```math
M\simeq ng\mu_{\mathrm B}
\frac{\dfrac{g\mu_{\mathrm B}H_{\mathrm{eff}}}{kT}
\displaystyle\sum_{m=-S}^{S}m^2}
{2S+1}
\tag{7}
```

となる．

スピン量子数についての和の公式

```math
\sum_{m=-S}^{S}m^2
=\frac{S(S+1)(2S+1)}3
```

を使うと，

```math
\boxed{
M=\frac{n(g\mu_{\mathrm B})^2S(S+1)}{3kT}
H_{\mathrm{eff}}
}
\tag{8}
```

を得る．
これは，高温の弱磁場領域で磁化が有効磁場に比例することを示す式である．

### 3．磁化率と Curie 温度

式 (4) の有効磁場 $H_{\mathrm{eff}}=H+qM$ を式 (8) に代入すると，

```math
M=\frac{n(g\mu_{\mathrm B})^2S(S+1)}{3kT}
(H+qM)
\tag{9}
```

である．
これを $M$ について整理すれば，

```math
M\left[
1-\frac{n(g\mu_{\mathrm B})^2S(S+1)q}{3kT}
\right]
=\frac{n(g\mu_{\mathrm B})^2S(S+1)}{3kT}H
\tag{10}
```

となる．
ここで式 (5) の $q$ を代入すると，

```math
\frac{n(g\mu_{\mathrm B})^2S(S+1)q}{3kT}
=\frac{2zJS(S+1)}{3kT}
```

である．
したがって，

```math
M\left[
1-\frac{2zJS(S+1)}{3kT}
\right]
=\frac{n(g\mu_{\mathrm B})^2S(S+1)}{3kT}H
\tag{11}
```

となる．

ここで Curie 温度 $T_c$ を

```math
\boxed{
T_c=\frac{2zJS(S+1)}{3k}
}
\tag{12}
```

と定義する．
すると，式 (11) は

```math
M\left(1-\frac{T_c}{T}\right)
=\frac{n(g\mu_{\mathrm B})^2S(S+1)}{3kT}H
```

となる．
両辺を整理すると，

```math
M=\frac{n(g\mu_{\mathrm B})^2S(S+1)}{3k(T-T_c)}H
\tag{13}
```

である．

磁化率 $\chi$ は，弱い外部磁場に対する磁化の比例係数 $\chi=M/H$ として定義される．
よって，

```math
\boxed{
\chi=\frac{n(g\mu_{\mathrm B})^2S(S+1)}
{3k(T-T_c)}
}
\tag{14}
```

を得る．
これは Curie–Weiss の法則である．

また，Curie 定数を

```math
\boxed{
C=\frac{n(g\mu_{\mathrm B})^2S(S+1)}{3k}
}
\tag{15}
```

と定義すれば，

```math
\boxed{\chi=\frac{C}{T-T_c}}
\tag{16}
```

と簡潔に表せる．
式 (12) と式 (15) から $T_c=qC$ であることも分かる．

### 結論

分子場近似による高温常磁性領域 $T>T_c$ の磁化率は，

```math
\boxed{
\chi=\frac{n(g\mu_{\mathrm B})^2S(S+1)}
{3k(T-T_c)}
}
```

であり，Curie 温度は

```math
\boxed{
T_c=\frac{2zJS(S+1)}{3k}
}
```

である．
この近似では，交換相互作用 $J$ ，スピンの大きさ $S$ ，および隣接原子数 $z$ が大きいほど Curie 温度は高くなる．
ただし， $T_c$ は分子場近似で得られる値であり，実際の物質の転移温度と厳密に一致するとは限らない．
