# 演習問題【9-B-17】

## 解答

本問題では，格子モデルを用いて溶媒 $A$ に鎖状高分子 $B$ を溶かしたときの配置の数 $W$ および混合のエントロピー $\Delta S$ を求める．

### 1．高分子 $l$ 番目の配置の数 $\nu_l$ の導出

まず，区別可能な $N_2$ 個の高分子を番号順に格子点に配置していく手順を考える．
$l$ 番目の高分子を配置する際の，その高分子の構造単位の配置の仕方の数 $\nu_l$ を求める．

高分子の構造単位は $r$ 個ある．
- 1番目の構造単位の配置：
  空いている格子点のどこに置いてもよいため，配置の仕方は $N - r(l-1)$ 通りである．
  （すでに配置済みの $(l-1)$ 個の高分子によって占有されている格子点は $r(l-1)$ 個であるため．）
- 2番目以降の構造単位の配置：
  2番目の構造単位は，1番目の構造単位の隣接格子点 $z$ 個のうち，空いている格子点に置く必要がある．
  格子全体に構造単位が均一に分布していると仮定すると，ある隣接格子点がすでに占有されている確率は $\frac{r(l-1)}{N}$ である．
  したがって，空いている確率は $1 - \frac{r(l-1)}{N}$ である．
  これを用いると，2番目の構造単位の配置の仕方は $z \left(1 - \frac{r(l-1)}{N}\right)$ 通りと見積もれる．
  3番目以降についても，同様に直前の単位の隣接格子点のうち，すでに占有されている可能性を考慮すると，配置の仕方は $(z-1) \left(1 - \frac{r(l-1)}{N}\right)$ となる．
  （ただし，1番目と隣接する場合を無視する近似を用いる．）

これらをまとめると，高分子 $l$ 番目の配置の数は，高分子の鎖の対称性を考慮して $\sigma$ で割ると，次のように書ける：

$$\nu_l = \frac{N}{\sigma} z (z-1)^{r-2} \left[1 - \frac{r(l-1)}{N}\right]^r \quad \dots (1)$$

ここで，最初の構造単位の配置の数 $N - r(l-1)$ を $N [1 - \frac{r(l-1)}{N}]$ と書き換えており，高分子の $r$ 個の単位すべてに対してこの因子が効いているものとして $[1 - \frac{r(l-1)}{N}]^r$ としている．

### 2．全配置の数 $W$ の導出

高分子はすべて同一構造であり，番号による区別はできないため，全体の配置の数 $W$ は次のように与えられる：

$$W = \frac{1}{N_2!} \prod_{l=1}^{N_2} \nu_l \quad \dots (2)$$

式 (1) を式 (2) に代入すると，

$$W = \frac{1}{N_2!} \prod_{l=1}^{N_2} \left( \frac{N}{\sigma} z (z-1)^{r-2} \left[1 - \frac{r(l-1)}{N}\right]^r \right)$$

$$W = \frac{z^{N_2} (z-1)^{N_2(r-2)}}{N_2! \sigma^{N_2}} N^{N_2} \prod_{l=1}^{N_2} \left[1 - \frac{r(l-1)}{N}\right]^r \quad \dots (3)$$

積の部分を計算する．

$$\prod_{l=1}^{N_2} \left[1 - \frac{r(l-1)}{N}\right]^r = \left[ \prod_{i=0}^{N_2-1} \left(1 - \frac{ri}{N}\right) \right]^r = \left[ \prod_{i=0}^{N_2-1} \frac{N-ri}{N} \right]^r = \frac{1}{N^{rN_2}} \left[ \prod_{i=0}^{N_2-1} (N-ri) \right]^r$$

ここで $\prod_{i=0}^{N_2-1} (N-ri) = r^{N_2} \prod_{i=0}^{N_2-1} (\frac{N}{r} - i) = r^{N_2} \frac{(N/r)!}{(N/r - N_2)!}$ である．
$N = N_1 + rN_2$ より $\frac{N}{r} - N_2 = \frac{N_1}{r}$ であるから，

$$\prod_{l=1}^{N_2} \left[1 - \frac{r(l-1)}{N}\right]^r = \frac{1}{N^{rN_2}} \left[ r^{N_2} \frac{(N/r)!}{(N_1/r)!} \right]^r = \frac{r^{rN_2}}{N^{rN_2}} \frac{(N/r)!^r}{(N_1/r)!^r}$$

これを式 (3) に代入すると，

$$W = \frac{z^{N_2} (z-1)^{N_2(r-2)}}{N_2! \sigma^{N_2}} N^{N_2} \cdot \frac{r^{rN_2}}{N^{rN_2}} \frac{(N/r)!^r}{(N_1/r)!^r}$$

$$W = \frac{z^{N_2} (z-1)^{N_2(r-2)}}{N_2! \sigma^{N_2}} N^{-(r-1)N_2} r^{rN_2} \frac{(N/r)!^r}{(N_1/r)!^r}$$

となり，問題で与えられた Flory の近似式が得られた．

### 3．混合エントロピー $\Delta S$ の導出

溶液のエントロピーは $S = k \log W$ で与えられる．
Stirling の近似 $\log n! \approx n \log n - n$ を用いて $\log W$ を計算する．

$$\log W = N_2 \log z + N_2(r-2) \log(z-1) - \log(N_2!) - N_2 \log \sigma - (r-1)N_2 \log N + rN_2 \log r + r \log(N/r)! - r \log(N_1/r)!$$

各項を近似すると，
- $\log(N_2!) \approx N_2 \log N_2 - N_2$
- $r \log(N/r)! \approx r \left( \frac{N}{r} \log \frac{N}{r} - \frac{N}{r} \right) = N \log N - N \log r - N$
- $r \log(N_1/r)! \approx r \left( \frac{N_1}{r} \log \frac{N_1}{r} - \frac{N_1}{r} \right) = N_1 \log N_1 - N_1 \log r - N_1$

これらを代入して整理すると，

$$\log W \approx N_2 \log z + N_2(r-2) \log(z-1) - N_2 \log N_2 + N_2 - N_2 \log \sigma - (r-1)N_2 \log N + rN_2 \log r + N \log N - N \log r - N - N_1 \log N_1 + N_1 \log r + N_1$$

定数項： $N_2 - N + N_1 = N_2 + N_1 - (N_1 + rN_2) = -(r-1)N_2$
$\log r$ の項： $rN_2 - N + N_1 = rN_2 - (N_1 + rN_2) + N_1 = 0$
$\log N$ の項： $-(r-1)N_2 + N = (N - rN_2 + N_2) = N_1 + N_2$
よって，

$$\log W = N_2 \log \frac{z(z-1)^{r-2}}{\sigma} - N_2 \log N_2 - (r-1)N_2 + (N_1 + N_2) \log N - N_1 \log N_1$$

$$\log W = N_2 \log \frac{z(z-1)^{r-2}}{\sigma e^{r-1}} + (N_1 + N_2) \log N - N_1 \log N_1 - N_2 \log N_2$$

$$S(N_1, N_2) = N_2 k \log \frac{z(z-1)^{r-2}}{\sigma e^{r-1}} - k (N_1 \log \frac{N_1}{N} + N_2 \log \frac{N_2}{N}) \quad \dots (4)$$

となり，式 (4) が得られた．

混合前のエントロピーは， $N_2$ 個の高分子のみが存在する状態 ( $N_1=0$ ) と， $N_1$ 個の溶媒分子のみが存在する状態 ( $N_2=0$ ) の和である．
$S(N_1, 0) = N_1 k \log(1) = 0$ （溶媒のみの場合は配置の自由度を基準とするため）
$S(0, N_2) = N_2 k \log \frac{z(z-1)^{r-2}}{\sigma e^{r-1}} + k N_2 \log r$ （式 (4) に $N_1=0$ を代入し， $N=rN_2$ を用いる）
※ここで $\log \frac{N_2}{N} = \log \frac{N_2}{rN_2} = \log \frac{1}{r} = -\log r$ であることに注意．

したがって，混合によるエントロピーの変化 $\Delta S$ は，

$$\Delta S = S(N_1, N_2) - S(0, N_2)$$

$$\Delta S = \left[ N_2 k \log \frac{z(z-1)^{r-2}}{\sigma e^{r-1}} - k (N_1 \log \frac{N_1}{N} + N_2 \log \frac{N_2}{N}) \right] - \left[ N_2 k \log \frac{z(z-1)^{r-2}}{\sigma e^{r-1}} + k N_2 \log r \right]$$

$$\Delta S = -k N_1 \log \frac{N_1}{N} - k N_2 \log \frac{N_2}{N} - k N_2 \log r$$

$$\Delta S = -k \left( N_1 \log \frac{N_1}{N} + N_2 \log \frac{r N_2}{N} \right)$$

ここで $\phi_1 = \frac{N_1}{N}$, $\phi_2 = \frac{rN_2}{N}$ であるから，

$$\Delta S = -k (N_1 \log \phi_1 + N_2 \log \phi_2)$$

が示された．

## 解説

本問題では，高分子溶液の統計力学的な記述における Flory の近似を用いて，混合のエントロピーを導出した．
高分子は単一の分子とは異なり，複数の構造単位が連結しているため，格子点への配置には特有の拘束が生じる．
Flory の近似では，高分子の鎖が周囲の格子点に与える影響を，格子全体の占有率に基づいて近似的に扱うことで，複雑な配置の数を扱いやすい数式に落とし込んでいる．
最終的に得られたエントロピーの式は，理想混合溶液のエントロピーの形をしているが，高分子の連結性（ $r$ の影響）が容積分率 $\phi_2$ の中に組み込まれている点が特徴的である．
