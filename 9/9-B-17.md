# 演習問題【9-B-17】

## 解答

## 1．高分子を1本ずつ配置する

溶媒分子 $A$ が $N_1$ 個，構造単位が $r$ 個連なった高分子 $B$ が $N_2$ 個ある系を考える．
格子点の総数を $N$ とすると，

```math
N=N_1+rN_2
\tag{1}
```

である．
各格子点は，溶媒分子または高分子の構造単位によって1つずつ占有される．
格子点1つあたりの隣接格子点の数を $z$ とする．
以下では $r\geq2$ とする．

まず，高分子に仮の番号 $1,2,\ldots,N_2$ を付け，番号順に格子上へ配置することを考える．

すでに $l-1$ 本の高分子を置いたとき，それらの具体的な配置を $C_{l-1}$ とする．
この配置を固定した場合， $l$ 番目の高分子を置く方法の数を

```math
\nu_l(C_{l-1})
```

と表す．

ここで重要なのは， $\nu_l(C_{l-1})$ が既配置高分子の具体的な配置 $C_{l-1}$ に依存することである．
したがって，厳密には，配置数を単純なスカラー量の積として表すことはできない．

高分子を仮に区別して配置する場合，配置数は，各段階で許される配置をすべて足し合わせることによって求められる．
実際の高分子は同一構造なので，仮の番号による重複を除くため，最後に $N_2!$ で割る．

ここから，Flory の近似を適用する．
すなわち，既配置高分子の具体的な分布による配置可能数の違いを無視し，各段階での配置可能数を平均的な値で近似する．
この平均的な配置可能数を $\bar{\nu}_l$ とする．

この近似では，既配置高分子の分布による相関を無視するため，仮に番号を付けた高分子の配置数は近似的に，

```math
\prod_{l=1}^{N_2}\bar{\nu}_l
```

となる．
したがって，同一高分子の番号による重複を除けば，

```math
\boxed{
W\simeq
\frac{1}{N_2!}
\prod_{l=1}^{N_2}\bar{\nu}_l
}
\tag{2}
```

となる．

## 2．Flory の近似による配置可能数の評価

すでに配置した $l-1$ 本の高分子は，合計 $r(l-1)$ 個の格子点を占有している．
したがって，空いている格子点は，

```math
N-r(l-1)
```

個である．

高分子の構造単位に鎖の一端から $1,2,\ldots,r$ と番号を付け，順に格子点へ配置する．

### 2.1．先頭の構造単位

最初の構造単位は，まだ空いている格子点ならどこにでも置くことができる．
したがって，配置方法は，

```math
\bar{\nu}_{l,1}
=N-r(l-1)
=N\left[1-\frac{r(l-1)}{N}\right]
\tag{3}
```

通りである．

### 2.2．2番目の構造単位

2番目の構造単位は，1番目の構造単位に隣接する $z$ 個の格子点のうち，空いている場所に置かなければならない．

Flory の近似では，すでに配置済みの高分子が格子全体に一様に分布しているとみなし，任意の格子点が占有されている割合を，

```math
\frac{r(l-1)}{N}
```

と近似する．

したがって，ある格子点が空いている割合は，

```math
q_l=1-\frac{r(l-1)}{N}
\tag{4}
```

である．

よって，2番目の構造単位を置く平均的な方法の数は，

```math
\bar{\nu}_{l,2}\simeq zq_l
\tag{5}
```

となる．

### 2.3．3番目以降の構造単位

3番目以降の構造単位は，直前の構造単位に隣接する格子点に置く必要がある．
ただし，直前の構造単位がすでに1個の隣接格子点を占有しているため，配置候補は $z$ 個ではなく $z-1$ 個である．

Flory の近似では，これらの $z-1$ 個の候補についても，空いている割合を一様に $q_l$ と評価する．

したがって，3番目の構造単位を置く平均的な方法の数は，

```math
\bar{\nu}_{l,3}\simeq(z-1)q_l
\tag{6}
```

となる．
4番目以降についても同様に評価する．

この近似では，直前の構造単位以外の既配置構造単位との接触や，鎖が折り返して先に置いた構造単位の近くに戻ることによる追加の配置制限を無視する．
また，各候補格子点の空き状態の相関も無視している．

これらが Flory の近似における主要な仮定である．

### 2.4．1本の高分子の配置数

以上の平均的な配置可能数を掛け合わせると， $l$ 番目の高分子を置く平均的な方法の数は，

```math
\begin{aligned}
\bar{\nu}_l\simeq{}&
\frac{1}{\sigma}
N\left[1-\frac{r(l-1)}{N}\right]\\
&\times z\left[1-\frac{r(l-1)}{N}\right]\\
&\times
\left\{
(z-1)\left[1-\frac{r(l-1)}{N}\right]
\right\}^{r-2}
\end{aligned}
\tag{7}
```

と表される．

ここで， $\sigma$ は高分子の対称数であり，鎖が中心対称である場合には $\sigma=2$ ，そうでない場合には $\sigma=1$ である．
中心対称な鎖では，鎖の両端から逆向きに番号を付けた配置を同一の配置として扱うため，2で割る．

式 (7) を整理すると，

```math
\boxed{
\bar{\nu}_l\simeq
\frac{N}{\sigma}z(z-1)^{r-2}
\left[1-\frac{r(l-1)}{N}\right]^r
}
\tag{8}
```

を得る．

空き割合の因子が $r$ 乗になるのは，先頭の構造単位の配置数に1個分，残りの $r-1$ 個の構造単位の配置数にそれぞれ1個分の因子が含まれるためである．

## 3．全配置数 $W$ の導出

式 (8) を式 (2) に代入すると，

```math
\begin{aligned}
W\simeq{}&
\frac{1}{N_2!}
\prod_{l=1}^{N_2}
\left[
\frac{N}{\sigma}z(z-1)^{r-2}
\left(1-\frac{r(l-1)}{N}\right)^r
\right]\\
={}&
\frac{z^{N_2}(z-1)^{N_2(r-2)}}
{N_2!\sigma^{N_2}}
N^{N_2}
\prod_{l=1}^{N_2}
\left[1-\frac{r(l-1)}{N}\right]^r
\end{aligned}
\tag{9}
```

となる．

残った積を整理するため， $i=l-1$ とおく．
すると，

```math
\begin{aligned}
&\prod_{l=1}^{N_2}
\left[1-\frac{r(l-1)}{N}\right]^r\\
&\qquad=
\left[
\prod_{i=0}^{N_2-1}\frac{N-ri}{N}
\right]^r\\
&\qquad=
\frac{1}{N^{rN_2}}
\left[\prod_{i=0}^{N_2-1}(N-ri)\right]^r
\end{aligned}
\tag{10}
```

である．

ここで，各因子から $r$ をくくり出すと，

```math
\prod_{i=0}^{N_2-1}(N-ri)
=
r^{N_2}
\prod_{i=0}^{N_2-1}
\left(\frac Nr-i\right)
\tag{11}
```

となる．

$N/r$ および $N_1/r$ が整数である場合，最後の積は階乗の比として，

```math
\begin{aligned}
\prod_{i=0}^{N_2-1}
\left(\frac Nr-i\right)
&=\frac{(N/r)!}{(N/r-N_2)!}\\
&=\frac{(N/r)!}{(N_1/r)!}
\end{aligned}
\tag{12}
```

と書ける．
最後の等号では，式 (1) から，

```math
\frac Nr-N_2=\frac{N_1}{r}
```

を用いた．

したがって，

```math
\begin{aligned}
&\prod_{l=1}^{N_2}
\left[1-\frac{r(l-1)}{N}\right]^r\\
&\qquad=
\frac{r^{rN_2}}{N^{rN_2}}
\left[
\frac{(N/r)!}{(N_1/r)!}
\right]^r
\end{aligned}
\tag{13}
```

である．

式 (13) を式 (9) に代入すれば，

```math
\begin{aligned}
W\simeq{}&
\frac{z^{N_2}(z-1)^{N_2(r-2)}}
{N_2!\sigma^{N_2}}
N^{N_2}
\frac{r^{rN_2}}{N^{rN_2}}
\left[
\frac{(N/r)!}{(N_1/r)!}
\right]^r\\
={}&
\frac{z^{N_2}(z-1)^{N_2(r-2)}}
{N_2!\sigma^{N_2}}
N^{-(r-1)N_2}r^{rN_2}
\left[
\frac{(N/r)!}{(N_1/r)!}
\right]^r
\end{aligned}
```

となる．

よって，Flory の近似による配置数は，

```math
\boxed{
W\simeq
\frac{z^{N_2}(z-1)^{N_2(r-2)}}
{N_2!\sigma^{N_2}}
N^{-(r-1)N_2}r^{rN_2}
\left[
\frac{(N/r)!}{(N_1/r)!}
\right]^r
}
\tag{14}
```

である．

これが問題文で与えられた Flory の近似による配置数である．

## 4．配置数からエントロピーを求める

配置数 $W$ が分かれば，Boltzmann の関係式，

```math
S(N_1,N_2)=k\log W
\tag{15}
```

によってエントロピーが求められる．

ここで $S(N_1,N_2)$ は，溶媒分子数が $N_1$ ，高分子分子数が $N_2$ の状態のエントロピーである．

式 (14) の対数を取ると，

```math
\begin{aligned}
\log W\simeq{}&
N_2\log z+N_2(r-2)\log(z-1)
-\log(N_2!)-N_2\log\sigma\\
&-(r-1)N_2\log N+rN_2\log r\\
&+r\log(N/r)!-r\log(N_1/r)!
\end{aligned}
\tag{16}
```

となる．

ここで，粒子数が十分大きいとして，Stirling の公式，

```math
\log m!\simeq m\log m-m
\tag{17}
```

を用いる．

各階乗項は，

```math
\log(N_2!)\simeq N_2\log N_2-N_2
\tag{18}
```

および，

```math
\begin{aligned}
r\log(N/r)!
&\simeq N\log(N/r)-N\\
&=N\log N-N\log r-N
\end{aligned}
\tag{19}
```

である．
同様に，

```math
\begin{aligned}
r\log(N_1/r)!
&\simeq N_1\log(N_1/r)-N_1\\
&=N_1\log N_1-N_1\log r-N_1
\end{aligned}
\tag{20}
```

となる．

式 (18)～(20) を式 (16) に代入し， $N=N_1+rN_2$ を使って整理する．
このとき， $\log r$ の係数はゼロになり，定数項から $-(r-1)N_2$ が残る．
したがって，

```math
\begin{aligned}
\log W\simeq{}&
N_2\log\left[z(z-1)^{r-2}\right]
-N_2\log\sigma-(r-1)N_2\\
&+(N_1+N_2)\log N
-N_1\log N_1-N_2\log N_2
\end{aligned}
\tag{21}
```

である．

ここで，

```math
\begin{aligned}
&(N_1+N_2)\log N
-N_1\log N_1-N_2\log N_2\\
&\qquad=-N_1\log\frac{N_1}{N}
-N_2\log\frac{N_2}{N}
\end{aligned}
```

を用いると，

```math
\begin{aligned}
\log W\simeq{}&
N_2\log
\frac{z(z-1)^{r-2}}{\sigma e^{r-1}}\\
&-N_1\log\frac{N_1}{N}
-N_2\log\frac{N_2}{N}
\end{aligned}
\tag{22}
```

を得る．

よって，式 (15) から，

```math
\boxed{
\begin{aligned}
S(N_1,N_2)\simeq{}&
N_2k\log\frac{z(z-1)^{r-2}}{\sigma e^{r-1}}\\
&-k\left(
N_1\log\frac{N_1}{N}
+N_2\log\frac{N_2}{N}
\right)
\end{aligned}
}
\tag{23}
```

となる．

## 5．混合エントロピー $\Delta S$

混合エントロピーは，混合後のエントロピーから，混合前の純溶媒と純高分子のエントロピーの和を差し引いたものである．
すなわち，

```math
\Delta S=S(N_1,N_2)-S(N_1,0)-S(0,N_2)
\tag{24}
```

である．

### 5.1．純溶媒と純高分子のエントロピー

純溶媒では $N_2=0$ であり，全格子点が溶媒分子によって占有される．
このモデルでは溶媒分子だけの配置数を1とするため，

```math
S(N_1,0)=k\log1=0
\tag{25}
```

である．

一方，純高分子では $N_1=0$ ，したがって $N=rN_2$ である．
式 (23) に代入すると，

```math
\begin{aligned}
S(0,N_2)\simeq{}&
N_2k\log\frac{z(z-1)^{r-2}}{\sigma e^{r-1}}\\
&-kN_2\log\frac{N_2}{rN_2}
\end{aligned}
```

となる．
ここで，

```math
\log\frac{N_2}{rN_2}=-\log r
```

であるから，

```math
\boxed{
S(0,N_2)\simeq
N_2k\log\frac{z(z-1)^{r-2}}{\sigma e^{r-1}}
+kN_2\log r
}
\tag{26}
```

となる．

### 5.2．混合エントロピー

式 (23)，(25)，(26) を式 (24) に代入すると，高分子の配置に関する項が相殺され，

```math
\begin{aligned}
\Delta S\simeq{}&
-kN_1\log\frac{N_1}{N}
-kN_2\log\frac{N_2}{N}
-kN_2\log r\\
={}&-k\left[
N_1\log\frac{N_1}{N}
+N_2\log\frac{rN_2}{N}
\right]
\end{aligned}
\tag{27}
```

を得る．

最後に，溶媒と溶質の容積分率を，

```math
\phi_1=\frac{N_1}{N},
\qquad
\phi_2=\frac{rN_2}{N}
\tag{28}
```

と定義する．

これらは，

```math
\phi_1+\phi_2=1
```

を満たす．

式 (27) に代入すれば，

```math
\boxed{
\Delta S\simeq
-k\left(
N_1\log\phi_1+N_2\log\phi_2
\right)
}
\tag{29}
```

となる．

以上より，Flory の近似のもとで，問題文に示された配置数と混合エントロピーの式が得られた．

なお，式 (14) の階乗表示は $N/r$ および $N_1/r$ が整数となる場合に通常の階乗として成立する．
それ以外の場合には，階乗を Gamma 関数で拡張した表現として扱う．
また，式 (17) の Stirling 近似は，対象となる粒子数が十分大きい場合に適用する．
