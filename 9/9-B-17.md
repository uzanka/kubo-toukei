# 演習問題【9-B-17】

## 解答

### 1．高分子を1本ずつ配置する

溶媒分子 $A$ が $N_1$ 個，構造単位が $r$ 個連なった高分子 $B$ が $N_2$ 個ある系を考える．
格子点の総数を $N$ とすると，

```math
N=N_1+rN_2
\tag{1}
```

である．
各格子点は，溶媒分子または高分子の構造単位によって1つずつ占有される．
格子点1つあたりの隣接格子点の数を $z$ とする．

まず，高分子に仮の番号 $1,2,\ldots,N_2$ を付け，番号順に格子上へ配置することを考える．
すでに $l-1$ 本の高分子を置いた後， $l$ 番目の高分子を置く方法の数を $\nu_l$ とする．

仮に高分子を区別できるとすれば，配置方法の総数は

```math
\nu_1\nu_2\cdots\nu_{N_2}
```

である．
しかし，実際には高分子は同一構造であり，仮の番号による区別は不要である．
どの配置にも $N_2!$ 通りの番号の付け方があるため，配置数 $W$ は

```math
\boxed{
W=\frac{1}{N_2!}\prod_{l=1}^{N_2}\nu_l
}
\tag{2}
```

となる．

### 2．Flory の近似による $\nu_l$ の評価

ここから， $l$ 番目の高分子を配置する方法の数 $\nu_l$ を求める．
すでに配置した $l-1$ 本の高分子は，合計 $r(l-1)$ 個の格子点を占有している．
したがって，空いている格子点は

```math
N-r(l-1)
```

個である．

高分子の構造単位に鎖の一端から $1,2,\ldots,r$ と番号を付け，順に格子点へ配置する．

#### 2.1．先頭の構造単位

最初の構造単位は，まだ空いている格子点ならどこにでも置くことができる．
したがって，置き方は

```math
N-r(l-1)
=N\left[1-\frac{r(l-1)}{N}\right]
\tag{3}
```

通りである．

#### 2.2．2番目の構造単位

2番目の構造単位は，1番目の構造単位に隣接する $z$ 個の格子点のうち，空いている場所に置かなければならない．

Flory の近似では，すでに配置済みの高分子が格子全体に一様に分布しているとみなし，任意の格子点が占有されている割合を

```math
\frac{r(l-1)}{N}
```

と近似する．
したがって，ある格子点が空いている割合は

```math
1-\frac{r(l-1)}{N}
\tag{4}
```

である．
よって，2番目の構造単位を置く方法の数は近似的に

```math
z\left[1-\frac{r(l-1)}{N}\right]
\tag{5}
```

となる．

#### 2.3．3番目以降の構造単位

3番目以降の構造単位は，直前の構造単位に隣接する格子点に置く必要がある．
ただし，直前の構造単位がすでに1個の隣接格子点を占有しているため，配置候補は $z$ 個ではなく $z-1$ 個である．

さらに，2番目以降の配置では，すでに配置された高分子が隣接格子点を占有している可能性を，式 (4) の空き割合で近似する．
このとき，3番目の構造単位を置く方法の数は

```math
(z-1)\left[1-\frac{r(l-1)}{N}\right]
```

となる．
4番目以降についても同様に評価する．

この近似では，鎖が折り返して先に置いた構造単位の近くに戻ることなどを無視し，直前の構造単位を除いた $z-1$ 個の候補について同じ空き割合を用いる．
これが Flory の近似における主要な仮定である．

#### 2.4．1本の高分子の配置数

以上を掛け合わせると， $l$ 番目の高分子を置く方法の数は

```math
\begin{aligned}
\nu_l\simeq{}&
\frac{1}{\sigma}
N\left[1-\frac{r(l-1)}{N}\right]\\
&\times z\left[1-\frac{r(l-1)}{N}\right]\\
&\times
\left\{
(z-1)\left[1-\frac{r(l-1)}{N}\right]
\right\}^{r-2}
\end{aligned}
\tag{6}
```

と表される．
ここで， $\sigma$ は高分子の対称数であり，鎖が中心対称である場合には $\sigma=2$ ，そうでない場合には $\sigma=1$ である．
中心対称な鎖では，鎖の両端から逆向きに番号を付けた配置を別々に数えないよう，2で割る必要がある．

式 (6) を整理すると，

```math
\boxed{
\nu_l\simeq
\frac{N}{\sigma}z(z-1)^{r-2}
\left[1-\frac{r(l-1)}{N}\right]^r
}
\tag{7}
```

を得る．
空き割合の因子が $r$ 乗になるのは，先頭の構造単位の配置数に1個分，残りの $r-1$ 個の構造単位の配置数にそれぞれ1個分の因子が含まれるためである．

### 3．全配置数 $W$ の導出

式 (7) を式 (2) に代入すると，

```math
\begin{aligned}
W\simeq{}&
\frac{1}{N_2!}
\prod_{l=1}^{N_2}
\left[
\frac{N}{\sigma}z(z-1)^{r-2}
\left(1-\frac{r(l-1)}{N}\right)^r
\right]\\[1mm]
={}&
\frac{z^{N_2}(z-1)^{N_2(r-2)}}
{N_2!\sigma^{N_2}}
N^{N_2}
\prod_{l=1}^{N_2}
\left[1-\frac{r(l-1)}{N}\right]^r
\end{aligned}
\tag{8}
```

となる．

残った積を整理するため， $i=l-1$ とおく．
すると，

```math
\begin{aligned}
&\prod_{l=1}^{N_2}
\left[1-\frac{r(l-1)}{N}\right]^r\\
&\qquad=
\left[
\prod_{i=0}^{N_2-1}\frac{N-ri}{N}
\right]^r\\
&\qquad=
\frac{1}{N^{rN_2}}
\left[\prod_{i=0}^{N_2-1}(N-ri)\right]^r
\end{aligned}
\tag{9}
```

である．

ここで，各因子から $r$ をくくり出すと，

```math
\prod_{i=0}^{N_2-1}(N-ri)
=
r^{N_2}
\prod_{i=0}^{N_2-1}
\left(\frac Nr-i\right)
\tag{10}
```

となる．
$N/r$ が整数である場合，最後の積は階乗の比として

```math
\begin{aligned}
\prod_{i=0}^{N_2-1}
\left(\frac Nr-i\right)
&=\frac{(N/r)!}{(N/r-N_2)!}\\
&=\frac{(N/r)!}{(N_1/r)!}
\end{aligned}
\tag{11}
```

と書ける．
最後の等号では，式 (1) から

```math
\frac Nr-N_2=\frac{N_1}{r}
```

を用いた．

したがって，

```math
\begin{aligned}
&\prod_{l=1}^{N_2}
\left[1-\frac{r(l-1)}{N}\right]^r\\
&\qquad=
\frac{r^{rN_2}}{N^{rN_2}}
\left[
\frac{(N/r)!}{(N_1/r)!}
\right]^r
\end{aligned}
\tag{12}
```

である．
式 (12) を式 (8) に代入すれば，

```math
\begin{aligned}
W\simeq{}&
\frac{z^{N_2}(z-1)^{N_2(r-2)}}
{N_2!\sigma^{N_2}}
N^{N_2}
\frac{r^{rN_2}}{N^{rN_2}}
\left[
\frac{(N/r)!}{(N_1/r)!}
\right]^r\\[1mm]
={}&
\frac{z^{N_2}(z-1)^{N_2(r-2)}}
{N_2!\sigma^{N_2}}
N^{-(r-1)N_2}r^{rN_2}
\left[
\frac{(N/r)!}{(N_1/r)!}
\right]^r
\end{aligned}
```

となる．
よって，Flory の近似による配置数は

```math
\boxed{
W\simeq
\frac{z^{N_2}(z-1)^{N_2(r-2)}}
{N_2!\sigma^{N_2}}
N^{-(r-1)N_2}r^{rN_2}
\left[
\frac{(N/r)!}{(N_1/r)!}
\right]^r
}
\tag{13}
```

である．
これは問題文で与えられた式である．

### 4．配置数から混合エントロピーを求める

配置数 $W$ が分かれば，Boltzmann の関係式

```math
S(N_1,N_2)=k\log W
\tag{14}
```

によってエントロピーが求められる．
ここで $S(N_1,N_2)$ は，溶媒分子数が $N_1$ ，高分子分子数が $N_2$ の状態のエントロピーを表す．

式 (13) の対数を取ると，

```math
\begin{aligned}
\log W={}&
N_2\log z+N_2(r-2)\log(z-1)
-\log(N_2!)-N_2\log\sigma\\
&-(r-1)N_2\log N+rN_2\log r\\
&+r\log(N/r)!-r\log(N_1/r)!
\end{aligned}
\tag{15}
```

となる．

ここで，粒子数が十分大きいとして，Stirling の公式

```math
\log m!\simeq m\log m-m
\tag{16}
```

を用いる．
各階乗項は，

```math
\log(N_2!)\simeq N_2\log N_2-N_2
\tag{17}
```

および

```math
\begin{aligned}
r\log(N/r)!
&\simeq N\log(N/r)-N\\
&=N\log N-N\log r-N
\end{aligned}
\tag{18}
```

である．
同様に，

```math
\begin{aligned}
r\log(N_1/r)!
&\simeq N_1\log(N_1/r)-N_1\\
&=N_1\log N_1-N_1\log r-N_1
\end{aligned}
\tag{19}
```

となる．

式 (17)～(19) を式 (15) に代入し， $N=N_1+rN_2$ を使って整理する．
このとき， $\log r$ の係数はゼロになり，定数項から $-(r-1)N_2$ が残る．
したがって，

```math
\begin{aligned}
\log W\simeq{}&
N_2\log\left[z(z-1)^{r-2}\right]
-N_2\log\sigma-(r-1)N_2\\
&+(N_1+N_2)\log N
-N_1\log N_1-N_2\log N_2
\end{aligned}
\tag{20}
```

である．
ここで，

```math
\begin{aligned}
&(N_1+N_2)\log N
-N_1\log N_1-N_2\log N_2\\
&\qquad=-N_1\log\frac{N_1}{N}
-N_2\log\frac{N_2}{N}
\end{aligned}
```

を用いると，

```math
\begin{aligned}
\log W\simeq{}&
N_2\log
\frac{z(z-1)^{r-2}}{\sigma e^{r-1}}\\
&-N_1\log\frac{N_1}{N}
-N_2\log\frac{N_2}{N}
\end{aligned}
\tag{21}
```

を得る．
よって，式 (14) から，

```math
\boxed{
\begin{aligned}
S(N_1,N_2)\simeq{}&
N_2k\log\frac{z(z-1)^{r-2}}{\sigma e^{r-1}}\\
&-k\left(
N_1\log\frac{N_1}{N}
+N_2\log\frac{N_2}{N}
\right)
\end{aligned}
}
\tag{22}
```

となる．

### 5．混合エントロピー $\Delta S$

混合エントロピーは，混合後のエントロピーから，混合前の純溶媒と純高分子のエントロピーの和を差し引いたものである．
すなわち，

```math
\Delta S=S(N_1,N_2)-S(N_1,0)-S(0,N_2)
\tag{23}
```

である．

#### 5.1．純溶媒と純高分子のエントロピー

純溶媒では $N_2=0$ であり，全格子点が溶媒分子によって占有される．
このモデルでは溶媒分子だけの配置数を $1$ とするため，

```math
S(N_1,0)=k\log1=0
\tag{24}
```

である．

一方，純高分子では $N_1=0$ ，したがって $N=rN_2$ である．
式 (22) に代入すると，

```math
\begin{aligned}
S(0,N_2)\simeq{}&
N_2k\log\frac{z(z-1)^{r-2}}{\sigma e^{r-1}}\\
&-kN_2\log\frac{N_2}{rN_2}
\end{aligned}
```

となる．
ここで，

```math
\log\frac{N_2}{rN_2}=-\log r
```

であるから，

```math
\boxed{
S(0,N_2)\simeq
N_2k\log\frac{z(z-1)^{r-2}}{\sigma e^{r-1}}
+kN_2\log r
}
\tag{25}
```

となる．

#### 5.2．混合エントロピー

式 (22)，(24)，(25) を式 (23) に代入すると，高分子の配置に関する項が相殺され，

```math
\begin{aligned}
\Delta S\simeq{}&
-kN_1\log\frac{N_1}{N}
-kN_2\log\frac{N_2}{N}
-kN_2\log r\\
={}&-k\left[
N_1\log\frac{N_1}{N}
+N_2\log\frac{rN_2}{N}
\right]
\end{aligned}
\tag{26}
```

を得る．

最後に，溶媒と溶質の容積分率を

```math
\phi_1=\frac{N_1}{N},
\qquad
\phi_2=\frac{rN_2}{N}
\tag{27}
```

と定義する．
これらを式 (26) に代入すれば，

```math
\boxed{
\Delta S\simeq
-k\left(N_1\log\phi_1+N_2\log\phi_2\right)
}
\tag{28}
```

となる．
以上より，Flory の近似のもとで，問題文に示された配置数と混合エントロピーの式が得られた．

なお，式 (13) の階乗表示は $N/r$ および $N_1/r$ が整数となる場合に直接解釈できる．
それ以外の場合には，階乗を Gamma 関数で拡張した近似表現として扱う．
