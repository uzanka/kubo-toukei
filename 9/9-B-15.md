# 演習問題【9-B-15】

## 解答

### 1．Ising スピンと合金原子の対応

磁場 $H$ のもとにある Ising スピン系の Hamiltonian は，

```math
\mathcal H
=-g\mu_{\mathrm B}H\sum_{j=1}^{N}\sigma_j
-J\sum_{\langle ij\rangle}\sigma_i\sigma_j
\tag{1}
```

である．
ここで， $\sigma_j=\pm1$ は格子点 $j$ にあるスピンの状態を表し， $g$ は $g$ 因子， $\mu_{\mathrm B}$ は Bohr 磁子， $J$ は隣接格子点間の相互作用定数である．

この Ising スピン系を，2元合金規則格子に対応させる．
問題のヒントに従い，部分格子 $a$ 上の A 原子と部分格子 $b$ 上の B 原子を $r$ 原子と呼び，部分格子 $a$ 上の B 原子と部分格子 $b$ 上の A 原子を $w$ 原子と呼ぶ．
これらをスピンに対応させると，

```math
\begin{cases}
r\text{ 原子}\longleftrightarrow \sigma=+1,\\
w\text{ 原子}\longleftrightarrow \sigma=-1
\end{cases}
\tag{2}
```

となる．

この対応では， $r-r$ および $w-w$ の組ではスピンの積が $+1$ であり， $r-w$ の組ではスピンの積が $-1$ である．
したがって，相互作用エネルギーは

```math
-J\sigma_i\sigma_j
=
\begin{cases}
-J & (r-r\text{ または }w-w),\\
+J & (r-w)
\end{cases}
\tag{3}
```

となる．
これは問題で指定された合金の相互作用エネルギーに一致する．
よって，合金の相互作用 Hamiltonian は

```math
\boxed{
\mathcal H_{\mathrm{alloy}}
=-J\sum_{\langle ij\rangle}\sigma_i\sigma_j
}
\tag{4}
```

と表される．

### 2．長距離規則度 $X$ とスピン総和の関係

$r$ 原子の数を $N_r$ ， $w$ 原子の数を $N_w$ とする．
格子点の総数は $N=N_r+N_w$ である．
長距離規則度 $X$ は，

```math
X=\frac{N_r-N_w}{N}
\tag{5}
```

と定義される．
一方，スピン総和は，式 (2) の対応から

```math
\sum_{j=1}^{N}\sigma_j
=N_r(+1)+N_w(-1)
=N_r-N_w
\tag{6}
```

である．
式 (5)，(6) より，

```math
\boxed{
\sum_{j=1}^{N}\sigma_j=NX
}
\tag{7}
```

となる．
したがって，長距離規則度 $X$ を固定することは，スピン総和 $NX$ を固定することに対応する．

有限個 $N$ の格子点では，スピン総和は

```math
N'=-N,-N+2,\ldots,N-2,N
\tag{8}
```

の値を取る．
よって，実際に許される規則度は $X=N'/N$ である．

### 3．規則度 $X$ を固定した合金の分配関数

温度 $T$ において，長距離規則度 $X$ を固定した合金の分配関数は，その規則度を満たすすべての原子配置について Boltzmann 因子を足し合わせたものである．
式 (4) より，

```math
\begin{aligned}
Z_A(X,T)
&=\sum_{\{\sigma_j\}:\,\sum_j\sigma_j=NX}
\exp\left(-\frac{\mathcal H_{\mathrm{alloy}}}{kT}\right)\\[1mm]
&=\sum_{\{\sigma_j\}:\,\sum_j\sigma_j=NX}
\exp\left(
\frac{J}{kT}\sum_{\langle ij\rangle}\sigma_i\sigma_j
\right)
\end{aligned}
\tag{9}
```

である．
ここで，和は $\sum_j\sigma_j=NX$ を満たすスピン配置だけについて取る．
この条件を課すことで，規則度が指定された合金の分配関数になる．

### 4．Ising 分配関数をスピン総和ごとに分ける

Ising スピン系の分配関数は，

```math
Z_I(H,T)
=\sum_{\{\sigma_j=\pm1\}}
\exp\left(-\frac{\mathcal H}{kT}\right)
\tag{10}
```

である．
式 (1) を代入すると，

```math
Z_I(H,T)
=
\sum_{\{\sigma_j=\pm1\}}
\exp\left[
\frac{g\mu_{\mathrm B}H}{kT}\sum_j\sigma_j
+\frac{J}{kT}\sum_{\langle ij\rangle}\sigma_i\sigma_j
\right]
\tag{11}
```

となる．

ここで，スピン総和を

```math
N'=\sum_j\sigma_j
\tag{12}
```

とする．
すべてのスピン配置を，スピン総和 $N'$ が等しいグループに分けて足し合わせると，

```math
\begin{aligned}
Z_I(H,T)
={}&\sum_{N'=-N,-N+2,\ldots,N}
\exp\left(\frac{g\mu_{\mathrm B}H}{kT}N'\right)\\
&\quad\times
\sum_{\{\sigma_j\}:\,\sum_j\sigma_j=N'}
\exp\left(
\frac{J}{kT}\sum_{\langle ij\rangle}\sigma_i\sigma_j
\right)
\end{aligned}
\tag{13}
```

を得る．

式 (9) と比較すると，内側の和は $X=N'/N$ とした合金の分配関数 $Z_A(N'/N,T)$ そのものである．
したがって，

```math
Z_I(H,T)
=\sum_{N'=-N,-N+2,\ldots,N}
\exp\left(\frac{g\mu_{\mathrm B}H}{kT}N'\right)
Z_A\left(\frac{N'}{N},T\right)
\tag{14}
```

となる．

ここで，

```math
\boxed{
\lambda=\exp\left(\frac{g\mu_{\mathrm B}H}{kT}\right)
}
\tag{15}
```

と定義する．
すると，式 (14) は

```math
\boxed{
Z_I(\lambda,T)
=\sum_{N'=-N,-N+2,\ldots,N}
\lambda^{N'}Z_A\left(\frac{N'}{N},T\right)
}
\tag{16}
```

と書ける．
この式が，Ising スピン系の分配関数と，規則度を固定した合金の分配関数との対応を示す基本式である．

### 5．係数抽出によって $Z_A(X,T)$ を求める

式 (16) から， $Z_I(\lambda,T)$ は $\lambda$ の Laurent 多項式であり，その $\lambda^{NX}$ の係数が $Z_A(X,T)$ であることが分かる．
したがって，

```math
\boxed{
Z_A(X,T)
=[\lambda^{NX}]\,Z_I(\lambda,T)
}
\tag{17}
```

である．
ここで $[\lambda^{NX}]$ は，Laurent 多項式から $\lambda^{NX}$ の係数を取り出すことを意味する．

係数抽出は，原点を一周する閉曲線積分を用いて表すことができる．
よって，

```math
\boxed{
Z_A(X,T)
=\frac{1}{2\pi i}
\oint_{\mathcal C}
\frac{Z_I(\lambda,T)}{\lambda^{NX+1}}\,d\lambda
}
\tag{18}
```

となる．
ここで $\mathcal C$ は原点を一周する正向きの閉曲線である．
この積分は，Laurent 多項式の $\lambda^{NX}$ の係数だけを取り出すものである．

なお，通常の多項式として係数抽出を行いたい場合には，式 (16) の両辺に $\lambda^N$ を掛ければよい．
すなわち，

```math
\lambda^N Z_I(\lambda,T)
=\sum_{N'}\lambda^{N+N'}
Z_A\left(\frac{N'}{N},T\right)
\tag{19}
```

となる．
右辺のべき指数 $N+N'$ は $0$ から $2N$ までの偶数刻みの非負整数である．
そのため， $NX=N'$ に対応する係数は，通常の多項式 $\lambda^N Z_I(\lambda,T)$ の $\lambda^{N+NX}$ の係数でもある．

したがって，磁場 $H$ と温度 $T$ の関数として Ising 分配関数 $Z_I$ が既知であれば，$\lambda=\exp(g\mu_{\mathrm B}H/(kT))$ によって $\lambda$ の関数に読み替え，式 (18) の係数抽出によって，規則度 $X$ と温度 $T$ の関数としての合金分配関数 $Z_A(X,T)$ を求めることができる．

以上が求める対応である．
