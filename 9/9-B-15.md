# 演習問題【9-B-15】

## 解答

## 1．Ising スピンと合金原子の対応

磁場 $H$ のもとにある Ising スピン系の Hamiltonian は，

```math
\mathcal H_I
=-g\mu_{\mathrm B}H\sum_{i=1}^{N}\sigma_i
-J\sum_{\langle ij\rangle}\sigma_i\sigma_j
\tag{1}
```

である．
ここで，

```math
\sigma_i=\pm1
```

は格子点 $i$ にあるスピンを表す．
また， $\langle ij\rangle$ は相互作用を持つ格子点の組を表す．

2元合金規則格子の2つの部分格子を $a,b$ とする．
問題のヒントに従い，

- $a$ 上の A 原子と $b$ 上の B 原子を $r$ 原子とする．
- $a$ 上の B 原子と $b$ 上の A 原子を $w$ 原子とする．

これらを Ising スピンに対応させると，

```math
\boxed{
\begin{aligned}
r\text{ 原子}&\longleftrightarrow \sigma_i=+1,\\
w\text{ 原子}&\longleftrightarrow \sigma_i=-1
\end{aligned}
}
\tag{2}
```

となる．

この対応では，

```math
\sigma_i\sigma_j=
\begin{cases}
+1 &(r-r,\ w-w),\\
-1 &(r-w)
\end{cases}
```

である．

§9.3 の合金模型において，スピン積が同じ値を持つ原子対の相互作用エネルギーがそれぞれ等しい場合，原子対の相互作用エネルギーを，

```math
E_{ij}=
\begin{cases}
E_{\parallel} &(\sigma_i\sigma_j=+1),\\
E_{\mathrm{anti}} &(\sigma_i\sigma_j=-1)
\end{cases}
```

と表すことができる．

このとき，

```math
E_{ij}
=
\frac{E_{\parallel}+E_{\mathrm{anti}}}{2}
-
\frac{E_{\mathrm{anti}}-E_{\parallel}}{2}
\sigma_i\sigma_j
\tag{3}
```

となる．

ここで，

```math
E_0^{(ij)}
=\frac{E_{\parallel}+E_{\mathrm{anti}}}{2},
\qquad
J=\frac{E_{\mathrm{anti}}-E_{\parallel}}{2}
```

と置けば，

```math
E_{ij}=E_0^{(ij)}-J\sigma_i\sigma_j
```

である．

全結合の集合を $\langle ij\rangle$ とすれば，合金の Hamiltonian は，

```math
\mathcal H_A
=
\sum_{\langle ij\rangle}E_0^{(ij)}
-J\sum_{\langle ij\rangle}\sigma_i\sigma_j
\tag{4}
```

となる．

すべての結合で $E_0^{(ij)}$ が同じ場合，結合数を $N_{\mathrm b}$ とすると，

```math
E_0=N_{\mathrm b}E_0^{(ij)}
```

である．
したがって，

```math
\mathcal H_A
=
E_0-J\sum_{\langle ij\rangle}\sigma_i\sigma_j
\tag{5}
```

となる．

以下では，この定数項が全配置に共通であり，規則度 $X$ にも依存しない場合，エネルギーの基準を変更して $E_0=0$ とする．
よって，

```math
\boxed{
\mathcal H_A
=-J\sum_{\langle ij\rangle}\sigma_i\sigma_j
}
\tag{6}
```

を用いる．

なお，結合ごとに $E_0^{(ij)}$ が異なる場合でも，その総和が全配置に共通ならば同様に除去できる．
規則度に依存する場合には除去せず，分配関数に対応する Boltzmann 因子を残す必要がある．

また，スピン積だけで原子対エネルギーを表すためには，同じスピン積を持つ原子対の相互作用エネルギーが等しいことが必要である．
この条件が成立しない一般の相互作用模型には，追加の項が必要となる．

## 2．規則度 $X$ とスピン総和の関係

$r$ 原子と $w$ 原子の個数をそれぞれ $N_r,N_w$ とする．
格子点の総数は，

```math
N=N_r+N_w
```

である．

長距離規則度 $X$ を，

```math
X=\frac{N_r-N_w}{N}
\tag{7}
```

と定義する．

一方，スピン総和は，

```math
\begin{aligned}
\sum_{i=1}^{N}\sigma_i
&=N_r(+1)+N_w(-1)\\
&=N_r-N_w
\end{aligned}
```

である．

したがって，

```math
\boxed{
\sum_{i=1}^{N}\sigma_i=NX
}
\tag{8}
```

となる．

つまり，規則度 $X$ を固定することは，スピン総和を $NX$ に固定することに対応する．

また，有限個 $N$ のスピンの総和は，

```math
N'=-N,-N+2,\ldots,N-2,N
\tag{9}
```

という値を取る．
したがって，許される規則度は，

```math
\boxed{
X=\frac{N'}{N}
}
\tag{10}
```

である．

## 3．規則度 $X$ を固定した合金の分配関数

温度 $T$ において，規則度 $X$ を固定した合金の分配関数は，その規則度を満たすすべての原子配置について Boltzmann 因子を足し合わせたものである．

本問では，問題のヒントに従い，規則度 $X$ のみを固定した配置和を考える．
すなわち，正負スピンの総数を別途固定する条件は課さない．

式 (6)，(8) より，

```math
\begin{aligned}
Z_A(X,T)
&=
\sum_{\{\sigma_i=\pm1\}}
\delta_{\sum_i\sigma_i,NX}
\exp\left(-\frac{\mathcal H_A}{kT}\right)\\
&=
\sum_{\{\sigma_i=\pm1\}}
\delta_{\sum_i\sigma_i,NX}
\exp\left(
\frac{J}{kT}
\sum_{\langle ij\rangle}\sigma_i\sigma_j
\right).
\end{aligned}
\tag{11}
```

ここで， $\delta_{p,q}$ は Kronecker のデルタであり，

```math
\delta_{p,q}
=
\begin{cases}
1 &(p=q),\\
0 &(p\ne q)
\end{cases}
```

を表す．

したがって，

```math
\boxed{
Z_A(X,T)
=
\sum_{\{\sigma_i\}:\,\sum_i\sigma_i=NX}
\exp\left(
\frac{J}{kT}
\sum_{\langle ij\rangle}\sigma_i\sigma_j
\right)
}
\tag{12}
```

となる．

この和は，規則度 $X$ を満たすすべてのスピン配置について取る．

## 4．Ising 分配関数をスピン総和ごとに分ける

問題文で与えられた Ising スピン系の分配関数は，

```math
Z_I(H,T)
=
\sum_{\{\sigma_i=\pm1\}}
\exp\left(-\frac{\mathcal H_I}{kT}\right)
\tag{13}
```

である．

式 (1) を代入すると，

```math
\begin{aligned}
Z_I(H,T)
=
\sum_{\{\sigma_i=\pm1\}}
\exp\left[
&\frac{g\mu_{\mathrm B}H}{kT}\sum_i\sigma_i\\
&+\frac{J}{kT}
\sum_{\langle ij\rangle}\sigma_i\sigma_j
\right].
\end{aligned}
\tag{14}
```

ここで，スピン総和を，

```math
N'=\sum_{i=1}^{N}\sigma_i
\tag{15}
```

とする．

すべてのスピン配置を，スピン総和 $N'$ が等しいグループに分けて足し合わせると，

```math
\begin{aligned}
Z_I(H,T)
={}&
\sum_{N'=-N,-N+2,\ldots,N}
\exp\left(
\frac{g\mu_{\mathrm B}H}{kT}N'
\right)\\
&\times
\sum_{\{\sigma_i\}:\,\sum_i\sigma_i=N'}
\exp\left(
\frac{J}{kT}
\sum_{\langle ij\rangle}\sigma_i\sigma_j
\right).
\end{aligned}
\tag{16}
```

式 (12) と比較すると，内側の和は，

```math
X=\frac{N'}{N}
```

とした合金の分配関数 $Z_A(X,T)$ に一致する．

したがって，

```math
\boxed{
Z_I(H,T)
=
\sum_{N'=-N,-N+2,\ldots,N}
\exp\left(
\frac{g\mu_{\mathrm B}H}{kT}N'
\right)
Z_A\left(\frac{N'}{N},T\right)
}
\tag{17}
```

となる．

## 5．係数抽出による合金分配関数の導出

ここで，

```math
\boxed{
\lambda=
\exp\left(
\frac{g\mu_{\mathrm B}H}{kT}
\right)
}
\tag{18}
```

と定義する．

すると，式 (17) は，

```math
\boxed{
Z_I(\lambda,T)
=
\sum_{N'=-N,-N+2,\ldots,N}
\lambda^{N'}
Z_A\left(\frac{N'}{N},T\right)
}
\tag{19}
```

と書ける．

この式は，有限個のスピンからなる系についての有限 Laurent 多項式である．

したがって， $\lambda^{NX}$ の係数を取り出せば，

```math
\boxed{
Z_A(X,T)
=
[\lambda^{NX}]Z_I(\lambda,T)
}
\tag{20}
```

となる．

ここで， $[\lambda^{NX}]$ は Laurent 多項式から $\lambda^{NX}$ の係数を抽出することを意味する．

この係数抽出は，Laurent 多項式に対する Cauchy の係数積分公式によって，

```math
\boxed{
Z_A(X,T)
=
\frac{1}{2\pi i}
\oint_{\mathcal C}
\frac{Z_I(\lambda,T)}
{\lambda^{NX+1}}
\,d\lambda
}
\tag{21}
```

と表すことができる．

ここで， $\mathcal C$ は原点を正向きに一周する閉曲線である．

この積分は有限 Laurent 多項式の係数抽出であるため，留数定理によって厳密に成立する．

なお，通常の多項式として係数抽出を行う場合には，式 (19) の両辺に $\lambda^N$ を掛ければよい．

```math
\lambda^N Z_I(\lambda,T)
=
\sum_{N'}
\lambda^{N+N'}
Z_A\left(\frac{N'}{N},T\right)
\tag{22}
```

右辺のべき指数 $N+N'$ は，

```math
0,2,\ldots,2N
```

という非負整数である．

したがって，

```math
\boxed{
Z_A(X,T)
=
[\lambda^{N+NX}]
\left\{\lambda^N Z_I(\lambda,T)\right\}
}
\tag{23}
```

としても求められる．

以上より，磁場 $H$ と温度 $T$ の関数として Ising 分配関数 $Z_I$ が既知であれば，

```math
\lambda=\exp\left(\frac{g\mu_{\mathrm B}H}{kT}\right)
```

によって $\lambda$ の関数に変換し，その $\lambda^{NX}$ の係数を抽出することで，規則度 $X$ と温度 $T$ の関数としての合金分配関数 $Z_A(X,T)$ を求めることができる．

これが求める対応である．
