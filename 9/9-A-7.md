# 演習問題【9-A-7】

## 解答

### 1．自由エネルギーの変分

結晶の原子数を $N$ ，各原子が取り得る内部状態の数を $r$ とし，内部状態を $\sigma$ で表す．
一つの原子が状態 $\sigma$ にある確率を $f(\sigma)$ とする．
確率であるため，

```math
\boxed{\sum_{\sigma}f(\sigma)=1}
\tag{1}
```

が成り立つ．

Bragg–Williams 近似では，各原子の状態が互いに独立であると近似し，隣接原子間の相互作用エネルギーを確率の積で表す．
問題文で与えられた全エネルギーは

```math
U=\frac{Nz}{2}
\sum_{\sigma'}\sum_{\sigma''}
u(\sigma',\sigma'')f(\sigma')f(\sigma'')
\tag{2}
```

である．
ここで， $z$ は一つの原子に隣接する原子の数， $u(\sigma',\sigma'')$ は状態 $\sigma'$ ， $\sigma''$ にある隣接原子間の相互作用エネルギーである．

以下では，解答例と同様に，相互作用エネルギーが二つの状態の入れ替えについて対称であると仮定する．
すなわち，

```math
u(\sigma',\sigma'')=u(\sigma'',\sigma')
\tag{3}
```

である．

ヘルムホルツ自由エネルギーは

```math
F=U-TS
\tag{4}
```

である．
確率 $f(\sigma)$ を微小量 $\delta f(\sigma)$ だけ変化させたとき，自由エネルギーの変分は

```math
\delta F=\delta U-T\delta S
\tag{5}
```

と書ける．
以下で，各項の変分を求める．

#### 1.1．エネルギーの変分

式 (2) を変分すると，積の微分法則により，

```math
\begin{aligned}
\delta U
=\frac{Nz}{2}\sum_{\sigma'}\sum_{\sigma''}
u(\sigma',\sigma'')
\bigl[
&\delta f(\sigma')f(\sigma'')\\
&+f(\sigma')\delta f(\sigma'')
\bigr]
\end{aligned}
\tag{6}
```

となる．
第2項では，和の変数 $\sigma'$ と $\sigma''$ を入れ替えることができる．
さらに，式 (3) の対称性を用いると，第1項と第2項は等しくなる．
したがって，

```math
\boxed{
\delta U
=Nz\sum_{\sigma'}\sum_{\sigma''}
u(\sigma',\sigma'')f(\sigma'')
\delta f(\sigma')
}
\tag{7}
```

を得る．

#### 1.2．エントロピーの変分

問題文で与えられたエントロピーは

```math
S=-Nk\sum_{\sigma}f(\sigma)\log f(\sigma)
\tag{8}
```

である．
これを変分すると，

```math
\begin{aligned}
\delta S
&=-Nk\sum_{\sigma}
\delta\bigl[f(\sigma)\log f(\sigma)\bigr]\\
&=-Nk\sum_{\sigma}
\bigl[\log f(\sigma)+1\bigr]\delta f(\sigma)
\end{aligned}
\tag{9}
```

となる．
よって，

```math
\delta S
=-Nk\sum_{\sigma}\delta f(\sigma)\log f(\sigma)
-Nk\sum_{\sigma}\delta f(\sigma)
\tag{10}
```

である．

ここで，確率の規格化条件 (1) を変分すると，

```math
\boxed{
\sum_{\sigma}\delta f(\sigma)=0
}
\tag{11}
```

となる．
したがって，式 (10) の第2項は，規格化条件を満たす変分に対してゼロである．
これより，

```math
\boxed{
\delta S=-Nk\sum_{\sigma}
\delta f(\sigma)\log f(\sigma)
}
\tag{12}
```

を得る．

#### 1.3．自由エネルギーの変分

式 (7)，(12) を式 (5) に代入すると，

```math
\begin{aligned}
\delta F
={}&Nz\sum_{\sigma'}\sum_{\sigma''}
u(\sigma',\sigma'')f(\sigma'')\delta f(\sigma')\\
&+NkT\sum_{\sigma}\delta f(\sigma)\log f(\sigma)
\end{aligned}
\tag{13}
```

となる．

### 2．規格化条件のもとで自由エネルギーを最小化する

確率 $f(\sigma)$ は式 (1) の規格化条件を満たさなければならないため，互いに独立な変数として無条件に変化させることはできない．
そこで，Lagrange の未定乗数法を用いる．

未定乗数を $\lambda$ とすると，極値条件は

```math
\delta F+\lambda\sum_{\sigma}\delta f(\sigma)=0
\tag{14}
```

と表される．
式 (13) を代入し，変分 $\delta f(\sigma')$ ごとに整理すると，

```math
\begin{aligned}
0=\sum_{\sigma'}\biggl[
&Nz\sum_{\sigma''}
u(\sigma',\sigma'')f(\sigma'')\\
&+NkT\log f(\sigma')+\lambda
\biggr]\delta f(\sigma')
\end{aligned}
\tag{15}
```

となる．
ここでは，規格化条件を Lagrange の未定乗数で処理しているため，各変分の係数がゼロでなければならない．
したがって，

```math
Nz\sum_{\sigma''}
u(\sigma',\sigma'')f(\sigma'')
+NkT\log f(\sigma')+\lambda=0
\tag{16}
```

を得る．
両辺を $N$ で割ると，

```math
z\sum_{\sigma''}
u(\sigma',\sigma'')f(\sigma'')
+kT\log f(\sigma')
+\frac{\lambda}{N}=0
\tag{17}
```

となる．
ここで，定数

```math
\alpha=\frac{\lambda}{N}
```

とおけば，

```math
kT\log f(\sigma')
=-z\sum_{\sigma''}
u(\sigma',\sigma'')f(\sigma'')-\alpha
\tag{18}
```

である．
両辺を $kT$ で割り，指数関数を取ると，

```math
f(\sigma')
=\exp\left(-\frac{\alpha}{kT}\right)
\exp\left[
-\frac{z}{kT}
\sum_{\sigma''}
u(\sigma',\sigma'')f(\sigma'')
\right]
\tag{19}
```

を得る．

ここで，

```math
C=\exp\left(-\frac{\alpha}{kT}\right)
\tag{20}
```

と定義すれば，求める方程式は

```math
\boxed{
f(\sigma')
=C\exp\left[
-\frac{z}{kT}
\sum_{\sigma''}
u(\sigma',\sigma'')f(\sigma'')
\right]
}
\tag{21}
```

となる．

定数 $C$ は規格化条件 $\sum_{\sigma'}f(\sigma')=1$ から決まる．
具体的には，

```math
\boxed{
C=
\left\{
\sum_{\sigma'}
\exp\left[
-\frac{z}{kT}
\sum_{\sigma''}
u(\sigma',\sigma'')f(\sigma'')
\right]
\right\}^{-1}
}
\tag{22}
```

である．

### 3．得られた方程式の意味

式 (21) は，ある状態 $\sigma'$ の存在確率 $f(\sigma')$ が，その状態にある原子と周囲の原子との平均的な相互作用エネルギーによって決まることを表している．

具体的には，

```math
z\sum_{\sigma''}
u(\sigma',\sigma'')f(\sigma'')
```

が，状態 $\sigma'$ にある原子が周囲から受ける平均的な相互作用エネルギーに対応する．
このエネルギーが低い状態ほど，指数因子が大きくなり，存在確率が高くなる．
逆に，エネルギーが高い状態ほど存在確率は小さくなる．
その際，温度 \(T\) が高くなるとエネルギー差の影響が相対的に弱くなり，低温ではエネルギーの低い状態がより強く選ばれる．

また，式 (21) の右辺には再び $f(\sigma'')$ が含まれている．
そのため，この式は各状態の確率を直接一度で求める式ではなく，確率 $f(\sigma)$ 自身を用いて確率を決定する自己無撞着方程式である．

なお，相互作用エネルギーが状態の入れ替えについて対称でない場合には，一般に式 (7) のエネルギー変分には $u(\sigma',\sigma'')$ と $u(\sigma'',\sigma')$ の両方が現れる．
この場合は，その対称部分を用いるか，結晶の隣接方向ごとの相互作用を明示して和を取る形に拡張する必要がある．
