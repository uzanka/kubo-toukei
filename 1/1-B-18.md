# 演習問題【1-B-18】

## 解答

一様な常磁性体について，磁場 $H$ を一定に保つ過程での熱容量 $C_H$ を求める．
磁化による体積変形は無視できるものとする．

### 1．熱力学第一法則の適用

一様な磁場 $H$ の下で，磁性体の磁気モーメント $I$ が微小量 $dI$ だけ変化するとき，外部が磁性体にする磁気的な仕事を $d'A$ とすると，

```math
d'A=H\,dI
\tag{1}
```

と表される．

ここでは， $d'A$ を「外部が系にする仕事」とする符号規約を用いる．
このとき，熱力学第一法則は

```math
dU=d'Q+d'A
```

と表される．
ここで， $dU$ は内部エネルギーの変化， $d'Q$ は磁性体が外部から吸収する熱量である．

したがって，式（1）を代入して整理すると，

```math
\boxed{
d'Q=dU-H\,dI
}
\tag{2}
```

を得る．

### 2．内部エネルギーと磁気モーメントの全微分

内部エネルギー $U$ と磁気モーメント $I$ は，温度 $T$ と磁場 $H$ の関数であると考える．
したがって，それぞれの全微分は，

```math
dU=
\left(\frac{\partial U}{\partial T}\right)_H dT
+\left(\frac{\partial U}{\partial H}\right)_T dH
\tag{3}
```

および

```math
dI=
\left(\frac{\partial I}{\partial T}\right)_H dT
+\left(\frac{\partial I}{\partial H}\right)_T dH
\tag{4}
```

と書ける．

ここで， $\left(\frac{\partial U}{\partial T}\right)_H$ は磁場 $H$ を一定に保ったときの，温度 $T$ に対する内部エネルギーの偏微分を表す．
他の偏微分も同様に解釈する．

### 3．吸収熱量 \(d'Q\) の導出

式（3），（4）を式（2）に代入すると，

```math
\begin{aligned}
d'Q
={}&\left[
\left(\frac{\partial U}{\partial T}\right)_H dT
+\left(\frac{\partial U}{\partial H}\right)_T dH
\right]\\
&-H\left[
\left(\frac{\partial I}{\partial T}\right)_H dT
+\left(\frac{\partial I}{\partial H}\right)_T dH
\right]
\end{aligned}
```

となる．
これを $dT$ と $dH$ について整理すれば，

```math
\begin{aligned}
d'Q
={}&\left\{
\left(\frac{\partial U}{\partial T}\right)_H
-H\left(\frac{\partial I}{\partial T}\right)_H
\right\}dT\\
&+\left\{
\left(\frac{\partial U}{\partial H}\right)_T
-H\left(\frac{\partial I}{\partial H}\right)_T
\right\}dH
\end{aligned}
\tag{5}
```

を得る．

### 4．定磁場熱容量 $C_H$ の導出

定磁場過程では磁場 $H$ を一定に保つため，

```math
dH=0
```

である．
これを式（5）に代入すると，

```math
d'Q=
\left\{
\left(\frac{\partial U}{\partial T}\right)_H
-H\left(\frac{\partial I}{\partial T}\right)_H
\right\}dT
\tag{6}
```

となる．

定磁場熱容量 $C_H$ は，磁場を一定に保ったときの，温度変化に対する吸収熱量の変化率として定義される．
すなわち，

```math
C_H=\left(\frac{d'Q}{dT}\right)_H
```

である．
したがって，式（6）の両辺を $dT$ で割ることにより，

```math
\boxed{
C_H=
\left(\frac{\partial U}{\partial T}\right)_H
-H\left(\frac{\partial I}{\partial T}\right)_H
}
```

が得られる．
よって，題意が示された．
