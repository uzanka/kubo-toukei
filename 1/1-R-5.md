# 例題【1-R-5】

## 解答

空気を理想気体とみなし，比熱は一定とする．前問で与えられた空気の性質は，

```math
\begin{aligned}
\rho&=0.00129\,\mathrm{g/cm^3},\\
c_p&=0.238\,\mathrm{cal/(g\cdot deg)},\\
\gamma&=\frac{c_p}{c_v}=1.41
\end{aligned}
```

である．
以下では，これらの値を用いて各場合に必要な熱量を求める．

### (i) 体積を一定にして加熱する場合

まず，0 ℃，1 atm，体積 $V=27\,\mathrm{m^3}$ の空気の質量 $M$ を求める．

体積の単位を $\mathrm{cm^3}$ に変換すると，

```math
27\,\mathrm{m^3}=27\times10^6\,\mathrm{cm^3}
```

である．
したがって，密度と体積の関係 $M=\rho V$ より，

```math
\begin{aligned}
M&=0.00129\times27\times10^6\\
&=3.483\times10^4\,\mathrm{g}\\
&\simeq3.48\times10^4\,\mathrm{g}
\end{aligned}
```

を得る．

次に，定積比熱 $c_v$ を求める．
比熱比の定義 $\gamma=c_p/c_v$ より，

```math
\begin{aligned}
c_v&=\frac{c_p}{\gamma}\\
&=\frac{0.238}{1.41}\\
&\simeq0.169\\,\mathrm{cal/(g\cdot deg)}
\end{aligned}
```

となる．

この空気全体の定積熱容量 $C_V$ は，質量に定積比熱を掛けて，

```math
\begin{aligned}
C_V&=Mc_v\\
&=3.48\times10^4\times0.169\\
&\simeq5.88\times10^3\,\mathrm{cal/deg}
\end{aligned}
```

と求められる．

定積過程では体積が一定であるため，気体は外部に膨張仕事をしない．
したがって，加えられた熱量はすべて内部エネルギーの増加に使われる．
比熱を一定とすると，温度を $T_1$ から $T_2$ まで上げるのに必要な熱量 $Q_V$ は，

```math
Q_V=\int_{T_1}^{T_2}C_V\,dT =C_V(T_2-T_1)
```

である．
温度変化は，

```math
T_2-T_1=20-0=20\,\mathrm{deg}
```

なので，

```math
\begin{aligned}
Q_V &=5.88\times10^3\times20\\
&=1.176\times10^5\,\mathrm{cal}
\end{aligned}
```

となる．
よって，

```math
\boxed{
Q_V\simeq1.18\times10^5\,\mathrm{cal}
}
```

を得る．

### (ii) 1 atm の下で加熱する場合

今度は，0 ℃で体積 $27\,\mathrm{m^3}$ をもっていた空気を，圧力 1 atm に保ちながら20 ℃まで加熱する．
この場合，空気の質量は一定であるが，温度上昇に伴って体積が増加する．
そのため，気体は外部に膨張仕事をし，定積加熱よりも多くの熱量を必要とする．

この過程では，定積熱容量 $C_V$ の代わりに定圧熱容量 $C_p$ を用いる．
空気全体の定圧熱容量は，

```math
C_p=Mc_p
```

で与えられる．
また，比熱比より $C_p/C_V=\gamma$ であるから，

```math
\begin{aligned}
C_p&=\gamma C_V\\
&=1.41\times5.88\times10^3\\
&\simeq8.29\times10^3\,\mathrm{cal/deg}
\end{aligned}
```

となる．

比熱が一定であるため，必要な熱量 $Q_p$ は，

```math
Q_p=C_p(T_2-T_1)
```

で与えられる．
したがって，

```math
\begin{aligned}
Q_p &=8.29\times10^3\times20\\
&=1.658\times10^5\,\mathrm{cal}
\end{aligned}
```

となる．
よって，

```math
\boxed{
Q_p\simeq1.66\times10^5\,\mathrm{cal}
}
```

を得る．

### (iii) 体積 27 m³ の部屋で，空気を逃がしながら加熱する場合

この場合，部屋の体積は一定である一方，壁の小孔から空気が逃げるため，室内に残る空気の質量は温度とともに変化する．
また，室内をゆっくり加熱し，内部の圧力が常に外圧 1 atm と等しいとみなす．

この過程では，流出する空気がエネルギーを持ち去るため，その分も考慮して必要な熱量を求める必要がある．

#### 1．温度 $T$ における室内の空気の質量

室内の体積を $V$ ，温度 $T$ における空気の質量を $M(T)$ ，空気のモル質量を $m$ とする．
理想気体の状態方程式は，

```math
pV=\frac{M(T)}{m}RT
```

と書ける．
ここで， $R$ は気体定数である．

圧力 $p$ ，体積 $V$ ，モル質量 $m$ ，気体定数 $R$ は一定であるため，

```math
M(T)T=\frac{pmV}{R}=\mathrm{const.}
```

となる．

加熱開始時の絶対温度を

```math
T_1=273\,\mathrm{K}
```

とし，そのときの空気の質量を $M_1$ とする．
すると，

```math
M(T)T=M_1T_1
```

であるから，

```math
\boxed{
M(T)=M_1\frac{T_1}{T}
}
\tag{1}
```

となる．
すなわち，室内の体積と圧力を一定に保つため，温度が高くなるほど室内に残る空気の質量は小さくなる．

#### 2．流出する空気を考慮して熱量を求める

部屋の壁は動かないため，部屋の境界がする体積仕事はない．
また，室内の空気の巨視的な運動エネルギーの変化を無視する．

理想気体の単位質量あたりの内部エネルギーを $u=c_vT$ とすると，室内の空気全体の内部エネルギー $U$ は，

```math
U=M(T)c_vT
```

で表される．
式 (1) より $M(T)T=M_1T_1$ は一定であり，比熱 $c_v$ も一定なので，

```math
U=M_1T_1c_v=\mathrm{const.}
```

となる．
したがって，

```math
dU=0
```

である．
つまり，室内に残る空気全体の内部エネルギーは一定である．

しかし，空気が小孔から流出すると，その空気はエネルギーを外部へ持ち去る．
理想気体では，単位質量あたりのエンタルピー $h$ は，

```math
h=u+p v_{\mathrm{s}}=c_pT
```

と表される．
ここで， $v_{\mathrm{s}}$ は単位質量あたりの比容であり， $c_p$ は定圧比熱である．
流出する空気が単位質量あたりに持ち去るエネルギーは，このエンタルピー $h=c_pT$ である．

温度が $dT$ だけ上がる間に，室内の空気の質量が $dM$ だけ変化するとする．
空気が流出するので $dM<0$ である．
このとき，流出する質量は $-dM$ であり，その空気が持ち去るエネルギーは，

```math
-c_pT\,dM
```

となる．
室内の内部エネルギー変化が $dU=0$ であるため，この流出によるエネルギーを補うために必要な微小熱量 $d'Q$ は，

```math
d'Q=-c_pT\,dM
\tag{2}
```

と表される．

式 (1) を温度 $T$ で微分すると，

```math
dM=-\frac{M_1T_1}{T^2}\,dT
```

を得る．
これを式 (2) に代入すれば，

```math
\begin{aligned}
d'Q &=c_pT\frac{M_1T_1}{T^2}\,dT\\
&=c_pM_1\frac{T_1}{T}\,dT
\end{aligned}
```

となる．
ここで，式 (1) の $M(T)=M_1T_1/T$ を用いると，

```math
\boxed{
d'Q=M(T)c_p\,dT
}
\tag{3}
```

を得る．

このように，解答例の $M(T)c_p\,dT$ という式は，単に室内に残る空気を温めるための熱量というだけではなく，流出する空気が持ち去るエネルギーも考慮したエネルギー収支から導かれる．

#### 3．必要な熱量を積分する

温度を $T_1$ から $T_2$ まで上げるために必要な熱量 $Q$ は，式 (3) を積分することにより，

```math
Q=\int_{T_1}^{T_2}M(T)c_p\,dT
```

で与えられる．
式 (1) を代入すると，

```math
\begin{aligned}
Q &=\int_{T_1}^{T_2} M_1\frac{T_1}{T}c_p\,dT\\
&=c_pM_1T_1 \int_{T_1}^{T_2}\frac{1}{T}\,dT
\end{aligned}
```

となる．
これを積分すれば，

```math
\begin{aligned}
Q &=c_pM_1T_1 \left[\ln T\right]_{T_1}^{T_2}\\
&=c_pM_1T_1 \ln\left(\frac{T_2}{T_1}\right)
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
Q=c_pM_1T_1 \ln\left(\frac{T_2}{T_1}\right)
}
\tag{4}
```

となる．
ここで， $\ln$ は自然対数を表す．

#### 4．数値を代入する

加熱開始時の空気の質量 $M_1$ は，(i) で求めた値である．したがって，

```math
M_1c_p\simeq8.29\times10^3\,\mathrm{cal/deg}
```

を用いることができる．
また，絶対温度は，

```math
T_1=273\,\mathrm{K},\qquad
T_2=293\,\mathrm{K}
```

である．
これらを式 (4) に代入すると，

```math
\begin{aligned}
Q &=8.29\times10^3\times273 \ln\left(\frac{293}{273}\right)\\
&\simeq8.29\times10^3\times273\times0.0707\\
&\simeq1.60\times10^5\,\mathrm{cal}
\end{aligned}
```

となる．
よって，必要な熱量は，

```math
\boxed{
Q\simeq1.60\times10^5\\,\mathrm{cal}
}
```

である．

## 3．結果のまとめ

| 条件 | 必要な熱量 |
| ------------------------ | ----------------------------------- |
| (i) 定積加熱 | $1.18\times10^5\,\mathrm{cal}$ |
| (ii) 定圧加熱 | $1.66\times10^5\,\mathrm{cal}$ |
| (iii) 定積の部屋で空気を流出させながら加熱 | $1.60\times10^5\,\mathrm{cal}$ |

(i) では体積が一定であるため，膨張仕事はなく，熱量は内部エネルギーの増加に使われる．
(ii) では空気が膨張して外部に仕事をするため，(i) より多くの熱量が必要である．
(iii) では室内に残る空気の質量が減少する一方，流出する空気がエネルギーを外部へ持ち去るため，その分を補う熱量が必要となる．
このエネルギー収支を考慮することで，(iii) の熱量が求められる．
