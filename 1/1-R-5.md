# 例題【1-R-5】

## 解答

空気を理想気体とみなし，比熱は一定とする．
前問で与えられた空気の性質は，

```math
\begin{aligned}
\rho&=0.00129\,\mathrm{g/cm^3},\\
c_p&=0.238\,\mathrm{cal/(g\cdot deg)},\\
\gamma&=\frac{c_p}{c_v}=1.41
\end{aligned}
```

である．
以下では，これらの値を用いて各場合に必要な熱量を求める．

### (i) 体積を一定にして加熱する場合

まず， $0^\circ\mathrm{C}$ ，1 atm，体積 $V=27\,\mathrm{m^3}$ の空気の質量 $M$ を求める．

体積の単位を $\mathrm{cm^3}$ に変換すると，

```math
27\,\mathrm{m^3}=27\times10^6\,\mathrm{cm^3}
```

である．
したがって，密度と体積の関係 $M=\rho V$ より，

```math
\begin{aligned}
M&=0.00129\times27\times10^6\\
&=3.483\times10^4\,\mathrm{g}
\end{aligned}
```

を得る．

次に，定積比熱 $c_v$ を求める．
比熱比の定義 $\gamma=c_p/c_v$ より，

```math
\begin{aligned}
c_v&=\frac{c_p}{\gamma}\\
&=\frac{0.238}{1.41}\\
&\simeq0.1687943\,\mathrm{cal/(g\cdot deg)}
\end{aligned}
```

となる．

この空気全体の定積熱容量 $C_V$ は，質量に定積比熱を掛けて，

```math
\begin{aligned}
C_V&=Mc_v\\
&=3.483\times10^4\times0.1687943\\
&\simeq5.8791\times10^3\,\mathrm{cal/deg}
\end{aligned}
```

と求められる．

定積過程では体積が一定であるため，気体は外部に膨張仕事をしない．
したがって，加えられた熱量はすべて内部エネルギーの増加に使われる．
比熱を一定とすると，温度を $T_1$ から $T_2$ まで上げるのに必要な熱量 $Q_V$ は，

```math
Q_V=\int_{T_1}^{T_2}C_V\,dT
=C_V(T_2-T_1)
```

である．

温度変化は，

```math
T_2-T_1=20\,\mathrm{K}
```

なので，

```math
\begin{aligned}
Q_V
&=5.8791\times10^3\times20\\
&\simeq1.1758\times10^5\,\mathrm{cal}
\end{aligned}
```

となる．
よって，

```math
\boxed{
Q_V\simeq1.18\times10^5\,\mathrm{cal}
}
```

を得る．

### (ii) 1 atm の下で加熱する場合

今度は， $0^\circ\mathrm{C}$ で体積 $27\,\mathrm{m^3}$ をもっていた空気を，圧力1 atmに保ちながら $20^\circ\mathrm{C}$ まで加熱する．
この場合，空気の質量は一定であるが，温度上昇に伴って体積が増加する．
そのため，気体は外部に膨張仕事をし，定積加熱よりも多くの熱量を必要とする．

この過程では，定積熱容量 $C_V$ の代わりに定圧熱容量 $C_p$ を用いる．
空気全体の定圧熱容量は，

```math
C_p=Mc_p
```

で与えられる．
また，比熱比より $C_p/C_V=\gamma$ であるから，

```math
\begin{aligned}
C_p&=\gamma C_V\\
&=1.41\times5.8791\times10^3\\
&\simeq8.2895\times10^3\,\mathrm{cal/deg}
\end{aligned}
```

となる．

比熱が一定であるため，必要な熱量 $Q_p$ は，

```math
Q_p=C_p(T_2-T_1)
```

で与えられる．
したがって，

```math
\begin{aligned}
Q_p&=8.28954\times10^3\times20\\
&=1.657908\times10^5\,\mathrm{cal}
\end{aligned}
```

となる．
よって，

```math
\boxed{
Q_p\simeq1.66\times10^5\,\mathrm{cal}
}
```

を得る．

### (iii) 体積 $27\,\mathrm{m^3}$ の部屋で，空気を逃がしながら加熱する場合

この場合，部屋の体積は一定である一方，壁の小孔から空気が逃げるため，室内に残る空気の質量は温度とともに変化する．
また，室内をゆっくり加熱し，内部の圧力が外圧1 atmにほぼ等しく保たれるとみなす．
厳密には流出を維持するために室内圧力と外圧との間にわずかな差が必要であるが，ここではその差を無視する準静的近似を用いる．

さらに，室内の空気は十分に混合されて温度が一様であり，流出する空気の温度は室内の温度に等しいとする．
流出速度は十分小さく，流出空気の運動エネルギーおよび位置エネルギーの変化を無視する．

この過程では，流出する空気がエネルギーを持ち去るため，その分も考慮して必要な熱量を求める必要がある．

#### 1．温度 $T$ における室内の空気の質量

室内の体積を $V$ ，温度 $T$ における空気の質量を $M(T)$ ，空気のモル質量を $m$ とする．
理想気体の状態方程式は，

```math
pV=\frac{M(T)}{m}RT
```

と書ける．
ここで， $R$ はモル気体定数である．

圧力 $p$ ，体積 $V$ ，モル質量 $m$ ，気体定数 $R$ は一定であるため，

```math
M(T)T=\frac{pmV}{R}=\mathrm{const.}
```

となる．

加熱開始時の絶対温度を

```math
T_1=273.15\,\mathrm{K}
```

とし，そのときの空気の質量を $M_1$ とする．
すると，

```math
M(T)T=M_1T_1
```

であるから，

```math
\boxed{
M(T)=M_1\frac{T_1}{T}
}
\tag{1}
```

となる．
すなわち，室内の体積と圧力を一定に保つため，温度が高くなるほど室内に残る空気の質量は小さくなる．

#### 2．開放系のエネルギー収支

部屋の内部を検査体積とする．部屋の壁は動かないため，検査体積の境界がする体積仕事はない．
また，軸仕事などの体積仕事以外の仕事，室内の空気の巨視的な運動エネルギーおよび位置エネルギーの変化を無視する．
空気の流入はなく，小孔からの流出のみを考える．

このとき，開放系の非定常エネルギー収支は，流出空気の運動エネルギーおよび位置エネルギーを含めて書けば，

```math
dU=\delta Q-
\left(
h_{\mathrm{out}}+\frac{w_{\mathrm{out}}^2}{2}
+gz_{\mathrm{out}}
\right)dm_{\mathrm{out}}
```

となる．
ここで， $U$ は室内の空気全体の内部エネルギー， $\delta Q$ は室内に供給する微小熱量， $h_{\mathrm{out}}$ は流出する空気の単位質量あたりのエンタルピー， $dm_{\mathrm{out}}$ は微小時間に流出する空気の質量であり，正の値とする．
また， $w_{\mathrm{out}}$ は流出速度， $z_{\mathrm{out}}$ は流出位置の高さ， $g$ は重力加速度である．

上記の近似により，流出空気の運動エネルギーおよび位置エネルギーを無視すると，

```math
dU=\delta Q-h_{\mathrm{out}}\,dm_{\mathrm{out}}
\tag{2}
```

となる．

室内に残る空気の質量が $dM$ だけ変化するとき，流出のみを考えているため，

```math
dm_{\mathrm{out}}=-dM
```

である．
したがって，式（2）は，

```math
\boxed{
\delta Q=dU-h_{\mathrm{out}}\,dM
}
\tag{3}
```

となる．

理想気体の単位質量あたりの内部エネルギーを $u$ とすると，定積比熱が一定であるため，

```math
du=c_v\,dT
```

である．
室内の空気全体の内部エネルギー $U$ は，

```math
U=M(T)u(T)
```

であるから，その微分は，

```math
dU=u\,dM+M\,du
```

となる．
よって，

```math
dU=u\,dM+Mc_v\,dT
\tag{4}
```

を得る．

一方，理想気体の単位質量あたりのエンタルピー $h$ は，

```math
h=u+pv_{\mathrm{s}}
```

と表される．
ここで， $v_{\mathrm{s}}$ は単位質量あたりの比容である．
理想気体の状態方程式より，

```math
pv_{\mathrm{s}}=R_{\mathrm{s}}T
```

であるから，

```math
h=u+R_{\mathrm{s}}T
```

となる．
ここで， $R_{\mathrm{s}}$ は単位質量あたりの気体定数である．
流出する空気は室内と同じ温度で流出すると仮定するため，

```math
h_{\mathrm{out}}=u+R_{\mathrm{s}}T
```

である．

式（3），（4）にこれを代入すると，

```math
\begin{aligned}
\delta Q
&=u\,dM+Mc_v\,dT
-(u+R_{\mathrm{s}}T)dM\\
&=Mc_v\,dT-R_{\mathrm{s}}T\,dM
\end{aligned}
\tag{5}
```

となる．

ここで，式（1）より，

```math
MT=M_1T_1=\mathrm{const.}
```

であるから，これを微分すると，

```math
T\,dM+M\,dT=0
```

したがって，

```math
-T\,dM=M\,dT
\tag{6}
```

となる．

式（6）を式（5）に代入すれば，

```math
\begin{aligned}
\delta Q
&=Mc_v\,dT+MR_{\mathrm{s}}\,dT\\
&=M(c_v+R_{\mathrm{s}})\,dT
\end{aligned}
```

を得る．
マイヤーの関係式

```math
c_p-c_v=R_{\mathrm{s}}
```

より，

```math
\boxed{
\delta Q=M(T)c_p\,dT
}
\tag{7}
```

となる．

#### 3．必要な熱量を積分する

温度を $T_1$ から $T_2$ まで上げるために必要な熱量 $Q$ は，式（7）を積分することにより，

```math
Q=\int_{T_1}^{T_2}M(T)c_p\,dT
```

で与えられる．
式（1）を代入すると，

```math
\begin{aligned}
Q
&=\int_{T_1}^{T_2}M_1\frac{T_1}{T}c_p\,dT\\
&=c_pM_1T_1\int_{T_1}^{T_2}\frac{1}{T}\,dT
\end{aligned}
```

となる．
これを積分すれば，

```math
\begin{aligned}
Q
&=c_pM_1T_1\left[\ln T\right]_{T_1}^{T_2}\\
&=c_pM_1T_1\ln\left(\frac{T_2}{T_1}\right)
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
Q=c_pM_1T_1\ln\left(\frac{T_2}{T_1}\right)
}
\tag{8}
```

となる．
ここで， $\ln$ は自然対数を表す．

#### 4．数値を代入する

加熱開始時の空気の質量 $M_1$ は，（i）で求めた初期質量と同じである．
また，空気全体の定圧熱容量 $M_1c_p$ は，

```math
\begin{aligned}
M_1c_p
&=3.483\times10^4\times0.238\\
&=8.28954\times10^3\,\mathrm{cal/deg}
\end{aligned}
```

である．

絶対温度は，

```math
T_1=273.15\,\mathrm{K},\qquad
T_2=293.15\,\mathrm{K}
```

である．
これらを式（8）に代入すると，

```math
\begin{aligned}
Q
&=8.28954\times10^3\times273.15
\ln\left(\frac{293.15}{273.15}\right)\\
&\simeq1.6000\times10^5\,\mathrm{cal}
\end{aligned}
```

となる．
よって，必要な熱量は，

```math
\boxed{
Q\simeq1.60\times10^5\,\mathrm{cal}
}
```

である．

## 3．結果のまとめ

| 条件 | 必要な熱量 |
|---|---:|
| (i) 定積加熱 | $1.18\times10^5\,\mathrm{cal}$ |
| (ii) 定圧加熱 | $1.66\times10^5\,\mathrm{cal}$ |
| (iii) 定積の部屋で空気を流出させながら加熱 | $1.60\times10^5\,\mathrm{cal}$ |

(i) では体積が一定であるため，膨張仕事はなく，熱量は内部エネルギーの増加に使われる．

(ii) では空気が膨張して外部に仕事をするため，(i) より多くの熱量が必要である．

(iii) では室内に残る空気の質量が減少する一方，流出する空気がエンタルピーを外部へ持ち去るため，その分を補う熱量が必要となる．開放系のエネルギー収支を考慮することで，(iii) の熱量が求められる．
