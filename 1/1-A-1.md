# 演習問題【1-A-1】

## 解答

### 1．状態方程式の全微分

圧力 $p$ は，温度 $T$ と体積 $V$ の関数である．
したがって，温度と体積がそれぞれ微小量 $dT$ ， $dV$ だけ変化するとき，圧力の変化 $dp$ は，全微分の公式から，

```math
dp=
\left(\frac{\partial p}{\partial T}\right)_VdT+
\left(\frac{\partial p}{\partial V}\right)_TdV
\tag{1}
```

と表される．

ここで， $\left(\frac{\partial p}{\partial T}\right)_V$ は体積を一定に保ったときの圧力の温度変化率を表し， $\left(\frac{\partial p}{\partial V}\right)_T$ は温度を一定に保ったときの圧力の体積変化率を表す．

### 2．各係数の定義を代入する

問題で定義された定積圧力係数は，

```math
\alpha_p=\frac{1}{p}
\left(\frac{\partial p}{\partial T}\right)_V
```

である．
したがって，

```math
\boxed{
\left(\frac{\partial p}{\partial T}\right)_V
=p\alpha_p
}
\tag{2}
```

となる．

また，等温体積弾性率は，

```math
k=-V\left(\frac{\partial p}{\partial V}\right)_T
```

と定義されている．
これを変形すると，

```math
\boxed{
\left(\frac{\partial p}{\partial V}\right)_T
=-\frac{k}{V}
}
\tag{3}
```

を得る．

式(2)，式(3)を式(1)に代入すれば，

```math
\boxed{
dp=p\alpha_p\,dT-\frac{k}{V}\,dV
}
\tag{4}
```

となる．

### 3．定圧条件を用いる

次に，圧力を一定に保ちながら温度と体積を変化させる場合を考える．
このとき，圧力は変化しないため，

```math
dp=0
```

である．
これを式(4)に代入すると，

```math
0=p\alpha_p\,dT-\frac{k}{V}\,dV
```

となる．
これを $dV$ について整理すると，

```math
\frac{k}{V}\,dV=p\alpha_p\,dT
```

を得る．
したがって，

```math
\frac{dV}{dT}=\frac{Vp\alpha_p}{k}
\tag{5}
```

となる．

ここで，圧力 $p$ を一定に保っているので，体積 $V$ は温度 $T$ の関数として変化する．
したがって，式(5)の変化率は，定圧条件での偏微分

```math
\boxed{
\left(\frac{\partial V}{\partial T}\right)_p
\=\frac{Vp\alpha_p}{k}
}
\tag{6}
```

に相当する．

### 4．定圧膨張係数を用いて証明する

定圧膨張係数の定義は，

```math
\alpha_V=\frac{1}{V}
\left(\frac{\partial V}{\partial T}\right)_p
\tag{7}
```

である．
式(6)を式(7)に代入すると，

```math
\begin{aligned}
\alpha_V
&=\frac{1}{V}\frac{Vp\alpha_p}{k} \\
&=\frac{p\alpha_p}{k}
\end{aligned}
```

となる．
両辺に $k$ を掛ければ，

```math
\boxed{
p\alpha_p=k\alpha_V
}
```

が得られる．
よって，求める関係式が証明された．


## 解説

各係数の物理的意味は以下の通りである．

定積圧力係数 $\alpha_p$ は，体積を一定にしたとき，温度変化によって圧力がどれほど変化するかを表す量である．

定圧膨張係数 $\alpha_V$ は，圧力を一定にしたとき，温度変化によって体積がどれほど変化するかを表す量である．

等温体積弾性率 $k$ は，温度を一定にしたときの圧力の体積変化に対する応答を表す量である．
通常の安定な物質では $k>0$ であり，値が大きいほど圧縮されにくい．

今回の関係式は，全微分に各係数の定義を代入し，定圧条件を適用することで得られる．
なお，式変形では $k\neq0$ を仮定している．

微分記法を定圧偏微分に統一する定圧経路の意味をさらに明確にする．
