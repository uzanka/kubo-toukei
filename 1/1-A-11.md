# 演習問題【1-A-11】

## 解答

この問題は，Mayerのサイクルと呼ばれる循環過程におけるエネルギーの出入りを，熱力学第1法則を用いて追跡することで，定圧モル比熱 $C_p$ と定積モル比熱 $C_v$ の関係（ $C_p - C_v = R$ ）を導出するものである．

### 1. 各過程における熱量 $Q$ と仕事 $W$ の整理

循環過程全体の熱力学第1法則は，吸収した熱量の総和 $\sum Q$ と，外部に対してなした仕事の総和 $\sum W_{\text{out}}$ の関係として次のように書ける．

$$\sum Q - \sum W_{\text{out}} = 0 \quad \text{（循環過程における内部エネルギー
変化はゼロのため）}$$

図に基づき，各過程を整理する．

#### (i) 過程 $1 \to 2$ （自由断熱膨張）

自由膨張とは，外部に抵抗がない（外圧 $p^{(e)} = 0$ ）状態で膨張することである．
- **仕事** : 外圧が $0$ であるため，気体が外部になす仕事は $W_{1 \to 2} = 0$ である．
- **熱量** : 断熱過程であるため，熱の出入りはない． $Q_{1 \to 2} = 0$ である．
- **内部エネルギー** : $\Delta U_{1 \to 2} = Q - W_{\text{out}} = 0$ であるため，内部エネルギーは変化しない．
理想気体の内部エネルギーは温度のみの関数であるから，温度も変化しない（ $T_1 = T_2$ ）．

#### (ii) 過程 $2 \to 3$ （等圧圧縮）

圧力 $p_2$ を一定に保ったまま，体積を $V_2$ から $V_1$ へ減少させる準静的な過程である．
- **仕事** : 気体が外部になす仕事は $W_{2 \to 3} = \int_{V_2}^{V_1} p_2 \, dV = p_2(V_1 - V_2)$ である．
- **熱量** : 定圧過程であるため，吸収する熱量は $Q_{2 \to 3} = \int_{T_2}^{T_3} C_p \, dT = C_p(T_3 - T_2)$ である．

#### (iii) 過程 $3 \to 1$ （等積加熱）

体積 $V_1$ を一定に保ったまま，圧力を $p_2$ から $p_1$ へ上昇させる準静的な過程である．
- **仕事** : 体積が変化しないため，仕事は $W_{3 \to 1} = 0$ である．
- **熱量** : 定積過程であるため，吸収する熱量は $Q_{3 \to 1} = \int_{T_3}^{T_1} C_v \, dT = C_v(T_1 - T_3)$ である．

### 2. Mayerの関係式の導出

循環過程におけるエネルギーの総和（熱量 $\sum Q$ と仕事 $\sum W_{\text{out}}$ の合計）が $0$ になることを利用する．

$$\sum Q = Q_{1 \to 2} + Q_{2 \to 3} + Q_{3 \to 1} = 0 + C_p(T_3 - T_2) + C_v(T_1 - T_3)$$

$$\sum W_{\text{out}} = W_{1 \to 2} + W_{2 \to 3} + W_{3 \to 1} = 0 + p_2(V_1 - V_2) + 0$$

熱力学第1法則 $\sum Q - \sum W_{\text{out}} = 0$ より，

$$C_p(T_3 - T_2) + C_v(T_1 - T_3) - p_2(V_1 - V_2) = 0$$

ここで， $T_1 = T_2$ であることを用いると，

$$C_p(T_3 - T_1) + C_v(T_1 - T_3) - p_2(V_1 - V_2) = 0$$

$$(C_p - C_v)(T_3 - T_1) + p_2(V_2 - V_1) = 0 \quad \cdots (A)$$

次に，理想気体の状態方程式 $pV = RT$ を用いて，圧力と体積の項を温度に変換する．
- 状態 1 ( $p_1, V_1, T_1$ ) より： $p_1 V_1 = RT_1$
- 状態 2 ( $p_2, V_2, T_2$ ) より： $p_2 V_2 = RT_2 = RT_1$ （ $T_1 = T_2$ より）
- 状態 3 ( $p_2, V_1, T_3$ ) より： $p_2 V_1 = RT_3$

これらを用いると，

$$p_2(V_2 - V_1) = p_2 V_2 - p_2 V_1 = RT_1 - RT_3 = R(T_1 - T_3)$$

となる．
これを式 $(A)$ に代入すると，

$$(C_p - C_v)(T_3 - T_1) + R(T_1 - T_3) = 0$$

$$(C_p - C_v)(T_3 - T_1) - R(T_3 - T_1) = 0$$

$$(C_p - C_v - R)(T_3 - T_1) = 0$$

$T_3 \neq T_1$ である（過程 $3 \to 1$ は加熱であるため）ことから，

$$C_p - C_v - R = 0 \implies C_p - C_v = R$$

が成り立つ．

よって，Mayerの関係式が証明された．

## 解説

### 1. 自由膨張の特殊性

このサイクルの最初のステップである「自由膨張」は，他の過程とは異なり **準静的ではない** ．
しかし，温度が変化しない（内部エネルギーが変わらない）という性質さえ保たれていれば，循環全体のエネルギー収支を考える上では問題なく扱うことができる．

### 2. Mayerのサイクルの物理的イメージ

このサイクルは，以下の3つのステップで構成されている．
1. **エネルギーの「解放」** : 膨張によって，気体が持っていたエネルギーを仕事（あるいは温度低下）として外に出す．
2. **エネルギーの「回収」** : 圧縮によって，外から仕事をしてもらう．
3. **エネルギーの「補填」** : 最後に熱を加えて，元の温度に戻す．

この一連のプロセスを通じて，熱（ $Q$ ）と仕事（ $W$ ）の間に，比熱の差 $C_p - C_v$ が介在することを数学的に示している．

### 3. なぜ $C_p > C_v$ なのか

この問題の結論である $C_p - C_v = R$ は，定圧比熱が定積比熱よりも常に大きいことを示している．
これは，定圧過程では「温度を上げるための熱」に加えて，「膨張して外に仕事をするためのエネルギー」も必要になるため，より多くの熱量が必要になるという物理的直感と一致している．
