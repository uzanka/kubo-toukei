# 演習問題【1-A-11】

## 解答

Mayerのサイクルに熱力学第1法則を適用し，定圧モル比熱 $C_P$ と定積モル比熱 $C_V$ の間に，

```math
\boxed{
C_P-C_V=R
}
```

が成り立つことを示す．
ここで， $R$ はモル気体定数である．
以下では，気体が吸収する熱量を正，気体が外界になす仕事を正とし，熱力学第1法則を

```math
\Delta U=Q-W_{\mathrm{out}}
```

と表す．

### 1．過程 $1\to2$ ：自由断熱膨張

状態1 $(p_1,V_1,T_1)$ にある $1\,\mathrm{mol}$ の理想気体を，断熱条件のもとで体積 $V_2$ まで自由膨張させ，状態2 $(p_2,V_2,T_2)$ に移す．

自由膨張では，気体は外圧がゼロのもとで膨張するため，外界になす仕事はゼロである．すなわち，

```math
W_{\mathrm{out},12}=0
```

である．
また，断熱過程では熱の出入りがないので，

```math
Q_{12}=0
```

となる．
これらを熱力学第1法則に代入すると，

```math
\begin{aligned}
U_2-U_1
&=Q_{12}-W_{\mathrm{out},12}\\
&=0
\end{aligned}
```

を得る．
したがって，

```math
U_2=U_1
```

である．

理想気体の内部エネルギーは温度のみの関数であるため，内部エネルギーが変化しなければ温度も変化しない．
よって，

```math
\boxed{T_2=T_1}
\tag{1}
```

が成り立つ．

なお，自由膨張は準静的過程ではないため，途中の気体の圧力を用いて $W_{\mathrm{out},12}=\int p\,dV$ と計算することはできない．
ここでは，外圧がゼロであることから仕事がゼロであると判断している．

### 2．過程 $2\to3$ ：等圧圧縮

次に，状態2から圧力 $p_2$ を一定に保ちながら，体積が $V_1$ となるまで準静的に圧縮する．
この終状態を状態3 $(p_2,V_1,T_3)$ とする．

この過程で気体が外界になす仕事は，

```math
\begin{aligned}
W_{\mathrm{out},23}
&=\int_{V_2}^{V_1}p_2\,dV\\
&=p_2(V_1-V_2)
\end{aligned}
```

である．
ここでは $V_2>V_1$ なので， $W_{\mathrm{out},23}<0$ となる．
すなわち，外部から気体に仕事がなされている．

また，定圧モル比熱 $C_P$ は，定圧過程で気体の温度を $dT$ だけ変化させるために必要な微小熱量を $d'Q=C_P\,dT$ と表したときの係数である．
比熱を一定とすると，この過程で気体が吸収する熱量は，

```math
\begin{aligned}
Q_{23}
&=\int_{T_2}^{T_3}C_P\,dT\\
&=C_P(T_3-T_2)
\end{aligned}
```

となる．
圧縮によって温度が低下するため，この熱量は負であり，気体は外部へ熱を放出する．

### 3．過程 $3\to1$ ：等積加熱

状態3から，体積 $V_1$ を一定に保ったまま，加熱して状態1に戻す．
体積変化がないため，気体が外界になす仕事は，

```math
W_{\mathrm{out},31}=0
```

である．

定積モル比熱を $C_V$ とすると，気体が吸収する熱量は，

```math
\begin{aligned}
Q_{31}
&=\int_{T_3}^{T_1}C_V\,dT\\
&=C_V(T_1-T_3)
\end{aligned}
```

となる．
ここでは $T_1>T_3$ なので， $Q_{31}>0$ であり，気体は熱を吸収する．

### 4．循環過程全体に熱力学第1法則を適用する

状態1から状態2，状態3を経て状態1に戻る循環過程では，最終状態が初期状態と同じであるため，内部エネルギーの変化はゼロである．したがって，

```math
\Delta U_{\mathrm{cycle}}=0
```

となる．
熱力学第1法則より，

```math
\sum Q-\sum W_{\mathrm{out}}=0
```

が成り立つ．

各過程の熱量と仕事を代入すると，

```math
\begin{aligned}
&Q_{12}+Q_{23}+Q_{31}\\
&\qquad-\left(
W_{\mathrm{out},12}
+W_{\mathrm{out},23}
+W_{\mathrm{out},31}
\right)=0
\end{aligned}
```

となる．
ここで，

```math
Q_{12}=0,\qquad
W_{\mathrm{out},12}=0,\qquad
W_{\mathrm{out},31}=0
```

であるから，

```math
C_P(T_3-T_2)+C_V(T_1-T_3)
-p_2(V_1-V_2)=0
```

を得る．
これを整理すると，

```math
C_P(T_3-T_2)+C_V(T_1-T_3)
+p_2(V_2-V_1)=0
```

となる．
さらに，式（1）の $T_2=T_1$ を代入すれば，

```math
C_P(T_3-T_1)+C_V(T_1-T_3)
+p_2(V_2-V_1)=0
```

である．
したがって，

```math
\boxed{
(C_P-C_V)(T_3-T_1)
+p_2(V_2-V_1)=0
}
\tag{2}
```

が得られる．

### 5．理想気体の状態方程式からMayerの関係式を導く

気体は $1\,\mathrm{mol}$ なので，理想気体の状態方程式は，

```math
pV=RT
```

である．
状態2では，

```math
p_2V_2=RT_2
```

であり，式（1）より $T_2=T_1$ であるため，

```math
p_2V_2=RT_1
\tag{3}
```

となる．
一方，状態3では，

```math
p_2V_1=RT_3
\tag{4}
```

が成り立つ．

式（3）から式（4）を引くと，

```math
p_2(V_2-V_1)=R(T_1-T_3)
```

を得る．
これを式（2）に代入すると，

```math
(C_P-C_V)(T_3-T_1)+R(T_1-T_3)=0
```

となる．
ここで $T_1-T_3=-(T_3-T_1)$ であるから，

```math
(C_P-C_V)(T_3-T_1)-R(T_3-T_1)=0
```

すなわち，

```math
(C_P-C_V-R)(T_3-T_1)=0
```

を得る．

最後に， $V_2>V_1$ であることと式（3），（4）から，

```math
T_3=\frac{p_2V_1}{R}
<
\frac{p_2V_2}{R}=T_1
```

となる．
したがって $T_3-T_1\neq0$ であるため，

```math
C_P-C_V-R=0
```

でなければならない．
よって，

```math
\boxed{
C_P-C_V=R
}
```

となり，Mayerの関係式が示された．

## 解説

この証明の要点は，Mayerのサイクルを構成する3つの過程について，熱量と仕事をそれぞれ求め，循環過程全体に熱力学第1法則を適用することである．

自由断熱膨張では熱の出入りも仕事もゼロであり，理想気体の内部エネルギーと温度は変化しない．
等圧圧縮では外部から仕事がなされるとともに熱が放出され，等積加熱では仕事をせずに熱を吸収する．
このように各過程のエネルギー収支を整理すると，定圧モル比熱と定積モル比熱の差が現れる．

さらに，理想気体の状態方程式を用いることで，圧力と体積の差を温度差に置き換えられる．
これによって循環過程全体のエネルギー収支は，

```math
(C_P-C_V-R)(T_3-T_1)=0
```

と表される．
$T_3\neq T_1$ であることから， $C_P-C_V=R$ が導かれる．

なお，この証明では自由膨張の仕事がゼロであることが重要であり， $pV$ 図に描かれた自由膨張の曲線の面積から仕事を求めているわけではない．
自由膨張は準静的過程ではないため，その途中の気体の圧力を用いて仕事を積分することはできない．
