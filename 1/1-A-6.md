# 演習問題【1-A-6】

## 解答

### 1．状態1から状態2への断熱過程

状態1 $(p_1,V_1,T_1)$ から状態2 $(p_2,V_2,T_2)$ への準静的断熱過程を考える．
気体が外界になす仕事を $W_{12}$ ，気体が外部から受け取る熱量を $Q_{12}$ ，内部エネルギーを $U$ とする．
ここでは，気体が外界になす仕事を正とする．

熱力学第1法則より，内部エネルギーの変化は，

```math
U_2-U_1=Q_{12}-W_{12}
```

と表される．
断熱過程では気体と外界との間に熱の出入りがないため，

```math
Q_{12}=0
```

である．
したがって，

```math
U_2-U_1=-W_{12}
```

となり，

```math
\boxed{
U_2=U_1-W_{12}
}
\tag{1}
```

を得る．
つまり，気体が外界に仕事をすると，その仕事に相当する分だけ気体の内部エネルギーが減少する．

### 2．状態2から状態3への定積加熱過程

次に，過程 $1\to2$ で気体が外界になした仕事 $W_{12}$ を熱に変換し，状態2の気体に体積を一定に保って加える．
この加熱過程の終状態を状態3 $(p_3,V_3,T_3)$ とし，気体に供給する熱量を $Q_{23}$ とする．

気体が外界になした仕事をすべて熱に変換して供給するため，

```math
Q_{23}=W_{12}
```

である．
また，体積一定の過程では $V_3=V_2$ であるから，気体が外界になす仕事 $W_{23}$ は，

```math
W_{23}=\int_{V_2}^{V_3}p\,dV=0
```

となる．

この過程に熱力学第1法則を適用すると，

```math
U_3-U_2=Q_{23}-W_{23}
```

である．
$W_{23}=0$ より，

```math
U_3-U_2=Q_{23}
```

となる．
ここに $Q_{23}=W_{12}$ を代入すると，

```math
U_3=U_2+W_{12}
```

を得る．
さらに，式（1）を用いれば，

```math
\begin{aligned}
U_3
&=U_2+W_{12}\\
&=U_1-W_{12}+W_{12}\\
&=U_1
\end{aligned}
```

となる．
したがって，

```math
\boxed{
U_3=U_1
}
```

が成り立つ．

### 3．温度が初めの温度に戻ることの証明

理想気体では，内部エネルギー $U$ は体積や圧力によらず，温度 $T$ のみによって決まる．
したがって，同じ種類，同じ量の理想気体では，内部エネルギーが等しければ温度も等しい．

先ほど，

```math
U_3=U_1
```

であることを示したので，

```math
\boxed{
T_3=T_1
}
```

が得られる．

よって，断熱過程で気体が外界になした仕事を熱に変換し，状態2の気体に体積一定のまま供給すると，気体の温度は初めの温度 $T_1$ に戻ることが示された．

## 解説

この問題の要点は，断熱過程と定積加熱過程における内部エネルギーの変化を，熱力学第1法則によって比較することである．

断熱過程 $1\to2$ では熱の出入りがないため，気体が外界になした仕事の分だけ内部エネルギーが減少する．
次に，その仕事に相当する熱量を気体に供給すると，定積過程 $2\to3$ では気体が外界になす仕事がゼロであるため，供給した熱量はすべて内部エネルギーの増加に使われる．

その結果，状態3の内部エネルギーは状態1の内部エネルギーに等しくなる．
理想気体の内部エネルギーは温度だけによって決まるので，最終的な温度 $T_3$ は初めの温度 $T_1$ に一致する．
