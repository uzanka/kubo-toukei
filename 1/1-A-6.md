# 演習問題【1-A-6】

## 解答

### 1．状態1から状態2への断熱過程

状態1 $(p_1,V_1,T_1)$ から状態2 $(p_2,V_2,T_2)$ への準静的断熱過程を考える．
気体が外部にした仕事を $W_{\mathrm{out}}$ とし，気体が外部にする仕事を正とする．

断熱過程では熱の出入りがないため，熱力学第1法則より，

```math
U_2-U_1=-W_{\mathrm{out}}
```

となる．
したがって，

```math
\boxed{
U_2=U_1-W_{\mathrm{out}}
}
\quad \cdots (1)
```

を得る．

### 2．状態2から状態3への定積加熱過程

次に，気体が外部にした仕事 $W_{\mathrm{out}}$ を全量回収して熱に変換し，状態2の気体に体積一定のまま加える．加える熱量を $Q_{\mathrm{add}}$ とすると，

```math
Q_{\mathrm{add}}=W_{\mathrm{out}}
```

である．

この加熱過程の終状態を状態3 $(p_3,V_3,T_3)$ とする．
体積一定の過程では気体が外部にする仕事はゼロであるため，熱力学第1法則より，

```math
U_3=U_2+Q_{\mathrm{add}}
```

となる．
ここに $Q_{\mathrm{add}}=W_{\mathrm{out}}$ を代入すると，

```math
U_3=U_2+W_{\mathrm{out}}
```

を得る．
さらに，式(1)を用いれば，

```math
\begin{aligned}
U_3
&=U_2+W_{\mathrm{out}} \\
&=U_1-W_{\mathrm{out}}+W_{\mathrm{out}} \\
&=U_1
\end{aligned}
```

となる．
したがって，

```math
\boxed{
U_3=U_1
}
```

が成り立つ．

### 3．温度への復帰

理想気体では，内部エネルギー $U$ は体積によらず，温度 $T$ のみによって決まる．
したがって，内部エネルギーが等しければ温度も等しいので，

```math
U_3=U_1
\quad\Longrightarrow\quad
\boxed{
T_3=T_1
}
```

となる．

よって，気体が外部にした仕事を熱に変換し，状態2の気体に体積一定のまま加えると，気体の温度は初めの温度 $T_1$ に戻ることが示された．

## 解説

この問題の要点は，断熱過程と定積過程における内部エネルギーの変化を，熱力学第1法則によって比較することである．

断熱膨張では，気体が外部にした仕事に相当する分だけ内部エネルギーが減少する．
一方，その仕事を全量熱に変換して気体に加えると，内部エネルギーは同じ量だけ増加する．

また，定積過程では気体が外部にする仕事がゼロであるため，加えた熱量はすべて内部エネルギーの増加に寄与する．
その結果，最終状態3の内部エネルギーは初期状態1の内部エネルギーに等しくなる．

理想気体の内部エネルギーは温度のみによって決まるため，最終温度 $T_3$ は初期温度 $T_1$ に一致する．
