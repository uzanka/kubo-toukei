# 演習問題【1-A-5】

## 解答

### 1．断熱体積弾性率 $k_{\mathrm{ad}}$ の導出

理想気体を準静的に断熱変化させるとき，圧力 $p$ と体積 $V$ の間には，ポアソンの法則

```math
pV^\gamma=\mathrm{const.}
```

が成り立つ．
ここで， $\gamma=c_p/c_v$ は比熱比である．

この式の両辺を微分すると，

```math
V^\gamma dp+\gamma pV^{\gamma-1}dV=0
```

となる．
両辺を $pV^\gamma$ で割ると，

```math
\frac{dp}{p}+\gamma\frac{dV}{V}=0
```

を得る．
これを変形すれば，

```math
\left(\frac{\partial p}{\partial V}\right)_{\mathrm{ad}}
=-\gamma\frac{p}{V}
```

となる．

体積弾性率は，体積の変化に対する圧力の変化の割合を表す量であり，断熱体積弾性率 $k_{\mathrm{ad}}$ は，

```math
k_{\mathrm{ad}}
=-V\left(\frac{\partial p}{\partial V}\right)_{\mathrm{ad}}
```

と定義される．
これに上の式を代入すると，

```math
\begin{aligned}
k_{\mathrm{ad}}
&=-V\left(-\gamma\frac{p}{V}\right)\\
&=\gamma p
\end{aligned}
```

となる．
したがって，断熱体積弾性率は，

```math
\boxed{
k_{\mathrm{ad}}=\gamma p
}
```

である．

なお，圧力が $p=1\,\mathrm{atm}=1.013\times10^6\,\mathrm{dyn/cm^2}$ ，空気の比熱比（実験値）が $\gamma=1.41$ のとき，

```math
\begin{aligned}
k_{\mathrm{ad}}
&=1.41\times1.013\times10^6\\
&=1.428\times10^6\,\mathrm{dyn/cm^2}
\end{aligned}
```

となる．
SI単位系では，

```math
\boxed{
k_{\mathrm{ad}}\simeq1.43\times10^5\,\mathrm{Pa}
}
```

である．

### 2．音速 $c$ の計算

音波が伝わるとき，気体の微小部分は圧縮と膨張を繰り返す．
この変化を断熱変化とみなすと，音速 $c$ は，

```math
c=\sqrt{\left(\frac{dp}{d\rho}\right)_{\mathrm{ad}}}
```

と表される．
ここで， $\rho$ は気体の密度である．

まず，気体の質量を一定とすると，密度と体積の間には，

```math
\rho=\frac{m}{V}
```

という関係が成り立つ．
これを微分すると，

```math
d\rho=-\frac{m}{V^2}dV
```

となる．
$\rho=m/V$ を用いれば，

```math
\frac{d\rho}{\rho}=-\frac{dV}{V}
```

が得られる．
したがって，

```math
\frac{dV}{d\rho}=-\frac{V}{\rho}
```

である．

これを用いると，断熱変化における圧力の密度に対する微分は，

```math
\begin{aligned}
\left(\frac{dp}{d\rho}\right)_{\mathrm{ad}}
&=\left(\frac{\partial p}{\partial V}\right)_{\mathrm{ad}}
\frac{dV}{d\rho}\\
&=-\frac{V}{\rho}
\left(\frac{\partial p}{\partial V}\right)_{\mathrm{ad}}\\
&=\frac{k_{\mathrm{ad}}}{\rho}
\end{aligned}
```

となる．
ここで， $k_{\mathrm{ad}}=\gamma p$ を代入すると，

```math
\left(\frac{dp}{d\rho}\right)_{\mathrm{ad}}
=\frac{\gamma p}{\rho}
```

を得る．
よって，音速は，

```math
c=\sqrt{\frac{\gamma p}{\rho}}
```

と表される．

次に，理想気体の状態方程式

```math
pV=nRT
```

を用いる．
ここで， $n$ は物質量， $R$ はモル気体定数， $T$ は絶対温度である．
また，気体のモル質量を $M$ とすると，密度は，

```math
\rho=\frac{nM}{V}
```

と表される．
状態方程式を密度で割ると，

```math
\frac{p}{\rho}=\frac{RT}{M}
```

となる．
これを音速の式に代入すれば，

```math
c=\sqrt{\frac{\gamma RT}{M}}
```

が得られる．
したがって，理想気体中の音速は，

```math
\boxed{
c=\sqrt{\frac{\gamma RT}{M}}
}
```

で与えられる．

ここで，空気について，

```math
\begin{aligned}
\gamma&=1.41,\\
R&=8.31\times10^7\,\mathrm{erg/(mol\,K)},\\
T&=273\,\mathrm{K},\\
M&=28.9\,\mathrm{g/mol}
\end{aligned}
```

を用いる．
これらを代入すると，

```math
\begin{aligned}
\frac{\gamma RT}{M}
&=\frac{1.41\times8.31\times10^7\times273}{28.9}\\
&\simeq1.1068\times10^9\,\mathrm{erg/g}
\end{aligned}
```

となる．
ここで，

```math
1\,\mathrm{erg}=1\,\mathrm{g\,cm^2/s^2}
```

であるから，

```math
1\,\mathrm{erg/g}=1\,\mathrm{cm^2/s^2}
```

となる．
したがって，

```math
\begin{aligned}
c
&=\sqrt{1.1068\times10^9}\\
&\simeq3.3269\times10^4\,\mathrm{cm/s}
\end{aligned}
```

を得る．
$1\,\mathrm{m}=100\,\mathrm{cm}$ であるため，

```math
c\simeq332.7\,\mathrm{m/s}
```

となる．
よって，有効数字3桁では， $0^\circ\mathrm{C}$ ， $1\,\mathrm{atm}$ の空気中での音速は，

```math
\boxed{
c=333\,\mathrm{m/s}
}
```

である．

### 3．音速の温度変化率 \(dc/dT\) の計算

音速の式

```math
c=\sqrt{\frac{\gamma RT}{M}}
```

において， $\gamma$ ， $R$ ， $M$ は一定とする．
この式を温度 $T$ について微分すると，

```math
\begin{aligned}
\frac{dc}{dT}
&=\left(\frac{\gamma R}{M}\right)^{1/2}
\frac{1}{2}T^{-1/2}\\
&=\frac{1}{2T}
\left(\frac{\gamma R}{M}\right)^{1/2}T^{1/2}
\end{aligned}
```

となる．
ここで，

```math
c=\left(\frac{\gamma R}{M}\right)^{1/2}T^{1/2}
```

であるから，

```math
\boxed{
\frac{dc}{dT}=\frac{c}{2T}
}
```

が得られる．

$T=273\,\mathrm{K}$ ， $c\simeq332.7\,\mathrm{m/s}$ を代入すると，

```math
\begin{aligned}
\frac{dc}{dT}
&=\frac{332.7}{2\times273}\\
&\simeq0.6093\,\mathrm{m/(s\,K)}
\end{aligned}
```

となる．
したがって，音速の温度変化率は，

```math
\boxed{
\frac{dc}{dT}=0.609\,\mathrm{m/(s\,K)}
}
```

である．
なお，温度差については $1\,\mathrm{K}$ と $1^\circ\mathrm{C}$ の大きさが等しいため，単位を $\mathrm{m/(s^\circ C)}$ としても数値は同じである．

## 解説

本問では，まずポアソンの法則から断熱体積弾性率を求め，次に密度と体積の関係および理想気体の状態方程式を用いて音速を導出し，最後に温度について微分して音速の温度変化率を求めた．

断熱体積弾性率 $k_{\mathrm{ad}}=\gamma p$ は，断熱変化に対する気体の圧縮されにくさを表す．
音速は，この弾性率と密度を用いて $c=\sqrt{k_{\mathrm{ad}}/\rho}$ と表される．
さらに，理想気体では $p/\rho=RT/M$ であるため，音速は温度の平方根に比例する．

その結果，

```math
c\propto\sqrt{T}
```

となり，温度が上昇すると音速も上昇する．
この比例関係を微分することで，

```math
\frac{dc}{dT}=\frac{c}{2T}
```

が得られる．

なお，音波の変化を断熱変化とみなすことの物理的根拠について補足する．
音波の振動数を $f$ ，空気の熱拡散率を $\chi\simeq 2\times10^{-5}\,\mathrm{m^2/s}$ とすると，時間スケル $\tau=1/f$ の間に熱が拡散する距離は

```math
\sqrt{\chi\tau}=\sqrt{\frac{\chi}{f}}
```

で与えられる．
一方，音波の波長は $\lambda=c/f$ であり，$c\simeq340\,\mathrm{m/s}$ を用いれば $\lambda\gg \sqrt{\chi\tau}$ となる．
例えば $f=100\,\mathrm{Hz}$ のとき，$\tau=0.01\,\mathrm{s}$ であって熱拡散距離は約 $1.4\,\mathrm{cm}$ であるが，波長は約 $3.4\,\mathrm{m}$ であり，圧縮・膨張する気体中に熱が均一に分配される暇がない．
したがって，通常の音叉や音声の周波数域では，音波による気体の圧縮・膨張を断熱過程とみなしてよい．

以上により，断熱体積弾性率，音速，および音速の温度変化率が求められた．
