# 演習問題【1-B-16】

## 解答

熱力学第1法則を出発点として，定積熱容量 $C_V$ ，定圧熱容量 $C_p$ の定義を導き，それらの間に成り立つ関係式を順に証明する．

以下では，系が受け取る微小熱量を $d'Q$ ，内部エネルギーを $U$ ，エンタルピーを $H$ とする．
準静的過程における熱力学第1法則は，

```math
d'Q=dU+p\,dV
\tag{1}
```

と表される．
ここでは，気体が外界にする仕事を $p\,dV$ とし，系が受け取る熱量を正とする．

### （i）定積熱容量と定圧熱容量の定義

まず，内部エネルギー $U$ を温度 $T$ と体積 $V$ の関数とみなすと，その全微分は，

```math
dU=
\left(\frac{\partial U}{\partial T}\right)_V dT
+
\left(\frac{\partial U}{\partial V}\right)_T dV
```

となる．
これを式（1）に代入すると，

```math
\begin{aligned}
d'Q={}&
\left(\frac{\partial U}{\partial T}\right)_VdT\\
&+\left\{
\left(\frac{\partial U}{\partial V}\right)_T+p
\right\}dV
\end{aligned}
\tag{2}
```

を得る．

定積過程では $dV=0$ であるから，式（2）は，

```math
d'Q=\left(\frac{\partial U}{\partial T}\right)_VdT
```

となる．
定積熱容量 $C_V$ は，体積を一定に保ったときの温度変化に対する吸熱量の割合として，

```math
C_V=\left(\frac{d'Q}{dT}\right)_V
```

と定義される．
したがって，

```math
\boxed{
C_V=\left(\frac{\partial U}{\partial T}\right)_V
}
```

が得られる．

次に，エンタルピー $H$ は，

```math
H=U+pV
```

と定義される．
両辺を微分すると，

```math
dH=dU+p\,dV+V\,dp
```

となる．
式（1）より $dU+p\,dV=d'Q$ であるから，

```math
d'Q=dH-V\,dp
\tag{3}
```

と書ける．

ここで，エンタルピー $H$ を温度 $T$ と圧力 $p$ の関数とみなすと，

```math
dH=
\left(\frac{\partial H}{\partial T}\right)_p dT
+
\left(\frac{\partial H}{\partial p}\right)_T dp
```

である．
これを式（3）に代入すると，

```math
\begin{aligned}
d'Q={}&
\left(\frac{\partial H}{\partial T}\right)_p dT\\
&+\left\{
\left(\frac{\partial H}{\partial p}\right)_T-V
\right\}dp
\end{aligned}
\tag{4}
```

を得る．

定圧過程では $dp=0$ であるため，

```math
d'Q=\left(\frac{\partial H}{\partial T}\right)_p dT
```

となる．
定圧熱容量 $C_p$ の定義より，

```math
\boxed{C_p=\left(\frac{\partial H}{\partial T}\right)_p}
```

が得られる．
以上で（i）が証明された．

### （ii）定圧熱容量と定積熱容量の差

#### （a）第1式の証明

式（2）を用いて，定圧熱容量 $C_p$ を求める．
体積 $V$ を圧力 $p$ と温度 $T$ の関数とみなすと，全微分は，

```math
dV=
\left(\frac{\partial V}{\partial T}\right)_p dT
+
\left(\frac{\partial V}{\partial p}\right)_T dp
```

である．
これを式（2）に代入すると，

```math
\begin{aligned}
d'Q={}&
\left[
C_V+
\left\{
\left(\frac{\partial U}{\partial V}\right)_T+p
\right\}
\left(\frac{\partial V}{\partial T}\right)_p
\right]dT\\
&+
\left\{
\left(\frac{\partial U}{\partial V}\right)_T+p
\right\}
\left(\frac{\partial V}{\partial p}\right)_Tdp
\end{aligned}
```

となる．
ここでは，（i）で得た関係式

```math
\left(\frac{\partial U}{\partial T}\right)_V=C_V
```

を用いた．

定圧過程では $dp=0$ であり， $d'Q=C_p\,dT$ であるから，

```math
C_p=C_V+
\left\{
p+\left(\frac{\partial U}{\partial V}\right)_T
\right\}
\left(\frac{\partial V}{\partial T}\right)_p
```

となる．
したがって，

```math
\boxed{
C_p-C_V=
\left(\frac{\partial V}{\partial T}\right)_p
\left\{
p+\left(\frac{\partial U}{\partial V}\right)_T
\right\}
}
\tag{5}
```

が得られる．
これが（ii）の第1式である．

#### （b）第2式の証明

次に，式（4）を用いて定積熱容量 $C_V$ を求める．
圧力 $p$ を温度 $T$ と体積 $V$ の関数とみなすと，

```math
dp=
\left(\frac{\partial p}{\partial T}\right)_VdT
+
\left(\frac{\partial p}{\partial V}\right)_T dV
```

である．
これを式（4）に代入し，（i）で得た
$\left(\dfrac{\partial H}{\partial T}\right)_p=C_p$
を用いると，

```math
\begin{aligned}
d'Q={}&
\left[
C_p+
\left\{
\left(\frac{\partial H}{\partial p}\right)_T-V
\right\}
\left(\frac{\partial p}{\partial T}\right)_V
\right]dT\\
&+
\left\{
\left(\frac{\partial H}{\partial p}\right)_T-V
\right\}
\left(\frac{\partial p}{\partial V}\right)_T dV
\end{aligned}
```

となる．

定積過程では $dV=0$ であるから， $d'Q=C_V\,dT$ より，

```math
C_V=C_p+
\left\{
\left(\frac{\partial H}{\partial p}\right)_T-V
\right\}
\left(\frac{\partial p}{\partial T}\right)_V
```

を得る．
これを整理すると，

```math
C_p-C_V=
-\left(\frac{\partial p}{\partial T}\right)_V
\left\{
\left(\frac{\partial H}{\partial p}\right)_T-V
\right\}
\tag{6}
```

となる．

ここで，次の（iii）で示す関係式

```math
\left(\frac{\partial H}{\partial p}\right)_T-V
=
\left(\frac{\partial U}{\partial p}\right)_T
+p\left(\frac{\partial V}{\partial p}\right)_T
```

を式（6）に代入すると，

```math
\boxed{
C_p-C_V=
-\left(\frac{\partial p}{\partial T}\right)_V
\left\{
\left(\frac{\partial U}{\partial p}\right)_T
+p\left(\frac{\partial V}{\partial p}\right)_T
\right\}
}
```

が得られる．
これが（ii）の第2式である．

### （iii）エンタルピーの偏微分に関する関係式

エンタルピーの定義

```math
H=U+pV
```

を用い，温度 $T$ を一定に保って圧力 $p$ で偏微分する．
積の微分法則より，

```math
\left(\frac{\partial H}{\partial p}\right)_T
=
\left(\frac{\partial U}{\partial p}\right)_T
+\left(\frac{\partial (pV)}{\partial p}\right)_T
```

である．
ここで，

```math
\left(\frac{\partial (pV)}{\partial p}\right)_T
=V+p\left(\frac{\partial V}{\partial p}\right)_T
```

となるため，

```math
\left(\frac{\partial H}{\partial p}\right)_T
=
\left(\frac{\partial U}{\partial p}\right)_T
+V+p\left(\frac{\partial V}{\partial p}\right)_T
```

を得る．
両辺から $V$ を引くと，

```math
\boxed{
\left(\frac{\partial H}{\partial p}\right)_T-V
=
\left(\frac{\partial U}{\partial p}\right)_T
+p\left(\frac{\partial V}{\partial p}\right)_T
}
```

となり，（iii）が証明された．

### （iv）熱容量と状態量の偏微分に関する関係式

（ii）の第1式は，

```math
C_p-C_V=
\left(\frac{\partial V}{\partial T}\right)_p
\left\{
p+\left(\frac{\partial U}{\partial V}\right)_T
\right\}
```

である．
ここで，温度 $T$ を圧力 $p$ と体積 $V$ の関数とみなすと，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=
\frac{1}{\left(\frac{\partial T}{\partial V}\right)_p}
```

が成り立つ．
したがって，（ii）の第1式は，

```math
\boxed{
(C_p-C_V)\left(\frac{\partial T}{\partial V}\right)_p
=p+\left(\frac{\partial U}{\partial V}\right)_T
}
\tag{7}
```

と書き換えられる．

この式の両辺を，体積 $V$ を一定に保って圧力 $p$ で偏微分する．
左辺には積の微分法則を用いると，

```math
\begin{aligned}
& (C_p-C_V)\frac{\partial^2T}{\partial p\,\partial V}\\
&\quad+
\left\{
\left(\frac{\partial C_p}{\partial p}\right)_V
-
\left(\frac{\partial C_V}{\partial p}\right)_V
\right\}
\left(\frac{\partial T}{\partial V}\right)_p
\end{aligned}
```

となる．
一方，右辺の微分は，

```math
1+
\left(\frac{\partial}{\partial p}\right)_V
\left(\frac{\partial U}{\partial V}\right)_T
```

である．
ここで， $U$ は $T,V$ の関数であり， $V$ を一定にして $p$ を変化させるときには $T$ が変化する．
連鎖律を用いると，

```math
\begin{aligned}
\left(\frac{\partial}{\partial p}\right)_V
\left(\frac{\partial U}{\partial V}\right)_T
&=
\left(\frac{\partial}{\partial T}\right)_V
\left(\frac{\partial U}{\partial V}\right)_T
\left(\frac{\partial T}{\partial p}\right)_V\\
&=
\left(\frac{\partial C_V}{\partial V}\right)_T
\left(\frac{\partial T}{\partial p}\right)_V
\end{aligned}
\tag{8}
```

となる．
最後の等号では，混合偏微分の順序を入れ替えられることと，

```math
C_V=\left(\frac{\partial U}{\partial T}\right)_V
```

を用いた．

したがって，式（7）を偏微分した結果は，

```math
\begin{aligned}
&(C_p-C_V)\frac{\partial^2T}{\partial p\,\partial V}\\
&\quad+
\left(\frac{\partial C_p}{\partial p}\right)_V
\left(\frac{\partial T}{\partial V}\right)_p\\
&\quad-
\left(\frac{\partial C_V}{\partial p}\right)_V
\left(\frac{\partial T}{\partial V}\right)_p\\
&=1+
\left(\frac{\partial C_V}{\partial V}\right)_T
\left(\frac{\partial T}{\partial p}\right)_V
\end{aligned}
\tag{9}
```

となる．

ここで， $C_V$ は $T,V$ の関数であるため，連鎖律より，

```math
\left(\frac{\partial C_V}{\partial p}\right)_V
=
\left(\frac{\partial C_V}{\partial T}\right)_V
\left(\frac{\partial T}{\partial p}\right)_V
\tag{10}
```

および，

```math
\left(\frac{\partial C_V}{\partial V}\right)_p
=
\left(\frac{\partial C_V}{\partial T}\right)_V
\left(\frac{\partial T}{\partial V}\right)_p
+
\left(\frac{\partial C_V}{\partial V}\right)_T
\tag{11}
```

が成り立つ．
式（10），（11）から，

```math
\begin{aligned}
&\left(\frac{\partial C_V}{\partial p}\right)_V
\left(\frac{\partial T}{\partial V}\right)_p
+
\left(\frac{\partial C_V}{\partial V}\right)_T
\left(\frac{\partial T}{\partial p}\right)_V\\
&\qquad=
\left(\frac{\partial C_V}{\partial V}\right)_p
\left(\frac{\partial T}{\partial p}\right)_V
\end{aligned}
\tag{12}
```

を得る．

式（12）を用いて，式（9）の $C_V$ に関する項をまとめると，

```math
\begin{aligned}
&(C_p-C_V)\frac{\partial^2T}{\partial p\,\partial V}\\
&\quad+
\left(\frac{\partial C_p}{\partial p}\right)_V
\left(\frac{\partial T}{\partial V}\right)_p\\
&\quad-
\left(\frac{\partial C_V}{\partial V}\right)_p
\left(\frac{\partial T}{\partial p}\right)_V
=1
\end{aligned}
```

となる．
よって，題意の関係式

```math
\boxed{
(C_p-C_V)\frac{\partial^2T}{\partial p\,\partial V}
+
\left(\frac{\partial C_p}{\partial p}\right)_V
\left(\frac{\partial T}{\partial V}\right)_p
-
\left(\frac{\partial C_V}{\partial V}\right)_p
\left(\frac{\partial T}{\partial p}\right)_V
=1
}
```

が証明された．

## 解説

この問題では，熱力学第1法則から出発し，内部エネルギーとエンタルピーの全微分を用いて定積熱容量と定圧熱容量を導く．
次に，体積や圧力をそれぞれ別の状態変数の関数とみなして全微分を展開することで， $C_p-C_V$ に関する2つの式を求める．

最後の（iv）では，これらの関係式から得られた式を偏微分し，連鎖律を用いて整理することが重要である．
特に， $C_V$ は $T,V$ の関数である一方，問題の式では $p,V$ を独立変数とする偏微分も現れるため，どの変数を固定して微分しているかを区別する必要がある．

以上により，定積熱容量，定圧熱容量，内部エネルギー，エンタルピー，および状態量の偏微分の間に成り立つ4つの関係式が示された．
