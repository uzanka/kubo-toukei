# 演習問題【1-A-4】

## 解答

### 1．気体が外界になした仕事 $W$ の計算

気体が準静的に膨張するとき，気体が外界になす仕事 $W$ は，体積を $V_1$ から $V_2$ まで変化させることによって，

```math
W=\int_{V_1}^{V_2}p\,dV
```

と表される．
ここで， $p$ は膨張過程の各瞬間における気体の圧力である．
準静的過程では，気体は各瞬間に平衡状態にあるとみなせるため，理想気体の状態方程式を用いて圧力を表すことができる．

理想気体の状態方程式は，

```math
pV=nRT
```

である．
本問では気体は $1\,\mathrm{mol}$ なので， $n=1$ であり，

```math
pV=RT
```

となる．
したがって，圧力 $p$ は，

```math
p=\frac{RT}{V}
```

と表される．
これを仕事の式に代入すると，

```math
\begin{aligned}
W
&=\int_{V_1}^{V_2}\frac{RT}{V}\,dV\\
&=RT\int_{V_1}^{V_2}\frac{1}{V}\,dV\\
&=RT\left[\ln V\right]_{V_1}^{V_2}\\
&=RT\ln\frac{V_2}{V_1}
\end{aligned}
```

を得る．
ここで， $\ln$ は自然対数を表す．

次に，等温過程では温度 $T$ が一定であるため，始状態と終状態について，

```math
p_1V_1=RT,\qquad p_2V_2=RT
```

が成り立つ．
これらの式から，

```math
\frac{V_2}{V_1}=\frac{p_1}{p_2}
```

となる．
よって，仕事は圧力を用いて，

```math
W=RT\ln\frac{p_1}{p_2}
```

と表すことができる．

ここで，問題で与えられた初めの圧力と終わりの圧力は，

```math
p_1=20\,\mathrm{atm},\qquad
p_2=1\,\mathrm{atm}
```

であるから，

```math
\frac{p_1}{p_2}=\frac{20}{1}=20
```

となる．
また，温度は，

```math
T=20^\circ\mathrm{C}=293.15\,\mathrm{K}
```

である．
気体定数 $R=8.314\,\mathrm{J/(mol\,K)}$ を用いると，

```math
\begin{aligned}
RT
&=8.314\times293.15\\
&=2437.2\,\mathrm{J/mol}
\end{aligned}
```

を得る．
さらに，自然対数は，

```math
\ln20\simeq2.9957
```

であるから，

```math
\begin{aligned}
W
&=RT\ln\frac{p_1}{p_2}\\
&=2437.2\times 2.9957\\
&\simeq7.30\times10^3\,\mathrm{J}
\end{aligned}
```

となる．
したがって，気体が外界になした仕事は，有効数字3桁で，

```math
\boxed{
W=7.30\times10^3\,\mathrm{J}
}
```

である．

### 2．気体に供給すべき熱量 $Q$ の計算

次に，気体に供給すべき熱量 $Q$ を求める．
熱力学第1法則は，気体が吸収した熱量を $Q$ ，気体が外界になした仕事を $W$ ，気体の内部エネルギーの変化を $\Delta U$ とすると，

```math
\Delta U=Q-W
```

と表される．
この式は，気体が受け取った熱のうち，内部エネルギーの増加に使われなかった分が，外界になす仕事に使われることを意味している．

理想気体の内部エネルギー $U$ は温度 $T$ だけの関数である．
本問では等温過程であり，温度が一定であるため，始状態と終状態の内部エネルギーは等しい．
したがって，

```math
\Delta U=U_2-U_1=0
```

となる．
これを熱力学第1法則に代入すると，

```math
0=Q-W
```

より，

```math
Q=W
```

が得られる．
つまり，気体が外界になした仕事と同じ量の熱を外部から供給しなければ，温度を一定に保つことができない．
したがって，

```math
Q=7.30\times10^3\,\mathrm{J}
```

である．

最後に，熱の仕事当量を $J=4.184\,\mathrm{J/cal}$ とすると，ジュールで表した熱量をカロリーに換算するには，熱の仕事当量で割ればよい．
よって，

```math
\begin{aligned}
Q
&=\frac{7301}{4.184}\\
&=\simeq1.745\times10^3\,\mathrm{cal}\\
&\simeq1.745\,\mathrm{kcal}
\end{aligned}
```

となる．
したがって，有効数字3桁では，

```math
\boxed{
Q=1.75\times10^3\,\mathrm{cal}
=1.75\,\mathrm{kcal}
}
```

である．

### 答え

気体が外界になした仕事は，

```math
\boxed{
W=7.30\times10^3\,\mathrm{J}
}
```

気体に供給すべき熱量は，

```math
\boxed{
Q=1.75\times10^3\,\mathrm{cal}
=1.75\,\mathrm{kcal}
}
```

である．

## 解説

この問題で重要なのは，等温準静的膨張の仕事を積分によって求め，熱力学第1法則を用いて熱量を導くことである．

理想気体では，状態方程式 $pV=RT$ を利用することで，圧力を体積の関数 $p=RT/V$ として表せる．
これを仕事の積分に代入すると，自然対数 $\ln(V_2/V_1)$ が現れる．
さらに，等温過程では $p_1V_1=p_2V_2$ であるため，体積比を圧力比に置き換えられる．

また，理想気体の内部エネルギーは温度だけに依存する．
そのため，等温過程では内部エネルギーが変化せず，気体が外界になした仕事と同じ量の熱を外部から受け取ることになる．
この関係から，仕事を求めた後に熱量を計算できる．
