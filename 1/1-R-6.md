# 例題【1-R-6】

## 解答

### 1. Poisson の式 $pV^\gamma = \text{const.}$ の導出

まず，理想気体の準静的断熱過程における関係式を導く．

**ステップ1：熱力学第一法則の適用**

熱力学第一法則は，微小変化におけるエネルギーの変化 $dU$ ，加えられた熱量 $d'Q$ ，外部になした仕事 $dW$ を用いて次のように書ける．

$$dU = d'Q - dW$$

ここで，$dW = p dV$ （気体が外部にする仕事）なので，

$$dU = d'Q - p dV$$

断熱過程では，外部との熱のやり取りがないため $d'Q = 0$ である．
したがって，

$$dU = -p dV \quad \cdots (\text{A})$$

となる．

**ステップ2：内部エネルギーと状態方程式の利用**

理想気体において，内部エネルギーの変化 $dU$ は温度変化 $dT$ を用いて次のように表される（比熱 $C_v$ が一定とする）．

$$dU = C_v dT \quad \cdots (\text{B})$$

また，理想気体の状態方程式は次のように書ける．

$$pV = nRT \quad \cdots (\text{C})$$

ここで， $n$ は物質量，$R$ は気体定数， $T$ は絶対温度である．

式 (A) と (B) より，

$$C_v dT = -p dV \quad \cdots (\text{D})$$

が得られる．
ここに式 (C) を変形したもの $p = \frac{nRT}{V}$ を代入する．

$$C_v dT = -\frac{nRT}{V} dV$$

両辺を $T$ で割ると，

$$C_v \frac{dT}{T} = -\frac{nR}{V} dV$$

整理すると，

$$C_v \frac{dT}{T} + nR \frac{dV}{V} = 0 \quad \cdots (\text{E})$$

となる．

**ステップ3：積分による関係式の導出**

式 (E) を $T$ と $V$ について積分する．

$$C_v \int \frac{1}{T} dT + nR \int \frac{1}{V} dV = \text{const.}$$

$$C_v \ln T + nR \ln V = \text{const.} \quad \cdots (\text{F})$$

ここで，マイヤーの関係式 $C_p - C_v = nR$ を用いて， $nR$ を書き換える．

$$C_v \ln T + (C_p - C_v) \ln V = \text{const.}$$

両辺を $C_v$ で割る．

$$\ln T + \left(\frac{C_p}{C_v} - 1\right) \ln V = \text{const.}$$

ここで，比熱比 $\gamma = \frac{C_p}{C_v}$ とおくと，

$$\ln T + (\gamma - 1) \ln V = \text{const.}$$

対数の性質 $\ln a + \ln b = \ln(ab)$ および $k \ln a = \ln(a^k)$ を用いると，

$$\ln (T V^{\gamma-1}) = \text{const.}$$

したがって，

$$T V^{\gamma-1} = \text{const.} \quad \cdots (\text{G})$$

が得られる．

最後に，式 (C) $pV = nRT$ より $T = \frac{pV}{nR}$ を式 (G) に代入する．

$$\left(\frac{pV}{nR}\right) V^{\gamma-1} = \text{const.}$$

$$\frac{p V^\gamma}{nR} = \text{const.}$$

$nR$ は定数なので，

$$pV^\gamma = \text{const.} \quad \cdots (\text{H})$$

が示された．
これが **Poisson の式** である．

### 2. 気体が外部になす仕事 $W$ の計算

断熱過程において，体積が $V_1$ から $V_2$ まで変化するとき，気体が外部になす仕事 $W$ は以下の積分で求められる．

$$W = \int_{V_1}^{V_2} p dV$$

ここで，Poisson の式 (H) より， $p = \frac{\text{const.}}{V^\gamma}$ である．
定数部分を $p_1 V_1^\gamma = p_2 V_2^\gamma$ とおくと， $p = p_1 V_1^\gamma V^{-\gamma}$ と書ける．

これを積分に代入する．

$$W = \int_{V_1}^{V_2} p_1 V_1^\gamma V^{-\gamma} dV = p_1 V_1^\gamma \int_{V_1}^{V_2} V^{-\gamma} dV$$

積分を実行すると，

$$W = p_1 V_1^\gamma \left[ \frac{V^{-\gamma+1}}{-\gamma+1} \right]_{V_1}^{V_2} = \frac{p_1 V_1^\gamma}{1-\gamma} (V_2^{1-\gamma} - V_1^{1-\gamma})$$

符号を整理して，

$$W = \frac{p_1 V_1^\gamma}{\gamma-1} (V_1^{1-\gamma} - V_2^{1-\gamma})$$

$$W = \frac{1}{\gamma-1} (p_1 V_1^\gamma V_1^{1-\gamma} - p_1 V_1^\gamma V_2^{1-\gamma})$$

$$W = \frac{1}{\gamma-1} (p_1 V_1 - p_1 V_1^\gamma V_2^{1-\gamma})$$

ここで，Poisson の式より $p_1 V_1^\gamma = p_2 V_2^\gamma$ なので，

$$W = \frac{1}{\gamma-1} (p_1 V_1 - p_2 V_2^\gamma V_2^{1-\gamma})$$

$$W = \frac{1}{\gamma-1} (p_1 V_1 - p_2 V_2) \quad \dots (\text{I})$$

が得られる．

また，状態方程式 $pV = nRT$ を用いて，

$$W = \frac{nRT_1 - nRT_2}{\gamma-1} = \frac{nR}{\gamma-1} (T_1 - T_2)$$

ここで， $\gamma = \frac{C_p}{C_v}$ より $\gamma - 1 = \frac{C_p}{C_v} - 1 = \frac{C_p - C_v}{C_v} = \frac{nR}{C_v}$ なので，
$\frac{nR}{\gamma - 1} = C_v$ となる．
したがって，

$$W = C_v (T_1 - T_2) \quad \dots (\text{J})$$

となる．

**答え：** $W = \frac{1}{\gamma-1}(p_1 V_1 - p_2 V_2) = C_v(T_1 - T_2)$

## 解説

この問題のポイントは， **「断熱過程」という条件をどう数式に落とし込むか** ，そして **「状態方程式」と「熱力学第一法則」をどう組み合わせて，目的の形に導くか** という点にある．

### 1.  断熱条件の数式化

「断熱」とは外部との熱のやり取りがないこと，つまり $d'Q = 0$ である．
これを第一法則 $dU = d'Q - p dV$ に代入することで， $dU = -p dV$ という非常にシンプルな関係式が得られる．
これがすべての計算の出発点である．

## 2.  変数の整理

問題では $p, V, T$ が登場するが，積分を行うためには変数を一つ（例えば $V$ だけ）に絞る必要がある．
そのためには，状態方程式 $pV = nRT$ を使って $p$ や $T$ を $V$ で表す操作が不可欠である．

### 3.  比熱と $\gamma$ の役割

$\gamma$ （比熱比）は，定圧比熱 $C_p$ と定積比熱 $C_v$ の比である．
これを用いることで，温度の変化と体積の変化を一つの式（Poisson の式）にまとめることができる．

### 4.  仕事の計算

仕事は「圧力 $\times$ 体積の変化」を積分したものである．
断熱過程では圧力が体積の変化に伴って激しく変わるため，単純な掛け算ではなく，Poisson の式を用いて圧力を $V$ の関数として表してから積分を行う必要がある．

### 5.  物理的な意味

最後に求めた $W = C_v(T_1 - T_2)$ という式は，断熱過程において「気体が外部になした仕事は，内部エネルギーの変化量（温度の変化）に等しい」という物理的実態を非常に美しく示している．
