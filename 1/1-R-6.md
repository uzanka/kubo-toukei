# 例題【1-R-6】

## 解答

### 1．Poisson の式 $pV^\gamma=\mathrm{const.}$ の導出

理想気体 $n$ mol の準静的過程に対する熱力学第一法則は，気体に加えられた微小熱量を $d'Q$ ，内部エネルギーの微小変化を $dU$ ，気体が外部にする微小仕事を $p\,dV$ とすると，

```math
d'Q=dU+p\,dV
```

と表される．
ここでは，気体が外部にする仕事を正とする．

断熱過程では外部との熱のやり取りがないため，

```math
d'Q=0
```

である．
したがって，熱力学第一法則は，

```math
dU=-p\,dV
\tag{1}
```

となる．

理想気体では，内部エネルギー $U$ は温度 $T$ のみの関数であり，体積 $V$ には依存しない．
気体全体の定積熱容量を $C_V$ とすると，比熱が一定であるため，

```math
dU=C_V\,dT
\tag{2}
```

と書ける．

式 (2) を式 (1) に代入すると，

```math
C_V\,dT=-p\,dV
\tag{3}
```

を得る．

ここで，理想気体の状態方程式

```math
pV=nRT
\tag{4}
```

より，

```math
p=\frac{nRT}{V}
```

である．
これを式 (3) に代入すれば，

```math
C_V\,dT=-\frac{nRT}{V}\,dV
```

となる．
両辺を $T$ で割って整理すると，

```math
C_V\frac{dT}{T} +nR\frac{dV}{V}=0
\tag{5}
```

を得る．

次に，式 (5) を積分する．
$C_V,n,R$ は一定であるから，

```math
C_V\int\frac{dT}{T} +nR\int\frac{dV}{V}=0
```

となり，

```math
C_V\ln T+nR\ln V=\mathrm{const.}
\tag{6}
```

を得る．

ここで，Mayer の関係式を用いる．
気体全体の定圧熱容量を $C_p$ とすると，

```math
C_p-C_V=nR
```

である．
したがって，式 (6) は，

```math
C_V\ln T+(C_p-C_V)\ln V =\mathrm{const.}
```

と書き換えられる．
両辺を $C_V$ で割ると，

```math
\ln T+ \left(\frac{C_p}{C_V}-1\right)\ln V =\mathrm{const.}
```

となる．
ここで，比熱比を

```math
\gamma=\frac{C_p}{C_V}
```

と定義すれば，

```math
\ln T+(\gamma-1)\ln V=\mathrm{const.}
```

を得る．
対数の性質を用いると，

```math
\ln\left(TV^{\gamma-1}\right)=\mathrm{const.}
```

となる．
よって，

```math
\boxed{
TV^{\gamma-1}=\mathrm{const.}
}
\tag{7}
```

が得られる．

さらに，理想気体の状態方程式 $pV=nRT$ より，

```math
T=\frac{pV}{nR}
```

である．
これを式 (7) に代入すると，

```math
\frac{pV}{nR}V^{\gamma-1} =\mathrm{const.}
```

となる．
$nR$ は一定なので，

```math
\boxed{
pV^\gamma=\mathrm{const.}
}
```

が得られる．
これが Poisson の式 である．

### 2．気体が外部にする仕事 $W$ の計算

次に，状態 $(p_1,V_1,T_1)$ から状態 $(p_2,V_2,T_2)$ までの準静的断熱過程で，気体が外部にする仕事 $W$ を求める．

微小な体積変化 $dV$ に対して，気体が外部にする仕事は $p\,dV$ であるため，全仕事は，

```math
W=\int_{V_1}^{V_2}p\,dV
\tag{8}
```

と表される．

Poisson の式より，

```math
pV^\gamma=p_1V_1^\gamma=p_2V_2^\gamma
```

であるから，圧力 $p$ は体積 $V$ の関数として，

```math
p=\frac{p_1V_1^\gamma}{V^\gamma}
```

と表される．
これを式 (8) に代入すると，

```math
W=p_1V_1^\gamma \int_{V_1}^{V_2}V^{-\gamma}\,dV
```

となる．
ここで，通常の気体では $\gamma>1$ であるため，積分を計算すると，

```math
\begin{aligned}
W &=p_1V_1^\gamma \left[\frac{V^{1-\gamma}}{1-\gamma}\right]_{V_1}^{V_2}\\
&=\frac{p_1V_1^\gamma}{\gamma-1} \left(V_1^{1-\gamma}-V_2^{1-\gamma}\right)
\end{aligned}
```

となる．
これを整理すれば，

```math
W=\frac{1}{\gamma-1} \left(p_1V_1-p_1V_1^\gamma V_2^{1-\gamma}\right)
```

を得る．
さらに，Poisson の式から，

```math
p_1V_1^\gamma=p_2V_2^\gamma
```

なので，

```math
p_1V_1^\gamma V_2^{1-\gamma}=p_2V_2
```

である．
したがって，

```math
\boxed{
W=\frac{p_1V_1-p_2V_2}{\gamma-1}
}
\tag{9}
```

となる．

最後に，状態方程式 $pV=nRT$ を初期状態と最終状態に適用すると，

```math
p_1V_1=nRT_1,\qquad
p_2V_2=nRT_2
```

であるから，式 (9) は，

```math
W=\frac{nR(T_1-T_2)}{\gamma-1}
```

と書ける．

ここで，比熱比の定義 $\gamma=C_p/C_V$ と Mayer の関係式 $C_p-C_V=nR$ より，

```math
\begin{aligned}
\gamma-1 &=\frac{C_p}{C_V}-1\\
&=\frac{C_p-C_V}{C_V}\\
&=\frac{nR}{C_V}
\end{aligned}
```

となる．
したがって，

```math
\frac{nR}{\gamma-1}=C_V
```

であるため，

```math
\boxed{
W=C_V(T_1-T_2)
}
```

を得る．

よって，求める仕事は，

```math
\boxed{
W=\frac{p_1V_1-p_2V_2}{\gamma-1} =C_V(T_1-T_2)
}
```

である．
ここで， $C_V$ は気体全体の定積熱容量を表している．
なお，1 mol あたりのモル定積比熱を $C_{V,m}$ と書く場合には，

```math
\boxed{
W=nC\_{V,m}(T_1-T_2)
}
```

となる．

## 3．解説

この問題では，熱力学第一法則，理想気体の状態方程式，Mayer の関係式を組み合わせることで，断熱過程における状態変化と仕事を導いた．

断熱過程では熱の出入りがないため，気体が外部に仕事をすると，その分だけ内部エネルギーが減少する．
理想気体の内部エネルギーは温度のみの関数であるから，断熱膨張では温度が下がり，断熱圧縮では温度が上がる．

実際，断熱膨張では $V_2>V_1$ となり，Poisson の式により $T_2<T_1$ であるため，

```math
W=C_V(T_1-T_2)>0
```

となる．
すなわち，気体は外部に正の仕事をする．
一方，断熱圧縮では $V_2<V_1$ となり， $T_2>T_1$ であるため，

```math
W=C_V(T_1-T_2)<0
```

となる．
これは，気体が外部に負の仕事をし，外部が気体に正の仕事をしていることを表している．

このように，Poisson の式は断熱過程における圧力・体積・温度の関係を与え，そこから得られる仕事の式は，断熱過程での内部エネルギーの変化と外部への仕事の関係を明確に示している．
