# 例題【1-R-3】

## 解答

理想気体 1 mol について，熱力学第一法則を考える．
気体に加えられた微小熱量を $d'Q$ ，内部エネルギーの微小変化を $dU$ ，気体が外部にする微小仕事を $p\,dV$ とすると，準静的過程では，

```math
d'Q=dU+p\,dV
\tag{1}
```

が成り立つ．
ここで， $p$ は圧力， $V$ は体積である．
この式は，加えられた熱量が内部エネルギーの増加と気体が外部にする仕事に使われることを表している．

理想気体の内部エネルギー $U$ は，体積 $V$ には依存せず，温度 $T$ のみの関数である．
したがって，内部エネルギーの微小変化は，定積モル比熱 $C_V$ を用いて，

```math
dU=C_V(T)\,dT
```

と書ける．
実際，定積過程では $dV=0$ であるため，式 (1) より $d'Q=dU$ となり，定積モル比熱は $C_V=(d'Q/dT)_V$ で与えられる．

これを式 (1) に代入すると，

```math
d'Q=C_V(T)\,dT+p\,dV
\tag{2}
```

を得る．

次に，式 (2) の $p\,dV$ を変形する．
積の微分公式

```math
d(pV)=p\,dV+V\,dp
```

より，

```math
p\,dV=d(pV)-V\,dp
```

となる．
これを式 (2) に代入すれば，

```math
d'Q=C_V(T)\,dT+d(pV)-V\,dp
\tag{3}
```

を得る．

ここで，理想気体 1 mol の状態方程式

```math
pV=RT
```

を用いる．
ただし， $R$ は気体定数であり，定数である．
両辺を微分すると，

```math
d(pV)=R\,dT
```

となる．
これを式 (3) に代入すれば，

```math
d'Q=C_V(T)\,dT+R\,dT-V\,dp
```

すなわち，

```math
d'Q=\left\{C_V(T)+R\right\}\,dT-V\,dp
\tag{4}
```

を得る．

さて，定圧モル比熱 $C_p$ は，圧力を一定に保ったときに，気体 1 mol の温度を変化させるために必要な熱量を温度変化で割ったものである．
したがって，

```math
C_p=\left(\frac{d'Q}{dT}\right)_p
```

と定義される．
定圧過程では $dp=0$ であるから，式 (4) は，

```math
d'Q=\left\{C_V(T)+R\right\}\,dT
```

となる．
両辺を $dT$ で割ると，

```math
\left(\frac{d'Q}{dT}\right)_p=C_V(T)+R
```

を得る．
定圧モル比熱の定義を用いれば，

```math
C_p=C_V+R
```

となる．
よって，Mayer の関係式

```math
\boxed{
C_p=C_V+R
}
```

が示された．

## 3．解説

この問題の要点は，熱力学第一法則と理想気体の状態方程式を組み合わせ，定積モル比熱と定圧モル比熱の違いを導くことである．

定積過程では体積が変化しないため，気体は外部に仕事をしない．
そのため，加えられた熱量はすべて内部エネルギーの増加に使われる．

一方，定圧過程では，加熱によって気体の温度が上昇すると体積が増加し，気体は外部に仕事をする．
そのため，同じ温度変化を得るには，内部エネルギーを増加させる熱量に加えて，膨張仕事に相当する熱量も必要となる．

理想気体の状態方程式 $pV=RT$ により，この膨張仕事に対応する熱量の差が $R\,dT$ と表されるため，

```math
C_p-C_V=R
```

が成り立つ．
これが Mayer の関係式の物理的な意味である．

なお，この導出では $C_V$ を温度の関数 $C_V(T)$ として扱っているため，比熱が温度に依存しても関係式は成立する．
ただし，ここで示した式は理想気体についての関係式である．
