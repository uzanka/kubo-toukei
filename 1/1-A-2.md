# 演習問題【1-A-2】

## 解答

前問の結果を利用して導出する．

まず，圧力 $p$ は温度 $T$ と体積 $V$ の関数であるから，圧力の全微分は

```math
dp=
\left(\frac{\partial p}{\partial T}\right)_V dT +
\left(\frac{\partial p}{\partial V}\right)_T dV
\tag{1}
```

と表される．
ここで， $\left(\dfrac{\partial p}{\partial T}\right)_V$ は体積 $V$ を一定に保ったときの温度 $T$ による圧力 $p$ の変化率を表し， $\left(\dfrac{\partial p}{\partial V}\right)_T$ は温度 $T$ を一定に保ったときの体積 $V$ による圧力 $p$ の変化率を表す．

次に，定積圧力係数 $\alpha_p$ の定義

```math
\alpha_p=\frac{1}{p}\left(\frac{\partial p}{\partial T}\right)_V
```

より，

```math
\left(\frac{\partial p}{\partial T}\right)_V=p\alpha_p
```

が得られる．
また，等温体積弾性率 $k$ の定義

```math
k=-V\left(\frac{\partial p}{\partial V}\right)_T
```

より，

```math
\left(\frac{\partial p}{\partial V}\right)_T=-\frac{k}{V}
```

が得られる．
これらを式（1）に代入すると，

```math
dp=p\alpha_p\,dT-\frac{k}{V}dV
\tag{2}
```

となる．

ここで，前問で示した関係式

```math
p\alpha_p=k\alpha_V
```

を式（2）に代入すると，

```math
dp=k\alpha_V\,dT-\frac{k}{V}dV
```

を得る．
右辺から共通因数 $k$ をくくり出すと，

```math
dp=k\left(\alpha_V\,dT-\frac{dV}{V}\right)
```

となる．
括弧内の項の順序を入れ替えれば，

```math
\boxed{
dp=k\left(-\frac{dV}{V}+\alpha_V\,dT\right)
}
```

が得られ，題意の関係式が示された．

## 解説

得られた式は，圧力の微小変化 $dp$ が，体積の微小変化 $dV$ と温度の微小変化 $dT$ によって決まることを表している．

```math
dp=-\frac{k}{V}dV+k\alpha_V\,dT
```

右辺の第1項 $-\dfrac{k}{V}dV$ は，温度を一定に保ったときの体積変化による圧力変化を表す．
通常，体積が増加すると圧力は低下するため，この項にはマイナス符号が付く．
また，等温体積弾性率 $k$ が大きいほど，同じ割合の体積変化に対する圧力変化は大きくなる．

第2項 $k\alpha_V\,dT$ は，体積を一定に保ったときの温度変化による圧力変化を表す．
通常，温度が上昇すると圧力は上昇する．

この導出のポイントは，前問で示した関係式 $p\alpha_p=k\alpha_V$ を利用することである．
これにより，式（2）に現れる $p\alpha_p$ を $k\alpha_V$ に置き換え，最後に共通因数 $k$ をくくり出すことで，題意の関係式が得られる．
