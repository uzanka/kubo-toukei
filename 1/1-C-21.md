# 演習問題【1-C-21】

## 解答

粘性および熱伝導を無視でき，重力その他の外力が働かない定常流れを考える．
このとき，単位質量当たりのエンタルピーと運動エネルギーの和が，流線に沿って一定であることを示す．

なお，以下では，内部エネルギー $e$ とエンタルピー $h$ はいずれも **単位質量当たりの量** として扱う．
このとき，求める関係は

```math
\boxed{
h+\frac{v^2}{2}=\text{const.}
}
```

である．
ここで， $v=|\mathbf v|$ は流速の大きさである．

### 1．流体の質量保存則

流体の密度を $\rho$ ，流速ベクトルを $\mathbf v$ とする．
質量保存則を表す連続の式は，

```math
\frac{\partial \rho}{\partial t}
+\nabla\cdot(\rho\mathbf v)=0
\tag{1}
```

である．

定常流れでは，各位置における物理量が時間に依存しないため，

```math
\frac{\partial \rho}{\partial t}=0
```

である．
したがって，式（1）は

```math
\boxed{
\nabla\cdot(\rho\mathbf v)=0
}
\tag{2}
```

となる．

積の微分公式を用いて展開すると，

```math
\rho\nabla\cdot\mathbf v
+\mathbf v\cdot\nabla\rho=0
```

を得る．
よって，

```math
\boxed{
\nabla\cdot\mathbf v
=-\frac{1}{\rho}\mathbf v\cdot\nabla\rho
}
\tag{3}
```

が成り立つ．
この関係は，後で圧力による仕事の項をエンタルピーにまとめるために用いる．

### 2．内部エネルギーと運動エネルギーの保存則

#### 2.1 内部エネルギーの方程式

流体の単位質量当たりの内部エネルギーを $e$ ，圧力を $p$ とする．
粘性による散逸，熱伝導による熱の移動，外部からの熱供給を無視すると，内部エネルギーの方程式は

```math
\boxed{
\rho\frac{De}{Dt}
=-p\nabla\cdot\mathbf v
}
\tag{4}
```

となる．

ここで，

```math
\frac{D}{Dt}
=\frac{\partial}{\partial t}
+\mathbf v\cdot\nabla
```

は実質微分であり，流体粒子とともに移動して観測したときの物理量の変化率を表す．
式（4）は，流体の膨張・圧縮による圧力仕事が，内部エネルギーを変化させることを意味する．

#### 2.2 運動エネルギーの方程式

粘性を無視し，重力その他の外力が働かない場合，流体の運動方程式は Euler 方程式

```math
\boxed{
\rho\frac{D\mathbf v}{Dt}=-\nabla p
}
\tag{5}
```

で与えられる．

式（5）の両辺と速度ベクトル $\mathbf v$ の内積を取ると，

```math
\rho\mathbf v\cdot\frac{D\mathbf v}{Dt}
=-\mathbf v\cdot\nabla p
```

となる．
速度の大きさについて，

```math
\mathbf v\cdot\frac{D\mathbf v}{Dt}
=\frac{D}{Dt}\left(\frac{v^2}{2}\right)
```

が成り立つため，

```math
\boxed{
\rho\frac{D}{Dt}\left(\frac{v^2}{2}\right)
=-\mathbf v\cdot\nabla p
}
\tag{6}
```

を得る．
これは，圧力勾配によって流体の運動エネルギーが変化することを表す．

#### 2.3 全エネルギーの方程式

式（4）と式（6）を辺々加えると，

```math
\rho\frac{D}{Dt}
\left(e+\frac{v^2}{2}\right)
=-p\nabla\cdot\mathbf v
-\mathbf v\cdot\nabla p
```

となる．
積の微分公式

```math
\nabla\cdot(p\mathbf v)
=p\nabla\cdot\mathbf v
+\mathbf v\cdot\nabla p
```

を用いれば，

```math
\boxed{
\rho\frac{D}{Dt}
\left(e+\frac{v^2}{2}\right)
=-\nabla\cdot(p\mathbf v)
}
\tag{7}
```

が得られる．
これは，単位質量当たりの内部エネルギーと運動エネルギーの変化を合わせたエネルギー保存則である．

### 3．圧力項をエンタルピーにまとめる

次に，式（7）の右辺にある圧力項を変形する．
積の微分公式より，

```math
\nabla\cdot(p\mathbf v)
=\mathbf v\cdot\nabla p
+p\nabla\cdot\mathbf v
\tag{8}
```

である．

式（3）の

```math
\nabla\cdot\mathbf v
=-\frac{1}{\rho}\mathbf v\cdot\nabla\rho
```

を式（8）に代入すると，

```math
\nabla\cdot(p\mathbf v)
=\mathbf v\cdot\nabla p
-\frac{p}{\rho}\mathbf v\cdot\nabla\rho
\tag{9}
```

となる．

一方，商の微分公式から，

```math
\nabla\left(\frac{p}{\rho}\right)
=\frac{1}{\rho}\nabla p
-\frac{p}{\rho^2}\nabla\rho
```

である．
両辺に $\rho$ を掛けると，

```math
\rho\nabla\left(\frac{p}{\rho}\right)
=\nabla p-\frac{p}{\rho}\nabla\rho
```

となる．
さらに両辺と $\mathbf v$ の内積を取れば，

```math
\rho\mathbf v\cdot\nabla\left(\frac{p}{\rho}\right)
=\mathbf v\cdot\nabla p
-\frac{p}{\rho}\mathbf v\cdot\nabla\rho
```

を得る．
これを式（9）と比較すると，

```math
\boxed{
\nabla\cdot(p\mathbf v)
=\rho\mathbf v\cdot\nabla\left(\frac{p}{\rho}\right)
}
\tag{10}
```

が示される．

式（7）に式（10）を代入すると，

```math
\rho\frac{D}{Dt}
\left(e+\frac{v^2}{2}\right)
=-\rho\mathbf v\cdot\nabla
\left(\frac{p}{\rho}\right)
```

となる．
密度 $\rho>0$ とし，両辺を $\rho$ で割ると，

```math
\frac{D}{Dt}
\left(e+\frac{v^2}{2}\right)
=-\mathbf v\cdot\nabla\left(\frac{p}{\rho}\right)
\tag{11}
```

を得る．

定常流れでは $\partial/\partial t=0$ なので，

```math
\frac{D}{Dt}=\mathbf v\cdot\nabla
```

である．
これを式（11）に用いると，

```math
\mathbf v\cdot\nabla
\left(e+\frac{v^2}{2}\right)
+\mathbf v\cdot\nabla\left(\frac{p}{\rho}\right)=0
```

となる．
微分の線形性から，

```math
\boxed{
\mathbf v\cdot\nabla
\left(e+\frac{p}{\rho}+\frac{v^2}{2}\right)=0
}
\tag{12}
```

が得られる．

### 4．エンタルピーを用いた結論

単位質量当たりのエンタルピー $h$ は，内部エネルギー $e$ と圧力・比体積の積の和として定義される．比体積は $1/\rho$ であるため，

```math
\boxed{h=e+\frac{p}{\rho}}
\tag{13}
```

となる．

式（13）を式（12）に代入すれば，

```math
\boxed{
\mathbf v\cdot\nabla
\left(h+\frac{v^2}{2}\right)=0
}
\tag{14}
```

を得る．

式（14）は，流れに沿った方向には $h+v^2/2$ が変化しないことを意味する．
したがって，流線に沿って，

```math
\boxed{
h+\frac{v^2}{2}=\text{const.}
}
```

が成立する．

よって，内部摩擦（粘性）および熱伝導を無視でき，外力が働かない定常流れにおいて， **単位質量当たりのエンタルピーと運動エネルギーの和は，各流線に沿って保存される** ことが示された．

なお，この定数は一般に流線ごとに異なり得るため，流れ全体で同じ値になるとは限らない．
