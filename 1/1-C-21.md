# 演習問題【1-C-21】

## 解答

粘性および熱伝導を無視でき，重力その他の外力が働かない定常流れを考える．
また，流体内部への熱源による加熱もないものとする．

なお，問題文の「エンタルピー密度」「運動エネルギー密度」を厳密に単位体積当たりの量と解釈すると，それらの和が流線に沿って一定になるとは一般にはいえない．
以下では，問題の意図を比エンタルピーと比運動エネルギーの和に関する命題と解釈し，その関係を導く．

流体の単位質量当たりの内部エネルギーを $e$ ，比エンタルピーを $h$ ，密度を $\rho$ ，圧力を $p$ ，速度ベクトルを $\mathbf v$ とする．
また，速度の大きさを $v=|\mathbf v|$ とする．
示すべき関係は

```math
\boxed{
h+\frac{v^2}{2}=\text{const.}
}
```

である．
ただし，この定数は一般に流線ごとに異なり得る．

### 1．質量保存則

質量保存則を表す連続の式は

```math
\frac{\partial \rho}{\partial t}
+\nabla\cdot(\rho\mathbf v)=0
\tag{1}
```

である．

定常流れでは，物理量は時間に依存しないので，

```math
\frac{\partial \rho}{\partial t}=0
```

である．
したがって，式 (1) は

```math
\boxed{
\nabla\cdot(\rho\mathbf v)=0
}
\tag{2}
```

となる．

積の微分公式を用いると，

```math
\rho\nabla\cdot\mathbf v
+\mathbf v\cdot\nabla\rho=0
```

を得る．
よって，密度 $\rho>0$ に対して，

```math
\boxed{
\nabla\cdot\mathbf v
=-\frac{1}{\rho}\mathbf v\cdot\nabla\rho
}
\tag{3}
```

が成り立つ．

### 2．内部エネルギーと運動エネルギーの方程式

#### 2.1 内部エネルギーの方程式

粘性による散逸，熱伝導および熱源による加熱を無視すると，内部エネルギーの方程式は

```math
\boxed{
\rho\frac{De}{Dt}
=-p\nabla\cdot\mathbf v
}
\tag{4}
```

である．
ここで，

```math
\frac{D}{Dt}
=\frac{\partial}{\partial t}
+\mathbf v\cdot\nabla
```

は実質微分を表す．

式 (4) は，流体の膨張・圧縮に伴う圧力仕事によって内部エネルギーが変化することを表している．

#### 2.2 運動エネルギーの方程式

粘性を無視し，重力その他の外力が働かないとき，流体の運動方程式は Euler 方程式

```math
\boxed{
\rho\frac{D\mathbf v}{Dt}=-\nabla p
}
\tag{5}
```

となる．

式 (5) の両辺と速度ベクトル $\mathbf v$ の内積を取ると，

```math
\rho\mathbf v\cdot\frac{D\mathbf v}{Dt}
=-\mathbf v\cdot\nabla p
```

を得る．

また，連鎖律より，

```math
\mathbf v\cdot\frac{D\mathbf v}{Dt}
=\frac{D}{Dt}\left(\frac{v^2}{2}\right)
```

である．
したがって，

```math
\boxed{
\rho\frac{D}{Dt}\left(\frac{v^2}{2}\right)
=-\mathbf v\cdot\nabla p
}
\tag{6}
```

となる．

#### 2.3 全エネルギーの方程式

式 (4) と式 (6) を辺々加えると，

```math
\rho\frac{D}{Dt}
\left(e+\frac{v^2}{2}\right)
=-p\nabla\cdot\mathbf v
-\mathbf v\cdot\nabla p
```

を得る．

ここで，積の微分公式

```math
\nabla\cdot(p\mathbf v)
=p\nabla\cdot\mathbf v
+\mathbf v\cdot\nabla p
```

を用いると，

```math
\boxed{
\rho\frac{D}{Dt}
\left(e+\frac{v^2}{2}\right)
=-\nabla\cdot(p\mathbf v)
}
\tag{7}
```

となる．

### 3．圧力項を変形する

式 (3) より，

```math
\nabla\cdot\mathbf v
=-\frac{1}{\rho}\mathbf v\cdot\nabla\rho
```

である．
これを積の微分公式

```math
\nabla\cdot(p\mathbf v)
=p\nabla\cdot\mathbf v+\mathbf v\cdot\nabla p
```

に代入すると，

```math
\nabla\cdot(p\mathbf v)
=\mathbf v\cdot\nabla p
-\frac{p}{\rho}\mathbf v\cdot\nabla\rho
\tag{8}
```

となる．

一方，商の微分公式より，

```math
\nabla\left(\frac{p}{\rho}\right)
=\frac{1}{\rho}\nabla p
-\frac{p}{\rho^2}\nabla\rho
```

である．
両辺に $\rho$ を掛けると，

```math
\rho\nabla\left(\frac{p}{\rho}\right)
=\nabla p-\frac{p}{\rho}\nabla\rho
```

となる．
さらに両辺と $\mathbf v$ の内積を取れば，

```math
\rho\mathbf v\cdot\nabla\left(\frac{p}{\rho}\right)
=\mathbf v\cdot\nabla p
-\frac{p}{\rho}\mathbf v\cdot\nabla\rho
```

を得る．

これを式 (8) と比較すると，

```math
\boxed{
\nabla\cdot(p\mathbf v)
=\rho\mathbf v\cdot\nabla\left(\frac{p}{\rho}\right)
}
\tag{9}
```

が成立する．

式 (7) に式 (9) を代入すると，

```math
\rho\frac{D}{Dt}
\left(e+\frac{v^2}{2}\right)
=-\rho\mathbf v\cdot\nabla\left(\frac{p}{\rho}\right)
```

となる．
密度 $\rho>0$ であるから，両辺を $\rho$ で割って，

```math
\frac{D}{Dt}
\left(e+\frac{v^2}{2}\right)
=-\mathbf v\cdot\nabla\left(\frac{p}{\rho}\right)
\tag{10}
```

を得る．

定常流れでは $\partial/\partial t=0$ なので，

```math
\frac{D}{Dt}=\mathbf v\cdot\nabla
```

である．
これを式 (10) に用いると，

```math
\mathbf v\cdot\nabla
\left(e+\frac{v^2}{2}\right)
=-\mathbf v\cdot\nabla\left(\frac{p}{\rho}\right)
```

となる．
微分の線形性より，

```math
\boxed{
\mathbf v\cdot\nabla
\left(e+\frac{p}{\rho}+\frac{v^2}{2}\right)=0
}
\tag{11}
```

を得る．

### 4．比エンタルピーを用いた結論

単位質量当たりのエンタルピー $h$ は，内部エネルギー $e$ と圧力・比体積の積の和として定義される．
比体積は $1/\rho$ であるから，

```math
\boxed{
h=e+\frac{p}{\rho}
}
\tag{12}
```

である．

式 (12) を式 (11) に代入すると，

```math
\boxed{
\mathbf v\cdot\nabla
\left(h+\frac{v^2}{2}\right)=0
}
\tag{13}
```

となる．

これは，流速がゼロでない滑らかな流線に沿って，

```math
\frac{d}{ds}\left(h+\frac{v^2}{2}\right)=0
```

が成立することを意味する．
ここで $s$ は流線に沿った位置を表す弧長である．
したがって，積分して，

```math
\boxed{
h+\frac{v^2}{2}=\text{const.}
}
```

を得る．

よって，粘性，熱伝導および熱源による加熱を無視でき，重力その他の外力が働かない定常流れでは， **比エンタルピーと比運動エネルギーの和は，各流線に沿って一定である** ことが示された．

なお，この関係は一般に流線ごとの定数を与えるものであり，流れ全体で同じ定数になるとは限らない．

### 補足：問題文の「密度」を単位体積当たりの量と解釈する場合

単位体積当たりのエンタルピーは $\rho h$，単位体積当たりの運動エネルギーは $\rho v^2/2$ である．
これらの和

```math
\rho h+\frac{1}{2}\rho v^2
```

が流線に沿って一定になるとは，一般にはいえない．

単位体積当たりの全エネルギーに関する局所保存則は，

```math
\boxed{
\frac{\partial}{\partial t}
\left[\rho\left(e+\frac{v^2}{2}\right)\right]
+\nabla\cdot
\left[
\rho\mathbf v\left(h+\frac{v^2}{2}\right)
\right]=0
}
```

である．
定常流れでは，

```math
\boxed{
\nabla\cdot
\left[
\rho\mathbf v\left(h+\frac{v^2}{2}\right)
\right]=0
}
```

となる．
したがって，問題文が単位体積当たりのエネルギー密度を意図しているなら，この局所保存則を示す形に問題文を修正する必要がある．
