# 演習問題【1-A-3】

## 解答

例題［4］と同様に，理想気体の状態方程式とマイヤーの関係式から単位質量あたりの気体定数を求め，それらを比較することで熱の仕事当量 $J$ を計算する．

まず，理想気体の状態方程式は

```math
pV_{\mathrm{tot}}=nRT
```

である．
ここで， $p$ は圧力， $V_{\mathrm{tot}}$ は気体全体の体積， $n$ は物質量， $R$ はモル気体定数， $T$ は絶対温度である．

気体全体の質量を $m_{\mathrm{gas}}$ ，酸素のモル質量を $M$ とすると，

```math
n=\frac{m_{\mathrm{gas}}}{M}
```

であるから，

```math
pV_{\mathrm{tot}}
=\frac{m_{\mathrm{gas}}}{M}RT
```

となる．
ここで，単位質量あたりの体積を

```math
v=\frac{V_{\mathrm{tot}}}{m_{\mathrm{gas}}}
```

と定義すると，

```math
pv=\frac{R}{M}T
```

が得られる．
したがって，単位質量あたりの気体定数 $R_{\mathrm{s}}$ は

```math
R_{\mathrm{s}}=\frac{R}{M}=\frac{pv}{T}
```

と表される．

酸素のモル質量は $M=32\,\mathrm{g/mol}$ であり，標準状態における $1\,\mathrm{mol}$ の体積は $22.4\,\mathrm{L}=22.4\times10^3\,\mathrm{cm^3}$ である．
よって，単位質量あたりの体積は

```math
\begin{aligned}
v&=\frac{22.4\times10^3}{32}\\
&=700\,\mathrm{cm^3/g}
\end{aligned}
```

となる．

また，標準状態では，

```math
p=1\,\mathrm{atm}
=1.013\times10^6\,\mathrm{dyn/cm^2}
```

```math
T=273\,\mathrm{K}
```

である．
これらを用いると，

```math
\begin{aligned}
R_{\mathrm{s}}
&=\frac{pv}{T}\\
&=\frac{1.013\times10^6\times700}{273}\\
&\simeq2.60\times10^6\,\mathrm{erg/(g\,K)}
\end{aligned}
```

となる．
ここで，

```math
1\,\mathrm{J}=10^7\,\mathrm{erg}
```

であるから，

```math
\begin{aligned}
R_{\mathrm{s}}
&=\frac{2.60\times10^6}{10^7}\\
&=0.260\,\mathrm{J/(g\,K)}
\end{aligned}
```

を得る．

次に，理想気体に対するマイヤーの関係式は，単位質量あたりの気体定数を用いると，

```math
c_p-c_v=R_{\mathrm{s}}
```

と表される．
ただし，この式では比熱と気体定数を同じエネルギー単位で表す必要がある．
本問では，比熱が $\mathrm{cal}$ ，気体定数が $\mathrm{J}$ で与えられているため，熱の仕事当量 $J$ を用いて単位をそろえる．

熱の仕事当量 $J$ は，熱量 $1\,\mathrm{cal}$ に相当する仕事が $J\,\mathrm{J}$ であることを表す．
したがって，マイヤーの関係式は，

```math
J(c_p-c_v)=R_{\mathrm{s}}
```

と書くことができる．
これを $J$ について解くと，

```math
J=\frac{R_{\mathrm{s}}}{c_p-c_v}
```

となる．

問題で与えられた定圧比熱と定積比熱は，

```math
c_p=0.2203\,\mathrm{cal/(g\,K)}
```

```math
c_v=0.1578\,\mathrm{cal/(g\,K)}
```

であるから，その差は，

```math
\begin{aligned}
c_p-c_v
&=0.2203-0.1578\\
&=0.0625\,\mathrm{cal/(g\,K)}
\end{aligned}
```

となる．
よって，

```math
\begin{aligned}
J
&=\frac{0.260\,\mathrm{J/(g\,K)}}
{0.0625\,\mathrm{cal/(g\,K)}}\\
&=4.16\,\mathrm{J/cal}
\end{aligned}
```

を得る．

したがって，求める熱の仕事当量は，

```math
\boxed{
J=4.16\,\mathrm{J/cal}
}
```

である．

## 解説

この問題の要点は，理想気体の状態方程式から求めた気体定数と，マイヤーの関係式から得られる比熱の差を利用して，熱の仕事当量を計算することである．

状態方程式から求めた単位質量あたりの気体定数は，

```math
R_{\mathrm{s}}=0.260\,\mathrm{J/(g\,K)}
```

である．
一方，与えられた比熱の差は，

```math
c_p-c_v=0.0625\,\mathrm{cal/(g\,K)}
```

である．
マイヤーの関係式によれば，この比熱の差は単位質量あたりの気体定数に等しいが，今回はエネルギーの単位が異なるため，そのまま数値を等しくすることはできない．
そこで，熱の仕事当量 $J$ を用いて，

```math
J(c_p-c_v)=R_{\mathrm{s}}
```

と表す．
この式から，気体定数を比熱の差で割ることによって， $\mathrm{cal}$ から $\mathrm{J}$ への換算係数が求められる．

以上より，熱の仕事当量は $4.16\,\mathrm{J/cal}$ となる．
