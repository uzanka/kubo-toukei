# 演習問題【1-A-10】

## 解答

ある過程における理想気体の比熱を $c_x$ とするとき，その過程で

```math
pv^f=\mathrm{const.},\qquad
f=\frac{c_x-c_p}{c_x-c_v}
```

が成り立つことを示す．
ここで， $p$ は圧力， $v$ は比容， $c_p$ は定圧比熱， $c_v$ は定積比熱であり，いずれの比熱も一定とする．

### 1．熱力学第1法則を用いた関係式

単位質量あたりの気体が微小な熱量 $dq$ を吸収するとき，熱力学第1法則より，

```math
dq=du+p\,dv
\tag{1}
```

が成り立つ．
ここで， $u$ は単位質量あたりの内部エネルギーであり，気体が外部にする仕事を正としている．

過程における比熱を $c_x$ とすると，吸収する熱量は温度変化 $dT$ を用いて，

```math
dq=c_x\,dT
\tag{2}
```

と表される．
また，理想気体の内部エネルギーは温度のみの関数であるため，比熱 $c_v$ が一定なら，

```math
du=c_v\,dT
\tag{3}
```

となる．
式（2），（3）を式（1）に代入すると，

```math
c_x\,dT=c_v\,dT+p\,dv
```

を得る．
これを整理すれば，

```math
\boxed{
(c_x-c_v)dT=p\,dv
}
\tag{4}
```

となる．

### 2．理想気体の状態方程式を用いた変形

理想気体の状態方程式を単位質量あたりで表すと，

```math
pv=R_{\mathrm{s}}T
\tag{5}
```

となる．
ここで， $R_{\mathrm{s}}$ は単位質量あたりの気体定数であり， $v$ が比容であることに対応する．

式（5）の両辺を微分すると，

```math
v\,dp+p\,dv=R_{\mathrm{s}}\,dT
```

となる．
両辺を $pv=R_{\mathrm{s}}T$ で割れば，

```math
\boxed{\frac{dT}{T}=\frac{dp}{p}+\frac{dv}{v}}
\tag{6}
```

が得られる．
したがって，

```math
dT=T\left(\frac{dp}{p}+\frac{dv}{v}\right)
```

と表せる．
これを式（4）に代入すると，

```math
(c_x-c_v)T
\left(\frac{dp}{p}+\frac{dv}{v}\right)
=p\,dv
```

となる．
両辺を $T$ で割り，項を整理すると，

```math
(c_x-c_v)\frac{dp}{p}
=
\left(\frac{p}{T}-(c_x-c_v)\right)\frac{dv}{v}
\tag{7}
```

を得る．

ここで，状態方程式（5）より，

```math
\frac{p}{T}=\frac{R_{\mathrm{s}}}{v}
```

であるから，式（7）は，

```math
(c_x-c_v)\frac{dp}{p}
=
(R_{\mathrm{s}}-c_x+c_v)\frac{dv}{v}
\tag{8}
```

と書ける．

単位質量あたりの比熱に対するマイヤーの関係式は，

```math
c_p-c_v=R_{\mathrm{s}}
\tag{9}
```

である．
これを式（8）に代入すると，

```math
(c_x-c_v)\frac{dp}{p}
=(c_p-c_x)\frac{dv}{v}
```

となる．
よって，

```math
\frac{dp}{p}
=-\frac{c_x-c_p}{c_x-c_v}\frac{dv}{v}
```

が得られる．
ここで，

```math
\boxed{
f=\frac{c_x-c_p}{c_x-c_v}
}
\tag{10}
```

と定義すれば，

```math
\boxed{\frac{dp}{p}+f\frac{dv}{v}=0}
\tag{11}
```

となる．

### 3．積分による結論

比熱 $c_x,c_p,c_v$ は一定であるため，式（10）で定義した $f$ も一定である．
したがって，式（11）を積分すると，

```math
\int\frac{dp}{p}+f\int\frac{dv}{v}=0
```

となり，

```math
\ln p+f\ln v=\mathrm{const.}
```

を得る．
対数の性質より，

```math
\ln(pv^f)=\mathrm{const.}
```

であるから，

```math
\boxed{pv^f=\mathrm{const.}}
```

となる．
以上より，題意の関係式が示された．

## 解説

この問題では，ある過程における比熱 $c_x$ を用いて熱力学第1法則を書き，理想気体の状態方程式によって温度変化 $dT$ を圧力変化 $dp$ と比容変化 $dv$ に置き換えることで，圧力と比容だけの関係式を導いた．

指数

```math
f=\frac{c_x-c_p}{c_x-c_v}
```

は，過程における比熱と定圧比熱・定積比熱との関係を表している．
特別な場合を考えると，この式の意味が分かりやすくなる．

- **定圧過程**： $c_x=c_p$ のとき， $f=0$ となるため，

  ```math
  p=\mathrm{const.}
  ```

  が得られる．

- **断熱過程**：熱の出入りがないので $c_x=0$ である．このとき，

  ```math
  f=\frac{-c_p}{-c_v}
  =\frac{c_p}{c_v}
  =\gamma
  ```

  となり，

  ```math
  pv^\gamma=\mathrm{const.}
  ```

  というポアソンの式が得られる．ここで， $\gamma=c_p/c_v$ は比熱比である．

- **定積過程**： $c_x=c_v$ のときは式（10）の分母がゼロになるため，この式から $f$ を定義することはできない．この場合は，式（4）に $c_x=c_v$ を代入すると，

  ```math
  0=p\,dv
  ```

  となる．
  圧力 $p$ は正であるため，

  ```math
  dv=0
  ```

  が得られ，比容が一定であることが直接示される．

以上のように，定圧過程や断熱過程は，導出した一般式の特別な場合として表すことができる．
ただし，定積過程については指数 $f$ の式をそのまま使うのではなく，導出途中の式から定積条件を確認する必要がある．
