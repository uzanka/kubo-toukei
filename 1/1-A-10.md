# 演習問題【1-A-10】

## 解答

ある過程における比熱 $c_x$ は，その過程で吸収される熱量 $dQ$ と温度変化 $dT$ の比として定義される．

$$dQ = c_x dT \quad \cdots (1)$$

熱力学第1法則より，微小な熱量 $dQ$ は内部エネルギーの変化 $dU$ と，外部に対してなす仕事 $pdv$ の和として表される．

$$dQ = dU + p dv \quad \cdots (2)$$

ここで，理想気体の内部エネルギー $U$ は温度 $T$ のみの関数であり，その変化は $dU = c_v dT$ と書ける．
これを用いると，式 $(2)$ は次のように書き換えられる．

$$c_x dT = c_v dT + p dv$$

$$(c_x - c_v) dT = p dv \quad \cdots (3)$$

次に，理想気体の状態方程式 $pv = RT$（ $1 \text{ mol}$ あたり）の両辺の対数をとり，微分する．

$$\ln p + \ln v = \ln R + \ln T$$

$$\frac{dp}{p} + \frac{dv}{v} = \frac{dT}{T}$$

これより，温度変化の項 $\frac{dT}{T}$ を消去するために，

$$\frac{dT}{T} = \frac{dp}{p} + \frac{dv}{v} \implies dT = T \left( \frac{dp}{p} + \frac{dv}{v} \right) \quad \cdots (4)$$

を用いる．
式 $(4)$ を式 $(3)$ に代入する．

$$(c_x - c_v) T \left( \frac{dp}{p} + \frac{dv}{v} \right) = p dv$$

両辺を $T$ で割り，さらに整理するために $p dv$ を右辺へ， $\frac{dp}{p}$ の項を左辺へ集める．

$$(c_x - c_v) \frac{dp}{p} + (c_x - c_v) \frac{dv}{v} = \frac{p}{T} dv$$

ここで，理想気体の状態方程式より $\frac{p}{T} = \frac{R}{v}$ である．

$$(c_x - c_v) \frac{dp}{p} + (c_x - c_v) \frac{dv}{v} = \frac{R}{v} dv$$

$$(c_x - c_v) \frac{dp}{p} = \left( \frac{R}{v} - \frac{c_x - c_v}{v} \right) dv$$

$$(c_x - c_v) \frac{dp}{p} = \frac{R - c_x + c_v}{v} dv$$

ここで，マイヤーの関係式 $c_p - c_v = R$ を用いると， $R - c_x + c_v = (c_p - c_v) - c_x + c_v = c_p - c_x$ となる．

$$(c_x - c_v) \frac{dp}{p} = \frac{c_p - c_x}{v} dv$$

$$\frac{dp}{p} = \frac{c_p - c_x}{c_x - c_v} \frac{dv}{v}$$

ここで， $f = \frac{c_x - c_p}{c_x - c_v}$ と定義すると，右辺の係数は $\frac{c_p - c_x}{c_x - c_v} = -f$ となる．

$$\frac{dp}{p} = -f \frac{dv}{v}$$

$$\frac{dp}{p} + f \frac{dv}{v} = 0$$

両辺を積分すると，

$$\ln p + f \ln v = \text{const.}$$

$$\ln (pv^f) = \text{const.}$$

よって，

$$pv^f = \text{const.}$$

が得られる．

## 解説

### 1. 比熱の定義と熱力学第1法則

比熱 $c$ は，物質の温度を $1$ 度上げるのに必要な熱量である．
しかし，物質が膨張したり圧縮したりする場合，加えられた熱の一部は「仕事」に使われてしまう．
そのため，一定の体積で加熱する場合の比熱（定積比熱 $c_v$ ）と，圧力を一定に保って加熱する場合の比熱（定圧比熱 $c_p$ ）では値が異なる．
本問では，特定の経路（過程）における比熱 $c_x$ を一般的に扱っている．

### 2. 理想気体の「状態方程式」の役割

理想気体において，圧力 $p$ ，体積 $v$ ，温度 $T$ は互いに密接に関係している．
この関係式を用いることで，温度の変化 $dT$ を，圧力の変化 $dp$ や体積の変化 $dv$ に置き換えることができ，最終的に $p$ と $v$ だけの関係式 $pv^f = \text{const.}$ を導き出すことができる．

### 3. 指数 $f$ の意味

導出された $f = \frac{c_x - c_p}{c_x - c_v}$ は，その過程がどのような性質を持っているかを表す指標である．
- $c_x = c_v$（定積過程）のとき，分母が0になるので $|f|\to\infty$ となり， $pv^f=\text{const.}$ は $v=\text{const.}$ を意味する．
- $c_x = c_p$（定圧過程）のとき， $f = 0$ となり， $pv^0 = p = \text{const.}$ となる．
- $c_x = 0$ （断熱過程）のとき， $f = \frac{-c_p}{-c_v} = \gamma$ となり， $pv^\gamma = \text{const.}$ となる．
このように， $f$ は過程の特性を一つの数で表現している．
