# 例題【1-R-7】

## 解答

断熱圧縮率 $\kappa_{ad}$ と等温圧縮率 $\kappa_T$ の間に，

```math
\boxed{
\kappa\_{ad}=\frac{C_v}{C_p}\kappa_T
}
```

が成り立つことを示す．
以下では，単位質量あたりの内部エネルギーを $u$ ，比容を $v$ ，圧力を $p$ ，絶対温度を $T$ とする．
また， $C_v$ ， $C_p$ はそれぞれ定積比熱，定圧比熱を表す．

### 1．熱力学第一法則から断熱過程の関係式を導く

準静的過程に対する熱力学第一法則は，

```math
d'q=du+p\,dv
```

と表される．
ここで， $d'q$ は単位質量あたりに加えられる微小熱量， $du$ は内部エネルギーの微小変化， $p\,dv$ は気体が外部にする微小仕事である．

断熱過程では外部との熱のやり取りがないため， $d'q=0$ である．
したがって，

```math
du+p\,dv=0
\tag{1}
```

となる．

内部エネルギー $u$ を圧力 $p$ と比容 $v$ の関数 $u=u(p,v)$ とみなすと，その全微分は，

```math
du= \left(\frac{\partial u}{\partial p}\right)_v dp + \left(\frac{\partial u}{\partial v}\right)_p dv
```

と書ける．
ここで， $\left(\frac{\partial u}{\partial p}\right)_v$ は比容を一定に保ったときの圧力による内部エネルギーの変化率であり， $\left(\frac{\partial u}{\partial v}\right)_p$ は圧力を一定に保ったときの比容による変化率である．

この全微分を式 (1) に代入すると，

```math
\left(\frac{\partial u}{\partial p}\right)_v dp + \left\{ \left(\frac{\partial u}{\partial v}\right)_p+p \right\}dv=0
```

となる．
これを $dp$ と $dv$ の関係について整理すれば，断熱過程における圧力の比容による変化率は，

```math
\boxed{
\left(\frac{\partial p}{\partial v}\right)_{ad} = -\frac{ p+\left(\frac{\partial u}{\partial v}\right)_p }{ \left(\frac{\partial u}{\partial p}\right)_v }
}
\tag{2}
```

と表される．

### 2．内部エネルギーの偏微分を比熱で表す

式 (2) の右辺に含まれる偏微分を，比熱 $C_v$ ， $C_p$ を用いて表す．

まず，内部エネルギー $u$ を温度 $T$ と比容 $v$ の関数とみなす．
定積過程では比容が一定であるため，定積比熱の定義から，

```math
C_v=\left(\frac{\partial u}{\partial T}\right)_v
```

が成り立つ．
また，温度 $T$ を圧力 $p$ と比容 $v$ の関数 $T=T(p,v)$ とみなして連鎖律を用いると，

```math
\begin{aligned}
\left(\frac{\partial u}{\partial p}\right)_v &= \left(\frac{\partial u}{\partial T}\right)_v \left(\frac{\partial T}{\partial p}\right)_v\\
&=C_v\left(\frac{\partial T}{\partial p}\right)_v
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\left(\frac{\partial u}{\partial p}\right)_v =C_v\left(\frac{\partial T}{\partial p}\right)_v }
\tag{3}
```

を得る．

次に，圧力 $p$ を一定に保ったときの $\left(\frac{\partial u}{\partial v}\right)_p$ を考える．
このとき，内部エネルギーを $u=u(T,p)$ とみなせば，連鎖律により，

```math
\left(\frac{\partial u}{\partial v}\right)_p = \left(\frac{\partial u}{\partial T}\right)_p \left(\frac{\partial T}{\partial v}\right)_p
```

となる．

さらに，圧力一定の条件のもとでは， $T$ と $v$ の偏微分は逆数の関係にあるから，

```math
\left(\frac{\partial v}{\partial T}\right)_p \left(\frac{\partial T}{\partial v}\right)_p=1
```

が成り立つ．
これを利用すると，

```math
p=p\left(\frac{\partial v}{\partial T}\right)_p \left(\frac{\partial T}{\partial v}\right)_p
```

と書ける．
よって，

```math
\begin{aligned}
\left(\frac{\partial u}{\partial v}\right)_p+p &= \left(\frac{\partial u}{\partial T}\right)_p \left(\frac{\partial T}{\partial v}\right)_p\\
&\quad+ p\left(\frac{\partial v}{\partial T}\right)_p \left(\frac{\partial T}{\partial v}\right)_p\\
&= \left\{ \left(\frac{\partial u}{\partial T}\right)_p +p\left(\frac{\partial v}{\partial T}\right)_p \right\} \left(\frac{\partial T}{\partial v}\right)_p
\end{aligned}
```

となる．

ここで，定圧過程では熱力学第一法則から，

```math
d'q=du+p\,dv
```

であり，圧力一定のもとでは，

```math
du=\left(\frac{\partial u}{\partial T}\right)_p dT, \qquad dv=\left(\frac{\partial v}{\partial T}\right)_p dT
```

と表せる．
したがって，定圧比熱の定義から，

```math
\begin{aligned}
C_p &=\left(\frac{d'q}{dT}\right)_p\\
&=\left(\frac{\partial u}{\partial T}\right)_p +p\left(\frac{\partial v}{\partial T}\right)_p
\end{aligned}
```

が成り立つ．
これを上の式に用いれば，

```math
\boxed{
\left(\frac{\partial u}{\partial v}\right)_p+p =C_p\left(\frac{\partial T}{\partial v}\right)_p }
\tag{4}
```

を得る．

式 (3)，(4) を式 (2) に代入すると，

```math
\boxed{
\left(\frac{\partial p}{\partial v}\right)_{ad} = -\frac{C_p}{C_v} \frac{ \left(\frac{\partial T}{\partial v}\right)_p }{ \left(\frac{\partial T}{\partial p}\right)_v }
}
\tag{5}
```

となる．

### 3．等温過程の変化率と結びつける

ここで，温度 $T$ を圧力 $p$ と比容 $v$ の関数 $T=T(p,v)$ とみなすと，全微分は，

```math
dT= \left(\frac{\partial T}{\partial v}\right)_p dv + \left(\frac{\partial T}{\partial p}\right)_v dp
```

と表される．

等温過程では温度が一定に保たれるため， $dT=0$ である．
したがって，

```math
\left(\frac{\partial T}{\partial v}\right)_p dv + \left(\frac{\partial T}{\partial p}\right)_v dp=0
```

となる．
この式を $dv$ で割って整理すると，

```math
\boxed{
\left(\frac{\partial p}{\partial v}\right)_T = -\frac{ \left(\frac{\partial T}{\partial v}\right)_p }{ \left(\frac{\partial T}{\partial p}\right)_v }
}
\tag{6}
```

を得る．

式 (6) を式 (5) に代入すれば，

```math
\boxed{
\left(\frac{\partial p}{\partial v}\right)_{ad} = \frac{C_p}{C_v} \left(\frac{\partial p}{\partial v}\right)_T
}
\tag{7}
```

となる．

### 4．圧縮率の定義を用いる

問題で与えられた断熱圧縮率と等温圧縮率の定義は，

```math
\kappa_{ad} =-\frac{1}{v} \left(\frac{\partial v}{\partial p}\right)_{ad}
```

および

```math
\kappa_T =-\frac{1}{v} \left(\frac{\partial v}{\partial p}\right)_T
```

である．

同じ過程に沿った変化率については， $\left(\frac{\partial v}{\partial p}\right)$ と $\left(\frac{\partial p}{\partial v}\right)$ は逆数の関係にある．
したがって，式 (7) の両辺の逆数をとると，

```math
\left(\frac{\partial v}{\partial p}\right)_{ad} = \frac{C_v}{C_p} \left(\frac{\partial v}{\partial p}\right)_T
```

となる．
この両辺に $-1/v$ を掛ければ，

```math
-\frac{1}{v} \left(\frac{\partial v}{\partial p}\right)_{ad} = \frac{C_v}{C_p} \left\{ -\frac{1}{v} \left(\frac{\partial v}{\partial p}\right)_T \right\}
```

を得る．
圧縮率の定義を用いると，

```math
\boxed{
\kappa\_{ad}=\frac{C_v}{C_p}\kappa_T
}
```

となる．
よって，題意の関係式が示された．

## 3．物理的な意味

断熱圧縮率は，熱の出入りがない条件で圧力を変化させたときに，比容がどれだけ変化するかを表す．
一方，等温圧縮率は，温度を一定に保った条件での比容の変化を表す．

通常の安定な物質で $C_p>C_v>0$ であれば，

```math
0<\frac{C_v}{C_p}<1
```

であるため，

```math
\boxed{
\kappa\_{ad}<\kappa_T
}
```

となる．
すなわち，同じ圧力変化に対する比容の変化は，断熱過程の方が小さい．

これは，断熱圧縮では圧縮に伴って温度が上昇し，圧力がより大きく上昇するためである．
一方，等温圧縮では熱を外部に放出して温度を一定に保つことができるため，比容はより変化しやすい．

なお，圧力 $p$ を比容 $v$ の関数として表したとき，通常はどちらの過程でも

```math
\left(\frac{\partial p}{\partial v}\right)<0
```

である．
したがって，断熱線の傾きは等温線よりも絶対値が大きいというのが正確な表現である．
これは，導出した圧縮率の関係とも一致する．
