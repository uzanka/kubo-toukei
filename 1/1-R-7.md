# 例題【1-R-7】

## 解答

断熱圧縮率 $\kappa_{\text{ad}}$ と等温圧縮率 $\kappa_T$ の間には，比熱 $C_p, C_v$ を用いて

$$\kappa_{\text{ad}} = \frac{C_v}{C_p} \kappa_T$$

という関係が成り立つことを示す．

### 1. 基本的な定義と準備

まず，問題で与えられている各変数の定義を確認する．

- 等温圧縮率 $\kappa_T$ :
  温度 $T$ が一定の条件下で，圧力が変化したときの体積の変化率を表す．
  $$\kappa_T = -\frac{1}{v} \left( \frac{\partial v}{\partial p} \right)_T$$

- 断熱圧縮率 $\kappa_{\text{ad}}$ :
  熱の出入りがない（断熱）条件下で，圧力が変化したときの体積の変化率を表す．
  $$\kappa_{\text{ad}} = -\frac{1}{v} \left( \frac{\partial v}{\partial p} \right)_{\text{ad}}$$

- 定積比熱 $C_v$ :
  体積が一定の条件下で，温度を1単位上昇させるのに必要な熱量．
  $$C_v = \left( \frac{\partial u}{\partial T} \right)_v$$

- 定圧比熱 $C_p$ :
  圧力が一定の条件下で，温度を1単位上昇させるのに必要な熱量．
  $$C_p = \left( \frac{\partial u}{\partial T} \right)_p + p \left( \frac{\partial v}{\partial T} \right)_p$$

ここで， $v$ は単位質量あたりの体積， $p$ は圧力， $u$ は内部エネルギー， $T$ は温度である．

### 2. 熱力学第一法則からの出発

断熱過程においては，外部との熱のやり取りがないため，熱力学第一法則（ $dq = du + p \, dv = 0$ ）より，以下の関係式が成り立つ．

$$du + p \, dv = 0 \quad \cdots (\text{A})$$

内部エネルギー $u$ は，状態量として圧力 $p$ と体積 $v$ の関数 $u(p, v)$ とみなせる．
したがって，全微分 $du$ は次のように書ける．

$$du = \left( \frac{\partial u}{\partial p} \right)_v dp + \left( \frac{\partial u}{\partial v} \right)_p dv$$

これを式 (A) に代入すると，

```math
\left( \frac{\partial u}{\partial p} \right)_v dp + \left\{ \left( \frac{\partial u}{\partial v} \right)_p + p \right\} dv = 0 \quad \cdots (\text{B})
```

したがって，断熱過程における圧力の体積による変化率は，

$$\left( \frac{\partial p}{\partial v} \right)_{\text{ad}} = - \frac{\left( \frac{\partial u}{\partial v} \right)_p + p}{\left( \frac{\partial u}{\partial p} \right)_v} \quad \cdots (\text{C})$$

と表せる．

### 3. 偏微分の計算

ここで，内部エネルギー $u$ を温度 $T$ と体積 $v$ （または圧力 $p$ ）の関数 $u(T, v)$ （または $u(T, p)$ ）とみなして chain rule を適用する．

まず， $\left( \frac{\partial u}{\partial p} \right)_v$ について， $u = u(T(p,v), v)$ とみて，

$$\left( \frac{\partial u}{\partial p} \right)_v = \left( \frac{\partial u}{\partial T} \right)_v \left( \frac{\partial T}{\partial p} \right)_v = C_v \left( \frac{\partial T}{\partial p} \right)_v \quad \cdots (\text{D})$$

次に， $\left( \frac{\partial u}{\partial v} \right)_p + p$ について， $u = u(T(p,v), p)$ とみて，

$$\left( \frac{\partial u}{\partial v} \right)_p = \left( \frac{\partial u}{\partial T} \right)_p \left( \frac{\partial T}{\partial v} \right)_p$$

ゆえに，

$$\left( \frac{\partial u}{\partial v} \right)_p + p = \left[ \left( \frac{\partial u}{\partial T} \right)_p + p \left( \frac{\partial v}{\partial T} \right)_p \right] \left( \frac{\partial T}{\partial v} \right)_p = C_p \left( \frac{\partial T}{\partial v} \right)_p \quad \cdots (\text{E})$$

(D), (E) を (C) に入れると，

$$\left( \frac{\partial p}{\partial v} \right)_{\text{ad}} = - \frac{C_p}{C_v} \frac{(\partial T / \partial v)_p}{(\partial T / \partial p)_v} \quad \cdots (\text{F})$$

### 4. 等温圧縮率との関係

ここで，温度を $p, v$ の関数とみなせば，全微分は

$$dT = \left( \frac{\partial T}{\partial v} \right)_p dv + \left( \frac{\partial T}{\partial p} \right)_v dp$$

と表される．
$T$ を一定に保つには $dT = 0$ であるから，

$$\left( \frac{\partial p}{\partial v} \right)_T = - \frac{(\partial T / \partial v)_p}{(\partial T / \partial p)_v} \quad \cdots (\text{G})$$

が得られる．
これは純粋な数学的恒等式であり，過程の条件とは無依に成り立つ．
(F) に (G) を代入すると，

$$\left( \frac{\partial p}{\partial v} \right)_{\text{ad}} = \frac{C_p}{C_v} \left( \frac{\partial p}{\partial v} \right)_T \quad \cdots (\text{H})$$

### 5. 圧縮率への変換

問題の定義に従って，断熱・等温圧縮率に書き換える．
$\kappa_{\text{ad}} = -\frac{1}{v} \left( \frac{\partial v}{\partial p} \right)_{\text{ad}}$ および $\kappa_T = -\frac{1}{v} \left( \frac{\partial v}{\partial p} \right)_T$ であるから，

$$\left( \frac{\partial v}{\partial p} \right)_{\text{ad}} = \left( \frac{\partial p}{\partial v} \right)_{\text{ad}}^{-1}, \quad \left( \frac{\partial v}{\partial p} \right)_T = \left( \frac{\partial p}{\partial v} \right)_T^{-1}$$

である．
(H) の両辺の逆数をとると，

$$\left( \frac{\partial v}{\partial p} \right)_{\text{ad}} = \frac{C_v}{C_p} \left( \frac{\partial v}{\partial p} \right)_T$$

両辺に $-\frac{1}{v}$ をかけて，

$$\kappa_{\text{ad}} = \frac{C_v}{C_p} \kappa_T$$

が示された．

## 解説

この問題は，熱力学における「圧縮のしやすさ」が，温度の変化を伴う場合（断熱）と伴わない場合（等温）でどのように異なるかを問うている．

### 1. なぜ断熱圧縮の方が「硬い」のか？

私たちがピストンでガスを圧縮するとき，早く圧縮すると（断熱過程），ガスは熱を逃がす暇がないため温度が上昇する．
温度が上がると，分子の運動が激しくなり，外側に押し戻そうとする力が増える．
そのため，等温過程（温度を一定に保つために熱を逃がし続ける過程）に比べて，断熱過程では圧力が急激に上がり，圧縮しにくくなる．

### 2. 数式的な意味

結果として得られた $\kappa_{\text{ad}} = \frac{C_v}{C_p} \kappa_T$ という式を見ると，比熱の比 $\frac{C_v}{C_p}$ が係数として現れている．
一般に，定圧比熱 $C_p$ は定積比熱 $C_v$ よりも大きくなる（ $C_p > C_v$ ）．
これは，定圧過程では膨張に伴う仕事をする分，より多くの熱が必要だからである．
したがって， $\frac{C_v}{C_p} < 1$ となり，

$$\kappa_{\text{ad}} < \kappa_T$$

が成り立つ．
圧縮率 $\kappa$ は「圧縮のしやすさ」を表すため，値が小さいほど「圧縮しにくい（硬い）」ことを意味する．
これは，先ほどの直感的な説明と一致している．

### 3. まとめ

- **等温圧縮** : 温度を一定に保てるので，圧縮しやすい （ $\kappa_T$ が大きい）．
- **断熱圧縮** : 圧縮に伴って温度が上がるため，押し戻す力が強く，圧縮しにくい （ $\kappa_{\text{ad}}$ が小さい）．
- この関係は，比熱の比によって数学的に美しく結ばれている．
