# 演習問題【1-C-22】

## 解答

温度 $300^\circ\mathrm{C}$ ，圧力 $5\,\mathrm{atm}$ の過熱水蒸気を，噴出口から圧力 $1\,\mathrm{atm}$ の大気中へ噴出させる．
水蒸気を比熱一定の理想気体とみなし，熱伝導，重力および流れの損失を無視した理想的な断熱膨張を考える．
このとき，流速の上限と噴出口での最終温度を求める．

与えられた定圧比熱と比熱比は，

```math
c_p=0.49\,\frac{\mathrm{cal}}{\mathrm{g\cdot K}},
\qquad \gamma=1.33
```

である．

### 1．定常流のエネルギー保存則

前問で導出した定常流のエネルギー保存則より，単位質量当たりのエンタルピー $h$ と運動エネルギーの和は，流線に沿って一定である．
すなわち，

```math
h+\frac{v^2}{2}=\mathrm{const.}
\tag{1}
```

ここで， $v$ は流速の大きさである．

比熱一定の理想気体では，単位質量当たりの内部エネルギー $e$ は，

```math
e=c_vT+\mathrm{const.}
```

と表される．
また，エンタルピーは，

```math
h=e+\frac{p}{\rho}
```

で定義される．
理想気体の状態方程式とマイヤーの関係式を用いると，

```math
\frac{p}{\rho}=R_{\mathrm{s}}T,
\qquad c_p=c_v+R_{\mathrm{s}}
```

となる．
ここで， $R_{\mathrm{s}}$ は単位質量当たりの気体定数である．
したがって，

```math
\begin{aligned}
h
&=c_vT+R_{\mathrm{s}}T+\mathrm{const.}\\
&=c_pT+\mathrm{const.}
\end{aligned}
```

を得る．
この関係を式（1）に代入し，両状態に共通する定数を消去すると，

```math
\boxed{
c_pT+\frac{v^2}{2}=\mathrm{const.}
}
\tag{2}
```

となる．
これが噴出する水蒸気の温度と流速を求めるためのエネルギー保存則である．

### 2．噴出口における最終温度

噴出前の容器内の状態を状態1，噴出口の状態を状態2とする．
それぞれの圧力と温度は，

```math
\begin{aligned}
p_1&=5\,\mathrm{atm},&
T_1&=300+273=573\,\mathrm{K},\\
p_2&=1\,\mathrm{atm},&
T_2&=? 
\end{aligned}
```

である．

流れの損失がなく，断熱かつ可逆な膨張を仮定すると，理想気体の断熱変化では，

```math
pV^\gamma=\mathrm{const.}
```

が成り立つ．
これと理想気体の状態方程式を組み合わせると，

```math
\boxed{
T\,p^{(1-\gamma)/\gamma}
=\mathrm{const.}
}
\tag{3}
```

が得られる．

式（3）を状態1と状態2に適用すると，

```math
T_1p_1^{(1-\gamma)/\gamma}
=T_2p_2^{(1-\gamma)/\gamma}
```

したがって，

```math
T_2=T_1
\left(\frac{p_2}{p_1}\right)^{(\gamma-1)/\gamma}
\tag{4}
```

となる．

ここで，比熱比 $\gamma=1.33$ より，

```math
\frac{\gamma-1}{\gamma}
=\frac{1.33-1}{1.33}
=\frac{0.33}{1.33}
\approx0.248
```

である．
よって，

```math
T_2=573\left(\frac15\right)^{0.248}\,\mathrm{K}
```

となる．

数値を計算するために，

```math
x=5^{-0.248}
```

とおき，常用対数を取ると，

```math
\begin{aligned}
\log_{10}x
&=-0.248\log_{10}5\\
&\approx-0.248\times0.699\\
&=-0.1734
\end{aligned}
```

である．
したがって，

```math
x=10^{-0.1734}\approx0.671
```

を得る．
これを式（4）に代入すると，

```math
\begin{aligned}
T_2&=573\times0.671\\
&\approx384\,\mathrm{K}
\end{aligned}
```

となる．
摂氏温度に換算すれば，

```math
t_2=384-273=111^\circ\mathrm{C}
```

である．
よって，噴出口における最終温度は，

```math
\boxed{
T_2\approx384\,\mathrm{K}
=111^\circ\mathrm{C}
}
```

となる．

### 3．流速の上限

状態1の容器内では流速が十分小さいとみなし，

```math
v_1\approx0
```

とする．
式（2）のエネルギー保存則を状態1と状態2に適用すると，

```math
c_pT_1+\frac{v_1^2}{2}
=c_pT_2+\frac{v_2^2}{2}
```

であるから，

```math
c_pT_1=c_pT_2+\frac{v_2^2}{2}
```

となる．
これを $v_2$ について解くと，

```math
\boxed{
v_2=\sqrt{2c_p(T_1-T_2)}
}
\tag{5}
```

が得られる．

ここで，温度差に対して定圧比熱を用いるため，単位をそろえて計算する．
与えられた比熱は，

```math
c_p=0.49\,\frac{\mathrm{cal}}{\mathrm{g\cdot K}}
```

である．
$1\,\mathrm{cal}=4.184\,\mathrm{J}$ ， $1\,\mathrm{g}=10^{-3}\,\mathrm{kg}$ より，

```math
\begin{aligned}
c_p
&=0.49\times4.184
\frac{\mathrm{J}}{\mathrm{g\cdot K}}\\
&=0.49\times4.184\times10^3
\frac{\mathrm{J}}{\mathrm{kg\cdot K}}\\
&\approx2050\,\frac{\mathrm{J}}{\mathrm{kg\cdot K}}
\end{aligned}
```

となる．

式（5）に $T_1=573\,\mathrm{K}$ ， $T_2\approx384\,\mathrm{K}$ を代入すると，

```math
\begin{aligned}
v_2
&=\sqrt{2\times2050\times(573-384)}\\
&=\sqrt{4100\times189}\\
&=\sqrt{774900}\\
&\approx880\,\mathrm{m/s}
\end{aligned}
```

を得る．

したがって，損失のない理想的な断熱膨張における流速の上限は，

```math
\boxed{
v_{\max}\approx880\,\mathrm{m/s}
}
```

となる．

### 答

求める最終温度と流速の上限は，

```math
\boxed{
\begin{aligned}
\text{最終温度}&\approx111^\circ\mathrm{C},\\
\text{流速の上限}&\approx880\,\mathrm{m/s}.
\end{aligned}
}
```

である．

この結果は，圧力低下を伴う断熱膨張によって水蒸気のエンタルピーが減少し，その分が運動エネルギーに変換されることを表している．
なお，実際の流れでは粘性やその他の損失が存在し得るため，実際の流速はこの理想的な上限より小さくなる．
