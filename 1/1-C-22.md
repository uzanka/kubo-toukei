# 演習問題【1-C-22】

## 解答

前問（演習問題【1-C-21】）の結果より，定常的な流体の流れにおいて，エンタルピー密度 $h$ と運動エネルギー密度 $\frac{1}{2}v^2$ の和は流線に沿って一定値をとる．
すなわち，

$$h + \frac{1}{2}v^2 = \text{const.} \quad \cdots (1)$$

である．

理想気体において，比熱が一定であるとき，内部エネルギー $u$ は温度 $T$ を用いて $u = c_v T + \text{const.}$ と表される．
また，エンタルピー $h$ は $h = u + p/\rho$ であり，理想気体の状態方程式 $p/\rho = RT/M$ および Mayer の関係式 $c_p = c_v + R/M$ を用いると，

$$h = c_v T + \frac{RT}{M} + \text{const.} = (c_v + \frac{R}{M})T + \text{const.} = c_p T + \text{const.}$$

となる．
したがって，式(1)は次のように書き換えられる：

$$c_p T + \frac{1}{2}v^2 = \text{const.} \quad \cdots (2)$$

また，理想気体の断熱変化において，圧力 $p$ と温度 $T$ の間には次の関係がある：

$$T p^{(1-\gamma)/\gamma} = \text{const.} \quad \cdots (3)$$

### 1. 最終温度の算出

噴出口の出口（大気中）における圧力を $p_2 = 1\,\text{atm}$ ，噴出口に到達する前の容器内の状態を 1 とすると，圧力 $p_1 = 5\,\text{atm}$ ，温度 $T_1 = 300^\circ\text{C} = 573\,\text{K}$ である．
噴出口から放出された後の最終的な温度を $T_2$ とすると，断熱膨張の式(3)より，

$$T_1 p_1^{(1-\gamma)/\gamma} = T_2 p_2^{(1-\gamma)/\gamma}$$

$$T_2 = T_1 \left( \frac{p_2}{p_1} \right)^{(\gamma-1)/\gamma}$$

ここで， $\gamma = 1.33$ を代入すると，指数部分は $\frac{1.33-1}{1.33} = \frac{0.33}{1.33} \approx 0.248$ となる．
したがって，

$$T_2 = 573 \times \left( \frac{1}{5} \right)^{0.248} = 573 \times 5^{-0.248}\,\text{K}$$

$x = 5^{-0.248}$ を計算するために，常用対数 $\log_{10}$ をとる：

$$\log_{10} x = -0.248 \log_{10} 5$$

$\log_{10} 5 \approx 0.699$ を用いると，

$$\log_{10} x = -0.248 \times 0.699 = -0.173352$$

$$x = 10^{-0.173352} \approx 0.671$$

これより，求める最終温度 $T_2$ は：

$$T_2 = 573 \times 0.671 \approx 384\,\text{K}$$

摂氏温度に直すと，

$$T_2 = 384 - 273 = 111^\circ\text{C}$$

### 2. 流速の上限の算出

定常流の速さの上限 $v$ は，噴出口から放出された直後の状態（温度 $T_2$ ，圧力 $p_2$ ）における運動エネルギーを求めることで得られる．
式(2)より，状態 1（容器内， $v_1 \approx 0$ ）と状態 2（噴出口，速度 $v_2$ ）の間で：

$$c_p T_1 + 0 = c_p T_2 + \frac{1}{2}v_2^2$$

$$\frac{1}{2}v_2^2 = c_p (T_1 - T_2)$$

$$v_2 = \sqrt{2 c_p (T_1 - T_2)}$$

ここで，与えられた定比熱 $c_p = 0.49\,\text{cal}/(\text{g}\cdot\text{deg})$ を SI 単位系に変換する必要がある．
$1\,\text{cal} = 4.184\,\text{J}$ であるから，

$$c_p = 0.49 \times 4.184\,\text{J}/(\text{g}\cdot\text{K}) = 0.49 \times 4.184 \times 10^3\,\text{J}/(\text{kg}\cdot\text{K}) \approx 2050\,\text{J}/(\text{kg}\cdot\text{K})$$

値を代入すると：

$$v_2 = \sqrt{2 \times 2050 \times (573 - 384)} = \sqrt{4100 \times 189} = \sqrt{774900} \approx 880\,\text{m/s}$$

**答：**
- 最終温度 $111^\circ\text{C}$
- 速さの上限 $880\,\text{m/s}$

## 解説

本問題は，熱力学の「定常流のエネルギー保存則」と「断熱変化」を組み合わせて，噴出する蒸気の速度と温度を求める実用的な問題である．

### ポイント1：エンタルピーとエネルギーの保存

前問で導いた通り，流体が移動する際には，単なる内部エネルギー $u$ だけでなく，周囲の圧力による仕事の成分を含む「エンタルピー $h$ 」が保存される．
流体が加速して運動エネルギーを得る場合，その分だけエンタルピー（つまり温度）が減少する．
これが，噴出後に温度が下がる理由である．

### ポイント2：断熱膨張と温度変化

噴出口から大気中へ流れ出す際，圧力は $5\,\text{atm}$ から $1\,\text{atm}$ へと急激に低下する．
この過程で外部と熱のやり取りがない（断熱）と仮定すると，圧力の低下に伴って温度も低下する．
この関係を $p, T$ の関係式（断熱変化の式）から計算している．

### ポイント3：単位系の変換

物理の問題を解く際，与えられた単位（ $\text{cal/g}\cdot\text{deg}$ ）を標準的な SI 単位（ $\text{J/kg}\cdot\text{K}$ ）に正しく変換することが重要である．
特に，熱量 $\text{cal}$ をエネルギー $\text{J}$ に，質量 $\text{g}$ を $\text{kg}$ に変換する際，桁数のミスに注意が必要である．
