# 例題【1-R-2】

## 解答

まず，熱力学第一法則を考える．
系の質量は一定であり，圧力による体積変化の仕事だけを考えると，単位質量あたりの内部エネルギーの変化 $du$ ，加えられた熱量 $d'q$ ，および気体が外部にする仕事 $dw$ の間には，

```math
du=d'q-dw
```

が成り立つ．

準静的な過程では，気体が外部にする微小仕事は，圧力を $p$ ，比容の変化を $dv$ として

```math
dw=p\,dv
```

と表される．
したがって，熱力学第一法則は，

```math
d'q=du+p\,dv
\tag{1}
```

となる．

次に，内部エネルギー $u$ は温度 $T$ と比容 $v$ の関数 $u=u(T,v)$ とみなせるため，その全微分は，

```math
du= \left(\frac{\partial u}{\partial T}\right)_v dT + \left(\frac{\partial u}{\partial v}\right)_T dv
\tag{2}
```

と書ける．
ここで， $\left(\frac{\partial u}{\partial T}\right)_v$ は比容 $v$ を一定に保ったときの温度による内部エネルギーの変化率であり， $\left(\frac{\partial u}{\partial v}\right)_T$ は温度 $T$ を一定に保ったときの比容による内部エネルギーの変化率である．

式 (2) を式 (1) に代入すると，

```math
\begin{aligned}
d'q ={}&\left(\frac{\partial u}{\partial T}\right)_v dT\\
&+\left(\frac{\partial u}{\partial v}\right)_T dv +p\,dv
\end{aligned}
```

となる．
これを整理すれば，

```math
\boxed{
d'q= \left(\frac{\partial u}{\partial T}\right)_v dT + \left\{ \left(\frac{\partial u}{\partial v}\right)_T+p \right\}dv
}
\tag{3}
```

を得る．

さて，問題で定義されている比熱 $c_x$ は，状態量 $x$ を一定に保ちながら温度を $dT$ だけ変化させるのに必要な熱量を，温度変化で割ったものである．
したがって，

```math
c_x=\left(\frac{d'q}{dT}\right)_x
\tag{4}
```

と定義される．

ここで，熱平衡状態では状態量 $x$ は温度 $T$ と比容 $v$ によって決まる．
独立変数を $T$ と $x$ に選び直し，比容を $v=v(T,x)$ とみなすことができるとする．
このとき， $x$ を一定に保ちながら温度を変化させると，比容の微小変化 $dv$ は，

```math
dv=\left(\frac{\partial v}{\partial T}\right)_x dT
\tag{5}
```

と表される．
ここで， $\left(\frac{\partial v}{\partial T}\right)_x$ は， $x$ を一定に保ったときの温度変化に対する比容の変化率である．

式 (5) を式 (3) に代入すると，

```math
\begin{aligned}
d'q ={}&\left(\frac{\partial u}{\partial T}\right)_v dT\\
&+\left\{ \left(\frac{\partial u}{\partial v}\right)_T+p \right\} \left(\frac{\partial v}{\partial T}\right)_x dT
\end{aligned}
```

となる．
両辺を $dT$ で割れば，

```math
\frac{d'q}{dT} = \left(\frac{\partial u}{\partial T}\right)_v + \left\{ \left(\frac{\partial u}{\partial v}\right)_T+p \right\} \left(\frac{\partial v}{\partial T}\right)_x
```

を得る．
ここで， $x$ 一定の条件を明示し，式 (4) を用いると，

```math
\boxed{
c_x= \left(\frac{\partial u}{\partial T}\right)_v + \left\{ \left(\frac{\partial u}{\partial v}\right)_T+p \right\} \left(\frac{\partial v}{\partial T}\right)_x
}
```

となる．
よって，題意の式が示された．

## 3．解説

この問題の要点は，比熱を定義する条件と，内部エネルギーを微分するときの条件を区別することにある．

内部エネルギー $u$ は温度 $T$ と比容 $v$ の関数であるため，微小な変化は，温度による寄与と比容による寄与に分けて表せる．
これが式 (2) の全微分である．

一方，求める比熱 $c_x$ は， $x$ を一定に保つという条件のもとで定義されている．
そのため，温度が変化するときの比容の変化は，

```math
dv=\left(\frac{\partial v}{\partial T}\right)_x dT
```

と表さなければならない．
この関係を熱力学第一法則に代入することで，求める比熱の式が導かれる．

得られた式の右辺の第1項

```math
\left(\frac{\partial u}{\partial T}\right)_v
```

は，比容を一定に保ったときの内部エネルギーの温度変化による寄与を表す．
第2項

```math
\left\{ \left(\frac{\partial u}{\partial v}\right)_T+p \right\} \left(\frac{\partial v}{\partial T}\right)_x
```

は， $x$ を一定に保って温度を変化させる際に比容も変化することによる寄与を表す．
この項には，比容の変化に伴う内部エネルギーの変化と，外部にする仕事の両方が含まれている．

したがって，比熱は温度による内部エネルギーの変化だけでなく，一定に保つ状態量 $x$ によって決まる比容の変化の仕方にも依存することが分かる．
