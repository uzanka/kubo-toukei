# 演習問題【1-B-20】

## 解答

熱輻射を物質とする Carnot サイクルを考える．
与えられた条件より，単位体積当たりの内部エネルギー密度は $u = \sigma T^4$ 、状態方程式は $p = u/3 = \sigma T^4/3$ である．

### 1. 準備：熱力学第一法則と断熱過程

単位体積当たりの内部エネルギー $U$ は、体積 $V$ を用いて $U = Vu = \sigma VT^4$ と書ける．
準静的な過程における熱力学第一法則は，次のように表される：

$$dU = d'Q - p \, dV \quad \cdots (1)$$

式(1)に $U = \sigma VT^4$ および $p = \sigma T^4/3$ を代入する：

$$d(\sigma VT^4) = d'Q - \frac{\sigma T^4}{3} dV$$

左辺を展開すると：

$$\sigma T^4 dV + 4\sigma VT^3 dT = d'Q - \frac{\sigma T^4}{3} dV$$

これより，吸収する熱量 $d'Q$ は次のように求められる：

$$d'Q = \left( \sigma T^4 + \frac{\sigma T^4}{3} \right) dV + 4\sigma VT^3 dT = \frac{4}{3}\sigma T^4 dV + 4\sigma VT^3 dT \quad \cdots (2)$$

ここで，断熱過程（ $d'Q = 0$ ）の条件を求めると：

$$\frac{4}{3}\sigma T^4 dV + 4\sigma VT^3 dT = 0$$

$$\frac{4}{3}\sigma T^4 V \left( \frac{dV}{V} + \frac{3 dT}{T} \right) = 0$$

これより， $\frac{dV}{V} + 3 \frac{dT}{T} = 0$ となり，積分すると $\log V + 3 \log T = \text{const.}$ ，すなわち

$$VT^3 = \text{const.} \quad \cdots (3)$$

が得られる．
また，状態方程式 $p = \sigma T^4/3$ を用いると，

$$p V^{4/3} = \left( \frac{\sigma T^4}{3} \right) V^{4/3} = \frac{\sigma}{3} (V T^3)^{4/3} = \text{const.}$$

となり，断熱過程において $p V^{4/3} = \text{const.}$ が成り立つ．

また，定積熱容量 $C_V$ は：

$$C_V = \left( \frac{\partial U}{\partial T} \right)_V = \frac{\partial}{\partial T}(\sigma VT^4) = 4\sigma VT^3$$

### 2. Carnot サイクルの各過程

Carnot サイクルは，状態1 $\to$ 2（等温膨張），2 $\to$ 3（断熱膨張），3 $\to$ 4（等温圧縮），4 $\to$ 1（断熱圧縮）の4つの過程からなる．

#### (i) 過程 $1 \to 2$（等温膨張：温度 $T_1$ 一定）

温度が $T_1$ で一定なので， $dT = 0$ である．
式(2)より，吸収する熱量は：

$$Q_{1 \to 2} = \int_{V_1}^{V_2} \frac{4}{3}\sigma T_1^4 dV = \frac{4}{3}\sigma T_1^4 (V_2 - V_1)$$

この過程で行われる仕事 $A_{1 \to 2}$ は（系が外部から受ける仕事として）：

$$A_{1 \to 2} = -\int_{V_1}^{V_2} p \, dV = -\int_{V_1}^{V_2} \frac{\sigma T_1^4}{3} dV = -\frac{\sigma T_1^4}{3} (V_2 - V_1)$$

#### (ii) 過程 $2 \to 3$（断熱膨張）

断熱過程なので $Q_{2 \to 3} = 0$ である．
内部エネルギーの変化 $dU_{2 \to 3}$ は，式(1)より $dU_{2 \to 3} = -A_{2 \to 3}$ である．
$U = \sigma VT^4$ より， $U_3 - U_2 = \sigma V_3 T_3^4 - \sigma V_2 T_1^4$ である．

#### (iii) 過程 $3 \to 4$（等温圧縮：温度 $T_3$ 一定）

温度が $T_3$ で一定なので， $dT = 0$ である．
吸収する熱量は：

$$Q_{3 \to 4} = \int_{V_3}^{V_4} \frac{4}{3}\sigma T_3^4 dV = \frac{4}{3}\sigma T_3^4 (V_4 - V_3)$$

ここで $V_4 < V_3$ なので， $Q_{3 \to 4} < 0$ となり，熱を放出している．

#### (iv) 過程 $4 \to 1$（断熱圧縮）

断熱過程なので $Q_{4 \to 1} = 0$ である．

### 3. Clausius の等式の検証

Carnot サイクルが成立するためには，Clausius の等式 $\frac{Q_{1 \to 2}}{T_1} + \frac{Q_{3 \to 4}}{T_3} = 0$ が成り立つ必要がある．

各項を計算すると：

$$\frac{Q_{1 \to 2}}{T_1} = \frac{\frac{4}{3}\sigma T_1^4 (V_2 - V_1)}{T_1} = \frac{4}{3}\sigma T_1^3 (V_2 - V_1)$$

$$\frac{Q_{3 \to 4}}{T_3} = \frac{\frac{4}{3}\sigma T_3^4 (V_4 - V_3)}{T_3} = \frac{4}{3}\sigma T_3^3 (V_4 - V_3)$$

これらを足し合わせると：

$$\frac{Q_{1 \to 2}}{T_1} + \frac{Q_{3 \to 4}}{T_3} = \frac{4}{3}\sigma \left[ T_1^3 (V_2 - V_1) + T_3^3 (V_4 - V_3) \right]$$

ここで，断熱過程の条件 $VT^3 = \text{const.}$ より，
- 過程 $2 \to 3$ において $V_2 T_1^3 = V_3 T_3^3$
- 過程 $4 \to 1$ において $V_4 T_3^3 = V_1 T_1^3$

これを用いると：

$$T_1^3 (V_2 - V_1) + T_3^3 (V_4 - V_3) = T_1^3 V_2 - T_1^3 V_1 + T_3^3 V_4 - T_3^3 V_3$$

$$= (T_1^3 V_2 - T_3^3 V_3) + (T_3^3 V_4 - T_1^3 V_1)$$

$$= (T_1^3 V_2 - T_1^3 V_2) + (T_1^3 V_1 - T_1^3 V_1) = 0$$

したがって，

$$\frac{Q_{1 \to 2}}{T_1} + \frac{Q_{3 \to 4}}{T_3} = 0$$

となり，Clausius の等式が成り立つことが示された．

## 解説

本問題は，光（熱輻射）を一種の「ガス」のように見なし，その熱力学的な振る舞いを解析するものである．

### 熱輻射の特殊な性質

通常の気体とは異なり，熱輻射の内部エネルギーは「温度の4乗」に比例するという Stefan-Boltzmann の法則に従う．
また，輻射圧 $p$ は内部エネルギー密度の $1/3$ であるという、非常に特徴的な状態方程式を持っている．

### 解法のロジック

1. **熱力学第一法則の書き換え** :
  まず，与えられた $u = \sigma T^4$ や $p = \sigma T^4/3$ を使って，熱量 $d'Q$ や内部エネルギー変化 $dU$ を $T, V$ の関数として具体的に書き下す．
2. **断熱過程の特定** :
  $d'Q = 0$ と置くことで，温度と体積がどのような関係（ $VT^3 = \text{const.}$ ）で変化するかを導く．
  これは，気体における $PV^\gamma = \text{const.}$ に相当するものである．
3. **サイクルの解析** :
  Carnot サイクルは「等温」と「断熱」の組み合わせでできている．
  それぞれの過程で，熱量 $Q$ がどのように計算されるかを求める．
4. **Clausius の等式の証明** :
  最後に，得られた $Q$ と $T$ の値を使って，熱力学の根本的な原理である $\sum Q/T = 0$ が成り立つことを数学的に確認する．

この問題を通じて，熱力学の法則が，気体のような目に見える物質だけでなく，光（熱輻射）のようなエネルギーの伝播に対しても同様に適用できることが理解できる．
