# 演習問題【1-B-20】

## 解答

熱輻射を作業物質とする Carnot サイクルを考える．
問題で与えられた Stefan–Boltzmann の法則と輻射圧の状態方程式は，

```math
u=\sigma T^4,\qquad p=\frac{u}{3}=\frac{\sigma T^4}{3}
```

である．
ここで， $u$ は内部エネルギー密度， $T$ は絶対温度， $p$ は輻射圧， $\sigma>0$ は定数である．
以下では，体積 $V$ の空洞中の熱輻射を考え，その全内部エネルギーを $U$ とする．

### 1．熱力学第一法則と断熱過程

#### 1.1 熱力学第一法則

内部エネルギー密度 $u$ から，全内部エネルギー $U$ は

```math
U=Vu=\sigma VT^4
\tag{1}
```

と表される．

系が外部から受ける仕事を $d'A$ ，熱輻射が外部から吸収する熱量を $d'Q$ とする．
準静的過程では，輻射圧による仕事について

```math
d'A=-p\,dV
```

であるから，熱力学第一法則は

```math
dU=d'Q-p\,dV
\tag{2}
```

と書ける．
これを熱量 $d'Q$ について解くと，

```math
d'Q=dU+p\,dV
\tag{3}
```

を得る．

式（1）を全微分すると，

```math
dU=\sigma T^4\,dV+4\sigma VT^3\,dT
```

となる．
また， $p=\sigma T^4/3$ であるから，式（3）に代入して，

```math
\begin{aligned}
d'Q
&=\sigma T^4\,dV+4\sigma VT^3\,dT
+\frac{\sigma T^4}{3}\,dV\\
&=\frac{4}{3}\sigma T^4\,dV+4\sigma VT^3\,dT
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
d'Q=\frac{4}{3}\sigma T^4\,dV+4\sigma VT^3\,dT
}
\tag{4}
```

となる．

#### 1.2 断熱過程の関係式

断熱過程では熱の出入りがないため，

```math
d'Q=0
```

である．
これを式（4）に代入すると，

```math
\frac{4}{3}\sigma T^4\,dV+4\sigma VT^3\,dT=0
```

となる．
両辺を $\frac43\sigma VT^4$ で割ると，

```math
\frac{dV}{V}+3\frac{dT}{T}=0
```

を得る．
これを積分して，

```math
\ln V+3\ln T=\text{const.}
```

すなわち，

```math
\boxed{
VT^3=\text{const.}
}
\tag{5}
```

となる．

さらに，状態方程式 $p=\sigma T^4/3$ を用いると，

```math
pV^{4/3}
=\frac{\sigma}{3}T^4V^{4/3}
=\frac{\sigma}{3}(VT^3)^{4/3}
```

であるから，断熱過程では

```math
\boxed{
pV^{4/3}=\text{const.}
}
\tag{6}
```

も成り立つ．
これは，気体の Carnot サイクルにおける断熱関係式に相当する．

#### 1.3 熱容量

定積熱容量 $C_V$ は，体積を一定に保ったときの内部エネルギーの温度変化率で定義される．
したがって，

```math
\begin{aligned}
C_V
&=\left(\frac{\partial U}{\partial T}\right)_V\\
&=\left(\frac{\partial}{\partial T}
\sigma VT^4\right)_V
\end{aligned}
```

より，

```math
\boxed{
C_V=4\sigma VT^3
}
\tag{7}
```

となる．

一方，圧力は体積に依存せず，温度だけで決まる：

```math
p=\frac{\sigma T^4}{3}
```

したがって，圧力 $p$ を一定に保つと，温度 $T$ も一定に保たれる．
つまり，定圧過程では温度を変化させられない．
このため，定圧熱容量 $C_p$ は有限の値としては定義できず，形式的には

```math
\boxed{
C_p\to+\infty
}
```

と表現される．

### 2．Carnot サイクルの各過程

Carnot サイクルを，次の4過程からなる可逆な循環過程として考える．

- $1\to2$ ：高温 $T_1$ での等温膨張
- $2\to3$ ：断熱膨張
- $3\to4$ ：低温 $T_3$ での等温圧縮
- $4\to1$ ：断熱圧縮

ここで，高温側を $T_1$ ，低温側を $T_3$ とし， $T_1>T_3$ とする．
また， $V_2>V_1$ ， $V_3>V_4$ である．
等温過程では $T_2=T_1$ ， $T_4=T_3$ が成り立つ．

#### 2.1 過程 $1\to2$ ：等温膨張

温度 $T_1$ が一定なので，式（4）で $dT=0$ とすると，

```math
d'Q=\frac43\sigma T_1^4\,dV
```

となる．
したがって，吸収熱量は

```math
\boxed{
Q_{12}=\frac43\sigma T_1^4(V_2-V_1)
}
\tag{8}
```

である．
$V_2>V_1$ より， $Q_{12}>0$ となり，熱輻射は高温熱源から熱を吸収する．

この過程で系が外部から受ける仕事は，

```math
\begin{aligned}
A_{12}
&=-\int_{V_1}^{V_2}p\,dV\\
&=-\int_{V_1}^{V_2}\frac{\sigma T_1^4}{3}\,dV
\end{aligned}
```

であるから，

```math
\boxed{
A_{12}=-\frac{\sigma T_1^4}{3}(V_2-V_1)
}
\tag{9}
```

となる．

一方，内部エネルギーの変化は，

```math
\Delta U_{12}=U_2-U_1
=\sigma T_1^4(V_2-V_1)
```

である．
式（8），（9）を用いると，

```math
\Delta U_{12}=Q_{12}+A_{12}
```

となり，熱力学第一法則が成立することを確認できる．

#### 2.2 過程 $2\to3$ ：断熱膨張

断熱過程なので，

```math
\boxed{
Q_{23}=0
}
```

である．
また，式（5）より，

```math
\boxed{
V_2T_1^3=V_3T_3^3
}
\tag{10}
```

となる．
したがって，状態3の温度は

```math
\boxed{
T_3=T_1\left(\frac{V_2}{V_3}\right)^{1/3}
}
\tag{11}
```

である．
膨張により $V_3>V_2$ となるため， $T_3<T_1$ となる．

断熱過程では熱の出入りがないから，第一法則より，

```math
\Delta U_{23}=Q_{23}+A_{23}=A_{23}
```

となる．
よって，系が外部から受ける仕事は，

```math
\boxed{
A_{23}=U_3-U_2
=\sigma V_3T_3^4-\sigma V_2T_1^4
}
\tag{12}
```

である．
膨張によって内部エネルギーが減少するため， $A_{23}<0$ となる．
これは，熱輻射が外部に仕事をすることを表している．

#### 2.3 過程 $3\to4$ ：等温圧縮

温度 $T_3$ が一定なので，式（4）から，

```math
d'Q=\frac43\sigma T_3^4\,dV
```

となる．
したがって，吸収熱量は

```math
\boxed{
Q_{34}=\frac43\sigma T_3^4(V_4-V_3)
}
\tag{13}
```

である．
ここで $V_4<V_3$ なので， $Q_{34}<0$ となる．
つまり，熱輻射は低温熱源へ熱を放出する．

系が外部から受ける仕事は，

```math
\begin{aligned}
A_{34}
&=-\int_{V_3}^{V_4}p\,dV\\
&=-\int_{V_3}^{V_4}\frac{\sigma T_3^4}{3}\,dV
\end{aligned}
```

より，

```math
\boxed{
A_{34}=-\frac{\sigma T_3^4}{3}(V_4-V_3)
}
\tag{14}
```

となる．

また，内部エネルギーの変化は，

```math
\Delta U_{34}=U_4-U_3
=\sigma T_3^4(V_4-V_3)
```

であり，式（13），（14）から，

```math
\Delta U_{34}=Q_{34}+A_{34}
```

となる．
したがって，この過程でも熱力学第一法則が成立する．

#### 2.4 過程 $4\to1$ ：断熱圧縮

断熱過程なので，

```math
\boxed{
Q_{41}=0
}
```

である．
式（5）より，

```math
\boxed{
V_4T_3^3=V_1T_1^3
}
\tag{15}
```

が成り立つ．

断熱過程では内部エネルギーの変化が外部から受ける仕事に等しいため，

```math
\Delta U_{41}=A_{41}
```

となる．
したがって，

```math
\boxed{
A_{41}=U_1-U_4
=\sigma V_1T_1^4-\sigma V_4T_3^4
}
\tag{16}
```

である．
圧縮によって温度が $T_3$ から $T_1$ に上昇するので，内部エネルギーが増加し， $A_{41}>0$ となる．

### 3．Clausius の等式の検証

Carnot サイクルでは，等温過程 $1\to2$ と $3\to4$ のみで熱の出入りが生じる．
したがって，可逆な Carnot サイクルについて，

```math
\frac{Q_{12}}{T_1}+\frac{Q_{34}}{T_3}=0
\tag{17}
```

が成立することを確認する．

式（8），（13）より，

```math
\frac{Q_{12}}{T_1}
=\frac43\sigma T_1^3(V_2-V_1)
```

および

```math
\frac{Q_{34}}{T_3}
=\frac43\sigma T_3^3(V_4-V_3)
```

である．
これらを加えると，

```math
\begin{aligned}
\frac{Q_{12}}{T_1}+\frac{Q_{34}}{T_3}
=\frac43\sigma\bigl[
&T_1^3(V_2-V_1)\\
&+T_3^3(V_4-V_3)
\bigr]
\end{aligned}
\tag{18}
```

を得る．

ここで，2つの断熱過程から得られた式（10），（15）を用いると，

```math
V_2T_1^3=V_3T_3^3,\qquad
V_4T_3^3=V_1T_1^3
```

が成り立つ．
したがって，式（18）の角括弧内は，

```math
\begin{aligned}
&T_1^3V_2-T_1^3V_1
+T_3^3V_4-T_3^3V_3\\
&=(T_1^3V_2-T_3^3V_3)
 +(T_3^3V_4-T_1^3V_1)\\
&=0
\end{aligned}
```

となる．
よって，

```math
\boxed{
\frac{Q_{12}}{T_1}+\frac{Q_{34}}{T_3}=0
}
```

が得られ，Clausius の等式が成立することが示された．

### 4．サイクル全体の仕事と熱効率

1サイクル終了後には，熱輻射は元の状態に戻るため，内部エネルギーの全変化はゼロである．
熱力学第一法則から，

```math
0=Q_{\mathrm{net}}+A_{\mathrm{net}}
```

となる．
したがって，熱輻射が外部にする正味の仕事 $W_{\mathrm{out}}$ は，

```math
W_{\mathrm{out}}=-A_{\mathrm{net}}
=Q_{\mathrm{net}}
```

である．
サイクル中に吸収する熱量を $Q_{\mathrm{in}}=Q_{12}>0$ ，放出する熱量の大きさを $Q_{\mathrm{out}}=-Q_{34}>0$ とすると，

```math
W_{\mathrm{out}}=Q_{\mathrm{in}}-Q_{\mathrm{out}}
```

となる．

Clausius の等式から，

```math
\frac{Q_{\mathrm{in}}}{T_1}
=\frac{Q_{\mathrm{out}}}{T_3}
```

であるため，

```math
\frac{Q_{\mathrm{out}}}{Q_{\mathrm{in}}}
=\frac{T_3}{T_1}
```

を得る．
したがって，Carnot サイクルの熱効率 $\eta$ は，

```math
\begin{aligned}
\eta
&=\frac{W_{\mathrm{out}}}{Q_{\mathrm{in}}}\\
&=\frac{Q_{\mathrm{in}}-Q_{\mathrm{out}}}
{Q_{\mathrm{in}}}\\
&=1-\frac{Q_{\mathrm{out}}}{Q_{\mathrm{in}}}
\end{aligned}
```

より，

```math
\boxed{
\eta=1-\frac{T_3}{T_1}
}
```

となる．
これは，作業物質が熱輻射であっても，Carnot サイクルの熱効率が高温熱源と低温熱源の絶対温度だけで決まることを示している．
