# 例題【1-R-4】

## 解答

### 1．熱の仕事当量 $J$ と気体定数の関係

熱の仕事当量 $J$ は，熱量をカロリー（ $\mathrm{cal}$ ）で表した値と，それに対応するエネルギーをジュール（ $\mathrm{J}$ ）で表した値との換算係数である．

まず，理想気体の状態方程式から気体定数をジュール単位で求め，次に Mayer の関係式から気体定数をカロリー単位で求める．
ジュール単位で表した気体定数を $R$ ，カロリー単位で表したものを $R'$ とすると，

```math
\boxed{
J=\frac{R}{R'}
}
```

となる．

### 2．ジュール単位の気体定数 \\(R\\) を求める

標準状態では，温度 $T$ ，圧力 $p$ ，1 mol の体積 $V$ は，問題文および解答例より，

```math
\begin{aligned}
T&=0^\circ\mathrm{C}=273\,\mathrm{K},\\
p&=1\,\mathrm{atm} =1.013\times10^6\,\mathrm{dyn/cm^2},\\
V&=22.4\,\mathrm{l} =22.4\times10^3\,\mathrm{cm^3}
\end{aligned}
```

である．

理想気体 1 mol の状態方程式

```math
pV=RT
```

より，

```math
R=\frac{pV}{T}
```

となる．
したがって，

```math
\begin{aligned}
R &=\frac{1.013\times10^6 \times22.4\times10^3}{273}\\
&\simeq8.31\times10^7\, \mathrm{erg/(mol\cdot K)}
\end{aligned}
```

を得る．
ここで， $1\,\mathrm{erg}=1\,\mathrm{dyn\cdot cm}$ および

```math
1\,\mathrm{J}=10^7\,\mathrm{erg}
```

であることを用いると，

```math
\boxed{
R\simeq8.31\,\mathrm{J/(mol\cdot K)}
}
```

となる．

### 3．空気 1 mol の質量を求める

次に，空気 1 mol の質量 $m$ を求める．
密度 $\rho$ と体積 $V$ の関係は

```math
m=\rho V
```

である．
与えられた密度と，標準状態における 1 mol の体積を代入すると，

```math
\begin{aligned}
m &=0.00129\times22.4\times10^3\\
&=28.896\,\mathrm{g/mol}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
m\simeq28.9\\,\mathrm{g/mol}
}
```

を得る．

### 4．カロリー単位のモル比熱 $C_p,C_v$ を求める

問題で与えられている定圧比熱 $c_p$ は，空気 1 g あたりの比熱である．
一方，Mayer の関係式に用いる $C_p,C_v$ は，空気 1 mol あたりのモル比熱である．
両者の間には，

```math
C_p=mc_p,\qquad
C_v=mc_v
```

という関係がある．

まず，定圧モル比熱 $C_p$ は，

```math
\begin{aligned}
C_p &=mc_p\\
&=28.896\times0.238\\
&=6.877248\,\mathrm{cal/(mol\cdot deg)}
\end{aligned}
```

である．
よって，

```math
\boxed{
C_p\simeq6.88\,\mathrm{cal/(mol\cdot deg)}
}
```

となる．

次に，比熱比 $\gamma=c_p/c_v=1.41$ が与えられている．
定圧比熱と定積比熱をともに同じモル質量 $m$ 倍すれば，

```math
\frac{C_p}{C_v} =\frac{mc_p}{mc_v} =\frac{c_p}{c_v} =\gamma
```

となるため，モル比熱についても $C_p/C_v=1.41$ が成り立つ．
したがって，

```math
C_v=\frac{C_p}{\gamma}
```

より，

```math
\begin{aligned}
C_v &=\frac{6.877248}{1.41}\\
&\simeq4.8775\,\mathrm{cal/(mol\cdot deg)}
\end{aligned}
```

となる．
よって，

```math
\boxed{
C_v\simeq4.88\,\mathrm{cal/(mol\cdot deg)}
}
```

を得る．

### 5．カロリー単位の気体定数 $R'$ を求める

Mayer の関係式は，理想気体 1 mol について，

```math
C_p-C_v=R
```

である．
この式で $C_p,C_v$ をカロリー単位で表せば，右辺もカロリー単位で表す必要がある．
そこで，カロリー単位の気体定数を $R'$ と書くと，

```math
R'=C_p-C_v
```

となる．
したがって，

```math
\begin{aligned}
R' &=6.877248-4.8775\\
&\simeq2.00\,\mathrm{cal/(mol\cdot deg)}
\end{aligned}
```

を得る．
つまり，

```math
\boxed{
R'\simeq2.00\,\mathrm{cal/(mol\cdot deg)}
}
```

である．

### 6．熱の仕事当量 $J$ を求める

以上で，ジュール単位とカロリー単位の気体定数が求められた．
これらを

```math
J=\frac{R}{R'}
```

に代入すると，

```math
\begin{aligned}
J &=\frac{8.31\,\mathrm{J/(mol\cdot K)}} {2.00\,\mathrm{cal/(mol\cdot deg)}}\\
&\simeq4.16\,\mathrm{J/cal}
\end{aligned}
```

となる．
ここでは，温度差について $1\,\mathrm{K}=1\,\mathrm{deg}$ であるため，温度の単位は換算時に相殺される．
また，モルあたりという単位も分子と分母で相殺される．

したがって，求める熱の仕事当量は，

```math
\boxed{
J\simeq4.16\\,\mathrm{J/cal}
}
```

である．

## 3．解説

この問題のポイントは，気体定数を異なるエネルギー単位で求め，その比から熱と仕事の換算係数を計算することにある．

まず，理想気体の状態方程式 $pV=RT$ を用いると，ジュール単位の気体定数 $R$ が求められる．
一方，定圧比熱と定積比熱は最初に質量あたりの値として与えられているため，空気 1 mol の質量を密度から求め，モル比熱に換算する必要がある．
その後，Mayer の関係式 $C_p-C_v=R'$ によって，カロリー単位の気体定数 $R'$ が求められる．

ここで，定圧比熱 $C_p$ が定積比熱 $C_v$ より大きい理由は，定圧加熱では気体が膨張して外部に仕事をするためである．
定積加熱では体積が変化せず，そのような膨張仕事がない．
この差が Mayer の関係式に現れている．

最後に $R/R'$ を計算することで，熱量と仕事を換算する係数が得られる．
なお，計算には問題文で与えられた近似値を用いているため，丸め方によって末尾にわずかな違いが生じるが，求める値は

```math
\boxed{
J\simeq4.16\\,\mathrm{J/cal}
}
```

である．
