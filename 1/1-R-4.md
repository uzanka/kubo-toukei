# 例題【1-R-4】

## 解答

### 1．熱の仕事当量と気体定数の関係

熱の仕事当量 $\mathcal J$ は，熱量をカロリーで表した値を，それに相当するエネルギーのジュール単位の値に換算する係数である．
本解答では，ジュールの単位記号 $\mathrm J$ と区別するため，熱の仕事当量を $\mathcal J$ と表す．

理想気体のモル気体定数を，ジュール単位では $R$ ，カロリー単位では $R'$ とする．
マイヤーの関係式より，

```math
C_p-C_v=R
```

が成り立つ．
ただし，この式では比熱と気体定数を同じエネルギー単位で表す必要がある．

したがって，カロリー単位でマイヤーの関係式を表すと，

```math
C_p-C_v=R'
```

となる．

よって，熱の仕事当量は，

```math
\boxed{\mathcal J=\frac{R}{R'}}
```

で求められる．

### 2．ジュール単位のモル気体定数 $R$ を求める

標準状態では，

```math
T=273\,\mathrm K,
```

```math
p=1\,\mathrm{atm}
=1.013\times10^6\,\mathrm{dyn/cm^2}
```

である．

また，問題で与えられた $1\,\mathrm{mol}$ の体積は，

```math
V_m=22.4\,\mathrm L
=22.4\times10^3\,\mathrm{cm^3/mol}
```

である．
ここで， $V_m$ はモル体積を表す．

理想気体の状態方程式

```math
pV=nRT
```

を物質量 $n$ で割ると，

```math
pV_m=RT
```

となる．
したがって，

```math
R=\frac{pV_m}{T}
```

である．

与えられた値を代入すると，

```math
\begin{aligned}
R
&=\frac{1.013\times10^6
\times22.4\times10^3}{273}\\
&\simeq8.31\times10^7\,
\mathrm{erg/(mol\cdot K)}.
\end{aligned}
```

ここで，

```math
1\,\mathrm{erg}=10^{-7}\,\mathrm J
```

であるから，

```math
\boxed{
R\simeq8.31\,\mathrm{J/(mol\cdot K)}
}
```

を得る．

### 3．空気のモル質量を求める

空気の密度を $\rho$ ，モル体積を $V_m$ ，モル質量を $M$ とする．

密度は単位体積当たりの質量であるため，モル質量は，

```math
M=\rho V_m
```

で求められる．

与えられた値を代入すると，

```math
\begin{aligned}
M
&=0.00129\,\mathrm{g/cm^3}
\times22.4\times10^3\,\mathrm{cm^3/mol}\\
&=28.896\,\mathrm{g/mol}.
\end{aligned}
```

したがって，

```math
\boxed{M\simeq28.9\,\mathrm{g/mol}}
```

となる．

### 4．カロリー単位のモル比熱 $C_p,C_v$ を求める

問題で与えられている定圧比熱 $c_p$ は，単位質量当たりの比熱であり，

```math
c_p=0.238\,\mathrm{cal/(g\cdot K)}
```

である．

一方，マイヤーの関係式に用いる $C_p,C_v$ は，1 mol 当たりのモル比熱である．
したがって，モル質量 $M$ を用いて，

```math
C_p=Mc_p,\qquad C_v=Mc_v
```

と表される．

まず，定圧モル比熱 $C_p$ は，

```math
\begin{aligned}
C_p
&=Mc_p\\
&=28.896\,\mathrm{g/mol}
\times0.238\,\mathrm{cal/(g\cdot K)}\\
&=6.877248\,\mathrm{cal/(mol\cdot K)}.
\end{aligned}
```

よって，

```math
\boxed{
C_p\simeq6.88\,\mathrm{cal/(mol\cdot K)}
}
```

となる．

次に，比熱比は，

```math
\gamma=\frac{c_p}{c_v}=1.41
```

である．
$C_p=Mc_p$ ， $C_v=Mc_v$ より，

```math
\frac{C_p}{C_v}
=\frac{Mc_p}{Mc_v}
=\frac{c_p}{c_v}
=\gamma
```

が成り立つ．

したがって，

```math
C_v=\frac{C_p}{\gamma}
```

であるから，

```math
\begin{aligned}
C_v
&=\frac{6.877248}{1.41}\\
&\simeq4.8775\,\mathrm{cal/(mol\cdot K)}.
\end{aligned}
```

よって，

```math
\boxed{
C_v\simeq4.88\,\mathrm{cal/(mol\cdot K)}
}
```

を得る．

### 5．カロリー単位のモル気体定数 $R'$ を求める

理想気体のマイヤーの関係式は，

```math
C_p-C_v=R'
```

と表される．
ここでは，モル比熱と気体定数をともにカロリー単位で表している．

したがって，

```math
\begin{aligned}
R'
&=C_p-C_v\\
&=6.877248-\frac{6.877248}{1.41}\\
&\simeq1.99977\,\mathrm{cal/(mol\cdot K)}.
\end{aligned}
```

よって，

```math
\boxed{
R'\simeq2.00\,\mathrm{cal/(mol\cdot K)}
}
```

となる．

### 6．熱の仕事当量を求める

ジュール単位とカロリー単位で求めたモル気体定数は，

```math
R\simeq8.31\,\mathrm{J/(mol\cdot K)}
```

および

```math
R'\simeq2.00\,\mathrm{cal/(mol\cdot K)}
```

である．

熱の仕事当量は，

```math
\mathcal J=\frac{R}{R'}
```

であるから，

```math
\begin{aligned}
\mathcal J
&=\frac{8.31\,\mathrm{J/(mol\cdot K)}}
{1.99977\,\mathrm{cal/(mol\cdot K)}}\\
&\simeq4.16\,\mathrm{J/cal}.
\end{aligned}
```

分子と分母の $\mathrm{mol}$ および温度差の単位 $\mathrm K$ は相殺されるため，結果の単位は $\mathrm{J/cal}$ となる．

したがって，求める熱の仕事当量は，

```math
\boxed{\mathcal J\simeq4.16\,\mathrm{J/cal}}
```

である．

## 解説

この問題の要点は，理想気体の状態方程式からジュール単位のモル気体定数を求め，マイヤーの関係式からカロリー単位のモル気体定数を求めることである．

密度とモル体積からモル質量 $M$ を求めれば，質量基準で与えられた比熱をモル基準の比熱に変換できる．
ここで，質量 $m$ とモル質量 $M$ ，体積 $V$ とモル体積 $V_m$ を区別することで，すべての計算において単位が整合する．

得られた二つの気体定数の比を取ると，熱の仕事当量が求められる．

以上より，

```math
\boxed{\mathcal J\simeq4.16\,\mathrm{J/cal}}
```

となる．
