# 例題【1-R-4】

## 解答

### 1. 熱の仕事当量 $J$ の定義

熱の仕事当量 $J$ とは，熱の単位であるカロリー ($\text{cal}$) と，仕事の単位であるジュール ( $\text{J}$ ) の間の換算係数のことである．
気体定数 $R$ をジュール単位 ( $\text{J/(mol}\cdot\text{K)}$ ) で表したものと，カロリー単位 ( $\text{cal/(mol}\cdot\text{K)}$ ) で表したもの $R'$ とすると，以下の関係が成り立つ．

$$J = \frac{R}{R'}$$

したがって，まず $R$ と $R'$ をそれぞれ求めていく．

### 2. 気体定数 $R$ の算出 (SI単位系)

理想気体の状態方程式 $pV = RT$ より，気体定数 $R$ は次のように求められる．

$$R = \frac{pV}{T}$$

問題文および解答例に示された標準状態の値を代入する．
- 圧力 $p = 1\text{ atm} = 1.013 \times 10^6\text{ dyn/cm}^2$
- 体積 $V = 22.4\text{ l} = 22.4 \times 10^3\text{ cm}^3$
- 温度 $T = 0\text{ }^\circ\text{C} = 273\text{ K}$

これらを計算すると，

$$R = \frac{(1.013 \times 10^6\text{ dyn/cm}^2) \times (22.4 \times 10^3\text{ cm}^3)}{273\text{ K}} = 8.32 \times 10^7\text{ erg/(mol}\cdot\text{K)}$$

ここで，エネルギーの単位の換算 ( $1\text{ J} = 10^7\text{ erg}$ ) を用いると，

$$R = 8.32\text{ J/(mol}\cdot\text{K)}$$

となる．

### 3. 空気のモル質量 $m$ の算出

次に，空気 $1\text{ mol}$ あたりの質量 $m$ を求める．
密度 $\rho$ と体積 $V$ の関係 ($m = \rho V$) を用いる．
- 密度 $\rho = 0.00129\text{ g/cm}^3$
- 体積 $V = 22.4 \times 10^3\text{ cm}^3$

$$m = 0.00129\text{ g/cm}^3 \times 22.4 \times 10^3\text{ cm}^3 = 28.9\text{ g/mol}$$

### 4. モル比熱の算出

問題で与えられているのは「質量あたりの比熱」であるため，これを「モルあたりの比熱（モル比熱）」に変換する必要がある．

#### 定圧モル比熱 $C_p$

定圧比熱 $c_p = 0.238\text{ cal/(g}\cdot\text{deg)}$ を用いて，

$$C_p = m \times c_p = 28.9\text{ g/mol} \times 0.238\text{ cal/(g}\cdot\text{deg)} = 6.88\text{ cal/(mol}\cdot\text{deg)}$$

#### 定積モル比熱 $C_v$

定圧比熱と定積比熱の比 $\gamma = C_p/C_v = 1.41$ を用いて，

$$C_v = \frac{C_p}{\gamma} = \frac{6.88\text{ cal/(mol}\cdot\text{deg)}}{1.41} = 4.88\text{ cal/(mol}\cdot\text{deg)}$$

### 5. カロリー単位の気体定数 $R'$ の算出

マイヤーの関係式 (Mayer's relation) $C_p - C_v = R$ を用いる．
カロリー単位で計算するため，左辺の $C_p, C_v$ は $\text{cal/(mol}\cdot\text{deg)}$ 単位のものである．

$$R' = C_p - C_v = 6.88 - 4.88 = 2.00\text{ cal/(mol}\cdot\text{deg)}$$

### 6. 最終的な $J$ の計算

最後に，最初に定義した式に $R$ と $R'$ を代入する．

$$J = \frac{R}{R'} = \frac{8.32\text{ J/(mol}\cdot\text{K)}}{2.00\text{ cal/(mol}\cdot\text{K)}} = 4.16\text{ J/cal}$$

したがって，熱の仕事当量 $J$ は $4.16\text{ J/cal}$ である．

## 解説

### 用語と概念の整理

#### 1. 熱の仕事当量 ( $J$ )

熱の量 ( $\text{cal}$ ) と，それによって外部になされる仕事の量 ( $\text{J}$ ) の比である．
例えば $J=4.16\text{ J/cal}$ なら，「 $1\text{ cal}$ の熱を与えると， $4 ．16\text{ J}$ の仕事ができる」という意味になる．

#### 2. 比熱とモル比熱の違い
- **比熱 ( $c$ )** : 物質 $1\text{ g}$ の温度を $1\text{ deg}$ 上げるのに必要な熱量．
- **モル比熱 ($C$)** : 物質 $1\text{ mol}$ の温度を $1\text{ deg}$ 上げるのに必要な熱量．
関係式は $C = m \cdot c$ （ $m$ はモル質量）となる．

#### 3. マイヤーの関係式 ( $C_p - C_v = R$ )

定圧比熱 $C_p$ は，圧力を一定に保ちながら加熱するため，体積膨張に伴う仕事も考慮する必要がある．
一方，定積比熱 $C_v$ は体積が一定なので仕事が発生しない．
この「仕事の差」が気体定数 $R$ に一致するというのがこの式の本質である．

#### 4. 単位の注意点

この問題では，単位系をまたぐ計算（ $\text{J}$ と $\text{cal}$ ，$\text{erg}$ と $\text{J}$ ，$\text{dyn}\cdot\text{cm}$ と $\text{erg}$）が頻出する．
計算過程で単位が正しく変換されているかを確認することが非常に重要である．
