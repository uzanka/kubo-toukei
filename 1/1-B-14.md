# 演習問題【1-B-14】

## 解答

### 1．磁性体が永久磁石に近づく過程での仕事 $A_1$

永久磁石の軸を $x$ 軸とし，その正の向きを永久磁石がつくる磁場 $H(x)$ の向きとする．
磁場は無限遠 $x=-\infty$ でゼロとなり，磁石に近づくにつれて単調に増大するものとする．

磁性体試料を $x=-\infty$ から $x=x_1$ までゆっくりと移動させ，最終的に磁気モーメント $m_1$ を生じさせる．
移動途中の位置 $x$ における磁気モーメントを $m(x)$ とする．
試料は十分に小さく，磁気モーメントは磁場と平行であるとみなす．
また，反磁場などの影響を無視し，試料が永久磁石から受ける力を

```math
K(x)=m(x)\frac{dH(x)}{dx}
\tag{1}
```

と表す．
ここで，力を求める際の空間微分は，その位置での磁気モーメントを固定して計算する．
移動に伴う磁気モーメントの変化 $m(x)$ は，後の積分で考慮する．

磁場の強さは磁石に近づくにつれて増大するので，試料には磁石に近づく向きの力がはたらく．
この力に逆らいながら試料を準静的に移動させるために，外界は磁石から受ける力と反対向きの力を加える．
したがって，外界が試料と永久磁石からなる系にする仕事を $A_1$ とすると，

```math
\begin{aligned}
A_1
&=-\int_{-\infty}^{x_1}K(x)\,dx\\
&=-\int_{-\infty}^{x_1}
m(x)\frac{dH(x)}{dx}\,dx
\end{aligned}
```

となる．
ここで，

```math
dH=\frac{dH(x)}{dx}\,dx
```

であるから，積分変数を位置 $x$ から磁場 $H$ に変えると，

```math
A_1=-\int_0^{H_1}m\,dH
\tag{2}
```

を得る．
ただし， $H_1=H(x_1)$ とおいた．

この式は，磁性体を磁石に近づける過程において，外界がした仕事を表している．
磁石からの引力に沿って試料が移動するため，この仕事は負になる場合がある．
したがって， $A_1$ だけでは，磁化そのものに必要な仕事を表すことはできない．

### 2．磁化を保ったまま磁場の外へ戻す仮想過程

次に，磁気モーメント $m_1$ を生じた試料を，その磁化を一定に保ったまま， $x=x_1$ から再び無限遠 $x=-\infty$ まで戻す仮想的な過程を考える．
この過程では，磁気モーメントを $m_1$ に固定するため，位置 $x$ で試料が永久磁石から受ける力 $K'(x)$ は，

```math
K'(x)=m_1\frac{dH(x)}{dx}
\tag{3}
```

と表される．

試料を磁石から遠ざけるときは，磁石の引力に逆らって移動させなければならない．
そのため，外界が試料にする仕事 $A_2$ は正となり，

```math
\begin{aligned}
A_2
&=-\int_{x_1}^{-\infty}K'(x)\,dx\\
&=-m_1\int_{x_1}^{-\infty}
\frac{dH(x)}{dx}\,dx\\
&=m_1\int_{-\infty}^{x_1}
\frac{dH(x)}{dx}\,dx
\end{aligned}
```

となる．
これを積分すれば，

```math
\begin{aligned}
A_2
&=m_1[H(x)]_{-\infty}^{x_1}\\
&=m_1\{H(x_1)-H(-\infty)\}
\end{aligned}
```

を得る．
無限遠では $H(-\infty)=0$ であるから，

```math
\boxed{
A_2=m_1H_1
}
\tag{4}
```

となる．

ここで， $A_2$ は外界が回収する仕事ではなく，磁化された試料を磁場から引き離すために外界が加える仕事である．
この仮想過程を導入するのは，磁場中に試料が置かれることによる相互作用エネルギーの寄与を取り除き，磁気モーメントを生じさせるために必要な仕事を取り出すためである．

### 3．磁化に必要な正味の仕事 $A$ の導出

磁化に必要な正味の仕事 $A$ は，試料を磁場に近づける過程の仕事 $A_1$ と，磁化を一定に保って磁場の外へ戻す仮想過程の仕事 $A_2$ とを合わせたものとして，

```math
A=A_1+A_2
```

と表される．
式（2），（4）を代入すると，

```math
A=-\int_0^{H_1}m\,dH+m_1H_1
\tag{5}
```

となる．

ここで，部分積分の公式

```math
\int u\,dv=uv-\int v\,du
```

を用いる．
式（5）の積分に対して $u=m$ ， $dv=dH$ とすると，

```math
\int_0^{H_1}m\,dH
=[mH]_0^{H_1}-\int_0^{m_1}H\,dm
```

となる．
無限遠では磁場も磁気モーメントもゼロであり，終点では $m=m_1$ ， $H=H_1$ であるから，

```math
\int_0^{H_1}m\,dH
=m_1H_1-\int_0^{m_1}H\,dm
\tag{6}
```

を得る．

式（6）を式（5）に代入すると，

```math
\begin{aligned}
A
&=-\left(m_1H_1-\int_0^{m_1}H\,dm\right)
+m_1H_1\\
&=-m_1H_1+\int_0^{m_1}H\,dm+m_1H_1\\
&=\int_0^{m_1}H\,dm
\end{aligned}
```

となる．
したがって，磁気モーメントを $0$ から $m_1$ まで生じさせるための磁化の仕事は，

```math
\boxed{
A=\int_0^{m_1}H\,dm
}
```

で与えられることが示された．

## 解説

本問の要点は，試料を磁場中へ移動させる際の仕事と，磁化を一定に保ったまま磁場の外へ戻す仮想過程の仕事を組み合わせて，磁化そのものに必要な仕事を求めることである．

磁気モーメントをもつ試料は，磁場の強さが位置によって変化すると力を受けるため，試料を移動させる仕事には，磁気モーメントを生じさせるための寄与だけでなく，磁石との相互作用エネルギーの変化も含まれる．
そこで，磁化を固定して磁場の外へ戻す仮想過程を考えることにより，この相互作用エネルギーの寄与を取り除く．

部分積分を用いると，磁場 $H$ の変化に関する積分が，磁気モーメント $m$ の変化に関する積分へと変換され，最終的に

```math
A=\int_0^{m_1}H\,dm
```

が得られる．
この式は，磁気モーメントを微小量 $dm$ だけ増加させるために必要な仕事が，そのときの磁場 $H$ と磁気モーメントの増分 $dm$ の積 $H\,dm$ で表されることを意味している．
