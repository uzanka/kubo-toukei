# 演習問題【1-A-9】

## 解答

カルノーサイクルにおける各過程の熱量を求め，断熱過程における温度と体積の関係を利用して，クラウジウスの等式

```math
\frac{Q_1}{T_1}+\frac{Q_2}{T_2}=0
```

が成り立つことを示す．
ここで，気体が吸収する熱量を正，放出する熱量を負とする．

### 1．各過程における熱量の計算

理想気体では，内部エネルギー $U$ は温度 $T$ のみの関数である．
したがって，温度が一定の等温過程では，内部エネルギーの変化はゼロとなる．

#### （i）状態 $1\to2$ ：温度 $T_1$ での等温膨張

等温過程では，

```math
\Delta U_{1\to2}=0
```

である．
熱力学第1法則より，気体が吸収する熱量 $Q_1$ は，気体が外部になす仕事 $W_{1\to2}$ に等しい．
よって，

```math
Q_1=W_{1\to2}
=\int_{V_1}^{V_2}p\,dV
```

となる．
理想気体の状態方程式 $pV=nRT_1$ より，

```math
p=\frac{nRT_1}{V}
```

であるから，

```math
\begin{aligned}
Q_1
&=\int_{V_1}^{V_2}\frac{nRT_1}{V}\,dV\\
&=nRT_1\ln\frac{V_2}{V_1}
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
\frac{Q_1}{T_1}=nR\ln\frac{V_2}{V_1}
}
\tag{1}
```

である．
ここで， $\ln$ は自然対数を表す．
$V_2>V_1$ であるため， $Q_1>0$ となり，気体は高温熱源から熱を吸収する．

#### （ii）状態 $2\to3$ ：断熱膨張

断熱過程では，気体と外界との間に熱の出入りがないため，

```math
\boxed{
Q_{2\to3}=0
}
```

である．

#### （iii）状態 $3\to4$ ：温度 $T_2$ での等温圧縮

この過程も等温過程であるから，

```math
\Delta U_{3\to4}=0
```

となる．
したがって，気体が吸収する熱量 $Q_2$ は，気体が外部になす仕事 $W_{3\to4}$ に等しい．
よって，

```math
Q_2=\int_{V_3}^{V_4}p\,dV
```

である．
状態方程式 $pV=nRT_2$ より，

```math
\begin{aligned}
Q_2
&=\int_{V_3}^{V_4}\frac{nRT_2}{V}\,dV\\
&=nRT_2\ln\frac{V_4}{V_3}
\end{aligned}
```

となる．
したがって，

```math
\boxed{
\frac{Q_2}{T_2}=nR\ln\frac{V_4}{V_3}
}
\tag{2}
```

である．
ここでは $V_4<V_3$ なので， $Q_2<0$ となる．
つまり，気体は低温熱源に熱を放出する．

#### （iv）状態 $4\to1$ ：断熱圧縮

この過程も断熱過程であるため，熱の出入りはなく，

```math
\boxed{
Q_{4\to1}=0
}
```

である．

### 2．断熱過程における温度と体積の関係

断熱過程では，理想気体に対してポアソンの関係式

```math
TV^{\gamma-1}=\mathrm{const.}
```

が成り立つ．
ここで， $\gamma=C_P/C_V$ は比熱比である．

まず，断熱膨張 $2\to3$ では，状態2の温度が $T_1$ ，状態3の温度が $T_2$ であるため，

```math
T_1V_2^{\gamma-1}
=T_2V_3^{\gamma-1}
\tag{3}
```

となる．
これを整理すると，

```math
\frac{T_1}{T_2}
=\left(\frac{V_3}{V_2}\right)^{\gamma-1}
\tag{4}
```

を得る．

次に，断熱圧縮 $4\to1$ では，状態4の温度が $T_2$ ，状態1の温度が $T_1$ であるから，

```math
T_2V_4^{\gamma-1}
=T_1V_1^{\gamma-1}
\tag{5}
```

となる．これを整理すると，

```math
\frac{T_1}{T_2}
=\left(\frac{V_4}{V_1}\right)^{\gamma-1}
\tag{6}
```

を得る．

式（4）と式（6）の左辺は等しいため，

```math
\left(\frac{V_3}{V_2}\right)^{\gamma-1}
=\left(\frac{V_4}{V_1}\right)^{\gamma-1}
```

が成り立つ．
ここで， $\gamma>1$ であるから，

```math
\frac{V_3}{V_2}=\frac{V_4}{V_1}
```

となる．
これを整理すると，

```math
\boxed{
\frac{V_2}{V_1}=\frac{V_3}{V_4}
}
\tag{7}
```

が得られる．

### 3．クラウジウスの等式の証明

式（1），（2）より，

```math
\frac{Q_1}{T_1}
=nR\ln\frac{V_2}{V_1}
```

および

```math
\frac{Q_2}{T_2}
=nR\ln\frac{V_4}{V_3}
```

である．
これらを加えると，

```math
\begin{aligned}
\frac{Q_1}{T_1}+\frac{Q_2}{T_2}
&=nR\left(
\ln\frac{V_2}{V_1}
+\ln\frac{V_4}{V_3}
\right)\\
&=nR\ln\left(
\frac{V_2}{V_1}\frac{V_4}{V_3}
\right)
\end{aligned}
```

となる．
式（7）より，

```math
\frac{V_2}{V_1}\frac{V_4}{V_3}
=\frac{V_3}{V_4}\frac{V_4}{V_3}=1
```

である．
したがって，

```math
\begin{aligned}
\frac{Q_1}{T_1}+\frac{Q_2}{T_2}
&=nR\ln1\\
&=0
\end{aligned}
```

を得る．

よって，カルノーサイクルに対して，

```math
\boxed{
\frac{Q_1}{T_1}+\frac{Q_2}{T_2}=0
}
```

が成り立つことが示された．
これがクラウジウスの等式である．

## 解説

この証明の要点は，等温過程で吸収・放出される熱量を求め，断熱過程の関係式から体積比の関係を導くことである．

等温過程では理想気体の内部エネルギーが変化しないため，気体が吸収する熱量は気体が外部になす仕事に等しい．
この性質と理想気体の状態方程式を用いると，熱量を体積比の自然対数で表すことができる．

また，断熱過程ではポアソンの関係式 $TV^{\gamma-1}=\mathrm{const.}$ が成り立つ．
2つの断熱過程の関係式を組み合わせると， $\dfrac{V_2}{V_1}=\dfrac{V_3}{V_4}$ が導かれる．
この関係を等温過程の熱量の式に代入することで，2つの熱量をそれぞれの熱源温度で割った値の和がゼロになることが分かる．

なお， $Q_2$ は気体が低温熱源から吸収する熱量としてではなく，気体が受け取る熱を正とする符号規約に基づいて定義しているため，放熱する過程では負の値となる．
これにより，クラウジウスの等式を符号も含めて正しく表すことができる．
