# 演習問題【1-C-23】

## 解答

熱力学第0法則に基づき，熱平衡状態における状態変数の関係から，温度という特性量の存在を導出する．

### 1. 問題の設定と前提条件

考える体系を A, B, C とし，それぞれの状態変数を $(p_A, v_A), (p_B, v_B), (p_C, v_C)$ とする．
ここで $p$ は圧力， $v$ は比容である．

「熱平衡にある二つの体系の自変数の間には一つの関係式が成り立つ」という経験的事実を用いる．

- 体系 A と B が熱平衡にあるとき，その変数間に成り立つ関係を次のように書く：
  $$F_3(p_A, v_A, p_B, v_B) = 0 \quad \cdots (1)$$
- 同様に，体系 B と C が熱平衡にあるとき，その変数間に成り立つ関係を次のように書く：
  $$F_1(p_B, v_B, p_C, v_C) = 0 \quad \cdots (2)$$

### 2. 熱力学第0法則の適用

熱力学第0法則によれば，「AとBが平衡にあり，かつBとCが平衡にあるならば，AとCも熱平衡にある」ことが保証される．
したがって，AとCが熱平衡にあるとき，その変数間に成り立つ関係は次のように書けるはずである：

$$F_2(p_A, v_A, p_C, v_C) = 0 \quad \cdots (3)$$

### 3. 関数形式の制約の導出

式(1)と式(2)から，共通の変数を持つ体系 B の圧力 $p_B$ を解くと，それぞれ次のように表される：

$$p_B = \phi_1(p_A, v_A, v_B) \quad \cdots (4)$$

$$p_B = \phi_3(p_C, v_C, v_B)$$

これらが等しいとき，すなわち A, B, C がすべて熱平衡にあるとき，

$$\phi_1(p_A, v_A, v_B) = \phi_3(p_C, v_C, v_B) \quad \cdots (5)$$

が成り立つ．

ここで，第0法則の主張（AとCが平衡にあるなら，Bの変数 $v_B$ が何であっても関係式(3)が成立しなければならない）を考慮する．
式(5)が $v_B$ の値によらず常に成立するためには，左辺は $v_B$ に依存しない部分と，共通の $v_B$ 依存部分に分離できる必要がある．
具体的には，次のような形をとる．

$$\phi_1(p_A, v_A, v_B) = f_1(p_A, v_A) \cdot \eta(v_B) + \zeta(v_B)$$

$$\phi_3(p_C, v_C, v_B) = f_3(p_C, v_C) \cdot \eta(v_B) + \zeta(v_B)$$

ここで $\eta(v_B)$ と $\zeta(v_B)$ は $v_B$ のみの関数である．

これを式(5)に代入すると，

$$f_1(p_A, v_A) \eta(v_B) + \zeta(v_B) = f_3(p_C, v_C) \eta(v_B) + \zeta(v_B)$$

$$\implies f_1(p_A, v_A) = f_3(p_C, v_C) \quad \cdots (6)$$

が得られる．
これは $v_B$ に依存しない関係式である．

### 4. 結論：温度の定義

同様の議論を体系 B と C の関係，および A と B の関係に適用すると，すべての熱平衡の関係は次のような形に集約される：

$$f_1(p_A, v_A) = f_2(p_B, v_B) \quad \cdots (7)$$

$$f_2(p_B, v_B) = f_3(p_C, v_C) \quad \cdots (8)$$

ここで， $\theta = f_1(p_A, v_A)$ と定義すると， $\theta$ は体系の自変数 $(p, v)$ によって一意に決まる量であり，熱平衡の条件は「各体系の $\theta$ の値が等しいこと」として記述できる．
この $\theta$ こそが「温度」と呼ばれる量である．

## 解説

この問題は，私たちが当たり前のように使っている「温度」という概念が，数学的・論理的にどのように定義されるかを導出するものである．

### 熱力学第0法則の本質

熱力学第0法則は，一見すると当たり前すぎるように思えるが，物理学的には非常に重要な役割を果たしている．
それは，**「熱平衡」という概念を，数値（温度）で測れる「等価関係」として定義することを可能にする** 点である．

### 数学的なアプローチ：変数分離

この証明の鍵は，「Bが介在しているが，AとCの間の関係にはBの個別の状態（ $v_B$ ）は影響を与えないはずである」という論理的な推論にある．
数学的には，関数 $\phi(p_A, v_A, v_B)$ が $v_B$ に関してどのように振る舞うかを制限することで，共通の関数 $f(p, v)$ を抽出している．
この「変数分離」のような考え方を用いることで，多変数の複雑な関係式から，熱平衡を決定づける「核」となる量（温度）を抜き出している．

### 温度とは何か

この議論により，温度とは単なる「熱さの度合い」ではなく，「熱平衡状態にある複数の系を比較するための，状態変数から導かれる指標（関数）」であることが示された．
これにより，温度計（体系B）を使って体系Aと体系Cの温度を測るという行為が，数学的に正当化されるのである．
