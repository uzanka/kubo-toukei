# 演習問題【1-C-23】

## 解答

熱平衡状態が圧力 $p$ と比容 $v$ によって指定される体系 $A,B,C,\ldots$ を考える．
熱力学第0法則と，熱平衡にある二つの体系の状態変数の間には一つの独立な関係式が成り立つという経験的事実を用いて，各体系の状態変数 $p,v$ から定まる共通のスカラー量が存在することを示す．

以下では，粒子数や組成などの他の条件を固定し，状態方程式および熱平衡条件が十分滑らかな正則領域を考える．
また，まず局所的に温度関数を構成し，その後，大域的な温度関数を得るために必要な条件を述べる．

## 1．熱平衡条件と同値関係

体系 $A,B,C$ の状態をそれぞれ

```math
X_A=(p_A,v_A),\qquad
X_B=(p_B,v_B),\qquad
X_C=(p_C,v_C)
```

と表す．

二つの体系 $A,B$ が熱平衡にある条件は，経験的事実より，一つの独立な関係式

```math
F_{AB}(X_A,X_B)=0
\tag{1}
```

で表される．
同様に，体系 $B,C$ の熱平衡条件は

```math
F_{BC}(X_B,X_C)=0
\tag{2}
```

と表される．

熱力学第0法則によれば， $A$ と $B$ が熱平衡にあり，かつ $B$ と $C$ が熱平衡にあるなら， $A$ と $C$ も熱平衡にある．
したがって，熱平衡関係は推移的である．
また，熱平衡は自分自身との間にも成立し，相互的でもある．

よって，熱平衡関係は同値関係をなす．
すなわち，すべての状態は熱平衡関係によって同値類に分類され，同じ同値類に属する状態どうしは熱平衡にあり，異なる同値類に属する状態どうしは熱平衡にない．

ただし，この段階で示されたのは熱平衡状態の分類が可能であるということであり，同値類を実数値の滑らかな関数で表現できることまでが直ちに証明されたわけではない．

## 2．基準系を用いた共通スカラー量の構成

温度を表す共通のスカラー量を構成するため，基準となる体系 $R$ を一つ選ぶ．
基準系の状態空間も，圧力 $p_R$ と比容 $v_R$ によって表されるものとする．

任意の状態 $X$ に対し，その状態と熱平衡にある基準系 $R$ の状態全体を

```math
L_X
=
\left\{
X_R\mid X_R\text{ は }X\text{ と熱平衡にある}
\right\}
\tag{3}
```

と定義する．

ここで，熱平衡にある二つの体系の状態変数間には一つの独立な関係式が成り立つという経験的事実を用いる．
熱平衡条件が正則である領域では，状態 $X$ を固定すると，基準系の状態空間において $L_X$ は局所的に一次元の曲線となる．

次に，二つの状態 $X,Y$ が熱平衡にあるとする．
熱平衡の推移性により，基準系の状態 $X_R$ について

```math
X_R\text{ が }X\text{ と熱平衡}
\quad\Longleftrightarrow\quad
X_R\text{ が }Y\text{ と熱平衡}
```

が成立する．
したがって，

```math
X\text{ と }Y\text{ が熱平衡}
\quad\Longrightarrow\quad
L_X=L_Y
\tag{4}
```

である．

逆に， $L_X$ と $L_Y$ が共通の状態 $X_R$ を含むなら， $X$ と $X_R$ は熱平衡にあり， $Y$ と $X_R$ も熱平衡にある．
熱力学第0法則と熱平衡の相互性から， $X$ と $Y$ も熱平衡にある．
したがって，

```math
L_X\cap L_Y\ne\varnothing
\quad\Longrightarrow\quad
X\text{ と }Y\text{ が熱平衡}
\tag{5}
```

となる．

つまり，異なる熱平衡のまとまりに対応する曲線は交差せず，同じ熱平衡のまとまりに属する状態には同じ曲線が対応する．

## 3．局所的な温度関数の構成

熱平衡曲線が正則に並ぶ状態領域を考え，その領域内で各曲線と局所的にただ一度交わる横断曲線 $\Gamma$ を選ぶ．
横断曲線上の状態を，実数パラメータ $\lambda$ によって

```math
X_R(\lambda)
=
\bigl(p_R(\lambda),v_R(\lambda)\bigr)
\tag{6}
```

と表す．

このとき，任意の状態 $X_A=(p_A,v_A)$ に対応する熱平衡曲線 $L_{X_A}$ は， $\Gamma$ とただ一つの点で交わる．
その交点のパラメータを $\lambda_A$ と定め，

```math
\boxed{
\theta_A=f_A(p_A,v_A):=\lambda_A
}
\tag{7}
```

と定義する．

同様に，体系 $B,C,\ldots$ についても，

```math
\theta_B=f_B(p_B,v_B),\qquad
\theta_C=f_C(p_C,v_C)
\tag{8}
```

と定義する．

この構成では，すべての体系に同じ基準系 $R$ と同じ横断曲線 $\Gamma$ を用いるので，各体系で独立に導入した量を後から無理に比較するのではなく，初めから共通のパラメータ $\lambda$ によって尺度をそろえている．

ここで，二つの状態 $X_A,X_B$ が熱平衡にあるなら，式 (4) より対応する熱平衡曲線は同一である．
したがって，両者が横断曲線 $\Gamma$ と交わる点も同一となるので，

```math
\theta_A=\theta_B
\tag{9}
```

が成立する．

反対に， $\theta_A=\theta_B$ であれば，両者の熱平衡曲線は $\Gamma$ 上の同じ状態を共有する．
式 (5) より， $X_A$ と $X_B$ は熱平衡にある．

よって，正則な領域において，

```math
\boxed{
X_A\text{ と }X_B\text{ が熱平衡}
\quad\Longleftrightarrow\quad
f_A(p_A,v_A)=f_B(p_B,v_B)
}
\tag{10}
```

が成立する．

したがって，各体系の状態変数 $p,v$ から計算されるスカラー量を等置することによって，熱平衡の条件を表現できる．

## 4．温度の定義と結論

以上で構成した共通のスカラー量 $\theta$ を，温度を表す状態量として採用できる．
すなわち，

```math
\boxed{\theta_A=f_A(p_A,v_A)}
```

と定義すれば，二つの体系 $A,B$ が熱平衡にあるための条件は，

```math
\boxed{\theta_A=\theta_B}
```

と表される．

この温度の数値尺度は一意ではない．
既に温度関数 $\theta$ が存在する場合，すべての体系に共通する一対一の関数 $g$ によって

```math
\theta'=g(\theta)
```

と変換しても，

```math
\theta'_A=\theta'_B
\quad\Longleftrightarrow\quad
\theta_A=\theta_B
```

が成立する。
したがって，熱平衡条件だけでは温度の数値尺度は決まらず，摂氏温度や絶対温度などの具体的な尺度を定めるには，別途，尺度の選択が必要である．

なお，ここでの構成は，熱平衡曲線が正則であり，横断曲線によって局所的に一意なラベルを割り当てられる領域に対するものである．
任意の状態領域全体で単一の滑らかな温度関数を定義するには，局所的に構成した関数どうしを整合的に接続できることなど，追加の大域的条件が必要となる．

したがって，熱力学第0法則と熱平衡条件の正則性のもとで，少なくとも局所的には，熱平衡を共通のスカラー量の等しさで表す温度関数が存在することが示された．
大域的な温度関数の存在は，さらに大域的な整合性が成立する場合に得られる．
