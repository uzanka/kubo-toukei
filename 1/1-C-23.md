# 演習問題【1-C-23】

## 解答

熱平衡状態が圧力 $p$ と比容 $v$ によって指定される体系 $A,B,C,\ldots$ を考える．
熱力学第0法則と，熱平衡にある二つの体系の状態変数の間には一つの独立な関係式が成り立つという経験的事実を用いて，各体系の温度を状態変数 $p,v$ の関数として表せることを示す．

### 1．熱平衡状態を関係式で表す

体系 $A,B,C$ の状態変数をそれぞれ

```math
(p_A,v_A),\qquad(p_B,v_B),\qquad(p_C,v_C)
```

とする．
ここで， $p$ は圧力， $v$ は比容である．

まず，体系 $A$ と $B$ が熱平衡にあるとき，それらの状態変数の間には一つの独立な関係式が成り立つという経験的事実から，

```math
F_3(p_A,v_A,p_B,v_B)=0
\tag{1}
```

と表せる．
同様に，体系 $B$ と $C$ が熱平衡にある条件は，

```math
F_1(p_B,v_B,p_C,v_C)=0
\tag{2}
```

と表される．

さらに，熱力学第0法則によれば， $A$ と $B$ が熱平衡にあり，かつ $B$ と $C$ が熱平衡にあれば， $A$ と $C$ も熱平衡にある．
したがって， $A$ と $C$ の間にも，

```math
F_2(p_A,v_A,p_C,v_C)=0
\tag{3}
```

という関係式が存在する．

ここで重要なのは，式（3）が体系 $A$ と $C$ の状態変数だけで決まり，中間に置いた体系 $B$ の状態変数には依存しないことである．

### 2．熱平衡条件が状態空間に描く曲線

熱平衡にある二つの体系の状態変数間には一つの独立な関係式が成り立つので，体系 $A$ の状態 $(p_A,v_A)$ を固定すると，体系 $B$ の熱平衡状態 $(p_B,v_B)$ は，その状態空間において一般に一本の曲線を描く．

例えば，式（1）が局所的に $p_B$ について解ける場合には，

```math
p_B=\phi_{AB}(p_A,v_A,v_B)
\tag{4}
```

と書ける．
これは， $A$ の状態を固定すると， $B$ が $A$ と熱平衡になるための圧力 $p_B$ が，比容 $v_B$ の関数として決まることを表している．

同様に，体系 $B$ と $C$ の熱平衡条件も，適切な条件のもとで，

```math
p_B=\phi_{BC}(p_C,v_C,v_B)
\tag{5}
```

と表せる．
両式が同時に成立するとき，体系 $A,B,C$ は互いに熱平衡にある．
熱力学第0法則により，そのときの $A$ と $C$ の熱平衡の有無は，体系 $B$ の個別の状態によって変わってはならない．

このように，熱平衡を表す曲線は，単なる状態変数間の関係式ではなく，熱力学第0法則によって互いに整合するように定まる．

### 3．熱平衡を表す一つの状態量の導入

次に，熱力学第0法則の意味を考える．

ある状態 $A$ と熱平衡にあるすべての状態を集めると，それらは一つの熱平衡のまとまりをつくる．
このまとまりに属する状態は，互いに熱平衡にある．
また，二つの熱平衡のまとまりが状態を一つでも共有すれば，第0法則によってその二つのまとまりは同一になる．
したがって，異なる熱平衡のまとまりは互いに区別できる．

さらに，熱平衡条件が一つの独立な関係式で与えられるため，各体系の二次元状態空間 $(p,v)$ において，熱平衡のまとまりは一般に一次元の曲線として表される．
状態変数と熱平衡条件が十分滑らかであると仮定すれば，これらの曲線を局所的に一つのスカラー量によって区別できる．

そこで，熱平衡のまとまりを区別する共通の指標を $\theta$ とし，各体系について，

```math
\theta_A=f_A(p_A,v_A)
\tag{6}
```

```math
\theta_B=f_B(p_B,v_B)
\tag{7}
```

```math
\theta_C=f_C(p_C,v_C)
\tag{8}
```

と定義する．
ここで，関数 $f_A,f_B,f_C$ は体系ごとに異なってよいが，それぞれの値は同じ熱平衡のまとまりに対して同じ指標 $\theta$ を与えるように尺度をそろえる．

この定義から，体系 $A$ と $B$ が熱平衡にあるための条件は，

```math
\boxed{
f_A(p_A,v_A)=f_B(p_B,v_B)
}
\tag{9}
```

と表される．
同様に，体系 $B$ と $C$ が熱平衡にある条件は，

```math
\boxed{
f_B(p_B,v_B)=f_C(p_C,v_C)
}
\tag{10}
```

となる．

つまり，各体系の二つの状態変数 $p,v$ から計算される一つの量の値を比較するだけで，熱平衡にあるかどうかを判定できる．

### 4．温度の定義と結論

以上より，各体系には，その圧力と比容によって決まる関数

```math
\boxed{
\theta_A=f_A(p_A,v_A)
}
```

が存在し，二つの体系 $A,B$ が熱平衡にある条件を，

```math
\boxed{
\theta_A=\theta_B
}
```

と表せる．
このように，熱平衡を判定するための共通の状態量が存在する．
これを温度と呼ぶ．

したがって，

```math
\boxed{
\text{体系 }A,B\text{ が熱平衡}
\iff
f_A(p_A,v_A)=f_B(p_B,v_B)
}
```

が成立し，温度の存在が示された．

なお，この議論で示されるのは，熱平衡を共通のスカラー量の等しさで表せることである．
その数値尺度は一意ではなく，すべての体系に共通する一対一の関数 $g$ を用いて $\theta'=g(\theta)$ と変換しても，熱平衡条件は変わらない．
摂氏温度や絶対温度などの具体的な温度尺度を定めるには，さらに尺度の選び方を指定する必要がある．
