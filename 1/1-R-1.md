# 例題【1-R-1】

## 解答

磁性体をコイルの中に入れ，電流を流して磁場を作り，磁性体を磁化する過程を考える．
磁化による体積変形は無視できるため，磁性体の体積 $V$ は一定とする．

求めるのは，磁化をゼロから最終値 $\boldsymbol M$ まで変化させるために必要な電源の仕事のうち，磁化に関係する部分を単位体積当たりで表したものである．

### 1．コイルの電流と磁場の関係

十分に細長い棒状の磁性体に，単位長さ当たり $n$ 回巻きのコイルを巻いた場合を考える．
コイルに流れる電流を $J$ とする．

アンペールの回路定理によれば，コイルの電流が作る磁場 $\boldsymbol H_J$ の大きさは，

```math
H_J=\frac{4\pi nJ}{c}
\tag{1}
```

である．
ここで， $c$ は光速である．

磁性体内部の磁場 $\boldsymbol H$ は，コイルの電流による磁場と磁性体の磁化による反磁場の和である．
十分に細長い棒状磁性体では反磁場を無視できるので，

```math
H\simeq H_J=\frac{4\pi nJ}{c}
```

と近似できる．
したがって，

```math
\boxed{
J=\frac{cH}{4\pi n}
}
\tag{2}
```

を得る．
この関係を使って，電源がする仕事を磁場の変化で表す．

### 2．コイルを貫く磁束と電源の仕事

磁性体の長さを $l$ ，断面積を $S$ とすると，体積は

```math
V=Sl
```

である．
コイルの全巻数は $nl$ であるから，磁束密度を $B$ とすると，コイル全体の磁束鎖交数 $\phi$ は，

```math
\phi=(nl)SB=VnB
\tag{3}
```

となる．
ここで，磁束鎖交数とは，各巻線を貫く磁束を全巻数について合計したものである．

ガウス単位系における Faraday の電磁誘導の法則より，コイルに生じる誘導起電力は，

```math
\mathcal E_{\mathrm{ind}}
=-\frac{1}{c}\frac{d\phi}{dt}
\tag{4}
```

と表される．
電源はこの誘導起電力に逆らって電流を流す必要があるため，電源の起電力は，この変化に対して

```math
\mathcal E_{\mathrm{src}}
=\frac{1}{c}\frac{d\phi}{dt}
```

となる．
したがって，時間 $dt$ に電流 $J$ が流れる間に電源がする仕事 $dW$ は，

```math
dW=\mathcal E_{\mathrm{src}}J\,dt
=\frac{J}{c}\,d\phi
\tag{5}
```

である．
この式は符号付きの仕事を表すため，磁束が減少するときには電源にエネルギーが戻る場合も扱える．

式（3）より $d\phi=Vn\,dB$ であるから，式（5）に式（2）を代入すると，

```math
\begin{aligned}
dW
&=\frac{J}{c}Vn\,dB\\
&=\frac{Vn}{c}\frac{cH}{4\pi n}\,dB\\
&=\frac{VH}{4\pi}\,dB
\end{aligned}
```

となる．
ベクトル量の変化も考慮すれば，この関係は

```math
\boxed{
dW=\frac{V}{4\pi}
\boldsymbol H\cdot d\boldsymbol B
}
\tag{6}
```

と一般化できる．

### 3．磁場を形成する仕事と磁化の仕事を分離する

ガウス単位系では，磁束密度 $\boldsymbol B$ ，磁場 $\boldsymbol H$ ，磁化 $\boldsymbol M$ の間に，

```math
\boxed{
\boldsymbol B=\boldsymbol H+4\pi\boldsymbol M
}
\tag{7}
```

という関係が成り立つ．

これを微分すると，

```math
d\boldsymbol B=d\boldsymbol H+4\pi\,d\boldsymbol M
\tag{8}
```

となる．
式（8）を式（6）に代入すれば，

```math
\begin{aligned}
dW
&=\frac{V}{4\pi}
\boldsymbol H\cdot
\left(d\boldsymbol H+4\pi\,d\boldsymbol M\right)\\
&=\frac{V}{4\pi}
\boldsymbol H\cdot d\boldsymbol H
+V\boldsymbol H\cdot d\boldsymbol M
\end{aligned}
\tag{9}
```

を得る．

ここで，ベクトルの内積の微分公式

```math
\boldsymbol H\cdot d\boldsymbol H
=\frac{1}{2}\,d(\boldsymbol H\cdot\boldsymbol H)
=\frac{1}{2}\,d(H^2)
```

を用いると，

```math
\frac{V}{4\pi}
\boldsymbol H\cdot d\boldsymbol H
=\frac{V}{8\pi}\,d(H^2)
```

となる．
磁性体の体積 $V$ は一定であるから，

```math
\frac{V}{8\pi}\,d(H^2)
=d\left(\frac{VH^2}{8\pi}\right)
```

である．
したがって式（9）は，

```math
\boxed{
dW=d\left(\frac{VH^2}{8\pi}\right)
+V\boldsymbol H\cdot d\boldsymbol M
}
\tag{10}
```

となる．

式（10）の第1項は，磁場 $H$ を形成するための磁場エネルギーの変化を表す．
この項は，磁性体を磁化する仕事そのものとは区別される．
第2項が，磁化の変化に伴う仕事である．

したがって，磁場を形成するためのエネルギー変化を差し引くと，磁化を $d\boldsymbol M$ だけ変化させるための仕事は，

```math
dW_{\mathrm{mag}}
=V\boldsymbol H\cdot d\boldsymbol M
\tag{11}
```

となる．

### 4．磁化に必要な仕事を積分する

磁化がゼロの状態から最終値 $\boldsymbol M$ まで変化するとき，式（11）をその過程に沿って積分すると，

```math
W_{\mathrm{mag}}
=V\int_{\boldsymbol 0}^{\boldsymbol M}
\boldsymbol H\cdot d\boldsymbol M
```

を得る．
両辺を磁性体の体積 $V$ で割ると，単位体積当たりの仕事 $A$ は，

```math
\boxed{
A=\int_{\boldsymbol 0}^{\boldsymbol M}
\boldsymbol H\cdot d\boldsymbol M
}
```

となる．
ここで，積分は磁化をゼロから最終値まで変化させる過程に沿った線積分である．

よって，題意が示された．
