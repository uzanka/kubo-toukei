# 例題【1-R-1】

## 解答

本問題は，磁性体を磁化するために電源がなすべき仕事を，磁場 $H$ と磁化 $M$ を用いて導出するものである．

### 1. 設定の整理

十分細長い棒状の磁性体に，単位長さあたり $n$ 回巻きのコイルを巻いている．
コイルに流れる電流を $J$ ，磁性体の長さを $l$ ，断面積を $\sigma$ とする．
磁性体の体積を $V = \sigma l$ とおく．

### 2. 磁場 $H$ と電流 $J$ の関係

アンペールの回路定理（Ampère's law）を用いると，コイル内部に生じる磁場 $H$ は電流 $J$ を用いて以下のように与えられる：

$$H = \frac{4\pi n J}{c}$$

これを電流 $J$ について解くと，以下のようになる：

$$J = \frac{c H}{4\pi n}$$

### 3. 磁束 $\phi$ と磁束密度 $B$

磁性体内における磁束密度 $B$ は，磁場 $H$ と磁化 $M$ を用いて次のように定義される：

$$B = H + 4\pi M$$

コイルの全巻数は $nl$ であるから，コイルを貫く全磁束 $\phi$ は次のように表される：

$$\phi = (nl) \times (\sigma B) = (nl\sigma) B = V n B$$

### 4. 電源がなす仕事の導出

電流 $J$ を変化させて磁場 $H$ および磁化 $M$ を変化させると，磁束 $\phi$ が変化する．
ファラデーの電磁誘導の法則により，コイル内には以下の逆起電力 $\mathcal{E}$ が生じる：

$$\mathcal{E} = -\frac{1}{c} \frac{d\phi}{dt}$$

この逆起電力に抗して，微小時間 $dt$ の間に電源が電荷 $dq = J dt$ を送り込むために必要な仕事 $dW$ は，その大きさを用いて次のように書ける：

$$dW = |\mathcal{E}| \cdot dq = \left( \frac{1}{c} \frac{d\phi}{dt} \right) (J dt)$$

ここで， $\phi = V n B$ より $\frac{d\phi}{dt} = V n \frac{dB}{dt}$ である．
また，前述の $J = \frac{c H}{4\pi n}$ を代入すると：

$$dW = \left( \frac{1}{c} V n \frac{dB}{dt} \right) \left( \frac{c H}{4\pi n} dt \right) = \frac{V H}{4\pi} dB$$

### 5. エネルギーの分解と磁化の仕事

磁束密度の微分は， $B = H + 4\pi M$ より $dB = dH + 4\pi dM$ となる．
これを上の式に代入する：

$$dW = \frac{V H}{4\pi} (dH + 4\pi dM) = \frac{V H dH}{4\pi} + V H dM$$

第1項 $\frac{V H dH}{4\pi}$ は，磁性体がなくても磁場 $H$ を作るために必要なエネルギーであり，次のように書き換えられる：

$$\frac{V H dH}{4\pi} = \frac{V}{8\pi} d(H^2) = d\left( \frac{VH^2}{8\pi} \right)$$

第2項 $V H dM$ は，磁化 $M$ を変化させるために必要なエネルギーである．

磁化を $0$ から $M$ まで増やすために必要な仕事の合計 $W$ は，この第2項を積分することで得られる：

$$W = \int V H dM$$

単位体積あたりの仕事 $A$ は， $A = \frac{W}{V}$ であるから，

$$A = \int_0^M H dM$$

が得られる．
問題文のベクトル表記 $\boldsymbol{H} \cdot d\boldsymbol{M}$ は，このスカラー量における内積の成分を表している．

以上により，題意が示された．

## 解説

この問題の核心は，「磁場そのものを作るためのエネルギー」と「物質を磁化させるためのエネルギー」を分けて考える点にある．

### 1. 磁場を作る仕事 (Energy to create $H$ )

電流を流して磁力線を発生させるプロセスである．
これは磁性体の有無に関わらず，磁場 $H$ を作るために消費されるエネルギーである．
エネルギーの変化量は $d(\frac{VH^2}{8\pi})$ で表され，これは磁力線の「数」を増やすことに相当する．

### 2. 磁化させる仕事 (Energy to magnetize $M$ )

物質の内部において，磁気モーメント（小さな磁石のようなもの）を整列させるプロセスである．
このプロセスに費やされるエネルギーが $\int H dM$ である．

### まとめ

もし，磁化 $M$ を一定に保ったまま電流 $J$ を減らして磁場 $H$ だけを弱めた場合，第1項のエネルギー（磁力線の数を減らすエネルギー）は電源へと回収されることができるが，第2項のエネルギー（磁化の状態を維持するために蓄えられたエネルギー）は物質の中に残る．
このように，磁化という「物質の状態の変化」に直接関わる部分を抽出することが，この問題の目的である．
