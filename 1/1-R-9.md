# 例題【1-R-9】

## 解答

### 1．外界から気体に加えられる仕事 $A$ を求める

Joule–Thomson の細孔栓の実験を，解答例と同様に，2つのピストン $P_1$ ， $P_2$ を用いたモデルで考える．
初めに，綿栓 $S$ とピストン $P_1$ の間に，圧力 $p_1$ ，温度 $T_1$ ，体積 $V_1$ の気体が入っており，綿栓の反対側のピストン $P_2$ は綿栓に接しているとする．

外部からピストン $P_1$ を押すと，気体は綿栓を通って右側へ移動し，最終的に圧力 $p_2$ ，温度 $T_2$ ，体積 $V_2$ の状態になる．
ここで，左側の圧力 $p_1$ と右側の圧力 $p_2$ はそれぞれ一定に保たれているものとする．

外界が気体に対してする仕事を $A$ とすると，体積が $dV$ だけ変化する際に外界が気体にする微小仕事は

```math
dA=-p\,dV
```

で与えられる．
体積が減少すると外界は気体に正の仕事をし，体積が増加すると気体が外部に仕事をするため，外界のする仕事は負になる．

まず，ピストン $P_1$ 側では，気体の体積が $V_1$ から $0$ まで減少するので，

```math
\begin{aligned}
A_1 &=-\int_{V_1}^{0}p_1\,dV\\
&=-p_1(0-V_1)\\
&=p_1V_1
\end{aligned}
```

となる．

一方，ピストン $P_2$ 側では，気体の体積が $0$ から $V_2$ まで増加するので，

```math
\begin{aligned}
A_2 &=-\int_0^{V_2}p_2\,dV\\
&=-p_2(V_2-0)\\
&=-p_2V_2
\end{aligned}
```

となる．

したがって，外界から気体に加えられる正味の仕事 $A$ は，これらの和として

```math
\begin{aligned}
A&=A_1+A_2\\
&=p_1V_1-p_2V_2
\end{aligned}
```

となる．
すなわち，

```math
\boxed{
A=p_1V_1-p_2V_2
}
\tag{1}
```

を得る．

### 2．熱力学第一法則からエンタルピーの保存を導く

気体全体に対する熱力学第一法則は，内部エネルギーの変化を $\Delta U=U_2-U_1$ ，気体に加えられた熱量を $Q$ ，外界から気体に加えられた仕事を $A$ とすると，

```math
\Delta U=Q+A
\tag{2}
```

と表される．

ここで，装置は断熱的であり，気体と外界との間に熱のやり取りがないものとする．
したがって，

```math
Q=0
```

である．
また，綿栓によって気体の巨視的な運動エネルギーの変化を無視できるものとする．
このとき，式 (2) は

```math
\Delta U=A
```

となる．
よって，

```math
U_2-U_1=A
\tag{3}
```

である．

式 (1) の $A=p_1V_1-p_2V_2$ を式 (3) に代入すると，

```math
U_2-U_1=p_1V_1-p_2V_2
```

を得る．
これを整理すれば，

```math
U_1+p_1V_1=U_2+p_2V_2
```

となる．

ここで，エンタルピー $H$ を

```math
H=U+pV
```

と定義する．
すると，初期状態と最終状態のエンタルピーはそれぞれ

```math
H_1=U_1+p_1V_1
```

```math
H_2=U_2+p_2V_2
```

であるから，

```math
\boxed{
H_1=H_2
}
\tag{4}
```

を得る．
したがって，この過程ではエンタルピーが保存されることが示された．

### 3．エンタルピーの保存条件から温度変化が定まることを示す

初期状態と最終状態の気体は，それぞれ圧力と温度によって指定される平衡状態にある．
一定量の気体について，体積を圧力 $p$ と温度 $T$ の関数として表せるので，エンタルピー $H=U+pV$ も圧力 $p$ と温度 $T$ の関数として

```math
H=H(p,T)
```

と表すことができる．

したがって，式 (4) のエンタルピー保存条件は，

```math
\boxed{
H(p_1,T_1)=H(p_2,T_2)
}
\tag{5}
```

と書き換えられる．

ここで，初期状態の圧力 $p_1$ と温度 $T_1$ ，および最終状態の圧力 $p_2$ が与えられているとする．
初期状態のエンタルピー $H(p_1,T_1)$ は定まっているため，式 (5) は

```math
H(p_2,T_2)=H(p_1,T_1)
```

を満たす最終温度 $T_2$ を定める条件となる．
実際の温度変化を数値で求めるには，気体のエンタルピーと圧力・温度との関係を知る必要がある．

以上より，Joule–Thomson の細孔栓の実験では，

```math
\boxed{
H(p_1,T_1)=H(p_2,T_2)
}
```

が成り立ち，この条件によって温度変化 $T_1\to T_2$ が定められることが示された．

## 3．補足説明

### エンタルピーが保存される理由

この実験では，気体が高圧側から低圧側へ移動する際，左側では外界が気体を押す仕事をし，右側では気体が外部を押す仕事をする．それぞれの仕事を合わせると，

```math
A=p_1V_1-p_2V_2
```

となる．
断熱条件のもとでは，この正味の仕事が内部エネルギーの変化に等しい．
その結果，内部エネルギー $U$ と圧力・体積の積 $pV$ を合わせた量 $H=U+pV$ が初期状態と最終状態で等しくなる．

### 温度が必ず変化するとは限らない

エンタルピーが保存されても，温度が必ず変化するわけではない．
実在気体では一般にエンタルピーが圧力にも依存するため，圧力が変化すると温度も変化し得る．
これが Joule–Thomson 効果である．

一方，理想気体ではエンタルピーは温度だけの関数 $H=H(T)$ である．
したがって，エンタルピー保存から

```math
H(T_1)=H(T_2)
```

となり，比熱が正であれば，

```math
\boxed{
T_2=T_1
}
```

となる．
つまり，理想気体では Joule–Thomson の細孔栓過程による温度変化は生じず，実在気体では一般に温度が変化し得る．
