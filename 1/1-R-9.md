# 例題【1-R-9】

## 解答

### 1．実験のモデルと仮定

Joule–Thomson の細孔栓の実験では，圧力 $p_1$ の気体を綿栓に通して圧力 $p_2$ まで低下させる．
このとき，気体の温度は一般に $T_1$ から $T_2$ へ変化する．

この実験を，2つのピストン $P_1，P_2$ を用いたモデルで考える．
初めに，綿栓 $S$ と左側のピストン $P_1$ の間に，圧力 $p_1$ ，温度 $T_1$ ，体積 $V_1$ の気体が入っている．
右側のピストン $P_2$ は，初め綿栓に接しているものとする．

左側のピストンを押すと，気体は綿栓を通過して右側へ移動し，最終的に圧力 $p_2$ ，温度 $T_2$ ，体積 $V_2$ の状態になる．

以下では，標準的な断熱細孔栓過程として，次の条件を仮定する．

1. 気体の物質量 $n$ および組成は変化しない．
2. 装置は断熱され，気体と外界との正味の熱交換はない．
3. 初期状態と最終状態は，それぞれ熱力学的平衡状態である．
4. 問題文の条件より，綿栓は気体に巨視的な運動エネルギーを与えないものとする．
   したがって，初期状態および最終状態において，

   ```math
   E_{\mathrm{k},1}\simeq0,
   \qquad
   E_{\mathrm{k},2}\simeq0
   ```

   とみなせる．

   また，装置の高さの差による位置エネルギー変化も無視できるので，

   ```math
   E_{\mathrm{p},1}\simeq E_{\mathrm{p},2}
   ```

   とする．
5. ピストンに作用する外圧は，左側では $p_1$ ，右側では $p_2$ に保たれている．
6. ピストン仕事以外の外部仕事はない．また，装置や綿栓にエネルギーの正味の蓄積はない．

ここで，綿栓内部では気体は実際には流動している．
問題文の「綿栓は気体が運動エネルギーをもつことを防ぐ」という条件を，入口および出口における巨視的運動エネルギーがともに無視できるという意味で用いる．

以上の条件のもとで，熱力学第一法則からエンタルピー保存を導く．

### 2．外界が気体にする仕事

外界が気体にする仕事を $A$ とする．

体積変化に伴う境界仕事について，気体に対して外界がする微小仕事は，

```math
\delta A=-p_{\mathrm{ext}}\,dV
```

である．
ここで， $p_{\mathrm{ext}}$ は気体全体の内部圧力ではなく，ピストンの境界に作用する外圧である．

#### 2.1 左側のピストン $P_1$ がする仕事

左側では，気体の体積が $V_1$ から $0$ まで減少する．
ピストンに作用する外圧は一定で $p_1$ であるから，

```math
\begin{aligned}
A_1
&=-\int_{V_1}^{0}p_1\,dV\\
&=-p_1[\,V\,]_{V_1}^{0}\\
&=-p_1(0-V_1)\\
&=p_1V_1
\end{aligned}
```

となる．
したがって，

```math
\boxed{A_1=p_1V_1}
```

である．

体積が減少しているため，外界は気体に正の仕事をしている．

#### 2.2 右側のピストン $P_2$ がする仕事

右側では，気体の体積が $0$ から $V_2$ まで増加する．
ピストンに作用する外圧は一定で $p_2$ であるから，

```math
\begin{aligned}
A_2
&=-\int_0^{V_2}p_2\,dV\\
&=-p_2[\,V\,]_0^{V_2}\\
&=-p_2(V_2-0)\\
&=-p_2V_2
\end{aligned}
```

となる．
したがって，

```math
\boxed{A_2=-p_2V_2}
```

である．

体積が増加しているため，気体は外界に仕事をしている．
そのため，外界が気体にする仕事は負となる．

#### 2.3 外界が気体にする正味の仕事

外界が気体にする正味の仕事は，左右のピストンによる仕事の和である．
したがって，

```math
\begin{aligned}
A
&=A_1+A_2\\
&=p_1V_1-p_2V_2
\end{aligned}
```

となる．
よって，

```math
\boxed{A=p_1V_1-p_2V_2}
\tag{1}
```

を得る．

### 3．熱力学第一法則からエンタルピー保存を導く

気体に加えられる熱量を $Q$ ，内部エネルギーを $U$ とする．
外界が気体にする仕事を正とする符号規約を採用すると，熱力学第一法則は，

```math
U_2-U_1=Q+A
\tag{2}
```

と表される．

より一般的には，巨視的な運動エネルギーおよび位置エネルギーも含めて，

```math
\Delta U+\Delta E_{\mathrm{k}}+\Delta E_{\mathrm{p}}
=Q+A
```

である．

本問では，初期状態と最終状態における巨視的な運動エネルギーおよび位置エネルギーの差を無視するため，

```math
E_{\mathrm{k},1}\simeq0,
\qquad
E_{\mathrm{k},2}\simeq0
```

であるから，

```math
\Delta E_{\mathrm{k}}
=
E_{\mathrm{k},2}-E_{\mathrm{k},1}
\simeq0
```

である．
また，

```math
E_{\mathrm{p},2}-E_{\mathrm{p},1}
=\Delta E_{\mathrm{p}}
\simeq0
```

である．
したがって，

```math
\Delta E_{\mathrm{k}}
=
0,
\qquad
\Delta E_{\mathrm{p}}
=
0
```

とみなせる．

また，装置は断熱されているので，

```math
Q=0
```

である．

したがって，式（2）は，

```math
U_2-U_1=A
\tag{3}
```

となる．

ここに式（1）を代入すると，

```math
U_2-U_1=p_1V_1-p_2V_2
```

である．
両辺を整理すれば，

```math
U_1+p_1V_1=U_2+p_2V_2
```

を得る．

ここで，エンタルピー $H$ を，

```math
H=U+pV
\tag{4}
```

と定義する．

初期状態と最終状態のエンタルピーは，

```math
H_1=U_1+p_1V_1
```

および，

```math
H_2=U_2+p_2V_2
```

である．
したがって，

```math
\boxed{H_1=H_2}
\tag{5}
```

となる．

以上より，標準的な断熱細孔栓過程では，気体のエンタルピーが保存されることが示された．

なお，ここで用いた熱力学第一法則はエネルギー保存則であり，細孔栓を通過する過程が可逆であることや，等エントロピー過程であることは仮定していない．
また，問題文の「綿栓は気体が運動エネルギーをもつことを防ぐ」という条件は，入口および出口の巨視的運動エネルギーが無視できることを意味している．
本導出で用いた

```math
\Delta E_{\mathrm{k}}=0
```

はこの条件から従うものであって，追加仮定ではない．
実際の細孔栓過程は不可逆過程であるが，断熱条件のもとでエンタルピーが保存されることに矛盾はない．

### 4．エンタルピー保存条件から温度変化が定まること

#### 4.1 エンタルピーを圧力と温度の関数として表す

初期状態と最終状態は，それぞれ熱力学的平衡状態にある．
また，気体の物質量と組成は一定である．

したがって，単一相の気体について，エンタルピーは圧力 $p$ と温度 $T$ の関数として，

```math
H=H(p,T)
```

と表すことができる．

式（5）のエンタルピー保存条件は，

```math
H(p_1,T_1)=H(p_2,T_2)
```

となる．
すなわち，

```math
\boxed{
H(p_1,T_1)=H(p_2,T_2)
}
\tag{6}
```

である．

初期状態の圧力 $p_1$ と温度 $T_1$ ，および最終圧力 $p_2$ が与えられれば，初期エンタルピー $H(p_1,T_1)$ は定まる．
したがって，最終温度 $T_2$ は，

```math
H(p_2,T_2)=H(p_1,T_1)
```

を満たす温度として求められる．

ただし，この条件だけで温度の数値を直接計算できるわけではない．
実際に $T_2$ を求めるには，気体の状態方程式や熱物性データなど，エンタルピーと圧力・温度との具体的な関係が必要である．

#### 4.2 最終温度が一意に定まる条件

定圧熱容量 $C_p$ は，

```math
C_p=
\left(\frac{\partial H}{\partial T}\right)_p
```

で定義される．

対象とする単一相の温度範囲で，

```math
C_p>0
```

が成立するとする．
このとき，圧力 $p_2$ を一定にすれば，

```math
\left(\frac{\partial H}{\partial T}\right)_{p_2}>0
```

であるため，エンタルピー $H(p_2,T)$ は温度 $T$ の単調増加関数となる．

したがって，

```math
H(p_2,T_2)=H(p_1,T_1)
```

を満たす温度が存在すれば，その温度は一意に定まる．

よって，エンタルピー保存条件は，気体の物性関係と定圧熱容量の条件のもとで，最終温度を決定する条件となる．

### 5．Joule–Thomson 係数との関係

温度変化の方向を調べるため，Joule–Thomson 係数を導く．

一定組成の単純圧縮性物質について，熱力学的な基本関係式は，

```math
dU=T\,dS-p\,dV
```

である．
ここで，

```math
H=U+pV
```

より，

```math
dH=dU+p\,dV+V\,dp
```

となる．
上の基本関係式を代入すると，

```math
\boxed{dH=T\,dS+V\,dp}
\tag{7}
```

を得る．

また，定圧熱容量の定義より，

```math
C_p=T\left(\frac{\partial S}{\partial T}\right)_p
```

である．
さらに，Maxwell の関係式，

```math
\left(\frac{\partial S}{\partial p}\right)_T
=
-\left(\frac{\partial V}{\partial T}\right)_p
```

を用いると，エントロピーの全微分は，

```math
\begin{aligned}
dS
&=
\left(\frac{\partial S}{\partial T}\right)_p dT
+
\left(\frac{\partial S}{\partial p}\right)_T dp\\
&=
\frac{C_p}{T}\,dT
-
\left(\frac{\partial V}{\partial T}\right)_p dp
\end{aligned}
\tag{8}
```

と表せる．

式（8）を式（7）に代入すると，

```math
\begin{aligned}
dH
&=
T\left[
\frac{C_p}{T}\,dT
-
\left(\frac{\partial V}{\partial T}\right)_p dp
\right]
+V\,dp\\
&=
C_p\,dT
+
\left[
V-T\left(\frac{\partial V}{\partial T}\right)_p
\right]dp
\end{aligned}
```

したがって，

```math
\boxed{
dH
=
C_p\,dT
+
\left[
V-T\left(\frac{\partial V}{\partial T}\right)_p
\right]dp
}
\tag{9}
```

となる．

細孔栓過程ではエンタルピーが一定であるから，

```math
dH=0
```

である．
これを式（9）に代入して整理すると，

```math
C_p\,dT
=
\left[
T\left(\frac{\partial V}{\partial T}\right)_p
-V
\right]dp
```

となる．
よって，

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_H
=
\frac{
T\left(\frac{\partial V}{\partial T}\right)_p-V
}{C_p}
}
\tag{10}
```

を得る．

この係数を Joule–Thomson 係数 $\mu_{\mathrm{JT}}$ という．

```math
\boxed{
\mu_{\mathrm{JT}}
=
\left(\frac{\partial T}{\partial p}\right)_H
}
```

圧力が低下する細孔栓過程では $dp<0$ であるため，温度変化の方向は Joule–Thomson 係数の符号によって決まる．

- $\mu_{\mathrm{JT}}>0$ の場合，圧力低下に伴って温度は低下する．
- $\mu_{\mathrm{JT}}<0$ の場合，圧力低下に伴って温度は上昇する．
- $\mu_{\mathrm{JT}}=0$ の場合，その状態では微小な圧力変化に対する温度変化は生じない．

有限の圧力変化については，等エンタルピーの経路に沿って，

```math
\boxed{
T_2-T_1
=
\int_{p_1}^{p_2}
\mu_{\mathrm{JT}}(p,T(p))\,dp
}
\tag{11}
```

と表せる．
ここで $T(p)$ は，エンタルピー一定の条件を満たす経路上の温度である．

このように，実在気体の温度変化は，気体の物性に依存する．
圧力が低下すれば必ず温度が低下するというわけではない．

なお，式（7）から式（10）までの関係は，平衡状態を表す熱力学的状態関数の微分関係である．
これを導くために，細孔栓を通過する実際の過程が可逆であると仮定する必要はない．

### 6．理想気体の場合

理想気体では，

```math
pV=nRT
```

であるから，

```math
V=\frac{nRT}{p}
```

となる．

したがって，圧力一定のもとでの体積の温度微分は，

```math
\left(\frac{\partial V}{\partial T}\right)_p
=
\frac{nR}{p}
```

である．
これより，

```math
T\left(\frac{\partial V}{\partial T}\right)_p
=
\frac{nRT}{p}
=V
```

となる．

これを式（10）に代入すると，

```math
\mu_{\mathrm{JT}}
=
\frac{V-V}{C_p}=0
```

である．
したがって，理想気体では圧力変化に伴う温度変化は生じない．

同じことは，エンタルピー保存条件からも説明できる．
理想気体では内部エネルギー $U$ は温度だけの関数であり，エンタルピーも，

```math
H=H(T)
```

と表される．
よって，

```math
H(T_1)=H(T_2)
```

となる．
定圧熱容量が正であればエンタルピーは温度の単調増加関数であるため，

```math
\boxed{T_2=T_1}
```

を得る．

したがって，理想気体では Joule–Thomson の細孔栓過程による温度変化は生じない．
一方，実在気体ではエンタルピーが圧力にも依存するため，圧力変化に伴って温度が変化し得る．

### 7．結論

断熱細孔栓過程では，左側のピストンが気体にする仕事と，右側のピストンで気体が外界にする仕事の差から，

```math
\boxed{
A=p_1V_1-p_2V_2
}
```

を得る．

これを熱力学第一法則に代入すると，

```math
U_2-U_1=p_1V_1-p_2V_2
```

であるから，

```math
U_1+p_1V_1=U_2+p_2V_2
```

となる．
したがって，

```math
\boxed{H_1=H_2}
```

が成立する．

さらに，エンタルピーを圧力と温度の関数として表せば，

```math
\boxed{
H(p_1,T_1)=H(p_2,T_2)
}
```

となる．
この関係と気体の物性関係から，最終温度 $T_2$ が定まる．

以上より，標準的な断熱 Joule–Thomson 細孔栓過程では，エンタルピーが保存され，その保存条件によって温度変化が決定されることが示された．
