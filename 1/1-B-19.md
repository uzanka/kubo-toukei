# 演習問題【1-B-19】

## 解答

一様な常磁性体について，定磁化熱容量 $C_M$ ，定磁場熱容量 $C_H$ ，等温磁化率 $\chi_T$ ，断熱磁化率 $\chi_{\mathrm{ad}}$ の間に成り立つ関係式

```math
\boxed{
\chi_{\mathrm{ad}}=\frac{C_M}{C_H}\chi_T
}
```

を導く．

### 1．気体と磁性体の熱力学的な対応関係

まず，磁性体の準静的過程における熱力学第一法則は，単位体積当たりの量について，

```math
d'Q=dU-H\,dM
\tag{1}
```

と表される．
ここで， $d'Q$ は吸収熱量， $U$ は内部エネルギー密度， $H$ は磁場， $M$ は磁化である．
磁化による体積変化は無視する．

一方，通常の圧縮性の系では，熱力学第一法則は

```math
d'Q=dU+p\,dV
\tag{2}
```

と書ける．
ここで， $p$ は圧力， $V$ は体積である．

式（1）と式（2）を比較すると，両者の数学的な構造は，次の対応関係によって一致する．

```math
\boxed{
p\longleftrightarrow -H,\qquad
V\longleftrightarrow M
}
\tag{3}
```

この対応に従えば，圧力一定の条件は磁場一定の条件に，体積一定の条件は磁化一定の条件に対応する．
したがって，定圧熱容量 $C_P$ と定積熱容量 $C_V$ は，それぞれ

```math
\boxed{
C_P\longleftrightarrow C_H,\qquad
C_V\longleftrightarrow C_M
}
\tag{4}
```

と対応づけられる．

### 2．圧縮率と磁化率の関係

気体などの圧縮性の系において，等温圧縮率 $\kappa_T$ と断熱圧縮率 $\kappa_{\mathrm{ad}}$ は，それぞれ

```math
\kappa_T=-\frac{1}{V}
\left(\frac{\partial V}{\partial p}\right)_T
\tag{5}
```

および

```math
\kappa_{\mathrm{ad}}=-\frac{1}{V}
\left(\frac{\partial V}{\partial p}\right)_{\mathrm{ad}}
\tag{6}
```

と定義される．
断熱条件では，熱の出入りがなく，準静的かつ可逆な過程ではエントロピーが一定に保たれる．

式（5）を式（6）で割ると，共通因子 $-1/V$ が相殺され，

```math
\frac{\kappa_T}{\kappa_{\mathrm{ad}}}
=
\frac{
\left(\dfrac{\partial V}{\partial p}\right)_T
}{
\left(\dfrac{\partial V}{\partial p}\right)_{\mathrm{ad}}
}
\tag{7}
```

となる．

ここで，式（3）の対応関係 $p\leftrightarrow-H$ ， $V\leftrightarrow M$ を用いると，

```math
\frac{\kappa_T}{\kappa_{\mathrm{ad}}}
=
\frac{
\left(\dfrac{\partial M}{\partial(-H)}\right)_T
}{
\left(\dfrac{\partial M}{\partial(-H)}\right)_{\mathrm{ad}}
}
\tag{8}
```

と書き換えられる．

一方，等温磁化率と断熱磁化率は，

```math
\chi_T=\left(\frac{\partial M}{\partial H}\right)_T,
\qquad
\chi_{\mathrm{ad}}=
\left(\frac{\partial M}{\partial H}\right)_{\mathrm{ad}}
\tag{9}
```

と定義される．

変数を $H$ から $-H$ に変更すると，偏微分にはマイナス符号が付くため，

```math
\left(\frac{\partial M}{\partial(-H)}\right)_T
=-\chi_T
```

および

```math
\left(\frac{\partial M}{\partial(-H)}\right)_{\mathrm{ad}}
=-\chi_{\mathrm{ad}}
```

である．
これらを式（8）に代入すると，分子と分母のマイナス符号が相殺され，

```math
\boxed{
\frac{\kappa_T}{\kappa_{\mathrm{ad}}}
=\frac{\chi_T}{\chi_{\mathrm{ad}}}
}
\tag{10}
```

を得る．

### 3．熱容量と磁化率の関係式の導出

例題［7］で得られた，圧縮性の系における熱容量と圧縮率の関係式

```math
\frac{C_P}{C_V}
=\frac{\kappa_T}{\kappa_{\mathrm{ad}}}
\tag{11}
```

を用いる．

式（4）の対応関係より，

```math
C_P\longleftrightarrow C_H,\qquad
C_V\longleftrightarrow C_M
```

であるから，式（11）は磁性体について，

```math
\frac{C_H}{C_M}
=\frac{\kappa_T}{\kappa_{\mathrm{ad}}}
\tag{12}
```

に対応する．
さらに，式（10）を代入すると，

```math
\frac{C_H}{C_M}
=\frac{\chi_T}{\chi_{\mathrm{ad}}}
\tag{13}
```

となる．

式（13）の両辺に $C_M\chi_{\mathrm{ad}}/C_H$ を掛けて整理すれば，

```math
\boxed{
\chi_{\mathrm{ad}}
=\frac{C_M}{C_H}\chi_T
}
```

が得られる．

よって，題意が示された．
