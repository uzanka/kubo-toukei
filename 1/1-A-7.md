# 演習問題【1-A-7】

## 解答

理想気体の状態方程式 $pV = nRT$ および，内部エネルギー $U$ と温度 $T$ の関係式 $U = C_V T + \text{const.}$ （ただし $C_V$ は定積比熱として一定）を用いる．
状態1から状態2への変化における内部エネルギーの増加 $\Delta U$ は，次のように求められる：

$$\Delta U = U_2 - U_1 = C_V (T_2 - T_1)$$

各過程における外から加えられた仕事 $A$ および吸収した熱量 $Q$ を求める．
ここで，仕事 $A$ は，系に対して外部からなされた仕事として $A = \int -p \, dV$ と定義する．

**(i)** 過程 1 $\to$ A $\to$ 2

この過程は，等積変化 $1 \to A$ と等圧変化 $A \to 2$ の組み合わせである．

1 $\to$ A は等積変化（ $V = V_1$ ）であるため，体積変化が $dV = 0$ であり，仕事は $A_{1 \to A} = 0$ である．
A $\to$ 2 は等圧変化（ $p = p_2$ ）であるため，仕事は次のように計算される：

$$A_{A \to 2} = \int_{V_1}^{V_2} -p_2 \, dV = -p_2 (V_2 - V_1)$$

したがって，過程(i)の全仕事は

$$A(i) = -p_2 (V_2 - V_1) \quad \cdots (1)$$

次に熱量を求める．
1 $\to$ A における熱量 $Q_{1 \to A}$ は，熱力学第一法則 $\Delta U = Q + A$ より，

$$Q_{1 \to A} = \Delta U_{1 \to A} - A_{1 \to A} = C_V (T_A - T_1) - 0 = C_V (T_A - T_1)$$

ここで， $T_A$ は状態Aにおける温度であり，状態Aでは $p = p_2, V = V_1$ である．
状態方程式 $p_2 V_1 = n R T_A$ より， $n R T_A = p_2 V_1$ が成り立つ．

A $\to$ 2 における熱量 $Q_{A \to 2}$ は，

$$Q_{A \to 2} = \Delta U_{A \to 2} - A_{A \to 2} = C_V (T_2 - T_A) - (-p_2 (V_2 - V_1)) = C_V (T_2 - T_A) + p_2 (V_2 - V_1)$$

ここで，$p_2 V_2 = n R T_2$ および $p_2 V_1 = n R T_A$ を用いると，

$$Q_{A \to 2} = C_V (T_2 - T_A) + n R T_2 - n R T_A = (C_V + n R) T_2 - (C_V + n R) T_A$$

マイヤーの関係式 $C_P = C_V + n R$ を用いると，

$$Q_{A \to 2} = C_P (T_2 - T_A)$$

したがって，過程(i)の全熱量は

$$Q(i) = Q_{1 \to A} + Q_{A \to 2} = C_V (T_A - T_1) + C_P (T_2 - T_A)$$

これを整理すると，

$$Q(i) = C_P T_2 - C_V T_1 - (C_P - C_V) T_A$$

$C_P - C_V = n R$ であり，$n R T_A = p_2 V_1$ であるから，

$$Q(i) = C_P T_2 - C_V T_1 - p_2 V_1$$

ここで， $p_2 V_1 = p_2 V_2 - p_2 (V_2 - V_1) = n R T_2 - p_2 (V_2 - V_1)$ を代入すると，

$$Q(i) = C_P T_2 - C_V T_1 - (n R T_2 - p_2 (V_2 - V_1)) = (C_P - n R) T_2 - C_V T_1 + p_2 (V_2 - V_1)$$

$C_P - n R = C_V$ であるから，

$$Q(i) = C_V (T_2 - T_1) + p_2 (V_2 - V_1) \quad \cdots (2)$$

**(ii)** 過程 1 $\to$ B $\to$ 2

この過程は，等温変化 $1 \to B$ と等積変化 $B \to 2$ の組み合わせである．

1 $\to$ B は等温変化（ $T = T_1$ ）であるため，仕事は次のように計算される：

$$A_{1 \to B} = \int_{V_1}^{V_2} -p \, dV = \int_{V_1}^{V_2} -\frac{n R T_1}{V} \, dV = -n R T_1 \ln \left( \frac{V_2}{V_1} \right) = n R T_1 \ln \left( \frac{V_1}{V_2} \right)$$

B $\to$ 2 は等積変化（ $V = V_2$ ）であるため，仕事は $A_{B \to 2} = 0$ である．
したがって，過程(ii)の全仕事は

$$A(ii) = n R T_1 \ln \left( \frac{V_1}{V_2} \right) \quad \cdots (3)$$

次に熱量を求める．
1 $\to$ B では温度が一定であるため，内部エネルギーの変化は $\Delta U_{1 \to B} = 0$ である．
第一法則より，

$$Q_{1 \to B} = \Delta U_{1 \to B} - A_{1 \to B} = 0 - n R T_1 \ln \left( \frac{V_1}{V_2} \right) = n R T_1 \ln \left( \frac{V_2}{V_1} \right)$$

B $\to$ 2 は等積変化であるため，

$$Q_{B \to 2} = C_V (T_2 - T_1)$$

したがって，過程(ii)の全熱量は

$$Q(ii) = C_V (T_2 - T_1) + n R T_1 \ln \left( \frac{V_2}{V_1} \right) \quad \cdots (4)$$

**(iii)** 過程 1 $\to$ C $\to$ 2

問題文の条件より， $1 \to D \to C$ は断熱過程である．
したがって， $1 \to C$ は一つの断熱過程として扱うことができる．
$C \to 2$ は等積変化である．

1 $\to$ C は断熱過程であるため，熱のやり取りはなく， $Q_{1 \to C} = 0$ である．
このときの仕事 $A_{1 \to C}$ は，第一法則 $\Delta U = Q + A$ より， $A_{1 \to C} = \Delta U_{1 \to C} = C_V (T_C - T_1)$ である．
断熱過程において， $T V^{\gamma-1} = \text{const.}$ が成り立つ．
したがって， $T_C V_2^{\gamma-1} = T_1 V_1^{\gamma-1}$ より， $T_C = T_1 (V_1/V_2)^{\gamma-1}$ となる．
これを用いると，

$$A_{1 \to C} = C_V (T_1 (V_1/V_2)^{\gamma-1} - T_1) = -C_V T_1 \{ 1 - \left( \frac{V_1}{V_2} \right)^{\gamma-1} \}$$

C $\to$ 2 は等積変化であるため，仕事は $A_{C \to 2} = 0$ である．
したがって，過程(iii)の全仕事は

$$A(iii) = -C_V T_1 \{ 1 - \left( \frac{V_1}{V_2} \right)^{\gamma-1} \} \quad \cdots (5)$$

次に熱量を求める．
1 $\to$ C では熱のやり取りがないため， $Q_{1 \to C} = 0$ である．
C $\to$ 2 は等積変化であるため，

$$Q_{C \to 2} = C_V (T_2 - T_C) = C_V \{ T_2 - T_1 \left( \frac{V_1}{V_2} \right)^{\gamma-1} \}$$

したがって，過程(iii)の全熱量は

$$Q(iii) = C_V \{ T_2 - T_1 \left( \frac{V_1}{V_2} \right)^{\gamma-1} \} \quad \cdots (6)$$

以上について，いずれの場合も $A + Q$ を計算すると， $\Delta U = C_V (T_2 - T_1)$ と一致することが確認できる．

## 解説

本問題では，理想気体の熱力学的な過程における仕事と熱の計算を扱った．
熱力学第一法則 $Q = \Delta U - A$ （ここで $A$ は外部から系に加えられた仕事）を基本とし，各過程の特徴的な性質を適切に適用することが重要である．

1.  **等積変化** ：
  体積が一定（ $dV = 0$ ）であるため，仕事は $0$ となる．
  熱量は内部エネルギーの変化に等しい ($Q = \Delta U$)．
2.  **等圧変化** ：
  圧力が一定であるため，仕事は $A = -p \Delta V$ となる．
  熱量は定圧比熱を用いて $Q = C_P \Delta T$ と表される．
3.  **等温変化** ：
  温度が一定であるため，内部エネルギーの変化は $\Delta U = 0$ となる．
  したがって，第一法則より $Q = -A$ となる．
4.  **断熱変化** ：
  外部との熱のやり取りがないため， $Q = 0$ である．
  したがって，仕事は内部エネルギーの変化に等しい ( $A = \Delta U$ )．

また，マイヤーの関係式 $C_P - C_V = n R$ や，断熱過程における温度と体積の関係式 $T V^{\gamma-1} = \text{const.}$ などの公式を使いこなすことが，複雑な式変形を解くための鍵となる．
