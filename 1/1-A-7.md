# 演習問題【1-A-7】

## 解答

### 1．内部エネルギーの増加

理想気体の内部エネルギーは温度のみに依存する．
比熱が一定であるから，

```math
U=C_VT+\mathrm{const.}
```

と表される．
ここで， $C_V$ は気体全体の定積熱容量である．

したがって，状態1から状態2への内部エネルギーの増加は，

```math
\boxed{
\Delta U=U_2-U_1=C_V(T_2-T_1)
}
```

である．

内部エネルギーは状態量なので，この変化は経路に依存しない．
一方，仕事と熱量は経路に依存する．

以下では，外部から気体になされる仕事を $A$ ，気体が吸収する熱量を $Q$ と定義する．
このとき熱力学第1法則は，

```math
\boxed{
\Delta U=Q+A
}
```

となる．

また，理想気体の状態方程式とマイヤーの関係式は，

```math
pV=nRT,\qquad C_P-C_V=nR
```

である．

### 2．過程（i）： $1\to A\to2$

図より， $1\to A$ は体積 $V_1$ 一定の等積過程， $A\to2$ は圧力 $p_2$ 一定の等圧過程である．

したがって，状態Aでは，

```math
V_A=V_1,\qquad p_A=p_2.
```

#### （1）仕事

等積過程では，

```math
A_{1\to A}=0.
```

等圧過程では，

```math
\begin{aligned}
A_{A\to2} &=-\int_{V_1}^{V_2}p_2\,dV\\
&=-p_2(V_2-V_1).
\end{aligned}
```

したがって，

```math
\boxed{
A(\mathrm{i})=-p_2(V_2-V_1)
}
\tag{1}
```

となる．

#### （2）熱量

状態Aの温度を $T_A$ とする．
状態方程式より，

```math
p_2V_1=nRT_A
```

なので，

```math
T_A=\frac{p_2V_1}{nR}.
```

等積過程では仕事がゼロであるため，

```math
Q_{1\to A}=C_V(T_A-T_1).
```

一方，等圧過程では，

```math
Q_{A\to2}=C_P(T_2-T_A).
```

したがって，

```math
\begin{aligned}
Q(\mathrm{i}) &=C_V(T_A-T_1)+C_P(T_2-T_A)\\
&=C_PT_2-C_VT_1-(C_P-C_V)T_A\\
&=C_PT_2-C_VT_1-nRT_A\\
&=C_PT_2-C_VT_1-p_2V_1.
\end{aligned}
```

ここで，

```math
C_P=C_V+nR
```

および

```math
nRT_2=p_2V_2
```

を使うと，

```math
\begin{aligned}
Q(\mathrm{i}) &=C_VT_2+p_2V_2-C_VT_1-p_2V_1\\
&=C_V(T_2-T_1)+p_2(V_2-V_1).
\end{aligned}
```

よって，

```math
\boxed{
Q(\mathrm{i}) =C_V(T_2-T_1)+p_2(V_2-V_1)
}
\tag{2}
```

である．

### 3．過程（ii）： $1\to B\to2$

図より， $1\to B$ は温度 $T_1$ 一定の等温過程， $B\to2$ は体積 $V_2$ 一定の等積過程である．

したがって，状態Bでは，

```math
\boxed{
T_B=T_1,\qquad V_B=V_2
}
```

が成立する．

#### （1）仕事

等温過程では，

```math
pV=nRT_1
```

なので，

```math
p=\frac{nRT_1}{V}.
```

したがって，

```math
\begin{aligned}
A_{1\to B} &=-\int_{V_1}^{V_2}p\,dV\\
&=-nRT_1\int_{V_1}^{V_2}\frac{dV}{V}\\
&=-nRT_1\ln\frac{V_2}{V_1}.
\end{aligned}
```

等積過程 $B\to2$ では仕事はゼロである．

したがって，

```math
\boxed{
A(\mathrm{ii}) =-nRT_1\ln\frac{V_2}{V_1}
}
\tag{3}
```

となる．

#### （2）熱量

等温過程では，理想気体の内部エネルギーは変化しない．

```math
\Delta U_{1\to B}=0.
```

したがって，熱力学第1法則から，

```math
Q_{1\to B}=-A_{1\to B} =nRT_1\ln\frac{V_2}{V_1}.
```

等積過程 $B\to2$ では，

```math
Q_{B\to2}=C_V(T_2-T_1).
```

以上より，

```math
\begin{aligned}
Q(\mathrm{ii}) &=Q_{1\to B}+Q_{B\to2}\\
&=nRT_1\ln\frac{V_2}{V_1} +C_V(T_2-T_1).
\end{aligned}
```

したがって，

```math
\boxed{
Q(\mathrm{ii}) =C_V(T_2-T_1) +nRT_1\ln\frac{V_2}{V_1}
}
\tag{4}
```

となる．

### 4．過程（iii）： $1\to D\to C\to2$

図より， $1\to D$ と $D\to C$ は，同じ断熱曲線上にある．
したがって， $1\to D\to C$ 全体が準静的断熱過程である．

また， $C\to2$ は等積過程であり，

```math
\boxed{
V_C=V_2
}
```

である．

点Dは断熱過程の途中の状態を表している．
以下では，点Dを含む各区間の仕事を明示的に計算する．

#### （1）仕事

まず，断熱過程 $1\to D$ と $D\to C$ では，

```math
Q_{1\to D}=Q_{D\to C}=0.
```

熱力学第1法則より，

```math
A_{1\to D}=C_V(T_D-T_1),
```

```math
A_{D\to C}=C_V(T_C-T_D)
```

となる．
ここで $T_D$ は状態Dの温度である．

両区間の仕事を加えると，

```math
\begin{aligned}
A_{1\to D\to C} &=A_{1\to D}+A_{D\to C}\\
&=C_V(T_D-T_1)+C_V(T_C-T_D)\\
&=C_V(T_C-T_1).
\end{aligned}
```

したがって，

```math
\boxed{
A_{1\to D\to C}=C_V(T_C-T_1)
}
\tag{5}
```

を得る．

ここで点Dの温度 $T_D$ が消えるのは，内部エネルギーが状態量であり，二つの断熱区間における内部エネルギー変化を加えると中間状態の寄与が相殺されるためである．

次に，断熱変化に対するポアソンの関係式は，

```math
TV^{\gamma-1}=\mathrm{const.}, \qquad \gamma=\frac{C_P}{C_V}
```

である．

これを状態1と状態Cに適用すると，

```math
T_1V_1^{\gamma-1} =T_CV_C^{\gamma-1}.
```

$V_C=V_2$ より，

```math
\boxed{
T_C=T_1 \left(\frac{V_1}{V_2}\right)^{\gamma-1}
}
\tag{6}
```

となる．

一方，等積過程 $C\to2$ では仕事はゼロである．

したがって，過程（iii）全体の仕事は，

```math
\begin{aligned}
A(\mathrm{iii}) &=A_{1\to D\to C}+A_{C\to2}\\
&=C_V(T_C-T_1).
\end{aligned}
```

式 (6) を代入すれば，

```math
\boxed{
A(\mathrm{iii}) =C_VT_1 \left\{ \left(\frac{V_1}{V_2}\right)^{\gamma-1}-1 \right\}
}
\tag{7}
```

を得る．

#### （2）熱量

断熱過程では熱の出入りがないため，

```math
Q_{1\to D}=Q_{D\to C}=0.
```

一方，等積過程 $C\to2$ では仕事がゼロなので，

```math
Q_{C\to2}=C_V(T_2-T_C).
```

したがって，

```math
Q(\mathrm{iii})=C_V(T_2-T_C).
```

式 (6) を代入すると，

```math
\boxed{
Q(\mathrm{iii}) =C_V\left\{ T_2-T_1 \left(\frac{V_1}{V_2}\right)^{\gamma-1} \right\}
}
\tag{8}
```

となる．

### 5．熱力学第1法則による確認

それぞれの過程について，

```math
A+Q=C_V(T_2-T_1)
```

が成立することを確認する．

過程（i）

```math
\begin{aligned}
A(\mathrm{i})+Q(\mathrm{i}) &=-p_2(V_2-V_1)\\
&\quad+C_V(T_2-T_1)+p_2(V_2-V_1)\\
&=C_V(T_2-T_1).
\end{aligned}
```

過程（ii）

```math
\begin{aligned}
A(\mathrm{ii})+Q(\mathrm{ii}) &=-nRT_1\ln\frac{V_2}{V_1}\\
&\quad+C_V(T_2-T_1) +nRT_1\ln\frac{V_2}{V_1}\\
&=C_V(T_2-T_1).
\end{aligned}
```

過程（iii）

```math
\begin{aligned}
A(\mathrm{iii})+Q(\mathrm{iii}) &=C_V(T_C-T_1)+C_V(T_2-T_C)\\
&=C_V(T_2-T_1).
\end{aligned}
```

したがって，すべての過程で，

```math
\boxed{
A+Q=\Delta U=C_V(T_2-T_1)
}
```

が成立する．

### 6．最終結果

内部エネルギーの増加は，経路によらず，

```math
\boxed{
\Delta U=C_V(T_2-T_1)
}
```

である．

各過程の仕事と熱量は次のとおりである．

| 過程 | 外部から気体になされる仕事 $A$ | 気体が吸収する熱量 $Q$ |
| ---- | ---------------------------- | -------------------- |
| (i) $1\to A\to2$ | $-p_2(V_2-V_1)$ | $C_V(T_2-T_1)+p_2(V_2-V_1)$ |
| (ii) $1\to B\to2$ | $-nRT_1\ln(V_2/V_1)$ | $C_V(T_2-T_1)+nRT_1\ln(V_2/V_1)$ |
| (iii) $1\to D\to C\to2$ | $C_VT_1\left\{(V_1/V_2)^{\gamma-1}-1\right\}$ | $C_V\left\{T_2-T_1(V_1/V_2)^{\gamma-1}\right\}$ |
