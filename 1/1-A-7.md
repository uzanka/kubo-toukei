# 演習問題【1-A-7】

## 解答

理想気体の状態方程式

```math
pV=nRT
```

および，比熱が一定のときの内部エネルギーと温度の関係式

```math
U=C_VT+\text{const.}
```

を用いる．
ここで， $n$ は気体の物質量， $R$ はモル気体定数， $C_V$ は気体全体の定積熱容量である．
また，気体全体の定圧熱容量を $C_P$ とすると，マイヤーの関係式

```math
C_P-C_V=nR
```

が成り立つ．

本解答では，外部から気体になされる仕事を $A$ ，気体が吸収する熱量を $Q$ とし，熱力学第1法則を

```math
\Delta U=Q+A
```

と表す．
この規約では，気体が膨張して外界に仕事をすると $A$ は負となる．

### 1．内部エネルギーの増加

理想気体では，内部エネルギーは温度のみによって決まる．
したがって，状態1から状態2への内部エネルギーの増加は，

```math
\boxed{
\Delta U=U_2-U_1=C_V(T_2-T_1)
}
```

である．
内部エネルギーは状態量であるため，この変化は経路（i），（ii），（iii）のいずれでも同じである．

### 2．過程（i）： $1\to A\to2$

この過程は，等積過程 $1\to A$ と等圧過程 $A\to2$ からなる．

**仕事の計算**

$1\to A$ は体積 $V_1$ が一定であるため，仕事はゼロである．

```math
A_{1\to A}=0
```

$A\to2$ は圧力 $p_2$ が一定であり，体積が $V_1$ から $V_2$ に増加する．
したがって，

```math
\begin{aligned}
A_{A\to2}
&=-\int_{V_1}^{V_2}p_2\,dV\\
&=-p_2(V_2-V_1)
\end{aligned}
```

となる．
よって，過程（i）全体で外部から気体になされる仕事は，

```math
\boxed{
A(\mathrm{i})=-p_2(V_2-V_1)
}
\tag{1}
```

である．

**熱量の計算**

状態Aの温度を $T_A$ とする．
状態Aでは圧力が $p_2$ ，体積が $V_1$ であるから，状態方程式より，

```math
p_2V_1=nRT_A
\tag{2}
```

が成り立つ．

等積過程 $1\to A$ では仕事がゼロなので，供給される熱量は内部エネルギーの増加に等しい．
したがって，

```math
Q_{1\to A}=C_V(T_A-T_1)
```

となる．
一方，等圧過程 $A\to2$ では，

```math
Q_{A\to2}=C_P(T_2-T_A)
```

である．
よって，過程（i）全体の熱量は，

```math
\begin{aligned}
Q(\mathrm{i})
&=C_V(T_A-T_1)+C_P(T_2-T_A)\\
&=C_PT_2-C_VT_1-(C_P-C_V)T_A
\end{aligned}
```

となる．
ここで， $C_P-C_V=nR$ と式（2）を用いると，

```math
Q(\mathrm{i})=C_PT_2-C_VT_1-p_2V_1
```

を得る．
さらに，状態2の状態方程式 $p_2V_2=nRT_2$ とマイヤーの関係式を用いれば，

```math
\begin{aligned}
Q(\mathrm{i})
&=C_PT_2-C_VT_1-p_2V_1\\
&=C_V(T_2-T_1)+p_2(V_2-V_1)
\end{aligned}
```

となる．
したがって，

```math
\boxed{
Q(\mathrm{i})
=C_V(T_2-T_1)+p_2(V_2-V_1)
}
\tag{2}
```

である．

### 3．過程（ii）： $1\to B\to2$

この過程は，温度 $T_1$ の等温過程 $1\to B$ と，体積 $V_2$ が一定の等積過程 $B\to2$ からなる．

**仕事の計算**

等温過程 $1\to B$ では，理想気体の状態方程式より，

```math
pV=nRT_1
```

である．
したがって，

```math
p=\frac{nRT_1}{V}
```

を仕事の式に代入すると，

```math
\begin{aligned}
A_{1\to B}
&=-\int_{V_1}^{V_2}p\,dV\\
&=-nRT_1\int_{V_1}^{V_2}\frac{dV}{V}\\
&=-nRT_1\ln\frac{V_2}{V_1}
\end{aligned}
```

となる．
ここで， $\ln$ は自然対数を表す．

等積過程 $B\to2$ では仕事はゼロなので，過程（ii）全体の仕事は，

```math
\boxed{
A(\mathrm{ii})
=-nRT_1\ln\frac{V_2}{V_1}
}
\tag{3}
```

である．

**熱量の計算**

等温過程 $1\to B$ では，理想気体の温度が一定であるため，内部エネルギーの変化はゼロである．
よって，熱力学第1法則より，

```math
Q_{1\to B}=-A_{1\to B}
=nRT_1\ln\frac{V_2}{V_1}
```

となる．

等積過程 $B\to2$ では，点Bの温度が $T_1$ ，状態2の温度が $T_2$ であるから，

```math
Q_{B\to2}=C_V(T_2-T_1)
```

となる．
したがって，過程（ii）全体の熱量は，

```math
\boxed{
Q(\mathrm{ii})
=C_V(T_2-T_1)
+nRT_1\ln\frac{V_2}{V_1}
}
\tag{4}
```

である．

### 4．過程（iii）： $1\to D\to C\to2$

問題文の経路の説明に従い， $1\to D$ を断熱過程， $D\to C$ を等圧過程， $C\to2$ を等積過程として計算する．

状態Dを $(p_D,V_D,T_D)$ ，状態Cを $(p_D,V_2,T_C)$ と表す．
すなわち，状態Dと状態Cの圧力は等しく，状態Cと状態2の体積は等しい．

**仕事の計算**

まず，断熱過程 $1\to D$ では熱の出入りがないため，

```math
Q_{1\to D}=0
```

である．
熱力学第1法則より，

```math
U_D-U_1=A_{1\to D}
```

となるので，

```math
A_{1\to D}=C_V(T_D-T_1)
```

を得る．
また，断熱過程ではポアソンの関係式

```math
TV^{\gamma-1}=\text{const.},
\qquad \gamma=\frac{C_P}{C_V}
```

が成り立つため，

```math
T_D=T_1\left(\frac{V_1}{V_D}\right)^{\gamma-1}
\tag{5}
```

となる．

次に，等圧過程 $D\to C$ では圧力 $p_D$ が一定であるから，

```math
\begin{aligned}
A_{D\to C}
&=-\int_{V_D}^{V_2}p_D\,dV\\
&=-p_D(V_2-V_D)
\end{aligned}
```

となる．
最後の等積過程 $C\to2$ では仕事はゼロなので，

```math
A_{C\to2}=0
```

である．
以上より，過程（iii）全体の仕事は，

```math
\boxed{
A(\mathrm{iii})
=C_V(T_D-T_1)-p_D(V_2-V_D)
}
\tag{6}
```

となる．

**熱量の計算**

断熱過程 $1\to D$ では，

```math
Q_{1\to D}=0
```

である．
等圧過程 $D\to C$ では，定圧熱容量 $C_P$ を用いて，

```math
Q_{D\to C}=C_P(T_C-T_D)
```

と表される．
また，等積過程 $C\to2$ では，

```math
Q_{C\to2}=C_V(T_2-T_C)
```

となる．
したがって，過程（iii）全体の熱量は，

```math
\boxed{
Q(\mathrm{iii})
=C_P(T_C-T_D)+C_V(T_2-T_C)
}
\tag{7}
```

である．

ここで，状態Dと状態Cは等圧過程で結ばれているため，状態方程式より，

```math
p_DV_D=nRT_D,\qquad
p_DV_2=nRT_C
```

が成り立つ．
これらの差をとると，

```math
p_D(V_2-V_D)=nR(T_C-T_D)
\tag{8}
```

を得る．
式（6），（7），（8）とマイヤーの関係式 $C_P-C_V=nR$ を用いると，

```math
\begin{aligned}
A(\mathrm{iii})+Q(\mathrm{iii})
&=C_V(T_D-T_1)-p_D(V_2-V_D)\\
&\quad+C_P(T_C-T_D)+C_V(T_2-T_C)\\
&=C_V(T_2-T_1)
\end{aligned}
```

となる．
したがって，過程（iii）についても，熱力学第1法則が成り立つことが確認できる．

### 5．まとめと注意点

内部エネルギーの増加は，どの経路でも共通して，

```math
\boxed{
\Delta U=C_V(T_2-T_1)
}
```

である．
また，各過程の仕事と熱量は，式（1）～（4），式（6），（7）で与えられる．
いずれの過程でも，

```math
\boxed{
A+Q=\Delta U
}
```

が成立する．

ただし， **問題文に記載された経路（iii）と解答例の式（5），（6）の経路は一致していない** ことに注意する．
解答例の式（5），（6）は，$1\to C$ 全体が直接の断熱過程であり，その後 $C\to2$ が等積過程となる場合の式である．
一方，本問の経路説明どおり $1\to D$ が断熱， $D\to C$ が等圧， $C\to2$ が等積であれば，式（6），（7）のように中間状態D，Cを含めて計算しなければならない．

指定された経路の説明だけでは，中間状態Dの位置が定量的に与えられていないため，過程（iii）の仕事と熱量を端点1，2だけの値で一意に決めることはできない．
