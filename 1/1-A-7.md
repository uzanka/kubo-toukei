# 演習問題【1-A-7】

## 解答

理想気体を状態1 $(p_1,V_1,T_1)$ から状態2 $(p_2,V_2,T_2)$ へ移す過程を考える．
比熱は一定とする．

本解答では，外部から気体になされる仕事を $A$ ，気体が吸収する熱量を $Q$ とする．
このとき，熱力学第1法則は

```math
\boxed{\Delta U=Q+A}
```

と表される．
気体が膨張して外界に仕事をするとき，外部から気体になされる仕事 $A$ は負となる．

また，気体全体の定積熱容量を $C_V$ ，定圧熱容量を $C_P$ ，物質量を $n$ ，モル気体定数を $R$ とする．
これらの間には，マイヤーの関係式

```math
C_P-C_V=nR
```

が成り立つ．
理想気体の状態方程式は

```math
pV=nRT
```

である．

## 1．内部エネルギーの増加

理想気体の内部エネルギー $U$ は温度のみによって決まり，比熱が一定であるから，

```math
U=C_VT+\text{const.}
```

と表される．
したがって，状態1から状態2への内部エネルギーの増加は

```math
\boxed{\Delta U=U_2-U_1=C_V(T_2-T_1)}
```

である．

内部エネルギーは状態量であるため，この変化は途中の経路によらず同じである．
一方，仕事 $A$ と熱量 $Q$ は経路に依存するため，各過程について個別に求める必要がある．

## 2．過程（i）： $1\to A\to2$

この過程は，体積一定の過程 $1\to A$ と，圧力一定の過程 $A\to2$ からなる．

### （1）仕事

まず， $1\to A$ は体積 $V_1$ が一定の等積過程である．
仕事は

```math
A_{1\to A}=-\int_{V_1}^{V_1}p\,dV=0
```

となる．

次に， $A\to2$ は圧力 $p_2$ が一定の等圧過程であり，体積が $V_1$ から $V_2$ に増加する．
したがって，

```math
\begin{aligned}
A_{A\to2}
&=-\int_{V_1}^{V_2}p_2\,dV\\
&=-p_2(V_2-V_1)
\end{aligned}
```

である．
よって，過程（i）全体の仕事は

```math
\boxed{A(\mathrm{i})=-p_2(V_2-V_1)}
\tag{1}
```

となる．
$V_2>V_1$ であるため，この仕事は負であり，気体が外界に仕事をしていることを意味する．

### （2）熱量

状態Aの温度を $T_A$ とする．
状態Aでは圧力が $p_2$ ，体積が $V_1$ であるから，状態方程式より

```math
p_2V_1=nRT_A
\tag{2}
```

が成り立つ．

等積過程 $1\to A$ では仕事がゼロであるため，熱力学第1法則より，吸収する熱量は内部エネルギーの増加に等しい．
したがって，

```math
Q_{1\to A}=C_V(T_A-T_1)
```

である．

一方，等圧過程 $A\to2$ では，気体が吸収する熱量は定圧熱容量を用いて

```math
Q_{A\to2}=C_P(T_2-T_A)
```

と表される．
よって，全熱量は

```math
\begin{aligned}
Q(\mathrm{i})
&=Q_{1\to A}+Q_{A\to2}\\
&=C_V(T_A-T_1)+C_P(T_2-T_A)\\
&=C_PT_2-C_VT_1-(C_P-C_V)T_A
\end{aligned}
```

となる．
ここで，マイヤーの関係式 $C_P-C_V=nR$ と式（2）を用いると，

```math
\begin{aligned}
Q(\mathrm{i})
&=C_PT_2-C_VT_1-nRT_A\\
&=C_PT_2-C_VT_1-p_2V_1
\end{aligned}
```

を得る．
さらに，状態2では $p_2V_2=nRT_2$ であるため，

```math
\begin{aligned}
C_PT_2
&=(C_V+nR)T_2\\
&=C_VT_2+p_2V_2
\end{aligned}
```

となる．
これを代入すれば，

```math
\begin{aligned}
Q(\mathrm{i})
&=C_VT_2+p_2V_2-C_VT_1-p_2V_1\\
&=C_V(T_2-T_1)+p_2(V_2-V_1)
\end{aligned}
```

である．
したがって，

```math
\boxed{Q(\mathrm{i})=C_V(T_2-T_1)+p_2(V_2-V_1)}
\tag{3}
```

となる．

## 3．過程（ii）： $1\to B\to2$

この過程は，温度 $T_1$ 一定の等温過程 $1\to B$ と，体積 $V_2$ 一定の等積過程 $B\to2$ からなる．

### （1）仕事

等温過程 $1\to B$ では，理想気体の状態方程式より

```math
pV=nRT_1
```

であるから，

```math
p=\frac{nRT_1}{V}
```

となる．
これを仕事の式に代入すると，

```math
\begin{aligned}
A_{1\to B}
&=-\int_{V_1}^{V_2}p\,dV\\
&=-nRT_1\int_{V_1}^{V_2}\frac{dV}{V}\\
&=-nRT_1\ln\frac{V_2}{V_1}
\end{aligned}
```

を得る．
ここで， $\ln$ は自然対数である．

等積過程 $B\to2$ では体積が変化しないため，仕事はゼロである．
したがって，過程（ii）全体の仕事は

```math
\boxed{A(\mathrm{ii})=-nRT_1\ln\frac{V_2}{V_1}}
\tag{4}
```

となる．

### （2）熱量

等温過程 $1\to B$ では温度が一定であるため，理想気体の内部エネルギーは変化しない．
すなわち，

```math
\Delta U_{1\to B}=0
```

である．
熱力学第1法則

```math
\Delta U=Q+A
```

より，

```math
Q_{1\to B}=-A_{1\to B}
```

となる．
したがって，

```math
Q_{1\to B}=nRT_1\ln\frac{V_2}{V_1}
```

である．

次に，等積過程 $B\to2$ を考える．
状態Bの温度は $T_1$ であり，状態2の温度は $T_2$ である．
等積過程では仕事がゼロであるため，

```math
Q_{B\to2}=C_V(T_2-T_1)
```

となる．
よって，全熱量は

```math
\begin{aligned}
Q(\mathrm{ii})
&=Q_{1\to B}+Q_{B\to2}\\
&=nRT_1\ln\frac{V_2}{V_1}+C_V(T_2-T_1)
\end{aligned}
```

である．
したがって，

```math
\boxed{Q(\mathrm{ii})=C_V(T_2-T_1)+nRT_1\ln\frac{V_2}{V_1}}
\tag{5}
```

となる．

## 4．過程（iii）： $1\to D\to C\to2$

この過程については，問題文の記述に注意する必要がある．
詳細な経路の説明では， $1\to D$ と $D\to C$ がともに断熱線上にあるとされている一方，補足的な手がかりでは等圧過程を含むとされている．
この2つの記述は一致していない．

以下では，解答例に従い， $1\to D\to C$ 全体を1つの断熱過程 $1\to C$ とみなし，その後に等積過程 $C\to2$ が続くものとして計算する．

### （1）仕事

断熱過程では熱の出入りがないため，

```math
Q_{1\to C}=0
```

である．
熱力学第1法則より，

```math
U_C-U_1=A_{1\to C}
```

となる．
内部エネルギーと温度の関係を用いれば，

```math
A_{1\to C}=C_V(T_C-T_1)
\tag{6}
```

である．

ここで，断熱過程を表すポアソンの関係式は

```math
TV^{\gamma-1}=\text{const.},
\qquad
\gamma=\frac{C_P}{C_V}
```

である．
状態1と状態Cについてこの関係式を適用すると，

```math
T_1V_1^{\gamma-1}=T_CV_C^{\gamma-1}
```

となる．
状態Cは体積 $V_2$ の位置にあるため， $V_C=V_2$ であり，

```math
\boxed{T_C=T_1\left(\frac{V_1}{V_2}\right)^{\gamma-1}}
\tag{7}
```

を得る．

式（7）を式（6）に代入すると，

```math
\begin{aligned}
A_{1\to C}
&=C_V\left[
T_1\left(\frac{V_1}{V_2}\right)^{\gamma-1}-T_1
\right]\\
&=C_VT_1
\left\{
\left(\frac{V_1}{V_2}\right)^{\gamma-1}-1
\right\}
\end{aligned}
```

となる．
等積過程 $C\to2$ では仕事がゼロであるため，過程（iii）全体の仕事は

```math
\boxed{
A(\mathrm{iii})
=C_VT_1
\left\{
\left(\frac{V_1}{V_2}\right)^{\gamma-1}-1
\right\}
}
\tag{8}
```

である．

### （2）熱量

断熱過程 $1\to C$ では熱の出入りがないから，

```math
Q_{1\to C}=0
```

である．

一方，等積過程 $C\to2$ では仕事がゼロであるため，吸収する熱量は内部エネルギーの変化に等しい．
したがって，

```math
Q_{C\to2}=C_V(T_2-T_C)
```

となる．
式（7）を代入すると，

```math
Q_{C\to2}
=C_V\left\{
T_2-T_1\left(\frac{V_1}{V_2}\right)^{\gamma-1}
\right\}
```

を得る．
よって，過程（iii）全体の熱量は

```math
\boxed{
Q(\mathrm{iii})
=C_V\left\{
T_2-T_1\left(\frac{V_1}{V_2}\right)^{\gamma-1}
\right\}
}
\tag{9}
```

である．

## 5．熱力学第1法則の確認

求めた仕事と熱量が熱力学第1法則を満たすことを確認する．

過程（i）では，式（1），（3）より，

```math
\begin{aligned}
A(\mathrm{i})+Q(\mathrm{i})
&=-p_2(V_2-V_1)\\
&\quad+C_V(T_2-T_1)+p_2(V_2-V_1)\\
&=C_V(T_2-T_1)
\end{aligned}
```

となる．

過程（ii）では，式（4），（5）より，

```math
\begin{aligned}
A(\mathrm{ii})+Q(\mathrm{ii})
&=-nRT_1\ln\frac{V_2}{V_1}\\
&\quad+C_V(T_2-T_1)
+nRT_1\ln\frac{V_2}{V_1}\\
&=C_V(T_2-T_1)
\end{aligned}
```

である．

過程（iii）では，式（6），（9）より，

```math
\begin{aligned}
A(\mathrm{iii})+Q(\mathrm{iii})
&=C_V(T_C-T_1)+C_V(T_2-T_C)\\
&=C_V(T_2-T_1)
\end{aligned}
```

となる．

以上より，どの過程でも

```math
\boxed{A+Q=\Delta U=C_V(T_2-T_1)}
```

が成り立つ．

## 6．最終結果

内部エネルギーの増加は，いずれの過程でも共通して

```math
\boxed{\Delta U=C_V(T_2-T_1)}
```

である．
各過程の仕事と熱量は，解答例と同じ解釈のもとで，次のようにまとめられる．

| 過程 | 外部から気体になされる仕事 $A$ | 気体が吸収する熱量 $Q$ |
|---|---|---|
| （i） $1\to A\to2$ | $-p_2(V_2-V_1)$ | $C_V(T_2-T_1)+p_2(V_2-V_1)$ |
| （ii） $1\to B\to2$ | $-nRT_1\ln\frac{V_2}{V_1}$ | $C_V(T_2-T_1)+nRT_1\ln\frac{V_2}{V_1}$ |
| （iii） $1\to D\to C\to2$ | $C_VT_1\left\{\left(\frac{V_1}{V_2}\right)^{\gamma-1}-1\right\}$ | $C_V\left\{T_2-T_1\left(\frac{V_1}{V_2}\right)^{\gamma-1}\right\}$ |

このように，内部エネルギーの変化は初期状態と最終状態だけで決まるが，仕事と熱量は過程によって異なる．
ただし，どの過程でも熱力学第1法則を満たし，仕事と熱量の和は内部エネルギーの増加に等しくなる．
