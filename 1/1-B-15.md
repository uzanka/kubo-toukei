# 演習問題【1-B-15】

## 解答

### 1. 系の設定とエネルギーの定義

断面積 $S$ を持つ，鉛直に立つ無限に高い空気柱を考える．
この空気柱は一様な重力場 $g$ の中にある．
高度 $z$ における空気の密度を $\rho(z)$ ，温度を $T$ ，単位質量当たりの内部エネルギーを $u(T)$ とする．

熱平衡状態では，温度 $T$ は高度 $z$ によらず一定であるとみなせる．
高度 $z$ から $z + dz$ の間にある微小な厚さ $dz$ の空気柱の体積は $S \, dz$ である．
この微小な部分の質量は $\rho(z) S \, dz$ と書ける．

この微小な部分が持つエネルギー $dE$ は，以下の2つの和で表される．
1. **内部エネルギー** : $\rho(z) S \, dz \cdot u(T)$
2. **位置エネルギー** : $\rho(z) S \, dz \cdot gz$

したがって，微小部分のエネルギーは $dE = S \{u(T) + gz\} \rho(z) \, dz$ である．
気柱全体のエネルギー $E(T)$ は，これを $z=0$ から $z=\infty$ まで積分することで得られる．

$$E(T) = S \int_{0}^{\infty} \{u(T) + gz\} \rho(z) \, dz \quad \cdots (1)$$

### 2. 密度の高度依存性と全質量

静水圧平衡の式 $\frac{dp}{dz} = -\rho(z) g$ と，理想気体の状態方程式 $p = \frac{\rho RT}{m}$ （ $m$ は分子の平均質量）を用いる．
$p$ を消去するために， $\rho$ についての微分方程式を作る．

$$\frac{d}{dz} \left( \frac{\rho RT}{m} \right) = -\rho g$$

温度 $T$ が一定であるとすると，

$$\frac{R T}{m} \frac{d\rho}{dz} = -\rho g \implies \frac{d\rho}{\rho} = -\frac{mg}{RT} dz$$

これを積分すると，

$$\ln \rho(z) = -\frac{mgz}{RT} + \text{const.}$$

$$\rho(z) = \rho(0) \exp\left( -\frac{mgz}{RT} \right) \quad \cdots (2)$$

が得られる．

ここで，気柱の全質量 $M$ は，

$$M = \int_{0}^{\infty} \rho(z) S \, dz = S \rho(0) \int_{0}^{\infty} \exp\left( -\frac{mgz}{RT} \right) dz$$

積分を実行すると，

$$M = S \rho(0) \left[ -\frac{RT}{mg} \exp\left( -\frac{mgz}{RT} \right) \right]_{0}^{\infty} = S \rho(0) \frac{RT}{mg}$$

これより，

$$S \rho(z) = S \rho(0) \exp\left( -\frac{mgz}{RT} \right) = \frac{Mmg}{RT} \exp\left( -\frac{mgz}{RT} \right) \quad \cdots (3)$$

と書ける．

### 3. 全エネルギーの計算

式 (3) を式 (1) に代入する．

$$E(T) = \int_{0}^{\infty} \{u(T) + gz\} \frac{Mmg}{RT} \exp\left( -\frac{mgz}{RT} \right) dz$$

ここで，変数変換 $\xi = \frac{mgz}{RT}$ を行う．
$dz = \frac{RT}{mg} d\xi$ であり， $z = \frac{RT\xi}{mg}$ である．
積分範囲は $z: 0 \to \infty$ から $\xi: 0 \to \infty$ となる．

```math
E(T) = \int_{0}^{\infty} \left\{ u(T) + g \frac{RT\xi}{mg} \right\} \frac{Mmg}{RT} e^{-\xi} \frac{RT}{mg} d\xi
```

```math
E(T) = M \int_{0}^{\infty} \left\{ u(T) + \frac{RT\xi}{m} \right\} e^{-\xi} d\xi$$
```

$$E(T) = M \left[ u(T) \int_{0}^{\infty} e^{-\xi} d\xi + \frac{RT}{m} \int_{0}^{\infty} \xi e^{-\xi} d\xi \right]$$

ここで， $\int_{0}^{\infty} e^{-\xi} d\xi = 1$ および $\int_{0}^{\infty} \xi e^{-\xi} d\xi = 1$ であるから，

$$E(T) = M \left( u(T) + \frac{RT}{m} \right) \quad \cdots (4)$$

となる．

### 4. 熱容量の導出

熱容量 $C$ は，系の全エネルギー $E(T)$ を温度 $T$ で微分することで得られる．

$$C = \frac{dE(T)}{dT} = M \frac{d}{dT} \left( u(T) + \frac{RT}{m} \right)$$

$$C = M \left( \frac{du}{dT} + \frac{R}{m} \right)$$

定積比熱 $c_v$ の定義は $c_v = \frac{du}{dT}$ であるから，

$$C = M \left( c_v + \frac{R}{m} \right)$$

ここで，マイヤーの関係式 $c_p = c_v + \frac{R}{m}$ を用いると，最終的に以下の結果が得られる．

$$C = M c_p$$

## 解説

この問題は，重力場の中に広がるガス（空気柱）のエネルギーを考え，その温度変化に対するエネルギーの変化量である「熱容量」を求めるものである．

1.  **エネルギーの構成**: 無限に高い空気柱を考えるとき，エネルギーは「ガスそのものが持つ内部エネルギー」と，「高さによって変わる位置エネルギー」の合計になる．
高度が上がるほど空気は薄くなるが（密度 $\rho$ が下がる），同時に位置エネルギーも高くなる．
2.  **密度の変化**: 重力の影響で，空気の密度は高度とともに指数関数的に減少する（ボルツマン分布に似た形）．
この性質を利用して，全体の質量 $M$ やエネルギーを積分で計算する．
3.  **結果の解釈**: 最終的に得られた $C = M c_p$ という結果は，非常に直感的である．
系全体の熱容量は，「全質量 $\times$ 定圧比熱」で表されることを示している．
これは，重力による位置エネルギーの寄与が，定圧比熱 $c_p$ の中にうまく組み込まれていることを意味している．
