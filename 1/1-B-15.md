# 演習問題【1-B-15】

## 解答

### 1．空気柱の全エネルギーを求める

断面積 $S$ をもち，鉛直に立つ無限に高い空気柱を考える．
空気は一様な重力場 $g$ の中にある理想気体とし，熱平衡状態にあるものとする．

熱平衡状態では，温度 $T$ は高度 $z$ によらず一定である．
ただし，重力の影響があるため，空気の密度 $\rho(z)$ は高度とともに変化する．

ここで，空気の単位質量あたりの内部エネルギーを $u(T)$ ，空気柱全体の質量を $M$ ，空気のモル質量を $m$ とする．
また， $R$ はモル気体定数であり， $c_v$ ， $c_p$ はそれぞれ単位質量あたりの定積比熱，定圧比熱である．
位置エネルギーの基準は $z=0$ にとる．

高度 $z$ から $z+dz$ までの微小な空気部分の体積は $S\,dz$ であるから，その質量は

```math
dm=\rho(z)S\,dz
```

となる．
この部分の内部エネルギーは $\rho(z)S\,dz\,u(T)$ ，重力による位置エネルギーは $\rho(z)S\,dz\,gz$ である．
したがって，空気柱全体のエネルギー $E(T)$ は，内部エネルギーと位置エネルギーの和として，

```math
\boxed{
E(T)=S\int_0^\infty
\{u(T)+gz\}\rho(z)\,dz
}
\tag{1}
```

と表される．

### 2．密度の高度分布を求める

まず，密度 $\rho(z)$ が高度 $z$ によってどのように変化するかを求める．
静水圧平衡の式は，

```math
\frac{dp}{dz}=-\rho(z)g
\tag{2}
```

である．
一方，理想気体の状態方程式を密度で表すと，

```math
p=\frac{\rho RT}{m}
\tag{3}
```

となる．
ここで， $m$ は分子1個の質量ではなく，空気のモル質量である．

熱平衡状態では $T$ が一定であるため，式（3）を $z$ で微分すると，

```math
\frac{dp}{dz}
=\frac{RT}{m}\frac{d\rho}{dz}
```

となる．
これを式（2）に代入すれば，

```math
\frac{RT}{m}\frac{d\rho}{dz}=-\rho g
```

を得る．
両辺を整理すると，

```math
\frac{d\rho}{\rho}=-\frac{mg}{RT}\,dz
```

となる．
これを積分し，高度 $z=0$ での密度を $\rho(0)$ とすると，

```math
\ln\rho(z)=-\frac{mgz}{RT}+\mathrm{const.}
```

であるから，

```math
\boxed{
\rho(z)=\rho(0)
\exp\left(-\frac{mgz}{RT}\right)
}
\tag{4}
```

が得られる．
すなわち，空気の密度は高度とともに指数関数的に減少する．

次に，空気柱全体の質量 $M$ を求める．
質量は各高度にある空気の質量を積分したものであるから，

```math
M=S\int_0^\infty\rho(z)\,dz
```

となる．
式（4）を代入すると，

```math
M=S\rho(0)\int_0^\infty
\exp\left(-\frac{mgz}{RT}\right)dz
```

である．
積分を実行すれば，

```math
\begin{aligned}
M
&=S\rho(0)
\left[-\frac{RT}{mg}
\exp\left(-\frac{mgz}{RT}\right)\right]_0^\infty\\
&=S\rho(0)\frac{RT}{mg}
\end{aligned}
```

を得る．
したがって，

```math
S\rho(0)=\frac{Mmg}{RT}
```

である．
これを式（4）に代入すれば，

```math
\boxed{
S\rho(z)=\frac{Mmg}{RT}
\exp\left(-\frac{mgz}{RT}\right)
}
\tag{5}
```

と表せる．
この式を用いることで，密度分布を空気柱全体の質量 $M$ によって表すことができる．

### 3．空気柱全体のエネルギーを計算する

式（5）を式（1）に代入すると，

```math
E(T)=\int_0^\infty
\{u(T)+gz\}
\frac{Mmg}{RT}
\exp\left(-\frac{mgz}{RT}\right)dz
```

となる．
ここで，積分を簡単にするため，

```math
\xi=\frac{mgz}{RT}
```

とおく．
すると，

```math
z=\frac{RT}{mg}\xi,\qquad
dz=\frac{RT}{mg}\,d\xi
```

となり，積分範囲は $z=0$ から $z=\infty$ に対して， $\xi=0$ から $\xi=\infty$ となる．
これらを代入すると，

```math
E(T)=M\int_0^\infty
\left\{u(T)+\frac{RT}{m}\xi\right\}
e^{-\xi}\,d\xi
```

を得る．
積分を項ごとに分ければ，

```math
\begin{aligned}
E(T)
&=M\left[
u(T)\int_0^\infty e^{-\xi}\,d\xi
+\frac{RT}{m}\int_0^\infty \xi e^{-\xi}\,d\xi
\right]
\end{aligned}
```

となる．
ここで，

```math
\int_0^\infty e^{-\xi}\,d\xi=1
```

および，

```math
\int_0^\infty \xi e^{-\xi}\,d\xi=1
```

である．
後者は部分積分によって求められる．
したがって，

```math
\begin{aligned}
E(T)
&=M\left[u(T)+\frac{RT}{m}\right]
\end{aligned}
```

となる．
よって，空気柱全体のエネルギーは，

```math
\boxed{
E(T)=M\left(u(T)+\frac{RT}{m}\right)
}
\tag{6}
```

で表される．
この式の第1項は内部エネルギー，第2項は重力による位置エネルギーの総和に対応する．

### 4．熱容量を求める

熱容量 $C$ は，空気柱全体の質量 $M$ を一定に保って温度を変化させたときの，全エネルギー $E(T)$ の温度に対する変化率として，

```math
C=\frac{dE}{dT}
```

と定義される．
式（6）を温度 $T$ で微分すると，

```math
\begin{aligned}
C
&=M\frac{d}{dT}
\left(u(T)+\frac{RT}{m}\right)\\
&=M\left(\frac{du}{dT}+\frac{R}{m}\right)
\end{aligned}
```

を得る．
ここで，単位質量あたりの定積比熱 $c_v$ の定義より，

```math
c_v=\frac{du}{dT}
```

であるから，

```math
\boxed{
C=M\left(c_v+\frac{R}{m}\right)
}
\tag{7}
```

となる．

最後に，単位質量あたりの比熱に対するマイヤーの関係式

```math
c_p-c_v=\frac{R}{m}
```

を用いると，

```math
c_v+\frac{R}{m}=c_p
```

である．
したがって，式（7）は，

```math
\boxed{
C=Mc_p
}
```

となる．

よって，重力場内にある無限に高い理想気体の空気柱の熱容量は，空気柱全体の質量 $M$ と空気の定圧比熱 $c_p$ の積で与えられることが示された．

## 解説

この問題では，重力場によって密度が高度とともに変化する空気柱について，内部エネルギーと位置エネルギーの両方を考慮して熱容量を求めた．

重要な点は，空気柱の温度が一様であっても，密度は一様ではないことである．
静水圧平衡と理想気体の状態方程式から密度の高度分布を求め，全質量が一定であることを利用してエネルギーを積分すると，

```math
E(T)=M\left(u(T)+\frac{RT}{m}\right)
```

が得られる．
ここで， $\frac{RT}{m}$ は重力による位置エネルギーの寄与を表している．

この式を温度で微分すると，熱容量には内部エネルギーの変化だけでなく，温度上昇に伴う密度分布の変化によって生じる位置エネルギーの変化も寄与する．
その結果，

```math
C=M\left(c_v+\frac{R}{m}\right)=Mc_p
```

となる．
したがって，重力場内の空気柱全体の熱容量は，定積比熱ではなく，定圧比熱を用いて表される．
