# 演習問題【1-A-8】

## 解答

### 1．大気の圧力の高度変化

空気が上昇するときの気温変化を求めるには，まず，高度 $z$ によって大気の圧力 $p(z)$ がどのように変化するかを調べる必要がある．

高度 $z$ から $z+dz$ までの間にある，底面積 $S$ ，厚さ $dz$ の微小な空気の柱を考える．
空気の密度を $\rho(z)$ ，重力加速度を $g$ とする．
この空気の柱には，上面に作用する下向きの圧力，下面に作用する上向きの圧力，および下向きの重力がはたらく．

鉛直方向の力のつりあいより，

```math
-p(z+dz)S+p(z)S-\rho(z)S\,dz\,g=0
```

となる．
これを整理すると，

```math
-\frac{p(z+dz)-p(z)}{dz}=\rho(z)g
```

である．
ここで， $dz$ を十分小さくして極限をとると，

```math
\boxed{
\frac{dp}{dz}=-\rho g
}
\tag{1}
```

を得る．
これは静水圧平衡の式であり，高度が上がるほど圧力が低下することを表している．

次に，理想気体の状態方程式を用いて，密度 $\rho$ を圧力 $p$ と温度 $T$ で表す．
気体全体の質量を $m_{\mathrm{gas}}$ ，モル質量を $M$ ，物質量を $n$ とすると，

```math
pV=nRT=\frac{m_{\mathrm{gas}}}{M}RT
```

である．
一方，密度の定義から，

```math
\rho=\frac{m_{\mathrm{gas}}}{V}
```

なので， $V=m_{\mathrm{gas}}/\rho$ である．
これを状態方程式に代入すると，

```math
p\frac{m_{\mathrm{gas}}}{\rho}
=\frac{m_{\mathrm{gas}}}{M}RT
```

となる．
両辺を $m_{\mathrm{gas}}$ で割れば，

```math
\frac{p}{\rho}=\frac{RT}{M}
```

を得る．
したがって，

```math
\boxed{
\rho=\frac{pM}{RT}
}
\tag{2}
```

である．

式（2）を式（1）に代入すると，

```math
\frac{dp}{dz}
=-\frac{pM}{RT}g
```

すなわち，

```math
\boxed{
\frac{dp}{dz}=-\frac{Mg}{RT}p
}
\tag{3}
```

となる．

### 2．断熱変化による温度と圧力の関係

空気の塊が上昇すると，周囲の大気圧が低くなるため，空気の塊は膨張する．
本問では，この膨張を準静的な断熱過程とみなす．
断熱過程とは，周囲との間に熱の出入りがない状態変化である．

理想気体の準静的断熱過程では，ポアソンの法則

```math
pV^\gamma=\mathrm{const.}
```

が成り立つ．
ここで， $\gamma=C_P/C_V$ は比熱比であり， $C_P$ と $C_V$ はそれぞれ気体全体の定圧熱容量と定積熱容量を表す．

ポアソンの法則の両辺を微分すると，

```math
V^\gamma dp+\gamma pV^{\gamma-1}dV=0
```

となる．
両辺を $pV^\gamma$ で割れば，

```math
\frac{dp}{p}+\gamma\frac{dV}{V}=0
\tag{4}
```

を得る．

一方，理想気体の状態方程式

```math
pV=nRT
```

を微分すると，

```math
\frac{dp}{p}+\frac{dV}{V}=\frac{dT}{T}
\tag{5}
```

となる．
式（4）から，

```math
\frac{dV}{V}=-\frac{1}{\gamma}\frac{dp}{p}
```

である．
これを式（5）に代入すると，

```math
\frac{dT}{T}
=\frac{dp}{p}-\frac{1}{\gamma}\frac{dp}{p}
```

となる．
整理すれば，

```math
\frac{dT}{T}
=\frac{\gamma-1}{\gamma}\frac{dp}{p}
```

である．
したがって，断熱過程における温度の圧力に対する変化率は，

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_{\mathrm{ad}}
=\frac{\gamma-1}{\gamma}\frac{T}{p}
}
\tag{6}
```

となる．

### 3．気温の高度変化率の導出

求めたいのは，温度 $T$ の高度 $z$ に対する変化率 $dT/dz$ である．
上昇する空気の塊は，準静的に周囲の大気圧とつり合っていると仮定するため，空気の塊の圧力を高度 $z$ における圧力 $p(z)$ とみなせる．
したがって，温度の高度変化率は連鎖律により，

```math
\frac{dT}{dz}
=\left(\frac{\partial T}{\partial p}\right)_{\mathrm{ad}}
\frac{dp}{dz}
```

と表される．

式（3）と式（6）を代入すると，

```math
\begin{aligned}
\frac{dT}{dz}
&=\frac{\gamma-1}{\gamma}\frac{T}{p}
\left(-\frac{Mg}{RT}p\right)\\
&=-\frac{(\gamma-1)Mg}{\gamma R}
\end{aligned}
```

となる．
よって，求める気温の高度変化率は，

```math
\boxed{
\frac{dT}{dz}=-\frac{(\gamma-1)Mg}{\gamma R}
}
```

である．
この式では，温度 $T$ と圧力 $p$ が相殺されるため， $\gamma$ ， $M$ ， $g$ ， $R$ を一定とする本モデルでは，気温の高度変化率は一定になる．
マイナス符号は，高度が上昇すると温度が低下することを表している．

### 4．数値計算

空気について，次の値を用いる．

```math
\begin{aligned}
\gamma&=1.41,\\
M&=29\,\mathrm{g/mol}
=0.029\,\mathrm{kg/mol},\\
g&=9.8\,\mathrm{m/s^2},\\
R&=8.31\,\mathrm{J/(mol\,K)}
\end{aligned}
```

これらを気温変化率の式に代入すると，

```math
\begin{aligned}
\frac{dT}{dz}
&=-\frac{(1.41-1)\times0.029\times9.8}
{1.41\times8.31}\\
&\simeq-9.94\times10^{-3}\,\mathrm{K/m}
\end{aligned}
```

を得る．
これを $1\,\mathrm{km}=1000\,\mathrm{m}$ あたりに換算すると，

```math
\frac{dT}{dz}\simeq-9.94\,\mathrm{K/km}
```

となる．
温度差については， $1\,\mathrm{K}$ と $1^\circ\mathrm{C}$ の大きさが等しいため，

```math
\boxed{
\frac{dT}{dz}\simeq-9.94^\circ\mathrm{C/km}
}
```

である．
したがって，高度が $1\mathrm{km}$ 上昇すると，気温は約 $10.0^\circ\mathrm{C}$ 低下する．

## 解説

本問では，静水圧平衡と断熱変化の2つの関係を組み合わせて，気温の高度変化率を導いた．
静水圧平衡は，重力と圧力差がつり合うことで圧力が高度とともに低下することを表す．
一方，断熱変化では，空気の塊が周囲から熱を受け取らずに膨張するため，内部エネルギーが減少し，温度が下がる．

この計算で得られた約 $10^\circ\mathrm{C/km}$ は，乾燥した理想気体が準静的に断熱膨張するという仮定に基づく理論値である．
実際の大気では，水蒸気の凝結による潜熱の放出などが温度低下に影響する．
そのため，湿った空気塊の気温低下率は，乾燥断熱過程の値より小さくなることがある．
また，実際の環境気温減率は場所や天候，高度などによって変わり，約 $6.5^\circ\mathrm{C/km}$ は標準大気における平均的な目安であって，常に成り立つ値ではない．
