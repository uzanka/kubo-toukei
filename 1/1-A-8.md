# 演習問題【1-A-8】

## 解答

### 1．大気の圧力の高度変化

空気が上昇するときの気温変化を求めるため，まず，高度 $z$ によって大気の圧力 $p(z)$ がどのように変化するかを調べる．

本問では，周囲の大気自体が静水圧平衡にあり，その鉛直方向の温度分布が乾燥断熱過程に従うものとする．
また，空気は理想気体とし，モル質量 $M$ ，比熱比 $\gamma$ ，重力加速度 $g$ は一定とする．
水蒸気の凝結および熱交換は無視する．

ここで，静水圧平衡にある周囲の大気の圧力，密度，温度をそれぞれ $p(z)$ ， $\rho(z)$ ， $T(z)$ とする．

高度 $z$ から $z+dz$ までの間にある，底面積 $S$ ，厚さ $dz$ の微小な空気の柱を考える．
この空気の柱には，上面に作用する下向きの圧力，下面に作用する上向きの圧力，および下向きの重力がはたらく．

鉛直方向の力のつりあいより，

```math
-p(z+dz)S+p(z)S-\rho(z)S\,dz\,g=0
```

となる．
これを整理すると，

```math
-\frac{p(z+dz)-p(z)}{dz}=\rho(z)g
```

である．
ここで， $dz$ を十分小さくして極限をとると，

```math
\boxed{
\frac{dp}{dz}=-\rho g
}
\tag{1}
```

を得る．
これは静水圧平衡の式であり，高度が上がるほど圧力が低下することを表している．

次に，理想気体の状態方程式を用いて，密度 $\rho$ を圧力 $p$ と温度 $T$ で表す．

気体全体の質量を $m_{\mathrm{gas}}$ ，モル質量を $M$ ，物質量を $n$ とすると，

```math
pV=nRT=\frac{m_{\mathrm{gas}}}{M}RT
```

である．
一方，密度の定義から，

```math
\rho=\frac{m_{\mathrm{gas}}}{V}
```

なので，

```math
V=\frac{m_{\mathrm{gas}}}{\rho}
```

である．
これを状態方程式に代入すると，

```math
p\frac{m_{\mathrm{gas}}}{\rho}
=\frac{m_{\mathrm{gas}}}{M}RT
```

となる．
両辺を $m_{\mathrm{gas}}$ で割れば，

```math
\frac{p}{\rho}=\frac{RT}{M}
```

を得る．
したがって，

```math
\boxed{
\rho=\frac{pM}{RT}
}
\tag{2}
```

である．

式（2）を式（1）に代入すると，

```math
\frac{dp}{dz}
=-\frac{pM}{RT}g
```

すなわち，

```math
\boxed{
\frac{dp}{dz}=-\frac{Mg}{RT}p
}
\tag{3}
```

となる．

### 2．断熱変化による温度と圧力の関係

本問では，周囲の大気自体が乾燥断熱的な温度分布を持つと仮定している．
したがって，静水圧平衡にある大気の状態量 $p(z)$ ， $T(z)$ ， $V(z)$ に対して，準静的断熱過程の関係式を適用できる．

理想気体の準静的断熱過程では，ポアソンの法則

```math
pV^\gamma=\mathrm{const.}
```

が成り立つ．
ここで，

```math
\gamma=\frac{C_P}{C_V}
```

は比熱比であり， $C_P$ と $C_V$ はそれぞれ気体全体の定圧熱容量と定積熱容量を表す．

ポアソンの法則の両辺を微分すると，

```math
V^\gamma dp+\gamma pV^{\gamma-1}dV=0
```

となる．
両辺を $pV^\gamma$ で割れば，

```math
\frac{dp}{p}+\gamma\frac{dV}{V}=0
\tag{4}
```

を得る．

一方，理想気体の状態方程式

```math
pV=nRT
```

を微分すると，

```math
\frac{dp}{p}+\frac{dV}{V}=\frac{dT}{T}
\tag{5}
```

となる．

式（4）から，

```math
\frac{dV}{V}
=-\frac{1}{\gamma}\frac{dp}{p}
```

である．
これを式（5）に代入すると，

```math
\frac{dT}{T}
=\frac{dp}{p}
-\frac{1}{\gamma}\frac{dp}{p}
```

となる．
整理すれば，

```math
\frac{dT}{T}
=\frac{\gamma-1}{\gamma}\frac{dp}{p}
```

である．

したがって，断熱変化における温度の圧力に対する変化率は，

```math
\boxed{
\left(\frac{\partial T}{\partial p}\right)_{\mathrm{ad}}
=\frac{\gamma-1}{\gamma}\frac{T}{p}
}
\tag{6}
```

となる．

### 3．気温の高度変化率の導出

求めたいのは，乾燥断熱的な温度分布を持つ大気の温度 $T$ の高度 $z$ に対する変化率 $dT/dz$ である．

本モデルでは，大気自体が静水圧平衡にあり，その温度分布が断熱関係に従うため，静水圧平衡の式と断熱変化の式を同一の大気について適用できる．
したがって，連鎖律により，

```math
\frac{dT}{dz}
=
\left(\frac{\partial T}{\partial p}\right)_{\mathrm{ad}}
\frac{dp}{dz}
```

と表される．

式（3）と式（6）を代入すると，

```math
\begin{aligned}
\frac{dT}{dz}
&=\frac{\gamma-1}{\gamma}\frac{T}{p}
\left(-\frac{Mg}{RT}p\right)\\
&=-\frac{(\gamma-1)Mg}{\gamma R}
\end{aligned}
```

となる．

よって，求める気温の高度変化率は，

```math
\boxed{
\frac{dT}{dz}
=-\frac{\gamma-1}{\gamma}\frac{Mg}{R}
}
```

である．

この式では，温度 $T$ と圧力 $p$ が相殺されるため， $\gamma$ ， $M$ ， $g$ ， $R$ を一定とする本モデルでは，気温の高度変化率は一定になる．
マイナス符号は，高度が上昇すると温度が低下することを表している．

### 4．数値計算

空気について，次の値を用いる．

```math
\begin{aligned}
\gamma&=1.41,\\
M&=29\,\mathrm{g/mol}
=0.029\,\mathrm{kg/mol},\\
g&=9.8\,\mathrm{m/s^2},\\
R&=8.31\,\mathrm{J/(mol\,K)}
\end{aligned}
```

これらを気温変化率の式に代入すると，

```math
\begin{aligned}
\frac{dT}{dz}
&=-\frac{(1.41-1)\times0.029\times9.8}
{1.41\times8.31}\\
&\simeq-9.94\times10^{-3}\,\mathrm{K/m}
\end{aligned}
```

を得る．

これを $1\,\mathrm{km}=1000\,\mathrm{m}$ あたりに換算すると，

```math
\frac{dT}{dz}\simeq-9.94\,\mathrm{K/km}
```

となる．

温度差については， $1\,\mathrm{K}$ と $1^\circ\mathrm{C}$ の大きさが等しいため，

```math
\boxed{
\frac{dT}{dz}\simeq-9.94^\circ\mathrm{C/km}
}
```

である．
したがって，高度が $1\,\mathrm{km}$ 上昇すると，気温は約 $9.94^\circ\mathrm{C}$ 低下する．

### 解説

本問では，周囲の大気が静水圧平衡にあり，かつ乾燥断熱的な温度分布を持つという理想化されたモデルを考えた．

静水圧平衡の式

```math
\frac{dp}{dz}=-\rho g
```

と，理想気体の状態方程式

```math
\rho=\frac{pM}{RT}
```

から，大気の圧力の高度変化が求められる．

一方，準静的断熱過程ではポアソンの関係式が成立し，

```math
\frac{dT}{T}
=\frac{\gamma-1}{\gamma}\frac{dp}{p}
```

が得られる．

この二つの関係を同一の大気について組み合わせることで，

```math
\frac{dT}{dz}
=-\frac{\gamma-1}{\gamma}\frac{Mg}{R}
```

が導かれる．

このモデルでは， $\gamma$ ， $M$ ， $g$ ， $R$ を一定とするため，温度の高度変化率も一定となる．

数値計算の結果，

```math
\boxed{
\frac{dT}{dz}\simeq-9.94\,\mathrm{K/km}
}
```

となり，高度が $1\,\mathrm{km}$ 上昇すると気温は約 $9.94^\circ\mathrm{C}$ 低下する．

この値は乾燥断熱減率に相当する理論値である．

ただし，これは周囲の大気自体が乾燥断熱的な温度分布を持つという理想化された条件に基づく．
一般の大気中を上昇する空気塊の温度低下率を求める場合には，周囲の大気の温度分布と空気塊自身の温度を区別する必要がある．

実際の大気では，水蒸気の凝結による潜熱の放出，熱交換，空気の組成や比熱の変化などが温度低下率に影響する．
そのため，現実の大気の温度減率は，乾燥断熱減率と必ずしも一致しない．
