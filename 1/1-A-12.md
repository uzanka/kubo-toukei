# 演習問題【1-A-12】

## 解答

### 1．臨界体積 $V_c$ ，臨界温度 $T_c$ ，臨界圧力 $p_c$ の導出

与えられた Dieterici の状態方程式は，

```math
p=\frac{nRT}{V-nb}
\exp\left(-\frac{na}{RTV}\right)
\tag{1}
```

である．
ここで， $p$ は圧力， $V$ は体積， $T$ は絶対温度， $n$ は物質量， $R$ はモル気体定数， $a,b$ は物質定数である．

臨界点では，圧力 $p$ を体積 $V$ の関数として表した等温線が水平な変曲点となるため，次の2つの条件が成り立つ．

```math
\left(\frac{\partial p}{\partial V}\right)_T=0,
\qquad
\left(\frac{\partial^2p}{\partial V^2}\right)_T=0
\tag{2}
```

まず，式（1）の両辺の自然対数をとると，

```math
\ln p=\ln(nRT)-\ln(V-nb)-\frac{na}{RTV}
```

となる．
これを体積 $V$ で偏微分すると，

```math
\left(\frac{\partial p}{\partial V}\right)_T
=p\left[
-\frac{1}{V-nb}
+\frac{na}{RTV^2}
\right]
```

を得る．
臨界点では1階微分がゼロであるから，

```math
-\frac{1}{V_c-nb}
+\frac{na}{RT_cV_c^2}=0
```

となる．
これを整理すると，

```math
\boxed{
\frac{V_c^2}{V_c-nb}=\frac{na}{RT_c}
}
\tag{3}
```

が得られる．

次に，2階微分を考える．

```math
\begin{aligned}
\left(\frac{\partial^2p}{\partial V^2}\right)_T
={}&p\left[
-\frac{1}{V-nb}+\frac{na}{RTV^2}
\right]^2\\
&+p\left[
\frac{1}{(V-nb)^2}-\frac{2na}{RTV^3}
\right]
\end{aligned}
```

臨界点では1階微分がゼロであるため，上式の第1項はゼロとなる．
したがって，2階微分がゼロという条件から，

```math
\frac{1}{(V_c-nb)^2}
-\frac{2na}{RT_cV_c^3}=0
```

を得る．
これを整理すると，

```math
\boxed{
\frac{V_c^3}{(V_c-nb)^2}=\frac{2na}{RT_c}
}
\tag{4}
```

となる．

式（4）を式（3）で割ると，

```math
\frac{V_c}{V_c-nb}=2
```

である．
よって，

```math
V_c=2(V_c-nb)
```

となり，これを整理すれば，

```math
V_c=2V_c-2nb
```

を得る．
したがって，臨界体積は，

```math
\boxed{
V_c=2nb
}
\tag{5}
```

である．

次に，式（5）を式（3）に代入して臨界温度 $T_c$ を求める．

```math
\frac{(2nb)^2}{2nb-nb}=\frac{na}{RT_c}
```

左辺を整理すると，

```math
4nb=\frac{na}{RT_c}
```

となる．
これを $T_c$ について解けば，

```math
\boxed{
T_c=\frac{a}{4Rb}
}
\tag{6}
```

が得られる．

最後に，臨界体積と臨界温度を元の状態方程式に代入して，臨界圧力 $p_c$ を求める．

```math
p_c=
\frac{nRT_c}{V_c-nb}
\exp\left(-\frac{na}{RT_cV_c}\right)
```

式（5），（6）より，

```math
\begin{aligned}
\frac{nRT_c}{V_c-nb}
&=\frac{nR\left(\dfrac{a}{4Rb}\right)}{2nb-nb}\\
&=\frac{na/(4b)}{nb}\\
&=\frac{a}{4b^2}
\end{aligned}
```

である．
また，指数部分は，

```math
\begin{aligned}
\frac{na}{RT_cV_c}
&=\frac{na}
{R\left(\dfrac{a}{4Rb}\right)(2nb)}\\
&=2
\end{aligned}
```

となる．
したがって，

```math
p_c=\frac{a}{4b^2}e^{-2}
```

を得る．
よって，臨界圧力は，

```math
\boxed{
p_c=\frac{a}{4e^2b^2}
}
\tag{7}
```

である．

以上より，臨界点における圧力，体積，温度はそれぞれ，

```math
\boxed{
p_c=\frac{a}{4e^2b^2},\qquad
V_c=2nb,\qquad
T_c=\frac{a}{4Rb}
}
```

となることが示された．

### 2．対応状態の法則を示す形への書き換え

対応状態の法則を示すために，圧力，体積，温度をそれぞれの臨界値で割った無次元量を導入する．
これらを縮約圧力 $P$ ，縮約体積 $v$ ，縮約温度 $t$ とすると，

```math
P=\frac{p}{p_c},\qquad
v=\frac{V}{V_c},\qquad
t=\frac{T}{T_c}
```

である．
したがって，

```math
p=p_cP,\qquad V=V_cv,\qquad T=T_ct
\tag{8}
```

と表される．

式（8）を元の状態方程式（1）に代入すると，

```math
p_cP=
\frac{nRT_ct}{V_cv-nb}
\exp\left(-\frac{na}{RT_cV_ctv}\right)
\tag{9}
```

となる．

まず，式（5），（6）を用いて，式（9）の分数部分を整理する．

```math
\begin{aligned}
\frac{nRT_ct}{V_cv-nb}
&=\frac{nR\left(\dfrac{a}{4Rb}\right)t}{2nbv-nb}\\
&=\frac{na t/(4b)}{nb(2v-1)}\\
&=\frac{at}{4b^2(2v-1)}
\end{aligned}
```

一方，式（7）から，

```math
p_c=\frac{a}{4e^2b^2}
```

であるため，

```math
\frac{a}{4b^2}=e^2p_c
```

が成り立つ．
よって，

```math
\boxed{
\frac{nRT_ct}{V_cv-nb}
=\frac{p_ce^2t}{2v-1}
}
\tag{10}
```

となる．
ここで，温度の縮約量 $t$ は分子に残ることに注意する．

次に，式（9）の指数部分を整理する．

```math
\begin{aligned}
\frac{na}{RT_cV_c}
&=\frac{na}
{R\left(\dfrac{a}{4Rb}\right)(2nb)}\\
&=2
\end{aligned}
```

したがって，

```math
\exp\left(-\frac{na}{RT_cV_ctv}\right)
=\exp\left(-\frac{2}{tv}\right)
\tag{11}
```

となる．

式（10），（11）を式（9）に代入すると，

```math
p_cP=
\frac{p_ce^2t}{2v-1}
\exp\left(-\frac{2}{tv}\right)
```

を得る．
両辺を $p_c$ で割れば，

```math
\boxed{
P=\frac{e^2t}{2v-1}
\exp\left(-\frac{2}{tv}\right)
}
```

となる．
さらに， $e^2=\exp(2)$ を用いて指数をまとめると，

```math
\boxed{
P=\frac{t}{2v-1}
\exp\left(2-\frac{2}{tv}\right)
}
```

とも表される．

この式には，元の状態方程式に含まれていた物質定数 $a,b$ と物質量 $n$ が現れない．
したがって，臨界値を基準とした無次元量を用いることで，Dieterici の状態方程式は，物質固有の定数に依存しない共通の形に書き換えられた．
これが対応状態の法則を示す表現である．

## 解説

臨界点は， $pV$ 図において等温線が水平な変曲点となる状態である．
そのため，圧力の体積に対する1階微分と2階微分がともにゼロになるという条件を利用して，臨界体積と臨界温度を求めることができる．
次に，これらの値を元の状態方程式に代入すれば，臨界圧力が得られる．

また，対応状態の法則では，圧力，体積，温度をそれぞれ臨界値で割ることで，無次元の縮約量を導入する．
この操作によって，Dieterici の状態方程式から物質定数 $a,b$ が消え，異なる物質についても共通の形で表現できる．

なお，縮約状態方程式の分数部分を計算する際には， $T=T_ct$ と置き換えたため，分子に縮約温度 $t$ が残る．
この因子を落とさないことが，正しい対応状態の式を導くうえで重要である．
