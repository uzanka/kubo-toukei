# 演習問題【1-A-13】

## 解答

空気を酸素 $\mathrm{O_2}$ と窒素 $\mathrm{N_2}$ の混合気体と考え，混合気体の定積比熱 $c_v$ を求める．

### 1．混合気体の定積比熱の公式の導出

混合気体の全質量を $M$ ，成分気体 $i$ の質量を $M_i$ ，その定積比熱を $c_{vi}$ とする．
また，混合気体全体の内部エネルギーを $U$ ，単位質量あたりの内部エネルギーを $u$ とすると，

```math
U=Mu
```

という関係が成り立つ．

化学反応が起こらない理想気体の混合物では，全内部エネルギーは各成分気体の内部エネルギーの和で表されるため，

```math
U=\sum_i U_i
```

となる．

混合気体の温度が微小量 $dT$ だけ変化するとき，各成分の定積比熱は一定であるから，成分気体 $i$ の内部エネルギー変化は，

```math
dU_i=M_i c_{vi}\,dT
```

と表される．
したがって，混合気体全体の内部エネルギー変化は，

```math
dU=\sum_i dU_i
=\sum_i M_i c_{vi}\,dT
```

となる．
一方，混合気体全体の定積比熱を $c_v$ とすると，その定義から，

```math
dU=M c_v\,dT
```

である．
これらの式を等しいとおけば，

```math
M c_v\,dT=\sum_i M_i c_{vi}\,dT
```

となる．
両辺を $M\,dT$ で割ると，

```math
\boxed{
c_v=\sum_i\frac{M_i}{M}c_{vi}
}
```

が得られる．

ここで，各成分気体の質量分率を

```math
w_i=\frac{M_i}{M}
```

と定義すると，

```math
\boxed{
c_v=\sum_i w_i c_{vi}
}
```

と書ける．
すなわち， **混合気体の定積比熱は，各成分気体の定積比熱を質量分率で重みづけした加重平均となる．**

### 2．空気の定積比熱の計算

問題より，酸素と窒素の重量比は $23:77$ である．
したがって，それぞれの質量分率は，

```math
w_{\mathrm{O_2}}=\frac{23}{23+77}=0.23
```

```math
w_{\mathrm{N_2}}=\frac{77}{23+77}=0.77
```

となる．

また，各成分気体の定積比熱は，

```math
c_{v,\mathrm{O_2}}=0.158\,
\mathrm{cal/(g\,deg)}
```

```math
c_{v,\mathrm{N_2}}=0.176\,
\mathrm{cal/(g\,deg)}
```

である．
これらを加重平均の式に代入すると，

```math
\begin{aligned}
c_v
&=w_{\mathrm{O_2}}c_{v,\mathrm{O_2}}
+w_{\mathrm{N_2}}c_{v,\mathrm{N_2}}\\
&=0.23\times0.158+0.77\times0.176\\
&=0.03634+0.13552\\
&=0.17186\,\mathrm{cal/(g\,deg)}
\end{aligned}
```

を得る．
有効数字3桁に丸めると，

```math
\boxed{
c_v=0.172\,\mathrm{cal/(g\,deg)}
}
```

となる．

したがって，求める空気の定積比熱は，

```math
\boxed{
0.172\,\mathrm{cal/(g\,deg)}
}
```

である．

## 解説

混合気体の定積比熱が加重平均となるのは，混合気体全体の内部エネルギー変化が，各成分気体の内部エネルギー変化の和になるためである．
各成分の温度変化は共通であり，それぞれの内部エネルギー変化は，成分の質量と定積比熱の積 $M_i c_{vi}$ に比例する．
したがって，全体の定積比熱は，各成分の定積比熱を質量分率で重みづけして求められる．

なお，本問で与えられた比熱の単位 $\mathrm{cal/(g\,deg)}$ における $\mathrm{deg}$ は温度差を表す．
温度差については $1\,\mathrm{K}$ と $1^\circ\mathrm{C}$ の大きさが等しいため，単位を $\mathrm{cal/(g\,K)}$ としても数値は変わらない．

また，重量比が与えられている場合には質量分率を用いる．
モル比が与えられている場合には，モル比熱を用いるか，質量比に換算してから計算する必要がある．
