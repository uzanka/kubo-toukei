# 演習問題【1-C-24】

## 解答

非一様な磁場 $\mathbf{H}$ ，磁化 $\mathbf{M}$ ，および磁束密度 $\mathbf{B}$ を持つ磁性体におけるエネルギー収支を、Maxwell 方程式を用いて導出する．

### 1. 基本方程式の準備

まず，磁性体における Maxwell 方程式を考える．
変位電流を無視する場合、以下の式が成り立つ：

1.  **Ampère の法則** :
  $\text{rot } \mathbf{H} = \frac{4\pi}{c} \mathbf{j}$
2.  **Faraday の誘導則** :
  $\text{rot } \mathbf{E} = -\frac{1}{c} \frac{\partial \mathbf{B}}{\partial t}$
3.  **磁束密度の発散** :
  $\text{div } \mathbf{B} = 0$

ここで，磁場 $\mathbf{H}$ は，電流 $\mathbf{j}$ によって生じる部分 $\mathbf{H}_{\text{J}}$ と，磁化 $\mathbf{M}$ による部分 $\mathbf{H}_{\text{M}}$ の和として表される：

$$\mathbf{H} = \mathbf{H}_{\text{J}} + \mathbf{H}_{\text{M}}$$

これらについては以下の性質を持つ：
- $\text{rot } \mathbf{H}_{\text{J}} = \frac{4\pi}{c} \mathbf{j}, \quad \text{div } \mathbf{H}_{\text{J}} = 0$
- $\text{rot } \mathbf{H}_{\text{M}} = 0, \quad \text{div } \mathbf{H}_{\text{M}} = -4\pi \text{div } \mathbf{M}$

### 2. 全空間におけるエネルギー収支の導出

ベクトル解析の公式 $\text{div}(\mathbf{H} \times \mathbf{E}) = \mathbf{E} \cdot \text{rot } \mathbf{H} - \mathbf{H} \cdot \text{rot } \mathbf{E}$ を用いる．
式(1) $\times \frac{c}{4\pi}$ と式(2) $\times (-c\mathbf{H})$ を加えると，

$$\mathbf{E} \cdot \text{rot } \mathbf{H} - \mathbf{H} \cdot \text{rot } \mathbf{E} = \mathbf{E} \cdot \left( \frac{4\pi}{c} \mathbf{j} \right) - \mathbf{H} \cdot \left( -\frac{1}{c} \frac{\partial \mathbf{B}}{\partial t} \right) = \frac{4\pi}{c} \left( \mathbf{E} \cdot \mathbf{j} + \frac{1}{4\pi} \mathbf{H} \cdot \frac{\partial \mathbf{B}}{\partial t} \right)$$

となる．
これを全空間で積分すると，ガウスの定理より，

$$\int \text{div}(\mathbf{H} \times \mathbf{E}) \, dV = \oint_{\infty} (\mathbf{H} \times \mathbf{E}) \cdot d\mathbf{S} = 0 \quad (\text{遠方で磁場が } 0 \text{ のため})$$

したがって，以下の関係が得られる：

$$\int \mathbf{E} \cdot \mathbf{j} \, dV + \frac{1}{4\pi} \int \mathbf{H} \cdot \frac{\partial \mathbf{B}}{\partial t} \, dV = 0 \quad \cdots (4)$$

### 3. 各項の物理的意味の解析

#### (i) 電流による仕事 $\int \mathbf{E} \cdot \mathbf{j} \, dV$

Ohm の法則 $\mathbf{E} = \rho \mathbf{j} - \mathbf{F}$ （$\mathbf{F}$ は印加起電力）を用いると，

$$\int \mathbf{E} \cdot \mathbf{j} \, dV = \int \rho j^2 \, dV - \int \mathbf{F} \cdot \mathbf{j} \, dV$$

ここで $\int \rho j^2 \, dV$ はジュール熱として失われるエネルギー， $\int \mathbf{F} \cdot \mathbf{j} \, dV$ は電池が外部へ供給する仕事である．

#### (ii) 磁場によるエネルギー変化 $\frac{1}{4\pi} \int \mathbf{H} \cdot \frac{\partial \mathbf{B}}{\partial t} \, dV$

$\mathbf{B} = \mathbf{H} + 4\pi \mathbf{M}$ を代入すると，

$$\frac{1}{4\pi} \int \mathbf{H} \cdot \frac{\partial (\mathbf{H} + 4\pi \mathbf{M})}{\partial t} \, dV = \frac{1}{4\pi} \int \mathbf{H} \cdot \frac{\partial \mathbf{H}}{\partial t} \, dV + \int \mathbf{H} \cdot \frac{\partial \mathbf{M}}{\partial t} \, dV$$

第1項は，磁場のエネルギー密度 $\frac{H^2}{8\pi}$ の時間変化率の積分に相当する：

$$\frac{1}{4\pi} \int \mathbf{H} \cdot \frac{\partial \mathbf{H}}{\partial t} \, dV = \frac{1}{4\pi} \frac{d}{dt} \int \frac{H^2}{2} \, dV = \frac{d}{dt} \int \frac{H^2}{8\pi} \, dV$$

第2項 $\int \mathbf{H} \cdot \frac{\partial \mathbf{M}}{\partial t} \, dV$ は，磁性体を磁化させるために必要な仕事率である．

### 4. 磁化のための仕事

磁化 $\mathbf{M}$ を $0$ から増やすために必要な仕事 $A$ は，磁化過程に沿った積分として以下のように書ける：

$$A = \int_{V} \left( \int_{0}^{\mathbf{M}} \mathbf{H} \cdot d\mathbf{M} \right) dV$$

ここで， $\mathbf{H} = \mathbf{H}_{\text{J}} + \mathbf{H}_{\text{M}}$ であるため，磁化による反磁場 $\mathbf{H}_{\text{M}}$ による仕事も含まれる点に注意が必要である．

## 解説

本問題は，磁場と磁化が空間的に一様でない複雑な状況において，エネルギーがどのように分配されるかを Maxwell 方程式から導出するものである．

### 反磁場の重要性

磁性体に磁場をかけると，磁性体自体が作る磁場（磁化 $\mathbf{M}$ による磁場 $\mathbf{H}_{\text{M}}$ ）が発生する．
これは外部磁場 $\mathbf{H}_{\text{J}}$ を打ち消す方向に働くことが多く，「反磁場」と呼ばれる．
磁性体を磁化するためには，外部磁場だけでなく，この反磁場に打ち勝つための仕事も必要となる．

### エネルギーの所在

エネルギーの収支は，以下の3つの主要な要素に分けられる：
1. **電気的なエネルギー** : 電流によるジュール熱および電池の仕事．
2. **磁場エネルギー** : 空間に蓄えられた磁場 $\mathbf{H}$ のエネルギー．
3. **磁化エネルギー** : 磁性体の内部状態（磁気モーメントの配列）を変化させるために使われるエネルギー．

### 楕円体近似

磁性体の形状が複雑な場合，反磁場 $\mathbf{H}_{\text{M}}$ の計算は非常に困難である．
しかし，磁性体が「楕円体」の形状をしている場合に限り，反磁場は磁化に比例し，かつ方向も一致するという非常に扱いやすい性質（ $\mathbf{H}_{\text{M}} = -N \mathbf{M}$ ）を持つ．
これが，実用的な計算における重要な近似となっている．
