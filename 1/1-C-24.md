# 演習問題【1-C-24】

## 解答

磁性体の磁化が空間的に一様でない場合には，磁場 $\mathbf H$ ，磁化 $\mathbf M$ ，磁束密度 $\mathbf B$ も一般に空間的に一様ではない．
このような場合，磁性体を磁化するために必要な仕事を求めるには，反磁場の効果を含め，Maxwell 方程式からエネルギー収支を導く必要がある．

以下では，解答例と同様に，変位電流を無視した Maxwell 方程式から出発し，電源の仕事，ジュール熱，磁場エネルギー，磁化に必要な仕事の関係を導く．
最後に，磁性体が楕円体の場合について考察する．

## 1．Maxwell 方程式

磁性体が静止しており，磁化が十分ゆっくり変化する準静的な過程を考える．
変位電流を無視すると，Gaussian 単位系における Maxwell 方程式は，

```math
\boxed{
\nabla\times\mathbf H=\frac{4\pi}{c}\mathbf j
}
\tag{1}
```

```math
\boxed{
\nabla\times\mathbf E =-\frac{1}{c}\frac{\partial\mathbf B}{\partial t}
}
\tag{2}
```

```math
\boxed{
\nabla\cdot\mathbf B=0
}
\tag{3}
```

となる．
ここで， $\mathbf E$ は電場， $\mathbf H$ は磁場， $\mathbf B$ は磁束密度， $\mathbf j$ は自由電流密度， $c$ は光速である．

また，磁場と磁化の間には，

```math
\boxed{
\mathbf B=\mathbf H+4\pi\mathbf M
}
\tag{4}
```

という関係がある．
式(3)，式(4)より，

```math
\nabla\cdot\mathbf H=-4\pi\nabla\cdot\mathbf M
\tag{5}
```

が得られる．
この式は，磁化が空間的に一様でない場合，磁場 $\mathbf H$ も一般には発散ゼロにならないことを示している．

## 2．磁場の電流成分と磁化成分への分解

磁場 $\mathbf H$ を，コイルなどの自由電流によって生じる成分 $\mathbf H_J$ と，磁化によって生じる成分 $\mathbf H_M$ に分ける．
すなわち，

```math
\boxed{
\mathbf H=\mathbf H_J+\mathbf H_M
}
\tag{6}
```

とする．
適切な境界条件のもとで，これらの成分は次の式を満たすように定められる．

電流による成分については，

```math
\nabla\times\mathbf H_J=\frac{4\pi}{c}\mathbf j, \qquad \nabla\cdot\mathbf H_J=0
\tag{7}
```

である．
一方，磁化による成分については，

```math
\nabla\times\mathbf H_M=0, \qquad \nabla\cdot\mathbf H_M=-4\pi\nabla\cdot\mathbf M
\tag{8}
```

となる．

式(8)の第1式より，スカラー・ポテンシャル $\varphi$ を用いて，

```math
\boxed{
\mathbf H_M=-\nabla\varphi
}
\tag{9}
```

と表せる．
これを式(8)の第2式に代入すると，

```math
\nabla^2\varphi=4\pi\nabla\cdot\mathbf M
\tag{10}
```

を得る．
したがって，磁化に起因する磁場 $\mathbf H_M$ は，磁化の空間分布と境界条件によって定まる．
この磁場が反磁場に対応する．

ここでいう磁荷は，磁化の発散を用いて磁場を計算するための数学的な表現であり，実在する磁気単極子を意味するものではない．

## 3．Maxwell 方程式からエネルギー収支を導く

### 3.1　ベクトル解析の恒等式を利用する

ベクトル解析の恒等式

```math
\nabla\cdot(\mathbf H\times\mathbf E) = \mathbf E\cdot(\nabla\times\mathbf H) -\mathbf H\cdot(\nabla\times\mathbf E)
\tag{11} 
```

を用いる．

式(1)の両辺に $\mathbf E$ を内積し，式(2)の両辺に $-\mathbf H$ を内積して加えると，

```math
\begin{aligned}
\nabla\cdot(\mathbf H\times\mathbf E) &=\frac{4\pi}{c}\mathbf E\cdot\mathbf j +\frac1c\mathbf H\cdot \frac{\partial\mathbf B}{\partial t} \\
&=\frac{4\pi}{c} \left( \mathbf E\cdot\mathbf j +\frac{1}{4\pi}\mathbf H\cdot \frac{\partial\mathbf B}{\partial t} \right)
\end{aligned}
\tag{12}
```

となる．

これを全空間で積分すると，

```math
\begin{aligned}
\int_{\mathbb R^3} \nabla\cdot(\mathbf H\times\mathbf E)\,dV &=\oint_{\infty}(\mathbf H\times\mathbf E) \cdot d\mathbf S \\
&=0
\end{aligned}
\tag{13}
```

となる．
ここでは，無限遠での電磁場の流束が消えることを仮定した．
境界からエネルギーが流出する場合には，式(13)の表面積分を残す必要がある．

したがって，式(12)から，

```math
\boxed{
\int_{\mathbb R^3}\mathbf E\cdot\mathbf j\,dV +\frac{1}{4\pi} \int_{\mathbb R^3} \mathbf H\cdot\frac{\partial\mathbf B}{\partial t}\,dV =0
}
\tag{14}
```

を得る．
これは，電場が電流にする仕事と磁場の変化に関係する項との間に成立するエネルギー収支である．

### 3.2　電流による仕事を求める

電流が流れる導体および電源の内部で，Ohm の法則を

```math
\mathbf E+\mathbf F=\rho\mathbf j
\tag{15}
```

とする．
ここで， $\rho$ は電気抵抗率， $\mathbf F$ は電源の印加起電力に対応する電場である．
この式を変形すると，

```math
\mathbf E=\rho\mathbf j-\mathbf F
```

となる．
したがって，

```math
\boxed{
\int\mathbf E\cdot\mathbf j\,dV = \int\rho j^2\,dV -\int\mathbf F\cdot\mathbf j\,dV
}
\tag{16}
```

である．

この式の第1項は，単位時間当たりにジュール熱として発生するエネルギーを表す．
第2項は，電源が電流を流すために供給する仕事率に対応する．

電源が単位時間当たりに供給する仕事を

```math
P_{\mathrm{source}} =\int\mathbf F\cdot\mathbf j\,dV
\tag{17}
```

と定義する．
式(14)，式(16)から，

```math
\boxed{
P_{\mathrm{source}} = \int\rho j^2\,dV +\frac{1}{4\pi} \int\mathbf H\cdot \frac{\partial\mathbf B}{\partial t}\,dV
}
\tag{18}
```

を得る．

### 3.3　磁場のエネルギーと磁化の仕事

式(4)の関係

```math
\mathbf B=\mathbf H+4\pi\mathbf M
```

を式(18)に代入する．
すると，

```math
\begin{aligned}
\frac{1}{4\pi} \int\mathbf H\cdot \frac{\partial\mathbf B}{\partial t}\,dV ={}& \frac{1}{4\pi} \int\mathbf H\cdot \frac{\partial\mathbf H}{\partial t}\,dV \\
&+\int\mathbf H\cdot \frac{\partial\mathbf M}{\partial t}\,dV
\end{aligned}
\tag{19}
```

となる．

第1項については，

```math
\mathbf H\cdot\frac{\partial\mathbf H}{\partial t} =\frac12\frac{\partial H^2}{\partial t}
```

であるため，

```math
\begin{aligned}
\frac{1}{4\pi} \int\mathbf H\cdot \frac{\partial\mathbf H}{\partial t}\,dV &=\frac{d}{dt} \int\frac{H^2}{8\pi}\,dV
\end{aligned}
\tag{20}
```

を得る．

したがって，電源の仕事率は，

```math
\boxed{
\begin{aligned}
P_{\mathrm{source}} ={}&\int\rho j^2\,dV +\frac{d}{dt}\int\_{\mathbb R^3} \frac{H^2}{8\pi}\,dV \\
&+\int\_{V_m} \mathbf H\cdot \frac{\partial\mathbf M}{\partial t}\,dV
\end{aligned}
}
\tag{21}
```

と書ける．
ここで $V_m$ は磁性体の体積である．
磁性体の外部では磁化がゼロなので，最後の積分は磁性体内で行えばよい．

式(21)は，電源から供給されるエネルギーが，ジュール熱，磁場エネルギーの変化，磁化に関係する仕事率に分配されることを示している．

## 4．電流による磁場と反磁場の直交性

解答例で用いられている

```math
\int_{\mathbb R^3} \mathbf H_J\cdot\mathbf H_M\,dV=0
\tag{22}
```

を証明する．

式(9)より，

```math
\begin{aligned}
\int_{\mathbb R^3} \mathbf H_J\cdot\mathbf H_M\,dV &=-\int_{\mathbb R^3} \mathbf H_J\cdot\nabla\varphi\,dV \\
&=-\int_{\mathbb R^3} \nabla\cdot(\varphi\mathbf H_J)\,dV \\
&\qquad +\int\_{\mathbb R^3} \varphi\nabla\cdot\mathbf H_J\,dV
\end{aligned}
\tag{23}
```

となる．
ここで式(7)の

```math
\nabla\cdot\mathbf H_J=0
```

を用いると，第2項はゼロである．
また，無限遠で境界項が消えるとすれば，第1項もゼロとなる．
したがって，

```math
\boxed{
\int_{\mathbb R^3} \mathbf H_J\cdot\mathbf H_M\,dV=0
}
\tag{24}
```

である．

これより，

```math
\begin{aligned}
\int_{\mathbb R^3}\frac{H^2}{8\pi}\,dV &=\int\_{\mathbb R^3} \frac{|\mathbf H_J+\mathbf H_M|^2}{8\pi}\,dV \\
&=\int_{\mathbb R^3}\frac{H_J^2}{8\pi}\,dV +\int\_{\mathbb R^3}\frac{H_M^2}{8\pi}\,dV
\end{aligned}
```

すなわち，

```math
\boxed{
\int_{\mathbb R^3}\frac{H^2}{8\pi}\,dV = \int_{\mathbb R^3}\frac{H_J^2}{8\pi}\,dV + \int_{\mathbb R^3}\frac{H_M^2}{8\pi}\,dV
}
\tag{25}
```

を得る．

この結果は，全空間で積分した場合の関係である．
磁性体の内部だけで積分した場合に，交差項が一般にゼロになるわけではない．

式(25)から分かるように，磁場のエネルギーには，コイルの電流による磁場のエネルギーだけでなく，磁化に伴う反磁場のエネルギーも含まれている．
そのため，磁場エネルギーの変化と，磁性体そのものを磁化するための仕事とを区別しなければならない．

## 5．磁化のための仕事

式(21)の最後の項は，

```math
P_{\mathrm{mag}} =\int_{V_m} \mathbf H\cdot\frac{\partial\mathbf M}{\partial t}\,dV
\tag{26}
```

である．
これは，磁化を変化させるための仕事率に対応する．
微小時間 $(dt$ の間に磁化が $d\mathbf M$ だけ変化するとき，磁化に必要な微小仕事は，

```math
\boxed{
d'A=\int_{V_m}\mathbf H\cdot d\mathbf M\,dV
}
\tag{27}
```

となる．
磁場の分解式(6)を代入すると，

```math
\boxed{
d'A=\int_{V_m} (\mathbf H_J+\mathbf H_M)\cdot d\mathbf M\,dV
}
\tag{28}
```

を得る．

ここで重要なのは，磁化の仕事を求める際には，コイルの電流が作る磁場 $\mathbf H_J$ だけでなく，磁性体自身の磁化による反磁場 $\mathbf H_M$ も考慮しなければならないという点である．

磁化をゼロから最終値 $\mathbf M$ まで変化させるのに必要な仕事は，その磁化過程に沿って積分することで，

```math
\boxed{
A=\int_{V_m} \left(\int_{\text{磁化過程}} \mathbf H\cdot d\mathbf M\right)dV
}
\tag{29}
```

と表される．

一般に磁場と磁化が空間的に一様でない場合，磁化仕事を単に磁性体の体積 $V_m$ と磁場，磁化の変化の積で表すことはできない．
磁性体内の各点で磁場と磁化が異なるため，体積積分を実行する必要がある．
また，磁化に履歴依存性がある場合，式(29)の仕事は磁化の経路にも依存し得る．

## 6．楕円体形状の磁性体における反磁場

一般の形状の磁性体では，反磁場 $\mathbf H_M$ の空間分布を求めるには，式(8)〜式(10)を境界条件とともに解く必要がある．
ただし，磁性体が一様に磁化された楕円体である場合，磁性体内部の反磁場は一様になるという重要な性質がある．

楕円体の主軸を $x,y,z$ 軸に選ぶと，反磁場の各成分は，

```math
\boxed{
(H_M)_x=-N_xM_x,\qquad (H_M)_y=-N_yM_y,\qquad (H_M)_z=-N_zM_z
}
\tag{30}
```

と書ける．
ここで $N_x,N_y,N_z$ は反磁場係数であり，楕円体の主軸の長さの比によって定まる．
Gaussian 単位系では，

```math
\boxed{
N_x+N_y+N_z=4\pi
}
\tag{31}
```

である．

一般の楕円体では $N_x,N_y,N_z$ が異なるため，磁化ベクトル $\mathbf M$ が複数の主軸方向の成分を持つ場合，反磁場 $\mathbf H_M$ は磁化ベクトルと必ずしも平行にならない．
磁化が主軸の1つに沿う場合には，その成分に対する反磁場は磁化と反平行になる．
また，球の場合は3つの反磁場係数が等しくなるので，任意の磁化方向について反磁場は磁化と反平行になる．

したがって，単一の係数 $N$ を用いて $\mathbf H_M=-N\mathbf M$ と表せるのは，球の場合や，磁化が楕円体の主軸方向を向いている場合などに限られる．

## 7．結論

Maxwell 方程式から導いたエネルギー収支は，

```math
\boxed{
\begin{aligned}
P_{\mathrm{source}} ={}&\int\rho j^2\,dV +\frac{d}{dt}\int_{\mathbb R^3} \frac{H^2}{8\pi}\,dV \\
&+\int_{V_m}\mathbf H\cdot \frac{\partial\mathbf M}{\partial t}\,dV
\end{aligned}
}
```

である．
これは，電源が供給する仕事率が，ジュール熱，磁場エネルギーの変化，磁化を変化させるための仕事率に分かれることを示している．

磁場や磁化が一様でない一般の場合には，各項を空間的に積分しなければならない．
特に磁化の仕事は，

```math
\boxed{
A=\int_{V_m} \left(\int_{\text{磁化過程}} \mathbf H\cdot d\mathbf M\right)dV
}
```

によって与えられ，磁性体自身が作る反磁場の寄与も含まれる．

以上が，Maxwell 方程式から出発し，反磁場の効果を含めて磁化に必要な仕事を導いた結果である．
