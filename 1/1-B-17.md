# 演習問題【1-B-17】

## 解答

問題［5］で導出した音速の式

```math
C^2=\gamma\frac{p}{\rho}
\tag{1}
```

を用いて，内部エネルギー $u$ およびエンタルピー $h$ を音速 $C$ で表す．

ここで， $p$ は圧力， $\rho$ は密度， $T$ は絶対温度， $\gamma=c_p/c_v$ は比熱比である．
また， $c_p$ と $c_v$ はそれぞれ単位質量当たりの定圧比熱と定積比熱， $R_{\mathrm{spec}}=R/M$ は比気体定数である．

### 1．比熱と温度の関係

理想気体の状態方程式を単位質量当たりの形で表すと，

```math
\frac{p}{\rho}=R_{\mathrm{spec}}T
\tag{2}
```

となる．

また，理想気体では，定圧比熱と定積比熱の間にマイヤーの関係式

```math
c_p-c_v=R_{\mathrm{spec}}
\tag{3}
```

が成り立つ．
式（3）を式（2）に代入すると，

```math
\frac{p}{\rho}=(c_p-c_v)T
\tag{4}
```

を得る．

ここで，比熱比 $\gamma=c_p/c_v$ より，

```math
c_p=\gamma c_v
```

であるから，

```math
c_p-c_v=(\gamma-1)c_v
```

となる．
これを式（4）に代入すると，

```math
\boxed{\frac{p}{\rho}=(\gamma-1)c_vT}
\tag{5}
```

が得られる．

### 2．音速を用いた表現

式（1）の音速の式に，式（5）を代入すると，

```math
\begin{aligned}
C^2
&=\gamma\frac{p}{\rho}\\
&=\gamma(\gamma-1)c_vT
\end{aligned}
```

となる．
したがって，

```math
\boxed{
c_vT=\frac{C^2}{\gamma(\gamma-1)}
}
\tag{6}
```

が得られる．
この関係を用いて，内部エネルギーとエンタルピーを順に求める．

### 3．内部エネルギー $u$ の導出

定積比熱 $c_v$ が一定の理想気体では，単位質量当たりの内部エネルギーは温度 $T$ のみの関数であり，

```math
u=c_vT+\text{const.}
\tag{7}
```

と表される．
ここで， $\text{const.}$ は内部エネルギーの基準の取り方によって決まる定数である．

式（6）を式（7）に代入すると，

```math
u=\frac{C^2}{\gamma(\gamma-1)}+\text{const.}
```

となる．
よって，

```math
\boxed{
u=\frac{C^2}{\gamma(\gamma-1)}+\text{const.}
}
```

が示された．

### 4．エンタルピー $h$ の導出

単位質量当たりのエンタルピーは，内部エネルギーと圧力・比体積の積を用いて，

```math
h=u+pv
```

と定義される．
ここで，比体積 $v$ は密度の逆数 $v=1/\rho$ であるため，

```math
h=u+\frac{p}{\rho}
\tag{8}
```

と書ける．

式（7）および式（5）を式（8）に代入すると，

```math
\begin{aligned}
h
&=c_vT+\text{const.}+(\gamma-1)c_vT\\
&=\gamma c_vT+\text{const.}
\end{aligned}
```

となる．

さらに，式（6）を代入すると，

```math
\begin{aligned}
h
&=\gamma\frac{C^2}{\gamma(\gamma-1)}+\text{const.}\\
&=\frac{C^2}{\gamma-1}+\text{const.}
\end{aligned}
```

を得る．
したがって，

```math
\boxed{
h=\frac{C^2}{\gamma-1}+\text{const.}
}
```

が示された．

以上より，求める関係式

```math
\boxed{
u=\frac{C^2}{\gamma(\gamma-1)}+\text{const.},
\qquad
h=\frac{C^2}{\gamma-1}+\text{const.}
}
```

が得られる．
