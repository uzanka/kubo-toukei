# 演習問題【1-B-17】

## 解答

与えられた条件および，問題[5]ですでに導出された音速の式 $C^2 = \gamma \frac{p}{\rho}$ を用いる．

### 1. 準備：比熱と温度・密度の関係

まず，理想気体の状態方程式および比熱の定義から，関係式を整理する．

理想気体の状態方程式は，単位質量あたりでは次のように書ける：

$$\frac{p}{\rho} = R_{\text{spec}} T \quad \cdots (1)$$

ここで $R_{\text{spec}} = R/M$ は比気体定数である．

また，定圧比熱 $c_p$ と定積比熱 $c_v$ の間には，以下の関係がある：

$$c_p - c_v = R_{\text{spec}} T \quad \cdots (2)$$

これより，式(1)は次のように書き換えられる：

$$\frac{p}{\rho} = (c_p - c_v) T \quad \cdots (3)$$

ここで，比熱比 $\gamma = \frac{c_p}{c_v}$ を用いると， $c_p = \gamma c_v$ であるから，

$$c_p - c_v = (\gamma - 1)c_v$$

となる．
これを式(3)に代入すると，

$$\frac{p}{\rho} = (\gamma - 1)c_v T \quad \cdots (4)$$

が得られる．

### 2. 音速 $C$ を用いた表現への変換

音速の式 $C^2 = \gamma \frac{p}{\rho}$ に，式(4)を代入する．

$$C^2 = \gamma \left[ (\gamma - 1)c_v T \right] = \gamma(\gamma - 1)c_v T \quad \cdots (5)$$

### 3. 内部エネルギー $u$ の導出

単位質量当たりの内部エネルギー $u$ は，定積比熱 $c_v$ と温度 $T$ を用いて次のように表される：

$$u = c_v T + \text{const.} \quad \cdots (6)$$

式(5)より， $c_v T$ について解くと：

$$c_v T = \frac{C^2}{\gamma(\gamma - 1)}$$

となる．
これを式(6)に代入すると，

$$u = \frac{C^2}{\gamma(\gamma - 1)} + \text{const.}$$

が得られ，示された．

### 4. エンタルピー $h$ の導出

エンタルピーの定義 $h = u + pv$ を，単位質量当たりの量として書き換えると：

$$h = u + \frac{p}{\rho} \quad \cdots (7)$$

となる．

式(7)に，式(6)と式(4)を代入する：

$$h = (c_v T + \text{const.}) + (\gamma - 1)c_v T$$

$$h = c_v T + (\gamma - 1)c_v T + \text{const.}$$

$$h = \gamma c_v T + \text{const.} \quad \cdots (8)$$

ここで，式(5)から得られた $c_v T = \frac{C^2}{\gamma(\gamma - 1)}$ を式(8)に代入する：

$$h = \gamma \left( \frac{C^2}{\gamma(\gamma - 1)} \right) + \text{const.}$$

$$h = \frac{C^2}{\gamma - 1} + \text{const.}$$

となり，こちらも示された．

## 解説

この問題では，理想気体の熱力学的性質（比熱，内部エネルギー，エンタルピー）と，音速という力学的な量との間の関係を導いている．

### 用語の整理

- 比熱 (Specific Heat): 物質1kgの温度を1K上げるのに必要な熱量．
    - 定積比熱 $c_v$ : 体積を一定に保ったときの比熱．
    - 定圧比熱 $c_p$ : 圧力を一定に保ったときの比熱．
- 比熱比 $\gamma$ : $c_p / c_v$ で定義される値．
理想気体において $\gamma > 1$ となる．
- 内部エネルギー $u$ : 物質が持っている微視的なエネルギーの総和．
理想気体では温度 $T$ のみに依存し， $u = c_v T$ と書ける．
- エンタルピー $h$ : 内部エネルギー $u$ に，その物質が押し広げるために必要な仕事 $pv$ を加えた量．
$h = u + pv$ ．
- 音速 $C$ : 断熱条件下での圧力波の伝播速度．
理想気体においては $C^2 = \gamma p / \rho$ という非常にシンプルな形で表される．

### 解法のポイント

この問題の鍵は，**「温度 $T$ を含む式」を「音速 $C$ を含む式」に書き換えること** にある．
音速の式には $p/\rho$ という項が含まれており，これは理想気体の状態方程式から $R_{\text{spec}} T$ （つまり温度に比例する量）に置き換えられる．
これを利用して，すべての熱力学的な量を $C^2$ の形で表現し直すことが求められている．
